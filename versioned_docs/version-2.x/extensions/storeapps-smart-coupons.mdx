[Smart Coupons](https://woocommerce.com/products/smart-coupons/) by StoreApps turns a coupon into store credit, such as a gift card: the customer spends part of it and keeps the rest for next time. StoreApps keeps that balance for online orders, but on its own it misses orders paid at the POS. The **WCPOS StoreApps Smart Coupons** extension fills the gap, so the right amount comes off the card and the balance left shows on the receipt.

This page is for the store's administrator. The extension works only with Smart Coupons by StoreApps (sold on WooCommerce.com), not with other plugins that have "Smart Coupons" in their name.

:::warning The till can't apply store credit yet
In WCPOS 2.0, the cart's **Add Discount** only applies percentage, fixed cart and fixed product coupons. Try to apply a store-credit coupon there and the till says **Coupon not found**. Take the payment another way, and keep the customer's card for later: nothing has been taken off it.
:::

## What it does {#what-it-does}

When a POS order carries a store-credit coupon, the extension:

- **Takes off what was spent, and no more.** It records how much of the card the order used, so StoreApps deducts that amount and leaves the rest on the card.
- **Deducts when the order is paid.** A POS order is paid from the POS's own open statuses, which StoreApps doesn't watch, so the extension asks StoreApps to deduct at that moment. It can't deduct twice.
- **Forgets a coupon you took off.** If the coupon is removed before payment, nothing is deducted for it.
- **Notes it on the order.** A private order note names the coupon, the amount used and the balance left.
- **Prints the balance on the receipt.** The coupon's discount row ends with the balance left.

With StoreApps Smart Coupons switched off, the extension does nothing.

## Install the extension {#install}

:::note Before you start
You need Smart Coupons by StoreApps active on the site, and an administrator login to **WP Admin**.
:::

### With WCPOS Pro {#install-pro}

1. In **WP Admin**, go to **POS → Settings → Extensions**.
2. Find **WCPOS StoreApps Smart Coupons** and press **Install**.
3. Press **Activate**.

See [Install an extension](./index.mdx#installing-an-extension) for updates and auto-updates.

### With the free plugin {#install-free}

The Extensions screen lists the extension, but its buttons need Pro. Instead:

1. Download `wcpos-storeapps-smart-coupons.zip` from the extension's [latest release](https://github.com/wcpos/wcpos-storeapps-smart-coupons/releases/latest).
2. In **WP Admin**, go to **Plugins → Add New Plugin** and press **Upload Plugin**.
3. Choose the file you downloaded and press **Install Now**.
4. Press **Activate Plugin**.

There is nothing to set up after that.

## What the receipt shows {#receipt}

The coupon's discount row ends with the card's balance after the sale. On the **Standard Receipt**, a store-credit coupon whose description is **Gift card** prints:

```text
Discount · Gift card — Store credit balance: $61.50
```

The balance is the card's balance when the receipt is made, which at checkout is right after the sale. Your receipt template needs nothing new. To print **Gift Card** instead of **Discount** on that row, see [For developers](#developers).

## The note on the order {#order-note}

When the order is paid, the extension adds one private note to it, which staff see on the order in **WP Admin → WooCommerce → Orders**:

```text
StoreApps Smart Coupons store credit recorded for WCPOS: Coupon store100 used $38.50. Current balance: $61.50.
```

Use it to check which card paid, how much it covered, and what was left on it. The note is added once per order.

## Refunds and cancellations {#refunds}

The extension doesn't put credit back. When you refund or cancel an order paid partly with store credit, StoreApps decides what happens to the balance. Check the coupon's amount in **WP Admin → Marketing → Coupons** afterwards.

## If something goes wrong {#goes-wrong}

**Coupon not found** when you apply a gift card at the till. The WCPOS 2.0 till can't apply store-credit coupons. See the warning at the top of this page.

**The balance didn't go down after the sale.** Check that both **Smart Coupons** and **WCPOS StoreApps Smart Coupons** are active in **Plugins**. The deduction happens when the order is paid, not when the coupon goes on. An order with no store-credit note was not deducted by the extension.

**The receipt has no balance.** A receipt printed while the till is offline is built on the device, and the balance comes from your store. Print it again once the till is back online. If your store's receipt template doesn't print the discount row's label, add it; see [Receipt Data](../receipts/receipt-data.mdx#discounts).

<details>
<summary>For developers: stored data and hooks</summary>

<span id="developers"></span>

The extension adds no WCPOS coupon fields. It works through WooCommerce order meta and StoreApps' own balance logic. It applies only to POS orders (`wcpos_is_pos_order()`: `created_via` is `woocommerce-pos`) and only to coupons of type `smart_coupon`.

- **Usage.** On `woocommerce_order_after_calculate_totals` it writes StoreApps' `smart_coupons_contribution` order meta (coupon code → amount used) and `wc_sc_environment`, when StoreApps hasn't. It drops entries for coupons no longer on the unpaid order.
- **Calculation outside REST.** While an unpaid POS order with a `smart_coupon` line recalculates outside a REST request (the coupon form on the payment page), it reports a REST context so StoreApps' own order-discount logic runs.
- **Deduction.** On `woocommerce_order_status_changed` from any status other than `pending` or `failed` (for a POS order, `pos-open` or `pos-partial`) to a paid status or `on-hold`, it calls StoreApps' `WC_SC_Coupon_Process::update_smart_coupon_balance()`, which marks each coupon line so it never deducts twice.
- **Order note.** Added on the move to `processing`, `completed` or `on-hold`, once per order (`_wcpos_storeapps_smart_coupons_audit_note_added`).
- **Receipt.** It filters `woocommerce_coupon_get_description` while a WCPOS receipt renders, and on the receipt data filter it adds `gift_card: true` to the store-credit row in `discounts` and appends the balance to its `label`. A template can then print:

```text
{{#discounts}}{{#gift_card}}Gift Card{{/gift_card}}{{^gift_card}}{{i18n.discount}}{{/gift_card}} · {{label}}{{/discounts}}
```

- **Hook names.** Version 0.2.3 still hooks the pre-2.0 names `woocommerce_pos_receipt_data`, `woocommerce_pos_before_template_render` and `woocommerce_pos_after_template_render`. WCPOS 2.0 still fires them after their `wcpos_` names, and WordPress logs a deprecation notice for each when `WP_DEBUG` is on. See [Hook naming](./index.mdx#hook-naming).

Source: [github.com/wcpos/wcpos-storeapps-smart-coupons](https://github.com/wcpos/wcpos-storeapps-smart-coupons).

</details>

:::info With WCPOS Pro
Install and update the extension from **POS → Settings → Extensions**. Without Pro, install it by hand from its release, as above. It works the same either way.
:::
