## What this means {#what-this-means}

Your store's reply had stray text in it, which WCPOS tried to clean up.

Check the action you were doing finished — the clean-up does not always work. The stray text usually comes from a plugin or a PHP notice printing extra output into store responses. If this appears often, ask your site admin to check the site's PHP error log for warnings.

## Your data {#your-data}

If the action you were doing didn't finish (see Troubleshoot step 1), follow that request's guidance; otherwise no order or product data is affected. If this appears often, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

1. Check the action you were doing finished — for example that the sale or change now shows. If it did, nothing more is needed. If it didn't, try it again; if that fails, follow the error it shows or contact support.
2. The cause is on the site: a plugin or theme is printing warnings or stray output into REST responses. Ask the site administrator to check the site's logs for PHP notices at the failure time.
3. **For the site admin:** the browser's developer tools (Network tab) — or **Advanced → Toggle Developer Tools** in the desktop app — show the raw response body; the stray output is visible immediately before or after the JSON.
4. **For the site admin:** the clean-up is best-effort — if this appears often, fix the offending plugin rather than relying on it.
