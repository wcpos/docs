## What this means {#what-this-means}

This variation could not be added to the product.

Nothing else changed. Open the product and check whether the variation is there; if it isn't, make sure it uses attributes set on the parent product, then add it again.

## Your data {#your-data}

Don't clear this device's data — it may hold changes your store doesn't have yet. Nothing else changed — only this variation was not added.

## Troubleshoot {#troubleshoot}

### At the till {#at-the-till}

1. Expand [the log entry](#log-entry) for the store's reason — usually a missing attribute or an invalid option combination.
2. Open the product and check whether the variation is there — if it is, don't add it again.
3. If it isn't, check the variation uses attributes set on the parent product, correct its fields, then add it again.
4. Still refused? Use **Copy debug info** in [**Store health → Logs**](#log-entry) and contact support.

### On the store {#on-the-store}

For the site administrator, in WP Admin.

1. Check the parent product's attributes — every attribute the variation uses must exist on the parent and be marked as used for variations.

## Find the entry in the log {#log-entry}

Every code is logged in **Store health → Logs**. Press **Errors**, then tap the entry with this code to open it under its row. The picture shows an example entry, AUTH201; on your till the entry shows this page's code.

1. **Errors** — the filter that's on.
2. **The entry** — the code in **Status** is its error code.
3. **What happened and what to do** — what your store said, when it said something, then one line on what to do. When it matters, a warning comes first, such as **Payment has been taken — don't charge again.** or **Don't clear this device's data**.
4. **Help** — opens the code's page in these docs.
5. **Open record** — opens the order, product or customer the entry is about, when this till has it, your store has WCPOS Pro, and you're allowed to edit it.
6. **Copy** — copies the whole entry for support. The rows under it are for support; you don't need to read them.
