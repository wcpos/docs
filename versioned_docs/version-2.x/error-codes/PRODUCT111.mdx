## What this means {#what-this-means}

This variation could not be added to the product.

Nothing else changed. Open the product and check whether the variation is there; if it isn't, make sure it uses attributes set on the parent product, then add it again.

## Your data {#your-data}

Don't clear this device's data — it may hold changes your store doesn't have yet. Nothing else changed — only this variation was not added.

## Troubleshoot {#troubleshoot}

1. Expand the log entry for the store's reason — usually a missing attribute or an invalid option combination.

**At the till:** open the product and check whether the variation is there — if it is, don't add it again. If it isn't, check the variation uses attributes set on the parent product, correct its fields, then add it again.

**On the store (WP Admin):** check the parent product's attributes — every attribute the variation uses must exist on the parent and be marked as used for variations.

Still refused? Use **Copy debug info** on the **Logs** tab and contact support.
