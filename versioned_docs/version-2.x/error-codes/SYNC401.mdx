## What this means {#what-this-means}

A background sync task stopped unexpectedly before finishing.

The POS restarts these tasks automatically and no order data is affected. If this code keeps appearing, export diagnostics and contact support.

## Your data {#your-data}

No order or product data is affected. If this persists, export diagnostics and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Nothing to do on first sight: the POS restarts the crashed background task automatically and no order data is involved.
2. If the code repeats within minutes, reload the app once so the sync engine starts clean.
3. If it still repeats, export debug info and contact support — a recurring task crash is an app defect worth reporting, not a store problem.
