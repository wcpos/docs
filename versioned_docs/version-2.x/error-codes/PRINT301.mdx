**Symptom:** after you press **Print receipt**, a pop-up reads "The selected printer cannot be reached." Its second line says what to check, such as "The printer did not answer. Check it is on and connected, then try again."

**Do this now:** check the printer is switched on and its cable or network is connected.

## Fix it at the till {#at-the-till}

1. Check the printer's power and cable. A network printer must be on the same network as this device.
2. Print the printer's self-test page. It shows the printer's IP address.
3. Open **Settings → Printing** and press **Edit** on the printer's row. Check **IP Address** and **Port**, or press **Scan Network**. Changes save as you make them.
4. Press **Test Print**, then print the receipt again.
5. **If Test Print fails too:** read the reason it shows, then see [If something goes wrong](../hardware/printers/index.mdx#when-nothing-prints).

## Is anything lost? {#your-data}

No. The sale is saved and complete. Only the receipt is missing: print it once the printer answers.

## If it keeps happening {#keeps-happening}

If a network printer worked before, check whether its address changed. See [Give the printer a fixed address](../hardware/printers/network-address.mdx).

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with the printer's **Copy setup report**.

<details>
<summary>Code details for support</summary>

<ErrorMeta code="PRINT301" />

A connection error, a timeout, a refused connection or a missing address. **Test Print** and the cash-drawer test log it without this pop-up.
