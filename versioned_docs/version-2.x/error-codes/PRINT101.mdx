## What this means {#what-this-means}

Automatic printing did not start for this receipt.

The sale is saved. Open the order's receipt and tap **Print Receipt**. Then check the automatic-printing settings and the printer so the next receipt prints by itself.

## Your data {#your-data}

The sale is saved. No order or product data is affected.

## Troubleshoot {#troubleshoot}

### At the till {#at-the-till}

1. On the receipt shown after the sale, press **Print Receipt** to print it by hand — the sale is unaffected.
   - If no receipt is on screen, on WCPOS Pro open **Orders**, use the order's **Receipt** action and press **Print Receipt**.
2. If nothing prints after sales at all, automatic printing is probably off: open the cart's settings (the sliders icon above the cart) and turn on **Automatically print receipt after checkout**. It prints whether **Automatically show receipt after checkout** is on or off.
3. Check the printer in **Settings → Printing**: the printer you expect is listed under **Printers**, and **Test Print** from its **Edit** screen prints.
4. If **Print Receipt** fails too, it is the printer or its connection — see [PRINT301](/error-codes/PRINT301).
   - If manual printing works but automatic printing keeps failing with that setting on, use **Copy debug info** in [**Store health → Logs**](#log-entry) and contact support.

## Find the entry in the log {#log-entry}

Every code is logged in **Store health → Logs**. Press **Errors**, then tap the entry with this code to open it under its row.

<JourneyShot manifest={logs} device="tablet" step={3} offsets={[[50, 0], [64, -10], [-54, -97], [131, 0], [101, 0], [-33, 0]]} alt="An error entry opened under its row in Store health → Logs: what the server said, what to do, Open record, the Help link, the event code with Copy, and the record, operation and request">

1. **Errors** — the filter that's on.
2. **The entry** — the code in **Status** is its error code.
3. **What happened and what to do** — what your store said, when it said something, then one line on what to do. When it matters, a warning comes first, such as **Payment has been taken — don't charge again.** or **Don't clear this device's data**.
4. **Help** — opens the code's page in these docs.
5. **Open record** — opens the order, product or customer the entry is about, when this till has it, your store has WCPOS Pro, and you're allowed to edit it.
6. **Copy** — copies the whole entry for support.
