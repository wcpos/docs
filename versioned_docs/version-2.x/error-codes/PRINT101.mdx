## What this means {#what-this-means}

Automatic printing did not start for this receipt.

Check the selected printer, template, and connection, then use Print now to print the receipt manually.

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

1. Use Print now to print the receipt by hand — the sale is unaffected.
2. Check the printing settings: the right printer is selected and a receipt template is chosen.
3. If auto-print fails on every sale, note whether manual printing works — manual-works-but-auto-fails is a settings problem; both failing is a printer problem.
