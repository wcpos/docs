## What this means {#what-this-means}

The store address is missing or not a valid URL.

Check the address for typos and include the full https:// URL of the store's WordPress site, then try again.

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

1. Check the address for typos and enter the full URL including https:// — for example https://shop.example.com.
2. Use the site's WordPress address, not an admin page or a checkout URL.
3. If the site lives in a subdirectory (for example /shop), include it.
