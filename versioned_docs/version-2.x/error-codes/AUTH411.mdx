## What this means {#what-this-means}

The store address is missing or not a valid URL.

Either the address field was empty, or your store answered but its WCPOS sign-in address is invalid — which is fixed on the store, not at the till.

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

1. Type the store's address into **Enter the URL of your WooCommerce store** — for example `shop.example.com` — and press **Connect**. A field holding only spaces counts as empty.
2. If the address is filled in and the message reads **"WCPOS login URL is invalid. Please ensure WCPOS plugin is properly configured"**, the problem is on the store. **Site administrator:** update WCPOS to the latest version in **WP Admin → Plugins**, deactivate and reactivate it, then press **Connect** again.
3. **Site administrator:** if that does not clear it, open `https://your-store.com/wp-json/` in a browser — or `https://your-store.com/?rest_route=/` if that returns a 404 (for example on plain permalinks). Under `authentication` → `wcpos` → `endpoints`, `authorization` should be a plain web address. If it is a list, an object or a number instead, a security, caching or REST-customising plugin is changing that response — disable those one at a time on a staging copy to find it.
