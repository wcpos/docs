# Error Codes

When WCPOS encounters an issue, it displays an error code that helps identify the problem. From **v1.10.0**, codes follow the format **domain + three digits** — for example `SYNC131` or `AUTH311`. The domain names the area of the POS; the number identifies the specific condition. Every code has its own page with what it means, what to do, and what it means for your data.

In the POS, error codes appear in **Store health → Logs**: expand a row and use the **Help** link to jump straight to the code's page here.

## Error Domains (v1.10.0+) {#error-domains}

| Domain | Area | Examples |
|--------|------|----------|
| `AUTH` | Login, sessions, and tokens | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | Completing orders at the till | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | The POS app itself and local storage | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `DISPLAY` | The customer-facing display | [DISPLAY101](./DISPLAY101) |
| `HOST` | Hosting and firewall rules that block the POS | [HOST101](./HOST101), [HOST121](./HOST121) |
| `LICENSE` | Pro licence activation and validation | [LICENSE101](./LICENSE101) |
| `PAYMENT` | Payment gateways and terminals | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | Receipt printing | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | Product data and catalogue operations | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `REGISTER` | Cash drawer, register sessions, and counts | [REGISTER101](./REGISTER101), [REGISTER211](./REGISTER211) |
| `SYNC` | Synchronisation between the POS and your store | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

Use the sidebar to browse every code in a domain, or search for the code directly.

Codes ending in `999` are the domain's catch-all for conditions that don't yet have a specific code.

## Codes from before v1.10.0 {#legacy-codes}

Codes such as `API04001` come from versions before v1.10.0 and are never shown by this version. If you are reading an old log entry or support thread, switch the version menu to **1.x** to look them up.
