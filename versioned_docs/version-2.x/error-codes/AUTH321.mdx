**Symptom:** after you press **Connect**, a pop-up reads "WooCommerce is not active on this site, so WCPOS cannot connect." with a **Help** button. Under **Connect**, red text reads "WooCommerce API not found", with a **Learn more** link to this page.

**Do this now:** send whoever looks after your website a link to this page and ask them to switch WooCommerce on.

## Fix it at the till {#at-the-till}

1. Send whoever looks after your website a link to this page.
2. Once WooCommerce is on again, press **Connect**.
3. **If it connects:** press **Sign in with WordPress** and carry on.
4. **If the red text shows again:** your store still doesn't show WooCommerce to WCPOS. Tell them again.

## Is anything lost? {#your-data}

No. Nothing on this device or on your store changed. WCPOS stopped before anything was saved.

## If it keeps happening {#keeps-happening}

WCPOS needs WooCommerce running on your website. Only whoever looks after your website can switch it on.

<details>
<summary>For whoever looks after your website</summary>

The app reads your store's REST API index (`/wp-json/`) and found no `wc/v3` namespace.

1. In WP Admin › **Plugins**, check WooCommerce is installed and active.
2. If a failed update switched it off, activate it and read any error banner. **WooCommerce › Status › Logs** records why it failed.
3. If WooCommerce is active, open `/wp-json/` in a browser. If `wc/v3` isn't under `namespaces`, something hides WooCommerce's REST routes.
4. Then the cashier presses **Connect** again.

</details>

## Still stuck? {#still-stuck}

Contact support with the red text and your store's address. Logs can't be opened from this screen.
