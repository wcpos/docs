## What this means {#what-this-means}

Syncing hit an unexpected problem.

Check the action named in this entry finished; if it didn't, repeat it. If this repeats, tap **Copy debug info** and send it to support.

## Your data {#your-data}

Changes not yet sent are kept on this device — don't clear its data. If the action named in the entry didn't finish, repeat it.

## Troubleshoot {#troubleshoot}

1. Expand the log entry and find the action it names. Check it finished — for a save, open the order or record and check the change shows up. If it did, WCPOS sends it by itself, so leave it.
2. If it didn't finish, repeat it. If the log entry says the change was never saved on this device, nothing was captured.
3. Note the code and any reason on the log entry: a 999 code means the specific cause has no dedicated code yet, so this context is exactly what support needs.
4. If this repeats, tap **Copy debug info** on the **Logs** tab and send it to support — reporting it is how the specific code gets added.
