## What this means {#what-this-means}

This browser lets only one tab send changes at a time.

WCPOS no longer raises this code: only one tab runs the POS. A second tab shows **The POS is open in another tab**; press **Take over here** to carry on in that tab, or go back to the first one. See [If the POS won't start](../getting-started/index.mdx#wont-start).

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

1. Use the POS in one tab. If a tab shows **The POS is open in another tab**, press **Take over here** to carry on there.
2. This browser (or a private window) lacks the tab-coordination feature the POS prefers, so it falls back to a single syncing tab. No fix is needed.
