## What this means {#what-this-means}

This browser lets only one tab send changes at a time.

You can keep using every tab — they all share the same local data. One tab quietly handles the syncing for all of them.

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

1. Keep using every tab normally — they share the same local data, and one tab quietly syncs on behalf of the rest.
2. This browser (or a private window) lacks the tab-coordination feature the POS prefers, so it falls back to a single syncing tab. No fix is needed.
