## What this means {#what-this-means}

WCPOS encountered an unexpected error.

Check whether your last action went through before trying again — for a sale, open the order and check its status. If it repeats, tap **Copy debug info** and send it to WCPOS support.

## Your data {#your-data}

The result couldn't be confirmed — check before trying again. If it repeats, use **Copy debug info** on the **Logs** tab and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Check whether your last action went through before trying again — for a sale, open the order and check its status; for a payment, also check the terminal or provider. If it didn't go through, try it once more.
2. Expand the log entry and note the event code and context — a 999 code means the failure has no dedicated code yet, and this is the information that identifies it.
3. If it repeats, tap **Copy debug info** on the **Logs** tab and send it to WCPOS support — reporting it is how the specific code gets added.
