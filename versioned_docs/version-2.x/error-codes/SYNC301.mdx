Current versions no longer show this code.

**Symptom:** **Store health → Logs** has an entry with this code: "Your store's list of changes moved unexpectedly, so WCPOS is re-checking it by itself. Nothing is lost."

**Do this now:** keep selling, because WCPOS checks your store's changes again by itself.

## Fix it at the till {#at-the-till}

1. Open **Store health**, then **Logs**. Press **All**, type SYNC301 in **Search Logs** and [open the entry](../support/logs.mdx#open).
2. If prices or stock still look out of date, go to **Database** and press **Check everything now**.
3. Don't clear data to fix it. The re-check already downloads this device's records again.
4. **Still wrong, or the code keeps coming back?** Press **Copy debug info** in **Logs** (**Share debug info** on phones and tablets) and send it to support.

## Is anything lost? {#your-data}

No. Until the re-check finishes, some prices or stock on this device can be out of date.

## If it keeps happening {#keeps-happening}

Send the debug info from step 4 to support. Nothing on your website needs changing for this code.

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with the time the entry appeared.
