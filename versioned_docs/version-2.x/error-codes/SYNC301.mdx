Current versions no longer show this code.

**Symptom:** **Store health → Logs** has an entry with this code: "Your store's list of changes moved unexpectedly, so WCPOS is re-checking it by itself. Nothing is lost."

{/* source: core.json:2450 (summary); registry error-registry.json:239-259; no pop-up of its own: apps/main/lib/sync-log-observer.ts:1144-1160 (warn row, no toast path) — NOTE no raise site at 6b2a2cb4f, see notes */}

**Do this now:** keep selling, because WCPOS checks your store's changes again by itself.

{/* source: core.json:2450, :2566; error-registry.json:250 */}

## Fix it at the till {#at-the-till}

1. Open **Store health**, then **Logs**. Press **All**, type SYNC301 in **Search Logs** and [open the entry](../support/logs.mdx#open).
2. If prices or stock still look out of date, go to **Database** and press **Check everything now**.
3. Don't clear data to fix it. The re-check already downloads this device's records again.
4. **Still wrong, or the code keeps coming back?** Press **Copy debug info** in **Logs** (**Share debug info** on phones and tablets) and send it to support.

{/* source: step 1 error-catalogue.json:642 (warn), so All, not Errors (logs-logic.ts:111-112); step 2 core.json:2566, :1985, packages/core/src/screens/main/health/database.tsx:854-864 (button runs engine.sync(), use-manual-sync.ts:73-94);
    step 3 apps/main/lib/sync-log-observer.ts:254-257 ("the same tick re-pulls the stored records and refreshes the reference lists"), current page's "don't clear data" warning; step 4 error-registry.json:254, core.json:2124, :2120, packages/core/src/screens/main/logs/index.tsx:344-354 */}

## Is anything lost? {#your-data}

No. Until the re-check finishes, some prices or stock on this device can be out of date.

{/* source: core.json:2450; error-registry.json:246 (dataSafety no-impact); current page "Your data" */}

## If it keeps happening {#keeps-happening}

Send the debug info from step 4 to support. Nothing on your website needs changing for this code.

{/* source: error-registry.json:254 (support-with-export); the cause is the app's own change-list position, apps/main/lib/change-signal-lane.ts:487-527 */}

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with the time the entry appeared.
