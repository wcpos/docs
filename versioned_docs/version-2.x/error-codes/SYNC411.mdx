**Symptom:** **Store health → Logs** has an entry with this code: "This device asked the store for data far more often than normal."

**Do this now:** keep working, because nothing was slowed down, blocked or lost.

## Fix it at the till {#at-the-till}

1. Open **Store health**, then **Logs**. Press **All**, type SYNC411 in **Search Logs** and [open the entry](../support/logs.mdx#open).
2. **If it appears once:** nothing to do.
3. **If it comes back:** note which screen was open and what you were doing when it appeared.
4. Press **Copy debug info** at the top of **Logs** (**Share debug info** in the phone and tablet apps) and send it to support with your note.

## Is anything lost? {#your-data}

No. WCPOS only counts the requests. It never slows, queues or drops one.

## If it keeps happening {#keeps-happening}

This can point to an app problem, such as a screen asking for the same data in a loop. Send the debug info within 30 days, while the entry is still in the log.

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with the screen and action you noted.
