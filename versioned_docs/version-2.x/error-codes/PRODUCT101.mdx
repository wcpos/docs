## What this means {#what-this-means}

This product change hasn't reached your store yet.

Read the reason shown, fix what it names or check your connection, then save the product again.

## Your data {#your-data}

Don't clear this device's data — it may hold changes your store doesn't have yet. After a connection failure, save the product again once you're connected. If the store refused the edit, this device goes back to the store's version instead (see [SYNC202](/error-codes/SYNC202)), so make the edit again once the reason is fixed. If this keeps happening, use **Copy debug info** in **Store health → Logs** and contact WCPOS support.

## Troubleshoot {#troubleshoot}

### At the till {#at-the-till}

1. Read the reason shown — [the log entry](#log-entry)'s error text usually shows whether this was a connection failure, a value the store refused, or a conflicting edit made in the store.
2. Then act on what it shows:
   - Connection failure: check the connection, then save the product again.
   - Refused value: correct what the reason names, then save the product again.
   - Conflicting edit: tell your site administrator which product it is (see [On the store](#on-the-store)).
3. If saves keep failing with no clear reason, use **Copy debug info** in [**Store health → Logs**](#log-entry) and contact support.

### On the store {#on-the-store}

For the site administrator, in WP Admin.

1. For a conflicting edit, open the product, compare it with what the till shows, and save the correct values once.

## Find the entry in the log {#log-entry}

Every code is logged in **Store health → Logs**. Press **Errors**, then tap the entry with this code to open it under its row. The picture shows an example entry, AUTH201; on your till the entry shows this page's code.

<JourneyShot manifest={logs} device="tablet" step={3} offsets={[[17, 28], [549, -9], [-54, -97], [131, 0], [101, 0], [-33, 0]]} alt="An error entry opened under its row in Store health → Logs: what the server said, what to do, Open record, the Help link, the event code with Copy, and the record, operation and request">

1. **Errors** — the filter that's on.
2. **The entry** — the code in **Status** is its error code.
3. **What happened and what to do** — what your store said, when it said something, then one line on what to do. When it matters, a warning comes first, such as **Payment has been taken — don't charge again.** or **Don't clear this device's data**.
4. **Help** — opens the code's page in these docs.
5. **Open record** — opens the order, product or customer the entry is about, when this till has it, your store has WCPOS Pro, and you're allowed to edit it.
6. **Copy** — copies the whole entry for support. The rows under it are for support; you don't need to read them.
