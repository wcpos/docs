**Symptom:** when you connect, red text under **Connect** reads "This store's hosting setup is blocking the app — the details page names the exact cause and fix.", with a **Learn more** link to this page.

**Do this now:** send whoever looks after your website a link to this page: only they can let the app past the bot check.

## Fix it at the till {#at-the-till}

1. Send whoever looks after your website a link to this page.
2. Ask them to let the app's requests past the bot check. The app can't solve the check itself.
3. Once it's fixed, enter **Your store's address** and press **Connect** again.
4. **If it connects:** carry on selling.
5. **If the red text shows again:** the check still answers instead of your store. Tell them again.

## Is anything lost? {#your-data}

No. No order or product data is affected, and nothing on your store changed.

## If it keeps happening {#keeps-happening}

A bot-protection service in front of your store answers with a check the app can't solve. Only whoever looks after your website can let the app through.

<details>
<summary>For whoever looks after your website</summary>

The store's REST API returns an HTML challenge page (bot protection, CAPTCHA or DDoS interstitial) where the app expects JSON.

1. Identify the protection layer from the challenge page (Cloudflare, Sucuri, Kinsta and others brand theirs) and open its settings.
2. Allow-list the REST API paths, `/wp-json/` and `/?rest_route=`, for API traffic.
3. On Cloudflare, add a WAF **Skip** rule for those paths. Bot Fight Mode (Free plan) can't be bypassed by any rule: turn it off. The [Cloudflare guide](../support/troubleshooting/cloudflare.mdx#add-a-skip-rule) has the rule and a `curl` check.
4. On Kinsta, allow-list the REST paths in its bot and firewall settings. On Sucuri, avoid the JavaScript-challenge DDoS mode for API routes.

</details>

## Still stuck? {#still-stuck}

If your host says nothing is blocked, tell support the code and when it happened.

<SupportContact />

<details>
<summary>Code details for support</summary>

<ErrorMeta code="HOST121" />

Store discovery or the sign-in check got an HTML challenge page instead of JSON. Logged under the connect message, or as "Store host blocked authorization probes".

</details>
