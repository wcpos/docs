**Symptom:** a red pop-up reads "WCPOS couldn't write a change to this device's storage.", with a **Help** button.

**Do this now:** write down the change you were making, with the values you entered: if WCPOS closes before it's written, it's gone. Then free up storage on this device, and leave its data where it is.

:::warning

Don't clear this device's data. It can hold sales that haven't reached your store.

:::

## Fix it at the till {#at-the-till}

1. Remove files or apps you don't need to free up space. Not the browser's **Clear browsing data**: it deletes unsent sales too.
2. Check the change you were making shows up. If it's missing, enter it again.
3. Still won't save? Restart WCPOS once (on the web, reload the tab) and try a small change you can undo.
4. Open **Store health**, then **Logs**, press **Errors** and [open the entry](../support/logs.mdx#open). Note the record it names: that change isn't saved.
5. **If changes keep failing:** [send the log to support](../support/logs.mdx#for-support) before you repair anything.

## Is anything lost? {#your-data}

Only the change that failed, if it isn't there when you check. Everything already saved stays on this device unless you clear its data, reset WCPOS or uninstall it.

## If it keeps happening {#keeps-happening}

If changes keep failing with space free, send the log to support before any repair.

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with the record the entry names.
