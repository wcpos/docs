## What this means {#what-this-means}

The updater is not authorized to download WCPOS Pro updates.

Re-authorize the updater for this store, then check for updates again.

## Your data {#your-data}

No order or product data is affected. If this persists, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

1. Re-enter or re-activate the license key in the POS settings so the updater can authenticate.
2. Check for updates again from WP Admin → Dashboard → Updates.
3. If authorization keeps failing, the site may be blocking outbound requests to the update server — ask the host whether outbound HTTPS is restricted.
