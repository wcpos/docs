## What this means {#what-this-means}

The store did not accept the sign-in credentials.

Re-enter the username and password, or reset the password in WordPress if it keeps failing. No order data is affected.

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

**At the till** — for the cashier: re-enter the username and password; the store refused this pair.

**On the store** — for the site administrator:

1. Confirm the account works by signing in to WP Admin with the same credentials; reset the password there if it fails.
2. If the credentials work in WP Admin but not in the POS, a login-protection or security plugin may be blocking programmatic sign-in — check its settings.
