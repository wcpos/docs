**Symptom:** a till on WCPOS 1.10 or 1.11 logs CLIENT141: search returned results that didn't match what you typed, and WCPOS hid them. WCPOS 2 searches another way and doesn't log this code.

**Do this now:** run the search again; there's nothing to fix unless results still look wrong.

## Fix it at the till {#at-the-till}

1. Run the search again. Results that didn't match are hidden, and WCPOS rebuilds search once per list in each session.
2. Still wrong? Reload: close WCPOS completely and open it again, or reload the tab on the web.
3. **If results look right:** there's nothing more to do.
4. **If they're still wrong:** note the search you typed and contact support.

## Is anything lost? {#your-data}

No. Search only reads the products on this device. Nothing on your store or on the till changed.

## If it keeps happening {#keeps-happening}

WCPOS 2 no longer uses this search index, so it can't log this code. See [Upgrade to 2.0](../getting-started/upgrading-to-2.mdx) for whether your store can move.

## Still stuck? {#still-stuck}

Contact support with the search you typed and the till's WCPOS version.
