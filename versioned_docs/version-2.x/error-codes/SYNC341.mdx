## What this means {#what-this-means}

This store now requires a newer version of the POS app.

Your store's WCPOS plugin has moved to a newer sync protocol than this version of the app speaks, and the store deliberately pauses syncing until the app is updated. This is a protection, not a fault: it stops an out-of-date app from reading or writing store data incorrectly. Update WCPOS (on the web, reload the page), then reopen. If this till runs 1.11, read [Your data](#your-data) first.

## Your data {#your-data}

A 1.11 till that updates to 2.0 loses what it hasn't sent. The first time a till opens 2.0, it clears the 1.11 data on that device: any sale, open order or change it hasn't sent to your store by then is lost, and it can't be got back. Until then it is still on the device, but this screen means your store refuses the till's syncs, so it can't be sent from here. Follow step 1 before you update the app or reload the page.

## Troubleshoot {#troubleshoot}

1. **If this till runs 1.11 and still has sales or open orders it hasn't sent, send them before you update.** Don't update the app, and on a browser till don't reload the page. Ask your site administrator to reinstall the 1.11 plugin; the till then reconnects and sends them. Wait until **changes waiting to send** in **Store health → Database** reads **0**, and finish each open order or press **Save to Server** on it. Only then update the store and this till to 2.0 again. Do the same for every other till that hasn't opened 2.0 yet. The full steps are in [A 1.11 till still has unsent sales](../getting-started/upgrading-to-2.mdx#unsent-sales).
2. On the web app, reload the browser tab — the web app picks up the new version on reload. If the screen comes back, use a hard reload (hold **Shift** while reloading).
3. On desktop, install the pending update and reopen the app — the check runs when the app reconnects. If no update is offered, download the latest build from the [Installation](/getting-started/installation) page.
4. On iPhone, iPad or Android, update WCPOS through the channel you installed it from — TestFlight on iOS, the Play testing programme on Android; both are linked from the [Installation](/getting-started/installation) page — then reopen the app.
5. **Site administrator:** if no newer app is available yet, the store's WCPOS plugin was updated ahead of the matching app release. Restoring the previous WCPOS plugin version on the store resumes syncing until the newer app ships.
6. If neither an app update nor a plugin rollback is available to you, contact WCPOS support.
