## What this means {#what-this-means}

The customer-facing display could not build the picture of the cart it was about to show, so it fell back to the idle screen.

The till itself is unaffected — keep serving. The display builds the snapshot again the next time the cart changes, so adding or removing a line usually brings it straight back.

## Your data {#your-data}

No order or product data is affected. Nothing about the sale is changed by this, and the customer display is a mirror rather than a record.

## Troubleshoot {#troubleshoot}

### At the till {#at-the-till}

1. Carry on with the sale. The till keeps working, and only the customer display returns to the idle screen.
2. Add or change a cart line — the display rebuilds the snapshot on the next cart change and normally recovers on its own.
3. If the display stays on the idle screen through several cart changes, check it is still listed under **Paired displays** in **Settings → Customer Display**.
4. Then close and reopen the display window.
5. If it keeps happening, note the affected order, use **Copy debug info** in [**Store health → Logs**](#log-entry), and send both to support. A snapshot that fails repeatedly on the same cart usually points at one line item rather than the display itself.

## Find the entry in the log {#log-entry}

Every code is logged in **Store health → Logs**. Press **Errors**, then tap the entry with this code to open it under its row. The picture shows an example entry, AUTH201; on your till the entry shows this page's code.

1. **Errors** — the filter that's on.
2. **The entry** — the code in **Status** is its error code.
3. **What happened and what to do** — what your store said, when it said something, then one line on what to do. When it matters, a warning comes first, such as **Payment has been taken — don't charge again.** or **Don't clear this device's data**.
4. **Help** — opens the code's page in these docs.
5. **Open record** — opens the order, product or customer the entry is about, when this till has it, your store has WCPOS Pro, and you're allowed to edit it.
6. **Copy** — copies the whole entry for support.
