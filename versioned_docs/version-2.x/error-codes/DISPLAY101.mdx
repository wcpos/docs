## What this means {#what-this-means}

The customer-facing display could not build the picture of the cart it was about to show, so it fell back to the idle screen.

The till itself is unaffected — keep serving. The display builds the snapshot again the next time the cart changes, so adding or removing a line usually brings it straight back.

## Your data {#your-data}

No order or product data is affected. Nothing about the sale is changed by this, and the customer display is a mirror rather than a record.

## Troubleshoot {#troubleshoot}

1. Carry on with the sale. The till keeps working, and only the customer display returns to the idle screen.
2. Add or change a cart line — the display rebuilds the snapshot on the next cart change and normally recovers on its own.
3. If the display stays on the idle screen through several cart changes, check it is still listed under **Paired displays** in **Settings → Customer Display**, then close and reopen the display window.
4. If it keeps happening, note the affected order, use **Copy debug info** on the Logs screen, and send both to support. A snapshot that fails repeatedly on the same cart usually points at one line item rather than the display itself.
