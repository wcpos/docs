## What this means {#what-this-means}

Your store no longer has this order, so this device settled its own copy.

Someone deleted (trashed) the order in WP Admin while this device still held it. The store's copy is gone, so this device either keeps the cart as a new order or removes its own copy.

## Your data {#your-data}

An open cart is kept and sent again as a new order with a new number. It is sent the next time you press **Pay**. Any other order is removed from this device, because the store's copy is gone. Nothing else is waiting to send.

## Troubleshoot {#troubleshoot}

1. Expand the log entry: it names the order number the store deleted and whether this device kept the cart as a new order or removed its copy.
2. If the cart was kept, the sale continues as normal. It reaches the store as a new order with a new number when you press **Pay**.
3. If the order was removed and that was a mistake, a store admin can restore it from **WooCommerce → Orders → Trash** in WP Admin. This device picks it up again on its next refresh.
4. If the same order keeps being reported, an admin is deleting orders this device is still using. Agree who closes open carts before they are trashed.
