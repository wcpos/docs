## What this means {#what-this-means}

Your store no longer has this order, so this device settled its own copy.

Someone deleted (trashed) the order in WP Admin while this device still held it. The store's copy is gone, so this device either keeps the cart as a new order or removes its own copy.

## Your data {#your-data}

An open cart is kept and sent again as a new order with a new number. It is sent the next time you press **Checkout**. Any other order is removed from this device, because the store's copy is gone. Nothing else is waiting to send.

## Troubleshoot {#troubleshoot}

### At the till {#at-the-till}

1. Expand [the log entry](#log-entry): it names the order number the store deleted and whether this device kept the cart as a new order or removed its copy.
2. If the cart was kept, the sale continues as normal. It reaches the store as a new order with a new number when you press **Checkout**.
3. If the order was removed and that was a mistake, ask your site administrator to restore it. This device picks it up again on its next refresh.

### On the store {#on-the-store}

For the site administrator.

1. To restore a removed order, open **WooCommerce → Orders → Trash** in WP Admin.
2. If the same order keeps being reported, an admin is deleting orders this device is still using. Agree who closes open carts before they are trashed.

## Find the entry in the log {#log-entry}

Every code is logged in **Store health → Logs**. Press **Errors**, then tap the entry with this code to open it under its row.

1. **Errors** — the filter that's on.
2. **The entry** — the code in **Status** is its error code.
3. **What happened and what to do** — what your store said, when it said something, then one line on what to do. When it matters, a warning comes first, such as **Payment has been taken — don't charge again.** or **Don't clear this device's data**.
4. **Help** — opens the code's page in these docs.
5. **Open record** — opens the order, product or customer the entry is about, when this till has it, your store has WCPOS Pro, and you're allowed to edit it.
6. **Copy** — copies the whole entry for support.
