## What this means {#what-this-means}

Search was missing a product it should have found.

Nothing to do unless a product you can see still won't come up in search — then reload WCPOS.

A periodic self-check asked the local search index for a record by that record's own words, and the index did not return it. That means searches may have been showing fewer results than this device really holds. The app may rebuild the index by itself, but only once per list per session, so a rebuild isn't guaranteed.

## Your data {#your-data}

No store data was changed. This concerns only the local search index, which is derived from the data already on this device — nothing is lost when it is rebuilt.

## Troubleshoot {#troubleshoot}

1. Nothing to do unless a product you can see still won't come up in search — sales can continue normally. The app may rebuild the index by itself, but only once per list per session, so if this code repeats, continue to the next step.
2. If search still misses records you can see in the app — a product, customer, order or other list — reload the app: on web, reload the browser tab; on desktop and mobile, close and reopen the app. That lets it attempt a fresh rebuild the next time the problem is detected.
3. If the code returns after a reload, use **Copy debug info** on the **Logs** tab and contact support — the log entry includes the details support needs to identify the affected list and the record the index missed.
