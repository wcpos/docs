Current versions no longer show this code.

**Symptom:** a checkout ends with no result from your store, so the till can't tell whether the order was created.

**Do this now:** check whether the order was created and paid before you charge again.

:::warning

Don't press **Charge** or charge the customer again until you know whether this sale was paid.

:::

## Fix it at the till {#at-the-till}

1. Check the payment: the card terminal or provider's screen, or the cash drawer.
2. **With WCPOS Pro:** in **Store health → Database**, press **⋮** on **Orders**, then **Check for changes now**, and open the order in **Orders**.
3. **Without Pro:** ask a manager to find the order in **WooCommerce → Orders** by its total and time.
4. **If it reads Processing or Completed, or the customer paid:** don't charge again. Reload the app so the till finishes the sale.
5. **If there's no order and no charge:** press **Charge** once more.

## Is anything lost? {#your-data}

The order was often created, but the confirmation never arrived. Go by its status, not by finding it.

## If it keeps happening {#keeps-happening}

If it's unclear, press **Copy debug info** in **Store health → Logs**, contact support, and ask whoever looks after your website to check its logs.

<details>
<summary>For whoever looks after your website</summary>

An empty answer comes from a PHP crash after the order is created, or something cutting the response short.

1. In WP Admin, check **WooCommerce → Status → Logs** for a fatal error at the time of the checkout.
2. If that shows nothing, ask your host for the server's PHP error log.
3. For a developer: in the browser's developer tools, or the desktop app's **Advanced → Toggle Developer Tools**, the checkout request on the Network tab shows a success status with an empty or cut-off body.

</details>

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with the order number and time.
