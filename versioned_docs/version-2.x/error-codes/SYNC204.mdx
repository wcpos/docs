## What this means {#what-this-means}

The store had already closed this order, so it refused a change to its lines.

This device sent a change to an order's lines (items, fees, shipping or coupons) after the store had already closed that order: it was paid or completed, cancelled or refunded. The store does not change the lines of a closed order, so it refused the change and kept its own copy as it was.

## Your data {#your-data}

The store's copy of the order is unchanged. The refused change stays on this device, listed in **Store health → Database**, until you settle it. To make the change land, the order has to be reopened on the store first; otherwise discard the change.

## Troubleshoot {#troubleshoot}

1. Expand the log entry: it names the order the store refused and the store's reason. If it also shows a rounding fee amount, the refused change carried a cash rounding line.
2. Open the same order in **WooCommerce → Orders** in WP Admin and check its status and lines. If the store's copy is already right, nothing was lost: press **Discard** on the change's row in **Store health → Database**.
3. If the change is still needed, a store admin has to reopen the order in WP Admin first. Then press **Send again** on the row.
4. If the same order keeps being refused while it is still open on this device, another device or an admin is closing it. Agree who finishes the sale before changing it here.
