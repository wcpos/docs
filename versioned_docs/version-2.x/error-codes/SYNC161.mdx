## What this means {#what-this-means}

This device's storage stopped responding, so saving is paused.

Restart WCPOS (on the web, reload the tab), then check your last sale or change saved — a change made in the seconds before storage stopped may not have been written. Don't clear this device's data. If it keeps happening, contact support.

## Your data {#your-data}

Don't clear this device's data — it may hold sales that haven't reached your store. If this keeps happening, use **Copy debug info** on the **Logs** tab and contact WCPOS support.

## Troubleshoot {#troubleshoot}

### At the till {#at-the-till}

1. Restart WCPOS — close and reopen the app; on web, reload the tab rather than closing it. This reconnects the local database in almost all cases.
2. After restarting, check your last sale or change saved: a change made in the seconds before the failure may not have been written. If it is missing, enter it again.
3. On web, don't run the till in a private/incognito window, and avoid aggressive storage-cleaning extensions — both can tear down local storage mid-session, and closing a private window deletes everything stored in it, including unsent sales. If you are in one now, keep it open until **Store health → Database** shows 0 **changes waiting to send**, with no [panel asking for a decision](../support/store-health.mdx#needs-attention) and no open order left unsynced ([Save to store](../pos/cart/open-orders.mdx#sync-order)).
4. If this returns regularly on the same device, use **Copy debug info** on the [**Logs** tab](#log-entry) and contact support, noting what the device was doing (sleep, tab switch, low memory) when it happened.

**Store health → Database**, where these steps send you:

## Find the entry in the log {#log-entry}

Every code is logged in **Store health → Logs**. Press **Errors**, then tap the entry with this code to open it under its row. The picture shows an example entry, AUTH201; on your till the entry shows this page's code.

<JourneyShot manifest={logs} device="tablet" step={3} offsets={[[17, 28], [549, -9], [-54, -97], [131, 0], [101, 0], [-33, 0]]} alt="An error entry opened under its row in Store health → Logs: what the server said, what to do, Open record, the Help link, the event code with Copy, and the record, operation and request">

1. **Errors** — the filter that's on.
2. **The entry** — the code in **Status** is its error code.
3. **What happened and what to do** — what your store said, when it said something, then one line on what to do. When it matters, a warning comes first, such as **Payment has been taken — don't charge again.** or **Don't clear this device's data**.
4. **Help** — opens the code's page in these docs.
5. **Open record** — opens the order, product or customer the entry is about, when this till has it, your store has WCPOS Pro, and you're allowed to edit it.
6. **Copy** — copies the whole entry for support. The rows under it are for support; you don't need to read them.
