## What this means {#what-this-means}

This device's storage stopped responding, so saving is paused.

Restart WCPOS (on the web, reload the tab), then check your last sale or change saved — a change made in the seconds before storage stopped may not have been written. Don't clear this device's data. If it keeps happening, contact support.

## Your data {#your-data}

Don't clear this device's data — it may hold sales that haven't reached your store. If this keeps happening, use **Copy debug info** on the **Logs** tab and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Restart WCPOS — close and reopen the app; on web, reload the tab rather than closing it. This reconnects the local database in almost all cases.
2. After restarting, check your last sale or change saved: a change made in the seconds before the failure may not have been written. If it is missing, enter it again.
3. On web, don't run the till in a private/incognito window, and avoid aggressive storage-cleaning extensions — both can tear down local storage mid-session, and closing a private window deletes everything stored in it, including unsent sales. If you are in one now, keep it open until **Store health → Database** shows 0 **changes waiting to send**.
4. If this returns regularly on the same device, use **Copy debug info** on the **Logs** tab and contact support, noting what the device was doing (sleep, tab switch, low memory) when it happened.
