**Symptom:** a red pop-up reads "WCPOS couldn't set up or remove storage on this device.", with a **Help** button. It comes while WCPOS sets up, re-downloads or clears data on this device.

{/* source: core.json:2528 (title, no toast title at any site, so the summary is the title: packages/core/src/contexts/merchant-toast.ts:50-77), Help logger/index.ts:873-891;
    sites with showToast: packages/database/src/create-db.ts:39-46, :67-75, :98-105; packages/database/src/plugins/reset-collection.ts:225-233 (re-adding a collection after it is removed, :53-60); packages/database/src/clear-all-db.ts:43-51 (native clear); packages/database/src/purge-legacy-db.ts:93-101 */}

**Do this now:** free up storage on this device, then restart WCPOS.

{/* source: core.json:2644. No warning box: dataSafety no-impact, error-registry.json:1969 */}

## Fix it at the till {#at-the-till}

1. Remove files or apps you don't need to free up space. Not the browser's **Clear browsing data**: it deletes unsent sales too.
2. Restart WCPOS (on the web, reload the tab) and try the same thing again.
3. On the web, check the browser allows persistent storage for this site. Private windows and settings that block all site data don't.
4. Open **Store health**, then **Logs**, press **Errors** and [open the entry](../support/logs.mdx#open).
5. **If it still fails:** [send the log to support](../support/logs.mdx#for-support).

### If it came while clearing data {#while-clearing}

Part of the data can already be gone, including changes that hadn't been sent. Check your recent sales and changes appear in your store.

{/* source: current/SYNC171.mdx:19; clear-all-db.ts:43-51 (fails partway and rethrows); reset-collection.ts:225-233 (the collection was removed before the re-add failed) */}

## Is anything lost? {#your-data}

Nothing, unless it came while clearing data: see [above](#while-clearing).

{/* source: dataSafety no-impact, error-registry.json:1969; current/SYNC171.mdx:19 */}

## If it keeps happening {#keeps-happening}

If it keeps failing with space free, send the log to support.

{/* source: error-registry.json:1972, :1977 */}

## Still stuck? {#still-stuck}

[Send the log to support](../support/logs.mdx#for-support) with what you were doing.
