## What this means {#what-this-means}

Local store data is damaged and needs repair before syncing can continue.

Clear and re-download just the affected data from Store health, once nothing is waiting to be sent; contact support if the damage comes back.

## Your data {#your-data}

Data on this device may be at risk — do not clear all local data or sign out. Clearing a single collection is safe once nothing is waiting to be sent. If this persists, export diagnostics and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Open **Store health → Database**. Check that **changes waiting to send** is 0 and that no **"… changes never reached your server"** or **"… changes were held"** panel is showing — those changes exist only on this device. If the count does not go down within a few minutes, do not clear anything: go to step 4.
2. The log entry does not say which data is damaged. Only if one kind of data is clearly broken on its own — for example the product list will not load while everything else works — open the **⋮** menu on that row (here **Products**) and choose **Clear & re-download…**. Only that data is cleared and downloaded again from your store — some of it straight away, the rest as you use it. Nothing else is touched and you stay signed in.
3. Retry the action that failed. If you cannot tell which data is broken, do not guess: go to step 4.
4. If you cannot tell which data is damaged, if the same data is damaged again after a re-download, or if you could not clear it safely, do not clear everything: on the **Logs** tab, use **Copy debug info** and contact support.
