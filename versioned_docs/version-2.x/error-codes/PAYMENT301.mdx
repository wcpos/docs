## What this means {#what-this-means}

The selected payment gateway is unavailable for this store.

Ask the site administrator to verify that the gateway is supported, enabled, and correctly configured.

## Your data {#your-data}

No order or product data is affected. If this persists, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

**At the till:**

1. Complete the sale meanwhile with another method, such as cash.
2. If the method is greyed out under **… not available right now** in the payment pane, that is a problem on this till, not this error — the reason shown (for example **Needs a connection** or **Turn on Bluetooth to use the reader**) tells you what to fix.

**On the store** — for the site administrator:

3. Go to **WP Admin > POS > Settings > Checkout**. Under **Gateways**, the gateway must be listed and its **Enabled** switch on. On WCPOS Free only the built-in cash and card methods can be enabled; other WooCommerce gateways need WCPOS Pro.
4. If the gateway worked yesterday, check whether it or WooCommerce updated — **WooCommerce → Status → Logs** may record gateway start-up errors.
5. Once it is fixed, reload the app on the till so it picks up the gateway again.
