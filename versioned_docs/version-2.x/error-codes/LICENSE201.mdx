## What this means {#what-this-means}

WCPOS Pro is disabled because its version does not match WCPOS.

Update the named WCPOS or WCPOS Pro component so both versions are compatible.

## Your data {#your-data}

No order or product data is affected. If this persists, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

1. Check both plugin versions in WP Admin → Plugins — the log entry names which of WCPOS and WCPOS Pro is behind.
2. Update the older one; updating both to the latest versions resolves the skew.
3. If Pro updates are not being offered, the updater may not be authorized (see LICENSE301) — fix that first, then update.
