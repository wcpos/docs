:::info Pro Feature
Gateways other than Cash and Card, including everything on the Legacy tab, require [WCPOS Pro](../../getting-started/pro-license.mdx).
:::

The **Legacy** tab opens a gateway's own WooCommerce payment page inside the POS, so gateways that haven't been built for the tender pane keep working. It needs your store to be reachable.

A legacy gateway charges the whole order, so it can't be used once a payment has been taken. To use one, [cancel the payments taken so far](./cancelling-a-payment.mdx) first.

If a gateway's page doesn't look or work right, see [A Gateway's Payment Page Looks Wrong](./troubleshooting.mdx#checkout-settings-troubleshooting).
