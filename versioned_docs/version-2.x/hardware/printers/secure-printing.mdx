This page is for you if an Epson printer won't print from the app:

- **During printer setup:** you print the test page in [Add printer](./setup-wizard.mdx#test-page), answer **Nothing came out**, and the panel says **Nothing printed** with the line *"Secure Printing is on. Turn it off on the printer, then try again."*
- **The printer looks ready, but nothing prints:** the job seems to go, there's no error, and nothing comes out. A self-test from the printer's own buttons still prints.

Secure Printing is a setting on the printer, not in the POS. You may not need to change it: check the table first.

## Do you need to turn it off? {#do-you-need-to}

The app prints to an Epson with Secure Printing on whenever it can use the printer's encrypted connection.

| How you print | With Secure Printing on |
|---|---|
| **Desktop app**, Wi-Fi or network printer | Prints. Leave it on. |
| **Web app** in a browser | Prints once the browser trusts the printer's certificate. See [Browser permissions](./browser-permissions.mdx#the-printers-certificate). |
| **Mobile apps** | Prints when the printer's card in **Add printer** says **Wi-Fi · secure**. If it says **Wi-Fi**, turn it off. |
| **USB** or **Bluetooth** | Not affected. |

Follow your row. Turn Secure Printing off only when the app's **Nothing printed** panel tells you to, when your row says so, or for the case below.

:::note Print receipts as an image needs it off
**Print receipts as an image**, the last switch on the printer's **Edit Printer** form, sends the receipt in a form the printer holds while Secure Printing is on. It's off unless you turned it on, usually for Arabic, Hebrew or Thai receipts. If you need it on an Epson, turn Secure Printing off. See [non-Latin receipts](./non-latin-receipts.mdx#print-the-receipt-as-an-image).
:::

## Turn it off {#turn-it-off}

You need the printer's IP address and admin password. On most models both are on its network status sheet.

1. Print the status sheet: on most models, open the paper cover and hold **Feed** for a second. If nothing prints, your printer's manual names the button. Note the IP address and the **Initial Password**. The password is also on a label on the printer; on some models it's the serial number.
2. On a computer on the same network, open `https://` followed by that address in a browser. Accept the certificate warning.
3. Log in as the administrator with the admin password.
4. Go to **Print → Secure Printing**.
5. Set it to **Disable** and save.
6. Unplug the printer for ten seconds and plug it back in.
7. Print a test page from the app. In **Add printer**, press **Try again**. For a printer you saved earlier, press **Test Print** on its row in **Settings → Printing**.

:::warning Check this setting after a firmware update
A firmware update can put Secure Printing back on. If printing stops after an update, check whether it's back on. If it is, repeat these steps.
:::

## Why it happens {#why-it-happens}

While Secure Printing is on, the printer refuses jobs sent the old, unencrypted way. It doesn't reject them: it **holds** them for about four minutes, prints nothing else in that time, then throws them away. That's why the printer looks fine and acts dead. See [Printed once, then stopped](./printed-once-then-stopped.mdx).

If the status sheet says **Security Mode: RED**, Secure Printing applies to this printer.

<Accordion>
<AccordionItem question="Which printers and connections this affects">

Epson TM-series printers sold in the EU, UK and EFTA since **1 August 2025** ship with **Secure Printing** on, to meet the EU's Radio Equipment Directive. Using the printer only over Ethernet does not change that. Printers sold elsewhere normally have it off, but one bought from EU or UK stock has it on.

From Epson's own guide for these printers:

| Connection | Secure Printing **on** | **off** |
|---|---|---|
| Raw, port 9100 | Held, then discarded | Prints |
| ePOS-Print over HTTP, port 80 | Can't print | Prints |
| ePOS SDK, ports 8008 and 8009 | Can't print | Prints |
| ePOS-Print over HTTPS, port 443 | Prints | Prints |
| ePOS SDK over TLS, ports 8043 and 8143 | Prints | Prints |
| Raw over TLS, port 9143 | Prints | Prints |
| Bluetooth | Prints | Prints |

The desktop and web apps print over port 443. The mobile apps print raw on port 9100 unless the card says **Wi-Fi · secure**.

</AccordionItem>
</Accordion>

## Still stuck? {#still-stuck}

**Secure Printing is already off and nothing prints.** If the printer's web page opens but every job fails, see [Server Direct Print](./server-direct-print.mdx).

**It printed once, then stopped.** See [Printed once, then stopped](./printed-once-then-stopped.mdx).

**Anything else.** Press **Copy setup report** under **Nothing printed** and paste it into your message. Epson's [Radio Equipment Directive FAQ](https://www.epson.eu/en_EU/faq/KA-01896/contents?loc=en-us) has more on the setting.
