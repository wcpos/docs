**The symptom:** the receipt looks right on screen, but the paper shows question marks, empty boxes or the wrong letters.

This page is about receipt printers. The **Print Dialog** and office printers use your computer's fonts, so they print every language as it looks on screen.

## Choose a fix {#choose-a-fix}

**[Set the receipt language](#receipt-language)** prints as text, so it stays fast. Use it for Cyrillic, Greek, Turkish, Vietnamese, or accented Western or Central European letters, on an Epson or other ESC/POS printer.

**[Print receipts as an image](#print-as-image)** works for every language, but is slower. Use it for:

- Chinese, Japanese or Korean.
- Arabic, Hebrew or Thai. These have a receipt language, but print best as an image. Try the receipt language first only if speed matters.
- A Star printer set to **StarPRNT** or **Star Line Mode**, which has no **Receipt language**.
- Two scripts on one receipt, such as Greek and Russian.
- A receipt language that is set, when the letters are still wrong.

## Set the receipt language {#receipt-language}

**Receipt language** tells the app which of the printer's character tables to use for the whole receipt, instead of choosing one line by line. The receipt still prints as text, so it stays fast.

**For a printer you already have:** go to **Settings → Printing**, press **Edit** on the printer's row, and choose the **Receipt language**. **Edit Printer** saves each change as you make it.

**While adding a printer:** in the **Add printer** panel, press **More options**. **Receipt language** is the fourth setting, under **Printer text width**.

Choose the entry named for your receipt's language, then press **Test Print** on the printer's row. If the letters are still wrong, [print as an image](#print-as-image) instead. Chinese, Japanese and Korean have no entry.

## Print receipts as an image {#print-as-image}

This fix works for every language, on any receipt printer you added in the app. The app draws the receipt as a picture and sends the picture, so the printer's character tables no longer matter.

A printer marked **managed by WCPOS** is a cloud printer. It has no **Edit**, because it is set up in **WP Admin → POS → Settings → Cloud Print** by whoever runs your store, not in the app. How cloud printers print is on [Cloud Printing](../../receipts/cloud-printing.mdx). For every other printer:

1. Go to **Settings → Printing**.
2. Press **Edit** on the printer's row.
3. Turn on **Print receipts as an image**, the last switch in **Edit Printer**. Its note reads: *For scripts the printer cannot render (Arabic, Hebrew, Thai). Slower and larger than text.*
4. Press **Test Print** on the printer's row to check.

The switch is in **Edit Printer** only, not in **More options**: add the printer first, then turn it on.

:::tip
An image is much more to send than text, so each receipt takes longer to print. Turn it on only for the printers that need it.
:::

## Why it happens {#why-it-happens}

A receipt printer doesn't use your computer's fonts. It prints text from character tables built into the printer, one table at a time. For each line, the app picks a table that holds its letters. That works for English and most European receipts. For other scripts the printer may not have a table the app can pick, and every letter it can't print comes out as a question mark or a box. **Receipt language** fixes the table for the whole receipt; an image skips the tables altogether.

## Still stuck? {#still-stuck}

On the printer's row in **Settings → Printing**, open the **⋯** menu and press **Copy setup report**. In the Android and iOS apps this opens the share sheet instead. Paste the report into your message, with a photo of the printed receipt and the language you're printing.
