On Windows, the desktop app reaches a USB receipt printer through Windows itself. It lists the printers installed in Windows and sends each receipt to the one you pick. So the printer has to be installed in Windows before the app can find it.

This page is for you if, in the desktop app on Windows:

- **Add printer** says **No printer found**, with the printer plugged in and switched on.
- A printer you added in an earlier version says **On Windows, add this printer as an installed printer instead.**
- The printer you picked prints nothing, or a page of stray letters and symbols.

## Install the printer in Windows {#do-this}

First, check whether Windows already has it:

1. Plug the printer in and switch it on. If the maker supplies a Windows driver or installer, run it now.
2. In Windows, open **Settings → Bluetooth & devices → Printers & scanners**.
3. If your printer is in the list, go on to [Add it in the POS](#add-in-pos). If not, next to **Add a printer or scanner**, choose **Add device**. If Windows finds the printer and adds it, go on to [Add it in the POS](#add-in-pos) too.

If Windows still doesn't list it, add it by hand with **Generic / Text Only**, the plain driver that comes with Windows.

<details>
<summary>Add the printer by hand</summary>

1. Choose **Add manually**, then **Add a local printer or network printer with manual settings**.
2. Under **Use an existing port**, pick the printer's USB port: its name starts with **USB**, such as USB001.
3. For the driver, choose the manufacturer **Generic** and the printer **Generic / Text Only**.
4. Give it a name you'll recognise at the till, such as *Receipt printer*, and finish.

</details>

<details>
<summary>On Windows 10</summary>

Start from **Settings → Devices → Printers & scanners** and choose **Add a printer or scanner**. Where Windows 11 says **Add manually**, Windows 10 says **The printer that I want isn't listed**.

</details>

## Add it in the POS {#add-in-pos}

1. In the desktop app, go to **Settings → Printing** and press **Add printer**. The search starts by itself and looks for **USB, Bluetooth and Wi-Fi** printers.
2. Pick the card with the name you gave the printer in Windows. It carries the badge **Installed printer**. With several printers, the panel asks **Which printer is yours?** and picks none for you.
3. Press **Print a test page**, then answer **Did the test page print?** See [Print a test page](./setup-wizard.mdx#test-page).

## How the app prints on Windows {#why-it-happens}

The desktop app prints to the printer you installed in Windows, so pick that one. Whether your model reads receipt commands is on [Supported receipt printers](./supported-printers.mdx).

<details>
<summary>Why the printer has to be installed in Windows</summary>

Windows puts its own driver, or the maker's, on a USB printer, and the desktop app prints through the printer's entry in Windows rather than to the cable. It sends each receipt as printer commands, and Windows passes them to the printer unchanged, so the driver doesn't reshape the receipt.

</details>

<details>
<summary>Which Windows printers the search lists</summary>

Every printer installed in Windows, except Windows' own entries such as **Microsoft Print to PDF** and **Fax**. An office printer installed in Windows is listed too, and looks like any other, so pick by name. A Bluetooth printer paired in Windows shows up the same way, as an installed printer.

</details>

## If something goes wrong {#goes-wrong}

**No printer found.** First check **Printers & scanners** in Windows. If your printer isn't listed, [install it in Windows](#do-this), then press **Scan again**. If it is listed and the app still finds nothing, see [Still stuck?](#still-stuck).

**On Windows, add this printer as an installed printer instead.** The printer was saved by an earlier version as a direct USB printer, which Windows doesn't allow. In **Settings → Printing**, open the printer's **More actions** menu, choose **Delete**, then add it again with **Add printer**.

**The test page is stray letters and symbols.** Check the name on the card you picked. If it's another printer, such as an office printer, it can't read receipt commands: press **Add printer** again and pick your receipt printer's entry. If it is your receipt printer, its **Printer Language** setting may not match the printer. In **Settings → Printing**, press **Edit** on its row and pick the language for your printer: **ESC/POS** for Epson and most other makes, **StarPRNT** or **Star Line Mode** for Star. After each change, press **Test Print** on the row; on a Star printer, if one language still prints symbols, try the other. Symbols with every language? Check your model on [Supported receipt printers](./supported-printers.mdx), then see [Still stuck?](#still-stuck).

**Nothing came out.** Answer **Nothing came out**. Then check the name on the card you picked: if it's another printer, press **Start over** and pick your receipt printer's entry. If it is yours, the panel says **Check the cable and that the printer is switched on, then try again.** If it still prints nothing, print a test page from Windows itself: in **Printers & scanners**, open your printer's **Printer properties** and press **Print Test Page**. If Windows can't print to it either, the fault is between Windows and the printer: the cable, the port or the driver.

**In the web app, Find a USB printer can't open the printer.** On Windows the printer's driver holds it, so Chrome or Edge often can't reach it. Use the desktop app.

## Still stuck? {#still-stuck}

Press **Copy setup report** on the **Nothing printed** panel, or in the printer's **More actions** menu in **Settings → Printing**. Paste it into your message: it names the Windows entry the app printed to.
