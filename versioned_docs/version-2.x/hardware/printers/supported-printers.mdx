Find your printer, your app and your connection below. **Verified** means we have printed on that model over the connections listed; other models are under **Expected to work**. The **Vendor** setting tells the app which make it is talking to.

## Verified {#verified}

Printed on real hardware here, on the connections listed.

| Printer and paper | Printed from |
|---|---|
| **Epson TM-m30III**<br />80 mm | Wi-Fi from the web, desktop and mobile apps. Bluetooth from the Android app. |
| **Netum NT-1809**<br />58 mm | USB and Bluetooth from the desktop app. |

A new Epson that the app finds but that prints nothing usually has Secure Printing switched on. See [Epson Secure Printing](./secure-printing.mdx).

## Expected to work {#expected-to-work}

Not tested by us model by model, but they use the same connections as the verified printers. If yours doesn't print, follow the [Setup Wizard](./setup-wizard.mdx), then [report it](#report-yours).

iPhone and iPad have no USB, so on those every printer below connects over Wi-Fi or Bluetooth.

- **Epson TM-series** printers with ePOS: Wi-Fi from every app, USB from the desktop app, Chrome, Edge and the Android app, Bluetooth from the desktop and mobile apps.
- **Star mC-Print and TSP** printers: Wi-Fi from every app, USB from the desktop app, Chrome, Edge and the Android app, Bluetooth from the desktop and mobile apps.
- **ESC/POS printers from other makers**: Wi-Fi from the desktop and mobile apps, USB from the desktop app, Chrome and Edge.
- **Bluetooth Low Energy printers**, the small 58 mm kind: from Chrome, Edge, the desktop app and the mobile apps.
- **Bluetooth Classic printers from other makers**: from the Android app, once [paired in Settings](./bluetooth-pairing.mdx#android-pair-first).

## Not supported yet {#not-supported-yet}

- **Wi-Fi printers other than Epson and Star in the web app.** A browser can only reach the web server built into Epson and Star printers. Use the desktop or mobile app, a USB or Bluetooth connection, or a [cloud printer](../../receipts/cloud-printing.mdx).
- **USB printers from other makers in the mobile apps.** On Android, the app reaches USB printers from Epson and Star only, through the makers' own software. Use Wi-Fi or Bluetooth, or a desktop till.
- **Bluetooth Classic printers from other makers on iPhone and iPad.** Use Bluetooth Low Energy or Wi-Fi, or an Android or desktop till.
- **The built-in printer in Sunmi and iMin all-in-one terminals.** The app has no support for them. An external printer works on those devices.

## Tell the app which make it is {#vendor}

The **Vendor** setting says whose printer this is. The app fills it in when it finds the printer or when an address answers. In **Edit Printer** it shows **Detected: Epson**, **Detected: Star** or **Detected: Generic** under the IP address. You change it yourself only when the app guessed wrong or could not reach the printer.

You'll find it in two places: in **Settings → Printing → Add printer** under **More options**, and in **Edit Printer** for a printer you have already added.

1. **More options** — opens the card below when the scan found nothing or found the wrong printer.
2. **Printer Name** — the name in your printer list and on the receipt screen.
3. **Epson** — the default in the web app.
4. **Star Micronics** — switches the card to Star's settings: **Receipt language** goes, because it only applies to ESC/POS.
5. **Auto-open cash drawer** — the command that opens the drawer depends on the vendor and the printer language. See [Connecting a cash drawer](./cash-drawer.mdx).
6. **Find a USB printer** — Chrome and Edge. The app reads the make from the printer when it can.
7. **Find a Bluetooth printer** — opens the browser's or computer's own Bluetooth chooser.
8. **Enter an IP address** — check one address. Its **Port** follows the vendor you chose.

In the web app you choose between **Epson** and **Star Micronics**, and only for a Wi-Fi printer. In the desktop app the list also has **Generic**. The mobile apps offer **Generic** for Wi-Fi printers and for Bluetooth printers the app found itself, but not for printers it reaches through Epson's or Star's software.

Changing **Vendor** also resets **Printer Language** and, in the web app, the **Port**. The app then stops checking the printer's make at that address.

### What changing it does {#what-vendor-changes}

<details>
<summary>Printer Language, Port and how each vendor prints</summary>

Receipt printers speak ESC/POS, which most makers use, or one of Star's own languages, StarPRNT or Star Line Mode.

- **Printer Language** goes back to that vendor's default: **ESC/POS** for Epson and Generic, **Star Line Mode** for Star. A saved printer keeps the language you set until you change the vendor.
- **Port** changes in the web app to the port that make listens on. After **Star Micronics** the address form reads **443** on a secure store:

<div className="pinned-legend">

1. **IP Address** — it is printed on the printer's status sheet.
2. **Port** — 443 for Star on a secure store (80 otherwise). Epson uses 8043 (8008 otherwise).
3. **Check this address** — the app asks the address which make answers and prints a test page.

- **How the app sends the receipt** changes too. Choosing a vendor by hand also stops the app re-detecting it at that address.

**How each vendor prints, app by app**

| | Epson | Star Micronics | Generic |
|---|---|---|---|
| **Web app, Wi-Fi** | Epson ePOS, port 8043 (8008 on a store without HTTPS) | Star WebPRNT, port 443 (80 without HTTPS) | Not offered |
| **Desktop app, Wi-Fi** | Epson ePOS | Plain network printing, port 9100 | Plain network printing, port 9100 |
| **Mobile apps, Wi-Fi** | Plain network printing, port 9100 | Plain network printing, port 9100 | Plain network printing, port 9100 |
| **Mobile apps, USB and Bluetooth** | Epson's own software | Star's own software | Bluetooth Low Energy, or Bluetooth Classic once paired on Android |
| **Opening a cash drawer, ESC/POS** | Epson's own drawer command | The standard ESC/POS drawer command | The standard ESC/POS drawer command |

In the web app, a USB or Bluetooth printer is sent plain ESC/POS whatever the vendor says.

</details>

## If something goes wrong {#goes-wrong}

**"Cash drawer kicks depend on printer language/emulation."** The vendor and the **Printer Language** don't match: a Star printer set to ESC/POS, or another make set to a Star language. That is fine if the printer really is in that emulation mode. If the drawer doesn't open, set **Printer Language** to the mode the printer is in.

**The drawer doesn't open on a printer that isn't an Epson.** With **Vendor** set to Epson, the app sends Epson's own drawer command, which many other printers ignore. In the desktop or mobile app, set **Vendor** to **Generic**.

**The app says Detected: Generic, but it's an Epson or a Star.** The printer answered only on its plain network port. Choose the right **Vendor** by hand.

**Your make isn't in the web app's list.** The browser can only print over Wi-Fi to Epson and Star. Connect the printer by USB or Bluetooth in Chrome or Edge, or use the desktop app.

## Report yours {#report-yours}

Whether it worked or not, tell us the model. Tap **Copy setup report**: it is on the **Nothing printed** screen of **Add printer**, on the screen that says the printer is set up, and in each printer's **More actions** menu in **Settings → Printing**. It records the printer, its vendor, how it answered and the app's recent printer log. Paste it into your message.
