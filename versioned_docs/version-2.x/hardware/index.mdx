## Card reader compatibility {#card-reader-compatibility}

Which card readers a till can use depends on **how you run WCPOS** and on the reader's connection type:

- **Smart readers** sit on your shop's network, and your store drives them. They work on every till: the browser, the desktop app, iPhone, iPad and Android. Examples: Stripe Reader S700, BBPOS WisePOS E.
- **Bluetooth readers** pair with one phone or tablet, and **Tap to Pay** turns the phone itself into the reader. Both need the **iOS or Android app**. A browser or the desktop app can't reach them. Examples: Stripe Reader M2, BBPOS WisePad 3, SumUp Solo Lite.
- **Each gateway supports its own readers.** Check the reader against the gateway you plan to use ([Stripe Terminal](../payment/gateways/stripe-terminal.mdx#readers), [SumUp](../payment/gateways/sumup-terminal.mdx#hardware-compatibility), [all card terminals](../payment/gateways/index.mdx#hardware-terminal-gateways)) before buying.

The store decides which kinds of reader its tills may use, on the gateway's page. Each till then picks its own reader in **Settings → Card readers**. If none is set up for this till, that page reads **No card readers are set up for this store**; see [Card Readers](./card-readers/index.mdx#open).

Card readers need [WCPOS Pro](../getting-started/pro-license.mdx).
