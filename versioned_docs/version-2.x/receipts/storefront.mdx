To print or email a receipt at the till, for any order including online ones, see [Receipt Reprinting](../orders/index.mdx#receipt-reprinting). This page is for setting up receipt downloads for customers on your website.

Your WCPOS receipt templates also work on your website. A customer who bought online can download their receipt as a PDF from **My Account**, or from a link you put on the order confirmation page.

## Turn on the Receipt button {#my-account}

:::warning Activate a receipt template first
Turn one on in **POS → Templates** before you start. Without one, customers won't see the **Receipt** button, even with the setting on. See [Customise Your Receipt](./customise.mdx#option-1--pick-a-different-template).
:::

The button is off until you turn it on. The PDF is made from your receipt template.

1. In WP Admin, go to **POS → Settings → General**.
2. In the **Customers** section, switch on **Let customers download receipts**.
3. **Receipt template for customers** appears under it. Leave it on **Use active receipt template**, or pick one. See [Choose the customer's template](#template-choice).

A logged-in customer now sees a **Receipt** button beside their orders in **My Account → Orders**. It downloads a PDF named after the order, such as `receipt-1234.pdf`.

The button shows only for orders that have been paid for:

| Order status | Receipt button |
|---|---|
| **Processing** | Yes |
| **Completed** | Yes |
| **Refunded** | Yes |
| Any other status, such as **Pending payment**, **On hold**, **Cancelled** or **Failed** | No |

A developer can [change which statuses show the button](#developers).

## Choose the customer's template {#template-choice}

**Receipt template for customers** sets which template the download uses.

- **Use active receipt template** (the default): customers get your active receipt template from **POS → Templates**. Change it there and their downloads follow.
- **A named template**: customers always get that one, whatever the cashier picks at the till. Use this when several receipt templates are active, or to give online orders their own look.

A narrow thermal-style template makes a narrow PDF. For online orders a full page usually reads better: the gallery's **Invoice** template is made for A4 and Letter paper. See [Customise Your Receipt](./customise.mdx#option-1--pick-a-different-template) to add it.

The PDF is filled from the same [receipt data](./receipt-data.mdx) as the till receipt, so your logo, store details and tax settings carry over.

If a template you picked is later deleted or unpublished, the dropdown shows **Unavailable template** and customers get your active receipt template instead. Pick another one.

## Add a receipt link to the order confirmation page {#shortcode}

Give customers a **Download receipt (PDF)** link on the "thank you" page they see after checkout. Guests who checked out without an account get their receipt this way.

If your WP Admin has **Appearance → Editor → Templates → Order Confirmation**, put the link on the thank-you page yourself:

1. In WP Admin, go to **Appearance → Editor → Templates** and open **Order Confirmation**.
2. Add a **Shortcode** block where you want the link, and type `[wcpos_receipt]` in it.
3. Press **Save**.

If you don't have that template, or you want the link on an order's page in **My Account**, ask a developer to [add the receipt link from code](#developers).

The shortcode works whether or not **Let customers download receipts** is on: that setting only controls the button in **My Account → Orders**.

<details>
<summary>Shortcode options and examples</summary>

`[wcpos_receipt]` works on the order confirmation page and on an order's page in **My Account**. It finds the order by itself, so you never type an order number. On any other page it shows nothing.

| Option | Default | What it does |
|---|---|---|
| `order_id` | *(found on the page)* | Link to one order. Shows only to a logged-in customer viewing their own order. |
| `link_text` | `Download receipt (PDF)` | The words of the link. |
| `format` | `pdf` | `pdf` downloads a PDF. `html` opens the receipt in the browser, ready to print. |
| `template` | *(your active receipt template)* | Use this template instead. |
| `class` | `wcpos-receipt-link` | CSS class on the link. |
| `id` | *(none)* | HTML `id` on the link. |

The shortcode's `template` option ignores **Receipt template for customers**: leave it out and the link uses your active receipt template.

A download link with your own words:

```text
[wcpos_receipt link_text="Download your invoice"]
```

Open the receipt in the browser instead of downloading a PDF:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

Use a particular template, for example an A4 invoice instead of your 80mm till receipt:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

The template number is in the address bar when you edit the template in **POS → Templates** (`post=123`). A template that isn't published is ignored, and the link uses your active receipt template.

</details>

## Who can open a receipt {#security}

- **Customers with an account** sign in and use the **Receipt** button in **My Account → Orders**.
- **Guests** who checked out without an account use the receipt link on their order confirmation page, once you [put one there](#shortcode).

:::warning Share receipt links only with the customer
Anyone who has a receipt link can open that receipt without signing in. Treat it like the order itself.
:::

<details>
<summary>How receipt links are protected</summary>

Every receipt link carries the order's private key, the same one WooCommerce puts on its order confirmation page. Without the right key, the receipt doesn't open. A shortcode with an `order_id` option shows its link only to the signed-in customer who owns that order.

</details>

## If something goes wrong {#goes-wrong}

**The customer sees no Receipt button.** Check that **Let customers download receipts** is on, that the order is **Processing**, **Completed** or **Refunded**, and that at least one receipt template is active in **POS → Templates**. The button is only in **My Account → Orders**, for a logged-in customer.

**"No receipt template is configured."** The PDF has no template to use. Turn on a receipt template in **POS → Templates**.

**"You do not have permission to view this receipt."** The link is missing its key or the key doesn't match the order. Send the customer the link from their confirmation page or **My Account** again.

**"Could not generate the receipt PDF."** The template failed to render. Open it in **POS → Templates** and preview it. See [Customise Your Receipt](./customise.mdx).

**The link opens a "Page not found" error.** Receipt links need pretty permalinks. In WP Admin, go to **Settings → Permalinks** and choose any structure except **Plain**.

## For developers {#developers}

<details>
<summary>Add the receipt link from code</summary>

On a classic theme, print the link from the two WooCommerce actions that draw those pages:

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

The shortcode finds the order on both pages, so it needs no `order_id`.

</details>

<details>
<summary>Filters for the Receipt button and the PDF template</summary>

Three filters sit on top of the settings above, for rules the settings can't express, such as per order or per customer:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

Before WCPOS 2.0 these filters were named `woocommerce_pos_storefront_receipt_*`. Those names still work but are deprecated since 2.0 and are removed in 2.2 at the earliest. See [Hook naming](../extensions/index.mdx#hook-naming).

The PDF address is `/wcpos-checkout/wcpos-receipt/{order_id}` with `?key={order_key}&format=pdf`: the same key-gated receipt address the POS uses, with `format=pdf` returning a PDF instead of the page.

</details>
