Store Settings are app-wide configurations that affect how the POS operates. These settings apply to the entire store, not individual screens.

## Accessing Store Settings {#accessing-store-settings}

Open the Store Settings by:

- Clicking the **user menu** (top-right corner) and selecting **Settings**
- Using the keyboard shortcut `Ctrl + Shift + S`

Settings open as a **side panel** rather than a pop-up window, so you can keep the sale in view while you adjust them. [Store health](/support/store-health) opens the same way.

## Settings Tabs {#settings-tabs}

The Store Settings panel contains these tabs:

| Tab | Description |
|-----|-------------|
| [General](./general.mdx) | Store info, language, currency, default customer |
| [Tax](./tax.mdx) | Tax calculation and display options |
| [Barcode](./barcode.mdx) | Barcode scanner configuration |
| [Keyboard Shortcuts](./hotkeys.mdx) | Available keyboard shortcuts |
| [Theme](./theme.mdx) | Appearance and colour scheme |
| [Printer](/hardware/printers) | Receipt printer connection and configuration |
