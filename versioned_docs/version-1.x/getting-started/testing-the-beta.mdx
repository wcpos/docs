WCPOS 2.0 is in public beta, for the browser POS and the desktop app. The Android and iOS apps come out once beta testing is finished, so keep phones and tablets on a 1.11 store until then. The beta is for testing on a staging copy of your store or a store you can afford to interrupt; it is not the release, and WordPress.org still offers 1.11. This page is the whole of what a tester needs.

## What you need {#what-you-need}

- **WooCommerce 9.0 or later.** 2.0 stops at a notice on anything older.
- **The app and the plugin must both be on 2.0.** A 2.0 app will not work with a 1.11 plugin, and a 1.11 app asks for an update when it meets a 2.0 plugin. Update the plugin first, then every till.
- **No magnetic-stripe card reader.** 2.0 removes the experimental reader. Card readers at the till go through Stripe Terminal or SumUp with WCPOS Pro.
- **Terminal extensions need WCPOS Pro 2.0.** Stripe Terminal, SumUp and the other card-terminal extensions have their own `2.0.0-beta1` prereleases on GitHub; install them by hand after Pro.

## Before you install {#before-you-install}

1. **Sync every till before you upgrade.** 2.0 starts a new local database on each till and does not carry over sales a 1.11 till has not sent to the store yet. Open each till on 1.11, let it finish syncing, and only then update the plugin. A sale still sitting unsent on a 1.11 till is gone after the upgrade.
2. **Back up the site** or ask your host for a restore point.
3. **Pick a quiet hour.** Every till reloads into the new register on first open, and a sale half-way through checkout on 1.11 has to be rung up again.
4. Read the [app release notes](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.1) for what changes: the register, the checkout and the cash drawer are new, every screen is redrawn, and negative-fee discounts are replaced by Add Discount.

## Get the beta {#get-the-beta}

**Plugin (free):** download `woocommerce-pos.zip` from the [WCPOS 2.0.0 beta 1 release](https://github.com/wcpos/woocommerce-pos/releases/tag/v2.0.0-beta.1) and install it through **WP Admin → Plugins → Add New → Upload Plugin**, replacing the current version. Browser tills pick up 2.0 as soon as the plugin is active.

**Plugin (Pro):** sign in at [wcpos.com/account/downloads](https://wcpos.com/account/downloads), download `woocommerce-pos-pro.zip` from the **WCPOS Pro 2.0 beta** card (an active licence is required) and upload it the same way. Pro contains the free plugin; you do not install both.

**Desktop app:** the [WCPOS Desktop 2.0.0 beta 1 release](https://github.com/wcpos/electron/releases/tag/v2.0.0-beta.1) carries the macOS, Windows and Linux installers. The beta build does not update itself; later betas are new downloads from the same releases page.

**iPhone, iPad and Android:** not in this beta. The 2.0 apps for the stores come out once beta testing is finished; a 1.11 app stops at an update notice when it meets a 2.0 store, so keep phones and tablets on a 1.11 store until then.

The app release notes for the beta are on the [app release](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.1); the plugin changes are in each plugin release's notes.

## Rolling back to 1.11 {#rolling-back}

Tell us on [Discord](https://wcpos.com/discord) first; most beta-day problems have a quicker fix than a rollback.

1. **Sync every till before you roll back.** Anything a 2.0 till has not sent stays in the 2.0 local database, which the 1.11 app never opens.
2. Reinstall the 1.11 plugin: free from [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) or [Previous versions](/getting-started/previous-versions), Pro from [wcpos.com/account/downloads](https://wcpos.com/account/downloads) (the latest 1.11 version in the list).
3. Reinstall the 1.11 desktop app where you installed the beta. A 2.0 app cannot connect to a 1.11 plugin.
4. The 1.11 till starts from an empty local database and re-syncs from the store. Orders made on 2.0 are ordinary WooCommerce orders and stay where they are; register sessions and closures recorded on 2.0 stay in the database but 1.11 does not show them.

## Reporting what you find {#reporting}

Open an issue on [wcpos/roadmap](https://github.com/wcpos/roadmap/issues/new) with the `beta` label, or write to [support](https://wcpos.com/support). Say which part (plugin, desktop, iOS, Android, browser), the version, what you did, what you expected and what happened; a screenshot or the error code from the screen helps. For a problem with a sale or a payment, include the order number.
