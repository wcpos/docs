## What this means {#what-this-means}

Your store is limiting requests temporarily, so this action will retry later.

Wait before retrying. If rate limits continue, ask the site administrator or host to review the store's request limits.

## Your data {#your-data}

The change is saved on this device but has not reached your store. If this persists, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

1. Wait — the POS backs off and retries by itself; retrying by hand only extends the throttle.
2. Nothing needs to be re-entered: the affected changes stay on the device and go through on a later attempt.
3. If the code keeps appearing, ask the site administrator to find which layer returns the 429 — a security plugin, a CDN or firewall rule, or the host's own limits — and to allow the POS's REST traffic.
4. The expanded log entry's endpoint and timestamps help the administrator match the throttle in their own dashboards.
