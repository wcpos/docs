## What this means {#what-this-means}

WooCommerce is not active on this site, so WCPOS cannot connect.

WCPOS requires the WooCommerce plugin. Ask the site administrator to install or reactivate WooCommerce, then connect again.

## Your data {#your-data}

No order or product data is affected. If this persists, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

1. Ask the site administrator to check WP Admin → Plugins: WooCommerce must be installed and active for WCPOS to connect.
2. If WooCommerce was deactivated by a failed update, reactivate it and watch for an error banner — WooCommerce → Status → Logs records why it failed.
3. Once WooCommerce is active again, reconnect from the till.
