# DB03002: Invalid Data Type

## What This Means {#what-this-means}

The data type doesn't match what the database expects. For example, text was provided where a number was expected.

## Common Causes {#common-causes}

- **User input error** — Entering text in a numeric field
- **Import issues** — Imported data has wrong format
- **Data corruption** — Values corrupted during transfer
- **Plugin conflict** — Another plugin modified data types

## How to Fix {#how-to-fix}

### 1. Check Your Input {#1-check-your-input}

Review the data you're entering:
- **Prices** — Should be numbers (e.g., `19.99`)
- **Quantities** — Should be whole numbers (e.g., `5`)
- **IDs** — Should be numeric

### 2. Clear and Re-enter {#2-clear-and-re-enter}

If data was corrupted:
- Clear the field
- Enter the value again manually
- Avoid copy-pasting from external sources

### 3. Check Source Data {#3-check-source-data}

If syncing from WooCommerce:
- Check the data in WordPress Admin
- Look for incorrectly formatted fields
- Fix data at the source

### 4. Re-sync Data {#4-re-sync-data}

:::warning Check for unsaved work first
Clearing local data or reinstalling the app deletes anything on this device that hasn't been saved to your store — open carts, and edits that didn't save. Completed sales are already in **WooCommerce → Orders**. Before you clear anything, finish or note every open cart, and check that your recent changes appear in WP Admin. If something is missing, or you can't open WP Admin, don't clear — ask your store owner or contact support.
:::

Only if the other steps on this page didn't help, and only after the check above, get fresh data from the server:
- Clear local cache
- Sync data again
- Check if the issue resolves

### 5. Check for Plugin Conflicts {#5-check-for-plugin-conflicts}

If using other WooCommerce plugins:
- They may modify data in unexpected ways
- Temporarily disable to test
- Report incompatibilities

## Common Examples {#common-examples}

| Field | Expected | Invalid |
|-------|----------|---------|
| Price | `19.99` | `$19.99` |
| Quantity | `5` | `five` |
| SKU | `ABC123` | — (any format OK) |
| Product ID | `42` | `product-42` |
