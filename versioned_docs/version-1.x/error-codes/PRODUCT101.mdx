## What this means {#what-this-means}

This product change hasn't reached your store yet.

Read the reason shown, fix what it names or check your connection, then save the product again.

## Your data {#your-data}

Changes not yet sent are kept on this device — don't clear its data. After a connection failure, your edit stays on this device until it can be sent. If the store refused the edit, this device goes back to the store's version instead (see [SYNC202](/error-codes/SYNC202)), so make the edit again once the reason is fixed. If this keeps happening, use **Copy debug info** on the **Logs** tab and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Read the reason shown — the log entry's error text usually shows whether this was a connection failure, a value the store refused, or a conflicting edit made in the store.

**At the till:**

- Connection failure: check the connection, then save the product again; the edit is kept on this device meanwhile.
- Refused value: correct what the reason names, then save the product again.

**On the store (WP Admin):** for a conflicting edit, open the product, compare it with what the till shows, and save the correct values once.

If saves keep failing with no clear reason, use **Copy debug info** on the **Logs** tab and contact support.
