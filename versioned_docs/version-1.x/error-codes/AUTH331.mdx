## What this means {#what-this-means}

This store's WCPOS plugin is too old for this version of the app.

The app has been updated but the WCPOS plugin on the store has not, and the two versions no longer work together. Ask whoever manages the site to update the WCPOS plugin in WP Admin, then connect again. Nothing needs to change on the till.

## Your data {#your-data}

No order or product data is affected. If this persists, ask the person who manages your WordPress site.

## Troubleshoot {#troubleshoot}

**On the store** — for whoever manages the WordPress site:

1. WP Admin → Plugins → update WCPOS to the latest version. If WCPOS Pro is installed, update it to a matching version at the same time.
2. If no update is offered, check WP Admin → Dashboard → Updates; for Pro, an unauthorized updater blocks updates (see [LICENSE301](./LICENSE301)) — fix that first.

**At the till** — for the cashier: once the store has been updated, reconnect. You do not need to type the store address again.

**If the store can't be updated yet:** contact support instead — the till needs an app version that matches the plugin, and support can tell you which one. They'll ask for the app version (from the till) and the store's current WCPOS version (from WP Admin).
