# SY02001: Invalid Configuration

## What This Means {#what-this-means}

The system configuration is invalid or corrupted. The POS application found configuration settings that don't make sense or are incomplete.

## Common Causes {#common-causes}

- **Corrupted settings** — Configuration file became corrupted
- **Incomplete setup** — Setup process wasn't completed
- **Manual editing error** — Config files were incorrectly modified
- **Version upgrade issue** — Old config incompatible with new version

## How to Fix {#how-to-fix}

### 1. Reset to Default Settings {#1-reset-to-default-settings}

If available in the app:
- Look for "Reset Settings" or "Restore Defaults"
- This clears custom settings but fixes corruption. If the reset offers to remove your store or its data, stop and do the check in step 3's warning first

### 2. Complete the Setup {#2-complete-the-setup}

If setup wasn't finished:
1. Start the setup process again
2. Complete all required steps
3. Verify configuration before finishing

### 3. Clear Application Data {#3-clear-application-data}

:::warning Check for unsaved work first
Clearing local data or reinstalling the app deletes anything on this device that hasn't reached your store — including sales taken while offline, open carts, and edits that didn't save. Before you clear anything, open **Store health → Database** and check nothing is listed as held or as never having reached your server, then **Store health → Logs** for **0 stuck records** and **0 changes waiting to send**; then finish or note every open cart. If your WCPOS has no Store health page, update WCPOS first, then check. If anything is listed or waiting, or you can't check, don't clear — ask your store owner or contact support.
:::

Only if the other steps on this page didn't help, and only after the check above, remove corrupted config:
- **Desktop:** Delete app data folder, restart app
- **Browser:** Clear site data, reload

### 4. Reinstall the Application {#4-reinstall-the-application}

:::warning Check for unsaved work first
Clearing local data or reinstalling the app deletes anything on this device that hasn't reached your store — including sales taken while offline, open carts, and edits that didn't save. Before you clear anything, open **Store health → Database** and check nothing is listed as held or as never having reached your server, then **Store health → Logs** for **0 stuck records** and **0 changes waiting to send**; then finish or note every open cart. If your WCPOS has no Store health page, update WCPOS first, then check. If anything is listed or waiting, or you can't check, don't clear — ask your store owner or contact support.
:::

Only for persistent issues, and only after the check above:
1. Uninstall completely
2. Remove any leftover data folders
3. Reinstall fresh
4. Complete setup from scratch

### 5. Check for Updates {#5-check-for-updates}

Configuration formats may change:
- Update the POS application
- Update the WCPOS plugin
- Reconfigure after update

## What Gets Reset {#what-gets-reset}

When resetting configuration:
- You'll need to log in again
- Custom settings will be lost
- Data will need to re-sync
- Your WooCommerce data is safe on the server, but anything on this device that never reached your store — such as an open cart — is lost
