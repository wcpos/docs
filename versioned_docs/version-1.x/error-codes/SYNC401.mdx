## What this means {#what-this-means}

A background sync task stopped unexpectedly before finishing.

Nothing to do — the POS restarts these tasks automatically, and nothing is lost. If this code keeps appearing, use **Copy debug info** on the **Logs** tab and contact support.

## Your data {#your-data}

Nothing is lost — no order or product data is affected. If this persists, use **Copy debug info** on the **Logs** tab and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Nothing to do on first sight: the POS restarts the crashed background task automatically and no order data is involved.
2. If the code repeats within minutes, reload the app once so the sync engine starts clean.
3. If it still repeats, use **Copy debug info** on the **Logs** tab and contact support — a recurring task crash is an app defect worth reporting, not a store problem.
