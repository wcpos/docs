## What this means {#what-this-means}

Printing hit an unexpected problem. No sale is affected.

Repeat the print or receipt action named in this entry. Contact support if it repeats.

## Your data {#your-data}

No sale is affected.

## Troubleshoot {#troubleshoot}

1. Expand the log entry first and identify the failed operation — this code also covers receipt-email queue actions and receipt-template sync, not only physical printing.
2. Repeat only the operation named in the log. Reprint from the order screen only for a physical print attempt; send a queued email again from Store health, and retry template sync by reopening the receipt screen while connected.
3. If that action keeps failing, use **Copy debug info** on the **Logs** tab and contact support.
