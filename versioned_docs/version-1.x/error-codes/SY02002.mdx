# SY02002: Service Unavailable

## What This Means {#what-this-means}

A required service or component is not available. The POS depends on various services to function, and one of them is currently inaccessible.

## Common Causes {#common-causes}

- **Background service stopped** — A required service isn't running
- **System resource issue** — Not enough resources to start the service
- **Dependency failure** — A service this depends on failed
- **Startup issue** — Service failed to start properly
- **Server error** — The WooCommerce server returned a 5xx error

## Server Error Mapping {#server-error-mapping}

This error code is triggered when the server returns:

| Server Code | Source |
|-------------|--------|
| HTTP 5xx | Any server error response (500, 502, 503, 504, etc.) |

## How to Fix {#how-to-fix}

### 1. Restart the Application {#1-restart-the-application}

Close and reopen the POS:
1. Fully close the application
2. Wait a few seconds
3. Start it again

### 2. Restart Your Device {#2-restart-your-device}

A full restart often resolves service issues:
1. Save any important work
2. Restart your computer
3. Try the POS again

### 3. Check System Resources {#3-check-system-resources}

Ensure system resources are available:
- Close unnecessary applications
- Check memory usage
- Check disk space

### 4. Update the Application {#4-update-the-application}

Ensure you're on the latest version:
- Check for available updates
- Install any pending updates
- Restart after updating

### 5. Reinstall if Necessary {#5-reinstall-if-necessary}

:::warning Check for unsaved work first
Clearing local data or reinstalling the app deletes anything on this device that hasn't reached your store — including sales taken while offline, open carts, and edits that didn't save. Before you clear anything, open **Store health → Logs** and check the header shows **0 stuck records** and **0 changes waiting to send**, then finish or note every open cart. If anything is waiting, or you can't open Store health, don't clear — ask your store owner or contact support.
:::

Only if your store's site opens normally in a browser, the steps above didn't help, and only after the check above:
1. Uninstall the application
2. Restart your device
3. Download the latest version
4. Install fresh

## Browser-Specific (Web Version) {#browser-specific-web-version}

For the web version:
- Ensure JavaScript is enabled
- Check that required browser features aren't blocked
- Try a different browser
- Disable browser extensions that might interfere

## When to Contact Support {#when-to-contact-support}

If this error persists:
- Note when it occurs
- Check if specific actions trigger it
- Report with details for investigation
