# SY01002: Disk Full

## What This Means {#what-this-means}

Your device's storage is full. The POS cannot save data or continue operating without available disk space.

## Common Causes {#common-causes}

- **Storage full** — No free space on the drive
- **Large local database** — POS data using significant space
- **Temp files** — Temporary files consuming space
- **Other applications** — Other apps filling the disk

## How to Fix {#how-to-fix}

### 1. Free Up Disk Space {#1-free-up-disk-space}

Delete unnecessary files:
- Empty the trash/recycle bin
- Remove old downloads
- Delete unused applications
- Clear temporary files

### 2. Check Available Space {#2-check-available-space}

**Windows:**
- Open File Explorer
- Right-click the drive → Properties
- View used and free space

**macOS:**
- Apple menu → About This Mac
- Click Storage

### 3. Clear Browser Data (Web Version) {#3-clear-browser-data-web-version}

:::warning Check for unsaved work first
Clearing local data or reinstalling the app deletes anything on this device that hasn't reached your store — including sales taken while offline, open carts, and edits that didn't save. Before you clear anything, open **Store health → Logs** and check the header shows **0 stuck records** and **0 changes waiting to send**, then finish or note every open cart. If anything is waiting, or you can't open Store health, don't clear — ask your store owner or contact support.
:::

Browsers store the POS data locally. Only after the check above:
- Clear cache and cookies
- Remove old site data
- Check browser storage usage

### 4. Move or Delete Large Files {#4-move-or-delete-large-files}

Find and handle large files:
- Old videos or photos
- Large downloads
- Unused software
- Backup files that can be moved to external storage

### 5. Check POS Data {#5-check-pos-data}

If POS data is very large:
- The local database may need cleaning
- Consider clearing and re-syncing — only after the check in step 3
- Check if old data can be purged

## Recommended Free Space {#recommended-free-space}

Keep at least:
- **10GB** free for normal operation
- **20GB+** for large catalogs
- More space is always better

## Preventing Future Issues {#preventing-future-issues}

- Regularly clean up unnecessary files
- Set up automatic temp file cleanup
- Monitor disk space usage
- Consider larger storage if frequently full
