# DB01003: Transaction Failed

## What This Means {#what-this-means}

A database transaction could not be completed. Transactions group multiple operations together — if any part fails, everything is rolled back to maintain data integrity.

## Common Causes {#common-causes}

- **Concurrent access** — Multiple operations trying to modify the same data
- **Storage full** — No space to write new data
- **Database locked** — Another process is locking the database
- **Power interruption** — Operation interrupted unexpectedly

## How to Fix {#how-to-fix}

### 1. Retry the Operation {#1-retry-the-operation}

The issue may be temporary:
- Wait a moment
- Try the operation again
- Avoid rapid repeated attempts

### 2. Check for Conflicts {#2-check-for-conflicts}

If multiple devices or tabs are open:
- Use one instance at a time
- Close duplicate browser tabs
- Coordinate multi-device usage

### 3. Check Storage Space {#3-check-storage-space}

Ensure there's space for data:
- Check available disk space
- Free up space if needed
- Clear the browser cache on the web version (untick “Cookies and other site data” — that holds the POS's saved data, including anything not yet sent)

### 4. Restart the Application {#4-restart-the-application}

Reset the database state:
1. Close the POS completely
2. Wait a few seconds
3. Reopen the application

### 5. Clear and Re-sync {#5-clear-and-re-sync}

:::warning Check for unsaved work first
Clearing local data or reinstalling the app deletes anything on this device that hasn't reached your store — including sales taken while offline, open carts, and edits that didn't save. Before you clear anything, open **Store health → Database** and check nothing is listed as held or as never having reached your server, then **Store health → Logs** for **0 stuck records** and **0 changes waiting to send**; then finish or note every open cart. If your WCPOS has no Store health page, update WCPOS first, then check. If anything is listed or waiting, or you can't check, don't clear — ask your store owner or contact support.
:::

Only if transactions consistently fail after every other step on this page, and only after the check above:
1. Clear local data
2. Login again
3. Sync fresh from server

## Transaction Safety {#transaction-safety}

WCPOS uses transactions to ensure:
- Data consistency
- Complete operations (all or nothing)
- Protection against partial updates

When a transaction fails, your data remains consistent.
