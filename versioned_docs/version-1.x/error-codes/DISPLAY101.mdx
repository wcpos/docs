## What this means {#what-this-means}

WCPOS could not build the picture of the cart that the customer-facing display shows, so that screen fell back to its idle view.

The till itself is unaffected. Keep serving: the display builds the snapshot again the next time the cart changes, so adding or removing a line usually brings it straight back.

## Your data {#your-data}

No impact. The customer display only mirrors the cart — it never holds the order, and nothing about the sale depends on it.

## Troubleshoot {#troubleshoot}

1. Keep working. Only the customer-facing screen is affected, and it recovers on the next cart change.
2. Add or remove a cart line to prompt a fresh snapshot if the display stays on the idle screen.
3. If the display never recovers during a sale, check it is still listed under **Paired displays** in **Settings → Customer Display**.
4. If this repeats, note the affected order, use **Copy debug info** on the Logs screen, and send both to support — a snapshot that fails repeatedly on the same cart usually points at one line item rather than the display itself.
