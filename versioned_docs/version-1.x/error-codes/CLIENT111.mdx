## What this means {#what-this-means}

Syncing is taking longer than expected to start.

This usually resolves by itself within a minute. If the app stays in this state, reload it once before anything else.

## Your data {#your-data}

No order or product data is affected.

## Troubleshoot {#troubleshoot}

1. Give it a minute — the first sync after an update, or on a large store, legitimately takes longer.
2. If the app stays in this state, reload it once.
3. If slow starts happen daily, check your connection to the store; if that is fine, ask whoever manages the store to check the site's own responsiveness.
