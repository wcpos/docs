## What this means {#what-this-means}

WCPOS couldn't set up or remove storage on this device.

Free up device storage, then restart WCPOS. On the web, the browser may also be restricting storage for the site — private windows do. Contact support if it keeps failing.

## Your data {#your-data}

This is a storage problem, not a refused edit. If it happened while data on this device was being cleared, part of that data may already be gone, including changes that hadn't been sent — check your recent sales and changes appear in your store. If this keeps happening, use **Copy debug info** on the **Logs** tab and contact WCPOS support.

## Troubleshoot {#troubleshoot}

1. Check free storage on the device and free some up by removing other files or apps — setting up storage fails outright when the disk or the browser's storage quota is full. Don't use the browser's "Clear browsing data" to make room — it deletes WCPOS's unsent sales too.
2. Restart WCPOS and try the same action again.
3. On web, check that the browser allows persistent storage for the site — private windows and block-all-data settings do not.
4. If it keeps failing, use **Copy debug info** on the **Logs** tab and contact support.
