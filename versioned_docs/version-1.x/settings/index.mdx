WCPOS has three types of settings organised by where they're configured.

## Where to Find Settings {#where-to-find-settings}

### 1. WordPress Admin Settings {#1-wordpress-admin-settings}

Backend settings configured in your WordPress dashboard:

**Location:** `WP Admin > POS > Settings`

These control:
- Default cart customer for all cashiers
- Product barcode field configuration
- Order email settings
- User role permissions (who can access POS)
- Payment gateway availability

See [WordPress Admin Settings](/1.x/settings/wp-admin) for details.

### 2. POS Store Settings {#2-pos-store-settings}

App-wide settings configured within the POS application:

**Location:** User menu (top-right) → Settings, or `Ctrl + Shift + S`

These control:
- Tax calculation options
- Barcode scanner configuration
- Keyboard shortcuts
- Theme/appearance

See [Store Settings](/1.x/settings/store) for details.

### 3. Display Settings (Per Screen) {#3-display-settings-per-screen}

Each screen in the POS has its own display settings for customizing the data table:

**Location:** Click the sliders icon (<Icon name="sliders" />) on any screen

These control:
- Which columns are visible
- Column display options
- Screen-specific features

Display settings are documented within each screen's documentation:
- [POS Product Panel](/1.x/pos/product-panel#display-settings)
- [Cart Panel](/1.x/pos/cart#display-settings)
- [Products Screen](/1.x/products#display-settings)
- [Orders Screen](/1.x/orders#display-settings)
- [Customers Screen](/1.x/customers#display-settings)
- [Reports Screen](/1.x/reports#display-settings)
