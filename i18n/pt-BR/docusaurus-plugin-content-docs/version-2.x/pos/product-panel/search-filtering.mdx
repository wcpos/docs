Digite no campo de busca para encontrar um produto e use a barra de filtros abaixo dele para refinar a lista. Os dois funcionam juntos: a lista mostra apenas os produtos que correspondem à busca **e** a todos os filtros ativos. Para conhecer todo o painel, veja [Encontrar um produto](index.mdx#find). Nada aparece? Veja [Quando nada corresponde](#no-match).

## Buscar um produto {#product-search}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[180, 0], [-32, 0], [0, 38], [0, 0], [-40, 0]]} alt="O painel de produtos com watch digitado no campo de busca: o botão de limpar no campo, o filtro Em estoque destacado, nove cartões de relógios e a contagem de 9 produtos abaixo da grade">

1. **Buscar produtos** — digite parte do nome de um produto, seu SKU ou seu código de barras. A lista é atualizada enquanto você digita.
2. **Limpar** — esvazia o campo. Os filtros ativos continuam sendo aplicados.
3. **Em estoque** — continua ativo durante a busca, então os produtos sem estoque permanecem ocultos. Veja [Status do estoque](#stock-status).
4. **Um cartão de produto** — toque nele para adicionar uma unidade ao carrinho. Um cartão que mostra **… opções** abre primeiro as opções; toque na que o cliente deseja. Veja [Escolher uma variação](index.mdx#variations).
5. **… produtos** — quantos produtos correspondem à busca. Uma lista longa mostra **Exibindo 20 de …**; role para baixo para ver o restante.

</JourneyShot>

### O que a busca considera {#what-search-matches}

- **Nome, SKU e código de barras.** O código de barras é o campo que sua loja usa para essa finalidade; veja [Qual campo é o código de barras](#barcode-configuration).
- **Qualquer parte de uma palavra.** "berry" encontra "Blueberry", e "123" encontra o SKU "ABC-123". Não há um tamanho mínimo.
- **Todas as palavras que você digita.** "sport watch" encontra "Bolo Sport Watch", em qualquer ordem, mas não um relógio sem "sport" no nome.
- **Sem diferenciar maiúsculas ou acentos.** "creme" encontra "Crème".
- **As opções também.** Um produto variável aparece quando o SKU ou o código de barras de uma de suas opções corresponde à busca.

A busca não considera categorias, tags ou descrições. Para refinar por categoria, tag ou marca, use a [barra de filtros](#product-filtering).

### Como a busca funciona {#how-search-works}

O POS busca primeiro nos produtos deste dispositivo, por isso os resultados aparecem imediatamente. Ele também consulta sua loja, então um produto que o dispositivo ainda não baixou aparece mesmo assim e fica salvo no dispositivo para a próxima vez. Sem conexão, a busca encontra apenas o que já está no dispositivo. Para ver quanto do seu catálogo está aqui, abra [Saúde da loja → Banco de dados](../../support/store-health.mdx#coverage).

## Filtrar a lista {#product-filtering}

Toque em um filtro para ativá-lo; ele fica destacado. Ative quantos quiser: cada um refina ainda mais a lista. Com dois ou mais ativos, **Limpar tudo** aparece no final da barra. **Em estoque** não entra nessa contagem quando já está ativo desde o início.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[38, 38], [26, 38], [-4, -38], [10, 38], [24, 38], [32, 38], [25, 38], [4, 38], [-40, 0]]} alt="A barra de filtros com Em promoção destacado e Categoria definida como Equipamentos e mais três, Tag e Marca sem destaque, seguidos de Limpar tudo e Salvar como botão; um produto corresponde aos filtros">

1. **Em promoção** — apenas os produtos em promoção no momento. Toque novamente para desativar. **Em destaque**, mais adiante na barra, funciona da mesma forma para produtos marcados como destaque no WooCommerce.
2. **Categoria** — mostra a categoria que você selecionou. Veja [Categoria, Tag e Marca](#category).
3. **+3** — mais três categorias também estão selecionadas.
4. **Remover** (o X) — desativa apenas este filtro.
5. **Tag** — selecione uma tag.
6. **Marca** — selecione uma marca.
7. **Limpar tudo** — restaura os filtros ao estado inicial do painel e esvazia a busca. Veja [Restaurar com Limpar tudo](#clear-all).
8. **Salvar como botão** — salva esses filtros como um botão personalizado. Veja [Salvar filtros como um botão](#save-as-button).
9. **… produto** — quantos produtos correspondem aos filtros.

</JourneyShot>

Deslize a barra para os lados para acessar os filtros que estão fora da área visível.

### Status do estoque {#stock-status}

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 0], [145, 0], [145, 0], [145, 0], [10, -38]]} alt="A lista de status do estoque aberta abaixo do filtro Em estoque: Em estoque marcado, Fora de estoque e Sob encomenda">

1. **Em estoque** — o filtro recebe o nome do status que exibe. Toque nele para abrir a lista.
2. **Em estoque** — produtos que você tem em estoque. Ativo desde o início, a menos que **Mostrar produtos sem estoque** esteja ativado em [Configurações de exibição](display-settings.mdx#show-out-of-stock-products).
3. **Fora de estoque** — apenas produtos sem unidades disponíveis.
4. **Sob encomenda** — apenas produtos que sua loja permite vender antes da reposição do estoque.
5. **Remover** (o X) — permite exibir todos os status do estoque. A busca e os outros filtros continuam sendo aplicados.

</JourneyShot>

### Categoria, Tag e Marca {#category}

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[40, -38], [246, 0], [147, 0], [39, 0], [131, 0], [10, -38]]} alt="A lista de Categoria aberta com Relógios digitado no campo de busca: Equipamentos marcado com sua seta e Relógios marcado abaixo; o filtro agora mostra Equipamentos e mais três">

1. **Categoria** — toque para abrir a lista de categorias. Depois que você seleciona uma, o filtro mostra o nome dela.
2. **Buscar categorias** — digite para refinar a lista. Uma subcategoria aparece abaixo da categoria à qual pertence.
3. **Uma categoria** — toque para selecioná-la. Selecione mais de uma para ver produtos de qualquer uma delas. Selecionar uma categoria também inclui suas subcategorias, por isso **Equipamentos** mostra **+3**.
4. **A seta** — expande ou recolhe as subcategorias de uma categoria, para que você possa selecionar apenas uma delas.
5. **Uma subcategoria** — marcada aqui porque **Equipamentos** está selecionado.
6. **Remover** (o X) — desativa o filtro de categoria.

</JourneyShot>

**Tag** e **Marca** abrem o mesmo tipo de lista, com um campo de busca no topo. Cada filtro aceita uma tag ou uma marca por vez: selecionar outra substitui a anterior.

### Restaurar com Limpar tudo {#clear-all}

**Limpar tudo** aparece quando dois ou mais filtros estão ativos, sem contar **Em estoque** quando já está ativo desde o início. Pressione para restaurar a barra ao estado inicial do painel: todos os filtros desativados, exceto **Em estoque**, se ele estiver ativo no início, e o campo de busca vazio. Se você abriu uma categoria, tag, marca ou atalho em **Navegar por**, permanece nele, com os filtros e a busca próprios desse atalho. Para ver também os produtos sem estoque, pressione o X em **Em estoque**.

Com apenas um filtro ativo além desse, **Limpar tudo** não aparece. Nesse caso, pressione o X desse filtro ou toque novamente em **Em destaque** ou **Em promoção**.

## Quando nada corresponde {#no-match}

Toque novamente em **Em destaque** ou **Em promoção** para desativar, ou pressione o X em qualquer outro filtro. **Limpar filtros** esvazia a busca e desativa os filtros de uma vez. **Em estoque** permanece ativo se já estava ativo no início; por isso, para encontrar um produto sem estoque, pressione também o X em **Em estoque**.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[180, 0], [38, 38], [-20, 0], [-27, 0]]} alt="Nenhum produto: o painel mostra Nenhum dos 230 produtos corresponde a watch, Em estoque, Em promoção, com um botão Limpar filtros abaixo">

1. **A busca** — o que você digitou.
2. **Em promoção** — um filtro ativo.
3. **Nenhum dos … produtos corresponde a …** — indica sua busca e todos os filtros ativos, para você identificar qual desativar.
4. **Limpar filtros** — esvazia a busca e desativa os filtros, exceto **Em estoque**, se já estava ativo no início. Uma categoria, tag, marca ou atalho que você abriu em **Navegar por** permanece aberto.

</JourneyShot>

## Salvar filtros como um botão {#save-as-button}

Se você usa os mesmos filtros todos os dias, salve-os em um único botão na barra. Com pelo menos um filtro ativo, sem contar **Em estoque** quando já está ativo no início, pressione o ícone de marcador no final da barra, **Salvar como botão**, dê um nome e pressione **Adicionar à barra**.

Toque no seu botão para mostrar os produtos correspondentes. Ele substitui os filtros e a busca que estavam ativos. Toque novamente para desativá-lo. Para editar ou remover, mantenha o botão pressionado.

<summary>O que o painel Salvar como botão mostra</summary>

1. **Nome do botão** — o texto do botão na barra.
2. **Na barra** — como o botão ficará.
3. **Na categoria: …** — um filtro ativo no momento. Desmarque para não incluí-lo.
4. **Em promoção** — outro filtro. Uma busca ou uma ordem de classificação que você alterou também aparece aqui, desmarcada; marque para mantê-la.
5. **… produtos correspondem neste dispositivo** — o que o botão mostrará, com os nomes de até cinco produtos.
6. **Adicionar à barra** — salva o botão neste dispositivo. Fica disponível quando o botão recebe um nome.
7. **Cancelar** — fecha sem salvar.

## Alterar a barra de filtros {#customise}

Mantenha um filtro pressionado, ou clique com o botão direito no computador, para abrir seu menu: oculte esse filtro da barra (o que também o restaura ao estado inicial do painel) ou organize toda a barra como preferir em [Configurações de exibição](display-settings.mdx#filter-bar). Em um botão que você salvou, o menu mostra **Editar "…"**, **Personalizar barra de filtros** e **Remover da barra**.

<details>
<summary>O que o menu de um filtro mostra</summary>

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[38, -38], [156, 0], [167, 0]]} alt="O menu do filtro Em promoção: Ocultar da barra e Personalizar barra de filtros">

1. **Em promoção** — o filtro que você manteve pressionado.
2. **Ocultar da barra** — remove o filtro da barra neste dispositivo e o restaura ao estado inicial do painel.
3. **Personalizar barra de filtros** — organize os filtros como preferir, desative ou ative filtros e adicione seus próprios botões. Veja [Configurações de exibição](display-settings.mdx#filter-bar).

</JourneyShot>

</details>

:::tip Dentro das opções de um produto
Quando um produto variável está aberto no painel, apenas o filtro de status do estoque se aplica às suas opções. Os outros filtros ficam desabilitados; toque em **Produtos** no caminho de navegação para voltar a eles. Veja [Produtos variáveis](variations.mdx).
:::

## Qual campo é o código de barras {#barcode-configuration}

Tanto a busca quanto a leitura de códigos usam o campo de código de barras da loja, definido em [Campo de código de barras](../../settings/wp-admin/general.mdx#barcode-field). Para ler códigos, veja [Leitura de códigos de barras](barcode-scanning.mdx).

<details>
<summary>Configurações do campo de código de barras</summary>

Por padrão, o código de barras é o campo ID exclusivo global do WooCommerce (`_global_unique_id`), onde você informa um GTIN, UPC, EAN ou ISBN. Você pode alterá-lo para o SKU (`_sku`) ou para o campo usado por um plugin de código de barras. O POS lê um código de barras por produto e um por opção de um produto variável.

</details>

## Se algo der errado {#goes-wrong}

- **Nenhum dos … produtos corresponde a …** — a mensagem indica a busca e todos os filtros ativos. Desative um deles ou pressione **Limpar filtros**.
- **A lista parece curta** — um filtro ainda está ativo. Procure itens destacados na barra, incluindo **Em estoque**, que oculta produtos sem estoque.
- **Um produto que você sabe que está na loja não aparece** — tente buscar por parte do nome ou pelo SKU. A busca consulta sua loja, então verifique se este dispositivo está conectado à internet. Se ainda não aparecer, o produto pode estar marcado como exclusivo da loja online; veja [Produtos exclusivos do POS](../../products/pos-only-products.mdx).
- **O nome de uma categoria não encontra nada** — a busca não considera categorias. Use o filtro **Categoria**.
- **Os filtros estão desabilitados** — você está dentro das opções de um produto variável. Toque em **Produtos** no caminho de navegação.
- **Um código de barras lido não é encontrado** — verifique qual campo está definido como código de barras. Veja [Qual campo é o código de barras](#barcode-configuration).
