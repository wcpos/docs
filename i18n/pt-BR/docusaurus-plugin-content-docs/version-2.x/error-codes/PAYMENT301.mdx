## O que isso significa {#what-this-means}

O gateway de pagamento selecionado não está disponível para esta loja.

Peça ao administrador do site que verifique se o gateway de pagamento é compatível, está ativado e foi configurado corretamente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, fale com a pessoa responsável pelo seu site WordPress.

## Como resolver {#troubleshoot}

**No caixa:**

1. Enquanto isso, conclua a venda com outra forma de pagamento, como dinheiro.
2. Se a forma de pagamento estiver esmaecida em **… indisponível no momento** no painel de pagamento, isso é um problema neste caixa, não este erro — o motivo exibido (por exemplo, **Precisa de uma conexão** ou **Ative o Bluetooth para usar o leitor**) informa o que corrigir.

**Na loja** — para o administrador do site:

3. Acesse **WP Admin > PDV > Configurações > Caixa**. Em **Gateways de pagamento**, o gateway de pagamento deve estar listado e sua opção **Ativado** deve estar ligada. Se ele não estiver listado, verifique se o plugin correspondente está instalado e ativo. Não é necessário ativá-lo em **WP Admin > WooCommerce > Configurações > Pagamentos**: o PDV lista todos os gateways de pagamento registrados por plugins ativos. No WCPOS Free, só é possível ativar as formas de pagamento integradas de dinheiro e cartão; outros gateways de pagamento do WooCommerce exigem o WCPOS Pro.
4. Se o gateway de pagamento funcionava ontem, verifique se ele ou o WooCommerce foi atualizado — **WooCommerce → Status → Logs** pode conter erros de inicialização do gateway de pagamento.
5. Depois de corrigir o problema, recarregue o aplicativo no caixa para que ele reconheça o gateway de pagamento novamente.
