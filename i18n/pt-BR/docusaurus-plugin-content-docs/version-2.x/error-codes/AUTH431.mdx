## O que isso significa {#what-this-means}

A API REST da loja não respondeu em nenhum formato de endereço que este aplicativo pode usar.

O aplicativo tentou acessar a API REST da loja no endereço normal (/wp-json/...) e no endereço alternativo nativo do WordPress (/?rest_route=...), mas nenhum deles respondeu. O site da loja em si pode estar funcionando — o problema é especificamente a API REST inacessível, geralmente porque um plugin de segurança a oculta ou uma regra de firewall a bloqueia.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

**Na loja** — para o administrador do site: se um plugin de segurança oculta ou renomeia `/wp-json/` (por exemplo, WP Hide), permita também o formato nativo `/?rest_route=` do WordPress — o aplicativo o usa automaticamente como alternativa.

**Na hospedagem / no servidor:**

1. Verifique as regras do firewall (WAF) em busca de correspondências com `wp-json` ou `rest_route` e permita o acesso à própria API REST da loja.
2. Se houver uma página de manutenção ou um desafio contra bots à frente do servidor, as solicitações REST podem receber uma página HTML como resposta — desative o desafio para a API REST.

**Para testar (qualquer pessoa):** `https://your-store.com/?rest_route=/` deve retornar JSON, não uma página 403 nem a página inicial do site.
