## O que isso significa {#what-this-means}

O atualizador não está autorizado a baixar atualizações do WCPOS Pro.

Autorize novamente o atualizador para esta loja e depois verifique se há atualizações.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, fale com a pessoa responsável pelo seu site WordPress.

## Como resolver {#troubleshoot}

1. Acesse **WP Admin > PDV > Configurações > Licença**. Se a página mostrar o campo **Chave da licença**, insira sua chave e pressione **Ativar**; se ela já mostrar a licença como ativada, primeiro copie a chave completa da sua conta WCPOS (a página mostra apenas uma versão abreviada), pressione **Desativar**, insira a chave novamente e pressione **Ativar**.
2. Verifique novamente se há atualizações em WP Admin → Painel → Atualizações.
3. Se a autorização continuar falhando, o site pode estar bloqueando solicitações de saída para o servidor de atualizações — pergunte ao provedor de hospedagem se há restrições de saída para HTTPS.
