## O que isso significa {#what-this-means}

Ocorreu um problema inesperado na finalização da compra.

Verifique o pedido no painel administrativo da sua loja antes de cobrar o cliente novamente. Exporte os dados de diagnóstico e entre em contato com o suporte se o problema se repetir.

## Seus dados {#your-data}

Não foi possível confirmar o resultado — verifique antes de tentar novamente. Se o problema persistir, exporte os dados de diagnóstico e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Verifique o pedido em WooCommerce → Pedidos no WP Admin antes de cobrar o cliente novamente.
2. Expanda a entrada do log e anote o código do evento e qualquer serverCode — este código genérico indica que a causa ainda não tem um código específico.
3. Se o problema se repetir, exporte as informações de depuração e entre em contato com o suporte.
