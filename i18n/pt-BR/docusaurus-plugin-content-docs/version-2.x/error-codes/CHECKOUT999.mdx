## O que isso significa {#what-this-means}

O checkout encontrou um problema inesperado.

Confira o pedido no painel da loja antes de cobrar o cliente novamente. Exporte os diagnósticos e entre em contato com o suporte se o problema se repetir.

## Seus dados {#your-data}

Não foi possível confirmar o resultado — verifique antes de tentar novamente. Se o problema persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. No WP Admin, confira em WooCommerce → Pedidos se o pedido existe antes de cobrar o cliente novamente.
2. Expanda a entrada do registro e anote o código do evento e qualquer serverCode — este código genérico indica que a causa ainda não tem um código específico.
3. Se o problema se repetir, exporte as informações de depuração e entre em contato com o suporte.
