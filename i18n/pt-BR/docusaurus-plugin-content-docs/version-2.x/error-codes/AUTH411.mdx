## O que isso significa {#what-this-means}

O endereço da loja está ausente ou não é uma URL válida.

O campo de endereço estava vazio, ou a loja respondeu, mas o endereço de login do WCPOS é inválido — nesse caso, a correção é feita na loja, não no caixa.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Digite o endereço da loja em **Digite a URL da sua loja WooCommerce** — por exemplo, `shop.example.com` — e pressione **Conectar**. Um campo contendo apenas espaços é considerado vazio.
2. Se o endereço estiver preenchido e a mensagem disser **"A URL de login do WCPOS é inválida. Verifique se o plugin WCPOS está configurado corretamente"**, o problema está na loja. **Administrador do site:** atualize o WCPOS para a versão mais recente em **WP Admin → Plugins** e pressione **Conectar** novamente. Não desative e reative o plugin para corrigir isso — a reativação restaura as permissões do POS de todas as funções para os valores padrão.
3. **Administrador do site:** se isso não resolver, abra o endereço completo da loja seguido de `/wp-json/` em um navegador — por exemplo, `https://your-store.com/wp-json/`, ou `https://example.com/shop/wp-json/` quando o WordPress estiver em `/shop`. Se isso retornar um 404 (por exemplo, com links permanentes simples), use o mesmo endereço seguido de `/?rest_route=/` em vez disso. Em `authentication` → `wcpos` → `endpoints`, `authorization` deve ser um endereço web simples. Se for uma lista, um objeto ou um número, um plugin de segurança, cache ou personalização de REST está alterando essa resposta — desative esses plugins um por vez em uma cópia de homologação para identificar o responsável.
