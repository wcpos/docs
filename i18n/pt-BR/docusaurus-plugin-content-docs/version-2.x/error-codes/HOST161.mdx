## O que isso significa {#what-this-means}

A hospedagem está limitando a frequência de solicitações dos caixas desta loja.

O servidor continua respondendo com 429 (solicitações em excesso), embora o aplicativo já esteja espaçando as tentativas e respeitando os intervalos Retry-After do servidor. Vários caixas na mesma conexão com a internet compartilham um endereço, por isso os limites por origem os tratam como um único cliente com muita atividade. A sincronização continua automaticamente, mas ficará atrasada até que o limite seja aumentado.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Como resolver {#troubleshoot}

1. Peça ao provedor de hospedagem que aumente ou remova o limite de solicitações da API REST para o tráfego da própria loja — informe o IP estático da loja, se houver.
2. Serviços de segurança que contabilizam respostas de erro repetidas (429) para aplicar um bloqueio (por exemplo, o IDS do Sucuri) podem precisar excluir a API da loja dessa contagem.
3. Se vários caixas compartilham uma conexão, informe isso ao provedor de hospedagem: nesse caso, um IP representa uma loja inteira, não apenas um usuário.
