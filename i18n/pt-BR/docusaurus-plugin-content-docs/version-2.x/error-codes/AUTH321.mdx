## O que isso significa {#what-this-means}

O WooCommerce não está ativo neste site, então o WCPOS não consegue se conectar.

O WCPOS requer o plugin WooCommerce. Peça ao administrador do site para instalar ou reativar o WooCommerce e conecte-se novamente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, peça ajuda a quem administra seu site WordPress.

## Solução de problemas {#troubleshoot}

1. Peça ao administrador do site para verificar WP Admin → Plugins: o WooCommerce precisa estar instalado e ativo para o WCPOS se conectar.
2. Se o WooCommerce foi desativado por uma falha na atualização, reative-o e observe se aparece uma faixa de erro — WooCommerce → Status → Registros informa o motivo da falha.
3. Assim que o WooCommerce estiver ativo novamente, reconecte-se pelo caixa.
