## O que isso significa {#what-this-means}

Outro plugin de autenticação está impedindo a conexão do WCPOS.

Peça ao administrador do site para resolver o conflito com o plugin indicado antes de entrar novamente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, peça ajuda a quem administra seu site WordPress.

## Solução de problemas {#troubleshoot}

**Na loja** — para o administrador do site:

1. O erro identifica o plugin em conflito. Revise as configurações desse plugin — a maioria dos plugins de autenticação permite criar exceções para as rotas REST do WCPOS, sem precisar desativar o plugin por completo.
2. Se não estiver claro qual plugin está causando o conflito, faça um teste em uma cópia de homologação, desativando os plugins de segurança e de login um por vez.

**No caixa** — para o operador de caixa: depois da alteração, entre novamente.
