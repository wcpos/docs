## O que isso significa {#what-this-means}

Alguns dados não foram sincronizados desta vez.

Este código aparece de duas formas — o título da linha do log indica qual é o seu caso:

- **"Sincronização parcial"** (títulos dos registros): alguns registros foram sincronizados, mas os registros indicados não foram. Não é necessário fazer nada se a próxima sincronização resolver o problema. Se **Saúde da loja → Banco de dados** listar alterações que precisam de atenção, resolva-as lá.
- **"Solicitação de dados travada abandonada"**: o processamento de solicitações de dados do mecanismo de sincronização parou de avançar em uma solicitação. Após uma longa espera, o aplicativo abandonou essa solicitação para que ela não bloqueasse tudo que estava na fila atrás dela. Não é necessário tentar novamente à mão — o mecanismo de sincronização refaz a solicitação automaticamente. Isso costuma acontecer após uma chamada ao banco de dados local travar, o que é registrado separadamente como [SYNC181](/error-codes/SYNC181).

## Seus dados {#your-data}

Não limpe os dados deste dispositivo — ele pode conter alterações que sua loja ainda não recebeu. No caso de uma solicitação de dados abandonada, nada foi alterado — a solicitação é refeita automaticamente. Se isso continuar acontecendo, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Para uma entrada **"Solicitação de dados travada abandonada"**, nenhuma ação é necessária, a menos que uma tela permaneça travada. Nesse caso, recarregue o aplicativo — recarregue a aba do navegador na web ou feche e abra novamente o aplicativo no desktop ou no dispositivo móvel.
2. Para uma sincronização parcial, não é necessário fazer nada se a próxima sincronização resolver o problema. Caso contrário, abra **Saúde da loja → Banco de dados**: os registros que ainda não foram sincronizados aparecem no topo. O aviso **"… registros precisam de atenção"** indica o primeiro deles e o motivo (corrija-o para que o próximo apareça), e os painéis **"… alterações nunca chegaram ao seu servidor"** e **"… alterações foram retidas"** listam os respectivos registros. Os registros que foram sincronizados não precisam de nenhuma ação.
3. Resolva cada registro listado de acordo com o motivo indicado. No aviso, **Corrigir registro** (quando exibido) abre o registro para edição; uma alteração recusada deve ser corrigida no próprio registro ([SYNC201](/error-codes/SYNC201)); para uma alteração retida, escolha qual versão manter ([SYNC221](/error-codes/SYNC221)).
4. Depois, envie-os novamente: use **Tentar novamente** no aviso (isso executa uma sincronização) ou **Enviar novamente** na linha do registro nos painéis. Um registro que o aviso indica que *não pode ser baixado da sua loja* não tem a opção **Tentar novamente** — consulte [SYNC331](/error-codes/SYNC331).
5. Se um registro ainda não for sincronizado, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte.
