## O que isso significa {#what-this-means}

Mais de um produto corresponde a este código de barras.

O WCPOS não consegue escolher entre eles com segurança, por isso nada foi adicionado. Busque o produto pelo nome e atribua um código de barras exclusivo a cada produto na loja para resolver o conflito.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, consulte o administrador da loja.

## Solução de problemas {#troubleshoot}

1. **No caixa:** a leitura não adicionou nada e apareceu a notificação **Várias correspondências**. O código lido está agora na caixa de busca de produtos, então os produtos que compartilham esse código estão listados — adicione o correto manualmente e finalize a venda.
2. Primeiro, limpe os filtros de categoria ou estoque — eles restringem a mesma busca e podem ocultar algumas correspondências. Depois, anote o nome de cada produto da lista para quem administra a loja.
3. **Administrador do site:** no WP Admin, abra cada um desses produtos e atribua um código de barras exclusivo a cada um. Confira o campo que a loja usa para códigos de barras — **WP Admin > PDV > Configurações > Geral > Campo de código de barras** (por padrão, o GTIN do produto, `_global_unique_id`). Um valor duplicado no SKU ou em outro campo de código de barras também pode gerar uma correspondência, então confira esses campos também.
4. **De volta ao caixa:** abra **Saúde da loja → Banco de dados**, abra o menu **⋮** na linha **Produtos** e escolha **Verificar alterações agora** — faça o mesmo na linha **Variações** se alguma das correspondências for uma variação — e leia o código novamente. Agora a leitura deve adicionar o produto diretamente.
