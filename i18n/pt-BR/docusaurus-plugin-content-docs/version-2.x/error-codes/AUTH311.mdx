## O que isso significa {#what-this-means}

O WCPOS não consegue acessar seu ponto de conexão na sua loja.

Peça ao administrador do site para verificar se o plugin WCPOS está ativo (**WP Admin → Plugins**) e se nenhum plugin de segurança está bloqueando a REST API.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Avise o administrador do site.

## Solução de problemas {#troubleshoot}

**No caixa** — para o operador de caixa: avise o administrador do site. Nada neste dispositivo é afetado.

**Na loja** — para o administrador do site:

1. Confirme que o WCPOS está ativo: WP Admin → Plugins.
2. Se nenhuma das duas formas de acesso REST funcionar, verifique se um plugin de segurança, proxy ou CDN está removendo os cabeçalhos das solicitações do WCPOS ou bloqueando as solicitações REST — regras de firewall e opções de reforço de segurança que desativam a REST API costumam ser as causas.
3. Em algumas hospedagens, salvar novamente os links permanentes (Configurações → Links permanentes → Salvar alterações) restaura as rotas REST ausentes.
