## O que isso significa {#what-this-means}

A sincronização está demorando mais do que o esperado para iniciar.

Geralmente, isso se resolve sozinho em até um minuto. Se o aplicativo continuar nesse estado, recarregue-o uma vez antes de fazer qualquer outra coisa.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Aguarde um minuto — é normal que a primeira sincronização após uma atualização, ou em uma loja grande, demore mais.
2. Se o aplicativo continuar nesse estado, recarregue-o uma vez.
3. Se a inicialização lenta acontecer todos os dias, confira sua conexão com a loja; se estiver tudo certo, peça a quem administra a loja para verificar a capacidade de resposta do próprio site.
