## O que isso significa {#what-this-means}

Um proxy à frente da loja rejeita as respostas do servidor por conterem cabeçalhos demais.

Uma camada de cache ou proxy (geralmente o Varnish) impõe um limite à quantidade ou ao tamanho dos cabeçalhos de resposta. Os endpoints leves da loja ficam dentro desse limite, mas as respostas completas da API o excedem e retornam erros 503 do proxy, não do WordPress. O limite precisa ser aumentado nessa camada.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. No Varnish, aumente http_max_hdr (quantidade de cabeçalhos) e http_resp_hdr_len / http_resp_size (tamanhos).
2. Pergunte ao provedor de hospedagem qual camada de proxy retorna o 503 — o log de erros do WordPress não mostrará nada, porque a requisição nunca falha nele.
3. Uma verificação rápida: /wcpos/v2/ping da loja responde normalmente, enquanto os endpoints de dados retornam 503.
