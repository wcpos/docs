## O que isso significa {#what-this-means}

O plugin WCPOS desta loja é antigo demais para esta versão do aplicativo.

O aplicativo foi atualizado, mas o plugin WCPOS da loja não, e as duas versões não funcionam mais juntas. Peça à pessoa responsável pelo site que atualize o plugin WCPOS no WP Admin e conecte-se novamente. Não é necessário alterar nada no caixa.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, consulte a pessoa responsável pelo seu site WordPress.

## Solução de problemas {#troubleshoot}

**Na loja** — para a pessoa responsável pelo site WordPress:

1. WP Admin → Plugins → atualize o WCPOS para a versão mais recente. Se o WCPOS Pro estiver instalado, atualize-o para uma versão correspondente ao mesmo tempo.
2. Se nenhuma atualização for oferecida, verifique WP Admin → Painel → Atualizações; no Pro, um atualizador não autorizado bloqueia as atualizações (veja [LICENSE301](./LICENSE301)) — resolva isso primeiro.

**No caixa** — para o operador de caixa: depois que a loja for atualizada, reconecte-se. Você não precisa digitar o endereço da loja novamente.

**Se ainda não for possível atualizar a loja:** entre em contato com o suporte — o caixa precisa de uma versão do aplicativo que corresponda ao plugin, e o suporte pode indicar qual usar. A equipe pedirá a versão do aplicativo (no caixa) e a versão atual do WCPOS da loja (no WP Admin).
