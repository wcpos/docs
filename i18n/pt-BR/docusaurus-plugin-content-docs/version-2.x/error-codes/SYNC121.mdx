## O que isso significa {#what-this-means}

Não é possível se conectar à sua loja no momento.

Não é preciso fazer nada — continue vendendo. As alterações são enviadas automaticamente quando a conexão volta. Se o problema persistir, confira a conexão deste dispositivo e se o site da sua loja carrega.

## Seus dados {#your-data}

Não limpe os dados deste dispositivo — ele pode conter alterações que sua loja ainda não recebeu. Elas são enviadas automaticamente assim que sua loja responde.

## Solução de problemas {#troubleshoot}

1. Continue vendendo — as vendas são salvas neste dispositivo e enviadas automaticamente assim que a loja responde.
2. Confira se o próprio terminal está conectado à internet: algum outro site carrega neste dispositivo?
3. Abra o site da sua loja em uma aba do navegador no mesmo dispositivo; se ele também não carregar ali, o site ou a hospedagem está fora do ar, não o POS.
4. **Para quem gerencia a rede deste dispositivo:** se o site carrega, mas o POS continua offline, algo entre os dois está bloqueando as solicitações à API — uma VPN, firewall, bloqueador de anúncios ou plugin de segurança. As ferramentas de desenvolvedor do navegador (aba Rede) — ou **Avançado → Alternar ferramentas de desenvolvedor** no aplicativo para desktop — mostram qual solicitação falha.
