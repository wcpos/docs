## O que isso significa {#what-this-means}

O WCPOS não conseguiu configurar ou remover o armazenamento neste dispositivo.

Libere espaço de armazenamento no dispositivo e reinicie o WCPOS. Na web, o navegador também pode estar restringindo o armazenamento do site — janelas privadas fazem isso. Entre em contato com o suporte se a falha persistir.

## Seus dados {#your-data}

Este é um problema de armazenamento, não uma edição recusada. Se aconteceu enquanto os dados deste dispositivo estavam sendo limpos, parte deles pode já ter sido excluída, incluindo alterações que não haviam sido enviadas — confira se suas vendas e alterações recentes aparecem na loja. Se isso continuar acontecendo, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Confira o espaço livre de armazenamento no dispositivo e libere espaço removendo outros arquivos ou aplicativos — não é possível configurar o armazenamento quando o disco está cheio ou a cota de armazenamento do navegador está esgotada. Não use a opção "Limpar dados de navegação" do navegador para liberar espaço — ela também exclui as vendas não enviadas do WCPOS.
2. Reinicie o WCPOS e tente a mesma ação novamente.
3. Na web, confira se o navegador permite armazenamento persistente para o site — janelas privadas e configurações que bloqueiam todos os dados não permitem.
4. Se a falha persistir, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte.
