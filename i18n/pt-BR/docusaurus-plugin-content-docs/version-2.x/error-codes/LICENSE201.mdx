## O que isso significa {#what-this-means}

O WCPOS Pro está desativado porque sua versão não corresponde à do WCPOS.

Atualize o componente indicado do WCPOS ou WCPOS Pro para que as duas versões sejam compatíveis.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, fale com a pessoa responsável pelo seu site WordPress.

## Como resolver {#troubleshoot}

1. Verifique as versões dos dois plugins em WP Admin → Plugins — o registro no log indica qual deles, WCPOS ou WCPOS Pro, está desatualizado.
2. Atualize o mais antigo; atualizar os dois para as versões mais recentes resolve a incompatibilidade.
3. Se as atualizações do Pro não estiverem sendo oferecidas, o atualizador pode não estar autorizado (consulte LICENSE301) — resolva isso primeiro e depois atualize.
