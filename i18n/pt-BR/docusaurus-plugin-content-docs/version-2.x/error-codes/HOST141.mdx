## O que isso significa {#what-this-means}

O filtro de segurança da hospedagem está bloqueando as buscas de produtos.

Uma regra de firewall desta hospedagem rejeita solicitações REST cuja string de consulta contém caracteres não ASCII ou palavras que parecem SQL. Nomes de produtos com acentos e buscas com palavras como 'select' ou 'union' falham com um erro 403, mesmo sendo buscas comuns no catálogo. O restante do caixa funciona; as buscas não serão confiáveis até que a regra seja flexibilizada.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Como resolver {#troubleshoot}

1. Peça ao provedor de hospedagem que permita os parâmetros de busca REST da própria loja (rotas /wcpos/ e /wc/) nas regras de firewall para strings de consulta.
2. Em firewalls baseados no OWASP CRS, as regras de injeção de SQL nos argumentos 's' e 'search' costumam ser as responsáveis — exclua esses argumentos das regras para as rotas da API REST.
3. Plugins de segurança com uma opção de 'filtrar strings de consulta suspeitas' precisam de uma exceção para a API REST, e não da desativação global dessa opção.
