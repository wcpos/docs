## O que isso significa {#what-this-means}

Sua loja não tem mais este pedido, por isso este dispositivo resolveu o que fazer com a própria cópia.

Alguém excluiu o pedido (enviou para a lixeira) no WP Admin enquanto este dispositivo ainda o mantinha. A cópia da loja não existe mais, por isso este dispositivo mantém o carrinho como um novo pedido ou remove a própria cópia.

## Seus dados {#your-data}

Um carrinho aberto é mantido e enviado novamente como um novo pedido, com um novo número. Ele é enviado na próxima vez que você pressionar **Finalizar Compra**. Qualquer outro pedido é removido deste dispositivo, porque a cópia da loja não existe mais. Não há mais nada aguardando envio.

## Solução de problemas {#troubleshoot}

1. Expanda a entrada do log: ela informa o número do pedido excluído na loja e se este dispositivo manteve o carrinho como um novo pedido ou removeu a cópia.
2. Se o carrinho foi mantido, a venda continua normalmente. Ela chega à loja como um novo pedido, com um novo número, quando você pressiona **Finalizar Compra**.
3. Se o pedido foi removido por engano, um administrador da loja pode restaurá-lo em **WooCommerce → Pedidos → Lixeira** no WP Admin. Este dispositivo o recebe novamente na próxima atualização.
4. Se o mesmo pedido continuar aparecendo nos avisos, um administrador está excluindo pedidos que este dispositivo ainda usa. Combinem quem fecha os carrinhos abertos antes de enviá-los para a lixeira.
