## O que isso significa {#what-this-means}

Este navegador permite que apenas uma aba envie alterações por vez.

O WCPOS não gera mais este código: apenas uma aba executa o PDV. Uma segunda aba exibe **O PDV está aberto em outra aba**; pressione **Assumir aqui** para continuar nessa aba ou volte à primeira. Consulte [Se o PDV não iniciar](../getting-started/index.mdx#wont-start).

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Use o PDV em uma única aba. Se uma aba exibir **O PDV está aberto em outra aba**, pressione **Assumir aqui** para continuar nela.
2. Este navegador (ou uma janela privada) não tem o recurso de coordenação entre abas preferido pelo PDV; por isso, ele usa uma única aba para sincronizar. Não é necessário corrigir nada.
