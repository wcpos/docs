# Códigos de erro {#error-codes}

Quando o WCPOS encontra um problema, ele exibe um código de erro que ajuda a identificá-lo. A partir da **v1.10.0**, os códigos seguem o formato **domínio + três dígitos** — por exemplo, `SYNC131` ou `AUTH311`. O domínio indica a área do POS; o número identifica a condição específica. Cada código tem sua própria página com seu significado, o que fazer e o que ele significa para seus dados.

No POS, os códigos de erro aparecem em **Saúde da loja → Logs**: expanda uma linha e use o link **Ajuda** para acessar diretamente a página do código aqui.

## Domínios de erro (v1.10.0+) {#error-domains}

| Domínio | Área |
|--------|------|
| [`AUTH`](#auth) | Login, sessões e tokens |
| [`CHECKOUT`](#checkout) | Finalização de pedidos no caixa |
| [`CLIENT`](#client) | O próprio aplicativo POS e o armazenamento local |
| [`DISPLAY`](#display) | A tela voltada ao cliente |
| [`HOST`](#host) | Hospedagem e regras de firewall que bloqueiam o POS |
| [`LICENSE`](#license) | Ativação e validação da licença Pro |
| [`PAYMENT`](#payment) | Gateways de pagamento e terminais |
| [`PRINT`](#print) | Impressão de recibos |
| [`PRODUCT`](#product) | Dados de produtos e operações do catálogo |
| [`REGISTER`](#register) | Gaveta de dinheiro, sessões de caixa e contagens |
| [`SYNC`](#sync) | Sincronização entre o POS e sua loja |

Encontre seu código abaixo ou pesquise por ele.

Os códigos terminados em `999` abrangem as condições do domínio que ainda não têm um código específico.

## Códigos anteriores à v1.10.0 {#legacy-codes}

Códigos como `API04001` vêm de versões anteriores à v1.10.0; esta versão nunca os gera. Você ainda pode encontrar um deles em um registro de log mantido desde antes da atualização ou em um tópico antigo de suporte. Selecione **1.x** no menu de versões para consultá-los.

2. Participe da nossa [comunidade no Discord](https://wcpos.com/discord) para obter suporte
3. Relate problemas no [GitHub](https://github.com/wcpos)
