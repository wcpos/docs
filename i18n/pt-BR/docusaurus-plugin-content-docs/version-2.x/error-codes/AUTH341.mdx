## O que isso significa {#what-this-means}

Esta loja informa a mesma identidade de uma loja já salva neste dispositivo.

Cada loja tem uma identidade que o plugin WCPOS cria uma única vez. Quando um site é copiado, por exemplo para criar um site de homologação, a cópia mantém a identidade do original. Assim, o aplicativo não consegue distinguir os dois e se recusa a salvar o segundo para evitar misturá-lo com o primeiro.

Um dos dois sites é uma cópia do outro. O conflito não indica qual: se a cópia foi conectada primeiro, a loja que você acabou de tentar conectar é a original. A pessoa responsável pelos sites sabe qual deles foi copiado, e é esse site que precisa de uma nova identidade.

## Seus dados {#your-data}

A recusa em si não altera nada: a loja salva foi mantida exatamente como estava, e a nova loja não foi salva.

Remover a loja salva, como faz a segunda solução abaixo, é diferente. As vendas dessa loja que ainda aguardam sincronização permanecem no dispositivo, mas não são retomadas automaticamente quando a loja é adicionada novamente. Verifique se a loja salva não tem nada pendente de sincronização antes de removê-la ou, se tiver, entre em contato com o suporte primeiro.

## Solução de problemas {#troubleshoot}

**No site copiado** — para a pessoa responsável por esse site WordPress:

1. Identifique qual dos dois sites é a cópia (geralmente o site de homologação ou de testes).
2. Na cópia: WP Admin → Plugins → atualize o WCPOS para a versão mais recente. A partir da versão 1.10.21, o plugin atribui uma identidade própria ao site copiado na primeira vez que é executado no novo endereço. Atualizar o original não resolve esse problema, pois o endereço dele não mudou.
3. Conecte-se novamente pelo caixa.

**No caixa** — se ainda não for possível atualizar a cópia:

1. Certifique-se de que todas as vendas da loja salva indicada na mensagem foram sincronizadas. Se ainda houver vendas aguardando, sincronize-as primeiro ou entre em contato com o suporte antes de continuar.
2. Na tela de conexão, remova essa loja salva.
3. Conecte a loja desejada pelo endereço dela.

Você só pode manter uma das duas conectada até que a cópia tenha sua própria identidade.

**Se os dois endereços apontam para a mesma loja** (por exemplo, um endereço de rede local e o domínio público): remova a entrada salva e conecte-se novamente usando o endereço que este caixa usará a partir de agora. A mesma verificação de vendas não sincronizadas se aplica antes da remoção.
