## O que isso significa {#what-this-means}

A conta conectada à loja não corresponde ao operador deste caixa.

Cada operador de caixa mantém seus próprios dados no terminal, então trabalhar com outra conta pode registrar pedidos na conta errada. Saia e entre com a conta do próprio operador.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. O PDV encerra a sessão automaticamente para proteger os dados de cada operador de caixa — nenhum dado de pedido é misturado entre contas.
2. Entre novamente com a conta do próprio operador de caixa; trabalhar com outra conta pode registrar pedidos na conta errada.
3. Se os terminais forem compartilhados entre operadores de caixa, inclua a troca de contas na rotina de passagem de turno.
