## O que isso significa {#what-this-means}

O token de login é maior do que este servidor aceita.

O servidor rejeitou o token de login por causa do tamanho: um 400 quando ele é enviado no cabeçalho Authorization ou um 414 quando é enviado na URL. Nenhuma codificação no lado do cliente consegue reduzi-lo — os limites de tamanho de cabeçalho/URL do servidor precisam ser aumentados, ou o token precisa ser menor.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. No Apache, aumente LimitRequestFieldSize (envio pelo cabeçalho) ou LimitRequestLine (envio pela URL) na configuração do vhost.
2. No nginx, aumente large_client_header_buffers.
3. Se houver um proxy ou CDN, o limite pode estar nessa camada — verifique tanto essa camada quanto o servidor.
4. Se não for possível alterar os limites, entre em contato com o suporte para saber sobre a emissão de um token menor para este site.
