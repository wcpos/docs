## O que isso significa {#what-this-means}

Não foi possível carregar as configurações de leitura de códigos de barras, por isso as leituras podem não encontrar os produtos.

O WCPOS continua tentando carregar essas configurações em segundo plano. Se a leitura continuar pouco confiável, recarregue o aplicativo uma vez.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Continue trabalhando — o WCPOS tenta carregar novamente as configurações de código de barras em segundo plano.
2. Se as leituras continuarem sem encontrar nenhum produto, recarregue o aplicativo uma vez.
3. Se o problema persistir após recarregar, a própria solicitação das configurações está falhando — confira a conexão com a loja e procure erros relacionados em Saúde da loja → Logs (peça ajuda a quem administra a loja, se precisar).
