## O que isso significa {#what-this-means}

A reconstrução de um índice de busca falhou, por isso os resultados podem ficar incompletos enquanto o aplicativo tenta inicializá-lo novamente.

Após detectar um problema no índice de busca ([CLIENT141](/error-codes/CLIENT141) ou [CLIENT143](/error-codes/CLIENT143)), o aplicativo tentou reconstruir o índice, mas a própria reconstrução falhou. A busca continua respondendo — pelo índice existente, ocultando os resultados sabidamente incorretos, ou por uma varredura direta dos dados neste dispositivo — mas pode omitir ou ordenar incorretamente os resultados da lista afetada. A próxima busca ou verificação de prontidão tenta inicializar o índice novamente e pode recuperá-lo automaticamente; recarregar o aplicativo é uma opção para recomeçar se os resultados continuarem incorretos.

## Seus dados {#your-data}

Nenhum dado da loja foi alterado. Isso afeta apenas o índice de busca local, que é gerado a partir dos dados já presentes neste dispositivo.

## Solução de problemas {#troubleshoot}

1. Abra a entrada do log — o contexto informa a lista afetada e o erro ocorrido na reconstrução. Se o erro mencionar armazenamento, primeiro libere espaço no dispositivo; na web, evite também janelas privadas ou anônimas.
2. Faça outra busca na lista afetada — o aplicativo tenta inicializar o índice novamente de forma automática.
3. Se ainda faltarem resultados ou eles estiverem na ordem errada, recarregue o aplicativo: na web, recarregue a aba do navegador; no computador e no celular, feche e reabra o aplicativo. Se CLIENT144 for registrado novamente depois disso, exporte as informações de depuração pela tela Logs e entre em contato com o suporte.
