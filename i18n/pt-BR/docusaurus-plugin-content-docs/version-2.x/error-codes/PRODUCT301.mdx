## O que isso significa {#what-this-means}

Uma leitura de código ou busca digitada não encontrou nenhum produto correspondente.

As causas mais comuns são um filtro ativo, um código de barras ausente ou armazenado em outro campo ou uma sincronização inicial que ainda não terminou.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

**No caixa:**

1. Primeiro, limpe os filtros — um filtro de categoria ou estoque restringe todas as buscas sem aviso (um código lido pelo leitor entra na mesma caixa de busca).
2. Busque o produto pelo nome. Se ele aparecer, mas a leitura do código não o encontrou, o código de barras dele na loja não corresponde ao valor lido. Se você digitou a busca, confira a grafia e os espaços extras.
3. Se o produto acabou de ser criado, o índice local ainda pode estar sendo sincronizado — aguarde a conclusão da sincronização inicial e tente novamente.

**Na loja:**

- Se o código de barras estiver ausente, adicione o valor lido no WP Admin, no campo indicado em **Campo de código de barras** (abaixo). Para um item com variações (tamanhos, cores), insira o valor na própria variação — edite o produto e expanda a variação — e não no produto pai.
- Se nenhuma leitura encontrar produtos, a loja pode estar buscando no campo errado. Confira **WP Admin > PDV > Configurações > Geral > Campo de código de barras** — ele deve indicar o campo em que os produtos realmente armazenam os códigos de barras (por exemplo, `_global_unique_id` para GTIN, `_sku` ou `_barcode`).
