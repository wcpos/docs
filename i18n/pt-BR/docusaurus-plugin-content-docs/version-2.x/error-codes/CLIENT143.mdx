## O que isso significa {#what-this-means}

A busca não estava encontrando um produto que deveria ter encontrado.

Nenhuma ação é necessária, a menos que um produto visível continue sem aparecer na busca — nesse caso, recarregue o WCPOS.

Uma verificação automática periódica procurou um registro no índice de busca local usando as palavras do próprio registro, e o índice não o retornou. Isso significa que as buscas podem ter mostrado menos resultados do que os dados realmente armazenados neste dispositivo. O aplicativo pode reconstruir o índice por conta própria, mas apenas uma vez por lista em cada sessão, portanto a reconstrução não é garantida.

## Seus dados {#your-data}

Nenhum dado da loja foi alterado. Isso afeta apenas o índice de busca local, que é gerado a partir dos dados já presentes neste dispositivo — nada se perde quando ele é reconstruído.

## Solução de problemas {#troubleshoot}

1. Nenhuma ação é necessária, a menos que um produto visível continue sem aparecer na busca — as vendas podem continuar normalmente. O aplicativo pode reconstruir o índice por conta própria, mas apenas uma vez por lista em cada sessão. Portanto, se esse código se repetir, vá para a próxima etapa.
2. Se a busca continuar sem encontrar registros que você consegue ver no aplicativo — em uma lista de produtos, clientes, pedidos ou outra lista — recarregue o aplicativo: na web, recarregue a aba do navegador; no computador e no celular, feche e reabra o aplicativo. Isso permite uma nova tentativa de reconstrução na próxima vez que o problema for detectado.
3. Se o código voltar após recarregar, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte — a entrada do log inclui os detalhes necessários para identificar a lista afetada e o registro que o índice não encontrou.
