## O que isso significa {#what-this-means}

Uma alteração neste dispositivo entrou em conflito com uma edição mais recente na sua loja. Nada foi perdido.

Se **Saúde da loja → Banco de dados** listar uma alteração retida para este registro, toque em **Enviar novamente** para manter a versão deste dispositivo, ou em **Usar versão do servidor** para manter a da loja. Caso contrário, não é preciso fazer nada — o conflito já foi resolvido.

## Seus dados {#your-data}

Nada foi perdido. Quando uma alteração é retida, sua loja mantém a própria versão e este dispositivo mantém a alteração até que você escolha qual manter; outras edições desse registro aguardam neste dispositivo até lá. Não limpe os dados deste dispositivo enquanto houver uma alteração retida — a limpeza exclui essa alteração.

## Solução de problemas {#troubleshoot}

1. Abra **Saúde da loja → Banco de dados**. Uma alteração retida aparece em um painel que começa com **"1 alteração foi retida"** (ou **"… alterações foram retidas"**), junto com o registro ao qual pertence.
2. Se não houver mais nenhuma alteração retida para este registro, o conflito já foi resolvido — aqui ou em outra aba — e não é preciso fazer nada. Um conflito de pedido que o WCPOS resolve sozinho, reenviando a versão deste dispositivo, é registrado como [SYNC222](/error-codes/SYNC222).
3. Se houver uma alteração retida, pressione **Abrir registro** (quando disponível) para ver a versão deste dispositivo e compare-a com o mesmo registro no WP Admin (talvez um administrador do site precise fazer isso).
4. Para manter a versão deste dispositivo, toque em **Enviar novamente** — a alteração é reenviada e substitui os valores da loja nos campos que este dispositivo alterou. Para manter a versão da loja, toque em **Usar versão do servidor** (algumas linhas mostram **Descartar alteração do dispositivo**) e confirme — a alteração deste dispositivo é descartada. Outras edições desse registro aguardam até que você escolha.
5. Conflitos frequentes nos mesmos registros geralmente indicam que duas pessoas editam os mesmos dados ao mesmo tempo — por exemplo, o estoque no terminal e no WP Admin. Combinem onde cada tipo de edição será feito.
