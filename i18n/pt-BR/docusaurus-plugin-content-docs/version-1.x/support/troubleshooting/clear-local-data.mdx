O WCPOS armazena uma cópia local dos seus produtos, pedidos e clientes para que o POS funcione rapidamente e também offline. Ocasionalmente, esses dados locais podem ficar fora de sincronia com a sua loja WooCommerce. Limpar todos os dados locais remove o banco de dados local e inicia uma nova sincronização a partir do seu servidor.

:::tip Tente primeiro uma redefinição direcionada (v1.10.0+)
A partir da v1.10.0, **Saúde da loja → Banco de dados** oferece **Limpar e baixar novamente** por coleção — essa opção remove e busca de novo apenas a coleção que está com problema (produtos, por exemplo), sem alterar mais nada nem desconectar você. A confirmação mostra quantos registros serão removidos e confirma que a cópia no servidor não é afetada. É normal que coleções baixadas sob demanda exibam uma contagem baixa logo após uma redefinição e voltem a ser preenchidas conforme o uso — esse é o comportamento previsto, não uma sincronização travada. Veja [Saúde da loja](/1.x/support/store-health#clear-and-redownload).
:::

:::warning
Esta é a opção mais drástica. Limpar os dados locais exclui tudo o que está armazenado no dispositivo e força uma ressincronização completa. Dependendo do tamanho da sua loja, isso pode levar algum tempo. Use essa opção apenas quando as outras — uma [sincronização](/1.x/products/sync) normal ou **Limpar e baixar novamente** por coleção — não tiverem resolvido o problema.

Antes de limpar, verifique o bloco **alterações aguardando envio** em **Saúde da loja → Banco de dados** — limpar os dados locais destrói todas as alterações ainda não enviadas no dispositivo.
:::

## Quando usar {#when-to-use-it}

Você pode precisar limpar os dados locais nas seguintes situações:

- **Problemas de sincronização** — produtos, pedidos ou clientes não estão sendo atualizados corretamente
- **Após uma atualização de plugin** — para garantir compatibilidade com novas estruturas de dados
- **Dados desatualizados** — preços, níveis de estoque ou outras informações parecem estar desatualizados

## O que é limpo {#what-gets-cleared}

| Limpo | Não limpo |
|---------|-------------|
| Banco de dados local de produtos | Dados no servidor |
| Banco de dados local de pedidos | Configurações do WooCommerce |
| Banco de dados local de clientes | |
| Sessão de login | |

Os dados da sua loja WooCommerce não são afetados — apenas a cópia local no seu dispositivo é removida. Uma nova sincronização começa automaticamente após a limpeza.

:::info Diferença entre plataformas
- **Aplicativo desktop:** Você será desconectado e precisará reconectar sua loja.
- **Aplicativo web:** Os dados de login são limpos, mas, como você ainda está conectado ao WP Admin, a sessão é restaurada automaticamente — por isso, você não perceberá a desconexão.
:::

## Como limpar os dados locais {#how-to-clear-local-data}

### Web {#web}

1. Clique no seu **menu de usuário** no canto superior direito para abrir o menu
2. Clique em **Limpar Todos os Dados Locais**
3. O banco de dados local será excluído e uma nova sincronização começará automaticamente

### Desktop {#desktop}

1. Abra o menu do aplicativo **WCPOS** na barra de menus superior
2. Passe o mouse sobre **Avançado**
3. Clique em **Limpar Dados do App**
4. O banco de dados local será excluído e uma nova sincronização começará automaticamente

:::note
Todas as plataformas armazenam os dados no mesmo formato de banco de dados local (armazenamento de arquivos baseado em OPFS a partir da v1.10.0). Ele é totalmente limpo em todas as plataformas, mas o comportamento do login difere — veja a nota sobre a diferença entre plataformas acima.
:::
