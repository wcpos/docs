## Nota do Pedido {#order-note}

<div class="image-container">
  <Image
    alt="Nota do Pedido no POS"

    style={{maxHeight: 500}}

- Abre uma caixa de diálogo para adicionar uma nota para o cliente ao pedido.
- As notas para o cliente ficam visíveis para ele e aparecem por padrão no recibo, na área Minha Conta do cliente e em `WP Admin > WooCommerce > Orders > Order`, abaixo do endereço de entrega.

:::note
As notas de pedidos são visíveis para os clientes.
:::

- Abre um modal para gerenciar metadados adicionais do pedido.
- Os recursos incluem:
  - Alterar a moeda do pedido.
  - Adicionar um ID de transação (por exemplo, de um terminal de pagamento externo).
  - Adicionar metadados personalizados ao pedido.

:::note
Novos recursos serão adicionados a este modal ao longo do tempo, incluindo a integração com outros plugins do WooCommerce.
:::

### O que são Metadados no WooCommerce? {#what-is-meta-data-in-woocommerce}

Os metadados fornecem informações extras sobre os pedidos e podem ser acessados pela API REST do WooCommerce. Desenvolvedores e plugins usam esses dados para ampliar as funcionalidades, como integrar serviços de terceiros.

### Visualização JSON {#json-view}

- Visualize a representação JSON bruta do pedido, útil para depuração ou integração.

## Salvar no Servidor {#save-to-server}

- Permite salvar carrinhos abertos no servidor, para que fiquem armazenados com segurança e disponíveis para uso futuro.
- Cria um pedido no WooCommerce com o status `pos-open`.

### Por que salvar? {#why-save}

Quando um novo pedido é criado no POS, ele existe apenas localmente. 
Salvar o pedido garante que ele seja mantido, mesmo que o banco de dados local seja limpo.

Veja [Pedidos Abertos](/1.x/pos/cart/open-orders) para mais detalhes sobre como gerenciar pedidos salvos.

## Anular {#void}

- Dois cenários:
  - Pedidos não salvos:
    - Se o pedido não foi salvo no servidor, ele será excluído permanentemente do banco de dados local.
  - Pedidos salvos:
    - Se o pedido estiver salvo no servidor, ele será movido para a Lixeira no WooCommerce e excluído do banco de dados local.
- Para recuperar um pedido anulado:
  - Acesse `WP Admin > WooCommerce > Orders > Trash`.

## Finalizar Compra {#checkout}

- Salva o pedido no servidor e inicia o processo de finalização da compra.
- Abre a [tela de finalização de compra](/1.x/pos/checkout) para concluir o pagamento.
