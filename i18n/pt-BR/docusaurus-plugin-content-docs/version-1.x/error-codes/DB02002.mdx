# DB02002: Registro Não Encontrado {#db02002-record-not-found}

## O Que Isso Significa {#what-this-means}

O registro solicitado não existe no banco de dados local. O POS tentou acessar um produto, cliente, pedido ou outro registro que não está armazenado localmente.

## Causas Comuns {#common-causes}

- **Ainda não sincronizado** — Os dados ainda não foram baixados
- **Deletado no servidor** — Registro foi removido no WooCommerce
- **Sincronização não completa** — Sincronização inicial ainda está em andamento
- **Filtro aplicado** — Registro excluído por filtros ativos

## Como Consertar {#how-to-fix}

### 1. Aguarde a Sincronização {#1-wait-for-sync}

Se iniciou recentemente:
- Aguarde a sincronização inicial ser concluída
- Verifique o indicador de progresso da sincronização
- O registro deve aparecer uma vez sincronizado

### 2. Atualizar/Re-sincronizar {#2-refreshre-sync}

Acione uma atualização de dados:
- Use o botão de refrescar/sincronizar (<Icon name="arrow-rotate-right" />) - breve pressão para sincronização
- Evite usar aqui a opção Limpar e Refrescar com **pressionamento longo** — ela esvazia a lista inteira deste dispositivo, inclusive carrinhos abertos que nunca foram salvos; consulte primeiro a etapa 5
- Puxe os últimos dados do servidor
- Aguarde a conclusão

### 3. Verifique o WooCommerce {#3-check-woocommerce}

Verifique se o registro existe no servidor:
- Faça login no WordPress Admin
- Verifique Produtos, Pedidos ou Clientes
- Confirme se o item ainda existe

### 4. Verifique os Filtros {#4-check-filters}

O registro pode estar filtrado:
- Reveja os filtros ativos no POS
- Verifique os filtros de categoria
- Verifique as configurações de visibilidade

### 5. Limpar e Re-sincronizar {#5-clear-and-re-sync}

:::warning Verifique se há trabalho não salvo
Limpar os dados locais ou reinstalar o aplicativo exclui tudo neste dispositivo que ainda não chegou à sua loja — incluindo vendas feitas offline, carrinhos abertos e edições que não foram salvas. Antes de limpar qualquer coisa, abra **Saúde da loja → Banco de dados** e confirme que nada está listado como retido ou como ainda não tendo chegado ao servidor; depois, confira em **Saúde da loja → Logs** se há **0 registros travados** e **0 alterações aguardando envio**. Em seguida, finalize ou anote todos os carrinhos abertos. Se o WCPOS não tiver uma página Saúde da loja, atualize o WCPOS primeiro e verifique novamente. Se houver algo listado ou aguardando, ou se você não puder verificar, não limpe — fale com o responsável pela loja ou entre em contato com o suporte.
:::

Somente se a sincronização continuar travada e depois de fazer a verificação acima:
1. Limpe os dados locais
2. Faça login novamente
3. Complete uma nova sincronização

## Cenários Comuns {#common-scenarios}

- **Produto não exibido:** Verifique se está publicado e visível
- **Cliente não encontrado:** Pode não ter sido sincronizado ainda
- **Pedido ausente:** Pode estar fora do intervalo de datas de sincronização
