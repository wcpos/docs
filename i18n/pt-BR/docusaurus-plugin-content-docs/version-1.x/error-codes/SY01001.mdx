# SY01001: Memória insuficiente {#sy01001-out-of-memory}

## O que isso significa {#what-this-means}

Seu dispositivo está com pouca memória (RAM) e não consegue concluir a operação solicitada. O WCPOS precisa de memória suficiente para funcionar corretamente.

## Causas comuns {#common-causes}

- **Muitos aplicativos abertos** — Outros aplicativos estão usando memória
- **Grande volume de dados** — Muitos produtos/clientes carregados
- **Vazamento de memória** — O aplicativo não libera a memória corretamente
- **RAM insuficiente** — O dispositivo não tem memória suficiente

## Como resolver {#how-to-fix}

### 1. Feche outros aplicativos {#1-close-other-applications}

Libere memória:
- Feche as abas do navegador que não estão em uso
- Feche outros aplicativos
- Feche programas em segundo plano

### 2. Reinicie o WCPOS {#2-restart-the-pos}

Libere a memória do aplicativo:
1. Feche completamente o WCPOS
2. Aguarde alguns segundos
3. Abra o aplicativo novamente

### 3. Reinicie o dispositivo {#3-restart-your-device}

Uma reinicialização completa libera toda a memória:
1. Salve qualquer trabalho em andamento
2. Reinicie o computador/dispositivo
3. Ao iniciar novamente, abra apenas o WCPOS

### 4. Limpe os dados do navegador (versão web) {#4-clear-browser-data-web-version}

Se estiver usando um navegador:
- Limpe o cache do navegador
- Feche e reabra o navegador
- Use menos abas no navegador

### 5. Reduza a carga de dados {#5-reduce-data-load}

Se você tiver um catálogo muito grande:
- Use filtros para carregar menos dados de cada vez
- Considere paginar os resultados
- Limite o escopo da sincronização, se possível

## Requisitos mínimos {#minimum-requirements}

Verifique se seu dispositivo atende aos requisitos mínimos:
- **RAM:** mínimo de 4GB, recomendado 8GB
- **Navegador:** navegador moderno (Chrome, Firefox, Edge)
- **Aplicativo para desktop:** consulte as notas da versão para ver os requisitos

## Problemas recorrentes {#ongoing-issues}

Se a memória acabar com frequência:
- Considere aumentar a RAM do dispositivo
- Use um dispositivo com mais recursos
- Relate o problema se parecer excessivo
