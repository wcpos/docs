## O que isso significa {#what-this-means}

Este dispositivo pediu dados à loja com uma frequência muito maior que o normal.

Não é preciso fazer nada: nada foi perdido. Nada foi desacelerado nem bloqueado: este é apenas um alerta de detecção. Um fluxo contínuo de solicitações geralmente indica um problema no app (uma tela solicitando os mesmos dados repetidamente em um loop), não algo que você fez. Se continuar aparecendo, toque em **Copiar informações de depuração** e envie ao suporte do WCPOS para que o loop seja localizado e corrigido.

## Seus dados {#your-data}

Nada foi perdido: nenhum dado de pedido ou produto foi afetado. Se isso persistir, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Continue trabalhando — este é um alarme apenas de detecção. O WCPOS não retarda, não enfileira nem descarta nenhuma requisição, e nenhum dado de pedido ou produto é afetado.
2. Se o código aparecer uma vez e parar, nenhuma ação é necessária. Se ele se repetir, anote qual tela estava aberta e qual ação você estava realizando quando ele apareceu.
3. Use Copiar informações de depuração enquanto o evento ainda estiver na janela do log e entre em contato com o suporte do WCPOS; a exportação permite que o suporte rastreie o ciclo de solicitações.
