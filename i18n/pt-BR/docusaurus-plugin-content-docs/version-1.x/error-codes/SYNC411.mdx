## O que isso significa {#what-this-means}

Este dispositivo pediu dados à loja com uma frequência muito maior que o normal.

Nada foi retardado nem bloqueado, e nenhum dado de pedido é afetado — este é um alarme apenas de detecção. Excessos contínuos de requisições costumam indicar um problema do aplicativo (uma tela solicitando os mesmos dados em looping), e não algo que você tenha feito. Se este código continuar aparecendo, exporte os diagnósticos e entre em contato com o suporte para que o looping possa ser encontrado e corrigido.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Continue trabalhando — este é um alarme apenas de detecção. O WCPOS não retarda, não enfileira nem descarta nenhuma requisição, e nenhum dado de pedido ou produto é afetado.
2. Se o código aparecer uma vez e parar, nenhuma ação é necessária. Se ele se repetir, anote qual tela estava aberta e qual ação você estava realizando quando ele apareceu.
3. Use Copiar informações de depuração enquanto o evento ainda estiver na janela do log e entre em contato com o suporte do WCPOS; a exportação permite que o suporte rastreie o ciclo de solicitações.
