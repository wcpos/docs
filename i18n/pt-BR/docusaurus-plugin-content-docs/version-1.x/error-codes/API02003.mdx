# API02003: Token Inválido {#api02003-token-invalid}

## O Que Isso Significa {#what-this-means}

O token de autenticação que está sendo usado não é reconhecido pelo servidor. Isso é diferente de um token expirado — este token nunca foi válido ou foi revogado.

## Causas Comuns {#common-causes}

- **Token revogado** — Um administrador revogou a sessão
- **Token corrompido** — Corrupção de dados durante o armazenamento ou transmissão
- **Reinicialização do servidor** — Chaves secretas do servidor mudaram, invalidando todos os tokens
- **Servidor errado** — Token de uma instalação WordPress diferente

## Mapeamento de Erro do Servidor {#server-error-mapping}

Este código de erro é acionado quando o servidor retorna:

| Código do Servidor | Fonte |
|-------------|--------|
| `jwt_auth_invalid_token` | Plugin de Autenticação JWT |

## Como Corrigir {#how-to-fix}

### 1. Faça Login Novamente {#1-log-in-again}

Limpe sua sessão e autentique-se novamente. Se este dispositivo puder conter vendas que ainda não chegaram à sua loja, primeiro faça a verificação indicada no aviso da etapa 2:
1. Desconecte-se completamente
2. Feche e reabra o POS
3. Faça login com suas credenciais

### 2. Limpe os Dados do Aplicativo {#2-clear-application-data}

:::warning Verifique primeiro se há trabalho não salvo
Limpar os dados locais ou reinstalar o aplicativo apaga tudo neste dispositivo que ainda não chegou à sua loja — incluindo vendas feitas offline, carrinhos abertos e edições que não foram salvas. Antes de limpar qualquer coisa, abra **Saúde da loja → Banco de dados** e confira se nada está listado como retido ou como nunca tendo chegado ao servidor; depois, em **Saúde da loja → Registros**, confira se há **0 registros travados** e **0 alterações aguardando envio**; por fim, finalize ou anote cada carrinho aberto. Se o seu WCPOS não tiver a página Saúde da loja, atualize o WCPOS antes de conferir. Se houver algo listado ou aguardando, ou se você não puder verificar, não limpe — peça ajuda ao responsável pela loja ou entre em contato com o suporte.
:::

Somente se sair da sessão não resolver, e apenas depois da verificação acima:
- Limpe o cache/dados do aplicativo POS
- Na web: Limpe os cookies do navegador e o armazenamento local para o site
- No desktop: Verifique as configurações do aplicativo para uma opção de "Limpar Dados"

### 3. Verifique a Configuração do Servidor {#3-check-server-configuration}

Se o problema afetar todos os usuários:
- Verifique se os sais do WordPress foram alterados
- Verifique as configurações do JWT ou do plugin de autenticação
- Revise as mudanças recentes no servidor

### 4. Verifique se Está no Servidor Correto {#4-verify-youre-on-the-correct-server}

Garanta que o POS esteja configurado para se conectar ao site WordPress correto, especialmente se você tiver múltiplas instalações.
