# DB03001: Erro de Sintaxe da Consulta {#db03001-query-syntax-error}

## O Que Isso Significa {#what-this-means}

A consulta ao banco de dados tem erros de sintaxe. Isso geralmente indica um bug na aplicação, em vez de um erro do usuário.

## Causas Comuns {#common-causes}

- **Bug de software** — Um problema na aplicação de POS
- **Incompatibilidade de versão** — Esquema de dados incompatível
- **Dados corrompidos** — Dados contêm caracteres inesperados
- **Problemas de codificação** — Problemas de codificação de caracteres

## Como Resolver {#how-to-fix}

### 1. Atualize a Aplicação {#1-update-the-application}

Certifique-se de que está utilizando a versão mais recente:
- Verifique se há atualizações para o aplicativo de POS
- Atualize o plugin do WordPress WCPOS
- Reinicie após a atualização

### 2. Limpe os Dados da Aplicação {#2-clear-application-data}

:::warning Verifique se há trabalho não salvo
Limpar os dados locais ou reinstalar o aplicativo exclui tudo neste dispositivo que ainda não chegou à sua loja — incluindo vendas feitas offline, carrinhos abertos e edições que não foram salvas. Antes de limpar qualquer coisa, abra **Saúde da loja → Banco de dados** e confirme que nada está listado como retido ou como ainda não tendo chegado ao servidor; depois, confira em **Saúde da loja → Logs** se há **0 registros travados** e **0 alterações aguardando envio**. Em seguida, finalize ou anote todos os carrinhos abertos. Se o WCPOS não tiver uma página Saúde da loja, atualize o WCPOS primeiro e verifique novamente. Se houver algo listado ou aguardando, ou se você não puder verificar, não limpe — fale com o responsável pela loja ou entre em contato com o suporte.
:::

Somente se as outras etapas desta página não ajudarem e depois de fazer a verificação acima, redefina para um estado limpo:
- Limpe os dados/cache locais
- Faça login novamente
- Re-sincronize os dados

### 3. Verifique Caracteres Especiais {#3-check-for-special-characters}

Se o erro ocorrer com dados específicos:
- Verifique se há caracteres incomuns nos nomes dos produtos
- Procure emojis ou símbolos especiais
- Tente com dados mais simples

### 4. Reporte o Bug {#4-report-the-bug}

Se o problema persistir:
1. Anote qual ação causa o erro
2. Capture quaisquer detalhes do erro
3. Reporte no [GitHub](https://github.com/wcpos)

## Geralmente Isso é um Bug {#this-is-usually-a-bug}

Erros de sintaxe de consulta são tipicamente bugs no software, não erros do usuário. Se você encontrar isso:
- Você não está fazendo nada de errado
- A equipe de desenvolvimento precisa saber
- Uma correção será lançada em uma atualização

## Solução Alternativa {#workaround}

Até que uma correção esteja disponível:
- Tente abordagens alternativas para realizar sua tarefa
- Use o admin do WooCommerce para operações afetadas
- Verifique atualizações regularmente
