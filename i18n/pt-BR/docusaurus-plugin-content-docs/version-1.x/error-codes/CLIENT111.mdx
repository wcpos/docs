## O que isso significa {#what-this-means}

A sincronização está demorando mais que o esperado para começar.

Isso costuma se resolver sozinho em até um minuto. Se o aplicativo continuar nesse estado, recarregue-o uma vez antes de qualquer outra coisa.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Aguarde um minuto — a primeira sincronização depois de uma atualização, ou em uma loja grande, realmente demora mais.
2. Se o aplicativo continuar nesse estado, recarregue-o uma vez.
3. Se a inicialização demorar todos os dias, verifique sua conexão com a loja; se estiver tudo certo, peça a quem administra a loja que verifique o tempo de resposta do próprio site.
