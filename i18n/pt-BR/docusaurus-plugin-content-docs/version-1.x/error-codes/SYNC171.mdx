## O que isso significa {#what-this-means}

Não foi possível criar ou remover um banco de dados local neste dispositivo.

Reinicie o WCPOS e tente novamente. Se continuar falhando, o dispositivo pode estar com pouco armazenamento ou o perfil do navegador pode estar restringindo o armazenamento; libere espaço e entre em contato com o suporte se o problema persistir.

## Seus dados {#your-data}

Não foi possível configurar nem limpar o banco de dados local do dispositivo. Este é um problema de armazenamento/configuração, não uma edição não sincronizada — libere espaço e tente novamente; se o problema persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Reinicie o WCPOS e tente a mesma ação novamente — a maioria das falhas de configuração é passageira.
2. Verifique o armazenamento livre do dispositivo; a criação de um banco de dados local falha por completo quando o disco ou a cota de armazenamento do navegador está cheio.
3. Na web, verifique se o navegador permite armazenamento persistente para o site — janelas privadas e configurações que bloqueiam todos os dados não permitem.
4. Se continuar falhando, exporte as informações de depuração e entre em contato com o suporte.
