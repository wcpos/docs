## O que isso significa {#what-this-means}

O WCPOS não conseguiu configurar nem remover o armazenamento deste dispositivo.

Libere espaço de armazenamento no dispositivo e reinicie o WCPOS. Na web, o navegador também pode estar restringindo o armazenamento do site — isso acontece em janelas privadas. Se continuar falhando, entre em contato com o suporte.

## Seus dados {#your-data}

Este é um problema de armazenamento, não uma edição recusada. Se aconteceu enquanto os dados deste dispositivo estavam sendo limpos, parte deles talvez já tenha sido excluída, incluindo alterações ainda não enviadas — verifique se suas vendas e alterações recentes aparecem na loja. Se isso continuar acontecendo, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Verifique o espaço livre no dispositivo e libere um pouco removendo outros arquivos ou apps: a configuração do armazenamento falha completamente quando o disco ou a cota de armazenamento do navegador está cheia. Não use a opção "Limpar dados de navegação" do navegador para liberar espaço: ela também exclui as vendas não enviadas do WCPOS.
2. Reinicie o WCPOS e tente executar a mesma ação novamente.
3. Na web, verifique se o navegador permite armazenamento persistente para o site — janelas privadas e configurações que bloqueiam todos os dados não permitem.
4. Se continuar falhando, use **Copiar informações de depuração** na aba **Logs** e entre em contato com o suporte.
