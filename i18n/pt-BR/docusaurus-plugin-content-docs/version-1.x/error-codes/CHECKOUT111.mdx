## O que isso significa {#what-this-means}

Não foi possível aplicar esta alteração ao carrinho, que permanece inalterado.

O item, a taxa, a linha de frete ou o cupom não foi adicionado, e nada foi removido. Tente a ação novamente.

## Seus dados {#your-data}

O pedido permanece seguro e inalterado.

## Solução de problemas {#troubleshoot}

1. Tente adicionar novamente o item, a taxa, a linha de entrega ou o cupom — o carrinho em si está inalterado.
2. Se o mesmo item continuar falhando, teste uma vez com outro produto: um único item falhando aponta para aquele registro; tudo falhando aponta para o dispositivo.
3. Se continuar falhando, reinicie o WCPOS; exporte as informações de depuração e entre em contato com o suporte se o problema persistir.
