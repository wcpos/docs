## O que isso significa {#what-this-means}

O atualizador não está autorizado a baixar atualizações do WCPOS Pro.

Autorize novamente o atualizador para esta loja e verifique as atualizações outra vez.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure a pessoa responsável pelo seu site WordPress.

## Solução de problemas {#troubleshoot}

1. Digite novamente ou reative a chave de licença nas configurações do POS para que o atualizador possa se autenticar.
2. Verifique as atualizações outra vez em WP Admin → Painel → Atualizações.
3. Se a autorização continuar falhando, o site pode estar bloqueando requisições de saída para o servidor de atualizações — pergunte à hospedagem se o HTTPS de saída está restrito.
