## O que isso significa {#what-this-means}

A conta da loja conectada não corresponde ao operador deste caixa.

Cada operador mantém os próprios dados de caixa, portanto trabalhar com outra conta pode arquivar pedidos de forma incorreta. Saia e entre com a conta do próprio operador.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. O POS encerra a sessão por conta própria para proteger os dados de cada operador — nenhum dado de pedido é misturado entre contas.
2. Entre novamente com a conta do próprio operador; trabalhar com outra conta pode arquivar pedidos de forma incorreta.
3. Se os caixas são compartilhados entre operadores, inclua a troca de conta na rotina de passagem de turno.
