## O que isso significa {#what-this-means}

A API REST da loja não respondeu em nenhum formato de endereço que este aplicativo pode usar.

O aplicativo tentou a API REST da loja em seu endereço normal (/wp-json/...) e no endereço de fallback embutido do WordPress (/?rest_route=...), e nenhum respondeu. O próprio site da loja pode estar no ar — trata-se especificamente da API REST estar inacessível, geralmente por um plugin de segurança que a oculta ou uma regra de firewall que a bloqueia.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

**Na loja** — para o administrador do site: se um plugin de segurança oculta ou renomeia `/wp-json/` (por exemplo, WP Hide), permita também o formato embutido `/?rest_route=` do WordPress — o aplicativo recorre a ele automaticamente.

**No host / servidor:**

1. Verifique as regras de firewall (WAF) em busca de qualquer coisa que corresponda a `wp-json` ou `rest_route` e libere a própria API REST da loja.
2. Se o servidor está atrás de uma página de manutenção ou desafio de bots, as requisições REST podem ser respondidas com uma página HTML — desative o desafio para a API REST.

**Para testar (qualquer pessoa):** `https://your-store.com/?rest_route=/` deve retornar JSON, e não uma página 403 ou a página inicial do site.
