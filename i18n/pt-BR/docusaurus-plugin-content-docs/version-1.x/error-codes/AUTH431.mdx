## O que isso significa {#what-this-means}

A API REST da loja não respondeu em nenhum formato de endereço que este aplicativo possa usar.

O aplicativo tentou acessar a API REST da loja em seu endereço normal (/wp-json/...) e no endereço alternativo integrado do WordPress (/?rest_route=...), mas nenhum deles respondeu. O site da loja pode estar funcionando — o problema é especificamente a inacessibilidade da API REST, geralmente porque um plugin de segurança a oculta ou porque uma regra de firewall a bloqueia.

## O que fazer {#what-to-do}

Exporte os diagnósticos e entre em contato com o suporte. Tente novamente após fazer a alteração acima; tentar novamente sem ela falhará da mesma forma.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Se um plugin de segurança ocultar ou renomear /wp-json/ (por exemplo, WP Hide), permita também o formato integrado do WordPress /?rest_route= — o aplicativo recorre a ele automaticamente.
2. Verifique as regras do firewall (WAF) para qualquer item que corresponda a wp-json ou rest_route e permita o acesso à própria API REST da loja.
3. Teste em um navegador: https://your-store.com/?rest_route=/ deve retornar JSON, não uma página 403 nem a página inicial do site.
4. Se o servidor estiver protegido por uma página de manutenção ou verificação de bots, as solicitações REST poderão receber uma página HTML como resposta — desative a verificação para a API REST.

## Onde verificar {#where-to-look}

Quando o WCPOS consegue salvar esse erro, ele é registrado no dispositivo em que ocorreu. Abra **Integridade da loja → Registros** (o ícone de pulsação cardíaca na parte inferior do painel de navegação), localize a entrada marcada com esse código e expanda-a: a linha expandida mostra o motivo em linguagem simples e o contexto capturado no momento da falha. Para uma solicitação da loja, esse contexto pode incluir o próprio código de erro do servidor (`serverCode`), o `status` HTTP ou o `endpoint`; os campos exibidos dependem de onde a falha ocorreu. Ao relatar um problema, use **Copiar informações de depuração** na parte superior da tela Registros (**Compartilhar informações de depuração** em telefones e tablets) em vez de capturas de tela: isso reúne a versão do aplicativo, o estado da conexão e os erros mais recentes. Os registros são mantidos por no máximo 30 dias; portanto, colete-os enquanto o problema ainda é recente. Também copie qualquer erro do console do navegador exibido antes de o POS conseguir gravar sua própria entrada de registro.
