## O que isso significa {#what-this-means}

Outro plugin de autenticação está impedindo a conexão do WCPOS.

Peça ao administrador do site que resolva o conflito com o plugin indicado antes de entrar novamente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure a pessoa responsável pelo seu site WordPress.

## Solução de problemas {#troubleshoot}

**Na loja** — para o administrador do site:

1. O erro identifica o plugin em conflito. Revise as configurações desse plugin — a maioria dos plugins de autenticação permite excluir as rotas REST do WCPOS, sem precisar desativá-lo por completo.
2. Se não estiver claro qual plugin está em conflito, teste em uma cópia de homologação desativando os plugins de segurança e de login um a um.

**No caixa** — para o operador de caixa: depois da alteração, entre novamente.
