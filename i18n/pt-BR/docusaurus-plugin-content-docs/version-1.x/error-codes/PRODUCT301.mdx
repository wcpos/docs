## O que isso significa {#what-this-means}

Uma leitura ou pesquisa digitada não encontrou nenhum produto correspondente.

As causas mais comuns são um filtro ativo, um código de barras ausente ou armazenado em outro campo, ou uma primeira sincronização ainda não concluída.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

**No caixa:**

1. Primeiro, limpe os filtros — um filtro de categoria ou estoque restringe silenciosamente todas as pesquisas (um código lido é inserido na mesma caixa de pesquisa).
2. Pesquise o produto pelo nome. Se ele aparecer, mas a leitura não o encontrar, o código de barras cadastrado na loja não corresponde ao valor lido. Se você digitou a pesquisa, confira a ortografia e se há espaços extras.
3. Se o produto for novo, o índice local talvez ainda esteja sendo sincronizado — aguarde a conclusão da primeira sincronização e tente novamente.

**Na loja:**

- Se o código de barras estiver ausente, adicione o valor lido ao campo de código de barras do produto no WP Admin.
- Se nenhuma leitura encontrar o produto, o WCPOS talvez esteja lendo o campo errado — confira em qual campo sua loja armazena os códigos de barras nas configurações de código de barras do WCPOS.
