## O que isso significa {#what-this-means}

A impressão automática não começou para este recibo.

Verifique a impressora selecionada, o modelo e a conexão e, em seguida, use Imprimir agora para imprimir o recibo manualmente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Use Imprimir agora para imprimir o recibo manualmente — a venda não é afetada.
2. Verifique as configurações de impressão: a impressora correta está selecionada e um modelo de recibo está escolhido.
3. Se a impressão automática falhar em todas as vendas, observe se a impressão manual funciona — funcionar no modo manual e falhar no automático é um problema de configuração; falhar nos dois é um problema da impressora.
