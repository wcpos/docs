## O que isso significa {#what-this-means}

Não foi possível carregar as configurações de leitura de código de barras, portanto as leituras podem não corresponder aos produtos.

O POS continua tentando carregar essas configurações em segundo plano. Se a leitura continuar instável, recarregue o aplicativo uma vez.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Continue trabalhando — o POS tenta novamente carregar as configurações de código de barras em segundo plano.
2. Se as leituras continuarem sem corresponder a nada, recarregue o aplicativo uma vez.
3. Se o problema persistir após recarregar, a própria requisição das configurações está falhando — confira a conexão com a loja e procure erros correspondentes em Saúde da loja → Logs (peça ajuda à pessoa que administra a loja, se necessário).
