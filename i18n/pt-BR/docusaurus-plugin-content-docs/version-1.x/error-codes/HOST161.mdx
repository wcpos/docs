## O que isso significa {#what-this-means}

O host está limitando a taxa de requisições dos caixas desta loja.

O servidor continua respondendo 429 (requisições em excesso) mesmo que o aplicativo já esteja reduzindo o ritmo e respeitando os atrasos Retry-After indicados pelo servidor. Vários caixas em uma mesma conexão de internet compartilham um único endereço, então os limites de taxa por origem os tratam como um único cliente muito ocupado. A sincronização continua automaticamente, mas ficará atrasada até que o limite seja aumentado.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. Peça ao host para aumentar ou isentar o limite de taxa da API REST para o próprio tráfego da loja — informe o IP estático da loja, se ela tiver um.
2. Serviços de segurança que contam respostas de erro repetidas (429) para um bloqueio (por exemplo, o IDS da Sucuri) podem precisar que a API da loja seja excluída desse contador.
3. Se vários caixas compartilham uma conexão, mencione isso ao host: um IP aqui é uma loja inteira, não um único usuário.
