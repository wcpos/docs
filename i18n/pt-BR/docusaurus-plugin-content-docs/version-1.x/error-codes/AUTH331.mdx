## O que isso significa {#what-this-means}

O plugin WCPOS desta loja é antigo demais para esta versão do aplicativo.

O aplicativo foi atualizado, mas o plugin WCPOS na loja não, e as duas versões não funcionam mais em conjunto. Peça a quem gerencia o site que atualize o plugin WCPOS no WP Admin e depois conecte novamente. Nada precisa mudar no caixa.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se o problema persistir, procure a pessoa que gerencia seu site WordPress.

## Solução de problemas {#troubleshoot}

**Na loja** — para quem gerencia o site WordPress:

1. WP Admin → Plugins → atualize o WCPOS para a versão mais recente. Se o WCPOS Pro estiver instalado, atualize-o para uma versão correspondente ao mesmo tempo.
2. Se nenhuma atualização for oferecida, verifique WP Admin → Painel → Atualizações; no caso do Pro, um atualizador não autorizado bloqueia as atualizações (consulte [LICENSE301](./LICENSE301)) — resolva isso primeiro.

**No caixa** — para o operador de caixa: assim que a loja tiver sido atualizada, reconecte. Você não precisa digitar o endereço da loja novamente.

**Se a loja ainda não puder ser atualizada:** entre em contato com o suporte — o caixa precisa de uma versão do aplicativo que corresponda ao plugin, e o suporte pode indicar qual é. Eles pedirão a versão do aplicativo (no caixa) e a versão atual do WCPOS da loja (no WP Admin).
