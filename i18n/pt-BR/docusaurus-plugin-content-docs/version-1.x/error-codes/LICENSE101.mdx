## O que isso significa {#what-this-means}

Sua licença do WCPOS Pro não está ativa para esta loja ou dispositivo.

Verifique o status local, o do servidor de licenciamento e o do atualizador e, em seguida, ative a licença para a loja indicada.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

**Na loja** — para o administrador do site ou titular da licença:

1. Verifique o status da licença nas configurações do POS no WP Admin — ele deve aparecer como ativo para a URL exata desta loja.
2. Uma mudança na URL do site (de http para https, incluir ou remover www, uma troca de domínio, uma cópia de homologação) desativa a licença para o novo endereço — reative-a para o endereço atual.
3. Se a licença aparecer como ativa, mas o WCPOS ainda indicar o contrário, desative-a e ative-a novamente uma vez.
4. Continua bloqueada? Exporte as informações de depuração e entre em contato com o suporte informando a referência da sua licença.

**No caixa:** depois que a licença for reativada, recarregue para aplicar a alteração.
