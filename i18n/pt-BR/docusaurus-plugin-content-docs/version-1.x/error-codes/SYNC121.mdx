## O que isso significa {#what-this-means}

Não é possível acessar sua loja no momento, portanto as alterações permanecerão neste dispositivo.

Verifique a conexão e continue trabalhando off-line; a sincronização será repetida automaticamente quando a loja estiver acessível.

## Seus dados {#your-data}

A alteração está salva neste dispositivo, mas não chegou à sua loja.

## Solução de problemas {#troubleshoot}

1. Continue vendendo — as vendas são salvas neste dispositivo e a sincronização é retomada automaticamente assim que a loja responder.
2. Verifique se o próprio caixa está on-line: algum outro site consegue carregar a partir deste dispositivo?
3. Abra o site da sua loja em uma aba do navegador no mesmo dispositivo; se ele também não carregar, quem está fora do ar é o site ou a hospedagem, não o POS.
4. **Para quem administra a rede deste dispositivo:** se o site carregar, mas o WCPOS continuar offline, algo entre os dois está bloqueando as requisições da API — uma VPN, um firewall, um bloqueador de anúncios ou um plugin de segurança. As ferramentas de desenvolvedor do navegador (aba Rede) — ou **Avançado → Alternar ferramentas de desenvolvedor** no aplicativo para desktop — mostram qual requisição falha.
