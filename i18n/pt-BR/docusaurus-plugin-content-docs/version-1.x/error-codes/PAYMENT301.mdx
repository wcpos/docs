## O que isso significa {#what-this-means}

O gateway de pagamento selecionado está indisponível para esta loja.

Peça ao administrador do site que verifique se o gateway é compatível, está ativado e está configurado corretamente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure a pessoa responsável pelo seu site WordPress.

## Solução de problemas {#troubleshoot}

**No caixa:** enquanto isso, conclua a venda com outro método, como dinheiro.

**Na loja** — para o administrador do site:

1. Verifique o gateway de pagamento em WooCommerce → Configurações → Pagamentos: ele precisa estar instalado, ativado e habilitado para uso no WCPOS nas configurações do WCPOS.
2. Se o gateway funcionava ontem, verifique se ele ou o WooCommerce foi atualizado — WooCommerce → Status → Logs pode registrar erros de inicialização do gateway.
