# Códigos de Erro

Quando o WCPOS encontra um problema, ele exibe um código de erro que ajuda a identificar a causa. A partir da **v1.10.0**, os códigos seguem o formato **domínio + três dígitos** — por exemplo, `SYNC131` ou `AUTH311`. O domínio indica a área do POS; o número identifica a condição específica. Cada código tem sua própria página com o que ele significa, o que fazer e o que isso representa para os seus dados.

No POS, os códigos de erro aparecem em **Saúde da loja → Logs**: expanda uma linha e use o link **Ajuda** para ir direto à página do código aqui.

## Domínios de Erro (v1.10.0+) {#error-domains}

| Domínio | Área | Exemplos |
|--------|------|----------|
| `AUTH` | Login, sessões e tokens | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | Conclusão de pedidos no caixa | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | O próprio aplicativo do POS e o armazenamento local | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `LICENSE` | Ativação e validação da licença Pro | [LICENSE101](./LICENSE101) |
| `PAYMENT` | Gateways de pagamento e terminais | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | Impressão de recibos | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | Dados de produtos e operações de catálogo | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `SYNC` | Sincronização entre o POS e a sua loja | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

Use a barra lateral para navegar por todos os códigos de um domínio, ou pesquise o código diretamente.

Códigos terminados em `999` são o código genérico do domínio para condições que ainda não têm um código específico.

## Códigos Legados (anteriores à v1.10.0) {#legacy-codes}

As versões anteriores à v1.10.0 usavam um esquema diferente: `[DOMÍNIO][CATEGORIA][CÓDIGO_ESPECÍFICO]`, por exemplo, `API04001` = API (domínio) + 04 (erros de resposta) + 001 (formato de resposta inválido). Se você estiver usando uma versão mais antiga, ou lendo uma entrada de log antiga ou um tópico de suporte antigo, estas páginas continuam válidas:

| Domínio | Total de Códigos | Abrange |
|--------|-------------|---------------|
| [API](./api) | 39 códigos | Comunicação com o servidor, autenticação, problemas de plugin |
| [DB](./db) | 9 códigos | Armazenamento e recuperação de dados locais |
| [PY](./py) | 6 códigos | Processamento de pagamentos |
| [SY](./sy) | 5 códigos | Recursos e configuração do dispositivo |

Um cliente v1.10.0+ nunca emite esses códigos — se você vir um em um POS atualizado, ele vem de uma entrada de log antiga retida ou de uma mensagem do lado do servidor.
