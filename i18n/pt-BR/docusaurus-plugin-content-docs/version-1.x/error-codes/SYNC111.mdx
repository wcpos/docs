## O que isso significa {#what-this-means}

Os dados locais da loja estão danificados e precisam de reparo antes que a sincronização possa continuar.

Execute o reparo direcionado para os dados afetados e só redefina esses dados locais se o problema voltar.

## Seus dados {#your-data}

Os dados neste dispositivo podem estar em risco — não limpe os dados locais. Se isso persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Abra Saúde da loja → Banco de dados e execute o reparo direcionado para os dados afetados; uma redefinição completa descarta mais do que o reparo.
2. Repita a ação que falhou e observe em Saúde da loja → Logs se este código se repete.
3. Se os mesmos dados forem sinalizados de novo, redefina apenas esses dados locais para que sejam baixados novamente da sua loja — mas só depois de anotar quaisquer alterações não enviadas.
4. Uma corrupção que continua voltando indica falha no armazenamento do dispositivo: exporte as informações de depuração e entre em contato com o suporte.
