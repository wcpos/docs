## O que isso significa {#what-this-means}

O WCPOS ficou sem memória e não conseguiu concluir a operação.

Reinicie o WCPOS e tente uma vez; exporte os diagnósticos se o dispositivo ficar sem memória novamente.

## Seus dados {#your-data}

Não foi possível confirmar o resultado — se você estava salvando algo quando a memória se esgotou, verifique se a operação foi concluída antes de tentar novamente.

## Solução de problemas {#troubleshoot}

1. Reinicie o WCPOS. Se você estava salvando algo quando a memória se esgotou, verifique se a operação foi concluída antes de tentar novamente — se não foi, tente mais uma vez.
2. Feche outros aplicativos ou abas do navegador — o POS divide a memória do dispositivo com tudo o mais que estiver em execução nele.
3. Se uma ação específica sempre esgotar a memória, anote qual foi e entre em contato com o suporte com as informações de depuração.
4. Se isso acontecer diariamente no mesmo dispositivo, ele pode ser pequeno demais para o catálogo — relate o caso para que o suporte possa confirmar.
