## O que isso significa {#what-this-means}

Esta loja agora exige uma versão mais recente do aplicativo POS.

O plugin WCPOS da loja passou a usar um protocolo de sincronização mais recente do que o compatível com esta versão do aplicativo, e a loja pausa deliberadamente a sincronização até que o aplicativo seja atualizado. Trata-se de uma proteção, não de uma falha: ela impede que um aplicativo desatualizado leia ou grave dados da loja de forma incorreta.

## Seus dados {#your-data}

Nada no caixa é perdido. As vendas e edições que aguardam envio permanecem seguras no dispositivo e serão sincronizadas quando um aplicativo atualizado se conectar à loja. Se ainda não houver um aplicativo mais recente (consulte as duas últimas etapas abaixo), elas permanecerão na fila até que haja um.

## Solução de problemas {#troubleshoot}

1. No aplicativo web, recarregue a aba do navegador — o aplicativo web obtém a nova versão ao recarregar. Se a tela reaparecer, faça uma recarga forçada (mantenha **Shift** pressionado durante a recarga).
2. No desktop, instale a atualização pendente e reabra o aplicativo — a verificação é executada quando o aplicativo se reconecta. Se nenhuma atualização for oferecida, baixe a versão mais recente na página de [Instalação](/getting-started/installation).
3. No iPhone, iPad ou Android, atualize o WCPOS pelo canal de onde ele foi instalado — TestFlight no iOS, programa de testes do Play no Android; ambos estão vinculados na página de [Instalação](/getting-started/installation) — e reabra o aplicativo.
4. **Administrador do site:** se uma versão mais recente do app ainda não estiver disponível, o plugin WCPOS da loja foi atualizado antes do lançamento da versão correspondente do app. Restaurar a versão anterior do plugin WCPOS na loja retoma a sincronização até que o app mais recente seja lançado.
5. Se não houver uma atualização do app nem uma reversão do plugin disponível, entre em contato com o suporte da WCPOS.
