## O que isso significa {#what-this-means}

O WooCommerce não está ativo neste site, portanto o WCPOS não consegue se conectar.

O WCPOS requer o plugin WooCommerce. Peça ao administrador do site que instale ou reative o WooCommerce e conecte novamente.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure a pessoa responsável pelo seu site WordPress.

## Solução de problemas {#troubleshoot}

1. Peça ao administrador do site que verifique WP Admin → Plugins: o WooCommerce precisa estar instalado e ativo para o WCPOS se conectar.
2. Se o WooCommerce foi desativado por uma atualização malsucedida, reative-o e observe se aparece um aviso de erro — WooCommerce → Status → Logs registra o motivo da falha.
3. Assim que o WooCommerce estiver ativo novamente, reconecte pelo caixa.
