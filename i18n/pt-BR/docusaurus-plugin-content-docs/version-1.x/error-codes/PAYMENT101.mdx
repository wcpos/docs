## O que isso significa {#what-this-means}

O pagamento foi concluído, mas o WCPOS não conseguiu atualizar o status depois.

O pagamento foi concluído — não cobre novamente. Reabra o pedido para atualizar o status; se ainda parecer desatualizado, atualize-o conforme descrito abaixo.

## Seus dados {#your-data}

O pagamento foi recebido — não cobre novamente. Apenas o status exibido na tela está desatualizado.

## Solução de problemas {#troubleshoot}

1. Não cobre o cliente novamente. A página de pagamento da loja confirmou o pagamento (se você viu a notificação **Payment completed for order #…**, foi essa a confirmação), e apenas a atualização seguinte no caixa falhou.
2. Reabra o pedido para atualizar o status e continue com a próxima venda.
3. Se o pedido pago ainda aparecer como pedido aberto no carrinho, atualize a cópia do caixa: abra **Saúde da loja → Banco de dados**, abra o menu **⋮** na linha **Pedidos** e escolha **Verificar alterações agora**. Quando o status de pagamento chegar, o pedido sairá do carrinho. No WCPOS Pro, você também pode atualizar apenas esse pedido: em **Pedidos**, abra o menu **⋮** do pedido e escolha **Sincronizar**.
4. Se ainda aparecer como aberto, recarregue o aplicativo (recarregue a aba do navegador na versão web; feche e reabra o aplicativo no computador ou dispositivo móvel). Ao iniciar, o caixa conclui qualquer venda cujo pagamento tenha registrado.
5. **Administrador do site:** para confirmar, abra o pedido em **WooCommerce → Pedidos** — ele aparecerá como pago.
