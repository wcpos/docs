## O que isso significa {#what-this-means}

O pagamento foi concluído, mas o WCPOS não conseguiu atualizar o status depois.

O pagamento foi concluído e não deve ser cobrado novamente; nenhuma ação é necessária, a menos que o status exibido continue desatualizado.

## Seus dados {#your-data}

O pagamento foi realizado — o dinheiro foi transferido. Não cobre o cliente novamente; apenas o status exibido na tela está desatualizado.

## Solução de problemas {#troubleshoot}

1. Nenhuma ação é necessária — o pagamento foi concluído; apenas a atualização de status posterior falhou.
2. Não cobre o cliente novamente.
3. Se o status do pedido parecer desatualizado no caixa, reabra ou sincronize o pedido; a loja já tem o status correto.
