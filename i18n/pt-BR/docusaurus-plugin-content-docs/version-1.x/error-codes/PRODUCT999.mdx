## O que isso significa {#what-this-means}

O carregamento ou a atualização de produtos encontrou um problema inesperado.

Tente novamente. Se os dados do produto ainda parecerem errados depois disso, exporte os diagnósticos e entre em contato com o suporte.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Tente novamente — a maioria dos problemas pontuais de carregamento de produtos se resolve em uma nova tentativa.
2. Se os dados do produto ainda parecerem errados, expanda a entrada de log em busca do código do evento e do contexto; este código genérico significa que a causa ainda não tem um código dedicado.
3. Exporte as informações de depuração e entre em contato com o suporte se o problema voltar a ocorrer.
