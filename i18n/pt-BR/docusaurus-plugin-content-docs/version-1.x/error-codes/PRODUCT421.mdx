## O que isso significa {#what-this-means}

Não foi possível ler os dados de preço das variações deste produto, portanto os preços exibidos podem estar errados ou ausentes.

Salve o produto novamente no WooCommerce para reconstruir os dados de preço dele ou entre em contato com o suporte se isso aparecer em muitos produtos.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure o administrador da sua loja.

## Solução de problemas {#troubleshoot}

**No caixa:** confira o preço antes de vender — se ele parecer incorreto ou estiver ausente, não venda por esse preço até que seja corrigido na loja.

**Na loja (WP Admin):**

1. Abra o produto e salve-o novamente — isso recria os dados de preço que o WCPOS não conseguiu ler.
2. Confira se cada variação tem um preço definido; uma variação sem preço gera faixas de preço ilegíveis.
3. Se muitos produtos apresentarem este código de uma vez, provavelmente um plugin de preços está gravando os dados de preço em um formato que o POS não consegue ler — anote qual plugin gerencia os preços e entre em contato com o suporte.
