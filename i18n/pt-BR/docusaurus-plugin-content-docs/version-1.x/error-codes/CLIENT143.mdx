## O que isso significa {#what-this-means}

A pesquisa não encontrou um produto que deveria ter encontrado.

Não é necessário fazer nada, a menos que um produto visível ainda não apareça na pesquisa — nesse caso, recarregue o WCPOS.

Uma verificação periódica pediu ao índice de pesquisa local um registro usando as próprias palavras desse registro, mas o índice não o retornou. Isso significa que as pesquisas podem ter mostrado menos resultados do que os realmente disponíveis neste dispositivo. O aplicativo pode reconstruir o índice automaticamente, mas apenas uma vez por lista em cada sessão, então a reconstrução não é garantida.

## Seus dados {#your-data}

Nenhum dado da loja foi alterado. Isso se refere apenas ao índice de pesquisa local, que é derivado dos dados já presentes neste dispositivo — nada é perdido quando ele é reconstruído.

## Solução de problemas {#troubleshoot}

1. Não é necessário fazer nada, a menos que um produto visível ainda não apareça na pesquisa — as vendas podem continuar normalmente. O aplicativo pode reconstruir o índice automaticamente, mas apenas uma vez por lista em cada sessão; se esse código se repetir, prossiga para a próxima etapa.
2. Se a pesquisa ainda não encontrar registros visíveis no aplicativo — um produto, cliente, pedido ou outra lista — recarregue o aplicativo: na web, recarregue a aba do navegador; no desktop e em dispositivos móveis, feche e reabra o aplicativo. Isso permite uma nova tentativa de reconstrução na próxima vez que o problema for detectado.
3. Se o código voltar após recarregar, use **Copiar informações de depuração** na guia **Registros** e entre em contato com o suporte — o registro contém os detalhes necessários para identificar a lista afetada e o item que o índice não encontrou.
