## O que isso significa {#what-this-means}

A pesquisa não encontrou um produto que deveria ter encontrado.

Não é preciso fazer nada, a menos que um produto visível continue sem aparecer na pesquisa — nesse caso, recarregue o WCPOS.

Uma verificação automática periódica consultou o índice de pesquisa local por um registro usando as próprias palavras desse registro, mas o índice não o retornou. Isso significa que as pesquisas podem ter exibido menos resultados do que os dados realmente armazenados neste dispositivo. O aplicativo pode reconstruir o índice automaticamente, mas apenas uma vez por lista em cada sessão; portanto, a reconstrução não é garantida.

## Seus dados {#your-data}

Nenhum dado da loja foi alterado. Isso se refere apenas ao índice de pesquisa local, que é derivado dos dados já presentes neste dispositivo — nada é perdido quando ele é reconstruído.

## Solução de problemas {#troubleshoot}

1. Não é preciso fazer nada, a menos que um produto visível continue sem aparecer na pesquisa — as vendas podem continuar normalmente. O aplicativo pode reconstruir o índice automaticamente, mas apenas uma vez por lista em cada sessão; portanto, se esse código aparecer novamente, siga para a próxima etapa.
2. Se a pesquisa ainda não encontrar registros visíveis no aplicativo — um produto, cliente, pedido ou outra lista — recarregue o aplicativo: na web, recarregue a aba do navegador; no desktop e em dispositivos móveis, feche e reabra o aplicativo. Isso permite uma nova tentativa de reconstrução na próxima vez que o problema for detectado.
3. Se o código aparecer novamente após recarregar, use **Copiar informações de depuração** na aba **Registros** e entre em contato com o suporte — o registro de log inclui os detalhes necessários para identificar a lista afetada e o registro que não foi encontrado pelo índice.
