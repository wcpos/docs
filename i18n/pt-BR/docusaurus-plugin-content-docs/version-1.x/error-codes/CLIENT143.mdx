## O que isso significa {#what-this-means}

O índice de pesquisa não conseguiu encontrar um produto que deveria estar no índice; o aplicativo tenta reconstruir automaticamente o índice de pesquisa.

Uma verificação periódica solicitou ao índice de pesquisa local um registro usando as próprias palavras desse registro, mas o índice não o retornou. Isso significa que as pesquisas podem ter exibido menos resultados do que os que este dispositivo realmente contém. O aplicativo tenta reconstruir automaticamente o índice uma vez por lista em cada sessão para corrigir isso.

## Seus dados {#your-data}

Nenhum dado da loja foi alterado. Isso se refere apenas ao índice de pesquisa local, que é derivado dos dados já presentes neste dispositivo — nada é perdido quando ele é reconstruído.

## Solução de problemas {#troubleshoot}

1. Normalmente, nenhuma ação é necessária e as vendas podem continuar normalmente: o aplicativo tenta reconstruir o índice automaticamente, e as pesquisas voltam ao normal quando isso termina. Apenas uma reconstrução é tentada por lista em cada sessão; portanto, se este código se repetir, prossiga para a próxima etapa.
2. Se a pesquisa ainda não encontrar registros visíveis no aplicativo — um produto, cliente, pedido ou outra lista — recarregue o aplicativo: na web, recarregue a aba do navegador; no desktop e em dispositivos móveis, feche e reabra o aplicativo. Isso permite uma nova tentativa de reconstrução na próxima vez que o problema for detectado.
3. Se o código retornar após recarregar o aplicativo, exporte as informações de depuração e entre em contato com o suporte — a entrada de log inclui os detalhes necessários para que o suporte identifique a lista afetada e o registro que o índice não encontrou.
