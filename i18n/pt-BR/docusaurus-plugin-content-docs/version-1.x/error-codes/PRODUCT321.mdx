## O que isso significa {#what-this-means}

Mais de um produto corresponde a este código de barras.

O WCPOS não consegue escolher entre eles com segurança, portanto nada foi adicionado. Procure o produto pelo nome e dê a cada produto um código de barras exclusivo na loja para resolver o conflito.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure o administrador da sua loja.

## Solução de problemas {#troubleshoot}

**No caixa:** pesquise o produto pelo nome para concluir esta venda — a leitura não adicionou nada porque o código de barras corresponde a mais de um produto.

A entrada de log registra o código escaneado e quantos produtos corresponderam; buscar o valor do código de barras no POS mostra quais são eles.

**Na loja (WP Admin):** atribua um código de barras exclusivo a cada um desses produtos e leia novamente para confirmar que resta apenas uma correspondência.
