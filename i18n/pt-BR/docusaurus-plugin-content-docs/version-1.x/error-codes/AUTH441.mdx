## O que isso significa {#what-this-means}

O token de login é maior do que este servidor aceita.

O servidor rejeitou o token de login por tamanho: um 400 quando ele viaja no cabeçalho Authorization, ou um 414 quando viaja na URL. Nenhuma codificação do lado do cliente pode reduzi-lo — os limites de tamanho de cabeçalho/URL do servidor precisam ser aumentados, ou o token precisa ser reduzido.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

1. No Apache, aumente LimitRequestFieldSize (caminho do cabeçalho) ou LimitRequestLine (caminho da URL) na configuração do vhost.
2. No nginx, aumente large_client_header_buffers.
3. Atrás de um proxy ou CDN, o limite pode estar nessa camada — verifique ambos.
4. Se os limites não puderem ser alterados, entre em contato com o suporte para emitir um token menor para este site.
