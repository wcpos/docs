## O que isso significa {#what-this-means}

A loja não aceitou as credenciais de acesso.

Digite novamente o nome de usuário e a senha ou redefina a senha no WordPress se continuar falhando. Nenhum dado de pedido é afetado.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado.

## Solução de problemas {#troubleshoot}

**No caixa** — para o operador de caixa: digite novamente o nome de usuário e a senha; a loja recusou essa combinação.

**Na loja** — para o administrador do site:

1. Confirme se a conta funciona entrando no WP Admin com as mesmas credenciais; se não funcionar, redefina a senha por lá.
2. Se as credenciais funcionarem no WP Admin, mas não no POS, um plugin de proteção de login ou de segurança pode estar bloqueando a entrada programática — verifique as configurações dele.
