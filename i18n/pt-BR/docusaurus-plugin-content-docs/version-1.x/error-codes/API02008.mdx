# API02008: Token de Atualização Inválido {#api02008-refresh-token-invalid}

## O Que Isso Significa {#what-this-means}

O token de atualização armazenado pelo POS não é reconhecido pelo servidor. Os tokens de atualização são usados para obter novos tokens de acesso sem a necessidade de fazer login novamente.

## Causas Comuns {#common-causes}

- **Token revogado** — Um administrador invalidou sua sessão
- **Segredos do servidor alterados** — As chaves de segurança do WordPress foram atualizadas
- **Corrupção de dados** — O token foi corrompido no armazenamento
- **Múltiplos logins** — Fazer login em outro lugar pode ter invalidado este token

## Como Corrigir {#how-to-fix}

### 1. Faça Login Novamente {#1-log-in-again}

Uma vez que o token de atualização é inválido, você precisará se autenticar novamente:
1. Faça logout do POS
2. Digite seu nome de usuário e senha
3. Isso gera novos tokens válidos

### 2. Verifique Sessões Revogadas {#2-check-for-revoked-sessions}

Se um administrador revogou sessões:
- Isso é uma prática de segurança normal
- Simplesmente faça login novamente
- Sua nova sessão funcionará normalmente

### 3. Verifique Alterações no Servidor {#3-check-server-changes}

Se isso afetar todos os usuários:
- As salgadas/chaves do WordPress podem ter mudado
- As configurações do plugin JWT podem ter sido modificadas
- Entre em contato com o administrador do seu servidor

### 4. Limpe os Dados Armazenados {#4-clear-stored-data}

Se os problemas continuarem, e somente depois da verificação abaixo:

:::warning Verifique primeiro se há trabalho não salvo
Limpar os dados locais ou reinstalar o aplicativo apaga tudo neste dispositivo que ainda não chegou à sua loja — incluindo vendas feitas offline, carrinhos abertos e edições que não foram salvas. Antes de limpar qualquer coisa, abra **Saúde da loja → Banco de dados** e confira se nada está listado como retido ou como nunca tendo chegado ao servidor; depois, em **Saúde da loja → Registros**, confira se há **0 registros travados** e **0 alterações aguardando envio**; por fim, finalize ou anote cada carrinho aberto. Se o seu WCPOS não tiver a página Saúde da loja, atualize o WCPOS antes de conferir. Se houver algo listado ou aguardando, ou se você não puder verificar, não limpe — peça ajuda ao responsável pela loja ou entre em contato com o suporte.
:::

- Limpe os dados do aplicativo POS
- Remova credenciais em cache
- Comece com um login limpo
