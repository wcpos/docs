## O que isso significa {#what-this-means}

O WCPOS encontrou um erro inesperado.

Confira se a última ação foi concluída antes de tentar novamente — no caso de uma venda, abra o pedido e confira o status. Se o problema se repetir, toque em **Copiar informações de depuração** e envie as informações ao suporte do WCPOS.

## Seus dados {#your-data}

Não foi possível confirmar o resultado — confira antes de tentar novamente. Se o problema se repetir, use **Copiar informações de depuração** na aba **Registros** e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Confira se a última ação foi concluída antes de tentar novamente — no caso de uma venda, abra o pedido e confira o status; no caso de um pagamento, confira também o terminal ou o provedor. Se não tiver sido concluída, tente mais uma vez.
2. Expanda a entrada de log e anote o código do evento e o contexto — um código 999 significa que a falha ainda não tem um código dedicado, e é essa informação que a identifica.
3. Se o problema se repetir, toque em **Copiar informações de depuração** na aba **Registros** e envie as informações ao suporte do WCPOS — é assim que o código específico é adicionado.
