## O que isso significa {#what-this-means}

O WCPOS encontrou um erro inesperado.

Tente a ação mais uma vez e, se falhar de novo, exporte os diagnósticos e entre em contato com o suporte.

## Seus dados {#your-data}

Não foi possível confirmar o resultado — verifique antes de tentar novamente. Se isso persistir, exporte os diagnósticos e entre em contato com o suporte do WCPOS.

## Solução de problemas {#troubleshoot}

1. Tente a ação mais uma vez.
2. Expanda a entrada de log e anote o código do evento e o contexto — um código 999 significa que a falha ainda não tem um código dedicado, e é essa informação que a identifica.
3. Se o problema se repetir, exporte as informações de depuração e entre em contato com o suporte — relatar o caso é o que faz o código específico ser criado.
