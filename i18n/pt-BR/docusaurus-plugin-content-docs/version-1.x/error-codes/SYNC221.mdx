## O que isso significa {#what-this-means}

Uma alteração neste dispositivo encontrou uma edição mais recente na sua loja. Nada foi perdido.

Se **Saúde da loja → Banco de dados** listar uma alteração retida para este registro, toque em **Enviar novamente** para manter a versão deste dispositivo ou em **Usar versão do servidor** para manter a versão da loja. Caso contrário, não é necessário fazer nada — o conflito já foi resolvido.

## Seus dados {#your-data}

Nada foi perdido. Quando uma alteração fica retida, sua loja mantém a própria versão e este dispositivo mantém a alteração até você escolher qual manter; novas edições desse registro ficam aguardando neste dispositivo até lá. Não apague os dados deste dispositivo enquanto uma alteração estiver retida — isso excluiria a alteração retida.

## Solução de problemas {#troubleshoot}

1. Abra **Saúde da loja → Banco de dados**. Uma alteração retida aparece em um painel que começa com **"1 alteração foi retida"** (ou **"… alterações foram retidas"**), junto com o registro ao qual ela pertence.
2. Se não houver mais nenhuma alteração retida para este registro, o conflito já foi resolvido — aqui ou em outra aba — e não é necessário fazer nada. Um conflito de pedido que o WCPOS resolve automaticamente, reenviando a versão deste dispositivo, é registrado como [SYNC222](/error-codes/SYNC222).
3. Se uma alteração estiver retida, pressione **Abrir registro** (quando disponível) para ver a versão deste dispositivo e compare-a com o mesmo registro no WP Admin (talvez um administrador do site precise fazer isso).
4. Para manter a versão deste dispositivo, toque em **Enviar novamente** — a alteração será reenviada e substituirá os valores da loja nos campos alterados neste dispositivo. Para manter a versão da loja, toque em **Usar versão do servidor** (em algumas linhas, **Descartar alteração do dispositivo**) e confirme — a alteração deste dispositivo será descartada. Novas edições desse registro ficam aguardando até você escolher.
5. Conflitos frequentes nos mesmos registros geralmente significam que duas pessoas estão editando os mesmos dados ao mesmo tempo — por exemplo, o estoque no caixa e no WP Admin. Combine onde cada tipo de edição deve ser feito.
