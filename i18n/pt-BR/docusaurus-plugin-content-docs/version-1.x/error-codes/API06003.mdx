# API06003: Configuração de Site Inválida {#api06003-invalid-site-configuration}

## O Que Isso Significa {#what-this-means}

A configuração do site é inválida ou incompleta. Isso pode envolver URLs incorretas, configurações de autenticação ou outros problemas de configuração.

## Causas Comuns {#common-causes}

- **Configuração parcial** — Algumas configurações estão ausentes
- **Configurações incompatíveis** — A configuração não corresponde ao site
- **Configuração corrompida** — As configurações foram corrompidas
- **Mudanças no site** — O site foi modificado sem atualizar a configuração do POS

## Como Corrigir {#how-to-fix}

### 1. Revise Todas as Configurações {#1-review-all-settings}

Verifique a configuração completa:
- A URL do site está correta
- A autenticação está configurada corretamente
- Quaisquer configurações adicionais estão corretas

### 2. Reconfigure do Zero {#2-reconfigure-from-scratch}

:::warning Verifique primeiro se há trabalho não salvo
Limpar os dados locais ou reinstalar o aplicativo apaga tudo neste dispositivo que ainda não chegou à sua loja — incluindo vendas feitas offline, carrinhos abertos e edições que não foram salvas. Antes de limpar qualquer coisa, abra **Saúde da loja → Banco de dados** e confira se nada está listado como retido ou como nunca tendo chegado ao servidor; depois, em **Saúde da loja → Registros**, confira se há **0 registros travados** e **0 alterações aguardando envio**; por fim, finalize ou anote cada carrinho aberto. Se o seu WCPOS não tiver a página Saúde da loja, atualize o WCPOS antes de conferir. Se houver algo listado ou aguardando, ou se você não puder verificar, não limpe — peça ajuda ao responsável pela loja ou entre em contato com o suporte.
:::

Somente se a configuração estiver corrompida, e apenas depois da verificação acima:
1. Limpe todas as configurações armazenadas
2. Inicie o processo de configuração novamente
3. Insira uma nova configuração

### 3. Verifique os Requisitos do Site {#3-check-site-requirements}

Verifique se seu site WordPress atende aos requisitos:
- WordPress está instalado e acessível
- WooCommerce está instalado e ativo
- O plugin WCPOS está instalado e ativo
- Os links permanentes estão habilitados (não "Simples")

### 4. Teste o Acesso ao Site {#4-test-site-access}

Verifique se essas URLs funcionam em um navegador:
- `https://yoursite.com/` — Site principal
- `https://yoursite.com/wp-json/` — REST API
- `https://yoursite.com/wp-json/wcpos/v1/` — API do WCPOS

### 5. Verifique as Configurações do WordPress {#5-check-wordpress-settings}

No Admin do WordPress:
1. Configurações → Geral — Verifique as URLs
2. Configurações → Links Permanentes — Certifique-se de que não está "Simples"
3. WooCommerce → Status — Verifique se há problemas

## Requisitos de Configuração {#configuration-requirements}

Uma configuração válida precisa de:
- **URL do Site** — URL completa com protocolo
- **Autenticação** — Credenciais ou chaves de API válidas
- **Permissões** — O usuário tem acesso ao POS
- **Plugins** — Plugins necessários estão ativos
