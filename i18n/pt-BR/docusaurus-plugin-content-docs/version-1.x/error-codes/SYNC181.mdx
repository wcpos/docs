## O que isso significa {#what-this-means}

Uma operação no banco de dados local está demorando muito mais que o normal; o resultado ainda é desconhecido.

Uma única leitura ou gravação no banco de dados local deste dispositivo ficou sem resposta por muito mais tempo que o normal, enquanto o banco de dados continua respondendo a todo o restante. Este relator apenas registra a paralisação — ele não cancela nem tenta novamente a operação, portanto a chamada original ainda pode ser concluída ou falhar mais tarde; a entrada existe para que uma tela ou indicador de carregamento travado deixe um registro identificando exatamente qual operação paralisou. O trabalho de sincronização paralisado tem um caminho separado de tempo limite e nova tentativa — registrado como uma entrada "Desistiu de uma solicitação de dados travada" em [SYNC321](/error-codes/SYNC321). Uma chamada paralisada de uma tela permanece pendente até ser concluída ou até que o aplicativo seja recarregado.

## Seus dados {#your-data}

A operação paralisada geralmente é uma consulta, que não altera nada. Se uma alteração estava sendo salva naquele momento, abra o registro e confirme se ela foi salva — talvez não tenha havido nenhum sintoma visível. O contexto da entrada identifica a operação e a coleção de dados envolvida.

## Solução de problemas {#troubleshoot}

1. Se tudo estiver funcionando, nenhuma ação será necessária — provavelmente a chamada foi concluída, apenas lentamente.
2. Se uma tela ou indicador de carregamento permanecer travado, recarregue o aplicativo — na web, recarregue a aba do navegador; no desktop e em dispositivos móveis, feche e abra novamente o aplicativo. Isso abandona a operação travada; a tela é carregada novamente e faz uma nova solicitação ao banco de dados. Um salvamento que estava em andamento não é reenviado — abra o registro e confirme se ele foi salvo.
3. Se este código voltar a aparecer regularmente no mesmo dispositivo, exporte as informações de depuração na tela Registros e entre em contato com o suporte — o contexto da entrada identifica a operação e a coleção, o tempo de espera exato e o nível de atividade do banco de dados nesse período.
