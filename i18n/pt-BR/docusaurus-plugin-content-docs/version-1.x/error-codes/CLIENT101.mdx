## O que isso significa {#what-this-means}

O WCPOS não conseguiu concluir a inicialização.

No caixa, isso aparece como uma tela em branco ou travada, ou como um indicador de carregamento que não desaparece. Geralmente, significa que não foi possível abrir o banco de dados local do dispositivo. Às vezes, reiniciar resolve; caso contrário, é preciso limpar o banco de dados local e abrir o app novamente. O WCPOS baixará todos os dados da sua loja outra vez.

:::warning A limpeza apaga dados não sincronizados
Limpar o banco de dados local **apaga permanentemente tudo neste dispositivo que ainda não foi sincronizado com sua loja** — por exemplo, vendas realizadas offline. Como não é possível abrir o app, esses dados não podem ser sincronizados antes e não podem ser recuperados. Se você sabe que há vendas importantes ainda não sincronizadas neste dispositivo, entre em contato com o suporte **antes** de limpar.
:::

## Seus dados {#your-data}

Os dados da sua loja estão seguros — eles serão baixados novamente na próxima vez que o app abrir. A limpeza remove somente a cópia local deste dispositivo, inclusive alterações que ainda não chegaram à loja (consulte o aviso acima).

## Solução de problemas {#troubleshoot}

1. Reinicie o app uma vez; na web, recarregue a aba por completo — uma falha temporária de inicialização muitas vezes se resolve sozinha.
2. Se ainda não iniciar, provavelmente não é possível abrir o banco de dados local. Limpe-o e abra o app novamente — siga as instruções em [Limpar todos os dados locais](/support/troubleshooting/clear-local-data), que abrangem o botão no app, o app web e o app para desktop. O WCPOS baixará os dados da sua loja automaticamente. (Isso apaga dados não sincronizados neste dispositivo — consulte o aviso acima.)
3. Se a inicialização continuar falhando depois da limpeza, use **Copiar informações de depuração** — ou consulte o erro no console do navegador, se o app não conseguir abrir os próprios logs — e entre em contato com o suporte.
