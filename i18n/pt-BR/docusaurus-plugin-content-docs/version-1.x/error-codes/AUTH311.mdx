## O que isso significa {#what-this-means}

A rota da loja do WCPOS está indisponível.

Peça ao administrador do site que verifique se algum plugin de segurança ou de proxy está removendo os cabeçalhos das requisições do WCPOS.

## Seus dados {#your-data}

Nenhum dado de pedido ou produto é afetado. Se isso persistir, procure a pessoa responsável pelo seu site WordPress.

## Solução de problemas {#troubleshoot}

**No caixa** — para o operador de caixa: teste no navegador os dois formatos REST compatíveis — o endereço `/wp-json/` da sua loja e `/index.php?rest_route=/`. Só conclua que há um bloqueio REST se nenhum deles retornar JSON; em seguida, informe o administrador.

**Na loja** — para o administrador do site:

1. Confirme se o WCPOS está ativo: WP Admin → Plugins.
2. Se nenhum dos formatos REST funcionar, verifique se um plugin de segurança, proxy ou CDN está removendo os cabeçalhos das solicitações do WCPOS ou bloqueando solicitações REST — regras de firewall e opções de proteção que desativam a API REST são as causas mais comuns.
3. Em alguns servidores, salvar novamente os links permanentes (Configurações → Links permanentes → Salvar) restaura rotas REST ausentes.
