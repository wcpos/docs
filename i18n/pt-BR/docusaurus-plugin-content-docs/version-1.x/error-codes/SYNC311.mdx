## O que isso significa {#what-this-means}

Os dados armazenados neste dispositivo são de uma versão diferente do aplicativo e não podem ser abertos.

A solução é limpar o banco de dados local do dispositivo e abrir o aplicativo novamente — o WCPOS baixará tudo da sua loja outra vez. Uma incompatibilidade de esquema geralmente ocorre após uma atualização ou reversão da versão do aplicativo neste dispositivo.

:::warning A limpeza remove dados não sincronizados
Limpar o banco de dados local **exclui permanentemente tudo neste dispositivo que ainda não foi sincronizado com sua loja** — por exemplo, vendas feitas enquanto estava offline. Como não será possível abrir o banco de dados, esses dados não poderão ser sincronizados antes e não poderão ser recuperados. Se você sabe que há vendas importantes ainda não sincronizadas neste dispositivo, entre em contato com o suporte **antes** de limpar.
:::

## Seus dados {#your-data}

Os dados da sua loja estão seguros — eles serão baixados novamente na próxima vez que o aplicativo for aberto. Somente a cópia local do dispositivo será limpa, incluindo as alterações que ainda não chegaram à loja (veja o aviso acima).

## Solução de problemas {#troubleshoot}

1. Confira se o WCPOS está na versão atual neste dispositivo — uma incompatibilidade de esquema geralmente ocorre após uma mudança de versão.
2. Limpe o banco de dados local e abra o aplicativo novamente — siga [Limpar todos os dados locais](/support/troubleshooting/clear-local-data), que explica o botão no aplicativo, o app Web e o aplicativo para desktop. O WCPOS baixará automaticamente os dados da sua loja. (Isso exclui os dados não sincronizados neste dispositivo — veja o aviso acima.)
3. Se o erro voltar após a limpeza, use **Copiar informações de depuração** e entre em contato com o suporte.
