A página Configurações gerais permite configurar as principais funcionalidades do WCPOS. Essas configurações afetam como os produtos são exibidos, como as quantidades são tratadas e como a leitura de código de barras funciona.

## Ativar produtos somente para POS {#enable-pos-only-products}

Essa configuração adiciona opções de visibilidade aos produtos, permitindo controlar se eles aparecem na loja virtual, no POS ou em ambos.

:::warning Impacto no desempenho
Ative essa configuração somente se precisar ocultar produtos da loja virtual ou do POS. Quando ativada, ela adiciona uma consulta adicional ao banco de dados para cada solicitação de produto.
:::

Para informações detalhadas sobre como usar este recurso, incluindo como definir a visibilidade de produtos individuais e editar em massa, consulte [Produtos somente para POS](/products/pos-only-products).

## Habilitar quantidades decimais {#enable-decimal-quantities}

Esta configuração permite que clientes e colaboradores insiram quantidades decimais ao adicionar produtos ao carrinho.

**Exemplos de quantidades decimais:**
- 0.25 (um quarto de unidade)
- 1.5 (uma unidade e meia)
- 2.75 (duas unidades e três quartos)

**Útil para:**
- Produtos vendidos por peso (por exemplo, 0.5kg de grãos de café)
- Serviços fracionados (por exemplo, 1.5 horas de consultoria)
- Produtos a granel que podem ser vendidos em quantidades parciais

## Restaurar estoque ao excluir pedido {#restore-stock-on-order-delete}

Quando ativada, WCPOS restaura automaticamente o estoque dos produtos quando um pedido do POS é movido para a lixeira ou excluído — assim, cancelar uma venda feita por engano devolve os itens ao estoque. Esta configuração fica **ativada por padrão**.

Desative esta opção se você reconcilia o estoque de outra forma e não quer que pedidos POS excluídos ajustem o inventário.

## Gerar automaticamente o nome de usuário a partir do e-mail do cliente {#automatically-generate-username-from-customer-email}

Quando ativada, a WCPOS criará automaticamente nomes de usuário para novos clientes com base em seus endereços de e-mail durante a finalização da compra. Isso simplifica o processo de criação de clientes e garante uma formatação consistente dos nomes de usuário.

## Cliente POS padrão {#default-pos-customer}

Selecione o cliente padrão que será atribuído aos novos pedidos POS. As opções comuns incluem:

- **Convidado**: os pedidos não são associados a nenhuma conta de usuário
- **Caixa**: os pedidos são associados à conta do caixa conectado
- **Cliente avulso**: os pedidos são associados a uma conta de cliente específica (será necessário criar essa conta primeiro)

## Usar conta do caixa {#use-cashier-account}

Quando ativada, a conta de usuário do caixa será usada como cliente padrão para pedidos POS em vez do Cliente POS padrão selecionado.

## Permitir que clientes baixem recibos {#storefront-receipts}

Quando ativada, a WCPOS adiciona um botão **Recibo** a **Minha conta → Pedidos** na loja online, para que os clientes possam baixar o próprio recibo do pedido como um PDF renderizado com o modelo da WCPOS. Esta configuração fica **desativada por padrão**.

O menu suspenso **Modelo de recibo para clientes** abaixo da opção de alternância escolhe qual modelo eles recebem. Por padrão, é **Usar modelo de recibo ativo**, para permanecer sincronizado com o POS; escolha um modelo específico para dar aos pedidos online uma aparência diferente (por exemplo, uma fatura de página inteira).

Consulte [Recibos da loja online](/receipts/storefront) para ver o guia completo, incluindo os status de pedido compatíveis, o shortcode `[wcpos_receipt]` e os filtros para desenvolvedores.

## Campo de código de barras {#barcode-field}

Esta configuração determina em qual campo de produto o WCPOS pesquisará ao escanear códigos de barras ou usar a função de pesquisa de código de barras.

<a id="default-option"></a>

:::note Chave meta padrão
Use **`_global_unique_id`** — o campo ID global exclusivo do WooCommerce, introduzido no WooCommerce 8.2 (julho de 2024). Ele foi desenvolvido para armazenar códigos GTIN, UPC, EAN ou ISBN e é a opção recomendada para novas instalações. Se não estiver usando o campo ID global exclusivo, **`_sku`** (o campo SKU / Stock Keeping Unit do produto) é uma boa alternativa.
:::

<a id="other-common-options"></a>
<a id="third-party-plugin-meta-keys"></a>

### Plugins comuns → chave meta {#common-plugins-meta-key}

Se estiver usando um plugin de gerenciamento de códigos de barras, talvez seja necessário usar a chave meta específica dele:

| Plugin / tipo de campo | Chave meta |
|---|---|
| ID global exclusivo do WooCommerce *(padrão, recomendado)* | `_global_unique_id` |
| SKU do produto *(alternativa)* | `_sku` |
| Plugins de EAN (Número Europeu de Artigo) | `_ean`, `_ean13`, `_ean8` |
| Plugins de UPC (Código Universal de Produto) | `_upc`, `_upc_code` |
| Plugins de GTIN (Número Global de Item Comercial) | `_gtin`, `_gtin13`, `_gtin14` |
| Campos genéricos de código de barras | `_barcode`, `_product_barcode` |
| Códigos de barras de produtos do WooCommerce | `_barcode_text` |
| Inventário ATUM | `_atum_barcode` |

<a id="custom-meta-keys"></a>

:::tip Chaves meta personalizadas
É possível usar **qualquer** chave meta personalizada que armazene dados de código de barras. Basta inserir o nome da chave meta (incluindo o prefixo de sublinhado, se aplicável) neste campo.
:::

### Como encontrar a chave meta do seu plugin {#finding-your-plugins-meta-key}

Se o plugin não estiver listado acima, encontre a chave meta correta da seguinte forma:

<Steps>
  <StepCard number="1" title="Adicionar um código de barras a um produto">

Edite um produto no WP Admin e adicione um código de barras usando seu plugin.

  </StepCard>
  <StepCard number="2" title="Consulte a documentação do plugin">

Procure na documentação do plugin o nome da chave meta que ele usa.

  </StepCard>
  <StepCard number="3" title="Ou inspecione o banco de dados" isLast>

Inspecione a tabela `wp_postmeta` do banco de dados para ver qual chave meta foi criada para o produto.

  </StepCard>
</Steps>

:::warning Limpe e atualize após alterar esta configuração
Após alterar a configuração do campo de código de barras, é **obrigatório** limpar e atualizar os dados dos produtos no POS para que a alteração entre em vigor. O POS armazena os dados dos produtos em cache localmente, e alterar a configuração do campo de código de barras não atualiza automaticamente os dados armazenados em cache.

**Como limpar e atualizar:**

1. Acesse a tela de Produtos no POS
2. **Mantenha pressionado** o ícone de sincronização (↻) na parte inferior da tela
3. Selecione **"Limpar e atualizar"** no menu de contexto
4. Aguarde o recarregamento dos produtos com os dados do novo campo de código de barras

Em seguida, teste a leitura de códigos de barras para confirmar que ela funciona corretamente com o campo escolhido.
:::

## Privacidade {#privacy}

A opção **Permitir dados de uso anônimos** controla se o WCPOS coleta análises de uso anônimas para ajudar a melhorar o produto. É uma opção real de ativação/desativação — dados de clientes, preços e endereço da loja nunca são coletados. Use o link **Saiba mais** ao lado da configuração para ver exatamente o que é e o que não é coletado.

## IDs fiscais da loja {#store-tax-ids}

Adicione os identificadores fiscais da empresa — número de IVA, ABN, GSTIN, EIN ou números de registro empresarial locais — que o WCPOS imprime em recibos e faturas do POS. O WooCommerce não tem um campo integrado para esses dados, e muitas regiões precisam de mais de um.

Consulte [IDs fiscais da loja](/settings/wp-admin/store-tax-ids) para ver o guia completo.

## IDs fiscais do cliente {#customer-tax-ids}

O WCPOS mantém um campo de ID fiscal nos clientes e o copia para os pedidos durante a finalização da compra. Como diferentes plugins armazenam esse campo com nomes diferentes, o WCPOS detecta qual plugin está instalado e grava automaticamente no campo correto. A seção **IDs fiscais** também permite substituir o nome do campo, se necessário.

Consulte [IDs fiscais do cliente](/settings/wp-admin/customer-tax-ids) para ver o guia completo.
