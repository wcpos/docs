O WCPOS possui três tipos de configurações, organizadas de acordo com o local onde são definidas.

## Onde Encontrar Configurações {#where-to-find-settings}

### 1. Configurações do WordPress Admin {#1-wordpress-admin-settings}

Configurações de backend definidas no seu painel do WordPress:

**Localização:** `WP Admin > POS > Configurações`

Elas controlam:
- Cliente padrão do carrinho para todos os caixas
- Configuração do campo de código de barras do produto
- Configurações de e-mail do pedido
- Permissões das funções de usuário (quem pode acessar o POS)
- Disponibilidade dos gateways de pagamento

Consulte [Configurações do WordPress Admin](/1.x/settings/wp-admin) para mais detalhes.

### 2. Configurações da Loja POS {#2-pos-store-settings}

Configurações gerais definidas dentro do aplicativo POS:

**Localização:** Menu do usuário (canto superior direito) → Configurações, ou `Ctrl + Shift + S`

Elas controlam:
- Opções de cálculo de impostos
- Configuração do scanner de código de barras
- Atalhos de teclado
- Tema/aparência

Consulte [Configurações da Loja](/1.x/settings/store) para mais detalhes.

### 3. Configurações de Exibição (Por Tela) {#3-display-settings-per-screen}

Cada tela do POS possui suas próprias configurações de exibição para personalizar a tabela de dados:

**Localização:** Clique no ícone de deslizadores (<Icon name="sliders" />) em qualquer tela

Elas controlam:
- Quais colunas ficam visíveis
- Opções de exibição das colunas
- Recursos específicos da tela

As configurações de exibição estão descritas na documentação de cada tela:
- [Painel de Produtos POS](/1.x/pos/product-panel#display-settings)
- [Painel do Carrinho](/1.x/pos/cart#display-settings)
- [Painel de Produtos](/1.x/products#display-settings)
- [Painel de Pedidos](/1.x/orders#display-settings)
- [Painel de Clientes](/1.x/customers#display-settings)
- [Painel de Relatórios](/1.x/reports#display-settings)
