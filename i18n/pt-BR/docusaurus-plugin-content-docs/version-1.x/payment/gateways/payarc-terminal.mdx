# Gateway de terminal PayArc {#payarc-terminal-gateway}

O gateway de terminal PayArc permite aceitar pagamentos presenciais em um terminal PayArc PAX pelo WCPOS, usando o PayArc Connect. O pagamento é iniciado no WooCommerce e concluído no terminal, e o pedido só é marcado como pago depois da confirmação do PayArc.

## Como funciona {#how-it-works}

O WordPress chama o **PayArc Connect**, e o PayArc se comunica com o terminal PAX. O POS se comunica apenas com o seu site. Cada pagamento cobra o **valor total do pedido**.

A página de pagamento verifica o resultado a cada **1.5 segundos** e para após **5 minutos**. Os callbacks do PayArc para a **Webhook URL** aceleram o resultado; os pagamentos ainda são concluídos por consulta periódica sem callbacks. Mantenha a página de pagamento aberta enquanto o cliente paga no terminal.

## Configuração {#setup}

<Steps>
  <StepCard number="1" title="Instalar o PayArc Terminal for WooCommerce">

Instale em `WP Admin > POS > Configurações > Extensões` ou baixe o arquivo **payarc-terminal-for-woocommerce.zip** na [página de versões do GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases) e envie-o em `Plugins > Adicionar novo > Enviar plugin`. Ative o plugin.

  </StepCard>
  <StepCard number="2" title="Inserir suas credenciais do PayArc">

1. Acesse `WP Admin > WooCommerce > Configurações > Pagamentos` e abra **PayArc Terminal**
2. Escolha **Mode**: `Live` é o padrão. Use `Test` somente com as credenciais do painel de teste do PayArc e o app PayArc Connect Test. Nunca misture ambientes
3. Insira **PayArc login email**, o endereço de e-mail usado para entrar no painel de comerciante do PayArc
4. Insira **PayArc MID** do perfil de comerciante do PayArc, não o ID do terminal
5. Insira **PayArc ClientSecret** da seção de API do painel e **PayArc SecretKey / API bearer token** do painel do PayArc
6. Deixe **Callback bearer token** em branco, a menos que o suporte do PayArc tenha fornecido um; ele é opcional

  </StepCard>
  <StepCard number="3" title="Conectar">

Clique em **Connect using these credentials**. Se a conexão for bem-sucedida, a tela solicitará que você insira ou confirme o número de série do terminal e salve as configurações. Se a mensagem indicar que as credenciais parecem pertencer ao outro ambiente, altere **Mode** e conecte-se novamente.

:::note
Depois de alterar o modo ou as credenciais, clique novamente em **Connect using these credentials** e salve. Os pagamentos são bloqueados até que o modo e as credenciais correspondam à conexão salva. Se estiver atualizando de uma versão anterior à 0.1.14, clique em Connect uma vez.
:::

  </StepCard>
  <StepCard number="4" title="Adicionar seu terminal">

1. Insira o **Terminal serial number** do PAX, que aparece na etiqueta **S/N** na parte de trás do dispositivo, conforme configurado pelo PayArc para sua conta
2. Escolha **Tender type** e **Print receipt**
3. Verifique se a **Webhook URL** usa HTTPS. Forneça-a ao PayArc somente se solicitarem
4. Clique em **Save changes**

O modo Live exige um site HTTPS.

  </StepCard>
  <StepCard number="5" title="Ativar no WCPOS" isLast>

1. Acesse `WP Admin > POS > Configurações > Finalização de compra`
2. Localize o gateway **PayArc Terminal** e ative-o para o POS
3. Salve suas configurações

:::note
A caixa de seleção **Enable/Disable** na tela de configurações do WooCommerce controla apenas o checkout da *loja virtual*. O WCPOS usa este gateway depois de configurado, independentemente de essa caixa estar marcada.

A maioria das lojas deixa esta opção desmarcada.
:::

  </StepCard>
</Steps>

## Referência das configurações {#settings}

| Configuração | O que faz |
|---|---|
| **Enable/Disable** | Ativa o PayArc Terminal para o checkout da loja virtual. Desativado por padrão; a ativação para o POS é controlada em `POS > Configurações > Finalização de compra` |
| **Title** | O rótulo exibido no checkout; o padrão é `PayArc Terminal` |
| **Description** | A descrição exibida no checkout; o padrão é `Pay in person at a PayArc PAX terminal.` |
| **Mode** | `Live` (padrão) ou `Test`. O modo Test exige credenciais do painel de teste do PayArc e o app PayArc Connect Test |
| **PayArc login email** | Seu e-mail de acesso ao painel de comerciante do PayArc; obrigatório antes da conexão |
| **PayArc MID** | O MID de comerciante do seu perfil de comerciante do PayArc, não o ID do terminal |
| **PayArc ClientSecret** | O segredo da seção de API do painel; armazenado somente no seu servidor |
| **PayArc SecretKey / API bearer token** | O token do painel do PayArc, usado para entrar e obter o registro de terminais |
| **Callback bearer token** | Opcional. Preencha somente se o suporte do PayArc tiver fornecido um |
| **PayArc connection** | Botões **Connect using these credentials**, **Refresh Terminals** e **Disconnect** |
| **Terminal serial number** | O S/N do PAX atribuído à sua conta, obrigatório para pagamentos. Preenchido com base no registro, se encontrado; insira ou confirme antes de salvar |
| **Tender type** | `CREDIT` (padrão) ou `DEBIT` |
| **Print receipt** | `0` — nenhum (padrão), `1` — estabelecimento, `2` — cliente, `3` — ambos |
| **Webhook URL** | Endereço de callback somente leitura. Verifique se usa HTTPS; forneça-o ao PayArc somente se solicitarem |
| **PayArc diagnostics** | Informações de conexão e um botão **Validate Settings**; os segredos nunca são exibidos |

Os campos de segredo salvos exibem somente os últimos 4 caracteres. Deixe um campo de segredo em branco para manter o valor salvo.

A tabela **PayArc diagnostics** mostra o modo, os endpoints, o MID / ID do tenant / número de série mascarados, se o token de acesso do Connect está configurado, a Webhook URL, o último callback e o último erro do PayArc. Use **Validate Settings** para verificar suas configurações.

## Uso {#usage}

### Processamento de pagamentos {#processing-payments}

1. **Select Gateway**: escolha **PayArc Terminal** como método de pagamento no POS
2. **Start Payment**: clique em **Start Payment** para enviar o valor total do pedido ao terminal
3. **Customer Payment**: mantenha a página aberta enquanto o cliente conclui o pagamento no terminal PAX. Acompanhe as mensagens de status: `Starting terminal payment...` → `Payment sent to terminal.` → `Waiting for the terminal result...` → `Payment approved. Completing the order...`
4. **Automatic Completion**: quando o PayArc confirmar o pagamento, o pedido será concluído automaticamente

### Controles de pagamento {#payment-controls}

- **Cancel Payment** aparece quando um pagamento é iniciado. Se o PayArc ainda não tiver retornado um ID de rastreamento, aguarde um instante antes de cancelar
- Após uma recusa, um cancelamento ou um tempo limite, você pode tentar novamente. Verifique o terminal antes de repetir um pagamento que atingiu o tempo limite
- O registro de atividade do pagamento fica recolhido por padrão. Use **Show activity** para exibi-lo e **Clear** para limpar a atividade exibida

### Recibos {#receipts}

A configuração **Print receipt** controla a impressão no terminal: nenhum recibo, recibo do estabelecimento, do cliente ou de ambos.

## Reembolsos {#refunds}

O plugin não oferece suporte a reembolsos. Faça o reembolso pelo PayArc e, em seguida, registre-o manualmente no WooCommerce.

## Registros {#logs}

Encontre os registros em `WooCommerce > Status > Logs`, na origem `payarc-terminal-for-woocommerce`. Eles incluem tentativas de conexão, vendas iniciadas ou malsucedidas, cancelamentos e callbacks aceitos ou rejeitados. Os identificadores são mascarados e os segredos são ocultados.

Não há opção para baixar um pacote de suporte. Ao pedir ajuda, envie o número do pedido e as linhas de registro relevantes. Não compartilhe MIDs completos, IDs de terminal, tokens ou dados do cartão.

## Escopo e limitações {#scope-and-limitations}

- O plugin não oferece suporte a reembolsos
- Os pagamentos cobram o **valor total do pedido**; pagamentos parciais ou divididos não são aceitos
- Gorjetas não são aceitas
- Um terminal por loja: uma única configuração de número de série, sem seletor de caixa
- As moedas estão limitadas a **USD, CAD, GBP, EUR e JPY**
- Os pagamentos são bloqueados até que o modo e as credenciais correspondam à conexão salva

## Solução de problemas {#troubleshooting}

### Problemas comuns {#common-issues}

<Accordion>
  <AccordionItem question="As credenciais parecem pertencer ao outro ambiente">

  - O modo selecionado e as credenciais são de ambientes diferentes
  - Altere **Mode** para corresponder às credenciais ou substitua as credenciais pelas do modo selecionado
  - Clique novamente em **Connect using these credentials** e salve

  </AccordionItem>
  <AccordionItem question="Não foi possível conectar ao PayArc">

  - O PayArc recusou as credenciais de acesso. Verifique as credenciais inseridas e tente novamente
  - Consulte `WooCommerce > Status > Logs`, origem `payarc-terminal-for-woocommerce`, para ver os detalhes

  </AccordionItem>
  <AccordionItem question="Não foi possível processar a solicitação de pagamento. (HTTP 500)">

  - Esta mensagem exibida ao caixa é genérica. Procure **PayArc payment action failed** no registro do WooCommerce para encontrar a causa real
  - Depois de alterar o modo ou as credenciais, clique novamente em **Connect using these credentials** e salve
  - Verifique se **Terminal serial number** está preenchido
  - Se o registro indicar que o PayArc rejeitou tanto o token de acesso do Connect quanto o SecretKey, peça ao suporte do PayArc que confirme se **PayArc Connect V3** está habilitado para sua conta de comerciante
  - Verifique se a moeda da loja é **USD, CAD, GBP, EUR ou JPY**

  </AccordionItem>
  <AccordionItem question="Acesso negado. (HTTP 403) ao iniciar o pagamento">

  - Atualize para **0.1.12 ou posterior**, versão que corrige esse erro nas sessões do POS

  </AccordionItem>
  <AccordionItem question="O registro de terminais está vazio">

  - É normal que o registro esteja vazio ou que um terminal apareça sem identificador de POS
  - Os dados do registro servem apenas para consulta. Os pagamentos usam o **Terminal serial number**

  </AccordionItem>
  <AccordionItem question="O pagamento demora demais">

  - Verifique a tela do terminal e mantenha a página de pagamento aberta
  - Verifique as observações do pedido e o painel do PayArc antes de tentar novamente
  - A página verifica o resultado a cada **1.5 segundos** e para após **5 minutos**

  </AccordionItem>
</Accordion>

### Como obter ajuda {#getting-help}

- Inclua o **número do pedido** e as **linhas de registro** relevantes na solicitação de suporte
- Acesse o [repositório do GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce) para relatar problemas
- Entre em contato com o suporte do PayArc para obter ajuda com a conta, o PayArc Connect e a configuração do terminal
