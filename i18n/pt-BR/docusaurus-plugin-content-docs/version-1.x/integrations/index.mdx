O WCPOS é executado na API REST do WooCommerce, portanto, a maioria dos plugins do WooCommerce funciona com pedidos do POS sem configuração adicional. Alguns exigem que o WCPOS faça algo em seu nome, pois só se integram ao checkout online ou à tela de pedidos do WP Admin. As páginas desta seção abordam esses plugins: o que o WCPOS faz por eles, como configurá-los e o que esperar no caixa.

Isso é diferente de [Extensões](/extensions), que são complementos criados para o WCPOS e instalados a partir do diretório de extensões. Uma integração é um plugin que já é usado na loja online.
