**Sintoma:** os recibos impressos por uma aba do navegador saem completos, exceto pelo logotipo da loja. O mesmo recibo impresso pelo aplicativo desktop ou móvel sai com o logotipo normalmente.

## Por que isso acontece {#why-it-happens}

O logotipo fica na biblioteca de mídia do seu WordPress, e o navegador o busca de lá. Antes que uma página web possa ler os pixels de uma imagem carregada de outro endereço, o servidor que a hospeda precisa autorizar isso com um cabeçalho chamado `Access-Control-Allow-Origin`. O WordPress não envia esse cabeçalho nos arquivos enviados por padrão, então o navegador entrega a imagem para exibir, mas não para imprimir.

O aplicativo não tem como contornar isso — ele imprime o recibo sem o logotipo em vez de fazer a venda falhar. Os aplicativos desktop e móvel buscam o arquivo por conta própria e não estão sujeitos a essa regra.

## Faça isto {#do-this}

Escolha o que for melhor para a loja:

- **Imprima pelo aplicativo desktop.** Não há nada para configurar, e é a resposta mais rápida se o caixa já o tiver instalado.
- **Autorize o cabeçalho no seu site.** Quem cuida do site adiciona o `Access-Control-Allow-Origin` para o diretório de uploads, na configuração do servidor web ou com um plugin que defina cabeçalhos CORS. Recarregue o POS depois e imprima de novo.

## Se o logotipo sai como ruído {#if-the-logo-prints-as-noise}

Uma faixa de pontos aleatórios no lugar do logotipo é outro problema: algumas impressoras antigas e baratas não conseguem decodificar o formato de imagem usado. Remova o logotipo do modelo de recibo daquela impressora.

## Ainda com problema? {#still-stuck}

Use **Copiar relatório de configuração** na tela de problema e cole o conteúdo na sua mensagem, junto com o endereço da imagem do logotipo.
