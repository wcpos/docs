O WCPOS funciona com os dispositivos físicos já utilizados no balcão. Esta página é o ponto de partida para conectar hardware — impressoras de recibos, leitores de código de barras, leitores de cartão e gavetas de dinheiro. Cada tipo de dispositivo tem sua própria página de configuração aqui ou direciona para a página onde sua configuração está disponível.

:::note Um local por dispositivo
O hub de hardware direciona para a configuração de cada dispositivo, mas as etapas efetivas ficam em um único local. A conta e o fluxo de emparelhamento de um leitor de cartões ficam na página do gateway de pagamento; a configuração de acionamento de uma gaveta de dinheiro fica na página Impressoras de recibos.
:::

## Compatibilidade de leitores de cartões {#card-reader-compatibility}

Os leitores de cartões compatíveis dependem de **como o WCPOS é executado** e do tipo de conexão do leitor:

- **O aplicativo web** só pode controlar leitores que oferecem um **SDK web (de navegador)** — normalmente terminais de balcão conectados à internet. Leitores **somente Bluetooth** (por exemplo, Stripe M2 / WisePad 3, SumUp Air) e o **Tap-to-Pay** em celulares **não são compatíveis** com o aplicativo web.
- A compatibilidade é **por gateway**, não universal — antes de comprar, verifique se o leitor é compatível com o gateway que será usado ([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [Leitor PayPal](/payment/gateways/paypal-reader)).

Cada página de gateway lista os leitores exatos compatíveis.
