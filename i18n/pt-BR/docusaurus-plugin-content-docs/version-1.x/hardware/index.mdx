:::note Um único lugar por dispositivo
A página de Hardware indica onde fica a configuração de cada dispositivo, mas as etapas em si ficam em um só lugar. A conta e o pareamento de um leitor de cartão ficam na página do gateway de pagamento correspondente; a ligação da gaveta de dinheiro e a configuração de abertura ficam na página Gaveta de dinheiro.
:::

## Compatibilidade de leitores de cartão {#card-reader-compatibility}

Os leitores de cartão compatíveis dependem de **como você usa o WCPOS** e do tipo de conexão do leitor:

- **O aplicativo web** só consegue controlar leitores que oferecem um **SDK web (navegador)** — normalmente terminais de balcão conectados à internet. Leitores **somente Bluetooth** (ex.: Stripe M2 / WisePad 3, SumUp Air) e o **Tap-to-Pay** pelo celular **não são compatíveis** com o aplicativo web.
- A compatibilidade é **por gateway de pagamento**, não universal — verifique se o leitor é compatível com o gateway de pagamento que você pretende usar ([Stripe Terminal](/1.x/payment/gateways/stripe-terminal), [SumUp](/1.x/payment/gateways/sumup-terminal), [PayPal Reader](/1.x/payment/gateways/paypal-reader)) antes de comprar.

Cada página de gateway de pagamento lista exatamente os leitores compatíveis.
