O WCPOS funciona com os dispositivos físicos que você já usa no balcão. Esta página é o ponto de partida para conectar hardware — impressoras de recibos, leitores de código de barras, leitores de cartão e gavetas de dinheiro. Cada tipo de dispositivo tem a sua própria página de configuração aqui ou aponta para a página onde a configuração realmente fica.

:::note Um único lugar por dispositivo
O hub de Hardware indica onde fica a configuração de cada dispositivo, mas as etapas em si ficam em um só lugar. A conta e o pareamento de um leitor de cartão ficam na página do gateway de pagamento correspondente; a ligação da gaveta de dinheiro e a opção de abertura ficam na página Gaveta de dinheiro.
:::

## Compatibilidade de leitores de cartão {#card-reader-compatibility}

Quais leitores de cartão funcionam depende de **como você usa o WCPOS** e do tipo de conexão do leitor:

- **O aplicativo web** só consegue operar leitores que oferecem um **SDK web (navegador)** — normalmente terminais de balcão conectados à internet. Leitores **somente Bluetooth** (ex.: Stripe M2 / WisePad 3, SumUp Air) e o **Tap-to-Pay** pelo celular **não são compatíveis** com o aplicativo web.
- A compatibilidade é **por gateway**, não universal — confira o leitor junto ao gateway que você pretende usar ([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [PayPal Reader](/payment/gateways/paypal-reader)) antes de comprar.

Cada página de gateway lista exatamente os leitores compatíveis.
