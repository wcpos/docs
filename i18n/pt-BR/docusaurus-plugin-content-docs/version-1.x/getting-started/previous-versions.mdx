## Reinstalando uma Versão Anterior {#re-installing-a-previous-version}

Se você precisar voltar para uma versão anterior do plugin WCPOS, siga estes passos:

1. Visite a página do WordPress.org [Visualização Avançada](https://wordpress.org/plugins/woocommerce-pos/advanced/) para o WCPOS.

2. Role para baixo até a seção **Opções Avançadas** e localize o menu de seleção **Versões Anteriores**.

3. Abra o menu de seleção e você verá uma lista de versões do plugin disponíveis. Encontre a versão que você deseja instalar e clique no botão **Baixar** ao lado dela. Salve o arquivo baixado na sua área de trabalho ou em um local conveniente.

4. Faça login no painel administrativo do WordPress.

5. Navegue até a página **Plugins** clicando em **Plugins** no menu à esquerda.

6. Desative e delete a versão atual do plugin WCPOS. Isso removerá o plugin da sua instalação do WordPress. Não se preocupe, seus dados não serão perdidos.

7. Clique no botão **Adicionar Plugin** na parte superior da página.

8. Na página **Adicionar Plugins**, clique no botão **Enviar Plugin**.

9. Escolha o arquivo do plugin que você baixou anteriormente da sua área de trabalho ou do local onde você o salvou.

10. Clique no botão **Instalar Agora** e aguarde a conclusão da instalação.

11. Após a instalação ser concluída, clique no botão **Ativar** para ativar a versão anterior do plugin WCPOS.

É isso! Você reinstalou com sucesso uma versão anterior do plugin WCPOS.

Se você encontrar algum problema durante o processo de reinstalação ou precisar de mais assistência, entre em contato com nossa equipe de suporte pelo e-mail support@wcpos.com.
