## Reinstalando uma Versão Anterior {#re-installing-a-previous-version}

Para voltar a uma versão anterior do plugin, desative as atualizações automáticas, baixe a versão desejada e envie-a por cima da versão instalada. Nada é excluído nesse processo, então seus pedidos, configurações e modelos de recibo permanecem intactos.

:::warning Não exclua o plugin primeiro
Envie o arquivo `.zip` por cima do plugin instalado; assim, tudo é mantido. Na versão 2.0, excluir o plugin em **Plugins** executa a limpeza do WCPOS: encerra a sessão de todos os caixas, então cada terminal precisa entrar novamente, e apaga os dados de sincronização que cada terminal reconstrói. Não há motivo para excluir o plugin.
:::

Se você está saindo da versão 2.0, leia primeiro [Reverter para uma versão anterior](/getting-started/upgrading-to-2#rolling-back). Com o WCPOS Pro, reverta apenas o WCPOS Pro. Ele inclui o plugin gratuito.

### Desative as atualizações automáticas {#turn-off-auto-updates}

Com as atualizações automáticas ativadas, o WordPress instala novamente a versão mais recente por conta própria.

1. Acesse **WP Admin → Plugins**.
2. Na linha do WCPOS (ou do WCPOS Pro), verifique a coluna **Atualizações automáticas**. Se aparecer **Desativar atualizações automáticas**, clique nessa opção.

### Baixe a versão necessária {#download}

Mantenha o arquivo `.zip` compactado. O WordPress instala o `.zip`, não uma pasta.

**WCPOS:**

1. Acesse a [Visualização Avançada do WCPOS](https://wordpress.org/plugins/woocommerce-pos/advanced/) no WordPress.org.
2. Role a página até **Opções Avançadas**. Em **Versões Anteriores**, escolha a versão desejada.
3. Clique em **Baixar**.

**WCPOS Pro:**

1. Entre na sua conta em [wcpos.com](https://wcpos.com/account/downloads) e abra **Downloads**.
2. Em **Histórico de versões**, encontre a versão desejada.
3. Clique em **Baixar** na linha dessa versão.

Para sair da versão 2.0, escolha a versão mais recente da série **1.11**, não uma versão 1.x mais antiga.

### Envie o arquivo por cima da versão atual {#install}

1. Acesse **WP Admin → Plugins** e clique em **Adicionar Plugin** no topo da página.
2. Clique em **Enviar Plugin**, selecione o arquivo `.zip` que você baixou e clique em **Instalar Agora**.
3. O WordPress exibe **Este plugin já está instalado.** e mostra as versões **Atual** e **Enviada** lado a lado. Confira se a versão desejada aparece em **Enviada**.
4. Clique em **Substituir a versão atual pela enviada**.
5. O WordPress exibe **Plugin rebaixado com sucesso.** Se aparecer a opção **Ativar Plugin**, clique nela. Caso contrário, o plugin já estava ativo e continuará ativo.

Mantenha as atualizações automáticas desativadas até você estar pronto para atualizar novamente; depois, reative-as para que as próximas correções sejam instaladas automaticamente.

Se encontrar algum problema durante a reinstalação ou precisar de mais ajuda, entre em contato com nossa equipe de suporte pelo endereço support@wcpos.com.
