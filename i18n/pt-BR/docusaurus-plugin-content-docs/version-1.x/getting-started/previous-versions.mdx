## Reinstalando uma Versão Anterior {#re-installing-a-previous-version}

Se você precisar voltar para uma versão anterior do plugin WCPOS, siga estes passos:

1. Visite a página do WordPress.org [Visualização Avançada](https://wordpress.org/plugins/woocommerce-pos/advanced/) para o WCPOS.

2. Role a página até a seção **Opções Avançadas** e localize o menu suspenso **Versões Anteriores**.

3. Abra o menu suspenso para ver a lista de versões disponíveis do plugin. Encontre a versão que deseja instalar e clique no botão **Baixar** ao lado dela. Salve o arquivo baixado na área de trabalho ou em outro local conveniente.

4. Entre no painel de administração do WordPress.

5. Acesse a página **Plugins** clicando em **Plugins** no menu à esquerda.

6. Desative e exclua a versão atual do plugin WCPOS. Isso removerá o plugin da instalação do WordPress. Não se preocupe: seus dados não serão perdidos.

7. Clique no botão **Adicionar Plugin** no topo da página.

8. Na página **Adicionar Plugins**, clique no botão **Enviar Plugin**.

9. Selecione o arquivo do plugin que você baixou anteriormente na área de trabalho ou no local onde o salvou.

10. Clique no botão **Instalar Agora** e aguarde a conclusão da instalação.

11. Quando a instalação terminar, clique no botão **Ativar** para ativar a versão anterior do plugin WCPOS.

Pronto! Você reinstalou com sucesso uma versão anterior do plugin WCPOS.

Se encontrar algum problema durante a reinstalação ou precisar de mais ajuda, entre em contato com nossa equipe de suporte pelo endereço support@wcpos.com.
