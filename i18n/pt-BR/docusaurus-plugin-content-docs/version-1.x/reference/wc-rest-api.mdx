A **API REST do WooCommerce** é como um conjunto de “canais” padronizados que permite que proprietários de lojas conectem sua loja WooCommerce a outros aplicativos e serviços.

Veja uma explicação simples de como funciona:

1. Ela funciona como uma ponte entre sua loja WooCommerce e aplicativos externos, permitindo que eles se comuniquem e compartilhem dados.

2. A API funciona enviando solicitações a **endpoints** específicos — pense neles como “canais” para diferentes tipos de dados da loja. Por exemplo, há endpoints para produtos, pedidos e clientes.

3. Aplicativos externos podem usar esses endpoints para:

- Obter informações (como buscar uma lista de produtos)
- Adicionar novos dados (como criar um pedido)
- Atualizar informações existentes (como alterar o preço de um produto)
- Excluir dados (como remover um produto desatualizado)

Em vez de depender de hooks e filtros do PHP (como muitos plugins tradicionais do WordPress fazem), ela funciona enviando e recebendo dados em um formato estruturado e previsível, conhecido como **JSON**.

## Por que alguns plugins não funcionam no PDV? {#why-dont-some-plugins-work-in-the-pos}

O WCPOS baixa os dados de produtos, pedidos e clientes da sua loja WooCommerce pela API REST.
Em seguida, mantém uma cópia local desses dados para continuar funcionando mesmo quando sua conexão com a internet estiver instável.
Essa abordagem torna o PDV mais rápido e confiável em um ambiente de caixa movimentado.

No entanto, isso significa que nosso PDV não “vê” em tempo real as alterações dinâmicas feitas no seu site. Por exemplo:

  <tr>
    <th style={{ width: "200px" }}>Tipo de plugin</th>

      personalizado.
    </td>
  </tr>
  <tr>
    <td>Complementos de produto</td>
    <td>
      Se outro plugin da sua loja adicionar dados extras ao produto, o PDV não
      receberá esses dados automaticamente. O PDV recebe apenas os dados expostos
      pela API REST.
    </td>
  </tr>
</table>
