## Wat dit betekent {#what-this-means}

De server blokkeert de toestemmingscontrole van de browser (CORS-preflight), waardoor de webapp de server niet kan bereiken.

Browsers sturen een OPTIONS-verzoek vóór elke cross-origin API-aanroep met aangepaste headers. Iets vóór deze winkel — meestal een firewallregel — blokkeert OPTIONS, waardoor de browser het eigenlijke verzoek nooit verstuurt. Native apps hebben hier geen last van; de oplossing ligt aan de serverkant.

## Je gegevens {#your-data}

Er zijn geen bestel- of productgegevens aangetast.

## Problemen oplossen {#troubleshoot}

1. Controleer of de firewall (WAF) een regel heeft die de OPTIONS-methode blokkeert en sta deze methode toe op /wcpos/ REST-routes.
2. Sommige beveiligingsplugins hebben een schakelaar voor ‘ongebruikelijke verzoekmethoden blokkeren’. OPTIONS moet toegestaan blijven.
3. Test: een OPTIONS-verzoek naar de REST API van de winkel mag geen 403 teruggeven.
4. De desktop- en mobiele apps gebruiken geen CORS en blijven werken terwijl dit wordt opgelost.
