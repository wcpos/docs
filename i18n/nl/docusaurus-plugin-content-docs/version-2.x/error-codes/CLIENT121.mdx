## Wat dit betekent {#what-this-means}

In deze browser kan maar één tabblad tegelijk wijzigingen versturen.

WCPOS geeft deze code niet meer: de POS draait maar in één tabblad. In een tweede tabblad verschijnt **De POS is geopend in een ander tabblad**. Druk op **Hier overnemen** om in dat tabblad verder te gaan, of ga terug naar het eerste tabblad. Zie [Als de POS niet start](../getting-started/index.mdx#wont-start).

## Je gegevens {#your-data}

Bestel- en productgegevens blijven ongewijzigd.

## Probleem oplossen {#troubleshoot}

1. Gebruik de POS in één tabblad. Verschijnt **De POS is geopend in een ander tabblad**, druk dan op **Hier overnemen** om daar verder te gaan.
2. Deze browser (of een privévenster) heeft de functie voor tabbladcoördinatie die de POS bij voorkeur gebruikt niet. Daarom wordt teruggevallen op één tabblad dat synchroniseert. Je hoeft niets op te lossen.
