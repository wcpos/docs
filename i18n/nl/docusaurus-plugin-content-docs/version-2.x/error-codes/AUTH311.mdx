## Wat dit betekent {#what-this-means}

WCPOS kan het verbindingspunt op je winkel niet bereiken.

Vraag je sitebeheerder te controleren of de WCPOS-plug-in actief is (**WP Admin → Plugins**) en of er geen beveiligingsplug-in is die de REST API blokkeert.

## Je gegevens {#your-data}

Bestel- en productgegevens blijven onaangetast. Meld dit bij je sitebeheerder.

## Problemen oplossen {#troubleshoot}

**Bij de kassa** — voor de kassamedewerker: meld dit bij je sitebeheerder. Alles op dit apparaat blijft onaangetast.

**In de winkel** — voor de sitebeheerder:

1. Controleer of WCPOS actief is: WP Admin → Plugins.
2. Als geen van beide REST-varianten werkt, controleer dan of een beveiligingsplug-in, proxy of CDN headers uit WCPOS-verzoeken verwijdert of REST-verzoeken blokkeert — meestal zijn firewallregels of beveiligingsopties die de REST API uitschakelen de oorzaak.
3. Bij sommige hostingproviders worden ontbrekende REST-routes hersteld door de permalinks opnieuw op te slaan (Instellingen → Permalinks → Wijzigingen opslaan).
