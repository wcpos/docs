## Wat dit betekent {#what-this-means}

Het inlogtoken is groter dan deze server accepteert.

De server heeft het inlogtoken geweigerd vanwege de grootte: een 400 als het via de Authorization-header wordt verzonden, of een 414 als het via de URL wordt verzonden. Geen enkele codering aan de clientzijde kan het verkleinen — de serverlimieten voor de header- of URL-grootte moeten worden verhoogd, of het token moet kleiner worden gemaakt.

## Je gegevens {#your-data}

Er zijn geen bestel- of productgegevens aangetast.

## Problemen oplossen {#troubleshoot}

1. Verhoog op Apache LimitRequestFieldSize (bij verzending via de header) of LimitRequestLine (bij verzending via de URL) in de vhost-configuratie.
2. Verhoog op nginx large_client_header_buffers.
3. Bij een proxy of CDN kan de limiet op die laag zitten — controleer beide.
4. Als de limieten niet kunnen worden gewijzigd, neem dan contact op met support over het uitgeven van een kleiner token voor deze site.
