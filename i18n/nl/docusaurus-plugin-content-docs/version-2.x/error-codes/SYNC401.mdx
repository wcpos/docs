## Wat dit betekent {#what-this-means}

Een synchronisatietaak op de achtergrond is onverwacht gestopt voordat deze was voltooid.

Je hoeft niets te doen — de POS start deze taken automatisch opnieuw en er gaat niets verloren. Als deze code blijft verschijnen, gebruik dan **Debuginfo kopiëren** op het tabblad **Logboeken** en neem contact op met ondersteuning.

## Je gegevens {#your-data}

Er gaat niets verloren — bestel- en productgegevens worden niet beïnvloed. Als dit aanhoudt, gebruik dan **Debuginfo kopiëren** op het tabblad **Logboeken** en neem contact op met WCPOS-ondersteuning.

## Problemen oplossen {#troubleshoot}

1. Je hoeft niets te doen als je dit voor het eerst ziet: de POS start de gecrashte achtergrondtaak automatisch opnieuw en er zijn geen bestelgegevens bij betrokken.
2. Als de code binnen enkele minuten opnieuw verschijnt, herlaad de app dan één keer zodat het synchronisatieproces opnieuw begint.
3. Als de code blijft terugkomen, gebruik dan **Debuginfo kopiëren** op het tabblad **Logboeken** en neem contact op met ondersteuning — een taak die herhaaldelijk crasht wijst op een fout in de app die het melden waard is, niet op een probleem met de winkel.
