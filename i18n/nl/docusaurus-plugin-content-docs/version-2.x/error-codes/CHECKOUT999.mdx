## Wat dit betekent {#what-this-means}

Er is een onverwacht probleem opgetreden bij het afrekenen.

Controleer de bestelling in het beheer van je winkel voordat je de klant opnieuw laat betalen. Exporteer diagnostische gegevens en neem contact op met support als het probleem zich opnieuw voordoet.

## Je gegevens {#your-data}

De uitkomst kon niet worden bevestigd — controleer deze voordat je het opnieuw probeert. Blijft dit probleem optreden, exporteer dan diagnostische gegevens en neem contact op met WCPOS-support.

## Probleem oplossen {#troubleshoot}

1. Controleer in WP Admin bij WooCommerce → Bestellingen of de bestelling bestaat voordat je de klant opnieuw laat betalen.
2. Vouw de logvermelding uit en noteer de eventcode en eventuele serverCode. Deze algemene code betekent dat er nog geen specifieke code voor de oorzaak is.
3. Keert het probleem terug, exporteer dan de debuggegevens en neem contact op met support.
