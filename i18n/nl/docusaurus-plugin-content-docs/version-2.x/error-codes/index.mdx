# Foutcodes {#error-codes}

Wanneer WCPOS een probleem tegenkomt, verschijnt er een foutcode die helpt om het probleem te herkennen. Vanaf **v1.10.0** hebben codes de vorm **domein + drie cijfers** — bijvoorbeeld `SYNC131` of `AUTH311`. Het domein geeft aan om welk onderdeel van de POS het gaat; het nummer duidt de specifieke situatie aan. Elke code heeft een eigen pagina met uitleg over de betekenis, wat je kunt doen en de gevolgen voor je gegevens.

In de POS staan foutcodes onder **Winkelstatus → Logboeken**: vouw een rij uit en gebruik de link **Help** om rechtstreeks naar de pagina van die code te gaan.

## Foutdomeinen (v1.10.0+) {#error-domains}

| Domein | Onderdeel |
|--------|------|
| [`AUTH`](#auth) | Inloggen, sessies en tokens |
| [`CHECKOUT`](#checkout) | Bestellingen afronden aan de kassa |
| [`CLIENT`](#client) | De POS-app zelf en lokale opslag |
| [`DISPLAY`](#display) | Het klantenscherm |
| [`HOST`](#host) | Hosting en firewallregels die de POS blokkeren |
| [`LICENSE`](#license) | Activering en validatie van de Pro-licentie |
| [`PAYMENT`](#payment) | Betaalgateways en betaalterminals |
| [`PRINT`](#print) | Bonnen afdrukken |
| [`PRODUCT`](#product) | Productgegevens en catalogusbewerkingen |
| [`REGISTER`](#register) | Kassalade, kassasessies en tellingen |
| [`SYNC`](#sync) | Synchronisatie tussen de POS en je winkel |

Zoek je code hieronder of gebruik de zoekfunctie.

Codes die eindigen op `999` zijn de algemene codes van het domein voor situaties waarvoor nog geen specifieke code bestaat.

## Codes van vóór v1.10.0 {#legacy-codes}

Codes zoals `API04001` komen uit versies van vóór v1.10.0; deze versie geeft ze nooit weer als nieuwe fout. Je kunt ze nog wel tegenkomen in een logboekvermelding die van vóór je upgrade bewaard is gebleven, of in een oud ondersteuningsgesprek. Zet het versiemenu op **1.x** om ze op te zoeken.
