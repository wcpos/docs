## Wat dit betekent {#what-this-means}

Er is een onverwacht probleem opgetreden bij het synchroniseren.

Controleer of de handeling in deze vermelding is voltooid; zo niet, herhaal deze dan. Als dit opnieuw gebeurt, tik dan op **Debuginfo kopiëren** en stuur de informatie naar ondersteuning.

## Je gegevens {#your-data}

Wis de gegevens van dit apparaat niet — er kunnen wijzigingen op staan die je winkel nog niet heeft. Als de handeling in de vermelding niet is voltooid, herhaal deze dan.

## Problemen oplossen {#troubleshoot}

1. Vouw de logboekvermelding uit en zoek de genoemde handeling. Controleer of deze is voltooid — open bij een opslagactie de bestelling of record en controleer of de wijziging zichtbaar is. Als dat zo is, verzendt WCPOS deze vanzelf en hoef je niets te doen.
2. Herhaal de handeling als deze niet is voltooid. Als de logboekvermelding aangeeft dat de wijziging nooit op dit apparaat is opgeslagen, is er niets vastgelegd.
3. Noteer de code en een eventuele reden in de logboekvermelding: een 999-code betekent dat er nog geen aparte code is voor de specifieke oorzaak, dus deze context is precies wat ondersteuning nodig heeft.
4. Als dit opnieuw gebeurt, tik dan op **Debuginfo kopiëren** op het tabblad **Logboeken** en stuur de informatie naar ondersteuning — door het te melden help je ervoor te zorgen dat er een specifieke code wordt toegevoegd.
