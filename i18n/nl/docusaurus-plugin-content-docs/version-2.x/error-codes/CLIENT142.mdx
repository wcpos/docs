## Wat dit betekent {#what-this-means}

De zoekindex reageerde niet op tijd, dus heeft WCPOS rechtstreeks in de catalogus gezocht.

De lokale zoekindex werd nog opgebouwd of kon niet reageren. Op het web komt dit meestal doordat het POS-tabblad op de achtergrond staat. Op desktop en mobiel gebeurt dit meestal direct na een grote synchronisatie of vlak nadat de app opnieuw is gestart, terwijl de opgeslagen index weer wordt geladen. Zoekopdrachten worden nog steeds beantwoord door de gegevens op dit apparaat rechtstreeks te doorzoeken. Zodra de index weer reageert, wordt deze automatisch opnieuw gebruikt.

## Je gegevens {#your-data}

Er zijn geen winkelgegevens gewijzigd en je zoekopdracht is nog steeds beantwoord: de gegevens op dit apparaat zijn rechtstreeks doorzocht in plaats van de index te gebruiken. Zoekopdrachten kunnen tijdelijk iets trager worden beantwoord totdat de index weer wordt gebruikt.

## Probleem oplossen {#troubleshoot}

1. Meestal hoef je niets te doen: de zoekresultaten blijven werken en zodra de index weer reageert, neemt deze vanzelf het zoeken over.
2. Houd de POS op het web in een eigen venster in plaats van in een tabblad op de achtergrond.
3. Blijven zoekopdrachten traag of verschijnt deze code steeds opnieuw? Laad de app dan één keer opnieuw. Laad op het web het browsertabblad opnieuw; sluit en open de app op desktop en mobiel opnieuw.
4. Keert de code daarna nog steeds terug, exporteer dan de debuggegevens en neem contact op met support.
