## Wat dit betekent {#what-this-means}

De REST API van de winkel heeft op geen enkele adresvorm die deze app kan gebruiken geantwoord.

De app heeft de REST API van de winkel geprobeerd via het normale adres (/wp-json/...) en via het ingebouwde alternatieve adres van WordPress (/?rest_route=...), maar geen van beide gaf antwoord. De website van de winkel zelf kan wel bereikbaar zijn — specifiek de REST API is onbereikbaar, meestal doordat een beveiligingsplugin deze verbergt of een firewallregel deze blokkeert.

## Je gegevens {#your-data}

Er zijn geen bestel- of productgegevens aangetast.

## Problemen oplossen {#troubleshoot}

**In de winkel** — voor de sitebeheerder: als een beveiligingsplugin `/wp-json/` verbergt of hernoemt (bijvoorbeeld WP Hide), sta dan ook de ingebouwde `/?rest_route=`-vorm van WordPress toe — de app valt daar automatisch op terug.

**Bij de hostingprovider / op de server:**

1. Controleer de firewallregels (WAF) op alles wat overeenkomt met `wp-json` of `rest_route` en laat de eigen REST API van de winkel door.
2. Als de server achter een onderhoudspagina of botcontrole staat, krijgen REST-verzoeken mogelijk een HTML-pagina als antwoord — schakel de controle uit voor de REST API.

**Om te testen (voor iedereen):** `https://your-store.com/?rest_route=/` moet JSON teruggeven, geen 403-pagina of de homepage van de site.
