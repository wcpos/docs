**WP admin:** schakel de knop **Bon** voor online bestellingen in via `WP Admin → POS → Settings → General`.

:::note Deze pagina is bedoeld voor de beheerder van de website
Met [WCPOS Pro](../getting-started/pro-license.mdx) kun je aan de kassa een bon afdrukken of e-mailen voor elke bestelling, ook voor online bestellingen: zie [Een bon opnieuw afdrukken](../orders/index.mdx#receipt-reprinting) op de pagina **Bestellingen**.
:::

:::tip Als een klant om de bon van een online bestelling vraagt
Zodra dit op de website is ingesteld, kan de klant de knop **Bon** gebruiken in **Mijn account → Bestellingen**, of een link naar de bon op de bestelbevestigingspagina als de winkel die heeft toegevoegd.
:::

Je WCPOS-bonsjablonen werken ook op je website. Een klant die online heeft gekocht, kan de bon als PDF downloaden vanuit **Mijn account**, of via een link die je op de bestelbevestigingspagina plaatst.

## De knop Bon inschakelen {#my-account}

:::warning Activeer eerst een bonsjabloon
Activeer een sjabloon via **POS → Sjablonen** voordat je begint. Zonder actief sjabloon zien klanten de knop **Bon** niet, ook niet als de instelling is ingeschakeld. Zie [Je bon aanpassen](./customise.mdx#option-1--pick-a-different-template).
:::

De knop is uitgeschakeld totdat je deze inschakelt. De PDF wordt gemaakt op basis van je bonsjabloon.

1. Ga in WP Admin naar **POS → Instellingen → Algemeen**.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="WP Admin met POS, Instellingen geselecteerd in het menu en Algemeen geopend in het instellingenmenu, met Winkels, Kassa en het begin van Producten in beeld">

1. **POS → Instellingen** — het menu-item in WP Admin voor de POS-instellingen.
2. **Algemeen** — het eerste instellingenscherm, dat meteen geopend is.

</JourneyShot>

2. Scrol omlaag naar het gedeelte **Klanten** en schakel **Klanten bonnen laten downloaden** in. De wijziging wordt direct opgeslagen.

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="Het gedeelte Klanten van Algemeen: Gebruikersnaam automatisch genereren op basis van het e-mailadres van de klant, Standaard POS-klant ingesteld op Gast en Klanten bonnen laten downloaden, hier nog uitgeschakeld">

1. **Klanten** — het gedeelte met de instelling voor bonnen.
2. **Klanten bonnen laten downloaden** — uitgeschakeld totdat je deze optie inschakelt.

</JourneyShot>

3. Daaronder verschijnt **Bonsjabloon voor klanten**. Laat deze optie op **Actief bonsjabloon gebruiken** staan of kies een sjabloon. Zie [Het sjabloon voor klanten kiezen](#template-choice).

Een ingelogde klant ziet nu een knop **Bon** naast de bestellingen in **Mijn account → Bestellingen**. Hiermee downloadt de klant een PDF met een bestandsnaam op basis van de bestelling, zoals `receipt-1234.pdf`.

De knop verschijnt alleen voor bestellingen die zijn betaald:

| Bestelstatus | Knop Bon |
|---|---|
| **In behandeling** | Ja |
| **Afgerond** | Ja |
| **Terugbetaald** | Ja |
| Elke andere status, zoals **In afwachting van betaling**, **In de wacht**, **Geannuleerd** of **Mislukt** | Nee |

Een ontwikkelaar kan [wijzigen bij welke statussen de knop verschijnt](#developers).

## Het sjabloon voor klanten kiezen {#template-choice}

**Bonsjabloon voor klanten** bepaalt welk sjabloon voor de download wordt gebruikt.

- **Actief bonsjabloon gebruiken** (de standaardinstelling): klanten krijgen je actieve bonsjabloon uit **POS → Sjablonen**. Als je het daar wijzigt, gebruiken hun downloads voortaan ook het gewijzigde sjabloon.
- **Een specifiek sjabloon**: klanten krijgen altijd dat sjabloon, ongeacht wat de kassamedewerker aan de kassa kiest. Gebruik dit als er meerdere bonsjablonen actief zijn, of om online bestellingen een eigen opmaak te geven.

Een smal sjabloon voor thermische bonnen levert een smalle PDF op. Voor online bestellingen is een volledige pagina meestal beter leesbaar: het sjabloon **Factuur** in de galerij is gemaakt voor papier van het formaat A4 en Letter. Zie [Je bon aanpassen](./customise.mdx#option-1--pick-a-different-template) om het toe te voegen.

De PDF wordt gevuld met dezelfde [bongegevens](./receipt-data.mdx) als de kassabon, dus je logo, winkelgegevens en belastinginstellingen worden overgenomen.

Als een gekozen sjabloon later wordt verwijderd of de publicatie ervan ongedaan wordt gemaakt, toont de keuzelijst **Sjabloon niet beschikbaar** en krijgen klanten in plaats daarvan je actieve bonsjabloon. Kies een ander sjabloon.

## Een link naar de bon toevoegen aan de bestelbevestigingspagina {#shortcode}

Geef klanten een link **Bon downloaden (PDF)** op de bedankpagina die ze na het afrekenen zien. Gasten die zonder account hebben afgerekend, krijgen hun bon op deze manier.

Als je WP Admin de optie **Weergave → Editor → Templates → Bestelbevestiging** heeft, kun je de link zelf op de bedankpagina plaatsen:

1. Ga in WP Admin naar **Weergave → Editor → Templates** en open **Bestelbevestiging**.
2. Voeg een **Shortcode**-blok toe waar je de link wilt hebben en typ daarin `[wcpos_receipt]`.
3. Klik op **Opslaan**.

Als je dat sjabloon niet hebt, of als je de link op de pagina van een bestelling in **Mijn account** wilt plaatsen, vraag dan een ontwikkelaar om [de link naar de bon via code toe te voegen](#developers).

De shortcode werkt ongeacht of **Klanten bonnen laten downloaden** is ingeschakeld: die instelling bepaalt alleen of de knop in **Mijn account → Bestellingen** verschijnt.

<details>
<summary>Opties en voorbeelden voor de shortcode</summary>

`[wcpos_receipt]` werkt op de bestelbevestigingspagina en op de pagina van een bestelling in **Mijn account**. Daar vindt de shortcode de bestelling automatisch, dus je hoeft geen bestelnummer in te voeren. Op andere pagina's wordt niets weergegeven, tenzij je een `order_id` opgeeft.

| Optie | Standaard | Functie |
|---|---|---|
| `order_id` | *(gevonden op de pagina)* | Link naar één bestelling, op elke gewenste pagina. Alleen zichtbaar voor de ingelogde klant bij wie die bestelling hoort. |
| `link_text` | `Download receipt (PDF)` | De tekst van de link. |
| `format` | `pdf` | Met `pdf` wordt een PDF gedownload. Met `html` wordt de bon in de browser geopend, klaar om af te drukken. |
| `template` | *(je actieve bonsjabloon)* | Gebruik in plaats daarvan dit sjabloon. |
| `class` | `wcpos-receipt-link` | CSS-klasse van de link. |
| `id` | *(geen)* | HTML-`id` van de link. |

De optie `template` van de shortcode negeert **Bonsjabloon voor klanten**: laat je deze optie weg, dan gebruikt de link je actieve bonsjabloon.

Een downloadlink met je eigen tekst:

```text
[wcpos_receipt link_text="Download your invoice"]
```

De bon openen in de browser in plaats van een PDF te downloaden:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

Een specifiek sjabloon gebruiken, bijvoorbeeld een A4-factuur in plaats van je kassabon van 80mm:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

Het sjabloonnummer staat in de adresbalk wanneer je het sjabloon bewerkt via **POS → Sjablonen** (`post=123`). Een niet-gepubliceerd sjabloon wordt genegeerd; de link gebruikt dan je actieve bonsjabloon.

</details>

## Wie een bon kan openen {#security}

- **Klanten met een account** loggen in en gebruiken de knop **Bon** in **Mijn account → Bestellingen**.
- **Gasten** die zonder account hebben afgerekend, gebruiken de link naar de bon op hun bestelbevestigingspagina, zodra je [die daar hebt geplaatst](#shortcode).

:::warning Deel links naar bonnen alleen met de klant
Iedereen met een link naar een bon kan die bon openen zonder in te loggen. Ga er net zo zorgvuldig mee om als met de bestelling zelf.
:::

<details>
<summary>Hoe links naar bonnen worden beveiligd</summary>

Elke link naar een bon bevat de privésleutel van de bestelling, dezelfde sleutel die WooCommerce op de bestelbevestigingspagina gebruikt. Zonder de juiste sleutel kan de bon niet worden geopend. Een shortcode met de optie `order_id` toont de link alleen aan de ingelogde klant bij wie die bestelling hoort.

</details>

## Als er iets misgaat {#goes-wrong}

De meeste oplossingen hieronder voer je uit in WP Admin. Ben je kassamedewerker, geef de melding die de klant ziet dan door aan de beheerder van de website. Ondertussen kun je met [WCPOS Pro](../getting-started/pro-license.mdx) de bon aan de kassa afdrukken of e-mailen: zie [Een bon opnieuw afdrukken](../orders/index.mdx#receipt-reprinting) op de pagina **Bestellingen**.

**De klant ziet geen knop Bon.** Controleer of **Klanten bonnen laten downloaden** is ingeschakeld, of de bestelling de status **In behandeling**, **Afgerond** of **Terugbetaald** heeft en of er minstens één bonsjabloon actief is in **POS → Sjablonen**. De knop verschijnt alleen in **Mijn account → Bestellingen**, voor een ingelogde klant.

**"Er is geen bonsjabloon ingesteld."** Er is geen sjabloon beschikbaar om de PDF te maken. Activeer een bonsjabloon via **POS → Sjablonen**.

**"Je hebt geen toestemming om deze bon te bekijken."** De link is onvolledig of verkeerd gekopieerd: elke link bevat een privésleutel voor de bijbehorende bestelling. Stuur de klant opnieuw de link vanaf de bevestigingspagina of vanuit **Mijn account**.

**"De PDF van de bon kon niet worden gegenereerd."** De PDF kon niet op basis van het sjabloon worden gemaakt. Open het sjabloon via **POS → Sjablonen** en bekijk het voorbeeld. Zie [Je bon aanpassen](./customise.mdx).

**De link geeft de foutmelding "Pagina niet gevonden".** Ga in WP Admin naar **Instellingen → Permalinks** en kies een andere optie dan **Standaard**. Links naar bonnen werken niet met **Standaard**.

## Voor ontwikkelaars {#developers}

<details>
<summary>De link naar de bon via code toevoegen</summary>

Bij een klassiek thema kun je de link weergeven via de twee WooCommerce-acties die deze pagina's opbouwen:

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

De shortcode vindt de bestelling op beide pagina's, dus een `order_id` is niet nodig.

</details>

<details>
<summary>Filters voor de knop Bon en het PDF-sjabloon</summary>

Drie filters vullen de bovenstaande instellingen aan voor regels die je niet via de instellingen kunt vastleggen, bijvoorbeeld per bestelling of per klant:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

Vóór WCPOS 2.0 heetten deze filters `woocommerce_pos_storefront_receipt_*`. Die namen werken nog, maar zijn sinds 2.0 verouderd en worden op zijn vroegst in 2.2 verwijderd. Zie [Naamgeving van hooks](../extensions/index.mdx#hook-naming).

Het PDF-adres is `/wcpos-checkout/wcpos-receipt/{order_id}` met `?key={order_key}&format=pdf`: hetzelfde met een sleutel beveiligde bonadres dat de POS gebruikt, waarbij `format=pdf` een PDF teruggeeft in plaats van de pagina.

</details>
