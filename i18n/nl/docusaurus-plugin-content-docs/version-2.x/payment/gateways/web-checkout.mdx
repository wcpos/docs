# Web Checkout-betaalgateway {#web-checkout-gateway}

:::info Pro-functie
Je hebt [WCPOS Pro](../../getting-started/free-vs-pro.mdx) nodig om betalingen met Web Checkout te ontvangen.
:::

Met Web Checkout kan de klant een POS-bestelling betalen op de eigen betaalpagina van je webwinkel, met de betaalmethoden die je webwinkel aanbiedt, zoals een online formulier voor kaartbetalingen of een digitale portemonnee. Gebruik dit wanneer de klant wil betalen met een methode die de kassa niet ondersteunt.

Ga direct naar: [Een betaling ontvangen](#take-payment) · [Instellen](#set-up) · [Als er iets misgaat](#goes-wrong)

## Een betaling ontvangen {#take-payment}

Web Checkout staat op het tabblad **Verouderd** van het afrekenscherm. Er is een verbinding nodig en de hele bestelling wordt in rekening gebracht: als er al een betaling is ontvangen, lees dan eerst [Een deel van de bestelling is al betaald](#split).

:::warning Houd het afrekenscherm open totdat je op Betaling verwerken drukt
De kassa houdt het andere tabblad niet in de gaten. De verkoop wordt pas afgerond wanneer je op **Betaling verwerken** drukt bij een bestelling die de klant heeft betaald. Houd het afrekenscherm dus open terwijl de klant betaalt.
:::

1. Voer de verkoop zoals gewoonlijk in en druk op **Afrekenen**.
2. Open het tabblad **Verouderd**. De betaalpagina van je winkel wordt binnen de POS geladen.
3. Kies **Web Checkout**. Daaronder verschijnen de bijbehorende toelichting en een link **Deze bestelling betalen**.
4. Druk op **Deze bestelling betalen**. De betaalpagina van je webwinkel voor deze bestelling wordt geopend in een nieuw browsertabblad; in de desktop-app wordt deze geopend in de webbrowser van je computer.
5. Geef de klant het scherm. De klant kiest een betaalmethode en betaalt, net als op je website.
6. Als de klant heeft betaald, verschijnt de bestelbevestiging van je winkel op het tabblad. Laat dat tabblad open en ga terug naar de POS.
7. Druk op **Betaling verwerken**. Als de bestelling is betaald, toont de kassa het scherm voor een geslaagde betaling en de bon, net als bij elke verkoop. Zo niet, dan blijft de kassa op deze pagina: zie [Als er iets misgaat](#goes-wrong).
8. Sluit het tabblad van de klant zodra de kassa de bon toont.

### Een deel van de bestelling is al betaald {#split}

Een verouderde betaalgateway brengt de hele bestelling in rekening. Zodra er een betaling is ontvangen, toont het tabblad Verouderd daarom **Een verouderde betaalgateway kan niet worden gebruikt zodra er een betaling is ontvangen**. Je hebt twee mogelijkheden:

- **Ontvang het resterende bedrag via een tegel**, zoals Contant of Kaart, op het tabblad Betalingen. Zie [Gesplitste betalingen](../../pos/checkout/split-payments.mdx).
- **Annuleer de tot nu toe ontvangen betalingen** en gebruik daarna Web Checkout voor de hele bestelling. Voordat er iets wordt teruggedraaid, toont de kassa wat er met elke betaling gebeurt: contant geld gaat terug naar de klant, andere betalingen worden via hun betaalmethode geannuleerd en een betaling die niet kan worden geannuleerd, wordt vanuit de bestelling terugbetaald. Zie [Een betaling annuleren](../../pos/checkout/cancelling-a-payment.mdx).

:::tip De klant wil later op de eigen telefoon betalen
Web Checkout opent de betaalpagina op het apparaat waarop de POS draait. Gebruik [Factuur per e-mail](./email-invoice.mdx) om de klant een link te sturen waarmee die later kan betalen.
:::

## Instellen {#set-up}

Iemand die je winkel in WP Admin beheert, doet dit eenmalig vóór de eerste verkoop via Web Checkout. Web Checkout is een gratis plugin, maar de POS biedt deze alleen aan met WCPOS Pro; zonder Pro accepteert de kassa Contant en Kaart. De plugin gebruikt de betaalmethoden die je webwinkel al heeft. Je hebt geen account of sleutels nodig.

<details>
<summary>Winkelbeheerder: installeren en inschakelen</summary>

1. **Installeer de plugin.** Web Checkout staat niet onder `WP Admin > POS > Settings > Extensions`. Download **woocommerce-pos-web-checkout-gateway.zip** (niet het zipbestand met de broncode) van de [GitHub-releasepagina](https://github.com/wcpos/web-checkout-gateway/releases), upload het via `WP Admin > Plugins > Add Plugin` en vervolgens **Plugin uploaden**, en activeer het.
2. **Schakel de plugin in voor de POS.** Schakel **Web Checkout** in onder `WP Admin > POS > Settings > Checkout` en sla op. Zie [Kassa-instellingen](../../settings/wp-admin/checkout.mdx#enabling-a-gateway). De plugin verschijnt nooit bij het afrekenen in je webwinkel: klanten bereiken deze alleen via de POS.
3. **Controleer je online betaalmethoden.** De klant betaalt met een van de methoden die voor het web zijn ingeschakeld onder `WP Admin > WooCommerce > Settings > Payments`. Minstens één methode moet klaar zijn om betalingen te ontvangen.

</details>

<details>
<summary>De naam of melding wijzigen</summary>

De naam en toelichting op de betaalpagina zijn de **Titel** en **Beschrijving** van de betaalgateway onder `WP Admin > WooCommerce > Settings > Payments > Web Checkout Gateway`. De standaardtoelichting luidt: “Ga naar de afrekenpagina om de bestelling te betalen. Klik na de betaling op de knop Betaling verwerken om door te gaan naar de bon.” Wil je de naam alleen voor de POS wijzigen, pas dan de **Titel** aan onder **POS-instellingen** in het menu **⋮** van de betaalgateway in [Kassa-instellingen](../../settings/wp-admin/checkout.mdx#payment-gateways); de toelichting komt altijd uit WooCommerce.

</details>

<details>
<summary>Voor ontwikkelaars: zo werkt het</summary>

De plugin voegt een WooCommerce-betaalgateway toe met de ID `wcpos_web_checkout`. In de code is deze uitgeschakeld voor het online afrekenen, zodat alleen de POS deze kan aanbieden. De betaalvelden tonen de beschrijving en een link naar de eigen betaal-URL van de bestelling (`$order->get_checkout_payment_url()`), die in een nieuw venster wordt geopend.

De betaalgateway ontvangt zelf geen geld. Wanneer **Betaling verwerken** een al betaalde, door de POS aangemaakte bestelling verstuurt waarvoor `wcpos_web_checkout` is gekozen, stuurt de plugin de betaalpagina door naar de pagina voor ontvangen bestellingen. Van daaruit rondt de POS de verkoop af. Een onbetaalde bestelling gaat niet verder. De broncode staat in de [web-checkout-gateway-repository](https://github.com/wcpos/web-checkout-gateway).

</details>

## Als er iets misgaat {#goes-wrong}

**Web Checkout staat niet in de lijst op het tabblad Verouderd.** De plugin is niet actief of Web Checkout is niet ingeschakeld in [Kassa-instellingen](../../settings/wp-admin/checkout.mdx#enabling-a-gateway). Zonder WCPOS Pro biedt de POS alleen Contant en Kaart aan.

**“Er zijn geen verouderde betaalgateways ingeschakeld voor de POS.”** Er is geen betaalgateway zonder tegel ingeschakeld. Schakel Web Checkout in bij Kassa-instellingen.

**Betaling verwerken gaat niet verder naar de bon.** De bestelling staat in de winkel niet als betaald geregistreerd. Bekijk het tabblad van de klant voordat je vraagt om opnieuw te betalen: als de betaalpagina nog wordt getoond, is de betaling nog niet afgerond. Als de bestelbevestiging wordt getoond, druk dan opnieuw op **Betaling verwerken**. Gaat de kassa nog steeds niet verder, controleer dan de bestelling onder `WP Admin > WooCommerce > Orders`.

**Op de betaalpagina verschijnt geen betaalmethode die de klant kan gebruiken.** Je webwinkel heeft geen geschikte methode ingeschakeld. Schakel er een in voor het web onder `WP Admin > WooCommerce > Settings > Payments`.

**De betaalpagina binnen de POS wordt niet goed weergegeven.** Een thema of plugin kan de weergave verstoren. Zie [De betaalpagina van een betaalgateway wordt niet goed weergegeven](../../pos/checkout/troubleshooting.mdx#checkout-settings-troubleshooting).
