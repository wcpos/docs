De afdruksjablonen voor POS-bonnen bevinden zich in het bestand `includes/views/print/tmpl-receipt.php` van zowel de gratis als de Pro-plugin. U kunt bonsjablonen aanpassen door een bestand `woocommerce-pos/print/tmpl-receipt.php` in uw themamap aan te maken. De code voor beide sjablonen staat hieronder.

### De datum op de bon aanpassen {#customising-the-receipt-date}

WCPOS gebruikt [moment.js](http://momentjs.com/) om datumweergaven te lokaliseren. De standaarddatumnotatie is `"MMMM Do YYYY, h:mm:ss a"`, bijvoorbeeld: 31 mei 2015, 7:20:44 pm. Raadpleeg de [documentatie van moment.js](http://momentjs.com/docs/#/parsing/string-format/) voor meer informatie over het aanpassen van de datumnotatie.

### Besteleigenschappen {#order-properties}

WCPOS gebruikt de JSON-uitvoer van de WC REST API om het sjabloon voor de bestelbon te vullen. [De documentatie van de WC REST API toont een voorbeeld](https://developer.woocommerce.com/docs/apis/rest-api/) van de standaard JSON-uitvoer. WCPOS heeft enkele aanvullende eigenschappen toegevoegd via het filter `woocommerce_api_order_response`.

| Eigenschap                        | Beschrijving                                                  |
| --------------------------------- | ------------------------------------------------------------- |
| cart_discount_tax                 | Het belastingdeel van de winkelwagenkorting                   |
| cashier.id                        | Gebruikers-ID van de kassamedewerker                          |
| cashier.first_name                | Voornaam van de kassamedewerker                               |
| cashier.last_name                 | Achternaam van de kassamedewerker                             |
| payment_details.result            | Geslaagde of mislukte betaling via de betaalgateway          |
| payment_details.message           | Eventuele berichten van de betaalgateway                      |
| payment_details.redirect          | Omleidings-URL voor externe betalingen, bijvoorbeeld: PayPal Standard |
| payment_details.method\_`gateway` | Gatewayspecifieke berichten, bijvoorbeeld: ontvangen bedrag en wisselgeld |
| shipping_lines[i].total_tax       | Voeg het belastingbedrag voor elke verzendregel toe           |
| subtotal_tax                      | Het belastingdeel van het subtotaal                           |
