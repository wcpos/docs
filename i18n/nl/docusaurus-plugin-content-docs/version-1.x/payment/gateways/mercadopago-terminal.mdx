# Mercado Pago Terminal-gateway {#mercado-pago-terminal-gateway}

Met de Mercado Pago Terminal-gateway kun je vanuit WCPOS betalingen ter plaatse ontvangen op Mercado Pago Point Smart-terminals. Een betaling wordt gestart vanuit WooCommerce en op de terminal voltooid; de bevestiging van Mercado Pago wordt vervolgens bij de bestelling opgeslagen.

:::info Nieuw in 0.1.0
Mercado Pago Terminal for WooCommerce is een nieuwe extensie en 0.1.0 is de eerste release. Beschouw deze als bèta: begin in de modus **Test** met de virtuele sandboxterminal van Mercado Pago en voer een testbetaling uit voordat je echte betalingen accepteert.
:::

## Zo werkt het {#how-it-works}

De gateway gebruikt Mercado Pago's **Orders API for Point** in de cloud. Wanneer je een betaling start, wordt een Mercado Pago-bestelling aangemaakt voor het volledige WooCommerce-bestellingstotaal en naar de geselecteerde terminal gestuurd. De Mercado Pago-bestelling verloopt na **5 minuten**.

De betaalpagina controleert Mercado Pago elke **2 seconden**. De webhook en een **achtergrondcontrole na 5 minuten** kunnen een betaalde bestelling ook voltooien, zelfs als de browser is gesloten. De webhook is optioneel, maar aanbevolen; zonder **Webhook secret** worden meldingen wel verwerkt, maar niet op hun handtekening geverifieerd.

De terminal moet in de modus **PDV (geïntegreerd)** staan. Terminals worden geleverd in de modus **STANDALONE**. Schakel daarom in de gateway-instellingen over naar PDV en start de terminal opnieuw op voordat je betalingen accepteert.

## Configuratie {#setup}

<Steps>
  <StepCard number="1" title="Mercado Pago Terminal for WooCommerce installeren">

Download het **zipbestand van de plugin** (niet het zipbestand met de GitHub-broncode) vanaf de [GitHub-releasespagina](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases). Upload het via `Plugins > Add New > Upload Plugin` en activeer het. WooCommerce moet hiervoor geïnstalleerd en actief zijn.

  </StepCard>
  <StepCard number="2" title="Je Mercado Pago-inloggegevens toevoegen">

1. Ga naar `WP Admin > WooCommerce > Settings > Payments` en open **Mercado Pago Terminal**
2. Kies **Mode**: met `Test` gebruik je de virtuele sandboxterminal; met `Live` gebruik je echte terminals
3. Plak het **Access token** (`APP_USR-…`) van je toepassing uit Mercado Pago → **Your integrations** → **Credentials**

:::warning Controleer je token in de modus Live
Een `TEST-`-token in de modus Live stuurt betalingen naar de sandbox. Het instellingenscherm waarschuwt voor deze combinatie; plak je productietoken voordat je echte betalingen accepteert.
:::

  </StepCard>
  <StepCard number="3" title="De webhook registreren">

1. Ga in Mercado Pago naar **Your integrations** → je toepassing → **Webhooks**
2. Voeg de webhook-URL toe die op het gateway-instellingenscherm wordt weergegeven
3. Selecteer de gebeurtenis **Order (Mercado Pago)** en sla op
4. Kopieer de **secret signature** naar **Webhook secret** in WooCommerce

De webhook is optioneel. Betalingen worden ook zonder webhook voltooid doordat de status periodiek wordt gecontroleerd, maar als je het geheim instelt, kan de plugin webhookhandtekeningen verifiëren.

  </StepCard>
  <StepCard number="4" title="Je terminals instellen">

1. Sla het instellingenscherm op en laad het opnieuw. De vervolgkeuzelijst **Default terminal** en de tabel **Terminals** tonen de terminals in je account
2. Klik bij een terminal die in de modus **STANDALONE** wordt weergegeven op **Switch to PDV** en **start de terminal opnieuw op**
3. Kies een **Default terminal**
4. *(Optioneel)* Beperk **Enabled terminals** tot de apparaten waaruit kassamedewerkers kunnen kiezen. Laat dit leeg om alle terminals toe te staan; de opgeslagen standaardterminal blijft beschikbaar, ook als deze hier niet is geselecteerd
5. *(Optioneel)* Schakel **Lock terminal selection** in om altijd de standaardterminal te gebruiken en te voorkomen dat kassamedewerkers deze kunnen wijzigen. Hiervoor is een standaardterminal vereist
6. Sla je instellingen op

  </StepCard>
  <StepCard number="5" title="Inschakelen in WCPOS" isLast>

1. Ga naar `WP Admin > POS > Settings > Checkout`
2. Zoek de gateway **Mercado Pago Terminal** en schakel deze in voor de POS
3. Sla je instellingen op

:::note
Het selectievakje **Enable/Disable** op het WooCommerce-instellingenscherm bepaalt alleen het afrekenen in de *webwinkel*. WCPOS gebruikt deze gateway zodra deze is geconfigureerd, ongeacht of het selectievakje is aangevinkt.
:::

  </StepCard>
</Steps>

## Instellingenoverzicht {#settings}

| Instelling | Beschrijving |
|---|---|
| **Enable/Disable** | Schakelt de gateway in voor afrekenen in de webwinkel. Inschakelen voor de POS regel je via `POS > Settings > Checkout` |
| **Title** | Het label bij het afrekenen; standaard `Mercado Pago Terminal` |
| **Description** | De beschrijving bij het afrekenen; standaard `Pay in person on a Mercado Pago Point terminal.` |
| **Mode** | `Test` (standaard) gebruikt de virtuele sandboxterminal; `Live` gebruikt echte terminals met live inloggegevens |
| **Access token** | Het token van je toepassing in Mercado Pago → Your integrations → Credentials. Een opgeslagen token wordt niet opnieuw getoond; laat dit leeg om het te behouden |
| **Webhook secret** | De geheime handtekening uit de webhookinstellingen van Mercado Pago, gebruikt om meldingen te verifiëren |
| **Default terminal** | De terminal die standaard wordt gebruikt bij het afrekenen, live opgehaald uit je account. Als de lijst niet kan worden opgehaald, verschijnt er een tekstveld |
| **Enabled terminals** | Beperkt de terminals waaruit kassamedewerkers kunnen kiezen. Leeg betekent dat alle terminals zijn toegestaan; de standaardterminal is altijd beschikbaar. Verborgen als de lijst niet kan worden geladen |
| **Lock terminal selection** | Gebruikt altijd de standaardterminal, zodat kassamedewerkers deze niet kunnen wijzigen. Een standaardterminal is vereist |
| **Checkout debug logs** | Toont **Show logs**, **Copy** en **Clear** in het betaalvenster. Standaard uitgeschakeld; schakel dit in wanneer je logs verzamelt voor ondersteuning |
| **Log level** | `Off`, `Errors only` of `Debug`. In deze release standaard ingesteld op Debug; verzoeken en antwoorden worden vastgelegd zonder geheimen |

Onder de velden toont de tabel **Mercado Pago Terminal diagnostics** de API-controle (inclusief het aantal terminals en PDV's), de laatst geverifieerde webhook, de actieve omgeving, of inloggegevens zijn ingesteld, de standaardterminal, de webhook-URL en een link naar de betalingslogs.

## Gebruik {#usage}

### Betalingen verwerken {#processing-payments}

1. **Producten toevoegen**: voeg producten toe aan je winkelwagen in de POS
2. **Gateway selecteren**: kies **Mercado Pago Terminal** als betaalmethode
3. **Terminal kiezen**: selecteer een terminal of gebruik de standaardterminal als de selectie is vergrendeld
4. **Betaling starten**: klik op **Start Terminal Payment** om het bestellingstotaal naar de terminal te sturen
5. **Betaling door de klant**: volg de statusmeldingen — `Sending to terminal…` → `Waiting for terminal…` → `Customer is paying on the terminal…` — terwijl de klant de betaling op de terminal voltooit
6. **Automatische voltooiing**: zodra Mercado Pago de betaling bevestigt, wordt de bestelling voltooid en gaat de POS naar de bon

### Betalingsopties {#payment-controls}

- **Start Terminal Payment**: stuur een nieuw betalingsverzoek naar de geselecteerde terminal
- **Cancel Terminal Payment**: annuleer alleen voordat de terminal de betaling heeft opgehaald. Annuleer daarna op de terminal of wacht tot deze na **5 minuten** verloopt
- **De pagina opnieuw laden**: hervat een betaling die al bezig is

### Bonnen {#receipts}

De terminal drukt geen bon af. Gebruik de POS-bon nadat de betaling is voltooid.

## Terugbetalingen {#refunds}

Open het terugbetalingsscherm van de WooCommerce-bestelling en kies **Refund via Mercado Pago Terminal** om een volledige of gedeeltelijke terugbetaling uit te voeren. Mercado Pago staat terugbetalingen toe tot **90 dagen** na de betaling.

Sommige kaartverwerkers staan terugbetalingen alleen op de terminal toe. Voer in dat geval de terugbetaling uit op de terminal en registreer een **handmatige terugbetaling** in WooCommerce.

## Logs en ondersteuningspakket {#logs-and-support-bundle}

Je vindt logs in `WooCommerce > Status > Logs` onder de bron `mercadopago-terminal`. Het logniveau is in deze release standaard ingesteld op **Debug**. Verzoeken, antwoorden, webhooks en wijzigingen in de betalingsstatus worden vastgelegd; geheimen en kaartnummers worden onleesbaar gemaakt.

Klik op **Download support bundle** op het gateway-instellingenscherm om een `.txt`-bestand te downloaden en aan je ondersteuningsverzoek toe te voegen. Het bevat omgevingsgegevens, instellingen met afgeschermde inloggegevens, de terminallijst en bedrijfsmodi, betalingspogingen van de 10 meest recente bestellingen en de laatste 500 logregels; je kunt er geen betalingen mee uitvoeren.

Schakel **Checkout debug logs** in om **Show logs**, **Copy** en **Clear** aan het betaalvenster toe te voegen. Betalingsactiviteit wordt ongeacht deze instelling vastgelegd in de WooCommerce-logs.

## Reikwijdte en beperkingen {#scope-and-limitations}

- Op de terminal wordt het **volledige bestellingstotaal** in rekening gebracht. Slechts een deel van een bestelling op de terminal betalen wordt niet ondersteund
- Fooien worden niet ondersteund
- Bedragen worden verzonden met **twee decimalen**. Winkels die Chileense of Colombiaanse peso's gebruiken, moeten eerst een testbetaling uitvoeren
- De **Blocks-afrekenfunctie** van de webwinkel wordt niet ondersteund
- De plugin geeft nog geen **HPOS-compatibiliteit** aan

## Problemen oplossen {#troubleshooting}

### Veelvoorkomende problemen {#common-issues}

<Accordion>
  <AccordionItem question="Toegangstoken geweigerd door Mercado Pago (HTTP 401)">

  - Het toegangstoken is ongeldig of verouderd
  - Kopieer een nieuw token uit **Your integrations** → **Credentials** en sla het op bij **Access token**

  </AccordionItem>
  <AccordionItem question="Er worden geen terminals weergegeven">

  - Als er geen Point-terminals aan het account zijn gekoppeld, log je op de terminal in met dat Mercado Pago-account, schakel je over naar PDV en start je de terminal opnieuw op
  - Als **Default terminal** een tekstveld is in plaats van een vervolgkeuzelijst, kon de lijst niet worden opgehaald. Controleer het token en de diagnostiek en laad vervolgens het instellingenscherm opnieuw

  </AccordionItem>
  <AccordionItem question="De terminal staat in de modus STANDALONE">

  - Voor geïntegreerde betalingen is de modus **PDV** vereist
  - Klik op **Switch to PDV** in de tabel **Terminals** van het instellingenscherm en start de terminal vervolgens opnieuw op

  </AccordionItem>
  <AccordionItem question="De betaling staat al op de terminal">

  - De terminal heeft de betaling ontvangen, dus deze kan niet meer vanuit WooCommerce worden geannuleerd
  - Annuleer de betaling op de terminal of wacht tot deze na **5 minuten** verloopt. De betaalpagina blijft de status controleren

  </AccordionItem>
  <AccordionItem question="De webhook is nooit geverifieerd">

  - Controleer de webhook-URL en het geheim in Mercado Pago als de diagnostiek **Last verified webhook: never** toont
  - Als **Webhook secret** ontbreekt, plak dan de **secret signature** van Mercado Pago. Betalingen worden nog steeds voltooid doordat de status periodiek wordt gecontroleerd, maar meldingen zonder het geheim worden niet op hun handtekening geverifieerd

  </AccordionItem>
  <AccordionItem question="De kaartverwerker heeft de terugbetaling geweigerd">

  - Sommige kaartverwerkers staan terugbetalingen alleen op de terminal toe; Mercado Pago beperkt terugbetalingen bovendien tot **90 dagen**
  - Voer de terugbetaling uit op de terminal en registreer een **handmatige terugbetaling** in WooCommerce

  </AccordionItem>
  <AccordionItem question="De betaling is verlopen op de terminal">

  - Mercado Pago-bestellingen verlopen na **5 minuten**
  - Start de betaling opnieuw

  </AccordionItem>
</Accordion>
