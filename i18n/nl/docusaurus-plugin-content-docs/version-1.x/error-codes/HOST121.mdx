## Wat dit betekent {#what-this-means}

Een botbeveiligingspagina antwoordt in plaats van de API van de winkel.

De REST API van de winkel retourneert een HTML-controlepagina (botbeveiliging, CAPTCHA of DDoS-tussenpagina) waar de app JSON verwacht. Een kassa-app kan zo'n browsercontrole niet oplossen; de REST API van de winkel moet op de lijst met toegestane paden van de beveiligingsdienst worden gezet.

## Je gegevens {#your-data}

Er zijn geen bestel- of productgegevens getroffen.

## Probleemoplossing {#troubleshoot}

1. Bepaal aan de hand van de controlepagina welke beveiligingsdienst wordt gebruikt (Cloudflare, Sucuri, Kinsta en andere diensten tonen elk hun eigen merk) en open de instellingen ervan.
2. Sta de eigen REST API-paden van de winkel (/wp-json/ en /?rest_route=) toe voor API-verkeer.
3. Voeg in Cloudflare een WAF-regel **Skip** toe voor de REST API-paden; Bot Fight Mode (gratis abonnement) kan met geen enkele regel worden omzeild en moet worden uitgeschakeld. De [Cloudflare-handleiding](/1.x/support/troubleshooting/cloudflare) bevat de exacte regel en een `curl`-controle.
4. Sta de REST API-paden toe in de bot-/firewallinstellingen van Kinsta; vermijd bij Sucuri de DDoS-modus met JavaScript-controle voor API-routes.
