## Wat dit betekent {#what-this-means}

Bij het synchroniseren is een onverwacht probleem opgetreden.

Controleer of de genoemde actie in deze vermelding is voltooid; zo niet, voer deze dan opnieuw uit. Gebeurt dit opnieuw, tik dan op **Copy debug info** en stuur de gegevens naar support.

## Je gegevens {#your-data}

Wis de gegevens op dit apparaat niet — er kunnen wijzigingen op staan die je winkel nog niet heeft. Is de genoemde actie in de vermelding niet voltooid, voer deze dan opnieuw uit.

## Probleemoplossing {#troubleshoot}

1. Vouw de logvermelding uit en zoek op welke actie erin wordt genoemd. Controleer of deze is voltooid — open bij een opslagactie de bestelling of het record en kijk of de wijziging zichtbaar is. Is dat zo, dan verstuurt WCPOS deze vanzelf; laat de vermelding staan.
2. Is de actie niet voltooid, voer deze dan opnieuw uit. Staat in de logvermelding dat de wijziging nooit op dit apparaat is opgeslagen, dan is er niets vastgelegd.
3. Noteer de code en eventuele reden in de logvermelding: een code 999 betekent dat er nog geen aparte code voor de specifieke oorzaak bestaat. Deze context is daarom precies wat support nodig heeft.
4. Gebeurt dit opnieuw, tik dan op **Copy debug info** op het tabblad **Logs** en stuur de gegevens naar support — door dit te melden kan er een specifieke code worden toegevoegd.
