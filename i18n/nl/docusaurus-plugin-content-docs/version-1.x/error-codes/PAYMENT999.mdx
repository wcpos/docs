## Wat dit betekent {#what-this-means}

Bij het verwerken van de betaling is een onverwacht probleem opgetreden.

Stel vast of de betaling is doorgekomen voordat je het opnieuw probeert. Exporteer diagnostische gegevens en neem contact op met support als het onduidelijk is.

## Je gegevens {#your-data}

De uitkomst kon niet worden bevestigd — controleer dit voordat je het opnieuw probeert. Als dit aanhoudt, exporteer dan diagnostische gegevens en neem contact op met WCPOS-support.

## Probleemoplossing {#troubleshoot}

1. Stel vast of de betaling is doorgekomen voordat je het opnieuw probeert: via het scherm van de terminal, het dashboard van de provider en de bestelling in WP Admin.
2. Vouw de logvermelding uit voor de gebeurteniscode en de context — deze algemene code betekent dat de oorzaak nog geen eigen code heeft.
3. Als de uitkomst onduidelijk blijft of de code terugkeert, exporteer dan de debug-info en neem contact op met support.
