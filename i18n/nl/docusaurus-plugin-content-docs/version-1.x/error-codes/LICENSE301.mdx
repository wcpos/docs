## Wat dit betekent {#what-this-means}

De updater is niet geautoriseerd om WCPOS Pro-updates te downloaden.

Autoriseer de updater opnieuw voor deze winkel en controleer daarna opnieuw op updates.

## Je gegevens {#your-data}

Er zijn geen bestel- of productgegevens getroffen. Als dit aanhoudt, vraag dan de persoon die je WordPress-site beheert.

## Probleemoplossing {#troubleshoot}

1. Voer de licentiesleutel opnieuw in of activeer deze opnieuw in de POS-instellingen, zodat de updater zich kan authenticeren.
2. Controleer opnieuw op updates via WP Admin → Dashboard → Updates.
3. Als de autorisatie blijft mislukken, blokkeert de site mogelijk uitgaande verzoeken naar de updateserver — vraag de host of uitgaand HTTPS beperkt is.
