## Wat dit betekent {#what-this-means}

Een synchronisatietaak op de achtergrond is onverwacht gestopt voordat deze klaar was.

Je hoeft niets te doen — de POS start deze taken automatisch opnieuw en er gaat niets verloren. Blijft deze code verschijnen, gebruik dan **Copy debug info** op het tabblad **Logs** en neem contact op met support.

## Je gegevens {#your-data}

Er gaat niets verloren — bestel- en productgegevens worden niet beïnvloed. Als dit aanhoudt, gebruik dan **Copy debug info** op het tabblad **Logs** en neem contact op met WCPOS-support.

## Probleemoplossing {#troubleshoot}

1. In eerste instantie hoef je niets te doen: de POS start de gecrashte achtergrondtaak automatisch opnieuw en er zijn geen bestelgegevens bij betrokken.
2. Als de code zich binnen enkele minuten herhaalt, herlaad de app dan één keer zodat de synchronisatie-engine schoon start.
3. Als dit zich daarna nog steeds herhaalt, gebruik dan **Copy debug info** op het tabblad **Logs** en neem contact op met support — een terugkerende taakcrash is een defect in de app dat het melden waard is, geen probleem met de winkel.
