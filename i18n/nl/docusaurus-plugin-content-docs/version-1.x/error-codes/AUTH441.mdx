## Wat dit betekent {#what-this-means}

Het inlogtoken is groter dan deze server accepteert.

De server weigerde het inlogtoken vanwege de grootte: een 400 wanneer het in de Authorization-header reist, of een 414 wanneer het in de URL reist. Geen enkele codering aan de clientzijde kan het verkleinen — de header-/URL-groottelimieten van de server moeten worden verhoogd, of het token moet kleiner worden gemaakt.

## Je gegevens {#your-data}

Er zijn geen bestel- of productgegevens getroffen.

## Probleemoplossing {#troubleshoot}

1. Verhoog op Apache LimitRequestFieldSize (headerpad) of LimitRequestLine (URL-pad) in de vhost-configuratie.
2. Verhoog op nginx large_client_header_buffers.
3. Achter een proxy of CDN kan de limiet op die laag liggen — controleer beide.
4. Als de limieten niet kunnen worden gewijzigd, neem dan contact op met support over het uitgeven van een kleiner token voor deze site.
