# Foutcodes

Wanneer WCPOS een probleem tegenkomt, wordt er een foutcode weergegeven die helpt het probleem te identificeren. Vanaf **v1.10.0** volgen codes het formaat **domein + drie cijfers** — bijvoorbeeld `SYNC131` of `AUTH311`. Het domein benoemt het gebied van de POS; het nummer identificeert de specifieke situatie. Elke code heeft een eigen pagina met wat de code betekent, wat je moet doen en wat het betekent voor je gegevens.

In de POS verschijnen foutcodes in **Winkelstatus → Logs**: vouw een rij uit en gebruik de link **Help** om direct naar de pagina van de code hier te springen.

## Foutdomeinen (v1.10.0+) {#error-domains}

| Domein | Gebied | Voorbeelden |
|--------|------|---------|
| `AUTH` | Inloggen, sessies en tokens | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | Bestellingen afronden aan de kassa | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | De POS-app zelf en de lokale opslag | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `LICENSE` | Activatie en validatie van de Pro-licentie | [LICENSE101](./LICENSE101) |
| `PAYMENT` | Betalingsgateways en -terminals | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | Kassabonnen afdrukken | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | Productgegevens en cataloguswerkzaamheden | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `SYNC` | Synchronisatie tussen de POS en je winkel | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

Gebruik de zijbalk om alle codes in een domein te bekijken, of zoek rechtstreeks naar de code.

Codes die eindigen op `999` zijn de vangnetcode van het domein voor situaties die nog geen specifieke code hebben.

## Oudere codes (van vóór v1.10.0) {#legacy-codes}

Versies van vóór v1.10.0 gebruikten een ander schema: `[DOMAIN][CATEGORY][SPECIFIC_CODE]`, bijv. `API04001` = API (domein) + 04 (responsfouten) + 001 (ongeldig responsformaat). Als je een oudere versie gebruikt, of een oude logboekvermelding of ondersteuningsdraad leest, gelden deze pagina's nog steeds:

| Domein | Totaal aantal codes | Waarover |
|--------|-------------|---------------|
| [API](./api) | 39 codes | Servercommunicatie, authenticatie, pluginproblemen |
| [DB](./db) | 9 codes | Lokaal opslaan en ophalen van gegevens |
| [PY](./py) | 6 codes | Betalingsverwerking |
| [SY](./sy) | 5 codes | Apparaatbronnen en configuratie |

Een client van v1.10.0 of hoger geeft deze codes nooit af — zie je er toch een op een bijgewerkte POS, dan komt die uit een oude bewaarde logboekvermelding of uit een bericht van de server.
