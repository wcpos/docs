# Foutcodes {#error-codes}

Wanneer WCPOS een probleem tegenkomt, wordt een foutcode weergegeven waarmee je het probleem kunt identificeren. Vanaf **v1.10.0** hebben codes de vorm **domein + drie cijfers** — bijvoorbeeld `SYNC131` of `AUTH311`. De domeinnaam geeft het POS-onderdeel aan; het getal identificeert de specifieke situatie. Elke code heeft een eigen pagina met uitleg, stappen om het probleem op te lossen en informatie over de gevolgen voor je gegevens.

In het POS verschijnen foutcodes onder **Winkelstatus → Logs**: vouw een regel uit en gebruik de link **Help** om direct naar de pagina van de code te gaan.

## Foutdomeinen (v1.10.0+) {#error-domains}

| Domein | Onderdeel | Voorbeelden |
|--------|------|----------|
| `AUTH` | Aanmelden, sessies en tokens | [AUTH101](./AUTH101.mdx), [AUTH311](./AUTH311.mdx) |
| `CHECKOUT` | Bestellingen afrekenen aan de kassa | [CHECKOUT101](./CHECKOUT101.mdx), [CHECKOUT201](./CHECKOUT201.mdx) |
| `CLIENT` | De POS-app zelf en lokale opslag | [CLIENT101](./CLIENT101.mdx), [CLIENT201](./CLIENT201.mdx) |
| `HOST` | Hosting- en firewallregels die de POS blokkeren | [HOST101](./HOST101.mdx), [HOST121](./HOST121.mdx) |
| `LICENSE` | Activering en validatie van de Pro-licentie | [LICENSE101](./LICENSE101.mdx) |
| `PAYMENT` | Betaalmethoden en terminals | [PAYMENT101](./PAYMENT101.mdx), [PAYMENT301](./PAYMENT301.mdx) |
| `PRINT` | Bonnen afdrukken | [PRINT101](./PRINT101.mdx), [PRINT301](./PRINT301.mdx) |
| `PRODUCT` | Productgegevens en catalogusbewerkingen | [PRODUCT101](./PRODUCT101.mdx), [PRODUCT401](./PRODUCT401.mdx) |
| `SYNC` | Synchronisatie tussen het POS en je winkel | [SYNC101](./SYNC101.mdx), [SYNC121](./SYNC121.mdx), [SYNC311](./SYNC311.mdx) |

Gebruik de zijbalk om alle codes in een domein te bekijken, of zoek de code direct op.

Codes die eindigen op `999` zijn de algemene code van het domein voor situaties waarvoor nog geen specifieke code bestaat.

## Oude codes (vóór v1.10.0) {#legacy-codes}

Versies vóór v1.10.0 gebruikten een ander schema: `[DOMAIN][CATEGORY][SPECIFIC_CODE]`, bijvoorbeeld `API04001` = API (domein) + 04 (antwoordfouten) + 001 (ongeldig antwoordformaat). Gebruik je een oudere versie of lees je een oud logboekitem of supportgesprek, dan zijn deze pagina's nog van toepassing:

| Domein | Totaal aantal codes | Betreft |
|--------|-------------|---------------|
| [API](./api.mdx) | 39 codes | Servercommunicatie, authenticatie, pluginproblemen |
| [DB](./db.mdx) | 9 codes | Lokale gegevensopslag en ophalen van gegevens |
| [PY](./py.mdx) | 6 codes | Betalingsverwerking |
| [SY](./sy.mdx) | 5 codes | Apparaatbronnen en configuratie |

Een client met v1.10.0 of hoger genereert deze codes nooit — zie je er een op een bijgewerkt POS, dan komt deze uit een oud bewaard logboekitem of een serverbericht.
