WCPOS ondersteunt extensies die nieuwe functionaliteit toevoegen aan je verkooppunt. Met de extensiedirectory kun je beschikbare extensies bekijken, ze rechtstreeks vanuit de POS-instellingen installeren en updates beheren.

:::info Pro-functie
Het installeren en beheren van extensies vereist [WCPOS Pro](/1.x/getting-started/pro-license). De gratis versie toont de extensiecatalogus, maar schakelt de installatie- en activeringsknoppen uit.
:::

## Door extensies bladeren {#browsing-extensions}

Open de extensiedirectory via `POS Settings > Extensions` (in sommige versies ook aangeduid als **Plugins**).

De directory toont een raster van kaarten met beschikbare extensies. Elke kaart toont:

- **Pictogram** (of een puzzelstukje als de extensie geen pictogram aanlevert)
- **Naam en versie**
- **Beschrijving**
- **Categoriebadge**
- **Status** — actief, inactief, update beschikbaar of niet geïnstalleerd

### Filteren en zoeken {#filtering-and-search}

Gebruik de **categoriepilknoppen** bovenaan om extensies op categorie te filteren. Je kunt ook het **zoekveld** gebruiken om extensies te vinden op naam, beschrijving of tags.

## Een extensie installeren {#installing-an-extension}

1. Open `POS Settings > Extensions`.
2. Zoek de gewenste extensie en klik op **Install**.
3. De extensie wordt gedownload en geïnstalleerd met het installatieprogramma voor WordPress-plugins.
4. Klik na de installatie op **Activate** om de extensie in te schakelen.

Achter de schermen gebruikt WCPOS de ingebouwde `Plugin_Upgrader` van WordPress om de installatie af te handelen. Extensies volgen dus hetzelfde proces als elke andere WordPress-plugin.

## Activeren en deactiveren {#activating-and-deactivating}

Elke geïnstalleerde extensie heeft de knoppen **Activate** en **Deactivate** op de bijbehorende kaart.

- **Activate** schakelt de extensie in zodat deze in de POS kan werken.
- **Deactivate** schakelt de extensie uit zonder deze te verwijderen. De extensiebestanden blijven op je server staan en je kunt de extensie op elk moment opnieuw activeren.

## Extensies bijwerken {#updating-extensions}

Wanneer er een nieuwere versie van een geïnstalleerde extensie beschikbaar is, toont de kaart een **Update Available**-badge en een **Update**-knop.

### Automatische updates {#auto-updates}

Voor extensies die vanuit de directory zijn geïnstalleerd, zijn **automatische updates standaard ingeschakeld**. Je kunt automatische updates per extensie in- of uitschakelen via de bijbehorende kaart in de directory. Wanneer automatische updates aanstaan, past WordPress nieuwe versies automatisch toe, net zoals bij plugins waarvoor automatische updates zijn ingeschakeld.

## Probleemoplossing {#troubleshooting}

### Melding ‘Pro vereist’ op knoppen {#requires-pro-message-on-buttons}

De knoppen voor installeren, activeren en bijwerken zijn uitgeschakeld in de gratis versie van WCPOS. Upgrade naar [WCPOS Pro](/1.x/getting-started/pro-license) om extensies te beheren.

### Extensie kan niet worden geïnstalleerd {#extension-fails-to-install}

- Controleer of je WordPress-server schrijfrechten heeft voor de map `wp-content/plugins`.
- Controleer of je server uitgaande HTTPS-aanvragen kan doen (sommige hosts blokkeren externe downloads).
- Bekijk de foutdetails in `WP Admin > POS > Support > Logs`.

### Extensie verschijnt niet na installatie {#extension-not-appearing-after-install}

- Vernieuw de POS — de extensielijst wordt maximaal 12 uur in de cache bewaard.
- Controleer of de extensie is geactiveerd (geïnstalleerde maar inactieve extensies werken niet).

### Catalogus laadt niet {#catalog-not-loading}

De extensiecatalogus wordt opgehaald uit een externe bron en lokaal 12 uur in de cache bewaard. Als de catalogus niet laadt:

- Controleer de internetverbinding van je server.
- Probeer het opnieuw nadat de cache is verlopen, of wis de transiëntcache van je server.

## Voor ontwikkelaars {#for-developers}

### Een POS-extensie maken {#creating-a-pos-extension}

Een WCPOS-extensie is een standaard WordPress-plugin die via WCPOS-hooks en -API's integreert met de POS. Zo maak je er een:

1. **Begin met een WordPress-plugin.** Je extensie heeft een standaard plugin-header en startbestand nodig, net als elke WooCommerce- of WordPress-plugin.
2. **Integreer met WCPOS.** Gebruik de hooks en filters van WCPOS om functionaliteit toe te voegen aan de POS-interface of backend.
3. **Host releases op GitHub.** De extensiedirectory gebruikt GitHub Releases om versies bij te houden en updates te leveren.

### Indienen bij de directory {#submitting-to-the-directory}

De extensiecatalogus wordt beheerd in de GitHub-repository [`wcpos/extensions`](https://github.com/wcpos/extensions). Zo laat je je extensie opnemen:

1. Bekijk het catalogusformaat en de metadatavereisten in de README van de repository.
2. Open een pull request om de metadata van je extensie toe te voegen aan `catalog.json`.
3. Nadat de pull request is samengevoegd, verschijnt je extensie in de directory voor alle WCPOS Pro-gebruikers.

### Conventies voor GitHub-releases {#github-release-conventions}

De updatecyclus berust op GitHub Releases:

- **Tag versies** met semantische versionering (bijv. `v1.0.0`, `v1.2.3`).
- **Voeg de plugin-zip toe** als release-asset — dit is het bestand dat wordt gedownload wanneer een gebruiker de extensie installeert of bijwerkt.
- **Publiceer de release** (niet als concept) zodat de directory deze kan detecteren.

Wanneer je een nieuwe release publiceert, zien gebruikers die je extensie hebben geïnstalleerd de beschikbare update in hun extensiedirectory. Als automatische updates zijn ingeschakeld, wordt deze automatisch toegepast.

Zie de repository [`wcpos/extensions`](https://github.com/wcpos/extensions) voor alle details over het catalogusschema en het indieningsproces.
