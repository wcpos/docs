## Was das bedeutet {#what-this-means}

Ihr Shop hat einen übermittelten Wert abgelehnt.

Die Begründung des Shops nennt den Wert. Korrigieren Sie ihn dort, wo Sie ihn eingegeben haben, und speichern Sie erneut. Normalerweise gehört der Wert zu einem Datensatz — einem Produkt, Kunden oder einer Bestellung. Dieser Code kann jedoch auch durch eine abgelehnte Einstellungs- oder Anmeldeanfrage entstehen. Korrigieren Sie ihn dann in der entsprechenden Ansicht.

## Ihre Daten {#your-data}

Löschen Sie die Daten dieses Geräts nicht — sie können Änderungen enthalten, die in Ihrem Shop noch nicht vorliegen. Eine abgelehnte Bearbeitung eines bestehenden Produkts, einer Variante, eines Kunden oder eines Gutscheins wird normalerweise automatisch rückgängig gemacht und stattdessen als [SYNC202](/error-codes/SYNC202) protokolliert. Wenn dieser Code angezeigt wird und die Änderung unter **Shop-Zustand → Datenbank** aufgeführt ist, wurde sie nicht automatisch rückgängig gemacht. Behandeln Sie sie dann wie jede andere aufgeführte Änderung. Bei einer Einstellungs- oder Anmeldeanfrage bleibt nichts zum Speichern zurück.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie den Protokolleintrag auf und lesen Sie die Begründung des Shops und den Endpunkt: Die Begründung nennt den Wert, und der Endpunkt zeigt, ob er aus einem Datensatz oder einer Einstellungs- oder Anmeldeanfrage stammt.
2. Korrigieren Sie den Wert dort, wo Sie ihn eingegeben haben, und speichern Sie erneut. Häufige Ursachen sind ein Wert außerhalb des zulässigen Bereichs, ein abgelehntes Format oder eine nicht ausgefüllte Pflichtoption. Wenn die Änderung nicht unter **Shop-Zustand → Datenbank** aufgeführt ist, wurde die Version des Shops wiederhergestellt. Nehmen Sie die Änderung daher mit dem korrigierten Wert erneut vor. Wenn sie nach der Korrektur weiterhin unter **„… Änderungen haben Ihren Server nie erreicht“** in **Shop-Zustand → Datenbank** aufgeführt ist, tippen Sie in ihrer Zeile auf **Erneut senden**.
3. Wenn der Datensatz stattdessen unter **„… Änderungen wurden zurückgehalten“** mit dem Hinweis *„Ihr Shop benötigte eine aktuelle Version“* aufgeführt ist, liegt es nicht an einem falschen Wert. Entscheiden Sie sich zwischen **Erneut senden** und **Geräteänderung verwerfen**, wie unter [SYNC221](/error-codes/SYNC221) beschrieben.
4. Wenn es sich um eine Einstellungs- oder Anmeldeanfrage handelte, korrigieren Sie den Wert in der Ansicht, in der Sie ihn eingegeben haben, und speichern Sie erneut. **Website-Administrator:** Die Entwicklertools des Browsers (Registerkarte „Netzwerk“) — oder **Erweitert → Entwicklertools ein-/ausblenden** in der Desktop-App — zeigen die Antwort des Shops, wenn die Details nicht im POS-Protokoll stehen.
5. **Website-Administrator:** Wenn ein genannter Wert im POS korrekt aussieht, vergleichen Sie ihn mit demselben Datensatz in WP Admin. Eine durch Plugins hinzugefügte Validierung im Shop kann Werte ablehnen, die der POS als gültig betrachtet.
