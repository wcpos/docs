## Was das bedeutet {#what-this-means}

In der Suche fehlte ein Produkt, das hätte gefunden werden müssen.

Sie müssen nichts tun, es sei denn, ein sichtbares Produkt erscheint weiterhin nicht in der Suche. Laden Sie WCPOS dann neu.

Bei einer regelmäßigen Selbstprüfung wurde im lokalen Suchindex mit Wörtern aus einem Datensatz nach diesem Datensatz gesucht, doch der Index lieferte ihn nicht zurück. Suchvorgänge haben daher möglicherweise weniger Ergebnisse angezeigt, als tatsächlich auf diesem Gerät vorhanden sind. Die App kann den Index selbstständig neu aufbauen, allerdings nur einmal pro Liste und Sitzung. Ein Neuaufbau ist daher nicht garantiert.

## Ihre Daten {#your-data}

Es wurden keine Shopdaten geändert. Betroffen ist nur der lokale Suchindex, der aus den bereits auf diesem Gerät vorhandenen Daten erstellt wird. Beim Neuaufbau geht nichts verloren.

## Fehlerbehebung {#troubleshoot}

1. Sie müssen nichts tun, solange ein sichtbares Produkt auch in der Suche erscheint. Der Verkauf kann normal weitergehen. Die App kann den Index selbstständig neu aufbauen, allerdings nur einmal pro Liste und Sitzung. Wenn dieser Code erneut auftritt, fahren Sie daher mit dem nächsten Schritt fort.
2. Wenn die Suche weiterhin Datensätze nicht findet, die in der App sichtbar sind — in der Produkt-, Kunden-, Bestellliste oder einer anderen Liste —, laden Sie die App neu: Laden Sie im Web den Browser-Tab neu; schließen und öffnen Sie auf Desktop- und Mobilgeräten die App. Dadurch kann sie beim nächsten Erkennen des Problems einen erneuten Neuaufbau versuchen.
3. Wenn der Code nach dem Neuladen erneut auftritt, wählen Sie **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den Support. Der Protokolleintrag enthält die Angaben, die der Support benötigt, um die betroffene Liste und den vom Index nicht gefundenen Datensatz zu identifizieren.
