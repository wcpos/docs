## Was das bedeutet {#what-this-means}

Ihr Shop ist derzeit nicht erreichbar.

Sie müssen nichts tun — verkaufen Sie weiter. Änderungen werden automatisch gesendet, sobald die Verbindung wiederhergestellt ist. Wenn das Problem anhält, prüfen Sie die Verbindung dieses Geräts und ob sich die Website Ihres Shops laden lässt.

## Ihre Daten {#your-data}

Löschen Sie die Daten dieses Geräts nicht — sie können Änderungen enthalten, die in Ihrem Shop noch nicht vorliegen. Sie werden automatisch gesendet, sobald Ihr Shop antwortet.

## Fehlerbehebung {#troubleshoot}

1. Verkaufen Sie weiter — Verkäufe werden auf diesem Gerät gespeichert und automatisch gesendet, sobald der Shop antwortet.
2. Prüfen Sie, ob das Kassengerät selbst online ist: Lässt sich eine andere Website auf diesem Gerät laden?
3. Öffnen Sie die Website Ihres Shops in einer Browser-Registerkarte auf demselben Gerät. Wenn sie sich auch dort nicht laden lässt, liegt der Ausfall an der Website oder ihrem Hosting, nicht am POS.
4. **Für die Netzwerkverwaltung dieses Geräts:** Wenn die Website lädt, der POS aber offline bleibt, blockiert etwas dazwischen die API-Anfragen — etwa ein VPN, eine Firewall, ein Werbeblocker oder ein Sicherheitsplugin. Die Entwicklertools des Browsers (Registerkarte „Netzwerk“) — oder **Erweitert → Entwicklertools ein-/ausblenden** in der Desktop-App — zeigen, welche Anfrage fehlschlägt.
