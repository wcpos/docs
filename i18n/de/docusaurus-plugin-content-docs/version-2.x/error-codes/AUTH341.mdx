## Was das bedeutet {#what-this-means}

Dieser Shop meldet dieselbe Identität wie ein Shop, der bereits auf diesem Gerät gespeichert ist.

Jeder Shop hat eine Identität, die das WCPOS-Plugin einmalig erstellt. Wenn eine Website kopiert wird, etwa für eine Staging-Website, behält die Kopie die Identität des Originals. Die App kann die beiden daher nicht unterscheiden und lehnt das Speichern des zweiten Shops ab, damit dessen Daten nicht mit denen des ersten vermischt werden.

Eine der beiden Websites ist eine Kopie der anderen. Der Konflikt zeigt nicht, welche: Wenn die Kopie zuerst verbunden wurde, ist der Shop, den Sie gerade hinzufügen wollten, das Original. Die Person, die die Websites verwaltet, weiß, welche kopiert wurde. Diese Website benötigt eine neue Identität.

## Ihre Daten {#your-data}

Die Ablehnung selbst ändert nichts: Der gespeicherte Shop bleibt genau so, wie er war, und der neue Shop wurde nicht gespeichert.

Anders verhält es sich beim Entfernen des gespeicherten Shops, wie in der zweiten Lösung unten beschrieben. Verkäufe dieses Shops, die noch auf die Synchronisierung warten, bleiben auf dem Gerät. Sie werden aber nicht automatisch wieder übernommen, wenn der Shop erneut hinzugefügt wird. Prüfen Sie vor dem Entfernen, ob beim gespeicherten Shop nichts mehr zu synchronisieren ist. Falls doch, wenden Sie sich zuerst an den Support.

## Fehlerbehebung {#troubleshoot}

**Auf der kopierten Website** — für die Person, die diese WordPress-Website verwaltet:

1. Stellen Sie fest, welche der beiden Websites die Kopie ist (meist die Staging- oder Testwebsite).
2. Auf der Kopie: WP Admin → Plugins → WCPOS auf die neueste Version aktualisieren. Ab 1.10.21 gibt das Plugin einer kopierten Website eine eigene Identität, sobald es zum ersten Mal unter ihrer neuen Adresse ausgeführt wird. Eine Aktualisierung des Originals bewirkt hier nichts, da sich dessen Adresse nicht geändert hat.
3. Stellen Sie von der Kasse aus erneut eine Verbindung her.

**An der Kasse** — falls die Kopie noch nicht aktualisiert werden kann:

1. Stellen Sie sicher, dass alle Verkäufe des in der Meldung genannten gespeicherten Shops synchronisiert wurden. Falls noch Verkäufe warten, synchronisieren Sie diese zuerst oder wenden Sie sich an den Support, bevor Sie fortfahren.
2. Entfernen Sie diesen gespeicherten Shop auf dem Verbindungsbildschirm.
3. Verbinden Sie den gewünschten Shop über seine Adresse.

Solange die Kopie keine eigene Identität hat, kann nur einer der beiden Shops verbunden bleiben.

**Wenn beide Adressen auf denselben Shop verweisen** (zum Beispiel eine lokale Netzwerkadresse und die öffentliche Domain): Entfernen Sie den gespeicherten Eintrag und verbinden Sie den Shop erneut über die Adresse, die diese Kasse künftig verwenden soll. Prüfen Sie auch in diesem Fall vor dem Entfernen, ob noch nicht synchronisierte Verkäufe vorhanden sind.
