## Was dies bedeutet {#what-this-means}

WooCommerce ist auf dieser Website nicht aktiv. Deshalb kann WCPOS keine Verbindung herstellen.

WCPOS benötigt das WooCommerce-Plugin. Bitten Sie den Website-Administrator, WooCommerce zu installieren oder erneut zu aktivieren, und stellen Sie anschließend die Verbindung erneut her.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Falls das Problem weiterhin besteht, wenden Sie sich an die Person, die Ihre WordPress-Website verwaltet.

## Fehlerbehebung {#troubleshoot}

1. Bitten Sie den Website-Administrator, unter WP Admin → Plugins nachzusehen: WooCommerce muss installiert und aktiv sein, damit WCPOS eine Verbindung herstellen kann.
2. Wenn WooCommerce durch ein fehlgeschlagenes Update deaktiviert wurde, aktivieren Sie es erneut und achten Sie auf ein Fehlerbanner — unter WooCommerce → Status → Protokolle wird der Grund für den Fehler protokolliert.
3. Sobald WooCommerce wieder aktiv ist, stellen Sie die Verbindung von der Kasse aus erneut her.
