## Was das bedeutet {#what-this-means}

Eine Änderung auf diesem Gerät ist auf eine neuere Bearbeitung in Ihrem Shop gestoßen. Es geht nichts verloren.

Wenn unter **Shop-Zustand → Datenbank** eine zurückgehaltene Änderung für diesen Datensatz aufgeführt ist, tippen Sie auf **Erneut senden**, um die Version dieses Geräts beizubehalten, oder auf **Serverversion verwenden**, um die Version des Shops beizubehalten. Andernfalls müssen Sie nichts tun — der Konflikt wurde bereits gelöst.

## Ihre Daten {#your-data}

Es geht nichts verloren. Wenn eine Änderung zurückgehalten wird, behält Ihr Shop seine Version und dieses Gerät seine Änderung bei, bis Sie entscheiden, welche erhalten bleiben soll. Weitere Bearbeitungen dieses Datensatzes warten bis dahin auf diesem Gerät. Löschen Sie die Daten dieses Geräts nicht, solange eine Änderung zurückgehalten wird — dadurch wird die zurückgehaltene Änderung gelöscht.

## Fehlerbehebung {#troubleshoot}

1. Öffnen Sie **Shop-Zustand → Datenbank**. Eine zurückgehaltene Änderung wird zusammen mit dem zugehörigen Datensatz in einem Bereich aufgeführt, der mit **„1 Änderung wurde zurückgehalten“** (oder **„… Änderungen wurden zurückgehalten“**) beginnt.
2. Wenn für diesen Datensatz keine Änderung mehr zurückgehalten wird, wurde der Konflikt bereits gelöst — hier oder in einer anderen Registerkarte — und Sie müssen nichts tun. Ein Bestellkonflikt, den WCPOS selbst löst, indem es die Version dieses Geräts erneut sendet, wird stattdessen als [SYNC222](/error-codes/SYNC222) protokolliert.
3. Wenn eine Änderung zurückgehalten wird, drücken Sie auf **Datensatz öffnen** (sofern angezeigt), um die Version dieses Geräts anzusehen, und vergleichen Sie sie mit demselben Datensatz in WP Admin. Möglicherweise muss dies ein Website-Administrator übernehmen.
4. Um die Version dieses Geräts beizubehalten, tippen Sie auf **Erneut senden**. Die Änderung wird erneut gesendet und ersetzt die Werte im Shop für die Felder, die dieses Gerät geändert hat. Um die Version des Shops beizubehalten, tippen Sie auf **Serverversion verwenden** (in manchen Zeilen steht **Geräteänderung verwerfen**) und bestätigen Sie. Die Änderung dieses Geräts wird verworfen. Weitere Bearbeitungen dieses Datensatzes warten, bis Sie sich entschieden haben.
5. Häufige Konflikte bei denselben Datensätzen bedeuten meist, dass zwei Personen dieselben Daten gleichzeitig bearbeiten — etwa den Bestand an der Kasse und in WP Admin. Vereinbaren Sie, wo die jeweilige Art von Bearbeitung vorgenommen wird.
