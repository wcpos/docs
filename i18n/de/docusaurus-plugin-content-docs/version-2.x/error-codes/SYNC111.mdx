## Was das bedeutet {#what-this-means}

Einige auf diesem Gerät gespeicherte Daten sind beschädigt und können daher nicht synchronisiert werden.

Tippen Sie oben auf der Registerkarte **Protokolle** auf **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support. Installieren Sie WCPOS nicht neu, melden Sie sich nicht ab und löschen Sie die Daten nicht: Änderungen, die Ihren Shop noch nicht erreicht haben, existieren nur auf diesem Gerät.

## Ihre Daten {#your-data}

Löschen Sie die Daten dieses Geräts nicht — sie können Verkäufe enthalten, die Ihren Shop noch nicht erreicht haben. Auch eine Neuinstallation der App oder eine Abmeldung kann diese löschen. Der Support kann Ihnen sagen, ob sich eine bestimmte Datenart gefahrlos erneut herunterladen lässt.

## Fehlerbehebung {#troubleshoot}

1. Verkaufen Sie weiter, wenn WCPOS noch funktioniert. Installieren Sie es nicht neu, melden Sie sich nicht ab und löschen Sie die Daten nicht.
2. Tippen Sie oben auf der Registerkarte **Protokolle** auf **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support. Beschreiben Sie dabei, was Sie getan haben, als der Eintrag erschien.
3. Öffnen Sie **Shop-Zustand → Datenbank** und teilen Sie dem Support mit, wie viele **Änderungen warten auf das Senden** angezeigt werden und ob ein Bereich **„… Änderungen haben Ihren Server nie erreicht“** oder **„… Änderungen wurden zurückgehalten“** zu sehen ist — diese Änderungen existieren nur auf diesem Gerät.
4. Der Protokolleintrag nennt nicht die beschädigten Daten. Der Support bittet Sie möglicherweise, eine bestimmte Datenart erneut herunterzuladen (über das Menü **⋮** in der entsprechenden Zeile → **Löschen und erneut herunterladen…**), sobald nichts mehr auf das Senden wartet. Tun Sie dies erst, wenn der Support bestätigt hat, welche Datenart gemeint ist: Wenn Sie die falschen Daten löschen oder Daten löschen, während Änderungen noch ausstehen, können Verkäufe verloren gehen, die Ihren Shop nie erreicht haben. Wenn Änderungen wegen der Beschädigung nicht gesendet werden können, stellt der Support sie zuerst wieder her. Laden Sie niemals Daten erneut herunter, solange noch etwas auf das Senden wartet.
