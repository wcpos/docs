## Was das bedeutet {#what-this-means}

WCPOS konnte nicht bestätigen, ob das Terminal die Zahlung eingezogen hat.

Prüfen Sie das Zahlungsterminal, bevor Sie eine erneute Belastung versuchen. Wenden Sie sich an den Zahlungsanbieter, falls das Ergebnis weiterhin unklar ist.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden — prüfen Sie es, bevor Sie es erneut versuchen. Falls das Problem bestehen bleibt, wenden Sie sich an Ihren Zahlungsanbieter.

## Fehlerbehebung {#troubleshoot}

1. Belasten Sie die Karte vorerst nicht erneut.
2. Prüfen Sie zuerst die Anzeige des Terminals und dann das Dashboard Ihres Zahlungsanbieters — der Datensatz des Anbieters ist maßgeblich dafür, ob die Belastung erfolgt ist.
3. Falls Sie Zugriff auf WP Admin haben, prüfen Sie WooCommerce → Bestellungen; andernfalls bitten Sie den Shopinhaber darum. Eine erfolgreiche Zahlung könnte dort bereits erfasst sein.
4. Nehmen Sie die Zahlung erst erneut entgegen, wenn das Dashboard des Anbieters keine Belastung anzeigt.
5. Falls die Belastung als ausstehend oder ungewiss angezeigt wird, wenden Sie sich an den Zahlungsanbieter, bevor Sie handeln.
