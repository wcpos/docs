## Was das bedeutet {#what-this-means}

Mehr als ein Produkt stimmt mit diesem Barcode überein.

WCPOS kann nicht sicher zwischen ihnen wählen, daher wurde nichts hinzugefügt. Suchen Sie das Produkt nach seinem Namen und weisen Sie jedem Produkt im Shop einen eindeutigen Barcode zu, um den Konflikt zu beheben.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Wenn das Problem weiterhin besteht, wenden Sie sich an Ihren Shop-Administrator.

## Fehlerbehebung {#troubleshoot}

1. **An der Kasse:** Der Scan hat nichts hinzugefügt und die Benachrichtigung **Mehrere Treffer** wurde angezeigt. Der gescannte Code steht jetzt im Produktsuchfeld, sodass die Produkte mit diesem Code aufgelistet werden — fügen Sie das richtige manuell hinzu und schließen Sie den Verkauf ab.
2. Entfernen Sie zuerst alle Kategorie- oder Bestandsfilter — sie schränken dieselbe Suche ein und können einige Treffer ausblenden. Notieren Sie anschließend alle Produktnamen in der Liste für die Person, die den Shop verwaltet.
3. **Website-Administrator:** Öffnen Sie in WP Admin jedes dieser Produkte und weisen Sie jedem einen eigenen Barcode zu. Prüfen Sie das Feld, das der Shop für Barcodes verwendet — **WP Admin > POS > Einstellungen > Allgemein > Barcode-Feld** (standardmäßig die GTIN des Produkts, `_global_unique_id`). Ein doppelter Wert in der SKU oder einem anderen Barcode-Feld kann ebenfalls einen Treffer verursachen, prüfen Sie daher auch diese Felder.
4. **Zurück an der Kasse:** Öffnen Sie **Shop-Zustand → Datenbank**, öffnen Sie das Menü **⋮** in der Zeile **Produkte** und wählen Sie **Jetzt auf Änderungen prüfen** — ebenso in der Zeile **Varianten**, falls einer der Treffer eine Variante war. Scannen Sie anschließend erneut. Der Scan sollte das Produkt jetzt direkt hinzufügen.
