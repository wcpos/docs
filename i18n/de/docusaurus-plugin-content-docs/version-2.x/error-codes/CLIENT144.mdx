## Was das bedeutet {#what-this-means}

Der Neuaufbau eines Suchindex ist fehlgeschlagen. Die Ergebnisse können daher unvollständig sein, während die App die Initialisierung erneut versucht.

Nachdem die App ein Problem mit dem Suchindex erkannt hatte ([CLIENT141](/error-codes/CLIENT141) oder [CLIENT143](/error-codes/CLIENT143)), versuchte sie, den Index neu aufzubauen. Dieser Neuaufbau schlug jedoch ebenfalls fehl. Die Suche liefert weiterhin Ergebnisse — aus dem vorhandenen Index, wobei bekannte fehlerhafte Ergebnisse ausgeblendet werden, oder durch direktes Durchsuchen der Daten auf diesem Gerät. Für die betroffene Liste können Ergebnisse jedoch fehlen oder falsch eingeordnet sein. Bei der nächsten Suche oder Bereitschaftsprüfung wird die Initialisierung des Index erneut versucht, wodurch sich das Problem automatisch beheben kann. Wenn die Ergebnisse weiterhin falsch sind, können Sie die App optional neu laden, um von vorn zu beginnen.

## Ihre Daten {#your-data}

Es wurden keine Shopdaten geändert. Betroffen ist nur der lokale Suchindex, der aus den bereits auf diesem Gerät vorhandenen Daten erstellt wird.

## Fehlerbehebung {#troubleshoot}

1. Öffnen Sie den Protokolleintrag. Sein Kontext nennt die betroffene Liste und den beim Neuaufbau aufgetretenen Fehler. Wenn dieser Fehler den Speicher betrifft, geben Sie zuerst Speicherplatz auf dem Gerät frei. Vermeiden Sie im Web außerdem private Fenster bzw. Inkognitofenster.
2. Führen Sie eine weitere Suche in der betroffenen Liste aus. Die App versucht automatisch erneut, den Index zu initialisieren.
3. Wenn weiterhin Ergebnisse fehlen oder falsch sortiert sind, laden Sie die App neu: Laden Sie im Web den Browser-Tab neu; schließen und öffnen Sie auf Desktop- und Mobilgeräten die App. Wenn CLIENT144 danach erneut protokolliert wird, exportieren Sie die Debug-Informationen aus der Ansicht Protokolle und wenden Sie sich an den Support.
