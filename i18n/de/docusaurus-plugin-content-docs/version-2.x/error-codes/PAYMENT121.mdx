## Was das bedeutet {#what-this-means}

Das Terminal hat die Zahlung entgegengenommen und das Geld liegt Ihrem Shop vor. Fehlgeschlagen ist der anschließende Schritt zum Abschließen der Bestellung. Der Verkauf ist also bezahlt, bleibt aber offen.

Dies ist kein Zahlungsproblem. Eine erneute Belastung der Karte würde den Betrag doppelt einziehen. Die Bestellung muss lediglich abgeschlossen werden.

## Ihre Daten {#your-data}

Geld wurde übertragen — die Karte wurde belastet und die Zahlung liegt Ihrem Shop vor. Die Bestellung ist noch offen statt abgeschlossen. Sie muss abgeschlossen, nicht erneut bezahlt werden.

## Fehlerbehebung {#troubleshoot}

**An der Kasse** — erledigen Sie dies, bevor der Kunde geht:

1. Nehmen Sie die Zahlung nicht erneut entgegen und verwenden Sie nicht die Schließen-Schaltfläche (**X**) im Zahlungsbereich — wenn bereits eine Zahlung für die Bestellung vorliegt, öffnet das Schließen **Zahlung stornieren**, wodurch die Zahlung rückgängig gemacht wird.
2. Laden Sie die App neu (im Web den Browser-Tab neu laden; auf Desktop und Mobilgeräten die App schließen und erneut öffnen). Beim Start versucht die Kasse erneut, alle Verkäufe abzuschließen, deren Kartenzahlung sie erfasst hat. Die abgeschlossene Bestellung verschwindet dann aus dem Warenkorb.
3. Falls die Bestellung nach dem Neuladen weiterhin offen im Warenkorb liegt, öffnen Sie **Filialstatus → Datenbank**, öffnen Sie das Menü **⋮** in der Zeile **Bestellungen**, wählen Sie **Jetzt auf Änderungen prüfen** und laden Sie anschließend nochmals neu.
4. Falls sie weiterhin offen ist, bedienen Sie den Kunden und lassen Sie die Bestellung unverändert — die Zahlung wurde entgegengenommen. Bitten Sie die für den Shop zuständige Person, die Bestellung abzuschließen (siehe unten).

**Im Shop** — für den Website-Administrator:

1. Falls sich die Bestellung an der Kasse weiterhin nicht abschließen lässt, öffnen Sie sie unter **WooCommerce → Bestellungen** und überprüfen Sie die Belastung im Dashboard Ihres Zahlungsanbieters. Stellen Sie bei einer aufgeteilten Zahlung sicher, dass jeder Teil bezahlt wurde. Setzen Sie die Bestellung dann auf den Status, den Ihr POS für so bezahlte Verkäufe verwendet: Unter **WP Admin > POS > Einstellungen > Kasse** zeigt die Spalte **Bestellstatus** in der Tabelle **Zahlungsgateways** diesen Status in der Zeile des Zahlungsgateways an, das die Zahlung entgegengenommen hat.
2. Um die Ursache zu ermitteln, klappen Sie **Support-Details** in der Meldung an der Kasse oder den Eintrag unter **Filialstatus → Protokolle** auf. Dort steht, woran der Abschlussschritt gescheitert ist — meist an einer Verbindung, die genau im falschen Moment abgebrochen ist. Geben Sie diese Informationen an, wenn Sie den Support kontaktieren.
