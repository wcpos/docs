## Was das bedeutet {#what-this-means}

Dieses Gerät hat wesentlich häufiger als üblich Daten beim Shop angefordert.

Sie müssen nichts tun — es ist nichts verloren gegangen. Es wurde nichts verlangsamt oder blockiert; diese Warnung meldet lediglich die erkannte Auffälligkeit. Eine anhaltende Flut von Anfragen deutet meist auf ein Problem der App hin (ein Bildschirm fordert in einer Schleife dieselben Daten immer wieder an), nicht auf etwas, das Sie getan haben. Wenn die Meldung wiederholt erscheint, tippen Sie auf **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support, damit die Schleife gefunden und behoben werden kann.

## Ihre Daten {#your-data}

Es ist nichts verloren gegangen — Bestell- und Produktdaten sind nicht betroffen. Wenn das Problem bestehen bleibt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Arbeiten Sie weiter — diese Warnung meldet lediglich die erkannte Auffälligkeit. WCPOS verlangsamt keine Anfragen, stellt sie nicht in eine Warteschlange und verwirft sie nicht. Bestell- und Produktdaten sind nicht betroffen.
2. Wenn der Code nur einmal erscheint, müssen Sie nichts tun. Falls er wiederholt erscheint, notieren Sie, welcher Bildschirm geöffnet war und welche Aktion Sie beim Auftreten gerade ausgeführt haben.
3. Verwenden Sie **Debug-Informationen kopieren**, solange das Ereignis noch im Protokollfenster sichtbar ist, und wenden Sie sich an den WCPOS-Support. Mithilfe des Exports kann der Support die Anfrageschleife nachvollziehen.
