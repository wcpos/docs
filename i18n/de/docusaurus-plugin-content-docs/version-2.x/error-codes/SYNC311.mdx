## Was das bedeutet {#what-this-means}

Die Daten auf diesem Gerät wurden mit einer anderen WCPOS-Version gespeichert und können noch nicht geöffnet werden.

Aktualisieren Sie WCPOS auf die neueste Version und öffnen Sie die App erneut. Wenn sie sich weiterhin nicht öffnen lässt, tippen Sie auf **Debug-Infos kopieren** und wenden Sie sich an den Support. Dies tritt meist nach einem Update oder einem Downgrade der App auf diesem Gerät auf.

:::warning Löschen Sie nicht die Daten dieses Geräts
Auf diesem Gerät können Verkäufe gespeichert sein, die Ihre Filiale noch nicht erreicht haben — beispielsweise Verkäufe, die offline erfasst wurden. Solange die Daten nicht geöffnet werden können, lassen sie sich auch nicht senden. Das Löschen der lokalen Datenbank, das Abmelden oder eine Neuinstallation würde diese Verkäufe daher unwiederbringlich löschen. Wenden Sie sich an den Support, bevor Sie etwas löschen.
:::

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten dieses Geräts — darauf können Verkäufe gespeichert sein, die Ihre Filiale noch nicht erreicht haben. Die Daten in Ihrer Filiale sind sicher und nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Aktualisieren Sie WCPOS auf diesem Gerät auf die neueste Version und öffnen Sie die App anschließend erneut:
   - **Web:** Laden Sie den Browser-Tab neu. Wenn erneut die alte Version erscheint, halten Sie beim Neuladen die **Umschalttaste** gedrückt. Das WCPOS-Plugin der Filiale bestimmt, welche Webversion geladen wird. Wenn das Neuladen nicht hilft, bitten Sie Ihren Website-Administrator, das WCPOS-Plugin zu aktualisieren.
   - **Desktop:** Installieren Sie das ausstehende Update und öffnen Sie die App erneut. Wenn kein Update angeboten wird, laden Sie die neueste Version von der Seite [Installation](/getting-started/installation) herunter.
   - **iPhone, iPad oder Android:** Aktualisieren Sie WCPOS über den Kanal, über den Sie die App installiert haben — TestFlight unter iOS, das Testprogramm von Play unter Android; beide sind auf der Seite [Installation](/getting-started/installation) verlinkt.
2. Wenn sich die App weiterhin nicht öffnen lässt, tippen Sie im Tab **Protokolle** auf **Debug-Infos kopieren** und wenden Sie sich an den Support. Geben Sie an, ob auf diesem Gerät möglicherweise Verkäufe gespeichert sind, die Ihre Filiale noch nicht erreicht haben.
3. Löschen Sie während der Wartezeit keine lokalen Daten, melden Sie sich nicht ab und installieren Sie die App nicht neu — der Support teilt Ihnen mit, ob zuerst Daten auf diesem Gerät wiederhergestellt werden müssen.
