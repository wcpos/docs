## Was das bedeutet {#what-this-means}

Beim Drucken ist ein unerwartetes Problem aufgetreten. Kein Verkauf ist betroffen.

Wiederholen Sie die in diesem Eintrag genannte Druck- oder Belegaktion. Wenden Sie sich an den Support, wenn der Fehler erneut auftritt.

## Ihre Daten {#your-data}

Kein Verkauf ist betroffen.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie zuerst den Protokolleintrag auf und ermitteln Sie den fehlgeschlagenen Vorgang — dieser Code umfasst auch Aktionen der Warteschlange für Beleg-E-Mails und die Synchronisierung von Belegvorlagen, nicht nur das Drucken auf Papier.
2. Wiederholen Sie nur den im Protokoll genannten Vorgang. Drucken Sie nur bei einem Druckversuch auf Papier erneut aus der Bestellansicht. Versenden Sie eine E-Mail in der Warteschlange über „Shop-Zustand“ erneut. Um die Vorlagensynchronisierung erneut anzustoßen, öffnen Sie bei bestehender Verbindung die Belegansicht erneut.
3. Wenn diese Aktion weiterhin fehlschlägt, wählen Sie auf der Registerkarte **Protokolle** die Option **Debug-Informationen kopieren** und wenden Sie sich an den Support.
