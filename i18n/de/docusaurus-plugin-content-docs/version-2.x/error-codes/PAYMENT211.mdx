## Was das bedeutet {#what-this-means}

Das Kartenterminal hat diesen Zahlungsvorgang beendet, ohne die Zahlung entgegenzunehmen. Häufige Gründe sind eine Ablehnung durch die Bank des Kunden, ein Abbruch am Kartenleser selbst oder ein Zeitablauf, bevor eine Karte vorgelegt wurde.

Es wurde nichts abgebucht, und der offene Betrag der Bestellung ist weiterhin fällig. Die Zahlung kann daher einfach auf anderem Weg entgegengenommen werden. Der vom Anbieter genannte Grund ist im Protokolleintrag erfasst und wird normalerweise gleichzeitig auf dem Terminal angezeigt.

## Ihre Daten {#your-data}

Es wurde kein Geld übertragen. Die Bestellung ist unverändert und ihr offener Betrag ist weiterhin fällig.

## Fehlerbehebung {#troubleshoot}

**An der Kasse** — erledigen Sie dies, bevor der Kunde geht:

1. Lesen Sie den Grund auf der Terminalanzeige oder im Protokolleintrag.
2. Bitten Sie den Kunden um eine andere Karte oder verwenden Sie eine andere Zahlungsmethode.
3. Falls der Kunde darauf besteht, dass die Zahlung erfolgt ist, prüfen Sie die Bestellung vor einer erneuten Belastung — eine Zahlung, die bei der Bank angekommen ist, wird in der Bestellung angezeigt.

**Im Shop** — für den Website-Administrator:

1. Wenn alle Karten wiederholt abgelehnt werden, deutet das eher auf das Terminal oder das zugehörige Konto als auf die Kunden hin: Prüfen Sie, ob der Kartenleser online ist, und sehen Sie im Dashboard Ihres Zahlungsanbieters nach.
2. Einzelne Ablehnungen betreffen den Kunden und seine Bank; WCPOS erfasst sie, kann sie aber nicht erklären.
