## Was dies bedeutet {#what-this-means}

WCPOS kann seinen Verbindungsendpunkt in Ihrer Filiale nicht erreichen.

Bitten Sie Ihren Website-Administrator zu prüfen, ob das WCPOS-Plugin aktiv ist (**WP Admin → Plugins**) und ob kein Sicherheits-Plugin die REST API blockiert.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Informieren Sie Ihren Website-Administrator.

## Fehlerbehebung {#troubleshoot}

**An der Kasse** — für den Kassierer: Informieren Sie Ihren Website-Administrator. Auf diesem Gerät ist nichts betroffen.

**In der Filiale** — für den Website-Administrator:

1. Prüfen Sie, ob WCPOS aktiv ist: WP Admin → Plugins.
2. Wenn keine der beiden REST-Varianten funktioniert, prüfen Sie, ob ein Sicherheits-Plugin, ein Proxy oder ein CDN die Header von WCPOS-Anfragen entfernt oder REST-Anfragen blockiert — die Ursache sind meist Firewall-Regeln oder Sicherheitseinstellungen zum Deaktivieren der REST API.
3. Bei manchen Hosting-Anbietern werden fehlende REST-Routen wiederhergestellt, wenn Sie die Permalinks erneut speichern (Einstellungen → Permalinks → Änderungen speichern).
