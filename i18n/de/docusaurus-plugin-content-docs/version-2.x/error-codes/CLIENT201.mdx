## Was das bedeutet {#what-this-means}

Auf diesem Gerät war nicht mehr genügend Arbeitsspeicher verfügbar. Die letzte Aktion wurde möglicherweise nicht abgeschlossen.

Schließen Sie andere Apps oder Tabs, starten Sie WCPOS neu und prüfen Sie dann, ob Ihr letzter Verkauf oder Ihre letzte Änderung gespeichert wurde. Falls nicht, führen Sie die Aktion erneut aus.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden. Prüfen Sie es, bevor Sie es erneut versuchen. Wenn Sie gerade einen Verkauf oder eine Änderung gespeichert haben, als der Arbeitsspeicher ausging, prüfen Sie vor einer Wiederholung, ob die Daten gespeichert wurden.

## Fehlerbehebung {#troubleshoot}

1. Schließen Sie andere Apps oder Browser-Tabs. WCPOS teilt sich den Arbeitsspeicher des Geräts mit allen anderen darauf laufenden Anwendungen.
2. Starten Sie WCPOS neu.
3. Prüfen Sie vor einer Wiederholung, ob Ihr letzter Verkauf oder Ihre letzte Änderung gespeichert wurde: Sehen Sie unter **Filialstatus → Datenbank** nach (ein unter **Änderungen warten auf Übertragung** gezählter Verkauf ist gespeichert und wird noch gesendet), im Warenkorb und unter Bestellungen (WCPOS Pro) oder **WooCommerce → Bestellungen**. Wenn eine Karte beteiligt war, prüfen Sie auch das Terminal oder den Zahlungsanbieter. Wurde der Kunde belastet, ziehen Sie den Betrag nicht erneut ein. Führen Sie die Aktion nur dann einmal erneut aus, wenn sie tatsächlich nicht gespeichert wurde.
4. Wenn bei einer bestimmten Aktion regelmäßig der Arbeitsspeicher ausgeht, notieren Sie die Aktion, tippen Sie auf **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den Support.
5. Wenn dies täglich auf demselben Gerät passiert, reicht dessen Leistung möglicherweise nicht für den Katalog aus. Melden Sie dies, damit der Support es überprüfen kann.
