## Was das bedeutet {#what-this-means}

Beim Anmelden oder beim Aufrechterhalten der Anmeldung ist ein unerwartetes Problem aufgetreten.

Versuchen Sie die Aktion noch einmal. Falls sich das Problem wiederholt, melden Sie sich ab und wieder an. Verwenden Sie anschließend **Debug-Informationen kopieren** und wenden Sie sich an den Support.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Falls das Problem bestehen bleibt, verwenden Sie **Debug-Informationen kopieren** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Versuchen Sie die Aktion noch einmal. Falls sie erneut fehlschlägt, melden Sie sich ab und wieder an.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode sowie einen gegebenenfalls vorhandenen serverCode. Ein 999-Code bedeutet, dass es für die Ursache noch keinen eigenen Code gibt. Diese Zusatzinformationen helfen, sie zu bestimmen.
3. Falls das Problem erneut auftritt, verwenden Sie Debug-Informationen kopieren und wenden Sie sich an den Support.
