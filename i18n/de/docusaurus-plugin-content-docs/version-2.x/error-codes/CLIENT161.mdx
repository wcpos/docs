## Was das bedeutet {#what-this-means}

Die Kasse läuft derzeit nicht in diesem Browser-Tab. Deshalb hat er keine neue Zahlungsanfrage gesendet.

Im Web läuft die Kasse jeweils nur in einem Browser-Tab. Wenn ein zweiter Tab geöffnet wird oder ein anderer Tab übernimmt, führt dieser Tab die Kasse nicht mehr aus und zeigt einen entsprechenden Hinweis an. Eine Zahlungsanfrage, die genau zu diesem Zeitpunkt starten sollte, wurde vor dem Senden abgewiesen. Dieser Eintrag dokumentiert die Ablehnung. Er dient nur zur Information: In Ihrem Shop und auf Ihrem Gerät ist nichts fehlgeschlagen, und er sagt nichts über das Ergebnis einer bereits gestarteten Zahlung aus.

## Ihre Daten {#your-data}

Durch die Ablehnung wurden weder Daten geschrieben noch gingen Daten verloren. Bereits auf diesem Gerät gespeicherte Verkäufe, Warenkörbe und Bestellungen sind nicht betroffen und werden wie gewohnt synchronisiert. Eine bereits gestartete Zahlung — eine Karte am Lesegerät oder eine bereits an den Shop gesendete Abbuchung — wurde durch diesen Eintrag nicht unterbrochen. Ihr Ergebnis wird in der Bestellung vermerkt, sobald der Tab, in dem die Kasse jetzt läuft, sie synchronisiert hat. Prüfen Sie daher diese Bestellung, bevor Sie die Zahlung erneut entgegennehmen.

## Fehlerbehebung {#troubleshoot}

1. Sehen Sie sich die Kassenansicht in diesem Tab an. Sie zeigt an, ob die Kasse in einem anderen Tab läuft. Wählen Sie **Hier übernehmen**, um in diesem Tab fortzufahren, oder arbeiten Sie im anderen Tab weiter.
2. Wenn die Ansicht **Neu laden** anbietet, laden Sie den Tab neu. Danach steht die Kasse wieder in diesem Tab zur Verfügung.
3. Bevor Sie eine bereits gestartete Zahlung erneut versuchen, öffnen Sie die Bestellung und prüfen Sie ihren Zahlungsstatus. So wird eine bereits geleistete Zahlung des Kunden nicht doppelt eingezogen.
