## Was das bedeutet {#what-this-means}

Die Shop-Adresse fehlt oder ist keine gültige URL.

Entweder war das Adressfeld leer, oder Ihr Shop hat geantwortet, aber seine WCPOS-Anmeldeadresse ist ungültig. Letzteres muss im Shop behoben werden, nicht an der Kasse.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Geben Sie die Shop-Adresse in **Geben Sie die URL Ihres WooCommerce-Shops ein** ein — zum Beispiel `shop.example.com` — und drücken Sie **Verbinden**. Ein Feld, das nur Leerzeichen enthält, gilt als leer.
2. Wenn die Adresse eingetragen ist und die Meldung **„Die WCPOS-Anmelde-URL ist ungültig. Bitte stellen Sie sicher, dass das WCPOS-Plugin korrekt konfiguriert ist“** lautet, liegt das Problem im Shop. **Website-Administrator:** Aktualisieren Sie WCPOS unter **WP Admin → Plugins** auf die neueste Version und drücken Sie dann erneut **Verbinden**. Deaktivieren und reaktivieren Sie das Plugin nicht, um diesen Fehler zu beheben — eine Reaktivierung setzt die POS-Berechtigungen aller Rollen auf die Standardwerte zurück.
3. **Website-Administrator:** Falls das Problem dadurch nicht behoben wird, öffnen Sie die vollständige Shop-Adresse mit angehängtem `/wp-json/` in einem Browser — zum Beispiel `https://your-store.com/wp-json/` oder `https://example.com/shop/wp-json/`, wenn WordPress in `/shop` liegt. Falls dies einen 404 zurückgibt (zum Beispiel bei einfachen Permalinks), verwenden Sie stattdessen dieselbe Adresse mit angehängtem `/?rest_route=/`. Unter `authentication` → `wcpos` → `endpoints` sollte `authorization` eine einfache Webadresse sein. Steht dort stattdessen eine Liste, ein Objekt oder eine Zahl, verändert ein Sicherheits-, Caching- oder REST-Anpassungsplugin diese Antwort. Deaktivieren Sie diese Plugins einzeln auf einer Staging-Kopie, um den Verursacher zu finden.
