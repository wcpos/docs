## Was das bedeutet {#what-this-means}

Diese Produktänderung hat Ihren Shop noch nicht erreicht.

Lesen Sie den angezeigten Grund, beheben Sie das genannte Problem oder prüfen Sie Ihre Verbindung und speichern Sie das Produkt anschließend erneut.

## Ihre Daten {#your-data}

Löschen Sie die Daten dieses Geräts nicht — es enthält möglicherweise Änderungen, die Ihr Shop noch nicht hat. Speichern Sie das Produkt nach einem Verbindungsfehler erneut, sobald die Verbindung wiederhergestellt ist. Wenn der Shop die Bearbeitung abgelehnt hat, kehrt dieses Gerät stattdessen zur Version des Shops zurück (siehe [SYNC202](/error-codes/SYNC202)). Nehmen Sie die Änderung daher erneut vor, sobald die Ursache behoben ist. Wenn dies wiederholt auftritt, wählen Sie auf der Registerkarte **Protokolle** die Option **Debug-Informationen kopieren** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Lesen Sie den angezeigten Grund — der Fehlertext im Protokolleintrag zeigt normalerweise, ob ein Verbindungsfehler, ein vom Shop abgelehnter Wert oder eine widersprüchliche Bearbeitung im Shop die Ursache war.

**An der Kasse:**

- Verbindungsfehler: Prüfen Sie die Verbindung und speichern Sie das Produkt anschließend erneut.
- Abgelehnter Wert: Korrigieren Sie die im Grund genannte Angabe und speichern Sie das Produkt anschließend erneut.

**Im Shop (WP Admin):** Öffnen Sie bei einer widersprüchlichen Bearbeitung das Produkt, vergleichen Sie es mit der Anzeige an der Kasse und speichern Sie die korrekten Werte einmal.

Wenn das Speichern ohne erkennbaren Grund weiterhin fehlschlägt, wählen Sie auf der Registerkarte **Protokolle** die Option **Debug-Informationen kopieren** und wenden Sie sich an den Support.
