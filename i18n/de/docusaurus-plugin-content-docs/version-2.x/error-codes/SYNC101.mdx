## Was das bedeutet {#what-this-means}

WCPOS konnte eine Änderung nicht im Speicher dieses Geräts speichern.

Geben Sie Speicherplatz auf dem Gerät frei und prüfen Sie anschließend, ob die Änderung angezeigt wird. Falls sie fehlt, geben Sie sie erneut ein. Wenden Sie sich an den Support, wenn das Problem erneut auftritt. Notieren Sie die Änderung, bis Sie sie überprüft haben: Wird WCPOS geschlossen, bevor die Änderung gespeichert wurde, geht sie verloren. Löschen Sie die Daten dieses Geräts nicht.

## Ihre Daten {#your-data}

Löschen Sie die Daten dieses Geräts nicht — sie können Verkäufe enthalten, die Ihren Shop noch nicht erreicht haben. Die fehlgeschlagene Änderung wurde möglicherweise noch nirgendwo gespeichert. Bewahren Sie daher eine Notiz dazu auf, bis Sie geprüft haben, dass sie angezeigt wird. Wenn dies wiederholt auftritt, verwenden Sie **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Notieren Sie die Änderung — den Datensatz und die eingegebenen Werte. Wenn der Protokolleintrag einen Datensatz nennt, betrifft die möglicherweise nicht gespeicherte Änderung diesen Datensatz. Beim Speichern von Website- oder Zugangsdaten werden stattdessen möglicherweise nur der fehlgeschlagene Vorgang und der Fehler genannt. Notieren Sie auch diese Angaben.
2. Löschen Sie keine Website-Daten, setzen Sie die App nicht zurück und deinstallieren Sie sie nicht: Andere Änderungen, die Ihren Shop noch nicht erreicht haben, etwa Verkäufe, existieren nur auf diesem Gerät. Wenn Sie den lokalen Speicher löschen, werden sie unwiderruflich gelöscht.
3. Geben Sie Speicherplatz auf dem Gerät frei, indem Sie andere Dateien oder Apps entfernen. Ein voller Datenträger oder ein ausgeschöpftes Speicherkontingent des Browsers ist der häufigste Grund für fehlgeschlagene lokale Schreibvorgänge. Verwenden Sie dazu nicht die Browserfunktion „Browserdaten löschen“ — sie löscht auch die noch nicht gesendeten Verkäufe von WCPOS.
4. Prüfen Sie, ob die Änderung angezeigt wird, indem Sie den Datensatz öffnen. Falls sie fehlt, geben Sie sie erneut ein und speichern Sie. Wenn das Speichern weiterhin nicht funktioniert, starten Sie WCPOS einmal neu und versuchen Sie es erneut.
5. Wenn das Speichern weiterhin fehlschlägt, verwenden Sie **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den Support, bevor Sie einen Reparaturversuch unternehmen.
