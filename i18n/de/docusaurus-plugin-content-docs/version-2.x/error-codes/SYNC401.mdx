## Was das bedeutet {#what-this-means}

Eine Synchronisierungsaufgabe im Hintergrund wurde vor ihrem Abschluss unerwartet beendet.

Sie müssen nichts tun — der POS startet diese Aufgaben automatisch neu, und es geht nichts verloren. Wenn dieser Code wiederholt erscheint, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den Support.

## Ihre Daten {#your-data}

Es geht nichts verloren — Bestell- und Produktdaten sind nicht betroffen. Wenn das Problem bestehen bleibt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Beim ersten Auftreten müssen Sie nichts tun: Der POS startet die abgestürzte Hintergrundaufgabe automatisch neu, und es sind keine Bestelldaten betroffen.
2. Wenn der Code innerhalb weniger Minuten erneut erscheint, laden Sie die App einmal neu, damit die Synchronisierung neu startet.
3. Wenn der Code weiterhin erscheint, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den Support. Ein wiederholter Absturz einer Aufgabe ist ein Fehler in der App, den Sie melden sollten, kein Problem Ihres Shops.
