## Was das bedeutet {#what-this-means}

WCPOS konnte nicht zu dieser Filiale wechseln.

Laden Sie WCPOS neu und wählen Sie die Filiale erneut aus. Auf diesem Gerät geht nichts verloren.

Der Wechsel zwischen Filialen oder Kassierern auf derselben Website ist vor dem Abschluss fehlgeschlagen. Die Daten der vorherigen Filiale auf diesem Gerät bleiben unverändert.

## Ihre Daten {#your-data}

Auf diesem Gerät geht nichts verloren. Die Daten der vorherigen Filiale — einschließlich aller noch nicht gesendeten Daten — bleiben unverändert.

## Fehlerbehebung {#troubleshoot}

1. Laden Sie WCPOS neu: Laden Sie im Web den Browser-Tab neu; schließen und öffnen Sie auf Desktop- und Mobilgeräten die App.
2. Wählen Sie die Filiale und den Kassierer erneut aus.
3. Wenn der Wechsel weiterhin fehlschlägt, tippen Sie auf **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den Support. Löschen Sie zur Behebung weder lokale Daten noch die Website. Die Daten der vorherigen Filiale, einschließlich aller noch nicht gesendeten Daten, befinden sich auf diesem Gerät.
