## Was das bedeutet {#what-this-means}

Die Änderungsliste Ihrer Filiale hat sich unerwartet verschoben. WCPOS prüft sie deshalb automatisch erneut. Nichts ist verloren gegangen.

Sie müssen nichts tun — verkaufen Sie weiter. WCPOS prüft die Änderungen Ihrer Filiale automatisch erneut. Wenn Preise oder Lagerbestände weiterhin veraltet erscheinen, tippen Sie unter **Shop-Zustand → Datenbank** auf **Jetzt alles prüfen**.

## Ihre Daten {#your-data}

Nichts ist verloren gegangen, und die Daten auf diesem Gerät sind nicht gefährdet. Bis die erneute Prüfung abgeschlossen ist, können einige Preise oder Lagerbestände auf diesem Gerät veraltet sein.

## Fehlerbehebung {#troubleshoot}

1. Verkaufen Sie weiter — auf diesem Gerät geht nichts verloren, und die erneute Prüfung läuft automatisch. Der Protokolleintrag kann angeben, was sich verschoben hat — beispielsweise, dass einige Änderungen in der Filiale übersprungen wurden oder dass die Änderungsliste der Filiale auf einen früheren Stand zurückgesprungen ist. In beiden Fällen kann jede Art von Daten betroffen sein.
2. Wenn Preise oder Lagerbestände weiterhin veraltet erscheinen, öffnen Sie **Shop-Zustand → Datenbank** und tippen Sie auf **Jetzt alles prüfen**.
3. Wenn ein Datensatz nach dieser Prüfung weiterhin falsch erscheint oder dieser Code immer wieder auftritt, verwenden Sie **Debug-Infos kopieren** im Tab **Protokolle** und wenden Sie sich an den Support. Löschen Sie zur Behebung keine Daten.
