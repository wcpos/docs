## Was das bedeutet {#what-this-means}

Die REST API des Shops hat unter keiner Adressform geantwortet, die diese App nutzen kann.

Die App hat die REST API des Shops unter ihrer normalen Adresse (/wp-json/...) und unter der integrierten Ausweichadresse von WordPress (/?rest_route=...) aufgerufen. Beide haben nicht geantwortet. Die Website des Shops selbst kann durchaus erreichbar sein — hier ist speziell die REST API nicht erreichbar. Meist wird sie von einem Sicherheitsplugin verborgen oder durch eine Firewall-Regel blockiert.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen.

## Fehlerbehebung {#troubleshoot}

**Im Shop** — für den Website-Administrator: Wenn ein Sicherheitsplugin `/wp-json/` verbirgt oder umbenennt (zum Beispiel WP Hide), erlauben Sie auch die in WordPress integrierte Form `/?rest_route=` — die App greift automatisch darauf zurück.

**Beim Hosting-Anbieter / auf dem Server:**

1. Prüfen Sie Firewall-Regeln (WAF) auf Einträge, die auf `wp-json` oder `rest_route` zutreffen, und lassen Sie die eigene REST API des Shops durch.
2. Wenn dem Server eine Wartungsseite oder Bot-Prüfung vorgeschaltet ist, werden REST-Anfragen möglicherweise mit einer HTML-Seite beantwortet. Deaktivieren Sie die Prüfung für die REST API.

**Zum Testen (für alle):** `https://your-store.com/?rest_route=/` sollte JSON zurückgeben, keine 403-Seite und auch nicht die Startseite der Website.
