## Was das bedeutet {#what-this-means}

WCPOS konnte den Start nicht abschließen.

An der Kasse zeigt sich dies durch einen leeren oder eingefrorenen Bildschirm oder eine Ladeanzeige, die nicht verschwindet. Starten Sie WCPOS neu (laden Sie im Browser den Tab neu) — ein Startfehler behebt sich oft von selbst. Wenn WCPOS weiterhin nicht startet, wenden Sie sich an den Support, bevor Sie etwas löschen.

:::warning Löschen Sie keine Daten auf diesem Gerät
Auf diesem Gerät können Verkäufe gespeichert sein, die noch nicht an Ihre Filiale übertragen wurden — zum Beispiel Verkäufe, die offline erfasst wurden. Solange WCPOS nicht starten kann, können diese nicht gesendet werden. Wenn Sie lokale Daten löschen, sich abmelden oder die App neu installieren, würden diese Verkäufe daher dauerhaft gelöscht. Wenden Sie sich an den Support, bevor Sie etwas löschen.
:::

## Ihre Daten {#your-data}

Löschen Sie keine Daten auf diesem Gerät — es können Änderungen gespeichert sein, die in Ihrer Filiale noch nicht vorliegen. Die Daten Ihrer Filiale sind sicher und nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Starten Sie WCPOS einmal neu; laden Sie im Browser den Tab vollständig neu — ein vorübergehender Startfehler behebt sich oft von selbst.
2. Wenn WCPOS weiterhin nicht startet, wenden Sie sich an den Support, bevor Sie etwas löschen. Senden Sie die über **Debug-Infos kopieren** im Tab **Protokolle** kopierten Informationen, sofern WCPOS weit genug startet, um darauf zuzugreifen — andernfalls die Fehlermeldung aus der Browserkonsole (Entwicklertools) oder aus den Entwicklertools der Desktop-App unter **Erweitert → Entwicklertools ein-/ausblenden**.
3. Löschen Sie in der Zwischenzeit keine lokalen Daten, melden Sie sich nicht ab und installieren Sie die App nicht neu — der Support teilt Ihnen mit, ob zunächst Daten auf diesem Gerät wiederhergestellt werden müssen.
