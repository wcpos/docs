## Was das bedeutet {#what-this-means}

Der Speicher dieses Geräts antwortet nicht mehr. Das Speichern wurde daher pausiert.

Starten Sie WCPOS neu (laden Sie im Browser die Registerkarte neu) und prüfen Sie anschließend, ob Ihr letzter Verkauf oder Ihre letzte Änderung gespeichert wurde. Eine Änderung aus den Sekunden vor dem Speicherausfall wurde möglicherweise nicht geschrieben. Löschen Sie die Daten dieses Geräts nicht. Wenn das Problem weiterhin auftritt, wenden Sie sich an den Support.

## Ihre Daten {#your-data}

Löschen Sie die Daten dieses Geräts nicht — sie können Verkäufe enthalten, die Ihren Shop noch nicht erreicht haben. Wenn dies wiederholt auftritt, verwenden Sie **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Starten Sie WCPOS neu — schließen und öffnen Sie die App. Laden Sie im Browser die Registerkarte neu, statt sie zu schließen. Dadurch wird die Verbindung zur lokalen Datenbank in fast allen Fällen wiederhergestellt.
2. Prüfen Sie nach dem Neustart, ob Ihr letzter Verkauf oder Ihre letzte Änderung gespeichert wurde: Eine Änderung aus den Sekunden vor dem Ausfall wurde möglicherweise nicht geschrieben. Falls sie fehlt, geben Sie sie erneut ein.
3. Betreiben Sie die Kasse im Browser nicht in einem privaten Fenster oder Inkognitofenster und vermeiden Sie Erweiterungen, die den Speicher aggressiv bereinigen. Beides kann den lokalen Speicher mitten in einer Sitzung entfernen. Beim Schließen eines privaten Fensters werden sämtliche darin gespeicherten Daten gelöscht, auch noch nicht gesendete Verkäufe. Wenn Sie gerade ein solches Fenster verwenden, lassen Sie es geöffnet, bis **Shop-Zustand → Datenbank** 0 **Änderungen warten auf das Senden** anzeigt, kein [Bereich eine Entscheidung verlangt](../support/store-health.mdx#needs-attention) und keine offene Bestellung mehr unsynchronisiert ist ([Bestellung synchronisieren](../pos/cart/open-orders.mdx#sync-order)).
4. Wenn dies auf demselben Gerät regelmäßig auftritt, verwenden Sie **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den Support. Geben Sie an, was das Gerät zu diesem Zeitpunkt tat (Ruhezustand, Wechsel der Registerkarte, geringer Arbeitsspeicher).
