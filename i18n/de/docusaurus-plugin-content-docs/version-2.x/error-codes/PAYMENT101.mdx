## Was das bedeutet {#what-this-means}

Die Zahlung war erfolgreich, aber WCPOS konnte ihren Status anschließend nicht aktualisieren.

Die Zahlung wurde abgeschlossen — ziehen Sie den Betrag nicht erneut ein. Öffnen Sie die Bestellung erneut, um ihren Status zu aktualisieren. Falls er weiterhin veraltet erscheint, aktualisieren Sie die Bestellung wie unten beschrieben.

## Ihre Daten {#your-data}

Die Zahlung wurde entgegengenommen — ziehen Sie den Betrag nicht erneut ein. Nur der angezeigte Status ist veraltet.

## Fehlerbehebung {#troubleshoot}

1. Belasten Sie den Kunden nicht erneut. Der Shop hat die Zahlung bestätigt (falls Sie die Benachrichtigung **Zahlung für Bestellung #… abgeschlossen** gesehen haben, war das die Bestätigung). Lediglich die anschließende Aktualisierung an der Kasse ist fehlgeschlagen.
2. Öffnen Sie die Bestellung erneut, um ihren Status zu aktualisieren, und fahren Sie mit dem nächsten Verkauf fort.
3. Falls die bezahlte Bestellung im Warenkorb weiterhin als offen angezeigt wird, aktualisieren Sie die Kopie an der Kasse: Öffnen Sie **Filialstatus → Datenbank**, öffnen Sie das Menü **⋮** in der Zeile **Bestellungen** und wählen Sie **Jetzt auf Änderungen prüfen**. Sobald der Bezahlstatus eintrifft, verschwindet die Bestellung aus dem Warenkorb. Mit WCPOS Pro können Sie stattdessen nur diese Bestellung aktualisieren: Öffnen Sie unter **Bestellungen** das Menü **⋮** der Bestellung und wählen Sie **Synchronisieren**.
4. Falls sie weiterhin als offen angezeigt wird, laden Sie die App neu (im Web den Browser-Tab neu laden; auf Desktop und Mobilgeräten die App schließen und erneut öffnen). Beim Start schließt die Kasse alle Verkäufe ab, deren Zahlung sie erfasst hat.
5. **Website-Administrator:** Öffnen Sie zur Sicherheit die Bestellung unter **WooCommerce → Bestellungen** — dort wird sie als bezahlt angezeigt.
