## Was dies bedeutet {#what-this-means}

Der Suchindex hat nicht rechtzeitig geantwortet. Deshalb hat WCPOS stattdessen den Katalog direkt durchsucht.

Der lokale Suchindex wurde noch erstellt oder konnte nicht antworten. Im Web liegt das meist daran, dass sich der POS-Tab im Hintergrund befand. Auf Desktop und Mobilgeräten passiert es typischerweise direkt nach einer umfangreichen Synchronisierung oder kurz nach einem Neustart der App, während der gespeicherte Index wieder geladen wird. Suchanfragen werden weiterhin beantwortet, indem die Daten auf diesem Gerät direkt durchsucht werden. Sobald der Index wieder antwortet, wird automatisch zu ihm gewechselt.

## Ihre Daten {#your-data}

Es wurden keine Filialdaten geändert und Ihre Suchanfrage wurde beantwortet — statt des Index hat eine direkte Suche in den Daten dieses Geräts die Ergebnisse geliefert. Suchanfragen können etwas langsamer beantwortet werden, bis der Index wieder übernimmt.

## Fehlerbehebung {#troubleshoot}

1. Normalerweise ist nichts zu tun: Die Suchergebnisse funktionieren weiterhin und der Index übernimmt wieder von selbst, sobald er antwortet.
2. Lassen Sie den POS im Web in einem eigenen Fenster statt in einem Hintergrund-Tab geöffnet.
3. Wenn die Suche langsam bleibt oder dieser Fehlercode weiterhin erscheint, laden Sie die App einmal neu. Laden Sie im Web den Browser-Tab neu. Schließen Sie auf Desktop und Mobilgeräten die App und öffnen Sie sie erneut.
4. Wenn der Fehlercode danach erneut auftritt, exportieren Sie die Debug-Informationen und wenden Sie sich an den Support.
