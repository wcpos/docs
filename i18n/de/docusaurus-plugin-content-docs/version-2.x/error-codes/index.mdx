# Fehlercodes {#error-codes}

Wenn in WCPOS ein Problem auftritt, wird ein Fehlercode angezeigt, der bei der Identifizierung des Problems hilft. Ab **v1.10.0** folgen die Codes dem Format **Bereich + drei Ziffern** — zum Beispiel `SYNC131` oder `AUTH311`. Der Bereich bezeichnet den betroffenen Teil des POS; die Zahl kennzeichnet den konkreten Fehlerzustand. Jeder Code hat eine eigene Seite mit einer Erklärung, Handlungsempfehlungen und Angaben zu den Auswirkungen auf Ihre Daten.

Im POS erscheinen Fehlercodes unter **Filialzustand → Protokolle**: Klappen Sie eine Zeile auf und folgen Sie dem Link **Hilfe**, um direkt zur entsprechenden Codeseite hier zu gelangen.

## Fehlerbereiche (v1.10.0+) {#error-domains}

| Bereich | Zuständigkeit |
|--------|------|
| [`AUTH`](#auth) | Anmeldung, Sitzungen und Tokens |
| [`CHECKOUT`](#checkout) | Bestellungen an der Kasse abschließen |
| [`CLIENT`](#client) | Die POS-App selbst und die lokale Speicherung |
| [`DISPLAY`](#display) | Die Kundenanzeige |
| [`HOST`](#host) | Hosting- und Firewall-Regeln, die den POS blockieren |
| [`LICENSE`](#license) | Aktivierung und Prüfung der Pro-Lizenz |
| [`PAYMENT`](#payment) | Zahlungsgateways und Terminals |
| [`PRINT`](#print) | Belegdruck |
| [`PRODUCT`](#product) | Produktdaten und Katalogvorgänge |
| [`REGISTER`](#register) | Kassenschublade, Kassensitzungen und Kassenstürze |
| [`SYNC`](#sync) | Synchronisierung zwischen dem POS und Ihrem Shop |

Suchen Sie Ihren Code in der folgenden Liste oder nutzen Sie die Suche.

Codes, die auf `999` enden, fassen Fehlerzustände des jeweiligen Bereichs zusammen, für die es noch keinen eigenen Code gibt.

## Codes aus Versionen vor v1.10.0 {#legacy-codes}

Codes wie `API04001` stammen aus Versionen vor v1.10.0; diese Version erzeugt sie nie. Sie können noch in einem Protokolleintrag aus der Zeit vor dem Upgrade oder in einem älteren Support-Beitrag auftauchen. Wählen Sie im Versionsmenü **1.x**, um sie nachzuschlagen.

## Benötigen Sie weitere Hilfe? {#need-more-help}

Wenn nach Durchführung der Schritte zur Fehlerbehebung weiterhin Probleme auftreten:

1. Im Abschnitt [Fehlerbehebung](../support/troubleshooting/response-error.mdx) finden Sie ausführlichere Anleitungen
2. Treten Sie unserer [Discord-Community](https://wcpos.com/discord) bei, um Unterstützung zu erhalten
3. Melden Sie Probleme auf [GitHub](https://github.com/wcpos)
