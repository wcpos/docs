## Was das bedeutet {#what-this-means}

In WCPOS ist ein unerwarteter Fehler aufgetreten.

Prüfen Sie vor einem erneuten Versuch, ob Ihre letzte Aktion erfolgreich war. Öffnen Sie bei einem Verkauf die Bestellung und prüfen Sie ihren Status. Wenn der Fehler erneut auftritt, tippen Sie auf **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden. Prüfen Sie es, bevor Sie es erneut versuchen. Wenn der Fehler erneut auftritt, wählen Sie **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie vor einem erneuten Versuch, ob Ihre letzte Aktion erfolgreich war. Öffnen Sie bei einem Verkauf die Bestellung und prüfen Sie ihren Status; prüfen Sie bei einer Zahlung auch das Terminal oder den Anbieter. Wenn die Aktion nicht erfolgreich war, versuchen Sie es noch einmal.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode und den Kontext. Ein Code mit 999 bedeutet, dass es für diesen Fehler noch keinen eigenen Code gibt. Mit diesen Angaben lässt sich der Fehler identifizieren.
3. Wenn der Fehler erneut auftritt, tippen Sie auf **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und senden Sie die Informationen an den WCPOS-Support. Durch Ihre Meldung kann ein spezifischer Code ergänzt werden.
