## Was das bedeutet {#what-this-means}

Dieser Shop benötigt jetzt eine neuere Version der POS-App.

Das WCPOS-Plugin Ihres Shops verwendet inzwischen ein neueres Synchronisierungsprotokoll, das diese App-Version noch nicht unterstützt. Der Shop hält die Synchronisierung deshalb bewusst an, bis die App aktualisiert wurde. Das ist eine Schutzmaßnahme, kein Fehler: Sie verhindert, dass eine veraltete App Shop-Daten falsch liest oder schreibt. Aktualisieren Sie WCPOS (laden Sie im Web die Seite neu) und öffnen Sie die App anschließend erneut. Noch nicht gesendete Verkäufe bleiben auf diesem Gerät und werden nach dem Update gesendet.

## Ihre Daten {#your-data}

An der Kasse geht nichts verloren. Verkäufe und Änderungen, die noch auf das Senden warten, bleiben sicher auf dem Gerät und werden synchronisiert, sobald eine aktualisierte App eine Verbindung zum Shop herstellt. Falls noch keine neuere App verfügbar ist (siehe die letzten beiden Schritte unten), bleiben sie so lange in der Warteschlange.

## Fehlerbehebung {#troubleshoot}

1. Laden Sie bei der Web-App den Browser-Tab neu — beim Neuladen übernimmt die Web-App die neue Version. Falls dieser Bildschirm erneut erscheint, laden Sie die Seite unter Umgehung des Caches neu (halten Sie beim Neuladen die **Umschalttaste** gedrückt).
2. Installieren Sie auf dem Desktop das ausstehende Update und öffnen Sie die App erneut. Die Prüfung erfolgt, wenn die App die Verbindung wiederherstellt. Falls kein Update angeboten wird, laden Sie die neueste Version von der Seite [Installation](/getting-started/installation) herunter.
3. Aktualisieren Sie WCPOS auf iPhone, iPad oder Android über denselben Kanal, über den Sie die App installiert haben: TestFlight unter iOS oder das Play-Testprogramm unter Android. Beide sind auf der Seite [Installation](/getting-started/installation) verlinkt. Öffnen Sie die App anschließend erneut.
4. **Website-Administrator:** Wenn noch keine neuere App verfügbar ist, wurde das WCPOS-Plugin des Shops vor der Veröffentlichung der passenden App-Version aktualisiert. Stellen Sie im Shop die vorherige WCPOS-Plugin-Version wieder her, damit die Synchronisierung bis zur Veröffentlichung der neueren App fortgesetzt werden kann.
5. Wenn Sie weder die App aktualisieren noch zur vorherigen Plugin-Version zurückkehren können, wenden Sie sich an den WCPOS-Support.
