## Was das bedeutet {#what-this-means}

Einige Daten wurden diesmal nicht synchronisiert.

Dieser Code tritt in zwei Varianten auf. Der Titel des Protokolleintrags zeigt, welche bei Ihnen vorliegt:

- **„Synchronisierung teilweise abgeschlossen“** (Datensatztitel): Einige Datensätze wurden synchronisiert, die genannten jedoch nicht. Wenn die nächste Synchronisierung das Problem behebt, müssen Sie nichts tun. Falls unter **Shop-Zustand → Datenbank** Änderungen aufgeführt sind, die Ihre Aufmerksamkeit erfordern, bearbeiten Sie diese dort.
- **„Festhängende Datenanfrage aufgegeben“**: Die Synchronisierung kam bei der Verarbeitung einer Datenanfrage nicht weiter. Nach längerer Wartezeit hat die App die Anfrage aufgegeben, damit sie nicht alle nachfolgenden Anfragen blockiert. Sie müssen nichts von Hand erneut versuchen: Die Synchronisierung stellt die Anfrage automatisch erneut. Häufig geht dem ein festhängender lokaler Datenbankaufruf voraus, der separat als [SYNC181](/error-codes/SYNC181) protokolliert wird.

## Ihre Daten {#your-data}

Löschen Sie die Daten auf diesem Gerät nicht — sie können Änderungen enthalten, die noch nicht in Ihrem Shop angekommen sind. Bei einer aufgegebenen Datenanfrage wurde nichts geändert; die Anfrage wird automatisch erneut gestellt. Wenn dies wiederholt passiert, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Bei einem Eintrag **„Festhängende Datenanfrage aufgegeben“** müssen Sie nur dann handeln, wenn ein Bildschirm dauerhaft festhängt. Laden Sie in diesem Fall die App neu: Laden Sie im Web den Browser-Tab neu oder schließen und öffnen Sie die App auf dem Desktop oder Mobilgerät.
2. Bei einer teilweise abgeschlossenen Synchronisierung müssen Sie nichts tun, wenn die nächste Synchronisierung das Problem behebt. Andernfalls öffnen Sie **Shop-Zustand → Datenbank**: Datensätze, die weiterhin nicht synchronisiert wurden, stehen ganz oben. Der Hinweis **„… Datensätze erfordern Ihre Aufmerksamkeit“** nennt den ersten Datensatz mit dem Grund. Sobald Sie ihn korrigiert haben, erscheint der nächste. Die Bereiche **„… Änderungen haben Ihren Server nie erreicht“** und **„… Änderungen wurden zurückgehalten“** führen die jeweils betroffenen Änderungen auf. Bei den erfolgreich synchronisierten Datensätzen müssen Sie nichts tun.
3. Beheben Sie bei jedem aufgeführten Datensatz das jeweils genannte Problem. Im Hinweis öffnet **Datensatz korrigieren** (sofern angezeigt) den Datensatz zur Bearbeitung. Eine abgelehnte Änderung korrigieren Sie direkt am Datensatz ([SYNC201](/error-codes/SYNC201)); bei einer zurückgehaltenen Änderung wählen Sie aus, welche Version beibehalten werden soll ([SYNC221](/error-codes/SYNC221)).
4. Senden Sie die Änderungen anschließend erneut: mit **Erneut versuchen** im Hinweis (dies startet eine Synchronisierung) oder mit **Erneut senden** in der Zeile des Datensatzes in den Bereichen. Bei einem Datensatz, der laut Hinweis *nicht aus Ihrem Shop heruntergeladen werden kann*, gibt es kein **Erneut versuchen** — siehe [SYNC331](/error-codes/SYNC331).
5. Wenn ein Datensatz weiterhin nicht synchronisiert wird, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den Support.
