## Was dies bedeutet {#what-this-means}

Beim Checkout ist ein unerwartetes Problem aufgetreten.

Prüfen Sie die Bestellung in der Filialverwaltung, bevor Sie den Kunden erneut belasten. Exportieren Sie die Diagnosedaten und wenden Sie sich an den Support, wenn das Problem erneut auftritt.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden — prüfen Sie es, bevor Sie den Vorgang wiederholen. Wenn das Problem weiterhin besteht, exportieren Sie die Diagnosedaten und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie in WP Admin unter WooCommerce → Bestellungen, ob die Bestellung vorhanden ist, bevor Sie den Kunden erneut belasten.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode sowie gegebenenfalls serverCode — dieser allgemeine Code bedeutet, dass es für die Ursache noch keinen eigenen Code gibt.
3. Wenn der Fehler erneut auftritt, exportieren Sie die Debug-Informationen und wenden Sie sich an den Support.
