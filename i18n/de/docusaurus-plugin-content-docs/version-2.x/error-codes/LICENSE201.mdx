## Was das bedeutet {#what-this-means}

WCPOS Pro ist deaktiviert, weil seine Version nicht zu WCPOS passt.

Aktualisieren Sie die genannte Komponente WCPOS oder WCPOS Pro, damit beide Versionen kompatibel sind.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Falls das Problem bestehen bleibt, wenden Sie sich an die Person, die Ihre WordPress-Website verwaltet.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie beide Plugin-Versionen unter WP Admin → Plugins — der Protokolleintrag nennt, ob WCPOS oder WCPOS Pro veraltet ist.
2. Aktualisieren Sie das ältere Plugin; wenn Sie beide auf die neuesten Versionen aktualisieren, wird der Versionskonflikt behoben.
3. Falls keine Pro-Updates angeboten werden, ist der Aktualisierungsdienst möglicherweise nicht autorisiert (siehe LICENSE301) — beheben Sie dies zuerst und führen Sie dann das Update durch.
