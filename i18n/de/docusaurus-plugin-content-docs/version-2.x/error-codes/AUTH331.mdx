## Was das bedeutet {#what-this-means}

Das WCPOS-Plugin dieses Shops ist für diese App-Version zu alt.

Die App wurde aktualisiert, das WCPOS-Plugin im Shop jedoch nicht. Die beiden Versionen funktionieren nicht mehr miteinander. Bitten Sie die Person, die die Website verwaltet, das WCPOS-Plugin in WP Admin zu aktualisieren. Stellen Sie anschließend die Verbindung erneut her. An der Kasse muss nichts geändert werden.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Falls das Problem bestehen bleibt, wenden Sie sich an die Person, die Ihre WordPress-Website verwaltet.

## Fehlerbehebung {#troubleshoot}

**Im Shop** — für die Person, die die WordPress-Website verwaltet:

1. WP Admin → Plugins → WCPOS auf die neueste Version aktualisieren. Falls WCPOS Pro installiert ist, aktualisieren Sie es gleichzeitig auf eine passende Version.
2. Wenn keine Aktualisierung angeboten wird, prüfen Sie WP Admin → Dashboard → Aktualisierungen. Bei Pro verhindert ein nicht autorisierter Updater die Aktualisierungen (siehe [LICENSE301](./LICENSE301)) — beheben Sie dies zuerst.

**An der Kasse** — für den Kassierer: Stellen Sie die Verbindung erneut her, sobald der Shop aktualisiert wurde. Sie müssen die Shop-Adresse nicht erneut eingeben.

**Wenn der Shop noch nicht aktualisiert werden kann:** Wenden Sie sich stattdessen an den Support. Die Kasse benötigt eine zum Plugin passende App-Version. Der Support kann Ihnen sagen, welche das ist. Dafür werden die App-Version (von der Kasse) und die aktuelle WCPOS-Version des Shops (aus WP Admin) benötigt.
