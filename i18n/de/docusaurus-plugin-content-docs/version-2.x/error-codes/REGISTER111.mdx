## Was das bedeutet {#what-this-means}

Sie haben eine Einzahlung oder Auszahlung storniert — mit **Rückgängig** in der Bestätigung oder **Stornieren** im Kassenbereich — und Ihr Shop hat die Stornierung abgelehnt.

Die Kasse zeigt die Bewegung als storniert an. Ihr Shop zählt sie weiterhin mit.

## Ihre Daten {#your-data}

Es ist nichts verloren gegangen. Die ursprüngliche Bewegung ist im Shop unverändert vorhanden und die Stornierung existiert nur auf diesem Gerät. Daher unterscheiden sich die Sollbestände der Kassenschublade um den Betrag dieser Bewegung.

## Fehlerbehebung {#troubleshoot}

1. Öffnen Sie die Liste der Ein- und Auszahlungen im Kassenbereich. Die Bewegung, die storniert werden sollte, wird vom Shop weiterhin mitgezählt.
2. Eine Bewegung kann nur einmal storniert werden und nur, solange ihre Sitzung geöffnet ist. Sobald die Zählung beginnt, lehnt Ihr Shop Stornierungen bewusst ab — so wird verhindert, dass sich eine gezählte Schicht während der Zählung verändert.
3. Wenn die Stornierung ein Versehen war, müssen Sie nichts tun: Ihr Shop hat sie nie übernommen.
4. **Erfassen Sie keine Gegenbewegung zum Ausgleich.** Eine neue Bewegung erreicht Ihren Shop *und* diese Kasse. Sie verändert also beide Summen um denselben Betrag, und die Differenz bleibt unverändert. Der Wert Ihres Shops ist korrekt.
5. Rechnen Sie damit, dass der an der Kasse angezeigte Bargeld-Sollbestand bis zur Kassenzählung um diesen Betrag abweicht. Vermerken Sie die Differenz bei der Zählung, damit die Abweichung erklärt ist.
