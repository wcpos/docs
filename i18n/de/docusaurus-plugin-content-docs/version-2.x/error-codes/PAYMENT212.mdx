## Was das bedeutet {#what-this-means}

Das vom Kassierer im Zahlungsbereich gewählte Zahlungsgateway hat die Zahlung abgelehnt oder den Vorgang beendet, ohne sie entgegenzunehmen. Dafür gibt es drei Möglichkeiten: Das Zahlungsgateway meldet einen Fehlschlag mit einer eigenen Nachricht, während der Ausführung tritt ein Fehler auf oder es versucht, den Kunden auf eine andere Website weiterzuleiten, was der POS nicht unterstützen kann.

Die eigene Meldung des Zahlungsgateways oder eine Zeile mit der anderen Website erscheint in der Benachrichtigung an der Kasse und im Protokolleintrag.

Wenn ein Zahlungsgateway lediglich eine Eingabe ablehnt, etwa eine nicht akzeptierte E-Mail-Adresse, erscheint seine Meldung stattdessen ohne Fehlercode im Zahlungsformular — unter dem betreffenden Feld oder unterhalb der Felder.

## Ihre Daten {#your-data}

Der POS hat keine Zahlung erfasst. Die Bestellung ist unverändert, ihre vorherige Zahlungsmethode wurde wiederhergestellt und ihr offener Betrag ist weiterhin fällig.

Falls nach dem Start des Zahlungsgateways ein Fehler aufgetreten ist, fügt der Shop eine Bestellnotiz hinzu. Diese fordert Sie auf, beim Zahlungsanbieter zu prüfen, ob Geld eingezogen wurde.

## Fehlerbehebung {#troubleshoot}

**An der Kasse** — erledigen Sie dies, bevor der Kunde geht:

1. Lesen Sie die Meldung des Zahlungsgateways in der Benachrichtigung oder im Protokolleintrag.
2. Korrigieren Sie die Angaben (die E-Mail-Adresse, die gewählte Option) und senden Sie sie erneut.
3. Falls das Zahlungsgateway die Zahlung weiterhin ablehnt, verwenden Sie eine andere Zahlungsmethode und informieren Sie den Shopinhaber.

**Im Shop** — für den Website-Administrator:

1. Prüfen Sie die Einstellungen des Zahlungsgateways auf der Zahlungsseite von WooCommerce. Wenn ein Zahlungsgateway jeden Versuch ablehnt, ist es meist falsch konfiguriert oder es fehlen Zugangsdaten.
2. Sehen Sie unter *WooCommerce > Status > Protokolle* nach. Das WCPOS-Protokoll mit der Quelle `woocommerce-pos` erfasst Fehler des Zahlungsgateways oder Weiterleitungen auf andere Websites. Viele Zahlungsgateways führen dort auch ein eigenes Protokoll.
3. Prüfen Sie die Bestellnotizen auf eine Notiz des Shops zum Zahlungsversuch.
