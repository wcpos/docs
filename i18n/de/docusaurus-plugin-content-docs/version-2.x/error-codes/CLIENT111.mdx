## Was dies bedeutet {#what-this-means}

Die Synchronisierung startet langsamer als erwartet.

Normalerweise behebt sich das innerhalb einer Minute von selbst. Wenn die App in diesem Zustand bleibt, laden Sie sie einmal neu, bevor Sie etwas anderes tun.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Warten Sie eine Minute — die erste Synchronisierung nach einem Upgrade oder bei einer großen Filiale dauert tatsächlich länger.
2. Wenn die App in diesem Zustand bleibt, laden Sie sie einmal neu.
3. Wenn der Start täglich lange dauert, prüfen Sie Ihre Verbindung zur Filiale. Ist diese in Ordnung, bitten Sie die zuständige Person, die Reaktionsfähigkeit der Website zu prüfen.
