## Was das bedeutet {#what-this-means}

Das Anmeldetoken ist größer, als dieser Server akzeptiert.

Der Server hat das Anmeldetoken wegen seiner Größe abgelehnt: mit einem 400 bei der Übertragung im Authorization-Header oder einem 414 bei der Übertragung in der URL. Keine clientseitige Kodierung kann es verkleinern — die Größenlimits des Servers für Header bzw. URLs müssen erhöht oder das Token muss verkleinert werden.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Erhöhen Sie bei Apache in der vhost-Konfiguration LimitRequestFieldSize (für die Übertragung im Header) oder LimitRequestLine (für die Übertragung in der URL).
2. Erhöhen Sie bei nginx large_client_header_buffers.
3. Wenn ein Proxy oder CDN vorgeschaltet ist, kann das Limit dort liegen — prüfen Sie beide Ebenen.
4. Falls die Limits nicht geändert werden können, wenden Sie sich an den Support, um ein kleineres Token für diese Website ausstellen zu lassen.
