## Was das bedeutet {#what-this-means}

Die Kasse hat eine Zahlung angenommen, die den im Shop gespeicherten offenen Betrag dieser Bestellung übersteigt. Der Shop hat die Verbuchung abgelehnt. Der Versuch bleibt als fehlgeschlagene Zahlung an der Bestellung gespeichert, sodass nichts verborgen bleibt.

Der Bestellung wurde nichts gutgeschrieben, aber das Geld liegt bereits in der Kassenschublade oder wurde bereits über die Karte des Kunden eingezogen. Deshalb sind zwei Schritte nötig: Der Kunde erhält die Differenz zurück, und der tatsächlich offene Betrag wird aus dem bereits erhaltenen Geld für die Bestellung verbucht.

Normalerweise bedeutet dies, dass die Bestellung an anderer Stelle geändert wurde — an einer anderen Kasse oder direkt in WooCommerce — nachdem diese Kasse sie zuletzt abgerufen hat.

## Ihre Daten {#your-data}

Es ist Geld geflossen, aber Ihr Shop hat es nicht verbucht. Die Differenz zwischen dem kassierten und dem für die Bestellung offenen Betrag muss dem Kunden zurückgegeben werden.

## Fehlerbehebung {#troubleshoot}

**An der Kasse** — erledigen Sie dies, bevor der Kunde geht:

1. Fordern Sie den Kunden nicht erneut zur Zahlung auf. Die abgelehnte Zahlung wurde zwar nie verbucht, aber das Geld liegt bereits in Ihrer Kassenschublade oder wurde bereits über seine Karte eingezogen.
2. Prüfen Sie, welcher Betrag laut Ihrem Shop für die Bestellung offen war — dieser Wert ist korrekt. Der Eintrag unter **Shop-Zustand → Protokolle** nennt ihn normalerweise, zum Beispiel *„Für Bestellung #… waren nur noch … offen; an der Kasse wurden … kassiert“*. Falls der Betrag dort fehlt, zeigt ihn der aktualisierte Zahlungsbereich in Schritt 3 an.
3. Aktualisieren Sie die Bestellung, bevor Sie etwas verbuchen: Öffnen Sie **Shop-Zustand → Datenbank**, öffnen Sie das Menü **⋮** in der Zeile **Bestellungen** und wählen Sie **Jetzt auf Änderungen prüfen**, damit der Zahlungsbereich den offenen Betrag aus dem Shop anzeigt.
4. Verbuchen Sie diesen offenen Betrag aus dem bereits erhaltenen Geld für die Bestellung. Dieser Fehler tritt nur bei Zahlungsarten auf, die Zahlungen lediglich erfassen, etwa Bargeld oder eine manuell erfasste Kartenzahlung: Wählen Sie im Zahlungsbereich dieselbe Zahlungsart, tippen Sie auf **Passend …** (Bargeld) oder **Gesamter offener Betrag …** und erfassen Sie die Zahlung. Wählen Sie dafür niemals eine Zahlungsart über ein Kartenterminal oder Zahlungsgateway — dadurch wird eine neue Belastung ausgelöst. Nehmen Sie kein weiteres Geld vom Kunden an.
5. Geben Sie dem Kunden die Differenz zwischen dem kassierten und dem für die Bestellung offenen Betrag zurück — bar aus der Kassenschublade oder als Rückerstattung der Differenz am Kartenterminal oder im Dashboard Ihres Zahlungsanbieters.

**Im Shop** — für den Website-Administrator:

1. Der abgelehnte Versuch und sein Grund stehen unter **Shop-Zustand → Protokolle** auf der Kasse, die die Zahlung angenommen hat. Die Bestellung unter **WooCommerce → Bestellungen** zeigt nur, was der Shop akzeptiert hat.
2. Wenn dies bei derselben Bestellung wiederholt auftritt, wird sie gleichzeitig an anderer Stelle beglichen — etwa an einer zweiten Kasse oder durch eine eingehende Onlinezahlung, während die Bestellung an der Kasse geöffnet ist.
