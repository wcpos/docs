## Was das bedeutet {#what-this-means}

Bei der Synchronisierung ist ein unerwartetes Problem aufgetreten.

Prüfen Sie, ob die in diesem Eintrag genannte Aktion abgeschlossen wurde. Falls nicht, wiederholen Sie sie. Wenn das Problem erneut auftritt, tippen Sie auf **Debug-Informationen kopieren** und senden Sie die Informationen an den Support.

## Ihre Daten {#your-data}

Löschen Sie die Daten auf diesem Gerät nicht — sie können Änderungen enthalten, die noch nicht in Ihrem Shop angekommen sind. Wenn die im Eintrag genannte Aktion nicht abgeschlossen wurde, wiederholen Sie sie.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie den Protokolleintrag auf und sehen Sie nach, welche Aktion er nennt. Prüfen Sie, ob sie abgeschlossen wurde. Bei einem Speichervorgang öffnen Sie die Bestellung oder den Datensatz und prüfen, ob die Änderung angezeigt wird. Ist das der Fall, sendet WCPOS sie automatisch. Sie müssen dann nichts weiter tun.
2. Wenn die Aktion nicht abgeschlossen wurde, wiederholen Sie sie. Wenn der Protokolleintrag besagt, dass die Änderung nie auf diesem Gerät gespeichert wurde, wurde nichts erfasst.
3. Notieren Sie den Code und einen gegebenenfalls im Protokolleintrag genannten Grund: Ein 999-Code bedeutet, dass es für die konkrete Ursache noch keinen eigenen Code gibt. Genau diese Informationen benötigt der Support.
4. Wenn das Problem erneut auftritt, tippen Sie im Tab **Protokolle** auf **Debug-Informationen kopieren** und senden Sie die Informationen an den Support. Ihre Meldung hilft dabei, einen eigenen Code für diese Ursache hinzuzufügen.
