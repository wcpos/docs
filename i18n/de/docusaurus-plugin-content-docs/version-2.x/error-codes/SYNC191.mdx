## Was das bedeutet {#what-this-means}

Diese Änderung ist noch auf dem Weg zu Ihrem Shop.

Sie müssen nichts tun — geben Sie die Änderung nicht erneut ein. Sie wird automatisch gesendet und angezeigt, sobald der Shop sie bestätigt.

Ein Verkauf oder eine Änderung wurde auf diesem Gerät gespeichert und gesendet, aber Ihr Shop hat den Empfang nicht innerhalb der üblichen Wartezeit bestätigt. Meist antwortet der Shop langsam oder die Verbindung ist unzuverlässig. WCPOS sendet weiter, bis der Shop den Empfang bestätigt. Der Shop erkennt eine Änderung, die er bereits erhalten hat. Daher können Sie dieselbe Schaltfläche gefahrlos erneut drücken. Den Verkauf oder Datensatz von Hand erneut einzugeben, ist dagegen nicht sicher: Dadurch entsteht ein zweiter, separater Eintrag — ein Duplikat.

## Ihre Daten {#your-data}

Es geht nichts verloren. Die Änderung wartet auf diesem Gerät und wird automatisch gesendet. Löschen Sie die Daten dieses Geräts nicht, solange sie auf das Senden wartet.

## Fehlerbehebung {#troubleshoot}

1. Geben Sie den Verkauf oder die Änderung nicht von Hand erneut ein — dadurch entsteht ein Duplikat.
2. Warten Sie, bis der Eintrag Ihren Shop erreicht. Ein Verkauf wird bereits in WCPOS angezeigt (im Warenkorb oder bei WCPOS Pro unter **Bestellungen**), weil er auf diesem Gerät gespeichert ist. Prüfen Sie **WooCommerce → Bestellungen** in WP Admin, um sicherzustellen, dass er den Shop erreicht hat.
3. Um den Fortschritt zu verfolgen, öffnen Sie **Shop-Zustand → Protokolle**: Die Anzahl bei **Änderungen warten auf das Senden** in der Kopfzeile sinkt, während Änderungen gesendet werden, und zeigt 0 an, sobald nichts mehr wartet.
4. Wenn der Eintrag lange aussteht, prüfen Sie die Verbindung dieses Geräts und ob sich die Website Ihres Shops laden lässt — siehe [SYNC121](/error-codes/SYNC121).
5. Wenn der Eintrag auch bei wieder funktionierender Verbindung noch nicht erschienen ist, tippen Sie auf **Debug-Informationen kopieren** auf der Registerkarte **Protokolle** und wenden Sie sich an den Support.
