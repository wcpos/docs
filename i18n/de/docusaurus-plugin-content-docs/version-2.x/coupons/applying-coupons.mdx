Ein Kunde gibt Ihnen einen Gutscheincode, oder Sie führen eine Werbeaktion durch. Hier erfahren Sie, wie Sie einen Gutschein Ihres Shops auf den Verkauf im Warenkorb anwenden. Das funktioniert auch mit dem kostenlosen Plugin.

:::note Der Gutschein stammt aus Ihrem Shop
Die Kasse wendet Gutscheine an, die bereits in Ihrem Shop vorhanden sind. Erstellen Sie diese unter **WP Admin → Marketing → Gutscheine**; siehe [Gutscheine](./index.mdx#creating-coupons). Für einen Preisnachlass ohne Gutschein verwenden Sie stattdessen [Rabatt hinzufügen](../pos/cart/discounts.mdx#order-level-discounts).
:::

## Den Gutschein finden {#find}

1. Wenn die Artikel im Warenkorb liegen, drücken Sie oben im Warenkorb auf **+** und wählen Sie **Rabatt hinzufügen**. Auf einem Smartphone hat der Warenkorb eine eigene Registerkarte: Öffnen Sie diese zuerst.
2. Wechseln Sie zu **Gutschein** und drücken Sie auf **Gutschein auswählen**.
3. Geben Sie einen Teil des Codes oder der Gutscheinbeschreibung ein und tippen Sie auf den Gutschein.
4. Drücken Sie auf **Anwenden**.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 0], [0, 0], [-24, 0], [-30, 0], [-30, 0], [0, -34], [0, -44]]} alt="Der Dialog „Rabatt hinzufügen“ auf der Registerkarte „Gutschein“ mit geöffneter Gutscheinliste: die Registerkarten „Schnellrabatt“ und „Gutschein“, das Feld „Gutschein auswählen“, das Suchfeld, ein Gutschein mit Typ und Betrag sowie die Schaltflächen „Neuer Gutschein“ und „Anwenden“">

1. **Schnellrabatt** — ein fester oder prozentualer Nachlass auf die Bestellung, ohne Gutschein. Siehe [Rabatte](../pos/cart/discounts.mdx#order-level-discounts).
2. **Gutschein** — die Gutscheine Ihres Shops.
3. **Gutschein auswählen** — öffnet die Liste. Sobald Sie einen auswählen, erscheint hier sein Code.
4. **Gutscheine suchen** — geben Sie einen beliebigen Teil des Codes oder der Beschreibung ein. Groß- und Kleinschreibung spielt keine Rolle.
5. **Ein Gutschein** — sein Code, gefolgt von seiner Beschreibung oder, falls keine vorhanden ist, seinem Typ: **Prozentualer Rabatt**, **Fester Warenkorbrabatt** oder **Fester Produktrabatt**. Rechts steht der Betrag, der abgezogen wird.
6. **Neuer Gutschein** (WCPOS Pro) — erstellen Sie direkt einen Gutschein und wenden Sie ihn auf diesen Verkauf an. Dafür benötigen Sie die Berechtigung zum Erstellen von Gutscheinen und eine Verbindung zu Ihrem Shop; andernfalls ist das **+** ausgegraut.
7. **Anwenden** — prüft die Regeln des Gutscheins für diese Bestellung und wendet ihn an.

</JourneyShot>

Die Liste zeigt alle Gutscheine Ihres Shops, auch abgelaufene oder aufgebrauchte. Die Kasse prüft die Regeln erst, wenn Sie auf **Anwenden** drücken, nicht schon bei der Auswahl.

## Den Gutschein anwenden {#apply}

Wenn Sie auf **Anwenden** drücken, schließt sich der Dialog und der Gutschein erscheint in der Summenübersicht unter **Zwischensumme**: mit seinem Code, einem **✕** zum Entfernen und dem abgezogenen Betrag. Jeder hinzugefügte Gutschein erhält eine eigene Zeile, in der Reihenfolge der Anwendung. Um einen weiteren hinzuzufügen, öffnen Sie erneut **Rabatt hinzufügen**.

Auch die Artikel im Warenkorb zeigen ihren jeweiligen Anteil: Die Summe jeder Position sinkt, und der alte Betrag wird durchgestrichen.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-28, 0], [100, 0], [40, 0], [40, 0], [0, 0]]} alt="Der Warenkorb mit zwei angewendeten Gutscheinen: das Menü zum Hinzufügen, die Zwischensumme, eine Zeile je Gutschein mit Code, Schaltfläche zum Entfernen und abgezogenem Betrag, die Artikelsumme mit durchgestrichenem altem Betrag sowie die Schaltfläche „Kasse“">

1. **+** — öffnen Sie erneut **Rabatt hinzufügen**, um einen weiteren Gutschein hinzuzufügen.
2. **Zwischensumme** — die Bestellsumme vor Abzug der Gutscheine. Die Gutscheinzeilen stehen darunter.
3. **Ein Gutschein** — sein Code, das **✕** zum Entfernen und der abgezogene Betrag.
4. **Der nächste Gutschein** — jeder Gutschein erhält eine eigene Zeile, in der Reihenfolge der Anwendung.
5. **Kasse** — nehmen Sie die Zahlung für die Bestellung entgegen. Siehe [Kasse](../pos/checkout/index.mdx).

</JourneyShot>

Auf dem Beleg wird die Gutscheinbeschreibung aus WooCommerce gedruckt oder, falls keine vorhanden ist, der Code. Ein offline gedruckter Beleg zeigt den Code. Wenn Sie den Warenkorb ändern, wird der Betrag jedes Gutscheins neu berechnet: Fügen Sie einen Artikel hinzu, zieht ein prozentualer Gutschein mehr ab.

Die Gutscheinprüfung nutzt die Daten auf diesem Gerät. Daher lassen sich Gutscheine auch offline anwenden. Ihr Shop kann die Summe dennoch ändern oder die Bestellung ablehnen, wenn er sie empfängt; siehe [Wenn etwas schiefgeht](#goes-wrong).

## Einen Gutschein entfernen {#remove}

Drücken Sie in der Summenübersicht auf **✕** in der Gutscheinzeile. Der abgezogene Betrag wird wieder hinzugerechnet, und die Meldung **Gutschein entfernt** erscheint. Um ihn wieder hinzuzufügen, wenden Sie ihn erneut an.

Beim Bezahlvorgang haben die Gutscheinzeilen kein **✕**, damit sich ein Gutschein während der Zahlung nicht ändern lässt. Drücken Sie oben im Bezahlvorgang auf **✕**, um zum Warenkorb zurückzukehren, ändern Sie dort die Gutscheine und drücken Sie dann erneut auf **Kasse**. {/* pending: monorepo#3364 */}

Beim [Verwerfen](../pos/cart/order-actions.mdx#void) der Bestellung werden auch ihre Gutscheine entfernt.

## Wenn die Kasse einen Gutschein ablehnt {#refused}

Wenn der Gutschein nicht zu dieser Bestellung passt, bleibt der Dialog geöffnet und zeigt den Grund in Rot über dem Gutschein an. Wählen Sie einen anderen Gutschein oder drücken Sie auf **Abbrechen**.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-24, 0], [0, -44]]} alt="Der Dialog „Rabatt hinzufügen“ nach dem Anwenden, mit der roten Meldung „Dieser Gutschein ist abgelaufen“ über dem Feld „Gutschein“">

1. **Gutschein auswählen** — der Gutschein, den Sie anwenden wollten. Die rote Zeile darüber erklärt, warum er nicht angewendet wurde. Wählen Sie hier einen anderen Gutschein.
2. **Anwenden** — versuchen Sie es erneut, sobald die Bestellung die Voraussetzungen erfüllt.

</JourneyShot>

Suchen Sie unten nach der Ursache. Jeder Eintrag nennt die genaue Meldung der Kasse, den Grund und die nächsten Schritte:

<Accordion>
  <AccordionItem question="Gutschein abgelaufen">

Die Kasse meldet: **Dieser Gutschein ist abgelaufen.**

Das Ablaufdatum des Gutscheins ist überschritten, daher lässt er sich nicht mehr verwenden. Wählen Sie einen anderen Gutschein. Soll der Gutschein weiterhin gelten, kann sein Datum im Shop unter WP Admin geändert werden.

  </AccordionItem>
  <AccordionItem question="Gutschein aufgebraucht">

Die Kasse meldet: **Dieser Gutschein hat sein Nutzungslimit erreicht.**

Der Gutschein wurde bereits so oft verwendet, wie der Shop es erlaubt. Wählen Sie einen anderen Gutschein.

  </AccordionItem>
  <AccordionItem question="Kunde hat sein Nutzungslimit erreicht">

Die Kasse meldet: **Dieser Kunde hat diesen Gutschein bereits so oft wie maximal zulässig verwendet.**

Der Kunde dieser Bestellung hat sein Nutzungslimit für diesen Gutschein erreicht. Prüfen Sie, ob der richtige Kunde der Bestellung zugeordnet ist, oder wählen Sie einen anderen Gutschein.

  </AccordionItem>
  <AccordionItem question="Mindestbestellwert nicht erreicht">

Die Kasse meldet: **Dieser Gutschein erfordert einen Mindestbestellwert von …**

Die Bestellung liegt unter dem Mindestbestellwert des Gutscheins. Die Meldung nennt den erforderlichen Betrag. Fügen Sie weitere Artikel hinzu oder wählen Sie einen anderen Gutschein.

  </AccordionItem>
  <AccordionItem question="Maximalbestellwert überschritten">

Die Kasse meldet: **Dieser Gutschein gilt nur für Bestellungen bis zu einem Wert von …**

Die Bestellung liegt über dem Maximalbestellwert des Gutscheins. Die Meldung nennt den zulässigen Betrag. Erfassen Sie einige Artikel als separaten Verkauf oder wählen Sie einen anderen Gutschein.

  </AccordionItem>
  <AccordionItem question="Der neue Gutschein darf nur einzeln angewendet werden">

Die Kasse meldet: **… kann nicht mit anderen Gutscheinen kombiniert werden. Entfernen Sie die anderen, um ihn zu verwenden.**

Der ausgewählte Gutschein muss der einzige Gutschein der Bestellung sein. Entfernen Sie die bereits angewendeten Gutscheine und wenden Sie dann diesen an.

  </AccordionItem>
  <AccordionItem question="Ein bereits angewendeter Gutschein darf nur einzeln verwendet werden">

Die Kasse meldet: **… ist bereits auf die Bestellung angewendet und kann nicht mit anderen Gutscheinen kombiniert werden.**

Ein Gutschein der Bestellung muss der einzige sein; die Meldung nennt ihn. Entfernen Sie diesen Gutschein, wenn Sie lieber den neuen verwenden möchten. Andernfalls behalten Sie ihn bei und verzichten auf den neuen.

  </AccordionItem>
  <AccordionItem question="Gutschein bereits auf die Bestellung angewendet">

Die Kasse meldet: **Dieser Gutschein ist bereits auf die Bestellung angewendet.**

Jeder Gutschein lässt sich pro Bestellung einmal anwenden, und dieser ist bereits angewendet. Sie müssen nichts weiter tun.

  </AccordionItem>
  <AccordionItem question="Keine Kunden-E-Mail-Adresse in der Bestellung">

Die Kasse meldet: **Dieser Gutschein ist auf bestimmte Kunden beschränkt. Fügen Sie der Bestellung zuerst einen Kunden mit einer E-Mail-Adresse hinzu.**

Der Gutschein gilt nur für bestimmte E-Mail-Adressen, und der Bestellung ist noch keine Kunden-E-Mail-Adresse zugeordnet. Wählen Sie den Kunden im Warenkorb aus und wenden Sie den Gutschein erneut an.

  </AccordionItem>
  <AccordionItem question="E-Mail-Adresse des Kunden nicht in der Liste">

Die Kasse meldet: **Dieser Gutschein ist auf bestimmte Kunden beschränkt, und die E-Mail-Adresse dieses Kunden gehört nicht dazu.**

Die E-Mail-Adresse des Kunden steht nicht in der Liste des Gutscheins. Prüfen Sie, ob der richtige Kunde der Bestellung zugeordnet ist, oder wählen Sie einen anderen Gutschein.

  </AccordionItem>
  <AccordionItem question="Keine passenden Artikel im Warenkorb">

Die Kasse meldet: **Dieser Gutschein kann nicht auf diesen Warenkorb angewendet werden.**

Keiner der Artikel im Warenkorb wird vom Gutschein abgedeckt. Oder der Gutschein schließt reduzierte Artikel aus, und der Warenkorb enthält einen solchen Artikel. Fügen Sie einen passenden Artikel hinzu oder entfernen Sie den reduzierten Artikel. Siehe [Preisänderungen und Gutscheine](#price-changes).

  </AccordionItem>
  <AccordionItem question="Gutschein nicht auf diesem Gerät vorhanden">

Die Kasse meldet: **Gutschein nicht gefunden**

Der Gutschein ist noch nicht auf diesem Gerät vorhanden. [Rufen Sie die Gutscheine ab](#sync) und versuchen Sie es erneut.

  </AccordionItem>
  <AccordionItem question="Warenkorb während der Prüfung geändert">

Die Kasse meldet: **Der Warenkorb wurde während der Gutscheinanwendung geändert. Bitte versuchen Sie es erneut.**

Der Warenkorb wurde geändert, während die Kasse den Gutschein geprüft hat. Drücken Sie erneut auf **Anwenden**.

  </AccordionItem>
</Accordion>

## Mehrere Gutscheine {#more-than-one}

Sie können mehrere Gutscheine auf eine Bestellung anwenden: Öffnen Sie für jeden erneut **Rabatt hinzufügen**. Ein Gutschein mit der Einstellung **Nur einzeln anwendbar** lässt sich nicht mit anderen Gutscheinen in derselben Bestellung verwenden, unabhängig von der Reihenfolge. Die Kasse nennt den Gutschein, der die Kombination verhindert.

<Accordion>
  <AccordionItem question="Wie ein zweiter Gutschein berechnet wird">

Das hängt von der WooCommerce-Einstellung **Gutscheinrabatte nacheinander berechnen** unter **WP Admin → WooCommerce → Einstellungen → Allgemein** ab. Die Kasse übernimmt die Einstellung Ihres Shops.

Zwei Gutscheine über 10% bei einer Bestellung über $100.00:

- **Aus** (Standardeinstellung von WooCommerce): Jeder Gutschein zieht 10% von $100.00 ab, also jeweils $10.00. Der Kunde zahlt **$80.00**.
- **Ein**: Der erste Gutschein zieht $10.00 ab. Der zweite zieht 10% der verbleibenden $90.00 ab, also $9.00. Der Kunde zahlt **$81.00**.

Wenn die Einstellung aktiviert ist, kann die Reihenfolge der Anwendung die Summe beeinflussen. Ein Gutschein mit festem Warenkorbrabatt, etwa $5 auf die Bestellung, zieht in beiden Fällen denselben Betrag ab.

  </AccordionItem>
</Accordion>

## Preisänderungen und Gutscheine {#price-changes}

Ein Gutschein wird anhand des Preises der Position berechnet. Wenn Sie den Preis eines Artikels an der Kasse gesenkt haben, zieht der Gutschein seinen Anteil vom niedrigeren Preis ab, nicht vom ursprünglichen.

<Accordion>
  <AccordionItem question="Gutscheine, die reduzierte Artikel ausschließen">

Ein Artikel, dessen Preis Sie gesenkt haben, gilt als reduziert. Ein Gutschein mit der Einstellung **Reduzierte Artikel ausschließen** überspringt ihn. Ein Gutschein mit festem Warenkorbrabatt und der Einstellung **Reduzierte Artikel ausschließen** lässt sich nicht anwenden, solange dieser Artikel im Warenkorb liegt. Siehe [Wie POS-Preisänderungen mit Gutscheinen zusammenwirken](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons).

  </AccordionItem>
</Accordion>

## Wenn etwas schiefgeht {#goes-wrong}

**Der Gutschein fehlt in der Liste.** <Anchor id="sync" />Dieses Gerät hat ihn noch nicht abgerufen. So rufen Sie ihn jetzt ab:

1. Öffnen Sie im Menü **Shop-Zustand** und dann **Datenbank**.
2. Öffnen Sie in der Gutscheinzeile **Weitere Aktionen** und wählen Sie **Jetzt auf Änderungen prüfen**.
3. Öffnen Sie erneut **Rabatt hinzufügen** und suchen Sie nach dem Gutschein.

Falls er weiterhin fehlt, wählen Sie in derselben Zeile **Leeren & erneut herunterladen…**. Die Kasse ruft alle Gutscheine erneut ab. Siehe [Leeren & erneut herunterladen](../support/store-health.mdx#clear-and-redownload).

<Accordion>
  <AccordionItem question="Wie Gutscheine an die Kasse gelangen">

Die Kasse ruft Ihre Gutscheine ab, wenn Sie die Liste zum ersten Mal öffnen. Danach prüft sie Ihren Shop regelmäßig auf Änderungen: mit der Standardvorgabe alle 60 Sekunden. Ein in WP Admin erstellter Gutschein erscheint normalerweise innerhalb dieses Zeitraums. Siehe [Synchronisierungsvorgaben](../support/store-health.mdx#sync-presets).

Mit WCPOS Pro gibt es auf der Seite **Gutscheine** am Ende der Liste eine Synchronisierungsschaltfläche. Halten Sie diese gedrückt, um **Leeren und aktualisieren** aufzurufen. Damit werden alle Gutscheine erneut abgerufen.

  </AccordionItem>
</Accordion>

**Ihr Shop hat die Summen dieser Bestellung geändert.** Der Shop hat beim Empfang der Bestellung andere Summen berechnet. Maßgeblich sind die Beträge des Shops; prüfen Sie die Gesamtsumme, bevor Sie die Ware übergeben.

**Bestellung nicht gespeichert — der Shop hat sie abgelehnt.** Der Shop hat die Bestellung nicht angenommen, und der Verkauf liegt unverändert im Warenkorb. Die Meldung nennt den Grund des Shops oder zeigt **Der Shop hat keinen Grund angegeben** an. Wird ein Gutschein als Grund genannt, entfernen Sie ihn und drücken Sie erneut auf **Kasse**. Die Schaltfläche **Shop-Zustand** in der Meldung zeigt, was der Shop abgelehnt hat; siehe [Änderungen, die Ihren Server nie erreicht haben](../support/store-health.mdx#refused-changes).

## Bewährte Gutscheinkonfigurationen für die Kasse {#common-setups}

Diese werden unter **WP Admin → Marketing → Gutscheine** erstellt. Die Feldnamen stammen aus WooCommerce.

<Accordion>
  <AccordionItem question="Ein nachvollziehbarer Rabatt durch die Filialleitung">

Erstellen Sie einen Gutschein namens `mgr10`:
- **Rabattart:** Prozentualer Rabatt
- **Gutscheinbetrag:** 10
- **Nur einzeln anwendbar:** aus, damit er zusammen mit einem Kundengutschein verwendet werden kann
- **Beschreibung:** „Filialleitungsrabatt“, damit Kassierer ihn über die Suche nach *Filialleitung* finden

Geben Sie den Code nur an die Filialleitung weiter. Anders als eine Preissenkung an der Kasse fließt er in WooCommerce in die Summe **Rabatt** ein und erscheint in Berichten. Siehe [POS-Rabatte und WooCommerce-Gutscheine im Vergleich](../pos/cart/discounts.mdx#pos-discounts-vs-woocommerce-coupons).

  </AccordionItem>

  <AccordionItem question="Eine Belohnung für einen wiederkehrenden Kunden">

Erstellen Sie einen Gutschein namens `loyal5`:
- **Rabattart:** Fester Warenkorbrabatt
- **Gutscheinbetrag:** 5
- **Mindestbestellwert:** 25 oder ein von Ihnen festgelegter Schwellenwert
- **Nutzungslimit pro Benutzer:** 1, wenn die Belohnung nur einmal gelten soll
- **Beschreibung:** „Treuebonus“

Suchen Sie an der Kasse nach *Treue*, um den Gutschein ohne Code zu finden. Wählen Sie vor dem Anwenden den Kunden aus, damit die Nutzung auf das benutzerbezogene Limit angerechnet werden kann.

  </AccordionItem>

  <AccordionItem question="Ein Flyer oder eine gedruckte Werbeaktion">

Erstellen Sie pro Aktion einen Gutschein. Setzen Sie **Nutzungslimit pro Gutschein** für einen einmalig einlösbaren Gutschein auf 1 oder für einen gemeinsam verwendeten Code auf einen höheren Wert. Legen Sie ein **Gutschein-Ablaufdatum** fest, damit er nach der Aktion nicht mehr verwendet werden kann. Soll ein gemeinsam verwendeter Code pro Kunde einmal gelten, setzen Sie auch **Nutzungslimit pro Benutzer** auf 1.

  </AccordionItem>

  <AccordionItem question="Ein Kunde bringt einen Gutschein mit und Sie möchten einen Rabatt der Filialleitung ergänzen">

Wenden Sie zuerst den Kundengutschein und dann den Gutschein der Filialleitung an. Hat der Kundengutschein die Einstellung **Nur einzeln anwendbar**, lehnt die Kasse den zweiten ab. Entscheiden Sie, welchen der Kunde erhält, oder verwenden Sie [Rabatt hinzufügen](../pos/cart/discounts.mdx#order-level-discounts) für den zusätzlichen Betrag.

  </AccordionItem>
</Accordion>

:::info Mit WCPOS Pro
**Neuer Gutschein** erstellt einen Gutschein an der Kasse und wendet ihn auf den Verkauf an. Die Seite **Gutscheine** zeigt alle Gutscheine mit Betrag, Typ, Nutzung und Ablaufdatum; im kostenlosen Plugin erscheint sie als Vorschau.
:::
