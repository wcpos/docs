Manche Produkte gehören nur an die Kasse, andere nur in den Onlineshop. Aktivieren Sie **Produkte nur im POS aktivieren**, und jedes Produkt erhält eine **POS-Sichtbarkeit** mit drei Auswahlmöglichkeiten:

| POS-Sichtbarkeit | Ihre Website | Der POS |
|------------|--------------|-----|
| **POS & Online** (die Ausgangseinstellung für jedes Produkt) | Sichtbar | Sichtbar |
| **Nur POS** | Verborgen | Sichtbar |
| **Nur Online** | Sichtbar | Verborgen |

:::note Einstellung in WP Admin
Sie legen die POS-Sichtbarkeit in WP Admin fest. Der POS richtet sich danach; an der Kasse gibt es dafür keine Einstellung. Fehlt ein Produkt an der Kasse? Siehe [Wenn etwas schiefgeht](#troubleshooting).
:::

## Funktion einschalten {#enabling-the-feature}

Gehen Sie in WP Admin zu **POS > Einstellungen > Allgemein**. Schalten Sie unter **Produkte** die Option **Produkte nur im POS aktivieren** ein. Die Einstellung wird sofort gespeichert. Jedes Produkt hat nun eine **POS-Sichtbarkeit**: **POS & Online**, wenn Sie noch nichts festgelegt haben, oder die zuvor gespeicherte Auswahl, falls Sie diese Funktion schon einmal verwendet haben.

Wenn Sie alle Produkte an beiden Orten verkaufen, lassen Sie die Funktion ausgeschaltet. Bei ausgeschalteter Funktion blendet die POS-Sichtbarkeit nichts aus; die eigenen Sichtbarkeitseinstellungen von WooCommerce gelten weiterhin.

:::warning
Wenn Sie die Funktion wieder ausschalten oder WCPOS deaktivieren, können Ihre Produkte mit der Einstellung Nur POS wieder auf Ihrer Website erscheinen, soweit ihre WooCommerce-Sichtbarkeit dies zulässt. Siehe [Funktion ausschalten](#switch-off).
:::

## Sichtbarkeit eines Produkts festlegen {#setting-product-visibility}

### Ein einzelnes Produkt {#individual-products}

1. Gehen Sie in WP Admin zu **Produkte** und öffnen Sie das Produkt.
2. Drücken Sie im Bereich **Veröffentlichen** neben **POS-Sichtbarkeit** auf **Bearbeiten**.
3. Wählen Sie **POS & Online**, **Nur POS** oder **Nur Online** und drücken Sie auf **OK**.
4. Drücken Sie auf **Aktualisieren**.

In der Produktliste bietet **Schnellbearbeitung** für ein Produkt dieselbe Auswahl für die **POS-Sichtbarkeit**.

### Mehrere Produkte gleichzeitig {#bulk-editing}

1. Gehen Sie in WP Admin zu **Produkte** und markieren Sie die Produkte.
2. Wählen Sie unter **Mehrfachaktionen** den Eintrag **Bearbeiten** und drücken Sie auf **Übernehmen**.
3. Wählen Sie eine Option unter **POS-Sichtbarkeit**. Bei **— Keine Änderung —** behält jedes Produkt seine eigene Einstellung.
4. Drücken Sie auf **Aktualisieren**.

### Varianten {#variable-products}

Jede Variante hat eine eigene **POS-Sichtbarkeit** in ihrem Bereich unter **Varianten**. Drücken Sie abschließend auf **Änderungen speichern**. So können Sie jede Farbe online und nur einige an der Kasse verkaufen oder eine Größe dem Ladengeschäft vorbehalten. Um ein ganzes variables Produkt umzustellen, ändern Sie stattdessen die **POS-Sichtbarkeit** des Produkts selbst: Ein Produkt mit **Nur Online** hat keine Kachel an der Kasse, und ein Produkt mit **Nur POS** wird mit allen Varianten aus Ihrem Onlineshop ausgeblendet.

### Produkte wiederfinden {#find-them}

Die Produktliste erhält über der Tabelle neben **Veröffentlicht** zwei zusätzliche Ansichten: **Nur POS** und **Nur Online**, jeweils mit der Anzahl. Klicken Sie auf eine davon, um nur diese Produkte aufzulisten.

## Im POS {#how-it-affects-the-pos}

Ein Produkt mit **Nur Online** ist an der Kasse überhaupt nicht vorhanden. Es erscheint nicht im Produktbereich, wird von der Suche nicht gefunden, und beim Scannen seines Barcodes erscheint **Barcode nicht gefunden**. Produkte mit **Nur POS** und **POS & Online** lassen sich wie gewohnt verkaufen.

Wenn Sie die Sichtbarkeit eines Produkts ändern, übernimmt der POS dies bei seiner nächsten Prüfung Ihres Shops auf Änderungen: Ein Produkt mit Nur Online verschwindet und erscheint wieder, wenn Sie die Einstellung zurücksetzen. Um die Prüfung sofort auszuführen, drücken Sie auf den Pfeil neben der Produktanzahl.

## Auf Ihrer Website {#where-pos-only-products-stay-visible}

Ein Produkt mit **Nur POS** wird für Käufer ausgeblendet:

- Es wird nicht aufgelistet: weder im Shop noch auf Kategorieseiten, in der Suche, unter ähnlichen Produkten, in Produktblöcken, Feeds oder Sitemaps.
- Es kann nicht in den Warenkorb gelegt oder online gekauft werden. Ein direkter Link öffnet weiterhin die Produktseite, wie bei der WooCommerce-Einstellung **Verborgen**. Dort kann es jedoch nicht in den Warenkorb gelegt werden.
- Eine Variante mit **Nur POS** wird in der Auswahl auf der Produktseite ausgelassen. Das Produkt bleibt mit seinen übrigen Varianten online verfügbar.

<details>
<summary>Katalogsichtbarkeit und wo Produkte mit Nur POS weiterhin erscheinen</summary>

WCPOS blendet ein Produkt mit Nur POS aus, indem es dessen WooCommerce-**Katalogsichtbarkeit** auf **Verborgen** setzt. Solange das Produkt auf Nur POS eingestellt ist, bleibt die **Katalogsichtbarkeit** im Bereich Veröffentlichen auf **Verborgen** gesperrt, mit dem Hinweis *Produkte mit Nur POS werden nie im Onlinekatalog oder in der Suche angezeigt.* Stellen Sie es wieder auf **POS & Online** oder **Nur Online**, und WCPOS stellt die vorherige Katalogsichtbarkeit wieder her. Der Bereich Veröffentlichen zeigt Ihnen diese an, bevor Sie auf **Aktualisieren** drücken. Ein Produkt, das zuvor immer sichtbar war, erhält wieder **Shop und Suchergebnisse**. Wenn Sie eine andere Katalogsichtbarkeit wünschen, ändern Sie diese nach der Aktualisierung. Varianten haben in WooCommerce keine eigene Katalogsichtbarkeit, daher wird bei ihnen nichts gesperrt.

Das Ausblenden gilt nur für Käufer. Wo Sie Ihren Shop verwalten, bleibt ein Produkt mit Nur POS sichtbar:

- **WP Admin**, einschließlich Produktliste und Produkteditor.
- **WooCommerce Analytics**, sodass ein nach einer Kategorie mit Nur-POS-Produkten gefilterter Bericht deren Verkäufe anzeigt.
- **Der POS** selbst.

</details>

## Funktion ausschalten {#switch-off}

Schalten Sie **Produkte nur im POS aktivieren** aus, und die POS-Sichtbarkeit blendet nichts mehr aus; die eigenen Sichtbarkeitseinstellungen von WooCommerce gelten weiterhin. Produkte mit Nur Online kehren bei der nächsten Prüfung auf Änderungen in den POS zurück, und Produkte mit Nur POS erhalten ihre vorherige Katalogsichtbarkeit zurück: Ein Produkt, das Sie selbst ausgeblendet hatten, bleibt verborgen. Die Auswahl jedes Produkts bleibt gespeichert. Wenn Sie die Funktion wieder einschalten, werden Ihre gespeicherten Einstellungen angewendet und dieselben Produkte erneut ausgeblendet.

Auch beim Deaktivieren von WCPOS erhält jedes Produkt mit Nur POS seine vorherige Katalogsichtbarkeit zurück und kann somit wieder auf Ihrer Website erscheinen.

## Wann die Funktion sinnvoll ist {#when-to-use-this-feature}

- **Gutscheinkarten am Verkaufstresen** — physische Karten, die an der Kasse aktiviert werden. Stellen Sie sie auf **Nur POS**.
- **Online-Vorbestellungen** — Produkte, die noch nicht vorrätig sind und von Kunden online bestellt werden. Stellen Sie sie auf **Nur Online**, damit sie die Kassenansicht nicht überladen.
- **Groß- und Einzelhandel in einem Shop** — reine Großhandelsprodukte für Ihre Geschäftskunden auf **Nur Online**, exklusive Ladenartikel auf **Nur POS**, alles andere auf **POS & Online**.
- **Downloads und reine Onlineangebote** — digitale Produkte und exklusive Webangebote, die Sie nicht am Verkaufstresen verkaufen. Stellen Sie sie auf **Nur Online**.
- **Sonderangebote im Ladengeschäft** — Aktionsartikel, die Sie nur an der Kasse verkaufen. Stellen Sie sie auf **Nur POS**.

## Wenn etwas schiefgeht {#troubleshooting}

**Ein Produkt mit Nur Online erscheint weiterhin im POS.** Drücken Sie auf den Pfeil neben der Produktanzahl, um auf Änderungen zu prüfen. Ist es weiterhin vorhanden, halten Sie den Pfeil gedrückt und wählen Sie **Leeren und neu laden**.

**Ein Produkt fehlt im POS.** Leeren Sie die Suche und prüfen Sie die Filterleiste einschließlich **Vorrätig**. Öffnen Sie dann das Produkt in WP Admin und prüfen Sie seine **POS-Sichtbarkeit**; bei einer Variante prüfen Sie auch die Einstellung des übergeordneten Produkts.

**Ein Produkt erscheint auf einem Gerät, aber nicht auf einem anderen.** Jedes Gerät behält seine eigene Suche und seine Filter und übernimmt Änderungen nur, solange es online ist: siehe [Produktsynchronisierung](./sync.mdx#one-device).

**Ein Produkt mit Nur POS erscheint weiterhin in Ihrem Shop, in Kategorien oder in der Suche.** Dass es sich über einen direkten Link öffnen lässt, ist vorgesehen; hier geht es um ein Produkt, das Käufer weiterhin finden können.

1. Öffnen Sie das Produkt und prüfen Sie die **Katalogsichtbarkeit** im Bereich Veröffentlichen. Bei einem Produkt mit Nur POS steht dort **Verborgen**.
2. Steht dort etwas anderes, drücken Sie einmal auf **Aktualisieren**, damit WCPOS wieder **Verborgen** setzt. Geschieht das weiterhin nicht, wird die Einstellung von einem Plugin oder individuellem Code geändert: siehe [Für Entwickler](#developers).
3. Steht dort **Verborgen**, stammt die Seite höchstwahrscheinlich aus dem Cache. Leeren Sie den Cache Ihres Caching-Plugins oder CDN.

**Produkte haben keine POS-Sichtbarkeit.** **Produkte nur im POS aktivieren** ist ausgeschaltet. Schalten Sie die Option unter **POS > Einstellungen > Allgemein** ein.

## Für Entwickler {#developers}

<details>
<summary>Filter für Produkte mit Nur POS</summary>

Produkte mit Nur POS werden aus der WooCommerce Store API, die der blockbasierte Warenkorb und die blockbasierte Kasse verwenden, sowie aus den Produkt- und Variantenlisten der WooCommerce REST API (`/wc/v1` bis `/wc/v3`) ausgeschlossen. WP-CLI-Befehle wie `wp wc product list` sehen sie weiterhin.

**`wcpos_hide_pos_only_products`** entscheidet, ob eine Produktabfrage Produkte mit Nur POS auslässt. Der Filter erhält die Standardentscheidung und die bevorstehende `WP_Query`: true im Frontend des Shops, false in WP Admin, WP-CLI, WooCommerce Analytics und im POS. Geben Sie `false` zurück, damit ein eigener Kontext Produkte mit Nur POS sehen kann.

```php
add_filter( 'wcpos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

**`wcpos_pos_only_catalog_visibility`** legt die Katalogsichtbarkeit fest, die WCPOS für ein Produkt mit Nur POS schreibt. Der Filter erhält `hidden` und das Produkt. Geben Sie einen der WooCommerce-Schlüssel für die Katalogsichtbarkeit (`visible`, `catalog`, `search` oder `hidden`) zurück, um stattdessen diesen anzuwenden, oder `null`, um die Katalogsichtbarkeit des Produkts selbst zu verwalten. Dies ändert nur, was WCPOS in **Katalogsichtbarkeit** schreibt: Die obige Regel für das Shop-Frontend gilt weiterhin. Kombinieren Sie den Filter daher mit `wcpos_hide_pos_only_products`, wenn ein Produkt mit Nur POS irgendwo online erscheinen soll.

```php
add_filter( 'wcpos_pos_only_catalog_visibility', function ( $visibility, $product ) {
    if ( has_term( 'club-stock', 'product_cat', $product->get_id() ) ) {
        return null; // I manage catalog visibility for these myself.
    }
    return $visibility;
}, 10, 2 );
```

**`wcpos_default_product_visibility`** legt die anfängliche **POS-Sichtbarkeit** eines neuen Produkts im Editor fest. Der Filter erhält `''` (**POS & Online**) und den Beitrag; geben Sie `pos_only` oder `online_only` zurück, damit neue Produkte mit dieser Einstellung beginnen.

Vor WCPOS 2.0 hießen diese Filter `woocommerce_pos_hide_pos_only_products`, `woocommerce_pos_pos_only_catalog_visibility` und `woocommerce_pos_default_product_visibility`. Die alten Namen funktionieren weiterhin, sind aber seit 2.0 veraltet und werden frühestens in 2.2 entfernt. Siehe [Hook-Benennung](../extensions/index.mdx#hook-naming).

</details>
