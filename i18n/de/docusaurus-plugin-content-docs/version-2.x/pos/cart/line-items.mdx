Jedes Produkt, jede Gebühr und alle Versandkosten bilden im Warenkorb eine Position. Die meisten Angaben ändern Sie direkt dort: Tippen Sie auf die Menge, den Preis oder den Namen. Alles Weitere finden Sie im Dialog **Bearbeiten** der Position.

## Eine Position im Warenkorb {#line}

Eine Produktposition zeigt Menge, Namen und Einzelpreis, rechts daneben den Gesamtbetrag der Position. Gebühren und Versand erscheinen ebenfalls als Positionen unterhalb der Produkte. Welche weiteren Angaben erscheinen, bestimmen die eingeblendeten [Spalten](./index.mdx#columns).

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 32], [122, -40], [0, -26], [0, -26], [-34, 0], [-34, 0], [-30, 0], [0, 24]]} maxWidth={379} alt="Der Warenkorb mit drei Positionen: 3 × Aim Analog Watch zu $45.00 mit dem benutzerdefinierten Feld Gravur: Alles Gute zum Geburtstag, einer Gebühr für Geschenkverpackung von $2.00 und lokaler Lieferung für $5.00">

1. **Menge** — die Stückzahl. Tippen Sie darauf, um sie zu ändern; siehe [Menge ändern](#quantity).
2. **Artikel** — der Produktname. Tippen Sie darauf, um die Position für diesen Verkauf umzubenennen: Der Name wird zu einem Textfeld. Mit der Eingabetaste oder durch Tippen auf eine andere Stelle übernehmen Sie den neuen Namen. Darunter stehen die Optionen, mit denen eine [Variante](../product-panel/variations.mdx) verkauft wurde, sowie die [benutzerdefinierten Felder](#meta-data) der Position als `Key: value`. Aktivieren Sie die Option **SKU** der Spalte, um auch die SKU anzuzeigen.
3. **Preis** — der Einzelpreis. Tippen Sie darauf, um ihn zu ändern; siehe [Preis ändern](#price). Liegt der Preis unter dem regulären Preis, erscheint dieser darüber durchgestrichen.
4. **Gesamt** — Menge mal Preis. Tippen Sie darauf, um **Bearbeiten** und **Entfernen** einzublenden; siehe [Position bearbeiten oder entfernen](#remove-item).
5. **Eine Gebühr** — tippen Sie ebenso auf den Namen, um ihn zu ändern, oder auf den Betrag, um ihn anzupassen. Siehe [Gebühren](./index.mdx#fees).
6. **Eine Versandposition** — hier gilt dasselbe: Tippen Sie auf den Titel oder den Betrag. Siehe [Versand](./index.mdx#shipping).
7. **+** — fügt dem Warenkorb eine Gebühr, Versandkosten, einen Rabatt oder ein [sonstiges Produkt](./index.mdx#miscellaneous-products) hinzu.
8. **Warenkorbeinstellungen** — auf welcher Seite der Warenkorb steht, wie seine Positionen sortiert werden und welche Spalten er zeigt; siehe [Warenkorbeinstellungen für Positionen](#cart-settings).

</JourneyShot>

## Menge ändern {#quantity}

Tippen Sie auf das Mengenfeld. In den iOS- und Android-Apps geben Sie die Zahl direkt im Feld ein; eine Menge von 0 entfernt die Position. In allen anderen Versionen öffnet sich ein Ziffernfeld: Geben Sie die neue Menge ein und tippen Sie auf das Häkchen (oder drücken Sie die Eingabetaste), um sie zu übernehmen. Auf einem Smartphone öffnet sich das Ziffernfeld als Bereich vom unteren Bildschirmrand; auf einem Tablet oder Computer klappt es am Mengenfeld auf, mit der Menge oben:

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, -24], [0, -24], [0, -24], [-6, 0], [-6, 0], [0, 0]]} maxWidth={441} alt="Das geöffnete Mengen-Ziffernfeld über einer Position mit der Menge 1: links von der 1 ein Papierkorb, rechts ein Plus, die Zifferntasten, eine Löschtaste und ein Häkchen">

1. **Die Menge** — Ihre bisherige Eingabe.
2. **−** — eins weniger. Bei 1 wird daraus wie hier ein Papierkorb: Ein Druck darauf entfernt die Position.
3. **+** — eins mehr.
4. **Zifferntasten** — geben Sie die neue Menge ein.
5. **Löschen** — entfernt die letzte Ziffer.
6. **Fertig** (das Häkchen) — übernimmt die neue Menge. Die Eingabetaste bewirkt dasselbe. Escape schließt das Ziffernfeld und behält die bisherige Menge bei.

</JourneyShot>

Wenn in Ihrem Shop [Dezimalmengen aktivieren](../../settings/wp-admin/general.mdx#enable-decimal-quantities) eingeschaltet ist, enthält das Ziffernfeld auch eine Dezimaltaste mit dem Dezimaltrennzeichen Ihres Shops. Damit können Sie Teilmengen wie 2.5 oder 0.25 (mit bis zu sechs Nachkommastellen) eingeben, etwa für Waren, die nach Gewicht oder Länge verkauft werden.

Wenn Ihr Shop Überverkäufe verhindert, wird eine Menge, die den Lagerbestand überschreitet, gelborange markiert; siehe [Wenn der Kassiervorgang blockiert ist](#checkout-blocked).

### Position aufteilen {#splitting-line-items}

**Aufteilen** macht aus einer Position mit mehreren Einheiten einzelne Positionen mit jeweils einer Einheit. So können Sie einer davon einen anderen Preis, Rabatt oder eine andere Notiz zuweisen. Bei einer Teilmenge bleibt der Bruchteil als eigene Position erhalten: Eine Position mit 2.5 wird in 1, 1 und 0.5 aufgeteilt.

Der Link **Aufteilen** steht unter der Menge jeder Position mit mehr als einer Einheit. Er ist ausgeblendet, bis Sie ihn in den **Warenkorbeinstellungen** aktivieren.

<JourneyShot manifest={manifest} device="tablet" step={13} offsets={[[0, -24], [4, 22]]} maxWidth={379} alt="Eine Position mit 3 Aim Analog Watch und dem Link Aufteilen unter der Menge">

1. **Menge** — die Menge der Position, hier 3.
2. **Aufteilen** — tippen Sie darauf, um drei Positionen mit jeweils einer Einheit zu erstellen.

</JourneyShot>

Öffnen Sie zum Aktivieren die **Warenkorbeinstellungen** (das Schieberegler-Symbol über dem Warenkorb), suchen Sie die Spalte **Menge** und aktivieren Sie dort **Aufteilen**.

<JourneyShot manifest={manifest} device="tablet" step={8} alt="Warenkorbeinstellungen, zu den Spalten gescrollt, mit der Option Aufteilen unter der Spalte Menge" />

## Preis ändern {#price}

Tippen Sie auf den Preis, geben Sie den neuen Einzelpreis ein (oder drücken Sie eine Taste für einen Schnellrabatt) und tippen Sie auf das Häkchen (oder drücken Sie die Eingabetaste), um ihn zu übernehmen. Am Preis öffnet sich ein Ziffernfeld:

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [-4, -20], [-4, -20], [-4, -20], [0, 0], [-4, 0], [0, 0]]} maxWidth={293} alt="Das Preis-Ziffernfeld für eine Position zu $45.00 mit hervorgehobener Taste −10%: $45.00 −10 % über dem neuen Preis $40.50, die Zifferntasten, ein Dezimalpunkt, eine Löschtaste und ein Häkchen">

1. **Der Preis** — der neue Einzelpreis. Nach einem Schnellrabatt erscheint darüber die Berechnung: hier $45.00 −10 %, also $40.50.
2. **−5%** — eine Taste für einen **Schnellrabatt**: Sie zieht 5% vom Preis der Position ab.
3. **−10%** — hervorgehoben, weil die Taste gedrückt wurde. Drücken Sie eine hervorgehobene Taste erneut, um den Rabatt rückgängig zu machen.
4. **−15%** — zieht 15% ab. Diese drei Rabatte sind voreingestellt; Sie können sie [ändern](./discounts.mdx#quick-discounts).
5. **Zifferntasten** — geben Sie den neuen Einzelpreis ein. Die erste Ziffer ersetzt den bisherigen Preis.
6. **Löschen** — entfernt die letzte Ziffer.
7. **Fertig** (das Häkchen) — übernimmt den neuen Preis. Die Eingabetaste bewirkt dasselbe. Escape schließt das Ziffernfeld und lässt den bisherigen Preis unverändert.

</JourneyShot>

Mit einer Tastatur geben Sie die Ziffern ein, löschen mit der Rücktaste, übernehmen mit der Eingabetaste und brechen mit Escape ab. Im Mengen-Ziffernfeld erhöhen oder verringern die Pfeiltasten nach oben und unten die Menge um eins (nach unten nur bis 1).

Im Browser auf einem Smartphone öffnet sich dasselbe Ziffernfeld als eingeblendeter Bereich. In den iOS- und Android-Apps wird der Preis beim Antippen zu einem Eingabefeld: Geben Sie den neuen Einzelpreis ein; er wird beim Verlassen des Feldes übernommen. Die Schnellrabatt-Tasten gibt es nur im Ziffernfeld.

:::note Eine Preisänderung ist kein WooCommerce-„Rabatt“
Ein gesenkter Preis wird als Angebotspreis des Artikels gespeichert. Belege können die Ersparnis anzeigen, doch die Summe unter **Rabatt** in der Bestellung ist Gutscheinen vorbehalten. Berichte erfassen den Verkauf zum tatsächlich gezahlten Preis. Unter [Warenkorbrabatte](./discounts.mdx#why-tracked-differently) erfahren Sie, warum WooCommerce beides unterschiedlich behandelt.
:::

### Ein neuer Preis gilt nur für diesen Verkauf {#price-this-sale}

Ein im Warenkorb geänderter Preis gilt nur für diesen Verkauf. Das Produkt behält seinen eigenen Preis: Seine Kachel zeigt ihn weiterhin an, auf diesem und auf anderen Geräten. Um den Preis für alle Verkäufe zu ändern, ändern Sie den Produktpreis auf der Seite [Produkte](../../products/index.mdx#inline-price-editing) oder in WP Admin.

Um etwas zu verkaufen, das nicht in Ihrem Katalog steht, und den Preis selbst einzugeben, drücken Sie **+** und fügen Sie ein [sonstiges Produkt](./index.mdx#miscellaneous-products) hinzu.

## Position bearbeiten oder entfernen {#remove-item}

Unter jeder Position sind die Schaltflächen **Bearbeiten** und **Entfernen** verborgen. So blenden Sie sie ein:

- **Tippen Sie auf den Gesamtbetrag der Position.** Durch erneutes Tippen blenden Sie die Schaltflächen wieder aus.
- **Bewegen Sie den Mauszeiger** über den Gesamtbetrag. Die Position gleitet etwas zur Seite und gibt einen Blick auf die Schaltflächen frei.
- **Wischen Sie die Position** auf einem Touchscreen nach links oder ziehen Sie sie mit der Maus nach links.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[6, -28], [6, -28]]} maxWidth={379} alt="Die Uhrenposition ist nach links verschoben und zeigt eine blaue Schaltfläche Bearbeiten und eine rote Schaltfläche Entfernen">

1. **Bearbeiten** — öffnet den [Dialog Bearbeiten](#edit-form).
2. **Entfernen** — entfernt die Position aus dem Warenkorb.

</JourneyShot>

Wischen Sie weiter, füllt **Entfernen** die gesamte Zeile rot aus: Lassen Sie los, wird die Position in einem Schritt entfernt.

Die anschließend angezeigte Meldung enthält **Rückgängig**, womit Sie die Position im ursprünglichen Zustand wiederherstellen.

## Der Dialog Bearbeiten {#edit-form}

**Bearbeiten** öffnet die Details der Position in einem Dialog mit ihrem Namen. Änderungen werden sofort gespeichert; drücken Sie **Schließen**, wenn Sie fertig sind.

Bei einer Produktposition:

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-35, 0], [-35, 0], [-35, 0], [-35, 0], [-35, 0], [-10, 0], [-10, 0], [-35, 0]]} alt="Aim Analog Watch bearbeiten: Name, Menge 3, Preis 45.00, Steuer Standardsatz, SKU 24-MG04 mit Entfernen, das benutzerdefinierte Feld Gravur: Alles Gute zum Geburtstag, die Schaltflächen Regulärer Preis und Benutzerdefiniertes Feld sowie Schließen">

1. **Name** — die Bezeichnung auf dem Beleg und in der Bestellung.
2. **Menge** — dieselbe wie im Warenkorb.
3. **Preis** — derselbe wie im Warenkorb. Bei einer Position im Angebot erscheint daneben der reguläre Preis mit **vorher**. Über das zugehörige **Entfernen** entfernen Sie den regulären Preis: Die Position gilt dann nicht mehr als Angebot und der aktuelle Preis bleibt unverändert.
4. **Steuer** — ob die Position steuerpflichtig ist und welche Steuerklasse gilt.
5. **SKU** — wird angezeigt, wenn das Produkt eine hat. Bei einer Position ohne SKU können Sie über die Schaltfläche **SKU** eine hinzufügen.
6. **Regulärer Preis** — fügt einer Position, die nicht im Angebot ist, einen regulären Preis hinzu.
7. **Benutzerdefiniertes Feld** — fügt einen Schlüssel und einen Wert hinzu, wie in der Zeile **Gravur** darüber; siehe [Benutzerdefinierte Felder](#meta-data).
8. **Schließen** — schließt den Dialog. Alle Änderungen sind bereits gespeichert.

</JourneyShot>

Jede hinzugefügte Zeile hat eine eigene Schaltfläche **Entfernen**. Ein [sonstiges Produkt](./index.mdx#miscellaneous-products) steht nicht in Ihrem Katalog, daher enthält sein Dialog zusätzlich **Kategorien**, **Virtuell** und **Herunterladbar**.

Die Steuer einer Position wird anhand der Steuersätze für die Adresse der Bestellung berechnet. Wenn Ihr Shop die [Steuer anhand der Kundenadresse berechnet](../../settings/store/tax.mdx#calculate-tax-based-on) und Sie den Kunden oder dessen Adresse ändern, sodass andere Steuersätze gelten, werden die Steuern der Positionen sofort mit den neuen Sätzen neu berechnet. Eine [steuerbefreite](./index.mdx#tax-exempt) Bestellung bleibt steuerbefreit.

### Eine Gebührenposition {#edit-fee}

**Bearbeiten** öffnet bei einer Gebühr einen eigenen Dialog mit ihrem Namen. Wie bei einem Produkt werden Änderungen sofort gespeichert.

Eine Gebühr darf nicht negativ sein: Der Dialog zeigt **Eine Gebühr darf nicht negativ sein. Verwenden Sie stattdessen Rabatt hinzufügen.** Siehe [Rabatte](./discounts.mdx).

<details>
<summary>Gebühr bearbeiten: der Dialog und seine Felder</summary>

<JourneyShot manifest={manifest} device="tablet" step={11} offsets={[[-35, 0], [-35, 0], [-12, 0], [-30, 0], [-35, 0], [-10, 0], [-35, 0]]} alt="Geschenkverpackung bearbeiten: Gebührenname, Betrag 2.00 mit Umschalter $ und %, Betrag enthält Steuern aktiviert, Steuer Standardsatz, die Schaltfläche Benutzerdefiniertes Feld und Schließen">

1. **Gebührenname** — die Bezeichnung der Gebühr auf dem Beleg.
2. **Betrag** — eine feste Summe oder ein Prozentsatz, wenn **%** ausgewählt ist.
3. **$ / %** — wechselt zwischen einem festen Betrag und einem Prozentsatz des Warenkorbgesamtbetrags.
4. **Betrag enthält Steuern** — aktiviert, wenn die Steuer bereits im Betrag enthalten ist.
5. **Steuer** — **Nicht steuerpflichtig** oder die für die Gebühr geltende Steuerklasse.
6. **Benutzerdefiniertes Feld** — siehe [Benutzerdefinierte Felder](#meta-data).
7. **Schließen** — schließt den Dialog.

### Eine Versandposition {#edit-shipping}

**Bearbeiten** öffnet bei einer Versandposition einen eigenen Dialog, der Änderungen ebenfalls sofort speichert.

<details>
<summary>Versandkosten bearbeiten: der Dialog und seine Felder</summary>

<JourneyShot manifest={manifest} device="tablet" step={12} offsets={[[330, 0], [458, 0], [-35, 0], [-30, 0], [106, 0], [-10, 0], [-35, 0]]} alt="Lokale Lieferung bearbeiten: Titel der Versandart, Versandart Abholung vor Ort, Betrag 5.00, Betrag enthält Steuern aktiviert, Steuer Steuerpflichtig oder Keine, die Schaltfläche Benutzerdefiniertes Feld und Schließen">

1. **Titel der Versandart** — die Bezeichnung auf dem Beleg.
2. **Versandart** — eine Versandart Ihres Shops, die mit der Bestellung gespeichert wird.
3. **Betrag** — die Versandkosten. Sie geben sie selbst ein: Der POS berechnet keine Versandtarife.
4. **Betrag enthält Steuern** — aktiviert, wenn die Steuer bereits in den Versandkosten enthalten ist.
5. **Steuer** — **Steuerpflichtig** oder **Keine**.
6. **Benutzerdefiniertes Feld** — siehe [Benutzerdefinierte Felder](#meta-data).
7. **Schließen** — schließt den Dialog.

### Der JSON-Tab {#raw-json-view}

Der Tab **JSON** neben **Formular** zeigt die Position genau so, wie sie an WooCommerce übermittelt wird. Für einen Verkauf brauchen Sie ihn nicht. Er hilft dabei zu prüfen, welche Daten ein Plugin erhält oder warum ein Feld nicht gespeichert wird.

#### Die drei Positionsarten {#line-item-types}

WooCommerce speichert Produkte, Gebühren und Versand als unterschiedliche Positionsarten:

| Art | In WooCommerce | Beispiele |
|------|----------------|----------|
| Produkt | `line_item` | T-Shirt, Kaffeetasse |
| Gebühr | `fee_line` | Geschenkverpackung, Servicegebühr |
| Versand | `shipping_line` | Standardversand, Expresslieferung |

#### WCPOS-eigene Felder {#protected-keys}

WooCommerce bezeichnet benutzerdefinierte Felder als Metadaten. Schlüssel, die mit einem Unterstrich beginnen, gehören zu WCPOS-eigenen Daten (etwa `_woocommerce_pos_data` und `_reduced_stock`). Sie erscheinen weder im Formular noch im Warenkorb, sind aber im Tab **JSON** sichtbar.

</details>

## Benutzerdefinierte Felder {#meta-data}

Ein benutzerdefiniertes Feld ist eine zu einer Position gespeicherte Angabe, etwa eine Gravur oder eine Seriennummer. Um eine Gravur hinzuzufügen, öffnen Sie den Dialog **Bearbeiten** der Position, tippen Sie auf **Benutzerdefiniertes Feld**, geben Sie unter **Schlüssel** den Text **Gravur** und unter **Wert** die Nachricht des Kunden ein. Das Feld erscheint im Warenkorb unter dem Namen der Position und in der Bestellung in WP Admin. Jedes Feld hat eine eigene Schaltfläche **Entfernen**.

Manche Felder stammen vom Produkt: Alle von Ihnen ausgewählten [Metadaten-Schlüssel](../product-panel/meta-data-keys.mdx) werden beim Hinzufügen in die Position übernommen.

Wenn das Formular **Dieser Schlüssel wird von WCPOS verwaltet. Wählen Sie einen anderen Schlüssel.** anzeigt, haben Sie einen der [WCPOS-eigenen Schlüssel](#protected-keys) eingegeben. Wählen Sie einen anderen.

## Warenkorbeinstellungen für Positionen {#cart-settings}

Die **Warenkorbeinstellungen**, erreichbar über das Schieberegler-Symbol über dem Warenkorb, legen die Seite des Warenkorbs und die Reihenfolge seiner Produktpositionen fest. Gebühren und Versand bleiben immer am Ende, in der Reihenfolge, in der Sie sie hinzugefügt haben.

1. **Warenkorb links / Warenkorb rechts** — auf welcher Bildschirmseite der Warenkorb steht. Standardmäßig steht er rechts.

## Wenn der Kassiervorgang blockiert ist {#checkout-blocked}

Wenn Ihr Shop [Überverkäufe verhindert](../../settings/wp-admin/checkout.mdx#prevent-overselling), gleicht der Warenkorb jede Produktposition mit dem Lagerbestand ab:

- Ein Hinweis über den Positionen listet alle mit unzureichendem Bestand auf: **Nur 2 verfügbar für Hoodie** mit **Reduzieren**, womit sich die Mengeneingabe dieser Position öffnet, oder **Hoodie nicht vorrätig** mit **Entfernen**.
- Die betroffenen Positionen werden gelborange markiert und zeigen die verfügbare Menge.
- **Kasse** wird ausgegraut. Wenn Sie darauf drücken, gelangen Sie zur ersten Position, die Sie korrigieren müssen.

Korrigieren Sie alle betroffenen Positionen, wird **Kasse** wieder aktiv. Ein Produkt, für das Nachbestellungen erlaubt sind, blockiert den Verkauf nicht.

## Wenn etwas schiefgeht {#goes-wrong}

**„Dieser Artikel konnte nicht aktualisiert werden — er ist nicht mehr im Warenkorb.“** Die Position wurde entfernt, während Sie sie geändert haben. Prüfen Sie den Warenkorb und nehmen Sie die Änderung erneut vor.

**„Dieser Artikel ist nicht mehr im Warenkorb.“** Sie haben bei einer bereits entfernten Position auf **Entfernen** gedrückt. Sie müssen nichts weiter tun.

**Der Link Aufteilen fehlt.** Aktivieren Sie **Aufteilen** unter der Spalte **Menge** in den **Warenkorbeinstellungen**. Der Link erscheint nur bei Positionen mit einer Menge über 1.

**Kasse ist ausgegraut.** Bei einer Position reicht der Lagerbestand nicht aus. Siehe [Wenn der Kassiervorgang blockiert ist](#checkout-blocked).

**Ein benutzerdefiniertes Feld lässt sich nicht speichern.** Sein Schlüssel beginnt mit einem Unterstrich und gehört zu WCPOS. Wählen Sie einen anderen Schlüssel.
