WCPOS Pro ist ein kostenpflichtiges WordPress-Plugin. Es enthält alle Funktionen des kostenlosen WCPOS-Plugins und wird daher eigenständig an dessen Stelle installiert. Diese Seite führt Sie vom Lizenzkauf bis zur Anzeige von **Pro** im POS.

:::note Sie benötigen einen WordPress-Administrator
Installation und Aktivierung erfolgen in WP Admin, nicht im POS. Dafür ist ein WordPress-Konto erforderlich, das Plugins installieren darf.
:::

## Eine Lizenz kaufen {#purchase-a-license}

Pro ist ein Plugin auf Ihrer WordPress-Website und wird nicht pro Gerät gekauft: Jedes Gerät und jeder Kassierer, die mit dieser Website verbunden sind, erhalten Pro.

Gehen Sie zu [wcpos.com/pro](https://wcpos.com/pro) und kaufen Sie eine Lizenz. Kauf, Tarifwechsel und Verlängerungen erfolgen auf wcpos.com: Im POS selbst gibt es dafür keinen Kaufabschluss. **Upgrade auf Pro** oben im POS öffnet dieselbe Seite (siehe [Was die kostenlose Version anzeigt](#free-version)). [Installieren Sie anschließend das Plugin](#installation).

Wenn Sie Ihr wcpos.com-Konto nicht erstellen oder den Kauf nicht abschließen können, schreiben Sie an **support@wcpos.com**.

Auch für den Wechsel von einer Jahreslizenz zu einer lebenslangen Lizenz wenden Sie sich an **support@wcpos.com**: Dort werden Lizenzen und Abrechnung bearbeitet. Siehe [An wen Sie sich wenden können](../support/index.mdx#where-to-ask).

Pro ergänzt die Ansichten Produkte, Bestellungen, Kunden und Gutscheine, Berichte für frühere Tage und alle Kassen, integrierte Kartenleser, das Kundendisplay, Rückerstattungen sowie weitere Kassen und Filialen. Die vollständige Liste finden Sie unter [Kostenlos und Pro im Vergleich](./free-vs-pro.mdx).

## Das Pro-Plugin installieren {#installation}

1. Melden Sie sich auf wcpos.com an und öffnen Sie Ihre [Downloads](https://wcpos.com/account/downloads). Laden Sie das Pro-Plugin herunter. Es ist eine ZIP-Datei: Entpacken Sie sie nicht.
2. Gehen Sie in WP Admin zu **Plugins**, fügen Sie ein neues Plugin hinzu und klicken Sie auf **Plugin hochladen**.
3. Wählen Sie die ZIP-Datei aus, klicken Sie auf **Jetzt installieren** und anschließend auf **Plugin aktivieren**.

:::note Wechseln Sie vom kostenlosen Plugin?
Sie müssen das kostenlose Plugin nicht vorher entfernen. Beim Start deaktiviert Pro das kostenlose Plugin und zeigt einen entsprechenden Hinweis an. Anschließend können Sie das kostenlose Plugin auf der Seite **Plugins** löschen, müssen es aber nicht: Beim Löschen werden alle Kassierer abgemeldet und müssen sich an jeder Kasse erneut anmelden. Siehe [Die aktuelle Version durch Hochladen ersetzen](./previous-versions.mdx#install).

Haben Sie das kostenlose Plugin bereits entfernt? Das ist kein Problem: Pro enthält dessen Code und läuft ohne das kostenlose Plugin. Falls Ihre Website nach der Installation von Pro einen Fehler anzeigt, lesen Sie [Kritischer Fehler](../support/troubleshooting/critical-error.mdx#common-errors).
:::

## Ihren Lizenzschlüssel aktivieren {#activate}

1. Kopieren Sie Ihren Schlüssel von der Seite [Lizenzen](https://wcpos.com/account/licenses) Ihres Kontos.
2. Gehen Sie in WP Admin zu **POS** > **Einstellungen**. Öffnen Sie unter **Konto** den Bereich **Lizenz**.
3. Fügen Sie den Schlüssel in **Lizenzschlüssel** ein und klicken Sie auf **Aktivieren**.

Danach werden **Vielen Dank!** und **Lizenz … wurde aktiviert.** angezeigt, wobei Ihr Schlüssel in der Mitte gekürzt ist. Falls stattdessen eine Meldung erscheint, lesen Sie [Wenn etwas schiefgeht](#troubleshooting).

## Prüfen, ob der POS mit Pro läuft {#checking-licence-status}

Laden Sie den POS neu: Aktualisieren Sie die Browserseite oder schließen und öffnen Sie die Desktop- oder Mobil-App erneut. Der Upgrade-Banner verschwindet, und die Ansichten Produkte, Bestellungen, Kunden und Gutscheine zeigen die Daten Ihres Shops statt einer unscharfen Vorschau.

Tippen Sie zur Kontrolle auf die Versionsnummer unten im Menü (**v 2.0.0** oder **Version 2.0.0** auf einem Smartphone). **Über WCPOS** öffnet sich.

<JourneyShot manifest={manifest} device="tablet" step={2} maxWidth={368} alt="Über WCPOS in einer Filiale mit Pro: App-Version und Plattform, darunter die Versionen von WCPOS Pro Plugin, WooCommerce und WordPress unter Server sowie Status Pro unter Lizenz" />

- Unter **Lizenz** muss **Status**: **Pro** stehen. Solange kein Schlüssel aktiv ist, wird **Kostenlos** angezeigt.
- Unter **Server** werden **WCPOS Pro Plugin** und dessen Version aufgeführt (**WCPOS Plugin** beim kostenlosen Plugin). Das bestätigt nur, dass das Plugin installiert ist: Der Eintrag erscheint mit und ohne aktive Lizenz.

## Updates {#updates}

Neue Pro-Versionen erscheinen wie bei jedem anderen Plugin unter **Dashboard** > **Aktualisierungen** und auf der Seite **Plugins**. Sie können die neueste ZIP-Datei auch über Ihre [Downloads](https://wcpos.com/account/downloads) herunterladen.

Die Pro-Zeile auf der Seite **Plugins** zeigt den Status Ihrer Lizenz: gültig und zum Empfang von Updates berechtigt, inaktiv oder abgelaufen.

## Wenn etwas schiefgeht {#troubleshooting}

### Nach einem Update werden Sie erneut zum Kauf von Pro aufgefordert {#pro-shows-free}

Der POS zeigt die kostenlose Version mit **Upgrade auf Pro** an, wenn das Pro-Plugin auf Ihrer Website nicht läuft oder dort kein Lizenzschlüssel aktiviert ist. Prüfen Sie beides, bevor Sie erneut kaufen:

1. Öffnen Sie in WP Admin **Plugins**. **WCPOS Pro – Point of Sale for WooCommerce** muss vorhanden und aktiv sein. Ist es vorhanden, aber inaktiv, klicken Sie auf **Aktivieren**. Ist nur **WCPOS – Point of Sale for WooCommerce** vorhanden, wurde Pro entfernt: [Installieren Sie es erneut](#installation). Beim Löschen von Pro bleibt Ihr Lizenzschlüssel erhalten und steht nach der Neuinstallation wieder zur Verfügung.
2. Gehen Sie zu **POS** > **Einstellungen** und öffnen Sie unter **Konto** den Bereich **Lizenz**. Wenn Sie das Feld **Lizenzschlüssel** und **Aktivieren** sehen, ist der Schlüssel auf dieser Website nicht aktiv: Fügen Sie ihn von Ihrer Seite [Lizenzen](https://wcpos.com/account/licenses) ein und klicken Sie auf **Aktivieren**.

Laden Sie anschließend den POS neu. Unter **Über WCPOS** sollte **Status** **Pro** stehen: siehe [Prüfen, ob der POS mit Pro läuft](#checking-licence-status). Falls bei der Aktivierung stattdessen eine Meldung erscheint, finden Sie die häufigsten Fälle weiter unten. Bei Updates, die sich nicht installieren lassen, lesen Sie [LICENSE301](../error-codes/LICENSE301.mdx).

### Ein Update wird angeboten, lässt sich aber nicht herunterladen {#update-wont-download}

WordPress bietet jeder Website eine neue Pro-Version an, unabhängig von der Lizenz. Beim eigentlichen Download wird Ihre Lizenz geprüft. Er wird verweigert, wenn:

- auf dieser Website kein Lizenzschlüssel aktiv ist oder
- die Lizenz abgelaufen ist.

Sehen Sie sich die Pro-Zeile auf der Seite **Plugins** an. **Ihre WCPOS Pro-Lizenz ist inaktiv.** verweist auf Schritt 2 oben: Aktivieren Sie den Schlüssel und versuchen Sie das Update erneut. **Ihre WCPOS Pro-Lizenz ist abgelaufen.** bedeutet, dass Sie die Lizenz in Ihrem [Konto](https://wcpos.com/account/licenses) verlängern und das Update dann erneut versuchen müssen. Wenn die Zeile Ihre Lizenz als gültig und aktiv ausweist, der Download aber weiterhin fehlschlägt, schreiben Sie an **support@wcpos.com**. Siehe [LICENSE301](../error-codes/LICENSE301.mdx).

<details>
<summary>Die Lizenzansicht zeigt eine Meldung von wcpos.com</summary>

Die Meldung kommt vom Lizenzserver, der Ihren Schlüssel prüft. Prüfen Sie, ob vor oder nach dem eingefügten Schlüssel Leerzeichen stehen und ob der Schlüssel von Ihrer Seite [Lizenzen](https://wcpos.com/account/licenses) stammt.

</details>

<details>
<summary>Die Lizenz hat ihr Aktivierungslimit erreicht</summary>

Eine Lizenz lässt sich auf 2 Websites aktivieren: einer produktiven Website und einer Entwicklungswebsite. Subdomains zählen einzeln, daher sind `example.com`, `staging.example.com` und `dev.example.com` drei Websites. Bei Hosting-Anbietern mit integrierten Entwicklungs-, Test- und Produktivumgebungen wird dieses Limit oft erreicht. Auf Ihrer Seite [Lizenzen](https://wcpos.com/account/licenses) können Sie die Websites einsehen und Aktivierungen freigeben. Alternativ schreiben Sie an **support@wcpos.com**: Zusätzliche Aktivierungen werden auf Anfrage gewährt.

</details>

<details>
<summary>Die Aktivierung schlägt mit einem Netzwerkfehler fehl</summary>

Die Aktivierung erfolgt direkt aus dem Browser, in dem Sie WP Admin verwenden, zu wcpos.com. Prüfen Sie, ob dieser Browser wcpos.com öffnen kann. Klicken Sie dann erneut auf **Aktivieren**, mit deaktivierten Werbe- oder Datenschutzblockern oder in einem anderen Browser.

</details>

<details>
<summary>Pro bietet nie Updates an</summary>

Update-Prüfungen erfolgen von Ihrem WordPress-Server aus zu `updates.wcpos.com`. Ein Sicherheitsplugin oder die Firewall Ihres Hosting-Anbieters kann sie blockieren: Bitten Sie Ihren Hosting-Anbieter, ausgehende Anfragen an `updates.wcpos.com` zuzulassen.

</details>

<details>
<summary>Der Upgrade-Banner ist nach der Aktivierung noch da</summary>

Laden Sie den POS neu (aktualisieren Sie die Seite oder schließen und öffnen Sie die App erneut). Wenn unter **Über WCPOS** weiterhin **Status** **Kostenlos** steht, öffnen Sie WP Admin, gehen Sie zu **POS** > **Einstellungen** und öffnen Sie unter **Konto** den Bereich **Lizenz**. Prüfen Sie, ob dort **Lizenz … wurde aktiviert.** steht.

</details>

<details>
<summary>Ihre Lizenz ist abgelaufen</summary>

Pro funktioniert weiter: Im POS wird nichts abgeschaltet. Auf der Seite **Plugins** steht „Ihre WCPOS Pro-Lizenz ist abgelaufen. Bitte verlängern Sie sie, um Updates zu erhalten.“ Verlängern Sie die Lizenz in Ihrem [Konto](https://wcpos.com/account/licenses), um wieder Updates zu erhalten. Ihr Schlüssel bleibt gleich.

</details>

<details>
<summary>Die Website auf eine neue Domain umziehen</summary>

Geben Sie zuerst die Aktivierung auf der alten Website frei: Gehen Sie in WP Admin zu **POS** > **Einstellungen**, öffnen Sie unter **Konto** den Bereich **Lizenz** und klicken Sie auf **Deaktivieren**. Aktivieren Sie anschließend denselben Schlüssel auf der neuen Website. Das Deaktivieren des Plugins selbst gibt die Aktivierung nicht frei. Falls die alte Website nicht mehr existiert, geben Sie die Aktivierung über Ihre Seite [Lizenzen](https://wcpos.com/account/licenses) frei oder schreiben Sie an **support@wcpos.com**.

</details>

<details>
<summary>Pro deinstallieren und Ihre Daten</summary>

Beim Löschen des Pro-Plugins werden die eigenen Arbeitsdaten und Übersetzungsdateien von Pro entfernt. Ihre Pro-Einstellungen einschließlich des Lizenzschlüssels sowie Ihre Filialen bleiben erhalten, sodass Sie nach einer Neuinstallation dort weitermachen können, wo Sie aufgehört haben. Bestell- und Produktdaten bleiben immer unberührt.

Die Übersetzungsdateien, die Pro mit dem kostenlosen Plugin teilt, werden erst entfernt, wenn das kostenlose Plugin nicht mehr installiert ist.

Wenn Sie vollständig neu beginnen und auch Einstellungen, Lizenzschlüssel und Filialen entfernen möchten, aktivieren Sie vor dem Löschen des Plugins die vollständige Datenlöschung: Fügen Sie `define( 'WCPOS_REMOVE_ALL_DATA', true );` in `wp-config.php` ein oder setzen Sie die Option `wcpos_remove_all_data` auf `yes`. Sind beide gesetzt, hat die Konstante Vorrang. Eine vollständige Datenlöschung lässt sich nicht rückgängig machen.

</details>
