WCPOS gibt es in zwei Editionen. Mit dem **kostenlosen Plugin** wickeln Sie Verkäufe ab: Bargeld, Kartenzahlungen über ein separates Kartenterminal, eine Kasse mit Kassenschublade, Belege, Gutscheine im Warenkorb und Verkäufe auch bei unterbrochener Verbindung. **WCPOS Pro** ergänzt die Ansichten zur Filialverwaltung im POS (Produkte, Bestellungen, Kunden, Gutscheine und Berichte über den heutigen Tag hinaus), Rückerstattungen, verbundene Kartenlesegeräte und weitere Zahlungsgateways, das Kundendisplay sowie weitere Kassen und Filialen.

Wenn Sie eine Kasse benötigen, die Verkäufe erfasst, reicht das kostenlose Plugin aus. Möchten Sie auch Bestände und Preise ändern, eine ältere Bestellung suchen, einem Kunden Geld zurückerstatten oder Kartenzahlungen über ein gekoppeltes Lesegerät annehmen, benötigen Sie Pro. Preise und Informationen dazu, was nach Ablauf einer Lizenz passiert, finden Sie unter [Preise](#pricing).

## So werden Pro-Funktionen im kostenlosen Plugin angezeigt {#on-the-free-plugin}

Das kostenlose Plugin zeigt jede Pro-Funktion an ihrem vorgesehenen Platz und bietet Ihnen die Möglichkeit, sie in Aktion zu sehen. In diesen Ansichten wird nichts an Ihrer Filiale geändert.

### Eine Pro-Ansicht {#pro-screen}

**Produkte**, **Bestellungen**, **Kunden** und **Gutscheine** öffnen sich als unscharfe Vorschau der tatsächlichen Ansicht mit einer darüberliegenden Karte.

2. **Upgrade auf Pro** — die Karte über der unscharfen Ansicht, unten im Detail.
3. **Produkte** — eine der vier Pro-Ansichten im Menü, neben **Bestellungen**, **Kunden** und **Gutscheine**.

</JourneyShot>

### Berichte {#reports}

Im kostenlosen Plugin zeigt [Berichte](../reports/index.mdx) die heutigen Verkäufe der Kasse, der dieses Gerät zugeordnet ist. Frühere Tage, andere Kassen und andere Filialen erfordern Pro: Drücken Sie auf eine gesperrte Option, um den Grund zu sehen.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[100, 0], [0, 0], [100, 0], [215, 0], [0, 0]]} maxWidth={560} alt="Die Datumsauswahl in Berichte im kostenlosen Plugin: Heute ist ausgewählt, die anderen Zeiträume und alle anderen Tage sind ausgegraut und mit einem Schloss versehen; dazu der Hinweis Frühere Tage sind in WCPOS Pro verfügbar mit der Schaltfläche Pro ansehen">

1. **Heute** — darüber berichtet das kostenlose Plugin: die heutigen Verkäufe an Ihrer Kasse.
2. **Gestern** und die anderen Zeiträume — gesperrt. Drücken Sie auf einen davon, um den Grund zu sehen.
3. **Kalender** — nur der heutige Tag lässt sich auswählen.
4. **Frühere Tage sind in WCPOS Pro verfügbar** — der Hinweis. Ebenso zeigt das Kassenmenü **Andere Kassen sind in WCPOS Pro verfügbar** und das Filialmenü **Andere Filialen sind in WCPOS Pro verfügbar**. Unter Abschlüsse lautet der Hinweis **Frühere Abschlüsse sind in WCPOS Pro verfügbar**.
5. **Pro ansehen** — öffnet die WCPOS-Pro-Seite auf wcpos.com.

</JourneyShot>

### Kundendisplay {#customer-display}

Ein Kundendisplay ist ein zweiter Bildschirm, auf dem der Kunde den Warenkorb sieht, während Sie den Verkauf erfassen. Sie koppeln es unter **Einstellungen › Kundendisplay**. Im kostenlosen Plugin weist diese Seite darauf hin, dass das Display Pro erfordert.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[130, 0], [260, -13], [-40, 0]]} maxWidth={640} alt="Einstellungen, Kundendisplay im kostenlosen Plugin: der Text Kundendisplays sind eine Pro-Funktion und der Link Mehr über Kundendisplays erfahren">

1. **Kundendisplay** — unter **Einstellungen**, dem Zahnrad unten im Menü.
2. **Kundendisplays sind eine Pro-Funktion.** — mit Pro koppeln Sie das Display auf dieser Seite. Ist Pro installiert, aber zu alt für Displays, lautet der Hinweis **Kundendisplays benötigen eine neuere Version von WCPOS Pro. Aktualisieren Sie das Pro-Plugin in WordPress.**
3. **Mehr über Kundendisplays erfahren** — öffnet die Anleitung [Kundendisplay](../hardware/customer-display/index.mdx) in Ihrem Browser.

</JourneyShot>

## Was das kostenlose Plugin bietet {#whats-in-the-free-plugin}

Das kostenlose Plugin von [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) deckt den gesamten Verkauf ab, vom ersten Produkt bis zum Beleg: Bargeld und Karte, eine Kasse, Gutscheine im Warenkorb, Belege und Drucken, Offline-Verkäufe, Barcode-Scannen und Steuer-IDs der Kunden — auf jeder Plattform.

Die heutigen Verkäufe und Abschlüsse finden Sie unter [Berichte](../reports/index.mdx), wo Sie die Abschlüsse als CSV-Datei exportieren können. Siehe [Kasse öffnen](../pos/register/index.mdx).

:::note Kunden und Gutscheine im kostenlosen Plugin
Sie können für einen Verkauf einen vorhandenen Kunden auswählen und einen Gutschein im Warenkorb anwenden. Das Hinzufügen oder Bearbeiten von Kunden und das Erstellen von Gutscheinen erfordern Pro. Unter **WP Admin › Marketing › Gutscheine** können Sie jederzeit Gutscheine erstellen.
:::

## Was Pro ergänzt {#what-pro-adds}

Pro schaltet die übrigen Funktionen des POS frei: die Verwaltungsansichten, weitere Möglichkeiten zur Zahlungsannahme sowie weitere Kassen und Filialen.

### Verwaltungsansichten {#management-screens}

| Ansicht | Was Sie mit Pro tun können |
|---|---|
| **[Produkte](../products/index.mdx)** | Bestände und Preise direkt in der Produktliste ändern. |
| **[Bestellungen](../orders/index.mdx)** | Eine ältere Bestellung suchen, erneut öffnen, bearbeiten, ihren Beleg erneut drucken und den Betrag zurückerstatten. |
| **[Kunden](../customers/index.mdx)** | Kunden hinzufügen und ihre Daten bearbeiten. |
| **[Berichte](../reports/index.mdx)** | Frühere Tage, jede Kasse und jede Filiale sowie die Abschlusshistorie einsehen. |
| **[Gutscheine](../coupons/index.mdx)** | Ihre Gutscheine nachschlagen und bei entsprechender Berechtigung neue erstellen. |

### Zahlungsgateways {#payment-gateways}

Das kostenlose Plugin erfasst Barzahlungen und Kartenzahlungen, die über ein separates Kartenterminal angenommen wurden. Mit Pro können Sie auch Zahlungen über verbundene Kartenlesegeräte und andere Zahlungsdienste annehmen.

Mit Pro können Sie die weiteren Zahlungsarten Ihres Shops (in WooCommerce als Zahlungsgateways bezeichnet) in den [Checkout-Einstellungen](../settings/wp-admin/checkout.mdx) für den POS aktivieren. Die folgenden WCPOS-Optionen benötigen jeweils ein eigenes Plugin.

## Preise {#pricing}

Pro ist auf [wcpos.com/pro](https://wcpos.com/pro) erhältlich. Jede Lizenz gilt für zwei Websites: eine produktive Website und eine Entwicklungswebsite.

- **Jährlich** — $129. Updates und bevorzugter Support für ein Jahr. Die Lizenz verlängert sich nicht automatisch.
- **Lebenslang** — $399, einmalige Zahlung. Unbegrenzt Updates.

Preise mit Stand November 2026.

Wenn eine Jahreslizenz abläuft, wird nichts abgeschaltet: Ihre vorhandene Pro-Version funktioniert mit allen Funktionen weiter. Neue Updates und bevorzugter Support stehen erst nach einer Verlängerung wieder zur Verfügung.

:::tip Erst ausprobieren
Die Schaltfläche **Demo ansehen** öffnet in jeder Pro-Ansicht dieselbe Ansicht im WCPOS-Demo-Shop unter [demo.wcpos.com/pos](https://demo.wcpos.com/pos).
:::

## Bereit für ein Upgrade? {#ready-to-upgrade}

Unter [WCPOS Pro installieren](./pro-license.mdx) finden Sie die Schritte zum Herunterladen und Aktivieren.

- **Pro ab 1.8** ist ein eigenständiges Plugin, das alle Funktionen des kostenlosen Plugins enthält. Installieren Sie es, während das kostenlose Plugin noch vorhanden ist: Entfernen Sie vorher nichts (siehe [Pro über das kostenlose Plugin installieren](./installation.mdx#pro-over-free)). Anschließend können Sie das kostenlose Plugin deaktivieren und löschen.
- **Pro vor 1.8** war ein Add-on, das parallel zum kostenlosen Plugin lief. Gehen Sie beim Umstieg genauso vor.
