WCPOS speichert POS-Verkäufe über die WooCommerce REST API. Deshalb funktionieren die meisten WooCommerce-Plugins damit ohne zusätzliche Einrichtung. Bei einigen muss WCPOS eingreifen, weil sie nur auf den Online-Checkout oder die Bestellansicht in WP Admin reagieren. Andere lassen sich überhaupt nicht mit dem POS verwenden. Diese Seite stellt vier davon vor und erklärt, was Sie jeweils tun müssen.

Product Bundles, Composite Products und Product Add-Ons stehen für 2.3 auf der [Roadmap](../getting-started/roadmap.mdx#your-other-plugins).

## Plugins, die nicht mit dem POS funktionieren {#not-supported}

:::warning Achten Sie auf diese beiden Plugins
Deaktivieren Sie **wePOS**, bevor Sie WCPOS verwenden. **Stripe Tax** funktioniert nicht mit POS-Bestellungen: Verwenden Sie für die automatische Steuerberechnung an der Kasse WooCommerce Tax.
:::

### wePOS {#wepos}

**Was Sie tun müssen:** Suchen Sie unter **WP Admin > Plugins** nach **wePOS** und wählen Sie **Deaktivieren**. Suchen Sie anschließend nach **WCPOS – Point of Sale for WooCommerce** und wählen Sie **Aktivieren**. Wenn Sie **Plugins** nicht öffnen können, bitten Sie Ihren Shop-Administrator darum. Solange wePOS aktiv ist, deaktiviert sich WCPOS beim nächsten Laden von WP Admin selbst und zeigt folgende Meldung: *WCPOS kann aufgrund von Kompatibilitätsproblemen nicht gleichzeitig mit dem wePOS-Plugin ausgeführt werden. WCPOS wurde deaktiviert.*

**Warum:** wePOS verändert, wie Ihr Shop variable Produkte übermittelt. Dadurch funktionieren Varianten im POS nicht mehr.

### Stripe Tax {#stripe-tax}

**Was Sie tun müssen:** Verwenden Sie für die automatische Steuerberechnung bei POS-Bestellungen [WooCommerce Tax](#woocommerce-tax). Dieses Plugin für die automatische Steuerberechnung wird von WCPOS unterstützt.

**Warum:** Stripe Tax funktioniert nicht mit POS-Bestellungen, und es gibt keine Umgehungslösung.

## Plugins, mit denen WCPOS zusammenarbeitet {#plugins}

### WooCommerce Tax {#woocommerce-tax}

**Was Sie tun müssen:** Befolgen Sie die [Schritte zur Einrichtung von WooCommerce Tax](./woocommerce-tax.mdx#setup), um die automatische Steuerberechnung zu aktivieren. Der POS übernimmt Ihre WooCommerce-Steuereinstellungen jedes Mal, wenn er Ihre Filiale lädt. Im POS müssen Sie daher nichts ändern.

<details>
<summary>Wie WCPOS mit WooCommerce Tax zusammenarbeitet</summary>

WooCommerce Tax ermittelt Steuersätze über Ihren Online-Checkout und die Bestellansicht in WP Admin. POS-Bestellungen gelangen jedoch auf einem anderen Weg in Ihren Shop. Deshalb fragt WCPOS bei jedem Speichern einer offenen POS-Bestellung die Steuersätze bei WooCommerce Tax ab. So gelten für POS-Verkäufe dieselben Steuersätze wie für Ihre Onlinebestellungen.

</details>

### Yoast SEO {#yoast-seo}

**Was Sie tun müssen:** nichts.

<details>
<summary>Wie WCPOS mit Yoast SEO zusammenarbeitet</summary>

WCPOS lässt die SEO-Daten von Yoast beim Herunterladen der POS-Daten weg, damit bei der Synchronisierung nur wenige Daten übertragen werden. Außerdem bleibt der Link erhalten, über den die Apps Ihren Shop finden – selbst wenn Yoast so eingestellt ist, dass es ihn entfernt.

</details>

## Integrationen und Erweiterungen {#extensions}

:::info Mit WCPOS Pro
Zum Installieren von Erweiterungen benötigen Sie WCPOS Pro. In der kostenlosen Version wird das Erweiterungsverzeichnis mit deaktivierten Installationsschaltflächen angezeigt.
:::

Wenn es für ein von Ihnen verwendetes Plugin eine WCPOS-Erweiterung gibt, richten Sie diese unter [Erweiterungen](../extensions/index.mdx) ein.

<details>
<summary>Was ist der Unterschied zwischen einer Integration und einer Erweiterung?</summary>

Eine Integration betrifft ein Plugin, das Sie bereits in Ihrem Onlineshop verwenden. WCPOS arbeitet ohne zusätzliches Add-on damit zusammen und greift bei Bedarf ein, wie etwa bei WooCommerce Tax. Eine Erweiterung ist ein speziell für WCPOS entwickeltes Add-on, etwa für ein Kartenterminal, oder ein Add-on, das die Zusammenarbeit von WCPOS mit einem Übersetzungsplugin wie WPML ermöglicht.

</details>

## Funktioniert etwas nicht? {#something-not-working}

Wenn ein benötigtes Plugin im Zusammenspiel mit dem POS Probleme verursacht, beginnen Sie mit [Plugin-Konflikte](../support/troubleshooting/plugin-conflicts.mdx). Dort finden Sie die [bekannten Konflikte](../support/troubleshooting/plugin-conflicts.mdx#known-plugin-conflicts) und erfahren, wie Sie neue erkennen.
