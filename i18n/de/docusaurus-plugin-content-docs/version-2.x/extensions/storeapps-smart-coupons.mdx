Mit der Erweiterung **WCPOS StoreApps Smart Coupons** lassen sich Guthabengutscheine aus [Smart Coupons](https://woocommerce.com/products/smart-coupons/) von StoreApps, etwa Geschenkkarten, zur Bezahlung eines POS-Verkaufs verwenden. Mit WCPOS Pro nehmen Sie die Karte auf der Zahlungsseite der Kasse an. Der richtige Betrag wird abgezogen und der Beleg zeigt das Restguthaben.

:::warning Über Rabatt hinzufügen lässt sich kein Guthaben einlösen
Wenn Sie eine Geschenkkarte über **Rabatt hinzufügen** im Warenkorb eingeben, erscheint **Gutschein nicht gefunden**. Lösen Sie sie stattdessen auf dem Tab **Legacy** der Kasse ein: siehe [Eine Geschenkkarte an der Kasse annehmen](#at-the-till).
:::

## Eine Geschenkkarte an der Kasse annehmen {#at-the-till}

Bevor Sie beginnen, muss der Administrator [diese Erweiterung installiert haben](#install) und Smart Coupons von StoreApps muss aktiv sein. Außerdem benötigen Sie eine Zahlungsart auf dem [Tab Legacy](../pos/checkout/legacy-tab.mdx) der Kasse: Dieser Tab öffnet die Zahlungsseite des Shops mit einem Gutscheinfeld.

1. Füllen Sie den Warenkorb, drücken Sie **Kasse** und öffnen Sie den Tab **Legacy**. Die Zahlungsseite des Shops öffnet sich in der Kasse.
2. Geben Sie den Code der Geschenkkarte unter **Gutscheincode** ein und drücken Sie **Gutschein anwenden**. Der Gesamtbetrag der Bestellung verringert sich um den Betrag, den die Karte abdeckt.
3. Wählen Sie die Zahlungsart, mit der der Kunde den Rest bezahlt, nehmen Sie die Zahlung auf dieser Seite entgegen und drücken Sie anschließend **Zahlung verarbeiten**.
4. Prüfen Sie auf dem Beleg, ob die Rabattzeile des Gutscheins **Restguthaben** enthält, wie unter [Was der Beleg zeigt](#receipt) beschrieben. Falls diese Angabe fehlt, siehe [Wenn etwas schiefgeht](#goes-wrong).

Wenn auf dem Tab **Legacy** keine Zahlungsarten vorhanden sind, gibt es keine Zahlungsseite, auf der Sie die Karte einlösen können. Nehmen Sie die Zahlung wie gewohnt entgegen und bitten Sie den Kunden, die Geschenkkarte für einen späteren Einkauf aufzubewahren: Es wurde nichts davon abgezogen.

## Was der Beleg zeigt {#receipt}

Am Ende der Rabattzeile des Gutscheins steht das Guthaben der Karte zum Zeitpunkt der Belegerstellung. Auf dem **Standardbeleg** wird für einen Guthabengutschein mit der Beschreibung **Geschenkkarte** Folgendes gedruckt:

> Rabatt · Geschenkkarte — Restguthaben: $61.50

Auf dem Beleg beim Kassiervorgang ist dies das Guthaben unmittelbar nach dem Verkauf. Ihre Belegvorlage benötigt keine Anpassung. Auch wenn der Gutschein keine Beschreibung hat, endet die Zeile mit **Restguthaben**. Wie Sie in dieser Zeile **Geschenkkarte** statt **Rabatt** drucken, erfahren Sie unter [Für Entwickler](#developers).

## Was die Erweiterung macht {#what-it-does}

StoreApps verwaltet Geschenkkartenguthaben für Online-Bestellungen, berücksichtigt aber allein keine am POS bezahlten Bestellungen. Wenn eine POS-Bestellung einen Guthabengutschein enthält, übernimmt die Erweiterung Folgendes:

- **Zieht nur den ausgegebenen Betrag ab.** Sie erfasst, wie viel vom Kartenguthaben für die Bestellung verwendet wurde, damit StoreApps diesen Betrag abzieht und den Rest auf der Karte belässt.
- **Verringert das Guthaben, sobald die Bestellung bezahlt wird.** Nie bereits beim Hinzufügen des Gutscheins und nie zweimal.
- **Berücksichtigt entfernte Gutscheine nicht mehr.** Wird der Gutschein vor der Zahlung entfernt, wird dafür nichts abgezogen.
- **Vermerkt den Vorgang in der Bestellung.** Siehe [Die Bestellnotiz](#order-note).
- **Druckt das Guthaben auf den Beleg.** Siehe [Was der Beleg zeigt](#receipt).

Wenn StoreApps Smart Coupons deaktiviert ist, hat die Erweiterung keine Wirkung.

## Die Erweiterung installieren {#install}

Ein Administrator installiert sie einmalig in **WP Admin**: mit WCPOS Pro unter **POS → Einstellungen → Erweiterungen** oder mit dem kostenlosen Plugin durch Hochladen der veröffentlichten Version.

<details>
<summary>Installationsschritte mit WCPOS Pro oder dem kostenlosen Plugin</summary>

:::note Bevor Sie beginnen
Sie benötigen einen Administratorzugang zu **WP Admin**. Außerdem muss Smart Coupons von StoreApps (erhältlich auf WooCommerce.com) auf der Website aktiv sein. Die Erweiterung funktioniert nur mit diesem Plugin, nicht mit anderen Plugins, die „Smart Coupons“ im Namen tragen.
:::

### Mit WCPOS Pro {#install-pro}

1. Gehen Sie in **WP Admin** zu **POS → Einstellungen → Erweiterungen**.
2. Suchen Sie **WCPOS StoreApps Smart Coupons** und drücken Sie **Installieren**.
3. Drücken Sie **Aktivieren**.

Informationen zu Updates und automatischen Updates finden Sie unter [Eine Erweiterung installieren](./index.mdx#installing-an-extension).

### Mit dem kostenlosen Plugin {#install-free}

Die Seite Erweiterungen führt die Erweiterung auf, ihre Schaltflächen erfordern jedoch Pro. Gehen Sie stattdessen so vor:

1. Laden Sie `wcpos-storeapps-smart-coupons.zip` aus der [neuesten Veröffentlichung](https://github.com/wcpos/wcpos-storeapps-smart-coupons/releases/latest) der Erweiterung herunter.
2. Gehen Sie in **WP Admin** zu **Plugins → Neues Plugin hinzufügen** und drücken Sie **Plugin hochladen**.
3. Wählen Sie die heruntergeladene Datei und drücken Sie **Jetzt installieren**.
4. Drücken Sie **Plugin aktivieren**.

</details>

Danach ist keine weitere Einrichtung nötig. Erstellen Sie Guthabengutscheine oder Geschenkkarten wie gewohnt in WooCommerce.

## Die Bestellnotiz {#order-note}

Sobald die Bestellung bezahlt wird, fügt die Erweiterung eine private Notiz hinzu. Mitarbeiter sehen sie in der Bestellung unter **WP Admin → WooCommerce → Bestellungen**:

> StoreApps Smart Coupons-Guthaben für WCPOS erfasst: Gutschein store100 hat $38.50 verwendet. Aktuelles Guthaben: $61.50.

Damit können Sie prüfen, mit welcher Karte bezahlt wurde, welchen Betrag sie abgedeckt hat und wie viel Guthaben übrig blieb. Die Notiz wird einmal pro Bestellung hinzugefügt.

## Rückerstattungen und Stornierungen {#refunds}

Die Erweiterung schreibt kein Guthaben zurück. Wenn Sie eine teilweise mit Guthaben bezahlte Bestellung erstatten oder stornieren, bestimmt StoreApps, was mit dem Guthaben geschieht. Prüfen Sie anschließend den Gutscheinbetrag unter **WP Admin → Marketing → Gutscheine**. Entspricht er nicht dem Guthaben, das dem Kunden zusteht, wenden Sie sich an Ihren Shop-Administrator: Er kann den Gutscheinbetrag dort ändern.

## Wenn etwas schiefgeht {#goes-wrong}

**Gutschein nicht gefunden** beim Anwenden einer Geschenkkarte über **Rabatt hinzufügen**. In WCPOS 2.0 lassen sich über Rabatt hinzufügen nur prozentuale Gutscheine sowie Gutscheine mit festen Warenkorb- oder Produktrabatten anwenden. Bei einem Guthabengutschein erscheint dort deshalb **Gutschein nicht gefunden**, mit oder ohne diese Erweiterung. Verwenden Sie stattdessen [die Zahlungsseite auf dem Tab Legacy](#at-the-till).

**Das Guthaben ist nach dem Verkauf unverändert.** Prüfen Sie unter **Plugins**, ob sowohl **Smart Coupons** als auch **WCPOS StoreApps Smart Coupons** aktiv sind. Der Abzug erfolgt bei der Zahlung der Bestellung, nicht beim Hinzufügen des Gutscheins. Bei einer Bestellung ohne Guthabennotiz hat die Erweiterung nichts abgezogen.

**Auf dem Beleg fehlt das Guthaben.** Ein Beleg, der bei offline geschalteter Kasse gedruckt wird, enthält kein Guthaben. Drucken Sie ihn erneut, sobald die Kasse wieder online ist. Fehlt die Angabe weiterhin, gibt Ihre Belegvorlage die Beschriftung der Rabattzeile nicht aus; siehe [Belegdaten](../receipts/receipt-data.mdx#discounts).

<details>
<summary>Für Entwickler: gespeicherte Daten und Hooks</summary>

<Anchor id="developers" />

Die Erweiterung fügt keine WCPOS-Gutscheinfelder hinzu. Sie arbeitet über WooCommerce-Bestellmetadaten und die Guthabenlogik von StoreApps. Sie gilt nur für POS-Bestellungen (`wcpos_is_pos_order()`: `created_via` ist `woocommerce-pos`) und nur für Gutscheine vom Typ `smart_coupon`.

- **Verwendung.** Bei `woocommerce_order_after_calculate_totals` schreibt sie die StoreApps-Bestellmetadaten `smart_coupons_contribution` (Gutscheincode → verwendeter Betrag) und `wc_sc_environment`, sofern StoreApps dies noch nicht getan hat. Einträge für Gutscheine, die nicht mehr in der unbezahlten Bestellung enthalten sind, werden entfernt.
- **Gutscheinfeld auf der Zahlungsseite.** Dieses Formular sendet einen einfachen Frontend-POST an `WC_Order::apply_coupon()`, den StoreApps nicht als Bestellkontext behandelt. Während eine unbezahlte POS-Bestellung mit einer `smart_coupon`-Position außerhalb einer REST-Anfrage neu berechnet wird, meldet die Erweiterung einen REST-Kontext, damit die Bestellrabattlogik von StoreApps ausgeführt wird.
- **Abzug.** Eine POS-Bestellung wird ausgehend von `pos-open` oder `pos-partial` bezahlt. StoreApps zieht Guthaben jedoch nur bei einem Wechsel von `pending` oder `failed` ab. Bei `woocommerce_order_status_changed` von einem anderen Status in einen bezahlten Status oder `on-hold` ruft die Erweiterung `WC_SC_Coupon_Process::update_smart_coupon_balance()` von StoreApps auf. Diese Methode markiert jede Gutscheinposition, damit nie zweimal Guthaben abgezogen wird.
- **Bestellnotiz.** Wird beim Wechsel zu `processing`, `completed` oder `on-hold` einmal pro Bestellung hinzugefügt (`_wcpos_storeapps_smart_coupons_audit_note_added`).
- **Beleg.** Die Erweiterung filtert `woocommerce_coupon_get_description`, während ein WCPOS-Beleg gerendert wird. Im Belegdatenfilter fügt sie der Guthabenzeile in `discounts` die Angabe `gift_card: true` hinzu und hängt das Guthaben an deren `label` an. Eine Vorlage kann dann Folgendes drucken:

```text
{{#discounts}}{{#gift_card}}Gift Card{{/gift_card}}{{^gift_card}}{{i18n.discount}}{{/gift_card}} · {{label}}{{/discounts}}
```

- **Hook-Namen.** Version 0.2.3 verwendet weiterhin die Namen aus der Zeit vor 2.0: `woocommerce_pos_receipt_data`, `woocommerce_pos_before_template_render` und `woocommerce_pos_after_template_render`. WCPOS 2.0 löst diese weiterhin nach den entsprechenden Hooks mit `wcpos_`-Namen aus. Wenn `WP_DEBUG` aktiviert ist, protokolliert WordPress für jeden einen Veraltungshinweis. Siehe [Hook-Benennung](./index.mdx#hook-naming).

Quelle: [github.com/wcpos/wcpos-storeapps-smart-coupons](https://github.com/wcpos/wcpos-storeapps-smart-coupons).

</details>
