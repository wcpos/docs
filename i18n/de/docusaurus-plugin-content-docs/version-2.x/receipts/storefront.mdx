**WP Admin:** Aktivieren Sie unter `WP Admin → POS → Settings → General` die Schaltfläche **Beleg** für Onlinebestellungen.

:::note Diese Seite richtet sich an die Verantwortlichen für die Website
Mit [WCPOS Pro](../getting-started/pro-license.mdx) können Sie an der Kasse für jede Bestellung, auch für Onlinebestellungen, einen Beleg drucken oder per E-Mail versenden: siehe [Beleg erneut drucken](../orders/index.mdx#receipt-reprinting) auf der Seite **Bestellungen**.
:::

:::tip Wenn ein Kunde nach seinem Onlinebeleg fragt
Sobald die Funktion auf der Website eingerichtet ist, finden Kunden die Schaltfläche **Beleg** unter **Mein Konto → Bestellungen** oder einen Beleglink auf ihrer Bestellbestätigungsseite, sofern der Shop dort einen hinzugefügt hat.
:::

Ihre WCPOS-Belegvorlagen funktionieren auch auf Ihrer Website. Kunden, die online gekauft haben, können ihren Beleg als PDF unter **Mein Konto** herunterladen oder über einen Link, den Sie auf der Bestellbestätigungsseite einfügen.

## Die Schaltfläche Beleg aktivieren {#my-account}

:::warning Aktivieren Sie zuerst eine Belegvorlage
Aktivieren Sie zunächst eine Vorlage unter **POS → Vorlagen**. Ohne aktive Vorlage sehen Kunden die Schaltfläche **Beleg** auch dann nicht, wenn die Einstellung aktiviert ist. Siehe [Beleg anpassen](./customise.mdx#option-1--pick-a-different-template).
:::

Die Schaltfläche ist deaktiviert, bis Sie sie aktivieren. Das PDF wird aus Ihrer Belegvorlage erstellt.

1. Gehen Sie in WP Admin zu **POS → Einstellungen → Allgemein**.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="WP Admin mit ausgewähltem Menüpunkt POS, Einstellungen und geöffnetem Einstellungsbereich Allgemein; zu sehen sind Filialen, Kasse und der Anfang von Produkte">

1. **POS → Einstellungen** — der Menüpunkt in WP Admin für die POS-Einstellungen.
2. **Allgemein** — die erste Einstellungsseite, die beim Aufrufen bereits geöffnet ist.

</JourneyShot>

2. Scrollen Sie zum Abschnitt **Kunden** und aktivieren Sie **Kunden das Herunterladen von Belegen erlauben**. Die Änderung wird sofort gespeichert.

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="Der Abschnitt Kunden unter Allgemein: Benutzername automatisch aus der E-Mail-Adresse des Kunden generieren, Standard-POS-Kunde auf Gast gesetzt und Kunden das Herunterladen von Belegen erlauben, hier noch deaktiviert">

1. **Kunden** — der Abschnitt mit der Belegeinstellung.
2. **Kunden das Herunterladen von Belegen erlauben** — deaktiviert, bis Sie die Einstellung aktivieren.

</JourneyShot>

3. Darunter erscheint **Belegvorlage für Kunden**. Behalten Sie **Aktive Belegvorlage verwenden** bei oder wählen Sie eine Vorlage aus. Siehe [Vorlage für Kunden auswählen](#template-choice).

Angemeldete Kunden sehen nun unter **Mein Konto → Bestellungen** neben ihren Bestellungen die Schaltfläche **Beleg**. Damit laden sie ein PDF herunter, dessen Dateiname sich nach der Bestellung richtet, etwa `receipt-1234.pdf`.

Die Schaltfläche erscheint nur bei bereits bezahlten Bestellungen:

| Bestellstatus | Schaltfläche Beleg |
|---|---|
| **In Bearbeitung** | Ja |
| **Abgeschlossen** | Ja |
| **Rückerstattet** | Ja |
| Jeder andere Status, etwa **Zahlung ausstehend**, **Wartend**, **Storniert** oder **Fehlgeschlagen** | Nein |

Ein Entwickler kann [ändern, bei welchen Status die Schaltfläche erscheint](#developers).

## Vorlage für Kunden auswählen {#template-choice}

**Belegvorlage für Kunden** legt fest, welche Vorlage für den Download verwendet wird.

- **Aktive Belegvorlage verwenden** (Standard): Kunden erhalten Ihre aktive Belegvorlage aus **POS → Vorlagen**. Wenn Sie diese dort ändern, gilt die Änderung auch für die Downloads.
- **Eine bestimmte Vorlage**: Kunden erhalten immer diese Vorlage, unabhängig davon, welche der Kassierer an der Kasse auswählt. Verwenden Sie diese Option, wenn mehrere Belegvorlagen aktiv sind oder Onlinebestellungen ein eigenes Erscheinungsbild erhalten sollen.

Eine schmale Vorlage im Thermobelegformat erzeugt ein schmales PDF. Bei Onlinebestellungen ist eine ganze Seite meist besser lesbar: Die Vorlage **Rechnung** in der Galerie ist für Papier im Format A4 und Letter ausgelegt. Wie Sie sie hinzufügen, erfahren Sie unter [Beleg anpassen](./customise.mdx#option-1--pick-a-different-template).

Das PDF wird mit denselben [Belegdaten](./receipt-data.mdx) wie der Kassenbeleg gefüllt. Ihr Logo, Ihre Filialdaten und Ihre Steuereinstellungen werden daher übernommen.

Wenn eine ausgewählte Vorlage später gelöscht oder ihre Veröffentlichung aufgehoben wird, zeigt die Auswahlliste **Nicht verfügbare Vorlage** an. Kunden erhalten stattdessen Ihre aktive Belegvorlage. Wählen Sie eine andere Vorlage aus.

## Einen Beleglink auf der Bestellbestätigungsseite hinzufügen {#shortcode}

Bieten Sie Kunden auf der Dankeseite, die sie nach dem Kauf sehen, einen Link **Beleg herunterladen (PDF)** an. Gäste, die ohne Konto bestellt haben, erhalten ihren Beleg auf diesem Weg.

Wenn es in Ihrem WP Admin **Design → Editor → Vorlagen → Bestellbestätigung** gibt, können Sie den Link selbst auf der Dankeseite einfügen:

1. Gehen Sie in WP Admin zu **Design → Editor → Vorlagen** und öffnen Sie **Bestellbestätigung**.
2. Fügen Sie an der gewünschten Stelle einen **Shortcode**-Block hinzu und geben Sie darin `[wcpos_receipt]` ein.
3. Klicken Sie auf **Speichern**.

Wenn Sie diese Vorlage nicht haben oder den Link auf der Seite einer Bestellung unter **Mein Konto** einfügen möchten, bitten Sie einen Entwickler, [den Beleglink per Code hinzuzufügen](#developers).

Der Shortcode funktioniert unabhängig davon, ob **Kunden das Herunterladen von Belegen erlauben** aktiviert ist: Diese Einstellung steuert nur die Schaltfläche unter **Mein Konto → Bestellungen**.

<details>
<summary>Shortcode-Optionen und Beispiele</summary>

`[wcpos_receipt]` funktioniert auf der Bestellbestätigungsseite und auf der Seite einer Bestellung unter **Mein Konto**. Dort erkennt er die Bestellung automatisch, sodass Sie keine Bestellnummer eingeben müssen. Auf jeder anderen Seite zeigt er nichts an, sofern Sie keine `order_id` angeben.

| Option | Standard | Funktion |
|---|---|---|
| `order_id` | *(auf der Seite ermittelt)* | Link zu einer bestimmten Bestellung auf einer beliebigen Seite. Wird nur dem angemeldeten Kunden angezeigt, dem die Bestellung gehört. |
| `link_text` | `Download receipt (PDF)` | Der Text des Links. |
| `format` | `pdf` | `pdf` lädt ein PDF herunter. `html` öffnet den Beleg druckfertig im Browser. |
| `template` | *(Ihre aktive Belegvorlage)* | Stattdessen diese Vorlage verwenden. |
| `class` | `wcpos-receipt-link` | CSS-Klasse des Links. |
| `id` | *(keine)* | HTML-`id` des Links. |

Die Shortcode-Option `template` berücksichtigt **Belegvorlage für Kunden** nicht: Wenn Sie sie weglassen, verwendet der Link Ihre aktive Belegvorlage.

Ein Downloadlink mit Ihrem eigenen Text:

```text
[wcpos_receipt link_text="Download your invoice"]
```

Den Beleg im Browser öffnen, statt ein PDF herunterzuladen:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

Eine bestimmte Vorlage verwenden, zum Beispiel eine A4-Rechnung anstelle Ihres 80mm-Kassenbelegs:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

Die Vorlagennummer steht in der Adressleiste, wenn Sie die Vorlage unter **POS → Vorlagen** bearbeiten (`post=123`). Eine nicht veröffentlichte Vorlage wird ignoriert; der Link verwendet dann Ihre aktive Belegvorlage.

</details>

## Wer einen Beleg öffnen kann {#security}

- **Kunden mit einem Konto** melden sich an und verwenden die Schaltfläche **Beleg** unter **Mein Konto → Bestellungen**.
- **Gäste**, die ohne Konto bestellt haben, verwenden den Beleglink auf ihrer Bestellbestätigungsseite, sobald Sie [dort einen eingefügt haben](#shortcode).

:::warning Teilen Sie Beleglinks nur mit dem jeweiligen Kunden
Jeder, der einen Beleglink besitzt, kann den Beleg ohne Anmeldung öffnen. Behandeln Sie ihn genauso vertraulich wie die Bestellung selbst.
:::

<details>
<summary>Wie Beleglinks geschützt werden</summary>

Jeder Beleglink enthält den privaten Schlüssel der Bestellung – denselben, den WooCommerce auf der Bestellbestätigungsseite verwendet. Ohne den richtigen Schlüssel lässt sich der Beleg nicht öffnen. Ein Shortcode mit der Option `order_id` zeigt seinen Link nur dem angemeldeten Kunden an, dem die Bestellung gehört.

</details>

## Wenn etwas schiefgeht {#goes-wrong}

Die meisten der folgenden Probleme werden in WP Admin behoben. Wenn Sie als Kassierer arbeiten, leiten Sie die Meldung, die der Kunde sieht, an die Verantwortlichen für die Website weiter. In der Zwischenzeit können Sie mit [WCPOS Pro](../getting-started/pro-license.mdx) den Beleg an der Kasse drucken oder per E-Mail versenden: siehe [Beleg erneut drucken](../orders/index.mdx#receipt-reprinting) auf der Seite **Bestellungen**.

**Der Kunde sieht keine Schaltfläche Beleg.** Prüfen Sie, ob **Kunden das Herunterladen von Belegen erlauben** aktiviert ist, die Bestellung den Status **In Bearbeitung**, **Abgeschlossen** oder **Rückerstattet** hat und mindestens eine Belegvorlage unter **POS → Vorlagen** aktiv ist. Die Schaltfläche erscheint nur unter **Mein Konto → Bestellungen** für angemeldete Kunden.

**„Es ist keine Belegvorlage konfiguriert.“** Für das PDF ist keine Vorlage verfügbar. Aktivieren Sie eine Belegvorlage unter **POS → Vorlagen**.

**„Sie haben keine Berechtigung, diesen Beleg anzuzeigen.“** Der Link ist unvollständig oder wurde falsch kopiert: Jeder Link enthält einen privaten Schlüssel für die jeweilige Bestellung. Senden Sie dem Kunden den Link von seiner Bestätigungsseite oder aus **Mein Konto** erneut.

**„Das Beleg-PDF konnte nicht erstellt werden.“** Aus der Vorlage konnte kein PDF erstellt werden. Öffnen Sie die Vorlage unter **POS → Vorlagen** und sehen Sie sich die Vorschau an. Siehe [Beleg anpassen](./customise.mdx).

**Der Link führt zum Fehler „Seite nicht gefunden“.** Gehen Sie in WP Admin zu **Einstellungen → Permalinks** und wählen Sie eine beliebige Option außer **Einfach**. Mit **Einfach** funktionieren Beleglinks nicht.

## Für Entwickler {#developers}

<details>
<summary>Den Beleglink per Code hinzufügen</summary>

Geben Sie bei einem klassischen Theme den Link über die beiden WooCommerce-Actions aus, die diese Seiten erzeugen:

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

Der Shortcode erkennt die Bestellung auf beiden Seiten und benötigt daher keine `order_id`.

</details>

<details>
<summary>Filter für die Schaltfläche Beleg und die PDF-Vorlage</summary>

Drei Filter ergänzen die obigen Einstellungen um Regeln, die sich darüber nicht abbilden lassen, etwa pro Bestellung oder pro Kunde:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

Vor WCPOS 2.0 hießen diese Filter `woocommerce_pos_storefront_receipt_*`. Diese Namen funktionieren weiterhin, sind aber seit 2.0 veraltet und werden frühestens in 2.2 entfernt. Siehe [Hook-Benennung](../extensions/index.mdx#hook-naming).

Die PDF-Adresse lautet `/wcpos-checkout/wcpos-receipt/{order_id}` mit `?key={order_key}&format=pdf`: dieselbe durch einen Schlüssel geschützte Belegadresse, die der POS verwendet. Mit `format=pdf` wird statt der Seite ein PDF zurückgegeben.

</details>
