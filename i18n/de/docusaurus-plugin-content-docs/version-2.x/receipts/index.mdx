**WP Admin:** Vorlagen werden unter `WP Admin → POS → Templates` ausgewählt.

Jeder Beleg, den WCPOS druckt, entsteht aus einer Vorlage, die mit den Verkaufsdaten gefüllt wird. Sie wählen die Vorlagen unter **WP Admin → POS → Vorlagen** aus. Die Kasse druckt die erste aktive Vorlage, sofern der Kassierer keine andere auswählt. Auf derselben Seite finden Sie Rechnungen, Geschenkbelege, Lieferscheine und Küchenbons.

Direkt zum gewünschten Thema:

- **An der Kasse:** [einen Beleg drucken](#at-the-till), [per E-Mail versenden](#email) oder [später erneut drucken](#reprint).
- **Für Filialinhaber:** [den Beleg Ihrer Filiale auswählen](#how-it-works) und [einem Drucker zuweisen](#template-printers).

## An der Kasse {#at-the-till}

Nach der Bezahlung eines Verkaufs erscheint der Beleg auf dem Zahlungsabschlussbildschirm. So drucken Sie ihn:

1. Prüfen Sie den Beleg in der Vorschau (5).
2. Prüfen Sie **Drucker** (4). **Auto** wählt einen zur Vorlage passenden Drucker.
3. Tippen Sie auf **Beleg drucken** (6). Nach dem ersten Druck heißt die Schaltfläche **Erneut drucken**.

<JourneyShot manifest={checkoutShots} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="Der Zahlungsabschlussbildschirm: das herauszugebende Wechselgeld, die Zahlungsart, die Auswahlfelder Vorlage und Drucker, die Belegvorschau sowie die Schaltflächen Beleg per E-Mail senden, PDF herunterladen, Beleg drucken und Neuer Verkauf">

1. **Wechselgeld**: der Betrag, den Sie zurückgeben müssen.
2. **Bezahlt**: der Betrag und die Zahlungsart.
3. **Vorlage**: welcher Beleg für diesen Verkauf verwendet wird. Siehe [Ein anderer Beleg für einen einzelnen Verkauf](#one-sale).
4. **Drucker**: wo der Beleg gedruckt wird. Siehe [Jede Vorlage einem Drucker zuweisen](#template-printers).
5. **Vorschau**: der Beleg so, wie er gedruckt wird.
6. **Beleg drucken**: druckt den angezeigten Beleg auf dem ausgewählten Drucker.
7. **Beleg per E-Mail senden**: sendet dem Kunden eine E-Mail. Siehe [Einen Beleg per E-Mail versenden](#email).
8. **Neuer Verkauf**: ein leerer Warenkorb für den nächsten Kunden.

</JourneyShot>

**PDF herunterladen** befindet sich zwischen den beiden Schaltflächen und speichert den Beleg als Datei. Dafür ist eine Verbindung erforderlich.

### Einen Beleg per E-Mail versenden {#email}

1. Tippen Sie auf **Beleg per E-Mail senden**.
2. Prüfen Sie **E-Mail-Adresse**. Zunächst ist dort die Rechnungs-E-Mail-Adresse der Bestellung eingetragen. Um eine neue Adresse in der Bestellung zu speichern, aktivieren Sie **E-Mail in Rechnungsadresse speichern**.
3. Tippen Sie auf **Senden**.

Der Kunde erhält die Rechnungs-E-Mail von WooCommerce für die Bestellung, nicht die in der Vorschau gezeigte Vorlage. Offline heißt die Schaltfläche **Senden, wenn online**. Die E-Mail wird versendet, sobald das Gerät Ihren Shop wieder erreicht.

### Einen Beleg erneut drucken {#reprint}

Mit [WCPOS Pro](../getting-started/pro-license.mdx) können Sie den Beleg später erneut drucken:

1. Öffnen Sie **Bestellungen** im Seitenmenü.
2. Suchen Sie die Bestellung und tippen Sie auf deren Belegschaltfläche.
3. Drucken Sie den Beleg in der geöffneten Ansicht.

Ohne Pro müssen Sie den Beleg auf dem Zahlungsabschlussbildschirm drucken oder per E-Mail versenden, bevor Sie auf **Neuer Verkauf** tippen.

Mehr dazu unter [Belege erneut drucken](./at-checkout.mdx#reprinting-receipts).

### Ein anderer Beleg für einen einzelnen Verkauf {#one-sale}

Der Kassierer kann unter **Vorlage** auf dem Zahlungsabschlussbildschirm eine andere aktive Vorlage auswählen. Diese Auswahl gilt nur für diesen Verkauf. Ist nur eine Vorlage aktiv, zeigt **Vorlage** lediglich deren Namen an und bietet keine Auswahl.

## Ihren Beleg auswählen {#how-it-works}

:::tip Sie möchten nur Ihren Beleg ändern?
Beginnen Sie bei **[Ihren Beleg anpassen](./customise.mdx)**. Dort werden die drei einfachsten Möglichkeiten erklärt: eine andere mitgelieferte Vorlage auswählen, eine Vorlage mithilfe von KI anpassen oder sie von Hand bearbeiten.
:::

Der Filialinhaber richtet dies einmalig in WP Admin ein:

1. Gehen Sie in WP Admin zu **POS → Vorlagen**. Auf dem Tab **Belege** stehen oben **Ihre Vorlagen** und darunter die **Vorlagengalerie**.
2. Grenzen Sie die Karten in der Galerie mit **Vorlagen suchen...**, **Kategorie**, **Format** und **Richtung** ein. **Vorschau** zeigt eine Vorlage mit **Beispieldaten** oder einer Ihrer Bestellungen.
3. Klicken Sie auf **Vorlage verwenden**. Ihre eigene Kopie wird am Ende der Liste **Ihre Vorlagen** hinzugefügt und ist bereits aktiviert.
4. Ziehen Sie sie in **Ihre Vorlagen** an die erste Stelle. Die Kasse verwendet die erste aktive Vorlage als Standard. Die integrierte **Legacy-PHP-Vorlage** steht so lange vor Ihrer Vorlage, bis Sie Ihre darüberziehen oder bei der Legacy-Vorlage den Schalter **Aktiv** ausschalten.

Um den Inhalt oder das Aussehen einer Vorlage zu ändern, öffnen Sie Ihre Kopie im Vorlageneditor. Dieser zeigt beim Bearbeiten eine Live-Vorschau. Siehe [Ihren Beleg anpassen](./customise.mdx).

## Jede Vorlage einem Drucker zuweisen {#template-printers}

In der App finden Sie unter **Einstellungen → Drucken** die druckbaren Vorlagen der Kasse unter **Belegvorlagen**, darunter **Berichtsvorlagen** und **Abschlussvorlagen**. Jede Zeile zeigt:

- **Die Vorlage**, beispielsweise die integrierte **Legacy-PHP-Vorlage**.
- **Ihren Typ**: **HTML** für den Druckdialog; bei einer Thermovorlage wird das Papierformat angezeigt, etwa **Thermo 80mm**.
- **Den Drucker**: **Auto** wählt einen Drucker, der zum Typ und zur Papierbreite der Vorlage passt, und öffnet den **Druckdialog**, wenn keiner passt. Wählen Sie einen Drucker aus, um diese Vorlage immer dort zu drucken.

Wie Sie einen Drucker hinzufügen, erfahren Sie unter [Drucker](../hardware/printers/index.mdx#adding-a-printer).

## Was auf einem Beleg gedruckt wird {#what-prints}

Dies ist der **Standardbeleg**, wie ihn die Galerie mit Beispieldaten in der Vorschau zeigt. Darunter werden die einzelnen Bestandteile und ihre Herkunft erklärt.

<div style={{maxWidth:'520px', marginInline:'auto'}}>

![Die Vorschau des Standardbelegs: oben links Logo, Name, Adresse, Telefonnummer und EIN von Coffee Monster; oben rechts Bestellnummer, Datum, Kassierer und Kunde; die Positionen mit einer Rabattzeile; Zwischensumme, Gesamt, Rückerstattet und Nettogesamtbetrag; ein Feld für zurückgegebene Artikel; ein Feld für die Kundennotiz; die Barzahlung mit gegebenem Betrag und Wechselgeld; sowie eine Dankeszeile](/img/2.x/receipts/index/en/standard-receipt-gallery-preview.webp)

- **Oben links** (Logo, Name, Adresse, Telefonnummer und Steuer-ID): Ihre Filialdaten. Ohne Pro stammen sie aus **POS → Einstellungen** (**Filialdetails** und **Steuer-IDs der Filiale**); als Logo dient das Logo Ihrer WordPress-Website. Mit Pro hat jede Filiale eigene Angaben auf ihren Seiten **Details** und **Steuer**.
- **Oben rechts** (Bestellnummer, Datum, Kassierer und Kunde): die Bestellung.
- **In der Mitte** (Positionen, Rabatt und Summen): die Bestellung mit Preisen entsprechend Ihrer Steuereinstellung. Siehe [Anpassung der Steueranzeige](#adaptive-tax-display).
- **Die beiden Felder** (Zurückgegebene Artikel und Kundennotiz): die Rückerstattungen und die Notiz zur Bestellung, sofern vorhanden.
- **Bezahlt** (weiter unten): jede Zahlung mit gegebenem Barbetrag und Wechselgeld.
- **Ganz unten** (die Dankeszeile): mit Pro die **Belegnachrichten** der jeweiligen Filiale. Andernfalls wird ein standardmäßiger Dankestext gedruckt.

</div>

Steuer-IDs werden unter [Steuer-IDs der Filiale](../settings/wp-admin/store-tax-ids.mdx) erklärt, die Angaben jeder Filiale (Pro) unter [Die Seiten der Filiale ausfüllen](../stores/setup.mdx#store-pages). Alle Felder, die eine Vorlage drucken kann, sind unter [Belegdaten](./receipt-data.mdx) aufgeführt.

Die mitgelieferten Vorlagen mit Preisanzeige drucken den regulären Preis und die Ersparnis, wenn ein Produkt im Angebot ist oder sein Preis an der Kasse geändert wurde ([Warenkorbrabatte](../pos/cart/discounts.mdx#showing-the-original-price-and-saving-on-receipts)). Wie Sie diese Angaben in Ihre eigene Vorlage aufnehmen, erfahren Sie unter [Regulären Preis und Ersparnis anzeigen](./receipt-data.mdx#displaying-regular-price-and-savings).

## Pro: ein Beleg für jede Filiale {#pro-features}

Mit [WCPOS Pro](../getting-started/pro-license.mdx) kann jede Filiale ihren eigenen Beleg drucken. Öffnen Sie unter **POS → Filialen** eine Filiale:

- **Belege**: Die Liste **Belegvorlagen** der Filiale zeigt **Wie auf der Website** an, bis Sie auf **Anpassen** klicken. Wählen Sie dann die Vorlagen aus, die Kassierer dort drucken dürfen. Die erste ausgewählte Vorlage ist der Standard der Filiale; durch Ziehen ändern Sie die Reihenfolge. Mit **Website-Vorlage verwenden** kehren Sie zur ursprünglichen Einstellung zurück. Auf derselben Seite finden Sie die **Belegnachrichten** der Filiale.
- **Details**: **Logo und Adresse**, mit **Website-Logo verwenden** oder **Logo hochladen**, sowie die Angaben unter **Kontakt** für die Filiale.

Siehe [Die Seiten der Filiale ausfüllen](../stores/setup.mdx#store-pages) und [Vorlagen pro Filiale](./customise.mdx#per-store-assignments).

## Belege außerhalb der Kasse {#beyond-the-till}

- **E-Mail**: **Beleg per E-Mail senden** an der Kasse versendet die Kundenrechnungs-E-Mail von WooCommerce, keine WCPOS-Vorlage. Ihr Aussehen ändern Sie unter **WooCommerce → Einstellungen → E-Mails**.
- **PDF herunterladen**: Der Server erstellt die PDF-Datei, daher ist eine Verbindung erforderlich.
- **Online-Kunden**: Aktivieren Sie **Kunden das Herunterladen von Belegen erlauben**, um ihren Bestellungen unter Mein Konto eine Schaltfläche **Beleg** hinzuzufügen. Diese Option ist zunächst deaktiviert. Mit **Belegvorlage für Kunden** wählen Sie die Vorlage aus, die Kunden erhalten. Siehe [Belege im Onlineshop](./storefront.mdx).

## Wenn etwas schiefgeht {#goes-wrong}

**Ihre neue Vorlage wird nicht gedruckt.** Die Kasse verwendet die erste aktive Vorlage unter **Ihre Vorlagen**. Ziehen Sie Ihre Vorlage nach oben oder deaktivieren Sie die Vorlagen darüber. Für einen einzelnen Verkauf kann der Kassierer sie unter **Vorlage** auf dem Zahlungsabschlussbildschirm auswählen.

**Vorlage zeigt auf dem Zahlungsabschlussbildschirm einen Namen, aber keine Liste.** Es ist nur eine Belegvorlage aktiv. Aktivieren Sie unter **Ihre Vorlagen** eine weitere, damit Kassierer eine Auswahl haben.

**Eine Vorlage lässt sich offline nicht auswählen.** Die **Legacy-PHP-Vorlage** und die Vorlagen von WP Overnight werden auf dem Server erstellt. Legen Sie eine HTML- oder Thermovorlage als Standard fest, wenn die Kasse häufig die Verbindung verliert.

**Das Logo fehlt.** Ohne Pro verwendet der Beleg das Logo Ihrer WordPress-Website. Legen Sie daher eines in Ihrem Theme fest. Mit Pro öffnen Sie die **Details** der Filiale und wählen **Website-Logo verwenden** oder **Logo hochladen**. Fehlt das Logo nur beim Drucken aus einem Browser-Tab, lesen Sie [Logo fehlt im Browser](../hardware/printers/logo-missing-browser.mdx).

**Es wird nichts gedruckt oder der falsche Drucker verwendet.** Prüfen Sie den Drucker der Vorlage unter **Einstellungen → Drucken** und lesen Sie anschließend [Wenn nichts gedruckt wird](../hardware/printers/index.mdx#when-nothing-prints).

## Vorlagengalerie {#template-gallery}

Die Galerie enthält fertige Vorlagen, die Sie unverändert verwenden oder anpassen können. Filtern Sie nach **Kategorie** (Beleg, Rechnung, Geschenkbeleg, Gutschrift, Einkaufsbestellung, Küchenbon, Barbon), **Format** (**HTML (Browserdruck)** oder **ESC/POS (Thermodrucker)**) und **Richtung** (**Links nach rechts** oder **Rechts nach links**). Jede Karte bietet **Vorschau** und **Vorlage verwenden**. **Vorlage verwenden** erstellt eine bearbeitbare Kopie unter *Ihre Vorlagen* und lässt das Original in der Galerie unverändert.

Wenn in der Galerie eine neuere Version einer kopierten Vorlage vorliegt, zeigt die Karte **Update verfügbar** an. **Neue Version installieren** fügt die neue Version als separate Kopie hinzu, sodass Ihre Änderungen erhalten bleiben.

### Berichte, Abschlüsse und Kundenanzeigen {#other-templates}

<Accordion>

### Dokumentvorlagen von Drittanbietern {#third-party-document-templates}

Wenn **PDF Invoices & Packing Slips for WooCommerce** von WP Overnight aktiv ist, werden dessen Rechnung und Lieferschein zu Ihren Belegvorlagen hinzugefügt. Zum Drucken benötigen sie eine Verbindung.

<Accordion>
  <AccordionItem question="So funktionieren die Vorlagen von WP Overnight">

WCPOS fügt **Rechnung (WP Overnight)** und **Lieferschein (WP Overnight)** als aktive Belegvorlagen hinzu. Sie übergeben die Bestellung an die Dokument-API von WP Overnight. Dadurch bleiben Rechnungs- und Lieferscheinnummerierung, Layout, Markenauftritt, rechtliche und steuerliche Felder sowie Vorlagenanpassungen erhalten, die in diesem Plugin eingerichtet wurden.

Sie stehen nur zur Verfügung, solange das Plugin von WP Overnight aktiv ist, und werden auf dem Server gerendert. Verwenden Sie eine mitgelieferte HTML- oder Thermovorlage, wenn Sie offline drucken müssen. Siehe [Vorlagen von WP Overnight](./customise.mdx#wp-overnight-invoice-and-packing-slip-templates).

  </AccordionItem>
</Accordion>

### Anpassung der Steueranzeige {#adaptive-tax-display}

Die meisten mitgelieferten Vorlagen drucken Preise mit oder ohne Steuer entsprechend Ihrer WooCommerce-Einstellung zur Steueranzeige.

<Accordion>
  <AccordionItem question="Welche Vorlagen der Einstellung folgen und wie">

Standardbeleg, Standardbeleg RTL, Minimal/Modern, Schmaler Beleg, Rechnung, Angebot und die Vorlagen für einfache Thermobelege **folgen Ihrer WooCommerce-Einstellung zur Steueranzeige**:

- **Filialen, die Preise mit Steuer anzeigen** (EU/UK/AU), drucken Bruttopreise mit einer Zeile „Steuer enthalten“.
- **Filialen, die Preise ohne Steuer anzeigen** (US/CA), drucken Nettopreise und fügen die Steuer als separate Zeile mit der Bezeichnung **Steuer gesamt** hinzu.
- Der Gesamtbetrag zeigt immer den tatsächlich berechneten Bruttobetrag.

Die **detaillierten** Vorlagen sind formelle Rechnungen mit Steuerausweis: Ihre Positionen werden immer ohne Steuer angegeben, gefolgt von einer Aufschlüsselung nach Steuersatz. Nur die Steuerüberschrift richtet sich nach Ihrer Einstellung.

  </AccordionItem>
</Accordion>

## Vorlagen-Engines {#template-engines}

Jede Vorlage verwendet eine von drei Engines: **HTML (Offline)**, **XML (Belegdrucker)** oder **PHP (Legacy)**. HTML und XML ermöglichen das Drucken offline; PHP benötigt den Server.

<Accordion>
  <AccordionItem question="Die drei Engines">

Sie wählen die Engine beim Erstellen einer Vorlage aus. Wenn Sie auf **Vorlage verwenden** klicken, ist sie durch die Galerievorlage festgelegt. Sie **kann nach dem Speichern der Vorlage nicht mehr geändert werden**: Erstellen Sie für einen Wechsel eine neue Vorlage.

<FeatureGrid>
  <FeatureCard icon="code" title="HTML (Offline), empfohlen">
    Logikfreies HTML mit <code>{"{{variable}}"}</code> -Platzhaltern. Wird auf dem Gerät gerendert, sodass das Drucken **offline funktioniert**. Für den Druckdialog.
  </FeatureCard>
  <FeatureCard icon="print" title="XML (Belegdrucker)">
    XML, das sowohl eine Bildschirmvorschau als auch **ESC/POS-Befehle** für Thermobelegdrucker erzeugt. Eine Vorlage, zwei Ausgaben. Für Thermodrucker von Epson, Star und anderen Herstellern.
  </FeatureCard>
  <FeatureCard icon="terminal" title="PHP (Legacy)">
    Serverseitiges PHP mit WooCommerce-Funktionen. Weiterhin verfügbar für bestehende Anpassungen in <code>yourtheme/woocommerce-pos/receipt.php</code> und die integrierte **Legacy-PHP-Vorlage**. Zum Rendern ist eine Verbindung zum Server erforderlich; nur für Belege verfügbar.
  </FeatureCard>
</FeatureGrid>

  </AccordionItem>
</Accordion>
