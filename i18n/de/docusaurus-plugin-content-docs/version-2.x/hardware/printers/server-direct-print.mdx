Der Epson ist eingeschaltet, seine eigene Webseite lässt sich öffnen und sein Selbsttest wird gedruckt, aber vom POS wird nichts ausgegeben. Aus- und Einschalten ändert nichts. Prüfen Sie, ob die Druckereinstellung **Server Direct Print** aktiviert ist.

:::note Prüfen Sie zuerst, ob WCPOS die Funktion nutzt
Steht in der Zeile dieses Druckers unter **Einstellungen → Drucken** **Epson Server Direct Print · verwaltet von WCPOS**? Dann lassen Sie Server Direct Print aktiviert: WCPOS sendet Belege über **Cloud-Druck** auf diesem Weg an den Drucker. Fügen Sie denselben Drucker nicht erneut über **Drucker hinzufügen** hinzu. Siehe [Cloud-Druck](../../receipts/cloud-printing.mdx#setup-polling).
:::

Wenn Sie diesen Drucker zum ersten Mal hinzufügen oder dieser Hinweis nicht in seiner Zeile steht, [prüfen Sie die Einstellung auf der Webseite des Druckers](#turn-it-off).

## Was im POS angezeigt wird {#what-you-see}

Wenn Sie den Drucker unter **Einstellungen → Drucken → Drucker hinzufügen** hinzufügen, steht auf seiner Karte **Keine Verbindung**, und Sie können ihn nicht auswählen.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[302, 0], [0, 0], [136, -20], [161, 0]]} maxWidth={559} alt="Der Bereich Drucker hinzufügen nach der Prüfung einer Adresse: oben rechts Erneut suchen, darunter die Druckerkarte mit Adresse und Epson sowie dem Hinweis Keine Verbindung, darunter IP-Adresse eingeben und Druckeranleitung öffnen">

1. **Die Druckerkarte** — Adresse und Hersteller des Druckers. **Keine Verbindung** bedeutet, dass die App keinen Weg zum Drucken gefunden hat. Deshalb lässt sich die Karte nicht auswählen.
2. **Erneut suchen** — durchsucht das Netzwerk erneut. Verwenden Sie diese Funktion, nachdem Sie Server Direct Print deaktiviert haben.
3. **IP-Adresse eingeben** — prüft eine einzelne Adresse direkt. Siehe [Adresse selbst eingeben](./setup-wizard.mdx#enter-address).
4. **Druckeranleitung öffnen** — öffnet diese Hilfeseiten zu Druckern.

</JourneyShot>

Möglicherweise sehen Sie auch Folgendes:

- **Nichts gedruckt** nach einer Testseite, mit dem Hinweis „Der Drucker hält Aufträge zurück. Schalten Sie ihn aus und wieder ein und versuchen Sie es erneut.“ Wenn die Meldung nach einem Neustart weiterhin erscheint, prüfen Sie, ob Server Direct Print aktiviert ist. Ist es deaktiviert, siehe [Epson Sicheres Drucken](./secure-printing.mdx), eine weitere Epson-Einstellung, die das Drucken von Aufträgen aus dem POS verhindert.
- **Testdruck** schlägt bei einem bereits gespeicherten Drucker fehl, ebenso wie jeder Belegdruck.

## Warum das passiert {#why-it-happens}

Mit aktiviertem **Server Direct Print** ruft der Drucker seine Aufträge von einem Server ab. Solange die Funktion aktiviert ist, weist er Aufträge ab, die über Ihr Netzwerk direkt an ihn gesendet werden. Genau so druckt der POS auf einem Netzwerkdrucker, den Sie über **Drucker hinzufügen** hinzugefügt haben. Die Webseite des Druckers funktioniert weiterhin, sodass der Drucker betriebsbereit wirkt. Die Einstellung ist gespeichert und bleibt daher auch nach einem Neustart bestehen.

Wenn Sie die Funktion nicht selbst aktiviert haben, stammt die Einstellung von einer früheren Einrichtung, einem Küchen- oder Online-Bestelldienst oder einer anderen Kasse.

## Deaktivieren {#turn-it-off}

:::warning Ein anderes System benötigt die Funktion möglicherweise
Wenn ein Küchendisplay oder ein Online-Bestelldienst über Server Direct Print auf diesem Epson druckt, kann dieser Dienst nach dem Deaktivieren nicht mehr drucken. Nur eines der beiden Systeme kann den Drucker nutzen: Geben Sie dem POS einen eigenen Drucker oder stellen Sie den anderen Dienst auf einen anderen Drucker um.
:::

Sie ändern die Einstellung auf der eigenen Webseite des Druckers, von einem Computer oder Tablet im selben Netzwerk wie der Drucker aus.

1. Öffnen Sie `https://` gefolgt von der Adresse des Druckers, zum Beispiel `https://192.168.1.100`, und akzeptieren Sie die Zertifikatswarnung. Die Adresse steht auf dem Statusblatt des Druckers. Siehe [Druckeradresse ermitteln](./network-address.mdx).
2. Drücken Sie auf **Administratoranmeldung**. Bei neueren Modellen ist das Passwort die **Seriennummer** des Druckers auf dem Aufkleber an der Unterseite, sofern es nicht geändert wurde.
3. Suchen Sie im Menü nach **Server Direct Print**. Die Position hängt vom Modell und der Firmware ab: Bei TM-i-Modellen finden Sie es unter **Webdienst-Einstellungen → Direktdruck** oder bei Firmware 3.x und älter unter **Konfiguration → Direktdruck**. Suchen Sie bei anderen Modellen im Menü oder im Handbuch Ihres Modells danach.
4. Wenn bereits **Deaktivieren** ausgewählt ist, lassen Sie die Funktion ausgeschaltet und folgen Sie stattdessen [Epson Sicheres Drucken](./secure-printing.mdx). Andernfalls wählen Sie **Deaktivieren**, speichern die Einstellung und fahren unten fort.
5. Lassen Sie den Drucker neu starten oder schalten Sie ihn für zehn Sekunden aus und dann wieder ein.
6. Testen Sie den Drucker anschließend im POS:
   - **Beim Hinzufügen eines Druckers:** Drücken Sie auf **Erneut suchen** oder **IP-Adresse eingeben**. Wenn auf der Karte **Bereit** steht, wählen Sie sie aus und drücken Sie auf **Testseite drucken**.
   - **Drucker bereits gespeichert:** Drücken Sie in dessen Zeile unter **Einstellungen → Drucken** auf **Testdruck**.

## Sie kommen nicht weiter? {#still-stuck}

Drücken Sie auf **Einrichtungsbericht kopieren** und fügen Sie ihn in Ihre Nachricht ein. Auf der Ansicht **Nichts gedruckt** listet der Bericht die Ports auf, die die App am Drucker ausprobiert hat, sowie alle erhaltenen Ablehnungen. Bei einem gespeicherten Drucker finden Sie ihn im Menü **Weitere Aktionen** in dessen Zeile unter **Einstellungen → Drucken**.
