Um einen USB-Belegdrucker mit der Desktop-App unter Windows zu verwenden, installieren Sie ihn zuerst in Windows: Die App findet einen USB-Drucker erst, wenn er in Windows eingerichtet ist. Fügen Sie ihn anschließend im POS hinzu:

1. [Den Drucker in Windows installieren](#do-this).
2. [Im POS hinzufügen](#add-in-pos).

Diese Seite hilft Ihnen auch, wenn in der Desktop-App unter Windows Folgendes auftritt:

- Unter **Drucker hinzufügen** steht **Kein Drucker gefunden**, obwohl der Drucker angeschlossen und eingeschaltet ist. Siehe [Kein Drucker gefunden](#no-printer-found).
- Bei einem Drucker, den Sie in einer früheren Version hinzugefügt haben, steht **Fügen Sie diesen Drucker unter Windows stattdessen als installierten Drucker hinzu.** Siehe [Ein Drucker aus einer früheren Version](#earlier-version).
- Die Testseite besteht aus [wirren Buchstaben und Symbolen](#stray-symbols), oder [es kam nichts heraus](#nothing-came-out).

## Den Drucker in Windows installieren {#do-this}

Prüfen Sie zuerst, ob der Drucker bereits in Windows eingerichtet ist:

1. Schließen Sie den Drucker an und schalten Sie ihn ein. Falls der Hersteller einen Windows-Treiber oder ein Installationsprogramm bereitstellt, führen Sie es jetzt aus.
2. Öffnen Sie in Windows **Einstellungen → Bluetooth und Geräte → Drucker und Scanner**.
3. Wenn Ihr Drucker in der Liste steht, fahren Sie mit [Im POS hinzufügen](#add-in-pos) fort. Andernfalls wählen Sie neben **Drucker oder Scanner hinzufügen** die Option **Gerät hinzufügen**. Wenn Windows den Drucker findet und hinzufügt, fahren Sie ebenfalls mit [Im POS hinzufügen](#add-in-pos) fort.

Wenn Windows den Drucker weiterhin nicht auflistet, fügen Sie ihn manuell mit **Generic / Text Only** hinzu, dem einfachen, in Windows enthaltenen Treiber.

<details>
<summary>Den Drucker manuell hinzufügen</summary>

1. Wählen Sie **Manuell hinzufügen** und anschließend **Lokalen Drucker oder Netzwerkdrucker mit manuellen Einstellungen hinzufügen**.
2. Wählen Sie unter **Vorhandenen Anschluss verwenden** den USB-Anschluss des Druckers aus: Sein Name beginnt mit **USB**, zum Beispiel USB001.
3. Wählen Sie für den Treiber den Hersteller **Generic** und den Drucker **Generic / Text Only** aus.
4. Geben Sie ihm einen Namen, den Sie an der Kasse wiedererkennen, etwa *Belegdrucker*, und schließen Sie die Einrichtung ab.

</details>

<details>
<summary>Unter Windows 10</summary>

Öffnen Sie **Einstellungen → Geräte → Drucker und Scanner** und wählen Sie **Drucker oder Scanner hinzufügen**. Was unter Windows 11 **Manuell hinzufügen** heißt, wird unter Windows 10 als **Der gewünschte Drucker ist nicht aufgelistet** angezeigt.

</details>

## Im POS hinzufügen {#add-in-pos}

1. Gehen Sie in der Desktop-App zu **Einstellungen → Drucken** und drücken Sie **Drucker hinzufügen**. Die Suche startet automatisch und sucht nach Druckern mit **USB, Bluetooth und WLAN**.
2. Wählen Sie die Karte mit dem Namen, den Sie dem Drucker in Windows gegeben haben. Sie trägt die Kennzeichnung **Installierter Drucker**. Bei mehreren Druckern fragt der Dialog **Welcher Drucker gehört Ihnen?** und wählt keinen automatisch aus.
3. Drücken Sie **Testseite drucken**. Im Dialog erscheint die Frage **Wurde die Testseite gedruckt?**
4. Wenn die Seite richtig aussieht, antworten Sie mit **Ja, und sie sieht richtig aus**. Der Drucker wird gespeichert: Im Dialog steht *Name* **ist eingerichtet**. Drücken Sie **Fertig**. Der Drucker erhält eine eigene Zeile unter **Einstellungen → Drucken**.

Wenn die Seite falsch oder gar nicht gedruckt wurde, lesen Sie [Wenn etwas schiefgeht](#goes-wrong). Die anderen Antworten finden Sie unter [Testseite drucken](./setup-wizard.mdx#test-page).

## Wenn etwas schiefgeht {#goes-wrong}

### Kein Drucker gefunden {#no-printer-found}

Prüfen Sie zuerst **Drucker und Scanner** in Windows. Wenn Ihr Drucker nicht aufgeführt ist, [installieren Sie ihn in Windows](#do-this) und drücken Sie dann **Erneut suchen**. Wenn er aufgeführt ist und die App trotzdem nichts findet, lesen Sie [Sie kommen nicht weiter?](#still-stuck).

<details>
<summary>Die anderen Schaltflächen im Dialog Kein Drucker gefunden</summary>

1. **Erneut suchen** — führt die Suche erneut aus. Drücken Sie darauf, nachdem Sie den Drucker in Windows installiert haben.
2. **Bluetooth-Drucker suchen** — für einen Bluetooth-Drucker, der keine Kopplung benötigt.
3. **IP-Adresse eingeben** — für einen Netzwerkdrucker, den die Suche nicht gefunden hat.
4. **Weitere Optionen** — Name, Papierbreite und Kassenlade vor dem Druck der Testseite. Siehe [Weitere Optionen](./setup-wizard.mdx#more-options).
5. **Druckeranleitung öffnen** — öffnet die [Druckeranleitung](./index.mdx).

</details>

### Ein Drucker aus einer früheren Version {#earlier-version}

Beim Drucken erscheint **Fügen Sie diesen Drucker unter Windows stattdessen als installierten Drucker hinzu.** Eine frühere Version hat ihn als direkten USB-Drucker gespeichert. Unter Windows erreicht die App einen USB-Drucker jetzt nur noch über seinen Eintrag in Windows. Öffnen Sie unter **Einstellungen → Drucken** das Menü **Weitere Aktionen** des Druckers, wählen Sie **Löschen** und fügen Sie ihn anschließend über **Drucker hinzufügen** erneut hinzu. Wählen Sie dabei seine Karte mit der Kennzeichnung **Installierter Drucker**.

### Wirre Buchstaben und Symbole {#stray-symbols}

#### Beim Hinzufügen eines Druckers {#symbols-during-setup}

1. Antworten Sie mit **Es kam nichts heraus**, obwohl Papier bedruckt wurde. Der Dialog bietet keine Antwort für Symbole an; mit dieser Antwort werden **Neu beginnen** und **Ohne Test speichern** verfügbar.
2. Prüfen Sie den Namen auf der ausgewählten Karte:
   - Ist es ein anderer Drucker, etwa ein Bürodrucker? Er kann keine Belegdruckbefehle verarbeiten. Drücken Sie **Neu beginnen** und wählen Sie den Eintrag Ihres Belegdruckers.
   - Ist es Ihr Belegdrucker? Drücken Sie **Ohne Test speichern** und [korrigieren Sie anschließend seine Druckersprache](#symbols-saved).

#### Bei einem bereits gespeicherten Drucker {#symbols-saved}

1. Prüfen Sie den Namen in seiner Zeile unter **Einstellungen → Drucken**. Wenn es ein anderer Drucker ist, drücken Sie **Drucker hinzufügen** und wählen Sie den Eintrag Ihres Belegdruckers.
2. Wenn es Ihr Belegdrucker ist, passt die Einstellung **Druckersprache** möglicherweise nicht zum Drucker. Drücken Sie in seiner Zeile auf **Bearbeiten**.
3. Stellen Sie **Druckersprache** auf die im Druckerhandbuch genannte Sprache ein. Star-Drucker verwenden **StarPRNT** oder **Star Line Mode**; Epson-Drucker verwenden **ESC/POS**, ebenso wie die meisten anderen Fabrikate.
4. Drücken Sie in der Zeile auf **Testdruck**. Wenn ein Star-Drucker weiterhin Symbole druckt, stellen Sie die andere Star-Sprache ein und testen Sie erneut.
5. Bei jeder Sprache erscheinen Symbole? Prüfen Sie Ihr Modell unter [Unterstützte Belegdrucker](./supported-printers.mdx) und lesen Sie anschließend [Sie kommen nicht weiter?](#still-stuck).

### Es kam nichts heraus {#nothing-came-out}

#### Beim Hinzufügen eines Druckers {#nothing-during-setup}

1. Antworten Sie mit **Es kam nichts heraus**.
2. Prüfen Sie den Namen auf der ausgewählten Karte. Wenn es ein anderer Drucker ist, drücken Sie **Neu beginnen** und wählen Sie den Eintrag Ihres Belegdruckers.
3. Wenn es Ihr Drucker ist, zeigt der Dialog **Prüfen Sie das Kabel und ob der Drucker eingeschaltet ist, und versuchen Sie es dann erneut.** Führen Sie diese Prüfung durch und drücken Sie anschließend **Erneut versuchen**.

#### Bei einem bereits gespeicherten Drucker {#nothing-saved}

1. Prüfen Sie den Namen in seiner Zeile unter **Einstellungen → Drucken**. Wenn es ein anderer Drucker ist, drücken Sie **Drucker hinzufügen** und wählen Sie den Eintrag Ihres Belegdruckers.
2. Wenn es Ihr Drucker ist, prüfen Sie das Kabel und ob der Drucker eingeschaltet ist. Drücken Sie dann in seiner Zeile auf **Testdruck**.

#### Weiterhin kein Ausdruck {#windows-test-page}

Drucken Sie direkt aus Windows eine Testseite über den Eintrag Ihres Druckers unter **Drucker und Scanner**. Wenn auch Windows nicht drucken kann, liegt der Fehler zwischen Windows und dem Drucker: am Kabel, am Anschluss oder am Treiber. Wenn Windows druckt, der POS aber weiterhin nicht, lesen Sie [Sie kommen nicht weiter?](#still-stuck).

### USB-Drucker suchen schlägt in der Web-App fehl {#web-app}

In der Web-App kann **USB-Drucker suchen** unter Windows häufig nicht auf einen USB-Drucker zugreifen. Verwenden Sie stattdessen die Desktop-App: [Installieren Sie den Drucker in Windows](#do-this) und [fügen Sie ihn anschließend im POS hinzu](#add-in-pos).

## Wie die App unter Windows druckt {#why-it-happens}

Die Desktop-App druckt auf dem Drucker, den Sie in Windows installiert haben. Wählen Sie daher diesen Drucker aus. Ob Ihr Modell Belegdruckbefehle verarbeiten kann, erfahren Sie unter [Unterstützte Belegdrucker](./supported-printers.mdx).

<details>
<summary>Warum der Drucker in Windows installiert sein muss</summary>

Windows weist einem USB-Drucker seinen eigenen Treiber oder den des Herstellers zu. Die Desktop-App druckt über den Druckereintrag in Windows, statt direkt auf das Kabel zuzugreifen. Sie sendet jeden Beleg als Druckerbefehle, die Windows unverändert an den Drucker weiterleitet. Der Treiber verändert daher das Beleglayout nicht.

</details>

<details>
<summary>Welche Windows-Drucker die Suche auflistet</summary>

Alle in Windows installierten Drucker, ausgenommen Windows-eigene Einträge wie **Microsoft Print to PDF** und **Fax**. Auch ein in Windows installierter Bürodrucker wird wie jeder andere Drucker aufgelistet. Wählen Sie daher anhand des Namens aus. Ein in Windows gekoppelter Bluetooth-Drucker erscheint auf dieselbe Weise als installierter Drucker.

</details>

## Sie kommen nicht weiter? {#still-stuck}

Drücken Sie im Dialog **Nichts gedruckt** auf **Einrichtungsbericht kopieren** oder wählen Sie diesen Eintrag im Menü **Weitere Aktionen** des Druckers unter **Einstellungen → Drucken**. Fügen Sie den Bericht in Ihre Nachricht ein: Er nennt den Windows-Eintrag, an den die App den Druckauftrag gesendet hat.
