Eine Kundenanzeige ist ein zweiter, zum Kunden gerichteter Bildschirm, etwa ein Tablet oder ein Monitor mit Webbrowser. Sie zeigt den Warenkorb beim Kassieren Position für Position samt Gesamtbetrag an.

:::info Pro-Funktion
Für Kundenanzeigen benötigen Sie WCPOS Pro. Ohne Pro erscheint unter **Einstellungen → Kundenanzeige** ein entsprechender Hinweis: siehe [Kostenlos vs. Pro](../../getting-started/free-vs-pro.mdx#customer-display).
:::

Jede Anzeige ist mit einer Kasse gekoppelt, die ihr den Warenkorb direkt sendet. Verbinden Sie Kasse und Anzeige mit demselben WLAN: Gastnetzwerke blockieren häufig die Verbindung zwischen den Geräten.

## Eine Anzeige koppeln {#pair}

Kasse und Anzeigegerät müssen nebeneinander stehen. Ein Kopplungscode kann einmal verwendet werden und läuft nach 10 Minuten ab.

1. Tippen Sie **an der Kasse** unten im Seitenmenü auf **Einstellungen** und dann auf **Kundenanzeige**.
2. **Tippen Sie auf Kopplungscode generieren.** Ein sechsstelliger Code erscheint zusammen mit seiner Ablaufzeit.
3. **Notieren Sie an der Kasse die Adresse.** **URL der Anzeigeseite** unter der Schaltfläche ist die Adresse Ihrer Website mit angehängtem `wcpos-display/`. Bei einer Kasse im Webbrowser können Sie sie mit **URL kopieren** kopieren und an das Anzeigegerät senden.
4. **Öffnen Sie diese Adresse auf dem Anzeigegerät.** Auf der Seite steht **Diese Anzeige koppeln**.
5. **Geben Sie den Code ein.** Tragen Sie ihn unter **Kopplungscode** ein, ändern Sie bei Bedarf **Anzeigename** (vorbelegt mit *Kundenanzeige*) und tippen Sie auf **Anzeige koppeln**.
6. **Prüfen Sie die Kasse.** Die Anzeige erscheint unter **Gekoppelte Anzeigen** mit dem Status **Verbunden**. Fügen Sie dem Warenkorb ein Produkt hinzu: Es erscheint auf der Anzeige. Falls dort stattdessen eine Meldung erscheint, siehe [Wenn etwas schiefgeht](#troubleshoot).

Bei einer Kasse im Webbrowser öffnet **Im Browser öffnen** neben **URL kopieren** die Anzeigeseite in einem neuen Tab auf der Kasse selbst, nicht auf dem Anzeigegerät.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[178, 0], [-44, 0], [0, 0], [-44, 0], [130, -20]]} alt="Einstellungen, Kundenanzeige an der Kasse: ein sechsstelliger Kopplungscode, der in 10 Minuten abläuft, die Schaltfläche Kopplungscode generieren, die URL der Anzeigeseite mit URL kopieren und Im Browser öffnen sowie eine leere Liste Gekoppelte Anzeigen">

1. **Kundenanzeige** — unter **Einstellungen**, nach Kartenlesegeräte.
2. **Der Kopplungscode** — geben Sie ihn auf der Anzeige ein. Ein Code koppelt eine Anzeige.
3. **Kopplungscode generieren** — erstellt einen neuen Code. Tippen Sie erneut darauf, wenn der Code vor der Verwendung abläuft.
4. **URL der Anzeigeseite** — die Adresse, die Sie auf der Anzeige öffnen. Bei einer Kasse im Webbrowser stehen **URL kopieren** und **Im Browser öffnen** zur Verfügung.
5. **Gekoppelte Anzeigen** — zeigt *Mit diesem Gerät sind keine Anzeigen gekoppelt.*, bis auf einer Anzeige ein Code eingegeben wird.

</JourneyShot>

Verwenden Sie auf dem Anzeigegerät den Vollbildmodus des Browsers, um den Bildschirm auszufüllen. Der Browser speichert die Kopplung: Öffnen Sie dieselbe Adresse im selben Browser erneut, verbindet sich die Anzeige ohne neuen Code wieder.

## Gekoppelte Anzeigen {#paired-displays}

Unter **Gekoppelte Anzeigen** werden die mit dieser Kasse gekoppelten Anzeigen aufgelistet. Jede Zeile zeigt den Namen der Anzeige, wann die Kasse sie zuletzt gesehen hat, und den Status **Verbunden** oder **Getrennt**.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[215, 0], [-22, 0]]} maxWidth={720} alt="Einstellungen, Kundenanzeige mit einer Anzeige unter Gekoppelte Anzeigen: Thekenanzeige, zuletzt vor weniger als einer Minute gesehen, Verbunden und die zugehörige Menüschaltfläche">

1. **Verbunden** — die Anzeige mit dem Namen *Thekenanzeige* ist derzeit mit dieser Kasse verbunden. **Getrennt** bedeutet, dass die Anzeigeseite geschlossen ist oder die Kasse nicht erreichen kann.
2. **⋮** — das Menü der Zeile mit **Vergessen**.

</JourneyShot>

Eine Anzeige zeigt die Verkäufe einer Kasse. Damit jede Verkaufstheke einen eigenen Bildschirm hat, koppeln Sie an jeder Kasse eine Anzeige.

## Was der Kunde sieht {#what-the-customer-sees}

Was die Anzeige zeigt, bestimmt ihre Vorlage. **Ledger**, die Standardvorlage für Anzeigen, listet auf einem breiten Bildschirm die Artikel mit einer Summenübersicht daneben auf. Auf einem schmalen Bildschirm steht der Gesamtbetrag fest am unteren Rand. Mit Ledger:

- **Zwischen Verkäufen**: das Logo der Filiale oder, falls keines vorhanden ist, ihr Name sowie eine Begrüßungszeile.
- **Während eines Verkaufs**: jede Position mit Menge, Name und Positionssumme unter **Ihre Artikel** sowie eine Übersicht mit **Zwischensumme**, etwaigen Gebühren, Versandkosten, Rabatten und Steuern, gefolgt von **Gesamt**. Spart der Kunde bei diesem Verkauf Geld, wird **Sie haben gespart** ergänzt. Ist der Bestellung ein Kunde zugeordnet, wird er mit seinem Vornamen begrüßt.

Die Anzeige begleitet den Verkauf bis zur Zahlung.

Verwendet wird das eigene Logo der Filiale von ihrer Seite **Details**, das auch auf Belegen gedruckt wird. Nutzt eine Filiale das Website-Logo, erscheint das Logo Ihrer WordPress-Website. Siehe [Filiale einrichten](../../stores/setup.mdx#store-pages).

## Die Vorlage auswählen {#template}

Jede Anzeige verwendet die als **Live** markierte Anzeigevorlage der Website, sofern ihre Filiale keine eigene auswählt. Eine Änderung wird innerhalb von etwa einer Minute übernommen, ohne erneute Kopplung.

<details>
<summary>Die Vorlage für alle Filialen ändern</summary>

1. Gehen Sie in WP Admin zu **POS → Vorlagen** und öffnen Sie den Tab **Anzeige** neben den Belegvorlagen.
2. Schalten Sie für die gewünschte Vorlage **Aktiviert** ein.
3. Wählen Sie sie in der Spalte **Live** aus.

Die Galerie selbst wird unter [Berichte, Abschlüsse und Kundenanzeigen](../../receipts/index.mdx#other-templates) beschrieben.

</details>

<details>
<summary>Die Vorlage für eine Filiale ändern</summary>

1. Gehen Sie in WP Admin zu **POS → Filialen**, klicken Sie auf die Filiale und dann in deren Menü auf **Kundenanzeige**.
2. Klicken Sie unter **Anzeigevorlage**, wo **Wie Website** steht, auf **Anpassen**.
3. Wählen Sie eine Vorlage. Die Liste enthält die im Tab **Anzeige** aktivierten Vorlagen. Änderungen werden auf der Seite automatisch gespeichert.

Mit **Website-Vorlage verwenden** nutzt die Filiale wieder die als **Live** markierte Vorlage der Website.

</details>

## Eine Anzeige vergessen {#forget}

Um die Kopplung einer Anzeige aufzuheben, öffnen Sie **⋮** in ihrer Zeile unter **Gekoppelte Anzeigen**, wählen Sie **Vergessen** und bestätigen Sie erneut mit **Vergessen**. Die Anzeigeseite meldet dann: *Diese Anzeige wurde entfernt. Koppeln Sie sie erneut.* Um diesen Bildschirm wieder zu verwenden, [koppeln Sie ihn](#pair) mit einem neuen Code.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-26, 0]]} maxWidth={600} alt="Das geöffnete Menü einer gekoppelten Anzeige mit Vergessen">

1. **Vergessen** — entfernt die Anzeige von dieser Kasse. Sie benötigt einen neuen Kopplungscode, bevor sie diese Kasse wieder anzeigen kann.

</JourneyShot>

## Wenn etwas schiefgeht {#troubleshoot}

### Kopplung {#troubleshoot-pairing}

<details>
<summary>Dieser Kopplungscode ist ungültig oder abgelaufen.</summary>

Codes sind 10 Minuten gültig und können einmal verwendet werden. Tippen Sie an der Kasse auf **Kopplungscode generieren** und geben Sie den neuen Code ein. Nach mehreren falschen Codes zeigt die Seite *Zu viele Versuche. Versuchen Sie es in Kürze erneut.*: Warten Sie einen Moment, bevor Sie es erneut versuchen.

</details>

<details>
<summary>Die Schaltfläche Kopplungscode generieren ist ausgegraut.</summary>

Die Seite zeigt *Der Kundenanzeigedienst läuft auf diesem Gerät nicht.* Laden Sie den POS neu. Bleibt die Schaltfläche ausgegraut, prüfen Sie unter **Protokolle** den Grund.

</details>

<details>
<summary>Kundenanzeigen benötigen eine neuere Version von WCPOS Pro.</summary>

Das Pro-Plugin auf Ihrer Website ist älter als die Funktion für Kundenanzeigen. Aktualisieren Sie WCPOS Pro in WordPress und laden Sie anschließend den POS neu.

</details>

<details>
<summary>Diese Anzeige wurde entfernt. Koppeln Sie sie erneut.</summary>

Jemand hat an der Kasse für diese Anzeige **Vergessen** gewählt. [Koppeln Sie sie](#pair) mit einem neuen Code.

</details>

### Verbindung {#troubleshoot-connection}

Wenn eine Anzeige 30 Sekunden lang keine Verbindung herstellen kann, zeigt sie den Grund auf ihrem Bildschirm an und versucht es weiter.

<details>
<summary>Diese Anzeige kann den POS in diesem Netzwerk nicht erreichen.</summary>

Die Anzeige hat Ihren Shop erreicht, aber nicht die Kasse. Verbinden Sie beide Geräte mit demselben WLAN. Gastnetzwerke trennen Geräte häufig voneinander; verwenden Sie daher das Hauptnetzwerk Ihres Geschäfts.

</details>

<details>
<summary>Diese Anzeige kann Ihren Shop nicht erreichen.</summary>

Das Anzeigegerät hat keine Internetverbindung oder kann Ihre Website nicht erreichen. Prüfen Sie die WLAN-Verbindung und laden Sie dann die Anzeigeseite neu.

</details>

<details>
<summary>Warten auf den POS.</summary>

Die Kasse, mit der diese Anzeige gekoppelt ist, läuft nicht. Öffnen Sie den POS auf dieser Kasse.

</details>

<details>
<summary>Der POS hat geantwortet, aber die Einrichtung dieser Anzeige nicht abgeschlossen.</summary>

Starten Sie den POS auf der Kasse neu und versuchen Sie es erneut.

</details>

### Was die Anzeige zeigt {#troubleshoot-content}

<details>
<summary>Es ist keine Vorlage für die Kundenanzeige konfiguriert.</summary>

Es ist keine Anzeigevorlage aktiviert. Aktivieren Sie eine im Tab **Anzeige** unter **POS → Vorlagen**.

</details>

<details>
<summary>Die Anzeige zeigt während eines Verkaufs den Begrüßungsbildschirm.</summary>

Die Darstellung des Warenkorbs konnte nicht erstellt werden. Dies wird als [DISPLAY101](../../error-codes/DISPLAY101.mdx) protokolliert. Setzen Sie den Verkauf fort: Bei der nächsten Änderung des Warenkorbs aktualisiert sich die Anzeige.

</details>
