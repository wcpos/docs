:::info Pro-Funktion
Mollie Terminal benötigt [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0 oder neuer.
:::

Mollie Terminal sendet den Verkauf von der Kasse an ein [Mollie](https://www.mollie.com/products/point-of-sale)-Kartenterminal. Der Kunde bezahlt am Terminal, und der Verkauf wird an der Kasse automatisch abgeschlossen. Es akzeptiert ausschließlich **Euro** und funktioniert nur im POS: Im Checkout Ihres Onlineshops wird es nie angeboten.

## Eine Zahlung annehmen {#take-payment}

Die Filialleitung [richtet es einmalig ein](#setup), wobei das Terminal zum Live-Mollie-Konto Ihres Shops gehört. [Öffnen Sie die Kasse](../../pos/register/index.mdx#open), bevor Sie beginnen.

:::warning
Wenn **Kasse öffnen und schließen** aktiviert ist, kann bei geschlossener Kasse keine Zahlung erfasst werden. Eine bereits eingezogene Kartenzahlung müsste dann zurückerstattet werden.
:::

1. Drücken Sie **Kasse** und tippen Sie dann im Zahlungsbereich auf die Kachel **Mollie Terminal**.
2. Prüfen Sie das Terminal im Zahlungsbereich: **Terminal:** und dessen Name. Um ein anderes zu verwenden, tippen Sie auf **Ändern** und wählen Sie es aus. **Ändern** wird nicht angezeigt, wenn für den Shop nur ein Terminal aktiviert ist oder die Auswahl gesperrt wurde.
3. Drücken Sie **… an Mollie Terminal senden**. Der Betrag wird an das Terminal gesendet.
4. Der Kunde hält seine Karte an das Terminal, steckt sie ein oder zieht sie durch. Die Kasse zeigt **Am Terminal** mit den Schritten **Gesendet**, **Am Terminal**, **Genehmigt** und **Eingezogen** an.
5. Sobald Mollie die Zahlung bestätigt, ist der Verkauf bezahlt und der Beleg bereit, wie bei jedem [Checkout](../../pos/checkout/index.mdx#paid).

Jede Kasse merkt sich das zuletzt verwendete Terminal. Siehe [Am Kartenlesegerät](../../pos/checkout/taking-a-payment.mdx#card-reader).

Trinkgeld, das der Kunde am Terminal hinzufügt, wird in der Bestellung als Position **Trinkgeld** erfasst. Siehe [Trinkgeld](../../pos/checkout/tips.mdx).

### Eine Zahlung am Terminal abbrechen {#cancel}

Während die Kasse wartet, drücken Sie **Am Terminal abbrechen**. Die Kasse zeigt **Abbruch läuft — Warten auf die Bestätigung des Terminals** an.

#### Zahlung abgebrochen oder abgelehnt {#cancelled}

Nach **Zahlung abgebrochen**, einer Ablehnung oder **Zeitüberschreitung — Zahlung abgebrochen** wurde die Zahlung nicht ausgeführt. Drücken Sie **Erneut versuchen**, um die Zahlung erneut zu senden, oder **Andere Zahlungsart wählen**, um mit einer anderen Methode zu bezahlen.

#### Das Terminal hat nicht bestätigt {#not-confirmed}

Sobald der Kunde mit dem Bezahlen begonnen hat, lässt Mollie möglicherweise keinen Abbruch von der Kasse aus mehr zu. Brechen Sie die Zahlung direkt am Terminal ab.

Wenn die Kasse weiterhin keine Antwort erhält, bietet sie **Diese Zahlung freigeben** an.

:::warning Bevor Sie erneut kassieren
Prüfen Sie das Terminal. Wenn es die Zahlung als genehmigt anzeigt, **kassieren Sie nicht erneut**: Der Shop prüft den Status noch bei Mollie. Wenn Sie sich nicht sicher sind, bitten Sie die Filialleitung, die Zahlung im Mollie-Dashboard zu prüfen, bevor Sie eine weitere Zahlung annehmen.
:::

**Diese Zahlung freigeben** gibt die Bestellung für eine andere Zahlungsart frei, und die Kasse zeigt **Zahlung freigegeben** an. Das bedeutet nicht, dass die Zahlung abgebrochen wurde: Der Shop prüft den Status des Terminals weiter.

### Im Tab Legacy {#legacy-tab}

Sie können die Zahlung auch im [Tab Legacy](../../pos/checkout/legacy-tab.mdx) des Checkouts annehmen, der Zahlungsseite der Bestellung. Öffnen Sie den Tab **Legacy** und wählen Sie **Mollie Terminal**. Welcher Zahlungsbereich angezeigt wird, hängt davon ab, ob die Filialleitung **QR-Code-Zahlungen** aktiviert hat.

**Wenn der Zahlungsbereich Terminal und QR-Code anzeigt**, bleiben Sie bei **Terminal** und drücken Sie **Terminalzahlung starten**. Zum Abbrechen drücken Sie **Terminalzahlung abbrechen**. Wenn Sie stattdessen einen Code anzeigen möchten, siehe [Per QR-Code bezahlen](#qr-code).

**Andernfalls:**

1. Wählen Sie das Terminal aus, wenn der Zahlungsbereich Sie dazu auffordert.
2. Drücken Sie **… senden an**, gefolgt vom Namen des Terminals. Der Zahlungsbereich zeigt dieselben Schritte wie die Kachel an.
3. Zum Abbrechen drücken Sie **Am Terminal abbrechen**, wie unter [Eine Zahlung abbrechen](#cancel) beschrieben. Nach dem Abbruch sendet **Erneut versuchen** die Zahlung erneut. Der POS erfasst diese Zahlung genauso wie bei der Kachel.

## Per QR-Code bezahlen {#qr-code}

In den Niederlanden und Belgien kann der Kunde zum Bezahlen einen iDEAL- oder Bancontact-QR-Code mit seiner Banking-App scannen, statt das Terminal zu verwenden. Die Filialleitung aktiviert die Methoden zuvor unter **QR-Code-Zahlungen** in [den Einstellungen](#settings).

1. Öffnen Sie im Checkout den [Tab Legacy](../../pos/checkout/legacy-tab.mdx) und wählen Sie **Mollie Terminal**.
2. Wechseln Sie im Zahlungsbereich von **Terminal** zu **QR-Code**.
3. Wählen Sie **iDEAL** oder **Bancontact**, wenn beide aktiviert sind, und drücken Sie **QR-Code anzeigen**.
4. Der Kunde scannt den Code und bezahlt auf seinem Smartphone. Der Verkauf wird wie bei einer Terminalzahlung abgeschlossen.

Bancontact akzeptiert höchstens €1,500.00 pro QR-Zahlung. Verwenden Sie für höhere Beträge das Terminal.

## Rückerstattungen {#refunds}

Erstatten Sie einen über Mollie Terminal bezahlten Verkauf im POS und wählen Sie **Über Mollie Terminal zurückerstatten**, oder führen Sie die Rückerstattung in der WooCommerce-Bestellansicht durch. Der Betrag wird vollständig oder teilweise über Mollie zurückgezahlt. Siehe [Rückerstattungen](../../pos/refunds.mdx#destination).

Eine Mollie-Rückerstattung ist zunächst ausstehend. WCPOS Pro prüft sie alle zehn Minuten bei Mollie, markiert sie anschließend als zurückerstattet oder fehlgeschlagen und fügt der Bestellung eine Notiz hinzu.

## Wenn etwas schiefgeht {#goes-wrong}

### Der Kunde hat bereits bezahlt: Nicht erneut kassieren {#already-paid}

**Der Kunde hat bezahlt, aber die Kasse wartet noch.** **Kassieren Sie nicht erneut.** Bleiben Sie in dieser Ansicht: Der Verkauf wird abgeschlossen, sobald Mollie die Zahlung bestätigt. Geschieht das nicht, bitten Sie die Filialleitung, die Zahlung im Mollie-Dashboard zu prüfen.

**„Eine frühere Mollie-Zahlung für diesen Verkauf wurde bezahlt“.** Eine Zahlung für diesen Verkauf wurde bei Mollie bereits ausgeführt, ist aber noch nicht in der Bestellung erfasst. **Kassieren Sie nicht erneut.** Warten Sie einige Minuten und laden Sie die Seite neu. Wenn die Meldung besagt, dass die Zahlung nicht zur Bestellung passt, muss die Filialleitung sie zuerst im Mollie-Dashboard prüfen.

### Weitere Probleme {#other-problems}

**„Keine Terminals für Mollie Terminal eingerichtet“.** Dem Shop steht kein aktives Terminal zur Verfügung. Die Filialleitung prüft, ob **Modus** mit einem Live-Schlüssel auf **Live** steht und ob das Terminal in diesem Mollie-Konto aktiv ist.

**„Wird von Bestellung #… verwendet“.** Dieses Terminal ist mit einem anderen Verkauf beschäftigt. Wählen Sie ein anderes Terminal oder schließen Sie zuerst den anderen Verkauf ab bzw. brechen Sie ihn ab.

**„Verbindung erforderlich“.** Die Kasse ist offline. Mollie Terminal funktioniert nur online: Nehmen Sie die Zahlung auf andere Weise an oder warten Sie auf die Verbindung.

**„Zeitüberschreitung — Zahlung abgebrochen“.** Es wurde nicht rechtzeitig bezahlt, daher wurde die Zahlung abgebrochen. Prüfen Sie, ob das Terminal eingeschaltet und online ist, und drücken Sie dann **Erneut versuchen** oder **Andere Zahlungsart wählen**.

**Ein Verkauf in einer anderen Währung wird abgelehnt.** Mollie Terminal akzeptiert nur Euro.

**Kommen Sie nicht weiter?** Melden Sie ein Problem mit der Erweiterung auf [GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/issues). Bei Fragen zu Ihrem Mollie-Konto oder dem Terminal selbst wenden Sie sich an den Mollie-Support oder lesen Sie die [Anleitung zur Terminaleinrichtung](https://docs.mollie.com/docs/setting-up-terminal) von Mollie.

<details>
<summary>Wie Kasse und Shop den Status bei Mollie abgleichen</summary>

- Solange eine Zahlung aussteht, fragt die Zahlungsseite alle zwei Sekunden bei Mollie nach. Mollies eigene Nachricht an Ihren Shop bestätigt die Zahlung meist früher. Für diese Nachricht müssen Sie nichts einrichten.
- Jede Aktualisierung wird bei Mollie geprüft, bevor sich die Bestellung ändert. So richtet sich die Bestellung nach den Angaben von Mollie.
- Wenn eine Rückerstattungsanfrage ohne Antwort bleibt, sucht die Erweiterung zuerst nach einer bereits von Mollie ausgeführten Rückerstattung, bevor sie eine weitere veranlasst.
- Im Tab Legacy wird die Zahlung bei aktivierten **QR-Code-Zahlungen** über den eigenen Zahlungsbereich der Erweiterung abgewickelt. Dieser bricht eine bei Mollie offen gebliebene Zahlung ab, wenn innerhalb von fünf Minuten niemand bezahlt, die Bestellung auf andere Weise bezahlt oder in WooCommerce storniert wird oder die Zahlungsseite während des Zahlungsvorgangs geschlossen wird. Eine Prüfung alle zehn Minuten bricht alle Zahlungen ab, die nach zehn Minuten für eine unbezahlte Bestellung noch offen sind.
- Eine Zahlung, die das Terminal bereits erreicht hat, kann nicht vom Shop aus abgebrochen werden. Brechen Sie sie am Terminal ab.
- Zur Fehlerbehebung wird jede Zahlung unter `WooCommerce > Status > Protokolle` protokolliert. Wenn ein Verkauf nicht abgeschlossen wird, sucht die Filialleitung dort nach Mollie-Meldungen.

</details>

## Einrichtung {#setup}

Die Filialleitung führt dies einmalig in WP Admin durch. Sie benötigen WCPOS Pro 2.0.0 oder neuer, ein Live-Mollie-Konto mit aktivierter Methode **Point of Sale** und Euro als Shopwährung.

<details>
<summary>Einrichtung durch die Filialleitung: Installation, Schlüssel, Terminals, Aktivierung</summary>

Die Erweiterung benötigt WCPOS Pro 2.0.0 oder neuer. Ohne diese Voraussetzung ist sie ohne Funktion und zeigt einen Hinweis in WP Admin an.

:::note Bevor Sie beginnen
Aktivieren Sie in der Mollie Web App die Zahlungsart **Point of Sale** für Ihr Profil und kaufen Sie dort Ihre Terminals. Mollie verkauft Terminals in den Niederlanden, Belgien, Deutschland, Frankreich und dem Vereinigten Königreich und verlangt möglicherweise zunächst eine Verifizierung Ihres Kontos. Terminals gibt es nur in einem **Live**-Konto, daher benötigen Sie Ihren Live-API-Schlüssel.
:::

1. **Installieren Sie die Erweiterung.** Öffnen Sie `POS Settings > Erweiterungen` und installieren Sie **Mollie Terminal**, oder laden Sie die Release-ZIP-Datei von [GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases) unter `Plugins > Add Plugin` über **Plugin hochladen** hoch. Verwenden Sie die dem Release beigefügte ZIP-Datei, nicht das Quellcodearchiv. Siehe [Erweiterungen](../../extensions/index.mdx#installing-an-extension).
2. **Fügen Sie Ihren Schlüssel hinzu.** Gehen Sie zu `WooCommerce > Einstellungen > Zahlungen > Mollie Terminal`. Setzen Sie **Modus** auf **Live** und fügen Sie entweder Ihren Live-Schlüssel unter **Mollie-API-Schlüssel** ein oder stellen Sie **Quelle des API-Schlüssels** so ein, dass der Schlüssel des Plugins Mollie Payments for WooCommerce verwendet wird. Speichern Sie.
3. **Wählen Sie Ihre Terminals.** Sobald der Schlüssel gespeichert ist, werden die Terminals Ihres Mollie-Kontos aufgelistet. Wählen Sie ein **Standardterminal**. Wenn einige Terminals nicht an der Kasse verwendet werden sollen, listen Sie unter **Aktivierte Terminals** nur die zulässigen auf. Speichern Sie.
4. **Aktivieren Sie es für den POS.** Gehen Sie zu `POS > Einstellungen > Kasse` und aktivieren Sie **Mollie Terminal**. Dies ist der einzige Ein-/Ausschalter. Siehe [Ein Zahlungsgateway aktivieren](../../settings/wp-admin/checkout.mdx#enabling-a-gateway).

Sie müssen im Mollie-Dashboard keinen Webhook einrichten und keine Profil-ID einfügen: Die Erweiterung sendet ihre Webhook-Adresse mit jeder Zahlung und listet die Terminals Ihres gesamten Kontos auf.

Wenn die Liste **Standardterminal** leer bleibt, prüfen Sie, ob **Modus** mit Ihrem Live-Schlüssel auf **Live** steht (in einem Testkonto gibt es keine Terminals), ob das Terminal in Mollie aktiv ist und ob Ihre Website Mollie erreichen kann.

</details>

### Die Einstellungen {#settings}

<details>
<summary>Alle Einstellungen auf der Seite Mollie Terminal</summary>

Alle diese Einstellungen finden Sie unter `WooCommerce > Einstellungen > Zahlungen > Mollie Terminal`.

| Einstellung | Funktion |
|---|---|
| **Titel** | Der Name auf der Kachel an der Kasse. Anfangs „Mollie Terminal“. |
| **Beschreibung** | Text, der zusammen mit der Zahlungsart auf der Zahlungsseite der Bestellung angezeigt wird. |
| **Modus** | **Test** oder **Live**. Anfangs auf **Test**, wobei eine Warnung angezeigt wird: Der Testschlüssel kann kein Terminal steuern. Verwenden Sie **Live**, um Zahlungen anzunehmen. |
| **Quelle des API-Schlüssels** | **Den unten eingegebenen Schlüssel verwenden** oder **Den Schlüssel des offiziellen Mollie-Plugins verwenden** (den zum **Modus** passenden Test- oder Live-Schlüssel). Wenn im Mollie-Plugin kein Schlüssel hinterlegt ist, wird der unten eingegebene Schlüssel verwendet. |
| **Mollie-API-Schlüssel** | Ihr Schlüssel für den ausgewählten Modus. Wird ignoriert, solange als Schlüsselquelle der Schlüssel des Mollie-Plugins verwendet wird. |
| **Standardterminal** | Das Terminal, mit dem eine Kasse beginnt. Die Liste wird direkt aus Ihrem Mollie-Konto geladen. Inaktive Terminals werden ausgeblendet, da Mollie sie nicht reaktivieren kann. |
| **Aktivierte Terminals** | Nur diese können an der Kasse ausgewählt werden. Leer bedeutet alle aktiven Terminals. Das Standardterminal wird immer angeboten. Ändern Sie es daher ebenfalls, wenn Sie ein Terminal außer Betrieb nehmen. Wird nicht angezeigt, solange die Terminalliste nicht geladen werden kann; Ihre gespeicherte Auswahl bleibt erhalten. |
| **QR-Code-Zahlungen** | **iDEAL** und **Bancontact**: Ermöglicht dem Kassierer, stattdessen einen QR-Code auf dem Bildschirm anzuzeigen. Die jeweilige Methode muss in Ihrem Mollie-Profil aktiv sein. iDEAL QR funktioniert auch im Modus **Test**, sodass Sie es ohne Terminal ausprobieren können. Bancontact QR benötigt **Live**. Siehe [Per QR-Code bezahlen](#qr-code). |
| **Terminalauswahl sperren** | Die Kasse verwendet immer das Standardterminal, und der Kassierer kann es nicht ändern. Erfordert ein **Standardterminal**. |
| **Checkout-Debug-Protokolle** | Zeigt **Protokolle anzeigen**, **Kopieren** und **Leeren** im Zahlungsbereich an. Lassen Sie dies deaktiviert, sofern der Support Sie nicht dazu auffordert: Zahlungen werden immer unter `WooCommerce > Status > Protokolle` protokolliert. |

</details>
