# Web Checkout Gateway {#web-checkout-gateway}

:::info Pro-Funktion
Sie benötigen [WCPOS Pro](../../getting-started/free-vs-pro.mdx), um Zahlungen mit Web Checkout entgegenzunehmen.
:::

Mit Web Checkout kann der Kunde eine POS-Bestellung auf der eigenen Zahlungsseite Ihres Onlineshops bezahlen. Dabei stehen ihm die Zahlungsarten Ihres Onlineshops zur Verfügung, etwa ein Onlineformular für Kartenzahlungen oder eine Wallet. Verwenden Sie diese Möglichkeit, wenn der Kunde mit einer Zahlungsart bezahlen möchte, die Ihre Kasse nicht annimmt.

Direkt zu: [Zahlung entgegennehmen](#take-payment) · [Einrichtung](#set-up) · [Wenn etwas schiefgeht](#goes-wrong)

## Zahlung entgegennehmen {#take-payment}

Web Checkout finden Sie auf der Registerkarte **Legacy** im Checkout. Es benötigt eine Verbindung und berechnet immer den gesamten Bestellbetrag. Wenn bereits eine Zahlung entgegengenommen wurde, lesen Sie zuerst [Ein Teil der Bestellung ist bereits bezahlt](#split).

:::warning Lassen Sie den Checkout geöffnet, bis Sie auf Zahlung verarbeiten drücken
Die Kasse überwacht die andere Registerkarte nicht. Sie schließt den Verkauf erst ab, wenn Sie bei einer vom Kunden bezahlten Bestellung auf **Zahlung verarbeiten** drücken. Lassen Sie den Checkout daher geöffnet, während der Kunde bezahlt.
:::

1. Erfassen Sie den Verkauf wie gewohnt und drücken Sie auf **Kasse**.
2. Öffnen Sie die Registerkarte **Legacy**. Die Zahlungsseite Ihres Shops wird im POS geladen.
3. Wählen Sie **Web Checkout**. Darunter erscheinen der zugehörige Hinweis und der Link **Diese Bestellung bezahlen**.
4. Drücken Sie auf **Diese Bestellung bezahlen**. Die Zahlungsseite Ihres Onlineshops für diese Bestellung öffnet sich in einer neuen Browser-Registerkarte. In der Desktop-App öffnet sie sich im Webbrowser Ihres Computers.
5. Überlassen Sie dem Kunden den Bildschirm. Er wählt eine Zahlungsart aus und bezahlt wie auf Ihrer Website.
6. Sobald der Kunde bezahlt hat, zeigt seine Registerkarte die Bestellbestätigung Ihres Shops. Lassen Sie diese Registerkarte geöffnet und kehren Sie zum POS zurück.
7. Drücken Sie auf **Zahlung verarbeiten**. Ist die Bestellung bezahlt, zeigt die Kasse wie bei jedem Verkauf die Zahlungsbestätigung und den Beleg an. Andernfalls bleibt die Kasse auf dieser Seite: siehe [Wenn etwas schiefgeht](#goes-wrong).
8. Schließen Sie die Registerkarte des Kunden, sobald die Kasse den Beleg anzeigt.

4. **Die Zahlungsseite des Shops** — zuerst die Bestellung, dann die für den POS aktivierten Zahlungsgateways. Web Checkout erscheint in dieser Liste, sobald es aktiviert ist; im abgebildeten Shop ist es nicht vorhanden. **Checkout-Einstellungen** oben hilft bei einer fehlerhaft dargestellten Seite; siehe [Wenn etwas schiefgeht](#goes-wrong).

6. **Die Bestellung** — Bestellnummer, Kunde und Uhrzeit.

### Ein Teil der Bestellung ist bereits bezahlt {#split}

Ein Legacy-Zahlungsgateway berechnet den gesamten Bestellbetrag. Sobald eine Zahlung entgegengenommen wurde, zeigt die Registerkarte Legacy daher **Ein Legacy-Zahlungsgateway kann nicht verwendet werden, nachdem bereits eine Zahlung entgegengenommen wurde** an. Sie haben zwei Möglichkeiten:

- **Nehmen Sie den Restbetrag über eine Kachel entgegen**, etwa Bargeld oder Karte auf der Registerkarte Zahlungen. Siehe [Geteilte Zahlungen](../../pos/checkout/split-payments.mdx).
- **Stornieren Sie die bisher entgegengenommenen Zahlungen** und verwenden Sie dann Web Checkout für die gesamte Bestellung. Bevor etwas rückgängig gemacht wird, listet die Kasse auf, was mit jeder Zahlung geschieht: Bargeld geht an den Kunden zurück, andere Zahlungen werden über ihre Zahlungsart storniert, und eine Zahlung, die sich nicht stornieren lässt, wird über die Bestellung rückerstattet. Siehe [Eine Zahlung stornieren](../../pos/checkout/cancelling-a-payment.mdx).

:::tip Der Kunde möchte später auf seinem eigenen Smartphone bezahlen
Web Checkout öffnet die Zahlungsseite auf dem Gerät, auf dem der POS läuft. Um dem Kunden einen Link zu senden, über den er später bezahlen kann, verwenden Sie [Rechnung per E-Mail](./email-invoice.mdx).
:::

## Einrichtung {#set-up}

Diese einmalige Einrichtung übernimmt vor dem ersten Verkauf mit Web Checkout jemand, der Ihren Shop in WP Admin verwaltet. Web Checkout ist ein kostenloses Plugin, wird im POS aber nur mit WCPOS Pro angeboten. Ohne Pro nimmt die Kasse Bargeld und Karte an. Es verwendet die Zahlungsarten, die Ihr Onlineshop bereits anbietet, und benötigt weder ein Konto noch Schlüssel.

<details>
<summary>Für Shop-Manager: installieren und aktivieren</summary>

1. **Installieren.** Web Checkout ist nicht unter `WP Admin > POS > Einstellungen > Erweiterungen` verfügbar. Laden Sie **woocommerce-pos-web-checkout-gateway.zip** (nicht die ZIP-Datei mit dem Quellcode) von der [GitHub-Releases-Seite](https://github.com/wcpos/web-checkout-gateway/releases) herunter. Laden Sie die Datei unter `WP Admin > Plugins > Add Plugin` über **Plugin hochladen** hoch und aktivieren Sie das Plugin.
2. **Für den POS aktivieren.** Aktivieren Sie **Web Checkout** unter `WP Admin > POS > Einstellungen > Kasse` und speichern Sie. Siehe [Checkout-Einstellungen](../../settings/wp-admin/checkout.mdx#enabling-a-gateway). Es erscheint nie im Checkout Ihres Onlineshops: Kunden erreichen es ausschließlich über den POS.
3. **Online-Zahlungsarten prüfen.** Der Kunde bezahlt mit den Zahlungsarten, die unter `WP Admin > WooCommerce > Einstellungen > Zahlungen` für den Onlineshop aktiviert sind. Mindestens eine davon muss Zahlungen entgegennehmen können.

</details>

<details>
<summary>Namen oder Hinweis ändern</summary>

Name und Hinweis auf der Zahlungsseite entsprechen den Feldern **Titel** und **Beschreibung** des Zahlungsgateways unter `WP Admin > WooCommerce > Einstellungen > Zahlungen > Web Checkout Gateway`. Der Standardhinweis lautet: „Gehen Sie zur Checkout-Seite, um die Bestellung zu bezahlen. Klicken Sie nach der Zahlung auf die Schaltfläche Zahlung verarbeiten, um zum Beleg zu gelangen.“ Um den Namen nur im POS zu ändern, ändern Sie den **Titel** unter **POS-Einstellungen** im Menü **⋮** des Zahlungsgateways in den [Checkout-Einstellungen](../../settings/wp-admin/checkout.mdx#payment-gateways). Der Hinweis stammt immer aus WooCommerce.

</details>

<details>
<summary>Für Entwickler: Funktionsweise</summary>

Das Plugin fügt ein WooCommerce-Zahlungsgateway mit der ID `wcpos_web_checkout` hinzu. Im Code ist es für den Online-Checkout deaktiviert, sodass nur der POS es anbieten kann. Seine Zahlungsfelder geben die Beschreibung sowie einen Link zur Zahlungs-URL der Bestellung (`$order->get_checkout_payment_url()`) aus, der sich in einem neuen Fenster öffnet.

Das Zahlungsgateway selbst nimmt kein Geld entgegen. Wenn **Zahlung verarbeiten** eine bereits bezahlte, vom POS erstellte Bestellung mit ausgewähltem `wcpos_web_checkout` übermittelt, leitet das Plugin von der Zahlungsseite zur Bestelleingangsseite weiter. Von dort aus schließt der POS den Verkauf ab. Bei einer unbezahlten Bestellung erfolgt keine Weiterleitung. Den Quellcode finden Sie im [Repository web-checkout-gateway](https://github.com/wcpos/web-checkout-gateway).

</details>

## Wenn etwas schiefgeht {#goes-wrong}

**Web Checkout fehlt in der Liste auf der Registerkarte Legacy.** Das Plugin ist nicht aktiv oder Web Checkout ist in den [Checkout-Einstellungen](../../settings/wp-admin/checkout.mdx#enabling-a-gateway) nicht aktiviert. Ohne WCPOS Pro bietet der POS nur Bargeld und Karte an.

**„Für den POS sind keine Legacy-Zahlungsgateways aktiviert.“** Es ist kein Zahlungsgateway ohne eigene Kachel aktiviert. Aktivieren Sie Web Checkout in den Checkout-Einstellungen.

**Zahlung verarbeiten führt nicht zum Beleg.** Die Bestellung ist im Shop nicht als bezahlt erfasst. Prüfen Sie die Registerkarte des Kunden, bevor Sie ihn erneut zur Zahlung auffordern: Wird noch die Zahlungsseite angezeigt, ist er noch nicht fertig. Wird die Bestellbestätigung angezeigt, drücken Sie erneut auf **Zahlung verarbeiten**. Wenn die Kasse weiterhin nicht zum nächsten Schritt wechselt, prüfen Sie die Bestellung unter `WP Admin > WooCommerce > Orders`.

**Auf der Zahlungsseite erscheint keine Zahlungsart, die der Kunde nutzen kann.** In Ihrem Onlineshop ist keine passende Zahlungsart aktiviert. Aktivieren Sie unter `WP Admin > WooCommerce > Einstellungen > Zahlungen` eine geeignete Zahlungsart für den Onlineshop.

**Die Zahlungsseite im POS wird fehlerhaft dargestellt.** Möglicherweise wird sie durch ein Theme oder Plugin beeinträchtigt. Siehe [Die Zahlungsseite eines Zahlungsgateways wird fehlerhaft dargestellt](../../pos/checkout/troubleshooting.mdx#checkout-settings-troubleshooting).
