# Vipps MobilePay-Zahlungsgateway {#vipps-mobilepay-gateway}

:::info Pro-Funktion
Um Vipps MobilePay an der Kasse anzunehmen, benötigen Sie [WCPOS Pro](../../getting-started/pro-license.mdx). Ohne Pro funktioniert das Zahlungsgateway weiterhin an der Kasse Ihres Onlineshops.
:::

Der Kunde bezahlt mit der Vipps- oder MobilePay-App auf seinem eigenen Smartphone. Er scannt einen QR-Code auf Ihrem Bildschirm oder bestätigt eine Zahlungsanfrage, die Sie an sein Smartphone senden. Ein Kartenleser ist nicht erforderlich. Das Zahlungsgateway läuft auf dem Reiter **Legacy** an der Kasse, auf der eigenen Zahlungsseite Ihres Shops.

Das Zahlungsgateway muss zunächst für Ihren Shop eingerichtet werden. Siehe [Vipps MobilePay einrichten](#setup).

## Eine Vipps-Zahlung entgegennehmen {#take-payment}

Vipps wickelt die gesamte Bestellung in einer einzigen Zahlung ab. Sobald ein Teil der Bestellung bezahlt ist, zeigt der Reiter Legacy **Ein Legacy-Zahlungsgateway kann nicht verwendet werden, nachdem eine Zahlung entgegengenommen wurde** an, und Sie können Vipps nicht auswählen: [Stornieren Sie zuerst diese Zahlung](../../pos/checkout/cancelling-a-payment.mdx) oder nehmen Sie den Rest auf andere Weise entgegen.

Drücken Sie **Kasse**, öffnen Sie den Reiter **Legacy** und wählen Sie **Vipps MobilePay**. Die Bedienelemente erscheinen darunter. Zeigen Sie dem Kunden anschließend [einen QR-Code](#qr) oder [senden Sie die Anfrage an sein Smartphone](#send-to-phone).

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[98, 0], [148, 0], [300, 0], [0, 0], [0, 0], [-80, 0], [-42, 0]]} alt="Der Reiter Legacy an der Kasse mit ausgewähltem Vipps MobilePay: das Telefonnummernfeld, die Schaltflächen QR-Code generieren und An Smartphone senden, der Restbetrag und Zahlung verarbeiten">

1. Reiter **Legacy** — Zahlungsgateways mit eigener Zahlungsseite. Siehe [Der Reiter Legacy](../../pos/checkout/legacy-tab.mdx).
2. **Vipps MobilePay** — das Zahlungsgateway. Ihr Shop kann ihm einen anderen Namen geben; siehe [Einstellungen](#settings).
3. **Telefonnummer (optional)** — nur für **An Smartphone senden**. Lassen Sie das Feld für einen QR-Code leer.
4. **QR-Code generieren** — zeigt einen Code an, den der Kunde scannen kann. Siehe [Mit einem QR-Code](#qr).
5. **An Smartphone senden** — sendet die Zahlungsanfrage an die eingegebene Nummer. Die Schaltfläche wird aktiviert, sobald eine Nummer eingegeben ist. Siehe [An das Smartphone senden](#send-to-phone).
6. **Restbetrag** — der Betrag, den der Kunde in der App bestätigt: die gesamte Bestellung.
7. **Zahlung verarbeiten** — für Vipps nicht erforderlich. Der Verkauf wird automatisch abgeschlossen, sobald der Kunde bestätigt.

</JourneyShot>

### Mit einem QR-Code {#qr}

1. Drücken Sie **QR-Code generieren**. Unter den Schaltflächen erscheint ein QR-Code, darunter **Warten auf Zahlung...**.
2. Drehen Sie den Bildschirm zum Kunden. Er scannt den Code mit der Vipps- oder MobilePay-App und bestätigt die Zahlung.
3. Die Kasse fragt alle zwei Sekunden bei Vipps nach. Sobald der Kunde bestätigt, zeigt die Seite **Zahlung erfolgreich!** an, und die Belegansicht öffnet sich automatisch, genau wie bei jedem [bezahlten Verkauf](../../pos/checkout/index.mdx#paid).

Während die Kasse wartet, sind beide Schaltflächen ausgegraut, und darunter erscheint die Schaltfläche **Zahlung abbrechen**. Wenn innerhalb von fünf Minuten niemand bestätigt, zeigt die Seite **Zahlung abgelaufen. Bitte versuchen Sie es erneut.** an.

### An das Smartphone senden {#send-to-phone}

Geben Sie die Telefonnummer des Kunden ein und drücken Sie **An Smartphone senden**. Anschließend geschieht eines von zwei Dingen:

- **Direkte Push-Benachrichtigung:** Die Anfrage erscheint in der Vipps-App des Kunden, und er bestätigt sie dort. Die Seite wartet und schließt den Vorgang genauso ab wie bei einem QR-Code.
- **Die Vipps-Seite öffnet sich in einem neuen Fenster**, oder die Seite fordert Sie zunächst auf, erneut zu drücken. Das ist zu erwarten, wenn Vipps direkte Push-Benachrichtigungen für Ihren Shop noch nicht aktiviert hat: Öffnen Sie unten **Sie sollen erneut auf An Smartphone senden drücken?**.

**Nur norwegische Nummern.** Geben Sie acht Ziffern ein oder stellen Sie `47`, `+47` oder `0047` voran. Eine achtstellige Nummer wird immer als norwegische Nummer interpretiert. Verwenden Sie daher für einen MobilePay-Kunden in Dänemark oder Finnland den QR-Code.

<details>
<summary>Sie sollen erneut auf An Smartphone senden drücken?</summary>

Die Seite zeigt **Direkte Push-Benachrichtigungen sind für Ihr Konto nicht verfügbar. Klicken Sie erneut auf An Smartphone senden.** an, wenn Vipps [direkte Push-Benachrichtigungen](#enabling-direct-push) für Ihr Konto noch nicht aktiviert hat.

1. Drücken Sie erneut **An Smartphone senden**.
2. Die Vipps-Seite für diese Nummer öffnet sich in einem neuen Fenster. Von dort wird die Anfrage an den Kunden gesendet.
3. Sobald der Kunde bezahlt hat, zeigt das Fenster **Zahlung abgeschlossen** an und schließt sich automatisch. Wenn der Browser es nicht schließt, wird darin die Startseite Ihres Shops geöffnet: Schließen Sie das Fenster und kehren Sie zur Kasse zurück.

Ab dann öffnet **An Smartphone senden** jedes Mal dieses Fenster, bis Sie [direkte Push-Benachrichtigungen aktivieren](#enabling-direct-push). Im **Testmodus** erscheint kein Fenster: Die Seite fordert Sie jedes Mal auf, erneut zu drücken. Testen Sie daher mit dem QR-Code.

</details>

### Eine Zahlung abbrechen {#cancel}

Drücken Sie **Zahlung abbrechen**, während die Kasse wartet. Die Zahlung wird bei Vipps abgebrochen, und die Seite zeigt **Zahlung abgebrochen.** an. Es wurde kein Geld eingezogen. Drücken Sie **QR-Code generieren** oder **An Smartphone senden**, um es erneut zu versuchen, oder wählen Sie eine andere Zahlungsart: Wählen Sie auf dem Reiter Legacy ein anderes Zahlungsgateway oder kehren Sie zum Reiter **Zahlungen** zurück.

Dieselbe Meldung **Zahlung abgebrochen.** erscheint, wenn der Kunde in seiner App ablehnt.

## Wenn etwas schiefgeht {#goes-wrong}

**Zahlung abgelaufen. Bitte versuchen Sie es erneut.** Fünf Minuten sind ohne Antwort des Kunden vergangen. Drücken Sie erneut **QR-Code generieren** oder **An Smartphone senden**.

**Zahlung abgebrochen.**, obwohl Sie nicht auf Abbrechen gedrückt haben. Der Kunde hat in seiner App abgelehnt. Fragen Sie bei ihm nach und versuchen Sie es dann erneut.

**Ungültige Telefonnummer. Verwenden Sie eine norwegische Nummer, z. B. 4741234567.** Die Nummer ist keine norwegische Mobilfunknummer. Prüfen Sie sie oder verwenden Sie den QR-Code.

**Pop-up blockiert. Bitte erlauben Sie Pop-ups und versuchen Sie es erneut.** Der Browser hat verhindert, dass sich das Vipps-Fenster öffnet. Erlauben Sie in den Browsereinstellungen Pop-ups für die Website Ihres Shops und drücken Sie dann erneut **An Smartphone senden**.

**Netzwerkfehler. Bitte prüfen Sie Ihre Verbindung.** Die Kasse konnte Ihren Shop nicht erreichen, um die Zahlung zu starten. Prüfen Sie die Verbindung der Kasse und drücken Sie dann erneut **QR-Code generieren** oder **An Smartphone senden**.

**Vipps-Zahlung konnte nicht erstellt werden.** Ihr Shop konnte die Zahlung bei Vipps nicht starten. Fragen Sie den Kunden, ob er eine Zahlung in seiner App bestätigt hat. Falls ja, bitten Sie den Shopinhaber, Vipps zu prüfen, bevor Sie eine weitere Zahlung entgegennehmen. Falls nicht, wickeln Sie diesen Verkauf auf andere Weise ab und bitten Sie den Shopinhaber, die Einrichtung des Zahlungsgateways zu prüfen.

<details>
<summary>Für den Shopinhaber: Einrichtung und Protokoll prüfen</summary>

- Die vier Schlüssel und den **Testmodus** unter [Einstellungen](#settings): Live-Schlüssel bei deaktiviertem Testmodus oder Testschlüssel bei aktiviertem Testmodus.
- Ihre Website verwendet HTTPS.
- Die Bestellung verwendet eine Währung, die Vipps akzeptiert. Siehe [Unterstützte Länder und Währungen](#supported-markets).
- Aktivieren Sie das **Debug-Protokoll** und versuchen Sie es erneut, um die Ursache zu finden. Es erscheint unter **Protokoll anzeigen** auf der Zahlungsseite sowie unter `WooCommerce > Status > Protokolle` mit der Quelle `wcpos-vipps`.

</details>

:::warning Prüfen Sie Vipps, bevor Sie erneut eine Zahlung entgegennehmen
**Die Vipps-Zahlung wurde akzeptiert, aber … Bitte versuchen Sie es erneut.** Die Zahlung des Kunden war bei Vipps erfolgreich, aber WooCommerce hat die Bestellung nicht als bezahlt markiert. Suchen Sie diese Zahlung im [Vipps MobilePay-Portal](https://portal.vippsmobilepay.com/), bevor Sie eine neue Zahlung entgegennehmen, damit der Kunde nicht doppelt bezahlt.
:::

**An Smartphone senden öffnet ein Fenster, statt direkt zur App zu führen.** Ihr Konto verwendet **Web-Weiterleitung**. Das funktioniert, erfordert aber einen zusätzlichen Schritt vom Kunden. Um direkt zur App zu gelangen, siehe [Direkte Push-Benachrichtigungen aktivieren](#enabling-direct-push).

## Vipps MobilePay einrichten {#setup}

:::note Bevor Sie beginnen
Sie benötigen ein Vipps MobilePay-Händlerkonto mit der ePayment API, dessen vier API-Schlüssel, [WCPOS Pro](../../getting-started/pro-license.mdx) und eine Website mit HTTPS, das die Vipps API voraussetzt.
:::

Der Shopinhaber installiert das Zahlungsgateway, trägt die vier Schlüssel ein und aktiviert es für den POS. Anschließend erscheint es auf dem Reiter Legacy an der Kasse.

<details>
<summary>Für den Shopinhaber: Zahlungsgateway installieren und aktivieren</summary>

1. **Installieren** Sie WCPOS Vipps MobilePay unter `WP Admin > POS > Einstellungen > Erweiterungen`. Siehe [Eine Erweiterung installieren](../../extensions/index.mdx#installing-an-extension). Oder laden Sie die **ZIP-Datei des Plugins** (nicht die Quellcode-ZIP-Datei) von der [Release-Seite](https://github.com/wcpos/wcpos-vipps/releases) herunter und laden Sie sie unter `Plugins > Add Plugin` über **Plugin hochladen** hoch.
2. **Fügen Sie Ihre Schlüssel hinzu.** Öffnen Sie `WP Admin > WooCommerce > Einstellungen > Zahlungen > WCPOS Vipps MobilePay` und geben Sie **Händlerseriennummer**, **Client-ID**, **Client-Geheimnis** und **Abonnementschlüssel** aus dem [Vipps MobilePay-Portal](https://portal.vippsmobilepay.com/) ein. Speichern Sie.
3. **Aktivieren Sie das Zahlungsgateway für den POS** unter `WP Admin > POS > Einstellungen > Kasse`. Siehe [Ein Zahlungsgateway aktivieren](../../settings/wp-admin/checkout.mdx#enabling-a-gateway). Anschließend erscheint es auf dem Reiter Legacy an der Kasse.

:::tip Verwenden Sie bereits das offizielle Vipps-Plugin?
Wenn [Checkout with Vipps MobilePay](https://wordpress.org/plugins/woo-vipps/) auf Ihrer Website eingerichtet ist, übernimmt WCPOS Vipps MobilePay beim ersten Laden dessen Schlüssel, einschließlich der Testschlüssel. Prüfen Sie diese und speichern Sie.
:::

Das Kontrollkästchen **Aktivieren/Deaktivieren** auf der WooCommerce-Seite gilt nur für die Kasse Ihres Onlineshops. Der POS verwendet das Zahlungsgateway, sobald es in den Checkout-Einstellungen aktiviert ist, unabhängig davon, ob dieses Kontrollkästchen aktiviert ist.

</details>

### Einstellungen {#settings}

Diese finden Sie unter `WP Admin > WooCommerce > Einstellungen > Zahlungen > WCPOS Vipps MobilePay`. Die meisten Shops müssen nur die vier Schlüssel eintragen. Die übrigen Voreinstellungen passen bereits für die Kasse: Das Geld wird eingezogen, sobald der Kunde bestätigt, und **An Smartphone senden** versucht zuerst eine direkte Push-Benachrichtigung.

<details>
<summary>Alle Einstellungen: Name und Beschreibung, Schlüssel, Automatischer Einzug, Zahlungsmethode für Smartphone, Debug-Protokoll und Testmodus</summary>

| Einstellung | Funktion |
|---|---|
| **Aktivieren/Deaktivieren** | Bietet Vipps MobilePay an der Kasse Ihres Onlineshops an. Für den POS nicht erforderlich. Standardmäßig deaktiviert. |
| **Titel** | Der Name des Zahlungsgateways auf dem Reiter Legacy und im Onlineshop. Standardmäßig `Vipps MobilePay`. In den Checkout-Einstellungen können Sie für den POS einen eigenen Titel festlegen. |
| **Beschreibung** | Die Zeile unter dem Namen. Standardmäßig „Bezahlen Sie mit Vipps MobilePay per QR-Code oder Push-Benachrichtigung.“ |
| **Händlerseriennummer**, **Client-ID**, **Client-Geheimnis**, **Abonnementschlüssel** | Ihre Live-Schlüssel aus dem Vipps MobilePay-Portal. Das Zahlungsgateway wird erst angeboten, wenn alle vier eingetragen sind (bei aktiviertem **Testmodus** stattdessen die vier **Test**-Schlüssel). |
| **Automatischer Einzug** | Standardmäßig aktiviert: Das Geld wird eingezogen, sobald der Kunde bestätigt. Deaktivieren Sie dies nur, wenn Sie reservierte Zahlungen selbst außerhalb von WCPOS einziehen. |
| **Zahlungsmethode für Smartphone** | Legt fest, wie **An Smartphone senden** den Kunden erreicht. **Direkte Push-Benachrichtigung** (Standard) führt direkt zu seiner Vipps-App. **Web-Weiterleitung** öffnet die Vipps-Seite in einem neuen Fenster. Wechselt automatisch zu **Web-Weiterleitung**, wenn Vipps eine direkte Push-Benachrichtigung ablehnt (nicht im Testmodus). |
| **Debug-Protokoll** | Protokolliert jeden Zahlungsschritt unter `WooCommerce > Status > Protokolle` und fügt unter den Bedienelementen für die Zahlung den Bereich **Protokoll anzeigen** hinzu. Aktivieren Sie es, um herauszufinden, warum eine Zahlung fehlschlägt, und deaktivieren Sie es anschließend wieder. |
| **Testmodus** | Sendet Zahlungen stattdessen an das Testsystem von Vipps und verwendet dabei die vier darunter stehenden **Test**-Schlüssel. Deaktivieren Sie ihn, bevor Sie echte Zahlungen entgegennehmen. |

</details>

### Direkte Push-Benachrichtigungen aktivieren {#enabling-direct-push}

Mit direkten Push-Benachrichtigungen führt **An Smartphone senden** direkt zur Vipps-App des Kunden, ohne zusätzliches Fenster. Vipps muss dies zunächst für Ihr Konto freigeben. Anschließend stellt der Shopinhaber das Zahlungsgateway einmalig darauf zurück.

<details>
<summary>Für den Shopinhaber: Vipps kontaktieren und anschließend zu direkten Push-Benachrichtigungen zurückwechseln</summary>

1. Melden Sie sich im [Vipps MobilePay-Portal](https://portal.vippsmobilepay.com/) an.
2. Wenden Sie sich an Ihren Key-Account-Manager, Partnermanager oder den Kundenservice von Vipps.
3. Teilen Sie Folgendes mit: „Ich benötige PUSH_MESSAGE für meine MSN zur Verwendung mit einer POS-Integration“. MSN ist Ihre **Händlerseriennummer**.
4. Sobald Sie die Bestätigung erhalten, stellen Sie **Zahlungsmethode für Smartphone** wieder auf **Direkte Push-Benachrichtigung** und speichern Sie. Das Zahlungsgateway wechselt nicht automatisch zurück. Solange **Web-Weiterleitung** eingestellt ist, erinnert Sie die Beschreibung der Einstellung daran, wie Sie direkte Push-Benachrichtigungen aktivieren.

Im **Testmodus** bleibt die Einstellung bei einer abgelehnten direkten Push-Benachrichtigung unverändert, und die Vipps-Seite öffnet sich nicht: Bei jedem **An Smartphone senden** werden Sie aufgefordert, erneut zu drücken. Testen Sie stattdessen mit dem QR-Code.

</details>

### Rückerstattungen {#refunds}

Erstatten Sie die Bestellung im POS zurück und wählen Sie **Rückerstattung an Vipps MobilePay**, oder führen Sie die Rückerstattung in der Bestellansicht von WooCommerce durch. Das Geld geht über Vipps an den Kunden zurück. Siehe [Rückerstattungen](../../orders/refunds.mdx). Wenn Vipps die Anfrage ablehnt, wird die Rückerstattung nicht erfasst, und die Meldung **Vipps-Rückerstattungsanfrage fehlgeschlagen.** erscheint. Versuchen Sie es erneut oder erstatten Sie den Betrag in bar zurück.

## Unterstützte Länder und Währungen {#supported-markets}

| Land | App | Währung |
|---|---|---|
| Norwegen | Vipps | NOK |
| Dänemark, Finnland | MobilePay | DKK, EUR |

Die Bestellung muss eine dieser Währungen verwenden. Welche davon Sie annehmen können, hängt von Ihrem Händlerkonto ab. **An Smartphone senden** funktioniert nur mit norwegischen Nummern; der QR-Code funktioniert überall.
