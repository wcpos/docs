# SumUp Terminal-Zahlungsgateway {#sumup-terminal-gateway}

Mit SumUp Terminal nutzen Sie einen SumUp-Kartenleser an Ihrer Kasse. Die Kasse sendet den Betrag an den Kartenleser, der Kunde bezahlt daran, und der Verkauf wird abgeschlossen, sobald SumUp die Zahlung genehmigt. Diese Seite führt Sie durch die einmalige Einrichtung des Zahlungsgateways, das Koppeln oder Verbinden des Kartenlesers und die erste Zahlung.

Bereits eingerichtet? [Koppeln Sie einen Solo](#pairing), [verbinden Sie einen Bluetooth-Kartenleser](#card-readers) oder [nehmen Sie eine Zahlung entgegen](#processing-payments).

:::info Pro-Funktion
SumUp Terminal 2.0 benötigt [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0 oder neuer. Ohne diese Version hat die Erweiterung an der Kasse keine Funktion.
:::

## Solo über die Cloud oder Bluetooth {#hardware-compatibility}

Die Einstellung **POS-Verbindung** des Zahlungsgateways legt fest, wie der POS den Kartenleser erreicht. Diese Auswahl gilt für die gesamte Filiale.

- **Solo über die Cloud** (Standard): Ihre Filiale verbindet sich über das Internet mit einem **SumUp Solo**. Das funktioniert an jeder Kasse: im Browser, in der Desktop-App, auf iPhone, iPad und Android. Sie koppeln den Solo einmalig auf der Seite des Zahlungsgateways.
- **Bluetooth-Kartenleser**: Die WCPOS-App für iOS oder Android verbindet sich über Bluetooth mit einem **Solo Lite**, **Solo** oder **Air**. Jede Kasse verbindet ihren eigenen Kartenleser in der App. Diese Option wird nur angezeigt, wenn WCPOS Pro in der Filiale Kartenleser unterstützt, die über die App verbunden werden.

Ein Browser oder die Desktop-App kann keinen Bluetooth-Kartenleser erreichen. Wenn **Bluetooth-Kartenleser** ausgewählt ist, erscheint die SumUp-Kachel an diesen Kassen unter **… derzeit nicht verfügbar**. Verwenden Sie daher **Solo über die Cloud**, wenn eine Kasse im Browser oder in der Desktop-App läuft. Die Meldung auf der Kachel wird unter [Nur Kartenleser der App sind zulässig](#only-app-readers) erklärt.

## Zahlungsgateway einrichten {#setup}

Ein Administrator führt diese Einrichtung einmal pro Filiale in WP Admin durch.

1. **Installieren Sie die Erweiterung.** Suchen Sie unter `WP Admin > POS > Einstellungen > Erweiterungen` nach **SumUp Terminal for WooCommerce**, klicken Sie auf **Installieren**, dann auf **Aktivieren**, und prüfen Sie, ob es sich um Version 2.0.0 oder neuer handelt: Im Verzeichnis kann noch eine ältere Version aufgeführt sein. Siehe [Erweiterungen](../../extensions/index.mdx#installing-an-extension).

   <details>
   <summary>Stattdessen aus einer heruntergeladenen ZIP-Datei installieren</summary>

   Laden Sie `sumup-terminal-for-woocommerce.zip` aus den Release-Dateien auf [GitHub](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases) herunter und laden Sie die Datei unter `Plugins > Add Plugin` über **Plugin hochladen** hoch. Die ZIP-Datei „Source code“ von GitHub lässt sich nicht installieren.

   </details>

2. **Fügen Sie Ihren API-Schlüssel hinzu.** Ihren **SumUp-API-Schlüssel** finden Sie im [SumUp-Entwicklerportal](https://developer.sumup.com/) in dem Konto, dem Ihre Kartenleser zugeordnet sind. Gehen Sie zu `WP Admin > WooCommerce > Einstellungen > Zahlungen`, öffnen Sie **SumUp Terminal** und fügen Sie ihn in **SumUp-API-Schlüssel** ein.
3. **Wählen Sie die POS-Verbindung**: **Solo über die Cloud** oder **Bluetooth-Kartenleser**. Geben Sie für **Bluetooth-Kartenleser** auch den **Affiliate-Schlüssel** aus [SumUp Affiliate Keys](https://developer.sumup.com/tools/authorization/affiliate-keys/) ein.
4. **Speichern Sie die Einstellungen.**
5. **Aktivieren Sie das Zahlungsgateway für den POS.** Gehen Sie zu `WP Admin > POS > Einstellungen > Kasse`, aktivieren Sie **SumUp Terminal** und speichern Sie. Sie müssen es nicht zusätzlich in der Zahlungsliste von WooCommerce aktivieren; siehe [Checkout-Einstellungen](../../settings/wp-admin/checkout.mdx).
6. **Koppeln oder verbinden Sie den Kartenleser**: Ein Solo über die Cloud wird [auf dieser Seite gekoppelt](#pairing); ein Bluetooth-Kartenleser wird [in der App verbunden](#card-readers).

SumUp Terminal ist ausschließlich für den POS vorgesehen. Es wird nicht an der Kasse Ihres Onlineshops angeboten.

<details>
<summary>Alle Einstellungen auf der Seite des Zahlungsgateways</summary>

| Einstellung | Funktion |
|---|---|
| **Titel** und **Beschreibung** | Der Name und die Beschreibung, die für das Zahlungsgateway angezeigt werden. An der Kasse erscheint der Titel auf der Kachel. |
| **SumUp-API-Schlüssel** | Aus Ihrem SumUp-Konto. |
| **Affiliate-App-ID** und **Affiliate-Schlüssel** | Aus [SumUp Affiliate Keys](https://developer.sumup.com/tools/authorization/affiliate-keys/). Der Schlüssel wird für **Bluetooth-Kartenleser** benötigt: Die App startet damit die Kartenleser-Software von SumUp. Für **Solo über die Cloud** ist er optional. |
| **POS-Verbindung** | *Solo über die Cloud (der Shop steuert den Kartenleser)* oder *Bluetooth-Kartenleser (die POS-App steuert den Kartenleser: Solo Lite, Solo, Air)*. |
| **Offline-Kartenzahlungen** | Hat in 2.0 keine Wirkung; siehe [Offline-Zahlungen](#offline-payments). |
| **Standardterminal** | Der gekoppelte Solo, mit dem eine Kasse Zahlungen abwickelt, bis ein anderer ausgewählt wird. |
| **Aktivierte Terminals** | Beschränkt die Kassen auf die von Ihnen ausgewählten Solos. Lassen Sie das Feld leer, um alle zuzulassen. |
| **Terminalauswahl sperren** | *Kassierer können das Terminal an der Kasse nicht ändern.* Erfordert ein **Standardterminal**. |
| **Checkout-Debug-Protokolle** | Zeigt detaillierte SumUp-Zahlungsprotokolle an der Kasse an. Zahlungsaktivitäten werden immer unter `WooCommerce > Status > Protokolle` protokolliert. |

Unter den Feldern zeigt die Seite den Verbindungsstatus, Ihre SumUp-Händlerdaten und die gekoppelten Kartenleser an. Sie müssen keinen Webhook einrichten: Der Shop teilt SumUp mit, wohin das jeweilige Ergebnis gesendet werden soll.

</details>

## Einen Solo über die Cloud koppeln {#pairing}

Der Kopplungscode stammt vom Solo selbst, nicht aus der SumUp-App. Sie geben ihn auf der Seite des Zahlungsgateways in WP Admin ein.

1. Schalten Sie den Solo ein. Melden Sie sich darauf nicht bei SumUp an.
2. Öffnen Sie auf dem Solo das Menü und dann **Verbindungen → Cloud API**. Dies ist der letzte Eintrag in der Liste. Tippen Sie auf **Verbinden**: Der Solo zeigt einen Kopplungscode an.
3. Öffnen Sie in WP Admin die Seite des Zahlungsgateways (`WooCommerce > Einstellungen > Zahlungen > SumUp Terminal`). Geben Sie unter **Neuen Kartenleser koppeln** den Code in **Kopplungscode eingeben** ein und drücken Sie **Kartenleser koppeln**.
4. Die Seite zeigt *Kartenleser erfolgreich gekoppelt!* an und wird neu geladen. Ihr Solo wird unter **Konfigurierte Kartenleser** mit Modell und Seriennummer aufgeführt.

**Keine Cloud API auf dem Solo?** Melden Sie sich auf dem Kartenleser von Ihrem SumUp-Konto ab und öffnen Sie das Menü erneut.

Um einen zweiten Solo zu koppeln, verwenden Sie **Weiteren Kartenleser koppeln**. Mit **Kopplung aufheben** neben einem Kartenleser entfernen Sie ihn aus der Filiale.

## Einen Bluetooth-Kartenleser in der App verbinden {#card-readers}

Wenn **POS-Verbindung** auf **Bluetooth-Kartenleser** eingestellt ist, verbindet jedes Smartphone oder Tablet seinen eigenen Kartenleser in der WCPOS-App für iOS oder Android. Tippen Sie unten im Seitenmenü auf **Einstellungen** und dann auf **Kartenleser**: Sobald das Zahlungsgateway eingerichtet ist, enthält die Seite den Abschnitt **Bluetooth-Kartenleser** mit der Schaltfläche **Kartenleser verbinden**. Wenn nur **Für diese Filiale sind keine Kartenleser eingerichtet** angezeigt wird, siehe [Keine Kartenleser](#no-card-readers).

1. Schalten Sie den Kartenleser ein und halten Sie ihn in der Nähe des Smartphones oder Tablets.
2. Tippen Sie auf **Kartenleser verbinden**. Wenn **Kartenleser verbinden mit** erscheint, wählen Sie **SumUp Terminal**.
3. Die Oberfläche von SumUp öffnet sich: Melden Sie sich bei Ihrem SumUp-Konto an und wählen Sie den Kartenleser aus.

Sobald ein Kartenleser gespeichert ist, erscheint unter **Kartenleser** ein Eintrag **SumUp Terminal**. Verwenden Sie beim nächsten Mal dessen Schaltfläche **SumUp Terminal-Kartenlesereinstellungen öffnen**. Die Schaltfläche verwendet den **Titel** des Zahlungsgateways und ist daher anders beschriftet, wenn Sie es umbenannt haben.

Zurück unter **Kartenleser** zeigt der Eintrag **Verbunden** an oder **In der SumUp Terminal-App gespeichert**, wenn der Kartenleser gespeichert, aber nicht verbunden ist. **Melden Sie sich bei SumUp Terminal an, um den Kartenleser zu verwenden.** bedeutet, dass die App noch nicht bei SumUp angemeldet ist: Tippen Sie erneut auf die Schaltfläche.

## Vor dem Livebetrieb testen {#testing}

Mit **Solo über die Cloud** können Sie einen Verkauf ohne Kartenleser und ohne echtes Geld durchführen: Der [Virtual Solo](https://virtual-solo.sumup.com) von SumUp simuliert einen Solo für ein SumUp-Sandbox-Konto.

<details>
<summary>Mit einem Virtual Solo testen</summary>

1. Fügen Sie auf der Seite des Zahlungsgateways den API-Schlüssel des Sandbox-Kontos in **SumUp-API-Schlüssel** ein und speichern Sie.
2. Koppeln Sie den Virtual Solo mit seinem Kopplungscode genauso wie [einen Solo](#pairing). Er wird unter **Konfigurierte Kartenleser** aufgeführt.
3. Führen Sie einen Verkauf anhand der Schritte unter [Eine Zahlung entgegennehmen](#processing-payments) durch. Die Kachel zeigt **Terminal: …** mit dem Virtual Solo an.

Tragen Sie anschließend wieder Ihren Live-API-Schlüssel ein, speichern Sie und koppeln Sie Ihren echten Solo, bevor Sie eine echte Zahlung entgegennehmen.

</details>

## Eine Zahlung entgegennehmen {#processing-payments}

:::note Zuerst die Kasse öffnen
Wenn **Kasse öffnen und schließen** aktiviert ist, erfasst die Kasse keine Zahlung, solange sie geschlossen ist. Eine bereits eingezogene Kartenzahlung müsste dann zurückerstattet werden. Siehe [Kasse öffnen](../../pos/register/index.mdx).
:::

1. Stellen Sie den Warenkorb zusammen und drücken Sie **Kasse**.
2. Tippen Sie bei den Zahlungsarten auf die Kachel **SumUp Terminal** und prüfen Sie die Zeile zum Kartenleser:
   - **Solo über die Cloud**: **Terminal: …**, mit **Ändern** zur Auswahl eines anderen Solo, sofern die Filiale dies erlaubt.
   - **Bluetooth-Kartenleser**: **Verbunden** mit dem Akkustand des Kartenlesers. **Kein Kartenleser verbunden** bedeutet, dass keine Verbindung besteht: Tippen Sie auf **Unter Einstellungen → Kartenleser verbinden**.
3. Drücken Sie **… an SumUp Terminal senden** und lassen Sie den Kunden am Kartenleser bezahlen:
   - **Solo über die Cloud**: Die Kasse zeigt **Warten auf den Kunden am Terminal** an. Zum Abbrechen drücken Sie **Am Terminal abbrechen**.
   - **Bluetooth-Kartenleser**: Die Kasse zeigt **Karte an den Kartenleser halten** an. Brechen Sie den Vorgang direkt am Kartenleser ab. Wenn Sie an der Kasse **Am Terminal abbrechen** drücken, erscheint **Am Kartenleser abbrechen**. Der Kartenleser kann den Kunden nach einem Trinkgeld fragen; siehe [Trinkgeld](../../pos/checkout/tips.mdx).

   Die Kasse hakt **Gesendet**, **Am Terminal**, **Genehmigt** und **Eingezogen** ab.
4. Wenn kein Betrag mehr offen ist, öffnet sich die Belegansicht: Drucken Sie den Beleg oder versenden Sie ihn per E-Mail und drücken Sie dann **Neuer Verkauf**. Siehe [Zahlungsabschluss prüfen](../../pos/checkout/index.mdx#paid). Wenn ein Teil des Gesamtbetrags offen bleibt, nehmen Sie den Rest auf andere Weise entgegen; siehe [Geteilte Zahlungen](../../pos/checkout/split-payments.mdx).

Bei einer abgelehnten oder abgebrochenen Kartenzahlung erscheint **Zahlung fehlgeschlagen: …** mit **Erneut versuchen** und **Andere Zahlungsart wählen**. Siehe [Am Kartenleser](../../pos/checkout/taking-a-payment.mdx#card-reader).

Auf dem Reiter [**Legacy**](../../pos/checkout/legacy-tab.mdx) an der Kasse zeigt SumUp Terminal eine **Terminal**-Auswahl mit **An Terminal senden**, **Abbrechen** und **Erneut versuchen** an. Die Zahlung wird genauso erfasst wie eine Zahlung aus dem Zahlungsbereich.

<details>
<summary>Eine ältere Version von SumUp Terminal, vor 2.0</summary>

Versionen vor 2.0 haben keine Kachel im Zahlungsbereich. Das Zahlungsgateway befindet sich auf dem Reiter **Legacy**, auf einer eigenen Zahlungsseite mit **Neue Zahlung starten**, **Zahlung abbrechen** und **Zahlungsstatus**, und funktioniert nur mit einem Solo über die Cloud. Aktualisieren Sie auf 2.0, um die Kachel und Bluetooth-Kartenleser zu nutzen.

</details>

## Offline-Zahlungen {#offline-payments}

WCPOS 2.0 nimmt keine SumUp-Kartenzahlungen an, solange die Kasse offline ist. Dies gilt für alle Kartenleser, unabhängig von der Einstellung **Offline-Kartenzahlungen** des Zahlungsgateways.{/* pending: monorepo#3387 */} Ohne Verbindung wird die SumUp-Kachel unter **… derzeit nicht verfügbar** mit **Verbindung erforderlich** aufgeführt. Nehmen Sie die Zahlung in bar entgegen oder warten Sie, bis die Verbindung wiederhergestellt ist; siehe [Offline-Modus](../../getting-started/offline.mdx#take-payment-offline).

Offline-Kartenzahlungen stehen auf der [Roadmap](../../getting-started/roadmap.mdx).

<Anchor id="solo-wont-pair" />

**Der Solo lässt sich nicht koppeln.** Verwenden Sie einen SumUp Solo: Er ist der einzige Kartenleser, der sich über die Cloud koppeln lässt. Ein Bluetooth-Kartenleser wird stattdessen über die WCPOS-App verbunden. Prüfen Sie, ob der Solo online und von SumUp abgemeldet ist und den Code unter **Verbindungen → Cloud API** anzeigt. Geben Sie den Code genau wie angezeigt ein.

<Anchor id="only-app-readers" />

**„Für diese Zahlungsart sind nur Kartenleser der App zulässig.“** Die Kasse läuft im Browser oder in der Desktop-App, und **POS-Verbindung** ist auf **Bluetooth-Kartenleser** eingestellt. Nehmen Sie die Zahlung in der iOS- oder Android-App entgegen oder lassen Sie einen Administrator **POS-Verbindung** auf **Solo über die Cloud** einstellen und [einen Solo koppeln](#pairing). Der Link **Probleme?** in der Zeile öffnet die Seite [Kartenleser](../../hardware/card-readers/index.mdx).

<Anchor id="needs-a-connection" />

**Die SumUp-Kachel ist offline nicht verfügbar.** Kartenleser warten auf die Verbindung; siehe [Offline-Zahlungen](#offline-payments).

<Anchor id="no-card-readers" />

**„Für diese Filiale sind keine Kartenleser eingerichtet“.** Das Zahlungsgateway ist noch nicht [eingerichtet](#setup), daher erscheint unter **Kartenleser** nur diese Meldung:

<JourneyShot manifest={manifest} device="tablet" step={1} maxWidth={720} alt="Einstellungen mit ausgewähltem Bereich Kartenleser an einer Kasse, für deren Filiale noch keine Kartenleser eingerichtet sind">

1. **Für diese Filiale sind keine Kartenleser eingerichtet** — schließen Sie [Zahlungsgateway einrichten](#setup) ab und [verbinden Sie anschließend den Kartenleser](#card-readers).

</JourneyShot>

Mit **Solo über die Cloud** werden Ihre gekoppelten Solos auf der Seite **Kartenleser** unter **Smarte Kartenleser** aufgeführt, nicht als SumUp-Eintrag.

<Anchor id="no-terminals" />

**„Keine Terminals für SumUp Terminal eingerichtet“.** Es ist kein Solo gekoppelt, oder unter **Aktivierte Terminals** ist keines für diese Kasse verfügbar. Siehe [Einen Solo über die Cloud koppeln](#pairing).

<Anchor id="payment-wont-start" />

**Die Zahlung startet nicht.** Öffnen Sie die Seite des Zahlungsgateways in WP Admin. Dort sollte **Mit SumUp verbunden** stehen. **Verbindung fehlgeschlagen** bedeutet, dass der **SumUp-API-Schlüssel** falsch oder nicht mehr aktiv ist. Prüfen Sie, ob der Solo eingeschaltet, aufgeladen und online ist und unter **Konfigurierte Kartenleser** aufgeführt wird.

<Anchor id="affiliate-key" />

**„Ein Filialadministrator muss einen SumUp-Affiliate-Schlüssel eingeben…“.** Dem Zahlungsgateway fehlt der **Affiliate-Schlüssel**, den ein Bluetooth-Kartenleser benötigt. Siehe [Zahlungsgateway einrichten](#setup), Schritt 3.

<Anchor id="card-declined" />

**Die Karte wird abgelehnt.** Bitten Sie um eine andere Karte oder eine andere Zahlungsart.

**Sie kommen nicht weiter?** Aktivieren Sie **Checkout-Debug-Protokolle** und lesen Sie die Zahlungsaktivitäten unter `WooCommerce > Status > Protokolle`, melden Sie einen Fehler auf [GitHub](https://github.com/wcpos/sumup-terminal-for-woocommerce/issues) oder wenden Sie sich bei Fragen zu Ihrem Konto oder Kartenleser an den SumUp-Support.
