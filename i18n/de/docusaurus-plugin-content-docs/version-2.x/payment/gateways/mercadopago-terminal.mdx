# Zahlungsgateway Mercado Pago Terminal {#mercado-pago-terminal-gateway}

Mercado Pago Terminal sendet einen Verkauf von der Kasse an ein Mercado Pago **Point**-Terminal. Der Kunde bezahlt am Terminal, und die Kasse erfasst die Zahlung, sobald Mercado Pago sie bestätigt.

Diese Seite beginnt an der Kasse. Filialadmins: Unter [Mercado Pago Terminal einrichten](#setup) erfahren Sie mehr über Zugriffstoken, Webhook und Terminals sowie darüber, wie Sie die Einrichtung überprüfen.

:::info Pro-Funktion
Für Mercado Pago Terminal benötigen Sie [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0 oder neuer sowie Version 1.0 oder neuer der Erweiterung.
:::

:::warning Filialadmins: Führen Sie zuerst eine Testzahlung durch
**Version 1.0 wurde noch nicht mit einem echten Point-Terminal oder einem Mercado-Pago-Konto eingesetzt.** Bevor Sie die Karte eines Kunden belasten, nehmen Sie eine kleine Zahlung mit Ihrer eigenen Karte entgegen und erstatten Sie sie.

<details>
<summary>Was getestet wurde und was nicht</summary>

Version 1.0 wurde mit einem Ersatzsystem getestet, das anhand der Dokumentation von Mercado Pago erstellt wurde. Mit Version 0.1 wurden auf einem Live-Konto und einem echten Point Smart die Terminals aufgelistet, eines in den PDV-Modus versetzt sowie eine Zahlung erstellt und abgebrochen. Mit keiner der beiden Versionen wurden bisher eine bezahlte Kartenzahlung, eine Ablehnung, ein Abbruch am Terminal, Benachrichtigungen von Mercado Pago, Rückerstattungen oder die Sandbox von Mercado Pago getestet.

</details>
:::

## Kartenzahlung entgegennehmen {#take-payment}

:::note Öffnen Sie zuerst die Kasse
Wenn **Kasse öffnen und schließen** aktiviert ist, erfasst die Kasse bei geschlossener Kasse keine Zahlung. Eine bereits entgegengenommene Kartenzahlung müsste dann erstattet werden. Informationen zur Einstellung finden Sie unter [Kassen](../../settings/wp-admin/registers.mdx#one-register).
:::

1. Drücken Sie im Warenkorb auf **Kasse** und tippen Sie im Tab **Zahlungen** auf die Kachel **Mercado Pago Terminal**. Möglicherweise hat Ihre Filiale der Kachel einen anderen Namen gegeben.
2. Sehen Sie oberhalb des Tastenfelds nach. Wenn **Terminal auswählen** angezeigt wird, tippen Sie auf das Terminal an Ihrer Kasse. Wenn **Terminal:** mit einem Namen angezeigt wird, verwendet diese Kasse dieses Terminal. Drücken Sie **Ändern**, um ein anderes auszuwählen. Die Kasse merkt sich Ihre Auswahl.
3. Um einen Teil des offenen Betrags mit der Karte zu bezahlen, geben Sie den Betrag ein. Der Rest bleibt für eine weitere Zahlung offen. Mit **Gesamter Restbetrag** wird der gesamte offene Betrag in das Feld eingetragen.
4. Drücken Sie **An Mercado Pago Terminal senden …**. Auf der Kasse wird **Warten auf den Kunden am Terminal** angezeigt.
5. Der Kunde bezahlt am Terminal. Sobald das Geld eingegangen ist und kein Betrag mehr offensteht, wird der Beleg geöffnet. Ist noch ein Betrag offen, nehmen Sie ihn mit einer anderen Kachel entgegen.

<details>
<summary>Was die Schritte auf der Kasse bedeuten</summary>

Während die Zahlung läuft, leuchtet die Kasse nacheinander **Gesendet**, **Am Terminal** und **Eingezogen** auf. **Eingezogen** bedeutet, dass das Geld eingezogen wurde. **Genehmigt** bleibt bei Mercado Pago dunkel, da das Geld in einem Schritt eingezogen wird.

</details>

Das Terminal druckt keinen Beleg. Drucken Sie den POS-Beleg wie gewohnt oder senden Sie ihn per E-Mail. Siehe [Belege im Checkout](../../receipts/at-checkout.mdx). Am Terminal kann kein Trinkgeld gegeben werden.

### Zahlung abbrechen {#cancel}

Drücken Sie an der Kasse **Am Terminal abbrechen**. Das funktioniert nur, bis die Zahlung auf dem Bildschirm des Terminals erscheint. Sobald der Kunde sie sehen kann, lässt sie sich an der Kasse nicht mehr zurücknehmen:

1. Wenn der Kunde den Betrag bereits sehen kann, **brechen Sie die Zahlung direkt am Mercado-Pago-Terminal ab** oder bitten Sie den Kunden, nicht zu bezahlen.
2. Warten Sie auf die Kasse. Während der Prüfung wird möglicherweise **Wird abgebrochen — auf Bestätigung des Terminals warten** angezeigt. Der Kunde kann weiterhin bezahlen, bis das Terminal die Zahlung abbricht. Nehmen Sie daher bis dahin keine andere Zahlung entgegen.
3. Sobald das Terminal die Zahlung abbricht, zeigt die Kasse **Zahlung abgebrochen** an. Bricht niemand die Zahlung ab, verwirft Mercado Pago sie nach 5 Minuten und die Kasse zeigt **Zahlung fehlgeschlagen: Zeitüberschreitung am Terminal** an.

Wenn die Kasse stattdessen **Release this payment** anbietet, drücken Sie erst darauf, nachdem eine Filialleitung Mercado Pago geprüft hat. Siehe [Die Kasse bietet Release this payment an](#other-messages) unter Weitere Meldungen.

## Wenn etwas schiefgeht {#goes-wrong}

### Wenn der Kunde möglicherweise bezahlt hat {#may-have-paid}

:::warning Nehmen Sie die Zahlung nicht erneut entgegen
In diesen Fällen wurde die Karte möglicherweise bereits belastet. Eine Filialleitung prüft zuerst Ihr Mercado-Pago-Konto. Dort wird die Zahlung als **Order #** mit der Bestellnummer aufgeführt.
:::

**Die Karte wurde belastet, aber die Bestellung nicht abgeschlossen.** Mercado Pago hat das Geld eingezogen, aber die Kasse konnte die Bestellung nicht abschließen. Belasten Sie die Karte nicht erneut. Laden Sie die App neu; die Kasse versucht dann, den Verkauf abzuschließen. Ist die Bestellung weiterhin offen, schließt eine Filialleitung sie ab. Siehe [Karte belastet, Bestellung nicht abgeschlossen](../../pos/checkout/troubleshooting.mdx#card-charged-order-open).

**Zahlung fehlgeschlagen: Das Terminal hat einen anderen Betrag bestätigt.** Das Terminal hat einen anderen Betrag als den von der Kasse gesendeten eingezogen. Deshalb hat die Kasse ihn nicht erfasst, die Karte wurde möglicherweise aber belastet. Bitten Sie eine Filialleitung, die Zahlung in Mercado Pago zu suchen und mit der Bestellung abzugleichen.

**Die Kasse wurde während einer Zahlung geschlossen oder hat die Verbindung verloren.** Senden Sie die Zahlung nicht erneut von einer anderen Kasse. Wenn Ihre Filialadmin den [Webhook](#webhook) eingerichtet hat, erfasst Ihre Filiale die Zahlung auch bei geschlossener Kasse. Öffnen Sie die Bestellung. Wird sie weiterhin als unbezahlt angezeigt, prüft eine Filialleitung Mercado Pago, bevor Sie die Zahlung erneut entgegennehmen.

Freigeben bedeutet nicht, dass die Zahlung abgebrochen wurde: Drücken Sie nur darauf, wenn eine Filialleitung Ihr Mercado-Pago-Konto geprüft und festgestellt hat, dass für die Bestellung keine genehmigte Zahlung vorliegt. Danach kann die Bestellung auf andere Weise bezahlt werden.

  - **Verbindung erforderlich** — Die Kasse ist offline. Eine Terminalzahlung läuft über Ihre Filiale. Nehmen Sie daher eine andere Zahlungsart entgegen oder warten Sie, bis die Verbindung wiederhergestellt ist.
  - **Keine Terminals für Mercado Pago Terminal eingerichtet** — Keines Ihrer Terminals befindet sich im **PDV**-Modus. Eine Filialleitung [stellt die Terminals auf PDV um](#terminals).
  - **Keine Kachel vorhanden** — Für das Zahlungsgateway ist kein Zugriffstoken hinterlegt oder es ist in WCPOS nicht aktiviert. Eine Filialleitung prüft [die Einrichtung](#setup).

## Mercado-Pago-Zahlung erstatten {#refunds}

Eine Rückerstattung wird über Mercado Pago auf die Karte des Kunden zurückgebucht, entweder vollständig oder teilweise.

1. Öffnen Sie im POS die Rückerstattung der Bestellung. Siehe [Rückerstattungen](../../pos/refunds.mdx).
2. Wählen Sie **An Mercado Pago Terminal zurückerstatten** und drücken Sie **Rückerstattung verarbeiten**.
3. Ihre Filiale fordert die Rückerstattung bei Mercado Pago an und fügt das Ergebnis den Bestellnotizen hinzu.

Eine Rückerstattung in WP Admin über die WooCommerce-Schaltfläche **… über Mercado Pago Terminal zurückerstatten** funktioniert genauso. Verkäufe aus Version 0.1 lassen sich ebenfalls auf diese Weise erstatten.

<Accordion>
  <AccordionItem question="Eine Rückerstattung bleibt ausstehend">

  Mercado Pago hatte die Rückerstattung bei der Antwort noch nicht abgeschlossen, und Ihre Filiale aktualisiert sie möglicherweise nicht automatisch. Suchen Sie die Rückerstattung in Ihrem Mercado-Pago-Konto, bevor Sie sie erneut ausführen: Wenn sie durchgeführt wurde, hat der Kunde sein Geld bereits erhalten.

  </AccordionItem>
  <AccordionItem question="Mercado Pago lehnt die Rückerstattung ab">

  Manche Kartenanbieter erlauben Rückerstattungen nur am Terminal. Führen Sie die Rückerstattung am Point-Terminal oder in Ihrem Mercado-Pago-Konto durch und erfassen Sie sie anschließend in WooCommerce mit **… manuell zurückerstatten**.

  </AccordionItem>
  <AccordionItem question="Ich habe die Rückerstattung am Terminal oder in Mercado Pago durchgeführt">

  Ihre Filiale wird über dort durchgeführte Rückerstattungen nicht informiert, daher zeigt die Bestellung weiterhin den vollen Zahlungsbetrag an. Erfassen Sie die Rückerstattung in WooCommerce mit **… manuell zurückerstatten**, damit das Geld nicht zweimal zurückgebucht wird.

  </AccordionItem>
</Accordion>

## Mercado Pago Terminal einrichten {#setup}

Eine Filialadmin erledigt dies einmal pro Filiale in WP Admin und wählt danach an jeder Kasse ein Terminal aus. Ihre Filiale erreicht jedes Terminal über Mercado Pago und das Internet. Es ist daher keine Kopplung erforderlich, und jede Kasse kann jedes Ihrer Terminals verwenden.

### Voraussetzungen {#requirements}

<RequirementsList>
  <RequirementItem label="Mercado Pago-Konto">Ein Verkäuferkonto mit Point und eine Anwendung unter **Your integrations** mit dem zugehörigen Zugriffstoken</RequirementItem>
  <RequirementItem label="Terminal">Ein Mercado-Pago-Point-Terminal, zum Beispiel ein Point Smart, das mit demselben Konto angemeldet ist</RequirementItem>
  <RequirementItem label="Währung">Die Währung Ihrer Filiale muss mit der Währung Ihres Mercado-Pago-Kontos übereinstimmen. Es findet keine Umrechnung statt.</RequirementItem>
  <RequirementItem label="WCPOS">WCPOS Pro 2.0 oder neuer sowie Version 1.0 oder neuer der Erweiterung</RequirementItem>
  <RequirementItem label="Server">WordPress 6.0 oder neuer, WooCommerce und PHP 7.4 oder neuer. Ihre Website muss für den Webhook über das Internet erreichbar sein.</RequirementItem>
</RequirementsList>

Wenn Ihre Währung keine Centbeträge kennt, wie etwa der chilenische Peso, setzen Sie **Anzahl der Dezimalstellen** unter `WooCommerce > Einstellungen > General` auf **0**. Mercado Pago lehnt bei diesen Konten Beträge mit Dezimalstellen ab.

### Erweiterung installieren {#install}

Öffnen Sie `WP Admin > POS > Einstellungen > Erweiterungen`, suchen Sie **Mercado Pago Terminal for WooCommerce**, installieren und aktivieren Sie die Erweiterung. Sie benötigen Version 1.0 oder neuer; Version 0.1 ist für WCPOS vor Version 2.0 vorgesehen. Siehe [Erweiterungen](../../extensions/index.mdx#installing-an-extension).

Sie können auch die **Plugin-ZIP-Datei** (nicht die ZIP-Datei mit dem Quellcode) von der [GitHub-Releases-Seite](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases) unter `Plugins > Add Plugin > Plugin hochladen` hochladen.

Ohne WCPOS Pro 2.0 zeigt WP Admin *Mercado Pago Terminal requires WooCommerce POS Pro 2.0 or newer.* an, und das Zahlungsgateway wird nicht hinzugefügt.

### Zugriffstoken eingeben {#credentials}

Melden Sie sich mit Ihrem Verkäuferkonto bei **Mercado Pago Developers** an und öffnen Sie **Your integrations**. Erstellen Sie eine Anwendung, falls noch keine vorhanden ist, und öffnen Sie sie. Kopieren Sie unter **Production credentials** das **Access token**: Es beginnt mit `APP_USR-`. Dieses Token ist für echte Zahlungen vorgesehen. Das Token unter **Test credentials** ermöglicht nur den Zugriff auf die Sandbox von Mercado Pago, die mit dieser Erweiterung noch nicht getestet wurde.

Öffnen Sie anschließend `WP Admin > WooCommerce > Einstellungen > Zahlungen` und dann **Mercado Pago Terminal**.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[80, 0], [410, 0], [850, 0], [410, 0], [410, 0], [410, 0]]} maxWidth={720} alt="WP Admin, Einstellungen von Mercado Pago Terminal: Enable nicht angekreuzt, Title Mercado Pago Terminal, die Standard-Description, Mode Test sowie leere Felder für Access token und Webhook secret">

1. **Enable** — Lassen Sie das Kästchen frei. Damit wird das Zahlungsgateway im Onlineshop angeboten; der POS verfügt über [einen eigenen Schalter](#enable).
2. **Title** — Der Name der Kachel an der Kasse.
3. **Description** — Wird unter dem Titel auf der Zahlungsseite der Filiale angezeigt.
4. **Mode** — Hier wird der Standardwert **Test** angezeigt. Stellen Sie ihn auf **Live**. Der Hinweis darunter ist veraltet: Ob Zahlungen echt sind, hängt vom Zugriffstoken ab, nicht von **Mode**.
5. **Access token** — Fügen Sie hier Ihr Produktionstoken ein. Nach dem Speichern bleibt das Feld leer. Lassen Sie es leer, um das gespeicherte Token beizubehalten.
6. **Webhook secret** — Lassen Sie das Feld vorerst leer. Sie füllen es aus, wenn Sie [den Webhook hinzufügen](#webhook).

</JourneyShot>

Klicken Sie auf **Save changes**.

### Webhook hinzufügen {#webhook}

Über den Webhook kann Mercado Pago Ihrer Filiale sofort mitteilen, wenn eine Zahlung abgeschlossen ist. Zahlungen funktionieren auch ohne ihn, weil Kasse und Filiale weiterhin bei Mercado Pago nachfragen. Richten Sie ihn dennoch ein, damit eine bezahlte Bestellung auch dann abgeschlossen wird, wenn die Kasse geschlossen wurde.

1. Kopieren Sie die Webhook-URL aus der Beschreibung unter **Webhook secret**. Sie endet auf `wp-json/wcpos/v2/payments/webhook?provider=mercadopago`.
2. Öffnen Sie in Mercado Pago Developers **Your integrations**, Ihre Anwendung und anschließend **Webhooks**. Fügen Sie die URL hinzu und wählen Sie das Ereignis **Order (Mercado Pago)** aus.
3. Kopieren Sie die von Mercado Pago angezeigte **secret signature**, fügen Sie sie unter **Webhook secret** ein und klicken Sie auf **Save changes**.

Ihre Filiale lehnt jede Benachrichtigung ab, die nicht mit diesem Geheimnis signiert wurde. Ohne Geheimnis hat ein Webhook daher keine Wirkung.

### Terminals auf PDV umstellen {#terminals}

Point-Terminals werden im Modus **STANDALONE** ausgeliefert, in dem sie keine Zahlungen von einer Kasse entgegennehmen können. Beim Checkout werden nur Terminals im Modus **PDV** angeboten.

1. Melden Sie sich auf jedem Terminal mit demselben Mercado-Pago-Konto an, falls noch nicht geschehen.
2. Laden Sie die Einstellungsseite von Mercado Pago Terminal neu. Unter **Mercado Pago diagnostics** werden in einer Tabelle alle Terminals mit ihrer **ID**, ihrem Namen (**Terminal**) und ihrem **Mode** aufgeführt.
3. Klicken Sie bei jedem Terminal im Modus **STANDALONE** auf **Switch to PDV** und **starten Sie das Terminal anschließend neu**. Mercado Pago benötigt den Neustart.

Die Tabelle führt bis zu 50 Terminals auf.

### In WCPOS aktivieren {#enable}

Öffnen Sie `WP Admin > POS > Einstellungen > Checkout`, suchen Sie **Mercado Pago Terminal** in der Tabelle **Gateways** und schalten Sie **Enabled** ein. Diese Seite speichert Änderungen automatisch; es gibt keine Schaltfläche zum Speichern.

<JourneyShot manifest={manifest} device="desktop" step={2} offsets={[[172, 0], [-26, 0]]} maxWidth={720} alt="WP Admin, POS-Einstellungen, Checkout: drei Zeilen der Gateways-Tabelle, Cash on delivery, Mercado Pago Terminal und Mollie Terminal, alle ausgeschaltet">

1. **Mercado Pago Terminal** — Die Zeile der Erweiterung in der Tabelle **Gateways**.
2. **Enabled** — Der Schalter neben der Gateway-ID. Schalten Sie ihn ein. Nach dem Neuladen wird an der Kasse die Kachel **Mercado Pago Terminal** angezeigt.

</JourneyShot>

Lassen Sie **Enable** auf der WooCommerce-Einstellungsseite ausgeschaltet. Der POS verwendet das Zahlungsgateway, sobald **Enabled** hier eingeschaltet ist, unabhängig davon, ob jenes Kästchen angekreuzt ist. Siehe [Checkout-Einstellungen](../../settings/wp-admin/checkout.mdx#enabling-a-gateway).

### Terminal für jede Kasse auswählen {#till-terminal}

Öffnen Sie an jeder Kasse **Settings > Card readers**. Ihre Terminals werden unter **Smart readers** mit den von Mercado Pago vergebenen Namen aufgeführt. Ein Terminal mit der Markierung **Offline** wurde noch nicht umgestellt. Siehe [Terminals auf PDV umstellen](#terminals). Drücken Sie beim Terminal an dieser Kasse auf **Use this reader**. In der Zeile wird **Selected** angezeigt. Der Kassierer kann beim Checkout weiterhin auf **Change** drücken.

Wenn nur ein Terminal im PDV-Modus ist, gibt es nichts auszuwählen: Es ist bereits an jeder Kasse **Selected**. Siehe [Smart Reader auswählen](../../hardware/card-readers/index.mdx#smart-readers).

### Einrichtung überprüfen {#check}

1. Auf der Einstellungsseite von Mercado Pago Terminal wird unter **Mercado Pago diagnostics** eine Meldung angezeigt:

   > Zugangsdaten akzeptiert. Starten Sie das Terminal nach der Umstellung auf PDV neu.

   Das bedeutet, dass Mercado Pago das Zugriffstoken akzeptiert hat. Wird *Mercado Pago access token is missing.* angezeigt, ist kein Token gespeichert. Jeder andere Text ist die Antwort von Mercado Pago auf das Token.
2. Bei jedem Terminal, das Sie verwenden möchten, wird unter **Mode** **PDV** angezeigt.
3. Laden Sie an einer Kasse den POS neu und drücken Sie auf **Checkout**. Die Kachel **Mercado Pago Terminal** wird als Zahlungsmöglichkeit angezeigt; die Terminals stehen oberhalb des Tastenfelds.
4. Nehmen Sie eine kleine Zahlung mit Ihrer eigenen Karte entgegen und erstatten Sie sie anschließend.

### Upgrade von Version 0.1 {#upgrade}

- Aktualisieren Sie zuerst WCPOS, WCPOS Pro und die App auf 2.0 und danach die Erweiterung.
- **Fügen Sie den neuen Webhook** und sein Geheimnis hinzu. Siehe [Webhook hinzufügen](#webhook). Die Webhook-Adresse aus Version 0.1 ist nicht mehr gültig, und Benachrichtigungen ohne Signatur werden abgelehnt.
- Eine während des Upgrades laufende Zahlung wird übernommen. Es wird nichts doppelt abgebucht.
- Diese Einstellungen aus Version 0.1 gibt es nicht mehr: **Default terminal**, **Enabled terminals**, **Lock terminal selection**, **Checkout debug logs** und **Log level**. Die Kassen wählen ihr Terminal jetzt unter **Settings > Card readers** aus.
- **Mode** legt die Umgebung nicht mehr fest. Prüfen Sie, ob das gespeicherte Zugriffstoken das gewünschte ist.
- Die Zahlung wird jetzt im Tab **Payments** abgewickelt. Der Tab **Store checkout** funktioniert weiterhin, aber nur für den gesamten Restbetrag.
- Verkäufe aus Version 0.1 lassen sich wie gewohnt erstatten. Siehe [Mercado-Pago-Zahlung erstatten](#refunds).

## Einstellungsreferenz {#settings}

Unter `WP Admin > WooCommerce > Einstellungen > Zahlungen > Mercado Pago Terminal`:

| Einstellung | Funktion |
|---|---|
| **Enable** | Bietet das Zahlungsgateway beim Checkout Ihres Onlineshops an. Lassen Sie es ausgeschaltet; der POS verfügt unter `POS > Einstellungen > Checkout` über einen eigenen Schalter |
| **Title** | Der Name der Kachel an der Kasse. Standardmäßig `Mercado Pago Terminal` |
| **Description** | Standardmäßig `Pay in person on a Mercado Pago Point terminal.` |
| **Mode** | **Test** (Standard) oder **Live**. Stellen Sie den Wert passend zu einem Produktionstoken auf **Live**. Der Wert dient nur als Kennzeichnung: Unabhängig von der Beschreibung des Feldes bestimmt das Zugriffstoken, ob Zahlungen echt sind |
| **Access token** | Mercado Pago Developers → **Your integrations** → Ihre Anwendung → **Production credentials**. Nach dem Speichern wird es nicht mehr vollständig angezeigt, sondern nur mit den letzten Zeichen. Lassen Sie das Feld leer, um es beizubehalten. Schließen Sie offene Zahlungen ab, bevor Sie es ersetzen |
| **Webhook secret** | Die geheime Signatur des Webhooks Ihrer Anwendung in Mercado Pago. Die Beschreibung zeigt die Webhook-URL Ihrer Filiale. Wird wie das Token gespeichert und angezeigt |

## Protokolle und Support-Paket {#logs-and-support-bundle}

Am Ende der Einstellungsseite befinden sich das Support-Paket, die Diagnosezeile und ein Link zu den Protokollen.

<JourneyShot manifest={manifest} device="desktop" step={3} offsets={[[260, 0], [80, 0], [-20, 0]]} maxWidth={720} alt="WP Admin, Ende der Einstellungen von Mercado Pago Terminal in einer noch nicht eingerichteten Filiale: Support-Paket mit Schaltfläche Download support bundle, Mercado Pago diagnostics mit der Meldung Mercado Pago access token is missing und View logs">

1. **Diagnosezeile** — In dieser noch nicht eingerichteten Filiale wird *Mercado Pago access token is missing.* angezeigt. Bei Ihnen sollte *Credentials accepted.* mit den darunter aufgeführten Terminals stehen.
2. **View logs** — Öffnet `WooCommerce > Status > Protokolle`, Quelle `mercadopago-terminal`.
3. **Download support bundle** — Eine Datei für den WCPOS-Support.

</JourneyShot>

Die Protokolle erfassen jede Anfrage an Mercado Pago und die jeweilige Antwort. Token und Kartennummern werden entfernt.

Wenn bei einer Zahlung ein Problem auftritt, klicken Sie auf **Download support bundle** und senden Sie die Datei zusammen mit der **Bestellnummer** an den WCPOS-Support. Diese Schaltfläche wird von WCPOS Pro hinzugefügt. Das Paket enthält Informationen zu allen POS-Zahlungsanbietern Ihrer Website; Geheimnisse und Kartennummern werden entfernt. Außerdem wird angegeben, wann Ihre Filiale zuletzt einen signierten Webhook empfangen hat.

## Was nicht unterstützt wird {#scope-and-limitations}

- Trinkgeld sowie Autorisierung jetzt und Einzug zu einem späteren Zeitpunkt.
- Einen Beleg am Terminal drucken.
- Zahlungen an Terminals im Modus **STANDALONE** entgegennehmen.
- Rückerstattungen erfassen, die am Terminal oder in Mercado Pago durchgeführt wurden.
- Währungen umrechnen: Die Filiale und das Mercado-Pago-Konto müssen dieselbe Währung verwenden.
- Mehr als 50 Terminals pro Konto.
- In WP Admin ein filialesweites Standardterminal festlegen oder die Terminals beschränken, die Kassen verwenden dürfen. Jede Kasse wählt ihr Terminal selbst aus.
- HPOS (die Bestelltabellen von WooCommerce): Die Erweiterung deklariert dafür noch keine Unterstützung.

<details>
<summary>Funktionsweise für Entwickler</summary>

Das Zahlungsgateway verwendet die **Orders API** von Mercado Pago für Point (`POST /v1/orders` with `type: point`) über die Zahlungsanbieter von WCPOS Pro. Bei jeder Zahlung wird in Mercado Pago eine Bestellung über den an der Kasse angegebenen Betrag erstellt. Sie enthält die Terminal-ID, `print_on_terminal: no_ticket`, eine externe Referenz für die Zahlung und einen Idempotenzschlüssel, damit ein erneuter Versuch keine doppelte Abbuchung verursacht. Die Bestellung läuft nach 5 Minuten ab (Filter `mptfwc_order_expiration_time`).

Die Kasse fragt den Status alle 2 Sekunden ab. Der Webhook `wp-json/wcpos/v2/payments/webhook?provider=mercadopago` muss eine gültige `x-signature` enthalten (HMAC-SHA256 mit dem Webhook-Geheimnis). Dem Inhalt des Webhooks wird niemals vertraut; stattdessen ruft die Filiale die Bestellung erneut bei Mercado Pago ab. WooCommerce POS prüft unbeantwortete Zahlungen vorsorglich alle 10 Minuten.

Die Terminals stammen aus `/terminals/v1/list`. Nur Terminals im PDV-Modus gelten als online. Die Filter `mptfwc_order_payload` und `mptfwc_poll_interval_ms` aus Version 0.1 gibt es nicht mehr.

</details>
