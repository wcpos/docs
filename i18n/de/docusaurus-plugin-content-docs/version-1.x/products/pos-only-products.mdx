Mit der Funktion „POS-Exklusive Produkte“ steuern Sie, ob Produkte in Ihrem Online-Shop, im POS oder in beiden angezeigt werden. Das ist nützlich, wenn Sie unterschiedliche Produktkataloge für den Online-Verkauf und den Verkauf in Ihrer Filiale haben.

## Übersicht {#overview}

Wenn die Funktion aktiviert ist, erhält jedes Produkt die Einstellung **POS-Sichtbarkeit** mit drei Optionen:

| Sichtbarkeit | Online-Shop | POS |
|------------|--------------|-----|
| **POS & Online** (Standardeinstellung) | Sichtbar | Sichtbar |
| **POS-Exklusiv** | Ausgeblendet | Sichtbar |
| **Online-Exklusiv** | Sichtbar | Ausgeblendet |

## Wann Sie diese Funktion verwenden sollten {#when-to-use-this-feature}

Aktivieren Sie „POS-Exklusive Produkte“ für folgende Zwecke:

- **Exklusive Produkte in der Filiale verkaufen** - Produkte, die nur beim Besuch Ihrer Filiale erhältlich sind
- **Online-exklusive Artikel im POS ausblenden** - Digitale Produkte, Vorbestellungen oder Artikel, die nicht in der Filiale verkauft werden sollen
- **Unterschiedliche Kataloge verwalten** - Getrennte Sortimente für Online-Verkauf und Einzelhandel
- **Aktionsartikel steuern** - Sonderangebote nur in der Filiale oder exklusive Online-Angebote

:::tip
Wenn alle Ihre Produkte in beiden Kanälen erscheinen sollen, benötigen Sie diese Funktion nicht. Lassen Sie sie für eine bessere Leistung deaktiviert.
:::

## Funktion aktivieren {#enabling-the-feature}

1. Gehen Sie zu **WP Admin > POS > Einstellungen > Allgemein**
2. Aktivieren Sie **„POS-Exklusive Produkte aktivieren“**
3. Speichern Sie die Änderungen

Weitere Informationen zu den allgemeinen Einstellungen finden Sie unter [WP Admin Allgemeine Einstellungen](/1.x/settings/wp-admin/general).

:::warning Auswirkungen auf die Leistung
Aktivieren Sie diese Einstellung nur, wenn Sie sie benötigen. Bei aktivierter Einstellung erfolgt bei jeder Produktanfrage eine zusätzliche Datenbankabfrage. Das kann die Leistung von Shops mit großen Katalogen beeinträchtigen.
:::

## Produktsichtbarkeit festlegen {#setting-product-visibility}

### Einzelne Produkte {#individual-products}

So legen Sie die Sichtbarkeit eines einzelnen Produkts fest:

1. Gehen Sie zu **WP Admin → Produkte** und bearbeiten Sie ein Produkt
2. Suchen Sie im Bereich **Produktdaten** nach **POS-Sichtbarkeit**
3. Wählen Sie die gewünschte Option:
   - **POS & Online** - Das Produkt erscheint überall (Standardeinstellung)
   - **POS-Exklusiv** - Das Produkt ist im Online-Shop ausgeblendet
   - **Online-Exklusiv** - Das Produkt ist im POS ausgeblendet
4. Klicken Sie zum Speichern auf **Aktualisieren**

### Massenbearbeitung {#bulk-editing}

So ändern Sie die Sichtbarkeit mehrerer Produkte gleichzeitig:

1. Gehen Sie zu **WP Admin → Produkte**
2. Wählen Sie die zu ändernden Produkte über die Kontrollkästchen aus
3. Wählen Sie im Dropdown-Menü **Massenaktionen** die Option **Bearbeiten**
4. Klicken Sie auf **Anwenden**
5. Suchen Sie im Bereich für die Massenbearbeitung das Dropdown-Menü **POS-Sichtbarkeit**
6. Wählen Sie die gewünschte Sichtbarkeitsoption
7. Klicken Sie auf **Aktualisieren**

### Variable Produkte {#variable-products}

Bei variablen Produkten können Sie die Sichtbarkeit sowohl für das übergeordnete Produkt als auch für jede einzelne Variation festlegen. So können Sie die Anzeige gezielt steuern – beispielsweise alle Variationen online anbieten, aber nur bestimmte Farben oder Größen in der Filiale.

## Auswirkungen auf den POS {#how-it-affects-the-pos}

Wenn ein Produkt auf **Online-Exklusiv** eingestellt ist:

- Es wird nicht im [Produktpanel](/1.x/pos/product-panel) angezeigt
- Es wird weder über die Suche noch durch das Scannen eines Barcodes gefunden
- Es kann im POS nicht in den Warenkorb gelegt werden

Wenn ein Produkt auf **POS-Exklusiv** eingestellt ist:

- Es wird im Shop-Katalog, auf Kategorieseiten und in der WooCommerce-eigenen Suche nicht angezeigt
- Es kann online weder in den Warenkorb gelegt noch gekauft werden
- Es wird nicht in den Produktlisten der WooCommerce REST API und Store API angezeigt

**Legen Sie außerdem die Katalogsichtbarkeit auf „Ausgeblendet“ fest.** POS-Exklusiv und die WooCommerce-Einstellung **Katalogsichtbarkeit**, die im Feld „Veröffentlichen“ direkt über der POS-Sichtbarkeit steht, sind getrennte Einstellungen. WCPOS schließt POS-exklusive Produkte aus standardmäßigen WooCommerce-Produktabfragen aus. Alles, was die WooCommerce-Katalogsichtbarkeit direkt ausliest, zeigt das Produkt jedoch weiterhin an, sofern die Katalogsichtbarkeit nicht auf **Ausgeblendet** gesetzt ist. Dazu gehören Such-Plugins wie FiboSearch oder Relevanssi, ähnliche Produkte sowie Blöcke oder Shortcodes, die Produkte anhand ihrer ID auflisten. Klicken Sie dazu neben **Katalogsichtbarkeit** im Feld „Veröffentlichen“ auf **Bearbeiten**, wählen Sie **Ausgeblendet** und klicken Sie anschließend auf **Aktualisieren**. Auch umgekehrt bleiben die Einstellungen getrennt: Wenn Sie das Produkt später wieder auf **POS & Online** oder **Online-Exklusiv** setzen, müssen Sie die Katalogsichtbarkeit selbst wieder auf **Shop und Suchergebnisse** setzen. Andernfalls bleibt das Produkt auf der Website ausgeblendet.

:::note
Wenn Sie die Sichtbarkeit eines Produkts kürzlich geändert haben und es weiterhin im POS erscheint (oder nicht erscheint), versuchen Sie eine Synchronisation. Halten Sie die Synchronisationstaste lange gedrückt und wählen Sie **„Löschen und Aktualisieren“**, um alle Produktdaten neu zu laden.
:::

### Wo POS-exklusive Produkte weiterhin sichtbar sind {#where-pos-only-products-stay-visible}

Das Ausblenden eines POS-exklusiven Produkts ist eine Regel für den Onlineshop. Das Produkt bleibt überall dort sichtbar, wo Sie den Shop verwalten, statt darin einzukaufen:

- **WP Admin**, einschließlich der Produktliste und des Produkteditors
- **WooCommerce Analytics**, sodass ein nach einer Kategorie von POS-exklusiven Produkten gefilterter Bericht deren Verkäufe zeigt
- **WP-CLI**-Befehle wie `wp wc product list`
- **Der POS selbst**

Das Produkt wird im Shop-Katalog und in der Suche, in der WooCommerce Store API für Warenkorb und Checkout auf Blockbasis, in der WooCommerce REST API (`/wc/v3/products`) sowie in darauf aufbauenden Funktionen wie Produktfeeds und Sitemaps ausgeblendet.

Entwickler können die Entscheidung für einen eigenen Kontext mit dem Filter `woocommerce_pos_hide_pos_only_products` ändern. Er erhält die Standardentscheidung und die auszuführende `WP_Query`. Geben Sie `false` zurück, damit diese Abfrage POS-exklusive Produkte berücksichtigt.

```php
add_filter( 'woocommerce_pos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

## Häufige Anwendungsfälle {#common-use-cases}

<UseCases>
  <UseCaseCard icon="gift" title="Nur in der Filiale erhältliche Geschenkkarten">

  Physische Geschenkkarten, die an der Kasse aktiviert werden müssen:

  1. Erstellen Sie das Geschenkkartenprodukt
  2. Setzen Sie die Sichtbarkeit auf **POS-Exklusiv**
  3. Die Karte erscheint nicht online, kann aber vom Personal in der Filiale verkauft werden

  </UseCaseCard>

  <UseCaseCard icon="globe" title="Online-Vorbestellungen">

  Produkte, die online vorbestellt werden können, aber noch nicht auf Lager sind:

  1. Erstellen Sie das Vorbestellprodukt
  2. Setzen Sie die Sichtbarkeit auf **Online-Exklusiv**
  3. Kunden können online vorbestellen, ohne dass das Produkt die Übersicht im POS beeinträchtigt

  </UseCaseCard>

  <UseCaseCard icon="building" title="Großhandel und Einzelhandel">

  Wenn Sie denselben WooCommerce-Shop für Großhandel und Einzelhandel nutzen:

  1. Setzen Sie reine Großhandelsprodukte auf **Online-Exklusiv** (für den B2B-Portalzugang)
  2. Setzen Sie reine Einzelhandelsprodukte auf **POS-Exklusiv**
  3. Belassen Sie reguläre Produkte auf **POS & Online**

  </UseCaseCard>
</UseCases>

## Fehlerbehebung {#troubleshooting}

<Accordion>
  <AccordionItem question="Produkte erscheinen weiterhin nach der Einstellung auf Online-Exklusiv">

  1. Öffnen Sie den POS
  2. Halten Sie die Synchronisationstaste am unteren Ende des Produktpanels lange gedrückt
  3. Wählen Sie **„Löschen und Aktualisieren“**
  4. Warten Sie, bis die Produkte neu geladen sind

  </AccordionItem>

  <AccordionItem question="Die Einstellung wird bei Produkten nicht angezeigt">

  Stellen Sie sicher, dass die Funktion aktiviert ist:

  1. Gehen Sie zu **WP Admin > POS > Einstellungen > Allgemein**
  2. Prüfen Sie, ob **„POS-Exklusive Produkte aktivieren“** ausgewählt ist
  3. Speichern Sie die Einstellungen, wenn Sie Änderungen vorgenommen haben

  </AccordionItem>

  <AccordionItem question="Ein POS-exklusives Produkt wird weiterhin auf der Website angezeigt">

  Prüfen Sie zwei Dinge:

  1. **Die Katalogsichtbarkeit ist auf „Ausgeblendet“ gesetzt.** Öffnen Sie das Produkt und prüfen Sie im Feld „Veröffentlichen“ die **Katalogsichtbarkeit**. Wenn dort nicht **Ausgeblendet** steht, klicken Sie auf **Bearbeiten**, wählen Sie **Ausgeblendet** und aktualisieren Sie das Produkt. Such-Plugins, ähnliche Produkte sowie Blöcke oder Shortcodes, die Produkte anhand ihrer ID auflisten, lesen diese WooCommerce-Einstellung statt der POS-Sichtbarkeit von WCPOS aus. Daher reicht POS-Exklusiv allein für sie nicht aus.
  2. **Die Seite ist nicht zwischengespeichert.** Ein Caching-Plugin oder CDN kann weiterhin eine Shop- oder Suchseite ausliefern, die gerendert wurde, bevor das Produkt auf POS-Exklusiv gesetzt wurde. Leeren Sie nach einer Änderung der Sichtbarkeit den Website-Cache.

  Wenn Sie das Produkt über einen direkten Link öffnen, wird seine Seite weiterhin angezeigt. So verhält sich auch die WooCommerce-eigene Sichtbarkeitseinstellung „Ausgeblendet“. Das Produkt kann auf dieser Seite nicht in den Warenkorb gelegt werden.

  </AccordionItem>

  <AccordionItem question="Analytics zeigt für eine Kategorie von POS-exklusiven Produkten „Keine Daten“ an">

  WCPOS-Pluginversionen bis einschließlich 1.10.26 wendeten die Regel für den Onlineshop auch auf WooCommerce Analytics an. Beim Filtern eines Berichts nach einer Kategorie aus POS-exklusiven Produkten wurden keine Produkte gefunden und **Keine Daten** angezeigt. Bei einer Suche nach denselben Produkten anhand des Namens wurden ihre Verkäufe hingegen angezeigt.

  Dies wurde in der ersten WCPOS-Pluginversion nach 1.10.26 behoben. Aktualisieren Sie das Plugin; Änderungen an den Produkten oder den Berichtseinstellungen sind nicht erforderlich.

  </AccordionItem>
</Accordion>
