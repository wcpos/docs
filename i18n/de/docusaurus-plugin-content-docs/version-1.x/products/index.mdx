:::info Pro-Funktion
Der Produkte-Bildschirm erfordert [WCPOS Pro](/1.x/getting-started/pro-license). Nutzer der kostenlosen Version können im [POS-Produkt-Panel](/1.x/pos/product-panel) Produkte anzeigen und in den Warenkorb legen, aber keine Bestände oder Preise bearbeiten.
:::

Der Produkte-Bildschirm ist eine eigene Oberfläche für die Bestandsverwaltung. Während das [POS-Produkt-Panel](/1.x/pos/product-panel) zum Verkaufen dient, verwalten Sie auf diesem Bildschirm Ihren Produktkatalog.

## Produkte-Bildschirm und POS-Produkt-Panel im Vergleich {#products-screen-vs-pos-product-panel}

| Funktion | POS-Produkt-Panel | Produkte-Bildschirm |
|---------|-------------------|-----------------|
| **Zweck** | Produkte in den Warenkorb legen | Bestände verwalten |
| **Bestand** | Nur anzeigen | Direkt bearbeiten |
| **Preise** | Nur anzeigen | Direkt bearbeiten |
| **Aktionen** | In den Warenkorb legen | Bearbeiten, Synchronisieren, Löschen |
| **Verfügbar in** | Kostenlos + Pro | Nur Pro |

## Übersicht der Oberfläche {#interface-overview}

### Suche & Filter {#search--filters}

Oben auf dem Bildschirm:

- **Suchleiste** - Produkte nach Name, SKU oder Barcode suchen
- **Filtertasten** - Bestandsstatus, Vorgestellt, Im Sale, Kategorie, Tag, Marke
- **Anzeigeeinstellungen** (<Icon name="sliders" />) - Sichtbare Spalten konfigurieren

### Produktliste {#product-list}

Der Hauptbereich zeigt Ihre Produkte in einer scrollbaren Tabelle an:

- **Bild** - Produktminiaturansicht
- **Produktname** - Optional mit SKU, Barcode und Attributen
- **Bestand** - Bearbeitbare Bestandsmenge mit „Verwalten“-Umschalter
- **Bestandsstatus** - Auf Lager (grün), Ausverkauft (rot), Nachbestellung
- **Kategorien** - Kennzeichnungen der Produktkategorien
- **Preise** - Aktueller Preis, regulärer Preis, Verkaufspreis (alle bearbeitbar)
- **Aktionen** - Drei-Punkte-Menü mit Bearbeiten, Synchronisieren, Löschen

:::note Sortierung und Filterung gelten für Ihren gesamten Shop
Sortierung und Filterung werden auf dem **Server** ausgeführt und gelten daher für Ihren gesamten Katalog – nicht nur für die Produkte, die bereits auf dem Gerät vorhanden sind. Sortieren Sie nach Name, SKU, Bestand, Preis oder Datum. Beim Scrollen lädt die Liste weitere Zeilen nach, bis hin zum Ende des Katalogs. Die **Suche** nach Produkten hingegen wird auf dem Gerät ausgeführt, sobald der Katalog lokal verfügbar ist, und liefert sofort Ergebnisse ohne Serveranfrage.
:::

### Variable Produkte {#variable-products}

Bei variablen Produkten werden folgende Angaben angezeigt:
- Attributoptionen (Farbe, Größe usw.)
- Link „Erweitern“ zum Anzeigen aller Variationen
- Einzelne Variationszeilen mit separaten Beständen und Preisen

### Fußzeile {#footer}

- **Steuerstatus** - Aktuelle Grundlage der Steuerberechnung
- **Produktanzahl** - „Zeigt X von Y“ mit Synchronisieren-Schaltfläche (<Icon name="arrow-rotate-right" />). Halten Sie die Synchronisieren-Schaltfläche **lange gedrückt**, um die Option Löschen und Aktualisieren aufzurufen (ab v1.10.0 werden dabei auch die Suche und die aktiven Filter des Bildschirms zurückgesetzt, sodass die Liste wieder ungefiltert angezeigt wird)

## Hauptfunktionen {#key-features}

### Bestand direkt bearbeiten {#inline-stock-editing}

Klicken Sie direkt auf die Bestandsmenge, um sie zu bearbeiten:

1. Klicken Sie auf die Bestandszahl
2. Geben Sie die neue Menge ein
3. Drücken Sie zum Speichern die Eingabetaste

Änderungen werden automatisch mit WooCommerce synchronisiert.

### Umschalter zur Bestandsverwaltung {#manage-stock-toggle}

Der Umschalter „Verwalten“ steuert, ob WooCommerce den Bestand dieses Produkts erfasst:

- **Ein** - Bestandsmengen werden erfasst und bei Verkäufen verringert
- **Aus** - Das Produkt ist immer verfügbar (unbegrenzter Bestand)

### Preise direkt bearbeiten {#inline-price-editing}

Klicken Sie auf ein beliebiges Preisfeld, um es zu bearbeiten:

- **Preis** - Aktueller Verkaufspreis
- **Regulärer Preis** - Preis ohne Rabatt
- **Verkaufspreis** - Reduzierter Preis (bei Angeboten)

### Kosten der verkauften Waren {#cost-of-goods-sold}

Mit der WooCommerce-Funktion „Kosten der verkauften Waren“ (COGS) können Sie den Einkaufspreis jedes Produkts erfassen. WCPOS zeigt diese Daten auf dem Produkte-Bildschirm an.

Um Einkaufspreise anzuzeigen, aktivieren Sie die Spalte **Kosten der verkauften Waren** in [Anzeigeeinstellungen](#display-settings) (<Icon name="sliders" />). Die Spalte zeigt den Einkaufspreis neben Ihren Verkaufspreisen an, sodass Sie die Margen auf einen Blick überprüfen können.

:::info Pro-Funktion
Nutzer von [WCPOS Pro](/1.x/getting-started/pro-license) können den Einkaufspreis direkt auf dem Produkte-Bildschirm **bearbeiten** – klicken Sie auf den Kostenwert, um ihn direkt zu aktualisieren, genau wie bei den Bestands- und Preisfeldern.
:::

:::note WooCommerce-Voraussetzung
Cost of Goods Sold muss in Ihrem WooCommerce-Shop aktiviert sein: Gehen Sie zu **WooCommerce > Settings > Advanced > Features** und aktivieren Sie die Option Cost of Goods Sold. Dies erfordert eine aktuelle Version von WooCommerce mit aktivierter Cost-of-Goods-Sold-Funktion. Details zur Einrichtung finden Sie in der WooCommerce-Dokumentation.
:::

### Produktaktionen {#product-actions}

Klicken Sie auf das Drei-Punkte-Menü (⋮) für jedes Produkt:

- **Bearbeiten** - Öffnen Sie das Produkt-Bearbeitungsmodal
- **Synchronisieren** - Aktualisieren Sie dieses Produkt von WooCommerce
- **Löschen** - Produkt aus der lokalen Datenbank entfernen

:::note
Wenn Sie ein Produkt im POS löschen, wird es nur **lokal** entfernt – in WooCommerce bleibt das Produkt erhalten und erscheint bei der nächsten Synchronisierung wieder. Wird ein Produkt **in WooCommerce** gelöscht, entfernt die Synchronisierung es auch aus dem POS, sodass Ihr Gerät mit der Filiale synchron bleibt.
:::

### Verfügbare Spalten {#available-columns}

| Spalte | Beschreibung | Anzeigeoptionen |
|--------|-------------|-----------------|
| **Bild** | Produktminiaturansicht | - |
| **ID** | WooCommerce-Produkt-ID | - |
| **Produkt** | Produktname | SKU, Barcode, Attribute |
| **Typ** | Einfach, variabel, gruppiert usw. | - |
| **SKU** | Lagerhaltungseinheit | - |
| **Barcode** | Produktbarcode | - |
| **Bestand** | Aktuelle Menge (bearbeitbar) | - |
| **Bestandsstatus** | Auf Lager / Ausverkauft / Nachbestellung | - |
| **Kategorien** | Produktkategorien | - |
| **Tags** | Produkt-Tags | - |
| **Marken** | Markeninformationen (wenn Plugin aktiv) | - |
| **Kosten der verkauften Waren** | Produkteinkaufspreis (bearbeitbar mit Pro) | - |
| **Preis** | Aktueller Verkaufspreis (bearbeitbar) | Steuerinfo |
| **Regulärer Preis** | Preis ohne Rabatt (bearbeitbar) | Steuerinfo |
| **Verkaufspreis** | Preis mit Rabatt (bearbeitbar) | Steuerinfo |
| **Erstellungsdatum** | Wann das Produkt erstellt wurde | - |
| **Änderungsdatum** | Datum der letzten Änderung | - |
| **Aktionen** | Schaltflächen zum Bearbeiten, Synchronisieren, Löschen | - |

### Standardwerte wiederherstellen {#restore-default-settings}

Klicken Sie, um alle Anzeigeeinstellungen auf ihre ursprünglichen Standardeinstellungen zurückzusetzen.

## Produkte filtern {#filtering-products}

Verwenden Sie die Filtertasten, um Ihre Ansicht einzuschränken:

- **Bestandsstatus** - Auf Lager, Ausverkauft, Nachbestellung
- **Vorgestellt** - Produkte, die als vorgestellt markiert sind
- **Im Sale** - Produkte, die derzeit im Angebot sind
- **Kategorie** - Nach Produktkategorie filtern
- **Tag** - Nach Produkt-Tag filtern
- **Marke** - Nach Marke filtern (wenn Sie das Marken-Plugin verwenden)

## Sortieren {#sorting}

Klicken Sie auf eine beliebige Spaltenüberschrift, um nach dieser Spalte zu sortieren. Klicken Sie erneut, um die Sortierreihenfolge umzukehren.
