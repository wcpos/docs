## Wiederherstellen einer vorherigen Version {#re-installing-a-previous-version}

Um zu einer früheren Version des Plugins zurückzukehren, deaktivieren Sie automatische Updates, laden die gewünschte Version herunter und laden sie über die vorhandene Version hoch. Dabei wird nichts gelöscht, sodass Ihre Bestellungen, Einstellungen und Belegvorlagen erhalten bleiben.

:::warning Löschen Sie das Plugin nicht zuerst
Laden Sie die `.zip`-Datei über das vorhandene Plugin hoch; so bleibt alles erhalten. Bei 2.0 führt das Löschen des Plugins unter **Plugins** die Bereinigung von WCPOS aus: Alle Kassierer werden abgemeldet, sodass sich jede Kasse erneut anmelden muss, und die Synchronisierungsdaten, die jede Kasse neu aufbaut, werden gelöscht. Es gibt keinen Grund, das Plugin zu löschen.
:::

Wenn Sie 2.0 verlassen, lesen Sie zuerst [Zurückwechseln](/getting-started/upgrading-to-2#rolling-back). Mit WCPOS Pro setzen Sie nur WCPOS Pro zurück. Das kostenlose Plugin ist darin enthalten.

### Automatische Updates deaktivieren {#turn-off-auto-updates}

Wenn automatische Updates aktiviert sind, installiert WordPress die neueste Version später wieder automatisch.

1. Rufen Sie **WP Admin → Plugins** auf.
2. Suchen Sie in der Zeile von WCPOS (oder WCPOS Pro) die Spalte **Automatische Updates**. Wenn dort **Automatische Updates deaktivieren** steht, klicken Sie darauf.

### Die benötigte Version herunterladen {#download}

Entpacken Sie die `.zip`-Datei nicht. WordPress installiert die `.zip`-Datei, keinen Ordner.

**WCPOS:**

1. Öffnen Sie die [erweiterte Ansicht von WCPOS](https://wordpress.org/plugins/woocommerce-pos/advanced/) auf WordPress.org.
2. Scrollen Sie zu **Erweiterte Optionen**. Wählen Sie unter **Frühere Versionen** die gewünschte Version aus.
3. Klicken Sie auf **Herunterladen**.

**WCPOS Pro:**

1. Melden Sie sich unter [wcpos.com](https://wcpos.com/account/downloads) bei Ihrem Konto an und öffnen Sie **Downloads**.
2. Suchen Sie im **Versionsverlauf** die gewünschte Version.
3. Klicken Sie in der entsprechenden Zeile auf **Herunterladen**.

Um 2.0 zu verlassen, wählen Sie die neueste Version **1.11** und keine ältere 1.x-Version.

### Die aktuelle Version überschreiben {#install}

1. Rufen Sie **WP Admin → Plugins** auf und klicken Sie oben auf der Seite auf **Plugin hinzufügen**.
2. Klicken Sie auf **Plugin hochladen**, wählen Sie die heruntergeladene `.zip`-Datei aus und klicken Sie auf **Jetzt installieren**.
3. WordPress meldet **Dieses Plugin ist bereits installiert.** und zeigt die Versionen **Aktuell** und **Hochgeladen** nebeneinander an. Prüfen Sie, ob unter **Hochgeladen** die gewünschte Version angezeigt wird.
4. Klicken Sie auf **Aktuelle Version durch hochgeladene Version ersetzen**.
5. WordPress meldet **Plugin erfolgreich herabgestuft.** Wenn die Option **Plugin aktivieren** angezeigt wird, klicken Sie darauf. Andernfalls war das Plugin bereits aktiv und bleibt aktiv.

Lassen Sie automatische Updates deaktiviert, bis Sie wieder aktualisieren möchten. Aktivieren Sie sie dann wieder, damit spätere Fehlerbehebungen automatisch installiert werden.

Wenn bei der Neuinstallation Probleme auftreten oder Sie weitere Unterstützung benötigen, wenden Sie sich an unser Supportteam unter support@wcpos.com.
