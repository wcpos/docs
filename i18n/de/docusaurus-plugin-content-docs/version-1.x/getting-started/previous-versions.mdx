## Wiederherstellen einer vorherigen Version {#re-installing-a-previous-version}

Wenn Sie zu einer vorherigen Version des WCPOS-Plugins zurückkehren müssen, befolgen Sie diese Schritte:

1. Besuchen Sie die WordPress.org-Seite [Erweiterte Ansicht](https://wordpress.org/plugins/woocommerce-pos/advanced/) für WCPOS.

2. Scrollen Sie nach unten zum Abschnitt **Erweiterte Optionen** und suchen Sie das Auswahlmenü **Frühere Versionen**.

3. Öffnen Sie das Auswahlmenü und Sie sehen eine Liste der verfügbaren Plugin-Versionen. Finden Sie die Version, die Sie installieren möchten, und klicken Sie auf die Schaltfläche **Herunterladen** daneben. Speichern Sie die heruntergeladene Datei auf Ihrem Desktop oder an einem praktischen Ort.

4. Melden Sie sich in Ihrem WordPress-Admin-Dashboard an.

5. Navigieren Sie zur Seite **Plugins**, indem Sie im linken Menü auf **Plugins** klicken.

6. Deaktivieren und löschen Sie die aktuelle Version des WCPOS-Plugins. Dadurch wird das Plugin von Ihrer WordPress-Installation entfernt. Keine Sorge, Ihre Daten gehen nicht verloren.

7. Klicken Sie auf die Schaltfläche **Plugin hinzufügen** oben auf der Seite.

8. Klicken Sie auf der Seite **Plugins hinzufügen** auf die Schaltfläche **Plugin hochladen**.

9. Wählen Sie die zuvor heruntergeladene Plugin-Datei von Ihrem Desktop oder dem Ort, an dem Sie sie gespeichert haben.

10. Klicken Sie auf die Schaltfläche **Jetzt installieren** und warten Sie, bis die Installation abgeschlossen ist.

11. Nachdem die Installation abgeschlossen ist, klicken Sie auf die Schaltfläche **Aktivieren**, um die vorherige Version des WCPOS-Plugins zu aktivieren.

Das war's! Sie haben erfolgreich eine vorherige Version des WCPOS-Plugins wiederhergestellt.

Wenn Sie während des Wiederherstellungsprozesses auf Probleme stoßen oder weitere Unterstützung benötigen, wenden Sie sich bitte an unser Support-Team unter support@wcpos.com.
