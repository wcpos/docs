## Wiederherstellen einer vorherigen Version {#re-installing-a-previous-version}

Wenn Sie zu einer vorherigen Version des WCPOS-Plugins zurückkehren müssen, befolgen Sie diese Schritte:

1. Besuchen Sie die WordPress.org-Seite [Erweiterte Ansicht](https://wordpress.org/plugins/woocommerce-pos/advanced/) für WCPOS.

2. Scrollen Sie zum Abschnitt **Erweiterte Optionen** und suchen Sie das Auswahlmenü **Frühere Versionen**.

3. Öffnen Sie das Auswahlmenü. Darin wird eine Liste der verfügbaren Plugin-Versionen angezeigt. Suchen Sie die gewünschte Version und klicken Sie daneben auf **Herunterladen**. Speichern Sie die heruntergeladene Datei auf Ihrem Desktop oder an einem anderen geeigneten Speicherort.

4. Melden Sie sich im WordPress-Admin-Dashboard an.

5. Rufen Sie die Seite **Plugins** auf, indem Sie im linken Menü auf **Plugins** klicken.

6. Deaktivieren und löschen Sie die aktuelle Version des WCPOS-Plugins. Dadurch wird das Plugin aus Ihrer WordPress-Installation entfernt. Keine Sorge: Ihre Daten gehen dabei nicht verloren.

7. Klicken Sie oben auf der Seite auf **Plugin hinzufügen**.

8. Klicken Sie auf der Seite **Plugins hinzufügen** auf **Plugin hochladen**.

9. Wählen Sie die zuvor heruntergeladene Plugin-Datei auf Ihrem Desktop oder an dem Speicherort aus, an dem Sie sie abgelegt haben.

10. Klicken Sie auf **Jetzt installieren** und warten Sie, bis die Installation abgeschlossen ist.

11. Klicken Sie nach Abschluss der Installation auf **Aktivieren**, um die vorherige Version des WCPOS-Plugins zu aktivieren.

Fertig! Sie haben erfolgreich eine vorherige Version des WCPOS-Plugins neu installiert.

Wenn bei der Neuinstallation Probleme auftreten oder Sie weitere Unterstützung benötigen, wenden Sie sich an unser Supportteam unter support@wcpos.com.
