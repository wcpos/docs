:::info Pro-Funktion
[WCPOS Pro](https://wcpos.com/pro) ist ein kostenpflichtiges Plugin, das die Verwaltungsbildschirme, zusätzliche Zahlungsgateways und weitere Pro-exklusive Funktionen in WCPOS bereitstellt.

**Ab v1.8+ ist Pro ein eigenständiges Plugin** — das kostenlose [WCPOS-Plugin](https://wordpress.org/plugins/woocommerce-pos/) muss nicht zusätzlich installiert sein.
:::

## Was ist in Pro enthalten? {#whats-included-in-pro}

WCPOS Pro schaltet zusätzliche Funktionen frei:

- **Produktbildschirm** - Lagerbestände und Preise direkt im POS bearbeiten
- **Bestellbildschirm** - Bestellverlauf anzeigen und verwalten
- **Kundenbildschirm** - Kundeninformationen hinzufügen und bearbeiten
- **Berichtsbildschirm** - Tagesabschlussberichte erstellen
- **Zusätzliche Zahlungsgateways** - Stripe Terminal, SumUp und benutzerdefinierte Gateways

## Installation {#installation}

Wenn Sie eine Lizenz für WCPOS Pro erworben haben, führen Sie die folgenden Schritte aus, um das Plugin zu installieren und zu aktivieren:

:::note Upgrade von älteren Versionen?
Wenn Sie zuvor sowohl das kostenlose WCPOS-Plugin als auch ein älteres Pro-Add-on installiert hatten, **deaktivieren und löschen Sie das kostenlose Plugin**, bevor Sie das neue eigenständige Pro-Plugin aktivieren. Der gleichzeitige Betrieb beider Plugins kann Aktivierungsfehler wie *„Invalid response fetching remote state“* oder schwerwiegende Fehler vom Typ *„Class not found“* verursachen.
:::

1. Rufen Sie folgende Seite auf: [https://wcpos.com/account/downloads](https://wcpos.com/account/downloads)
2. Klicken Sie unter **Downloads** auf den Download-Link und speichern Sie das Plugin auf Ihrem Desktop.
3. Rufen Sie dann Ihre Website auf, melden Sie sich an und öffnen Sie `WP Admin > Plugins > Add Plugin > Plugin hochladen`.
4. Laden Sie die Plugin-ZIP-Datei von Ihrem Desktop hoch und aktivieren Sie sie.
5. Öffnen Sie anschließend `WP Admin > POS > Einstellungen > License` und geben Sie Ihren Lizenzschlüssel (angezeigt auf Ihrer [Lizenzseite](https://wcpos.com/account/licenses)) sowie Ihre Lizenz-E-Mail-Adresse ein, um die Aktivierung abzuschließen.

## Updates {#updates}

Sobald neue Versionen verfügbar sind, erscheinen sie wie bei jedem anderen Plugin in Ihrem Dashboard unter „Updates“. Sie können die neueste Version auch von Ihrer [Kontoseite](https://wcpos.com/account/downloads) herunterladen.

## Pro und Ihre Daten deinstallieren {#uninstalling}

Bei der Deinstallation des Pro-Plugins werden dessen eigene Betriebsdaten entfernt. Ihre **Pro-Einstellungen (einschließlich des Lizenzschlüssels) und Ihre Filialkonfiguration bleiben jedoch erhalten**, sodass Sie nach einer Neuinstallation dort weitermachen können, wo Sie aufgehört haben. Gemeinsam genutzte Übersetzungsdaten werden erst entfernt, wenn auch das **kostenlose** Plugin deinstalliert wurde. Die alleinige Entfernung von Pro beeinträchtigt das kostenlose Plugin daher nicht.

Wenn Sie wirklich ganz von vorn beginnen und auch Einstellungen, Lizenz und Filialkonfiguration entfernen möchten, aktivieren Sie vor der Deinstallation eine vollständige Löschung, indem Sie `wcpos_remove_all_data` definieren. Ohne diese Einstellung ist die Deinstallation sicher und umkehrbar.

## Fehlerbehebung {#troubleshooting}

### Aktivierungsfehler {#activation-failures}

- **„Invalid licence key“** — achten Sie beim Einfügen auf nachgestellte Leerzeichen und prüfen Sie, ob die E-Mail-Adresse mit der beim Kauf verwendeten übereinstimmt.
- **„Licence limit reached“** — standardmäßig kann eine Lizenz auf **2 Domains** aktiviert werden (vorgesehen für eine Live-Website und eine Staging-Website). Beachten Sie, dass **Subdomains als separate Aktivierungen zählen** — `example.com`, `staging.example.com` und `dev.example.com` sind drei. Das betrifft häufig Hosting-Anbieter wie Pantheon mit obligatorischen Entwicklungs-, Test- und Live-Umgebungen. Deaktivieren Sie nicht verwendete Websites auf Ihrer [Kontoseite](https://wcpos.com/account/licenses) oder schreiben Sie an **support@wcpos.com** — zusätzliche Aktivierungen werden auf Anfrage regelmäßig gewährt.

### Abgelaufene Lizenz {#expired-licence}

- Nach Ablauf einer Lizenz bleiben die Pro-Funktionen aktiv, Sie erhalten jedoch keine Updates mehr.
- Verlängern Sie die Lizenz auf Ihrer [Kontoseite](https://wcpos.com/account/licenses) — der vorhandene Schlüssel bleibt unverändert.

### Domain-Umzüge {#domain-transfers}

- Wenn Sie Ihre Website auf eine neue Domain umgezogen haben, deaktivieren Sie zuerst die Lizenz auf der alten Domain und aktivieren Sie sie anschließend auf der neuen erneut.
- Wenn die alte Domain nicht mehr erreichbar ist, wenden Sie sich an **support@wcpos.com**, um die Aktivierung zurücksetzen zu lassen.

### Verbindung zum Lizenzserver {#licence-server-connectivity}

- Für die Aktivierung muss Ihr WordPress-Server den WCPOS-Lizenzserver erreichen können.
- Wenn die Aktivierung ohne Fehlermeldung fehlschlägt, prüfen Sie, ob ausgehende HTTPS-Anfragen durch die Firewall Ihres Hosting-Anbieters oder ein Sicherheits-Plugin blockiert werden.
- Einige Managed-Hosting-Anbieter blockieren externe API-Aufrufe standardmäßig — bitten Sie Ihren Anbieter, `wcpos.com` auf die Zulassungsliste zu setzen.

### Lizenzstatus prüfen {#checking-licence-status}

- Rufen Sie `WP Admin > POS > Einstellungen > License` auf, um den aktuellen Aktivierungsstatus anzuzeigen.
- Auf Ihrer [Kontoseite](https://wcpos.com/account/licenses) werden alle aktiven Websites und das Ablaufdatum angezeigt.

## Lizenz kaufen {#purchase-a-license}

Besuchen Sie [wcpos.com/pro](https://wcpos.com/pro), um eine Pro-Lizenz zu erwerben.

:::note Käufe und Upgrades erfolgen auf der Website
Es gibt in der App keine Schaltfläche „Upgrade auf Pro“ — Käufe, Tarif-Upgrades und Verlängerungen werden alle auf [wcpos.com](https://wcpos.com/pro) und Ihrer [Kontoseite](https://wcpos.com/account/licenses) abgewickelt. Installieren Sie Pro nach dem Kauf anhand der [obigen Schritte](#installation).
:::
