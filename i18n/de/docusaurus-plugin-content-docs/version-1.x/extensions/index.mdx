WCPOS unterstützt Erweiterungen, die Ihrer Kasse neue Funktionen hinzufügen. Im Erweiterungsverzeichnis können Sie verfügbare Erweiterungen durchsuchen, direkt über die POS-Einstellungen installieren und Updates verwalten.

:::info Pro-Funktion
Für die Installation und Verwaltung von Erweiterungen ist [WCPOS Pro](/1.x/getting-started/pro-license) erforderlich. Die kostenlose Version zeigt den Erweiterungskatalog an, die Schaltflächen zum Installieren und Aktivieren sind jedoch deaktiviert.
:::

## Erweiterungen durchsuchen {#browsing-extensions}

Öffnen Sie das Erweiterungsverzeichnis über `POS Settings > Erweiterungen` (in manchen Versionen auch als **Plugins** bezeichnet).

Das Verzeichnis zeigt die verfügbaren Erweiterungen in einem Kartenraster. Jede Karte enthält:

- **Symbol** (oder ein Puzzleteil als Platzhalter, wenn die Erweiterung keines bereitstellt)
- **Name und Version**
- **Beschreibung**
- **Kategorie-Badge**
- **Status** — aktiv, inaktiv, Update verfügbar oder nicht installiert

### Filtern und Suchen {#filtering-and-search}

Verwenden Sie die **Kategorie-Buttons** oben, um Erweiterungen nach Kategorie zu filtern. Über das **Suchfeld** können Sie Erweiterungen auch nach Name, Beschreibung oder Schlagwörtern suchen.

## Eine Erweiterung installieren {#installing-an-extension}

1. Öffnen Sie `POS Settings > Erweiterungen`.
2. Suchen Sie die gewünschte Erweiterung und klicken Sie auf **Installieren**.
3. Die Erweiterung wird über den WordPress-Plugin-Installer heruntergeladen und installiert.
4. Klicken Sie nach der Installation auf **Aktivieren**, um die Erweiterung zu aktivieren.

Im Hintergrund verwendet WCPOS die native WordPress-Klasse `Plugin_Upgrader` für die Installation. Erweiterungen durchlaufen somit denselben Prozess wie jedes andere WordPress-Plugin.

## Aktivieren und Deaktivieren {#activating-and-deactivating}

Jede installierte Erweiterung hat auf ihrer Karte die Schaltflächen **Aktivieren** und **Deaktivieren**.

- **Aktivieren** schaltet die Erweiterung ein, sodass sie im POS ausgeführt werden kann.
- **Deaktivieren** schaltet die Erweiterung ab, ohne sie zu deinstallieren. Die Erweiterungsdateien bleiben auf Ihrem Server, und die Erweiterung kann jederzeit wieder aktiviert werden.

## Erweiterungen aktualisieren {#updating-extensions}

Wenn eine neuere Version einer installierten Erweiterung verfügbar ist, zeigt die Karte ein Badge **Update verfügbar** und eine Schaltfläche **Aktualisieren**.

### Automatische Aktualisierungen {#auto-updates}

Bei Erweiterungen, die aus dem Verzeichnis installiert werden, sind **automatische Updates standardmäßig aktiviert**. Sie können automatische Updates für jede Erweiterung über deren Karte im Verzeichnis ein- oder ausschalten. Wenn automatische Updates aktiviert sind, installiert WordPress neue Versionen automatisch — genau wie bei Plugins mit aktivierten automatischen Updates.

## Fehlerbehebung {#troubleshooting}

### Meldung „Pro erforderlich“ auf Schaltflächen {#requires-pro-message-on-buttons}

Die Schaltflächen zum Installieren, Aktivieren und Aktualisieren sind in der kostenlosen Version von WCPOS deaktiviert. Führen Sie ein Upgrade auf [WCPOS Pro](/1.x/getting-started/pro-license) durch, um Erweiterungen zu verwalten.

### Erweiterung lässt sich nicht installieren {#extension-fails-to-install}

- Stellen Sie sicher, dass Ihr WordPress-Server Schreibrechte für das Verzeichnis `wp-content/plugins` hat.
- Prüfen Sie, ob Ihr Server ausgehende HTTPS-Anfragen senden kann (einige Hosting-Anbieter blockieren externe Downloads).
- Sehen Sie sich die Fehlerdetails unter `WP Admin > POS > Support > Protokolle` an.

### Erweiterung wird nach der Installation nicht angezeigt {#extension-not-appearing-after-install}

- Laden Sie den POS neu — die Erweiterungsliste wird bis zu 12 Stunden zwischengespeichert.
- Stellen Sie sicher, dass die Erweiterung aktiviert ist (installierte, aber inaktive Erweiterungen werden nicht ausgeführt).

### Katalog wird nicht geladen {#catalog-not-loading}

Der Erweiterungskatalog wird von einer externen Quelle abgerufen und lokal für 12 Stunden zwischengespeichert. Wenn der Katalog nicht geladen wird:

- Überprüfen Sie die Internetverbindung Ihres Servers.
- Versuchen Sie es nach Ablauf des Caches erneut oder leeren Sie den Transient-Cache Ihres Servers.

## Für Entwickler {#for-developers}

### Eine POS-Erweiterung erstellen {#creating-a-pos-extension}

Eine WCPOS-Erweiterung ist ein reguläres WordPress-Plugin, das über WCPOS-Hooks und APIs in den POS eingebunden wird. So erstellen Sie eine:

1. **Beginnen Sie mit einem WordPress-Plugin.** Ihre Erweiterung benötigt einen Standard-Plugin-Header und eine Einstiegsdatei, genau wie jedes WooCommerce- oder WordPress-Plugin.
2. **Integrieren Sie die Erweiterung in WCPOS.** Verwenden Sie die von WCPOS bereitgestellten Hooks und Filter, um der POS-Oberfläche oder dem Backend Funktionen hinzuzufügen.
3. **Hosten Sie Releases auf GitHub.** Das Erweiterungsverzeichnis verwendet GitHub Releases zur Versionsverfolgung und Bereitstellung von Updates.

### Einreichung im Verzeichnis {#submitting-to-the-directory}

Der Erweiterungskatalog wird im GitHub-Repository [`wcpos/extensions`](https://github.com/wcpos/extensions) gepflegt. So nehmen Sie Ihre Erweiterung auf:

1. Lesen Sie die Anforderungen an Katalogformat und Metadaten in der README des Repositorys.
2. Öffnen Sie einen Pull Request, um die Metadaten Ihrer Erweiterung zu `catalog.json` hinzuzufügen.
3. Nach dem Zusammenführen erscheint Ihre Erweiterung für alle WCPOS Pro-Nutzer im Verzeichnis.

### Konventionen für GitHub Releases {#github-release-conventions}

Der Aktualisierungsprozess basiert auf GitHub Releases:

- **Versehen Sie Versionen mit Tags** nach semantischer Versionierung (z. B. `v1.0.0`, `v1.2.3`).
- **Hängen Sie die ZIP-Datei des Plugins** als Release-Asset an — diese Datei wird heruntergeladen, wenn ein Nutzer die Erweiterung installiert oder aktualisiert.
- **Veröffentlichen Sie das Release** (nicht als Entwurf), damit das Verzeichnis es erkennen kann.

Wenn Sie ein neues Release veröffentlichen, sehen Nutzer, die Ihre Erweiterung installiert haben, das verfügbare Update in ihrem Erweiterungsverzeichnis. Bei aktiviertem automatischem Update wird es automatisch installiert.

Ausführliche Informationen zum Katalogschema und Einreichungsprozess finden Sie im Repository [`wcpos/extensions`](https://github.com/wcpos/extensions).
