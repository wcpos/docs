- Öffnet einen Dialog, um der Bestellung eine Kundennotiz hinzuzufügen.
- Kundennotizen sind für den Kunden sichtbar und erscheinen standardmäßig auf dem Beleg, im Bereich „Mein Konto“ des Kunden sowie unter `WP Admin > WooCommerce > Orders > Order` unterhalb der Versandadresse.

:::note
Bestellnotizen sind für Kunden sichtbar.
:::

- Öffnet einen Dialog zur Verwaltung zusätzlicher Meta-Daten der Bestellung.
- Zu den Funktionen gehören:
  - Ändern der Bestellwährung.
  - Hinzufügen einer Transaktions-ID (z. B. von einem externen Zahlungsterminal).
  - Hinzufügen benutzerdefinierter Meta-Daten zur Bestellung.

:::note
Dieser Dialog wird nach und nach um weitere Funktionen ergänzt, darunter die Integration mit anderen WooCommerce-Plugins.
:::

### Was sind Meta-Daten in WooCommerce? {#what-is-meta-data-in-woocommerce}

Meta-Daten enthalten zusätzliche Informationen zu Bestellungen und sind über die WooCommerce REST API zugänglich. Entwickler und Plugins nutzen diese Daten, um Funktionen zu erweitern, etwa durch die Integration von Drittanbieterdiensten.

### JSON-Ansicht {#json-view}

- Zeigt die unverarbeitete JSON-Darstellung der Bestellung an, die für die Fehlersuche oder für Integrationen nützlich ist.

## Auf Server speichern {#save-to-server}

- Ermöglicht das Speichern offener Warenkörbe auf dem Server, damit sie sicher aufbewahrt werden und später wieder zugänglich sind.
- Erstellt eine WooCommerce-Bestellung mit dem Status `pos-open`.

### Warum speichern? {#why-save}

Eine neu im POS erstellte Bestellung existiert zunächst nur lokal. 
Durch das Speichern bleibt die Bestellung erhalten, selbst wenn die lokale Datenbank geleert wird.

Weitere Informationen zur Verwaltung gespeicherter Bestellungen finden Sie unter [Offene Bestellungen](/1.x/pos/cart/open-orders).

## Stornieren {#void}

- Zwei Szenarien:
  - Ungespeicherte Bestellungen:
    - Wenn die Bestellung noch nicht auf dem Server gespeichert wurde, wird sie dauerhaft aus der lokalen Datenbank gelöscht.
  - Gespeicherte Bestellungen:
    - Wenn die Bestellung auf dem Server gespeichert ist, wird sie in WooCommerce in den Papierkorb verschoben und aus der lokalen Datenbank gelöscht.
- So stellen Sie eine stornierte Bestellung wieder her:
  - Gehen Sie zu `WP Admin > WooCommerce > Orders > Trash`.

## Kasse {#checkout}

- Speichert die Bestellung auf dem Server und startet den Checkout-Prozess.
- Öffnet den [Checkout-Bildschirm](/1.x/pos/checkout), um die Zahlung abzuschließen.
