Mit WCPOS können Sie mehrere Bestellungen gleichzeitig bearbeiten. Das ist hilfreich, wenn Sie Bestellungen für Kunden zurückstellen, zwischen Transaktionen wechseln oder nach einer Unterbrechung fortfahren möchten.

## Karussell für offene Bestellungen {#open-orders-carousel}

Am unteren Rand des Warenkorb-Panels werden alle offenen Bestellungen in einem horizontalen Karussell angezeigt:

{/* Screenshot: open-orders-carousel.png */}

- Jeder Warenkorb zeigt seinen **Gesamtbetrag**
- Die **aktuelle Bestellung** ist hervorgehoben
- Klicken Sie auf einen Warenkorb, um zu ihm zu wechseln
- Scrollen Sie nach links/rechts, um weitere Warenkörbe zu sehen

## Neue Bestellung erstellen {#creating-a-new-order}

Ein neuer leerer Warenkorb ist immer verfügbar. Klicken Sie einfach im Karussell auf einen leeren Warenkorb oder fügen Sie Produkte hinzu, wenn der aktuelle Warenkorb leer ist.

## Zwischen Bestellungen wechseln {#switching-between-orders}

Klicken Sie im Karussell auf eine Bestellung, um zu ihr zu wechseln. Das Warenkorb-Panel zeigt dann den Inhalt der ausgewählten Bestellung an.

**Anwendungsfälle:**

- Ein Kunde geht kurz weg, um einen weiteren Artikel zu holen
- Sie müssen einem Kunden mit einem kleinen Einkauf helfen, während eine umfangreiche Bestellung bearbeitet wird
- Preise oder Artikel zwischen Bestellungen vergleichen

## Bestellungen auf dem Server speichern {#saving-orders-to-server}

Bestellungen können sich in zwei Zuständen befinden:

### Nur lokal {#local-only}

Neue Bestellungen werden standardmäßig nur in der lokalen Datenbank des Browsers bzw. der App gespeichert. Sie bleiben nach dem Aktualisieren der Seite erhalten, aber:

- Sie sind nicht in der WooCommerce-Administration sichtbar
- Sie gehen verloren, wenn die lokale Datenbank gelöscht wird
- Sie sind auf anderen Geräten nicht verfügbar

### Auf dem Server gespeichert {#saved-to-server}

Klicken Sie auf **Auf Server speichern**, um eine WooCommerce-Bestellung mit dem Status `pos-open` zu erstellen. Dadurch wird:

- eine echte Bestellung in WooCommerce erstellt
- die Bestellung auch dann beibehalten, wenn die lokale Datenbank gelöscht wird
- der Zugriff von anderen Geräten ermöglicht
- die Bestellung unter WP Admin > WooCommerce > Bestellungen angezeigt

:::tip Wann speichern?
Speichern Sie Bestellungen auf dem Server, wenn:
- ein Kunde eine Bestellung zur späteren Abholung zurückstellen möchte
- Sie Ihre Schicht beenden und ein anderer Kassierer die Bestellung weiterbearbeitet
- Sie eine Sicherung für den Fall von Problemen mit der App oder dem Browser wünschen
:::

## Gespeicherte Bestellungen wiederherstellen {#recovering-saved-orders}

Wenn Sie Bestellungen auf dem Server gespeichert haben, können Sie erneut darauf zugreifen, indem Sie:

1. den Bildschirm **Bestellungen** öffnen (Pro-Funktion)
2. nach dem Status `pos-open` filtern
3. die Bestellung erneut öffnen

## Beständigkeit von Bestellungen {#order-persistence}

### Lokaler Speicher {#local-storage}

WCPOS speichert Bestellungen in der lokalen Datenbank auf dem Gerät. Das bietet:

- dauerhafte Speicherung über mehrere Browsersitzungen hinweg
- schnellen Zugriff ohne Netzwerkanfragen
- Offline-Funktionalität

### Mit dem Server synchronisieren {#sync-with-server}

Wenn Sie eine Bestellung auf dem Server speichern oder den Checkout durchführen:

- wird die Bestellung an WooCommerce gesendet
- wird eine Bestätigung empfangen
- werden die lokalen und die Serverdaten synchronisiert

## Bestellungen stornieren {#voiding-orders}

So entfernen Sie eine offene Bestellung:

1. Wechseln Sie zu der Bestellung, die Sie entfernen möchten
2. Klicken Sie auf die Schaltfläche **Stornieren**

**Was geschieht dabei?**

- **Nicht gespeicherte Bestellungen:** werden dauerhaft aus der lokalen Datenbank gelöscht
- **Gespeicherte Bestellungen:** werden in WooCommerce in den Papierkorb verschoben und lokal gelöscht

So stellen Sie eine stornierte, gespeicherte Bestellung wieder her:
1. Gehen Sie zu `WP Admin > WooCommerce > Orders > Trash`
2. Stellen Sie die Bestellung wieder her

## Tipps {#tips}

### Bestellungen übersichtlich halten {#keep-orders-organized}

Wenn mehrere Bestellungen offen sind, empfiehlt es sich:

- Kundennamen zu Bestellungen hinzuzufügen, damit sie leicht zu erkennen sind
- Bestellnotizen mit dem Grund für das Zurückstellen hinzuzufügen
- Wichtige Bestellungen auf dem Server zu speichern

### Schichtübergaben {#shift-handoffs}

Wenn Sie eine Schicht mit offenen Bestellungen beenden:

1. Speichern Sie alle wichtigen Bestellungen auf dem Server
2. Fügen Sie Bestellnotizen hinzu, die den Status erläutern
3. Der nächste Kassierer kann über den Bildschirm „Bestellungen“ darauf zugreifen

### Hinweise zum Offline-Betrieb {#offline-considerations}

Wenn die Verbindung unterbrochen wird:

- bleiben lokale Bestellungen verfügbar und Sie können weiterhin Artikel hinzufügen
- Sie können eine Bestellung mit einer offlinefähigen Zahlungsmethode abschließen; serverabhängige Zahlungsgateways bleiben nicht verfügbar, bis ihre Dienste erreichbar sind
- Sie können Bestellungen erst wieder auf dem Server speichern, wenn die Verbindung wiederhergestellt ist
- Sie können erst wieder neue Kunden anlegen, wenn die Verbindung wiederhergestellt ist
