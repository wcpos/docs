Jeder Artikel im Warenkorb ist eine Position, die direkt bearbeitet werden kann. WCPOS ermöglicht eine flexible Inline-Bearbeitung von Mengen, Preisen und anderen Details.

## Positionstypen {#line-item-types}

WooCommerce verwendet drei Positionstypen:

| Typ | Beschreibung | Beispiele |
|------|-------------|----------|
| **line_item** | Produkte aus Ihrem Katalog | T-Shirt, Kaffeetasse |
| **fee_line** | Zusätzliche Gebühren | Geschenkverpackung, Servicegebühr |
| **shipping_line** | Versandkosten | Standardversand, Expresslieferung |

:::note
Versandkosten werden manuell eingegeben. Der POS berechnet Versandtarife nicht automatisch.
:::

## Warenkorbpositionen bearbeiten {#editing-line-items}

### Menge {#quantity}

Klicken Sie auf das Mengenfeld, um es direkt zu bearbeiten. Geben Sie eine neue Zahl ein oder verwenden Sie die Pfeilschaltflächen.

{/* Screenshot: cart-line-item-edit-qty.png */}

### Produktname {#product-name}

Bei sonstigen Produkten und Gebühren können Sie den Namen direkt bearbeiten, indem Sie darauf klicken.

### Preis {#price}

Klicken Sie auf das Preisfeld, um den Stückpreis zu ändern. Dies ist nützlich für:

- Manuelles Anwenden von Rabatten
- Angleichung an Konkurrenzpreise
- Korrektur von Preisfehlern

Die Gesamtsumme wird automatisch anhand von Menge × Preis aktualisiert.

:::note Eine Preisänderung ist kein WooCommerce-„Rabatt“
Ein reduzierter Preis wird als Angebotspreis des Artikels erfasst — Belege können die Ersparnis anzeigen, aber die Bestellsumme **Rabatt** ist Gutscheinen vorbehalten, und Berichte erfassen den Verkauf zum gezahlten Preis. Unter [Warenkorbrabatte](/1.x/pos/cart/discounts#why-tracked-differently) erfahren Sie, warum WooCommerce die beiden Fälle unterschiedlich behandelt.
:::

### Drei-Punkte-Menü {#three-dot-menu}

Klicken Sie bei einer Position auf **⋮** (drei Punkte), um auf zusätzliche Optionen zuzugreifen:

{/* Screenshot: cart-line-item-menu.png */}

#### Bearbeitungsformular {#edit-form}

Öffnet ein detailliertes Bearbeitungsformular für die Position, in dem Sie alle Felder ändern können.

#### Roh-JSON-Ansicht {#raw-json-view}

Zeigt die JSON-Rohdaten der Position an. Dies ist besonders hilfreich für:

- **Debugging** - Genau sehen, welche Daten an WooCommerce gesendet werden
- **Fehlerbehebung** - Probleme mit benutzerdefinierten Feldern oder Metadaten erkennen
- **Entwicklung** - Die Datenstruktur für Integrationen verstehen

### Artikel entfernen {#remove-item}

Klicken Sie auf die rote Schaltfläche **×**, um einen Artikel aus dem Warenkorb zu entfernen.

## Variantenattribute {#variation-attributes}

Bei variablen Produkten werden die ausgewählten Variantenattribute unter dem Produktnamen angezeigt:

```
Hoodie
Colour: Green
Size: Large
```

Diese Attribute sind Teil der Positionsdaten und werden in die Bestellung übernommen.

## Metadaten {#meta-data}

Wenn Sie in den Einstellungen des Produktbereichs [Metadaten-Schlüssel](/1.x/pos/product-panel#meta-data-keys) konfiguriert haben, werden diese Daten automatisch in die Position kopiert, sobald das Produkt zum Warenkorb hinzugefügt wird.

Sie können diese Metadaten in der Roh-JSON-Ansicht anzeigen.

## Warenkorbpositionen aufteilen {#splitting-line-items}

Wenn die entsprechende Option in den [Anzeigeeinstellungen](/1.x/pos/cart#display-settings) aktiviert ist, können Sie eine Position in mehrere Zeilen aufteilen. Dies ist nützlich, wenn ein Kunde unterschiedliche Rabatte auf Teilmengen desselben Produkts anwenden möchte.

## Tipps {#tips}

### Schnelle Preisanpassungen {#quick-price-adjustments}

So gewähren Sie schnell einen Rabatt:

1. Klicken Sie auf das Preisfeld
2. Geben Sie den neuen Preis ein
3. Drücken Sie die Eingabetaste

### Tastaturnavigation {#keyboard-navigation}

- **Tab** - Zwischen bearbeitbaren Feldern wechseln
- **Enter** - Änderung bestätigen
- **Escape** - Änderung abbrechen

### Stapelbearbeitung {#batch-edits}

Bei komplexen Bestellungen können Sie über das Drei-Punkte-Menü das vollständige Bearbeitungsformular öffnen, in dem alle Felder gleichzeitig angezeigt werden.
