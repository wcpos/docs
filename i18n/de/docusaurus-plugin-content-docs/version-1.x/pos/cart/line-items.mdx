Jeder Artikel im Warenkorb ist eine Warenkorb-Position, die direkt bearbeitet werden kann. WCPOS bietet flexible Inline-Bearbeitung für Mengen, Preise und andere Details.

## Positionstypen {#line-item-types}

WooCommerce verwendet drei Typen von Warenkorb-Positionen:

| Typ | Beschreibung | Beispiele |
|------|-------------|----------|
| **line_item** | Produkte aus Ihrem Katalog | T-Shirt, Kaffeetasse |
| **fee_line** | Zusätzliche Gebühren | Geschenkverpackung, Servicegebühr |
| **shipping_line** | Versandkosten | Standardversand, Expresslieferung |

:::note
Versandkosten werden manuell eingegeben. Das POS berechnet Versandpreise nicht automatisch.
:::

## Bearbeiten von Warenkorb-Positionen {#editing-line-items}

### Menge {#quantity}

Klicken Sie auf das Mengenfeld, um es direkt zu bearbeiten. Geben Sie eine neue Zahl ein oder verwenden Sie die Spinner-Steuerung.

{/* Screenshot: cart-line-item-edit-qty.png */}

### Produktname {#product-name}

Für verschiedene Produkte und Gebühren können Sie den Namen direkt durch Klicken darauf bearbeiten.

### Preis {#price}

Klicken Sie auf das Preisfeld, um den Einzelpreis zu ändern. Dies ist nützlich für:

- Manuelles Anwenden von Rabatten
- Preisvergleich
- Korrektur von Preisfehlern

Der Gesamtbetrag aktualisiert sich automatisch basierend auf Menge × Preis.

:::note Eine Preisänderung ist kein WooCommerce-„Rabatt“
Ein gesenkter Preis wird als Angebotspreis des Artikels erfasst – auf Belegen kann die Ersparnis angezeigt werden, aber die Bestellsumme **Rabatt** ist Gutscheinen vorbehalten, und in Berichten wird der Verkauf zum tatsächlich gezahlten Preis gezählt. Unter [Warenkorbrabatte](/pos/cart/discounts#why-tracked-differently) erfahren Sie, warum WooCommerce die beiden Fälle unterschiedlich behandelt.
:::

### Drei-Punkte-Menü {#three-dot-menu}

Klicken Sie auf **⋮** (drei Punkte) bei einer Warenkorb-Position, um auf zusätzliche Optionen zuzugreifen:

{/* Screenshot: cart-line-item-menu.png */}

#### Bearbeitungsformular {#edit-form}

Öffnet ein detailliertes Bearbeitungsformular für die Warenkorb-Position, mit dem Sie alle Felder ändern können.

#### Roh-JSON-Ansicht {#raw-json-view}

Zeigt die Rohdaten im JSON-Format für die Warenkorb-Position an. Dies ist äußerst hilfreich für:

- **Debugging** - Sehen Sie genau, welche Daten an WooCommerce gesendet werden
- **Fehlerbehebung** - Identifizieren Sie Probleme mit benutzerdefinierten Feldern oder Metadaten
- **Entwicklung** - Verstehen Sie die Datenstruktur für Integrationen

### Artikel Entfernen {#remove-item}

Klicken Sie auf die rote **×**-Schaltfläche, um einen Artikel aus dem Warenkorb zu entfernen.

## Variationsattribute {#variation-attributes}

Für variable Produkte werden die ausgewählten Variationsattribute unter dem Produktnamen angezeigt:

```
Hoodie
Colour: Green
Size: Large
```

Diese Attribute sind Teil der Warenkorb-Positionsdaten und werden mit der Bestellung einbezogen.

## Meta-Daten {#meta-data}

Wenn Sie [Metadaten-Schlüssel](/pos/product-panel#meta-data-keys) in den Einstellungen des Produkt-Panels konfiguriert haben, werden diese Daten automatisch in die Warenkorb-Position kopiert, wenn das Produkt in den Warenkorb gelegt wird.

Sie können diese Meta-Daten in der Roh-JSON-Ansicht anzeigen.

## Aufteilen von Warenkorb-Positionen {#splitting-line-items}

Wenn in den [Anzeigeeinstellungen](/pos/cart#display-settings) aktiviert, können Sie eine Warenkorb-Position in mehrere Zeilen aufteilen. Dies ist nützlich, wenn ein Kunde unterschiedliche Rabatte auf Teile des gleichen Produkts anwenden möchte.

## Tipps {#tips}

### Schnelle Preisanpassungen {#quick-price-adjustments}

So gewähren Sie schnell einen Rabatt:

1. Klicken Sie auf das Preisfeld
2. Geben Sie den neuen Preis ein
3. Drücken Sie die Eingabetaste

### Tastaturnavigation {#keyboard-navigation}

- **Tab** - Zwischen bearbeitbaren Feldern wechseln
- **Enter** - Änderung bestätigen
- **Escape** - Änderung abbrechen

### Stapelbearbeitung {#batch-edits}

Bei komplexen Bestellungen können Sie über das Drei-Punkte-Menü das vollständige Bearbeitungsformular öffnen, in dem alle Felder gleichzeitig angezeigt werden.
