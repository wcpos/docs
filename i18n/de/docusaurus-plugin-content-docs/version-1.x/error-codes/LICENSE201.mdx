## Was dies bedeutet {#what-this-means}

WCPOS Pro ist deaktiviert, weil seine Version nicht zu WCPOS passt.

Aktualisieren Sie die genannte WCPOS- oder WCPOS-Pro-Komponente, damit beide Versionen zueinander passen.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen. Wenn dies weiterhin auftritt, wenden Sie sich an die Person, die Ihre WordPress-Website betreut.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie beide Plugin-Versionen unter WP Admin → Plugins — der Protokolleintrag nennt, welche von WCPOS und WCPOS Pro zurückliegt.
2. Aktualisieren Sie die ältere; ein Update beider auf die neuesten Versionen behebt die Abweichung.
3. Wenn keine Pro-Updates angeboten werden, ist der Updater möglicherweise nicht autorisiert (siehe LICENSE301) — beheben Sie das zuerst und aktualisieren Sie dann.
