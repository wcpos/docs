## Bedeutung {#what-this-means}

WCPOS Pro ist deaktiviert, weil seine Version nicht mit WCPOS übereinstimmt.

Aktualisieren Sie die angegebene WCPOS- oder WCPOS Pro-Komponente, sodass beide Versionen kompatibel sind.

## Vorgehensweise {#what-to-do}

Damit dies funktioniert, ist eine Änderung der Einstellungen erforderlich. Wiederholen Sie den Vorgang nach der oben genannten Änderung; ohne diese Änderung schlägt der erneute Versuch auf dieselbe Weise fehl.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen. Wenn das Problem weiterhin besteht, wenden Sie sich an die Person, die Ihre WordPress-Website verwaltet.

## Fehlerbehebung {#troubleshoot}

1. Überprüfen Sie beide Plugin-Versionen unter WP Admin → Plugins — der Protokolleintrag zeigt an, ob WCPOS oder WCPOS Pro veraltet ist.
2. Aktualisieren Sie die ältere Version; durch die Aktualisierung beider auf die neuesten Versionen wird die Abweichung behoben.
3. Wenn keine Pro-Updates angeboten werden, ist der Updater möglicherweise nicht autorisiert (siehe LICENSE301) — beheben Sie dies zuerst und aktualisieren Sie anschließend.

## Wo nachsehen {#where-to-look}

Jedes Auftreten dieses Codes wird auf dem Gerät protokolliert, das ihn ausgelöst hat. Öffnen Sie **Filialstatus → Protokolle** (das Herzschlag-Symbol unten in der Navigationsleiste), suchen Sie den mit diesem Code markierten Eintrag und erweitern Sie ihn: Die erweiterte Zeile zeigt den verständlich formulierten Grund sowie den zum Zeitpunkt des Fehlers erfassten Kontext — bei allem, was eine Anfrage an Ihren Shop betraf, umfasst dies den servereigenen Fehlercode (`serverCode`), den HTTP-`status` und den `endpoint`. Verwenden Sie beim Melden eines Problems oben auf dem Protokollbildschirm **Debug-Informationen kopieren** (**Debug-Informationen teilen** auf Smartphones und Tablets) statt Screenshots: Dies bündelt die App-Version, den Verbindungsstatus und die neuesten Fehler. Protokolle werden höchstens 30 Tage aufbewahrt; erfassen Sie sie daher, solange das Problem aktuell ist.

Neben dem In-App-Protokoll kann dieser Fehler Spuren hinterlassen in:

- **Serverseitige POS-Protokolle**: Öffnen Sie in WP Admin **POS → Einstellungen → Werkzeuge → Protokolle**. Diese Seite zeichnet POS-bezogene Warnungen und Fehler auf, die auf dem Server selbst auftreten und möglicherweise nie in der App angezeigt werden. Eine rote Markierung im Menü weist auf ungelesene serverseitige Fehler hin.
