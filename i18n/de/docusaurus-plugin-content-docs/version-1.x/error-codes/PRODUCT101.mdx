## Was dies bedeutet {#what-this-means}

Dieses Produkt konnte nicht in Ihrem Shop gespeichert werden.

Prüfen Sie die gemeldete Ursache, bevor Sie es erneut versuchen: bei einem Netzwerkfehler die Verbindung wiederherstellen, ungültige Felder korrigieren oder ein in Konflikt stehendes Produkt aktualisieren.

## Ihre Daten {#your-data}

Ihre Änderung bleibt auf diesem Gerät und wird erst an die Filiale übertragen, wenn die angegebene Ursache behoben wurde. Besteht das Problem weiterhin, exportieren Sie die Diagnosedaten und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie den Protokolleintrag auf — der Fehlertext zeigt meist, ob es sich um einen Netzwerkfehler, ein vom Shop abgelehntes Feld oder eine im Shop vorgenommene, in Konflikt stehende Bearbeitung handelte.

**An der Kasse:**
- Netzwerkfehler: Prüfen Sie die Verbindung und versuchen Sie es erneut; die Bearbeitung bleibt auf diesem Gerät erhalten.
- Abgelehntes Feld: Korrigieren Sie das genannte Feld und versuchen Sie es erneut.

**In der Filiale (WP Admin):** Öffnen Sie bei einem Bearbeitungskonflikt das Produkt, vergleichen Sie die Versionen und übernehmen Sie die richtigen Werte erneut.

Wenn das Speichern ohne erkennbaren Grund weiterhin fehlschlägt, exportieren Sie Debug-Infos und wenden Sie sich an den Support.
