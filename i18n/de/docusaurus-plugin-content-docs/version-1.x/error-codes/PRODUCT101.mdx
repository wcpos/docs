## Was dies bedeutet {#what-this-means}

Diese Produktänderung hat Ihre Filiale noch nicht erreicht.

Lesen Sie den angezeigten Grund, beheben Sie das genannte Problem oder prüfen Sie Ihre Verbindung und speichern Sie das Produkt erneut.

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten auf diesem Gerät – möglicherweise enthält es Änderungen, die Ihre Filiale noch nicht erhalten hat. Speichern Sie das Produkt nach einem Verbindungsfehler erneut, sobald Sie wieder verbunden sind. Wenn die Filiale die Änderung abgelehnt hat, wird auf diesem Gerät stattdessen die Filialversion wiederhergestellt (siehe [SYNC202](/error-codes/SYNC202)); nehmen Sie die Änderung erneut vor, sobald der angegebene Grund behoben ist. Tritt das Problem weiterhin auf, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Lesen Sie den angezeigten Grund – der Fehlertext im Protokolleintrag zeigt normalerweise, ob ein Verbindungsfehler, ein von der Filiale abgelehnter Wert oder eine dort vorgenommene widersprüchliche Änderung vorliegt.

**An der Kasse:**

- Verbindungsfehler: Prüfen Sie die Verbindung und speichern Sie das Produkt erneut.
- Abgelehnter Wert: Korrigieren Sie den im Grund genannten Wert und speichern Sie das Produkt erneut.

**In der Filiale (WP Admin):** Öffnen Sie bei einer widersprüchlichen Änderung das Produkt, vergleichen Sie es mit der Anzeige an der Kasse und speichern Sie einmal die richtigen Werte.

Wenn das Speichern ohne klaren Grund weiterhin fehlschlägt, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den Support.
