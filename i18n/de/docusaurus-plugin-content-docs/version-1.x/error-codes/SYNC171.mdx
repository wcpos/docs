## Was dies bedeutet {#what-this-means}

WCPOS konnte den Speicher dieses Geräts nicht einrichten oder entfernen.

Geben Sie Gerätespeicher frei und starten Sie WCPOS anschließend neu. Im Web schränkt möglicherweise auch der Browser den Speicherzugriff für die Website ein – das ist bei privaten Fenstern der Fall. Wenden Sie sich an den Support, wenn das Problem weiterhin auftritt.

## Ihre Daten {#your-data}

Dies ist ein Speicherproblem, keine abgelehnte Änderung. Trat es beim Löschen von Daten auf diesem Gerät auf, könnten Teile davon bereits verloren sein, einschließlich noch nicht gesendeter Änderungen. Prüfen Sie, ob Ihre letzten Verkäufe und Änderungen in Ihrer Filiale angezeigt werden. Wenn dies weiterhin auftritt, verwenden Sie **Debug-Infos kopieren** auf dem Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie den freien Speicherplatz auf dem Gerät und geben Sie etwas frei, indem Sie andere Dateien oder Apps entfernen – das Einrichten des Speichers schlägt sofort fehl, wenn der Datenträger oder das Speicherlimit des Browsers voll ist. Verwenden Sie nicht „Browserdaten löschen“, um Speicherplatz freizugeben – dadurch werden auch die noch nicht gesendeten Verkäufe von WCPOS gelöscht.
2. Starten Sie WCPOS neu und führen Sie dieselbe Aktion erneut aus.
3. Prüfen Sie im Web, ob der Browser dauerhaften Speicher für die Website zulässt — private Fenster und Einstellungen, die alle Daten blockieren, tun das nicht.
4. Wenn das Problem weiterhin auftritt, verwenden Sie **Debug-Infos kopieren** auf dem Tab **Protokolle** und wenden Sie sich an den Support.
