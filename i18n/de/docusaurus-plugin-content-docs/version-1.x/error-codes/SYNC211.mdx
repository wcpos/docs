## Was dies bedeutet {#what-this-means}

Ihre Filiale hat einen übermittelten Wert abgelehnt.

Der Grund der Filiale nennt den Wert. Korrigieren Sie ihn dort, wo Sie ihn eingegeben haben, und speichern Sie erneut. Meist gehört der Wert zu einem Datensatz – einem Produkt, Kunden oder einer Bestellung. Dieser Code kann jedoch auch durch eine Einstellungs- oder Anmeldeanfrage entstehen, die von der Filiale abgelehnt wurde. Korrigieren Sie den Wert dann auf dem entsprechenden Bildschirm.

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten auf diesem Gerät – sie können Änderungen enthalten, die Ihre Filiale noch nicht erhalten hat. Eine abgelehnte Bearbeitung eines vorhandenen Produkts, einer Variante, eines Kunden oder eines Gutscheins wird normalerweise automatisch rückgängig gemacht und stattdessen als [SYNC202](/error-codes/SYNC202) protokolliert. Wird sie mit diesem Code angezeigt und ist die Änderung unter **Shop-Zustand → Datenbank** aufgeführt, wurde sie nicht automatisch rückgängig gemacht – behandeln Sie sie wie jede andere aufgeführte Änderung. Bei einer Einstellungs- oder Anmeldeanfrage gibt es nichts zu speichern.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie den Protokolleintrag auf und lesen Sie den Grund der Filiale sowie den Endpunkt: Der Grund nennt den Wert, und der Endpunkt zeigt, ob die Anfrage von einem Datensatz oder von einer Einstellung oder Anmeldung stammt.
2. Korrigieren Sie den Wert dort, wo Sie ihn eingegeben haben – häufige Ursachen sind ein Wert außerhalb des zulässigen Bereichs, ein abgelehntes Format oder eine leere Pflichtoption – und speichern Sie erneut. Wenn die Änderung nicht unter **Shop-Zustand → Datenbank** aufgeführt ist, wurde die Version der Filiale wiederhergestellt. Nehmen Sie die Änderung daher mit dem korrigierten Wert erneut vor. Wenn sie nach der Korrektur weiterhin unter **„… changes never reached your server“** in **Shop-Zustand → Datenbank** aufgeführt ist, tippen Sie in der entsprechenden Zeile auf **Send again**.
3. Wenn der Datensatz stattdessen unter **„… changes were held“** mit *„Your store required a current version“* aufgeführt ist, ist kein Wert fehlerhaft – entscheiden Sie wie unter [SYNC221](/error-codes/SYNC221) beschrieben zwischen **Send again** und **Discard device change**.
4. Bei einer Einstellungs- oder Anmeldeanfrage korrigieren Sie den Wert auf dem Bildschirm, auf dem Sie ihn eingegeben haben, und speichern Sie erneut. **Website-Administrator:** Die Entwicklertools des Browsers (Tab Netzwerk) – oder **Erweitert → Entwicklertools umschalten** in der Desktop-App – zeigen die Antwort der Filiale, wenn die Details nicht im POS-Protokoll stehen.
5. **Website-Administrator:** Wenn ein genannter Wert im POS korrekt aussieht, vergleichen Sie ihn mit demselben Datensatz in WP Admin – eine von einem Plugin hinzugefügte Validierung in der Filiale kann Werte ablehnen, die der POS für korrekt hält.
