## Was dies bedeutet {#what-this-means}

Eine Änderung auf diesem Gerät kollidiert mit einer Bearbeitung, die in Ihrem Shop vorgenommen wurde.

Öffnen Sie den Datensatz und prüfen Sie, welche Version korrekt ist. Das POS hält beide Seiten sicher, bis die Kollision geklärt ist — es geht nichts verloren.

## Ihre Daten {#your-data}

Der Datensatz selbst ist sicher und unverändert — das POS behält sowohl die Version an der Kasse als auch die Version der Filiale, bis der Konflikt gelöst ist.

## Fehlerbehebung {#troubleshoot}

1. Öffnen Sie den im Protokolleintrag genannten Datensatz und vergleichen Sie ihn mit der Kopie der Filiale in WP Admin (möglicherweise muss dies ein Website-Administrator übernehmen).
2. Entscheiden Sie, welche Version richtig ist — die der Kasse oder die des Shops — und übernehmen Sie die korrekten Werte einmal; das POS hält beide Seiten sicher, und weitere Bearbeitungen dieses Datensatzes werden zurückgehalten, bis die Kollision geklärt ist.
3. Häufige Konflikte bei denselben Datensätzen bedeuten meist, dass zwei Personen dieselben Daten parallel bearbeiten; einigen Sie sich darauf, wo welche Art von Bearbeitung stattfindet.
