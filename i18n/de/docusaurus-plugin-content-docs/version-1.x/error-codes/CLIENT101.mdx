## Was dies bedeutet {#what-this-means}

WCPOS konnte den Start nicht abschließen.

An der Kasse sieht dies wie ein leerer oder eingefrorener Bildschirm oder ein dauerhaft angezeigtes Ladesymbol aus. Starten Sie WCPOS neu (im Web laden Sie den Tab neu) — ein Startfehler behebt sich oft von selbst. Wenn WCPOS weiterhin nicht startet, wenden Sie sich an den Support, bevor Sie etwas löschen.

:::warning Löschen Sie nicht die Daten dieses Geräts
Auf diesem Gerät könnten Verkäufe gespeichert sein, die Ihre Filiale noch nicht erreicht haben — zum Beispiel offline erfasste Verkäufe. Solange WCPOS nicht starten kann, lassen sie sich nicht senden. Durch das Löschen lokaler Daten, Abmelden oder eine Neuinstallation würden sie dauerhaft gelöscht. Wenden Sie sich an den Support, bevor Sie etwas löschen.
:::

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten dieses Geräts — möglicherweise enthält es Änderungen, die Ihre Filiale noch nicht erhalten hat. Die Daten Ihrer Filiale sind sicher und nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Starten Sie WCPOS einmal neu; im Web laden Sie den Tab vollständig neu — ein vorübergehender Startfehler behebt sich oft von selbst.
2. Wenn WCPOS weiterhin nicht startet, wenden Sie sich an den Support, bevor Sie etwas löschen. Senden Sie **Debug-Infos kopieren** im Tab **Protokolle**, sofern WCPOS weit genug startet, um diesen zu öffnen — andernfalls die Fehlermeldung aus der Browserkonsole (Entwicklertools) oder in der Desktop-App unter **Erweitert → Entwicklertools umschalten**.
3. Löschen Sie während der Wartezeit keine lokalen Daten, melden Sie sich nicht ab und installieren Sie WCPOS nicht neu — der Support teilt Ihnen mit, ob auf diesem Gerät zuerst etwas wiederhergestellt werden muss.
