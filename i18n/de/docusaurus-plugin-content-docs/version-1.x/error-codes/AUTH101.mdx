## Was dies bedeutet {#what-this-means}

Ihre Sitzung ist beendet und Sie müssen sich erneut anmelden.

Melden Sie sich erneut an. Es geht nichts verloren – ausstehende Änderungen werden gesendet, sobald Sie angemeldet sind.

## Ihre Daten {#your-data}

Bestell- und Produktdaten sind nicht betroffen. Ein Verkauf, den Sie während der abgelaufenen Sitzung gespeichert haben, bleibt auf dem Gerät erhalten und geht nach der Anmeldung automatisch an Ihre Filiale.

## Fehlerbehebung {#troubleshoot}

1. Melden Sie sich erneut an. WCPOS öffnet automatisch das WordPress-Anmeldefenster. Falls Sie es geschlossen haben, fordert WCPOS Sie erneut zur Anmeldung auf. Melden Sie sich als derselbe Kassierer an.
2. Sie müssen nichts erneut eingeben oder speichern: Ein ausstehender Verkauf wird automatisch gesendet, sobald Sie wieder angemeldet sind. Öffnen Sie **Shop-Zustand → Datenbank**, um den Vorgang zu verfolgen – **Änderungen ausstehend** sinkt auf 0.
3. Wenn ein Verkauf stattdessen unter **„… Änderungen haben Ihren Server nie erreicht“** aufgeführt ist, tippen Sie in seiner Zeile auf **Erneut senden**.
4. Häufige Abläufe (mehrmals täglich) werden meist durch die Website verursacht: Ein Sicherheits-Plugin verkürzt die Sitzungsdauer oder löscht Token. Fragen Sie die Website-Administration, welche Sicherheits-Plugins auf der Filiale ausgeführt werden und ob sie unter **WP Admin > POS > Einstellungen > Werkzeuge > Protokolle** nachsehen kann – dort wird eine abgelehnte Anmeldung mit dem Grund protokolliert.
