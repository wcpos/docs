## Was dies bedeutet {#what-this-means}

Die Shop-Adresse fehlt oder ist keine gültige URL.

Prüfen Sie die Adresse auf Tippfehler, geben Sie die vollständige https://-URL der WordPress-Website des Shops an und versuchen Sie es dann erneut.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie die Adresse auf Tippfehler und geben Sie die vollständige URL einschließlich https:// ein — zum Beispiel https://shop.example.com.
2. Verwenden Sie die WordPress-Adresse der Website, nicht eine Admin-Seite oder eine Checkout-URL.
3. Wenn die Website in einem Unterverzeichnis liegt (zum Beispiel /shop), geben Sie dieses mit an.
