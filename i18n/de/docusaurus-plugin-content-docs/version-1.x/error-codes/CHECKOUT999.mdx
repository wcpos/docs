## Was dies bedeutet {#what-this-means}

Beim Checkout ist ein unerwartetes Problem aufgetreten.

Prüfen Sie die Bestellung in Ihrer Shop-Verwaltung, bevor Sie den Kunden erneut belasten. Exportieren Sie Diagnosedaten und wenden Sie sich an den Support, wenn sich das Problem wiederholt.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden — prüfen Sie es, bevor Sie es erneut versuchen. Wenn dies weiterhin auftritt, exportieren Sie Diagnosedaten und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie WooCommerce → Bestellungen in WP Admin auf die Bestellung, bevor Sie den Kunden erneut belasten.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode sowie einen etwaigen serverCode — dieser allgemeine Code bedeutet, dass die Ursache noch keinen eigenen Code hat.
3. Wenn es sich wiederholt, exportieren Sie Debug-Infos und wenden Sie sich an den Support.
