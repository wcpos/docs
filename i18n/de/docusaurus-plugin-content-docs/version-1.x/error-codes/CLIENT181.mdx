## Was dies bedeutet {#what-this-means}

WCPOS konnte nicht zu dieser Filiale wechseln.

Laden Sie WCPOS neu und wählen Sie die Filiale erneut aus. Auf diesem Gerät geht nichts verloren.

Der Wechsel zwischen Filialen oder Kassierern auf derselben Website ist vor dem Abschluss fehlgeschlagen. Die Daten der vorherigen Filiale auf diesem Gerät sind unverändert.

## Ihre Daten {#your-data}

Auf diesem Gerät geht nichts verloren. Die Daten der vorherigen Filiale — einschließlich noch ausstehender Änderungen — bleiben unverändert.

## Fehlerbehebung {#troubleshoot}

1. Laden Sie WCPOS neu — im Web laden Sie den Browser-Tab neu; auf Desktop und Mobilgerät schließen Sie die App und öffnen sie erneut.
2. Wählen Sie die Filiale (und den Kassierer) erneut aus.
3. Wenn der Wechsel weiterhin fehlschlägt, tippen Sie im Tab **Protokolle** auf **Debug-Infos kopieren** und wenden Sie sich an den Support. Löschen Sie keine lokalen Daten und entfernen Sie die Website nicht, um das Problem zu beheben — die Daten der vorherigen Filiale, einschließlich noch nicht gesendeter Änderungen, befinden sich auf diesem Gerät.
