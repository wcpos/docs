## Was dies bedeutet {#what-this-means}

Ihr Shop kann derzeit nicht erreicht werden, daher bleiben Änderungen auf diesem Gerät.

Prüfen Sie die Verbindung und arbeiten Sie offline weiter; die Synchronisierung wird automatisch erneut versucht, sobald der Shop erreichbar ist.

## Ihre Daten {#your-data}

Die Änderung ist auf diesem Gerät gespeichert, hat Ihren Shop aber nicht erreicht.

## Fehlerbehebung {#troubleshoot}

1. Verkaufen Sie weiter — Verkäufe werden auf diesem Gerät gespeichert und die Synchronisierung wird automatisch fortgesetzt, sobald der Shop antwortet.
2. Prüfen Sie, ob die Kasse selbst online ist: Lässt sich von diesem Gerät aus irgendeine andere Website laden?
3. Öffnen Sie die Website Ihres Shops in einem Browser-Tab auf demselben Gerät; wenn sie auch dort nicht lädt, sind die Website oder ihr Hosting ausgefallen und nicht das POS.
4. **Für die Person, die das Netzwerk dieses Geräts verwaltet:** Wenn die Website geladen wird, der POS aber offline bleibt, blockiert etwas dazwischen die API-Anfragen – etwa ein VPN, eine Firewall, ein Werbeblocker oder ein Sicherheits-Plugin. In den Entwicklertools des Browsers (Tab „Netzwerk“) – oder über **Erweitert → Entwicklertools umschalten** in der Desktop-App – sehen Sie, welche Anfrage fehlschlägt.
