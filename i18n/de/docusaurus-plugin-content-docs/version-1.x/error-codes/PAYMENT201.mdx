## Was dies bedeutet {#what-this-means}

WCPOS konnte nicht bestätigen, ob das Terminal die Zahlung belastet hat.

Prüfen Sie das Zahlungsterminal, bevor Sie eine weitere Belastung versuchen, und wenden Sie sich an den Zahlungsanbieter, wenn das Ergebnis unklar bleibt.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden — prüfen Sie es, bevor Sie es erneut versuchen. Wenn dies weiterhin auftritt, wenden Sie sich an Ihren Zahlungsanbieter.

## Fehlerbehebung {#troubleshoot}

1. Ziehen Sie die Karte noch nicht erneut ein.
2. Prüfen Sie den Bildschirm des Terminals und danach das Dashboard Ihres Zahlungsanbieters — die Aufzeichnung des Anbieters ist maßgeblich dafür, ob die Belastung durchgeführt wurde.
3. Wenn Sie Zugriff auf WP Admin haben (oder den Filialinhaber fragen), prüfen Sie WooCommerce → Bestellungen. Eine erfolgreiche Zahlung ist dort möglicherweise bereits erfasst.
4. Nehmen Sie die Zahlung erst dann erneut entgegen, wenn das Dashboard des Anbieters keine Belastung zeigt.
5. Wenn die Belastung als ausstehend oder unsicher angezeigt wird, wenden Sie sich an den Zahlungsanbieter, bevor Sie handeln.
