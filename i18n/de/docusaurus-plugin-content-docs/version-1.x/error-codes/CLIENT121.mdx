## Was dies bedeutet {#what-this-means}

Dieser Browser lässt zu, dass jeweils nur ein Tab Änderungen sendet.

Sie können alle Tabs weiterverwenden — sie teilen sich dieselben lokalen Daten. Ein Tab übernimmt im Hintergrund die Synchronisierung für alle.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen.

## Fehlerbehebung {#troubleshoot}

1. Verwenden Sie alle Tabs ganz normal weiter — sie teilen sich dieselben lokalen Daten, und ein Tab synchronisiert unbemerkt für alle übrigen.
2. Diesem Browser (oder einem privaten Fenster) fehlt die Tab-Koordinationsfunktion, die das POS bevorzugt, daher weicht es auf einen einzelnen synchronisierenden Tab aus. Es ist keine Korrektur erforderlich.
