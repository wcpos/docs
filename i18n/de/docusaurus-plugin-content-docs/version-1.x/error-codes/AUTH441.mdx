## Was dies bedeutet {#what-this-means}

Das Login-Token ist größer, als dieser Server akzeptiert.

Der Server hat das Login-Token wegen seiner Größe abgelehnt: ein 400, wenn es im Authorization-Header übertragen wird, oder ein 414, wenn es in der URL übertragen wird. Keine clientseitige Kodierung kann es verkleinern — die Header-/URL-Größenbeschränkungen des Servers müssen erhöht oder das Token verkleinert werden.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen.

## Fehlerbehebung {#troubleshoot}

1. Erhöhen Sie bei Apache LimitRequestFieldSize (Header-Pfad) oder LimitRequestLine (URL-Pfad) in der vhost-Konfiguration.
2. Erhöhen Sie bei nginx large_client_header_buffers.
3. Hinter einem Proxy oder CDN liegt das Limit möglicherweise auf dieser Ebene — prüfen Sie beide.
4. Wenn die Limits nicht geändert werden können, wenden Sie sich an den Support, um ein kleineres Token für diese Website ausstellen zu lassen.
