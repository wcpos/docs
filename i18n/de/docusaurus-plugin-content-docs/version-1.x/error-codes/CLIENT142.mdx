## Bedeutung {#what-this-means}

Der Suchindex hat nicht rechtzeitig geantwortet, daher hat WCPOS stattdessen direkt im Katalog gesucht.

Der lokale Suchindex wurde noch aufgebaut oder konnte nicht antworten. Im Web geschieht dies in der Regel, weil der POS-Tab im Hintergrund war oder ein anderer Tab die Führung der Datenbank hat; auf Desktop und Mobilgeräten geschieht dies in der Regel direkt nach einer großen Synchronisierung oder kurz nach einem App-Neustart, während der gespeicherte Index erneut geladen wird. Suchen funktionieren weiterhin über eine direkte Durchsuchung der Daten auf diesem Gerät und wechseln automatisch wieder zum Index, sobald dieser antwortet.

## Ihre Daten {#your-data}

Es wurden keine Filialdaten geändert, und Ihre Suche wurde weiterhin beantwortet — statt des Index hat eine direkte Durchsuchung der Daten auf diesem Gerät die Antwort geliefert. Suchen können lediglich etwas langsamer sein, bis der Index wieder übernimmt.

## Fehlerbehebung {#troubleshoot}

1. In der Regel ist keine Maßnahme erforderlich: Die Suchergebnisse funktionieren weiterhin, und der Index übernimmt automatisch wieder, sobald er antwortet.
2. Wenn WCPOS im Web in mehreren Browser-Tabs geöffnet ist, schließen Sie die zusätzlichen Tabs — nur ein Tab kann die Führung der lokalen Datenbank übernehmen — und lassen Sie den POS in einem eigenen Fenster statt in einem Hintergrund-Tab geöffnet.
3. Wenn Suchen weiterhin langsam sind oder dieser Code wiederholt angezeigt wird, laden Sie die App einmal neu — im Web den Browser-Tab neu laden; auf Desktop und Mobilgeräten die App schließen und erneut öffnen.
4. Wenn der Code danach weiterhin angezeigt wird, exportieren Sie die Debug-Informationen und wenden Sie sich an den Support.
