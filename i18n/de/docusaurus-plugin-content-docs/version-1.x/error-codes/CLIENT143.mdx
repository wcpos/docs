## Bedeutung {#what-this-means}

Der Suchindex konnte ein Produkt nicht finden, das er enthalten sollte; die App versucht, den Suchindex automatisch neu aufzubauen.

Bei einer regelmäßigen Selbstprüfung wurde der lokale Suchindex anhand der eigenen Begriffe eines Datensatzes abgefragt, doch der Index gab ihn nicht zurück. Das bedeutet, dass Suchen möglicherweise weniger Ergebnisse angezeigt haben, als tatsächlich auf diesem Gerät vorhanden sind. Die App versucht pro Liste und Sitzung einen automatischen Neuaufbau des Index, um dies zu korrigieren.

## Ihre Daten {#your-data}

Es wurden keine Filialdaten geändert. Dies betrifft nur den lokalen Suchindex, der aus den bereits auf diesem Gerät vorhandenen Daten abgeleitet wird — beim Neuaufbau gehen keine Daten verloren.

## Fehlerbehebung {#troubleshoot}

1. In der Regel ist keine Maßnahme erforderlich und Verkäufe können normal fortgesetzt werden: Die App versucht den Neuaufbau automatisch, und die Suche funktioniert wieder, sobald dieser abgeschlossen ist. Pro Liste und Sitzung wird nur ein Neuaufbau versucht. Wenn dieser Code erneut angezeigt wird, fahren Sie mit dem nächsten Schritt fort.
2. Falls die Suche weiterhin Datensätze übersieht, die in der App sichtbar sind — ein Produkt, ein Kunde, eine Bestellung oder eine andere Liste — laden Sie die App neu: Laden Sie im Web den Browser-Tab neu; schließen Sie die App auf Desktop- und Mobilgeräten und öffnen Sie sie erneut. Dadurch kann beim nächsten Erkennen des Problems ein erneuter Neuaufbau versucht werden.
3. Wenn der Code nach dem Neuladen erneut angezeigt wird, exportieren Sie Debug-Informationen und wenden Sie sich an den Support — der Protokolleintrag enthält die Angaben, die der Support benötigt, um die betroffene Liste und den vom Index übersehenen Datensatz zu identifizieren.
