## Bedeutung {#what-this-means}

Die Suche hat ein Produkt nicht gefunden, das sie hätte finden müssen.

Sie müssen nichts tun, es sei denn, ein sichtbares Produkt wird weiterhin nicht in der Suche angezeigt – laden Sie WCPOS dann neu.

Bei einer regelmäßigen Selbstprüfung wurde im lokalen Suchindex nach einem Datensatz mit dessen eigenen Begriffen gesucht, aber der Index gab ihn nicht zurück. Das bedeutet, dass die Suche möglicherweise weniger Ergebnisse angezeigt hat, als auf diesem Gerät vorhanden sind. Die App kann den Index selbst neu erstellen, aber nur einmal pro Liste und Sitzung; eine Neuerstellung ist daher nicht garantiert.

## Ihre Daten {#your-data}

Es wurden keine Filialdaten geändert. Dies betrifft nur den lokalen Suchindex, der aus den bereits auf diesem Gerät vorhandenen Daten abgeleitet wird — beim Neuaufbau gehen keine Daten verloren.

## Fehlerbehebung {#troubleshoot}

1. Sie müssen nichts tun, es sei denn, ein sichtbares Produkt wird weiterhin nicht in der Suche angezeigt – Verkäufe können normal fortgesetzt werden. Die App kann den Index selbst neu erstellen, jedoch nur einmal pro Liste und Sitzung. Wenn dieser Code erneut auftritt, fahren Sie mit dem nächsten Schritt fort.
2. Falls die Suche weiterhin Datensätze übersieht, die in der App sichtbar sind — ein Produkt, ein Kunde, eine Bestellung oder eine andere Liste — laden Sie die App neu: Laden Sie im Web den Browser-Tab neu; schließen Sie die App auf Desktop- und Mobilgeräten und öffnen Sie sie erneut. Dadurch kann beim nächsten Erkennen des Problems ein erneuter Neuaufbau versucht werden.
3. Wenn der Code nach dem Neuladen erneut auftritt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und kontaktieren Sie den Support – der Protokolleintrag enthält die benötigten Details zur betroffenen Liste und zum vom Index übersehenen Datensatz.
