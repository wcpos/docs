## Bedeutung {#what-this-means}

Die Suche hat ein Produkt nicht gefunden, das sie hätte finden müssen.

Sie müssen nichts tun, außer ein sichtbares Produkt lässt sich weiterhin nicht über die Suche finden – laden Sie dann WCPOS neu.

Bei einer regelmäßigen Selbstprüfung wurde der lokale Suchindex anhand der eigenen Begriffe eines Datensatzes nach diesem Datensatz durchsucht, aber der Index hat ihn nicht zurückgegeben. Daher wurden möglicherweise weniger Ergebnisse angezeigt, als tatsächlich auf diesem Gerät vorhanden sind. Die App kann den Index selbst neu erstellen, jedoch nur einmal pro Liste und Sitzung. Eine Neuerstellung ist daher nicht garantiert.

## Ihre Daten {#your-data}

Es wurden keine Filialdaten geändert. Dies betrifft nur den lokalen Suchindex, der aus den bereits auf diesem Gerät vorhandenen Daten abgeleitet wird — beim Neuaufbau gehen keine Daten verloren.

## Fehlerbehebung {#troubleshoot}

1. Sie müssen nichts tun, außer ein sichtbares Produkt lässt sich weiterhin nicht über die Suche finden – Verkäufe können normal fortgesetzt werden. Die App kann den Index selbst neu erstellen. Da dies jedoch nur einmal pro Liste und Sitzung geschieht, fahren Sie bei erneutem Auftreten dieses Fehlercodes mit dem nächsten Schritt fort.
2. Falls die Suche weiterhin Datensätze übersieht, die in der App sichtbar sind — ein Produkt, ein Kunde, eine Bestellung oder eine andere Liste — laden Sie die App neu: Laden Sie im Web den Browser-Tab neu; schließen Sie die App auf Desktop- und Mobilgeräten und öffnen Sie sie erneut. Dadurch kann beim nächsten Erkennen des Problems ein erneuter Neuaufbau versucht werden.
3. Wenn der Fehler nach dem Neuladen erneut auftritt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den Support. Der Protokolleintrag enthält die erforderlichen Details, damit der Support die betroffene Liste und den vom Index übersehenen Datensatz ermitteln kann.
