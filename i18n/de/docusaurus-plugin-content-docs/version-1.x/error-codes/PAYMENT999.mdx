## Was dies bedeutet {#what-this-means}

Bei der Zahlungsabwicklung ist ein unerwartetes Problem aufgetreten.

Prüfen Sie, ob die Zahlung durchgeführt wurde, bevor Sie es erneut versuchen. Exportieren Sie Diagnosedaten und wenden Sie sich an den Support, wenn es unklar ist.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden — prüfen Sie es, bevor Sie es erneut versuchen. Wenn dies weiterhin auftritt, exportieren Sie Diagnosedaten und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie, ob die Zahlung durchgeführt wurde, bevor Sie es erneut versuchen: der Bildschirm des Terminals, das Dashboard des Anbieters und die Bestellung in WP Admin.
2. Klappen Sie den Protokolleintrag auf, um Ereigniscode und Kontext zu sehen — dieser allgemeine Code bedeutet, dass die Ursache noch keinen eigenen Code hat.
3. Wenn das Ergebnis unklar bleibt oder der Code erneut auftritt, exportieren Sie Debug-Infos und wenden Sie sich an den Support.
