## Was dies bedeutet {#what-this-means}

Einige auf diesem Gerät gespeicherte Daten sind beschädigt und können daher nicht synchronisiert werden.

Tippen Sie oben im Tab **Protokolle** auf **Debug-Infos kopieren** und senden Sie die Informationen an den WCPOS-Support. Installieren Sie WCPOS nicht neu, melden Sie sich nicht ab und löschen Sie keine Daten: Änderungen, die Ihre Filiale noch nicht erreicht haben, befinden sich nur auf diesem Gerät.

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten dieses Geräts — möglicherweise enthält es Verkäufe, die Ihre Filiale noch nicht erreicht haben. Auch eine Neuinstallation oder Abmeldung kann sie löschen. Der Support kann Ihnen mitteilen, ob eine bestimmte Datenart sicher erneut heruntergeladen werden kann.

## Fehlerbehebung {#troubleshoot}

1. Verkaufen Sie weiter, wenn WCPOS noch funktioniert. Installieren Sie die App nicht neu, melden Sie sich nicht ab und löschen Sie keine Daten.
2. Tippen Sie im Tab **Protokolle** oben auf **Debug-Infos kopieren** und senden Sie die Informationen zusammen mit einer Beschreibung Ihrer Tätigkeit beim Auftreten des Eintrags an den WCPOS-Support.
3. Öffnen Sie **Filialstatus → Datenbank** und teilen Sie dem Support mit, wie viele **Änderungen zum Senden ausstehen** dort angezeigt werden und ob ein Bereich **„… Änderungen haben Ihren Server nie erreicht“** oder **„… Änderungen wurden zurückgehalten“** zu sehen ist — diese Änderungen befinden sich nur auf diesem Gerät.
4. Der Protokolleintrag gibt nicht an, welche Daten beschädigt sind. Der Support bittet Sie möglicherweise, eine Datenart erneut herunterzuladen (Menü **⋮** der Zeile → **Löschen und erneut herunterladen…**), sobald keine Änderungen mehr ausstehen. Tun Sie dies nicht, bevor der Support bestätigt hat, welche Datenart betroffen ist: Beim Löschen falscher Daten oder während Änderungen ausstehen, können Verkäufe verloren gehen, die Ihre Filiale nie erreicht haben. Wenn Änderungen aufgrund der Beschädigung nicht gesendet werden können, stellt der Support sie zuerst wieder her. Laden Sie niemals Daten erneut herunter, solange Änderungen ausstehen.
