## Was dies bedeutet {#what-this-means}

In WCPOS ist ein unerwarteter Fehler aufgetreten.

Prüfen Sie vor einem erneuten Versuch, ob Ihre letzte Aktion ausgeführt wurde – öffnen Sie bei einem Verkauf die Bestellung und prüfen Sie ihren Status. Wenn dies erneut auftritt, verwenden Sie **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden – prüfen Sie es, bevor Sie es erneut versuchen. Wenn dies erneut auftritt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und kontaktieren Sie den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie vor einem erneuten Versuch, ob Ihre letzte Aktion ausgeführt wurde – öffnen Sie bei einem Verkauf die Bestellung und prüfen Sie ihren Status. Prüfen Sie bei einer Zahlung auch das Terminal oder den Anbieter. Wenn die Aktion nicht ausgeführt wurde, versuchen Sie es einmal erneut.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode und den Kontext — ein 999er-Code bedeutet, dass der Fehler noch keinen eigenen Code hat, und genau diese Informationen identifizieren ihn.
3. Wenn dies erneut auftritt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und senden Sie die Informationen an den WCPOS-Support – durch die Meldung kann ein eigener Code für den jeweiligen Fehler hinzugefügt werden.
