## Was dies bedeutet {#what-this-means}

In WCPOS ist ein unerwarteter Fehler aufgetreten.

Prüfen Sie vor einem erneuten Versuch, ob Ihre letzte Aktion erfolgreich war – öffnen Sie bei einem Verkauf die Bestellung und prüfen Sie ihren Status. Wenn der Fehler erneut auftritt, tippen Sie auf **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden – prüfen Sie es, bevor Sie es erneut versuchen. Wenn der Fehler erneut auftritt, verwenden Sie **Debug-Informationen kopieren** im Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Prüfen Sie vor einem erneuten Versuch, ob Ihre letzte Aktion erfolgreich war – öffnen Sie bei einem Verkauf die Bestellung und prüfen Sie ihren Status; prüfen Sie bei einer Zahlung auch das Terminal oder den Zahlungsanbieter. Wenn sie nicht durchgeführt wurde, versuchen Sie es einmal erneut.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode und den Kontext — ein 999er-Code bedeutet, dass der Fehler noch keinen eigenen Code hat, und genau diese Informationen identifizieren ihn.
3. Wenn der Fehler erneut auftritt, tippen Sie im Tab **Protokolle** auf **Debug-Informationen kopieren** und senden Sie die Informationen an den WCPOS-Support – durch Ihre Meldung kann der spezifische Fehlercode hinzugefügt werden.
