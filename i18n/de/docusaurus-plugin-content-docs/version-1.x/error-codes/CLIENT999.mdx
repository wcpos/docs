## Was dies bedeutet {#what-this-means}

In WCPOS ist ein unerwarteter Fehler aufgetreten.

Versuchen Sie die Aktion noch einmal und exportieren Sie dann Diagnosedaten und wenden Sie sich an den Support, wenn sie erneut fehlschlägt.

## Ihre Daten {#your-data}

Das Ergebnis konnte nicht bestätigt werden — prüfen Sie es, bevor Sie es erneut versuchen. Wenn dies weiterhin auftritt, exportieren Sie Diagnosedaten und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Versuchen Sie die Aktion noch einmal.
2. Klappen Sie den Protokolleintrag auf und notieren Sie den Ereigniscode und den Kontext — ein 999er-Code bedeutet, dass der Fehler noch keinen eigenen Code hat, und genau diese Informationen identifizieren ihn.
3. Wenn er sich wiederholt, exportieren Sie Debug-Infos und wenden Sie sich an den Support — nur durch solche Meldungen entsteht ein eigener Code.
