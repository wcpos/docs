## Was dies bedeutet {#what-this-means}

Die REST API des Shops hat auf keiner Adressform geantwortet, die diese App verwenden kann.

Die App hat die REST API des Shops unter ihrer normalen Adresse (/wp-json/...) und unter der in WordPress eingebauten Ausweichadresse (/?rest_route=...) versucht, und keine hat geantwortet. Die Website des Shops selbst ist möglicherweise erreichbar — hier geht es speziell darum, dass die REST API nicht erreichbar ist, meist weil ein Sicherheits-Plugin sie verbirgt oder eine Firewall-Regel sie blockiert.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen.

## Fehlerbehebung {#troubleshoot}

**Im Shop** — für den Website-Administrator: Wenn ein Sicherheits-Plugin `/wp-json/` verbirgt oder umbenennt (zum Beispiel WP Hide), lassen Sie zusätzlich die in WordPress eingebaute Form `/?rest_route=` zu — die App weicht automatisch darauf aus.

**Auf dem Host / Server:**

1. Prüfen Sie die Firewall-Regeln (WAF) auf alles, was auf `wp-json` oder `rest_route` passt, und lassen Sie die shopeigene REST API durch.
2. Wenn der Server hinter einer Wartungsseite oder einem Bot-Challenge liegt, werden REST-Anfragen möglicherweise mit einer HTML-Seite beantwortet — deaktivieren Sie den Challenge für die REST API.

**Zum Testen (für alle):** `https://your-store.com/?rest_route=/` sollte JSON zurückgeben, nicht eine 403-Seite oder die Startseite der Website.
