## Bedeutung {#what-this-means}

Der Neuaufbau eines Suchindex ist fehlgeschlagen, daher können die Ergebnisse unvollständig sein, während die App die Initialisierung erneut versucht.

Nachdem die App ein Problem mit dem Suchindex erkannt hatte ([CLIENT141](/error-codes/CLIENT141) oder [CLIENT143](/error-codes/CLIENT143)), versuchte sie, den Index neu aufzubauen, doch auch dieser Neuaufbau schlug fehl. Die Suche liefert weiterhin Ergebnisse — aus dem bestehenden Index, wobei bekannte fehlerhafte Ergebnisse ausgeblendet werden, oder durch einen direkten Scan der Daten auf diesem Gerät —, kann jedoch Ergebnisse für die betroffene Liste übersehen oder falsch einordnen. Die nächste Suche oder Bereitschaftsprüfung versucht die Initialisierung des Index erneut und kann das Problem automatisch beheben; falls die Ergebnisse weiterhin falsch sind, kann die App optional neu geladen werden.

## Ihre Daten {#your-data}

Es wurden keine Daten geändert. Dies betrifft nur den lokalen Suchindex, der aus den bereits auf diesem Gerät vorhandenen Daten abgeleitet wird.

## Fehlerbehebung {#troubleshoot}

1. Öffnen Sie den Protokolleintrag — sein Kontext nennt die betroffene Liste und den Fehler, der beim Neuaufbau aufgetreten ist. Wenn dieser Fehler Speicher erwähnt, schaffen Sie zunächst Speicherplatz auf dem Gerät frei; vermeiden Sie im Web außerdem private/Inkognito-Fenster.
2. Führen Sie eine weitere Suche in der betroffenen Liste aus — die App versucht die Initialisierung des Index automatisch erneut.
3. Wenn weiterhin Ergebnisse fehlen oder falsch sortiert sind, laden Sie die App neu: Laden Sie im Web den Browser-Tab neu; schließen Sie die App auf dem Desktop und Mobilgerät und öffnen Sie sie erneut. Wenn CLIENT144 danach erneut protokolliert wird, exportieren Sie Debug-Informationen im Bildschirm „Protokolle“ und kontaktieren Sie den Support.
