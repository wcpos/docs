## Was dies bedeutet {#what-this-means}

Die Zahlung war erfolgreich, aber WCPOS konnte anschließend seinen Status nicht aktualisieren.

Die Zahlung wurde abgeschlossen – belasten Sie den Kunden nicht erneut. Öffnen Sie die Bestellung erneut, um ihren Status zu aktualisieren. Wenn der Status weiterhin veraltet wirkt, aktualisieren Sie ihn wie unten beschrieben.

## Ihre Daten {#your-data}

Die Zahlung wurde angenommen – belasten Sie den Kunden nicht erneut. Nur der angezeigte Status ist veraltet.

## Fehlerbehebung {#troubleshoot}

1. Belasten Sie den Kunden nicht erneut. Die Zahlungsseite der Filiale hat die Zahlung bestätigt (wenn Sie die Meldung **Payment completed for order #…** gesehen haben, ist das bereits geschehen); lediglich die anschließende Aktualisierung an der Kasse ist fehlgeschlagen.
2. Öffnen Sie die Bestellung erneut, um ihren Status zu aktualisieren, und fahren Sie mit dem nächsten Verkauf fort.
3. Wenn die bezahlte Bestellung im Warenkorb weiterhin als offen angezeigt wird, aktualisieren Sie die lokale Kopie an der Kasse: Öffnen Sie **Store health → Database**, dann das Menü **⋮** in der Zeile **Orders** und wählen Sie **Check for changes now**. Sobald der Status „bezahlt“ eingegangen ist, wird die Bestellung aus dem Warenkorb entfernt. Mit WCPOS Pro können Sie stattdessen nur diese Bestellung aktualisieren: Öffnen Sie unter **Orders** das Menü **⋮** der Bestellung und wählen Sie **Sync**.
4. Wird die Bestellung weiterhin als offen angezeigt, laden Sie die App neu (im Web den Browser-Tab neu laden; auf Desktop und Mobilgerät die App schließen und erneut öffnen). Beim Start schließt die Kasse jeden Verkauf ab, dessen Zahlung sie registriert hat.
5. **Website-Administrator:** Öffnen Sie zur Sicherheit die Bestellung unter **WooCommerce → Orders** – dort wird sie als bezahlt angezeigt.
