## Was dies bedeutet {#what-this-means}

Die Änderungsliste Ihrer Filiale hat sich unerwartet verschoben. WCPOS prüft sie deshalb automatisch erneut. Es geht nichts verloren.

Sie müssen nichts tun – verkaufen Sie einfach weiter. WCPOS prüft die Änderungen Ihrer Filiale automatisch erneut. Wenn Preise oder Lagerbestände weiterhin veraltet wirken, tippen Sie unter **Shop-Zustand → Datenbank** auf **Check everything now**.

## Ihre Daten {#your-data}

Es geht nichts verloren, und auf diesem Gerät ist nichts gefährdet. Bis die erneute Prüfung abgeschlossen ist, können einige Preise oder Lagerbestände auf diesem Gerät veraltet sein.

## Fehlerbehebung {#troubleshoot}

1. Verkaufen Sie weiter – auf diesem Gerät geht nichts verloren, und die erneute Prüfung läuft automatisch. Im Protokolleintrag steht möglicherweise, was sich verschoben hat, zum Beispiel, dass einige Änderungen der Filiale übersprungen wurden oder ihre Liste rückwärts ging. In beiden Fällen können beliebige Daten betroffen sein.
2. Wenn Preise oder Lagerbestände weiterhin veraltet wirken, öffnen Sie **Shop-Zustand → Datenbank** und tippen Sie auf **Check everything now**.
3. Wenn ein Datensatz nach dieser Prüfung weiterhin falsch aussieht oder dieser Code erneut erscheint, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den Support. Löschen Sie zur Behebung keine Daten.
