## Was dies bedeutet {#what-this-means}

Beim Laden oder Aktualisieren von Produkten ist ein unerwartetes Problem aufgetreten.

Wiederholen Sie den Vorgang und prüfen Sie, ob die Änderung gespeichert wurde. Wenn Produkte weiterhin falsch angezeigt werden, tippen Sie auf **Copy debug info** und senden Sie die Informationen an den Support.

## Ihre Daten {#your-data}

Verkäufe und Bestellungen sind nicht betroffen. Wenn Sie ein Produkt bearbeitet haben, prüfen Sie, ob die Änderung gespeichert wurde.

## Fehlerbehebung {#troubleshoot}

1. Wiederholen Sie den Vorgang und prüfen Sie, ob die Änderung gespeichert wurde – die meisten einmaligen Probleme beim Laden von Produkten beheben sich beim zweiten Versuch.
2. Wenn Produkte weiterhin falsch angezeigt werden, tippen Sie auf dem Tab **Logs** auf **Copy debug info** und senden Sie die Informationen an den Support.
