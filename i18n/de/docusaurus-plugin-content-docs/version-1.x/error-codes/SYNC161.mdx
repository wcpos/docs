## Was dies bedeutet {#what-this-means}

Der Speicher dieses Geräts reagiert nicht mehr, daher wurde das Speichern angehalten.

Starten Sie WCPOS neu (im Web laden Sie den Tab neu) und prüfen Sie anschließend, ob der letzte Verkauf oder die letzte Änderung gespeichert wurde – eine Änderung aus den Sekunden vor dem Ausfall wurde möglicherweise nicht geschrieben. Löschen Sie nicht die Daten dieses Geräts. Tritt das Problem weiterhin auf, wenden Sie sich an den Support.

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten dieses Geräts – möglicherweise enthält es Verkäufe, die Ihre Filiale noch nicht erreicht haben. Wenn dies weiterhin auftritt, verwenden Sie **Debug-Infos kopieren** auf dem Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Starten Sie WCPOS neu – schließen Sie die App und öffnen Sie sie erneut; im Web laden Sie den Tab neu, statt ihn zu schließen. Dadurch wird die lokale Datenbank in fast allen Fällen wieder verbunden.
2. Prüfen Sie nach dem Neustart, ob der letzte Verkauf oder die letzte Änderung gespeichert wurde: Eine Änderung aus den Sekunden vor dem Fehler wurde möglicherweise nicht geschrieben. Fehlt sie, geben Sie sie erneut ein.
3. Verwenden Sie im Web die Kasse nicht in einem privaten/Inkognito-Fenster und vermeiden Sie aggressive Erweiterungen zum Bereinigen des Speichers – beides kann den lokalen Speicher während einer Sitzung außer Betrieb setzen. Beim Schließen eines privaten Fensters werden alle darin gespeicherten Daten gelöscht, auch noch nicht gesendete Verkäufe. Ist ein solches Fenster gerade geöffnet, lassen Sie es geöffnet, bis unter **Filialstatus → Datenbank** der Wert 0 für **noch zu sendende Änderungen** angezeigt wird.
4. Wenn dies auf demselben Gerät regelmäßig auftritt, verwenden Sie **Debug-Infos kopieren** auf dem Tab **Protokolle** und wenden Sie sich an den Support. Geben Sie dabei an, was das Gerät zum Zeitpunkt des Fehlers tat (Ruhezustand, Tab-Wechsel, wenig Arbeitsspeicher).
