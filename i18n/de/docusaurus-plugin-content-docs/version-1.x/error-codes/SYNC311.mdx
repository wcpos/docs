## Was dies bedeutet {#what-this-means}

Daten auf diesem Gerät wurden mit einer anderen WCPOS-Version gespeichert und können noch nicht geöffnet werden.

Aktualisieren Sie WCPOS auf die neueste Version und öffnen Sie die App erneut. Falls sie weiterhin nicht geöffnet werden kann, tippen Sie auf **Debug-Infos kopieren** und wenden Sie sich an den Support. Dies tritt meist nach einem Update oder Downgrade der App auf diesem Gerät auf.

:::warning Löschen Sie nicht die Daten dieses Geräts
Auf diesem Gerät könnten Verkäufe gespeichert sein, die Ihre Filiale noch nicht erreicht haben — zum Beispiel offline erfasste Verkäufe. Solange die Daten nicht geöffnet werden können, lassen sie sich nicht senden. Durch das Löschen der lokalen Datenbank, Abmelden oder eine Neuinstallation würden sie dauerhaft gelöscht. Wenden Sie sich an den Support, bevor Sie etwas löschen.
:::

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten dieses Geräts — möglicherweise enthält es Verkäufe, die Ihre Filiale noch nicht erreicht haben. Die Daten Ihrer Filiale sind sicher und nicht betroffen.

## Fehlerbehebung {#troubleshoot}

1. Aktualisieren Sie WCPOS auf diesem Gerät auf die neueste Version und öffnen Sie die App erneut:
   - **Web:** Laden Sie den Browser-Tab neu. Wenn die alte Version wieder erscheint, halten Sie beim Neuladen **Shift** gedrückt. Das WCPOS-Plugin Ihrer Filiale bestimmt, welche Webversion geladen wird. Wenn das Neuladen nicht hilft, bitten Sie den Website-Administrator, das WCPOS-Plugin zu aktualisieren.
   - **Desktop:** Installieren Sie das ausstehende Update und öffnen Sie die App erneut. Wenn kein Update angeboten wird, laden Sie den neuesten Build von der Seite [Installation](/getting-started/installation) herunter.
   - **iPhone, iPad oder Android:** Aktualisieren Sie WCPOS über den Installationskanal — TestFlight unter iOS, das Play-Testprogramm unter Android. Beide sind auf der Seite [Installation](/getting-started/installation) verlinkt.
2. Wenn WCPOS weiterhin nicht geöffnet werden kann, tippen Sie im Tab **Protokolle** auf **Debug-Infos kopieren** und wenden Sie sich an den Support. Teilen Sie mit, ob auf diesem Gerät möglicherweise Verkäufe gespeichert sind, die Ihre Filiale noch nicht erreicht haben.
3. Löschen Sie während der Wartezeit keine lokalen Daten, melden Sie sich nicht ab und installieren Sie WCPOS nicht neu — der Support teilt Ihnen mit, ob auf diesem Gerät zuerst etwas wiederhergestellt werden muss.
