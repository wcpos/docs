## Was dies bedeutet {#what-this-means}

Bei der Synchronisierung ist ein unerwartetes Problem aufgetreten.

Prüfen Sie, ob die in diesem Eintrag genannte Aktion abgeschlossen wurde. Falls nicht, wiederholen Sie sie. Tritt dies erneut auf, tippen Sie auf **Copy debug info** und senden Sie die Informationen an den Support.

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten auf diesem Gerät – sie können Änderungen enthalten, die Ihre Filiale noch nicht erhalten hat. Wurde die im Eintrag genannte Aktion nicht abgeschlossen, wiederholen Sie sie.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie den Protokolleintrag auf und suchen Sie die darin genannte Aktion. Prüfen Sie, ob sie abgeschlossen wurde – öffnen Sie nach einem Speichervorgang die Bestellung oder den Datensatz und kontrollieren Sie, ob die Änderung angezeigt wird. Ist das der Fall, sendet WCPOS sie automatisch. Lassen Sie sie daher unverändert.
2. Falls die Aktion nicht abgeschlossen wurde, wiederholen Sie sie. Steht im Protokolleintrag, dass die Änderung auf diesem Gerät nie gespeichert wurde, wurde nichts erfasst.
3. Notieren Sie den Code und einen etwaigen Grund aus dem Protokolleintrag: Ein 999-Code bedeutet, dass es für die konkrete Ursache noch keinen eigenen Code gibt. Daher benötigt der Support genau diesen Kontext.
4. Tritt dies erneut auf, tippen Sie auf dem Tab **Logs** auf **Copy debug info** und senden Sie die Informationen an den Support – durch Ihre Meldung kann ein eigener Code für diese Ursache hinzugefügt werden.
