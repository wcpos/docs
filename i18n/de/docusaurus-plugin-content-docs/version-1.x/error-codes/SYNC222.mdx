## Was dies bedeutet {#what-this-means}

Dieses Gerät hat seine Version gespeichert und damit eine neuere Bearbeitung in Ihrer Filiale überschrieben.

Prüfen Sie die im Protokolleintrag aufgeführten Felder in WP Admin. Wenn die Bearbeitung der Filiale korrekt war, nehmen Sie sie dort erneut vor.

Dies geschieht bei Bestellungen. Die Bestellung wurde in Ihrer Filiale geändert, nachdem dieses Gerät sie zuletzt heruntergeladen hatte — durch eine Person in WP Admin oder automatisch durch ein Plugin oder eine Zahlungsbenachrichtigung. Als dieses Gerät anschließend seine eigene Änderung an der Bestellung speicherte, meldete die Filiale den Konflikt. Damit der Verkauf an der Kasse nicht aufgehalten wird, sendete WCPOS die Version dieses Geräts erneut und überschrieb damit die Version der Filiale; die Filiale akzeptierte sie. Der Protokolleintrag listet alle Felder auf, in denen der Wert dieses Geräts einen anderen Wert in der Filiale ersetzt hat. Einige davon können eigene Änderungen dieses Geräts sein — etwa eine hinzugefügte Position oder ein an der Kasse festgelegter Status — und nicht Bearbeitungen in der Filiale.

Wenn derselbe Konflikt zweimal hintereinander auftritt, hält WCPOS die Änderung stattdessen zurück und bittet Sie um eine Auswahl — siehe [SYNC221](/error-codes/SYNC221).

## Ihre Daten {#your-data}

Die Bestellung ist mit der Version dieses Geräts in Ihrer Filiale gespeichert; an der Kasse ging nichts verloren. Möglicherweise muss die neuere Bearbeitung der Filiale in den aufgeführten Feldern erneut vorgenommen werden. Das Protokoll listet die ersetzten Felder auf, nicht deren alte Werte. Wenn der Eintrag angibt, dass nur einige Felder angezeigt werden, wurden weitere ersetzt, als aufgeführt sind — prüfen Sie die gesamte Bestellung.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie den Protokolleintrag auf: Er nennt die Bestellung und listet die Felder auf, in denen der Wert dieses Geräts den Wert der Filiale ersetzt hat.
2. Öffnen Sie die Bestellung unter **WooCommerce → Bestellungen** in WP Admin und prüfen Sie diese Felder. In den Bestellnotizen steht möglicherweise, wer oder was die Bearbeitung in der Filiale vorgenommen hat.
3. Wenn die Felder so korrekt sind — beispielsweise weil sie der Änderung an der Kasse entsprechen — müssen Sie nichts tun.
4. Wenn die Bearbeitung der Filiale korrekt war, nehmen Sie sie in WP Admin erneut vor. Die Kasse übernimmt die Änderung bei der nächsten Synchronisierung.
5. Wenn dies wiederholt geschieht, ändern zwei Stellen gleichzeitig dieselben Bestellungen — beispielsweise wird in WP Admin ein Status festgelegt, während der Verkauf an der Kasse noch geöffnet ist, oder ein Plugin aktualisiert Bestellungen nach ihrer Erstellung. Legen Sie fest, wo die jeweiligen Bestelländerungen vorgenommen werden. Ein Website-Administrator kann prüfen, welches Plugin Bestellungen bearbeitet.
