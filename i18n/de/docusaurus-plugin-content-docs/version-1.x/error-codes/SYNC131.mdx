## Was dies bedeutet {#what-this-means}

Bei Ihrer Filiale ist ein Fehler aufgetreten und sie hat diese Anfrage nicht abgeschlossen.

Die Filiale wurde erreicht, aber ihr Server konnte die Anfrage nicht verarbeiten – das Problem liegt bei der Website und nicht beim POS. Versuchen Sie die Aktion erneut. Wenn das Problem weiterhin auftritt, bitten Sie Ihre Website-Administration, **WooCommerce → Status → Protokolle** zu prüfen. Auf diesem Gerät ist nichts verloren gegangen.

## Ihre Daten {#your-data}

Löschen Sie nicht die Daten dieses Geräts – möglicherweise enthält es Änderungen, die Ihre Filiale noch nicht hat. Eine gerade gesendete Änderung hat Ihre Filiale möglicherweise nicht erreicht. Wenn dies weiterhin auftritt, verwenden Sie **Debug-Infos kopieren** auf dem Tab **Protokolle** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

**Im POS (Kassierer):** Klappen Sie den Protokolleintrag auf und notieren Sie Status, Endpunkt und serverCode – daran erkennen Sie, was der Server zum Zeitpunkt des Fehlers gerade tat.

**Auf der Website (Website-Administrator / Hosting-Anbieter):**

1. Öffnen Sie WooCommerce → Status → Protokolle auf der Website und prüfen Sie das neueste Protokoll der fatalen Fehler rund um den Fehlerzeitpunkt; eine Antwort der 500er-Klasse hinterlässt dort fast immer einen PHP-Fehler.
2. Wenn der Fehler nach einem Plugin-, Theme- oder PHP-Update auf der Website begonnen hat, verdächtigen Sie zuerst diese Änderung und machen Sie sie rückgängig oder deaktivieren Sie sie.
3. Wenn die Protokolle von WooCommerce nichts zeigen, fragen Sie den Hosting-Anbieter nach dem PHP-Fehlerprotokoll des Servers für denselben Zeitraum.

**Anschließend zurück im POS:** Versuchen Sie die Aktion erneut.
