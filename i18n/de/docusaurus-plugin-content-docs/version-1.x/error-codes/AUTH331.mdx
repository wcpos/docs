## Was dies bedeutet {#what-this-means}

Das WCPOS-Plugin dieses Shops ist zu alt für diese Version der App.

Die App wurde aktualisiert, das WCPOS-Plugin im Shop jedoch nicht, und die beiden Versionen sind nicht mehr miteinander kompatibel. Bitten Sie die Person, die die Website verwaltet, das WCPOS-Plugin im WP Admin zu aktualisieren, und stellen Sie dann erneut eine Verbindung her. An der Kasse muss nichts geändert werden.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen. Falls dies weiterhin auftritt, wenden Sie sich an die Person, die Ihre WordPress-Website verwaltet.

## Fehlerbehebung {#troubleshoot}

**Im Shop** — für die Person, die die WordPress-Website verwaltet:

1. WP Admin → Plugins → WCPOS auf die neueste Version aktualisieren. Falls WCPOS Pro installiert ist, aktualisieren Sie es gleichzeitig auf eine passende Version.
2. Wird kein Update angeboten, prüfen Sie WP Admin → Dashboard → Aktualisierungen; bei Pro blockiert ein nicht autorisierter Updater die Updates (siehe [LICENSE301](./LICENSE301)) — beheben Sie das zuerst.

**An der Kasse** — für den Kassierer: Sobald der Shop aktualisiert wurde, verbinden Sie sich erneut. Sie müssen die Shop-Adresse nicht noch einmal eingeben.

**Falls der Shop noch nicht aktualisiert werden kann:** Wenden Sie sich stattdessen an den Support — die Kasse benötigt eine App-Version, die zum Plugin passt, und der Support kann Ihnen sagen, welche das ist. Man wird nach der App-Version (von der Kasse) und der aktuellen WCPOS-Version des Shops (aus dem WP Admin) fragen.
