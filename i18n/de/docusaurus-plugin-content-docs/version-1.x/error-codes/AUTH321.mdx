## Was dies bedeutet {#what-this-means}

WooCommerce ist auf dieser Website nicht aktiv, daher kann WCPOS keine Verbindung herstellen.

WCPOS benötigt das WooCommerce-Plugin. Bitten Sie den Website-Administrator, WooCommerce zu installieren oder erneut zu aktivieren, und stellen Sie dann erneut eine Verbindung her.

## Ihre Daten {#your-data}

Es sind keine Bestell- oder Produktdaten betroffen. Wenn dies weiterhin auftritt, wenden Sie sich an die Person, die Ihre WordPress-Website betreut.

## Fehlerbehebung {#troubleshoot}

1. Bitten Sie den Website-Administrator, WP Admin → Plugins zu prüfen: WooCommerce muss installiert und aktiv sein, damit WCPOS eine Verbindung herstellen kann.
2. Wenn WooCommerce durch ein fehlgeschlagenes Update deaktiviert wurde, aktivieren Sie es erneut und achten Sie auf ein Fehlerbanner — WooCommerce → Status → Protokolle zeichnet auf, warum es fehlgeschlagen ist.
3. Sobald WooCommerce wieder aktiv ist, stellen Sie von der Kasse aus erneut eine Verbindung her.
