## Bedeutung {#what-this-means}

Diese Filiale benötigt jetzt eine neuere Version der POS-App.

Das WCPOS-Plugin Ihrer Filiale verwendet jetzt ein neueres Synchronisierungsprotokoll, als diese App-Version unterstützt. Daher wird die Synchronisierung bewusst angehalten, bis die App aktualisiert wurde. Dies ist eine Schutzmaßnahme, kein Fehler: Sie verhindert, dass eine veraltete App Filialdaten falsch liest oder schreibt.

## Ihre Daten {#your-data}

An der Kasse geht nichts verloren. Verkäufe und Änderungen, die noch gesendet werden müssen, bleiben sicher auf dem Gerät und werden synchronisiert, sobald sich eine aktualisierte App mit der Filiale verbindet. Falls noch keine neuere App verfügbar ist (siehe die letzten beiden Schritte unten), bleiben sie in der Warteschlange, bis eine verfügbar ist.

## Fehlerbehebung {#troubleshoot}

1. Laden Sie in der Web-App den Browser-Tab neu — die Web-App übernimmt die neue Version beim Neuladen. Wenn der Bildschirm erneut angezeigt wird, führen Sie ein vollständiges Neuladen durch (halten Sie beim Neuladen **Shift** gedrückt).
2. Installieren Sie auf dem Desktop das ausstehende Update und öffnen Sie die App erneut — die Prüfung erfolgt, wenn die App sich wieder verbindet. Wenn kein Update angeboten wird, laden Sie den neuesten Build von der Seite [Installation](/getting-started/installation) herunter.
3. Aktualisieren Sie WCPOS auf iPhone, iPad oder Android über den Installationskanal — TestFlight unter iOS oder das Play-Testprogramm unter Android; beide sind auf der Seite [Installation](/getting-started/installation) verlinkt — und öffnen Sie anschließend die App erneut.
4. **Website-Administrator:** Wenn noch keine neuere App verfügbar ist, wurde das WCPOS-Plugin der Filiale vor der entsprechenden App-Version aktualisiert. Durch die Wiederherstellung der vorherigen WCPOS-Plugin-Version in der Filiale wird die Synchronisierung fortgesetzt, bis die neuere App veröffentlicht wird.
5. Wenn weder ein App-Update noch ein Plugin-Rollback verfügbar ist, wenden Sie sich an den WCPOS-Support.
