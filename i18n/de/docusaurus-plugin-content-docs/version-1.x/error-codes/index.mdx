# Fehlercodes {#error-codes}

Wenn WCPOS auf ein Problem stößt, zeigt es einen Fehlercode an, der hilft, das Problem zu identifizieren. Ab **v1.10.0** folgen die Codes dem Format **Domain + drei Ziffern** — zum Beispiel `SYNC131` oder `AUTH311`. Die Domain benennt den Bereich des POS; die Zahl bezeichnet die konkrete Situation. Zu jedem Code gibt es eine eigene Seite mit der Bedeutung, den empfohlenen Schritten und den Auswirkungen auf Ihre Daten.

Im POS erscheinen Fehlercodes unter **Shop-Zustand → Protokolle**: Klappen Sie eine Zeile auf und nutzen Sie den Link **Hilfe**, um direkt zur Seite des Codes hier zu springen.

## Fehlerdomains (ab v1.10.0) {#error-domains}

| Domain | Bereich | Beispiele |
|--------|---------|-----------|
| `AUTH` | Anmeldung, Sitzungen und Tokens | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | Abschluss von Bestellungen an der Kasse | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | Die POS-App selbst und der lokale Speicher | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `LICENSE` | Aktivierung und Validierung der Pro-Lizenz | [LICENSE101](./LICENSE101) |
| `PAYMENT` | Zahlungsgateways und Terminals | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | Belegdruck | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | Produktdaten und Katalogvorgänge | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `SYNC` | Synchronisierung zwischen dem POS und Ihrem Shop | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

Verwenden Sie die Seitenleiste, um alle Codes einer Domain zu durchsuchen, oder suchen Sie direkt nach dem Code.

Codes, die auf `999` enden, sind der Auffangcode der jeweiligen Domain für Situationen, für die es noch keinen spezifischen Code gibt.

## Alte Codes (vor v1.10.0) {#legacy-codes}

Versionen vor v1.10.0 verwendeten ein anderes Schema: `[DOMAIN][CATEGORY][SPECIFIC_CODE]`, z. B. `API04001` = API (Domain) + 04 (Antwortfehler) + 001 (ungültiges Antwortformat). Wenn Sie eine ältere Version einsetzen oder einen alten Protokolleintrag bzw. Support-Thread lesen, gelten diese Seiten weiterhin:

| Domain | Gesamte Codes | Umfasst |
|--------|---------------|---------------|
| [API](./api) | 39 Codes | Serverkommunikation, Authentifizierung, Plugin-Probleme |
| [DB](./db) | 9 Codes | Lokale Datenspeicherung und -abfrage |
| [PY](./py) | 6 Codes | Zahlungsabwicklung |
| [SY](./sy) | 5 Codes | Geräteressourcen und Konfiguration |

Ein Client ab v1.10.0 gibt diese Codes nie aus — wenn Sie einen davon auf einem aktuellen POS sehen, stammt er aus einem alten, noch aufbewahrten Protokolleintrag oder aus einer serverseitigen Meldung.

## Weitere Hilfe benötigt? {#need-more-help}

Wenn Sie weiterhin Probleme haben, nachdem Sie die Problemlösungsansätze befolgt haben:

1. Überprüfen Sie den [Fehlerbehebung](/support/troubleshooting/response-error)-Bereich für detailliertere Anleitungen
2. Treten Sie unserer [Discord-Community](https://wcpos.com/discord) bei, um Unterstützung zu erhalten
3. Melden Sie Probleme auf [GitHub](https://github.com/wcpos)
