# Fehlercodes {#error-codes}

Wenn in WCPOS ein Problem auftritt, wird ein Fehlercode angezeigt, der bei der Bestimmung der Ursache hilft. Ab **v1.10.0** folgen die Codes dem Format **Bereich + drei Ziffern** — zum Beispiel `SYNC131` oder `AUTH311`. Der Bereich bezeichnet den Teil des POS; die Zahl identifiziert den konkreten Zustand. Zu jedem Code gibt es eine eigene Seite mit Erklärung, Handlungsempfehlungen und Informationen zu den Auswirkungen auf Ihre Daten.

Im POS erscheinen Fehlercodes unter **Shop-Zustand → Protokolle**: Klappen Sie eine Zeile auf und verwenden Sie den Link **Hilfe**, um direkt zur Seite des Codes zu gelangen.

## Fehlerbereiche (v1.10.0+) {#error-domains}

| Bereich | Teilbereich | Beispiele |
|--------|------|----------|
| `AUTH` | Anmeldung, Sitzungen und Tokens | [AUTH101](./AUTH101.mdx), [AUTH311](./AUTH311.mdx) |
| `CHECKOUT` | Bestellungen an der Kasse abschließen | [CHECKOUT101](./CHECKOUT101.mdx), [CHECKOUT201](./CHECKOUT201.mdx) |
| `CLIENT` | Die POS-App selbst und lokaler Speicher | [CLIENT101](./CLIENT101.mdx), [CLIENT201](./CLIENT201.mdx) |
| `HOST` | Hosting- und Firewallregeln, die den POS blockieren | [HOST101](./HOST101.mdx), [HOST121](./HOST121.mdx) |
| `LICENSE` | Aktivierung und Validierung der Pro-Lizenz | [LICENSE101](./LICENSE101.mdx) |
| `PAYMENT` | Zahlungsgateways und Terminals | [PAYMENT101](./PAYMENT101.mdx), [PAYMENT301](./PAYMENT301.mdx) |
| `PRINT` | Belegdruck | [PRINT101](./PRINT101.mdx), [PRINT301](./PRINT301.mdx) |
| `PRODUCT` | Produktdaten und Katalogvorgänge | [PRODUCT101](./PRODUCT101.mdx), [PRODUCT401](./PRODUCT401.mdx) |
| `SYNC` | Synchronisierung zwischen POS und Ihrer Filiale | [SYNC101](./SYNC101.mdx), [SYNC121](./SYNC121.mdx), [SYNC311](./SYNC311.mdx) |

Verwenden Sie die Seitenleiste, um alle Codes eines Bereichs zu durchsuchen, oder suchen Sie direkt nach dem Code.

Codes mit der Endung `999` sind Auffangcodes eines Bereichs für Zustände, für die es noch keinen spezifischen Code gibt.

## Ältere Codes (vor v1.10.0) {#legacy-codes}

In Versionen vor v1.10.0 wurde ein anderes Schema verwendet: `[DOMAIN][CATEGORY][SPECIFIC_CODE]`, z. B. `API04001` = API (Bereich) + 04 (Antwortfehler) + 001 (ungültiges Antwortformat). Wenn Sie eine ältere Version verwenden oder einen alten Protokolleintrag bzw. Support-Beitrag lesen, sind diese Seiten weiterhin relevant:

| Bereich | Anzahl der Codes | Beschreibung |
|--------|-------------|---------------|
| [API](./api.mdx) | 39 Codes | Serverkommunikation, Authentifizierung, Plugin-Probleme |
| [DB](./db.mdx) | 9 Codes | Lokale Datenspeicherung und -abruf |
| [PY](./py.mdx) | 6 Codes | Zahlungsabwicklung |
| [SY](./sy.mdx) | 5 Codes | Geräteressourcen und Konfiguration |

Ein Client ab v1.10.0 gibt diese Codes nie aus — wenn Sie einen auf einem aktuellen POS sehen, stammt er aus einem alten gespeicherten Protokolleintrag oder einer serverseitigen Meldung.

## Benötigen Sie weitere Hilfe? {#need-more-help}

Wenn weiterhin Probleme auftreten, nachdem Sie die Schritte zur Fehlerbehebung befolgt haben:

1. Überprüfen Sie den [Fehlerbehebung](/support/troubleshooting/response-error)-Bereich für detailliertere Anleitungen
2. Treten Sie unserer [Discord-Community](https://wcpos.com/discord) bei, um Unterstützung zu erhalten
3. Melden Sie Probleme auf [GitHub](https://github.com/wcpos)
