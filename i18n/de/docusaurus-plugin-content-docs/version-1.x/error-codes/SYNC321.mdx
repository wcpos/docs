## Was dies bedeutet {#what-this-means}

Einige Datensätze wurden synchronisiert, einer oder mehrere jedoch nicht.

Dieser Code tritt in zwei Formen auf — der Titel der Protokollzeile zeigt, welche davon vorliegt:

- **„Sync partial“** (Datensatztitel): Einige Datensätze wurden synchronisiert, die genannten jedoch nicht. Prüfen Sie jeden genannten Datensatz und den jeweiligen Grund, bevor Sie nur diese Datensätze erneut synchronisieren.
- **„Gave up on a stuck data request“**: Der Datenanforderungs-Bereich der Synchronisierungs-Engine machte bei einer Anfrage keine Fortschritte. Nach einer großzügig bemessenen Wartezeit hat die App diese Anfrage aufgegeben, anstatt dadurch alle dahinter wartenden Anfragen zu blockieren. Sie müssen nichts manuell wiederholen — die Synchronisierungs-Engine stellt die Anfrage automatisch erneut. Häufig geht dem ein blockierter Aufruf der lokalen Datenbank voraus, der separat als [SYNC181](/error-codes/SYNC181) protokolliert wird.

## Ihre Daten {#your-data}

Bei nicht synchronisierten Datensätzen ist die Änderung auf diesem Gerät gespeichert, hat Ihre Filiale aber noch nicht erreicht. Wenn das Problem weiterhin besteht, exportieren Sie die Diagnoseinformationen und wenden Sie sich an den WCPOS-Support. Bei einer aufgegebenen Datenanfrage wurde nichts geändert — die aufgegebene Anfrage wird automatisch erneut gestellt.

## Fehlerbehebung {#troubleshoot}

1. Bei einer unvollständigen Synchronisierung erweitern Sie den Protokolleintrag, um zu sehen, welche Datensätze nicht synchronisiert wurden und welcher Grund jeweils angegeben ist.
2. Behandeln Sie jeden genannten Datensatz nach seiner eigenen Ursache — ein ungültiges Feld muss bearbeitet, ein Konflikt mit dem Shop verglichen werden.
3. Versuchen Sie nur die fehlgeschlagenen Datensätze erneut; die übrigen sind bereits synchronisiert und benötigen nichts.
4. Bei einem Eintrag „Gave up on a stuck data request“ ist keine Aktion erforderlich, es sei denn, die Anzeige bleibt hängen — laden Sie die App dann neu. Wenn das Problem weiterhin auftritt, exportieren Sie die Debug-Informationen und wenden Sie sich an den Support.
