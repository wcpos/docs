## Was dies bedeutet {#what-this-means}

Beim Drucken ist ein unerwartetes Problem aufgetreten. Kein Verkauf ist betroffen.

Wiederholen Sie den in diesem Eintrag genannten Druck- oder Belegvorgang. Wenden Sie sich an den Support, wenn das Problem erneut auftritt.

## Ihre Daten {#your-data}

Kein Verkauf ist betroffen.

## Fehlerbehebung {#troubleshoot}

1. Klappen Sie zuerst den Protokolleintrag auf und bestimmen Sie den fehlgeschlagenen Vorgang — dieser Code deckt auch Aktionen der Beleg-E-Mail-Warteschlange und die Synchronisierung von Belegvorlagen ab, nicht nur den physischen Druck.
2. Wiederholen Sie nur den im Protokoll genannten Vorgang. Drucken Sie über die Bestellansicht nur dann erneut, wenn ein physischer Ausdruck fehlgeschlagen ist; senden Sie eine wartende E-Mail über Store health erneut und versuchen Sie die Vorlagensynchronisierung erneut, indem Sie bei bestehender Verbindung die Belegansicht öffnen.
3. Wenn der Vorgang weiterhin fehlschlägt, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den Support.
