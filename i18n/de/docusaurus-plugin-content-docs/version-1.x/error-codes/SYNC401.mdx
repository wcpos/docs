## Was dies bedeutet {#what-this-means}

Eine Hintergrundaufgabe der Synchronisierung wurde unerwartet vor ihrem Abschluss beendet.

Sie müssen nichts tun – der POS startet diese Aufgaben automatisch neu, und es geht nichts verloren. Wenn dieser Code weiterhin erscheint, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den Support.

## Ihre Daten {#your-data}

Es geht nichts verloren – Bestell- und Produktdaten sind nicht betroffen. Wenn das Problem weiterhin besteht, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den WCPOS-Support.

## Fehlerbehebung {#troubleshoot}

1. Zunächst ist nichts zu tun: Das POS startet die abgestürzte Hintergrundaufgabe automatisch neu, und es sind keine Bestelldaten beteiligt.
2. Wenn sich der Code innerhalb von Minuten wiederholt, laden Sie die App einmal neu, damit die Synchronisierungs-Engine sauber startet.
3. Wenn dies weiterhin auftritt, verwenden Sie **Copy debug info** auf dem Tab **Logs** und wenden Sie sich an den Support – ein wiederkehrender Absturz einer Aufgabe ist ein meldewürdiger App-Fehler und kein Problem der Filiale.
