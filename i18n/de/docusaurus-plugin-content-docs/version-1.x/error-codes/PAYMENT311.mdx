## Was dies bedeutet {#what-this-means}

WCPOS konnte nicht bestätigen, ob diese Rückerstattung durchgeführt wurde.

Öffnen Sie die Bestellung und prüfen Sie die Rückerstattungen, bevor Sie es erneut versuchen — ein erneuter Versuch könnte doppelt erstatten.

Die Rückerstattungsanfrage wurde gesendet, aber die Antwort ging verloren — die Anfrage lief ab, die Filiale antwortete mit einem Fehler oder bat WCPOS zu warten und es erneut zu versuchen. Die Rückerstattung wurde möglicherweise durchgeführt. Jeder erneute Versuch sendet eine neue Anfrage an das Zahlungsgateway. Ohne vorherige Prüfung könnte der Kunde daher doppelt erstattet werden.

## Ihre Daten {#your-data}

Auf diesem Gerät geht nichts verloren. Ihre Filiale oder das Zahlungsgateway hat dem Kunden möglicherweise bereits den Betrag erstattet.

## Fehlerbehebung {#troubleshoot}

1. Führen Sie die Rückerstattung vorerst nicht erneut durch.
2. Öffnen Sie die Bestellung unter **Bestellungen** und prüfen Sie die Rückerstattungen — sie werden direkt aus Ihrer Filiale geladen, daher muss dieses Gerät online sein. Sie können die Bestellung auch unter **WooCommerce → Bestellungen** in WP Admin öffnen; dort sind die Rückerstattungen aufgeführt.
3. Wenn die Rückerstattung über ein Zahlungsgateway erfolgte — ein Kartenterminal oder ein Anbieter wie Vipps MobilePay — prüfen Sie auch das Dashboard des Gateways oder bitten Sie den Filialinhaber darum. Dort sehen Sie, ob die Rückerstattung gesendet wurde, selbst wenn sie in der Bestellung noch nicht angezeigt wird.
4. Wenn die Rückerstattung aufgeführt ist, wurde sie durchgeführt — führen Sie sie nicht erneut durch. Nur wenn sie an keinem der beiden Orte erscheint, versuchen Sie es erneut. Wenn niemand das Gateway prüfen kann, fahren Sie stattdessen mit dem nächsten Schritt fort.
5. Wenn weiterhin unklar ist, was geschehen ist, tippen Sie im Tab **Protokolle** auf **Debug-Infos kopieren** und wenden Sie sich vor einem erneuten Versuch an den Support.
