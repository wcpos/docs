WCPOS arbeitet mit den Geräten, die Sie an der Kasse ohnehin schon verwenden. Diese Seite ist der Ausgangspunkt für den Anschluss von Hardware — Bondrucker, Barcodescanner, Kartenlesegeräte und Kassenschubladen. Jeder Gerätetyp hat entweder eine eigene Einrichtungsseite in diesem Bereich oder verweist auf die Seite, auf der die Einrichtung tatsächlich beschrieben ist.

:::note Ein Zuhause pro Gerät
Der Hardware-Bereich verweist Sie auf die Einrichtung des jeweiligen Geräts, aber die eigentlichen Schritte stehen an genau einer Stelle. Konto und Kopplung eines Kartenlesegeräts stehen auf der Seite seines Zahlungsgateways; Verkabelung und Öffnungseinstellung einer Kassenschublade stehen auf der Seite Kassenschublade.
:::

## Kompatibilität von Kartenlesegeräten {#card-reader-compatibility}

Welche Kartenlesegeräte funktionieren, hängt davon ab, **wie Sie WCPOS betreiben**, und von der Anschlussart des Lesegeräts:

- **Die Web-App** kann nur Lesegeräte ansteuern, die ein **Web-SDK (Browser-SDK)** anbieten — in der Regel internetfähige Thekenterminals. Reine **Bluetooth**-Lesegeräte (z. B. Stripe M2 / WisePad 3, SumUp Air) und **Tap-to-Pay** per Telefon werden in der Web-App **nicht unterstützt**.
- Die Unterstützung gilt **pro Gateway**, nicht allgemein — prüfen Sie das Lesegerät vor dem Kauf gegen das Gateway, das Sie einsetzen möchten ([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [PayPal Reader](/payment/gateways/paypal-reader)).

Auf jeder Gateway-Seite sind die genau unterstützten Lesegeräte aufgeführt.
