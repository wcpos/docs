Diese Seite ist der Ausgangspunkt für den Anschluss von Hardware — Belegdrucker, Barcodescanner, Kartenlesegeräte und Kassenschubladen. Jeder Gerätetyp hat entweder eine eigene Einrichtungsseite in diesem Bereich oder verweist auf die Seite, auf der seine Einrichtung beschrieben ist.

## Kompatibilität von Kartenlesegeräten {#card-reader-compatibility}

Welche Kartenlesegeräte funktionieren, hängt davon ab, **wie Sie WCPOS betreiben**, und von der Anschlussart des Lesegeräts:

- **Die Web-App** kann nur Lesegeräte ansteuern, die ein **Web-SDK (Browser-SDK)** anbieten — in der Regel internetfähige Thekenterminals. Lesegeräte **nur mit Bluetooth** (z. B. Stripe M2 / WisePad 3, SumUp Air) und **Tap-to-Pay** per Smartphone werden in der Web-App **nicht unterstützt**.
- Die Unterstützung gilt **pro Zahlungsgateway**, nicht allgemein — prüfen Sie vor dem Kauf, ob das Lesegerät mit dem Zahlungsgateway funktioniert, das Sie einsetzen möchten ([Stripe Terminal](/1.x/payment/gateways/stripe-terminal), [SumUp](/1.x/payment/gateways/sumup-terminal), [PayPal Reader](/1.x/payment/gateways/paypal-reader)).

Auf jeder Seite eines Zahlungsgateways sind die unterstützten Lesegeräte im Einzelnen aufgeführt.
