WCPOS funktioniert mit den physischen Geräten, die bereits an der Kasse verwendet werden. Diese Seite ist der Ausgangspunkt zum Verbinden von Hardware — Belegdruckern, Barcodescannern, Kartenlesegeräten und Kassenschubladen. Jeder Gerätetyp verfügt hier entweder über eine eigene Einrichtungsseite oder verweist auf die Seite, auf der die Einrichtung tatsächlich beschrieben wird.

## Kompatibilität von Kartenlesern {#card-reader-compatibility}

Welche Kartenleser funktionieren, hängt davon ab, **wie Sie WCPOS verwenden**, und von der Verbindungsart des Lesers:

- **Die Web-App** kann nur Leser ansteuern, die ein **Web- (Browser-) SDK** bieten — in der Regel internetverbundene stationäre Terminals. **Reine Bluetooth-**Leser (z. B. Stripe M2 / WisePad 3, SumUp Air) und **Tap-to-Pay** per Smartphone werden in der Web-App **nicht unterstützt**.
- Die Unterstützung erfolgt **pro Zahlungsgateway**, nicht allgemein — prüfen Sie den Leser vor dem Kauf anhand des Zahlungsgateways, das Sie verwenden möchten ([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [PayPal Reader](/payment/gateways/paypal-reader)).

Auf jeder Zahlungsgateway-Seite sind die exakt unterstützten Leser aufgeführt.
