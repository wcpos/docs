**Symptom:** Die Webseite des Druckers lädt, sein Selbsttest über das Bedienfeld druckt, Sicheres Drucken ist bereits aus — und trotzdem scheitert jeder Auftrag aus dem POS oder läuft in eine Zeitüberschreitung. Ein Neustart am Netzstecker ändert nichts.

## Warum das passiert {#why-it-happens}

Epson-Drucker lassen sich so einstellen, dass sie ihre Aufträge selbst von einem Server abholen — eine Funktion namens **Server Direct Print**. Eine verwandte Funktion, **ePOS-Device**, erlaubt es einer Anwendung, den Drucker für eine Sitzung zu belegen. Beide übernehmen das Druckwerk, und solange es belegt ist, weist der Drucker alles andere als beschäftigt ab — ohne das zu melden. Weil es eine gespeicherte Einstellung im Drucker ist, hilft ein Neustart nicht.

Meist wurde das von einer früheren Installation, einem Küchendruck-Dienst oder einer anderen Kasse aktiviert gelassen.

## So schalten Sie es ab {#turn-it-off}

1. Öffnen Sie `https://printer-ip` in einem Browser und akzeptieren Sie die Zertifikatswarnung.
2. **Administrator-Anmeldung** — das Passwort ist die Seriennummer auf dem Etikett an der Unterseite des Druckers, sofern es niemand geändert hat.
3. Suchen Sie **Server Direct Print** (je nach Firmware unter den Diensten oder den Druckeinstellungen des Druckers) und setzen Sie es auf **Deaktivieren**.
4. Prüfen Sie auf derselben Seite, ob auch **ePOS-Device** deaktiviert ist, falls nichts anderes es nutzt.
5. Bestätigen Sie, ziehen Sie dann den Netzstecker des Druckers für zehn Sekunden und stecken Sie ihn wieder ein.
6. Drucken Sie die Testseite erneut.

:::note Möglicherweise nutzt etwas anderes die Funktion
Wenn ein anderes System tatsächlich über Server Direct Print druckt — ein Küchendisplay, ein Online-Bestelldienst —, kann nur eines von beiden den Drucker belegen. Leiten Sie dieses System woandershin, oder geben Sie dem POS einen eigenen Drucker.
:::

## Immer noch nicht gelöst? {#still-stuck}

Nutzen Sie **Einrichtungsbericht kopieren** auf dem Problembildschirm und fügen Sie ihn in Ihre Nachricht ein — er hält fest, wie der Drucker auf jedem Port geantwortet hat.
