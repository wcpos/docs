**Symptom:** Auf einem Android-Telefon oder -Tablet findet der Suchlauf nichts, ein Bluetooth-Drucker taucht nie in der Auswahl auf, oder ein Drucker unter einer bekannten Adresse läuft in eine Zeitüberschreitung.

## Warum das passiert {#why-it-happens}

Android regelt diese Punkte getrennt, und eine Ablehnung bleibt unbemerkt — eine blockierte Verbindung läuft genauso in eine Zeitüberschreitung wie ein ausgeschalteter Drucker.

- **Geräte in der Nähe** deckt das Finden von und Verbinden mit Bluetooth-Druckern ab.
- **Lokales Netzwerk** muss auf neueren Android-Versionen erlaubt sein, bevor eine App etwas in Ihrem WLAN erreichen darf.

## Die Berechtigungen aktivieren {#turn-the-permissions-on}

1. Öffnen Sie unter Android **Einstellungen → Apps → WCPOS → Berechtigungen**.
2. Erlauben Sie **Geräte in der Nähe**.
3. Wenn **Lokales Netzwerk** aufgeführt ist, erlauben Sie das ebenfalls. Ältere Android-Versionen haben es nicht.
4. Schließen Sie die App, öffnen Sie sie erneut und starten Sie dann den Suchlauf.

## Bluetooth-Drucker {#bluetooth-printers}

Unter Android verbinden sich Epson- und Star-Drucker über die Software des jeweiligen Herstellers und müssen **zuerst in Android gekoppelt** werden — **Einstellungen → Verbundene Geräte → Neues Gerät koppeln** —, bevor sie in der App erscheinen. Kleine Bluetooth-Low-Energy-Drucker wählen Sie stattdessen in der Auswahl der App aus; koppeln Sie diese nicht in Android. Siehe [Einen Bluetooth-Bondrucker koppeln](/hardware/printers/bluetooth-pairing).

## WLAN-Drucker {#wi-fi-printers}

Prüfen Sie, ob das Tablet im WLAN des Ladens ist und nicht im Mobilfunknetz oder in einem Gastnetzwerk. Wenn der Suchlauf leer bleibt, Sie die Adresse des Druckers aber kennen, nutzen Sie **IP-Adresse eingeben** — damit wird die eine Adresse direkt geprüft, unabhängig von der Geräteerkennung.
