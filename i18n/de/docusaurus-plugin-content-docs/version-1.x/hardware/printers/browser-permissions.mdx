**Symptom:** Das POS läuft im Browser und erreicht den Drucker nicht — der Suchlauf findet nichts, oder derselbe Drucker druckt aus der Desktop-App, aber nicht aus dem Browser-Tab.

## Zugriff auf das lokale Netzwerk erlauben {#allow-local-network-access}

Chrome und Edge fragen nach einer Erlaubnis, bevor eine Website mit einem Gerät in Ihrem Netzwerk sprechen darf. Wurde diese Abfrage weggeklickt, scheitert danach jeder Versuch unbemerkt.

Klicken Sie auf das Symbol links in der Adressleiste → **Website-Einstellungen** → setzen Sie **Lokales Netzwerk** auf **Zulassen**, laden Sie die Seite neu und suchen Sie erneut.

## Gemischte Inhalte {#mixed-content}

Ein POS, das über `https://` ausgeliefert wird, kann keine einfache `http://`-Verbindung zu einem Drucker öffnen. Chrome und Edge erlauben es, sobald Sie den Zugriff auf das lokale Netzwerk gestattet haben; andere Browser blockieren es grundsätzlich. Wenn Ihr Shop über HTTPS läuft und der Drucker nur HTTP beherrscht, nutzen Sie die Desktop-App.

## Das Zertifikat des Druckers {#the-printers-certificate}

Drucker sichern sich mit einem eigenen Zertifikat ab, dem kein Browser von Haus aus vertraut — die Verbindung scheitert, bevor sie beginnt. Öffnen Sie `https://printer-ip` einmal im selben Browser, akzeptieren Sie die Warnung und kehren Sie zum POS zurück. Das müssen Sie auf jedem Computer einmal tun.

Die Desktop-App hat dieses Problem nicht: Sie akzeptiert das Zertifikat des Druckers selbst, weshalb derselbe Drucker dort funktioniert und im Tab nicht.

## Safari und Firefox {#safari-and-firefox}

Beide bieten keinen dieser Wege. Es gibt dort keine Berechtigung für das lokale Netzwerk, die man erteilen könnte, und keine Unterstützung für USB- oder Bluetooth-Drucker von einer Webseite aus. Nutzen Sie in diesen Browsern einen WLAN-Drucker, der zu HTTP oder HTTPS Ihres Shops passt, oder die Desktop-App.

## Immer noch nicht gelöst? {#still-stuck}

Nutzen Sie **Einrichtungsbericht kopieren** auf dem Problembildschirm und fügen Sie ihn in Ihre Nachricht ein — er hält fest, welcher Browser und welche Verbindungswege versucht wurden.
