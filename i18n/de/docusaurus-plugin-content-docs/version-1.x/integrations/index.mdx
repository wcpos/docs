WCPOS basiert auf der WooCommerce REST API, sodass die meisten WooCommerce-Plugins ohne zusätzliche Einrichtung mit POS-Bestellungen funktionieren. Einige benötigen Unterstützung durch WCPOS, da sie nur in den Online-Checkout oder in den Bestellbildschirm von WP Admin eingebunden sind. Die Seiten in diesem Abschnitt behandeln diese Plugins: was WCPOS für sie übernimmt, wie sie eingerichtet werden und was an der Kasse zu erwarten ist.

Das unterscheidet Integrationen von [Erweiterungen](/1.x/extensions): Erweiterungen sind speziell für WCPOS entwickelte Add-ons, die Sie aus dem Erweiterungsverzeichnis installieren. Eine Integration ist dagegen ein Plugin, das Sie bereits für Ihren Onlineshop verwenden.

## Funktioniert etwas nicht? {#something-not-working}

Wenn ein benötigtes Plugin im POS nicht wie erwartet funktioniert, lesen Sie zunächst [Plugin-Konflikte](/1.x/support/troubleshooting/plugin-conflicts). Dort finden Sie bekannte Konflikte und Hinweise dazu, wie Sie neue erkennen.
