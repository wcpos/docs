Filialeinstellungen sind app-weite Konfigurationen, die sich auf die Funktionsweise des POS auswirken. Diese Einstellungen gelten für die gesamte Filiale und nicht für einzelne Bildschirme.

## Filialeinstellungen aufrufen {#accessing-store-settings}

Öffnen Sie die Filialeinstellungen wie folgt:

- Klicken Sie auf das **Benutzermenü** (oben rechts) und wählen Sie **Einstellungen** aus.
- Verwenden Sie die Tastenkombination `Ctrl + Shift + S`.

Die Einstellungen werden in einem **Seitenbereich** statt in einem Pop-up-Fenster geöffnet. So behalten Sie den Verkauf im Blick, während Sie die Einstellungen anpassen. [Filialstatus](/support/store-health) wird auf dieselbe Weise geöffnet.

## Registerkarten der Einstellungen {#settings-tabs}

Der Bereich mit den Filialeinstellungen enthält folgende Registerkarten:

| Registerkarte | Beschreibung |
|-----|-------------|
| [Allgemein](./general.mdx) | Filialinformationen, Sprache, Währung, Standardkunde |
| [Steuern](./tax.mdx) | Optionen für Steuerberechnung und -anzeige |
| [Strichcode](./barcode.mdx) | Konfiguration des Strichcode-Scanners |
| [Tastaturkürzel](./hotkeys.mdx) | Verfügbare Tastaturkürzel |
| [Design](./theme.mdx) | Darstellung und Farbschema |
| [Drucker](/hardware/printers) | Verbindung und Konfiguration des Belegdruckers |
