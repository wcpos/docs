WCPOS bietet drei Arten von Einstellungen, gegliedert danach, wo sie konfiguriert werden.

## Wo Sie die Einstellungen finden {#where-to-find-settings}

### 1. WordPress-Admin-Einstellungen {#1-wordpress-admin-settings}

Backend-Einstellungen, die Sie in Ihrem WordPress-Dashboard konfigurieren:

**Ort:** `WP Admin > POS > Einstellungen`

Diese steuern:
- Standardkunden im Warenkorb für alle Kassierer
- Konfiguration des Produktbarcode-Feldes
- Einstellungen für Bestell-E-Mails
- Berechtigungen der Benutzerrollen (wer auf den POS zugreifen kann)
- Verfügbarkeit von Zahlungsgateways

Weitere Informationen finden Sie unter [WordPress-Admin-Einstellungen](/1.x/settings/wp-admin).

### 2. POS-Filialeinstellungen {#2-pos-store-settings}

App-weite Einstellungen, die Sie innerhalb der POS-Anwendung konfigurieren:

**Ort:** Benutzermenü (oben rechts) → Einstellungen oder `Ctrl + Shift + S`

Diese steuern:
- Optionen zur Steuerberechnung
- Konfiguration des Barcode-Scanners
- Tastenkombinationen
- Design/Erscheinungsbild

Weitere Informationen finden Sie unter [Filialeinstellungen](/1.x/settings/store).

### 3. Anzeigeeinstellungen (pro Bildschirm) {#3-display-settings-per-screen}

Jeder Bildschirm im POS verfügt über eigene Anzeigeeinstellungen zur Anpassung der Datentabelle:

**Ort:** Klicken Sie auf das Schieberegler-Symbol (<Icon name="sliders" />) auf einem beliebigen Bildschirm

Diese steuern:
- Welche Spalten sichtbar sind
- Optionen zur Spaltenanzeige
- Bildschirmspezifische Funktionen

Die Anzeigeeinstellungen werden in der Dokumentation des jeweiligen Bildschirms beschrieben:
- [POS-Produktpanel](/1.x/pos/product-panel#display-settings)
- [Warenkorb-Panel](/1.x/pos/cart#display-settings)
- [Produktbildschirm](/1.x/products#display-settings)
- [Bestellbildschirm](/1.x/orders#display-settings)
- [Kundenbildschirm](/1.x/customers#display-settings)
- [Berichtsbildschirm](/1.x/reports#display-settings)
