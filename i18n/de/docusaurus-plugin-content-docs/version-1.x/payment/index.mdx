WCPOS unterstützt mehrere Zahlungsmethoden, um unterschiedlichen geschäftlichen Anforderungen gerecht zu werden. Der Checkout verwendet ein iframe/eine WebView, um die WooCommerce-Seite zur Bezahlung der Bestellung zu laden. Das bedeutet, dass jedes Zahlungsgateway, das mit WooCommerce funktioniert, auch im POS funktionieren kann.

## Standard-Zahlungsmethoden {#default-payment-methods}

Die kostenlose Version enthält zwei integrierte Zahlungsgateways:

### Bargeld {#cash}

- Gezahlten Betrag eingeben
- Automatische Wechselgeldberechnung
- Keine zusätzliche Konfiguration erforderlich

### Karte {#card}

- Zur Verwendung mit externen Kartenterminals
- Die Zahlung nach der Verarbeitung auf Ihrem Terminal einfach als abgeschlossen markieren
- Keine direkte Integration erforderlich

## Zusätzliche Zahlungsgateways (Pro) {#additional-payment-gateways-pro}

:::info Pro-Funktion
Zusätzliche Zahlungsgateways erfordern [WCPOS Pro](/1.x/getting-started/pro-license).
:::

Mit Pro können Sie zusätzliche WooCommerce-Zahlungsgateways im POS-Checkout aktivieren:

- **Stripe Terminal** - Direkte Integration mit Stripe-Kartenlesegeräten
- **SumUp Terminal** - Integration mit SumUp-Kartenlesegeräten
- **Beliebiges WooCommerce-Zahlungsgateway** - Jedes in Ihrem Shop installierte Zahlungsgateway aktivieren

## Zahlungsgateways aktivieren und deaktivieren {#enabling-and-disabling-gateways}

Zahlungsgateways werden im WordPress-Adminbereich verwaltet:

1. Gehen Sie zu `WP Admin > POS > Einstellungen > Kasse`
2. Sie sehen eine Liste aller installierten WooCommerce-Zahlungsgateways
3. Aktivieren oder deaktivieren Sie jedes Zahlungsgateway für den POS unabhängig von Ihrem Online-Shop
4. Ändern Sie die Reihenfolge durch Ziehen — das erste aktivierte Zahlungsgateway wird beim Checkout zum Standard

Ein Zahlungsgateway kann also auf Ihrer Website aktiv, im POS aber deaktiviert sein oder umgekehrt. Ausführliche Informationen finden Sie unter [Checkout-Einstellungen](/1.x/settings/wp-admin/checkout).

## Zahlungen testen {#testing-payments}

Bevor Sie ein neues Zahlungsgateway im Live-Betrieb verwenden:

1. **Bargeld-Gateway** — immer verfügbar, um den Checkout-Ablauf ohne echte Transaktionen zu testen.
2. **Stripe Terminal** — Stripe stellt für den Testmodus einen [simulierten Reader](https://docs.stripe.com/terminal/testing) bereit. Aktivieren Sie zuerst den Testmodus in Ihrem Stripe-Dashboard.
3. **Drittanbieter-Gateways** — prüfen Sie die Dokumentation des jeweiligen Zahlungsgateways auf Anweisungen zum Sandbox-/Testmodus. Bei den meisten WooCommerce-Zahlungsgateways lässt sich ein Testmodus einschalten.

:::tip
Wenn ein neu aktiviertes Zahlungsgateway beim Checkout nicht angezeigt wird, laden Sie den POS neu. Änderungen an Zahlungsgateways in WP Admin werden beim nächsten Laden der Seite wirksam.
:::

## Häufige Probleme {#common-issues}

### Zahlungsgateway erscheint nicht beim Checkout {#gateway-not-appearing-at-checkout}

- Prüfen Sie, ob das Zahlungsgateway unter `WP Admin > POS > Einstellungen > Kasse` für den POS aktiviert ist.
- Prüfen Sie, ob das Zahlungsgateway auch unter `WP Admin > WooCommerce > Einstellungen > Zahlungen` aktiviert ist — ein Zahlungsgateway muss in WooCommerce aktiv sein, bevor es im POS angezeigt werden kann.
- Laden Sie den POS nach Ihren Änderungen neu.

### Zahlungsgateway wird falsch angezeigt {#gateway-displays-incorrectly}

Das Checkout-iframe lädt die Theme-Stile Ihrer Website, was gelegentlich zu Konflikten führen kann. Verwenden Sie die Schaltfläche **Checkout-Einstellungen** im Checkout-Dialog, um Stile oder Skripte gezielt zu deaktivieren. Weitere Informationen finden Sie unter [Checkout-Fehlerbehebung](/1.x/pos/checkout#checkout-settings-troubleshooting).

### Zahlungsverarbeitung schlägt fehl {#payment-processing-fails}

- Prüfen Sie die Fehlerprotokolle Ihrer Website (`WP Admin > POS > Support > Protokolle`) auf Fehler des Zahlungsgateways.
- Stellen Sie sicher, dass Ihr SSL-Zertifikat gültig ist — die meisten Zahlungsgateways erfordern HTTPS.
- Wenn Sie eine Staging- oder lokale Umgebung verwenden, prüfen Sie, ob das Zahlungsgateway einen Test-/Sandbox-Modus unterstützt.
