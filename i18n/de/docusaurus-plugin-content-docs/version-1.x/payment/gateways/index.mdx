# Zahlungsgateways {#payment-gateways}

WCPOS unterstützt mehrere benutzerdefinierte Zahlungsgateways, die die Funktionalität Ihres Point-of-Sale-Systems erweitern. Diese Gateways wurden speziell für POS-Umgebungen entwickelt und ermöglichen eine nahtlose Integration verschiedener Zahlungsmethoden und Dienste.

## Verfügbare benutzerdefinierte Zahlungsgateways {#available-custom-gateways}

### Zahlungsgateways für Hardware-Terminals {#hardware-terminal-gateways}

- **[Stripe Terminal](./stripe-terminal.mdx)** - Zahlungen mit Stripe Terminal-Kartenlesegeräten akzeptieren
- **[SumUp Terminal](./sumup-terminal.mdx)** - Zahlungen über SumUp-Kartenlesegeräte abwickeln
- **[Square Terminal](./square-terminal.mdx)** - Vor-Ort-Zahlungen auf Square Terminal-Geräten annehmen
- **[PayPal Reader (Zettle)](./paypal-reader.mdx)** - Vor-Ort-Kartenzahlungen an einem PayPal Reader (Zettle)-Terminal annehmen
- **[Mollie Terminal](./mollie-terminal.mdx)** - Vor-Ort-Zahlungen auf Mollie Terminal-Geräten annehmen
- **[Mercado Pago Terminal](./mercadopago-terminal.mdx)** - Vor-Ort-Zahlungen an Mercado Pago Point Smart-Terminals annehmen (neu in 0.1.0)
- **[Windcave Terminal](./windcave-terminal.mdx)** - Vor-Ort-Kartenzahlungen an Windcave-Terminals annehmen (neu in 0.1.0)
- **[PayArc Terminal](./payarc-terminal.mdx)** - Vor-Ort-Zahlungen an PayArc PAX-Terminals annehmen

### Mobile Zahlungsgateways {#mobile-payment-gateways}

- **[Vipps MobilePay](./vipps-mobilepay.mdx)** - Zahlungen per QR-Code oder Push-Benachrichtigung annehmen

### Digitale Zahlungsgateways {#digital-payment-gateways}

- **[E-Mail-Rechnung](./email-invoice.mdx)** - Rechnungen per E-Mail an Kunden senden, damit sie bezahlen können
- **[Web-Checkout](./web-checkout.mdx)** - Kunden zur Online-Zahlung weiterleiten

## Eigenes Zahlungsgateway erstellen {#creating-your-own-gateway}

Wenn ein individuelles Zahlungsgateway für bestimmte Anforderungen benötigt wird, kann unsere **[Gateway-Vorlage](/reference/gateway-template)** verwendet werden, um ein eigenes WCPOS-Zahlungsgateway zu erstellen.

## Installationsübersicht {#installation-overview}

Alle individuellen Gateways folgen einem ähnlichen Installationsprozess:

1. **Herunterladen** der neuesten Version aus dem jeweiligen GitHub-Repository
2. **Installieren** des Plugins über `WP Admin > Plugins > Neu hinzufügen > Plugin hochladen`
3. **Konfigurieren** der Gateway-Einstellungen unter `WP Admin > WooCommerce > Einstellungen > Zahlungen`
4. **Aktivieren** Sie das Gateway unter `WP Admin > POS > Einstellungen > Kasse`
