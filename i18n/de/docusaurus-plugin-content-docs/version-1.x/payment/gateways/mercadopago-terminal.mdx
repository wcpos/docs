# Mercado Pago Terminal-Zahlungsgateway {#mercado-pago-terminal-gateway}

Mit dem Zahlungsgateway Mercado Pago Terminal können Sie Vor-Ort-Zahlungen an Mercado Pago Point Smart-Terminals über WCPOS entgegennehmen. Die Zahlung wird in WooCommerce gestartet und am Terminal abgeschlossen. Die Bestätigung von Mercado Pago wird in den Auftrag übernommen.

:::info Neu in 0.1.0
Mercado Pago Terminal für WooCommerce ist eine neue Erweiterung; 0.1.0 ist die erste Version. Betrachten Sie sie als Beta: Beginnen Sie im **Test**-Modus mit dem virtuellen Sandbox-Terminal von Mercado Pago und führen Sie eine Testzahlung durch, bevor Sie echte Zahlungen entgegennehmen.
:::

## Funktionsweise {#how-it-works}

Das Zahlungsgateway verwendet die cloudbasierte **Orders API for Point** von Mercado Pago. Beim Start einer Zahlung wird ein Mercado-Pago-Auftrag über den Gesamtbetrag des WooCommerce-Auftrags erstellt und an das ausgewählte Terminal gesendet. Der Mercado-Pago-Auftrag läuft nach **5 Minuten** ab.

Die Zahlungsseite fragt Mercado Pago alle **2 Sekunden** ab. Auch der Webhook und eine **Hintergrundprüfung nach 5 Minuten** können einen bezahlten Auftrag abschließen, selbst wenn der Browser geschlossen wurde. Der Webhook ist optional, wird aber empfohlen. Ohne **Webhook secret** werden Benachrichtigungen weiterhin verarbeitet, jedoch nicht auf ihre Signatur geprüft.

Das Terminal muss sich im **PDV-Modus (integriert)** befinden. Terminals werden im **STANDALONE**-Modus ausgeliefert. Wechseln Sie daher in den Einstellungen des Zahlungsgateways zu PDV und starten Sie das Terminal neu, bevor Sie Zahlungen entgegennehmen.

## Einrichtung {#setup}

<Steps>
  <StepCard number="1" title="Mercado Pago Terminal für WooCommerce installieren">

Laden Sie das **Plugin-ZIP-Asset** (nicht das ZIP-Archiv mit dem GitHub-Quellcode) von der [GitHub-Release-Seite](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases) herunter. Laden Sie es über `Plugins > Neu hinzufügen > Plugin hochladen` hoch und aktivieren Sie es. WooCommerce muss installiert und aktiv sein.

  </StepCard>
  <StepCard number="2" title="Mercado-Pago-Zugangsdaten hinzufügen">

1. Gehen Sie zu `WP Admin > WooCommerce > Einstellungen > Zahlungen` und öffnen Sie **Mercado Pago Terminal**.
2. Wählen Sie **Modus**: `Test` verwendet das virtuelle Sandbox-Terminal, `Live` die echten Terminals.
3. Fügen Sie das **Access token** (`APP_USR-…`) Ihrer Anwendung unter Mercado Pago → **Your integrations** → **Credentials** ein.

:::warning Token im Live-Modus prüfen
Ein `TEST-`-Token im Live-Modus sendet Zahlungen an die Sandbox. Die Einstellungsseite warnt vor dieser Kombination. Fügen Sie vor der Annahme echter Zahlungen Ihr Produktions-Token ein.
:::

  </StepCard>
  <StepCard number="3" title="Webhook registrieren">

1. Gehen Sie in Mercado Pago zu **Your integrations** → Ihrer Anwendung → **Webhooks**.
2. Fügen Sie die URL des Webhooks hinzu, die auf der Einstellungsseite des Zahlungsgateways angezeigt wird.
3. Wählen Sie das Ereignis **Order (Mercado Pago)** aus und speichern Sie.
4. Kopieren Sie die **secret signature** in WooCommerce in das Feld **Webhook secret**.

Der Webhook ist optional. Zahlungen werden auch ohne ihn durch regelmäßige Abfragen abgeschlossen. Wenn Sie das Geheimnis konfigurieren, kann das Plugin Webhook-Signaturen überprüfen.

  </StepCard>
  <StepCard number="4" title="Terminals einrichten">

1. Speichern Sie die Einstellungen und laden Sie die Einstellungsseite neu. Das Dropdown **Default terminal** und die Tabelle **Terminals** listen die Terminals Ihres Kontos auf.
2. Wenn für ein Terminal der Modus **STANDALONE** angezeigt wird, klicken Sie auf **Switch to PDV** und **starten Sie das Terminal neu**.
3. Wählen Sie ein **Default terminal** aus.
4. *(Optional)* Beschränken Sie **Enabled terminals** auf die Geräte, die Kassierer auswählen können. Lassen Sie das Feld leer, um alle Terminals zuzulassen. Das gespeicherte Standardterminal bleibt auch dann verfügbar, wenn es hier nicht ausgewählt ist.
5. *(Optional)* Aktivieren Sie **Lock terminal selection**, um immer das Standardterminal zu verwenden und zu verhindern, dass Kassierer es ändern. Dafür muss ein Standardterminal festgelegt sein.
6. Speichern Sie Ihre Einstellungen.

  </StepCard>
  <StepCard number="5" title="In WCPOS aktivieren" isLast>

1. Gehen Sie zu `WP Admin > POS > Einstellungen > Kasse`.
2. Suchen Sie das Zahlungsgateway **Mercado Pago Terminal** und aktivieren Sie es für das POS.
3. Speichern Sie Ihre Einstellungen.

:::note
Das Kontrollkästchen **Aktivieren/Deaktivieren** in den WooCommerce-Einstellungen steuert nur den Checkout des *Onlineshops*. WCPOS verwendet dieses Zahlungsgateway nach der Konfiguration unabhängig davon, ob das Kästchen aktiviert ist.
:::

  </StepCard>
</Steps>

## Einstellungen im Überblick {#settings}

| Einstellung | Funktion |
|---|---|
| **Aktivieren/Deaktivieren** | Aktiviert das Zahlungsgateway für den Checkout des Onlineshops. Die Aktivierung für das POS wird unter `POS > Einstellungen > Kasse` gesteuert. |
| **Titel** | Bezeichnung beim Checkout; Standardwert ist `Mercado Pago Terminal`. |
| **Beschreibung** | Beschreibung beim Checkout; Standardwert ist `Pay in person on a Mercado Pago Point terminal.` |
| **Modus** | `Test` (Standard) verwendet das virtuelle Sandbox-Terminal; `Live` verwendet echte Terminals mit Live-Zugangsdaten. |
| **Access token** | Das Token Ihrer Anwendung von Mercado Pago → Your integrations → Credentials. Ein gespeichertes Token wird nicht erneut angezeigt; lassen Sie das Feld leer, um es beizubehalten. |
| **Webhook secret** | Die geheime Signatur aus den Webhook-Einstellungen von Mercado Pago, mit der Benachrichtigungen überprüft werden. |
| **Default terminal** | Das Terminal, das standardmäßig beim Checkout verwendet und live aus Ihrem Konto abgerufen wird. Kann die Liste nicht abgerufen werden, wird ein Textfeld angezeigt. |
| **Enabled terminals** | Beschränkt die Terminals, die Kassierer auswählen können. Leer bedeutet, dass alle Terminals zugelassen sind; das Standardterminal ist immer verfügbar. Wird ausgeblendet, wenn die Liste nicht geladen werden kann. |
| **Lock terminal selection** | Verwendet immer das Standardterminal, sodass Kassierer es nicht ändern können. Ein Standardterminal muss festgelegt sein. |
| **Checkout debug logs** | Zeigt im Zahlungsbereich **Show logs**, **Copy** und **Clear** an. Standardmäßig deaktiviert; aktivieren Sie die Option, wenn Sie Protokolle für den Support erfassen. |
| **Log level** | `Off`, `Errors only` oder `Debug`. In dieser Version ist standardmäßig Debug eingestellt. Anfragen und Antworten werden aufgezeichnet, wobei Geheimnisse entfernt werden. |

Unter den Feldern zeigt die Tabelle **Mercado Pago Terminal diagnostics** die API-Prüfung (einschließlich der Anzahl der Terminals und der Terminals im PDV-Modus), den Zeitpunkt der letzten bestätigten Webhook-Prüfung, die aktive Umgebung, den Status der Zugangsdaten, das Standardterminal, die Webhook-URL und den Link zu den Zahlungsprotokollen an.

## Verwendung {#usage}

### Zahlungen verarbeiten {#processing-payments}

1. **Artikel hinzufügen**: Fügen Sie Produkte im POS zum Warenkorb hinzu.
2. **Zahlungsgateway auswählen**: Wählen Sie **Mercado Pago Terminal** als Zahlungsmethode aus.
3. **Terminal auswählen**: Wählen Sie ein Terminal oder verwenden Sie das Standardterminal, wenn die Auswahl gesperrt ist.
4. **Zahlung starten**: Klicken Sie auf **Start Terminal Payment**, um den Auftragsgesamtbetrag an das Terminal zu senden.
5. **Kundenzahlung**: Folgen Sie den Statusmeldungen — `Sending to terminal…` → `Waiting for terminal…` → `Customer is paying on the terminal…` — während der Kunde die Zahlung am Terminal abschließt.
6. **Automatischer Abschluss**: Sobald Mercado Pago die Zahlung bestätigt, wird der Auftrag abgeschlossen und das POS wechselt zur Belegansicht.

### Zahlungssteuerung {#payment-controls}

- **Start Terminal Payment**: Senden Sie eine neue Zahlungsanforderung an das ausgewählte Terminal.
- **Cancel Terminal Payment**: Brechen Sie die Zahlung nur ab, bevor das Terminal sie übernommen hat. Danach brechen Sie sie am Terminal ab oder warten Sie auf den **Ablauf nach 5 Minuten**.
- **Neuladen der Seite**: Setzt eine bereits laufende Zahlung fort.

### Belege {#receipts}

Das Terminal druckt keinen Beleg. Verwenden Sie nach Abschluss der Zahlung den POS-Beleg.

## Rückerstattungen {#refunds}

Öffnen Sie die Rückerstattungsansicht des WooCommerce-Auftrags und wählen Sie **Refund via Mercado Pago Terminal**, um eine vollständige oder teilweise Rückerstattung zu senden. Mercado Pago ermöglicht Rückerstattungen bis zu **90 Tage** nach der Zahlung.

Einige Karten-Acquirer erlauben Rückerstattungen nur am Terminal. Führen Sie die Rückerstattung in diesem Fall am Terminal durch und erfassen Sie in WooCommerce eine **manuelle Rückerstattung**.

## Protokolle und Support-Paket {#logs-and-support-bundle}

Sie finden die Protokolle unter `WooCommerce > Status > Protokolle` in der Quelle `mercadopago-terminal`. Der Protokollierungsgrad ist in dieser Version standardmäßig **Debug**. Anfragen, Antworten, Webhooks und Änderungen des Zahlungsstatus werden aufgezeichnet; Geheimnisse und Kartennummern werden unkenntlich gemacht.

Klicken Sie auf der Einstellungsseite des Zahlungsgateways auf **Download support bundle**, um eine `.txt`-Datei herunterzuladen und Ihrer Supportanfrage beizufügen. Sie enthält Umgebungsdetails, Einstellungen mit maskierten Zugangsdaten, die Terminalliste und Betriebsmodi, Zahlungsversuche der letzten 10 Aufträge sowie die letzten 500 Protokollzeilen. Die Datei kann nicht zum Durchführen von Zahlungen verwendet werden.

Aktivieren Sie **Checkout debug logs**, um dem Zahlungsbereich **Show logs**, **Copy** und **Clear** hinzuzufügen. Zahlungsaktivitäten werden unabhängig von dieser Einstellung in den WooCommerce-Protokollen erfasst.

## Umfang und Einschränkungen {#scope-and-limitations}

- Am Terminal wird der **volle Auftragsbetrag** abgebucht. Eine Teilzahlung eines Auftrags am Terminal wird nicht unterstützt.
- Trinkgelder werden nicht unterstützt.
- Beträge werden mit **zwei Dezimalstellen** übermittelt. Filialen, die chilenische oder kolumbianische Pesos verwenden, sollten zuerst eine Testzahlung durchführen.
- Der **Blocks-Checkout** des Onlineshops wird nicht unterstützt.
- Das Plugin weist derzeit keine **HPOS-Kompatibilität** aus.

## Fehlerbehebung {#troubleshooting}

### Häufige Probleme {#common-issues}

<Accordion>
  <AccordionItem question="Mercado Pago weist das Access token zurück (HTTP 401)">

  - Das Access token ist ungültig oder veraltet.
  - Kopieren Sie ein neues Token aus **Your integrations** → **Credentials** und speichern Sie es unter **Access token**.

  </AccordionItem>
  <AccordionItem question="Es werden keine Terminals aufgelistet">

  - Wenn keine Point-Terminals mit dem Konto verknüpft sind, melden Sie sich am Terminal mit diesem Mercado-Pago-Konto an, wechseln Sie zu PDV und starten Sie es neu.
  - Wenn **Default terminal** als Textfeld statt als Dropdown angezeigt wird, konnte die Liste nicht abgerufen werden. Prüfen Sie das Token und die Diagnose und laden Sie anschließend die Einstellungsseite neu.

  </AccordionItem>
  <AccordionItem question="Das Terminal befindet sich im STANDALONE-Modus">

  - Integrierte Zahlungen erfordern den **PDV**-Modus.
  - Klicken Sie in der Tabelle **Terminals** auf der Einstellungsseite auf **Switch to PDV** und starten Sie anschließend das Terminal neu.

  </AccordionItem>
  <AccordionItem question="Die Zahlung liegt bereits am Terminal vor">

  - Das Terminal hat die Zahlung übernommen. Sie kann daher nicht mehr über WooCommerce storniert werden.
  - Brechen Sie die Zahlung am Terminal ab oder warten Sie auf den **Ablauf nach 5 Minuten**. Die Zahlungsseite prüft weiterhin den Status.

  </AccordionItem>
  <AccordionItem question="Der Webhook wurde noch nie überprüft">

  - Prüfen Sie die Webhook-URL und das Geheimnis in Mercado Pago, wenn in der Diagnose **Last verified webhook: never** angezeigt wird.
  - Wenn **Webhook secret** fehlt, fügen Sie die **secret signature** von Mercado Pago ein. Zahlungen werden weiterhin durch regelmäßige Abfragen abgeschlossen, aber Benachrichtigungen ohne das Geheimnis werden nicht auf ihre Signatur geprüft.

  </AccordionItem>
  <AccordionItem question="Der Karten-Acquirer hat die Rückerstattung abgelehnt">

  - Einige Karten-Acquirer erlauben Rückerstattungen nur am Terminal; Mercado Pago begrenzt Rückerstattungen außerdem auf **90 Tage**.
  - Führen Sie die Rückerstattung am Terminal durch und erfassen Sie in WooCommerce eine **manuelle Rückerstattung**.

  </AccordionItem>
  <AccordionItem question="Die Zahlung ist am Terminal abgelaufen">

  - Mercado-Pago-Aufträge laufen nach **5 Minuten** ab.
  - Starten Sie die Zahlung erneut.

  </AccordionItem>
</Accordion>
