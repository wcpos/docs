Wenn diese Fehlermeldung angezeigt wird, ist im POS ein schwerwiegender Serverfehler aufgetreten, sodass der Betrieb nicht fortgesetzt werden kann.
Die gute Nachricht: Diese Fehlermeldung wird in den WooCommerce-Protokollen gespeichert, und unser Support-Team kann Ihnen bei der Fehlerbehebung helfen.

## Schritte zur Fehlerfindung {#steps-to-find-the-error}

1. Melden Sie sich in Ihrem WordPress-Adminbereich an.
2. Navigieren Sie zu "WooCommerce" > "Status" > "Protokolle" im WordPress-Seitenmenü.
3. Suchen Sie den Abschnitt "fatal_error"-Protokolle.
4. Klicken Sie auf den Protokolleintrag, der dem Tag entspricht, an dem der Fehler aufgetreten ist (normalerweise das heutige Datum), um die Einzelheiten des Fehlers anzuzeigen.
5. Ermitteln Sie die Ursache des Fehlers, wie sie in diesem Abschnitt protokolliert ist.
6. Kopieren Sie alle relevanten Fehlermeldungen oder machen Sie einen Screenshot und teilen Sie diese mit unserem Support-Team, indem Sie sie im [Discord-Chat](https://wcpos.com/discord) posten oder an support@wcpos.com senden.
