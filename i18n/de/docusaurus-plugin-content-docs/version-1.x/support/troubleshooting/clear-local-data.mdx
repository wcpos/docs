WCPOS speichert eine lokale Kopie Ihrer Produkte, Bestellungen und Kunden, damit der POS schnell arbeiten und auch offline funktionieren kann. Gelegentlich sind diese lokalen Daten nicht mehr mit Ihrem WooCommerce-Shop synchron. Das Zurücksetzen aller lokalen Daten entfernt die lokale Datenbank und löst eine neue Synchronisierung mit Ihrem Server aus.

:::tip Versuchen Sie zuerst einen gezielten Reset (v1.10.0+)
Ab v1.10.0 bietet **Shop-Zustand → Datenbank** die Option **Löschen & neu herunterladen** für jede Sammlung an. Damit wird nur die Sammlung entfernt und erneut abgerufen, die Probleme verursacht (zum Beispiel Produkte), ohne andere Daten anzutasten oder Sie abzumelden. Die Bestätigung zeigt, wie viele Datensätze entfernt werden, und bestätigt, dass Ihre Kopie auf dem Server unberührt bleibt. Beachten Sie: Sammlungen, die bei Bedarf heruntergeladen werden, zeigen direkt nach einem Reset erwartungsgemäß eine niedrige Anzahl und füllen sich bei der Nutzung wieder auf — das ist das vorgesehene Verhalten und kein Zeichen einer stockenden Synchronisierung. Siehe [Shop-Zustand](/1.x/support/store-health#clear-and-redownload).
:::

:::warning
Dies ist die letzte, umfassendste Maßnahme. Das Zurücksetzen lokaler Daten löscht alles, was auf dem Gerät gespeichert ist, und erzwingt eine vollständige erneute Synchronisierung. Je nach Größe Ihres Shops kann dies einige Zeit dauern. Verwenden Sie diese Option nur, wenn andere Möglichkeiten — eine normale [Synchronisierung](/1.x/products/sync) oder **Löschen & neu herunterladen** für eine einzelne Sammlung — das Problem nicht gelöst haben.

Prüfen Sie vor dem Zurücksetzen die Kachel **Änderungen, die auf den Versand warten** unter **Shop-Zustand → Datenbank** — beim Zurücksetzen lokaler Daten gehen alle noch nicht gesendeten Änderungen auf dem Gerät verloren.
:::

## Wann Sie es verwenden sollten {#when-to-use-it}

Sie müssen möglicherweise die lokalen Daten zurücksetzen, wenn:

- **Sync-Probleme** — Produkte, Bestellungen oder Kunden werden nicht ordnungsgemäß aktualisiert
- **Nach einem Plugin-Update** — um die Kompatibilität mit neuen Datenstrukturen sicherzustellen
- **Veraltete Daten** — Preise, Bestände oder andere Informationen erscheinen veraltet

## Was zurückgesetzt wird {#what-gets-cleared}

| Zurückgesetzt | Nicht zurückgesetzt |
|---------|-------------|
| Lokale Produktdatenbank | Serverseitige Daten |
| Lokale Bestelldatenbank | WooCommerce-Einstellungen |
| Lokale Kundendatenbank | |
| Anmeldesitzung | |

Ihre WooCommerce-Shop-Daten sind nicht betroffen — nur die lokale Kopie auf Ihrem Gerät wird entfernt. Eine frische Synchronisierung beginnt automatisch nach dem Zurücksetzen.

:::info Plattformunterschied
- **Desktop-App:** Sie werden abgemeldet und müssen Ihren Shop erneut verbinden.
- **Web-App:** Die Anmeldedaten werden zurückgesetzt, aber da Sie weiterhin in WP Admin angemeldet sind, wird die Sitzung automatisch wiederhergestellt — Sie werden also nicht bemerken, dass Sie abgemeldet wurden.
:::

## So setzen Sie lokale Daten zurück {#how-to-clear-local-data}

### Web {#web}

1. Klicken Sie auf Ihr **Benutzermenü** in der oberen rechten Ecke, um das Menü zu öffnen
2. Klicken Sie auf **Alle lokalen Daten zurücksetzen**
3. Die lokale Datenbank wird gelöscht und eine frische Synchronisierung beginnt automatisch

### Desktop {#desktop}

1. Öffnen Sie das Anwendungsmenü **WCPOS** in der oberen Menüleiste
2. Fahren Sie mit der Maus über **Erweitert**
3. Klicken Sie auf **App-Daten zurücksetzen**
4. Die lokale Datenbank wird gelöscht und eine frische Synchronisierung beginnt automatisch

:::note
Alle Plattformen speichern Daten im selben lokalen Datenbankformat (ab v1.10.0 OPFS-basierte Dateispeicherung). Sie wird auf jeder Plattform vollständig zurückgesetzt, aber das Anmeldeverhalten unterscheidet sich — siehe den obigen Hinweis zum Plattformunterschied.
:::
