**Das Symptom:** Der Checkout in WCPOS dauert mehrere Sekunden und wird mit der Zeit immer langsamer.

Eine häufige Ursache ist die Art, wie WooCommerce Ihre Bestellungen speichert. Auf dieser Seite erfahren Sie, wie Sie dies prüfen und mit dem WooCommerce-eigenen Werkzeug zur schnelleren Option wechseln.

## Warum die veraltete Bestellspeicherung den Checkout verlangsamt {#why-legacy-order-storage-slows-checkout}

Bei der veralteten Speicherung legt WooCommerce Bestellungen zusammen mit Ihren WordPress-Beiträgen ab. Dort gibt es keine schnelle Möglichkeit, eine Bestellung anhand der ID zu finden, die WCPOS ihr zuweist. Deshalb muss WCPOS bei jedem Speichern einer Bestellung die Datensätze Ihrer Filiale einzeln durchsuchen. Je größer Ihre Filiale wird, desto länger dauert diese Suche.

WooCommerce speichert Bestellungen mit **Hochleistungs-Bestellspeicherung (HPOS)** in eigenen Tabellen. Dieselbe Suche dauert dort nahezu augenblicklich.

In einer Filiale, die wir gemessen haben (30,000 Produkte, veraltete Speicherung), dauerte jede Suche etwa 0.46 Sekunden; bei einem Checkout fanden ungefähr zwei solcher Suchen statt. Mit HPOS dauerte dieselbe Suche etwa 1 Millisekunde. Die Werte können in Ihrer Filiale abweichen, doch je größer sie ist, desto mehr können Sie voraussichtlich gewinnen.

## Was WCPOS unterstützt {#what-wcpos-supports}

- **HPOS wird vollständig unterstützt und von uns empfohlen.**
- **Die veraltete Speicherung funktioniert weiterhin.** Es geht nichts kaputt; bei großen Filialen ist lediglich der Checkout langsamer.

## Prüfen, welche Speicherung Ihre Filiale verwendet {#check-which-storage-your-store-uses}

1. Gehen Sie in der WordPress-Administration zu **WooCommerce → Einstellungen → Erweitert → Funktionen**.
2. Suchen Sie nach **Speicherung der Bestelldaten**:
   - **Hochleistungs-Bestellspeicherung (empfohlen)** ist ausgewählt: Sie verwenden bereits HPOS; dies ist also nicht die Ursache. Siehe [Weitere Ursachen für einen langsamen Checkout](#other-causes-of-slow-checkout).
   - **WordPress-Beitragsspeicherung (veraltet)** ist ausgewählt: Ein Wechsel zu HPOS sollte den Checkout beschleunigen. Lesen Sie weiter.

## Zu HPOS wechseln {#switch-to-hpos}

WooCommerce verschiebt Ihre Bestellungen für Sie. Zuerst werden sie in die neuen Tabellen kopiert (die Synchronisierung), danach wechseln Sie. WooCommerce lässt den Wechsel erst zu, wenn der Kopiervorgang abgeschlossen ist.

:::warning Erstellen Sie zuerst eine Sicherungskopie
Erstellen Sie vor dem Start eine vollständige Sicherungskopie Ihrer Website und Datenbank und prüfen Sie, ob Sie sie wiederherstellen können. Wenn Sie eine [Staging-Website](/support/troubleshooting/plugin-conflicts#before-you-start-use-a-staging-site) haben, testen Sie den Wechsel zuerst dort.
:::

1. Gehen Sie zu **WooCommerce → Einstellungen → Erweitert → Funktionen**.
2. Aktivieren Sie **Kompatibilitätsmodus aktivieren** und klicken Sie auf **Änderungen speichern**. WooCommerce beginnt im Hintergrund, Ihre Bestellungen zu kopieren. Bei einer großen Filiale kann das eine Weile dauern; der Fortschritt wird unter dem Kontrollkästchen angezeigt. Wenn dort steht, dass Bestellungen nicht synchron sind, aber nichts passiert, klicken Sie auf **Bestellungen jetzt synchronisieren**.
3. Wählen Sie nach Abschluss des Kopiervorgangs **Hochleistungs-Bestellspeicherung (empfohlen)** aus und klicken Sie auf **Änderungen speichern**.
4. Lassen Sie den Kompatibilitätsmodus noch eine Weile aktiviert. Er hält beide Kopien Ihrer Bestellungen synchron, sodass Sie bei Problemen sofort zurückwechseln können. Prüfen Sie in dieser Zeit Ihre anderen Plugins und führen Sie einige Testverkäufe in WCPOS durch.
5. Wenn alles passt, deaktivieren Sie **Kompatibilitätsmodus aktivieren** und klicken Sie auf **Änderungen speichern**.

:::info Wenn die HPOS-Option ausgegraut ist
WooCommerce verhindert den Wechsel, solange ein aktives Plugin als nicht mit HPOS kompatibel markiert ist. Auf der Seite „Funktionen“ weist eine Warnung mit einem Link **Anzeigen und verwalten** auf diese Plugins hin. Aktualisieren Sie sie oder fragen Sie deren Entwickler nach der HPOS-Unterstützung, bevor Sie wechseln.
:::

Ausführliche Informationen finden Sie im Leitfaden von WooCommerce: [High-Performance Order Storage](https://woocommerce.com/document/high-performance-order-storage/#how-to-enable-high-performance-order-storage).

## Weitere Ursachen für einen langsamen Checkout {#other-causes-of-slow-checkout}

Die Bestellspeicherung ist nicht der einzige Faktor, der den Checkout verlangsamt. Wenn Sie bereits HPOS verwenden oder der Checkout nach dem Wechsel weiterhin langsam ist, prüfen Sie Folgendes:

- **Ihr Hosting.** Ein ausgelasteter oder zu schwach dimensionierter Server verlangsamt jeden Schritt. Siehe [Serverleistung](/support/performance/server).
- **Andere Plugins, die beim Speichern einer Bestellung ausgeführt werden**, etwa Plugins für Buchhaltung, E-Mail-Marketing oder Lagerverwaltung. Siehe [Plugin-Konflikte](/support/troubleshooting/plugin-conflicts) und [Checkout-Leistung](/support/performance/checkout#2-plugin-interference-during-order-creation).
