Die **WooCommerce REST API** ähnelt einer Reihe standardisierter „Kanäle“, über die Shopbetreiber ihren WooCommerce-Shop mit anderen Anwendungen und Diensten verbinden können.

Hier eine einfache Erklärung der Funktionsweise:

1. Sie dient als Brücke zwischen Ihrem WooCommerce-Shop und externen Anwendungen und ermöglicht deren Kommunikation und Datenaustausch.

2. Die API sendet Anfragen an bestimmte **Endpunkte** – stellen Sie sich diese als „Kanäle“ für verschiedene Arten von Shopdaten vor. Es gibt beispielsweise Endpunkte für Produkte, Bestellungen und Kunden.

3. Externe Anwendungen können diese Endpunkte verwenden, um:

- Informationen abzurufen (z. B. eine Produktliste)
- Neue Daten hinzuzufügen (z. B. eine neue Bestellung zu erstellen)
- Vorhandene Informationen zu aktualisieren (z. B. den Preis eines Produkts zu ändern)
- Daten zu löschen (z. B. ein veraltetes Produkt zu entfernen)

Statt sich auf PHP-Hooks und -Filter zu stützen (wie es viele herkömmliche WordPress-Plugins tun), sendet und empfängt sie Daten in einem strukturierten, vorhersehbaren Format namens **JSON**.

## Warum funktionieren manche Plugins nicht im POS? {#why-dont-some-plugins-work-in-the-pos}

WCPOS lädt Produkt-, Bestell- und Kundendaten über die REST API aus Ihrem WooCommerce-Shop herunter.
Anschließend speichert es eine lokale Kopie dieser Daten, damit der Betrieb auch bei einer unzuverlässigen Internetverbindung fortgesetzt werden kann.
Dadurch ist der POS bei hohem Andrang an der Kasse schneller und zuverlässiger.

Das bedeutet jedoch, dass unser POS Änderungen, die dynamisch und in Echtzeit auf Ihrer Website erfolgen, nicht „sieht“. Zum Beispiel:

    <td>
      Wenn ein anderes Plugin in Ihrem Shop zusätzliche Produktdaten hinzufügt, erhält der POS diese Daten nicht
      automatisch. Der POS erhält nur die Daten, die
      über die REST API bereitgestellt werden.
    </td>
  </tr>
</table>
