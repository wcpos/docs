Wenn Sie das Aussehen Ihres Belegs ändern möchten, stehen Ihnen drei Möglichkeiten zur Verfügung. Wählen Sie die einfachste, die Ihren Anforderungen entspricht — die meisten Filialen benötigen nur die erste.

## Drei Möglichkeiten zur Anpassung {#three-ways-to-customise}

<FeatureGrid>
  <FeatureCard icon="grid" title="1. Eine andere Vorlage wählen">
    Verwenden Sie eine der fertigen Vorlagen aus der Galerie. **Kein Code erforderlich.** Ideal für: ein anderes Layout, Preise ausblenden, eine A4-Rechnung, einen Küchenbon.
  </FeatureCard>
  <FeatureCard icon="sparkles" title="2. KI um Anpassung bitten">
    Fügen Sie die Vorlage in ChatGPT oder Claude ein und beschreiben Sie, was Sie möchten. **Keine Programmierkenntnisse erforderlich** — die Beschreibung erfolgt in einfacher Sprache. Ideal für: kleine Anpassungen wie Formulierungen, Farben oder das Verschieben von Elementen.
  </FeatureCard>
  <FeatureCard icon="code" title="3. Manuell bearbeiten">
    Der integrierte Editor ermöglicht die direkte Bearbeitung der Vorlage. Ideal für: präzise Kontrolle oder wenn Sie bereits HTML-Kenntnisse haben.
  </FeatureCard>
</FeatureGrid>

Alle drei beginnen am selben Ort: **WP Admin → POS → Vorlagen**. Die Seite besteht aus zwei Bereichen — **Ihre Vorlagen** oben (die derzeit verwendeten) und die **Vorlagengalerie** darunter (die Starter-Bibliothek).

## Option 1 — Eine andere Vorlage wählen {#option-1--pick-a-different-template}

Dies ist der einfachste Weg und deckt die meisten Anforderungen ab.

<Steps>
  <StepCard number="1" title="Vorlagengalerie öffnen">

Gehen Sie in WP Admin zu **POS → Vorlagen**. Scrollen Sie an *Ihre Vorlagen* vorbei zum Abschnitt **Vorlagengalerie** — das ist die Starter-Bibliothek.

  </StepCard>
  <StepCard number="2" title="Durchsuchen und Vorschau anzeigen">

Nach **Kategorie** (Beleg, Rechnung, Geschenkbeleg, Küchenbon, Angebot / Bestellung), **Format** (HTML für den Browserdruck, Thermal für Thermodrucker) oder **Richtung** (Links nach rechts oder rechts nach links) filtern. Klicken Sie auf das Miniaturbild einer Karte — oder auf den Link **Vorschau** in der Fußzeile —, um eine Live-Vorschau mit echten Daten Ihrer Filiale zu öffnen.

  </StepCard>
  <StepCard number="3" title="Verwenden" isLast>

Klicken Sie auf der Karte auf **Vorlage verwenden**. WCPOS erstellt eine bearbeitbare Kopie und fügt sie oben auf der Seite zu **Ihre Vorlagen** hinzu. Aktivieren Sie den Schalter **Aktiv** in der Zeile, um sie für Belege zu verwenden; ziehen Sie den Griff der Zeile, um die Reihenfolge zu ändern. Mehrere Vorlagen können gleichzeitig aktiv sein — die Kasse wählt sie beim Verkauf aus.

  </StepCard>
</Steps>

:::tip Vorlage verwenden ersetzt nie etwas
Ein Klick auf **Vorlage verwenden** erstellt immer eine neue Kopie. Die ursprüngliche Galerievorlage bleibt unverändert, sodass Sie jederzeit zurückkehren und einen anderen Ausgangspunkt wählen können. Wenn mehrere Belegvorlagen aktiv sind, zeigt der Belegbildschirm ein Dropdown-Menü, mit dem die Kasse spontan zwischen ihnen wechseln kann.
:::

### Die mitgelieferten Vorlagen {#the-bundled-templates}

| Vorlage | Format | Verwendungszweck |
|---|---|---|
| **Standardbeleg** | HTML | Standard — Logo, Artikel, Summen, Zahlung. Geeignet für die meisten Filialen |
| **Standardbeleg (RTL)** | HTML | Wie Standard, gespiegelt für Arabisch / Hebräisch / Persisch / Urdu |
| **Minimal / Modern** | HTML | Gleiche Informationen wie Standard, kompakter in der Höhe |
| **Detaillierter Beleg** | HTML | Vollständige Steuerrechnung — SKU-Spalte, Einzelpreis, Steueraufschlüsselung nach Satz, Adressen |
| **Geschenkbeleg** | HTML | Nur Artikel — Preise ausgeblendet. Enthält Geschenknachricht und Rückgabebedingungen |
| **Rechnung** | HTML | Ganzseitige A4/Letter-Rechnung. Enthält einen "So bezahlen Sie"-Bereich für unbezahlte Bestellungen |
| **Lieferschein** | HTML | Lagerbegleitdokument — Artikel + Mengen, Lieferadresse, keine Preise |
| **Angebot / Kostenvoranschlag** | HTML | Vorverkaufsdokument mit Preisen und Bedingungen — kein Zahlungsbereich |
| **Schmaler Beleg** | HTML | Monospace-Beleg für schmales Papier oder HTML-fähige Thermodrucker |
| **Einfacher Thermobeleg (58 mm)** | Thermal | Übersichtliches 58-mm-Thermolayout |
| **Einfacher Thermobeleg (80 mm)** | Thermal | Übersichtliches 80-mm-Thermolayout — am häufigsten verwendet |
| **Einfacher Thermobeleg 80 mm (RTL)** | Thermal | RTL-Variante für 80 mm. Erfordert einen Drucker mit arabischer Codepage |
| **Detaillierter Thermobeleg (58 mm / 80 mm)** | Thermal | Enthält Steueraufschlüsselung, Adressen, Erstattungen, Zahlungen, Bedingungen und Barcode |
| **Küchenbon** | Thermal | Nur Artikel, große Schrift, keine Preise — für Zubereitungsstationen |

Die meisten mitgelieferten Vorlagen **passen sich automatisch an die Steuereinstellungen Ihrer Filiale an** — Filialen mit Preisen inklusive Steuer sehen Bruttopreise und eine Zeile "Steuer enthalten"; Filialen mit Preisen exklusive Steuer sehen Nettopreise mit separat ausgewiesener Steuer. Die **Detailliert**-Familie zeigt unabhängig von der Einstellung immer eine vollständige Steueraufschlüsselung.

### WP-Overnight-Rechnungs- und Lieferscheinvorlagen {#wp-overnight-invoice-and-packing-slip-templates}

Wenn Ihre Website auch [PDF Invoices & Packing Slips for WooCommerce](https://wordpress.org/plugins/woocommerce-pdf-invoices-packing-slips/) von WP Overnight verwendet, fügt WCPOS automatisch zwei zusätzliche Vorlagen zu **Ihre Vorlagen** hinzu:

| Vorlage | Format | Verwendungszweck |
|---|---|---|
| **Rechnung (WP Overnight)** | Serverseitig gerendertes HTML | Verwendet das in WP Overnight konfigurierte Rechnungsdokument für die POS-Bestellung |
| **Lieferschein (WP Overnight)** | Serverseitig gerendertes HTML | Verwendet das in WP Overnight konfigurierte Lieferscheindokument für die POS-Bestellung |

Diese Vorlagen kopieren nicht die integrierten Rechnungs- oder Lieferscheinlayouts von WCPOS. Sie lassen WP Overnight das Dokument für die POS-Bestellung rendern. So bleiben Ihre vorhandenen Rechnungsnummern, Ihr Branding, rechtliche und steuerliche Felder sowie Ihre Vorlagenanpassungen in WP Overnight bei Online- und Vor-Ort-Bestellungen einheitlich.

Sie erscheinen nur, solange das Plugin von WP Overnight aktiv ist. Die Ausgabe wird als HTML im WCPOS-Druckbildschirm geöffnet, nicht als separater PDF-Download. Da das Dokument auf dem Server gerendert wird, benötigt der POS zum Drucken dieser Vorlagen eine Verbindung zu Ihrer Website; verwenden Sie für den Offline-Druck die mitgelieferten HTML- oder Thermovorlagen.

## Zuweisungen pro Filiale {#per-store-assignments}

Wenn Sie mehr als eine [Filiale](/1.x/stores) (Pro) haben, kann jede Filiale eine **eigene Vorlagenauswahl und Reihenfolge** verwenden, unabhängig von den Vorgaben für die gesamte Website. Das Café um die Ecke kann einen kleinen Thermobeleg mit anderem Logo und anderer Adresse verwenden, das Lager einen Lieferschein und das Hauptgeschäft den Standardbeleg — alles aus derselben Vorlagengalerie.

Gehen Sie zur Einrichtung zu **WP Admin → POS → Filialen** und öffnen Sie die gewünschte Filiale. Die Seite **Filiale bearbeiten** enthält den Abschnitt **Belegvorlagen** mit dem Schalter *„Filialspezifische Belegvorlagen“*:

- **Schalter aus** *(Standard)* — die Filiale übernimmt die für die gesamte Website geltende Vorlagenliste von der Hauptseite **POS → Vorlagen**.
- **Schalter ein** — die Filiale erhält eine eigene Vorlagenauswahl und Reihenfolge, unabhängig von den Vorgaben für die gesamte Website. Das Ändern der Reihenfolge per Ziehgriff funktioniert genauso.

Auf derselben Seite Filiale bearbeiten befindet sich auch der **Briefkopf** jeder Filiale (Logo, Adresse, Kontaktdaten und der Block *Belegnachrichten* — Grußformel, Rückgabebedingungen, Fußzeile). Die mitgelieferten Vorlagen lesen diese filialspezifischen Felder aus, sodass eine einzige Vorlage „Standardbeleg“ an verschiedenen Standorten unterschiedliches Branding verwenden kann.

Wenn sich ein Kassierer in einer Filiale anmeldet, erscheinen im Beleg-Dropdown nur die aktiven Vorlagen dieser Filiale.

:::tip Für die gesamte Website oder pro Filiale
Die Seite **Vorlagen** in WP Admin legt die Vorgaben für die gesamte Website fest. Die filialspezifischen Einstellungen ermöglichen es, mit einer einzigen Vorlage (z. B. einem Standardbeleg) an verschiedenen Standorten unterschiedliches Branding zu verwenden oder einem Standort ein anderes Layout zuzuweisen. Wenn alle Filialen dieselben Vorlagen verwenden sollen, lassen Sie die Zuweisungen pro Filiale einfach leer; dann gelten die Vorgaben für die gesamte Website.
:::

## Option 2 — KI um Anpassungen bitten {#option-2--ask-ai-to-tweak-it}

Wenn eine Vorlage aus der Galerie fast, aber noch nicht ganz passt, kann ein KI-Assistent sie in wenigen Minuten für Sie anpassen — HTML-Kenntnisse sind dafür nicht erforderlich.

<Steps>
  <StepCard number="1" title="Vorlage kopieren">

Öffnen Sie die gewünschte Ausgangsvorlage unter **WP Admin → POS → Vorlagen**, klicken Sie in den Editor und markieren Sie den gesamten Text auf der linken Seite (Ctrl/Cmd + A). Kopieren Sie ihn.

  </StepCard>
  <StepCard number="2" title="In ChatGPT oder Claude einfügen">

[ChatGPT](https://chat.openai.com) oder [Claude](https://claude.ai) öffnen. Die Vorlage einfügen und in einfachen Worten beschreiben, was geändert werden soll:

  </StepCard>
  <StepCard number="3" title="Gewünschte Änderungen beschreiben">

Beschreiben Sie der KI genau, was Sie möchten. Diese Beispiele funktionieren gut:

- *„Den Filialnamen größer und zentriert darstellen.“*
- *„Am Ende eine Dankesnachricht in Kursivschrift hinzufügen.“*
- *„Den Kundennamen ausblenden. Stattdessen die Telefonnummer unter der Bestellnummer hinzufügen.“*
- *„Den Barcode durch einen QR-Code ersetzen, der auf meine Rückgabeseite verlinkt.“*
- *„Unter dem Filialnamen den Slogan ‚Familienunternehmen seit 1987‘ hinzufügen.“*

Die KI gibt Ihnen eine angepasste Vorlage zurück.

  </StepCard>
  <StepCard number="4" title="Wieder einfügen" isLast>

Kopieren Sie die Antwort der KI. Wechseln Sie zurück zum WCPOS-Vorlageneditor, markieren Sie alles (Ctrl/Cmd + A), fügen Sie die neue Version ein und klicken Sie auf **Aktualisieren**. Die Vorschau rechts wird aktualisiert, sodass Sie das Ergebnis sehen können. Wenn es nicht richtig aussieht, bitten Sie die KI um eine Korrektur und beschreiben Sie, was nicht stimmt.

  </StepCard>
</Steps>

:::tip Bewährte Vorgehensweise
Jeder Klick auf **Vorlage verwenden** in der Galerie erstellt eine neue bearbeitbare Kopie, sodass das Original erhalten bleibt. Beim Experimentieren können Sie dieselbe Galerievorlage mehrfach verwenden — benennen Sie Ihre Kopien um *(Beleg v1, Beleg v2)* und wechseln Sie zwischen ihnen, bis Sie sich entschieden haben.
:::

:::info Was ist mit Variablen?
Ausdrücke wie `{{store.name}}` und `{{order.number}}` sind **Platzhalter** für Ihre tatsächlichen Daten. Die KI versteht sie — Sie müssen das nicht. Alle verfügbaren Platzhalter finden Sie in der [Belegdaten-Referenz](/1.x/receipts/receipt-data).
:::

## Option 3 — Manuell bearbeiten {#option-3--edit-it-by-hand}

Wenn Sie etwas HTML beherrschen (oder mit einem Entwickler zusammenarbeiten), können Sie die Vorlage direkt im integrierten Editor bearbeiten. Er bietet eine Live-Vorschau, Syntaxhervorhebung, eine durchsuchbare Feldauswahl, Rückgängig/Wiederherstellen und Suchen-und-Ersetzen.

Wählen Sie Ihre Engine:

- **[HTML-Vorlagen](/1.x/receipts/html-templates)** — `{{variable}}`-Platzhalter im Mustache-Stil. Werden clientseitig gerendert und funktionieren offline. **Für die meisten Filialen empfohlen.**
- **[Thermovorlagen](/1.x/receipts/thermal-templates)** — XML für ESC/POS-Thermodrucker. Dieselbe Vorlage erzeugt sowohl die Bildschirmvorschau als auch die Druckerausgabe.
- **[Belegdaten-Referenz](/1.x/receipts/receipt-data)** — Alle verfügbaren Platzhalter, nach Abschnitt gruppiert.

:::note Alte PHP-Vorlagen
Wenn Sie den Beleg bisher mit einer PHP-Datei in Ihrem Theme überschrieben haben (`yourtheme/woocommerce-pos/receipt.php`), funktioniert das weiterhin. Diese Option heißt in der Galerie jetzt **Alte PHP-Vorlage** und steht neben den neuen logiklosen und Thermo-Engines. Auch die Integration von WP Overnight verwendet die serverseitige Ausgabe, da die Dokument-API des Drittanbieters HTML auf dem Server rendert. Verwenden Sie für neue Anpassungen stattdessen die Galerie oder den integrierten Editor — sie funktionieren offline, bieten eine Live-Vorschau und benötigen keine Anfrage an den Server.
:::

## Häufige Anpassungen {#common-customisations}

Kurze Antworten auf die Fragen, die uns am häufigsten gestellt werden.

<Accordion>
  <AccordionItem question="Wie füge ich das Logo meiner Filiale hinzu?">

Logos stammen aus Ihren Filialeinstellungen, nicht aus der Vorlage selbst. Gehen Sie zu **WP Admin > POS > Einstellungen > Filialen**, bearbeiten Sie Ihre Filiale und laden Sie dort ein Logo hoch. Jede mitgelieferte Vorlage, die ein Logo anzeigt, verwendet es automatisch.

Wenn Sie ändern möchten, *wo* das Logo in der Vorlage erscheint, bearbeiten Sie die Vorlage und verschieben Sie den `{{#store.logo}}<img src="{{store.logo}}" ...>{{/store.logo}}` Block an die gewünschte Stelle.

  </AccordionItem>

  <AccordionItem question="Wie ändere ich den Fußzeilentext (z. B. „Vielen Dank für Ihren Einkauf!“)?">

Zwei Möglichkeiten:

1. **Am einfachsten** — legen Sie den Text einmalig für alle Belege unter **WP Admin > POS > Einstellungen > Filialen > Filialdetails > Belegfußzeile / persönliche Notiz** fest. Mitgelieferte Vorlagen übernehmen ihn automatisch; wenn keine Fußzeile festgelegt ist, verwenden sie einen freundlichen Standardtext wie *„Vielen Dank für Ihren Einkauf!“*.
2. **In einer einzelnen Vorlage** — bearbeiten Sie die Vorlage und ersetzen Sie den Fußzeilentext direkt. Suchen Sie nach `{{store.personal_notes}}` oder der ausgeschriebenen Dankeszeile.

  </AccordionItem>

  <AccordionItem question="Wie füge ich eine Tagline oder einen Slogan unter dem Filialnamen hinzu?">

Bearbeiten Sie die Vorlage und fügen Sie unter `{{store.name}}` eine Zeile hinzu:

```html
<div style="font-style: italic; color: #6b7280;">Family-owned since 1987</div>
```

In einer Thermovorlage:

```xml
<align mode="center"><text>Family-owned since 1987</text></align>
```

  </AccordionItem>

  <AccordionItem question="Wie blende ich Preise aus (für einen Geschenkbeleg)?">

Klicken Sie in der Galerie auf der Karte **Geschenkbeleg** auf **Vorlage verwenden** — damit werden alle Preise und Summen ausgeblendet, während Artikel, SKU, Attribute und die Geschenknachricht sichtbar bleiben. Eine Bearbeitung ist nicht erforderlich.

Wenn Sie lieber einen eigenen Beleg ohne Preise erstellen möchten, kopieren Sie eine beliebige Vorlage und löschen Sie die Blöcke `{{...total...}}`, `{{...price...}}` und `{{#totals}}...{{/totals}}`.

  </AccordionItem>

  <AccordionItem question="Wie ändere ich den Barcode in einen QR-Code?">

Suchen Sie das `<barcode>` Element in Ihrer Vorlage und ändern Sie das `type` Attribut:

```html
<!-- Default: Code 128 barcode of the order number -->
<barcode type="code128">{{order.number}}</barcode>

<!-- Switch to a QR code -->
<barcode type="qrcode">{{order.number}}</barcode>

<!-- Or encode something else, like a returns URL -->
<barcode type="qrcode">https://example.com/returns?order={{order.number}}</barcode>
```

Dieselbe `<barcode>` Syntax funktioniert sowohl in HTML- als auch in Thermovorlagen. Weitere unterstützte Typen sind `ean13`, `ean8`, `upca`, `pdf417` und [alles, was bwip-js unterstützt](https://github.com/metafloor/bwip-js/wiki/Supported-Barcode-Types).

  </AccordionItem>

  <AccordionItem question="Wie sende ich eine andere Vorlage an einen bestimmten Drucker?">

Gehen Sie in der POS-App zu **POS > Einstellungen > Drucken** und suchen Sie dann nach **Belegvorlagen**. Neben jeder aktiven Vorlage wird ein Drucker-Dropdown angezeigt. Wählen Sie den gewünschten Drucker aus oder belassen Sie die Einstellung bei **Auto**.

- **Auto** ordnet Vorlagen automatisch Druckern zu — Thermovorlagen gehen an Thermodrucker, HTML-Vorlagen öffnen den Systemdruckdialog.
- Ein **bestimmter Drucker** überschreibt Auto und sendet diese Vorlage immer an diesen Drucker.
- Beim Drucken kann die Kasse beide Einstellungen über das Drucker-Dropdown auf dem Belegbildschirm überschreiben.

Die Weiterleitung wird pro Gerät gespeichert, sodass jedes iPad oder jeder Computer eine eigene Einrichtung haben kann.

  </AccordionItem>

  <AccordionItem question="Mein Beleg zeigt nach der Bearbeitung immer noch die alte Version">

Klicken Sie auf dem Bearbeitungsbildschirm der Vorlage auf den WordPress-Button **Aktualisieren**. Der Editor speichert nicht automatisch — Ihre Änderungen bleiben erst erhalten, wenn Sie aktualisieren.

Bei **Legacy-PHP-Vorlagen** zeigt die Vorschau im Editor die *zuletzt gespeicherte* Version, nicht den gerade eingegebenen Inhalt. Speichern Sie zuerst und aktualisieren Sie dann die Vorschau.

  </AccordionItem>

  <AccordionItem question="Die Vorschau ist leer oder zeigt 'Keine POS-Bestellungen gefunden'">

Dies tritt nur bei **Legacy-PHP-Vorlagen** auf, die eine echte Bestellung für die Vorschau benötigen. Führen Sie eine einzelne POS-Bestellung durch — auch einen $0-Testverkauf — und die Vorschau wird funktionieren.

Logiklose (HTML) und Thermovorlagen verfügen immer über Beispieldaten als Fallback, sodass die Vorschau auch bei einem brandneuen Shop problemlos funktioniert.

  </AccordionItem>

  <AccordionItem question="Ich habe etwas durcheinandergebracht — wie fange ich neu an?">

Drei Sicherheitsnetze:

1. Der Editor verfügt über **Rückgängig** (Strg/Cmd + Z) für Änderungen innerhalb der Sitzung.
2. Jedes Speichern erstellt eine WordPress-**Revision** — öffnen Sie **Revisionen** auf dem Bearbeitungsbildschirm, um frühere Versionen zu vergleichen und wiederherzustellen.
3. Wenn Sie mit einer Galerievor­lage begonnen haben, klicken Sie auf **Löschen** bei Ihrer Kopie unter *Ihre Vorlagen* und dann erneut auf **Vorlage verwenden** auf derselben Galeriekarte. Sie erhalten eine neue, unveränderte Kopie.

  </AccordionItem>
</Accordion>

## Wann Sie um Hilfe bitten sollten {#when-to-ask-for-help}

- Der Vorlageneditor wird nicht geladen oder Änderungen werden nicht gespeichert.
- Der Beleg wird auf einem Gerät korrekt gedruckt, auf einem anderen jedoch nicht.
- Sie benötigen ein steuerliches oder rechtliches Layout für ein bestimmtes Land (Italien, Brasilien, Spanien usw.) — dies wird in der Regel durch [WCPOS Pro](/1.x/getting-started/pro-license) oder eine länderspezifische Integration abgedeckt.
- Sie versuchen etwas Individuelles umzusetzen und KI liefert nicht ganz das richtige Ergebnis.

Erstellen Sie ein [Support-Ticket](https://wcpos.com/support) und fügen Sie die Vorlage ein, an der Sie arbeiten — so haben wir alles, was wir zur Unterstützung benötigen.
