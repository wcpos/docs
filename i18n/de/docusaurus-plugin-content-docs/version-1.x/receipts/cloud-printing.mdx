Cloud-Druck ermöglicht es WCPOS, Belege an einen Drucker zu senden, der nicht direkt mit dem Gerät verbunden ist, auf dem die Kasse läuft. Richten Sie ihn einmal in WP Admin ein, und Ihre Bestellungen werden auf einem Küchendrucker, einem Backoffice-Drucker oder einem Drucker in einem anderen Raum gedruckt — ohne dass jedes Gerät die Hardware selbst erkennen und sich mit ihr koppeln muss.

## Was ist Cloud-Druck? {#what-is-cloud-printing}

Beim **lokalen Druck** kommuniziert das Gerät, auf dem der POS läuft, direkt über USB, Bluetooth oder das lokale Netzwerk mit dem Drucker. Das ist die richtige Wahl, wenn der Drucker neben der Kasse steht — unter [Druckereinrichtung](/1.x/hardware/printers) erfahren Sie, wie Sie USB-, Bluetooth- und Netzwerkdrucker mit demselben Gerät verbinden.

**Cloud-Druck** ist für alle anderen Fälle gedacht: einen Drucker an einem anderen Standort, in einem anderen Netzwerk oder einen Drucker, den alle Geräte gemeinsam nutzen sollen, ohne ihn auf jedem einzeln zu konfigurieren. Es gibt zwei Zustellmodelle:

- **Abfragende Drucker (Polling).** Der Drucker kontaktiert WCPOS in regelmäßigen Abständen über das Internet, fragt „Haben Sie etwas für mich?“ und holt alle wartenden Aufträge ab. WCPOS verbindet sich nie mit dem Drucker — der Drucker beginnt die Kommunikation immer selbst. So funktionieren **Star CloudPRNT** und **Epson Server Direct Print**.
- **Gehostete Relay-Anbieter.** WCPOS übermittelt den Druckauftrag an einen gehosteten Dienst, der ihn an den Drucker zustellt. So funktionieren **Star Online** und **PrintNode**. Star Online stellt Aufträge an Drucker mit Star CloudPRNT zu, die in Ihrem stario.online-Konto registriert sind; PrintNode erreicht über seinen Desktop-Client nahezu jeden Drucker, auf dem dieser Computer bereits drucken kann.

:::info Warum ein abfragender Drucker?
Ein abfragender Drucker benötigt keinen offenen Port, keine statische IP-Adresse und keine Firewall-Änderungen — er stellt ausschließlich ausgehende Anfragen. Damit eignet er sich ideal für einen entfernten Standort oder für den Einsatz hinter einem Router, den Sie nicht verwalten. Der Nachteil ist eine kurze Verzögerung: Der Drucker druckt erst bei seiner nächsten Abfrage.
:::

## WCPOS Cloud Print — das Relay {#relay}

Wenn Sie einen **abfragenden** Drucker einrichten (Star CloudPRNT oder Epson Server Direct Print), verweist die von WCPOS bereitgestellte Abfrage-URL auf **cloudprint.wcpos.com**, nicht auf Ihre eigene Website. Das ist **WCPOS Cloud Print** — ein kostenloses, von WCPOS betriebenes Relay zwischen Ihrem Drucker und Ihrem Shop.

**Warum es existiert.** Belegdrucker verwenden schlanke, selten aktualisierte Firmware. Viele können keine sichere Verbindung zu einem Shop auf modernem Hosting aufbauen: Neuere TLS-Versionen, neuere Zertifizierungsstellen oder ein CDN bzw. eine Firewall vor der Website (häufig Cloudflare) weisen den Drucker ab — oder werden von ihm abgewiesen. Das zeigt sich daran, dass der Drucker dauerhaft auf **Wartend** bleibt, obwohl alle Einstellungen korrekt sind. Das Relay bietet Druckern eine Verbindung, die auch ältere Firmware immer aushandeln kann, und leitet ihren Datenverkehr an Ihren Shop weiter.

**So funktioniert es:**

- Ihre Website verbindet sich **automatisch** mit dem Relay, wenn Sie die Cloud-Druck-Einstellungen zum ersten Mal öffnen — Sie müssen nichts aktivieren oder konfigurieren.
- Der Drucker fragt `cloudprint.wcpos.com` ab; das Relay leitet die Anfrage an Ihren Shop weiter und gibt dessen Antwort zurück. Druckaufträge laufen **durch** das Relay — sie werden dort niemals gespeichert.
- Das Relay fängt die meisten Abfragen im Leerlauf ab, sodass ein untätiger Drucker auf Ihrer Website etwa eine Anfrage pro Minute verursacht statt einer alle paar Sekunden.
- Wenn Ihre Website keine Verbindung zum Relay herstellen kann (zum Beispiel eine lokale Entwicklungswebsite, die das Relay nicht erreicht), greift WCPOS automatisch auf direkte URLs zur Website zurück.

:::note Lieber eine Direktverbindung?
Der Einrichtungsbildschirm jedes Druckers hat einen Aufklappbereich **Erweitert**, der die direkte URL zur Website anzeigt. Verwenden Sie diese, wenn Sie wissen, dass Ihr Hosting Druckerverbindungen unterstützt, oder wenn Sie Aufträge lieber nicht über das Relay leiten möchten. Entwickler können das Relay mit einer Zeile für die gesamte Website abschalten:

```php
add_filter( 'woocommerce_pos_cloud_print_relay_enabled', '__return_false' );
```
:::

**Was das Relay sehen kann.** Beim Verbinden wird Ihre Website-URL an wcpos.com übermittelt, und Druckaufträge — Beleginhalte, die Bestelldetails enthalten — passieren auf ihrem Weg zum Drucker das Relay. Nichts davon wird aufbewahrt. Alle Einzelheiten finden Sie in der [Datenschutzerklärung](https://wcpos.com/privacy).

## Einen Cloud-Drucker einrichten {#setup}

Cloud-Drucker werden einmal in WP Admin konfiguriert und von allen Geräten gemeinsam genutzt — im Gegensatz zu lokalen Druckern, die pro Gerät gespeichert werden.

Gehen Sie zu **WP Admin > POS > Einstellungen > Cloud-Druck** und klicken Sie auf **Drucker hinzufügen**. Geben Sie ihm einen **Namen** (zum Beispiel „Küche“ oder „Backoffice“). WCPOS leitet automatisch eine stabile **Drucker-ID** vom Drucker ab — sie ändert sich nie und kann daher zuverlässig in der Firmware-Konfiguration eines Druckers verwendet werden.

Nachdem der Drucker angelegt ist, nehmen Sie die Konfiguration auf Anbieterseite vor.

### Star oder Epson (abfragende Drucker) {#setup-polling}

<Steps>
  <StepCard number="1" title="Den Drucker in WCPOS hinzufügen">

Fügen Sie unter **WP Admin > POS > Einstellungen > Cloud-Druck** einen Drucker hinzu und wählen Sie **Star CloudPRNT** oder **Epson Server Direct Print** als Anbieter. WCPOS generiert für diesen Drucker eine **Abfrage-URL** und einen **Einmal-Token**.

  </StepCard>
  <StepCard number="2" title="Die Abfrage-URL und den Token kopieren">

Kopieren Sie die generierte Abfrage-URL und den Token. Die URL verweist normalerweise auf **cloudprint.wcpos.com** — das ist das [WCPOS Cloud Print Relay](#relay) und die vorgesehene Verbindung; die direkte URL zur Website finden Sie im Aufklappbereich **Erweitert**. Der **Token wird nur einmal angezeigt** — wenn Sie ihn verlieren, generieren Sie auf der Druckerkarte einen neuen und tragen Sie den neuen Wert im Drucker ein.

  </StepCard>
  <StepCard number="3" title="In die Konfiguration des Druckers eintragen" isLast>

Öffnen Sie die Konfigurationsseite des Druckers — die **CloudPRNT**-Einstellungen bei Star oder die **Server Direct Print**-Einstellungen bei Epson — und fügen Sie die Abfrage-URL und den Token ein. Stellen Sie das Abfrageintervall ein, falls der Drucker danach fragt (einige Sekunden sind üblich). Speichern Sie und starten Sie den Drucker bei Bedarf neu.

Innerhalb eines Abfragezyklus meldet sich der Drucker, und sein Status in WCPOS wechselt von **Wartend** zu **Verbunden**.

  </StepCard>
</Steps>

### PrintNode {#setup-printnode}

<Steps>
  <StepCard number="1" title="Den PrintNode-Desktop-Client installieren">

Installieren Sie den **PrintNode-Client** auf einem Computer, der bereits auf dem gewünschten Drucker drucken kann, und melden Sie sich an. Der Client muss weiterhin laufen und online bleiben, damit Aufträge gedruckt werden.

  </StepCard>
  <StepCard number="2" title="Einen PrintNode-API-Schlüssel erhalten">

Erstellen Sie in Ihrem PrintNode-Konto einen **API-Schlüssel**. Damit kann WCPOS Aufträge an Ihr PrintNode-Konto übermitteln.

  </StepCard>
  <StepCard number="3" title="Den API-Schlüssel in WCPOS eintragen">

Fügen Sie unter **WP Admin > POS > Einstellungen > Cloud-Druck** einen Drucker hinzu, wählen Sie **PrintNode** als Anbieter und fügen Sie den API-Schlüssel ein. WCPOS ruft damit die Liste der in Ihrem PrintNode-Konto registrierten Drucker ab.

  </StepCard>
  <StepCard number="4" title="Den Drucker auswählen" isLast>

Wählen Sie den gewünschten Drucker aus der Liste der vom PrintNode-Client gemeldeten Drucker und speichern Sie. WCPOS übermittelt Aufträge für diesen Drucker an PrintNode, und der Client druckt sie.

  </StepCard>
</Steps>

### Star Online {#setup-star-online}

Verwenden Sie Star Online, wenn Ihr Star-Drucker bereits in einem **stario.online**-Konto registriert ist und der gehostete Dienst von Star die Zustellung übernehmen soll.

<Steps>
  <StepCard number="1" title="Die CloudPRNT-URL erhalten">

Öffnen Sie in stario.online **Device Groups** und kopieren Sie die **CloudPRNT-URL** der Gruppe. Sie sollte wie `https://device.stario.online/cloudprnt/...` oder `https://eu-device.stario.online/cloudprnt/...` aussehen.

  </StepCard>
  <StepCard number="2" title="Einen API-Schlüssel mit Berechtigungen erstellen">

Erstellen Sie in stario.online einen API-Schlüssel für WCPOS. Der Schlüssel muss die Berechtigung haben, Geräte aufzulisten und auf ihnen zu drucken. Aktivieren Sie mindestens:

- **EnumDevices** — erforderlich, wenn WCPOS die Geräteliste abruft
- **ViewDevice** — wird zur Prüfung des Gerätestatus verwendet
- **PrintToDevice** — erforderlich zum Übermitteln von Druckaufträgen
- **ViewDeviceGroups** — empfohlen für die Gruppensuche und Diagnose

Auch ein vorhandener API-Schlüssel kann fehlschlagen, wenn diese Berechtigungen nicht aktiviert sind.

  </StepCard>
  <StepCard number="3" title="Die URL und den API-Schlüssel in WCPOS eintragen">

Fügen Sie unter **WP Admin > POS > Einstellungen > Cloud-Druck** einen Drucker hinzu, wählen Sie **Star Online** als Anbieter und fügen Sie die CloudPRNT-URL und den API-Schlüssel ein. Klicken Sie auf **Meine Geräte abrufen**.

  </StepCard>
  <StepCard number="4" title="Das Star-Gerät auswählen" isLast>

Wählen Sie den Drucker aus der Geräteliste und speichern Sie. WCPOS speichert den API-Schlüssel serverseitig und verwendet die Zugriffskennung des ausgewählten Geräts, um Aufträge an Star Online zu übermitteln.

  </StepCard>
</Steps>

## Automatische Druckregeln {#auto-print}

Regeln für den automatischen Druck legen in einfachen Sätzen fest, was automatisch wo gedruckt wird. Eine Regel besteht aus **Geltungsbereich × Drucker × Vorlage** sowie dem **Zeitpunkt** der Auslösung und der **Anzahl der Kopien**, zum Beispiel:

> Drucken Sie **jede Bestellung** auf **Küche** mit **Küchenbon**, **nach der Zahlung**, **×2**.

Eine Regel kann **bei Erstellung der Bestellung** oder **erst nach erfolgter Zahlung** ausgelöst werden — so kann ein Küchenbon sofort bei einer Bestellung gedruckt werden, während der Kundenbeleg auf die Zahlung wartet. Sie können außerdem die **Anzahl der Kopien** festlegen, wenn eine Station mehr als eine benötigt. Sobald eine passende Bestellung den gewählten Auslöser erreicht, rendert WCPOS die ausgewählte **Vorlage** serverseitig im benötigten Druckerformat und stellt sie in die Warteschlange — der Kassierer muss nichts tun.

:::note Die Vorlagenkompatibilität ist wichtig
Star- und Epson-Drucker können nur **Thermo**-Vorlagen verwenden, da der Auftrag in die native Befehlssprache des Druckers umgewandelt werden muss (Star Document Markup oder ESC/POS bei Star, ePOS-Print bei Epson). PrintNode kann **jede** Vorlage verwenden — Thermo oder ganzseitiges HTML —, da der Auftrag als **PDF** gerendert wird. Wenn eine Vorlage für einen Drucker nicht zur Auswahl steht, kann der Drucker dieses Format nicht rendern. Unter [Thermovorlagen](/1.x/receipts/thermal-templates) erfahren Sie, wie Sie Thermo-Layouts erstellen.
:::

## Drucker pro Filiale (Pro) {#per-store-printers}

:::info Pro-Funktion
Die Druckweiterleitung pro Filiale erfordert [WCPOS Pro](/1.x/getting-started/pro-license) und eine Einrichtung mit [mehreren Filialen](/1.x/stores).
:::

Standardmäßig gelten automatische Druckregeln global — alle Filialen nutzen dieselben Regeln. Mit Pro können Sie einer einzelnen Filiale **eigene** Cloud-Druckregeln zuweisen, damit ihre Bestellungen auf ihren eigenen Druckern gedruckt werden (ein Küchenbon für einen Standort sollte nicht an einem anderen gedruckt werden).

Bearbeiten Sie eine Filiale unter **POS → Filialen**, öffnen Sie den Abschnitt **Cloud-Druck** und klicken Sie auf **Regel hinzufügen**. Jede Regel besteht aus:

- **Drucker-ID** — die stabile ID des Cloud-Druckers, an den gesendet werden soll
- **Geltungsbereich** — **Nur POS-Bestellungen** (Standard), **Nur Online-Bestellungen** oder **Jede Bestellung**
- **Format** — **StarPRNT** (Standard), **ESC/POS**, **Epson ePOS-Print** oder **HTML**

Gehört eine Bestellung zu einer Filiale mit eigenen Regeln, leitet WCPOS sie an die Drucker dieser Filiale weiter. Hat eine Filiale **keine** eigenen Regeln, **greift sie auf die globalen** automatischen Druckregeln zurück — Sie müssen also nur Filialen mit abweichenden Anforderungen konfigurieren.

## Manueller Druck {#manual}

Sie müssen nicht auf eine automatische Druckregel warten. Vom **Kasse**-/Belegbildschirm aus kann ein Kassierer bei Bedarf einen Beleg an einen Cloud-Drucker senden — praktisch für Nachdrucke oder um einen einzelnen Bon an einen bestimmten Drucker zu schicken.

Wie der Beleg erzeugt wird, hängt vom Drucker ab:

- **Star CloudPRNT** — der Beleg wird **auf dem Gerät** gerendert und über CloudPRNT an den Drucker übergeben.
- **Star Online, Epson und PrintNode** — der Beleg wird **auf dem Server** aus der ausgewählten Bestellung und Vorlage gerendert und anschließend an den Drucker oder das gehostete Relay zugestellt.

:::note Alternative Ausgabeformate für problematische Drucker
**Star CloudPRNT** handelt den Medientyp mit dem Drucker aus und weicht auf Klartext (`text/plain`) aus, wenn ein Drucker das umfangreichere Format nicht akzeptiert. Bei Star-Druckern, deren Firmware StarPRNT-Befehle nicht dekodieren kann, kann WCPOS den Beleg **serverseitig als PNG-Bild** rendern und stattdessen dieses senden — so wird der Beleg trotzdem gedruckt, statt dass der Druck fehlschlägt.
:::

## Die Druckwarteschlange {#print-queue}

Jeder Auftrag für einen Cloud-Drucker bleibt in einer Warteschlange auf Ihrer Website, bis der Drucker ihn abholt (bei abfragenden Druckern) oder der Anbieter die Zustellung bestätigt. Unter **WP Admin > POS > Einstellungen > Cloud-Druck** wird die Warteschlange unterhalb Ihrer Drucker angezeigt:

- **Filtern** Sie nach Drucker oder Status — **Wartend**, **Wird gedruckt**, **Gedruckt**, **Fehlgeschlagen**, **Storniert** — mit laufend aktualisierten Anzahlen.
- Jede Zeile zeigt, wie lange der Beleg bereits **wartet**, und verlinkt auf die WooCommerce-**Bestellung**, zu der er gehört.
- Mit **Abbrechen** können Sie wartende Aufträge einzeln, gesammelt oder für einen ganzen Drucker auf einmal abbrechen. **Wiederholen** stellt einen fehlgeschlagenen Auftrag erneut in die Warteschlange.

Wenn für einen Drucker Aufträge warten, er aber seit mehreren Minuten nichts abgeholt hat, nennt ein **Warnbanner** den Drucker, zeigt die Anzahl und Wartezeit der aufgestauten Belege und bietet **Alle abbrechen** an — so kann sich kein unbemerkter Rückstau bilden, während ein Drucker nicht angeschlossen ist.

## Testdruck & Verbindungsstatus {#status}

Jede Druckerkarte hat eine Schaltfläche **Testdruck**, die einen kurzen Diagnosedruck sendet. Damit können Sie prüfen, ob der Drucker erreichbar ist und das Format stimmt, bevor Sie ihn für echte Bestellungen einsetzen.

Die Karte zeigt außerdem den aktuellen Status:

| Anbieter | Status | Bedeutung |
|----------|--------|---------|
| **Star CloudPRNT / Epson** | **Wartend** | Der Drucker hat sich noch nicht gemeldet — WCPOS wartet auf seine erste Abfrage. |
| **Star CloudPRNT / Epson** | **Verbunden** | Der Drucker hat WCPOS kürzlich abgefragt und holt Aufträge ab. |
| **Star Online** | **Online** | Star Online meldet, dass das ausgewählte Gerät verfügbar ist. |
| **Star Online** | **Offline** | Star Online meldet, dass das ausgewählte Gerät nicht verfügbar ist. |
| **Star Online** | **Unbekannt** | WCPOS konnte den Gerätestatus von Star Online nicht bestätigen. |
| **PrintNode** | **Online** | Der PrintNode-Dienst meldet, dass Client und Drucker verfügbar sind. |
| **PrintNode** | **Offline** | PrintNode meldet, dass der Client oder Drucker nicht verfügbar ist. |

## Fehlerbehebung {#troubleshooting}

<Accordion>
  <AccordionItem question="Drucker bleibt bei Wartend hängen">

  Ein abfragender Drucker, der dauerhaft auf **Wartend** bleibt, hat WCPOS noch nie erfolgreich erreicht. Prüfen Sie Folgendes:

  - Die **Abfrage-URL und der Token** in der Druckerfirmware stimmen exakt mit den von WCPOS generierten Werten überein. Schon ein falsches Zeichen führt dazu, dass jede Abfrage abgelehnt wird — generieren Sie den Token in WCPOS neu und tragen Sie ihn erneut ein, wenn Sie unsicher sind.
  - Der Drucker kann über das Internet tatsächlich **Ihre Website erreichen** (korrektes DNS, keine Firewall, die ausgehende HTTPS-Verbindungen blockiert, gültiges SSL-Zertifikat für Ihren Shop).
  - **Das Abfragen ist aktiviert**, und in der CloudPRNT-/Server-Direct-Print-Konfiguration des Druckers ist ein sinnvolles Intervall eingestellt. Starten Sie den Drucker nach Änderungen an den Einstellungen neu.
  - Wenn Sie die **direkte URL zur Website** (aus dem Aufklappbereich Erweitert) eingetragen haben und sich der Drucker weiterhin nicht verbindet, wechseln Sie zur Standard-URL **cloudprint.wcpos.com** — viele Drucker können mit modernem Hosting keine sichere Verbindung aushandeln, und [genau dieses Problem behebt das Relay](#relay).

  </AccordionItem>

  <AccordionItem question="Warum verweist meine Drucker-URL auf cloudprint.wcpos.com?">

  Das ist [WCPOS Cloud Print](#relay), das kostenlose Relay, das Druckern eine von ihrer Firmware unterstützte Verbindung bietet und ihre Druckaufträge an Ihren Shop weiterleitet. Es ist automatisch aktiv, Aufträge werden dort niemals gespeichert, und die direkte URL zur Website steht jederzeit im Aufklappbereich **Erweitert** des Druckers zur Verfügung, falls Sie diese bevorzugen.

  </AccordionItem>

  <AccordionItem question="Ich habe meinen Drucker eingerichtet, bevor es das Relay gab — muss ich etwas ändern?">

  Nein — bereits in der Druckerkonfiguration gespeicherte URLs funktionieren weiterhin. Wenn der Drucker jedoch **auf Wartend hängen bleibt**, kann seine Firmware wahrscheinlich keine direkte Verbindung zu Ihrem Hosting herstellen: Öffnen Sie **Einrichtung &amp; Token** auf der Druckerkarte, generieren Sie den Token neu und tragen Sie die neue **cloudprint.wcpos.com**-URL und den Token in der Druckerkonfiguration ein.

  </AccordionItem>

  <AccordionItem question="Star Online meldet, dass der API-Schlüssel nicht autorisiert oder verboten ist">

  Star Online unterscheidet zwischen **Authentifizierung** und **Berechtigungen**:

  - **401 / Authentifizierung fehlgeschlagen** bedeutet, dass der API-Schlüssel selbst nicht akzeptiert wurde. Prüfen Sie, ob er korrekt kopiert und nicht widerrufen wurde und zum erwarteten Star Online-Konto bzw. zur erwarteten Region gehört.
  - **403 / verboten** bedeutet, dass der API-Schlüssel akzeptiert wurde, aber keine Berechtigung für die angeforderte Aktion hat. Bearbeiten Sie den Schlüssel in stario.online und aktivieren Sie die erforderlichen Berechtigungen, insbesondere **EnumDevices** für **Meine Geräte abrufen** und **PrintToDevice** zum Drucken.

  Wenn **Meine Geräte abrufen** erfolgreich ist, aber keine Drucker erscheinen, prüfen Sie in stario.online die Seite **Device Groups**. Die Gruppe muss mindestens ein verbundenes Gerät enthalten, und die CloudPRNT-URL in WCPOS muss auf dieselbe Gruppe verweisen.

  </AccordionItem>

  <AccordionItem question="PrintNode-Auftrag wird nie gedruckt">

  Der Auftrag hat PrintNode erreicht, wurde aber nicht vom Drucker ausgegeben. Prüfen Sie Folgendes:

  - Der **PrintNode-Desktop-Client läuft und ist online** auf dem Computer, der mit dem Drucker verbunden ist. Befindet sich der Computer im Ruhezustand oder ist der Client geschlossen, wird nichts gedruckt.
  - Sie haben in WCPOS den **richtigen Drucker** ausgewählt — der Name muss mit dem vom Client gemeldeten Drucker übereinstimmen.
  - Der **API-Schlüssel ist gültig** und wurde nicht widerrufen. Tragen Sie ihn erneut ein, wenn PrintNode den Drucker als Offline anzeigt.

  </AccordionItem>

  <AccordionItem question="Meine Vorlage ist für einen Star- oder Epson-Drucker nicht auswählbar">

  Auf Star- und Epson-Cloud-Druckern funktionieren nur **Thermo**-Vorlagen, da der Beleg in ESC/POS- oder ePOS-Print-Befehle umgewandelt werden muss. HTML- und ganzseitige Vorlagen lassen sich in diesen Formaten nicht darstellen und werden daher für diese Drucker ausgeblendet.

  Wählen Sie entweder eine [Thermovorlage](/1.x/receipts/thermal-templates) oder verwenden Sie einen **PrintNode**-Drucker — PrintNode rendert als PDF und kann daher jede Vorlage drucken.

  </AccordionItem>
</Accordion>
