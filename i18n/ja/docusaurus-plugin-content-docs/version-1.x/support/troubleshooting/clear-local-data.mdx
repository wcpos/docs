WCPOS は、商品、注文、顧客のローカルコピーを保存し、POS がすばやく動作し、オフラインでも利用できるようにしています。このローカルデータが WooCommerce 店舗のデータと一致しなくなることがあります。ローカルデータをすべてクリアすると、ローカルデータベースが削除され、サーバーから新たに同期が始まります。

:::tip まずは対象を絞ったリセットをお試しください（v1.10.0+）
v1.10.0 以降、**ストアヘルス → データベース**ではコレクションごとに**クリアして再ダウンロード**を利用できます。問題が起きているコレクション（たとえば商品）だけを削除して再取得でき、他のデータには影響せず、ログアウトもされません。確認画面には削除されるレコード数が表示され、サーバー側のデータには影響しないことが示されます。必要に応じてダウンロードされるコレクションは、リセット直後には件数が少なく表示され、使用するにつれてデータが補充されます。これは想定どおりの動作であり、同期が停止しているわけではありません。[ストアヘルス](/1.x/support/store-health#clear-and-redownload)を参照してください。
:::

:::warning
これは最終手段です。ローカルデータをクリアすると、デバイスに保存されているすべてのデータが削除され、完全な再同期が行われます。店舗の規模によっては時間がかかることがあります。通常の[同期](/1.x/products/sync)や、コレクションごとの**クリアして再ダウンロード**など、他の方法で問題が解決しない場合にのみ使用してください。

クリアする前に、**ストアヘルス → データベース**の**送信待ちの変更**タイルを確認してください。ローカルデータをクリアすると、デバイス上の未送信の変更はすべて失われます。
:::

## 使用するタイミング {#when-to-use-it}

次の場合は、ローカルデータのクリアが必要になることがあります。

- **同期の問題** — 商品、注文、顧客が正しく更新されない場合
- **プラグインの更新後** — 新しいデータ構造との互換性を確保するため
- **古いデータ** — 価格、在庫数、その他の情報が古い状態で表示される場合

## クリアされる項目 {#what-gets-cleared}

| クリアされる項目 | クリアされない項目 |
|---------|-------------|
| ローカル商品データベース | サーバー側のデータ |
| ローカル注文データベース | WooCommerce の設定 |
| ローカル顧客データベース | |
| ログインセッション | |

WooCommerce 店舗のデータには影響せず、デバイス上のローカルコピーのみが削除されます。クリア後は、新たな同期が自動的に始まります。

:::info プラットフォームによる違い
- **デスクトップアプリ：** ログアウトされるため、店舗に再接続する必要があります。
- **ウェブアプリ：** ログインデータはクリアされますが、WP Admin にはログインしたままなので、セッションが自動的に復元されます。そのため、ログアウトされたようには見えません。
:::

## ローカルデータをクリアする方法 {#how-to-clear-local-data}

### ウェブ {#web}

1. 右上の**ユーザーメニュー**をクリックしてメニューを開きます
2. **すべてのローカルデータをクリア**をクリックします
3. ローカルデータベースが削除され、新たな同期が自動的に始まります

### デスクトップ {#desktop}

1. 上部のメニューバーから **WCPOS** アプリケーションメニューを開きます
2. **アドバンスト**にマウスポインターを合わせます
3. **アプリデータをクリア**をクリックします
4. ローカルデータベースが削除され、新たな同期が自動的に始まります

:::note
すべてのプラットフォームで同じローカルデータベース形式を使用しています（v1.10.0 以降は OPFS ベースのファイルストレージ）。どのプラットフォームでも完全にクリアされますが、ログインの動作は異なります。上記のプラットフォームによる違いについての説明を参照してください。
:::
