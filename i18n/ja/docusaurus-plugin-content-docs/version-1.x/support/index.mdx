WCPOSについての助けが必要ですか？サポートを受ける方法と質問に対する答えを見つける方法は以下の通りです。

## アプリ内サポート {#in-app-support}

POSには、左側のナビゲーションドロワーからアクセスできる組み込みのサポート画面があります。この画面はアプリ内にWCPOS Discordコミュニティを埋め込んでおり、以下のことができます：

- 既存のディスカッションを閲覧する
- よくある質問の答えを検索する
- #generalチャンネルで質問する
- お知らせを常に最新の状態に保つ

アプリ外からは、[wcpos.com/discord](https://wcpos.com/discord) で同じサーバーに参加できます。

## Discordコミュニティ {#discord-community}

WCPOS の主なサポート窓口は Discord サーバーです。[wcpos.com/discord](https://wcpos.com/discord) から参加してください。このリンクから常に最新の招待を開けます。

### チャンネル {#channels}

| チャンネル | 目的 |
|---------|---------|
| **#welcome-and-rules** | コミュニティガイドライン |
| **#announcements** | 更新情報やニュース |
| **#general** | 主なサポートチャンネル - ここで質問してください |
| **#forum** | より長いディスカッションや機能リクエスト |
| **#github-activity** | 開発の更新情報 |

### 質問する前に {#before-asking}

最良の助けを得るために：

1. **まずテスト** - プラグインをダウンロードし、数日間テストしてニーズに合っているか理解してください
2. **ドキュメントをチェック** - 多くの質問はこのドキュメントで回答されています
3. **[Discord](https://wcpos.com/discord) で検索する** - 質問への回答がすでに見つかるかもしれません。
4. **詳細を提供** - WooCommerceのバージョン、WCPOSのバージョン、問題を再現する手順を含めてください

## メールサポート {#email-support}

ライセンス関連の問題やプライベートな問い合わせについては、以下のメールに連絡してください：**support@wcpos.com**

:::note
一般的なサポートの質問は [Discord](https://wcpos.com/discord) に投稿してください。コミュニティから回答を得られ、他の人もその回答を参考にできます。
:::

## ストアヘルスのログ {#logs-screen}

POS のアクティビティログは [**ストアヘルス → ログ**](/1.x/support/logs) にあります。次のような場面で役立ちます：

- 同期の問題をデバッグする
- エラーメッセージを理解する
- サポートを依頼する際に詳しい情報を提供する

サポートを依頼する際は、**ストアヘルス → ログ** にエラーメッセージがないか確認し、問い合わせに含めてください。

## Pro サポート {#pro-support}

[WCPOS Pro](https://wcpos.com/pro) をご利用のお客様も、[Discord](https://wcpos.com/discord) で同じコミュニティサポートを受けられます。Pro ライセンスは、無料機能と Pro 機能の継続的な開発を支えます。

## 貢献 {#contributing}

WCPOSはオープンソースです！あなたは以下のように貢献できます：

- [GitHub](https://github.com/wcpos)でバグを報告する
- [Discord](https://wcpos.com/discord) の #forum チャンネルで機能を提案する
- ドキュメントを翻訳する
- 自分の経験を他の人と共有する
