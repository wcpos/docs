WCPOS でスムーズにチェックアウトするには、パフォーマンスの最適化が重要です。このセクションでは、一般的なパフォーマンスの問題とその解決方法を説明します。

## 一般的なパフォーマンスの問題 {#common-performance-issues}

パフォーマンスに関してよく寄せられる問題は、次のとおりです：

- **チェックアウト処理が遅い** - 決済モーダルの読み込みや決済処理に時間がかかります
- **インターフェースの反応が遅い** - POS 画面の操作に対する反応が鈍く感じられます
- **同期に時間がかかる** - 商品や注文の同期に時間がかかりすぎます。v1.10.0 以降では、まず **ストアヘルス → パフォーマンス** で実測の応答時間を確認してください。ホスティング環境に負荷がかかっている場合は、より負荷の軽い[同期プリセット](/1.x/support/store-health#sync-presets)を検討してください

## パフォーマンスのカテゴリー {#performance-categories}

### [チェックアウトパフォーマンス](/1.x/support/performance/checkout) {#checkout-performance}
チェックアウト処理を最適化して、決済を高速化し、顧客体験を向上させます。

### [注文ストレージ（HPOS）](/1.x/support/performance/order-storage) {#order-storage-hpos}
店舗の規模が大きくなるにつれてチェックアウトが遅くなっていませんか？WooCommerce が従来の注文ストレージを使用しているか確認し、HPOS に切り替えてください。

### [サーバーパフォーマンス](/1.x/support/performance/server) {#server-performance}
組み込みの指標とトラブルシューティングの手法を使って、WordPress/WooCommerce サーバーを監視し、最適化します。

### [ストアヘルス](/1.x/support/store-health) {#store-health}
このレジから実測したサーバー負荷、同期プリセット、ダウンロードのカバレッジ、アクティビティログを表示するアプリ内ダッシュボードです（v1.10.0+）。
