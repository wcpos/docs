WCPOS は WooCommerce REST API 上で動作するため、ほとんどの WooCommerce プラグインは追加設定なしで POS 注文に対応します。一部のプラグインはオンラインのチェックアウトまたは WP Admin の注文画面にしかフックしないため、WCPOS 側で処理を行う必要があります。このセクションのページでは、対象プラグインに対して WCPOS が行うこと、設定方法、レジで想定される動作を説明します。

これは、拡張機能ディレクトリからインストールする WCPOS 向けアドオンの[拡張機能](/1.x/extensions)とは異なります。連携の対象は、オンラインストアですでに使用しているプラグインです。

## 動作しない場合 {#something-not-working}

使用中のプラグインが POS で正常に動作しない場合は、まず[プラグインの競合](/1.x/support/troubleshooting/plugin-conflicts)をご覧ください。既知の競合と、新しい競合の特定方法を説明しています。
