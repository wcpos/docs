:::info プロ機能
商品画面を使用するには[WCPOS Pro](/1.x/getting-started/pro-license)が必要です。無料版では[POS商品パネル](/1.x/pos/product-panel)で商品を表示してカートに追加できますが、在庫や価格は編集できません。
:::

商品画面は、在庫管理専用のインターフェースです。販売用の[POS商品パネル](/1.x/pos/product-panel)とは異なり、商品カタログを管理するための画面です。

{/* Screenshot: products-screen.png */}

## 商品画面とPOS商品パネルの違い {#products-screen-vs-pos-product-panel}

| 機能 | POS商品パネル | 商品画面 |
|---------|-------------------|-----------------|
| **目的** | 商品をカートに追加 | 在庫管理 |
| **在庫** | 表示のみ | インライン編集 |
| **価格** | 表示のみ | インライン編集 |
| **アクション** | カートに追加 | 編集、同期、削除 |
| **利用可能** | 無料版 + Pro | Proのみ |

## インターフェース概要 {#interface-overview}

### 検索とフィルター {#search--filters}

画面上部には次の項目があります。

- **検索バー** - 名前、SKU、バーコードで商品を検索
- **フィルターボタン** - 在庫状況、特集、セール中、カテゴリー、タグ、ブランド
- **表示設定** (<Icon name="sliders" />) - 表示する列を設定

### 商品リスト {#product-list}

メインエリアには、スクロール可能なテーブルで商品が表示されます。

- **画像** - 商品のサムネイル
- **商品名** - 必要に応じてSKU、バーコード、属性を表示
- **在庫** - 「管理」トグル付きの編集可能な在庫数量
- **在庫状況** - 在庫あり（緑）、在庫切れ（赤）、バックオーダー
- **カテゴリー** - 商品カテゴリーのバッジ
- **価格** - 現在の価格、通常価格、セール価格（すべて編集可能）
- **アクション** - 編集、同期、削除を選べる三点メニュー

:::note 並べ替えと絞り込みは店舗全体が対象です
並べ替えと絞り込みは**サーバー**上で実行されるため、端末に保存済みの商品だけでなく、カタログ全体が対象になります。名前、SKU、在庫、価格、日付で並べ替えられ、スクロールするとカタログの最後まで商品行が読み込まれます。一方、商品**検索**はカタログがローカルに保存された後は端末上で実行されるため、サーバーへのリクエストなしですぐに結果が表示されます。
:::

### バリアブル商品 {#variable-products}

バリアブル商品には次の項目が表示されます。
- 属性の選択肢（色、サイズなど）
- すべてのバリエーションを表示する「展開」リンク
- 在庫と価格を個別に管理する各バリエーションの行

### フッター {#footer}

- **税の状況** - 現在の税計算基準
- **商品数** - 「Y件中X件を表示」と同期ボタン (<Icon name="arrow-rotate-right" />)。同期ボタンを**長押し**すると、クリアとリフレッシュのオプションが表示されます（v1.10.0以降は、この操作で画面の検索条件と有効なフィルターもクリアされ、リストがフィルターなしの状態に戻ります）

## 主な機能 {#key-features}

### インライン在庫編集 {#inline-stock-editing}

在庫数量を直接クリックして編集します。

1. 在庫数をクリックします
2. 新しい数量を入力します
3. Enterを押して保存します

変更はWooCommerceに自動的に同期されます。

### 在庫管理トグル {#manage-stock-toggle}

「管理」トグルでは、WooCommerceでこの商品の在庫を管理するかどうかを切り替えます。

- **オン** - 在庫数を管理し、販売時に減算します
- **オフ** - 常に購入可能にします（在庫数は無制限）

### インライン価格編集 {#inline-price-editing}

編集する価格フィールドをクリックします。

- **価格** - 現在の販売価格
- **通常価格** - 割引前の価格
- **セール価格** - 割引後の価格（セール中の場合）

### 売上原価 {#cost-of-goods-sold}

WooCommerceの売上原価（COGS）機能では、各商品の原価を管理できます。WCPOSはこのデータを商品画面に表示します。

原価を表示するには、**売上原価**の列を有効にします。設定場所： [表示設定](#display-settings) （<Icon name="sliders" />）で**売上原価**の列を有効にします。この列には販売価格とともに原価が表示されるため、利益率を一目で確認できます。

:::info プロ機能
[WCPOS Pro](/1.x/getting-started/pro-license)では、商品画面から原価を直接**編集**できます。在庫や価格フィールドと同様に、原価の値をクリックしてインラインで更新できます。
:::

:::note WooCommerceの要件
売上原価はWooCommerceストアで有効にする必要があります。**WooCommerce > 設定 > 詳細設定 > 機能**に移動し、売上原価オプションを有効にしてください。これには、売上原価機能が有効になっている最近のバージョンのWooCommerceが必要です。設定の詳細についてはWooCommerceのドキュメントを参照してください。
:::

### 商品アクション {#product-actions}

各商品の三点メニュー（⋮）をクリックします：

- **編集** - 商品編集モーダルを開く
- **同期** - WooCommerceからこの商品をリフレッシュ
- **削除** - ローカルデータベースから商品を削除

:::note
POS で商品を削除しても、**ローカル**から削除されるだけです。商品は WooCommerce に残り、次回の同期で戻ります。**WooCommerce で**商品が削除されると、同期によって POS からも削除されるため、端末と店舗のデータが一致した状態に保たれます。
:::

### 利用可能な列 {#available-columns}

| 列 | 説明 | 表示オプション |
|--------|-------------|-----------------|
| **画像** | 商品サムネイル | - |
| **ID** | WooCommerce商品ID | - |
| **商品** | 商品名 | SKU、バーコード、属性 |
| **タイプ** | シンプル、バリアブル、グループなど | - |
| **SKU** | 在庫保持単位 | - |
| **バーコード** | 商品バーコード | - |
| **在庫** | 現在の数量（編集可能） | - |
| **在庫状況** | 在庫あり / 在庫切れ / バックオーダー | - |
| **カテゴリー** | 商品カテゴリー | - |
| **タグ** | 商品タグ | - |
| **ブランド** | ブランド情報（プラグインがアクティブな場合） | - |
| **売上原価** | 商品原価（Proで編集可能） | - |
| **価格** | 現在の販売価格（編集可能） | 税情報 |
| **通常価格** | 割引されていない価格（編集可能） | 税情報 |
| **セール価格** | 割引された価格（編集可能） | 税情報 |
| **作成日** | 商品が作成された日 | - |
| **最終更新日** | 最後の変更日 | - |
| **アクション** | 編集、同期、削除ボタン | - |

### デフォルト設定に戻す {#restore-default-settings}

すべての表示設定を元のデフォルトにリセットするにはクリックします。

## 商品のフィルタリング {#filtering-products}

フィルターボタンを使用して表示を絞り込みます：

- **在庫状況** - 在庫あり、在庫切れ、バックオーダー
- **特集** - 特集としてマークされた商品
- **セール中** - 現在セール中の商品
- **カテゴリー** - 商品カテゴリーでフィルタリング
- **タグ** - 商品タグでフィルタリング
- **ブランド** - ブランドでフィルタリング（ブランドプラグインを使用している場合）

## ソート {#sorting}

任意の列ヘッダーをクリックすると、その列でソートされます。再度クリックするとソート順序が逆になります。
