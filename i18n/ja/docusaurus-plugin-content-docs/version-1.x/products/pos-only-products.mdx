POS専用製品は、製品をオンラインストア、POS、またはその両方のどこに表示するかを制御する機能です。オンライン販売と店頭販売で製品カタログが異なる場合に便利です。

## 概要 {#overview}

有効にすると、各製品に次の三つの選択肢を持つ**POSでの表示**設定が追加されます。

| 可視性 | オンラインストア | POS |
|------------|--------------|-----|
| **POS & オンライン**（デフォルト） | 表示 | 表示 |
| **POS専用** | 非表示 | 表示 |
| **オンライン専用** | 表示 | 非表示 |

## この機能を使用するタイミング {#when-to-use-this-feature}

次のような場合に、POS専用製品を有効にしてください。

- **店頭限定商品を販売する** - 実店舗に来店した顧客だけが購入できる製品
- **オンライン専用アイテムをPOSから隠す** - デジタル製品、予約商品、店頭では販売しないアイテム
- **異なるカタログを管理する** - オンラインと小売の販売チャネルで異なる品揃え
- **プロモーションアイテムを制御する** - 店頭限定の特別商品やオンライン限定の特売品

:::tip
すべての製品を両方のチャネルに表示する場合、この機能は不要です。パフォーマンスを保つため、無効のままにしてください。
:::

## 機能の有効化 {#enabling-the-feature}

1. **WP Admin > WCPOS > 設定 > 一般**に移動します
2. **「POS専用商品を有効化」** を有効にします
3. 変更を保存します

一般設定の詳細については、[WP Admin一般設定](/1.x/settings/wp-admin/general)を参照してください。

:::warning パフォーマンスへの影響
この設定は必要な場合のみ有効にしてください。有効にすると、製品へのリクエストのたびにデータベースへの追加の問い合わせが発生するため、大規模なカタログを持つ店舗ではパフォーマンスに影響する可能性があります。
:::

## 製品可視性の設定 {#setting-product-visibility}

### 個別製品 {#individual-products}

製品ごとに可視性を設定するには、次の手順に従います。

1. **WP Admin → 製品**に移動し、製品を編集します
2. **製品データ**パネルで**POS可視性**を探します
3. 希望するオプションを選択します。
   - **POS & オンライン** - 製品を両方に表示します（デフォルト）
   - **POS専用** - オンラインストアでは製品を非表示にします
   - **オンライン専用** - POSでは製品を非表示にします
4. **更新**をクリックして保存します

### 一括編集 {#bulk-editing}

複数の製品の可視性をまとめて変更するには、次の手順に従います。

1. **WP Admin → 製品**に移動します
2. チェックボックスで変更する製品を選択します
3. **一括アクション**のドロップダウンから**編集**を選択します
4. **適用**をクリックします
5. 一括編集パネルで**POS可視性**のドロップダウンを探します
6. 希望する可視性オプションを選択します
7. **更新**をクリックします

### 変数製品 {#variable-products}

変数製品では、親製品と各バリエーションの両方で可視性を設定できます。たとえば、オンラインではすべてのバリエーションを表示し、店頭では特定の色やサイズだけを表示するなど、細かく制御できます。

## POSへの影響 {#how-it-affects-the-pos}

製品を**オンライン専用**に設定すると、次のようになります。

- [製品パネル](/1.x/pos/product-panel)に表示されません
- 検索やバーコードスキャンで見つかりません
- POSでカートに追加できません

製品を**POS専用**に設定すると、次のようになります。

- ショップの製品カタログ、カテゴリーページ、WooCommerce独自の検索から除外されます
- オンラインでカートに追加したり、購入したりできません
- WooCommerce REST APIとStore APIの製品リストから除外されます

**カタログでの表示も非表示に設定してください。** POS専用の設定と、公開ボックス内のPOS可視性のすぐ上にあるWooCommerceの**カタログでの表示**は別々の設定です。WCPOSはPOS専用製品を標準的なWooCommerceの製品クエリから除外しますが、WooCommerceのカタログでの表示を直接参照する機能では、カタログでの表示を**非表示**に設定しない限り製品が表示されます。FiboSearchやRelevanssiなどの検索プラグイン、関連製品、IDで製品を一覧表示するブロックやショートコードが該当します。設定するには、公開ボックスの**カタログでの表示**の横にある**編集**をクリックし、**非表示**を選択してから**更新**をクリックします。逆方向も同様に、設定は連動しません。製品を後で**POS & オンライン**または**オンライン専用**に戻すときは、カタログでの表示を自分で**ショップと検索結果**に戻してください。戻さないと、ウェブサイトでは非表示のままになります。

:::note
製品の表示設定を変更した後も、POSに製品が表示される（または表示されない）場合は、同期を試してください。同期ボタンを長押しし、**「クリアして更新」** を選択すると、すべての製品データが再読み込みされます。
:::

### POS専用製品が引き続き表示される場所 {#where-pos-only-products-stay-visible}

POS専用製品の非表示は、ストアフロントに適用されるルールです。買い物用ではなく、ショップを運営するための画面やツールでは、製品は引き続き表示されます。

- **WP Admin**（製品一覧と製品編集画面を含む）
- **WooCommerce Analytics**（POS専用製品のカテゴリーで絞り込んだレポートにも、その製品の売上が表示されます）
- `wp wc product list`などの**WP-CLI**コマンド
- **POS自体**

ショップの製品カタログと検索、ブロック型のカートとチェックアウトで使用されるWooCommerce Store API、WooCommerce REST API(`/wc/v3/products`)、および製品フィードやサイトマップなど、これらを利用する機能では非表示になります。

開発者は`woocommerce_pos_hide_pos_only_products`フィルターを使って、独自のコンテキストでこの判定を変更できます。このフィルターにはデフォルトの判定と実行予定の`WP_Query`が渡されます。`false`を返すと、そのクエリでPOS専用製品を取得できます。

```php
add_filter( 'woocommerce_pos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

## 一般的な使用例 {#common-use-cases}

<UseCases>
  <UseCaseCard icon="gift" title="店頭専用ギフトカード">

  レジで有効化する必要がある実物のギフトカードの場合：

  1. ギフトカード製品を作成します
  2. 可視性を**POS専用**に設定します
  3. カードはオンラインには表示されませんが、スタッフは店頭で販売できます

  </UseCaseCard>

  <UseCaseCard icon="globe" title="オンライン予約販売">

  オンラインで予約可能ですが、まだ入荷していない製品の場合：

  1. 予約商品を作成します
  2. 可視性を**オンライン専用**に設定します
  3. 顧客はオンラインで予約でき、POSには不要な製品が表示されません

  </UseCaseCard>

  <UseCaseCard icon="building" title="卸売と小売">

  同じWooCommerceストアで卸売と小売を行う場合：

  1. 卸売専用製品を**オンライン専用**に設定します（B2Bポータルからのアクセス用）
  2. 小売限定製品を**POS専用**に設定します
  3. 通常の製品は**POS & オンライン**のままにします

  </UseCaseCard>
</UseCases>

## トラブルシューティング {#troubleshooting}

<Accordion>
  <AccordionItem question="オンライン専用に設定した後も製品が表示される">

  1. POSを開きます
  2. 製品パネル下部の同期ボタンを長押しします
  3. **「クリアして更新」** を選択します
  4. 製品が再読み込みされるまで待ちます

  </AccordionItem>

  <AccordionItem question="製品に設定が表示されない">

  機能が有効になっていることを確認してください。

  1. **WP Admin > WCPOS > 設定 > 一般**に移動します
  2. **「POS専用商品を有効化」** にチェックが入っていることを確認します
  3. 変更した場合は設定を保存します

  </AccordionItem>

  <AccordionItem question="POS専用製品がウェブサイトに表示される">

  次の二点を確認してください。

  1. **カタログでの表示が「非表示」になっていること。** 製品を開き、公開ボックスの**カタログでの表示**を確認します。**非表示**以外になっている場合は、**編集**をクリックし、**非表示**を選択して製品を更新してください。検索プラグイン、関連製品、IDで製品を一覧表示するブロックやショートコードは、WCPOSのPOS可視性ではなく、このWooCommerce設定を参照するため、POS専用に設定するだけでは非表示になりません。
  2. **ページがキャッシュされていないこと。** キャッシュプラグインやCDNにより、製品をPOS専用にする前に生成されたショップページや検索ページが引き続き配信されることがあります。表示設定を変更した後、サイトのキャッシュをクリアしてください。

  製品への直接リンクを開くと、引き続き製品ページが表示されます。これはWooCommerce独自の「非表示」設定でも同じです。そのページから製品をカートに追加することはできません。

  </AccordionItem>

  <AccordionItem question="POS専用製品のカテゴリーで絞り込むと、アナリティクスに「データなし」と表示される">

  WCPOSプラグインのバージョン1.10.26以前では、ストアフロントのルールがWooCommerce Analyticsにも適用されていました。POS専用製品で構成されたカテゴリーでレポートを絞り込むと製品が見つからず、**データなし**と表示される一方、同じ製品を名前で検索すると売上が表示されていました。

  この問題は、WCPOSプラグインの1.10.26より後の最初のリリースで修正されています。プラグインを更新してください。製品やレポートの設定を変更する必要はありません。

  </AccordionItem>
</Accordion>
