POS専用製品は、製品がオンラインストア、POS、またはその両方に表示されるかを制御する機能です。これは、オンラインと店頭販売のために異なる製品カタログがある場合に便利です。

## 概要 {#overview}

有効にすると、各商品に3つの選択肢がある**POS可視性**設定が追加されます:

| 可視性 | オンラインストア | POS |
|------------|--------------|-----|
| **POS & オンライン** (デフォルト) | 表示 | 表示 |
| **POS専用** | 非表示 | 表示 |
| **オンライン専用** | 表示 | 非表示 |

## この機能を使用するタイミング {#when-to-use-this-feature}

POS専用製品を有効にする必要がある場合：

- **店頭限定商品を販売する** - 顧客が物理店舗を訪れたときにのみ利用可能な製品
- **オンライン専用アイテムをPOSから隠す** - デジタル製品、予約商品、または店舗で販売すべきでないアイテム
- **異なるカタログを管理する** - オンラインと小売チャネルのための別々の製品範囲
- **プロモーションアイテムを制御する** - 店頭専用の特別商品またはオンライン限定のディール

:::tip
すべての製品が両方のチャネルに表示される場合、この機能は必要ありません。パフォーマンス向上のために無効のままにしてください。
:::

## 機能の有効化 {#enabling-the-feature}

1. **WP Admin → WCPOS → 設定 → 一般**に移動します
2. **「POS専用製品を有効にする」**を有効にします
3. 変更を保存します

一般設定の詳細については、[WP Admin一般設定](/settings/wp-admin/general)をご覧ください。

:::warning パフォーマンスへの影響
この設定は必要な場合のみ有効にしてください。有効にすると、すべての製品リクエストに対して追加のデータベースルックアップが追加され、大規模カタログの店舗のパフォーマンスに影響を与える可能性があります。
:::

## 製品可視性の設定 {#setting-product-visibility}

### 個別製品 {#individual-products}

単一の製品の可視性を設定するには：

1. **WP Admin → 製品**に移動し、製品を編集
2. **製品データ**パネルで**POS可視性**を探します
3. 希望のオプションを選択：
   - **POS & オンライン** - 製品はすべての場所に表示されます（デフォルト）
   - **POS専用** - 製品はオンラインストアから隠されます
   - **オンライン専用** - 製品はPOSから隠されます
4. **更新**をクリックして保存します

### 一括編集 {#bulk-editing}

複数の製品の可視性を一度に変更するには：

1. **WP Admin → 製品**に移動
2. チェックボックスを使用して変更したい製品を選択
3. **一括アクション**のドロップダウンから**編集**を選択
4. **適用**をクリック
5. 一括編集パネルで**POS可視性**のドロップダウンを見つけます
6. 希望の可視性オプションを選択
7. **更新**をクリックします

### 変数製品 {#variable-products}

変数製品の場合、親製品レベルと各個別のバリエーションの両方で可視性を設定できます。これにより詳細な制御が可能です - 例えば、すべてのバリエーションをオンラインで表示しつつ、特定の色やサイズのみを店頭で表示することができます。

## POSへの影響 {#how-it-affects-the-pos}

製品が**オンライン専用**に設定されている場合：

- [製品パネル](/pos/product-panel)に表示されません
- 検索やバーコードスキャンでは見つかりません
- POSでカートに追加できません

製品が**POS専用**に設定されている場合：

- ショップの製品カタログ、カテゴリーページ、WooCommerce 独自の検索には表示されません
- カートに追加したり、オンラインで購入したりできません
- WooCommerce REST API と Store API の製品リストには含まれません

**カタログでの表示も「非表示」に設定してください。** POS専用と、WooCommerce独自の**カタログでの表示**設定は別々です。この設定は「公開」ボックスでPOS可視性のすぐ上にあります。WCPOSはPOS専用製品を標準のWooCommerce製品クエリから除外しますが、WooCommerceのカタログでの表示設定を直接参照するものには、設定を**非表示**にしない限り製品が表示されます。FiboSearchやRelevanssiなどの検索プラグイン、関連製品、IDで製品を一覧表示するブロックやショートコードが該当します。設定するには、「公開」ボックスで**カタログでの表示**の横にある**編集**をクリックし、**非表示**を選んでから**更新**をクリックします。逆の場合も2つの設定は別々です。後で製品を**POS & オンライン**または**オンライン専用**に戻すときは、カタログでの表示も自分で**ショップと検索結果**に戻してください。戻さないと、Webサイトでは非表示のままになります。

:::note
最近製品の可視性を変更した場合で、POSにまだ表示されている（または表示されていない）場合は、同期を試してください。同期ボタンを長押しし、**「クリアしてリフレッシュ」**を選択してすべての製品データを再読み込みします。
:::

### POS専用製品が引き続き表示される場所 {#where-pos-only-products-stay-visible}

POS専用製品の非表示は、ストアフロントに適用されるルールです。製品は、買い物をする画面ではなく、ショップを運営する画面では引き続き表示されます:

- **WP Admin**（製品一覧や製品編集画面を含む）
- **WooCommerce Analytics**（POS専用製品のカテゴリーで絞り込んだレポートにも、その製品の売上が表示されます）
- `wp wc product list` などの **WP-CLI** コマンド
- **POS 自体**

ショップの製品カタログと検索、ブロック型カートとチェックアウトで使用される WooCommerce Store API、WooCommerce REST API (`/wc/v3/products`)、および製品フィードやサイトマップなど、これらを利用して構築された機能では非表示になります。

開発者は `woocommerce_pos_hide_pos_only_products` フィルターを使って、独自のコンテキストでこの判定を変更できます。このフィルターには既定の判定と実行予定の `WP_Query` が渡されます。`false` を返すと、そのクエリで POS専用製品を表示できます。

```php
add_filter( 'woocommerce_pos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

## 一般的な使用例 {#common-use-cases}

<UseCases>
  <UseCaseCard icon="gift" title="店頭専用ギフトカード">

  レジでアクティベートが必要な物理的なギフトカード：

  1. ギフトカード製品を作成
  2. 可視性を**POS専用**に設定
  3. カードはオンラインに表示されませんが、スタッフは店頭で販売できます

  </UseCaseCard>

  <UseCaseCard icon="globe" title="オンライン予約販売">

  オンラインで予約販売可能ですが、まだ在庫がない製品：

  1. 予約商品を作成
  2. 可視性を**オンライン専用**に設定
  3. 顧客はオンラインで予約できますが、POSが混雑することはありません

  </UseCaseCard>

  <UseCaseCard icon="building" title="卸売と小売">

  同じWooCommerceストアを卸売と小売の両方で使用している場合：

  1. 卸売専用製品を**オンライン専用**に設定（B2Bポータルアクセス用）
  2. 小売専用を**POS専用**に設定
  3. 通常の製品は**POS & オンライン**として保持

  </UseCaseCard>
</UseCases>

## トラブルシューティング {#troubleshooting}

<Accordion>
  <AccordionItem question="オンライン専用に設定した後も製品が表示される">

  1. POSを開く
  2. 製品パネルの底にある同期ボタンを長押し
  3. **「クリアしてリフレッシュ」**を選択
  4. 製品が再読み込みされるのを待つ

  </AccordionItem>

  <AccordionItem question="製品に設定が表示されない">

  機能が有効になっていることを確認してください：

  1. **WP Admin → WCPOS → 設定 → 一般**に移動します
  2. **「POS専用製品を有効にする」**がチェックされていることを確認
  3. 変更した場合は設定を保存

  </AccordionItem>

  <AccordionItem question="POS専用製品がウェブサイトに表示される">

  次の2点を確認してください:

  1. **カタログでの表示が「非表示」になっていること。** 製品を開き、「公開」ボックスの **カタログでの表示** を確認します。**非表示** 以外になっている場合は、**編集** をクリックし、**非表示** を選択して製品を更新してください。検索プラグイン、関連製品、ID で製品を一覧表示するブロックやショートコードは、WCPOS の POS可視性ではなく、この WooCommerce 設定を参照するため、POS専用に設定するだけでは非表示になりません。
  2. **ページがキャッシュされていないこと。** キャッシュプラグインや CDN により、製品を POS専用にする前に生成されたショップまたは検索ページが引き続き配信されることがあります。表示設定を変更した後、サイトのキャッシュをクリアしてください。

  製品への直接リンクを開くと、引き続き製品ページが表示されます。WooCommerce 独自の「非表示」設定でも同じ動作になります。そのページから製品をカートに追加することはできません。

  </AccordionItem>

  <AccordionItem question="POS専用製品のカテゴリーで絞り込むと、Analytics に「No data」と表示される">

  WCPOS プラグインのバージョン 1.10.26 以前では、ストアフロントのルールが WooCommerce Analytics にも適用されていました。POS専用製品で構成されたカテゴリーでレポートを絞り込むと製品が見つからず、**No data** と表示される一方、同じ製品を名前で検索すると売上が表示されていました。

  この問題は、WCPOS プラグインの 1.10.26 より後の最初のリリースで修正されています。プラグインを更新してください。製品やレポートの設定を変更する必要はありません。

  </AccordionItem>
</Accordion>
