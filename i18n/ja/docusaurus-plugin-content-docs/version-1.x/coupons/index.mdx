:::info Pro機能
クーポン画面およびレジでのクーポン適用機能を利用するには、[WCPOS Pro](/getting-started/pro-license)が必要です。無料ユーザーにはクーポン画面のぼかしプレビューが表示されますが、クーポンの詳細を確認したり、カートでコードを適用したりすることはできません。
:::

クーポン画面では、POS内からWooCommerceのクーポンを閲覧・検索できます。カートの**クーポンを追加**ボタンを押すと、現在の注文に適用されます。クーポンの作成と管理はWooCommerceで行います。POSはクーポンを同期してローカルで検証するため、レジですぐに結果を確認できます。

## インターフェースの概要 {#interface-overview}

### ヘッダーの操作 {#header-actions}

画面上部には次の項目があります：

- **検索バー** — コードでクーポンを検索します
- **表示設定** (<Icon name="sliders" />) — 表示する列を設定します

### クーポンテーブル {#coupons-table}

メインエリアには、同期済みクーポンの次の情報が表示されます：

- **コード** — 顧客が入力するクーポンコード
- **説明** — 内部向けの説明（設定されている場合、レシートのラベルにも使用）
- **割引タイプ** — 割合、カート定額、または商品定額
- **金額** — 割引額
- **使用回数 / 上限** — 使用回数と全体の使用上限
- **有効期限** — 有効期限。設定されていない場合は空欄です
- **アクション** — 三点メニュー

### フッター {#footer}

- 同期ボタン付きのクーポン数 (<Icon name="arrow-rotate-right" />)。**長押し**すると、クリアと更新のオプションが表示されます。

## クーポンの種類 {#coupon-types}

WCPOSはWooCommerceの標準クーポン3種類に対応しています：

| 種類 | 内容 | 例 |
|---|---|---|
| **割合割引** | カートの小計を割合で割り引きます | 注文から `10%` 割引 |
| **カート定額割引** | カートの合計から定額を割り引きます | 注文から `$5` 割引 |
| **商品定額割引** | 対象商品の明細を1個あたり定額で割り引きます | Tシャツ1枚につき `$2` 割引 |

3種類すべてに同じ検証ルール（有効期限、使用回数制限、商品やカテゴリの制限など）が適用されます。

## クーポンの作成 {#creating-coupons}

クーポンはPOSではなくWooCommerceで作成します。**WP Admin → マーケティング → クーポン → クーポンを追加**に移動します：

1. **クーポンコード** — レジでレジ係が入力するコードです。大文字と小文字は区別されません。
2. **説明** — 内部向けのメモです。設定されている場合、WCPOSはレシートの割引ラベルとして使用するため、内部コードではなく「マネージャー割引 10%」のような顧客向けの表現をおすすめします。
3. **割引タイプ** — 割合、カート定額、または商品定額です。
4. **クーポン金額** — 割引額です。
5. **有効期限** — 任意です。この日付を過ぎるとクーポンは拒否されます。

### 利用制限 {#usage-restriction}

| 制限 | 内容 | 例 |
|---|---|---|
| **最低利用金額 / 最高利用金額** | 小計が指定した金額を超える / 下回る場合にのみクーポンが適用されます | `$50` を超える注文でのみ有効 |
| **個別利用のみ** | このクーポンを他のクーポンと併用できないようにします | "VIP20" と "SALE10" は併用できません |
**セール商品を除外** — すでにセール中の商品（およびキャッシャーがレジで価格を下げた明細行）をスキップします（[POSの価格変更](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)を参照）。
| **対象商品 / 除外商品** | クーポンの対象商品を指定、または対象外の商品を指定します | "Espresso Beans" にのみ適用 |
| **対象カテゴリ / 除外カテゴリ** | カテゴリで制限します。POSで作成したその他の商品やカスタム商品にも、POSで割り当てたカテゴリが適用されます | "Drinks" カテゴリにのみ適用 |
| **許可メールアドレス** | 特定の顧客メールアドレスに限定します（`*` ワイルドカードに対応） | スタッフ限定の場合は `*@yourcompany.com` |

### 使用制限 {#usage-limits}

| 制限 | 内容 |
|---|---|
| **クーポンごとの使用回数制限** | すべての顧客を通じて、このコードを使用できる合計回数 |
| **ユーザーごとの使用回数制限** | 1人の顧客が使用できる回数 |
| **使用をX個の商品に制限** | 商品定額クーポンの場合、1回の使用で割引する対象商品の個数を制限します |

<a id="tips-for-pos-use"></a>

:::tip POSでの使用のヒント
- **「マネージャー 10%」**クーポン（10%割引、最低利用金額なし、有効期限なし、個別利用の制限なし）を作成し、そのコードをマネージャーに渡します。スタッフはレジで臨時の調整に使え、レポートには割引の記録が残ります。
- リピーターへの特典として、**「ロイヤルティ $5」**クーポンを作成します。
- 一度限りのプロモーションでは、コードが後で誤って再利用されないよう、有効期限を短く設定します。
- **説明**にレシートへ印字したい文言を設定すると、割引にブランド名を反映する最も手早い方法になります。
:::

## レジでクーポンを適用する {#applying-a-coupon-at-the-register}

カートで**クーポンを追加**をタップし、コードを入力するか、説明で検索します。同期済みデータを使ってクーポンがすぐに検証され、カート合計の上に削除可能なピルとして表示されます。

検索、クーポンピル、複数クーポンの併用、検証エラーの解決など、レジでの完全なワークフローについては、**[レジでのクーポン適用](/coupons/applying-coupons)** を参照してください。

## バリデーションの仕組み {#how-validation-works}

コードが入力されると、POSはWooCommerceがサーバー上でチェックするのと同じルールをすべて検証します：

- クーポンが存在し、有効期限内であること
- 使用回数の上限を超えていないこと（全体およびユーザーごと）
- 最小/最大利用金額の条件を満たしていること
- 「個別利用」クーポンが適用済みのクーポンと競合しないこと
- 商品/カテゴリの制限がカートの内容と一致すること
- メール制限が選択された顧客と一致すること（ゲスト注文の場合はスキップ）
- **セール商品を除外**が有効な場合、セール商品は除外されること

いずれかのチェックに失敗すると、レジ担当者に具体的なエラーメッセージが表示されます（例：「このクーポンは有効期限切れです」「最低利用金額に達していません」）。注文送信時にサーバー上で同じチェックが再度実行されます — ローカルバリデーションは速度のためであり、信頼性を担保するものではありません。

## 同期の動作 {#sync-behaviour}

クーポンは、他のPOSデータと同様にWooCommerceからデバイスに同期されます：

- WP Admin で作成した新しいクーポンは、次回の同期時に POS に表示されます。
- 既存クーポンの更新（使用回数、有効期限の変更など）は自動的に同期されます。
- クーポンはローカルデータベースに保存されるため、オフラインでも利用できます。

WP Admin でクーポンを作成したのにまだ表示されない場合は、同期がまだ実行されていない可能性があります。クーポン画面のフッターから同期アイコン（<Icon name="arrow-rotate-right" />）をタップして更新してください。完全に再取得する必要がある場合は、長押しして**クリアして更新**を選択してください。

## 接続要件 {#connectivity}

- **クーポンの適用**は、同期済みデータによるクライアント側の検証で処理されるため、オフラインでも動作します。
- **会計の完了**は、オフライン対応の支払い方法を使えばオフラインでも行えます。売上はローカルにキューイングされ、WooCommerce に到達した時点でサーバーがクーポンを再検証し、使用回数を更新します。
- **クーポンの作成・編集**は WP Admin で行うため、WordPress サイトへの接続が必要です。

## クーポンと POS 割引の関係 {#how-coupons-interact-with-pos-discounts}

レジでスタッフが明細の価格を下げた後にクーポンを適用すると、クーポンは元の価格ではなく**値下げ後の価格**に対して計算されます。POS で値下げされた明細は「セール中」として扱われるため、**セール品を除外**が有効なクーポンはそれらをスキップします。詳細は[割引](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)を参照してください。
