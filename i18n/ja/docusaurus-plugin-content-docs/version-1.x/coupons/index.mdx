:::info Pro機能
クーポン画面とレジでのクーポン適用機能には [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。無料版ではクーポン画面のぼかしプレビューが表示されますが、クーポンの詳細を確認したり、カートでコードを適用したりすることはできません。
:::

クーポン画面では、POS 内から WooCommerce のクーポンを参照・検索できます。カートの**クーポンを追加**ボタンで、現在の注文にクーポンを適用します。クーポンの作成と管理は引き続き WooCommerce で行います。POS はクーポンを同期してローカルで検証するため、レジで即座に結果を確認できます。

## 画面の概要 {#interface-overview}

### ヘッダーの操作 {#header-actions}

画面上部には次の項目があります：

- **検索バー** — コードでクーポンを検索します
- **表示設定** (<Icon name="sliders" />) — 表示する列を設定します

### クーポンテーブル {#coupons-table}

メインエリアには、同期済みのクーポンが次の情報とともに表示されます：

- **コード** — 顧客が入力するクーポンコード
- **説明** — 内部向けの説明（設定されている場合はレシートのラベルにも使用されます）
- **割引タイプ** — 割合割引、カート定額割引、商品固定割引
- **金額** — 割引額
- **使用回数 / 上限** — 使用回数と全体の使用回数上限
- **有効期限** — 有効期限。未設定の場合は空欄
- **アクション** — 三点メニュー

### フッター {#footer}

- クーポン数と同期ボタン (<Icon name="arrow-rotate-right" />)。**長押し**すると、クリアと更新のオプションが表示されます。

## クーポンの種類 {#coupon-types}

WCPOS は、WooCommerce 標準の三種類のクーポンに対応しています：

| 種類 | 内容 | 例 |
|---|---|---|
| **割合割引** | カート小計を一定の割合で割引します | 注文から `10%` 割引 |
| **カート定額割引** | カート合計から一定額を割引します | 注文から `$5` 割引 |
| **商品固定割引** | 条件に一致する商品明細を、商品あたり一定額割引します | Tシャツ各点につき `$2` 割引 |

三種類すべてに同じ検証ルール（有効期限、使用回数上限、商品・カテゴリ制限など）が適用されます。

## クーポンの作成 {#creating-coupons}

クーポンは POS ではなく WooCommerce で作成します。**WP Admin → マーケティング → クーポン → クーポンを追加**に移動してください：

1. **クーポンコード** — レジ係がレジで入力するコードです。大文字と小文字は区別されません。
2. **説明** — 内部向けのメモです。設定すると、WCPOS はレシートの割引ラベルに使用します。内部コードよりも「マネージャー割引 10%」など、顧客にわかりやすい文言を使ってください。
3. **割引タイプ** — 割合割引、カート定額割引、商品固定割引です。
4. **クーポン金額** — 割引額です。
5. **有効期限** — 任意です。この日付を過ぎるとクーポンは拒否されます。

### 利用制限 {#usage-restriction}

| 制限 | 内容 | 例 |
|---|---|---|
| **最低利用金額 / 最高利用金額** | 小計が下限を上回る、または上限を下回る場合にのみ適用されます | `$50` を超える注文でのみ有効 |
| **個別利用のみ** | 他のクーポンとの併用を禁止します | 「VIP20」と「SALE10」は併用できません |
| **セール商品を除外** | セール中の商品と、レジ係がレジで値下げした明細を対象外にします（[POSでの価格変更](/1.x/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)を参照） | 在庫処分品には追加割引が適用されません |
| **対象商品 / 除外商品** | 特定の商品を対象にする、または対象外にします | 「エスプレッソ豆」のみに適用 |
| **対象カテゴリ / 除外カテゴリ** | カテゴリで制限します。POS で作成したその他の商品やカスタム商品にも、POS で割り当てたカテゴリに基づく制限が適用されます | 「ドリンク」カテゴリのみに適用 |
| **許可メールアドレス** | 特定の顧客のメールアドレスにクーポンを制限します（`*` ワイルドカードに対応） | スタッフ専用なら `*@yourcompany.com` |

### 使用制限 {#usage-limits}

| 制限 | 内容 |
|---|---|
| **クーポンごとの使用回数制限** | 全顧客を通じてこのコードを使用できる合計回数 |
| **ユーザーごとの使用制限** | 顧客あたりの使用可能回数 |
| **使用をX個の商品に制限** | 商品固定割引クーポンで、利用ごとに割引する対象商品の数を制限します |

<a id="tips-for-pos-use"></a>

:::tip POSでの活用ヒント
- **「マネージャー 10%」** クーポン（10%割引、最低利用金額なし、有効期限なし、個別利用のみの制限はオフ）を作成し、コードをマネージャーに渡します。スタッフがレジで臨時の調整に使え、レポートには追跡可能な割引として残ります。
- リピーター向けの特典として **「ロイヤルティ $5」** クーポンを作成します。
- 一度限りのプロモーションでは、コードが後日誤って再利用されないよう、有効期限を短く設定してください。
- **説明**にレシートへ印刷したい文言を設定するのが、独自の割引名を付ける最も手軽な方法です。
:::

## レジでのクーポン適用 {#applying-a-coupon-at-the-register}

カートの**クーポンを追加**をタップし、コードを入力するか説明で検索します。同期済みデータに基づいて即座に検証され、カート合計の上に削除可能なピルとして表示されます。

検索、クーポンピル、複数クーポンの併用、検証エラーへの対処など、レジ係の詳しい操作手順は **[レジでのクーポン適用](/1.x/coupons/applying-coupons)** を参照してください。

## バリデーションの仕組み {#how-validation-works}

コードを入力すると、POS は WooCommerce がサーバー上で確認するのと同じルールをすべて確認します：

- クーポンが存在し、有効期限内であること
- 使用回数の上限を超えていないこと（全体およびユーザーごと）
- 最低利用金額・最高利用金額の条件を満たしていること
- 「個別利用」のクーポンが適用済みのクーポンと競合しないこと
- カートの内容が商品・カテゴリの制限に合っていること
- 選択した顧客がメールアドレスの制限に合っていること（ゲスト注文では確認を省略します）
- **セール商品を除外**が有効な場合、セール商品が除外されること

いずれかの確認で条件を満たさない場合、レジ係に具体的なエラーメッセージ（「このクーポンは有効期限切れです」「最低利用金額に達していません」など）が表示されます。注文の送信時には、サーバーでも同じ確認を再度行います。ローカルでの検証は処理を速くするためであり、信頼性を保証するためではありません。

## 同期の動作 {#sync-behaviour}

クーポンは、他の POS データと同じように WooCommerce からデバイスに同期されます：

- WP Admin で新しく作成したクーポンは、次回の同期時に POS に表示されます。
- 既存クーポンの更新（使用回数、有効期限の変更など）は自動的に同期されます。
- クーポンはローカルデータベースに保存されるため、オフラインでも利用できます。

WP Admin で作成したばかりのクーポンがまだ表示されない場合は、同期が実行されていない可能性があります。クーポン画面のフッターにある同期アイコン (<Icon name="arrow-rotate-right" />) をタップして更新してください。データを取得し直すには、長押しして**クリアして更新**を選択します。

## 接続要件 {#connectivity}

- **クーポンの適用**は、同期済みデータを使ってクライアント側で検証するため、オフラインでも動作します。
- **会計の完了**は、オフライン対応の支払い方法を使えばオフラインでも可能です。販売データはローカルで送信待ちとなり、注文が WooCommerce に届くとサーバーがクーポンを再検証し、使用回数を更新します。
- **クーポンの作成・編集**は WP Admin で行うため、WordPress サイトへの接続が必要です。

## クーポンとPOS割引の関係 {#how-coupons-interact-with-pos-discounts}

レジ係が明細の価格を下げてからクーポンを適用すると、元の価格ではなく**値下げ後の価格**で割引が計算されます。POS で値下げされた明細は「セール中」として扱われ、**セール商品を除外**が有効なクーポンは適用されません。詳しくは[割引](/1.x/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)を参照してください。
