:::info Pro機能
クーポン画面およびレジでのクーポン適用機能を利用するには、[WCPOS Pro](/getting-started/pro-license)が必要です。無料ユーザーにはクーポン画面のぼかしプレビューが表示されますが、クーポンの詳細を確認したり、カートでコードを適用したりすることはできません。
:::

クーポン画面では、POS内からWooCommerceのクーポンを参照・検索できます。カートの**クーポンを追加**ボタンを押すと、現在の注文にクーポンが適用されます。クーポンの作成と管理は引き続きWooCommerceで行います。POSはクーポンを同期し、レジで即座に結果を確認できるようローカルで検証します。

## 画面の概要 {#interface-overview}

### ヘッダーの操作 {#header-actions}

画面上部には次の項目があります:

- **検索バー** — クーポンコードを検索します
- **表示設定** (<Icon name="sliders" />) — 表示するカラムを設定します

### クーポンテーブル {#coupons-table}

メインエリアには、同期済みのクーポンが次の情報とともに表示されます:

- **コード** — 顧客が入力するクーポンコード
- **説明** — 内部向けの説明（設定されている場合、レシートラベルにも使用されます）
- **割引タイプ** — パーセント、固定カート、または固定商品
- **金額** — 割引額
- **使用回数 / 上限** — 使用回数と全体の使用上限
- **有効期限** — 有効期限。設定されていない場合は空欄です
- **アクション** — 三点メニュー

### フッター {#footer}

- 同期ボタン付きのクーポン数 (<Icon name="arrow-rotate-right" />) — **長押し**すると、クリアと更新のオプションが表示されます。

## クーポンの種類 {#coupon-types}

WCPOSは、標準的なWooCommerceクーポンの3種類に対応しています:

| 種類 | 内容 | 例 |
|---|---|---|
| **割合割引** | カートの小計を割合で割引します | 注文から`10%`割引 |
| **カート定額割引** | カート合計から一定額を割引します | 注文から`$5`割引 |
| **商品定額割引** | 条件に一致する商品の明細を1個あたり一定額で割引します | Tシャツ1枚あたり`$2`割引 |

3種類すべてに同じ検証ルール（有効期限、使用制限、商品やカテゴリーの制限など）が適用されます。

## クーポンの作成 {#creating-coupons}

クーポンはPOSではなくWooCommerceで作成します。**WP Admin → マーケティング → クーポン → クーポンを追加**に移動します:

1. **クーポンコード** — レジ係がレジで入力するコードです。大文字と小文字は区別されません。
2. **説明** — 内部向けのメモです。設定されている場合、WCPOSはレシート上の割引名として使用します。内部コードよりも「マネージャー割引 10%」のような顧客にわかりやすい表現がおすすめです。
3. **割引タイプ** — パーセント、固定カート、または固定商品です。
4. **クーポン金額** — 割引額です。
5. **有効期限** — 任意です。この日付を過ぎるとクーポンは使用できません。

### 利用制限 {#usage-restriction}

| 制限 | 内容 | 例 |
|---|---|---|
| **最低利用金額 / 最高利用金額** | 小計がしきい値を上回る（または下回る）場合にのみ適用されます | `$50`を超える注文でのみ有効 |
| **個別利用のみ** | 他のクーポンとの併用を禁止します | 「VIP20」と「SALE10」は併用できません |
| **セール商品を除外** | セール中の商品（およびレジ係が会計時に値下げした明細 — [POSでの価格変更](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)を参照）を対象外にします | 値下げ商品には追加割引が適用されません |
| **対象商品 / 除外商品** | 特定の商品を対象にする（または対象外にする）よう制限します | 「エスプレッソ豆」のみに適用 |
| **対象カテゴリ / 除外カテゴリ** | カテゴリで制限します。POSで作成されたその他の商品やカスタム商品も、POSで割り当てられたカテゴリが適用されます | 「ドリンク」カテゴリのみに適用 |
| **許可メールアドレス** | クーポンを特定の顧客メールアドレスに制限します（`*`ワイルドカードに対応） | スタッフ専用なら`*@yourcompany.com` |

### 使用制限 {#usage-limits}

| 制限 | 内容 |
|---|---|
| **クーポンごとの使用回数制限** | すべての顧客を通じた、このコードの合計使用回数 |
| **ユーザーごとの使用回数制限** | 1人の顧客が使用できる回数 |
| **使用をX個の商品に制限** | 固定商品クーポンの場合、1回の使用で割引する対象商品の数を制限します |

<a id="tips-for-pos-use"></a>

:::tip POS での活用ヒント
- **「マネージャー 10%」**クーポン（10%割引、最低利用金額なし、有効期限なし、1回限りの使用制限なし）を作成して、コードをマネージャーに知らせます。レジ係はその場の調整に使用でき、レポートには追跡可能な割引として記録されます。
- リピーター向けの特典として、**「ロイヤルティ $5」**クーポンを作成します。
- 1回限りのプロモーションでは、後から誤ってコードを再利用しないよう、有効期限を短く設定してください。
- **説明**にレシートへ印字したい文言を設定すると、割引に名前を付ける最も手早い方法になります。
:::

## レジでのクーポン適用 {#applying-a-coupon-at-the-register}

カートの**クーポンを追加**をタップし、コードを入力するか、説明で検索します。同期済みデータに基づいてクーポンがすぐに検証され、カート合計の上に削除可能なピルとして表示されます。

検索、クーポンピル、複数クーポンの併用、検証エラーの解決など、レジでの完全なワークフローについては、**[レジでのクーポン適用](/coupons/applying-coupons)** を参照してください。

## バリデーションの仕組み {#how-validation-works}

コードが入力されると、POSはWooCommerceがサーバー上でチェックするのと同じルールをすべて検証します：

- クーポンが存在し、有効期限内であること
- 使用回数の上限を超えていないこと（全体およびユーザーごと）
- 最小/最大利用金額の条件を満たしていること
- 「個別利用」クーポンが適用済みのクーポンと競合しないこと
- 商品/カテゴリの制限がカートの内容と一致すること
- メール制限が選択された顧客と一致すること（ゲスト注文の場合はスキップ）
- **セール商品を除外**が有効な場合、セール商品は除外されること

いずれかのチェックに失敗すると、レジ担当者に具体的なエラーメッセージが表示されます（例：「このクーポンは有効期限切れです」「最低利用金額に達していません」）。注文送信時にサーバー上で同じチェックが再度実行されます — ローカルバリデーションは速度のためであり、信頼性を担保するものではありません。

## 同期の動作 {#sync-behaviour}

クーポンは、他のPOSデータと同様にWooCommerceからデバイスに同期されます：

- WP Admin で作成した新しいクーポンは、次回の同期時に POS に表示されます。
- 既存クーポンの更新（使用回数、有効期限の変更など）は自動的に同期されます。
- クーポンはローカルデータベースに保存されるため、オフラインでも利用できます。

WP Admin でクーポンを作成したのにまだ表示されない場合は、同期がまだ実行されていない可能性があります。クーポン画面のフッターから同期アイコン（<Icon name="arrow-rotate-right" />）をタップして更新してください。完全に再取得する必要がある場合は、長押しして**クリアして更新**を選択してください。

## 接続要件 {#connectivity}

- **クーポンの適用**は、同期済みデータによるクライアント側の検証で処理されるため、オフラインでも動作します。
- **会計の完了**は、オフライン対応の支払い方法を使えばオフラインでも行えます。売上はローカルにキューイングされ、WooCommerce に到達した時点でサーバーがクーポンを再検証し、使用回数を更新します。
- **クーポンの作成・編集**は WP Admin で行うため、WordPress サイトへの接続が必要です。

## クーポンと POS 割引の関係 {#how-coupons-interact-with-pos-discounts}

レジでスタッフが明細の価格を下げた後にクーポンを適用すると、クーポンは元の価格ではなく**値下げ後の価格**に対して計算されます。POS で値下げされた明細は「セール中」として扱われるため、**セール品を除外**が有効なクーポンはそれらをスキップします。詳細は[割引](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)を参照してください。
