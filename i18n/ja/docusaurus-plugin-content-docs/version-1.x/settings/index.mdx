WCPOS の設定は、設定場所に応じて三種類に分かれています。

## 設定の場所 {#where-to-find-settings}

### 1. WordPress 管理設定 {#1-wordpress-admin-settings}

WordPress ダッシュボードで行うバックエンドの設定です。

**場所：** `WP Admin > POS > 設定`

次の項目を設定します。
- すべてのレジ係に適用されるカートのデフォルト顧客
- 商品バーコードフィールドの設定
- 注文メールの設定
- ユーザーロールの権限（POS にアクセスできるユーザー）
- 利用できる決済ゲートウェイ

詳細については、[WordPress 管理設定](/1.x/settings/wp-admin)を参照してください。

### 2. POS 店舗設定 {#2-pos-store-settings}

POS アプリケーション内で行う、アプリ全体の設定です。

**場所：** ユーザーメニュー（右上）→ 設定、または `Ctrl + Shift + S`

次の項目を設定します。
- 税計算オプション
- バーコードスキャナーの設定
- キーボードショートカット
- テーマ/外観

詳細については、[店舗設定](/1.x/settings/store)を参照してください。

### 3. 表示設定（画面ごと） {#3-display-settings-per-screen}

POS の各画面には、データテーブルをカスタマイズするための表示設定があります。

**場所：** 任意の画面でスライダーアイコン（<Icon name="sliders" />）をクリックします

次の項目を設定します。
- 表示する列
- 列の表示オプション
- 画面固有の機能

表示設定については、各画面のドキュメントで説明しています。
- [POS 商品パネル](/1.x/pos/product-panel#display-settings)
- [カートパネル](/1.x/pos/cart#display-settings)
- [商品画面](/1.x/products#display-settings)
- [注文画面](/1.x/orders#display-settings)
- [顧客画面](/1.x/customers#display-settings)
- [レポート画面](/1.x/reports#display-settings)
