店舗設定は、POSの動作に影響するアプリ全体の設定です。個々の画面ではなく、店舗全体に適用されます。

## 店舗設定を開く {#accessing-store-settings}

店舗設定を開く方法は次のとおりです。

- 右上の**ユーザーメニュー**をクリックし、**設定**を選択します
- キーボードショートカット`Ctrl + Shift + S`を使用します

設定はポップアップウィンドウではなく**サイドパネル**で開くため、設定を調整しながら販売内容を確認できます。[店舗の健全性](/support/store-health)も同じ方法で開きます。

## 設定タブ {#settings-tabs}

店舗設定パネルには、次のタブがあります。

| タブ | 説明 |
|-----|-------------|
| [一般](./general.mdx) | 店舗情報、言語、通貨、デフォルト顧客 |
| [税](./tax.mdx) | 税額計算と表示オプション |
| [バーコード](./barcode.mdx) | バーコードスキャナーの設定 |
| [キーボードショートカット](./hotkeys.mdx) | 利用可能なキーボードショートカット |
| [テーマ](./theme.mdx) | 外観とカラースキーム |
| [プリンター](/hardware/printers) | レシートプリンターの接続と設定 |
