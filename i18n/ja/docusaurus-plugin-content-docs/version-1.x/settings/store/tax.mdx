:::warning 重要
初回読み込み時に、POSはWooCommerceからデフォルトの税設定を取得します。特別な必要がない限り、WooCommerceと同じ設定を使用してください。サーバーと異なる税設定を使用すると、POSとWooCommerceで異なる税額が計算される可能性が非常に高く、注文の同期時に不整合や問題が発生する可能性があります。
:::

## すべての税率を表示 {#view-all-tax-rates}

**すべての税率を表示**ボタンをクリックすると、POSにダウンロードされたすべての税率を確認できます。表示される内容:

- 税率名
- 税率（%）
- 適用対象の地域/場所

正しい税率が読み込まれていることの確認や、税額計算に関する問題のデバッグに役立ちます。

## 税額計算の設定 {#tax-calculation-settings}

### 税込価格の入力 {#prices-entered-with-tax}

商品価格に税が含まれるかどうかを指定します。

| オプション | 説明 |
|--------|-------------|
| **はい** | 商品価格に税が含まれます。POSは合計金額から逆算して税額を計算します |
| **いいえ** | 商品価格に税は含まれません。POSは入力した価格に税を加算します |

自動税計算を有効にして[WooCommerce Tax](/integrations/woocommerce-tax)を使用している店舗では、WooCommerceにより **いいえ** に固定されるため、POSもそれに合わせる必要があります。

### 税額計算の基準 {#calculate-tax-based-on}

税額計算に使用する住所を指定します。

| オプション | 説明 |
|--------|-------------|
| **顧客の配送先住所** | 注文の配送先に基づく税率 |
| **顧客の請求先住所** | 顧客の請求先住所に基づく税率 |
| **店舗の基本住所** | 店舗の実際の所在地に基づく税率 |

自動税計算を有効にして [WooCommerce Tax](/integrations/woocommerce-tax) を使用している店舗では、WooCommerce により顧客の配送先住所に固定されます。ここで別の選択肢を指定しても、POS と店舗の両方で POS 注文には引き続き適用されます。

### 配送の税区分 {#shipping-tax-class}

配送料への課税方法を決定します:

| オプション | 説明 |
|--------|-------------|
| **カートの商品に基づく配送の税区分** | カート内の商品の税区分に基づいて配送料の税額が計算されます |
| **標準** | 配送料には標準税率で課税されます |
| **軽減税率** | 配送料には軽減税率で課税されます |
| **ゼロ税率** | 配送料には税金が適用されません |

### 端数処理 {#rounding}

| オプション | 説明 |
|--------|-------------|
| **小計レベルで税を丸める** | 各明細行ごとに税を丸めるのではなく、小計全体に対して税を計算してから丸めます |

WCPOS は WooCommerce の税計算に従うため、レジで入力した注文でもウェブサイトで行われた注文でも、注文合計は同じになります。

- **完全精度** — 明細と注文の合計は完全精度で保持され、表示時にのみ丸められます。そのため、注文に保存される金額は、表示用の小数桁数にあらかじめ丸められた値ではなく、WooCommerce が想定する正確な値になります。
- **店舗での端数処理** — 通貨の小数点以下の精度を使用して丸めを行い、上記の **小計レベルで税を丸める** 設定に従います。
- **複合税** — 税率が *compound* として指定されている場合、税率は WooCommerce の優先順位 (`tax_rate_priority`) に従って適用されます。そのため、別の税に上乗せされる税は後から計算されます。

## 表示設定 {#display-settings}

### ショップでの価格表示 {#display-prices-in-the-shop}

| オプション | 説明 |
|--------|-------------|
| **税込** | 表示価格に税額が含まれます |
| **税抜** | 表示価格に税額は含まれません |

### カートとチェックアウト時の価格表示 {#display-prices-during-cart-and-checkout}

| オプション | 説明 |
|--------|-------------|
| **税込** | カートとチェックアウトの価格に税金を含める |
| **税抜** | カートとチェックアウトの価格に税金を含めない |

### 価格表示の接尾辞 {#price-display-suffix}

税の扱いを示すために価格の後に表示されるテキスト（例：「税込」または「税抜」）。

### 税額合計の表示 {#display-tax-totals}

| オプション | 説明 |
|--------|-------------|
| **単一の合計として** | すべての税金を1つの合計行にまとめる |
| **項目別** | 各税率を個別の明細行として表示する |

## サーバー設定を復元 {#restore-server-settings}

クリックすると、サーバーから現在のWooCommerce税設定を取得して適用します。

:::tip 使用方法と使用するタイミング
税設定の信頼できる情報源はWooCommerceであり、POSはそれを反映する必要があります。**サーバー設定を復元** は、店舗から最新の設定を安全に取得する方法です。`WP Admin > WooCommerce > 設定 > Tax` で税設定を変更し、POSに反映させたい場合は、この操作を行ってください。

ただし、慎重に判断すべき場合があります。サーバーと異なるPOS側の税設定を **意図的に** 上書きしている場合（高度な設定）、サーバー設定を復元するとその上書きは消去されます。上書きしたかどうか不明な場合は、ほぼ間違いなく上書きしていません。
:::

## よくある問題 {#common-issues}

### POSとWooCommerceで合計額が異なる {#pos-and-woocommerce-showing-different-totals}

最も頻繁に発生する税の問題は、POSの税設定とWooCommerceの税設定の不一致です。これらが異なると、同じ注文でも作成場所によって合計額が異なります。POSの設定は常に同期してください。`WP Admin > WooCommerce > 設定 > Tax` で何らかの変更を行った後は、**サーバー設定を復元** を使用します。

WooCommerce Taxを使用している店舗では、もう1つ確認すべき原因があります。それは、店舗でこれまで課税したことのない場所での最初の販売です。[WooCommerce Tax](/integrations/woocommerce-tax#what-to-expect)を参照してください。

### 税込価格設定に関する混乱 {#tax-inclusive-pricing-confusion}

「税込価格で入力」が **はい** に設定され、「ショップでの価格表示」が **税抜き** に設定されている場合、表示価格は入力価格より低くなります。これは正しい動作です。POSは表示用に税額分を除外しています。ただし、値札の価格が表示されることを想定しているレジ担当者には意外に感じられる場合があります。

### 顧客住所と税額計算 {#customer-address-and-tax-calculation}

「税金計算の基準」が **顧客の配送先住所** または **顧客の請求先住所** に設定されている場合、POSは正しい税率を取得するために有効な住所を必要とします。来店客の住所が登録されていない場合、WCPOSは計算に **ショップの基本住所** を使用します。これは通常、店頭販売では適切な動作ですが、特定の顧客で想定外の税率が表示される場合は、その顧客の住所詳細を確認してください。

## トラブルシューティング {#troubleshooting}

### 税額が正しくない {#tax-amounts-are-incorrect}

1. POS の **税金設定** に移動し、**サーバー設定を復元** をクリックして、WooCommerce から最新の設定を取得します。
2. **すべての税率を表示** をクリックし、想定どおりの税率が表示されることを確認します。税率がない場合は、`WP Admin > WooCommerce > 設定 > Tax > Standard rates` で正しく設定されていることを確認してください。[WooCommerce Tax](/integrations/woocommerce-tax) の自動税計算が有効な場合は、行を手動で追加しないでください。店舗で初めて販売が行われると、その場所の行が表示され、POS は次回の変更確認時に取得します。または、店舗の状態の **税率** 行にある **消去して再ダウンロード** を使用すると、すぐに取得できます。
3. 商品の税区分を確認してください。"ゼロ税率" の税区分に割り当てられた商品には、設定にかかわらず税金は適用されません。

### 税額がゼロと表示される {#tax-is-showing-as-zero}

- WooCommerce で税金が有効になっていることを確認してください (`WP Admin > WooCommerce > 設定 > General > Enable tax rates and calculations`).
- POS の **すべての税率を表示** を使用して、税率がダウンロードされていることを確認します。リストが空の場合は、完全同期を試してください。
- 商品の税ステータスが "課税対象" に設定されていることを確認してください（"なし" または "配送のみ" ではありません）。

### 端数処理の差異 {#rounding-discrepancies}

一方のシステムでは "小計レベルで税金を端数処理" が有効で、もう一方では無効の場合、POS と WooCommerce の間でわずかな端数の差異（数セント程度）が生じることがあります。この設定が両方で一致していることを確認してください。
