## 利用できるテーマ {#available-themes}

### システムテーマ {#system-theme}

- **説明**: デバイスの設定に合わせます
- **動作**: デバイスのシステム設定に基づき、ライトモードとダークモードを自動的に切り替えます

### ライトテーマ {#light-theme}

- **説明**: すっきりと明るい表示
- **おすすめ**: 明るい環境や、従来型の明るいインターフェースを好む方

### ダークテーマ {#dark-theme}

- **説明**: 目に優しい表示
- **おすすめ**: 暗い環境や、長時間使用時の目の疲れを軽減したい場合

### オーシャンテーマ {#ocean-theme}

- **説明**: 涼しげな青と青緑
- **おすすめ**: 落ち着いたプロフェッショナルな雰囲気を演出したい場合

### サンセットテーマ {#sunset-theme}

- **説明**: 温かみのあるオレンジと紫
- **おすすめ**: 居心地のよい、親しみやすい雰囲気を演出したい場合

### モノクロテーマ {#monochrome-theme}

- **説明**: コントラストの高いグレースケール
- **おすすめ**: アクセシビリティへの配慮や、高いコントラストが必要な環境

## テーマを選択する {#selecting-a-theme}

1. テーマ設定パネルには、利用できるテーマがカード形式で表示されます
2. 各テーマカードには、テーマ名と簡単な説明が表示されます
3. テーマカードをクリックして選択します
4. 現在有効なテーマは青い枠線で強調表示されます
5. 選択内容は自動的に保存され、すぐに適用されます

## テーマ選択のヒント {#tips-for-theme-selection}

| テーマ | おすすめの環境 |
|-------|------------------|
| **システム** | POSをデバイスに合わせて自動的に切り替えたい場合 |
| **ライト** | 照明が十分な明るい小売環境 |
| **ダーク** | 薄暗い環境や夕方・夜間のシフト |
| **オーシャン／サンセット** | 個性を加え、ブランドイメージに合わせたい場合 |
| **モノクロ** | 最大限のコントラストが必要な場合 |

選択したテーマは、すべてのPOSセッションで保持されます。
