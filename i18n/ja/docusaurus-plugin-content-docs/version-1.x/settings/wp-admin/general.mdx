## POS専用商品を有効化 {#enable-pos-only-products}

この設定により、商品に表示オプションが追加され、オンライン店舗、POS、またはその両方に表示するかを制御できます。

:::warning パフォーマンスへの影響
この設定は、オンライン店舗または POS で商品を非表示にする必要がある場合にのみ有効にしてください。有効にすると、すべての商品リクエストで追加のデータベース検索が発生します。
:::

商品ごとの表示設定や一括編集など、この機能の使い方について詳しくは、[POS専用商品](/1.x/products/pos-only-products)を参照してください。

## 小数数量を有効化 {#enable-decimal-quantities}

この設定により、顧客とスタッフは商品をカートに追加するときに小数数量を入力できます。

**小数数量の例:**
- 0.25（四分の一単位）
- 1.5（一単位半）
- 2.75（二と四分の三単位）

**次の用途に便利です:**
- 重量単位で販売する商品（例: コーヒー豆 0.5kg）
- 端数単位のサービス（例: 1.5時間のコンサルティング）
- 小分けで販売できるバルク商品

:::note 重量単位での販売
WCPOS は計量器への接続や、計量器からの重量の読み取りには対応していません。商品を計量し、カートの該当行の数量として重量を入力してください。キログラム単価の商品では、350 g は数量 `0.35` に相当します。この設定が無効のままだと店舗で小数数量を含む注文が拒否されるため、先に有効にしてください。

一部の計量器が印刷するバーコードラベルに記録された重量や価格も、WCPOS では読み取れません。
:::

## 注文削除時に在庫を復元 {#restore-stock-on-order-delete}

有効にすると、POS 注文がゴミ箱に移動または削除されたときに、WCPOS が商品の在庫を自動的に復元します。誤った販売をキャンセルすると、商品が在庫に戻ります。この設定は**デフォルトでオン**です。

別の方法で在庫を照合しており、POS 注文の削除によって在庫を調整したくない場合は、無効にしてください。

## 顧客のメールアドレスからユーザー名を自動生成 {#automatically-generate-username-from-customer-email}

有効にすると、WCPOS はチェックアウト時に、新規顧客のメールアドレスに基づいてユーザー名を自動生成します。これにより、顧客の作成手順が簡単になり、ユーザー名の形式も統一されます。

## デフォルトPOS顧客 {#default-pos-customer}

新しい POS 注文に割り当てるデフォルト顧客を選択します。主な選択肢は次のとおりです。

- **ゲスト**: 注文はどのユーザーアカウントにも関連付けられません
- **レジ係**: 注文はログイン中のレジ係のアカウントに関連付けられます
- **来店顧客**: 注文は特定の顧客アカウントに関連付けられます（事前にこのアカウントを作成する必要があります）

## レジ係アカウントを使用 {#use-cashier-account}

有効にすると、選択したデフォルトPOS顧客の代わりに、レジ係のユーザーアカウントが POS 注文のデフォルト顧客として使用されます。

## 顧客によるレシートのダウンロードを許可する {#storefront-receipts}

有効にすると、WCPOS はオンライン店舗の **マイアカウント → 注文** に **レシート** ボタンを追加します。顧客はこのボタンから、WCPOS のテンプレートで生成された自分の注文レシートを PDF としてダウンロードできます。この設定は**デフォルトでオフ**です。

切り替えスイッチの下にある**顧客向けレシートテンプレート**のドロップダウンで、顧客に提供するテンプレートを選択します。デフォルトは**有効なレシートテンプレートを使用**で、POS と同じテンプレートが使われます。オンライン注文に異なるデザイン（たとえばページ全体を使った請求書）を使うには、特定のテンプレートを選択してください。

対象となる注文ステータス、`[wcpos_receipt]` ショートコード、開発者向けフィルターを含む詳しいガイドは、[オンラインストアのレシート](/1.x/receipts/storefront)を参照してください。

## バーコードフィールド {#barcode-field}

この設定では、バーコードをスキャンするときやバーコード検索機能を使うときに、WCPOS が検索する商品フィールドを指定します。

<a id="default-option"></a>

:::note デフォルトのメタキー
WooCommerce 9.2（2024年8月）で導入された、WooCommerce のグローバル一意IDフィールド **`_global_unique_id`** を使用してください。GTIN、UPC、EAN、ISBN コードの保存用に設計されており、新規インストールで推奨される選択肢です。グローバル一意IDフィールドを使わない場合は、**`_sku`**（商品 SKU／在庫管理単位フィールド）が適切な代替になります。
:::

### 一般的なプラグイン → メタキー {#common-plugins-meta-key}

バーコード管理プラグインを使っている場合は、代わりにそのプラグイン固有のメタキーを使う必要があることがあります。

| プラグイン／フィールドの種類 | メタキー |
|---|---|
| WooCommerce のグローバル一意ID *（デフォルト、推奨）* | `_global_unique_id` |
| 商品 SKU *（代替）* | `_sku` |
| EAN プラグイン（欧州商品番号） | `_ean`, `_ean13`, `_ean8` |
| EAN for WooCommerce（WPFactory の EAN Barcode Generator） | `_alg_ean`（高度な設定で **メタキー** を変更している場合を除く） |
| UPC プラグイン（共通商品コード） | `_upc`, `_upc_code` |
| GTIN プラグイン（国際商品識別番号） | `_gtin`, `_gtin13`, `_gtin14` |
| 汎用バーコードフィールド | `_barcode`, `_product_barcode` |
| WooCommerce Product Barcodes | `_barcode_text` |
| ATUM Inventory | `_atum_barcode` |

<a id="custom-meta-keys"></a>

:::tip カスタムメタキー
バーコードデータを保存する**任意の**カスタムメタキーを使用できます。このフィールドにメタキー名を入力するだけです。先頭にアンダースコアがある場合は、それも含めて入力してください。
:::

### プラグインのメタキーを確認する {#finding-your-plugins-meta-key}

使用しているプラグインが上記にない場合は、次の手順で正しいメタキーを確認してください。

<Steps>
  <StepCard number="1" title="商品にバーコードを追加する">

WP Admin で商品を編集し、プラグインを使ってバーコードを追加します。

  </StepCard>
  <StepCard number="2" title="プラグインのドキュメントを確認する">

プラグインのドキュメントで、使用されているメタキー名を確認します。

  </StepCard>
  <StepCard number="3" title="またはデータベースを確認する" isLast>

データベースの `wp_postmeta` テーブルを調べ、商品に対してどのメタキーが作成されたかを確認します。

  </StepCard>
</Steps>

:::note この設定を変更するとバーコードインデックスが再構築されます
バーコードフィールドを変更すると、WCPOS はローカルカタログのバーコードインデックスを再構築し、新しく選択したフィールドでスキャン結果を照合します。商品を手動で消去して再ダウンロードする必要はありません。

それでもスキャン結果が一致しない場合は、完全更新を実行できます。商品画面に移動し、画面下部の同期アイコン（↻）を**長押し**して、**「クリアして更新」** を選択します。その後、スキャンを試して、新しいフィールドが使われていることを確認してください。
:::

## プライバシー {#privacy}

**匿名の使用状況データを許可**の切り替えスイッチで、製品改善のために WCPOS が匿名の使用状況分析データを収集するかどうかを設定します。収集への同意と拒否を自由に選択でき、顧客データ、価格、店舗住所が収集されることはありません。設定の横にある **詳細を見る** リンクで、収集する情報と収集しない情報を具体的に確認できます。

## 店舗税 ID {#store-tax-ids}

WCPOS が POS レシートや請求書に印刷する事業者の税務識別番号（VAT 番号、ABN、GSTIN、EIN、各地域の会社登録番号など）を追加します。WooCommerce にはこれらのフィールドが標準では用意されておらず、多くの地域では複数の番号が必要です。

詳しいガイドは、[店舗の税務ID](/1.x/settings/wp-admin/store-tax-ids)を参照してください。

## 顧客の税務ID {#customer-tax-ids}

WCPOS は顧客情報に税務IDフィールドを保持し、購入手続き時にその値を注文にコピーします。プラグインによってこのフィールドの保存名が異なるため、WCPOS はインストールされているプラグインを検出し、適切なフィールドに自動的に書き込みます。必要に応じて、この**税務ID**セクションでフィールド名を上書きすることもできます。

詳しいガイドは、[顧客の税務ID](/1.x/settings/wp-admin/customer-tax-ids)を参照してください。
