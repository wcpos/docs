これらの設定では、PHP と WooCommerce の構成を含む POS アプリケーションのバックエンド機能を構成します。`WP Admin > POS > 設定` に移動してアクセスできます。

## 設定の概要 {#settings-at-a-glance}

| 設定 | 機能 | 詳細 |
|---|---|---|
| **一般** | すべてのレジ係に対するデフォルトのカート顧客、POS 専用商品、小数数量、商品バーコードフィールド。 | [一般設定](./general.mdx) |
| **レジ** | POS で利用可能な決済ゲートウェイと、POS 注文の処理方法。 | [レジ設定](./checkout.mdx) |
| **メール通知** | メールごとの管理者、顧客、レジ係向けの切り替えで、POS 注文に対して送信する WooCommerce メールを制御します。 | [メール通知](./email-notifications.mdx) |
| **アクセス** | 専用のレジ係権限グループを含む、POS を利用できるユーザーの権限グループと権限。 | [POS へのアクセス](./access.mdx) |
| **セッション** | ユーザーおよびデバイスごとのアクティブな POS ログインセッションを表示し、デバイスをリモートでサインアウトさせます。 | [セッション](./sessions.mdx) |
| **店舗税務 ID** | レシートや請求書に印刷される事業者の税務識別番号（VAT、ABN、GSTIN、EIN、会社登録番号）。 | [店舗税務 ID](./store-tax-ids.mdx) |
| **顧客税務 ID** | 顧客税務 ID の保存方法、書き込み先となるプラグインのフィールド、チェックアウト時に注文へコピーされる仕組み。 | [顧客税務 ID](./customer-tax-ids.mdx) |
