WCPOS は顧客に税務IDフィールドを保持します。VAT 番号、ABN、CPF、GSTIN、NIF など、請求書に購入者の税務識別番号を記載する必要がある B2B 取引向けのフィールドです。顧客の注文が作成されると、WCPOS は顧客の税務IDを注文にコピーし、レシートに印刷できるようにします。

**WP Admin > POS > 設定 > 一般** の **税務ID** セクションで、このフィールドの検出方法と保存方法を設定します。

## プラグインとフィールド名 {#plugins-and-field-names}

多くの WooCommerce プラグインは顧客に VAT や税番号のフィールドを追加しますが、それぞれ異なるデータベースのフィールド名（メタキー）を使用しています。既存の顧客データを移行せずに使い続けられるよう、WCPOS はインストール済みのプラグインを検出し、適切なフィールドに自動的に書き込みます。

WCPOS は次の優先順位でフィールド名を決定します。

1. **対応プラグインが有効な場合** — WCPOS はそのプラグインのフィールドに書き込みます。検出対象には次のプラグインが含まれます。
   - WooCommerce EU VAT Number
   - Aelia EU VAT Assistant（検証ステータスを含む）
   - EU VAT for WooCommerce (WPFactory)
   - WooCommerce Germanized / Germanized Pro
   - Brazilian Market on WooCommerce / Extra Checkout Fields for Brazil
   - NIF/CIF Spain
2. **対応プラグインがない場合** — WCPOS は最近の注文を調べ、すでに使用されている VAT/CPF などのフィールドを検出して、そこに書き込みます。
3. **何も見つからない場合** — WCPOS は適切なデフォルト値を使用します（VAT 形式の ID には `_billing_vat_number`、ブラジルには `_billing_cpf` / `_billing_cnpj`、インドには `_billing_gstin` など）。

### フィールド名を手動で指定する {#choosing-the-field-name-yourself}

検出されたフィールド名を上書きするには、**WP Admin > POS > 設定 > 一般** に移動し、**税務ID** セクションを開いて、**詳細設定：別のフィールド名を使用** を展開します。

バナーには自動検出されたプラグイン名が表示されます。プラグインが検出されず、組み込みのデフォルト値を使用している場合は「プラグインが検出されませんでした」と表示されます。上書き用の入力欄には、他のプラグインでよく使われるメタキーを入力に応じて候補表示する機能があります。入力欄を空にすると上書きが解除され、自動で決定されたフィールド名に戻ります。

:::note
このエディターには、顧客向けの税IDの種類のみが表示されます。ドイツの USt-IdNr. やオランダの KVK 番号などの法人登記識別子は店舗レベルのフィールドです。[店舗税ID](/1.x/settings/wp-admin/store-tax-ids)をご覧ください。
:::

## 税務番号は注文にコピーされます {#tax-ids-are-copied-onto-orders}

注文が作成されると、顧客の税務番号が注文に **スナップショットとして保存** されます。注文には販売時点で登録されていた値が保持されます。

- 後から顧客の税務番号を編集しても、過去の注文は **変更されません**。
- チェックアウト時にレジ係が入力した税務番号は、その注文に限り顧客レコードの値を上書きします。
- 既存の注文を編集した場合、更新内容に税務番号が明示的に含まれているときにのみ変更されます。WCPOS が顧客レコードから再コピーすることはありません。

これにより、顧客情報が変更された後も過去の請求書の正確性が保たれます。

## 対応する種類 {#supported-types}

EU VAT、GB VAT、SA VAT、オーストラリアの ABN、ブラジルの CPF / CNPJ、インドの GSTIN、イタリアの Codice Fiscale と Partita IVA、スペインの NIF、アルゼンチンの CUIT、カナダの GST/HST、米国の EIN に対応しています。その他の番号には汎用の **税務番号** を使用できます。

## 税務番号による顧客検索 {#finding-customers-by-tax-id}

POS の顧客検索では、旧プラグインのフィールド名も含めて税務番号の値が検索対象になるため、レジ係は VAT 番号、CPF、NIF で顧客を検索できます。

## レシートでの表示 {#on-receipts}

顧客の税務番号は、顧客情報を表示するレシートに、種類に応じた適切なローカライズ済みラベルとともに表示されます。VAT 番号には国コードが先頭に付きます（例：`DE123456789`）。
