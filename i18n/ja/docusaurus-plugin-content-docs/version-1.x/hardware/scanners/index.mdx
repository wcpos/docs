WCPOS は、すべてのプラットフォームでバーコードをスキャンできます。デバイスの**カメラ**、一般的な**キーボードモード**のスキャナー、USB または Bluetooth スキャナーへの**直接接続**に対応しています。ほとんどのスキャナーは、接続またはペアリングすればすぐに使えます。以下のページでは、設定手順、レジでのスキャンの動作、検出の微調整方法を説明します。

## スキャンの方法 {#ways-to-scan}

- **カメラ** — Web、デスクトップ、iOS、Android で利用できます。検索バーのスキャンアイコンからカメラを開きます。フィルターの下にサイズ変更可能なパネルとして表示されるため、商品一覧を見ながら使えます。追加のハードウェアは不要です。
- **キーボードモード（HID）** — ほぼすべてのスキャナーの工場出荷時の設定です。スキャナーがバーコードを「入力」し、WCPOS がその高速なキー入力を認識します。設定は不要で、接続またはペアリングしてスキャンするだけです。
- **直接接続** — シリアルモードまたは POS モードに切り替えたスキャナー向けです。USB シリアルと HID-POS（ブラウザーの Web Serial および WebHID を使用）、Bluetooth SPP、メーカーの GATT サービスを介した Bluetooth LE に対応しています。直接接続では、入力速度、キーボードレイアウト、フォーカスのあるフィールドに関係なく、すべてのスキャン結果を WCPOS に直接送信します。デスクトップアプリと Chrome ベースのブラウザーで利用でき、デスクトップアプリではアプリ内にデバイス選択画面が表示されます。

:::note どのフィールドがバーコードですか？
WCPOS は、スキャン結果を設定済みの単一のバーコードフィールドと照合します。デフォルトは WooCommerce の GTIN フィールド(`_global_unique_id`)です。[設定](/1.x/settings/wp-admin/general#barcode-field)で `_sku` または任意のカスタムメタキーを指定できます。変更すると、ローカルのバーコードインデックスが自動的に再構築されます。
:::
