**症状：** レシートが一枚印刷された後、何も印刷されません。アプリには *「プリンターの電源を切ってから入れ直し、もう一度お試しください。」* と表示されます。プリンターは正常に見えます。準備完了ランプが点灯し、用紙も入っており、パネルからのセルフテストも印刷できます。

## まず電源を入れ直す {#power-cycle-first}

プリンターの電源プラグを抜き、十秒数えてから差し込み、準備完了ランプが点灯するまで待ちます。その後、テストページを印刷します。

設定を変更する前に、この手順を実行してください。プリンターの処理が止まっているのか、設定が誤っているのかを最も手早く見分けられます。また、以下のケースではこれだけで問題が解消します。

## 原因 {#why-it-happens}

Epson プリンターは、印刷しないジョブでも受け付けることがあります。多くの場合、プリンターがブロックするよう設定されている通信チャネルから届いたジョブです。ジョブを拒否せず、**保留** します。ジョブを保留している間は、どのチャネルからも印刷できず、次のレシートもアプリのテストページも出力されません。保留は数分後に自動解除されますが、プリンターを再起動すればすぐに解除されます。

プリンターが正常に見えるのに動かないのも、原因を調べている最中に同じプリンターがまた動き出すのも、このためです。

## 再発する場合 {#if-it-comes-back}

電源の入れ直しは症状への対処です。繰り返し発生する場合は、何かがブロックされたチャネルにジョブを送り続けています。

- [セキュア印刷](/1.x/hardware/printers/secure-printing)を確認してください。2025 年半ば以降に購入したプリンターでは、これがよくある原因です。
- プリンターの Web ページは開くのに何も印刷されない場合は、[サーバーダイレクト印刷](/1.x/hardware/printers/server-direct-print)を確認してください。

プリンターのスキャンでも保留が発生することがあります。そのため、**プリンターを追加** をタップした直後にプリンターが応答しなくなる場合も、同じ問題が起きています。

## それでも解決しない場合 {#still-stuck}

トラブル画面で **セットアップレポートをコピー** を使い、メッセージに貼り付けてください。
