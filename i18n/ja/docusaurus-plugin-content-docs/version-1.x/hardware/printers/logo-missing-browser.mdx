**症状：** ブラウザーのタブから印刷したレシートが、店舗のロゴだけを除いて完全な状態で出てくる。同じレシートをデスクトップアプリやモバイルアプリから印刷すると、ロゴも通常どおり印刷される。

## 原因 {#why-it-happens}

ロゴは WordPress のメディアライブラリにあり、ブラウザーはそこから読み込みます。Web ページが別のアドレスから読み込んだ画像のピクセルを読み取るには、その画像を配信するサーバーが `Access-Control-Allow-Origin` というヘッダーで許可を示す必要があります。WordPress は既定ではアップロードファイルにこのヘッダーを付けないため、ブラウザーは画像を表示用には渡しても、印刷用には渡しません。

アプリ側で回避することはできません。会計を失敗させるよりはと、ロゴなしでレシートを印刷します。デスクトップアプリとモバイルアプリはファイルを自分で取得するため、このルールの対象外です。

## 対処方法 {#do-this}

店舗に合うほうを選んでください。

- **デスクトップアプリから印刷する。** 設定は不要で、レジにすでにインストールされているなら最も手早い方法です。
- **サイト側でヘッダーを許可する。** サイトの管理担当者が、Web サーバーの設定または CORS ヘッダーを設定するプラグインで、アップロードディレクトリに `Access-Control-Allow-Origin` を追加します。その後 POS を再読み込みして、もう一度印刷してください。

## ロゴがノイズとして印刷される場合 {#if-the-logo-prints-as-noise}

ロゴの代わりにランダムな点の帯が出るのは別の問題です。古い機種や安価なプリンターの一部は、使われている画像形式をデコードできません。そのプリンターのレシートテンプレートからロゴを削除してください。

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、ロゴ画像のアドレスを添えてメッセージに貼り付けてください。
