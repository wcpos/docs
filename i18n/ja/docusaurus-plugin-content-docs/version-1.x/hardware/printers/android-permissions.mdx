**症状：** Android のスマートフォンやタブレットで、スキャンしても何も見つからない、Bluetooth プリンターが選択画面に一向に出てこない、またはアドレスが分かっているプリンターがタイムアウトする。

## 原因 {#why-it-happens}

Android はこれらの権限を個別に管理しており、拒否されても通知はありません。接続がブロックされた状態は、電源が入っていないプリンターとまったく同じようにタイムアウトします。

- **付近のデバイス**は、Bluetooth プリンターの検出と接続に関わります。
- **ローカルネットワーク**へのアクセスは、最近の Android では、アプリが Wi-Fi 上の機器に接続する前に必要です。

## 権限をオンにする {#turn-the-permissions-on}

1. Android の **設定 → アプリ → WCPOS → 権限** を開きます。
2. **付近のデバイス**を許可します。
3. **ローカルネットワーク**の項目があれば、それも許可します。古い Android にはこの項目がありません。
4. アプリを終了してから開き直し、スキャンします。

## Bluetooth プリンター {#bluetooth-printers}

Android では、Epson と Star のプリンターはメーカー自身のソフトウェアを介して接続するため、**先に Android 側でペアリング**する必要があります（**設定 → 接続済みのデバイス → 新しいデバイスとペア設定**）。ペアリングしないとアプリに表示されません。小型の Bluetooth Low Energy プリンターは、代わりにアプリ内の選択画面で選びます。こちらは Android 側でペアリングしないでください。[Bluetooth レシートプリンターをペアリングする](/hardware/printers/bluetooth-pairing)をご覧ください。

## Wi-Fi プリンター {#wi-fi-printers}

タブレットがモバイルデータやゲストネットワークではなく、店舗の Wi-Fi につながっているか確認してください。スキャンで何も見つからなくてもプリンターのアドレスが分かっている場合は、**IP アドレスを入力**を使ってください。指定した 1 つのアドレスを直接確認するので、検出のしくみに依存しません。

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。
