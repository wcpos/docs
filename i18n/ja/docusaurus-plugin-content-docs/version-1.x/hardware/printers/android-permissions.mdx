**症状：** Androidのスマートフォンやタブレットで、スキャンしても何も見つからない、Bluetoothプリンターが選択画面に表示されない、またはアドレスが分かっているプリンターへの接続がタイムアウトします。

## 原因 {#why-it-happens}

Androidはこれらの権限を個別に管理しており、拒否されても通知はありません。接続がブロックされると、電源が入っていないプリンターと同じようにタイムアウトします。

- **付近のデバイス**は、Bluetoothプリンターの検出と接続に関わります。
- 最近のAndroidでは、アプリがWi-Fi上の機器に接続するには、**ローカルネットワーク**へのアクセス許可が必要です。

## 権限をオンにする {#turn-the-permissions-on}

1. Androidの**設定 → アプリ → WCPOS → 権限**を開きます。
2. **付近のデバイス**を許可します。
3. **ローカルネットワーク**の項目があれば、それも許可します。古いAndroidにはこの項目がありません。
4. アプリを終了してから開き直し、スキャンします。

## Bluetoothプリンター {#bluetooth-printers}

Androidでは、EpsonとStarのプリンターはメーカー独自のソフトウェアを介して接続するため、**先にAndroid側でペアリング**する必要があります。**設定 → 接続済みのデバイス → 新しいデバイスとペア設定**でペアリングすると、アプリに表示されます。小型のBluetooth Low Energyプリンターは、代わりにアプリ内の選択画面で選びます。こちらはAndroid側でペアリングしないでください。[Bluetoothレシートプリンターをペアリングする](/1.x/hardware/printers/bluetooth-pairing)をご覧ください。

## Wi-Fiプリンター {#wi-fi-printers}

タブレットがモバイルデータ通信やゲストネットワークではなく、店舗のWi-Fiに接続されていることを確認してください。スキャン結果が空でもプリンターのアドレスが分かっている場合は、**IP アドレスを入力**を使用してください。自動検出に依存せず、指定したアドレスを直接確認できます。

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。
