**症状：** POS をブラウザーで使っていて、プリンターに接続できない。スキャンしても何も見つからない、または同じプリンターがデスクトップアプリでは印刷できるのにブラウザーのタブからは印刷できない。

## ローカルネットワークへのアクセスを許可する {#allow-local-network-access}

Chrome と Edge は、Web サイトがネットワーク上の機器と通信する前に許可を求めます。この確認を閉じてしまうと、以降はすべての試行が何の通知もなく失敗します。

アドレスバー左端のアイコン →**サイトの設定**の順にクリックし、**ローカルネットワーク**を**許可**に設定します。その後ページを再読み込みして、もう一度スキャンしてください。

## 混在コンテンツ {#mixed-content}

`https://` で配信されている POS は、プリンターへの暗号化されていない `http://` 接続を開けません。Chrome と Edge では、ローカルネットワークへのアクセスを許可すれば利用できますが、他のブラウザーは完全にブロックします。店舗が HTTPS で動作していて、プリンターが HTTP にしか対応していない場合は、デスクトップアプリを使ってください。

## プリンターの証明書 {#the-printers-certificate}

プリンターは自身の証明書で通信を保護しますが、この証明書はどのブラウザーも既定では信頼しないため、接続は始まる前に失敗します。同じブラウザーで一度 `https://printer-ip` を開き、警告を承認してから POS に戻ってください。これはパソコンごとに必要です。

デスクトップアプリにはこの問題がありません。プリンターの証明書を自身で受け入れるため、同じプリンターがアプリでは動作し、タブでは動作しないのです。

## Safari と Firefox {#safari-and-firefox}

どちらにもこれらの手段がありません。許可すべきローカルネットワークの権限そのものがなく、Web ページから USB や Bluetooth のプリンターを使うこともできません。これらのブラウザーでは、店舗の HTTP／HTTPS に合った Wi-Fi プリンターを使うか、デスクトップアプリを使ってください。

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。どのブラウザーで、どの接続方法を試したかが記録されています。
