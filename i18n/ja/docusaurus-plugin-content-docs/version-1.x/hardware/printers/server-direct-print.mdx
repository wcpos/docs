**症状：** プリンター自身の Web ページは開き、パネルからのセルフテストも印刷され、セキュア印刷もすでに無効になっている。それでも POS からのジョブはすべて失敗するかタイムアウトする。電源を入れ直しても何も変わらない。

## 原因 {#why-it-happens}

Epson プリンターには、**Server Direct Print** と呼ばれる機能で、サーバーから自分でジョブを取得するよう設定できます。関連機能の **ePOS-Device** では、1 つのアプリケーションがセッション中プリンターを占有できます。どちらも印刷エンジンを占有するため、占有中はプリンターがほかのすべてのジョブをビジー状態として拒否しますが、そのことは通知されません。プリンターに保存された設定なので、再起動しても解除されません。

たいていは、以前の導入作業、キッチンプリンターのサービス、別のレジによって有効なまま残されたものです。

## 無効にする {#turn-it-off}

1. ブラウザーで `https://printer-ip` を開き、証明書の警告を承認します。
2. **管理者ログイン**を行います。パスワードは、誰かが変更していなければ、プリンター底面のラベルに記載されたシリアル番号です。
3. **Server Direct Print**（ファームウェアによって、プリンターのサービスまたは印刷設定の下にあります）を探し、**無効**に設定します。
4. 同じ画面で、他に使っているものがなければ **ePOS-Device** も無効になっているか確認します。
5. 確定したら、プリンターの電源コードを抜いて 10 秒待ち、再び差し込みます。
6. もう一度テストページを印刷します。

:::note 他のシステムが使っている可能性があります
キッチンディスプレイやオンライン注文サービスなど、別のシステムが実際に Server Direct Print で印刷している場合、プリンターを所有できるのはどちらか一方だけです。そのシステムの送信先を変更するか、POS 専用のプリンターを用意してください。
:::

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。各ポートでプリンターがどう応答したかが記録されています。
