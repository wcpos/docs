**症状：** iPad や iPhone でスキャンしても何も見つからない、または正しいと分かっているアドレスのプリンターが単にタイムアウトする。同じ Wi-Fi 上のパソコンからは同じプリンターで印刷できる。

## 原因 {#why-it-happens}

iOS は初回利用時に一度だけ、アプリがローカルネットワーク上の機器と通信してよいかを尋ねます。この確認を拒否した場合、あるいは別の人が答えた場合や、そもそも表示されなかった場合、それ以降すべてのスキャンと印刷がブロックされます。iOS はアプリにエラーを返さないため、電源が入っていないプリンターと見分けがつきません。

## 権限をオンにする {#turn-the-permission-on}

1. iPad または iPhone の**設定**アプリを開きます。
2. **プライバシーとセキュリティ → ローカルネットワーク**に移動します。
3. **WCPOS** のスイッチをオンにします。
4. アプリを完全に終了し（App スイッチャーから上へスワイプします）、もう一度開きます。

その後、**設定 → 印刷 → プリンターを追加**からもう一度スキャンしてください。

## あわせて確認すること {#also-check}

- iPad が**店舗の Wi-Fi** につながっていること。ゲストネットワークやモバイルデータではいけません。[プリンターに固定アドレスを割り当てる](/hardware/printers/network-address)をご覧ください。
- Wi-Fi がオンであること。Wi-Fi がオフだと、権限をどう設定してもローカルアドレスのプリンターには接続できません。

## スキャンでは見つからないのにプリンターは動いている場合 {#if-the-scan-finds-nothing}

スキャンはプリンターが自分の存在を知らせることを前提にしていますが、これをブロックするネットワークもあります。代わりに **IP アドレスを入力**を使ってください。スキャンを止めて、その 1 つのアドレスを直接確認します。アドレスはプリンターのステータスシートを印刷すると分かります。

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。iPad が何を試し、どんな応答が返ってきたかが記録されています。
