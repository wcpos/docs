**症状：** iPad や iPhone でスキャンしても何も見つからない、または正しいと分かっているアドレスのプリンターがタイムアウトします。同じ Wi-Fi 上のパソコンからは、そのプリンターで印刷できます。

## 原因 {#why-it-happens}

iOS は初回利用時に一度だけ、アプリがローカルネットワーク上の機器と通信してよいかを尋ねます。この確認を拒否した場合、別の人が回答した場合、または確認自体が表示されなかった場合、それ以降すべてのスキャンと印刷がブロックされます。iOS はその旨のエラーをアプリに返さないため、プリンターの電源が入っていない場合と見分けがつきません。

## 権限をオンにする {#turn-the-permission-on}

1. iPad または iPhone の **設定** アプリを開きます。
2. **プライバシーとセキュリティ → ローカルネットワーク** を開きます。
3. **WCPOS** のスイッチをオンにします。
4. アプリを完全に終了し（App スイッチャーで上へスワイプします）、もう一度開きます。

その後、**設定 → 印刷 → プリンターを追加** を開き、もう一度スキャンします。

## あわせて確認すること {#also-check}

- iPad がゲストネットワークやモバイルデータ通信ではなく、**店舗の Wi-Fi** に接続されていることを確認します。[プリンターに固定アドレスを割り当てる](/1.x/hardware/printers/network-address)をご覧ください。
- Wi-Fi がオンになっていることを確認します。Wi-Fi がオフだと、権限の設定にかかわらず、ローカルアドレスのプリンターには接続できません。

## スキャンでは見つからないのにプリンターは動いている場合 {#if-the-scan-finds-nothing}

スキャンはプリンターが自身の存在を通知する仕組みに依存していますが、一部のネットワークではこの通知がブロックされます。その場合は **IP アドレスを入力** を使用してください。スキャンを停止し、指定したアドレスを直接確認します。アドレスは、プリンターのステータスシートを印刷して確認できます。

## それでも解決しない場合 {#still-stuck}

トラブル画面で **セットアップレポートをコピー** を使い、メッセージに貼り付けてください。iPad が試した内容と、返ってきた応答が記録されています。
