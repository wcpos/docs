:::

## プラットフォーム別の対応プリンター {#supported-printers-by-platform}

**プリンターを追加**フォームは、使用中のアプリに応じて変化します。各プラットフォームでは、実際に使用できる接続方法とオプションのみが表示されます。

| プラットフォーム | 対応プリンター | 接続方法 |
|----------|--------------------|-------------|
| **Web アプリ** | Web サーバー内蔵の Epson および Star プリンター（ネットワーク）、WebUSB 経由の大半の ESC/POS プリンター（USB）、Web Bluetooth 経由の Bluetooth Low Energy（BLE）プリンター（USB/Bluetooth は Chrome/Edge のみ） | ネットワーク（HTTP）、USB、Bluetooth |
| **デスクトップアプリ** | 任意のネットワークレシートプリンター | ネットワーク（raw TCP）、USB、Bluetooth |
| **iOS アプリ** | Epson および Star | ネットワーク、Bluetooth |
| **Android アプリ** | Epson および Star | ネットワーク、Bluetooth、USB |

:::info Web ではネットワーク経由で Epson と Star のみ対応している理由
Web ブラウザーでは raw TCP 接続を開くことができません。Epson および Star のレシートプリンターには、HTTP 経由で印刷ジョブを受け付ける Web サーバーが内蔵されています。これは、ブラウザーから*ネットワーク*プリンターに ESC/POS コマンドを送信する唯一の方法です。デスクトップアプリには TCP 経由で直接接続できるため、この制限はありません。

ブラウザーでの USB および Bluetooth 印刷にも対応していますが、利用できるのは **Chrome または Microsoft Edge** のみです（WebUSB API および Web Bluetooth API を使用します）。Safari と Firefox は対応していません。**USB** 経由では Epson および Star に限定されず、ブラウザーのデバイス選択画面に表示される大半の ESC/POS プリンターで印刷できます。**Bluetooth** 経由ではプリンターの Bluetooth タイプが重要です。ブラウザーから接続できるのは **Bluetooth Low Energy（BLE）** プリンターのみで、クラシック Bluetooth モデル（大半の Bluetooth 対応 Epson および Star プリンターを含む）にはブラウザーから接続できません。

**モバイルアプリ**では、Bluetooth および USB 印刷に Epson と Star の公式 SDK を使用するため、これらの接続には Epson または Star のプリンターが必要です。汎用プリンターはネットワーク経由でのみ使用できます。
:::

## プリンターを追加する {#adding-a-printer}

<Steps>
  <StepCard number="1" title="プリンター設定を開く">

**POS > 設定 > 印刷** に移動します。プリンターがまだ設定されていない場合は、**プリンターを追加** ボタンがある空の画面が表示されます。各プリンターには **プリンター名** が設定されます。これはプリンターを区別するためのラベルで、初期値は「レシートプリンター」（以降は「レシートプリンター 2」など）です。分かりやすい名前に変更できます。

  </StepCard>
  <StepCard number="2" title="プリンターの接続方法を選択">

すべてのプラットフォームで、まず **接続タイプ** を選択します。表示されるのは、そのプラットフォームで対応しているオプションのみです。下の項目は選択内容に合わせて更新されます。

- **Web アプリ** — **ネットワーク**、**USB**、または **Bluetooth**（USB と Bluetooth には Chrome または Edge が必要です）。**ネットワーク** プリンターでは、ブラウザーが各ブランドに組み込まれた Web サーバーを介してネットワークプリンターに接続するため、**メーカー** として Epson または Star を選択します。
- **デスクトップアプリ** — **ネットワーク**、**USB**、または **Bluetooth**。
- **モバイルアプリ** — **ネットワーク** または **Bluetooth**。Android では **USB** も利用できます（iOS は USB に対応していません）。

</StepCard>
  <StepCard number="3" title="プリンターを識別">

**ネットワークプリンター** — **IP アドレス** を入力します（例: `192.168.1.100`）。WCPOS はこのアドレスを確認して Epson または Star のデバイスかどうかを検出し、ポート、コマンド言語、メーカーを自動入力します。検出が完了すると、「検出済み: Epson」または「検出済み: Star」と表示されます。Web アプリでは、接続先の正確なエンドポイント URL も表示されます。

**Bluetooth または USB プリンター**（モバイル）— 検出されたデバイス一覧からプリンターを選択します。デバイスを選択すると、名前とメーカーが自動的に入力されます。プリンターがまだ一覧にない場合は、**プリンターをスキャン**（Bluetooth）または **更新**（USB）をタップします。

自動検出で正しく設定されない項目がある場合は、**詳細設定** で調整できます。

  </StepCard>
  <StepCard number="4" title="保存してテスト" isLast>

**保存** をクリックします。WCPOS は最初に **テスト印刷** を送信し、成功した場合にのみプリンターを保存します。

テスト印刷は、番号付きの列ルーラー、中央揃えの標準サイズと倍サイズのテキスト、左/右揃えの行、用紙カットからなる短い診断です。プリンターに接続できることだけでなく、用紙幅、配置、サイズ、カットがすべて正しく設定されていることを確認できるように設計されています。

:::tip テストに失敗しても保存できます
テストに失敗した場合でも、エラーとともに **テストせずに保存** オプションが表示され、プロファイルをそのまま保存できます。
:::

  </StepCard>
</Steps>

## 接続タイプ {#connection-types-mobile-apps}

まず、プリンターを追加フォームの上部で **接続タイプ** を選択します。接続フィールドは選択内容に応じて更新されます。利用できるタイプはプラットフォームによって異なります（上記の表を参照）。

### ネットワーク {#network}

プリンターが端末と同じ Wi-Fi ネットワークに接続されています。**デスクトップ** アプリと **モバイル** アプリでは、**ネットワークをスキャン** をタップしてプリンターを自動検出するか、IP アドレスを手動で入力します。詳しくは [プリンターの IP アドレスを確認する](#finding-your-printers-ip-address) を参照してください。**Web アプリ** では、IP アドレスを手動で入力する必要があります。デスクトップおよびモバイルアプリのネットワークプリンターには Epson、Star、または汎用プリンターを使用できます。Web では **Epson または Star** が必要で、ネットワーク接続で選択します。

### Bluetooth {#bluetooth}

プリンターが Bluetooth 経由で端末とペアリングされています。リストから対象のプリンターを選択すると、名前とベンダーが自動的に入力されます。**モバイル** では、Bluetooth 印刷に Epson と Star のネイティブ SDK を使用するため、プリンターは **Epson または Star** モデルである必要があります。**Web** では、Bluetooth は Web Bluetooth API を介して Chrome または Edge で利用できます。

### USB {#usb-android-only}

プリンターは USB ケーブルで接続されています。接続済みデバイスのリストから選択します。USB は **Web**（Chrome または Edge、WebUSB 経由）、**デスクトップ** アプリ、**Android** で利用できますが、一般的な USB 周辺機器をサポートしていない **iOS** では利用できません。モバイルでは、USB 印刷に **Epson または Star** プリンターが必要です。

:::note
**ポート**設定はネットワークプリンターにのみ適用されます。Bluetooth 接続および USB 接続では非表示になります。
:::

## 詳細設定 {#advanced-settings}

**詳細設定**を展開して、プリンターの設定を微調整します。これらの設定のほとんどは、ベンダーが判明すると自動的に入力されます。

これらの設定はすべてのプラットフォームに適用されます。

| 設定 | オプション | 説明 |
|---------|---------|-------------|
| **言語** | ESC/POS、StarPRNT、Star Line Mode | プリンターが使用するコマンドプロトコルです。検出されたベンダーに基づいて自動入力されます。 |
| **プリンターテキスト幅** | 58mm（32 文字）、80mm 標準（42 文字）、80mm 幅広（48 文字） | 1 行に収まる文字数です。用紙とプリンターに合わせて設定してください。80mm プリンターの多くは 1 行あたり 42 文字ですが、48 文字のものもあります。 |
| **レシート全体をラスター化** | オフ / オン | テキストではなく、レシート全体を画像として印刷します。以下の [レシート全体をラスター化](#full-receipt-raster) を参照してください。 |

これら 2 つの設定は、プラットフォームおよび接続タイプによって動作が異なります。

| 設定 | オプション | 適用場所 |
|---------|---------|------------------|
| **ベンダー** | Epson、Star、汎用 | プリンタのメーカー。**ウェブアプリ**では、詳細設定ではなく **ネットワーク**接続で直接ベンダーを選択します（Epson または Star のみ）。汎用はデスクトップアプリとモバイルアプリの**ネットワーク**プリンタで利用できますが、Bluetooth または USB 接続では利用できません。 |
| **ポート** | 自動入力 | プリンタのネットワークポートで、IP アドレスの横に表示されます。**ネットワーク接続のみ** — Bluetooth および USB では非表示です。ベンダーに応じて自動入力されます（ウェブでは、POS が HTTP と HTTPS のどちらで提供されているかにも応じます）。ネットワークでポートが再割り当てされている場合にのみ変更してください。 |

## プリンタオプション {#printer-options}

これらの切り替えは、［プリンタを追加］フォームの下部にあります。

| オプション | 説明 |
|--------|-------------|
| **用紙を自動カット** | レシートごとに印刷後、自動的に用紙をカットします |
| **キャッシュドロワーを自動で開く** | 印刷後、接続されたキャッシュドロワーを開くキックコマンドを送信します |
| **デフォルトに設定** | このプリンタをデフォルトプリンタにします — 特定のプリンタに振り分けられていないすべてのレシートに使用されます |

:::note 「チェックアウト後に自動印刷」をお探しですか？
販売の完了時にレシートを自動印刷する機能は、プリンタ設定ではなく**カート設定**です。POS のカート設定で **レシートを自動印刷**をオンにしてください。使用するプリンタは、デフォルトプリンタとテンプレートごとのプリンタ振り分けによって決まります。
:::

## 印刷の振り分け {#print-routing}

複数のテンプレート（たとえばサーマルレシート**と**A4請求書）を使用する場合、印刷ルーティングによって各テンプレートの印刷先プリンターが決まります。ルーティングには、次の順序で確認される3つのレイヤーがあります。

1. **ジョブごとの上書き。** レシート画面では、テンプレート切替の横にプリンターのドロップダウンがあります。ここでプリンターを選択すると、その印刷ジョブに限り他のすべての設定より優先されます。テンプレートを切り替えると、**自動**にリセットされます。
2. **設定による上書き。** **POS > 設定 > 印刷**に移動し、**レシートテンプレート**セクションで各テンプレートに特定のプリンターを割り当てます。たとえば、サーマルレシートはEpsonネットワークプリンターに、HTML請求書はシステム印刷ダイアログにルーティングできます。上書きを解除するには、テンプレートを**自動**に戻します。
3. **自動一致。** 上書きが設定されていない場合、WCPOSは自動的に一致させます。
   - **サーマルテンプレート**は、文字幅が一致するサーマルプリンターにルーティングされます。58mmのサーマルテンプレートでは32列プリンターが優先され、80mmテンプレートでは42列または48列プリンターが優先されます。
   - **HTMLテンプレート**は、システム印刷ダイアログにルーティングされます。
   - 複数のプリンターが一致する場合は、**デフォルト**プリンターが選択されます。

テンプレートを互換性のないプリンター（たとえば、サーマルテンプレートをシステム印刷ダイアログ）に手動で送信すると、レシート画面に琥珀色の**不一致の警告**が表示されます。印刷は続行されますが、出力が正しく表示されない場合があります。

ルーティングの上書きは**デバイスごと**に保存されます。各iPad、スマートフォン、またはコンピューターが独自のルーティングを管理し、サーバー側で同期されることはありません。

:::note
**POS > 設定 > 印刷**にある**レシートテンプレート**のプリンター設定は、少なくとも1台のプリンターを追加すると表示されます。プリンターが設定されていない場合、すべてのテンプレートは暗黙的にシステム印刷ダイアログを使用します。店舗用に設定した**クラウドプリンター**も対象に含まれます。デバイスに追加しなくても、自動的にルーティング先として表示されます。
:::

## レシート全体をラスタライズ {#full-receipt-raster}

デフォルトでは、WCPOS は内蔵フォントを使用して、レシートを **テキスト** としてサーマルプリンターに送信します。これは高速、コンパクトで鮮明です。ただし、サーマルプリンターのフォントで対応できる文字は限られています。プリンターにフォントがない文字体系（多くの非ラテン文字、右から左へ記述するテキスト、一部の記号など）は、空白の四角形や文字化けとして印刷されることがあります。

**レシート全体をラスタライズ**すると、この問題を解決できます。有効にすると、WCPOS はレシート全体を画像としてレンダリングし、その画像をプリンターに送信します。そのため、どの言語や文字体系でも、画面に表示される内容と完全に一致した印刷結果になります。

プリンターごとに **詳細設定** で有効にします。次の点に注意してください。

- **速度が遅くなります。** 画像は1行のテキストより大幅にサイズが大きいため、レシートの送信と印刷に時間がかかります。
- **必要な場合にのみ使用してください。** レシートがテキストとして正常に印刷される場合は、無効のままにしてください。
- ネットワーク、Bluetooth、USB のいずれの接続を使用するサーマルプリンターにも適用されます。すでにページ全体をレンダリングして印刷するシステム印刷ダイアログには適用されません。

## プリンターを検出する {#discovering-printers}

プリンターの検出方法は、接続方式によって異なります。

- **Bluetooth と USB** — **モバイルアプリ**では、**プリンターをスキャン**（Bluetooth）または **更新**（USB）をタップして、一覧からプリンターを選択します。名前とベンダーが自動的に入力されます。**Web**（Chrome または Edge）では、**接続**をクリックし、ブラウザーのデバイス選択画面でプリンターを選択します。
- **ネットワーク** — **デスクトップ**および**モバイル**アプリでは、**ネットワークをスキャン**をタップすると、ローカルネットワーク上のプリンターを自動的に検出できます（デスクトップでは mDNS/Bonjour を使用して検出し、モバイルでは Epson および Star SDK を使用します）。その後、一覧からプリンターを選択します。IP アドレスを直接入力することもできます。以下の [プリンターの IP アドレスを確認する](#finding-your-printers-ip-address) を参照してください。ブラウザーではネットワークをスキャンできないため、**Web アプリ**では常に IP アドレスを手動で入力します。

## プリンターの IP アドレスを確認する {#finding-your-printers-ip-address}

ほとんどのレシートプリンターでは、IPアドレスを含むセルフテストページを印刷できます：

- **Epson**：電源を入れながらフィードボタンを押し続けます
- **Star**：電源が入った状態でフィードボタンを5秒間押し続けます

または、ルーターの接続済みデバイス一覧またはプリンターの設定ユーティリティを確認してください。

### 静的IPを推奨 {#static-ip-recommended}

レシートプリンターでは、プリンターの再起動時にアドレスが変わらないよう、**静的IPアドレス**を使用することをお勧めします。次のいずれかで設定します：

- プリンターの内蔵Webインターフェース (通常は次のアドレスからアクセスできます `http://<printer-ip>`)
- ルーターのDHCP設定（プリンターのMACアドレスに予約済みIPを割り当てます）

## Epsonプリンター {#epson-printers}

ePOS対応のEpsonプリンターはHTTP経由で通信します。WCPOSはプリンターの内蔵WebサーバーにSOAP/XMLリクエストを送信します。

**接続の詳細:**
- ポート `8008`（HTTP）または `8043`（HTTPS）— POS が HTTP と HTTPS のどちらで提供されているかに合わせて自動入力されます
- エンドポイント: `/cgi-bin/epos/service.cgi`
- **新しいモデル（TM-m30III など）:** これらのモデルでは、ポートで ePOS が提供されます `80` （HTTP）/ `443` （HTTPS）で提供され、8008/8043 は使用されません。Web アプリで自動入力されたポートに接続できない場合は、**ポート**を `80` （HTTP の店舗）または `443` （HTTPS の店舗）に設定します。HTTPS の場合は、まず `https://<printer-ip>` を各 POS デバイスで開き、プリンターの証明書警告を受け入れます。ブラウザーがプリンターを信頼できない場合は、代わりに**デスクトップアプリ**を使用してください。

**動作確認済みモデル:**
- Epson TM-T70-i 2（ネットワーク）
- Epson TM-m30III（ネットワーク — 直接接続、ミドルウェア不要）

:::tip
Epsonプリンターの設定で ePOS が有効になっていることを確認してください。プリンターの Web インターフェースにアクセスし、 `http://<printer-ip>` ePOS 設定を確認して有効にします。
:::

:::warning 新しい Epson プリンターで印刷されない場合
2025年半ば以降に製造された Epson プリンターでは、**セキュアプリント**が有効になっています。この機能によりネットワーク印刷ジョブが通知なく破棄されるため、テスト印刷は「送信」されても何も印刷されません。2分で解決する方法については、[Epson セキュアプリント](/hardware/printers/secure-printing)を参照してください。
:::

**モバイルアプリ**では、Epson プリンターは Epson のネイティブ SDK を介して Bluetooth または USB でも接続できます。IP アドレスや ePOS Web サーバーは不要です。

## Star プリンター {#star-printers}

WebPRNT をサポートする Star プリンターは HTTP 経由で通信します。WCPOS は Star WebPRNT エンドポイントにコマンドを送信します。

**接続の詳細:**
- ポート `80`（HTTP）または `443`（HTTPS）— POS が HTTP と HTTPS のどちらで提供されているかに応じて自動入力されます
- エンドポイント: `/StarWebPRNT/SendMessage`

**モバイルアプリ**では、StarプリンターはStarのネイティブSDKを介してBluetoothまたはUSBでも接続できます。

## 汎用プリンター {#generic-printers}

**デスクトップアプリ**は、raw TCPを介したあらゆるネットワークレシートプリンターに対応しています。プリンターのIPアドレスとポート（通常は`9100`）を入力します。ESC/POSコマンドを受け付けるほとんどのサーマルプリンターで、メーカーを問わず利用できます。

**モバイルアプリ**でも汎用プリンターに対応していますが、**ネットワーク**接続のみで、BluetoothまたはUSBには対応していません（これらにはEpsonまたはStarプリンターが必要です）。**ウェブアプリ**は汎用プリンターにまったく対応していません。

## キャッシュドロワー {#cash-drawers}

レシートプリンターに接続されたキャッシュドロワーは、販売ごとに自動で開くよう設定できます。

1. プリンターオプションで**キャッシュドロワーを自動で開く**を有効にします
2. POSは印刷後にESC/POSキックコマンドを送信します

:::note
キャッシュドロワーの制御にはサーマルプリンタープロファイルが必要です。ブラウザーの印刷ダイアログからキャッシュドロワーを開くことはできません。
:::

## トラブルシューティング {#troubleshooting}

<Accordion>
  <AccordionItem question="セットアップ中にプリンターが検出されない">

  - プリンターの電源が入っており、使用中のデバイスと同じネットワークに接続されていることを確認してください
  - ネットワークプリンターの場合: デスクトップアプリまたはモバイルアプリで **ネットワークをスキャン** を試して自動的に検出してください。それでも検出されない場合は、IP アドレスが正しいことを確認してください（セルフテストページを印刷）
  - **ネットワーク** 経由で Web アプリを使用する場合: プリンターが ePOS/WebPRNT をサポートする Epson または Star のモデルであることを確認してください（Web アプリでの USB と Bluetooth はブランドに制限されません。以下を参照）
  - デスクトップアプリの場合: ポート 9100 で汎用ベンダーオプションを試してください
  - Bluetooth の場合: まずデバイスの Bluetooth 設定でプリンターをペアリングしてから、**プリンターをスキャン** をタップしてください
  - USB（Android）の場合: ケーブルを確認し、USB の権限確認が表示された場合は許可してください
  - ファイアウォールによって接続がブロックされていないことを確認してください

  </AccordionItem>

  <AccordionItem question="プリンターは検出されるが印刷されない">

  - **新しい Epson プリンターですか？** 最近の Epson モデルでは **セキュア印刷** が有効になっており、プリンターが正常と表示されていてもネットワーク印刷ジョブが通知なく破棄されます。対処方法については [Epson セキュア印刷](/hardware/printers/secure-printing) を参照してください
  - 用紙ロールを確認してください。用紙切れまたは紙詰まりの可能性があります
  - **プリンターのテキスト幅** 設定が使用している用紙に合っていることを確認してください（58mm または 80mm）
  - プリンター本体からセルフテストを印刷して、正常に動作することを確認してください
  - コマンド言語がプリンターと一致していることを確認してください（Epson は ESC/POS、Star は StarPRNT または Star Line Mode）

  </AccordionItem>

  <AccordionItem question="新しい Epson プリンター：テスト印刷は送信済みと表示されるが、何も印刷されない">

  これは、2025年半ば以降に製造された Epson プリンターで工場出荷時から有効になっている **セキュアプリント** の特徴です（EU のセキュリティ規制）。プリンターは従来のチャネル経由で送信されたジョブをエラーを表示せずに保留して破棄し、ステータスページには "Available" と表示されます。パネルからのセルフテストは引き続き印刷されます。プリンターの Web 設定で2分ほどで修正できます：[Epson セキュアプリント](/hardware/printers/secure-printing)。

  </AccordionItem>

  <AccordionItem question="レシートの文字が乱れる、または文字が正しく表示されない">

  - コマンド言語の設定が正しくない可能性があります。ESC/POS、StarPRNT、Star Line Mode を切り替えてみてください
  - **プリンターテキスト幅** の設定が正しいことを確認してください
  - レシートが非ラテン文字または右から左へ表記する言語の場合は、詳細設定で **レシート全体をラスター化** を有効にしてください。レシートが画像として印刷されるため、どの言語も正しく表示されます

  </AccordionItem>

  <AccordionItem question="キャッシュドロワーが開かない">

  - プリンターオプションで **キャッシュドロワーを自動で開く** が有効になっていることを確認してください
  - ドロワーが別の電源ではなく、プリンターの DK ポートに接続されていることを確認してください
  - すべてのプリンターがドロワー開放コマンドに対応しているわけではありません。プリンターのドキュメントを確認してください

  </AccordionItem>

  <AccordionItem question="Webアプリから接続できない">

  - **ネットワーク**経由では、Webアプリが接続できるのは Epson および Star プリンター（内蔵Webサーバー経由）のみです。汎用のRAWネットワークプリンターはブラウザーではサポートされません。デスクトップアプリまたはモバイルアプリ、あるいは[クラウドプリンター](/receipts/cloud-printing)を使用してください
  - **USBおよびBluetooth**プリンターはWebでも使用できますが、対応するのは **Chrome または Microsoft Edge** のみです（Safari および Firefox は WebUSB / Web Bluetooth API をサポートしていません）
  - **Bluetooth**経由では、ブラウザーが接続できるのは **Bluetooth Low Energy (BLE)** プリンターのみです。クラシックBluetoothモデル（Bluetooth対応の Epson および Star プリンターの大半を含む）はブラウザーの選択画面に表示されません。これらにはデスクトップアプリまたはモバイルアプリを使用してください
  - サイトで HTTPS を使用していてプリンターが HTTP のみを使用する場合、ブラウザーが混在コンテンツとして接続をブロックすることがあります。プリンターはPOSと同じ HTTP/HTTPS を使用する必要があります

  </AccordionItem>

  <AccordionItem question="Bluetoothプリンターが接続できない（モバイル）">

  - WCPOSに追加する前に、デバイスのシステムBluetooth設定でプリンターをペアリングしてください
  - Bluetooth印刷でサポートされるのは Epson および Star プリンターのみです。汎用Bluetoothプリンターはサポートされません
  - プリンターが一覧に表示されない場合は、**プリンターをスキャン**をもう一度タップし、電源が入っていて通信範囲内にあることを確認してください

  </AccordionItem>

  <AccordionItem question="テスト印刷はできるが列が揃わない">

  **プリンターの文字幅**設定が用紙と一致していません。プリンターに合わせて **詳細設定** で設定してください。58mmは32文字、80mmは42文字、80mm幅は48文字です。

  </AccordionItem>

  <AccordionItem question="文字がぼやけている、または薄い（コピーのような状態）">

  文字が薄くコピーのように見える場合、レシートは **ESC/POS** コマンドとして送信されず、**システム印刷ダイアログ** を通じて印刷されています。サーマルテンプレートは、システムダイアログではなくサーマルプリンタープロファイルに割り当ててください。文字がくっきり鮮明に印刷される場合は、ESC/POS が動作しています。

  </AccordionItem>

  <AccordionItem question="レシートは送信されたと表示されるが、何も印刷されない（Web アプリ）">

  Web アプリでは、「正常に送信されました」というメッセージは、リクエストがブラウザーから送信されたことを示すだけで、プリンターが受信したことを意味するものではありません。通常、ブラウザーからネットワーク経由でプリンターに到達できないことが原因です（HTTP/HTTPS スキームの誤り、ポートのブロック、証明書の不足など）。最も確実な解決方法は、プリンターに直接接続する **デスクトップアプリ** を使用することです。

  </AccordionItem>
</Accordion>
