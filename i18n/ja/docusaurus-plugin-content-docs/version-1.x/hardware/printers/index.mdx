プリンターの設定は **POS → 設定 → 印刷** にあります。プリンターはデバイスごとに管理され、レジ端末の中に保存されます。デバイス間で同期されることはありません。

:::tip このレジにないプリンターへ印刷しますか？
このページで扱うのは、USB や Bluetooth でレジにつないだプリンター、または同じ Wi-Fi 上にあるプリンターです。別の部屋や別の店舗にあるプリンター、あるいはすべてのデバイスで共有したいプリンターについては、[クラウド印刷](/receipts/cloud-printing)をご覧ください。クラウドプリンターはすべてのデバイスのプリンター一覧に自動的に表示されるため、ここで追加する必要はありません。
:::

## プリンターを追加する {#adding-a-printer}

<Steps>
  <StepCard number="1" title="スキャンする">

**設定 → 印刷**に移動し、**プリンターを追加**をタップします。1回のスキャンでUSB、Bluetooth、Wi-Fiプリンターを同時に検索するため、先に接続方法を選ぶ必要はありません。検出されたプリンターは、見つかるとすぐにカードとして表示されます。

  </StepCard>
  <StepCard number="2" title="テストページを印刷する">

お使いのプリンターのカードで**テストページを印刷**をタップします。テストページは用紙いっぱいに番号付きのルーラーを印刷するので、プリンターが動作することに加えて、用紙幅が合っているかどうかも確認できます。

用紙幅がまだ分かっていない場合は、先に **58 mm** か **80 mm** かを尋ねられます。

  </StepCard>
  <StepCard number="3" title="質問に答える">

続いて、アプリに**テストページは印刷されましたか？**と表示されます。回答は3つあります：

- **はい** — プリンターが保存され、これで完了です。
- **印刷されたが、ルーラーがずれている** — どの用紙が入っているかを尋ねられ、その答えに合わせてテストページをもう一度印刷します。[レシート幅を正しく設定する](/hardware/printers/receipt-width)をご覧ください。
- **何も印刷されない** — 最も可能性の高い原因と対処方法が1行で表示されます。

</StepCard>
  <StepCard number="4" title="名前を付ける" isLast>

保存すると、そのプリンターの**名前**、**用紙幅**、**キャッシュドロワー**の設定が **設定 → 印刷** の各行の下に表示されます。いつでもそこで変更できます。

  </StepCard>
</Steps>

### スキャン中にできること {#while-the-scan-is-running}

結果の横に3つのボタンが表示されます：

- **Bluetooth プリンターを探す** — ブラウザーまたはパソコン自身の Bluetooth 選択画面を開きます。Chrome とデスクトップアプリでは、プリンターらしい名前が一覧の上位に表示されます。
- **IP アドレスを入力** — スキャンを停止して、指定したアドレスを確認します。プリンターの場所が分かっているのにスキャンで見つからない場合に使います。業務用ネットワークではよくある状況です。
- **停止** — スキャンを中止します。すでに見つかったプリンターは画面に残ります。

## 何も印刷されないとき {#when-nothing-prints}

各トラブル画面には、問題と対処方法を示す説明が1行表示され、さらに2つのボタンがあります：

- **セットアップレポートをコピー** — アプリが試した内容、プリンターからの応答、開いていた接続をコピーします。サポートへのメッセージに貼り付けてください。何度も質問をやり取りする手間が省けます。
- **プリンターガイドを開く** — このページを開きます。

状況に合ったガイドを選んでください。

## アプリごとに接続できるもの {#supported-printers-by-platform}

| | Wi-Fi 経由 | USB と Bluetooth 経由 |
|---|---|---|
| **Web アプリ** | Epson と Star。プリンター自身の Web ポートを使います。HTTPS の店舗では、初回に Chrome がローカルネットワークへの接続許可を求めます。 | ブラウザー自身のデバイス選択画面を通じた USB と Bluetooth Low Energy。Chrome と Edge のみ。 |
| **デスクトップアプリ** | あらゆる Wi-Fi レシートプリンター。ネットワークをスキャンして探します。 | USB、Bluetooth Low Energy、および OS にインストール済みまたはペアリング済みのプリンター。 |
| **iPhone と iPad** | あらゆる Wi-Fi レシートプリンター。 | Epson と Star はメーカー自身のソフトウェア経由。その他のメーカーは Bluetooth Low Energy 経由。 |
| **Android** | あらゆる Wi-Fi レシートプリンター。 | Epson と Star はメーカー自身のソフトウェア経由。その他のメーカーは Bluetooth Low Energy 経由、または[設定でペアリング](/hardware/printers/bluetooth-pairing#android-pair-first)した Bluetooth Classic 経由。 |

ブラウザーはアプリのようにプリンターへ直接接続できません。そのため、Web アプリから Wi-Fi 経由で接続できるのは、Web サーバーを内蔵した Epson と Star のプリンターに限られます。Wi-Fi 接続のその他のプリンターには、デスクトップアプリまたはモバイルアプリ、あるいは[クラウドプリンター](/receipts/cloud-printing)を使用してください。

## プリンターのオプション {#printer-options}

**設定 → 印刷** の各プリンターの行の下にあります。

| オプション | 内容 |
|---|---|
| **用紙幅** | 1行に収まる文字数です。テストページで設定されます。[レシート幅](/hardware/printers/receipt-width)を参照してください。 |
| **用紙を自動カット** | レシートごとに用紙をカットします。 |
| **キャッシュドロワーを自動的に開く** | このプリンターにつないだドロワーを開きます。[キャッシュドロワー](/hardware/printers/cash-drawer)をご覧ください。 |
| **既定のプリンターに設定** | 他に振り分け先が決まっていないレシートを、このプリンターで印刷します。 |
| **レシート全体をラスター印刷** | レシートを文字ではなく画像として印刷します。遅くなりますが、どの言語でも印刷できます。[ラテン文字以外のレシート](/hardware/printers/non-latin-receipts)をご覧ください。 |

:::note 「会計後の自動印刷」をお探しですか？
販売完了時にレシートを自動で印刷するのは、プリンターの設定ではなく**カートの設定**です。POS のカート設定で**レシートを自動印刷**をオンにしてください。*どの*プリンターを使うかは、既定のプリンターと印刷の振り分けで決まります。
:::

## 印刷の振り分け {#print-routing}

複数のテンプレート（たとえば感熱紙のレシート**と**A4の請求書）を使う場合、印刷ルーティングによって各テンプレートを印刷するプリンターが決まります。ルーティングは次の3段階で順に確認されます：

1. **ジョブごとの上書き。**レシート画面では、プリンターのドロップダウンがテンプレート切り替えの横にあります。ここでプリンターを選ぶと、その印刷ジョブに限り他の設定より優先されます。テンプレートを切り替えると、**自動**に戻ります。
2. **設定での上書き。** **POS → 設定 → 印刷** を開き、**レシートテンプレート**のセクションで各テンプレートに特定のプリンターを割り当てます。テンプレートを**自動**に戻すと、上書きが解除されます。
3. **自動判定。** 上書きがない場合、WCPOS が自動で組み合わせます。サーマルのテンプレートは幅の合うサーマルプリンターへ（58 mm のテンプレートは 32 桁のプリンター、80 mm のテンプレートは 42 桁か 48 桁のプリンターを優先）、HTML のテンプレートはシステムの印刷ダイアログへ送られます。条件に合うプリンターが複数ある場合は、**既定**のプリンターが選ばれます。

サーマルのテンプレートをシステムダイアログへ送るなど、合わないプリンターへテンプレートを送ると、レシート画面に黄色の**不一致の警告**が表示されます。印刷はそのまま実行されますが、正しく出力されないことがあります。

振り分けは**デバイスごと**に保存され、レジ端末がそれぞれ自分の設定を管理します。

:::note
**レシートテンプレート**の設定は、プリンターを1台以上追加すると表示されます。プリンターがない場合、すべてのテンプレートでシステムの印刷ダイアログが使われます。クラウドプリンターも対象となり、ルーティング先として自動的に表示されます。
:::
