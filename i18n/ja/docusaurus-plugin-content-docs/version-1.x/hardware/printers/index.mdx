プリンターの設定は **POS → 設定 → 印刷** にあります。プリンターはデバイスごとにレジ端末に保存され、デバイス間では同期されません。

:::tip このレジにないプリンターで印刷するには？
このページでは、USB や Bluetooth でレジ端末に接続したプリンターと、同じ Wi-Fi 上にあるプリンターを扱います。別の部屋や別の店舗にあるプリンター、またはすべてのデバイスで共有したいプリンターについては、[クラウド印刷](/1.x/receipts/cloud-printing)をご覧ください。クラウドプリンターは各デバイスのプリンター一覧に自動的に表示されるため、ここで追加する必要はありません。
:::

## プリンターを追加する {#adding-a-printer}

<Steps>
  <StepCard number="1" title="スキャンする">

**設定 → 印刷** を開き、**プリンターを追加** をタップします。一度のスキャンで USB、Bluetooth、Wi-Fi のプリンターを同時に検索するため、事前に接続方法を選ぶ必要はありません。見つかったプリンターは、検出され次第カードとして表示されます。

  </StepCard>
  <StepCard number="2" title="テストページを印刷する">

お使いのプリンターのカードで **テストページを印刷** をタップします。テストページでは用紙の幅にわたって番号付きのルーラーが印刷されるため、プリンターの動作だけでなく、用紙幅が正しいかどうかも確認できます。

アプリが用紙幅をまだ把握していない場合は、最初に **58 mm** か **80 mm** かを尋ねられます。

  </StepCard>
  <StepCard number="3" title="質問に答える">

次に、アプリに **テストページは印刷されましたか？** と表示されます。回答は次の三つです。

- **はい** — プリンターが保存され、設定は完了です。
- **印刷されたが、ルーラーがずれている** — プリンターに入っている用紙を尋ねられ、回答に合わせてテストページが再印刷されます。[レシート幅を正しく設定する](/1.x/hardware/printers/receipt-width)をご覧ください。
- **何も印刷されない** — 最も可能性の高い原因と対処方法が一行で表示されます。

</StepCard>
  <StepCard number="4" title="名前を付ける" isLast>

保存すると、**設定 → 印刷** のプリンターの行の下に、**名前**、**用紙幅**、**キャッシュドロワー** の設定が表示されます。これらはいつでも変更できます。

  </StepCard>
</Steps>

### スキャン中にできること {#while-the-scan-is-running}

検索結果の横には、次の三つのボタンがあります。

- **Bluetooth プリンターを探す** — ブラウザーまたはパソコンの Bluetooth 選択画面を開きます。Chrome とデスクトップアプリでは、プリンターと思われる名前が一覧の上位に表示されます。
- **IP アドレスを入力** — スキャンを停止し、指定したアドレスだけを確認します。プリンターのアドレスが分かっているのにスキャンで見つからない場合に使用します。業務用ネットワークではよくある状況です。
- **停止** — スキャンを停止します。すでに見つかったプリンターは画面に残ります。

## 何も印刷されないとき {#when-nothing-prints}

トラブル画面には、問題と対処方法を示す一行の説明と、次の二つのボタンが表示されます。

- **セットアップレポートをコピー** — アプリが試した内容、プリンターからの応答、開いていた接続をコピーします。サポートへのメッセージに貼り付けると、何度も質問をやり取りする手間を省けます。
- **プリンターガイドを開く** — このページを開きます。

状況に合ったガイドを選んでください。

**セットアップ中**

- [レシート幅を正しく設定する](/1.x/hardware/printers/receipt-width) — ルーラーが用紙の端をはみ出す、または端まで届かない
- [プリンターに固定アドレスを割り当てる](/1.x/hardware/printers/network-address) — Wi-Fi で何も見つからない、またはプリンターが使えなくなった
- [Bluetooth レシートプリンターをペアリングする](/1.x/hardware/printers/bluetooth-pairing) — 選択画面に表示されない
- [Windows の USB](/1.x/hardware/printers/usb-windows) と [Linux の USB](/1.x/hardware/printers/usb-linux)

## アプリごとに接続できるプリンター {#supported-printers-by-platform}

| | Wi-Fi 経由 | USB と Bluetooth 経由 |
|---|---|---|
| **Web アプリ** | Epson と Star。プリンターの Web ポート経由で接続します。HTTPS の店舗では、初回に Chrome がローカルネットワークへの接続許可を求めます。 | ブラウザーのデバイス選択画面を通じた USB と Bluetooth Low Energy。Chrome と Edge のみ対応しています。 |
| **デスクトップアプリ** | あらゆる Wi-Fi レシートプリンター。ネットワークをスキャンして検出します。 | USB、Bluetooth Low Energy、および OS にインストール済みまたはペアリング済みのプリンター。 |
| **iPhone と iPad** | あらゆる Wi-Fi レシートプリンター。 | Epson と Star はメーカーのソフトウェア経由、その他のメーカーは Bluetooth Low Energy 経由で接続します。 |
| **Android** | あらゆる Wi-Fi レシートプリンター。 | Epson と Star はメーカーのソフトウェア経由で接続します。その他のメーカーは Bluetooth Low Energy 経由、または[設定でペアリング](/1.x/hardware/printers/bluetooth-pairing#android-pair-first)した後に Bluetooth Classic 経由で接続します。 |

ブラウザーはアプリのようにプリンターへ直接接続できません。そのため、Web アプリから Wi-Fi 経由で接続できるのは、Web サーバーを内蔵した Epson と Star のプリンターに限られます。Wi-Fi 接続のその他のプリンターには、デスクトップアプリやモバイルアプリ、または[クラウドプリンター](/1.x/receipts/cloud-printing)を使用してください。

## プリンターのオプション {#printer-options}

**設定 → 印刷** の各プリンターの行の下に、次のオプションがあります。

| オプション | 内容 |
|---|---|
| **用紙幅** | 一行に収まる文字数です。テストページで設定します。[レシート幅](/1.x/hardware/printers/receipt-width)をご覧ください。 |
| **用紙を自動カット** | レシートを印刷するたびに用紙をカットします。 |
| **キャッシュドロワーを自動的に開く** | このプリンターにケーブルで接続されたドロワーを開きます。[キャッシュドロワー](/1.x/hardware/printers/cash-drawer)をご覧ください。 |
| **既定のプリンターに設定** | 別のプリンターに振り分けられていないレシートを、このプリンターで印刷します。 |
| **レシート全体をラスター印刷** | レシートを文字ではなく画像として印刷します。印刷は遅くなりますが、どの言語でも印刷できます。[ラテン文字以外のレシート](/1.x/hardware/printers/non-latin-receipts)をご覧ください。 |

:::note 「会計後の自動印刷」をお探しですか？
販売完了時にレシートを自動で印刷する機能は、プリンターの設定ではなく **カートの設定** にあります。POS のカート設定で **レシートを自動印刷** をオンにしてください。*どの* プリンターを使うかは、既定のプリンターと印刷の振り分けで決まります。
:::

## 印刷の振り分け {#print-routing}

サーマルレシート **と** A4 請求書など、複数のテンプレートを使用する場合、各テンプレートをどのプリンターで印刷するかは、印刷の振り分けによって決まります。振り分けには三つの段階があり、次の順に確認されます。

1. **印刷ジョブごとの上書き。** レシート画面では、テンプレート切り替えの横にプリンターのドロップダウンがあります。ここでプリンターを選ぶと、その印刷ジョブに限り、ほかのすべての設定より優先されます。テンプレートを切り替えると、**自動** に戻ります。
2. **設定での上書き。** **POS → 設定 → 印刷** を開き、**レシートテンプレート** セクションで各テンプレートに特定のプリンターを割り当てます。テンプレートを **自動** に戻すと、上書きが解除されます。
3. **自動判定。** 上書きがない場合、WCPOS が自動で振り分けます。サーマルテンプレートは幅の合うサーマルプリンターへ送られます（58 mm のテンプレートは 32 桁のプリンター、80 mm のテンプレートは 42 桁または 48 桁のプリンターを優先します）。HTML テンプレートはシステムの印刷ダイアログへ送られます。条件に合うプリンターが複数ある場合は、**既定** のプリンターが選ばれます。

サーマルテンプレートをシステムの印刷ダイアログへ送るなど、対応していないプリンターにテンプレートを送ると、レシート画面に黄橙色の **不一致の警告** が表示されます。印刷はそのまま実行されますが、正しく出力されないことがあります。

振り分けは **デバイスごと** に保存され、各レジ端末で個別に管理します。

:::note
**レシートテンプレート** の設定項目は、プリンターを一台以上追加すると表示されます。プリンターがない場合、すべてのテンプレートでシステムの印刷ダイアログが使用されます。クラウドプリンターも対象で、振り分け先として自動的に表示されます。
:::
