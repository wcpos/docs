  <WizardStep id="network-setup" title="ネットワークプリンターを接続する">

**POS &gt; 設定 &gt; プリンター &gt; プリンターを追加**を開きます。プリンターの **IP アドレス**を入力し、保存します。

IP アドレスを確認するには、プリンターのネットワークセルフテストを印刷します。

- **Star：** プリンターの電源が入った状態で、**FEED** ボタンを約 5 秒間押し続けます。
- **Epson：** **FEED** ボタンを押しながらプリンターの電源を入れます。

後でアドレスが変わって印刷できなくならないよう、プリンターに**固定アドレス**（ルーターの DHCP 予約）を割り当てることを強くおすすめします。

  <WizardFix id="fix-not-printing" title="テスト印刷が出てこないとき">

まず、用紙が入っているか、カバーが閉まっているか、用紙が正しい向きにセットされているかを確認してください。感熱紙は片面にしか印刷できないため、裏表を逆に入れると白紙のまま排出されます。爪で用紙をこすって確認してください。跡がつく面を印字ヘッドに向ける必要があります。

次に、プリンターにアクセスできるか確認します。Web ブラウザで `http://<printer-ip>/` を開きます（読み込まれない場合は `https://<printer-ip>/`を試してください）。プリンターの設定ページが表示されれば、ネットワークには接続できており、問題は設定にあります。どちらも読み込まれない場合は、ネットワーク／IP の問題です（アドレスが間違っているか、プリンターが接続されていません）。

  <WizardFix id="net-deep" title="ネットワークを詳しく確認する">
基本的な確認で問題がなく、それでも印刷できない場合は、通常、次のいずれかのネットワークの問題が原因です。

**IP が間違っている、または変わった。** プリンターのセルフテストに表示された IP が、入力したものと一致しているか確認してください。別のプリンターのアドレスを入力してしまうこともあります。DHCP を使用するプリンターは再起動時にアドレスが変わることがあるため、ルーターで **DHCP 予約**を設定して固定してください。`169.254` で始まるアドレスは、プリンターがネットワークに接続できていないことを意味します。

**動作していたのに、その日の最初の印刷に失敗する。** プリンターのネットワークカードがスリープ状態になり、最初のジョブで復帰する際にそのジョブが失われています。もう一度テスト印刷を送信してください。固定レジでは、有線の **Ethernet** 接続も検討してください。

**二台のレジで一台のプリンターを共有している。** 多くの Star ネットワークプリンターは、既定では同時に一つの接続しか受け付けないため、二台目のレジからの接続はタイムアウトします。プリンターの Web 設定で **9100 multi-session** を有効にしてください。

**プリンターのネットワーク設定でプロトコルが間違っている。** WCPOS は **ポート 9100 の raw TCP** でジョブを送信します。ブラウザでプリンターの設定ページを開きます（`http://<printer-ip>/`、読み込まれない場合は `https://<printer-ip>/` ）。**raw／ポート 9100** での印刷が有効になっていることを確認してください。プリンターが LPR、IPP、WSD のみに設定されていると、ジョブは届きません。

**Wi-Fi に接続できない、または接続が頻繁に切れる。** レシートプリンターは通常、**2.4GHz のみ**に対応しています。5GHz 専用やバンドステアリングを使用するネットワークではなく、2.4GHz のネットワークに接続してください。接続が不安定な場合は、有線 Ethernet が確実な解決策です。

  <WizardInvalid id="web-generic-invalid" title="汎用プリンターにはデスクトップアプリが必要です">

Web ブラウザでは raw ネットワーク接続を確立できないため、印刷サーバーを内蔵した **Epson** と **Star** のプリンターにしか接続できません。汎用の ESC/POS ネットワークプリンターには、ネットワーク経由（ポート 9100）で直接接続する**デスクトップアプリ**を使用してください。[プリンターの設定](/1.x/hardware/printers)ページからダウンロードできます。

  </WizardInvalid>

  <WizardStep id="web-net-setup" title="Web アプリからネットワークプリンターを接続する">

**Web ブラウザから**ネットワークプリンターに印刷する方法は、設定が最も複雑です。ブラウザは HTTP/HTTPS 経由でプリンターの内蔵 Web サーバーとしか通信できず、HTTPS の POS ではプリンターへの接続にも HTTPS が必須になるためです。

まず、プリンターにアクセスできるか確認します。ブラウザの新しいタブで `http://<printer-ip>/` を開きます（読み込まれない場合は `https://<printer-ip>/`を試してください）。プリンターの設定ページが表示されれば、ネットワークに接続できています。どちらも読み込まれない場合は、先にネットワーク／IP の問題を解消してください。

次に、**POS &gt; 設定 &gt; プリンター**で、IP アドレスを指定してプリンターを追加します。POS が **HTTPS** で動作している場合、プリンターへの接続も HTTPS（Epson はポート 8043、Star は 443）になります。これが機能するには、プリンターに信頼された **SSL 証明書**が必要です。

  <WizardFix id="web-net-fix" title="Web でのネットワーク印刷がうまくいかないとき">

これは特によくつまずく箇所で、通常はブラウザ側だけでは解決できません。原因と対処法は次のとおりです。

プリンターの**セルフテスト**を印刷し、SSL/TLS の項目を確認してください。証明書が**存在しない**と表示されている場合は、証明書を生成するまで HTTPS で印刷できません。また、自己署名証明書の場合は、各デバイスで `https://<printer-ip>` に一度アクセスして承認しない限り、ブラウザはその証明書を信頼しません。

「正常に送信されました」と表示されるのに何も印刷されない場合は、ブラウザが通知せずにリクエストをブロックしたか（プリンターは HTTP、POS は HTTPS のため「混合コンテンツ」としてブロック）、証明書がないまま HTTPS ポート（Epson は 8043、Star は 443）への接続が強制されたことを意味します。

また、Web アプリはプリンターの**内蔵 Web サーバー**（Epson の **ePOS-Print** または Star の **WebPRNT**）経由でしか接続できません。プリンターの設定で、そのサービスが**オン**になっていることを確認してください。内蔵 Web サーバーを備えているのは、Epson の「インテリジェント」／**-NT** モデルと Star の **WebPRNT** モデルのみです。搭載していないプリンターには、ブラウザから接続できません。

**確実な解決策はデスクトップアプリです**。ブラウザの HTTPS 制限を受けずに、ネットワーク経由（ポート 9100）でプリンターへ直接接続します。[プリンターの設定](/1.x/hardware/printers)からダウンロードし、同じプリンターを追加してください。

      <WizardChoice value="yes" label="はい" goTo="g-width" />
      <WizardChoice value="no" label="まだ印刷されません" goTo="support" />
    </WizardGate>

  <WizardStep id="bt-setup" title="Bluetooth で接続する">

Bluetooth でのレシート印刷にはプリンターメーカー独自のソフトウェアを使用するため、**Epson** または **Star** のモデルが必要です。汎用 Bluetooth プリンターの Bluetooth 接続には、どのプラットフォームも対応していません。

まず、WCPOS ではなく、**コンピューターまたはデバイスのシステム Bluetooth 設定でプリンターをペアリング**します。Bluetooth プリンターが一度に記憶できるデバイスは一台だけなので、別のレジとペアリング済みの場合は、先にそちらで登録を解除してください。**iPhone/iPad** では、許可を求められたら WCPOS に **Bluetooth** と**ローカルネットワーク**の両方へのアクセスを許可します。**Android** では、システムによって接続が切断されないよう、WCPOS のバッテリー使用を**制限なし**に設定します。**Windows または Mac のデスクトップ**では、まず OS の Bluetooth 設定でペアリングしてから、WCPOS でスキャンします。

次に、**POS &gt; 設定 &gt; プリンター**で**プリンターをスキャン**をタップし、お使いのプリンターを選択します。名前とブランドが自動的に入力されます。

      <WizardChoice value="yes" label="はい" goTo="g-width" />
      <WizardChoice value="no" label="いいえ／ペアリングまたは接続できません" goTo="bt-fix" />
    </WizardGate>
  </WizardStep>

  <WizardFix id="bt-fix" title="Bluetooth でペアリングできない、または接続が頻繁に切れる">

**まずデバイスのシステム Bluetooth 設定でペアリング**してから、WCPOS でもう一度スキャンしてください。以前はペアリングできたのに再接続できない場合は、他のデバイスとの関連付けが残らないよう、そちらで登録を解除し、プリンターの Bluetooth もリセットしてください。電源が入っていて、通信範囲内にあることを確認します。iPhone/iPad では WCPOS に Bluetooth とローカルネットワークの両方へのアクセスを許可し、Android ではアプリのバッテリー使用を制限なしに設定してください。Bluetooth で対応しているのは **Epson と Star のみ**です。汎用 Bluetooth プリンターは接続できません。

  <WizardStep id="usb-setup" title="USB で接続する">

プリンターを USB で接続します。**Android** では、USB のアクセス許可を求められたら承認し、**POS &gt; 設定 &gt; プリンター**でプリンターを選択します。**Mac** では、USB は通常、追加設定なしで動作します。**Windows** では、汎用プリンターを接続する**前に**ドライバーのインストールが必要な場合があります。

  <WizardFix id="usb-fix" title="USB で接続できない">

**Android** では、ケーブルを差し直し、USB のアクセス許可を求められたら承認してください。**デスクトップアプリ（Windows）** で `LIBUSB_ERROR_NOT_SUPPORTED` エラーが出る場合は、Windows がデバイスを自身の印刷ドライバーに固定していることを意味します。最も簡単な解決策は、**代わりにネットワーク経由（ポート 9100）でプリンターを接続する**ことです。USB ドライバーを使わずに印刷できます。（上級者は WinUSB ツールでドライバーを置き換えることもできますが、そのデバイスの通常の Windows 印刷キューが無効になります。内容を理解している場合にのみ行ってください。）

  <WizardStep id="web-btusb" title="Web ブラウザからの Bluetooth &amp; USB 接続">

**Web アプリ**に Bluetooth または USB でプリンターを接続できるのは、**Google Chrome または Microsoft Edge** のみです（Safari と Firefox では接続できません）。**POS &gt; 設定 &gt; プリンター**で**接続**をクリックし、ブラウザのデバイス選択画面でプリンターを選択します。

**USB** は Epson、Star、およびほとんどの汎用 ESC/POS プリンターで動作します。ブラウザの選択画面にプリンターが表示されれば、印刷できるはずです。**Windows** では、プリンターのドライバーがブラウザとの通信を妨げることがあります。接続に失敗する場合は、デスクトップアプリを使用してください。

**Bluetooth** で接続できるかどうかは、ブランドではなくプリンターの Bluetooth の種類で決まります。ブラウザから接続できるのは **Bluetooth Low Energy（BLE）** プリンターだけです。小型のポータブルプリンターは BLE 対応のものが多く、問題なく動作します。一方、Bluetooth 対応の Epson や Star のほとんどのモデルを含め、従来の Bluetooth を使用するプリンターはブラウザの選択画面に表示されません。お使いのプリンターが表示されない場合は、これが理由です。代わりにデスクトップアプリまたはモバイルアプリを使用してください。

どちらの方法でも接続できない場合、Bluetooth と USB には**デスクトップアプリ**が最も確実です。[プリンターの設定](/1.x/hardware/printers)からダウンロードしてください。

Star Online は認証と権限を分けて扱います。**401／認証失敗**エラーは、API キーが受け入れられなかったことを意味します。キーを正しくコピーしたか、失効していないか、正しい stario.online アカウントに属しているか、CloudPRNT URL の**リージョン**と一致しているかを確認してください（US は `device.stario.online`、EU は `eu-device.stario.online` です。リージョンが違うと必ず 401 エラーになります）。**403／禁止**エラーは、キーは受け入れられたものの、権限が不足していることを意味します。stario.online でキーを編集し、**EnumDevices**（「デバイスを取得」に必要）と **PrintToDevice**（印刷に必要）を有効にしてください。**一覧が空**の場合は、キーと URL は有効ですが、デバイスグループに接続済みのデバイスがないか、URL が別のグループを指しています。stario.online の Device Groups ページで、正しいデバイスが存在し、接続されていることを確認してください。

    <WizardGate id="g-cloud-so-retry" question="キーまたは URL を修正した後、「デバイスを取得」でデバイスが表示されましたか？">
      <WizardChoice value="yes" label="はい" goTo="cloud-so-test" />
      <WizardChoice value="no" label="まだ失敗します" goTo="support" />
    </WizardGate>
  </WizardFix>

  <WizardFix id="fix-cloud-so-job" title="Star Online に接続したのに何も印刷されない">

デバイスの取得は成功したのに何も印刷されない場合は、Star Online のカードでプリンターの**ステータス**を確認してください。**オフライン**または**不明**は、Star Online がプリンターに接続できないことを意味します（電源が入っていて、ネットワークに接続されていることを確認してください）。また、Star Online では感熱テンプレートのみ使用できるため、**感熱テンプレート**が割り当てられていることを確認してください（選択肢に表示されない場合は、割り当ててからもう一度試してください）。最後に、WCPOS の **CloudPRNT URL** が正しいデバイスグループとリージョンを指していることを確認してください。
