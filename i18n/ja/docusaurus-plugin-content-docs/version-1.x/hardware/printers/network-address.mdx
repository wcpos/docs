**症状：** Wi-Fi でスキャンしても何も見つからない、または数週間使えていたプリンターが、突然どのレシートでもタイムアウトするようになります。

## 原因 {#why-it-happens}

ほとんどの場合、原因は次の三つのネットワークの状態にあります。

- **ネットワークが異なる。** レジ端末とプリンターが、ゲスト SSID、別のアクセスポイント、別の VLAN など、異なる Wi-Fi に接続されています。プリンターの検出はネットワークをまたいで行われません。
- **クライアント分離。** ゲスト用や公共の Wi-Fi では通常、機器同士の通信が完全にブロックされます。そのため、プリンターが同じネットワークにあっても接続できません。
- **アドレスが変わった。** ルーターはアドレスを期限付きで貸し出します。このリースが変わると、プリンターには新しいアドレスが割り当てられますが、保存されたプリンターの設定は古いアドレスを指したままです。そのため、昨日は使えたのに今日はタイムアウトすることがあります。

## 対処方法 {#do-this}

1. レジ端末とプリンターを、ゲストネットワークではなく **同じ Wi-Fi** に接続します。
2. プリンターのステータスシートを印刷して、現在のアドレスを確認します。Epson ではロール紙カバーを開き、**Feed** を一秒間長押しします。Star では電源が入った状態で **Feed** を五秒間長押しします。
3. プリンターに **固定アドレス** を割り当てます。ルーターの DHCP 設定でプリンターの MAC アドレスに対してアドレスを予約するか、`http://printer-ip` にあるプリンターの Web ページで静的アドレスを設定します。どちらの方法でも、アドレスが変わらなくなります。
4. アプリで **IP アドレスを入力** を選び、アドレスを入力します。スキャンを停止して指定したアドレスを直接確認するため、自動検出がブロックされていても接続できます。

アドレスが正しくてもタイムアウトする場合、プリンターがジョブを保留している可能性があります。[一度印刷した後、印刷できなくなった](/1.x/hardware/printers/printed-once-then-stopped)をご覧ください。

## それでも解決しない場合 {#still-stuck}

トラブル画面で **セットアップレポートをコピー** を使い、メッセージに貼り付けてください。接続を試したアドレスと、応答したポートが記録されています。
