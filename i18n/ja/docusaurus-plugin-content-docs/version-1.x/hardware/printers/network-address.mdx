**症状：** Wi-Fi でスキャンしても何も見つからない、または数週間問題なく使えていたプリンターが、急にどのレシートでもタイムアウトするようになった。

## 原因 {#why-it-happens}

ほとんどの場合、次の 3 つのネットワーク状況のいずれかです。

- **ネットワークが別々。** レジが一方の Wi-Fi に、プリンターがもう一方（ゲスト SSID、2 台目のアクセスポイント、別の VLAN）につながっています。プリンターの検出は、この境界を越えられません。
- **クライアント分離。** ゲスト用や公共の Wi-Fi は通常、機器同士の通信を完全にブロックします。プリンターは同じネットワークにいるのに、それでも接続できません。
- **アドレスが変わった。** ルーターはアドレスをリースとして割り当てます。リースが変わるとプリンターは新しいアドレスに移りますが、保存されたプリンターは古いアドレスを指したままです。昨日は動いたのに今日はタイムアウトする、というのはこれが原因です。

## 対処方法 {#do-this}

1. レジとプリンターを**同じ Wi-Fi** に接続します。ゲストネットワークは使わないでください。
2. プリンターのステータスシートを印刷して現在のアドレスを確認します。Epson ではロール紙カバーを開いて **Feed** を 1 秒間長押しします。Star では電源が入った状態で **Feed** を 5 秒間長押しします。
3. **固定アドレス**を割り当てます。ルーターの DHCP 設定でプリンターの MAC アドレスに対してアドレスを予約するか、`http://printer-ip` にあるプリンター自身の Web ページで静的アドレスを設定します。どちらの方法でもアドレスは変わらなくなります。
4. アプリで **IP アドレスを入力**を使い、そのアドレスを入力します。スキャンを止めて 1 つのアドレスを直接確認するので、検出がブロックされていても機能します。

アドレスが正しいのにタイムアウトする場合、プリンターがジョブを保留している可能性があります。[1 枚印刷した後で止まった](/hardware/printers/printed-once-then-stopped)をご覧ください。

## それでも解決しない場合 {#still-stuck}

トラブル画面で**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。試したアドレスと、どのポートが応答したかが記録されています。
