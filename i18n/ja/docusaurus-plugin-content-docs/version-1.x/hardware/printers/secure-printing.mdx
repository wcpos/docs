**症状：** アプリに *「セキュア印刷が有効です。プリンター側で無効にしてから、もう一度お試しください。」* と表示される。あるいは、新品の Epson がネットワーク上で見つかり、テストページは送信されたように見えるのに、何も出てこない。エラーもランプの表示もなく、プリンター自身のステータスページには利用可能と表示される。パネルからのセルフテストは正常に印刷される。

## 原因 {#why-it-happens}

EUおよび英国向けに製造された Epson TM シリーズのプリンターは、EU無線機器指令に準拠するため、**2025年8月1日**以降、**Secure Printing** が有効な状態で出荷されています。有効時、プリンターは旧式の暗号化されていない通信経路で送信されたジョブを受け付けた後、**通知なく破棄**します。

| チャネル | セキュア印刷が**有効** | **無効** |
|---|---|---|
| Raw TCP、ポート 9100 | 受け付けた後、破棄される | 印刷される |
| ePOS-Print over HTTP（80、8008） | 提供されない | 印刷される |
| ePOS-Print over HTTPS（443、8043） | 印刷される | 印刷される |

EU 域外で販売された製品にも同じファームウェアが搭載されている場合があります。世界のどこであっても、新しい Epson でこの症状が出たら設定を確認してください。

## 無効にする {#turn-it-off}

プリンターの管理者パスワードが必要です。最近のモデルではプリンター底面のラベルに記載された**シリアル番号**が、古いモデルでは `epson` が使われていました。

1. プリンターのアドレスを確認します。ステータスシートに記載されています（ロール紙カバーを開き、**Feed** を長押しします）。
2. ブラウザーで `https://printer-ip` を開き、証明書の警告を承認します。
3. **管理者ログイン**の後、**印刷 → セキュア印刷**へ進みます。
4. **無効**に設定して確定します。
5. プリンターの電源コードを抜いて10秒待ち、再び差し込んでください。
6. もう一度テストページを印刷します。

:::warning ファームウェア更新で再び有効になります
Epson はファームウェア更新時にセキュリティ設定を既定値に戻します。数か月間正常に動いていたプリンターが更新直後に止まった場合は、この手順をもう一度実行してください。
:::

設定画面を開いたついでに、独自の管理者パスワードを設定してください。無防備なレシートプリンターには、同じネットワーク上の誰でも接続できます。

## それでも解決しない場合 {#still-stuck}

**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。[Epson の無線機器指令に関する FAQ](https://www.epson.co.uk/en_GB/faq/KA-01896/contents?loc=en-us) もあわせてご覧ください。
