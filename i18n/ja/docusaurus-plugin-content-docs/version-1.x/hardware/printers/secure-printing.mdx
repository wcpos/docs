# Epson セキュア印刷 {#epson-secure-printing}

**症状:** 新しい Epson レシートプリンターを追加すると、WCPOS はネットワーク上で検出し、テスト印刷は送信済みと表示されますが、何も印刷されません。エラーも点滅ランプもなく、プリンター自体のステータスページには「利用可能」と表示されます。パネルのセルフテストは正常に印刷されます。

この症状に当てはまる場合、プリンターではほぼ間違いなく **セキュア印刷** が有効になっています。最近の Epson モデルでは、工場出荷時にこの設定が有効です。

## 何が起きているのか {#whats-happening}

**2025 年 8 月 1 日**以降、EU のサイバーセキュリティ規制（無線機器指令、"RED"）により、EU 市場に投入されるネットワーク接続機器は **デフォルトで安全** であることが求められています。TM シリーズのレシートプリンターに対する Epson の対応が、**セキュア印刷** という設定です。有効な間は、従来の暗号化されていないチャネル（ほとんどの POS ソフトウェアが使用する raw TCP ポート（9100）およびプレーン HTTP の ePOS）経由で届く印刷ジョブを、プリンターが**通知なく保留してから破棄**します。ジョブはエラーとして拒否されるのではなく、単に印刷されません。そのため、すべてが正常に*見える*のです。

これは WCPOS だけでなく、すべての POS 製品に影響します。Epson はレガシーシステム向けに従来のポートを再度有効にするよう案内しており、他の POS ベンダーも同じ解決方法を案内しています。

:::info EU 域外の場合
EU 規制そのものは EU 域外には適用されませんが、他の地域で販売される製品にも同じファームウェアとデフォルト設定が搭載されている場合があります。世界のどこであっても、新品の Epson でこの症状が発生した場合は設定を確認してください。2 分で確認でき、原因を特定できます。
:::

## 解決方法 {#the-fix}

プリンターの Web 設定ページと **管理者パスワード** が必要です。最近の Epson プリンターでは、工場出荷時の管理者パスワードはデバイスごとに固有です。通常はプリンター底面のラベルに記載されている **シリアル番号** です（古いモデルではパスワードに `epson` が設定されていました）。以前に誰かがプリンターを設定している場合、変更されている可能性があります。

1. プリンターの IP アドレスを確認します（自己診断シートに記載されています。または WCPOS のプリンター設定で **ネットワークをスキャン** を使用します）。
2. ブラウザーで次を開きます `https://<printer-ip>` — 例： `https://192.168.1.131`。証明書の警告を承認します（プリンターは自己署名証明書を使用しており、これは正常です）。
3. **管理者ログイン** をクリックし、管理者パスワードでサインインします。
4. **印刷** タブ → **セキュアプリント** に移動します。
5. **セキュアプリント** を **無効** に設定し、確認します。
6. **プリンターの電源を入れ直します** — 電源コードを 10 秒間抜きます。一部の設定は再起動後にのみ有効になります。
7. 最近のモデルで **Web アプリ** を使用している場合は、**POS > 設定 > 印刷** でプリンターを編集し、店舗で HTTP を使用している場合は **ポート** を `80` に、HTTPS を使用している場合は `443` に設定します。HTTPS の場合は、まず手順 2 の説明に従って、そのデバイスでプリンターの証明書警告を承認します。
8. WCPOS に戻り、**テスト印刷** を再度実行します。すぐに印刷されるはずです。

:::warning ファームウェア更新により再び有効になります
Epsonの案内によると、ファームウェア更新を行うとセキュリティ設定は準拠したデフォルト設定にリセットされます。つまり、**プリンターのファームウェア更新後はセキュア印刷が再び有効になります**。数か月間正常に動作していたプリンターがファームウェア更新直後に突然印刷できなくなった場合は、上記の手順をもう一度実行してください。
:::

**お使いのプリンターが対象かどうかわからない場合**：ネットワークステータスシートを印刷し（ロール紙カバーを開いた状態でFEEDボタンを1秒間長押しするか、ステータスシートボタン搭載モデルではそのボタンを3秒間長押しします）、`Security Mode` の行を確認してください。`RED` はセキュア印刷が有効な状態で出荷されたことを示し、`Normal`（または該当する行がない場合）は対象外であることを示します。

:::tip この機会に管理者パスワードを変更してください
工場出荷時のパスワードは誰でも読めるラベルに記載されており、プリンターの管理ページにはネットワーク上のすべてのデバイスからアクセスできます。プリンターが共有ネットワーク（オフィス、コワーキングスペース、ショッピングモールなど）に接続されている場合は、独自の管理者パスワードを設定し、可能であればプリンターを専用のネットワークセグメントに配置してください。オープンなレシートプリンターにアクセスできる人は誰でも、印刷の実行、プリンターの占有、接続されたキャッシュドロワーの開放を行えます。
:::

## この規制が存在する理由 {#why-the-regulation-exists}

これは恣意的なものではありません。認証されていないオープンなネットワークポートを備えたレシートプリンターは、接続されたキャッシュドロワーを開くコマンドを含め、**ネットワーク上の誰からでも**コマンドを受け付けます。インターネットに公開されたレシートプリンターはスパムを印刷させる目的で大量に乗っ取られ、工場出荷時のパスワードを使用する組み込みデバイスはボットネットに組み込まれてきました。[委任規則（EU）2022/30](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32022R0030) は、[規則（EU）2023/2444](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32023R2444) により2025年8月1日以降に市場投入される製品に適用され、こうした開かれた入口を持たない状態でデバイスを出荷することを求めています。

セキュア印刷を無効にすること自体は正当です。この規制が求めているのは安全な*デフォルト設定*であり、常に安全であることではありません。従来のポートを再び有効にすることは、デバイス所有者による意図的な選択です。十分に理解したうえで選択してください。レジにはプライベートネットワークを使用し、独自の管理者パスワードを設定することを推奨します。

## 技術的な詳細：ポート {#ports}

実機のTM-m30III（ファームウェア 13.21）で確認済み：

| 状態 | Raw TCP 9100 | ePOS-Print (HTTP :80) | ePOS-Print (HTTPS :443) |
|---|---|---|---|
| セキュアプリントが**有効** | 受け付けられるが、通知なく破棄される | 提供されない | 動作する |
| セキュアプリントが**無効** | 動作する | 動作する | 動作する |

知っておくべき点が2つあります。まず、セキュアプリントが有効な場合、破棄は即時には行われません。プリンターはジョブを数分間保持し、**保持している間は、どのチャネルからも印刷されません**。そのため、誤って送信されたジョブ1件によって、正常なプリンターが完全に停止しているように見えることがあります。次に、この世代のプリンターでは、従来の ePOS ポート `8008`/`8043` は ePOS-Print を提供しません（8008 は閉じており、8043 では別の Epson サービスが動作します）。そのため、**Web アプリ**では、店舗が HTTP で動作している場合はプリンターの**ポートを 80**に設定し、HTTPS で動作している場合は **443** に設定してください。

Epson の互換性ガイドでもこのマトリクスが確認されており、暗号化されたバリエーションも記載されています。セキュアプリントが有効な場合でも、TLS ポートの `9143`（暗号化された raw）、`443`（HTTPS ePOS）、`8043`/`8143`（SDK）は動作し続けます。そのため、RED 対応ソフトウェアでは何も無効にせずに印刷できます。RED ファームウェアでは、LPR（ポート 515）および TLS 1.0/1.1 は、セキュアプリントの切り替え設定にかかわらず完全に無効になります。
