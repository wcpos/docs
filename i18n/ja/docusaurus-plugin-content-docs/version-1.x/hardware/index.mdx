## カードリーダーの互換性 {#card-reader-compatibility}

使用できるカードリーダーは、**WCPOSをどの環境で動かしているか**と、リーダーの接続方式によって決まります。

- **Webアプリ**が操作できるのは、**Web（ブラウザ）SDK**を提供するリーダーだけです。通常はインターネット接続型の据え置き端末が該当します。**Bluetooth専用**のリーダー（例：Stripe M2 / WisePad 3、SumUp Air）やスマートフォンの**タッチ決済**には、Webアプリは**対応していません**。
- 対応状況は**ゲートウェイごと**に異なります。購入前に、使う予定のゲートウェイ（[Stripe Terminal](/1.x/payment/gateways/stripe-terminal)、[SumUp](/1.x/payment/gateways/sumup-terminal)、[PayPal Reader](/1.x/payment/gateways/paypal-reader)）のページでリーダーの対応を確認してください。

各ゲートウェイのページに、対応するリーダーの一覧が記載されています。
