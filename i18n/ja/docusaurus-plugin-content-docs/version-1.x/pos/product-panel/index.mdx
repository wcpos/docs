商品パネルは POS 画面の左側にあり、カートに追加する商品を検索、閲覧、選択できます。

{/* Screenshot: pos-product-panel.png */}

## インターフェースの概要 {#interface-overview}

### 検索バー {#search-bar}

パネル上部の検索バーでは、次の情報を使って商品をすばやく探せます。

- **商品名** - 商品名の一部を入力します
- **SKU** - 在庫管理単位で検索します
- **バーコード** - バーコード番号をスキャンまたは入力します

詳しくは[検索と絞り込み](/1.x/pos/product-panel/search-filtering)を参照してください。

### 表示設定 {#display-settings}

検索バーの横にある **スライダーアイコン**（<Icon name="sliders" />）をクリックすると表示設定が開き、商品一覧に表示する列や情報をカスタマイズできます。

### フィルターボタン {#filter-buttons}

検索バーの下にあるフィルターボタンで商品を絞り込めます。

- **在庫あり** - 在庫がある商品のみを表示
- **おすすめ** - WooCommerce でおすすめに設定した商品を表示
- **セール中** - 現在セール中の商品を表示
- **カテゴリー** - 商品カテゴリーで絞り込み
- **タグ** - 商品タグで絞り込み
- **ブランド** - ブランドで絞り込み（ブランドプラグインを使用している場合）

有効なフィルターは強調表示されます。再度クリックすると解除されます。

### 商品一覧 {#product-list}

メイン領域には、商品がスクロール可能な一覧で表示されます。各行には次の情報が表示されます。

- **商品画像** - 商品のサムネイル
- **商品名** - 任意の詳細情報（在庫、SKU、カテゴリーなど）も表示
- **価格** - 現在の販売価格（該当する場合はセール価格も表示）
- **アクションボタン** - カートに追加（<Icon name="circle-plus" color="green" />）またはバリエーションを選択（<Icon name="circle-arrow-right" color="green" />）

### 商品タイプ {#product-types}

- **シンプル商品** には緑色の <Icon name="circle-plus" color="green" /> ボタンが表示され、直接カートに追加できます
- **バリエーションのある商品** には緑色の <Icon name="circle-arrow-right" color="green" /> 矢印が表示され、バリエーションセレクターを開けます

詳しくは[バリエーション商品](/1.x/pos/product-panel/variations)を参照してください。

### フッター {#footer}

商品パネルの下部には、次の情報と操作ボタンがあります。

- **税ステータス** - 現在の税計算の基準を表示します（例：「税の基準：ショップの基本住所」）。クリックすると、適用される税率を確認できます。
- **商品数** - 表示中の商品数を示します（例：「17 件中 10 件を表示」）
- **同期ボタン**（<Icon name="arrow-rotate-right" />）- サーバーから商品情報を取得して更新します。**長押し** すると、次の追加オプションが表示されます。
  - **同期** - サーバーからの通常の更新
  - **クリアして更新** - ローカルデータを消去し、すべて再読み込み

スライダーアイコン（<Icon name="sliders" />）をクリックして、商品パネルの表示をカスタマイズします。

### 在庫切れの商品を表示 {#show-out-of-stock-products}

現在在庫切れの商品を表示するかどうかを制御します。

- **有効**: 在庫切れの商品は表示されたままですが、カートには追加できません
- **無効**: 在庫切れの商品はリストから非表示になります

### 列 {#columns}

商品リストに表示する列を設定します:

| 列 | 説明 |
|--------|-------------|
| **画像** | 商品のサムネイル |
| **商品** | 商品名と詳細 |
| **SKU** | Stock Keeping Unit（個別の列） |
| **バーコード** | 商品バーコード（個別の列） |
| **タイプ** | 商品タイプ（シンプル、バリエーションなど） |
| **在庫** | 現在の在庫数量 |
| **売上原価** | 商品原価 |
| **価格** | 販売価格 |
| **操作** | カートに追加ボタン |

二つの列では、追加の表示オプションを切り替えられます。

| 列 | 表示オプション |
|--------|-----------------|
| **商品** | 在庫、SKU、バーコード、カテゴリー、タグ、ブランド、属性、メタデータ |
| **価格** | 税情報、セール中インジケーター |

### メタデータキー {#meta-data-keys}

メタデータキーは、WooCommerce の商品に保存されるカスタムフィールドです。デフォルトでは、これらは商品に残り、注文にはコピーされません。この設定を使用すると、商品が追加されたときに、特定のキーをカートの明細項目へ引き継げます。

**例:** ボトルデポジットプラグインが、各商品に `_bottle_deposit` の値を保存しているとします。ここにそのキーを追加すると、商品がカートに追加されるたびに、そのデポジット値が明細項目とともに注文へ引き継がれます。そのため、注文、レシート、後続のレポートに表示されます。

メタキーをカンマ区切りのリストで入力します:

```
_bottle_deposit,_custom_field,_tracking_code
```

:::tip
メタキーは大文字と小文字が区別され、商品のメタデータに保存されている内容と完全に一致している必要があります。
:::

<Accordion>
  <AccordionItem question="どのような場合に使用しますか?">

商品のメタデータを注文明細に引き継ぐ主な用途は次のとおりです。

- **ボトルデポジットプラグイン** — デポジット金額を注文に引き継ぎます。
- **カスタム商品フィールド** — 独自の商品データを注文に引き継ぎます。
- **サードパーティ連携データ** — 注文明細を読み取る他のプラグインに値を渡します。
- **コンプライアンス / 追跡情報** — バッチ、ロット、追跡コードを販売した商品に紐付けて保持します。

</AccordionItem>
</Accordion>

### デフォルト設定に戻す {#restore-default-settings}

クリックすると、すべての表示設定が初期設定に戻ります。

## 商品をカートに追加する {#adding-products-to-cart}

### シンプル商品 {#simple-products}

緑色の <Icon name="circle-plus" color="green" /> ボタンをクリックすると、シンプル商品がカートに追加されます。クリックするたびに数量が一つ増えます。

### バリエーション商品 {#variable-products}

バリエーション商品（サイズや色を選べる T シャツなど）には、緑色の <Icon name="circle-arrow-right" color="green" /> 矢印が表示されます。クリックすると、次の方法で選択できます。

1. **クイックポップオーバー** - ドロップダウンからバリエーションを選択
2. **インラインで展開** - 「展開」をクリックして、一覧内にすべてのバリエーションを表示

詳しくは[バリエーション商品](/1.x/pos/product-panel/variations)を参照してください。

### バーコードスキャン {#barcode-scanning}

USB または Bluetooth のバーコードスキャナーを接続すると、商品をすばやく追加できます。バーコードをスキャンすると、WCPOS が一致する商品を自動的に検索して追加します。

設定手順については、[バーコードスキャン](/1.x/pos/product-panel/barcode-scanning)を参照してください。

## 一部の商品が表示されない理由 {#why-cant-i-see-some-products}

商品パネルに商品が表示されない場合は、次の点を確認してください。

- **POS 表示** - 「オンラインのみ」に設定された商品は POS に表示されません。[POS 専用商品](/1.x/products/pos-only-products)を参照してください。
- **在庫設定** - 表示設定で「在庫切れの商品を表示」が無効になっていると、在庫切れの商品は非表示になります。
- **同期ステータス** - 新規商品や最近更新された商品は、同期が必要な場合があります。同期ボタンを長押しして、**「クリアして更新」** を選択してください。
- **フィルター** - 有効なフィルター（カテゴリー、タグなど）によって商品が非表示になっていないか確認してください。
