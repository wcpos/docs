POS画面は製品を販売するための主要なインターフェースです。WCPOSを使用しているときに最も多くの時間を過ごす場所です。

{/* スクリーンショット: pos-desktop-layout.png */}

## 画面レイアウト {#screen-layout}

### ヘッダー {#header}

ヘッダーバーには以下が表示されます：

- **店舗名** - 接続されているWooCommerceストアの名前
- **接続性インジケーター** - サーバーに接続されているときは緑のドット、オフラインのときは黄色/赤
- **ユーザーメニュー** - 設定にアクセスしたり、ユーザーを切り替えたり、ログアウトしたりするためにクリック

### ナビゲーションドロワー {#navigation-drawer}

左側のサイドバーから、すべての主要画面にすばやくアクセスできます。販売画面と診断・サポート画面は無料版プラグインに含まれています。管理画面（商品、注文、顧客、レポート）は [WCPOS Pro](/1.x/getting-started/free-vs-pro) に含まれています。

| アイコン | 画面 | 説明 | エディション |
|------|--------|-------------|---------|
| <Icon name="cash-register" /> | **POS** | 主な販売インターフェース（ここです） | 無料版 |
| <Icon name="gift" /> | **商品** | 在庫管理 — 在庫数、価格、商品詳細の編集 | <ProBadge /> |
| <Icon name="receipt" /> | **注文** | 注文履歴 — 過去の注文の検索、再印刷、編集、返金 | <ProBadge /> |
| <Icon name="users" /> | **顧客** | 顧客管理 — 顧客の追加と編集 | <ProBadge /> |
| <Icon name="chart-line" /> | **レポート** | 売上レポート — 支払い方法、キャッシャー、店舗別の日次締め合計 | <ProBadge /> |
| <Icon name="heart-pulse" /> | **ストアヘルス** | 同期のパフォーマンス、データベースのカバレッジ、アクティビティログ | 無料版 |
| <Icon name="circle-question" /> | **サポート** | Discordサポートチャンネル | 無料版 |

バージョン番号はドロワーの下部に表示されます。

:::note 無料版と Pro の画面
無料版プラグインでも、レジで既存の顧客を **選択** できますが、管理画面は開けません。商品、注文、顧客、レポートの画面は Pro で利用できます。詳しい比較は[無料版と Pro の比較](/1.x/getting-started/free-vs-pro)を参照してください。
:::

## レスポンシブレイアウト {#responsive-layout}

WCPOS はさまざまな画面サイズに対応します。

### デスクトップ / タブレット（大画面） {#desktop--tablet-large-screens}

大きな画面では、POS は **二列レイアウト** で表示されます。

- **左列：** 商品パネル - 商品の検索と閲覧
- **右列：** カートパネル - 現在の注文の表示と管理

列は **サイズ変更可能** です。列の間の仕切りをドラッグして幅の比率を調整します。

{/* スクリーンショット: pos-desktop-layout.png */}

### モバイル（小画面） {#mobile-small-screens}

小さな画面では、POS は **タブベースのレイアウト** を使用します。

- **商品タブ：** 商品の閲覧とカートへの追加
- **カートタブ：** カートの表示、明細の管理、チェックアウト

画面下部のナビゲーションバーでタブを切り替えます。

{/* Screenshot: pos-mobile-layout.png */}

## 主なコンポーネント {#main-components}

### 商品パネル {#product-panel}

POS の左側にある[商品パネル](/1.x/pos/product-panel)では、次の操作ができます。

- 商品名、SKU、バーコードで商品を検索
- 在庫状況、カテゴリー、タグなどで商品を絞り込み
- 商品をカートに追加

[商品パネルの詳細 →](/1.x/pos/product-panel)

### カートパネル {#cart-panel}

POS の右側にある[カートパネル](/1.x/pos/cart)では、次の操作ができます。

- 現在の注文の商品を表示
- 数量と価格を編集
- 顧客を選択または追加
- 注文アクション（メモ、無効化、チェックアウト）にアクセス

[カートパネルの詳細 →](/1.x/pos/cart)

### チェックアウト {#checkout}

販売を完了する準備ができたら、**チェックアウト** をクリックして[チェックアウトモーダル](/1.x/pos/checkout)を開きます。

- クーポンコードを適用
- 支払い方法を選択
- 決済を処理
- レシートを印刷またはメール送信

[チェックアウトの詳細 →](/1.x/pos/checkout)

## キーボードショートカット {#keyboard-shortcuts}

WCPOS では、操作をすばやく行うためのキーボードショートカットを利用できます。すべてのショートカットは設定モーダル、または[キーボードショートカット](/1.x/settings/store/hotkeys)で確認できます。

よく使うショートカット：

| ショートカット | アクション |
|----------|--------|
| `Ctrl + F` | 検索バーにフォーカス |
| `Ctrl + Shift + S` | 設定を開く |
| `Escape` | モーダル/ダイアログを閉じる |

## 接続状態 {#connectivity}

ヘッダーの緑色のインジケーターは接続状態を示します。

- **緑** - WooCommerce サーバーに接続済み
- **黄** - 接続に問題があり、再試行中
- **赤** - オフラインモード

オフライン中も、キャッシュ済みの商品や顧客を閲覧し、オフライン対応の支払い方法で販売を完了できます。これらの注文はローカルのキューに保存され、自動的に同期されます。ウェブ決済ゲートウェイと統合型ゲートウェイを利用するには、それぞれのサービスに接続できる必要があります。
