POS画面は製品を販売するための主要なインターフェースです。WCPOSを使用しているときに最も多くの時間を過ごす場所です。

{/* スクリーンショット: pos-desktop-layout.png */}

## 画面レイアウト {#screen-layout}

### ヘッダー {#header}

ヘッダーバーには以下が表示されます：

- **店舗名** - 接続されているWooCommerceストアの名前
- **接続性インジケーター** - サーバーに接続されているときは緑のドット、オフラインのときは黄色/赤
- **ユーザーメニュー** - 設定にアクセスしたり、ユーザーを切り替えたり、ログアウトしたりするためにクリック

### ナビゲーションドロワー {#navigation-drawer}

左側のサイドバーからすべての主要画面に迅速にアクセスできます。販売画面と診断・サポート画面は無料版プラグインに含まれています。管理画面（商品、注文、顧客、レポート）は [WCPOS Pro](/getting-started/free-vs-pro) の一部です。

| アイコン | 画面 | 説明 | エディション |
|------|--------|-------------|---------|
| <Icon name="cash-register" /> | **POS** | 主な販売インターフェース（ここです） | 無料版 |
| <Icon name="gift" /> | **商品** | 在庫管理 — 在庫数、価格、商品詳細の編集 | <ProBadge /> |
| <Icon name="receipt" /> | **注文** | 注文履歴 — 過去の注文の検索、再印刷、編集、返金 | <ProBadge /> |
| <Icon name="users" /> | **顧客** | 顧客管理 — 顧客の追加と編集 | <ProBadge /> |
| <Icon name="chart-line" /> | **レポート** | 売上レポート — 支払い方法、キャッシャー、店舗別の日次締め合計 | <ProBadge /> |
| <Icon name="heart-pulse" /> | **ストアヘルス** | 同期のパフォーマンス、データベースのカバレッジ、アクティビティログ | 無料版 |
| <Icon name="circle-question" /> | **サポート** | Discordサポートチャンネル | 無料版 |

バージョン番号はドロワーの下部に表示されます。

:::note 無料版と Pro の画面
無料版プラグインでも、レジで既存の顧客を**選択**することはできます。開けないのは管理画面のみです。商品、注文、顧客、レポートは Pro で利用できるようになります。詳細な内訳は [無料版と Pro の比較](/getting-started/free-vs-pro) を参照してください。
:::

## レスポンシブレイアウト {#responsive-layout}

WCPOSはさまざまな画面サイズに適応します：

### デスクトップ / タブレット（大画面） {#desktop--tablet-large-screens}

大画面では、POSは**二列レイアウト**を表示します：

- **左列:** 商品パネル - 商品を検索・閲覧
- **右列:** カートパネル - 現在の注文を表示・管理

カラムは**サイズ変更可能**です - 列間の仕切りをドラッグして比率を調整します。

{/* スクリーンショット: pos-desktop-layout.png */}

### モバイル（小画面） {#mobile-small-screens}

小画面では、POSは**タブベースのレイアウト**を使用します：

- **商品タブ:** 商品を閲覧し、カートに追加
- **カートタブ:** カートを表示し、アイテムを管理し、チェックアウト

画面下部のナビゲーションバーを使ってタブ間を切り替えます。

{/* スクリーンショット: pos-mobile-layout.png */}

## 主なコンポーネント {#main-components}

### 商品パネル {#product-panel}

POSの左側は[商品パネル](/pos/product-panel)で、以下を行います：

- 名前、SKU、またはバーコードで商品を検索
- 在庫状況、カテゴリ、タグなどで商品をフィルター
- カートに商品を追加

[商品パネルについてさらに学ぶ →](/pos/product-panel)

### カートパネル {#cart-panel}

POSの右側は[カートパネル](/pos/cart)で、以下を行います：

- 現在の注文に含まれているアイテムを表示
- 数量や価格を編集
- 顧客を選択または追加
- 注文アクション（メモ、無効、チェックアウト）にアクセス

[カートパネルについてさらに学ぶ →](/pos/cart)

### チェックアウト {#checkout}

販売を完了する準備ができたら、**チェックアウト**をクリックして[チェックアウトモーダル](/pos/checkout)を開きます：

- クーポンコードを適用
- 支払い方法を選択
- 支払いを処理
- 領収書を印刷またはメール

[チェックアウトについてさらに学ぶ →](/pos/checkout)

## キーボードショートカット {#keyboard-shortcuts}

WCPOSは迅速な操作のためにキーボードショートカットをサポートしています。全ショートカットのリストは設定モーダルからアクセスできます。または[キーボードショートカット](/settings/store/hotkeys)を参照してください。

一般的なショートカット：

| ショートカット | アクション |
|----------|--------|
| `Ctrl + F` | 検索バーにフォーカス |
| `Ctrl + Shift + S` | 設定を開く |
| `Escape` | モーダル/ダイアログを閉じる |

## 接続性 {#connectivity}

ヘッダーの緑のインジケーターは接続状態を示します：

- **緑** - WooCommerceサーバーに接続されています
- **黄色** - 接続に問題、再接続中
- **赤** - オフラインモード

オフライン中でもキャッシュされた商品や顧客を閲覧でき、オフライン対応の支払い方法であれば販売を完了できます。これらの注文はローカルにキューイングされ、自動的に同期されます。Web ゲートウェイや統合型ゲートウェイは、引き続きそれぞれのサービスに接続できる必要があります。
