## 注文メモ {#order-note}

<div class="image-container">
  <Image
    alt="POS の注文メモ"
    img="/img/order-note.png"

  />
  <p class="image-caption">POS の注文メモモーダル（左）と WP 管理画面の注文メモ（右）</p>

- 注文に顧客メモを追加するダイアログを開きます。
- 顧客メモは顧客に公開され、デフォルトでレシート、顧客のマイアカウント、および `WP Admin > WooCommerce > Orders > Order` の配送先住所の下に表示されます。

:::note
注文メモは顧客にも表示されます。
:::

## 注文メタ {#order-meta}

<div class="image-container">
  <Image
    alt="POS の注文メタと JSON ビュー"
    img="/img/order-meta.png"
    style={{maxHeight: 500}}
  />
  <p class="image-caption">POS の注文メタと JSON ビュー</p>

- 注文の追加メタデータを管理するモーダルを開きます。
- 次の機能を利用できます。
  - 注文の通貨を変更します。
  - 取引 ID（外部の決済端末で発行されたものなど）を追加します。
  - 注文にカスタムメタデータを追加します。

:::note
このモーダルには、他の WooCommerce プラグインとの連携など、今後さらに機能が追加される予定です。
:::

### WooCommerce のメタデータとは？ {#what-is-meta-data-in-woocommerce}

メタデータは注文に関する追加情報で、WooCommerce REST API 経由でアクセスできます。開発者やプラグインはこのデータを使い、外部サービスとの連携などの機能を拡張します。

### JSON ビュー {#json-view}

- 注文の生の JSON データを表示します。デバッグや外部連携に役立ちます。

## サーバーに保存 {#save-to-server}

- 開いているカートをサーバーに保存し、安全に保管して後から利用できるようにします。
- ステータスが `pos-open` の WooCommerce 注文を作成します。

### 保存が必要な理由 {#why-save}

POS で作成した新しい注文は、最初はローカルにしか存在しません。 
注文を保存しておけば、ローカルデータベースを消去しても注文が残ります。

保存した注文の管理について詳しくは、[オープン注文](/1.x/pos/cart/open-orders)を参照してください。

## 無効化 {#void}

- 次の二つのケースがあります。
  - 未保存の注文：
    - サーバーに保存されていない注文は、ローカルデータベースから完全に削除されます。
  - 保存済みの注文：
    - サーバーに保存されている注文は、WooCommerce のゴミ箱に移動され、ローカルデータベースから削除されます。
- 無効化した注文を復元するには：
  - `WP Admin > WooCommerce > Orders > Trash` に移動します。

## チェックアウト {#checkout}

- 注文をサーバーに保存し、チェックアウトを開始します。
- [チェックアウト画面](/1.x/pos/checkout)を開き、支払いを完了します。
