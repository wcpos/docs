カート内の各アイテムは、直接編集できるラインアイテムです。WCPOS では、数量、価格、その他の詳細をその場で柔軟に編集できます。

## ラインアイテムタイプ {#line-item-types}

WooCommerce では、3種類のラインアイテムを使用します。

| タイプ | 説明 | 例 |
|------|-------------|----------|
| **line_item** | カタログの商品 | Tシャツ、コーヒーマグ |
| **fee_line** | 追加の手数料 | ギフトラッピング、サービス料 |
| **shipping_line** | 配送料 | 標準配送、エクスプレス配送 |

:::note
配送料は手動で入力します。POS は配送料を自動計算しません。
:::

## ラインアイテムの編集 {#editing-line-items}

### 数量 {#quantity}

数量フィールドをクリックして直接編集します。新しい数値を入力するか、スピナーで増減してください。

{/* Screenshot: cart-line-item-edit-qty.png */}

### 製品名 {#product-name}

その他の商品や手数料は、名前をクリックして直接編集できます。

### 価格 {#price}

価格フィールドをクリックすると単価を変更できます。次のような場合に便利です。

- 手動での割引の適用
- 他店の価格に合わせた値下げ
- 価格の誤りの修正

合計は数量 × 価格に基づいて自動的に更新されます。

:::note 価格の編集は WooCommerce の「割引」ではありません
値下げした価格は商品のセール価格として記録されます。レシートには節約額を表示できますが、注文の **割引** 合計はクーポン専用で、レポートでは実際に支払われた価格で売上が集計されます。WooCommerce がこの二つを異なる方法で扱う理由については、[カートの割引](/1.x/pos/cart/discounts#why-tracked-differently)を参照してください。
:::

### 三点メニュー {#three-dot-menu}

各ラインアイテムの **⋮**（三点メニュー）をクリックすると、追加のオプションが表示されます。

{/* Screenshot: cart-line-item-menu.png */}

#### 編集フォーム {#edit-form}

ラインアイテムの詳細な編集フォームが開き、すべてのフィールドを変更できます。

#### 生の JSON ビュー {#raw-json-view}

ラインアイテムの生の JSON データを表示します。次のような場合に特に便利です。

- **デバッグ** - WooCommerce に送信されるデータを正確に確認します
- **トラブルシューティング** - カスタムフィールドやメタデータの問題を特定します
- **開発** - 連携に必要なデータ構造を把握します

### アイテムを削除 {#remove-item}

赤い **×** ボタンをクリックすると、カートから商品を削除できます。

## バリエーション属性 {#variation-attributes}

バリエーション商品では、選択したバリエーションの属性が商品名の下に表示されます。

```
Hoodie
Colour: Green
Size: Large
```

これらの属性はラインアイテムのデータの一部であり、注文に含まれます。

## メタデータ {#meta-data}

商品パネルの設定で[メタデータキー](/1.x/pos/product-panel#meta-data-keys)を設定している場合、商品をカートに追加すると、そのデータが自動的にラインアイテムにコピーされます。

このメタデータは生の JSON ビューで確認できます。

## ラインアイテムの分割 {#splitting-line-items}

[表示設定](/1.x/pos/cart#display-settings)で有効にすると、ラインアイテムを複数の行に分割できます。同じ商品の一部に異なる割引を適用したい場合に便利です。

## ヒント {#tips}

### 価格をすばやく調整する {#quick-price-adjustments}

すばやく値引きするには、次の手順に従います。

1. 価格フィールドをクリックします
2. 新しい価格を入力します
3. Enter キーを押します

### キーボード操作 {#keyboard-navigation}

- **Tab** - 編集可能なフィールド間を移動します
- **Enter** - 編集を確定します
- **Escape** - 編集をキャンセルします

### まとめて編集 {#batch-edits}

複雑な注文では、三点メニューから詳細な編集フォームを開くと、すべてのフィールドを一度に確認できます。
