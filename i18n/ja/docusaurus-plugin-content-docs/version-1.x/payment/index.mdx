WCPOSは、さまざまなビジネスニーズに対応するため、複数のお支払い方法をサポートしています。チェックアウトではiframe/webviewを使用してWooCommerceの注文支払いページを読み込むため、WooCommerceで動作する決済ゲートウェイであればPOSでも利用できます。

## デフォルトのお支払い方法 {#default-payment-methods}

無料版には、組み込みの決済ゲートウェイが二つ含まれています。

### 現金 {#cash}

- 預かり金額を入力
- おつりの自動計算
- 追加の設定は不要

### カード {#card}

- 外部カード端末での使用向け
- 端末で処理した後、決済を完了としてマークするだけです
- 直接の連携は不要です

## 追加の決済ゲートウェイ（Pro） {#additional-payment-gateways-pro}

:::info Pro 機能
追加の決済ゲートウェイには [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。
:::

Pro では、POS の会計画面で追加の WooCommerce 決済ゲートウェイを有効にできます。

- **Stripe Terminal** - Stripe カードリーダーとの直接連携
- **SumUp Terminal** - SumUp カードリーダーとの連携
- **すべての WooCommerce ゲートウェイ** - 店舗にインストール済みの任意のゲートウェイを有効化

## ゲートウェイの有効化と無効化 {#enabling-and-disabling-gateways}

決済ゲートウェイは WordPress 管理画面で管理します。

1. `WP Admin > POS > 設定 > 支払い` に移動します
2. インストール済みのすべての WooCommerce 決済ゲートウェイが一覧表示されます
3. オンラインストアとは独立して、各ゲートウェイを POS 用に有効または無効に切り替えます
4. ドラッグして並べ替えます。有効なゲートウェイのうち、先頭のものが会計時のデフォルトになります

つまり、ウェブサイトでは有効、POS では無効にしたり、その逆に設定したりできます。詳細は[会計設定](/1.x/settings/wp-admin/checkout)を参照してください。

## 決済のテスト {#testing-payments}

新しいゲートウェイを本番運用する前に、次の点を確認してください。

1. **現金ゲートウェイ** — 実際の取引を行わずに会計フローをテストするために、いつでも利用できます。
2. **Stripe Terminal** — Stripe はテストモード用の[シミュレーテッドリーダー](https://docs.stripe.com/terminal/testing)を提供しています。まず Stripe ダッシュボードでテストモードを有効にしてください。
3. **サードパーティゲートウェイ** — サンドボックスやテストモードの手順は、各ゲートウェイのドキュメントで確認してください。ほとんどの WooCommerce ゲートウェイはテストモードの切り替えに対応しています。

:::tip
新しく有効にしたゲートウェイが会計画面に表示されない場合は、POS を再読み込みしてください。WP Admin で行ったゲートウェイの変更は、次回のページ読み込み時に反映されます。
:::

## よくある問題 {#common-issues}

### 会計時にゲートウェイが表示されない {#gateway-not-appearing-at-checkout}

- `WP Admin > POS > 設定 > 支払い` で、ゲートウェイが POS 向けに有効になっていることを確認してください。
- `WP Admin > WooCommerce > 設定 > 支払い` でもゲートウェイが有効になっていることを確認してください。POS に表示するには、WooCommerce 側でゲートウェイが有効になっている必要があります。
- 変更後は POS を再読み込みしてください。

### ゲートウェイが正しく表示されない {#gateway-displays-incorrectly}

会計画面の iframe はサイトのテーマスタイルを読み込むため、表示に影響が出ることがあります。会計モーダルの **会計設定** ボタンを使い、スタイルやスクリプトを選択的に無効にしてください。詳細は[会計のトラブルシューティング](/1.x/pos/checkout#checkout-settings-troubleshooting)を参照してください。

### 決済処理が失敗する {#payment-processing-fails}

- サイトのエラーログ(`WP Admin > POS > サポート > ログ`)で、ゲートウェイ固有のエラーを確認してください。
- SSL 証明書が有効であることを確認してください。ほとんどの決済ゲートウェイには HTTPS が必要です。
- ステージング環境やローカル環境を使用している場合は、ゲートウェイがテストモードやサンドボックスモードに対応していることを確認してください。
