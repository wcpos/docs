# カスタム支払いゲートウェイ {#payment-gateways}

WCPOSは、販売時点管理システムの機能を拡張するいくつかのカスタム支払いゲートウェイをサポートしています。これらのゲートウェイは、POS環境専用に設計されており、さまざまな支払い方法やサービスとのシームレスな統合を提供します。

## 利用可能なカスタムゲートウェイ {#available-custom-gateways}

### ハードウェア端末ゲートウェイ {#hardware-terminal-gateways}

- **[Stripe Terminal](./stripe-terminal.mdx)** - Stripe Terminalハードウェアリーダーを使用して支払いを受け付けます
- **[SumUp Terminal](./sumup-terminal.mdx)** - SumUpカードリーダーを介して支払いを処理します
- **[Square Terminal](./square-terminal.mdx)** - Square Terminal端末で対面決済を受け付けます
- **[PayPal Reader (Zettle)](./paypal-reader.mdx)** - PayPal Reader (Zettle)端末でカードによる対面決済を受け付けます
- **[Mollie Terminal](./mollie-terminal.mdx)** - Mollie Terminal端末で対面決済を受け付けます
- **[Mercado Pago Terminal](./mercadopago-terminal.mdx)** - Mercado Pago Point Smart端末で対面決済を受け付けます（0.1.0で追加）
- **[Windcave Terminal](./windcave-terminal.mdx)** - Windcave端末でカードによる対面決済を受け付けます（0.1.0で追加）
- **[PayArc Terminal](./payarc-terminal.mdx)** - PayArc PAX端末で対面決済を受け付けます

### モバイル支払いゲートウェイ {#mobile-payment-gateways}

- **[Vipps MobilePay](./vipps-mobilepay.mdx)** - QRコードまたはプッシュ通知を通じて電話ベースの支払いを受け付けます

### デジタル支払いゲートウェイ {#digital-payment-gateways}

- **[Email Invoice](./email-invoice.mdx)** - 顧客に支払い請求書をメールで送信します
- **[Web Checkout](./web-checkout.mdx)** - 顧客をオンラインで支払いを完了するためにリダイレクトします

## 独自のゲートウェイを作成する {#creating-your-own-gateway}

特定の要件に合わせたカスタム決済ゲートウェイが必要な場合は、**[ゲートウェイテンプレート](/1.x/reference/gateway-template)** を使用して独自の WCPOS 決済ゲートウェイを作成できます。

## インストール概要 {#installation-overview}

どのカスタムゲートウェイも、おおむね同じ手順でインストールできます。

1. それぞれの GitHub リポジトリから最新リリースを **ダウンロード** します
2. `WP Admin > プラグイン > 新規追加 > プラグインのアップロード` からプラグインを **インストール** します
3. `WP Admin > WooCommerce > 設定 > 支払い` でゲートウェイを **設定** します
4. `WP Admin > POS > 設定 > 支払い` でゲートウェイを **有効化** します
