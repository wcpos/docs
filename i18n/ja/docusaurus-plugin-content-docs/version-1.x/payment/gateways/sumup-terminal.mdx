# SumUp Terminalゲートウェイ {#sumup-terminal-gateway}

SumUp Terminalゲートウェイを使うと、SumUpカードリーダーでWCPOSから直接カード決済を受け付けられます。このゲートウェイは、対面取引向けのSumUp決済処理システムとシームレスに連携します。

## インストール {#installation}

<Steps>
  <StepCard number="1" title="WooCommerce用SumUp Terminalをインストール">

`WP Admin > POS > 設定 > 拡張機能`からインストールするか、[GitHubリリースページ](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases)から最新の**プラグインZIPアセット**（GitHubのソースコードZIPまたはtarballではありません）をダウンロードし、`プラグイン > 新規追加 > プラグインのアップロード`からアップロードします。

  </StepCard>
  <StepCard number="2" title="SumUpの設定">

1. `WP Admin > WooCommerce > 設定 > 支払い`に移動します
2. 決済方法の一覧から**SumUp Terminal**を探します
3. **SumUp Terminal**をクリックして設定を開きます
4. **SumUp APIキー**を入力します（SumUp加盟店ダッシュボードで確認できます）
5. 設定を保存します

:::note
WooCommerceの設定でSumUp Terminalゲートウェイを有効にする必要はありません。後の手順でPOS用に有効化します。
:::

  </StepCard>
  <StepCard number="3" title="SumUp Terminalをペアリング">

1. 同じ設定ページで、**リーダーをペアリング**セクションを探します
2. SumUp端末でペアリング画面を開き、ペアリングコードを表示します
3. SumUp端末に表示されたペアリングコードを入力します
4. **"リーダーをペアリング"**をクリックして接続します
5. リーダーのペアリングが完了したことを示す確認を待ちます

:::warning 重要
決済を処理するには、リーダーのペアリングが正常に完了している必要があります。次に進む前に、ペアリングを完了してください。
:::

  </StepCard>
  <StepCard number="4" title="WCPOSで有効化" isLast>

1. `WP Admin > POS > 設定 > 支払い`に移動します
2. 一覧から**SumUp Terminal**ゲートウェイを探します
3. POSで使用するゲートウェイを有効にします
4. 設定を保存します

  </StepCard>
</Steps>

## 使い方 {#usage}

### 決済の処理 {#processing-payments}

1. **商品を追加**：POSで商品をカートに追加します
2. **ゲートウェイを選択**：「SumUp Terminal」を決済方法として選択します
3. **決済を開始**：クリックしてSumUp端末で新しい決済を開始します
4. **顧客の支払い**：顧客がSumUp端末で支払いを完了します
5. **自動完了**：決済が検出されると注文は自動的に完了します

### 決済コントロール {#payment-controls}

SumUp Terminalゲートウェイを使うと、次の操作ができます：

- **新しい決済を開始**：接続された端末に決済リクエストを送信します
- **決済をキャンセル**：処理中の決済をキャンセルします
- **決済状況**：決済処理の現在の状態を確認します

### 注文管理 {#order-management}

- **自動更新**：決済が成功すると注文は自動的に完了としてマークされます
- **決済の追跡**：すべての決済詳細が注文メモに記録されます
- **レシートの生成**：決済成功後に標準のPOSレシートが生成されます

## ハードウェアの互換性 {#hardware-compatibility}

:::important 接続要件
この実装ではSumUpのJavaScript SDKを使用するため、ウェブアプリケーション上で動作しますが、**インターネット接続対応端末のみ**が必要です。Bluetooth端末には現在対応していません。
:::

### 対応端末（インターネット接続） {#supported-terminals-internet-connected}

- **SumUp Solo** ✅ - WiFi/Ethernet接続端末

### 非対応端末（Bluetooth） {#unsupported-terminals-bluetooth}

- **SumUp Air** ❌ - Bluetooth専用
- **SumUp 3G** ❌ - Bluetooth専用

:::note 今後の対応
Bluetooth端末への対応は、今後のiOSおよびAndroidアプリのリリースで予定されています。対応すると、Airや3Gモデルを含む、SumUp認定端末すべてが使えるようになります。
:::

## トラブルシューティング {#troubleshooting}

### よくある問題 {#common-issues}

<Accordion>
  <AccordionItem question="リーダーをペアリングできない">

  - 対応するインターネット接続端末（Soloのみ）を使用していることを確認します
  - SumUp Solo端末がWiFiに接続され、オンラインであることを確認します
  - 端末がペアリングモードになっており、ペアリングコードが正しく入力されていることを確認します
  - SumUpアカウントでAPIアクセスが有効になっていることを確認します
  - ペアリング中に安定したインターネット接続があることを確認します

  </AccordionItem>

  <AccordionItem question="決済を処理できない">

  - リーダーが正しくペアリングされていることを確認します
  - SumUpアカウントが有効で、問題のない状態であることを確認します
  - 端末のバッテリー残量と接続状態が十分であることを確認します
  - APIキーが正しく、有効であることを確認します

  </AccordionItem>

  <AccordionItem question="注文が完了しない">

  - インターネット接続が安定していることを確認します
  - SumUpアカウントのWebhook設定を確認します
  - SumUp端末で決済が成功したことを確認します
  - API通信の問題がないか、WordPressのエラーログを確認します

  </AccordionItem>
</Accordion>

### APIレート制限 {#api-rate-limits}

このゲートウェイはAPI呼び出しを減らし、レート制限を避けるよう最適化されています：
- 決済状況を効率的に確認します
- 不要なAPIリクエストを最小限に抑えます
- 一時的な失敗には自動再試行ロジックで対応します
