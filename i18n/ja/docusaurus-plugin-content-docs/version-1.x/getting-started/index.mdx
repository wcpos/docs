## WCPOSとは？ {#what-is-wcpos}

WCPOSはWooCommerce向けのPOSです。ウェブブラウザーまたはWindows、macOS、Linux用デスクトップアプリで動作し、iOSおよびAndroidアプリはベータ版です。オンラインストアと同じ商品カタログ、在庫、価格を使い、すべての販売をWooCommerceの注文として記録します。無料プラグインでは現金および外部カード決済を受け付け、レシートを印刷できます。WCPOS Proでは、カードリーダー連携、返金、在庫編集、注文履歴、レポート、複数店舗の機能が追加されます。

店舗に合うかどうか分からない場合は、[WCPOSはあなたに合っていますか？](/1.x/getting-started/is-wcpos-right-for-you)で、対象となる店舗、必要なもの、費用、他製品との比較をご確認ください。

## 5分で始める {#get-started-in-5-minutes}

<Steps>

<StepCard number={1} title="プラグインをインストール">

無料の[WCPOSプラグイン](https://wordpress.org/plugins/woocommerce-pos/)をWordPressサイトにインストールします：

1. **WP管理 → プラグイン → 新規追加**に移動
2. "WCPOS"を検索
3. **今すぐインストール**をクリックし、その後**有効化**します

詳細な要件については、[インストール](/1.x/getting-started/installation)を参照してください。

</StepCard>

<StepCard number={2} title="POSにアクセス">

**ウェブユーザー：** ブラウザーで`yourdomain.com/pos`にアクセスします。WordPressの認証情報でログインするように求められます。

**デスクトップ/モバイルユーザー：** アプリをダウンロードし、店舗のURLを入力して**接続**をクリックし、WordPressの認証情報でログインします。

複数の店舗やユーザーの管理については、[接続](/1.x/getting-started/connect)を参照してください。

</StepCard>

<StepCard number={3} title="初期同期を待つ">

WCPOSはサーバーに負荷をかけないように、バックグラウンドで小分けにしてカタログをダウンロードします。すべての同期が終わるのを待たずに販売を開始できます。商品を検索すると、まだデバイスにない場合はその場で取得されます。

詳細については、[商品同期](/1.x/products/sync)を参照してください。

</StepCard>

<StepCard number={4} title="販売を開始する" isLast>

- 検索またはスキャンして商品をカートに追加します
- 顧客を選択するか「ゲスト」を使用します
- **チェックアウト**をクリックして支払いを処理します
- レシートを印刷またはメールで送信します

</StepCard>

</Steps>

## 主な特徴 {#key-features}

<FeatureGrid>
  <FeatureCard icon="search" title="迅速なローカル検索">
    商品はローカルに保存され、即座に検索結果が表示されます
  </FeatureCard>
  <FeatureCard icon="wifi" title="オフラインブラウジング">
    インターネット接続なしで商品や顧客を検索し、オフライン対応の売上をキューに追加できます
  </FeatureCard>
  <FeatureCard icon="barcode" title="バーコードスキャン">
    USBまたはBluetoothのバーコードスキャナーを使用できます
  </FeatureCard>
  <FeatureCard icon="credit-card" title="現金とカードの支払い">
    現金および基本的なカード支払いに標準で対応しています
  </FeatureCard>
  <FeatureCard icon="print" title="レシート印刷">
    カスタマイズ可能なレシートを印刷またはメールで送信できます
  </FeatureCard>
  <FeatureCard icon="calculator" title="自動税計算">
    WooCommerceの税設定に基づいて税金を計算します
  </FeatureCard>
</FeatureGrid>
