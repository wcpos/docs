WCPOS プラグインが正しく動作し、最適なパフォーマンスを発揮するために、ご利用の環境が以下の最小要件を満たしていることをご確認ください。

## サーバー要件 {#server-requirements}

WCPOS プラグインは WordPress サイト上で動作し、サイトは以下の最小要件を満たす必要があります：

| コンポーネント | 最小バージョン | 備考 |
| ----------- | --------------- | --------------- |
| WordPress | 5.6 | — |
| WooCommerce | 5.3 | — |
| PHP | 7.4 | 8.x 推奨 |

これらの最小要件を満たすことで、WordPress 環境との互換性と安定性が確保され、最新の WCPOS 機能にアクセスできるようになります。

## ブラウザ要件 {#browser-requirements}

POS のウェブ版は、あらゆるモダンブラウザで動作します。最新の安定版リリースを使用してください：

| ブラウザ | 対応バージョン |
| --------------- | ----------------- |
| Google Chrome | 最新の安定版 |
| Mozilla Firefox | 最新の安定版 |
| Safari | 最新の安定版 |
| Microsoft Edge | 最新の安定版 |

:::warning プライベート／シークレットモードは避けてください
プライベートブラウジングは、WCPOS がデータをオフラインで保存するために使用するブラウザのローカルストレージへのアクセスをブロックすることがあり、一部の機能が正しく動作しなくなります。また、JavaScript も有効になっている必要があります。
:::

## アプリ要件 {#app-requirements}

WCPOS はデスクトップアプリおよびモバイルアプリとしても利用できます。それぞれ、以下の最小オペレーティングシステム向けに構築されています：

| プラットフォーム | 最小 OS | アーキテクチャ |
| --------------- | ------------------------- | -------------------------- |
| Windows デスクトップ | Windows 10 | x64、ARM64 |
| macOS デスクトップ | macOS 12 (Monterey) | Intel (x64)、Apple Silicon |
| Linux デスクトップ | 現行の64ビットディストリビューション | x64                     |
| iOS / iPadOS | iOS 16.4 | — |
| Android | Android 10 (API level 29) | — |

:::note 印刷の権限
Bluetooth およびネットワーク印刷には、プロンプトが表示されたときに、アプリに関連する Bluetooth およびローカルネットワークの権限を付与する必要があります。
:::

## プラグインのインストール {#installing-the-plugin}

WP Adminの**プラグインを追加**では、WordPress.orgの最新のWCPOSがインストールされます。リリース後は2.0が対象になります。WCPOS 1.xをインストールするには、代わりに最新の1.11リリースをアップロードしてください。

1. WordPress.orgの[WCPOS詳細ページ](https://wordpress.org/plugins/woocommerce-pos/advanced/)を開きます。
2. **詳細設定**までスクロールします。**以前のバージョン**から最新の**1.11**リリースを選択し、**ダウンロード**をクリックします。`.zip`ファイルは圧縮されたままにしてください。
3. **WP Admin → プラグイン**に移動し、ページ上部の**プラグインを追加**をクリックしてから、**プラグインをアップロード**をクリックします。
4. `.zip`ファイルを選択して**今すぐインストール**をクリックし、続いて**プラグインを有効化**をクリックします。
5. WCPOSの自動更新は無効にしておいてください。有効にするとWordPressが自動的に2.0に更新します。**プラグイン**ページのWCPOSの行で、**自動更新**列に**自動更新を有効化**と表示されていれば、自動更新は無効です。

WCPOS Proをインストールする場合や、すでにインストールされているバージョンを置き換える場合は、[以前のバージョン](./previous-versions.mdx)を参照してください。

## POS へのアクセス {#accessing-the-pos}

有効化後、次の場所から POS にアクセスできます。

- **Web:** `yourdomain.com/pos`
- **デスクトップ:** [Windows](https://updates.wcpos.com/v1/electron/download/win32-x64)、[Mac（Intel）](https://updates.wcpos.com/v1/electron/download/darwin-x64)、[Mac（Apple Silicon）](https://updates.wcpos.com/v1/electron/download/darwin-arm64)、[Linux](https://updates.wcpos.com/v1/electron/download/linux-x64)
- **モバイル：** [iOS](https://testflight.apple.com/join/JGBdVRrW)、[Android](https://play.google.com/apps/testing/com.wcpos.main)

最小要件を満たし、対応する Web ブラウザを使用することで、WCPOS プラグインをスムーズに利用でき、その潜在能力を最大限に活用して POS 業務を効率的に管理できます。

ご不明な点やサポートが必要な場合は、[Discord チャット](https://wcpos.com/discord)に投稿するか、support@wcpos.com にメールでお気軽にお問い合わせください。
