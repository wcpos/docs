WCPOS 2.0は大規模なアップデートです。レジ、チェックアウト、キャッシュドロワーが新しくなり、プラグインには**WooCommerce 9.0以降**が必要になりました。このページでは、**更新**をクリックする前に確認すべきことを説明します。更新する前にお読みください。

## 今すぐアップグレードできますか？ {#can-you-upgrade-today}

**WP Admin → プラグイン**を開き、WooCommerceのバージョンを確認します。

- **WooCommerce 9.0以降:** [店舗の準備ができている場合](#if-your-store-is-ready)に進みます。
- **9.0未満:** [店舗の準備がまだできていない場合](#if-your-store-isnt-ready-yet)に進みます。先にWCPOSを更新しないでください。

## 店舗の準備ができている場合 {#if-your-store-is-ready}

### 更新をクリックする前に {#before-you-click-update}

1. **すべてのレジを同期します。** 2.0では各レジに新しいローカルデータベースが作成され、1.11のレジから店舗にまだ送信されていないデータは引き継がれません。各レジを開いて同期が完了するまで待ってから更新してください。**店舗の状態 → データベース**で、**送信待ちの変更**が**0**であり、判断を求めるパネルが表示されていないことを確認します。この件数に未完了の注文は含まれません。それぞれを完了するか、注文の**サーバーに保存**を押してください。どちらも現在サインインしているユーザーだけに表示されます。店舗と使用するレジごとに、各レジを使うレジ係についてこの手順を繰り返します。
2. **サイトをバックアップする**か、ホスティング会社に復元ポイントの作成を依頼してください。アップデートによって注文や商品が変更されることはありませんが、大規模なアップデートの前には元に戻せる手段を用意しておきましょう。
3. **店舗が落ち着いている時間を選びます。** すべてのレジが再読み込みされて新しいレジに切り替わります。旧バージョンでチェックアウト中の販売は、最初からやり直す必要があります。
4. **Proライセンスが有効であることを確認します**（WP Admin → POS → 設定 → ライセンス。[WCPOS Proのインストール](/getting-started/pro-license)を参照）。Proのアップデートは、有効なライセンスがある場合にのみ届きます。
5. **割引の扱いを確認します。** レジ係が*負の手数料*を追加して注文の金額を差し引いていた場合、この方法は使えなくなります。2.0では代わりにレジの**割引を追加**を使い、割引を正しく記録できます。[カートの割引](/pos/cart/discounts)を参照してください。
6. **決済端末の拡張機能も更新します。** Stripe Terminal、SumUp、Mollie Terminalにはそれぞれ2.0リリースがあります。古い拡張機能もチェックアウトの**レガシー**タブから引き続き使えますが、新しい決済方法パネルからカードリーダーを操作することはできません。

### 更新する {#updating}

1. **プラグインを更新します。** 無料版のサイトでは**WCPOS**を更新します。Proをお使いの場合は**WCPOS Pro**だけを更新してください。無料プラグインはすでに含まれており、別にインストールされたコピーは無効になります。
2. すべてのデバイスでPOSを開き、初回の同期が完了するまで待ちます。ブラウザーのレジはプラグインの更新後すぐに2.0に切り替わります。デスクトップアプリとモバイルアプリは通常の方法で更新してください。2.0のプラグインに接続した1.11のアプリは、アプリが更新されるまで更新通知の画面で停止します。アプリとプラグインの両方を2.0にする必要があります。

更新後にレジで**AUTH331**が表示される場合は、2.0のアプリがまだ更新されていない店舗に接続しています。プラグインを更新してから再接続してください。[AUTH331](/error-codes/AUTH331)を参照してください。

### 初日に変わること {#what-changes-on-day-one}

- **レジの外観が変わります。** すべての画面で統一されたデザインになり、デバイスのサイズに合わせて表示倍率（コンパクト、標準、ゆったり）を設定できます。フォームや選択画面はポップアップダイアログではなく、パネルとしてスライド表示されます。上部のバーには利用中の店舗名が表示され、店舗に複数のレジがある場合はレジ名も表示されます。カートを左右どちらに表示するか選び、レジ設定でクイックフィルターボタンを並べることもできます。
- **チェックアウトは決済パネルです。** **チェックアウト**を押すとテンキーが開きます。お客様から受け取った金額を入力すると、お釣りが表示されます。現金とカード、または複数のカードに分けて支払えます。レジに接続されたカードリーダーも同じ画面から操作できます（Pro）。独自の決済ページを使う決済ゲートウェイは**レガシー**タブにあります。[チェックアウト](/pos/checkout)を参照してください。
- **すべてのレジにレジセッションがあります。** レジ係が初めてPOSを開くときに、開始時の現金を登録してレジを開きます。**レジを締める**とドロワー内の現金を数えて、番号付きの締め処理として記録します。続いて表示される完了シートから、締めレポート（Zレポート）を印刷できます。この機能は無料プラグインに含まれています。無料プラグインでは、すべてのデバイスで1つのレジを共有します。管理者は**WP Admin → POS → 設定 → レジ**でレジ名と既定の開始金額を設定できます。Proではレジを追加できます。キャッシュドロワーを使わない場合は、POS設定でレジセッションを無効にできます。[一日の締め処理](/pos/reconciliation)を参照してください。
- **レジでのクーポン利用は無料です。** 無料プラグインのレジ係は、カートでWooCommerceのクーポンコードを適用できます。POS内のクーポン画面を閲覧する機能は引き続きPro限定です。
- **負の手数料は使えなくなりました。** **割引を追加**を使用してください。すでに負の手数料が設定された注文には変更はありません。
- **WooCommerce Analyticsでは、POSの注文は支払い完了時に集計されます。** レジで未完了、または一部しか支払われていない注文は、完了するまで売上に表示されません。そのため、これらを含んでいた合計は少なくなります。
- **レシートに表示される情報が増えます。** すべてのレシートにレジ名、ソフトウェアのバージョン、QRコードが表示されます。返金時にはクレジットノートとして専用のレシートが印刷されます。カスタムレシートテンプレートも引き続き使えます。
- **磁気ストライプ式カードリーダーはサポートされなくなりました。** レジでのカード決済には、統合型リーダー（Pro）を使うか、外部カード決済として記録してください。

## 店舗の準備がまだできていない場合 {#if-your-store-isnt-ready-yet}

**WCPOS 1.11を使い続けてください。** 引き続き動作し、2.0のリリース後6か月間は修正も提供されます。

1. **WCPOSとWCPOS Proの自動更新を無効にします。** **WP Admin → プラグイン**で、各プラグインの行に**自動更新を有効化**/**自動更新を無効化**のリンクがあります。*有効化*と表示されていることを確認してください。この手順で自動更新を止めれば、勤務中のレジ係の前に更新を求めるブロック画面が表示されるのを防げます。
2. 準備ができたら、**WooCommerceを9.0以降に更新します**。更新についてはWooCommerceのリリースノートを参照してください。
3. **[店舗の準備ができている場合](#if-your-store-is-ready)に戻ります。**
4. **2.0に移行したら、使用していた自動更新を再び有効にします**。そうしないと、以後の修正が自動で適用されません。

### WooCommerceより先にWCPOSが更新された場合 {#if-wcpos-updated-first}

POSにはWooCommerce 9.0が必要という通知が表示されて停止しますが、データは失われません。WooCommerceを今すぐ更新するか、[WCPOS 1.11を再インストール](/getting-started/previous-versions)して、上記の手順で自動更新を無効にしてください。

## ロールバック {#rolling-back}

### 1.11のレジに未送信の売上が残っている場合 {#unsent-sales}

レジに更新画面が表示され、売上がまだ店舗に届いていません。2.0を開くまでは、そのデバイス上に残っています。店舗に送信するには、次の手順を行います。

1. **そのレジはそのままにしておきます。** アプリを更新しないでください。ブラウザーのレジではページを再読み込みしないでください。どちらも2.0を開き、未送信の売上が消去されます。
2. 店舗に **[1.11のプラグインを再インストール](/getting-started/previous-versions)** します。
3. **ブラウザーのレジではページを再読み込みし、アプリでは終了して再度開きます。** 店舗が再び1.11になったので、レジが再接続して売上を送信します。**店舗の状態 → データベース**で、**送信待ちの変更**が**0**になり、判断を求めるパネルが表示されなくなるまで待ちます。未完了の注文はこの件数に含まれません。それぞれを完了するか、注文の**サーバーに保存**を押してください。これで売上が店舗に保存されます。
4. [更新](#updating)の手順に従って、**もう一度2.0に更新します**。

### 1.11に戻す {#back-to-1-11}

2.0で問題が起きた場合は、まず[Discord](https://wcpos.com/discord)でお知らせください。アップグレード当日の問題は、ロールバックよりも簡単に解決できることが多くあります。

:::warning ロールバックする前に同期してください
1.11に戻すと各レジのローカルデータベースは空の状態から始まり、2.0のレジから店舗にまだ送信されていない売上は1.11から送信できません。すべての2.0のレジで同期を完了してください。**店舗の状態 → データベース**で、**送信待ちの変更**が**0**になり、判断を求めるパネルも未同期の未完了注文もないことを確認します。
:::

**すでに2.0になっているデスクトップアプリまたはモバイルアプリは、1.11のプラグインに接続できません**（[AUTH331](/error-codes/AUTH331)が表示されます）。アプリストアでは以前のバージョンを提供していません。再度アップグレードするまで、そのレジではブラウザーPOSの`yourdomain.com/pos`を使用してください。

ロールバックするには、[1.11のプラグインを再インストール](/getting-started/previous-versions)してください。引き続き1.11のブラウザーのレジとアプリは、これまでどおり動作します。

2.0で作成された注文は通常のWooCommerce注文として、そのまま残ります。2.0で記録されたレジセッションと締め処理もデータベースに残りますが、1.11には表示されません。
