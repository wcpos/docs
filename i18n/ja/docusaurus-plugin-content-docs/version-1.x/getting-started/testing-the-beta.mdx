WCPOS 2.0 は、ブラウザのレジとデスクトップアプリを対象に公開ベータ中です。Android と iOS のアプリはベータテストの終了後に公開されるため、それまではスマートフォンとタブレットを 1.11 のサイトで使い続けてください。ベータ版は、サイトのステージング用コピーや、一時的に止まっても問題のないサイトでのテストを目的としています。正式リリースではなく、WordPress.org では引き続き 1.11 が提供されています。テスターに必要な情報はこのページにすべてまとめています。

## 必要なもの {#what-you-need}

- **WooCommerce 9.0 以降。** それより古いバージョンでは、2.0 は通知を表示して停止します。
- **アプリとプラグインの両方を 2.0 にする必要があります。** 2.0 のアプリは 1.11 のプラグインでは動作せず、1.11 のアプリは 2.0 のプラグインに接続すると更新を求めます。先にプラグインを更新し、その後すべてのレジを更新してください。
- **磁気ストライプカードリーダーは使えません。** 2.0 では試験的なリーダーが削除されます。レジでのカードリーダーは、WCPOS Pro と Stripe Terminal または SumUp を使って接続します。
- **端末拡張機能には WCPOS Pro 2.0 が必要です。** 各カード端末拡張機能には GitHub にベータ版のプレリリースがあります。Pro をインストールした後に手動でインストールしてください: [Stripe Terminal](https://github.com/wcpos/stripe-terminal-for-woocommerce/releases/tag/v2.0.0-beta1)、[SumUp](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases/tag/v2.0.0-beta1)、[Mollie](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases/tag/v2.0.0-beta1)、[Square](https://github.com/wcpos/square-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)、[PayArc](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)、[Windcave](https://github.com/wcpos/windcave-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)、[Mercado Pago](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)。これらの拡張機能の現在の安定版は 1.11 向けです。

## インストールの前に {#before-you-install}

1. **アップグレードの前に、すべてのレジを同期してください。** 2.0 は各レジで新しいローカルデータベースを作成し、1.11 のレジがまだサイトに送信していない販売は引き継ぎません。各レジを 1.11 で開いて同期が完了するのを待ち、それからプラグインを更新してください。1.11 のレジに未送信のまま残っている販売は、アップグレード後に失われます。
2. **サイトをバックアップする**か、ホスティング会社に復元ポイントを作成してもらってください。
3. **落ち着いた時間帯を選んでください。** 各レジは最初に開いたときに新しいレジ画面へ再読み込みされます。1.11 でチェックアウトの途中だった販売は、もう一度打ち直す必要があります。
4. 変更点は[アプリのリリースノート](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.2)で確認してください。レジ画面、チェックアウト、キャッシュドロワーが新しくなり、すべての画面が描き直され、マイナス手数料による割引は「割引を追加」に置き換えられています。

## ベータ版を入手する {#get-the-beta}

**プラグイン（無料版）：** [WCPOS 2.0.0 ベータ 2 リリース](https://github.com/wcpos/woocommerce-pos/releases/tag/v2.0.0-beta.2)から `woocommerce-pos.zip` をダウンロードし、**WordPress 管理画面 → プラグイン → プラグインを追加 → プラグインのアップロード** からインストールして、現在のバージョンを置き換えます。ブラウザのレジは、プラグインが有効になるとすぐに 2.0 に切り替わります。

**プラグイン（Pro）：** [wcpos.com/account/downloads](https://wcpos.com/account/downloads) にサインインし、**WCPOS Pro 2.0 beta** カードから `woocommerce-pos-pro.zip` をダウンロードして（有効なライセンスが必要です）、同じ方法でアップロードします。Pro には無料版プラグインが含まれているため、両方をインストールする必要はありません。

**デスクトップアプリ：** [WCPOS Desktop 2.0.0 ベータ 2 リリース](https://github.com/wcpos/electron/releases/tag/v2.0.0-beta.2)に macOS、Windows、Linux 用のインストーラーがあります。ベータ版のビルドは自動更新されません。以降のベータ版は、同じリリースページから新たにダウンロードしてください。

**iPhone、iPad、Android：** このベータ版には含まれていません。アプリストア向けの 2.0 アプリはベータテストの終了後に公開されます。1.11 のアプリは 2.0 のサイトに接続すると更新のお知らせで止まるため、それまではスマートフォンとタブレットを 1.11 のサイトで使い続けてください。

ベータ版アプリのリリースノートは[アプリリリース](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.2)にあります。プラグインの変更点は、各プラグインのリリースノートに記載されています。

## 1.11 へのロールバック {#rolling-back}

まず [Discord](https://wcpos.com/discord) でお知らせください。ベータ版で起きる問題の多くは、ロールバックよりも早く解決できます。

1. **ロールバックの前に、すべてのレジを同期してください。** 2.0 のレジが送信していないデータは 2.0 のローカルデータベースに残り、1.11 のアプリはそれを開きません。
2. 1.11 のプラグインを再インストールします。無料版は [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) または[以前のバージョン](/getting-started/previous-versions)から、Pro は [wcpos.com/account/downloads](https://wcpos.com/account/downloads)（一覧の最新の 1.11 バージョン）から再インストールします。
3. ベータ版をインストールした場所に、1.11 のデスクトップアプリを再インストールします。2.0 のアプリは 1.11 のプラグインに接続できません。
4. 1.11 のレジは空のローカルデータベースから始まり、サイトから再同期します。2.0 で作成した注文は通常の WooCommerce の注文なので、そのまま残ります。2.0 で記録したレジのセッションと締め処理はデータベースに残りますが、1.11 には表示されません。

## 見つけた問題の報告 {#reporting}

[wcpos/roadmap](https://github.com/wcpos/roadmap/issues/new) に `beta` ラベルを付けて Issue を作成するか、[サポート](https://wcpos.com/support)にご連絡ください。どの部分か（プラグイン、デスクトップ、iOS、Android、ブラウザ）、バージョン、行った操作、期待した結果、実際に起きたことをお知らせください。スクリーンショットや画面に表示されたエラーコードがあると助かります。販売や支払いに関する問題の場合は、注文番号も記載してください。
