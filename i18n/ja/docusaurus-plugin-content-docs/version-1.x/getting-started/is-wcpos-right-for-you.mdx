WCPOSはWooCommerce向けのPOS（販売時点情報管理）システムです。ウェブブラウザー、またはWindows、macOS、Linux用のデスクトップアプリで動作し、iOSおよびAndroidアプリはベータ版です。オンラインストアと同じ商品カタログ、在庫、価格を使って販売でき、すべての売上がWooCommerceの注文として記録されます。無料プラグインでは現金や外部カード決済を受け付け、レシートを印刷できます。WCPOS Proでは、カードリーダー連携、返金、在庫編集、注文履歴、レポート、複数店舗の機能が追加されます。

2025年11月まで、このプラグインはwordpress.orgでWooCommerce POSとして掲載されていました。プラグインのスラッグは今も`woocommerce-pos`で、古いレビュー、フォーラムの投稿、チュートリアルではその名前が使われています。

このページでは、インストール前によく寄せられる質問に答えます。どのような方に適しているか、必要なものや費用、他の選択肢との違いについて説明します。

## WCPOSが適している方 {#who-its-for}

WCPOSは、すでにWooCommerceで販売しており、同じ在庫を使って対面販売も行いたい事業者に適しています。

- **オンラインでも販売している店舗、カウンター、マーケットの出店者、ポップアップストア。** ウェブサイトでもレジでも、商品カタログ、在庫数、注文一覧を一元管理できます。
- **販売データを自社のデータベースで管理したい店舗。** WCPOSはWordPressプラグインです。注文、顧客、商品はサードパーティのサービスではなく、WooCommerceのインストール環境に保存されます。
- **電話注文や業務用の販売窓口。** 既存の顧客を検索して注文を作成し、現金またはカードで支払いを受け付けられます。また、Proでは[メール請求書](/payment/gateways/email-invoice)を送信できます。
- **複数のレジや複数の店舗を運営する事業者。** 各デバイスには商品カタログのローカルコピーが保存されます。Proでは、それぞれのレシート、税ID、ブランド設定を持つ[複数の店舗](/stores)を追加できます。店舗間で在庫は共有されますが、[ATUM](/extensions/atum)を追加すると店舗ごとの在庫を管理できます。

## WCPOSが適していない方 {#who-its-not-for}

- **WooCommerceを利用していない方。** WCPOSを使うには、WooCommerceをインストールしたWordPressサイトが必要です。Shopify、Magento、単独のオンラインショップでは動作しません。
- **法令に適合した認証が今すぐ必要な方。** WCPOSは、フランスのNF525やスペインのVERIFACTUなどの制度に基づく認証を取得していません。[税務コンプライアンス](/reference/fiscal-compliance)では、各国の状況を説明しています。認証が必須の場合、それを回避する方法はありません。
- **インターネットにまったく接続せずに、すべての販売を完了する必要がある方。** 販売を完了するには店舗への接続が必要です。オフラインでも商品を閲覧してカートを作成し、注文を保存できますが、支払い手続きはオンラインに戻るまで保留されます。[オフラインモード](/getting-started/offline)をご覧ください。オフラインでの現金販売の完了は[ロードマップ](/getting-started/roadmap)に掲載されています。
- **セルフサービス端末や、販売業者が提供するハードウェア一式が必要な方。** WCPOSはお手持ちのハードウェアで動作します。キオスクモードはなく、決済端末やタブレットも販売していません。

## 必要なもの {#what-you-need}

| 必要条件 | 最低要件 |
|---|---|
| WordPress | 5.6 |
| WooCommerce | 5.3 |
| PHP | 7.4（8.xを推奨） |
| デバイス | 最新のウェブブラウザー、またはWindows、macOS、Linux用のデスクトップアプリ。iOSおよびAndroidアプリはベータ版です |

レシートプリンター、バーコードスキャナー、キャッシュドロワーは任意です。[インストール要件](/getting-started/installation)と[ハードウェア](/hardware)をご覧ください。

## 費用 {#what-it-costs}

- **WCPOS（無料プラグイン）：** $0。GPL-3.0のオープンソースで、[WordPressプラグインディレクトリー](https://wordpress.org/plugins/woocommerce-pos/)からインストールできます。販売の受付、レシートの印刷、WooCommerceへの注文の同期ができ、WCPOSによる取引手数料はかかりません。
- **WCPOS Pro：** 1サイトあたり年額$129、または1サイトあたり買い切りの永久ライセンス$399です。どちらもライセンス期間中のアップデートとサポートが含まれます。有効化については[Proライセンス](/getting-started/pro-license)、全機能の比較については[無料版とPro版](/getting-started/free-vs-pro)をご覧ください。

価格は2026年5月現在のもので、変更される場合があります。カード決済手数料は決済ゲートウェイが定めるもので、WCPOSが設定するものではありません。

## 他の選択肢との比較 {#how-it-compares}

[wcpos.com/compare](https://wcpos.com/compare)では、WooCommerce向けの主要なPOS製品それぞれと比較できます：[Oliver POS](https://wcpos.com/compare/oliver-pos)、[WooCommerce公式POS](https://wcpos.com/compare/woocommerce-pos)、[Square](https://wcpos.com/compare/square)、[Jovvie](https://wcpos.com/compare/jovvie)、[Vitepos](https://wcpos.com/compare/vitepos)、[YITH Point of Sale](https://wcpos.com/compare/yith-pos)、[FooSales](https://wcpos.com/compare/foosales)。各ページはWCPOSの開発元が作成し、他社の公式価格ページとwordpress.orgの情報に基づいています。作成日を明記し、他社製品のほうが適している場合も説明しています。

## 試してみる {#try-it}

[デモ店舗](https://demo.wcpos.com/pos)ではWCPOS Proを利用でき、ログイン情報は`demo` / `demo`です。Pro限定の画面も確認できます。すでにWooCommerceを利用しているサイトなら、無料プラグインのインストールは約5分で完了します。
