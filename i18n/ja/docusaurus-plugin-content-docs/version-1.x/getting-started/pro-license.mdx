:::info Pro 機能
[WCPOS Pro](https://wcpos.com/pro) は、WCPOS の管理画面、追加の決済ゲートウェイ、その他の Pro 限定機能を提供する有料プラグインです。

**v1.8 以降、Pro はスタンドアロンプラグインです** — 無料の [WCPOS プラグイン](https://wordpress.org/plugins/woocommerce-pos/) を併せてインストールする必要はありません。
:::

## Pro に含まれる機能 {#whats-included-in-pro}

WCPOS Pro では、以下の追加機能が利用できるようになります:

- **商品画面** - POS から直接、在庫数や価格を編集
- **注文画面** - 注文履歴の閲覧と管理
- **顧客画面** - 顧客情報の追加と編集
- **レポート画面** - 日次売上レポートの作成
- **追加の決済ゲートウェイ** - Stripe Terminal、SumUp、カスタムゲートウェイ

## インストール {#installation}

WCPOS Pro のライセンスをご購入済みの場合は、以下の手順でプラグインをインストールし、有効化してください:

:::note 旧バージョンからのアップグレードですか？
以前、無料の WCPOS プラグインと旧 Pro アドオンの両方をインストールしていた場合は、新しいスタンドアロン Pro プラグインを有効化する前に、**無料プラグインを無効化して削除してください**。両方を同時に使用すると、*「Invalid response fetching remote state」* や致命的な *「Class not found」* エラーなどの有効化エラーが発生する場合があります。
:::

1. [https://wcpos.com/my-account/](https://wcpos.com/my-account/) にアクセスします。
2. **Downloads** の下で、ダウンロードリンクをクリックし、プラグインをデスクトップに保存します。
3. 次に、サイトにログインし、`WP Admin > Plugins > Add Plugin > Upload Plugin` に移動します。
4. デスクトップからプラグインの zip ファイルをアップロードして有効化します。
5. 次に、`WP Admin > POS > Settings > License` に移動し、ライセンスキーとライセンスメールアドレスを入力して有効化を完了します。

![My Downloads](https://wcpos.com/wp-content/uploads/2014/07/my-download.png "アカウントページから WCPOS Pro をダウンロードできます")

## アップデート {#updates}

新しいバージョンが公開されると、他のプラグインと同様に更新ダッシュボードに表示されます。最新バージョンは[アカウントページ](https://wcpos.com/my-account/)からもダウンロードできます。

## Pro のアンインストールとデータ {#uninstalling}

Pro プラグインをアンインストールすると、Pro 自身の運用データは削除されますが、**Pro の設定（ライセンスキーを含む）とストア設定は保持される**ため、再インストールすると中断したところから再開できます。共有される翻訳データは、**無料**プラグインもアンインストールされたときにのみ削除されるため、Pro だけを削除しても無料プラグインが影響を受けることはありません。

設定、ライセンス、ストア設定も含めて本当にまっさらな状態にしたい場合は、アンインストール前に `wcpos_remove_all_data` を定義して完全消去を選択してください。それがなければ、アンインストールは安全で元に戻せます。

## トラブルシューティング {#troubleshooting}

### 有効化の失敗 {#activation-failures}

- **「Invalid licence key」** — 貼り付け時に末尾のスペースが含まれていないか再確認し、メールアドレスが購入時に使用したものと一致しているか確認してください。
- **「Licence limit reached」** — 既定では、ライセンスは **2 つのドメイン**で有効化できます（本番サイト 1 つとステージングサイト 1 つを想定）。**サブドメインは別々の有効化としてカウントされます** — `example.com`、`staging.example.com`、`dev.example.com` は 3 つです。これは、dev/test/live 環境が必須の Pantheon のようなホストでよく発生します。使用していないサイトは[アカウントページ](https://wcpos.com/my-account/)から無効化するか、**support@wcpos.com** にメールしてください — 追加の有効化はリクエストに応じて通常付与されます。

### ライセンスの有効期限切れ {#expired-licence}

- ライセンスの有効期限が切れても Pro 機能は引き続き有効ですが、アップデートは受け取れなくなります。
- [アカウントページ](https://wcpos.com/my-account/)から更新してください — 既存のキーはそのまま使用できます。

### ドメインの移行 {#domain-transfers}

- サイトを新しいドメインに移行した場合は、まず旧ドメインでライセンスを無効化してから、新しいドメインで再度有効化してください。
- 旧ドメインにアクセスできなくなった場合は、**support@wcpos.com** に連絡して有効化をリセットしてください。

### ライセンスサーバーへの接続 {#licence-server-connectivity}

- 有効化には、WordPress サーバーから WCPOS ライセンスサーバーへの接続が必要です。
- 有効化がエラーなく失敗する場合は、ホストのファイアウォールやセキュリティプラグインによって外部への HTTPS リクエストがブロックされていないか確認してください。
- 一部のマネージドホストでは外部 API 呼び出しが既定でブロックされています — ホストに連絡して `wcpos.com` をホワイトリストに追加してください。

### ライセンスステータスの確認 {#checking-licence-status}

- `WP Admin > POS > Settings > License` で現在の有効化ステータスを確認できます。
- [アカウントページ](https://wcpos.com/my-account/)には、有効なサイトの一覧と有効期限が表示されます。

## ライセンスの購入 {#purchase-a-license}

Pro ライセンスの購入は [wcpos.com/pro](https://wcpos.com/pro) にアクセスしてください。

:::note 購入とアップグレードはウェブサイト上で行います
アプリ内に「Pro にアップグレード」ボタンはありません。購入、プランのアップグレード、更新はすべて [wcpos.com](https://wcpos.com/pro) と[アカウントページ](https://wcpos.com/my-account/)で行います。購入後は、[上記の手順](#installation)に従って Pro をインストールしてください。
:::
