:::info Pro 機能
[WCPOS Pro](https://wcpos.com/pro) は、WCPOS の管理画面、追加の決済ゲートウェイ、その他の Pro 限定機能を提供する有料プラグインです。

**v1.8 以降、Pro はスタンドアロンプラグインです** — 無料の [WCPOS プラグイン](https://wordpress.org/plugins/woocommerce-pos/) を併せてインストールする必要はありません。
:::

## Pro に含まれる機能 {#whats-included-in-pro}

WCPOS Pro では、次の追加機能を利用できます。

- **商品画面** - POS から在庫数や価格を直接編集できます。
- **注文画面** - 注文履歴を表示、管理できます。
- **顧客画面** - 顧客情報を追加、編集できます。
- **レポート画面** - 日次売上レポートを作成できます。
- **追加の決済ゲートウェイ** - Stripe Terminal、SumUp、カスタムゲートウェイに対応します。

## インストール {#installation}

WCPOS Pro のライセンスを購入済みの場合は、以下の手順でプラグインをインストールして有効化してください。

:::note 以前のバージョンからアップグレードしますか？
以前、無料の WCPOS プラグインと旧 Pro アドオンの両方をインストールしていた場合は、新しい単体版 Pro プラグインを有効化する前に、**無料プラグインを無効化して削除**してください。両方を同時に使用すると、*「Invalid response fetching remote state」* や致命的な *「Class not found」* エラーなどの有効化エラーが発生することがあります。
:::

1. こちらにアクセスしてください: [https://wcpos.com/account/downloads](https://wcpos.com/account/downloads)
2. **ダウンロード**でダウンロードリンクをクリックし、プラグインをデスクトップに保存します。
3. サイトに移動してログインし、`WP Admin > プラグイン > Add Plugin > プラグインのアップロード` を開きます。
4. デスクトップからプラグインの ZIP ファイルをアップロードして有効化します。
5. 次に、`WP Admin > POS > 設定 > License` を開き、[ライセンスページ](https://wcpos.com/account/licenses)に表示されているライセンスキーとライセンス用メールアドレスを入力して、有効化を完了します。

## アップデート {#updates}

新しいバージョンが公開されると、他のプラグインと同様にアップデートダッシュボードに表示されます。[アカウントページ](https://wcpos.com/account/downloads)から最新バージョンをダウンロードすることもできます。

## Pro のアンインストールとデータ {#uninstalling}

Pro プラグインをアンインストールすると、Pro 固有の運用データは削除されますが、**Pro の設定（ライセンスキーを含む）と店舗設定は保持される**ため、再インストール後に続きから利用できます。共有翻訳データは**無料**プラグインもアンインストールされた場合にのみ削除されるため、Pro だけを削除しても無料プラグインには影響しません。

設定、ライセンス、店舗設定も含めて完全に初期化する場合は、アンインストール前に `wcpos_remove_all_data` を定義して全データの削除を有効にしてください。定義しなければ、安全に元に戻せる形でアンインストールされます。

## トラブルシューティング {#troubleshooting}

### 有効化の失敗 {#activation-failures}

- **「Invalid licence key」** — 貼り付け時に末尾の空白が入っていないか確認し、購入時に使用したメールアドレスと一致していることを確認してください。
- **「ライセンス上限に達しました」** — デフォルトでは、ライセンスは**2つのドメイン**で有効化できます（本番サイト1つとステージングサイト1つを想定）。**サブドメインも別の有効化として数えられます** — `example.com`、`staging.example.com`、`dev.example.com`は3つとして扱われます。開発・テスト・本番環境が必須のPantheonなどのホストでは、これが原因となることがあります。使用していないサイトを[アカウントページ](https://wcpos.com/account/licenses)で無効化するか、**support@wcpos.com**にメールでお問い合わせください。追加の有効化は通常、依頼に応じて承認されます。

### ライセンスの有効期限切れ {#expired-licence}

- ライセンスの有効期限が切れても Pro 機能は引き続き利用できますが、アップデートは受け取れなくなります。
- [アカウントページ](https://wcpos.com/account/licenses)から更新してください。既存のキーは変わりません。

### ドメインの移行 {#domain-transfers}

- サイトを新しいドメインに移行した場合は、まず旧ドメインでライセンスを無効化してから、新しいドメインで再度有効化してください。
- 旧ドメインにアクセスできなくなった場合は、**support@wcpos.com** に連絡して有効化をリセットしてください。

### ライセンスサーバーへの接続 {#licence-server-connectivity}

- 有効化には、WordPress サーバーから WCPOS ライセンスサーバーへの接続が必要です。
- 有効化がエラーなく失敗する場合は、ホストのファイアウォールやセキュリティプラグインによって外部への HTTPS リクエストがブロックされていないか確認してください。
- 一部のマネージドホストでは外部 API 呼び出しが既定でブロックされています。ホストに連絡して `wcpos.com` を許可リストに追加してください。

### ライセンス状態の確認 {#checking-licence-status}

- `WP Admin > POS > 設定 > License` で現在の有効化状態を確認できます。
- [アカウントページ](https://wcpos.com/account/licenses)には、有効なサイトの一覧と有効期限が表示されます。

## ライセンスの購入 {#purchase-a-license}

Pro ライセンスの購入は [wcpos.com/pro](https://wcpos.com/pro) にアクセスしてください。

:::note 購入とアップグレードはウェブサイト上で行います
アプリ内に「Pro にアップグレード」ボタンはありません。購入、プランのアップグレード、更新はすべて [wcpos.com](https://wcpos.com/pro) と[アカウントページ](https://wcpos.com/account/licenses)で行います。購入後は、[上記の手順](#installation)に従って Pro をインストールしてください。
:::
