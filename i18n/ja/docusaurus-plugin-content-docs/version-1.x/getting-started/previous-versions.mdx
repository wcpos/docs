## 以前のバージョンを再インストールする {#re-installing-a-previous-version}

プラグインを以前のバージョンに戻すには、自動更新を無効にして、必要なバージョンをダウンロードし、現在のバージョンに上書きアップロードします。この手順で何も削除されないため、注文、設定、レシートテンプレートはそのまま残ります。

:::warning 先にプラグインを削除しないでください
`.zip`を現在のプラグインに上書きアップロードしてください。これですべてが保持されます。2.0では、**プラグイン**から削除するとWCPOSのクリーンアップが実行され、すべてのレジ係がログアウトされるため、各レジで再ログインが必要になります。また、各レジが再構築する同期データも消去されます。削除する必要はありません。
:::

2.0から戻す場合は、先に[ロールバック](/getting-started/upgrading-to-2#rolling-back)をお読みください。WCPOS Proをお使いの場合は、WCPOS Proだけをロールバックしてください。無料プラグインはその中に含まれています。

### 自動更新を無効にする {#turn-off-auto-updates}

自動更新が有効だと、WordPressが最新バージョンを再び自動でインストールします。

1. **WP Admin → プラグイン**に移動します。
2. WCPOSの行（またはWCPOS Proの行）で、**自動更新**列を確認します。**自動更新を無効化**と表示されている場合はクリックしてください。

### 必要なバージョンをダウンロードする {#download}

`.zip`ファイルは圧縮されたままにしてください。WordPressがインストールするのはフォルダーではなく`.zip`です。

**WCPOS:**

1. WordPress.orgの[WCPOS詳細ページ](https://wordpress.org/plugins/woocommerce-pos/advanced/)を開きます。
2. **詳細設定**までスクロールします。**以前のバージョン**から必要なバージョンを選択します。
3. **ダウンロード**をクリックします。

**WCPOS Pro:**

1. [wcpos.com](https://wcpos.com/account/downloads)でアカウントにサインインし、**ダウンロード**を開きます。
2. **バージョン履歴**から必要なバージョンを探します。
3. その行の**ダウンロード**をクリックします。

2.0から戻す場合は、古い1.xではなく、最新の**1.11**リリースを選択してください。

### 現在のバージョンに上書きアップロードする {#install}

1. **WP Admin → プラグイン**に移動し、ページ上部の**プラグインを追加**をクリックします。
2. **プラグインをアップロード**をクリックし、ダウンロードした`.zip`ファイルを選択して、**今すぐインストール**をクリックします。
3. WordPressに**このプラグインはすでにインストールされています。**と表示され、**現在**と**アップロード済み**のバージョンが並んで表示されます。**アップロード済み**に必要なバージョンが表示されていることを確認します。
4. **現在のバージョンをアップロード済みのバージョンに置き換える**をクリックします。
5. WordPressに**プラグインのダウングレードに成功しました。** と表示されます。**プラグインを有効化**が表示された場合はクリックしてください。表示されない場合、プラグインはすでに有効で、そのまま有効な状態です。

再び更新する準備ができるまでは自動更新を無効にしておき、準備ができたら有効に戻してください。そうしないと、以後の修正が自動で適用されません。

再インストール中に問題が発生した場合や、サポートが必要な場合は、support@wcpos.com までお問い合わせください。
