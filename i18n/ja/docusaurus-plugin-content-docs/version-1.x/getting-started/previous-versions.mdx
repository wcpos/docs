## 以前のバージョンを再インストールする {#re-installing-a-previous-version}

WCPOSプラグインの以前のバージョンに戻す必要がある場合は、以下の手順に従ってください。

1. WCPOSのためのWordPress.orgページの[高度なビュー](https://wordpress.org/plugins/woocommerce-pos/advanced/)を訪問します。

2. 下にスクロールして**詳細設定**セクションを開き、**以前のバージョン**の選択メニューを見つけます。

3. 選択メニューを開くと、利用可能なプラグインのバージョン一覧が表示されます。インストールするバージョンを探し、横にある**ダウンロード**ボタンをクリックします。ダウンロードしたファイルをデスクトップなどの分かりやすい場所に保存します。

4. WordPress 管理画面にログインします。

5. 左側のメニューで**プラグイン**をクリックして、**プラグイン**ページを開きます。

6. 現在の WCPOS プラグインを無効化して削除します。WordPress からプラグインが削除されますが、データは失われないのでご安心ください。

7. ページ上部の**プラグインを追加**ボタンをクリックします。

8. **プラグインの追加**ページで、**プラグインのアップロード**ボタンをクリックします。

9. 先ほどダウンロードしたプラグインファイルを、デスクトップまたは保存先から選択します。

10. **今すぐインストール**ボタンをクリックし、インストールが完了するまで待ちます。

11. インストール完了後、**有効化**ボタンをクリックして以前のバージョンの WCPOS プラグインを有効化します。

これで以前のバージョンの WCPOS プラグインの再インストールは完了です。

再インストール中に問題が発生した場合や、サポートが必要な場合は、support@wcpos.com までお問い合わせください。
