:::info Pro 機能
注文画面には [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。
:::

注文画面は、POS 内で直接注文履歴へのアクセスを提供します。過去の注文を表示し、領収書を再印刷し、WooCommerce 管理画面に切り替えることなく注文詳細を管理できます。

{/* Screenshot: orders-screen.png */}

## インターフェースの概要 {#interface-overview}

### 検索とフィルター {#search--filters}

画面の上部にあります：

- **検索バー** - 注文番号、顧客名などで注文を探します。
- **ステータスフィルター** - 注文のステータスでフィルタリングします（完了、処理中など）
- **顧客フィルター** - 顧客でフィルタリングします
- **キャッシャーフィルター** - 注文を処理した人でフィルタリングします
- **店舗フィルター** - 店舗でフィルタリングします（複数店舗設定の場合）
- **日付範囲** - 日付でフィルタリングします

アクティブなフィルターは青いバッジとして表示され、×をクリックすることで削除できます。

### 注文テーブル {#orders-table}

メイン領域には次のように注文が表示されます：

- **ステータスアイコン** - ビジュアルインジケーター（✓ 完了、🕐 保留中、🛒 オープン）
- **注文番号** - 一意の注文 ID
- **顧客** - 顧客名（または「ゲスト」）
- **請求先住所** - 顧客の請求情報
- **ノートインジケーター** - 注文にノートがあるときに表示される吹き出し
- **作成日** - 相対的なタイムスタンプ（「2 時間前」）
- **キャッシャー** - 注文を処理した人
- **支払い方法** - 現金、カードなど
- **合計** - 注文の合計金額
- **アクション** - 三点メニュー

:::note フィルタリングとページ送りは店舗全体が対象です
ステータス、顧客、レジ係、店舗、期間での絞り込みは**サーバー**上で実行されるため、端末に保存済みの注文だけでなく、すべての注文が対象になります。スクロールするとリストにさらに読み込まれます。列見出しをクリックすると並べ替えられます。
:::

### フッター {#footer}

- 注文数と同期ボタン (<Icon name="arrow-rotate-right" />)。**長押し**でクリアおよびリフレッシュオプション

## 主な機能 {#key-features}

### 注文検索 {#order-lookup}

次の方法で注文を迅速に見つけます：

- **注文番号検索**
- **顧客名検索**
- **日付範囲フィルタリング**
- **ステータスフィルタリング**
- **キャッシャーフィルタリング**

### 領収書の再印刷 {#receipt-reprinting}

任意の注文について、次の操作が可能です：

1. 三点メニューをクリックします
2. 領収書オプションを選択
3. 領収書を表示、印刷、またはメール送信

### 注文詳細 {#order-details}

注文をクリックすると次の情報が表示されます：

- 完全な品目詳細
- 顧客情報
- 支払い詳細
- 注文ノート
- メタデータ

### 利用可能な列 {#available-columns}

#### 必須の列 {#essential-columns}

ほとんどの店舗が表示したままにしておく中心的な列です。注文を識別し、操作できるようにします。

| 列 | 説明 |
|--------|-------------|
| **ステータス** | 注文ステータスアイコン |
| **注文番号** | 一意の注文 ID |
| **顧客** | 顧客名と詳細 |
| **合計** | 注文の合計 |
| **領収書** | 即時領収書アクセス |
| **アクション** | 編集、表示など |

#### 任意の列 {#optional-columns}

必要に応じてオンにできる追加の詳細です。住所、日付、注文メタデータを表示します。

| 列 | 説明 |
|--------|-------------|
| **請求先住所** | 請求情報 |
| **配送先住所** | 配送情報 |
| **顧客ノート** | 顧客からのノート |
| **作成日** | 注文が行われた日 |
| **更新日** | 最後の変更 |
| **完了日** | 注文が完了した日 |
| **支払日** | 支払いを受け取った日 |
| **作成元** | 注文のソース（POS、オンラインなど） |
| **キャッシャー** | 注文を処理した人 |
| **支払い方法** | 使用された支払いタイプ |

## 注文アクション {#order-actions}

三点メニュー（⋮）をクリックすると、次の操作ができます：

- **表示** - 注文の詳細を確認
- **編集** - 注文をカートに戻さず、フォームで詳細を変更します
- **再開** - 注文をカートに戻し、明細を変更して再度支払いを受けます
- **領収書** - 領収書を表示/印刷/メール送信
- **返金** - 注文の全額または一部を返金します（[返金](#refunds)を参照）
- **同期** - サーバーから注文を更新します
- **削除** - 注文を削除します

### 注文の編集 {#editing-orders}

三点メニューから **編集** を選択すると、フォームで注文の詳細を変更できます。対象はステータス、顧客、顧客ノート、請求先住所と配送先住所、支払い方法、通貨、取引 ID、税 ID、メタデータです。ここでは明細を変更できません。明細を変更するには注文を再開してください。

### 注文の再開 {#reopening-orders}

三点メニューから **再開** を選択すると、注文がカートに戻り、次の操作ができます。

- 明細の追加または削除
- 数量または価格の変更
- 顧客の更新
- ノートまたはメタデータの追加

カートに入っている間、注文のステータスは **POS - オープン** になります。変更後、もう一度チェックアウトに進み、更新した注文を完了してください。

### 注文ステータス {#order-statuses}

POS 注文では、WooCommerce の標準注文ステータスに加えて、独自のステータスが1つ使用されます。

:::info 一般的な注文の流れ
注文は通常、**POS - オープン → 支払い待ち → 処理中 → 完了** の順に進み、**キャンセル** または **返金済み** で終了することもあります。ほとんどの POS 注文は販売時に支払いを受け取るため、直接 **完了** になります。
:::

| ステータス | 説明 |
|--------|-------------|
| **POS - オープン** | POS から保存された未完了の注文（一時保存・保留中の注文） |
| **支払い待ち** | 支払いを待っている状態 |
| **処理中** | 支払いを受け取り、注文を処理している状態 |
| **完了** | 注文の処理がすべて完了した状態 |
| **キャンセル** | 注文がキャンセルされた状態 |
| **返金済み** | 注文が全額返金された状態 |

ほとんどの POS 注文は販売時に支払いを受け取るため、直接 **完了** になります。未完了の注文（カートの **サーバーに保存** ボタンで保存した注文）は **POS - オープン** ステータスになり、後で再開して取引を続けられます。

### 返金 {#refunds}

POS から直接、全額または一部の返金を行えます。ゲートウェイが対応している場合は元の支払い方法に返金でき、レジから現金で返金することもできます。注文の三点メニュー（⋮）を開いて **払い戻し** を選択するか、注文表示画面のフッターにある **払い戻し** ボタンをクリックします。

返金先、一部返金、レシートでの返金の表示など、詳しい手順については[返金](/1.x/orders/refunds)を参照してください。
