:::info Pro機能
マルチ店舗機能には [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。
:::

WCPOS Pro では、単一の WooCommerce インストール内に複数の店舗を作成できます。各店舗に独自の住所、ロゴ、設定を持たせることができ、複数の実店舗を運営している場合に便利です。

## 店舗で設定できる項目 {#what-stores-provide}

各店舗では以下を設定できます。

- **店舗名と住所** — レシートやレポートに使用されます
- **店舗ロゴ** — 印刷したレシートに表示されます
- **税率** — 店舗の所在地によって税務上の要件が異なる場合があります
- **レジ係の割り当て** — どのレジ係がどの店舗で勤務するかを管理します

## 店舗の設定 {#setting-up-stores}

Pro を有効にすると、WP Admin の POS メニューの下に**店舗**サブメニューが追加されます。ここから各店舗を作成し、住所、ロゴ、税務番号、サインインできるレジ係を設定できます。詳しい手順は、**[店舗の設定](/1.x/stores/setup)** を参照してください。

レジ係は POS にログインするときに、業務を行う店舗を選択します。これにより、レシートに表示される店舗情報と、レポートに適用される店舗フィルターが決まります。

## 店舗でのフィルタリング {#filtering-by-store}

複数の店舗を設定すると、POS の各画面で店舗フィルターが表示されます。

- **[注文](/1.x/orders)** — 店舗ごとに注文履歴をフィルタリングします
- **[レポート](/1.x/reports)** — 特定の店舗の日次レポートを生成します
- **[レシート](/1.x/receipts/at-checkout)** — 正しい店舗の住所とロゴがレシートに自動表示されます

## 店舗別価格設定 {#store-specific-pricing}

WCPOS Pro は**店舗ごとに異なる価格**の設定に対応しています。商品とバリエーションのどちらも、店舗別に通常価格とセール価格を設定できます。

レジ係が特定の店舗で操作しているときは、POS がその店舗の価格を自動的に使用します。店舗別の価格が設定されていない場合は、WooCommerce のデフォルト価格が使用されます。

## 在庫管理 {#inventory-management}

デフォルトでは、すべての店舗が同じWooCommerceの在庫数を共有します。拠点ごとの在庫管理を行うには、WCPOS Proが[ATUM Inventory Management](https://www.atum.org/)プラグインと連携します：

1. WooCommerceサイトにATUMプラグインをインストールして設定します
2. ATUMで在庫ロケーションを作成します
3. WCPOS Proで、各店舗をATUMの在庫ロケーションに関連付けます
4. 注文が行われると、対応するロケーションの在庫数が更新されます

### 代替方法：WordPressマルチサイト {#alternative-wordpress-multisite}

ATUMを使用せずに在庫を完全に分離するには、[WordPressマルチサイト](https://developer.wordpress.org/advanced-administration/multisite/create-network/)を利用できます：

1. 各店舗拠点ごとに個別のWordPressサイトを作成します
2. 各サイトにWooCommerceとWCPOSをインストールします
3. 各サイトは独立した商品カタログと在庫数を管理します

この方法では完全に分離された環境を構築できますが、複数のWooCommerceインストールを管理する必要があります。

## 既知の制限事項 {#known-limitations}

- **単一のWooCommerceインスタンス** — 店舗は1つのWooCommerceインストール内にある拠点であり、個別のショップではありません
- **店舗ごとの商品表示制御なし** — すべての店舗で同じ商品カタログが表示されます
