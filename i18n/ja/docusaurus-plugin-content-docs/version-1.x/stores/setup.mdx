:::info Pro機能
マルチ店舗には [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。Pro がない場合、WCPOS は WooCommerce の一般設定に基づく単一の仮想店舗として動作し、店舗画面は表示されません。
:::

このページでは、店舗の作成手順を最初から最後まで説明します。概要（マルチ店舗の機能、店舗別価格設定、ATUM 連携）については、まず[マルチ店舗](/1.x/stores)をご覧ください。

## 始める前に {#before-you-start}

- **WCPOS Pro がインストールされ、ライセンスが有効化されていること。** Pro を有効化すると、WP Admin の POS 配下に **店舗** サブメニューが追加されます。
- **この店舗で働くレジ係が WordPress アカウントを持っていること**。そのアカウントには、*WCPOS へのアクセス* 権限を含むロールが必要です。まだ設定していない場合は、[アクセス設定](/1.x/settings/wp-admin/access)をご覧ください。
- *（任意）* **アップロード用のロゴファイル** — PNG または JPG、300×300 以上を推奨します。

## 店舗を作成する {#create-the-store}

<Steps>
  <StepCard number="1" title="店舗一覧を開く">

WP Admin で **POS → 店舗** に移動します。既存の店舗がある場合は、**店舗**、**住所**、**許可ユーザー** の列と、各行に **POS を開く** ボタンが表示されます。

初めての店舗で、Pro を有効化したばかりの場合、一覧は空です。ページヘッダーの **新しい店舗を追加** をクリックしてください。

  </StepCard>
  <StepCard number="2" title="店舗名を設定する">

エディターの上部で **店舗名** を設定します。この名前はレシート、ログイン時の店舗選択、POS 全体の店舗フィルターに表示されます。必須項目です。

例：*「メインストリートカフェ」*、*「倉庫 — 受け取り」*、*「マーケット出店 #3」*。

  </StepCard>
  <StepCard number="3" title="メインカラムを入力する">

エディターの左側には、レシートに記載される情報がまとめられています：

- **店舗ロゴ** — WP メディアライブラリからアップロードします。サイトのカスタマイザーでロゴを設定している場合は、*「店舗ロゴが未設定のときにサイトロゴを使用する」* トグルで、そのロゴを代わりに使用できます。
- **住所** — 住所 1、住所 2、市区町村、都道府県、郵便番号、国。国は入力に応じて候補を検索するドロップダウンです。
- **連絡先** — Web アドレス、電話番号、メールアドレス。
- **レシートメッセージ** — *結語*、*返品ポリシー*、*フッター*。プレーンテキストに加え、簡単な HTML も使用できます（`<strong>`、 `<em>`、 `<b>`、 `<i>`、 `<br>`、 `<p>`）。
- **レシートテンプレート** — *「店舗別レシートテンプレート」* トグルを **オフ** のままにすると、**POS → テンプレート** のサイト全体のテンプレートリストが継承されます。**オン** にすると、この店舗用にカスタムセットを選択できます。カスタムセットを選択すると、ドラッグハンドルで並べ替えられます。
- **レシートプレビュー** — テンプレートセレクターと「サンプルデータ / 注文」の切り替えを備えたライブプレビューです。保存前にレシートの実際の見た目を確認できます。

</StepCard>
  <StepCard number="4" title="サイドバーの設定">

右側のカラムには、レシートには表示されない店舗ごとの設定があります：

- **許可ユーザー** — *WCPOS へのアクセス* 権限を含むロールを持つすべての WordPress ユーザーが、チェックボックス付きで表示されます。この店舗へのサインインを許可するレジ係にチェックを入れてください。**リストを空のままにすると、POS を利用できるすべてのユーザーが許可されます** — 単一店舗のサイトに便利です。
- **税率** — *税金の計算基準* ドロップダウンで、**この店舗の住所** *（デフォルト）* または **基本所在地** を選択します。下の表には、選択した住所に適用される税率が税区分ごとに表示されます。この表は読み取り専用なので、実際の税率は **WooCommerce → 設定 → 税** で設定してください。
- **税ID** — 店舗ごとの VAT、ABN、GSTIN などを登録するための、追加可能な行（種類 / 値 / 国 / ラベル）です。空のままにすると、サイト全体の[店舗税ID](/1.x/settings/wp-admin/store-tax-ids)が使用されます。
- **店舗設定** — 通貨、通貨の位置、ロケール、タイムゾーン。デフォルトではサイトの値が適用されます。この店舗でサイトのデフォルトと異なる設定が必要な場合のみ上書きしてください。
- **営業時間** — 曜日ごとの時間帯と、自由入力のメモ欄です。任意項目で、一部のテンプレートで使用されます。

</StepCard>
  <StepCard number="5" title="保存" isLast>

新規店舗では、初めて保存するまで **作成** ボタンが表示されます。**作成** をクリックしてください。

保存後、ページは自動保存に切り替わります。編集内容は少し時間を置いて自動保存され、画面の隅に *保存中… → 保存済み* と表示されます。いつでもページを離れることができ、変更は保持されます。未保存の変更がある状態で閉じようとすると、ブラウザに警告が表示されます。

  </StepCard>
</Steps>

## ログイン時にレジ係に表示される内容 {#what-cashiers-see-at-login}

レジ係がサインインすると、POS に **店舗選択画面** が表示され、そのレジ係が利用を許可されているすべての店舗が一覧表示されます：

- **利用を許可された店舗が一つの場合** — その店舗が自動選択され、**POS を開く** ボタンがすぐに有効になります。レジ係がこれから利用する店舗を確認できるよう、店舗選択画面は引き続き表示されます。
- **利用を許可された店舗が複数の場合** — 店舗選択画面にラジオボタンのリストが表示されます。店舗を選択してから **POS を開く** をクリックします。
- **利用を許可された店舗がない場合** — 店舗選択画面は空になります。レジ係を店舗の *許可ユーザー* リストに追加するか、リストを空のままにして全員を許可してください。

選択した店舗は、POS 起動時に `?store={id}` として URL に追加され、そのセッション中に作成されたすべての注文に記録されます（`_pos_store` 注文メタ）。これにより、店舗別レポート、注文画面の店舗フィルター、レシートへの適切なロゴと住所の表示、店舗別価格設定が機能します。

## 店舗別価格設定 {#per-store-pricing}

WCPOS Pro には、ATUM とは独立した標準の店舗別価格設定機能があります。各商品（およびバリエーション）の編集画面で、**価格** タブと **税** タブに店舗ごとの上書き設定が追加されます：

1. WP Admin → 商品 → 編集 から商品を開きます。
2. **価格** タブで、上書きしたい店舗の *「店舗別価格を設定」* チェックボックスをオンにします。
3. その店舗の通常価格（必要に応じてセール価格も）を入力します。
4. 商品を保存します。

レジ係がその店舗で操作している場合、POS は店舗別価格を使用します。上書き設定のない店舗で操作している場合は、WooCommerce の標準価格が適用されます。

**税** タブでも同じ方法で、店舗ごとの税ステータス / 税クラスを設定できます。ある店舗が免税地域にあり、別の店舗はそうでない場合に便利です。

:::tip ATUM と標準の店舗別価格設定の比較
WCPOS 標準の店舗別価格設定は、在庫を **共有** しつつ、店舗ごとに異なる販売価格を設定したい場合に適しています。**店舗ごとの在庫数** も必要な場合は、[ATUM Multi-Inventory](/1.x/extensions/atum) 連携をインストールしてください。店舗エディターに *在庫ロケーション* ドロップダウンと *価格ソース* セレクター（デフォルト / WCPOS Pro / ATUM）が追加され、店舗ごとに両方のシステムを組み合わせて使用できます。
:::

## 特殊なケース {#edge-cases}

<Accordion>
  <AccordionItem question="新しい店舗を追加すると、既存の注文はどうなりますか？">

何も変わりません。注文には販売時に `_pos_store` メタが記録されます。新しい店舗を追加しても、既存の注文がさかのぼって再割り当てされることはありません。Pro を有効化する前（または単一店舗の構成時）に作成された注文には `_pos_store` メタがなく、引き続きサイトのデフォルト設定で表示されます。

既存の注文を別の店舗に再割り当てする必要がある場合は、WP Admin → WooCommerce → 注文 で注文を開き、Pro が個別注文画面に追加する **店舗** ドロップダウンを使用してください。

  </AccordionItem>

  <AccordionItem question="店舗を削除するにはどうすればよいですか？">

店舗エディターの **ゴミ箱** ボタン（および店舗一覧の行アクション）は、WordPress の論理削除(`wp_trash_post`)を実行します。完全削除ではないため、次のようになります：

- その店舗は、レジ係の店舗選択画面やフィルタードロップダウンに表示されなくなります。
- ゴミ箱に移動した店舗を参照する既存の注文でも、レシートの再印刷や注文詳細の表示は引き続き正しく行われます。ゴミ箱内の店舗の名前、住所、ロゴは引き続き使用できます。
- ゴミ箱から復元すると、すべての設定を保持したまま、店舗が有効な状態に戻ります。

完全削除（ゴミ箱 → 完全に削除する）を行った場合にのみ、店舗レコードが削除されます。完全削除された店舗を参照する注文では、*「店舗 #ID」* とサイト全体のデフォルト設定が代わりに使用されます。

  </AccordionItem>

  <AccordionItem question="レジ係は複数の店舗で作業できますか？">

はい。アクセスを許可するすべての店舗の *許可ユーザー* リストで、該当するレジ係の名前にチェックを入れてください。ユーザーごとの「主な店舗」という概念はありません。サインインするたびに、店舗選択画面で作業する店舗を選択します。

  </AccordionItem>

  <AccordionItem question="店舗ごとに異なる通貨を使用できますか？">

店舗のサイドバーで **通貨** と **通貨の位置** を設定します。その店舗で開いたすべてのセッションで、サイト全体の WooCommerce 通貨設定が上書きされ、レシート、価格、合計はすべて店舗の通貨で表示されます。

これは表示形式のみの設定です。各通貨に対応した WooCommerce 互換の決済ゲートウェイは別途必要で、為替レートの処理は店舗側で対応する必要があります。

  </AccordionItem>

  <AccordionItem question="Pro をインストールしても店舗サブメニューが表示されないのはなぜですか？">

よくある原因は次の二つです：

1. **Pro が有効化されていない** — **WP Admin > POS > 設定 > ライセンス** に移動し、ライセンスキーが有効と表示されていることを確認してください。
2. **旧バージョンの無料版 + Pro の構成** — v1.8 より前の Pro は、無料プラグインに追加するアドオンでした。v1.8+ にアップグレードした場合、無料プラグインを無効化して削除する必要があります（[WCPOS Pro のインストール](/1.x/getting-started/pro-license)の注記を参照）。両方をインストールしたままにすると、店舗メニューが表示されなくなることがあります。

  </AccordionItem>
</Accordion>
