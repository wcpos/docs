:::info プロ機能
レポート画面では、[WCPOS Pro](/getting-started/pro-license)が必要です。
:::

レポート画面は、売上報告と日次調整ツールを提供します。主にキャッシャーやマネージャーが日を締めくくるのを助けるための**終日レポート**を設計しています。

{/* スクリーンショット: reports-overview.png */}

:::tip 包括的な分析
任意の日付範囲で詳細な分析を行うには、**WP管理 > 分析**を使用してください。POSレポート画面は、迅速な終日要約と日次調整に最適化されています。
:::

## インターフェース概要 {#interface-overview}

### フィルター {#filters}

画面の上部に：

- **ステータスフィルター** - 注文のステータスでフィルタリング（完了、処理中など）
- **顧客フィルター** - 顧客でフィルタリング
- **キャッシャーフィルター** - 注文を処理した人物でフィルタリング
- **ストアフィルター** - ストア（複数店舗の設定）でフィルタリング
- **日付範囲** - 報告期間を選択（今日、今週、カスタム）

### 三つのパネルレイアウト {#three-panel-layout}

レポート画面は三つのエリアに分かれています：

#### 1. 売上チャート (上部) {#1-sales-chart-top}

時間経過に伴う売上を示す棒グラフ：

- 日次レポートのための時間単位の内訳
- 売上パターンの視覚的表現
- ピーク販売時間を特定するのに役立ちます

#### 2. 注文テーブル (左下) {#2-orders-table-bottom-left}

レポートに含まれる注文のリスト：

- **チェックボックス** - 含める注文を選択/選択解除
- **ステータス** - 注文ステータスアイコン
- **注文番号** - ユニークな注文ID
- **作成日** - 注文が行われた日時
- **支払日** - 支払いが受領された日時
- **合計** - 注文金額

表示設定アイコンをクリックして列をカスタマイズします。

#### 3. レポート要約 (右下) {#3-report-summary-bottom-right}

計算されたレポート総計：

- **レポートタイプ**ドロップダウン（デフォルト/オフライン）
- **ストア情報**（名前、ID）
- **レポート期間**（開始/終了タイムスタンプ）
- **キャッシャー**（フィルタリングされた場合）

**売上要約:**
- 総注文数
- 総純売上
- 総税額
- **総売上**
- 総割引
- **返金合計**（期間内に返金がある場合に表示）

**支払い方法:**
- 支払いタイプ別の内訳（現金、カードなど）

**レジ係 / 店舗別合計:**
- 複数のレジ係または店舗を含むレポートの場合に表示される、レジ係別・店舗別の内訳

物理的なレポートを生成するための**印刷**ボタンです。

## レポートタイプ {#report-types}

### デフォルト (オフライン) {#default-offline}

デフォルトのレポートは、ローカルに保存されたデータから生成されます。これは：

- サーバー接続なしに動作します
- 高速なレポート生成を提供します
- デバイスに既に同期されたデータを使用します

これは、すべての関連する注文が既に同期されている迅速な終日要約に最適です。

:::note オンライン時は完全なレポートを取得します
接続中に、レポートの日付範囲がデバイス上の注文数を超える場合、WCPOSは条件に一致するすべての注文を最後まで取得します。10,000件の上限はありません。処理中は進捗が表示され、途中で切り詰められた範囲ではなく全期間の合計が示されます。オフラインの場合、デフォルトのレポートはこのデバイスにすでに同期された注文に限定されます。
:::

## 終日ワークフロー {#end-of-day-workflow}

レジ係向けの締め作業の全手順（釣銭準備金、ドロワー計数、現金とカードの照合、差異の処理、署名）については、**[日次締め精算](/reports/reconciliation)**をご覧ください。

簡単な手順は次のとおりです。

1. **日付範囲を設定**して*今日*を選び、個別のレポートを作成する場合は必要に応じて**レジ係で絞り込み**ます。
2. 表の**注文を確認**し、内容が正しいことを確かめます。
3. **ドロワー内の現金を数え**、サマリーパネルの*現金*行と比較します。
4. カード端末で**バッチ合計を実行**し、*カード*行と比較します。
5. 記録用に**レポートを印刷**します。

## レポートの印刷 {#printing-reports}

**印刷**ボタンをクリックして印刷可能なレポートを生成します。これには以下が含まれます：

- ストア情報
- レポート期間
- 売上要約
- 支払い方法の内訳
- 注文の詳細（選択された場合）

## データのエクスポート {#exporting-data}

POSレポート画面では、現在CSVまたはExcelへのエクスポートに対応していません。データをエクスポートするには、次の機能を備えた**WP Admin > WooCommerce > 分析**を使用してください。

- 注文、売上、商品などの**CSVダウンロード**
- 任意の期間や比較対象を指定できる**カスタム日付範囲**
- 任意の期間で売れ筋商品を確認できる**商品別レポート**

POSレポートとWooCommerce Analyticsは同じ注文データを参照するため、同じ日付範囲とフィルターを指定すれば合計は一致するはずです。

### WooCommerce AnalyticsのPOSフィルター (Pro) {#pos-filters-in-woocommerce-analytics}

WCPOS Proを有効にすると、`WP Admin > WooCommerce > Analytics`にPOS対応のフィルターが追加され、対面販売とオンライン販売を分けて確認できます。

- **注文**レポートでは、注文タイプのフィルターに「すべての注文」と並んで**POS注文**と**オンライン注文**が追加されます。
- **売上**レポートには、追加のフィルターが3つ表示されます（それぞれ複数の値がある場合に表示）：**店舗**、**レジ係**、**決済方法**。

WooCommerceの充実したレポート機能とCSVエクスポートを使って、「レジ係ごとの売上はいくらか」「先月この店舗の対面販売の売上はいくらだったか」といった質問に答えられます。アプリ内のオフラインレポートではできないことです。
