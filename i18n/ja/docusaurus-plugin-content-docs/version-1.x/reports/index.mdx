:::info プロ機能
レポート画面には、[WCPOS Pro](/1.x/getting-started/pro-license)が必要です。
:::

レポート画面は、売上報告と日次調整ツールを提供します。主にキャッシャーやマネージャーが日を締めくくるのを助けるための**終日レポート**を設計しています。

{/* スクリーンショット: reports-overview.png */}

:::tip 包括的な分析
任意の日付範囲で詳細な分析を行うには、**WP管理 > 分析**を使用してください。POSレポート画面は、迅速な終日要約と日次調整に最適化されています。
:::

## インターフェース概要 {#interface-overview}

### フィルター {#filters}

画面の上部に：

- **ステータスフィルター** - 注文のステータスでフィルタリング（完了、処理中など）
- **顧客フィルター** - 顧客でフィルタリング
- **キャッシャーフィルター** - 注文を処理した人物でフィルタリング
- **ストアフィルター** - ストア（複数店舗の設定）でフィルタリング
- **日付範囲** - 報告期間を選択（今日、今週、カスタム）

### 三つのパネルレイアウト {#three-panel-layout}

レポート画面は三つのエリアに分かれています：

#### 1. 売上チャート (上部) {#1-sales-chart-top}

時間経過に伴う売上を示す棒グラフ：

- 日次レポートのための時間単位の内訳
- 売上パターンの視覚的表現
- ピーク販売時間を特定するのに役立ちます

#### 2. 注文テーブル (左下) {#2-orders-table-bottom-left}

レポートに含まれる注文のリスト：

- **チェックボックス** - 含める注文を選択/選択解除
- **ステータス** - 注文ステータスアイコン
- **注文番号** - ユニークな注文ID
- **作成日** - 注文が行われた日時
- **支払日** - 支払いが受領された日時
- **合計** - 注文金額

表示設定アイコンをクリックして列をカスタマイズします。

#### 3. レポート要約 (右下) {#3-report-summary-bottom-right}

計算されたレポート総計：

- **レポートタイプ**ドロップダウン（デフォルト/オフライン）
- **ストア情報**（名前、ID）
- **レポート期間**（開始/終了タイムスタンプ）
- **キャッシャー**（フィルタリングされた場合）

**売上要約:**
- 総注文数
- 総純売上
- 総税額
- **総売上**
- 総割引
- **返金合計**（期間内に返金がある場合に表示）

**支払い方法:**
- 支払いタイプ別の内訳（現金、カードなど）

**レジ係 / 店舗別合計:**
- 複数のレジ係または店舗を含むレポートの場合に表示される、レジ係別・店舗別の内訳

物理的なレポートを生成するための**印刷**ボタンです。

## レポートタイプ {#report-types}

### デフォルト（オフライン） {#default-offline}

デフォルトのレポートは、ローカルに保存されたデータから生成されます。次の特徴があります。

- サーバーに接続せずに動作します
- レポートをすばやく生成できます
- デバイスに同期済みのデータを使用します

対象の注文がすべて同期済みの場合に、一日の終わりの集計をすばやく確認するのに適しています。

:::note オンライン時はすべての注文を取得して完全なレポートを作成します
接続中に、レポートの日付範囲に含まれる注文がデバイス上にある注文より多い場合、WCPOSは条件に一致するすべての注文を最後まで取得します。10,000件という上限はありません。処理中は進捗を表示し、合計には一部の注文だけでなく、対象期間全体が反映されます。オフラインの場合、デフォルトのレポートはこのデバイスに同期済みの注文に限られます。
:::

## 一日の終わりのワークフロー {#end-of-day-workflow}

レジ係向けの全手順（営業開始時の釣銭準備金、ドロワー内の現金の計数、現金とカードの照合、差異の処理、承認）については、**[日次締め精算](/1.x/reports/reconciliation)** を参照してください。

簡単な手順は次のとおりです。

1. *今日*に**日付範囲を設定**し、個別のレポートを作成する場合は、必要に応じて**レジ係で絞り込み**ます
2. 表の**注文を確認**し、内容が正しいことを確かめます
3. **ドロワー内の現金を数え**、要約パネルの*現金*行と比較します
4. カード端末で**バッチ合計を実行**し、*カード*行と比較します
5. 紙の記録として残すため、**レポートを印刷**します

## レポートの印刷 {#printing-reports}

**印刷**ボタンをクリックすると、印刷用のレポートが生成されます。次の内容が含まれます。

- 店舗情報
- レポート期間
- 売上要約
- 支払い方法の内訳
- 注文の詳細（選択した場合）

## データのエクスポート {#exporting-data}

POSのレポート画面は、現在CSVやExcelへのエクスポートには対応していません。データをエクスポートするには、次の機能を備えた**WP Admin > WooCommerce > 分析**を使用してください。

- 注文、売上、商品などの**CSVダウンロード**
- 任意の期間と比較対象を指定できる**カスタム日付範囲**
- 任意の期間で売れ筋商品を確認できる**商品別レポート**

POSレポートとWooCommerce Analyticsは同じ注文データを参照するため、同じ日付範囲とフィルターを指定すれば、合計は一致するはずです。

### WooCommerce AnalyticsのPOSフィルター（Pro） {#pos-filters-in-woocommerce-analytics}

WCPOS Proを有効にすると、`WP Admin > WooCommerce > Analytics`にPOS対応のフィルターが追加され、対面販売とオンライン販売を分けて確認できます。

- **注文**レポートでは、注文タイプのフィルターに「すべての注文」と並んで**POS注文**と**オンライン注文**が追加されます。
- **売上**レポートには、**店舗**、**レジ係**、**支払い方法**の3つのフィルターが追加されます。それぞれ、選択肢が複数ある場合に表示されます。

WooCommerceの充実したレポート機能とCSVエクスポートを使って、「レジ係ごとの売上はいくらか」「先月、この店舗の対面販売の売上はいくらだったか」といった疑問を確認できます。アプリ内のオフラインレポートではできないことです。
