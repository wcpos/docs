# 翻訳: WCPOS Polylang {#wcpos-polylang}

[Polylang](https://polylang.pro/) 対応を WCPOS に追加し、POS が単一言語の商品のみを表示するようにします。商品検索、カタロググリッド、レジ業務で翻訳の重複が発生しません。WCPOS Pro の店舗では店舗ごとに言語を固定できます。無料版では Polylang のデフォルト言語が適用されます。

## 機能概要 {#what-it-does}

- WCPOS の商品およびバリエーションの REST クエリを言語でフィルタリングします。
- WCPOS の**高速同期**ルート（POS がローカルインデックスを更新するために使用する軽量な `posts_per_page=-1` + `fields` リクエスト）をインターセプトし、翻訳の重複がクライアントに届かないようにします。
- 無料版では、Polylang のデフォルト言語が適用されます。
- Pro 版では、店舗エディタの新しい**言語**セクションから店舗ごとに言語を選択できます。
- 高速同期ペイロードの構築時に、WCPOS の **POS 限定**商品表示設定を考慮します。

Polylang が有効でない場合、この連携機能は何も行いません。Polylang を有効化する前にプラグインをインストールしても、エラーは発生しません。

## インストール {#installation}

<Steps>
  <StepCard number="1" title="JA: Polylang のインストール">

[Polylang](https://wordpress.org/plugins/polylang/)（またはPolylang Pro）をインストールし、通常どおりサイトの言語を設定します。少なくとも一つの言語をデフォルトに設定してください。

  </StepCard>
  <StepCard number="2" title="JA: WCPOS Polylang のインストール">

`WP Admin > POS > 設定 > 拡張機能` の WCPOS 拡張機能ディレクトリからインストールするか、[GitHub リリースページ](https://github.com/wcpos/wcpos-polylang/releases)から最新リリースをダウンロードし、`プラグイン > 新規追加 > プラグインのアップロード` からアップロードしてください。

  </StepCard>
  <StepCard number="3" title="JA: （Pro）店舗ごとの言語設定" isLast>

WCPOS Pro で[複数の店舗](/1.x/stores)を運営している場合は、`POS > 店舗` で店舗を編集し、サイドバーの **言語** セクションから言語を選択してください。Polylang のデフォルト言語を使用するには、*デフォルト* のままにします。

  </StepCard>
</Steps>

## 店舗ごとの言語設定（Pro） {#per-store-language-pro}

WCPOS Pro では、このプラグインによって店舗エディターのサイドバーに **言語** セクションが追加されます。各店舗に単一の Polylang 言語スラッグを指定でき、その店舗に提供される商品は指定言語のみに絞り込まれます。*デフォルト* のままの店舗では、Polylang のデフォルト言語を使用します。

店舗ごとの値は、店舗投稿の `_wcpos_polylang_language` メタとして保存され、WCPOS Pro の店舗 REST API(`/wcpos/v1/stores`)を通じて公開されます。そのため、他の店舗設定と同様に POS で取得・保存できます。

## 互換性に関する注意事項 {#compatibility-notes}

- **POS 専用商品：** WCPOS 設定で POS 専用モードが有効な場合、オンライン専用の商品 ID は高速同期ペイロードから除外され、POS に混入しないようになります。
- **無料版：** 店舗ごとに言語を変更する UI はなく、プラグインは Polylang のデフォルト言語を使用します。店舗ごとの言語設定が必要な場合は、[WCPOS Pro](/1.x/getting-started/pro-license) にアップグレードしてください。
- **プラグイン無効時：** Polylang が無効化されている場合、このプラグインは何も行いません。エラーを出したり、POS の動作を妨げたりすることはありません。

## 開発者向けフック {#developer-hooks}

高度な用途向けに、プラグインはいくつかのフィルターを公開しています。

| フィルター | 用途 |
| --- | --- |
| `wcpos_polylang_resolved_language` | リクエストに使用する言語を上書きします。解決済みのスラッグと `WP_REST_Request` を受け取ります。 |
| `wcpos_polylang_default_language` | 店舗ごとの値が未設定の場合に使用するフォールバック言語を上書きします。 |
| `wcpos_polylang_is_supported` | Polylang の検出結果に関係なく、プラグインを強制的に有効または無効にします。 |
| `wcpos_polylang_minimum_version` | Polylang の最低バージョンを指定します（デフォルト：バージョン制限なし）。 |
