WCPOS は、POS に新しい機能を追加する拡張機能に対応しています。拡張機能ディレクトリでは、利用可能な拡張機能の閲覧、POS 設定からの直接インストール、更新の管理ができます。

:::info Pro 機能
拡張機能のインストールと管理には [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。無料版では拡張機能カタログを表示できますが、インストールや有効化の操作は無効になっています。
:::

## 拡張機能の閲覧 {#browsing-extensions}

`POS Settings > 拡張機能` から拡張機能ディレクトリを開きます（バージョンによっては **プラグイン** と表示されます）。

ディレクトリには、利用可能な拡張機能がカード形式のグリッドで表示されます。各カードには次の情報が表示されます。

- **アイコン**（拡張機能にアイコンがない場合は、代わりにパズルピースを表示）
- **名前とバージョン**
- **説明**
- **カテゴリバッジ**
- **ステータス** — 有効、無効、更新あり、または未インストール

### フィルタリングと検索 {#filtering-and-search}

上部の **カテゴリピルボタン** を使うと、カテゴリ別に拡張機能を絞り込めます。**検索フィールド** で、名前、説明、タグから拡張機能を探すこともできます。

## 拡張機能のインストール {#installing-an-extension}

1. `POS Settings > 拡張機能` を開きます。
2. 目的の拡張機能を見つけて、**インストール** をクリックします。
3. WordPress のプラグインインストーラーを使って、拡張機能がダウンロードおよびインストールされます。
4. インストールが完了したら、**有効化** をクリックして有効にします。

内部では WCPOS が WordPress 標準の `Plugin_Upgrader` でインストールを処理するため、拡張機能も通常の WordPress プラグインと同じ手順でインストールされます。

## 有効化と無効化 {#activating-and-deactivating}

インストール済みの各拡張機能のカードには、**有効化** ボタンと **無効化** ボタンがあります。

- **有効化** すると、拡張機能が POS で動作するようになります。
- **無効化** すると、アンインストールせずに拡張機能を無効にします。ファイルはサーバーに残り、いつでも再び有効化できます。

## 拡張機能の更新 {#updating-extensions}

インストール済みの拡張機能に新しいバージョンがある場合、カードに **更新あり** バッジと **更新** ボタンが表示されます。

### 自動更新 {#auto-updates}

ディレクトリからインストールした拡張機能は、**デフォルトで自動更新が有効** です。ディレクトリ内の各拡張機能のカードで、自動更新のオン・オフを切り替えられます。オンの場合、自動更新が有効な他のプラグインと同様に、WordPress が新しいバージョンを自動的に適用します。

## トラブルシューティング {#troubleshooting}

### ボタンに「Pro が必要です」と表示される {#requires-pro-message-on-buttons}

無料版の WCPOS では、インストール、有効化、更新ボタンが無効になっています。拡張機能を管理するには、[WCPOS Pro](/1.x/getting-started/pro-license) にアップグレードしてください。

### 拡張機能のインストールに失敗する {#extension-fails-to-install}

- WordPress サーバーに `wp-content/plugins` ディレクトリへの書き込み権限があるか確認してください。
- サーバーが外部への HTTPS リクエストを送信できるか確認してください（一部のホスティングでは外部からのダウンロードがブロックされています）。
- `WP Admin > POS > サポート > ログ` でエラーの詳細を確認してください。

### インストール後に拡張機能が表示されない {#extension-not-appearing-after-install}

- POS を再読み込みしてください。拡張機能の一覧は最大 12 時間キャッシュされます。
- 拡張機能が有効化されているか確認してください（インストール済みでも無効な拡張機能は動作しません）。

### カタログが読み込まれない {#catalog-not-loading}

拡張機能カタログはリモートソースから取得され、ローカルに 12 時間キャッシュされます。カタログが読み込まれない場合は、次の点を確認してください。

- サーバーのインターネット接続を確認してください。
- キャッシュの有効期限が切れた後に再試行するか、サーバーのトランジェントキャッシュをクリアしてください。

## 開発者向け {#for-developers}

### POS 拡張機能の作成 {#creating-a-pos-extension}

WCPOS の拡張機能は、WCPOS のフックと API を通じて POS と連携する標準的な WordPress プラグインです。作成手順は次のとおりです。

1. **WordPress プラグインから始めます。** 拡張機能には、通常の WooCommerce や WordPress のプラグインと同様に、標準的なプラグインヘッダーとエントリファイルが必要です。
2. **WCPOS と連携します。** WCPOS が提供するフックとフィルターを使って、POS インターフェースやバックエンドに機能を追加します。
3. **GitHub でリリースをホストします。** 拡張機能ディレクトリは GitHub Releases を使ってバージョンを管理し、更新を配信します。

### ディレクトリへの登録 {#submitting-to-the-directory}

拡張機能カタログは GitHub リポジトリの [`wcpos/extensions`](https://github.com/wcpos/extensions) で管理されています。拡張機能を登録する手順は次のとおりです。

1. リポジトリの README で、カタログ形式とメタデータの要件を確認します。
2. 拡張機能のメタデータを `catalog.json` に追加するプルリクエストを作成します。
3. マージされると、すべての WCPOS Pro ユーザーのディレクトリに拡張機能が表示されます。

### GitHub リリースの規則 {#github-release-conventions}

更新のライフサイクルは GitHub Releases に基づいています。

- セマンティックバージョニングで **バージョンタグを付けます**（例：`v1.0.0`、`v1.2.3`）。
- リリースアセットとして **プラグインの zip ファイルを添付します**。ユーザーがインストールや更新を行う際に、このファイルがダウンロードされます。
- ディレクトリで検出できるように、ドラフトではなく **リリースを公開します**。

新しいリリースを公開すると、拡張機能をインストール済みのユーザーの拡張機能ディレクトリに、更新が利用可能であることが表示されます。自動更新が有効な場合は、自動的に適用されます。

カタログスキーマと登録手順の詳細は、[`wcpos/extensions`](https://github.com/wcpos/extensions) リポジトリを参照してください。
