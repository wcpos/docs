:::info Pro機能
顧客画面には [WCPOS Pro](/1.x/getting-started/pro-license) が必要です。無料版でも注文に既存の顧客を選択できますが、顧客一覧全体の表示や顧客情報の編集はできません。
:::

顧客画面では、POS上で直接、包括的な顧客管理を行えます。WooCommerce管理画面に切り替えることなく、顧客の表示、編集、作成が可能です。

## インターフェースの概要 {#interface-overview}

### ヘッダーアクション {#header-actions}

画面上部には以下があります：

- **検索バー** - 名前やメールアドレスなどで顧客を検索できます。
- **顧客を追加** (<Icon name="plus" />) - 新しい顧客を作成します
- **表示設定** (<Icon name="sliders" />) - 表示する列を設定します

### 顧客テーブル {#customer-table}

メインエリアには以下の情報とともに顧客が表示されます：

- **アバター** - 顧客のプロフィール画像（またはプレースホルダー）
- **名** - 顧客の名前
- **姓** - 顧客の姓（並べ替え可能）
- **メールアドレス** - 連絡先メールアドレス
- **請求先住所** - 完全な請求先住所
- **作成日** - 顧客が追加された日付
- **アクション** - 三点メニュー

### フッター {#footer}

- 同期ボタン付きの顧客数（<Icon name="arrow-rotate-right" />）。**長押し**でクリアと更新オプションを表示

## 主な機能 {#key-features}

### 顧客検索 {#customer-search}

以下の情報で顧客をすばやく検索できます：

- 姓または名
- メールアドレス
- 住所情報

検索では、入力した**すべての単語**が対象フィールド内で順不同に照合されます。そのため、「jane paris」と検索すると、都市がParisのJaneが見つかります。並べ替えと絞り込みはサーバー上で実行され、端末内にある顧客だけでなく、すべての顧客が対象になります。

### 新規顧客の追加 {#add-new-customer}

POSから直接顧客を作成できます：

1. ヘッダーの <Icon name="plus" /> アイコンをクリックします
2. 顧客情報を入力します
3. 新しい顧客を保存します

顧客がWooCommerceに作成され、すぐに注文で利用できるようになります。

### 顧客の編集 {#edit-customer}

顧客情報を更新します：

1. 顧客の三点メニューをクリックします
2. **編集**を選択します
3. 詳細（名前、メールアドレス、住所）を変更します
4. 変更を保存します

変更はWooCommerceに自動的に同期されます。

### 利用可能な列 {#available-columns}

| 列 | 説明 |
|--------|-------------|
| **画像** | 顧客のアバター |
| **ID** | WooCommerce の顧客 ID |
| **名** | 顧客の名 |
| **姓** | 顧客の姓 |
| **メールアドレス** | メールアドレス |
| **権限** | ユーザーの権限グループ（顧客、購読者など） |
| **ユーザー名** | WordPress のユーザー名 |
| **請求先住所** | 請求先情報 |
| **配送先住所** | 配送先情報 |

| **更新日** | 最終更新日時 |
| **アクション** | 編集、同期、削除 |

## 顧客の操作 {#customer-actions}

三点メニュー（⋮）をクリックすると、次のオプションが表示されます：

- **編集** - 顧客情報を変更します
- **同期** - サーバーから顧客情報を取得して更新します
- **削除** - ローカルデータベースから削除します

:::note
POS で顧客を削除しても、削除されるのは**ローカルでのみ**です。顧客は WooCommerce に残り、次回の同期で再び表示されます。顧客を **WooCommerceで**削除すると、同期時に POS からも削除されます。
:::

## デフォルト顧客（ゲスト） {#default-customer-guest}

顧客が選択されていない場合、注文は**ゲスト**注文として処理されます。ゲスト注文には次の特徴があります：

- 顧客名、メールアドレス、住所が紐づいていません
- 注文履歴で顧客から検索できません
- 注文画面と WooCommerce 管理画面には表示されます

ゲスト注文を避けるには、会計前にカートパネルで顧客を選択してください。すべての注文に顧客の指定が必要な場合は、必ず顧客を割り当てるようレジ係に指導することを検討してください。これを強制する組み込み設定はありません。

## 注文での顧客の使用 {#using-customers-in-orders}

注文に顧客を割り当てる手順：

1. [カートパネル](/1.x/pos/cart)で顧客バッジをクリックします
2. 名前、メールアドレス、電話番号で顧客を検索します
3. 顧客を選択します
4. 顧客が注文に関連付けられます

顧客情報（請求先住所・配送先住所）は、自動的に注文に使用されます。

## 同期 {#synchronization}

顧客データは POS と WooCommerce の間で同期されます：

- **デバイス間で同期** - 他のデバイスにも、次回の変更チェック時に変更が反映されます
- **WooCommerce連携** - 顧客は WooCommerce に保存されます
- **オフライン対応** - オフラインでも顧客を表示できます
