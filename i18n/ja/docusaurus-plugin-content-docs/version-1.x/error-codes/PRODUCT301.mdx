## これが意味すること {#what-this-means}

スキャンまたは入力した検索語に一致する商品が見つかりませんでした。

よくある原因は、フィルターが有効になっていること、バーコードが未登録か別の項目に保存されていること、初回同期が完了していないことです。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

**レジ端末：**

1. まずフィルターを解除してください。カテゴリーまたは在庫フィルターが有効だと、スキャンしたコードを含むすべての検索が絞り込まれます（スキャンしたコードも同じ検索ボックスに入力されます）。
2. 商品名で検索してください。商品が表示されるのにスキャンで見つからない場合、店舗のバーコードとスキャン値が一致していません。検索語を入力した場合は、スペルミスや余分な空白がないか確認してください。
3. 新商品の場合、ローカルインデックスの同期中かもしれません。初回同期が完了するまで待ってから、もう一度お試しください。

**店舗側：**

- バーコードが未登録の場合は、WP Adminでスキャン値を商品のバーコード項目に追加してください。
- すべてのスキャンで商品が見つからない場合、POSが誤った項目を参照している可能性があります。POSのバーコード設定で、店舗がバーコードを保存している項目を確認してください。
