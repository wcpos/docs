## このエラーの意味 {#what-this-means}

ローカル検索でカタログと一致しない結果が返されました。アプリは検索インデックスの自動再構築を試みます。

検索に即座に応答するため、WCPOS は商品、顧客、注文など、検索対象のリストのローカル検索インデックスを保持しています。自己チェックにより、そのインデックス内に入力内容と実際には一致しないエントリーが検出されました。不一致の結果は直ちに非表示になり、アプリはインデックス自体を修正するため、セッションごとに各リストについて一度だけ自動でインデックスの再構築を試みます。

## データについて {#your-data}

店舗データは変更されていません。この問題は、このデバイス上にすでにあるデータから作成されるローカル検索インデックスにのみ関係します。不一致の結果を非表示にしても検索表示が変わるだけで、元のレコードは変更されません。

## トラブルシューティング {#troubleshoot}

1. 通常は対応不要で、販売は通常どおり続行できます。ただし、ログエントリーに記載された検索を再実行し（コンテキストには検索語が記録されています）、結果が入力内容と一致し、想定していた項目が欠けていないことを確認してください。
2. 存在することがわかっている商品、顧客、または注文が検索結果にまだ表示されない場合は、アプリを再読み込みしてください。Web ではブラウザータブを再読み込みし、デスクトップおよびモバイルではアプリを閉じてから再度開きます。これにより、次回問題が検出されたときに新たなインデックス再構築を試行できます。
3. 再読み込み後にコードが再び表示される場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。エントリーのコンテキストには、影響を受けたリストと問題を発生させた検索が記載されています。
