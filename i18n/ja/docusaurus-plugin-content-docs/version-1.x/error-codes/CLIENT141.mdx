## このエラーの意味 {#what-this-means}

検索結果の一部が商品に一致しなかったため、WCPOSはそれらを非表示にしました。

検索結果に問題がなければ対応は不要です。問題が続く場合はWCPOSを再読み込みしてください。

検索にすばやく応答するため、WCPOSは商品、顧客、注文など、検索対象の一覧のローカル検索インデックスを保持しています。自己診断で、インデックス内に入力内容と一致しない項目が見つかりました。一致しない結果はすぐに非表示になりました。アプリが自動的にインデックスを再構築する場合もありますが、セッションごとに一覧単位で1回だけのため、再構築されるとは限りません。

## データについて {#your-data}

店舗データは変更されていません。この問題は、このデバイス上にすでにあるデータから作成されるローカル検索インデックスにのみ関係します。不一致の結果を非表示にしても検索表示が変わるだけで、元のレコードは変更されません。

## トラブルシューティング {#troubleshoot}

1. 検索結果に問題がなければ、通常どおり販売を続けられます。確認する場合は、ログに記録された検索をもう一度実行してください（ログのコンテキストに検索語が記録されています）。入力した内容と結果が一致し、表示されるはずの結果が欠けていないことを確認します。
2. 検索結果が依然として誤っている場合、または存在を確認できる商品、顧客、注文が表示されない場合は、アプリを再読み込みしてください。Web版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを終了して再度開きます。問題が次に検出されたとき、新しいインデックスの再構築が試みられます。
3. 再読み込み後にこのコードが再び表示された場合は、**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。ログのコンテキストには、影響を受けた一覧と、その問題を引き起こした検索が記録されています。
