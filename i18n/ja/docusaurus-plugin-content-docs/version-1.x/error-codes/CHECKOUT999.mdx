## これが意味すること {#what-this-means}

チェックアウトで予期しない問題が発生しました。

お客様に再度請求する前に、ストアの管理画面で注文を確認してください。問題が繰り返す場合は、診断情報をエクスポートしてサポートにお問い合わせください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. お客様に再度請求する前に、WP Adminの WooCommerce → 注文 で該当の注文を確認してください。
2. ログエントリーを展開し、イベントコードと（あれば）serverCodeを控えてください。この汎用コードは、その原因に専用のコードがまだ割り当てられていないことを意味します。
3. 繰り返す場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。
