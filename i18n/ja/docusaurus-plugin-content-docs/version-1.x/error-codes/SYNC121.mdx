## これが意味すること {#what-this-means}

現在、店舗に接続できません。

対応は不要です。そのまま販売を続けてください。接続が復旧すると、変更は自動的に送信されます。長時間続く場合は、このデバイスの接続と店舗の Web サイトが表示されるかを確認してください。

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ反映されていない変更が含まれている可能性があります。店舗から応答があれば、自動的に送信されます。

## トラブルシューティング {#troubleshoot}

1. 販売を続けてください。販売内容はこのデバイスに保存され、店舗から応答があれば自動的に送信されます。
2. レジ自体がオンラインかどうかを確認してください。このデバイスから他のウェブサイトは表示できますか。
3. 同じデバイスのブラウザーのタブで、ストアのウェブサイトを開いてみてください。そちらも表示されない場合は、POSではなくサイトまたはそのホスティングが停止しています。
4. **このデバイスのネットワーク管理者向け：** サイトは読み込めるのにPOSがオフラインのままの場合、その間にある何かがAPIリクエストをブロックしています（VPN、ファイアウォール、広告ブロッカー、セキュリティプラグインなど）。ブラウザーの開発者ツール（Networkタブ）、またはデスクトップアプリの**Advanced → Toggle Developer Tools**で、失敗したリクエストを確認できます。
