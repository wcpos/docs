## これが意味すること {#what-this-means}

商品のSKUが重複しているか無効なため、チェックアウトを続行できません。

指摘されたSKUを変更または削除してから、保持されているカートで再試行してください。

## データへの影響 {#your-data}

注文自体は安全で、変更されていません。

## トラブルシューティング {#troubleshoot}

1. ログエントリーには、ストアが拒否したSKUが記載されています。

**レジ端末：**SKUを修正するまで、この商品は販売できません。カートから明細を削除して商品を取り置きし、残りの販売を先に完了してください。店舗側で修正した後、この商品に戻ります。

**店舗側** — サイト管理者向け：

1. WP Admin で「商品」を検索し、その SKU を確認してください。SKU が同じ商品が2つ（または商品とバリエーションが1つずつ）ある場合は、それぞれに一意の SKU を設定してください。該当する商品が1つだけの場合は、SKU の形式に誤りがあります。その商品の SKU を修正してください。
2. SKUが有効で重複しなくなれば、レジ端末で商品を追加して販売を完了できます（カートは保持されています）。
