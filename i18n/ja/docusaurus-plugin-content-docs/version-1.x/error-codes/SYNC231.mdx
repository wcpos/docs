## このエラーの意味 {#what-this-means}

店舗はこの変更を受信しましたが、このデバイスでは送信済みとして記録できませんでした。

対応は不要です。再入力しないでください。WCPOSは再確認を続け、店舗側は重複分を無視します。

販売または編集内容は店舗に届き、そこで保存されました。その後、このデバイスは変更が送信済みであることを記録しようと3回連続で試みましたが、失敗しました。そのため、このデバイスでは変更が未送信のように表示され、次回の同期時にWCPOSが再送信します。店舗は変更をIDで識別して重複を無視するため、二重に保存されることはありません。実際のリスクは、誰かが販売や編集を手入力でもう一度登録することです。別のデータとして二重に作成されます。

## データについて {#your-data}

データは失われていません。店舗にはすでに変更が保存されています。このデバイスで再送信が記録されるまで、送信待ちとして数えられる場合があります。

## トラブルシューティング {#troubleshoot}

1. 販売や編集を手入力でもう一度登録しないでください。店舗にはすでに保存されており、再登録すると重複します。
2. 販売が店舗に届いたことを確認するには、WP管理画面の**WooCommerce → 注文**を確認してください。このデバイスに保存されているため、WCPOSにも表示されます。
3. WCPOSが同期するまでそのままにしてください。次の再送信は店舗側で無視され、通常は項目が解消されます。解消すると、**ストアヘルス → ログ**のヘッダーにある**送信待ちの変更**の数が減ります。
4. この表示が繰り返される場合、デバイス自身のストレージへの保存に問題がある可能性があります。空き容量を確認し、**ログ**タブで**デバッグ情報をコピー**をタップして、サポートにお問い合わせください。解決のために、このデバイスのデータを消去しないでください。
