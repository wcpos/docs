## 意味 {#what-this-means}

店舗はこの変更を受信しましたが、このデバイスでは送信済みとして記録できませんでした。

対応は不要です。再入力しないでください。WCPOSは再確認を続け、店舗側では重複分が無視されます。

販売または編集内容は店舗に届き、保存されています。その後、このデバイスは変更の送信済み記録を3回連続で保存しようとしましたが、失敗しました。そのため、このデバイスでは変更が未送信のように表示され、次回の同期時にWCPOSが再送します。店舗は変更をIDで識別して重複を無視するため、二重に保存されることはありません。実際に注意が必要なのは、誰かが販売や編集内容を手入力でもう一度登録することです。その場合、別のデータが作成されます。

## データについて {#your-data}

データは失われていません。変更はすでに店舗にあります。このデバイスで再送信が記録されるまでは、送信待ちとしてカウントされる場合があります。

## トラブルシューティング {#troubleshoot}

1. 販売や編集内容を手動で再入力しないでください。店舗にはすでに保存されており、再入力すると重複が作成されます。
2. 販売が店舗に届いたことを確認するには、WP Adminの**WooCommerce → Orders**を確認してください。このデバイスにも保存されているため、WCPOSにも表示されます。
3. WCPOSの同期を続けてください。次回の再送信は店舗側で無視され、通常はエントリーが解消されます。解消されると、**Store health → Logs**のヘッダーにある**changes waiting to send**の数が減ります。
4. これが繰り返し表示される場合、デバイス自身のストレージへの保存に問題がある可能性があります。空き容量を確認し、**Logs**タブの**Copy debug info**をタップしてサポートに連絡してください。解決のためにこのデバイスのデータを消去しないでください。
