## このエラーの意味 {#what-this-means}

この操作を実行する権限がアカウントにありません。

データは失われていません。店舗管理者に、この操作を行う権限をユーザーの権限グループに付与してもらってから、もう一度お試しください。

## データへの影響 {#your-data}

データは失われていません。注文や商品データにも影響はありません。

## トラブルシューティング {#troubleshoot}

**レジ端末** — レジ係向け：拒否された操作を控えて（ログに記録されています）、管理者に伝えてください。

**店舗側** — サイト管理者向け：アカウントの権限グループを確認してください。POS のレジ係には WCPOS が登録する POS の操作権限が必要ですが、権限編集プラグインによって削除されることがあります。

サインインはできるのに商品、顧客、注文のリクエストがすべて拒否される場合は、**複数の権限グループ**が割り当てられていないか確認してください。Members などの権限編集プラグインは、いずれかの権限グループに設定された*拒否*をアカウント全体に適用します。そのため、顧客の権限グループも持つ管理者は、顧客の権限グループで拒否された機能を使えなくなります。余分な権限グループを削除するか、*拒否*の設定を解除してください。[複数の権限グループを持つユーザー](/1.x/settings/wp-admin/access#more-than-one-role)を参照してください。

**レジに戻ったら：** 権限グループを修正した後、POS セッションがまだ開いている場合は一度サインアウトしてからサインインし直してください。開いていない場合は、再度サインインしてください。その後、拒否された操作をもう一度試してください。
