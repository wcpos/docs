## これが意味すること {#what-this-means}

この操作を実行する権限がアカウントにありません。

店舗管理者にアカウントの権限と機能を確認してもらい、もう一度お試しください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、ストア管理者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジ端末** — レジ係向け：拒否された操作を確認してください（ログに記録されています）。内容を管理者に伝えます。

**店舗側** — サイト管理者向け：アカウントの権限を確認します。POSのレジ係にはWCPOSが登録するPOS機能が必要です。権限編集プラグインによって機能が削除される場合があります。

サインインはできるのに、商品、顧客、注文のリクエストがすべて拒否される場合、**複数の権限グループ**が割り当てられていないか確認してください。Membersなどの権限編集プラグインでは、いずれかの権限グループに設定された*拒否*がアカウント全体に適用されます。そのため、Customer権限も持つAdministratorは、Customer権限で拒否された機能を使えなくなります。余分な権限グループを削除するか、*拒否*の設定を解除してください。[複数の権限グループを持つユーザー](/settings/wp-admin/access#more-than-one-role)を参照してください。

**レジ端末に戻り：**権限の修正後、POSセッションが開いたままならサインアウトして再度サインインします。セッションが開いていない場合も、改めてサインインしてください。その後、拒否された操作をもう一度行います。
