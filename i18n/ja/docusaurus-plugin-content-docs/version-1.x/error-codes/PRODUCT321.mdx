## これが意味すること {#what-this-means}

このバーコードに一致する商品が複数あります。

WCPOSはそれらを安全に選び分けられないため、何も追加していません。この会計は商品名で検索して進め、重複を解消するにはストア側で各商品に固有のバーコードを設定してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、ストア管理者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジ端末：**商品名で検索して販売を完了してください。バーコードが複数の商品に一致したため、スキャンでは商品が追加されていません。

ログエントリーには、スキャンしたコードと一致した商品の件数が記録されています。POSでそのバーコードの値を検索すると、該当する商品を確認できます。

**店舗側（WP Admin）：**対象の商品それぞれに異なるバーコードを設定し、再スキャンして一致が1件だけになることを確認してください。
