## これが意味すること {#what-this-means}

表示されている在庫数が、ストアの在庫数より古い可能性があります。

在庫を超えて販売するおそれがある会計を完了する前に、ストアで現在の在庫数を確認してください。

## データへの影響 {#your-data}

データが失われる心配はありません。レジ端末の在庫数が店舗側より古いだけで、同期が復旧すると最新の数に追いつきます。問題が続く場合は、WordPressサイトの管理者に相談してください。

## トラブルシューティング {#troubleshoot}

**レジ端末：**在庫が少ない商品を販売する前に、レジ端末の数をそのまま信じず、棚を確認するか管理者に聞いて実際の数量を確認してください。店舗側の数より遅れている可能性があります。

**遅延を解消するには：**在庫情報が古い場合、通常は同期が失敗しているか一時停止しています。ストアヘルス → ログで同期エラーを確認し、解消してください。同期が復旧すると在庫表示は自動的に最新になります。
