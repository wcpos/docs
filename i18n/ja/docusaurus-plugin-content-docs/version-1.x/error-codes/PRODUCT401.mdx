## これが意味すること {#what-this-means}

表示されている在庫数が、ストアの在庫数より古い可能性があります。

在庫を超えて販売するおそれがある会計を完了する前に、ストアで現在の在庫数を確認してください。

## データへの影響 {#your-data}

データが失われる心配はありません。レジ端末の在庫数が店舗側より古いだけで、同期が復旧すると最新の数に追いつきます。問題が続く場合は、WordPressサイトの管理者に相談してください。

## トラブルシューティング {#troubleshoot}

**レジ端末：** 在庫が少ない商品を販売する前に、実際の数量を確認してください。棚を確認するか管理者に確認し、店舗の在庫数とずれている可能性があるレジの表示だけを信頼しないでください。

**ずれを解消するには：** 在庫数が古い場合、通常は同期が失敗または一時停止しています。**店舗の状態 → ログ**で同期エラーを確認し、解決してください。同期が復旧すると、在庫表示は自動的に最新になります。
