## これが意味すること {#what-this-means}

ライセンスの確認で予期しない問題が発生しました。

POSはそのまま動作し続けます。Proの機能がロックされたままの場合は、ライセンスキーを入力し直したうえで、サポートにお問い合わせください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. そのまま作業を続けてください。POSがライセンスの確認によって動かなくなることはありません。
2. Proの機能がロックされたままの場合は、POS設定でライセンスキーを入力し直してください。
3. それでも解消しない場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。
