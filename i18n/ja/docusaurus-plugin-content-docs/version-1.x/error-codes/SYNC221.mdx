## これが意味すること {#what-this-means}

このデバイスでの変更が、ストアで行われた編集と競合しました。

レコードを開いて、どちらのバージョンが正しいかを確認してください。競合が解消されるまでPOSは両方の内容を保持するため、失われるものはありません。

## データへの影響 {#your-data}

レコード自体は安全で変更されていません。競合が解決するまで、POSはレジ側と店舗側の両方のバージョンを保持します。

## トラブルシューティング {#troubleshoot}

1. ログに記載されたレコードを開き、WP Adminにある店舗側のコピーと比較してください（サイト管理者による操作が必要な場合があります）。
2. レジ側とストア側のどちらのバージョンが正しいかを判断し、正しい値を一度だけあらためて適用してください。POSは両方の内容を保持しており、そのレコードへの以降の編集は、競合が解消されるまで保留されます。
3. 同じレコードで頻繁に競合する場合、通常は複数の人が同じデータを同時に編集しています。編集の種類ごとに、どちらで編集するか決めてください。
