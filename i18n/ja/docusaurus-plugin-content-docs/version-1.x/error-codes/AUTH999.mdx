## これが意味すること {#what-this-means}

サインイン、またはサインイン状態の維持で予期しない問題が発生しました。

操作をもう一度試してください。再発する場合はサインアウトして再度サインインし、**デバッグ情報をコピー**で情報をコピーしてサポートに連絡してください。

## データへの影響 {#your-data}

注文や商品データには影響しません。問題が続く場合は**デバッグ情報をコピー**で情報をコピーし、WCPOSサポートに連絡してください。

## トラブルシューティング {#troubleshoot}

1. もう一度操作をお試しください。再び失敗する場合は、サインアウトして再度サインインしてください。
2. ログエントリーを展開し、イベントコードと（あれば）serverCodeを控えてください。999のコードは、その原因に専用のコードがまだ割り当てられていないことを意味し、そのコンテキストこそが原因を特定する手がかりになります。
3. 再発する場合は、デバッグ情報をコピーしてサポートにお問い合わせください。
