## これが意味すること {#what-this-means}

WCPOSが店舗の接続先に到達できません。

サイト管理者に、WCPOSプラグインが有効か（**WP Admin → プラグイン**）、またセキュリティプラグインがREST APIをブロックしていないか確認してもらってください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。サイト管理者にお知らせください。

## トラブルシューティング {#troubleshoot}

**レジでの対応** — レジ係向け：サイト管理者にお知らせください。このデバイスへの影響はありません。

**店舗側** — サイト管理者向け：

1. WCPOSが有効になっていることを確認します：WP Admin → プラグイン。
2. どちらのREST形式も動作しない場合は、セキュリティプラグイン、プロキシ、CDNがWCPOSリクエストのヘッダーを削除したり、RESTリクエストをブロックしたりしていないか確認してください。ファイアウォールルールやREST APIを無効にする強化設定が、よくある原因です。
3. ホスティング環境によっては、パーマリンクを保存し直す（設定 → パーマリンク → 保存）ことで、失われたRESTルートが復旧します。
