## この意味 {#what-this-means}

ログイントークンが、このサーバーが受け入れるサイズより大きくなっています。

サーバーはサイズを理由にログイントークンを拒否しました: Authorization ヘッダーで送信した場合は 400、URL で送信した場合は 414 です。クライアント側のエンコードでは小さくできません — サーバーのヘッダー／URL のサイズ上限を引き上げるか、トークンを小さくする必要があります。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. Apache では、vhost の設定で LimitRequestFieldSize（ヘッダー経路）または LimitRequestLine（URL 経路）を引き上げます。
2. nginx では、large_client_header_buffers を引き上げます。
3. プロキシや CDN の背後にある場合、その層で上限がかかっている可能性があります — 両方を確認してください。
4. 上限を変更できない場合は、このサイト用に小さいトークンを発行することについてサポートに連絡してください。
