## これが意味すること {#what-this-means}

店舗から WCPOS に、一時的に処理速度を落とすよう求められました。

対応は不要です。WCPOS は待機して自動的に再試行します。毎日このメッセージが表示される場合は、サイト管理者に店舗のレート制限について確認してください。

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ反映されていない変更が含まれている可能性があります。後の再試行で送信されます。

## トラブルシューティング {#troubleshoot}

1. 対応は不要です。POS は待機して自動的に再試行します。手動で再試行すると、スロットリングが長引くだけです。
2. 入力し直す必要はありません。該当する変更はデバイス上に保持され、後の試行で送信されます。
3. 毎日このメッセージが表示される場合は、サイト管理者に、どの層が 429 を返しているかを特定し、POS の REST トラフィックを許可するよう依頼してください。該当する層には、セキュリティプラグイン、CDN、ファイアウォールルール、ホスト独自の制限などがあります。
4. 展開したログエントリーのendpointとタイムスタンプは、管理者が自分のダッシュボードで該当する制限を突き合わせる際に役立ちます。
