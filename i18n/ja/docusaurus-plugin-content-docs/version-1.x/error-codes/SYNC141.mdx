## これが意味すること {#what-this-means}

ストアが一時的にリクエストを制限しているため、この操作は後で再試行されます。

しばらく待ってから再試行してください。レート制限が続く場合は、ストアのリクエスト制限を見直すようサイト管理者またはホスティング事業者に依頼してください。

## データへの影響 {#your-data}

変更はこのデバイスに保存されていますが、ストアには届いていません。この状態が続く場合は、WordPressサイトの管理担当者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. お待ちください。POSは自動的に間隔をあけて再試行します。手動で再試行すると、制限期間が延びるだけです。
2. 入力し直す必要はありません。該当する変更はデバイス上に保持され、後の試行で送信されます。
3. このコードが繰り返し表示される場合は、どの層が429を返しているのか（セキュリティプラグイン、CDNやファイアウォールのルール、ホスティング事業者自身の制限）を特定し、POSのRESTトラフィックを許可するようサイト管理者に依頼してください。
4. 展開したログエントリーのendpointとタイムスタンプは、管理者が自分のダッシュボードで該当する制限を突き合わせる際に役立ちます。
