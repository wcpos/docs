## これが意味すること {#what-this-means}

この商品画像は利用できませんが、商品自体は販売できます。

画像なしでそのまま会計を進めてください。WCPOSは後ほど画像の読み込みを再試行します。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

**レジ端末：**通常どおり販売できます。商品には影響がなく、画像はバックグラウンドで再試行されます。

**店舗側（WP Admin）：**

1. 特定の商品の画像が読み込まれない場合は、画像を再保存してください。メディアライブラリからファイルが削除された可能性があります。
2. 多数の画像が一度に失敗する場合は、サイトのメディアホスティングまたはCDNが原因です。ストアのウェブサイト自体で画像が表示されるか確認してください。
