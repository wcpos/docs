## これが意味すること {#what-this-means}

このバリエーションを商品に追加できませんでした。

ほかに変更はありません。商品を開き、バリエーションがあるか確認してください。ない場合は、親商品に設定された属性を使用していることを確認してから、もう一度追加してください。

## データへの影響 {#your-data}

この端末のデータを消去しないでください。店舗にまだ反映されていない変更が含まれている可能性があります。ほかに変更はありません。このバリエーションだけが追加されませんでした。

## トラブルシューティング {#troubleshoot}

1. ログ項目を展開して、店舗側で拒否された理由を確認してください。通常、属性の不足または無効なオプションの組み合わせが原因です。

**レジ側：** 商品を開き、バリエーションがあるか確認してください。すでにある場合は、再度追加しないでください。ない場合は、バリエーションが親商品に設定された属性を使用していることを確認し、各項目を修正してから再度追加してください。

**店舗側（WP Admin）：** 親商品の属性を確認してください。バリエーションで使われている属性はすべて親商品に存在し、バリエーションに使用する設定になっている必要があります。

引き続き拒否される場合は、**ログ**タブで**Copy debug info**を使い、サポートにお問い合わせください。
