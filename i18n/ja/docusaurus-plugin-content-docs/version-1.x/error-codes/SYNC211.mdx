## これが意味すること {#what-this-means}

店舗が送信された値を拒否しました。

店舗が示した理由で値を確認してください。入力した画面で値を修正し、もう一度保存してください。通常、値は商品、顧客、注文などのレコードに含まれていますが、店舗が拒否した設定やサインインのリクエストでこのコードが発生することもあります。その場合は該当画面で修正してください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだ届いていない変更が含まれている可能性があります。既存の商品、バリエーション、顧客、クーポンへの拒否された編集は通常、自動的に元に戻され、代わりに[SYNC202](/error-codes/SYNC202)として記録されます。このコードで表示され、変更が**店舗の状態 → データベース**にある場合、自動取り消しが行われていません。一覧にある他の変更と同様に扱ってください。設定やサインインのリクエストの場合、保存するものはありません。

## トラブルシューティング {#troubleshoot}

1. ログ項目を展開し、店舗が示した理由とエンドポイントを確認してください。理由には値が、エンドポイントにはレコード、設定、サインインのどれに由来するかが示されます。
2. 入力した画面で値を修正してください。よくある原因は、範囲外の値、拒否される形式、必須オプションの未入力です。その後、もう一度保存してください。変更が**店舗の状態 → データベース**に表示されていない場合は、店舗側のバージョンに戻されているため、修正した値でもう一度変更してください。修正後も**店舗の状態 → データベース**の**「… サーバーに届かなかった変更」**に表示されている場合は、その行の**もう一度送信**をタップしてください。
3. 代わりにレコードが**「… 保留中の変更」**の下に*「店舗で最新のバージョンが必要とされました」*という理由で表示されている場合は、値に問題はありません。[SYNC221](/error-codes/SYNC221)の説明に従い、**もう一度送信**と**デバイスの変更を破棄**のどちらかを選んでください。
4. 設定またはサインインのリクエストだった場合は、入力した画面で値を修正し、もう一度保存してください。**サイト管理者:** POSのログに詳細がない場合は、ブラウザーの開発者ツール（Networkタブ）、またはデスクトップアプリの**詳細設定 → 開発者ツールを切り替え**で店舗からの応答を確認できます。
5. **サイト管理者:** 指定された値がPOSでは正しく見える場合は、WP Adminで同じレコードと比較してください。店舗に追加されたプラグインの検証により、POSでは問題ないと判断される値が拒否されることがあります。
