## これが意味すること {#what-this-means}

このレシートの自動印刷が開始されませんでした。

選択されているプリンター、テンプレート、接続を確認したうえで、**今すぐ印刷** から手動でレシートを印刷してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. **今すぐ印刷** から手動でレシートを印刷してください。売上には影響ありません。
2. 印刷設定を確認してください。正しいプリンターが選択され、レシートテンプレートが選ばれている必要があります。
3. すべての売上で自動印刷が失敗する場合は、手動印刷ができるかどうかを確認してください。手動は成功するのに自動だけ失敗するなら設定の問題、どちらも失敗するならプリンターの問題です。
