## これが意味すること {#what-this-means}

このレシートの自動印刷が開始されませんでした。

販売は保存されています。注文のレシートを開き、**今すぐ印刷**をタップして印刷してください。次回からレシートが自動印刷されるよう、自動印刷の設定とプリンターを確認してください。

## データへの影響 {#your-data}

販売は保存されています。注文や商品データには影響ありません。

## トラブルシューティング {#troubleshoot}

1. 販売後に表示されたレシートで**今すぐ印刷**を押すと、手動で印刷できます。販売への影響はありません。レシートが画面に表示されない場合は、WCPOS Proで**注文**を開き、注文の**Receipt**アクションを選んで**今すぐ印刷**を押してください。
2. 販売後にレシートがまったく表示されない場合は、自動表示がオフになっている可能性があります。カート上部のスライダーアイコンからカートの設定を開き、**Automatically show receipt after checkout**と**Automatically print receipt after checkout**の両方をオンにしてください。自動印刷はそのレシート上で行われるため、両方の設定が必要です。
3. **Settings → Printing**でプリンターを確認してください。使用するプリンターが**Printers**に表示され、プリンターの**Edit**画面から**Test Print**を実行すると印刷されることを確認します。
4. **今すぐ印刷**でも失敗する場合は、プリンターかその接続に問題があります。[PRINT301](/1.x/error-codes/PRINT301)を参照してください。手動印刷はできるのに、両方の設定をオンにしても自動印刷に失敗し続ける場合は、**ログ**タブの**デバッグ情報をコピー**を使い、サポートに問い合わせてください。
