## この意味 {#what-this-means}

このストアの WCPOS プラグインが、このバージョンのアプリには古すぎます。

アプリは更新されましたが、ストアの WCPOS プラグインは更新されておらず、両方のバージョンがもう連携して動作しなくなっています。サイトを管理している担当者に、WP Admin で WCPOS プラグインを更新してから、再度接続するよう依頼してください。レジ側では何も変更する必要はありません。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。この状態が続く場合は、WordPress サイトを管理している担当者に問い合わせてください。

## トラブルシューティング {#troubleshoot}

**ストア側** — WordPress サイトを管理している担当者向け:

1. WP Admin → プラグイン → WCPOS を最新バージョンに更新します。WCPOS Pro がインストールされている場合は、同じタイミングで一致するバージョンに更新してください。
2. 更新が表示されない場合は、WP Admin → ダッシュボード → 更新 を確認してください。Pro については、認証されていない更新プログラムが更新をブロックしています（[LICENSE301](./LICENSE301) を参照）— まずそれを解消してください。

**レジ側** — レジ担当者向け: ストアが更新されたら、再接続してください。ストアのアドレスを再入力する必要はありません。

**ストアをまだ更新できない場合:** 代わりにサポートに連絡してください。レジにはプラグインに一致するアプリのバージョンが必要で、どのバージョンかはサポートが案内できます。その際、アプリのバージョン（レジから）とストアの現在の WCPOS バージョン（WP Admin から）を尋ねられます。
