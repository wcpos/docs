## これが意味すること {#what-this-means}

チェックアウトは完了しませんでしたが、カートはそのまま残っているので再試行できます。

カートの内容を確認して、チェックアウトをやり直してください。現在のカートの内容は保持されています。

## データへの影響 {#your-data}

注文自体は安全で、変更されていません。

## トラブルシューティング {#troubleshoot}

**レジ端末** — レジ係向け：

1. カートを確認し（内容は変わっていません）、もう一度チェックアウトをお試しください。
2. 再度失敗した場合は、ストアヘルス → ログでログ項目を展開してください。serverCodeとステータスから、店舗が注文を拒否したか、その理由を確認できます。
3. 理由として特定の明細行が示されている場合は、その行を削除して会計を完了し、あとでその商品を調査してください。

**店舗側** — サイト管理者向け：ステータスが500番台で失敗を繰り返す場合は、サイトの問題です。WooCommerce → ステータス → ログで、失敗時刻のPHPエラーを確認してください。
