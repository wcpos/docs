## これが意味すること {#what-this-means}

印刷中に予期しない問題が発生しました。販売には影響ありません。

このログ項目に記載された印刷またはレシートの操作を再度実行してください。繰り返し発生する場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

販売には影響ありません。

## トラブルシューティング {#troubleshoot}

1. まずログエントリーを展開し、失敗した操作を特定してください。このコードは物理的な印刷だけでなく、レシートメールのキュー操作やレシートテンプレートの同期も対象としています。
2. ログに記載された操作だけを再試行してください。紙への印刷の場合に限り、注文画面から再印刷します。キューに入ったメールはストアヘルスから再送信し、テンプレートの同期は接続した状態でレシート画面を再度開いて再試行してください。
3. その操作が引き続き失敗する場合は、**ログ**タブで**Copy debug info**を使い、サポートにお問い合わせください。
