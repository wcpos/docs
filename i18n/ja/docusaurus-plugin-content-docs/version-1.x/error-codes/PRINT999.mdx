## これが意味すること {#what-this-means}

印刷で予期しない問題が発生しました。

もう一度印刷をお試しください。失敗が続く場合は、注文画面から再印刷し、診断情報を添えてサポートにお問い合わせください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. まずログエントリーを展開し、失敗した操作を特定してください。このコードは物理的な印刷だけでなく、レシートメールのキュー操作やレシートテンプレートの同期も対象としています。
2. ログに記載された操作だけをやり直してください。注文画面からの再印刷は物理的な印刷の場合のみ行い、キューに入っているメールはストアヘルスから再試行または削除し、テンプレートの同期は接続された状態でレシート画面を開き直して再試行してください。
3. その操作が失敗し続ける場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。
