## このエラーの意味 {#what-this-means}

この注文の明細にはPOSで読み取れない価格情報があるため、金額には保存済みの合計が使用されました。

WCPOS が注文に追加する各明細には、価格の算出方法を記録した小さな情報が含まれています。これには価格そのもの、税込みかどうか、税区分が含まれます。この情報を読み取れない場合、WCPOS は再計算せずに、明細にすでに保存されている合計を使用します。表示される金額は通常正しいものですが、確認されてはいないため、支払いを受ける前に注文合計を確認してください。

一般的な原因は、現在のバージョンでは認識されなくなった形式で、非常に古いバージョンの WCPOS により追加された明細、またはバックアップから復元された明細です。

## データについて {#your-data}

注文は安全で、データが失われることはありません。影響を受ける明細の金額だけが未確認です。

## トラブルシューティング {#troubleshoot}

**レジで** — 支払いを受ける前に次を実行してください:

1. 注文合計が想定どおりか確認してください。影響を受ける明細の金額には、再計算された価格ではなく保存済みの合計が使用されています。
2. 該当する明細行を削除し、商品、手数料、または配送方法をもう一度追加してください。新しく追加した明細行には常にアプリが読み取れる価格情報が含まれるため、次回の注文時に通知は消えます。
3. 合計金額が正しくなかった場合、追加し直した明細行によって修正されます — 変更前後を比較してください。

**ストア側** — サイト管理者向け：

1. 古い注文や復元された注文ではなく、最近追加された明細行でこの問題が発生する場合、何らかの要因がアプリで読み取れない形式でPOS価格データを書き込んでいます。
2. カートまたは注文の明細データを変更するプラグインを記録してください。次に、**ストアの健全性 → ログ**でログエントリを開き、**コピー**（または**共有**）を使用して詳細を送信し、注文番号を添えてサポートにお問い合わせください。
