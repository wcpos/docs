## これが意味すること {#what-this-means}

選択されているプリンターに接続できません。

プリンターの電源が入っていて接続されていることを確認してから、もう一度印刷をお試しください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. プリンターの電源が入っていること、ケーブルまたはネットワーク接続がしっかり挿さっていることを確認してください。
2. ネットワークプリンターの場合は、レジ端末とプリンターが同じネットワークに接続され、プリンターのアドレスが変わっていないことを確認してください。DHCPの更新でアドレスが変わる場合があります。変わっている場合は、POSでプリンターを設定した場所からアドレスを更新してください。
3. プリンター本体からセルフテストを印刷してハードウェアが正常であることを確認したうえで、POSからもう一度お試しください。
