## これが意味すること {#what-this-means}

選択されているプリンターに接続できません。

プリンターの電源が入っていて接続されていることを確認してから、もう一度印刷をお試しください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. プリンターの電源が入っていること、ケーブルまたはネットワーク接続がしっかり挿さっていることを確認してください。
2. ローカルネットワーク経由でレジと直接通信するプリンターの場合、レジとプリンターが同じネットワークに接続されていること、プリンターのアドレスが変わっていないことを確認してください。DHCPの更新でアドレスが変わることがあります。変わっていた場合は、POSの設定時に指定したプリンターのアドレスを更新してください。
3. クラウド印刷のレシートでは、レジとプリンターが同じネットワークに接続されている必要はありません。確認する内容は配信方式によって異なります（[クラウド印刷](../receipts/cloud-printing.mdx#status)）。
   - **Star CloudPRNTまたはEpson Server Direct Print**（プリンターがWCPOSに問い合わせる方式）：プリンターが接続確認を行うまで、POSのプリンターカードには**Waiting**と表示されます。プリンターがインターネットに接続できること、問い合わせURLとトークンがWCPOSで生成されたものと一致することを確認してください。[プリンターがWaitingのまま](../receipts/cloud-printing.mdx#troubleshooting)も参照してください。
   - **Star Online**：カードにはStar Onlineが報告するデバイスの状態が表示されます。デバイスが**Offline**または**Unknown**と表示される場合は、レジではなくStar Onlineダッシュボードで対処してください。
   - **PrintNode**：PrintNodeデスクトップクライアントを実行しているコンピューターが起動しており、クライアントがオンラインである必要があります。また、POSで選択したプリンターがクライアントの報告するプリンターと一致していることを確認してください。[PrintNodeのジョブが印刷されない](../receipts/cloud-printing.mdx#troubleshooting)も参照してください。
4. プリンター本体からセルフテストを印刷してハードウェアが正常であることを確認したうえで、POSからもう一度お試しください。
