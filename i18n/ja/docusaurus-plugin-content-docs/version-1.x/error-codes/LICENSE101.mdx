## これが意味すること {#what-this-means}

お使いのWCPOS Proライセンスが、このストアまたはデバイスで有効化されていません。

ローカル、ライセンスサーバー、アップデーターの各ステータスを確認したうえで、指定されたストアに対してライセンスを有効化してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

**店舗側** — サイト管理者／ライセンス所有者向け：

1. WP AdminのPOS設定でライセンスの状態を確認してください。このストアのURLと完全に一致する形で「有効」と表示されているはずです。
2. サイトURLの変更（httpからhttpsへ、wwwの追加や削除、ドメイン移転、ステージングへの複製）を行うと、新しいアドレスではライセンスが無効になります。現在のアドレスで再度有効化してください。
3. ライセンスが有効と表示されているのにPOSの表示が異なる場合は、1度無効にしてから再度有効にしてください。
4. それでもロックされたままの場合は、デバッグ情報をエクスポートし、ライセンスの参照情報を添えてサポートにお問い合わせください。

**レジ端末：**ライセンスを再度有効にした後、再読み込みして変更を反映します。
