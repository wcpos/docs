## このエラーの意味 {#what-this-means}

この注文は店舗に現在存在しない税率を参照しているため、税額が正しくない可能性があります。

注文の明細に、店舗の現在の税率表にない税率が設定されています。ほとんどの場合、注文の開始後に WooCommerce でその税率が削除または編集されたことが原因です。WCPOS は税率を参照できないため、この注文の税額が、現在店舗で請求される税額と一致しない可能性があります。

## データについて {#your-data}

注文データは安全です。問題となるのは税額だけです。支払いを受ける前に税額を確認し、税率について店舗管理者に問い合わせてください。

## トラブルシューティング {#troubleshoot}

**レジでの対応** — 支払いを受ける前に、次の操作を行ってください：

1. 注文の税額を確認してください。店舗に現在存在しない税率で計算されています。
2. 税額が正しくないと思われる場合は、新しい注文で販売を開始してください。新しい注文には店舗の現在の税率が適用されます。

**店舗（WP Admin）** — サイト管理者向け：

1. **WooCommerce → 設定 → 税**に移動し、最近税率が削除または編集されていないか確認してください。未完了の注文が参照している税率を削除したことが、よくある原因です。
2. 意図的に税率を削除した場合は、その時点で未完了だった注文を作り直す以外に対応は必要ありません。
3. 店舗の税率が変更されていない場合、POS に古いコピーが残っている可能性があります。**店舗の状態 → データベース → 税率 → クリアして再ダウンロード**から更新してください。影響するのはそのコレクションだけで、ユーザーがログアウトされることはありません。[店舗の状態](/1.x/support/store-health#clear-and-redownload)を参照してください。
4. 税率のダウンロード完了後に再びこのコードが表示された場合は、**店舗の状態 → ログ**でログエントリを開き、**コピー**（または**共有**）で詳細を送信し、注文番号を添えてサポートに問い合わせてください。
