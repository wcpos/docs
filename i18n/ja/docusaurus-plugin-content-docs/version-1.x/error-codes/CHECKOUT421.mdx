## このエラーの意味 {#what-this-means}

この注文は、店舗に現在存在しない税率を参照しているため、税額が正しくない可能性があります。

注文内の明細に、店舗の現在の税率表にない税率が設定されています。ほとんどの場合、注文の開始後に WooCommerce でその税率が削除または編集されたことが原因です。WCPOS はその税率を取得できないため、この注文の税額は現在店舗で適用される税額と一致しない可能性があります。

## データについて {#your-data}

注文データは安全です。問題となるのは税額のみです。支払いを受ける前に確認し、税率について店舗管理者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジでの対応** — 支払いを受ける前に実施してください：

1. 注文の税額を確認してください。店舗に現在存在しない税率で計算されています。
2. 税額が正しくないと思われる場合は、新しい注文で販売を開始してください。新しい注文には店舗の現在の税率が適用されます。

**店舗（WP Admin）** — サイト管理者向け：

1. **WooCommerce → 設定 → 税** に移動し、最近税率が削除または編集されていないか確認してください。すでに参照されている未完了の注文の税率を削除することが、通常の原因です。
2. 意図的に税率を削除した場合は、その時点で未完了だった注文を再開する以外に必要な操作はありません。
3. 店舗の税率が変更されていない場合、POS に古いコピーが保持されている可能性があります。**店舗の状態 → データベース → 税率 → クリアして再ダウンロード** から更新してください。これはそのコレクションにのみ影響し、ログアウトされることはありません。[店舗の状態](/support/store-health#clear-and-redownload)を参照してください。
4. 税率のダウンロード完了後に再度このコードが表示される場合は、**店舗の状態 → ログ** でログエントリを開き、**コピー**（または**共有**）を使用して詳細を送信し、注文番号を添えてサポートにお問い合わせください。
