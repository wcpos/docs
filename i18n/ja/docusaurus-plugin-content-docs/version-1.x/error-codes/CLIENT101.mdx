## これが意味すること {#what-this-means}

WCPOSが起動を完了できませんでした。

レジ端末では、画面が真っ白または停止したように見えたり、読み込み中の表示が消えなかったりします。通常、端末のローカルデータベースを開けないことを意味します。再起動で解消する場合もあります。解消しない場合は、ローカルデータベースを消去して再度開いてください。WCPOSが店舗からすべてのデータを再ダウンロードします。

:::warning 同期されていないデータが消去されます
ローカルデータベースを消去すると、**この端末にあり、店舗にまだ同期されていないデータが完全に削除されます**。これにはオフライン中の販売などが含まれます。アプリを開けないため、先に同期できず、復元もできません。この端末に重要な未同期の販売データがあると分かっている場合は、消去する**前に**サポートへ連絡してください。
:::

## データへの影響 {#your-data}

店舗のデータは安全です。次回アプリを開くと再びダウンロードされます。消去されるのはこの端末のローカルコピーだけですが、店舗にまだ届いていない変更も含まれます（上記の警告を参照）。

## トラブルシューティング {#troubleshoot}

1. アプリを1度再起動してください。Webではタブを完全に再読み込みします。一時的な起動エラーなら、それだけで解消することがあります。
2. 起動しない場合、ローカルデータベースを開けない可能性が高いです。データベースを消去して再度開いてください。[ローカルデータをすべて消去](/support/troubleshooting/clear-local-data)の手順には、アプリ内ボタン、Webアプリ、デスクトップアプリでの操作が記載されています。WCPOSが店舗データを自動で再ダウンロードします。（この端末の未同期データは削除されます。上記の警告を参照。）
3. 消去後も起動に失敗する場合は、**デバッグ情報をコピー**で情報をコピーするか、アプリのログを開けない場合はブラウザーのコンソールエラーを取得し、サポートに連絡してください。
