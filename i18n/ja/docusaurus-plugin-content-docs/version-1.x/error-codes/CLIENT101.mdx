## これが意味すること {#what-this-means}

WCPOSが起動を完了できませんでした。

レジでは、画面が真っ白または停止したように見えたり、読み込み中の表示が消えなかったりします。WCPOSを再起動してください（Web版ではタブを再読み込みします）。起動時のエラーは、多くの場合自然に解消します。それでも起動しない場合は、何も消去する前にサポートへお問い合わせください。

:::warning このデバイスのデータを消去しないでください
このデバイスには、店舗にまだ届いていない販売データ（オフライン中の販売など）が保存されている可能性があります。WCPOSを起動できない間は送信できないため、ローカルデータを消去したり、サインアウトしたり、再インストールしたりすると、データが完全に削除されます。何かを消去する前にサポートへお問い合わせください。
:::

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ届いていない変更が含まれている可能性があります。店舗側のデータは安全で、影響を受けません。

## トラブルシューティング {#troubleshoot}

1. WCPOSを一度再起動してください。Web版ではタブを完全に再読み込みしてください。一時的な起動エラーは自然に解消することがあります。
2. それでも起動しない場合は、何も消去する前にサポートへお問い合わせください。WCPOSが開き、操作できる場合は、**ログ**タブの**デバッグ情報をコピー**を送ってください。開けない場合は、ブラウザーのコンソール（開発者ツール）に表示されるエラー、またはデスクトップアプリの**詳細設定 → 開発者ツールを切り替え**に表示されるエラーを送ってください。
3. お待ちの間、ローカルデータを消去したり、サインアウトしたり、再インストールしたりしないでください。このデバイス上のデータを先に復元する必要があるか、サポートからご案内します。
