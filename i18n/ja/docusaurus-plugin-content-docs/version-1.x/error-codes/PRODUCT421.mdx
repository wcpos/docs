## これが意味すること {#what-this-means}

この商品のバリエーション価格データを読み取れなかったため、表示価格が誤っているか表示されない場合があります。

WooCommerceで商品を保存し直して価格データを再構築してください。多数の商品でこの現象が発生する場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、ストア管理者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジ端末：**販売前に価格を確認してください。価格が誤っている、または表示されていない場合は、店舗側で修正されるまでその価格で販売しないでください。

**店舗側（WP Admin）：**

1. 商品を開いて再保存してください。POSが読み取れなかった価格データが再構築されます。
2. 各バリエーションに価格が設定されていることを確認してください。価格のないバリエーションがあると、価格範囲を読み取れなくなります。
3. 多数の商品で同時にこのコードが表示される場合は、価格系プラグインがPOSの読み取れない形式で価格データを書き込んでいる可能性が高いです。どのプラグインが価格を管理しているかを控えて、サポートにお問い合わせください。
