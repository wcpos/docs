## これが意味すること {#what-this-means}

WCPOSはその店舗に切り替えられませんでした。

WCPOSを再読み込みして、もう一度店舗を選択してください。このデバイス上のデータは失われません。

同じサイト上で店舗またはレジ係を切り替える処理が、完了前に失敗しました。このデバイスにある切り替え前の店舗のデータは変更されていません。

## データへの影響 {#your-data}

このデバイス上のデータは失われません。送信待ちのデータを含め、切り替え前の店舗のデータは変更されていません。

## トラブルシューティング {#troubleshoot}

1. WCPOSを再読み込みしてください。Web版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを終了して再度開きます。
2. もう一度店舗（およびレジ係）を選択してください。
3. 切り替えに繰り返し失敗する場合は、**ログ**タブの**デバッグ情報をコピー**をタップして、サポートへお問い合わせください。解決のためにローカルデータを消去したり、サイトを削除したりしないでください。送信前のデータを含め、切り替え前の店舗のデータはこのデバイスにあります。
