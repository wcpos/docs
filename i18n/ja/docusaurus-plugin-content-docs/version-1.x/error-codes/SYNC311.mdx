## これが意味すること {#what-this-means}

このデバイスのデータは別のバージョンのWCPOSで保存されているため、まだ開けません。

WCPOSを最新バージョンに更新して、もう一度開いてください。それでも開けない場合は、**デバッグ情報をコピー**をタップしてサポートへお問い合わせください。通常、このデバイスでアプリを更新またはダウングレードした後に発生します。

:::warning このデバイスのデータを消去しないでください
このデバイスには、店舗にまだ届いていない販売データ（オフライン中の販売など）が保存されている可能性があります。データを開けない間は送信できないため、ローカルデータベースを消去したり、サインアウトしたり、再インストールしたりすると、データが完全に削除されます。何かを消去する前にサポートへお問い合わせください。
:::

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ届いていない販売データが含まれている可能性があります。店舗側のデータは安全で、影響を受けません。

## トラブルシューティング {#troubleshoot}

1. このデバイスでWCPOSを最新バージョンに更新してから、もう一度開いてください。
   - **Web版：**ブラウザーのタブを再読み込みしてください。古いバージョンが再び表示される場合は、**Shift**キーを押しながら再読み込みしてください。Web版で読み込まれるバージョンは、店舗のWCPOSプラグインが決定します。再読み込みで解決しない場合は、サイト管理者にWCPOSプラグインの更新を依頼してください。
   - **デスクトップ版：**保留中の更新をインストールして、アプリを再度開いてください。更新が表示されない場合は、[インストール](/getting-started/installation)ページから最新のビルドをダウンロードしてください。
   - **iPhone、iPad、Android：**インストール元の配信経路でWCPOSを更新してください。iOSではTestFlight、AndroidではPlayのテストプログラムを使用します。どちらも[インストール](/getting-started/installation)ページからアクセスできます。
2. それでも開けない場合は、**ログ**タブの**デバッグ情報をコピー**をタップしてサポートへお問い合わせください。このデバイスに店舗に届いていない販売データがある可能性も伝えてください。
3. お待ちの間、ローカルデータを消去したり、サインアウトしたり、再インストールしたりしないでください。このデバイス上のデータを先に復元する必要があるか、サポートからご案内します。
