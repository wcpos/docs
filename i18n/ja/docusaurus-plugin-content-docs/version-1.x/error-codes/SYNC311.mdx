## これが意味すること {#what-this-means}

このデバイスに保存されているデータは別のアプリバージョンのもので、開くことができません。

解決するには、デバイスのローカルデータベースを消去してアプリを再度開きます。WCPOSはその後、店舗からすべてのデータを再ダウンロードします。スキーマの不一致は通常、このデバイスでアプリを更新またはダウングレードした後に発生します。

:::warning 未同期データを消去すると失われます
ローカルデータベースを消去すると、**店舗にまだ同期されていないこのデバイス上のデータは完全に削除されます**（オフライン中の販売データなど）。データベースを開けないため、先に同期できず、復元もできません。このデバイスに重要な未同期の販売データが残っている場合は、消去する**前に**サポートにお問い合わせください。
:::

## データへの影響 {#your-data}

店舗のデータは安全です。次回アプリを開くと再ダウンロードされます。消去されるのはデバイス上のローカルコピーだけですが、店舗に未反映の変更も含まれます（上記の警告を参照）。

## トラブルシューティング {#troubleshoot}

1. このデバイスでWCPOSが最新バージョンであることを確認してください。スキーマの不一致は通常、バージョン変更後に発生します。
2. ローカルデータベースを消去してアプリを再度開いてください。[すべてのローカルデータを消去](/support/troubleshooting/clear-local-data)の手順に従ってください。アプリ内ボタン、ウェブアプリ、デスクトップアプリの方法を説明しています。WCPOSは店舗のデータを自動的に再ダウンロードします。（このデバイスの未同期データは削除されます。上記の警告を参照してください。）
3. 消去後にエラーが再発する場合は、**デバッグ情報をコピー**を使用してサポートにお問い合わせください。
