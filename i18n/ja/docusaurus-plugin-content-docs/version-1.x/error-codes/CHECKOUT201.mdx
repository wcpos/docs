## これが意味すること {#what-this-means}

チェックアウトが完了したかどうかをWCPOSは確認できませんでした。

むやみに再試行しないでください。まずストア側に注文が作成されていないか確認し、それでも結果がはっきりしない場合は診断情報をエクスポートしてください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

**まず、状況を悪化させないでください：**注文が存在するか確認できるまで、チェックアウトを再試行したり、顧客に再度請求したりしないでください。

**注文の有無を確認します** — 確認方法は利用できる環境によって異なります。WCPOS ProではPOSを同期し、レジ端末の「注文」一覧を確認します。それ以外の場合は、担当者にWP AdminのWooCommerce → 注文を開いてもらい、合計金額と直近数分の注文を検索してもらいます。注文があれば販売は完了しています。再作成しないでください。

**次に：**確認して注文が存在しない場合は、チェックアウトを1回だけ再試行します。それでも不明な場合は、次に試す前にデバッグ情報をエクスポートしてサポートに連絡してください。
