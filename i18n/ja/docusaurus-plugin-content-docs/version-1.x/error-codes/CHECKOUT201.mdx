## これが意味すること {#what-this-means}

チェックアウトが完了したかどうかをWCPOSは確認できませんでした。

再試行する前に注文を開き、ステータスを確認してください。支払い済みまたは完了している場合は、再度請求しないでください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。この状態が続く場合は、**ログ**タブで**デバッグ情報をコピー**し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 注文のステータスがわかるまで、**支払いを処理**を再度押したり、顧客に再度請求したりしないでください。
2. 注文を開き、ステータスを確認してください。WCPOS Proでは、まずレジ端末の注文を更新します — **店舗の健全性 → データベース**で、**注文**の行にある**⋮**メニューから**今すぐ変更を確認**を選び、その後**注文**で注文を開きます。Proをお使いでない場合は、担当者にWP Adminの**WooCommerce → 注文**を開いてもらい、合計金額と直近数分の注文から検索してください。
3. 注文が見つかっただけでは不十分です。注文があっても、支払い済みとは限りません。ステータスが**処理中**または**完了**なら、販売は成立しています。再度請求しないでください。
4. 注文が未払いのまま、または注文が見つからない場合は、顧客が支払ったか確認してください。カードの場合は決済事業者の画面、レシート、またはダッシュボードで、現金の場合はレジの現金と預かった金額を確認します。支払い済みなら、再度請求しないでください。注文が見つかった場合は、アプリを再読み込みしてステータスをもう一度確認します（アプリの起動時に、レジ端末は支払いを記録した販売を完了します）。注文が見つからない、または未払いのままの場合は、最後の手順に進んでください。
5. 注文が未払いで、決済事業者にも請求記録がない場合は、チェックアウトを1回だけ再試行してください。
6. それでも状況が不明な場合は、再試行する前に**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。
