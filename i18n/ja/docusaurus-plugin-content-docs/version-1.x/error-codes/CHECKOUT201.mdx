## これが意味すること {#what-this-means}

チェックアウトが完了したかどうかをWCPOSは確認できませんでした。

再試行する前に注文を開き、ステータスを確認してください。支払い済みまたは完了済みの場合は、再度請求しないでください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。この状態が続く場合は、**ログ**タブで**デバッグ情報をコピー**を使用し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 注文のステータスがわかるまで、再度**支払いを処理**を押したり、顧客に再請求したりしないでください。
2. 注文を開いてステータスを確認してください。WCPOS Proでは、まずレジの注文を更新します。**店舗の状態 → データベース**を開き、**注文**行の**⋮**メニューから**今すぐ変更を確認**を選択してから、**注文**で注文を開いてください。Proをお使いでない場合は、担当者にWP Adminの**WooCommerce → 注文**を開いてもらい、合計金額と直近数分の注文を検索してください。
3. 注文が見つかっただけでは不十分です。注文が存在しても、支払い済みとは限りません。ステータスが**処理中**または**完了**なら販売は完了しています。再度請求しないでください。
4. 注文が未払いのまま、または注文が見つからない場合は、顧客が支払ったか確認してください。カードの場合は決済プロバイダーの画面、レシート、ダッシュボードを確認し、現金の場合はレジと預かった金額を確認します。支払い済みなら再度請求しないでください。注文が見つかった場合はアプリを再読み込みし、ステータスをもう一度確認してください（起動時に、レジは支払いを記録した販売の処理を完了します）。注文が見つからない、または未払いのままの場合は最後の手順に進んでください。
5. 注文が未払いで、プロバイダーにも請求記録がない場合は、チェックアウトを一回だけ再試行してください。
6. まだ状況がはっきりしない場合は、もう一度試す前に**ログ**タブで**デバッグ情報をコピー**を使用し、サポートにお問い合わせください。
