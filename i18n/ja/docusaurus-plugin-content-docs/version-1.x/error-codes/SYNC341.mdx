## このエラーの意味 {#what-this-means}

この店舗では、より新しいバージョンのPOSアプリが必要になりました。

店舗のWCPOSプラグインが、このバージョンのアプリが対応しているものより新しい同期プロトコルに移行しました。そのため、アプリが更新されるまで店舗では意図的に同期が一時停止されます。これは障害ではなく保護機能です。古いアプリが店舗データを誤って読み書きすることを防ぎます。

## データについて {#your-data}

レジ上のデータが失われることはありません。送信待ちの販売データや編集内容はデバイス上に安全に保持され、更新済みのアプリが店舗に接続すると同期されます。まだ新しいアプリがない場合（以下の最後の2つの手順を参照）、利用可能になるまでキューに保持されます。

## トラブルシューティング {#troubleshoot}

1. Webアプリでは、ブラウザータブを再読み込みしてください。Webアプリは再読み込み時に新しいバージョンを取得します。画面が戻る場合は、ハード再読み込みを行ってください（再読み込み中に **Shift** を押したままにします）。
2. デスクトップでは、保留中の更新をインストールしてアプリを再度開いてください。アプリの再接続時に確認が実行されます。更新が表示されない場合は、[インストール](/getting-started/installation)ページから最新ビルドをダウンロードしてください。
3. iPhone、iPad、またはAndroidでは、インストールした配布チャネルからWCPOSを更新してください。iOSではTestFlight、AndroidではPlayテストプログラムを使用します。どちらも[インストール](/getting-started/installation)ページからリンクされています。更新後、アプリを再度開いてください。
4. **サイト管理者:** まだ新しいアプリが利用可能でない場合、店舗の WCPOS プラグインが対応するアプリリリースより先に更新されています。店舗で以前の WCPOS プラグインバージョンに戻すと、新しいアプリがリリースされるまで同期が再開されます。
5. アプリの更新もプラグインのロールバックも利用できない場合は、WCPOS サポートにお問い合わせください。
