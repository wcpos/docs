## これが意味すること {#what-this-means}

支払いは成功しましたが、その後のステータス更新をWCPOSが行えませんでした。

決済は完了しています。二重に請求しないでください。注文を再度開いてステータスを更新してください。それでも古い状態に見える場合は、以下の手順で更新します。

## データへの影響 {#your-data}

決済は完了しています。二重に請求しないでください。画面上のステータスだけが古い状態です。

## トラブルシューティング {#troubleshoot}

1. お客様に再度請求しないでください。店舗の決済ページで決済が確認されています（**注文 #… の決済が完了しました**という通知が表示された場合は、決済済みです）。レジでの後続の更新だけが失敗しました。
2. 注文を再度開いてステータスを更新し、次の販売に進んでください。
3. 決済済みの注文がカート内で未処理の注文として表示される場合は、レジ側のデータを更新します。**ストアヘルス → データベース**を開き、**注文**の行にある**⋮**メニューから**Check for changes now**を選択してください。決済済みのステータスが届くと、注文はカートから消えます。WCPOS Proでは、その注文だけを更新することもできます。**注文**で注文の**⋮**メニューを開き、**Sync**を選択してください。
4. まだ未処理として表示される場合は、アプリを再読み込みしてください（Webではブラウザーのタブを再読み込みし、デスクトップとモバイルではアプリを終了して再度開きます）。起動時に、決済を記録済みの販売処理が完了します。
5. **サイト管理者：**確認するには、**WooCommerce → 注文**で注文を開きます。ここでは決済済みと表示されます。
