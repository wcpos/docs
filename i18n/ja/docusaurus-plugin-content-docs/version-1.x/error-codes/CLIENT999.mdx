## これが意味すること {#what-this-means}

WCPOSで予期しないエラーが発生しました。

もう一度操作をお試しください。再び失敗する場合は、診断情報をエクスポートしてサポートにお問い合わせください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. もう一度操作をお試しください。
2. ログエントリーを展開し、イベントコードとコンテキストを控えてください。999のコードは、その失敗に専用のコードがまだ割り当てられていないことを意味し、この情報こそが原因を特定する手がかりになります。
3. 繰り返す場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。報告いただくことで、専用のコードが新たに割り当てられます。
