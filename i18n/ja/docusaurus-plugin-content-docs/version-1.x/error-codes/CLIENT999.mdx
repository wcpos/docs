## これが意味すること {#what-this-means}

WCPOSで予期しないエラーが発生しました。

再試行する前に、直前の操作が完了したか確認してください。販売の場合は注文を開き、ステータスを確認します。繰り返し発生する場合は、**デバッグ情報をコピー**してWCPOSサポートに送信してください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 再試行する前に、直前の操作が完了したか確認してください。販売の場合は注文を開き、ステータスを確認します。支払いの場合は、決済端末または決済事業者も確認してください。完了していなければ、もう一度だけ操作してください。
2. ログエントリーを展開し、イベントコードとコンテキストを控えてください。999のコードは、その失敗に専用のコードがまだ割り当てられていないことを意味し、この情報こそが原因を特定する手がかりになります。
3. 繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**してWCPOSサポートに送信してください。具体的なコードの追加には、問題の報告が必要です。
