## これが意味すること {#what-this-means}

WCPOSで予期しないエラーが発生しました。

再試行する前に、直前の操作が完了したか確認してください。販売の場合は注文を開いてステータスを確認します。問題が繰り返し発生する場合は、**デバッグ情報をコピー**をタップしてWCPOSサポートに送信してください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。問題が繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**を使用し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 再試行する前に、直前の操作が完了したか確認してください。販売の場合は注文を開いてステータスを確認し、支払いの場合は端末またはプロバイダーも確認します。完了していない場合は、もう一度だけ試してください。
2. ログエントリーを展開し、イベントコードとコンテキストを控えてください。999のコードは、その失敗に専用のコードがまだ割り当てられていないことを意味し、この情報こそが原因を特定する手がかりになります。
3. 問題が繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**をタップしてWCPOSサポートに送信してください。この報告を基に、問題に対応する固有のコードが追加されます。
