## これが意味すること {#what-this-means}

デバイスレベルのクラッシュにより、WCPOSが停止しました。

WCPOSを再起動し、直前の販売または変更が保存されたか確認してください。アプリまたはシステムの更新があればインストールしてください。クラッシュが繰り返し発生する場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。クラッシュしたときに販売や変更を保存していた場合は、再度操作する前に保存されたことを確認してください。

## トラブルシューティング {#troubleshoot}

1. 再度操作する前にWCPOSを再起動し、直前の販売または変更が保存されたか確認してください。**店舗の健全性 → データベース**（販売が**送信待ちの変更**として表示されている場合は、保存済みで送信中です）、カート、注文（WCPOS Proの場合）、または**WooCommerce → 注文**を確認します。カード決済の場合は端末または決済事業者も確認してください。顧客への請求が済んでいる場合は、再度請求しないでください。本当に保存されていない場合に限り、再入力してください。
2. アプリと端末のOSに保留中の更新をインストールしてください。ネイティブアプリのクラッシュは、すでに修正済みの不具合であることがよくあります。管理対象のレジ端末では、端末の管理者が更新します。
3. 同じ操作でクラッシュが繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**してサポートにお問い合わせください。クラッシュ時に何をタップしたかも正確に伝えてください。
