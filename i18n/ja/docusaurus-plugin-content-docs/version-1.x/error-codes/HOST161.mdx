## この意味 {#what-this-means}

ホストがこのストアのレジにレート制限をかけています。

アプリはすでにリクエスト間隔を空け、サーバーのRetry-Afterによる待機時間も守っていますが、サーバーは429（リクエスト過多）を返し続けています。同じインターネット接続を使う複数のレジは同じアドレスを共有するため、送信元ごとのレート制限では、非常に頻繁にリクエストするクライアントとして扱われます。同期は自動的に続きますが、制限が引き上げられるまで遅延します。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. ストア自身のトラフィックについて REST API のレート制限を引き上げるか免除するよう、ホストに依頼してください — ショップに固定 IP がある場合はそれを伝えてください。
2. エラー応答（429）の繰り返しをブロックのカウントに加算するセキュリティサービス（例: Sucuri の IDS）では、そのカウンターからストアの API を除外する必要がある場合があります。
3. 複数のレジが同じ接続を共有している場合は、ホスティング事業者に伝えてください。ここでのIPアドレスはユーザーではなく、店舗全体を表しています。
