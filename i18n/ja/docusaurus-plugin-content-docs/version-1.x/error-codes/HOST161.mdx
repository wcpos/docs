## この意味 {#what-this-means}

ホストがこのストアのレジにレート制限をかけています。

アプリはすでにバックオフしてサーバーの Retry-After の遅延を守っているにもかかわらず、サーバーは 429（リクエストが多すぎます）を返し続けています。1 つのインターネット接続を共有する複数のレジは 1 つのアドレスを共有するため、送信元ごとのレート制限はそれらを 1 つの非常に多忙なクライアントとして扱います。同期は自動的に続きますが、上限が引き上げられるまで遅延します。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. ストア自身のトラフィックについて REST API のレート制限を引き上げるか免除するよう、ホストに依頼してください — ショップに固定 IP がある場合はそれを伝えてください。
2. エラー応答（429）の繰り返しをブロックのカウントに加算するセキュリティサービス（例: Sucuri の IDS）では、そのカウンターからストアの API を除外する必要がある場合があります。
3. 複数のレジが 1 つの接続を共有している場合は、その旨をホストに伝えてください: ここでの 1 つの IP は 1 人のユーザーではなく、ショップ全体です。
