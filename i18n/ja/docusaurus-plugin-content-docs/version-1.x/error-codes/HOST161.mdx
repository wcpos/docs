## この意味 {#what-this-means}

ホストがこのストアのレジにレート制限をかけています。

アプリがすでにリクエスト間隔を延ばし、サーバーがRetry-Afterで指定した待機時間を守っているにもかかわらず、サーバーは429（リクエスト過多）を返し続けています。複数のレジが1つのインターネット接続を使うと接続元のアドレスも同じになるため、接続元ごとのレート制限では、アクセス頻度の非常に高い1つのクライアントとして扱われます。同期は自動的に続きますが、制限が引き上げられるまで遅延します。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. ストア自身のトラフィックについて REST API のレート制限を引き上げるか免除するよう、ホストに依頼してください — ショップに固定 IP がある場合はそれを伝えてください。
2. エラー応答（429）の繰り返しをブロックのカウントに加算するセキュリティサービス（例: Sucuri の IDS）では、そのカウンターからストアの API を除外する必要がある場合があります。
3. 複数のレジで同じ接続を共有している場合は、ホストに伝えてください。この場合、1つのIPアドレスは1人ではなく店舗全体を表します。
