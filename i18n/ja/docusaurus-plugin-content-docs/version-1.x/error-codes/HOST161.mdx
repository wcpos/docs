## この意味 {#what-this-means}

ホストがこのストアのレジにレート制限をかけています。

アプリがすでに待機時間を延ばし、サーバーのRetry-After遅延を守っているにもかかわらず、サーバーは429（リクエスト過多）を返し続けています。1つのインターネット接続を使う複数のレジ端末は同じIPアドレスを共有するため、送信元ごとのレート制限では非常に頻繁にアクセスする1つのクライアントとして扱われます。同期は自動で続きますが、制限が引き上げられるまで遅れます。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. ストア自身のトラフィックについて REST API のレート制限を引き上げるか免除するよう、ホストに依頼してください — ショップに固定 IP がある場合はそれを伝えてください。
2. エラー応答（429）の繰り返しをブロックのカウントに加算するセキュリティサービス（例: Sucuri の IDS）では、そのカウンターからストアの API を除外する必要がある場合があります。
3. 複数のレジ端末で1つの接続を共有している場合、その点をホスティング事業者に伝えてください。このIPアドレスは1人のユーザーではなく、店舗全体を表しています。
