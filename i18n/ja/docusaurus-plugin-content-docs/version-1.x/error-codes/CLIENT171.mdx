## これが意味すること {#what-this-means}

このデバイスの時計と店舗の時計が、1分以上ずれています。

このデバイスの日付と時刻が自動更新されるように設定してください。すでに設定されている場合は、サイト管理者にサーバーの時計を確認してもらってください。

WCPOSは、このデバイスの時計と、店舗のサーバーが応答で報告する時刻を比較します。時刻が1分以上ずれていると、両方の時計が一致するまで、注文時刻、レシート、レポートにずれが生じることがあります。

## データへの影響 {#your-data}

販売は引き続き保存されます。時計がずれている間は、記録される時刻のみが正しくない場合があります。

## トラブルシューティング {#troubleshoot}

1. ログ項目を展開すると、2つの時計のずれの大きさと、どちらが進んでいるかを確認できます。
2. このデバイスの日付と時刻の設定を開き、自動（ネットワーク）時刻とタイムゾーンを有効にしてください。
3. **サイト管理者：**デバイスがすでに自動更新に設定され、時刻も正しい場合は、サーバーの時計が間違っています。ホスティング事業者にサーバーの日付、時刻、タイムゾーンを確認してもらってください。
4. 修正後、WCPOSを再度開いてください。店舗を開くたびに時計が再比較され、時刻が一致すると警告は表示されなくなります。
