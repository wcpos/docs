## これが意味すること {#what-this-means}

WCPOSのメモリが不足し、処理を完了できませんでした。

WCPOSを再起動して一度だけ再試行してください。再びメモリ不足になる場合は、診断情報をエクスポートしてください。

## データへの影響 {#your-data}

結果を確認できませんでした。メモリ不足が起きたときに何かを保存していた場合は、再試行する前に完了したか確認してください。

## トラブルシューティング {#troubleshoot}

1. WCPOSを再起動してください。メモリ不足が起きたときに何かを保存していた場合は、再試行する前に完了したか確認し、完了していない場合に限って1度再試行してください。
2. 他のアプリやブラウザーのタブを閉じてください。POSはデバイスのメモリを、同時に動作している他のすべてのものと共有しています。
3. 特定の操作で必ずメモリ不足になる場合は、その操作を控えたうえで、デバッグ情報を添えてサポートにお問い合わせください。
4. 同じデバイスで毎日発生する場合、そのデバイスではカタログの規模に対して能力が不足している可能性があります。サポートが確認できるよう報告してください。
