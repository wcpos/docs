## これが意味すること {#what-this-means}

この端末のメモリが不足し、直前の操作が完了していない可能性があります。

他のアプリやタブを閉じてWCPOSを再起動し、直前の販売または変更が保存されたか確認してください。保存されていなければ、もう一度操作してください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。メモリ不足の際に販売や変更を保存していた場合は、再度操作する前に保存されたことを確認してください。

## トラブルシューティング {#troubleshoot}

1. 他のアプリやブラウザーのタブを閉じてください。WCPOSは、端末上で実行中の他のすべてのものとメモリを共有しています。
2. WCPOSを再起動してください。
3. 再度操作する前に、直前の販売または変更が保存されたか確認してください。**店舗の健全性 → データベース**（販売が**送信待ちの変更**として表示されている場合は、保存済みで送信中です）、カート、注文（WCPOS Proの場合）、または**WooCommerce → 注文**を確認します。カード決済の場合は端末または決済事業者も確認してください。顧客への請求が済んでいる場合は、再度請求しないでください。本当に保存されていない場合に限り、もう一度操作してください。
4. 特定の操作で必ずメモリ不足になる場合は、操作内容を記録し、**ログ**タブで**デバッグ情報をコピー**してサポートにお問い合わせください。
5. 同じデバイスで毎日発生する場合、そのデバイスではカタログの規模に対して能力が不足している可能性があります。サポートが確認できるよう報告してください。
