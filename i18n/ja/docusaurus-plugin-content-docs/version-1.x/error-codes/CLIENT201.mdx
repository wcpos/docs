## これが意味すること {#what-this-means}

このデバイスのメモリが不足し、直前の操作が完了していない可能性があります。

ほかのアプリやタブを閉じてWCPOSを再起動し、直前の販売や変更が保存されたか確認してください。保存されていない場合は、もう一度操作してください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に状況を確認してください。メモリ不足が発生したときに販売や変更を保存中だった場合は、もう一度操作する前に保存されたか確認してください。

## トラブルシューティング {#troubleshoot}

1. ほかのアプリやブラウザータブを閉じてください。WCPOSは、デバイスで実行中のほかのすべてのアプリとメモリを共有しています。
2. WCPOSを再起動してください。
3. もう一度操作する前に、直前の販売や変更が保存されたか確認してください。**店舗の状態 → データベース**（**送信待ちの変更**に表示される販売は保存済みで、送信中です）、カート、注文（WCPOS Proの場合）または**WooCommerce → 注文**を確認します。カード決済の場合は端末または決済プロバイダーも確認してください。顧客への請求が済んでいる場合は、再度請求しないでください。本当に保存されていない場合に限り、もう一度だけ入力してください。
4. 特定の操作で繰り返しメモリ不足が発生する場合は、その操作を記録し、**ログ**タブで**デバッグ情報をコピー**をタップしてサポートにお問い合わせください。
5. 同じデバイスで毎日発生する場合、そのデバイスではカタログの規模に対して能力が不足している可能性があります。サポートが確認できるよう報告してください。
