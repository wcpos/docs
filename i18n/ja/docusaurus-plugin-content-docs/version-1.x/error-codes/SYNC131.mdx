## これが意味すること {#what-this-means}

店舗でエラーが発生し、このリクエストを完了できませんでした。

店舗には接続できましたが、サーバーがリクエストを処理できませんでした。POS ではなく、Web サイト側の問題です。もう一度操作してください。繰り返し発生する場合は、サイト管理者に **WooCommerce → ステータス → ログ** を確認するよう依頼してください。このデバイス上のデータは失われていません。

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ反映されていない変更が含まれている可能性があります。送信中の変更が店舗に届いていない可能性があります。繰り返し発生する場合は、**Logs** タブの **Copy debug info** を使用して、WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

**POS側（レジ係）：** ログの項目を展開し、status、endpoint、serverCodeを確認してください。これらから、失敗時にサーバーで何が起きていたか分かります。

**ウェブサイト側（サイト管理者／ホスティング業者）：**

1. サイトで WooCommerce → ステータス → ログ を開き、失敗した時刻前後の最新のfatal-errorsログを確認してください。500番台の応答は、ほぼ必ずそこにPHPエラーを残します。
2. サイトでプラグイン、テーマ、PHPを更新した後に発生し始めた場合は、まずその変更を疑い、元に戻すか無効にしてください。
3. WooCommerceのログに何も出ていない場合は、同じ時間帯のサーバーのPHPエラーログをホスティング事業者に問い合わせてください。

**次に、POS に戻って:** 操作をもう一度行ってください。
