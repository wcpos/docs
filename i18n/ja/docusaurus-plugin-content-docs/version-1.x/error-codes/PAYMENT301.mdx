## これが意味すること {#what-this-means}

選択された決済ゲートウェイは、このストアでは利用できません。

そのゲートウェイがサポートされていて、有効になっており、正しく設定されているかを確認するようサイト管理者に依頼してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、WordPressサイトの管理担当者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジ端末：**その間、現金など別の方法で販売を完了してください。

**店舗側** — サイト管理者向け：

1. WooCommerce → 設定 → 支払いでゲートウェイを確認してください。インストール済みで有効になっており、POS設定でもPOS利用が有効である必要があります。
2. 昨日までゲートウェイが動作していた場合は、ゲートウェイまたはWooCommerceが更新されたか確認してください。WooCommerce → ステータス → ログに、ゲートウェイの初期化エラーが記録されていることがあります。
