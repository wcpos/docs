## これが意味すること {#what-this-means}

印刷ジョブが完了したかどうかを、WCPOSは確認できませんでした。

レシートが二重に印刷されないよう、再試行する前にプリンターを確認してください。

## データへの影響 {#your-data}

販売データと注文データは安全で、変更されていません。確認できないのは印刷結果だけです。

## トラブルシューティング {#troubleshoot}

1. 再試行する前にプリンターを確認してください。確認結果が返ってこなかっただけで、実際には印刷されている場合があり、確認せずに再試行するとレシートが二重に印刷されます。
2. プリンターの用紙、カバー、エラーランプを確認してください。
3. 何も印刷されていない場合は、注文のレシート画面から一度だけ再試行してください。
4. 失敗が繰り返す場合は、プリンターの電源を入れ直し、レジとの接続を確認してください。
