## これが意味すること {#what-this-means}

セッションが終了したため、再度サインインする必要があります。

再度サインインしてください。データは失われません。サインインすると、未送信の変更が送信されます。

## データへの影響 {#your-data}

注文や商品データには影響しません。セッション切れの間に保存した販売データは失われず端末に保持され、サインイン後に店舗へ自動送信されます。

## トラブルシューティング {#troubleshoot}

1. 再度サインインしてください。WCPOSはWordPressのサインイン画面を自動的に開きます。閉じた場合は、WCPOSから再度サインインを求められます。同じレジ係としてサインインしてください。
2. 再入力や再保存は不要です。保留中の販売は、再度サインインすると自動的に送信されます。送信状況を確認するには、**Store health → Database**を開きます。**changes waiting to send**が0になります。
3. 販売が**「… changes never reached your server」**に表示されている場合は、その行の**Send again**をタップしてください。
4. 1日に数回など、頻繁に有効期限が切れる場合は、通常サイト側に原因があります。セキュリティプラグインがセッションの有効期間を短縮したり、トークンを消去したりしている可能性があります。サイト管理者に、店舗で使用しているセキュリティプラグインを確認し、**WP Admin > POS > 設定 > ツール > ログ**を確認するよう依頼してください。サインインが拒否された理由は、そこに記録されています。
