## これが意味すること {#what-this-means}

セッションが終了したため、再度サインインする必要があります。

もう一度サインインしてください。データは失われません。サインインすると未送信の変更が送信されます。

## データへの影響 {#your-data}

注文や商品データには影響しません。セッション切れの間に保存した販売データは失われず端末に保持され、サインイン後に店舗へ自動送信されます。

## トラブルシューティング {#troubleshoot}

1. もう一度サインインしてください。WCPOSはWordPressのサインイン画面を自動的に開きます。画面を閉じた場合は、WCPOSから再度サインインを求められます。同じレジ係のアカウントでサインインしてください。
2. 再入力や再保存は不要です。保留中の販売データは、再度サインインすると自動的に送信されます。送信状況を確認するには、**ストアヘルス → データベース**を開きます。**送信待ちの変更**が0になります。
3. 販売データが代わりに**「… 件の変更がサーバーに届いていません」**の下に表示されている場合は、その行の**再送信**をタップしてください。
4. 有効期限切れが頻繁に（1日に数回）発生する場合、通常はサイト側が原因です。セキュリティプラグインがセッションの有効期間を短縮したり、トークンを消去したりしている可能性があります。サイト管理者に、店舗で使用しているセキュリティプラグインを確認してもらい、**WP Admin > POS > 設定 > ツール > ログ**も確認するよう依頼してください。サインイン拒否とその理由が記録されています。
