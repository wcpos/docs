## これが意味すること {#what-this-means}

セッションが終了したため、再度サインインする必要があります。

再度サインインすると続行できます。すでに保存した内容はレジの端末に保持され、サインイン後に自動で送信されます。

## データへの影響 {#your-data}

注文や商品データには影響しません。セッション切れの間に保存した販売データは失われず端末に保持され、サインイン後に店舗へ自動送信されます。

## トラブルシューティング {#troubleshoot}

1. 求められたら再度サインインしてください。保留中の販売データは自動送信されるため、再入力したり、もう一度保存したりする必要はありません。送信状況は「ストアヘルス」を開き、「データベース」で確認できます。
2. サインインして数分たっても同じ注文が送信待ちのままなら、「ストアヘルス」から「データベース」を開き、その行の「再送信」を使ってください。
3. 頻繁な有効期限切れ（1日に数回）は、通常サイト側が原因です。セキュリティプラグインによってセッションの有効期間が短縮されたり、トークンが消去されたりしている可能性があります。サイト管理者に、店舗で使用しているセキュリティプラグインを確認し、WP AdminのPOSからログを確認してもらってください。サインインが拒否された理由はログに記録されています。
