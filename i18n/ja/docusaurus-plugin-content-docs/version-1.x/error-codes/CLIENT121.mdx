## これが意味すること {#what-this-means}

このブラウザーでは、一度に変更を送信できるタブは一つだけです。

すべてのタブをそのまま使用できます。各タブは同じローカルデータを共有し、一つのタブがすべてのタブの同期をバックグラウンドで処理します。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. すべてのタブを通常どおり使用できます。ローカルデータを共有し、一つのタブがほかのタブに代わってバックグラウンドで同期します。
2. このブラウザー（またはプライベートウィンドウ）には、POSが推奨するタブ間調整機能がないため、同期を行うタブを一つに限定して動作します。対応は不要です。
