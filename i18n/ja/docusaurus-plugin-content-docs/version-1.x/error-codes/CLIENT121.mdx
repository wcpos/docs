## これが意味すること {#what-this-means}

このブラウザーでは、一度に変更を送信できるタブは1つだけです。

すべてのタブを引き続き使用できます。どのタブも同じローカルデータを共有し、1つのタブが他のタブの同期をバックグラウンドで処理します。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. 通常どおりすべてのタブを使い続けられます。ローカルデータは共有され、1つのタブが他のタブに代わって同期をバックグラウンドで行います。
2. このブラウザー（またはプライベートウィンドウ）には、POSが推奨するタブ間調整機能がないため、同期を1つのタブに集約します。修正は不要です。
