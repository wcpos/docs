## これが意味すること {#what-this-means}

このブラウザーでは、変更を送信できるタブは一度に1つだけです。

すべてのタブを引き続き使用できます。タブ間でローカルデータは共有されます。1つのタブがバックグラウンドで全タブの同期を処理します。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. 通常どおりすべてのタブを使用できます。ローカルデータは共有され、1つのタブが他のタブに代わって同期を行います。
2. このブラウザー（またはプライベートウィンドウ）には、POSが推奨するタブ間調整機能がないため、同期を行うタブを1つに限定します。修正は不要です。
