## これが意味すること {#what-this-means}

このブラウザーでは、一度に変更を送信できるタブは1つだけです。

すべてのタブを引き続き使用できます。ローカルデータは共有され、1つのタブがすべてのタブの同期をバックグラウンドで処理します。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. すべてのタブを通常どおり使用できます。ローカルデータは共有され、1つのタブが他のタブに代わって同期を行います。
2. このブラウザー（またはプライベートウィンドウ）には、POSが推奨するタブ間連携機能がないため、同期を1つのタブに限定しています。修正は不要です。
