## このエラーの意味 {#what-this-means}

ローカルデータベース操作に通常より大幅に時間がかかっており、結果はまだ不明です。

このデバイスのローカルデータベースへの単一の読み取りまたは書き込みが通常より大幅に長い間応答を返していませんが、データベースはほかのすべての要求には応答し続けています。このレポーターは停止を記録するだけで、操作をキャンセルまたは再試行しないため、元の呼び出しは後で完了または失敗する可能性があります。このエントリは、画面やスピナーが停止したときに、どの操作が停止したのかを正確に示す記録を残すために存在します。停止した同期処理には別のタイムアウトおよび再試行の仕組みがあり、[SYNC321](/error-codes/SYNC321) では「停止したデータリクエストを断念しました」エントリとして記録されます。画面からの停止した呼び出しは、完了するかアプリが再読み込みされるまで保留状態のままです。

## データへの影響 {#your-data}

停止した操作は通常、データを変更しない参照です。その時点で変更を保存していた場合は、レコードを開いて保存されたことを確認してください。目に見える症状がまったくない場合もあります。エントリのコンテキストには、操作と対象のデータコレクションが示されます。

## トラブルシューティング {#troubleshoot}

1. すべて正常に動作している場合は、対応は不要です。呼び出しは単に遅れて完了した可能性が高いです。
2. 画面またはスピナーが停止したままの場合は、アプリを再読み込みしてください。Web ではブラウザータブを再読み込みし、デスクトップ版およびモバイル版ではアプリを閉じて再度開きます。これにより停止した操作は破棄され、画面が再度読み込まれてデータベースにあらためて要求します。処理中だった保存は再送されないため、レコードを開いて保存されたことを確認してください。
3. 同じデバイスでこのコードが繰り返し表示される場合は、ログ画面からデバッグ情報をエクスポートしてサポートに連絡してください。エントリのコンテキストには、操作とコレクション、正確な待機時間、その間のデータベースの負荷状況が示されます。
