## このエラーの意味 {#what-this-means}

このデバイスでの保存または読み込みが非常に遅く、結果はまだ確認できていません。

WCPOSが動作している場合、対応は不要です。画面が停止したままの場合はWCPOSを再読み込みし、直近の変更が保存されているか確認してください。

このデバイスのローカルデータベースへの読み取りまたは書き込みのうち、一つだけが通常より大幅に長い間応答を返していません。データベースは他の処理には引き続き応答しています。この報告機能は停止を記録するだけで、操作のキャンセルや再試行は行いません。そのため、元の呼び出しが後から完了したり失敗したりする可能性があります。このログは、画面やスピナーが止まった場合に、どの操作が停止したのかを正確に記録するためのものです。停止した同期処理には別のタイムアウトと再試行の仕組みがあり、[SYNC321](/1.x/error-codes/SYNC321) の「停滞したデータリクエストを中止」という項目として記録されます。画面からの呼び出しが停止した場合は、完了するかアプリを再読み込みするまで保留状態が続きます。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に確認してください。停止した操作は通常、何も変更しない検索です。その時点で変更を保存中だった場合は、レコードを開いて保存されたことを確認してください。目に見える症状がなかった場合もあります。ログ項目のコンテキストには、操作と対象のデータコレクションが記載されています。

## トラブルシューティング {#troubleshoot}

1. WCPOSが動作している場合、対応は不要です。処理はおそらく完了していますが、時間がかかっただけです。ログ項目の操作が保存だった場合は、レコードを開いて保存されたことを確認してください。
2. 画面またはスピナーが停止したままの場合は、アプリを再読み込みしてください。Web ではブラウザータブを再読み込みし、デスクトップ版およびモバイル版ではアプリを閉じて再度開きます。これにより停止した操作は破棄され、画面が再度読み込まれてデータベースにあらためて要求します。処理中だった保存は再送されないため、レコードを開いて保存されたことを確認してください。
3. 同じデバイスでこのコードが繰り返し発生する場合は、ログ項目のコンテキストに操作、コレクション、正確な待ち時間、その間のデータベースの負荷が記載されています。**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。
