## これが意味すること {#what-this-means}

WCPOS はこのデバイスのストレージに変更を書き込めませんでした。

デバイスのストレージを空けてから、変更が表示されるか確認してください。表示されない場合は、もう一度入力してください。繰り返し発生する場合はサポートにお問い合わせください。確認が済むまでは、変更内容をメモしてください。書き込み前に WCPOS が終了すると、変更は失われます。このデバイスのデータは消去しないでください。

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ届いていない販売内容が含まれている可能性があります。失敗した変更はどこにも保存されていない可能性があるため、表示されたことを確認するまで内容を記録しておいてください。繰り返し発生する場合は、**Logs** タブの **Copy debug info** を使用して、WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 変更内容（レコードと入力した値）を記録してください。ログ項目にレコード名が表示されている場合、その変更が保存されていない可能性があります。サイトや認証情報の書き込みでは、失敗した操作とエラーのみが表示される場合もあります。その詳細も記録してください。
2. サイトデータを消去したり、アプリをリセットまたはアンインストールしたりしないでください。販売内容など、店舗にまだ届いていないほかの変更がこのデバイスにしか存在しない場合があり、ローカルストレージを消去すると完全に失われます。
3. ほかのファイルやアプリを削除してデバイスのストレージを空けてください。ディスクの空き容量不足やブラウザーのストレージ割り当て上限が、ローカルへの書き込みに失敗する最も一般的な原因です。容量を空けるためにブラウザーの「閲覧データを消去」を使わないでください。WCPOS の未送信の販売内容も削除されます。
4. レコードを開き、変更が表示されるか確認してください。表示されない場合は、もう一度入力して保存してください。それでも保存できない場合は、WCPOS を一度再起動してから再試行してください。
5. 保存に繰り返し失敗する場合は、修復を試みる前に **Logs** タブの **Copy debug info** を使用して、サポートにお問い合わせください。
