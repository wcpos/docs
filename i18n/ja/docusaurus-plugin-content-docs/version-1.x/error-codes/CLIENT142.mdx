## このメッセージの意味 {#what-this-means}

検索インデックスが時間内に応答しなかったため、WCPOS は代わりにカタログを直接検索しました。

ローカル検索インデックスはまだ構築中であるか、応答できない状態でした。Web版では通常、POS タブがバックグラウンドにあるか、別のタブがデータベースのリーダーになっていることが原因です。デスクトップ版およびモバイル版では通常、大規模な同期の直後、または保存済みインデックスの再読み込み中にアプリを再起動した直後に発生します。検索は引き続きこのデバイス上のデータを直接スキャンして応答し、インデックスが応答すると自動的にインデックス検索へ戻ります。

## データについて {#your-data}

店舗データは変更されておらず、検索にも引き続き応答しています。インデックスではなく、このデバイス上のデータを直接スキャンして応答しました。インデックス検索へ戻るまで、検索結果の表示がやや遅くなる場合があります。

## トラブルシューティング {#troubleshoot}

1. 通常、対応は不要です。検索結果は引き続き機能し、インデックスが応答すると自動的にインデックス検索へ戻ります。
2. Web版で WCPOS を複数のブラウザータブで開いている場合は、余分なタブを閉じてください。ローカルデータベースのリーダーになれるのは 1 つのタブだけです。POS はバックグラウンドタブではなく、専用のウィンドウで開いたままにしてください。
3. 検索が遅いままの場合や、このコードが繰り返し表示される場合は、アプリを一度再読み込みしてください。Web版ではブラウザータブを再読み込みし、デスクトップ版およびモバイル版ではアプリを閉じてから再度開いてください。
4. それでもコードが再度表示される場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。
