## これが意味すること {#what-this-means}

一部のレコードは同期されましたが、同期されなかったレコードがあります。

このコードには2つの形式があり、ログ行のタイトルでどちらかを確認できます：

- **「同期が一部完了」**（レコードタイトル）：一部のレコードは同期されましたが、名前が表示されたレコードは同期されませんでした。再試行する前に、各レコードとその理由を確認し、該当するものだけを再試行してください。
- **「停滞したデータリクエストを中止」**：同期エンジンのデータリクエスト処理で1つのリクエストが進行しなくなったため、後続のキュー全体を止めないよう、十分に待機した後にアプリがそのリクエストを中止しました。手動で再試行する必要はありません。同期エンジンが自動的にリクエストを再送します。多くの場合、別途[SYNC181](/error-codes/SYNC181)として記録されるローカルデータベース呼び出しの停滞が先に発生しています。

## データへの影響 {#your-data}

同期されなかったレコードの場合：変更はこのデバイスに保存されていますが、店舗にはまだ届いていません。問題が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。中止されたデータリクエストの場合：変更はなく、中止されたリクエストは自動的に再送されます。

## トラブルシューティング {#troubleshoot}

1. 一部同期の場合は、ログ項目を展開して、同期されなかったレコードとそれぞれの理由を確認してください。
2. 記載された各レコードを、その理由に応じて処理してください。フィールドが無効なら編集が必要で、競合ならストアとの比較が必要です。
3. 失敗したレコードだけを再試行してください。残りはすでに同期済みで、対応は不要です。
4. 「停滞したデータリクエストを中止」という項目では、画面が停止したままでない限り対応は不要です。画面が停止した場合はアプリを再読み込みしてください。繰り返し発生する場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。
