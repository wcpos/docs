## これが意味すること {#what-this-means}

この変更はまだ店舗に送信中です。

何もする必要はありません。もう一度入力しないでください。自動的に送信され、店舗が確認すると表示されます。

販売または変更はこのデバイスに保存されて送信されましたが、通常の待ち時間内に店舗から確認応答がありませんでした。通常は、店舗の応答が遅いか、接続が不安定なためです。店舗から確認応答があるまで、WCPOSは送信を続けます。店舗はすでに受信した変更を認識するため、同じボタンをもう一度押しても問題ありません。ただし、販売やレコードを手動で再入力すると、別のものが作成され、重複になります。

## データへの影響 {#your-data}

データは失われません。変更はこのデバイスで送信待ちとなり、自動的に送信されます。送信待ちの間は、このデバイスのデータを消去しないでください。

## トラブルシューティング {#troubleshoot}

1. 販売や変更を手動で再入力しないでください。重複が作成されます。
2. 店舗に届くまでお待ちください。販売はこのデバイスに保存されているため、WCPOS（カート内、またはWCPOS Proでは**注文**）にすでに表示されています。店舗に届いたことを確認するには、WP Adminの**WooCommerce → 注文**を確認してください。
3. 送信状況を確認するには、**店舗の状態 → ログ**を開いてください。変更が送信されるにつれて、ヘッダーの**送信待ちの変更**の数が減り、すべて送信されると0になります。
4. 長時間送信待ちのままの場合は、このデバイスの接続と、店舗のWebサイトが読み込めるかを確認してください。[SYNC121](/error-codes/SYNC121)を参照してください。
5. 接続に問題がないのに表示されない場合は、**ログ**タブの**デバッグ情報をコピー**をタップしてサポートへお問い合わせください。
