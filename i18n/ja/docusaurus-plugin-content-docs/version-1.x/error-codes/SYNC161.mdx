## これが意味すること {#what-this-means}

このデバイスのストレージが応答しなくなったため、保存を一時停止しました。

WCPOSを再起動し（Webの場合はタブを再読み込みし）、直近の販売や変更が保存されているか確認してください。ストレージが応答しなくなる直前の数秒間に行った変更は、書き込まれていない可能性があります。このデバイスのデータは消去しないでください。繰り返し発生する場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだ届いていない販売データが含まれている可能性があります。繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. WCPOSを再起動してください。アプリを終了して再度開きます。Webの場合は、タブを閉じずに再読み込みしてください。ほとんどの場合、これでローカルデータベースに再接続できます。
2. 再起動後、直近の販売や変更が保存されているか確認してください。障害直前の数秒間に行った変更は、書き込まれていない可能性があります。見つからない場合は、もう一度入力してください。
3. Webでは、プライベート／シークレットウィンドウでレジを使用しないでください。また、ストレージを積極的に消去する拡張機能も避けてください。どちらもセッション中にローカルストレージを消去するおそれがあります。プライベートウィンドウを閉じると、未送信の販売データを含め、保存されているすべてのデータが削除されます。現在そのウィンドウを使っている場合は、**店舗の状態 → データベース**で**送信待ちの変更**が0になるまで閉じないでください。
4. 同じデバイスで繰り返し発生する場合は、発生時にデバイスで何が起きていたか（スリープ、タブ切り替え、メモリ不足など）を記録し、**ログ**タブで**デバッグ情報をコピー**してサポートにお問い合わせください。
