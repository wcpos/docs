## この意味 {#what-this-means}

ストアの REST API が、このアプリで利用できるどのアドレス形式でも応答しませんでした。

アプリは、通常のアドレス（/wp-json/...）と WordPress の組み込みフォールバックアドレス（/?rest_route=...）の両方でストアの REST API を試しましたが、どちらも応答しませんでした。ストアのウェブサイト自体は稼働している可能性があります — これは特に REST API に到達できない状態で、通常はセキュリティプラグインがそれを隠しているか、ファイアウォールのルールがブロックしています。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

**ストア側** — サイト管理者向け: セキュリティプラグインが `/wp-json/` を隠したり名前を変更したりしている場合（例: WP Hide）、WordPress の組み込みの `/?rest_route=` 形式も許可してください — アプリは自動的にそれにフォールバックします。

**ホスト／サーバー側:**

1. ファイアウォール（WAF）のルールで `wp-json` や `rest_route` に一致するものを確認し、ストア自身の REST API を通過させてください。
2. サーバーがメンテナンスページやボットチャレンジの背後にある場合、REST リクエストに HTML ページが返されることがあります — REST API に対してはチャレンジを無効にしてください。

**テスト方法（誰でも可）:** `https://your-store.com/?rest_route=/` は、403 ページやサイトのホームページではなく JSON を返すはずです。
