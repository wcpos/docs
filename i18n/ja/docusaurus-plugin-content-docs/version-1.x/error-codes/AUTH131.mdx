## これが意味すること {#what-this-means}

保存された店舗セッションが不完全だったため、WCPOSは店舗リストに戻りました。

WCPOSは、レジを前回の続きから再開できるよう、開いていたサイト、レジ係、店舗を記憶しています。今回はその記録の一部（通常はサイトまたはレジ係の情報）が欠けていたため、セッションが壊れた状態で店舗を開く代わりに、レジは店舗リストに戻りました。もう一度店舗を選んでサインインしてください。このチェックが導入される前は、この状態のレジには空白の画面上に赤い「useStoreSession must be called within an active store session」バナーが表示され、先に進めませんでした。

通常は、デバイスのローカルストレージにアプリが書き込んだデータが保存されなかったことを意味します。一度だけなら記録しておく価値がありますが、同じデバイスで繰り返し発生する場合は、ストレージの問題として調査してください。

## データへの影響 {#your-data}

開いていたセッションへの参照だけがクリアされました。同期待ちの販売データを含む店舗のローカルデータは、デバイスに残っています。

サイトまたはレジ係がリストに残っている場合は、同じ店舗をもう一度選ぶと、同じローカルデータを引き続き使用できます。サイトを再登録する必要があった場合、レジは店舗の新しいローカルコピーを開きます。前のセッションで同期待ちだった販売データはデバイスに残りますが、自動では引き継がれません。未同期の販売データがあった場合は、ローカルデータを消去する前にサポートへお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. サイトと店舗をもう一度選んでサインインしてください。このデバイス上の店舗データは変更されておらず、記憶されていたセッションだけがクリアされています。
2. サイトがリストに表示されなくなった場合は、アドレスを再入力してサインインしてください。同期待ちの販売データがあった場合は、先にサポートへお問い合わせください。上記の「データへの影響」を参照してください。
3. 同じデバイスで再発する場合、ローカルストレージがアプリの書き込みを保持できていません。ディスクの空き容量を確認し、同じ頃に発生したストレージエラーがないかログ画面を確認してください。
4. 繰り返し発生する場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。ログには、セッションのどの情報が欠けていたかが記録されています。
