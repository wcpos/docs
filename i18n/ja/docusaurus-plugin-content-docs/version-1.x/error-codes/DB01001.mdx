# DB01001: 接続失敗 {#db01001-connection-failed}

## これの意味 {#what-this-means}

POSはローカルデータベースに接続できませんでした。WCPOSは、製品、顧客、その他のデータを迅速にアクセスし、オフライン機能を提供するためにローカルデータベースを使用します。

## 一般的な原因 {#common-causes}

- **ストレージが満杯** — デバイスにストレージスペースが残っていない
- **データベースが破損** — ローカルデータベースファイルが損傷している
- **権限の問題** — アプリにストレージ権限がない
- **ブラウザストレージが無効** — IndexedDBが無効になっている（ウェブ版）

## 修正方法 {#how-to-fix}

### 1. ストレージスペースを確認 {#1-check-storage-space}

デバイスに利用可能なストレージがあることを確認してください：
- ストレージが満杯の場合はスペースを解放
- 使用していないアプリやファイルを削除
- 利用可能なディスクスペースを確認

### 2. アプリデータをクリア {#2-clear-app-data}

:::warning 未保存の作業がないか確認してください
ローカルデータを消去したり、アプリを再インストールしたりすると、この端末上にあり店舗にまだ届いていないデータがすべて削除されます。オフライン中の売上、開いたままのカート、保存されていない編集も含まれます。消去する前に、**店舗の健全性 → データベース**を開き、保留中またはサーバーに未到達の項目がないことを確認してください。次に**店舗の健全性 → ログ**で、**停止中のレコードが0件**、**送信待ちの変更が0件**であることを確認し、開いているカートをすべて完了するか内容を記録してください。WCPOSに店舗の健全性ページがない場合は、先にWCPOSを更新してから確認してください。項目や待機中のデータがある場合、または確認できない場合は消去せず、店舗の責任者に相談するかサポートにお問い合わせください。
:::

上記の確認を行ったうえで、手順1、3、4で解決しない場合に限り、ローカルデータベースをリセットしてください：
- **デスクトップアプリ:** 設定内の「データをクリア」を探す
- **ウェブブラウザ:** POSドメインのサイトデータをクリア
- **注：**店舗にすでにあるデータは再ダウンロードされますが、店舗に一度も届いていないデータは失われます

### 3. ブラウザ設定を確認（ウェブ） {#3-check-browser-settings-web}

ウェブ版を使用している場合：
1. IndexedDBが有効になっていることを確認
2. プライベート/シークレットモードを使用しない（ストレージが制限される）
3. サイトにデータを保存することを許可

### 4. 権限を確認 {#4-check-permissions}

デスクトップ上で：
- アプリがデータディレクトリに書き込む権限があることを確認
- ウイルス対策ソフトがデータベースアクセスをブロックしていないか確認

### 5. アプリを再インストール {#5-reinstall-the-app}

:::warning 未保存の作業がないか確認してください
ローカルデータを消去したり、アプリを再インストールしたりすると、この端末上にあり店舗にまだ届いていないデータがすべて削除されます。オフライン中の売上、開いたままのカート、保存されていない編集も含まれます。消去する前に、**店舗の健全性 → データベース**を開き、保留中またはサーバーに未到達の項目がないことを確認してください。次に**店舗の健全性 → ログ**で、**停止中のレコードが0件**、**送信待ちの変更が0件**であることを確認し、開いているカートをすべて完了するか内容を記録してください。WCPOSに店舗の健全性ページがない場合は、先にWCPOSを更新してから確認してください。項目や待機中のデータがある場合、または確認できない場合は消去せず、店舗の責任者に相談するかサポートにお問い合わせください。
:::

他の方法で解決しない場合に限り、上記の確認を行ったうえで実施してください：
1. POSアプリをアンインストール
2. デバイスを再起動
3. アプリを再インストール
4. ログインし、データを同期

## データ復旧 {#data-recovery}

未保存のデータがある場合：
- アプリに同期できなかった保留中の変更があるかもしれません
- データの復旧が必要な場合はサポートに連絡してください
- 消去後、店舗にすでにあるデータは再ダウンロードされます。一方、店舗に一度も届いていない売上はこの端末にしか存在しません。消去または再インストールを行うと削除されるため、どちらを行う場合も事前にサポートにお問い合わせください。
