# DB01001: 接続失敗 {#db01001-connection-failed}

## これの意味 {#what-this-means}

POSはローカルデータベースに接続できませんでした。WCPOSは、製品、顧客、その他のデータを迅速にアクセスし、オフライン機能を提供するためにローカルデータベースを使用します。

## 一般的な原因 {#common-causes}

- **ストレージが満杯** — デバイスにストレージスペースが残っていない
- **データベースが破損** — ローカルデータベースファイルが損傷している
- **権限の問題** — アプリにストレージ権限がない
- **ブラウザストレージが無効** — IndexedDBが無効になっている（ウェブ版）

## 修正方法 {#how-to-fix}

### 1. ストレージスペースを確認 {#1-check-storage-space}

デバイスに利用可能なストレージがあることを確認してください：
- ストレージが満杯の場合はスペースを解放
- 使用していないアプリやファイルを削除
- 利用可能なディスクスペースを確認

### 2. アプリデータをクリア {#2-clear-app-data}

:::warning 未保存の作業がないか先に確認してください
ローカルデータを消去したりアプリを再インストールしたりすると、このデバイス上にあり、まだ店舗に届いていないデータがすべて削除されます。オフライン中の販売、開いたままのカート、保存されなかった編集も含まれます。消去する前に、**店舗の状態 → データベース**を開き、保留中またはサーバーに一度も届いていない項目がないことを確認してください。次に**店舗の状態 → ログ**で、**0件の滞留レコード**および**0件の送信待ちの変更**であることを確認し、開いているカートをすべて完了するか内容を記録してください。WCPOSに店舗の状態ページがない場合は、まずWCPOSを更新してから確認してください。項目が表示されている、送信待ちである、または確認できない場合は消去せず、店舗のオーナーに相談するかサポートにお問い合わせください。
:::

手順1、3、4で解決せず、上記の確認を済ませた場合に限り、ローカルデータベースをリセットしてください：
- **デスクトップアプリ:** 設定内の「データをクリア」を探す
- **ウェブブラウザ:** POSドメインのサイトデータをクリア
- **注：** 店舗にすでにあるデータは再度ダウンロードされます。店舗に一度も届いていないデータは失われます。

### 3. ブラウザ設定を確認（ウェブ） {#3-check-browser-settings-web}

ウェブ版を使用している場合：
1. IndexedDBが有効になっていることを確認
2. プライベート/シークレットモードを使用しない（ストレージが制限される）
3. サイトにデータを保存することを許可

### 4. 権限を確認 {#4-check-permissions}

デスクトップ上で：
- アプリがデータディレクトリに書き込む権限があることを確認
- ウイルス対策ソフトがデータベースアクセスをブロックしていないか確認

### 5. アプリを再インストール {#5-reinstall-the-app}

:::warning 未保存の作業がないか先に確認してください
ローカルデータを消去したりアプリを再インストールしたりすると、このデバイス上にあり、まだ店舗に届いていないデータがすべて削除されます。オフライン中の販売、開いたままのカート、保存されなかった編集も含まれます。消去する前に、**店舗の状態 → データベース**を開き、保留中またはサーバーに一度も届いていない項目がないことを確認してください。次に**店舗の状態 → ログ**で、**0件の滞留レコード**および**0件の送信待ちの変更**であることを確認し、開いているカートをすべて完了するか内容を記録してください。WCPOSに店舗の状態ページがない場合は、まずWCPOSを更新してから確認してください。項目が表示されている、送信待ちである、または確認できない場合は消去せず、店舗のオーナーに相談するかサポートにお問い合わせください。
:::

ほかの解決策で解決せず、上記の確認を済ませた場合に限り、次の操作を行ってください：
1. POSアプリをアンインストール
2. デバイスを再起動
3. アプリを再インストール
4. ログインし、データを同期

## データ復旧 {#data-recovery}

未保存のデータがある場合：
- アプリに同期できなかった保留中の変更があるかもしれません
- データの復旧が必要な場合はサポートに連絡してください
- 店舗にすでに保存されているデータは消去後に再ダウンロードされますが、店舗に一度も届いていない販売データはこのデバイスにしかありません。消去または再インストールすると削除されるため、いずれかを行う前にサポートにお問い合わせください。
