## これが意味すること {#what-this-means}

この注文についてストアが算出した合計金額が、レジに表示された金額と異なります。

これ以上の支払いを受け付ける前に、ストアの管理画面で注文を確認してください。ストア側の合計金額が正となります。差額に心当たりがない場合は、診断情報をエクスポートしてサポートにお問い合わせください。

## データへの影響 {#your-data}

金銭が動いている可能性があります。対応する前に支払い状況を確認してください。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジ端末** — 顧客が帰る前に対応してください：

1. 停止してください。それ以上の支払いを受け取らないでください。店舗の合計金額を正しい値として扱います。
2. 顧客が支払ったか、いくら支払ったかを確認します。カード端末の場合は画面またはレシート、現金の場合は預かった金額、他の決済ゲートウェイの場合はその記録を確認してください。
3. 支払い済みで店舗の合計と異なる場合は、顧客が帰る前に通常の手順で差額を精算（返金または追加請求）してください。

**店舗側** — サイト管理者向け：

1. WP Adminで注文を開き、その合計金額とレジに表示された金額を比較してください。どの金額が食い違ったかはログエントリーに記録されています。
2. よくある原因は、レジ端末の想定と異なる税設定、またはサーバー上で再計算する割引・価格設定プラグインです。まず店舗の税設定を確認してください。
3. 相違の理由が説明できない場合は、デバッグ情報をエクスポートし、注文番号を添えてサポートにお問い合わせください。
