## これが意味すること {#what-this-means}

この注文の店舗側の合計金額がレジに表示された金額と異なります。店舗側の金額で注文が保存されています。

顧客が帰る前に注文を開き、合計金額を比較してください。すでに代金を受け取っている場合は、差額を請求または返金してください。差額の理由がわからない場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

注文は店舗側の合計金額で保存されています。支払いはまだ行われていない場合も、すでに行われている場合もあります。この確認は注文の保存時に実行されるため、支払い前の場合があります。この状態が続く場合は、**ログ**タブで**デバッグ情報をコピー**し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

**レジ端末** — 顧客が帰る前に対応してください：

1. 注文を開き、合計金額とレジに表示された金額を比較してください。ログには、異なる金額が記録されています。
2. すでに支払いを受け取ったか、金額はいくらかを確認してください。カード端末の場合は画面またはレシートで、現金の場合は預かった金額で、その他の決済ゲートウェイの場合はその記録で確認します。
3. すでに代金を受け取っている場合は、通常の手順で差額を請求または返金してください。まだ支払いを受け取っていない場合は、現在表示されている注文の合計金額を受け取ってください。

**店舗側** — サイト管理者向け：

1. WP Adminで注文を開き、その合計金額とレジに表示された金額を比較してください。どの金額が食い違ったかはログエントリーに記録されています。
2. よくある原因は、レジ端末の想定と異なる税設定、またはサーバー上で再計算する割引・価格設定プラグインです。まず店舗の税設定を確認してください。
3. 差額の理由がわからない場合は、**ログ**タブで**デバッグ情報をコピー**し、注文番号を添えてサポートにお問い合わせください。
