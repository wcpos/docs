## これが意味すること {#what-this-means}

WCPOSでこのデバイスのストレージを設定または削除できませんでした。

デバイスのストレージを空けてから、WCPOSを再起動してください。Webでは、ブラウザーがサイトのストレージを制限している可能性もあります。プライベートウィンドウでは制限されます。失敗が続く場合はサポートにお問い合わせください。

## データへの影響 {#your-data}

これはストレージの問題であり、編集が拒否されたわけではありません。このデバイスのデータを消去中に発生した場合、未送信の変更を含むデータの一部がすでに失われている可能性があります。最近の販売や変更が店舗に反映されているか確認してください。繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. デバイスの空き容量を確認し、不要なファイルやアプリを削除して空きを増やしてください。ディスクまたはブラウザーのストレージ容量がいっぱいだと、ストレージを設定できません。空きを作るためにブラウザーの「閲覧データを消去」を使わないでください。WCPOSの未送信販売データも削除されます。
2. WCPOSを再起動して、同じ操作をもう一度行ってください。
3. ウェブ版では、ブラウザーがそのサイトに対して永続ストレージを許可しているか確認してください。プライベートウィンドウや「すべてのデータをブロック」の設定では許可されません。
4. 失敗が続く場合は、**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。
