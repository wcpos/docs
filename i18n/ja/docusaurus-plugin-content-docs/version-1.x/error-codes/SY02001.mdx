# SY02001: 無効な構成 {#sy02001-invalid-configuration}

## これは何を意味するか {#what-this-means}

システムの構成が無効または破損しています。POSアプリケーションは、意味がないか不完全な構成設定を見つけました。

## 一般的な原因 {#common-causes}

- **設定の破損** — 構成ファイルが破損した
- **設定の未完了** — 設定プロセスが完了していなかった
- **手動編集エラー** — 構成ファイルが不正に修正された
- **バージョンアップグレードの問題** — 古い構成が新しいバージョンと互換性がない

## 修正方法 {#how-to-fix}

### 1. デフォルト設定にリセット {#1-reset-to-default-settings}

アプリで利用可能な場合：
- 「設定をリセット」または「デフォルトに復元」を探します
- この操作でカスタム設定は消去されますが、破損は修正されます。リセット時に店舗またはそのデータを削除するか確認された場合は中止し、先に手順3の警告に記載された確認を行ってください。

### 2. セットアップを完了する {#2-complete-the-setup}

設定が完了していない場合：
1. 設定プロセスを再開始
2. 必要なすべてのステップを完了
3. 完了前に構成を確認

### 3. アプリケーションデータをクリア {#3-clear-application-data}

:::warning 先に未保存の作業がないか確認してください
ローカルデータを消去したりアプリを再インストールしたりすると、この端末から店舗にまだ届いていないデータがすべて削除されます。オフライン中の販売、開いたままのカート、保存されなかった編集も含まれます。消去する前に、**ストアヘルス → データベース**を開き、保留中またはサーバーに一度も届いていない項目がないことを確認してください。続けて**ストアヘルス → ログ**で、**0 stuck records**と**0 changes waiting to send**を確認し、開いているカートをすべて完了するか内容を控えてください。WCPOSにストアヘルスページがない場合は、先にWCPOSを更新してから確認してください。項目が表示されている、送信待ちのものがある、または確認できない場合は消去せず、店舗のオーナーに相談するかサポートにお問い合わせください。
:::

このページのほかの手順で解決せず、上記の確認を済ませた場合に限り、破損した設定を削除してください：
- **デスクトップ:** アプリデータフォルダーを削除し、アプリを再起動
- **ブラウザ:** サイトデータをクリアし、リロード

### 4. アプリケーションを再インストール {#4-reinstall-the-application}

:::warning 先に未保存の作業がないか確認してください
ローカルデータを消去したりアプリを再インストールしたりすると、この端末から店舗にまだ届いていないデータがすべて削除されます。オフライン中の販売、開いたままのカート、保存されなかった編集も含まれます。消去する前に、**ストアヘルス → データベース**を開き、保留中またはサーバーに一度も届いていない項目がないことを確認してください。続けて**ストアヘルス → ログ**で、**0 stuck records**と**0 changes waiting to send**を確認し、開いているカートをすべて完了するか内容を控えてください。WCPOSにストアヘルスページがない場合は、先にWCPOSを更新してから確認してください。項目が表示されている、送信待ちのものがある、または確認できない場合は消去せず、店舗のオーナーに相談するかサポートにお問い合わせください。
:::

問題が続く場合に限り、上記の確認を済ませてから行ってください：
1. 完全にアンインストール
2. 残ったデータフォルダーを削除
3. 新しく再インストール
4. 最初からセットアップを完了

### 5. アップデートを確認 {#5-check-for-updates}

構成形式が変更される可能性があります：
- POSアプリケーションを更新
- WCPOSプラグインを更新
- 更新後に再構成

## リセットされる内容 {#what-gets-reset}

構成をリセットすると：
- 再度ログインする必要があります
- カスタム設定は失われます
- データの再同期が必要
- WooCommerceのデータはサーバー上に安全に保存されていますが、この端末から店舗に一度も届かなかったデータ（開いたままのカートなど）は失われます。
