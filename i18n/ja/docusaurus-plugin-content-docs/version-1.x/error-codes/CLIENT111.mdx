## これが意味すること {#what-this-means}

同期の開始に想定より時間がかかっています。

通常は1分以内に自動で解消します。アプリがこの状態から戻らない場合は、他の操作をする前に1度再読み込みしてください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. 1分ほど待ってください。更新後の初回同期や、大規模な店舗での同期には通常より時間がかかります。
2. この状態のままアプリが止まっている場合は、一度だけ再読み込みしてください。
3. 起動が毎日遅い場合は、店舗への接続を確認してください。問題がなければ、店舗の担当者にサイトの応答性を確認してもらってください。
