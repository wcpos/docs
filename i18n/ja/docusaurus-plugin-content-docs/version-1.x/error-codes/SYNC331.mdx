## これが意味すること {#what-this-means}

このデバイス上のレコードのコピーが店舗のものと一致しません。入力内容には影響しません。

**店舗の状態 → データベース**で、該当リストの**消去して再ダウンロード**を選び、このデバイスのコピーを店舗の内容に置き換えてください。それまでは、レコードに古い価格や在庫が表示される可能性があります。最初に送信待ちの項目がないことを確認してください。トラブルシューティングを参照してください。

## データへの影響 {#your-data}

販売データや未送信の変更には影響しません。置き換えるまで、このデバイス上のレコードに古い価格や在庫が表示される場合があります。繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**し、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 販売を続けてください。**店舗の状態 → データベース** を開くと、該当レコードが上部に表示されます。コピーが異なるレコードには **「… 店舗からダウンロードできません」**、店舗で削除されたレコードには **「… このデバイスから削除する必要があります」** と表示されます。
2. 商品を販売する前に、価格と在庫を棚または店舗の管理者に確認してください（管理者はWP Adminで照合できます）。
3. 何かを消去する前に、**店舗の状態 → データベース**で**送信待ちの変更**が 0 であり、**「… サーバーに届かなかった変更」** や **「… 保留中の変更」** のパネルが表示されていないことを確認してください。これらの変更はこのデバイスにしかなく、該当するリストを消去すると失われる可能性があります。件数が 0 になるのを待ち、一覧にある変更を先に解決してください（[SYNC201](/1.x/error-codes/SYNC201)、[SYNC221](/1.x/error-codes/SYNC221)）。**注文**を消去する前には、このデバイスで開いているすべてのカートも**サーバーに保存**するか、会計を完了してください。店舗に一度も保存されていないカートはこのデバイスにしか存在せず、これらの確認の件数にも含まれないため、**注文**を消去すると削除されます。保存できないカートがある場合は、**注文**の行をスキップしてサポートに問い合わせてください。次に、レコードのリスト（例：**商品**）の **⋮** メニューを開き、**消去して再ダウンロード…** を選択してください。デバイス上のコピーが破棄されて店舗のデータが取得され、店舗で削除されたレコードは取り除かれます。次回のバックグラウンド確認まで項目が一覧に残る場合があるため、価格と在庫が一致しているかで判断してください。その後、通知に別のリストのレコードが表示された場合は、そのリストについても、まず確認を行ってからこの手順を繰り返してください。
4. **サイト管理者:** 再ダウンロード後も同じレコードが繰り返し戻る場合、原因は通常、WooCommerceの保存フックを通さない一括変更です。CSVインポート、移行プラグイン、WP-CLI、または直接SQLなどが該当します。レジの確認が正しく行われるよう、WooCommerce経由で編集してください。同じ差異が繰り返し発生すると、WCPOSが整合性データを自動的に再構築します。
5. 再ダウンロード後もレジに誤った価格や在庫が表示される場合は、**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。
