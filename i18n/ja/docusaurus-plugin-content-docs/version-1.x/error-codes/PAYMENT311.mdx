## これが意味すること {#what-this-means}

WCPOSはこの返金が処理されたか確認できませんでした。

再試行する前に注文を開き、返金を確認してください。再試行すると二重に返金される可能性があります。

返金リクエストは送信されましたが、応答が失われました。リクエストがタイムアウトしたか、店舗がエラーを返した、またはWCPOSに待機して再試行するよう求めた可能性があります。返金されたかどうかは分かりません。再試行するたびに決済ゲートウェイへ新しい返金リクエストが送られるため、確認せず再試行すると顧客に二重返金される可能性があります。

## データへの影響 {#your-data}

このデバイス上のデータは失われません。店舗または決済ゲートウェイでは、すでに顧客への返金が処理されている可能性があります。

## トラブルシューティング {#troubleshoot}

1. まだ返金をやり直さないでください。
2. **注文**を開き、返金を確認してください。返金情報は店舗から直接読み込むため、このデバイスがオンラインである必要があります。WP Adminの**WooCommerce → 注文**で注文を開いても、返金を確認できます。
3. カード端末やVipps MobilePayなどの決済サービスを通じて返金した場合は、その決済サービス独自のダッシュボードも確認してください（または店舗オーナーに確認を依頼してください）。注文にまだ表示されていなくても、返金リクエストが送信されたか確認できます。
4. 返金が表示されていれば、処理済みです。もう一度返金しないでください。どちらにも表示されていない場合に限り、返金をもう一度試してください。決済サービスを確認できない場合は、次の手順に進んでください。
5. まだ不明な場合は、もう一度試す前に、**ログ**タブの**デバッグ情報をコピー**をタップしてサポートへお問い合わせください。
