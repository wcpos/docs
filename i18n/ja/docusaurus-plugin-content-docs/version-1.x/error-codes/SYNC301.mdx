## これが意味すること {#what-this-means}

ストア側の古い変更の一部がスキップされたため、再度ダウンロードする必要があります。

該当するデータに対して個別のダウンロードを実行してください。それでも差分が残る場合は、診断情報をエクスポートしてください。

## データへの影響 {#your-data}

店舗側で行われた一部の変更がまだこのデバイスに届いていないため、ダウンロードが完了するまでローカルデータが古い可能性があります。ローカルの変更が失われることはありません。この状態が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. ログエントリーを展開してください。コンテキストには、レジがどれだけ遅れていたか、変更がスキップされたかどうかが記録されています。
2. 該当するデータに対して個別のダウンロードを実行し、スキップされたストア側の変更を取得し直してください。
3. その後、最近編集したレコードをいくつかWP Adminと照合し、差分が解消したことを確認してください。
4. 差分が再び現れる場合は、何もリセットせずに、デバッグ情報をエクスポートしてサポートにお問い合わせください。
