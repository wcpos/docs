## これが意味すること {#what-this-means}

店舗の変更一覧が予期せず移動したため、WCPOSが自動的に再確認しています。データは失われていません。

対応は不要です。そのまま販売を続けてください。WCPOSが店舗の変更を自動的に再確認します。価格や在庫が古いままの場合は、**店舗の状態 → データベース**で**すべてを今すぐ確認**をタップしてください。

## データへの影響 {#your-data}

データは失われておらず、このデバイス上のデータにも危険はありません。再確認が完了するまで、このデバイスの一部の価格や在庫が古い場合があります。

## トラブルシューティング {#troubleshoot}

1. 販売を続けてください。このデバイスのデータは失われず、再確認は自動的に行われます。ログ項目には、店舗の変更が一部スキップされた、または店舗の一覧が後退したなど、何が起きたかが記載されている場合があります。どちらの場合も、あらゆる種類のデータが対象になり得ます。
2. 価格や在庫が古いままの場合は、**店舗の状態 → データベース**を開き、**すべてを今すぐ確認**をタップしてください。
3. 確認後もレコードに問題がある場合、またはこのコードが繰り返し表示される場合は、**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。データを消去して解決しようとしないでください。
