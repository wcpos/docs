## これが意味すること {#what-this-means}

このデバイスに保存されたデータの一部が破損しているため、同期できません。

**ログ**タブの上部にある**デバッグ情報をコピー**をタップし、WCPOSサポートに送ってください。WCPOSを再インストールしたり、サインアウトしたり、データを消去したりしないでください。店舗にまだ届いていない変更は、このデバイスにしかありません。

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ届いていない販売データが含まれている可能性があります。アプリの再インストールやサインアウトでも、データが削除される場合があります。どの種類のデータなら安全に再ダウンロードできるか、サポートに確認してください。

## トラブルシューティング {#troubleshoot}

1. WCPOSが引き続き使える場合は、販売を続けてください。再インストール、サインアウト、データの消去はしないでください。
2. **ログ**タブの上部にある**デバッグ情報をコピー**をタップして、エントリーが表示されたときに行っていた操作とともにWCPOSサポートへ送ってください。
3. **店舗の状態 → データベース**を開き、**送信待ちの変更**の件数と、**「… 件の変更がサーバーに届いていません」**または**「… 件の変更が保留中です」** パネルが表示されているかをサポートに伝えてください。これらの変更はこのデバイスにしかありません。
4. ログエントリーには、どのデータが破損しているか記載されていません。送信待ちの変更がなくなった後、サポートから特定の種類のデータを再ダウンロードするよう案内される場合があります（該当行の **⋮** メニュー → **消去して再ダウンロード…**）。どのデータかサポートが確認する前に実行しないでください。間違ったデータを消去したり、送信待ちの変更がある間に消去したりすると、店舗に届いていない販売データが削除される可能性があります。破損が原因で変更を送信できない場合は、サポートが先に復元します。送信待ちのデータがある間は、決して再ダウンロードしないでください。
