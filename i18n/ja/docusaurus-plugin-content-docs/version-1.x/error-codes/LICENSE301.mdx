## これが意味すること {#what-this-means}

アップデーターがWCPOS Proの更新をダウンロードする権限を持っていません。

このストアでアップデーターを再承認してから、もう一度更新を確認してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、WordPressサイトの管理担当者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. アップデーターが認証できるよう、POS設定でライセンスキーを入力し直すか、再度有効化してください。
2. WP Admin → ダッシュボード → 更新 から、もう一度更新を確認してください。
3. 承認が失敗し続ける場合は、サイトから更新サーバーへの外向きリクエストがブロックされている可能性があります。外向きのHTTPSが制限されていないか、ホスティング事業者に確認してください。
