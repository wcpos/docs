## これが意味すること {#what-this-means}

バージョンがWCPOSと一致しないため、WCPOS Proが無効になっています。

両方のバージョンに互換性が生じるよう、指摘されたWCPOSまたはWCPOS Proのコンポーネントを更新してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。この状態が続く場合は、WordPressサイトの管理担当者にお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. WP Admin → プラグイン で両方のプラグインのバージョンを確認してください。WCPOSとWCPOS Proのどちらが古いかは、ログエントリーに記載されています。
2. 古い方を更新してください。両方を最新バージョンに更新すれば、不一致は解消します。
3. Proの更新が提供されない場合は、アップデーターが承認されていない可能性があります（LICENSE301を参照）。先にそちらを解決してから更新してください。
