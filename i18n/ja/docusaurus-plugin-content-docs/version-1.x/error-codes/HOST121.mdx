## このエラーの意味 {#what-this-means}

店舗の API の代わりにボット保護ページが応答しています。

アプリが JSON を受け取るはずの箇所で、店舗の REST API が HTML の認証チャレンジページ（ボット保護、CAPTCHA、DDoS 対策の中間ページ）を返しています。POS アプリはブラウザー向けのチャレンジを解くことができません。保護サービスで店舗の REST API を許可リストに追加する必要があります。

## データへの影響 {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. チャレンジページから保護サービスを特定し、その設定を開いてください。Cloudflare、Sucuri、Kinsta など、それぞれのブランドがページに表示されています。
2. API 通信を許可するため、店舗自身の REST API パス（/wp-json/ と /?rest_route=）を許可リストに追加してください。
3. Cloudflare では、REST API のパスに対する WAF の**スキップ**ルールを追加してください。無料プランの Bot Fight Mode はどのルールでも回避できないため、無効にする必要があります。[Cloudflareガイド](/1.x/support/troubleshooting/cloudflare)に、具体的なルールと `curl` での確認方法があります。
4. Kinsta ではボット・ファイアウォール設定で REST API パスを許可リストに追加してください。Sucuri では API ルートに JavaScript チャレンジを使う DDoS モードを適用しないでください。
