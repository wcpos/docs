## これが意味すること {#what-this-means}

サインインの認証情報がストアに受け入れられませんでした。

ユーザー名とパスワードを入力し直してください。失敗が続く場合は、WordPressでパスワードをリセットしてください。注文データへの影響はありません。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

**レジ端末** — レジ係向け：ユーザー名とパスワードを再入力してください。この組み合わせは店舗側で拒否されました。

**店舗側** — サイト管理者向け：

1. 同じ認証情報でWP Adminにサインインできることを確認してください。失敗する場合は、そこでパスワードをリセットします。
2. WP AdminにはサインインできるのにPOSではできない場合、ログイン保護またはセキュリティプラグインがプログラムからのサインインをブロックしている可能性があります。設定を確認してください。
