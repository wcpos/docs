## これが意味すること {#what-this-means}

この商品変更はまだ店舗に反映されていません。

表示された理由を確認し、該当する内容を修正するか接続を確認してから、商品を再度保存してください。

## データへの影響 {#your-data}

この端末のデータを消去しないでください。店舗にまだ反映されていない変更が含まれている可能性があります。接続エラーの場合は、接続後に商品を再度保存してください。店舗で編集が拒否された場合、この端末の内容は店舗のバージョンに戻ります（[SYNC202](/error-codes/SYNC202)を参照）。理由を解決してから、再度編集してください。問題が続く場合は、**ログ**タブで**Copy debug info**を使い、WCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 表示された理由を確認してください。通常、ログ項目のエラーテキストから、接続エラー、店舗で拒否された値、または店舗で競合する編集が行われたかどうかがわかります。

**レジ端末：**

- 接続エラー：接続を確認してから、商品を再度保存してください。
- 拒否された値：理由に記載された内容を修正してから、商品を再度保存してください。

**店舗側（WP Admin）：** 編集が競合している場合は、商品を開き、レジに表示されている内容と比較し、正しい値を一度保存してください。

明確な理由がないまま保存に失敗し続ける場合は、**ログ**タブで**Copy debug info**を使い、サポートにお問い合わせください。
