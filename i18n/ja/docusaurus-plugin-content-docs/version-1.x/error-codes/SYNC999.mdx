## これが意味すること {#what-this-means}

同期で予期しない問題が発生しました。

この項目に記載された操作が完了したか確認してください。完了していない場合は、もう一度実行してください。繰り返し発生する場合は、**デバッグ情報をコピー**をタップしてサポートに送信してください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだ届いていない変更が含まれている可能性があります。項目に記載された操作が完了していない場合は、もう一度実行してください。

## トラブルシューティング {#troubleshoot}

1. ログ項目を展開し、記載された操作を確認してください。完了したか確認します。保存の場合は注文またはレコードを開き、変更が反映されたことを確認してください。完了していれば、WCPOSが自動的に送信するため、そのままにしてください。
2. 完了していない場合は、もう一度実行してください。ログ項目に、このデバイスで変更が保存されなかったと記載されている場合、記録された内容はありません。
3. ログ項目のコードと理由を記録してください。999コードは、具体的な原因に専用コードがまだないことを意味します。そのため、このコンテキストがサポートにとって特に重要です。
4. 繰り返し発生する場合は、**ログ**タブで**デバッグ情報をコピー**をタップしてサポートに送信してください。報告によって、該当する原因に専用コードが追加されます。
