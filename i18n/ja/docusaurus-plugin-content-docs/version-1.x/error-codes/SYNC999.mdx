## これが意味すること {#what-this-means}

同期で予期しない問題が発生しました。

このデバイスですでに記録された販売データは安全です。まずログを確認してください（トラブルシューティングを参照）。自動的に再試行される場合があります。書き込みがキューに届かなかった場合は、再入力が必要です。このコードが繰り返し表示される場合は、診断情報をエクスポートしてサポートにお問い合わせください。

## データへの影響 {#your-data}

入力内容が取得されていれば、このデバイスに安全に保存されていますが、店舗にはまだ届いていません。ログでキューに入る前に書き込みが失敗したことが示されている場合（トラブルシューティングの手順2を参照）は、再入力してください。問題が続く場合は、診断情報をエクスポートしてWCPOSサポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. このコードが必ず再試行されると考えないでください。まずログエントリーを展開してください。変更がすでにキューに入っていることが確認できる場合、WCPOSは自動的に再試行しますので、そのままにしてキューが処理されるのを待ってください。
2. エンジンのレジデントが見つからない、またはミューテーションIDが返される前に書き込みが失敗した、とエラーに記載されている場合は、何もキューに入っていません。そのレコードまたは注文に戻って、もう一度保存してください。
3. ログエントリーを展開し、イベントコードと（あれば）serverCodeを控えてください。999のコードは、その具体的な原因に専用のコードがまだ割り当てられていないことを意味するため、このコンテキストこそがサポートに必要な情報です。
4. このコードが繰り返し表示される場合は、**デバッグ情報をコピー** を使用してサポートにお問い合わせください。報告いただくことで、専用のコードが追加されます。
