## これが意味すること {#what-this-means}

店舗の応答に余分なテキストが含まれていたため、WCPOS が取り除こうとしました。

操作が完了したことを確認してください。余分なテキストの除去に失敗する場合があります。余分なテキストは通常、プラグインや PHP の通知が店舗の応答に出力を追加することで発生します。頻繁に表示される場合は、サイト管理者にサイトの PHP エラーログで警告を確認するよう依頼してください。

## データへの影響 {#your-data}

操作が完了しなかった場合（トラブルシューティングの手順1を参照）、そのリクエストの案内に従ってください。完了していれば、注文や商品データに影響はありません。頻繁に発生する場合は、WordPress サイトの管理者に相談してください。

## トラブルシューティング {#troubleshoot}

1. 操作が完了したか、たとえば販売内容や変更が表示されているかを確認してください。完了していれば、それ以上の対応は不要です。完了していなければ、もう一度操作してください。それでも失敗する場合は、表示されたエラーの案内に従うか、サポートにお問い合わせください。
2. 原因はサイト側にあります。プラグインまたはテーマが、REST応答に警告や余分な出力を書き出しています。失敗した時刻のPHPの通知がないか、サイトのログを確認するようサイト管理者に依頼してください。
3. **サイト管理者向け:** ブラウザーの開発者ツール（Network タブ）、またはデスクトップアプリの **Advanced → Toggle Developer Tools** で、生の応答本文を確認できます。JSON の直前または直後に余分な出力が表示されます。
4. **サイト管理者向け:** 余分なテキストの除去は可能な範囲で行われます。頻繁に発生する場合は、それに頼らず原因となるプラグインを修正してください。
