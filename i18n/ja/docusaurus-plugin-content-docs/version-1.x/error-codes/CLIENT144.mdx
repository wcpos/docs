## このエラーの意味 {#what-this-means}

検索インデックスの再構築に失敗したため、アプリが初期化を再試行している間は検索結果が不完全になる可能性があります。

検索インデックスの問題（[CLIENT141](/error-codes/CLIENT141) または [CLIENT143](/error-codes/CLIENT143)）を検出した後、アプリはインデックスの再構築を試みましたが、その再構築自体に失敗しました。検索は引き続き応答します。既存のインデックスから既知の不正な結果を除外して検索するか、このデバイス上のデータを直接スキャンしますが、影響を受けたリストでは結果が見つからなかったり、順位が正しくなかったりする場合があります。次回の検索または準備状態チェックでインデックスの初期化が再試行され、自動的に回復することがあります。結果が引き続き正しくない場合は、アプリを再読み込みして新たに開始することもできます。

## データについて {#your-data}

店舗データは変更されていません。この問題は、このデバイスにすでにあるデータから生成されるローカル検索インデックスにのみ関係します。

## トラブルシューティング {#troubleshoot}

1. ログエントリを開きます。コンテキストには、影響を受けたリストと再構築時に発生したエラーが示されます。エラーにストレージに関する記載がある場合は、まずデバイスの空き容量を確保してください。Web では、プライベートブラウズまたはシークレットウィンドウも避けてください。
2. 影響を受けたリストで再度検索を実行します。アプリはインデックスの初期化を自動的に再試行します。
3. 結果が引き続き見つからない、または並び順が正しくない場合は、アプリを再読み込みしてください。Web ではブラウザタブを再読み込みし、デスクトップおよびモバイルではアプリを閉じて再度開きます。その後も CLIENT144 が再度記録される場合は、ログ画面からデバッグ情報をエクスポートし、サポートにお問い合わせください。
