## これが意味すること {#what-this-means}

ストアのアドレスが未入力か、有効なURLではありません。

アドレスに入力ミスがないか確認し、ストアのWordPressサイトの完全なURL（https:// を含む）を入力してから、もう一度お試しください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. アドレスに入力ミスがないか確認し、https:// を含む完全なURLを入力してください（例: https://shop.example.com）。
2. 管理画面やチェックアウトのURLではなく、サイトのWordPressアドレスを使用してください。
3. サイトがサブディレクトリ（例: /shop）にある場合は、それも含めてください。
