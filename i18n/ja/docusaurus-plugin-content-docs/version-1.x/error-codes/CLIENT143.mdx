## このエラーの意味 {#what-this-means}

検索で見つかるはずの商品が見つかりませんでした。

表示されている商品が検索で見つからない場合を除き、対応は不要です。その場合はWCPOSを再読み込みしてください。

定期的な自己チェックで、ローカル検索インデックスに、そのレコード自体の語句でレコードを検索させましたが、インデックスから結果が返されませんでした。つまり、このデバイスに実際に保存されている件数より少ない結果が検索に表示されていた可能性があります。アプリがインデックスを自動的に再構築する場合もありますが、セッションごとにリスト一つにつき一回だけなので、再構築されるとは限りません。

## データについて {#your-data}

店舗データは変更されていません。これは、このデバイスにすでにあるデータから生成されるローカル検索インデックスのみに関するものです。再構築してもデータは失われません。

## トラブルシューティング {#troubleshoot}

1. 表示されている商品が検索で見つからない場合を除き、対応は不要で、販売を通常どおり続けられます。アプリがインデックスを自動的に再構築する場合もありますが、セッションごとにリスト一つにつき一回だけです。このコードが再び表示された場合は、次の手順に進んでください。
2. アプリで確認できるレコード（商品、顧客、注文、その他のリスト）が検索で引き続き見つからない場合は、アプリを再読み込みしてください。Webではブラウザータブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じてから再度開きます。これにより、次回問題が検出されたときに新たな再構築を試行できます。
3. 再読み込み後にこのコードが再び表示された場合は、**ログ**タブで**デバッグ情報をコピー**を使用してサポートにお問い合わせください。ログエントリーには、影響を受けたリストとインデックスから漏れたレコードを特定するために必要な詳細が含まれています。
