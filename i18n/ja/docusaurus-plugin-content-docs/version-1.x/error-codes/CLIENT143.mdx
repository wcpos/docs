## このエラーの意味 {#what-this-means}

検索で見つかるはずの商品が表示されませんでした。

画面で確認できる商品が検索に出てこない場合を除き、対応は不要です。その場合はWCPOSを再読み込みしてください。

定期的な自己診断で、ローカル検索インデックスに、そのレコード自身の語句で検索しても見つからないレコードがあることがわかりました。そのため、この端末に実際に保存されている数より少ない結果が表示されていた可能性があります。アプリが自動的にインデックスを再構築する場合もありますが、セッションごとに一覧単位で1回だけのため、再構築されるとは限りません。

## データについて {#your-data}

店舗データは変更されていません。これは、このデバイスにすでにあるデータから生成されるローカル検索インデックスのみに関するものです。再構築してもデータは失われません。

## トラブルシューティング {#troubleshoot}

1. 表示されるはずの商品が検索に出てこない場合を除き、対応は不要です。通常どおり販売を続けられます。アプリが自動的にインデックスを再構築する場合もありますが、セッションごとに一覧単位で1回だけです。このコードが繰り返し表示される場合は、次の手順に進んでください。
2. アプリで確認できるレコード（商品、顧客、注文、その他のリスト）が検索で引き続き見つからない場合は、アプリを再読み込みしてください。Webではブラウザータブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じてから再度開きます。これにより、次回問題が検出されたときに新たな再構築を試行できます。
3. 再読み込み後にこのコードが再び表示された場合は、**ログ**タブで**デバッグ情報をコピー**し、サポートにお問い合わせください。ログには、影響を受けた一覧と、インデックスで見つからなかったレコードを特定するために必要な情報が含まれています。
