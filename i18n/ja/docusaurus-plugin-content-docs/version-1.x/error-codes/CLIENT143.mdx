## このエラーの意味 {#what-this-means}

検索インデックスに含まれているはずの商品が見つからなかったため、アプリは検索インデックスの自動再構築を試みます。

定期的な自己チェックで、ローカル検索インデックスに対してレコード自身の語句で検索を行いましたが、インデックスからそのレコードが返されませんでした。これは、このデバイスに実際に保存されている件数よりも少ない検索結果が表示されていた可能性があることを意味します。アプリは修正のため、セッションごとに各リストで1回、自動的にインデックスの再構築を試みます。

## データについて {#your-data}

店舗データは変更されていません。これは、このデバイスにすでにあるデータから生成されるローカル検索インデックスのみに関するものです。再構築してもデータは失われません。

## トラブルシューティング {#troubleshoot}

1. 通常は対応不要で、販売は通常どおり継続できます。アプリが自動的に再構築を試み、完了すると検索は復旧します。各リストで試行される再構築はセッションごとに1回のみです。このコードが繰り返し表示される場合は、次の手順に進んでください。
2. アプリで確認できるレコード（商品、顧客、注文、その他のリスト）が検索で引き続き見つからない場合は、アプリを再読み込みしてください。Webではブラウザータブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じてから再度開きます。これにより、次回問題が検出されたときに新たな再構築を試行できます。
3. 再読み込み後もコードが表示される場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。ログエントリーには、影響を受けたリストとインデックスで見つからなかったレコードを特定するためにサポートが必要とする詳細が含まれています。
