## この意味 {#what-this-means}

ストアの前段にあるプロキシが、ヘッダーが多すぎることを理由にサーバーの応答を拒否しています。

キャッシュまたはプロキシの層（一般的には Varnish）が、応答ヘッダーの数やサイズに上限を課しています。ストアの軽量なエンドポイントは収まりますが、完全な API 応答は上限を超え、WordPress からではなくプロキシから 503 として返ってきます。その層で上限を引き上げる必要があります。

## お客様のデータ {#your-data}

注文データや商品データには影響しません。

## トラブルシューティング {#troubleshoot}

1. Varnish では、http_max_hdr（ヘッダー数）と http_resp_hdr_len / http_resp_size（サイズ）を引き上げます。
2. どのプロキシ層が 503 を返しているかをホストに尋ねてください — リクエストがそこで失敗することはないため、WordPress のエラーログには何も表示されません。
3. 簡単な確認方法: ストアの /wcpos/v2/ping は正常に応答するのに、データエンドポイントが 503 になります。
