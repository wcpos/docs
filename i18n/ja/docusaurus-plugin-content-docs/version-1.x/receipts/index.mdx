WCPOSには、レシート、請求書、ギフトレシート、納品書、キッチンチケットなどに対応する包括的なテンプレートシステムがあり、すべて **WP Admin → POS → テンプレート** で管理できます。

:::tip レシートを変更したいだけの場合は？
まず **[レシートをカスタマイズする](/1.x/receipts/customise)** をご覧ください。同梱テンプレートの変更、AIによる調整、手動編集という、最も簡単な三つの方法を説明しています。
:::

## テンプレートエンジン {#template-engines}

WCPOSは三種類のテンプレートエンジンに対応しています。テンプレートの作成時、またはギャラリーカードの **テンプレートを使用** をクリックしたときにエンジンが選ばれ、**後から変更することはできません**。エンジンを切り替える場合は、新しいテンプレートを作成してください。

<FeatureGrid>
  <FeatureCard icon="code" title="ロジックレスHTML（推奨）">
    Mustache形式の <code>{"{{variable}}"}</code> プレースホルダーをプレーンHTML内で使用します。クライアント側でレンダリングするため、レシートは **オフラインで動作** します。ブラウザー印刷やPDFレシートに使用します。
  </FeatureCard>
  <FeatureCard icon="print" title="サーマル XML">
    画面プレビューと、サーマルレシートプリンター用の **ESC/POS コマンド** の両方を生成するXMLテンプレートです。同じテンプレートから二種類の出力が得られます。Epson、Starなどのサーマルプリンターに使用します。
  </FeatureCard>
  <FeatureCard icon="terminal" title="レガシー PHP">
    WooCommerceの関数を使用するサーバー側のPHPテンプレートです。既存の <code>yourtheme/woocommerce-pos/receipt.php</code> による上書きとの後方互換性を維持するために残されています。レンダリングにはサーバー接続が必要です。
  </FeatureCard>
</FeatureGrid>

## テンプレートギャラリー {#template-gallery}

ギャラリーには、そのまま使うこともカスタマイズすることもできる既成テンプレートが用意されています。**カテゴリ**（レシート、請求書、ギフトレシート、キッチンチケット、見積書 / 発注書）、**フォーマット**（HTML / サーマル）、**方向**（LTR / RTL）で絞り込み、店舗の実データでプレビューできます。各カードのフッターには **プレビュー** リンクと、主操作となる **テンプレートを使用** ボタンがあります。「テンプレートを使用」をクリックすると、編集可能なコピーが *マイテンプレート* に作成されます。

### サードパーティ製ドキュメントテンプレート {#third-party-document-templates}

WP Overnightの **PDF Invoices & Packing Slips for WooCommerce** が有効な場合、WCPOSはレシートテンプレート一覧に **請求書（WP Overnight）** と **納品書（WP Overnight）** も表示します。これらのHTMLテンプレートはサーバー側でレンダリングされ、WP OvernightのドキュメントAPIを利用して、そのプラグインで設定した請求書と納品書の採番、レイアウト、ブランド設定、法的情報・税務項目、テンプレートのカスタマイズを再利用します。

これらはWP Overnightプラグインが有効な場合にのみ利用でき、レンダリングにはサーバー接続が必要です。オフライン印刷が必要な場合は、WCPOSに同梱されているHTMLまたはサーマルテンプレートを使用してください。

### 税表示の自動調整 {#adaptive-tax-display}

同梱テンプレートの大半（標準、標準RTL、ミニマル/モダン、狭幅、請求書、見積書、シンプルなサーマルレシートの各種）は、**WooCommerceの税表示設定に自動的に対応します**。

- **税込価格の店舗**（EU/UK/AU）では、税込価格と「税金込み」の行が表示されます。
- **税抜価格の店舗**（US/CA）では、税抜価格が表示され、税額は別の行に追加されます。
- 総合計には、実際に請求された税込金額が常に表示されます。

**詳細** シリーズは正式な税務請求書であり、店舗設定にかかわらず、常に税抜きの明細行と明確な税額内訳を表示します。

## 仕組み {#how-it-works}

1. **テンプレートを追加** — ギャラリーカードで **テンプレートを使用** をクリックするか、一から作成します。
2. **カスタマイズ** — ライブプレビュー付きのアプリ内エディターを使用するか、ChatGPT / Claudeに貼り付けて希望する変更を依頼します。
3. **有効化** — *マイテンプレート* で **有効** トグルをオンにします。有効なレシートテンプレートはすべて、レジのレシート画面にあるドロップダウンに表示されます。
4. **印刷または表示** — チェックアウト後にレシートが開き、印刷、メール送信、画面表示を選択できます。テンプレートはレジ以外でも使用でき、オンラインのお客様も同じデザインで生成された[レシートをマイアカウントからダウンロード](/1.x/receipts/storefront)できます。

テンプレートは、店舗情報、明細、合計、税金、支払い、払い戻しなどのセクションを含む標準化された[レシートデータペイロード](/1.x/receipts/receipt-data)に基づいてレンダリングされます。すべての通貨フィールドには、整形済みの `_display` バリアントが含まれます（例：`29.99` の代わりに `$29.99`）。

## Pro機能 {#pro-features}

[WCPOS Pro](/1.x/getting-started/pro-license)では、店舗ごとにテンプレートの割り当て、ブランド設定（ロゴ、住所、連絡先）、テンプレートの並び順を設定できます。各店舗が独自のレターヘッドで印刷する複数拠点の運用に便利です。
