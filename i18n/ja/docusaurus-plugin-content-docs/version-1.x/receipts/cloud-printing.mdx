クラウド印刷を使うと、レジを実行しているデバイスに直接接続されていないプリンターにも、WCPOS からレシートを送信できます。WP Admin で一度設定すれば、キッチン、バックオフィス、別室などのプリンターで注文を印刷できます。各デバイスでプリンターを検出してペアリングする必要はありません。

## クラウド印刷とは？ {#what-is-cloud-printing}

**ローカル印刷**では、POS を実行しているデバイスが USB、Bluetooth、ローカルネットワーク経由でプリンターと直接通信します。レジの隣にプリンターがある場合に適しています。同じデバイスに USB、Bluetooth、ネットワークプリンターを接続する方法は、[プリンター設定](/1.x/hardware/printers)を参照してください。

**クラウド印刷**は、それ以外の場合に適しています。別の場所やネットワークにあるプリンターを使う場合や、デバイスごとに設定せずにプリンターを共有したい場合です。配信方式は二種類です。

- **ポーリング型プリンター。** プリンターが一定の間隔でインターネット経由で WCPOS に問い合わせ、待機中のジョブがあれば取得します。WCPOS からプリンターに接続することはなく、通信は常にプリンター側から開始します。**Star CloudPRNT** と **Epson Server Direct Print** はこの方式です。
- **ホスト型リレープロバイダー。** WCPOS がホスト型サービスに印刷ジョブを送信し、そのサービスがプリンターに配信します。**Star Online** と **PrintNode** はこの方式です。Star Online は stario.online アカウントに登録された Star CloudPRNT プリンターに配信します。PrintNode はデスクトップクライアントを通じて、そのコンピューターから印刷できるほぼすべてのプリンターに配信します。

:::info ポーリング型プリンターを使う理由
ポーリング型プリンターは外向きのリクエストのみを送信するため、ポートの開放、固定 IP、ファイアウォールの変更は不要です。遠隔地や、自分で管理できないルーターの配下にあるプリンターに適しています。ただし、次のポーリング時に印刷するため、少し遅延が生じます。
:::

## WCPOS Cloud Print — リレー {#relay}

**ポーリング型**プリンター（Star CloudPRNT または Epson Server Direct Print）を設定すると、WCPOS が発行するポーリング URL は、ご自身のサイトではなく **cloudprint.wcpos.com** を指します。これが **WCPOS Cloud Print** です。WCPOS が運営する無料のリレーで、プリンターと店舗の間を中継します。

**リレーが必要な理由。** レシートプリンターのファームウェアは小規模で、更新されることもほとんどありません。そのため、多くのプリンターは最新のホスティング上の店舗サイトと安全な接続を確立できません。新しい TLS バージョンや認証局、サイトの前段にある CDN やファイアウォール（よくある例は Cloudflare）がプリンターの接続を拒否したり、逆にプリンター側が拒否したりします。この場合、すべての設定が正しくてもプリンターは**待機中**のままになります。リレーは古いファームウェアでも確立できる接続をプリンターに提供し、通信を店舗サイトへ中継します。

**仕組み：**

- クラウド印刷の設定を初めて開くと、サイトがリレーに**自動的に**接続します。有効化や設定の操作は不要です。
- プリンターが `cloudprint.wcpos.com` をポーリングすると、リレーが店舗サイトにリクエストを転送し、サイトからの応答を返します。印刷ジョブはリレーを**通過**するだけで、保存されることはありません。
- リレーが待機中のポーリングの大部分を処理するため、待機中のプリンターからサイトへのリクエストは、数秒ごとではなく約一分に一回に減ります。
- サイトがリレーに接続できない場合（リレーからアクセスできないローカル開発サイトなど）、WCPOS は自動的にサイト直結の URL に切り替えます。

:::note 直接接続を使いたい場合
各プリンターの設定画面には**詳細設定**の開閉セクションがあり、サイト直結の URL を確認できます。ホスティングがプリンターからの接続に対応している場合や、ジョブをリレー経由で送信したくない場合に使用してください。開発者は次の一行で、サイト全体のリレーを無効にできます。

```php
add_filter( 'woocommerce_pos_cloud_print_relay_enabled', '__return_false' );
```
:::

**リレーから見えるもの。** 接続すると、サイトの URL が wcpos.com と共有されます。また、印刷ジョブ（注文の詳細を含むレシートの内容）はプリンターへ届くまでの経路でリレーを通過します。データが保持されることはありません。詳細は[プライバシーポリシー](https://wcpos.com/privacy)に記載されています。

## クラウドプリンターの設定 {#setup}

クラウドプリンターは WP Admin で一度設定すれば、すべてのデバイスで共有されます。設定がデバイスごとに保存されるローカルプリンターとは異なります。

**WP Admin > POS > 設定 > クラウド印刷**に移動し、**プリンターを追加**をクリックします。**名前**（例：「キッチン」「バックオフィス」）を付けてください。WCPOS はプリンターに基づいて固定の**プリンター ID** を自動生成します。この ID は変わらないため、プリンターのファームウェア設定から安心して参照できます。

プリンターを作成したら、プロバイダー側を設定します。

### Star または Epson（ポーリング型プリンター） {#setup-polling}

<Steps>
  <StepCard number="1" title="WCPOS にプリンターを追加">

**WP Admin > POS > 設定 > クラウド印刷**でプリンターを追加し、プロバイダーに **Star CloudPRNT** または **Epson Server Direct Print** を選択します。WCPOS がそのプリンター用の**ポーリング URL** と**ワンタイムトークン**を生成します。

  </StepCard>
  <StepCard number="2" title="ポーリング URL とトークンをコピー">

生成されたポーリング URL とトークンをコピーします。通常、URL は **cloudprint.wcpos.com** を指します。これは [WCPOS Cloud Print リレー](#relay)で、通常はこちらを使用します。サイト直結の URL は**詳細設定**の開閉セクションにあります。**トークンは一度しか表示されません**。紛失した場合は、プリンターカードから新しいトークンを生成し、プリンター側の値も更新してください。

  </StepCard>
  <StepCard number="3" title="プリンターの設定に入力" isLast>

プリンターの設定ページを開きます。Star では **CloudPRNT** 設定、Epson では **Server Direct Print** 設定に、ポーリング URL とトークンを貼り付けてください。ポーリング間隔の指定が必要な場合は設定します（通常は数秒）。保存し、必要に応じてプリンターを再起動してください。

次のポーリング時にプリンターが接続すると、WCPOS のステータスが**待機中**から**接続済み**に変わります。

  </StepCard>
</Steps>

### PrintNode {#setup-printnode}

<Steps>
  <StepCard number="1" title="PrintNode デスクトップクライアントをインストール">

対象のプリンターで既に印刷できるコンピューターに、**PrintNode クライアント**をインストールしてサインインします。ジョブを印刷するには、クライアントを起動したまま、オンラインにしておく必要があります。

  </StepCard>
  <StepCard number="2" title="PrintNode API キーを取得">

PrintNode アカウントで **API キー**を作成します。このキーにより、WCPOS から PrintNode アカウントにジョブを送信できるようになります。

  </StepCard>
  <StepCard number="3" title="WCPOS に API キーを入力">

**WP Admin > POS > 設定 > クラウド印刷**でプリンターを追加し、プロバイダーに **PrintNode** を選択して、API キーを貼り付けます。WCPOS はこのキーを使って、PrintNode アカウントに登録されているプリンターの一覧を取得します。

  </StepCard>
  <StepCard number="4" title="プリンターを選択" isLast>

PrintNode クライアントが報告するプリンターの一覧から対象のプリンターを選択し、保存します。WCPOS がこのプリンター向けのジョブを PrintNode に送信し、クライアントが印刷します。

  </StepCard>
</Steps>

### Star Online {#setup-star-online}

Star プリンターが既に **stario.online** アカウントに登録されており、Star のホスト型サービスで配信したい場合は、Star Online を使用します。

<Steps>
  <StepCard number="1" title="CloudPRNT URL を取得">

stario.online で**デバイスグループ**を開き、グループの **CloudPRNT URL** をコピーします。`https://device.stario.online/cloudprnt/...` または `https://eu-device.stario.online/cloudprnt/...` のような形式です。

  </StepCard>
  <StepCard number="2" title="必要な権限を持つ API キーを作成">

stario.online で WCPOS 用の API キーを作成します。キーには、デバイスの一覧取得と印刷の権限が必要です。少なくとも次の権限を有効にしてください。

- **EnumDevices** — WCPOS がデバイス一覧を取得する際に必要
- **ViewDevice** — デバイスのステータス確認に使用
- **PrintToDevice** — 印刷ジョブの送信に必要
- **ViewDeviceGroups** — グループの検索と診断のために推奨

API キーが存在していても、これらの権限が有効でないと操作に失敗することがあります。

  </StepCard>
  <StepCard number="3" title="WCPOS に URL と API キーを入力">

**WP Admin > POS > 設定 > クラウド印刷**でプリンターを追加し、プロバイダーに **Star Online** を選択して、CloudPRNT URL と API キーを貼り付けます。**デバイスを取得**をクリックしてください。

  </StepCard>
  <StepCard number="4" title="Star デバイスを選択" isLast>

デバイス一覧からプリンターを選択して保存します。WCPOS は API キーをサーバー側に保存し、Star Online にジョブを送信する際に、選択したデバイスのアクセス識別子を使用します。

  </StepCard>
</Steps>

## 自動印刷ルール {#auto-print}

自動印刷ルールでは、何をどこに自動印刷するかを平易な文章で指定します。ルールは**スコープ × プリンター × テンプレート**に、実行する**タイミング**と印刷する**部数**を組み合わせたものです。たとえば、次のように指定します。

> **すべての注文**を、**支払い完了時**に、**キッチン**プリンターで**キッチンチケット**を使って **×2** 部印刷する。

ルールは**注文作成時**または**支払い完了後のみ**に実行できます。注文が入った時点でキッチンチケットを印刷し、お客様用のレシートは支払い完了まで待つ、といった設定が可能です。調理場などで複数部必要な場合は、**印刷部数**も設定できます。条件に一致する注文が指定したタイミングに達すると、WCPOS が選択した**テンプレート**をサーバー側でプリンターに必要な形式にレンダリングし、キューに追加します。レジ係の操作は不要です。

:::note テンプレートの互換性にご注意ください
Star と Epson のプリンターは、ジョブをプリンター固有のコマンド言語（Star は Star Document Markup または ESC/POS、Epson は ePOS-Print）にレンダリングする必要があるため、**サーマル**テンプレートのみ使用できます。PrintNode はジョブを **PDF** にレンダリングするため、サーマルからフルページの HTML まで、**任意**のテンプレートを使用できます。プリンターの選択肢にテンプレートが表示されない場合は、その形式に対応していないためです。サーマルレイアウトの作成については、[サーマルテンプレート](/1.x/receipts/thermal-templates)を参照してください。
:::

## 店舗別プリンター（Pro） {#per-store-printers}

:::info Pro 機能
店舗別の印刷ルーティングには、[WCPOS Pro](/1.x/getting-started/pro-license) と[複数店舗](/1.x/stores)の設定が必要です。
:::

デフォルトでは、自動印刷ルールはグローバルで、すべての店舗が共有します。Pro では、各店舗に**独自の**クラウド印刷ルールを設定し、その店舗の注文を専用のプリンターで印刷できます。ある店舗のキッチンチケットが別の店舗で印刷されるのを防げます。

**POS → 店舗**で店舗を編集し、**クラウド印刷**セクションを開いて**ルールを追加**をクリックします。各ルールには次の項目があります。

- **プリンター ID** — 送信先クラウドプリンターの固定 ID
- **スコープ** — **POS 注文のみ**（デフォルト）、**オンライン注文のみ**、または**すべての注文**
- **形式** — **StarPRNT**（デフォルト）、**ESC/POS**、**Epson ePOS-Print**、または **HTML**

注文が独自のルールを持つ店舗に属している場合、WCPOS はその店舗のプリンターに送信します。店舗に独自のルールが**ない**場合は、自動印刷ルールを**グローバルのものに戻します**。そのため、設定が異なる店舗だけを設定すれば十分です。

## 手動印刷 {#manual}

自動印刷ルールの実行を待つ必要はありません。レジ係は**チェックアウト／レシート画面**から、必要なときにクラウドプリンターへレシートを送信できます。再印刷や、特定のプリンターに一度だけチケットを送信する場合に便利です。

レシートの生成方法はプリンターによって異なります。

- **Star CloudPRNT** — レシートは**デバイス上**でレンダリングされ、CloudPRNT 経由でプリンターに送信されます。
- **Star Online、Epson、PrintNode** — 選択した注文とテンプレートから**サーバー上**でレシートをレンダリングし、プリンターまたはホスト型リレーに配信します。

:::note 一部の形式に対応していないプリンター向けの代替レンダリング
**Star CloudPRNT** はプリンターとメディアタイプを調整し、高機能な形式を受け付けない場合はプレーンテキスト(`text/plain`)に切り替えます。ファームウェアが StarPRNT コマンドを解釈できない Star プリンターでは、WCPOS がレシートを**サーバー側で PNG 画像として**レンダリングし、代わりに送信できます。これにより、印刷に失敗せずにレシートを出力できます。
:::

## 印刷キュー {#print-queue}

クラウドプリンター向けのジョブは、プリンターが取得するまで（ポーリング型の場合）、またはプロバイダーが配信を確認するまで、サイト上のキューに保持されます。**WP Admin > POS > 設定 > クラウド印刷**で、プリンター一覧の下にキューが表示されます。

- プリンター別、またはステータス別（**待機中**、**印刷中**、**印刷済み**、**失敗**、**キャンセル済み**）に**絞り込み**でき、件数がリアルタイムで表示されます。
- 各行にはレシートの**待機**時間と、印刷対象の WooCommerce **注文**へのリンクが表示されます。
- 待機中のジョブは、個別、複数選択、またはプリンター単位でまとめて**キャンセル**できます。**再試行**を使うと、失敗したジョブが再びキューに追加されます。

待機中のジョブがあるのにプリンターが数分以上取得していない場合は、**警告バナー**にプリンター名、滞留しているレシートの件数と経過時間が表示され、**すべてキャンセル**を選択できます。プリンターが未接続の間に、気づかないままジョブがたまり続けることはありません。

## テスト印刷と接続ステータス {#status}

各プリンターカードの**テスト印刷**ボタンで、簡単な診断用データを送信できます。実際の注文に使う前に、プリンターに接続できることと、印刷形式が正しいことを確認できます。

カードには、現在のステータスも表示されます。

| プロバイダー | ステータス | 意味 |
|----------|--------|---------|
| **Star CloudPRNT / Epson** | **待機中** | プリンターからまだ接続がありません。WCPOS は最初のポーリングを待っています。 |
| **Star CloudPRNT / Epson** | **接続済み** | プリンターが最近 WCPOS をポーリングし、ジョブを取得しています。 |
| **Star Online** | **オンライン** | Star Online が、選択したデバイスは利用可能と報告しています。 |
| **Star Online** | **オフライン** | Star Online が、選択したデバイスは利用不可と報告しています。 |
| **Star Online** | **不明** | WCPOS が Star Online からデバイスのステータスを確認できませんでした。 |
| **PrintNode** | **オンライン** | PrintNode サービスが、クライアントとプリンターは利用可能と報告しています。 |
| **PrintNode** | **オフライン** | PrintNode が、クライアントまたはプリンターは利用不可と報告しています。 |

## トラブルシューティング {#troubleshooting}

<Accordion>
  <AccordionItem question="プリンターが待機中のままになる">

  ポーリング型プリンターが**待機中**のままの場合、WCPOS への接続に一度も成功していません。次の点を確認してください。

  - プリンターのファームウェアに設定した**ポーリング URL とトークン**が、WCPOS の生成した値と完全に一致していること。一文字でも異なると、すべてのポーリングが拒否されます。不確かな場合は、WCPOS でトークンを再生成して入力し直してください。
  - プリンターがインターネット経由で実際に**サイトにアクセス**できること（DNS が正しい、ファイアウォールが外向きの HTTPS をブロックしていない、店舗サイトの SSL 証明書が有効）。
  - プリンターの CloudPRNT / Server Direct Print 設定で**ポーリングが有効**になっており、適切な間隔が設定されていること。設定変更後はプリンターを再起動してください。
  - 詳細設定の開閉セクションにある**サイト直結の URL** を入力しても接続できない場合は、標準の **cloudprint.wcpos.com** の URL に切り替えてください。多くのプリンターは最新のホスティングと安全な接続を確立できません。[リレーはまさにこの問題を解決します](#relay)。

  </AccordionItem>

  <AccordionItem question="プリンターの URL が cloudprint.wcpos.com を指しているのはなぜですか？">

  これは [WCPOS Cloud Print](#relay) です。プリンターのファームウェアが確立できる接続を提供し、印刷ジョブを店舗サイトへ中継する無料のリレーです。自動的に有効になり、ジョブが保存されることはありません。直接接続を使いたい場合は、プリンターの**詳細設定**の開閉セクションから、いつでもサイト直結の URL を確認できます。

  </AccordionItem>

  <AccordionItem question="リレーの導入前にプリンターを設定しました。変更は必要ですか？">

  いいえ。プリンターの設定に保存済みの URL は、そのまま使用できます。ただし、プリンターが**待機中のまま**の場合は、ファームウェアがホスティングに直接接続できない可能性があります。プリンターカードの**設定 &amp; トークン**を開いてトークンを再生成し、新しい **cloudprint.wcpos.com** の URL とトークンをプリンターの設定に入力してください。

  </AccordionItem>

  <AccordionItem question="Star Online で API キーの認証エラーやアクセス禁止が表示される">

  Star Online では、**認証**と**権限**が分かれています。

  - **401 / 認証失敗**は、API キー自体が受け付けられなかったことを意味します。キーを正しくコピーしたか、失効していないか、想定する Star Online アカウントとリージョンのキーであるかを確認してください。
  - **403 / 禁止**は、API キーは受け付けられたものの、要求した操作の権限がないことを意味します。stario.online でキーを編集し、必要な権限を有効にしてください。特に、**デバイスを取得**には **EnumDevices**、印刷には **PrintToDevice** が必要です。

  **デバイスを取得**が成功してもプリンターが表示されない場合は、stario.online の**デバイスグループ**ページを確認してください。グループには接続済みのデバイスが少なくとも一台必要で、WCPOS の CloudPRNT URL も同じグループを指している必要があります。

  </AccordionItem>

  <AccordionItem question="PrintNode のジョブが印刷されない">

  ジョブは PrintNode に届いていますが、プリンターから出力されていません。次の点を確認してください。

  - プリンターに接続されたコンピューターで、**PrintNode デスクトップクライアントが起動しており、オンラインである**こと。コンピューターがスリープ中、またはクライアントが終了していると印刷されません。
  - WCPOS で**正しいプリンター**を選択していること。名前は、クライアントが報告するプリンター名と一致する必要があります。
  - **API キーが有効**で、失効していないこと。PrintNode でプリンターがオフラインと表示される場合は、キーを入力し直してください。

  </AccordionItem>

  <AccordionItem question="Star または Epson プリンターでテンプレートを選択できない">

  Star と Epson のクラウドプリンターでは、レシートを ESC/POS または ePOS-Print コマンドにレンダリングする必要があるため、**サーマル**テンプレートのみ使用できます。HTML やフルページのテンプレートはこれらの形式で表現できないため、この種類のプリンターでは非表示になります。

  [サーマルテンプレート](/1.x/receipts/thermal-templates)を選択するか、**PrintNode** プリンターを使用してください。PrintNode は PDF にレンダリングするため、どのテンプレートでも印刷できます。

  </AccordionItem>
</Accordion>
