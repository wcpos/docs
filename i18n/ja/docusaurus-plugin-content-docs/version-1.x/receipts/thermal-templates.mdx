サーマルテンプレートはXML形式を使用し、同じテンプレートから画面プレビューとESC/POSプリンターコマンドの両方を生成します。データバインディングには[HTMLテンプレート](/1.x/receipts/html-templates)と同じ `{{variable}}` プレースホルダーを使用します。

[プリンター設定](/1.x/hardware/printers)でレシートプリンターを接続している場合は、このエンジンを選択してください。

## XML要素 {#xml-elements}

### ルート要素 {#root-element}

すべてのサーマルテンプレートは、 `<receipt>` ルート要素で始まります。

```xml
<receipt paper-width="48">
  <!-- 48 characters = 80mm paper -->
  <!-- 32 characters = 58mm paper -->
</receipt>
```

### テキストと書式設定 {#text-and-formatting}

```xml
<text>Plain text</text>
<bold>Bold text</bold>
<underline>Underlined text</underline>
<invert>Inverted (white on black)</invert>
```

### 配置 {#alignment}

```xml
<align mode="left">Left aligned</align>
<align mode="center">Centered</align>
<align mode="right">Right aligned</align>
```

### 文字サイズ {#text-size}

テキストの幅と高さを個別に拡大します。

```xml
<size width="2" height="2">Double-size text</size>
<size width="2" height="1">Wide text</size>
<size width="1" height="2">Tall text</size>
```

### 表形式のレイアウト {#tabular-layout}

ロゴを埋め込むには、 `<row>` と `<col>` を使用します。

```xml
<row>
  <col width="24">Item name</col>
  <col width="8" align="right">Qty</col>
  <col width="16" align="right">Price</col>
</row>
```

列幅の単位は文字数です。残りの幅を埋める可変幅の列には `width="*"` を使用します。これにより、用紙幅が異なってもテンプレートを変更せずに使えます。

```xml
<row>
  <col width="*">{{name}}</col>
  <col width="12" align="right">{{line_total_display}}</col>
</row>
```

### 区切りと間隔 {#separators-and-spacing}

```xml
<line />                       <!-- Default single rule -->
<line style="double" />        <!-- Printer-native double rule -->
<line style="dashed" />        <!-- Character dashes across the width -->
<line style="dotted" />        <!-- Character dots across the width -->
<feed lines="2" />             <!-- Blank lines -->
```

`<line/>` （または `style="single"`）と `style="double"` は、プリンター標準の罫線を印刷します。 `dashed` と `dotted` は、現在の列幅全体に文字による区切り線を印刷します。サーマルプレビューのスクリーンショットでも区切り線を残したい場合に便利です。

### プリンターコマンド {#printer-commands}

```xml
<cut />              <!-- Full paper cut -->
<cut mode="partial" /> <!-- Partial cut (leaves a tab) -->
<drawer />           <!-- Open cash drawer -->
```

### バーコードとQRコード {#barcodes-and-qr-codes}

```xml
<barcode type="code128" height="40">{{order.number}}</barcode>
<barcode type="qrcode" scale="3">{{fiscal.qr_payload}}</barcode>
```

## 例：シンプルな80mmレシート {#example-simple-80mm-receipt}

```xml
<receipt paper-width="48">
  <align mode="center">
    <size width="2" height="2">{{store.name}}</size>
  </align>
  <feed lines="1" />
  <align mode="center">
    <text>{{store.address_1}}</text>
    <text>{{store.city}} {{store.state}} {{store.postcode}}</text>
    {{#store.phone}}<text>{{store.phone}}</text>{{/store.phone}}
  </align>
  <line />

  <text>Order: #{{order.number}}</text>
  <text>Date: {{order.created.datetime}}</text>
  {{#cashier.name}}<text>Cashier: {{cashier.name}}</text>{{/cashier.name}}
  <line />

  <!-- Column headers -->
  <row>
    <col width="*"><bold>Item</bold></col>
    <col width="4" align="right"><bold>Qty</bold></col>
    <col width="12" align="right"><bold>Total</bold></col>
  </row>
  <line />

  <!-- Line items -->
  {{#lines}}
  <row>
    <col width="*">{{name}}</col>
    <col width="4" align="right">{{qty}}</col>
    <col width="12" align="right">{{line_total_display}}</col>
  </row>
  {{/lines}}

  <line />

  <!-- Totals -->
  <row>
    <col width="*">Subtotal</col>
    <col width="16" align="right">{{totals.subtotal_display}}</col>
  </row>
  {{#totals.tax_total}}
  <row>
    <col width="*">Tax</col>
    <col width="16" align="right">{{totals.tax_total_display}}</col>
  </row>
  {{/totals.tax_total}}
  <row>
    <col width="*"><bold>TOTAL</bold></col>
    <col width="16" align="right"><bold>{{totals.total_display}}</bold></col>
  </row>

  <line />

  {{#payments}}
  <row>
    <col width="*">{{method_title}}</col>
    <col width="16" align="right">{{amount_display}}</col>
  </row>
  {{#tendered}}
  <row>
    <col width="*">Tendered</col>
    <col width="16" align="right">{{tendered_display}}</col>
  </row>
  <row>
    <col width="*">Change</col>
    <col width="16" align="right">{{change_display}}</col>
  </row>
  {{/tendered}}
  {{/payments}}

  <feed lines="2" />
  <align mode="center">
    <text>Thank you for your purchase!</text>
  </align>
  <feed lines="3" />
  <cut />
</receipt>
```

## スター幅の列 {#star-width-columns}

`width="*"` 機能を使うと、用紙幅に依存しないテンプレートを作成できます。特定の用紙サイズに合わせて列幅を固定するのではなく、伸縮させる列に `*` を指定します。

```xml
<!-- Works on 58mm (32 char) AND 80mm (48 char) printers -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

80mmプリンター（48文字）では商品名に38文字、58mmプリンター（32文字）では22文字が割り当てられます。固定列の幅はどちらでも同じです。

:::warning 旧StarPRNT固定レイアウトアダプターは削除されました
旧StarPRNTの **固定レイアウト出力アダプター** はv1.10で削除されました。これに依存するテンプレートは、現在のサーマルテンプレート（このページで説明するXMLエンジン）に切り替えてください。共通のサーマルレイアウトを通じてStar出力を生成します。レイアウトの再作成には、 `<row>`/`<col>` と `width="*"` を使い、固定アダプターは使用しないでください。
:::

## テンプレートのプレビュー {#template-preview}

テンプレートエディターでは、編集中に **サーマルプレビューをリアルタイム表示** します。XMLをスタイル付きの等幅HTMLとして描画し、レシートの印刷イメージを再現します。変更は短い待ち時間の後に反映されます（300msのデバウンス処理）。

同じテンプレートからプレビューとESC/POSプリンター出力の両方が生成されるため、印刷専用テンプレートは不要です。バーコードとQRコードは、プレビューではインラインSVGとして、プリンターではネイティブのESC/POSコマンド（またはラスター画像）として描画されます。

## 作成時のヒントと注意点 {#authoring-tips-and-pitfalls}

サーマル印刷には、HTMLにはない注意点があります。作成時によく遭遇する問題を紹介します。

### スタイル付き見出しは `<text>` で囲んで改行する {#wrap-styled-headings-in-text-for-a-line-break}

スタイル付きコンテナの `<bold>`、 `<size>`、 `<underline>`、 `<align>` は、**それだけでは改行を出力しません**。改行するのは、 `<text>` とブロック要素（`<line/>`、 `<row>`、 `<feed>`）だけです。

```xml
<!-- ❌ Bug: the heading runs together with whatever follows -->
<bold>{{i18n.bill_to}}</bold>
{{customer.name}}

<!-- ✅ Fix: wrap the inner content in <text> -->
<bold><text>{{i18n.bill_to}}</text></bold>
<text>{{customer.name}}</text>
```

同梱の80mmギャラリーテンプレートでは、すべての見出しにこのパターンを使用しています。

### 狭い行では `<size width="2">` を避ける {#avoid-size-width2-inside-narrow-rows}

横幅を倍にしたテキストは、**実質的に倍の文字数を消費します**。80mmプリンターに収まる見出しでも、一般的な42桁の80mmプリンターでははみ出すことがあり、58mm用紙では16文字しか入りません。

大きな合計金額やキッチンの注文番号など、目立たせたい値は独立した拡大行として出力し、複数列の `<row>`の中には入れないでください。

```xml
<!-- For store names, prefer normal-width, double-height -->
<bold><size height="2"><text>{{store.name}}</text></size></bold>

<!-- For a bold total, put it on its own line above the row -->
<align mode="right">
  <bold><size height="2"><text>{{totals.total_display}}</text></size></bold>
</align>
```

### 用紙幅に依存しないレイアウトには `width="*"` を使う {#use-width-for-paper-width-agnostic-layouts}

`width="*"`（スター）列は、固定幅の列を配置した後に残る幅を埋めます。同じテンプレートを変更せずに、32桁（58mm）、42桁（標準80mm）、48桁（幅広80mm）のプリンターで正しく描画できます。

```xml
<!-- Works on 58mm AND 80mm without changes -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

数値で幅を固定する場合は、48ではなく **合計42に収めてください**。合計48の行は、一般的な42桁の80mmプリンターで折り返されます。

### `<align>` ブロック内の中央揃えのスタイル付き見出し {#centred-styled-headings-inside-align-blocks}

配置を `<align mode="center">` （または `right`）にしたブロック内で、スタイル付き見出しの要素（ `<bold>`、 `<size>`、 `<underline>`、 `<invert>` ）を直接配置すると、 `<align>` 内でその後に別の行が続く場合、見出しは自動的に独立した行として閉じられます。中央揃えの住所行の上に、拡大した店舗名を中央揃えで配置した場合も、明示的に `<text>` で囲んでください。

配置ブロックの外では、引き続き `<text>` で囲んでください。

### ESC/POSの句読点の正規化 {#escpos-punctuation-normalisation}

プリンター言語がESC/POSの場合、エンコーダーは書き込み前に組版用の句読点を安全なASCII文字に正規化します。

- enダッシュ、emダッシュ、数字幅ダッシュ、Unicodeのマイナス記号 → `-`
- 曲線型の引用符 → 直線型の引用符
- 改行しないスペース → 通常のスペース

そのため、Unicodeフォントがないプリンターでも `Mon–Sat 9:00–18:00` や `"open"` が正しく印刷されます。Starプリンター（`star-line` / `star-prnt`）では元の文字表記が **保持される** ため、プリンターのフォントで対応している文字を使用してください。

### 非ラテン文字と右から左に書く文字 {#non-latin-and-rtl-scripts}

サーマルプリンターは内蔵フォントとコードページを使って印刷します。そのため、アラビア語、ヘブライ語、ペルシア語、ウルドゥー語などの非ラテン文字を正しく印刷するには、対応するコードページ（例：アラビア語ではCP864 / Windows-1256）をプリンターに設定する必要があります。設定しないと、文字が空白になったり文字化けしたりします。

これらの文字を確実に印刷するには、**レシート全体をラスター化** を使用します。レシート全体を画像として描画するため、プリンター内蔵フォントに関係なく、デザインどおりに印刷できます。ラスターモードを有効にする方法は[プリンター設定](/1.x/hardware/printers)を参照してください。

:::note サーマルプリンターにはサーマルテンプレートが必要です
サーマルプリンターでは、全ページの **HTML** テンプレートを印刷できません。印刷ジョブをESC/POSまたはStarコマンドに変換する必要がありますが、HTMLではそれらを表現できないためです。サーマルプリンターにはサーマルテンプレートを使用してください。A4/Letterの全ページHTMLは、システム/PDFプリンター、または[PrintNode](/1.x/receipts/cloud-printing#setup-printnode)経由で印刷します。
:::

### ロゴと画像 {#logos-and-images}

ロゴを埋め込むには、 `<image>` を使用します。

```xml
<align mode="center">
  <image src="data:image/png;base64,..." />
</align>
```

WCPOSはクライアント側で画像をラスター化します。画像のデコード、透明部分の白色への合成、プリンターのドット数上限に合わせたサイズ変更、モノクロ変換（ロゴにはAtkinsonディザリング、バーコードにはしきい値処理）を行ってから、ESC/POSまたはStarの画像コマンドを送信します。

- **ドット数の上限**：58mmでは幅384ドット、80mmでは幅576ドットです。
- **利用可能なソース**：`data:image/png` と `data:image/jpeg` のデータURL、`http(s)` の絶対URL、同一オリジンのルート相対パスです。プロトコル相対の `//`、バックスラッシュ、パーセントエンコードされた `..` によるトラバーサルは拒否されます。
- **推奨形式**：透明または白背景の高コントラストPNGです。JPEGも使えますが、圧縮による乱れがノイズとして印刷されることがあります。
- サーマルプリンターへの直接出力では、**SVGはまだサポートされていません**。

### ヒント {#tips}

- **ギャラリーテンプレートから始める** — ギャラリーのサーマルテンプレートは上記のすべてのパターンを使用し、実機プリンターで検証されています。
- 店舗で異なるプリンターを使う場合は、**両方の用紙サイズをテスト** するか、`width="*"` の列を使用してください。
- 通貨には **`_display` フィールドを使用** してください。すでにロケールに対応しています。
- **シンプルに保つ** — サーマル印刷は、設計上HTMLより書式設定の手段が少なくなっています。 `<row>` + `<col width="*">` を中心に使い、プリンターに処理を任せてください。
