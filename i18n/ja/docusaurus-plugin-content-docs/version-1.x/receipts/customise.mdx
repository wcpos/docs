レシートの見た目を変更する方法は3つあります。必要なことができる、最も簡単な方法を選んでください。大半の店舗では、最初の方法だけで十分です。

## カスタマイズする3つの方法 {#three-ways-to-customise}

<FeatureGrid>
  <FeatureCard icon="grid" title="1. 別のテンプレートを選ぶ">
    ギャラリーにある既成のテンプレートを使用します。**コードは一切不要です。** 最適な用途：レイアウトの変更、価格の非表示、A4インボイス、キッチンチケット。
  </FeatureCard>
  <FeatureCard icon="sparkles" title="2. AIに調整を依頼する">
    テンプレートをChatGPTまたはClaudeに貼り付けて、変更したい内容を説明します。**コーディングスキルは不要です** — 自然な言葉で説明するだけです。最適な用途：文言、色、配置などの小さな調整。
  </FeatureCard>
  <FeatureCard icon="code" title="3. 直接編集する">
    アプリ内エディターでテンプレートを直接変更できます。最適な用途：細かい調整が必要な場合、またはHTMLの知識がある場合。
  </FeatureCard>
</FeatureGrid>

3つの方法はすべて、**WP Admin → POS → テンプレート**から始めます。ページは2つの部分に分かれています。上部の **マイテンプレート** には現在使用中のテンプレートが、下部の **テンプレートギャラリー** にはスターター用のライブラリが表示されます。

## オプション 1 — 別のテンプレートを選ぶ {#option-1--pick-a-different-template}

最も簡単な方法で、ほとんどのニーズに対応できます。

<Steps>
  <StepCard number="1" title="テンプレートギャラリーを開く">

WP Admin で **POS → テンプレート** に移動します。*マイテンプレート* を過ぎて**テンプレートギャラリー**セクションまでスクロールしてください。ここがスターターライブラリです。

  </StepCard>
  <StepCard number="2" title="閲覧とプレビュー">

**カテゴリ**（レシート、請求書、ギフトレシート、キッチンチケット、見積書 / 発注書）、**フォーマット**（ブラウザー印刷用 HTML、サーマルプリンター用サーマル）、または**方向**（左から右、右から左）で絞り込めます。カードのサムネイル、またはフッターの**プレビュー**リンクをクリックすると、店舗の実データを使ったライブプレビューが開きます。

  </StepCard>
  <StepCard number="3" title="使用する" isLast>

カード上の**テンプレートを使用**をクリックします。WCPOS が編集可能なコピーを作成し、ページ上部の**マイテンプレート**に追加します。行の**有効**トグルをオンにするとレシートで使用が開始されます。行のグリップハンドルをドラッグして並べ替えることもできます。複数のテンプレートを同時に有効にでき、レジでキャッシャーが選択できます。

  </StepCard>
</Steps>

:::tip 「テンプレートを使用」は既存のテンプレートを置き換えません
**テンプレートを使用**をクリックすると、常に新しいコピーが作成されます。元のギャラリーテンプレートはそのまま残るため、いつでも別の出発点を選び直すことができます。複数のレシートテンプレートが有効になっている場合、レシート画面にドロップダウンが表示され、キャッシャーがその場で切り替えることができます。
:::

### 同梱テンプレート {#the-bundled-templates}

| テンプレート | 形式 | 用途 |
|---|---|---|
| **標準レシート** | HTML | デフォルト — ロゴ、商品、合計、支払い。ほとんどの店舗に対応 |
| **標準レシート（RTL）** | HTML | 標準と同内容で、アラビア語／ヘブライ語／ペルシア語／ウルドゥー語向けにミラー表示 |
| **ミニマル／モダン** | HTML | 標準と同じ情報を、より少ない縦幅にまとめたレイアウト |
| **詳細レシート** | HTML | 完全な税務インボイス — SKU列、単価、税率別内訳、住所を含む |
| **ギフトレシート** | HTML | 商品のみ — 価格非表示。ギフトメッセージと返品ポリシーを含む |
| **インボイス** | HTML | A4／レター用フルページインボイス。未払い注文には「支払い方法」パネルを追加 |
| **納品書** | HTML | 倉庫用の付属書類 — 商品＋数量、配送先、価格なし |
| **見積書** | HTML | 価格と条件を記載した販売前書類 — 支払いセクションなし |
| **ナローレシート** | HTML | 狭い用紙またはHTML対応サーマルプリンター向けの等幅レシート |
| **シンプルサーマルレシート（58mm）** | 感熱 | すっきりとした58mmサーマルレイアウト |
| **シンプル感熱レシート（80mm）** | 感熱 | 最も一般的な80mm感熱レイアウト |
| **シンプル感熱レシート 80mm（RTL）** | 感熱 | 80mm用のRTL対応版。アラビア語コードページ対応のプリンターが必要 |
| **詳細感熱レシート（58mm / 80mm）** | 感熱 | 税内訳、住所、返金、支払い、利用規約、バーコードを追加 |
| **キッチンチケット** | 感熱 | 商品のみ、大きなフォント、価格なし — 調理場向け |

同梱テンプレートの多くは**店舗の税設定に自動的に対応します** — 税込店舗では税込価格と「税込」の行が表示され、税抜店舗では税抜価格に税額が別行として追加されます。**詳細**テンプレートファミリーは設定に関わらず、常に完全な税内訳を表示します。

### WP Overnightの請求書・納品書テンプレート {#wp-overnight-invoice-and-packing-slip-templates}

WP Overnightの[PDF Invoices & Packing Slips for WooCommerce](https://wordpress.org/plugins/woocommerce-pdf-invoices-packing-slips/)もサイトで使用している場合、WCPOSは **マイテンプレート** に2つのテンプレートを自動的に追加します。

| テンプレート | 形式 | 用途 |
|---|---|---|
| **請求書（WP Overnight）** | サーバー側でレンダリングする HTML | POS 注文に、WP Overnight で設定した請求書を使用 |
| **納品書（WP Overnight）** | サーバー側でレンダリングする HTML | POS 注文に、WP Overnight で設定した納品書を使用 |

これらのテンプレートは、WCPOS 内蔵の請求書や納品書のレイアウトをコピーするものではありません。WP Overnight に POS 注文のドキュメントのレンダリングを依頼します。そのため、既存の請求書番号、ブランド情報、法務・税務項目、WP Overnight のテンプレートのカスタマイズを、オンライン注文と店舗での注文の両方で統一できます。

これらは WP Overnight プラグインが有効な場合にのみ表示されます。出力は個別の PDF ダウンロードではなく、WCPOS の印刷画面に HTML として表示されます。ドキュメントはサーバー側でレンダリングされるため、これらのテンプレートを印刷するには POS がサイトに接続されている必要があります。オフライン印刷には、同梱の HTML テンプレートまたはサーマルテンプレートを使用してください。

## 店舗ごとの割り当て {#per-store-assignments}

複数の[店舗](/1.x/stores)がある場合（Pro）、各店舗はサイト全体のデフォルトとは別に、**独自のテンプレート選択と並び順**を設定できます。近くのカフェでは別のロゴと住所を入れた小型サーマルレシートを、倉庫では納品書を、本店では標準レシートを使うなど、すべて同じテンプレートギャラリーから選択できます。

**WP Admin → POS → 店舗**から、設定したい店舗を開きます。**店舗の編集**ページの**レシートテンプレート**セクションに、*「店舗固有のレシートテンプレート」*トグルがあります。

- **トグルオフ** *（デフォルト）* — メインの **POS → テンプレート**ページで設定した、サイト全体のテンプレート一覧を店舗に引き継ぎます。
- **トグルオン** — サイト全体のデフォルトとは別に、店舗独自のテンプレートと並び順を設定できます。ドラッグハンドルによる並べ替えも同じように使えます。

同じ店舗の編集ページで、各店舗の**レターヘッド**も設定します。ロゴ、住所、連絡先情報のほか、*レシートメッセージ*ブロックの結びの言葉、返品ポリシー、フッターが含まれます。同梱テンプレートは店舗ごとのこれらの項目を参照するため、同じ「標準レシート」テンプレートでも、店舗ごとに異なるブランド情報を表示できます。

レジ係が店舗にサインインすると、その店舗で有効なテンプレートだけがレシートのドロップダウンに表示されます。

:::tip サイト全体と店舗ごとの設定
WP Admin の**テンプレート**ページでは、サイト全体のデフォルトを設定します。店舗ごとの上書き設定を使うと、同じテンプレート（例：標準レシート）に店舗ごとに異なるブランド情報を表示したり、ある店舗だけ別のレイアウトを使ったりできます。すべての店舗で同じテンプレートを使う場合は、店舗ごとの割り当てを空のままにすれば、サイト全体のデフォルトが適用されます。
:::

## オプション 2 — AI に調整を依頼する {#option-2--ask-ai-to-tweak-it}

ギャラリーのテンプレートが希望に近いものの少し調整したい場合は、AI アシスタントに依頼すれば数分で変更できます。HTML の知識は不要です。

<Steps>
  <StepCard number="1" title="テンプレートをコピーする">

**WP Admin → POS → テンプレート**でベースにしたいテンプレートを開き、エディター内をクリックして左側のテキストをすべて選択します（Ctrl/Cmd + A）。選択したテキストをコピーしてください。

  </StepCard>
  <StepCard number="2" title="ChatGPT または Claude に貼り付ける">

[ChatGPT](https://chat.openai.com)または[Claude](https://claude.ai)を開きます。テンプレートを貼り付けて、変更したい内容をわかりやすい言葉で記述します：

  </StepCard>
  <StepCard number="3" title="変更内容を説明する">

変更したい内容を AI に具体的に伝えます。次のような例が効果的です。

- *「店舗名を大きくして中央揃えにしてください。」*
- *「下部にイタリック体でお礼のメッセージを追加してください。」*
- *「顧客名を非表示にしてください。代わりに注文番号の下に電話番号を追加してください。」*
- *「バーコードを返品ページへのリンク付き QR コードに変更してください。」*
- *「店舗名の下に『1987年創業の家族経営店』というキャッチフレーズを追加してください。」*

AI が修正したテンプレートを返します。

  </StepCard>
  <StepCard number="4" title="貼り付けて戻す" isLast>

AI の応答をコピーします。WCPOS のテンプレートエディターに戻り、すべてを選択（Ctrl/Cmd + A）して新しい内容を貼り付け、**更新**をクリックします。右側のプレビューが更新され、変更結果を確認できます。意図した表示にならない場合は、問題点を説明して AI に修正を依頼してください。

  </StepCard>
</Steps>

:::tip ベストプラクティス
ギャラリーで**テンプレートを使用**をクリックするたびに、編集可能な新しいコピーが作成され、元のテンプレートはそのまま残ります。試行錯誤する場合は、同じギャラリーテンプレートを複数回使用できます。コピーの名前を*（レシート v1、レシート v2）*のように変更し、切り替えながら選んでください。
:::

:::info 変数について
`{{store.name}}` や `{{order.number}}` のような部分は、実際のデータが入る**プレースホルダー**です。AI がこれらを理解するので、ご自身で理解する必要はありません。利用できるすべてのプレースホルダーについては、[レシートデータリファレンス](/1.x/receipts/receipt-data)を参照してください。
:::

## オプション 3 — 手動で編集する {#option-3--edit-it-by-hand}

HTML の知識が少しある場合や、開発者と作業している場合は、アプリ内エディターでテンプレートを直接編集できます。エディターには、ライブプレビュー、シンタックスハイライト、検索可能なフィールドピッカー、元に戻す／やり直し、検索と置換の機能があります。

エンジンを選択してください。

- **[HTML テンプレート](/1.x/receipts/html-templates)** — Mustache 形式の `{{variable}}` プレースホルダーを使用します。クライアント側でレンダリングされ、オフラインでも動作します。**ほとんどの店舗に推奨します。**
- **[サーマルテンプレート](/1.x/receipts/thermal-templates)** — ESC/POS サーマルプリンター用の XML です。同じテンプレートから画面プレビューとプリンター出力を生成します。
- **[レシートデータリファレンス](/1.x/receipts/receipt-data)** — 使用できるすべてのプレースホルダーをセクション別にまとめています。

:::note レガシー PHP テンプレート
以前、テーマ内の PHP ファイル(`yourtheme/woocommerce-pos/receipt.php`)でレシートを上書きしていた場合、その方法は引き続き使えます。現在はギャラリーで**レガシーPHPテンプレート**と表示され、新しいロジックレスエンジンやサーマルエンジンとともに利用できます。WP Overnight 連携も、外部のドキュメント API がサーバー上で HTML をレンダリングするため、サーバー側のレンダリングを使用します。新たにカスタマイズする場合は、ギャラリーまたはアプリ内エディターを使用してください。オフラインで動作し、ライブプレビューを利用でき、サーバーとの通信も不要です。
:::

## よくあるカスタマイズ {#common-customisations}

よく寄せられる質問に簡潔に回答します。

<Accordion>
  <AccordionItem question="店舗ロゴを追加するには？">

ロゴはテンプレート自体ではなく、店舗の設定から取得されます。**WP Admin > POS > 設定 > 店舗**に移動し、店舗を編集してロゴをアップロードしてください。ロゴを表示する同梱テンプレートには、自動的に反映されます。

テンプレート内でロゴの*表示位置*を変更するには、テンプレートを編集し、次の `{{#store.logo}}<img src="{{store.logo}}" ...>{{/store.logo}}` ブロックを目的の位置に移動してください。

  </AccordionItem>

  <AccordionItem question="フッターのテキスト（例：「お買い上げありがとうございます！」）を変更するには？">

方法は二つあります。

1. **最も簡単な方法** — **WP Admin > POS > 設定 > 店舗 > 店舗の詳細 > レシートのフッター / 個人メモ**で一度設定すれば、すべてのレシートに適用されます。同梱テンプレートには自動的に反映されます。フッターが未設定の場合は、*「お買い上げありがとうございます！」*のような親しみやすいデフォルトのメッセージが表示されます。
2. **単一のテンプレートで** — テンプレートを編集してフッターのテキストを直接置き換えます。`{{store.personal_notes}}` またはお礼の文言が直接書かれた行を探してください。

  </AccordionItem>

  <AccordionItem question="店舗名の下にキャッチフレーズやスローガンを追加するには？">

テンプレートを編集し、`{{store.name}}` の下に行を追加します。

```html
<div style="font-style: italic; color: #6b7280;">Family-owned since 1987</div>
```

サーマルテンプレートの場合：

```xml
<align mode="center"><text>Family-owned since 1987</text></align>
```

  </AccordionItem>

  <AccordionItem question="ギフトレシート用に価格を非表示にするには？">

ギャラリーの**ギフトレシート**カードで**テンプレートを使用**をクリックします。すべての価格と合計が非表示になり、商品、SKU、属性、ギフトメッセージはそのまま表示されます。編集は不要です。

価格を表示しないレシートを独自に作成したい場合は、任意のテンプレートをコピーし、`{{...total...}}`、`{{...price...}}`、`{{#totals}}...{{/totals}}` のブロックを削除してください。

  </AccordionItem>

  <AccordionItem question="バーコードを QR コードに変更するには？">

テンプレート内の `<barcode>` 要素を探し、 `type` 属性を変更します。

```html
<!-- Default: Code 128 barcode of the order number -->
<barcode type="code128">{{order.number}}</barcode>

<!-- Switch to a QR code -->
<barcode type="qrcode">{{order.number}}</barcode>

<!-- Or encode something else, like a returns URL -->
<barcode type="qrcode">https://example.com/returns?order={{order.number}}</barcode>
```

同じ `<barcode>` 構文が HTML テンプレートとサーマルテンプレートの両方で使えます。その他に対応している種類は、 `ean13`、 `ean8`、 `upca`、 `pdf417`のほか、 [bwip-js がサポートするすべての形式](https://github.com/metafloor/bwip-js/wiki/Supported-Barcode-Types)。

  </AccordionItem>

  <AccordionItem question="特定のプリンターに別のテンプレートを送信するには？">

POS アプリで **POS > 設定 > 印刷**に移動し、**レシートテンプレート**を確認します。有効なテンプレートごとに、横にプリンターのドロップダウンが表示されます。使用するプリンターを選ぶか、**自動**のままにします。

- **自動**はテンプレートとプリンターを自動的にマッチングします。サーマルテンプレートはサーマルプリンターに、HTML テンプレートはシステムの印刷ダイアログに送信されます。
- **特定のプリンター**を指定すると、自動設定を上書きして、そのテンプレートを常に指定したプリンターに送信します。
- 印刷時に、レシート画面のプリンタードロップダウンから上記の設定を上書きすることもできます。

ルーティングはデバイスごとに保存されるため、iPad やコンピューターごとに個別の設定が可能です。

  </AccordionItem>

  <AccordionItem question="編集してもレシートに古いバージョンが表示される">

テンプレート編集画面で WordPress の**更新**ボタンをクリックしてください。エディターは自動保存されないため、変更は更新を実行した時点でのみ保存されます。

**レガシー PHP テンプレート**の場合、エディター内のプレビューには入力中の内容ではなく*最後に保存されたバージョン*が表示されます。まず保存してから、プレビューを更新してください。

  </AccordionItem>

  <AccordionItem question="プレビューが空白、または「POS注文が見つかりません」と表示される">

これは、プレビューに実際の注文が必要な **Legacy PHPテンプレート** でのみ発生します。POSで注文を1件処理してください。$0のテスト販売でも構いません。するとプレビューが表示されます。

ロジックレス（HTML）テンプレートとサーマルテンプレートには常にサンプルデータが用意されているため、新規店舗でも問題なくプレビューできます。

  </AccordionItem>

  <AccordionItem question="ぐちゃぐちゃにしてしまった — 最初からやり直すには？">

安全策は3つあります。

1. エディターには**元に戻す**（Ctrl/Cmd + Z）機能があり、セッション中の変更を取り消せます。
2. 保存するたびに WordPress の**リビジョン**が作成されます。編集画面で**リビジョン**を開くと、過去のバージョンを比較・復元できます。
3. ギャラリーテンプレートから作成した場合は、*テンプレート一覧*でコピーの**削除**をクリックし、同じギャラリーカードの**テンプレートを使用**を再度クリックしてください。未編集の新しいコピーが作成されます。

  </AccordionItem>
</Accordion>

## サポートが必要な場合 {#when-to-ask-for-help}

- テンプレートエディターが読み込まれない、または保存内容が反映されない。
- レシートが一方のデバイスでは正常に印刷されるが、別のデバイスでは印刷されない。
- 特定の国（イタリア、ブラジル、スペインなど）の税務・法的要件に対応したレイアウトが必要な場合。通常は [WCPOS Pro](/1.x/getting-started/pro-license) または各国向けの連携機能で対応します。
