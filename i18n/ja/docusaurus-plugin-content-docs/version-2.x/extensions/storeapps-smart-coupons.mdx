**WCPOS StoreApps Smart Coupons**拡張機能を使うと、StoreAppsの[Smart Coupons](https://woocommerce.com/products/smart-coupons/)で発行したギフトカードなどのストアクレジットクーポンを、POSでの販売の支払いに充てられます。WCPOS Proでは、チェックアウトの支払いページでカードを受け付けると、正しい金額が差し引かれ、レシートに残高が表示されます。

:::warning 割引を追加ではストアクレジットを利用できません
カートの**割引を追加**でギフトカードを入力すると、**クーポンが見つかりません**と表示されます。代わりに、チェックアウトの**レガシー**タブで受け付けてください。[レジでギフトカードを受け付ける](#at-the-till)を参照してください。
:::

## レジでギフトカードを受け付ける {#at-the-till}

始める前に、管理者がStoreAppsのSmart Couponsを有効にし、[この拡張機能をインストール](#install)しておく必要があります。また、チェックアウトの[レガシータブ](../pos/checkout/legacy-tab.mdx)に支払い方法が必要です。このタブでは、クーポン入力欄のある店舗独自の支払いページが開きます。

1. カートに商品を入れ、**チェックアウト**を押して**レガシー**タブを開きます。チェックアウト内に店舗の支払いページが開きます。
2. **クーポンコード**にギフトカードのコードを入力し、**クーポンを適用**を押します。カードで支払える金額分だけ注文合計が減ります。
3. お客様が残額を支払う方法を選び、そのページで支払いを受け付けてから、**支払いを処理**を押します。
4. [レシートの表示内容](#receipt)の例のように、レシートのクーポン割引行に**ストアクレジット残高**があることを確認します。表示されない場合は、[問題が起きた場合](#goes-wrong)を参照してください。

**レガシー**タブに支払い方法がない場合、カードを受け付けるための支払いページがありません。通常どおり支払いを受け付け、ギフトカードは次回の購入時に使えるよう保管していただいてください。カードからは何も差し引かれていません。

## レシートの表示内容 {#receipt}

クーポン割引行の末尾には、レシート作成時点のカード残高が表示されます。説明が**ギフトカード**のストアクレジットクーポンは、**標準レシート**に次のように印刷されます。

> 割引 · ギフトカード — ストアクレジット残高: $61.50

チェックアウト時のレシートには、販売直後の残高が表示されます。レシートテンプレートに何かを追加する必要はありません。クーポンに説明がなくても、行の末尾に**ストアクレジット残高**が表示されます。その行の**割引**を**ギフトカード**に変えて印刷する方法は、[開発者向け](#developers)を参照してください。

## 主な機能 {#what-it-does}

StoreAppsはオンライン注文のギフトカード残高を管理しますが、単体ではPOSで支払われた注文を処理できません。POS注文にストアクレジットクーポンが含まれる場合、この拡張機能は次の処理を行います。

- **利用した金額だけを差し引きます。** 注文でカードからいくら利用したかを記録するため、StoreAppsはその金額を差し引き、残りをカードに残します。
- **注文の支払い時に残高を減らします。** クーポンを適用した時点では減らさず、二重に差し引くこともありません。
- **取り外したクーポンは処理対象から外します。** 支払い前にクーポンを取り外した場合、そのクーポンからは何も差し引かれません。
- **注文にメモを残します。** [注文メモ](#order-note)を参照してください。
- **レシートに残高を印刷します。** [レシートの表示内容](#receipt)を参照してください。

StoreApps Smart Couponsが無効の場合、この拡張機能は何も処理しません。

## 拡張機能をインストールする {#install}

管理者が**WP Admin**で一度インストールします。WCPOS Proでは**POS → 設定 → 拡張機能**から、無料プラグインではリリースファイルをアップロードしてインストールします。

<details>
<summary>WCPOS Proまたは無料プラグインでのインストール手順</summary>

:::note 始める前に
**WP Admin**に管理者としてログインできることと、サイトでStoreAppsのSmart Coupons（WooCommerce.comで販売）が有効になっていることが必要です。この拡張機能はそのプラグイン専用で、名前に「Smart Coupons」が含まれる他のプラグインでは動作しません。
:::

### WCPOS Proを使用する場合 {#install-pro}

1. **WP Admin**で、**POS → 設定 → 拡張機能**に移動します。
2. **WCPOS StoreApps Smart Coupons**を探し、**インストール**を押します。
3. **有効化**を押します。

更新と自動更新については、[拡張機能のインストール](./index.mdx#installing-an-extension)を参照してください。

### 無料プラグインを使用する場合 {#install-free}

拡張機能画面にはこの拡張機能が表示されますが、ボタンの使用にはProが必要です。代わりに、次の手順でインストールします。

1. 拡張機能の[最新リリース](https://github.com/wcpos/wcpos-storeapps-smart-coupons/releases/latest)から`wcpos-storeapps-smart-coupons.zip`をダウンロードします。
2. **WP Admin**で、**プラグイン → 新規プラグインを追加**に移動し、**プラグインのアップロード**を押します。
3. ダウンロードしたファイルを選択し、**今すぐインストール**を押します。
4. **プラグインを有効化**を押します。

</details>

その後の設定は不要です。WooCommerceで通常どおりストアクレジットクーポンやギフトカードを作成してください。

## 注文メモ {#order-note}

注文が支払われると、拡張機能が非公開のメモを1件追加します。スタッフは**WP Admin → WooCommerce → 注文**で注文を開くと確認できます。

> WCPOS用にStoreApps Smart Couponsのストアクレジットを記録しました: クーポンstore100で$38.50を利用。現在の残高: $61.50。

どのカードで支払ったか、いくら支払ったか、残高はいくらかを確認できます。メモは注文ごとに一度だけ追加されます。

## 払い戻しとキャンセル {#refunds}

この拡張機能はクレジットを戻しません。ストアクレジットで一部を支払った注文を払い戻しまたはキャンセルした場合、残高の扱いはStoreAppsが決めます。処理後に**WP Admin → マーケティング → クーポン**でクーポンの金額を確認してください。お客様に返すべき金額になっていない場合は、店舗管理者に相談してください。管理者はそこでクーポンの金額を変更できます。

## 問題が起きた場合 {#goes-wrong}

**割引を追加**からギフトカードを適用すると、**クーポンが見つかりません**と表示されます。WCPOS 2.0の割引を追加では、割引率指定、カート固定額、商品固定額のクーポンのみ適用できます。そのため、この拡張機能の有無にかかわらず、ストアクレジットクーポンでは**クーポンが見つかりません**と表示されます。代わりに[レガシータブの支払いページ](#at-the-till)を使用してください。

**販売後に残高が減りません。** **プラグイン**で**Smart Coupons**と**WCPOS StoreApps Smart Coupons**の両方が有効になっているか確認してください。差し引かれるのはクーポン適用時ではなく、注文の支払い時です。ストアクレジットのメモがない注文では、この拡張機能による差し引きは行われていません。

**レシートに残高が表示されません。** レジがオフラインの間に印刷したレシートには残高が表示されません。レジがオンラインに戻ってから再印刷してください。それでも表示されない場合、レシートテンプレートが割引行のラベルを印刷していません。[レシートデータ](../receipts/receipt-data.mdx#discounts)を参照してください。

<details>
<summary>開発者向け: 保存データとフック</summary>

<Anchor id="developers" />

この拡張機能はWCPOSのクーポンフィールドを追加しません。WooCommerceの注文メタデータとStoreApps独自の残高処理を通じて動作します。対象はPOS注文（`wcpos_is_pos_order()`で判定し、`created_via`が`woocommerce-pos`）と、種類が`smart_coupon`のクーポンのみです。

- **利用額。** `woocommerce_order_after_calculate_totals`で、StoreAppsがまだ書き込んでいない場合に、StoreAppsの注文メタデータ`smart_coupons_contribution`（クーポンコード → 利用額）と`wc_sc_environment`を書き込みます。未払いの注文から取り外されたクーポンの項目は削除します。
- **支払いページのクーポン入力欄。** このフォームは`WC_Order::apply_coupon()`への通常のフロントエンドPOSTであり、StoreAppsは注文コンテキストとして扱いません。`smart_coupon`行を含む未払いのPOS注文がRESTリクエスト外で再計算される際、拡張機能はRESTコンテキストであると通知し、StoreApps独自の注文割引処理を実行させます。
- **残高の差し引き。** POS注文は`pos-open`または`pos-partial`から支払い済みになりますが、StoreAppsは`pending`または`failed`からの移行時にしか残高を差し引きません。それ以外のステータスから支払い済みのステータスまたは`on-hold`に移行する`woocommerce_order_status_changed`で、StoreAppsの`WC_SC_Coupon_Process::update_smart_coupon_balance()`を呼び出します。このメソッドは各クーポン行に処理済みの印を付け、二重に差し引かないようにします。
- **注文メモ。** `processing`、`completed`または`on-hold`への移行時に、注文ごとに一度だけ追加します(`_wcpos_storeapps_smart_coupons_audit_note_added`)。
- **レシート。** WCPOSのレシート描画中に`woocommerce_coupon_get_description`をフィルタリングします。また、レシートデータのフィルターで`discounts`内のストアクレジット行に`gift_card: true`を追加し、その`label`の末尾に残高を付加します。これにより、テンプレートで次のように印刷できます。

```text
{{#discounts}}{{#gift_card}}Gift Card{{/gift_card}}{{^gift_card}}{{i18n.discount}}{{/gift_card}} · {{label}}{{/discounts}}
```

- **フック名。** バージョン0.2.3では、引き続き2.0より前の名前である`woocommerce_pos_receipt_data`、`woocommerce_pos_before_template_render`、`woocommerce_pos_after_template_render`にフックします。WCPOS 2.0は`wcpos_`名のフックの後にこれらも発火し、`WP_DEBUG`が有効な場合、WordPressはそれぞれの非推奨通知をログに記録します。[フックの命名](./index.mdx#hook-naming)を参照してください。

ソース: [github.com/wcpos/wcpos-storeapps-smart-coupons](https://github.com/wcpos/wcpos-storeapps-smart-coupons)。

</details>

:::info WCPOS Proを使用する場合
レジではレガシータブの支払いページでギフトカードを受け付け、**POS → 設定 → 拡張機能**から拡張機能のインストールと更新を行います。Proを使用しない場合は、前述のようにリリースファイルから手動でインストールしてください。
:::
