**WP管理画面:** `WP Admin → POS → Settings → Extensions`でインストールし、`WP Admin → POS → Stores`で店舗ごとに設定します。

WPMLは、商品の各翻訳を別々の商品として保存します。そのままではPOSにすべてが表示されるため、時計を検索すると英語版、フランス語版、ドイツ語版が並びます。無料の**WCPOS WPML**拡張機能は、POSに表示する言語を1つに絞り、各商品が1回だけ表示されるようにします。

レジ係が設定することはありません。最初のセクションで、レジ係の画面にどのような変化があるかを説明します。それ以降は店舗管理者向けの説明です。

## レジ係の画面に表示される内容 {#what-the-cashier-sees}

商品検索、商品グリッド、バリエーション商品の選択肢はすべて店舗の言語で表示され、実際の商品1点につき1つの商品が表示されます。レジ係の販売操作は変わりません。通常どおりカートに追加し、支払いを受け付け、レシートを印刷します。[チェックアウト](../pos/checkout/index.mdx)を参照してください。

## 拡張機能をインストールする {#install}

:::note 始める前に
サイトに[WPML](https://wpml.org/)を設定し、デフォルト言語を指定しておく必要があります。また、**WP Admin**に管理者としてログインできることが必要です。
:::

管理者が**WP Admin**で一度インストールします。店舗に別の言語を選択しない限り、商品にはWPMLの**デフォルト言語**が使われます。拡張機能を有効化したら、後述の[動作を確認する](#check)に従ってください。

### WCPOS Proを使用する場合 {#install-pro}

1. **POS → 設定 → 拡張機能**に移動します。
2. **WCPOS WPML**を探し、**インストール**を押します。インストールと有効化が一度に行われ、カードに**有効**と表示されます。代わりに**無効**と表示される場合は、**有効化**を押してください。

更新と自動更新については、[拡張機能のインストール](./index.mdx#installing-an-extension)を参照してください。

### 無料プラグインを使用する場合 {#install-free}

拡張機能画面にはこの拡張機能が表示されますが、ボタンの使用にはProが必要です。代わりに、次の手順でインストールします。

1. 拡張機能の[最新リリース](https://github.com/wcpos/wcpos-wpml/releases/latest)から`wcpos-wpml.zip`をダウンロードします。
2. **プラグイン → 新規プラグインを追加**に移動し、**プラグインのアップロード**を押します。
3. ダウンロードしたファイルを選択し、**今すぐインストール**を押します。
4. **プラグインを有効化**を押します。

### 動作を確認する {#check}

1. POSを開きます。商品パネル下部の **…件中…件を表示**の横にある [同期ボタン](../pos/product-panel/display-settings.mdx#footer) (<Icon name="arrow-rotate-right" />) を長押しし、**クリアして更新**を選択します。
2. 翻訳のある商品を検索します。WPMLのデフォルト言語、または後述の手順で店舗に選択した言語で、1回だけ表示されます。

引き続き2回または3回表示される場合は、[問題が起きた場合](#goes-wrong)を参照してください。

## 店舗の言語を選択する {#store-language}

WCPOS Proでは、[店舗](../stores/index.mdx)ごとに独自の言語で表示できます。同じサイトにフランス語の店舗と英語の店舗があっても、それぞれの言語の翻訳が表示されます。

:::note 言語ページの表示には3つの条件があります
WCPOS Proを使用していること、**WCPOS WPML**拡張機能が有効であること、WPMLが有効で少なくとも1つの言語が設定されていることが必要です。これらを満たさない場合、店舗のメニューに**言語**ページは表示されません。**WooCommerce Multilingual**がインストールされている場合は、バージョン4.11.0以降が必要です。
:::

1. **WP Admin**で、**POS → 店舗**に移動し、店舗名をクリックします。
2. 店舗のメニューで、**拡張機能**の**言語**を開きます。
3. **店舗の言語**で言語を選択します。一覧には、WPMLで有効にしたすべての言語が表示されます。**デフォルト言語**はWPMLのデフォルト設定に従います。選択は自動的に保存されます。
4. この店舗のPOSを開き、[動作を確認](#check)します。選択した言語で商品が1回だけ表示されます。

他の店舗の言語は変わりません。

### 商品の言語と画面の言語 {#product-and-screen-language}

店舗のメニューには、**言語**という名前の設定が2か所あります。

- **拡張機能 → 言語 → 店舗の言語**では、各商品のどの翻訳をPOSに表示するかを選択します。
- **通貨と言語 → 言語**では、POS画面とレシートの文言を選択します。[店舗の各ページを設定する](../stores/setup.mdx#store-pages)を参照してください。

:::tip
フランス語の店舗では、両方をフランス語に設定してください。
:::

## 問題が起きた場合 {#goes-wrong}

**各商品が引き続き2回または3回表示されます。** **プラグイン**で**WCPOS WPML**が有効になっていることと、WPMLにデフォルト言語が設定されていることを確認してください。**WooCommerce Multilingual**がインストールされている場合は、バージョン4.11.0以降が必要です。それより古いバージョンでは、拡張機能は自動的に無効になります。

**店舗のメニューの拡張機能に言語ページがありません。** このページの表示には、WCPOS Pro、この拡張機能の有効化、少なくとも1つの言語が設定されたWPMLの有効化が必要です。**WooCommerce Multilingual**がインストールされている場合は、バージョン4.11.0以降が必要です。

**POSのみ、またはオンラインのみの商品が、別の言語では意図しない場所に表示されます。** POSのみとオンラインのみの設定は商品ごとに保存されます。各翻訳は独立した商品なので、元の商品の設定は引き継がれません。各翻訳を開き、同じ表示設定を指定してください。[POS専用商品](../products/pos-only-products.mdx)を参照してください。

:::info WCPOS Proを使用する場合
店舗ごとに商品の言語を選択できます。Proを使用しない場合、店舗は1つで、WPMLのデフォルト言語を使用します。
:::

<details>
<summary>開発者向け: フィルターと保存データ</summary>

この拡張機能はPOSからの商品およびバリエーションのリクエストだけに作用し、商品クエリにWPMLの`lang`を追加します。他のWooCommerce RESTクライアントには影響しません。ログイン中のユーザーがリクエストで指定された店舗を使用できる場合は、その店舗から言語を取得し、それ以外の場合はWPMLのデフォルトを使用します。

- 店舗で選択した言語は、その店舗の`_wcpos_wpml_language`メタデータに保存されます。空の値はWPMLのデフォルト言語を意味します。
- `wcpos_wpml_resolved_language`は、1回のリクエストで使用する言語を変更します。
- `wcpos_wpml_default_language`は、デフォルト言語を変更します。
- `wcpos_wpml_is_supported`は、拡張機能の有効と無効を切り替えます。
- `wcpos_wpml_minimum_wpml_version`と`wcpos_wpml_minimum_wcml_version`は、動作に必要なWPMLとWooCommerce Multilingualの最低バージョンを設定します。WooCommerce Multilingualの最低バージョンは`4.11.0`で、WPMLはデフォルトでは指定されていません。

ソース: [github.com/wcpos/wcpos-wpml](https://github.com/wcpos/wcpos-wpml)。

</details>
