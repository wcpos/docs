Epsonの電源は入り、本体のWebページも開き、セルフテストでは印刷できるのに、POSから送ったものは何も出てきません。電源を入れ直しても変わりません。プリンターの**サーバーダイレクトプリント**という設定がオンになっていないか確認してください。

:::note まずWCPOSがこの機能を使用しているか確認してください
**設定 → 印刷**のプリンターの行に **Epsonサーバーダイレクトプリント · WCPOSで管理**と表示されている場合は、サーバーダイレクトプリントをオンのままにしてください。WCPOSの**クラウド印刷**は、この方式でレシートをプリンターに送信します。**プリンターを追加**で同じプリンターを再度追加しないでください。[クラウド印刷](../../receipts/cloud-printing.mdx#setup-polling)をご覧ください。
:::

このプリンターを初めて追加する場合や、その行に上記の表示がない場合は、[プリンターのWebページで設定を確認してください](#turn-it-off)。

## POSでの表示 {#what-you-see}

**設定 → 印刷 → プリンターを追加**でプリンターを追加すると、カードに**接続なし**と表示され、選択できません。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[302, 0], [0, 0], [136, -20], [161, 0]]} maxWidth={559} alt="アドレスを確認した後の「プリンターを追加」パネル。右上に「再スキャン」、その下にアドレスとEpsonの表示、「接続なし」のバッジが付いたプリンターカードがあり、さらに下に「IPアドレスを入力」「プリンターガイドを開く」があります">

1. **プリンターのカード** — アドレスとメーカーが表示されます。**接続なし**は、アプリが印刷する方法を見つけられなかったことを示し、そのカードは選択できません。
2. **再スキャン** — ネットワークを再検索します。サーバーダイレクトプリントをオフにした後に使用してください。
3. **IPアドレスを入力** — 指定したアドレスを直接確認します。[アドレスを手動で入力する](./setup-wizard.mdx#enter-address)をご覧ください。
4. **プリンターガイドを開く** — これらのプリンターの説明ページを開きます。

</JourneyShot>

次のような状態になることもあります。

- テストページの印刷後に**何も印刷されませんでした**と表示され、「プリンターがジョブを保留しています。電源を入れ直してから、もう一度お試しください。」と案内されます。再起動後も同じ表示が出る場合は、サーバーダイレクトプリントがオンか確認してください。オフの場合は、POSからの印刷を妨げるもう1つのEpson設定である[Epsonのセキュア印刷](./secure-printing.mdx)をご覧ください。
- 保存済みのプリンターで**テスト印刷**が失敗し、すべてのレシート印刷も失敗します。

## 原因 {#why-it-happens}

**サーバーダイレクトプリント**がオンの場合、プリンターはサーバーからジョブを取得します。オンの間は、ネットワーク経由で直接送られてきたジョブを拒否します。**プリンターを追加**で追加したネットワークプリンターにPOSが印刷する際は、この直接送信の方式を使います。Webページは引き続き動作するため、プリンターは正常に見えます。設定は保存されているため、再起動しても解除されません。

自分でオンにしていなくても、以前のセットアップ、キッチンやオンライン注文のサービス、別のレジなどによってオンになった可能性があります。

## オフにする {#turn-it-off}

:::warning 別のシステムがこの機能を必要としている場合があります
キッチンディスプレイやオンライン注文サービスがサーバーダイレクトプリントでこのEpsonに印刷している場合、オフにするとそのサービスから印刷できなくなります。このプリンターを使えるのはどちらか一方だけです。POS専用のプリンターを用意するか、そのサービスを別のプリンターに切り替えてください。
:::

プリンターと同じネットワーク上のコンピューターまたはタブレットから、プリンター本体のWebページで操作します。

1. `https://`の後にプリンターのアドレスを付けて開きます。たとえば`https://192.168.1.100`です。証明書の警告を承認して進んでください。アドレスはプリンターのステータスシートに記載されています。[プリンターのアドレスを調べる](./network-address.mdx)をご覧ください。
2. **管理者ログイン**を押します。最近の機種では、変更されていない限り、プリンター底面のラベルに記載された**シリアル番号**がパスワードです。
3. メニューで**サーバーダイレクトプリント**を探します。場所は機種やファームウェアによって異なります。TM-iモデルでは**Webサービス設定 → ダイレクトプリント**にあり、ファームウェア3.x以前では**設定 → ダイレクトプリント**にあります。それ以外の機種では、メニューまたは機種のマニュアルで確認してください。
4. すでに**無効**になっている場合は、そのままにして[Epsonのセキュア印刷](./secure-printing.mdx)の手順に従ってください。それ以外の場合は、**無効**に設定して保存し、以下に進みます。
5. プリンターの再起動を待つか、電源を切って10秒待ってから入れ直します。
6. POSに戻り、プリンターをテストします。
   - **プリンターを追加中の場合：** **再スキャン**または **IPアドレスを入力**を押します。カードに**準備完了**と表示されたら選択し、**テストページを印刷**を押します。
   - **プリンターを保存済みの場合：** **設定 → 印刷**のプリンターの行にある**テスト印刷**を押します。

## 解決しない場合 {#still-stuck}

**セットアップレポートをコピー**を押し、問い合わせメッセージに貼り付けてください。**何も印刷されませんでした**画面のレポートには、アプリがプリンターへの接続を試みたポートと、返された拒否応答が記録されます。保存済みのプリンターでは、**設定 → 印刷**のプリンターの行にある**その他の操作**メニューにあります。
