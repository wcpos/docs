**症状：** ネットワークプリンターの検索が **プリンターが見つかりません** で終了します。または、数週間使えていたプリンターが動作しなくなり、どのレシートも **選択したプリンターに接続できません**（[PRINT301](../../error-codes/PRINT301.mdx)）で印刷に失敗します。

通常、プリンター自体に問題はありません。レジとプリンターが別のネットワークに接続されているか、プリンターのアドレスが変わったために、レジから接続できない状態です。

- **プリンターを追加する場合：** [ネットワークを確認](#same-network)し、[アドレスを確認](#read-the-address)してから、[アドレスを指定して追加](#enter-address)します。
- **使えていたプリンターが動作しなくなった場合：** [アドレスを確認](#read-the-address)してから、[登録済みプリンターのアドレスを変更](#change-address)します。

印刷できるようになったら、再発を防ぐために[アドレスを固定](#fixed-address)します。

## まずネットワークを確認する {#same-network}

レジとプリンターを、ゲスト用ではなく **店舗と同じネットワーク** に接続します。プリンターはWi-Fi、またはルーターにつないだネットワークケーブルで接続できます。次に **設定 → 印刷** を開き、**プリンターを追加** を押して検索します。プリンターが表示されたら追加し、[アドレスを固定](#fixed-address)します。表示されない場合は、アドレスを確認して直接追加します。接続が妨げられる理由は[原因](#why-it-happens)で説明しています。

## プリンターのアドレスを確認する {#read-the-address}

プリンターのアドレスは、プリンター自身が印刷する **ステータスシート** に記載されています。メーカーによっては、ネットワークセルフテストや設定ページと呼ばれます。

- **ネットワーク接続のEpson TMプリンター**（TM-m30IIIなど）：電源を入れた状態でロール紙カバーを開け、**Feed** を一秒以上押し続けてからカバーを閉じます。ステータスシートボタンがある機種では、そのボタンを約三秒押し続けても同じシートを印刷できます。
- **ネットワーク接続のStarプリンター：** 電源を入れた状態で **Feed** を約五秒押し続けます。アドレスは **現在のIPパラメーター** に記載されています。
- **その他のプリンター、またはシートが出てこない場合：** ボタンの操作方法は機種によって異なります。プリンターのマニュアルで「ステータスシート」または「ネットワークセルフテスト」を調べてください。

シートの **IPアドレス** の行を探します。たとえば `192.168.1.100` です。店舗にプリンターが二台ある場合は、目的のプリンターのシートであることを確認してください。

次に、[プリンターを追加](#enter-address)するか、登録済みプリンターの[アドレスを変更](#change-address)します。

## アドレスを指定してプリンターを追加する {#enter-address}

検索でプリンターが見つからない場合は、アドレスを直接入力します。この場合も、店舗のネットワーク経由でレジからプリンターに接続できる必要があります。

1. **設定 → 印刷** を開き、**プリンターを追加** を押します。検索が自動的に始まります。
2. 検索中または検索終了後に **IPアドレスを入力** を押します。検索が停止します。
3. ステータスシートに記載されたアドレスを **IPアドレス** に入力します。
4. **このアドレスを確認** を押します。
5. カードに **準備完了** または **テストが必要** と表示されたら、**テストページを印刷** を押します。カードの横に **用紙幅** が表示されている場合は、先に **58 mm** または **80 mm** を選びます。
6. アプリに **テストページは印刷されましたか？** と表示されたら、**はい、正しく印刷されました** を押します。プリンターが保存され、**…の設定が完了しました** と表示されます。

テストページの目盛りが合わない場合や何も印刷されなかった場合は、残りの二つの回答から選ぶと次の手順に進めます。[プリンターを追加する](./index.mdx#adding-a-printer)を参照してください。

画面は次の順に表示されます。

## 設定済みプリンターのアドレスを変更する {#change-address}

アドレスが変わったために使えていたプリンターが動作しなくなった場合は、登録済みプリンターのアドレスを変更します。追加し直す必要はありません。

1. **設定 → 印刷** を開きます。
2. プリンターの行にある **編集** を押します。
3. **IPアドレス** をステータスシートに記載されたアドレスに変更します。変更は入力時に保存されます。**ネットワークをスキャン** を使うと、入力の代わりにプリンターを検索できます。
4. **テスト印刷** を押します。何も印刷されない場合は、[問題が起きた場合](#if-something-goes-wrong)を参照してください。

1. **プリンター名** — 変更するプリンターの名前です。
2. **IPアドレス** — ステータスシートに記載されたアドレスです。変更は入力時に保存されます。
3. **ポート** — 自動入力されるため、ここに表示されている値とは異なる場合があります。ブラウザーではHTTPSと通常のHTTPの選択も決まります。[HTTPSとHTTP](./browser-permissions.mdx#https-or-http)を参照してください。
4. **ネットワークをスキャン** — アドレスを入力する代わりにプリンターを検索します。
5. **テスト印刷** — 新しいアドレスでテストページを印刷します。
6. **閉じる** — 保存して閉じます。

</JourneyShot>

## アドレスを固定する {#fixed-address}

プリンターの追加や復旧に必須の操作ではありませんが、アドレスが再び変わるのを防ぎ、入力が一度で済むようになります。印刷できるようになったら、店舗のルーターを管理している方に、ステータスシートに記載された **プリンターのアドレスを予約する** よう依頼してください。これで、ルーターが毎回同じアドレスをプリンターに割り当てます。

<details>
<summary>ルーターとプリンターの設定</summary>

- **ルーターで予約する（推奨）。** ルーターの設定で、ネットワーク上の機器の一覧ページ（通常はDHCPやLANという名前）を開きます。ステータスシートのアドレスでプリンターを探し、そのアドレスを予約します。多くのルーターでは、ここでプリンターのMACアドレスの入力を求められます。プリンター側の設定変更は不要です。
- **またはプリンター側で設定します。** 同じネットワーク上のWebブラウザーで、プリンターのアドレス（例：`http://192.168.1.100`）を開き、ネットワーク設定で固定（静的）アドレスを割り当てます。ルーターが他の機器に割り当てないアドレスを選んでください。そうしないと、二台の機器が同じアドレスになることがあります。割り当て対象のアドレスはルーターの設定で確認できます。

</details>

## 原因 {#why-it-happens}

- **ネットワークが異なる。** レジとプリンターが別のネットワークに接続されています。ゲストネットワーク、二台目のルーター、スタッフ端末用の別ネットワークなどが考えられます。検索の対象は、レジが接続しているネットワークだけです。
- **ゲストWi-Fiが機器間の通信を遮断している。** ゲスト用や公衆Wi-Fiでは、通常、接続している機器同士の通信が制限されます。ルーターの設定では、クライアント分離やAP分離と呼ばれます。そのため、同じWi-Fiに接続していてもプリンターに接続できません。
- **アドレスが変わった。** ルーターは各機器に一定期間アドレスを貸し出します。再起動後や貸し出し期間の終了時にプリンターへ新しいアドレスが割り当てられても、アプリは古いアドレスに印刷データを送信し続けることがあります。これが、昨日は使えたのに今日は使えない原因になります。

<details>
<summary>Webブラウザーでの検索は一般的なアドレスだけを試す</summary>

ブラウザーはネットワーク上の機器を問い合わせることができないため、多くのルーターが使うアドレス範囲（`192.168.0.x`、`192.168.1.x`、`192.168.4.x`、`192.168.10.x`、`10.0.0.x`、`10.0.1.x`、`172.16.0.x`）への接続を試します。それ以外の範囲にあるプリンターは検索では見つかりません。アドレスを指定して追加してください。ブラウザーでは、アプリはネットワーク経由でEpsonとStarのプリンターに接続します。[各アプリで接続できるプリンター](./index.mdx#supported-printers-by-platform)を参照してください。

</details>

## 問題が起きた場合 {#if-something-goes-wrong}

- **シートのアドレスが `169.254` で始まる。** プリンターがネットワークからアドレスを取得できていません。ネットワークケーブルまたはWi-Fi設定を確認してから、ステータスシートをもう一度印刷してください。
- **アドレスは正しいのに「接続なし」と表示される。** レジとプリンターがゲストWi-Fiではなく、店舗の同じネットワークに接続されていることを確認してください（[原因](#why-it-happens)を参照）。同じネットワークであれば、以下のアプリの権限を確認してください。
- **iPadやiPhoneで検索しても何も見つからない。** アプリには **ローカルネットワーク** の権限が必要です。[iPadやiPhoneでアプリがプリンターを検出できるようにする](./ios-local-network.mdx)を参照してください。
- **ブラウザーで検索しても何も見つからない、またはデスクトップアプリでは印刷できるのにブラウザーではできない。** ブラウザーにはネットワークへのアクセス許可が必要です。[ブラウザーからの印刷](./browser-permissions.mdx)を参照してください。
- **アドレスは正しく、一度印刷できた後に止まった。** プリンターがジョブを保留している可能性があります。[Epsonで一度印刷できた後に止まった場合](./printed-once-then-stopped.mdx)を参照してください。

## 解決しない場合 {#still-stuck}

設定レポートをコピーして、お問い合わせのメッセージに貼り付けてください。**プリンターを追加** の **何も印刷されませんでした** 画面、または **設定 → 印刷** のプリンターの行にある **⋯** メニューで、**設定レポートをコピー** を押します。モバイルアプリでは共有シートが開きます。レポートには、アプリが使用したアドレスとポート、直近のプリンターログが含まれます。**プリンターを追加** から取得した場合は、プリンターの各ポートからの応答も含まれます。貼り付けるか共有するまでは、端末の外に送信されることはありません。
