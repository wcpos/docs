**症状：** 画面上ではレシートが正しく表示されるのに、紙には疑問符、空の四角、誤った文字が印刷されます。

このページはレシートプリンターについて説明しています。**印刷ダイアログ** やオフィス用プリンターはコンピューターのフォントを使うため、どの言語も画面どおりに印刷されます。

## 対処方法を選ぶ {#choose-a-fix}

まず、プリンターで使える設定を確認します。**設定 → 印刷** を開き、プリンターの行にある **編集** を押します。

<details>
<summary>「編集」ボタンがなく、「WCPOSが管理」と表示される場合</summary>

**WCPOSが管理** と表示されているのはクラウドプリンターです。アプリ内ではなく、店舗の管理者が **WP Admin → POS → 設定 → クラウド印刷** で設定するため、**編集** はありません。クラウドプリンターの印刷方法については、[クラウド印刷](../../receipts/cloud-printing.mdx)を参照してください。

</details>

**高速なテキスト印刷：[レシートの言語を設定する](#receipt-language)** — **プリンターを編集** に **レシートの言語** が表示され、レシートにキリル文字、ギリシャ語、トルコ語、ベトナム語、またはアクセント記号付きの西欧・中欧の文字を使う場合に選びます。

**速度は遅くなりますが、すべての言語に対応：[レシートを画像として印刷する](#print-the-receipt-as-an-image)** — 次の場合に選びます。

- **プリンターを編集** に **レシートの言語** がない。
- レシートが中国語、日本語、韓国語である。
- レシートがアラビア語、ヘブライ語、タイ語である。これらはレシートの言語として選択できますが、画像として印刷する方が適しています。速度を重視する場合にのみ、先にレシートの言語設定を試してください。
- 一枚のレシートに、ギリシャ語とロシア語のように二種類の文字体系が混在している。
- レシートの言語を設定しても文字が正しく印刷されない。

<details>
<summary>「レシートの言語」が表示されないプリンターがある理由</summary>

**レシートの言語** は、**プリンター言語** が **ESC/POS** の場合にのみ表示されます。これはEpsonや多くのレシートプリンターが使うコマンド言語です（[対応プリンター](supported-printers.mdx)を参照）。**StarPRNT** または **Star Line Mode** に設定されたStarプリンターには、この項目はありません。ラテン文字以外を印刷する場合は、[レシートを画像として印刷](#print-the-receipt-as-an-image)をオンにしてください。

</details>

## レシートの言語を設定する {#receipt-language}

レシートに使う言語を選びます。引き続きテキストとして印刷されるため、印刷速度を保てます。

**登録済みのプリンターの場合：**

1. **設定 → 印刷** を開き、プリンターの行にある **編集** を押します。
2. **レシートの言語** を開き、レシートに使う言語に対応した項目を選びます。**プリンターを編集** では、変更するたびに保存されます。
3. **プリンターを編集** の下部にある **テスト印刷** を押します。文字がまだ正しく印刷されない場合は、プリンターにその言語が内蔵されていない可能性があります。代わりに[画像として印刷](#print-the-receipt-as-an-image)してください。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} alt="ネットワーク接続のEpsonプリンターの「プリンターを編集」画面。プリンター言語はESC/POS、用紙幅は48 — 80 mm（ほとんどのEpsonとStar）、レシートの言語は自動。「用紙を自動カット」、「キャッシュドロワーを自動で開く」、「デフォルトに設定」のスイッチと、「レシートを画像として印刷」およびその注記が表示されています">

1. **プリンター言語** — ここでは **ESC/POS** です。**レシートの言語** はESC/POSの場合にのみ表示されます。
2. **用紙幅** — 一行あたりの文字数です。[レシートの幅](receipt-width.mdx)を参照してください。
3. **レシートの言語** — 開いて、レシートに使う言語の項目を選びます。どのプリンターも初期設定は **自動** です。
4. **レシートを画像として印刷** — すべての言語に対応する、もう一つの対処方法です。[レシートを画像として印刷する](#print-the-receipt-as-an-image)を参照してください。

</JourneyShot>

**プリンターを追加するとき：** **プリンターを追加** パネルで **その他のオプション** を押します。**レシートの言語** は四番目の設定で、**プリンターの文字幅**（**プリンターを編集** では **用紙幅** と呼ばれる設定）の下にあります。

一覧には十一の項目があります。中国語、日本語、韓国語の項目はありません。[これらは画像として印刷](#print-the-receipt-as-an-image)してください。言語名ではなく、地域や文字体系の名前が付いた項目もあります。ロシア語、ウクライナ語、ブルガリア語は **キリル文字**、ポーランド語、チェコ語、ハンガリー語は **中欧** を選びます。

<details>
<summary>レシートの言語はどれを選べばよいですか？</summary>

| 項目 | 対象 |
|---|---|
| **自動** | アプリが行ごとに文字テーブルを選びます。すべてのプリンターの初期設定です |
| **英語** | 通常の英語のテキスト |
| **西欧** | フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語、オランダ語、北欧の言語 |
| **中欧** | ポーランド語、チェコ語、スロバキア語、ハンガリー語、クロアチア語、スロベニア語 |
| **キリル文字** | ロシア語、ウクライナ語、ブルガリア語、セルビア語 |
| **ギリシャ語**、**トルコ語**、**アラビア語**、**ヘブライ語**、**タイ語**、**ベトナム語** | それぞれの言語 |

</details>

**レシートの言語** は、**プリンターを編集** の **プリンター言語** が **ESC/POS** の場合にのみ表示されます。Epsonや多くのレシートプリンターはESC/POSを使います。

<details>
<summary>「その他のオプション」にある他の設定</summary>

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[100, -18], [463, 0], [0, 0], [442, -38], [442, 45], [-34, 0], [-34, 0]]} alt="「プリンターを追加」パネルで「その他のオプション」を開いた状態。プリンター名、EpsonとStar Micronicsを選べるメーカー、プリンターの文字幅、自動に設定されたレシートの言語、用紙を自動カット、キャッシュドロワーを自動で開くが表示されています">

1. **その他のオプション** — テストページを印刷する前に、パネル内でプリンターの設定を開きます。もう一度押すと閉じます。
2. **プリンター名** — **設定 → 印刷** のプリンターの行や、プリンター一覧に表示される名前です。変更するまでは **レシートプリンター** です。
3. **メーカー** — **Epson** または **Star Micronics** です。**Star Micronics** を選ぶと **レシートの言語** が非表示になります。Starプリンターでは、[ラテン文字以外のテキストを画像として印刷](#print-the-receipt-as-an-image)してください。
4. **プリンターの文字幅** — 一行に収まる文字数です。58 mmの用紙では32文字、80 mmでは42、48、64文字です。テストページで確認できます。[レシートの幅](receipt-width.mdx)を参照してください。
5. **レシートの言語** — レシートのテキストに使う文字テーブルです。**自動** ではアプリが行ごとに選びます。一覧は[上記](#receipt-language)を参照してください。
6. **用紙を自動カット** — レシートを印刷するたびに用紙をカットします。
7. **キャッシュドロワーを自動で開く** — このプリンターに接続されたドロワーを開きます。[キャッシュドロワー](cash-drawer.mdx)を参照してください。

</JourneyShot>

これらの下にある **デフォルトに設定** をオンにすると、他の送信先が指定されていないレシートはこのプリンターで印刷されます。ここでの設定はすべて、後から **プリンターを編集** で変更できます。パネルのその他の項目は[設定ウィザード](setup-wizard.mdx)で説明しています。

</details>

## レシートを画像として印刷する {#print-the-receipt-as-an-image}

この方法は、アプリで追加したどのレシートプリンターでも、すべての言語に使えます。アプリがレシートを画像として描画して送信するため、プリンターの文字テーブルに左右されません。

:::warning
Wi-Fiまたはネットワークケーブルで接続したEpsonで画像として印刷するには、[セキュア印刷](secure-printing.mdx)をオフにする必要があります。
:::

1. **設定 → 印刷** を開きます。
2. プリンターの行にある **編集** を押します。
3. **プリンターを編集** の最後のスイッチ、**レシートを画像として印刷** をオンにします。注記には *プリンターで表示できない文字体系（アラビア語、ヘブライ語、タイ語）向けです。テキストより印刷に時間がかかり、データ量も大きくなります。* と表示されています。
4. **プリンターを編集** の下部にある **テスト印刷** を押して確認します。**設定 → 印刷** のプリンターの行にも **テスト印刷** があります。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} maxWidth={799} alt="「プリンターを編集」の設定。最後の「レシートを画像として印刷」スイッチはオフで、「プリンターで表示できない文字体系（アラビア語、ヘブライ語、タイ語）向けです。テキストより印刷に時間がかかり、データ量も大きくなります。」という注記が表示されています。">

1. **プリンター言語** — ここでは **ESC/POS** です。**レシートの言語** がないStarプリンターでも画像印刷を使えます。
2. **用紙幅** — 一行あたりの文字数です。[レシートの幅](receipt-width.mdx)を参照してください。
3. **レシートの言語** — 画像ではプリンターの文字テーブルを使わないため、この設定は影響しなくなります。
4. **レシートを画像として印刷** — ここではオフになっています。オンにしてから **テスト印刷** を押して確認してください。

</JourneyShot>

このスイッチは **プリンターを編集** にのみあり、**その他のオプション** にはありません。先にプリンターを追加してからオンにしてください。

:::tip
画像はテキストより送信するデータ量が大幅に増えるため、レシート一枚ごとの印刷に時間がかかります。必要なプリンターだけでオンにしてください。
:::

## 原因 {#why-it-happens}

レシートプリンターは、コンピューターのフォントを使いません。文字をテキストとして印刷する方法がない場合、疑問符や四角として印刷されます。画像を使えば、この問題を回避できます。

<details>
<summary>レシートプリンターがテキストを印刷する仕組み</summary>

プリンターに内蔵された文字テーブルを、一度に一つずつ使ってテキストを印刷します。アプリは行ごとに、その行の文字を含むテーブルを選びます。この方法で、英語やヨーロッパのほとんどの言語のレシートを印刷できます。他の文字体系では、アプリが選べるテーブルがプリンターにない場合があり、印刷できない文字はすべて疑問符や四角になります。**レシートの言語** を指定すると、レシート全体で使うテーブルが固定されます。画像印刷ではテーブルを一切使いません。

</details>

## 解決しない場合 {#still-stuck}

**設定 → 印刷** のプリンターの行にある **⋯** メニューを開き、**設定レポートをコピー** を押します。AndroidおよびiOSアプリでは、代わりに共有シートが開きます。レポートをお問い合わせのメッセージに貼り付け、印刷したレシートの写真と、印刷している言語もお知らせください。
