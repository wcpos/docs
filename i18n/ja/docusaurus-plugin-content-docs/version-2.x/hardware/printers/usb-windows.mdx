WindowsのデスクトップアプリでUSBレシートプリンターを使用するには、先にWindowsにインストールしてください。アプリがUSBプリンターを検出できるのは、Windowsに登録された後です。その後、POSに追加します。

1. [Windowsにプリンターをインストールする](#do-this)。
2. [POSに追加する](#add-in-pos)。

このページは、Windowsのデスクトップアプリで次の問題が発生する場合にも役立ちます。

- プリンターを接続して電源を入れているのに、**プリンターを追加**で**プリンターが見つかりません**と表示される。[プリンターが見つかりません](#no-printer-found)を参照してください。
- 以前のバージョンで追加したプリンターに、**Windowsでは、このプリンターをインストール済みプリンターとして追加し直してください。** と表示される。[以前のバージョンで追加したプリンター](#earlier-version)を参照してください。
- テストページに[意味不明な文字や記号が印刷される](#stray-symbols)、または[何も出てこない](#nothing-came-out)。

## Windowsにプリンターをインストールする {#do-this}

まず、Windowsに登録済みかどうかを確認します。

1. プリンターを接続し、電源を入れます。メーカーがWindows用のドライバーやインストーラーを提供している場合は、この時点で実行してください。
2. Windowsで**設定 → Bluetooth とデバイス → プリンターとスキャナー**を開きます。
3. プリンターが一覧にある場合は、[POSに追加する](#add-in-pos)に進んでください。ない場合は、**プリンターまたはスキャナーを追加します**の横にある**デバイスの追加**を選択します。Windowsがプリンターを検出して追加できた場合も、[POSに追加する](#add-in-pos)に進んでください。

それでもWindowsの一覧に表示されない場合は、Windowsに付属する基本的なドライバーである**Generic / Text Only**を使用して手動で追加してください。

<details>
<summary>プリンターを手動で追加する</summary>

1. **手動で追加**を選択し、次に**ローカル プリンターまたはネットワーク プリンターを手動設定で追加する**を選択します。
2. **既存のポートを使用**で、プリンターのUSBポートを選択します。USB001のように、名前が**USB**で始まるポートです。
3. ドライバーは、製造元で**Generic**、プリンターで**Generic / Text Only**を選択します。
4. *レシートプリンター*など、レジで見分けやすい名前を付けて完了します。

</details>

<details>
<summary>Windows 10の場合</summary>

**設定 → デバイス → プリンターとスキャナー**を開き、**プリンターまたはスキャナーを追加します**を選択します。Windows 11で**手動で追加**と表示される箇所は、Windows 10では**プリンターが一覧にない場合**と表示されます。

</details>

## POSに追加する {#add-in-pos}

1. デスクトップアプリで**設定 → 印刷**を開き、**プリンターを追加**を押します。検索が自動的に始まり、**USB、Bluetooth、Wi-Fi**のプリンターを探します。
2. Windowsで付けたプリンター名のカードを選択します。カードには**インストール済みプリンター**のバッジが付いています。複数のプリンターがある場合、パネルに**どのプリンターを使用しますか？** と表示され、自動では選択されません。
3. **テストページを印刷**を押します。パネルに**テストページは印刷されましたか？** と表示されます。
4. ページが正しく印刷されたら、**はい、正しく印刷されました**と回答します。プリンターが保存され、パネルに*名前* **の設定が完了しました**と表示されます。**完了**を押すと、**設定 → 印刷**にそのプリンターの行が表示されます。

ページが正しく印刷されなかった場合や、何も印刷されなかった場合は、[問題が発生した場合](#goes-wrong)を参照してください。その他の回答については、[テストページを印刷](./setup-wizard.mdx#test-page)を参照してください。

## 問題が発生した場合 {#goes-wrong}

### プリンターが見つかりません {#no-printer-found}

まず、Windowsの**プリンターとスキャナー**を確認してください。プリンターが一覧にない場合は、[Windowsにインストール](#do-this)してから**再スキャン**を押します。一覧にあるのにアプリで見つからない場合は、[解決しない場合](#still-stuck)を参照してください。

<details>
<summary>プリンターが見つかりませんパネルのその他のボタン</summary>

1. **再スキャン** — もう一度検索します。Windowsにプリンターをインストールした後に押してください。
2. **Bluetoothプリンターを探す** — ペアリングが不要なBluetoothプリンター用です。
3. **IPアドレスを入力** — 検索で見つからなかったネットワークプリンター用です。
4. **その他のオプション** — テストページを印刷する前に、名前、用紙幅、ドロアーを設定します。[その他のオプション](./setup-wizard.mdx#more-options)を参照してください。
5. **プリンターガイドを開く** — [プリンターガイド](./index.mdx)を開きます。

</details>

### 以前のバージョンで追加したプリンター {#earlier-version}

印刷しようとすると、**Windowsでは、このプリンターをインストール済みプリンターとして追加し直してください。** と表示されます。以前のバージョンでは直接接続のUSBプリンターとして保存されていましたが、現在のアプリはWindowsに登録されたプリンターを介してのみUSBプリンターに接続します。**設定 → 印刷**でプリンターの**その他の操作**メニューを開き、**削除**を選択してください。その後、**プリンターを追加**で再度追加し、該当する**インストール済みプリンター**のカードを選択します。

### 意味不明な文字や記号が印刷される {#stray-symbols}

#### プリンターを追加している場合 {#symbols-during-setup}

1. 用紙に印刷されていても、**何も出てきませんでした**と回答します。パネルには記号が印刷された場合の回答がなく、この回答を選ぶと**最初からやり直す**と**テストせずに保存**が表示されます。
2. 選択したカードの名前を確認してください。
   - オフィス用など、別のプリンターになっていませんか。そのプリンターはレシート用のコマンドを読み取れません。**最初からやり直す**を押し、お使いのレシートプリンターを選択してください。
   - お使いのレシートプリンターであれば、**テストせずに保存**を押し、[言語設定を修正](#symbols-saved)してください。

#### 保存済みのプリンターの場合 {#symbols-saved}

1. **設定 → 印刷**で、そのプリンターの行の名前を確認してください。別のプリンターの場合は、**プリンターを追加**を押して、お使いのレシートプリンターを選択します。
2. お使いのレシートプリンターであれば、**プリンター言語**の設定がプリンターと合っていない可能性があります。その行の**編集**を押してください。
3. **プリンター言語**を、プリンターのマニュアルに記載された言語に設定してください。Starプリンターは**StarPRNT**または**Star Line Mode**を使用します。Epsonプリンターとその他の多くのメーカーは**ESC/POS**を使用します。
4. その行の**テスト印刷**を押します。Starプリンターでまだ記号が印刷される場合は、もう一方のStarの言語に設定して再度テストしてください。
5. どの言語でも記号が印刷される場合は、[対応レシートプリンター](./supported-printers.mdx)でお使いの機種を確認し、[解決しない場合](#still-stuck)を参照してください。

### 何も出てきませんでした {#nothing-came-out}

#### プリンターを追加している場合 {#nothing-during-setup}

1. **何も出てきませんでした**と回答します。
2. 選択したカードの名前を確認してください。別のプリンターの場合は、**最初からやり直す**を押して、お使いのレシートプリンターを選択します。
3. お使いのプリンターであれば、パネルに**ケーブルとプリンターの電源を確認してから、もう一度お試しください。** と表示されます。確認してから**再試行**を押してください。

#### 保存済みのプリンターの場合 {#nothing-saved}

1. **設定 → 印刷**で、そのプリンターの行の名前を確認してください。別のプリンターの場合は、**プリンターを追加**を押して、お使いのレシートプリンターを選択します。
2. お使いのプリンターであれば、ケーブルとプリンターの電源を確認してから、その行の**テスト印刷**を押してください。

#### それでも何も出てこない場合 {#windows-test-page}

Windowsの**プリンターとスキャナー**で該当するプリンターを開き、Windowsからテストページを印刷してください。Windowsからも印刷できない場合は、ケーブル、ポート、ドライバーなど、Windowsとプリンターの間に問題があります。Windowsからは印刷できるのにPOSからは印刷できない場合は、[解決しない場合](#still-stuck)を参照してください。

### WebアプリでUSBプリンターを探す機能が失敗する {#web-app}

WindowsのWebアプリでは、**USBプリンターを探す**でUSBプリンターにアクセスできないことがよくあります。デスクトップアプリを使用してください。[Windowsにプリンターをインストール](#do-this)してから、[POSに追加](#add-in-pos)します。

## Windowsでのアプリの印刷方法 {#why-it-happens}

デスクトップアプリはWindowsにインストールされたプリンターに印刷するため、そのプリンターを選択してください。お使いの機種がレシート用のコマンドを読み取れるかどうかは、[対応レシートプリンター](./supported-printers.mdx)で確認できます。

<details>
<summary>Windowsへのプリンターのインストールが必要な理由</summary>

WindowsはUSBプリンターに標準またはメーカー製のドライバーを割り当てます。デスクトップアプリはケーブルに直接送信するのではなく、Windowsに登録されたプリンターを介して印刷します。各レシートはプリンターコマンドとして送信され、Windowsがそのままプリンターに渡すため、ドライバーによってレシートの形式が変わることはありません。

</details>

<details>
<summary>検索に表示されるWindowsのプリンター</summary>

**Microsoft Print to PDF**や**Fax**などのWindows標準の項目を除き、Windowsにインストールされたすべてのプリンターが表示されます。オフィス用プリンターも他のプリンターと同じように表示されるため、名前で選択してください。WindowsでペアリングしたBluetoothプリンターも、同じようにインストール済みプリンターとして表示されます。

</details>

## 解決しない場合 {#still-stuck}

**何も印刷されませんでした**パネル、または**設定 → 印刷**のプリンターの**その他の操作**メニューで、**セットアップレポートをコピー**を押してください。レポートには、アプリが印刷先に使用したWindows上のプリンター名が記載されています。メッセージに貼り付けてください。
