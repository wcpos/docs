Epsonプリンターでアプリから印刷できず、次のような状態の場合は、このページをご覧ください。

- **プリンターのセットアップ中：** [プリンターを追加](./setup-wizard.mdx#test-page)でテストページを印刷し、**何も出てきませんでした**を選ぶと、パネルに**何も印刷されませんでした**と表示され、*「セキュア印刷がオンです。プリンターでオフにしてから、もう一度お試しください。」*という文が出ます。[オフにする](#turn-it-off)に進んでください。
- **プリンターは準備完了に見えるのに何も印刷されない：** ジョブは送信されたように見え、エラーもありませんが、何も出てきません。プリンター本体のボタンで行うセルフテストでは印刷できます。

セキュア印刷はPOS内の設定ではなく、プリンター本体の設定です。変更が不要な場合もあります。まず[オフにする必要がありますか？](#do-you-need-to)を確認してください。

## オフにする必要がありますか？ {#do-you-need-to}

ほとんどの構成では、セキュア印刷がオンでもアプリから印刷できます。アプリの**何も印刷されませんでした**パネルでオフにするよう指示された場合は、[オフにしてください](#turn-it-off)。それ以外の場合は、表を上から確認し、印刷方法が最初に当てはまる行に従ってください。**レシートを画像として印刷**がオンかどうかわからない場合は、先に[スイッチを確認してください](#print-as-image)。

| 印刷方法 | セキュア印刷がオンの場合 |
|---|---|
| アプリの種類を問わず、EpsonをWi-Fiまたはネットワークケーブルで接続し、**レシートを画像として印刷**がオン | 印刷できません。セキュア印刷をオフにしてください。 |
| **デスクトップアプリ**（コンピューターにインストールしたWCPOS）、Wi-Fiまたはネットワークプリンター | 印刷できます。 |
| **Webアプリ**（Chrome、Edge、Safariなどのブラウザーで開いたPOS） | ブラウザーがプリンターの証明書を信頼すると、HTTPS経由で印刷できます。[ブラウザーの権限](./browser-permissions.mdx#the-printers-certificate)をご覧ください。HTTP（ポート8008または80）では印刷できないため、セキュア印刷をオフにしてください。 |
| **モバイルアプリ** | **プリンターを追加**のプリンターカードに **Wi-Fi · セキュア**と表示されていれば印刷できます。**Wi-Fi** と表示されている場合は、セキュア印刷をオフにしてください。 |
| **USB** または **Bluetooth** | 影響はありません。 |

### 「レシートを画像として印刷」を確認する {#print-as-image}

このスイッチをオンにすると、セキュア印刷がオンの間はプリンターが保留してしまう形式でレシートが送信されます。自分でオンにしていなければオフです。**設定 → 印刷**に移動し、プリンターの行にある**編集**を押します。

1. **用紙を自動カット** — 表示範囲の最後の行です。さらに下にスクロールすると、**レシートを画像として印刷**があります。

</JourneyShot>

フォームの末尾にあります。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} maxWidth={799} alt="Epsonプリンターの「プリンターを編集」の設定。最後のスイッチ「レシートを画像として印刷」はオフになっています">

1. **プリンター言語** — 設定はそのままにしてください。セキュア印刷によって1から3の項目が変わることはありません。
2. **用紙幅** — 行あたりの文字数です。
3. **レシートの言語** — テキスト形式のレシートに使用する文字体系です。
4. **レシートを画像として印刷** — 確認するスイッチです。ここではオフになっており、自分でオンにしない限りオフです。Wi-Fiまたはネットワークケーブルで接続したEpsonで使用するには、セキュア印刷をオフにする必要があります。

## オフにする {#turn-it-off}

プリンターと同じネットワーク上のコンピューター、プリンターのIPアドレス、管理者パスワードである**初期パスワード**が必要です。セキュア印刷がオンのプリンターでは、手順1で印刷するステータスシートに両方が記載されています。

1. ステータスシートを印刷します。ほとんどの機種では、用紙カバーを開き、**紙送り**を1秒間押してからカバーを閉じます。ステータスシート専用のボタンがある場合は、代わりにそのボタンを3秒間押します。IPアドレスと**初期パスワード**を控えてください。
2. 同じネットワーク上のコンピューターで、`https://`の後にそのアドレスを付けてブラウザーで開きます。証明書の警告を承認して進んでください。
3. シートに記載された**初期パスワード**を使って管理者としてログインします。パスワードを変更済みの場合は、設定したパスワードを使ってください。
4. **印刷 → セキュア印刷**に移動します。
5. **無効**に設定して保存します。
6. プリンターの電源プラグを抜き、10秒待ってから差し直します。
7. アプリからテストページを印刷します。**プリンターを追加**では、**再試行**を押します。保存済みのプリンターでは、**設定 → 印刷**のプリンターの行にある**テスト印刷**を押します。

<Accordion>
<AccordionItem question="ステータスシートが印刷されない、またはパスワードが通らない場合">

- **ステータスシートが出ない：** 使用するボタンと押し続ける時間は機種によって異なります。プリンターのマニュアルで確認してください。
- **シートに初期パスワードがない：** プリンター本体のラベルを確認してください。機種によっては、シリアル番号がパスワードです。
- **パスワードが変更されている：** プリンターを設定した担当者に確認してください。

</AccordionItem>
</Accordion>

:::warning ファームウェアの更新後はこの設定を確認してください
ファームウェアを更新すると、セキュア印刷が再びオンになることがあります。更新後に印刷できなくなった場合は、オンに戻っていないか確認してください。戻っている場合は、この手順を繰り返します。
:::

## 原因 {#why-it-happens}

セキュア印刷がオンの間、プリンターはアプリから安全な接続経由でテキストとして送られたものだけを印刷します。画像として送られたレシートなど、それ以外は保留します。ジョブを拒否するのではなく、約4分間**保留**し、その間はほかの印刷も行わず、最後に破棄します。そのため、正常に見えるのに反応しない状態になります。[一度印刷した後に止まる](./printed-once-then-stopped.mdx)をご覧ください。

ステータスシートに **セキュリティーモード：RED** と記載されていれば、このプリンターはセキュア印刷の対象です。

<Accordion>
<AccordionItem question="影響を受けるプリンターと接続方法">

**2025年8月1日**以降にEU、英国、EFTAで販売されるEpson TMシリーズのプリンターは、EUの無線機器指令に準拠するため、**セキュア印刷**がオンの状態で出荷されます。Ethernet接続だけで使う場合も同じです。それ以外の地域で販売されるプリンターは通常オフですが、EUまたは英国向けの在庫から購入したものはオンになっています。

Epsonが挙げている対象機種は、TM-H6000VI、TM-L100、TM-m30II-S、TM-m30II-SL、TM-m30III、TM-m30III-H、TM-m50、TM-m50II、TM-P20II、TM-P80II、TM-T20IV、TM-T88VIIです。USBまたはシリアルポートのみを備えたTM-L100とTM-T20IVは対象外です。

これらのプリンターに関するEpsonの公式ガイドによる情報です。

| 接続方法 | セキュア印刷が**オン** | **オフ** |
|---|---|---|
| Raw、ポート9100 | 印刷不可 | 印刷可能 |
| HTTP経由のePOS-Print、ポート80 | 印刷不可 | 印刷可能 |
| ePOS SDK、ポート8008と8009 | 印刷不可 | 印刷可能 |
| HTTPS経由のePOS-Print、ポート443 | 印刷可能 | 印刷可能 |
| TLS経由のePOS SDK、ポート8043と8143 | 印刷可能 | 印刷可能 |
| TLS経由のRaw、ポート9143 | 印刷可能 | 印刷可能 |
| Bluetooth | 印刷可能 | 印刷可能 |

デスクトップアプリは、まずHTTPSのポート443経由でEpsonへの印刷を試みます。WebアプリはHTTPSのポート8043を使用しますが、セットアップウィザードがポート443で検出した場合はそちらを使用します。モバイルアプリは、カードに **Wi-Fi · セキュア**と表示されていない限り、ポート9100でRaw印刷します。

</AccordionItem>
</Accordion>

## 解決しない場合 {#still-stuck}

**セキュア印刷がすでにオフなのに何も印刷されない。** プリンターのWebページは開くのに、すべてのジョブが失敗する場合は、[サーバーダイレクトプリント](./server-direct-print.mdx)をご覧ください。

**一度印刷した後に止まった。** [一度印刷した後に止まる](./printed-once-then-stopped.mdx)をご覧ください。

**その他の場合。** セットアップレポートをコピーし、問い合わせメッセージに貼り付けてください。**プリンターを追加**では、**何も印刷されませんでした**の下にある**セットアップレポートをコピー**を押します。保存済みのプリンターでは、**設定 → 印刷**のプリンターの行にある**その他の操作**メニューを開き、**セットアップレポートをコピー**を選びます。この設定の詳細は、Epsonの[無線機器指令に関するFAQ](https://www.epson.eu/en_EU/faq/KA-01896/contents?loc=en-us)に記載されています。
