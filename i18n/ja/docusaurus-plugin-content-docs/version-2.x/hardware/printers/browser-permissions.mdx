EpsonまたはStarのプリンターの電源が入っていて同じネットワークに接続されているのに、ブラウザーのタブ内のPOSからアクセスできない場合は、[この順番で対処する](#fix-in-order)から始めてください。デスクトップアプリでは、これらの対処は不要です。

## 表示される症状 {#symptom}

プリンターの電源が入っていて同じネットワークに接続されているのに、**設定 → 印刷 → プリンターを追加**でスキャンしても何も見つからない（**プリンターが見つかりません**）、またはプリンターのアドレスを入力してもカードに**未接続**と表示されます。同じプリンターでも、デスクトップアプリからは印刷できるのに、ブラウザーのタブからは印刷できないこともあります。

テストページの印刷に失敗すると、**アプリからプリンターへのアクセスが許可されていません。システム設定で許可してから、もう一度お試しください。** と表示されることがあります。ブラウザーでは、これはブラウザーからプリンターにアクセスできなかったことを意味します。プリンターの電源が入っていて、アドレスが正しいことを確認してから、以下の対処法を順番に試してください。両方の画面について、[後ほど各項目を説明します](#on-screen)。

## この順番で対処する {#fix-in-order}

SafariやFirefoxでは、まず[利用できる接続方法](#safari-and-firefox)を確認してください。ChromeやEdgeでは、次の手順で進めます。

1. [ローカルネットワークへのアクセスを許可](#allow-local-network-access)してから、もう一度確認します。
2. それでも失敗する場合は、プリンターの**ポート**を確認します。保存済みのプリンターなら**プリンターを編集**、追加中なら**IPアドレスを入力**にあります。ポートを見れば、POSがHTTPSと通常のHTTPのどちらを使うか分かります。

   | プリンター | HTTPSポート | HTTPポート |
   |---|---|---|
   | Epson | **8043**または**443** | **8008**または**80** |
   | Star | **443** | **80** |

   確認したポートに応じて、次のいずれかに進んでください。

   - **HTTPSポート：** [プリンターの証明書を信頼する](#the-printers-certificate)手順を行ってから、もう一度確認します。
   - **HTTPポート：** [プリンターがHTTPを使用する場合](#mixed-content)を参照してください。

3. まだ**未接続**と表示される、またはテストが失敗する場合は、[解決しない場合](#still-stuck)を参照してください。

### もう一度確認する {#check-again}

- **プリンターを追加する場合：** **IPアドレスを入力**、**このアドレスを確認**の順に押します。カードに**準備完了**と表示されれば、ブラウザーからプリンターにアクセスできています。[テストページを印刷する](./setup-wizard.mdx#test-page)に進んでください。
- **保存済みのプリンターの場合：** **設定 → 印刷**の該当する行、または**プリンターを編集**で**テスト印刷**を押します。

ローカルネットワークへのアクセスを許可しても失敗する場合は、[ポートを確認](#fix-in-order)してください（手順2）。ポートに応じた対処を行っても失敗する場合は、[解決しない場合](#still-stuck)を参照してください。

[HTTPSとHTTP](#https-or-http)に、ポートの確認場所を示す画面を掲載しています。

## ローカルネットワークへのアクセスを許可する {#allow-local-network-access}

ChromeとEdgeは、ウェブサイトがローカルネットワーク内のデバイスにアクセスする前に許可を求めます。**ローカルネットワーク上の他のデバイスへのアクセス**を求められたら、許可してください。

**許可しない**を選んだ場合や、確認画面を閉じた場合は、次の手順を行ってください。

1. アドレスバーの左側にあるアイコンをクリックし、**サイトの設定**をクリックします。
2. **ローカルネットワーク**を**許可**に設定します。
3. POSを再読み込みし、[もう一度確認](#check-again)します。

## プリンターの証明書 {#the-printers-certificate}

HTTPSでは、プリンターが独自の証明書を提示します。ブラウザーがその証明書を信頼していないと、何かを送信する前に接続が失敗します。次の手順で、このブラウザーから接続できるようにします。

1. プリンターに証明書があることを確認します。ステータスシートに証明書がないと記載されている場合は、プリンターのウェブ設定画面で自己署名証明書を作成してください。Epsonでは、[Epsonのセキュア印刷](./secure-printing.mdx#turn-it-off)の説明に従ってログインします。
2. 同じブラウザーで、お使いのプリンターのIPアドレスを使って、プリンターのアドレスをHTTPSで開きます。
   - **Epson：** まず`https://192.168.1.200:8043`を試してください。開かない場合は、ポート443を使う`https://192.168.1.200`を試してください。
   - **Star：** ポート443を使う`https://192.168.1.200`を開きます。
3. 証明書の警告を承認します。お使いのブラウザーの手順を開いてください。

   <details>
   <summary>Chrome</summary>

   **この接続ではプライバシーが保護されません**で、**詳細設定**、**192.168.1.200 にアクセスする（安全ではありません）** の順に押します。

   </details>

   <details>
   <summary>Edge</summary>

   **詳細設定**、**192.168.1.200 に進む（安全ではありません）** の順に押します。

   </details>

   <details>
   <summary>Safari</summary>

   **この接続はプライベートではありません**で、**詳細を表示**、**このWebサイトを閲覧**リンク、**Webサイトを閲覧**の順に押します。

   </details>

   <details>
   <summary>Firefox</summary>

   警告画面に表示される、サイトへのアクセスを続行するための選択肢を使用してください。

   </details>

4. POSに戻り、[もう一度確認](#check-again)します。

印刷に使うすべてのパソコンで、使用するブラウザーごとにこの操作を行ってください。

デスクトップアプリは、プリンターの証明書を自動的に受け入れます。そのため、同じプリンターでもデスクトップアプリでは使えるのに、ブラウザーのタブでは使えないことがあります。

## プリンターがHTTPを使用する場合 {#mixed-content}

店舗サイトのアドレスが`https://`で始まり、プリンターが通常のHTTPにしか対応していない場合は、ChromeまたはEdgeの142以降を使用し、[ローカルネットワークへのアクセスを許可](#allow-local-network-access)して印刷してください。

他のブラウザーでは、この通信はブロックされます。安全なページから安全でないアドレスに送信することはできず、ブラウザーではこれを混在コンテンツと呼びます。ChromeやEdgeを使えない場合は、[証明書](#the-printers-certificate)を使ってプリンターをHTTPSに切り替えるか、デスクトップアプリを使用してください。

## SafariとFirefox {#safari-and-firefox}

- **Wi-Fi経由：** プリンターの通信方式を店舗サイトに合わせる必要があります。`https://`の店舗サイトからは、[証明書を承認](#the-printers-certificate)したうえでHTTPSのみ使用できます。通常のHTTPはブロックされます。`http://`の店舗サイトからは、通常のHTTPを使用できます。
- **USBとBluetooth：** **USBプリンターを検索**と**Bluetoothプリンターを検索**は、これらの機器にアクセスできるブラウザーであるChromeとEdgeでのみ表示されます。

それ以外の場合は、Chrome、Edge、またはデスクトップアプリを使用してください。

## POSでの表示箇所 {#on-screen}

**プリンターを編集**で**テスト印刷**が失敗すると、**アプリからプリンターへのアクセスが許可されていません**と表示されます。

<JourneyShot manifest={manifest} device="tablet" step={18} offsets={[[290, 0], [0, -28], [-36, -4], [0, 36], [130, 0], [110, 0]]} maxWidth={559} alt="192.168.1.128のポート8008へのテスト印刷に失敗した後の「プリンターを編集」。赤い枠に「アプリからプリンターへのアクセスが許可されていません。システム設定で許可してから、もう一度お試しください」と表示され、横に「お困りですか？」、下に「サポート用の詳細情報」、下部に「ドロアを開く」、「テスト印刷」、「閉じる」があります">

1. **IPアドレス** — ステータスシートに記載されているプリンターのアドレスです。
2. **ポート** — 8008はEpsonの通常のHTTPポートです。[HTTPSとHTTP](#https-or-http)を参照してください。
3. **アプリからプリンターへのアクセスが許可されていません** — ブラウザーでは、プリンターにアクセスできないと常にこのメッセージが表示されます。プリンターの電源がオフ、アドレスが異なる、ローカルネットワークの権限が無効、証明書が信頼されていないなどの原因が考えられます。アドレスを確認してから、[対処法を順番に](#fix-in-order)試してください。
4. **お困りですか？** — プリンターガイドを開きます。
5. **サポート用の詳細情報** — サポートに送るためにコピーする詳細情報を開きます。[解決しない場合](#still-stuck)を参照してください。
6. **テスト印刷** — 対処法を試すたびに、もう一度実行してください。

</JourneyShot>

**プリンターを追加**で**このアドレスを確認**を押すと、ブラウザーからアクセスできないプリンターのカードはグレー表示になります。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-12, -33], [134, -18], [95, 18], [162, 0]]} maxWidth={559} alt="「このアドレスを確認」を押した後の「プリンターを追加」パネル。「プリンターが見つかりません」と表示され、192.168.1.200、Epson、Wi-Fiのレシートプリンターのカードは「未接続」でグレー表示になっており、別の方法を試すためのボタンがあります">

1. **プリンターのカード** — **未接続**は、そのアドレスからブラウザーに応答がなかったことを意味します。[対処法を順番に](#fix-in-order)試してください。
2. **IPアドレスを入力** — 問題に対処してから、アドレスをもう一度確認します。
3. **その他のオプション** — **Epson**または**Star Micronics**を選びます。
4. **プリンターガイドを開く** — [プリンターガイド](./index.mdx)を開きます。

</JourneyShot>

## HTTPSとHTTP {#https-or-http}

ブラウザーは、[上の表](#fix-in-order)にあるいずれかのポートでプリンターのウェブサーバーにアクセスします。ポートによって、HTTPSと通常のHTTPのどちらを使用するかが決まります。

- **HTTPS**では、このブラウザーが信頼する証明書がプリンターに必要です。[プリンターの証明書](#the-printers-certificate)を参照してください。
- HTTPSの店舗サイトから**HTTP**で接続するには、ChromeまたはEdgeの142以降と、[ローカルネットワークの権限](#allow-local-network-access)が必要です。[プリンターがHTTPを使用する場合](#mixed-content)を参照してください。

保存済みのプリンターでは、**プリンターを編集**の**ウェブ印刷エンドポイント**に、使用している方式が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={13} offsets={[[290, 0], [0, 30], [572, -2], [700, 0]]} alt="192.168.1.128、ポート8008のEpsonの「プリンターを編集」。「検出：Epson」、ウェブ印刷エンドポイント http://192.168.1.128:8008/cgi-bin/epos/service.cgi、「HTTP経由でEpson ePOSを使用しています。ChromeまたはEdgeでローカルネットワークへのアクセス許可を求められることがあります」と表示されています">

1. **IPアドレス** — プリンターのアドレスです。
2. **ポート** — この例では、Epsonの通常のHTTPポートである8008です。HTTPSの店舗サイトでEpsonを新規追加する場合、初期値はHTTPSを使う**8043**です。
3. **ウェブ印刷エンドポイント** — ブラウザーがレシートを送信するアドレスです。通常のHTTPでは`http://`、HTTPSでは`https://`で始まります。
4. **エンドポイントの下の行** — メーカー名と、HTTPSかHTTPかを文章で示します。HTTPの場合は、ChromeまたはEdgeで[ローカルネットワークの権限](#allow-local-network-access)を求められる可能性があることも表示されます。HTTPSの場合は、このブラウザーが信頼する証明書がプリンターに必要であることが表示されます（[プリンターの証明書](#the-printers-certificate)）。

</JourneyShot>

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[351, 0], [64, 0], [133, -18]]} maxWidth={559} alt="プリンターのIPアドレスを入力する画面。IPアドレスに192.168.1.200、ポートに8043が入力され、「このアドレスを確認」が表示されています">

1. **IPアドレス** — プリンターのステータスシートに記載されています。
2. **ポート** — HTTPSの店舗サイトでは、初期値はEpsonのHTTPSポートである**8043**です。
3. **このアドレスを確認** — EpsonとStarで一般的に使われるHTTPSおよびHTTPのポートを試し、応答があったポートを使用します。

</JourneyShot>

## 解決しない場合 {#still-stuck}

**セットアップレポートをコピー**を使い、メッセージに貼り付けてください。この項目は、テストページの印刷に失敗した後の**何も印刷されませんでした**画面と、保存済みプリンターのメニューにあります。レポートには、アドレス、ポート、試した処理が記録されています。**何も印刷されませんでした**画面では、**サポート用の詳細情報**に使用したブラウザーも表示されます。
