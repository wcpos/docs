**症状：** Androidのスマートフォンやタブレットで、**プリンターを追加**に**プリンターが見つかりません**と表示される、またはBluetoothプリンターが検索結果に表示されません。

WCPOSにBluetoothの使用が許可されていないと、Bluetoothプリンターを検出できません。まずこの権限を確認してください。

Wi-Fiプリンターは、どのAndroidバージョンでも権限を必要としません。[Wi-Fiプリンター](#wi-fi-printers)に進んでください。 {/* pending: monorepo#3366 */}

## WCPOSからプリンターへのアクセスを許可する {#allow-nearby-devices}

1. Bluetoothプリンターを使う場合は、Androidのクイック設定でBluetoothがオンになっていることを確認します。
2. Androidのバージョンを確認します。Androidの**設定 → デバイス情報 → Android バージョン**を開いてください。
3. Androidの**設定 → アプリ → WCPOS → 権限**を開きます。
4. お使いのバージョンに応じて権限を許可します。
   - **Android 11以前：** 「付近のデバイス」の権限はありません。**位置情報**をタップして許可してください。これらのバージョンでは、Bluetoothプリンターを検出するために位置情報が必要です。
   - **Android 12以降：** **付近のデバイス**をタップし、**許可**を選びます。これにより、WCPOSでBluetoothプリンターを検出して接続できるようになります。
5. WCPOSに戻り、**プリンターを追加**画面で**再スキャン**をタップします。

プリンターが表示されたら、そのカードの下にある**テストページを印刷**をタップします。ページが印刷され、ページ上の目盛りが正しく表示されていれば、**はい、正しく印刷されています**と回答してください。プリンターが保存され、問題が解決したことを確認できます。詳しい手順は[プリンターを追加する](./index.mdx#adding-a-printer)を参照してください。

Androidの設定メニューの名前はメーカーによって多少異なりますが、どのAndroidスマートフォンにも、アプリごとに**権限**のページがあります。

## Bluetoothプリンター {#bluetooth-printers}

権限を許可すると、WCPOSがBluetoothプリンターを検索します。お使いのプリンターが見つかるかどうかは、プリンターのBluetoothの種類にもよります。

- **Bluetooth Low Energyプリンター**は、スキャンすると自動的に表示されます。Androidでのペアリングは不要です。
- **Classic Bluetoothプリンター**は、Androidでペアリングしてからでないと表示されません。安価な58 mmプリンターの多くがこの種類です。**プリンターが見つかりません**画面で**Bluetooth設定を開く**をタップし、そこでプリンターをペアリングしてから戻り、**再スキャン**をタップしてください。

プリンターの種類が分からない場合やペアリングできない場合は、[Bluetoothレシートプリンターのペアリング](./bluetooth-pairing.mdx#classic-or-low-energy)を参照してください。種類の見分け方と、プリンターをペアリングモードにする方法を説明しています。

## Wi-Fiプリンター {#wi-fi-printers}

スマートフォンやタブレットが、プリンターと同じ店舗のWi-Fiネットワークに接続されていることを確認してください。モバイルデータ通信やゲストネットワークには接続しないでください。

スキャンしても何も見つからず、プリンターのアドレスが分かっている場合は、**IPアドレスを入力**をタップします。スキャンを省略し、そのアドレスを直接確認します。アドレスはプリンターのステータスシートに印刷されています。[プリンターのネットワークアドレスを確認する](./network-address.mdx)を参照してください。

## 問題が発生した場合 {#goes-wrong}

### 検出に失敗する {#discovery-failed}

**プリンターが見つかりません**の下に、プリンターの検出に失敗したことを示す赤いメッセージが表示されます。例：「Bluetoothがオフになっているか、このアプリでの使用が許可されていません。」スマートフォンのBluetoothがオフになっているか、WCPOSに使用が許可されていません。Bluetoothをオンにして[Androidのバージョンに応じた権限を許可](#allow-nearby-devices)し、**再スキャン**をタップしてください。

### 印刷が許可されていない {#printing-not-allowed}

テスト印刷後、**何も印刷されませんでした**に「アプリからプリンターへのアクセスが許可されていません。システム設定で許可してから、もう一度お試しください。」と表示されます。WCPOSが印刷しようとした際にAndroidがアクセスを拒否しました。[Androidのバージョンに応じた権限を許可](#allow-nearby-devices)してから、**再試行**をタップしてください。

### プリンターのペアリングが必要 {#printer-needs-pairing}

テスト印刷後、**何も印刷されませんでした**に「このスマートフォンのBluetooth設定でプリンターをペアリングしてから、再スキャンしてください。」と表示されます。プリンターはClassic Bluetoothを使用しており、Androidとのペアリングが解除されています。メッセージの下にある**Bluetooth設定を開く**をタップしてペアリングし、**最初からやり直す**をタップして再スキャンしてください。

### 許可してもプリンターが見つからない {#still-missing}

付近のデバイス（Android 11以前では位置情報）を許可してもプリンターが見つからない場合は、プリンターの電源を入れ直してから**再スキャン**をタップしてください。それでも見つからない場合は、次を確認してください。

- **Bluetoothプリンター：** その他の原因は、[Bluetoothレシートプリンターのペアリング](./bluetooth-pairing.mdx)を参照してください。
- **Wi-Fiプリンター：** [Wi-Fiプリンター](#wi-fi-printers)の説明に従ってネットワークを確認し、プリンターのアドレスで接続を試してください。

### 解決しない場合 {#still-stuck}

プリンターが一度も表示されない場合は、報告できるテスト印刷の結果がありません。以下からお問い合わせいただき、Androidのバージョンとプリンターのメーカー・機種をお知らせください。

プリンターは表示されるものの印刷できない場合は、**何も印刷されませんでした**画面の**セットアップレポートをコピー**をタップしてください。この画面は、テスト印刷が失敗した場合や、テスト印刷後に**何も出てきませんでした**と回答した場合に自動的に開きます。Androidでは「セットアップレポートをコピー」をタップすると共有メニューが開きます。レポートをメールで送信するか、メッセージにコピーしてお送りください。レポートには、アプリのバージョン、プリンター、アプリが試した処理、プリンターの応答が記載されています。
