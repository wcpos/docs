レシートプリンターで各行に印字できる文字数は決まっています。58 mm用紙では32文字、80 mm用紙では42、48、64文字です。アプリは選択した文字数に合わせてすべてのレシートをレイアウトします。文字数が多すぎると長い行が次の行に折り返され、少なすぎると価格が右端まで届きません。テストページの目盛りで、どちらにずれているかを確認できます。

プリンターを追加済みの場合は、[後から幅を変更する](#change-later)をご覧ください。

## テストページを印刷する {#answer}

{/* reshoot: the Paper width toggle needs a printer whose width the app can't read; whole-screen Add printer frames wait for a clean Printing list behind the panel */}

**プリンターを追加**でプリンターを選択した後、次の操作を行います。

1. **用紙の設定を求められたら設定します。** **用紙幅**が表示されたら、プリンターに入っているロール紙に合わせて **58 mm** または **80 mm** を選びます。
2. **「テストページを印刷」を押します。**
3. 印刷されたページの **1 文字数の目盛り**を**確認します**。最後の数字が印字領域の右端にあれば適切です。次の行に折り返されていれば文字数が多すぎ、右端のかなり手前で終わっていれば少なすぎます。下の[目盛りの読み方](#what-the-ruler-is-off-means)に図があります。
4. **「テストページは印刷されましたか？」に回答します。**
   - **はい、正しく印刷されました** — 今印刷した幅でプリンターを保存します。
   - **印刷されましたが、目盛りがずれています** — アプリに **プリンターにはどの用紙が入っていますか？** と表示され、4種類の幅が一覧に並びます。
     1. [幅の選び方](#which-answer-to-pick)を参考に幅を選びます。アプリがその幅でテストページを再印刷します。
     2. 新しい目盛りを確認します。
     3. まだずれている場合は、選び直します。目盛りの終端が印字領域の右端に合ったら、**はい、正しく印刷されました**を選びます。
   - **何も出てきませんでした** — 幅の問題ではありません。[何も印刷されない場合](./index.mdx#when-nothing-prints)をご覧ください。

1. **はい、正しく印刷されました** — プリンターを保存します。
2. **印刷されましたが、目盛りがずれています** — 下記の幅の一覧を開きます。
3. **何も出てきませんでした** — [何も印刷されない場合](./index.mdx#when-nothing-prints)をご覧ください。
4. **テストページ 1 · 行あたり48文字** — 印刷したテストページの数と、最後に印刷した幅です。

1. **32 — 58 mm用紙** — 幅の狭いロール紙です。
2. **42 — 80 mm、旧型プリンター** — 48で折り返された場合に選びます。
3. **48 — 80 mm、ほとんどのEpson・Star** — 選択されている項目です。最後のテストページを印刷した幅を示します。

保存済みのプリンターでは、**設定 → 印刷**のプリンターの行にある**テスト印刷**を押します。

<details>
<summary>「用紙幅」が表示される条件と初期値</summary>

モバイルアプリと、USB プリンターに接続するデスクトップアプリは、まずプリンターに用紙サイズを問い合わせ、**用紙幅を確認中…** と表示します。それでも判別できない場合にのみ、**用紙幅**が表示されます。Epson と Star のプリンターでは、初期値は 80 mm です。それ以外のプリンターでは、印刷前に、装着しているロール紙のサイズが表示されていることを確認してください。

</details>

最後の数字で、印刷した幅がわかります。48文字の行は **8**、42文字と32文字の行は **2**、64文字の行は **4** で終わります。

## 幅の選び方 {#which-answer-to-pick}

| 一覧の選択肢 | 選ぶ条件 |
|---|---|
| **32 — 58 mm用紙** | 幅の狭いロール紙：ほとんどの小型・携帯型・Bluetoothプリンター |
| **42 — 80 mm、旧型プリンター** | 48で次の行に折り返された場合 |
| **48 — 80 mm、ほとんどのEpson・Star** | 80 mm用紙で最初に試す場合 |
| **64 — 80 mm、小さいフォント** | 小さいフォントを使用しているStarプリンターで、48では右端まで届かない場合。[フォントAとフォントB](#font-a-and-font-b)をご覧ください。 |

ロール紙の種類がわからない場合は、幅を測ってください。58 mm用紙は6 cm弱、80 mm用紙は8 cmです。

## 後から幅を変更する {#change-later}

1. **プリンターを開きます。** **設定 → 印刷**に移動し、プリンターの行にある**編集**を押します。

設定画面の上に**プリンターを編集**が開き、**プリンター言語**の下に**用紙幅**が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={9} offsets={[[-46, 0], [-46, 0], [-46, 0], [104, 0]]} alt="「設定」の「印刷」画面の上に開いた、Front Counterというプリンターの「プリンターを編集」。ネットワーク設定の下に、プリンター言語「ESC/POS」、用紙幅「48 — 80 mm、ほとんどのEpson・Star」、レシートの言語「自動」、「用紙を自動カット」があり、下部に「ドロアーを開く」「テスト印刷」「閉じる」があります">

1. **プリンター言語** — ここでは **ESC/POS** です。プリンターのフォントが幅にどう影響するかは、この設定で決まります。[フォントAとフォントB](#font-a-and-font-b)をご覧ください。
2. **用紙幅** — 行あたりの文字数です。ここでは **48 — 80 mm、ほとんどのEpson・Star** になっています。開くと **32**、**42**、**48**、**64** から選べます。
3. **レシートの言語** — 幅ではなく、テキストに使用する文字テーブルです。[ラテン文字以外のレシート](./non-latin-receipts.mdx)をご覧ください。
4. **テスト印刷** — 現在設定されている幅でテストページを印刷します。

</JourneyShot>

2. **「用紙幅」で文字数を選びます：** **32**、**42**、**48**、**64** から選択します。ここでの**用紙幅**は行あたりの文字数を意味し、セットアップ中に尋ねられることがある58 mm / 80 mmのロール紙の幅ではありません。変更はその場で保存されます。
3. 同じダイアログの下部、またはプリンターの行にある**テスト印刷**を押し、もう一度[目盛りを確認します](#what-the-ruler-is-off-means)。

## 問題が発生した場合 {#troubleshooting}

**レシートの行が次の行に折り返される。** 用紙に対して幅が大きすぎます。80 mm用紙では48から42へ1段階下げ、58 mm用紙では現在の値にかかわらず32にしてください。

**価格が右端まで届かない。** 幅が小さすぎます。42から48へ1段階上げてください。Starプリンターで48でも右端まで届かない場合は、[フォントAとフォントB](#font-a-and-font-b)をご覧ください。

**58 mm用紙でロゴが見切れる。** 幅を **32** に設定し、**シンプルな感熱レシート (58mm)** などの58 mm用紙用のレシートテンプレート、または用紙サイズを指定しないテンプレートで印刷してください。80 mm用紙用のテンプレートでは、幅の設定にかかわらずロゴのサイズが80 mm用になります。テストページのロゴは常に幅の設定に従うため、レシートでは見切れていてもテストページでは全体が印刷されることがあります。

**£、€、アクセント付き文字が別の文字で印字される。** 幅ではなく、プリンターの文字テーブルの問題です。テストページの **8 文字**の項目を確認してください。[ラテン文字以外のレシート](./non-latin-receipts.mdx)をご覧ください。

## フォントAとフォントB {#font-a-and-font-b}

レシートプリンターには2種類のフォントが内蔵されています。フォントAが標準です。フォントBは小さく、行あたりの文字数を多くできます。**64** はそのための設定です。ESC/POSプリンターで80 mm用紙を使う場合は、48または42を使用してください。64は、Starプリンターがすでに小さいフォントに設定されている場合にのみ使用します。

<details>
<summary>プリンターのフォントが幅に与える影響</summary>

- **ESC/POSプリンター**（ほとんどのEpsonプリンターのように、**プリンター言語**が **ESC/POS** に設定されている場合）：アプリは、テストページとレシートの印刷開始時に毎回フォントAを指定します。プリンター本体の設定がフォントBのままでも、アプリからはフォントAで印刷されるため、48または42を使用してください。
- **Starプリンター**（**StarPRNT** または **Star Line Mode**）：アプリは、プリンターに設定されているフォントで印刷します。80 mm用紙で48が右端のかなり手前で終わる場合は、小さいフォントに設定されています。**64** を選ぶか、Starの設定ツールでフォントAに戻して48を使用してください。

</details>

## 解決しない場合 {#still-stuck}

**セットアップレポートをコピー**を押し、問い合わせメッセージに貼り付けてください。**プリンターを追加**では、**何も印刷されませんでした**の画面と、プリンターの設定完了画面にあります。

<JourneyShot manifest={manifest} device="tablet" step={8} offsets={[[-30, 0], [-30, 0]]} maxWidth={559} alt="「Front Counterの設定が完了しました」「デフォルトのプリンターです」と表示された「プリンターを追加」画面。「完了」ボタン、「名前、幅、キャッシュドロアーは設定のプリンターの行で設定できます」という文、「セットアップレポートをコピー」があります">

1. **完了** — 「プリンターを追加」を閉じます。プリンターは、最後のテストページの幅ですでに保存されています。
2. **セットアップレポートをコピー** — 問い合わせメッセージに添付するレポートをコピーします。

</JourneyShot>

**設定 → 印刷**のプリンターの行にある**その他の操作**メニューにもあります。レポートには、プリンター、アプリが使用している幅、プリンターの応答がわかるアプリの直近のプリンターログが記録されます。**プリンターを追加**から取得した場合は、印刷したテストページの数と最後のエラーも記録されます。モバイルアプリでは、コピーする代わりに共有シートが開きます。
