**症状：** iPadやiPhoneで**プリンターを追加**を実行すると**プリンターが見つかりません**と表示される、または、これまで使えていたWi-Fiプリンターで印刷できなくなります。同じWi-Fiに接続したパソコンからは、そのプリンターで引き続き印刷できます。

まず、WCPOSにローカルネットワークの使用が許可されているか確認してください。

<details>
<summary>アクセスを拒否するとプリンターの電源が切れているときと同じ症状になる理由</summary>

WCPOSが初めてプリンターを検索するとき、iOSはローカルネットワーク上のデバイスの検索と接続を許可するか尋ねます。その下には、*WCPOSはローカルネットワークを使用してカードリーダーとレシートプリンターに接続します。* と表示されます。

**許可しない**をタップすると、それ以降、iOSはWCPOSからすべてのWi-Fiプリンターへのアクセスをブロックします。検索、アドレスの確認、すべてのレシート印刷が対象です。iOSは拒否したことをアプリに通知しないため、WCPOSにはプリンターの電源が切れているときと同じ画面が表示されます。

- 検索後に**プリンターが見つかりません**と表示され、*プリンターの電源が入り、同じWi-Fiに接続されているか、Bluetooth設定でペアリングされていることを確認してください。* と案内されます。
- **このアドレスを確認**を実行すると、プリンターのカードに**接続なし**と表示されます。
- 以前保存したプリンターの**テスト印刷**に失敗します。

Bluetoothプリンターはこの許可を使いません。Bluetoothプリンターが見つからない場合は、[Bluetoothレシートプリンターのペアリング](./bluetooth-pairing.mdx)を参照してください。

</details>

## アクセスを許可する {#turn-the-permission-on}

1. iPadまたはiPhoneの**設定**アプリを開きます。
2. **プライバシーとセキュリティ → ローカルネットワーク**に進みます。
3. **WCPOS**の横にあるスイッチをオンにします。
4. アプリスイッチャーでWCPOSを上にスワイプして、完全に終了します。その後、もう一度開いてください。

同じスイッチは、**設定**アプリ内のWCPOSのページにもあります。下にスクロールして**WCPOS**を開き、**ローカルネットワーク**をオンにしてください。

<details>
<summary>一覧にWCPOSがない場合</summary>

iOSは、WCPOSが一度プリンターを検索した後にだけ、一覧にWCPOSを追加します。WCPOSで**設定 → 印刷**を開き、**プリンターを追加**を押してください。iOSがローカルネットワーク上のデバイスの検索を求めたら、**許可**をタップしてください。検索が終わっても**プリンターが見つかりません**と表示される場合は、**再検索**を押してください。WCPOSが一度許可を求めると、一覧に表示されます。

</details>

## Wi-Fiを確認する {#also-check}

- iPadがプリンターと同じ**店舗のWi-Fi**に接続されていることを確認してください。ゲストネットワークやモバイルデータ通信では接続できません。[プリンターのアドレスを固定する](./network-address.mdx)を参照してください。
- Wi-Fiがオンになっていることを確認してください。Wi-Fiがオフの場合、アクセス許可の設定に関係なくWi-Fiプリンターには接続できません。

## 印刷できるか確認する {#check-it-worked}

WCPOSで**設定 → 印刷**を開きます。

- **プリンターを保存済みの場合：** その横の**テスト印刷**を押してください。
- **プリンターをまだ保存していない場合：** **プリンターを追加**を押してください。プリンターが表示されたら、カードの下にある**テストページを印刷**を押し、印刷結果を回答してください。検索で何も見つからない場合は、[再検索しても見つからない場合](#if-the-scan-finds-nothing)を参照してください。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[60, 0], [0, -38], [0, -38], [140, 0], [190, 0]]} alt="WCPOSの「設定」の「印刷」：各行に「テスト印刷」ボタンと「その他の操作」メニューがあるプリンター一覧、「プリンターを追加」ボタン、「お困りですか？」リンク">

1. **印刷** — このデバイスのプリンターを管理する場所です。
2. **テスト印刷** — 保存済みの各プリンターの行にあります。Wi-Fiプリンターの横にあるボタンを押してください。印刷できれば完了です。
3. **その他の操作** — 各行のメニューです。ここに**セットアップレポートをコピー**があります。[解決しない場合](#still-stuck)を参照してください。
4. **プリンターを追加** — セットアップパネルを開き、すぐに検索を開始します。[レシートプリンター](./index.mdx)を参照してください。
5. **お困りですか？** — プリンターガイドを開きます。

</JourneyShot>

## 再検索しても見つからない場合 {#if-the-scan-finds-nothing}

iPadやiPhoneでは、Wi-Fi、Bluetooth、USB経由で**EpsonとStar**のプリンターを検索します。他メーカーのWi-Fiプリンターは表示されず、ネットワークによっては検索がブロックされることもあります。その場合は、アドレスを指定してプリンターを確認してください。

1. プリンターのステータスシートを印刷し、記載されているIPアドレスを確認してください。手順は[プリンターのアドレスを固定する](./network-address.mdx)を参照してください。
2. 検索画面で**IPアドレスを入力**を押します。検索が停止し、アドレス入力フォームが開きます。
3. アドレスを入力し、**このアドレスを確認**を押します。
4. プリンターのカードに**準備完了**または**テストが必要**と表示されたら、**テストページを印刷**を押し、印刷結果を回答してください。**接続なし**と表示される場合、iPadはそのアドレスに接続できていません。[Wi-Fi](#also-check)と、新たに印刷したステータスシートのアドレスを確認してください。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[110, -38], [40, -38], [-38, 0], [0, 40], [165, 0]]} alt="「プリンターを追加」パネルの「プリンターのIPアドレスを入力」画面：IPアドレスとポートの入力欄、「このアドレスを確認」、「キャンセル」、ステータスシートのヒント、「再検索」、「プリンターガイドを開く」">

1. **IPアドレス** — プリンターのステータスシートに記載されているアドレスです。
2. **ポート** — 初期値は**9100**です。確認時にプリンターが応答するポートが検出されるため、変更が必要になることはほとんどありません。
3. **このアドレスを確認** — プリンターに問い合わせて機種を確認します。カードには**準備完了**または**テストが必要**と表示され、その下に**テストページを印刷**が表示されます。応答がなければ**接続なし**と表示されます。
4. **再検索** — 検索に戻ります。
5. **プリンターガイドを開く** — [レシートプリンター](./index.mdx)を開きます。

</JourneyShot>

## 解決しない場合 {#still-stuck}

セットアップレポートをお送りください。**セットアップレポートをコピー**は、セットアップパネルの**何も印刷されませんでした**画面と、**設定 → 印刷**のプリンター行にある**その他の操作**メニューにあります。iPadやiPhoneでは共有シートが開くので、メールで送信するか、メッセージにコピーしてください。

レポートには、アプリのバージョン、iOSのバージョン、プリンターの設定、アプリの直近のプリンターログが含まれます。セットアップパネルから取得した場合は、確認時の検出結果も含まれます。
