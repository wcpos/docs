キャッシュドロワーはPOSに直接接続するのではなく、**レシートプリンター**に接続します。POSからの指示を受けて、プリンターがドロワーを開きます。このページでは、ドロワーの接続、アプリでの設定、動作確認の手順を説明します。

:::note 先にレシートプリンターを用意してください
ドロワーより先にプリンターを追加してください。[プリンター設定ウィザード](./setup-wizard.mdx)を参照してください。組み込みの**印刷ダイアログ**とクラウドプリンターでは、ドロワーを開けません。
:::

## ドロワーをプリンターに接続する {#wire-it-up}

1. プリンターの背面にある、**DK**、**ドロワー**、または**キャッシュドロワー**と表示された差し込み口を探します。
2. ドロワーのケーブルを差し込みます。プラグは電話線のプラグに似ています。隣にあるネットワーク用の差し込み口は幅が広いので、そちらには接続しないでください。
3. プリンターの電源を切り、入れ直します。

## アプリで有効にする {#switch-it-on-in-the-app}

**キャッシュドロワーを自動で開く**スイッチは、プリンターごとに用意されています。新しいプリンターではオフになっています。プリンターの追加時にオンにすることも、追加後にプリンターの行からオンにすることもできます。すでに追加済みの場合は、[ドロワーの動作確認](#test-the-drawer)に進んでください。

:::note レシートを印刷するたびにドロワーが開きます
**キャッシュドロワーを自動で開く**をオンにすると、そのプリンターでレシートを印刷するたびにドロワーが開きます。カード決済や再印刷の場合も同様です。[ドロワーが開くタイミング](#when-it-opens)を参照してください。
:::

### プリンターの追加時に設定する {#while-adding}

**設定 → 印刷**で**プリンターを追加**を押します。検索が完了したら、**その他のオプション**を押します。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[96, 0], [-24, 0], [-60, 0], [-60, 0]]} maxWidth={559} alt="その他のオプションを開いたプリンターを追加パネル。プリンター名、メーカー、プリンターの文字幅、レシートの言語が表示され、用紙を自動でカット、キャッシュドロワーを自動で開く、デフォルトに設定のスイッチはすべてオン">

1. **その他のオプション** — 検索結果の下にプリンターの設定を開きます。
2. **メーカー** — **Epson**または**Star Micronics**を選びます。ドロワーを開くコマンドはメーカーごとに異なるため、お使いのプリンターのメーカーを選んでください。
3. **キャッシュドロワーを自動で開く** — プリンターがレシートを印刷するたびにドロワーを開きます。
4. **デフォルトに設定** — **販売なし**では、デフォルトのプリンターに接続されたドロワーが開きます。[販売せずにドロワーを開く](#no-sale)を参照してください。

</JourneyShot>

[プリンター設定ウィザード](./setup-wizard.mdx)の説明に従って、プリンターの追加を完了してください。ウィザードのテストページではドロワーは開かないため、次にドロワーの動作を確認します。

### ドロワーの動作確認と追加済みプリンターの設定変更 {#test-the-drawer}

1. **設定 → 印刷**で、プリンターの行にある**編集**を押します。
2. **キャッシュドロワーを自動で開く**がオフの場合はオンにします。その下に、ドロワーの接続先のピンを指定する**キャッシュドロワーのコネクター**が表示されます。ほとんどのドロワーには**ピン 2 / ドロワー 1**が適しています。二台目のドロワーを使う場合や、ドロワーの説明書でピン 5が指定されている場合は、**ピン 5 / ドロワー 2**を選んでください。
3. **プリンターを編集**の下部にある、**テスト印刷**の隣の**ドロワーを開く**を押します。印刷せずにドロワーを一度開きます。ドロワーが開くことを確認してください。開かない場合は、アプリに**キャッシュドロワーを開きました**と表示されていても、[ドロワーが開かない場合](#when-it-doesnt-open)を参照してください。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[685, 0], [685, 0], [47, -30], [36, -30]]} alt="設定 → 印刷でネットワークプリンターのプリンターを編集パネルを開き、ドロワー設定までスクロールした状態。キャッシュドロワーを自動で開くがオン、キャッシュドロワーのコネクターがピン 2 / ドロワー 1に設定され、下部にドロワーを開くボタンとテスト印刷ボタンが表示されている">

1. **キャッシュドロワーを自動で開く** — この例ではオンです。プリンターがレシートを印刷するたびにドロワーを開きます。
2. **キャッシュドロワーのコネクター** — ドロワーの接続先のピンです。この例では**ピン 2 / ドロワー 1**です。**キャッシュドロワーを自動で開く**がオンの場合にのみ表示されます。
3. **ドロワーを開く** — 印刷せずにドロワーを一度開きます。
4. **テスト印刷** — このプリンターでテストページを印刷します。この例のように**キャッシュドロワーを自動で開く**がオンの場合は、ドロワーも開きます。

</JourneyShot>

## ドロワーが開くタイミング {#when-it-opens}

**キャッシュドロワーを自動で開く**がオンの場合、次のようにそのプリンターでレシートを印刷するたびにドロワーが開きます。

- 会計時に手動または自動でレシートを印刷したとき。
- 後からレシートを再印刷したとき。
- プリンターの行にある**テスト印刷**を実行したとき。

現金に限らず、どの支払い方法でも開きます。

Xレポート、引き継ぎ、締め処理などのレジレポートでは開きません。[レジを開く](../../pos/register/index.mdx)を参照してください。

## 販売せずにドロワーを開く {#no-sale}

両替や釣銭準備金の確認には、レジパネルの**販売なし**を使います。入出金を伴わずにドロワーを開き、その理由を記録します。

{/* pending: monorepo#3360 */}
:::note 始める前に
- レジが開いていることを確認してください。[レジを開く](../../pos/register/index.mdx)を参照してください。
- デフォルトのレシートプリンターで**キャッシュドロワーを自動で開く**がオンになっていることを確認してください。**販売なし**では、そのプリンターに接続されたドロワーが開きます。プリンターをデフォルトにするには、**設定 → 印刷**でそのプリンターの**その他の操作**メニューを開き、**デフォルトに設定**を押します。
:::

レジバーの端にある自分のアバターをタップし、**ドロワー内の現金**をタップすると、レジパネルが開きます。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [200, 0]]} alt="レジが開いている状態のレジパネル。ドロワー内の現金、入金、出金、販売なしのタイル、下部にXレポートを印刷が表示されている">

1. **販売なし** — ドロワーを開きます。レジが開いている場合にのみ使えます。隣にある**入金**と**出金**は現金の出入りを記録するもので、ドロワーは開きません。
2. **ドロワー内の現金** — レジの記録上の現金残高です。販売なしでは変わりません。下部の**Xレポートを印刷**では、ドロワーは開きません。

</JourneyShot>

**販売なし**を押します。シートに**ドロワーを開く理由は？** と表示されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [440, 0], [140, -42]]} alt="販売なしの「ドロワーを開く理由は？」シート。ドロワー内の現金、理由の選択肢である両替、操作ミス、ドロワーの確認、その他…、両替と入力された理由欄、ドロワーを開くボタンが表示されている">

1. **両替** — **操作ミス**、**ドロアーの確認**とともに用意されている理由の一つです。いずれかをタップすると理由が入力されます。**その他…** をタップすると入力欄が空になり、自分で理由を入力できます。
2. **理由** — 記録する理由です。入力するまでは、シートに**理由を追加**と表示されます。
3. **ドロワーを開く** — 販売なしを記録し、ドロワーを開きます。

</JourneyShot>

上部の金額は、レジの記録上ドロワーにあるはずの現金残高です。残高を見ずに現金を数えるレジ係には表示されません。

ドロワーが開くことを確認してください。開かない場合は、[ドロワーが開かない場合](#when-it-doesnt-open)を参照してください。開いたかどうかにかかわらず、販売なしは記録されます。

## ドロワーが開かない場合 {#when-it-doesnt-open}

まず、**編集**の**ドロワーを開く**を使ってください。レシートを印刷せずにドロワーを開くので、そもそも開くかどうかを確認できます。その後、該当する症状の項目を開いてください。

<Accordion>
<AccordionItem question="「ドロワーを開く」では開くが、レシートの印刷では開かない">

配線は正しく接続されています。レシートを印刷するプリンターで、**キャッシュドロワーを自動で開く**がオンになっていることを確認してください。

</AccordionItem>
<AccordionItem question="「ドロワーを開く」で「プリンターがジョブを受け付けませんでした。」と表示される">

プリンターがコマンドを受け付けませんでした。まず、プリンターの行からテストページを印刷してください。[レシートプリンター](./index.mdx#when-nothing-prints)を参照してください。

</AccordionItem>
<AccordionItem question="アプリに「キャッシュドロワーを開きました」と表示されるが、何も起きない">

ケーブルがネットワーク用ではなく、ドロワー用の差し込み口に接続されていることを確認してください。次に、**キャッシュドロワーのコネクター**をもう一方の設定に切り替えてみてください。ドロワーがピン 5に接続されている可能性があります。

</AccordionItem>
<AccordionItem question="ドロワーからカチッと音がするが開かない">

ドロワーの鍵を確認してください。多くのドロワーには前面に鍵穴があり、鍵の位置によっては閉じたままになります。次に電圧を確認してください。ドロワーには12 V用と24 V用があり、プリンターの出力電圧と一致している必要があります。対応電圧はプリンターの説明書に記載されています。

</AccordionItem>
<AccordionItem question="編集画面に「キャッシュドロワーの開放動作はプリンター言語／エミュレーションに依存します」と警告が表示される">

StarプリンターにESC/POSが設定されているなど、**プリンター言語**がプリンターのメーカーと一致していません。プリンターのエミュレーションモードに合う言語を設定してください。

</AccordionItem>
<AccordionItem question="販売なしの画面が閉じたが、ドロワーは開かなかった">

開いたかどうかにかかわらず、販売なしは記録されます。デフォルトのレシートプリンターで**キャッシュドロワーを自動で開く**がオンになっていることを確認してください。プリンターが拒否した場合は、シートが開いたままエラーが表示されます。**ドロワーを開く**をもう一度押してください。ドロワーを開くだけで、販売なしが重複して記録されることはありません。

</AccordionItem>
<AccordionItem question="低価格のプリンターが反応しない">

低価格のプリンターの中には、古いバージョンのドロワーコマンドにしか対応していないものがあります。**Epson**に設定したプリンターでは、**ドロワーを開く**がEpsonの新しいコマンドを送信するため、こうしたプリンターは反応しません。ドロワー用の差し込み口がないプリンターや、ドロワーを駆動できないプリンターもあります。キャッシュドロワーへの対応状況は、プリンターの説明書で確認してください。

</AccordionItem>
<AccordionItem question="「キャッシュドロワーを自動で開く」がオフなのにドロワーが開く">

カスタムのサーマルテンプレートには、独自の `<drawer />` コマンドを含めることができ、このコマンドはスイッチの設定にかかわらずドロワーを開きます。開かないようにするには、テンプレートからこのタグを削除してください。詳しくは、 [サーマルテンプレート](../../receipts/thermal-templates.mdx)を参照してください。

</AccordionItem>
</Accordion>

## 解決しない場合 {#still-stuck}

**設定 → 印刷**でプリンターの**その他の操作**メニューを開き、**セットアップレポートをコピー**を押します。レポートをメッセージに貼り付け、プリンターとドロワーの機種名を添えてください。
