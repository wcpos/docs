## このエラーの意味 {#what-this-means}

このデバイスのメモリが不足したため、最後の操作が完了していない可能性があります。

他のアプリやタブを閉じて WCPOS を再起動し、最後の売上や変更が保存されたか確認してください。保存されていなければ、操作をやり直してください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に確認してください。売上や変更の保存中にメモリが不足した場合は、やり直す前に保存されているか確認してください。

## トラブルシューティング {#troubleshoot}

1. 他のアプリやブラウザーのタブを閉じてください。WCPOS は、デバイス上で動作する他のすべてのアプリとメモリを共有しています。
2. WCPOS を再起動してください。
3. 最後の売上や変更をやり直す前に、保存されているか確認してください。**店舗の状態 → データベース**（**送信待ちの変更**に数えられている売上は保存済みで、送信が進行中です）、カート、注文（WCPOS Pro）または **WooCommerce → 注文**を確認します。カード払いの場合は、決済端末や決済サービス側も確認してください。お客様に請求済みの場合は、再度請求しないでください。本当に保存されていない場合に限り、一度だけ操作をやり直してください。
4. 特定の操作で必ずメモリ不足が発生する場合は、その操作を控え、**ログ**タブの**デバッグ情報をコピー**をタップして、サポートにお問い合わせください。
5. 同じデバイスで毎日発生する場合は、商品カタログの規模に対してデバイスのメモリが不足している可能性があります。サポートが確認できるよう、報告してください。
