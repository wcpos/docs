## このエラーの意味 {#what-this-means}

この変更は、まだ店舗に送信中です。

対応は不要です。再入力しないでください。自動的に送信され、店舗が受信を確認すると表示されます。

売上や変更はこのデバイスに保存されて送信されましたが、通常の待機時間内に店舗から受信確認が届きませんでした。多くの場合、店舗の応答が遅いか、接続が不安定なことが原因です。WCPOS は店舗から確認が届くまで送信を続けます。店舗は受信済みの変更を識別できるため、同じボタンをもう一度押しても問題ありません。ただし、売上やレコードを手動で入力し直すと、別のデータが作成されて重複するため、行わないでください。

## データへの影響 {#your-data}

データは失われていません。変更はこのデバイスで待機しており、自動的に送信されます。送信待ちの間は、このデバイスのデータを消去しないでください。

## トラブルシューティング {#troubleshoot}

1. 売上や変更を手動で入力し直さないでください。重複が作成されます。
2. 店舗に届くまで待ってください。売上はこのデバイスに保存されているため、WCPOS のカート内、または WCPOS Pro の **注文** にすでに表示されています。店舗に届いたことを確認するには、WP Admin の **WooCommerce → 注文** を確認してください。
3. 送信状況を確認するには、**店舗の状態 → ログ** を開いてください。ヘッダーの **送信待ちの変更** は送信が進むにつれて減り、待機中の変更がなくなると 0 になります。
4. 長時間待機したままの場合は、このデバイスの接続と、店舗のウェブサイトが表示されるかを確認してください。[SYNC121](/error-codes/SYNC121) を参照してください。
5. 接続が正常になっても表示されない場合は、**ログ** タブの **デバッグ情報をコピー** をタップしてサポートにお問い合わせください。
