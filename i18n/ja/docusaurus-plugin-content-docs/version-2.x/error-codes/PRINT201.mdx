## このエラーの意味 {#what-this-means}

WCPOS は印刷ジョブの完了を確認できませんでした。

レシートが二重に印刷されないよう、再試行する前にプリンターを確認してください。

## データへの影響 {#your-data}

販売と注文のデータは安全に保存されており、変更されていません。印刷結果だけが未確認です。

## トラブルシューティング {#troubleshoot}

1. 再試行する前にプリンターを確認してください。完了の応答がなくても、印刷されている場合があります。確認せずに再試行すると、レシートが二重に印刷されます。
2. プリンターの用紙、カバー、エラーランプを確認してください。
3. 何も印刷されていなければ、一度再試行してください。販売後に表示されるレシートで**レシートを印刷**（または**再印刷**）を押します。そのレシートを閉じた場合、WCPOS Pro では**注文**を開き、注文の**レシート**アクションを使用して**レシートを印刷**を押してください。Pro がない場合、閉じたレシートを再度開くことはできません。
4. 繰り返し失敗する場合は、プリンターの電源を入れ直し、レジとの接続を確認してください。
