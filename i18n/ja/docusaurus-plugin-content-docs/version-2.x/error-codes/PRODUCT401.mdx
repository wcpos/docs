## このエラーの意味 {#what-this-means}

表示中の在庫情報は、店舗側の在庫情報より古い可能性があります。

在庫数を超えて販売するおそれがある場合は、販売を完了する前に店舗側の現在の在庫を確認してください。

## データへの影響 {#your-data}

データが失われる危険はありません。レジの在庫数が店舗側より古いだけで、同期が復旧すれば最新の情報に更新されます。問題が続く場合は、WordPress サイトの管理者に確認してください。

## トラブルシューティング {#troubleshoot}

1. **レジでの対応：** 在庫の少ない商品を販売する前に、レジの数字だけを信用せず、棚や WP Admin の商品在庫を確認して実際の数量を確かめてください。
2. レジのデータを更新してください。**店舗の状態 → データベース**を開き、**商品**行の **⋮** メニューから**今すぐ変更を確認**を選択します。サイズや色などのバリエーションがある商品では、各バリエーションが個別に在庫を持つため、**バリエーション**行でも同じ操作を行ってください。
3. それでも数字が古いままなら、同期が失敗しているか一時停止しています。**ログ**タブで**エラー**または**同期**を選び、表示されるコードに対処してください。たとえば、店舗に接続できない場合は [SYNC121](/error-codes/SYNC121) が表示されます。同期が復旧すれば、在庫情報は自動で最新になります。
4. **サイト管理者の対応：** 複数のレジやオンラインショップで同じ在庫を販売する場合は、**WP Admin > POS > 設定 > レジ**で**過剰販売を防止**をオンにしてください。レジの数字が古くても、店舗側の在庫数を超える販売は拒否されます。この確認は、レジがオンラインの状態でチェックアウトする際に行われます。オフラインで完了した販売については、後で同期する際に確実に確認されるとは限らないため、在庫の少ない商品をオフラインで販売する前に手動で在庫を確認してください（手順 1）。
