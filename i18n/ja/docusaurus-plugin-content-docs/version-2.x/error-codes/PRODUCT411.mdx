## このエラーの意味 {#what-this-means}

バーコードスキャンの設定を読み込めなかったため、スキャンしても商品が見つからない可能性があります。

POS はバックグラウンドでこの設定の読み込みを繰り返し試みます。スキャンが不安定なままなら、アプリを一度再読み込みしてください。

## データへの影響 {#your-data}

注文や商品のデータに影響はありません。

## トラブルシューティング {#troubleshoot}

1. 作業を続けてください。POS はバックグラウンドでバーコード設定の読み込みを再試行します。
2. スキャンしても商品がまったく見つからない状態が続く場合は、アプリを一度再読み込みしてください。
3. 再読み込みしても問題が続く場合、設定の取得リクエスト自体が失敗しています。店舗への接続を確認し、「店舗の状態 → ログ」で関連するエラーを探してください（必要であれば店舗の管理者に相談してください）。
