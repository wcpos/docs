## このエラーの意味 {#what-this-means}

同期中に予期しない問題が発生しました。

このログ項目に記載された操作が完了したか確認し、完了していなければ、もう一度行ってください。繰り返し発生する場合は、**デバッグ情報をコピー** をタップして、サポートに送信してください。

## データへの影響 {#your-data}

この端末のデータを消去しないでください。店舗側にまだ届いていない変更が残っている可能性があります。ログ項目に記載された操作が完了していなければ、もう一度行ってください。

## トラブルシューティング {#troubleshoot}

1. ログ項目を展開し、記載されている操作を確認してください。その操作が完了したか確認します。保存操作の場合は、注文やレコードを開き、変更が反映されているか確認してください。反映されていれば、WCPOS が自動で送信するため、そのままにしてください。
2. 操作が完了していなければ、もう一度行ってください。変更がこの端末に保存されなかったとログ項目に記載されている場合、その変更は記録されていません。
3. ログ項目のコードと、理由があればその内容を控えてください。999 のコードは、その具体的な原因に対応する専用コードがまだないことを意味します。そのため、こうした状況の情報がサポートにとって必要です。
4. 繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** をタップして、サポートに送信してください。報告が、その原因に対応する専用コードの追加につながります。
