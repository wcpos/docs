## このエラーの意味 {#what-this-means}

このアプリで利用できるどのアドレス形式でも、店舗の REST API から応答がありませんでした。

アプリは店舗の REST API に、通常のアドレス (/wp-json/...) と WordPress に組み込まれた代替アドレス (/?rest_route=...) の両方でアクセスしましたが、どちらからも応答がありませんでした。店舗のウェブサイト自体は動いている場合もあります。これは REST API に接続できない問題で、通常はセキュリティプラグインによる非表示設定やファイアウォールのルールによるブロックが原因です。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。

## 対処方法 {#troubleshoot}

**店舗側での対応** — サイト管理者の方：WP Hide などのセキュリティプラグインで `/wp-json/` を非表示にしたり名前を変更したりしている場合は、WordPress に組み込まれた `/?rest_route=` 形式も許可してください。アプリは自動的にこの形式に切り替えます。

**ホスト／サーバー側での対応：**

1. ファイアウォール（WAF）のルールに `wp-json` や `rest_route` に一致するものがないか確認し、店舗自体の REST API への通信を許可してください。
2. サーバーの手前にメンテナンスページやボット確認画面がある場合、REST リクエストに HTML ページが返されることがあります。REST API へのアクセスでは確認画面を無効にしてください。

**確認方法（どなたでも）：** `https://your-store.com/?rest_route=/` からは、403 ページやサイトのホームページではなく JSON が返される必要があります。
