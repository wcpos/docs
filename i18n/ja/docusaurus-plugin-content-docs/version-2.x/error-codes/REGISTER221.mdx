## このエラーの意味 {#what-this-means}

二台のデバイスが同じレジを開きました。店舗側ではすでに開いていたセッションが維持され、このデバイスはそのセッションに切り替わりました。

現在、両方の端末が同じドロワーの現金を集計しています。このデバイスに表示されている開始時の釣銭準備金とレジ係は、ここで入力したものではなく、もう一方のデバイスのものです。

## データへの影響 {#your-data}

データは失われていませんが、このデバイスが開始したセッションは使われなくなり、店舗側にすでにあったセッションが採用されました。切り替え前にここで記録した内容は、使われなくなったセッションに属しており、現在表示されているドロワーの合計には含まれません。

## トラブルシューティング {#troubleshoot}

1. レジパネルで開始時の釣銭準備金とレジ係の名前を確認してください。入力した内容と異なる場合は、もう一方のデバイスのセッションを使用しています。
2. 一つのドロワーに対して、二台のデバイスで一つのレジを使うのは通常の構成です。無料プラグインでは、すべてのデバイスが一つのレジを共有します。両方のデバイスの売上は同じドロワーに入り、現金の確認は一回だけ行うため、シフト終了前に誰が現金を数えてレジを閉じるかを決めてください。実際にはデバイスごとに別のキャッシュドロワーがある場合は、二つ目のカウンターに専用のレジを割り当ててください（WCPOS Pro）。[店舗、レジ、デバイス](../stores/registers-and-devices.mdx)を参照してください。
3. このデバイスで切り替え前に入金や出金を記録した場合、その記録は使われなくなったセッションに残っています。現在のセッションでもう一度記録してください。
4. **店舗管理者：** レジのセッションが繰り返し切り替わる場合、二台のデバイスがそのレジを使っています。一つのドロワーを共有している場合は正常です。WCPOS Pro で各カウンターに専用のドロワーがある場合は、店舗編集画面で二つ目のカウンター用のレジを追加し、そのデバイスの **レジを切り替え** から選択してください。
