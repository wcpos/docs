## このエラーの意味 {#what-this-means}

ホスティング環境のセキュリティフィルターが商品検索をブロックしています。

このホスティング環境のファイアウォールルールが、クエリ文字列に非 ASCII 文字や SQL に似た単語を含む REST リクエストを拒否しています。アクセント記号付きの商品名や、'select' や 'union' などの単語を含む検索は、通常の商品カタログ検索であっても 403 で失敗します。レジの他の機能は動作しますが、ルールが緩和されるまで検索は安定しません。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## 対処方法 {#troubleshoot}

1. クエリ文字列のファイアウォールルールで、店舗自身の REST 検索パラメーター（/wcpos/ および /wc/ ルート）を許可リストに追加するよう、ホスティング事業者に依頼してください。
2. OWASP CRS ベースのファイアウォールでは、通常、's' 引数と 'search' 引数に対する SQL インジェクション対策ルールが原因です。REST API ルートでは、これらの引数を対象から除外してください。
3. 「疑わしいクエリ文字列をフィルタリングする」設定のあるセキュリティプラグインでは、機能全体をオフにするのではなく、REST API を例外にする必要があります。
