## これが意味すること {#what-this-means}

このサイトではWooCommerceが有効になっていないため、WCPOSは接続できません。

WCPOSにはWooCommerceプラグインが必要です。サイト管理者にWooCommerceのインストールまたは再有効化を依頼してから、もう一度接続してください。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。問題が続く場合は、WordPressサイトの管理者にご相談ください。

## トラブルシューティング {#troubleshoot}

1. サイト管理者にWP Admin → プラグインを確認するよう依頼してください。WCPOSが接続するには、WooCommerceがインストールされ、有効になっている必要があります。
2. 更新の失敗によってWooCommerceが無効になった場合は、再度有効にしてエラーバナーが表示されないか確認してください。WooCommerce → ステータス → ログに、失敗の理由が記録されています。
3. WooCommerceが再び有効になったら、レジから再接続してください。
