## このエラーの意味 {#what-this-means}

スキャンまたは入力による検索で、一致する商品が見つかりませんでした。

よくある原因は、有効なフィルター、バーコードの未登録や別フィールドへの登録、初回同期の未完了です。

## データへの影響 {#your-data}

注文や商品のデータに影響はありません。

## トラブルシューティング {#troubleshoot}

**レジでの対応：**

1. まずフィルターを解除してください。カテゴリーや在庫のフィルターは、気づかないうちにすべての検索結果を絞り込みます（スキャンしたコードも同じ検索ボックスに入力されます）。
2. 商品名で検索してください。名前では表示されるのにスキャンで見つからない場合、店舗側のバーコードがスキャンした値と一致していません。検索語を入力した場合は、誤字や余分な空白がないか確認してください。
3. 新しく追加した商品の場合、ローカルのインデックスがまだ同期中の可能性があります。初回同期の完了を待ってから再試行してください。

**店舗側での対応：**

- バーコードが未登録の場合は、WP Admin で、以下の**バーコードフィールド**に指定されているフィールドにスキャンした値を追加してください。サイズや色などのバリエーションがある商品では、親商品ではなく、そのバリエーション自体に入力してください。商品を編集し、対象のバリエーションを展開します。
- すべてのスキャンで商品が見つからない場合、店舗側が誤ったフィールドを参照している可能性があります。**WP Admin > POS > 設定 > 一般 > バーコードフィールド**を確認してください。商品が実際にバーコードを保存しているフィールドを指定する必要があります（たとえば GTIN の `_global_unique_id`、`_sku`、`_barcode`）。
