## このエラーの意味 {#what-this-means}

更新機能に WCPOS Pro の更新をダウンロードする権限がありません。

この店舗の更新機能を再認証し、もう一度更新を確認してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。問題が続く場合は、WordPress サイトの管理者に相談してください。

## 対処方法 {#troubleshoot}

1. **WP Admin > POS > 設定 > ライセンス** を開きます。**ライセンスキー** フィールドが表示されている場合は、キーを入力して **有効化** を押してください。すでにライセンスが有効と表示されている場合は、まず WCPOS アカウントから完全なキーをコピーします（ページには短縮形しか表示されません）。その後、**無効化** を押し、キーを入力し直して **有効化** を押してください。
2. WP Admin → ダッシュボード → 更新から、もう一度更新を確認してください。
3. 認証が繰り返し失敗する場合は、サイトが更新サーバーへの送信リクエストをブロックしている可能性があります。外部への HTTPS 通信が制限されていないか、ホスティング事業者に確認してください。
