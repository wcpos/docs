## これが意味すること {#what-this-means}

セッションが終了したため、再度サインインする必要があります。

もう一度サインインしてください。データは失われていません。未送信の変更は、サインインすると送信されます。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。セッションが切れている間に保存した販売データは、失われずにデバイスに保持され、サインイン後に自動的に店舗へ送信されます。

## トラブルシューティング {#troubleshoot}

1. もう一度サインインしてください。WCPOSがWordPressのサインインウィンドウを自動的に開きます。閉じてしまった場合は、WCPOSが再度サインインを求めます。同じレジ係のアカウントでサインインしてください。
2. 再入力や再保存は不要です。送信待ちの販売データは、サインインすると自動的に送信されます。送信状況を確認するには、**店舗の状態 → データベース**を開いてください。**送信待ちの変更**の数が0になります。
3. 販売データが **「… 件の変更がサーバーに届いていません」** に表示されている場合は、その行の**もう一度送信**をタップしてください。
4. 有効期限が頻繁に切れる場合（毎日数回など）、通常はサイト側に原因があります。セキュリティプラグインがセッションの有効期間を短くしたり、トークンを消去したりしている可能性があります。店舗で使用しているセキュリティプラグインをサイト管理者に確認し、**WP Admin > POS > 設定 > ツール > ログ**を確認するよう依頼してください。拒否されたサインインとその理由が記録されています。
