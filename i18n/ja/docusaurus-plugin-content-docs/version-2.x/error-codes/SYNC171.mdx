## このエラーの意味 {#what-this-means}

WCPOS がこのデバイスのストレージを設定または削除できませんでした。

デバイスのストレージに空きを作り、WCPOS を再起動してください。ウェブ版では、ブラウザーがサイトのストレージを制限している場合もあります。プライベートウィンドウでは制限されます。失敗が続く場合はサポートにお問い合わせください。

## データへの影響 {#your-data}

これはストレージの問題であり、編集が拒否されたわけではありません。このデバイスのデータを消去しているときに発生した場合は、未送信の変更を含め、データの一部がすでに失われている可能性があります。最近の売上や変更が店舗側に表示されるか確認してください。繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使用して WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. デバイスの空き容量を確認し、他のファイルやアプリを削除して空きを作ってください。ディスクやブラウザーのストレージ割り当て量がいっぱいになると、ストレージのセットアップは実行できません。空きを作るためにブラウザーの「閲覧履歴データの削除」を使用しないでください。WCPOS の未送信の売上も削除されます。
2. WCPOS を再起動し、同じ操作をもう一度試してください。
3. ウェブ版では、ブラウザーがサイトの永続ストレージを許可しているか確認してください。プライベートウィンドウや、すべてのデータをブロックする設定では許可されません。
4. 失敗が続く場合は、**ログ** タブの **デバッグ情報をコピー** を使用してサポートにお問い合わせください。
