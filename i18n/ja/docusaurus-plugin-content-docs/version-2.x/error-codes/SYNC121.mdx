## このエラーの意味 {#what-this-means}

現在、店舗に接続できません。

対応は不要です。そのまま販売を続けてください。接続が復旧すると変更は自動的に送信されます。長く続く場合は、このデバイスの接続と、店舗のウェブサイトが表示されるかを確認してください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだない変更が保存されている可能性があります。店舗が応答するようになると、自動的に送信されます。

## トラブルシューティング {#troubleshoot}

1. そのまま販売を続けてください。売上はこのデバイスに保存され、店舗が応答するようになると自動的に送信されます。
2. 端末自体がオンラインか確認してください。このデバイスで他のウェブサイトを表示できますか？
3. 同じデバイスのブラウザータブで、店舗のウェブサイトを開いてください。そこでも表示できない場合は、POS ではなくサイトまたはホスティングが停止しています。
4. **このデバイスのネットワーク管理者向け：** サイトは表示できるのに POS がオフラインのままの場合は、VPN、ファイアウォール、広告ブロッカー、セキュリティプラグインなど、両者の間にある何かが API リクエストをブロックしています。ブラウザーの開発者ツール（ネットワークタブ）、またはデスクトップアプリの **詳細設定 → 開発者ツールの切り替え** で、失敗しているリクエストを確認できます。
