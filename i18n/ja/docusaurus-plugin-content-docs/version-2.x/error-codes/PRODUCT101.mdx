## このエラーの意味 {#what-this-means}

この商品の変更は、まだ店舗側に届いていません。

表示された理由を読み、指摘された内容を修正するか接続を確認してから、商品をもう一度保存してください。

## データへの影響 {#your-data}

この端末のデータを消去しないでください。店舗側にまだ届いていない変更が保存されている可能性があります。接続に失敗した場合は、再接続後に商品をもう一度保存してください。店舗側が編集を拒否した場合、この端末のデータは店舗側の内容に戻ります（[SYNC202](/error-codes/SYNC202) を参照）。そのため、原因を解消してから再度編集してください。繰り返し発生する場合は、**ログ**タブの**デバッグ情報をコピー**を使用して WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 表示された理由を読んでください。通常、ログ項目のエラー文には、接続の失敗、店舗側が拒否した値、店舗側で行われた編集との競合のいずれかが示されています。

**レジでの対応：**

- 接続の失敗：接続を確認し、商品をもう一度保存してください。
- 値の拒否：理由として指摘された内容を修正し、商品をもう一度保存してください。

**店舗側（WP Admin）での対応：** 編集が競合している場合は、商品を開いてレジの表示と比較し、正しい値を一度保存してください。

明確な理由がないまま保存が繰り返し失敗する場合は、**ログ**タブの**デバッグ情報をコピー**を使用してサポートにお問い合わせください。
