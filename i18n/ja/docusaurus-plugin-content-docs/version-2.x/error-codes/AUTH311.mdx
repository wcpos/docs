## これが意味すること {#what-this-means}

WCPOSが店舗側の接続先にアクセスできません。

WCPOSプラグインが有効になっていること（**WP Admin → プラグイン**）と、セキュリティプラグインがREST APIをブロックしていないことを確認するよう、サイト管理者に依頼してください。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。サイト管理者にお知らせください。

## トラブルシューティング {#troubleshoot}

**レジ側** — レジ係の方：サイト管理者にお知らせください。このデバイス上のデータへの影響はありません。

**店舗側** — サイト管理者の方：

1. WP Admin → プラグインで、WCPOSが有効になっていることを確認してください。
2. どちらのREST形式も機能しない場合は、セキュリティプラグイン、プロキシ、CDNがWCPOSのリクエストヘッダーを削除したり、RESTリクエストをブロックしたりしていないか確認してください。よくある原因は、ファイアウォールのルールや、セキュリティ強化のためにREST APIを無効にする設定です。
3. ホスティング環境によっては、パーマリンクを再保存する（設定 → パーマリンク → 変更を保存）と、見つからなかったRESTルートが復元されます。
