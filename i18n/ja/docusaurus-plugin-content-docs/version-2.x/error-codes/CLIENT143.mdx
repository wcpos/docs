## このエラーの意味 {#what-this-means}

検索で見つかるはずの商品が結果に含まれていませんでした。

画面で確認できる商品が検索に出てこない場合を除き、対応は不要です。その場合は WCPOS を再読み込みしてください。

定期的な自己チェックで、レコード自体に含まれる語句を使ってローカル検索インデックスを検索しましたが、そのレコードが返されませんでした。このため、検索結果が、このデバイスに実際に保存されている件数より少なかった可能性があります。アプリがインデックスを自動で再構築する場合もありますが、セッションごとに各リストにつき一度だけなので、必ず再構築されるとは限りません。

## データへの影響 {#your-data}

サイトのデータは変更されていません。問題は、このデバイスに保存済みのデータから作成されるローカル検索インデックスに限られます。再構築によってデータが失われることはありません。

## トラブルシューティング {#troubleshoot}

1. 画面で確認できる商品が検索に出てこない場合を除き、対応は不要です。販売は通常どおり続けられます。アプリがインデックスを自動で再構築する場合もありますが、セッションごとに各リストにつき一度だけなので、このコードが繰り返し表示される場合は次の手順に進んでください。
2. 商品、顧客、注文などのリストで、アプリ上に表示されているレコードが検索に出てこない場合は、アプリを再読み込みしてください。ウェブ版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じて開き直します。次に問題が検出されたときに、改めて再構築を試みられるようになります。
3. 再読み込み後にコードが再び表示される場合は、**ログ**タブの**デバッグ情報をコピー**を使って、サポートにお問い合わせください。ログには、影響を受けたリストとインデックスで見つからなかったレコードを特定するために必要な情報が含まれています。
