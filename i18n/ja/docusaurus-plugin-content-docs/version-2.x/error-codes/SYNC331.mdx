## このエラーの意味 {#what-this-means}

この端末にあるレコードのコピーが店舗側と一致しません。入力した内容への影響はありません。

**店舗の健全性 → データベース** で、該当する一覧の **消去して再ダウンロード** を使い、この端末のコピーを店舗側のデータに置き換えてください。それまでは、レコードに古い価格や在庫が表示される可能性があります。まず送信待ちの変更がないことを確認してください。トラブルシューティングを参照してください。

## データへの影響 {#your-data}

販売データや未送信の変更への影響はありません。この端末にあるレコードのコピーは、置き換えられるまで古い価格や在庫を表示する可能性があります。繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使って、WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. そのまま販売を続けてください。**店舗の健全性 → データベース** を開くと、上部にレコード名が表示されます。コピーが一致しないレコードには **「…を店舗からダウンロードできません」**、店舗側で削除されたレコードには **「…をこの端末から削除する必要があります」** と表示されます。
2. その商品を販売する前に、価格や在庫を売り場の表示・現物と照合するか、店舗の管理担当者に確認してください（担当者は WP Admin と照合できます）。
3. 何かを消去する前に、**店舗の健全性 → データベース** で **送信待ちの変更** が 0 であり、**「…件の変更がサーバーに届きませんでした」** や **「…件の変更が保留されました」** のパネルが表示されていないことを確認してください。それらの変更はこの端末にしか存在せず、該当する一覧を消去すると失われる可能性があります。件数が 0 になるのを待ち、表示されている変更があれば先に解決してください（[SYNC201](/error-codes/SYNC201)、[SYNC221](/error-codes/SYNC221)）。**注文** を消去する前には、この端末で開いているすべてのカートを **サーバーに保存** で保存するか、販売を完了してください。店舗側に一度も保存されていないカートはこの端末にしか存在せず、これらの確認項目の件数にも含まれないため、**注文** を消去すると失われます。保存できないカートがある場合は、**注文** の行を操作せず、サポートにお問い合わせください。次に、レコードが含まれる一覧（たとえば **商品**）の **⋮** メニューを開き、**消去して再ダウンロード…** を選択してください。端末内のコピーが破棄され、店舗側のデータが取得されます。店舗側で削除されたレコードは端末からも削除されます。次のバックグラウンド確認までログ項目が表示されたままになる場合があるため、価格と在庫が一致するようになったかどうかで判断してください。その後、通知に別の一覧のレコードが表示された場合は、その一覧でも先に確認事項を確かめてから、この手順を繰り返してください。
4. **サイト管理者の方へ：** 再ダウンロード後も同じレコードが繰り返し表示される場合、通常は WooCommerce の保存フックを経由しない一括変更が原因です。CSV インポート、移行プラグイン、WP-CLI、SQL の直接実行などが該当します。レジの確認処理の正確さを保つため、できるだけ WooCommerce を通じて編集してください。同じ差異が繰り返し検出されると、WCPOS は整合性確認用のデータを自動で再構築します。
5. 再ダウンロード後もレジに誤った価格や在庫が表示される場合は、**ログ** タブの **デバッグ情報をコピー** を使って、サポートにお問い合わせください。
