## このエラーの意味 {#what-this-means}

このレシートの自動印刷が開始されませんでした。

販売は保存されています。注文のレシートを開き、**レシートを印刷**をタップしてください。その後、次のレシートが自動で印刷されるように、自動印刷の設定とプリンターを確認してください。

## データへの影響 {#your-data}

販売は保存されています。注文や商品のデータに影響はありません。

## トラブルシューティング {#troubleshoot}

1. 販売後に表示されるレシートで**レシートを印刷**を押して、手動で印刷してください。販売に影響はありません。レシートが画面に表示されていない場合、WCPOS Pro では**注文**を開き、その注文の**レシート**アクションを使用して**レシートを印刷**を押してください。
2. 販売後にまったく印刷されない場合は、自動印刷がオフになっている可能性があります。カートの設定（カート上部のスライダーアイコン）を開き、**チェックアウト後にレシートを自動印刷**をオンにしてください。**チェックアウト後にレシートを自動表示**のオン・オフにかかわらず印刷されます。
3. **設定 → 印刷**でプリンターを確認してください。目的のプリンターが**プリンター**に表示され、その**編集**画面で**テスト印刷**を実行すると印刷されることを確認します。
4. **レシートを印刷**も失敗する場合は、プリンターまたは接続の問題です。[PRINT301](/error-codes/PRINT301) を参照してください。手動印刷は成功するのに、設定をオンにしても自動印刷が繰り返し失敗する場合は、**ログ**タブの**デバッグ情報をコピー**を使用してサポートにお問い合わせください。
