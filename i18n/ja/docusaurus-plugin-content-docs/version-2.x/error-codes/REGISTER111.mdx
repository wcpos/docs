## このエラーの意味 {#what-this-means}

確認画面の**元に戻す**、またはレジパネルの**無効化**で入金や出金を取り消しましたが、店舗側が取り消しを拒否しました。

レジには移動が取り消されたと表示されますが、店舗側では引き続き計上されています。

## データへの影響 {#your-data}

失われたものはありません。元の移動は店舗側にそのまま残り、取り消しはこの端末にのみ存在するため、ドロワーの予定残高が両者でその移動額だけ異なります。

## トラブルシューティング {#troubleshoot}

1. レジパネルの入金・出金一覧を開いてください。取り消しの対象となった移動が、店舗側で引き続き計上されている移動です。
2. 移動を取り消せるのは一度だけで、そのセッションが開いている間に限られます。現金の集計が始まると、店舗側は仕様として取り消しを拒否します。これにより、集計中のシフトの内容が変わることを防ぎます。
3. 誤って取り消した場合は、何もする必要はありません。店舗側には取り消しが反映されていません。
4. **帳尻を合わせるために逆方向の移動を記録しないでください。** 新しい移動は店舗側*と*このレジの両方に届くため、両方の残高が同額だけ変わり、差額はそのまま残ります。店舗側の金額が正しい金額です。
5. レジの現金を集計するまでは、レジに表示される予定現金残高はその金額だけずれたままになります。不明な差異とならないよう、集計時に差額の理由を記録してください。
