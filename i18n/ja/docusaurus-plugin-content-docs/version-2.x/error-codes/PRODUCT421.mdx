## このエラーの意味 {#what-this-means}

この商品のバリエーション価格データを読み込めなかったため、価格が正しく表示されないか、表示されない可能性があります。

WooCommerce で商品を保存し直して価格データを再構築してください。多くの商品で発生する場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

注文や商品のデータに影響はありません。問題が続く場合は、店舗の管理者に確認してください。

## トラブルシューティング {#troubleshoot}

**レジでの対応：** 販売前に価格を確認してください。価格がおかしい、または表示されない場合は、店舗側で修正されるまでその価格で販売しないでください。

**店舗側（WP Admin）での対応：**

1. 商品を開いて保存し直してください。POS が読み込めなかった価格データが再構築されます。
2. 各バリエーションに価格が設定されていることを確認してください。価格のないバリエーションがあると、価格帯のデータが読み込めなくなります。
3. 多くの商品でこのコードが一斉に表示される場合、価格設定プラグインが POS の読み込めない形式で価格データを書き込んでいる可能性があります。価格を管理するプラグインを控えて、サポートにお問い合わせください。
