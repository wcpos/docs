## このエラーの意味 {#what-this-means}

支払いは成功しましたが、その後 WCPOS が状態を更新できませんでした。

支払いは完了しています。再度請求しないでください。注文を開き直して状態を更新してください。それでも古い状態が表示される場合は、以下の手順で更新してください。

## データへの影響 {#your-data}

支払いは受領済みです。再度請求しないでください。画面上の状態だけが古いままです。

## 対処方法 {#troubleshoot}

1. お客様に再度請求しないでください。店舗側で支払いは確認済みです（**注文 #… の支払いが完了しました** というトースト通知が表示された場合、それが確認の通知です）。失敗したのは、その後のレジ側の更新だけです。
2. 注文を開き直して状態を更新し、次の販売に進んでください。
3. 支払い済みの注文がカートに未完了のまま表示される場合は、レジ側のコピーを更新してください。**店舗の状態 → データベース** を開き、**注文** 行の **⋮** メニューから **今すぐ変更を確認** を選びます。支払い済みの状態を受信すると、注文はカートから消えます。WCPOS Pro では、その注文だけを更新することもできます。**注文** で対象の注文の **⋮** メニューを開き、**同期** を選んでください。
4. それでも未完了と表示される場合は、アプリを再読み込みしてください（Web ではブラウザーのタブを再読み込みし、デスクトップとモバイルではアプリを閉じて開き直します）。起動時に、レジは支払いを記録済みの販売を完了させます。
5. **サイト管理者の方へ：** 確認のため、**WooCommerce → 注文** で注文を開いてください。そこでは支払い済みと表示されます。
