## このエラーの意味 {#what-this-means}

サーバーのクロスオリジン（CORS）設定に問題があるため、ブラウザーが応答を拒否しています。

サイトは応答していますが、CORS 応答ヘッダーに重複、誤ったオリジンの指定、エラー応答での欠落などの問題があります。そのためブラウザーは実際の応答をウェブアプリに渡さず、他のエラーもすべて一般的なネットワーク障害としてしか見えなくなります。サーバー側で、すべてのステータスコードの応答に Access-Control-Allow-Origin が必ず一つだけ含まれるように修正してください。

## データへの影響 {#your-data}

注文や商品のデータには影響しません。

## トラブルシューティング {#troubleshoot}

1. CORS を処理する層が重複していないか確認し（プラグインとサーバー設定の両方でヘッダーを追加している場合など）、片方を削除してください。Access-Control-Allow-Origin が重複すると、ブラウザーで致命的なエラーになります。
2. nginx では、add_header 行の末尾に 'always' がないと、エラー応答には適用されません。4xx/5xx の応答にも CORS ヘッダーが必要です。
3. CDN やプロキシが CORS ヘッダーを追加している場合は、WordPress 自体のヘッダーと競合しないことを確認してください。
4. デスクトップアプリとモバイルアプリは CORS を使用しないため、修正作業中も利用できます。
