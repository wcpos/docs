## これが意味すること {#what-this-means}

検索結果に商品と一致しない項目が含まれていたため、WCPOSがそれらを非表示にしました。

検索結果にまだ問題がある場合を除き、対応は必要ありません。その場合はWCPOSを再読み込みしてください。

検索にすばやく応答するため、WCPOSは商品、顧客、注文などの検索対象リストのローカル検索インデックスを保持しています。自己診断で、入力した内容と一致しないエントリーがそのインデックス内に見つかりました。一致しない検索結果はすぐに非表示になりました。アプリが自動的にインデックスを再構築することもありますが、各リストにつきセッションごとに1回だけなので、必ず再構築されるとは限りません。

## データへの影響 {#your-data}

店舗のデータは変更されていません。この問題の対象は、このデバイスのデータから作成されたローカル検索インデックスのみです。一致しない検索結果を非表示にすると検索結果の表示は変わりますが、元のレコードは変更されません。

## トラブルシューティング {#troubleshoot}

1. 検索結果にまだ問題がある場合を除き、対応は必要ありません。通常どおり販売を続けられます。確認する場合は、ログエントリーに記録された検索をもう一度実行してください（詳細に検索語が記録されています）。入力内容と検索結果が一致し、表示されるはずの項目が欠けていないことを確認してください。
2. 検索結果にまだ誤りがある場合や、存在するはずの商品、顧客、注文が見つからない場合は、アプリを再読み込みしてください。Web版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じて開き直します。次に問題が検出されたとき、新しいインデックスの再構築が試みられます。
3. 再読み込み後にコードが再び表示される場合は、ログタブの**デバッグ情報をコピー**を使ってサポートに問い合わせてください。ログエントリーの詳細には、影響を受けたリストと原因となった検索が記録されています。
