## このエラーの意味 {#what-this-means}

今回は一部のデータが同期されませんでした。

このコードには2つの形式があり、ログ行のタイトルでどちらかを確認できます。

- **「一部のみ同期されました」** （レコード名付き）：一部のレコードは同期されましたが、記載されたレコードは同期されませんでした。次回の同期で解消する場合は対応不要です。**店舗の健全性 → データベース** に対応が必要な変更が表示されている場合は、そこで解決してください。
- **「停止したデータリクエストを中止しました」**：同期エンジンのデータリクエスト処理で、あるリクエストが進まなくなりました。そのため、十分な時間待った後、後続のリクエストすべてが止まらないように、アプリがそのリクエストを中止しました。同期エンジンが自動でリクエストを再発行するため、手動で再試行する必要はありません。ローカルデータベースの呼び出しが停止した後に発生することが多く、その停止は [SYNC181](/error-codes/SYNC181) として別途記録されます。

## データへの影響 {#your-data}

この端末のデータを消去しないでください。店舗側にまだ届いていない変更が残っている可能性があります。データリクエストが中止された場合、データに変更はなく、リクエストは自動で再発行されます。繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使って、WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. **「停止したデータリクエストを中止しました」** というログ項目の場合、画面が停止したままでなければ対応は不要です。停止したままの場合は、アプリを再読み込みしてください。ウェブ版ではブラウザーのタブを再読み込みし、デスクトップ版やモバイル版ではアプリを閉じて再度開いてください。
2. 一部のみ同期された場合、次回の同期で解消すれば対応不要です。解消しない場合は、**店舗の健全性 → データベース** を開いてください。まだ同期されていないレコードが上部に表示されます。**「…件のレコードに対応が必要です」** の通知には最初のレコードとその理由が表示されます（解決すると次のレコードが表示されます）。また、**「…件の変更がサーバーに届きませんでした」** と **「…件の変更が保留されました」** のパネルには、それぞれ該当する変更が表示されます。同期済みのレコードへの対応は不要です。
3. 一覧にある各レコードについて、表示された理由に応じて解決してください。通知に **レコードを修正** が表示されている場合は、それを使ってレコードを開き、編集できます。拒否された変更はレコード自体を修正してください（[SYNC201](/error-codes/SYNC201)）。保留された変更は、どちらのデータを残すか選択してください（[SYNC221](/error-codes/SYNC221)）。
4. その後、再送信してください。通知の **再試行**（同期が実行されます）、またはパネル内のレコード行の **再送信** を使います。通知に *店舗からダウンロードできません* と表示されるレコードには **再試行** はありません。[SYNC331](/error-codes/SYNC331) を参照してください。
5. それでもレコードが同期されない場合は、**ログ** タブの **デバッグ情報をコピー** を使って、サポートにお問い合わせください。
