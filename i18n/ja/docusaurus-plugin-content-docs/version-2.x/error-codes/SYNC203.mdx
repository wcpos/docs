## このエラーの意味 {#what-this-means}

店舗側にこの注文がなくなったため、このデバイスにあるコピーを処理しました。

このデバイスが注文を保持している間に、誰かが WP Admin でその注文を削除しました（ゴミ箱に移動しました）。店舗側のコピーがなくなったため、このデバイスではカートを新しい注文として保持するか、デバイス上のコピーを削除します。

## データへの影響 {#your-data}

未完了のカートは保持され、新しい番号の新規注文として再送信されます。次に **チェックアウト** を押すと送信されます。それ以外の注文は、店舗側のコピーがなくなったため、このデバイスから削除されます。他に送信待ちとなるものはありません。

## トラブルシューティング {#troubleshoot}

1. ログを展開してください。店舗側で削除された注文番号と、このデバイスがカートを新しい注文として保持したのか、コピーを削除したのかが記載されています。
2. カートが保持された場合は、通常どおり販売を続けられます。**チェックアウト** を押すと、新しい番号の新規注文として店舗に届きます。
3. 注文が誤って削除された場合は、店舗管理者が WP Admin の **WooCommerce → 注文 → ゴミ箱** から復元できます。このデバイスでは、次回の更新時に再び取得されます。
4. 同じ注文が繰り返し報告される場合は、管理者がこのデバイスでまだ使用中の注文を削除しています。ゴミ箱に移動する前に、誰が未完了のカートを閉じるかを決めてください。
