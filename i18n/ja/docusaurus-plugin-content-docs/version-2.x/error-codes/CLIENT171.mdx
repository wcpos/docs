## このエラーの意味 {#what-this-means}

このデバイスの時計とサイトの時計に一分を超えるずれがあります。

このデバイスの日時を自動更新に設定してください。すでに自動更新になっている場合は、サイト管理者にサーバーの時計の確認を依頼してください。

WCPOS は、デバイスの時計と、サイトのサーバーが応答で返す時刻を比較します。一分を超えるずれがあると、両方の時計が一致するまで、注文時刻、レシート、レポートの時刻が不正確になる可能性があります。

## データへの影響 {#your-data}

売上は引き続き保存されます。時計が一致していない間は、記録される時刻だけが不正確になる可能性があります。

## トラブルシューティング {#troubleshoot}

1. ログの項目を展開してください。両方の時計のずれの大きさと、どちらが進んでいるかが表示されます。
2. デバイスの日時設定を開き、時刻とタイムゾーンの自動設定（ネットワークによる設定）を有効にしてください。
3. **サイト管理者の方へ：** デバイスがすでに自動更新に設定されていて、時刻も正しい場合は、サーバーの時計がずれています。ホスティング事業者にサーバーの日時とタイムゾーンの確認を依頼してください。
4. 修正後に WCPOS を開き直してください。サイトを開くたびに時計が比較され、一致すると警告が表示されなくなります。
