## このエラーの意味 {#what-this-means}

変更は店舗側に届きましたが、この端末では送信済みとして記録できませんでした。

対応は不要です。再入力しないでください。WCPOS が確認を続け、店舗側は重複した送信を無視します。

販売データや編集内容は店舗側に届き、保存されています。その後、この端末は変更を送信済みとして記録しようと続けて3回試みましたが、できませんでした。そのため、この端末では変更が未送信のままに見え、WCPOS は次回の同期で再送信します。店舗側は ID で変更を識別し、重複した送信を無視するため、二重に保存されることはありません。実際に注意が必要なのは、販売データや編集内容を手作業で再入力することです。再入力すると、別のデータとして重複が作成されます。

## データへの影響 {#your-data}

データは失われていません。変更はすでに店舗側に保存されています。この端末で再送信が記録されるまでは、送信待ちの件数に含まれることがあります。

## トラブルシューティング {#troubleshoot}

1. 販売データや編集内容を手作業で再入力しないでください。すでに店舗側に保存されており、再入力すると重複します。
2. 販売データが店舗側に届いたかを確認するには、WP Admin の **WooCommerce → 注文** を確認してください。この端末にも保存されているため、WCPOS にも表示されます。
3. WCPOS が同期するのを待ってください。次の再送信は店舗側で無視され、通常はこれでログに記載された問題が解消します。解消すると、**店舗の健全性 → ログ** のヘッダーにある **送信待ちの変更** の件数が減ります。
4. これが繰り返し表示される場合、端末内のストレージへの保存に問題がある可能性があります。ストレージの空き容量を確認し、**ログ** タブの **デバッグ情報をコピー** をタップして、サポートにお問い合わせください。解決のためにこの端末のデータを消去しないでください。
