## このエラーの意味 {#what-this-means}

印刷で予期しない問題が発生しました。販売に影響はありません。

このログ項目に記載されている印刷またはレシートの操作を再実行してください。繰り返し発生する場合はサポートにお問い合わせください。

## データへの影響 {#your-data}

販売に影響はありません。

## トラブルシューティング {#troubleshoot}

1. まずログ項目を展開し、失敗した操作を特定してください。このコードは紙への印刷だけでなく、レシートメールのキュー操作やレシートテンプレートの同期も対象です。
2. ログに記載された操作だけを再実行してください。注文画面から再印刷するのは、紙への印刷を試みた場合だけです。キュー内のメールは「店舗の状態」から再送信し、テンプレートの同期は接続中にレシート画面を開き直して再試行してください。
3. その操作が繰り返し失敗する場合は、**ログ**タブの**デバッグ情報をコピー**を使用してサポートにお問い合わせください。
