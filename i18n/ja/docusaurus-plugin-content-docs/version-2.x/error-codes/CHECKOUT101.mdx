## このエラーの意味 {#what-this-means}

会計が完了しませんでした。カートは保持されているため、安全にやり直せます。

カートを確認し、会計をやり直してください。現在のカートの内容は保持されています。

## データへの影響 {#your-data}

注文自体は安全に保持され、変更されていません。

## 対処方法 {#troubleshoot}

**レジでの対応** — レジ係の方：

1. カートの内容は変更されていません。確認して、もう一度会計を試してください。
2. 再び失敗する場合は、店舗の状態 → ログで該当項目を展開してください。serverCode とステータスから、店舗が注文を拒否したかどうかと、その理由がわかります。
3. 理由に特定の明細項目が示されている場合は、その項目を削除して販売を完了し、後でその商品を調べてください。

**店舗側での対応** — サイト管理者の方：500 番台のステータスで失敗が繰り返される場合は、サイト側の問題です。WooCommerce → ステータス → ログで、失敗した時刻に PHP エラーがないか確認してください。
