## このエラーの意味 {#what-this-means}

このレシートをメール送信またはダウンロードできませんでした。

販売は保存されています。メールアドレス、または PDF の場合は端末の空き容量を確認し、レシートから再試行してください。すべてのメール送信が失敗する場合は、サイト管理者に店舗のメール送信機能の確認を依頼してください。

## データへの影響 {#your-data}

販売は保存されており、変更されていません。

## トラブルシューティング {#troubleshoot}

1. ログ項目を展開してください。メールアドレスが表示されていればメール送信の失敗、それ以外は PDF の処理（作成、ダウンロード、保存、共有）の失敗です。
2. メール送信の場合は、アドレスと接続を確認し、レシートから再送信してください。すべてのメール送信が失敗する場合は、サイト管理者に店舗の送信メールと SMTP 設定の確認を依頼してください。
3. PDF の処理に失敗した場合は、端末の空き容量を確認し、レシートの「PDF をダウンロード」を再試行してください。ダウンロードの権限を確認し、書き込み可能な保存先か、利用可能な別の共有先を選択してください。
