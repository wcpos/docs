## このエラーの意味 {#what-this-means}

決済端末と WCPOS のペアリングが完了しませんでした。

通常は接続またはペアリング状態の問題です。決済端末がスリープ中、Bluetooth やネットワークの通信範囲外、または別のレジとペアリングされたままになっています。スリープを解除し、通信範囲内に移動して、ペアリングをやり直してください。決済サービス事業者に問い合わせる場合は、トレース ID を添えてください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。問題が続く場合は、決済サービス事業者にお問い合わせください。

## 対処方法 {#troubleshoot}

1. 決済端末をスリープさせず、レジと同じネットワークに接続した状態で、端末側のペアリングをやり直してください。
2. まず基本事項を確認してください。決済端末が充電されているか、正しいネットワークまたは Bluetooth に接続されているか、別のレジとペアリングされたままになっていないかを確認します。
3. ログにはトレース ID が記載されています。それでもペアリングが完了しない場合は、決済サービス事業者への問い合わせにその ID を添えてください。
