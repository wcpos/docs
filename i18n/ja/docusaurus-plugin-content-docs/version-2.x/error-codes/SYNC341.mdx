## このエラーの意味 {#what-this-means}

この店舗では、より新しいバージョンの POS アプリが必要になりました。

店舗側の WCPOS プラグインが、このバージョンのアプリでは対応していない新しい同期プロトコルに移行したため、アプリが更新されるまで店舗側で意図的に同期を停止しています。これは不具合ではなく、古いアプリが店舗データを誤って読み書きするのを防ぐ保護機能です。WCPOS を更新し（ウェブ版ではページを再読み込みし）、再度開いてください。未送信の販売データはこの端末に残り、更新後に送信されます。

## データへの影響 {#your-data}

レジのデータは失われていません。送信待ちの販売データや編集内容は端末に安全に保持され、更新済みのアプリが店舗に接続すると同期されます。新しいアプリがまだ提供されていない場合（下記の最後の2つの手順を参照）は、提供されるまで送信待ちのまま保持されます。

## トラブルシューティング {#troubleshoot}

1. ウェブ版では、ブラウザーのタブを再読み込みしてください。再読み込みすると新しいバージョンが読み込まれます。同じ画面が再び表示される場合は、強制再読み込みを行ってください（**Shift** を押しながら再読み込みします）。
2. デスクトップ版では、利用可能な更新をインストールして、アプリを再度開いてください。再接続時に確認が行われます。更新が表示されない場合は、[インストール](/getting-started/installation)ページから最新のビルドをダウンロードしてください。
3. iPhone、iPad、Android では、インストール時に使用した配信元から WCPOS を更新し、アプリを再度開いてください。iOS では TestFlight、Android では Play のテストプログラムを使用します。どちらも[インストール](/getting-started/installation)ページにリンクがあります。
4. **サイト管理者の方へ：** 新しいアプリがまだ提供されていない場合、対応するアプリのリリースより先に、店舗側の WCPOS プラグインが更新されています。店舗側の WCPOS プラグインを以前のバージョンに戻すと、新しいアプリが提供されるまで同期を再開できます。
5. アプリの更新もプラグインを以前のバージョンに戻すこともできない場合は、WCPOS サポートにお問い合わせください。
