## このエラーの意味 {#what-this-means}

販売をキャンセルすると、注文に含まれる各支払いの取り消しを店舗に要求します。そのうち少なくとも一部が拒否され、店舗からその旨の応答が返されました。接続が切れたわけではありません。

その金額は、お客様のカードでまだ確保されているか、レジ内の現金として計上されたままです。「一部が返金された」だけでは店舗側が対処できないため、取り消せなかった支払いがログ行に明記されています。

## データへの影響 {#your-data}

金銭は移動済みで、まだ返金されていません。記載された支払いの金額は確保されたままで、手動で返金する必要があります。

## 対処方法 {#troubleshoot}

**レジでの対応** — お客様がお帰りになる前に行ってください：

1. ログ行の支払い ID を確認してください。それらが、まだ金額が確保されている支払いです。
2. お客様がお帰りになる前に、どの支払いが取り消され、どれがまだ取り消されていないかをお伝えください。
3. 拒否が一時的なものと思われる場合は、もう一度キャンセルを試してください。

**店舗側での対応** — サイト管理者の方へ：

1. WooCommerce で注文を開き、通常の払い戻し手順で、記載された支払いを払い戻してください。
2. 売上が確定されない与信枠の確保は、通常は自動的に解除されますが、その時期は銀行によって異なります。解除されたとお客様に伝える前に確認してください。
3. 記載されたすべての支払いの処理が解決するまで、販売が取り消されたものとして扱わないでください。
