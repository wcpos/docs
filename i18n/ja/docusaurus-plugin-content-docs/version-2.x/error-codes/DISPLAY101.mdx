## このエラーの意味 {#what-this-means}

お客様向けディスプレイで、表示するカートの内容を生成できなかったため、待機画面に戻りました。

レジ自体には影響しないため、接客を続けてください。次にカートが変更されるとディスプレイのスナップショットが再作成されるため、通常は明細を追加または削除するとすぐに復旧します。

## データへの影響 {#your-data}

注文や商品のデータには影響しません。販売内容も変更されません。カスタマーディスプレイは内容を映すためのもので、記録を保持するものではありません。

## トラブルシューティング {#troubleshoot}

1. 販売を続けてください。レジは引き続き動作し、カスタマーディスプレイだけが待機画面に戻ります。
2. カートの明細を追加または変更してください。次にカートが変更されるとディスプレイのスナップショットが再作成され、通常は自動的に復旧します。
3. カートを何度か変更しても待機画面のままの場合は、**設定 → カスタマーディスプレイ**の**ペアリング済みディスプレイ**に引き続き表示されているか確認し、ディスプレイのウィンドウを閉じて開き直してください。
4. 繰り返し発生する場合は、対象の注文を控え、ログ画面の**デバッグ情報をコピー**を使って、両方をサポートに送信してください。同じカートでスナップショットの作成に繰り返し失敗する場合は、通常、ディスプレイ自体ではなく、いずれかの明細に原因があります。
