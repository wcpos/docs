## このエラーの意味 {#what-this-means}

この注文の明細にはPOSで読み取れない価格情報があるため、その金額には保存済みの合計金額が使用されました。

WCPOSが注文に追加する各明細には、価格の算出方法についての簡単な記録が含まれています。記録されるのは、価格そのもの、税込みかどうか、税区分です。この記録を読み取れない場合、WCPOSは再計算せずに、明細にすでに保存されている合計金額を使用します。表示される金額は通常正しいものですが、正しいことが確認されてはいないため、支払いを受ける前に注文の合計金額を確認してください。

よくある原因は、非常に古いバージョンのWCPOSで追加された明細や、バックアップから復元された明細が、現在のバージョンでは認識されない形式になっていることです。

## データへの影響 {#your-data}

注文は安全で、データは失われていません。影響を受ける明細の金額だけが未確認です。

## トラブルシューティング {#troubleshoot}

**レジでの対応** — 支払いを受ける前に対応してください：

1. 注文の合計金額が想定どおりか確認してください。影響を受ける明細の金額には、再計算された価格ではなく保存済みの合計金額が使用されています。
2. 該当する明細行を削除し、商品、手数料、または配送方法をもう一度追加してください。新しく追加した明細行には常にアプリが読み取れる価格情報が含まれ、次の注文で通知が消えます。
3. 合計金額が正しくなかった場合は、明細行を追加し直すことで修正されます。変更前後の金額を比較してください。

**店舗側** — サイト管理者向け：

1. 古い注文や復元された注文ではなく、最近追加された明細行でこの問題が発生する場合、何らかの要因により、アプリで読み取れない形式でPOSの価格データが書き込まれています。
2. カートや注文の明細データを変更するプラグインがあれば記録してください。次に、**店舗の状態 → ログ** でログエントリーを開き、**コピー**（または **共有**）を使用して詳細を送信し、注文番号を添えてサポートにお問い合わせください。
