## このエラーの意味 {#what-this-means}

このデバイスでの保存または読み込みに非常に時間がかかっており、結果はまだわかっていません。

WCPOS が動作していれば、対応は不要です。画面が動かないままの場合は、WCPOS を再読み込みし、最後の変更が保存されているか確認してください。

このデバイスのローカルデータベースに対する単一の読み取りまたは書き込みが、通常よりはるかに長く応答を返していません。一方、他の処理には引き続き応答しています。この報告機能は停滞を記録するだけで、操作のキャンセルや再試行は行いません。そのため、元の呼び出しが後から完了したり失敗したりする可能性があります。このログは、画面や読み込み表示が動かなくなったときに、どの操作が停滞したのかを正確に残すためのものです。同期処理の停滞には別のタイムアウトと再試行の仕組みがあり、[SYNC321](/error-codes/SYNC321) の「応答のないデータリクエストを断念しました」というログに記録されます。画面からの呼び出しが停滞した場合は、処理が完了するかアプリが再読み込みされるまで保留のままです。

## データへの影響 {#your-data}

結果を確認できていません。再試行する前に確認してください。停滞した操作は通常、データを変更しない検索です。その時点で変更を保存していた場合は、レコードを開いて保存されたか確認してください。画面上では何も異常がなかった可能性もあります。ログのコンテキストには、対象の操作とデータコレクションが記載されています。

## トラブルシューティング {#troubleshoot}

1. WCPOS が動作していれば、対応は不要です。呼び出しは時間がかかっただけで、完了した可能性が高いです。ログに記載された操作が保存だった場合は、レコードを開いて保存されたか確認してください。
2. 画面や読み込み表示が動かないままの場合は、アプリを再読み込みしてください。ウェブ版ではブラウザータブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じて開き直します。これにより停滞した操作は打ち切られ、画面が再読み込みされてデータベースへの問い合わせが新たに行われます。処理中だった保存は再送されないため、レコードを開いて保存されたか確認してください。
3. 同じデバイスでこのコードが定期的に表示される場合は、**ログ** タブの **デバッグ情報をコピー** を使用してサポートにお問い合わせください。ログのコンテキストには、操作とコレクション、正確な待機時間、その間のデータベースの負荷が記載されています。
