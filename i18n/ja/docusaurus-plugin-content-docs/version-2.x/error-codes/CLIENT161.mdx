## このエラーの意味 {#what-this-means}

このタブでは現在レジが稼働していないため、新しい支払いリクエストは送信されませんでした。

ウェブ版では、レジを同時に稼働させられるブラウザータブは一つだけです。別のタブを開いた場合や、別のタブがレジを引き継いだ場合、このタブではレジが停止し、その旨が画面に表示されます。そのタイミングで開始しようとしていた支払いリクエストは送信前に拒否され、このログにはその拒否が記録されています。これは情報通知です。サイトやデバイスで障害が発生したわけではなく、すでに開始済みの支払いの結果を示すものでもありません。

## データへの影響 {#your-data}

この拒否による書き込みやデータの損失はありません。このデバイスに保存済みの売上、カート、注文には影響せず、通常どおり同期されます。カードリーダーでの処理中やサイトに売上確定リクエストを送信済みの場合など、すでに開始していた支払いは、この通知によって中断されません。現在レジを稼働させているタブで同期が完了すると、その結果が注文に記録されます。再度支払いを受け付ける前に、その注文を確認してください。

## トラブルシューティング {#troubleshoot}

1. このタブのレジ画面を確認してください。別のタブでレジが稼働しているかどうかが表示されます。このタブで続ける場合は**ここで引き継ぐ**を選択するか、もう一方のタブで操作を続けてください。
2. 画面に**再読み込み**が表示されている場合は、タブを再読み込みしてください。再読み込みが完了すると、このタブでレジが再開します。
3. すでに開始していた支払いを再試行する前に、注文を開いて支払い状況を確認してください。お客様がすでに済ませた支払いを二重に受け付けないようにします。
