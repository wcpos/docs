## このエラーの意味 {#what-this-means}

店舗側で支払いを受領し、注文に記録しています。その後に失敗したのは、レジ側に保存された注文のコピーを店舗側の記録に合わせて更新する処理だけです。

代金は確保され、販売も記録されています。支払いパネルの残額にはすでにこの支払いが反映されていますが、カートや注文一覧など、レジの他の画面は更新が追いつくまで古い状態を表示する場合があります。そのため、トースト通知では、支払いを再度受け取らないようレジ係に伝えています。

この問題が発生すると、WCPOS は直ちに店舗へ最新の注文データを要求するため、ほとんどの場合、レジの表示は数秒以内に自動で修正されます。

## データへの影響 {#your-data}

代金は移動済みで、店舗が受領しています。この支払いを絶対に再度受け取らないでください。古いのはレジに保存された注文のローカルコピーだけで、正しいのは店舗側の記録です。

## 対処方法 {#troubleshoot}

**レジでの対応** — お客様がお帰りになる前に行ってください：

1. 支払いを再度受け取らないでください。
2. 支払いパネルに表示されている残額に従って処理を続けてください。この支払いはすでに反映されています。残額があればその分を受け取り、残額がなければ販売が完了します。
3. 注文を「開き直す」ために閉じるボタン（**X**）を使わないでください。支払いが記録されている注文を閉じると **支払いをキャンセル** が開き、更新ではなく返金が行われます。
4. 販売後もレジの表示が古いままの場合は、**店舗の状態 → データベース** を開き、**注文** 行の **⋮** メニューから **今すぐ変更を確認** を選んでください。

**店舗側での対応** — サイト管理者の方へ：

1. 店舗側では支払いを受領済みのため、修復する必要はありません。**WooCommerce → 注文** の注文には現在の状態が表示されます。
2. レジで自身のコピーの保存に繰り返し失敗する場合は、そのデバイスの **店舗の状態 → データベース** で **ストレージ使用量** の数値と、デバイスの空き容量が不足していないかを確認してください。ローカルデータベースがいっぱいになっているか、障害が起きている可能性があります。
