## このエラーの意味 {#what-this-means}

チェックアウトで予期しない問題が発生しました。

お客様に再度請求する前に、店舗の管理画面で注文を確認してください。問題が繰り返し発生する場合は、診断情報をエクスポートしてサポートにお問い合わせください。

## データについて {#your-data}

処理結果を確認できませんでした。再試行する前に結果を確認してください。問題が解消しない場合は、診断情報をエクスポートして WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. お客様に再度請求する前に、WP Admin の WooCommerce → 注文で該当する注文を確認してください。
2. ログの項目を展開し、イベントコードと、serverCode があればその値を控えてください。この汎用コードは、問題の原因に対応する専用のコードがまだないことを示します。
3. 問題が繰り返し発生する場合は、デバッグ情報をエクスポートしてサポートにお問い合わせください。
