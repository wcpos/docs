## これが意味すること {#what-this-means}

この店舗への安全な接続の信頼性を確認できませんでした。

正しい店舗アドレスを使用し、サイト管理者に証明書の修正を依頼してから再接続してください。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。問題が続く場合は、WordPressサイトの管理者にご相談ください。

## トラブルシューティング {#troubleshoot}

1. 同じデバイスのブラウザーで店舗のアドレスを開いてください。ブラウザーの鍵アイコンや警告ページに、証明書の具体的な問題（有効期限切れ、自己署名、別のドメイン用に発行された証明書など）が表示されます。
2. POSで使用しているアドレスを確認してください。https:// で始まり、証明書の対象ドメインと完全に一致している必要があります。wwwの有無も重要です。
3. サイト管理者またはホスティング事業者に証明書の更新や修正を依頼してください。最も多い原因は、気づかないうちに自動更新が失敗していることです。
4. セキュリティを無効にして証明書の警告を回避しないでください。証明書を修正してください。
