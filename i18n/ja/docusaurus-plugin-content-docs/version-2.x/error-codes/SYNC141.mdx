## このエラーの意味 {#what-this-means}

店舗側から WCPOS に、一時的にリクエストの頻度を下げるよう求められました。

対応は不要です。WCPOS はしばらく待ってから自動的に再試行します。毎日表示される場合は、店舗のレート制限についてサイト管理者に確認してください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだない変更が保存されている可能性があります。それらは後の再試行で送信されます。

## トラブルシューティング {#troubleshoot}

1. 対応は不要です。POS は間隔を空けて自動的に再試行します。手動で再試行すると、制限が長引くだけです。
2. 再入力は不要です。対象の変更はデバイスに残り、後の再試行で送信されます。
3. 毎日表示される場合は、セキュリティプラグイン、CDN やファイアウォールのルール、ホスティング側の制限のうち、どこが 429 を返しているかをサイト管理者に調べてもらい、POS の REST 通信を許可するよう依頼してください。
4. 展開したログのエンドポイントとタイムスタンプを使うと、管理者が自分のダッシュボードで該当する制限を照合できます。
