## このエラーの意味 {#what-this-means}

この店舗の WCPOS プラグインは古く、このバージョンのアプリに対応していません。

アプリは更新されましたが、店舗側の WCPOS プラグインが更新されていないため、両者が連携できなくなっています。サイト管理者に WP Admin で WCPOS プラグインを更新してもらい、再度接続してください。レジ側で変更する必要はありません。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。問題が続く場合は、WordPress サイトの管理者に相談してください。

## 対処方法 {#troubleshoot}

**店舗側での対応** — WordPress サイトの管理者の方：

1. WP Admin → プラグインで、WCPOS を最新バージョンに更新してください。WCPOS Pro がインストールされている場合は、同時に対応するバージョンへ更新してください。
2. 更新が表示されない場合は、WP Admin → ダッシュボード → 更新を確認してください。Pro では、更新プログラムが未認証だと更新がブロックされます（[LICENSE301](./LICENSE301) を参照）。まずその問題を解決してください。

**レジでの対応** — レジ係の方：店舗側の更新が完了したら再接続してください。店舗のアドレスを入力し直す必要はありません。

**店舗側をまだ更新できない場合：** サポートに連絡してください。レジにはプラグインに対応するバージョンのアプリが必要です。サポートが適切なバージョンをご案内します。問い合わせ時には、レジで確認できるアプリのバージョンと、WP Admin で確認できる店舗側の WCPOS の現在のバージョンが必要です。
