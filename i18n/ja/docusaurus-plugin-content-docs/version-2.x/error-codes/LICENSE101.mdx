## このエラーの意味 {#what-this-means}

この店舗またはデバイスでは、WCPOS Pro ライセンスが有効になっていません。

ローカル環境、ライセンスサーバー、更新機能の状態を確認し、表示された店舗のライセンスを有効化してください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。問題が続く場合は、診断情報をエクスポートして WCPOS サポートにお問い合わせください。

## 対処方法 {#troubleshoot}

**店舗側での対応** — サイト管理者またはライセンス所有者の方へ：

1. **WP Admin > POS > 設定 > ライセンス** を開きます。有効なライセンスには **「ライセンス … が有効化されました」** と表示され、それ以外の場合は **ライセンスキー** フィールドが表示されます。（代わりにアップグレードカードが表示される場合は、WCPOS Pro プラグインが有効になっていません。まず **WP Admin → プラグイン** で有効化してください。）
2. 有効になっていない場合は、WCPOS アカウントのキーを **ライセンスキー** に貼り付け、**有効化** を押します。
3. サイト URL を変更すると（http から https への変更、www の追加や削除、ドメインの移行、ステージング環境へのコピー）、ライセンスは古いアドレスに残ります。まず古いサイトで無効化してください。まだアクセスできる場合は古いサイトの **ライセンス** ページで、それ以外の場合は [WCPOS アカウントページ](https://wcpos.com/account/licenses)で操作します。古いサイトが存在しない場合は、**support@wcpos.com** にメールを送り、有効化のリセットを依頼してください。その後、このサイトの **ライセンスキー** に WCPOS アカウントの完全なキーを入力し、**有効化** を押します。ページにライセンスが有効と表示されている場合は、先に **無効化** を押してください（表示されているキーは短縮形で、**無効化** を押すと消去されます）。
4. ライセンスが有効と表示されるのに POS では認識されない場合は、まず WCPOS アカウントから完全なキーをコピーしてください（ページには短縮形しか表示されず、**無効化** を押すと消去されます）。その後、**無効化** を押し、**ライセンスキー** にキーを貼り付けて **有効化** を押します。
5. まだロックされていますか？レジの **店舗の状態 → ログ** で **デバッグ情報をコピー** を使い、ライセンスの識別情報を添えてサポートにお問い合わせください。

**レジでの対応：** ライセンスを有効化したら、アプリを再読み込みして変更を反映してください。
