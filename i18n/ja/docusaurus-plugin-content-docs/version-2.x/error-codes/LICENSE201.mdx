## このエラーの意味 {#what-this-means}

WCPOS とバージョンが一致しないため、WCPOS Pro が無効になっています。

表示された WCPOS または WCPOS Pro のコンポーネントを更新し、両方のバージョンに互換性がある状態にしてください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。問題が続く場合は、WordPress サイトの管理者に相談してください。

## 対処方法 {#troubleshoot}

1. WP Admin → プラグインで両方のプラグインのバージョンを確認してください。ログには WCPOS と WCPOS Pro のどちらが古いかが記載されています。
2. 古い方を更新してください。両方を最新バージョンに更新すると、不一致が解消されます。
3. Pro の更新が表示されない場合は、更新機能が認証されていない可能性があります（LICENSE301 を参照）。先にその問題を解決してから更新してください。
