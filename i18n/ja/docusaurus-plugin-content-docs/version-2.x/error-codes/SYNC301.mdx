## このエラーの意味 {#what-this-means}

店舗側の変更一覧が予期せず変動したため、WCPOS が自動で再確認しています。データは失われていません。

対応は不要です。そのまま販売を続けてください。WCPOS が店舗側の変更を自動で再確認します。価格や在庫がまだ古いままの場合は、**店舗の健全性 → データベース** の **今すぐすべて確認** をタップしてください。

## データへの影響 {#your-data}

データは失われておらず、この端末のデータが失われるおそれもありません。再確認が完了するまでは、この端末に表示される一部の価格や在庫が古いままの場合があります。

## トラブルシューティング {#troubleshoot}

1. そのまま販売を続けてください。この端末のデータは失われておらず、再確認は自動で行われます。ログ項目には、店舗側の一部の変更がスキップされた、変更一覧が以前の状態に戻ったなど、何が変動したかが記載されている場合があります。どちらの場合も、対象となるデータの種類は限定されません。
2. 価格や在庫がまだ古いままの場合は、**店舗の健全性 → データベース** を開き、**今すぐすべて確認** をタップしてください。
3. 確認後もレコードが正しくない場合や、このコードが繰り返し表示される場合は、**ログ** タブの **デバッグ情報をコピー** を使って、サポートにお問い合わせください。解決のためにデータを消去しないでください。
