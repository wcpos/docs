## このエラーの意味 {#what-this-means}

選択したプリンターに接続できません。

プリンターの電源が入っていて接続されていることを確認し、もう一度印刷してください。

## データへの影響 {#your-data}

注文や商品のデータに影響はありません。

## トラブルシューティング {#troubleshoot}

1. プリンターの電源が入っていて、ケーブルやネットワークが確実に接続されていることを確認してください。
2. プリンター本体でセルフテストを印刷してください（操作方法はマニュアルを参照）。ほとんどのネットワークプリンターでは、セルフテストページに現在の IP アドレスも表示されます。
3. ネットワークプリンターの場合は、レジとプリンターが同じネットワークに接続されていることを確認してください。次に、**設定 → 印刷**を開き、**プリンター**にある対象プリンターの**編集**を押して、**IP アドレス**がセルフテストページと一致することを確認してください（ページにポートが表示されている場合は**ポート**も確認します）。再起動後、ルーターがプリンターに新しいアドレスを割り当てることがあります。設定を修正するか、**ネットワークをスキャン**を使用してください。変更はその都度保存されます。
4. **設定 → 印刷**でプリンターの**編集**画面を開き、**テスト印刷**を押してから、レシートをもう一度印刷してください。
