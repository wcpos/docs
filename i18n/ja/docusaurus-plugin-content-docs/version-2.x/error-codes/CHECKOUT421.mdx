## これが意味すること {#what-this-means}

この注文は店舗に存在しない税率を参照しているため、税額が誤っている可能性があります。

注文の明細行に、店舗の現在の税率テーブルにない税率が指定されています。ほとんどの場合、注文開始後にWooCommerceでその税率が削除または編集されたことが原因です。WCPOSは税率を検索できないため、この注文の税額は現在店舗で適用される金額と一致しない可能性があります。

## データへの影響 {#your-data}

注文自体に問題はありません。確認が必要なのは税額だけです。支払いを受ける前に確認し、税率について店舗管理者に問い合わせてください。

## トラブルシューティング {#troubleshoot}

**レジ側** — 支払いを受ける前に次の操作を行ってください：

1. 注文の税額を確認してください。店舗に現在存在しない税率を使って計算されています。
2. 税額が誤っているようであれば、新しい注文で販売を開始してください。新しい注文には店舗の現在の税率が適用されます。

**店舗側（WP Admin）** — サイト管理者向け：

1. **WooCommerce → 設定 → 税**に移動し、最近税率が削除または編集されていないか確認してください。未完了の注文が参照している税率を削除したことが、通常の原因です。
2. 税率を意図的に削除した場合、その時点で未完了だった注文を新しく作り直せば、ほかに対応は必要ありません。
3. 店舗の税率が変更されていない場合、POSに古いデータが残っている可能性があります。**店舗の状態 → データベース → 税率 → クリアして再ダウンロード**から更新してください。この操作は該当するデータだけに影響し、ログアウトは発生しません。[店舗の状態](/troubleshooting/store-health#clear-and-redownload)を参照してください。
4. 税率のダウンロード完了後にコードが再び表示された場合は、**店舗の状態 → ログ**でログエントリーを開き、**コピー**（または**共有**）を使って詳細を送り、注文番号を添えてサポートに問い合わせてください。
