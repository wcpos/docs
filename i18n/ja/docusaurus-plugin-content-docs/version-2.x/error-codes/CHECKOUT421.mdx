## これが意味すること {#what-this-means}

この注文は店舗に現在存在しない税率を参照しているため、税額が正しくない可能性があります。

注文の明細に、店舗の現在の税率テーブルに存在しない税率が設定されています。ほとんどの場合、注文の作成後にWooCommerceでその税率が削除または編集されたことが原因です。WCPOSはその税率を参照できないため、この注文の税額は、店舗が現在適用する税額と一致しない可能性があります。

## データへの影響 {#your-data}

注文データは安全です。確認が必要なのは税額だけです。支払いを受け付ける前に税額を確認し、税率について店舗管理者に問い合わせてください。

## トラブルシューティング {#troubleshoot}

**レジ側** — 支払いを受け付ける前に、次の手順を行ってください：

1. 注文の税額を確認してください。店舗に現在存在しない税率で計算されています。
2. 税額が正しくないと思われる場合は、新しい注文で販売をやり直してください。新しい注文には、店舗の現在の税率が適用されます。

**店舗側（WP Admin）** — サイト管理者向けの手順：

1. **WooCommerce → 設定 → 税**に移動し、最近、税率が削除または編集されていないか確認してください。通常は、未完了の注文が参照している税率を削除したことが原因です。
2. 税率を意図的に削除した場合は、その時点で未完了だった注文を作成し直す以外に、対応は必要ありません。
3. 店舗の税率が変更されていない場合は、POSに古いデータが残っている可能性があります。**店舗の状態 → データベース → 税率 → 消去して再ダウンロード**から更新してください。この操作の影響はそのコレクションだけに限られ、誰もログアウトされません。[店舗の状態](/troubleshooting/store-health#clear-and-redownload)を参照してください。
4. 税率のダウンロードが完了した後もこのコードが表示される場合は、**店舗の状態 → ログ**でログのエントリーを開き、**コピー**（または**共有**）を使って詳細を送り、注文番号を添えてサポートにお問い合わせください。
