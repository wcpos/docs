## これが意味すること {#what-this-means}

保存された店舗のセッション情報が不完全だったため、WCPOSは店舗一覧に戻りました。

WCPOSは、レジを前回の状態から再開できるように、使用していたサイト、レジ係、店舗を記憶します。今回はその記録の一部（通常はサイトまたはレジ係の情報）が欠けていたため、不完全なセッションで店舗を開かずに店舗一覧に戻りました。店舗を再度選択してサインインしてください。このチェックが導入される前は、この状態になると空白のウィンドウに「useStoreSession must be called within an active store session」という赤いバナーが表示され、先に進めませんでした。

通常、アプリが書き込んだ情報の一部をデバイスのローカルストレージが保持できなかったことを意味します。一度だけでも発生したことを記録しておいてください。同じデバイスで繰り返し発生する場合は、ストレージの問題を調査する必要があります。

## データへの影響 {#your-data}

消去されたのは、開いていたセッションへの参照情報だけです。同期を待っている販売データを含め、店舗のローカルデータはデバイスに残っています。

サイトまたはレジ係がまだ一覧にある場合は、同じ店舗を再度選択すると、同じローカルデータが使用されます。サイトの再追加が必要だった場合、レジは店舗の新しいローカルコピーを開きます。以前のセッションで同期を待っていた販売データはデバイスに残りますが、自動的には引き継がれません。未同期の販売データがあったことが分かっている場合は、ローカルデータを消去する前にサポートへお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. サイトと店舗を再度選択してサインインしてください。このデバイス上の店舗データは変更されていません。消去されたのは、記憶されていたセッション情報だけです。
2. サイトが一覧にない場合は、アドレスを再入力してサインインしてください。同期を待っていた販売データがあったことが分かっている場合は、先にサポートへお問い合わせください。上記の「データへの影響」を参照してください。
3. 同じデバイスで再発する場合、ローカルストレージがアプリの書き込んだ情報を保持できていません。ディスクの空き容量を確認し、ログ画面で同じ時間帯のストレージエラーを確認してください。
4. 繰り返し発生する場合は、デバッグ情報をエクスポートしてサポートへお問い合わせください。ログエントリーには、セッションのどの情報が欠けていたかが記載されています。
