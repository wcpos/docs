## このエラーの意味 {#what-this-means}

ライセンスの確認中に予期しない問題が発生しました。

POS は引き続き動作します。Pro 機能がロックされたままの場合は、ライセンスキーを入力し直してからサポートにお問い合わせください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。問題が続く場合は、診断情報をエクスポートして WCPOS サポートにお問い合わせください。

## 対処方法 {#troubleshoot}

1. そのまま作業を続けてください。ライセンスの確認が原因で POS が操作不能になることはありません。
2. Pro 機能がロックされたままの場合は、店舗の管理者に **WP Admin > POS > 設定 > ライセンス** を開いてもらってください。ライセンスが有効と表示されている場合は、WCPOS アカウントの完全なキーを用意し（ページには短縮形しか表示されません）、先に **無効化** を押します。その後、**ライセンスキー** にキーを入力して **有効化** を押してください。
3. レジのアプリを再読み込みして、ライセンスを再取得してください。
4. それでも Pro 機能がロックされている場合は、**店舗の状態 → ログ** で **デバッグ情報をコピー** を使い、ライセンスの識別情報を添えてサポートにお問い合わせください。
