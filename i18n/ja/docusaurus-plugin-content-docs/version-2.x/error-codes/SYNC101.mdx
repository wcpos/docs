## このエラーの意味 {#what-this-means}

WCPOS がこのデバイスのストレージに変更を書き込めませんでした。

デバイスのストレージに空きを作り、変更が表示されるか確認してください。表示されなければ、もう一度入力してください。繰り返し発生する場合はサポートにお問い合わせください。確認が済むまでは、変更内容を控えておいてください。書き込み前に WCPOS が終了すると、その変更は失われます。このデバイスのデータは消去しないでください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだ届いていない売上が保存されている可能性があります。失敗した変更はまだどこにも保存されていない可能性があるため、表示されることを確認するまで内容を控えておいてください。繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使用して WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. 変更内容、つまり対象のレコードと入力した値を控えてください。ログにレコード名が記載されている場合、そのレコードの変更が保存されていない可能性があります。サイト情報や認証情報の書き込みでは、代わりに失敗した操作とエラーだけが記載される場合があります。その詳細も控えてください。
2. サイトデータの消去、アプリのリセット、アンインストールは行わないでください。売上など、店舗にまだ届いていない他の変更はこのデバイスにしか存在せず、ローカルストレージを消去すると完全に削除されます。
3. 他のファイルやアプリを削除して、デバイスのストレージに空きを作ってください。ローカルへの書き込みに失敗する最も一般的な原因は、ディスクの空き容量不足やブラウザーのストレージ割り当て量の使い切りです。空きを作るためにブラウザーの「閲覧履歴データの削除」を使用しないでください。WCPOS の未送信の売上も削除されます。
4. レコードを開き、変更が表示されるか確認してください。表示されなければ、もう一度入力して保存してください。それでも保存できない場合は、WCPOS を一度再起動して再試行してください。
5. 保存に引き続き失敗する場合は、修復を試みる前に、**ログ** タブの **デバッグ情報をコピー** を使用してサポートにお問い合わせください。
