## このエラーの意味 {#what-this-means}

ドロワーの現金を数えてレジを締めましたが、店舗側が締め処理を拒否したため、店舗側ではシフトが開いたままです。

締め処理が届かなかったのではなく店舗側が拒否したため、自動で再試行されることはありません。レジには集計額、メモ、金種別の内訳が保持されています。原因を解消したら、**再試行**をタップしてください。

## データへの影響 {#your-data}

注文に影響はなく、販売が失われる危険もありません。レジには集計額、メモ、金種別の内訳が保持されているため、書き控える必要はありません。

## トラブルシューティング {#troubleshoot}

1. まず原因を解消してください。そうしないと、次の試行も同じように拒否されます。よくある原因は、締め処理を行うレジ係のアカウントから現金管理の権限が失われたことや、別の端末ですでにセッションが終了されていることです。
2. このレジの集計中は販売できません。マネージャーに締め処理の権限の復元を依頼してください。
3. 締め処理にマネージャーの承認が必要だった場合、承認は締め処理の実行時点で確認され、次の試行には引き継がれません。マネージャーに再試行の承認を依頼してください。
4. **再試行**をタップしてください。入力済みの金額で集計画面が開くので、内容を確認してもう一度締め処理を行ってください。
5. **店舗管理者の対応：** WP Admin でセッションがまだ開いていることと、締め処理を行うレジ係に現金管理の権限があることを確認してください。同じレジで締め処理が繰り返し拒否される場合は、ログ項目に、店舗側が問題としたフィールドや権限が記載されています。
