## このエラーの意味 {#what-this-means}

画面の一部を読み込めず、代わりにエラーメッセージが表示されました。

画面やパネルの描画中にエラーが発生したため、WCPOS は終了せず、その部分に赤い「問題が発生しました」というメッセージを表示しました。アプリの他の部分は引き続き動作します。これはアプリの不具合であり、サイトやデバイスの問題ではありません。メッセージには問題の内容が、ログには画面のどの部分で失敗したかが記録されます。これらがサポートに必要な情報です。エラー報告が許可されている場合、このエラーは開発者にも自動的に送信されます。

## データへの影響 {#your-data}

このエラー自体による書き込みやデータの損失はありません。保存済みのカート、注文、商品の編集内容はデバイスに残っており、通常どおり同期されます。操作の途中でメッセージが表示された場合は、パネルが復旧してから操作が完了したか確認し、そのうえで再実行してください。

## トラブルシューティング {#troubleshoot}

1. エラーメッセージを X で閉じてください。パネルが再描画され、一時的なエラーであれば解消されます。
2. すぐに再発する場合は、アプリを再読み込みしてください。ウェブ版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じて開き直します。
3. 再読み込み後も同じメッセージが表示される場合は、ログ画面からデバッグ情報をエクスポートして、サポートにお問い合わせください。ログにはエラーの内容と、画面のどの部分で失敗したかが記録されています。
