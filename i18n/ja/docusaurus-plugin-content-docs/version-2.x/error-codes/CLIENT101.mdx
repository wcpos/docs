## このエラーの意味 {#what-this-means}

WCPOSの起動を完了できませんでした。

レジでは、画面が真っ白になる、動かなくなる、読み込み中の表示が消えないといった状態になります。WCPOSを再起動してください（ウェブ版ではタブを再読み込みします）。起動時の問題は、これだけで解消することがよくあります。それでも起動しない場合は、何も削除せずにサポートにお問い合わせください。

:::warning この端末のデータを消去しないでください
この端末には、オフライン中に行った販売など、まだ店舗に送信されていない売上が残っている可能性があります。WCPOSが起動できない間は送信できないため、ローカルデータの消去、ログアウト、再インストールを行うと、その売上は完全に失われます。何も削除せずにサポートにお問い合わせください。
:::

## データについて {#your-data}

この端末のデータを消去しないでください。店舗にまだ反映されていない変更が残っている可能性があります。店舗側のデータは安全で、影響はありません。

## トラブルシューティング {#troubleshoot}

1. WCPOSを一度再起動してください。ウェブ版ではタブを完全に再読み込みします。一時的な起動の問題は、これだけで解消することがよくあります。
2. それでも起動しない場合は、何も削除せずにサポートにお問い合わせください。WCPOSで**ログ**タブを開ける場合は、**デバッグ情報をコピー**で取得した情報を送ってください。開けない場合は、ブラウザーのコンソール（開発者ツール）、またはデスクトップアプリの**詳細設定 → 開発者ツールの切り替え**に表示されるエラーを送ってください。
3. 返答を待つ間は、ローカルデータの消去、ログアウト、再インストールをしないでください。この端末から先に復旧すべきデータがあるかどうかは、サポートが案内します。
