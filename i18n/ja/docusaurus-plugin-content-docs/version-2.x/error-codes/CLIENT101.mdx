## これが意味すること {#what-this-means}

WCPOSを起動できませんでした。

レジでは、画面が真っ白になったり、固まったり、読み込み中の表示が消えなくなったりします。WCPOSを再起動してください（Web版ではタブを再読み込みします）。起動時の問題は自然に解消することがよくあります。それでも起動しない場合は、何も消去する前にサポートに問い合わせてください。

:::warning このデバイスのデータを消去しないでください
このデバイスには、まだ店舗に送信されていない売上データが保存されている可能性があります。たとえば、オフライン中に行った販売などです。WCPOSが起動できない間はデータを送信できません。そのため、ローカルデータの消去、サインアウト、再インストールを行うと、データが完全に削除されます。何かを消去する前にサポートに問い合わせてください。
:::

## データへの影響 {#your-data}

このデバイスのデータを消去しないでください。店舗にまだ反映されていない変更が含まれている可能性があります。店舗側のデータは安全で、影響を受けません。

## トラブルシューティング {#troubleshoot}

1. WCPOSを一度再起動してください。Web版ではタブを完全に再読み込みします。一時的な起動エラーは自然に解消することがよくあります。
2. それでも起動しない場合は、何も消去する前にサポートに問い合わせてください。WCPOSが開き、ログタブまで進める場合は、**デバッグ情報をコピー**を送信してください。それ以外の場合は、ブラウザーのコンソール（開発者ツール）に表示されたエラー、またはデスクトップアプリの**詳細 → 開発者ツールを切り替え**に表示されたエラーを送ってください。
3. 回答を待つ間、ローカルデータの消去、サインアウト、再インストールは行わないでください。デバイス上のデータを復元する必要があるか、サポートが先に確認します。
