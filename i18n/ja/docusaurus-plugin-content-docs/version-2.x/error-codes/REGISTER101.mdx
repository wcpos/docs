## このエラーの意味 {#what-this-means}

入金、出金、または売上なしのドロワー開放を記録しました。レジは受け付けて現金は実際に移動しましたが、店舗側が記録の保存を拒否しました。

移動の記録はこの端末に残っています。店舗側には存在しないため、店舗側が示すドロワーの予定残高には含まれず、そのシフトのレジレポートにも表示されません。

## データへの影響 {#your-data}

移動の記録はこの端末にのみ保存されています。送信されたものの店舗側が拒否したため、後で届くようにキューに入っているものはありません。受け付けられるまでは、この端末にあるものだけが現金移動の記録です。

## トラブルシューティング {#troubleshoot}

1. レジパネルを開いてください。拒否された移動がパネル上部に**再試行**ボタンとともに表示されます。まず再試行してください。拒否の多くは入力内容の問題ではなく、権限やセッションの問題です。
2. ログ項目にフィールド名が記載されている場合、そのフィールドが店舗側に拒否されています。有効な金額と理由を入力し、移動をもう一度記録してください。
3. 失敗が続く場合は、現金を数える前に金額、種類、理由を控えてください。店舗側の予定残高にはこの移動が含まれないため、ドロワーにはその金額と同額の不足（出金後）または超過（入金後）があるように見えます。
4. すべての移動が拒否される場合、よくある原因は、レジ係のアカウントから現金管理の権限が失われたこと、または別の端末でレジのセッションが終了されたことです。WP Admin で両方を確認してください。
5. 移動が受け付けられるか、内容を控えるまでは、レジを締めないでください。
