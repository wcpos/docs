## このエラーの意味 {#what-this-means}

決済端末で請求が行われたかどうかを WCPOS が確認できませんでした。

再度請求する前に決済端末を確認し、結果が不明なままの場合は決済サービス事業者にお問い合わせください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に確認してください。問題が続く場合は、決済サービス事業者にお問い合わせください。

## 対処方法 {#troubleshoot}

1. まだカードで再決済しないでください。
2. 決済端末自体の画面を確認してから、決済サービス事業者のダッシュボードを確認してください。請求が完了したかどうかは、事業者の記録で判断します。
3. WP Admin にアクセスできる場合は WooCommerce → 注文を確認してください。アクセスできない場合は店舗オーナーに依頼してください。成功した支払いは、すでにそこに記録されている場合があります。
4. 事業者のダッシュボードで請求がないことを確認してから、支払いを再度受け取ってください。
5. 請求が保留中または結果不明と表示される場合は、操作する前に決済サービス事業者にお問い合わせください。
