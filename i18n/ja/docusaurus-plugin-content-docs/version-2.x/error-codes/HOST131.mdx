## このエラーの意味 {#what-this-means}

サイトの手前にあるプロキシが、ヘッダーが多すぎるためにサーバーの応答を拒否しています。

キャッシュ層やプロキシ層（多くの場合は Varnish）には、応答ヘッダーの数やサイズの上限があります。サイトの軽量なエンドポイントは上限内に収まりますが、完全な API 応答は上限を超え、WordPress ではなくプロキシから 503 が返されます。その層の上限を引き上げる必要があります。

## データへの影響 {#your-data}

注文や商品のデータには影響しません。

## トラブルシューティング {#troubleshoot}

1. Varnish では、http_max_hdr（ヘッダー数）と http_resp_hdr_len / http_resp_size（サイズ）の上限を引き上げてください。
2. どのプロキシ層が 503 を返しているか、ホスティング事業者に確認してください。WordPress 側ではリクエストが失敗していないため、WordPress のエラーログには何も記録されません。
3. 簡単な確認方法：サイトの /wcpos/v2/ping は正常に応答する一方、データを返すエンドポイントでは 503 になります。
