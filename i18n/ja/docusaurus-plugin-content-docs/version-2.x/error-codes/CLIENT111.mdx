## これが意味すること {#what-this-means}

同期の開始に予想以上の時間がかかっています。

通常は1分以内に自動で解消します。アプリがこの状態のままの場合は、まず一度再読み込みしてください。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

1. 1分ほどお待ちください。アップデート後の初回同期や、大規模な店舗での同期には、通常より時間がかかります。
2. アプリがこの状態のままの場合は、一度再読み込みしてください。
3. 起動が毎日遅い場合は、店舗への接続を確認してください。問題がなければ、店舗の管理者にサイト自体の応答速度を確認してもらってください。
