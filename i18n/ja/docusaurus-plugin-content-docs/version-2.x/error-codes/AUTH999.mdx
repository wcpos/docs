## このエラーの意味 {#what-this-means}

ログイン、またはログイン状態の維持で予期しない問題が発生しました。

もう一度操作を試してください。再発する場合は、ログアウトして再度ログインし、**デバッグ情報をコピー**を使ってサポートに連絡してください。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。問題が続く場合は、**デバッグ情報をコピー**を使って WCPOS サポートに連絡してください。

## 対処方法 {#troubleshoot}

1. もう一度操作を試してください。再び失敗する場合は、ログアウトして再度ログインしてください。
2. ログ項目を展開し、イベントコードと、表示されていれば serverCode を控えてください。999 コードは、その原因にまだ専用のコードがないことを意味します。これらの情報が原因の特定に役立ちます。
3. 再発する場合は、デバッグ情報をコピーしてサポートに連絡してください。
