## このエラーの意味 {#what-this-means}

ホスティング環境が、この店舗のレジからのリクエストをレート制限しています。

アプリがすでにリクエスト間隔を延ばし、サーバーの Retry-After に指定された待機時間を守っているにもかかわらず、サーバーは 429（リクエストが多すぎます）を返し続けています。同じインターネット接続を使う複数のレジは同じアドレスを共有するため、接続元ごとのレート制限では、リクエスト数の非常に多い単一のクライアントとして扱われます。同期は自動的に続きますが、上限が引き上げられるまでは遅延します。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。

## 対処方法 {#troubleshoot}

1. 店舗自身の通信に対する REST API のレート制限を引き上げるか、制限対象から除外するよう、ホスティング事業者に依頼してください。店舗に固定 IP がある場合は、それを伝えてください。
2. 繰り返されるエラー応答（429）をブロック判定のためにカウントするセキュリティサービス（Sucuri の IDS など）では、店舗の API をそのカウントから除外する必要がある場合があります。
3. 複数のレジで接続を共有している場合は、ホスティング事業者にそのことを伝えてください。この場合、単一の IP はユーザー個人ではなく店舗全体を表します。
