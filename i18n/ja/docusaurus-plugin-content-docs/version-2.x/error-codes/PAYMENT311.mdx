## このエラーの意味 {#what-this-means}

この払い戻しが完了したかどうかを WCPOS が確認できませんでした。

再試行する前に、注文を開いて払い戻しを確認してください。再試行すると二重に払い戻してしまう可能性があります。

払い戻しリクエストは送信されましたが、応答を取得できませんでした。リクエストがタイムアウトしたか、店舗がエラーを返したか、WCPOS に待機して再試行するよう求めました。払い戻しが行われたかどうかは不明です。再試行するたびに決済ゲートウェイへ新たな払い戻しリクエストが送られるため、確認せずに再試行すると、お客様に二重に払い戻してしまう可能性があります。

## データへの影響 {#your-data}

このデバイスのデータは失われていません。店舗または決済ゲートウェイが、お客様にすでに払い戻している可能性があります。

## 対処方法 {#troubleshoot}

1. まだ払い戻しを再実行しないでください。
2. **注文** で注文を開き、払い戻しを確認してください。払い戻し情報は店舗から直接読み込まれるため、このデバイスがオンラインである必要があります。WP Admin の **WooCommerce → 注文** で注文を開いて、一覧に表示される払い戻しを確認することもできます。
3. カード決済端末や Vipps MobilePay などの決済サービス事業者を通じて払い戻した場合は、そのゲートウェイ独自のダッシュボードも確認するか、店舗オーナーに確認を依頼してください。注文にまだ表示されていなくても、払い戻しが送信されたかどうかを確認できます。
4. 払い戻しが表示されていれば、完了しています。再度払い戻さないでください。どちらにも表示されていない場合に限り、もう一度払い戻しを試してください。誰もゲートウェイを確認できない場合は、再試行せず次の手順に進んでください。
5. それでも不明な場合は、**ログ** タブの **デバッグ情報をコピー** をタップし、再試行する前にサポートにお問い合わせください。
