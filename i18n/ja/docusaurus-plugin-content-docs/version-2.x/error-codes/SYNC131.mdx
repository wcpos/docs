## このエラーの意味 {#what-this-means}

店舗側でエラーが発生し、このリクエストが完了しませんでした。

店舗には接続できましたが、サーバーがリクエストを処理できませんでした。POS ではなくウェブサイト側の問題です。操作をもう一度試してください。繰り返し発生する場合は、サイト管理者に **WooCommerce → ステータス → ログ** の確認を依頼してください。このデバイスのデータは失われていません。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだない変更が保存されている可能性があります。送信中だった変更は、店舗に届いていない可能性があります。繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使用して WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

**POS での操作（レジ係）：** ログを展開し、ステータス、エンドポイント、serverCode を控えてください。これらから、失敗したときにサーバーが何をしていたかがわかります。

**ウェブサイトでの操作（サイト管理者 / ホスティング事業者）：**

1. サイトの WooCommerce → ステータス → ログ を開き、最新の fatal-errors ログで障害発生時刻の前後を確認してください。500 番台の応答では、ほとんどの場合そこに PHP エラーが記録されます。
2. サイトのプラグイン、テーマ、PHP を更新してから障害が発生し始めた場合は、まずその変更を疑い、元に戻すか無効化してください。
3. WooCommerce のログに何も表示されない場合は、同じ時間帯のサーバーの PHP エラーログをホスティング事業者に依頼してください。

**その後、POS に戻って：** 操作をもう一度試してください。
