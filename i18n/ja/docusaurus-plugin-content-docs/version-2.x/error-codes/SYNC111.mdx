## このエラーの意味 {#what-this-means}

このデバイスに保存されているデータの一部が破損しているため、同期できません。

**ログ** タブの上部にある **デバッグ情報をコピー** をタップし、WCPOS サポートに送ってください。WCPOS の再インストール、ログアウト、データの消去は行わないでください。店舗にまだ届いていない変更は、このデバイスにしか存在しません。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだ届いていない売上が保存されている可能性があります。アプリの再インストールやログアウトでも削除される場合があります。どの種類のデータなら安全に再ダウンロードできるかは、サポートが案内します。

## トラブルシューティング {#troubleshoot}

1. WCPOS が動作していれば、販売を続けてください。再インストール、ログアウト、データの消去は行わないでください。
2. **ログ** タブの上部にある **デバッグ情報をコピー** をタップし、ログが表示されたときに行っていた操作とともに WCPOS サポートに送ってください。
3. **店舗の状態 → データベース** を開き、**送信待ちの変更** の件数と、**「… 件の変更がサーバーに届きませんでした」** または **「… 件の変更が保留されました」** のパネルが表示されているかをサポートに伝えてください。これらの変更は、このデバイスにしか存在しません。
4. ログには、どのデータが破損しているかは記載されていません。送信待ちがなくなってから、特定の種類のデータを再ダウンロードするようサポートから案内される場合があります（該当行の **⋮** メニュー → **消去して再ダウンロード…**）。対象をサポートが確認するまでは実行しないでください。誤ったデータを消去したり、送信待ちの変更がある状態で消去したりすると、店舗に届いていない売上が削除されるおそれがあります。破損が原因で変更を送信できない場合は、サポートが先に復旧します。送信待ちがある間は、絶対に再ダウンロードしないでください。
