## このエラーの意味 {#what-this-means}

デバイスレベルのクラッシュにより WCPOS が停止しました。

WCPOS を再起動し、最後の売上や変更が保存されたか確認してください。アプリやシステムの更新があればインストールしてください。クラッシュが繰り返される場合は、サポートにお問い合わせください。

## データへの影響 {#your-data}

結果を確認できませんでした。再試行する前に確認してください。売上や変更の保存中にクラッシュした場合は、やり直す前に保存されているか確認してください。

## トラブルシューティング {#troubleshoot}

1. WCPOS を再起動し、最後の売上や変更をやり直す前に、保存されているか確認してください。**店舗の状態 → データベース**（**送信待ちの変更**に数えられている売上は保存済みで、送信が進行中です）、カート、注文（WCPOS Pro）または **WooCommerce → 注文**を確認します。カード払いの場合は、決済端末や決済サービス側も確認してください。お客様に請求済みの場合は、再度請求しないでください。本当に保存されていない場合に限り、再入力してください。
2. アプリとデバイスのオペレーティングシステムに未適用の更新があればインストールしてください。ネイティブクラッシュの原因は、すでに修正済みの不具合であることがよくあります。管理対象のレジでは、デバイスの管理担当者がこの作業を行います。
3. 同じ操作でクラッシュが繰り返される場合は、クラッシュ時に何をタップしたかを正確に控え、**ログ**タブの**デバッグ情報をコピー**をタップして、サポートにお問い合わせください。
