## このエラーの意味 {#what-this-means}

サーバーがブラウザーのアクセス許可確認（CORS プリフライト）をブロックしているため、ウェブアプリから接続できません。

ブラウザーは、カスタムヘッダーを含むクロスオリジンの API 呼び出しの前に、OPTIONS リクエストを送信します。サイトの手前にある何らかの仕組み（通常はファイアウォールのルール）が OPTIONS をブロックしているため、ブラウザーは本来のリクエストを送信できません。ネイティブアプリには影響しません。修正はサーバー側で行います。

## データへの影響 {#your-data}

注文や商品のデータには影響しません。

## トラブルシューティング {#troubleshoot}

1. ファイアウォール（WAF）に OPTIONS メソッドをブロックするルールがないか確認し、/wcpos/ の REST ルートで OPTIONS を許可してください。
2. 一部のセキュリティプラグインには「一般的でないリクエストメソッドをブロックする」設定があります。OPTIONS は必ず許可したままにしてください。
3. 確認方法：サイトの REST API への OPTIONS リクエストで 403 が返されないことを確認してください。
4. デスクトップアプリとモバイルアプリは CORS を使用しないため、修正作業中も利用できます。
