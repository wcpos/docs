## このエラーの意味 {#what-this-means}

このデバイスのストレージが応答しなくなったため、保存が一時停止しています。

WCPOS を再起動し（ウェブ版ではタブを再読み込み）、直前の売上や変更が保存されているか確認してください。ストレージが停止する直前の数秒間に行った変更は、書き込まれていない可能性があります。このデバイスのデータは消去しないでください。繰り返し発生する場合はサポートにお問い合わせください。

## データへの影響 {#your-data}

このデバイスのデータは消去しないでください。店舗にまだ届いていない売上が保存されている可能性があります。繰り返し発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使用して WCPOS サポートにお問い合わせください。

## トラブルシューティング {#troubleshoot}

1. WCPOS を再起動してください。アプリを閉じて開き直します。ウェブ版では、タブを閉じずに再読み込みしてください。ほとんどの場合、これでローカルデータベースに再接続できます。
2. 再起動後、直前の売上や変更が保存されているか確認してください。障害の直前の数秒間に行った変更は、書き込まれていない可能性があります。見つからなければ、もう一度入力してください。
3. ウェブ版では、プライベート / シークレットウィンドウで端末を使用せず、ストレージを積極的に消去する拡張機能も避けてください。どちらもセッションの途中でローカルストレージを使えなくする可能性があります。また、プライベートウィンドウを閉じると、未送信の売上を含め、そこに保存されたすべてのデータが削除されます。現在使用している場合は、**店舗の状態 → データベース** の **送信待ちの変更** が 0 件になり、[判断を求めるパネル](../support/store-health.mdx#needs-attention)がなく、未同期の未完了注文もなくなるまで（[注文を同期](../pos/cart/open-orders.mdx#sync-order)）、ウィンドウを開いたままにしてください。
4. 同じデバイスで定期的に発生する場合は、**ログ** タブの **デバッグ情報をコピー** を使用し、発生時のデバイスの状態（スリープ、タブの切り替え、メモリ不足）を添えてサポートにお問い合わせください。
