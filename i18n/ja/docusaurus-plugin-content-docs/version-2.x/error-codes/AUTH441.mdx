## このエラーの意味 {#what-this-means}

ログイントークンのサイズが、このサーバーの上限を超えています。

サーバーがサイズを理由にログイントークンを拒否しました。Authorization ヘッダーで送信した場合は 400、URL で送信した場合は 414 が返されます。クライアント側でどのようにエンコードしても小さくはできません。サーバーのヘッダー／URL のサイズ上限を引き上げるか、トークンを小さくする必要があります。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。

## 対処方法 {#troubleshoot}

1. Apache では、vhost 設定の LimitRequestFieldSize（ヘッダー経由の場合）または LimitRequestLine（URL 経由の場合）を引き上げてください。
2. nginx では、large_client_header_buffers を引き上げてください。
3. プロキシや CDN を経由している場合は、そちらに上限がある可能性もあります。両方を確認してください。
4. 上限を変更できない場合は、このサイト用に小さいトークンを発行できるかサポートに相談してください。
