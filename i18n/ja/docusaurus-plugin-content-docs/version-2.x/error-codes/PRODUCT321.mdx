## このエラーの意味 {#what-this-means}

このバーコードに一致する商品が複数あります。

WCPOS は正しい商品を安全に選べないため、何も追加しませんでした。商品名で検索し、重複を解消するために店舗側で各商品に固有のバーコードを設定してください。

## データへの影響 {#your-data}

注文や商品のデータに影響はありません。問題が続く場合は、店舗の管理者に確認してください。

## トラブルシューティング {#troubleshoot}

1. **レジでの対応：** スキャンでは何も追加されず、**複数の一致**というトースト通知が表示されています。スキャンしたコードは商品検索ボックスに入力されているため、同じコードを持つ商品の一覧が表示されます。正しい商品を手動で追加して販売を完了してください。
2. まずカテゴリーや在庫のフィルターを解除してください。同じ検索結果を絞り込むため、一致する商品の一部が非表示になることがあります。その後、店舗の管理者に伝えるために、一覧のすべての商品名を控えてください。
3. **サイト管理者の対応：** WP Admin で該当商品をそれぞれ開き、固有のバーコードを設定してください。店舗がバーコードに使用するフィールドは、**WP Admin > POS > 設定 > 一般 > バーコードフィールド**で確認します（デフォルトは商品の GTIN、`_global_unique_id`）。SKU や別のバーコードフィールドの重複でも一致する場合があるため、それらも確認してください。
4. **レジに戻って行う対応：** **店舗の状態 → データベース**を開き、**商品**行の **⋮** メニューから**今すぐ変更を確認**を選択してください。一致した商品の中にバリエーションがあれば、**バリエーション**行でも同じ操作を行ってから、もう一度スキャンしてください。これでスキャン時に商品が直接追加されるはずです。
