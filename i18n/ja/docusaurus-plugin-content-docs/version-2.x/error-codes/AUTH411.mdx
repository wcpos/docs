## このエラーの意味 {#what-this-means}

店舗のアドレスが入力されていないか、有効な URL ではありません。

アドレス欄が空だったか、店舗から応答はあったものの WCPOS のログインアドレスが無効です。後者の場合は、レジではなく店舗側で修正する必要があります。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。

## 対処方法 {#troubleshoot}

1. **WooCommerce の店舗 URL を入力**に、`shop.example.com` などの店舗アドレスを入力し、**接続**を押してください。スペースだけの入力は空欄とみなされます。
2. アドレスが入力されていて、**「WCPOS のログイン URL が無効です。WCPOS プラグインが正しく設定されていることを確認してください」** と表示される場合は、店舗側の問題です。**サイト管理者：** **WP Admin → プラグイン**で WCPOS を最新バージョンに更新してから、もう一度 **接続**を押してください。解決のために無効化して再有効化しないでください。再有効化すると、すべての権限グループの POS 権限がデフォルトにリセットされます。
3. **サイト管理者：** それでも解消しない場合は、店舗の完全なアドレスに `/wp-json/` を付けてブラウザで開いてください。例えば `https://your-store.com/wp-json/`、WordPress が `/shop` にある場合は `https://example.com/shop/wp-json/` です。これで 404 が返る場合（パーマリンクが基本設定の場合など）は、代わりに同じアドレスに `/?rest_route=/` を付けてください。`authentication` → `wcpos` → `endpoints` の中の `authorization` は、通常のウェブアドレスである必要があります。リスト、オブジェクト、数値になっている場合は、セキュリティ、キャッシュ、REST のカスタマイズ用プラグインのいずれかが応答を書き換えています。ステージング用コピーでそれらを一つずつ無効化し、原因を特定してください。
