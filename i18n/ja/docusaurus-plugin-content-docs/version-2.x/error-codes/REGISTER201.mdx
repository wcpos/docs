## このエラーの意味 {#what-this-means}

この端末でレジを開始し、釣銭準備金を数えて登録しましたが、店舗側がセッションの作成を拒否しました。

販売は引き続き行え、注文が失われる危険はありません。ただし、店舗側ではこのレジは開始されていない扱いのため、現金移動をこのセッションに記録できず、シフトもレジレポートに表示されません。

## データへの影響 {#your-data}

注文は通常どおり保存・送信され、影響はありません。レジのセッションに紐づいていないため、そのシフトのレジレポートには計上されません。

## トラブルシューティング {#troubleshoot}

1. レジパネルでレジを締めてから、もう一度開始してください。通常、新しいセッションは正常に開始できます。
2. ログ項目にフィールド名が記載されている場合、通常は開始時の釣銭準備金が原因です。数字と小数点だけで入力し直してください。`10,50` や `10.` ではなく、`10.50` のように入力します。
3. **店舗管理者の対応：** WP Admin で、レジがまだ存在し、廃止されていないことと、レジ係のアカウントに現金管理の権限があることを確認してください。
4. セッションがない間に受け付けた注文は店舗側に残りますが、後からレジレポートに追加することはできません。照合作業でシフトの記録が必要な場合は、レジを再開した時刻を控えてください。
