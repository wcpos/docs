## このエラーの意味 {#what-this-means}

選択した決済ゲートウェイは、この店舗では利用できません。

ゲートウェイが対応対象であり、有効になっていて、正しく設定されていることをサイト管理者に確認してもらってください。

## データへの影響 {#your-data}

注文データや商品データへの影響はありません。問題が続く場合は、WordPress サイトの管理者に相談してください。

## 対処方法 {#troubleshoot}

**レジでの対応：**

1. 解決するまでは、現金など別の方法で販売を完了してください。
2. 支払いパネルの **… 現在利用できません** の下で支払方法がグレー表示されている場合は、このエラーではなく、このレジ側の問題です。表示されている理由（**接続が必要です** や **リーダーを使用するには Bluetooth をオンにしてください** など）から、修正が必要な点を確認できます。

**店舗側での対応** — サイト管理者の方へ：

3. **WP Admin > POS > 設定 > レジ** を開きます。**決済ゲートウェイ** に該当のゲートウェイが表示され、**有効** スイッチがオンになっている必要があります。表示されていない場合は、そのプラグインがインストールされ、有効化されていることを確認してください。**WP Admin > WooCommerce > 設定 > 決済** で有効にする必要はありません。POS には、有効なプラグインが登録するすべてのゲートウェイが表示されます。WCPOS Free で有効にできるのは、組み込みの現金とカードの支払方法だけです。他の WooCommerce ゲートウェイには WCPOS Pro が必要です。
4. 昨日までゲートウェイが動作していた場合は、ゲートウェイまたは WooCommerce が更新されていないか確認してください。**WooCommerce → ステータス → ログ** にゲートウェイの起動エラーが記録されている場合があります。
5. 修正したら、レジのアプリを再読み込みしてゲートウェイを再認識させてください。
