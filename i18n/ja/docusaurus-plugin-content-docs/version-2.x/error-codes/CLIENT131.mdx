## これが意味すること {#what-this-means}

WCPOSが一度に多くのリクエストをキューに追加したため、一部が破棄されました。

通常、これは店舗の問題ではなく、アプリの不具合です。WCPOSを再起動してください。コードが再び表示される場合は、診断情報をエクスポートしてサポートに問い合わせてください。

## データへの影響 {#your-data}

すでに完了したリクエストに問題はありません。破棄されたリクエストは実行されていないため、次に進む前に、途中だった操作が実際に完了したか確認してください。

## トラブルシューティング {#troubleshoot}

1. 数秒お待ちください。キューは自動的に処理され、古いリクエストは自動的に破棄されます。途中だった操作が完了したか確認し、完了していない場合に限り再試行してください。
2. 同じセッションで再び発生する場合は、WCPOSを再起動してください。再起動するとキューがクリアされます。
3. 通常、これは店舗の問題ではなく、アプリの不具合です。繰り返し発生する場合は、デバッグ情報をエクスポートしてサポートに問い合わせてください。ログエントリーの詳細から、開発者はキューに集中したリクエストを特定できます。
