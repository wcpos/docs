# エラーコード {#error-codes}

WCPOSで問題が発生すると、原因の特定に役立つエラーコードが表示されます。**v1.10.0** 以降、コードは **分野名 + 3桁の数字** という形式です。例：`SYNC131`、`AUTH311`。分野名はPOSのどの領域かを、数字は具体的な状況を示します。各コードには専用ページがあり、意味、対処方法、データへの影響を説明しています。

POSでは、エラーコードは **店舗の状態 → ログ** に表示されます。行を展開し、**ヘルプ** リンクを使うと、このドキュメントの該当コードのページに直接移動できます。

## エラーの分野（v1.10.0+） {#error-domains}

| 分野 | 対象領域 |
|--------|------|
| [`AUTH`](#auth) | ログイン、セッション、トークン |
| [`CHECKOUT`](#checkout) | レジでの注文の完了 |
| [`CLIENT`](#client) | POSアプリ本体とローカルストレージ |
| [`DISPLAY`](#display) | カスタマーディスプレイ |
| [`HOST`](#host) | POSをブロックするホスティングやファイアウォールのルール |
| [`LICENSE`](#license) | Proライセンスの有効化と検証 |
| [`PAYMENT`](#payment) | 決済ゲートウェイと決済端末 |
| [`PRINT`](#print) | レシートの印刷 |
| [`PRODUCT`](#product) | 商品データとカタログ操作 |
| [`REGISTER`](#register) | キャッシュドロワー、レジセッション、現金確認 |
| [`SYNC`](#sync) | POSと店舗間の同期 |

以下の一覧からコードを探すか、検索してください。

末尾が `999` のコードは、その分野で専用のコードがまだない状況に使われる汎用コードです。

| コード | 意味 |

## v1.10.0より前のコード {#legacy-codes}

`API04001` などのコードはv1.10.0より前のバージョンのもので、このバージョンでは発生しません。アップグレード前から残っているログや、古いサポートスレッドには表示される場合があります。調べるには、バージョンメニューを **1.x** に切り替えてください。

1. [トラブルシューティング](../support/troubleshooting/response-error.mdx)セクションで、詳しいガイドを確認してください
2. [Discordコミュニティ](https://wcpos.com/discord)に参加してサポートを受けてください
3. [GitHub](https://github.com/wcpos)で問題を報告してください
