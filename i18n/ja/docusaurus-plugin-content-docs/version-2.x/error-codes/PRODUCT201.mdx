## このエラーの意味 {#what-this-means}

この商品画像は利用できませんが、商品の販売は可能です。

画像なしで販売を続けてください。WCPOS は後で画像の読み込みを再試行します。

## データへの影響 {#your-data}

注文や商品のデータに影響はありません。

## トラブルシューティング {#troubleshoot}

**レジでの対応：** 通常どおり販売してください。商品に影響はなく、画像の読み込みはバックグラウンドで再試行されます。

**店舗側（WP Admin）での対応：**

1. 特定の商品の画像がまったく読み込まれない場合は、その画像を保存し直してください。メディアライブラリからファイルが削除された可能性があります。
2. 多くの画像が一斉に読み込めなくなる場合は、サイトのメディアホスティングや CDN が原因です。店舗のウェブサイト自体で画像が読み込まれるか確認してください。
