## これが意味すること {#what-this-means}

検索インデックスが時間内に応答しなかったため、WCPOSは代わりにカタログを直接検索しました。

ローカル検索インデックスの構築中、または応答できない状態でした。Web版では、POSのタブがバックグラウンドにあることが主な原因です。デスクトップ版とモバイル版では、大規模な同期の直後や、アプリ再起動後に保存済みインデックスを読み込んでいる間に発生することがあります。検索は引き続き応答し、このデバイスのデータを直接スキャンして結果を返します。インデックスが応答すると、自動的にインデックスを使った検索に戻ります。

## データへの影響 {#your-data}

店舗のデータは変更されておらず、検索にも応答しました。インデックスの代わりに、このデバイスのデータを直接スキャンして結果を返しました。インデックスが再び使われるまで、検索への応答が少し遅くなることがあります。

## トラブルシューティング {#troubleshoot}

1. 通常、対応は必要ありません。検索結果は引き続き表示され、インデックスが応答すると自動的に再び使われます。
2. Web版では、POSをバックグラウンドのタブではなく、独立したウィンドウで開いてください。
3. 検索が遅いままの場合や、このコードが繰り返し表示される場合は、アプリを一度再読み込みしてください。Web版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じて開き直します。
4. その後もコードが再び表示される場合は、デバッグ情報をエクスポートしてサポートに問い合わせてください。
