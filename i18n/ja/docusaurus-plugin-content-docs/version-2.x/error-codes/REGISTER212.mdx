## このエラーの意味 {#what-this-means}

このデバイスでドロワーの引き継ぎが完了しませんでした。店舗は切り替わっていません。

引き継ぎでは、店舗側で引き継ぎ元のレジを閉じ、引き継ぎ先のレジを開きます。リクエストが拒否された場合、どちらのレジも変更されません。

## データへの影響 {#your-data}

接続が途切れた場合は、再試行する前に両方のレジを確認してください。このデバイスが応答を受信していなくても、店舗側では引き継ぎが完了している可能性があります。

## トラブルシューティング {#troubleshoot}

1. 現金を移動する前や再試行する前に、引き継ぎ元と引き継ぎ先のレジを確認してください。
2. 引き継ぎ先がすでに開いている場合は、引き継ぎをせずに切り替え、そのレジに対応するドロワーを確認してください。
3. レジと実際のドロワーが一致しない場合は、店舗管理者に相談してください。
