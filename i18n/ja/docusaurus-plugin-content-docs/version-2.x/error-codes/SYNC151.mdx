## このエラーの意味 {#what-this-means}

店舗からの応答に余分なテキストが含まれていたため、WCPOS が除去を試みました。

行っていた操作が完了したか確認してください。余分なテキストの除去は、必ず成功するとは限りません。通常、余分なテキストはプラグインや PHP の通知が店舗の応答に追加出力を混入させることで生じます。頻繁に表示される場合は、サイトの PHP エラーログに警告がないか、サイト管理者に確認を依頼してください。

## データへの影響 {#your-data}

行っていた操作が完了しなかった場合（トラブルシューティングのステップ 1 を参照）は、そのリクエストの案内に従ってください。完了していれば、注文や商品のデータへの影響はありません。頻繁に表示される場合は、WordPress サイトの管理担当者に相談してください。

## トラブルシューティング {#troubleshoot}

1. 行っていた操作が完了したか、例えば売上や変更が表示されているかを確認してください。完了していれば、追加の対応は不要です。完了していなければ再試行し、それでも失敗する場合は表示されたエラーの案内に従うか、サポートにお問い合わせください。
2. 原因はサイト側にあります。プラグインやテーマが、警告や余分な出力を REST 応答に混入させています。障害発生時刻のサイトログに PHP の通知がないか、サイト管理者に確認を依頼してください。
3. **サイト管理者向け：** ブラウザーの開発者ツール（ネットワークタブ）、またはデスクトップアプリの **詳細設定 → 開発者ツールの切り替え** で、応答本文をそのまま確認できます。余分な出力は JSON の直前または直後に表示されます。
4. **サイト管理者向け：** 余分なテキストの除去は可能な範囲で行われるもので、成功は保証されません。頻繁に表示される場合は、この処理に頼らず、原因となっているプラグインを修正してください。
