## このエラーの意味 {#what-this-means}

カード決済端末は、代金を受け取らずにこの支払いを終了しました。通常の原因は、お客様の銀行による拒否、リーダー本体でのキャンセル、またはカードが提示される前に支払いの有効期限が切れたことです。

請求は行われておらず、注文の残額は未払いのままです。別の方法で支払いを受け付けることができます。決済サービス事業者が返した理由はログ行に記録され、通常は同時に決済端末の画面にも表示されます。

## データへの影響 {#your-data}

金銭の移動はありません。注文は変更されておらず、残額は未払いのままです。

## 対処方法 {#troubleshoot}

**レジでの対応** — お客様がお帰りになる前に行ってください：

1. 決済端末の画面またはログ行で理由を確認してください。
2. お客様に別のカードをお願いするか、別の支払方法で受け付けてください。
3. お客様が支払いは完了したとおっしゃる場合は、再度請求する前に注文を確認してください。銀行まで届いた支払いは注文に表示されます。

**店舗側での対応** — サイト管理者の方へ：

1. どのカードでも拒否が続く場合は、お客様ではなく、決済端末またはそれに紐づくアカウントに問題があると考えられます。リーダーがオンラインであることを確認し、決済サービス事業者のダッシュボードを確認してください。
2. 個々のカードの拒否は、お客様と銀行の間の問題です。WCPOS は拒否を記録しますが、その理由を説明することはできません。
