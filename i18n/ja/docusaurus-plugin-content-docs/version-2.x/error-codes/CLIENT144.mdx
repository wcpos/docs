## このエラーの意味 {#what-this-means}

検索インデックスの再構築に失敗しました。アプリが初期化を再試行する間、検索結果が不完全になることがあります。

検索インデックスの問題（[CLIENT141](/error-codes/CLIENT141) または [CLIENT143](/error-codes/CLIENT143)）を検出した後、アプリはインデックスの再構築を試みましたが、再構築自体が失敗しました。既存のインデックスから誤りが判明している結果を除外するか、デバイス上のデータを直接検索することで、検索は引き続き応答します。ただし、対象リストの結果に欠落や順位の誤りが生じることがあります。次の検索や準備状態の確認時にインデックスの初期化が再試行され、自動的に復旧する場合があります。結果が改善しない場合は、アプリを再読み込みしてやり直すこともできます。

## データへの影響 {#your-data}

サイトのデータは変更されていません。問題は、このデバイスに保存済みのデータから作成されるローカル検索インデックスに限られます。

## トラブルシューティング {#troubleshoot}

1. ログの項目を開いてください。コンテキストに、対象のリストと再構築時のエラーが記載されています。ストレージに関するエラーの場合は、まずデバイスの空き容量を増やしてください。ウェブ版では、プライベートウィンドウやシークレットウィンドウの使用も避けてください。
2. 対象リストでもう一度検索してください。アプリがインデックスの初期化を自動で再試行します。
3. 検索結果の欠落や並び順の誤りが続く場合は、アプリを再読み込みしてください。ウェブ版ではブラウザーのタブを再読み込みし、デスクトップ版とモバイル版ではアプリを閉じて開き直します。その後も CLIENT144 が記録される場合は、ログ画面からデバッグ情報をエクスポートして、サポートにお問い合わせください。
