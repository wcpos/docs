## このエラーの意味 {#what-this-means}

現金確認の結果が店舗の過不足の許容限度を超えたため、マネージャーの承認が必要になりました。店舗側で承認が拒否され、レジは現金確認のステップで開いたままになっています。

## データへの影響 {#your-data}

現金確認の結果はこのデバイスに保持されており、データは失われていません。入力したドロワーの金額は画面に残っているため、そのまま再試行できます。

## トラブルシューティング {#troubleshoot}

1. ユーザー名とパスワードを確認してください。承認には通常の WordPress ログインを使用し、大文字と小文字が区別されます。
2. レジ係は自分の現金確認を承認できません。承認者は、レジを閉じるアカウントとも、セッションを開いたアカウントとも異なる必要があります。
3. 承認するアカウントには、レジ締めを管理する権限が必要です。ショップマネージャーには標準でこの権限がありますが、レジ係にはありません。
4. 承認に引き続き失敗する場合は、マネージャーが自分のアカウントでログインしてレジを閉じられるよう、現金確認の状態を残しておけます。先に、数えた現金の合計を控えてください。
5. **店舗管理者：** 一つのレジで拒否が繰り返される場合は、確認する価値があります。試行は毎回記録されます。現金不足のドロワーで承認失敗が何度も発生している場合は、調査が必要です。
