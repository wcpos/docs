## これが意味すること {#what-this-means}

店舗がサインインの認証情報を受け付けませんでした。

ユーザー名とパスワードを再入力してください。それでも失敗する場合は、WordPressでパスワードをリセットしてください。注文データへの影響はありません。

## データへの影響 {#your-data}

注文や商品データへの影響はありません。

## トラブルシューティング {#troubleshoot}

**レジ側** — レジ係の方：ユーザー名とパスワードを再入力してください。この組み合わせは店舗に拒否されました。

**店舗側** — サイト管理者の方：

1. 同じ認証情報でWP Adminにサインインし、アカウントが使用できることを確認してください。失敗する場合は、そこでパスワードをリセットしてください。
2. 同じ認証情報でWP AdminにはサインインできるのにPOSではできない場合、ログイン保護やセキュリティのプラグインがプログラムからのサインインをブロックしている可能性があります。プラグインの設定を確認してください。
