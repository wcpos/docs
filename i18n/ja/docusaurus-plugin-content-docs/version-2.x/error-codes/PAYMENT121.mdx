## このエラーの意味 {#what-this-means}

決済端末で支払いが行われ、店舗が代金を受領しています。失敗したのは、その後に注文を完了する処理です。そのため、代金は支払い済みですが、販売は未完了のままになっています。

これは支払いの問題ではありません。カードに再度請求すると、代金を二重に受け取ることになります。必要なのは注文を完了する処理だけです。

## データへの影響 {#your-data}

代金は移動済みです。カードへの請求は完了し、店舗が支払いを受領しています。注文は未完了なので、必要なのは支払いではなく完了処理です。

## 対処方法 {#troubleshoot}

**レジでの対応** — お客様がお帰りになる前に行ってください：

1. 支払いを再度受け取らず、支払いパネルの閉じるボタン（**X**）も使わないでください。支払いが記録されている注文を閉じると **支払いをキャンセル** が開き、支払いが取り消されます。
2. アプリを再読み込みしてください（Web ではブラウザーのタブを再読み込みし、デスクトップとモバイルではアプリを閉じて開き直します）。起動時に、レジはカード支払いを記録済みの販売の完了処理を再試行し、完了した注文はカートから消えます。
3. 再読み込み後も注文がカートに未完了のまま残っている場合は、**店舗の状態 → データベース** を開き、**注文** 行の **⋮** メニューから **今すぐ変更を確認** を選び、もう一度再読み込みしてください。
4. それでも未完了の場合は、注文はそのままにしてお客様への対応を済ませてください。代金は受領済みです。店舗の管理者に完了処理を依頼してください（下記参照）。

**店舗側での対応** — サイト管理者の方へ：

1. レジで注文を完了できない場合は、**WooCommerce → 注文** で注文を開き、決済サービス事業者のダッシュボードで請求を確認してください。支払いを分割した販売では、すべての支払いが済んでいることを確認します。その後、その支払方法で支払い済みの販売に POS が使用するステータスを設定してください。**WP Admin > POS > 設定 > レジ** の **決済ゲートウェイ** 表で、支払いを処理したゲートウェイの行の **注文ステータス** 列に表示されています。
2. 原因を調べるには、レジの通知で **サポート用の詳細情報** を展開するか、**店舗の状態 → ログ** の該当項目を開いてください。完了処理がどこで失敗したかが記載されています。通常は、処理の途中で接続が切れたことが原因です。サポートに問い合わせる際は、この情報を添えてください。
