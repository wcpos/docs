# レシートと支払い完了画面 {#receipts-and-the-paid-screen}

最後の支払いを受け取ると、会計欄が支払い完了画面に切り替わります。返す金額が表示され、レシートの印刷、メール送信、保存ができます。**新しい販売**を押すと、次のお客様のためにレジがクリアされます。後から注文画面、払い戻し、カートからレシートを再度開くこともできます。

各手順へ：[レシートを印刷する](#print-receipt) · [レシートをメールで送信する](#email-receipt) · [次の販売を開始する](#new-sale)

## 支払い完了画面の見方 {#paid}

<JourneyShot manifest={checkoutManifest} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="現金販売後の支払い完了画面：お釣り、支払額と預り額、テンプレートとプリンター、レシートのプレビュー、印刷、メール送信、新しい販売の各ボタン">

1. **お釣り** — お客様に返す金額です。返す金額がない場合は、**支払い済み**と金額が表示されます。
2. **支払い方法** — 金額と使用した支払い方法です。
3. **テンプレート** — この販売で使うレシートです。ここでの選択は、この販売にのみ適用されます。[レシートのカスタマイズ](./customise.mdx)をご覧ください。
4. **プリンター** — 印刷先です。[レシートを印刷する](#print-receipt)をご覧ください。
5. **プレビュー** — 印刷されるレシートの見た目です。**−** と **+** で拡大・縮小できます。サイズを選ぶまでは、欄の幅に合わせて表示されます。
6. **レシートを印刷** — 上記のプリンターで印刷します。
7. **レシートをメール送信** — お客様に送信します。[レシートをメールで送信する](#email-receipt)をご覧ください。
8. **新しい販売** — 次のお客様のために空のカートを用意します。[次の販売を開始する](#new-sale)をご覧ください。

</JourneyShot>

**レシートをメール送信**の横にある **PDFをダウンロード**は、レシートをファイルとして保存します。接続が必要です。

<details>
<summary>現金、分割払い、店舗の確認待ちのメッセージ</summary>

見出しの下の行は、販売内容に応じて変わります。

- **支払額 $X · 現金預り額 $Y**：お釣りがある現金販売です。
- **現金**や**カード**などの支払い方法名：それ以外の一回の支払いです。
- 使用した支払い方法を重複なく **+** でつなぎ、その後に支払い回数を表示：複数回に分けて支払った販売です。現金の支払いでお釣りが出た場合は、代わりに上記の現金の行が表示され、その後に支払い回数が続きます。[分割払い](../pos/checkout/split-payments.mdx)をご覧ください。
- 先頭に**店舗の確認待ち ·** と表示：店舗がまだ販売を確認していません。通常はレジがオフラインの場合に表示されます。緑色のチェックマークがオレンジ色の保留マークに変わり、レシートには**店舗の確認待ち · 未確認**と表示されます。販売はレジに安全に保存されており、接続が戻ると店舗に送信されます。[オフラインモード](../getting-started/offline.mdx#offline-writes)をご覧ください。

</details>

## レシートを印刷する {#print-receipt}

**レシートを印刷**を押します。支払い完了画面に表示されているプリンターにレシートが送信されます。**自動 — 印刷ダイアログ**は、このレジにレシートプリンターが設定されておらず、代わりにブラウザーの印刷ウィンドウが開くことを意味します。そのウィンドウでプリンターを選択し、印刷を確定してください。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-26, 0], [272, 0], [251, 0], [146, 0]]} maxWidth={569} alt="印刷後の支払い完了画面の上部：閉じるボタン、お釣り、支払額と預り額、レシートの印刷先を示す行">

1. **✕** — **新しい販売**と同じく、販売を終了します。
2. **お釣り** — お客様に返す金額です。
3. **支払い方法** — 金額と使用した支払い方法です。
4. **印刷先** — レシートの送信先のプリンターまたは印刷ウィンドウです。実際に印刷されたことを確認してください。**レシートを印刷**は**再印刷**に変わり、追加の一枚を印刷できます。

</JourneyShot>

別の場所で印刷するには、先に**プリンター**で別のプリンターを選択します。レシートプリンターを追加するには、[プリンター](../hardware/printers/index.mdx#adding-a-printer)をご覧ください。

<details>
<summary>印刷に失敗した場合、またはキャンセルした場合</summary>

印刷できなかった場合、エラーコード付きのメッセージが表示されます。

- [PRINT101](../error-codes/PRINT101.mdx)：自動印刷が開始されませんでした。
- [PRINT201](../error-codes/PRINT201.mdx)：印刷ジョブが失敗したか、レジが完了を確認できませんでした。
- [PRINT301](../error-codes/PRINT301.mdx)：レジがプリンターに接続できませんでした。

印刷せずにブラウザーの印刷ウィンドウを閉じてもエラーにはなりません。印刷済みにはならず、**レシートを印刷**をもう一度押せます。

</details>

## レシートをメールで送信する {#email-receipt}

**レシートをメール送信**を押します。**メールアドレス**にお客様のアドレスを入力するか、注文の請求先メールアドレスから入力されたアドレスを確認します。注文にアドレスを保存するには、**メールアドレスを請求先住所に保存**をオンにします。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[54, -22]]} maxWidth={400} alt="レシートをメール送信ダイアログ：メールアドレス欄、メールアドレスを請求先住所に保存スイッチ、キャンセルと送信ボタン">

1. **送信** — レシートを送信します。送信されるか送信待ちになると、ダイアログが閉じます。

</JourneyShot>

店舗のメール設定を使ってメールが送信され、**メールを送信しました**と表示されます。店舗が送信を拒否した場合は、**サーバーがメールを送信しませんでした。** などのメッセージが表示され、ダイアログは開いたままになります。アドレスを確認して、再試行できます。

レジが店舗に接続できない場合、ボタンは**オンラインになったら送信**に変わります。レシートは送信待ちになり、接続が戻ると自動で送信されます。送信途中で接続が切れた場合も、同様に送信待ちになります。そのため、レジがオフラインでも支払い済みの販売のレシートをメールで送れます。

## 次の販売を開始する {#new-sale}

**新しい販売**を押すと、次のお客様のためにカートが空になります。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[111, -22], [118, -22], [93, -22], [104, -24]]} maxWidth={569} alt="印刷後の支払い完了画面の下部に並ぶボタン：レシートをメール送信、PDFをダウンロード、再印刷、新しい販売">

1. **レシートをメール送信** — お客様に送信します。
2. **PDFをダウンロード** — ファイルとして保存します。
3. **再印刷** — もう一枚印刷します。
4. **新しい販売** — 次のお客様のためにカートを空にします。

</JourneyShot>

幅の広い画面では、**新しい販売**は右側の塗りつぶされたボタンです。スマートフォンでは、支払い完了画面が画面全体に表示され、**新しい販売**は先頭の全幅ボタンになります。

<details>
<summary>ボタンに「レシートを印刷 · 新しい販売」と表示される場合</summary>

[チェックアウト後にレシートを自動印刷](#automatic-receipt-options)がオンの場合、レシートは自動で印刷され、ボタンには**レシートを印刷 · 新しい販売**と表示されます。印刷が開始されるまで処理中の状態が続きます。その後ボタンを押すと、次の販売が始まります。追加のレシートは印刷されません。

</details>

## レシートを再度開く {#reprinting-receipts}

後からレシートを再度開くことができます。

- **注文から**（WCPOS Pro）：注文行のレシートボタン、または開いた注文の下部にある**レシート**を使用します。[注文](../orders/index.mdx#receipt-reprinting)をご覧ください。
- **払い戻しから**：開いた注文には、払い戻しごとに**レシート**ボタンがあります。その払い戻し専用の**払い戻しレシート**が開きます。
- **支払い前にプレビューまたは印刷する**：カートの**チェックアウト**の横にある **⋮** を押し、**印刷**を押します。カート内の販売について、支払い前のレシートが表示されます。

**レシート**ウィンドウには、支払い完了画面と同じ**テンプレート**と**プリンター**の選択欄、およびズーム機能があります。各ボタンの動作も同じで、**閉じる**を押すと閉じます。

### プレビューを表示できない場合 {#preview-unavailable}

<details>
<summary>注文を同期してプレビューを表示する</summary>

まだ店舗に保存されていない注文は、テンプレートによっては表示できません。カートに残っている販売で発生します。**注文を同期**を押すと、注文の送信中は選択欄の上に**サーバーと同期中...** と表示されます。店舗に保存されると、**注文を同期**が消え、プレビューが表示され、**レシートをメール送信**と **PDFをダウンロード**が使えるようになります。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[235, 42], [94, -22], [59, -22], [111, -22], [118, -22], [133, -22]]} maxWidth={560} alt="まだ店舗に保存されていない注文のレシートウィンドウの下半分：プレビューのメッセージ、注文を同期、閉じる、レシートをメール送信、PDFをダウンロード、レシートを印刷ボタン。メール送信とダウンロードはグレー表示">

1. **プレビューを表示できません** — このテンプレートではまだ注文を表示できません。別のテンプレートを選ぶか、注文を同期してください。
2. **注文を同期** — 注文を店舗に送信します。注文がまだ店舗に保存されていない間だけ表示されます。
3. **閉じる** — ウィンドウを閉じます。
4. **レシートをメール送信** — 注文が店舗に保存されるまでグレー表示になります。
5. **PDFをダウンロード** — 注文が店舗に保存されるまでグレー表示になります。
6. **レシートを印刷** — プレビューがなくても利用できます。

</JourneyShot>

まだ店舗に保存されていない注文のレシートには、**店舗に未保存 · 注文番号なし**と表示されます。

</details>

## 自動印刷と支払い完了画面のスキップ {#automatic-receipt-options}

カートの表示設定にある二つのスイッチで、販売後の動作を設定できます。カート上部のスライダーボタンで開きます。[カート](../pos/cart/index.mdx#display-settings)をご覧ください。

- **チェックアウト後にレシートを自動表示**（デフォルトでオン）：支払い完了画面を表示します。オフの場合は、**注文の支払いが完了しました**というメッセージと注文番号が表示され、カートで次の販売を開始できます。
- **チェックアウト後にレシートを自動印刷**（デフォルトでオフ）：販売のたびに、支払い完了画面に表示されるプリンターでレシートを自動印刷します。支払い完了画面をオフにしていても動作します。レシートプリンターがない場合は、販売のたびに印刷ウィンドウが開きます。

これらのスイッチは端末ごとの設定です。クラウドプリンターには独自の自動印刷ルールがあります。[クラウド印刷](./cloud-printing.mdx#auto-print)をご覧ください。

## レシートの記載内容 {#receipt-contents}

店舗名、住所、ロゴ、注文番号と日付、商品、合計、支払い、顧客など、レシートの表示内容はテンプレートで決まります。変更するには、[レシートのカスタマイズ](./customise.mdx)をご覧ください。テンプレートで利用できるすべてのフィールドについては、[レシートデータ](./receipt-data.mdx)をご覧ください。

## 問題が発生した場合 {#goes-wrong}

**何も印刷されない。** **プリンター**の行を確認してから、[何も印刷されない場合](../hardware/printers/index.mdx#when-nothing-prints)をご覧ください。

**レシートをメール送信またはPDFをダウンロードがグレー表示になる。** 注文が店舗に保存されておらず、支払い済みの販売でもありません。カートに残っている販売で発生します。**レシート**ウィンドウで**注文を同期**を押してください。**PDFをダウンロード**には、レジがオンラインであることも必要です。

**レシートに「店舗の確認待ち」と表示される。** 販売はレジに保存されていますが、店舗がまだ確認していません。接続が戻ると送信されます。店舗側のデータを印刷するクラウドプリンターも確認を待つため、店舗に販売が保存されたら再印刷してください。
