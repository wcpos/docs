**WP管理画面：** `WP Admin → POS → Settings → General`で、オンライン注文用の**レシート**ボタンを有効にします。

:::note このページはウェブサイトの運営担当者向けです
[WCPOS Pro](../getting-started/pro-license.mdx)では、オンライン注文を含むどの注文でも、レジでレシートを印刷したりメールで送信したりできます。**注文**ページの[レシートの再印刷](../orders/index.mdx#receipt-reprinting)をご覧ください。
:::

:::tip お客様からオンライン注文のレシートを求められた場合
ウェブサイト側の設定が済んでいれば、**マイアカウント → 注文**の**レシート**ボタンから取得できます。ショップが注文確認ページにレシートのリンクを追加している場合は、そのリンクも利用できます。
:::

WCPOSのレシートテンプレートはウェブサイトでも使えます。オンラインで購入したお客様は、**マイアカウント**や注文確認ページに設置したリンクから、レシートをPDFでダウンロードできます。

## レシートボタンを有効にする {#my-account}

:::warning 先にレシートテンプレートを有効にしてください
始める前に、**POS → テンプレート**でテンプレートを有効にしてください。有効なテンプレートがないと、設定をオンにしてもお客様に**レシート**ボタンは表示されません。[レシートのカスタマイズ](./customise.mdx#option-1--pick-a-different-template)をご覧ください。
:::

ボタンは有効にするまでオフになっています。PDFはレシートテンプレートから作成されます。

1. WP Adminで**POS → 設定 → 一般**を開きます。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="WP AdminでメニューのPOS、設定が選択され、設定メニューの一般が開いている画面。店舗、レジ、商品セクションの冒頭が表示されています">

1. **POS → 設定** — POSの設定を開くWP Adminのメニュー項目です。
2. **一般** — 最初の設定画面です。設定を開くと、この画面が表示されます。

</JourneyShot>

2. **顧客**セクションまでスクロールし、**顧客によるレシートのダウンロードを許可**をオンにします。切り替えるとすぐに保存されます。

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="一般設定の顧客セクション。顧客のメールアドレスからユーザー名を自動生成、ゲストに設定されたデフォルトのPOS顧客、まだオフになっている顧客によるレシートのダウンロードを許可が表示されています">

1. **顧客** — レシートの設定があるセクションです。
2. **顧客によるレシートのダウンロードを許可** — 有効にするまでオフになっています。

</JourneyShot>

3. その下に**顧客用レシートテンプレート**が表示されます。**有効なレシートテンプレートを使用**のままにするか、テンプレートを選択します。[顧客用テンプレートの選択](#template-choice)をご覧ください。

これで、ログイン済みのお客様には、**マイアカウント → 注文**の各注文の横に**レシート**ボタンが表示されます。ボタンを押すと、`receipt-1234.pdf`のように注文に基づく名前のPDFがダウンロードされます。

ボタンは支払い済みの注文にのみ表示されます。

| 注文ステータス | レシートボタン |
|---|---|
| **処理中** | 表示 |
| **完了** | 表示 |
| **払い戻し済み** | 表示 |
| **支払い待ち**、**保留中**、**キャンセル**、**失敗**など、その他のステータス | 非表示 |

開発者は[ボタンを表示するステータスを変更](#developers)できます。

## 顧客用テンプレートの選択 {#template-choice}

**顧客用レシートテンプレート**で、ダウンロードに使用するテンプレートを設定します。

- **有効なレシートテンプレートを使用**（デフォルト）：**POS → テンプレート**で有効になっているレシートテンプレートがお客様に適用されます。そこで変更すると、ダウンロードにも反映されます。
- **名前を指定したテンプレート**：レジ係がレジで何を選んでも、お客様には常にそのテンプレートが適用されます。複数のレシートテンプレートが有効な場合や、オンライン注文専用のデザインにしたい場合に使います。

幅の狭い感熱紙用テンプレートからは、幅の狭いPDFが作成されます。オンライン注文では、通常はページ全体を使ったレイアウトのほうが読みやすくなります。ギャラリーの**請求書**テンプレートはA4およびレター用紙向けです。追加方法は[レシートのカスタマイズ](./customise.mdx#option-1--pick-a-different-template)をご覧ください。

PDFにはレジのレシートと同じ[レシートデータ](./receipt-data.mdx)が使われるため、ロゴ、店舗情報、税金設定も引き継がれます。

選択したテンプレートが後で削除されたり非公開になったりすると、ドロップダウンに**利用できないテンプレート**と表示され、お客様には代わりに有効なレシートテンプレートが適用されます。別のテンプレートを選択してください。

## 注文確認ページにレシートのリンクを追加する {#shortcode}

購入手続き後に表示される「ご注文ありがとうございます」ページに、**レシートをダウンロード (PDF)** リンクを設置します。アカウントを使わずに購入したゲストのお客様は、このリンクからレシートを取得できます。

WP Adminに**外観 → エディター → テンプレート → 注文確認**があれば、注文完了ページに自分でリンクを設置できます。

1. WP Adminで**外観 → エディター → テンプレート**に移動し、**注文確認**を開きます。
2. リンクを表示したい場所に**ショートコード**ブロックを追加し、`[wcpos_receipt]`と入力します。
3. **保存**を押します。

そのテンプレートがない場合や、**マイアカウント**内の注文ページにリンクを設置したい場合は、開発者に[コードからレシートのリンクを追加](#developers)してもらってください。

ショートコードは、**顧客によるレシートのダウンロードを許可**がオンでもオフでも機能します。この設定が制御するのは、**マイアカウント → 注文**のボタンだけです。

<details>
<summary>ショートコードのオプションと使用例</summary>

`[wcpos_receipt]`は、注文確認ページと**マイアカウント**内の注文ページで機能します。これらのページでは注文が自動的に特定されるため、注文番号の入力は不要です。それ以外のページでは、`order_id`を指定しないと何も表示されません。

| オプション | デフォルト | 機能 |
|---|---|---|
| `order_id` | *（ページから取得）* | 任意のページから特定の注文にリンクします。その注文を行ったログイン済みの顧客にのみ表示されます。 |
| `link_text` | `Download receipt (PDF)` | リンクの表示テキストです。 |
| `format` | `pdf` | `pdf`ではPDFをダウンロードします。`html`では印刷可能なレシートをブラウザーで開きます。 |
| `template` | *（有効なレシートテンプレート）* | 代わりにこのテンプレートを使います。 |
| `class` | `wcpos-receipt-link` | リンクのCSSクラスです。 |
| `id` | *（なし）* | リンクのHTML `id`です。 |

ショートコードの`template`オプションでは、**顧客用レシートテンプレート**の設定は参照されません。このオプションを省略すると、リンクには有効なレシートテンプレートが使われます。

独自の文言を使ったダウンロードリンク：

```text
[wcpos_receipt link_text="Download your invoice"]
```

PDFをダウンロードする代わりに、ブラウザーでレシートを開く場合：

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

80mmのレジ用レシートの代わりにA4の請求書を使うなど、特定のテンプレートを指定する場合：

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

テンプレート番号は、**POS → テンプレート**でテンプレートを編集するときにアドレスバーに表示されます(`post=123`)。公開されていないテンプレートは無視され、リンクには有効なレシートテンプレートが使われます。

</details>

## レシートを開ける人 {#security}

- **アカウントをお持ちのお客様**は、ログインして**マイアカウント → 注文**の**レシート**ボタンを使います。
- アカウントを使わずに購入した**ゲスト**は、注文確認ページに[リンクを設置](#shortcode)すると、そのリンクからレシートを取得できます。

:::warning レシートのリンクは該当のお客様にのみ共有してください
レシートのリンクを知っていれば、誰でもログインせずにそのレシートを開けます。注文情報と同じように慎重に扱ってください。
:::

<details>
<summary>レシートのリンクを保護する仕組み</summary>

すべてのレシートリンクには、WooCommerceが注文確認ページで使うものと同じ、その注文の秘密キーが含まれています。正しいキーがないとレシートは開けません。`order_id`オプションを指定したショートコードは、その注文を行ったログイン済みのお客様にのみリンクを表示します。

</details>

## 問題が発生した場合 {#goes-wrong}

以下の対処の多くはWP Adminで行います。レジ係の方は、お客様に表示されているメッセージをウェブサイトの運営担当者に伝えてください。その間も、[WCPOS Pro](../getting-started/pro-license.mdx)ならレジでレシートを印刷したりメールで送信したりできます。**注文**ページの[レシートの再印刷](../orders/index.mdx#receipt-reprinting)をご覧ください。

**お客様にレシートボタンが表示されない。** **顧客によるレシートのダウンロードを許可**がオンであること、注文が**処理中**、**完了**、**払い戻し済み**のいずれかであること、**POS → テンプレート**で少なくとも1つのレシートテンプレートが有効になっていることを確認してください。ボタンは、ログイン済みのお客様の**マイアカウント → 注文**にのみ表示されます。

**「レシートテンプレートが設定されていません。」** PDFの作成に使うテンプレートがありません。**POS → テンプレート**でレシートテンプレートを有効にしてください。

**「このレシートを表示する権限がありません。」** リンクが不完全か、正しくコピーされていません。各リンクには注文の秘密キーが含まれています。注文確認ページまたは**マイアカウント**のリンクを、もう一度お客様に送ってください。

**「レシートのPDFを生成できませんでした。」** テンプレートからPDFを作成できませんでした。**POS → テンプレート**で該当のテンプレートを開き、プレビューしてください。[レシートのカスタマイズ](./customise.mdx)をご覧ください。

**リンクを開くと「ページが見つかりません」エラーが表示される。** WP Adminで**設定 → パーマリンク**に移動し、**基本**以外のオプションを選んでください。**基本**ではレシートのリンクは機能しません。

## 開発者向け {#developers}

<details>
<summary>コードからレシートのリンクを追加する</summary>

クラシックテーマでは、該当ページを描画する2つのWooCommerceアクションからリンクを出力します。

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

どちらのページでもショートコードが注文を特定するため、`order_id`は不要です。

</details>

<details>
<summary>レシートボタンとPDFテンプレートのフィルター</summary>

上記の設定よりも優先される3つのフィルターがあります。注文ごとや顧客ごとなど、設定だけでは指定できないルールに使えます。

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

WCPOS 2.0より前は、これらのフィルターは`woocommerce_pos_storefront_receipt_*`という名前でした。これらの名前は引き続き使えますが、2.0以降は非推奨となっており、早ければ2.2で削除されます。[フックの命名](../extensions/index.mdx#hook-naming)をご覧ください。

PDFのアドレスは、`/wcpos-checkout/wcpos-receipt/{order_id}`に`?key={order_key}&format=pdf`を付けたものです。POSが使うものと同じ、キーでアクセスを制限したレシートのアドレスで、`format=pdf`を指定するとページの代わりにPDFが返されます。

</details>
