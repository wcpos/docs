**WP 管理画面：** テンプレートは `WP Admin → POS → Templates` で選びます。

WCPOS が印刷するすべてのレシートは、テンプレートに販売データを埋め込んだものです。**WP 管理画面 → POS → テンプレート**でテンプレートを選ぶと、レジ係が別のものを選ばない限り、レジは先頭の有効なテンプレートを印刷します。同じ画面で、請求書、ギフトレシート、納品書、キッチン伝票も扱います。

必要な項目へ：

- **レジでの操作：** [レシートの印刷](#at-the-till)、[メール送信](#email)、[後からの再印刷](#reprint)。
- **店舗オーナー：** [店舗のレシートを選ぶ](#how-it-works)、[印刷先を指定する](#template-printers)。

## レジでの操作 {#at-the-till}

販売の支払いが完了すると、支払い完了画面にレシートが表示されます。印刷するには：

1. プレビュー (5) でレシートを確認します。
2. **プリンター** (4) を確認します。**自動**では、テンプレートに適したプリンターが選ばれます。
3. **レシートを印刷** (6) をタップします。最初の印刷後は**もう一度印刷**に変わります。

2 つのボタンの間にある **PDF をダウンロード**は、レシートをファイルとして保存します。接続が必要です。

### レシートのメール送信 {#email}

1. **レシートをメールで送信**をタップします。
2. **メールアドレス**を確認します。最初は注文の請求先メールアドレスが入っています。新しいアドレスを注文に保存するには、**メールアドレスを請求先住所に保存**をオンにします。
3. **送信**をタップします。

お客様には、プレビューに表示されたテンプレートではなく、その注文の WooCommerce 請求書メールが届きます。オフラインではボタンが**オンライン時に送信**となり、デバイスが店舗に再接続したときに送信されます。

### レシートの再印刷 {#reprint}

[WCPOS Pro](../getting-started/pro-license.mdx) では、後から再印刷できます：

1. サイドメニューから**注文**を開きます。
2. 注文を探し、そのレシートボタンをタップします。
3. 開いたレシート画面から印刷します。

Pro をお使いでない場合は、**新しい販売**をタップする前に、支払い完了画面からレシートを印刷またはメール送信してください。

詳しくは、[レシートの再印刷](./at-checkout.mdx#reprinting-receipts)をご覧ください。

### 今回の販売だけ別のレシートを使う {#one-sale}

レジ係は、支払い完了画面の**テンプレート**から別の有効なテンプレートを選べます。選択は今回の販売だけに適用されます。有効なテンプレートが 1 つの場合、**テンプレート**にはその名前だけが表示され、選択肢はありません。

## レシートを選ぶ {#how-it-works}

:::tip レシートを変更したいだけですか？
まず **[レシートのカスタマイズ](./customise.mdx)** をご覧ください。別の付属テンプレートを選ぶ、AI に調整を依頼する、手動で編集するという、簡単な 3 つの方法を説明しています。
:::

店舗オーナーが WP 管理画面で一度設定します：

1. WP 管理画面で **POS → テンプレート**に移動します。**レシート**タブの上部に**自分のテンプレート**、その下に**テンプレートギャラリー**が表示されます。
2. ギャラリーでは、**テンプレートを検索...**、**カテゴリー**、**形式**、**方向**でカードを絞り込みます。**プレビュー**には、**サンプルデータ**または実際の注文データを埋め込んだテンプレートが表示されます。
3. **テンプレートを使用**をクリックします。**自分のテンプレート**の一覧の末尾に、有効になった状態でコピーが追加されます。
4. そのコピーを**自分のテンプレート**の先頭にドラッグします。レジは先頭の有効なテンプレートを既定として使います。内蔵の**従来の PHP テンプレート**より上に移動するか、その**有効**スイッチをオフにするまでは、従来のテンプレートが優先されます。

文言や見た目を変更するには、コピーをテンプレートエディターで開きます。編集中はライブプレビューで確認できます。[レシートのカスタマイズ](./customise.mdx)をご覧ください。

## テンプレートごとに印刷先を指定する {#template-printers}

アプリの**設定 → 印刷**では、レジで印刷できるテンプレートが**レシートテンプレート**に表示され、その下に**レポートテンプレート**と**締め処理テンプレート**が並びます。各行には次の情報が表示されます：

- **テンプレート**：内蔵の**従来の PHP テンプレート**など。
- **種類**：印刷ダイアログ用は **HTML**、サーマルテンプレートは**サーマル 80mm**などの用紙情報が表示されます。
- **プリンター**：**自動**では、テンプレートの種類と用紙幅に適したプリンターが選ばれます。該当するプリンターがない場合は**印刷ダイアログ**が開きます。常に同じプリンターに送るには、そのプリンターを選んでください。

プリンターの追加については、[プリンター](../hardware/printers/index.mdx#adding-a-printer)をご覧ください。

## レシートに印刷される内容 {#what-prints}

サンプルデータを使い、ギャラリーでプレビューした**標準レシート**です。その下で各部分とデータの取得元を説明します。

<div style={{maxWidth:'520px', marginInline:'auto'}}>

![標準レシートのプレビュー。左上に Coffee Monster のロゴ、名前、住所、電話番号、EIN、右上に注文番号、日付、レジ係、お客様、中央に割引行付きの明細、小計、合計、返金済み金額、差引合計、返品商品の枠、お客様メモの枠、お預かり金額とお釣りを含む現金払い、最後にお礼の一文が表示されています](/img/2.x/receipts/index/en/standard-receipt-gallery-preview.webp)

- **左上**（ロゴ、名前、住所、電話番号、納税者 ID）：店舗の詳細です。Pro をお使いでない場合は **POS → 設定**の**店舗の詳細**と**店舗の納税者 ID**から取得され、ロゴには WordPress サイトのロゴが使われます。Pro では、各店舗の**詳細**ページと**税**ページに独自の情報を設定できます。
- **右上**（注文番号、日付、レジ係、お客様）：注文から取得します。
- **中央**（明細、割引、合計）：注文から取得し、税設定に従った価格を表示します。[設定に応じた税表示](#adaptive-tax-display)をご覧ください。
- **2 つの枠**（返品商品とお客様メモ）：注文に返金やメモがある場合に表示します。
- **支払い済み**（下部付近）：各支払いと、お預かり現金、お釣りです。
- **最下部**（お礼の一文）：Pro では各店舗の**レシートメッセージ**です。それ以外の場合は、標準のお礼の文が印刷されます。

</div>

納税者 ID は[店舗の納税者 ID](../settings/wp-admin/store-tax-ids.mdx)、各店舗の詳細（Pro）は[店舗の各ページへの入力](../stores/setup.mdx#store-pages)で説明しています。テンプレートで印刷できるすべてのフィールドは、[レシートデータ](./receipt-data.mdx)に記載されています。

価格を表示する付属テンプレートでは、商品がセール中の場合やレジで価格を変更した場合に、通常価格と割引額が印刷されます（[カートの割引](../pos/cart/discounts.mdx#showing-the-original-price-and-saving-on-receipts)）。独自のテンプレートに追加するには、[通常価格と割引額の表示](./receipt-data.mdx#displaying-regular-price-and-savings)をご覧ください。

## Pro：店舗ごとのレシート {#pro-features}

[WCPOS Pro](../getting-started/pro-license.mdx) では、各店舗が独自のレシートを印刷できます。**POS → 店舗**で店舗を開きます：

- **レシート**：店舗の**レシートテンプレート**一覧には、**カスタマイズ**をクリックするまで**サイトと同じ**と表示されます。クリックしたら、その店舗でレジ係が印刷できるものにチェックを入れます。最初にチェックされたテンプレートが店舗の既定になり、ドラッグで順序を変更できます。**サイトのテンプレートを使用**で元に戻せます。同じページに店舗の**レシートメッセージ**もあります。
- **詳細**：**ロゴと住所**には**サイトのロゴを使用**または**ロゴをアップロード**があり、店舗の**連絡先**情報も設定できます。

[店舗の各ページへの入力](../stores/setup.mdx#store-pages)と[店舗ごとのテンプレート](./customise.mdx#per-store-assignments)をご覧ください。

## レジ以外でのレシート {#beyond-the-till}

- **メール**：レジの**レシートをメールで送信**は、WCPOS テンプレートではなく、WooCommerce 独自のお客様向け請求書メールを送信します。見た目は **WooCommerce → 設定 → メール**で変更できます。
- **PDF をダウンロード**：サーバーが PDF を生成するため、接続が必要です。
- **オンラインのお客様**：**お客様によるレシートのダウンロードを許可**をオンにすると、マイアカウントの注文に**レシート**ボタンが追加されます。有効にするまではオフです。**お客様用レシートテンプレート**で、使用するテンプレートを選べます。[オンラインショップのレシート](./storefront.mdx)をご覧ください。

<Accordion>
  <AccordionItem question="テンプレート編集者向け：レシートデータ">

すべてのテンプレートは、店舗の詳細、明細、合計、税、支払い、返金など、共通の[レシートデータ](./receipt-data.mdx)を使って印刷します。各金額には、`29.99` に対する `$29.99` のように、書式設定済みの `_display` 版もあります。

## 問題が起きた場合 {#goes-wrong}

**新しいテンプレートで印刷されません。** レジは**自分のテンプレート**の先頭にある有効なテンプレートを使います。使いたいものを先頭にドラッグするか、その上にあるものを無効にしてください。1 回の販売だけなら、レジ係が支払い完了画面の**テンプレート**から選べます。

**支払い完了画面のテンプレートに名前は表示されますが、一覧がありません。** 有効なレシートテンプレートが 1 つだけです。レジ係が選べるようにするには、**自分のテンプレート**で別のテンプレートを有効にしてください。

**オフラインでテンプレートを選べません。** **従来の PHP テンプレート**と WP Overnight のテンプレートはサーバーで生成されます。レジの接続がよく切れる場合は、HTML またはサーマルテンプレートを既定にしてください。

**ロゴが表示されません。** Pro をお使いでない場合、レシートは WordPress サイトのロゴを使うため、テーマでロゴを設定してください。Pro では、店舗の**詳細**を開き、**サイトのロゴを使用**または**ロゴをアップロード**を選びます。ブラウザーのタブから印刷した場合だけロゴが表示されない場合は、[ブラウザーでロゴが表示されない](../hardware/printers/logo-missing-browser.mdx)をご覧ください。

**何も印刷されない、または別のプリンターで印刷されます。** **設定 → 印刷**でテンプレートのプリンターを確認し、[何も印刷されない場合](../hardware/printers/index.mdx#when-nothing-prints)をご覧ください。

## テンプレートギャラリー {#template-gallery}

ギャラリーには、そのまま使うこともカスタマイズすることもできる既製テンプレートが付属しています。**カテゴリー**（レシート、請求書、ギフトレシート、クレジットノート、発注書、キッチン伝票、バー伝票）、**形式**（**HTML（ブラウザー印刷）** または **ESC/POS（サーマルプリンター）**）、**方向**（**左から右**または**右から左**）で絞り込めます。各カードには**プレビュー**と**テンプレートを使用**があります。**テンプレートを使用**は、*自分のテンプレート*に編集可能なコピーを作成し、ギャラリーの原本をそのまま残します。

コピー元のテンプレートがギャラリーで更新されると、カードに**更新あり**と表示されます。**新しいバージョンをインストール**は、新版を別のコピーとして追加するため、編集内容は保持されます。

### サードパーティーの書類テンプレート {#third-party-document-templates}

WP Overnight の **PDF Invoices & Packing Slips for WooCommerce** を有効にすると、その請求書と納品書がレシートテンプレートに追加されます。印刷には接続が必要です。

<Accordion>
  <AccordionItem question="WP Overnight テンプレートの仕組み">

WCPOS は、レシートテンプレートに**請求書（WP Overnight）** と**納品書（WP Overnight）** を有効な状態で追加します。注文を WP Overnight の書類 API に渡すため、そのプラグインで設定した請求書と納品書の採番、レイアウト、ブランド表現、法務・税務フィールド、テンプレートの変更が維持されます。

これらは WP Overnight プラグインが有効な間だけ表示され、サーバーで描画されます。オフラインで印刷する必要がある場合は、付属の HTML またはサーマルテンプレートを使ってください。[WP Overnight テンプレート](./customise.mdx#wp-overnight-invoice-and-packing-slip-templates)をご覧ください。

  </AccordionItem>
</Accordion>

### 設定に応じた税表示 {#adaptive-tax-display}

ほとんどの付属テンプレートは、WooCommerce の税表示設定に合わせて、税込または税抜の価格を印刷します。

<Accordion>
  <AccordionItem question="設定に従うテンプレートとその表示方法">

標準、標準 RTL、ミニマル/モダン、幅狭、請求書、見積書、シンプルなサーマルの各テンプレートは、**WooCommerce の税表示設定に従います**：

- **税込価格を表示する店舗**（EU/UK/AU）では、税込価格と「税込」の行が印刷されます。
- **税抜価格を表示する店舗**（US/CA）では、税抜価格が印刷され、税額が**税合計**という別の行に加算表示されます。
- 総合計には、実際に請求された税込金額が常に表示されます。

**詳細**テンプレートは正式な税務用請求書です。明細は常に税抜で表示され、その後に税率ごとの内訳が続きます。設定に従うのは税の見出しだけです。

  </AccordionItem>
</Accordion>

## テンプレートエンジン {#template-engines}

各テンプレートは、**HTML（オフライン）**、**XML（レシートプリンター）**、**PHP（従来版）** の 3 つのエンジンのいずれかを使います。HTML と XML はオフラインで印刷できますが、PHP はサーバーが必要です。

<Accordion>
  <AccordionItem question="3 つのエンジン">

エンジンはテンプレート作成時に選ぶか、**テンプレートを使用**をクリックしたギャラリーカードによって決まります。**テンプレートの保存後は変更できません**。切り替えるには新しいテンプレートを作成してください。

<FeatureGrid>
  <FeatureCard icon="code" title="HTML（オフライン）、推奨">
    ロジックを持たない HTML で、 <code>{"{{variable}}"}</code> プレースホルダーを使います。デバイス上で描画されるため、**オフラインで印刷できます**。印刷ダイアログ用です。
  </FeatureCard>
  <FeatureCard icon="print" title="XML（レシートプリンター）">
    画面プレビューとサーマルレシートプリンター用の **ESC/POS コマンド**の両方を生成する XML です。1 つのテンプレートから 2 種類の出力を得られます。Epson、Star などのサーマルプリンター用です。
  </FeatureCard>
  <FeatureCard icon="terminal" title="PHP（従来版）">
    WooCommerce の関数を使うサーバー側の PHP です。既存の <code>yourtheme/woocommerce-pos/receipt.php</code> による上書きと、内蔵の**従来の PHP テンプレート**のために残されています。描画にはサーバーへの接続が必要で、レシート専用です。
  </FeatureCard>
</FeatureGrid>
