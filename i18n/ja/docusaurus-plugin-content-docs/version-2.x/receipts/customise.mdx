**WP管理画面：** `WP Admin → POS → Templates`。

レシートはテンプレートから作成されます。見た目を変えるには、別のテンプレートを選ぶ、AIに変更を依頼する、手動で編集するという方法があります。まずはテンプレートの選択から始めてください。ほとんどの店舗では、ほかの方法を使う必要はありません。

1回の販売だけ別のレシートを使う場合は、レジ係がレシート画面の**テンプレート**で選択します。[レジでの表示](#at-the-till)をご覧ください。

## カスタマイズする3つの方法 {#three-ways-to-customise}

どの方法も、WP管理画面の **POS → テンプレート**から始めます。**レシート**タブには、上部にレジ係が印刷できる**自分のテンプレート**、その下にひな形が並ぶ**テンプレートギャラリー**があります。

ロゴ、お礼のメッセージ、フッターを変える場合は、まず設定を確認してください。[よく使うカスタマイズ](#common-customisations)をご覧ください。

- **[別のテンプレートを選ぶ](#option-1--pick-a-different-template)**：ギャラリーの既成テンプレートを使う方法で、**コードは一切不要**です。レイアウトの変更、価格の非表示、A4請求書やキッチン伝票の作成に適しています。
- **[AIに調整を依頼する](#option-2--ask-ai-to-tweak-it)**：テンプレートをChatGPTやClaudeに貼り付け、希望を普段の言葉で伝える方法で、**プログラミングは不要**です。文言や色、配置の変更に適しています。
- **[手動で編集する](#option-3--edit-it-by-hand)**：ライブプレビューを見ながらエディターでテンプレートを変更します。細かく調整したい場合や、HTMLの知識がある場合に適しています。

## 方法1 — 別のテンプレートを選ぶ {#option-1--pick-a-different-template}

**テンプレートギャラリー**は、**レシート**タブの**自分のテンプレート**の下にあります。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[143, 0], [185, 0], [86, 0], [71, 0], [0, 0], [110, 0], [69, 0], [45, -48]]} alt="WP管理画面のPOS、テンプレートでテンプレートギャラリーまでスクロールした状態。左側に検索ボックスとカテゴリー、形式のフィルターがあり、詳細レシート、ギフトレシート、請求書の各カードには画像、タグ、プレビュー、テンプレートを使用が表示されています">

1. **テンプレートギャラリー** — 既成のひな形です。使用しても元のテンプレートは変わりません。
2. **テンプレートを検索...** — 名前でテンプレートを検索します。
3. **カテゴリー** — レシート、ギフトレシート、請求書、発注書、キッチン伝票から選びます。その下に**形式**と**方向**があります。
4. **形式** — ブラウザーやPDF、またはレシートプリンターでの印刷形式です。**HTML（ブラウザー印刷）** または **ESC/POS（サーマルプリンター）** を選びます。
5. **カードの画像** — クリックすると、データが入ったテンプレートを確認できます。
6. **タグ** — 印刷方法を示します。サイトに接続せずレジで生成できる場合は、**オフライン対応**と表示されます。
7. **プレビュー** — **サンプルデータ**または最新の**注文**を使って、同じプレビューを表示します。
8. **テンプレートを使用** — 有効な状態で**自分のテンプレート**にコピーします。

</JourneyShot>

1. WP管理画面で **POS → テンプレート**を開き、**テンプレートギャラリー**までスクロールします。
2. **テンプレートを検索...** またはその横のフィルターで、ギャラリーを絞り込みます。
3. カードの画像か、その下の**プレビュー**をクリックすると、データが入ったテンプレートを確認できます。**サンプルデータ**では架空の商品が、**注文**では最新のPOS注文が表示されます。
4. **テンプレートを使用**をクリックします。有効になったコピーが**自分のテンプレート**に追加され、レジ係は次のレシートから印刷できます。

同じタブの上部にある**自分のテンプレート**には、レジ係が印刷できるテンプレートが一覧表示されます。先頭がデフォルトになるため、組み込みの**旧式PHPテンプレート**が先頭にある間は、別のテンプレートをその上に移動するまでデフォルトのままです。各行には次の項目があります。

- **≡ ハンドル** — 行を上下にドラッグします。
- **有効** — 切り替えスイッチです。オフにすると、レジ係にはそのテンプレートが表示されません。
- **アクション**の **↑ ↓** — 行を1つ上または下に移動します。
- **プレビュー** — データが入った状態を表示します。
- **編集** — エディターでテンプレートを開きます。自分で作ったコピーにのみ表示され、組み込みの**旧式PHPテンプレート**には**編集**も**削除**もありません。
- **新しいバージョンをインストール** — **更新あり**と表示される場合、コピー後にギャラリーのカードが更新されています。編集内容を残したまま、新しいバージョンを別のテンプレートとして追加します。
- **削除** — 確認後、コピーを完全に削除します。

5. **自分のテンプレート**で、デフォルトで印刷したいものを先頭に移動します。行の≡ハンドルをドラッグするか、**アクション**の↑矢印をクリックしてください。レジ係に表示しないテンプレートは、**有効**をオフにします。

:::tip 「テンプレートを使用」で元のテンプレートが変わることはありません
**テンプレートを使用**をクリックするたびに新しいコピーが作成されるため、ギャラリーのカードは元のままです。同じカードを2回使って、2つのバージョンを並べて試すこともできます。
:::

### 付属のテンプレート {#the-bundled-templates}

ギャラリーには、ブラウザーの印刷ウィンドウやPDFで印刷するHTMLテンプレートが9種類、レシートプリンター用のサーマルテンプレートが6種類付属しています。ほとんどの店舗には**標準レシート**が適しています。[テンプレートエンジン](./index.mdx#template-engines)をご覧ください。

<Accordion>
  <AccordionItem question="付属テンプレート全15種類とそれぞれの用途">

| テンプレート | 形式 | 用途 |
|---|---|---|
| **標準レシート** | HTML | ロゴ、商品、合計、支払い。ほとんどの店舗に対応 |
| **標準レシート（RTL）** | HTML | 標準と同じ内容を、アラビア語、ヘブライ語、ペルシャ語、ウルドゥー語向けに左右反転 |
| **ミニマル / モダン** | HTML | 標準と同じ情報を、より省スペースで表示 |
| **詳細レシート** | HTML | SKU列、単価、税率別の税額、住所を含む詳細な税務用請求書 |
| **ギフトレシート** | HTML | 商品のみで価格は非表示。ギフトメッセージと返品ポリシーを追加 |
| **請求書** | HTML | A4またはレターサイズの全面を使う請求書。未払いの注文には「お支払い方法」パネルを追加 |
| **納品書** | HTML | 商品と数量、配送先住所を表示し、価格は非表示 |
| **見積書 / 概算見積書** | HTML | 販売前の価格と条件を表示し、支払い欄はなし |
| **幅狭レシート** | HTML | 幅の狭い用紙やHTML対応レシートプリンター向けの等幅フォントのレシート |
| **シンプルなサーマルレシート（58mm）** | サーマル | すっきりした58 mm幅のレシート |
| **シンプルなサーマルレシート（80mm）** | サーマル | 最も一般的なサイズで、すっきりした80 mm幅のレシート |
| **シンプルなサーマルレシート80mm（RTL）** | サーマル | 右から左に表示する80 mm幅のレシート。アラビア語のコードページを備えたプリンターが必要 |
| **詳細サーマルレシート（58mm）** | サーマル | 税の内訳、住所、払い戻し、支払い、条件、バーコードを追加 |
| **詳細サーマルレシート（80mm）** | サーマル | 同じ内容を80 mm幅の用紙に印刷 |
| **キッチン伝票** | サーマル | 厨房や調理スペース向けに商品のみを大きな文字で表示し、価格は非表示 |

</AccordionItem>

  <AccordionItem question="付属テンプレートの価格と税の表示方法">

価格を表示する付属テンプレートは、**WooCommerce → 設定 → 税**の**カートと購入手続きで価格を表示**の設定に従います。**税込**では税込価格と**内税**の行を印刷し、**税抜**では税抜価格と別の行に税額を印刷します。**詳細**テンプレートでは、常に税の詳細な内訳を印刷します。

</AccordionItem>
</Accordion>

### WP Overnightの請求書と納品書テンプレート {#wp-overnight-invoice-and-packing-slip-templates}

サイトでWP Overnightの [PDF Invoices & Packing Slips for WooCommerce](https://wordpress.org/plugins/woocommerce-pdf-invoices-packing-slips/) も使用している場合、**自分のテンプレート**に**請求書（WP Overnight）** と**納品書（WP Overnight）** も表示されます。レジからサイトに接続できるときだけ印刷できます。

<Accordion>
  <AccordionItem question="WP Overnightテンプレートの仕組み">

| テンプレート | 形式 | 用途 |
|---|---|---|
| **請求書（WP Overnight）** | サイトで生成 | POS注文用のWP Overnightの請求書 |
| **納品書（WP Overnight）** | サイトで生成 | POS注文用のWP Overnightの納品書 |

これらの書類はWP Overnightが生成するため、請求書番号、ブランド表示、税の項目、WP Overnightのレイアウトがオンライン注文と一致します。このプラグインが有効な間だけ表示され、PDFのダウンロードではなく、WCPOSの印刷画面内のページとして開きます。

**自分のテンプレート**では、これらの**モード**は**サーバー**です。印刷には、レジからサイトへの接続が必要です。オフラインで印刷するには、付属のHTMLまたはサーマルテンプレートを使用してください。

</AccordionItem>
</Accordion>

## 方法2 — AIに調整を依頼する {#option-2--ask-ai-to-tweak-it}

ギャラリーのテンプレートが希望に近くても少し違う場合は、AIアシスタントに変更を依頼できます。HTMLの知識は不要です。

:::tip 現在のレシートで印刷を続ける
新しいコピーは最初から有効なため、編集中でもレジ係が印刷できてしまいます。手順1で、まず無効にします。
:::

1. **作業用のコピーを作成します。** ベースにするギャラリーのカードで**テンプレートを使用**をクリックします。**自分のテンプレート**で、新しいコピーの**有効**をオフにします。
2. **テンプレートをコピーします。** 作業用コピーの行で**編集**をクリックします。コード内をクリックし、すべてを選択（Ctrl/Cmd + A）してコピーします。
3. **ChatGPTまたはClaudeに貼り付けます。** [ChatGPT](https://chat.openai.com) または [Claude](https://claude.ai) を開き、テンプレートを貼り付けます。
4. 普段の言葉で**変更したい内容を伝え**、波括弧の中はすべてそのままにするよう依頼します。例えば、*「店舗名を大きくして中央に配置してください。」* と伝えます。
5. **回答を貼り戻し、プレビューを確認します。** テンプレートエディターですべてを選択し、新しいバージョンを貼り付けます。貼り付けるとコードの下のプレビューが更新されます。店舗名、商品、合計、支払いが引き続き表示されることを確認してください。不足や誤りがあれば、AIに問題を伝えて再度試します。
6. **保存します。** **更新**をクリックします。
7. **有効にします。** **自分のテンプレート**で新しいコピーの**有効**をオンにし、≡ハンドルか↑矢印で先頭に移動してデフォルトにします。置き換え前のレシートの**有効**はオフにします。

<Accordion>
  <AccordionItem question="ほかの依頼例">

- *「下部に斜体でお礼のメッセージを追加してください。」*
- *「顧客名を非表示にしてください。代わりに、注文番号の下に電話番号を配置してください。」*
- *「返品案内ページへのリンクを示すQRコードを追加してください。」*
- *「店舗名の下に『1987年創業の家族経営店』というキャッチフレーズを追加してください。」*

</AccordionItem>
</Accordion>

:::info 波括弧の部分はどうすればよいですか？
`{{store.name}}` や `{{order.number}}` は、実際のデータを表示するための**プレースホルダー**です。AIには変更しないよう依頼し、その後、レシートに期待どおりの情報が表示されることを確認してください。すべてのプレースホルダーは[レシートデータリファレンス](./receipt-data.mdx)に記載されています。
:::

## 方法3 — 手動で編集する {#option-3--edit-it-by-hand}

HTMLの知識がある場合や開発者と一緒に作業する場合は、テンプレートを直接編集できます。**自分のテンプレート**の該当行で**編集**をクリックしてエディターを開くか、一覧上部の**新しいテンプレートを追加**をクリックして空のテンプレートから始めます。

エディターにはコードが表示され、左側の**フィールド**でプレースホルダーを検索して挿入できます。コードの下にはライブプレビューがあります。**更新**をクリックするまで保存されません。

テンプレートの種類を選びます。

- **[HTMLテンプレート](./html-templates.mdx)**：ブラウザーやPDFで印刷します。`{{variable}}` プレースホルダーを含む通常のHTMLで、レジで生成するためオフラインでも使えます。**ほとんどの店舗におすすめです。**
- **[サーマルテンプレート](./thermal-templates.mdx)**：レシートプリンターで印刷します。XMLで記述し、同じテンプレートから画面のプレビューと印刷物を生成します。

使用できるフィールドは[レシートデータリファレンス](./receipt-data.mdx)をご覧ください。利用可能なすべてのプレースホルダーをセクション別に掲載しています。

<Accordion>
  <AccordionItem question="エディターのツールバーの機能">

入力中のコードは色分けされます。ツールバーには**元に戻す**、**やり直す**、**検索**（置換機能付き）、**折り返し**、**整形**、**すべて折りたたむ**、**すべて展開する**があります。

</AccordionItem>

  <AccordionItem question="旧式PHPテンプレート">

テーマ内のPHPファイル(`yourtheme/woocommerce-pos/receipt.php`)で上書きしたレシートも引き続き使えます。**自分のテンプレート**には**テーマのレシートテンプレート**と表示され、サイトで印刷処理を行うため、レジには接続が必要です。プラグイン標準のPHPレシートは**旧式PHPテンプレート**と表示されます。新しく作成する場合は、ギャラリーかエディターを使ってください。これらのテンプレートはオフラインで使え、入力しながらプレビューを確認できます。

</AccordionItem>
</Accordion>

## レジでの表示 {#at-the-till}

作成方法にかかわらず、**自分のテンプレート**で有効なテンプレートがレジに表示されます。レシート画面の**テンプレート**には、有効なすべてのテンプレートが**自分のテンプレート**と同じ順序で並びます。販売ごとに先頭が選択されますが、レジ係はそのレシートに別のテンプレートを選べます。

有効なテンプレートが1つだけの場合、**テンプレート**にはその名前が表示され、選択肢はありません。オフライン時には、WP Overnightなどサイトへの接続が必要なテンプレートはグレー表示になります。各テンプレートの印刷先はレジごとに設定します。[印刷先の振り分け](../hardware/printers/index.mdx#print-routing)をご覧ください。

## 店舗ごとの割り当て {#per-store-assignments}

:::info Pro機能
複数の店舗を利用するには、[WCPOS Pro](../getting-started/pro-license.mdx) が必要です。
:::

複数の[店舗](../stores/index.mdx)がある場合、店舗ごとに使用するテンプレートとその順序を設定できます。カフェは小型のサーマルレシート、倉庫は納品書、本店は標準レシートというように、すべて同じ**自分のテンプレート**一覧から選べます。店舗が1つの場合、この設定は不要です。どのレジでも**自分のテンプレート**が使用されます。

**POS → 店舗**にある、各店舗の**レシート**ページ：

<JourneyShot manifest={manifest} device="desktop" step={2} offsets={[[98, 0], [115, 0], [115, 0], [60, 0], [246, 0], [-40, 0], [418, 41], [-40, 0]]} alt="WP管理画面の店舗のレシートページ。販売の下にあるレシート項目、お礼のメッセージ、返品ポリシー、フッターの入力欄、「サイトと同じ」と表示されカスタマイズボタンがあるレシートテンプレートの行、サンプル販売と最新の注文を選べるレシートプレビュー">

1. **レシート** — **販売**の下にある店舗のレシートページです。
2. **お礼のメッセージ** — この店舗のレシートに表示するお礼の文言です。
3. **返品ポリシー** — この店舗の返品条件です。
4. **フッター** — 会社登録番号などを表示する、レシートの最後の行です。
5. **サイトと同じ** — サイトのテンプレートを店舗で使用します。横にデフォルトのテンプレート名が表示されます。
6. **カスタマイズ** — この店舗で使う独自のテンプレートと順序を選びます。
7. **レシートプレビュー** — テンプレートを選び、この店舗のレシートを確認します。
8. **サンプル販売** — 架空の商品でプレビューします。**最新の注文**では店舗の最新の注文を使用します。

</JourneyShot>

<Accordion>
  <AccordionItem question="店舗ごとに異なるレシートを使う">

1. WP管理画面で **POS → 店舗**を開き、店舗名をクリックします。
2. 店舗のメニューで、**販売**の下にある**レシート**を開きます。
3. **レシートテンプレート**には、**サイトと同じ**とサイトのデフォルトのテンプレートが表示されています。**カスタマイズ**をクリックします。
4. この店舗のレジ係が印刷できるテンプレートにチェックを入れます。チェックの入った先頭のテンプレートがデフォルトです。≡ハンドルをドラッグして順序を変更できます。店舗の表示が**この店舗用にカスタマイズ済み**に変わります。

変更はその都度保存されます。**サイトのテンプレートを使用**で、サイトの一覧に戻せます。

店舗で使えるのは、**自分のテンプレート**で有効なテンプレートだけです。そこで無効になっているものには**印刷されません**と表示されます。店舗でチェックしたテンプレートがすべて無効な場合は、サイトの一覧が使われます。レジ係が店舗にサインインすると、**テンプレート**にはその店舗のテンプレートだけが表示されます。

同じ**レシート**ページの**レシートのメッセージ**には、店舗の**お礼のメッセージ**、**返品ポリシー**、**フッター**があります。**レシートプレビュー**で、**サンプル販売**または店舗の**最新の注文**を使った結果を確認できます。店舗のロゴと住所は**詳細**ページにあります。付属テンプレートは店舗ごとの情報を印刷するため、1つの標準レシートで各店舗のブランドを表現できます。[店舗の設定](../stores/setup.mdx#store-pages)をご覧ください。

</AccordionItem>
</Accordion>

## よく使うカスタマイズ {#common-customisations}

<Accordion>
  <AccordionItem question="店舗のロゴを追加するにはどうすればよいですか？">

ロゴはテンプレートではなく、設定から取得します。

- **Proを使わない場合：** テーマが表示するWordPressサイトのロゴがレシートに使われます。
- **Proを使う場合：** 店舗ごとにロゴを設定できます。**POS → 店舗**で店舗を開き、**詳細**の**ロゴと住所**に進みます。**店舗ロゴ**をアップロードするか、**サイトのロゴを使用**をクリックします。

ロゴを表示するすべての付属テンプレートに反映されます。ロゴの位置を変えるには、テンプレートを編集し、次のブロックを移動します： `{{#store.logo}}<img src="{{store.logo}}" ...>{{/store.logo}}` 。

</AccordionItem>

  <AccordionItem question="お礼のメッセージやフッターを変更するにはどうすればよいですか？">

Proでは、店舗ごとに一度設定すれば使えます。**POS → 店舗**で店舗を開き、**レシート**の**お礼のメッセージ**、**返品ポリシー**、**フッター**を設定します。付属テンプレートは、これらを `{{store.personal_notes}}`、`{{store.policies_and_conditions}}`、`{{store.footer_imprint}}` として印刷します。お礼のメッセージが未設定の場合、ほとんどの付属テンプレートでは *「お買い上げありがとうございます！」* と印刷されます。

Proを使わない場合はお礼のメッセージを設定する項目がないため、デフォルトの文言が印刷されます。返品ポリシーは **POS → 設定 → 一般**の**店舗の詳細**にある**払い戻し・返品ポリシー**で設定します。

1つのテンプレートだけ文言を変えるには、そのテンプレートを編集し、`{{store.personal_notes}}` またはその周囲のテキストを希望の内容に置き換えます。

</AccordionItem>

  <AccordionItem question="店舗名の下にキャッチフレーズを追加するにはどうすればよいですか？">

テンプレートを編集し、`{{store.name}}` の下に行を追加します。

```html
<div style="font-style: italic; color: #6b7280;">Family-owned since 1987</div>
```

サーマルテンプレートの場合：

```xml
<align mode="center"><text>Family-owned since 1987</text></align>
```

</AccordionItem>

  <AccordionItem question="ギフトレシートで価格を非表示にするにはどうすればよいですか？">

**ギフトレシート**のカードで**テンプレートを使用**をクリックします。すべての価格と合計が非表示になり、商品、SKU、属性、ギフトメッセージは引き続き表示されます。編集は不要です。

価格のない独自のレシートを作るには、任意のテンプレートをコピーして、`{{...total...}}`、`{{...price...}}`、`{{#totals}}...{{/totals}}` のブロックを削除します。

</AccordionItem>

  <AccordionItem question="バーコードをQRコードに変更するにはどうすればよいですか？">

**詳細レシート**、**納品書**、シンプルおよび詳細サーマルレシートは、注文番号をCode 128バーコードとして印刷します。テンプレート内で次の要素を探します： `<barcode>` 。この要素の変更対象の属性は `type`です：

```html
<!-- Code 128 barcode of the order number -->
<barcode type="code128">{{order.number}}</barcode>

<!-- A QR code instead -->
<barcode type="qrcode">{{order.number}}</barcode>

<!-- Or a QR code of something else, like a returns page -->
<barcode type="qrcode">https://example.com/returns?order={{order.number}}</barcode>
```

同じ `<barcode>` 要素がHTMLテンプレートとサーマルテンプレートで使えます。POSのHTMLテンプレートで使用できる種類は、 [bwip-jsが対応するものすべて](https://github.com/metafloor/bwip-js/wiki/Supported-Barcode-Types)です。例えば、 `ean13` または `pdf417`などです。テンプレートエディターのプレビューや、PDFダウンロードなどサイトで生成するレシートでは、以下の一覧にない種類はすべてCode 128バーコードとして表示されます。レシートプリンターで使用できる種類は、 `code128`、 `code39`、 `code93`、 `ean13`、 `ean8`、 `upca`、 `upce`、 `codabar`、 `itf` または `qrcode`です。

</AccordionItem>

  <AccordionItem question="テンプレートを特定のプリンターに送るにはどうすればよいですか？">

各レジの**設定 → 印刷**にある**レシートテンプレート**には、有効なテンプレートとそれぞれのプリンターが一覧表示されます。**自動**では、サーマルテンプレートは用紙幅に合ったレシートプリンターへ、HTMLテンプレートは印刷ウィンドウへ送られます。印刷時に、レジ係はレシート画面の**プリンター**で別のプリンターを選べます。[印刷先の振り分け](../hardware/printers/index.mdx#print-routing)をご覧ください。

</AccordionItem>
</Accordion>

## 問題が発生した場合 {#goes-wrong}

**レシートに古いバージョンが表示されたままです。** エディターは自動保存しません。テンプレートの編集画面で**更新**をクリックし、レシートをもう一度開いてください。

**プレビューに「POS注文が見つかりません」と表示されます。** これは**旧式PHP**テンプレートで、プレビューには実際のPOS注文が必要です。$0でもよいので販売を1件処理すると、プレビューが使えるようになります。HTMLとサーマルテンプレートは、新しい店舗でもサンプルデータでプレビューできます。**旧式PHP**のプレビューは最後に保存したバージョンを表示するため、内容を反映するには**更新**をクリックしてください。

**レジにテンプレートが表示されません。** **自分のテンプレート**で、そのテンプレートの**有効**がオンになっているか確認してください。Proで店舗の**レシート**ページに**この店舗用にカスタマイズ済み**と表示されている場合は、そのページでテンプレートにチェックが入っているか確認してください。

**編集に失敗したので、やり直したいです。** 元に戻すには3つの方法があります。

1. エディターを開いてからの変更には、**元に戻す**（Ctrl/Cmd + Z）を使います。
2. テンプレートに履歴がある場合、編集画面の**リビジョン**で以前のバージョンと比較し、復元できます。
3. ギャラリーから作成した場合は、**自分のテンプレート**でコピーを**削除**し、同じカードの**テンプレートを使用**をクリックして新しいコピーを作ります。

## サポートに問い合わせるケース {#when-to-ask-for-help}

- テンプレートエディターが読み込まれない、または保存内容が反映されない。
- ある端末では正しく印刷できるのに、別の端末ではできない。
- 自国の税務規則に対応したレシートが必要。まず[税務コンプライアンス](../reference/fiscal-compliance.mdx)をご覧ください。WCPOS 2.0には特定の国向けの認証は含まれていません。
- 独自のカスタマイズをしたいが、AIではうまく実現できない。

[サポートチケット](https://wcpos.com/support)を作成し、作業中のテンプレートを貼り付けてください。サポートに必要な情報を確認できます。
