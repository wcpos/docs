このページで答えが見つからないことがありますか。POSから直接、WCPOSのDiscordで質問できます。このページでは、問い合わせ先と、最初のやり取りから適切なサポートを受けるために送る情報を説明します。

1. まず[よくある問題](#before-asking)を確認してください。検索するだけで答えが見つかることも多くあります。
2. **店舗の状態 → ログ**から[デバッグ情報をコピー](#what-to-send)します。
3. デバッグ情報と発生した状況を添えて、[Discordに投稿](#in-app-support)します。

ライセンス、請求、非公開にしたい内容については、[メールでサポートにお問い合わせ](#where-to-ask)ください。

## POSから質問する {#in-app-support}

まず[デバッグ情報をコピー](#what-to-send)します。次に、メニュー下部の**サポート**を押します。POS内でWCPOSのDiscordが開くため、レジを離れずにほかの人の質問を読んだり、自分の質問を投稿したりできます。**general**を選び、**ログイン**を押してログインし、質問を投稿してください。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="サポート画面：POS内にWCPOSのDiscordが表示され、チャンネル一覧、welcome-and-rulesチャンネル、ログインボタン、メッセージ欄があり、メニュー下部でサポートが選択されています">

1. **サポート** — メニュー下部の吹き出しアイコンです。スマートフォンでは、先にメニューを開いてください。
2. **サポート** — POS内に表示されるWCPOSのDiscordです。最初に**welcome-and-rules**が開きます。
3. **Discord** — 左側でチャンネルを選びます。質問は**general**に投稿してください。**ログイン**を押してDiscordにログインすると投稿できます。
4. **店舗の状態** — 赤い数字は、最後に**ログ**を開いてから発生した新しいエラーの件数です。これらを[質問と一緒に送って](#what-to-send)ください。

</JourneyShot>

スマートフォンでは、画面上部の隅からメニューを開きます。**サポート**は一番下にあり、アイコンの横に名前が表示されます。

<summary>スマートフォンでサポートを見つける</summary>

<JourneyShot manifest={manifest} device="phone" step={4} maxWidth={360} alt="スマートフォンで開いたメニュー：上部にPOS、商品、注文、クーポン、顧客、レポートがあり、下部のバージョン番号の上に店舗の状態、設定、サポートがあります">

1. **店舗の状態** — データベース、パフォーマンス、ログです。
2. **設定** — POSの設定です。
3. **サポート** — WCPOSのDiscordです。

</JourneyShot>

</details>

<details>
<summary>Discordのチャンネル</summary>

| チャンネル | 用途 |
|---|---|
| **welcome-and-rules** | サーバーの使い方です。最初にお読みください。 |
| **announcements** | 新しいバージョンやお知らせです。 |
| **roadmap** | 今後の予定についてのフォーラムです。 |
| **general** | 質問と回答です。質問はこちらへどうぞ。 |
| **github-activity** | コードの変更を随時お知らせします。 |

</details>

レジ以外からも、[wcpos.com/discord](https://wcpos.com/discord)で同じサーバーにアクセスできます。または、サポート画面の上部の隅にある**Discordアプリを開く**を押してください。

## 必要な情報を送る {#what-to-send}

使用しているバージョンとPOSで発生したエラーが分かると、多くの場合、回答が早くなります。どちらの情報もPOSがまとめてくれます。

メニューの**店舗の状態**を開き、**ログ**を選んで**デバッグ情報をコピー**を押すと、クリップボードにコピーされます。iOSとAndroidのアプリでは、ボタンは**デバッグ情報を共有**と表示され、代わりに共有シートが開きます。メッセージに貼り付けるか共有し、次の情報を添えてください。

- 行っていた操作
- 期待していた結果と、実際に起きたこと
- `SYNC201`など、画面に表示されたコード
- 毎回発生するかどうか

画面のスクリーンショットも役立ちます。

<JourneyShot manifest={manifest} device="tablet" step={2} alt="店舗の状態のログタブ：当日の件数、デバッグ情報をコピーボタン、ログ検索、フィルターチップ">

1. **店舗の状態** — メニューの心拍アイコンです。[店舗の状態](./store-health.mdx)をご覧ください。
2. **ログ** — POSで行われた処理や発生した問題です。[ログ](./logs.mdx)をご覧ください。
3. **今日のエラー** — タップするとエラーだけが表示されます。
4. **デバッグ情報をコピー** — POSと最近のエラーについて、サポートに必要な詳細情報をコピーします。
5. **ログを検索** — 行に含まれる語句で検索します。
6. **エラー** — **今日のエラー**と同じフィルターです。
7. **詳細診断** — より詳しい情報を記録します。サポート担当者に依頼された場合にのみオンにしてください。24時間後に自動でオフになります。

</JourneyShot>

準備ができたら、[POSから質問する](#in-app-support)に戻ってログインし、質問と一緒にデバッグ情報を貼り付けてください。

<details>
<summary>ログについて詳しく</summary>

デバッグ情報には、アプリ、WordPress、WooCommerce、WCPOSのバージョン、店舗、接続状況、送信待ちの変更、処理が滞っているレコード、最近のエラーが含まれます。

行を開くと詳細が表示されます。**コピー**ではその項目だけをコピーし、**ヘルプ — CODE**ではそのコードを説明する[エラーコード](../error-codes/index.mdx)のページを開きます。フィルターと**詳細診断**については、[ログ](./logs.mdx)のページで詳しく説明しています。

</details>

### バージョンをまとめて確認する {#versions}

<details>
<summary>WCPOSについてでバージョンを確認する</summary>

メニューの一番下にあるバージョン番号（タブレットでは**v 2.0.0**、スマートフォンでは**バージョン 2.0.0**）をタップします。**WCPOSについて**には、アプリのバージョンとプラットフォーム、店舗で使用しているWCPOSプラグイン、WooCommerce、WordPressのバージョン、ライセンスがProかどうかが表示されます。**リリースノート**を押すと、ブラウザーでupdates.wcpos.comが開きます。

## 問い合わせ先 {#where-to-ask}

- **Discord** — 使い方の質問、不具合、アイデアはこちらへどうぞ。回答は、後からほかの人も見つけられる場所に残ります。[wcpos.com/discord](https://wcpos.com/discord)
- **[wcpos.com/support](https://wcpos.com/support)の質問欄** — 質問を入力すると、WCPOSのドキュメントに基づく回答とリンクが表示されます。回答できない場合はDiscordへ案内します。
- **メール [support@wcpos.com](mailto:support@wcpos.com)** — ライセンス、請求、払い戻し、公開したくない内容はこちらへどうぞ。

:::info WCPOS Proをご利用の場合
DiscordのProチャンネルで優先サポートを受けられます。ライセンスの購入は、無料版とPro版のWCPOSの開発支援にもつながります。[Proライセンス](../getting-started/pro-license.mdx)をご覧ください。
:::

<details>
<summary>Proサポートを利用するためにDiscordを連携する</summary>

1. [wcpos.comアカウント](https://wcpos.com/account/licenses)で、ライセンスの**Discordを連携**を押します。または、Discordサーバーで`/link`とライセンスキーを入力します。
2. ライセンスが有効な間は、DiscordアカウントからProチャンネルにアクセスできます。有効期限が切れるとアクセスできなくなり、更新すると再びアクセスできるようになります。

各ライセンスは最大五人まで利用できます。

</details>

## 質問する前に {#before-asking}

検索するだけで答えが見つかることも多くあります。

- **WCPOSが自分の店舗に合うかまだ分からない場合** — まず無料プラグインをインストールして、数日間試してみてください。「こんなことができるだろうか」という疑問の多くを解消できます。
- **画面にエラーコードが表示される場合** — [エラーコード](../error-codes/index.mdx)で調べてください。
- **商品、注文、顧客が表示されない、または情報が古い場合** — **店舗の状態 → データベース**を確認してください。[店舗の状態](./store-health.mdx#database)をご覧ください。
- **POSが読み込まれない、または古いデータが表示される場合** — [ローカルデータの消去](./troubleshooting/clear-local-data.mdx)、続いて[プラグインの競合](./troubleshooting/plugin-conflicts.mdx)と[Cloudflare](./troubleshooting/cloudflare.mdx)をご覧ください。
- **POSの動作が遅い場合** — [パフォーマンス](./performance/index.mdx)をご覧ください。
- **合計がWooCommerceと異なる場合** — [合計の不一致](./troubleshooting/totals-disagree.mdx)をご覧ください。
- **同じ質問がすでに投稿されているかもしれません** — 投稿する前にDiscordで検索してください。

## 問題が発生した場合 {#goes-wrong}

**サポート画面が空白のままになる。** Discordにはインターネット接続が必要です。接続を確認するか、ブラウザーで[wcpos.com/discord](https://wcpos.com/discord)を開いてください。

**「デバッグ情報をコピーできませんでした」。** クリップボードにコピーされませんでした。POSウィンドウ内をクリックしてから、もう一度**デバッグ情報をコピー**を押すか、代わりに**ログ**画面のスクリーンショットを撮ってください。

## WCPOSの改善に協力する {#contributing}

WCPOSはオープンソースです。次の方法で協力できます。

- Discordまたは[GitHub](https://github.com/wcpos)で不具合を報告する
- Discordで機能を提案する
- Discordの**general**でほかの店舗オーナーの質問に回答する
- アプリやこのドキュメントの翻訳を改善する。[翻訳への貢献](./translations.mdx)をご覧ください。
