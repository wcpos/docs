レポートでは、指定した期間のレジ別、店舗別、または全店舗の売上を確認できます。合計と比較に続き、支払い、商品、レジ係、税金、払い戻しのカードが表示されます。サイドメニューの **レポート** から開きます。すべての数値は、デバイスにダウンロード済みの注文をもとに、そのデバイス上で計算されます。

1. レポートを開くと、店舗内の全レジの本日のデータが表示されます（無料プラグインでは、このデバイスのレジのみ）。別の条件で確認するには、[期間](#dates)、続いて[店舗とレジ](#scope)を選択します。
2. [売上を確認](#sales)し、合計と比較を把握します。
3. 詳細を見るには、下にスクロールして[カード](#cards)を表示し、カードの矢印をタップして[パネルを開きます](#panels)。

:::info 無料版と Pro
無料プラグインのレポートでは、このデバイスのレジの本日のデータを確認できます。[WCPOS Pro](../getting-started/free-vs-pro.mdx#at-a-glance) では、過去の日付、他のレジ、全店舗、レジ締め履歴も確認できます。
:::

## 期間を選択する {#dates}

**レポート** を開き、上部の期間をタップすると、プリセットとカレンダーが表示されます。

<JourneyShot manifest={manifest} device="tablet" step={2} alt="期間メニュー：今日、昨日、今週、先週、今月、先月の選択肢と、6日が選択された11月のカレンダー、完了ボタン">

1. **今日** と **昨日** — 1日分を、前日または先週の同じ曜日と比較します。
2. **今週** と **先週** — カレンダー上の1週間です。今週は今日までが対象です。
3. **今月** と **先月** — カレンダー上の1か月です。今月は今日までが対象です。
4. **カレンダー** — 日付を1つタップするとその日を、2つタップするとその間の期間を選択できます。
5. **完了** — タップした日付を適用します。

</JourneyShot>

<details>
<summary>期間がロックされている場合</summary>

無料プラグインでは、**今日** 以外の期間にロックが表示されます。タップすると、**過去の日付は WCPOS Pro で利用できます** と **Pro を見る** ボタンが表示されます。

</details>

## 店舗とレジを選択する {#scope}

上部の店舗名とレジ名をタップします。

<JourneyShot manifest={manifest} device="tablet" step={3} alt="店舗グループ（すべての店舗、AL Store、AL 12345 Store）とレジグループ（すべてのレジ、レジ）がある店舗とレジのメニュー">

1. **すべての店舗** — 全店舗を1つのレポートにまとめます。店舗が複数ある場合にのみ表示されます。
2. **店舗** — 1つの店舗の売上です。
3. **すべてのレジ** — 店舗内のすべてのレジと、オンラインで受けた注文が対象です。
4. **レジ** — 1台のレジの売上です。

</JourneyShot>

<details>
<summary>店舗またはレジがロックされている場合</summary>

無料プラグインでは、サインインしている店舗とレジのみ開けます。それ以外にはロックが表示され、選択すると **他のレジは WCPOS Pro で利用できます**（または **他の店舗**、**すべての店舗**）と **Pro を見る** が表示されます。

</details>

期間の横にある2つのボタンで、集計対象をさらに絞り込めます。**全員** をタップすると、このデバイスにサインインしたことのあるレジ係から選択できます。一度もサインインしていないレジ係は、レジ係カードで **#8** のような番号で表示されます。**完了および処理中** をタップすると、代わりに **すべてのステータス** を選択できます。

スマートフォンでは、最上段に期間と印刷ボタン、その下に **全員** と **完了および処理中** が2列で表示されます。[注文を除外](#leave-out)すると、**除外した注文** ボタンも表示されます。

## 売上を確認する {#sales}

画面上部では、バーで選択した期間、店舗、レジの売上状況を確認できます。合計は、すべての支払い方法を含む、払い戻し前の税込金額です。ドロワー内の現金額ではありません。現金額はレジ情報バーの **ドロワー内予定額** に表示されます。

:::caution 注文のダウンロードが完了するまでお待ちください
上部の **注文をダウンロード中** が消えてから数値を確認してください。対象期間の注文がデバイスに保存済みの件数より多い場合に、ダウンロード済みの件数とともに表示されます。
:::

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-22, 0], [-22, 0], [-22, 0], [0, 0], [0, 0], [0, 0]]} alt="タブレットで全レジを対象に表示した昨日のレポート：店舗名とレジ名、レジ情報バー、期間・レジ係・ステータスのチップ、概要を印刷、合計 $520.00 と注文・平均注文額・商品数、前日比のチップ、時間別グラフ">

1. **店舗とレジ** — 集計対象の店舗とレジです。[店舗とレジを選択する](#scope)を参照してください。
2. **レジ情報バー** — このデバイスのレジセッションの情報です。**営業中** または **締め済み** と、現金の **ドロワー内予定額** が表示されます。店舗、レジ、期間の選択にかかわらず、表示内容は変わりません。[レジ情報バーとレジ締め](#closures)を参照してください。
3. **期間** — 集計対象の日付です。[期間を選択する](#dates)を参照してください。
4. **レジ係** — **全員** または1人のレジ係の売上を表示します。
5. **ステータス** — **完了および処理中** は販売済みの注文を集計します。**すべてのステータス** では、支払い待ちや保留中の注文も含めます。
6. **概要を印刷** — 対象期間の **売上概要** を印刷します。[印刷・エクスポートする](#print)を参照してください。

</JourneyShot>

チップの下に数値とグラフが表示されます。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-10, -30], [60, -26], [0, 0], [0, 0]]} alt="昨日の数値：$520.00、前日比85.1%減、注文22件、平均注文額 $23.64、商品数16とそれぞれの増減、前日比のチップ、前日の数値を破線で示す時間別グラフ">

1. **合計** — 対象期間の払い戻し前の税込売上です（**払い戻し** カードには払い戻し後に残った金額が表示されます）。すべての支払い方法を含む金額で、ドロワー内の現金額ではありません。その下には、比較対象に対する増減率が表示されます。赤は減少、緑は増加を表します。
2. **注文、平均注文額、商品数** — それぞれに比較対象に対する増減が表示されます。**—** は比較対象がないことを示します。
3. **比較** — 増減の比較対象です。1日分の場合は、**前日比** または **先週比** と曜日を選択します。[比較の仕組み](#comparisons)を参照してください。
4. **グラフ** — 1日分は **時間別**、それより長い期間は **日別** で表示できます。**累計** では期間中の積み上がりを確認できます。破線は比較対象期間を示します。

</JourneyShot>

### 比較の仕組み {#comparisons}

数値の下にある比較チップには、増減の比較対象期間が表示されます。1日分は前日または先週の同じ曜日、1週間分はその前の週、1か月分はその前の月と比較します。

<details>
<summary>比較対象期間の計算方法</summary>

- **1日分** は、比較チップで選択した前日または先週の同じ曜日と比較します。
- **今日** はまだ途中なので、同じ時刻までで比較します。午後3時なら、昨日の午後3時までと比較します。
- **1週間**、または2〜7日間の範囲は、その1週間前の同じ日付範囲と比較します。チップには **前週比** と表示され、変更できません。
- **カレンダー上の1か月全体** は、その前の月全体と比較します。**今月** や7日を超える範囲は、1か月前から始まる同じ日数の期間と比較します。チップには **前月比** と表示されます。
- 数値の下の **—** は、比較対象期間に注文がないことを示します。

</details>

## カードを確認する {#cards}

下にスクロールするとカードが表示されます。各カードから、一覧全体を表示するパネルを開けます。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-26, 0], [-26, 0], [-26, 0], [-26, 0], [-26, 0]]} alt="今週のレポートカード：平均値とステータスバーがある注文、方法別の支払い、店頭とオンラインに分かれた販売場所、売れ筋商品">

1. **注文** — 注文の傾向に続き、**完了**、**処理中**、**払い戻し済み** の注文を示すバーが表示されます。
2. **要対応** — 処理中、保留中、支払い待ちの注文の件数です。該当する注文がなければ **対応が必要な注文はありません** と表示されます。
3. **支払い** — 支払い方法別の売上と、各方法の割合です。**未払い** は注文の未払い金額です。**不明** は支払い方法が記録されていない注文です。
4. **販売場所** — **店頭** と **オンライン** を比較します。複数のレジを集計している場合は **レジ** に、**すべての店舗** を選択している場合は **店舗** に切り替えられます。レジが設定されていない注文には **レジなし** と表示されます。
5. **売れ筋商品** — 売上上位の商品と、それぞれの割合、販売数量です。

</JourneyShot>

<details>
<summary>注文の数値の意味</summary>

- **平均注文額** — 売上を注文件数で割った値です。
- **中央値** — 注文合計額を順に並べたときの中央の値です。注文の半数がこの金額を下回ります。
- **最大注文額** — 最も金額が大きい注文です。
- **販売商品数** — 注文に含まれる商品の数量です。
- **注文あたりの商品数** — 販売商品数を注文件数で割った値です。
- **割引** — 適用した割引です。

</details>

さらに下には、次のカードがあります。

- **カテゴリー** — 商品カテゴリー別の売上です。
- **ブランド** — ブランド別の売上です。
- **レジ係** — レジ係ごとの売上です。
- **税金** — 税率ごとの税額と、それぞれの **課税対象** となった税抜売上です。
- **払い戻し** — 対象期間に行った払い戻しの金額、対象の注文件数、期間中の売上から払い戻し後に残った金額です。注文が過去のものでも、払い戻しを行った期間に計上されます。

<details>
<summary>商品・カテゴリー・ブランドが見つからない場合</summary>

- カテゴリーカードの **未分類** は、どのカテゴリーにも属していない商品です。
- **不明な商品** は、このデバイスに商品データがないため、カテゴリーを割り当てられない明細です。**117明細中58明細の商品がデバイスにありません** のように、該当する明細数が注記されます。売上は合計に含まれます。
- ブランドカードの **ブランドなし** は、ブランドが設定されていない商品です。ブランドカードは、商品にブランドが設定されている場合、または店舗で売上原価を管理している場合にのみ表示されます。

</details>

## パネルを開く {#panels}

カードの矢印をタップします。タブレットでは、パネルが右からスライドしてレポートに重なり、サイドメニューはその横に残ります。スマートフォンでは独立したページとして開き、上部の **売上** から戻れます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-18, 0], [0, 0], [-34, 0], [-10, 0], [0, 0]]} alt="今週の売れ筋商品パネル：すべてのカテゴリーのフィルター、数量・金額・原価・利益・利益率 % の列があるレポートプレビュー、134商品中134商品の原価が未設定と示すステータス行、閉じる、CSV をエクスポート、レポートを印刷">

1. **期間とレジ** — パネルの集計対象です。
2. **フィルター** — 売れ筋商品ではカテゴリー（**すべてのカテゴリー**）、ブランド別売上ではブランドを1つに絞り込めます。
3. **ステータス行** — 注文と合計が表示されます。売上原価の管理が有効な場合は、原価が未設定の商品数も表示されます。[原価・利益・利益率](#margin)を参照してください。
4. **CSV をエクスポート** — 一覧を CSV ファイルとして保存します。ブラウザーではダウンロードされ、アプリでは共有シートが開きます。
5. **レポートを印刷** — プレビューの上に表示されている **テンプレート** と **プリンター** を使って一覧を印刷します。

</JourneyShot>

パネルには、**注文**、**支払い方法別売上**、**売れ筋商品**、**カテゴリー別売上**、**ブランド別売上**、**レジ係別売上**、**徴収税額**（税率ごとの税抜金額、税額、税込金額）、**払い戻し** があります。また、販売場所からは **販売チャネル**、**レジ**、**店舗** のいずれかを開けます。

## 注文を除外する {#leave-out}

テスト販売やスタッフの購入は、その日の集計に影響することがあります。**注文** パネルを開き、除外する注文のチェックを外します。

<JourneyShot manifest={manifest} device="tablet" step={6} maxWidth={543} alt="昨日の注文パネルの上部：2件が除外され、一部選択状態になっているすべての注文のチェックボックス。その下に注文番号順で時刻、レジ係、合計、支払い方法が並び、2件はチェックが外れてグレー表示になっている">

1. **すべての注文** — すべての注文のチェックを付けるか、外します。横には除外件数が表示され、この例では **2件を除外** となっています。
2. **注文** — チェックを外すと除外されます。注文はグレー表示になり、パネル下部に **38件中36件を集計 · 数値に反映** と表示されます。

</JourneyShot>

各行には注文番号、時刻、レジ係、合計、支払い方法が表示されます。パネルには最新の60件が表示され、その後に残りの件数が示されます。過去の注文を表示するには、先に期間を短くするか、レジまたはレジ係を1つに絞り込みます。レポートの数値とカードは、除外した注文を含めずに再計算されます。レジ情報バーは変わりません。

ステータスの横にある **除外した注文** ボタンに、たとえば **2件の注文を除外** と表示されます。タップすると注文パネルに戻り、**×** をタップすると再び集計に含まれます。注文の除外が影響するのは、このデバイスのこのレポートだけで、注文自体は変更されません。すべての注文のチェックを外すと、注文カードに **すべての注文が除外されています** と表示されます。

## 印刷・エクスポートする {#print}

- 上部の **概要を印刷** では、対象期間の **売上概要** を印刷できます。売上（税抜金額、税額、払い戻し、割引）、支払い方法、税金、送料に続き、複数ある場合は店舗・レジ・レジ係、さらに販売商品数と平均注文額が含まれます。除外した注文は含まれません。
- パネル内の **レポートを印刷** では、そのパネルの一覧を印刷します。
- パネル内の **CSV をエクスポート** では、その一覧を保存します。

印刷には、[レシートテンプレート](../receipts/index.mdx)と選択したプリンターを使用します。

<details>
<summary>印刷が待機中になる、または失敗する場合</summary>

- **読み込み中です。** レポートやテンプレートの読み込み中は、印刷シートに **店舗の読み込みを待機中**、**レポートを読み込み中**、**この期間の注文を読み込み中**、**この期間の払い戻しを読み込み中**、**テンプレートを読み込み中** のいずれかが表示されます。読み込みが完了すると印刷できます。
- **オフラインで印刷できるテンプレートがありません · WP Admin でテンプレートを管理してください。** このデバイスには、オフラインで印刷できるテンプレートが保存されていません。テンプレートは WP Admin で管理します。
- **保存済みのプリンターではこのテンプレートを印刷できません。** テンプレートとプリンターが対応していません。印刷シートで別のプリンターを選択してください。
- **「印刷できませんでした。もう一度お試しください。」または「エクスポートに失敗しました。もう一度お試しください。」** 再度お試しください。印刷が繰り返し失敗する場合は、印刷シートでプリンターを確認してください。

</details>

## 原価・利益・利益率 {#margin}

店舗で[売上原価](../products/index.mdx#cost-of-goods-sold)を管理している場合、売れ筋商品、カテゴリー別売上、ブランド別売上のパネルに **原価**、**利益**、**利益率 %** の列が追加されます。原価が未設定の商品には **—** と表示されます。ステータス行にも **40商品中3商品の原価が未設定** のように件数が表示され、利益率の信頼性を判断できます。

## レジ情報バーとレジ締め {#closures}

レジ情報バーには、このデバイスのレジの状態（**営業中** または **締め済み**）、その状態になった時刻、レジを開いた担当者、ドロワーの金額 **開始時の釣り銭 + 現金売上 − 現金払い戻し = ドロワー内予定額** が表示されます。セッション中に **入金** や **出金** があれば、それらも計算に含まれます。**X レポートを印刷** では営業中のセッションを印刷します。締め済みのレジでは、代わりに **レジ締めを印刷** が表示されます。レジが設定されていないデバイスには **このデバイスにレジはありません** と表示されます。

WCPOS Pro では、バーの端にある矢印から **レジ締め** を開けます。閲覧できるレジの番号付きレジ締め記録がすべて表示され、再印刷、再集計、確認ができます。ここの **CSV をエクスポート** では、表示中のレジ締め記録を保存します。`WP Admin > POS > 設定` の **ツール** にある **レジ締めをエクスポート** では、すべてのレジ締め記録をダウンロードできます。1日の手順は[レジ精算](./reconciliation.mdx)を参照してください。

## WooCommerce アナリティクスでより長い期間を確認する {#woocommerce-analytics}

注文単位のエクスポートや任意の日付範囲の集計には、`WP Admin > WooCommerce > Analytics` を使用します。同じ注文データを参照します。WCPOS Pro では、次の機能が追加されます。

- **注文** レポートの注文タイプフィルターに、**POS 注文** と **オンライン注文** が追加されます。
- **収益** レポートに **店舗**、**レジ係**、**支払い方法** のフィルターが追加されます。それぞれ選択肢が複数ある場合に表示されます。

## 問題が発生した場合 {#goes-wrong}

**「レポートへのアクセスが許可されていません」。** ご利用のユーザーには *レポートの表示* 権限がありません。[アクセス権限](../settings/wp-admin/access.mdx)を参照してください。

**数値が少なく見える。** ステータスボタンを確認してください。**完了および処理中** では、支払い待ちと保留中の注文が除外されます。**除外した注文** ボタンの有無を確認し、続いて店舗、レジ、レジ係を確認してください。

**商品が「不明な商品」と表示される。** このデバイスに商品データがないため、その明細にカテゴリーを割り当てられません。売上は合計に含まれます。

**レジ係が番号で表示される。** そのレジ係は、このデバイスに一度もサインインしていません。売上はそのレジ係のもので、名前だけが表示されていない状態です。

**印刷が待機中になる、または失敗する。** [印刷・エクスポートする](#print)の **印刷が待機中になる、または失敗する場合** を開いてください。

:::info WCPOS Pro の場合
Pro では、過去の日付、任意の期間、他のレジ、**すべての店舗**、**レジ締め** 履歴を確認できます。[無料版と Pro の比較](../getting-started/free-vs-pro.mdx#at-a-glance)を参照してください。
:::
