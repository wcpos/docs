**WP管理画面：** `WP Admin → POS → Settings`。すべてのレジで共有する設定です。

これらの設定を表示するには、**POS設定の管理**権限が必要です。管理者とショップマネージャーにはこの権限がありますが、レジ係にはありません（[アクセス](./access.mdx)）。

個々のレジのプリンター、バーコードスキャナー、テーマ、表示を設定する場合は、[POS内の設定](../index.mdx#open)を開いてください。そちらの設定は、その端末にのみ適用されます。

## 設定を探す {#settings-at-a-glance}

よく行う操作：

- 店舗名、電話番号、返品ポリシーを変更する：[店舗詳細](#store-details)。
- レジで利用できる支払い方法を選ぶ：[支払い方法の選択](./checkout.mdx#payment-gateways)。
- レジ係が行える操作を決める：[アクセス](./access.mdx)。
- 紛失した端末や共有端末をサインアウトする：[セッション](./sessions.mdx)。
- 開始時の釣銭準備金を設定する：[レジ](./registers.mdx#one-register)。
- バーコードスキャナーで読み取る商品フィールドを選ぶ：[バーコードフィールド](./general.mdx#barcode-field)。
- 各販売の開始時に選択される顧客を指定する：[デフォルトのPOS顧客](./general.mdx#default-pos-customer)。
- すべてのレジ締め記録をスプレッドシートとしてダウンロードする：[レジ締め記録のエクスポート](../../reports/reconciliation.mdx#export)。
- WCPOSが記録したエラーや警告を確認する：[ログ](../../support/logs.mdx#wp-admin-logs)。
- WCPOS Proのライセンスキーを有効化する：[WCPOS Proのインストール](../../getting-started/pro-license.mdx#activate)。

**POS > 設定**の左側のメニューには、**設定**、**ツール**、**アカウント**の3つのグループがあります。一般とレジでは変更するとすぐに保存されます。**保存**ボタンがあるのは、支払い方法のPOS設定だけです。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [75, 0], [95, 0]]} alt="WCPOS ProのWP Admin、POS、設定、一般画面。左側のWCPOSメニューには設定、ツール、アカウントのグループがあり、一般が選択されています。その隣に店舗、レジ、商品の各セクションが表示されています">

1. **設定** — 一般、レジ、クラウド印刷、アクセス、セッション、拡張機能。
2. **ツール** — レジ締め記録のエクスポートとログ。
3. **アカウント** — ライセンス。

</JourneyShot>

<details>
<summary>設定メニューの全項目</summary>

**設定**

- **一般**：店舗詳細、レジ、商品、顧客、プライバシー、**SSLの強制**。[一般設定](./general.mdx)を参照するか、下の**一般の設定内容**を開いてください。
- **レジ**：在庫数を超える販売、POSのメール、支払い方法（**ゲートウェイ**）と各支払い方法で設定する注文ステータス。[レジ設定](./checkout.mdx)を参照するか、下の**レジの設定内容**を開いてください。
- **クラウド印刷**：インターネット経由でレシートを取得するプリンター、注文を自動印刷するルール、印刷キュー。[クラウド印刷](../../receipts/cloud-printing.mdx)を参照してください。
- **アクセス**：レジ係を含むWordPressの各権限グループがPOSで行える操作。[アクセス](./access.mdx)を参照してください。
- **セッション**：POSにサインインしているユーザーとその端末の確認、および端末のサインアウト。[セッション](./sessions.mdx)を参照してください。
- **拡張機能**：WCPOS拡張機能の閲覧、インストール、更新、無効化。名前の横の数字は更新待ちの件数です。[拡張機能](../../extensions/index.mdx)を参照してください。

**ツール**

- **レジ締め記録のエクスポート**：この店舗で記録されたすべてのレジ締め記録を、**CSVをダウンロード**で取得します。レジ締めごとに1行で、締め時点の数値が入ります。[照合](../../reports/reconciliation.mdx)を参照してください。
- **ログ**：エラーや警告を含む、店舗のWCPOSログです。名前の横には、未読のエラー数と警告数がそれぞれ表示されます。[ログ](../../support/logs.mdx#wp-admin-logs)を参照してください。

**アカウント**

- **ライセンス**：WCPOS Proがインストールされている場合、**ライセンスキー**を入力して**有効化**するか、**無効化**できます。Proがない場合はアップグレードが案内されます。[WCPOS Proのインストール](../../getting-started/pro-license.mdx#activate)を参照してください。

拡張機能によって、**ツール**や**アカウント**に専用のページが追加される場合があります。

</details>

<details>
<summary>一般の設定内容：店舗詳細、レジ、商品、顧客、プライバシー、SSLの強制</summary>

- **店舗詳細**：名前、電話番号、メールアドレス、返品ポリシー、**店舗の税務ID**。[店舗詳細](#store-details)を参照してください。
- **レジ**：レジの開始と締め、開始時の釣銭準備金、締めのルール。無料プラグインではレジは1台です。レジを増やすにはProが必要です。[レジ](./registers.mdx)を参照してください。
- **商品**：POS専用商品、小数の数量、注文削除時の在庫復元、**バーコードフィールド**。[一般設定](./general.mdx)を参照してください。
- **顧客**：ユーザー名の生成、**デフォルトのPOS顧客**、**顧客によるレシートのダウンロードを許可**、顧客の**税務ID**（[顧客の税務ID](./customer-tax-ids.mdx)）。[一般設定](./general.mdx#default-pos-customer)を参照してください。
- **プライバシー**：匿名の利用状況データとエラーレポート。管理者が回答するまでは、**許可**と**許可しない**のボタンが表示されます。[一般設定](./general.mdx#privacy)を参照してください。
- **高度な設定**：**SSLの強制**。[SSLの強制](#force-ssl)を参照してください。

</details>

<details>
<summary>レジの設定内容：在庫数を超える販売、メール、支払い方法</summary>

- **在庫数を超える販売を防止**。[レジ設定](./checkout.mdx#prevent-overselling)を参照してください。
- **管理者メール**、**顧客メール**、**レジ係メール**のスイッチ。[メール通知](./email-notifications.mdx)を参照してください。
- 支払い**ゲートウェイ**の表。[レジ設定](./checkout.mdx#payment-gateways)を参照してください。この表では次の操作ができます。
  - レジで利用できる支払い方法とその表示順を選択します（無料プラグインで有効化や変更ができるのは**現金**と**カード**のみです。その他の支払い方法にはProが必要です）。
  - 各支払い方法で支払ったPOS注文に設定する**注文ステータス**を選択します。
  - 支払い方法のPOS設定を開き、レジに表示する名前と説明を変更します。現金の場合は**丸め処理**も設定でき、**丸めなし**、または**0.05**から**10**までの単位を選択します。[現金の丸め処理](../../payment/index.mdx#cash-rounding)を参照してください。

</details>

<details>
<summary>メール通知、レジ、税務ID</summary>

**メール通知**は**レジ**にある3つのメールスイッチです。**レジ一覧**に関する設定は**一般**の**レジ**セクションにあります。**店舗の税務ID**は**店舗詳細**の一部で、**顧客の税務ID**は**顧客**にあり、どちらも**一般**にあります。

</details>

## 店舗詳細 {#store-details}

**`WP Admin > POS > 設定 > General`** を開き、上部のフィールドを変更します。変更するとすぐに保存されます。これらの情報はPOSのレシートと請求書に使用されます。

| フィールド | 内容 |
|---|---|
| **店舗名** | 店舗の名前。 |
| **電話番号** | 店舗の電話番号。 |
| **メールアドレス** | 店舗のメールアドレス。 |
| **返金・返品ポリシー** | POSのレシートに印刷する短い説明文。 |
| **店舗の税務ID** | 店舗の税務番号。[店舗の税務ID](./store-tax-ids.mdx)を参照してください。 |

フィールドを空欄にすると、WooCommerceに設定済みの値を使用します。その値は空欄のフィールドにグレーで表示されます。WooCommerceにも値がない場合、**店舗名**にはサイトのタイトル、**メールアドレス**にはWooCommerceメールの送信元アドレスが使用されます。

<JourneyShot manifest={manifest} device="desktop" step={3} offsets={[[100, 0], [100, 0], [100, 0], [0, 34], [100, -6]]} maxWidth={560} alt="無料プラグインの一般画面にある店舗詳細。店舗別設定を利用するための案内、店舗名、電話番号、メールアドレス、返金・返品ポリシーがあり、その下に1行の店舗の税務IDと税務IDを追加ボタンがあります">

1. **店舗名** — ここでは空欄のため、グレーで表示されたサイトのタイトルが使用されます。
2. **電話番号** — デフォルトでは未設定です。
3. **メールアドレス** — ここでは空欄のため、グレーで表示されたアドレスが使用されます。
4. **返金・返品ポリシー** — POSのレシートに印刷されます。
5. **店舗の税務ID** — 店舗の税務番号。[店舗の税務ID](./store-tax-ids.mdx)を参照してください。

</JourneyShot>

:::info WCPOS Proの場合
店舗を作成するまでは、**店舗詳細**に同じフィールドと**店舗を管理**ボタンが表示されます。店舗を作成すると、このセクションは**店舗**に変わり、各店舗に**編集**ボタンが付いた一覧になります。各店舗の詳細はそれぞれの店舗で設定します。[店舗の設定](../../stores/setup.mdx#store-pages)を参照してください。
:::

## SSLの強制 {#force-ssl}

**SSLの強制**はオンのままにしてください。**一般**の下部にある**高度な設定**にあり、デフォルトでオンです。POSとサイト間のすべての接続をHTTPSで保護します。

<JourneyShot manifest={manifest} device="desktop" step={2} offsets={[[102, 0]]} maxWidth={560} alt="一般の下部にある高度な設定セクション。SSLの強制がオンになっています">

1. **SSLの強制** — デフォルトでオンです。そのままにしてください。

</JourneyShot>

<details>
<summary>SSLの強制による変更と、オフにする場合</summary>

**SSLの強制**がオンの場合、`http://`のアドレスでPOSを開くと、`https://`のアドレスに転送されます。また、SSLを処理するプロキシの背後にある場合など、サイト自体のアドレスが`http://`で始まっていても、POSのサインイン、チェックアウト、レシートのリンクはHTTPSを使用します。

オフにするのは、自分のコンピューター上のテストサイトなど、SSL証明書がないサイトの場合だけにしてください。オフにすると、POSはサイト自体のアドレスに従います。

</details>

## WCPOS Proの場合 {#pro}

ProではWP Adminメニューに**POS > 店舗**が追加されます。各店舗には独自の詳細情報、レシートテンプレート、レジ、スタッフ、および**顧客用ディスプレイ**ページがあります。[店舗の設定](../../stores/setup.mdx)を参照してください。

<details>
<summary>店舗の顧客用ディスプレイテンプレートを選ぶ</summary>

店舗の**顧客用ディスプレイ**ページにある**表示テンプレート**一覧の先頭は**サイトと同じ**で、その後の括弧内にサイトの表示テンプレート名が表示されます（サイトで有効なテンプレートがない場合は**店舗のデフォルト**）。このままにすると、店舗はサイトで使用するテンプレートに従います。店舗専用のテンプレートを使うには、別のテンプレートを選びます。テンプレートは**POS > テンプレート**の**ディスプレイ**タブで有効にすると一覧に表示されます。

</details>

## 問題が起きた場合 {#goes-wrong}

**WP AdminにPOSメニューがありません。** WordPressは**POS設定の管理**権限を持つユーザーにのみ、**設定**を含む**POS**メニュー全体を表示します。現在のアカウントにはこの権限がありません。管理者に自分の権限グループへの付与を依頼するか、[アクセス](./access.mdx)を参照してください。

**一般で、店舗詳細があった場所に店舗が表示されます。** WCPOS Proを使用していて、店舗が1つ以上あるためです。店舗の**編集**を押すと詳細を変更できます。

<details>
<summary>レシートフォントをダウンロードできない</summary>

警告は「WCPOSはcdn.jsdelivr.netからレシートフォントをダウンロードできませんでした。」で始まります。WooCommerceを管理するユーザーのWP Adminに表示されます。ダウンロードが成功するまではラテン文字のみに対応した基本フォントを使うため、他の文字体系のテキストは正しく印刷されない場合があります。WCPOSは1時間ごとに再試行します。ホスティング事業者が外向きのリクエストをブロックしている場合は、`cdn.jsdelivr.net`へのアクセスを許可するよう依頼してください。

</details>

<details>
<summary>レシートフォントを設定できない</summary>

警告は「WCPOSはレシートのフォントマップを公開できませんでした。」で始まります。レシートにフォントの場所を伝えるファイルをWCPOSが保存できなかったことを意味します。成功するまでは基本的なラテン文字フォントを使用し、WCPOSは1時間ごとに再試行します。WordPressのuploadsフォルダーに書き込みが可能か、ホスティング事業者に確認を依頼してください。

</details>

**一般の上部に「店舗はCloudflare経由で接続されています」と表示されます。** WCPOSがサイトでのCloudflareの使用を検出しました。Cloudflareのセキュリティチェックが、POSから店舗への接続を妨げる場合があります。POSに**HOST121**やセキュリティチェックのウィンドウが表示される場合は、[Cloudflare](../../support/troubleshooting/cloudflare.mdx)を参照してください。

<details>
<summary>レジに処理速度低下の警告が表示される</summary>

レジの上部の警告は「商品カタログや注文履歴が増えると、WCPOSのチェックアウトが遅くなります」で始まります。店舗ではまだWooCommerceの従来の注文ストレージを使用しています。高パフォーマンス注文ストレージに切り替えてください。警告にはWooCommerce設定へのリンクがあり、切り替えるまで表示され続けます。[注文ストレージ](../../support/performance/order-storage.mdx#switch-to-hpos)を参照してください。

</details>

<details>
<summary>WP Adminの「WCPOSの改善にご協力ください」</summary>

WCPOSが匿名の利用状況データとエラーレポートの送信を許可するか尋ねています。**許可**または**許可しない**を押してください。回答は**一般 > プライバシー**でいつでも変更できます。

**POS設定の管理**権限を持つユーザーが回答するまで、このボックスはダッシュボードとプラグイン画面に表示されます。WCPOSのインストールまたは更新後の7日間は、WooCommerceのほとんどの画面にも表示されます。閉じると、自分の画面では7日間表示されなくなります。

</details>
