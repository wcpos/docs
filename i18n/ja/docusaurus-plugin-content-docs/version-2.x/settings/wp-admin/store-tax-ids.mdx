**WP管理画面：** `WP Admin → POS → Settings → General → Store details`。

事業者の税務番号は、POSの[レシートと請求書](#what-prints-on-receipts)の上部にある店舗情報に印刷されます。番号の一覧は、**WP Admin → POS → 設定 → 一般**の**店舗情報**内にある**店舗の税務番号**にあります。

WCPOS Proですでに店舗を作成している場合、**一般**には**店舗情報**の代わりに店舗の一覧が表示されます。各店舗の番号は、その店舗の**税**ページで設定します。[店舗ごとに番号を設定する](#per-store-tax-ids-pro)を参照してください。

## 税務番号を追加する {#adding-a-tax-id}

店舗の電話番号、メールアドレス、返品ポリシーの下にある**店舗の税務番号**一覧で、番号を1行に1つずつ登録します。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[110, 0], [87, 0], [88, 0], [81, 0], [121, 0], [24, -34]]} alt="無料プラグインのWP Admin、POS、設定、一般で、店舗の税務番号までスクロールした画面。種類がFR SIRET、値、国がフランス、空のカスタムラベル、削除を含む行があり、その下に税務番号を追加ボタン、続いてレジのセクションが表示されています">

1. **税務番号を追加** — 行を追加します。
2. **種類** — 番号の種類です。この例では**FR SIRET**です。
3. **国** — **種類**に連動し、**種類**も国に連動します。
4. **値** — 番号を入力します。この欄からフォーカスを移すと行が保存されます。
5. **カスタムラベル** — 種類の略称の代わりに印刷する文言です。
6. **削除** — 行を削除します。

</JourneyShot>

1. WP Adminで**POS → 設定 → 一般**を開き、**店舗の税務番号**までスクロールします。
2. **税務番号を追加**をクリックします。新しい行が表示され、**国**にはWooCommerceで設定した店舗の国、**種類**にはその国で通常印刷される番号の種類が設定されます。
3. **種類**を確認し、別の番号が必要な場合は変更します。**種類**を変更すると、**国**も変わることがあります。[種類と国の連動](#the-first-row-uses-your-store-country)を参照してください。新しい行は、**値**に番号を入力するまで保存されません。
4. **値**に番号を入力し、クリックまたはTabキーで欄からフォーカスを移します。**値**からフォーカスを移すと行が保存され、**保存済み**というメッセージが表示されます。
5. レシートに別の文言を印刷する場合は、**カスタムラベル**に入力します。たとえば、`P.IVA`の代わりに`Partita IVA`と入力し、欄からフォーカスを移します。**値**と同じ方法で保存されます。
6. 番号ごとに繰り返します。**削除**で行を削除できます。保存済みの行では、**種類**や**国**を変更するとすぐに保存され、**保存済み**というメッセージが表示されます。

番号は一覧の順序で印刷されます。順序を変えるには、番号を削除して再度追加します。

:::tip 行を残すには値を入力してください
新しい行は、**値**に番号を入力して初めて保持されます。空のままの行は、ページを再読み込みすると消えます。
:::

### 種類と国の連動 {#the-first-row-uses-your-store-country}

**国**を変更すると**種類**が変わることがあり、**種類**を変更すると**国**が変わることもあります。行の操作を終える前に両方を確認してください。

<Accordion>
  <AccordionItem question="種類と国が互いにどう連動するか">

- **国**を選択すると、**種類**がその国で通常印刷される番号の種類に変わります。具体的な種類は、下の**国別の一覧**を開いて確認できます。各国で最初に記載されている種類が選ばれます。専用の行がないEU加盟国では**EU VAT**、それ以外の国では**その他**になります。
- **種類**を選択すると、**国**がそれに合う国に変わります。**EU VAT**では、選択済みのEU加盟国が維持されます。または、店舗の国がEU加盟国であればその国が使われます。**その他**では**国**は変わりません。
- 国の一覧で**国なし**を選ぶと、国の選択が解除されます。国は種類の選択に使われ、レシートにはラベルと番号が印刷されます。

</AccordionItem>
</Accordion>

### 番号の種類と印刷時の表記 {#available-types}

税務番号にはVAT番号、ABN、GSTIN、EIN、会社登録番号などがあります。WooCommerceにはこれらの入力欄がないため、WCPOSが独自に一覧を保持し、必要なだけ追加できます。たとえばドイツの店舗では、同じレシートにUSt-IdNr.、Steuernummer、**さらに**HRB番号を印刷できます。

**値**には、番号の一般的な形式の例が灰色で表示されます。これは入力のヒントにすぎません。WCPOSは入力内容をそのまま保存するため、一般的でない形式の番号も保存できます。レシートでは、**EU VAT**なら**VAT ID**、**AU ABN**なら**ABN**など、各種類の略称がレシートの言語に翻訳されて印刷されます。**カスタムラベル**は入力どおりに印刷されます。

## レシートに印刷される内容 {#what-prints-on-receipts}

各番号はレシート上部の店舗情報に、ラベル、番号の順で1行ずつ印刷されます。付属のレシート（標準・感熱紙用）、請求書、見積書、ギフトレシート、レジ締めレポートでは、一覧全体が印刷されます。納品書、キッチン伝票、通常のレポートテンプレートでは印刷されません。

<Accordion>
  <AccordionItem question="独自のレシートテンプレートをお使いの場合">

カスタムテンプレートでは、`store.tax_ids`をループ処理して一覧を印刷します。

```html
{{#store.tax_ids}}{{label}}: {{value}}{{/store.tax_ids}}
```

各項目には`type`と`country`も含まれます。「レシートデータ」の[税務番号オブジェクト](../../receipts/receipt-data.mdx#tax-id-objects)を参照してください。

  </AccordionItem>
</Accordion>

## 店舗ごとに番号を設定する（Pro） {#per-store-tax-ids-pro}

:::info Proの機能
店舗ごとの税務番号を設定するには、[WCPOS Pro](../../getting-started/pro-license.mdx)が必要です。
:::

店舗ごとに独自の税務番号を印刷できます。店舗を個別に登記しているチェーン店や、複数の国で事業を行っている場合に利用できます。

1. WP Adminで**POS → 店舗**を開き、店舗名をクリックします。
2. 店舗のメニューで**税**を開きます。
3. **レシートに印刷する税務番号**の下にある**税務番号を追加**をクリックします。新しい行には、店舗の**詳細**ページで設定した国と、その国の一般的な番号の種類が設定されます。
4. **種類**、**値**、**国**を入力し、必要に応じて**ラベル（任意）**も入力します。種類と国は[一般設定と同じように](#the-first-row-uses-your-store-country)連動します。新しい行は、**値**に番号を入力して欄からフォーカスを移すと保存されます。その後は、**種類**と**国**は選択するとすぐに、**値**と**ラベル（任意）**は欄からフォーカスを移すと保存されます。ページ上部の隅には**保存中…**、続いて **✓ 保存済み**と表示されます。

店舗で印刷される番号は次のとおりです。

- **店舗に独自の番号がある場合：** その店舗のレシートには、独自の番号だけが印刷されます。サイトの一覧は印刷されません。
- **店舗に番号がない場合：** サイトの**店舗の税務番号**がレシートに印刷されます。
- **どちらにも番号がない場合：** レシートに税務番号は印刷されません。

<Accordion>
  <AccordionItem question="番号がない場合に店舗の税ページに表示される内容">

店舗に独自の番号がない場合、店舗の**税**ページに、代わりに何が印刷されるかが表示されます。

- サイトに番号がある場合：**この店舗には税務番号がありません。レシートにはサイトの税務番号が印刷されます：…**（複数の場合は**税務番号一覧：…**）と表示され、その後にサイトの一覧が続きます。
- サイトにも番号がない場合：**この店舗にもサイトにも税務番号がありません。レシートには印刷されません。**

</AccordionItem>
</Accordion>

店舗の**税**ページのその他の設定（税の計算に使う住所や適用する税率）については、[店舗の各ページを設定する](../../stores/setup.mdx#store-pages)を参照してください。

## 問題が起きた場合 {#troubleshooting}

**追加した行が再読み込みすると消えます。** **値**が未入力だったためです。もう一度**税務番号を追加**をクリックし、行の操作を終える前に番号を入力してください。

**店舗で間違った番号が印刷されます。** その店舗の**税**ページを開いてください。番号が登録されている場合、その店舗は独自の一覧だけを印刷するため、そこで該当する行を削除または修正します。番号がない場合は、サイトの**店舗の税務番号**が印刷されます。

**レシートのラベルが税務署の求める表記と異なります。** **カスタムラベル**（店舗の**税**ページでは**ラベル（任意）**）に必要な文言を入力してください。

**独自のテンプレートで番号が1つしか印刷されないか、まったく印刷されません。** [レシートに印刷される内容](#what-prints-on-receipts)にある**独自のレシートテンプレートをお使いの場合**を開いてください。
