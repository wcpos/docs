設定は4か所にあります。レジで変更する項目の多くはPOSの **設定** にあり、変更はこの端末だけに適用されます。すべてのレジで共有する項目は、店舗オーナーがWordPressで設定します。WCPOS Proでは、そこに各店舗専用のページもあります。また、一部の画面には、その画面の表示方法を設定する専用のボタンがあります。

- [POSの **設定**](#open) は、現在の店舗について、この端末の設定を変更します。POSを開ける人なら誰でも変更できます。
- [`WP Admin > POS > 設定`](#wp-admin) は、サイト上のすべてのレジの設定を変更します。店舗オーナーが設定しますが、一部の設定はレジに一度しか反映されません。[変更できる人と対象の設定](#wp-admin)を参照してください。
- WCPOS Proでは、`WP Admin > POS > 店舗` にある[各店舗専用のページ](../stores/index.mdx)で、その店舗の名前と住所、通貨と言語、税金、レシート、カスタマーディスプレイ、レジ、スタッフを設定します。
- [画面ごとの表示設定](#screen-settings)は、この端末でのその画面の表示方法を変更します。POSを開ける人なら誰でも変更できます。

## POSの設定を開く {#open}

メニュー下部の **店舗の状態** と **サポート** の間にある歯車を押します。設定の **一般** ページが開き、左側に7つのページが並びます。ページを押すと開きます。変更はその都度保存されるため、保存ボタンを押す必要はありません。スマートフォンでは、先に左上のメニューを開いてください。[スマートフォンの場合](#phone)を参照してください。

<JourneyShot manifest={storeManifest} device="tablet" step={1} offsets={[[38, -20], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0]]} alt="タブレットのPOS設定で一般を開いた画面。左端にアイコンのメニューとその下部の設定の歯車、その隣に縦に並ぶ7つの設定ページ、右側に一般ページが表示されています">

1. **設定** — メニュー下部の歯車です。販売画面に戻るには、メニュー上部のレジアイコンを押します。
2. **一般** — 店舗の名前と住所、言語、新しいカートに最初に設定される顧客、通貨と金額の表記方法です。住所はWooCommerceで、WCPOS Proでは店舗専用のページで設定します。それ以外はこの端末用に変更できます。[この端末に保存される設定](#this-device)と[店舗情報・言語・通貨](./store/general.mdx)を参照してください。
3. **税金** — POSでの税額の計算方法と表示方法です。税金のルール自体はWooCommerceで設定します。[税金設定](./store/tax.mdx)を参照してください。
4. **印刷** — この端末の印刷先プリンター、各プリンターの **テスト印刷**、各レシートテンプレートで使用するプリンターを設定します。[プリンター](../hardware/printers/index.mdx)を参照してください。
5. **カードリーダー** — このレジで決済に使用するカードリーダーです。まずWooCommerceの決済ゲートウェイでリーダーを設定すると、ここに表示されて接続できるようになります。カードリーダーはWCPOS Proで利用できます。[カードリーダーの互換性](../hardware/index.mdx#card-reader-compatibility)を参照してください。
6. **カスタマーディスプレイ** — ペアリングコードを使って、お客様に購入内容を表示するセカンドスクリーンをペアリングします。カスタマーディスプレイはWCPOS Proで利用できます。[カスタマーディスプレイ](../getting-started/free-vs-pro.mdx#customer-display)を参照してください。
7. **バーコードスキャン** — POSがスキャンと手入力を区別する方法、スキャン時の音、スキャナーのテスト欄です。[バーコードスキャン](./store/barcode.mdx)を参照してください。
8. **テーマ** — この端末でのPOSの外観です。テーマ、ボタンや文字の **表示倍率**、アイコン、フォントを設定します。[テーマ](./store/theme.mdx)を参照してください。

</JourneyShot>

キーボードショートカットは設定項目ではなく、固定されています。設定を開くショートカットもありません。POS画面で **Alt + /** を押すと一覧を確認できます。[キーボードショートカット](./store/hotkeys.mdx)も参照してください。

## この端末に保存される設定 {#this-device}

POSの **設定** で変更した内容は、現在の店舗について、この端末だけに適用されます。同じ店舗の別のレジにはそれぞれの設定が保持され、ここでの変更がWordPressに反映されることはありません。WordPressで権限グループの **POS設定の管理** をオフにしても、この画面は非表示になりません。[アクセスと権限グループ](./wp-admin/access.mdx)を参照してください。

特に注意が必要なのは **一般** ページです。店舗名、言語、デフォルト顧客、通貨と数値の書式は店舗から一度コピーされ、ここでこの端末用に変更できます。店舗の住所も同様にコピーされますが、ここでは変更できません。最初のコピー以降、WooCommerceやWP Adminで変更しても、**一般** の下部にある **サーバー設定を復元** を押すまで、これらの項目には反映されません。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-36, 0]]} maxWidth={724} alt="設定の一般ページ下部。サーバー設定を復元ボタンの隣に、WooCommerceの店舗からコピーされた設定であり、復元するとローカルの変更が上書きされるという説明があります">

1. **サーバー設定を復元** — **一般** の下部にあります。押してから確認します。

</JourneyShot>

:::warning 復元すると、この端末での変更が上書きされます
**サーバー設定を復元** は、WooCommerceから店舗の設定を再度読み込み、この端末での変更を上書きします。対象は、住所を含む **一般** の全項目（**桁のグループ化形式** を除く）と、**税金** のすべての選択項目です。プリンター、カードリーダー、カスタマーディスプレイ、バーコードスキャン、テーマの設定は変わりません。
:::

## すべてのレジで共有する設定 {#wp-admin}

店舗オーナーがWordPressの `WP Admin > POS > 設定` で設定します。サイト上のすべてのレジに適用されます。たとえば、商品のスキャンに使用する **バーコードフィールド**、新しいカートに最初に設定される顧客、チェックアウトに表示する決済ゲートウェイ、POS注文で送信するメール、POSを利用できる人などです。WCPOS Proでは、ここのレジのルールがサイトのデフォルトになり、各店舗の **レジ** ページで変更できます。[Proでレジを増やす](./wp-admin/registers.mdx#more-registers-with-pro)と[WordPress管理画面の設定](./wp-admin/index.mdx)を参照してください。

変更するには、POSを管理できるWordPressユーザーが必要です。管理者とショップマネージャーは変更できます。レジ係は、オーナーがその権限グループの **POS設定の管理** をオンにしない限り変更できません。[アクセスと権限グループ](./wp-admin/access.mdx)を参照してください。

新しいカートに最初に設定される顧客など、一部の設定はレジの初期設定時に各レジの **一般** ページにコピーされます。そのレジで **サーバー設定を復元** を押すまでは、コピーされた設定が保持されます。[この端末に保存される設定](#this-device)を参照してください。

## 画面ごとの設定 {#screen-settings}

商品パネルとカートには、それぞれスライダーのボタン（<Icon name="sliders" />）があり、**商品設定** と **カート設定** を開けます。**商品**、**注文**、**顧客**、**クーポン** の各画面にも同じボタンがあり、**表示オプション** と呼ばれます。表示する列や詳細、並び順、最初に表示する内容など、その画面の表示方法を設定します。変更はその都度、この端末だけに保存されます。各画面の設定は、それぞれの画面の説明を参照してください。

- [商品パネル](../pos/product-panel/display-settings.mdx)
- [カート](../pos/cart/index.mdx#display-settings)
- [商品](../products/index.mdx#display-settings)
- [注文](../orders/index.mdx#display-settings)
- [顧客](../customers/index.mdx#display-settings)
- [クーポン](../coupons/index.mdx#coupon-list)

## 問題が発生した場合 {#goes-wrong}

**あるレジでの変更が別のレジに表示されない。** POSの設定は端末ごとに保存されます。各レジで同じ変更を行ってください。すべてのレジで共有する項目の場合は、店舗オーナーに [`WP Admin > POS > 設定`](#wp-admin) での変更を依頼してください。

**WooCommerceで変更したのに、店舗名や通貨が古いままになっている。** **設定** から **一般** を開き、**サーバー設定を復元** を押してください。この端末での **一般** と **税金** の変更が上書きされます（[この端末に保存される設定](#this-device)を参照）。[店舗情報・言語・通貨](./store/general.mdx)も参照してください。

**WP AdminにPOSメニューがない。** お使いのWordPressユーザーにはPOSを管理する権限がありません。管理者に、該当する権限グループの **POS設定の管理** をオンにするよう依頼してください。[アクセスと権限グループ](./wp-admin/access.mdx)を参照してください。
