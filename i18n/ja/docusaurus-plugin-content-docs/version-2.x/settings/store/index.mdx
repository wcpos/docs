**POS 設定：** POS 内の設定は、この端末にのみ適用されます。

**設定**では、この端末での POS の動作を設定します。言語、金額の表記、税の表示、このレジで使うプリンター・カードリーダー・スキャナー、カスタマーディスプレイ、POS の外観を設定できます。保存ボタンはなく、変更はすぐに反映されます。

ここでの変更は、**税**の各項目も含めてこの端末に保存され、再読み込みや店舗との同期後も保持されます。他のレジにはそのレジ独自の設定があるため、レジごとに設定してください。

POS を利用できるユーザー、チェックアウト時の支払い方法、レジは、ここではなく WordPress で設定します。[WP Admin の設定](#wp-admin)をご覧ください。

## 設定を開く {#open}

スマートフォンでは、左上のメニュー（**☰**）をタップし、**設定**をタップします。[スマートフォンの場合](#phone)をご覧ください。

幅の広い画面では、サイドメニュー下部の **店舗の状態**と **サポート**の間にある **設定**をクリックします。**一般**が開き、その隣に七つの設定ページが一覧表示されます。ページをクリックすると開きます。設定が終わったら、サイドメニュー上部の **POS** をクリックしてレジに戻ります。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[38, -20], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0]]} alt="設定の一般ページ。サイドメニューでは設定ボタンが選択され、その隣の七つのページの一覧では一般が選択されています。一般ページには、店舗名、WooCommerce で設定した住所、言語、デフォルトの顧客、通貨が表示されています">

1. **設定** — サイドメニューの **店舗の状態**（赤い件数が付いた脈拍アイコン）の下、**サポート**の上にあります。
2. **一般** — 店舗名、言語、新しいカートのデフォルトの顧客、金額の表記（通貨、小数桁数、区切り文字）を設定します。下部に **サーバー設定を復元**があります。[一般](./general.mdx)をご覧ください。
3. **税** — 税の計算基準と、価格を税込み・税抜きのどちらで表示するかを設定します。[税](./tax.mdx)をご覧ください。
4. **印刷** — この端末の印刷先となるレシートプリンターと、各レシートテンプレートで使うプリンターを設定します。[プリンター](../../hardware/printers/index.mdx)をご覧ください。
5. **カードリーダー** — このレジで決済に使うカードリーダーを接続、切断、登録解除します。カードリーダーは WCPOS Pro で利用できます。[カードリーダー](../../hardware/card-readers/index.mdx)をご覧ください。
6. **カスタマーディスプレイ** — 顧客に向けた二つ目の画面をペアリングします。カスタマーディスプレイは WCPOS Pro で利用できます。[カスタマーディスプレイをペアリングする](#customer-display)をご覧ください。
7. **バーコードスキャン** — このレジのバーコードスキャナーを設定し、テストします。スキャンが認識されない場合や、キー入力がスキャンと認識される場合は、[バーコード設定](./barcode.mdx)をご覧ください。
8. **テーマ** — 色、ボタンと文字のサイズ、アイコン、フォントを設定します。[テーマ](./theme.mdx)をご覧ください。

</JourneyShot>

:::warning サーバー設定を復元すると変更が置き換わります
**サーバー設定を復元**を実行すると、この端末で変更した **一般**と **税**の値が、**桁区切りの形式**を除いて店舗の値に置き換わります。プリンター、スキャナー、テーマは変わりません。[サーバー設定を復元](./general.mdx#restore-server-settings)をご覧ください。
:::

**WooCommerce で設定**と表示された行には、住所や **税を有効化**など、店舗から送られる値が表示されます。ここでは変更できません。横にある **開く**を押し、WooCommerce で変更してください。

### カスタマーディスプレイをペアリングする {#customer-display}

1. **設定**で **カスタマーディスプレイ**を開きます。
2. **ペアリングコードを生成**を押します。
3. 顧客に向けた画面で **ディスプレイページの URL** を開き、コードを入力します。

## スマートフォンの場合 {#phone}

1. 左上のメニュー（**☰**）をタップし、メニュー下部の **設定**をタップします。
2. [上記](#open)と同じ七つの設定ページが一覧表示されます。いずれかをタップして開きます。
3. 上部の **‹ 設定**をタップすると、一覧に戻ります。
4. レジに戻るには、一覧画面のメニュー（**☰**）をタップし、**POS** をタップします。

## キーボードショートカット {#shortcuts}

キーボードショートカットの設定ページはなく、キーは変更できません。POS 画面で **Alt + /** を押すと、すべて表示されます。[キーボードショートカット](./hotkeys.mdx)をご覧ください。

## WP Admin の設定 {#wp-admin}

POS を利用できるユーザー、チェックアウト時の決済ゲートウェイ、レジと釣銭準備金、POS 注文で送信するメール、店舗の納税者 ID は、アプリではなく WordPress の `WP Admin > POS > 設定` で設定します。[WordPress 管理画面の設定](../wp-admin/index.mdx)をご覧ください。

## 問題が発生した場合 {#goes-wrong}

**他のレジと見た目や動作が異なります。** 設定は端末ごとに保存されます。そのレジでも **設定**を開いて設定してください。

**値が WooCommerce と一致しません。** 復元すると、この端末で変更した **一般**と **税**の値が、**桁区切りの形式**を除いて店舗の値に置き換わります。プリンター、スキャナー、テーマは変わりません。**一般**の下部にある **サーバー設定を復元**を押してください。[サーバー設定を復元](./general.mdx#restore-server-settings)をご覧ください。

**この店舗にはカードリーダーが設定されていません。** カードリーダーは、先に WooCommerce の決済ゲートウェイのページで設定します。また、WCPOS Pro が必要です。[決済ゲートウェイ](../../payment/gateways/index.mdx)をご覧ください。

**カスタマーディスプレイは Pro 機能です。** 店舗では無料版プラグインが動作しています。[WCPOS Pro](../../getting-started/pro-license.mdx)をご覧ください。**カスタマーディスプレイには新しいバージョンの WCPOS Pro が必要です**と表示される場合は、WordPress で Pro プラグインを更新してください。
