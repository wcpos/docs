カウンターにキーボードがあれば、マウスに手を伸ばさずに販売を処理できます。**Alt**（Mac では **Option ⌥**）を押しながらキーを押します。**Alt + /** で一覧を表示できます。

:::note ショートカットを使える場所
ブラウザーとデスクトップアプリの POS 画面で使えます。テキスト欄にカーソルがある場合も動作します。{/* pending: monorepo#3357 */} Mac では、**Option + N** など、その欄にアクセント記号を入力するショートカットを使うには、先に[欄の外をクリック](#goes-wrong)する必要があります。スマートフォンとタブレットのアプリにはショートカットはありません。他の画面にもありませんが、注文一覧では専用の[矢印キー操作](#orders)を使えます。
:::

## ショートカット一覧 {#shortcuts}

チェックアウト中や支払い済み画面では、**Alt + /** 以外のショートカットは使えません。また、レジ選択画面、**レジを開く**カード、現金の集計画面、未完了の注文一覧に隠れてカートが見えないときは、**Alt + F** と **Alt + /** 以外は使えません。

| キー | 動作 |
|---|---|
| **Alt + F** | **商品を検索**にカーソルを移動します。幅の狭い画面では、先に商品タブが開きます。 |
| **Alt + P** | **チェックアウト**を開きます。<br />_カートに商品が入っている必要もあります。_ |
| **Alt + N** | 空のカートを開きます。それまで操作していた注文は未完了のまま残ります。<br />_空のカートではなく、カートに注文がある必要もあります。_ |
| **Alt + ←** または **Alt + →** | 前または次の未完了の注文に移動します。<br />_未完了の注文が二つ以上ある必要もあります。_ |
| **Alt + D** | **割引を追加**を開きます。<br />_カートに注文がある必要もあります。_ |
| **Alt + V** | カート内の注文を即座に無効にします。誤って操作した場合は、すぐに **元に戻す**を押してください。<br />_カートに注文がある必要もあります。_ |
| **Alt + /** | ショートカット一覧を開閉します。<br />_チェックアウト中も含め、POS 画面ではいつでも使えます。_ |

:::warning Alt + V では確認は表示されません
キーを押すと即座に注文が無効になります。表示されるメッセージには **元に戻す**ボタンがあります。誤って操作した場合は、すぐに押してください。
:::

ショートカットは固定されており、変更する設定はありません。別のキーをご希望の場合は、[Discord](https://wcpos.com/discord) でお知らせください。

## すべてのショートカットを表示する {#list}

**Alt + /** を押します。右側から一覧が表示されます。

グレーの行は現在実行できません。カートが空の場合、**チェックアウト**、**新しいカート**、**割引を追加**、**注文を無効化**がグレーになります。**前のカート**と **次のカート**は、未完了の注文が二つになるまでグレーのままです。それ以外の行を押すと、対応するキーと同じ操作を実行できます。Windows では、下部に [Firefox](#goes-wrong) についての注意が表示されます。**閉じる**を押すか、もう一度 **Alt + /** を押すと一覧が閉じます。

一覧はカートを覆い、その隣の商品が暗く表示されます。

1. **商品を検索** — 商品検索欄にカーソルを移動し、入力やスキャンができる状態にします。[検索と絞り込み](../../pos/product-panel/search-filtering.mdx)をご覧ください。
2. **チェックアウト** — カート内の注文の支払いパネルを開きます。[チェックアウト](../../pos/checkout/index.mdx)をご覧ください。
3. **新しいカート** — 空のカートを開きます。それまで操作していた注文は[未完了の注文](../../pos/cart/open-orders.mdx)に残ります。
4. **前のカート** — 一つ前の未完了の注文に戻ります。
5. **次のカート** — 次の未完了の注文に進みます。
6. **割引を追加** — 注文の **割引を追加**を開きます。[割引](../../pos/cart/discounts.mdx)をご覧ください。
7. **注文を無効化** — 確認を表示せず、カート内の注文を即座に無効にします。誤って操作した場合は、すぐに **元に戻す**を押してください。[無効化](../../pos/cart/order-actions.mdx#void)をご覧ください。
8. **キーボードショートカット** — この一覧です。

</JourneyShot>

## 注文一覧内を移動する {#orders}

ブラウザーまたはデスクトップアプリの **注文**画面で注文をクリックするか、**Tab** で一覧に移動してから、次のキーを使います。

- **↓** / **↑** で、次または前の注文に選択を移動します。
- **Enter** で、選択中の注文を開きます。

:::info Pro 機能
注文画面は WCPOS Pro で利用できます。[注文](../../orders/index.mdx)をご覧ください。
:::

## 問題が発生した場合 {#goes-wrong}

**何も起こりません。** **Alt + /** で一覧を開いてください。ショートカットの行がグレーの場合は、[表](#shortcuts)に記載された理由でまだ実行できません。POS 画面を開いていること、レジが開いていること、未完了の注文一覧がカートを覆っていないことを確認してください。

**Alt + F または Alt + D で Firefox のメニューが開きます。** Windows では、Firefox がこの二つのキー操作を優先することがあります。代わりにショートカット一覧の行を押すか、Chrome、Edge、デスクトップアプリを使ってください。

**Mac で Option + N を押すと、検索欄にアクセント記号が入力されます。** 一部のキーボード配列では、Option + 英字でアクセント記号を入力します。欄への入力中は、POS もその入力を受け付けます。欄の外をクリックしてから、もう一度ショートカットを押してください。
