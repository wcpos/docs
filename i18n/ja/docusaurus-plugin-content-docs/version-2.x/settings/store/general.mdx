**POS設定：** POSの `Settings → General` で設定し、この端末に保存されます。

**一般** には、店舗の名前と住所、POSの表示言語、新しいカートに最初に設定される顧客、金額の表記方法があります。メニュー下部の **設定** から開きます。一覧の最初のページです。

これらの初期値には店舗の設定が使われます。名前はWP Adminの[店舗情報](../wp-admin/general.mdx#store-details)、住所と金額の書式はWooCommerce、言語はWordPress、デフォルト顧客は[デフォルトのPOS顧客](../wp-admin/general.mdx#default-pos-customer)から取得します。WCPOS Proで `WP Admin > POS > 店舗` に作成した店舗の場合は、その店舗独自の名前、住所、通貨、言語が使われます。[店舗の設定](../../stores/setup.mdx#store-pages)を参照してください。

変更はすぐに保存され（保存ボタンはありません）、この端末だけに適用されます。WooCommerceの設定やほかのレジは変わりません。店舗の値に戻すには、[サーバー設定を復元](#restore-server-settings)を使ってください。

## 一般ページ {#general-page}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[115,0],[180,0],[450,0],[0,-26],[200,0],[100,0]]} alt="設定の一般ページ。店舗欄には店舗名と、WooCommerceで設定と表示された読み取り専用の所在地4項目があり、ローカライズ欄には言語、デフォルト顧客、レジ係をデフォルト顧客にするスイッチがあります">

1. **一般** — このページです。**設定** の一覧の先頭にあります。
2. **店舗名** — この端末のPOSに表示される店舗の名前です。
3. **店舗の所在国** — ここでは変更できない住所4項目の最初の項目です。[店舗の住所](#store-address)を参照してください。
4. **開く** — 住所を設定するWooCommerceの設定画面をブラウザーで開きます。
5. **言語** — この端末のPOS画面の言語です。[言語](#language)を参照してください。
6. **デフォルト顧客** — 新しいカートに最初に設定される顧客です。[デフォルト顧客](#default-customer)を参照してください。

</JourneyShot>

**デフォルト顧客** の下にある **レジ係をデフォルト顧客にする** をオンにすると、新しいカートにログイン中のレジ係が最初から設定されます。さらに下には **通貨と数値**、**サーバー設定を復元**、**すべてのローカルデータを削除** があります。[金額の書式](#money-format)と[サーバー設定を復元する](#restore-server-settings)を参照してください。

## 店舗の住所 {#store-address}

**店舗の所在国**、**店舗の都道府県**、**店舗の市区町村**、**店舗の郵便番号** には、編集できないテキストとして住所が表示され、**WooCommerceで設定** と記されています。これは店舗の住所で、[店舗の所在地](tax.mdx#calculate-tax-based-on)に基づいて課税する場合にPOSが税額の計算に使うため、店舗で使用している住所と一致している必要があります。

住所を変更するには：

1. 4項目のいずれかにある **開く** を押します。WooCommerceの設定がブラウザーで開きます。
2. `WP Admin > WooCommerce > 設定 > General` の **店舗の住所** を変更して保存します。
3. POSに戻り、[サーバー設定を復元](#restore-server-settings)を押します。POSは新しい住所を自動では取得しません。

:::info WCPOS Proの場合
`WP Admin > POS > 店舗` で作成した店舗は、**詳細** ページに独自の住所を保持します。そこで変更してから（[店舗の各ページに入力する](../../stores/setup.mdx#store-pages)を参照）、**サーバー設定を復元** を押してください。**開く** は引き続きWooCommerceの設定を開きますが、そこにはその店舗の住所は保存されていません。
:::

市区町村を設定していない店舗では、**店舗の市区町村** にダッシュが表示されます。スマートフォンでは、各値の下に **WooCommerceで設定** と **開く** が表示されます。

## 言語 {#language}

**言語** は、この端末のPOS画面の言語と、レシートやカスタマーディスプレイでの金額の表記方法を変更します。「小計」など、レシートに印刷される文言は翻訳しません。それらは店舗から取得されます。[翻訳](../../support/translations.mdx)を参照してください。

初期値はWordPressサイトの言語です。WCPOS Proでは、店舗の **通貨と言語** ページで設定した言語になります。

## デフォルト顧客 {#default-customer}

新しいカートには、最初から **デフォルト顧客** が設定されます。店頭での販売用の **ゲスト**、または一覧から選んだ顧客です。**レジ係をデフォルト顧客にする** をオンにすると、新しいカートにはログイン中のレジ係が設定され、**デフォルト顧客** の一覧はグレー表示になって選択できなくなります。

どちらも初期値には、店舗の[デフォルトのPOS顧客](../wp-admin/general.mdx#default-pos-customer)と[レジ係のアカウントを使用](../wp-admin/general.mdx#use-cashier-account)が使われます。ここでの変更は、この端末の新しいカートに適用されます。すでに開いているカートの顧客は変わりません。また、どの販売でもカート内で顧客を変更できます。[顧客を選ぶ](../../pos/cart/index.mdx#customer-selector)を参照してください。

## 金額の書式 {#money-format}

:::warning 通貨と小数点以下の桁数は店舗と同じ設定にしてください
**通貨** は、この端末からWooCommerceへ送信するすべての新規注文に設定されます。**小数点以下の桁数** は、チェックアウト時の支払額やお釣りの丸め処理に使われます。店舗と異なる値にすると、注文の通貨が誤ったものになったり、支払額が注文合計と一致しなくなったりします。すでに開いているカートでは、作成時の通貨が保持されます。
:::

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[230,0],[60,0],[-30,0],[-30,0]]} alt="設定の一般ページを下にスクロールした画面。通貨と数値欄に、通貨、通貨記号の位置、小数点の区切り文字、小数点以下の桁数、桁区切り文字、桁のグループ化形式があり、その下にサーバー設定を復元とすべてのローカルデータを削除があります">

1. **通貨** — この端末で作成する新規注文の通貨です。店舗と同じ設定にしてください。
2. **小数点以下の桁数** — 画面とチェックアウトで金額を小数点以下何桁まで扱うかを設定します。店舗と同じ設定にしてください。
3. **サーバー設定を復元** — 店舗の値に戻します。[サーバー設定を復元する](#restore-server-settings)を参照してください。
4. **すべてのローカルデータを削除** — この端末に保存されたすべてのデータを削除し、再度ダウンロードします。[ローカルデータを削除する](../../support/troubleshooting/clear-local-data.mdx)を参照してください。

</JourneyShot>

**通貨**、**通貨記号の位置**、**小数点の区切り文字**、**桁区切り文字**、**小数点以下の桁数** の初期値には、`WP Admin > WooCommerce > 設定 > General` にある店舗の通貨オプションが使われます。WCPOS Proでは、店舗専用の **通貨と言語** ページで **通貨** と **通貨記号の位置** を個別に設定できます。

**通貨記号の位置**、**小数点の区切り文字**、**桁区切り文字**、**桁のグループ化形式** は、この端末の画面での金額の見え方だけを変更します。

<details>
<summary>通貨記号の位置、区切り文字、桁のグループ化</summary>

| 項目 | 設定内容（1234.5米ドルの表示例） |
|---|---|
| **通貨記号の位置** | **左** $1,234.50 · **右** 1,234.50$ · **左（スペースあり）** $ 1,234.50 · **右（スペースあり）** 1,234.50 $ |
| **小数点の区切り文字** | セントの前に入る記号です。通常は `.` または `,` です。 |
| **桁区切り文字** | 数字のグループ間に入る記号です。通常は `,`、`.`、またはスペースです。小数点の区切り文字とは異なるものを使ってください。 |
| **桁のグループ化形式** | 123,456,789（3桁区切り）· 12,34,56,789（インドで使われるラーク方式）· 1,2345,6789（中国や日本で使われる4桁区切り）。選択肢には設定した桁区切り文字が表示されます。 |

</details>

レシートとカスタマーディスプレイでは、代わりに[言語](#language)に応じた書式で金額を表示します。

## サーバー設定を復元する {#restore-server-settings}

**サーバー設定を復元** は、店舗の設定を再度読み込みます。WooCommerceで店舗の住所や通貨などを変更した後や、POSと店舗の設定が一致しない場合に使ってください。

:::warning 復元すると複数の設定が一度に上書きされます
店舗の名前、住所、言語、デフォルト顧客、金額の書式は、この端末で変更していても店舗の値に戻ります。
:::

<details>
<summary>どの設定が復元されますか？</summary>

復元すると、[税金](tax.mdx)ページにある店舗の税金設定も更新されます。**桁のグループ化形式** はこの端末だけの設定なので、変わりません。

</details>

1. **一般** の下部までスクロールし、**サーバー設定を復元** を押します。**サーバー設定を復元しますか？** が開きます。
2. 実行するには **サーバー設定を復元** を、何も変更しない場合は **キャンセル** を押します。
3. 完了すると、ボタンの下に **復元しました** と一時的に表示され、ページに店舗の値が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0,38],[0,38]]} alt="設定の一般ページの上に表示された「サーバー設定を復元しますか？」ダイアログ。設定はWooCommerceの店舗からコピーされており、復元するとローカルの変更が上書きされるという説明と、キャンセル、サーバー設定を復元のボタンがあります">

1. **キャンセル** — ダイアログを閉じます。何も変更されません。
2. **サーバー設定を復元** — この端末の設定を店舗の値に戻します。

</JourneyShot>

復元には店舗への接続が必要です。オフラインの場合は **店舗に接続できませんでした** と表示され、何も変更されません。オンラインに戻ったら **再試行** を押してください。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-30,0],[0,0]]} alt="設定の一般ページ下部。サーバー設定を復元ボタンと、その下に「店舗に接続できませんでした」というメッセージと再試行ボタンがあります">

1. **サーバー設定を復元** — 店舗に接続できなかった復元操作です。
2. **再試行** — 確認画面をもう一度開きます。オンラインに戻ったら押してください。

</JourneyShot>

## 問題が発生した場合 {#troubleshooting}

**店舗の名前、住所、通貨が古いままになっている。** POSは店舗を初めて読み込んだときにこれらをコピーし、その後は自動更新しません。そのため、WP Adminでの名前の変更やWooCommerceでの変更は、自動ではPOSに反映されません。[サーバー設定を復元](#restore-server-settings)を押してください。

**店舗に接続できませんでした。** 端末がオフラインになっているか、店舗から応答がありませんでした。接続を確認してから **再試行** を押してください。復元が成功するまでは、設定は元のままです。

**価格の通貨記号や区切り文字が正しくない。** この端末で **通貨と数値** が変更されています。各項目を手動で戻すか、[サーバー設定を復元](#restore-server-settings)を押してください。復元すると、この端末の店舗名、住所、言語、デフォルト顧客も店舗の値に戻ります。

**POSが意図しない言語で表示される。** このページの **言語** を変更してください。言語は端末ごとに保存されます。

**新しいカートに意図しない顧客が設定される。** この端末の **デフォルト顧客** と **レジ係をデフォルト顧客にする** を確認してください。すべての端末に適用するには、WP Adminで[デフォルトのPOS顧客](../wp-admin/general.mdx#default-pos-customer)を変更してから、各端末で **サーバー設定を復元** を押します。
