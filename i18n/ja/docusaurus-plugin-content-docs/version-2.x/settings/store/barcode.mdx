**POS設定：** この端末のPOSで `Settings → Barcode Scanning` を開きます。バーコードフィールドはWP Adminの一般にあります。

**設定** を開き、**バーコードスキャン** を選択します。ほとんどの店舗では、ここでの変更は不要です。スキャナーは接続またはペアリングするだけで使えます。スキャン音をオンにしたい場合や、スキャンが期待どおりに読み取られない場合に、このページを開いてください。

変更はその都度保存され、**保存** ボタンはありません。この端末だけに適用されるため、スキャナーを使うレジごとに設定してください。

**スキャンできませんか？** まず[スキャナーをテストする](#test)をお試しください。POSが受け取った内容と修正方法が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[60, 0], [60, 0], [60, 0], [60, 0], [-50, 0], [260, 0], [165, 0], [-50, 0], [150, 0]]} alt="設定のバーコードスキャン画面。スキャン欄はしきい値が24、最小文字数が8、プレフィックスとサフィックスが空欄。サウンド欄のスキャン時に音を鳴らすはオフ。スキャナー欄には、ほとんどのスキャナーは設定不要、スキャナー設定ガイド、直接接続があり、その下にバーコードスキャンテストの上部が見えます">

1. **バーコード平均入力間隔のしきい値 (ms)** — スキャンと判定するキー入力の速さです。[スキャンと手入力を区別する](#settings)を参照してください。
2. **バーコードの最小文字数** — スキャンと判定するコードの最小文字数です。
3. **バーコードスキャナーのプレフィックス** — スキャナーが各コードの先頭に付ける文字で、検索前に削除されます。
4. **バーコードスキャナーのサフィックス** — スキャナーが各コードの末尾に付ける文字で、検索前に削除されます。
5. **スキャン時に音を鳴らす** — 初期状態ではオフです。オンにすると音を選べます。[スキャン音を選ぶ](#sound)を参照してください。
6. **ほとんどのスキャナーは設定不要** — この端末にスキャナーを直接接続または登録するまで、**スキャナー** 欄に表示されるメッセージです。
7. **スキャナー設定ガイド** — [スキャナー設定ウィザード](../../hardware/scanners/setup-wizard.mdx)を開きます。
8. **スキャナーを直接接続（詳細設定）** — キーボードモードでは対応できない場合に使用します。[スキャナーを接続する](#scanner)を参照してください。
9. **バーコードスキャンテスト** — スキャンすると、POSがどのように判定したかを確認できます。[スキャナーをテストする](#test)を参照してください。

</JourneyShot>

## スキャンと手入力を区別する {#settings}

何を設定すればよいかわからない場合は、[テスト欄でスキャン](#test)してください。スキャナーの入力間隔を計測し、修正方法を提案します。

<details>
<summary>スキャン検出を調整する</summary>

ほぼすべてのスキャナーが使用するキーボードモードでは、非常に速いキーボードのようにバーコードを入力します。POSはキー入力の間隔を計測します。平均間隔がしきい値未満ならスキャン、しきい値を超えていれば手入力と判定します。**スキャン** 欄で、この境界を設定します。

- **バーコード平均入力間隔のしきい値 (ms)** — 初期値は **24** です。キー入力の平均間隔がこのミリ秒数未満なら、スキャンと判定します。遅いスキャナーでは値を上げ、速い手入力がスキャンと判定される場合は下げてください。
- **バーコードの最小文字数** — 初期値は **8** です。スキャンと判定するコードの最小文字数です。使用する最も短いバーコードに合わせて設定してください。8はEAN-8に適した値です。
- **バーコードスキャナーのプレフィックス** — 初期状態では空欄です。スキャナーが各コードの先頭に付ける1文字を指定します。POSはコードを検索する前にこの文字を削除します。
- **バーコードスキャナーのサフィックス** — 初期状態では空欄です。スキャナーが各コードの末尾に付ける1文字を指定します。プレフィックスと同様に削除されます。

</details>

<details>
<summary>余分な文字を削除する</summary>

スキャナーが文字を追加する設定でなければ、**バーコードスキャナーのプレフィックス** と **バーコードスキャナーのサフィックス** は空欄のままにしてください。各コードの先頭に `A`、末尾に `Z` が付く場合は、プレフィックスに `A`、サフィックスに `Z` を入力します。スキャンした `A4006381333931Z` は `4006381333931` として検索されます。POSが文字を削除するのは指定した端だけで、コードの途中からは削除しません。末尾のEnterはPOSが無視するため、サフィックスの設定は不要です。

</details>

<details>
<summary>バーコードが短すぎる場合</summary>

**バーコードの最小文字数** より短いスキャンは検索されません。POSにはコードとともに **スキャンしたバーコード：** と **バーコードは8文字以上である必要があります**（設定した最小文字数に応じた表示）が表示されます。キーボードモードのスキャナーでは、キー入力がスキャンらしく、すべて数字であるか末尾にEnterがある場合に限り、このメッセージが表示されます。表示頻度は最大で30秒に1回です。短い英字の連続入力は速い手入力と判定され、そのまま扱われます。

</details>

## スキャン音を選ぶ {#sound}

スキャン音を使うと、お客様から目を離さずに、商品がカートに追加されたか、スキャンに対応が必要かを音で確認できます。選び方は次のとおりです。

1. **サウンド** の **スキャン時に音を鳴らす** をオンにします。その下にほかのサウンド設定が表示されます。
2. テーマ名を押して選択します。テーマの **▶** と **▶✕** を押すと、成功音と失敗音を試聴できます。
3. **音量** をドラッグし、その隣の **▶** を押して確認します。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-50, 0], [110, -108], [2, -40], [8, -40], [0, -30], [0, -34], [-50, 0], [-50, 0]]} alt="スキャン時に音を鳴らすをオンにしたバーコードスキャン画面。サウンドテーマ一覧にクラシック、チェックアウト、ソフトがあり、それぞれに説明と2つの試聴ボタンがあります。音量スライダーにも試聴ボタンがあり、成功音と失敗音のスイッチが並んでいます">

1. **スキャン時に音を鳴らす** — スキャン音をオンにし、その下にオプションを表示します。
2. **サウンドテーマ** — **クラシック**、**チェックアウト**、**ソフト** から選びます。テーマ名を押して選択してください。
3. **▶** — そのテーマの成功音を再生します。商品がカートに追加されたときの音です。
4. **▶✕** — そのテーマの失敗音を再生します。
5. **音量** — スライダーをドラッグします。初期状態では小さめの音量に設定されています。
6. **音量** の隣の **▶** — 選択したテーマの成功音を、その音量で再生します。
7. **成功音** — 初期状態ではオンです。失敗音だけを鳴らすにはオフにします。
8. **失敗音** — 初期状態ではオンです。成功音だけを鳴らすにはオフにします。

</JourneyShot>

<details>
<summary>サウンドテーマを比較する</summary>

各テーマには成功音と失敗音があります。アプリでは次のように説明されています。

| テーマ | 成功音 / 失敗音 |
|---|---|
| **クラシック** | 明るく上がる短い電子音 / 低いブザー音。初期状態のテーマです。 |
| **チェックアウト** | スーパーのレジのような一定の電子音 / 低い音が2回 |
| **ソフト** | 優しいチャイム / 控えめなノック音。静かな店舗向け |

試聴音は設定した音量で再生されるため、試聴しながらテーマと音量を一緒に選べます。

</details>

**各音が鳴るタイミング。** 成功音は、スキャンした商品がカートに追加されたときに鳴ります。失敗音は、それ以外のスキャン結果で鳴ります。**バーコードが見つかりません**、**複数の一致があります**、**バリエーションを選択**、在庫切れなど、[画面のメッセージ](../../pos/product-panel/barcode-scanning.mdx#messages)に記載された結果が対象です。**店舗を検索中…** の間は、まだ結果が出ていないため音は鳴りません。

<details>
<summary>iPhone、iPad、Androidでの振動</summary>

iPhone、iPad、Androidアプリには、**失敗時に振動** というスイッチもあり、初期状態ではオンです。スキャンに失敗すると、失敗音とともに端末が振動します。**失敗音** がオフの場合は振動のみになります。使用するには **スキャン時に音を鳴らす** をオンにする必要があります。▶✕の試聴では音だけが再生され、振動しません。ブラウザーとデスクトップアプリにはこの機能はありません。

</details>

:::tip 静かなレジカウンターにする
穏やかな音にするには、**ソフト** を選んで音量を下げます。無音にするには、iPhone、iPad、Androidアプリで **スキャン時に音を鳴らす** と **失敗時に振動** をオンにしたまま、**成功音** と **失敗音** をオフにします。これでスキャンに失敗したときだけ、振動で通知されます。
:::

## スキャナーを接続する {#scanner}

**スキャナー** 欄は、入力速度ではなく機器自体でPOSが識別するスキャナー向けです。ほぼすべてのスキャナーはBluetoothまたはUSBキーボードとして接続されるため、ここでの設定は不要です。端末の設定でペアリングしてスキャンしてください。

- **スキャナー設定ガイド** は[スキャナー設定ウィザード](../../hardware/scanners/setup-wizard.mdx)を開きます。いくつかの質問に答えると、設定や問題の解決方法が案内されます。
- **スキャナーを直接接続（詳細設定）** は、キーボードモード以外のUSBまたはBluetoothスキャナー用のパネルを開きます。Androidでは、この項目は **スキャナーを登録** と表示されます。キーボードモードのスキャナーを機器として登録するため、スキャン判定が入力速度に依存しなくなります。[スキャナーを直接接続する](../../hardware/scanners/index.mdx#direct)を参照してください。

SafariとFirefoxには **スキャナー** 欄がありません。これらのブラウザーではスキャナーを直接接続できないためです。

## スキャナーをテストする {#test}

画面下部の **バーコードスキャンテスト** には、上の設定に基づいてPOSが各スキャンをどう判定したかが表示されます。

1. スキャンの準備をします。ブラウザーやデスクトップアプリでは、テキスト入力欄の外をクリックします。iPhone、iPad、Androidアプリでは、**キー入力イベント** をタップします。
2. 任意のバーコードをスキャンします。
3. グラフの下に表示される判定を確認します。**スキャンとして検出**、または手入力として扱われた理由が表示されます。
4. 修正方法が提案されたら、**適用** を押します。
5. もう一度スキャンして確認します。

ここでは同じバーコードを2回スキャンしています。1回は遅く入力されたため手入力として扱われ、もう1回はスキャナーの速度で入力されています。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[190, 0], [190, 0], [420, 0], [330, -24], [200, -52], [175, -8]]} alt="高速なスキャン後のバーコードスキャンテスト。キー入力イベントには受信したキー、検出したバーコードにはコードが表示されています。キー入力間隔のグラフには破線のしきい値があり、スキャンとして検出の判定と平均入力間隔、スキャンと手入力が各1回の最近の試行、トラブルシューティングガイドへのリンクが表示されています">

1. **キー入力イベント** — 末尾のEnterを含む、受信したすべてのキーです。
2. **検出したバーコード** — プレフィックスとサフィックスを削除した後、POSが検索するコードです。
3. **入力間隔のグラフ** — キーごとに棒が表示され、しきい値の破線と比較できます。線を超えた黄色の棒は、入力が遅すぎたキーを示します。
4. **判定** — **スキャンとして検出**、または手入力として扱われた理由です。設定が原因の場合は、修正方法と、それを保存する **適用** ボタンが表示されます。
5. **最近の試行** — 直近の数回の結果です。それぞれに **スキャン**、**手入力**、**短すぎる** のラベルと、キー入力の平均間隔が表示されます。
6. **トラブルシューティングガイド** — 症状別の解決方法を調べるための[スキャナー設定ウィザード](../../hardware/scanners/setup-wizard.mdx)を開きます。

</JourneyShot>

テストで提案される修正方法は、スキャナーが少し遅い場合の **しきい値を上げる**、コードが最小文字数未満の場合の **最小文字数を下げる**、先頭の文字をプレフィックスとして削除する設定です。各判定の詳しい説明は、[テストパネルでスキャンを確認する](../../hardware/scanners/setup-wizard.mdx#test-panel)を参照してください。

## 問題が発生した場合 {#goes-wrong}

**テストに何も表示されない。** まずスキャンの入力先を確認してください。ブラウザーやデスクトップアプリでは、テキスト入力欄にスキャンすると、その欄に文字が入力されます。スキャン前に欄の外をクリックしてください。iPhone、iPad、Androidアプリでは、先に **キー入力イベント** をタップします。それでも何も表示されない場合は、スキャナーがペアリングまたは接続されているか確認してください。[スキャナーを接続する](#scanner)を参照してください。

**判定に「手入力として処理」と表示される。** スキャナーの入力が、設定したしきい値より遅くなっています。提案の **適用** を押すか、**バーコード平均入力間隔のしきい値 (ms)** を上げて、もう一度スキャンしてください。

**商品検索での手入力がスキャンと判定される。** iPhone、iPad、Androidアプリでは、POSが検索の手入力も速度で判定するため、この現象が起こります。しきい値を下げるか、**バーコードの最小文字数** を増やしてください。ブラウザーやデスクトップアプリでは、入力欄への手入力がスキャンと判定されることはありません。

**コードの先頭や末尾に余分な文字がある。** スキャナーが追加している文字です。その文字を **バーコードスキャナーのプレフィックス** または **バーコードスキャナーのサフィックス** に入力してください。末尾のEnterには設定は不要です。

**「バーコードは8文字以上である必要があります」と表示される。** コードが **バーコードの最小文字数** より短くなっています。使用する最も短いバーコードの文字数まで値を下げてください。

**スキャンしても音が鳴らない。** **スキャン時に音を鳴らす** がオンであること、鳴らしたい **成功音** または **失敗音** がオンであること、端末がミュートになっていないことを確認してください。ブラウザーでは、ページ内のどこかをクリックまたはタップするまで音が再生されないため、ページを開いた直後の最初のスキャンは無音になることがあります。

**POSにはスキャンが届くのに商品が表示されない。** 理由はPOSに表示されます。[画面のメッセージ](../../pos/product-panel/barcode-scanning.mdx#messages)を参照してください。バーコードを格納する商品フィールドは、[バーコードフィールド](../wp-admin/general.mdx#barcode-field)で設定します。
