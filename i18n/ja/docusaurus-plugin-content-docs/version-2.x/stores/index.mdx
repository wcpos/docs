:::info Pro 機能
複数の店舗を使うには [WCPOS Pro](../getting-started/pro-license.mdx) が必要です。Pro がない場合、POS は単一店舗で動作します。店舗名、連絡先、納税者番号は **WP Admin → レジ → 設定 → 一般**から取得し、その他は WooCommerce の設定を使います。
:::

店舗とは、ショップ、市場の屋台、業務用の販売窓口など、販売を行う場所です。1 つの WooCommerce サイト内で、各店舗に住所、レシート、税、レジ、スタッフを設定できます。すべての売上は販売した店舗に紐づけて記録されるため、注文やレポートを店舗ごとに確認できます。

店舗を作成するには、[店舗の設定](./setup.mdx)をご覧ください。店舗・レジ・デバイスの関係については、[店舗、レジ、デバイス](./registers-and-devices.mdx)をご覧ください。

## レジ係が店舗を確認する場所 {#in-the-pos}

レジ係はサインイン時に店舗を選びます。一覧には、利用を許可された店舗だけが表示されます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[170, 0], [170, 0], [0, 0]]} maxWidth={460} alt="レジ係がサインインした状態のサインインカード。「店舗を選択」に番号付きで 2 つの店舗が並び、片方が選択されています。POS を開くボタンも表示されています">

1. **利用できる店舗** — ここでは選択済みです。右側の番号は WP Admin での店舗 ID です。
2. **別の店舗** — このレジ係が利用できるもう一方の店舗です。
3. **POS を開く** — 選択した店舗の POS を開きます。店舗が 1 つだけの場合は最初から選択され、見出しは**店舗**と表示されます。

</JourneyShot>

POS では、カートの上にあるレジバーの先頭に店舗名が表示されます。店舗に複数のレジがある場合はレジ名も表示されます。店舗名、またはバーの端にある自分のアバターをタップすると、レジ係パネルが開きます。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[232, 0], [-30, 0]]} maxWidth={512} alt="レジ係パネル：レジ係の名前の下に店舗とレジの時刻が表示され、店舗の行には切り替えボタンがあります">

1. **店舗とレジの時刻** — 自分の名前の下に、販売中の店舗が表示されます。
2. **切り替え** — 複数の店舗を利用できる場合にのみ、**店舗**の行に表示されます。

</JourneyShot>

### 別の店舗に切り替える {#switch-store}

先に処理中の支払いを完了し、オンラインの状態で次の手順を行います。

1. 店舗名、またはバーの端にある自分のアバターをタップして、レジ係パネルを開きます。
2. **店舗**の行の**切り替え**を押し、店舗を選びます。
3. 確認画面を読みます。***店舗名*に切り替えますか？** と表示され、その店舗のレジが開いているかどうかも示されます。
4. ***店舗名*に切り替え**を押します。その店舗で POS が再読み込みされます。

支払いの処理中や POS がサイトに接続できない間は、**切り替え**がグレー表示になります。接続できない場合、その行には**切り替えには店舗への接続が必要です**と表示されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[160, 0], [160, 0], [-16, 0]]} maxWidth={512} alt="レジ係パネルの店舗切り替え画面：現在の店舗にチェックが付き、選択できる別の店舗と戻る矢印が表示されています">

1. **現在の店舗** — チェックが付いています。再度選択することはできません。
2. **別の店舗** — 押すとその店舗に切り替わります。
3. **戻る** — 切り替えずにレジ係パネルへ戻ります。

</JourneyShot>

<Accordion>
  <AccordionItem question="切り替え時に開いているドロワーはどうなるか">

レジが開いている場合、確認画面で現金の扱いを次の 2 つから選べます。

- **ドロワーを持ち運ぶ** — 現在のレジを予定残高で締め、その金額を釣銭準備金として別の店舗のレジを開きます。移動先の店舗のレジが閉じている場合に選択できます。
- **ここで開いたままにする** — 現在のレジを開いたままにします。確認画面には、ドロワーがここで開いたままになると表示されます。

移動先の店舗に複数のレジがある場合は、その店舗でレジを選びます。[店舗とレジの選択](./registers-and-devices.mdx#choosing-a-store-and-a-register)をご覧ください。

  </AccordionItem>
</Accordion>

## 店舗ごとに設定する項目 {#what-stores-provide}

管理者は **WP Admin → レジ → 店舗**にある各店舗のページで、住所とレシート、税、レジ、サインインできるスタッフを設定します。

<Accordion>
  <AccordionItem question="管理者が店舗ごとに変更できる設定">

| 店舗ごとの項目 | 設定ページ |
| --- | --- |
| レシートに印刷する店舗名、住所、ロゴ、連絡先 | [**詳細**](./setup.mdx#store-pages) |
| レシートに印刷する営業時間 | **営業時間** |
| 通貨、POS とレシートの言語、レポートと締め処理リマインダーのタイムゾーン | **通貨と言語** |
| 税の計算方法とレシートに印刷する納税者番号 | **税** |
| レシートのメッセージとレジ係が印刷できるレシートテンプレート | **レシート** |
| お客様向け画面に表示する内容 | **カスタマーディスプレイ** |
| レジ（キャッシュドロワー）とキャッシュドロワーのルール | [**レジ**](./setup.mdx#registers) |
| サインインできるスタッフ | [**スタッフ**](./setup.mdx#staff) |

  </AccordionItem>
</Accordion>

商品、顧客、クーポン、支払い方法、税率そのもの（[税設定](../settings/store/tax.mdx)を参照）、その他の WooCommerce 設定は、すべての店舗で共有します。ただし商品には、[店舗独自の価格や税](#store-specific-pricing)を設定したり、[ATUM で店舗ごとの在庫](#inventory-management)を持たせたりできます。

## 店舗ごとの注文とレポート {#filtering-by-store}

- **[注文](../orders/index.mdx)** を開くと、サインイン中の店舗で自分が受け付けた注文が表示されます。上部のフィルターに店舗名が表示され、タップすると別の店舗や、**作成元**の **POS**、**オンラインショップ**、**WP Admin** を選べます。オンライン注文や WP Admin で作成した注文も含め、すべての店舗の注文を表示するには、このフィルターと隣のレジ係フィルターを解除してください。
- **[レポート](../reports/index.mdx)**は、画面上部に名前が表示されている店舗とレジを対象とします。名前をタップすると、別の店舗や**すべての店舗**を選べます。
- **[レシート](../receipts/index.mdx)** には、その売上を登録した店舗の住所とロゴが印刷されます。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[150, 0], [150, 0], [150, 0], [150, 0]]} maxWidth={344} alt="レポートの「AL 12345 Store・すべてのレジ」の下に開いた店舗とレジのメニュー。店舗グループには「すべての店舗」、チェック付きの「AL 12345 Store」、「AL Store」があり、レジグループにはチェック付きの「すべてのレジ」と「レジ」があります">

1. **すべての店舗** — すべての店舗を 1 つのレポートにまとめます。店舗が複数ある場合にのみ表示されます。
2. **店舗** — その店舗の売上だけを表示します。
3. **すべてのレジ** — 選択した店舗のすべてのレジと、オンラインで受け付けた注文を対象とします。
4. **レジ** — 1 台のレジの売上を表示します。

</JourneyShot>

WP Admin では、注文の **POS 店舗**に販売した店舗が表示されます。変更すると、その注文は別の店舗へ移動します。

## 店舗ごとの価格、税、在庫 {#store-specific-pricing}

商品には、特定の店舗独自の価格や税を設定できます。その店舗のレジ係にはその設定が適用され、他の店舗では商品の通常の WooCommerce の価格と税が使われます。

<Accordion>
  <AccordionItem question="特定の店舗で商品の価格や税を変更する">

**WP Admin → 商品**で商品または各バリエーションを開き、店舗ごとに独自の**通常価格**と**セール価格**、または**税区分**と**税クラス**を設定します。[店舗ごとの価格と税](./setup.mdx#per-store-pricing)をご覧ください。

  </AccordionItem>
</Accordion>

### 在庫 {#inventory-management}

すべての店舗で同じ WooCommerce の在庫を共有します。店舗ごとに在庫を管理するには、[ATUM Multi-Inventory](../extensions/atum.mdx) を使います。各店舗を ATUM のロケーションに紐づけると、販売時にそのロケーションの在庫が減ります。ATUM では、各店舗にロケーションの価格や SKU を適用することもできます。

<Accordion>
  <AccordionItem question="ATUM を使わずにショップを完全に分離する：WordPress Multisite">

何も共有しないショップを運営するには、[WordPress Multisite](https://developer.wordpress.org/advanced-administration/multisite/create-network/) でそれぞれを独立したサイトにします。

1. ショップごとに WordPress サイトを作成します。
2. 各サイトに WooCommerce と WCPOS をインストールします。
3. 各サイトが独自の商品、在庫、注文を保持します。

この場合、複数の WooCommerce 環境を管理することになり、注文とレポートもサイトごとに独立します。

  </AccordionItem>
</Accordion>

## 店舗ではできないこと {#known-limitations}

- **独立したショップを作る機能ではありません。** 店舗は 1 つの WooCommerce サイト内の販売拠点であり、商品、顧客、クーポンを共有します。
- **特定の店舗で商品を非表示にはできません。** すべての店舗で同じ商品カタログを扱います。ATUM を使う場合、店舗に紐づくロケーションで在庫がなくなった商品は、その店舗で在庫切れと表示されます。
- **店舗を追加しても過去の注文は移動しません。** 注文は販売した店舗に紐づいたままです。[過去の注文の扱い](./setup.mdx#edge-cases)をご覧ください。
