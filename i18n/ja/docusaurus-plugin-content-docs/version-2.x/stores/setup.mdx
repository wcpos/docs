:::info Proの機能
複数の店舗を使うには[WCPOS Pro](../getting-started/pro-license.mdx)が必要です。Proがない場合、POSはWooCommerceの設定をもとにした1つの店舗で動作します。
:::

このページでは、空の一覧から店舗を作成し、レジ係がサインインするまでの手順を説明します。店舗の用途については、まず[店舗](./index.mdx)をご覧ください。

## 始める前に {#before-you-start}

- **WCPOS Proがインストールされ、ライセンスが有効になっていること。** Proを有効にすると、WP Adminの**POS**メニューの一番上に**店舗**が表示されます。
- **レジ係がPOSにサインインできること。** POS自体へのアクセス権限は、[アクセス](../settings/wp-admin/access.mdx)で設定します。店舗側では、その対象者を絞り込むことだけができます。
- *（任意）* **ロゴファイル**（PNGまたはJPG）。

## 店舗の作成 {#create-the-store}

1. WP Adminで**POS → 店舗**を開きます。
2. **新しい店舗を追加**をクリックします。
3. 店舗の**詳細**ページが開きます。上部の**店舗名**に名前を入力します。この名前は、サインイン時の店舗選択画面とPOSに表示されます。
4. 右上の**作成**をクリックします。

以後、店舗は自動で保存されます。ページ上部に**保存中…**、続いて**保存済み**と表示されます。変更を保存している途中でページを離れようとすると、ブラウザーが確認を表示します。代わりに**保存できませんでした。** と表示された場合は、[問題が起きた場合](#goes-wrong)をご覧ください。

<Accordion>
  <AccordionItem question="店舗一覧に表示される内容">

各店舗の行には、**店舗**名、**住所**、**許可されたユーザー**（**スタッフ**ページで誰も選択していない場合は**全員**）、**レジ**の数、その店舗でPOSを開く**POSを開く**ボタンが表示されます。

**POS → 設定 → 一般**からも店舗にアクセスできます。店舗を作成すると、**店舗**セクションに各店舗の**住所**と**編集**ボタンが表示されます。**店舗を管理**を選ぶと一覧全体が開きます。

  </AccordionItem>
</Accordion>

## 店舗の各ページを設定する {#store-pages}

店舗の各ページは、左側のメニューから開きます（幅の狭い画面では**店舗メニューを表示**）。どのページも変更が自動で保存されます。新しい店舗では、次の設定を行います。

1. **詳細**で店舗の住所（**住所1**、**住所2**、**国**、続けて市区町村、都道府県、郵便番号）と、**連絡先**の情報（**ウェブアドレス**、**電話番号**、**メールアドレス**）を入力します。住所はレシートに印刷され、ロゴを追加すると一緒に印刷されます。後から店舗名を変えるには、ここで**店舗名**を変更します。
2. [レジを設定します](#registers)。
3. [店舗を利用できるスタッフを選択します](#staff)。

ほかのページでは、この店舗独自の設定を行えます。メニュー上部の**すべての店舗**で一覧に戻れます。後から店舗を開くには、**POS → 店舗**で店舗名をクリックします。

<Accordion>
  <AccordionItem question="店舗設定リファレンス：各ページで設定できる項目">

メニューには、**店舗**（詳細、営業時間、通貨と言語、税金）と**販売**（レシート、カスタマーディスプレイ、レジ、スタッフ）の2つのグループがあります。[ATUM](../extensions/atum.mdx)など、店舗設定を追加するプラグインには、3つ目のグループである**拡張機能**に専用のページが表示されます。

店舗を作成すると、一部の項目にバッジが付きます。**レジ**には開いているレジの数（**1台使用中**）、開いているレジがなければレジの総数が表示されます。**税金**には、この店舗の販売に税金が適用されない場合（WooCommerceで税金がオフ、税率が未設定、店舗に一致する税率がない場合）に**設定**と表示されます。**スタッフ**にはチェックを付けた人数が表示されます。

| ページ | 設定する内容 |
| --- | --- |
| **詳細** | レシートに印刷される**ロゴと住所**、および**連絡先**（**ウェブアドレス**、**電話番号**、**メールアドレス**）。**ロゴをアップロード**するか、サイトにロゴがあれば**サイトのロゴを使用**を選択します。 |
| **営業時間** | 曜日ごとの時間帯、**火〜金にコピー**、**備考**。レシートに印刷されます。 |
| **通貨と言語** | **通貨**と**通貨記号の位置**、**言語**（POS画面とレシート）、**タイムゾーン**（レジ締めのリマインダーとレポートの日付）。 |
| **税金** | **税額計算の基準**として、この店舗の住所、ショップの基本住所、顧客の請求先住所または配送先住所を選び、**適用される税率**を確認します。その下に**レシートに印刷する税務番号**があります。**税務番号を追加**（**種類**、**値**、**国**、任意の**ラベル**）するか、空欄にするとサイトの[店舗の税務ID](../settings/wp-admin/store-tax-ids.mdx)がレシートに印刷されます。 |
| **レシート** | **レシートのメッセージ**（**お礼の文**、**返品ポリシー**、**フッター**：プレーンテキストで、 `<strong>`、 `<em>`、 `<b>`、 `<i>`、 `<br>` および `<p>` を使用可能）、**レシートテンプレート**の一覧（**カスタマイズ**をクリックするまでは**サイトと同じ**。レジ係が印刷できるものにチェックを付けると、最初にチェックしたものが既定になります。ドラッグで順序を変更できます）、その下の**レシートのプレビュー**。詳しくは、 [店舗別のテンプレート](../receipts/customise.mdx#per-store-assignments)をご覧ください。 |
| **カスタマーディスプレイ** | 販売中に顧客向け画面に表示する**ディスプレイテンプレート**。 |
| **レジ** | 店舗のレジと現金管理のルール。[レジの設定](#registers)をご覧ください。 |
| **スタッフ** | この店舗を利用できるスタッフ。[店舗を利用できるスタッフの選択](#staff)をご覧ください。 |

税率自体は**WooCommerce → 設定 → 税**で設定します。**税金**ページでは、適用される税率を確認するだけです。

  </AccordionItem>
</Accordion>

## レジの設定 {#registers}

店舗メニューで**レジ**を開きます。レジは1つのキャッシュドロアに対応し、それぞれに釣銭準備金と現金集計があります。それぞれの関係については、[店舗・レジ・端末](./registers-and-devices.mdx)をご覧ください。

### レジ一覧 {#tills}

どの店舗にも、あらかじめ1つのレジがあります。最初に作成した店舗はサイトの既存のレジを引き継ぎ、それ以降の店舗には専用のレジが作成されます。店舗を保存すると、**レジ一覧**の表に表示されます。保存前は**レジを追加するには、先に店舗を保存してください。** と表示されます。

1. レジ係に表示するレジ名を設定するには、**⋯**メニューから**名前を変更**を選択します。
2. レジ係がこのレジを開くときに自動入力する**釣銭準備金**を入力します。変更は、次にレジを開くときに適用されます。ここで金額を設定するまでは、POSに前回の集計額が入力されます。欄に表示されている**200.00**は保存されていません。
3. キャッシュドロアを追加する場合のみ、**+ レジを追加**をクリックします。新しいレジには**レジ2**、**レジ3**などの名前が付き、後から変更できます。

<Accordion>
  <AccordionItem question="レジ一覧の表：状態と⋯メニュー">

- **レジ** — POSに表示されるレジの名前です。
- **釣銭準備金** — レジ係がこのレジで業務を始めるときに用意する現金です。
- **状態** — **開始時刻**とレジを開いた人、**集計中**と集計担当者、または**締め済み**と前回の締め記録の番号・日付が表示されます。
- **⋯** — **名前を変更**、別の店舗への**移動先**の指定、**使用を終了**を選べます。セッションが開いているレジは使用を終了できません。先にセッションを締めてください。レジは同時に1つの店舗だけに所属します。

</AccordionItem>
</Accordion>

### キャッシュドロアのルール {#cash-drawer-rules}

この店舗のレジ係がレジ開けとレジ締めの際に現金を数える必要があり、**毎日レジの開閉を行う**がオフの場合は、次の手順で設定します。

1. **カスタマイズ**をクリックします。
2. **毎日レジの開閉を行う**をオンにします。

これは多くの店舗で必要なルールです。レジ係は釣銭準備金を用意して業務を始め、終了時にドロア内の現金を数えます。オフの場合、POSは直接カートを表示します。

これらのルールには、最初は**POS → 設定 → 一般**の[レジ](../settings/wp-admin/registers.mdx#one-register)で設定した**サイトの既定値**が使われます。**カスタマイズ**を選ぶと、この店舗だけの設定に変更できます。

<Accordion>
  <AccordionItem question="任意のキャッシュドロアのルール：マネージャーの承認、レジ締めのリマインダー、サイトのルールに戻す">

毎日レジの開閉を行う場合は、さらに2つのルールを有効にできます。

- **集計の差額が次の金額を超えたらマネージャーに確認**に金額を設定します（初めてオンにしたときは**5.00**）。差額がこの金額を超える場合、レジを締める前にマネージャーの承認が必要です。
- **レジ係にレジ締めを通知する時刻**を設定します（初めてオンにしたときは**17:30**）。その時刻を過ぎると、レジに**締め時刻超過**と表示され、カートが空のときは**チェックアウト**ボタンが**レジを締める**に変わります。

サイトの設定に従っている間は、各ルールに**サイトの既定値**と表示されます。変更後は、**サイトの既定値を使用**でそのルールだけを戻し、**サイトの既定値にリセット**で3つすべてを戻せます。

</AccordionItem>
</Accordion>

### レポートとレジ締め {#reports-and-closures}

**締め記録の印刷**と**売上レポート**では、レジを締めたときや売上レポートを作成したときに印刷する内容を選択します。どちらも**カスタマイズ**をクリックするまでは**サイトと同じ**になっています。**サイトのテンプレートを使用**で元に戻せます。

## 店舗を利用できるスタッフの選択 {#staff}

店舗メニューで**スタッフ**を開きます。

- **POSへのアクセス権がある全員** — 既定の設定です。店舗が1つの場合に適しています。
- **選択した人のみ** — この店舗にサインインできる人にチェックを付けます。一覧には、役割によって権限を持つ人も個別に権限を付与された人も含め、POSへのアクセス権がある全員が表示されます。10人を超える場合は、**ユーザーを検索**で一覧を絞り込めます。

:::warning 最後の1人のチェックを外すと、全員が店舗を利用できるようになります
最後の1人のチェックを外すと、店舗の設定が**POSへのアクセス権がある全員**に切り替わり、その旨のお知らせが表示されます。誰かを対象から外すときは、ほかの人に少なくとも1人はチェックが残っていることを確認してください。
:::

複数の店舗で働くレジ係には、それぞれの店舗でチェックを付けます。

## レジ係に表示される画面 {#what-cashiers-see-at-login}

新しい店舗を確認するには、その店舗のレジ係のWordPressアカウントでPOSにサインインします。サインイン後の選択肢は端末によって異なります。

**サインイン時に新しい店舗が表示される場合：**

1. **店舗を選択**で新しい店舗を選びます。利用できる店舗がその店舗だけの場合は、**店舗**の下ですでに選択されています。
2. **POSを開く**を押します。

**サインイン時に利用可能な別の店舗しか表示されない場合**（端末がすでにその店舗で使われている場合）：

1. その店舗でPOSを開きます。
2. アバターをタップしてレジ係パネルを開き、**店舗を切り替え**で新しい店舗を選びます。[店舗とレジの選択](./registers-and-devices.mdx#choosing-a-store-and-a-register)をご覧ください。

どちらの場合も、カート上部のレジバーに新しい店舗名が表示されていることを確認します。

新しい端末では、**店舗を選択**にレジ係が利用できるすべての店舗が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="レジ係がサインインした画面。「店舗を選択」に番号付きで2つの店舗が表示され、1つが選択されている状態と「POSを開く」ボタン">

1. **利用できる店舗** — ここでは選択済みです。名前の後の番号は、WP Adminでの店舗IDです。
2. **別の店舗** — このレジ係が利用できるもう1つの店舗で、切り替えて選択できます。
3. **POSを開く** — 店舗を選択すると有効になります。店舗が1つだけの場合はすでに選択済みで、見出しは**店舗**になります。

</JourneyShot>

レジ係が利用できる店舗がない場合は、**このユーザーが利用できる店舗はありません**と表示されます。店舗の**スタッフ**ページでその人にチェックを付けるか、**POSへのアクセス権がある全員**に設定してください。

店舗にレジが複数ある場合、レジバーにはレジ名も表示されます。レジで対応が必要なときは、その横に状態が表示されます。バーの画面例は、[レジを開く](../pos/register/index.mdx#open)で確認できます。

<Accordion>
  <AccordionItem question="レジの状態：締め済み、集計中、承認が必要、締め時刻超過">

各状態は、店舗の[キャッシュドロアのルール](#cash-drawer-rules)に従って表示されます。

| 状態 | 表示されるタイミング |
| --- | --- |
| **締め済み** | レジが開いていません。現金欄には、レジの**釣銭準備金**が設定されていればその金額、未設定なら前回の集計額が入力されます。 |
| **集計中** | 誰かがレジを締めるためにドロア内の現金を数えています。 |
| **承認が必要** | 集計の差額が設定した上限を超えているため、マネージャーの承認が必要です。 |
| **締め時刻超過** | 設定した締め時刻を過ぎてもレジが開いています。 |

開いているレジで対応が不要な場合、状態は表示されません。

  </AccordionItem>
</Accordion>

各販売は、会計を行った店舗に紐付けて記録されます。

## 店舗別の価格と税金 {#per-store-pricing}

Proでは、在庫を共有しながら、特定の店舗だけで商品に独自の価格や税金を設定できます。店舗で必要な場合にだけ設定してください。

<Accordion>
  <AccordionItem question="任意：この店舗で異なる価格や税金を設定する">

1. **WP Admin → 商品**で商品を開きます。
2. **一般**タブで、その店舗の **「*店舗名*」専用の価格を有効にする。** にチェックを付けます。
3. **通常価格**と、必要に応じて**セール価格**を入力します。
4. 商品を更新します。

その店舗のレジ係には設定した価格が適用され、ほかの店舗では通常のWooCommerce価格が使われます。税制が異なる地域の店舗では、**「*店舗名*」専用の税金を有効にする。** で、同じように**課税状況**と**税区分**を設定できます。バリエーション商品の場合、これらのチェックボックスは**バリエーション**内の各バリエーションにあります。バリエーションの税金のチェックボックスでは、**税区分**だけを設定します。

:::tip 拠点ごとの在庫
店舗別の価格を設定しても、在庫数は共通です。拠点ごとに在庫を管理する場合は、[ATUM Multi-Inventory](../extensions/atum.mdx)をご覧ください。ATUMを使用していて、店舗の**価格の取得元**が**ATUM**の場合、その商品にATUMの価格があれば、代わりに拠点の価格を使用します。[価格の取得元を選択する](../extensions/atum.mdx#pricing-source)をご覧ください。
:::

</AccordionItem>
</Accordion>

## 問題が起きた場合 {#goes-wrong}

**保存できませんでした。** というメッセージが理由とともにページ上部に表示された場合、サイトに変更が保存されていません。メッセージの**再試行**を押すか、ページを再読み込みして内容を確認してください。

**レジを追加するには、先に店舗を保存してください。** まず**作成**をクリックしてください。店舗が作成されると、**レジ一覧**の表が表示されます。

**レジの使用を終了できない。** 開いているか集計中のセッションがあります。POSで現金を集計してレジを締めてから、**使用を終了**を選択してください。

サインイン時に**このユーザーが利用できる店舗はありません**と表示される場合、レジ係がどの店舗の**スタッフ**一覧にも登録されていません。その人にチェックを付けるか、店舗を**POSへのアクセス権がある全員**に設定してください。

**店舗メニューがない。** Proが有効になっていません。**POS → 設定 → ライセンス**でライセンスを確認してください。[WCPOS Proのインストール](../getting-started/pro-license.mdx)をご覧ください。

## 特殊なケース {#edge-cases}

<Accordion>
  <AccordionItem question="店舗を追加すると、過去の注文はどうなりますか？">

変わりません。販売は会計時に店舗に紐付けて記録されるため、新しい店舗が過去の注文を引き継ぐことはありません。個別の注文を別の店舗に移すには、**WooCommerce → 注文**で注文を開き、**POS店舗**を変更します。

  </AccordionItem>

  <AccordionItem question="店舗を削除するにはどうすればよいですか？">

店舗の各ページの右上にある**店舗をゴミ箱へ移動**（実行前に確認が表示されます）、または一覧の**ゴミ箱へ移動**を選びます。ゴミ箱に移動した店舗は店舗選択画面から消えますが、注文には引き続き店舗の名前、住所、ロゴが表示されます。**復元**すると設定とともに元に戻ります。

ゴミ箱の**完全に削除**で店舗を永久に削除できます。ただし、その店舗のレジが1つでも開いているか集計中の場合は削除できません。削除後、注文には**店舗 #** と店舗IDが表示されます。

  </AccordionItem>

  <AccordionItem question="店舗ごとに異なる通貨を使えますか？">

はい。**通貨と言語**で設定できます。その店舗の価格、合計、レシートに設定した通貨が使われます。これは金額の表示方法を変えるもので、金額自体は変わりません。支払い方法がその通貨に対応している必要があり、為替レートはご自身で管理してください。

  </AccordionItem>

  <AccordionItem question="Proを無効にするとどうなりますか？">

サイトはレジが1つの状態に戻ります。[Proを無効にした場合](../settings/wp-admin/registers.mdx#if-pro-is-deactivated)をご覧ください。

  </AccordionItem>
