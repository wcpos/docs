レジのセッションは、釣銭準備金を数えてドロワーに入れた時点から、最後に現金を数える時点まで続きます。このページでは、釣銭準備金を入れてレジを開ける手順、ドロワーの金額、現金の入出金など、一日の開始から営業中の操作までを説明します。一日の終わりの集計とレジ締めは、[レジを締める](../reconciliation.mdx)を参照してください。

:::note このページの操作にはレジ機能の有効化が必要です
ここで説明する操作には、**レジの開閉**を有効にする必要があります。無効の場合、POS は直接カートを表示し、レジ開けや集計はありません。設定については[レジ](../../settings/wp-admin/registers.mdx#one-register)を参照してください。WCPOS Pro で店舗を使用している場合、店舗ごとに設定できます。[店舗の設定](../../stores/setup.mdx)を参照してください。
:::

## レジを開ける {#open}

レジが締め済みの間は、レジバーに**締め済み**、商品欄に**レジを開けるまでは価格の確認のみ可能です。** と表示されます。商品の検索と価格の確認はできますが、カートには追加できません。カート欄には代わりに**レジを開ける**カードが表示されます。

- **ドロワー内の現金** — レジが提案する釣銭準備金が大きく表示されます。[レジ](../../settings/wp-admin/registers.mdx#one-register)の**開始時の釣銭準備金**が使われ、未設定の場合は前回の集計額が使われます。
- **既定の釣銭準備金**と**前回の集計額** — どちらかをタップすると、その金額に戻せます。予定額を見ずに集計するレジ係には、前回の集計額は表示されません。
- **テンキー** — ドロワーの現金を数えて入力します。最初に押したキーで提案額が置き換わるので、先に消す必要はありません。**⌫** で末尾の一桁を削除できます。
- **開始時の差額** — 入力額が提案された釣銭準備金と異なる場合に表示されます。実際に数えた釣銭準備金と一緒に、セッションに保存されます。
- **レジを開ける** — セッションを開始します。開始時の釣銭準備金を確認するメッセージが表示されます。
- **前回の締め記録** — 前回の締め番号と集計額です。

他のデバイスですでにレジが開いている場合、釣銭準備金の入力は求められず、このデバイスもそのセッションに参加します。[店舗、レジ、デバイス](../../stores/registers-and-devices.mdx#several-devices-on-one-register)を参照してください。

## レジ係シート {#cashier-sheet}

レジバーの端にあるアバターをタップします。ここでドロワーを確認したり、他の担当者に引き継いだりできます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[325, -31], [140, 0], [147, -17], [-57, 0], [-57, 0], [112, 0]]} alt="レジ係シート：ドロワーの金額、本日の自分の売上、レジを引き継ぐ、レジを切り替える、店舗を切り替える、サインアウト">

1. **ドロワー内の現金** — レジが算出した現在の予定現金額です。タップすると[レジパネル](#cash-movements)が開きます。*レポートの閲覧*権限がない場合は予定額を見ずに集計するため、ここには金額の代わりに売上件数が表示されます。[アクセス](../../settings/wp-admin/access.mdx)を参照してください。
2. **本日の自分の売上** — 自分が処理した売上です。
3. **レジを引き継ぐ** — 別のレジ係に引き継ぎます。レジは営業中のまま、POS が引き継ぎ先のユーザーとして再読み込みされます。未完了のカートは担当のレジ係のために残ります。
4. **レジを切り替える** — 複数のレジがある場合にのみ表示されます。先に現在の販売を完了するか、保留にしてください。[店舗とレジを選ぶ](../../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)を参照してください。
5. **店舗を切り替える** — 複数の店舗がある場合にのみ表示されます（WCPOS Pro）。
6. **サインアウト** — レジを開けたままにすると、次のレジ係もその状態で使えます。POS は先にレジを締めるかどうかを確認します。

</JourneyShot>

## 現金を出し入れする {#cash-movements}

レジ係シートの**ドロワー内の現金**をタップして、レジパネルを開きます。先頭に、ドロワーにあるはずの現金が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[250, 0], [250, 0], [0, 0], [0, 0], [0, 0], [190, 0], [275, 0], [0, -34], [0, -34]]} alt="レジパネル：先頭にドロワー内の現金、セッション売上、入金、出金、空開け、折りたたまれたドロワー内の予定額、その他の支払い方法、前回の締め記録、X レポートを印刷、レジを締める">

1. **ドロワー内の現金** — レジが算出した予定現金額で、販売や入出金のたびに更新されます。予定額を見ずに集計するレジ係には表示されません。
2. **セッション売上** — レジを開けてからの売上の合計と件数です。
3. **入金** — ドロワーに現金を入れます。
4. **出金** — ドロワーから現金を取り出します。
5. **空開け** — 現金を出し入れせずにドロワーを開けます。
6. **ドロワー内の予定額** — タップすると、釣銭準備金、現金売上、現金での払い戻し、すべての入出金という計算内訳が展開されます。その下の**その他の支払い方法**を開くと、カードなどの支払い方法の内訳が表示されます。
7. **前回の締め記録** — このセッションの前の締め記録で、番号、集計額、**一致**、**不足**、**超過**のいずれかの結果が表示されます。
8. **X レポートを印刷** — レジを締めずに、セッションの現時点までのレポートを出力します。
9. **レジを締める** — 集計を開始します。[レジを締める](../reconciliation.mdx#count)を参照してください。

</JourneyShot>

### 入金する {#pay-in}

**入金**を押します。パネルに *ドロアーにいくら入れますか？* と表示されます。金額を入力してから、理由を指定してください。現金の出し入れには毎回理由が必要です。理由をタップするか、**その他…** をタップして自分で入力してください。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[392, 0], [100, 0], [0, 0], [0, 0], [0, 0], [150, 0], [0, -34]]} alt="入金シート：現在と入金後のドロワー内の現金、金額、テンキー、グリッド状の理由、入力した理由、入金するボタン">

1. **ドロワー内の現金と処理後の金額** — 現在のドロワー内の現金と、この入出金後の現金です。
2. **金額** — 入力した金額です。
3. **テンキー** — 金額を入力します。
4. **理由の選択肢** — **釣銭準備金**、**両替**、**銀行**です。タップすると理由が入力され、もう一度タップすると消去されます。
5. **その他…** — 理由を消去して、自由に入力できるようにします。
6. **理由** — 入出金と一緒に保存される理由です。ここに直接入力するか、選択肢から入力された文言を編集できます。
7. **…を入金** — 入金を記録します。金額と理由が揃うまでは、不足している項目がシートに表示されます。

</JourneyShot>

### 出金する {#pay-out}

納品時の仕入先への支払い、小口現金、銀行への預け入れ、チップなど、ドロワーから現金を取り出すときは**出金**を押します。シートに*ドロワーからいくら取り出しますか？*と表示され、入金と同じように操作できます。スマートフォンでは理由が二列で表示されます。

<JourneyShot manifest={manifest} device="phone" step={6} maxWidth={390} offsets={[[330, 8], [60, 0], [0, 0], [0, 0], [0, 0], [150, 0], [0, 0]]} alt="スマートフォンの出金シート：現在と出金後のドロワー内の現金、金額、テンキー、二列の理由、入力した理由、出金するボタン">

1. **ドロワー内の現金と処理後の金額** — 現在と出金後のドロワー内の現金です。
2. **金額** — 入力した金額です。
3. **テンキー** — 金額を入力します。
4. **理由の選択肢** — **仕入先**、**小口現金**、**銀行**、**チップ**、**両替**です。
5. **その他…** — 理由を自由に入力します。
6. **理由** — 入出金と一緒に保存される理由です。
7. **…を出金** — 出金を記録します。

</JourneyShot>

**空開け**は、現金を出し入れせずにドロアーを開きます。この場合も *ドロアーを開ける理由は？* と聞かれるので、**両替**、**操作ミス**、**ドロアーの確認**、**その他…** のいずれかをタップし、**ドロアーを開ける**を押してください。

### 入出金を確認する {#movements}

入出金ごとに、**$1.00 を入金しました**などの確認メッセージと**元に戻す**が表示されます。セッション内のすべての入出金を見るには、**ドロワー内の予定額**をタップします。

<JourneyShot manifest={manifest} device="tablet" step={8} offsets={[[250, 0], [200, 0], [150, -42], [150, -56], [0, 26], [0, -34]]} alt="ドロワー内の予定額を展開したレジパネル：釣銭準備金、現金売上と払い戻し、理由と取消を伴う入金と出金の行、レジを締める">

1. **ドロワー内の現金** — 入出金はすでに反映されています。
2. **釣銭準備金** — セッション開始時の金額と日時です。この金額を起点に、現金売上を加え、現金での払い戻しを差し引きます。
3. **入金** — 件数、合計、理由付きの各入金です。
4. **出金** — 取り出した現金について、入金と同じ内容を表示します。
5. **取消** — その入出金を取り消します。レジが営業中の場合にのみ使えます。
6. **レジを締める** — 一日の終わりに使います。[レジを締める](../reconciliation.mdx#count)を参照してください。

</JourneyShot>

## 集計して締める {#close}

一日の終わりに、パネルの**レジを締める**を押し、ドロワーの現金を数えて締め記録を保存します。集計、締め記録、現金が合わない場合の対処については、[レジを締める](../reconciliation.mdx#count)を参照してください。

## 問題が発生した場合 {#goes-wrong}

**入出金を間違えて入力しました。** 表示されたメッセージの**元に戻す**を押すか、**ドロワー内の予定額**の該当行で**取消**を押してください。どちらもパネルからその入出金が消え、ドロワーの金額が元に戻ります。取り消した入出金は復元できないため、再度入力してください。取消はレジが営業中の場合にのみ使え、集計中には使えません。

**ボタンに「金額を入力」または「理由を追加」と表示されます。** 入出金の入力が完了していません。金額を入力し、理由をタップするか入力してください。

**パネルに「金額は次回の同期で反映されます」と表示されます。** レジは店舗からの金額データを待っています。届くまで**レジを締める**は無効のままです。ページを開いたまま、接続を確認してください。

**入出金が拒否されました。** パネル上部の通知に、店舗で拒否された件数が表示されます。その通知の**再試行**を押してください。

**他の端末でレジが締められました。** レジを開けるカードに、締めた担当者と日時が表示されます。ドロワーの現金を数え、レジを開け直してください。

**他の担当者が集計中です。** 「他の端末で集計中」に、集計を始めた担当者と日時が表示されます。完了するまでお待ちください。

**「この店舗にレジがありません」または「この店舗のレジに接続できません」。** POS で開けるレジがありません。接続を確認し、**もう一度試す**を押してください。実際に店舗にレジがない場合は、マネージャーが追加します。[店舗、レジ、デバイス](../../stores/registers-and-devices.mdx#where-the-settings-live)を参照してください。

**レジ締め時に集計額が合いません。** [レジを締める](../reconciliation.mdx#goes-wrong)を参照してください。

:::info WCPOS Pro をお使いの場合
Pro では、店舗ごとのレジを増やせるほか、レポートですべての締め履歴を閲覧できます。[Pro でレジを増やす](../../settings/wp-admin/registers.mdx#more-registers-with-pro)を参照してください。
:::
