表示設定では、商品パネルの見た目と最初に表示する内容を指定します。検索欄の横にある **設定** を押すと、**商品設定** が開きます。変更はその都度、この端末だけに保存されるため、レジごとに設定を変えられます。パネルの使い方は、[商品を探す](index.mdx#find)から確認してください。

ここでできること：

- [タイル表示と行表示を切り替える](#view-mode)
- [パネルに最初に表示する内容を選ぶ](#browse-by)
- [在庫切れの商品を表示または非表示にする](#show-out-of-stock-products)
- [商品の表示順を変える](#sort)
- [選択肢のある商品の開き方を選ぶ](#variations)
- [各商品に表示する項目を選ぶ](#fields)
- [フィルターバーと独自のフィルターボタンを設定する](#filter-bar)
- [新しい端末の初期設定に戻す](#restore-default-settings)

## パネルの見た目を変える {#display-settings}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[59, 0], [309, 60], [218, 0], [238, 41], [-115, 0], [105, -39], [0, 0], [199, 0], [-29, 0]]} maxWidth={512} alt="商品設定。表示モード、タイルサイズ、各選択肢に件数が付いた閲覧方法、在庫切れの商品を表示、並べ替え基準、並べ替え方向、バリエーションがあり、下部にデフォルト設定に戻すと閉じるがあります">

1. **表示モード** — **グリッド** は画像付きのタイルで、**テーブル** は行で表示します。[グリッドまたはテーブル](#view-mode)を参照してください。
2. **タイルサイズ** — パネルの横一列に並べるタイル数を 2 から 8 の範囲で指定します。**グリッド** でのみ使用できます。
3. **閲覧方法** — パネルに最初に表示する内容です。[閲覧方法](#browse-by)を参照してください。
4. **在庫切れの商品を表示** — オフにすると、在庫切れの商品を非表示にします。[在庫切れの商品](#show-out-of-stock-products)を参照してください。
5. **並べ替え基準** — 商品の表示順です。[並べ替え](#sort)を参照してください。
6. **並べ替え方向** — **昇順** または **降順** です。
7. **バリエーション** — 選択肢のある商品の開き方です。[バリエーション](#variations)を参照してください。
8. **デフォルト設定に戻す** — ここにあるすべての設定を、確認なしで一度に新しい端末の初期設定に戻します。この端末のクイックフィルターも削除されます。[初期設定に戻す](#restore-default-settings)を参照してください。
9. **閉じる** — 設定を閉じます。変更はすでに保存されています。

</JourneyShot>

下にスクロールすると、[タイルの項目](#tile-fields)または[列](#columns)、[メタデータキー](#meta-data-keys)、[フィルターバー](#filter-bar)があります。

### グリッドまたはテーブル {#view-mode}

**グリッド** は、各商品の画像、名前、価格をタイルに表示します。タイルをタップすると、カートに 1 点追加されます。選択肢のある商品には **… 個の選択肢** と表示され、追加する代わりに[バリエーション](variations.mdx)が開きます。**テーブル** は同じ商品を行で表示し、各行の末尾にある **+** で追加できます。

新しい端末では、横に 4 枚のタイルを並べた **グリッド** で表示されます。検索欄の横にあるグリッドまたはテーブルのボタンで、設定を開かずに切り替えられます。

商品をカートに入れると、タイルの隅にある小さな丸に数量が表示されます。行表示では **+** の代わりに数量が表示され、タップするとさらに 1 点追加されます。

### 閲覧方法 {#browse-by}

パネルに最初に表示する内容：

| 選択肢 | パネルに最初に表示する内容 |
|--------|--------------------|
| **すべての商品** | [並べ替え順](#sort)に従ったすべての商品 |
| **カテゴリー** | 最上位のカテゴリーごとのタイル。新しい端末の初期設定です |
| **タグ** | タグごとのタイル |
| **ブランド** | ブランドごとのタイル |
| **ショートカット** | [クイックフィルター](#quick-filters)ごとのタイル |

各選択肢には、**6 カテゴリー** のように件数が表示されます。項目がない選択肢は淡色表示になり、**ブランドはまだありません** のように表示されます。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-22, 0], [-30, 0], [0, 0], [0, 0], [282, 297]]} alt="カテゴリーで用品の中を閲覧している画面。カテゴリー › 用品のパンくずリスト、戻る矢印の付いた用品のタイル、商品数付きの各サブカテゴリーのタイル、用品自体の商品、グリッド下部の件数が表示されています">

1. **カテゴリー** — パンくずリストです。戻りたい階層をタップすると、その階層に戻れます。
2. **戻る矢印** — 現在のカテゴリーのタイルに表示されます。タイルをタップすると、1 つ上の階層に戻ります。
3. **サブカテゴリー** — 含まれる商品数が表示されます。タップすると中に入れます。
4. **商品** — パネル内のほかの場所と同様に、タップするとカートに追加されます。
5. **3 カテゴリー · 43 件中 20 件を表示** — この階層のサブカテゴリー数と、画面に表示されている商品数です。

</JourneyShot>

タイルをタップすると中に入れます。カテゴリーには、WooCommerce の設定に従ってサブカテゴリー、商品、またはその両方が表示されます。最上位では、**すべての商品** のタイルが先頭に表示されます。検索した場合や、閲覧方法と同じ項目で絞り込んだ場合は、タイルの代わりに一致する商品が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[0, 0], [259, 0]]} alt="2 階層下の時計の中。カテゴリー › 用品 › 時計のパンくずリスト、戻る矢印の付いた時計のタイル、9 点の時計が表示されています">

1. **商品** — 時計にはサブカテゴリーがないため、商品のみ表示されます。
2. **時計** — 現在の階層です。**用品** または **カテゴリー** をタップすると、上の階層に戻れます。

</JourneyShot>

1 つ上の階層に戻るには、パンくずリストをタップするか、キーボードの **Escape** を押すか、タッチスクリーンの左端から内側にスワイプするか、Android の戻るボタンを使います。スマートフォンでは、パンくずリストに戻る矢印と 1 つ上の階層のみが表示されます。

**テーブル** では同じ階層が行として表示され、それぞれに件数と矢印が付きます。

### 在庫切れの商品 {#show-out-of-stock-products}

新しい端末では、**在庫切れの商品を表示** はオフです。オフの場合、在庫切れの商品は非表示になり、スキャンしても追加されません。オンの場合は一覧に残り、淡色表示で **売り切れ** と表示され、**在庫あり** フィルターはオフの状態で開始します。

店舗で[在庫数を超える販売を防止](../../settings/wp-admin/checkout.mdx#prevent-overselling)をオンにしている場合、POS は商品を追加するときにも在庫を確認します。

- **… は在庫切れです** または **… の在庫は … のみです** — 商品は追加されません。
- **… の在庫はこの端末にまだ読み込まれていません** — 商品の在庫情報をダウンロード中です。少し待ってから再試行してください。
- **… はお取り寄せになります** — 商品は追加されます。この商品は、お取り寄せを許可して顧客に通知する設定になっています。

### 並べ替え {#sort}

**並べ替え基準** で、**名前**、**SKU**、**バーコード**、**種類**、**価格**、**作成日**、**更新日**、**人気順**、**在庫数**、**在庫状況**、**メニュー順** のいずれかを選びます。**人気順** は累計販売数に基づき、**降順** では売れ筋商品から表示されます。**メニュー順** は、WooCommerce で各商品に設定した順序です。新しい端末では、**名前** の **昇順** で並びます。

**テーブル** では、列見出しをタップしてその列で並べ替えることもできます。その場合、ここの **並べ替え基準** も変わります。

### バリエーション {#variations}

選択肢のある商品の開き方を指定します。新しい端末の初期設定である **その場で開く** では、パネル内に選択肢ごとのタイルが表示されます。もう一方の選択肢は、**グリッド** では **ポップオーバー**、**テーブル** では **行を展開** です。[バリエーションのある商品](variations.mdx)を参照してください。

## 各商品に表示する項目を選ぶ {#fields}

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-302, -288], [-212, 39], [0, 0]]} maxWidth={512} alt="商品設定を下にスクロールした画面。タイルの項目のスイッチ、メタデータキー、フィルターバーをカスタマイズボタンのあるフィルターバーセクションが表示されています">

1. **タイルの項目** — 各タイルに表示する内容です。[タイルの項目](#tile-fields)を参照してください。
2. **メタデータキー** — カートにコピーする商品のカスタムフィールドです。[メタデータキー](#meta-data-keys)を参照してください。
3. **フィルターバーをカスタマイズ** — バーに表示するフィルターを選び、独自のフィルターを作成します。[フィルターバー](#filter-bar)を参照してください。

</JourneyShot>

### タイルの項目 {#tile-fields}

**グリッド** では、タイルに表示する **商品名**、**価格**、**税**、**セール中**、**カテゴリー**、**SKU**、**バーコード**、**在庫**、**売上原価** をオンにします。新しい端末では名前と価格が表示されます。**セール中** をオンにすると、セール価格とともに通常価格が取り消し線付きで表示されます。**在庫** をオンにすると、タイルに残りの数量が表示されます。

### 列 {#columns}

**テーブル** では、同じ場所に **列** が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 0], [5, 92], [139, 70], [159, 150]]} maxWidth={512} alt="テーブル表示の商品設定で列までスクロールした画面。各列にドラッグハンドルとスイッチがあり、商品名の下に表示オプションがあります">

1. **行を展開** — **テーブル** で **バリエーション** の 2 番目の選択肢を選ぶと、商品の下に選択肢が行として開きます。
2. **ドラッグハンドル** — 列を上下にドラッグすると、テーブル内の左右の位置が変わります。
3. **列のスイッチ** — 列の表示をオンまたはオフにします。
4. **表示オプション** — **在庫** や **カテゴリー** など、商品名の下に表示する詳細情報です。

</JourneyShot>

新しい端末では画像、商品名、価格、アクションが表示され、名前の下に **在庫** と **カテゴリー**、価格の下に **セール中** が表示されます。**商品名** の下には、SKU、バーコード、タグ、ブランド、属性、メタデータも表示できます。**価格** の下には税も表示できます。

| **画像** | 商品の画像 |

| **SKU** | 独立した列に表示される SKU |

| **売上原価** | 商品の仕入れにかかる費用 |

| **アクション** | 商品をカートに追加する **+** |

### メタデータキー {#meta-data-keys}

カートの明細行にコピーし、注文にも引き継ぐ商品のカスタムフィールドを指定します。[メタデータキー](meta-data-keys.mdx)を参照してください。

## フィルターバーを設定する {#filter-bar}

**フィルターバーをカスタマイズ** を押して、商品の上にあるバーに表示する項目を選びます。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-24, 0], [-42, 0], [160, 0], [-29, 0]]} maxWidth={512} alt="フィルターバーの設定。各フィルターの横にドラッグハンドルとスイッチがあり、クイックフィルターを追加ボタンが表示されています">

1. **ドラッグハンドル** — フィルターを上下にドラッグすると、バー上の位置が変わります。
2. **スイッチ** — フィルターをオフにするとバーから非表示になります。オンにすると再び表示されます。
3. **クイックフィルターを追加** — 独自のボタンを作成します。[独自のフィルターボタン](#quick-filters)を参照してください。
4. **閉じる** — 変更はすでに保存されています。

</JourneyShot>

新しい端末では、バーに **在庫状況**、**おすすめ**、**セール中**、**カテゴリー**、**タグ**、**ブランド** の順に表示されます。設定を開かずに非表示にするには、バー上の項目を長押しし（マウスでは右クリック）、**バーから非表示** を選びます。

## 独自のフィルターボタン {#quick-filters}

クイックフィルターは、**靴** カテゴリーの **セール中** の商品を価格順に並べるなど、複数の条件を一度に適用するボタンです。画面に表示中の条件を使うか、最初から作成できます。パネルを開いたときにクイックフィルターを最初に表示するには、[閲覧方法](#browse-by)を **ショートカット** に設定します。

- [表示中の条件を保存する](#save-as-button)
- [最初から作成する](#add-quick-filter)
- [クイックフィルターを変更する](#edit-quick-filter)
- [クイックフィルターを削除する](#delete-quick-filter)

### 表示中の条件を保存する {#save-as-button}

バーで必要なフィルターを設定し、バーの末尾にあるブックマークの **ボタンとして保存** を押します。このボタンはフィルターをオンにすると表示されます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[438, 0], [139, 0], [39, -40]]} maxWidth={512} alt="ボタンとして保存の画面。ボタン名の入力欄、ボタンのプレビュー、保持する各条件の横にチェックが表示されています">

1. **ボタン名** — バー上のボタンに表示する名前です。
2. **現在の表示条件を保持** — 保持する条件にチェックを入れます。カテゴリー内にいる場合は、そのカテゴリーとサブカテゴリーも条件に含まれます。検索には、自分でチェックを入れない限りチェックは付きません。
3. **バーに追加** — ボタンをバーに追加します。

</JourneyShot>

チェック項目の下には、この端末で一致する商品数が表示されます。**キャンセル** を押すと、何も追加せずに閉じます。

### 最初から作成する {#add-quick-filter}

例として、セール中の靴を表示するボタンを作成します。

1. **フィルターバーをカスタマイズ** で、**クイックフィルターを追加** を押します。
2. **カテゴリー内のセール商品** を選びます。ほかに **カテゴリー**、**指定価格未満**、**売れ筋**、**新着商品**、**在庫僅少**、**タグ** を出発点にできます。何も選ばずに始めるには、**最初から作成** を押します。
3. **ボタン名** に「セールの靴」などの名前を入力します。
4. **表示する商品の条件…** では、**セール中** がすでに設定されています。**カテゴリー内** に **選択…** と表示されているので、タップして **靴** を選びます。
5. **続いて** の **並べ替え** を押し、**価格の安い順** を選びます。変更しなければ、**グリッドの通常の順序** のままになります。
6. **バーに追加** を押します。ボタンに名前を付け、すべての条件を選ぶまで、このボタンは淡色表示のままです。

手順 3 と 4 を終え、カテゴリーを選ぶ前の画面：

<JourneyShot manifest={manifest} device="tablet" step={9} offsets={[[120, 0], [130, 0]]} maxWidth={512} alt="新しいクイックフィルター。ボタン名にセールの靴と入力され、バーのプレビューにも表示されています。カテゴリー内は選択…の状態で、セール中ははいに設定され、バーに追加は淡色表示になっています">

1. **ボタン名** — ボタンに表示する名前です。**バー上の表示** で見た目を確認できます。
2. **カテゴリー内** — 選ぶまでは **選択…** と表示されます。その下の **セール中** はすでに **はい** になっています。**続いて** と **並べ替え** はさらに下にあります。

</JourneyShot>

### クイックフィルターを変更する {#edit-quick-filter}

クイックフィルターを変更するには、バー上で長押しして **編集** を選ぶか、**フィルターバーをカスタマイズ** でそのフィルターをタップします。変更はその都度保存されます。

### クイックフィルターを削除する {#delete-quick-filter}

バー上で長押しして **バーから削除** を選ぶか、**フィルターバーをカスタマイズ** で開いて下部の **バーから削除** を押します。**削除** で確定します。クイックフィルターはオフにして保持することはできず、バーから削除するとフィルター自体が削除されます。

## 初期設定に戻す {#restore-default-settings}

**商品設定** の下部にある **デフォルト設定に戻す** は、ここのすべての設定を新しい端末の初期設定に戻します。横に 4 枚のタイルを並べた **グリッド**、**カテゴリー**、**名前** 順の並べ替え、バー上の 6 つの標準フィルターに戻ります。事前の確認はありません。

:::warning
デフォルト設定に戻すと、この端末のクイックフィルターも削除されます。クイックフィルターはフィルターバーの一部であるためです。
:::

## パネルのフッター {#footer}

- **… 件中 … 件を表示** — この端末にある条件に一致する商品のうち、画面に表示されている件数です。
- **課税基準** — **店舗の所在地** などが表示されます。店舗で税を計算する場合に表示され、タップすると適用中の税率を確認できます。
- **同期ボタン** — 店舗から商品情報を更新します。長押しすると、同じ更新を行う **同期** と、この端末の商品データを消去して再ダウンロードする **消去して更新** の 2 つが表示されます。
