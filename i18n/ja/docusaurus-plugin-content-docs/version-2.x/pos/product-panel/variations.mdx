バリエーション商品とは、5 種類のサイズと 3 色から選べるパーカーのように、複数のオプションがある商品です。各オプションにはそれぞれ価格、在庫、バーコードがあり、カートには選んだオプションが追加されます。WooCommerce では、このオプションをバリエーションと呼びます。

## バリエーション商品の見分け方 {#identifying-variable-products}

- **グリッド表示の場合** — タイルに最低価格とオプション数が表示されます。例：**$60.00 から**、**15 個のオプション**。表示方法が**ポップオーバー**の場合は、代わりに**バリエーション**バッジと価格帯が表示されます。
- **テーブル表示の場合** — 行にオプション数が表示されます。表示方法が**行を展開**の場合は、商品名の下にオプションが表示されます。

## オプションを選ぶ {#adding-variable-products-to-cart}

バリエーション商品をタップし、開いた画面に応じて該当する説明を参照してください。

| 開く画面 | 参照先 |
| --- | --- |
| 商品パネル全体にオプションが表示される | [その場で開く](#open-in-place) |
| 商品の横にボックスが表示される、またはスマートフォンの画面下部にシートが表示される | [ポップオーバー](#method-1-quick-popover)（**グリッド**の場合） |
| 商品の下にオプションが行として表示される | [行を展開](#method-2-expand-inline)（**テーブル**の場合） |

新しい端末では、その場で開く設定になっています。切り替えるには、[商品の開き方を変更する](#change-style)を参照してください。[スキャン](#method-3-barcode-scanning)の動作は、どの開き方でも同じです。

### その場で開く {#open-in-place}

商品をタップすると、パネル全体にオプションが 1 つずつタイルで表示されます。オプションをタップすると追加できます。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-26, 0], [264, 0], [99, -36], [0, 0], [97, -36], [140, 0], [-40, 0], [58, 26]]} alt="その場で開いた Abominable Hoodie：「商品」のパンくずリスト、戻るバッジ付きの親商品タイル、サイズ・色・価格が表示された 15 個のオプションタイル。最初のタイルにはカート内の数量バッジがあり、カートの明細には「サイズ: L · 色: 青」と表示されている">

1. **商品** — タップすると元の商品一覧に戻ります。
2. **現在の位置** — 開いている商品です。
3. **商品** — 価格帯とオプション数が表示されます。ここをタップしても戻れます。
4. **個別のオプション** — タップするとカートに追加されます。チップにはサイズと色が表示されます。
5. **カート内の数量** — このオプションがカートにいくつ入っているかを示します。画面はそのままなので、続けて追加できます。
6. **カートの明細** — 商品名と、その下にオプションが表示されます。
7. **15 個のオプション** — パネル下の件数は、現在開いている商品のオプション数を示します。
8. **在庫あり** — 有効な間は、在庫切れのオプションが非表示になります。無効にすると、それらは**売り切れ**と表示されます。

</JourneyShot>

キーボードの Escape キーを押す、タッチ画面の左端から内側へスワイプする、Android の戻るボタンを使う、別の検索語を入力することでも戻れます。

**テーブル**では、商品行をタップすると、**オプション**列のある行形式でオプションが開きます。行またはその **+** をタップすると追加できます。

### ポップオーバー {#method-1-quick-popover}

**グリッド**で表示方法が**ポップオーバー**の場合は、商品をタップし、その横に開くポップオーバーで各項目を選びます。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-43, -30], [37, -62], [5, -38], [20, -38], [100, 0], [0, 0]]} alt="Abominable Hoodie のタイル横に開いたポップオーバー：サイズのチップは XS から XL まであり、L が選択されている。色は青、緑、赤のチップがあり、青が選択されている。「在庫 100 個」と「カートに追加: $69.00」の表示">

1. **バリエーション** — このタイルにはオプションがあります。タップするとポップオーバーが開きます。
2. **サイズ** — オプションを区別する項目ごとに 1 行ずつ表示されます。
3. **L** — 選択したサイズです。
4. **緑** — 別のチップをタップすると選択を変更できます。
5. **在庫 100 個** — 選択したオプションの在庫数です。**在庫切れ**または**お取り寄せ**と表示されることもあります。ショップで在庫を管理していない場合は表示されません。
6. **カートに追加: $69.00** — オプションを追加し、ポップオーバーを閉じます。

</JourneyShot>

スマートフォンでは、ポップオーバーは画面下部から開くシートとして表示されます。番号は上の図と同じです。

<details>
<summary>グレー表示の選択肢と選択できないオプション</summary>

項目を選ぶと、組み合わせ可能なオプションがないチップはグレー表示になり、タップできなくなります。選択肢が 1 つしかない場合は、自動的に選択されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-57, -63], [39, -26], [34, -26], [46, -26], [55, -26], [41, -26], [0, 0]]} alt="ロゴで「はい」を選んだパーカーのポップオーバー：青が自動的に選択され、緑と赤はグレー表示になっている">

1. **パーカー** — 色とロゴの有無でオプションが分かれる商品です。
2. **はい** — ロゴの有無の選択内容です。
3. **いいえ** — タップすると選択を変更できます。
4. **青** — ロゴ付きはこの色だけなので、自動的に選択されます。
5. **緑** — ロゴ付きの緑のパーカーはないため、グレー表示になっています。
6. **赤** — 同じ理由でグレー表示になっています。
7. **カートに追加: $45.00** — ショップでこのオプションの在庫を管理していないため、在庫の行は表示されません。

</JourneyShot>

選択肢が多い場合は、**オプションを選択**と表示されたドロップダウンになります。選択肢が 10 個を超える場合は検索欄も付きます。ドロップダウンでは選択肢がグレー表示にならないため、実在しない組み合わせを選べることがあります。その場合、ポップオーバーには**バリエーションは利用できません**と表示され、追加できません。別の組み合わせを選んでください。

</details>

### 行を展開 {#method-2-expand-inline}

**テーブル**で表示方法が**行を展開**の場合は、商品の下にオプションが行として開きます。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[129, 0], [151, -49], [89, 70], [406, 70], [-356, -2], [9, 22], [9, -27]]} alt="テーブルで行を展開した Abominable Hoodie：商品名の下にサイズと色が並び、「15 個のバリエーション」ボタンと「サイズ」「色」のフィルターがある。各オプションの行には在庫、価格、プラスボタンが表示されている">

1. **15 個のバリエーション** — 行を展開したり折りたたんだりします。
2. **XS, S, M, L, XL** — いずれかをタップすると行が開き、そのサイズや色だけが表示されます。
3. **サイズ**と**色** — 行を特定のサイズや色に絞り込みます。
4. **折りたたむ** — 行を閉じます。
5. **個別のオプション** — サイズ、色、在庫数が表示されます。
6. **+** — カートに追加します。
7. **›** — 代わりに、この商品の[ポップオーバー](#method-1-quick-popover)を開きます。

</JourneyShot>

## オプションをスキャンする {#method-3-barcode-scanning}

オプション固有のバーコードをスキャンすると、表示方法にかかわらず、そのままカートに追加されます。オプションがまだこの端末にない場合は、POS に**ショップを検索中…** と表示され、取得してから追加されます。スキャンしても追加できない場合は、次のようなメッセージを確認してください。

- **… は在庫切れです** — **在庫切れの商品を表示**が無効な間は、スキャンが拒否されます。
- **スキャンできません** — オプションがこの端末になく、ショップにも接続できません。オンラインに戻ってから検索してください。

オプションではなく商品のバーコードをスキャンすると、何も追加されません。POS に**バリエーションを選択**と表示され、検索欄にバーコードが入力されて商品が表示されます。そこでオプションを選んでください。

バーコードとして使うフィールドは、[バーコードフィールド](../../settings/wp-admin/general.mdx#barcode-field)で設定します。スキャン時のその他の動作は、[バーコードスキャン](barcode-scanning.mdx)を参照してください。

## カート内の表示 {#variations-in-the-cart}

カートの明細には商品名が表示され、その下に**サイズ: L · 色: 青**などのオプションが表示されます。同じオプションを再度追加すると、行が増えるのではなく数量が増えます。オプションを変更するには、その明細を削除して正しいものを追加してください。

## 商品の開き方を変更する {#change-style}

1. 検索欄の横にある設定ボタンを押します。**商品設定**が開きます。
2. **表示モード**で**グリッド**または**テーブル**を選択します。
3. **バリエーション**で**その場で開く**、または各表示モードのもう一方の方法を選択します。グリッドでは**ポップオーバー**、テーブルでは**行を展開**です。
4. **閉じる**を押します。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[84, -39], [59, 0], [299, 0], [234, -147], [71, -39], [34, 0], [294, 0]]} alt="商品設定：表示モードは「グリッド」、「在庫切れの商品を表示」は無効、バリエーションは「その場で開く」が選択され、その横に「ポップオーバー」がある">

1. **表示モード** — タイル表示か行表示かを選びます。
2. **グリッド** — もう一方の開き方は**ポップオーバー**です。
3. **テーブル** — もう一方の開き方は**行を展開**です。
4. **在庫切れの商品を表示** — 無効な間は、在庫切れのオプションは非表示になり、スキャンも拒否されます。
5. **バリエーション** — バリエーション商品の開き方です。
6. **その場で開く** — 新しい端末での初期設定です。
7. **ポップオーバー** — **表示モード**が**テーブル**の場合は、**行を展開**と表示されます。

</JourneyShot>

設定はこの端末にのみ適用されます。この画面のその他の設定については、[表示設定](display-settings.mdx#variations)を参照してください。

## すべてのオプションが読み込まれますか？ {#all-options}

はい。バリエーション商品を開くと、オプション数にかかわらず、すべてのオプションが読み込まれます。「その場で開く」「ポップオーバー」「行を展開」のいずれでも同じです。引き上げるべき上限や、それを変更する設定はありません。

端末で商品を初めて開いたとき、POS はショップからその商品のオプションを取得し、端末に保存します。オプションが多い商品は、初回に少し時間がかかることがあります。取得が終わるまで**同期中…** と表示されます。その後も表示されないオプションは、通常は在庫切れで、**在庫あり**フィルターによって非表示になっています。[問題が起きた場合](#goes-wrong)を参照してください。

## 問題が起きた場合 {#goes-wrong}

- **オプションが表示されない** — **在庫あり**フィルターで非表示になっていないか確認してください。フィルターの × 印を押すか、**在庫切れの商品を表示**を有効にしてください。
- **「カートに追加」がグレー表示のまま** — そのオプションは在庫切れで、ショップでは POS による在庫数を超える販売が許可されていません。別のオプションを選ぶか、WooCommerce で在庫を更新してください。
- **バリエーションは利用できません** — 選択した組み合わせに一致するオプションがありません。選択項目のいずれかを変更してください。
- **同期中…** — この端末にオプションを読み込んでいます。しばらくお待ちください。
- **バリエーションを選択** — オプションではなく、商品のバーコードをスキャンしています。オプションを選ぶか、オプション固有のバーコードをスキャンしてください。
- **カートに違うオプションが入っている** — [明細を削除](../checkout/index.mdx#goes-wrong)して、正しいものを追加してください。
