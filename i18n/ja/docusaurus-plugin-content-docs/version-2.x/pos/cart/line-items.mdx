カート内の商品、手数料、配送料は、それぞれ明細として表示されます。明細のほとんどの項目は、数量、価格、名前をタップしてその場で変更できます。それ以外の項目は、明細の **編集** ダイアログで変更します。

## カートの明細 {#line}

商品明細には数量、商品名、単価が表示され、右側に明細の合計が表示されます。手数料と配送料も商品明細の下に明細として表示されます。そのほかに表示される内容は、表示する[列](./index.mdx#columns)によって決まります。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 32], [122, -40], [0, -26], [0, -26], [-34, 0], [-34, 0], [-30, 0], [0, 24]]} maxWidth={379} alt="三つの明細があるカート：$45.00 の Aim Analog Watch × 3（カスタムフィールド「刻印：誕生日おめでとう」付き）、ギフト包装の手数料 $2.00、地域配送の配送料 $5.00">

1. **数量** — 数量です。タップすると変更できます。[数量の変更](#quantity)を参照してください。
2. **項目** — 商品名です。タップすると名前がテキストボックスに変わり、今回の販売に限って明細名を変更できます。Enter を押すか、ほかの場所をタップすると新しい名前が保存されます。その下には、販売した[バリエーション](../product-panel/variations.mdx)のオプションと、明細の[カスタムフィールド](#meta-data)が `Key: value` の形式で表示されます。列の **SKU** オプションをオンにすると、SKU も表示されます。
3. **価格** — 単価です。タップすると変更できます。[価格の変更](#price)を参照してください。通常価格より安い場合は、その上に通常価格が取り消し線付きで表示されます。
4. **合計** — 数量に価格を掛けた金額です。タップすると **編集** と **削除** が表示されます。[明細の編集と削除](#remove-item)を参照してください。
5. **手数料** — 同様に、名前をタップすると名前を、金額をタップすると金額を変更できます。[手数料](./index.mdx#fees)を参照してください。
6. **配送明細** — 同様に、タイトルまたは金額をタップします。[配送](./index.mdx#shipping)を参照してください。
7. **+** — 手数料、配送料、割引、または[その他の商品](./index.mdx#miscellaneous-products)をカートに追加します。
8. **カート設定** — カートを左右のどちらに配置するか、明細の並び順、表示する列を設定します。[明細に関するカート設定](#cart-settings)を参照してください。

</JourneyShot>

## 数量の変更 {#quantity}

数量ボックスをタップします。iOS アプリと Android アプリでは、ボックスに直接数値を入力します。数量を 0 にすると明細が削除されます。それ以外ではテンキーが開きます。新しい数量を入力して、チェックマークをタップするか Enter を押すと保存されます。スマートフォンでは画面下部からシートとして開きます。タブレットやパソコンではボックスから広がるように開き、上部に数量が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, -24], [0, -24], [0, -24], [-6, 0], [-6, 0], [0, 0]]} maxWidth={441} alt="数量 1 の明細で開いた数量用テンキー：1 の左側にごみ箱、右側にプラス、数字キー、削除キー、チェックマーク">

1. **数量** — 現在入力されている値です。
2. **−** — 数量を一つ減らします。数量が 1 になると、図のようにごみ箱に変わります。押すと明細が削除されます。
3. **+** — 数量を一つ増やします。
4. **数字キー** — 新しい数量を入力します。
5. **削除** — 末尾の数字を削除します。
6. **完了**（チェックマーク）— 新しい数量を保存します。Enter も同じ動作です。Escape を押すとテンキーが閉じ、元の数量が維持されます。

</JourneyShot>

店舗で[小数の数量を有効にする](../../settings/wp-admin/general.mdx#enable-decimal-quantities)をオンにしている場合、テンキーに店舗の小数点記号が付いたキーも表示されます。重量や長さで販売する商品に、2.5 や 0.25 などの小数の数量を入力できます（小数点以下六桁まで）。

店舗で在庫数を超える販売を防止している場合、在庫数を超えた数量はオレンジ色になります。[チェックアウトがブロックされる場合](#checkout-blocked)を参照してください。

### 明細の分割 {#splitting-line-items}

**分割** を使うと、数量が複数ある明細を一つずつの明細に分け、個別に価格、割引、メモを設定できます。小数の数量の場合、端数は独立した明細になります。数量 2.5 の明細は、1、1、0.5 に分割されます。

**分割** リンクは、数量が一つを超える明細の数量の下に表示されます。**カート設定** でオンにするまでは無効です。

1. **数量** — 明細の数量です。ここでは 3 です。
2. **分割** — タップすると、数量一つずつの三つの明細に分割します。

## 価格の変更 {#price}

価格をタップし、新しい単価を入力するかクイック割引キーを押してから、チェックマークをタップするか Enter を押すと保存されます。価格の欄が広がり、テンキーが表示されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [-4, -20], [-4, -20], [-4, -20], [0, 0], [-4, 0], [0, 0]]} maxWidth={293} alt="$45.00 の明細で開いた価格用テンキー。−10% キーが点灯し、新しい価格 $40.50 の上に $45.00 −10 % と表示されている。数字キー、小数点、削除キー、チェックマークもある">

1. **価格** — 新しい単価です。クイック割引を適用すると、その上に計算式が表示されます。ここでは $45.00 −10 % で、$40.50 になります。
2. **−5%** — **クイック割引** キーです。明細の価格を 5% 引きにします。
3. **−10%** — 押したため点灯しています。点灯しているキーをもう一度押すと、割引が取り消されます。
4. **−15%** — 15% 引きにします。初期設定はこの三つですが、[変更できます](./discounts.mdx#quick-discounts)。
5. **数字キー** — 新しい単価を入力します。最初の数字を入力すると、元の価格が置き換わります。
6. **削除** — 末尾の数字を削除します。
7. **完了**（チェックマーク）— 新しい価格を保存します。Enter も同じ動作です。Escape を押すとテンキーが閉じ、価格は元のままになります。

</JourneyShot>

キーボードでは、数字を入力し、Backspace で削除、Enter で保存、Escape でキャンセルします。数量用テンキーでは、上矢印と下矢印で数量を一つずつ増減できます（下矢印では 1 より小さくなりません）。

スマートフォンのブラウザーでは、同じテンキーがシートとして開きます。iOS アプリと Android アプリでは、価格をタップすると入力ボックスに変わります。新しい単価を入力してボックスからフォーカスを外すと、保存されます。クイック割引キーはテンキーにのみ表示されます。

:::note 価格の編集は WooCommerce の「割引」ではありません
値下げした価格は、商品のセール価格として記録されます。レシートには値引き額を表示できますが、注文の **割引** 合計に含まれるのはクーポンのみで、レポートでは実際に支払われた価格で売上が集計されます。WooCommerce が両者を別に扱う理由は、[カートの割引](./discounts.mdx#why-tracked-differently)を参照してください。
:::

### 変更した価格は今回の販売にのみ適用 {#price-this-sale}

カートで変更した価格は、今回の販売にのみ適用されます。商品自体の価格は変わらず、この端末でもほかの端末でも、商品タイルには元の価格が表示されます。すべての販売に適用するには、[商品](../../products/index.mdx#inline-price-editing)画面または WP Admin で商品の価格を変更してください。

カタログにない商品を任意の価格で販売するには、**+** を押して[その他の商品](./index.mdx#miscellaneous-products)を追加します。

## 明細の編集と削除 {#remove-item}

各明細には、通常は隠れている **編集** ボタンと **削除** ボタンがあります。表示するには、次のいずれかの操作を行います。

- **明細の合計をタップします。** もう一度タップすると非表示になります。
- 合計にマウスを **重ねる** と、明細が横にずれてボタンが見えます。
- タッチスクリーンで **明細をスワイプ** して左に動かすか、マウスで左にドラッグします。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[6, -28], [6, -28]]} maxWidth={379} alt="時計の明細が左にスライドし、青い編集ボタンと赤い削除ボタンが表示されている">

1. **編集** — [編集ダイアログ](#edit-form)を開きます。
2. **削除** — カートから明細を削除します。

</JourneyShot>

さらにスワイプすると、**削除** が行全体に広がって赤くなります。そのまま指を離すと、一度の操作で明細を削除できます。

削除後のメッセージには **元に戻す** が表示されます。押すと明細が元の状態に戻ります。

## 編集ダイアログ {#edit-form}

**編集** を押すと、明細名をタイトルとするダイアログに詳細が表示されます。変更はその都度保存されます。終わったら **閉じる** を押してください。

商品明細の場合：

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-35, 0], [-35, 0], [-35, 0], [-35, 0], [-35, 0], [-10, 0], [-10, 0], [-35, 0]]} alt="Aim Analog Watch の編集：名前、数量 3、価格 45.00、税の標準税率、削除ボタン付きの SKU 24-MG04、カスタムフィールド「刻印：誕生日おめでとう」、通常価格ボタンとカスタムフィールドボタン、閉じるボタン">

1. **名前** — レシートと注文に表示される名前です。
2. **数量** — カートに表示される数量と同じです。
3. **価格** — カートに表示される価格と同じです。セール中の明細では、横に **元の価格** と通常価格が表示されます。その **削除** を押すと通常価格が削除され、セール扱いではなくなりますが、現在の価格は変わりません。
4. **税** — 明細が課税対象かどうか、および税区分です。
5. **SKU** — 商品に SKU がある場合に表示されます。SKU がない明細には、追加用の **SKU** ボタンが表示されます。
6. **通常価格** — セール中ではない明細に通常価格を追加します。
7. **カスタムフィールド** — 上にある **刻印** の行のように、キーと値を追加します。[カスタムフィールド](#meta-data)を参照してください。
8. **閉じる** — ダイアログを閉じます。変更内容はすべて保存済みです。

</JourneyShot>

追加した各行には、それぞれ **削除** があります。[その他の商品](./index.mdx#miscellaneous-products)はカタログに登録されていないため、ダイアログには **カテゴリー**、**バーチャル**、**ダウンロード可能** も表示されます。

明細の税額は、注文の住所に適用される税率で計算されます。店舗が顧客の住所に基づいて[税を計算](../../settings/store/tax.mdx#calculate-tax-based-on)する設定の場合、顧客またはその住所を別の税率が適用されるものに変更すると、明細の税額は直ちに新しい税率で再計算されます。[免税](./index.mdx#tax-exempt)の注文は免税のままです。

### 手数料明細 {#edit-fee}

手数料の **編集** を押すと、手数料名をタイトルとする専用のダイアログが開きます。商品と同様に、変更はその都度保存されます。

手数料に負の値は設定できません。ダイアログに **手数料を負の値にはできません。代わりに「割引を追加」を使用してください。** と表示されます。[割引](./discounts.mdx)を参照してください。

### JSON タブ {#raw-json-view}

**フォーム** の隣にある **JSON** タブには、WooCommerce に送信される明細データがそのまま表示されます。販売時に使う必要はありませんが、プラグインが受け取るデータや、フィールドが保存されない原因を調べる際に役立ちます。

#### 明細の三つの種類 {#line-item-types}

WooCommerce は、商品、手数料、配送をそれぞれ異なる種類の明細として保存します。

| 種類 | WooCommerce での名称 | 例 |
|------|----------------|----------|
| 商品 | `line_item` | T シャツ、コーヒーマグ |
| 手数料 | `fee_line` | ギフト包装、サービス料 |
| 配送 | `shipping_line` | 通常配送、速達配送 |

#### WCPOS 独自のフィールド {#protected-keys}

WooCommerce では、カスタムフィールドをメタデータと呼びます。アンダースコアで始まるキーは、WCPOS 独自の記録です（`_woocommerce_pos_data` や `_reduced_stock` など）。これらはフォームやカートには表示されませんが、**JSON** タブで確認できます。

</details>

## カスタムフィールド {#meta-data}

カスタムフィールドは、刻印の内容やシリアル番号など、明細ごとに保存するメモです。刻印を追加するには、明細の **編集** ダイアログを開いて **カスタムフィールド** をタップし、**キー** に **刻印**、**値** に顧客のメッセージを入力します。フィールドはカートの明細名の下と、WP Admin の注文に表示されます。各フィールドには、それぞれ **削除** があります。

商品から引き継がれるフィールドもあります。選択した[メタデータキー](../product-panel/meta-data-keys.mdx)は、商品をカートに追加したときに明細にコピーされます。

フォームに **このキーは WCPOS が管理しています。別のキーを選択してください。** と表示された場合は、[WCPOS 独自のキー](#protected-keys)を入力しています。別のキーを選んでください。

## チェックアウトがブロックされる場合 {#checkout-blocked}

店舗で[在庫数を超える販売を防止](../../settings/wp-admin/checkout.mdx#prevent-overselling)している場合、カートは各商品明細の数量を在庫数と照合します。

- 明細の上の通知に、在庫が不足している商品が表示されます。**パーカーの在庫は残り 2 点です** には、その明細の数量入力を開く **減らす** が、**パーカーは在庫切れです** には **削除** が表示されます。
- 在庫が不足している明細はオレンジ色になり、利用可能な在庫数が表示されます。
- **チェックアウト** がグレー表示になります。押すと、修正が必要な最初の明細に移動します。

すべての明細を修正すると、**チェックアウト** が再び有効になります。取り寄せ注文が可能な商品は、販売をブロックしません。

## 問題が発生した場合 {#goes-wrong}

**「項目を更新できませんでした。カートから削除されています。」** 変更中に明細が削除されました。カートを確認し、もう一度変更してください。

**「その項目はカートから削除されています。」** すでに削除された明細の **削除** を押しました。追加の操作は必要ありません。

**分割リンクがありません。** **カート設定** の **数量** 列で **分割** をオンにしてください。このリンクは、数量が 1 を超える明細にのみ表示されます。

**チェックアウトがグレー表示になっています。** 在庫が不足している明細があります。[チェックアウトがブロックされる場合](#checkout-blocked)を参照してください。

**カスタムフィールドが保存されません。** キーがアンダースコアで始まっており、WCPOS が使用しています。別のキーを選んでください。
