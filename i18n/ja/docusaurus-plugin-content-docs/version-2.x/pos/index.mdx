POS は販売を行う画面です。片側に商品、もう片側にカートがあり、その他の機能には画面端のメニューからアクセスできます。このページでは画面の各部分を紹介し、詳しい説明ページへ案内します。

**操作に移動：** [商品を探す](./product-panel/index.mdx) · [支払いを受け付ける](./checkout/index.mdx) · [レジを開く](./register/index.mdx) · [レジ係シートを開く](#cashier-sheet)

## 画面の構成 {#layout}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[34, -28], [52, 0], [52, 0], [52, 0], [240, 0], [0, -50], [200, 0], [128, 0], [-30, 0], [-14, 26]]} alt="カートに商品が入ったタブレットの POS 画面。左端のメニューにはカーソルを合わせた注文アイコンの名前が表示され、下部には店舗の状態、設定、サポートがあります。商品検索とグリッド、仕切り、カート、カート上部の店舗名・ベル・アバターが並ぶバーも表示されています">

1. **メニュー** — 画面ごとにアイコンがあります。アイコンにカーソルを合わせると名前が表示されます。[メニュー](#menu)を参照してください。
2. **店舗の状態** — この端末と店舗の同期状況や、記録された問題を確認します。赤い数字はログに新しいエラーがあることを示します。[店舗の状態](../support/store-health.mdx)を参照してください。
3. **設定** — この端末の言語、金額の形式、税の表示、プリンター、カードリーダー、カスタマーディスプレイ、スキャナー、テーマを設定します。[設定](../settings/index.mdx)を参照してください。
4. **サポート** — アプリ内で WCPOS の Discord チャットを利用できます。[サポート](../support/index.mdx)を参照してください。
5. **商品パネル** — 検索や絞り込みを行い、商品をタップして追加します。[商品パネル](./product-panel/index.mdx)を参照してください。
6. **仕切り** — ドラッグすると、商品またはカートの表示領域を広げられます。POS はこの端末での幅を記憶します。
7. **カート** — 現在の販売内容です。顧客、明細、合計、**チェックアウト** が表示されます。[カート](./cart/index.mdx)を参照してください。
8. **レジバー** — 販売先の店舗が表示されます。店舗に複数のレジがある場合はレジも表示されます。[上部のバー](#bar)を参照してください。
9. **ベル** — プラグインの更新、ライセンスのリマインダー、お知らせなど、WCPOS からの通知です。[通知](../support/notifications.mdx)を参照してください。
10. **アバター** — レジ係シートを開きます。[レジ係シート](#cashier-sheet)を参照してください。

</JourneyShot>

メニューの下にあるバージョン（ここでは **v 2.0.0**）を押すと、[WCPOS について](#about)が開きます。

## メニュー {#menu}

タブレットやパソコンでは、メニューのアイコンが左端に縦に並び、常に表示されます。スマートフォンでは左上の **☰** を押すと、名前付きのメニューが画面に重なって開きます。名前をタップすると、その画面に移動します。

<JourneyShot manifest={manifest} device="phone" step={2} offsets={[[-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0]]} maxWidth={390} alt="スマートフォンで開いたメニュー。上部に POS、商品、注文、クーポン、顧客、レポート、下部に店舗の状態、設定、サポートがあり、その下にバージョンが表示されています">

1. **POS** — 販売を行うレジ画面です。[チェックアウト](./checkout/index.mdx)を参照してください。
2. **商品** — 在庫、価格、商品詳細です。[商品](../products/index.mdx)を参照してください。
3. **注文** — 過去の注文を検索し、レシートの再印刷や払い戻しを行います。[注文](../orders/index.mdx)を参照してください。
4. **クーポン** — 店舗のクーポンです。[クーポン](../coupons/index.mdx)を参照してください。
5. **顧客** — 顧客を追加・編集します。[顧客](../customers/index.mdx)を参照してください。
6. **レポート** — 支払い方法別・レジ係別の当日の売上と、レジ締めの記録です。[レポート](../reports/index.mdx)を参照してください。
7. **店舗の状態** — この端末と店舗の同期状況や、記録された問題です。[店舗の状態](../support/store-health.mdx)を参照してください。
8. **設定** — この端末の設定です。[設定](../settings/index.mdx)を参照してください。
9. **サポート** — アプリ内で WCPOS の Discord チャットを利用できます。[サポート](../support/index.mdx)を参照してください。

</JourneyShot>

無料プラグインでは、**商品**、**注文**、**クーポン**、**顧客** はプレビュー表示となり、変更できません。

<details>
<summary>WCPOS Pro では何が変わりますか？</summary>

**無料プラグインでは**、**商品**、**注文**、**クーポン**、**顧客** はぼかし付きのプレビューで開き、**Pro にアップグレード** パネルが表示されます。カートでは引き続き顧客の選択やクーポンの適用ができます。**レポート** には使用中のレジの当日分が表示されます。

**WCPOS Pro では**、**商品**、**注文**、**クーポン**、**顧客** を編集できます。**レポート** では、閲覧権限のあるすべてのレジと店舗について、当日より前の記録も確認できます。複数の店舗がある場合は、バーやレジ係シートから切り替えられます。

[無料版と Pro の比較](../getting-started/free-vs-pro.mdx#management-screens)を参照してください。

</details>

### WCPOS について {#about}

メニュー下部のバージョンをタップします。**WCPOS について** には、この端末で実行中のソフトウェアの情報が表示されます。サポートから最初に確認される情報です。

<details>
<summary>サポートに伝える情報</summary>

<JourneyShot manifest={manifest} device="tablet" step={7} alt="WCPOS についてのダイアログ。アプリのバージョンとプラットフォーム、WCPOS Pro プラグイン・WooCommerce・WordPress のバージョン、ライセンスの状態 Pro、閉じるボタンとリリースノートボタンが表示されています" />

- **アプリケーション** — アプリのバージョンと実行環境（ウェブ、デスクトップ、iOS、Android）です。
- **サーバー** — サイトの WCPOS プラグイン（インストール済みの場合は WCPOS Pro）、WooCommerce、WordPress のバージョンです。
- **ライセンス** — **無料** または **Pro** です。
- **リリースノート** — wcpos.com にある、各バージョンの変更内容です。

</details>

## スマートフォンでの表示 {#phone}

スマートフォンや幅の狭いブラウザーウィンドウでは、商品とカートは下部のタブに分かれます。バーは上部に表示されたままで、**☰** からメニューを開けます。

<JourneyShot manifest={manifest} device="phone" step={3} offsets={[[-10, 0], [108, 0], [-12, 0], [-14, 0], [40, 0], [40, 0]]} maxWidth={390} alt="カートに商品が入ったスマートフォンの POS 画面。上部にメニューボタン、店舗名、ベル、アバター、中央に商品検索と商品タイル、下部に商品タブと件数付きのカートタブがあります">

1. **☰ メニュー** — [メニュー](#menu)を開きます。
2. **レジバー** — 店舗と、複数ある場合はレジを表示します。
3. **ベル** — [通知](../support/notifications.mdx)です。
4. **アバター** — [レジ係シート](#cashier-sheet)です。
5. **商品** — [商品パネル](./product-panel/index.mdx)です。
6. **カート** — 販売内容とカート内の件数を表示します。ここからチェックアウトを開始します。

</JourneyShot>

他の画面の表示も変わります。商品、注文、クーポン、顧客は、マウス操作では表形式ですが、タッチスクリーンでは各項目が行として並び、末尾に **›** が表示されます。スマートフォンでは、行をタップするとその項目が個別のページで開きます。**✕** を押すと一覧に戻ります。

1. **☰ メニュー** — スマートフォンではすべての画面にあります。
2. **検索** — ボックスには **商品を検索**、**注文を検索** など、表示中の画面に応じた名前が表示されます。

## 上部のバー {#bar}

すべての画面の上部にバーがあり、右端には常にベルとアバターが表示されます。

POS では **レジバー** として、販売先の店舗と、店舗に複数のレジがある場合はレジ名を表示します。WCPOS Pro で複数の店舗がある場合は、店舗名をタップして店舗を切り替えます。確認が必要なことがあると、名前の横に状態が表示されます。

<details>
<summary>レジの状態の意味</summary>

- **終了**、**集計中**、**承認が必要**、**期限超過** — その日のレジの進行状況です。[レジを開く](./register/index.mdx)を参照してください。
- **レジを選択** または **レジなし** — この端末にはまだレジが割り当てられていません。[店舗とレジの選択](../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)を参照してください。
- **オフライン** または **オフライン · 送信待ちの売上 2 件** — 下の[バーのオフライン表示](#offline)を参照してください。
- **店舗の確認待ちの売上 1 件** — 店舗側でまだ確認されていない売上です。自動で処理されるため、操作は不要です。

レジが開いていて、特に通知することがなければ、状態は表示されません。

</details>

<details>
<summary>他の画面とデスクトップアプリのバー</summary>

**商品**、**注文**、**クーポン**、**顧客** では、タイトルの代わりに画面名を含む検索ボックスが表示されます。**レポート** では、そこに店舗とレジの選択欄が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[34, -28], [260, 0], [10, 40], [10, 40], [10, 40]]} alt="商品画面のバー。商品一覧の上に、メニュー内で強調表示された商品アイコン、検索ボックス、表示オプション、ベル、アバターが並んでいます">

1. **現在の画面** — メニュー内で強調表示されているアイコンです。
2. **検索** — この画面の項目を検索します。
3. **表示オプション** — 一覧に表示する列を選びます。[表示設定](../products/index.mdx#display-settings)を参照してください。
4. **ベル** — POS と同じ[通知](../support/notifications.mdx)です。
5. **アバター** — どの画面からも同じ[レジ係シート](#cashier-sheet)を開けます。

</JourneyShot>

デスクトップアプリでは、店舗名、状態、ベル、アバターはウィンドウのタイトルバーに移ります。ウィンドウを全画面表示にすると、元のバーに戻ります。

</details>

## レジ係シート {#cashier-sheet}

どの画面でもアバターをタップすると、右側からレジ係シートが開きます。スマートフォンでは画面全体に表示されます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[130, 0], [230, -15], [180, -19], [-30, 0], [0, -32], [0, -32], [100, 0]]} alt="POS に重なって表示されるレジ係シート。名前、店舗、サインインからの経過時間、本日の自分の売上、ドロアーのタイル、レジの引き継ぎ先、切り替え付きの店舗、WordPress 管理画面とデスクトップアプリへのリンク、サインアウトが表示されています">

1. **本日の自分の売上** — 自分が処理した売上です。
2. **ドロアー内の現金** — レジで計算された現金の予定残高です。レポートの閲覧権限がない場合は、金額の代わりに売上件数を表示します。タップすると入金、出金、レジ締めを行えます。[レジを開く](./register/index.mdx#cashier-sheet)を参照してください。
3. **レジの引き継ぎ先** — ドロアーを締めずに別のレジ係へレジを引き継ぎます。相手の名前をタップするか、**別のアカウント…** からサインインしてもらいます。[レジを開く](./register/index.mdx#cashier-sheet)を参照してください。
4. **店舗 · 切り替え** — 別の店舗に移動します（複数の店舗がある WCPOS Pro）。店舗に複数のレジがある場合は、その下に **レジ · 切り替え** が表示されます。
5. **WordPress 管理画面** — アクセス権を持つ管理者向けに、サイトの管理画面を新しいタブで開きます。
6. **デスクトップアプリ** — デスクトップアプリのダウンロードページです。この二つのリンクはブラウザーでのみ表示されます。
7. **サインアウト** — レジが開いている場合、先に締めるかどうか POS が確認します。

</JourneyShot>

## キーボードショートカット {#keyboard-shortcuts}

ブラウザーやデスクトップアプリでキーボードを使用する場合、入力欄への入力中も含め、POS 画面のどこでも使えます。Mac では **Alt** の代わりに **Option**（⌥）を押します。

<details>
<summary>キーボードショートカットを表示</summary>

| ショートカット | 機能 |
|---|---|
| `Alt` + `F` | 商品を検索 |
| `Alt` + `P` | チェックアウト |
| `Alt` + `N` | 新しいカート |
| `Alt` + `←` / `Alt` + `→` | 前のカート / 次のカート |
| `Alt` + `D` | 割引を追加 |
| `Alt` + `V` | 注文を無効化 |
| `Alt` + `/` | ショートカットを表示 |
| `Esc` | 入力欄への入力中でなければ、チェックアウトからカートに戻る |

ショートカットは、その操作ができる状況でのみ動作します。たとえば **チェックアウト** にはカート内の商品が必要です。キーは変更できません。[キーボードショートカット](../settings/store/hotkeys.mdx)を参照してください。

</details>

## 問題が起きた場合 {#goes-wrong}

### バーのオフライン表示 {#offline}

インターネット接続が切れているか、ウェブサイトが応答しないため、この端末から店舗に接続できません。そのまま販売を続けられます。現金や、別途使用する決済端末でのカード支払いは完了できます。バーには待機中の件数が **送信待ちの売上** として表示され、再接続できると店舗へ送信されます。レジから操作するカードリーダーやオンライン決済ゲートウェイには接続が必要です。[オフラインモード](../getting-started/offline.mdx)を参照してください。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[80, 0], [52, 26]]} alt="接続が切れた直後の POS。バーの店舗名の横にオフラインと表示され、端末がオフラインになったこと、作業を続行できること、店舗に接続できると同期が再開することを知らせるメッセージがあります">

1. **オフライン** — 店舗が再び応答するまで表示されます。
2. **店舗名** — 売上の送信先の店舗です。

</JourneyShot>

### 「ローカルデータベースを利用できません」 {#database-unavailable}

商品の上とチェックアウト画面に、スキャン、チェックアウト、保存、無効化ができないことを示すバナーが表示されます。

1. **アプリを再読み込み** を押します。
2. アプリに再読み込みできないと表示された場合（一部のスマートフォン・タブレット用アプリ）は、完全に終了してから再度開いてください。
3. 繰り返し発生する場合は、[ローカルデータの消去](../support/troubleshooting/clear-local-data.mdx)を参照してください。

<details>
<summary>発生した問題</summary>

端末に保存された店舗データのコピーが機能しなくなっています。バナーの **状態を表示** を押すと、店舗の状態の[データベース](../support/store-health.mdx#database)セクションが開きます。

</details>

### 店舗の状態に赤い数字が表示される {#store-health-errors}

この端末で新しいエラーが記録されました。**店舗の状態** からログを開いて確認してください。ログを開くと数字は消えます。[ログ](../support/store-health.mdx#logs)を参照してください。

### 「この画面は存在しません」 {#not-found}

古いブックマークなど、使用しているアドレスが古くなっています。**最初に戻る** を押すと POS に移動します。サインアウトしている場合は、店舗に接続する画面に移動します。

### 画面に「Pro にアップグレード」と表示される {#upgrade-to-pro}

その画面には WCPOS Pro が必要です。[メニュー](#menu)の **WCPOS Pro では何が変わりますか？** または[無料版と Pro の比較](../getting-started/free-vs-pro.mdx)を参照してください。
