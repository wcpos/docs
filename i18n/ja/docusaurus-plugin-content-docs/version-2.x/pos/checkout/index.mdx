顧客が購入する商品を持ってレジに来ました。このページでは、最初の商品を追加してから次の顧客を迎えるまで、現金での販売の流れを説明します。

:::note 先にレジを開いてください
**レジの開閉**がオンの場合、レジが閉まっている間は支払いを記録できず、すでに受け付けたカード支払いは払い戻す必要があります。設定については[レジ](../../settings/wp-admin/registers.mdx#one-register)、仕組みについては[店舗、レジ、端末](../../stores/registers-and-devices.mdx)をご覧ください。
:::

## カートに商品を追加する {#cart}

商品をタップするとカートに入ります。もう一度タップすると1点追加されます。商品とカートは横並びに表示され、スマートフォンでは別々のタブに表示されます。

各販売は、店舗の既定の顧客で始まります。[既定の POS 顧客](../../settings/wp-admin/general.mdx#default-pos-customer)で指定した顧客、または[レジ係のアカウントを使用](../../settings/wp-admin/general.mdx#use-cashier-account)がオンの場合はレジ係が設定されます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[180, 0], [281, 0], [141, -224], [103, 0], [54, -38], [6, 56], [-27, 0], [165, 0], [12, 0]]} alt="時計が1点カートに入った POS：レジバー、検索ボックス、商品グリッド、未完了の注文が表示され、カートには顧客、数量、追加メニュー、小計、チェックアウトボタンがある">

1. **レジバー** — 使用中のレジとそのセッションです。[店舗、レジ、端末](../../stores/registers-and-devices.mdx)をご覧ください。
2. **検索** — 名前や SKU を入力するか、[バーコードをスキャン](../product-panel/barcode-scanning.mdx)します。[検索と絞り込み](../product-panel/search-filtering.mdx)をご覧ください。
3. **商品** — タップすると追加されます。選択肢がある商品では、どれを使うか選択します。[バリエーション](../product-panel/variations.mdx)をご覧ください。
4. **未完了の注文** — このレジで進行中のすべての販売です。タップするとその注文に切り替わります。[未完了の注文](../cart/open-orders.mdx)をご覧ください。
5. **顧客** — 販売先の顧客です。タップすると別の顧客を選べます。[カート](../cart/index.mdx)をご覧ください。
6. **数量** — タップして新しい数量を入力し、**完了**を押します。[明細項目](../cart/line-items.mdx#quantity)をご覧ください。
7. **追加メニュー** — 新規顧客、カタログにない商品、手数料、割引を追加します。[割引](../cart/discounts.mdx)をご覧ください。
8. **小計** — 支払いを受け付ける前の注文金額です。
9. **チェックアウト** — 合計金額が表示されます。カートの内容を確認したら押します。

</JourneyShot>

## 支払いを受け付ける {#take-cash}

**チェックアウト**を押します。注文の横に支払い画面が開き、支払額が大きく表示され、最初の支払い方法が選択されています。スマートフォンでは、**注文のチェックアウト #** というタイトルと注文番号の下に、画面全体を使って表示されます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[28, 42], [29, 42], [-55, 0], [66, 0], [-4, 0], [122, 0], [0, 0], [0, 0]]} alt="$45.00 の現金販売の支払い画面：支払いタブ、従来方式タブ、支払額、分割、現金とカードのタイル、金額のクイック選択、キーパッド、受け取るボタン">

1. **支払い**タブ — 支払い方法のタイルと、受け付け済みの支払いが表示されます。[支払いパネル](./payment-methods.mdx)をご覧ください。
2. **従来方式**タブ — 店舗の決済ページを POS 内に表示します。無料プラグインでは **カード**を使用でき、[WCPOS Pro](../../getting-started/pro-license.mdx)では店舗の他の支払い方法も追加されます。**現金**は表示されません。支払いを受け付けた後は、タブの下に **全額の支払いのみ**と表示されます。[従来方式タブ](./legacy-tab.mdx)と[一部支払い済みの注文の場合](./legacy-tab.mdx#after-payment)をご覧ください。
3. **支払額** — まだ支払われていない残額です。一部支払いの後は、次の支払額と残額が表示されます。
4. **分割** — 代金を複数回の支払いに分けます。[代金を分割する](#split)をご覧ください。
5. **支払い方法のタイル** — 店舗のレジで受け付ける支払い方法です。[レジ設定](../../settings/wp-admin/checkout.mdx)で設定します。[支払い方法](./payment-methods.mdx)をご覧ください。
6. **金額のクイック選択** — ちょうどの金額や、それ以上のきりのよい紙幣の金額を選べます。
7. **キーパッド** — 顧客から受け取った金額を入力します。**C** で消去できます。
8. **受け取る** — 金額と支払い方法が表示されます。押すと支払いを記録します。[支払いの受付](./taking-a-payment.mdx)をご覧ください。

</JourneyShot>

スマートフォンでは、同じ操作項目がタイトルの下に縦に並び、右上に **✕** が表示されます。

<JourneyShot manifest={manifest} device="phone" step={5} offsets={[[0, 0], [0, 0], [-40, 0], [55, 0], [0, 0], [115, 0], [0, 0], [0, 0]]} maxWidth={300} alt="スマートフォンの支払い画面：注文のチェックアウトのタイトルと注文番号、閉じるボタン、支払いタブ、従来方式タブ、支払額、分割、現金とカードのタイル、金額のクイック選択、キーパッド、受け取るボタン" />

独立した決済端末でのカード払いも同様です。先にカード決済を行い、その後で記録します。ペアリング済みのリーダーには、レジから金額が送られます。[カードリーダーでの支払い](./taking-a-payment.mdx#card-reader)をご覧ください。

## お釣りを渡す {#change}

支払額より多い金額を入力またはタップすると、お釣りが大きく表示され、その下に預かり金額が表示されます。**受け取る**を押す前に、お釣りを数えて用意してください。

<JourneyShot manifest={manifest} device="tablet" step={8} offsets={[[-40, 0], [-40, 0], [-45, 0], [-60, 0], [-4, 0], [0, 0]]} alt="$45.00 の現金販売で $50.00 を預かった支払い画面：閉じるボタン、支払額 $45.00、大きく表示されたお釣り $5.00、その下に預かり金額 $50.00、選択された現金、受け取るボタン">

1. **✕** — 注文を残したままカートに戻ります。支払いを受け付けた後は、代わりに **支払いをキャンセル**が開きます。[支払いの取り消し](./cancelling-a-payment.mdx)をご覧ください。
2. **支払額** — この販売の代金です。
3. **お釣り** — 返す金額です。
4. **預かり金額** — 入力またはタップした金額です。
5. **現金** — この支払いを記録する支払い方法です。
6. **受け取る** — 支払いを記録し、販売を完了します。

</JourneyShot>

## 代金を分割する {#split}

代金を複数回に分けて受け付けるには、**分割**を押します。**割合**と、**2分割**から **6分割**までの均等分割の選択肢が並び、それぞれ1回分の金額が表示されます。横にスクロールすると他の選択肢も確認できます。各自が支払う商品を選ぶこともできます。**分割**をもう一度押すと、1回の支払いに戻ります。[分割払い](./split-payments.mdx)をご覧ください。

<JourneyShot manifest={manifest} device="tablet" step={9} offsets={[[55, 0], [108, -50], [76, -56]]} alt="分割がオンの支払い画面：残額を分割の欄に割合と2分割から5分割までの選択肢が並び、それぞれ1回分の金額が表示されている。横の注文には今回の支払い列があり、各明細にマイナスとプラスのボタンがある">

1. **分割** — 分割を設定している間はオンになります。もう一度押すとオフになりますが、受け付け済みの支払いは残ります。
2. **残額を分割** — **2分割**から **6分割**をタップすると残額を均等に分けられ、**割合**をタップすると一定の割合で支払えます。
3. **今回の支払い** — **−** と **+** で、この支払いの対象となる各商品の数量を選びます。

</JourneyShot>

## 支払い完了を確認する {#paid}

未払いの金額がなくなると販売が完了し、レシートが用意されます。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="現金販売後の支払い完了画面：渡すお釣り、支払額と預かり金額、標準レシートが選択されたテンプレート選択欄、プリンター選択欄、レシートのプレビュー、レシートをメール送信、PDF をダウンロード、レシートを印刷、新規販売の各ボタン">

1. **お釣り** — 返す金額です。
2. **支払い内容** — 金額と支払い方法です。
3. **テンプレート** — この販売に使うレシートです。ここでの選択は今回の販売にのみ適用されます。[レシートのカスタマイズ](../../receipts/customise.mdx)をご覧ください。
4. **プリンター** — 印刷先です。[レシートを印刷](../../receipts/at-checkout.mdx#print-receipt)をご覧ください。
5. **プレビュー** — 印刷されるレシートの見た目です。
6. **レシートを印刷** — レシートを印刷します。
7. **レシートをメール送信** — 顧客にレシートを送信します。[レシートをメール送信](../../receipts/at-checkout.mdx#email-receipt)をご覧ください。
8. **新規販売** — 次の顧客に向けてカートを空にし、既定の顧客に戻します。

</JourneyShot>

**PDF をダウンロード**は、レシートをファイルとして保存します。接続が必要です。上部の **✕** でも、**新規販売**と同様に販売を終了できます。

支払い完了画面をスキップして自動印刷する設定でも、各販売の後にレシートは印刷されます。[自動印刷または支払い完了画面のスキップ](../../receipts/at-checkout.mdx#automatic-receipt-options)をご覧ください。

## 問題が起きた場合 {#goes-wrong}

**カートに間違った商品が入っています。** 明細の合計をタップしてから、**削除**を押します。削除も間違いだった場合は、表示されたメッセージの **元に戻す**ボタンを使えます。[明細項目](../cart/line-items.mdx#remove-item)をご覧ください。

**顧客が購入を取りやめました。** 会計画面の **✕** を押すと、注文を残したままカートに戻ります。販売を取りやめるには、**チェックアウト**の横の **⋮** を押してから **無効化**を押します。[無効化](../cart/order-actions.mdx#void)をご覧ください。支払いを受け付け済みの場合、**✕** を押すとまず **支払いをキャンセル**が開きます。[支払いの取り消し](./cancelling-a-payment.mdx)をご覧ください。

**現金が足りません。** 受け取った金額を入力します。ボタンには、例えば **現金で $20.00 を受け取る · 残り $25.00** と表示されます。押すと支払いが記録され、残額は未払いのまま残ります。残額はどのタイルでも受け付けられます。[残額の一部を受け取る](./taking-a-payment.mdx#part-payment)をご覧ください。

**接続が切れました。** 店舗にすでに登録されている販売、つまり会計画面の商品一覧の上に注文番号がある販売では、現金での支払いを完了できます。オフライン中に開始した販売は、接続が回復するまで支払えません。レシートには実際の時刻とレジが保持され、接続が回復すると注文が同期されます。オフラインで支払いを受け付けられる方法がない場合、会計画面に **接続がありません**と表示され、販売が未完了の注文に保存されたことが示されます。**レジに戻る**を押してください。[オフラインモード](../../getting-started/offline.mdx)をご覧ください。

:::info WCPOS Pro をお使いの場合
ペアリング済みのカスタマーディスプレイには、会計操作に合わせてカートの内容が顧客に表示されます。
:::
