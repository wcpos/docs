顧客が注文の一部を支払った後で、購入を取りやめることがあります。**支払いをキャンセル**を使うと、受け付けた支払いが取り消され、返す金額が表示され、注文がカートに戻ります。このページでは、$45.00 の注文で現金 $20.00 を受け取った場合を例に説明します。

支払いを1件だけ取り消して残りの支払いを続ける場合は、[支払いを1件だけ取り消す](#cancel-one)をご覧ください。完了済みの販売を取り消す場合は、払い戻しを行います。[レジでの払い戻し](../refunds.mdx)をご覧ください。

## 支払いのキャンセル画面を開く {#open}

注文で支払いを受け付けると、支払いパネルの上部に **支払いをキャンセル**が表示されます。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-32, 0], [185, -14], [-50, 0], [10, 40], [-34, 0]]} alt="$45.00 の注文で現金 $20.00 を受け取った後の支払いパネル：支払いをキャンセルボタン、売上確定済みの現金支払い、残額 $25.00、閉じるボタン、キーパッドの上に現金 $20.00 と表示された支払い済みバッジ">

1. **支払いをキャンセル** — この注文のすべての支払いを取り消す画面を開きます。
2. **支払い** — これまでに受け付けた支払いと、その方法・ステータスです。
3. **残額** — まだ支払われていない金額です。
4. **閉じる** — 支払いを受け付けた後は、会計画面を終了せずに同じ取り消し画面を開きます。カードリーダーが支払いを処理中の場合は、何も取り消さずに会計画面を終了します。
5. **支払い済みバッジ** — これまでに受け付けた支払いです。1件なら **現金 $20.00**、2件になると **2件支払い済み · $30.00** のように表示されます。押すと支払いを1件だけ取り消せます。[支払いを1件だけ取り消す](#cancel-one)をご覧ください。

</JourneyShot>

カードリーダーが支払いを処理中は、**支払いをキャンセル**は表示されません。パネルの **端末でキャンセル**を押すか、レジに **リーダーでキャンセルしてください**と表示された場合はリーダー本体で取り消します。[カードリーダーでの支払い](./taking-a-payment.mdx#card-reader)をご覧ください。

## 返す金額を確認する {#check}

**支払いをキャンセル**または閉じるボタンを押します。レジに **この支払いをキャンセルしますか？** と表示され、取り消しを実行する前に、各支払いに必要な処理が一覧で示されます。

:::warning 取り消しが完了するまで現金を返さないでください
取り消しには店舗への接続が必要です。メッセージが表示されて会計画面に留まる場合、少なくとも1件の支払いは取り消されず、有効なままです。取り消しが成功するまで現金は返さないでください。[問題が起きた場合](#goes-wrong)をご覧ください。
:::

各行には、次のいずれかが表示されます。

- その金額を現金で顧客に **返却**します。
- 支払い方法側でその金額を **無効化**します。取り消し時にレジが処理するため、現金を返す必要はありません。注文全体を削除する **⋮** 内の **無効化**とは異なります。
- その金額は **受領済みのため無効化できません**。注文から払い戻してください。通常は、すでに顧客に請求済みのカード支払いです。管理者に WordPress での払い戻しを依頼してください。[支払いを無効化できない](#goes-wrong-taken)をご覧ください。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-26, 0], [-22, 0], [156, 0]]} alt="この支払いをキャンセルの画面：顧客に現金 $20.00 を返すよう示す行と、支払いの受付を続けるボタン、キャンセルして無効化ボタン">

1. **返す金額** — 支払いごとに1行ずつ表示されます。ここでは、返却する現金 $20.00 です。
2. **支払いの受付を続ける** — 支払いパネルに戻ります。何も変更されません。
3. **キャンセルして無効化** — 支払いを取り消します。

</JourneyShot>

## キャンセルして無効化する {#cancel}

**キャンセルして無効化**を押します。すべての支払いが取り消されると会計画面が閉じ、カートに戻ります。注文は未完了のまま、内容もすべて残っています。カートが表示されたら、画面に示されていた現金を返してください。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[60, -36], [270, 0], [12, -36]]} alt="支払い取り消し後のカート：顧客と商品はそのままで、チェックアウトボタンに全額の $45.00 が表示されている">

1. **顧客** — 注文の顧客はそのまま維持されます。
2. **チェックアウト** — 再び合計全額が表示されます。押すと新たに支払いを受け付けられます。
3. **チェックアウト**の横の **⋮** — 顧客が注文を取りやめる場合は、これを押してから **無効化**を押します。[注文を無効化する](../cart/order-actions.mdx#void)をご覧ください。

</JourneyShot>

会計画面をもう一度開くと、取り消した支払いは取り消し線付きで注文に残り、**キャンセル**と表示されます。支払額には含まれなくなり、**支払い済み**は $0.00 に戻り、全額が未払いになります。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[210, -14], [192, -1], [-45, 0]]} alt="同じ注文で再び開いた支払いパネル：現金 $20.00 の支払いに取り消し線とキャンセルの表示があり、支払い済み $0.00、残額 $45.00 と表示されている">

1. **キャンセル** — 何があったかを確認できるよう、取り消した支払いは注文の記録に残ります。
2. **支払い済み** — $0.00 に戻ります。取り消した支払いは含まれません。
3. **残額** — $45.00 全額が再び未払いになります。

</JourneyShot>

## 支払いを1件だけ取り消す {#cancel-one}

[分割払い](./split-payments.mdx)の一部など、1件の支払いだけが間違っていて他は残したい場合は、その1件だけを取り消します。会計画面は開いたまま、その金額が再び未払いになります。ここでは、$45.00 の注文に対して現金で $20.00、続いて $10.00 を受け取り、その $10.00 を取り消します。

キーパッドの上にある支払い済みバッジ（[最初の画像](#open)の注釈 5）を押します。支払いが2件ある場合は **2件支払い済み · $30.00** と表示されます。受け付けた支払いの一覧が開きます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[170, 0], [-34, 0], [-36, 0], [-32, 0]]} alt="支払い済みバッジを開いた支払いパネル：現金 $20.00 と $10.00 の支払いが並び、それぞれに支払いをキャンセルボタンがある。下に非表示、上部にすべての支払いを取り消す支払いをキャンセルボタンがある">

1. **支払い** — 受け付けた支払いごとに1行ずつ表示されます。分割払いでは、その支払いの対象商品も表示されます。
2. **支払いをキャンセル** — この支払いだけを取り消します。
3. **非表示** — 一覧を再び折りたたみます。
4. 上部の **支払いをキャンセル** — 1件だけでなく、すべての支払いを取り消します。[支払いをキャンセルを開く](#open)をご覧ください。

</JourneyShot>

該当行の **支払いをキャンセル**を押します。レジに **この支払いをキャンセルしますか？** と表示され、[すべての支払いの取り消し](#check)と同じ表現で返す金額が示されます。ここでは **顧客に現金 $10.00 を返却してください**と表示されます。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[-36, 0], [101, -40]]} alt="現金 $10.00 の支払いに対する「この支払いをキャンセルしますか？」の確認画面。キャンセルボタンと支払いをキャンセルボタンがある">

1. **キャンセル** — 支払いを維持し、確認画面を閉じます。
2. **支払いをキャンセル** — この支払いを取り消します。

</JourneyShot>

取り消しの処理中に店舗から応答がないと表示された場合は、[店舗から応答がない](#goes-wrong-unanswered)をご覧ください。

**支払いをキャンセルしました**と表示され、会計画面は開いたままになります。現金 $10.00 を返してから、残りの支払いを受け付けます。

支払いは取り消し線付きで注文に残り、**キャンセル**と表示されます。残っている支払いだけが **支払い済み**に含まれます。分割払いでは、取り消した支払いの対象商品を再び支払えるようになります。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[210, -14], [192, -1], [-45, 0]]} alt="$10.00 の支払いを取り消した後の支払いパネル：$10.00 の行に取り消し線とキャンセルの表示があり、支払い済み $20.00、残額 $25.00 と表示されている">

1. **キャンセル** — 記録に残っている $10.00 の支払いです。
2. **支払い済み** — $20.00 だけが含まれます。
3. **残額** — $25.00 が再び未払いになります。

</JourneyShot>

支払いを取り消せない場合は、以下のいずれかのメッセージが表示され、支払いは有効なままです。

## 問題が起きた場合 {#goes-wrong}

### オフラインになっている {#goes-wrong-offline}

レジに次のように表示されます：**これらの支払いをキャンセルするには店舗への接続が必要です。何もキャンセルされていません。オンラインになってから再試行してください。**

店舗に再接続してから、もう一度取り消してください。[接続が必要な操作](../../getting-started/offline.mdx#what-requires-a-connection)をご覧ください。

### リーダーでの支払いがまだ確定していない {#goes-wrong-reader}

レジに次のように表示されます：**このリーダーでの支払いは、確定するまでキャンセルできません。**

レジがオンラインに戻り、リーダーでの支払いが店舗に届くまで待ってから取り消します。リーダーでの支払いがオフラインで承認された場合や、リーダーでの支払いがある注文でレジがオフラインになっている場合に表示されます。

### 一部の支払いが無効化されなかった {#goes-wrong-not-voided}

レジに次のように表示されます：**一部の支払いを無効化できなかったため、その金額はまだ保持されています。再試行するか、注文から払い戻してください。**

もう一度取り消してください。完了するまで現金は返さないでください。

失敗が続く場合は、メッセージに表示されたコードを管理者に伝えてください。[PAYMENT221](../../error-codes/PAYMENT221.mdx) は店舗側が拒否したことを、[PAYMENT201](../../error-codes/PAYMENT201.mdx) は処理が完了したかどうかレジで確認できなかったことを意味します。

### 店舗から応答がない {#goes-wrong-unanswered}

レジに次のように表示されます：**直前の支払いに対して店舗から応答がありません。再試行して確認してください。二重に支払いが行われることはありません。**

数秒お待ちください。取り消しの処理中に表示されることがあり、店舗から応答があると消えます。表示が残る場合は **再試行**を押してください。取り消しを再送しますが、店舗側で二重に処理されることはありません。

### 支払いを無効化できない {#goes-wrong-taken}

レジに次のように表示されます：**受領済みの金額は無効化できないため、この販売は未完了のままです。注文から払い戻してください。** 通常は、すでに顧客に請求済みのカード支払いです。

この支払いはレジでは払い戻せません。レジの **払い戻し**は、販売が終了した注文（完了、処理中、保留中）にのみ表示され、この販売は未完了のままだからです。販売は未完了のままにし、管理者に WordPress の注文から払い戻すよう依頼してください。[払い戻し操作が表示される条件](../../orders/refunds.mdx#when-the-refund-action-appears)をご覧ください。支払いが残っている間は、注文を **キャンセル**にすることもできません。

### 無効化しても注文を削除できない {#goes-wrong-void}

レジに次のように表示されます：**この注文には支払いがあります。支払いパネルのキャンセルで取り消してから、注文を無効化してください。**

会計画面を開き、支払いを取り消してから、注文を無効化します。
