お客様はレジではなくカードリーダーでチップを追加します。レジが支払額を送信すると、リーダーがお客様にチップの有無と金額を尋ね、レジがリーダーで受け取った金額を記録します。レジにチップのボタンはありません。

## チップを含むカード決済を受け付ける {#take-a-tip}

:::info Proの機能
カードリーダーでチップを受け取るには、[WCPOS Pro](../../getting-started/pro-license.mdx)とチップの入力に対応したリーダーが必要です。
:::

始める前に、[リーダーがチップの入力に対応しているか](#which-readers)確認してください。**レジの開閉**が有効な場合は、先に[レジを開いて](../register/index.mdx#open)ください。レジを閉じている間は支払いを記録できません。

1. **チェックアウト**を押し、リーダーのタイルをタップします。[カードリーダーでの決済](./taking-a-payment.mdx#card-reader)を参照してください。
2. **…を…に送信**を押します。ボタンには支払額と決済方法が表示され、レジがその金額をリーダーに送信します。
3. お客様がリーダーでチップの金額、またはチップなしを選び、支払います。
4. レジの支払いパネルでは、該当する支払いの行にリーダーが受け取った総額が表示され、その下に**チップ：** とチップの金額が表示されます。

注文に**チップ**という手数料の明細が追加され、注文合計がチップの分だけ増えます。チップはすでに支払い済みです。レシートには、注文のほかの手数料と一緒に記載されます。チップには課税されません。

<details>
<summary>チップへの課税（開発者向け）</summary>

チップへの課税が必要な店舗は、`wcpos_payment_tip_fee_taxable`フィルターで有効にできます。この場合、税額はチップから差し引かれるため、お客様の支払額はリーダーで選んだ金額のままです。

</details>

## チップの入力に対応するリーダー {#which-readers}

| 決済方法 | チップの入力に対応するリーダー |
|---|---|
| [Stripe Terminal](../../payment/gateways/stripe-terminal.mdx) | Stripeダッシュボードでリーダーのチップ機能を有効にしたWisePad 3、WisePOS E、S700、S710。M2とTap to Payは対応していません。 |
| [SumUp Terminal](../../payment/gateways/sumup-terminal.mdx) | WCPOSアプリとペアリングしたBluetoothリーダー。インターネット接続型のリーダーは対応していません。 |
| [Mollie Terminal](../../payment/gateways/mollie-terminal.mdx) | すべてのリーダー。 |

次の決済方法ではチップの入力を求めません。

- [Square Terminal](../../payment/gateways/square-terminal.mdx)
- [PayArc Terminal](../../payment/gateways/payarc-terminal.mdx)
- [Authorize.net Tap to Pay](../../payment/gateways/authorize-net-terminal.mdx)：Authorize.net アプリでチップを追加すると、決済に失敗します
- [Windcave Terminal](../../payment/gateways/windcave-terminal.mdx)
- [Mercado Pago Terminal](../../payment/gateways/mercadopago-terminal.mdx)
- [PayPal Reader (Zettle)](../../payment/gateways/paypal-reader.mdx)

**カード**のタイルは、別途用意した端末で受け付けたカード決済を記録するものです。チップは含まれません。[決済方法](./payment-methods.mdx)を参照してください。

## ドロワーからチップを支払う {#pay-out-tips}

スタッフにチップを現金で渡すときは、ドロワーの金額が合うように出金として記録します。この機能は無料版のプラグインでも利用できます。**レジの開閉**を有効にする必要があります。[現金の入出金](../register/index.mdx#cash-movements)を参照してください。

1. レジバーの端にあるアバターをタップし、**ドロワー内の現金**、**出金**の順にタップします。
2. 渡す金額をテンキーで入力します。
3. **理由**の下にある**チップ**をタップします。入力されるのは理由で、金額ではありません。
4. **…を出金**を押します。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[180, 0], [370, 0], [-4, 0], [0, 0], [0, 0], [100, 0], [-14, -36]]} alt="出金シート：テンキーで入力した二ドル、出金前後のドロワー内の金額、選択して入力された理由の「チップ」、および「$2.00を出金」ボタン">

1. **金額** — 取り出す金額です。入力に合わせて表示されます。
2. **ドロワー内の現金** — レジ、現在あるはずの現金額、今回の出金後に残る金額です。
3. **テンキー** — 金額を入力します。キーボードも使えます。
4. **チップ** — 出金の理由です。タップすると理由欄に入力され、もう一度タップすると消去されます。
5. **その他…** — 欄を空にしてカーソルを置き、理由を自由に入力できるようにします。
6. **理由** — すべての出金に必要です。入力しないと、シートに**理由を追加**と表示されます。
7. **$2.00を出金** — 金額が表示されます。押すと出金が記録されます。**キャンセル**を押すと、ドロワーの記録は変わりません。

</JourneyShot>

記録を確認するには、**ドロワー内の現金**をタップしてレジパネルを開き、**ドロワー内の予定現金額**の行をタップして内訳を開きます。**出金**の下に、理由とともに出金が表示されます。誤った出金なら、その項目の**無効化**を押します。無効化できるのはレジを開いていて、現金を計数していないときだけです。無効化した出金は元に戻せないため、再入力してください。[問題が発生した場合](../register/index.mdx#goes-wrong)を参照してください。

## 問題が発生した場合 {#goes-wrong}

**リーダーがチップの入力を求めませんでした。** [対応表](#which-readers)を確認してください。決済方法やリーダーによっては、チップの入力を求めません。Stripeの場合は、Stripeダッシュボードでリーダーのチップ機能を有効にしてください。

**支払いに失敗しました：端末が異なる金額を確定しました。** チップに対応しない決済方法で、リーダーがレジから送信した額より多く受け取ったため、レジはその支払いを失敗とし、注文の支払額に算入しませんでした。

:::warning
お客様に再度請求する前に、決済サービスで支払いを確認してください。確認しないと二重請求になる可能性があります。
:::

決済サービスに請求が表示されている場合は、そちらで払い戻してください。レジでは失敗した支払いを払い戻せません。注文の支払額は未払いのままなので、利用できる決済方法で改めて支払いを受け付けてください。
