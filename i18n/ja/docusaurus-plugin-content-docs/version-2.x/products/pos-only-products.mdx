レジだけで販売する商品もあれば、オンラインだけで販売する商品もあります。**POS 専用商品を有効にする** をオンにすると、すべての商品に **POS の表示設定** が追加され、次の三つから選べます。

| POS の表示設定 | ウェブサイト | POS |
|------------|--------------|-----|
| **POS とオンライン**（すべての商品の初期設定） | 表示 | 表示 |
| **POS のみ** | 非表示 | 表示 |
| **オンラインのみ** | 表示 | 非表示 |

:::note WP Admin で設定します
POS の表示設定は WP Admin で行います。POS はその設定に従うだけで、レジで変更することはできません。レジに商品が見当たらない場合は、[問題が起きた場合](#troubleshooting) を参照してください。
:::

## 機能を有効にする {#enabling-the-feature}

WP Admin の **POS > 設定 > 一般** を開きます。**商品** の **POS 専用商品を有効にする** をオンにします。切り替えるとすぐに保存されます。すべての商品に **POS の表示設定** が付き、未設定の商品は **POS とオンライン** になります。以前この機能を有効にして設定を保存した商品には、保存済みの設定が適用されます。

すべての商品を両方で販売する場合は、オフのままにしてください。オフのときは POS の表示設定で非表示になる商品はありません。WooCommerce 自体の表示設定は引き続き適用されます。

:::warning
この機能を再びオフにするか WCPOS を無効化すると、POS のみの商品が、WooCommerce の表示設定で許可される範囲でウェブサイトに再表示されます。[機能を無効にする](#switch-off) を参照してください。
:::

## 商品の表示設定を変更する {#setting-product-visibility}

### 商品を個別に設定する {#individual-products}

1. WP Admin で **商品** を開き、対象の商品を開きます。
2. **公開** ボックスで、**POS の表示設定** の横にある **編集** を押します。
3. **POS とオンライン**、**POS のみ**、**オンラインのみ** のいずれかを選び、**OK** を押します。
4. **更新** を押します。

### 複数の商品を一括設定する {#bulk-editing}

1. WP Admin で **商品** を開き、対象の商品にチェックを入れます。
2. **一括操作** で **編集** を選び、**適用** を押します。
3. **POS の表示設定** で設定を選びます。**— 変更なし —** のままにすると、各商品の現在の設定が維持されます。
4. **更新** を押します。

### バリエーション {#variable-products}

各バリエーションには、**バリエーション** 内の個別パネルに専用の **POS の表示設定** があります。設定が終わったら **変更を保存** を押します。すべての色をオンラインで販売し、一部だけをレジで販売したり、特定のサイズを店頭専用にしたりできます。バリエーション商品全体を切り替えるには、商品自体の **POS の表示設定** を変更します。**オンラインのみ** の商品はレジにタイルが表示されず、**POS のみ** の商品はすべてのバリエーションとともにオンラインショップから非表示になります。

### 設定した商品を見つける {#find-them}

商品一覧の表の上部に、**公開済み** の横に **POS のみ** と **オンラインのみ** の二つの表示切り替えが件数付きで追加されます。クリックすると、該当する商品だけを一覧表示します。

## POS での動作 {#how-it-affects-the-pos}

**オンラインのみ** の商品はレジに一切表示されません。商品パネルにも検索結果にも表示されず、バーコードをスキャンすると **バーコードが見つかりません** と表示されます。**POS のみ** と **POS とオンライン** の商品は通常どおり販売できます。

商品の表示設定を変更すると、POS が次に店舗の変更を確認したときに反映されます。オンラインのみの商品は非表示になり、設定を戻すと再び表示されます。今すぐ確認するには、商品数の横の矢印を押します。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[190, 0], [0, 0], [0, 0], [0, -40], [-50, 0]]} alt="検索後の商品パネル。在庫ありフィルターが有効で、商品タイルが一つ、商品数が表示されています。件数の横には同期メニューが開き、同期とクリアして再読み込みが表示されています">

1. **商品を検索** — 店舗にも問い合わせますが、オンラインのみの商品は検索結果に含まれません。[検索と絞り込み](../pos/product-panel/search-filtering.mdx#how-search-works) を参照してください。
2. **設定** — **在庫切れの商品を表示** があります。[表示設定](../pos/product-panel/display-settings.mdx#show-out-of-stock-products) を参照してください。
3. **在庫あり** — 在庫切れの商品を非表示にします。商品がないと判断する前に、× を押して解除してください。[在庫状況](../pos/product-panel/search-filtering.mdx#stock-status) を参照してください。
4. **商品タイル** — POS のみと POS とオンラインの商品がここに表示されます。
5. **商品数** — この端末で条件に一致する商品数です。ここでは **1 商品**、一覧全体では **259 件中 20 件を表示** と表示されます。横の矢印を押すと、今すぐ変更を確認できます。長押しすると、図のように **同期** と **クリアして再読み込み** のメニューが開きます。後者は検索とフィルターを消去し、商品を再度ダウンロードします。[パネルの下部](../pos/product-panel/display-settings.mdx#footer) を参照してください。

## ウェブサイトでの動作 {#where-pos-only-products-stay-visible}

**POS のみ** の商品は、買い物客に対して非表示になります。

- オンラインショップ、カテゴリーページ、検索、関連商品、商品ブロック、フィード、サイトマップのいずれにも掲載されません。
- カートへの追加やオンラインでの購入はできません。WooCommerce 自体の **非表示** と同様に、直接リンクから商品ページを開くことはできますが、そのページでもカートに追加できません。
- **POS のみ** のバリエーションは、商品ページの選択肢から除外されます。そのほかのバリエーションについては、商品が引き続きオンラインで表示されます。

<details>
<summary>カタログの表示設定と、POS のみの商品が引き続き表示される場所</summary>

WCPOS は、POS のみの商品の WooCommerce の **カタログの表示設定** を **非表示** にして、商品を表示しないようにします。商品が POS のみである間は、公開ボックスの **カタログの表示設定** が **非表示** に固定され、*POS のみの商品はオンラインカタログや検索には表示されません。* と表示されます。**POS とオンライン** または **オンラインのみ** に戻すと、WCPOS は以前のカタログの表示設定を復元します。**更新** を押す前に、復元される設定が公開ボックスに表示されます。表示以外の設定にしたことがない商品は **ショップと検索結果** に戻ります。別のカタログ表示設定にしたい場合は、更新後に変更してください。WooCommerce ではバリエーション自体にカタログの表示設定がないため、バリエーションでは固定される設定はありません。

非表示のルールは買い物客にのみ適用されます。POS のみの商品は、店舗の運営に使う次の場所では引き続き表示されます。

- 商品一覧や商品エディターなどの **WP Admin**。
- **WooCommerce Analytics**。POS のみの商品のカテゴリーで絞り込んだレポートにも、その売上が表示されます。
- **POS** 自体。

</details>

## 機能を無効にする {#switch-off}

**POS 専用商品を有効にする** をオフにすると、POS の表示設定による非表示は解除されます。WooCommerce 自体の表示設定は引き続き適用されます。オンラインのみの商品は、POS が次に変更を確認したときに再表示されます。POS のみの商品は以前のカタログの表示設定に戻るため、自分で非表示にしていた商品は非表示のままです。各商品の選択は保存されているので、再びオンにすると保存済みの設定が使われ、同じ商品が再び非表示になります。

WCPOS を無効化した場合も、すべての POS のみの商品が以前のカタログの表示設定に戻り、ウェブサイトに再表示されるようになります。

## 活用例 {#when-to-use-this-feature}

- **店頭で販売するギフトカード** — レジで有効化する実物のカードです。**POS のみ** に設定します。
- **オンラインの予約注文** — まだ入荷していない商品を、お客様がオンラインで注文します。レジに不要な商品が並ばないよう、**オンラインのみ** に設定します。
- **一つの店舗で卸売と小売を行う** — 取引先向けの卸売専用商品は **オンラインのみ**、店頭限定商品は **POS のみ**、それ以外は **POS とオンライン** に設定します。
- **ダウンロード商品とオンライン限定の特典** — 店頭では販売しないデジタル商品やウェブ限定のお得な商品です。**オンラインのみ** に設定します。
- **店頭限定の特売品** — レジだけで販売する販促商品です。**POS のみ** に設定します。

## 問題が起きた場合 {#troubleshooting}

**オンラインのみの商品が POS に表示される。** 商品数の横の矢印を押して変更を確認してください。それでも表示される場合は、矢印を長押しして **クリアして再読み込み** を選びます。

**POS に商品が見当たらない。** 検索内容を消去し、**在庫あり** を含めてフィルターバーを確認してください。次に WP Admin で商品を開いて **POS の表示設定** を確認します。バリエーションの場合は、商品自体の設定も確認してください。

**ある端末には商品が表示されるが、別の端末には表示されない。** 検索とフィルターは端末ごとに保持され、変更が取り込まれるのはオンラインの間だけです。[商品の同期](./sync.mdx#one-device) を参照してください。

**POS のみの商品がショップ、カテゴリー、検索に表示される。** 直接リンクから開けるのは想定どおりの動作です。ここでは、買い物客が商品を見つけられる状態について説明します。

1. 商品を開き、公開ボックスの **カタログの表示設定** を確認してください。POS のみの商品では **非表示** となります。
2. 別の設定になっている場合は、**更新** を一度押すと WCPOS が再び **非表示** に設定します。それでも変わらない場合は、プラグインやカスタムコードが設定を変更しています。[開発者向け](#developers) を参照してください。
3. **非表示** になっている場合は、ページがキャッシュされている可能性が高いです。キャッシュプラグインまたは CDN のキャッシュを消去してください。

**商品に POS の表示設定がない。** **POS 専用商品を有効にする** がオフになっています。**POS > 設定 > 一般** でオンにしてください。

## 開発者向け {#developers}

<details>
<summary>POS のみの商品に関するフィルター</summary>

POS のみの商品は、ブロックのカートとチェックアウトが使う WooCommerce Store API と、WooCommerce REST API の商品およびバリエーションの一覧（`/wc/v1` から `/wc/v3`）から除外されます。`wp wc product list` などの WP-CLI コマンドでは、引き続き表示されます。

**`wcpos_hide_pos_only_products`** は、商品クエリから POS のみの商品を除外するかどうかを決めます。デフォルトの判定と、実行直前の `WP_Query` を受け取ります。判定はショップの表示側では true、WP Admin、WP-CLI、WooCommerce Analytics、POS では false です。独自のコンテキストで POS のみの商品を表示するには、`false` を返します。

```php
add_filter( 'wcpos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

**`wcpos_pos_only_catalog_visibility`** は、WCPOS が POS のみの商品に書き込むカタログの表示設定を指定します。`hidden` と商品を受け取ります。WooCommerce のカタログ表示設定のキー（`visible`、`catalog`、`search`、`hidden`）のいずれかを返すと、その値が適用されます。カタログの表示設定を自分で管理するには `null` を返します。変更されるのは WCPOS が **カタログの表示設定** に書き込む値だけです。前述のショップ側のルールは引き続き適用されるため、POS のみの商品をオンラインのどこかに表示する場合は、`wcpos_hide_pos_only_products` と組み合わせてください。

```php
add_filter( 'wcpos_pos_only_catalog_visibility', function ( $visibility, $product ) {
    if ( has_term( 'club-stock', 'product_cat', $product->get_id() ) ) {
        return null; // I manage catalog visibility for these myself.
    }
    return $visibility;
}, 10, 2 );
```

**`wcpos_default_product_visibility`** は、エディターで新しい商品に最初に設定される **POS の表示設定** を指定します。`''`（**POS とオンライン**）と投稿を受け取ります。新しい商品を別の設定で開始するには、`pos_only` または `online_only` を返します。

WCPOS 2.0 より前は、これらのフィルターは `woocommerce_pos_hide_pos_only_products`、`woocommerce_pos_pos_only_catalog_visibility`、`woocommerce_pos_default_product_visibility` という名前でした。旧名も引き続き使えますが、2.0 で非推奨となり、早くても 2.2 で削除されます。[フックの命名](../extensions/index.mdx#hook-naming) を参照してください。

</details>
