# PayArc Terminal ゲートウェイ {#payarc-terminal-gateway}

PayArc Terminal は、レジから PayArc PAX 端末に決済を送信します。お客様が端末で支払いを行い、PayArc が決済を確認すると、レジに支払いが記録されます。

このページでは、まずレジでの操作を説明します。ゲートウェイの設定方法は、[PayArc Terminal の設定](#setup)をご覧ください。

:::info Pro 機能
PayArc Terminal には [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0 以降が必要です。
:::

## カード決済を受け付ける {#take-payment}

:::note 先にレジを開いてください
**レジの開閉**が有効な場合、レジが閉じている間は支払いを記録できず、すでにカードで受け取った金額は払い戻す必要があります。設定については、[レジ](../../settings/wp-admin/registers.mdx#one-register)をご覧ください。
:::

カートで**チェックアウト**を押します。**支払い**タブには、他の支払い方法と並んで PayArc Terminal のタイルが表示されます。

1. **PayArc Terminal** のタイルをタップします。
2. テンキーの上にある**端末: …** で端末名を確認します。端末が複数ある場合は、**変更**を押し、そのカウンターの端末をタップします。選択した端末は次回もレジで使用されます。
3. 未払い残高の一部をカードで支払う場合は、その金額を入力します。残りは未払いとなり、別の支払いで受け取ります。
4. **… を PayArc Terminal に送信**を押します。レジに**端末で処理中**と表示され、**送信済み**、**端末で処理中**、**承認済み**、**売上確定済み**の四段階で進行状況が示されます。
5. お客様が端末で支払いを行います。売上が確定し、未払い残高がなくなるとレシートが開きます。残高がある場合は、別のタイルで残りの支払いを受け付けます。

進行状況の下にある**詳細**を開くと、送信時刻、端末への到達時刻、承認金額などの決済ログを確認できます。決済には、カードブランド、下 4 桁、カードの読み取り方法、PayArc の承認コードが保存されます。

この端末にはチップの入力画面はありません。対応する端末については、[チップ](../../pos/checkout/tips.mdx)をご覧ください。

### 決済をキャンセルする {#cancel}

お客様が支払う前に、**端末でキャンセル**を押します。レジは端末からの確認を待ち、確認後に**決済がキャンセルされました**と表示します。

カードの読み取りがすでに始まっている場合、PayArc がキャンセルを受け付けずに決済を完了することがあります。レジは確認を続け、結果を表示します。待機中は**キャンセル中 — 端末の確認を待っています**と表示され、**この決済を解放**を選べます。解放すると、店舗側で端末の確認を続けながら、その注文を別の方法で支払えるようになります。

:::warning
拘束を解除しても決済はキャンセルされず、端末で支払いが完了する可能性があります。別の支払いを受け付ける前に、端末の結果を確認してください。
:::

## 決済で問題が起きた場合 {#goes-wrong}

:::warning
**端末が異なる金額を確定しましたか？** 決済をやり直さないでください。まず端末、注文、PayArc ダッシュボードを確認してください。
:::

<Accordion>
  <AccordionItem question="決済失敗: カードが拒否されました">

  **再試行**を押すと端末に再送信します。別のタイルで支払う場合は、**別の方法を選択**を押します。

  </AccordionItem>
  <AccordionItem question="決済が失敗し、PayArc のメッセージが表示される">

  端末の電源が入っていない、またはオンラインでないなどの理由で、PayArc が決済を拒否しました。端末を確認してから、**再試行**を押してください。

  </AccordionItem>
  <AccordionItem question="タイムアウト — 決済がキャンセルされました">

  5 分以内に支払いが行われなかったか、端末がカードの読み取りを待ったままになっていました。端末を確認してから、**再試行**を押してください。

  </AccordionItem>
  <AccordionItem question="PayArc Terminal のタイルがグレー表示される">

  レジのタイルの下に理由が表示されます。すべての理由については、[タイルを使用できない場合](../index.mdx#unavailable-tiles)をご覧ください。

  - **PayArc Terminal の端末が設定されていません** — 店舗にこのゲートウェイ用の端末がありません。管理者が [PayArc Terminal の設定](#setup)の手順 4 で追加します。
  - **注文 #… で使用中** — 端末が別の注文の決済を処理しています。その決済を完了またはキャンセルするか、**変更**を押して別の端末を選んでください。
  - **接続が必要です** — レジがオフラインです。端末決済は店舗のサイトを経由するため、別の種類の支払いを受け付けるか、接続の復旧を待ってください。

  </AccordionItem>
  <AccordionItem question="接続が不安定です。再試行を続けています">

  このメッセージは**詳細**ログに表示されます。レジは確認を続けます。端末では決済が続いているため、画面を開いたままにしてください。

  </AccordionItem>
  <AccordionItem question="決済が進まない、または決済サービスから応答がないとレジに表示される">

  [カードリーダーの決済が進まない場合](../index.mdx#card-reader-problems)をご覧ください。

  </AccordionItem>
  <AccordionItem question="決済の待ち時間が長すぎる">

  - 端末の画面を確認し、決済画面は開いたままにしてください
  - **5 分**が経過するとレジは処理を停止し、**タイムアウト — 決済がキャンセルされました**と表示します
  - 決済をやり直す前に、端末、注文メモ、PayArc ダッシュボードを確認してください

  </AccordionItem>
  <AccordionItem question="現在の PayArc 認証情報では、この注文の以前の PayArc Terminal 決済を読み取れません">

  - 別の方法で支払いを受け付けるか、管理者に相談してください。この注文には、モードまたは認証情報を変更する前の決済が含まれています
  - 管理者が PayArc ダッシュボードで、その決済を受け付けたモードに切り替えて確認します
  - この注文で再び PayArc を使うには、管理者が PayArc を元のモードに戻して**この認証情報で接続**をクリックした後、レジの画面を再読み込みしてください

  </AccordionItem>
</Accordion>

## PayArc 決済を払い戻す {#refunds}

全額または一部の払い戻しは、元の決済を受け付けた端末に送信されます。

1. POS で注文の払い戻し画面を開きます。[払い戻し](../../pos/refunds.mdx)をご覧ください。
2. **PayArc Terminal に払い戻し**を選び、**払い戻しを処理**を押します。
3. PayArc が端末に払い戻しを送信し、端末で承認または拒否されます。端末が応答するまで払い戻しは保留となり、結果が注文メモに追加されます。

WP Admin で WooCommerce の **PayArc Terminal 経由で … を払い戻し**ボタンを使う場合も、同じように処理されます。

払い戻しが保留のままの場合は、再度払い戻す前に PayArc ダッシュボードを確認してください。

<details>
<summary>払い戻しに PayArc が応答しない場合</summary>

店舗のサイトは、同じリクエストキーで 2 分ごとに最大 5 回再試行します。そのため、PayArc は各再試行を同じ払い戻しとして扱います。それでも応答がない場合は、PayArc ダッシュボードを確認するようスタッフに通知します。

</details>

<details>
<summary>古いバージョンで受け付けた決済</summary>

**この PayArc 決済は、プラグイン独自の注文支払いパネルで受け付けたものです。** WCPOS 2 より前の拡張機能バージョン 0.1 で受け付けた決済のため、ゲートウェイからは払い戻せません。PayArc ダッシュボードまたは端末で払い戻しを行い、WooCommerce の **… を手動で払い戻し**で記録してください。

</details>

## PayArc Terminal の設定 {#setup}

管理者が WP Admin で一度ゲートウェイを設定し、その後、各レジで使用する端末を選びます。

<details>
<summary>設定前に必要なもの</summary>

### 要件 {#requirements}

MID、ClientSecret、SecretKey、および設定済み端末のシリアル番号は PayArc から提供されます。

店舗のサイトはインターネット上の PayArc を経由して各端末に接続するため、ペアリングは不要で、どのレジからでもどの端末でも使用できます。WCPOS Pro 2.0 以降がない場合、拡張機能は WP Admin に通知を表示し、POS には何も追加しません。

<RequirementsList>
  <RequirementItem label="PayArc アカウント">PayArc Connect V3 にアクセスできる加盟店アカウント</RequirementItem>
  <RequirementItem label="対応ハードウェア">アカウントに割り当てられた、PayArc 対応の PAX 端末</RequirementItem>
  <RequirementItem label="接続">インターネット接続のみ対応しています。店舗のサイトはシリアル番号を指定して PAX 端末に各決済を送信するため、すべてのレジで使用できます。使用する端末はチェックアウト時にレジで選びます</RequirementItem>
  <RequirementItem label="WCPOS">WCPOS Pro 2.0 以降、および拡張機能バージョン 1.0 以降</RequirementItem>
  <RequirementItem label="サーバー">WooCommerce 7.0+、PHP 7.4+、本番モードには HTTPS</RequirementItem>
  <RequirementItem label="通貨">USD、CAD、GBP、EUR、JPY のいずれか</RequirementItem>
</RequirementsList>

</details>

<details>
<summary>六つの手順: インストール、接続、端末の追加、有効化、各レジの端末選択</summary>

<Steps>
  <StepCard number="1" title="PayArc Terminal for WooCommerce のインストール">

[GitHub のリリースページ](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases)からバージョン 1.0 以降の **payarc-terminal-for-woocommerce.zip** をダウンロードします。`プラグイン > Add Plugin` を開き、**プラグインのアップロード**からアップロードして、プラグインを有効化します。

`WP Admin > POS > 設定 > 拡張機能` には、WCPOS 2 より前に開発されたバージョン 0.1 が表示されている場合があります。そこからインストールする前に、バージョンを確認してください。

  </StepCard>
  <StepCard number="2" title="PayArc の認証情報の入力">

1. `WP Admin > WooCommerce > 設定 > 支払い` に移動し、**PayArc Terminal** を開きます
2. **モード**を選びます。デフォルトは `Live` です。`Test` は、PayArc テストダッシュボードの認証情報と PayArc Connect Test アプリを使う場合にのみ使用してください。異なる環境を混在させないでください
3. **PayArc ログインメールアドレス**に、PayArc 加盟店ダッシュボードへのログインに使用するメールアドレスを入力します
4. **PayArc MID** に PayArc の加盟店プロフィールにある MID を入力します。端末 ID ではありません
5. **PayArc ClientSecret** にダッシュボードの API セクションの値を、**PayArc SecretKey / API ベアラートークン**に PayArc ダッシュボードの値を入力します
6. **コールバックベアラートークン**は、PayArc サポートから発行された場合を除き、空欄にしてください

  </StepCard>
  <StepCard number="3" title="接続">

**この認証情報で接続**をクリックします。接続に成功すると、画面に **PayArc に接続済み**と表示され、端末のシリアル番号を入力または確認して保存するよう案内されます。別の環境の認証情報と思われると表示された場合は、**モード**を切り替えて再度接続してください。

:::note
**モード**または認証情報を変更した後は、**この認証情報で接続**をもう一度クリックしてから保存してください。WCPOS で PayArc Terminal を有効化した後（手順 5）は、この操作を行うまで保存時にエラーが表示されます。端末で決済を処理している間は、モード、認証情報、接続を変更できません。
:::

  </StepCard>
  <StepCard number="4" title="端末の追加">

1. **端末のシリアル番号**に、機器の背面の **S/N** ラベルに記載された PAX の番号を入力します。PayArc がアカウントに設定した番号を使用してください
2. **支払い種別**と**レシートの印刷**を選びます
3. **Webhook URL** が HTTPS であることを確認します。PayArc から求められた場合にのみ、この URL を伝えてください
4. **変更を保存**をクリックします

レジにはこの端末に加え、PayArc の端末レジストリでアカウントに対して有効とされているすべての端末が表示されます。**接続**を押すとレジストリを取得し、**端末を更新**を押すと再取得します。PayArc が無効とした端末は、入力したシリアル番号と一致していても表示されません。入力したシリアル番号がレジストリにない場合も、端末は表示されます。本番モードには HTTPS サイトが必要です。

  </StepCard>
  <StepCard number="5" title="WCPOS での有効化">

1. `WP Admin > POS > 設定 > 支払い` に移動します
2. 一覧から **PayArc Terminal** を見つけ、**有効**スイッチをオンにします
3. 次にページを読み込むと、レジにタイルが表示されます

:::note
有効化に使うスイッチはこれだけです。WooCommerce の決済一覧にある**有効**スイッチは影響せず、オンラインショップのチェックアウトに PayArc Terminal が表示されることもありません。[レジ設定](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)をご覧ください。
:::

  </StepCard>
  <StepCard number="6" title="各レジの端末選択" isLast>

各レジで**設定 > カードリーダー**を開きます。PayArc の端末は**スマートリーダー**の下に一台ずつ表示され、すべて**オンライン**と表示されます。PayArc は端末の電源が入っているかどうかを通知しません。そのカウンターの端末で**このリーダーを使用**を押すと、その行に**選択済み**と表示されます。レジ係はチェックアウト時にも**変更**を押せます。

PayArc の端末が一台だけの場合、選ぶ必要はありません。すべてのレジでその端末がすでに**選択済み**になっています。**店舗で設定**と表示される行は、レジが店舗のデフォルト端末に固定されていることを意味します。[スマートリーダーの選択](../../hardware/card-readers/index.mdx#smart-readers)をご覧ください。

  </StepCard>
</Steps>

</details>

## 設定リファレンス {#settings}

`WP Admin > WooCommerce > 設定 > 支払い > PayArc Terminal` のゲートウェイページにある全項目です。

<details>
<summary>PayArc Terminal のすべての設定</summary>

| 設定 | 機能 |
|---|---|
| **タイトル** | レジに表示されるタイルの名前。デフォルトは `PayArc Terminal` |
| **説明** | 支払い方法の説明。デフォルトは `Pay in person at a PayArc PAX terminal.` |
| **モード** | `Live`（デフォルト）または `Test`。テストモードには、PayArc テストダッシュボードの認証情報と PayArc Connect Test アプリが必要です |
| **PayArc ログインメールアドレス** | PayArc 加盟店ダッシュボードへのログイン用メールアドレス。接続前に入力が必要です |
| **PayArc MID** | PayArc の加盟店プロフィールにある加盟店 MID。端末 ID ではありません |
| **PayArc ClientSecret** | ダッシュボードの API セクションにあるシークレット。サーバーにのみ保存されます |
| **PayArc SecretKey / API ベアラートークン** | PayArc ダッシュボードのトークン。ログインと端末レジストリの読み取りに使用します |
| **コールバックベアラートークン** | 任意。PayArc サポートから発行された場合にのみ入力してください |
| **PayArc 接続** | **この認証情報で接続**、**端末を更新**、**切断**の各ボタン |
| **端末のシリアル番号** | PayArc がアカウントに設定した PAX の S/N。決済に必要です |
| **支払い種別** | `CREDIT`（デフォルト）または `DEBIT` |
| **レシートの印刷** | 端末での印刷: `0 - No receipt`（デフォルト）、`1 - Merchant receipt`、`2 - Customer receipt`、`3 - Both receipts` のいずれか |
| **Webhook URL** | 読み取り専用のコールバックアドレス。HTTPS であることを確認し、PayArc から求められた場合にのみ伝えてください |
| **PayArc 診断** | 接続情報と**設定を検証**ボタン。シークレットは表示されません |

保存済みのシークレット欄には末尾の 4 文字だけが表示されます。保存済みの値を保持するには、シークレット欄を空欄にしてください。

**PayArc 診断**の表には、モード、PayArc のエンドポイント、ログインメールアドレスと Connect アクセストークンの設定状況、マスクされた MID・テナント ID・端末シリアル番号、検出された端末の数、Webhook URL、最後のコールバック時刻、最後の PayArc エラーが表示されます。**設定を検証**は保存済みの設定を確認し、不足している項目を一覧表示します。

**切断**を押すと、保存済みの PayArc 接続、端末一覧、**端末のシリアル番号**が消去されます。認証情報は残るため、すぐに再接続できます。保存する前にシリアル番号を確認してください。

</details>

## ログ {#logs}

サポートを依頼する際は、注文番号と関連するログの行を送ってください。

<details>
<summary>サポート用のログを探す</summary>

`WooCommerce > Status > ログ` で、ソースが `payarc-terminal-for-woocommerce` のログを確認できます。識別子はマスクされ、シークレットは除去されます。

サポート用データ一式のダウンロード機能はありません。MID や端末 ID の全桁、トークン、カードデータを共有しないでください。

</details>

## 対応範囲と制限 {#scope-and-limitations}

- 端末でのチップ入力には対応していません
- 端末は一度に一件の決済を処理します。処理中は、他のレジに**注文 #… で使用中**と表示されます
- 対応通貨は **USD、CAD、GBP、EUR、JPY** に限られます
- この接続では端末の電源が入っているかどうかは通知されません。オフラインの端末への決済は即座に失敗し、端末には何も送信されません
- 拡張機能バージョン 0.1 で受け付けた決済は、ゲートウェイ経由ではなく PayArc で払い戻します
- 払い戻しは、元の決済を受け付けた端末に送信されます

## 設定で問題が起きた場合 {#troubleshooting}

### よくある問題 {#common-issues}

<Accordion>
  <AccordionItem question="これは PayArc のテスト環境（または本番環境）の認証情報と思われます">

  - 選択したモードと認証情報が、それぞれ異なる PayArc 環境のものです
  - **モード**をメッセージに表示されたものに切り替えるか、選択中のモードに対応する認証情報に置き換えてください
  - **この認証情報で接続**をもう一度クリックして保存してください

  </AccordionItem>
  <AccordionItem question="PayArc に接続できません">

  - PayArc がログインを拒否しました。入力した認証情報を確認して、再試行してください
  - 詳細は `WooCommerce > Status > ログ` で、ソースが `payarc-terminal-for-woocommerce` のログを確認してください

  </AccordionItem>
  <AccordionItem question="本番モードを有効にするには、コールバック URL が HTTPS である必要があります">

  - 本番モードでは、PayArc が **Webhook URL** にアクセスできるよう、サイトを HTTPS にする必要があります
  - サイトを HTTPS に移行するか、テスト用サイトで**テスト**モードを使用してください

  </AccordionItem>
  <AccordionItem question="端末レジストリが空です">

  - この場合、レジには**端末のシリアル番号**で指定した端末だけが表示されます。その端末での決済は引き続き利用できます
  - アカウントに登録されたシリアル番号を PayArc に確認してもらってください。他の端末もレジで選べるようにするには、それらの端末の登録も依頼してください
  - PayArc が端末を追加したら、**端末を更新**をクリックしてください

  </AccordionItem>
  <AccordionItem question="PayArc が Connect AccessToken と SecretKey の両方を拒否しました">

  - PayArc が、このアカウントからのトランザクション API の利用を拒否しました
  - 加盟店アカウントで **PayArc Connect V3** が有効になっているか、また、どの認証情報でトランザクションが許可されるかを PayArc サポートに確認してください

  </AccordionItem>
</Accordion>

### サポートを受ける {#getting-help}

- サポートへのお問い合わせには、**注文番号**と関連する**ログの行**を添えてください
- 問題の報告は [GitHub リポジトリ](https://github.com/wcpos/payarc-terminal-for-woocommerce)から行ってください
- アカウント、PayArc Connect、端末の設定については、PayArc サポートにお問い合わせください
