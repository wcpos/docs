**WP管理画面：** 各ゲートウェイはWordPressにインストールするプラグインです。`WP Admin → POS → Settings → Checkout`で有効にします。

決済ゲートウェイを追加すると、レジで利用できる支払い方法が増えます。カウンターのカード端末、お客様のスマートフォンでの支払い、後払い用の請求書などに対応できます。いずれもWCPOSが提供するWordPressプラグインで、店舗に追加して利用します。使いたいゲートウェイを探すには、[ゲートウェイを選ぶ](#gateways)をご覧ください。

お客様がオンラインストアの支払い方法を使いたい場合は[Web Checkout](./web-checkout.mdx)を、現金やカードなど、レジで受け付ける支払い方法については[支払い方法](../index.mdx)をご覧ください。

:::info Proの機能
ゲートウェイの利用には[WCPOS Pro](../../getting-started/pro-license.mdx)が必要です。Proがない場合、レジで使えるのは**現金**と**カード**だけです。
:::

## チェックアウト時のゲートウェイの表示場所 {#at-the-till}

**チェックアウト**を押すと、支払いパネルの**支払い**タブが開きます。[以下の一覧](#gateways)で**支払い**と記載されているゲートウェイは、**現金**と**カード**の隣に専用のタイルとして表示されます。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[28, 42], [0, 0], [0, 0], [29, 42]]} alt="支払いタブの支払いパネル：支払いタブとレガシータブ、現金とカードのタイル、支払い金額、受け取りボタン">

1. **支払い** — 支払いパネルです。タイルがある支払い方法はすべてここに表示されます。[支払いパネル](../../pos/checkout/payment-methods.mdx)をご覧ください。
2. **現金** — お釣りを計算します。すべての店舗で利用できます。
3. **カード** — POSに接続していないカード決済端末用です。端末でカード決済を行い、ここに記録します。すべての店舗で利用できます。
4. **レガシー** — 独自の支払いページで動作するゲートウェイです。[レガシータブ](../../pos/checkout/legacy-tab.mdx)をご覧ください。

</JourneyShot>

ゲートウェイのタイルは、[レジ設定](../../settings/wp-admin/checkout.mdx#reordering-gateways)で指定した順序で並びます。レジで現在使えないタイルは、タイルの下に折りたたまれ、**Stripe Terminalは現在利用できません**、複数ある場合は**現在利用できないものが2件あります**などと表示されます。その行をタップすると理由を確認できます。

WooCommerceの代金引換、銀行振込、小切手のゲートウェイにもタイルが表示され、**カード**と同じようにレジで支払いを記録できます。[レジでの支払い方法](../../pos/checkout/payment-methods.mdx)をご覧ください。それ以外のゲートウェイは**レガシー**タブに表示され、POS内で、その注文に対する店舗独自の支払いページが開きます。レガシーのゲートウェイは注文全体の支払いに使うため、[分割払い](../../pos/checkout/split-payments.mdx)の一部には使えません。

<details>
<summary>レガシータブで支払いを受け付ける</summary>

1. **レガシー** — このタブは常に表示されます。利用できるゲートウェイがない場合は、その旨が表示されます。
2. **支払いページ** — この注文に対する店舗独自の支払いページです。ゲートウェイを選び、必要な情報を入力してください。
3. **支払いを処理** — ゲートウェイに支払いを送信します。

## ゲートウェイを選ぶ {#gateways}

### カード端末 {#hardware-terminal-gateways}

お客様は、決済サービス事業者の端末にカードをタッチ、挿入、またはスワイプします。レジから端末に金額が送信され、事業者が決済を確認すると支払いが記録されます。

| ゲートウェイ | チェックアウト時の表示 |
|---|---|
| [Stripe Terminal](./stripe-terminal.mdx) | 支払い, 2.0+ |
| [SumUp Terminal](./sumup-terminal.mdx) | 支払い, 2.0+ |
| [Mollie Terminal](./mollie-terminal.mdx) | 支払い, 2.0+ |
| [Square Terminal](./square-terminal.mdx) | 支払い, 1.0+ |
| [Mercado Pago Terminal](./mercadopago-terminal.mdx) (Point Smart) | 支払い, 1.0+ |
| [Windcave Terminal](./windcave-terminal.mdx) | 支払い, 1.0+ |
| [PayArc Terminal](./payarc-terminal.mdx) (PAX) | 支払い, 1.0+ |
| [PayPal Reader (Zettle)](./paypal-reader.mdx) | レガシー, すべてのバージョン |

数字は、タイルに対応するゲートウェイプラグインの最も古いバージョンです。それより古いバージョンは**レガシー**タブに表示されます。各デバイスで使えるリーダーについては、[カードリーダーの互換性](../../hardware/index.mdx#card-reader-compatibility)をご覧ください。

### スマートフォン決済 {#mobile-payment-gateways}

- **[Vipps MobilePay](./vipps-mobilepay.mdx)** — お客様がVippsまたはMobilePayアプリで画面のQRコードを読み取るか、スマートフォンに届いたリクエストを承認します。**レガシー**タブに表示されます。

### 後払い {#digital-payment-gateways}

注文は未払いのまま保存され、お客様が後でオンラインで支払います。

- **[Email Invoice](./email-invoice.mdx)** — 注文の支払いリンクを含むメールがお客様に届きます。バージョン0.1.0以降は**支払い**タブに、それより古いバージョンは**レガシー**に表示されます。
- **[Web Checkout](./web-checkout.mdx)** — お客様がオンラインストアのチェックアウトで支払います。**レガシー**タブに表示されます。

## 店舗にゲートウェイを追加する {#install}

店舗のオーナーがWordPressで一度だけ行う設定です。ゲートウェイをインストールし、アカウントを接続して、POSで有効にした後、POSを再読み込みします。各ゲートウェイのページに、それぞれの設定方法が記載されています。

<details>
<summary>店舗オーナー向け：ゲートウェイのインストール、有効化、グレー表示への対処</summary>

1. **インストールします。** `WP Admin > POS > 設定 > 拡張機能`でゲートウェイを探し、**インストール**、**有効化**の順に押します。または、ゲートウェイのGitHubリリースページからプラグインのzipをダウンロードし、`プラグイン > Add Plugin`の**プラグインのアップロード**からアップロードします。Web Checkoutは拡張機能の一覧にないため、必ずzipでインストールします。[拡張機能](../../extensions/index.mdx#installing-an-extension)をご覧ください。
2. **アカウントを接続します。** `WP Admin > WooCommerce > 設定 > 支払い`でゲートウェイを開き、決済サービス事業者から取得したキーを入力します。テストモードがある場合は、本番運用を始める前にテスト決済を行ってください。
3. **POSで有効にします。** `WP Admin > POS > 設定 > 支払い`でゲートウェイの**有効**をオンにし、タイルを表示したい位置にドラッグします。オンラインストア側で有効にする必要はありません。[レジ設定](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)をご覧ください。
4. **POSを再読み込みします。** レジは起動するたびに支払い方法を読み込みます。

**「インストール」がグレー表示になり、「インストールにはProが必要です」と表示されます。** **拡張機能**からのインストールにはWCPOS Proが必要です。

**「有効」スイッチがグレー表示になっています。** 現金とカード以外のすべてのゲートウェイには、ライセンスキーで有効化したWCPOS Proが必要です。[Proライセンス](../../getting-started/pro-license.mdx)をご覧ください。

</details>

## 問題が発生した場合 {#goes-wrong}

**チェックアウトにゲートウェイが表示されません。** まず**レガシー**タブを確認してください。そこにもない場合は、レジ設定で**有効**がオンになっていることを確認してから、POSを再読み込みします。スイッチがグレー表示の場合は、[店舗にゲートウェイを追加する](#install)の**店舗オーナー向け：ゲートウェイのインストール、有効化、グレー表示への対処**を開いてください。

**タイルではなくレガシータブに表示されます。** PayPal Reader、Vipps MobilePay、Web Checkoutは常にこのタブに表示されます。[上の一覧](#hardware-terminal-gateways)でバージョンが記載されている端末は、インストール済みのバージョンと表を照合してください。古い場合は更新します。新しいバージョンがあると、**拡張機能**のカードに**更新が利用可能**と表示されます。

**タイルが「現在利用できません」の下にあります。** その行をタップしてください。オフライン時の**接続が必要です**など、各ゲートウェイに理由が表示されます。それまでは別の方法で販売を完了してください。

**決済に失敗します。** レジに**PAYMENT301**が表示される場合は、店舗側でゲートウェイが拒否されています。POSで有効になっていないか、削除されています。[PAYMENT301](../../error-codes/PAYMENT301.mdx)をご覧ください。端末や決済サービス事業者側の問題については、各ゲートウェイのページにエラーメッセージと対処方法が記載されています。不具合を報告するには、[サポート](../../support/index.mdx)をご覧ください。

### 独自のゲートウェイを作成する {#creating-your-own-gateway}

開発者向け：WooCommerceの決済プラグインは、どれでもラッパーを作成してPOSに対応させることができます。[ゲートウェイテンプレート](../../reference/gateway-template.mdx)から始めてください。
