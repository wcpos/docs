:::info Pro機能
Mollie Terminalには[WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0以降が必要です。
:::

Mollie Terminalは、レジから[Mollie](https://www.mollie.com/products/point-of-sale)のカード決済端末に決済を送信します。お客様が端末で支払うと、レジで販売処理が自動的に完了します。対応通貨は**ユーロ**のみで、POS専用です。オンラインストアのチェックアウトには表示されません。

## 決済を受け付ける {#take-payment}

責任者が店舗の本番用Mollieアカウントに登録された端末で、一度だけ[設定](#setup)を行います。開始前に[レジを開いて](../../pos/register/index.mdx#open)ください。

:::warning
**レジの開閉**がオンの場合、レジを閉じたままでは支払いを記録できず、すでにカードに請求した代金は払い戻す必要があります。
:::

1. **チェックアウト**を押し、支払いパネルの**Mollie Terminal**タイルをタップします。
2. 支払いパネルの**端末：** と端末名を確認します。別の端末を使うには、**変更**をタップして選択します。店舗で有効な端末が1台だけの場合や、選択がロックされている場合は、**変更**は表示されません。
3. **…をMollie Terminalに送信**を押します。金額が端末に送信されます。
4. お客様が端末にカードをタッチするか、差し込むか、スワイプします。レジには**端末で処理中**と表示され、**送信済み**、**端末で処理中**、**承認済み**、**売上確定済み**の順に進みます。
5. Mollieが支払いを確認すると、通常の[チェックアウト](../../pos/checkout/index.mdx#paid)と同様に、販売が支払い済みとなり、レシートが準備されます。

各レジは、最後に使用した端末を記憶します。[カードリーダーでの支払い](../../pos/checkout/taking-a-payment.mdx#card-reader)を参照してください。

お客様が端末で追加したチップは、注文に**チップ**の明細として記録されます。[チップ](../../pos/checkout/tips.mdx)を参照してください。

### 端末の決済をキャンセルする {#cancel}

レジが待機している間に、**端末でキャンセル**を押します。レジに**キャンセル中 — 端末からの確認を待機中**と表示されます。

#### 決済がキャンセルまたは拒否された場合 {#cancelled}

**決済がキャンセルされました**、決済の拒否、または**タイムアウト — 決済がキャンセルされました**と表示された場合、支払いは成立していません。**再試行**を押して決済を再送信するか、**別の方法を選択**を押して別の支払い方法を使ってください。

#### 端末からの確認が得られない場合 {#not-confirmed}

お客様が支払いを始めると、Mollie側でレジからのキャンセルができなくなる場合があります。端末本体でキャンセルしてください。

それでもレジが応答を取得できない場合は、**この決済を解除**が表示されます。

:::warning 再度代金を受け取る前に
端末を確認してください。支払いが承認済みと表示されている場合は、**再度請求しないでください**。店舗サイトはまだMollieに確認中です。判断できない場合は、別の決済を受け付ける前に、責任者にMollieダッシュボードでの決済確認を依頼してください。
:::

**この決済を解除**を押すと、注文を別の方法で支払えるようになり、レジに**決済を解除しました**と表示されます。これは決済がキャンセルされたという意味ではありません。店舗サイトは端末の確認を続けます。

### レガシータブでの操作 {#legacy-tab}

注文の決済ページである、チェックアウトの[レガシータブ](../../pos/checkout/legacy-tab.mdx)でも支払いを受け付けられます。**レガシー**タブを開き、**Mollie Terminal**を選択します。表示されるパネルは、責任者が**QRコード決済**をオンにしているかどうかで異なります。

**パネルに「端末」と「QRコード」が表示されている場合**は、**端末**を選択したまま**端末決済を開始**を押します。中止するには**端末決済をキャンセル**を押します。代わりにコードを表示する場合は、[QRコードで支払う](#qr-code)を参照してください。

**それ以外の場合：**

1. パネルで端末の選択を求められた場合は、端末を選択します。
2. 端末名が付いた **…を送信**を押します。パネルにはタイルと同じ進行状況が表示されます。
3. 中止するには、[決済のキャンセル](#cancel)と同様に**端末でキャンセル**を押します。停止後に**再試行**を押すと再送信されます。POSは、タイルからの決済と同じようにこの支払いを記録します。

## QRコードで支払う {#qr-code}

オランダとベルギーでは、お客様が端末の代わりに、銀行アプリでiDEALまたはBancontactのQRコードを読み取って支払えます。まず責任者が[設定](#settings)の**QRコード決済**でこれらの方法をオンにします。

1. チェックアウト時に[レガシータブ](../../pos/checkout/legacy-tab.mdx)を開き、**Mollie Terminal**を選択します。
2. 決済パネルを**端末**から**QRコード**に切り替えます。
3. 両方がオンの場合は**iDEAL**または**Bancontact**を選択し、**QRコードを表示**を押します。
4. お客様がコードを読み取り、スマートフォンで支払います。端末での決済と同様に販売処理が完了します。

BancontactのQR決済は1回あたり最大€1,500.00です。それを超える場合は端末を使用してください。

## 払い戻し {#refunds}

POSからMollie Terminalでの販売を払い戻すには、**Mollie Terminalに払い戻す**を選択します。WooCommerceの注文画面から払い戻すこともできます。全額または一部の金額がMollie経由で返金されます。[払い戻し](../../pos/refunds.mdx#destination)を参照してください。

Mollieの払い戻しは保留中の状態で始まります。WCPOS Proが10分ごとにMollieに確認し、払い戻し済みまたは失敗に更新して、注文にメモを追加します。

## 問題が発生した場合 {#goes-wrong}

### お客様がすでに支払っている場合：再度請求しないでください {#already-paid}

**お客様が支払いを済ませたのに、レジがまだ待機しています。** **再度請求しないでください。** 画面を開いたままにします。Mollieが支払いを確認すると、販売処理が完了します。完了しない場合は、責任者にMollieダッシュボードでの決済確認を依頼してください。

**「この販売に対する以前のMollie決済は支払い済みです」。** この販売の決済はMollieですでに成立していますが、注文にはまだ反映されていません。**再度請求しないでください。** 数分待ってから再読み込みしてください。決済が注文と一致しないというメッセージが表示された場合は、まず責任者がMollieダッシュボードで確認します。

### その他の問題 {#other-problems}

**「Mollie Terminal用の端末が設定されていません」。** 店舗に利用可能な有効な端末がありません。責任者が、**モード**が**本番**で本番用キーが設定されていることと、そのMollieアカウントで端末が有効であることを確認します。

**「注文#…で使用中」。** その端末は別の販売で使用中です。別の端末を選択するか、先にもう一方の販売を完了またはキャンセルしてください。

**「接続が必要です」。** レジがオフラインです。Mollie Terminalはオンラインでのみ動作します。別の方法で支払いを受け付けるか、接続が復旧するまでお待ちください。

**「タイムアウト — 決済がキャンセルされました」。** 制限時間内に支払いがなかったため、決済がキャンセルされました。端末の電源が入り、オンラインであることを確認してから、**再試行**または**別の方法を選択**を押してください。

**他の通貨での販売が拒否されます。** Mollie Terminalはユーロにのみ対応しています。

**解決しない場合は？** 拡張機能の問題は[GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/issues)で報告してください。Mollieアカウントや端末本体については、Mollieサポートにお問い合わせいただくか、Mollieの[端末設定ガイド](https://docs.mollie.com/docs/setting-up-terminal)を参照してください。

<details>
<summary>レジと店舗サイトがMollieの状態を確認する仕組み</summary>

- 決済の待機中、決済ページは2秒ごとにMollieに確認します。通常は、それより早くMollieから店舗サイトへの通知で決済が確認されます。この通知のための設定は不要です。
- 注文を変更する前に、すべての更新内容をMollieに確認するため、注文の状態はMollieの情報に従います。
- 払い戻しリクエストに応答がない場合、拡張機能は新たな払い戻しを作成する前に、Mollieですでに行われた払い戻しを探します。
- レガシータブで**QRコード決済**がオンの場合、拡張機能独自のパネルが決済を処理します。5分以内に支払いがない場合、WooCommerceで注文が別の方法で支払われたかキャンセルされた場合、または決済の途中で決済ページが閉じられた場合、Mollieに残っている未完了の決済をキャンセルします。また、10分ごとの確認で、未払いの注文について10分経過後も未完了の決済をキャンセルします。
- 端末にすでに届いた決済は、店舗サイトからキャンセルできません。端末でキャンセルしてください。
- トラブルシューティングのため、すべての決済は`WooCommerce > Status > ログ`に記録されます。販売が完了しない場合、責任者がここでMollieのメッセージを確認します。

</details>

## 設定する {#setup}

責任者がWP Adminで一度だけ設定します。WCPOS Pro 2.0.0以降、**対面決済**が有効な本番用Mollieアカウント、店舗の通貨としてユーロの設定が必要です。

<details>
<summary>責任者向けの設定：インストール、キー、端末、有効化</summary>

この拡張機能にはWCPOS Pro 2.0.0以降が必要です。ない場合は動作せず、WP Adminに通知が表示されます。

:::note 始める前に
Mollie Web Appで、プロフィールの支払い方法として**対面決済**をオンにし、そこで端末を購入します。Mollieはオランダ、ベルギー、ドイツ、フランス、英国で端末を販売しており、事前にアカウントの確認を求める場合があります。端末は**本番**アカウントにのみ存在するため、本番用APIキーが必要です。
:::

1. **拡張機能をインストールします。** `POS Settings > 拡張機能`を開いて**Mollie Terminal**をインストールします。または、[GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases)からリリースのzipファイルを取得し、`プラグイン > Add Plugin`の**プラグインのアップロード**からアップロードします。ソースコードのアーカイブではなく、リリースに添付されたzipファイルを使用してください。[拡張機能](../../extensions/index.mdx#installing-an-extension)を参照してください。
2. **キーを追加します。** `WooCommerce > 設定 > 支払い > Mollie Terminal`に移動します。**モード**を**本番**に設定し、**Mollie APIキー**に本番用キーを貼り付けるか、**APIキーの取得元**でMollie Payments for WooCommerceプラグインのキーを再利用するよう設定します。保存します。
3. **端末を選択します。** キーを保存すると、Mollieアカウントの端末が一覧表示されます。**デフォルトの端末**を選択します。レジで使わせたくない端末がある場合は、使用を許可する端末だけを**有効な端末**に指定します。保存します。
4. **POSで有効にします。** `POS > 設定 > 支払い`に移動し、**Mollie Terminal**を有効にします。有効・無効を切り替えるスイッチはこれだけです。[ゲートウェイの有効化](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)を参照してください。

MollieダッシュボードでWebhookを設定したり、プロフィールIDを貼り付けたりする必要はありません。拡張機能が決済のたびにWebhookアドレスを送信し、アカウント全体の端末を一覧表示します。

**デフォルトの端末**の一覧が空のままの場合は、**モード**が**本番**で本番用キーが設定されていること（テストアカウントには端末がありません）、Mollieで端末が有効であること、サイトがMollieに接続できることを確認してください。

</details>

### 設定項目 {#settings}

<details>
<summary>Mollie Terminal画面のすべての設定</summary>

これらはすべて`WooCommerce > 設定 > 支払い > Mollie Terminal`にあります。

| 設定 | 機能 |
|---|---|
| **タイトル** | レジのタイルに表示される名前です。初期値は「Mollie Terminal」です。 |
| **説明** | 注文の決済ページで、支払い方法とともに表示されるテキストです。 |
| **モード** | **テスト**または**本番**を選択します。初期値は**テスト**で、テスト用キーでは端末を操作できないという警告が表示されます。決済を受け付けるには**本番**を使用してください。 |
| **APIキーの取得元** | **以下に入力したキーを使用**または**公式Mollieプラグインのキーを再利用**（**モード**に合ったテスト用または本番用キー）を選択します。Mollieプラグインにキーが設定されていない場合は、下のキーを使用します。 |
| **Mollie APIキー** | 選択したモードのキーです。取得元でMollieプラグインのキーを再利用している間は無視されます。 |
| **デフォルトの端末** | レジで最初に使用する端末です。Mollieアカウントから最新の一覧を取得します。Mollieでは無効な端末を再有効化できないため、無効な端末は非表示になります。 |
| **有効な端末** | レジではここで指定した端末だけを選択できます。空欄の場合は、有効なすべての端末が対象です。デフォルトの端末は常に選択肢に含まれるため、端末の使用をやめる際はデフォルトの設定も変更してください。端末一覧を読み込めない間は表示されませんが、保存済みの選択内容は保持されます。 |
| **QRコード決済** | **iDEAL**と**Bancontact**：レジ係が端末の代わりに画面にQRコードを表示できるようにします。それぞれMollieのプロフィールで有効になっている必要があります。iDEAL QRは**テスト**モードでも動作するため、端末がなくても試せます。Bancontact QRには**本番**が必要です。[QRコードで支払う](#qr-code)を参照してください。 |
| **端末の選択をロック** | レジは常にデフォルトの端末を使用し、レジ係は変更できません。**デフォルトの端末**の設定が必要です。 |
| **チェックアウトのデバッグログ** | 決済パネルに**ログを表示**、**コピー**、**クリア**を表示します。サポートから指示がない限りオフにしてください。決済は常に`WooCommerce > Status > ログ`に記録されます。 |

</details>
