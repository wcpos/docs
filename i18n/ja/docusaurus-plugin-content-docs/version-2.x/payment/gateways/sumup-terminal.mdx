# SumUp Terminal 決済ゲートウェイ {#sumup-terminal-gateway}

SumUp Terminal を使うと、レジで SumUp カードリーダーを利用できます。レジからリーダーに金額を送信し、お客様がリーダーで支払うと、SumUp の決済承認後に販売が完了します。このページでは、ゲートウェイの初期設定、リーダーのペアリングまたは接続、初回の決済までを説明します。

設定済みの場合は、[Solo のペアリング](#pairing)、[Bluetooth リーダーの接続](#card-readers)、または[決済の受け付け](#processing-payments)に進んでください。

:::info Pro 機能
SumUp Terminal 2.0 には [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0 以降が必要です。これがないと、レジで拡張機能は動作しません。
:::

## Solo のクラウド接続と Bluetooth 接続 {#hardware-compatibility}

ゲートウェイの **POS 接続**設定で、POS とリーダーの接続方法を選択します。この設定は店舗全体に適用されます。

- **クラウド経由の Solo**（デフォルト）：店舗からインターネット経由で **SumUp Solo** に接続します。ブラウザー、デスクトップアプリ、iPhone、iPad、Android のどのレジでも利用できます。Solo のペアリングは、ゲートウェイのページで一度だけ行います。
- **Bluetooth リーダー**：WCPOS の iOS または Android アプリから、Bluetooth 経由で **Solo Lite**、**Solo**、**Air** に接続します。各レジのアプリで、そのレジ用のリーダーを接続します。この選択肢は、店舗の WCPOS Pro がアプリ接続型のリーダーに対応している場合にのみ表示されます。

ブラウザーやデスクトップアプリから Bluetooth リーダーには接続できません。**Bluetooth リーダー**を選択すると、これらのレジでは SumUp タイルが **… 現在利用できません**の下に表示されます。ブラウザーやデスクトップアプリを使うレジがある場合は、**クラウド経由の Solo** を選んでください。タイルのメッセージについては、[アプリのリーダーのみ使用可能](#only-app-readers)を参照してください。

## ゲートウェイの設定 {#setup}

管理者が WP Admin で、店舗ごとに一度設定します。

1. **拡張機能をインストールします。** `WP Admin > POS > 設定 > 拡張機能` で **SumUp Terminal for WooCommerce** を探し、**インストール**、**有効化**の順にクリックします。ディレクトリには古いバージョンが表示されることもあるため、バージョンが 2.0.0 以降であることを確認してください。[拡張機能](../../extensions/index.mdx#installing-an-extension)を参照してください。

   <details>
   <summary>ダウンロードした zip からインストールする場合</summary>

   [GitHub](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases) のリリースアセットから `sumup-terminal-for-woocommerce.zip` をダウンロードし、`プラグイン > Add Plugin` の**プラグインのアップロード**からアップロードします。GitHub の「Source code」の zip はインストールできません。

   </details>

2. **API キーを追加します。** **SumUp API キー**は、[SumUp 開発者ポータル](https://developer.sumup.com/)で、リーダーを所有するアカウントから確認できます。`WP Admin > WooCommerce > 設定 > 支払い` で **SumUp Terminal** を開き、**SumUp API キー**に貼り付けます。
3. **POS 接続を選択します**：**クラウド経由の Solo** または **Bluetooth リーダー**を選びます。**Bluetooth リーダー**の場合は、[SumUp アフィリエイトキー](https://developer.sumup.com/tools/authorization/affiliate-keys/)の**アフィリエイトキー**も入力します。
4. **設定を保存します。**
5. **POS で有効にします。** `WP Admin > POS > 設定 > 支払い` で **SumUp Terminal** をオンにして保存します。WooCommerce 自体の決済一覧で有効にする必要はありません。[レジ設定](../../settings/wp-admin/checkout.mdx)を参照してください。
6. **リーダーをペアリングまたは接続します**：クラウド経由の Solo は[このページでペアリング](#pairing)し、Bluetooth リーダーは[アプリで接続](#card-readers)します。

SumUp Terminal は POS 専用です。オンラインショップの購入手続きには表示されません。

<details>
<summary>ゲートウェイページのすべての設定</summary>

| 設定 | 機能 |
|---|---|
| **タイトル**と**説明** | ゲートウェイに表示される名前と説明文です。レジではタイルにタイトルが表示されます。 |
| **SumUp API キー** | SumUp アカウントから取得します。 |
| **アフィリエイトアプリ ID** と**アフィリエイトキー** | [SumUp アフィリエイトキー](https://developer.sumup.com/tools/authorization/affiliate-keys/)から取得します。**Bluetooth リーダー**では、アプリが SumUp のリーダー用ソフトウェアを起動するためにキーが必要です。**クラウド経由の Solo**では任意です。 |
| **POS 接続** | *クラウド経由の Solo（店舗からリーダーを操作）*または*Bluetooth リーダー（POS アプリからリーダーを操作：Solo Lite、Solo、Air）*。 |
| **オフラインカード決済** | 2.0 では効果がありません。[オフライン決済](#offline-payments)を参照してください。 |
| **デフォルト端末** | レジで別の端末を選ぶまで、決済に使用するペアリング済みの Solo です。 |
| **有効な端末** | レジで使用できる Solo を、選択したものに限定します。すべて許可する場合は空欄にします。 |
| **端末選択をロック** | *レジ係はチェックアウト時に端末を変更できません。* **デフォルト端末**の指定が必要です。 |
| **チェックアウトのデバッグログ** | チェックアウト画面に SumUp 決済の詳細ログを表示します。決済の履歴は常に `WooCommerce > Status > ログ` に記録されます。 |

入力欄の下には、接続状態、SumUp 加盟店情報、ペアリング済みのリーダーが表示されます。各決済結果の送信先は店舗から SumUp に通知されるため、Webhook の設定は不要です。

</details>

## クラウド経由で Solo をペアリングする {#pairing}

ペアリングコードは SumUp アプリではなく Solo 本体に表示されます。そのコードを WP Admin のゲートウェイページに入力します。

1. Solo の電源を入れます。Solo で SumUp にログインしないでください。
2. Solo でメニューを開き、**接続 → クラウド API** を開きます。一覧の最後の項目です。**接続**をタップすると、Solo にペアリングコードが表示されます。
3. WP Admin でゲートウェイのページ(`WooCommerce > 設定 > 支払い > SumUp Terminal`)を開きます。**新しいリーダーをペアリング**の**ペアリングコードを入力**にコードを入力し、**リーダーをペアリング**を押します。
4. *リーダーのペアリングが完了しました！* と表示され、ページが再読み込みされます。**設定済みリーダー**に、Solo のモデルとシリアル番号が表示されます。

**Solo にクラウド API が表示されない場合**は、リーダーで SumUp アカウントからログアウトし、もう一度メニューを開いてください。

もう一台の Solo をペアリングするには、**リーダーを追加でペアリング**を使います。リーダーの横にある**リーダーのペアリングを解除**を選ぶと、そのリーダーが店舗から削除されます。

## アプリで Bluetooth リーダーを接続する {#card-readers}

**POS 接続**を **Bluetooth リーダー**にすると、各スマートフォンやタブレットの WCPOS iOS または Android アプリで、その端末用のリーダーを接続します。サイドメニュー下部の**設定**、**カードリーダー**の順にタップします。ゲートウェイの設定が済んでいると、**Bluetooth リーダー**セクションに**リーダーを接続**ボタンが表示されます。**この店舗にはカードリーダーが設定されていません**とだけ表示される場合は、[カードリーダーがない場合](#no-card-readers)を参照してください。

1. リーダーの電源を入れ、スマートフォンやタブレットの近くに置きます。
2. **リーダーを接続**をタップします。**リーダーの接続先**が表示されたら、**SumUp Terminal** を選択します。
3. SumUp の画面が開きます。SumUp アカウントにサインインしてリーダーを選択します。

リーダーが保存されると、**カードリーダー**に **SumUp Terminal** の行が表示されます。次回からは、その行の **SumUp Terminal のリーダー設定を開く**ボタンを使います。ボタンにはゲートウェイの**タイトル**が使われるため、名前を変更していると表示も変わります。

**カードリーダー**に戻ると、行に**接続済み**と表示されます。リーダーが保存済みで未接続の場合は、**SumUp Terminal アプリに保存済み**と表示されます。**リーダーを使用するには SumUp Terminal にサインインしてください。** と表示される場合は、アプリがまだ SumUp にサインインしていません。もう一度ボタンをタップしてください。

## 本番運用前にテストする {#testing}

**クラウド経由の Solo**では、リーダーや実際のお金を使わずに販売をテストできます。SumUp の [Virtual Solo](https://virtual-solo.sumup.com) は、SumUp のサンドボックスアカウント用に Solo の動作を再現します。

<details>
<summary>Virtual Solo でテストする</summary>

1. ゲートウェイのページで、サンドボックスアカウントの API キーを **SumUp API キー**に貼り付けて保存します。
2. [Solo](#pairing) と同じ手順で、Virtual Solo のペアリングコードを使ってペアリングします。**設定済みリーダー**に表示されます。
3. [決済の受け付け](#processing-payments)の手順で販売を行います。タイルの**端末：…** に Virtual Solo が表示されます。

テストが終わったら、本番用の API キーに戻して保存し、実際の決済を受け付ける前に実機の Solo をペアリングしてください。

</details>

## 決済を受け付ける {#processing-payments}

:::note 最初にレジを開いてください
**レジの開閉**がオンの場合、レジを閉じている間は決済が記録されず、すでに受け付けたカード決済は返金する必要があります。[レジを開く](../../pos/register/index.mdx)を参照してください。
:::

1. カートに商品を入れ、**チェックアウト**を押します。
2. 支払い方法の中から **SumUp Terminal** タイルをタップし、リーダーの表示を確認します。
   - **クラウド経由の Solo**：**端末：…** と表示されます。店舗で許可されている場合は、**変更**で別の Solo を選択できます。
   - **Bluetooth リーダー**：**接続済み**とリーダーのバッテリー残量が表示されます。**リーダーが接続されていません**の場合は未接続です。**設定 → カードリーダーで接続**をタップしてください。
3. **… を SumUp Terminal に送信**を押し、お客様にリーダーで支払ってもらいます。
   - **クラウド経由の Solo**：レジに**端末でお客様の操作を待っています**と表示されます。中止するには、**端末でキャンセル**を押します。
   - **Bluetooth リーダー**：レジに**リーダーにカードをかざしてください**と表示されます。中止するには、リーダー本体でキャンセルします。レジで**端末でキャンセル**を押すと、**リーダーでキャンセルしてください**と表示されます。リーダーがお客様にチップの入力を求めることもあります。[チップ](../../pos/checkout/tips.mdx)を参照してください。

   レジでは、**送信済み**、**端末で処理中**、**承認済み**、**売上確定済み**の順にチェックが入ります。
4. 残額がなくなるとレシート画面が開きます。レシートを印刷またはメールで送信し、**新しい販売**を押してください。[支払い完了の確認](../../pos/checkout/index.mdx#paid)を参照してください。合計金額の一部が残っている場合は、別の方法で残額を受け付けます。[分割払い](../../pos/checkout/split-payments.mdx)を参照してください。

カード決済が拒否またはキャンセルされると、**決済に失敗しました：…** と、**再試行**、**別の方法を選択**が表示されます。[カードリーダーでの決済](../../pos/checkout/taking-a-payment.mdx#card-reader)を参照してください。

チェックアウトの[**レガシー**](../../pos/checkout/legacy-tab.mdx)タブでは、SumUp Terminal に**端末**の選択欄と、**端末に送信**、**キャンセル**、**再試行**が表示されます。支払いパネルからの決済と同様に記録されます。

<details>
<summary>2.0 より前の SumUp Terminal</summary>

2.0 より前のバージョンでは、支払いパネルにタイルがありません。ゲートウェイは**レガシー**タブの専用決済ページにあり、**新しい決済を開始**、**決済をキャンセル**、**決済状況**が表示されます。クラウド経由の Solo のみに対応しています。タイルや Bluetooth リーダーを利用するには、2.0 に更新してください。

</details>

## オフライン決済 {#offline-payments}

WCPOS 2.0 では、ゲートウェイの**オフラインカード決済**の設定にかかわらず、レジがオフラインの間はどのリーダーでも SumUp のカード決済を受け付けられません。{/* pending: monorepo#3387 */} 接続がないと、SumUp タイルは **… 現在利用できません**の下に表示され、**接続が必要です**と表示されます。現金で受け付けるか、接続の復旧を待ってください。[オフラインモード](../../getting-started/offline.mdx#take-payment-offline)を参照してください。

オフラインカード決済は[ロードマップ](../../getting-started/roadmap.mdx)に含まれています。

## 問題が発生した場合 {#common-issues}

- [Solo をペアリングできない](#solo-wont-pair)
- [「この支払い方法では、アプリのリーダーのみ使用できます。」](#only-app-readers)
- [オフラインでは SumUp タイルを利用できない](#needs-a-connection)
- [「この店舗にはカードリーダーが設定されていません」](#no-card-readers)
- [「SumUp Terminal の端末が設定されていません」](#no-terminals)
- [決済が開始しない](#payment-wont-start)
- [「店舗管理者が SumUp アフィリエイトキーを入力する必要があります…」](#affiliate-key)
- [カードが拒否される](#card-declined)

<Anchor id="solo-wont-pair" />

**Solo をペアリングできない。** SumUp Solo を使用してください。クラウド経由でペアリングできるのはこのリーダーだけです。Bluetooth リーダーは WCPOS アプリから接続します。Solo がオンラインで、SumUp からログアウトしており、**接続 → クラウド API** のコードを表示していることを確認します。表示どおりにコードを入力してください。

<Anchor id="only-app-readers" />

**「この支払い方法では、アプリのリーダーのみ使用できます。」** レジがブラウザーまたはデスクトップアプリで動作し、**POS 接続**が **Bluetooth リーダー**になっています。iOS または Android アプリで決済するか、管理者に **POS 接続**を**クラウド経由の Solo**に変更して [Solo をペアリング](#pairing)してもらってください。このメッセージの**お困りですか？** リンクから、[カードリーダー](../../hardware/card-readers/index.mdx)ページが開きます。

<Anchor id="needs-a-connection" />

**オフラインでは SumUp タイルを利用できない。** カードリーダーは接続の復旧を待ちます。[オフライン決済](#offline-payments)を参照してください。

<Anchor id="no-card-readers" />

**「この店舗にはカードリーダーが設定されていません」。** ゲートウェイの[設定](#setup)がまだ済んでいないため、**カードリーダー**には次のメッセージだけが表示されます。

<JourneyShot manifest={manifest} device="tablet" step={1} maxWidth={720} alt="カードリーダーがまだ設定されていない店舗のレジで、設定の「カードリーダー」を選択した画面">

1. **この店舗にはカードリーダーが設定されていません** — [ゲートウェイの設定](#setup)を完了し、[リーダーを接続](#card-readers)してください。

</JourneyShot>

**クラウド経由の Solo**では、ペアリング済みの Solo は SumUp の行ではなく、**カードリーダー**の**スマートリーダー**に表示されます。

<Anchor id="no-terminals" />

**「SumUp Terminal の端末が設定されていません」。** Solo がペアリングされていないか、**有効な端末**の設定により、このレジで使える端末がありません。[クラウド経由で Solo をペアリングする](#pairing)を参照してください。

<Anchor id="payment-wont-start" />

**決済が開始しない。** WP Admin でゲートウェイのページを開きます。**SumUp に接続済み**と表示されているはずです。**接続失敗**と表示される場合は、**SumUp API キー**が正しくないか、無効になっています。Solo の電源が入り、充電済みでオンラインになっており、**設定済みリーダー**に表示されていることを確認してください。

<Anchor id="affiliate-key" />

**「店舗管理者が SumUp アフィリエイトキーを入力する必要があります…」。** Bluetooth リーダーに必要な**アフィリエイトキー**がゲートウェイに設定されていません。[ゲートウェイの設定](#setup)の手順 3 を参照してください。

<Anchor id="card-declined" />

**カードが拒否される。** 別のカードや支払い方法をお願いしてください。

**まだ解決しない場合**は、**チェックアウトのデバッグログ**にチェックを入れ、`WooCommerce > Status > ログ` で決済履歴を確認してください。[GitHub](https://github.com/wcpos/sumup-terminal-for-woocommerce/issues) で不具合を報告するか、アカウントやリーダーについて SumUp サポートにお問い合わせください。
