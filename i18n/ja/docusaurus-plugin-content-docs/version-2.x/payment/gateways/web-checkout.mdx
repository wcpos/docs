# Web Checkoutゲートウェイ {#web-checkout-gateway}

:::info Pro機能
Web Checkoutで支払いを受け付けるには、[WCPOS Pro](../../getting-started/free-vs-pro.mdx)が必要です。
:::

Web Checkoutでは、オンラインのカード入力フォームやウォレットなど、オンラインストアが提供する決済方法を使って、ストアの支払いページでPOSの注文をお客様に支払っていただけます。レジが対応していない方法でのお支払いを希望される場合に利用します。

目的の項目へ：[支払いを受け付ける](#take-payment) · [設定する](#set-up) · [問題が発生した場合](#goes-wrong)

## 支払いを受け付ける {#take-payment}

Web Checkoutはチェックアウトの**レガシー**タブにあります。接続が必要で、注文全額を請求します。すでに支払いを受け付けている場合は、先に[注文の一部が支払い済みの場合](#split)をご覧ください。

:::warning 「支払いを処理」を押すまでチェックアウトを開いたままにしてください
レジは別のタブの状態を監視しません。お客様が支払った注文で**支払いを処理**を押したときにのみ販売が完了するため、お支払い中はチェックアウトを開いたままにしてください。
:::

1. 通常どおり商品を登録し、**チェックアウト**を押します。
2. **レガシー**タブを開きます。POS内にストアの支払いページが読み込まれます。
3. **Web Checkout**を選択します。その下に説明文と**この注文の支払い**リンクが表示されます。
4. **この注文の支払い**を押します。この注文に対応するオンラインストアの支払いページが、ブラウザーの新しいタブで開きます。デスクトップアプリの場合は、コンピューターのウェブブラウザーで開きます。
5. お客様に画面を操作していただきます。お客様はウェブサイトでの購入と同じように、決済方法を選んで支払います。
6. お客様の支払いが完了すると、そのタブにストアの注文確認ページが表示されます。そのタブを開いたまま、POSに戻ります。
7. **支払いを処理**を押します。注文が支払い済みであれば、通常の販売と同じように、レジに支払い完了画面とレシートが表示されます。未払いの場合は、このページにとどまります。[問題が発生した場合](#goes-wrong)をご覧ください。
8. レジにレシートが表示されたら、お客様のタブを閉じます。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[28, 32], [30, 32], [-26, 0], [192, -272], [-30, 0], [230, 0], [-78, 0]]} maxWidth={1024} alt="レガシータブのチェックアウト：POS内にストアの支払いページが表示され、注文、ゲートウェイの一覧、「支払いを処理」ボタンが並んでいます。その横には注文番号と残額が表示されています">

1. **支払い**タブ — 現金、カード、専用タイルを持つゲートウェイのタイルが表示されます。
2. **レガシー**タブ — ストアの支払いページで動作するゲートウェイです。[レガシータブ](../../pos/checkout/legacy-tab.mdx)をご覧ください。
3. **閉じる** — 支払いを受け付けずにカートへ戻ります。注文は未完了のままです。
4. **ストアの支払いページ** — 注文に続いて、POS用に有効になっているゲートウェイが表示されます。Web Checkoutも有効にするとこの一覧に加わりますが、画像のストアでは有効になっていません。ページの表示が崩れている場合は、上部の**レジ設定**を使います。[問題が発生した場合](#goes-wrong)をご覧ください。
5. **支払いを処理** — お客様の支払いが完了したら押します。注文の支払いが完了するまで、レジはこのページにとどまります。
6. **注文** — 注文番号、お客様、時刻が表示されます。
7. **残額** — まだ支払われていない金額です。Web Checkoutは注文全額を請求するため、別の支払いを受け付けた後は利用できません。

### 注文の一部が支払い済みの場合 {#split}

レガシーゲートウェイは注文全額を請求するため、一度支払いを受け付けると、レガシータブに**支払いを受け付けた後はレガシーゲートウェイを利用できません**と表示されます。次のいずれかの方法を選んでください。

- 支払いタブにある現金やカードなどの**タイルで残額を受け付けます**。[分割払い](../../pos/checkout/split-payments.mdx)をご覧ください。
- **それまでに受け付けた支払いをキャンセルし**、Web Checkoutで注文全額を支払います。取り消しを行う前に、各支払いの処理内容がレジに一覧表示されます。現金はお客様に返し、その他の支払いはそれぞれの決済方法で取り消します。取り消せない支払いは注文から払い戻します。[支払いのキャンセル](../../pos/checkout/cancelling-a-payment.mdx)をご覧ください。

:::tip お客様が後でご自身のスマートフォンから支払いたい場合
Web Checkoutは、POSを実行している端末で支払いページを開きます。後で支払えるリンクをお客様に送るには、[請求書メール](./email-invoice.mdx)を利用してください。
:::

## 設定する {#set-up}

WP Adminでストアを管理している担当者が、Web Checkoutで初めて販売する前に一度だけ行います。Web Checkoutは無料のプラグインですが、POSで利用するにはWCPOS Proが必要です。Proがない場合、レジで受け付けられるのは現金とカードです。オンラインストアにすでにある決済方法を使うため、アカウントやキーは不要です。

<details>
<summary>ストア管理者向け：インストールして有効にする</summary>

1. **インストールします。** Web Checkoutは`WP Admin > POS > 設定 > 拡張機能`にはありません。[GitHubのリリースページ](https://github.com/wcpos/web-checkout-gateway/releases)から**woocommerce-pos-web-checkout-gateway.zip**（ソースコードのzipではありません）をダウンロードし、`WP Admin > プラグイン > Add Plugin`の**プラグインのアップロード**からアップロードして有効化します。
2. **POS用に有効にします。** `WP Admin > POS > 設定 > 支払い`で**Web Checkout**を有効にして保存します。[レジ設定](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)をご覧ください。オンラインストアのチェックアウトには表示されず、お客様はPOS経由でのみ利用できます。
3. **オンラインの決済方法を確認します。** お客様は、`WP Admin > WooCommerce > 設定 > 支払い`でウェブ用に有効になっている決済方法を使って支払います。少なくとも1つは、支払いを受け付けられる状態にしておく必要があります。

</details>

<details>
<summary>名前やメッセージを変更する</summary>

支払いページに表示される名前と説明文は、`WP Admin > WooCommerce > 設定 > 支払い > Web Checkout Gateway`にあるゲートウェイの**タイトル**と**説明**です。既定の説明文は「チェックアウトページに移動して注文の支払いを行ってください。支払い後、『支払いを処理』ボタンをクリックしてレシートに進んでください。」です。POSでの名前だけを変えるには、[レジ設定](../../settings/wp-admin/checkout.mdx#payment-gateways)でゲートウェイの **⋮**メニューを開き、**POS設定**内の**タイトル**を変更します。説明文は常にWooCommerceの設定が使われます。

</details>

<details>
<summary>開発者向け：仕組み</summary>

このプラグインは、IDが`wcpos_web_checkout`のWooCommerceゲートウェイを追加します。コード上でオンラインのチェックアウトでは無効にしているため、POSでのみ利用できます。決済欄には説明文と、その注文の支払いURL(`$order->get_checkout_payment_url()`)へのリンクが表示され、リンクは新しいウィンドウで開きます。

このゲートウェイ自体は代金を受け取りません。POSで作成され、`wcpos_web_checkout`が選択された支払い済みの注文を**支払いを処理**で送信すると、プラグインが支払いページを注文受付ページに移動し、POSが販売を完了します。未払いの注文は次に進みません。ソースコードは[web-checkout-gatewayリポジトリ](https://github.com/wcpos/web-checkout-gateway)にあります。

</details>

## 問題が発生した場合 {#goes-wrong}

**レガシータブの一覧にWeb Checkoutが表示されない。** プラグインが有効化されていないか、[レジ設定](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)でWeb Checkoutが有効になっていません。WCPOS Proがない場合、POSで利用できるのは現金とカードだけです。

**「POSで有効なレガシーゲートウェイがありません。」** タイルを持たないゲートウェイが1つも有効になっていません。レジ設定でWeb Checkoutを有効にしてください。

**「支払いを処理」を押してもレシートに進まない。** ストア側で注文が支払い済みになっていません。お客様に再度お支払いをお願いする前に、お客様のタブを確認してください。支払いページがまだ表示されている場合は、支払いが完了していません。注文確認ページが表示されている場合は、もう一度**支払いを処理**を押します。それでもレジが次に進まない場合は、`WP Admin > WooCommerce > Orders`で注文を確認してください。

**支払いページにお客様が利用できる決済方法が表示されない。** オンラインストアで、お客様に適した決済方法が有効になっていません。`WP Admin > WooCommerce > 設定 > 支払い`で、該当する決済方法をウェブ用に有効にしてください。

**POS内の支払いページの表示が崩れている。** テーマやプラグインが干渉している可能性があります。[ゲートウェイの支払いページの表示が崩れる](../../pos/checkout/troubleshooting.mdx#checkout-settings-troubleshooting)をご覧ください。
