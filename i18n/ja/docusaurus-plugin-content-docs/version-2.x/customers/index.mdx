顧客画面には、販売の顧客として指定できる店舗のWordPressユーザーが一覧表示されます。[WCPOS Pro](../getting-started/pro-license.mdx)を使用すると、WP Adminを開かずに、この画面で追加、編集、削除できます。Proがなくても、既存の顧客を販売に指定できます。[販売の顧客](#on-a-sale)をご覧ください。

<details>
<summary>Proがない場合の顧客画面</summary>

WCPOS Proがない場合、アップグレード案内カードの背後の一覧はぼかして表示され、**新規顧客を追加**と各行の **›** はグレー表示になります。**表示オプション**は引き続き使用できます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[0, 0], [560, 0], [-40, 0], [-45, 0], [-30, 0], [150, 0]]} alt="WCPOS Proがない場合の顧客画面：ぼかされた一覧の上に検索欄とグレー表示の新規顧客を追加ボタンがあり、Proにアップグレードのカードにはデモを見るとProにアップグレードが表示されています">

1. **顧客** — メニューからこの画面を開きます。
2. **顧客を検索** — 名前、メールアドレス、電話番号、納税者番号の一部を入力します。
3. **新規顧客を追加** — WCPOS Proがない場合はグレー表示になります。
4. **Proにアップグレード** — 一覧の上に表示されるカードです。
5. **デモを見る** — WCPOSデモ店舗の顧客画面を開きます。
6. **Proにアップグレード** — wcpos.com/proを開きます。

</JourneyShot>

</details>

## 販売の顧客 {#on-a-sale}

各販売は店舗のデフォルト顧客で始まります。[デフォルトのPOS顧客](../settings/wp-admin/general.mdx#default-pos-customer)で指定したユーザー、または[レジ係のアカウントを使用](../settings/wp-admin/general.mdx#use-cashier-account)がオンの場合はレジ係が設定されます。別の顧客を選ぶには、カート内の顧客名をタップします。[顧客を選択する](../pos/cart/index.mdx#customer-selector)をご覧ください。

:::note 顧客を変更すると税額が変わる場合があります
店舗で[顧客の住所に基づいて税金を計算する](../settings/store/tax.mdx#calculate-tax-based-on)場合、別の顧客を選択または追加したり、カート内で顧客の住所を変更したりすると、カート内の商品の税額が変わることがあります。税抜価格は変わりません。[免税](../pos/cart/index.mdx#tax-exempt)の注文では税額は再計算されません。
:::

<JourneyShot manifest={cartManifest} device="tablet" step={2} alt="カートの顧客を選択の検索欄にSmithを入力した状態。上部にゲスト、その下に一致する顧客が表示されています">

1. **顧客を選択** — 名前、メールアドレス、電話番号の一部を入力します。
2. **ゲスト** — 顧客アカウントを使わない販売です。
3. **顧客** — タップすると、請求先住所と配送先住所とともに注文に設定されます。

</JourneyShot>

## 顧客を検索する {#find}

メニューから**顧客**を開きます。**顧客を検索**に名前、メールアドレス、電話番号を入力します。

<details>
<summary>検索できる項目</summary>

入力したすべての語が、名前、メールアドレス、ユーザー名、会社名、電話番号、納税者番号の各フィールドのいずれかに一致する必要があります。語の順序は問いません。たとえば、`jane acme`で会社名がAcmeのJaneが見つかります。[検索の一致条件](../reference/search.mdx#customers)をご覧ください。

</details>

一覧は最初、姓のAからZの順に並んでいます。**名**、**メールアドレス**、**作成日**などの見出しをタップすると、その列で並べ替えられ、もう一度タップすると逆順になります。フッターには、表示中の顧客数と総顧客数が表示されます。

## 顧客を追加する {#add-new-customer}

1. 検索欄の横にある**新規顧客を追加**を押します。空の**顧客を追加**フォームが開きます。
2. 顧客の**メールアドレス**を入力します。必須項目はこれだけです。
3. **名前**、**電話番号**など、わかる情報を追加します。下部の**住所とその他の任意項目**を開いてください。
4. **顧客を追加**を押します。顧客名を含むメッセージが表示され、フォームが閉じます。

販売の途中で顧客を追加する場合は、カートの追加メニューから**新規顧客を追加**を使用します。同じフォームが開き、顧客はそのまま注文に設定されます。[新規顧客を追加する](../pos/cart/index.mdx#new-customer)をご覧ください。

<details>
<summary>住所とその他の任意項目</summary>

フォームには最初、**名前**、**メールアドレス**、**電話番号**、**ユーザー名**が表示されます。

- **ユーザー名** — 顧客の追加時にのみ設定できます。デフォルトでオンになっている[顧客のメールアドレスからユーザー名を自動生成](../settings/wp-admin/general.mdx#automatically-generate-username-from-customer-email)が有効な場合、空欄にすると店舗がメールアドレスからユーザー名を生成します。

それ以外の項目は下部にボタンとして表示されます。ボタンを押すと、その項目の行が追加されます。

- **会社名**、**請求先住所**、**配送先住所**。**配送先住所**は、**別の住所を使用**を押すまで**請求先と同じ**に設定されています。
- **パスワード** — 入力しなければ、店舗が生成します。
- **納税者番号** — 種類、ID、国を指定します。新しい行には、請求先の国に対応する種類が設定されます。請求先住所がない場合は、店舗の国に対応する種類が設定されます。「形式が選択した種類と一致しません。」は警告のみで、IDは保存されます。
- **カスタムフィールド** — キーと値を指定し、顧客のアカウントに保存します。

顧客の権限グループはここではなく、WP Adminで設定します。

</details>

## 顧客を編集する {#edit-customer}

1. 顧客を開きます。タッチ画面では顧客をタップします。マウスでは行の末尾の **›** をクリックします。**アクション**列が非表示の場合は、行自体をクリックします。顧客名をタイトルに含む**編集**ダイアログが開きます。
2. 項目を変更します。**保存**ボタンはありません。入力を止めて少し待つと、変更が保存されます。
3. 項目の横に緑色の**保存済み**マークが表示されることを確認します。
4. 完了したら**閉じる**を押します。

<details>
<summary>アカウントへのアクセスと顧客情報の更新</summary>

- **パスワード**は入力中ではなく、入力欄からフォーカスを移したときに保存されます。
- `@`のないメールアドレスなど、**フォームで受け付けられない値**を入力すると、項目の下にエラーが表示され、保存されません。
- **ユーザー名**は変更できません。作成時に設定されます。
- **権限グループ**は変更できません。WordPressで設定します。
- **同期**は保存待ちの変更を保存してから、店舗から顧客を再取得します。顧客情報が古いと思われる場合に使用してください。
- **JSON**は、この端末に保存されている顧客レコードを表示します。サポートからPOSに保持されている情報を尋ねられた際に使用します。

</details>

## 顧客を削除する {#delete-customer}

:::warning 削除は取り消せません
顧客を削除すると、店舗のWordPressユーザーが削除されます。WordPressユーザーにはゴミ箱がないため、元に戻すことはできません。
:::

**編集**ダイアログで**削除**を押します。**確認**にチェックを入れ、もう一度**削除**を押します。

**削除**は、ユーザーを削除する権限があるレジ係にのみ表示されます。ショップマネージャーや他のレジ係などのスタッフアカウントを編集または削除できるのは管理者だけです。[アクセス権限](../settings/wp-admin/access.mdx)をご覧ください。

WP Adminで削除された顧客は、次回の同期でPOSの一覧からも削除されます。

## 表示設定 {#display-settings}

**表示オプション**（**新規顧客を追加**の横にあるスライダー）を押すと、**顧客設定**が開きます。列の表示をオンまたはオフにしたり、ハンドル（⠿）をドラッグして移動したりできます。この設定は、この端末にのみ保存されます。

1. **デフォルト設定に戻す** — 列を初期状態に戻します。初期状態は、下記のデフォルトの列に記載しています。
2. **閉じる** — パネルを閉じます。変更はその都度反映されます。

## 問題が発生した場合 {#goes-wrong}

### ボタンがグレー表示になる {#greyed}

- **新規顧客を追加がグレー表示になる** — 店舗にWCPOS Proが必要か、現在の権限グループでは顧客を追加できません。管理者が[アクセス権限](../settings/wp-admin/access.mdx)で許可できます。マウスの場合、ボタンにポインターを合わせると理由を確認できます。
- **› がグレー表示で顧客を開けない** — 現在の権限グループでは顧客を編集できません。管理者が[アクセス権限](../settings/wp-admin/access.mdx)で許可できます。

### 変更が保存されない {#not-saving}

- **「顧客の保存に失敗しました」** — 入力内容を保持したままフォームが開いています。**顧客を追加**をもう一度押してください。
- **項目の横に「未保存」と表示される** — その変更は保存されていません。もう一度入力してください。
- **顧客は保存されたが、この注文に追加されなかった** — カートの**新規顧客を追加**で発生することがあります。カートでその顧客を検索し、再度追加してください。

### 顧客が見つからない、または一覧の表示がおかしい {#list-wrong}

- **「更新できませんでした。この端末のデータは変更されていません」** — **同期**で店舗に接続できませんでした。接続を確認して、もう一度**同期**を押してください。
- **いるはずの顧客が見つからない** — オフライン時は、この端末に保存されている顧客だけが検索対象になります。[端末内と店舗内の検索](../reference/search.mdx#device-and-store)をご覧ください。
- **一覧の表示がおかしい** — フッターの同期ボタンを長押しして、**クリアして更新**を選択してください。この端末の顧客一覧を消去して再ダウンロードします。店舗のデータは変更されません。
