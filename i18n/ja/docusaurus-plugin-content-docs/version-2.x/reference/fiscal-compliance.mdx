**設定ではなく参考情報です：** 税務規則に関連してWCPOSが記録する内容を、国ごとに説明します。

国によっては、レジの認証取得、改ざんできない記録の保存、売上ごとの税務当局への報告が義務付けられています。該当する国でWCPOSを使って実際の販売を始める前に、このページを確認してください。

:::warning WCPOSは認証済みのレジではありません
WCPOS 2.0は、どの国でも税務に関する認証を取得していません。営業する地域の法律で認証済みのレジが必要な場合、現時点ではWCPOSをそのレジとして使用できません。実際の販売を始める前に、その国でレジに求められる要件を会計士や税務当局に確認してください。レジ係の方は店舗のオーナーに確認してください。
:::

## WCPOSの対応状況 {#where-wcpos-stands}

営業する地域を確認してください。各行から、下にある詳しい説明に移動できます。2.1で予定しているのは各国が求める記録への対応であり、認証取得を約束するものではありません。

| 地域 | WCPOS 2.0 |
|---|---|
| [フランス](#france-nf525) | NF525認証未取得。必要な記録への対応は[2.1](../getting-started/roadmap.mdx#fiscal-compliance)で予定しています。 |
| [スペイン](#spain-verifactu) | VeriFactu未対応。必要な記録への対応は[2.1](../getting-started/roadmap.mdx#fiscal-compliance)で予定しています。 |
| [ノルウェー](#norway-kassasystemloven) | 税務当局への届出なし。現時点では対応予定もありません。 |
| [チリ](#chile-sii) | 税務当局への送信機能なし。現時点では対応予定もありません。 |
| [EU OSS](#eu-oss) | VAT制度。OSS報告書は作成せず、WooCommerceの税率を使用します。 |
| [その他の国](#other-regulated-markets) | ドイツ、イタリア、オーストリア、ポルトガル、チェコ：未対応で、現時点では対応予定もありません。 |

## 国別の対応状況 {#country-status}

法律や適用日は変更されることがあります。フランス、スペイン、ノルウェー、チリについてリンクしている情報源は、2026年11月に確認したものです。このページと税務当局の説明が異なる場合は、税務当局の説明を優先してください。

### フランス：NF525 {#france-nf525}

WCPOSはNF525認証を取得しておらず、開発元による適合宣言も発行していません。フランスの規則が求める記録への対応は、スペインとともに[2.1](../getting-started/roadmap.mdx#fiscal-compliance)で予定しています。

<details>
<summary>フランスの規則と情報源</summary>

2018年以降、フランス一般租税法第286条により、顧客からの支払いをレジソフトウェアに記録するVAT登録事業者は、不正防止規則を満たすシステムの使用が義務付けられています。適合の証明には、NF525などの認証またはソフトウェア開発元による自己宣言（_適合証明書_）が必要です。[フランス税務当局のガイダンス](https://bofip.impots.gouv.fr/export/pdf/12315)（フランス語）を参照してください。

</details>

### スペイン：VeriFactu {#spain-verifactu}

WCPOSはまだVeriFactuに対応していません。必要な記録への対応は、フランスとともに[2.1](../getting-started/roadmap.mdx#fiscal-compliance)で予定しています。

<details>
<summary>スペインの規則と情報源</summary>

VeriFactu（勅令1007/2023）は、事業者が請求書の発行に使用するソフトウェアの規則を定めています。勅令法15/2025により適用開始日が定められ、法人は2027年1月1日から、同勅令の対象となるその他の事業者は2027年7月1日から対応が必要です。[スペイン税務庁のVeriFactuに関する質問集](https://sede.agenciatributaria.gob.es/Sede/iva/sistemas-informaticos-facturacion-verifactu/preguntas-frecuentes/sistemas-verifactu.html)（スペイン語）を参照してください。

</details>

### ノルウェー：レジシステム法 {#norway-kassasystemloven}

WCPOSはノルウェー税務当局（Skatteetaten）への届出を行っておらず、現時点では予定もありません。

<details>
<summary>ノルウェーの規則と情報源</summary>

ノルウェーのレジシステム法（_kassasystemloven_）では、レジの供給者にSkatteetatenへの製品届出が義務付けられています。[Skatteetatenのレジに関するページ](https://www.skatteetaten.no/bedrift-og-organisasjon/starte-og-drive/rutiner-regnskap-og-kassasystem/kassasystem/)（ノルウェー語）を参照してください。

</details>

### チリ：SII {#chile-sii}

WCPOSはチリの内国歳入庁（Servicio de Impuestos Internos、SII）に接続しないため、承認済みの電子レシート（_boletas_）を発行できません。[レシートテンプレートの変更](../receipts/customise.mdx)はできますが、SIIにレシートを送信する機能はありません。[SIIの電子レシートに関する質問集](https://www.sii.cl/preguntas_frecuentes/bol_electr_vtas_serv/001_380_6568.htm)（スペイン語）を参照してください。

### EU：ワンストップショップ（OSS） {#eu-oss}

WCPOSにはEUのVATワンストップショップ制度に対応した機能はなく、OSS報告書も作成しません。POSは、**税の計算基準**で指定された住所に基づいてWooCommerceに設定された税率を適用し、オンラインショップ側でも同じ税率で注文を再計算します。別のEU加盟国へ発送する販売にその国のVATを適用するには、WooCommerceにその国の税率を登録し、顧客の住所に基づいて注文の税額を計算する必要があります。[税額の計算方法](#how-wcpos-handles-tax)を参照してください。

### その他の国 {#other-regulated-markets}

ドイツ、イタリア、オーストリア、ポルトガルには独自の税務上のレジ規則があり、チェコでも新たな規則の導入が進んでいます。WCPOSはまだいずれにも対応していません。フランスとスペインで必要な記録への対応は2.1で予定していますが、これらの他の国への対応は現時点では予定していません。

## 2.0ですでに記録される内容 {#what-2-0-records}

各国の規則の基礎となる記録は、Proだけでなく無料プラグインでも、すべてのレジですでに保存されています。ただし、まだ署名も税務当局への送信も行わないため、これだけでWCPOSが法令に適合するわけではありません。

<details>
<summary>各レジが記録する内容</summary>

- **販売ごとに使用したレジ。** 各注文と各レシートには会計を行ったレジが記録され、レシートにはWCPOSのバージョンも記載されます。
- **オフライン販売の実際の日時。** 接続がない状態で行った販売は、店舗に届くのがどれだけ遅れても、販売時の日時と使用したレジが保持されます。
- **払い戻しと取消を独立した記録として保存。** 払い戻しや取消によって元の販売が変更されることはありません。それぞれ編集できない独立した記録となり、修正対象の販売を参照します。払い戻しでは、対象の販売を記載したクレジットノートとして、専用のレシートも印刷されます。
- **番号付きの締め記録。** レジを締めるたびに、締め記録が一度だけ書き込まれ、番号が付けられます。[現金の集計とレジ締め](../pos/register/index.mdx#close)を参照してください。
- レシートには**税務用QRコードの欄**があり、各国の規則に応じて値が設定されるまでは空欄になります。

[税務規則に対応するためのレシートと払い戻し](../getting-started/whats-new.mdx#receipts-and-refunds)を参照してください。

</details>

## 税額の計算方法 {#how-wcpos-handles-tax}

最終的に採用されるのは店舗側の金額です。POSに表示された合計と店舗側で計算した合計が異なる場合、POSには**店舗がこの注文の合計を変更しました**と表示されます。[合計が一致しない場合](../support/troubleshooting/totals-disagree.mdx)を参照してください。

<details>
<summary>POSとオンラインショップでの税額計算</summary>

POSはWooCommerceからコピーした税率を使い、端末上で税額を計算するため、接続がなくてもカートに合計を表示できます。注文がオンラインショップに届くと、WooCommerceが注文の明細から合計を再計算します。

そのため、WooCommerceの注文合計の計算に作用する税規則やプラグインは、POSでの販売にも適用されます。一方、ウェブサイトの購入手続きページだけに作用するプラグインは適用されません。POSの注文はそのページを経由しないためです。税率の決定に使う住所は**税の計算基準**で指定します。[税設定](../settings/store/tax.mdx#calculate-tax-based-on)を参照してください。

</details>

<details>
<summary>開発者向け：税務フィールドへの値の設定</summary>

税務対応プラグインは、販売記録の書き込み時に`wcpos_fiscal_snapshot_enrich`フィルターを通じて、QRコードや署名などのレシートの税務フィールドに値を設定します。この処理は記録への採番中に実行されるため、ネットワーク呼び出しを行わずローカルで処理する必要があります。税務当局への送信は、記録の作成後に行ってください。フィールドの一覧は[レシートデータ](../receipts/receipt-data.mdx#fiscal)にあります。表示時のレシートのフィールドを`wcpos_receipt_data`で変更しても、記録済みの税務データは置き換わりません。

</details>

## お住まいの国で必要な対応をお知らせください {#tell-us}

多くの店舗から要望がある国を優先します。営業する地域と税務当局の要件を[コミュニティ](https://wcpos.com/discord)でお知らせいただくか、[機能をリクエスト](../getting-started/roadmap.mdx#request-or-vote)してください。
