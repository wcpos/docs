WCPOSはWooCommerceサイト向けのプラグインです。一度インストールすれば、ブラウザーで`yourdomain.com/pos`にアクセスしてPOSを使えます。デスクトップアプリとモバイルアプリの利用は任意です。どちらも同じPOSを開き、同じサイトにサインインします。

インストールはウェブサイトの管理担当者が行います。レジ係の方は[POSを開く](#accessing-the-pos)から始められます。

## サイトの準備を確認する {#server-requirements}

- **WooCommerce 9.0**以降がインストールされ、有効になっていること。WP Adminの**プラグイン**で確認できます。
- **WordPress 5.6**以降、Proの場合は5.8以降。WP Adminの**ダッシュボード**で確認できます。
- **PHP 7.4**以降。ホスティングのアカウントで確認するか、ホスティング会社にお問い合わせください。
- **パーマリンク**が**基本**以外に設定されていること。WP Adminの**設定 › パーマリンク**で確認できます。

WCPOS 2.0にはWooCommerce 9.0が必要です。1.xはそれより古いバージョンでも動作していました。現在WCPOS 1.xを使っている店舗では、更新を行う前に[2.0へのアップグレード](./upgrading-to-2.mdx)をお読みください。

利用の多い店舗では、最低要件を満たすことに加え、サーバーの性能も重要です。[サーバーのパフォーマンス](../support/performance/server.mdx#minimum-server-requirements)をご覧ください。

## プラグインをインストールする {#installing-the-plugin}

1. WP Adminで**プラグイン**を開き、新しいプラグインを追加します。
2. **WCPOS**を検索します。検索結果には、kilbotによる**WCPOS – Point of Sale (POS) plugin for WooCommerce**として表示されます。
3. **今すぐインストール**を押し、続いて**有効化**を押します。

WordPressはWordPress.orgのプラグインディレクトリから最新リリースをインストールします。このページはWCPOS 2.0以降について説明しています。プラグインを有効化したら、[インストール済みのバージョンを確認する](#check-versions)の手順で**サーバー**欄のバージョンを確認できます。**プラグイン**ページでバージョンが1.11以前と表示される場合はWCPOS 1.xです。その場合は[1.xのインストールガイド](/1.x/getting-started/installation)に従ってください。

WP Adminに**POS**メニューが追加されます。**POSを表示**でPOSが開き、**設定**にはプラグインの設定、**テンプレート**にはレシートのテンプレートがあります。無料プラグインでは、メニューに**Proにアップグレード**も表示されます。

1. **POS** — WP Adminにあるプラグインのメニューです。

:::

## POSを開く {#accessing-the-pos}

1. ブラウザーで`yourdomain.com/pos`にアクセスするか、WP Adminで**POS › POSを表示**を選びます。
2. WordPressのユーザー名とパスワードでサインインします。
3. 店舗に複数のレジがある場合、初回にPOSから**この端末はどのレジで使用しますか？** と尋ねられます。使用するレジを選んでください。[店舗・レジ・端末](../stores/registers-and-devices.mdx)をご覧ください。
4. カートに**レジを開く**カードが表示された場合は、ドロワー内の現金額を入力し、**レジを開く**を押します。このカードは、**レジの開閉**が有効で、レジが閉じているときにのみ表示されます。[レジ](../settings/wp-admin/registers.mdx)をご覧ください。

接客の準備はできましたか？[チェックアウト](../pos/checkout/index.mdx)に従って、最初の販売を行いましょう。以下は検索語を入力し、**在庫あり**フィルターを有効にしたPOS画面です。両方を解除すると、ほかの商品も表示されます。見つからない商品がある場合は、[検索と絞り込み](../pos/product-panel/search-filtering.mdx#no-match)をご覧ください。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [114, 0], [-9, 22], [141, 0], [44, 0], [44, 0], [44, 0]]} alt="ブラウザーで開いたPOS。左側のメニューではPOSが選択され、下部に健全性、設定、サポートがあります。商品検索と、カートの上に店舗名とレジ係のアバターが表示されています">

1. **POS** — レジ画面を開きます。左側に商品、右側にカートが表示されます。スマートフォンでは、それぞれ別のタブに表示されます。[チェックアウト](../pos/checkout/index.mdx)をご覧ください。
2. **レジバー** — 販売を行う店舗と、店舗に複数のレジがある場合はレジが表示されます。[店舗・レジ・端末](../stores/registers-and-devices.mdx)をご覧ください。
3. **アバター** — レジ係パネルを開きます。ドロワーの操作、引き継ぎ、サインアウトができます。ブラウザーでは**デスクトップアプリ**のリンクもあります。[レジ係パネル](../pos/register/index.mdx#cashier-sheet)をご覧ください。
4. **商品を検索** — 名前、SKU、バーコードで商品を探せます。[商品](../pos/product-panel/index.mdx)をご覧ください。
5. **健全性** — この端末と店舗が正常に通信しているかを確認し、問題がある場合の対処方法を調べられます。[店舗の健全性](../support/store-health.mdx)をご覧ください。
6. **設定** — 言語、印刷、カードリーダー、バーコードスキャン、テーマなどを設定します。[設定](../settings/index.mdx)をご覧ください。
7. **サポート** — POS内からDiscordのWCPOSコミュニティを利用できます。[サポート](../support/index.mdx)をご覧ください。

</JourneyShot>

初めて開くと、POSは商品を端末にコピーします。これにより、接続が切れても販売を続けられます。[オフライン](./offline.mdx)をご覧ください。

管理者とショップマネージャーは、すぐにPOSを使えます。それ以外の方のために、プラグインは**レジ係**の権限グループを追加します。販売担当者にこの権限グループを割り当ててください。[アクセス](../settings/wp-admin/access.mdx)をご覧ください。

### WordPressへのサインインは必要ですか？ {#sign-in}

はい。POSはWordPressアカウントを使用し、POS専用のログインはありません。このブラウザーでWordPressにサインインしていない場合、`/pos`にアクセスするとWordPressのサインインページが開き、サインイン後にPOSが開きます。

サインインしたのに**このアカウントではPOSを使用できません**と表示されますか？WordPressの権限グループにPOSの使用が許可されていません。[アクセス](../settings/wp-admin/access.mdx#goes-wrong)をご覧ください。

`/pos`でページが見つからないと表示されますか？[「`/pos`でページが見つからないと表示される」](#pos-not-found)をご覧ください。

## デスクトップアプリとモバイルアプリを入手する {#app-requirements}

ブラウザーでは、追加で必要なものはありません。最新版のChrome、Edge、Firefox、Safariのいずれかを使い、JavaScriptを有効にして通常のウィンドウで開いてください。プライベートウィンドウでは、利用中に端末上のPOSデータが消去されることがあり、閉じるとデータが削除されます。

アプリは、専用のウィンドウで同じPOSを実行します。お使いの端末用のアプリをダウンロードしてください。

- **Windows** — Windows 10以降、64ビット（x64）。[Windowsインストーラー](https://updates.wcpos.com/v1/electron/download/win32-x64)をダウンロードしてください。
- **macOS** — macOS 12 Monterey以降。[Apple silicon](https://updates.wcpos.com/v1/electron/download/darwin-arm64)版または[Intel](https://updates.wcpos.com/v1/electron/download/darwin-x64)版をダウンロードしてください。
- **Linux** — 64ビット（x64）。[Debian・Ubuntu向けの.deb](https://updates.wcpos.com/v1/electron/download/linux-x64)または[Fedora・Red Hat向けの.rpm](https://updates.wcpos.com/v1/electron/download/linux-x64-rpm)をダウンロードしてください。
- **iPhoneとiPad** — iOS・iPadOS 16.4以降。[TestFlightのベータテスト](https://testflight.apple.com/join/JGBdVRrW)にご参加ください。
- **Android** — Android 10以降。[Google Playのベータテスト](https://play.google.com/apps/testing/com.wcpos.main)にご参加ください。

アプリを開き、**接続**画面で店舗を追加します。[店舗への接続](./connect.mdx)をご覧ください。

ブラウザー版POSのレジ係パネルにある**デスクトップアプリ**リンクからも、デスクトップアプリのダウンロードページを開けます。

1. **WordPress管理画面** — サイトのWP Adminを開きます。
2. **デスクトップアプリ** — デスクトップアプリのダウンロードページです。
3. **サインアウト** — ブラウザーでは、WordPressからもサインアウトします。

:::note アプリからの印刷
Bluetoothプリンターやネットワークプリンターを使うには、アプリにBluetoothとローカルネットワークへのアクセス権限が必要です。アプリから求められたら許可してください。[Androidの権限](../hardware/printers/android-permissions.mdx)と[iOSのローカルネットワーク](../hardware/printers/ios-local-network.mdx)をご覧ください。
:::

## WCPOS Proを使う場合 {#with-pro}

### どのダウンロードがProですか？ {#which-download}

インストール後、二つのプラグインは**プラグイン**ページに次の名前で表示されます（上で紹介したWordPress.orgの掲載名では、無料版により長い名前が使われています）。

- **WCPOS – Point of Sale for WooCommerce**は、WordPress.orgから入手できる無料プラグインです。
- **WCPOS Pro – Point of Sale for WooCommerce**がProです。wcpos.comアカウントの[ダウンロード](https://wcpos.com/account/downloads)ページからのみ、zipファイルとして入手できます。

### データを失わずに無料プラグインからProへ切り替える {#pro-over-free}

無料プラグインを残したままProをインストールしてください。先に何かを削除する必要はありません。Proが起動すると無料プラグインを無効化し、その旨の通知を表示します。

データは保持されます。Proには無料プラグインのコードが含まれているため、サイトにすでにあるPOS設定、レシートテンプレート、レジをそのまま使います。無料プラグインを無効化しても、これらは削除されません。また、注文、商品、顧客はWooCommerceのデータであり、どちらのプラグインも削除しません。

続いて、ライセンスキーを有効化します。[ライセンスキーの有効化](./pro-license.mdx#activate)をご覧ください。

## 問題が発生した場合 {#troubleshooting}

WP Adminの上部に **「WCPOSにはWooCommerce 9.0以降が必要です」** と表示される。WooCommerceが未インストール、無効、または9.0より古い状態です。インストールまたは更新してから有効化してください。まだWCPOS 1.xを使っている店舗では、[2.0へのアップグレード](./upgrading-to-2.mdx#if-your-store-isnt-ready-yet)に従ってください。 {/* pending: docs#675 */}

**「WCPOSにはPHP 7.4以降が必要です」** と表示される。サイトのPHPを新しいバージョンに変更するよう、ホスティング会社に依頼してください。

**「WooCommerce REST APIが正しく動作するには、プリティーパーマリンクが必要です」** と表示される、または`yourdomain.com/pos`でサイトの「ページが見つかりません」が表示される。[「`/pos`でページが見つからないと表示される」](#pos-not-found)をご覧ください。

**「WordPressサイトのWCPOSプラグインを更新してください。」** アプリがプラグインより新しい状態です。**プラグイン**でWCPOSを更新してください。[AUTH331](../error-codes/AUTH331.mdx)をご覧ください。

**「この端末のPOSアプリを更新してください。」** プラグインがアプリより新しい状態です。ブラウザーではページを再読み込みし、アプリでは更新をインストールしてください。[SYNC341](../error-codes/SYNC341.mdx)をご覧ください。

**サインインウィンドウにエラーや空白のページが表示される。** 多くの場合、セキュリティ、ファイアウォール、ログイン関連のプラグインが妨げています。[プラグインの競合](../support/troubleshooting/plugin-conflicts.mdx#security-and-login-plugins)をご覧ください。

サインイン後に **「このアカウントではPOSを使用できません」** と表示される。WordPressの権限グループにPOSの使用が許可されていません。[アクセス](../settings/wp-admin/access.mdx#goes-wrong)をご覧ください。

**Windows のインストーラーで「Installation has failed」と表示される、または起動しない。** [Windows でインストールに失敗する](#windows-install-fails)を参照してください。

**解決しませんか？** [Discord](https://wcpos.com/discord)でご質問ください。ライセンスや非公開の内容に関するお問い合わせは、support@wcpos.comにメールをお送りください。[サポート](../support/index.mdx)をご覧ください。

### `/pos`でページが見つからないと表示される {#pos-not-found}

サインインの有無にかかわらず、`yourdomain.com/pos`でサイトの「ページが見つかりません」が表示される場合、主に次の二つの原因が考えられます。

- **パーマリンクが「基本」に設定されている。** POSのアドレスには、ほかの設定が必要です。WP Adminに **「WooCommerce REST APIが正しく動作するには、プリティーパーマリンクが必要です」** と表示されます。通知の**パーマリンクを有効化**を押すか、**設定 › パーマリンク**を開いて別の設定を選び、**変更を保存**を押してください。
- **POSのアドレスが異なる。** 管理者は`pos`を別の文字列に変更できます。**設定 › パーマリンク**の**POSベース**を確認してください。[ブラウザーでPOSを開く](./connect.mdx#web)をご覧ください。

### Windows でインストールに失敗する {#windows-install-fails}

このアプリは 64 ビット (x64) 専用です。32 ビット版や ARM 版はありません。[デスクトップアプリとモバイルアプリを入手する](#app-requirements)を参照してください。

Windows インストーラーはコード署名されていないため、Setup をダブルクリックすると、青い **「Windows によって PC が保護されました」** 画面に**不明な発行元**と表示されることがあります。続行するには、**詳細情報**を選択してから**実行**を選択します。以下のように PowerShell から Setup を起動した場合、この画面は表示されません。

WCPOS 1.11.8〜1.11.11 と 2.0.0 には既知の問題があります。Setup をダブルクリックすると、**「Installation has failed」** と表示されて停止することがあります。修正は次のリリースで提供される予定です。それまでは、代わりに PowerShell からインストールしてください。

1. **WCPOS を終了します。** タスクマネージャーを開き、実行中の **WooCommercePOS** プロセスをすべて終了します。WCPOS が実行中のままだと、次の手順はメッセージなしで失敗します。
2. **ダウンロードフォルダーで PowerShell を開きます。** エクスプローラーで `WCPOS-2.0.0-Setup.exe` があるフォルダーを開きます。空白部分を右クリックし、**ターミナルで開く**を選択します。
3. **インストーラーをサイレントモードで実行します：**
   ```powershell
   .\WCPOS-2.0.0-Setup.exe --silent
   ```
   別のバージョンをダウンロードした場合は、お使いの Setup ファイルの名前を使用してください。ウィンドウは表示されません。1 分ほど待ちます。
4. デスクトップまたはスタートメニューのショートカットから **WCPOS を開きます。**

この方法は、失敗した Setup が中途半端に残したインストールの修復にもなります。ストアと設定は `%AppData%\WCPOS` にあり、インストーラーはこれらに触れません。

すでに WCPOS をインストール済みの場合、この手順は不要です。アプリ内からの更新（「更新が見つかりました」の通知）は通常どおり動作します。

それでも失敗する場合は、support@wcpos.com にメールするか、[Discord](https://wcpos.com/discord) でお尋ねください。その際、次の情報をお送りください：

- インストーラーのログ `%LocalAppData%\SquirrelTemp\Squirrel-Install.log`（古いバージョンでは `SquirrelSetup.log`）。
- 実行したセットアップファイルの名前と、それ以前に使用していた WCPOS のバージョン (ある場合)。
- お使いの Windows のバージョン。Win+R を押して `winver` と入力すると確認できます。
- お使いのウイルス対策製品。
