プラグインを以前のバージョンに戻す必要がある場合に、このページを参照してください。多くの場合、2.0から1.11に戻す操作です。WP Adminで自動更新を無効にし、目的のバージョンをダウンロードして、現在のプラグインに上書きアップロードします。途中で何も削除しないため、注文、設定、レシートテンプレートはそのまま残ります。

:::tip まずはご相談ください
[Discord](https://wcpos.com/discord)またはsupport@wcpos.comで、発生した問題をお知らせください。アップグレード直後の問題の多くは、以前のバージョンに戻すよりも早く解決できます。
:::

## 始める前に {#before-you-start}

- **同期できるレジをすべて同期してください。** 各レジでPOSを開き、保持している売上データを店舗に送信させます。**送信待ちの変更**が0になり、判断を求めるパネルがなく、未同期の未完了注文もない状態で作業を始めてください（[確認方法](#check-sync)）。1.11のレジに未送信の売上データが残っているためにバージョンを戻す場合、そのレジは1.11に戻すまで送信できません。バージョンを戻してから同期してください。
- **アプリを使っているレジを確認してください。** すでに2.0に更新したデスクトップアプリやモバイルアプリは、1.11のプラグインに接続できず、[AUTH331](../error-codes/AUTH331.mdx)が表示されます。アプリストアでは古いアプリを入手できません。再びアップグレードするまでは、それらのレジで`yourdomain.com/pos`のブラウザー版POSを使う準備をしてください。
- **管理者にログインしてもらってください。** プラグインをインストールできるWordPressの管理者アカウントが必要です。
- **WCPOS Proをお使いの場合は、WCPOS Proだけを以前のバージョンに戻してください。** 無料プラグインの機能も含まれています。

2.0から戻す場合は、アップグレードのページにある[以前のバージョンに戻す](./upgrading-to-2.mdx#rolling-back)もお読みください。

### レジがすべて送信済みか確認する {#check-sync}

各レジで[店舗の状態](../support/store-health.mdx#database)を開き、**データベース**タブを確認します。集計対象は現在ログインしているレジ係と店舗だけなので、そのレジを使うすべてのレジ係について、利用する店舗ごとに確認してください。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [140, 0], [170, 0]]} alt="タブレットの店舗の状態でデータベースタブを開いた画面：販売準備完了、この端末のレコード、使用中のストレージ、送信待ちの変更0件">

1. **店舗の状態**：メニューの下部にある脈拍のアイコンです。
2. **データベース**：タブレットやパソコンでは、店舗の状態を開くとこのタブが表示されます。
3. **送信待ちの変更**：**0**で、数値の下にパネルがなく、未同期の未完了注文もなければ、そのレジはすべて送信済みです。0より多い場合は、送信できるようにPOSを開いたままオンラインにしておいてください。未完了注文は集計に含まれないため、各注文で[注文を同期](../pos/cart/open-orders.mdx#sync-order)を押します。店舗が拒否した変更や選択が必要な変更はパネルに表示されます。先に解決してください（[対応が必要なとき](../support/store-health.mdx#needs-attention)）。

</JourneyShot>

## 自動更新を無効にする {#turn-off-auto-updates}

自動更新が有効だと、WordPressが再び最新版を自動でインストールします。

1. **WP Admin → プラグイン**に移動します。
2. WCPOSの行（またはWCPOS Proの行）の**自動更新**列を確認します。**自動更新を無効化**と表示されている場合はクリックしてください。**自動更新を有効化**と表示されていれば、自動更新は無効です。

## 必要なバージョンをダウンロードする {#download}

目的のバージョンを`.zip`ファイルとしてダウンロードし、解凍せずに保存します。WordPressにインストールするのはフォルダーではなく`.zip`です。お使いのプラグインに応じた手順に進んでください。

- **WCPOS：** [WordPress.orgからダウンロード](#download-free)。
- **WCPOS Pro：** [wcpos.comのアカウントからダウンロード](#download-pro)。

### WCPOS：WordPress.orgからダウンロード {#download-free}

1. WordPress.orgで[WCPOSの詳細表示](https://wordpress.org/plugins/woocommerce-pos/advanced/)を開きます。
2. **詳細オプション**までスクロールします。**以前のバージョン**で目的のバージョンを選択します。
3. **ダウンロード**をクリックします。

目的のバージョンの最新リリースを選んでください。2.0から戻す場合は、古い1.xではなく、**1.11**の最新リリースを選びます。WordPress.orgでは以前のバージョンの安全性や安定性について警告が表示されますが、最新リリースにはすべての修正が含まれています。

### WCPOS Pro：wcpos.comのアカウントからダウンロード {#download-pro}

1. [wcpos.com](https://wcpos.com/account/downloads)のアカウントにログインし、**ダウンロード**を開きます。
2. **バージョン履歴**で目的のバージョンを探します。2.0から戻す場合は、1.11の最新リリースを使用してください。
3. その行の**ダウンロード**をクリックします。

ダウンロードできるバージョンはライセンスによって決まります。ライセンスの有効期限が切れていても、期限前に公開されたバージョンはダウンロードできます。それ以降のバージョンはグレー表示になり、**ライセンスの有効期限後にリリースされました。** と表示されます。

## 現在のバージョンに上書きアップロードする {#install}

:::warning 先にプラグインを削除しないでください
現在のプラグインに`.zip`を上書きアップロードすれば、すべて保持されます。**プラグイン**からプラグインを削除すると、WCPOSのクリーンアップ処理が実行されます。すべてのレジ係がログアウトするため各レジで再ログインが必要になり、各レジで再構築される同期データも消去されます。その場合でも、アンインストール時にWCPOSの全データを削除する設定がサイトにされていない限り、注文、設定、レシートテンプレート、レジは保持されます。削除する必要はありません。
:::

1. **WP Admin → プラグイン**に移動し、ページ上部の**新規プラグインを追加**をクリックします。
2. **プラグインのアップロード**をクリックし、ダウンロードした`.zip`ファイルを選択して、**今すぐインストール**をクリックします。
3. WordPressに**このプラグインはすでにインストールされています。** と表示され、二つの列が並びます。
   - **現在**：現在使用しているバージョンです。
   - **アップロード済み**：`.zip`内のバージョンです。**バージョン**の行に目的のバージョンが表示されていることを確認します。

   その下に**現在のプラグインより古いバージョンをアップロードしています。** と表示されます。
4. **アップロードしたもので現在のものを置き換える**をクリックします。
5. WordPressがプラグインを置き換え、**プラグインのダウングレードが完了しました。** と表示します。**プラグインを有効化**が表示された場合はクリックしてください。表示されなければ、プラグインはもともと有効で、そのまま有効になっています。

## 以前のバージョンに戻した後 {#after}

1. **アプリを使っているレジをブラウザーに切り替えます。** アプリが2.0のレジでは、代わりにブラウザーで`yourdomain.com/pos`を開いてください（[始める前に](#before-you-start)を参照）。
2. **すべてのレジでPOSを開き**、最初の同期が完了するまで待ちます。ブラウザーを使うレジでは、次にPOSを開いたときにインストールしたバージョンが読み込まれます。
3. 再び更新する準備ができるまで、**自動更新を無効のままにしておきます**。準備ができたら[2.0へのアップグレード](./upgrading-to-2.mdx)に従い、その後で自動更新を有効に戻してください。有効にしないと、その後の修正が自動で適用されません。

2.0で作成した注文は通常のWooCommerce注文としてそのまま残ります。2.0で記録したレジセッションと締め処理の記録もデータベースに残りますが、1.11では表示されません。

## 問題が発生した場合 {#if-something-goes-wrong}

**新しいバージョンに勝手に戻ってしまった。** 自動更新が有効なままです。[無効にして](#turn-off-auto-updates)から、目的のバージョンを再度アップロードしてください。

**バージョン履歴で必要なバージョンがグレー表示になっている。** ライセンスの有効期限後に公開されたバージョンです。ライセンスを更新するか、有効期限前に公開されたバージョンを選んでください。

**レジに[AUTH331](../error-codes/AUTH331.mdx)が表示される。** そのレジは2.0のアプリで1.11のプラグインに接続しようとしています。その端末のブラウザーでPOSを開いてください。

<details>
<summary>開発者向け：WP-CLIで以前のバージョンに戻す</summary>

[WP-CLI](https://developer.wordpress.org/cli/commands/plugin/install/)があるサーバーでは、次のコマンドでアンインストール処理を実行せずに、無料プラグインをWordPress.orgの指定バージョンに置き換えられます。

```bash
wp plugin install woocommerce-pos --version=<version> --force
```

`--version`でリリースを指定します。`--force`は確認を求めずにインストール済みのプラグインを上書きします。WCPOS Proの場合は、上記の手順でアカウントから`.zip`をダウンロードし、プラグイン名の代わりにそのパスを渡してください：`wp plugin install /path/to/woocommerce-pos-pro.zip --force`。

</details>
