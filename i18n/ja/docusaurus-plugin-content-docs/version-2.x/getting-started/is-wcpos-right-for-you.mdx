WCPOS は WooCommerce 向けの POS アプリです。ウェブブラウザー、または Windows、macOS、Linux のデスクトップアプリで利用でき、iOS と Android のアプリもベータ版として提供されています。オンラインショップと同じ商品カタログ、在庫、価格で販売し、すべての売上を WooCommerce の注文として記録します。

2025 年 11 月まで、このプラグインは wordpress.org に WooCommerce POS という名前で掲載されていました。プラグインのスラッグは今も `woocommerce-pos` で、古いレビューやフォーラムのスレッド、チュートリアルでは旧名称が使われています。

このページでは、インストール前によくある疑問に答えます。[適しているケース](#who-its-for)、[適していないケース](#who-its-not-for)、[必要な環境](#what-you-need)、[費用](#what-it-costs)、[画面の紹介](#what-it-looks-like)、[他の POS との比較](#how-it-compares)、[試す方法](#try-it)をご覧ください。

## WCPOS が適しているケース {#who-its-for}

WCPOS は、すでに WooCommerce で販売しており、同じ在庫を使って対面販売も行いたいビジネスに適しています。

- **オンライン販売も行う店舗、販売カウンター、市場の出店、ポップアップショップ。** ウェブサイトとレジのどちらで販売しても、商品カタログ、在庫数、注文一覧を一元管理できます。
- **売上データを自社のデータベースで管理したいショップ。** WCPOS は WordPress プラグインです。注文、顧客、商品は外部サービスではなく、ご自身の WooCommerce 環境に保存されます。
- **キャッシュドロアーを備えた販売カウンター。** 無料プラグインでは、カウンター上のすべてのデバイスで共有するレジを 1 台利用できます。釣銭準備金、入出金、終業時の現金確認、締めレポートに対応しています。Pro では、ドロアーごとにレジを追加できます。
- **電話注文や業者向けの受注窓口。** 既存の顧客を検索して注文を作成し、現金やカードで支払いを受け付けられます。Pro では、顧客がリンクから支払える[メール請求書](../payment/gateways/email-invoice.mdx)も送信できます。
- **レジや店舗が複数あるビジネス。** 商品カタログのコピーを各デバイスに保存するため、レジは軽快に動作します。Pro ではレジや[店舗](../stores/index.mdx)を追加でき、店舗ごとに住所、ロゴ、税務登録番号、レシートテンプレートを設定できます。店舗別の在庫管理に [ATUM](../extensions/atum.mdx) を追加しない限り、すべての店舗で同じ在庫数を共有します。

## WCPOS が適していないケース {#who-its-not-for}

- **WooCommerce を利用していない。** WCPOS には、WooCommerce がインストールされた WordPress サイトが必要です。Shopify、Magento、単独のショップでは利用できません。
- **認証済みのレジが今すぐ必要。** WCPOS 2.0 は、フランスの NF525 やスペインの VeriFactu を含め、どの国の税務認証も取得していません。国ごとの状況は[税務要件への準拠](../reference/fiscal-compliance.mdx)で説明しています。認証が必要な場合、それを回避する方法はありません。
- **完全にオフラインの状態で販売を開始し、完了する必要がある。** 判断の目安は、チェックアウト画面の商品一覧の上にある注文番号です。**番号がある場合**は、接続が切れる前に販売データがショップに届いています。現金、別途お使いの決済端末で処理したカード決済、その他レジで記録する支払いを受け付けられます。オフラインで開始した販売のように**番号がない場合**は、デバイスに保存しておき、接続が復旧してから支払いを受け付けてください。連携するカードリーダーやオンライン決済ゲートウェイには、常に接続が必要です。[オフラインモード](./offline.mdx#take-payment-offline)をご覧ください。
- **セルフサービス端末や、提供元によるハードウェアとのセット販売が必要。** WCPOS にはキオスクモードがなく、ハードウェアの販売も行っていません。お好きなパソコン、タブレット、スマートフォンで、[対応するプリンター、スキャナー、キャッシュドロアー](../hardware/index.mdx)と組み合わせて利用できます。

## 必要な環境 {#what-you-need}

| 要件 | 最低要件 |
|---|---|
| WordPress | 5.6 |
| WooCommerce | 9.0（WCPOS 2.0 以降で必須） |
| PHP | 7.4（8.x 推奨） |
| デバイス | 現行のウェブブラウザー、または Windows、macOS、Linux 向けデスクトップアプリ。iOS と Android のアプリはベータ版です |

レシートプリンター、バーコードスキャナー、キャッシュドロアーは任意です。[インストール](./installation.mdx#server-requirements)と[ハードウェア](../hardware/index.mdx)をご覧ください。

初回のダウンロードが完了した後は、同期によるサーバー負荷はカタログ全体の大きさではなく、変更された内容に応じて決まります。[同期のパフォーマンス](../reference/sync-performance.mdx#the-four-rules)をご覧ください。

## 費用 {#what-it-costs}

無料プラグインは、現金、別途お使いの決済端末で処理したカード決済、複数の支払い方法を組み合わせた決済に対応し、キャッシュドロアー付きのレジを 1 台利用でき、レシートを印刷できます。WCPOS Pro では、カードリーダーとの連携、払い戻し、在庫と価格の編集、注文履歴、カスタマーディスプレイ、レジと店舗の追加が利用できます。

- **WCPOS（無料プラグイン）：** $0。GPL-3.0 ライセンスのオープンソースで、[WordPress プラグインディレクトリ](https://wordpress.org/plugins/woocommerce-pos/)からインストールできます。販売、レシート印刷、すべての売上の WooCommerce 注文への記録に対応し、WCPOS による取引手数料はかかりません。
- **WCPOS Pro、年間ライセンス：** $129 の 1 回払いです。1 年間のアップデートと優先サポートが含まれます。自動更新はなく、期間が終了しても Pro は引き続き使えます。終了するのは新しいアップデートと優先サポートのみです。
- **WCPOS Pro、永久ライセンス：** $399 の 1 回払いです。アップデートを無期限で利用できます。

各 Pro ライセンスは、本番用と開発用の計 2 サイトで有効化できます。そのサイトのすべてのデバイスとレジ係が Pro を利用できます。価格は [wcpos.com/pro](https://wcpos.com/pro) に掲載されている 2026 年 11 月時点のものです。カード決済の処理手数料は WCPOS ではなく、決済サービス提供元が定めます。

売上を記録するレジだけが必要なら、無料プラグインで十分です。すべての違いを並べた[無料版と Pro の比較](./free-vs-pro.mdx)と、有効化の手順を説明する [WCPOS Pro のインストール](./pro-license.mdx)をご覧ください。

## 画面の紹介 {#what-it-looks-like}

タブレットで表示した POS です。カートに商品が 1 点入っています。左側のメニューから他の画面を開けます。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="カートに商品が 1 点入ったタブレットの POS 画面。左側のメニュー、検索ボックス、商品グリッド、店舗名、レジ係のアバター、顧客、チェックアウトボタンを含むカートが表示されています">

1. **レジバー** — このデバイスで販売を行う店舗が表示されます。レジで対応が必要な場合は、**営業終了**や**オフライン**などの状態も表示されます。[店舗、レジ、デバイス](../stores/registers-and-devices.mdx)をご覧ください。
2. **自分のアバター** — レジ係シートを開きます。ここからレジパネルに進めます。[レジを開く](../pos/register/index.mdx)をご覧ください。
3. **検索** — 商品名や SKU を入力するか、カメラやスキャナーでバーコードを読み取ります。[商品パネル](../pos/product-panel/index.mdx)をご覧ください。
4. **商品** — ウェブサイトと同じ価格と在庫を持つ WooCommerce の商品カタログです。商品をタップすると追加できます。
5. **顧客** — この販売の対象となる顧客を WooCommerce の顧客から選びます。[カート](../pos/cart/index.mdx)をご覧ください。
6. **チェックアウト** — 現金の受け取り、別途お使いの決済端末で処理したカード決済の記録、複数の支払い方法を組み合わせた決済ができます。Pro では、連携するカードリーダーやショップのその他の支払い方法も利用できます。[チェックアウト](../pos/checkout/index.mdx)をご覧ください。
7. メニューの**商品** — その下の**注文**、**顧客**、**クーポン**とともに、POS からショップを管理する画面です。利用には Pro が必要で、無料プラグインではプレビューが表示されます。[無料版と Pro の比較](./free-vs-pro.mdx#management-screens)をご覧ください。
8. **レポート** — 本日の売上とレジ締めを確認できます。過去の日付、他のレジ、他の店舗の情報を見るには Pro が必要です。[レポート](../reports/index.mdx)をご覧ください。
9. **設定** — このデバイスのプリンター、カードリーダー、バーコードスキャナー、カスタマーディスプレイを設定します。[設定](../settings/index.mdx)をご覧ください。

</JourneyShot>

<details>
<summary>レジバーとレジパネルの詳細</summary>

店舗に複数のレジがある場合、レジバーにはこのデバイスが使用しているレジ名も表示されます。

**レジの開閉**をオンにすると、レジ係シートにドロアー内の現金が表示されます。レジパネルでは入出金を記録し、現金を数え、締めレポートを作成してレジを締められます。[レジを開く](../pos/register/index.mdx)をご覧ください。

</details>

スマートフォンでは、商品とカートは画面下部の別々のタブに表示されます。

<JourneyShot manifest={manifest} device="phone" step={1} maxWidth={390} alt="スマートフォンの POS のカートタブ。未完了の注文、顧客、数量付きの商品 1 点、チェックアウトボタンが表示されています">

1. **未完了の注文** — このレジで進行中の販売です。タップするとその販売に切り替わり、他の販売は保留されます。[未完了の注文](../pos/cart/open-orders.mdx)をご覧ください。
2. **顧客** — タップすると別の顧客を選べます。
3. **数量** — タップして数を入力します。[明細行](../pos/cart/line-items.mdx)をご覧ください。
4. **チェックアウト** — 合計が表示されます。押すと支払いを受け付けられます。

</JourneyShot>

## 他の POS との比較 {#how-it-compares}

[wcpos.com/compare](https://wcpos.com/compare) では、WooCommerce 向けの主な POS である [Oliver POS](https://wcpos.com/compare/oliver-pos)、[WooCommerce 公式 POS](https://wcpos.com/compare/woocommerce-pos)、[Square](https://wcpos.com/compare/square)、[Jovvie](https://wcpos.com/compare/jovvie)、[Vitepos](https://wcpos.com/compare/vitepos)、[YITH Point of Sale](https://wcpos.com/compare/yith-pos)、[FooSales](https://wcpos.com/compare/foosales) との比較を掲載しています。いずれも WCPOS の開発元が作成し、各社の公式料金ページと wordpress.org の情報を基に、日付を明記しています。他の製品のほうが適しているケースも説明しています。

## 試してみる {#try-it}

[デモ店舗](https://demo.wcpos.com/pos)は WCPOS Pro で動作しており、`demo` / `demo` でログインすると Pro の画面も確認できます。無料プラグインでは、各 Pro 画面の**デモを表示**ボタンを押すと、デモ店舗の該当画面が開きます。

ご自身のショップで試すには、WP Admin の**プラグイン**から無料プラグインをインストールしてください。手順は[インストール](./installation.mdx#installing-the-plugin)に記載しています。
