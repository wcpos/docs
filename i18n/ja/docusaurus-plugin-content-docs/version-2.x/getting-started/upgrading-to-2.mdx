WCPOS 2.0は、レジ画面と会計機能を刷新し、キャッシュドロワー機能を追加する大型アップデートです。このページは、**更新**を押す方に向けたものです。実行する前に最後までお読みください。

:::warning 先にすべてのレジ端末を同期してください
レジ端末で初めて2.0を開くと、その端末の1.11のデータが消去されます。それまでに店舗に送信されていない売上は失われます。更新する前に、すべてのレジ端末の同期を完了させてください。

店舗をすでに更新し、レジ端末に未送信の売上が残っている場合は、[1.11のレジ端末に未送信の売上が残っている](#unsent-sales)を参照してください。
:::

## 今すぐアップグレードできますか？ {#can-you-upgrade-today}

**WP Admin → プラグイン**を開き、次の二点を確認してください。

- **WooCommerceが9.0以降であること。** 2.0にはこのバージョンが必要です。9.0より古い場合は、[店舗の準備がまだ整っていない場合](#if-your-store-isnt-ready-yet)を参照し、WCPOSを先に更新しないでください。
- **カード決済端末の拡張機能を使っている場合は、WCPOS Proを導入していること。** 2.0からは、Stripe Terminal、SumUp、Mollie Terminalなどの決済端末拡張機能にProが必要です。これらを利用していてProを導入していない場合は、ここで作業を止め、更新前に[無料版とProの比較](./free-vs-pro.mdx)をお読みください。

WooCommerceが9.0以降で、カード決済端末の拡張機能を使っていないか、WCPOS Proを導入している場合は、[更新を押す前に](#before-you-click-update)に進んでください。

## 更新を押す前に {#before-you-click-update}

1. **すべてのレジ端末を同期します。** 各レジ端末を開き、メニューから**店舗の状態 → データベース**を開きます。**送信待ちの変更**が **0** で、[判断を求めるパネル](../support/store-health.mdx#needs-attention)が表示されていないことを確認してください。0より大きい場合は、まだ店舗に届いていない変更があります。レジ端末をオンラインにしたまま待ってください。この件数には未完了の注文は含まれません。各注文を完了するか、その注文で**サーバーに保存**（2.0では[注文を同期](../pos/cart/open-orders.mdx#sync-order)）を押してください。どちらも現在サインインしている人の分だけが表示されるため、レジ端末を使う各レジ係について、その人が利用するすべての店舗とレジで繰り返してください。レジ端末から店舗に未送信の売上、未完了の注文、変更は、2.0を開くと失われます。
2. **サイトをバックアップする**か、ホスティング事業者に復元ポイントの作成を依頼してください。更新で注文が変更されることはありませんが、大型アップデートに備えて元に戻せるようにしておきましょう。
3. **来店の少ない時間帯を選びます。** プラグインを更新すると、各レジ端末も2.0に移行するまで、その端末の売上が店舗に届かなくなります。また、旧バージョンで会計の途中だった売上は、入力し直す必要があります。
4. **WCPOS Proを使っている場合は、ライセンスが有効であることを確認してください**。確認場所は **WP Admin → POS → 設定 → ライセンス**です。有効なライセンスがなければProの更新は届きません。[WCPOS Proのインストール](./pro-license.mdx)を参照してください。
5. **割引の変更点をレジ係に伝えてください。** *マイナスの手数料*を追加して値引きしている場合、その方法は使えなくなります。2.0では代わりに**割引を追加**を使います。[初日から変わる点](#what-changes-on-day-one)を参照してください。
6. **カード決済端末の拡張機能を使っている場合は、2.0対応版があることを確認してください。** Stripe Terminal、SumUp、Mollie Terminalには、それぞれ対応版があります。以下の手順で、WCPOSの直後に更新します。

## プラグインとレジ端末を更新する {#updating}

1. **プラグインを更新します。** 無料版のサイトでは **WCPOS** を更新します。Proの場合は **WCPOS Pro** だけを更新してください。Proには無料プラグインが含まれており、別途インストールされている無料版は無効化されます。その旨の通知が表示されたら、無料プラグインは削除できます。
2. カード決済端末の拡張機能を使っている場合は、**拡張機能を更新し**、2.0対応版にしてください。未更新の拡張機能も会計の**レガシー**タブには表示されますが、支払いパネルからリーダーを操作することはできません。
3. **すべてのレジ端末を2.0に移行します。** ブラウザーのレジ端末ではページを再読み込みすると、店舗から2.0が読み込まれます。デスクトップアプリとモバイルアプリは、通常の更新方法で2.0に更新してから開きます。各レジ端末の初回同期が完了するまで待ってください。
4. **各レジ端末が2.0になっていることを確認します。** メニュー下部のバージョン（**v 2.0.0**、スマートフォンでは**バージョン 2.0.0**）をタップすると、**WCPOSについて**が開きます。

4. **ステータス** — **Pro** または**無料**です。Proなのにここが**無料**と表示される場合は、[WCPOS Proのインストール](./pro-license.mdx)を参照してください。

アプリとプラグインは、両方とも2.0である必要があります。バージョンが合わないレジ端末は、その旨を知らせる画面で停止します。

- **2.0の店舗に接続する1.11のアプリ**には、アプリの更新を求める画面が表示されます。[SYNC341](../error-codes/SYNC341.mdx)を参照してください。未送信の売上が残っている場合は、まだ更新せず、[1.11のレジ端末に未送信の売上が残っている](#unsent-sales)を参照してください。{/* pending: docs#675 */}
- **まだ1.11の店舗に接続する2.0のアプリ**には、**AUTH331** が表示されます。プラグインを更新してから再接続してください。[AUTH331](../error-codes/AUTH331.mdx)を参照してください。

## 初日から変わる点 {#what-changes-on-day-one}

レジ係が更新後に初めてPOSを開くと、新しいレジ画面が表示されます。基本的な操作はこれまでと同じですが、次の点が変わります。すべての変更点は[2.0の新機能](./whats-new.mdx)をご覧ください。

### マイナスの手数料に代わる割引機能 {#discounts}

手数料にマイナスの値は指定できなくなりました。値引きするには、カートの **+** を押して**割引を追加**を選択します。すでにマイナスの手数料が付いている注文は変更されません。

<summary>割引を追加とクーポンの場所を確認する</summary>

1. **レジバー** — このレジ端末が接続している店舗と、その店舗に複数のレジがある場合はレジが表示されます。[店舗、レジ、端末](../stores/registers-and-devices.mdx)を参照してください。
2. **+** — 商品タイル以外のものを追加するための、カートの追加メニューです。

4. **割引を追加** — 注文から金額または割合で値引きできます。また、**クーポン**タブではWooCommerceのクーポンコードを適用できます。レジでのクーポン利用にProは不要になりました。[カートの割引](../pos/cart/discounts.mdx)を参照してください。

### 会計は支払いパネルで行います {#checkout}

**チェックアウト**を押すと、WooCommerceの支払いページではなく、カートの横にテンキーが開きます。お客様からの預かり金額を入力すると、お釣りが表示されます。一件の売上を現金とカードに分けて支払うこともできます。

<details>
<summary>支払い方法、分割、レガシーの場所を確認する</summary>

1. **支払い** — 店舗のレジで使える支払い方法と、このレジ端末にペアリングされたカードリーダーです。[支払いパネル](../pos/checkout/payment-methods.mdx)を参照してください。
2. **レガシー** — まだ独自の支払いページを使う決済ゲートウェイです。未更新の決済端末拡張機能も含まれます。[レガシータブ](../pos/checkout/legacy-tab.mdx)を参照してください。

6. **受領** — 支払いを記録します。[会計](../pos/checkout/index.mdx)を参照してください。

</details>

### 初日から変わるその他の点 {#also-new}

- **新しい外観。** フォームや選択画面がパネルとしてスライド表示されます。**設定 → テーマ**の**表示サイズ**で、端末に合わせてPOSの大きさを調整できます。カートを左側に配置したり、独自のクイックフィルターボタンを追加したりすることもできます。[新機能：新しいレジ画面](./whats-new.mdx#a-new-register)を参照してください。
- **WooCommerce Analyticsでは、支払いが完了したPOS注文を売上として集計します。** レジでまだ未完了の注文や一部のみ支払い済みの注文は売上に含まれなくなるため、それらを含んでいた合計額は少なくなります。
- **レシートにレジ名とソフトウェアのバージョンが記載されます。** 払い戻しでは、**払い戻し**という見出しの専用レシートが印刷され、訂正対象の売上が明記されます。カスタムレシートテンプレートは引き続き使えます。新しい情報は、テンプレートに追加した場合にのみ表示されます。[レシート](../receipts/index.mdx)を参照してください。
- プラグインの更新時に一度だけ、**POS専用商品のカタログ表示が「非表示」に設定されます**。これにより、オンラインショップに表示されなくなります。
- **磁気ストライプ式カードリーダーはサポートされなくなりました。** ペアリングしたリーダー（Pro）またはお手持ちの決済端末でカード決済を行い、レジで支払いを記録してください。

### レジとキャッシュドロワー {#registers-and-cash-drawer}

<details>
<summary>レジとキャッシュドロワー：有効にするまでオフのままです</summary>

2.0では、無料プラグインでも、釣銭準備金の登録と現金の実査によるレジ開け・レジ締めができます。導入初日には何も変わりません。管理者が **WP Admin → POS → 設定 → 一般**の**レジ**にある**レジの開閉**を有効にするまで、この機能はオフのままです。同じ場所で**釣銭準備金**も設定します。有効にすると、最初の販売前にPOSから釣銭準備金の入力を求められます。**レジを締める**ではドロワー内の現金を数え、番号付きの締め記録を作成します。その後の画面で**締め記録を印刷**を押すと印刷できます。[営業終了時の照合](../pos/reconciliation.mdx)を参照してください。

無料プラグインでは、一つのレジをすべての端末で共有します。Proではレジを追加できます。[レジ](../settings/wp-admin/registers.mdx#one-register)と[レジを開ける](../pos/register/index.mdx)を参照してください。

</details>

## 店舗の準備がまだ整っていない場合 {#if-your-store-isnt-ready-yet}

**WCPOS 1.11をそのままお使いください。** 引き続き動作し、2.0のリリース後六か月間は修正も提供されます。

1. WCPOSとWCPOS Proの**自動更新を無効にします**。**WP Admin → プラグイン**では、各プラグインの行に**自動更新を有効化** / **自動更新を無効化**のリンクがあります。**自動更新を有効化**と表示されていれば、自動更新はオフです。これにより、勤務中のレジ端末に自動更新が届くのを防ぎます。
2. 準備が整ったら、**WooCommerceを9.0以降に更新します**。この更新については、WooCommerceのリリースノートを参照してください。
3. **[更新を押す前に](#before-you-click-update)に戻ってください。**
4. 自動更新を利用していた場合は、**2.0への移行後に自動更新を再び有効にしてください**。無効のままでは、今後の修正が自動で届きません。

### WooCommerceより先にWCPOSが更新された場合 {#if-wcpos-updated-first}

{/* pending: docs#675 */}
WooCommerceが9.0以降になるまでPOSは開きません。店舗にすでに保存されている注文は保持されます。未送信の売上がレジ端末に残るのは、2.0を開くまでです。そのレジ端末を更新したり再読み込みしたりせず、[1.11のレジ端末に未送信の売上が残っている](#unsent-sales)の手順に従ってください。今すぐWooCommerceを更新するか、[WCPOS 1.11を再インストール](./previous-versions.mdx)して、上記のとおり自動更新を無効にしてください。

## プラグイン更新後にPOSが消えた場合 {#pos-gone}

WP Adminから **POS** メニューが消え、`yourdomain.com/pos` でもPOSが開かなくなった場合です。WCPOS 2.0は、サイトが[動作要件](./installation.mdx#server-requirements)を満たしている場合にのみ動作します。要件を満たさない場合、プラグインはインストールされたままですが、機能は一切有効になりません。注文はWooCommerceに残ります。

1. **WooCommerceを確認してください。** **WP Admin → プラグイン**で、WooCommerceが有効になっており、9.0以降である必要があります。更新または有効化してください。まだ更新できない場合は、[WooCommerceより先にWCPOSが更新された場合](#if-wcpos-updated-first)を参照してください。
2. **PHPを確認してください。** 2.0にはPHP 7.4以降が必要です。サイトで使用しているバージョンをホスティング事業者に確認してください。
3. **Proの場合は、WCPOS Proが有効であることを確認してください。** 無料の **WCPOS** プラグインは意図的に無効化されています。Proに含まれているためです。[プラグインとレジ端末を更新する](#updating)を参照してください。
4. WP Admin上部に **「WCPOSプラグインを正しく読み込めませんでした。」と表示されていないか確認してください。** プラグイン自体のファイルが読み込まれなかったため、そこで停止しています。[現在のバージョンに上書きアップロードする](./previous-versions.mdx#install)に従い、同じバージョンを再度ダウンロードして、既存のものに上書きアップロードしてください。先にプラグインを削除しないでください。

レジ端末に更新前の売上が残っている場合は、再読み込みする前に[1.11のレジ端末に未送信の売上が残っている](#unsent-sales)をお読みください。

## 以前のバージョンに戻す {#rolling-back}

### 1.11のレジ端末に未送信の売上が残っている {#unsent-sales}

レジ端末に更新画面が表示され、売上が店舗に届いていない場合です。2.0を開くまでは、売上はその端末に残っています。送信するには、次の手順に従ってください。

1. **そのレジ端末はそのままにしてください。** アプリを更新せず、ブラウザーのレジ端末ではページを再読み込みしないでください。どちらも2.0を開くことになり、未送信の売上が消去されます。
2. 店舗に **[1.11のプラグインを再インストール](./previous-versions.mdx)** してください。
3. **ブラウザーのレジ端末ではページを再読み込みし、アプリでは一度閉じて開き直してください。** 店舗が1.11に戻ったので、レジ端末が再接続して売上を送信します。**店舗の状態 → データベース**の**送信待ちの変更**が **0** になり、[判断を求めるパネル](../support/store-health.mdx#needs-attention)が表示されなくなるまで待ってください。未完了の注文はこの件数に含まれません。各注文を完了するか、その注文で**サーバーに保存**を押してください。これで売上が店舗に保存されます。
4. [プラグインとレジ端末を更新する](#updating)の手順に従って、**再び2.0に更新します**。

### 1.11に戻す {#back-to-1-11}

2.0で問題が発生している場合は、まず[Discord](https://wcpos.com/discord)でお知らせください。アップグレード当日の問題の多くは、以前のバージョンに戻すよりも早く解決できます。

:::warning 以前のバージョンに戻す前に同期してください
1.11に戻すと、各レジ端末は空のローカルデータベースから開始します。また、2.0のレジ端末がまだ店舗に送信していない売上を、1.11から送信することはできません。先にすべての2.0のレジ端末の同期を完了させてください。**店舗の状態 → データベース**で**送信待ちの変更**が **0** になっており、[判断を求めるパネル](../support/store-health.mdx#needs-attention)が表示されず、未完了の注文にも未同期のものが残っていないことを確認します（[注文を同期](../pos/cart/open-orders.mdx#sync-order)）。
:::

**すでに2.0になっているデスクトップアプリやモバイルアプリは、1.11のプラグインに接続できません**（[AUTH331](../error-codes/AUTH331.mdx)が表示されます）。また、アプリストアでは旧バージョンを入手できません。再びアップグレードするまでは、そのレジ端末で `yourdomain.com/pos` のブラウザー版POSを使ってください。

以前のバージョンに戻すには、[1.11のプラグインを再インストール](./previous-versions.mdx)してください。ブラウザーのレジ端末と、まだ1.11のアプリは、これまでどおり使えます。

2.0で作成した注文は通常のWooCommerce注文で、そのまま残ります。2.0で記録したレジセッションと締め記録もデータベースに残りますが、1.11では表示されません。
