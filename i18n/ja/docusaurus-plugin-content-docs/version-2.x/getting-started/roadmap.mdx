### 2.1：税務法令への対応 {#fiscal-compliance}

売上が改変されていないことをレジで証明するよう法律で義務付けられている国の店舗が、このテーマの対象です。このリリースには、他にも四つの変更が含まれます。

- <Anchor id="records-the-law-requires" />**法律で求められる記録**：売上が変更されたかどうかを示す記録をPOSが保存します。まずフランスとスペインに対応します。

  <details>
  <summary>税務法令への対応に含まれる内容</summary>

  署名付きの記録、欠番のない連番、正式な締めレポート、エクスポート可能な監査ファイルに加え、国によって義務付けられている場合はPOSから税務当局への報告も含まれます。フランスの規則はNF525、スペインの規則はVeriFactuです。2.0でその基盤を整えました。[税務ルールに対応したレシートと払い戻し](./whats-new.mdx#receipts-and-refunds)を参照してください。

  </details>

- <Anchor id="report-templates" />**レポートテンプレート**：日次締めレポート（Zレポート）やシフト集計のレイアウトを選び、A4用紙や感熱紙に印刷できます。
- <Anchor id="scale-barcodes" />**はかりのバーコード**：はかりが印刷したバーコードをスキャンすると、バーコードに含まれる価格または重量でPOSに商品が追加されます。
- <Anchor id="exchanges" />**交換**：返品の受け付けと交換品の販売を一回の取引で行います。
- <Anchor id="card-payments-offline" />**オフラインカード決済**：2.1でSumUpのSoloとSolo Liteへの対応を予定しています。SumUp側でお客様のアカウントにこの機能を有効にする必要もあります。それまでは、レジとペアリングしたカードリーダーには接続が必要です。現在、接続なしで使える機能については、次のページをご覧ください： [オフラインモード](./offline.mdx)。

  <details>
  <summary>対応リーダーとオフラインカード決済の仕組み</summary>

  SoloとSolo LiteはBluetoothでPOSアプリに接続します。POSがオフラインの間、リーダーは決済を仮承認し、接続が復旧すると送信します。その時点でSumUpが決済を拒否する可能性があり、そのリスクは店舗が負います。

  </details>


### 2.2：レジ係ごとの操作権限の管理 {#cashier-permissions}

現在も、レジの開始、現金の実査、締め、承認を行える担当者や、**レポート**画面を開いて予定現金残高を確認できる担当者を、権限グループごとに設定できます。[POSへのアクセス](../settings/wp-admin/access.mdx)を参照してください。それ以外のレジ操作の大半は、すべてのレジ係が利用できます。2.2では、それらの操作も制御できるようになります。

- <Anchor id="permissions-by-role" />**権限グループごとの権限**：払い戻しや割引、明細の価格変更、注文の取消や再開、他のレジ係の売上の閲覧を、どの権限グループに許可するか決められます。

  <details>
  <summary>非表示にできるページと初期設定での動作</summary>

  権限グループに対して**注文**、**顧客**、POS設定の各ページを非表示にすることもできます。レジ係に許可されていない操作は、非表示になるかロックされます。すべての権限は初期状態で有効なため、いずれかを無効にするまで店舗の動作は変わりません。

  </details>

- <Anchor id="shared-till-settings" />**店舗全体のレジ設定**：会計後にレシートを開くかどうかなど、すべてのレジ係に適用するレジ設定を一度に行い、レジ係が変更してよい設定も決められます。

### 2.3：他のプラグインとの連携 {#your-other-plugins}

オンラインショップで使用しているWooCommerceプラグインを、店頭でも使えるようにします。

- <Anchor id="loyalty-gift-cards-subscriptions" />**ポイント、ギフトカード、定期購入**：レジでポイントの付与と利用、ギフトカードやストアクレジットの販売と利用、定期購入の申し込みを行えます。
- <Anchor id="pricing-rules-email-lists" />**価格ルールとメーリングリスト**：まとめ買い価格や割引ルールがオンラインと同じようにレジにも適用され、店頭で受け取ったメールアドレスを同じメーリングリストに追加できます。
- <Anchor id="more-extensions" />**さらに多くのWooCommerce拡張機能**：Product Add-Ons、Product Bundles、Composite Products、Bookings、Product Options、Product Vendors。
- <Anchor id="order-notifications" />**注文通知**：新しいオンライン注文が入ると、レジで音付きの通知が表示され、誰かが確認するまで残ります。注文への即時対応が必要な飲食店向けの機能です。

### 未定の項目 {#later}

リリースがまだ決まっていないアイデアもボードに載っています。例えば、オンライン注文のメールとは別のPOS注文用メールテンプレートなどです。店舗にとって重要なものがあれば、[リクエストしてください](#request-or-vote)。

## WCPOSに搭載済みの機能 {#already-shipped}

### 2.0に含まれる機能 {#shipped-in-2-0}

2.0ではレジと会計処理を再構築しました。現金とカードを組み合わせた支払い、店舗にすでに登録された売上に対するオフラインでの支払いの記録（現金、独立した決済端末でのカード決済、その他の支払い）、釣銭準備金を設定したレジの開始と現金実査による締め、レジからカードリーダーへの金額送信、二台目の画面でのお客様へのカート表示ができます。カードリーダーと二台目の画面はProの機能です。全機能は[2.0の新機能](./whats-new.mdx)をご覧ください。

## 機能をリクエストする {#request-or-vote}

多くの店舗から要望がある機能は、ロードマップで優先されます。次のいずれかでリクエストしてください。

- **[Discord](https://wcpos.com/discord)**：私たちや他の店舗オーナーに最も早く連絡できる方法です。機能のリクエストは`#forum`、簡単な質問は`#general`に投稿してください。
- **[GitHub Discussions](https://github.com/orgs/wcpos/discussions)**：機能を提案したり、すでにある提案にご自身の利用例を追加したりできます。ロードマップの多くの項目は、ここでの話し合いから生まれました。

:::tip 実現したいことを教えてください
機能名だけでなく、実際の業務について教えてください。今、店頭で何が起きていて、それをどう変えたいのかをお知らせください。具体的な事例は、投票以上に設計の参考になります。
:::
