WCPOS には 2 つのエディションがあります。**無料プラグイン** は販売処理に対応しています。現金、別のカード端末で受け取ったカード決済、キャッシュドロアーを備えた 1 台のレジ、レシート、カートでのクーポン適用を利用でき、接続が切れても販売を続けられます。**WCPOS Pro** では、POS から店舗を運営するための画面（商品、注文、顧客、クーポン、今日以外のレポート）、払い戻し、連携したカードリーダーやその他の決済ゲートウェイ、カスタマーディスプレイ、複数のレジと店舗が追加されます。

売上を記録するレジが必要であれば、無料プラグインで十分です。在庫や価格の変更、過去の注文の検索、顧客への払い戻し、ペアリングしたリーダーでのカード決済も行いたい場合は Pro が必要です。料金とライセンスの有効期限が切れた場合の扱いは、[料金](#pricing)を参照してください。

### レポート {#reports}

無料プラグインの[レポート](../reports/index.mdx)には、このデバイスで使用しているレジの今日の売上が表示されます。過去の日付、他のレジ、他の店舗には Pro が必要です。ロックされた項目を押すと理由が表示されます。

1. **今日** — 無料プラグインで確認できる、そのレジの今日の売上です。

3. **カレンダー** — 今日だけを選択できます。
4. **過去の日付は WCPOS Pro で利用できます** — 案内メッセージです。同様に、レジのメニューには **他のレジは WCPOS Pro で利用できます**、店舗のメニューには **他の店舗は WCPOS Pro で利用できます** と表示されます。レジ締めでは **過去のレジ締めは WCPOS Pro で利用できます** と表示されます。
5. **Pro を見る** — wcpos.com の WCPOS Pro ページを開きます。

</JourneyShot>

[WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) の無料プラグインは、最初の商品追加からレシート発行までの販売処理に対応します。現金とカード、1 台のレジ、カート内のクーポン、レシートと印刷、オフライン販売、バーコードスキャン、顧客の税 ID を、すべてのプラットフォームで利用できます。

## Pro で追加される機能 {#what-pro-adds}

Pro では POS の残りの機能が利用できるようになります。管理画面、追加の支払い方法、複数のレジと店舗などです。

### 管理画面 {#management-screens}

| 画面 | Pro でできること |
|---|---|
| **[商品](../products/index.mdx)** | 商品一覧で在庫や価格を直接変更できます。 |
| **[注文](../orders/index.mdx)** | 過去の注文を検索し、再度開いて編集したり、レシートを再印刷したり、払い戻したりできます。 |
| **[顧客](../customers/index.mdx)** | 顧客を追加し、詳細情報を編集できます。 |
| **[レポート](../reports/index.mdx)** | 過去の日付、すべてのレジと店舗、レジ締め履歴を確認できます。 |
| **[クーポン](../coupons/index.mdx)** | クーポンを確認でき、権限があれば新しく作成できます。 |

### 決済ゲートウェイ {#payment-gateways}

## 料金 {#pricing}

Pro は [wcpos.com/pro](https://wcpos.com/pro) で購入できます。各ライセンスは、本番用と開発用の 2 つのサイトで利用できます。

- **年間** — $129。1 年間の更新と優先サポートが含まれます。自動更新はされません。
- **無期限** — $399 の買い切りです。無期限に更新を受けられます。

2026 年 11 月時点の料金です。

年間ライセンスの有効期限が切れても、機能が停止することはありません。お使いの Pro バージョンは、すべての機能を引き続き利用できます。ライセンスを更新するまで、新しいアップデートと優先サポートの提供が停止します。

:::tip まずはお試しください
各 Pro 画面の **デモを見る** ボタンを押すと、[demo.wcpos.com/pos](https://demo.wcpos.com/pos) にある WCPOS デモ店舗で同じ画面が開きます。
:::

## アップグレードするには {#ready-to-upgrade}

ダウンロードと有効化の手順は、[WCPOS Pro のインストール](./pro-license.mdx)を参照してください。

- **Pro 1.8 以降** は、無料プラグインの全機能を含む単独で動作するプラグインです。無料プラグインを残したままインストールしてください。事前に削除する必要はありません（[無料プラグインに Pro を上書きインストールする](./installation.mdx#pro-over-free)を参照）。その後、無料プラグインを無効化して削除できます。
- **1.8 より前の Pro** は、無料プラグインと併用するアドオンでした。そこから移行する場合も、同じ手順に従ってください。
