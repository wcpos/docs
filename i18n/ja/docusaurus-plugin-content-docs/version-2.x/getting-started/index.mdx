## WCPOSとは？ {#what-is-wcpos}

WCPOSはWooCommerce向けの販売時点情報管理（POS）システムです。オンラインショップと同じ商品、在庫、価格で販売でき、すべての販売がWooCommerceの注文として記録されます。ウェブブラウザーのほか、Windows、macOS、Linux向けのアプリで動作します。iOSとAndroid向けのアプリはベータ版です。

## 画面の見方 {#find-your-way-around}

これは「watch」で検索し、**在庫あり**フィルターを有効にして、時計をカートに入れたPOS画面です。このドキュメントの説明はすべてここから始まります。[POS画面の概要](../pos/index.mdx)では、各部分を順に紹介しています。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[36, -12], [124, 0], [-30, 0], [10, 28], [72, 0], [0, -72], [-42, 0], [40, 28], [0, 0]]} alt="時計がカートに入ったPOS画面。左側にメニュー、検索ボックス、商品、商品数があり、右側に店舗、通知、アバター、顧客、チェックアウトボタンがあります">

1. **メニュー** — **POS**で販売を行います。**商品**、**注文**、**クーポン**、**顧客**には[WCPOS Pro](./free-vs-pro.mdx#management-screens)が必要です。**レポート**には当日の売上とレジ締めが表示されます。下部には**健全性**、**設定**、**サポート**があります。
2. **レジバー** — この端末が接続している店舗と、店舗に複数のレジがある場合はレジ名が表示されます。[店舗・レジ・端末](../stores/registers-and-devices.mdx)をご覧ください。
3. **通知** — WCPOSからのお知らせ、更新通知、ライセンスのリマインダーです。[通知](../support/notifications.mdx)をご覧ください。
4. **アバター** — レジ係パネルを開きます。キャッシュドロワーの操作、別の担当者へのレジの引き継ぎ、サインアウトができます。[レジを開く](../pos/register/index.mdx#cashier-sheet)をご覧ください。
5. **検索** — 名前やSKUを入力するか、バーコードをスキャンします。[検索と絞り込み](../pos/product-panel/search-filtering.mdx)をご覧ください。
6. **商品** — タップするとカートに追加されます。[商品パネル](../pos/product-panel/index.mdx)をご覧ください。
7. **商品数** — 条件に一致する商品の数です。横の矢印を押すと、店舗から最新の情報を取得します。
8. **顧客** — 販売先の顧客です。タップすると別の顧客を選べます。[カート](../pos/cart/index.mdx)をご覧ください。
9. **チェックアウト** — 合計金額が表示されます。押すと支払いを受け付けます。[チェックアウト](../pos/checkout/index.mdx)をご覧ください。

</JourneyShot>

スマートフォンでは、左上のボタンからメニューを開きます。カートは下部の**カート**タブにあります。

## 5分で始める {#get-started-in-5-minutes}

レジ係の方：店舗ですでにWCPOSを使っている場合は、[手順2から始めてください](#open-the-pos)。手順1は店舗オーナー向けです。

<Steps>

<StepCard number={1} title="プラグインをインストールする（店舗オーナー）">

WordPressサイトに無料の[WCPOSプラグイン](https://wordpress.org/plugins/woocommerce-pos/)をインストールします。

1. WP Adminで**プラグイン**を開き、新しいプラグインを追加します。
2. 「WCPOS」を検索します。
3. **今すぐインストール**を押し、続いて**有効化**を押します。

サーバーと端末の要件は、[インストール](./installation.mdx)をご覧ください。

</StepCard>

<StepCard number={2} title="POSを開く">

<Anchor id="open-the-pos" />

**ブラウザーの場合：** `yourdomain.com/pos`にアクセスし、WordPressのユーザー名とパスワードでサインインします。

**アプリの場合**（[ダウンロード](#where-it-runs)）：店舗のアドレスを入力して**接続**を押し、**WordPressでサインイン**、**POSを開く**の順に押します。

一台の端末で複数の店舗やレジ係を使う方法は、[接続](./connect.mdx)をご覧ください。

</StepCard>

<StepCard number={3} title="POSの起動を待つ">

POSを開くたびに、バーの上にWCPOSロゴが表示されます。バーがいっぱいになるとPOSが開くので、そのままお待ちください。アプリでまだ誰もサインインしていない場合は、代わりに**接続**画面が開きます。開かない場合は、[POSが起動しない場合](#wont-start)をご覧ください。

<details>
<summary>バーが示す処理</summary>

POSがこの端末に保存されているデータを開き、店舗への接続方法を確認し（ブラウザーの場合）、最後に使用した店舗を開くにつれて、バーが進みます。アプリでは前回と同じレジ係として、ブラウザーではWordPressにサインインしているユーザーとして開きます。

このバーはPOSの起動状況を示すもので、商品のダウンロード状況ではありません。商品のダウンロードはその後、販売中に進みます。

</details>

</StepCard>

<StepCard number={4} title="商品をダウンロードしながら販売する">

商品カタログ全体のダウンロードを待つ必要はありません。販売中も商品はダウンロードされ続けます。この端末にまだない商品を検索すると、店舗に問い合わせます。

<details>
<summary>最初は商品数が少ない理由</summary>

店舗のサーバーに負荷がかかりすぎないよう、POSはバックグラウンドで商品カタログを少しずつダウンロードします。

**すべての商品**を表示しているとき、商品の下の **…件中…件を表示**は、この端末にある商品の数を示します。そのため、新しい端末では少ない数から始まり、徐々に増えていきます。[商品の同期](../products/sync.mdx)をご覧ください。

</details>

</StepCard>

<StepCard number={5} title="最初の販売を行う" isLast>

POSに**レジを開くまでは価格確認のみ可能です**と表示される場合は、先に[レジを開いてください](../pos/register/index.mdx)。**検索**、商品、**チェックアウト**の位置は、上の[画面の見方](#find-your-way-around)に示しています。現金で販売する場合は、次の手順に進みます。

1. **検索**に入力するか商品をスキャンし、商品をタップしてカートに追加します。
2. スマートフォンでは**カート**タブを開きます。**チェックアウト**を押すと、支払額が入力されます。
3. **現金**を選び、顧客から受け取った金額を入力するか、金額のクイックボタンをタップします。入力すると、お釣りが表示されます。
4. **受け取る**を押します。支払い完了画面に、返すお釣りとレシートが表示されます。
5. レシートを印刷またはメールで送信し、**新規販売**を押して次の顧客を迎えます。

この例では、$45.00の販売に対して顧客から$50.00を受け取っています。

<JourneyShot manifest={checkoutManifest} device="tablet" step={8} offsets={[[-40, 0], [-70, 0], [-75, 0], [-90, 0], [-4, 0], [0, 0]]} alt="$45.00の現金販売で$50.00を預かった支払い画面。閉じるボタン、支払額$45.00、大きく表示されたお釣り$5.00、その下の預かり金額$50.00、選択された現金、受け取るボタンがあります">

1. **✕** — 注文を残したままカートに戻ります。
2. **支払額** — まだ支払いが必要な残額です。
3. **お釣り** — 顧客に返す金額です。
4. **預かり金額** — 入力またはタップした金額です。
5. **現金** — この支払いに使う方法です。
6. **受け取る** — 金額と支払い方法が表示されます。押すと支払いを記録します。

</JourneyShot>

<details>
<summary>支払い完了画面を見る（別の販売の例）：お釣り、レシートを印刷、新規販売</summary>

<JourneyShot manifest={checkoutManifest} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="現金販売後の支払い完了画面。返すお釣り、支払済み金額と預かり金額、標準レシートが選択されたテンプレート選択欄、プリンター選択欄、レシートのプレビュー、レシートをメール送信、PDFをダウンロード、レシートを印刷、新規販売の各ボタンがあります">

1. **お釣り** — 顧客に返す金額です。
2. **支払済み … · 現金預かり …** — 販売額と顧客から受け取った金額です。
3. **テンプレート** — この販売で使うレシートです。[レシートのカスタマイズ](../receipts/customise.mdx)をご覧ください。
4. **プリンター** — 印刷先です。[レシートの印刷](../receipts/at-checkout.mdx#print-receipt)をご覧ください。
5. **プレビュー** — 印刷されるレシートの見た目です。
6. **レシートを印刷** — レシートを印刷します。
7. **レシートをメール送信** — 顧客にレシートを送信します。[レシートのメール送信](../receipts/at-checkout.mdx#email-receipt)をご覧ください。
8. **新規販売** — 次の顧客用にカートを空にし、顧客をデフォルトの顧客に戻します。

</JourneyShot>

</details>

販売の一連の流れは[チェックアウト](../pos/checkout/index.mdx)、カードなどの支払い方法は[支払い方法](../payment/index.mdx)をご覧ください。

</StepCard>

</Steps>

## POSが起動しない場合 {#wont-start}

**バーが途中で止まる。** ブラウザーでは、POSが店舗への接続方法を確認しています。接続が遅いと時間がかかることがありますが、そのまま待つと処理が進みます。

**「問題が発生しました」。** この端末でPOSを起動できませんでした。メッセージの下に、失敗した処理が表示されます。**再試行**を押してください。端末内のデータはすべて保持されます。同じメッセージが再び表示されたら、内容を控えて[サポートにお問い合わせください](../support/index.mdx)。

:::warning

サポートから指示がない限り、その画面で**アプリのデータをリセットして再起動**を押さないでください。店舗にまだ送信されていない販売を含め、この端末のすべてのデータが削除されます。削除前に確認を求められ、店舗に届いていない変更がある場合は警告が表示されます。

:::

**「POSは別のタブで開かれています」。** POSを実行できるのは一つのタブだけです。**このタブで引き継ぐ**を押すか、もう一方のタブに戻ってください。

**アプリを開くと接続画面が表示される。** この端末でまだ誰もサインインしていないか、サインアウトした状態です。サインインを完了できない場合は、[接続](./connect.mdx#troubleshooting)をご覧ください。

## 主な機能 {#key-features}

無料プラグインでは、現金やお手持ちの決済端末を使ったカードでの販売、キャッシュドロワー付きのレジ一台、レシート、カート内のクーポン、バーコードスキャンを利用でき、接続が切れても販売を続けられます。詳しい比較は[無料版とProの比較](./free-vs-pro.mdx)をご覧ください。

<details>
<summary>無料プラグインでできること</summary>

<FeatureGrid>
  <FeatureCard icon="search" title="高速なローカル検索">
    商品は端末に保存されるため、検索結果がすぐに表示されます
  </FeatureCard>
  <FeatureCard icon="wifi" title="オフラインでも販売を継続">
    商品や顧客を検索し、接続が切れる前に店舗に送信済みの販売について現金を受け付けられます。[オフラインモード](./offline.mdx)をご覧ください
  </FeatureCard>
  <FeatureCard icon="barcode" title="バーコードスキャン">
    USBやBluetoothのスキャナー、または端末のカメラを利用できます
  </FeatureCard>
  <FeatureCard icon="credit-card" title="現金とカードでの支払い">
    お釣りを自動計算する現金払い、お手持ちの決済端末でのカード払い、複数の支払い方法の併用に対応しています
  </FeatureCard>
  <FeatureCard icon="print" title="レシート印刷">
    店舗のテンプレートを使ってレシートを印刷またはメールで送信できます
  </FeatureCard>
  <FeatureCard icon="calculator" title="税金の自動計算">
    WooCommerceの税設定に基づいて税金を計算します
  </FeatureCard>

</details>

## Proの機能 {#pro-features}

[WCPOS Pro](https://wcpos.com/pro)では、POSから店舗を運営するための画面（商品、注文、顧客、クーポン、過去の日付のレポート）、払い戻し、連携するカードリーダーやその他の決済ゲートウェイ、顧客用ディスプレイが追加され、レジや店舗の数も増やせます。

<details>
<summary>Proで追加される機能</summary>

<FeatureGrid>
  <FeatureCard icon="box" title="商品管理" variant="pro">
    POSから直接、在庫や価格を変更できます
  </FeatureCard>
  <FeatureCard icon="file-invoice" title="注文と払い戻し" variant="pro">
    過去の注文を検索し、レシートの再印刷、編集、払い戻しができます
  </FeatureCard>
  <FeatureCard icon="users" title="顧客管理" variant="pro">
    顧客を追加・編集できます
  </FeatureCard>
  <FeatureCard icon="chart-pie" title="レポート" variant="pro">
    過去の日付、すべてのレジと店舗のデータを確認できます
  </FeatureCard>
  <FeatureCard icon="credit-card" title="カードリーダー" variant="pro">
    Stripe TerminalやSumUpなどの連携リーダーと、その他の決済ゲートウェイを利用できます

  </FeatureCard>
