お客様からクーポンコードを提示されたときや、キャンペーンを実施しているときに、店舗のクーポンをカート内の注文に適用する方法を説明します。クーポンの適用は無料プラグインでも利用できます。

:::note 店舗で作成したクーポンを使います
レジでは、店舗で作成済みのクーポンを適用します。**WP Admin → マーケティング → クーポン**で作成してください。詳しくは[クーポン](./index.mdx#creating-coupons)を参照してください。クーポンを使わずに値引きする場合は、[割引を追加](../pos/cart/discounts.mdx#order-level-discounts)を使用します。
:::

## クーポンを探す {#find}

1. 商品をカートに入れた状態で、カート上部の **+** を押し、**割引を追加**を選択します。スマートフォンではカートが独立したタブになっているので、先にそのタブを開いてください。
2. **クーポン**に切り替え、**クーポンを選択**を押します。
3. コードまたはクーポンの説明の一部を入力し、クーポンをタップします。
4. **適用**を押します。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 0], [0, 0], [-24, 0], [-30, 0], [-30, 0], [0, -34], [0, -44]]} alt="割引を追加ダイアログのクーポンタブでクーポン一覧を開いた状態。クイック割引とクーポンのタブ、クーポンを選択フィールド、検索ボックス、種類と金額が表示されたクーポン、新しいクーポンボタン、適用ボタンが表示されています">

1. **クイック割引** — クーポンを使わず、金額または割合を指定して注文を割り引きます。[割引](../pos/cart/discounts.mdx#order-level-discounts)を参照してください。
2. **クーポン** — 店舗のクーポンです。
3. **クーポンを選択** — 一覧を開きます。選択すると、ここにクーポンコードが表示されます。
4. **クーポンを検索** — コードまたは説明の一部を入力します。大文字と小文字は区別されません。
5. **クーポン** — コードに続いて説明が表示されます。説明がない場合は、**パーセント割引**、**カート固定割引**、**商品固定割引**のいずれかの種類が表示されます。右側には割引額が表示されます。
6. **新しいクーポン** (WCPOS Pro) — その場でクーポンを作成し、今回の注文に適用します。クーポンを作成する権限と店舗への接続が必要です。条件を満たしていない場合、**+** はグレー表示になります。
7. **適用** — この注文がクーポンの条件を満たしているか確認して適用します。

</JourneyShot>

一覧には、有効期限切れや利用上限に達したものを含め、店舗のすべてのクーポンが表示されます。レジが条件を確認するのは、選択したときではなく、**適用**を押したときです。

## クーポンを適用する {#apply}

**適用**を押すとダイアログが閉じ、合計欄の**小計**の下にクーポンが表示されます。コード、解除用の **✕**、割引額が表示されます。クーポンを追加するたびに、適用した順に行が追加されます。別のクーポンを追加するには、**割引を追加**をもう一度開きます。

カート内の商品にも割引分が反映されます。各行の合計が下がり、元の金額には取り消し線が付きます。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-28, 0], [100, 0], [40, 0], [40, 0], [0, 0]]} alt="クーポンを二つ適用したカート。追加メニュー、小計、各クーポンのコードと解除ボタンと割引額が並ぶ行、元の金額に取り消し線が付いた商品の合計、チェックアウトボタンが表示されています">

1. **+** — **割引を追加**をもう一度開き、別のクーポンを追加します。
2. **小計** — クーポン適用前の注文金額です。その下にクーポンの行が表示されます。
3. **クーポン** — コード、解除用の **✕**、割引額が表示されます。
4. **次のクーポン** — 適用した順に、クーポンごとに行が表示されます。
5. **チェックアウト** — 注文の支払いを受け付けます。[チェックアウト](../pos/checkout/index.mdx)を参照してください。

</JourneyShot>

レシートには WooCommerce に登録されたクーポンの説明が印刷されます。説明がない場合はコードが印刷されます。オフラインで印刷するレシートにはコードが表示されます。カートを変更すると、各クーポンの割引額が再計算されます。たとえば商品を追加すると、パーセント割引のクーポンによる割引額が増えます。

クーポンの確認には端末上のデータを使うため、オフラインでも適用できます。ただし、店舗が注文を受信した際に、合計を変更したり注文を拒否したりする場合があります。[問題が発生した場合](#goes-wrong)を参照してください。

## クーポンを解除する {#remove}

合計欄のクーポンの行にある **✕** を押します。割引額が元に戻り、**クーポンを解除しました**と表示されます。元に戻すには、クーポンを再度適用してください。

チェックアウト中は、クーポンの行に **✕** が表示されないため、支払いの受付中にクーポンが変更されることはありません。チェックアウト画面上部の **✕** を押してカートに戻り、クーポンを変更してから、再度**チェックアウト**を押してください。 {/* pending: monorepo#3364 */}

注文を[無効にする](../pos/cart/order-actions.mdx#void)と、適用したクーポンも解除されます。

## レジでクーポンを適用できない場合 {#refused}

注文がクーポンの条件を満たさない場合、ダイアログは開いたままとなり、クーポンの上に理由が赤字で表示されます。別のクーポンを選択するか、**キャンセル**を押してください。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-24, 0], [0, -44]]} alt="適用を押した後の割引を追加ダイアログ。クーポンフィールドの上に、このクーポンは有効期限が切れていますというメッセージが赤字で表示されています">

1. **クーポンを選択** — 適用を試みたクーポンです。上の赤字に適用できなかった理由が表示されます。ここで別のクーポンを選択できます。
2. **適用** — 注文が条件を満たす状態になったら、もう一度試します。

</JourneyShot>

以下から原因を確認してください。それぞれに、レジに表示されるメッセージ、原因、対処方法を記載しています。

<Accordion>
  <AccordionItem question="クーポンの有効期限が切れている">

レジの表示：**このクーポンは有効期限が切れています。**

クーポンの有効期限が過ぎているため利用できません。別のクーポンを選択してください。引き続き利用できるはずのクーポンであれば、店舗側で WP Admin から有効期限を変更できます。

  </AccordionItem>
  <AccordionItem question="クーポンの利用上限に達している">

レジの表示：**このクーポンは利用上限に達しています。**

店舗が設定した利用回数の上限に達しています。別のクーポンを選択してください。

  </AccordionItem>
  <AccordionItem question="お客様の利用回数が上限に達している">

レジの表示：**このお客様は、このクーポンを利用できる回数の上限に達しています。**

注文に設定されているお客様は、このクーポンの利用回数を使い切っています。注文に正しいお客様が設定されているか確認するか、別のクーポンを選択してください。

  </AccordionItem>
  <AccordionItem question="最低利用金額に達していない">

レジの表示：**このクーポンの最低利用金額は … です**

注文金額がクーポンの最低利用金額を下回っています。必要な金額はメッセージに表示されます。商品を追加するか、別のクーポンを選択してください。

  </AccordionItem>
  <AccordionItem question="最大利用金額を超えている">

レジの表示：**このクーポンは … 以下の注文にのみ適用できます。**

注文金額がクーポンの最大利用金額を超えています。上限額はメッセージに表示されます。一部の商品を別会計にするか、別のクーポンを選択してください。

  </AccordionItem>
  <AccordionItem question="追加するクーポンが併用不可になっている">

レジの表示：**… は他のクーポンと併用できません。利用するには、他のクーポンを解除してください。**

選択したクーポンは単独でのみ利用できます。注文に適用済みのクーポンを解除してから、このクーポンを適用してください。

  </AccordionItem>
  <AccordionItem question="適用済みのクーポンが併用不可になっている">

レジの表示：**… はすでに注文に適用されており、他のクーポンと併用できません。**

注文に単独でのみ利用できるクーポンが適用されています。該当するクーポンはメッセージに表示されます。新しいクーポンを使う場合は、適用済みのクーポンを解除してください。そうでなければ、適用済みのクーポンを残し、新しいクーポンの適用を取りやめてください。

  </AccordionItem>
  <AccordionItem question="クーポンがすでに適用されている">

レジの表示：**このクーポンはすでに注文に適用されています。**

同じクーポンを一つの注文に適用できるのは一度だけです。このクーポンはすでに適用されているため、操作は不要です。

  </AccordionItem>
  <AccordionItem question="注文にお客様のメールアドレスが設定されていない">

レジの表示：**このクーポンは特定のお客様のみ利用できます。まず、メールアドレスが登録されたお客様を注文に追加してください。**

このクーポンは特定のメールアドレスにのみ利用できますが、注文にはまだお客様のメールアドレスが設定されていません。カートでお客様を選択してから、クーポンを再度適用してください。

  </AccordionItem>
  <AccordionItem question="お客様のメールアドレスが対象に含まれていない">

レジの表示：**このクーポンは特定のお客様のみ利用できます。このお客様のメールアドレスは対象に含まれていません。**

お客様のメールアドレスがクーポンの対象リストにありません。注文に正しいお客様が設定されているか確認するか、別のクーポンを選択してください。

  </AccordionItem>
  <AccordionItem question="カートにクーポンの対象商品がない">

レジの表示：**このクーポンはこのカートに適用できません。**

カート内にクーポンの対象商品がないか、セール品を除外するクーポンなのにカートにセール品が含まれています。対象商品を追加するか、セール品をカートから削除してください。[価格変更とクーポン](#price-changes)を参照してください。

  </AccordionItem>
  <AccordionItem question="端末にクーポンがない">

レジの表示：**クーポンが見つかりません**

この端末にはまだクーポンがありません。[クーポンを取得](#sync)してから、もう一度試してください。

  </AccordionItem>
  <AccordionItem question="確認中にカートが変更された">

レジの表示：**クーポンの適用中にカートが変更されました。もう一度お試しください。**

レジがクーポンを確認している間にカートが変更されました。**適用**をもう一度押してください。

  </AccordionItem>
</Accordion>

## 複数のクーポンを使う {#more-than-one}

一つの注文に複数のクーポンを適用できます。クーポンを追加するたびに、**割引を追加**を開いてください。**個別使用のみ**に設定されたクーポンは、適用する順序にかかわらず、他のクーポンと併用できません。レジには、併用を妨げているクーポンが表示されます。

<Accordion>
  <AccordionItem question="二つ目のクーポンの計算方法">

**WP Admin → WooCommerce → 設定 → 一般**にある WooCommerce の**クーポン割引を順次計算する**設定によって異なります。レジは店舗の設定に従います。

$100.00 の注文に 10% 割引クーポンを二つ適用する場合：

- **オフ**（WooCommerce の初期設定）：各クーポンで $100.00 の 10%、つまりそれぞれ $10.00 が割り引かれます。お客様の支払額は **$80.00** です。
- **オン**：最初のクーポンで $10.00 が割り引かれます。二つ目では、残りの $90.00 の 10%、つまり $9.00 が割り引かれます。お客様の支払額は **$81.00** です。

この設定がオンの場合、適用する順序によって合計が変わることがあります。注文から $5 を値引きするようなカート固定割引クーポンは、どちらの設定でも同じ金額を割り引きます。

  </AccordionItem>
</Accordion>

## 価格変更とクーポン {#price-changes}

クーポンは商品行の価格を基に計算されます。レジで商品の価格を下げた場合、クーポンによる割引は元の価格ではなく、値下げ後の価格に対して適用されます。

<Accordion>
  <AccordionItem question="セール品を除外するクーポン">

レジで値下げした商品はセール品として扱われます。**セール品を除外する**に設定されたクーポンは、その商品を割引対象から除外します。また、**セール品を除外する**に設定されたカート固定割引クーポンは、その商品がカートにある間は利用できません。[POS での価格変更とクーポンの関係](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons)を参照してください。

  </AccordionItem>
</Accordion>

## 問題が発生した場合 {#goes-wrong}

**クーポンが一覧にありません。** <Anchor id="sync" />この端末がまだクーポンを取得していません。今すぐ取得するには、次の手順を行います。

1. メニューから**店舗の状態**を開き、**データベース**を開きます。
2. クーポンの行で**その他の操作**を開き、**今すぐ変更を確認**を選択します。
3. **割引を追加**をもう一度開き、クーポンを検索します。

それでも表示されない場合は、同じ行で**消去して再ダウンロード…** を選択します。レジがすべてのクーポンを再取得します。[消去して再ダウンロード](../support/store-health.mdx#clear-and-redownload)を参照してください。

<Accordion>
  <AccordionItem question="レジがクーポンを取得する仕組み">

レジは、初めて一覧を開いたときにクーポンを取得します。その後は定期的に店舗の変更を確認します。標準のプリセットでは 60 秒ごとです。WP Admin で作成したクーポンは、通常その時間内に表示されます。[同期プリセット](../support/store-health.mdx#sync-presets)を参照してください。

WCPOS Pro では、**クーポン**画面の一覧の下部に同期ボタンがあります。長押しして**消去して更新**を実行すると、すべてのクーポンを再取得できます。

  </AccordionItem>
</Accordion>

**店舗側でこの注文の合計が変更されました。** 注文が店舗に届いた際に、異なる合計が計算されました。店舗側の金額が確定額になるため、商品を渡す前に合計を確認してください。

**注文は保存されませんでした — 店舗が拒否しました。** 店舗が注文を受け付けなかったため、注文は元の状態でカートに残っています。メッセージには店舗側の理由、または**店舗から理由が返されませんでした**と表示されます。理由にクーポンが挙げられている場合は、そのクーポンを解除してから、もう一度**チェックアウト**を押してください。メッセージ内の**店舗の状態**ボタンで、拒否された内容を確認できます。[サーバーに反映されなかった変更](../support/store-health.mdx#refused-changes)を参照してください。

## レジで使いやすいクーポンの設定例 {#common-setups}

以下のクーポンは、**WP Admin → マーケティング → クーポン**で作成します。フィールド名は WooCommerce のものです。

<Accordion>
  <AccordionItem question="利用状況を追跡できるマネージャー割引">

`mgr10` というクーポンを作成します。
- **割引の種類：** パーセント割引
- **クーポン金額：** 10
- **個別使用のみ：** オフにすると、お客様のクーポンと併用できます
- **説明：** 「マネージャー割引」と入力すると、レジ係が *マネージャー* で検索して見つけられます

コードはマネージャーだけに伝えてください。レジで直接価格を下げる場合とは異なり、WooCommerce の**割引**合計に計上され、レポートにも表示されます。[POS の割引と WooCommerce クーポンの違い](../pos/cart/discounts.mdx#pos-discounts-vs-woocommerce-coupons)を参照してください。

  </AccordionItem>

  <AccordionItem question="リピーター向けの特典">

`loyal5` というクーポンを作成します。
- **割引の種類：** カート固定割引
- **クーポン金額：** 5
- **最低利用金額：** 25、または任意の金額
- **ユーザーごとの利用制限：** 特典を一度限りにする場合は 1
- **説明：** 「リピーター特典」

レジで *リピーター* を検索すれば、コードがわからなくても見つけられます。ユーザーごとの利用回数を正しく数えられるよう、適用する前にお客様を選択してください。

  </AccordionItem>

  <AccordionItem question="チラシや印刷物でのキャンペーン">

キャンペーンごとにクーポンを作成します。一度だけ使える券なら**クーポンごとの利用制限**を 1 に、共通コードならそれより多く設定します。キャンペーン終了後に使われないよう、**クーポンの有効期限**を設定してください。各お客様が一度ずつ使える共通コードにする場合は、**ユーザーごとの利用制限**も 1 に設定します。

  </AccordionItem>

  <AccordionItem question="お客様のクーポンにマネージャー割引を追加したい">

お客様のクーポンを先に適用し、その後でマネージャーのクーポンを適用します。お客様のクーポンが**個別使用のみ**の場合、レジは二つ目のクーポンを受け付けません。どちらを適用するか選ぶか、追加の値引きには[割引を追加](../pos/cart/discounts.mdx#order-level-discounts)を使ってください。

  </AccordionItem>
</Accordion>

:::info WCPOS Pro の場合
**新しいクーポン**で、レジからクーポンを作成して注文に適用できます。**クーポン**画面には、すべてのクーポンが金額、種類、利用状況、有効期限とともに一覧表示されます。無料プラグインではプレビューとして表示されます。
:::
