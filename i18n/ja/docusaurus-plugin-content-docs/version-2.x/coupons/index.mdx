:::info Pro の機能
**クーポン**画面には [WCPOS Pro](/getting-started/pro-license) が必要です。店舗で作成済みのクーポンの適用は、無料プラグインでも利用できます。[クーポンの適用](./applying-coupons.mdx)を参照してください。
:::

**クーポン**画面では、店舗の WooCommerce クーポンを POS 内で一覧表示できます。クーポンの検索、キャンペーン用クーポンの作成、金額や有効期限の変更、古いクーポンの削除ができます。変更はすべて店舗に送信されるため、**WP Admin › マーケティング › クーポン**やウェブサイトでも同じ内容になり、他のレジにも同期時に反映されます。

左側のメニューの**クーポン**アイコンから開きます。スマートフォンでは、先にメニューを開いてください。

<summary>無料プラグインでの画面表示</summary>

## クーポン一覧 {#coupon-list}

新しいクーポンが上に表示されます。下にスクロールすると、さらに読み込まれます。

一覧で変更すると、その都度店舗に送信されます。保存ボタンはありません。変更を取り消すには、元の値に戻してください。

1. **クーポンを検索** — コードまたは説明の一部を入力します。
2. **+** — [クーポンを作成](#creating-coupons)します。
3. **表示オプション** — 表示する列を選びます。**ステータス**、**作成日**、**更新日**は最初は非表示です。
4. **ステータス** — **公開済み**、**下書き**、**承認待ち**、**ゴミ箱**です。一覧には店舗の公開済みクーポンが表示されます。この端末で**下書き**や**承認待ち**に変更したクーポンは、レジが次にクーポンを取得するまでここに表示されます。
5. **割引の種類** — 特定の種類のクーポンだけを表示します。
6. **有効期限** — 指定した二つの日付の間に期限が切れるクーポンだけを表示します。
7. **有効** — 公開済みで有効期限内のクーポンには、緑色の**有効**が表示されます。それ以外は**無効**です。これはラベルであり、切り替えスイッチではありません。**有効**なクーポンでも、利用回数や購入金額の条件によって使えない場合があります。[レジでクーポンを適用できない場合](./applying-coupons.mdx#refused)を参照してください。
8. **コード** — お客様が提示するコードです。タップすると変更できます。
9. **>** — クーポンを開いて[変更](#edit)します。
10. **47 件中 8 件を表示** — 店舗の全クーポンのうち、一覧に表示されている件数です。横の矢印を押すと、店舗から最新の情報を取得します。

</JourneyShot>

1. **金額** — タップすると、テンキーで金額を変更できます。
2. **種類** — タップすると、その種類で一覧を絞り込みます。
3. **説明** — クーポンの[内部メモ](#fields)です。欄をタップすると変更できます。

1. **利用状況** — 利用済みの回数に続いて上限が表示されます。**1 / 100** は百回中一回利用済みという意味です。上限がない場合は、その上の **0** のように利用回数だけが表示されます。一度限りのクーポンでまだ誰も使っていない場合は **0 / 1** と表示されます。
2. **有効期限** — タップすると新しい日付を選択できます。**2025 年 12 月 31 日**はすでに過ぎているため、そのクーポンは**無効**と表示されています。

### 一覧を絞り込む {#filters}

フィルターを押して、表示されたリストから選択します。選択した条件と、解除用の **✕** がフィルターに表示されます。二つ以上のフィルターが有効な場合、**すべてクリア**ですべて解除できます。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[0, 0], [-14, 0], [-14, 0], [-14, 0]]} maxWidth={400} alt="ステータス、割引の種類、有効期限のフィルター。割引の種類を開くと、パーセント割引、カート固定割引、商品固定割引が表示されています">

1. **割引の種類** — 開いているフィルターです。
2. **パーセント割引** — 商品価格から一定の割合を割り引きます。
3. **カート固定割引** — 注文全体から一定の金額を割り引きます。
4. **商品固定割引** — 対象商品ごとに一定の金額を割り引きます。

</JourneyShot>

該当するクーポンがない場合は、**このフィルターに一致するクーポンはありません**と表示され、その下に**フィルターをクリア**が表示されます。

## クーポンを作成する {#creating-coupons}

1. クーポン画面上部の **+** を押します。
2. コードを入力するか、**生成**を押します。
3. 割引を選択し、金額を入力します。
4. 有効期限を選択します。
5. クーポンをすぐに使うには、**ステータス**を**ステータスを選択**のままにします。**有効**として保存され、一覧の**ステータス**フィルターでは**公開済み**と呼ばれます。まだ使わせたくない場合は、**下書き**または**承認待ち**を選択します。
6. 必要な制限を追加してから、**クーポンを追加**を押します。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-36, 0], [-32, 0], [-20, 0], [-20, 0], [36, 30], [-30, 0], [440, 0], [12, -30]]} alt="クーポン一覧の上に開いたクーポンを追加ダイアログ。生成されたコード、生成ボタン、10 パーセントに設定されたパーセント割引、有効期限として選択された 1 週間とその日付、一度限りの利用スイッチ、最低利用金額などの制限を追加するボタン、クーポンを追加ボタンが表示されています">

1. **コード** — お客様がレジで提示するコードです。レジでは大文字と小文字は区別されません。
2. **生成** — **POS-UA43** のようなコードを作成します。読み間違えやすい文字（0 と O、1、I、L）は使いません。
3. **割引** — **パーセント**、**注文金額から割引**、**商品金額から割引**から選びます。[クーポンの種類](#coupon-types)を参照してください。
4. **金額** — 割引率、または店舗の通貨での割引額です。
5. **有効期限** — **無期限**、**当日の終わり**、**1 週間**、**1 か月**、**日付を選択**から選びます。**当日の終わり**、**1 週間**、**1 か月**は、店舗のタイムゾーンで該当日の終わりまで有効です。日付は下に表示されます。
6. **一度限りの利用** — 一度使うと、そのクーポンは使えなくなります。
7. **最低利用金額**などのボタン — クーポンに制限や設定を追加します。[各設定の役割](#fields)を参照してください。
8. **クーポンを追加** — クーポンを店舗に保存します。**キャンセル**は保存せずに閉じます。

</JourneyShot>

新しいクーポンは、一覧とカート内のクーポン一覧にすぐに表示されます。

会計中にクーポンを作成し、そのまま注文に適用するには、カートの**新しいクーポン**を使います。[割引](../pos/cart/discounts.mdx#new-coupon)を参照してください。

### クーポンの種類 {#coupon-types}

三種類のクーポンは、POS と WooCommerce で名称が異なります。

- **パーセント**（WooCommerce：*パーセント割引*）— カート内の商品を一定の割合で割り引きます。`10` なら 10% 割引です。
- **注文金額から割引**（WooCommerce：*カート固定割引*）— 注文全体から一定額を割り引きます。`5.00` なら注文から $5 を割り引きます。
- **商品金額から割引**（WooCommerce：*商品固定割引*）— 対象商品ごとに一定額を割り引きます。`2.00` なら T シャツ一枚につき $2 を割り引きます。

### 各設定の役割 {#fields}

フォームには常に**ステータス**が表示されます。その下の各ボタンで、購入金額や利用回数の制限、**内部メモ**などの設定を一つずつ追加できます。追加した設定には**削除**ボタンが付き、再び取り除くことができます。各設定の役割は、以下の一覧を開いて確認してください。

<details>
<summary>クーポンの設定と制限</summary>

| 設定 | 役割 |
|---|---|
| **ステータス** | **有効**、**下書き**、**承認待ち**から選びます。**有効**は、WooCommerce と一覧の**ステータス**列では**公開済み**に相当します。下書きや承認待ちのクーポンは**無効**と表示され、次にレジがクーポンを取得したときに一覧から消えます。新しいクーポンは、別の設定を選ばない限り有効になります。 |
| **最低利用金額** | 注文金額がこの金額以上になるとクーポンを適用できます。 |
| **最大利用金額** | 注文金額がこの金額を超えるとクーポンを適用できません。 |
| **合計利用回数** | すべてのお客様を合わせて利用できる回数です。**一度限りの利用**がオンの場合は設定できません。 |
| **お客様ごとの利用回数** | 一人のお客様が利用できる回数です。 |
| **割引対象商品の最大数** | クーポンで割り引く商品の数です。**パーセント**と**商品金額から割引**のみで使えます。 |
| **併用不可** | 注文に他のクーポンが適用されていると、レジはこのクーポンを受け付けません。 |
| **送料無料も適用** | クーポンを必要とする送料無料の配送方法が、その注文で利用できるようになります。 |
| **内部メモ** | WooCommerce のクーポンの説明です。カートのクーポン一覧ではコードの下に表示され、店舗から印刷するレシートではコードの代わりに表示されるため、お客様にも見えます。非公開の情報は入力しないでください。 |
| **カスタムフィールド** | クーポンに保存する独自のキーと値です。 |

</details>

WooCommerce の一部の設定は POS のフォームにはありません。**商品**と**除外する商品**、**商品カテゴリー**と**除外するカテゴリー**、**セール品を除外する**、**許可するメールアドレス**が該当します。メールアドレスには `*` ワイルドカードが使えます。たとえばスタッフ専用にするなら `*@yourcompany.com` とします。これらは **WP Admin › マーケティング › クーポン**で設定してください。レジでもこれらの条件は適用されます。[レジでクーポンを適用できない場合](./applying-coupons.mdx#refused)を参照してください。**セール品を除外する**は、レジで値下げした商品も除外します。[POS での価格変更とクーポンの関係](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons)、開発者の方は [POS 割引リファレンス](../reference/pos-discounts.mdx)も参照してください。

## クーポンを変更する {#edit}

:::warning 保存ボタンはありません
変更はその都度店舗に送信されます。**閉じる**を押しても変更は取り消されません。元に戻すには、フィールドを再度変更してください。
:::

クーポンの行の右端にある **>** を押します。スマートフォンでは、クーポンをタップします。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-36, 0], [-32, 0], [-20, 0], [-38, 0], [96, 0], [-30, 0], [110, 0], [36, -24], [-14, 0], [84, 0], [-20, 0]]} alt="クーポン一覧の上に開いた welcome5 の編集ダイアログ。コードと生成ボタン、5.00 に設定された注文金額から割引、1 か月に設定された有効期限、オンになった一度限りの利用、有効のステータス、削除ボタン付きの最低利用金額、表示ボタン付きの非表示フィールド、同期ボタンと閉じるボタンが表示されています">

1. **コード** — ここで変更するか、**生成**を押して新しいコードを作成します。
2. **生成** — 新しいコードを作成します。古いコードは使えなくなります。
3. **割引** — 割引の種類です。
4. **金額** — 割引額です。
5. **有効期限** — 利用できなくなる日付です。
6. **一度限りの利用** — この例ではオンになっているため、一覧の**利用状況**には **0 / 1** と表示されます。
7. **ステータス** — **有効**、**下書き**、**承認待ち**から選びます。**有効**は、一覧の**ステータス**フィルターでは**公開済み**と呼ばれます。
8. **削除** — クーポンから設定を取り除きます。WP Admin で保存したクーポンでは、**最低利用金額**と**最大利用金額**が **0.00** と表示されることがよくあります。これは制限なしを意味します。
9. **表示** — プラグインが追加したフィールドを表示します。下の**非表示フィールドと JSON タブ**を参照してください。
10. **同期** — その後 WP Admin で行われた変更を反映するために、このクーポンを店舗から再取得します。
11. **閉じる** — ダイアログを閉じます。

</JourneyShot>

<details>
<summary>非表示フィールドと JSON タブ</summary>

**表示**を押すと、クーポンの非表示のカスタムフィールドが開きます。プラグインが独自の設定を保存するために使うため、プラグインの説明で指示されている場合にのみ変更してください。

ダイアログ上部の **JSON** タブには、店舗から送られてきたクーポンのデータがそのまま表示されます。

</details>

**同期**で店舗に接続できない場合は、**更新できませんでした。この端末のデータは変更されていません。接続を確認して、もう一度お試しください。** と表示されます。

## クーポンを削除する {#delete}

クーポンを削除する権限があるスタッフには、クーポンのダイアログの下部に**削除**が表示されます。

1. クーポンを開き、**削除**を押します。
2. **確認**にチェックを入れてから、**削除**を押します。

ダイアログには、**削除したクーポンはサーバー上のゴミ箱に移動されます。** という警告が表示されます。クーポンは WooCommerce の**ゴミ箱**に移動され、利用できなくなります。元に戻すには、**WP Admin › マーケティング › クーポン**を開き、**ゴミ箱**を選択して復元してください。削除せずに利用を停止したい場合は、有効期限を設定します。その日を過ぎると、レジで利用できなくなります。

## クーポンを作成・変更できるスタッフ {#permissions}

クーポンの作成、変更、削除にはそれぞれ権限が必要です。**WP Admin › POS › 設定 › アクセス**で設定します。

- **クーポンの作成と編集** — レジ係には初期設定で付与されています。この権限がないと、**+** はグレー表示になり、一覧を変更できません。
- **クーポンの削除** — レジ係には初期設定では付与されていません。この権限がないと、クーポンのダイアログに**削除**が表示されません。

グレー表示の **+** にカーソルを合わせると理由が表示されます。権限グループを変更するには、[POS へのアクセス](../settings/wp-admin/access.mdx)を参照してください。

## 会計にクーポンを適用する {#apply}

カートで **+** を押して**割引を追加**を選択し、**クーポン**に切り替えます。クーポンを選んで**適用**を押します。無料プラグインでも利用できます。[クーポンの適用](./applying-coupons.mdx)を参照してください。

## 問題が発生した場合 {#goes-wrong}

**WP Admin で作成したクーポンが一覧にありません。** 一覧の下部にある **… 件中 … 件を表示**の横の矢印を押すと、最新の情報を取得できます。長押しして**消去して更新**を実行すると、この端末の一覧データを消去し、すべて再取得します。

**+ がグレー表示になっています。** 無料プラグインでは、**Pro にアップグレード**と表示されます。それ以外の場合は、権限グループにクーポンを作成する権限がありません。[クーポンを作成・変更できるスタッフ](#permissions)を参照してください。

**変更が元に戻ります。** 店舗が変更を拒否しています。POS は店舗側の値に戻し、**店舗が拒否した変更を元に戻しました**とログに記録します。コードがすでに存在するなどの理由で店舗が拒否した新しいクーポンは、**店舗の状態**に表示されます。

**クーポンに「無効」と表示されます。** 有効期限が切れているか、ステータスが**有効**ではありません。クーポンを開き、**有効期限**または**ステータス**を変更してください。

**レジでクーポンを適用できません。** [レジでクーポンを適用できない場合](./applying-coupons.mdx#refused)を参照してください。
