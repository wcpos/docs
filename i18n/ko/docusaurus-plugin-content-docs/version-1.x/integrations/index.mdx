WCPOS는 WooCommerce REST API를 기반으로 실행되므로 대부분의 WooCommerce 플러그인은 별도 설정 없이 POS 주문에서 작동합니다. 일부 플러그인은 온라인 결제 또는 WP Admin 주문 화면에만 연결되므로 WCPOS에서 대신 작업을 수행해야 합니다. 이 섹션의 페이지에서는 해당 플러그인에 대해 WCPOS가 수행하는 작업, 설정 방법, 그리고 계산대에서 예상할 수 있는 사항을 설명합니다.

이는 [확장 기능](/extensions)과 다릅니다. 확장 기능은 확장 기능 디렉터리에서 설치하는 WCPOS용 추가 기능입니다. 통합은 온라인 매장에서 이미 사용 중인 플러그인입니다.

## 작동하지 않나요? {#something-not-working}

사용 중인 플러그인이 POS에서 제대로 작동하지 않는 경우 [플러그인 충돌](/support/troubleshooting/plugin-conflicts)부터 확인하세요. 알려진 충돌과 새 충돌을 식별하는 방법을 안내합니다.
