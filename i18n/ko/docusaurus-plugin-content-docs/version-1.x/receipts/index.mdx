WCPOS에는 영수증, 인보이스, 선물 영수증, 포장 명세서, 주방 티켓 등을 위한 완전한 템플릿 시스템이 포함되어 있으며, 모두 **WP Admin → POS → 템플릿**에서 관리합니다.

:::tip 영수증만 변경하고 싶으신가요?
**[영수증 사용자 지정하기](/1.x/receipts/customise)** 부터 시작하세요. 다른 기본 제공 템플릿 선택, AI에 수정 요청, 직접 편집이라는 가장 쉬운 세 가지 방법을 안내합니다.
:::

## 템플릿 엔진 {#template-engines}

WCPOS는 세 가지 템플릿 엔진을 지원합니다. 엔진은 템플릿을 만들거나 갤러리 카드에서 **템플릿 사용**을 클릭할 때 선택하며, **이후에는 변경할 수 없습니다**. 엔진을 바꾸려면 새 템플릿을 만드세요.

<FeatureGrid>
  <FeatureCard icon="code" title="로직리스 HTML (권장)">
    Mustache 스타일의 <code>{"{{variable}}"}</code> 플레이스홀더를 일반 HTML 안에 사용합니다. 클라이언트 측에서 렌더링되므로 영수증이 **오프라인에서도 작동**합니다. 브라우저 인쇄 및 PDF 영수증에 사용하세요.
  </FeatureCard>
  <FeatureCard icon="print" title="열전사 XML">
    화면 미리보기와 열전사 영수증 프린터용 **ESC/POS 명령**을 모두 생성하는 XML 템플릿입니다. 하나의 템플릿으로 두 가지 출력을 제공합니다. Epson, Star 및 기타 열전사 프린터에 사용하세요.
  </FeatureCard>
  <FeatureCard icon="terminal" title="레거시 PHP">
    WooCommerce 함수를 사용하는 서버 측 PHP 템플릿입니다. 기존 <code>yourtheme/woocommerce-pos/receipt.php</code> 오버라이드와의 하위 호환성을 위해 유지됩니다. 렌더링하려면 서버 연결이 필요합니다.
  </FeatureCard>
</FeatureGrid>

## 템플릿 갤러리 {#template-gallery}

갤러리에는 그대로 사용하거나 사용자 지정할 수 있는 완성된 템플릿이 포함되어 있습니다. **카테고리**(영수증, 인보이스, 선물 영수증, 주방 티켓, 견적서 / 구매 주문서), **형식**(HTML / 열전사), **방향**(LTR / RTL)으로 필터링하고 매장의 실제 데이터로 미리 보세요. 각 카드 하단에는 **미리보기** 링크와 기본 작업인 **템플릿 사용** 버튼이 있습니다. 템플릿 사용을 클릭하면 *내 템플릿*에 편집 가능한 사본이 생성됩니다.

### 서드파티 문서 템플릿 {#third-party-document-templates}

WP Overnight의 **PDF Invoices & Packing Slips for WooCommerce**가 활성화되어 있으면 WCPOS는 영수증 템플릿 목록에 **인보이스 (WP Overnight)** 와 **포장 명세서 (WP Overnight)** 도 표시합니다. 서버에서 렌더링되는 이 HTML 템플릿은 WP Overnight의 문서 API에 처리를 위임하며, 해당 플러그인에 설정된 인보이스 및 포장 명세서 번호 매기기, 레이아웃, 브랜딩, 법률/세금 필드, 템플릿 사용자 지정 내용을 그대로 사용합니다.

이 템플릿은 WP Overnight 플러그인이 활성화된 동안에만 사용할 수 있으며, 렌더링하려면 서버 연결이 필요합니다. 오프라인 인쇄가 필요하다면 WCPOS의 기본 제공 HTML 또는 열전사 템플릿을 사용하세요.

### 적응형 세금 표시 {#adaptive-tax-display}

대부분의 기본 제공 템플릿(기본, 기본 RTL, 미니멀/모던, 좁은 영수증, 인보이스, 견적서, 간편 열전사 변형)은 **WooCommerce 세금 표시 설정에 자동으로 맞춰집니다**:

- **세금 포함 매장**(EU/UK/AU)에는 세금 포함 가격과 ‘세금 포함’ 항목이 표시됩니다.
- **세금 별도 매장**(US/CA)에는 세금 제외 가격이 표시되며 세금이 별도 항목으로 추가됩니다.
- 총합계에는 항상 실제로 청구된 세금 포함 금액이 표시됩니다.

**상세** 계열은 정식 세금계산서로, 매장 설정과 관계없이 항상 세금 제외 항목과 명시적인 세금 내역을 표시합니다.

## 작동 방식 {#how-it-works}

1. **템플릿 추가** — 갤러리 카드에서 **템플릿 사용**을 클릭하거나 처음부터 직접 만드세요.
2. 실시간 미리보기가 있는 인앱 편집기로 **사용자 지정**하거나, ChatGPT / Claude에 붙여넣고 원하는 변경 사항을 요청하세요.
3. **활성화** — *내 템플릿*에서 **활성** 토글을 켜세요. 활성화된 모든 영수증 템플릿은 계산대의 영수증 화면 드롭다운에 표시됩니다.
4. **인쇄 또는 표시** — 결제 후 영수증이 열리며 인쇄, 이메일 전송, 화면 보기 옵션이 제공됩니다. 템플릿은 계산대 밖에서도 사용할 수 있습니다. 온라인 고객은 동일한 디자인으로 렌더링된 영수증을 [내 계정에서 다운로드](/1.x/receipts/storefront)할 수 있습니다.

템플릿은 매장 정보, 항목, 합계, 세금, 결제, 환불 등의 섹션을 갖춘 표준화된 [영수증 데이터 페이로드](/1.x/receipts/receipt-data)를 사용해 렌더링됩니다. 모든 통화 필드에는 미리 서식이 지정된 `_display` 변형이 포함됩니다(예: `$29.99` 대신 `29.99`).

## Pro 기능 {#pro-features}

[WCPOS Pro](/1.x/getting-started/pro-license)를 사용하면 매장별로 템플릿 할당, 브랜딩(로고, 주소, 연락처 정보), 템플릿 순서를 설정할 수 있습니다. 각 지점에서 자체 레터헤드를 인쇄하는 다중 매장 운영에 유용합니다.
