열전사 템플릿은 하나의 템플릿에서 화면 미리보기와 ESC/POS 프린터 명령을 모두 생성하는 XML 형식을 사용합니다. 데이터 바인딩에는 [HTML 템플릿](/1.x/receipts/html-templates)과 동일한 `{{variable}}` 플레이스홀더를 사용합니다.

[프린터 설정](/1.x/hardware/printers)을 통해 연결한 영수증 프린터가 있다면 이 엔진을 선택하세요.

## XML 요소 {#xml-elements}

### 루트 요소 {#root-element}

모든 열전사 템플릿은 `<receipt>` 루트로 시작합니다:

```xml
<receipt paper-width="48">
  <!-- 48 characters = 80mm paper -->
  <!-- 32 characters = 58mm paper -->
</receipt>
```

### 텍스트 및 서식 {#text-and-formatting}

```xml
<text>Plain text</text>
<bold>Bold text</bold>
<underline>Underlined text</underline>
<invert>Inverted (white on black)</invert>
```

### 정렬 {#alignment}

```xml
<align mode="left">Left aligned</align>
<align mode="center">Centered</align>
<align mode="right">Right aligned</align>
```

### 텍스트 크기 {#text-size}

텍스트의 너비와 높이를 각각 조정하세요:

```xml
<size width="2" height="2">Double-size text</size>
<size width="2" height="1">Wide text</size>
<size width="1" height="2">Tall text</size>
```

### 표 형식 레이아웃 {#tabular-layout}

로고를 삽입하려면 `<row>` 와 `<col>` 을 사용하세요:

```xml
<row>
  <col width="24">Item name</col>
  <col width="8" align="right">Qty</col>
  <col width="16" align="right">Price</col>
</row>
```

열 너비의 단위는 문자 수입니다. 남은 공간을 채우는 가변 열에는 `width="*"`를 사용하세요. 그러면 용지 너비가 달라도 수정 없이 템플릿을 사용할 수 있습니다:

```xml
<row>
  <col width="*">{{name}}</col>
  <col width="12" align="right">{{line_total_display}}</col>
</row>
```

### 구분선 및 간격 {#separators-and-spacing}

```xml
<line />                       <!-- Default single rule -->
<line style="double" />        <!-- Printer-native double rule -->
<line style="dashed" />        <!-- Character dashes across the width -->
<line style="dotted" />        <!-- Character dots across the width -->
<feed lines="2" />             <!-- Blank lines -->
```

`<line/>` (또는 `style="single"`) 및 `style="double"` 는 프린터의 기본 구분선을 인쇄합니다. `dashed` 와 `dotted` 는 현재 열 너비 전체에 문자 기반 구분선을 인쇄합니다. 열전사 미리보기의 스크린샷에도 구분선이 보이게 하고 싶을 때 유용합니다.

### 프린터 명령 {#printer-commands}

```xml
<cut />              <!-- Full paper cut -->
<cut mode="partial" /> <!-- Partial cut (leaves a tab) -->
<drawer />           <!-- Open cash drawer -->
```

### 바코드 및 QR 코드 {#barcodes-and-qr-codes}

```xml
<barcode type="code128" height="40">{{order.number}}</barcode>
<barcode type="qrcode" scale="3">{{fiscal.qr_payload}}</barcode>
```

## 예시: 간단한 80mm 영수증 {#example-simple-80mm-receipt}

```xml
<receipt paper-width="48">
  <align mode="center">
    <size width="2" height="2">{{store.name}}</size>
  </align>
  <feed lines="1" />
  <align mode="center">
    <text>{{store.address_1}}</text>
    <text>{{store.city}} {{store.state}} {{store.postcode}}</text>
    {{#store.phone}}<text>{{store.phone}}</text>{{/store.phone}}
  </align>
  <line />

  <text>Order: #{{order.number}}</text>
  <text>Date: {{order.created.datetime}}</text>
  {{#cashier.name}}<text>Cashier: {{cashier.name}}</text>{{/cashier.name}}
  <line />

  <!-- Column headers -->
  <row>
    <col width="*"><bold>Item</bold></col>
    <col width="4" align="right"><bold>Qty</bold></col>
    <col width="12" align="right"><bold>Total</bold></col>
  </row>
  <line />

  <!-- Line items -->
  {{#lines}}
  <row>
    <col width="*">{{name}}</col>
    <col width="4" align="right">{{qty}}</col>
    <col width="12" align="right">{{line_total_display}}</col>
  </row>
  {{/lines}}

  <line />

  <!-- Totals -->
  <row>
    <col width="*">Subtotal</col>
    <col width="16" align="right">{{totals.subtotal_display}}</col>
  </row>
  {{#totals.tax_total}}
  <row>
    <col width="*">Tax</col>
    <col width="16" align="right">{{totals.tax_total_display}}</col>
  </row>
  {{/totals.tax_total}}
  <row>
    <col width="*"><bold>TOTAL</bold></col>
    <col width="16" align="right"><bold>{{totals.total_display}}</bold></col>
  </row>

  <line />

  {{#payments}}
  <row>
    <col width="*">{{method_title}}</col>
    <col width="16" align="right">{{amount_display}}</col>
  </row>
  {{#tendered}}
  <row>
    <col width="*">Tendered</col>
    <col width="16" align="right">{{tendered_display}}</col>
  </row>
  <row>
    <col width="*">Change</col>
    <col width="16" align="right">{{change_display}}</col>
  </row>
  {{/tendered}}
  {{/payments}}

  <feed lines="2" />
  <align mode="center">
    <text>Thank you for your purchase!</text>
  </align>
  <feed lines="3" />
  <cut />
</receipt>
```

## 가변 너비 열 {#star-width-columns}

`width="*"` 기능을 사용하면 용지 너비에 종속되지 않는 템플릿을 만들 수 있습니다. 특정 용지 크기에 맞춰 열 너비를 고정하는 대신 늘어나야 하는 열에 `*`를 사용하세요:

```xml
<!-- Works on 58mm (32 char) AND 80mm (48 char) printers -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

80mm 프린터(48자)에서는 상품 이름에 38자를 사용할 수 있습니다. 58mm 프린터(32자)에서는 22자를 사용할 수 있습니다. 고정 열은 두 용지 크기에서 동일한 너비를 유지합니다.

:::warning 기존 StarPRNT 고정 레이아웃 어댑터 제거
기존 StarPRNT **고정 레이아웃 출력 어댑터**는 v1.10에서 제거되었습니다. 이 어댑터를 사용하던 템플릿은 공유 열전사 레이아웃을 통해 Star 출력을 생성하는 현재 열전사 템플릿(이 페이지의 XML 엔진)으로 전환하세요. 고정 어댑터 대신 `<row>`/`<col>` 와 `width="*"` 를 사용해 레이아웃을 다시 만드세요.
:::

## 템플릿 미리보기 {#template-preview}

템플릿 편집기는 편집 중에 **실시간 열전사 미리보기**를 표시합니다. XML을 스타일이 적용된 고정폭 HTML로 렌더링하여 용지에 인쇄될 영수증의 모습을 보여 줍니다. 변경 사항은 짧은 지연 후 반영됩니다(300ms 디바운스 적용).

같은 템플릿이 미리보기와 ESC/POS 프린터 출력을 모두 생성하므로 별도의 ‘인쇄’ 템플릿이 필요하지 않습니다. 바코드와 QR 코드는 미리보기에서는 인라인 SVG로, 프린터에서는 기본 ESC/POS 명령(또는 래스터 이미지)으로 렌더링됩니다.

## 작성 팁과 주의 사항 {#authoring-tips-and-pitfalls}

열전사 인쇄에는 HTML에는 없는 몇 가지 주의점이 있습니다. 작성자가 가장 자주 마주치는 문제는 다음과 같습니다.

### 줄을 바꾸려면 스타일이 적용된 제목을 `<text>`로 감싸세요 {#wrap-styled-headings-in-text-for-a-line-break}

스타일 컨테이너인 `<bold>`, `<size>`, `<underline>`, `<align>` 는 **자체적으로 줄바꿈을 출력하지 않습니다**. 줄바꿈은 `<text>` 와 블록 요소(`<line/>`, `<row>`, `<feed>`)만 출력합니다.

```xml
<!-- ❌ Bug: the heading runs together with whatever follows -->
<bold>{{i18n.bill_to}}</bold>
{{customer.name}}

<!-- ✅ Fix: wrap the inner content in <text> -->
<bold><text>{{i18n.bill_to}}</text></bold>
<text>{{customer.name}}</text>
```

기본 제공되는 80mm 갤러리 템플릿은 모든 제목에 이 패턴을 사용합니다.

### 좁은 행 안에서는 `<size width="2">`를 사용하지 마세요 {#avoid-size-width2-inside-narrow-rows}

너비를 두 배로 늘린 텍스트는 **문자당 차지하는 공간도 두 배가 됩니다**. 80mm 프린터에 맞는 제목도 일반적인 42열 80mm 프린터에서는 넘칠 수 있으며, 58mm 용지에는 16자만 들어갑니다.

크게 표시할 합계나 주방 주문 번호처럼 눈에 띄어야 하는 값은 여러 열로 구성된 `<row>`안에 넣는 대신 별도의 확대된 줄로 출력하세요:

```xml
<!-- For store names, prefer normal-width, double-height -->
<bold><size height="2"><text>{{store.name}}</text></size></bold>

<!-- For a bold total, put it on its own line above the row -->
<align mode="right">
  <bold><size height="2"><text>{{totals.total_display}}</text></size></bold>
</align>
```

### 용지 너비에 종속되지 않는 레이아웃에는 `width="*"`를 사용하세요 {#use-width-for-paper-width-agnostic-layouts}

`width="*"`(별표) 열은 고정 너비 열이 차지하고 남은 너비를 채웁니다. 따라서 같은 템플릿이 수정 없이 32열(58mm), 42열(표준 80mm), 48열(넓은 80mm) 프린터에서 올바르게 렌더링됩니다:

```xml
<!-- Works on 58mm AND 80mm without changes -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

너비를 숫자로 직접 지정한다면 48이 아니라 **42에 맞추세요**. 너비 합계가 48인 행은 일반적인 42열 80mm 프린터에서 줄바꿈됩니다.

### `<align>` 블록 안에서 스타일이 적용된 제목 가운데 정렬 {#centred-styled-headings-inside-align-blocks}

정렬 모드가 `<align mode="center">` (또는 `right`)인 블록에서 스타일이 적용된 제목 요소인 `<bold>`, `<size>`, `<underline>`, `<invert>` 를 `<align>` 바로 안에 배치하고 뒤에 다른 줄을 넣으면 제목은 자동으로 별도의 줄에 배치됩니다. 가운데 정렬된 주소 줄 위의 가운데 정렬된 확대 매장 이름은 명시적으로 `<text>` 로 감싸는 방식을 유지하세요.

정렬 블록 밖에서는 `<text>` 로 감싸는 방식을 유지하세요.

### ESC/POS 문장 부호 정규화 {#escpos-punctuation-normalisation}

프린터 언어가 ESC/POS이면 인코더는 출력 전에 인쇄용 문장 부호를 안전한 ASCII로 정규화합니다:

- 엔 대시, 엠 대시, 숫자 대시, 유니코드 빼기 기호 → `-`
- 곡선 따옴표 → 직선 따옴표
- 줄바꿈 없는 공백 → 일반 공백

따라서 유니코드 글꼴이 없는 프린터에서도 `Mon–Sat 9:00–18:00`과 `"open"`이 올바르게 인쇄됩니다. Star 프린터(`star-line` / `star-prnt`)는 원래 문자 형태를 **유지**하므로 프린터 글꼴이 지원하는 문자를 사용하세요.

### 비라틴 문자 및 오른쪽에서 왼쪽으로 쓰는 문자 {#non-latin-and-rtl-scripts}

열전사 프린터는 내장 글꼴과 코드페이지를 사용해 텍스트를 인쇄합니다. 따라서 아랍어, 히브리어, 페르시아어, 우르두어 등 비라틴 문자는 프린터를 해당 문자에 맞는 코드페이지(예: 아랍어의 경우 CP864 / Windows-1256)로 설정해야 올바르게 인쇄됩니다. 그렇지 않으면 공백이나 깨진 문자가 출력됩니다.

이러한 문자를 안정적으로 인쇄하는 방법은 **전체 영수증 래스터**입니다. 영수증 전체를 이미지로 렌더링하므로 프린터의 내장 글꼴과 관계없이 디자인한 그대로 인쇄됩니다. 래스터 모드를 켜는 방법은 [프린터 설정](/1.x/hardware/printers)을 참조하세요.

:::note 열전사 하드웨어에는 열전사 템플릿이 필요합니다
열전사 프린터는 전체 페이지 **HTML** 템플릿을 인쇄할 수 없습니다. 인쇄 작업을 ESC/POS 또는 Star 명령으로 렌더링해야 하지만 HTML로는 이를 표현할 수 없기 때문입니다. 열전사 하드웨어에는 열전사 템플릿을 사용하세요. A4/Letter 전체 페이지 HTML은 시스템/PDF 프린터나 [PrintNode](/1.x/receipts/cloud-printing#setup-printnode)를 통해 인쇄하세요.
:::

### 로고와 이미지 {#logos-and-images}

로고를 삽입하려면 `<image>` 를 사용하세요:

```xml
<align mode="center">
  <image src="data:image/png;base64,..." />
</align>
```

WCPOS는 클라이언트에서 이미지를 래스터화합니다. 디코딩, 투명 영역을 흰색으로 변환, 프린터의 도트 수에 맞춘 크기 조정, 단색 변환(로고에는 Atkinson 디더링, 바코드에는 임계값 처리)을 거친 뒤 ESC/POS 또는 Star 이미지 명령을 전송합니다.

- **도트 수**: 58mm는 너비 384도트, 80mm는 너비 576도트입니다.
- **허용되는 소스**: `data:image/png` 및 `data:image/jpeg` 데이터 URL, 절대 `http(s)` URL, 동일 출처의 루트 상대 경로입니다. 프로토콜 상대 경로 `//`, 백슬래시, 퍼센트 인코딩된 `..` 경로 탐색은 거부됩니다.
- **권장 형식**: 배경이 투명하거나 흰색인 고대비 PNG입니다. JPEG도 사용할 수 있지만 압축으로 인한 흔적이 잡음처럼 인쇄될 수 있습니다.
- 원시 열전사 출력에서는 **SVG가 아직 지원되지 않습니다**.

### 팁 {#tips}

- **갤러리 템플릿에서 시작하세요** — 갤러리의 열전사 템플릿은 위 패턴을 모두 사용하며 실제 프린터로 검증되었습니다.
- 매장마다 다른 프린터를 사용한다면 **두 용지 크기를 모두 테스트**하거나 `width="*"` 열을 사용하세요.
- 통화에는 **`_display` 필드를 사용하세요** — 이미 로케일을 반영합니다.
- **단순하게 유지하세요** — 열전사 인쇄는 설계상 HTML보다 서식 도구가 적습니다. `<row>` + `<col width="*">` 조합을 활용하고 나머지는 프린터가 처리하도록 하세요.
