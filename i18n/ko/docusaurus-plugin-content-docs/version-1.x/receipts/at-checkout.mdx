결제가 성공적으로 처리되면 영수증 모달이 표시됩니다. 완료된 주문의 요약을 보여 주며, 영수증을 인쇄하거나 이메일로 보낼 수 있습니다.

{/* Screenshot: receipt-modal.png */}

## 영수증 내용 {#receipt-contents}

영수증에는 다음 정보가 표시됩니다:

### 매장 정보 {#store-information}
- **매장 이름**
- **주소**
- **전화번호**
- **이메일**
- **웹사이트**
- **로고** (설정된 경우)

### 영수증 헤더 {#receipt-header}
- **영수증 유형** (예: ‘세금 영수증’)
- **주문 번호**
- **날짜 및 시간**
- **캐셔 이름**
- **결제 방법**

### 주문 상세 정보 {#order-details}
- **품목**별로 다음 정보가 포함됩니다:
  - 제품명
  - 변형 속성(해당하는 경우)
  - 수량
  - 가격
  - 합계

### 합계 {#totals}
- **소계**
- **세금** (해당하는 경우)
- **합계**
- **받은 금액** (현금 결제 시)
- **거스름돈** (현금 결제 시)

### 고객 정보 {#customer-information}
- **청구 주소**
- **배송 주소** (청구 주소와 다른 경우)

## 영수증 작업 {#receipt-actions}

### 닫기 {#close}
영수증 모달을 닫고 POS로 돌아갑니다.

### 영수증 이메일 보내기 {#email-receipt}
고객의 이메일 주소로 영수증을 보내려면:

1. **영수증 이메일 보내기**를 클릭하세요
2. 이메일 주소를 확인하세요
3. WooCommerce 이메일 시스템을 통해 영수증이 전송됩니다

주문에 고객의 이메일 주소가 연결되어 있어야 합니다.

### 영수증 인쇄 {#print-receipt}
영수증을 종이로 인쇄하려면:

1. **영수증 인쇄**를 클릭하세요
2. 브라우저의 인쇄 대화 상자가 열립니다
3. 영수증 프린터를 선택하고 인쇄하세요

:::tip 영수증 프린터
WCPOS는 브라우저에서 접근할 수 있는 모든 프린터에서 작동합니다. 최상의 결과를 위해 다음을 권장합니다:
- 전용 영수증 프린터 사용(감열식 프린터가 일반적입니다)
- 프린터 설정에서 용지 크기를 설정하세요
- 빠르게 인쇄할 수 있도록 인쇄 프리셋을 설정하세요
:::

## 자동 영수증 옵션 {#automatic-receipt-options}

[카트 표시 설정](/1.x/pos/cart#display-settings)에서 다음 옵션을 설정할 수 있습니다:

- **결제 후 영수증 자동 표시** - 결제 직후 영수증 모달을 엽니다
- **결제 후 영수증 자동 인쇄** - 영수증이 표시되면 자동으로 인쇄를 실행합니다

이 옵션을 사용하면 많은 결제를 더 빠르게 처리할 수 있습니다.

## 영수증 사용자 지정 {#customising-receipts}

영수증 모양은 WordPress의 다음 위치에 있는 템플릿에서 설정합니다:

`WP Admin > POS > Templates`

다음 항목을 사용자 지정하는 방법은 [영수증 템플릿](/1.x/receipts)을 참조하세요:

- 매장 정보 표시
- 로고 및 브랜딩
- 레이아웃 및 서식
- 포함할 정보

## 영수증 재인쇄 {#reprinting-receipts}

이전 주문의 영수증을 다시 인쇄하려면:

1. [주문 화면](/1.x/orders)으로 이동하세요(Pro 기능)
2. 주문을 찾으세요
3. 클릭하여 주문을 여세요
4. 영수증 옵션을 사용하여 다시 인쇄하세요
