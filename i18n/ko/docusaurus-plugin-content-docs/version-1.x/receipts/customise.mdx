영수증 모양을 변경하려면 세 가지 방법이 있습니다. 필요에 맞는 가장 쉬운 방법을 선택하세요 — 대부분의 매장은 첫 번째 방법만으로 충분합니다.

## 세 가지 사용자 정의 방법 {#three-ways-to-customise}

<FeatureGrid>
  <FeatureCard icon="grid" title="1. 다른 템플릿 선택하기">
    갤러리에서 미리 만들어진 템플릿을 사용합니다. **코드가 전혀 필요 없습니다.** 적합한 경우: 다른 레이아웃, 가격 숨기기, A4 인보이스, 주방 전표.
  </FeatureCard>
  <FeatureCard icon="sparkles" title="2. AI에게 수정 요청하기">
    템플릿을 ChatGPT 또는 Claude에 붙여넣고 원하는 내용을 설명합니다. **코딩 기술이 필요 없습니다** — 일반 언어로 설명하기만 하면 됩니다. 적합한 경우: 문구, 색상 또는 배치 변경 등 간단한 수정.
  </FeatureCard>
  <FeatureCard icon="code" title="3. 직접 편집하기">
    앱 내 편집기에서 템플릿을 직접 변경할 수 있습니다. 적합한 경우: 정밀한 제어가 필요하거나, 이미 HTML을 알고 있는 경우.
  </FeatureCard>
</FeatureGrid>

세 가지 방법 모두 같은 곳에서 시작합니다: **WP Admin → POS → 템플릿**. 이 페이지는 두 부분으로 구성되어 있습니다 — 상단의 **내 템플릿**(현재 사용 중인 템플릿)과 하단의 **템플릿 갤러리**(기본 제공 라이브러리).

## 옵션 1 — 다른 템플릿 선택 {#option-1--pick-a-different-template}

가장 쉬운 방법이며 대부분의 요구 사항을 충족합니다.

<Steps>
  <StepCard number="1" title="템플릿 갤러리 열기">

WP Admin에서 **POS → 템플릿**으로 이동합니다. *내 템플릿*을 지나 **템플릿 갤러리** 섹션으로 스크롤하면 스타터 라이브러리를 확인할 수 있습니다.

  </StepCard>
  <StepCard number="2" title="탐색 및 미리보기">

**카테고리**(영수증, 송장, 선물 영수증, 주방 티켓, 견적서 / 구매 주문서), **형식**(브라우저 인쇄용 HTML, 감열 프린터용 Thermal) 또는 **방향**(왼쪽에서 오른쪽 또는 오른쪽에서 왼쪽)으로 필터링하세요. 카드의 미리보기 이미지나 하단의 **미리보기** 링크를 클릭하면 매장의 실제 데이터가 적용된 실시간 미리보기가 열립니다.

  </StepCard>
  <StepCard number="3" title="사용하기" isLast>

카드에서 **템플릿 사용**을 클릭합니다. WCPOS가 편집 가능한 사본을 만들어 페이지 상단의 **내 템플릿**에 추가합니다. 행의 **활성화** 토글을 켜면 영수증에 사용되며, 행의 그립 핸들을 드래그하여 순서를 변경할 수 있습니다. 여러 템플릿을 동시에 활성화할 수 있으며, 계산대에서 캐셔가 선택합니다.

  </StepCard>
</Steps>

:::tip 템플릿 사용은 기존 항목을 대체하지 않습니다
**템플릿 사용**을 클릭하면 항상 새 사본이 생성됩니다. 원본 갤러리 템플릿은 변경되지 않으므로 언제든 다시 돌아와 다른 시작점을 선택할 수 있습니다. 여러 영수증 템플릿이 활성화된 경우 영수증 화면에 드롭다운이 표시되어 캐셔가 즉시 전환할 수 있습니다.
:::

### 번들 템플릿 {#the-bundled-templates}

| 템플릿 | 형식 | 용도 |
|---|---|---|
| **표준 영수증** | HTML | 기본 — 로고, 항목, 합계, 결제. 대부분의 매장에 적합 |
| **표준 영수증 (RTL)** | HTML | 표준과 동일하며, 아랍어 / 히브리어 / 페르시아어 / 우르두어용으로 미러링 |
| **미니멀 / 모던** | HTML | 표준과 동일한 정보를 더 적은 세로 공간에 배치 |
| **상세 영수증** | HTML | 전체 세금계산서 — SKU 열, 단가, 세율별 세금 내역, 주소 |
| **선물 영수증** | HTML | 항목만 표시 — 가격 숨김. 선물 메시지 및 반품 정책 포함 |
| **인보이스** | HTML | A4/레터 전체 페이지 인보이스. 미결제 주문에 "결제 방법" 패널 추가 |
| **포장 명세서** | HTML | 창고용 — 항목 + 수량, 배송지, 가격 없음 |
| **견적서** | HTML | 가격 및 조건이 포함된 사전 판매 문서 — 결제 섹션 없음 |
| **좁은 영수증** | HTML | 좁은 용지 또는 HTML 지원 감열 프린터용 고정폭 영수증 |
| **간단한 감열 영수증 (58mm)** | 감열 | 깔끔한 58mm 감열 레이아웃 |
| **간편 감열 영수증 (80mm)** | 감열 | 깔끔한 80mm 감열 레이아웃 — 가장 일반적 |
| **간편 감열 영수증 80mm (RTL)** | 감열 | 80mm RTL 버전. 아랍어 코드페이지를 지원하는 프린터 필요 |
| **상세 감열 영수증 (58mm / 80mm)** | 감열 | 세금 내역, 주소, 환불, 결제, 약관, 바코드 포함 |
| **주방 티켓** | 감열 | 품목만 표시, 큰 글꼴, 가격 없음 — 조리 스테이션용 |

대부분의 기본 제공 템플릿은 **매장의 세금 설정에 자동으로 적응합니다** — 세금 포함 매장에서는 총액과 "세금 포함" 항목이 표시되고, 세금 별도 매장에서는 순액에 세금이 별도 항목으로 추가됩니다. **상세** 계열은 설정에 관계없이 항상 전체 세금 내역을 표시합니다.

### WP Overnight 송장 및 포장 명세서 템플릿 {#wp-overnight-invoice-and-packing-slip-templates}

사이트에서 WP Overnight의 [PDF Invoices & Packing Slips for WooCommerce](https://wordpress.org/plugins/woocommerce-pdf-invoices-packing-slips/)도 사용하는 경우, WCPOS는 **내 템플릿**에 두 개의 추가 템플릿을 자동으로 추가합니다:

| 템플릿 | 형식 | 용도 |
|---|---|---|
| **송장 (WP Overnight)** | 서버에서 렌더링한 HTML | POS 주문에 WP Overnight에서 설정한 송장 문서를 사용 |
| **포장 명세서 (WP Overnight)** | 서버에서 렌더링한 HTML | POS 주문에 WP Overnight에서 설정한 포장 명세서 문서를 사용 |

이 템플릿은 WCPOS의 기본 제공 송장이나 포장 명세서 레이아웃을 복사하지 않습니다. WP Overnight에 POS 주문의 문서 렌더링을 요청하므로 기존 송장 번호, 브랜딩, 법률/세금 관련 필드, WP Overnight 템플릿의 사용자 정의 사항이 온라인 주문과 매장 주문에서 일관되게 유지됩니다.

이 템플릿은 WP Overnight 플러그인이 활성화되어 있을 때만 표시됩니다. 출력 결과는 별도 PDF로 다운로드되는 대신 WCPOS 인쇄 화면에서 HTML로 열립니다. 문서를 서버에서 렌더링하므로 이 템플릿을 인쇄할 때는 POS가 사이트에 연결되어 있어야 합니다. 오프라인 인쇄에는 기본 제공 HTML 또는 감열 템플릿을 사용하세요.

## 매장별 지정 {#per-store-assignments}

[매장](/1.x/stores)이 여러 개라면(Pro), 각 매장에서 사이트 전체 기본값과 별도로 **자체 템플릿 선택 및 정렬**을 설정할 수 있습니다. 가까운 카페는 다른 로고와 주소가 들어간 소형 감열 영수증을, 창고는 포장 명세서를, 본점은 표준 영수증을 사용할 수 있습니다. 모두 같은 템플릿 갤러리에서 선택할 수 있습니다.

**WP Admin → POS → 매장**으로 이동해 설정할 매장을 여세요. **매장 편집** 페이지의 **영수증 템플릿** 섹션에는 *"매장별 영수증 템플릿"* 토글이 있습니다:

- **토글 끔** *(기본값)* — 매장은 기본 **POS → 템플릿** 페이지의 사이트 전체 템플릿 목록을 상속합니다.
- **토글 켬** — 매장은 사이트 전체 기본값과 별도로 자체 템플릿 선택 및 정렬 설정을 갖습니다. 드래그 핸들로 순서를 바꾸는 방법은 동일합니다.

같은 매장 편집 페이지에서 각 매장의 **레터헤드**도 관리합니다. 여기에는 로고, 주소, 연락처 정보와 *영수증 메시지* 블록(맺음말, 반품 정책, 푸터)이 포함됩니다. 기본 제공 템플릿은 이 매장별 필드를 참조하므로 하나의 "표준 영수증" 템플릿으로도 지점마다 다른 브랜딩을 적용할 수 있습니다.

캐셔가 매장에 로그인하면 영수증 드롭다운에는 해당 매장에서 활성화한 템플릿만 표시됩니다.

:::tip 사이트 전체 설정과 매장별 설정
WP Admin의 **템플릿** 페이지에서 사이트 전체 기본값을 설정합니다. 매장별 재정의를 사용하면 하나의 템플릿(예: 표준 영수증)에 지점마다 다른 브랜딩을 적용하거나 특정 지점에서만 다른 레이아웃을 사용할 수 있습니다. 모든 매장에서 같은 템플릿을 사용하려면 매장별 지정을 비워두세요. 사이트 전체 기본값이 적용됩니다.
:::

## 옵션 2 — AI에게 수정 요청하기 {#option-2--ask-ai-to-tweak-it}

갤러리 템플릿이 원하는 모습에 가깝지만 조금 아쉽다면 AI 어시스턴트가 몇 분 안에 수정해 줄 수 있습니다. HTML을 알 필요도 없습니다.

<Steps>
  <StepCard number="1" title="템플릿 복사">

**WP Admin → POS → 템플릿**에서 수정의 바탕으로 사용할 템플릿을 여세요. 편집기를 클릭하고 왼쪽 텍스트를 모두 선택한 다음(Ctrl/Cmd + A) 복사하세요.

  </StepCard>
  <StepCard number="2" title="ChatGPT 또는 Claude에 붙여넣기">

[ChatGPT](https://chat.openai.com) 또는 [Claude](https://claude.ai)를 엽니다. 템플릿을 붙여넣은 다음, 원하는 내용을 자연스러운 문장으로 작성합니다:

  </StepCard>
  <StepCard number="3" title="변경 사항 설명">

AI에게 원하는 내용을 정확히 알려주세요. 다음과 같이 요청하면 좋습니다:

- *"매장 이름을 더 크게 표시하고 가운데 정렬해 주세요."*
- *"하단에 이탤릭체로 감사 메시지를 추가해 주세요."*
- *"고객 이름을 숨기고, 대신 주문 번호 아래에 전화번호를 추가해 주세요."*
- *"바코드를 제 반품 페이지로 연결되는 QR 코드로 바꿔 주세요."*
- *"매장 이름 아래에 '1987년부터 가족이 운영하는 가게'라는 슬로건을 추가해 주세요."*

AI가 수정된 템플릿을 제공합니다.

  </StepCard>
  <StepCard number="4" title="다시 붙여넣기" isLast>

AI의 응답을 복사하세요. WCPOS 템플릿 편집기로 돌아가 전체 선택(Ctrl/Cmd + A)한 다음 새 버전을 붙여넣고 **업데이트**를 클릭하세요. 오른쪽 미리보기가 새로고침되어 결과를 확인할 수 있습니다. 원하는 모습이 아니라면 어떤 부분이 잘못되었는지 설명하고 AI에게 수정을 요청하세요.

  </StepCard>
</Steps>

:::tip 유용한 팁
갤러리에서 **템플릿 사용**을 클릭할 때마다 편집 가능한 새 사본이 생성되므로 원본은 안전하게 유지됩니다. 여러 방법을 시도할 때는 같은 갤러리 템플릿을 여러 번 사용해도 됩니다. 사본의 이름을 바꾸고 *(영수증 v1, 영수증 v2)* 서로 전환하며 비교해 보세요.
:::

:::info 변수란 무엇인가요?
`{{store.name}}`과 `{{order.number}}` 같은 부분은 실제 데이터가 들어갈 자리를 나타내는 **플레이스홀더**입니다. AI가 이를 이해하므로 직접 알 필요는 없습니다. 사용 가능한 모든 플레이스홀더는 [영수증 데이터 참조](/1.x/receipts/receipt-data)를 확인하세요.
:::

## 옵션 3 — 직접 편집하기 {#option-3--edit-it-by-hand}

HTML을 조금 알고 있거나 개발자와 함께 작업한다면 앱 내 편집기에서 템플릿을 직접 편집할 수 있습니다. 편집기는 실시간 미리보기, 구문 강조, 검색 가능한 필드 선택기, 실행 취소/다시 실행, 찾기 및 바꾸기를 지원합니다.

엔진을 선택하세요:

- **[HTML 템플릿](/1.x/receipts/html-templates)** — Mustache 스타일의 `{{variable}}` 플레이스홀더를 사용합니다. 클라이언트 측에서 렌더링되며 오프라인에서도 작동합니다. **대부분의 매장에 권장됩니다.**
- **[감열 템플릿](/1.x/receipts/thermal-templates)** — ESC/POS 감열 프린터용 XML입니다. 같은 템플릿으로 화면 미리보기와 프린터 출력을 모두 생성합니다.
- **[영수증 데이터 참조](/1.x/receipts/receipt-data)** — 사용할 수 있는 모든 플레이스홀더를 섹션별로 정리한 목록입니다.

:::note 레거시 PHP 템플릿
기존에 테마의 PHP 파일(`yourtheme/woocommerce-pos/receipt.php`)로 영수증을 재정의했다면 그 방식은 계속 작동합니다. 이제 갤러리에서 **레거시 PHP 템플릿**으로 표시되며 새로운 로직 없는 엔진 및 감열 엔진과 함께 제공됩니다. WP Overnight 통합도 외부 문서 API가 서버에서 HTML을 렌더링하기 때문에 서버 렌더링 방식을 사용합니다. 새로 사용자 정의할 때는 갤러리나 앱 내 편집기를 사용하세요. 오프라인에서도 작동하고 실시간 미리보기를 제공하며 서버와 통신할 필요가 없습니다.
:::

## 일반적인 사용자 정의 {#common-customisations}

가장 자주 받는 질문에 대한 간단한 답변입니다.

<Accordion>
  <AccordionItem question="매장 로고를 추가하려면 어떻게 하나요?">

로고는 템플릿 자체가 아니라 매장 설정에서 가져옵니다. **WP Admin > POS > 설정 > 매장**으로 이동하여 매장을 편집하고 로고를 업로드하세요. 로고를 표시하는 모든 기본 제공 템플릿이 자동으로 이 로고를 사용합니다.

템플릿에서 로고가 *표시되는 위치*를 바꾸려면 템플릿을 편집하여 `{{#store.logo}}<img src="{{store.logo}}" ...>{{/store.logo}}` 블록을 원하는 위치로 옮기세요.

  </AccordionItem>

  <AccordionItem question="하단 문구(예: ‘구매해 주셔서 감사합니다!’)를 바꾸려면 어떻게 하나요?">

두 가지 방법이 있습니다:

1. **가장 간단한 방법** — **WP Admin > POS > 설정 > 매장 > 매장 세부 정보 > 영수증 바닥글 / 개인 메모**에서 한 번 설정하면 모든 영수증에 적용됩니다. 기본 제공 템플릿이 자동으로 이 값을 사용합니다. 바닥글을 설정하지 않으면 *"구매해 주셔서 감사합니다!"* 같은 친근한 기본 문구가 표시됩니다.
2. **단일 템플릿에서** — 템플릿을 편집하여 하단 문구를 직접 바꾸세요. `{{store.personal_notes}}` 또는 직접 입력된 감사 문구를 찾으세요.

  </AccordionItem>

  <AccordionItem question="매장 이름 아래에 태그라인이나 슬로건을 추가하려면 어떻게 하나요?">

템플릿을 편집하여 `{{store.name}}` 아래에 한 줄을 추가하세요:

```html
<div style="font-style: italic; color: #6b7280;">Family-owned since 1987</div>
```

감열 템플릿의 경우:

```xml
<align mode="center"><text>Family-owned since 1987</text></align>
```

  </AccordionItem>

  <AccordionItem question="선물 영수증에서 가격을 숨기려면 어떻게 하나요?">

갤러리의 **선물 영수증** 카드에서 **템플릿 사용**을 클릭하세요. 모든 가격과 합계가 숨겨지고 품목, SKU, 속성, 선물 메시지는 그대로 표시됩니다. 편집할 필요가 없습니다.

가격 없는 영수증을 직접 만들려면 원하는 템플릿을 복사하고 `{{...total...}}`, `{{...price...}}`, `{{#totals}}...{{/totals}}` 블록을 삭제하세요.

  </AccordionItem>

  <AccordionItem question="바코드를 QR 코드로 바꾸려면 어떻게 하나요?">

템플릿에서 `<barcode>` 요소를 찾아 `type` 속성을 변경하세요:

```html
<!-- Default: Code 128 barcode of the order number -->
<barcode type="code128">{{order.number}}</barcode>

<!-- Switch to a QR code -->
<barcode type="qrcode">{{order.number}}</barcode>

<!-- Or encode something else, like a returns URL -->
<barcode type="qrcode">https://example.com/returns?order={{order.number}}</barcode>
```

동일한 `<barcode>` 구문은 HTML 및 감열 템플릿 모두에서 사용할 수 있습니다. 지원되는 다른 유형으로는 `ean13`, `ean8`, `upca`, `pdf417`, 그리고 [bwip-js가 지원하는 모든 것](https://github.com/metafloor/bwip-js/wiki/Supported-Barcode-Types).

  </AccordionItem>

  <AccordionItem question="특정 프린터에 다른 템플릿을 전송하려면 어떻게 하나요?">

POS 앱에서 **POS > 설정 > 인쇄**로 이동한 다음 **영수증 템플릿**을 확인하세요. 활성 템플릿마다 옆에 프린터 드롭다운이 표시됩니다. 사용할 프린터를 선택하거나 **자동**으로 두세요.

- **자동**은 템플릿을 프린터에 자동으로 매칭합니다 — 감열 템플릿은 감열 프린터로, HTML 템플릿은 시스템 인쇄 대화 상자로 전송됩니다.
- **특정 프린터**를 지정하면 자동 설정을 무시하고 해당 템플릿을 항상 지정된 프린터로 전송합니다.
- 인쇄 시 캐셔는 영수증 화면의 프린터 드롭다운을 사용하여 위 설정을 재정의할 수 있습니다.

라우팅은 기기별로 저장되므로 각 iPad 또는 컴퓨터마다 별도로 설정할 수 있습니다.

  </AccordionItem>

  <AccordionItem question="편집 후에도 영수증에 이전 버전이 표시됩니다">

템플릿 편집 화면에서 WordPress **업데이트** 버튼을 클릭합니다. 편집기는 자동 저장되지 않으므로 업데이트를 클릭해야만 변경 사항이 저장됩니다.

**레거시 PHP 템플릿**의 경우, 편집기의 미리 보기는 현재 입력 중인 내용이 아닌 *마지막으로 저장된* 버전을 표시합니다. 먼저 저장한 후 미리 보기를 새로고침하세요.

  </AccordionItem>

  <AccordionItem question="미리보기가 비어 있거나 'POS 주문을 찾을 수 없음'이 표시됩니다">

이 현상은 미리보기에 실제 주문이 필요한 **레거시 PHP 템플릿**에서만 발생합니다. POS 주문을 하나만 처리하면(테스트용 $0 판매도 가능) 미리보기가 정상적으로 작동합니다.

로직리스(HTML) 및 감열식 템플릿은 항상 대체용 샘플 데이터가 있으므로, 새로 만든 매장에서도 미리보기가 정상적으로 표시됩니다.

  </AccordionItem>

  <AccordionItem question="엉망이 되었습니다 — 처음부터 다시 시작하려면 어떻게 하나요?">

세 가지 안전장치:

1. 편집기에는 현재 세션의 변경 사항을 되돌리는 **실행 취소**(Ctrl/Cmd + Z) 기능이 있습니다.
2. 저장할 때마다 WordPress **리비전**이 생성됩니다. 편집 화면에서 **리비전**을 열면 이전 버전과 비교하고 복원할 수 있습니다.
3. 갤러리 템플릿에서 시작한 경우, *내 템플릿*에서 해당 사본의 **삭제**를 클릭한 다음, 같은 갤러리 카드에서 **템플릿 사용**을 다시 클릭하면 수정되지 않은 새 사본을 받을 수 있습니다.

  </AccordionItem>
</Accordion>

## 도움을 요청해야 할 때 {#when-to-ask-for-help}

- 템플릿 편집기가 로드되지 않거나, 저장한 내용이 유지되지 않는 경우.
- 한 기기에서는 영수증이 정상 출력되지만 다른 기기에서는 그렇지 않은 경우.
- 특정 국가(이탈리아, 브라질, 스페인 등)의 세금/법률 요건에 맞는 레이아웃이 필요한 경우 — 일반적으로 [WCPOS Pro](/1.x/getting-started/pro-license) 또는 국가별 통합 기능으로 처리합니다.
- 커스텀 작업을 시도하고 있지만 AI로 원하는 결과를 얻기 어려운 경우.

[지원 티켓](https://wcpos.com/support)을 열고 작업 중인 템플릿을 붙여넣으면, 도움에 필요한 모든 정보를 확인할 수 있습니다.
