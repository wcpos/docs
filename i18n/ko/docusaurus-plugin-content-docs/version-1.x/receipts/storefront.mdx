WCPOS 영수증 템플릿은 계산대에서만 사용할 수 있는 것이 아닙니다. 온라인 스토어 고객은 내 계정 또는 주문 확인 페이지에서 주문 영수증이나 청구서를 보고 다운로드할 수 있으며, **WP Admin → POS → 템플릿**에서 만든 맞춤 템플릿으로 렌더링됩니다.

:::info 버전 안내
웹사이트 영수증 액세스 기능인 **내 계정** 버튼과 `[wcpos_receipt]` 단축 코드는 WCPOS **1.9.11**에 포함되었습니다. 아래에서 설명하는 **고객 영수증 다운로드 허용** 설정과 **고객용 영수증 템플릿** 선택기는 **1.9.12**에 추가되었습니다. 1.9.11에서는 버튼이 기본적으로 켜져 있으며 제어 설정이 없습니다. 이전 버전에서는 POS 내부에서만 영수증을 표시합니다.
:::

:::note 이 페이지는 고객이 자신의 영수증을 다운로드하는 방법을 설명합니다
캐셔와 직원은 이 기능을 사용할 필요가 없습니다. POS의 **주문** 화면에는 온라인 주문을 포함한 모든 WooCommerce 주문이 이미 표시되며, 점 3개 메뉴에서 영수증을 [확인, 인쇄하거나 이메일로 보낼 수 있습니다](/orders#receipt-reprinting). 이 페이지에서는 반대로 **고객**이 웹사이트에서 직접 영수증을 다운로드하는 방법을 다룹니다.
:::

## 내 계정 다운로드 버튼 {#my-account}

**영수증** 버튼은 기본적으로 **꺼져 있습니다**. **POS > 설정 > 일반**의 **고객** 섹션에서 **고객 영수증 다운로드 허용**을 켜세요. 활성화되면 로그인한 고객은 **내 계정 → 주문**에서 대상 주문 옆에 **영수증** 버튼을 볼 수 있으며, 버튼을 클릭하면 영수증 템플릿으로 렌더링된 PDF(`receipt-1234.pdf`)가 다운로드됩니다.

이 버튼은 주문 대금이 결제된 상태인 **처리 중**, **완료됨**, **환불됨** 주문에 표시됩니다. 보류 중, 취소됨, 실패한 주문에는 표시되지 않습니다. (개발자는 [표시할 상태를 변경할 수 있습니다](#developers).)

**활성** 영수증 템플릿도 필요합니다. 활성 템플릿이 없으면 렌더링할 것이 없으므로 설정을 켜도 버튼은 숨겨져 있습니다.

:::note 단축 코드는 별도입니다
아래의 [`[wcpos_receipt]` 단축 코드](#shortcode)는 이 설정과 관계없이 작동합니다. 이 토글은 자동 **내 계정** 버튼만 제어합니다.
:::

## `[wcpos_receipt]` 쇼트코드 {#shortcode}

주문 확인("감사합니다") 페이지 또는 **내 계정 → 주문 보기** 페이지에 영수증 링크를 추가하려면 다음을 사용하세요:

```text
[wcpos_receipt]
```

속성이 없으면 쇼트코드는 두 페이지에서 현재 주문을 자동으로 감지하고 *영수증 다운로드 (PDF)* 링크를 표시합니다. 다른 페이지에서는 아무것도 출력하지 않습니다. 명시적으로 지정한 `order_id` 값은 해당 주문을 소유한 로그인 고객에게만 작동합니다.

### 속성 {#shortcode-attributes}

| 속성 | 기본값 | 기능 |
|---|---|---|
| `order_id` | *(자동 감지됨)* | 특정 주문으로 연결합니다. 해당 주문을 소유한 로그인 고객에게만 작동합니다. |
| `link_text` | `Download receipt (PDF)` | 링크 텍스트입니다. |
| `format` | `pdf` | `pdf` 형식은 PDF를 다운로드하고, `html` 형식은 대신 인쇄 가능한 영수증 보기를 엽니다. |
| `template` | *(스토어프런트 기본값)* | 스토어프런트 기본값 대신 특정 템플릿 ID로 렌더링합니다. |
| `class` | `wcpos-receipt-link` | 링크의 CSS 클래스입니다. |
| `id` | *(없음)* | 링크의 HTML `id`. |

### 예시 {#shortcode-examples}

주문 확인 페이지의 다운로드 링크:

```text
[wcpos_receipt link_text="Download your invoice"]
```

PDF 대신 화면에 표시되는(인쇄 가능한) 영수증 링크:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

특정 템플릿으로 렌더링합니다. 예를 들어 80mm 계산대 영수증 대신 A4 청구서 템플릿을 사용할 수 있습니다:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

템플릿 ID는 **WP Admin → POS → 템플릿**에서 템플릿 편집 화면 URL의 숫자(`post=123`)입니다.

## 고객에게 제공되는 템플릿은 무엇인가요? {#template-choice}

토글 바로 아래의 **고객용 영수증 템플릿**에서 다운로드에 사용할 템플릿을 선택합니다. 기본값은 **활성 영수증 템플릿 사용**이므로 고객에게 POS에서 사용하는 것과 같은 템플릿이 제공됩니다. 활성 템플릿을 변경하면 고객 영수증도 자동으로 변경됩니다.

온라인 주문에 다른 디자인을 사용하려면 드롭다운에서 특정 템플릿을 선택하세요. 그러면 고객 다운로드에는 캐셔가 POS 드롭다운에서 선택한 템플릿과 관계없이 해당 템플릿이 항상 사용됩니다. 고객 템플릿이 좁은 감열지 영수증인 경우 PDF도 좁게 출력됩니다. 온라인 주문에는 전체 페이지 문서가 더 적합할 수 있으며, 갤러리의 **송장** 템플릿은 A4/Letter 용지용으로 설계되었습니다.

:::tip 페이지별 재정의
이 설정은 **내 계정** 버튼을 제어합니다. 특정 페이지의 일회성 링크에는 단축 코드의 [`template` 속성](#shortcode-attributes)으로 템플릿을 계속 재정의할 수 있으며, 아래의 [개발자 필터](#developers)를 사용하면 버튼을 포함해 사이트 전체 템플릿을 변경할 수 있습니다.
:::

템플릿은 POS와 동일한 [영수증 데이터 페이로드](/receipts/receipt-data)로 렌더링되므로 로고, 매장 정보, 세금 설정, 사용자 지정 항목이 모두 적용됩니다.

## 보안 {#security}

영수증 링크에는 주문의 고유 키가 포함됩니다. 이는 WooCommerce에서 주문 확인 페이지에 사용하는 것과 동일한 방식이므로, 계정 없이 결제한 게스트도 확인 페이지의 링크를 계속 사용할 수 있습니다. 링크가 없는 사용자는 주문 고객으로 로그인해야 합니다. 명시적인 `order_id` 쇼트코드는 해당 주문의 로그인한 소유자에게만 표시됩니다.

:::note 고유주소 설정 필요
모든 WCPOS 결제 페이지와 마찬가지로 영수증 URL은 WordPress 다시 쓰기 규칙을 사용합니다. **기본** 고유주소(설정 → 고유주소)를 사용하는 사이트는 다른 고유주소 구조로 변경해야 합니다.
:::

## 개발자용 {#developers}

웹사이트에 표시되는 영역은 세 가지 필터로 제어됩니다. 위 설정에 추가로 적용되며, 설정만으로 표현할 수 없는 조건부 로직(주문별, 고객별 등)에 유용합니다:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// The filter's default value is the "Let customers download receipts" setting,
// so you only need this to override it — e.g. show the button for one user role.
add_filter( 'woocommerce_pos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'woocommerce_pos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the
// "Receipt template for customers" setting. Receives and returns the full
// template array (null when none is configured).
add_filter( 'woocommerce_pos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

PDF 경로는 `/wcpos-checkout/wcpos-receipt/{order_id}?key={order_key}&format=pdf` 경로입니다. 이는 POS에서 영수증에 사용하는 것과 동일한 주문 키 제한 엔드포인트이며, `format=pdf` 형식은 화면 보기 대신 렌더링된 PDF를 반환합니다.
