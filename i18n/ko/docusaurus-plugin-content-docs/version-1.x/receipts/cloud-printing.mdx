클라우드 인쇄를 사용하면 WCPOS가 계산대를 실행하는 장치에 직접 연결되지 않은 프린터로 영수증을 전송할 수 있습니다. WP Admin에서 한 번만 설정하면, 각 장치가 하드웨어를 직접 검색하고 페어링할 필요 없이 주문이 주방 프린터, 백오피스 프린터 또는 다른 방의 프린터로 인쇄됩니다.

## 클라우드 인쇄란? {#what-is-cloud-printing}

**로컬 인쇄**에서는 POS를 실행하는 장치가 USB, 블루투스 또는 로컬 네트워크를 통해 프린터와 직접 통신합니다. 프린터가 계산대 옆에 있을 때 적합한 방식입니다 — 동일한 장치에서 USB, 블루투스, 네트워크 프린터를 연결하는 방법은 [프린터 설정](/hardware/printers)을 참조하세요.

**클라우드 인쇄**는 그 외의 모든 경우를 위한 것입니다: 다른 위치에 있거나, 다른 네트워크에 있거나, 각 장치마다 따로 설정하지 않고 모든 장치가 공유하기를 원하는 프린터입니다. 전달 방식은 두 가지가 있습니다:

- **폴링 프린터.** 프린터가 일정에 따라 인터넷을 통해 WCPOS에 접속하여 "전송할 작업이 있나요?"라고 물어보고 대기 중인 작업을 가져옵니다. WCPOS는 프린터에 연결하지 않으며, 항상 프린터가 먼저 통신을 시작합니다. **Star CloudPRNT**와 **Epson Server Direct Print**가 이 방식으로 작동합니다.
- **호스팅 릴레이 제공업체.** WCPOS가 호스팅 서비스에 인쇄 작업을 제출하면, 해당 서비스가 프린터로 전달합니다. **Star Online**과 **PrintNode**가 이 방식으로 작동합니다. Star Online은 stario.online 계정에 등록된 Star CloudPRNT 프린터로 전달하고, PrintNode는 데스크톱 클라이언트를 통해 해당 컴퓨터가 이미 인쇄할 수 있는 거의 모든 프린터로 전달합니다.

:::info 왜 폴링 방식 프린터인가?
폴링 프린터는 열린 포트, 고정 IP 또는 방화벽 변경이 필요 없으며, 오직 아웃바운드 요청만 보냅니다. 따라서 원격 사이트에 있거나 제어할 수 없는 라우터 뒤에 있는 프린터에 이상적입니다. 단점은 약간의 지연입니다: 프린터는 다음 폴링이 돌아올 때만 인쇄합니다.
:::

## WCPOS Cloud Print — 릴레이 {#relay}

**폴링** 프린터(Star CloudPRNT 또는 Epson Server Direct Print)를 설정하면 WCPOS가 알려주는 폴 URL은 내 사이트가 아니라 **cloudprint.wcpos.com**을 가리킵니다. 이것이 **WCPOS Cloud Print**로, WCPOS가 운영하는 무료 릴레이이며 프린터와 스토어 사이에 위치합니다.

**존재 이유.** 영수증 프린터는 거의 업데이트되지 않는 소형 펌웨어로 동작합니다. 최신 TLS 버전, 최신 인증 기관, 사이트 앞단의 CDN/방화벽(Cloudflare가 대표적입니다) 때문에 많은 프린터가 최신 호스팅의 스토어와 보안 연결을 맺지 못합니다. 프린터가 거부되거나 프린터가 거부하는 것입니다. 증상은 모든 설정이 올바른데도 프린터가 **Waiting** 상태에서 계속 멈춰 있는 것입니다. 릴레이는 오래된 펌웨어도 항상 협상할 수 있는 연결을 프린터에 제공하고, 그 트래픽을 스토어로 전달합니다.

**작동 방식:**

- 클라우드 인쇄 설정을 처음 여는 순간 사이트가 릴레이에 **자동으로** 연결됩니다 — 활성화하거나 구성할 것이 없습니다.
- 프린터는 `cloudprint.wcpos.com`을 폴링하고, 릴레이가 요청을 스토어로 전달한 뒤 스토어의 응답을 반환합니다. 인쇄 작업은 릴레이를 **통과**할 뿐 릴레이에 저장되지 않습니다.
- 릴레이가 대부분의 유휴 폴링을 흡수하므로, 유휴 상태의 프린터는 몇 초마다 한 번이 아니라 분당 약 한 번의 요청만 사이트에 발생시킵니다.
- 사이트가 릴레이에 연결할 수 없는 경우(예: 릴레이가 접근할 수 없는 로컬 개발 사이트) WCPOS는 자동으로 사이트 직접 연결 URL로 대체합니다.

:::note 직접 연결을 선호하시나요?
모든 프린터의 설정 화면에는 사이트 직접 연결 URL을 보여주는 **고급** 항목이 있습니다. 호스팅이 프린터와 잘 호환된다는 것을 알고 있거나, 작업을 릴레이를 거쳐 보내고 싶지 않다면 이를 사용하세요. 개발자는 한 줄로 사이트 전체에서 릴레이를 끌 수 있습니다:

```php
add_filter( 'woocommerce_pos_cloud_print_relay_enabled', '__return_false' );
```
:::

**릴레이가 볼 수 있는 것.** 연결하면 사이트 URL이 wcpos.com과 공유되며, 인쇄 작업(주문 정보를 포함하는 영수증 내용)이 프린터로 가는 도중 릴레이를 경유합니다. 어떤 것도 보관되지 않습니다. 자세한 내용은 [개인정보처리방침](https://wcpos.com/privacy)에 있습니다.

## 클라우드 프린터 설정 {#setup}

클라우드 프린터는 WP Admin에서 한 번 설정하면 모든 기기에서 공유됩니다. 기기별로 저장되는 로컬 프린터와 다릅니다.

**WP Admin > POS > 설정 > 클라우드 인쇄**로 이동해 **Add printer**를 클릭하세요. **이름**(예: "주방" 또는 "백오피스")을 지정하세요. WCPOS는 프린터에서 변경되지 않는 **프린터 ID**를 자동으로 생성하므로 프린터 펌웨어 설정에서 참조해도 안전합니다.

프린터를 추가한 후 제공업체 쪽을 설정하세요.

### Star 또는 Epson(폴링 프린터) {#setup-polling}

<Steps>
  <StepCard number="1" title="WCPOS에서 프린터 추가">

**WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터를 추가하고 제공업체로 **Star CloudPRNT** 또는 **Epson Server Direct Print**를 선택하세요. WCPOS는 해당 프린터의 **폴 URL**과 **일회용 토큰**을 생성합니다.

  </StepCard>
  <StepCard number="2" title="폴 URL과 토큰 복사">

생성된 폴 URL과 토큰을 복사하세요. URL은 보통 **cloudprint.wcpos.com**을 가리키며, 이것이 사용해야 할 [WCPOS Cloud Print 릴레이](#relay)입니다. 사이트 직접 연결 URL은 **Advanced**를 펼치면 볼 수 있습니다. **토큰은 한 번만 표시됩니다**. 잃어버린 경우 프린터 카드에서 새 토큰을 생성하고 프린터의 토큰을 새 값으로 업데이트하세요.

  </StepCard>
  <StepCard number="3" title="프린터 설정에 입력하세요." isLast>

프린터 설정 페이지를 여세요. Star에서는 **CloudPRNT** 설정을, Epson에서는 **Server Direct Print** 설정을 열고 폴 URL과 토큰을 붙여 넣으세요. 프린터에서 폴링 간격을 요청하면 설정하세요(보통 몇 초). 필요한 경우 저장하고 프린터를 재부팅하세요.

폴링 주기 내에 프린터가 연결되며 WCPOS에서 상태가 **Waiting**에서 **Connected**로 바뀝니다.

  </StepCard>
</Steps>

### PrintNode {#setup-printnode}

<Steps>
  <StepCard number="1" title="PrintNode 데스크톱 클라이언트 설치">

대상 프린터로 이미 인쇄할 수 있는 컴퓨터에 **PrintNode 클라이언트**를 설치하고 로그인하세요. 작업을 인쇄하려면 클라이언트를 계속 실행하고 온라인 상태로 유지해야 합니다.

  </StepCard>
  <StepCard number="2" title="PrintNode API 키 받기">

PrintNode 계정에서 **API 키**를 만드세요. 이 키를 사용해 WCPOS가 PrintNode 계정으로 작업을 제출합니다.

  </StepCard>
  <StepCard number="3" title="WCPOS에 API 키 입력">

**WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터를 추가하고 제공업체로 **PrintNode**를 선택한 다음 API 키를 붙여 넣으세요. WCPOS는 이 키를 사용해 PrintNode 계정에 등록된 프린터 목록을 가져옵니다.

  </StepCard>
  <StepCard number="4" title="프린터 선택" isLast>

PrintNode 클라이언트가 보고한 프린터 목록에서 대상 프린터를 선택하고 저장하세요. WCPOS가 해당 프린터의 작업을 PrintNode에 제출하면 클라이언트가 인쇄합니다.

  </StepCard>
</Steps>

### Star Online {#setup-star-online}

Star 프린터가 이미 **stario.online** 계정에 등록되어 있고 Star 호스팅 서비스에서 작업 전달을 처리하도록 하려면 Star Online을 사용하세요.

<Steps>
  <StepCard number="1" title="CloudPRNT URL 받기">

stario.online에서 **Device Groups**를 열고 그룹의 **CloudPRNT URL**을 복사하세요. URL은 `https://device.stario.online/cloudprnt/...` 또는 `https://eu-device.stario.online/cloudprnt/...` 형식이어야 합니다.

  </StepCard>
  <StepCard number="2" title="권한이 있는 API 키 만들기">

stario.online에서 WCPOS용 API 키를 만드세요. 키에는 기기 목록 조회 및 인쇄 권한이 있어야 합니다. 최소한 다음 권한을 활성화하세요:

- **EnumDevices** — WCPOS가 기기 목록을 가져올 때 필요
- **ViewDevice** — 기기 상태 확인에 사용
- **PrintToDevice** — 인쇄 작업 제출에 필요
- **ViewDeviceGroups** — 그룹 조회 및 진단에 권장

API 키가 있어도 이 권한이 활성화되어 있지 않으면 작동하지 않을 수 있습니다.

  </StepCard>
  <StepCard number="3" title="WCPOS에 URL과 API 키 입력">

**WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터를 추가하고 제공업체로 **Star Online**을 선택한 다음 CloudPRNT URL과 API 키를 붙여 넣으세요. **내 기기 가져오기**를 클릭하세요.

  </StepCard>
  <StepCard number="4" title="Star 기기 선택" isLast>

기기 목록에서 프린터를 선택하고 저장하세요. WCPOS는 API 키를 서버에 저장하고, 작업을 Star Online에 제출할 때 선택한 기기의 액세스 식별자를 사용합니다.

  </StepCard>
</Steps>

## 자동 인쇄 규칙 {#auto-print}

자동 인쇄 규칙은 일반 문장으로 작성하며 무엇을 어디에 자동 인쇄할지 결정합니다. 규칙은 **범위 × 프린터 × 템플릿**에 실행 시점과 인쇄 매수를 더한 것입니다. 예를 들면 다음과 같습니다:

> 결제 완료 시 **모든 주문**을 **주방** 프린터로 **주방 티켓** 템플릿을 사용해 **×2**로 인쇄합니다.

규칙은 **주문 생성 시** 또는 **결제 완료 후에만** 실행되도록 설정할 수 있습니다. 따라서 주문이 접수되는 즉시 주방 티켓을 출력하고 고객 영수증은 결제를 기다리게 할 수 있습니다. 여러 장이 필요한 작업대에서는 **인쇄 매수**도 설정할 수 있습니다. 일치하는 주문이 선택한 시점에 도달하면 WCPOS가 선택된 **템플릿**을 서버에서 프린터에 필요한 형식으로 렌더링하고 대기열에 추가하므로 캐셔가 별도로 할 일은 없습니다.

:::note 템플릿 호환성이 중요합니다
Star 및 Epson 프린터는 **감열** 템플릿만 사용할 수 있습니다. 작업이 프린터의 네이티브 명령 언어(Star의 경우 Star Document Markup 또는 ESC/POS, Epson의 경우 ePOS-Print)로 렌더링되어야 하기 때문입니다. PrintNode는 작업이 **PDF**로 렌더링되므로 **모든** 템플릿(감열 또는 전체 페이지 HTML)을 사용할 수 있습니다. 템플릿이 특정 프린터의 옵션으로 나타나지 않는다면, 이는 프린터가 해당 형식을 렌더링할 수 없기 때문입니다. 감열 레이아웃 생성은 [감열 템플릿](/receipts/thermal-templates)을 참조하세요.
:::

매장별 인쇄 라우팅에는 [WCPOS Pro](/getting-started/pro-license)와 [다중 매장](/stores) 설정이 필요합니다.
:::

기본적으로 자동 인쇄 규칙은 전역적이며, 모든 매장이 이를 공유합니다. Pro에서는 개별 매장에 **자체** 클라우드 인쇄 규칙을 부여하여 해당 매장의 주문이 자체 프린터로 인쇄되도록 할 수 있습니다(한 위치의 주방 티켓이 다른 위치에서 인쇄되어서는 안 됩니다).

**POS → Stores**에서 매장을 편집하고 **Cloud Printing** 섹션을 열어 **Add rule**을 클릭하세요. 각 규칙은 다음과 같습니다:

- **프린터 ID** — 전송할 클라우드 프린터의 안정적인 ID
- **범위** — **POS 주문만**(기본값), **온라인 주문만** 또는 **모든 주문**
- **형식** — **StarPRNT**(기본값), **ESC/POS**, **Epson ePOS-Print** 또는 **HTML**

주문이 자체 규칙이 있는 매장에 속하면 WCPOS는 이를 해당 매장의 프린터로 라우팅합니다. 매장에 자체 규칙이 **없으면** **전역** 자동 인쇄 규칙으로 **폴백**합니다 — 따라서 다른 설정이 필요한 매장만 구성하면 됩니다.

## 수동 인쇄 {#manual}

자동 인쇄 규칙을 기다릴 필요가 없습니다. **결제/영수증 화면**에서 캐셔는 필요에 따라 클라우드 프린터로 영수증을 전송할 수 있습니다 — 재인쇄하거나 일회성 티켓을 특정 프린터로 라우팅할 때 유용합니다.

영수증이 생성되는 방식은 프린터에 따라 다릅니다:

- **Star CloudPRNT** — 영수증이 **장치에서** 렌더링되어 CloudPRNT를 통해 프린터로 전달됩니다.
- **Star Online, Epson, PrintNode** — 영수증이 선택한 주문과 템플릿으로부터 **서버에서** 렌더링된 후 프린터 또는 호스팅 릴레이로 전달됩니다.

:::note 까다로운 프린터의 렌더링 대체 방법
**Star CloudPRNT**는 프린터와 미디어 유형을 협상하며 프린터가 더 풍부한 형식을 지원하지 않으면 일반 텍스트(`text/plain`)로 대체합니다. 펌웨어가 StarPRNT 명령을 해석하지 못하는 Star 프린터의 경우 WCPOS가 영수증을 **서버에서 PNG 이미지로** 렌더링해 전송할 수 있습니다. 그러면 인쇄 실패 대신 영수증이 인쇄됩니다.
:::

## 인쇄 대기열 {#print-queue}

클라우드 프린터로 보낸 모든 작업은 프린터가 이를 수거하거나(폴링 프린터) 제공업체가 전달을 확인할 때까지 사이트의 대기열에 머무릅니다. **WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터 아래에 대기열이 표시됩니다:

- 프린터별 또는 상태별(**Waiting**, **Printing**, **Printed**, **Failed**, **Cancelled**)로 **필터링**할 수 있으며, 개수가 실시간으로 표시됩니다.
- 각 행에는 영수증이 얼마나 오래 **대기**했는지가 표시되고, 인쇄 대상 WooCommerce **주문**으로 연결됩니다.
- 대기 중인 작업은 하나씩, 일괄로, 또는 프린터 단위로 **취소**할 수 있습니다. 실패한 작업은 **재시도**로 다시 대기열에 넣습니다.

프린터에 대기 중인 작업이 있는데 몇 분 넘게 아무것도 수거하지 않았다면, **경고 배너**가 해당 프린터 이름과 밀린 영수증 수, 지연 시간을 표시하고 **모두 취소** 옵션을 제공합니다. 프린터가 뽑혀 있는 동안 대기 물량이 조용히 쌓이는 일은 없습니다.

## 테스트 인쇄 및 연결 상태 {#status}

각 프린터 카드에는 **Test print** 버튼이 있어 짧은 진단 작업을 전송하므로, 실제 주문에 사용하기 전에 프린터에 도달할 수 있는지와 형식이 올바른지 확인할 수 있습니다.

또한 카드에는 실시간 상태가 표시됩니다:

| 제공업체 | 상태 | 의미 |
|----------|--------|---------|
| **Star CloudPRNT / Epson** | **Waiting** | 프린터가 아직 체크인하지 않았습니다 — WCPOS가 첫 폴링을 기다리고 있습니다. |
| **Star CloudPRNT / Epson** | **Connected** | 프린터가 최근에 WCPOS를 폴링했으며 작업을 수집하고 있습니다. |
| **Star Online** | **Online** | Star Online이 선택한 장치가 사용 가능하다고 보고합니다. |
| **Star Online** | **Offline** | Star Online이 선택한 장치가 사용 불가능하다고 보고합니다. |
| **Star Online** | **Unknown** | WCPOS가 Star Online에서 장치 상태를 확인할 수 없었습니다. |
| **PrintNode** | **Online** | PrintNode 서비스가 클라이언트와 프린터가 사용 가능하다고 보고합니다. |
| **PrintNode** | **Offline** | PrintNode가 클라이언트 또는 프린터를 사용할 수 없다고 보고합니다. |

## 문제 해결 {#troubleshooting}

<Accordion>
  <AccordionItem question="프린터가 Waiting 상태에 멈춤">

  **Waiting** 상태를 벗어나지 못하는 폴링 프린터는 WCPOS에 한 번도 성공적으로 도달하지 못한 것입니다. 다음을 확인하세요:

  - 프린터 펌웨어의 **폴 URL과 토큰**이 WCPOS가 생성한 것과 정확히 일치하는지. 문자 하나만 틀려도 모든 폴링이 거부됩니다 — 확실하지 않으면 WCPOS에서 토큰을 재생성하고 다시 입력하세요.
  - 프린터가 인터넷을 통해 실제로 **사이트에 도달**할 수 있는지(올바른 DNS, 아웃바운드 HTTPS를 차단하는 방화벽 없음, 스토어의 유효한 SSL 인증서).
  - 프린터의 CloudPRNT / Server Direct Print 구성에서 **폴링이 활성화**되어 있고 적절한 간격으로 설정되어 있는지. 설정을 변경한 후에는 프린터를 재부팅하세요.
  - (고급 항목의) **사이트 직접 연결 URL**을 입력했는데도 프린터가 연결되지 않는다면 표준 **cloudprint.wcpos.com** URL로 전환하세요. 많은 프린터가 최신 호스팅과 보안 연결을 협상하지 못하며, [릴레이가 바로 이 문제를 해결합니다](#relay).

  </AccordionItem>

  <AccordionItem question="프린터 URL이 cloudprint.wcpos.com을 가리키는 이유는 무엇인가요?">

  이것이 [WCPOS Cloud Print](#relay)입니다. 프린터 펌웨어가 항상 협상할 수 있는 연결을 제공하고 인쇄 작업을 스토어로 전달하는 무료 릴레이입니다. 자동으로 켜져 있고, 작업은 릴레이에 저장되지 않으며, 원한다면 프린터의 **고급** 항목에서 사이트 직접 연결 URL을 언제든 사용할 수 있습니다.

  </AccordionItem>

  <AccordionItem question="릴레이가 생기기 전에 프린터를 설정했습니다 — 무언가 변경해야 하나요?">

  아니요 — 프린터 구성에 이미 저장된 URL은 계속 작동합니다. 다만 그 프린터가 **Waiting 상태에 멈춰** 있다면, 해당 펌웨어가 호스팅에 직접 연결할 수 없는 종류일 가능성이 높습니다. 프린터 카드에서 **설정 &amp; 토큰**을 열어 토큰을 재생성한 뒤, 새 **cloudprint.wcpos.com** URL과 토큰을 프린터 구성에 입력하세요.

  </AccordionItem>

  <AccordionItem question="Star Online에서 API 키가 권한이 없거나 금지되었다고 표시됨">

  Star Online은 **인증**과 **권한**을 구분합니다:

  - **401 / 인증 실패**는 API 키 자체가 수락되지 않았음을 의미합니다. 키가 올바르게 복사되었는지, 취소되지 않았는지, 예상한 Star Online 계정/지역에 속하는지 확인하세요.
  - **403 / 금지**는 API 키는 수락되었지만 요청한 작업에 대한 권한이 없음을 의미합니다. stario.online에서 키를 편집하고 필요한 권한, 특히 **Fetch my devices**를 위한 **EnumDevices**와 인쇄를 위한 **PrintToDevice**를 활성화하세요.

  **Fetch my devices**는 성공하지만 프린터가 나타나지 않으면 stario.online의 **Device Groups** 페이지를 확인하세요. 그룹에는 연결된 장치가 하나 이상 있어야 하며, WCPOS의 CloudPRNT URL이 동일한 그룹을 가리켜야 합니다.

  </AccordionItem>

  <AccordionItem question="PrintNode 작업이 인쇄되지 않음">

  작업이 PrintNode에 도달했지만 프린터에서 출력되지 않았습니다. 다음을 확인하세요:

  - 프린터에 연결된 컴퓨터에서 **PrintNode 데스크톱 클라이언트가 실행 중이고 온라인 상태**인지. 컴퓨터가 절전 모드이거나 클라이언트가 닫혀 있으면 아무것도 인쇄되지 않습니다.
  - WCPOS에서 **올바른 프린터**를 선택했는지 — 이름이 클라이언트가 보고하는 프린터와 일치해야 합니다.
  - **API 키가 유효**하고 취소되지 않았는지. PrintNode가 프린터를 Offline으로 표시하면 다시 입력하세요.

  </AccordionItem>

  <AccordionItem question="Star 또는 Epson 프린터에서 내 템플릿을 선택할 수 없음">

  Star 및 Epson 클라우드 프린터에서는 **감열** 템플릿만 작동합니다. 영수증이 ESC/POS 또는 ePOS-Print 명령으로 렌더링되어야 하기 때문입니다. HTML 및 전체 페이지 템플릿은 이러한 형식으로 표현할 수 없으므로 이 프린터에서는 숨겨집니다.

  [감열 템플릿](/receipts/thermal-templates)을 선택하거나 **PrintNode** 프린터를 사용하세요 — PrintNode는 PDF로 렌더링하므로 모든 템플릿을 인쇄할 수 있습니다.

  </AccordionItem>
</Accordion>
