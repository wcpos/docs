클라우드 인쇄를 사용하면 WCPOS가 POS 실행 기기에 직접 연결되지 않은 프린터로 영수증을 전송할 수 있습니다. WP Admin에서 한 번만 설정하면 각 기기에서 하드웨어를 검색하고 페어링할 필요 없이 주방, 사무실 또는 다른 방에 있는 프린터로 주문을 인쇄할 수 있습니다.

## 클라우드 인쇄란? {#what-is-cloud-printing}

**로컬 인쇄**에서는 POS를 실행하는 기기가 USB, Bluetooth 또는 로컬 네트워크를 통해 프린터와 직접 통신합니다. 프린터가 계산대 옆에 있을 때 적합한 방식입니다. 동일한 기기에 USB, Bluetooth 및 네트워크 프린터를 연결하는 방법은 [프린터 설정](/1.x/hardware/printers)을 참조하세요.

**클라우드 인쇄**는 그 밖의 경우에 사용합니다. 다른 장소나 네트워크에 있는 프린터, 또는 기기마다 따로 설정하지 않고 모든 기기에서 공유하려는 프린터에 적합합니다. 작업 전달 방식은 두 가지입니다:

- **폴링 프린터.** 프린터가 일정한 간격으로 인터넷을 통해 WCPOS에 접속하여 인쇄할 작업이 있는지 확인하고 대기 중인 작업을 가져옵니다. WCPOS가 프린터에 연결하는 것이 아니라 항상 프린터가 먼저 통신을 시작합니다. **Star CloudPRNT**와 **Epson Server Direct Print**가 이 방식으로 작동합니다.
- **호스팅 릴레이 제공업체.** WCPOS가 호스팅 서비스에 인쇄 작업을 제출하면 해당 서비스가 프린터로 전달합니다. **Star Online**과 **PrintNode**가 이 방식으로 작동합니다. Star Online은 stario.online 계정에 등록된 Star CloudPRNT 프린터로 작업을 전달합니다. PrintNode는 데스크톱 클라이언트를 통해 해당 컴퓨터에서 이미 인쇄할 수 있는 거의 모든 프린터로 작업을 전달합니다.

:::info 폴링 프린터를 사용하는 이유는 무엇인가요?
폴링 프린터는 외부로 요청만 보내므로 포트를 열거나 고정 IP를 사용하거나 방화벽 설정을 변경할 필요가 없습니다. 따라서 원격 장소에 있거나 직접 관리할 수 없는 라우터 뒤에 있는 프린터에 적합합니다. 다만 다음 폴링 시점이 되어야 인쇄하므로 약간의 지연이 발생합니다.
:::

## WCPOS Cloud Print — 릴레이 {#relay}

**폴링** 프린터(Star CloudPRNT 또는 Epson Server Direct Print)를 설정하면 WCPOS가 제공하는 폴 URL은 매장 사이트가 아닌 **cloudprint.wcpos.com**을 가리킵니다. 이것이 **WCPOS Cloud Print**입니다. WCPOS가 운영하는 무료 릴레이로, 프린터와 매장 사이에서 통신을 중계합니다.

**필요한 이유.** 영수증 프린터는 소형 펌웨어로 작동하며 업데이트도 드뭅니다. 이 때문에 많은 프린터가 최신 호스팅 환경의 매장 사이트와 보안 연결을 맺지 못합니다. 최신 TLS 버전이나 인증 기관, 사이트 앞단의 CDN/방화벽(대표적으로 Cloudflare) 때문에 프린터의 연결이 거부되거나 프린터 쪽에서 연결을 거부할 수 있습니다. 그러면 모든 설정이 올바른데도 프린터가 계속 **대기 중** 상태에 머무릅니다. 릴레이는 오래된 펌웨어도 연결을 맺을 수 있는 접속 방식을 제공하고 프린터의 통신을 매장 사이트로 전달합니다.

**작동 방식:**

- 클라우드 인쇄 설정을 처음 열면 사이트가 릴레이에 **자동으로** 연결됩니다. 별도로 활성화하거나 설정할 항목은 없습니다.
- 프린터가 `cloudprint.wcpos.com`을 폴링하면 릴레이가 요청을 매장 사이트로 전달하고 사이트의 응답을 반환합니다. 인쇄 작업은 릴레이를 **통과**할 뿐, 릴레이에 저장되지 않습니다.
- 릴레이가 대기 상태에서 발생하는 폴링을 대부분 처리하므로, 대기 중인 프린터가 사이트에 보내는 요청은 몇 초에 한 번에서 분당 약 한 번으로 줄어듭니다.
- 사이트가 릴레이에 연결할 수 없는 경우(예: 릴레이에서 접근할 수 없는 로컬 개발 사이트), WCPOS는 자동으로 사이트 직접 연결 URL을 사용합니다.

:::note 직접 연결을 선호하시나요?
각 프린터의 설정 화면에서 **고급** 항목을 펼치면 사이트 직접 연결 URL을 확인할 수 있습니다. 호스팅 환경이 프린터와 잘 호환되거나 작업을 릴레이를 거치지 않고 보내려면 이 URL을 사용하세요. 개발자는 다음 한 줄로 사이트 전체에서 릴레이를 끌 수 있습니다:

```php
add_filter( 'woocommerce_pos_cloud_print_relay_enabled', '__return_false' );
```
:::

**릴레이가 볼 수 있는 것.** 연결하면 사이트 URL이 wcpos.com과 공유되며, 인쇄 작업(주문 정보를 포함하는 영수증 내용)이 프린터로 가는 도중 릴레이를 경유합니다. 어떤 것도 보관되지 않습니다. 자세한 내용은 [개인정보처리방침](https://wcpos.com/privacy)에 있습니다.

## 클라우드 프린터 설정 {#setup}

클라우드 프린터는 WP Admin에서 한 번 설정하면 모든 기기에서 공유됩니다. 로컬 프린터 설정은 기기별로 저장됩니다.

**WP Admin > POS > 설정 > 클라우드 인쇄**로 이동해 **프린터 추가**를 클릭하세요. **이름**(예: "주방" 또는 "사무실")을 지정하세요. WCPOS는 프린터에서 고정된 **프린터 ID**를 자동으로 생성합니다. 이 ID는 바뀌지 않으므로 프린터의 펌웨어 설정에서 안심하고 참조할 수 있습니다.

프린터를 추가한 후 제공업체 쪽을 설정하세요.

### Star 또는 Epson(폴링 프린터) {#setup-polling}

<Steps>
  <StepCard number="1" title="WCPOS에서 프린터 추가">

**WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터를 추가하고 제공업체로 **Star CloudPRNT** 또는 **Epson Server Direct Print**를 선택하세요. WCPOS가 해당 프린터의 **폴 URL**과 **일회용 토큰**을 생성합니다.

  </StepCard>
  <StepCard number="2" title="폴 URL과 토큰 복사">

생성된 폴 URL과 토큰을 복사하세요. URL은 보통 **cloudprint.wcpos.com**을 가리킵니다. 이것이 사용해야 할 [WCPOS Cloud Print 릴레이](#relay) 주소입니다. 사이트 직접 연결 URL은 **고급** 항목을 펼치면 확인할 수 있습니다. **토큰은 한 번만 표시됩니다**. 분실한 경우 프린터 카드에서 새 토큰을 생성하고 프린터에 저장된 값을 새 토큰으로 업데이트하세요.

  </StepCard>
  <StepCard number="3" title="프린터 설정에 입력" isLast>

프린터의 설정 페이지를 여세요. Star는 **CloudPRNT**, Epson은 **Server Direct Print** 설정에 폴 URL과 토큰을 붙여넣으세요. 프린터에서 폴링 간격을 요청하면 설정하세요(일반적으로 몇 초). 저장하고 필요하면 프린터를 재부팅하세요.

한 번의 폴링 주기 안에 프린터가 접속하며, WCPOS에 표시되는 상태가 **대기 중**에서 **연결됨**으로 바뀝니다.

  </StepCard>
</Steps>

### PrintNode {#setup-printnode}

<Steps>
  <StepCard number="1" title="PrintNode 데스크톱 클라이언트 설치">

대상 프린터로 이미 인쇄할 수 있는 컴퓨터에 **PrintNode 클라이언트**를 설치하고 로그인하세요. 작업을 인쇄하려면 클라이언트를 계속 실행하고 온라인 상태로 유지해야 합니다.

  </StepCard>
  <StepCard number="2" title="PrintNode API 키 받기">

PrintNode 계정에서 **API 키**를 만드세요. WCPOS는 이 키로 PrintNode 계정에 작업을 제출합니다.

  </StepCard>
  <StepCard number="3" title="WCPOS에 API 키 입력">

**WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터를 추가하고 제공업체로 **PrintNode**를 선택한 다음 API 키를 붙여넣으세요. WCPOS는 이 키로 PrintNode 계정에 등록된 프린터 목록을 가져옵니다.

  </StepCard>
  <StepCard number="4" title="프린터 선택" isLast>

PrintNode 클라이언트가 제공하는 프린터 목록에서 대상 프린터를 선택한 다음 저장하세요. WCPOS가 이 프린터의 작업을 PrintNode에 제출하면 클라이언트가 인쇄합니다.

  </StepCard>
</Steps>

### Star Online {#setup-star-online}

Star 프린터가 이미 **stario.online** 계정에 등록되어 있고 Star의 호스팅 서비스에서 작업 전달을 처리하도록 하려면 Star Online을 사용하세요.

<Steps>
  <StepCard number="1" title="CloudPRNT URL 받기">

stario.online에서 **기기 그룹**을 열고 그룹의 **CloudPRNT URL**을 복사하세요. URL은 `https://device.stario.online/cloudprnt/...` 또는 `https://eu-device.stario.online/cloudprnt/...` 형식이어야 합니다.

  </StepCard>
  <StepCard number="2" title="권한이 있는 API 키 만들기">

stario.online에서 WCPOS용 API 키를 만드세요. 키에는 기기 목록 조회 및 인쇄 권한이 있어야 합니다. 최소한 다음 권한을 활성화하세요:

- **EnumDevices** — WCPOS가 기기 목록을 가져올 때 필요
- **ViewDevice** — 기기 상태 확인에 사용
- **PrintToDevice** — 인쇄 작업 제출에 필요
- **ViewDeviceGroups** — 그룹 조회 및 진단에 권장

API 키가 있어도 이 권한들이 활성화되어 있지 않으면 작업이 실패할 수 있습니다.

  </StepCard>
  <StepCard number="3" title="WCPOS에 URL과 API 키 입력">

**WP Admin > POS > 설정 > 클라우드 인쇄**에서 프린터를 추가하고 제공업체로 **Star Online**을 선택한 다음 CloudPRNT URL과 API 키를 붙여넣으세요. **내 기기 가져오기**를 클릭하세요.

  </StepCard>
  <StepCard number="4" title="Star 기기 선택" isLast>

기기 목록에서 프린터를 선택하고 저장하세요. WCPOS는 API 키를 서버에 저장하고 Star Online에 작업을 제출할 때 선택한 기기의 액세스 식별자를 사용합니다.

  </StepCard>
</Steps>

## 자동 인쇄 규칙 {#auto-print}

자동 인쇄 규칙은 무엇을 어디에 자동으로 인쇄할지 결정하며 일반 문장으로 표현됩니다. 규칙은 **범위 × 프린터 × 템플릿**에 **실행 시점**과 **인쇄 매수**를 더한 것입니다. 예를 들면 다음과 같습니다:

> **결제 완료 시**, **모든 주문**을 **주방 티켓** 템플릿으로 **주방** 프린터에 **×2** 인쇄합니다.

규칙은 **주문 생성 시** 또는 **결제 완료 후에만** 실행되도록 설정할 수 있습니다. 따라서 주문이 접수되는 즉시 주방 티켓을 인쇄하고 고객 영수증은 결제 후에 인쇄할 수 있습니다. 작업대에 여러 장이 필요하면 **인쇄 매수**를 설정할 수도 있습니다. 조건에 맞는 주문이 지정된 실행 시점에 도달하면 WCPOS가 선택한 **템플릿**을 서버에서 프린터에 필요한 형식으로 렌더링하여 대기열에 추가합니다. 캐셔가 따로 할 일은 없습니다.

:::note 템플릿 호환성이 중요합니다
Star 및 Epson 프린터는 **감열** 템플릿만 사용할 수 있습니다. 인쇄 작업을 프린터 고유의 명령 언어(Star는 Star Document Markup 또는 ESC/POS, Epson은 ePOS-Print)로 렌더링해야 하기 때문입니다. PrintNode는 작업을 **PDF**로 렌더링하므로 감열 및 전체 페이지 HTML을 포함한 **모든** 템플릿을 사용할 수 있습니다. 특정 프린터에서 템플릿이 선택 항목으로 나타나지 않는다면 해당 프린터가 그 형식을 렌더링할 수 없기 때문입니다. 감열 레이아웃을 만드는 방법은 [감열 템플릿](/1.x/receipts/thermal-templates)을 참조하세요.
:::

매장별 인쇄 라우팅에는 [WCPOS Pro](/1.x/getting-started/pro-license)와 [다중 매장](/1.x/stores) 설정이 필요합니다.
:::

기본적으로 자동 인쇄 규칙은 모든 매장이 공유하는 전역 규칙입니다. Pro에서는 각 매장에 **자체** 클라우드 인쇄 규칙을 지정해 해당 매장의 주문을 해당 매장의 프린터로 인쇄할 수 있습니다. 한 매장의 주방 티켓이 다른 매장에서 인쇄되어서는 안 되기 때문입니다.

**POS → 매장**에서 매장을 편집하고 **클라우드 인쇄** 섹션을 연 다음 **규칙 추가**를 클릭하세요. 각 규칙은 다음 항목으로 구성됩니다:

- **프린터 ID** — 작업을 보낼 클라우드 프린터의 고정 ID
- **범위** — **POS 주문만**(기본값), **온라인 주문만** 또는 **모든 주문**
- **형식** — **StarPRNT**(기본값), **ESC/POS**, **Epson ePOS-Print** 또는 **HTML**

주문이 자체 규칙을 가진 매장에 속하면 WCPOS는 그 매장의 프린터로 작업을 보냅니다. 매장에 자체 규칙이 **없으면** **전역 자동 인쇄 규칙을 대신 적용**합니다. 따라서 다른 규칙이 필요한 매장만 설정하면 됩니다.

## 수동 인쇄 {#manual}

자동 인쇄 규칙이 실행될 때까지 기다릴 필요는 없습니다. 캐셔는 **결제 / 영수증 화면**에서 필요할 때 클라우드 프린터로 영수증을 보낼 수 있습니다. 영수증을 재인쇄하거나 특정 프린터에 티켓을 한 번만 보낼 때 유용합니다.

영수증 생성 방식은 프린터에 따라 다릅니다:

- **Star CloudPRNT** — 영수증을 **기기에서** 렌더링하고 CloudPRNT를 통해 프린터로 전달합니다.
- **Star Online, Epson, PrintNode** — 선택한 주문과 템플릿을 바탕으로 영수증을 **서버에서** 렌더링한 다음 프린터 또는 호스팅 릴레이로 전달합니다.

:::note 형식 지원이 제한적인 프린터를 위한 대체 렌더링
**Star CloudPRNT**는 프린터와 미디어 유형을 협상하고, 프린터가 더 풍부한 형식을 지원하지 않으면 일반 텍스트(`text/plain`)로 대체합니다. 펌웨어가 StarPRNT 명령을 해석하지 못하는 Star 프린터의 경우 WCPOS가 영수증을 **서버에서 PNG 이미지로** 렌더링하여 대신 보낼 수 있습니다. 이렇게 하면 인쇄가 실패하지 않고 영수증을 출력할 수 있습니다.
:::

## 인쇄 대기열 {#print-queue}

클라우드 프린터로 보낸 모든 작업은 프린터가 가져가거나(폴링 프린터) 제공업체가 전달을 확인할 때까지 사이트의 대기열에 남아 있습니다. **WP Admin > POS > 설정 > 클라우드 인쇄**의 프린터 목록 아래에 대기열이 표시됩니다:

- 프린터 또는 상태(**대기 중**, **인쇄 중**, **인쇄 완료**, **실패**, **취소됨**)별로 **필터링**할 수 있으며 작업 수가 실시간으로 표시됩니다.
- 각 행에는 영수증이 얼마나 오래 **대기**했는지와 인쇄 대상인 WooCommerce **주문**의 링크가 표시됩니다.
- 대기 중인 작업을 하나씩, 여러 개씩 또는 프린터 전체 단위로 **취소**할 수 있습니다. **재시도**를 클릭하면 실패한 작업을 다시 대기열에 추가합니다.

프린터에 대기 중인 작업이 있는데 몇 분이 지나도록 작업을 가져가지 않으면 **경고 배너**에 프린터 이름, 밀린 영수증 수, 대기 시간이 표시되고 **모두 취소** 옵션이 제공됩니다. 따라서 프린터가 분리된 상태에서 작업이 쌓여도 이를 놓치지 않습니다.

## 테스트 인쇄 및 연결 상태 {#status}

각 프린터 카드에는 간단한 진단 작업을 보내는 **테스트 인쇄** 버튼이 있습니다. 실제 주문을 인쇄하기 전에 프린터에 연결할 수 있는지, 인쇄 형식이 올바른지 확인할 수 있습니다.

카드에는 실시간 상태도 표시됩니다:

| 제공업체 | 상태 | 의미 |
|----------|--------|---------|
| **Star CloudPRNT / Epson** | **대기 중** | 프린터가 아직 접속하지 않았습니다. WCPOS가 첫 폴링을 기다리고 있습니다. |
| **Star CloudPRNT / Epson** | **연결됨** | 프린터가 최근에 WCPOS를 폴링했으며 작업을 가져오고 있습니다. |
| **Star Online** | **온라인** | Star Online에서 선택한 기기를 사용할 수 있다고 보고합니다. |
| **Star Online** | **오프라인** | Star Online에서 선택한 기기를 사용할 수 없다고 보고합니다. |
| **Star Online** | **알 수 없음** | WCPOS가 Star Online에서 기기 상태를 확인하지 못했습니다. |
| **PrintNode** | **온라인** | PrintNode 서비스에서 클라이언트와 프린터를 사용할 수 있다고 보고합니다. |
| **PrintNode** | **오프라인** | PrintNode에서 클라이언트 또는 프린터를 사용할 수 없다고 보고합니다. |

## 문제 해결 {#troubleshooting}

<Accordion>
  <AccordionItem question="프린터가 대기 중 상태에 머무릅니다">

  **대기 중** 상태를 벗어나지 못하는 폴링 프린터는 WCPOS에 한 번도 정상적으로 접속하지 못한 것입니다. 다음을 확인하세요:

  - 프린터 펌웨어의 **폴 URL과 토큰**이 WCPOS가 생성한 값과 정확히 일치하는지 확인하세요. 문자 하나만 틀려도 모든 폴링이 거부됩니다. 확실하지 않으면 WCPOS에서 토큰을 다시 생성하여 입력하세요.
  - 프린터가 인터넷을 통해 실제로 **사이트에 접속**할 수 있는지 확인하세요. DNS가 올바르고, 방화벽이 아웃바운드 HTTPS를 차단하지 않으며, 매장 사이트의 SSL 인증서가 유효해야 합니다.
  - 프린터의 CloudPRNT / Server Direct Print 설정에서 **폴링이 활성화**되어 있고 간격이 적절한지 확인하세요. 설정을 변경한 후에는 프린터를 재부팅하세요.
  - 고급 항목의 **사이트 직접 연결 URL**을 입력했는데도 프린터가 연결되지 않으면 기본 **cloudprint.wcpos.com** URL로 전환하세요. 많은 프린터가 최신 호스팅 환경과 보안 연결을 맺지 못하며, [릴레이가 바로 이 문제를 해결합니다](#relay).

  </AccordionItem>

  <AccordionItem question="프린터 URL이 cloudprint.wcpos.com을 가리키는 이유는 무엇인가요?">

  이 주소는 [WCPOS Cloud Print](#relay)입니다. 프린터 펌웨어가 연결을 맺을 수 있는 접속 방식을 제공하고 인쇄 작업을 매장 사이트로 중계하는 무료 릴레이입니다. 자동으로 활성화되며 작업은 릴레이에 저장되지 않습니다. 직접 연결을 원하면 프린터의 **고급** 항목에서 언제든 사이트 직접 연결 URL을 사용할 수 있습니다.

  </AccordionItem>

  <AccordionItem question="릴레이가 도입되기 전에 프린터를 설정했습니다. 변경할 사항이 있나요?">

  아니요. 프린터 설정에 이미 저장된 URL은 계속 작동합니다. 다만 프린터가 **대기 중 상태에 머무른다면** 해당 펌웨어가 호스팅 환경에 직접 연결하지 못하는 것일 수 있습니다. 프린터 카드에서 **설정 &amp; 토큰**을 열고 토큰을 다시 생성한 다음, 새 **cloudprint.wcpos.com** URL과 토큰을 프린터 설정에 입력하세요.

  </AccordionItem>

  <AccordionItem question="Star Online에서 API 키의 인증 실패 또는 접근 금지 오류가 표시됩니다">

  Star Online은 **인증**과 **권한**을 구분합니다:

  - **401 / 인증 실패**는 API 키 자체가 승인되지 않았다는 뜻입니다. 키가 올바르게 복사되었는지, 폐기되지 않았는지, 사용하려는 Star Online 계정/지역의 키가 맞는지 확인하세요.
  - **403 / 금지**는 API 키는 승인되었지만 요청한 작업에 대한 권한이 없다는 뜻입니다. stario.online에서 키를 편집하여 필요한 권한을 활성화하세요. 특히 **내 기기 가져오기**에는 **EnumDevices**, 인쇄에는 **PrintToDevice**가 필요합니다.

  **내 기기 가져오기**가 성공해도 프린터가 표시되지 않으면 stario.online의 **기기 그룹** 페이지를 확인하세요. 그룹에 연결된 기기가 하나 이상 있어야 하며, WCPOS의 CloudPRNT URL도 같은 그룹을 가리켜야 합니다.

  </AccordionItem>

  <AccordionItem question="PrintNode 작업이 인쇄되지 않습니다">

  작업이 PrintNode에 도달했지만 프린터에서 출력되지 않았습니다. 다음을 확인하세요:

  - 프린터에 연결된 컴퓨터에서 **PrintNode 데스크톱 클라이언트가 실행 중이며 온라인 상태인지** 확인하세요. 컴퓨터가 절전 모드이거나 클라이언트가 종료되어 있으면 인쇄되지 않습니다.
  - WCPOS에서 **올바른 프린터**를 선택했는지 확인하세요. 이름이 클라이언트에서 표시하는 프린터와 일치해야 합니다.
  - **API 키가 유효**하고 폐기되지 않았는지 확인하세요. PrintNode에서 프린터가 오프라인으로 표시되면 키를 다시 입력하세요.

  </AccordionItem>

  <AccordionItem question="Star 또는 Epson 프린터에서 템플릿을 선택할 수 없습니다">

  Star 및 Epson 클라우드 프린터에서는 **감열** 템플릿만 사용할 수 있습니다. 영수증을 ESC/POS 또는 ePOS-Print 명령으로 렌더링해야 하기 때문입니다. HTML 및 전체 페이지 템플릿은 이 형식으로 표현할 수 없어 해당 프린터에서는 표시되지 않습니다.

  [감열 템플릿](/1.x/receipts/thermal-templates)을 선택하거나 **PrintNode** 프린터를 사용하세요. PrintNode는 PDF로 렌더링하므로 모든 템플릿을 인쇄할 수 있습니다.

  </AccordionItem>
</Accordion>
