# PayArc Terminal 결제 게이트웨이 {#payarc-terminal-gateway}

PayArc Terminal 결제 게이트웨이를 사용하면 PayArc Connect를 통해 WCPOS에서 PayArc PAX 단말기로 대면 결제를 받을 수 있습니다. 결제는 WooCommerce에서 시작해 단말기에서 완료되며, PayArc가 확인한 후에만 주문이 결제 완료로 표시됩니다.

## 작동 방식 {#how-it-works}

WordPress가 **PayArc Connect**를 호출하면 PayArc가 PAX 단말기에 연결합니다. POS는 사이트와만 통신합니다. 결제마다 **주문 전체 금액**이 청구됩니다.

결제 페이지는 **1.5초**마다 결과를 확인하고 **5분** 후 중지됩니다. **Webhook URL**로 전송되는 PayArc 콜백은 결과 확인을 앞당깁니다. 콜백이 없어도 폴링을 통해 결제가 완료됩니다. 고객이 단말기에서 결제하는 동안 결제 페이지를 열어 두세요.

## 설정 {#setup}

<Steps>
  <StepCard number="1" title="WooCommerce용 PayArc Terminal 설치">

`WP Admin > POS > 설정 > 확장`에서 설치하거나 [GitHub 릴리스 페이지](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases)에서 **payarc-terminal-for-woocommerce.zip** 파일을 다운로드한 다음 `플러그인 > 새로 추가 > 플러그인 업로드`에서 업로드하세요. 플러그인을 활성화하세요.

  </StepCard>
  <StepCard number="2" title="PayArc 자격 증명 입력">

1. `WP Admin > WooCommerce > 설정 > 결제`로 이동해 **PayArc Terminal**을 여세요.
2. **모드**를 선택하세요. 기본값은 `Live`입니다. PayArc 테스트 대시보드 자격 증명과 PayArc Connect Test 앱을 사용하는 경우에만 `Test`를 선택하세요. 환경을 혼용하지 마세요.
3. PayArc 가맹점 대시보드에 로그인할 때 사용하는 이메일인 **PayArc 로그인 이메일**을 입력하세요.
4. 단말기 ID가 아닌 PayArc Merchant Profile의 **PayArc MID**를 입력하세요.
5. 대시보드 API 섹션의 **PayArc ClientSecret**과 PayArc 대시보드의 **PayArc SecretKey / API bearer token**을 입력하세요.
6. PayArc 지원팀에서 발급한 경우가 아니라면 **Callback bearer token**은 비워 두세요. 이 항목은 선택 사항입니다.

  </StepCard>
  <StepCard number="3" title="연결">

**이 자격 증명으로 연결**을 클릭하세요. 연결에 성공하면 화면에 단말기 일련 번호를 입력하거나 확인하고 설정을 저장하라는 메시지가 표시됩니다. 자격 증명이 다른 환경의 것으로 보인다는 메시지가 표시되면 **모드**를 전환한 후 다시 연결하세요.

:::note
모드나 자격 증명을 변경한 후에는 **이 자격 증명으로 연결**을 다시 클릭하고 저장하세요. 모드와 자격 증명이 저장된 연결과 일치할 때까지 결제가 차단됩니다. 0.1.14 이전 버전에서 업그레이드하는 경우 Connect를 한 번 누르세요.
:::

  </StepCard>
  <StepCard number="4" title="단말기 추가">

1. PayArc에서 계정에 설정한 PAX **단말기 일련 번호**를 기기 뒷면의 **S/N** 라벨에서 확인해 입력하세요.
2. **결제 유형**과 **영수증 인쇄**를 선택하세요.
3. **Webhook URL**이 HTTPS인지 확인하세요. PayArc에서 요청하는 경우에만 URL을 전달하세요.
4. **변경 사항 저장**을 클릭하세요.

Live 모드에는 HTTPS 사이트가 필요합니다.

  </StepCard>
  <StepCard number="5" title="WCPOS에서 활성화" isLast>

1. `WP Admin > POS > 설정 > 결제`로 이동하세요.
2. **PayArc Terminal** 결제 게이트웨이를 찾아 POS에서 활성화하세요.
3. 설정을 저장하세요.

:::note
WooCommerce 설정 화면의 **활성화/비활성화** 체크박스는 *온라인 스토어*의 결제만 제어합니다. 이 체크박스의 선택 여부와 관계없이 WCPOS에서는 게이트웨이를 구성한 후 사용할 수 있습니다.

대부분의 매장은 이 항목을 선택하지 않은 상태로 둡니다.
:::

  </StepCard>
</Steps>

## 설정 참조 {#settings}

| 설정 | 기능 |
|---|---|
| **활성화/비활성화** | 온라인 스토어 결제에서 PayArc Terminal을 활성화합니다. 기본값은 꺼짐이며, POS 활성화 여부는 `POS > 설정 > 결제`에서 제어합니다. |
| **제목** | 결제 시 표시되는 레이블입니다. 기본값은 `PayArc Terminal`입니다. |
| **설명** | 결제 설명입니다. 기본값은 `Pay in person at a PayArc PAX terminal.`입니다. |
| **모드** | `Live`(기본값) 또는 `Test`입니다. Test에는 PayArc 테스트 대시보드 자격 증명과 PayArc Connect Test 앱이 필요합니다. |
| **PayArc 로그인 이메일** | PayArc 가맹점 대시보드 로그인 이메일이며 연결 전에 입력해야 합니다. |
| **PayArc MID** | PayArc Merchant Profile의 가맹점 MID입니다. 단말기 ID가 아닙니다. |
| **PayArc ClientSecret** | 대시보드 API 섹션의 시크릿이며 서버에만 저장됩니다. |
| **PayArc SecretKey / API bearer token** | PayArc 대시보드의 토큰으로, 로그인하고 단말기 레지스트리를 가져오는 데 사용됩니다. |
| **Callback bearer token** | 선택 사항입니다. PayArc 지원팀이 발급한 경우에만 입력하세요. |
| **PayArc 연결** | **이 자격 증명으로 연결**, **단말기 새로 고침**, **연결 해제** 버튼입니다. |
| **단말기 일련 번호** | 계정에 할당된 PAX S/N으로 결제에 필요합니다. 레지스트리에서 찾으면 입력란이 채워집니다. 저장 전에 입력하거나 확인하세요. |
| **결제 유형** | `CREDIT`(기본값) 또는 `DEBIT`입니다. |
| **영수증 인쇄** | `0` — 인쇄 안 함(기본값), `1` — 가맹점, `2` — 고객, `3` — 모두입니다. |
| **Webhook URL** | 읽기 전용 콜백 주소입니다. HTTPS인지 확인하세요. PayArc에서 요청하는 경우에만 전달하세요. |
| **PayArc 진단** | 연결 정보와 **설정 검증** 버튼을 표시합니다. 시크릿은 표시되지 않습니다. |

저장된 시크릿 필드에는 마지막 4자만 표시됩니다. 저장된 값을 유지하려면 시크릿 필드를 비워 두세요.

**PayArc 진단** 표에는 모드, 엔드포인트, 마스킹된 MID / 테넌트 ID / 일련 번호, Connect 액세스 토큰 설정 여부, Webhook URL, 마지막 콜백 및 마지막 PayArc 오류가 표시됩니다. **설정 검증**을 사용해 설정을 확인하세요.

## 사용법 {#usage}

### 결제 처리 {#processing-payments}

1. **결제 게이트웨이 선택**: POS에서 결제 방법으로 **PayArc Terminal**을 선택하세요.
2. **결제 시작**: **결제 시작**을 클릭해 주문 총액을 단말기로 보내세요.
3. **고객 결제**: 고객이 PAX 단말기에서 결제를 완료하는 동안 페이지를 열어 두세요. 상태 메시지를 확인하세요: `Starting terminal payment...` → `Payment sent to terminal.` → `Waiting for the terminal result...` → `Payment approved. Completing the order...`
4. **자동 완료**: PayArc가 결제를 확인하면 주문이 자동으로 완료됩니다.

### 결제 제어 {#payment-controls}

- 결제가 시작되면 **결제 취소**가 표시됩니다. PayArc에서 추적 ID를 아직 반환하지 않았다면 취소하기 전에 잠시 기다리세요.
- 거절, 취소 또는 시간 초과 후에는 다시 시도할 수 있습니다. 시간 초과된 결제를 다시 시도하기 전에 단말기를 확인하세요.
- 결제 활동 로그는 기본적으로 접혀 있습니다. **활동 표시**를 사용해 로그를 확인하고, **지우기**를 사용해 표시된 활동을 지우세요.

### 영수증 {#receipts}

**영수증 인쇄** 설정은 단말기에서 인쇄할 영수증을 제어합니다. 인쇄 안 함, 가맹점, 고객 또는 모두를 선택할 수 있습니다.

## 환불 {#refunds}

플러그인을 통한 환불은 지원되지 않습니다. PayArc에서 환불한 다음 WooCommerce에 환불 내역을 직접 기록하세요.

## 로그 {#logs}

로그는 `WooCommerce > Status > 로그`에서 `payarc-terminal-for-woocommerce` 소스 아래에 있습니다. 로그에는 연결 시도, 시작되었거나 실패한 판매, 취소, 수락 또는 거부된 콜백이 포함됩니다. 식별 정보는 마스킹되고 비밀 값은 가려집니다.

지원 번들은 다운로드할 수 없습니다. 도움을 요청할 때 주문 번호와 관련 로그 줄을 보내세요. 전체 MID, 단말기 ID, 토큰 또는 카드 데이터를 공유하지 마세요.

## 범위 및 제한 사항 {#scope-and-limitations}

- 플러그인을 통한 환불은 지원되지 않습니다.
- 결제 시 **주문 전체 금액**이 청구됩니다. 부분 결제 또는 분할 결제는 지원되지 않습니다.
- 팁은 지원되지 않습니다.
- 매장당 단말기 한 대만 사용할 수 있습니다. 일련 번호 설정은 하나이며 캐셔 선택 기능은 없습니다.
- 통화는 **USD, CAD, GBP, EUR 및 JPY**로 제한됩니다.
- 모드와 자격 증명이 저장된 연결과 일치할 때까지 결제가 차단됩니다.

## 문제 해결 {#troubleshooting}

### 일반적인 문제 {#common-issues}

<Accordion>
  <AccordionItem question="자격 증명이 다른 환경의 것으로 보입니다">

  - 선택한 모드와 자격 증명이 서로 다른 환경의 것입니다.
  - 자격 증명에 맞게 **모드**를 전환하거나 선택한 모드에 해당하는 자격 증명으로 교체하세요.
  - **이 자격 증명으로 연결**을 다시 클릭하고 저장하세요.

  </AccordionItem>
  <AccordionItem question="PayArc에 연결할 수 없음">

  - PayArc에서 로그인 자격 증명을 거부했습니다. 입력한 자격 증명을 확인하고 다시 시도하세요.
  - 자세한 내용은 `WooCommerce > Status > 로그`에서 `payarc-terminal-for-woocommerce` 소스를 확인하세요.

  </AccordionItem>
  <AccordionItem question="결제 요청을 처리할 수 없음. (HTTP 500)">

  - 이 캐셔 메시지는 일반적인 내용입니다. 실제 원인을 확인하려면 WooCommerce 로그에서 **PayArc payment action failed**를 찾으세요.
  - 모드나 자격 증명을 변경한 후에는 **이 자격 증명으로 연결**을 다시 클릭하고 저장하세요.
  - **단말기 일련 번호**가 입력되어 있는지 확인하세요.
  - 로그에 PayArc가 Connect 액세스 토큰과 SecretKey를 모두 거부했다고 표시되면 PayArc 지원팀에 문의해 가맹점 계정에서 **PayArc Connect V3**가 활성화되어 있는지 확인하세요.
  - 매장 통화가 **USD, CAD, GBP, EUR 또는 JPY**인지 확인하세요.

  </AccordionItem>
  <AccordionItem question="결제 시작 시 액세스 거부됨. (HTTP 403)">

  - **0.1.12 이상**으로 업데이트하세요. 이 버전에서는 POS 세션에서 이 오류가 해결되었습니다.

  </AccordionItem>
  <AccordionItem question="단말기 레지스트리가 비어 있음">

  - 레지스트리가 비어 있거나 POS 식별자 없이 단말기가 표시되는 것은 정상입니다.
  - 레지스트리 데이터는 정보 제공용입니다. 결제에는 **단말기 일련 번호**를 사용합니다.

  </AccordionItem>
  <AccordionItem question="결제 대기 시간이 너무 깁니다">

  - 단말기 화면을 확인하고 결제 페이지를 열어 두세요.
  - 다시 시도하기 전에 주문 메모와 PayArc 대시보드를 확인하세요.
  - 페이지는 **1.5초**마다 확인하고 **5분** 후 중지됩니다.

  </AccordionItem>
</Accordion>

### 도움 받기 {#getting-help}

- 지원 요청에 **주문 번호**와 관련 **로그 줄**을 포함하세요.
- 문제를 신고하려면 [GitHub 저장소](https://github.com/wcpos/payarc-terminal-for-woocommerce)를 방문하세요.
- 계정, PayArc Connect 및 단말기 설정에 대해서는 PayArc 지원팀에 문의하세요.
