# POS 할인 기술 레퍼런스 {#pos-discount-technical-reference}

이 페이지는 WCPOS가 캐셔가 적용한 라인 항목 가격 재정의를 처리하는 방법, 즉 저장 방식, WooCommerce 쿠폰과의 상호 작용, 사용 가능한 필터를 설명합니다. 사용자용 문서는 [장바구니 할인](/1.x/pos/cart/discounts)과 [쿠폰](/1.x/coupons)을 참조하세요.

## POS 가격 재정의 저장 방식 {#how-pos-price-overrides-are-stored}

캐셔가 POS에서 라인 항목의 가격을 설정하거나 변경하면 단가가 해당 라인 항목의 `_woocommerce_pos_data` 메타에 JSON으로 저장됩니다:

```json
{
  "price": "16.00",
  "regular_price": "18.00",
  "tax_status": "taxable"
}
```

기타(사용자 정의) 상품의 경우 이 메타에 쿠폰 유효성 검사에 사용되는 `virtual`, `downloadable`, `categories` 필드도 포함될 수 있습니다.

이 메타는 해당 항목의 단가를 결정하는 기준 원본입니다. WooCommerce가 라인 항목에 저장하는 `subtotal`은 `price * qty`에서 산출됩니다(세금 분리 및 반올림 적용). 쿠폰 할인이 적용되면 저장된 `total`이 더 낮아질 수 있으므로 정확한 단가를 확인하려면 항상 `_woocommerce_pos_data.price`와 `regular_price`를 읽어야 합니다.

새 POS 주문에는 서버 플러그인 버전도 비공개 `_woocommerce_pos_version` 주문 메타에 기록됩니다. 이는 향후 호환성 검사에 사용할 명시적인 버전 표시입니다. 오프라인 주문은 해당 주문을 생성한 앱보다 최신 버전의 서버에서 접수될 수 있으므로 영수증 계산에서는 저장된 라인 항목 구조를 계속 기준으로 삼습니다.

## 소계 모델 (v1.9.0+) {#subtotal-model-v190}

v1.9.0부터 WCPOS는 WooCommerce의 기본 할인가 처리 방식에 맞춰 동작합니다:

- `line_item.subtotal = price * qty`에서 `price`는 재정의가 적용된 후의 POS 가격입니다.
- `line_item.total = subtotal - coupon_discount_for_line`.
- `order.discount_total`은 POS 가격 재정의가 아닌 **쿠폰 할인만** 반영합니다.

이는 WooCommerce가 세일 중인 상품을 처리하는 방식과 같습니다. `sale_price`가 소계가 되고 `discount_total`은 쿠폰에만 사용됩니다. 주문에 별도의 ‘POS 할인’ 항목은 없습니다.

:::note 1.9.0 이전 버전에서의 마이그레이션
이전 버전에서는 `subtotal = regular_price * qty`를 전송했기 때문에 WooCommerce가 `discount_total = subtotal - total`을 계산하면서 POS 가격 재정의를 할인에 포함했습니다. 이 방식은 쿠폰 계산과 충돌하여 변경되었습니다. `recalculate_coupons()`가 `subtotal`을 기준 가격으로 사용하므로 쿠폰이 원래 가격을 기준으로 계산되어 잘못된 합계가 나왔습니다.

이전의 서버 측 해결 방법 — `woocommerce_order_item_get_subtotal` 실행 중 활성화되던 `recalculate_coupons()` 필터 — 은 v1.9.0에서 제거되었습니다. 전체 변경 이력은 [ADR](https://github.com/wcpos/wiki/blob/main/architecture/decisions/2026-04-08-subtotal-parity.md)을 참조하십시오.
:::

## 쿠폰 적용 동작 {#coupon-interaction-behaviour}

쿠폰 지원은 [WCPOS Pro](https://wcpos.com/pro) 기능입니다. POS 할인이 적용된 항목이 포함된 주문에 쿠폰을 적용하면:

1. 쿠폰은 원래 `regular_price`가 아니라 **POS 할인이 적용된 가격**(`_woocommerce_pos_data.price`의 값)을 기준으로 계산됩니다.
2. 쿠폰을 제거하면 라인 항목은 POS 할인이 적용된 가격으로 돌아갑니다.

### `exclude_sale_items` 동작 {#exclude_sale_items-behaviour}

`_woocommerce_pos_data.price < regular_price`이면 WooCommerce는 POS 할인이 적용된 항목을 ‘세일 중’으로 처리합니다. 따라서 `exclude_sale_items`가 활성화된 쿠폰은 해당 항목을 제외하며, 이는 WooCommerce의 일반 세일 가격 처리 방식과 같습니다.

다른 동작이 필요하다면 아래의 `woocommerce_pos_item_is_on_sale` 필터를 참조하세요.

## 사용 가능한 필터 {#available-filters}

### `woocommerce_pos_item_is_on_sale` {#woocommerce_pos_item_is_on_sale}

쿠폰 유효성 검사 시 POS 할인이 적용된 항목을 ‘세일 중’으로 간주할지 여부를 재정의합니다.

```php
add_filter( 'woocommerce_pos_item_is_on_sale', function ( $is_on_sale, $product, $item, $pos_data ) {
    // Allow coupons with exclude_sale_items to apply to POS-discounted items
    return false;
}, 10, 4 );
```

**매개변수:**

| 매개변수 | 타입 | 설명 |
|---|---|---|
| `$is_on_sale` | `bool` | 항목을 세일 중으로 간주할지 여부(기본값: `price < regular_price`) |
| `$product` | `WC_Product` | 상품 객체 |
| `$item` | `WC_Order_Item_Product` | 주문 라인 항목 |
| `$pos_data` | `array` | 디코딩된 `_woocommerce_pos_data` JSON |

## REST API 엔드포인트 {#rest-api-endpoint}

쿠폰 REST 엔드포인트는 **무료 플러그인**의 `/wp-json/wcpos/v1/coupons`에 있습니다. 따라서 WCPOS Pro가 설치되지 않은 사이트에서도 POS 앱이 쿠폰을 조회할 때 404 응답을 받지 않습니다. 다만 사용자가 이용하는 쿠폰 기능 자체에는 Pro가 필요합니다.

이 컨트롤러는 `WC_REST_Coupons_Controller`를 확장하여 POS 전용 기능을 추가합니다:

- 오프라인 우선 동기화를 위한 UUID 처리
- 권한 검사를 위한 `access_woocommerce_pos` 권한
- `posts_per_page=-1` 및 `fields=id`(또는 `fields=id,date_modified_gmt`)가 요청될 때 최적화된 대량 ID 조회 경로

## 영수증 데이터 노출 {#receipt-data-exposure}

영수증 데이터 빌더(`Receipt_Data_Builder`)는 다음을 노출합니다:

- `lines[].discounts`, `lines[].discounts_incl`, `lines[].discounts_excl` — `subtotal - total`로 계산한 항목별 할인 금액입니다. v1.9.0부터 POS 가격 재정의에 대해서는 **쿠폰 할인만** 반영합니다. 쿠폰이 적용되지 않으면 `subtotal === total`이기 때문입니다.
- `totals.discount_total`, `totals.discount_total_incl`, `totals.discount_total_excl` — `WC_Order::get_discount_total()`에서 가져온 주문 단위 쿠폰 할인 합계입니다.
- `totals.sale_savings_total`, `totals.sale_savings_total_incl`, `totals.sale_savings_total_excl` — 상품 항목 전체에 기록된 정상 가격 대비 판매 가격의 절감액 합계입니다. 카탈로그 세일 가격과 계산대에서 재정의한 가격도 포함합니다.
- `totals.total_saved`, `totals.total_saved_incl`, `totals.total_saved_excl` — WooCommerce 할인과 정상 가격 대비 절감액을 합산한 값입니다. 빌더는 v1.9.0 이전 주문의 WooCommerce 할인 합계에 이미 반영된 항목별 절감액을 제외합니다.
- `totals.total_saved_complete` — 신뢰할 수 있는 합계를 계산하기에 기록된 가격 데이터가 부족한 항목이 하나라도 있으면 false입니다. 이 경우 null을 허용하는 절감액 합계 필드는 `null`이 됩니다.
- `discounts[]` — `label`, `code`, `total`을 포함하는 쿠폰 라인 항목 배열입니다.

라인 항목의 밑줄로 시작하는 메타(`_woocommerce_pos_data` 포함)는 `Receipt_Data_Builder::get_item_meta_pairs()`에 의해 `lines[].meta`에서 제외됩니다. 대신 영수증 데이터 v1.1은 기록된 정상 가격, 쿠폰 적용 전 판매 가격, 항목별 절감액, 전체 절감액을 표준 필드로 제공합니다. 템플릿 예시는 [정상 가격 및 절감액 표시](/1.x/receipts/receipt-data#displaying-regular-price-and-savings)와 [합계](/1.x/receipts/receipt-data#totals)를 참조하세요.
