## 의미 {#what-this-means}

검색 색인에서 포함되어야 하는 상품을 찾지 못해 앱이 검색 색인 재구축을 자동으로 시도합니다.

정기 자체 점검에서 로컬 검색 색인에 레코드 자체의 단어로 해당 레코드를 요청했지만 색인이 이를 반환하지 않았습니다. 이는 실제로 이 기기에 있는 항목보다 검색 결과가 적게 표시되었을 수 있음을 의미합니다. 앱은 이를 수정하기 위해 세션당 각 목록마다 한 번 자동으로 색인 재구축을 시도합니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았습니다. 이는 이 기기에 이미 있는 데이터에서 생성되는 로컬 검색 색인에만 해당하므로, 색인을 재구축해도 데이터가 손실되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 대부분 별도의 조치가 필요하지 않으며 판매는 정상적으로 계속할 수 있습니다. 앱이 자동으로 재구축을 시도하며, 완료되면 검색 기능이 복구됩니다. 세션당 각 목록에 대해 재구축은 한 번만 시도되므로 이 코드가 반복되면 다음 단계를 진행하세요.
2. 앱에서 볼 수 있는 레코드(상품, 고객, 주문 또는 다른 목록)가 검색에서 계속 누락되면 앱을 다시 로드하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱 및 모바일에서는 앱을 닫았다가 다시 여세요. 그러면 다음에 문제가 감지될 때 새 재구축을 시도할 수 있습니다.
3. 다시 로드한 후에도 코드가 다시 나타나면 디버그 정보를 내보내고 지원팀에 문의하세요. 로그 항목에는 영향을 받은 목록과 색인에서 누락된 레코드를 식별하는 데 필요한 세부 정보가 포함되어 있습니다.
