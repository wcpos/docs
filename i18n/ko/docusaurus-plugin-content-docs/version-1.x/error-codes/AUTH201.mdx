## 이것이 의미하는 바 {#what-this-means}

귀하의 계정에는 이 작업을 수행할 권한이 없습니다.

매장 관리자에게 계정의 역할과 권한을 확인해 달라고 한 다음 다시 시도하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 스토어 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔: 거부된 작업을 확인하고(로그 항목에 기록됨) 관리자에게 전달하세요.

**매장에서** — 사이트 관리자: 계정 역할을 검토하세요. POS 캐셔에게는 WCPOS가 등록하는 POS 권한이 필요하며, 역할 편집 플러그인이 해당 권한을 제거할 수 있습니다.

계정에는 로그인할 수 있지만 모든 상품, 고객 또는 주문 요청이 거부된다면 **역할이 두 개 이상인지** 확인하세요. Members 같은 역할 편집 플러그인은 한 역할에 설정된 *거부*를 계정 전체에 적용합니다. 따라서 관리자 계정에 고객 역할도 있으면 고객 역할이 거부하는 권한이 관리자에게도 적용됩니다. 추가 역할을 제거하거나 *거부* 표시를 해제하세요. [역할이 두 개 이상인 사용자](/settings/wp-admin/access#more-than-one-role)를 참조하세요.

**계산대로 돌아와서:** 역할을 수정한 후 POS 세션이 열려 있으면 로그아웃한 다음 다시 로그인하세요. 세션이 열려 있지 않으면 다시 로그인하면 됩니다. 그런 다음 거부된 작업을 다시 시도하세요.
