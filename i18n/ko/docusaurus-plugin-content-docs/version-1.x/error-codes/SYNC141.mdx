## 이것이 의미하는 바 {#what-this-means}

매장에서 WCPOS에 잠시 속도를 늦춰 달라고 요청했습니다.

별도로 하실 일은 없습니다. WCPOS가 기다린 후 자동으로 다시 시도합니다. 매일 이 메시지가 표시되면 사이트 관리자에게 매장의 요청 제한에 대해 문의하세요.

## 내 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 전송되지 않은 변경 사항이 들어 있을 수 있습니다. 이후 다시 시도할 때 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 별도로 하실 일은 없습니다. POS가 자동으로 대기한 뒤 다시 시도합니다. 직접 재시도하면 제한 시간이 늘어날 뿐입니다.
2. 다시 입력할 것은 없습니다. 영향을 받은 변경 사항은 기기에 남아 있다가 이후 시도에서 전송됩니다.
3. 매일 이 메시지가 표시되면 사이트 관리자에게 어떤 계층에서 429를 반환하는지 확인해 달라고 요청하세요. 보안 플러그인, CDN 또는 방화벽 규칙, 호스트 자체의 제한일 수 있습니다. POS의 REST 트래픽을 허용하도록 요청하세요.
4. 펼친 로그 항목의 endpoint와 타임스탬프는 관리자가 자체 대시보드에서 해당 제한을 대조하는 데 도움이 됩니다.
