## 이것이 의미하는 바 {#what-this-means}

스토어가 일시적으로 요청을 제한하고 있어 이 작업은 나중에 재시도됩니다.

잠시 기다린 후 재시도하세요. 요청 제한이 계속된다면 사이트 관리자나 호스트에게 스토어의 요청 한도를 검토해 달라고 요청하세요.

## 내 데이터 {#your-data}

변경 사항은 이 기기에 저장되었지만 스토어에는 전달되지 않았습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. 기다리세요. POS가 스스로 간격을 두고 재시도합니다. 수동으로 재시도하면 제한 시간만 길어집니다.
2. 다시 입력할 것은 없습니다. 영향을 받은 변경 사항은 기기에 남아 있다가 이후 시도에서 전송됩니다.
3. 코드가 계속 나타난다면 사이트 관리자에게 어느 계층이 429를 반환하는지(보안 플러그인, CDN 또는 방화벽 규칙, 호스트 자체 한도) 찾아내고 POS의 REST 트래픽을 허용해 달라고 요청하세요.
4. 펼친 로그 항목의 endpoint와 타임스탬프는 관리자가 자체 대시보드에서 해당 제한을 대조하는 데 도움이 됩니다.
