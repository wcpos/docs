## 이것이 의미하는 바 {#what-this-means}

이 변형을 상품에 추가할 수 없었습니다.

변형 필드를 검토하고 수정한 다음 재시도하세요. 그래도 거부된다면 진단 정보를 내보내세요.

## 내 데이터 {#your-data}

거부 원인을 해결할 때까지 변경 사항은 이 기기에 남아 매장에 전송되지 않습니다. 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 스토어가 알려 준 이유(serverCode)를 확인하세요. 대개 누락된 속성이거나 잘못된 옵션 조합입니다.

**계산대에서:** 변형의 필드를 수정하고 다시 시도하세요.

**매장에서 (WP Admin):** 상위 상품의 속성을 확인하세요. 변형이 사용하는 모든 속성이 상위 상품에 있어야 하며 변형용으로 사용하도록 표시되어야 합니다.

그래도 거부되나요? 디버그 정보를 내보내고 지원팀에 문의하세요.
