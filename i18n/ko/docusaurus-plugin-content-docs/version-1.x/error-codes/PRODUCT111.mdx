## 이것이 의미하는 바 {#what-this-means}

이 변형을 상품에 추가할 수 없었습니다.

다른 변경 사항은 없습니다. 상품을 열어 변형이 있는지 확인하세요. 없다면 상위 상품에 설정된 속성을 사용하는지 확인한 다음 다시 추가하세요.

## 내 데이터 {#your-data}

이 기기의 데이터를 지우지 마세요. 매장에 아직 전달되지 않은 변경 사항이 들어 있을 수 있습니다. 다른 변경 사항은 없으며 이 변형만 추가되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 매장에서 표시한 이유를 보려면 로그 항목을 펼치세요. 대개 누락된 속성이나 유효하지 않은 옵션 조합이 원인입니다.

**계산대에서:** 상품을 열고 변형이 있는지 확인하세요. 있다면 다시 추가하지 마세요. 없다면 변형이 상위 상품에 설정된 속성을 사용하는지 확인하고 필드를 수정한 다음 다시 추가하세요.

**매장에서 (WP Admin):** 상위 상품의 속성을 확인하세요. 변형이 사용하는 모든 속성이 상위 상품에 있어야 하며 변형용으로 사용하도록 표시되어야 합니다.

계속 거부되나요? **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
