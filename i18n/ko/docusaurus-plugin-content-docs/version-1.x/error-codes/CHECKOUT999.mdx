## 이것이 의미하는 바 {#what-this-means}

결제 중에 예기치 않은 문제가 발생했습니다.

고객에게 다시 청구하기 전에 스토어 관리자 화면에서 주문을 확인하세요. 문제가 반복되면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 재시도하기 전에 실제 상태를 확인하세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 고객에게 다시 청구하기 전에 WP Admin에서 WooCommerce → 주문에 해당 주문이 있는지 확인하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 serverCode가 있다면 기록해 두세요. 이 일반 코드는 아직 전용 코드가 없는 원인이라는 뜻입니다.
3. 문제가 반복되면 디버그 정보를 내보내고 지원팀에 문의하세요.
