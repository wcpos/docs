## 이것이 의미하는 바 {#what-this-means}

스토어가 로그인 자격 증명을 수락하지 않았습니다.

사용자 이름과 비밀번호를 다시 입력하고, 계속 실패한다면 WordPress에서 비밀번호를 재설정하세요. 주문 데이터에는 영향이 없습니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔: 사용자 이름과 비밀번호를 다시 입력하세요. 매장에서 해당 조합을 거부했습니다.

**매장에서** — 사이트 관리자:

1. 같은 로그인 정보로 WP Admin에 로그인해 계정이 작동하는지 확인하세요. 로그인에 실패하면 그곳에서 비밀번호를 재설정하세요.
2. WP Admin에서는 로그인 정보가 작동하지만 POS에서 작동하지 않는다면 로그인 보호 또는 보안 플러그인이 프로그래밍 방식의 로그인을 차단할 수 있습니다. 해당 플러그인 설정을 확인하세요.
