# DB01001: 연결 실패 {#db01001-connection-failed}

## 이것이 의미하는 바 {#what-this-means}

POS가 로컬 데이터베이스에 연결할 수 없습니다. WCPOS는 빠른 액세스와 오프라인 기능을 위해 제품, 고객 및 기타 데이터를 저장하기 위해 로컬 데이터베이스를 사용합니다.

## 일반적인 원인 {#common-causes}

- **저장소 가득 참** — 장치에 남은 저장 공간이 없음
- **데이터베이스 손상** — 로컬 데이터베이스 파일이 손상됨
- **권한 문제** — 앱에 저장 권한이 없음
- **브라우저 저장소 비활성화** — IndexedDB가 비활성화됨 (웹 버전)

## 해결 방법 {#how-to-fix}

### 1. 저장 공간 확인 {#1-check-storage-space}

장치에 사용 가능한 저장 공간이 있는지 확인:
- 저장 공간이 가득 찼다면 공간을 확보하십시오
- 사용하지 않는 앱이나 파일 삭제
- 사용 가능한 디스크 공간 확인

### 2. 앱 데이터 지우기 {#2-clear-app-data}

:::warning 저장하지 않은 작업이 있는지 먼저 확인하세요
로컬 데이터를 지우거나 앱을 다시 설치하면 이 장치에 저장된 데이터 중 매장에 전송되지 않은 모든 항목이 삭제됩니다. 여기에는 오프라인에서 처리한 판매, 열린 장바구니, 저장되지 않은 수정 사항이 포함됩니다. 데이터를 지우기 전에 **Store health → Database**를 열어 보류 중이거나 서버에 도달한 적이 없는 항목이 없는지 확인한 다음, **Store health → Logs**에서 **0 stuck records** 및 **0 changes waiting to send**인지 확인하세요. 그런 다음 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 Store health 페이지가 없으면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 표시되거나 전송 대기 중이거나 확인할 수 없다면 데이터를 지우지 말고 매장 소유자에게 문의하거나 지원팀에 연락하세요.
:::

1, 3, 4단계로 해결되지 않았고 위 확인 절차를 마친 경우에만 로컬 데이터베이스를 초기화하세요:
- **데스크톱 앱:** 설정에서 "데이터 지우기"를 찾습니다
- **웹 브라우저:** POS 도메인의 사이트 데이터를 지웁니다
- **참고:** 매장에 이미 저장된 데이터는 다시 다운로드되지만, 매장에 전송된 적이 없는 데이터는 사라집니다

### 3. 브라우저 설정 확인 (웹) {#3-check-browser-settings-web}

웹 버전을 사용하는 경우:
1. IndexedDB가 활성화되어 있는지 확인
2. 개인/시크릿 모드를 사용하지 마십시오 (저장소 제한)
3. 사이트가 데이터를 저장하도록 허용

### 4. 권한 확인 {#4-check-permissions}

데스크톱에서:
- 앱이 데이터 디렉토리에 쓰기 권한이 있는지 확인
- 안티바이러스가 데이터베이스 접근을 차단하고 있는지 확인

### 5. 앱 재설치 {#5-reinstall-the-app}

:::warning 저장하지 않은 작업이 있는지 먼저 확인하세요
로컬 데이터를 지우거나 앱을 다시 설치하면 이 장치에 저장된 데이터 중 매장에 전송되지 않은 모든 항목이 삭제됩니다. 여기에는 오프라인에서 처리한 판매, 열린 장바구니, 저장되지 않은 수정 사항이 포함됩니다. 데이터를 지우기 전에 **Store health → Database**를 열어 보류 중이거나 서버에 도달한 적이 없는 항목이 없는지 확인한 다음, **Store health → Logs**에서 **0 stuck records** 및 **0 changes waiting to send**인지 확인하세요. 그런 다음 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 Store health 페이지가 없으면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 표시되거나 전송 대기 중이거나 확인할 수 없다면 데이터를 지우지 말고 매장 소유자에게 문의하거나 지원팀에 연락하세요.
:::

다른 해결 방법으로 해결되지 않았고 위 확인 절차를 마친 경우에만 진행하세요:
1. POS 앱을 제거하십시오
2. 장치를 재시작하십시오
3. 앱을 재설치하십시오
4. 로그인하고 데이터를 동기화하십시오

## 데이터 복구 {#data-recovery}

저장되지 않은 데이터가 있는 경우:
- 앱에 동기화되지 않은 변경 사항이 있을 수 있습니다
- 데이터 복구에 도움이 필요하면 지원팀에 문의하십시오
- 매장에 이미 저장된 데이터는 삭제 후 다시 다운로드되지만, 매장에 전송된 적이 없는 판매 데이터는 이 장치에만 있습니다. 데이터를 지우거나 앱을 다시 설치하면 해당 데이터가 삭제되므로 두 작업을 하기 전에 지원팀에 문의하세요
