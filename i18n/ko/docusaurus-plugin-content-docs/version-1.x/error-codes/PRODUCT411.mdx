## 이것이 의미하는 바 {#what-this-means}

바코드 스캔 설정을 불러올 수 없어 스캔 결과가 상품과 일치하지 않을 수 있습니다.

POS는 백그라운드에서 이 설정을 계속 불러오려고 시도합니다. 스캔이 계속 불안정하다면 앱을 한 번 새로 고치세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 계속 작업하세요. POS가 백그라운드에서 바코드 설정 불러오기를 다시 시도합니다.
2. 스캔이 계속 아무것도 찾지 못한다면 앱을 한 번 새로 고치세요.
3. 새로고침 후에도 계속되면 설정 요청 자체가 실패한 것입니다. 매장 연결을 확인하고 스토어 상태 → 로그에서 관련 오류를 찾으세요(도움이 필요하면 매장 관리자에게 문의하세요).
