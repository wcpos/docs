## 이것이 의미하는 바 {#what-this-means}

지금은 스토어에 연결할 수 없어 변경 사항이 이 기기에 남아 있게 됩니다.

연결 상태를 확인하고 오프라인으로 계속 작업하세요. 스토어에 다시 연결되면 동기화가 자동으로 재시도됩니다.

## 내 데이터 {#your-data}

변경 사항은 이 기기에 저장되었지만 스토어에는 전달되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 계속 판매하세요. 판매 내역은 이 기기에 저장되며 스토어가 응답하면 동기화가 자동으로 재개됩니다.
2. 계산대 자체가 온라인 상태인지 확인하세요. 이 기기에서 다른 웹사이트는 열리나요?
3. 같은 기기의 브라우저 탭에서 스토어 웹사이트를 열어 보세요. 그곳에서도 열리지 않는다면 POS가 아니라 사이트나 호스팅이 중단된 것입니다.
4. **이 기기의 네트워크 관리자:** 사이트는 열리는데 POS가 오프라인 상태라면 VPN, 방화벽, 광고 차단기 또는 보안 플러그인 등이 두 곳 사이의 API 요청을 차단하고 있을 수 있습니다. 브라우저 개발자 도구의 네트워크 탭이나 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 실패한 요청을 확인할 수 있습니다.
