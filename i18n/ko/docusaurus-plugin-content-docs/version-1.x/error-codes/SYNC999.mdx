## 이것이 의미하는 바 {#what-this-means}

동기화 중에 예기치 않은 문제가 발생했습니다.

이 항목에 표시된 작업이 완료되었는지 확인하세요. 완료되지 않았다면 다시 실행하세요. 반복되면 **디버그 정보 복사**를 눌러 지원팀에 보내세요.

## 내 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 반영되지 않은 변경 사항이 있을 수 있습니다. 항목에 표시된 작업이 완료되지 않았다면 다시 실행하세요.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 표시된 작업을 찾으세요. 작업이 완료되었는지 확인하세요. 저장 작업이라면 주문이나 레코드를 열어 변경 사항이 표시되는지 확인하세요. 완료되었다면 WCPOS가 자동으로 전송하므로 그대로 두세요.
2. 완료되지 않았다면 다시 실행하세요. 로그 항목에 변경 사항이 이 기기에 저장되지 않았다고 표시되면 기록된 내용이 없습니다.
3. 로그 항목의 코드와 사유를 기록하세요. 999 코드는 해당 원인에 아직 전용 코드가 없다는 뜻이므로, 이 내용이 바로 지원팀에 필요한 정보입니다.
4. 반복되면 **로그** 탭에서 **디버그 정보 복사**를 눌러 지원팀에 보내세요. 문제를 보고해야 해당 원인에 맞는 코드가 추가됩니다.
