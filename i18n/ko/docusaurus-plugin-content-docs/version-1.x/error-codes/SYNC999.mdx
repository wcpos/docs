## 이것이 의미하는 바 {#what-this-means}

동기화 중에 예기치 않은 문제가 발생했습니다.

이 기기에 이미 기록된 판매 내역은 안전합니다. 먼저 로그를 확인하세요(문제 해결 참고). 자동으로 다시 시도될 수 있으며, 쓰기 작업이 대기열에 도달하지 않았다면 다시 입력해야 할 수 있습니다. 이 코드가 계속 나타나면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

입력한 내용이 캡처되었다면 이 기기에 안전하게 저장되어 있으며 아직 매장에 도달하지 않은 상태입니다. 로그에 쓰기 작업이 대기열에 추가되기 전에 실패했다고 표시되면(문제 해결 2단계 참고) 다시 입력하세요. 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 이 코드가 항상 재시도된다고 가정하지 마세요. 먼저 로그 항목을 펼쳐 보세요. 변경 작업이 이미 대기열에 들어간 것으로 확인된다면 WCPOS가 자동으로 재시도하므로, 앱을 열어 둔 채 대기열이 비워지도록 두세요.
2. 엔진 레지던트가 없거나 변경 ID가 반환되기 전에 쓰기가 실패했다는 오류라면 대기열에 들어간 것이 없습니다. 해당 레코드나 주문으로 돌아가 다시 저장하세요.
3. 로그 항목을 펼쳐 이벤트 코드와 serverCode가 있다면 기록해 두세요. 999 코드는 구체적인 원인에 아직 전용 코드가 없다는 뜻이므로, 이 컨텍스트가 지원팀에 꼭 필요한 정보입니다.
4. 코드가 계속 나타난다면 디버그 정보 복사를 사용해 지원팀에 문의하세요. 이렇게 신고해 주셔야 전용 코드가 추가됩니다.
