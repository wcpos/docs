## 이 오류의 의미 {#what-this-means}

저장된 매장 세션이 완전하지 않아 WCPOS가 매장 목록으로 돌아갔습니다.

WCPOS는 POS가 중단된 지점부터 다시 시작할 수 있도록 열려 있던 사이트, 캐셔, 매장을 기억합니다. 이번에는 해당 기록의 일부(대개 사이트 또는 캐셔 항목)가 누락되어, 불완전한 세션으로 매장을 여는 대신 매장 목록으로 돌아갔습니다. 매장을 다시 선택해 로그인하세요. 이 확인 절차가 없었을 때는 이런 상태의 POS에 빈 화면 위로 빨간색 "useStoreSession must be called within an active store session" 배너가 표시되어 더 진행할 수 없었습니다.

대개 앱이 저장한 내용을 기기의 로컬 저장소가 보존하지 못했다는 뜻입니다. 한 번 발생한 경우는 기록해 두고, 같은 기기에서 반복되면 저장소 문제를 조사해야 합니다.

## 데이터 {#your-data}

열려 있던 세션을 가리키는 정보만 삭제되었습니다. 동기화를 기다리는 판매 내역을 포함한 매장의 로컬 데이터는 기기에 그대로 남아 있습니다.

사이트나 캐셔가 아직 목록에 있으면 같은 매장을 다시 선택해 동일한 로컬 데이터를 불러올 수 있습니다. 사이트를 다시 추가해야 했다면 POS는 매장의 새로운 로컬 사본을 엽니다. 이전 세션에서 동기화를 기다리던 판매 내역은 기기에 남아 있지만 자동으로 불러오지 않습니다. 동기화되지 않은 판매 내역이 있었다면 로컬 데이터를 지우기 전에 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 사이트와 매장을 다시 선택해 로그인하세요. 이 기기의 매장 데이터는 그대로이며, 기억된 세션 정보만 삭제되었습니다.
2. 사이트가 목록에 더 이상 없다면 주소를 다시 입력하고 로그인하세요. 동기화를 기다리는 판매 내역이 있었다면 먼저 지원팀에 문의하세요. 위의 "데이터"를 참고하세요.
3. 같은 기기에서 다시 발생하면 로컬 저장소가 앱의 기록 내용을 보존하지 못하는 것입니다. 디스크 여유 공간을 확인하고, 로그 화면에서 비슷한 시간대에 발생한 저장소 오류를 살펴보세요.
4. 계속 반복되면 디버그 정보를 내보내고 지원팀에 문의하세요. 로그 항목에서 세션의 어떤 부분이 누락되었는지 확인할 수 있습니다.
