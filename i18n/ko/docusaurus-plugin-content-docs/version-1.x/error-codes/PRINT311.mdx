## 이것이 의미하는 바 {#what-this-means}

이 영수증을 이메일로 보내거나 다운로드할 수 없었습니다.

판매는 저장되었습니다. 이메일 주소를 확인하세요. PDF의 경우 기기에 저장 공간이 있는지 확인한 다음 영수증에서 다시 시도하세요. 모든 이메일 전송이 실패하면 사이트 관리자가 매장의 이메일 전송 설정을 확인하도록 요청하세요.

## 내 데이터 {#your-data}

판매는 저장되었으며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 확인하세요. 이메일 주소가 표시되면 이메일 전송 실패이고, 그렇지 않으면 PDF 생성, 다운로드, 저장 또는 공유 실패입니다.
2. 이메일 전송의 경우 주소와 연결을 확인한 다음 영수증에서 다시 보내세요. 모든 이메일 전송이 실패하면 사이트 관리자에게 매장의 발신 이메일 및 SMTP 설정을 확인해 달라고 요청하세요.
3. PDF 오류라면 기기의 여유 저장 공간을 확인하고 영수증에서 PDF 다운로드를 다시 시도하세요. 다운로드 권한을 확인한 다음 쓰기 가능한 저장 위치나 사용할 수 있는 다른 공유 대상을 선택하세요.
