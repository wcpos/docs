# 오류 코드

WCPOS가 문제를 발견하면 문제를 식별하는 데 도움이 되는 오류 코드를 표시합니다. **v1.10.0**부터 코드는 **도메인 + 세 자리 숫자** 형식을 따릅니다 — 예를 들어 `SYNC131` 또는 `AUTH311`입니다. 도메인은 POS의 어느 영역인지를 나타내고, 숫자는 구체적인 상황을 식별합니다. 모든 코드에는 의미, 조치 방법, 데이터에 미치는 영향을 설명하는 전용 페이지가 있습니다.

POS에서는 오류 코드가 **스토어 상태 → 로그**에 표시됩니다. 행을 펼친 뒤 **도움말** 링크를 사용하면 이 문서의 해당 코드 페이지로 바로 이동합니다.

## 오류 도메인 (v1.10.0+) {#error-domains}

| 도메인 | 영역 | 예시 |
|--------|------|------|
| `AUTH` | 로그인, 세션, 토큰 | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | 계산대에서의 주문 완료 | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | POS 앱 자체 및 로컬 저장소 | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `LICENSE` | Pro 라이선스 활성화 및 검증 | [LICENSE101](./LICENSE101) |
| `PAYMENT` | 결제 게이트웨이 및 단말기 | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | 영수증 인쇄 | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | 상품 데이터 및 카탈로그 작업 | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `SYNC` | POS와 스토어 간 동기화 | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

사이드바를 사용하여 도메인의 모든 코드를 탐색하거나 코드를 직접 검색하세요.

`999`로 끝나는 코드는 아직 전용 코드가 없는 상황을 위한 해당 도메인의 포괄 코드입니다.

## 이전 코드 (v1.10.0 이전) {#legacy-codes}

v1.10.0 이전 버전은 다른 체계를 사용했습니다: `[DOMAIN][CATEGORY][SPECIFIC_CODE]` 형식이며, 예를 들어 `API04001` = API(도메인) + 04(응답 오류) + 001(유효하지 않은 응답 형식)입니다. 이전 버전을 사용 중이거나 오래된 로그 항목 또는 지원 스레드를 읽고 있다면 다음 페이지가 여전히 유효합니다:

| 도메인 | 총 코드 | 대상 |
|--------|-------------|---------------|
| [API](./api) | 39 코드 | 서버 통신, 인증, 플러그인 문제 |
| [DB](./db) | 9 코드 | 로컬 데이터 저장 및 검색 |
| [PY](./py) | 6 코드 | 결제 처리 |
| [SY](./sy) | 5 코드 | 장치 리소스 및 구성 |

v1.10.0 이상의 클라이언트는 이러한 코드를 생성하지 않습니다 — 최신 POS에서 이런 코드가 보인다면 보관 중인 오래된 로그 항목이거나 서버 측 메시지입니다.

## 도움이 더 필요하신가요? {#need-more-help}

문제 해결 단계를 따라도 여전히 문제가 발생하면:

1. 더 자세한 가이드를 보려면 [문제 해결](/support/troubleshooting/response-error) 섹션을 확인하세요.
2. 지원을 위해 [Discord 커뮤니티](https://wcpos.com/discord)에 참여하세요.
3. [GitHub](https://github.com/wcpos)에서 문제를 보고하세요.
