# 오류 코드 {#error-codes}

WCPOS에서 문제가 발생하면 문제를 파악하는 데 도움이 되는 오류 코드가 표시됩니다. **v1.10.0**부터 코드는 **도메인 + 세 자리 숫자** 형식을 따릅니다. 예를 들어 `SYNC131` 또는 `AUTH311`과 같습니다. 도메인은 POS의 영역을, 숫자는 구체적인 상태를 나타냅니다. 각 코드에는 코드의 의미와 조치 방법, 데이터에 미치는 영향을 설명하는 전용 페이지가 있습니다.

POS에서 오류 코드는 **매장 상태 → 로그**에 표시됩니다. 행을 펼친 다음 **도움말** 링크를 누르면 이 문서의 해당 코드 페이지로 바로 이동합니다.

## 오류 도메인 (v1.10.0 이상) {#error-domains}

| 도메인 | 영역 | 예시 |
|--------|------|----------|
| `AUTH` | 로그인, 세션 및 토큰 | [AUTH101](./AUTH101.mdx), [AUTH311](./AUTH311.mdx) |
| `CHECKOUT` | 계산대에서 주문 완료 | [CHECKOUT101](./CHECKOUT101.mdx), [CHECKOUT201](./CHECKOUT201.mdx) |
| `CLIENT` | POS 앱 자체 및 로컬 저장소 | [CLIENT101](./CLIENT101.mdx), [CLIENT201](./CLIENT201.mdx) |
| `HOST` | POS를 차단하는 호스팅 및 방화벽 규칙 | [HOST101](./HOST101.mdx), [HOST121](./HOST121.mdx) |
| `LICENSE` | Pro 라이선스 활성화 및 검증 | [LICENSE101](./LICENSE101.mdx) |
| `PAYMENT` | 결제 게이트웨이 및 단말기 | [PAYMENT101](./PAYMENT101.mdx), [PAYMENT301](./PAYMENT301.mdx) |
| `PRINT` | 영수증 인쇄 | [PRINT101](./PRINT101.mdx), [PRINT301](./PRINT301.mdx) |
| `PRODUCT` | 상품 데이터 및 카탈로그 작업 | [PRODUCT101](./PRODUCT101.mdx), [PRODUCT401](./PRODUCT401.mdx) |
| `SYNC` | POS와 매장 간 동기화 | [SYNC101](./SYNC101.mdx), [SYNC121](./SYNC121.mdx), [SYNC311](./SYNC311.mdx) |

사이드바에서 도메인의 모든 코드를 찾아보거나 코드를 직접 검색하세요.

`999`로 끝나는 코드는 아직 전용 코드가 없는 상황에 사용하는 해당 도메인의 포괄 코드입니다.

## 이전 코드 (v1.10.0 이전) {#legacy-codes}

v1.10.0 이전 버전에서는 `[DOMAIN][CATEGORY][SPECIFIC_CODE]` 형식의 다른 체계를 사용했습니다. 예를 들어 `API04001`은 API(도메인) + 04(응답 오류) + 001(잘못된 응답 형식)을 뜻합니다. 이전 버전을 사용하거나 오래된 로그 항목 또는 지원 스레드를 읽는 경우에도 다음 페이지가 유효합니다:

| 도메인 | 전체 코드 수 | 설명 |
|--------|-------------|---------------|
| [API](./api.mdx) | 코드 39개 | 서버 통신, 인증, 플러그인 문제 |
| [DB](./db.mdx) | 코드 9개 | 로컬 데이터 저장 및 검색 |
| [PY](./py.mdx) | 코드 6개 | 결제 처리 |
| [SY](./sy.mdx) | 코드 5개 | 장치 리소스 및 구성 |

v1.10.0 이상 클라이언트는 이러한 코드를 생성하지 않습니다. 최신 POS에서 이 코드가 보인다면 보관된 이전 로그 항목이거나 서버 측 메시지입니다.

## 도움이 더 필요하신가요? {#need-more-help}

문제 해결 단계를 따라도 문제가 계속되면 다음을 확인하세요:

1. 더 자세한 가이드를 보려면 [문제 해결](/support/troubleshooting/response-error) 섹션을 확인하세요.
2. 지원을 위해 [Discord 커뮤니티](https://wcpos.com/discord)에 참여하세요.
3. [GitHub](https://github.com/wcpos)에서 문제를 보고하세요.
