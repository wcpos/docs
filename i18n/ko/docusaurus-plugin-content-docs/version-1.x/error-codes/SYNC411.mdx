## 이것이 의미하는 바 {#what-this-means}

이 기기가 평소보다 훨씬 자주 스토어에 데이터를 요청했습니다.

느려지거나 차단된 것은 없으며 주문 데이터에도 영향이 없습니다. 이는 감지 전용 알림입니다. 요청 폭주가 지속되는 것은 대개 사용자의 조작 때문이 아니라 앱의 문제(어떤 화면이 같은 데이터를 반복해서 요청하는 루프)를 나타냅니다. 이 코드가 계속 나타난다면 진단 정보를 내보내고 지원팀에 문의하여 해당 루프를 찾아 수정할 수 있도록 해 주세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 계속 작업하세요. 이는 감지 전용 알림입니다. WCPOS는 어떤 요청도 늦추거나 대기시키거나 폐기하지 않으며, 주문이나 상품 데이터에도 영향이 없습니다.
2. 코드가 한 번 나타났다가 멈춘다면 조치할 것이 없습니다. 반복된다면 그때 어떤 화면이 열려 있었고 어떤 작업을 하고 있었는지 기록해 두세요.
3. 이벤트가 로그 창에 남아 있을 때 디버그 정보 복사를 사용하고 WCPOS 지원팀에 문의하세요. 내보낸 정보로 지원팀에서 요청 반복을 추적할 수 있습니다.
