## 이것이 의미하는 바 {#what-this-means}

로그인된 스토어 계정이 이 계산대의 계산원과 일치하지 않습니다.

계산원마다 자신의 계산대 데이터를 별도로 보관하므로, 다른 계정으로 작업하면 주문이 잘못 기록될 수 있습니다. 로그아웃한 다음 해당 계산원 본인의 계정으로 로그인하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. POS는 각 계산원의 데이터를 보호하기 위해 스스로 세션을 로그아웃합니다. 계정 간에 주문 데이터가 섞이지 않습니다.
2. 해당 계산원 본인의 계정으로 다시 로그인하세요. 다른 계정으로 작업하면 주문이 잘못 기록될 수 있습니다.
3. 여러 계산원이 계산대를 공유한다면 인수인계 절차에 계정 전환을 포함하세요.
