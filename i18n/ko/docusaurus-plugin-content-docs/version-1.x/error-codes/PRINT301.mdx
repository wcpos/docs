## 이것이 의미하는 바 {#what-this-means}

선택한 프린터에 연결할 수 없습니다.

프린터의 전원이 켜져 있고 연결되어 있는지 확인한 다음 인쇄를 다시 시도하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 프린터의 전원이 켜져 있는지, 케이블이나 네트워크 연결이 제대로 꽂혀 있는지 확인하세요.
2. 로컬 네트워크를 통해 POS와 직접 통신하는 프린터라면 POS와 프린터가 같은 네트워크에 연결되어 있는지, 프린터 주소가 바뀌지 않았는지 확인하세요. DHCP 갱신으로 주소가 바뀔 수 있습니다. 주소가 바뀌었다면 POS에서 프린터를 설정한 위치에서 주소를 업데이트하세요.
3. 클라우드로 인쇄하는 영수증은 POS와 프린터가 같은 네트워크를 사용할 필요가 없습니다. 확인할 항목은 전송 방식에 따라 다릅니다([클라우드 인쇄](../receipts/cloud-printing.mdx#status)):
   - **Star CloudPRNT 또는 Epson Server Direct Print**(프린터가 WCPOS를 폴링함): 프린터가 연결을 확인할 때까지 POS의 프린터 카드에 **대기 중**이 표시됩니다. 프린터가 인터넷에 연결되어 있고 폴링 URL과 토큰이 WCPOS에서 생성한 값과 일치하는지 확인하세요. [프린터가 대기 중 상태에서 멈춤](../receipts/cloud-printing.mdx#troubleshooting)을 참조하세요.
   - **Star Online**: 카드에는 Star Online에서 보고하는 기기 상태가 표시됩니다. 기기 상태가 **오프라인** 또는 **알 수 없음**이라면 POS가 아니라 Star Online 대시보드에서 확인해야 합니다.
   - **PrintNode**: PrintNode 데스크톱 클라이언트를 실행하는 컴퓨터가 켜져 있고 클라이언트가 온라인이어야 합니다. 또한 POS에서 선택한 프린터가 클라이언트에 표시되는 프린터와 일치해야 합니다. [PrintNode 작업이 인쇄되지 않음](../receipts/cloud-printing.mdx#troubleshooting)을 참조하세요.
4. 프린터에서 직접 자체 테스트를 인쇄해 하드웨어가 정상인지 확인한 다음 POS에서 다시 시도하세요.
