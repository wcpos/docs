## 이것이 의미하는 바 {#what-this-means}

선택한 프린터에 연결할 수 없습니다.

프린터의 전원이 켜져 있고 연결되어 있는지 확인한 다음 인쇄를 다시 시도하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 프린터의 전원이 켜져 있는지, 케이블이나 네트워크 연결이 제대로 꽂혀 있는지 확인하세요.
2. 네트워크 프린터라면 계산대와 프린터가 같은 네트워크에 있고 프린터 주소가 바뀌지 않았는지 확인하세요. DHCP 갱신으로 주소가 바뀔 수 있습니다. 주소가 바뀌었다면 POS에서 프린터를 설정한 위치에서 주소를 업데이트하세요.
3. 프린터에서 직접 자체 테스트를 인쇄해 하드웨어가 정상인지 확인한 다음 POS에서 다시 시도하세요.
