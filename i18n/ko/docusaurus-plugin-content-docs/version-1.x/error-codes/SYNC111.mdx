## 이것이 의미하는 바 {#what-this-means}

로컬 스토어 데이터가 손상되어 동기화를 계속하려면 복구가 필요합니다.

영향을 받은 데이터에 대해 대상 복구를 실행하고, 문제가 다시 발생하는 경우에만 해당 로컬 데이터를 초기화하세요.

## 내 데이터 {#your-data}

이 기기의 데이터가 위험할 수 있습니다. 로컬 데이터를 지우지 마세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 스토어 상태 → 데이터베이스를 열고 영향을 받은 데이터에 대해 대상 복구를 실행하세요. 전체 초기화는 복구보다 더 많은 것을 삭제합니다.
2. 실패했던 작업을 다시 시도한 다음, 스토어 상태 → 로그에서 이 코드가 다시 나타나는지 지켜보세요.
3. 같은 데이터가 다시 표시된다면 해당 로컬 데이터만 초기화해 스토어에서 새로 내려받도록 하세요. 단, 전송되지 않은 변경 사항을 먼저 기록해 둔 후에만 진행하세요.
4. 손상이 계속 재발한다면 기기 저장 장치의 고장을 의심할 수 있습니다. 디버그 정보를 내보내고 지원팀에 문의하세요.
