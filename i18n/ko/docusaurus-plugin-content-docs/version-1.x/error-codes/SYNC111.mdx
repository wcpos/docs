## 이것이 의미하는 바 {#what-this-means}

이 기기에 저장된 일부 데이터가 손상되어 동기화할 수 없습니다.

**로그** 탭 상단에서 **디버그 정보 복사**를 탭해 WCPOS 지원팀에 보내세요. WCPOS를 재설치하거나 로그아웃하거나 데이터를 지우지 마세요. 매장에 아직 도착하지 않은 변경 사항은 이 기기에만 있습니다.

## 내 데이터 {#your-data}

이 기기의 데이터를 지우지 마세요. 매장에 아직 도착하지 않은 판매 내역이 있을 수 있습니다. 앱을 재설치하거나 로그아웃해도 판매 내역이 삭제될 수 있습니다. 특정 종류의 데이터를 다시 다운로드해도 안전한지는 지원팀에서 알려줄 수 있습니다.

## 문제 해결 {#troubleshoot}

1. WCPOS가 계속 작동한다면 판매를 계속하세요. 앱을 재설치하거나 로그아웃하거나 데이터를 지우지 마세요.
2. **로그** 탭 상단에서 **디버그 정보 복사**를 탭해 WCPOS 지원팀에 보내고, 로그 항목이 표시될 때 무엇을 하고 있었는지도 알려주세요.
3. **매장 상태 → 데이터베이스**를 열고 표시된 **전송 대기 중인 변경 사항**의 수와 **"…개 변경 사항이 서버에 도달하지 않았습니다"** 또는 **"…개 변경 사항이 보류되었습니다"** 패널이 표시되는지 지원팀에 알려주세요. 해당 변경 사항은 이 기기에만 있습니다.
4. 로그 항목에는 어떤 데이터가 손상되었는지 표시되지 않습니다. 전송 대기 중인 항목이 없으면 지원팀에서 한 종류의 데이터를 다시 다운로드하라고 안내할 수 있습니다(해당 행의 **⋮** 메뉴 → **지우고 다시 다운로드…**). 지원팀이 확인하기 전에는 실행하지 마세요. 잘못된 데이터를 지우거나 변경 사항이 전송 대기 중일 때 지우면 매장에 도착하지 않은 판매 내역이 삭제될 수 있습니다. 손상 때문에 변경 사항을 전송할 수 없는 경우 지원팀에서 먼저 복구합니다. 전송 대기 중인 항목이 하나라도 있으면 다시 다운로드하지 마세요.
