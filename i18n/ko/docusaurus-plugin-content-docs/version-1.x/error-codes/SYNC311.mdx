## 이것이 의미하는 바 {#what-this-means}

이 기기의 데이터는 다른 버전의 WCPOS에서 저장되어 아직 열 수 없습니다.

WCPOS를 최신 버전으로 업데이트한 뒤 다시 여세요. 그래도 열리지 않으면 **디버그 정보 복사**를 탭하고 지원팀에 문의하세요. 이 문제는 보통 이 기기에서 앱을 업데이트하거나 이전 버전으로 되돌린 뒤 발생합니다.

:::warning 이 기기의 데이터를 지우지 마세요
이 기기에는 매장에 아직 도착하지 않은 판매 내역이 있을 수 있습니다. 예를 들어 오프라인 상태에서 처리한 판매가 그렇습니다. 데이터를 열 수 없는 동안에는 전송할 수 없으므로 로컬 데이터베이스를 지우거나 로그아웃하거나 재설치하면 영구적으로 삭제됩니다. 무엇이든 지우기 전에 지원팀에 문의하세요.
:::

## 내 데이터 {#your-data}

이 기기의 데이터를 지우지 마세요. 매장에 아직 도착하지 않은 판매 내역이 있을 수 있습니다. 매장에 저장된 데이터는 안전하며 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. 이 기기의 WCPOS를 최신 버전으로 업데이트한 뒤 다시 여세요:
   - **웹:** 브라우저 탭을 새로고침하세요. 이전 버전이 다시 표시되면 새로고침하는 동안 **Shift** 키를 누르세요. 매장의 WCPOS 플러그인이 웹에서 불러올 버전을 결정하므로 새로고침해도 해결되지 않으면 사이트 관리자에게 WCPOS 플러그인 업데이트를 요청하세요.
   - **데스크톱:** 대기 중인 업데이트를 설치하고 앱을 다시 여세요. 업데이트가 제공되지 않으면 [설치](/getting-started/installation) 페이지에서 최신 빌드를 다운로드하세요.
   - **iPhone, iPad 또는 Android:** 설치한 경로를 통해 WCPOS를 업데이트하세요. iOS에서는 TestFlight, Android에서는 Play 테스트 프로그램을 이용합니다. 두 링크 모두 [설치](/getting-started/installation) 페이지에 있습니다.
2. 그래도 열리지 않으면 **로그** 탭에서 **디버그 정보 복사**를 탭하고 지원팀에 문의하세요. 이 기기에 매장에 도착하지 않은 판매 내역이 있을 수 있는지도 알려주세요.
3. 기다리는 동안 로컬 데이터를 지우거나 로그아웃하거나 재설치하지 마세요. 이 기기에서 먼저 복구해야 할 데이터가 있는지 지원팀이 안내해 드립니다.
