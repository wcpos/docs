## 이것이 의미하는 바 {#what-this-means}

로컬 데이터가 호환되지 않는 버전의 것이어서 아직 열 수 없습니다.

이 기기에 스토어로 전달되지 않은 변경 사항이 있을 수 있다면 영향을 받은 로컬 컬렉션을 초기화하지 마세요. 초기화하면 유일한 로컬 사본이 삭제됩니다. 지원팀이 조사할 수 있도록 진단 정보를 내보낸 다음, 복구 방법에 대해 지원팀에 문의하세요.

## 조치 방법 {#what-to-do}

진단 정보를 내보내고 지원팀에 문의하세요. 위의 변경을 적용한 후에 재시도하세요. 변경하지 않고 재시도하면 같은 방식으로 실패합니다.

## 내 데이터 {#your-data}

이 기기의 데이터가 위험할 수 있습니다. 로컬 데이터를 지우지 마세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 영향을 받은 컬렉션을 초기화하거나 삭제하지 마세요. 이 기기에 스토어로 전달되지 않은 변경 사항이 있다면 로컬 사본이 유일한 사본입니다.
2. 이 기기에서 최근에 앱을 업데이트하거나 다운그레이드했는지 확인하세요. 앱과 저장된 데이터 간의 버전 불일치가 일반적인 원인입니다.
3. 이 기기에서 WCPOS를 최신 버전으로 업데이트한 다음 스토어를 다시 여세요.
4. 그래도 컬렉션이 열리지 않는다면 로컬 데이터를 건드리기 전에 디버그 정보 복사를 사용해 복구 방법을 지원팀에 문의하세요.

## 확인할 위치 {#where-to-look}

WCPOS가 이 오류를 저장할 수 있는 경우, 오류는 이를 발생시킨 기기에 기록됩니다. **스토어 상태 → 로그**(내비게이션 서랍 하단의 심박 아이콘)를 열고 이 코드가 표시된 항목을 찾아 펼치세요. 펼쳐진 행에는 알기 쉽게 설명된 원인과 오류가 발생한 시점에 수집된 컨텍스트가 표시됩니다. 스토어 요청의 경우 이 컨텍스트에 서버 자체의 오류 코드(`serverCode`), HTTP `status` 또는 `endpoint`가 포함될 수 있으며, 표시되는 필드는 오류가 발생한 위치에 따라 다릅니다. 문제를 신고할 때는 스크린샷 대신 로그 화면 상단의 **디버그 정보 복사**(휴대폰과 태블릿에서는 **디버그 정보 공유**)를 사용하세요. 여기에는 앱 버전, 연결 상태, 가장 최근의 오류가 함께 담깁니다. 로그는 최대 30일간만 보관되므로 문제가 발생한 직후에 수집하세요. 또한 POS가 자체 로그 항목을 기록하기 전에 나타난 브라우저 콘솔 오류가 있다면 함께 복사하세요.

앱 내 로그 외에도 이 오류는 다음 위치에 흔적을 남길 수 있습니다:

- **콘솔**(웹 및 데스크톱): 동일한 개발자 도구의 **콘솔** 탭에는 클라이언트 측 오류가 기록되며, POS가 자체 로그 항목을 기록하기 전에 발생한 오류도 포함됩니다.
