## 이것이 의미하는 바 {#what-this-means}

이 기기에 저장된 데이터는 다른 앱 버전의 데이터이므로 열 수 없습니다.

기기의 로컬 데이터베이스를 지운 뒤 앱을 다시 여세요. 그러면 WCPOS에서 매장의 데이터를 다시 다운로드합니다. 이 기기에서 앱을 업데이트하거나 이전 버전으로 되돌린 뒤 스키마가 일치하지 않는 경우가 많습니다.

:::warning 동기화되지 않은 데이터가 삭제됩니다
로컬 데이터베이스를 지우면 **이 기기에 저장되어 매장과 아직 동기화되지 않은 모든 데이터가 영구적으로 삭제됩니다**. 오프라인 상태에서 발생한 판매가 그 예입니다. 데이터베이스를 열 수 없어 먼저 동기화할 수 없으므로 복구할 수 없습니다. 이 기기에 중요한 미동기화 판매 내역이 있다면 삭제하기 **전에** 지원팀에 문의하세요.
:::

## 내 데이터 {#your-data}

매장 데이터는 안전하며 다음에 앱을 열 때 다시 다운로드됩니다. 기기의 로컬 사본만 삭제되며, 매장에 아직 도달하지 않은 변경 사항도 포함됩니다(위 경고 참고).

## 문제 해결 {#troubleshoot}

1. 이 기기의 WCPOS가 최신 버전인지 확인하세요. 스키마가 일치하지 않는 문제는 버전 변경 후 발생하는 경우가 많습니다.
2. 로컬 데이터베이스를 지운 뒤 앱을 다시 여세요. 앱 내 버튼, 웹 앱, 데스크톱 앱을 다루는 [모든 로컬 데이터 지우기](/support/troubleshooting/clear-local-data)의 안내를 따르세요. WCPOS에서 매장 데이터를 자동으로 다시 다운로드합니다. (이 기기의 미동기화 데이터는 삭제됩니다. 위 경고를 참고하세요.)
3. 삭제한 뒤에도 오류가 다시 발생하면 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
