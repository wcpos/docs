## 이것이 의미하는 바 {#what-this-means}

스토어 앞단의 프록시가 헤더가 너무 많다는 이유로 서버의 응답을 거부합니다.

캐시 또는 프록시 계층(일반적으로 Varnish)이 응답 헤더의 개수나 크기에 제한을 적용합니다. 스토어의 가벼운 엔드포인트는 제한에 들어맞지만, 전체 API 응답은 제한을 초과하여 WordPress가 아니라 프록시에서 503으로 돌아옵니다. 해당 계층에서 제한을 높여야 합니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터는 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. Varnish에서는 http_max_hdr(헤더 개수)와 http_resp_hdr_len / http_resp_size(크기)를 높이세요.
2. 어느 프록시 계층이 503을 반환하는지 호스트에 문의하세요 — 요청이 그곳에서 실패하는 것이 아니므로 WordPress 오류 로그에는 아무것도 표시되지 않습니다.
3. 빠른 확인 방법: 스토어의 /wcpos/v2/ping은 정상적으로 응답하는 반면 데이터 엔드포인트는 503을 반환합니다.
