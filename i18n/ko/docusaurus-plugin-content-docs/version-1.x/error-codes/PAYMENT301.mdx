## 이것이 의미하는 바 {#what-this-means}

선택한 결제 게이트웨이를 이 스토어에서 사용할 수 없습니다.

사이트 관리자에게 해당 게이트웨이가 지원되고 활성화되어 있으며 올바르게 구성되어 있는지 확인해 달라고 요청하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서:** 현금 등 다른 결제 수단으로 먼저 판매를 완료하세요.

**매장에서** — 사이트 관리자:

1. WooCommerce → 설정 → 결제에서 결제 게이트웨이를 확인하세요. 설치 및 활성화되어 있어야 하며 POS 설정에서도 POS용으로 활성화되어야 합니다.
2. 결제 게이트웨이가 어제까지 작동했다면 결제 게이트웨이 또는 WooCommerce가 업데이트되었는지 확인하세요. WooCommerce → 상태 → 로그에 결제 게이트웨이 초기화 오류가 기록되어 있을 수 있습니다.
