## 의미 {#what-this-means}

이 매장에는 이제 더 최신 버전의 POS 앱이 필요합니다.

매장의 WCPOS 플러그인이 이 앱 버전에서 지원하는 것보다 최신 동기화 프로토콜로 변경되었습니다. 따라서 앱이 업데이트될 때까지 매장에서 의도적으로 동기화를 일시 중지합니다. 이는 오류가 아니라 보호 기능으로, 오래된 앱이 매장 데이터를 잘못 읽거나 쓰는 것을 방지합니다.

## 데이터 {#your-data}

판매 단말기의 데이터는 손실되지 않습니다. 전송 대기 중인 판매 및 수정 사항은 기기에 안전하게 보관되며, 업데이트된 앱이 매장에 연결되면 동기화됩니다. 아직 최신 앱이 없는 경우(아래 마지막 두 단계 참조)에는 앱이 제공될 때까지 대기열에 유지됩니다.

## 문제 해결 {#troubleshoot}

1. 웹 앱에서는 브라우저 탭을 새로고침하세요. 웹 앱은 새로고침할 때 새 버전을 적용합니다. 화면이 다시 표시되면 강력 새로고침을 사용하세요(새로고침하는 동안 **Shift** 키를 누름).
2. 데스크톱에서는 대기 중인 업데이트를 설치한 후 앱을 다시 여세요. 앱이 다시 연결될 때 확인이 실행됩니다. 업데이트가 제공되지 않으면 [설치](/getting-started/installation) 페이지에서 최신 빌드를 다운로드하세요.
3. iPhone, iPad 또는 Android에서는 설치한 경로를 통해 WCPOS를 업데이트하세요. iOS에서는 TestFlight, Android에서는 Play 테스트 프로그램을 사용합니다. 두 경로 모두 [설치](/getting-started/installation) 페이지에서 연결할 수 있습니다. 그런 다음 앱을 다시 여세요.
4. **사이트 관리자:** 아직 최신 앱을 사용할 수 없는 경우, 매장의 WCPOS 플러그인이 해당 앱 릴리스보다 먼저 업데이트된 것입니다. 매장에서 이전 WCPOS 플러그인 버전으로 복원하면 최신 앱이 출시될 때까지 동기화가 재개됩니다.
5. 앱 업데이트나 플러그인 롤백을 모두 사용할 수 없는 경우 WCPOS 지원팀에 문의하세요.
