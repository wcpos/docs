## 이것이 의미하는 바 {#what-this-means}

이 기기의 저장소가 응답을 멈춰 저장이 일시 중지되었습니다.

WCPOS를 다시 시작하세요(웹에서는 탭을 새로고침하세요). 그런 다음 마지막 판매 내역이나 변경 사항이 저장되었는지 확인하세요. 저장소가 응답을 멈추기 직전 몇 초 동안의 변경 사항은 기록되지 않았을 수 있습니다. 이 기기의 데이터를 삭제하지 마세요. 문제가 계속되면 지원팀에 문의하세요.

## 내 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 전송되지 않은 판매 내역이 들어 있을 수 있습니다. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. WCPOS를 다시 시작하세요. 앱을 닫았다가 다시 여세요. 웹에서는 탭을 닫지 말고 새로고침하세요. 이렇게 하면 대부분의 경우 로컬 데이터베이스에 다시 연결됩니다.
2. 다시 시작한 후 마지막 판매 내역이나 변경 사항이 저장되었는지 확인하세요. 실패 직전의 변경 사항은 기록되지 않았을 수 있습니다. 표시되지 않으면 다시 입력하세요.
3. 웹에서는 시크릿 창에서 POS를 실행하지 말고 저장소를 공격적으로 정리하는 확장 프로그램을 피하세요. 둘 다 세션 도중 로컬 저장소를 제거할 수 있으며, 시크릿 창을 닫으면 전송하지 않은 판매 내역을 포함해 그 안에 저장된 모든 데이터가 삭제됩니다. 지금 시크릿 창을 사용 중이라면 **매장 상태 → 데이터베이스**에 **전송 대기 중인 변경 사항**이 0으로 표시될 때까지 창을 열어 두세요.
4. 같은 기기에서 이 문제가 자주 발생하면 문제가 발생했을 때 기기가 어떤 상태였는지(절전, 탭 전환, 메모리 부족) 적어 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
