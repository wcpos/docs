## 이것이 의미하는 바 {#what-this-means}

이 기기의 로컬 데이터베이스가 응답을 멈춰 이를 필요로 하는 작업이 일시 중지되었습니다.

WCPOS를 다시 시작해 로컬 데이터베이스에 다시 연결하세요. 이 기기에서 저장되지 않은 변경 사항이 기록되지 않았을 수 있으므로, 다시 시작한 후 최근 주문을 확인하세요. 문제가 계속되면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

이 기기의 데이터가 위험할 수 있습니다. 로컬 데이터를 지우지 마세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. WCPOS를 다시 시작하세요. 앱(또는 브라우저 탭)을 닫았다가 다시 열면 거의 모든 경우에 로컬 데이터베이스가 다시 연결됩니다.
2. 다시 시작한 후 가장 최근의 주문을 확인하세요. 오류 발생 직전 몇 초 사이에 이루어진 변경은 기록되지 않았을 수 있습니다.
3. 웹에서는 시크릿 창과 저장소를 공격적으로 정리하는 확장 프로그램을 피하세요. 두 경우 모두 세션 도중에 로컬 저장소를 없앨 수 있습니다.
4. 같은 기기에서 이 문제가 자주 재발한다면 디버그 정보를 내보내고, 발생 당시 기기가 무엇을 하고 있었는지(절전, 탭 전환, 메모리 부족) 기록해 지원팀에 문의하세요.
