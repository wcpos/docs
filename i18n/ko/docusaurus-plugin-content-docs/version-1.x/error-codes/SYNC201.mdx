## 이것이 의미하는 바 {#what-this-means}

이 레코드는 스토어에서 거부되어 이 기기에만 저장되어 있습니다.

해당 레코드에 표시된 사유를 수정한 다음 다시 시도하세요. 계속 거부된다면 진단 정보를 내보내세요.

## 내 데이터 {#your-data}

변경 사항은 이 기기에 저장되었지만 스토어에는 전달되지 않았습니다. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 보세요. 거부된 레코드의 이름과 스토어가 거부한 자체 사유(serverCode)가 함께 표시됩니다.
2. 거부된 레코드는 스토어 상태에 나열됩니다. 해당 레코드를 열어 스토어가 거부한 항목을 수정한 다음 그곳에서 다시 시도하세요.
3. **사이트 관리자:** POS에 표시되지 않는 필드가 원인으로 언급되면 WP Admin에서 같은 레코드를 열어 확인하세요. 다른 플러그인이 POS에서 확인할 수 없는 유효성 검사를 추가했을 수 있습니다.
4. 수정 후에도 계속 거부된다면 디버그 정보 복사를 사용해 serverCode를 포함시켜 지원팀에 문의하세요.
