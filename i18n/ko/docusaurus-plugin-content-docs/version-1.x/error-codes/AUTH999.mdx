## 이것이 의미하는 바 {#what-this-means}

로그인하거나 로그인 상태를 유지하는 중에 예기치 않은 문제가 발생했습니다.

작업을 한 번 더 시도하세요. 다시 발생하면 로그아웃했다가 다시 로그인한 다음 **디버그 정보 복사**를 사용해 지원팀에 문의하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 **디버그 정보 복사**를 사용해 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 해당 작업을 한 번 더 시도하고, 다시 실패하면 로그아웃했다가 다시 로그인하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 serverCode가 있다면 기록해 두세요. 999 코드는 아직 전용 코드가 없는 원인이라는 뜻이므로, 이 컨텍스트가 원인을 식별하는 유일한 단서입니다.
3. 문제가 재발하면 디버그 정보 복사를 사용해 지원팀에 문의하세요.
