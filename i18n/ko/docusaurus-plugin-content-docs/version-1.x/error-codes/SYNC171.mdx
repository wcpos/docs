## 이것이 의미하는 바 {#what-this-means}

이 기기에서 로컬 데이터베이스를 만들거나 제거할 수 없었습니다.

WCPOS를 다시 시작하고 다시 시도하세요. 계속 실패한다면 기기의 저장 공간이 부족하거나 브라우저 프로필이 저장소를 제한하고 있을 수 있습니다. 공간을 확보한 다음에도 문제가 계속되면 지원팀에 문의하세요.

## 내 데이터 {#your-data}

기기의 로컬 데이터베이스를 설정하거나 지울 수 없습니다. 동기화되지 않은 편집 내용의 문제가 아니라 저장 공간 또는 설정 문제입니다. 저장 공간을 확보한 뒤 다시 시도하세요. 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. WCPOS를 다시 시작하고 같은 작업을 다시 시도하세요. 대부분의 설정 실패는 일시적입니다.
2. 기기의 여유 저장 공간을 확인하세요. 디스크나 브라우저의 저장소 할당량이 가득 차면 로컬 데이터베이스 생성이 아예 실패합니다.
3. 웹에서는 브라우저가 해당 사이트에 대해 영구 저장소를 허용하는지 확인하세요. 시크릿 창이나 모든 데이터 차단 설정에서는 허용되지 않습니다.
4. 계속 실패한다면 디버그 정보를 내보내고 지원팀에 문의하세요.
