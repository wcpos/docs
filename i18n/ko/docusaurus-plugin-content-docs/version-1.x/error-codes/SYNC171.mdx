## 이것이 의미하는 바 {#what-this-means}

WCPOS가 이 기기에서 저장소를 설정하거나 제거하지 못했습니다.

기기의 저장 공간을 확보한 다음 WCPOS를 다시 시작하세요. 웹에서는 브라우저가 사이트의 저장소 사용을 제한할 수도 있습니다. 시크릿 창에서도 제한됩니다. 문제가 계속되면 지원팀에 문의하세요.

## 내 데이터 {#your-data}

이는 편집이 거부된 문제가 아니라 저장소 문제입니다. 이 기기의 데이터를 지우는 중에 발생했다면 전송하지 않은 변경 사항을 포함해 데이터 일부가 이미 사라졌을 수 있습니다. 최근 판매 내역과 변경 사항이 매장에 표시되는지 확인하세요. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 기기의 여유 저장 공간을 확인하고 다른 파일이나 앱을 제거해 공간을 확보하세요. 디스크나 브라우저 저장소 할당량이 가득 차면 저장소 설정이 완전히 실패합니다. 공간을 확보하려고 브라우저의 "Clear browsing data"를 사용하지 마세요. WCPOS에서 아직 전송하지 않은 판매 내역도 삭제됩니다.
2. WCPOS를 다시 시작하고 같은 작업을 다시 시도하세요.
3. 웹에서는 브라우저가 해당 사이트에 대해 영구 저장소를 허용하는지 확인하세요. 시크릿 창이나 모든 데이터 차단 설정에서는 허용되지 않습니다.
4. 계속 실패하면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
