## 이것이 의미하는 바 {#what-this-means}

WCPOS가 결제 완료 여부를 확인할 수 없었습니다.

다시 시도하기 전에 주문을 열어 상태를 확인하세요. 결제가 완료되었거나 주문 상태가 완료됨이면 다시 청구하지 마세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 다시 시도하기 전에 확인하세요. 이 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 주문 상태를 확인할 때까지 **결제 처리**를 다시 누르거나 고객에게 다시 청구하지 마세요.
2. 주문을 열어 상태를 확인하세요. WCPOS Pro에서는 먼저 계산대의 주문을 새로 고치세요 — **매장 상태 → 데이터베이스**에서 **주문** 행의 **⋮** 메뉴를 열고 **지금 변경 사항 확인**을 선택한 다음 **주문**에서 해당 주문을 여세요. Pro를 사용하지 않는 경우, 누군가 WP Admin에서 **WooCommerce → 주문**을 열고 합계와 최근 몇 분을 기준으로 검색하도록 요청하세요.
3. 주문을 찾았다고 충분한 것은 아닙니다. 결제되지 않은 주문도 있을 수 있습니다. 상태가 **처리 중** 또는 **완료됨**이면 판매가 완료된 것이므로 다시 청구하지 마세요.
4. 주문이 아직 미결제 상태이거나 찾을 수 없다면 고객이 결제했는지 확인하세요 — 카드 결제는 결제 제공업체의 화면, 영수증 또는 대시보드에서, 현금 결제는 금전함과 받은 금액을 확인하세요. 결제가 완료되었다면 다시 청구하지 마세요. 주문을 찾았다면 앱을 다시 불러와 상태를 다시 확인하세요(앱을 시작할 때 계산대는 결제 기록이 있는 판매를 마무리합니다). 주문을 찾을 수 없거나 여전히 미결제라면 마지막 단계로 넘어가세요.
5. 주문이 미결제이고 결제 제공업체에 청구 내역이 없다면 결제 절차를 한 번 다시 시도하세요.
6. 여전히 불분명하다면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 다시 시도하기 전에 지원팀에 문의하세요.
