## 이것이 의미하는 바 {#what-this-means}

WCPOS가 결제 완료 여부를 확인할 수 없었습니다.

무작정 재시도하지 마세요. 먼저 스토어에서 주문을 확인하고, 그래도 결과가 불분명하다면 진단 정보를 내보내세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 재시도하기 전에 실제 상태를 확인하세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**상황을 악화시키지 마세요:** 주문이 있는지 확인하기 전에는 결제를 다시 시도하거나 고객에게 다시 청구하지 마세요.

**주문이 있는지 확인하세요** — 접근 가능한 항목에 따라 방법이 다릅니다. WCPOS Pro에서는 POS를 동기화하고 계산대의 주문 목록을 확인하세요. 그렇지 않으면 누군가 WP Admin에서 WooCommerce → 주문을 열고 합계와 최근 몇 분을 기준으로 검색해야 합니다. 주문이 있으면 판매가 완료된 것이므로 다시 만들지 마세요.

**그다음:** 확인 후에도 주문이 없으면 결제를 한 번 다시 시도하세요. 여전히 확실하지 않다면 다시 시도하기 전에 디버그 정보를 내보내고 지원팀에 문의하세요.
