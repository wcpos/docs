## 이것이 의미하는 바 {#what-this-means}

스토어가 결제 결과를 반환하지 않아 주문 상태를 알 수 없습니다.

결제를 다시 시도하기 전에 주문이 생성되었는지 확인하세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 재시도하기 전에 실제 상태를 확인하세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**먼저 주문이 있는지 확인하세요** — 빈 응답은 주문은 생성됐지만 확인 응답이 도착하지 않았다는 뜻일 수 있습니다. WCPOS Pro에서는 POS를 동기화하고 계산대의 주문 목록을 확인하세요. 그렇지 않으면 누군가 WP Admin의 WooCommerce → 주문에서 확인해야 합니다. 주문이 생성되지 않았음을 확인한 경우에만 결제를 다시 시도하세요.

**매장에서** — 사이트 관리자:

1. WooCommerce → 상태 → 로그에서 결제 중 발생한 치명적 오류를 확인하세요. 주문 생성 후의 PHP 충돌이 정확히 이런 결과를 만듭니다.
2. WooCommerce 로그에 아무것도 없다면 호스팅 업체에 서버의 PHP 오류 로그를 요청하세요. 일부 치명적 오류는 그곳에만 기록됩니다.

**개발자의 경우:** 브라우저 개발자 도구 또는 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 네트워크 탭의 결제 요청을 확인하세요. 성공 상태인데 응답 본문이 비어 있거나 잘렸다면 플러그인 또는 서버 버퍼가 응답을 자르고 있을 수 있습니다.
