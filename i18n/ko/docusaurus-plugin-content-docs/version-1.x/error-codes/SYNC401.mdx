## 이것이 의미하는 바 {#what-this-means}

백그라운드 동기화 작업이 완료되기 전에 예기치 않게 중단되었습니다.

할 일은 없습니다. POS가 이러한 작업을 자동으로 다시 시작하며 손실된 내용은 없습니다. 이 코드가 계속 표시되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

손실된 내용은 없습니다. 주문 또는 상품 데이터에는 영향이 없습니다. 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 처음 보였을 때는 조치할 것이 없습니다. POS가 중단된 백그라운드 작업을 자동으로 다시 시작하며 주문 데이터는 관련이 없습니다.
2. 몇 분 안에 코드가 반복된다면 앱을 한 번 새로 고쳐 동기화 엔진이 깨끗한 상태로 시작하도록 하세요.
3. 계속 반복되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요. 작업이 반복해서 중단되는 것은 매장 문제가 아니라 보고할 가치가 있는 앱 결함입니다.
