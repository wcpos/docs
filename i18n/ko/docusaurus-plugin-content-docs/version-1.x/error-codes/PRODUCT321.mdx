## 이것이 의미하는 바 {#what-this-means}

이 바코드와 일치하는 상품이 두 개 이상입니다.

WCPOS가 그중 하나를 안전하게 고를 수 없으므로 아무것도 추가되지 않았습니다. 상품을 이름으로 검색하고, 충돌을 해결하려면 스토어에서 각 상품에 고유한 바코드를 지정하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 스토어 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서:** 바코드가 둘 이상의 상품과 일치해 스캔으로는 아무것도 추가되지 않았습니다. 판매를 완료하려면 상품명을 검색하세요.

로그 항목에는 스캔한 코드와 일치한 상품 수가 기록됩니다. POS에서 해당 바코드 값을 검색하면 어떤 상품들인지 확인할 수 있습니다.

**매장에서 (WP Admin):** 해당 상품마다 고유한 바코드를 지정한 다음 다시 스캔해 일치 항목이 하나만 남는지 확인하세요.
