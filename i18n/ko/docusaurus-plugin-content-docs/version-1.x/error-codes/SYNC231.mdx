## 이 오류의 의미 {#what-this-means}

매장에서 이 변경 사항을 받았지만, 이 기기에서 전송 완료 사실을 기록하지 못했습니다.

따로 할 일은 없습니다. 다시 입력하지 마세요. WCPOS가 계속 확인하며, 매장은 중복 전송을 무시합니다.

판매 또는 수정 사항은 매장에 도착해 저장되었습니다. 그 후 이 기기는 변경 사항이 전송되었다고 기록하려고 연속으로 세 번 시도했지만 실패했습니다. 따라서 이 기기에서는 여전히 미전송으로 표시되고, 다음 동기화 때 WCPOS가 다시 보냅니다. 매장은 ID로 변경 사항을 식별하고 중복 전송을 무시하므로 두 번 저장되지 않습니다. 실제로 주의할 점은 누군가 판매 또는 수정 사항을 직접 다시 입력하는 경우입니다. 그러면 별도의 사본이 하나 더 생깁니다.

## 데이터 상태 {#your-data}

데이터는 손실되지 않았습니다. 매장에 변경 사항이 이미 있습니다. 이 기기에서 재전송 완료가 기록될 때까지 전송 대기 중으로 표시될 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 판매 또는 수정 사항을 직접 다시 입력하지 마세요. 매장에 이미 저장되어 있으며, 다시 입력하면 중복 항목이 생깁니다.
2. 판매가 매장에 도착했는지 확인하려면 WP Admin의 **WooCommerce → 주문**에서 확인하세요. 이 기기에 저장되어 있으므로 WCPOS에도 표시됩니다.
3. WCPOS가 동기화되도록 두세요. 다음 재전송은 매장에서 무시하며, 보통 해당 항목이 사라집니다. 사라지면 **매장 상태 → 로그** 헤더의 **전송 대기 중인 변경 사항** 수가 줄어듭니다.
4. 이 메시지가 계속 표시되면 기기 자체 저장소에 문제가 있을 수 있습니다. 여유 저장 공간을 확인한 다음 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 문의하세요. 해결을 위해 이 기기의 데이터를 삭제하지 마세요.
