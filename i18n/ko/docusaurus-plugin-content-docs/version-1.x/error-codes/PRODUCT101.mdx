## 이것이 의미하는 바 {#what-this-means}

이 상품을 스토어에 저장할 수 없었습니다.

재시도하기 전에 보고된 원인을 검토하세요. 네트워크 오류라면 다시 연결하고, 잘못된 필드는 수정하며, 충돌하는 상품은 새로 고치세요.

## 내 데이터 {#your-data}

보고된 원인을 해결할 때까지 수정 내용은 이 기기에 남아 매장에 전송되지 않습니다. 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 보세요. 오류 문구를 통해 네트워크 오류인지, 스토어가 거부한 필드인지, 스토어에서 이루어진 충돌 편집인지 대개 알 수 있습니다.

**계산대에서:**
- 네트워크 오류: 연결을 확인하고 재시도하세요. 편집 내용은 이 기기에 보관됩니다.
- 거부된 필드: 표시된 필드를 수정하고 재시도하세요.

**매장에서 (WP Admin):** 수정 내용이 충돌한다면 상품을 열고 버전을 비교한 다음 올바른 값을 다시 적용하세요.

뚜렷한 원인 없이 저장이 계속 실패한다면 디버그 정보를 내보내고 지원팀에 문의하세요.
