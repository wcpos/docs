## 이것이 의미하는 바 {#what-this-means}

이 상품 변경 사항은 아직 매장에 전달되지 않았습니다.

표시된 이유를 확인하고 해당 문제를 해결하거나 연결을 확인한 다음 상품을 다시 저장하세요.

## 내 데이터 {#your-data}

이 기기의 데이터를 지우지 마세요. 매장에 아직 전달되지 않은 변경 사항이 들어 있을 수 있습니다. 연결 문제였다면 연결된 후 상품을 다시 저장하세요. 매장에서 수정을 거부한 경우 이 기기는 매장의 버전으로 되돌아갑니다([SYNC202](/error-codes/SYNC202) 참조). 따라서 이유를 해결한 뒤 다시 수정하세요. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 표시된 이유를 확인하세요. 로그 항목의 오류 텍스트에서 연결 실패인지, 매장에서 거부한 값인지, 매장에서 발생한 충돌 편집인지 대개 확인할 수 있습니다.

**계산대에서:**

- 연결 실패: 연결을 확인한 다음 상품을 다시 저장하세요.
- 거부된 값: 이유에 표시된 내용을 수정한 다음 상품을 다시 저장하세요.

**매장에서 (WP Admin):** 편집 충돌이 발생했다면 상품을 열어 계산대에 표시된 내용과 비교하고 올바른 값을 한 번 저장하세요.

명확한 이유 없이 저장이 계속 실패하면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
