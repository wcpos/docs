## 이것이 의미하는 바 {#what-this-means}

이 변경 사항을 장바구니에 적용할 수 없었으며 장바구니는 그대로입니다.

상품, 수수료, 배송 항목 또는 쿠폰이 추가되지 않았으며 삭제된 항목도 없습니다. 작업을 다시 시도하세요.

## 내 데이터 {#your-data}

주문 자체는 안전하며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 품목, 수수료, 배송 라인 또는 쿠폰을 다시 추가해 보세요. 장바구니 자체는 변경되지 않았습니다.
2. 같은 품목에서 계속 실패한다면 다른 상품으로 한 번 시도해 보세요. 특정 품목만 실패하면 그 레코드의 문제이고, 모든 항목이 실패하면 기기의 문제입니다.
3. 계속 실패한다면 WCPOS를 다시 시작하세요. 그래도 문제가 계속되면 디버그 정보를 내보내고 지원팀에 문의하세요.
