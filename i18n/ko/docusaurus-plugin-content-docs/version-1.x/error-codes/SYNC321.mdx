## 이것이 의미하는 바 {#what-this-means}

일부 데이터가 이번에 동기화되지 않았습니다.

이 코드는 두 가지 형태로 나타납니다. 로그 행의 제목으로 어떤 경우인지 확인할 수 있습니다:

- **"부분 동기화"**(레코드 제목): 일부 레코드는 동기화되었지만 표시된 레코드는 동기화되지 않았습니다. 다음 동기화에서 해결되면 할 일이 없습니다. **스토어 상태 → 데이터베이스**에 조치가 필요한 변경 사항이 표시되면 해당 항목을 처리하세요.
- **"Gave up on a stuck data request"**: 동기화 엔진의 데이터 요청 대기열에서 요청 하나가 더 이상 진행되지 않아, 앱은 뒤에 대기 중인 모든 요청이 막히지 않도록 충분히 기다린 후 해당 요청을 중단했습니다. 직접 다시 시도할 필요는 없습니다. 동기화 엔진에서 요청을 자동으로 다시 보냅니다. 이 문제는 별도로 기록되는 로컬 데이터베이스 호출 지연([SYNC181](/error-codes/SYNC181)) 뒤에 자주 발생합니다.

## 내 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 반영되지 않은 변경 사항이 있을 수 있습니다. 중단된 데이터 요청의 경우 변경된 내용이 없으며 해당 요청은 자동으로 다시 전송됩니다. 계속 발생하면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. **"멈춘 데이터 요청 중단"** 항목의 경우 화면이 멈춘 상태로 남아 있지 않다면 할 일이 없습니다. 화면이 멈춰 있으면 앱을 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱 및 모바일에서는 앱을 닫았다가 다시 여세요.
2. 부분 동기화의 경우 다음 동기화에서 해결되면 할 일이 없습니다. 해결되지 않으면 **스토어 상태 → 데이터베이스**를 여세요. 여전히 동기화되지 않은 레코드가 맨 위에 표시됩니다. **"… 조치가 필요한 레코드"** 알림에는 사유와 함께 첫 번째 레코드가 표시됩니다(해당 레코드를 수정하면 다음 레코드가 표시됨). **"… 서버에 전달되지 않은 변경 사항"** 및 **"… 보류된 변경 사항"** 패널에도 해당 항목이 표시됩니다. 동기화된 레코드는 조치할 필요가 없습니다.
3. 각 레코드는 해당 사유에 따라 처리하세요. 알림에서 **레코드 수정**(표시되는 경우)을 누르면 레코드를 열어 수정할 수 있습니다. 거부된 변경은 레코드 자체에서 수정하세요([SYNC201](/error-codes/SYNC201)). 보류된 변경은 유지할 버전을 선택하세요([SYNC221](/error-codes/SYNC221)).
4. 그런 다음 다시 전송하세요. 알림에서 **다시 시도**(동기화를 실행함)를 누르거나 패널의 레코드 행에서 **다시 보내기**를 누르세요. 알림에 *매장에서 다운로드할 수 없음*이라고 표시된 레코드에는 **다시 시도**가 없습니다. [SYNC331](/error-codes/SYNC331)을 참조하세요.
5. 레코드가 계속 동기화되지 않으면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
