## 이것이 의미하는 바 {#what-this-means}

일부 레코드는 동기화되었지만 하나 이상의 레코드는 동기화되지 않았습니다.

이 코드는 두 가지 형태로 나타납니다. 로그 행의 제목으로 어떤 경우인지 확인할 수 있습니다:

- **"Sync partial"**(레코드 제목): 일부 레코드는 동기화되었지만 이름이 표시된 레코드는 동기화되지 않았습니다. 해당 레코드만 다시 시도하기 전에 각 레코드와 이유를 확인하세요.
- **"Gave up on a stuck data request"**: 동기화 엔진의 데이터 요청 대기열에서 요청 하나가 더 이상 진행되지 않아, 앱은 뒤에 대기 중인 모든 요청이 막히지 않도록 충분히 기다린 후 해당 요청을 중단했습니다. 직접 다시 시도할 필요는 없습니다. 동기화 엔진에서 요청을 자동으로 다시 보냅니다. 이 문제는 별도로 기록되는 로컬 데이터베이스 호출 지연([SYNC181](/error-codes/SYNC181)) 뒤에 자주 발생합니다.

## 내 데이터 {#your-data}

동기화되지 않은 레코드의 경우 변경 사항은 이 기기에 저장되어 있지만 매장에는 도달하지 않았습니다. 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요. 중단된 데이터 요청의 경우 아무것도 변경되지 않았으며 중단된 요청은 자동으로 다시 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 부분 동기화의 경우 로그 항목을 펼쳐 동기화되지 않은 레코드와 각각의 이유를 확인하세요.
2. 표시된 각 레코드를 사유에 맞게 처리하세요. 잘못된 필드는 수정해야 하고, 충돌은 스토어와 비교해야 합니다.
3. 실패한 레코드만 다시 시도하세요. 나머지는 이미 동기화되었으므로 조치할 것이 없습니다.
4. "Gave up on a stuck data request" 항목이라면 화면이 멈춘 상태로 유지되는 경우가 아니면 별도의 조치가 필요하지 않습니다. 화면이 계속 멈춰 있으면 앱을 새로고침하세요. 문제가 계속되면 디버그 정보를 내보내고 지원팀에 문의하세요.
