## 이것이 의미하는 바 {#what-this-means}

로그인 토큰이 이 서버가 허용하는 크기보다 큽니다.

서버가 크기를 이유로 로그인 토큰을 거부했습니다: Authorization 헤더로 전달될 때는 400, URL로 전달될 때는 414. 클라이언트 측 인코딩으로는 토큰을 줄일 수 없습니다 — 서버의 헤더/URL 크기 제한을 높이거나 토큰을 더 작게 만들어야 합니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터는 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. Apache에서는 vhost 설정에서 LimitRequestFieldSize(헤더 경로) 또는 LimitRequestLine(URL 경로)을 높이세요.
2. nginx에서는 large_client_header_buffers를 높이세요.
3. 프록시나 CDN 뒤에 있는 경우 제한이 그 계층에 있을 수 있습니다 — 양쪽 모두 확인하세요.
4. 제한을 변경할 수 없는 경우, 이 사이트에 더 작은 토큰을 발급하는 것에 관해 지원팀에 문의하세요.
