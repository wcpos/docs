# SY01002: 디스크 가득 참 {#sy01002-disk-full}

## 이것이 의미하는 바 {#what-this-means}

기기의 저장 공간이 가득 찼습니다. POS는 데이터를 저장하거나 사용 가능한 디스크 공간 없이 작동을 계속할 수 없습니다.

## 일반적인 원인 {#common-causes}

- **스토리지 가득 참** — 드라이브에 무료 공간 없음
- **대용량 로컬 데이터베이스** — 상당한 공간을 차지하는 POS 데이터
- **임시 파일** — 공간을 차지하는 임시 파일
- **다른 애플리케이션** — 디스크를 채우고 있는 다른 앱들

## 해결 방법 {#how-to-fix}

### 1. 디스크 공간 확보 {#1-free-up-disk-space}

불필요한 파일을 삭제합니다:
- 휴지통/재활용통 비우기
- 오래된 다운로드 삭제
- 사용하지 않는 애플리케이션 삭제
- 임시 파일 지우기

### 2. 사용 가능한 공간 확인 {#2-check-available-space}

**Windows:**
- 파일 탐색기 열기
- 드라이브를 우클릭 → 속성
- 사용 중인 공간과 무료 공간 보기

**macOS:**
- 애플 메뉴 → 이 Mac에 관하여
- 저장 공간 클릭

### 3. 브라우저 데이터 지우기 (웹 버전) {#3-clear-browser-data-web-version}

:::warning 저장되지 않은 작업이 있는지 먼저 확인하세요
기기의 로컬 데이터를 지우거나 앱을 다시 설치하면 오프라인에서 처리한 판매, 열린 장바구니, 저장되지 않은 수정 사항 등 매장에 전달되지 않은 기기의 모든 데이터가 삭제됩니다. 데이터를 지우기 전에 **매장 상태 → 데이터베이스**를 열어 서버에 아직 전달되지 않았거나 보류 중인 항목이 없는지 확인한 다음, **매장 상태 → 로그**에서 **멈춘 레코드 0개**와 **전송 대기 중인 변경 사항 0개**인지 확인하세요. 그런 다음 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 매장 상태 페이지가 없으면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 있거나 대기 중인 내용이 있거나 확인할 수 없다면 데이터를 지우지 말고 매장 소유자에게 문의하거나 지원팀에 연락하세요.
:::

브라우저는 POS 데이터를 로컬에 저장합니다. 위의 확인을 마친 경우에만 다음을 진행하세요:
- 캐시 및 쿠키 지우기
- 오래된 사이트 데이터 삭제
- 브라우저 저장 공간 사용량 확인

### 4. 대용량 파일 이동 또는 삭제 {#4-move-or-delete-large-files}

대용량 파일을 찾아서 처리합니다:
- 오래된 비디오 또는 사진
- 대용량 다운로드
- 사용하지 않는 소프트웨어
- 외부 저장소로 이동할 수 있는 백업 파일

### 5. POS 데이터 확인 {#5-check-pos-data}

POS 데이터가 매우 클 경우:
- 로컬 데이터베이스 정리가 필요할 수 있음
- 3단계의 확인을 마친 경우에만 데이터 삭제와 재동기화를 고려하세요.
- 오래된 데이터 삭제 가능 여부 확인

## 권장하는 무료 공간 {#recommended-free-space}

최소한 유지하십시오:
- **10GB** 정상 작동을 위해 무료
- **20GB+** 대규모 카탈로그를 위해
- 여유 공간이 많을수록 좋습니다

## 향후 문제 예방 {#preventing-future-issues}

- 정기적으로 불필요한 파일을 정리
- 자동 임시 파일 정리 설정
- 디스크 공간 사용량 모니터링
- 자주 가득 찬 경우 더 큰 저장소 고려
