## 이것이 의미하는 바 {#what-this-means}

결제가 완료되지 않았지만 장바구니는 그대로여서 안전하게 다시 시도할 수 있습니다.

장바구니를 검토한 후 결제를 다시 시도하세요. 현재 장바구니 내용은 그대로 유지되었습니다.

## 내 데이터 {#your-data}

주문 자체는 안전하며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔:

1. 장바구니를 검토하고(내용은 변경되지 않았습니다) 결제를 다시 시도하세요.
2. 다시 실패하면 스토어 상태 → 로그에서 로그 항목을 펼치세요. serverCode와 상태를 보면 매장에서 주문을 거부했는지, 이유가 무엇인지 알 수 있습니다.
3. 원인에 특정 라인 항목이 명시되어 있다면 해당 항목을 제거하고 판매를 완료한 다음, 그 상품을 나중에 조사하세요.

**매장에서** — 사이트 관리자: 500번대 상태 코드와 함께 반복해서 실패한다면 사이트 문제입니다. WooCommerce → 상태 → 로그에서 실패 시각의 PHP 오류를 확인하세요.
