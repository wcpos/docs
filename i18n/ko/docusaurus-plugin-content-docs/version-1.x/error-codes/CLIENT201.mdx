## 이것이 의미하는 바 {#what-this-means}

기기의 메모리가 부족해 마지막 작업이 완료되지 않았을 수 있습니다.

다른 앱이나 탭을 닫고 WCPOS를 다시 시작한 다음 마지막 판매 또는 변경 사항이 저장되었는지 확인하세요. 저장되지 않았다면 다시 처리하세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 다시 시도하기 전에 확인하세요. 메모리가 부족해질 때 판매 또는 변경 사항을 저장 중이었다면 다시 처리하기 전에 저장 여부를 확인하세요.

## 문제 해결 {#troubleshoot}

1. 다른 앱이나 브라우저 탭을 닫으세요. WCPOS는 기기에서 실행 중인 다른 모든 프로그램과 메모리를 공유합니다.
2. WCPOS를 다시 시작하세요.
3. 다시 처리하기 전에 마지막 판매 또는 변경 사항이 저장되었는지 확인하세요. **매장 상태 → 데이터베이스**(판매가 **전송 대기 중인 변경 사항**에 포함되면 저장된 상태로 전송 중임), 장바구니, 주문(WCPOS Pro) 또는 **WooCommerce → 주문**을 살펴보세요. 카드 결제가 관련되었다면 단말기나 결제 제공업체에서도 확인하세요. 고객이 결제했다면 다시 청구하지 마세요. 실제로 저장되지 않은 경우에만 한 번 다시 처리하세요.
4. 특정 작업에서 반복적으로 메모리가 부족해진다면 어떤 작업이었는지 기록하고 **로그** 탭에서 **디버그 정보 복사**를 누른 다음 지원팀에 문의하세요.
5. 같은 기기에서 매일 발생한다면 카탈로그 규모에 비해 기기 사양이 부족할 수 있습니다. 지원팀이 확인할 수 있도록 신고해 주세요.
