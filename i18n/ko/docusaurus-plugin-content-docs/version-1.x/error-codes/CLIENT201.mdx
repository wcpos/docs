## 이것이 의미하는 바 {#what-this-means}

WCPOS의 메모리가 부족하여 작업을 완료할 수 없었습니다.

WCPOS를 다시 시작하고 한 번 재시도하세요. 기기의 메모리가 또 부족해지면 진단 정보를 내보내세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 메모리가 부족해졌을 때 저장 중이었다면 다시 시도하기 전에 저장이 완료됐는지 확인하세요.

## 문제 해결 {#troubleshoot}

1. WCPOS를 다시 시작하세요. 메모리가 부족해졌을 때 저장 중이었다면 다시 시도하기 전에 완료 여부를 확인하고, 완료되지 않았을 때만 한 번 다시 시도하세요.
2. 다른 앱이나 브라우저 탭을 닫으세요. POS는 기기에서 실행 중인 다른 모든 프로그램과 메모리를 공유합니다.
3. 특정 작업에서 항상 메모리가 부족해진다면 어떤 작업인지 기록해 두고 디버그 정보와 함께 지원팀에 문의하세요.
4. 같은 기기에서 매일 발생한다면 카탈로그 규모에 비해 기기 사양이 부족할 수 있습니다. 지원팀이 확인할 수 있도록 신고해 주세요.
