## 의미 {#what-this-means}

이 기기의 시계와 매장 시계의 차이가 1분을 넘습니다.

이 기기의 날짜와 시간이 자동으로 업데이트되도록 설정하세요. 이미 자동 업데이트 중이라면 사이트 관리자에게 서버 시계를 확인해 달라고 요청하세요.

WCPOS는 이 기기의 시계와 매장 서버가 응답에 표시하는 시간을 비교합니다. 두 시간의 차이가 1분을 넘으면 두 시계가 일치할 때까지 주문 시간, 영수증, 보고서가 부정확할 수 있습니다.

## 데이터 {#your-data}

판매 내역은 계속 저장됩니다. 두 시계가 일치하지 않는 동안 기록된 시간만 올바르지 않을 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼치면 두 시계의 차이와 어느 쪽이 앞서는지 확인할 수 있습니다.
2. 이 기기의 날짜 및 시간 설정을 열고 자동 네트워크 시간과 시간대를 켜세요.
3. **사이트 관리자:** 기기가 이미 자동 업데이트로 설정되어 있고 시간이 정확하다면 서버 시계가 잘못된 것입니다. 호스트에 서버의 날짜, 시간 및 시간대를 확인해 달라고 요청하세요.
4. 문제를 해결한 뒤 WCPOS를 다시 여세요. 매장을 열 때마다 시계를 다시 비교하며, 두 시계가 일치하면 경고가 사라집니다.
