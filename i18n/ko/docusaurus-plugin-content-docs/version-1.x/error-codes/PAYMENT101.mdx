## 이것이 의미하는 바 {#what-this-means}

결제는 성공했지만 WCPOS가 이후 상태를 새로 고치지 못했습니다.

결제가 완료되었습니다. 다시 청구하지 마세요. 주문을 다시 열어 상태를 업데이트하고, 여전히 최신 상태가 아닌 것 같으면 아래 설명에 따라 새로고침하세요.

## 내 데이터 {#your-data}

결제가 완료되었습니다. 다시 청구하지 마세요. 화면에 표시된 상태만 최신 정보가 아닙니다.

## 문제 해결 {#troubleshoot}

1. 고객에게 다시 청구하지 마세요. 매장의 결제 페이지에서 결제가 확인되었습니다(**주문 #… 결제 완료** 알림이 표시되었다면 결제가 확인된 것입니다). 계산대의 후속 업데이트만 실패했습니다.
2. 주문을 다시 열어 상태를 업데이트하고 다음 판매를 진행하세요.
3. 결제된 주문이 장바구니에 계속 미결 주문으로 표시되면 계산대에 저장된 주문 정보를 새로고침하세요. **매장 상태 → 데이터베이스**를 열고 **주문** 행의 **⋮** 메뉴를 연 다음 **지금 변경 사항 확인**을 선택하세요. 결제 상태가 반영되면 주문이 장바구니에서 사라집니다. WCPOS Pro에서는 해당 주문만 새로고침할 수도 있습니다. **주문**에서 주문의 **⋮** 메뉴를 열고 **동기화**를 선택하세요.
4. 계속 미결 상태로 표시되면 앱을 다시 불러오세요(웹에서는 브라우저 탭을 새로고침하고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요). 앱이 시작되면 계산대가 결제를 기록해 둔 판매를 마무리합니다.
5. **사이트 관리자:** 확실히 하려면 **WooCommerce → 주문**에서 주문을 여세요. 해당 주문이 결제 완료로 표시됩니다.
