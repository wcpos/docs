## 이것이 의미하는 바 {#what-this-means}

결제는 성공했지만 WCPOS가 이후 상태를 새로 고치지 못했습니다.

결제는 완료되었으므로 다시 청구해서는 안 됩니다. 표시된 상태가 계속 최신이 아닌 경우가 아니라면 별도의 조치가 필요하지 않습니다.

## 내 데이터 {#your-data}

결제가 성공해 실제로 대금을 받았습니다. 고객에게 다시 청구하지 마세요. 화면의 상태만 오래된 정보입니다.

## 문제 해결 {#troubleshoot}

1. 조치할 사항이 없습니다. 결제는 완료되었고 이후의 상태 새로 고침만 실패했습니다.
2. 고객에게 다시 청구하지 마세요.
3. 계산대에서 주문 상태가 최신이 아닌 것처럼 보인다면 주문을 다시 열거나 동기화하세요. 스토어에는 이미 올바른 상태가 반영되어 있습니다.
