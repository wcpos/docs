## 이것이 의미하는 바 {#what-this-means}

상품을 불러오거나 업데이트하는 중에 예기치 않은 문제가 발생했습니다.

하던 작업을 다시 시도하고 저장되었는지 확인하세요. 상품이 계속 잘못 표시되면 **디버그 정보 복사**를 누르고 지원팀에 보내세요.

## 내 데이터 {#your-data}

판매 및 주문에는 영향이 없습니다. 상품을 변경 중이었다면 변경 사항이 저장되었는지 확인하세요.

## 문제 해결 {#troubleshoot}

1. 하던 작업을 다시 시도하고 저장되었는지 확인하세요. 대부분의 일시적인 상품 불러오기 문제는 두 번째 시도에서 해결됩니다.
2. 상품이 계속 잘못 표시되면 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 보내세요.
