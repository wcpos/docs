## 이것이 의미하는 바 {#what-this-means}

상품을 불러오거나 업데이트하는 중에 예기치 않은 문제가 발생했습니다.

다시 시도하세요. 그 후에도 상품 데이터가 잘못되어 보인다면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 다시 시도하세요. 일시적인 상품 불러오기 문제는 대부분 재시도하면 해결됩니다.
2. 그래도 상품 데이터가 잘못되어 보인다면 로그 항목을 펼쳐 이벤트 코드와 컨텍스트를 확인하세요. 이 일반 코드는 아직 전용 코드가 없는 원인이라는 뜻입니다.
3. 문제가 재발하면 디버그 정보를 내보내고 지원팀에 문의하세요.
