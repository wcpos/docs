## 이것이 의미하는 바 {#what-this-means}

매장의 변경 사항 목록이 예기치 않게 바뀌어 WCPOS가 자동으로 다시 확인하고 있습니다. 손실된 내용은 없습니다.

할 일은 없습니다. 계속 판매하세요. WCPOS가 매장의 변경 사항을 자동으로 다시 확인합니다. 가격이나 재고가 여전히 최신 상태가 아닌 것 같으면 **스토어 상태 → 데이터베이스**에서 **지금 모두 확인**을 누르세요.

## 내 데이터 {#your-data}

손실된 내용은 없으며 이 기기의 어떤 내용도 위험하지 않습니다. 다시 확인이 끝날 때까지 이 기기의 일부 가격이나 재고가 최신 상태가 아닐 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 계속 판매하세요. 이 기기의 내용은 손실되지 않으며 다시 확인은 자동으로 실행됩니다. 로그 항목에 변경된 내용이 표시될 수 있습니다. 예를 들어 일부 매장 변경 사항이 건너뛰어졌거나 매장 목록이 이전 상태로 돌아갔다고 표시될 수 있습니다. 어느 경우든 어떤 종류의 데이터든 해당할 수 있습니다.
2. 가격이나 재고가 여전히 최신 상태가 아닌 것 같으면 **스토어 상태 → 데이터베이스**를 열고 **지금 모두 확인**을 누르세요.
3. 확인 후에도 레코드가 잘못된 것 같거나 이 코드가 계속 다시 나타나면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요. 문제를 해결하려고 데이터를 삭제하지 마세요.
