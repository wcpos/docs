## 이것이 의미하는 바 {#what-this-means}

매장의 응답에 불필요한 텍스트가 있어 WCPOS가 이를 정리하려고 했습니다.

수행 중이던 작업이 완료되었는지 확인하세요. 정리가 항상 성공하는 것은 아닙니다. 불필요한 텍스트는 대개 플러그인이나 PHP 알림이 매장 응답에 추가 출력을 기록해서 발생합니다. 자주 표시되면 사이트 관리자에게 사이트의 PHP 오류 로그에서 경고를 확인해 달라고 요청하세요.

## 내 데이터 {#your-data}

수행 중이던 작업이 완료되지 않았다면(문제 해결의 1단계 참조) 해당 요청의 안내를 따르세요. 그렇지 않으면 주문이나 상품 데이터에는 영향이 없습니다. 자주 표시되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. 수행 중이던 작업이 완료되었는지 확인하세요. 예를 들어 판매 내역이나 변경 사항이 표시되는지 확인하세요. 완료되었다면 더 할 일은 없습니다. 완료되지 않았다면 다시 시도하세요. 그래도 실패하면 표시되는 오류에 따른 안내를 따르거나 지원팀에 문의하세요.
2. 원인은 사이트 쪽에 있습니다. 플러그인이나 테마가 REST 응답에 경고나 불필요한 출력을 함께 내보내고 있습니다. 사이트 관리자에게 오류 발생 시각의 PHP 알림을 사이트 로그에서 확인해 달라고 요청하세요.
3. **사이트 관리자용:** 브라우저 개발자 도구의 네트워크 탭이나 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 원시 응답 본문을 확인할 수 있습니다. 불필요한 출력은 JSON 바로 앞이나 뒤에 표시됩니다.
4. **사이트 관리자용:** 정리는 최선의 노력으로 수행됩니다. 자주 표시되면 정리에 의존하지 말고 문제를 일으키는 플러그인을 수정하세요.
