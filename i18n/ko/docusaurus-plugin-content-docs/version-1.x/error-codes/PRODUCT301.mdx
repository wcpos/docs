## 이것이 의미하는 바 {#what-this-means}

스캔하거나 입력한 검색어와 일치하는 상품을 찾지 못했습니다.

일반적인 원인은 필터가 적용되어 있거나, 바코드가 없거나 다른 필드에 저장되어 있거나, 첫 동기화가 아직 끝나지 않은 경우입니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**계산대에서:**

1. 먼저 필터를 지우세요. 카테고리 또는 재고 필터가 적용되면 모든 검색 결과가 알림 없이 제한됩니다(스캔한 코드도 같은 검색창에 입력됩니다).
2. 상품명을 검색하세요. 상품이 표시되지만 스캔으로 찾지 못했다면 매장에 저장된 바코드가 스캔 값과 일치하지 않습니다. 검색어를 입력했다면 철자와 불필요한 공백을 확인하세요.
3. 새 상품이라면 로컬 색인이 아직 동기화 중일 수 있습니다. 첫 동기화가 끝날 때까지 기다린 다음 다시 시도하세요.

**매장에서:**

- 바코드가 없다면 WP Admin에서 상품의 바코드 필드에 스캔한 값을 추가하세요.
- 모든 스캔이 실패한다면 POS가 잘못된 필드를 읽고 있을 수 있습니다. POS 바코드 설정에서 매장이 바코드를 저장하는 필드를 확인하세요.
