## 의미 {#what-this-means}

로컬 검색에서 카탈로그와 일치하지 않는 결과가 반환되었습니다. 앱이 검색 색인을 자동으로 다시 빌드합니다.

검색에 즉시 응답하기 위해 WCPOS는 상품, 고객, 주문 등 검색 대상 목록의 로컬 검색 색인을 유지합니다. 자체 검사에서 해당 색인에 입력한 내용과 실제로 일치하지 않는 항목이 발견되었습니다. 일치하지 않는 결과는 즉시 숨겨졌으며, 앱은 색인 자체를 수정하기 위해 세션당 각 목록에 대해 한 번 자동으로 색인을 다시 빌드합니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았습니다. 이 문제는 이 기기에 이미 있는 데이터에서 파생된 로컬 검색 색인에만 해당합니다. 일치하지 않는 결과를 숨겨도 검색에 표시되는 내용만 변경되며, 원본 레코드는 변경되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 일반적으로 별도의 조치는 필요하지 않으며 판매를 정상적으로 계속할 수 있습니다. 다만 로그 항목에 표시된 검색을 다시 실행하고(컨텍스트에 검색어가 기록됨), 이제 결과가 입력한 내용과 일치하며 예상한 항목이 누락되지 않았는지 확인하세요.
2. 존재하는 것으로 알고 있는 상품, 고객 또는 주문이 검색 결과에 계속 표시되지 않으면 앱을 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱 및 모바일에서는 앱을 닫았다가 다시 여세요. 그러면 다음에 문제가 감지될 때 앱이 새 색인 빌드를 시도할 수 있습니다.
3. 새로고침 후에도 코드가 다시 표시되면 디버그 정보를 내보내고 지원팀에 문의하세요. 항목의 컨텍스트에는 영향을 받은 목록과 이를 유발한 검색이 표시됩니다.
