## 의미 {#what-this-means}

검색 결과에 상품과 일치하지 않는 항목이 있어 WCPOS에서 숨겼습니다.

검색 결과가 여전히 잘못된 경우가 아니라면 할 일은 없습니다. 문제가 있다면 WCPOS를 새로고침하세요.

검색 결과를 빠르게 보여 주기 위해 WCPOS는 상품, 고객, 주문 등 검색 대상 목록의 로컬 검색 색인을 유지합니다. 자체 점검에서 색인 항목이 입력한 내용과 일치하지 않는 것을 발견했습니다. 일치하지 않는 결과는 즉시 숨겼습니다. 앱이 색인을 자동으로 다시 빌드할 수도 있지만 세션당 목록별 한 번뿐이므로 재빌드가 보장되지는 않습니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았습니다. 이 문제는 이 기기에 이미 있는 데이터에서 파생된 로컬 검색 색인에만 해당합니다. 일치하지 않는 결과를 숨겨도 검색에 표시되는 내용만 변경되며, 원본 레코드는 변경되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 검색 결과가 여전히 잘못된 경우가 아니라면 따로 할 일은 없으며 판매를 정상적으로 계속할 수 있습니다. 확인하려면 로그 항목에 표시된 검색을 다시 실행하세요(검색어는 컨텍스트에 기록됨). 결과가 입력한 내용과 일치하고 예상한 항목이 누락되지 않았는지 확인하세요.
2. 검색 결과가 여전히 잘못되거나 존재하는 상품, 고객 또는 주문이 검색되지 않으면 앱을 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고 데스크톱 및 모바일에서는 앱을 닫았다가 다시 여세요. 그러면 다음에 문제가 감지될 때 색인을 새로 빌드하도록 시도합니다.
3. 새로고침한 후에도 코드가 다시 나타나면 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 문의하세요. 항목의 컨텍스트에 영향을 받은 목록과 문제를 일으킨 검색이 표시됩니다.
