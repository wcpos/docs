## 이것이 의미하는 바 {#what-this-means}

이 스토어의 WCPOS 플러그인이 이 버전의 앱에 비해 너무 오래되었습니다.

앱은 업데이트되었지만 스토어의 WCPOS 플러그인은 업데이트되지 않아, 두 버전이 더 이상 함께 작동하지 않습니다. 사이트를 관리하는 담당자에게 WP Admin에서 WCPOS 플러그인을 업데이트한 뒤 다시 연결하도록 요청하세요. 계산대에서는 변경할 것이 없습니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터는 영향을 받지 않습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**스토어에서** — WordPress 사이트를 관리하는 담당자용:

1. WP Admin → Plugins → WCPOS를 최신 버전으로 업데이트합니다. WCPOS Pro가 설치되어 있다면 동시에 일치하는 버전으로 업데이트하세요.
2. 업데이트가 제공되지 않으면 WP Admin → Dashboard → Updates를 확인하세요. Pro의 경우 인증되지 않은 업데이터가 업데이트를 차단합니다([LICENSE301](./LICENSE301) 참조) — 그 문제를 먼저 해결하세요.

**계산대에서** — 계산원용: 스토어가 업데이트된 후 다시 연결하세요. 스토어 주소를 다시 입력할 필요는 없습니다.

**스토어를 아직 업데이트할 수 없는 경우:** 대신 지원팀에 문의하세요 — 계산대에는 플러그인과 일치하는 앱 버전이 필요하며, 지원팀이 어떤 버전인지 알려줄 수 있습니다. 지원팀은 (계산대에서 확인한) 앱 버전과 (WP Admin에서 확인한) 스토어의 현재 WCPOS 버전을 요청할 것입니다.
