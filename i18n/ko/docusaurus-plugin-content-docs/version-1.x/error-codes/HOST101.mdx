## 이것이 의미하는 바 {#what-this-means}

서버가 브라우저의 권한 확인(CORS 프리플라이트)을 차단하고 있어 웹 앱이 서버에 연결할 수 없습니다.

브라우저는 사용자 지정 헤더를 포함하는 모든 교차 출처 API 호출 전에 OPTIONS 요청을 보냅니다. 이 스토어 앞단의 무언가 — 보통 방화벽 규칙 — 가 OPTIONS를 차단하고 있어, 브라우저가 실제 요청을 보내지 못합니다. 네이티브 앱은 영향을 받지 않으며, 해결은 서버 측에서 이루어집니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터는 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. OPTIONS 메서드를 차단하는 규칙이 있는지 방화벽(WAF)을 확인하고, /wcpos/ REST 경로에서 이를 허용하세요.
2. 일부 보안 플러그인에는 '일반적이지 않은 요청 메서드 차단' 토글이 있습니다 — OPTIONS는 계속 허용되어야 합니다.
3. 테스트: 스토어의 REST API에 대한 OPTIONS 요청이 403을 반환해서는 안 됩니다.
4. 데스크톱 및 모바일 앱은 CORS를 사용하지 않으므로 이 문제가 해결되는 동안에도 계속 작동합니다.
