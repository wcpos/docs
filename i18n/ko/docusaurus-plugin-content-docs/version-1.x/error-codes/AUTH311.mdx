## 이것이 의미하는 바 {#what-this-means}

WCPOS가 매장의 연결 지점에 연결할 수 없습니다.

사이트 관리자에게 WCPOS 플러그인이 활성화되어 있는지(**WP Admin → 플러그인**), 보안 플러그인이 REST API를 차단하지 않는지 확인해 달라고 요청하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 사이트 관리자에게 알리세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔는 사이트 관리자에게 알리세요. 이 기기에는 영향이 없습니다.

**매장에서** — 사이트 관리자:

1. WCPOS가 활성화되어 있는지 확인하세요: WP Admin → 플러그인.
2. 두 REST 형식이 모두 작동하지 않으면 보안 플러그인, 프록시 또는 CDN이 WCPOS 요청 헤더를 제거하거나 REST 요청을 차단하는지 확인하세요. 방화벽 규칙과 REST API 비활성화 강화 옵션이 흔한 원인입니다.
3. 일부 호스트에서는 고유주소를 다시 저장하면(설정 → 고유주소 → 저장) 누락된 REST 경로가 복구됩니다.
