## 이것이 의미하는 바 {#what-this-means}

WCPOS 스토어 경로를 사용할 수 없습니다.

보안 또는 프록시 플러그인이 WCPOS 요청 헤더를 제거하고 있는지 사이트 관리자에게 확인을 요청하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔: 브라우저에서 지원되는 두 REST 형식, 즉 매장의 `/wp-json/` 주소와 `/index.php?rest_route=/`를 모두 테스트하세요. 둘 다 JSON을 반환하지 않는 경우에만 REST 차단을 의심하고 관리자에게 알리세요.

**매장에서** — 사이트 관리자:

1. WCPOS가 활성화되어 있는지 확인하세요: WP Admin → 플러그인.
2. 두 REST 형식이 모두 작동하지 않으면 보안 플러그인, 프록시 또는 CDN이 WCPOS 요청 헤더를 제거하거나 REST 요청을 차단하는지 확인하세요. 방화벽 규칙과 REST API 비활성화 강화 옵션이 흔한 원인입니다.
3. 일부 호스트에서는 고유주소를 다시 저장하면(설정 → 고유주소 → 저장) 누락된 REST 경로가 복구됩니다.
