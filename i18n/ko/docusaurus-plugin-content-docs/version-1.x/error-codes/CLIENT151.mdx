## 이 오류의 의미 {#what-this-means}

화면의 일부를 불러오지 못해 오류 메시지로 대체했습니다.

화면이나 패널을 그리는 중 오류가 발생해 WCPOS는 종료되지 않고 해당 영역을 빨간색 "문제가 발생했습니다" 메시지로 대체했습니다. 앱의 나머지 부분은 계속 작동합니다. 이는 앱의 결함이지 매장이나 기기의 문제가 아닙니다. 메시지에 오류 내용이 표시되고 로그 항목에는 오류가 발생한 화면 부분이 기록되므로 지원팀이 문제를 파악할 수 있습니다. 오류 보고가 허용된 경우 같은 오류가 개발자에게 자동으로 전달됩니다.

## 데이터 {#your-data}

이 오류로 인해 데이터가 저장되거나 손실되지는 않았습니다. 이미 저장된 장바구니, 주문, 상품 수정 사항은 기기에 그대로 있으며 평소처럼 동기화됩니다. 패널이 돌아온 후 작업이 완료되었는지 확인한 다음 반복하세요.

## 문제 해결 {#troubleshoot}

1. 오류 메시지의 X를 눌러 닫으세요. 패널이 다시 그려지고 일회성 오류는 저절로 해결됩니다.
2. 오류가 바로 다시 나타나면 앱을 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱 및 모바일에서는 앱을 닫았다가 다시 여세요.
3. 새로고침 후에도 같은 메시지가 다시 나타나면 로그 화면에서 디버그 정보를 내보내고 지원팀에 문의하세요. 로그 항목에 오류와 문제가 발생한 화면 부분이 기록되어 있습니다.
