## 의미 {#what-this-means}

검색 인덱스가 제시간에 응답하지 않아 WCPOS에서 대신 카탈로그를 직접 검색했습니다.

로컬 검색 인덱스가 아직 생성 중이거나 응답할 수 없는 상태였습니다. 웹에서는 일반적으로 POS 탭이 백그라운드에 있거나 다른 탭이 데이터베이스 리더 역할을 맡고 있기 때문에 발생합니다. 데스크톱과 모바일에서는 대규모 동기화 직후 또는 저장된 인덱스를 다시 불러오는 앱 재시작 직후에 주로 발생합니다. 이 기기의 데이터를 직접 검색하여 계속 결과를 제공하며, 인덱스가 응답하면 자동으로 다시 인덱스를 사용합니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았으며 검색 결과도 계속 제공됩니다. 인덱스 대신 이 기기의 데이터를 직접 검색하여 결과를 제공했습니다. 인덱스가 다시 처리하기 전까지 검색 응답이 약간 느려질 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 일반적으로 별도의 조치는 필요하지 않습니다. 검색 결과는 계속 제공되며, 인덱스가 응답하면 자동으로 다시 사용됩니다.
2. 웹에서 WCPOS가 둘 이상의 브라우저 탭에 열려 있다면 추가 탭을 닫으세요. 로컬 데이터베이스의 리더 역할은 하나의 탭만 맡을 수 있습니다. 또한 POS는 백그라운드 탭이 아닌 별도 창에서 유지하세요.
3. 검색이 계속 느리거나 이 코드가 반복해서 표시되면 앱을 한 번 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱 및 모바일에서는 앱을 닫았다가 다시 여세요.
4. 그래도 코드가 계속 반환되면 디버그 정보를 내보내고 지원팀에 문의하세요.
