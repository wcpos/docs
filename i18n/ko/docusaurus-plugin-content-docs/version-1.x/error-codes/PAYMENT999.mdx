## 이것이 의미하는 바 {#what-this-means}

결제 처리 중에 예기치 않은 문제가 발생했습니다.

재시도하기 전에 결제가 실제로 처리되었는지 확인하세요. 불분명하다면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 재시도하기 전에 실제 상태를 확인하세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 재시도하기 전에 결제가 실제로 처리되었는지 확인하세요. 단말기 화면, 제공업체 대시보드, WP Admin의 주문을 모두 확인합니다.
2. 로그 항목을 펼쳐 이벤트 코드와 컨텍스트를 확인하세요. 이 일반 코드는 아직 전용 코드가 없는 원인이라는 뜻입니다.
3. 결과가 계속 불분명하거나 코드가 재발한다면 디버그 정보를 내보내고 지원팀에 문의하세요.
