# DB03001: 쿼리 구문 오류 {#db03001-query-syntax-error}

## 의미 {#what-this-means}

데이터베이스 쿼리에 구문 오류가 발생했습니다. 이는 보통 사용자 오류가 아닌 애플리케이션의 버그를 나타냅니다.

## 일반적인 원인 {#common-causes}

- **소프트웨어 버그** — POS 애플리케이션의 문제
- **버전 불일치** — 호환되지 않는 데이터 스키마
- **손상된 데이터** — 데이터에 예상치 못한 문자가 포함됨
- **인코딩 문제** — 문자 인코딩 문제

## 수정 방법 {#how-to-fix}

### 1. 애플리케이션 업데이트 {#1-update-the-application}

최신 버전을 실행하고 있는지 확인하십시오:
- POS 앱 업데이트 확인
- WCPOS WordPress 플러그인 업데이트
- 업데이트 후 재시작

### 2. 애플리케이션 데이터 지우기 {#2-clear-application-data}

:::warning 저장되지 않은 작업을 먼저 확인하세요
로컬 데이터를 지우거나 앱을 다시 설치하면 매장에 도착하지 않은 이 기기의 모든 데이터가 삭제됩니다. 오프라인 중 발생한 판매, 열린 장바구니, 저장되지 않은 수정 사항이 여기에 포함됩니다. 삭제하기 전에 **매장 상태 → 데이터베이스**를 열어 보류 중이거나 서버에 도달한 적 없는 항목이 없는지 확인한 다음, **매장 상태 → 로그**에서 **중단된 레코드 0개** 및 **전송 대기 중인 변경 사항 0개**인지 확인하세요. 이어서 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 매장 상태 페이지가 없다면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 있거나 전송 대기 중이거나 확인할 수 없다면 삭제하지 말고 매장 관리자에게 문의하거나 지원팀에 연락하세요.
:::

이 페이지의 다른 단계가 도움이 되지 않았을 때만, 그리고 위 확인을 마친 경우에만 깨끗한 상태로 초기화하세요:
- 로컬 데이터/캐시 지우기
- 다시 로그인
- 데이터 다시 동기화

### 3. 특수 문자 확인 {#3-check-for-special-characters}

특정 데이터에서 오류가 발생하면:
- 제품 이름에 비정상적인 문자가 있는지 확인
- 이모지 또는 특수 기호 찾기
- 더 간단한 데이터로 시도

### 4. 버그 보고 {#4-report-the-bug}

문제가 지속되면:
1. 오류를 발생시키는 작업을 기록
2. 오류 세부 정보 캡처
3. [GitHub](https://github.com/wcpos)에서 보고

## 일반적으로 버그입니다 {#this-is-usually-a-bug}

쿼리 구문 오류는 일반적으로 사용자 오류가 아닌 소프트웨어의 버그입니다. 이 오류가 발생하면:
- 잘못한 것이 없습니다
- 개발팀이 알아야 합니다
- 업데이트에서 수정 사항이 발표될 것입니다

## 우회 방법 {#workaround}

수정 사항이 제공될 때까지:
- 작업을 수행하기 위한 대안적인 접근 방식을 시도하십시오
- 영향을 받는 작업에 WooCommerce 관리 사용
- 정기적으로 업데이트 확인
