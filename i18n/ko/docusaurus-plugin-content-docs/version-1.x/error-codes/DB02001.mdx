# DB02001: 중복 레코드 {#db02001-duplicate-record}

## 이것이 의미하는 바 {#what-this-means}

데이터베이스가 이미 존재하는 ID로 레코드를 삽입하려고 시도했습니다. 각 레코드는 고유한 식별자를 가져야 합니다.

## 일반적인 원인 {#common-causes}

- **동기화 충돌** — 동일한 데이터가 두 번 동기화됨
- **경쟁 조건** — 여러 작업이 동일한 레코드를 생성함
- **데이터 손상** — ID가 손상되거나 중복됨
- **가져오기 문제** — 이미 존재하는 데이터를 가져옴

## 해결 방법 {#how-to-fix}

### 1. 데이터 새로 고침 {#1-refresh-data}

서버에서 다시 동기화합니다:
- 최신 데이터 가져오기
- 동기화 프로세스가 충돌을 해결하도록 허용
- 최신 데이터가 우선해야 합니다.

### 2. 작업 다시 시도 {#2-retry-the-operation}

새로운 레코드를 생성하는 경우:
- 시스템이 이미 그것을 생성했을 수 있음
- 레코드가 존재하는지 확인
- 여러 번 제출 버튼 클릭을 피함

### 3. 로컬 캐시 지우기 {#3-clear-local-cache}

:::warning 저장되지 않은 작업을 먼저 확인하세요
로컬 데이터를 지우거나 앱을 다시 설치하면 매장에 도착하지 않은 이 기기의 모든 데이터가 삭제됩니다. 오프라인 중 발생한 판매, 열린 장바구니, 저장되지 않은 수정 사항이 여기에 포함됩니다. 삭제하기 전에 **매장 상태 → 데이터베이스**를 열어 보류 중이거나 서버에 도달한 적 없는 항목이 없는지 확인한 다음, **매장 상태 → 로그**에서 **중단된 레코드 0개** 및 **전송 대기 중인 변경 사항 0개**인지 확인하세요. 이어서 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 매장 상태 페이지가 없다면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 있거나 전송 대기 중이거나 확인할 수 없다면 삭제하지 말고 매장 관리자에게 문의하거나 지원팀에 연락하세요.
:::

1, 2, 4단계로 해결되지 않았을 때만, 그리고 위 확인을 마친 경우에만 로컬 데이터를 초기화하세요:
1. 로컬 데이터베이스/캐시 지우기
2. 다시 로그인
3. 데이터를 새로 동기화

### 4. WooCommerce에서 중복 확인 {#4-check-for-duplicates-in-woocommerce}

문제가 지속되는 경우:
- WooCommerce에서 중복 항목 확인
- 동일한 ID를 가진 제품/주문 확인
- 관리자에서 중복 항목 청소

### 5. 지속적인 문제 보고 {#5-report-persistent-issues}

이런 일이 자주 발생하는 경우:
- 원인을 재확인
- 패턴 확인
- 세부사항과 함께 지원팀에 보고

## 이것이 중요한 이유 {#why-this-matters}

중복 ID는 다음과 같은 문제를 일으킬 수 있습니다:
- 어떤 레코드가 정확한지 혼란
- 데이터 덮어쓰기
- 동기화 문제

이 오류는 데이터 손상을 방지합니다.
