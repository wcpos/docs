## 이것이 의미하는 바 {#what-this-means}

이 상품 이미지를 사용할 수 없지만 상품은 계속 판매할 수 있습니다.

이미지 없이 판매를 계속하세요. WCPOS가 나중에 이미지를 다시 불러옵니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**계산대에서:** 평소처럼 판매하세요. 상품에는 영향이 없으며 이미지 다운로드는 백그라운드에서 다시 시도됩니다.

**매장에서 (WP Admin):**

1. 특정 상품의 이미지가 계속 로드되지 않으면 이미지를 다시 저장하세요. 미디어 라이브러리에서 파일이 삭제되었을 수 있습니다.
2. 여러 이미지가 한꺼번에 실패한다면 사이트의 미디어 호스팅이나 CDN이 원인입니다. 스토어 웹사이트 자체에서 이미지가 로드되는지 확인하세요.
