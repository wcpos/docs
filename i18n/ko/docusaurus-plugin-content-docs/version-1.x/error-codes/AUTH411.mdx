## 이것이 의미하는 바 {#what-this-means}

스토어 주소가 없거나 유효한 URL이 아닙니다.

주소에 오타가 없는지 확인하고 스토어 WordPress 사이트의 전체 https:// URL을 입력한 다음 다시 시도하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 주소에 오타가 없는지 확인하고 https://를 포함한 전체 URL을 입력하세요. 예: https://shop.example.com.
2. 관리자 페이지나 결제 URL이 아니라 사이트의 WordPress 주소를 사용하세요.
3. 사이트가 하위 디렉터리에 있다면(예: /shop) 그 경로도 포함하세요.
