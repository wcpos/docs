## 이것이 의미하는 바 {#what-this-means}

호스트의 보안 필터가 상품 검색을 차단하고 있습니다.

이 호스트의 방화벽 규칙이 쿼리 문자열에 비ASCII 문자나 SQL처럼 보이는 단어가 포함된 REST 요청을 거부합니다. 악센트가 포함된 상품 이름이나 'select' 또는 'union' 같은 단어가 포함된 검색은 평범한 카탈로그 검색인데도 403으로 실패합니다. 그 외에는 계산대가 작동하지만, 규칙이 완화될 때까지 검색은 불안정합니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터는 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. 쿼리 문자열 방화벽 규칙에서 스토어 자체의 REST 검색 매개변수(/wcpos/ 및 /wc/ 경로)를 허용 목록에 추가하도록 호스트에 요청하세요.
2. OWASP CRS 기반 방화벽에서는 's' 및 'search' 인수에 대한 SQL 인젝션 규칙이 흔한 원인입니다 — REST API 경로에서는 해당 인수를 제외하세요.
3. '의심스러운 쿼리 문자열 필터링' 토글이 있는 보안 플러그인에는 전체를 끄는 스위치가 아니라 REST API에 대한 예외가 필요합니다.
