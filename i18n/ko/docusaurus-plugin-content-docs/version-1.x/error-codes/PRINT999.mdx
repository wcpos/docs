## 이것이 의미하는 바 {#what-this-means}

인쇄 중에 예기치 않은 문제가 발생했습니다.

인쇄를 다시 시도하세요. 계속 실패한다면 주문 화면에서 다시 인쇄하고 진단 정보와 함께 지원팀에 문의하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 먼저 로그 항목을 펼쳐 실패한 작업을 확인하세요. 이 코드는 실제 인쇄뿐 아니라 영수증 이메일 대기열 작업과 영수증 템플릿 동기화도 포함합니다.
2. 로그에 표시된 작업만 다시 실행하세요. 실제 인쇄 시도였을 때만 주문 화면에서 다시 인쇄하고, 대기 중인 이메일은 스토어 상태에서 재시도하거나 제거하며, 템플릿 동기화는 연결된 상태에서 영수증 화면을 다시 열어 재시도하세요.
3. 해당 작업이 계속 실패한다면 디버그 정보를 내보내고 지원팀에 문의하세요.
