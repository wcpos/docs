## 이것이 의미하는 바 {#what-this-means}

인쇄 중 예상치 못한 문제가 발생했습니다. 판매에는 영향이 없습니다.

이 항목에 표시된 인쇄 또는 영수증 작업을 다시 시도하세요. 문제가 반복되면 지원팀에 문의하세요.

## 내 데이터 {#your-data}

판매에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 먼저 로그 항목을 펼쳐 실패한 작업을 확인하세요. 이 코드는 실제 인쇄뿐 아니라 영수증 이메일 대기열 작업과 영수증 템플릿 동기화도 포함합니다.
2. 로그에 표시된 작업만 다시 시도하세요. 실제 인쇄를 다시 시도할 때만 주문 화면에서 재인쇄하세요. 대기 중인 이메일은 매장 상태에서 다시 보내고, 템플릿 동기화는 연결된 상태에서 영수증 화면을 다시 열어 시도하세요.
3. 해당 작업이 계속 실패하면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
