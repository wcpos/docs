## 이것이 의미하는 바 {#what-this-means}

매장에서 오류가 발생해 이 요청을 완료하지 못했습니다.

매장에 연결되었지만 서버가 요청을 처리하지 못했습니다. POS가 아닌 웹사이트의 문제입니다. 작업을 다시 시도하세요. 문제가 계속되면 사이트 관리자에게 **WooCommerce → 상태 → 로그**를 확인해 달라고 요청하세요. 이 기기의 데이터는 손실되지 않았습니다.

## 내 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 전송되지 않은 변경 사항이 들어 있을 수 있습니다. 전송 중이던 변경 사항이 매장에 도착하지 않았을 수 있습니다. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**POS(캐셔)에서:** 로그 항목을 펼쳐 상태, 엔드포인트, serverCode를 확인하세요. 오류가 발생했을 때 서버에서 어떤 작업을 수행 중이었는지 알 수 있습니다.

**웹사이트에서(사이트 관리자/호스트):**

1. 사이트에서 WooCommerce → 상태 → 로그를 열고 오류 발생 시각 전후의 최신 fatal-errors 로그를 확인하세요. 500번대 응답은 거의 항상 그곳에 PHP 오류를 남깁니다.
2. 사이트에서 플러그인, 테마 또는 PHP를 업데이트한 후부터 오류가 시작되었다면 그 변경을 가장 먼저 의심하고 되돌리거나 비활성화하세요.
3. WooCommerce 로그에 아무것도 없다면 같은 시간대의 서버 PHP 오류 로그를 호스팅 제공업체에 요청하세요.

**그런 다음 POS로 돌아와:** 작업을 다시 시도하세요.
