## 이것이 의미하는 바 {#what-this-means}

스토어가 오류를 반환하여 이 작업이 완료되지 않았습니다.

스토어에는 연결되었지만 서버가 요청을 처리하지 못했습니다. 이는 POS가 아니라 웹사이트의 문제이므로 재시도만으로는 해결되지 않을 수 있습니다. 사이트의 오류 로그를 확인하거나 호스트에게 확인을 요청한 다음 재시도하세요. 이 기기에서 손실된 것은 없습니다.

## 내 데이터 {#your-data}

변경 사항은 이 기기에 저장되었지만 스토어에는 전달되지 않았습니다. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**POS(캐셔)에서:** 로그 항목을 펼쳐 상태, 엔드포인트, serverCode를 확인하세요. 오류가 발생했을 때 서버에서 어떤 작업을 수행 중이었는지 알 수 있습니다.

**웹사이트에서(사이트 관리자/호스트):**

1. 사이트에서 WooCommerce → 상태 → 로그를 열고 오류 발생 시각 전후의 최신 fatal-errors 로그를 확인하세요. 500번대 응답은 거의 항상 그곳에 PHP 오류를 남깁니다.
2. 사이트에서 플러그인, 테마 또는 PHP를 업데이트한 후부터 오류가 시작되었다면 그 변경을 가장 먼저 의심하고 되돌리거나 비활성화하세요.
3. WooCommerce 로그에 아무것도 없다면 같은 시간대의 서버 PHP 오류 로그를 호스팅 제공업체에 요청하세요.

**그런 다음 POS로 돌아와:** 서버 측 원인을 해결한 뒤 다시 시도하세요. 변경 사항은 이 기기에 계속 저장되어 있습니다.
