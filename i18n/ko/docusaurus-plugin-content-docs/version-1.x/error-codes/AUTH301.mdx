## 이것이 의미하는 바 {#what-this-means}

다른 인증 플러그인이 WCPOS의 연결을 막고 있습니다.

다시 로그인하기 전에 사이트 관리자에게 로그에 표시된 플러그인 충돌을 해결해 달라고 요청하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**매장에서** — 사이트 관리자:

1. 오류에 충돌하는 플러그인의 이름이 표시됩니다. 해당 플러그인 설정을 검토하세요. 대부분의 인증 플러그인에서는 플러그인을 완전히 비활성화하지 않고 WCPOS REST 경로를 예외로 지정할 수 있습니다.
2. 어떤 플러그인이 충돌하는지 불분명하다면 스테이징 사본에서 보안 및 로그인 플러그인을 하나씩 비활성화하며 테스트하세요.

**계산대에서** — 캐셔: 변경 후 다시 로그인하세요.
