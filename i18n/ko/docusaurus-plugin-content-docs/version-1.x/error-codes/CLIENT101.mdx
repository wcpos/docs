## 이것이 의미하는 바 {#what-this-means}

WCPOS가 시작을 완료하지 못했습니다.

계산대 화면이 비어 있거나 멈춰 있거나 로딩 표시가 계속되는 것처럼 보일 수 있습니다. 보통 기기의 로컬 데이터베이스를 열지 못했다는 뜻입니다. 다시 시작하면 해결될 때도 있습니다. 그렇지 않으면 로컬 데이터베이스를 지우고 다시 열어야 하며, WCPOS가 매장에서 모든 데이터를 다시 다운로드합니다.

:::warning 동기화되지 않은 데이터가 삭제됩니다
로컬 데이터베이스를 지우면 **매장과 아직 동기화되지 않은 이 기기의 모든 데이터가 영구 삭제됩니다**. 오프라인 상태에서 처리한 판매 내역이 그 예입니다. 앱을 열 수 없어 먼저 동기화할 수 없으므로 복구할 수 없습니다. 이 기기에 중요한 미동기화 판매 내역이 남아 있는 것을 알고 있다면 삭제하기 **전에** 지원팀에 문의하세요.
:::

## 내 데이터 {#your-data}

매장 데이터는 안전하며 앱을 다음에 열 때 다시 다운로드됩니다. 삭제되는 것은 이 기기의 로컬 사본뿐이며, 매장에 아직 반영되지 않은 변경 사항도 포함됩니다(위 경고 참조).

## 문제 해결 {#troubleshoot}

1. 앱을 한 번 다시 시작하세요. 웹에서는 탭을 완전히 새로고침하세요. 일시적인 시작 오류는 저절로 해결되는 경우가 많습니다.
2. 계속 시작되지 않으면 로컬 데이터베이스를 열 수 없는 것일 가능성이 큽니다. 데이터베이스를 지우고 다시 여세요. 앱 내 버튼, 웹 앱, 데스크톱 앱에 대한 안내는 [모든 로컬 데이터 지우기](/support/troubleshooting/clear-local-data)를 따르세요. WCPOS가 매장 데이터를 자동으로 다시 다운로드합니다. (이 기기의 미동기화 데이터가 삭제됩니다. 위 경고를 참조하세요.)
3. 삭제 후에도 시작되지 않으면 **디버그 정보 복사**를 사용하세요. 앱 로그를 열 수 없는 경우에는 브라우저 콘솔 오류를 복사한 뒤 지원팀에 문의하세요.
