## 이것이 의미하는 바 {#what-this-means}

WCPOS가 시작을 완료하지 못했습니다.

계산대에서는 화면이 비어 있거나 멈춘 것처럼, 또는 로딩 표시가 사라지지 않는 것처럼 보일 수 있습니다. WCPOS를 다시 시작하세요(웹에서는 탭을 새로고침하세요). 시작 오류는 저절로 해결되는 경우가 많습니다. 그래도 시작되지 않으면 무엇이든 지우기 전에 지원팀에 문의하세요.

:::warning 이 기기의 데이터를 지우지 마세요
이 기기에는 매장에 아직 도착하지 않은 판매 내역이 있을 수 있습니다. 예를 들어 오프라인 상태에서 처리한 판매가 그렇습니다. WCPOS가 시작되지 않는 동안에는 판매 내역을 전송할 수 없으므로 로컬 데이터를 지우거나 로그아웃하거나 재설치하면 영구적으로 삭제됩니다. 무엇이든 지우기 전에 지원팀에 문의하세요.
:::

## 내 데이터 {#your-data}

이 기기의 데이터를 지우지 마세요. 매장에 아직 반영되지 않은 변경 사항이 있을 수 있습니다. 매장에 저장된 데이터는 안전하며 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. WCPOS를 한 번 다시 시작하세요. 웹에서는 탭을 완전히 새로고침하세요. 일시적인 시작 오류는 저절로 해결되는 경우가 많습니다.
2. 그래도 시작되지 않으면 무엇이든 지우기 전에 지원팀에 문의하세요. WCPOS가 **로그** 탭에 접근할 수 있을 만큼 열리면 **디버그 정보 복사**로 복사한 정보를 보내세요. 그렇지 않으면 브라우저 콘솔(개발자 도구)에 표시된 오류나 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 확인한 오류를 보내세요.
3. 기다리는 동안 로컬 데이터를 지우거나 로그아웃하거나 재설치하지 마세요. 이 기기에서 먼저 복구해야 할 데이터가 있는지 지원팀이 안내해 드립니다.
