## 이것이 의미하는 바 {#what-this-means}

이 영수증에 대해 자동 인쇄가 시작되지 않았습니다.

판매가 저장되었습니다. 주문의 영수증을 열고 **영수증 인쇄**를 누르세요. 다음 영수증이 자동으로 인쇄되도록 자동 인쇄 설정과 프린터도 확인하세요.

## 내 데이터 {#your-data}

판매가 저장되었습니다. 주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 판매 후 표시된 영수증에서 **영수증 인쇄**를 눌러 직접 인쇄하세요. 판매에는 영향이 없습니다. 화면에 영수증이 없다면 WCPOS Pro에서 **주문**을 열고 해당 주문의 **영수증** 작업을 선택한 다음 **영수증 인쇄**를 누르세요.
2. 판매 후 영수증이 전혀 표시되지 않는다면 자동 표시가 꺼져 있을 수 있습니다. 장바구니 위의 슬라이더 아이콘을 눌러 장바구니 설정을 열고 **결제 후 영수증 자동 표시**와 **결제 후 영수증 자동 인쇄**를 모두 켜세요. 자동 인쇄는 해당 영수증에서 실행되므로 두 설정이 모두 필요합니다.
3. **설정 → 인쇄**에서 프린터를 확인하세요. 사용하려는 프린터가 **프린터** 아래에 표시되어야 하며, 해당 프린터의 **편집** 화면에서 **테스트 인쇄**를 실행하면 인쇄되어야 합니다.
4. **영수증 인쇄**도 실패한다면 프린터 또는 연결 문제입니다. [PRINT301](/error-codes/PRINT301)을 참조하세요. 수동 인쇄는 되지만 두 설정을 모두 켠 상태에서 자동 인쇄가 계속 실패하면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
