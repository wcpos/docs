## 이것이 의미하는 바 {#what-this-means}

이 영수증에 대해 자동 인쇄가 시작되지 않았습니다.

선택된 프린터, 템플릿, 연결 상태를 확인한 다음 지금 인쇄를 사용해 영수증을 수동으로 인쇄하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 지금 인쇄를 사용해 영수증을 직접 인쇄하세요. 판매에는 영향이 없습니다.
2. 인쇄 설정을 확인하세요. 올바른 프린터가 선택되어 있고 영수증 템플릿이 지정되어 있어야 합니다.
3. 모든 판매에서 자동 인쇄가 실패한다면 수동 인쇄는 되는지 확인하세요. 수동은 되는데 자동만 실패하면 설정 문제이고, 둘 다 실패하면 프린터 문제입니다.
