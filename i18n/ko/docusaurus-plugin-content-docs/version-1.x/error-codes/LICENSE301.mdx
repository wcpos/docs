## 이것이 의미하는 바 {#what-this-means}

업데이터가 WCPOS Pro 업데이트를 다운로드할 권한이 없습니다.

이 스토어에 대해 업데이터를 다시 승인한 다음 업데이트를 다시 확인하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. 업데이터가 인증할 수 있도록 POS 설정에서 라이선스 키를 다시 입력하거나 다시 활성화하세요.
2. WP Admin → 알림판 → 업데이트에서 업데이트를 다시 확인하세요.
3. 승인이 계속 실패한다면 사이트가 업데이트 서버로 나가는 요청을 차단하고 있을 수 있습니다. 호스트에게 아웃바운드 HTTPS가 제한되어 있는지 문의하세요.
