## 이것이 의미하는 바 {#what-this-means}

상품 SKU가 중복되었거나 올바르지 않아 결제를 계속할 수 없습니다.

로그에 표시된 SKU를 변경하거나 제거한 다음, 그대로 유지된 장바구니로 다시 시도하세요.

## 내 데이터 {#your-data}

주문 자체는 안전하며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목에는 스토어가 거부한 SKU가 표시됩니다.

**계산대에서:** SKU를 수정하기 전까지 이 상품을 판매할 수 없습니다. 장바구니에서 해당 항목을 제거하고 따로 보관한 다음 나머지 판매를 완료하세요. 매장에서 SKU를 수정한 뒤 다시 처리하면 됩니다.

**매장에서** — 사이트 관리자:

1. WP Admin의 상품에서 해당 SKU를 검색하세요. 두 상품(또는 상품과 변형)이 같은 SKU를 사용한다면 각각 고유한 SKU를 지정하세요. 상품 하나에만 있다면 SKU 형식이 잘못된 것이므로 해당 상품에서 수정하세요.
2. SKU가 고유하고 올바른 형식이면 계산대에서 상품을 추가하고 판매를 완료할 수 있습니다(장바구니는 유지됩니다).
