## 이것이 의미하는 바 {#what-this-means}

이 스토어와의 보안 연결을 신뢰할 수 없습니다.

올바른 스토어 주소를 사용하고, 다시 연결하기 전에 사이트 관리자에게 인증서를 복구해 달라고 요청하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 WordPress 사이트를 관리하는 담당자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. 같은 기기의 브라우저에서 스토어 주소를 열어 보세요. 브라우저의 자물쇠 아이콘이나 경고 페이지에 인증서의 정확한 문제(만료됨, 자체 서명됨, 다른 도메인용으로 발급됨)가 표시됩니다.
2. POS가 사용하는 주소를 확인하세요. https:// 및 인증서가 적용되는 정확한 도메인이어야 하며, www 포함 여부도 중요합니다.
3. 사이트 관리자나 호스트에게 인증서를 갱신하거나 수정해 달라고 요청하세요. 자동 갱신이 조용히 실패하는 것이 가장 흔한 원인입니다.
4. 보안을 비활성화하는 방식으로 인증서 경고를 우회하지 마세요. 인증서 자체를 수정해야 합니다.
