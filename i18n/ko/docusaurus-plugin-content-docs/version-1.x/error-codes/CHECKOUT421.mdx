## 의미 {#what-this-means}

이 주문은 현재 매장에 없는 세율을 참조하므로 세금이 올바르지 않을 수 있습니다.

주문의 항목에 매장의 현재 세율표에 없는 세율이 적용되어 있습니다. 이는 대부분 주문이 시작된 후 WooCommerce에서 해당 세율이 삭제되거나 수정되었기 때문입니다. WCPOS에서 세율을 조회할 수 없으므로 이 주문의 세금이 현재 매장에서 청구될 세금과 일치하지 않을 수 있습니다.

## 데이터 {#your-data}

주문은 안전합니다. 세금 금액만 확인이 필요합니다. 결제를 받기 전에 확인하고 매장 관리자에게 세율을 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 결제를 받기 전에 다음을 수행하세요:

1. 주문의 세금 금액을 확인하세요. 현재 매장에 없는 세율로 계산되었습니다.
2. 세금이 올바르지 않아 보이면 새 주문으로 판매를 시작하세요. 새 주문에는 매장의 현재 세율이 적용됩니다.

**매장(WP Admin)** — 사이트 관리자용:

1. **WooCommerce → 설정 → 세금**으로 이동하여 최근에 세율이 삭제되거나 수정되었는지 확인합니다. 이미 열려 있는 주문에서 참조하는 세율을 삭제하는 것이 일반적인 원인입니다.
2. 의도적으로 세율을 제거한 경우, 당시 열려 있던 주문을 다시 시작하는 것 외에는 별도의 조치가 필요하지 않습니다.
3. 매장의 세율이 변경되지 않았다면 POS에 오래된 사본이 남아 있을 수 있습니다. **매장 상태 → 데이터베이스 → 세율 → 지우고 다시 다운로드**에서 새로 고칩니다. 이 작업은 해당 컬렉션에만 영향을 주며 누구도 로그아웃되지 않습니다. [매장 상태](/support/store-health#clear-and-redownload)를 참조하세요.
4. 세율 다운로드가 완료된 후에도 코드가 다시 표시되면 **매장 상태 → 로그**에서 로그 항목을 열고 **복사**(또는 **공유**)를 사용하여 세부 정보를 전송한 다음 주문 번호와 함께 지원팀에 문의하세요.
