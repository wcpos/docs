## 이것이 의미하는 바 {#what-this-means}

세션이 종료되어 다시 로그인해야 합니다.

다시 로그인하세요. 데이터는 손실되지 않으며 로그인하면 미전송 변경 사항이 전송됩니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 세션이 만료된 동안 저장한 판매 내역은 기기에 보관되므로 사라지지 않으며, 로그인 후 자동으로 매장에 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 다시 로그인하세요. WCPOS가 WordPress 로그인 창을 자동으로 엽니다. 창을 닫았다면 WCPOS에서 다시 로그인하라는 메시지가 표시됩니다. 이전과 동일한 캐셔 계정으로 로그인하세요.
2. 다시 입력하거나 저장할 필요가 없습니다. 대기 중인 판매는 로그인하면 자동으로 전송됩니다. 전송 상태를 보려면 **매장 상태 → 데이터베이스**를 여세요. **전송 대기 중인 변경 사항**이 0으로 줄어듭니다.
3. 대신 판매가 **"… 서버에 도달하지 않은 변경 사항"** 아래에 표시되면 해당 행에서 **다시 보내기**를 누르세요.
4. 세션이 자주 만료되는 경우(하루에 여러 번) 대개 사이트 문제입니다. 보안 플러그인이 세션 수명을 단축하거나 토큰을 지우고 있을 수 있습니다. 사이트 관리자에게 매장에서 실행 중인 보안 플러그인을 확인하고, **WP Admin > POS > 설정 > 도구 > 로그**를 확인해 달라고 요청하세요. 거부된 로그인과 그 이유가 로그에 기록됩니다.
