## 이것이 의미하는 바 {#what-this-means}

세션이 종료되어 다시 로그인해야 합니다.

계속하려면 다시 로그인하세요. 이미 저장한 항목은 계산대에 보관되며, 다시 로그인하면 자동으로 전송됩니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 세션이 만료된 동안 저장한 판매 내역은 기기에 보관되므로 사라지지 않으며, 로그인 후 자동으로 매장에 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 요청이 표시되면 다시 로그인하세요. 대기 중인 판매 내역은 자동으로 전송되므로 다시 입력하거나 저장을 누를 필요가 없습니다. 전송 상태를 확인하려면 스토어 상태에서 데이터베이스를 여세요.
2. 로그인한 지 몇 분이 지난 뒤에도 같은 주문이 대기 중으로 표시되면 스토어 상태 → 데이터베이스에서 해당 행의 다시 보내기를 사용하세요.
3. 하루에 여러 번 세션이 만료된다면 대개 사이트 설정이 원인입니다. 보안 플러그인이 세션 유효 기간을 줄이거나 토큰을 지울 수 있습니다. 사이트 관리자에게 매장에서 어떤 보안 플러그인이 실행 중인지 확인하고 WP Admin → POS → 로그를 확인해 달라고 하세요. 로그인 거부 사유가 기록됩니다.
