## 이것이 의미하는 바 {#what-this-means}

스토어의 REST API가 이 앱이 사용할 수 있는 어떤 주소 형식으로도 응답하지 않았습니다.

앱은 스토어의 REST API를 일반 주소(/wp-json/...)와 WordPress 기본 대체 주소(/?rest_route=...)에서 시도했지만, 어느 쪽도 응답하지 않았습니다. 스토어 웹사이트 자체는 정상일 수 있습니다 — 이것은 특히 REST API에 연결할 수 없는 상황으로, 보통 보안 플러그인이 이를 숨기거나 방화벽 규칙이 차단하기 때문입니다.

## 내 데이터 {#your-data}

주문이나 상품 데이터는 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

**스토어에서** — 사이트 관리자용: 보안 플러그인이 `/wp-json/`을 숨기거나 이름을 변경하는 경우(예: WP Hide), WordPress 기본 `/?rest_route=` 형식도 허용하세요 — 앱이 자동으로 이 형식으로 대체합니다.

**호스트 / 서버에서:**

1. `wp-json` 또는 `rest_route`와 일치하는 항목이 있는지 방화벽(WAF) 규칙을 확인하고, 스토어 자체의 REST API를 통과시키세요.
2. 서버가 유지 관리 페이지나 봇 챌린지 뒤에 있는 경우, REST 요청이 HTML 페이지로 응답될 수 있습니다 — REST API에 대한 챌린지를 비활성화하세요.

**테스트(누구나):** `https://your-store.com/?rest_route=/` 는 403 페이지나 사이트 홈페이지가 아니라 JSON을 반환해야 합니다.
