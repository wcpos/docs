## 의미 {#what-this-means}

검색 인덱스 재구성에 실패하여 앱이 초기화를 다시 시도하는 동안 결과가 불완전할 수 있습니다.

검색 인덱스 문제([CLIENT141](/error-codes/CLIENT141) 또는 [CLIENT143](/error-codes/CLIENT143))를 감지한 후 앱이 인덱스를 재구성하려 했지만 재구성 자체에 실패했습니다. 검색은 계속 응답합니다. 기존 인덱스에서 알려진 잘못된 결과를 숨기거나 이 기기의 데이터를 직접 검사하여 응답하지만, 영향을 받은 목록의 결과가 누락되거나 순위가 잘못될 수 있습니다. 다음 검색 또는 준비 상태 확인 시 인덱스 초기화를 다시 시도하며 자동으로 복구될 수 있습니다. 결과가 계속 잘못되면 앱을 새로고침하여 다시 시작할 수 있습니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았습니다. 이 문제는 이 기기에 이미 있는 데이터에서 생성된 로컬 검색 인덱스에만 관련됩니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 엽니다. 컨텍스트에는 영향을 받은 목록과 재구성 중 발생한 오류가 표시됩니다. 오류에 저장 공간이 언급되면 먼저 기기의 공간을 확보합니다. 웹에서는 비공개/시크릿 창도 피합니다.
2. 영향을 받은 목록에서 다시 검색합니다. 앱이 인덱스 초기화를 자동으로 다시 시도합니다.
3. 결과가 계속 누락되거나 순서가 잘못되면 앱을 다시 로드합니다. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱 및 모바일에서는 앱을 닫았다가 다시 엽니다. 이후에도 CLIENT144가 다시 기록되면 로그 화면에서 디버그 정보를 내보내 지원팀에 문의합니다.
