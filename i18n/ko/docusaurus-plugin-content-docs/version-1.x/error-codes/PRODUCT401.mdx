## 이것이 의미하는 바 {#what-this-means}

표시된 재고가 스토어의 재고보다 오래된 정보일 수 있습니다.

품목이 초과 판매될 수 있는 판매를 완료하기 전에 스토어에서 현재 재고를 확인하세요.

## 내 데이터 {#your-data}

데이터 손실 위험은 없습니다. 계산대의 재고 수량이 매장보다 오래된 것일 뿐이며 동기화가 복구되면 최신 수량으로 갱신됩니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서:** 재고가 적은 상품을 판매하기 전에 실제 수량을 확인하세요. 선반을 확인하거나 관리자에게 문의하고, 매장보다 늦을 수 있는 계산대의 수량만 믿지 마세요.

**지연 해결:** 오래된 재고는 대개 동기화가 실패했거나 일시 중지되었음을 뜻합니다. 스토어 상태 → 로그에서 동기화 오류를 확인하고 해결하세요. 동기화가 복구되면 재고 표시가 자동으로 최신 상태가 됩니다.
