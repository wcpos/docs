## 이것이 의미하는 바 {#what-this-means}

라이선스 확인 중에 예기치 않은 문제가 발생했습니다.

POS는 계속 작동합니다. Pro 기능이 계속 잠겨 있다면 라이선스 키를 다시 입력한 다음 지원팀에 문의하세요.

## 내 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 계속 작업하세요. POS는 라이선스 확인 때문에 잠기지 않습니다.
2. Pro 기능이 계속 잠겨 있다면 POS 설정에서 라이선스 키를 다시 입력하세요.
3. 그래도 해결되지 않으면 디버그 정보를 내보내고 지원팀에 문의하세요.
