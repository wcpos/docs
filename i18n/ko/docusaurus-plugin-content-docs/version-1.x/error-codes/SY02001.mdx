# SY02001: 잘못된 구성 {#sy02001-invalid-configuration}

## 의미 {#what-this-means}

시스템 구성이 잘못되었거나 손상되었습니다. POS 애플리케이션은 의미가 없거나 불완전한 구성 설정을 발견했습니다.

## 일반적인 원인 {#common-causes}

- **손상된 설정** — 구성 파일이 손상됨
- **불완전한 설정** — 설정 프로세스가 완료되지 않음
- **수동 편집 오류** — 구성 파일이 잘못 수정됨
- **버전 업그레이드 문제** — 오래된 구성 파일이 새로운 버전과 호환되지 않음

## 수정 방법 {#how-to-fix}

### 1. 기본 설정으로 재설정 {#1-reset-to-default-settings}

애플리케이션에서 사용할 수 있는 경우:
- "설정 재설정" 또는 "기본값 복원"을 찾으십시오
- 이렇게 하면 사용자 지정 설정은 지워지지만 손상 문제는 해결됩니다. 재설정 과정에서 매장이나 매장 데이터를 삭제하라는 메시지가 나오면 중단하고 먼저 3단계 경고의 확인 절차를 따르세요

### 2. 설정 완료 {#2-complete-the-setup}

설정이 완료되지 않은 경우:
1. 설정 프로세스를 다시 시작하십시오
2. 모든 필수 단계를 완료하십시오
3. 완료 전에 구성을 확인하십시오

### 3. 애플리케이션 데이터 지우기 {#3-clear-application-data}

:::warning 저장되지 않은 작업이 있는지 먼저 확인하세요
기기의 로컬 데이터를 지우거나 앱을 다시 설치하면 오프라인에서 처리한 판매, 열린 장바구니, 저장되지 않은 수정 사항 등 매장에 전달되지 않은 기기의 모든 데이터가 삭제됩니다. 데이터를 지우기 전에 **매장 상태 → 데이터베이스**를 열어 서버에 아직 전달되지 않았거나 보류 중인 항목이 없는지 확인한 다음, **매장 상태 → 로그**에서 **멈춘 레코드 0개**와 **전송 대기 중인 변경 사항 0개**인지 확인하세요. 그런 다음 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 매장 상태 페이지가 없으면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 있거나 대기 중인 내용이 있거나 확인할 수 없다면 데이터를 지우지 말고 매장 소유자에게 문의하거나 지원팀에 연락하세요.
:::

이 페이지의 다른 단계로 해결되지 않은 경우에만, 그리고 위 확인을 마친 후 손상된 구성을 제거하세요:
- **데스크탑:** 애플리케이션 데이터 폴더를 삭제하고 앱을 재시작합니다
- **브라우저:** 사이트 데이터를 지우고 새로 고침합니다

### 4. 애플리케이션 재설치 {#4-reinstall-the-application}

:::warning 저장되지 않은 작업이 있는지 먼저 확인하세요
기기의 로컬 데이터를 지우거나 앱을 다시 설치하면 오프라인에서 처리한 판매, 열린 장바구니, 저장되지 않은 수정 사항 등 매장에 전달되지 않은 기기의 모든 데이터가 삭제됩니다. 데이터를 지우기 전에 **매장 상태 → 데이터베이스**를 열어 서버에 아직 전달되지 않았거나 보류 중인 항목이 없는지 확인한 다음, **매장 상태 → 로그**에서 **멈춘 레코드 0개**와 **전송 대기 중인 변경 사항 0개**인지 확인하세요. 그런 다음 열린 장바구니를 모두 완료하거나 내용을 기록해 두세요. WCPOS에 매장 상태 페이지가 없으면 먼저 WCPOS를 업데이트한 후 확인하세요. 항목이 있거나 대기 중인 내용이 있거나 확인할 수 없다면 데이터를 지우지 말고 매장 소유자에게 문의하거나 지원팀에 연락하세요.
:::

문제가 계속되는 경우에만, 그리고 위 확인을 마친 후 진행하세요:
1. 완전히 제거하십시오
2. 남은 데이터 폴더를 모두 제거하십시오
3. 새로 설치하십시오
4. 처음부터 설정을 완료하십시오

### 5. 업데이트 확인 {#5-check-for-updates}

구성 형식이 변경될 수 있습니다:
- POS 애플리케이션을 업데이트하십시오
- WCPOS 플러그인을 업데이트하십시오
- 업데이트 후 재구성하십시오

## 재설정되는 항목 {#what-gets-reset}

구성을 재설정할 때:
- 다시 로그인해야 합니다
- 사용자 정의 설정은 손실됩니다
- 데이터는 다시 동기화해야 합니다
- WooCommerce 데이터는 서버에 안전하게 보관되지만 열린 장바구니처럼 매장에 한 번도 전달되지 않은 이 기기의 데이터는 손실됩니다
