## 이것이 의미하는 바 {#what-this-means}

WCPOS에서 예기치 않은 오류가 발생했습니다.

다시 시도하기 전에 마지막 작업이 처리되었는지 확인하세요. 판매의 경우 주문을 열어 상태를 확인하세요. 문제가 반복되면 **디버그 정보 복사**를 누르고 WCPOS 지원팀에 보내세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 다시 시도하기 전에 확인하세요. 문제가 반복되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 다시 시도하기 전에 마지막 작업이 처리되었는지 확인하세요. 판매의 경우 주문을 열어 상태를 확인하고, 결제의 경우 단말기 또는 결제 제공업체도 확인하세요. 처리되지 않았다면 한 번 더 시도하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 컨텍스트를 기록해 두세요. 999 코드는 아직 전용 코드가 없는 오류라는 뜻이며, 이 정보가 원인을 식별하는 단서입니다.
3. 문제가 반복되면 **로그** 탭에서 **디버그 정보 복사**를 누르고 WCPOS 지원팀에 보내세요. 오류를 신고하면 해당 오류에 전용 코드가 추가됩니다.
