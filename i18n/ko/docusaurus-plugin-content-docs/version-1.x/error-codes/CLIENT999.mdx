## 이것이 의미하는 바 {#what-this-means}

WCPOS에서 예기치 않은 오류가 발생했습니다.

해당 작업을 한 번 더 시도해 보고, 다시 실패하면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 재시도하기 전에 실제 상태를 확인하세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 해당 작업을 한 번 더 시도하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 컨텍스트를 기록해 두세요. 999 코드는 아직 전용 코드가 없는 오류라는 뜻이며, 이 정보가 원인을 식별하는 단서입니다.
3. 문제가 반복되면 디버그 정보를 내보내고 지원팀에 문의하세요. 이렇게 신고해 주셔야 전용 코드가 새로 만들어집니다.
