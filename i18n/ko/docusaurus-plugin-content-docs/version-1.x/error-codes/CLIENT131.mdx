## 이것이 의미하는 바 {#what-this-means}

WCPOS가 한 번에 너무 많은 요청을 대기열에 넣어 일부를 폐기했습니다.

이는 대개 스토어 문제가 아니라 앱의 결함입니다. WCPOS를 다시 시작하고, 코드가 다시 나타나면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

이미 완료된 요청은 안전합니다. 중단된 요청은 실행되지 않은 것이므로 다음 단계로 넘어가기 전에 진행 중이던 작업이 실제로 완료됐는지 확인하세요.

## 문제 해결 {#troubleshoot}

1. 몇 초간 기다리세요. 대기열은 자동으로 처리되고 오래된 요청은 자동으로 삭제됩니다. 진행 중이던 작업이 완료됐는지 확인한 뒤, 완료되지 않은 경우에만 다시 시도하세요.
2. 같은 세션에서 다시 발생한다면 WCPOS를 다시 시작하세요. 다시 시작하면 대기열이 비워집니다.
3. 이는 대개 스토어 문제가 아니라 앱의 결함입니다. 계속 반복된다면 디버그 정보를 내보내고 지원팀에 문의하세요. 해당 항목의 컨텍스트를 통해 개발자가 어떤 요청이 대기열을 가득 채웠는지 파악할 수 있습니다.
