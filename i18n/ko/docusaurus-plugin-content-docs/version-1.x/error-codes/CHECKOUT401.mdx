## 이것이 의미하는 바 {#what-this-means}

이 주문의 매장 합계가 계산대에 표시된 금액과 다릅니다. 주문은 매장 합계로 저장됩니다.

고객이 떠나기 전에 주문을 열어 합계를 비교하세요. 이미 금액을 받았다면 차액을 청구하거나 환불하세요. 예상치 못한 차이라면 지원팀에 문의하세요.

## 내 데이터 {#your-data}

주문은 매장 합계로 저장됩니다. 결제가 이미 이루어졌을 수도, 아직 이루어지지 않았을 수도 있습니다. 이 확인은 주문 저장 시 실행되며 결제 전일 수도 있습니다. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 누르고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 고객이 떠나기 전에 처리하세요:

1. 주문을 열어 합계를 계산대에 표시된 금액과 비교하세요. 로그 항목에는 서로 다른 금액이 기록됩니다.
2. 이미 결제했는지, 결제했다면 금액이 얼마인지 확인하세요. 카드 단말기에서는 화면이나 영수증을, 현금은 받은 금액을, 다른 결제 게이트웨이는 해당 기록을 확인하세요.
3. 이미 금액을 받았다면 평소 절차에 따라 차액을 청구하거나 환불하세요. 아직 결제받지 않았다면 현재 표시된 주문 합계를 결제받으세요.

**매장에서** — 사이트 관리자:

1. WP Admin에서 주문을 열고 계산대에 표시된 금액과 합계를 비교하세요. 로그 항목에는 어떤 금액이 달랐는지 기록됩니다.
2. 주된 원인은 계산대에서 예상한 것과 다른 세금 설정 또는 서버에서 다시 계산하는 할인·가격 플러그인입니다. 먼저 매장의 세금 설정을 검토하세요.
3. 차이의 원인을 알 수 없다면 **로그** 탭에서 **디버그 정보 복사**를 누르고 주문 번호와 함께 지원팀에 문의하세요.
