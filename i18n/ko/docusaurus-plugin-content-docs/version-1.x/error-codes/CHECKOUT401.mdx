## 이것이 의미하는 바 {#what-this-means}

스토어가 계산한 이 주문의 합계가 계산대에 표시된 금액과 다릅니다.

추가 결제를 진행하기 전에 스토어 관리자 화면에서 주문을 확인하세요. 스토어의 합계가 기준입니다. 차이가 예상 밖이라면 진단 정보를 내보내고 지원팀에 문의하세요.

## 내 데이터 {#your-data}

금액이 이동했을 수 있습니다. 조치를 취하기 전에 결제 내역을 확인하세요. 이 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 고객이 떠나기 전에 처리하세요:

1. 중단하세요. 추가 결제를 받지 마세요. 매장의 합계가 기준입니다.
2. 고객이 결제했는지와 금액을 확인하세요. 카드 단말기라면 화면이나 영수증을 확인하고, 현금이라면 받은 금액을 확인하세요. 다른 결제 게이트웨이라면 해당 기록을 확인하세요.
3. 금액을 받았는데 매장 합계와 다르면 고객이 떠나기 전에 평소 절차에 따라 차액을 정산하세요(환불 또는 추가 청구).

**매장에서** — 사이트 관리자:

1. WP Admin에서 주문을 열고 계산대에 표시된 금액과 합계를 비교하세요. 로그 항목에는 어떤 금액이 달랐는지 기록됩니다.
2. 주된 원인은 계산대에서 예상한 것과 다른 세금 설정 또는 서버에서 다시 계산하는 할인·가격 플러그인입니다. 먼저 매장의 세금 설정을 검토하세요.
3. 차이의 원인을 설명할 수 없다면 디버그 정보를 내보내고 주문 번호와 함께 지원팀에 문의하세요.
