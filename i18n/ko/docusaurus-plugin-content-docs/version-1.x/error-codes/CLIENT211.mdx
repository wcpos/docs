## 이것이 의미하는 바 {#what-this-means}

기기 수준의 충돌로 인해 WCPOS가 중지되었습니다.

WCPOS를 다시 시작하고 마지막 판매 또는 변경 사항이 저장되었는지 확인하세요. 앱 또는 시스템 업데이트를 설치하세요. 충돌이 반복되면 지원팀에 문의하세요.

## 내 데이터 {#your-data}

결과를 확인할 수 없습니다. 다시 시도하기 전에 확인하세요. 충돌 당시 판매 또는 변경 사항을 저장 중이었다면 다시 처리하기 전에 저장 여부를 확인하세요.

## 문제 해결 {#troubleshoot}

1. 다시 처리하기 전에 WCPOS를 다시 시작하고 마지막 판매 또는 변경 사항이 저장되었는지 확인하세요. **매장 상태 → 데이터베이스**(판매가 **전송 대기 중인 변경 사항**에 포함되면 저장된 상태로 전송 중임), 장바구니, 주문(WCPOS Pro) 또는 **WooCommerce → 주문**을 살펴보세요. 카드 결제가 관련되었다면 단말기나 결제 제공업체에서도 확인하세요. 고객이 결제했다면 다시 청구하지 마세요. 실제로 저장되지 않은 경우에만 다시 입력하세요.
2. 앱과 기기의 운영 체제에 대기 중인 업데이트를 설치하세요. 네이티브 앱 충돌은 이미 수정된 버그인 경우가 많습니다. 관리되는 계산대 기기라면 기기 관리자가 업데이트를 진행합니다.
3. 같은 작업에서 충돌이 반복되면 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 문의하세요. 충돌 당시 어떤 항목을 눌렀는지 정확히 알려 주세요.
