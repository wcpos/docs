## 이것이 의미하는 바 {#what-this-means}

WCPOS가 이 기기의 저장소에 변경 사항을 기록하지 못했습니다.

기기의 저장 공간을 확보한 다음 변경 사항이 표시되는지 확인하세요. 표시되지 않으면 다시 입력하세요. 문제가 반복되면 지원팀에 문의하세요. 확인할 때까지 어떤 내용을 변경했는지 적어 두세요. 변경 사항이 기록되기 전에 WCPOS가 종료되면 해당 변경 사항은 사라집니다. 이 기기의 데이터를 삭제하지 마세요.

## 내 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 전송되지 않은 판매 내역이 들어 있을 수 있습니다. 실패한 변경 사항은 아직 어디에도 저장되지 않았을 수 있으므로, 표시되는지 확인할 때까지 메모해 두세요. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 변경한 내용, 즉 레코드와 입력한 값을 적어 두세요. 로그 항목에 레코드가 표시되어 있다면 저장되지 않았을 수 있는 변경 사항입니다. 사이트 및 자격 증명 쓰기의 경우 실패한 작업과 오류만 표시될 수 있으니 해당 세부 정보도 적어 두세요.
2. 사이트 데이터를 지우거나 앱을 초기화하거나 제거하지 마세요. 판매 내역처럼 매장에 아직 전송되지 않은 다른 변경 사항은 이 기기에만 있으며, 로컬 저장소를 지우면 영구적으로 삭제됩니다.
3. 다른 파일이나 앱을 제거해 기기의 저장 공간을 확보하세요. 디스크가 가득 찼거나 브라우저 저장소 할당량이 소진되면 로컬 쓰기가 실패하는 경우가 가장 많습니다. 공간을 확보하려고 브라우저의 "Clear browsing data"를 사용하지 마세요. WCPOS에서 아직 전송하지 않은 판매 내역도 삭제됩니다.
4. 레코드를 열어 변경 사항이 표시되는지 확인하세요. 표시되지 않으면 다시 입력하고 저장하세요. 그래도 저장되지 않으면 WCPOS를 한 번 다시 시작한 다음 다시 시도하세요.
5. 저장이 계속 실패하면 복구를 시도하기 전에 **로그** 탭에서 **디버그 정보 복사**를 사용해 지원팀에 문의하세요.
