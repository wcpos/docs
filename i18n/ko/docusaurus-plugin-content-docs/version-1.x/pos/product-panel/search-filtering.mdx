## 상품 검색 {#product-search}

### 통합 검색 필드 {#unified-search-field}

WCPOS는 하나의 검색 필드로 여러 상품 속성을 동시에 검색합니다:

- **상품명** - 상품 제목과 설명 검색
- **SKU** - 상품의 postmeta `_sku` 필드와 대조
- **바코드** - 설정된 바코드 필드를 검색합니다. 기본값은 WooCommerce의 GTIN 필드인 `_global_unique_id`이며, [설정](/1.x/settings/wp-admin/general#barcode-field)에서 `_sku` 또는 사용자 지정 postmeta 키로 변경할 수 있습니다.

"제품 검색" 필드에 검색어를 입력하면 POS가 이 모든 필드에서 결과를 즉시 필터링합니다.

### 토큰화 검색 기술 {#tokenized-search-technology}

검색 기능은 고급 토큰화 기능을 갖춘 [FlexSearch 라이브러리](https://github.com/nextapps-de/flexsearch)를 사용합니다.

- **부분 문자열 일치** - 단어 내 어느 위치에 있든 검색어를 찾습니다(예: "berry"로 검색하면 "blueberry" 검색 가능)
- **성능 최적화** - 빠른 검색 결과를 위해 성능 프리셋 사용
- **언어 인식** - 매장에 설정된 언어에 맞게 조정
- **지연 초기화** - 필요한 경우에만 검색 인덱스를 불러와 메모리 사용량 최적화

:::note 검색어는 3자 이상이어야 합니다
v1.10.0부터는 단어 **안쪽**의 부분 문자열도 검색됩니다. "berry"로 "blueberry"를, "saippua"로 "Kuorintasaippua"를 찾을 수 있습니다. 대신 최소 검색어 길이가 적용되어 **3자** 미만의 검색어는 텍스트 인덱스와 대조하지 않습니다. 짧은 코드는 바코드 및 SKU 조회로 계속 찾을 수 있습니다.

v1.10.0 이전에는 접두사 일치만 지원하여 단어의 시작 부분만 검색할 수 있었으며 중간 부분은 검색할 수 없었습니다.
:::

### 검색 작동 방식 {#how-search-works}

검색 필드에 입력하면 POS가 다음을 수행합니다:

1. 입력 내용을 검색 가능한 용어로 **토큰화**합니다
2. 저장된 상품 데이터를 먼저 **로컬에서 검색**하여 결과를 즉시 표시합니다
3. 일치하는 상품이 아직 로컬에 없으면 **서버에 조회**하고 저장하여 다음에 같은 검색을 하면 즉시 결과를 표시합니다
4. 입력하는 동안 실시간으로 **결과를 업데이트**합니다

검색 시에는 검색한 항목만 가져옵니다. 나머지 카탈로그는 백그라운드의 초기 다운로드로 채워지므로([상품 동기화](/1.x/products/sync) 참조), 관련 없는 데이터를 가져오지 않아 검색 속도가 유지됩니다.

## 상품 필터링 {#product-filtering}

### 필터 표시줄 {#filter-bar}

검색 필드 아래에는 특정 기준으로 상품 범위를 좁힐 수 있는 필터 토글과 드롭다운 메뉴가 있습니다.

### 사용 가능한 필터 {#available-filters}

#### 재고 상태 {#stock-status}
재고 상태에 따라 상품을 필터링합니다:
- **재고 있음** - 판매 가능한 재고가 있는 상품
- **재고 없음** - 재고가 없는 상품
- **품절 후 주문 가능** - 품절 후에도 주문할 수 있는 상품

#### 추천 상품 {#featured-products}
WooCommerce 상점에서 "추천"으로 지정된 상품만 표시하도록 전환합니다.

#### 할인 상품 {#on-sale-products}
현재 세일 중이거나 할인이 적용된 상품만 표시하도록 필터링합니다.

#### 카테고리 {#category}
카테고리 드롭다운으로 상품에 지정된 카테고리별로 필터링하세요. 특정 부문이나 제품군의 상품을 빠르게 찾을 수 있습니다.

#### 태그 {#tag}
상품 태그로 필터링하여 WooCommerce 상점에 정의한 특정 속성이나 특징이 있는 상품을 찾으세요.

### 필터 사용 {#using-filters}

- **필터 전환** - 필터 버튼을 클릭하여 활성화하세요(활성 필터는 강조 표시됩니다)
- **여러 필터** - 여러 필터를 조합하여 검색 범위를 더 좁힐 수 있습니다
- **필터 지우기** - 활성 필터를 다시 클릭하여 비활성화하세요
- **검색 + 필터** - 원하는 상품을 정확하게 찾으려면 검색 필드와 필터를 함께 사용하세요

## 바코드 구성 {#barcode-configuration}

### 검색 필드 {#search-fields}

검색 대상에는 설정된 바코드 필드가 자동으로 포함됩니다. 검색에 사용하는 바코드 필드는 POS 설정에 따라 달라집니다.

## 자주 묻는 질문 {#faq}

<Accordion>
  <AccordionItem question="바코드용 _global_unique_id 필드는 무엇인가요?">

`_global_unique_id`는 상점 간 바코드 표준화를 개선하기 위해 WooCommerce가 추가한 GTIN 필드입니다. WCPOS의 **기본** 바코드 필드입니다.

**주요 사항:**

- **최신 표준**: 전 세계 바코드 식별(GTIN / UPC / EAN)을 위해 특별히 설계된 필드입니다
- **기본값**: 별도 설정 없이 POS는 `_global_unique_id`를 바코드 필드로 사용합니다. 설정에서 `_sku` 또는 사용자 지정 메타 필드로 변경할 수 있습니다
- **유연성**: 타사 바코드 플러그인을 사용한다면 원하는 상품 메타 필드를 바코드 필드로 설정할 수 있습니다
- **상품당 하나의 필드**: POS는 설정된 바코드 필드 하나를 검색하며, WooCommerce는 상품별(또는 변형별)로 바코드 값을 하나씩 저장합니다. 한 상품에 여러 코드가 필요하다면 사용자 정의 필드에 저장하고 바코드 설정에서 해당 필드를 지정하세요
- **변경 시 재구축**: 바코드 필드를 변경하면 로컬 카탈로그의 바코드 인덱스가 다시 생성되어 스캔 시 새로 선택한 필드와 즉시 대조합니다

POS에서 바코드에 사용할 필드를 설정하려면 WordPress 관리자 영역의 POS 설정으로 이동하세요.

  </AccordionItem>

  <AccordionItem question="검색할 때 모든 상품이 보이지 않는 이유는 무엇인가요?">

백그라운드의 초기 카탈로그 다운로드가 아직 완료되지 않았을 수 있습니다. 상품이 보이지 않는다면:

1. **상품 검색** - 일치하는 상품이 아직 로컬에 없다면 서버에서 직접 가져옵니다
2. **다운로드 진행률 확인** - **매장 상태 → 데이터베이스**에서 이 기기에 카탈로그가 얼마나 저장되어 있는지 확인할 수 있습니다
3. **표시 여부 확인** - 품절 상품은 기본적으로 숨겨지며, 표준 WooCommerce 상품 유형만 지원됩니다

자세한 내용은 [상품 동기화](/1.x/products/sync) 가이드를 참조하세요.

  </AccordionItem>

  <AccordionItem question="상품명이나 SKU의 일부만으로 검색할 수 있나요?">

네. 토큰화 검색은 부분 문자열을 찾으므로 다음과 같이 검색할 수 있습니다:

- "blue"로 검색하면 "blueberry", "blue shirt" 등이 포함된 상품을 찾습니다
- "berry"로 검색해도 "blueberry"를 찾습니다. 검색어가 단어 내 어느 위치에 있어도 됩니다
- "ABC"로 검색하면 "ABC123", "ABC-XYZ" 등의 SKU를 찾습니다
- 단어나 코드를 전부 입력할 필요는 없습니다(단, 3자 미만의 검색어는 일치 항목을 찾지 않습니다)

검색 기능은 최소한의 입력으로 상품을 빠르게 찾도록 설계되었습니다.

  </AccordionItem>
</Accordion>
