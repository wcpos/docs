WooCommerce의 가변 상품은 크기, 색상, 소재 등 여러 옵션이 있는 상품입니다. WCPOS는 가변 상품을 효율적으로 다루는 여러 방법을 제공합니다.

## 가변 상품 식별 {#identifying-variable-products}

상품 패널에서 가변 상품은 다음과 같이 구분할 수 있습니다:

- **화살표 버튼** (<Icon name="circle-arrow-right" color="green" />)이 단순 상품에 사용되는 더하기 버튼 (<Icon name="circle-plus" color="green" />) 대신 표시됩니다
- 상품명 아래에 **속성 옵션**이 표시됩니다(예: "색상: 파랑, 초록, 빨강")
- 모든 변형을 목록 안에서 볼 수 있는 **"확장" 링크**가 있습니다

## 가변 상품을 장바구니에 추가 {#adding-variable-products-to-cart}

### 방법 1: 빠른 팝오버 {#method-1-quick-popover}

가변 상품의 녹색 <Icon name="circle-arrow-right" color="green" /> 화살표 버튼을 클릭하면 각 속성의 드롭다운 메뉴가 있는 팝오버가 열립니다:

1. 추가할 변형의 <Icon name="circle-arrow-right" color="green" /> 버튼을 클릭하세요
2. 각 드롭다운에서 옵션을 선택하세요(예: 크기: 대, 색상: 파랑)
3. 일치하는 변형이 장바구니에 추가됩니다

선택 범위가 하나의 변형으로 좁혀지면 팝오버의 장바구니 추가 버튼 옆에 해당 변형의 재고 상태가 표시됩니다. 재고를 관리하는 경우 **"재고 8개"**, 품절 후 주문이 가능한 상품은 **"백오더"**, 품절 상품은 **"품절"**(버튼 비활성화)로 표시됩니다. 자체 재고를 관리하지 않는 변형에는 수량이 표시되지 않습니다.

**품절 상품 표시** 설정으로 품절 상품을 숨기는 경우, 연결된 변형이 모두 품절인 옵션은 흐리게 표시되며 선택할 수 없습니다.

필요한 변형을 정확히 알고 있을 때 가장 빠른 방법입니다.

### 방법 2: 인라인 확장 {#method-2-expand-inline}

가변 상품의 **"확장"** 링크를 클릭하면 상품 목록에서 모든 변형을 바로 볼 수 있습니다:

1. 상품명 아래의 **확장**을 클릭하세요
2. 모든 변형이 상위 상품 아래에 별도 행으로 표시됩니다
3. 추가할 변형의 <Icon name="circle-plus" color="green" /> 버튼을 클릭하여 장바구니에 추가하세요
4. **축소**를 클릭하면 변형이 다시 숨겨집니다

**품절 상품 표시** 설정으로 품절 상품을 숨기는 경우 품절된 변형은 이 행에 표시되지 않습니다(품절 후 주문이 가능한 변형은 판매할 수 있으므로 계속 표시됩니다).

사용 가능한 모든 옵션과 각 옵션의 재고 수량, 가격을 확인하고 싶을 때 유용한 방법입니다.

### 방법 3: 바코드 스캔 {#method-3-barcode-scanning}

각 상품 변형에는 고유한 바코드를 지정할 수 있습니다. 변형의 바코드를 스캔하면:

- 일치하는 변형이 하나뿐이면 장바구니에 바로 추가됩니다
- 여러 변형이 같은 바코드를 사용하면 검색창에 일치하는 결과가 표시됩니다
- 일치하는 변형이 품절이고 **품절 상품 표시** 설정으로 품절 상품을 숨기는 경우, 장바구니에 추가되지 않고 *"품절"* 메시지와 함께 스캔이 거부됩니다

변형은 **서버**에서도 조회합니다. 스캔한 변형이 아직 기기에 없다면 WCPOS가 온라인에서 찾아 다운로드합니다. 단순 상품과 동일하게 온라인 조회로 전환됩니다.

자세한 내용은 [바코드 스캔](/1.x/pos/product-panel/barcode-scanning)을 참조하세요.

## 변형 정보 {#variation-information}

각 변형에는 다음 정보를 표시할 수 있습니다:

- **변형 속성** - 해당 변형의 구체적인 옵션(예: "크기: 대, 색상: 파랑")
- **SKU** - 변형의 고유 식별자(상위 상품과 다를 수 있음)
- **재고 수량** - 해당 변형의 개별 재고 수량
- **가격** - 변형의 가격은 상위 상품과 다를 수 있으며 변형마다 다를 수도 있습니다

## 장바구니의 변형 {#variations-in-the-cart}

변형을 장바구니에 추가하면 다음 정보가 표시됩니다:

- 상위 상품의 **제품 이름**
- 이름 아래의 **변형 속성**
- 해당 변형의 **가격**

장바구니의 다른 상품과 마찬가지로 해당 항목을 편집할 수 있습니다.

## 효율적인 변형 선택을 위한 팁 {#tips-for-efficient-variation-selection}

### 바코드 스캔 사용하기 {#use-barcode-scanning}

변형마다 개별 바코드가 있다면(권장), 스캔이 장바구니에 추가하는 가장 빠른 방법입니다.

### 표시 옵션 구성 {#configure-display-options}

상품 패널의 [표시 설정](/1.x/pos/product-panel#display-settings)에서 **속성** 옵션을 활성화하면 목록을 펼치지 않고도 상품 목록에서 변형 속성을 바로 확인할 수 있습니다.

### 키보드 탐색 {#keyboard-navigation}

변형 팝오버가 열려 있을 때 키보드 방향키로 옵션을 탐색하고 Enter 키로 선택할 수 있습니다.

## 자주 묻는 질문 {#faq}

<Accordion>
  <AccordionItem question="특정 변형이 보이지 않는 이유는 무엇인가요?">

해당 변형이 다음 조건을 충족하는지 확인하세요:
- 임시글 상태가 아닌 게시된 상태
- "재고 있음"으로 설정되어 있거나 재고 수량 > 0(재고 관리가 활성화된 경우)
- 모든 필수 속성이 정의된 상태

변형이 품절이라면 "재고 있음" 필터 때문에 상품이 제외되지 않았는지도 확인하세요.

  </AccordionItem>

  <AccordionItem question="개별 변형에 바코드를 추가하려면 어떻게 하나요?">

WooCommerce에서 가변 상품을 편집하고 각 변형을 펼치세요. 각 변형의 바코드 필드에 고유한 바코드를 추가할 수 있습니다(설정에 따라 일반적으로 `_sku` 또는 `_global_unique_id` 사용).

  </AccordionItem>
