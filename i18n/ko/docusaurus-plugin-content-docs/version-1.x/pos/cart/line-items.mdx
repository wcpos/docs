장바구니의 각 항목은 직접 편집할 수 있는 라인 항목입니다. WCPOS는 수량, 가격 및 기타 세부 정보를 유연하게 수정할 수 있는 인라인 편집 기능을 제공합니다.

## 라인 항목 유형 {#line-item-types}

WooCommerce는 세 가지 유형의 라인 항목을 사용합니다:

| 유형 | 설명 | 예시 |
|------|-------------|----------|
| **line_item** | 카탈로그의 상품 | 티셔츠, 커피 머그 |
| **fee_line** | 추가 수수료 | 선물 포장, 서비스 요금 |
| **shipping_line** | 배송비 | 일반 배송, 특급 배송 |

:::note
배송비는 수동으로 입력합니다. POS는 배송 요금을 자동으로 계산하지 않습니다.
:::

## 라인 항목 편집하기 {#editing-line-items}

### 수량 {#quantity}

수량 필드를 클릭하여 직접 편집하세요. 새 숫자를 입력하거나 증감 버튼을 사용하세요.

{/* Screenshot: cart-line-item-edit-qty.png */}

### 제품 이름 {#product-name}

기타 상품과 수수료는 이름을 클릭하여 직접 편집할 수 있습니다.

### 가격 {#price}

가격 필드를 클릭하여 단가를 변경하세요. 다음과 같은 경우에 유용합니다:

- 수동 할인 적용
- 가격 맞춤
- 가격 오류 수정

합계는 수량 × 가격을 기준으로 자동 업데이트됩니다.

:::note 가격 수정은 WooCommerce의 ‘할인’이 아닙니다
인하한 가격은 품목의 세일 가격으로 기록됩니다. 영수증에는 절감액을 표시할 수 있지만 주문의 **할인** 합계에는 쿠폰만 반영되며, 보고서에는 실제 지불한 가격으로 판매가 집계됩니다. WooCommerce가 두 가지를 다르게 처리하는 이유는 [장바구니 할인](/1.x/pos/cart/discounts#why-tracked-differently)을 참조하세요.
:::

### 점 세 개 메뉴 {#three-dot-menu}

라인 항목의 **⋮**(점 세 개)를 클릭하면 추가 옵션을 사용할 수 있습니다:

{/* Screenshot: cart-line-item-menu.png */}

#### 편집 양식 {#edit-form}

라인 항목의 상세 편집 양식이 열리며 모든 필드를 수정할 수 있습니다.

#### 원시 JSON 보기 {#raw-json-view}

라인 항목의 원시 JSON 데이터를 표시합니다. 다음과 같은 경우에 매우 유용합니다:

- **디버깅** - WooCommerce에 전송되는 데이터를 정확히 확인
- **문제 해결** - 사용자 지정 필드 또는 메타 데이터의 문제 파악
- **개발** - 연동에 필요한 데이터 구조 이해

### 항목 제거 {#remove-item}

빨간색 **×** 버튼을 클릭하여 장바구니에서 항목을 제거하세요.

## 변형 속성 {#variation-attributes}

옵션 상품은 선택한 변형 속성이 상품 이름 아래에 표시됩니다:

```
Hoodie
Colour: Green
Size: Large
```

이 속성은 라인 항목 데이터의 일부이며 주문에 포함됩니다.

## 메타 데이터 {#meta-data}

제품 패널 설정에서 [메타 데이터 키](/1.x/pos/product-panel#meta-data-keys)를 구성한 경우, 상품을 장바구니에 추가하면 해당 데이터가 라인 항목에 자동으로 복사됩니다.

원시 JSON 보기에서 이 메타 데이터를 확인할 수 있습니다.

## 라인 항목 분할 {#splitting-line-items}

[표시 설정](/1.x/pos/cart#display-settings)에서 활성화하면 라인 항목을 여러 행으로 나눌 수 있습니다. 고객이 같은 상품의 일부에 서로 다른 할인을 적용하려는 경우에 유용합니다.

## 유용한 정보 {#tips}

### 빠른 가격 조정 {#quick-price-adjustments}

할인을 빠르게 적용하려면:

1. 가격 필드를 클릭하세요
2. 새 가격을 입력하세요
3. Enter 키를 누르세요

### 키보드 탐색 {#keyboard-navigation}

- **Tab** - 편집 가능한 필드 간 이동
- **Enter** - 편집 확정
- **Escape** - 편집 취소

### 일괄 수정 {#batch-edits}

복잡한 주문은 점 세 개 메뉴에서 전체 편집 양식을 열어 보세요. 모든 필드를 한 번에 확인할 수 있습니다.
