- 주문의 추가 메타 데이터를 관리하는 모달을 엽니다.
- 다음 기능을 제공합니다:
  - 주문 통화 변경.
  - 거래 ID 추가(예: 외부 결제 단말기의 거래 ID).
  - 주문의 사용자 정의 메타 데이터 추가.

:::note
다른 WooCommerce 플러그인과의 연동을 비롯한 기능이 이 모달에 점차 추가될 예정입니다.
:::

### WooCommerce의 메타 데이터란 무엇인가요? {#what-is-meta-data-in-woocommerce}

메타 데이터는 주문에 관한 추가 정보이며 WooCommerce REST API를 통해 접근할 수 있습니다. 개발자와 플러그인은 이 데이터를 활용하여 타사 서비스 연동 등으로 기능을 확장합니다.

### JSON 보기 {#json-view}

- 주문의 원시 JSON 데이터를 확인할 수 있어 디버깅이나 연동 작업에 유용합니다.

## 서버에 저장 {#save-to-server}

- 열린 장바구니를 서버에 안전하게 저장하여 나중에 다시 사용할 수 있습니다.
- 상태가 `pos-open`인 WooCommerce 주문을 생성합니다.

### 왜 저장해야 하나요? {#why-save}

POS에서 새로 생성한 주문은 로컬에만 존재합니다. 
주문을 저장하면 로컬 데이터베이스가 지워져도 주문이 유지됩니다.

저장된 주문을 관리하는 방법은 [열린 주문](/1.x/pos/cart/open-orders)을 참조하세요.

## 무효화 {#void}

- 두 가지 경우가 있습니다:
  - 저장되지 않은 주문:
    - 주문이 서버에 저장되지 않았다면 로컬 데이터베이스에서 영구적으로 삭제됩니다.
  - 저장된 주문:
    - 주문이 서버에 저장되어 있다면 WooCommerce의 휴지통으로 이동하고 로컬 데이터베이스에서는 삭제됩니다.
- 무효화된 주문을 복구하려면:
  - `WP Admin > WooCommerce > Orders > Trash`으로 이동하세요.

## 결제 {#checkout}

- 주문을 서버에 저장하고 결제 절차를 시작합니다.
- 결제를 완료할 수 있도록 [결제 화면](/1.x/pos/checkout)을 엽니다.
