**증상:** 앱에 *"보안 인쇄가 켜져 있습니다. 프린터에서 끈 다음 다시 시도하세요."* 라고 표시됩니다. 또는 새로 산 Epson이 네트워크에서 검색되고 테스트 페이지도 전송되는 것처럼 보이는데 아무것도 나오지 않습니다 — 오류도 없고, 표시등도 그대로이며, 프린터 자체 상태 페이지에는 사용 가능으로 나옵니다. 패널 자체 테스트는 정상으로 인쇄됩니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

**2025년 8월 1일** 이후 EU와 영국 시장용으로 생산된 Epson TM 시리즈 프린터는 EU 무선 기기 지침을 충족하기 위해 **보안 인쇄**가 켜진 상태로 출고됩니다. 이 기능이 켜져 있으면 프린터는 기존의 암호화되지 않은 채널로 들어온 작업을 받아들인 뒤 **조용히 폐기합니다**.

| 채널 | 보안 인쇄 **켜짐** | **꺼짐** |
|---|---|---|
| Raw TCP, 포트 9100 | 수신 후 폐기 | 인쇄됨 |
| HTTP를 통한 ePOS-Print (80, 8008) | 제공되지 않음 | 인쇄됨 |
| HTTPS를 통한 ePOS-Print (443, 8043) | 인쇄됨 | 인쇄됨 |

EU 외 지역에서 판매된 제품도 같은 펌웨어를 쓸 수 있습니다. 어느 지역이든 새 Epson에서 이 증상이 나타나면 이 설정을 확인하세요.

## 끄는 방법 {#turn-it-off}

프린터의 관리자 비밀번호가 필요합니다. 최신 모델은 프린터 밑면 라벨의 **일련번호**이고, 구형 모델은 `epson`을 사용했습니다.

1. 프린터의 주소를 확인합니다 — 상태 시트에 있습니다(롤 커버를 열고 **Feed**를 길게 누르세요).
2. 브라우저에서 `https://printer-ip`를 열고 인증서 경고를 수락합니다.
3. **Administrator Login**을 누른 다음 **Print → Secure Printing**으로 이동합니다.
4. **Disable**로 설정하고 확인합니다.
5. 프린터 전원을 10초간 뽑았다가 다시 꽂습니다.
6. 테스트 페이지를 다시 인쇄합니다.

:::warning 펌웨어 업데이트를 하면 다시 켜집니다
Epson은 펌웨어를 업데이트할 때 보안 설정을 기본값으로 되돌립니다. 몇 달 동안 잘 쓰던 프린터가 업데이트 직후 멈췄다면 위 단계를 다시 수행하세요.
:::

들어간 김에 관리자 비밀번호를 직접 설정해 두세요 — 같은 네트워크에 있는 누구나 열려 있는 영수증 프린터에 접근할 수 있습니다.
