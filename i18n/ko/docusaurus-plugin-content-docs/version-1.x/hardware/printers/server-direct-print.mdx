**증상:** 프린터 자체 웹 페이지는 열리고, 패널 자체 테스트도 인쇄되고, 보안 인쇄도 이미 꺼져 있는데 — POS에서 보낸 작업은 모두 실패하거나 시간 초과됩니다. 전원을 껐다 켜도 달라지지 않습니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

Epson 프린터는 서버에서 인쇄 작업을 직접 가져오도록 설정할 수 있는데, 이 기능을 **Server Direct Print**라고 합니다. 관련 기능인 **ePOS-Device**는 하나의 애플리케이션이 세션 동안 프린터를 점유할 수 있게 합니다. 둘 중 하나라도 켜져 있으면 인쇄 엔진의 소유권을 가져가고, 점유되어 있는 동안 프린터는 다른 모든 요청을 사용 중으로 보고 거부합니다 — 그 사실을 알려 주지도 않습니다. 프린터에 저장된 설정이기 때문에 다시 시작해도 해제되지 않습니다.

이전 설치 작업, 주방 인쇄 서비스, 또는 다른 계산대가 켜 둔 채로 남겨 둔 경우가 대부분입니다.

## 끄는 방법 {#turn-it-off}

1. 브라우저에서 `https://printer-ip`를 열고 인증서 경고를 수락합니다.
2. **Administrator Login** — 비밀번호는 누군가 변경하지 않았다면 프린터 밑면 라벨의 일련번호입니다.
3. **Server Direct Print**를 찾아(펌웨어에 따라 프린터의 서비스 또는 인쇄 설정 아래에 있습니다) **Disable**로 설정합니다.
4. 같은 화면에서 다른 곳에서 사용하지 않는다면 **ePOS-Device**도 비활성화되어 있는지 확인합니다.
5. 확인한 다음 프린터 전원을 10초간 뽑았다가 다시 꽂습니다.
6. 테스트 페이지를 다시 인쇄합니다.

:::note 다른 시스템이 사용 중일 수 있습니다
주방 디스플레이나 온라인 주문 서비스처럼 다른 시스템이 실제로 Server Direct Print로 인쇄하고 있다면, 둘 중 하나만 프린터를 점유할 수 있습니다. 그 시스템을 다른 프린터로 돌리거나, POS 전용 프린터를 따로 두세요.
:::

## 그래도 안 되나요? {#still-stuck}

문제 화면에서 **설정 보고서 복사**를 눌러 메시지에 붙여 넣으세요. 각 포트에서 프린터가 어떻게 응답했는지 기록됩니다.
