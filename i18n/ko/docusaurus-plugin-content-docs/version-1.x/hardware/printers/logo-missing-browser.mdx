**증상:** 브라우저 탭에서 인쇄한 영수증이 매장 로고만 빼고 온전하게 나옵니다. 같은 영수증을 데스크톱 앱이나 모바일 앱에서 인쇄하면 로고가 정상으로 나옵니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

로고는 WordPress 미디어 라이브러리에 있고, 브라우저는 그곳에서 로고를 가져옵니다. 웹 페이지가 다른 주소에서 불러온 이미지의 픽셀을 읽으려면, 그 이미지를 가진 서버가 `Access-Control-Allow-Origin`이라는 헤더로 이를 허용해야 합니다. WordPress는 업로드된 파일에 이 헤더를 기본으로 보내지 않기 때문에, 브라우저는 이미지를 화면에 표시하는 용도로만 넘겨주고 인쇄용으로는 넘겨주지 않습니다.

앱이 이를 우회할 수는 없습니다. 판매를 실패시키는 대신 로고 없이 영수증을 인쇄합니다. 데스크톱 앱과 모바일 앱은 파일을 직접 가져오므로 이 규칙의 적용을 받지 않습니다.

## 이렇게 하세요 {#do-this}

매장 상황에 맞는 방법을 고르세요.

- **데스크톱 앱에서 인쇄하세요.** 설정할 것이 없고, 계산대에 이미 설치되어 있다면 가장 빠른 해결책입니다.
- **사이트에서 헤더를 허용하세요.** 사이트 관리자가 웹 서버 설정이나 CORS 헤더를 설정하는 플러그인으로 업로드 디렉터리에 `Access-Control-Allow-Origin`을 추가합니다. 그다음 POS를 새로 고치고 다시 인쇄하세요.

## 로고가 잡티처럼 인쇄될 때 {#if-the-logo-prints-as-noise}

로고 대신 무작위 점들이 띠처럼 나오는 것은 다른 문제입니다. 일부 구형·저가형 프린터는 사용된 이미지 형식을 해석하지 못합니다. 해당 프린터의 영수증 템플릿에서 로고를 제거하세요.

## 그래도 안 되나요? {#still-stuck}

문제 화면에서 **설정 보고서 복사**를 눌러 로고 이미지의 주소와 함께 메시지에 붙여 넣으세요.
