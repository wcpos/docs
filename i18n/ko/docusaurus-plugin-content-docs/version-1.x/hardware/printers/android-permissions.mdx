**증상:** Android 휴대폰이나 태블릿에서 검색해도 아무것도 나오지 않거나, Bluetooth 프린터가 선택 창에 끝내 나타나지 않거나, 주소를 알고 있는 프린터가 시간 초과됩니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

Android는 이 권한들을 따로 관리하며, 거부되어도 아무 알림이 없습니다. 차단된 연결은 전원이 꺼진 프린터와 똑같이 시간 초과됩니다.

- **근처 기기** 권한은 Bluetooth 프린터를 찾고 연결하는 데 필요합니다.
- **로컬 네트워크** 접근 권한은 최신 Android 버전에서 앱이 Wi-Fi의 기기에 접근하기 전에 반드시 필요합니다.

## 권한 켜기 {#turn-the-permissions-on}

1. Android의 **설정 → 앱 → WCPOS → 권한**을 엽니다.
2. **근처 기기**를 허용합니다.
3. **로컬 네트워크** 항목이 있다면 그것도 허용합니다. 구버전 Android에는 없습니다.
4. 앱을 완전히 닫았다가 다시 열고 검색합니다.

## Bluetooth 프린터 {#bluetooth-printers}

Android에서 Epson과 Star 프린터는 제조사 자체 소프트웨어를 통해 연결되므로, 앱에 표시되기 전에 먼저 **Android에서 페어링**해야 합니다 — **설정 → 연결된 기기 → 새 기기와 페어링**. 소형 Bluetooth Low Energy 프린터는 대신 앱 자체 선택 창에서 고릅니다. 이런 프린터는 Android에서 페어링하지 마세요. [Bluetooth 영수증 프린터 페어링](/hardware/printers/bluetooth-pairing)을 참조하세요.

## Wi-Fi 프린터 {#wi-fi-printers}

태블릿이 모바일 데이터나 게스트 네트워크가 아니라 매장 Wi-Fi에 연결되어 있는지 확인하세요. 검색 결과가 비어 있는데 프린터 주소를 알고 있다면 **IP 주소 입력**을 사용하세요. 주소 하나를 바로 확인하므로 검색 기능에 의존하지 않습니다.
