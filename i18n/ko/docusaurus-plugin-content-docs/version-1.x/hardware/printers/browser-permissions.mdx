**증상:** POS를 브라우저에서 실행하는데 프린터에 연결되지 않습니다. 검색해도 아무것도 나오지 않거나, 같은 프린터가 데스크톱 앱에서는 인쇄되는데 브라우저 탭에서는 인쇄되지 않습니다.

## 로컬 네트워크 접근 허용하기 {#allow-local-network-access}

Chrome과 Edge는 웹사이트가 네트워크의 기기와 통신하기 전에 권한을 묻습니다. 그 요청을 닫아 버렸다면 이후 모든 시도가 아무 알림 없이 실패합니다.

주소 표시줄 왼쪽 아이콘 → **사이트 설정**을 클릭한 다음 **로컬 네트워크**를 **허용**으로 설정하고, 페이지를 새로 고친 뒤 다시 검색하세요.

## 혼합 콘텐츠 {#mixed-content}

`https://`로 제공되는 POS는 프린터에 일반 `http://` 연결을 열 수 없습니다. Chrome과 Edge는 로컬 네트워크 접근을 허용하면 이를 허용하지만, 다른 브라우저는 아예 차단합니다. 매장이 HTTPS로 운영되고 프린터가 HTTP만 지원한다면 데스크톱 앱을 사용하세요.

## 프린터의 인증서 {#the-printers-certificate}

프린터는 자체 인증서로 통신을 보호하는데, 어떤 브라우저도 이 인증서를 기본으로 신뢰하지 않습니다. 그래서 연결이 시작되기도 전에 실패합니다. 같은 브라우저에서 `https://printer-ip`를 한 번 열어 경고를 수락한 다음 POS로 돌아오세요. 컴퓨터마다 한 번씩 해 주어야 합니다.

데스크톱 앱에는 이 문제가 없습니다. 프린터의 인증서를 앱이 직접 수락하기 때문에, 같은 프린터가 탭에서는 안 되고 데스크톱 앱에서는 되는 것입니다.

## Safari와 Firefox {#safari-and-firefox}

이 두 브라우저에는 위 방법이 하나도 없습니다. 허용할 로컬 네트워크 권한 자체가 없고, 웹 페이지에서 USB나 Bluetooth 프린터를 사용하는 기능도 지원하지 않습니다. 이 브라우저에서는 매장의 HTTP 또는 HTTPS와 맞는 Wi-Fi 프린터를 쓰거나 데스크톱 앱을 사용하세요.

## 그래도 안 되나요? {#still-stuck}
