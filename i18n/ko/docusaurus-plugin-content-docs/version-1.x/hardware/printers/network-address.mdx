**증상:** Wi-Fi에서 검색해도 아무것도 나오지 않거나, 몇 주 동안 잘 쓰던 프린터가 갑자기 모든 영수증에서 시간 초과됩니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

거의 모든 경우 다음 세 가지 네트워크 상황이 원인입니다.

- **서로 다른 네트워크.** 계산대는 한 Wi-Fi에, 프린터는 다른 Wi-Fi에 있습니다 — 게스트 SSID, 두 번째 액세스 포인트, 또는 별도의 VLAN. 프린터 검색은 이 경계를 넘지 못합니다.
- **클라이언트 격리.** 게스트용·공용 Wi-Fi는 보통 기기끼리 통신하는 것을 아예 차단합니다. 프린터가 같은 네트워크에 있어도 연결할 수 없습니다.
- **주소가 바뀜.** 공유기는 임대 방식으로 주소를 나눠 줍니다. 임대가 갱신되면 프린터는 새 주소로 옮겨 가는데 저장된 프린터는 여전히 예전 주소를 가리킵니다. 그래서 어제는 되던 것이 오늘은 시간 초과됩니다.

## 이렇게 하세요 {#do-this}

1. 계산대와 프린터를 게스트 네트워크가 아닌 **같은 Wi-Fi**에 연결하세요.
2. 프린터의 상태 시트를 인쇄해 현재 주소를 확인하세요. Epson은 롤 커버를 열고 **Feed**를 1초간 누르고, Star는 전원이 켜진 상태에서 **Feed**를 5초간 누릅니다.
3. **고정 주소**를 지정하세요. 공유기의 DHCP 설정에서 프린터의 MAC 주소에 주소를 예약하거나, `http://printer-ip`의 프린터 자체 웹 페이지에서 고정 주소를 설정합니다. 어느 쪽이든 주소가 더는 바뀌지 않습니다.
4. 앱에서 **IP 주소 입력**을 사용해 그 주소를 입력하세요. 검색을 멈추고 주소 하나를 바로 확인하므로, 검색이 차단된 환경에서도 작동합니다.

주소가 맞는데도 계속 시간 초과된다면 프린터가 작업을 붙들고 있을 수 있습니다 — [한 번 인쇄한 뒤 멈췄을 때](/hardware/printers/printed-once-then-stopped)를 참조하세요.

## 그래도 안 되나요? {#still-stuck}

문제 화면에서 **설정 보고서 복사**를 눌러 메시지에 붙여 넣으세요. 시도한 주소와 어떤 포트가 응답했는지가 기록됩니다.
