어디서 시작해야 할지 모르겠나요? [**프린터 설정 마법사**](/hardware/printers/setup-wizard)가 몇 가지 질문을 통해 프린터 연결 과정을 단계별로 안내하며, 테스트 인쇄가 작동하지 않을 때 문제 해결도 도와줍니다.
:::

프린터 설정은 **POS > 설정 > 인쇄**에서 확인할 수 있습니다. 각 기기는 자체 프린터 구성을 관리하며, 프린터는 로컬에 저장되고 기기 간에 동기화되지 않습니다.

:::tip 이 기기에 연결되지 않은 프린터로 인쇄하시나요?
이 페이지에서는 USB, Bluetooth 또는 로컬 네트워크를 통해 계산대에 연결된 프린터를 다룹니다. 다른 방이나 위치에 있는 프린터 또는 모든 기기에서 공유할 프린터는 [클라우드 인쇄](/receipts/cloud-printing)를 참조하세요. 매장에 설정한 클라우드 프린터는 모든 기기의 프린터 목록에 **자동으로** 표시되므로 여기에서 추가할 필요가 없습니다.
:::

## 플랫폼별 지원 프린터 {#supported-printers-by-platform}

**프린터 추가** 양식은 사용 중인 앱에 맞게 조정되며, 각 플랫폼에서는 실제로 사용할 수 있는 연결 방식과 옵션만 표시됩니다.

| 플랫폼 | 지원되는 프린터 | 연결 방식 |
|----------|--------------------|-------------|
| **웹 앱** | 내장 웹 서버가 있는 Epson 및 Star 프린터(네트워크), WebUSB를 통한 대부분의 ESC/POS 프린터(USB), Web Bluetooth를 통한 Bluetooth Low Energy(BLE) 프린터(USB/Bluetooth는 Chrome/Edge에서만 지원) | 네트워크(HTTP), USB, Bluetooth |
| **데스크톱 앱** | 모든 네트워크 영수증 프린터 | 네트워크(raw TCP), USB, Bluetooth |
| **iOS 앱** | Epson 및 Star | 네트워크, Bluetooth |
| **Android 앱** | Epson 및 Star | 네트워크, Bluetooth, USB |

:::info 웹에서 네트워크를 통해 Epson 및 Star만 지원하는 이유
웹 브라우저는 raw TCP 연결을 열 수 없습니다. Epson 및 Star 영수증 프린터에는 HTTP를 통해 인쇄 작업을 수신하는 내장 웹 서버가 있습니다. 브라우저에서 *네트워크* 프린터로 ESC/POS 명령을 전송하는 유일한 방법입니다. 데스크톱 앱은 TCP를 통해 직접 연결할 수 있으므로 이러한 제한이 없습니다.

브라우저에서도 USB 및 Bluetooth 인쇄를 사용할 수 있지만 **Chrome 또는 Microsoft Edge**에서만 지원됩니다(WebUSB 및 Web Bluetooth API 사용). Safari와 Firefox는 이를 지원하지 않습니다. **USB**를 사용하는 경우 Epson 및 Star로 제한되지 않습니다. 브라우저의 기기 선택기에 표시되는 대부분의 ESC/POS 프린터에서 인쇄할 수 있습니다. **Bluetooth**를 사용하는 경우 프린터의 Bluetooth 유형이 중요합니다. 브라우저는 **Bluetooth Low Energy(BLE)** 프린터에만 연결할 수 있으며, 클래식 Bluetooth 모델(대부분의 Bluetooth Epson 및 Star 프린터 포함)은 브라우저에서 연결할 수 없습니다.

**모바일 앱**에서는 Bluetooth 및 USB 인쇄가 Epson 및 Star의 공식 SDK를 통해 이루어지므로, 이러한 연결에는 Epson 또는 Star 프린터가 필요합니다. 일반 프린터는 네트워크를 통해서만 사용할 수 있습니다.
:::

## 프린터 추가 {#adding-a-printer}

<Steps>
  <StepCard number="1" title="프린터 설정 열기">

**POS > 설정 > 인쇄**로 이동합니다. 아직 구성된 프린터가 없으면 **프린터 추가** 버튼이 있는 빈 화면이 표시됩니다. 각 프린터에는 **프린터 이름**이 지정됩니다. 이는 프린터를 구분하기 위한 레이블이며, 기본값은 "영수증 프린터"(이후 "영수증 프린터 2" 등)로 자동 입력됩니다. 필요에 따라 이름을 변경할 수 있습니다.

  </StepCard>
  <StepCard number="2" title="프린터 연결 방식 선택">

모든 플랫폼에서 **연결 유형**을 먼저 선택하며, 해당 플랫폼에서 지원하는 옵션만 표시됩니다. 아래 필드는 선택 사항에 따라 변경됩니다.

- **웹 앱** — **네트워크**, **USB** 또는 **Bluetooth**를 지원합니다(USB 및 Bluetooth에는 Chrome 또는 Edge가 필요함). **네트워크** 프린터의 경우 **제조업체**(Epson 또는 Star)를 선택합니다. 브라우저는 해당 브랜드에 내장된 웹 서버를 통해 네트워크 프린터에 연결합니다.
- **데스크톱 앱** — **네트워크**, **USB** 또는 **Bluetooth**를 지원합니다.
- **모바일 앱** — **네트워크** 또는 **Bluetooth**를 지원하며, Android에서는 **USB**도 지원합니다(iOS는 USB를 지원하지 않음).

</StepCard>
  <StepCard number="3" title="프린터 식별">

**네트워크 프린터** — **IP 주소**를 입력합니다(예: `192.168.1.100`). WCPOS는 주소를 확인하여 Epson 또는 Star 장치인지 감지하고 포트, 명령 언어 및 제조업체를 자동으로 입력합니다. 감지가 완료되면 "감지됨: Epson" 또는 "감지됨: Star" 레이블이 표시됩니다. 웹 앱에서는 연결할 정확한 엔드포인트 URL도 표시됩니다.

**Bluetooth 또는 USB 프린터**(모바일) — 검색된 장치 목록에서 프린터를 선택합니다. 장치를 선택하면 이름과 제조업체가 자동으로 입력됩니다. 프린터가 아직 목록에 없으면 **프린터 검색**(Bluetooth) 또는 **새로 고침**(USB)을 탭합니다.

자동 감지 결과가 정확하지 않은 경우 **고급 설정**에서 모두 조정할 수 있습니다.

  </StepCard>
  <StepCard number="4" title="저장 및 테스트" isLast>

**저장**을 클릭합니다. WCPOS는 먼저 **테스트 인쇄**를 전송하고, 성공한 경우에만 프린터를 저장합니다.

테스트 인쇄는 번호가 매겨진 열 눈금자, 가운데 정렬된 일반 및 두 배 크기 텍스트, 좌/우 정렬 행, 용지 절단으로 구성된 짧은 진단입니다. 프린터에 연결할 수 있는지만이 아니라 용지 너비, 정렬, 크기, 절단이 모두 올바르게 구성되었는지 확인하도록 설계되었습니다.

:::tip 테스트에 실패했나요? 그래도 저장할 수 있습니다
테스트에 실패하면 오류와 함께 프로필을 그대로 저장할 수 있는 **테스트 없이 저장** 옵션이 표시됩니다.
:::

  </StepCard>
</Steps>

## 연결 유형 {#connection-types-mobile-apps}

프린터 추가 양식 상단에서 **연결 유형**을 선택하면 연결 필드가 해당 유형에 맞게 업데이트됩니다. 사용할 수 있는 유형은 플랫폼에 따라 다릅니다(위 표 참조).

### 네트워크 {#network}

프린터가 기기와 동일한 Wi-Fi 네트워크에 있습니다. **데스크톱** 및 **모바일** 앱에서는 **네트워크 검색**을 탭하여 프린터를 자동으로 찾거나 IP 주소를 수동으로 입력할 수 있습니다. [프린터의 IP 주소 찾기](#finding-your-printers-ip-address)를 참조하세요. **웹 앱**에서는 IP 주소를 수동으로만 입력할 수 있습니다. 데스크톱 및 모바일 앱에서 네트워크 프린터는 Epson, Star 또는 일반 프린터일 수 있지만, 웹에서는 **Epson 또는 Star**여야 하며 네트워크 연결에서 선택합니다.

### Bluetooth {#bluetooth}

프린터가 Bluetooth를 통해 기기와 페어링되어 있습니다. 목록에서 프린터를 선택하면 이름과 제조업체가 자동으로 입력됩니다. **모바일**에서는 Bluetooth 인쇄에 Epson 및 Star의 네이티브 SDK를 사용하므로 프린터가 **Epson 또는 Star** 모델이어야 합니다. **웹**에서는 Web Bluetooth API를 통해 Chrome 또는 Edge에서 Bluetooth를 사용할 수 있습니다.

### USB {#usb-android-only}

프린터가 USB 케이블로 연결되어 있습니다. 연결된 기기 목록에서 선택하세요. USB는 **웹**(Chrome 또는 Edge에서 WebUSB 사용), **데스크톱** 앱 및 **Android**에서 사용할 수 있지만, 일반 USB 주변기기를 지원하지 않는 **iOS**에서는 사용할 수 없습니다. 모바일에서 USB 인쇄를 사용하려면 **Epson 또는 Star** 프린터가 필요합니다.

:::note
**포트** 설정은 네트워크 프린터에만 적용되며 Bluetooth 및 USB 연결에서는 숨겨집니다.
:::

## 고급 설정 {#advanced-settings}

**고급 설정**을 펼쳐 프린터 구성을 세부 조정합니다. 대부분의 설정은 공급업체가 확인되면 자동으로 입력됩니다.

다음 설정은 모든 플랫폼에 적용됩니다.

| 설정 | 옵션 | 설명 |
|---------|---------|-------------|
| **언어** | ESC/POS, StarPRNT, Star Line Mode | 프린터가 사용하는 명령 프로토콜입니다. 감지된 공급업체를 기준으로 자동 입력됩니다. |
| **프린터 텍스트 너비** | 58mm (32자), 80mm 표준 (42자), 80mm 와이드 (48자) | 한 줄에 들어갈 수 있는 문자 수입니다. 용지와 프린터에 맞게 설정하세요. 대부분의 80mm 프린터는 줄당 42자이며, 일부는 48자입니다. |
| **전체 영수증 래스터** | 끔 / 켬 | 텍스트 대신 전체 영수증을 이미지로 인쇄합니다. 아래의 [전체 영수증 래스터](#full-receipt-raster)를 참조하세요. |

다음 두 설정은 플랫폼 및 연결 유형에 따라 다르게 동작합니다.

| 설정 | 옵션 | 적용 위치 |
|---------|---------|------------------|
| **제조업체** | Epson, Star, 일반 | 프린터 제조업체입니다. **웹 앱**에서는 **네트워크** 연결에서 제조업체를 직접 선택합니다(Epson 또는 Star만 해당). 고급 설정으로 선택하는 항목은 아닙니다. 일반은 데스크톱 및 모바일 앱의 **네트워크** 프린터에서 사용할 수 있지만 Bluetooth 또는 USB 연결에서는 사용할 수 없습니다. |
| **포트** | 자동 입력 | IP 주소 옆에 표시되는 프린터의 네트워크 포트입니다. **네트워크 전용** — Bluetooth 및 USB에서는 숨겨집니다. 제조업체(웹에서는 POS가 HTTP 또는 HTTPS를 통해 제공되는지 여부)에 따라 자동으로 입력됩니다. 네트워크에서 포트를 다시 매핑한 경우에만 변경하세요. |

## 프린터 옵션 {#printer-options}

이 토글은 프린터 추가 양식 하단에 있습니다:

| 옵션 | 설명 |
|--------|-------------|
| **용지 자동 절단** | 영수증을 출력한 후마다 자동으로 용지를 절단합니다 |
| **현금 서랍 자동 열기** | 출력 후 연결된 현금 서랍을 여는 킥 명령을 보냅니다 |
| **기본값으로 설정** | 특정 프린터로 라우팅되지 않은 모든 영수증에 사용할 기본 프린터로 설정합니다 |

:::note "결제 후 자동 출력"을 찾고 있나요?
판매가 완료될 때 영수증을 자동으로 출력하는 기능은 프린터 설정이 아니라 **장바구니 설정**입니다. POS 장바구니 설정에서 **영수증 자동 출력**을 켜세요. 사용할 프린터는 기본 프린터와 템플릿별 프린터 라우팅에 따라 결정됩니다.
:::

## 출력 라우팅 {#print-routing}

감열 영수증 **및** A4 송장처럼 둘 이상의 템플릿을 사용하는 경우, 인쇄 라우팅에서 각 템플릿을 어떤 프린터로 인쇄할지 결정합니다. 라우팅에는 다음 순서로 확인되는 세 가지 계층이 있습니다:

1. **작업별 재정의.** 영수증 화면에서 템플릿 전환기 옆에 프린터 드롭다운이 표시됩니다. 여기에서 프린터를 선택하면 해당 인쇄 작업에 대해서만 모든 설정이 재정의됩니다. 템플릿을 전환하면 다시 **자동**으로 재설정됩니다.
2. **설정 재정의.** **POS > 설정 > 인쇄**로 이동한 다음 **영수증 템플릿** 섹션에서 각 템플릿에 특정 프린터를 할당합니다. 예를 들어 감열 영수증은 Epson 네트워크 프린터로, HTML 송장은 시스템 인쇄 대화 상자로 라우팅할 수 있습니다. 재정의를 제거하려면 템플릿을 다시 **자동**으로 설정합니다.
3. **자동 일치.** 재정의가 설정되지 않은 경우 WCPOS가 자동으로 일치시킵니다:
   - **감열 템플릿**은 문자 너비가 일치하는 감열 프린터로 라우팅됩니다. 58mm 감열 템플릿은 32열 프린터를 우선 사용하며, 80mm 템플릿은 42열 또는 48열 프린터를 우선 사용합니다.
   - **HTML 템플릿**은 시스템 인쇄 대화 상자로 라우팅됩니다.
   - 일치하는 프린터가 여러 개인 경우 **기본** 프린터가 선택됩니다.

감열 템플릿을 시스템 대화 상자로 보내는 것처럼 호환되지 않는 프린터로 템플릿을 수동 전송하면 영수증 화면에 황색 **불일치 경고**가 표시됩니다. 인쇄는 계속 진행되지만 출력 결과가 올바르게 렌더링되지 않을 수 있습니다.

라우팅 재정의는 **기기별로** 저장됩니다. 각 iPad, 휴대폰 또는 컴퓨터에서 자체 라우팅을 관리하며 서버 측 동기화는 제공되지 않습니다.

:::note
**POS > 설정 > 인쇄**의 **영수증 템플릿** 프린터 제어 항목은 프린터를 하나 이상 추가한 후에만 표시됩니다. 구성된 프린터가 없으면 모든 템플릿은 자동으로 시스템 인쇄 대화 상자를 사용합니다. 매장에 설정된 **클라우드 프린터**도 여기에 포함되며, 기기에 추가하지 않아도 자동으로 라우팅 대상으로 표시됩니다.
:::

## 전체 영수증 래스터 {#full-receipt-raster}

기본적으로 WCPOS는 프린터에 내장된 글꼴을 사용하여 영수증을 **텍스트** 형식으로 감열 프린터에 전송합니다. 이 방식은 빠르고 간결하며 선명합니다. 단, 감열 프린터 글꼴은 제한된 문자 집합만 지원합니다. 프린터에 해당 글꼴이 없는 문자 체계(많은 비라틴 문자, 오른쪽에서 왼쪽으로 쓰는 텍스트, 일부 기호 등)는 빈 상자나 깨진 문자로 출력될 수 있습니다.

**전체 영수증 래스터**를 사용하면 이 문제가 해결됩니다. 활성화하면 WCPOS가 전체 영수증을 이미지로 렌더링하여 프린터로 전송하므로, 어떤 언어나 문자 체계에서도 화면에 표시되는 내용과 동일하게 출력됩니다.

프린터별로 **고급 설정**에서 활성화할 수 있습니다. 다음 사항을 참고하세요.

- **속도가 느려집니다.** 이미지는 텍스트 한 줄보다 훨씬 크므로 영수증을 전송하고 인쇄하는 데 시간이 더 걸립니다.
- **필요한 경우에만 사용하세요.** 영수증이 텍스트로 정상 출력된다면 비활성화 상태로 두세요.
- 네트워크, Bluetooth, USB 등 모든 연결 방식의 감열 프린터에 적용됩니다. 이미 전체 페이지 렌더링으로 인쇄하는 시스템 인쇄 대화 상자에는 적용되지 않습니다.

## 프린터 검색 {#discovering-printers}

프린터를 찾는 방법은 연결 방식에 따라 다릅니다.

- **Bluetooth 및 USB** — **모바일 앱**에서 **프린터 검색**(Bluetooth) 또는 **새로 고침**(USB)을 탭한 후 목록에서 프린터를 선택합니다. 프린터 이름과 공급업체 정보가 자동으로 입력됩니다. **웹**(Chrome 또는 Edge)에서는 **연결**을 클릭하고 브라우저의 기기 선택 창에서 프린터를 선택합니다.
- **네트워크** — **데스크톱** 및 **모바일** 앱에서 **네트워크 검색**을 탭하면 로컬 네트워크의 프린터를 자동으로 찾을 수 있습니다(데스크톱은 mDNS/Bonjour를 통해 검색하고, 모바일은 Epson 및 Star SDK를 사용합니다). 그런 다음 목록에서 프린터를 선택합니다. IP 주소를 직접 입력할 수도 있습니다. 아래의 [프린터 IP 주소 찾기](#finding-your-printers-ip-address)를 참조하세요. 브라우저에서는 네트워크를 검색할 수 없으므로 **웹 앱**에서는 항상 IP 주소를 직접 입력해야 합니다.

## 프린터 IP 주소 찾기 {#finding-your-printers-ip-address}

대부분의 영수증 프린터는 IP 주소가 포함된 자체 테스트 페이지를 인쇄할 수 있습니다:

- **Epson**: 전원을 켜는 동안 급지 버튼을 길게 누릅니다
- **Star**: 전원이 켜진 상태에서 급지 버튼을 5초간 길게 누릅니다

또는 라우터의 연결된 기기 목록이나 프린터 구성 유틸리티를 확인합니다.

### 고정 IP 권장 {#static-ip-recommended}

프린터를 재시작할 때 주소가 변경되지 않도록 영수증 프린터에는 **고정 IP 주소**를 사용해야 합니다. 다음 중 한 가지 방법으로 구성합니다:

- 프린터의 내장 웹 인터페이스에서(일반적으로 다음 주소에서 액세스 가능: `http://<printer-ip>`)
- 라우터의 DHCP 설정에서(프린터의 MAC 주소에 예약 IP 할당)

## Epson 프린터 {#epson-printers}

ePOS를 지원하는 Epson 프린터는 HTTP를 통해 통신합니다. WCPOS는 프린터의 내장 웹 서버로 SOAP/XML 요청을 전송합니다.

**연결 세부 정보:**
- 포트 `8008` (HTTP) 또는 `8043` (HTTPS) — POS가 HTTP 또는 HTTPS를 통해 제공되는지에 맞춰 자동으로 입력됩니다
- 엔드포인트: `/cgi-bin/epos/service.cgi`
- **최신 모델(TM-m30III 및 유사 모델):** ePOS는 다음 포트에서 제공됩니다 `80` (HTTP) / `443` (HTTPS) 대신 사용됩니다. 웹 앱에서 자동으로 입력된 포트에 연결되지 않으면 **포트**를 `80` (HTTP 매장) 또는 `443` (HTTPS 매장)으로 설정하세요. HTTPS의 경우 먼저 `https://<printer-ip>` 각 POS 기기에서 프린터의 인증서 경고를 수락하세요. 브라우저가 프린터를 신뢰할 수 없는 경우 **데스크톱 앱**을 사용하세요.

**작동이 확인된 모델:**
- Epson TM-T70-i 2 (네트워크)
- Epson TM-m30III (네트워크 — 직접 연결, 미들웨어 불필요)

:::tip
Epson 프린터 구성에서 ePOS가 활성화되어 있는지 확인합니다. 프린터 웹 인터페이스에 액세스합니다. `http://<printer-ip>` ePOS 설정을 확인하고 활성화합니다.
:::

:::warning 새 Epson 프린터에서 아무것도 인쇄되지 않나요?
2025년 중반 이후 제조된 Epson 프린터는 **보안 인쇄**가 활성화된 상태로 제공됩니다. 이 기능은 네트워크 인쇄 작업을 조용히 폐기하므로 테스트 인쇄는 "전송"되지만 아무것도 출력되지 않습니다. 2분 안에 해결하는 방법은 [Epson 보안 인쇄](/hardware/printers/secure-printing)를 참조하세요.
:::

**모바일 앱**에서는 Epson 프린터를 Epson의 네이티브 SDK를 통해 Bluetooth 또는 USB로도 연결할 수 있습니다. IP 주소나 ePOS 웹 서버는 필요하지 않습니다.

## Star 프린터 {#star-printers}

WebPRNT를 지원하는 Star 프린터는 HTTP를 통해 통신합니다. WCPOS는 Star WebPRNT 엔드포인트로 명령을 전송합니다.

**연결 세부 정보:**
- 포트 `80`(HTTP) 또는 `443`(HTTPS) — POS가 HTTP 또는 HTTPS 중 어느 방식으로 제공되는지에 맞춰 자동으로 입력됩니다.
- 엔드포인트: `/StarWebPRNT/SendMessage`

**모바일 앱**에서는 Star 프린터를 Star의 네이티브 SDK를 통해 Bluetooth 또는 USB로 연결할 수도 있습니다.

## 일반 프린터 {#generic-printers}

**데스크톱 앱**은 원시 TCP를 통해 모든 네트워크 영수증 프린터를 지원합니다. 프린터의 IP 주소와 포트(일반적으로 `9100`)를 입력하세요. ESC/POS 명령을 수신하는 대부분의 감열식 프린터에서 제조업체와 관계없이 사용할 수 있습니다.

**모바일 앱**에서도 일반 프린터를 지원하지만, Bluetooth나 USB가 아닌 **네트워크** 연결만 지원합니다(Bluetooth 또는 USB 연결에는 Epson 또는 Star 프린터가 필요합니다). **웹 앱**은 일반 프린터를 전혀 지원하지 않습니다.

## 금전함 {#cash-drawers}

영수증 프린터에 연결된 금전함은 각 판매 후 자동으로 열리도록 설정할 수 있습니다:

1. 프린터 옵션에서 **금전함 자동 열기**를 활성화합니다.
2. POS는 인쇄 후 ESC/POS 킥 명령을 전송합니다.

:::note
금전함 제어에는 감열식 프린터 프로필이 필요합니다. 브라우저 인쇄 대화상자에서는 금전함을 열 수 없습니다.
:::
