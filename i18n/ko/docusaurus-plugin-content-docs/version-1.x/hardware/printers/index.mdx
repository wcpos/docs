프린터 설정은 **POS → 설정 → 인쇄**에 있습니다. 프린터는 기기마다 따로 저장됩니다 — 계산대에 저장되며 기기 간에 동기화되지 않습니다.

:::tip 이 계산대에 없는 프린터로 인쇄하시나요?
이 페이지는 USB나 Bluetooth로 계산대에 연결된 프린터, 또는 같은 Wi-Fi에 있는 프린터를 다룹니다. 다른 방이나 다른 매장에 있는 프린터, 또는 모든 기기가 함께 쓰는 프린터는 [클라우드 인쇄](/receipts/cloud-printing)를 참조하세요. 클라우드 프린터는 모든 기기의 프린터 목록에 자동으로 나타나므로 여기에서 추가하지 않아도 됩니다.
:::

## 프린터 추가 {#adding-a-printer}

<Steps>
  <StepCard number="1" title="검색">

**설정 → 인쇄**로 이동해 **프린터 추가**를 탭하세요. 한 번의 검색으로 USB, Bluetooth, Wi-Fi 프린터를 동시에 찾으므로 먼저 고를 것이 없습니다. 찾은 프린터는 발견되는 즉시 카드로 표시됩니다.

  </StepCard>
  <StepCard number="2" title="테스트 페이지 인쇄">

사용할 프린터의 카드에서 **테스트 페이지 인쇄**를 탭하세요. 테스트 페이지는 용지를 가로지르는 번호 눈금자라서, 프린터가 작동하는지뿐 아니라 너비가 맞는지도 함께 보여 줍니다.

용지 너비를 앱이 아직 모른다면 먼저 **58 mm**인지 **80 mm**인지 묻습니다.

  </StepCard>
  <StepCard number="3" title="질문에 답하기">

그다음 앱이 **테스트 페이지가 인쇄되었나요?** 하고 묻습니다. 답은 세 가지입니다.

- **예** — 프린터가 저장되고 설정이 끝납니다.
- **인쇄됐지만 눈금자가 맞지 않음** — 프린터에 어떤 용지가 들어 있는지 묻고, 답한 내용으로 테스트 페이지를 다시 인쇄합니다. [영수증 너비 맞추기](/hardware/printers/receipt-width)를 참조하세요.
- **아무것도 나오지 않음** — 가장 가능성 높은 원인과 해결 방법을 한 줄로 안내합니다.

</StepCard>
  <StepCard number="4" title="이름 지정" isLast>

저장한 뒤에는 **설정 → 인쇄**의 프린터 행 아래에 **이름**, **용지 너비**, **금전함** 설정이 표시됩니다. 언제든 이곳에서 변경할 수 있습니다.

  </StepCard>
</Steps>

### 검색이 진행되는 동안 {#while-the-scan-is-running}

결과 옆에 버튼 세 개가 있습니다.

- **Bluetooth 프린터 찾기** — 브라우저나 컴퓨터 자체의 Bluetooth 선택 창을 엽니다. Chrome과 데스크톱 앱은 프린터로 보이는 이름을 목록 위쪽에 올려 줍니다.
- **IP 주소 입력** — 검색을 멈추고 주소 하나만 확인합니다. 프린터의 위치를 알고 있는데 검색으로 찾지 못할 때 사용하세요. 업무용 네트워크에서 흔한 상황입니다.
- **중지** — 검색을 멈춥니다. 이미 찾은 항목은 화면에 그대로 남습니다.

## 아무것도 인쇄되지 않을 때 {#when-nothing-prints}

모든 문제 화면에는 무엇이 잘못됐고 어떻게 해야 하는지 한 줄로 안내하고, 버튼 두 개가 함께 표시됩니다.

- **설정 보고서 복사** — 앱이 시도한 내용, 프린터가 응답한 내용, 어떤 연결이 열려 있었는지를 복사합니다. 지원 문의 메시지에 붙여 넣으세요. 긴 질문과 답변을 주고받는 수고를 덜어 줍니다.
- **프린터 가이드 열기** — 이 페이지로 이동합니다.

상황에 맞는 가이드를 고르세요.

**설정 중**

- [영수증 너비 맞추기](/hardware/printers/receipt-width) — 눈금자가 가장자리를 넘어가거나 못 미칠 때
- [프린터에 고정 주소 지정하기](/hardware/printers/network-address) — Wi-Fi에서 아무것도 찾지 못하거나, 잘 되던 프린터가 멈췄을 때
- [Bluetooth 영수증 프린터 페어링](/hardware/printers/bluetooth-pairing) — 선택 창에 프린터가 없을 때
- [Windows에서 USB 사용](/hardware/printers/usb-windows) 및 [Linux에서 USB 사용](/hardware/printers/usb-linux)
- [지원되는 영수증 프린터](/hardware/printers/supported-printers)

**Epson이 아무것도 인쇄하지 않을 때**

- [Epson 보안 인쇄](/hardware/printers/secure-printing) — 새 Epson이 전송은 되는 듯한데 아무것도 인쇄되지 않을 때
- [Server Direct Print](/hardware/printers/server-direct-print) — 프린터 웹 페이지는 열리는데 작업이 인쇄되지 않을 때
- [한 번 인쇄한 뒤 멈췄을 때](/hardware/printers/printed-once-then-stopped) — 먼저 전원을 껐다 켜세요

## 앱별 연결 가능 범위 {#supported-printers-by-platform}

| | Wi-Fi | USB 및 Bluetooth |
|---|---|---|
| **웹 앱** | 프린터 자체 웹 포트를 통한 Epson 및 Star. HTTPS 매장에서는 처음 한 번 Chrome이 로컬 네트워크 접근 권한을 묻습니다. | 브라우저 자체 장치 선택 창을 통한 USB 및 Bluetooth Low Energy — Chrome과 Edge에서만 가능합니다. |
| **데스크톱 앱** | 모든 Wi-Fi 영수증 프린터. 네트워크를 검색해 찾아 줍니다. | USB, Bluetooth Low Energy, 그리고 운영체제에 이미 설치되었거나 페어링된 프린터. |
| **iPhone 및 iPad** | 모든 Wi-Fi 영수증 프린터. | Epson과 Star는 제조사 자체 소프트웨어로, 다른 제조사는 Bluetooth Low Energy로 연결합니다. |
| **Android** | 모든 Wi-Fi 영수증 프린터. | Epson과 Star는 제조사 자체 소프트웨어로, 다른 제조사는 Bluetooth Low Energy로 연결하거나, [설정에서 페어링](/hardware/printers/bluetooth-pairing#android-pair-first)한 뒤 Bluetooth Classic으로 연결합니다. |

브라우저는 앱처럼 프린터에 직접 연결할 수 없습니다. 그래서 웹 앱은 Wi-Fi에서 Epson과 Star에만 연결됩니다 — 이 두 제조사는 웹 서버를 내장하고 있기 때문입니다. Wi-Fi의 다른 프린터는 데스크톱 앱이나 모바일 앱, 또는 [클라우드 프린터](/receipts/cloud-printing)를 사용하세요.

## 프린터 옵션 {#printer-options}

**설정 → 인쇄**의 각 프린터 행 아래에 있습니다.

| 옵션 | 기능 |
|---|---|
| **용지 너비** | 한 줄에 들어가는 문자 수입니다. 테스트 페이지로 설정합니다 — [영수증 너비](/hardware/printers/receipt-width)를 참조하세요. |
| **용지 자동 절단** | 영수증을 인쇄할 때마다 용지를 절단합니다. |
| **현금 서랍 자동 열기** | 이 프린터에 연결된 금전함을 엽니다 — [금전함](/hardware/printers/cash-drawer)을 참조하세요. |
| **기본값으로 설정** | 다른 곳으로 라우팅되지 않은 영수증을 이 프린터로 인쇄합니다. |
| **전체 영수증 래스터** | 영수증을 텍스트 대신 이미지로 인쇄합니다. 더 느리지만 어떤 언어든 인쇄됩니다 — [비라틴 문자 영수증](/hardware/printers/non-latin-receipts)을 참조하세요. |

:::note "결제 후 자동 인쇄"를 찾고 있나요?
판매가 끝날 때 영수증을 자동으로 인쇄하는 기능은 프린터 설정이 아니라 **장바구니 설정**입니다. POS 장바구니 설정에서 **영수증 자동 출력**을 켜세요. *어떤* 프린터로 인쇄할지는 기본 프린터와 인쇄 라우팅이 결정합니다.
:::

## 인쇄 라우팅 {#print-routing}

감열 영수증 **과** A4 송장처럼 템플릿을 둘 이상 사용한다면, 인쇄 라우팅이 각 템플릿을 어느 프린터로 보낼지 결정합니다. 라우팅에는 세 개의 계층이 있고, 다음 순서로 확인됩니다.

1. **작업별 재정의.** 영수증 화면에서 템플릿 전환기 옆에 프린터 드롭다운이 있습니다. 여기에서 프린터를 고르면 그 인쇄 작업에 한해 다른 모든 설정보다 우선합니다. 템플릿을 바꾸면 다시 **자동**으로 돌아갑니다.
2. **설정 재정의.** **POS → 설정 → 인쇄**로 이동해 **영수증 템플릿** 섹션에서 템플릿마다 특정 프린터를 지정합니다. 재정의를 없애려면 템플릿을 다시 **자동**으로 설정하세요.
3. **자동 일치.** 재정의가 없으면 WCPOS가 자동으로 맞춥니다. 감열 템플릿은 너비가 맞는 감열식 프린터로 가고(58 mm 템플릿은 32열 프린터를, 80 mm 템플릿은 42열이나 48열 프린터를 우선합니다), HTML 템플릿은 시스템 인쇄 대화상자로 갑니다. 조건에 맞는 프린터가 여럿이면 **기본** 프린터가 선택됩니다.

호환되지 않는 프린터로 템플릿을 보내면 — 예를 들어 감열 템플릿을 시스템 대화상자로 보내면 — 영수증 화면에 주황색 **불일치 경고**가 표시됩니다. 인쇄는 그대로 진행되지만 결과가 제대로 나오지 않을 수 있습니다.

라우팅은 **기기별로** 저장되며, 계산대마다 따로 관리합니다.

:::note
**영수증 템플릿** 설정은 프린터를 하나 이상 추가한 뒤에만 표시됩니다. 프린터가 없으면 모든 템플릿이 시스템 인쇄 대화상자를 사용합니다. 클라우드 프린터도 여기에 포함되며, 라우팅 대상으로 자동으로 나타납니다.
:::
