프린터 설정은 **POS → 설정 → 인쇄**에 있습니다. 프린터 정보는 각 계산대 기기에 저장되며, 기기 간에 동기화되지 않습니다.

:::tip 이 계산대에 없는 프린터로 인쇄하시나요?
이 페이지는 USB나 Bluetooth로 계산대에 연결되거나 같은 Wi-Fi에 연결된 프린터를 다룹니다. 다른 방이나 다른 매장에 있는 프린터, 또는 모든 기기가 함께 사용할 프린터는 [클라우드 인쇄](/1.x/receipts/cloud-printing)를 참조하세요. 클라우드 프린터는 모든 기기의 프린터 목록에 자동으로 표시되므로 여기에서 추가하지 않습니다.
:::

## 프린터 추가 {#adding-a-printer}

<Steps>
  <StepCard number="1" title="검색">

**설정 → 인쇄**로 이동해 **프린터 추가**를 탭하세요. 한 번의 검색으로 USB, Bluetooth, Wi-Fi 프린터를 동시에 찾으므로 미리 선택할 항목은 없습니다. 프린터를 찾으면 즉시 카드로 표시합니다.

  </StepCard>
  <StepCard number="2" title="테스트 페이지 인쇄">

사용할 프린터의 카드에서 **테스트 페이지 인쇄**를 탭하세요. 테스트 페이지에는 용지 너비에 걸쳐 숫자가 표시된 눈금자가 인쇄되므로, 프린터 작동 여부와 너비 설정이 맞는지 함께 확인할 수 있습니다.

앱이 용지 너비를 아직 모르는 경우, 먼저 **58 mm**인지 **80 mm**인지 묻습니다.

  </StepCard>
  <StepCard number="3" title="질문에 답하기">

그다음 앱이 **테스트 페이지가 인쇄되었나요?** 하고 묻습니다. 답은 세 가지입니다.

- **예** — 프린터가 저장되고 설정이 끝납니다.
- **인쇄됐지만 눈금자가 맞지 않음** — 앱이 프린터에 어떤 용지가 들어 있는지 묻고, 답변에 따라 테스트 페이지를 다시 인쇄합니다. [영수증 너비 맞추기](/1.x/hardware/printers/receipt-width)를 참조하세요.
- **아무것도 나오지 않음** — 가장 가능성이 높은 원인과 해결 방법을 한 줄로 안내합니다.

</StepCard>
  <StepCard number="4" title="이름 지정" isLast>

저장한 뒤에는 **설정 → 인쇄**의 해당 프린터 행 아래에 **이름**, **용지 너비**, **금전함** 설정이 표시됩니다. 언제든 이곳에서 변경하세요.

  </StepCard>
</Steps>

### 검색이 진행되는 동안 {#while-the-scan-is-running}

결과 옆에 버튼 세 개가 있습니다.

- **Bluetooth 프린터 찾기** — 브라우저나 컴퓨터 자체의 Bluetooth 선택 창을 엽니다. Chrome과 데스크톱 앱은 프린터로 보이는 이름을 목록 위쪽에 표시합니다.
- **IP 주소 입력** — 검색을 멈추고 주소 하나만 확인합니다. 프린터 주소를 알고 있는데 검색으로 찾지 못할 때 사용하세요. 업무용 네트워크에서 흔히 발생하는 상황입니다.
- **중지** — 검색을 멈춥니다. 이미 찾은 항목은 화면에 그대로 남습니다.

## 아무것도 인쇄되지 않을 때 {#when-nothing-prints}

모든 문제 화면에는 문제와 해결 방법을 설명하는 한 줄 안내와 버튼 두 개가 표시됩니다.

- **설정 보고서 복사** — 앱이 시도한 내용, 프린터의 응답, 열려 있던 연결을 복사합니다. 지원 문의 메시지에 붙여 넣으세요. 질문과 답변을 길게 주고받는 수고를 덜 수 있습니다.
- **프린터 가이드 열기** — 이 페이지로 이동합니다.

상황에 맞는 가이드를 고르세요.

**설정 중**

- [영수증 너비 맞추기](/1.x/hardware/printers/receipt-width) — 눈금자가 용지 가장자리를 넘어가거나 못 미칠 때
- [프린터에 고정 주소 지정하기](/1.x/hardware/printers/network-address) — Wi-Fi에서 아무것도 찾지 못하거나 잘 되던 프린터가 멈췄을 때
- [Bluetooth 영수증 프린터 페어링](/1.x/hardware/printers/bluetooth-pairing) — 선택 창에 프린터가 없을 때
- [Windows에서 USB 사용](/1.x/hardware/printers/usb-windows) 및 [Linux에서 USB 사용](/1.x/hardware/printers/usb-linux)
- [지원되는 영수증 프린터](/1.x/hardware/printers/supported-printers)

**Epson이 아무것도 인쇄하지 않을 때**

- [Epson 보안 인쇄](/1.x/hardware/printers/secure-printing) — 새 Epson 프린터로 전송은 되는 듯한데 아무것도 인쇄되지 않을 때
- [Server Direct Print](/1.x/hardware/printers/server-direct-print) — 프린터 웹 페이지는 열리는데 작업이 인쇄되지 않을 때
- [한 번 인쇄한 뒤 멈췄을 때](/1.x/hardware/printers/printed-once-then-stopped) — 먼저 전원을 껐다 켜세요

## 앱별 연결 가능 범위 {#supported-printers-by-platform}

| | Wi-Fi | USB 및 Bluetooth |
|---|---|---|
| **웹 앱** | 프린터 자체 웹 포트를 통해 Epson 및 Star에 연결합니다. HTTPS를 사용하는 매장에서는 처음 연결할 때 Chrome이 로컬 네트워크 접근 권한을 요청합니다. | 브라우저 자체 장치 선택 창을 통한 USB 및 Bluetooth Low Energy 연결 — Chrome과 Edge에서만 가능합니다. |
| **데스크톱 앱** | 모든 Wi-Fi 영수증 프린터. 네트워크를 검색해 프린터를 찾습니다. | USB, Bluetooth Low Energy, 그리고 운영체제에 이미 설치되었거나 페어링된 프린터. |
| **iPhone 및 iPad** | 모든 Wi-Fi 영수증 프린터. | Epson과 Star는 제조사 자체 소프트웨어로, 다른 제조사의 프린터는 Bluetooth Low Energy로 연결합니다. |
| **Android** | 모든 Wi-Fi 영수증 프린터. | Epson과 Star는 제조사 자체 소프트웨어로, 다른 제조사의 프린터는 Bluetooth Low Energy로 연결하거나 [설정에서 페어링](/1.x/hardware/printers/bluetooth-pairing#android-pair-first)한 뒤 Bluetooth Classic으로 연결합니다. |

브라우저는 앱처럼 프린터에 직접 연결할 수 없습니다. 그래서 웹 앱은 웹 서버가 내장된 Epson과 Star에는 Wi-Fi로 연결할 수 있지만, 다른 제조사의 프린터에는 연결할 수 없습니다. Wi-Fi로 다른 프린터를 사용하려면 데스크톱 앱이나 모바일 앱, 또는 [클라우드 프린터](/1.x/receipts/cloud-printing)를 사용하세요.

## 프린터 옵션 {#printer-options}

**설정 → 인쇄**의 각 프린터 행 아래에 다음 옵션이 있습니다.

| 옵션 | 기능 |
|---|---|
| **용지 너비** | 한 줄에 들어가는 문자 수입니다. 테스트 페이지로 설정합니다. [영수증 너비](/1.x/hardware/printers/receipt-width)를 참조하세요. |
| **용지 자동 절단** | 영수증을 인쇄할 때마다 용지를 절단합니다. |
| **현금 서랍 자동 열기** | 이 프린터에 유선으로 연결된 금전함을 엽니다. [금전함](/1.x/hardware/printers/cash-drawer)을 참조하세요. |
| **기본값으로 설정** | 다른 곳으로 라우팅되지 않은 영수증을 이 프린터로 인쇄합니다. |
| **전체 영수증 래스터** | 영수증을 텍스트 대신 이미지로 인쇄합니다. 속도는 느리지만 어떤 언어든 인쇄할 수 있습니다. [비라틴 문자 영수증](/1.x/hardware/printers/non-latin-receipts)을 참조하세요. |

:::note "결제 후 자동 인쇄"를 찾고 있나요?
판매가 완료될 때 영수증을 자동으로 인쇄하는 기능은 프린터 설정이 아니라 **장바구니 설정**입니다. POS 장바구니 설정에서 **영수증 자동 출력**을 켜세요. *어떤* 프린터로 인쇄할지는 기본 프린터와 인쇄 라우팅에 따라 결정됩니다.
:::

## 인쇄 라우팅 {#print-routing}

감열 영수증 **및** A4 송장처럼 템플릿을 둘 이상 사용한다면, 인쇄 라우팅이 각 템플릿을 어느 프린터로 인쇄할지 결정합니다. 라우팅은 다음 세 단계를 순서대로 확인합니다.

1. **작업별 재정의.** 영수증 화면의 템플릿 전환기 옆에 프린터 드롭다운이 있습니다. 여기에서 프린터를 선택하면 해당 인쇄 작업에 한해 다른 모든 설정보다 우선합니다. 템플릿을 바꾸면 다시 **자동**으로 돌아갑니다.
2. **설정 재정의.** **POS → 설정 → 인쇄**로 이동한 뒤 **영수증 템플릿** 섹션에서 템플릿마다 특정 프린터를 지정하세요. 재정의를 해제하려면 템플릿을 다시 **자동**으로 설정하세요.
3. **자동 일치.** 재정의가 없으면 WCPOS가 자동으로 연결합니다. 감열 템플릿은 너비가 맞는 감열식 프린터로 전송하고(58 mm 템플릿은 32열 프린터를, 80 mm 템플릿은 42열이나 48열 프린터를 우선합니다), HTML 템플릿은 시스템 인쇄 대화상자로 전송합니다. 조건에 맞는 프린터가 여럿이면 **기본** 프린터가 선택됩니다.

호환되지 않는 프린터로 템플릿을 보내면, 예를 들어 감열 템플릿을 시스템 대화상자로 보내면 영수증 화면에 황색 **불일치 경고**가 표시됩니다. 인쇄는 그대로 진행되지만 결과가 제대로 나오지 않을 수 있습니다.

라우팅은 **기기별로** 저장되며, 계산대마다 따로 관리합니다.

:::note
**영수증 템플릿** 설정은 프린터를 하나 이상 추가한 뒤에만 표시됩니다. 프린터가 없으면 모든 템플릿이 시스템 인쇄 대화상자를 사용합니다. 클라우드 프린터도 여기에 포함되며 라우팅 대상으로 자동으로 표시됩니다.
:::
