**증상:** iPad나 iPhone에서 검색해도 아무것도 찾지 못하거나, 주소가 올바른 프린터에 연결해도 시간 초과가 발생합니다. 같은 Wi-Fi에 연결된 컴퓨터에서는 해당 프린터가 정상적으로 작동합니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

iOS는 앱을 처음 사용할 때 로컬 네트워크의 기기와 통신해도 되는지 한 번 묻습니다. 이 요청을 거절했거나, 다른 사람이 대신 응답했거나, 요청이 아예 표시되지 않았다면 이후 모든 검색과 인쇄가 차단됩니다. iOS는 이 사실을 앱에 오류로 알려 주지 않으므로 전원이 꺼진 프린터와 똑같이 보입니다.

## 권한 켜기 {#turn-the-permission-on}

1. iPad나 iPhone의 **설정** 앱을 여세요.
2. **개인정보 보호 및 보안 → 로컬 네트워크**로 이동하세요.
3. **WCPOS** 스위치를 켜세요.
4. 앱을 완전히 종료한 뒤(앱 전환기에서 위로 밀어 닫기) 다시 여세요.

그다음 **설정 → 인쇄 → 프린터 추가**로 이동해 다시 검색하세요.

## 함께 확인할 것 {#also-check}

- iPad가 게스트 네트워크나 모바일 데이터가 아니라 **매장 Wi-Fi**에 연결되어 있는지 확인하세요. [프린터에 고정 주소 지정하기](/1.x/hardware/printers/network-address)를 참조하세요.
- Wi-Fi가 켜져 있는지 확인하세요. Wi-Fi가 꺼져 있으면 권한 설정과 관계없이 로컬 주소의 프린터에 연결할 수 없습니다.

## 프린터는 작동하는데 검색에서 안 나올 때 {#if-the-scan-finds-nothing}

검색은 프린터가 네트워크에 자신의 존재를 알리는 방식에 의존하며, 일부 네트워크는 이를 차단합니다. 대신 **IP 주소 입력**을 사용하세요. 검색을 멈추고 해당 주소를 직접 확인합니다. 프린터의 상태 시트를 인쇄해 주소를 확인하세요.

## 그래도 안 되나요? {#still-stuck}

문제 화면에서 **설정 보고서 복사**를 눌러 메시지에 붙여 넣으세요. iPad가 시도한 내용과 받은 응답이 기록됩니다.
