**증상:** 프린터는 목록에 나오는데 테스트 페이지가 도착하지 않습니다. 또는 영수증 대신 알 수 없는 글자와 괄호, 기호로 가득한 종이가 나옵니다.

## 왜 이런 일이 생기나요 {#why-it-happens}

Windows에서는 프린터와 함께 설치한 드라이버가 USB 포트의 소유권을 가져갑니다. 앱은 그 드라이버를 지나 프린터에 직접 연결할 수 없기 때문에, 프린터의 **설치된 Windows 대기열**을 통해 인쇄합니다. 대기열이 영수증 명령을 그대로 통과시키기만 한다면 이 방식은 잘 작동합니다. 그런데 제조사 자체 드라이버에 연결된 대기열은 명령을 다시 그리거나 버리는 경우가 많고, 기호로 가득한 종이는 여기에서 나옵니다.

## 이렇게 하세요 {#do-this}

1. **설정 → Bluetooth 및 장치 → 프린터 및 스캐너**를 엽니다.
2. **장치 추가**를 선택하고, Windows가 프린터를 찾지 못하면 **수동으로 추가**를 선택합니다.
3. **로컬 프린터 추가**를 선택하고 목록에서 프린터의 **USB** 포트를 고릅니다.
4. 드라이버는 제조업체에서 **Generic**을, 모델에서 **Generic / Text Only**를 선택합니다.
5. 알아보기 쉬운 이름을 대기열에 지정하고 마칩니다.
6. POS로 돌아가 **설정 → 인쇄 → 프린터 추가**를 열고 다시 검색한 다음 그 대기열을 고릅니다. 그리고 테스트 페이지를 인쇄합니다.

그래도 기호로 가득한 종이가 나온다면, 앱이 여전히 제조사 드라이버 대기열을 찾고 있는 것입니다. 그 대기열을 삭제하거나, Generic/Text 대기열을 이름으로 정확히 선택했는지 확인하세요.

## 그래도 안 되나요? {#still-stuck}

문제 화면에서 **설정 보고서 복사**를 눌러 메시지에 붙여 넣으세요. 앱이 사용한 대기열 이름이 기록됩니다.
