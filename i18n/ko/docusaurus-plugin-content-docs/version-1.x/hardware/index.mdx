WCPOS는 계산대에서 이미 사용 중인 물리적 장치와 함께 작동합니다. 이 페이지에서는 영수증 프린터, 바코드 스캐너, 카드 리더기, 금전함 등 하드웨어 연결을 시작할 수 있습니다. 각 장치 유형에는 여기에서 별도의 설정 페이지가 제공되거나, 실제 설정이 있는 페이지로 연결됩니다.

:::note 기기별 설정 위치
하드웨어 허브에서는 각 기기의 설정 위치를 안내하지만, 실제 설정 단계는 한곳에 있습니다. 카드 리더의 계정 및 페어링 절차는 해당 결제 게이트웨이 페이지에 있고, 현금 서랍의 열기 설정은 영수증 프린터 페이지에 있습니다.
:::

## 카드 리더 호환성 {#card-reader-compatibility}

사용 가능한 카드 리더는 **WCPOS 실행 방식** 및 리더의 연결 유형에 따라 다릅니다:

- **웹 앱**은 **웹(브라우저) SDK**를 제공하는 리더만 사용할 수 있습니다 — 일반적으로 인터넷에 연결된 카운터형 단말기입니다. **Bluetooth 전용** 리더(예: Stripe M2 / WisePad 3, SumUp Air)와 휴대폰의 **Tap-to-Pay**는 웹 앱에서 **지원되지 않습니다**.
- 지원 여부는 범용이 아니라 **게이트웨이별**로 다릅니다 — 구매하기 전에 사용할 게이트웨이에서 해당 리더를 확인하세요([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [PayPal Reader](/payment/gateways/paypal-reader)).

각 게이트웨이 페이지에는 지원하는 정확한 리더 목록이 나와 있습니다.
