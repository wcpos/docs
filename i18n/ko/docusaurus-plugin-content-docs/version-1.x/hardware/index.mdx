WCPOS는 매장 카운터에서 이미 쓰고 있는 장치와 함께 작동합니다. 이 페이지는 하드웨어를 연결할 때 가장 먼저 보는 곳입니다 — 영수증 프린터, 바코드 스캐너, 카드 리더, 금전함. 각 장치 유형에는 이곳에 설정 페이지가 있거나, 실제 설정 방법이 있는 페이지로 안내하는 링크가 있습니다.

:::note 장치마다 한 곳에서만
하드웨어 허브는 각 장치의 설정 위치를 알려 주지만, 실제 단계는 한 곳에만 있습니다. 카드 리더의 계정과 페어링 절차는 해당 결제 게이트웨이 페이지에 있고, 금전함의 배선과 열림 설정은 금전함 페이지에 있습니다.
:::

## 카드 리더 호환성 {#card-reader-compatibility}

어떤 카드 리더를 쓸 수 있는지는 **WCPOS를 실행하는 방식**과 리더의 연결 유형에 따라 달라집니다.

- **웹 앱**은 **웹(브라우저) SDK**를 제공하는 리더만 제어할 수 있습니다. 보통 인터넷에 연결된 카운터형 단말기가 여기에 해당합니다. **Bluetooth 전용** 리더(예: Stripe M2 / WisePad 3, SumUp Air)와 휴대폰 **탭투페이**는 웹 앱에서 **지원되지 않습니다**.
- 지원 여부는 모든 리더에 공통이 아니라 **게이트웨이별**로 다릅니다. 구매하기 전에 사용할 게이트웨이([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [PayPal Reader](/payment/gateways/paypal-reader))에서 그 리더를 지원하는지 확인하세요.

각 게이트웨이 페이지에 지원되는 리더 목록이 정확히 나와 있습니다.
