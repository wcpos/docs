WCPOS는 매장 카운터에서 이미 사용 중인 장치와 함께 작동합니다. 이 페이지는 영수증 프린터, 바코드 스캐너, 카드 리더, 금전함 등 하드웨어를 연결하기 위한 시작점입니다. 각 장치 유형의 설정 페이지가 이 섹션에 있거나, 실제 설정 방법이 있는 페이지로 안내하는 링크가 제공됩니다.

:::note 장치별 설정 안내는 한 곳에
하드웨어 페이지는 각 장치의 설정 위치를 안내하며, 실제 절차는 한 곳에서만 설명합니다. 카드 리더의 계정 및 페어링 절차는 해당 결제 게이트웨이 페이지에 있고, 금전함의 배선 및 열림 설정은 금전함 페이지에 있습니다.
:::

## 카드 리더 호환성 {#card-reader-compatibility}

사용할 수 있는 카드 리더는 **WCPOS를 실행하는 방식**과 리더의 연결 유형에 따라 달라집니다:

- **웹 앱**은 **웹(브라우저) SDK**를 제공하는 리더만 제어할 수 있습니다. 보통 인터넷에 연결된 카운터형 단말기가 여기에 해당합니다. **Bluetooth 전용** 리더(예: Stripe M2 / WisePad 3, SumUp Air)와 휴대폰 **탭투페이**는 웹 앱에서 **지원되지 않습니다**.
- 지원 여부는 모든 리더에 공통이 아니라 **결제 게이트웨이별**로 다릅니다. 구매하기 전에 사용할 결제 게이트웨이([Stripe Terminal](/1.x/payment/gateways/stripe-terminal), [SumUp](/1.x/payment/gateways/sumup-terminal), [PayPal Reader](/1.x/payment/gateways/paypal-reader))에서 해당 리더를 지원하는지 확인하세요.

각 결제 게이트웨이 페이지에 지원되는 리더 목록이 정확히 나와 있습니다.
