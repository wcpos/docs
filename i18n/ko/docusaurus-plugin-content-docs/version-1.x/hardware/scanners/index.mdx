WCPOS는 모든 플랫폼에서 바코드를 스캔합니다 — 기기 **카메라**로, 일반적인 **키보드 모드** 스캐너로, 또는 USB나 Bluetooth 스캐너와의 **직접 연결**로. 대부분의 스캐너는 연결하거나 페어링하는 즉시 작동합니다. 아래 페이지에서는 안내식 설정, 계산대에서 스캔이 동작하는 방식, 그리고 감지를 세밀하게 조정하는 방법을 다룹니다.

## 스캔 방법 {#ways-to-scan}

- **카메라** — 웹, 데스크톱, iOS, Android에서 사용할 수 있습니다. 검색창의 스캔 아이콘에서 카메라를 여세요. 카메라는 필터 아래에 크기를 조절할 수 있는 패널로 나타나 상품 목록이 계속 보입니다. 추가 하드웨어가 필요 없습니다.
- **키보드 모드(HID)** — 거의 모든 스캐너의 공장 기본값입니다. 스캐너가 바코드를 "입력"하면 WCPOS가 빠른 키 입력을 인식합니다. 구성할 것이 없습니다 — 연결하거나 페어링한 후 스캔하세요.
- **직접 연결** — 시리얼 또는 POS 모드로 전환된 스캐너용: USB 시리얼과 HID-POS(브라우저의 Web Serial 및 WebHID 지원을 통해), Bluetooth SPP, 그리고 공급업체 GATT 서비스를 통한 Bluetooth LE. 직접 연결은 입력 속도, 키보드 레이아웃, 포커스가 있는 필드와 상관없이 모든 스캔을 WCPOS에 곧바로 전달합니다. 데스크톱 앱과 Chrome 기반 브라우저에서 지원되며, 데스크톱 앱은 앱 내부에 기기 선택기를 표시합니다.

:::note 어느 필드가 바코드인가요?
WCPOS는 스캔을 하나의 구성된 바코드 필드와 대조하며, 기본값은 WooCommerce의 GTIN 필드(`_global_unique_id`)입니다. [설정](/settings/wp-admin/general#barcode-field)에서 이를 `_sku`나 임의의 사용자 지정 메타 키로 지정할 수 있습니다. 변경하면 로컬 바코드 인덱스가 자동으로 다시 구축됩니다.
:::
