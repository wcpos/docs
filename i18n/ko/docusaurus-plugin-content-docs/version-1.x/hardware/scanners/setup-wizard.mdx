  <WizardStep id="kb-first-d" title="키보드 모드로 시작 — 설정할 필요 없음">

거의 모든 스캐너는 별도 설정 없이 **키보드**처럼 동작해 바코드를 하나씩 입력합니다. WCPOS는 빠른 키 입력을 스캔으로 인식합니다. 설정할 것이 없습니다.

1. **USB 스캐너:** 연결하면 끝입니다.
2. **Bluetooth 스캐너:** 페어링 모드로 전환한 뒤(설명서를 확인하세요. 보통 트리거를 길게 누르거나 특정 비프음 순서를 사용합니다) 다른 키보드처럼 **시스템 Bluetooth 설정**에서 페어링하세요.
3. WCPOS를 열고 제품 바코드를 하나 스캔하세요. 제품이 표시되고 판매에 추가되어야 합니다.

  <WizardFix id="fix-nothing" title="스캔해도 아무 반응이 없을 때">

1. **스캐너가 반응하나요?** 트리거를 당겨 보세요. 비프음이나 불빛이 없다면 WCPOS가 아니라 전원 또는 배터리 문제입니다.
2. **연결되어 있나요?** Bluetooth 설정에 단순히 “페어링됨”이 아니라 **연결됨**으로 표시되어야 합니다. 확실하지 않다면 다시 페어링하세요.
3. **입력되는지 확인하세요:** 아무 메모 앱이나 빈 텍스트 입력란을 열고 스캔해 보세요. 문자가 나타나면 스캐너는 정상이며 POS가 입력을 스캔으로 인식하지 못하는 것입니다.
4. 스캔이 입력되지만 WCPOS가 무시한다면 여세요 <kbd>설정</kbd> → <kbd>바코드 스캔</kbd> **테스트 패널**에 스캔하세요. 각 시도가 왜 타이핑으로 처리되었는지 정확히 보여 주고, **적용** 버튼으로 해결 방법(예: 타이밍 임계값 올리기)을 제안합니다.

    <WizardGate id="g-fix-nothing" question="이제 스캔이 작동하나요?">
      <WizardChoice value="yes" label="네 — 해결되었습니다" goTo="success-kb" />
      <WizardChoice value="no" label="아니요, 여전히 반응이 없습니다" goTo="support" />
    </WizardGate>
  </WizardFix>

  <WizardFix id="fix-garbled-d" title="스캔 결과가 깨져서 나올 때">

키보드 모드 스캐너는 **키보드 레이아웃**을 사용해 입력합니다. 스캐너와 기기의 레이아웃이 다르면(QWERTY와 AZERTY, 기호 위치 등) 문자가 뒤바뀝니다.

1. **테스트 패널**에 스캔하세요(<kbd>설정</kbd> → <kbd>바코드 스캔</kbd>). Shift를 별도의 키로 보내는 스캐너처럼 흔한 문제를 감지하고 무엇이 나타나는지 알려 줍니다.
2. 스캐너 설명서에서 **“키보드 언어”** 또는 **“키보드 레이아웃”** 설정 바코드를 찾아 기기에 맞게 설정하세요(보통 US 레이아웃이 무난합니다).
3. 가장 확실한 해결책은 **직접 연결**입니다. 직접 연결된 스캐너는 바코드를 데이터로 전송하므로 키보드 레이아웃의 영향을 받지 않아 문자가 깨지지 않습니다.

  <WizardStep id="mode-netum" title="Netum을 시리얼(SPP) 모드로 전환">

Netum은 키보드(HID) 모드로 출고됩니다. 직접 연결하려면 **사용 중인 모델의 설명서**에 있는 바코드로 모드를 전환하세요:

:::info 설명서에서 다음 항목을 찾아 해당 이름의 바코드를 스캔하세요:
**`Bluetooth SPP Mode`**

섹션: **“Bluetooth Connection Modes”** — 모든 모델의 Netum 설명서는 [netum.net → Barcode Scanner User Manuals](https://www.netum.net/pages/barcode-scanner-user-manuals)에서 확인할 수 있습니다. SPP 모드에 대한 Netum의 설명은 다음과 같습니다: *“스캐너를 지원하는 애플리케이션을 사용하는 경우 권장되는 모드입니다.”*
:::

:::warning 삭제한 다음 다시 페어링하세요
모드를 전환한 뒤에도 기기는 이전의 키보드 페어링을 기억하고 있습니다. **시스템 Bluetooth 설정**을 열고 스캐너를 삭제/제거한 다음 다시 페어링하세요. 이 과정을 건너뛰는 것이 다음 단계가 실패하는 가장 흔한 원인입니다.
