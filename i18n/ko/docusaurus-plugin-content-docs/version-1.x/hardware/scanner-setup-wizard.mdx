WCPOS는 기기의 카메라로 바코드를 스캔할 수 있습니다. POS 검색창의 **카메라 아이콘**을 탭하고 바코드를 비추세요.

웹캠이 있는 휴대폰, 태블릿, 노트북에서 작동하며, 처음 시작하거나 가끔 스캔할 때 적합한 방법입니다. 바쁜 계산대에서는 전용 스캐너가 더 빠르므로, 스캐너를 마련하면 이 마법사를 다시 실행하세요.

  <WizardStep id="kb-first-d" title="키보드 모드로 시작하세요 — 설정할 것이 없습니다">

거의 모든 스캐너는 별도의 설정 없이 **키보드**처럼 동작하여 바코드를 하나씩 “입력”합니다. WCPOS는 이 빠른 키 입력을 스캔으로 인식합니다. 구성할 것이 전혀 없습니다.

1. **USB 스캐너:** 연결하기만 하면 됩니다.
2. **Bluetooth 스캐너:** 페어링 모드로 전환한 뒤(설명서를 확인하세요. 보통 트리거를 길게 누르거나 특정 비프음 순서를 사용합니다) 다른 키보드와 마찬가지로 **시스템 Bluetooth 설정**에서 페어링하세요.
3. WCPOS를 열고 아무 제품 바코드나 스캔하세요. 해당 제품이 표시되고 판매에 추가되어야 합니다.

Safari와 Firefox에서 WCPOS는 **키보드 모드** 스캐너와 **카메라 스캔**을 지원합니다. 스캐너 직접 연결에는 **데스크톱 앱** 또는 **Chromium 브라우저**(Chrome/Edge)가 필요합니다. 이 브라우저에서는 직접 연결용 API를 사용할 수 없습니다.

**세부 조정:** <kbd>설정</kbd> → <kbd>바코드 스캔</kbd>을 열고 **테스트 패널**을 사용하세요. 여기에 스캔하면 스캐너의 키 입력 타이밍을 그래프로 보여주고, 한 번의 탭으로 **적용**할 수 있는 설정(임계값, 접두/접미 문자)을 제안합니다.

  <WizardFix id="fix-nothing" title="스캔해도 아무 반응이 없을 때">

1. **스캐너가 반응하나요?** 트리거를 당겨 보세요. 비프음이나 불빛이 없다면 WCPOS가 아니라 전원/배터리 문제입니다.
2. **연결되어 있나요?** Bluetooth 설정에 단순히 “페어링됨”이 아니라 **연결됨**으로 표시되어야 합니다. 확실하지 않다면 다시 페어링하세요.
3. **입력이 되는지 확인하세요.** 아무 메모 앱이나 빈 텍스트 입력란을 열고 스캔해 보세요. 거기에 문자가 나타난다면 스캐너는 정상이며, POS가 그 입력을 스캔으로 인식하지 못하는 것입니다.
4. 입력은 되는데 WCPOS가 무시한다면 <kbd>설정</kbd> → <kbd>바코드 스캔</kbd>을 열고 **테스트 패널**에 스캔하세요. 각 시도가 왜 일반 타이핑으로 처리되었는지 정확히 보여주고, **적용** 버튼과 함께 해결 방법(예: 타이밍 임계값 상향)을 제안합니다.

      <WizardChoice value="no" label="아니요, 여전히 반응이 없습니다" goTo="support" />
    </WizardGate>
  </WizardFix>

  <WizardFix id="fix-garbled-d" title="스캔 결과가 깨져서 나올 때">

키보드 모드 스캐너는 **키보드 레이아웃**을 사용해 “입력”합니다. 스캐너의 레이아웃이 기기의 레이아웃과 다르면(QWERTY와 AZERTY, 기호 위치 차이 등) 문자가 뒤바뀝니다.

1. **테스트 패널**(<kbd>설정</kbd> → <kbd>바코드 스캔</kbd>)에 스캔하세요. 스캐너가 Shift를 별도의 키로 전송하는 등 흔한 사례를 감지하여 무엇이 보이는지 알려 줍니다.
2. 스캐너 설명서에서 **“키보드 언어”** 또는 **“키보드 레이아웃”** 설정 바코드를 찾아 기기와 일치하도록 설정하세요(보통 US 레이아웃이 무난합니다).
3. 가장 확실한 해결책은 **직접 연결**입니다. 직접 연결된 스캐너는 바코드를 데이터로 전송하므로 키보드 레이아웃이 관여하지 않고, 따라서 문자가 깨질 일이 없습니다.

1. **아직 키보드 모드일 가능성이 높습니다.** 가장 흔한 원인입니다. 모드 바코드가 적용되지 않았을 수 있으니 다시 스캔한 다음 스캐너의 전원을 껐다 켜세요. 간단한 확인 방법은 아무 텍스트 입력란을 클릭하고 트리거를 당겨 보는 것입니다. 문자가 나타나면 여전히 키보드입니다. Eyoyo에서는 Bluetooth 이름을 확인하세요. `ScannerSPP`로 표시되어야 합니다.
2. **이전 페어링이 방해하고 있습니다**(Bluetooth). 시스템 Bluetooth 설정에서 스캐너를 삭제/제거하고 모드 전환 *이후에* 다시 페어링하세요. 선택기에는 올바르게 페어링된 시리얼 기기만 표시됩니다.
3. **표시되지만 연결되지 않는 경우:** 포트를 점유하고 있을 수 있는 제조사 구성 도구를 모두 닫고, 스캐너를 가까이 가져간 다음 다시 시도하세요.
4. **여전히 안 되나요?** 일부 스캐너는 시리얼 연결을 비표준 방식으로 알리기 때문에 선택기가 아직 표시하지 못합니다. 이는 사용자 문제가 아니라 저희 쪽 문제입니다. 스캐너의 **브랜드와 모델**을 알려 주시고 지원팀에 문의하세요.
