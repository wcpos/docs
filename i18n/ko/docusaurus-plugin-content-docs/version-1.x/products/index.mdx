:::info 프로 기능
제품 화면을 사용하려면 [WCPOS Pro](/1.x/getting-started/pro-license)가 필요합니다. 무료 사용자는 [POS 제품 패널](/1.x/pos/product-panel)에서 제품을 보고 장바구니에 추가할 수 있지만, 재고나 가격을 편집할 수는 없습니다.
:::

제품 화면은 재고 관리 전용 인터페이스입니다. 판매용인 [POS 제품 패널](/1.x/pos/product-panel)과 달리, 이 화면은 제품 카탈로그를 관리하도록 설계되었습니다.

## 제품 화면과 POS 제품 패널 비교 {#products-screen-vs-pos-product-panel}

| 기능 | POS 제품 패널 | 제품 화면 |
|---------|-------------------|-----------------|
| **목적** | 장바구니에 제품 추가 | 재고 관리 |
| **재고** | 조회만 가능 | 목록에서 직접 편집 |
| **가격** | 조회만 가능 | 목록에서 직접 편집 |
| **작업** | 장바구니에 추가 | 편집, 동기화, 삭제 |
| **사용 가능 버전** | 무료 + Pro | Pro 전용 |

## 인터페이스 개요 {#interface-overview}

### 검색 및 필터 {#search--filters}

화면 상단에는 다음 항목이 있습니다:

- **검색 창** - 이름, SKU 또는 바코드로 제품 검색
- **필터 버튼** - 재고 상태, 추천 제품, 판매 중, 카테고리, 태그, 브랜드
- **표시 설정** (<Icon name="sliders" />) - 표시할 열 설정

### 제품 목록 {#product-list}

주요 영역에는 제품이 스크롤 가능한 표로 표시됩니다:

- **이미지** - 제품 썸네일
- **제품 이름** - 설정에 따라 SKU, 바코드, 속성을 함께 표시
- **재고** - ‘관리’ 토글이 있는 편집 가능한 재고 수량
- **재고 상태** - 재고 있음(녹색), 품절(빨간색), 백오더
- **카테고리** - 제품 카테고리 배지
- **가격** - 현재 가격, 정가, 판매 가격(모두 편집 가능)
- **작업** - 편집, 동기화, 삭제 항목이 있는 점 세 개 메뉴

:::note 정렬과 필터링은 매장 전체에 적용됩니다
정렬과 필터링은 **서버**에서 실행되므로 기기에 이미 저장된 제품뿐 아니라 전체 카탈로그에 적용됩니다. 이름, SKU, 재고, 가격 또는 날짜로 정렬하면 스크롤할 때마다 카탈로그 끝까지 목록에 행이 계속 추가됩니다. 반면 제품 **검색**은 카탈로그가 로컬에 저장된 후에는 기기에서 실행되므로 서버 요청 없이 즉시 결과를 반환합니다.
:::

### 변동 제품 {#variable-products}

변동 제품에는 다음 정보가 표시됩니다:
- 속성 옵션(색상, 크기 등)
- 모든 변형을 볼 수 있는 ‘확장’ 링크
- 재고와 가격이 각각 표시되는 개별 변형 행

### 바닥글 {#footer}

- **세금 상태** - 현재 세금 계산 기준
- **제품 수** - ‘Y개 중 X개 표시’ 및 동기화 버튼 (<Icon name="arrow-rotate-right" />). 동기화 버튼을 **길게 누르면** 지우고 새로고침 옵션이 표시됩니다(v1.10.0부터는 화면의 검색어와 활성 필터도 함께 지워지므로 목록이 필터 없이 다시 표시됩니다)

## 주요 기능 {#key-features}

### 인라인 재고 편집 {#inline-stock-editing}

재고 수량을 클릭하여 직접 편집하세요:

1. 재고 수량을 클릭하세요
2. 새 수량을 입력하세요
3. Enter를 눌러 저장하세요

변경 사항은 WooCommerce에 자동으로 동기화됩니다.

### 재고 관리 토글 {#manage-stock-toggle}

‘관리’ 토글은 WooCommerce에서 이 제품의 재고를 추적할지 결정합니다:

- **켜기** - 재고 수량을 추적하고 판매 시 차감합니다
- **끄기** - 제품을 항상 판매할 수 있습니다(무한 재고)

### 인라인 가격 편집 {#inline-price-editing}

편집하려는 가격 필드를 클릭하세요:

- **가격** - 현재 판매 가격
- **정가** - 할인 전 가격
- **판매 가격** - 할인된 가격(할인 판매 시)

### 매출원가 {#cost-of-goods-sold}

WooCommerce의 매출원가(COGS) 기능을 사용하면 각 제품의 원가를 추적할 수 있습니다. WCPOS는 이 데이터를 제품 화면에 표시합니다.

원가를 보려면 **매출원가** 열을 활성화하세요. 설정 위치: [표시 설정](#display-settings) (<Icon name="sliders" />)에서 **매출원가** 열을 활성화하세요. 이 열은 판매 가격과 함께 원가를 표시하여 마진을 한눈에 검토하기 쉽게 합니다.

:::info 프로 기능
[WCPOS Pro](/1.x/getting-started/pro-license) 사용자는 제품 화면에서 원가를 직접 **수정**할 수 있습니다. 재고 및 가격 필드와 마찬가지로 원가 값을 클릭하여 목록에서 바로 업데이트하세요.
:::

:::note WooCommerce 요구 사항
매출원가는 WooCommerce 스토어에서 활성화되어 있어야 합니다: **WooCommerce > Settings > Advanced > Features**로 이동하여 매출원가 옵션을 활성화하세요. 이 기능에는 매출원가 기능이 활성화된 최신 버전의 WooCommerce가 필요합니다. 설정 세부 정보는 WooCommerce 문서를 참조하세요.
:::

### 제품 작업 {#product-actions}

각 제품에 대해 세 점 메뉴 (⋮)를 클릭합니다:

- **편집** - 제품 편집 모달 열기
- **동기화** - WooCommerce에서 이 제품 새로 고침
- **삭제** - 로컬 데이터베이스에서 제품 제거

:::note
POS에서 상품을 삭제해도 **로컬에서만** 제거됩니다. 상품은 WooCommerce에 남아 있으며 다음 동기화 때 다시 표시됩니다. WooCommerce에서 상품을 삭제하면 동기화 시 POS에서도 제거되어 기기와 매장 정보가 일치합니다.
:::

### 사용 가능한 열 {#available-columns}

| 열 | 설명 | 표시 옵션 |
|--------|-------------|-----------------|
| **이미지** | 제품 썸네일 | - |
| **ID** | WooCommerce 제품 ID | - |
| **제품** | 제품 이름 | SKU, 바코드, 속성 |
| **유형** | 단순, 변동, 그룹 등 | - |
| **SKU** | 재고 관리 단위 | - |
| **바코드** | 제품 바코드 | - |
| **재고** | 현재 수량 (편집 가능) | - |
| **재고 상태** | 재고 있음 / 품절 / 백오더 | - |
| **카테고리** | 제품 카테고리 | - |
| **태그** | 제품 태그 | - |
| **브랜드** | 브랜드 정보 (플러그인이 활성화된 경우) | - |
| **매출원가** | 제품 원가 (Pro에서 편집 가능) | - |
| **가격** | 현재 판매 가격 (편집 가능) | 세금 정보 |
| **정가** | 할인되지 않은 가격 (편집 가능) | 세금 정보 |
| **판매 가격** | 할인된 가격 (편집 가능) | 세금 정보 |
| **생성일** | 제품 생성 일자 | - |
| **수정일** | 마지막 수정 일자 | - |
| **작업** | 편집, 동기화, 삭제 버튼 | - |

### 기본 설정 복원 {#restore-default-settings}

클릭하여 모든 표시 설정을 기본값으로 재설정합니다.

## 제품 필터링 {#filtering-products}

필터 버튼을 사용하여 보기를 좁힙니다:

- **재고 상태** - 재고 있음, 품절, 백오더
- **추천 제품** - 추천으로 표시된 제품
- **판매 중** - 현재 할인 중인 제품
- **카테고리** - 제품 카테고리로 필터링
- **태그** - 제품 태그로 필터링
- **브랜드** - 브랜드로 필터링 (브랜드 플러그인 사용 시)

## 정렬 {#sorting}

열 헤더를 클릭하여 해당 열로 정렬합니다. 다시 클릭하면 정렬 순서가 역전됩니다.
