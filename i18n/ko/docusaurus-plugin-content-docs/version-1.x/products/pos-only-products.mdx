POS 전용 제품은 제품을 온라인 매장, POS 또는 양쪽 모두에 표시할지 설정하는 기능입니다. 온라인 판매와 매장 판매에 서로 다른 제품 카탈로그를 사용할 때 유용합니다.

## 개요 {#overview}

이 기능을 활성화하면 각 제품에 세 가지 옵션이 있는 **POS 가시성** 설정이 추가됩니다:

| 가시성 | 온라인 매장 | POS |
|------------|--------------|-----|
| **POS & 온라인** (기본값) | 표시됨 | 표시됨 |
| **POS 전용** | 숨김 | 표시됨 |
| **온라인 전용** | 표시됨 | 숨김 |

## 이 기능이 필요한 경우 {#when-to-use-this-feature}

다음과 같은 경우 POS 전용 제품 기능을 활성화하세요:

- **매장 전용 제품 판매** - 고객이 실제 매장을 방문해야 구매할 수 있는 제품
- **온라인 전용 품목을 POS에서 숨기기** - 디지털 제품, 예약 주문 제품 또는 매장에서 판매하면 안 되는 품목
- **서로 다른 카탈로그 관리** - 온라인과 오프라인 판매 채널별로 구분된 제품군
- **프로모션 품목 관리** - 매장 전용 특별 상품 또는 온라인 전용 할인 상품

:::tip
모든 제품을 두 채널에 모두 표시해야 한다면 이 기능은 필요하지 않습니다. 성능을 위해 비활성화해 두세요.
:::

## 기능 활성화 {#enabling-the-feature}

1. **WP Admin > POS > 설정 > 일반**으로 이동하세요
2. **"POS 전용 제품 활성화"** 옵션을 켜세요
3. 변경 사항을 저장하세요

일반 설정에 대한 자세한 내용은 [WP Admin 일반 설정](/1.x/settings/wp-admin/general)을 참조하세요.

:::warning 성능에 미치는 영향
이 설정은 필요할 때만 활성화하세요. 활성화하면 제품을 요청할 때마다 데이터베이스 조회가 추가되어 카탈로그가 큰 매장의 성능에 영향을 줄 수 있습니다.
:::

## 제품 가시성 설정 {#setting-product-visibility}

### 개별 제품 {#individual-products}

단일 제품의 가시성을 설정하려면:

1. **WP Admin → 제품**으로 이동하여 제품을 편집하세요
2. **제품 데이터** 패널에서 **POS 가시성**을 찾으세요
3. 원하는 옵션을 선택하세요:
   - **POS & 온라인** - 제품을 모든 채널에 표시(기본값)
   - **POS 전용** - 온라인 매장에서 제품 숨김
   - **온라인 전용** - POS에서 제품 숨김
4. **업데이트**를 클릭하여 저장하세요

### 일괄 편집 {#bulk-editing}

여러 제품의 가시성을 한 번에 변경하려면:

1. **WP Admin → 제품**으로 이동하세요
2. 체크박스로 수정할 제품을 선택하세요
3. **일괄 작업** 드롭다운에서 **편집**을 선택하세요
4. **적용**을 클릭하세요
5. 일괄 편집 패널에서 **POS 가시성** 드롭다운을 찾으세요
6. 원하는 가시성 옵션을 선택하세요
7. **업데이트**를 클릭하세요

### 변동 제품 {#variable-products}

변동 제품은 부모 제품과 각 개별 변형의 가시성을 모두 설정할 수 있습니다. 이를 통해 세밀하게 제어할 수 있습니다. 예를 들어 온라인에는 모든 변형을 표시하고 매장에는 특정 색상이나 크기만 표시할 수 있습니다.

## POS에 미치는 영향 {#how-it-affects-the-pos}

제품을 **온라인 전용**으로 설정하면:

- [제품 패널](/1.x/pos/product-panel)에 표시되지 않습니다
- 검색이나 바코드 스캔으로 찾을 수 없습니다
- POS에서 장바구니에 추가할 수 없습니다

제품을 **POS 전용**으로 설정하면:

- 매장 카탈로그, 카테고리 페이지 및 WooCommerce 자체 검색에서 제외됩니다
- 장바구니에 추가하거나 온라인으로 구매할 수 없습니다
- WooCommerce REST API 및 Store API 제품 목록에서 제외됩니다

**Catalog visibility도 Hidden으로 설정하세요.** POS 전용 설정과 상품 편집 화면의 Publish 상자에서 POS 가시성 바로 위에 있는 WooCommerce의 **Catalog visibility**는 별개의 설정입니다. WCPOS는 POS 전용 상품을 표준 WooCommerce 상품 쿼리에서 제외하지만, WooCommerce의 카탈로그 표시 설정을 직접 읽는 기능에서는 Catalog visibility를 **Hidden**으로 설정하지 않으면 상품이 계속 표시됩니다. 여기에는 FiboSearch나 Relevanssi 같은 검색 플러그인, 관련 상품, ID로 상품을 나열하는 블록 또는 쇼트코드가 포함됩니다. 설정하려면 Publish 상자에서 **Catalog visibility** 옆의 **Edit**를 클릭하고 **Hidden**을 선택한 다음 **Update**를 클릭하세요. 반대의 경우에도 두 설정은 별개입니다. 나중에 상품을 **POS & Online** 또는 **Online Only**로 변경하면 Catalog visibility도 직접 **Shop and search results**로 되돌려야 합니다. 그렇지 않으면 웹사이트에서 계속 숨겨집니다.

:::note
최근 제품의 가시성을 변경했는데 POS에 여전히 표시되거나 표시되지 않는다면 동기화를 시도하세요. 동기화 버튼을 길게 누르고 **"지우고 새로고침"** 을 선택하여 모든 제품 데이터를 다시 불러오세요.
:::

### POS 전용 제품이 계속 표시되는 위치 {#where-pos-only-products-stay-visible}

POS 전용 제품을 숨기는 규칙은 고객이 쇼핑하는 화면에 적용됩니다. 매장을 운영하고 관리하는 다음 위치에서는 제품이 계속 표시됩니다:

- 제품 목록과 제품 편집기를 포함한 **WP Admin**
- **WooCommerce Analytics**: POS 전용 제품으로 구성된 카테고리로 보고서를 필터링해도 해당 제품의 판매 내역이 표시됩니다
- `wp wc product list`와 같은 **WP-CLI** 명령
- **POS 자체**

제품은 매장 카탈로그와 검색, 블록 장바구니 및 결제에 사용되는 WooCommerce Store API, WooCommerce REST API (`/wc/v3/products`), 그리고 제품 피드와 사이트맵 등 이를 기반으로 하는 기능에서 숨겨집니다.

개발자는 `woocommerce_pos_hide_pos_only_products` 필터를 사용하여 특정 상황에서의 숨김 여부를 변경할 수 있습니다. 이 필터에는 기본 판단 결과와 실행 예정인 `WP_Query`가 전달됩니다. 해당 쿼리에서 POS 전용 제품을 조회할 수 있도록 하려면 `false`를 반환하세요.

```php
add_filter( 'woocommerce_pos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

## 일반적인 사용 사례 {#common-use-cases}

<UseCases>
  <UseCaseCard icon="gift" title="매장 전용 기프트 카드">

  계산대에서 활성화해야 하는 실물 기프트 카드:

  1. 기프트 카드 제품을 생성하세요
  2. 가시성을 **POS 전용**으로 설정하세요
  3. 카드는 온라인에 표시되지 않지만 직원이 매장에서 판매할 수 있습니다

  </UseCaseCard>

  <UseCaseCard icon="globe" title="온라인 예약 주문">

  아직 입고되지 않았지만 온라인으로 예약 주문할 수 있는 제품:

  1. 예약 주문 제품을 생성하세요
  2. 가시성을 **온라인 전용**으로 설정하세요
  3. 고객은 온라인으로 예약 주문할 수 있고, POS에는 불필요한 제품이 표시되지 않습니다

  </UseCaseCard>

  <UseCaseCard icon="building" title="도매와 소매">

  동일한 WooCommerce 매장에서 도매와 소매를 모두 운영하는 경우:

  1. 도매 전용 제품을 **온라인 전용**으로 설정하세요(B2B 포털 접근용)
  2. 소매 전용 제품을 **POS 전용**으로 설정하세요
  3. 일반 제품은 **POS & 온라인**으로 유지하세요

  </UseCaseCard>
</UseCases>

## 문제 해결 {#troubleshooting}

<Accordion>
  <AccordionItem question="온라인 전용으로 설정한 후에도 제품이 표시됩니다">

  1. POS를 여세요
  2. 제품 패널 하단의 동기화 버튼을 길게 누르세요
  3. **"지우고 새로고침"** 을 선택하세요
  4. 제품을 다시 불러올 때까지 기다리세요

  </AccordionItem>

  <AccordionItem question="제품에 설정이 표시되지 않습니다">

  기능이 활성화되어 있는지 확인하세요:

  1. **WP Admin > POS > 설정 > 일반**으로 이동하세요
  2. **"POS 전용 제품 활성화"** 가 선택되어 있는지 확인하세요
  3. 변경한 내용이 있으면 설정을 저장하세요

  </AccordionItem>

  <AccordionItem question="POS 전용 제품이 웹사이트에 계속 표시됩니다">

  다음 두 가지를 확인하세요:

  1. **Catalog visibility가 Hidden인지 확인하세요.** 상품을 열고 Publish 상자에서 **Catalog visibility**를 확인하세요. **Hidden**이 아니면 **Edit**를 클릭하고 **Hidden**을 선택한 다음 상품을 업데이트하세요. 검색 플러그인, 관련 상품, 상품 ID를 나열하는 블록이나 쇼트코드는 WCPOS의 POS 표시 설정이 아니라 이 WooCommerce 설정을 읽으므로 POS 전용 설정만으로는 숨길 수 없습니다.
  2. **페이지가 캐시되지 않았는지 확인하세요.** 캐시 플러그인이나 CDN은 제품이 POS 전용으로 변경되기 전에 렌더링된 매장 또는 검색 페이지를 계속 제공할 수 있습니다. 가시성을 변경한 후 사이트 캐시를 지우세요.

  직접 링크로 제품에 접근하면 제품 페이지는 계속 표시됩니다. WooCommerce 자체의 숨김 설정도 동일하게 작동합니다. 해당 페이지에서 제품을 장바구니에 추가할 수는 없습니다.

  </AccordionItem>

  <AccordionItem question="POS 전용 제품 카테고리의 분석에 ‘데이터 없음’이 표시됩니다">

  WCPOS 플러그인 1.10.26까지는 고객용 매장 화면에 적용되는 규칙이 WooCommerce Analytics에도 적용되었습니다. POS 전용 제품으로 구성된 카테고리로 보고서를 필터링하면 제품을 찾지 못해 **데이터 없음**이 표시됐지만, 동일한 제품을 이름으로 검색하면 판매 내역이 표시됐습니다.

  이 문제는 1.10.26 이후 첫 WCPOS 플러그인 릴리스에서 수정되었습니다. 플러그인을 업데이트하세요. 제품이나 보고서 설정을 변경할 필요는 없습니다.

  </AccordionItem>
</Accordion>
