:::info Pro 기능
[WCPOS Pro](https://wcpos.com/pro)는 WCPOS의 관리 화면, 추가 결제 게이트웨이 및 기타 Pro 전용 기능을 제공하는 유료 플러그인입니다.

**v1.8 이상부터 Pro는 독립형 플러그인입니다** — 무료 [WCPOS 플러그인](https://wordpress.org/plugins/woocommerce-pos/)을 함께 설치할 필요가 없습니다.
:::

## Pro에 포함된 기능 {#whats-included-in-pro}

WCPOS Pro를 사용하면 다음 기능을 이용할 수 있습니다:

- **상품 화면** - POS에서 바로 재고와 가격을 수정합니다.
- **주문 화면** - 주문 내역을 확인하고 관리합니다.
- **고객 화면** - 고객 정보를 추가하고 수정합니다.
- **보고서 화면** - 일일 판매 보고서를 생성합니다.
- **추가 결제 게이트웨이** - Stripe Terminal, SumUp 및 사용자 지정 게이트웨이

## 설치 {#installation}

WCPOS Pro 라이선스를 구매했다면 아래 단계에 따라 플러그인을 설치하고 활성화하세요:

:::note 이전 버전에서 업그레이드하시나요?
이전에 무료 WCPOS 플러그인과 구형 Pro 애드온을 모두 설치했다면 새 독립형 Pro 플러그인을 활성화하기 전에 **무료 플러그인을 비활성화하고 삭제하세요**. 두 플러그인을 함께 실행하면 *"Invalid response fetching remote state"* 또는 치명적인 *"Class not found"* 오류와 같은 활성화 오류가 발생할 수 있습니다.
:::

1. 다음 주소로 이동하세요: [https://wcpos.com/account/downloads](https://wcpos.com/account/downloads)
2. **Downloads**에서 다운로드 링크를 클릭하고 플러그인을 데스크톱에 저장하세요.
3. 그런 다음 사이트에 로그인하고 `WP Admin > 플러그인 > Add Plugin > 플러그인 업로드`로 이동하세요.
4. 데스크톱에 저장한 플러그인 zip 파일을 업로드하고 활성화하세요.
5. 그런 다음 `WP Admin > POS > 설정 > License`로 이동해 라이선스 키([라이선스 페이지](https://wcpos.com/account/licenses)에 표시됨)와 라이선스 이메일을 입력하여 활성화를 완료하세요.

## 업데이트 {#updates}

새 버전이 준비되면 다른 플러그인과 마찬가지로 업데이트 대시보드에 표시됩니다. [계정 페이지](https://wcpos.com/account/downloads)에서 최신 버전을 다운로드할 수도 있습니다.

## Pro 및 데이터 제거 {#uninstalling}

Pro 플러그인을 제거하면 Pro 자체의 운영 데이터는 삭제되지만 **라이선스 키를 포함한 Pro 설정과 매장 구성은 유지**되므로 다시 설치하면 이전 상태에서 이어서 사용할 수 있습니다. 공유 번역 데이터는 **무료** 플러그인도 제거한 경우에만 삭제되므로 Pro만 제거해도 무료 플러그인에는 영향을 주지 않습니다.

설정, 라이선스, 매장 구성까지 모두 제거해 완전히 초기화하려면 제거 전에 `wcpos_remove_all_data`를 정의해 전체 삭제를 선택하세요. 그렇게 하지 않으면 안전하게 제거할 수 있고 되돌릴 수 있습니다.

## 문제 해결 {#troubleshooting}

### 활성화 실패 {#activation-failures}

- **"Invalid licence key"** — 붙여넣을 때 끝에 공백이 들어가지 않았는지 확인하고, 구매할 때 사용한 이메일 주소와 일치하는지 확인하세요.
- **"Licence limit reached"** — 기본적으로 라이선스는 **도메인 2개**에서 활성화됩니다(운영 사이트 하나와 스테이징 사이트 하나를 위한 것입니다). **하위 도메인도 별도 활성화로 계산됩니다** — `example.com`, `staging.example.com`, `dev.example.com`은 세 개로 계산됩니다. 필수 dev/test/live 환경을 사용하는 Pantheon 같은 호스트에서 이 문제가 자주 발생합니다. [계정 페이지](https://wcpos.com/account/licenses)에서 사용하지 않는 사이트를 비활성화하거나 **support@wcpos.com**으로 이메일을 보내세요. 요청하면 추가 활성화 권한을 보통 받을 수 있습니다.

### 만료된 라이선스 {#expired-licence}

- 라이선스가 만료되어도 Pro 기능은 계속 활성화되어 있지만 업데이트를 받을 수 없습니다.
- [계정 페이지](https://wcpos.com/account/licenses)에서 갱신하세요. 기존 키는 그대로 유지됩니다.

### 도메인 이전 {#domain-transfers}

- 사이트를 새 도메인으로 옮겼다면 먼저 이전 도메인에서 라이선스를 비활성화한 다음 새 도메인에서 다시 활성화하세요.
- 이전 도메인에 더 이상 접속할 수 없다면 **support@wcpos.com**에 문의해 활성화를 초기화하세요.

### 라이선스 서버 연결 {#licence-server-connectivity}

- 활성화하려면 WordPress 서버가 WCPOS 라이선스 서버에 연결할 수 있어야 합니다.
- 활성화에 실패해도 아무 메시지가 표시되지 않는다면 호스트의 방화벽이나 보안 플러그인이 외부 HTTPS 요청을 차단하고 있지 않은지 확인하세요.
- 일부 관리형 호스트는 기본적으로 외부 API 호출을 차단합니다. 호스트에 문의해 `wcpos.com`을 허용 목록에 추가하세요.

### 라이선스 상태 확인 {#checking-licence-status}

- 현재 활성화 상태를 확인하려면 `WP Admin > POS > 설정 > License`로 이동하세요.
- [계정 페이지](https://wcpos.com/account/licenses)에서 활성화된 모든 사이트와 만료일을 확인할 수 있습니다.

## 라이선스 구매 {#purchase-a-license}

Pro 라이선스를 구매하려면 [wcpos.com/pro](https://wcpos.com/pro)를 방문하세요.

:::note 구매 및 업그레이드는 웹사이트에서 진행합니다
앱 안에는 "Pro로 업그레이드" 버튼이 없습니다. 구매, 요금제 업그레이드 및 갱신은 모두 [wcpos.com](https://wcpos.com/pro)과 [계정 페이지](https://wcpos.com/account/licenses)에서 처리합니다. 구매 후 [위 단계](#installation)에 따라 Pro를 설치하세요.
:::
