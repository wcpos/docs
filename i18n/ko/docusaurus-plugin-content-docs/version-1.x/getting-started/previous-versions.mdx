## 이전 버전 재설치 {#re-installing-a-previous-version}

플러그인의 이전 버전으로 되돌리려면 자동 업데이트를 끄고 원하는 버전을 다운로드한 다음, 기존 플러그인 위에 업로드하세요. 이 과정에서 아무것도 삭제되지 않으므로 주문, 설정, 영수증 템플릿이 그대로 유지됩니다.

:::warning 플러그인을 먼저 삭제하지 마세요
기존 플러그인 위에 `.zip` 파일을 업로드하면 모든 항목이 유지됩니다. 2.0에서는 **플러그인**에서 WCPOS를 삭제하면 정리 작업이 실행됩니다. 모든 캐셔가 로그아웃되므로 각 계산대에서 다시 로그인해야 하고, 각 계산대가 다시 구축하는 동기화 데이터도 지워집니다. 삭제할 이유가 없습니다.
:::

2.0에서 이전 버전으로 돌아가려면 먼저 [롤백](/getting-started/upgrading-to-2#rolling-back)을 읽으세요. WCPOS Pro를 사용한다면 WCPOS Pro만 롤백하세요. 여기에는 무료 플러그인이 포함되어 있습니다.

### 자동 업데이트 끄기 {#turn-off-auto-updates}

자동 업데이트가 켜져 있으면 WordPress가 최신 버전을 다시 자동으로 설치합니다.

1. **WP 관리자 → 플러그인**으로 이동하세요.
2. WCPOS 행(또는 WCPOS Pro 행)의 **자동 업데이트** 열을 확인하세요. **자동 업데이트 사용 안 함**이라고 표시되어 있으면 클릭하세요.

### 필요한 버전 다운로드하기 {#download}

`.zip` 파일의 압축을 풀지 마세요. WordPress는 폴더가 아니라 `.zip` 파일을 설치합니다.

**WCPOS:**

1. WordPress.org에서 [WCPOS 고급 보기](https://wordpress.org/plugins/woocommerce-pos/advanced/)를 여세요.
2. **고급 옵션**까지 아래로 스크롤하세요. **이전 버전**에서 원하는 버전을 선택하세요.
3. **다운로드**를 클릭하세요.

**WCPOS Pro:**

1. [wcpos.com](https://wcpos.com/account/downloads)에서 계정에 로그인한 다음 **다운로드**를 여세요.
2. **버전 기록**에서 원하는 버전을 찾으세요.
3. 해당 행의 **다운로드**를 클릭하세요.

2.0에서 이전 버전으로 돌아가려면 이전 1.x 버전이 아닌 최신 **1.11** 릴리스를 선택하세요.

### 현재 버전 위에 업로드하기 {#install}

1. **WP 관리자 → 플러그인**으로 이동하여 페이지 상단의 **플러그인 추가**를 클릭하세요.
2. **플러그인 업로드**를 클릭하고 다운로드한 `.zip` 파일을 선택한 다음 **지금 설치**를 클릭하세요.
3. WordPress에 **이 플러그인은 이미 설치되어 있습니다.** 라는 메시지가 표시되고 **현재 버전**과 **업로드한 버전**이 나란히 표시됩니다. **업로드한 버전**에 원하는 버전이 표시되는지 확인하세요.
4. **현재 버전을 업로드한 버전으로 교체**를 클릭하세요.
5. WordPress에 **플러그인이 성공적으로 다운그레이드되었습니다.** 라는 메시지가 표시됩니다. **플러그인 활성화**가 표시되면 클릭하세요. 표시되지 않으면 플러그인이 이미 활성화된 상태이므로 계속 활성화되어 있습니다.

다시 업데이트할 준비가 될 때까지 자동 업데이트를 꺼 두세요. 그런 다음 다시 켜야 이후 수정 사항이 자동으로 적용됩니다.

재설치 과정에서 문제가 발생하거나 추가 지원이 필요한 경우, support@wcpos.com으로 지원팀에 문의해 주십시오.
