WCPOS에서 원활한 결제 경험을 제공하려면 성능 최적화가 중요합니다. 이 섹션에서는 일반적인 성능 문제와 해결 방법을 다룹니다.

## 일반적인 성능 문제 {#common-performance-issues}

가장 흔한 성능 문제는 다음과 같습니다:

- **느린 결제 과정** - 결제 모달을 로드하거나 결제를 처리하는 데 시간이 오래 걸림
- **느린 인터페이스** - POS 인터페이스의 반응이 느림
- **긴 동기화 시간** - 상품과 주문을 동기화하는 데 시간이 너무 오래 걸림. v1.10.0부터는 **매장 상태 → 성능**을 먼저 확인하세요. 측정된 응답 시간을 확인하고, 호스팅이 부하를 감당하지 못한다면 더 가벼운 [동기화 프리셋](/1.x/support/store-health#sync-presets)을 고려하세요

## 성능 범주 {#performance-categories}

### [결제 성능](/1.x/support/performance/checkout) {#checkout-performance}
결제 과정을 최적화하여 결제 처리 속도를 높이고 고객 경험을 개선하세요.

### [주문 저장 방식(HPOS)](/1.x/support/performance/order-storage) {#order-storage-hpos}
매장이 성장하면서 결제 속도가 느려지나요? WooCommerce가 기존 주문 저장 방식을 사용하는지 확인하고 HPOS로 전환하세요.

### [서버 성능](/1.x/support/performance/server) {#server-performance}
내장 지표와 문제 해결 기법을 활용하여 WordPress/WooCommerce 서버를 모니터링하고 최적화하세요.

### [매장 상태](/1.x/support/store-health) {#store-health}
앱 내 대시보드(v1.10.0+)로, 이 계산대에서 발생한 서버 부하 측정값, 동기화 프리셋, 다운로드 범위, 활동 로그를 보여줍니다.
