**증상:** WCPOS에서 결제하는 데 몇 초씩 걸리며, 시간이 지날수록 점점 느려집니다.

일반적인 원인 중 하나는 WooCommerce의 주문 저장 방식입니다. 이 페이지에서는 저장 방식을 확인하는 방법과 WooCommerce 자체 도구를 사용해 더 빠른 방식으로 전환하는 방법을 설명합니다.

## 기존 주문 저장 방식으로 인해 결제가 느려지는 이유 {#why-legacy-order-storage-slows-checkout}

기존 저장 방식에서는 WooCommerce가 주문을 WordPress 게시물과 함께 저장합니다. 이 방식으로는 WCPOS가 주문에 부여한 ID로 주문을 빠르게 찾을 수 없습니다. 따라서 WCPOS가 주문을 저장할 때마다 매장 기록을 하나씩 검색해야 하며, 매장이 커질수록 검색 시간이 길어집니다.

WooCommerce의 **고성능 주문 저장 방식(HPOS)** 은 주문을 별도의 테이블에 저장하므로 같은 검색을 거의 즉시 수행할 수 있습니다.

한 매장(상품 30,000개, 기존 저장 방식)에서 측정한 결과, 검색 한 번에 약 0.46초가 걸렸고 결제 한 건당 검색이 약 두 번 발생했습니다. HPOS를 사용하면 같은 검색에 약 1밀리초가 걸렸습니다. 매장마다 결과는 다르지만, 규모가 클수록 더 큰 효과를 볼 수 있습니다.

## WCPOS 지원 범위 {#what-wcpos-supports}

- **HPOS를 완벽하게 지원하며, HPOS 사용을 권장합니다.**
- **기존 저장 방식도 계속 사용할 수 있습니다.** 기능이 중단되지는 않으며, 대규모 매장에서 결제 속도만 느려집니다.

## 매장에서 사용하는 저장 방식 확인하기 {#check-which-storage-your-store-uses}

1. WordPress 관리자에서 **WooCommerce → 설정 → 고급 → 기능**으로 이동하세요.
2. **주문 데이터 저장 방식**을 찾으세요:
   - **고성능 주문 저장 방식(권장)** 이 선택되어 있다면 이미 HPOS를 사용 중이므로 원인이 아닙니다. [느린 결제의 다른 원인](#other-causes-of-slow-checkout)을 확인하세요.
   - **WordPress 게시물 저장 방식(기존)** 이 선택되어 있다면 HPOS로 전환해 결제 속도를 높일 수 있습니다. 계속 읽어 보세요.

## HPOS로 전환하기 {#switch-to-hpos}

WooCommerce가 주문을 대신 옮겨 줍니다. 먼저 주문을 새 테이블에 복사(동기화)한 다음 저장 방식을 전환합니다. 복사가 완료되기 전에는 WooCommerce에서 전환할 수 없습니다.

:::warning 먼저 백업하세요
시작하기 전에 사이트와 데이터베이스 전체를 백업하고, 복원할 수 있는지 확인하세요. [스테이징 사이트](/support/troubleshooting/plugin-conflicts#before-you-start-use-a-staging-site)가 있다면 먼저 그곳에서 전환해 보세요.
:::

1. **WooCommerce → 설정 → 고급 → 기능**으로 이동하세요.
2. **호환성 모드 활성화**를 선택한 다음 **변경 사항 저장**을 클릭하세요. WooCommerce가 백그라운드에서 주문 복사를 시작합니다. 매장이 크면 시간이 걸릴 수 있으며, 진행 상황은 체크박스 아래에 표시됩니다. 주문 동기화가 완료되지 않았다는 메시지가 나오고 진행되지 않으면 **지금 주문 동기화**를 클릭하세요.
3. 복사가 완료되면 **고성능 주문 저장 방식(권장)** 을 선택하고 **변경 사항 저장**을 클릭하세요.
4. 호환성 모드를 한동안 켜 두세요. 두 곳에 저장된 주문을 계속 동기화하므로 문제가 생겨도 즉시 이전 방식으로 돌아갈 수 있습니다. 이 기간에 다른 플러그인을 확인하고 WCPOS에서 테스트 판매를 몇 건 진행하세요.
5. 문제가 없다고 판단되면 **호환성 모드 활성화**를 해제하고 **변경 사항 저장**을 클릭하세요.

:::info HPOS 옵션이 비활성화된 경우
활성 플러그인이 HPOS와 호환되지 않는 것으로 표시되어 있으면 WooCommerce에서 전환을 차단합니다. 기능 페이지의 경고에 해당 플러그인과 **보기 및 관리** 링크가 표시됩니다. 전환하기 전에 플러그인을 업데이트하거나 개발자에게 HPOS 지원 여부를 문의하세요.
:::

자세한 내용은 WooCommerce 가이드 [고성능 주문 저장 방식](https://woocommerce.com/document/high-performance-order-storage/#how-to-enable-high-performance-order-storage)을 참조하세요.

## 느린 결제의 다른 원인 {#other-causes-of-slow-checkout}

주문 저장 방식만 결제 속도에 영향을 주는 것은 아닙니다. 이미 HPOS를 사용 중이거나 전환 후에도 결제가 느리다면 다음을 확인하세요:

- **호스팅.** 서버가 바쁘거나 성능이 부족하면 모든 단계가 느려집니다. [서버 성능](/support/performance/server)을 참조하세요.
- **주문 저장 시 실행되는 다른 플러그인**(예: 회계, 이메일 마케팅 또는 재고 관리 플러그인). [플러그인 충돌](/support/troubleshooting/plugin-conflicts)과 [결제 성능](/support/performance/checkout#2-plugin-interference-during-order-creation)을 참조하세요.
