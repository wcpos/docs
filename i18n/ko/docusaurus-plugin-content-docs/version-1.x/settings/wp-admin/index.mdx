이 설정은 PHP 및 WooCommerce 구성을 포함하여 POS 애플리케이션의 백엔드 기능을 구성합니다. `WP Admin > POS > Settings`로 이동하여 액세스할 수 있습니다.

## 설정 한눈에 보기 {#settings-at-a-glance}

| 설정 | 기능 | 자세히 보기 |
|---|---|---|
| **일반** | 모든 캐셔의 기본 장바구니 고객, POS 전용 상품, 소수 수량, 상품 바코드 필드를 설정합니다. | [일반 설정](./general.mdx) |
| **결제** | POS에서 사용할 수 있는 결제 게이트웨이와 POS 주문 처리 방식을 설정합니다. | [결제 설정](./checkout.mdx) |
| **이메일 알림** | 이메일별 관리자, 고객, 캐셔 설정을 통해 POS 주문에 대해 발송할 WooCommerce 이메일을 제어합니다. | [이메일 알림](./email-notifications.mdx) |
| **접근** | 전용 캐셔 역할을 포함해 POS를 사용할 수 있는 사용자 역할과 권한을 설정합니다. | [POS 접근](./access.mdx) |
| **세션** | 사용자 및 기기별 활성 POS 로그인 세션을 확인하고 원격으로 기기를 로그아웃합니다. | [세션](./sessions.mdx) |
| **매장 세금 ID** | 영수증과 송장에 인쇄되는 사업자 세금 식별 번호(VAT, ABN, GSTIN, EIN, 사업자 등록 번호)를 관리합니다. | [매장 세금 ID](./store-tax-ids.mdx) |
| **고객 세금 ID** | 고객 세금 ID의 저장 방식, 기록할 플러그인 필드, 결제 시 주문으로 복사되는 방식을 설명합니다. | [고객 세금 ID](./customer-tax-ids.mdx) |
