## POS 전용 상품 활성화 {#enable-pos-only-products}

이 설정은 상품에 표시 옵션을 추가하여 온라인 매장, POS 또는 양쪽 모두에 상품을 표시할지 제어할 수 있게 합니다.

:::warning 성능 영향
온라인 매장 또는 POS에서 상품을 숨겨야 할 때만 이 설정을 활성화하세요. 활성화하면 상품을 요청할 때마다 추가 데이터베이스 조회가 발생합니다.
:::

개별 상품의 표시 여부 설정과 일괄 편집 등 이 기능의 자세한 사용법은 [POS 전용 상품](/1.x/products/pos-only-products)을 참조하세요.

## 소수 수량 활성화 {#enable-decimal-quantities}

이 설정을 사용하면 고객과 직원이 장바구니에 상품을 추가할 때 소수 수량을 입력할 수 있습니다.

**소수 수량 예시:**
- 0.25(사분의 일 단위)
- 1.5(한 단위와 절반)
- 2.75(두 단위와 사분의 삼)

**유용한 경우:**
- 무게 단위로 판매하는 상품(예: 커피 원두 0.5kg)
- 소수 단위로 제공하는 서비스(예: 상담 1.5시간)
- 일부 수량만 나누어 판매할 수 있는 대량 상품

:::note 무게 단위 판매
WCPOS는 저울에 연결하거나 저울에서 무게를 읽지 않습니다. 상품의 무게를 잰 다음 장바구니에서 해당 항목의 수량으로 입력하세요. 킬로그램당 가격이 책정된 상품의 경우 350 g은 수량 `0.35`에 해당합니다. 먼저 이 설정을 켜세요. 켜지 않으면 매장에서 소수 수량이 포함된 주문을 거부합니다.

WCPOS는 일부 저울에서 인쇄하는 바코드 라벨에 인코딩된 무게나 가격도 읽지 않습니다.
:::

## 주문 삭제 시 재고 복원 {#restore-stock-on-order-delete}

활성화하면 POS 주문이 휴지통으로 이동되거나 삭제될 때 WCPOS가 상품 재고를 자동으로 복원합니다. 따라서 잘못된 판매를 취소하면 해당 상품이 재고로 돌아갑니다. 이 설정은 **기본적으로 켜져 있습니다**.

다른 방식으로 재고를 조정하며 삭제된 POS 주문이 재고에 영향을 주지 않도록 하려면 이 설정을 끄세요.

## 고객 이메일에서 사용자 이름 자동 생성 {#automatically-generate-username-from-customer-email}

활성화하면 WCPOS가 결제 중 새 고객의 이메일 주소를 기반으로 사용자 이름을 자동 생성합니다. 고객 생성 과정이 간소화되고 사용자 이름 형식이 일관되게 유지됩니다.

## 기본 POS 고객 {#default-pos-customer}

새 POS 주문에 할당할 기본 고객을 선택하세요. 일반적인 옵션은 다음과 같습니다:

- **비회원**: 주문이 어떤 사용자 계정과도 연결되지 않습니다
- **캐셔**: 주문이 로그인한 캐셔의 계정과 연결됩니다
- **방문 고객**: 주문이 특정 고객 계정과 연결됩니다(해당 계정을 먼저 생성해야 합니다)

## 캐셔 계정 사용 {#use-cashier-account}

활성화하면 선택한 기본 POS 고객 대신 캐셔의 사용자 계정이 POS 주문의 기본 고객으로 사용됩니다.

## 고객의 영수증 다운로드 허용 {#storefront-receipts}

활성화하면 WCPOS가 온라인 매장의 **내 계정 → 주문**에 **영수증** 버튼을 추가합니다. 고객은 WCPOS 템플릿으로 렌더링된 PDF 형식의 주문 영수증을 직접 다운로드할 수 있습니다. 이 설정은 **기본적으로 꺼져 있습니다**.

토글 아래의 **고객용 영수증 템플릿** 드롭다운에서 고객에게 제공할 템플릿을 선택합니다. 기본값은 **활성 영수증 템플릿 사용**이므로 POS와 동일한 템플릿을 사용합니다. 온라인 주문에 다른 디자인(예: 전체 페이지 송장)을 적용하려면 특정 템플릿을 선택하세요.

해당하는 주문 상태, `[wcpos_receipt]` 단축 코드, 개발자 필터를 포함한 전체 안내는 [온라인 매장 영수증](/1.x/receipts/storefront)을 참조하세요.

## 바코드 필드 {#barcode-field}

이 설정은 바코드를 스캔하거나 바코드 검색 기능을 사용할 때 WCPOS가 검색할 상품 필드를 결정합니다.

<a id="default-option"></a>

:::note 기본 메타 키
**`_global_unique_id`** 를 사용하세요. WooCommerce 9.2(2024년 8월)에 도입된 WooCommerce의 전역 고유 ID 필드입니다. GTIN, UPC, EAN 또는 ISBN 코드를 저장하도록 설계되었으며 새로 설치할 때 권장되는 옵션입니다. 전역 고유 ID 필드를 사용하지 않는다면 **`_sku`**(상품 SKU / 재고 관리 단위 필드)를 대안으로 사용할 수 있습니다.
:::

### 일반적인 플러그인 → 메타 키 {#common-plugins-meta-key}

바코드 관리 플러그인을 사용한다면 해당 플러그인의 전용 메타 키를 대신 사용해야 할 수 있습니다:

| 플러그인 / 필드 유형 | 메타 키 |
|---|---|
| WooCommerce 전역 고유 ID *(기본값, 권장)* | `_global_unique_id` |
| 상품 SKU *(대안)* | `_sku` |
| EAN 플러그인(유럽 상품 번호) | `_ean`, `_ean13`, `_ean8` |
| EAN for WooCommerce(WPFactory의 EAN Barcode Generator) | 고급 설정에서 **메타 키**를 변경하지 않았다면 `_alg_ean` |
| UPC 플러그인(범용 상품 코드) | `_upc`, `_upc_code` |
| GTIN 플러그인(국제 상품 식별 코드) | `_gtin`, `_gtin13`, `_gtin14` |
| 일반 바코드 필드 | `_barcode`, `_product_barcode` |
| WooCommerce Product Barcodes | `_barcode_text` |
| ATUM Inventory | `_atum_barcode` |

<a id="custom-meta-keys"></a>

:::tip 사용자 지정 메타 키
바코드 데이터를 저장하는 사용자 지정 메타 키는 **어떤 것이든** 사용할 수 있습니다. 이 필드에 메타 키 이름을 입력하세요. 밑줄 접두사가 있다면 함께 입력하세요.
:::

### 플러그인의 메타 키 찾기 {#finding-your-plugins-meta-key}

위 목록에 플러그인이 없다면 다음 방법으로 올바른 메타 키를 찾으세요:

<Steps>
  <StepCard number="1" title="상품에 바코드 추가">

WP Admin에서 상품을 편집하고 플러그인을 사용하여 바코드를 추가하세요.

  </StepCard>
  <StepCard number="2" title="플러그인 문서 확인">

플러그인 문서에서 사용하는 메타 키 이름을 확인하세요.

  </StepCard>
  <StepCard number="3" title="또는 데이터베이스 검사" isLast>

데이터베이스의 `wp_postmeta` 테이블에서 상품에 어떤 메타 키가 생성되었는지 확인하세요.

  </StepCard>
</Steps>

:::note 이 설정을 변경하면 바코드 색인이 다시 생성됩니다
바코드 필드를 변경하면 WCPOS가 로컬 카탈로그의 바코드 색인을 다시 생성하여 새로 선택한 필드에 맞춰 스캔합니다. 상품을 직접 지우고 다시 다운로드할 필요가 없습니다.

그래도 스캔 결과가 일치하지 않으면 전체 새로고침을 강제로 실행할 수 있습니다. 상품 화면으로 이동하여 하단의 동기화 아이콘(↻)을 **길게 누르고** **‘지우고 새로고침’** 을 선택하세요. 그런 다음 스캔을 테스트하여 새 필드가 사용되는지 확인하세요.
:::

## 개인정보 보호 {#privacy}

**익명 사용 데이터 허용** 토글은 제품 개선을 위해 WCPOS가 익명 사용 분석 데이터를 수집할지 제어합니다. 수집 여부를 자유롭게 선택할 수 있으며, 고객 데이터, 가격, 매장 주소는 전혀 수집하지 않습니다. 설정 옆의 **자세히 알아보기** 링크에서 수집되는 항목과 수집되지 않는 항목을 정확히 확인하세요.

## 매장 세금 ID {#store-tax-ids}

WCPOS가 POS 영수증과 송장에 인쇄할 사업자 세금 식별번호를 추가하세요. VAT 번호, ABN, GSTIN, EIN 또는 현지 사업자등록번호 등이 해당됩니다. WooCommerce에는 이러한 정보를 위한 기본 필드가 없으며, 많은 지역에서는 둘 이상의 식별번호가 필요합니다.

전체 안내는 [매장 세금 ID](/1.x/settings/wp-admin/store-tax-ids)를 참조하세요.

## 고객 세금 ID {#customer-tax-ids}

WCPOS는 고객에 세금 ID 필드를 유지하고 결제 시 주문에 복사합니다. 플러그인마다 이 필드를 서로 다른 이름으로 저장하므로, WCPOS는 설치된 플러그인을 감지하여 올바른 필드에 자동으로 기록합니다. 여기의 **세금 ID** 섹션에서 필요에 따라 필드 이름을 재정의할 수도 있습니다.

전체 안내는 [고객 세금 ID](/1.x/settings/wp-admin/customer-tax-ids)를 참조하세요.
