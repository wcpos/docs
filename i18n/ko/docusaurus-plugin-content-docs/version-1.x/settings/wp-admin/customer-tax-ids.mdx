WCPOS는 구매자의 세금 식별번호가 송장에 표시되어야 하는 B2B 판매를 위해 고객에 세금 ID 필드를 유지합니다. VAT 번호, ABN, CPF, GSTIN, NIF 등이 해당됩니다. 고객의 주문이 생성되면 WCPOS는 세금 ID를 주문에 복사하여 영수증에 인쇄할 수 있도록 합니다.

**WP Admin > POS > 설정 > 일반**의 **세금 ID** 섹션에서 이 필드의 감지 및 저장 방식을 제어합니다.

{/* Screenshot: wp-admin-customer-tax-ids.png */}

## 플러그인 및 필드 이름 {#plugins-and-field-names}

많은 WooCommerce 플러그인이 이미 고객에 VAT 또는 세금 번호 필드를 추가하며, 플러그인마다 서로 다른 데이터베이스 필드 이름(메타 키)을 사용합니다. 기존 고객 데이터를 이전 없이 계속 사용할 수 있도록 WCPOS는 설치된 플러그인을 감지하여 올바른 필드에 자동으로 기록합니다.

WCPOS는 다음 순서로 필드 이름을 결정합니다:

1. **인식된 플러그인이 활성화되어 있는 경우** — WCPOS는 해당 플러그인의 필드에 기록합니다. 감지되는 플러그인은 다음과 같습니다:
   - WooCommerce EU VAT Number
   - Aelia EU VAT Assistant(인증 상태 포함)
   - EU VAT for WooCommerce (WPFactory)
   - WooCommerce Germanized / Germanized Pro
   - Brazilian Market on WooCommerce / Extra Checkout Fields for Brazil
   - NIF/CIF Spain
2. **인식된 플러그인 없음** — WCPOS는 최근 주문에서 이미 사용 중인 VAT/CPF 등의 필드를 찾아 해당 필드에 기록합니다.
3. **검색 결과 없음** — WCPOS는 적절한 기본값을 사용합니다(VAT 유형 ID는 `_billing_vat_number`, 브라질은 `_billing_cpf` / `_billing_cnpj`, 인도는 `_billing_gstin` 등).

### 필드 이름 직접 선택하기 {#choosing-the-field-name-yourself}

감지된 필드 이름을 재정의하려면 **WP Admin > POS > 설정 > 일반**으로 이동하여 **세금 ID** 섹션을 열고 **고급: 다른 필드 이름 사용**을 펼치세요.

배너에 자동 감지된 플러그인이 표시됩니다. 기본 제공 값을 사용 중이라면 ‘플러그인이 감지되지 않음’이 표시됩니다. 재정의 입력란에는 다른 플러그인에서 일반적으로 사용하는 메타 키를 제안하는 자동 완성 기능이 있습니다. 입력란을 비우면 재정의가 해제되고 자동 필드 이름으로 돌아갑니다.

:::note
이 편집기에는 고객용 세금 ID 유형만 표시됩니다. 독일 USt-IdNr.이나 네덜란드 KVK 번호 같은 사업자 등록 식별자는 매장 수준 필드입니다. [매장 세금 ID](/1.x/settings/wp-admin/store-tax-ids)를 참조하세요.
:::

## 세금 ID는 주문에 복사됩니다 {#tax-ids-are-copied-onto-orders}

주문이 접수되면 고객의 세금 ID가 해당 주문에 **스냅샷으로 저장됩니다**. 주문에는 판매 시점에 등록되어 있던 값이 보존됩니다.

- 나중에 고객의 세금 ID를 수정해도 과거 주문은 변경되지 **않습니다**.
- 결제 시 캐셔가 입력한 세금 ID는 해당 주문에 한해 고객 기록의 값을 대체합니다.
- 기존 주문을 수정할 때는 업데이트에 세금 ID가 명시적으로 포함된 경우에만 세금 ID가 변경됩니다. WCPOS는 고객 기록에서 다시 복사하지 않습니다.

따라서 고객 정보가 변경된 후에도 과거 송장의 정확성이 유지됩니다.

## 지원되는 유형 {#supported-types}

EU VAT, GB VAT, SA VAT, 호주 ABN, 브라질 CPF / CNPJ, 인도 GSTIN, 이탈리아 Codice Fiscale 및 Partita IVA, 스페인 NIF, 아르헨티나 CUIT, 캐나다 GST/HST, 미국 EIN을 지원하며, 그 외 항목에는 일반 **세금 ID**를 사용할 수 있습니다.

## 세금 ID로 고객 검색 {#finding-customers-by-tax-id}

POS의 고객 검색은 이전 플러그인 필드 이름에 저장된 값을 포함하여 세금 ID 값도 검색하므로, 캐셔가 VAT 번호, CPF 또는 NIF로 고객을 찾을 수 있습니다.

## 영수증 표시 {#on-receipts}

고객 세금 ID는 고객 상세 정보를 표시하는 영수증에 각 유형에 맞는 현지화된 라벨과 함께 표시됩니다. VAT 번호에는 국가 접두사가 붙습니다(예: `DE123456789`).
