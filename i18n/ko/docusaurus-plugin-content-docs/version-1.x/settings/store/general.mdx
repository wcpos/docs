## 개요 {#overview}

처음 로드할 때 POS는 WooCommerce 매장 설정에서 기본 설정을 자동으로 가져옵니다. 대부분의 경우 모든 판매 채널에서 일관성을 유지하려면 이 설정을 WooCommerce 매장과 동기화된 상태로 두는 것이 좋습니다.

:::tip 권장 사항
일반적으로 POS에 별도의 통화를 사용하거나 매장 거래에 다른 기본 고객을 설정하는 등 특별한 사업상 필요가 없다면 WooCommerce 매장과 동일한 설정을 유지해야 합니다.
:::

## 매장 정보 {#store-information}

### 매장 이름 {#store-name}

POS 인터페이스와 영수증에 표시되는 매장 이름입니다. 일반적으로 WooCommerce 매장 이름과 동기화됩니다.

### 매장 주소 {#store-address}

매장 주소에는 다음 항목이 포함됩니다:

- **매장 기본 도시**: 매장이 위치한 도시
- **매장 기본 우편번호**: 매장 위치의 우편번호
- **매장 기본 주/도**: 매장이 운영되는 주 또는 도
- **매장 기본 국가**: 매장이 위치한 국가

:::warning 주소 설정 사용 중지
매장 주소를 변경하면 세금 계산에 영향을 미치고 주문 처리에 문제가 생길 수 있으므로 현재 POS 설정에서 주소 필드를 사용할 수 없습니다. 이 설정은 WooCommerce 매장 구성과 계속 동기화됩니다.
:::

## 현지화 설정 {#localisation-settings}

### 언어 {#language}

POS 인터페이스의 표시 언어를 설정합니다. 다음 항목에 사용되는 언어를 제어합니다:

- 메뉴 항목 및 탐색
- 버튼 레이블 및 인터페이스 텍스트
- 시스템 메시지 및 알림
- 날짜 및 시간 형식

### 통화 {#currency}

거래와 가격 표시에 사용할 기본 통화를 지정합니다. 이 설정은 다음 항목에 영향을 줍니다:

- 상품 가격 표시
- 주문 합계 및 계산
- 영수증 형식
- 재무 보고서

### 통화 기호 위치 {#currency-position}

가격 금액을 기준으로 통화 기호가 표시되는 위치를 제어합니다:

- **왼쪽**: $10.00 (금액 앞에 기호 표시)
- **오른쪽**: 10.00$ (금액 뒤에 기호 표시)
- **왼쪽, 공백 포함**: $ 10.00
- **오른쪽, 공백 포함**: 10.00 $

## 숫자 형식 {#number-formatting}

### 소수점 구분 기호 {#decimal-separator}

정수 부분과 소수 부분을 구분하는 문자입니다(예: "." 또는 ",").

### 소수 자릿수 {#number-of-decimals}

가격과 금액에 표시할 소수 자릿수를 지정합니다(대부분의 통화는 일반적으로 2자리).

### 천 단위 구분 기호 {#thousand-separator}

큰 숫자에서 천 단위를 구분하는 문자입니다(예: 1,000의 "," 또는 1.000의 ".").

### 천 단위 그룹화 방식 {#thousands-group-style}

천 단위를 그룹화하여 표시하는 방식을 지정합니다:

- **thousand**: 서양식 표준 그룹화(123,456,789) - 3자리마다 구분
- **lakh**: 인도식 숫자 체계(12,34,56,789) - 처음에는 3자리, 그다음부터 2자리마다 구분
- **wan**: 동아시아 숫자 체계(1,2345,6789) - 4자리마다 구분

## 고객 설정 {#customer-settings}

### 기본 고객 {#default-customer}

새 주문에 자동으로 선택할 고객을 설정합니다. 일반적으로 다음 옵션이 있습니다:

- **게스트**: 계정이 없는 방문 고객
- **특정 고객**: 미리 지정된 고객 계정
- **캐셔**: 로그인한 캐셔를 고객으로 지정

### 기본 고객은 캐셔 {#default-customer-is-cashier}

활성화하면 현재 로그인한 캐셔가 새 주문의 고객으로 자동 지정됩니다.

## 서버 설정 복원 {#restore-server-settings}

"서버 설정 복원" 버튼을 사용하면 모든 일반 설정을 WooCommerce 매장의 기본값으로 재설정할 수 있습니다.

:::info 동기화
"서버 설정 복원"을 클릭하면 현재 WooCommerce 매장 기본값을 가져와 사용자 지정 POS 설정을 덮어씁니다.
:::
