매장 설정은 POS 작동 방식에 영향을 주는 앱 전체 설정입니다. 이 설정은 개별 화면이 아니라 매장 전체에 적용됩니다.

## 매장 설정 열기 {#accessing-store-settings}

다음 방법으로 매장 설정을 여세요:

- 오른쪽 위의 **사용자 메뉴**를 클릭하고 **설정**을 선택합니다.
- 키보드 단축키 `Ctrl + Shift + S`를 사용합니다.

설정은 팝업 창이 아니라 **사이드 패널**로 열리므로 설정을 조정하는 동안에도 판매 화면을 계속 볼 수 있습니다. [매장 상태](/support/store-health)도 같은 방식으로 열립니다.

## 설정 탭 {#settings-tabs}

매장 설정 패널에는 다음 탭이 있습니다:

| 탭 | 설명 |
|-----|-------------|
| [일반](./general.mdx) | 매장 정보, 언어, 통화, 기본 고객 |
| [세금](./tax.mdx) | 세금 계산 및 표시 옵션 |
| [바코드](./barcode.mdx) | 바코드 스캐너 설정 |
| [키보드 단축키](./hotkeys.mdx) | 사용 가능한 키보드 단축키 |
| [테마](./theme.mdx) | 외관 및 색상 구성 |
| [프린터](/hardware/printers) | 영수증 프린터 연결 및 설정 |
