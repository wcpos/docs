WCPOS의 설정은 구성하는 위치에 따라 세 가지 유형으로 나뉩니다.

## 설정 찾는 방법 {#where-to-find-settings}

### 1. WordPress 관리자 설정 {#1-wordpress-admin-settings}

WordPress 대시보드에서 구성하는 백엔드 설정입니다:

**위치:** `WP Admin > POS > 설정`

다음 항목을 제어합니다:
- 모든 캐셔의 기본 카트 고객
- 제품 바코드 필드 구성
- 주문 이메일 설정
- 사용자 역할 권한(POS에 접근할 수 있는 사용자)
- 결제 게이트웨이 사용 가능 여부

자세한 내용은 [WordPress 관리자 설정](/1.x/settings/wp-admin)을 참조하세요.

### 2. POS 매장 설정 {#2-pos-store-settings}

POS 애플리케이션 내에서 구성하는 앱 전체 설정입니다:

**위치:** 사용자 메뉴(오른쪽 위) → 설정 또는 `Ctrl + Shift + S`

다음 항목을 제어합니다:
- 세금 계산 옵션
- 바코드 스캐너 구성
- 키보드 단축키
- 테마/모양

자세한 내용은 [매장 설정](/1.x/settings/store)을 참조하세요.

### 3. 디스플레이 설정(화면별) {#3-display-settings-per-screen}

POS의 각 화면에는 데이터 테이블을 맞춤 설정할 수 있는 자체 디스플레이 설정이 있습니다:

**위치:** 각 화면의 슬라이더 아이콘(<Icon name="sliders" />)을 클릭하세요

다음 항목을 제어합니다:
- 표시할 열
- 열 표시 옵션
- 화면별 기능

디스플레이 설정은 각 화면의 문서에서 설명합니다:
- [POS 제품 패널](/1.x/pos/product-panel#display-settings)
- [카트 패널](/1.x/pos/cart#display-settings)
- [제품 화면](/1.x/products#display-settings)
- [주문 화면](/1.x/orders#display-settings)
- [고객 화면](/1.x/customers#display-settings)
- [보고서 화면](/1.x/reports#display-settings)
