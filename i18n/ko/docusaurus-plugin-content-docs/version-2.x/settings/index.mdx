설정은 네 곳에 있습니다. 계산대에서 바꾸는 대부분의 항목은 POS의 **설정**에 있으며, 이 기기에만 적용됩니다. 모든 계산대가 공유하는 항목은 매장 소유자가 WordPress에서 설정합니다. WCPOS Pro에서는 매장별 전용 페이지도 제공됩니다. 일부 화면에는 해당 화면의 표시 방식을 바꾸는 별도의 버튼이 있습니다.

- [POS의 **설정**](#open)은 현재 연결된 매장에 대해 이 기기의 설정을 변경합니다. POS를 열 수 있는 사람은 누구나 변경할 수 있습니다.
- [`WP Admin > POS > 설정`](#wp-admin)은 사이트의 모든 계산대에 적용됩니다. 매장 소유자가 설정하며, 일부 설정은 계산대에 한 번만 전달됩니다. [변경 권한과 해당 설정](#wp-admin)을 참고하세요.
- WCPOS Pro에서는 `WP Admin > POS > 매장`의 [매장별 전용 페이지](../stores/index.mdx)에서 해당 매장의 이름과 주소, 통화와 언어, 세금, 영수증, 고객용 디스플레이, 계산대, 직원을 설정합니다.
- [화면별 표시 설정](#screen-settings)은 이 기기에서 해당 화면의 표시 방식만 변경합니다. POS를 열 수 있는 사람은 누구나 변경할 수 있습니다.

## POS에서 설정 열기 {#open}

메뉴 하단의 **매장 상태**와 **지원** 사이에 있는 톱니바퀴를 누르세요. 설정의 **일반** 페이지가 열리고 왼쪽에 일곱 개 페이지가 표시됩니다. 원하는 페이지를 눌러 여세요. 변경 사항은 즉시 저장되므로 저장 버튼을 누를 필요가 없습니다. 휴대폰에서는 먼저 왼쪽 상단의 메뉴를 여세요. [휴대폰에서](#phone)를 참고하세요.

1. **설정** — 메뉴 하단의 톱니바퀴입니다. 판매 화면으로 돌아가려면 메뉴 상단의 계산대 아이콘을 누르세요.
2. **일반** — 매장 이름과 주소, 언어, 새 장바구니에 기본으로 지정되는 고객, 통화 및 금액 표시 형식입니다. 주소는 WooCommerce에서 설정하며, WCPOS Pro에서는 매장별 페이지에서도 설정할 수 있습니다. 나머지는 이 기기에서 변경할 수 있습니다. [이 기기에만 저장되는 설정](#this-device)과 [매장 정보, 언어 및 통화](./store/general.mdx)를 참고하세요.
3. **세금** — POS의 세금 계산 및 표시 방식입니다. 세금 규칙 자체는 WooCommerce에서 설정합니다. [세금 설정](./store/tax.mdx)을 참고하세요.
4. **인쇄** — 이 기기에서 사용할 프린터, 각 프린터의 **테스트 인쇄**, 영수증 템플릿별로 사용할 프린터를 설정합니다. [프린터](../hardware/printers/index.mdx)를 참고하세요.
5. **카드 리더기** — 이 계산대에서 결제에 사용할 카드 리더기입니다. 먼저 WooCommerce의 결제 게이트웨이에서 리더기를 설정하면 여기에 표시되어 연결할 수 있습니다. 카드 리더기는 WCPOS Pro에서 제공됩니다. [카드 리더기 호환성](../hardware/index.mdx#card-reader-compatibility)을 참고하세요.
6. **고객용 디스플레이** — 페어링 코드로 고객에게 구매 내역을 보여 주는 보조 화면을 연결합니다. 고객용 디스플레이는 WCPOS Pro에서 제공됩니다. [고객용 디스플레이](../getting-started/free-vs-pro.mdx#customer-display)를 참고하세요.
7. **바코드 스캔** — POS가 스캔과 타이핑을 구분하는 방식, 스캔 시 재생할 소리, 스캐너 테스트 영역입니다. [바코드 스캔](./store/barcode.mdx)을 참고하세요.
8. **테마** — 이 기기의 POS 화면 모양을 설정합니다. 테마, 버튼과 텍스트의 **배율**, 아이콘, 글꼴을 지정합니다. [테마](./store/theme.mdx)를 참고하세요.

## 이 기기에만 저장되는 설정 {#this-device}

POS의 **설정**에서 변경한 내용은 현재 연결된 매장에 대해 이 기기에만 적용됩니다. 같은 매장의 다른 계산대는 자체 설정을 유지하며, 여기서 변경한 내용은 WordPress에 전달되지 않습니다. WordPress에서 특정 역할의 **POS 설정 관리**를 꺼도 이 화면은 숨겨지지 않습니다. [접근 권한 및 역할](./wp-admin/access.mdx)을 참고하세요.

**일반** 페이지는 특히 주의해야 합니다. 매장 이름, 언어, 기본 고객, 통화 및 숫자 형식은 매장에서 한 번 복사되며, 여기서 이 기기에 맞게 변경할 수 있습니다. 매장 주소도 같은 방식으로 복사되지만 여기서는 변경할 수 없습니다. 처음 복사된 이후에는 **일반** 하단의 **서버 설정 복원**을 누르기 전까지 WooCommerce나 WP Admin에서 변경한 내용이 이 항목들에 반영되지 않습니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-36, 0]]} maxWidth={724} alt="설정의 일반 페이지 하단: 서버 설정 복원 버튼 옆에 WooCommerce 매장에서 복사한 설정이며 복원하면 로컬 변경 사항을 덮어쓴다는 안내">

1. **서버 설정 복원** — **일반** 하단에 있습니다. 누른 다음 확인하세요.

</JourneyShot>

:::warning 복원하면 이 기기의 변경 사항을 덮어씁니다
**서버 설정 복원**은 WooCommerce에서 매장 설정을 다시 불러와 이 기기에서 변경한 내용을 덮어씁니다. 주소를 포함한 **일반**의 모든 값 중 **자릿수 그룹 형식**을 제외한 항목과 **세금**의 모든 선택 항목이 복원됩니다. 프린터, 카드 리더기, 고객용 디스플레이, 바코드 스캔, 테마는 그대로 유지됩니다.
:::

## 모든 계산대가 공유하는 설정 {#wp-admin}

매장 소유자가 WordPress의 `WP Admin > POS > 설정`에서 지정합니다. 사이트의 모든 계산대에 적용되며, 상품 스캔에 사용할 **바코드 필드**, 새 장바구니의 기본 고객, 결제 시 표시할 결제 게이트웨이, POS 주문에 대해 보낼 이메일, POS를 사용할 수 있는 사용자 등이 포함됩니다. WCPOS Pro에서는 여기에 지정한 계산대 규칙이 사이트 기본값이 되며, 각 매장의 **계산대** 페이지에서 변경할 수 있습니다. [Pro로 계산대 추가하기](./wp-admin/registers.mdx#more-registers-with-pro)와 [WordPress 관리자 설정](./wp-admin/index.mdx)을 참고하세요.

변경하려면 POS를 관리할 수 있는 WordPress 사용자 계정이 필요합니다. 관리자와 상점 관리자는 변경할 수 있습니다. 캐셔는 소유자가 해당 역할의 **POS 설정 관리**를 켜야 변경할 수 있습니다. [접근 권한 및 역할](./wp-admin/access.mdx)을 참고하세요.

새 장바구니의 기본 고객 등 일부 설정은 계산대를 설정할 때 해당 계산대의 **일반** 페이지에 복사됩니다. 누군가 해당 계산대에서 **서버 설정 복원**을 누를 때까지 복사된 값이 유지됩니다. [이 기기에만 저장되는 설정](#this-device)을 참고하세요.

## 화면별 설정 {#screen-settings}

상품 패널과 장바구니에는 각각 슬라이더 버튼(<Icon name="sliders" />)인 **상품 설정**과 **장바구니 설정**이 있습니다. **상품**, **주문**, **고객**, **쿠폰** 화면에도 같은 버튼이 있으며 이름은 **표시 옵션**입니다. 표시할 열과 세부 정보, 정렬 방식, 처음 열릴 때의 상태 등 해당 화면의 표시 방식을 설정합니다. 변경 사항은 즉시 이 기기에만 저장됩니다. 각 화면의 설정은 해당 화면의 문서에서 설명합니다:

- [상품 패널](../pos/product-panel/display-settings.mdx)
- [장바구니](../pos/cart/index.mdx#display-settings)
- [상품](../products/index.mdx#display-settings)
- [주문](../orders/index.mdx#display-settings)
- [고객](../customers/index.mdx#display-settings)
- [쿠폰](../coupons/index.mdx#coupon-list)

## 문제가 발생한 경우 {#goes-wrong}

**한 계산대에서 변경한 내용이 다른 계산대에 표시되지 않습니다.** POS의 설정은 기기별로 저장됩니다. 각 계산대에서 동일하게 변경하세요. 모든 계산대가 공유해야 할 항목이라면 매장 소유자에게 [`WP Admin > POS > 설정`](#wp-admin)에서 변경해 달라고 요청하세요.

**WooCommerce에서 변경했는데도 매장 이름이나 통화가 이전 값으로 표시됩니다.** **설정**에서 **일반**을 열고 **서버 설정 복원**을 누르세요. 이 기기에서 변경한 **일반**과 **세금** 설정을 덮어씁니다([이 기기에만 저장되는 설정](#this-device) 참고). [매장 정보, 언어 및 통화](./store/general.mdx)를 참고하세요.

**WP Admin에 POS 메뉴가 없습니다.** 현재 WordPress 사용자에게 POS 관리 권한이 없습니다. 관리자에게 해당 역할의 **POS 설정 관리**를 켜 달라고 요청하세요. [접근 권한 및 역할](./wp-admin/access.mdx)을 참고하세요.
