**WP 관리자:** `WP Admin → POS → Settings → General → Register`.

여기에서 금전등록기 기능을 켜고 시작 준비금, 현금 집계에 관리자 승인이 필요한 기준, 캐셔에게 마감을 알릴 시간을 설정합니다. 아래에서는 각 설정에 따라 캐셔에게 표시되는 내용을 안내합니다.

금전등록기의 개념과 매장 및 기기와의 차이는 [매장, 금전등록기 및 기기](../../stores/registers-and-devices.mdx)를 참고하세요.

## 금전등록기 기능 켜기 {#one-register}

Pro를 사용하고 매장이 하나 이상 있으면 이 설정은 사이트 기본값이 되고, 각 금전등록기의 준비금 설정은 해당 매장으로 이동합니다. [매장의 금전등록기 페이지](#store-registers)를 참고하세요.

1. **일반** 설정 페이지에서 **금전등록기**로 스크롤하세요.
2. **금전등록기 개점 및 마감**을 켜세요. 아래에 규칙이 표시됩니다. 끄면 POS가 바로 장바구니로 이동하며, 캐셔는 금전등록기를 개점하거나 현금을 집계하지 않습니다.
3. **시작 준비금**을 확인하세요. 금전등록기 기능을 처음 켜면 **200.00**으로 설정됩니다. 하루를 시작할 때 현금 서랍에 넣어 두는 금액으로 변경하세요. Pro 매장이 있으면 이 필드는 여기에 표시되지 않습니다. [해당 매장의 금전등록기 페이지](#store-registers)에서 각 금전등록기의 준비금을 설정하세요.
4. 선택 사항: **집계 차액이 다음 금액을 초과하면 관리자 승인 요청**을 켜고 금액을 설정하세요.
5. 선택 사항: **캐셔에게 마감을 알릴 시간**을 켜고 시간을 설정하세요.

변경 사항은 변경 즉시 또는 필드를 벗어날 때 저장됩니다. 필드를 비워 두면 이전 값으로 돌아갑니다.

<Accordion>
<AccordionItem question="시작 준비금, 관리자 승인 및 마감 알림">

각 설정은 값이 포함된 문장으로 표시됩니다.

- **금전등록기 개점 및 마감**은 금전등록기 세션을 활성화합니다. 캐셔는 준비금으로 개점하고 현금 입출금을 기록한 뒤 마감 시 서랍의 현금을 집계합니다. 끄면 POS가 바로 장바구니로 이동하며, 개점이나 집계 작업이 없습니다.
- **시작 준비금**은 서랍에 처음 넣어 두는 현금입니다. 캐셔가 금전등록기를 개점할 때 **서랍 내 현금**에 자동으로 입력되며, 캐셔는 실제로 있는 금액을 입력할 수 있습니다. 금전등록기 기능이 켜져 있을 때만 표시됩니다.
- **집계 차액이 다음 금액을 초과하면 관리자 승인 요청 …** 은 기본으로 꺼져 있으며, 켜면 **5.00**으로 시작합니다. 마감 집계액이 이 금액을 초과하여 부족하거나 많으면 금전등록기를 마감하기 전에 관리자 승인이 필요합니다. 끄면 차액에 관계없이 승인 없이 마감합니다.
- **캐셔에게 마감을 알릴 시간 …** 은 기본으로 꺼져 있으며, 켜면 **17:30**으로 시작합니다. 이 시간이 지나면 금전등록기에 **마감 시간 초과**가 표시되고, 빈 장바구니에는 **결제** 대신 **금전등록기 마감**이 표시됩니다. [마감 시간이 되면](#overdue)을 참고하세요.

선택 규칙을 켜면 초기값이 입력됩니다. 끄면 값이 지워지고, 다시 켜면 초기값에서 다시 시작합니다.

</AccordionItem>
</Accordion>

설정 아래에는 **Pro로 더 많은 금전등록기와 매장 사용** 링크가 표시됩니다.

무료 플러그인에는 금전등록기가 정확히 하나 있습니다.

<Accordion>
<AccordionItem question="여러 기기에서 같은 금전등록기 사용">

로그인한 모든 기기는 하나의 금전등록기를 사용합니다. 같은 계산대의 브라우저, 데스크톱 앱, 휴대전화가 모두 같은 현금 서랍으로 판매를 처리하고 하나의 금전등록기 세션을 공유하므로, 서랍의 현금 집계와 마감은 한 번만 합니다. 이름을 지정하는 설정은 없으며, 금전등록기 표시줄에는 매장만 표시됩니다.

</AccordionItem>
</Accordion>

## 캐셔에게 표시되는 내용 {#what-the-cashier-sees}

금전등록기가 마감되어 있으면 캐셔는 서랍의 현금을 집계하고 장바구니 열에서 개점합니다.

<JourneyShot manifest={registerManifest} device="tablet" step={1} offsets={[[81, 0], [-34, 0], [0, 0], [255, 0], [157, 0], [0, 0]]} alt="금전등록기가 마감된 POS: 마감 상태의 금전등록기 표시줄, 상품 위의 가격 확인 안내줄, 장바구니 열의 현금 필드, 마지막 집계액, 금전등록기 개점 버튼">

1. **금전등록기 상태** — 여기서는 **마감**입니다. **마감 시간 초과**([마감 시간이 되면](#overdue) 참고) 또는 **승인 필요**([집계 차액이 있을 때](#count-out) 참고)가 표시될 수도 있습니다.
2. **금전등록기 표시줄** — 이 기기가 판매를 처리하는 매장입니다. Pro를 사용하고 매장에 금전등록기가 여러 개 있으면 금전등록기 이름도 표시됩니다.
3. **가격 확인 안내줄** — 금전등록기가 마감되어 있는 동안 캐셔는 상품을 검색하고 가격을 확인할 수 있지만 장바구니에는 추가할 수 없습니다.
4. **서랍 내 현금** — **시작 준비금**으로 시작하며, 시작 준비금이 설정되어 있지 않으면 마지막 집계액을 사용합니다. 캐셔는 실제로 집계한 금액을 입력합니다.
5. **마지막 집계액** — 이전 마감의 집계액이 담긴 칩으로, 한 번 누르면 해당 금액을 사용할 수 있습니다. 예상 현금을 보지 않고 집계하는 캐셔에게는 이 칩도 표시되지 않습니다. 이는 [접근 권한](./access.mdx)에서 설정합니다.
6. **금전등록기 개점** — 세션을 시작합니다. 준비금과 다른 금액은 **개점 차액**으로 표시됩니다.

</JourneyShot>

준비금부터 마감까지 세션 전체 과정은 [금전등록기 개점](../../pos/register/index.mdx)에서 안내합니다.

### 마감 시간이 되면 {#overdue}

**캐셔에게 마감을 알릴 시간**은 자동으로 마감하거나 판매를 중단하지 않습니다. 매장 시계 기준으로 설정한 시간이 지나면 POS는 계산대를 사용하는 사람에게 다음과 같이 알립니다:

- 금전등록기 표시줄에 **마감 시간 초과**가 표시됩니다.
- 장바구니가 비어 있으면 **결제** 대신 **금전등록기 마감**이 표시됩니다. 상품이 담긴 장바구니는 평소처럼 결제할 수 있습니다.
- 금전등록기 패널의 버튼에는 설정한 시간이 반영되어 **금전등록기 마감 · 17:30이 지났습니다**와 같이 표시됩니다.

설정한 시간 이후에 개점한 금전등록기의 마감 시간은 다음 날 같은 시간입니다. 밤새 개점 상태로 둔 금전등록기는 누군가 마감할 때까지 **마감 시간 초과** 상태를 유지합니다.

{/* reshoot: Overdue bar and Close register in an empty cart, see reshoot.md */}

### 집계 차액이 있을 때 {#count-out}

마감 시 캐셔는 준비금을 포함하여 실제로 집계한 금액을 입력하며, 입력하는 동안 차액이 표시됩니다. 아래의 **메모** 필드에 차액의 이유를 설명할 수 있습니다.

<JourneyShot manifest={registerManifest} device="tablet" step={7} offsets={[[150, 0], [-90, 0], [-12, -24]]} alt="금전등록기 마감: 집계한 현금 필드, 일치로 표시된 예상 금액, 마감 및 인쇄 버튼">

1. **집계한 현금, 준비금 포함** — 캐셔가 집계한 금액입니다.
2. **예상 금액** 및 차액 — 여기서는 **일치**입니다. 집계액이 다르면 **부족**하거나 **초과**한 금액이 표시됩니다. 기준액을 넘으면 *기준액 … 초과 · 관리자 승인이 필요합니다*가 추가됩니다.
3. **마감 및 인쇄** — 금전등록기를 마감합니다. 차액이 **집계 차액이 다음 금액을 초과하면 관리자 승인 요청**의 기준액을 넘으면 버튼이 **승인 및 마감**으로 바뀌며, 관리자가 로그인하여 승인합니다. 승인하려면 연결이 필요합니다.

</JourneyShot>

승인할 수 있는 사용자와 예상 금액을 보지 않고 집계하는 사용자는 [접근 권한](./access.mdx)에서 설정합니다. 마감과 승인 내역은 [정산](../../reports/reconciliation.mdx)에 보관됩니다.

:::note 세션 화면과의 차이
[세션](./sessions.mdx)은 POS에 로그인한 사용자와 기기를 표시합니다. *금전등록기 세션*은 별개의 개념으로, 준비금을 넣고 금전등록기를 개점한 뒤 현금을 집계하여 마감할 때까지의 기간입니다.
:::

## Pro로 더 많은 금전등록기 사용 {#more-registers-with-pro}

두 번째 현금 서랍에는 두 번째 금전등록기가 필요하며, 이는 [WCPOS Pro](../../getting-started/free-vs-pro.mdx) 기능입니다. Pro에서는 금전등록기가 매장에 속합니다. Pro가 활성화되면 일반 설정의 **금전등록기** 섹션이 다음과 같이 바뀝니다:

<Accordion>
<AccordionItem question="첫 매장을 만들기 전">

- **금전등록기 개점 및 마감**과 두 규칙은 무료 플러그인과 마찬가지로 사이트의 유일한 금전등록기에 적용됩니다.
- **시작 준비금**은 해당 금전등록기의 설정으로 여기에 그대로 남아 있습니다.
- 설정 아래에는 *금전등록기를 여러 개 운영하려면 매장을 만들고 해당 페이지에서 금전등록기를 추가하세요.*라는 안내와 **매장 추가** 링크가 표시됩니다.

</AccordionItem>
<AccordionItem question="매장을 만든 후">

- **금전등록기 개점 및 마감**과 두 규칙은 **사이트 기본값**이 됩니다. 섹션에 *사이트 기본값입니다. 각 매장의 페이지에서 개별적으로 설정할 수 있습니다.*라는 안내가 표시됩니다.
- **시작 준비금**이 이 섹션에서 사라집니다. 각 금전등록기의 준비금은 해당 매장의 **금전등록기 목록** 페이지에서 설정합니다.
- 설정 아래의 **매장 관리**를 누르면 매장 목록이 열립니다.

</AccordionItem>
</Accordion>

매장을 만들면:

- 처음 만든 매장은 기존 금전등록기를 그대로 넘겨받습니다. 새 금전등록기가 만들어지지는 않습니다.
- 이후에 만드는 매장마다 자체 금전등록기가 생깁니다.
- 공개된 매장에 금전등록기가 없으면 다음에 POS나 매장 페이지에서 금전등록기 목록을 표시할 때 **금전등록기**라는 이름으로 하나가 추가됩니다.
- 금전등록기는 한 번에 하나의 매장에만 속합니다.

### 매장의 금전등록기 페이지 {#store-registers}

**POS → 매장**을 열고 매장을 클릭한 뒤, 매장 메뉴의 **판매** 아래에서 **금전등록기 목록**을 선택하세요. **계산대** 표에 매장의 금전등록기가 나열됩니다. **+ 금전등록기 추가**를 누르면 **금전등록기 2**, **금전등록기 3** 등의 이름으로 추가되며, 이름을 바꿀 수 있습니다. 새 매장은 먼저 **만들기**를 눌러야 합니다. 그전까지 표에는 **금전등록기를 추가하려면 먼저 매장을 저장하세요.** 라는 안내가 표시됩니다.

<Accordion>
  <AccordionItem question="계산대 표: 열, 상태 및 ⋯ 메뉴">

| 열 | 표시 내용 |
| --- | --- |
| **금전등록기** | POS에 표시되는 금전등록기 이름. |
| **시작 준비금** | 캐셔가 이 계산대에서 시작할 때의 현금입니다. 변경 사항은 다음 개점부터 적용됩니다. |
| **상태** | 녹색 점과 함께 **개점 시각** 및 시간 **·** 개점한 사용자가 표시됩니다. 집계 중이면 황색 점과 함께 **집계 중** **·** 개점한 사용자가 표시됩니다. 마감되면 회색 점과 함께 **마감 · 마지막 마감 #** 및 번호와 날짜가 표시되며, 첫 마감 전에는 **마감**만 표시됩니다. |
| **⋯** | **이름 변경**, 다른 매장으로 **이동** 또는 **사용 중지**. 세션이 열려 있거나 집계 중인 금전등록기는 사용 중지할 수 없으며, **먼저 세션을 마감하세요**라는 메시지가 표시됩니다. |

매장 메뉴의 **금전등록기 목록** 배지에는 개점한 계산대 수가 표시되며, 개점한 계산대가 없으면 전체 계산대 수가 표시됩니다.

  </AccordionItem>
  <AccordionItem question="개별 매장의 현금 서랍 규칙">

매장이 일반의 규칙을 사용하는 동안에는 표 아래의 **현금 서랍 규칙**이 접힌 상태로 유지되며 **사이트 기본값**이 표시됩니다. **사용자 지정**을 클릭하면 **매일 금전등록기 개점 및 마감**, **집계 차액이 다음 금액을 초과하면 관리자 승인 요청**, **캐셔에게 마감을 알릴 시간**의 동일한 세 설정이 표시됩니다. 여기에서 변경하기 전까지 각 항목에는 **사이트 기본값**이 표시됩니다. **사이트 기본값 사용**은 규칙 하나를 되돌리고, **사이트 기본값으로 초기화**는 세 규칙을 모두 되돌립니다.

그 아래의 **보고서 및 마감**에서는 이 매장에서 계산대를 마감할 때(**마감 인쇄물**)와 판매 보고서를 실행할 때(**판매 보고서**) 인쇄할 내용을 설정합니다.

  </AccordionItem>
</Accordion>

매장의 영수증과 직원을 포함한 전체 과정은 [매장 설정](../../stores/setup.mdx#registers)에서 안내합니다.

### Pro를 비활성화하면 {#if-pro-is-deactivated}

무료 플러그인은 금전등록기 하나를 사용하는 상태로 돌아갑니다. 다른 금전등록기에 아직 열려 있는 세션이 있으면 집계 후 마감할 수 있지만, Pro를 다시 활성화하기 전까지 해당 금전등록기를 다시 개점할 수는 없습니다.

## 문제가 발생한 경우 {#goes-wrong}

**금전등록기를 저장하지 못했습니다.** 시작 준비금이 저장되지 않았습니다. 연결을 확인하고 다시 입력하세요.

**시작 준비금 필드가 회색으로 표시됩니다.** 불러오거나 저장하는 중입니다. 잠시 기다려도 회색 상태가 유지되면 페이지를 새로고침하세요.

**캐셔에게 마감 시간 초과가 표시되지 않습니다.** **캐셔에게 마감을 알릴 시간**이 켜져 있는지 확인하세요. Pro에서는 매장 자체의 **현금 서랍 규칙**도 확인하세요. 규칙을 개별적으로 설정한 매장은 일반 설정을 따르지 않습니다. 설정한 시간 이후에 개점한 금전등록기의 마감 시간은 다음 날입니다.

**금전등록기를 추가하려면 먼저 매장을 저장하세요.** 새 매장은 생성되기 전까지 **계산대** 표가 없습니다. **만들기**를 클릭한 뒤 금전등록기를 추가하세요.

**먼저 세션을 마감하세요.** 사용 중지하려는 금전등록기가 개점 상태이거나 집계 중입니다. POS에서 집계하고 마감한 뒤 사용 중지하세요.
