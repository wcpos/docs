**WP 관리자:** `WP Admin → POS → Settings → General → Store details`.

사업자의 세금 번호는 POS [영수증과 청구서](#what-prints-on-receipts) 상단의 매장 정보에 인쇄됩니다. 이 목록은 **WP Admin → POS → 설정 → 일반**의 **매장 정보** 아래 **매장 세금 ID**에 있습니다.

WCPOS Pro로 매장을 이미 만들었나요? 그러면 **일반**에 **매장 정보** 대신 매장 목록이 표시되며, 각 매장의 번호는 해당 매장의 **세금** 페이지에서 입력합니다. [매장별 번호 설정](#per-store-tax-ids-pro)을 참고하세요.

## 세금 번호 추가 {#adding-a-tax-id}

각 번호는 매장 전화번호, 이메일, 반품 정책 아래에 있는 **매장 세금 ID** 목록의 한 행에 해당합니다.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[110, 0], [87, 0], [88, 0], [81, 0], [121, 0], [24, -34]]} alt="무료 플러그인의 WP Admin, POS, 설정, 일반에서 매장 세금 ID까지 스크롤한 화면: 유형 FR SIRET, 값, 국가 프랑스, 비어 있는 사용자 지정 라벨, 삭제가 있는 행 하나와 그 아래 세금 ID 추가 버튼, 이어지는 계산대 섹션">

1. **세금 ID 추가** — 행을 추가합니다.
2. **유형** — 번호의 종류입니다. 여기서는 **FR SIRET**입니다.
3. **국가** — **유형**에 따라 변경되며, **유형**도 국가에 따라 변경됩니다.
4. **값** — 번호입니다. 이 필드에서 벗어나면 행이 저장됩니다.
5. **사용자 지정 라벨** — 유형의 약칭 대신 인쇄할 문구입니다.
6. **삭제** — 행을 삭제합니다.

</JourneyShot>

1. WP Admin에서 **POS → 설정 → 일반**을 열고 **매장 세금 ID**까지 스크롤하세요.
2. **세금 ID 추가**를 클릭하세요. **국가**가 WooCommerce 매장 국가로, **유형**이 해당 국가에서 일반적으로 인쇄하는 번호로 설정된 새 행이 나타납니다.
3. **유형**을 확인하고 다른 번호가 필요하면 다른 유형을 선택하세요. **유형**을 바꾸면 **국가**가 변경될 수 있습니다. [유형과 국가의 연동](#the-first-row-uses-your-store-country)을 참고하세요. **값**에 번호를 입력하기 전에는 새 행의 내용이 저장되지 않습니다.
4. **값**에 번호를 입력한 다음 다른 곳을 클릭하거나 Tab 키를 눌러 필드에서 벗어나세요. **값** 필드에서 벗어나면 행이 저장되고 **저장됨** 메시지가 표시됩니다.
5. 영수증에 다른 문구를 표시하려면 **사용자 지정 라벨**에 입력한 다음 필드에서 벗어나세요. 예를 들어 `P.IVA` 대신 `Partita IVA`를 입력할 수 있습니다. **값**과 같은 방식으로 저장됩니다.
6. 각 번호에 대해 반복하세요. **삭제**를 누르면 행이 삭제됩니다. 이미 저장된 행에서 새 **유형**이나 **국가**를 선택하면 즉시 저장되고 **저장됨** 메시지가 표시됩니다.

번호는 목록 순서대로 인쇄됩니다. 순서를 바꾸려면 해당 번호를 삭제한 다음 다시 추가하세요.

:::tip 행을 유지하려면 값을 입력하세요
새 행은 **값**에 번호를 입력해야 유지됩니다. 비워 둔 행은 페이지를 새로고침하면 사라집니다.
:::

### 유형과 국가의 연동 {#the-first-row-uses-your-store-country}

**국가**를 바꾸면 **유형**이 변경될 수 있고, **유형**을 바꾸면 **국가**가 변경될 수 있습니다. 행에서 벗어나기 전에 둘 다 확인하세요.

<Accordion>
  <AccordionItem question="유형과 국가가 서로 변경되는 방식">

- **국가**를 선택하면 **유형**이 해당 국가에서 일반적으로 인쇄하는 번호로 변경됩니다. 어떤 유형인지 확인하려면 아래의 **국가 찾기**를 여세요. 해당 국가의 목록에서 첫 번째 유형이 선택됩니다. 별도 행이 없는 EU 국가는 **EU VAT**, 그 외 국가는 **기타**로 설정됩니다.
- **유형**을 선택하면 그에 맞게 **국가**가 변경됩니다. **EU VAT**는 이미 선택한 EU 국가를 유지하거나, 매장 국가가 EU에 속하면 매장 국가를 사용합니다. **기타**는 **국가**를 그대로 유지합니다.
- 국가 목록의 **국가 없음**을 선택하면 국가가 지워집니다. 국가는 유형 선택을 돕는 정보이며, 영수증에는 라벨과 번호가 인쇄됩니다.

</AccordionItem>
</Accordion>

### 유형과 인쇄되는 이름 {#available-types}

세금 번호에는 VAT 번호, ABN, GSTIN, EIN 또는 법인 등록 번호가 있습니다. WooCommerce에는 이를 위한 필드가 없으므로 WCPOS에서 별도 목록을 관리하며, 필요한 만큼 추가할 수 있습니다. 독일 매장은 같은 영수증에 USt-IdNr., Steuernummer **및** HRB 번호를 인쇄할 수 있습니다.

**값**에는 번호의 일반적인 형식 예시가 회색으로 표시됩니다. 이는 참고용일 뿐입니다. WCPOS는 입력한 내용을 그대로 저장하므로 일반적인 형식이 아닌 번호도 저장됩니다. 영수증에는 **EU VAT**의 **VAT ID**, **AU ABN**의 **ABN**처럼 각 유형의 약칭이 영수증 언어로 번역되어 인쇄됩니다. **사용자 지정 라벨**은 입력한 그대로 인쇄됩니다.

## 영수증에 인쇄되는 내용 {#what-prints-on-receipts}

각 번호는 영수증 상단의 매장 정보에 라벨, 번호 순서로 한 줄씩 인쇄됩니다. 기본 제공 영수증(표준 및 감열식), 청구서, 견적서, 선물 영수증, 계산대 마감 보고서는 목록 전체를 인쇄합니다. 포장 명세서, 주방 주문서, 일반 보고서 템플릿에는 인쇄되지 않습니다.

<Accordion>
  <AccordionItem question="직접 만든 영수증 템플릿을 사용하나요?">

사용자 지정 템플릿에서는 `store.tax_ids`를 반복 처리하여 목록을 인쇄합니다.

```html
{{#store.tax_ids}}{{label}}: {{value}}{{/store.tax_ids}}
```

각 항목에는 `type`과 `country`도 포함됩니다. 영수증 데이터의 [세금 ID 객체](../../receipts/receipt-data.mdx#tax-id-objects)를 참고하세요.

  </AccordionItem>
</Accordion>

## 매장별 번호 설정(Pro) {#per-store-tax-ids-pro}

:::info Pro 기능
매장별 세금 번호를 사용하려면 [WCPOS Pro](../../getting-started/pro-license.mdx)가 필요합니다.
:::

매장마다 자체 세금 번호를 인쇄할 수 있습니다. 매장별로 사업자 등록이 되어 있거나 여러 국가에서 영업하는 체인점에 적합합니다.

1. WP Admin에서 **POS → 매장**을 열고 매장 이름을 클릭하세요.
2. 매장 메뉴에서 **세금**을 여세요.
3. **영수증에 인쇄할 세금 번호** 아래에서 **세금 번호 추가**를 클릭하세요. 새 행에는 해당 매장의 **상세 정보** 페이지에 있는 국가와 그 국가의 일반적인 유형이 설정됩니다.
4. **유형**, **값**, **국가**를 입력하고, 원하면 **라벨(선택 사항)** 도 입력하세요. 유형과 국가는 [일반 페이지에서와 같이](#the-first-row-uses-your-store-country) 연동됩니다. **값**에 번호를 입력하고 필드에서 벗어나면 새 행이 저장됩니다. 이후에는 **유형**과 **국가**가 선택 즉시 저장되고, **값**과 **라벨(선택 사항)** 은 필드에서 벗어날 때 저장됩니다. 페이지 상단 모서리에 **저장 중…** 이 표시된 다음 **✓ 저장됨**이 표시됩니다.

매장에 인쇄되는 번호는 다음과 같습니다.

- **매장에 자체 번호가 있는 경우:** 해당 매장의 영수증에는 자체 번호만 인쇄됩니다. 사이트 목록은 인쇄되지 않습니다.
- **매장에 번호가 없는 경우:** 영수증에 사이트의 **매장 세금 ID**가 인쇄됩니다.
- **둘 다 번호가 없는 경우:** 영수증에 세금 번호가 인쇄되지 않습니다.

<Accordion>
  <AccordionItem question="번호가 없을 때 매장 세금 페이지에 표시되는 내용">

자체 번호가 없으면 매장의 **세금** 페이지에서 대신 인쇄될 내용을 안내합니다.

- 사이트에 번호가 있는 경우: **이 매장에 세금 번호가 없습니다. 영수증에 사이트의 세금 번호가 인쇄됩니다: …**(또는 **세금 번호 목록: …**) 뒤에 사이트 목록이 표시됩니다.
- 사이트에도 번호가 없는 경우: **이 매장과 사이트에 세금 번호가 없습니다. 영수증에 세금 번호가 인쇄되지 않습니다.**

</AccordionItem>
</Accordion>

매장의 **세금** 페이지에 있는 나머지 설정(세금 계산에 사용하는 주소 및 적용 세율)은 [매장 페이지 작성](../../stores/setup.mdx#store-pages)을 참고하세요.

## 문제가 발생한 경우 {#troubleshooting}

**추가한 행이 새로고침 후 사라졌습니다.** **값**이 입력되지 않았기 때문입니다. **세금 ID 추가**를 다시 클릭하고 행에서 벗어나기 전에 번호를 입력하세요.

**매장에서 잘못된 번호가 인쇄됩니다.** 해당 매장의 **세금** 페이지를 여세요. 번호가 하나라도 있으면 매장의 자체 목록만 인쇄됩니다. 해당 행을 삭제하거나 수정하세요. 번호가 없으면 사이트의 **매장 세금 ID**가 인쇄됩니다.

**영수증의 라벨이 세무서에서 요구하는 문구와 다릅니다.** **사용자 지정 라벨**(매장의 **세금** 페이지에서는 **라벨(선택 사항)**)에 필요한 문구를 입력하세요.

**직접 만든 템플릿에 번호가 하나만 인쇄되거나 전혀 인쇄되지 않습니다.** [영수증에 인쇄되는 내용](#what-prints-on-receipts)에서 **직접 만든 영수증 템플릿을 사용하나요?** 를 여세요.
