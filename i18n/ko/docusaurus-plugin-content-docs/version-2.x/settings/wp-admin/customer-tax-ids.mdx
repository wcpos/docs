**WP 관리자:** `WP Admin → POS → Settings → General → Tax IDs`. 이 설정 후 고객에게 ID를 추가합니다.

사업용으로 구매하는 고객은 영수증에 VAT 번호, ABN, CPF, GSTIN 등의 세금 ID가 필요한 경우가 많습니다. 고객에게 한 번 추가하면 POS가 고객의 각 주문에 복사하고 영수증에 인쇄합니다. [개별 판매에 추가](#one-sale)할 수도 있으며, 무료 플러그인에서도 가능합니다.

대부분의 매장은 별도 설정이 필요하지 않습니다. **WP Admin > POS > 설정 > 일반**의 **세금 ID** 섹션은 기존 VAT 플러그인이 계속 작동하도록 번호를 저장할 WordPress 필드만 지정합니다. [세금 ID 저장 위치 선택](#plugins-and-field-names)을 확인하세요.

## 고객에게 세금 ID 추가 {#add}

:::info WCPOS Pro 사용 시
POS에서 고객을 추가하고 편집하려면 Pro가 필요합니다. 무료 플러그인에서는 대신 [판매에](#one-sale) 세금 ID를 추가하세요.
:::

1. 고객 양식을 여세요:
   - **신규 고객:** 장바구니에서 **+** 를 누르고 **새 고객 추가**를 선택하거나, **고객** 화면의 검색 옆에 있는 **새 고객 추가**를 누르세요.
   - **기존 고객:** **고객**에서 해당 고객 행의 열기 화살표(›)를 누르세요.
2. **세금 ID**를 누르세요. 행이 열립니다.
3. **유형**을 선택하고 **ID**를 입력한 뒤 **국가**를 확인하세요. [세금 ID 행](#row)을 확인하세요.
4. **신규 고객:** **고객 추가**를 누르세요. **기존 고객:** 저장 버튼 없이 변경할 때마다 저장됩니다. 양식의 나머지 항목은 [고객](../../customers/index.mdx#add-new-customer)에서 확인하세요.

## 개별 판매에 세금 ID 추가 {#one-sale}

무료 플러그인에서도 사용할 수 있습니다.

1. **주소** — 고객 이름 옆의 핀입니다. 판매에 도로명 주소, 도시 또는 우편번호가 입력되기 전까지는 회색이지만 누를 수 있습니다.

</JourneyShot>

1. 장바구니 상단에서 고객 이름 옆의 주소를 누르세요. **고객 주소 편집**이 열립니다.
2. **세금 ID**를 누른 뒤 [세금 ID 행](#row)의 설명에 따라 **유형**을 선택하고 **ID**를 입력한 다음 **국가**를 확인하세요.
3. **닫기**를 누르세요. 번호는 입력하는 동안 이 주문에 저장되었으며, 주문 영수증에 인쇄됩니다.

<JourneyShot manifest={cartManifest} device="tablet" step={7} offsets={[[80, 0], [250, 0], [200, 0], [200, 0], [285, 0], [0, 0], [0, -40]]} alt="Linda Smith의 고객 주소 편집: 이름, 이메일과 전화번호, 국가와 시/도가 포함된 청구 주소 입력란, 배송 주소, 회사와 세금 ID 버튼, 닫기와 고객 정보도 업데이트">

1. **이름** — 이름과 성입니다. 그 아래에 **이메일**과 **전화번호**가 있습니다.
2. **청구 주소** — **편집**을 누르면 입력란이 열리고, **제거**를 누르면 내용이 지워집니다.
3. **국가** — 목록에서 선택하세요. 국가가 열 개를 넘으면 검색할 수 있습니다.
4. **시/도** — 지역 목록이 있는 국가는 목록으로, 나머지는 텍스트 필드로 표시됩니다.
5. **배송 주소** — **다른 주소 사용**을 누르기 전까지는 **청구 주소와 동일**로 설정됩니다.
6. **세금 ID** — 이 주문에 [세금 ID 행](#row)을 추가합니다.
7. **고객 정보도 업데이트** — 이 정보를 고객 프로필에도 저장합니다.

</JourneyShot>

고객 프로필에도 번호를 저장하려면 **고객 정보도 업데이트**를 누르세요. 이 버튼은 계정이 있는 고객에 대해, 고객 편집 권한이 있는 캐셔에게만 표시됩니다. [주문 주소 편집](../../pos/cart/index.mdx#address)을 확인하세요.

## 세금 ID 행 {#row}

고객 양식과 여기 표시된 장바구니의 **고객 주소 편집**에서 동일한 행을 사용합니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 0], [40, -38], [24, -38], [64, -39], [-24, 0]]} maxWidth={560} alt="세금 ID 행이 입력된 고객 주소 편집: 유형 EU VAT, ID DE123456789, 국가 DE. 행 옆에는 제거, 아래에는 세금 ID 버튼이 있습니다">

1. **세금 ID** — 행을 추가합니다. 이탈리아 고객의 Codice Fiscale과 Partita IVA처럼 두 번째 번호가 있으면 다시 누르세요.
2. **유형** — 번호의 종류입니다. 새 행에는 고객의 청구 국가에 해당하는 첫 번째 유형이 선택됩니다. 청구 주소가 비어 있으면 매장 국가를 기준으로 하며, 해당 국가에 맞는 유형이 없으면 **기타**가 선택됩니다. [세금 ID 유형](#supported-types)을 확인하세요.
3. **ID** — 번호입니다. 빈 필드에는 해당 유형의 올바른 형식 예시가 표시되며, 긴 번호는 입력란 안에서 스크롤됩니다. 저장할 때 공백이 제거되고 영문자는 대문자로 바뀝니다.
4. **국가** — 두 글자 코드입니다. 유형을 선택하면 자동으로 입력됩니다. **영국 VAT**는 **GB**, **브라질 CPF**는 **BR**입니다. **EU VAT**와 **기타**는 청구 국가를 사용하므로, 다른 EU 회원국 고객이라면 확인하세요.
5. **제거** — 행을 삭제합니다.

</JourneyShot>

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-16, 0], [0, 0]]} maxWidth={520} alt="미국 매장의 새 세금 ID 행에서 열린 유형 목록: 맨 위에 미국 EIN이 선택되어 있고 구분선 아래에 EU VAT, 영국 VAT, 호주 ABN과 기타 유형이 있습니다">

1. **해당 국가의 유형** — 구분선 위에 청구 국가 또는 매장 국가에 맞는 유형이 표시됩니다. 여기서는 매장이 미국에 있으므로 **미국 EIN**만 표시됩니다.
2. **나머지 모든 유형** — 구분선 아래에 **EU VAT**부터 표시됩니다.

</JourneyShot>

EU VAT 번호는 **DE123456789**처럼 국가 문자를 포함하여 입력합니다. 국가 문자 없이 입력하면 **EU VAT**와 **영국 VAT**에 한해 저장 시 번호 앞에 **국가** 코드가 추가됩니다.

## 주문에 보관되는 정보 {#tax-ids-are-copied-onto-orders}

판매할 고객을 선택하면 POS가 고객의 세금 ID를 주문에 복사합니다. 세금 ID는 [주문 주소](../../pos/cart/index.mdx#address) 아래에 표시되며, 이번 판매에 사용할 번호를 변경할 수 있습니다. 주문에는 판매 당시의 번호가 보관됩니다:

- 나중에 고객의 세금 ID를 변경해도 과거 주문은 바뀌지 않으므로 이전 영수증은 원래 내용 그대로 다시 인쇄됩니다.
- 장바구니에서 변경하거나 추가한 세금 ID는 해당 주문에서 고객의 기존 세금 ID 대신 사용됩니다.
- 주문의 세금 ID를 변경하면 해당 주문에만 적용됩니다. 고객 정보에서 다시 복사하지 않습니다.
- 비회원 판매에는 직접 추가하지 않는 한 세금 ID가 없습니다.

## 영수증 표시 {#on-receipts}

**표준 영수증**, **상세 영수증**, **청구서**, **견적서** 템플릿과 상세 감열 영수증은 고객 정보와 함께 고객 세금 ID를 인쇄합니다. 각 번호에는 **VAT ID**, **ABN**, **CPF** 등의 레이블이 붙습니다. [세금 ID 유형](#supported-types)의 표를 확인하세요. 직접 만든 템플릿에서 인쇄하려면 [세금 ID 객체](../../receipts/receipt-data.mdx#tax-id-objects)를 확인하세요.

## 세금 ID로 고객 찾기 {#finding-customers-by-tax-id}

장바구니 또는 **고객** 화면의 고객 검색에 번호를 입력하세요. [세금 ID 저장 위치 선택](#plugins-and-field-names)에 나열된 VAT 플러그인이 WCPOS 사용 전에 저장한 번호도 검색됩니다. [고객 검색](../../customers/index.mdx#find)을 확인하세요.

## 세금 ID 저장 위치 선택 {#plugins-and-field-names}

WCPOS는 VAT 플러그인이 기존에 사용하는 위치에 세금 ID를 저장합니다. 따라서 계산대에서 입력한 번호는 플러그인에, 플러그인이 저장한 번호는 POS에 표시됩니다. 서로 일치하지 않을 때만 이 섹션의 설정이 필요합니다.

확인하려면 **WP Admin > POS > 설정 > 일반**을 열고 **세금 ID**까지 스크롤하세요. 배너에 WCPOS가 VAT 플러그인을 감지했는지 표시됩니다.

<JourneyShot manifest={manifest} device="desktop" step={5} offsets={[[-60, 0], [-60, 0], [76, 0], [166, 0], [96, 0], [108, 0]]} alt="일반의 고객 아래에 있는 세금 ID 섹션: 감지된 플러그인 없음 배너와 고급: 다른 필드 이름 사용을 펼친 모습. 유형, 사용 중인 필드 이름, 출처, 재정의 열이 있으며 모든 행의 출처는 기본 제공이고 재정의 입력란은 비어 있습니다">

1. **감지된 플러그인 없음** — WCPOS가 VAT 플러그인을 찾지 못해 기본 제공 필드 이름을 사용합니다.
2. **고급: 다른 필드 이름 사용** — 아래 표를 엽니다. [다른 필드 이름 사용](#choosing-the-field-name-yourself)을 확인하세요.
3. **유형** — 세금 ID 종류마다 행이 하나씩 있습니다.
4. **사용 중인 필드 이름** — WCPOS가 현재 해당 유형을 저장하는 위치입니다.
5. **출처** — 필드 이름이 선택된 방식입니다. 여기서는 모든 유형이 **기본 제공**입니다.
6. **재정의** — 직접 지정할 필드 이름입니다. 비워 두면 기본값을 사용합니다.

</JourneyShot>

<details>
<summary>WCPOS의 필드 선택 방식과 감지하는 플러그인</summary>

WordPress는 이름이 지정된 필드(메타 키)에 고객 세금 ID를 보관하며, VAT 플러그인마다 서로 다른 필드 이름을 사용합니다. 배너에는 다음과 같이 표시됩니다:

- **자동 감지됨** — 감지한 플러그인을 “…이(가) 설치되어 있습니다.”라고 표시합니다. WCPOS는 VAT 형식의 세금 ID를 해당 플러그인이 읽는 필드에 저장합니다. 별도로 할 일은 없습니다.
- **감지된 플러그인 없음** — WCPOS는 기본 제공 필드 이름 또는 최근 주문에서 이미 사용하는 필드를 사용합니다.

각 유형에 대해 WCPOS는 다음 중 처음으로 해당하는 항목을 사용합니다:

1. [다른 필드 이름 사용](#choosing-the-field-name-yourself)에서 직접 지정한 필드 이름이 있으면 해당 이름.
2. 감지한 플러그인의 필드.
3. 감지한 플러그인이 없으면 최근 200개 주문에서 가장 많이 사용된 필드.
4. 기본 제공 필드 이름.

감지하는 플러그인:

- WooCommerce EU VAT Number
- Aelia EU VAT Assistant. Aelia가 해당 번호를 유효한 것으로 확인했는지도 포함합니다
- WPFactory EU/UK VAT Manager
- WooCommerce Germanized 및 Germanized Pro
- Brazilian Market on WooCommerce 및 Extra Checkout Fields for Brazil
- NIF/CIF Spain for WooCommerce

기본 제공 필드 이름:

| 유형 | 필드 이름 |
|---|---|
| EU VAT, 영국 VAT, 사우디아라비아 VAT, 호주 ABN, 캐나다 GST/HST, 미국 EIN, 기타 | `_billing_vat_number` |
| 브라질 CPF | `_billing_cpf` |
| 브라질 CNPJ | `_billing_cnpj` |
| 인도 GSTIN | `_billing_gstin` |
| 이탈리아 Codice Fiscale | `_billing_cf` |
| 이탈리아 P. IVA | `_billing_piva` |
| 스페인 NIF/CIF | `_billing_nif` |
| 아르헨티나 CUIT | `_billing_cuit` |

</details>

### 다른 필드 이름 사용 {#choosing-the-field-name-yourself}

플러그인이 WCPOS가 알지 못하는 필드 이름으로 세금 ID를 보관할 때만 변경하세요.

<details>
<summary>필드 이름 변경</summary>

**세금 ID** 섹션에서 **고급: 다른 필드 이름 사용**을 여세요. 유형마다 행이 하나씩 표시됩니다:

- **유형** — 세금 ID의 종류입니다.
- **사용 중인 필드 이름** — WCPOS가 현재 해당 유형을 저장하는 위치입니다.
- **출처** — **플러그인**(감지된 플러그인), **기본 제공**(WCPOS 기본값), **사용자 지정**(직접 재정의한 값) 중 하나입니다.
- **재정의** — 플러그인이 사용하는 필드 이름을 입력하세요. 입력란에는 WCPOS가 다른 플러그인에서 파악한 이름이 제안됩니다. 제안된 이름을 선택하거나, 직접 입력한 뒤 Enter를 누르거나 입력란을 벗어나면 저장됩니다. 저장 버튼은 없습니다.

자동으로 선택한 이름으로 돌아가려면 **재정의** 입력란을 비우세요. 입력란에는 “(기본값을 사용하려면 비워 두세요)”라고 표시됩니다. **고급: 다른 필드 이름 사용** 줄에는 활성화된 재정의 수가 표시됩니다.

</details>

:::note
여기에는 고객 세금 ID만 표시됩니다. 사업체의 USt-IdNr., KVK, SIRET 번호 등은 [매장 세금 ID](./store-tax-ids.mdx)에서 설정합니다.
:::

## 문제가 발생한 경우 {#goes-wrong}

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-28, 0]]} maxWidth={560} alt="유형이 EU VAT이고 ID가 DE1234인 세금 ID 행. ID 아래에 ‘형식이 선택한 유형과 일치하지 않습니다.’ 경고가 표시됩니다">

1. **형식 경고** — **ID** 아래에 표시됩니다. 대처 방법은 아래 첫 번째 항목을 확인하세요.

</JourneyShot>

- **형식이 선택한 유형과 일치하지 않습니다.** — 먼저 **유형**을 확인한 뒤 고객과 함께 번호에 빠진 숫자가 없는지 확인하세요. 경고일 뿐이며 번호는 저장됩니다. EU VAT 번호를 국가 문자 없이 입력한 경우에도 표시됩니다. 저장 시 번호 앞에 **국가** 코드가 추가되므로 **국가**가 올바른지 확인하세요. POS는 번호의 형식만 검사하며 세무 기관에서 실제로 발급한 번호인지는 확인하지 않습니다.
- **이전 영수증에 이전 번호가 표시됨** — 주문에는 판매 당시의 번호가 보관됩니다. 고객 정보가 아니라 해당 주문의 세금 ID를 변경하세요.
- **영수증에 세금 ID가 없음** — 비회원 판매였거나 판매 당시 고객에게 세금 ID가 없었습니다. 결제 전에 판매에 세금 ID를 추가하고, 영수증 템플릿이 고객 정보를 표시하는 템플릿인지 확인하세요.
- **계산대에서 입력한 번호가 VAT 플러그인에 표시되지 않음** — **WP Admin > POS > 설정 > 일반 > 세금 ID**에서 **고급: 다른 필드 이름 사용**을 열고 **사용 중인 필드 이름**을 플러그인이 읽는 필드와 비교하세요. 다르면 **재정의**를 설정하세요.
- **고객 정보도 업데이트가 표시되지 않음** — 비회원 판매이거나 WordPress 역할에 고객 편집 권한이 없습니다. 세금 ID는 주문에는 저장됩니다.
- **새 고객 추가가 회색으로 표시됨** — Pro와 고객 생성 권한이 있는 역할이 필요합니다.
