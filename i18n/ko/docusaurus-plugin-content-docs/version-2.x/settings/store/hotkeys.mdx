계산대에 키보드가 있으면 마우스를 사용하지 않고도 판매를 처리할 수 있습니다. **Alt**(Mac에서는 **Option ⌥**)를 누른 상태에서 키를 누르세요. **Alt + /** 를 누르면 전체 단축키가 표시됩니다.

:::note 단축키가 작동하는 곳
브라우저와 데스크톱 앱의 POS 화면에서 작동합니다. 커서가 텍스트 입력란에 있어도 사용할 수 있습니다. {/* pending: monorepo#3357 */} Mac에서 **Option + N**처럼 입력란에 악센트 기호를 입력하는 단축키를 사용하려면 먼저 [입력란 바깥을 클릭](#goes-wrong)해야 합니다. 휴대폰과 태블릿 앱에는 단축키가 없습니다. 다른 화면에도 없지만, 주문 목록에서는 별도의 [방향키](#orders)를 사용할 수 있습니다.
:::

## 단축키 목록 {#shortcuts}

결제 화면이나 결제 완료 화면에서는 **Alt + /** 를 제외한 모든 단축키가 작동을 멈춥니다. 계산대 선택 화면, **계산대 열기** 카드, 현금 집계 화면 또는 진행 중인 주문 목록에 장바구니가 가려져 있을 때도 **Alt + F**와 **Alt + /** 를 제외한 모든 단축키가 작동을 멈춥니다.

| 단축키 | 동작 |
|---|---|
| **Alt + F** | 커서가 **상품 검색**으로 이동합니다. 화면이 좁으면 먼저 상품 탭이 열립니다. |
| **Alt + P** | **결제** 화면이 열립니다.<br />_장바구니에 상품이 있어야 합니다._ |
| **Alt + N** | 빈 장바구니가 열립니다. 작업하던 주문은 진행 중인 상태로 유지됩니다.<br />_장바구니가 비어 있지 않고 주문이 있어야 합니다._ |
| **Alt + ←** 또는 **Alt + →** | 이전 또는 다음 진행 중인 주문으로 이동합니다.<br />_진행 중인 주문이 두 개 이상 있어야 합니다._ |
| **Alt + D** | **할인 추가**가 열립니다.<br />_장바구니에 주문이 있어야 합니다._ |
| **Alt + V** | 장바구니의 주문이 즉시 무효화됩니다. 실수로 눌렀다면 바로 **실행 취소**를 누르세요.<br />_장바구니에 주문이 있어야 합니다._ |
| **Alt + /** | 단축키 목록을 열거나 닫습니다.<br />_결제 화면을 포함한 POS 화면에서 언제든 사용할 수 있습니다._ |

:::warning Alt + V는 확인 없이 실행됩니다
키를 누르는 즉시 주문이 무효화됩니다. 표시되는 메시지에 **실행 취소** 버튼이 있으니, 실수로 눌렀다면 바로 누르세요.
:::

단축키는 고정되어 있으며 변경하는 설정은 없습니다. 다른 키를 사용하고 싶다면 [Discord](https://wcpos.com/discord)에서 알려주세요.

## 전체 단축키 보기 {#list}

**Alt + /** 를 누르세요. 오른쪽에서 목록이 펼쳐집니다.

회색 행은 현재 실행할 수 없습니다. 장바구니가 비어 있으면 **결제**, **새 장바구니**, **할인 추가**, **주문 무효화**가 회색으로 표시되며, **이전 장바구니**와 **다음 장바구니**는 진행 중인 주문이 두 개 이상 열릴 때까지 회색으로 유지됩니다. 나머지 행을 누르면 해당 단축키를 누른 것과 동일하게 실행됩니다. Windows에서는 하단에 [Firefox](#goes-wrong) 관련 주의 사항이 표시됩니다. **닫기**를 누르거나 **Alt + /** 를 다시 누르면 목록이 닫힙니다.

목록은 장바구니를 덮고 옆의 상품 영역을 어둡게 표시합니다.

1. **상품 검색** — 상품 검색란으로 커서를 이동해 입력하거나 스캔할 수 있게 합니다. [검색 및 필터링](../../pos/product-panel/search-filtering.mdx)을 참고하세요.
2. **결제** — 장바구니에 있는 주문의 결제 패널을 엽니다. [결제](../../pos/checkout/index.mdx)를 참고하세요.
3. **새 장바구니** — 빈 장바구니로 시작합니다. 작업하던 주문은 [진행 중인 주문](../../pos/cart/open-orders.mdx)에 남습니다.
4. **이전 장바구니** — 현재 주문 바로 앞의 진행 중인 주문으로 이동합니다.
5. **다음 장바구니** — 다음 진행 중인 주문으로 이동합니다.
6. **할인 추가** — 해당 주문의 **할인 추가**를 엽니다. [할인](../../pos/cart/discounts.mdx)을 참고하세요.
7. **주문 무효화** — 확인 없이 장바구니의 주문을 즉시 무효화합니다. 실수로 눌렀다면 바로 **실행 취소**를 누르세요. [무효화](../../pos/cart/order-actions.mdx#void)를 참고하세요.
8. **키보드 단축키** — 이 목록입니다.

## 주문 목록에서 이동하기 {#orders}

브라우저나 데스크톱 앱의 **주문** 화면에서 주문을 클릭하거나 **Tab**으로 목록에 진입한 뒤 다음 키를 사용하세요.

- **↓** / **↑** 를 누르면 다음 또는 이전 주문으로 강조 표시가 이동합니다.
- **Enter**를 누르면 강조 표시된 주문이 열립니다.

:::info Pro 기능
주문 화면은 WCPOS Pro에서 제공됩니다. [주문](../../orders/index.mdx)을 참고하세요.
:::

## 문제가 발생한 경우 {#goes-wrong}

**아무 반응이 없습니다.** **Alt + /** 로 목록을 여세요. 단축키 행이 회색이면 [표](#shortcuts)에 설명된 이유로 아직 실행할 수 없는 상태입니다. POS 화면에 있는지, 계산대가 열려 있는지, 진행 중인 주문 목록이 장바구니를 가리고 있지 않은지 확인하세요.

**Alt + F 또는 Alt + D를 누르면 Firefox 메뉴가 열립니다.** Windows에서는 Firefox가 이 두 단축키를 자체적으로 사용할 수 있습니다. 대신 단축키 목록에서 해당 행을 누르거나 Chrome, Edge 또는 데스크톱 앱을 사용하세요.

**Mac에서 Option + N을 누르면 검색란에 악센트 기호가 입력됩니다.** 일부 키보드 배열은 Option + 문자 키로 악센트 기호를 입력하며, 입력란에 입력하는 동안 POS는 이 기호 입력을 허용합니다. 입력란 바깥을 클릭한 다음 단축키를 다시 누르세요.
