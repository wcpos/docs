:::info Pro 기능
주문 페이지에는 [WCPOS Pro](../getting-started/pro-license.mdx)가 필요합니다. Pro가 없으면 목록의 흐릿한 미리보기가 표시되며, WP Admin의 **WooCommerce → 주문**에서 주문을 관리합니다.
:::

메뉴의 **주문**에는 매장의 판매 내역이 표시됩니다. 고객이 다시 방문하면 판매 내역을 찾아 영수증을 재인쇄하거나 환불하거나 장바구니로 다시 가져와 수정할 수 있습니다. 이를 위해 WP Admin으로 전환할 필요는 없습니다.

## 주문 찾기 {#find-an-order}

목록을 열면 **이 매장에서 본인이 처리한 판매 내역**이 최신순으로 표시됩니다. 판매 내역을 찾으려면 다음을 수행하세요.

1. 상단의 **주문 검색**에 주문 번호, 고객 이름, 전화번호, 이메일 또는 상품을 입력하세요.
2. 판매 내역이 표시되지 않으면 다른 캐셔가 처리했을 수 있습니다. **캐셔** 필터의 **×** 를 눌러 모든 캐셔의 판매 내역을 검색하세요. 다른 매장이나 온라인에서 이루어진 판매라면 **매장** 필터를 변경하세요.
3. 판매 내역을 탭하여 여세요. [주문 열기](#order-details)를 참조하세요.

주문 페이지가 열린 상태에서 직접 입력하는 대신 인쇄된 영수증의 주문 번호 바코드를 스캔하세요. 스캔한 값이 **주문 검색**에 입력되고 해당 판매 내역이 표시됩니다. [바코드 스캐너](../hardware/scanners/index.mdx)를 참조하세요.

<details>
<summary>검색 대상</summary>

주문 번호, 고객 이름, 회사, 전화번호(청구 또는 배송 정보), 청구 이메일, 주문에 포함된 상품의 이름 또는 SKU가 검색 대상입니다. [검색 대상](../reference/search.mdx#orders)을 참조하세요.

</details>

페이지를 열면 **캐셔** 필터에는 본인이, **매장** 필터에는 로그인한 매장(사이트에 매장이 하나뿐이면 **POS**)이 표시됩니다. 최신 판매가 먼저 표시되며, 매장의 시간대를 기준으로 날짜별 제목 아래에 묶여 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[300, 0], [0, -28], [0, -28], [0, -28], [-30, 0], [80, 0], [434, 0], [95, 0], [0, -26], [-40, 0]]} alt="주문 번호 하나를 검색한 주문 페이지: 검색창, 캐셔와 매장이 설정된 필터, 완료된 주문 하나 위의 오늘 제목, 하단의 개수와 동기화 버튼">

1. **주문 검색**: 주문 번호, 이름, 전화번호 또는 상품을 입력하세요.
2. **필터**: 목록의 범위를 좁힙니다. [목록 필터링](#filters)을 참조하세요.
3. **캐셔**: 페이지를 열면 본인으로 설정됩니다. 모든 캐셔의 판매 내역을 보려면 **×** 를 누르세요.
4. **매장**: 로그인한 매장으로 설정됩니다.
5. **표시 설정**: 열을 선택합니다. [표시 설정](#display-settings)을 참조하세요.
6. **날짜 제목**: 하루의 판매 내역을 묶어 표시하며, 가장 최근 날짜가 먼저 나옵니다.
7. **열 머리글**: 클릭하면 해당 열을 기준으로 정렬합니다. [열 정렬 및 너비 조정](#sort-and-resize)을 참조하세요.
8. **상태 배지**: 누르면 해당 상태의 주문만 표시됩니다.
9. **열기**: 주문을 엽니다. [주문 열기](#order-details)를 참조하세요.
10. **M개 중 N개 표시** 및 동기화 버튼: 목록에 표시된 주문 수를 보여 주고 새 주문과 변경된 주문을 가져옵니다.

## 주문 열기 {#order-details}

주문 행을 탭하여 여세요. 마우스를 사용하는 경우 행 끝의 화살표(<Icon name="chevron-right" />)를 클릭하거나 방향키로 행을 선택한 다음 **Enter**를 누르세요. 주문이 오른쪽 패널의 **보기** 탭에서 열립니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[350, 0], [24, -29], [26, -29], [19, -29], [28, -29], [31, -29]]} alt="주문 페이지에서 보기 탭으로 연 주문: 날짜, 매장과 캐셔 정보, 상품, 합계와 현금 결제, 하단의 삭제, 환불, 동기화, 닫기, 영수증, 다시 열기 버튼">

1. **주문 상세 정보**: 주문 시점, 매장, 담당 캐셔 및 주문 생성 경로입니다.
2. **삭제**: 저장된 주문을 매장의 휴지통으로 이동합니다. [주문 삭제](#delete)를 참조하세요.
3. **환불**: 환불 양식을 엽니다. [판매 환불](#refunds)을 참조하세요.
4. **동기화**: 매장에서 이 주문의 최신 데이터를 가져옵니다. [개별 주문 동기화](#sync)를 참조하세요.
5. **영수증**: 다시 인쇄하거나 이메일로 보낼 수 있는 주문 영수증입니다. [영수증 재인쇄](#receipt-reprinting)를 참조하세요.
6. **다시 열기**: 주문을 수정할 수 있도록 장바구니로 다시 가져옵니다. [상품 또는 수량 변경](#reopening-orders)을 참조하세요.

</JourneyShot>

표시되는 버튼은 주문에 따라 다릅니다. [주문 작업](#order-actions)을 참조하세요. 이 기기에 주문이 없으면 패널에 **주문을 찾을 수 없습니다**가 표시됩니다.

<details>
<summary>보기, 편집 및 JSON 탭</summary>

- **보기**: 고객이 구매한 그대로의 주문을 표시합니다. [보기에 표시되는 내용](#view-tab)을 참조하세요.
- **편집**: 양식에서 주문 상세 정보를 변경합니다. [상태, 고객 또는 주소 변경](#editing-orders)을 참조하세요.
- **JSON**: 지원 및 문제 해결에 사용하는 주문 원시 데이터입니다. 상품, 고객, 쿠폰을 열 때도 동일한 **JSON** 탭이 있습니다.

</details>

### 보기에 표시되는 내용 {#view-tab}

보기에서는 스크롤하며 상태, 상품, 합계, 결제, 환불, 고객 등 주문 전체를 확인할 수 있습니다.

<details>
<summary>보기의 모든 구성 요소: 위에서 아래 순서</summary>

- **상태**: 주문 상태 배지입니다. 일부 환불된 주문에는 **부분 환불됨**이, 열린 주문에는 **POS 열림** 또는 **POS 부분 결제**가 표시됩니다.
- **주문 상세 정보**: 날짜와 시간, 매장(주문에 지정된 경우), 캐셔, 주문 생성 경로를 나타내는 아이콘입니다.
- **상품**: 각 행에 수량, 상품, 가격, 합계가 표시되며 수수료도 포함됩니다. 항목이 없는 주문에는 **주문 항목이 없습니다.** 메시지가 표시됩니다.
- **합계**: 소계, 할인, 배송비, 수수료, 세금이 표시되며 세율별로 한 줄씩 나옵니다. 환불 후에는 환불 금액이 빨간색으로 표시되고 마지막 줄이 **순 결제액**으로 바뀝니다. 그 외에는 **합계**가 표시됩니다.
- **결제**: 결제 방법과 금액입니다. 결제된 주문에는 **매입 완료**와 결제 날짜, 거래 ID가 있는 경우 해당 ID가 표시됩니다. 나누어 결제한 주문은 **결제 내역** 아래에 각 결제가 표시됩니다. 이메일로 보낸 청구서에는 발송 대상과 시점이 표시됩니다.
- **환불**: 해당 주문에 환불 내역이 있으면 각 환불을 표시합니다.
- **고객**: 이름, 이메일, 전화번호, 고객 메모, 청구 주소, 청구 주소와 다른 경우 배송 주소, 세금 ID입니다.

</details>

## 주문 작업 {#order-actions}

<details>
<summary>주문에 표시되는 버튼</summary>

| 버튼 | 기능 | 표시되는 경우 |
|--------|--------------|-----------------|
| **다시 열기** | 주문을 장바구니로 다시 가져와 수정하고 다시 결제합니다. | Pro 사용 시 항상 표시됩니다. |
| **영수증** | 인쇄하거나 이메일로 보낼 영수증을 표시합니다. | 주문이 매장에 저장된 후 표시됩니다. |
| **다시 보내기** | 청구서 결제 방법이 선택된 상태로 주문을 결제 화면에서 다시 열어 새 청구서를 보낼 수 있습니다. | 이메일로 보낸 청구서의 결제를 기다리는 주문에 표시됩니다. |
| **동기화** | 매장에서 이 주문 하나를 다시 가져옵니다. | 주문이 매장에 저장된 후 표시됩니다. |
| **삭제** | 주문을 삭제합니다. | Pro 사용 시 항상 표시됩니다. |
| **환불** | 환불 양식을 엽니다. | 매장에 저장된 주문이 완료, 처리 중 또는 보류 중 상태일 때 표시됩니다. |
| **청구서 취소** | 이메일로 보낸 청구서를 취소합니다. 인터넷 연결이 필요합니다. | 이메일로 보낸 청구서의 결제를 기다리는 주문에 표시됩니다. |

</details>

### 영수증 재인쇄 {#receipt-reprinting}

영수증을 다시 인쇄하거나 이메일로 보내려면 다음을 수행하세요.

1. 주문을 열고 하단의 **영수증**을 누르세요.
2. 영수증을 인쇄하거나 고객에게 이메일로 보내세요. [영수증 재인쇄](../receipts/index.mdx#reprint)를 참조하세요.

목록에서 한 번의 클릭으로 재인쇄하려면 [표시 설정](#display-settings)에서 **영수증** 열을 켜세요. 저장된 각 주문의 행에 영수증 버튼이 표시됩니다. 아직 매장에 전송되지 않은 주문에는 영수증 버튼이 없습니다.

### 상태, 고객 또는 주소 변경 {#editing-orders}

주문의 **편집** 탭을 여세요. 여기에서는 주문 항목을 변경할 수 없습니다. 항목을 변경하려면 주문을 다시 여세요.

- **상태**: 새 상태를 선택한 다음 **상태 업데이트**를 누르세요. 매장에 반영되면 **상태가 업데이트되었습니다**가 표시됩니다.
- **고객, 고객 메모 및 주소**: 필드를 변경하세요. 저장 버튼은 없습니다. 각 필드는 변경할 때마다 저장되며, 저장되면 **저장됨**이 표시됩니다. **저장되지 않음**은 변경 사항이 반영되지 않았다는 뜻입니다. 필드를 다시 변경하세요.

<details>
<summary>변경할 수 있는 다른 정보</summary>

결제 방법, 통화, 거래 ID, 세금 ID, 메타데이터입니다. 위의 필드와 마찬가지로 각각 변경할 때마다 저장됩니다.

</details>

### 상품 또는 수량 변경 {#reopening-orders}

:::note 수정할 때마다 재고가 변동됩니다
이미 재고가 차감된 판매는 각 항목을 변경할 때마다 재고가 즉시 변동됩니다.
:::

:::warning 합계가 줄어도 차액은 환불되지 않습니다
변경 후 판매 금액이 결제한 금액보다 적어도 POS는 초과 금액을 돌려주지 않습니다. 고객과 차액을 정산하세요. [판매 환불](#refunds)을 참조하세요.
:::

1. 주문 하단의 **다시 열기**를 누르세요. POS에서 해당 주문의 장바구니가 열리고(휴대전화에서는 **장바구니** 탭), 주문이 **POS - 열림** 상태로 바뀝니다.

2. 장바구니를 수정하세요.
   - **수량 변경**: 수량을 탭하고 새 숫자를 입력한 다음 **완료**(체크 표시)를 탭하거나 **Enter**를 누르세요. iOS 및 Android 앱에는 숫자 키패드가 없으므로 입력란에 직접 입력합니다. [수량 변경](../pos/cart/line-items.mdx#quantity)을 참조하세요.
   - **항목 제거**: 항목의 합계를 탭한 다음 **제거**를 탭하세요.
   - **상품 추가**: 새 판매와 마찬가지로 상품 그리드에서 상품을 탭하거나 스캔하세요. 스캔할 때마다 하나씩 추가됩니다.
   - **가격 또는 고객 변경**: [주문 항목](../pos/cart/line-items.mdx) 및 [고객 선택](../pos/cart/index.mdx#customer-selector)을 참조하세요.
   - **메모 또는 사용자 지정 필드 변경**: **결제** 옆의 **⋮** 를 탭하여 **주문 상세 정보**를 여세요. [고객 메모 추가](../pos/cart/order-actions.mdx#order-note) 및 [추가 정보 입력](../pos/cart/order-actions.mdx#order-meta)을 참조하세요.

3. 결제 과정을 다시 진행하여 수정된 주문을 완료하세요. 이미 받은 결제는 주문에 유지됩니다. 결제 화면에는 기존 결제가 나열되고 아직 받지 않은 금액만 **잔액**으로 표시되어 청구됩니다. 장바구니가 그대로이고 환불도 없었다면 청구액이 없고, 상품을 추가했다면 차액만 청구됩니다. [결제](../pos/checkout/index.mdx)를 참조하세요.

<details>
<summary>다시 연 판매의 재고 및 결제</summary>

판매에서 이미 재고가 차감되었다면(다시 열기 전에 결제를 받았다면), 장바구니의 각 항목을 변경할 때마다 재고가 즉시 변동됩니다. 항목을 추가하거나 수량을 늘리면 상품 재고가 줄고, 항목을 제거하거나 수량을 줄이면 재고가 복원됩니다. 판매를 다시 완료해도 재고가 중복 차감되지는 않습니다.

상품을 제거하여 판매 금액이 결제한 금액보다 적어지면 결제 화면에서는 추가 금액을 청구하지 않으며, POS가 초과 금액을 자동으로 돌려주지도 않습니다. 환불 등의 방법으로 고객과 차액을 정산하세요. [판매 환불](#refunds)을 참조하세요.

</details>

카드 결제가 아직 진행 중인 판매는 다시 열 수 없습니다. 메시지에 진행 중인 결제가 표시됩니다. 먼저 해당 결제를 취소하세요. [결제 취소](../pos/checkout/cancelling-a-payment.mdx)를 참조하세요.

### 판매 환불 {#refunds}

POS에서 전액 또는 부분 환불을 할 수 있습니다. 결제 게이트웨이가 지원하는 경우 원래 결제 방법으로 환불하거나 계산대에서 현금으로 환불할 수 있습니다. 주문을 열고 하단의 **환불**을 누르세요.

계산대에서의 단계별 환불 방법은 [계산대에서 환불](../pos/refunds.mdx)을 참조하세요. 환불 수단, 부분 환불, 영수증의 환불 표시 방식은 [환불](./refunds.mdx)을 참조하세요.

### 개별 주문 동기화 {#sync}

다른 사람이 WP Admin에서 주문을 변경한 경우 등에는 **동기화**를 눌러 매장에서 이 주문의 최신 데이터를 가져오세요. 매장에 연결할 수 없으면 “이 주문을 새로고침할 수 없습니다. 이 기기의 사본은 변경되지 않았습니다”가 표시됩니다. 연결을 확인하고 다시 시도하세요.

### 주문 삭제 {#delete}

**삭제**를 누른 다음 확인하세요. 저장된 주문은 매장의 **휴지통**으로 이동하며, 관리자가 WP Admin에서 복원할 수 있습니다. 매장에 한 번도 전송되지 않은 주문은 영구적으로 삭제되며 확인 창에도 이 내용이 안내됩니다.

캐셔 역할에는 **서버에서 주문을 삭제할 권한이 없습니다**가 표시되고 주문은 그대로 유지됩니다. 매장 관리자나 관리자에게 삭제를 요청하세요.

<details>
<summary>관리자를 위한 권한 안내</summary>

삭제하려면 WordPress의 `delete_shop_orders` 권한이 필요하며, 다른 캐셔의 주문이나 온라인 주문에는 `delete_others_shop_orders` 권한도 필요합니다. 캐셔 역할에는 둘 다 없습니다.

</details>

## 목록 사용하기 {#the-list}

스크롤하면 주문을 계속 추가로 불러옵니다. 하단에는 표시된 주문 수(**240개 중 10개 표시**)와 동기화 버튼(<Icon name="arrow-rotate-right" />)이 있습니다. 버튼을 누르면 새 주문과 변경된 주문을 가져옵니다. 길게 누르면 **지우고 새로고침**이 표시됩니다. 이 기능은 검색어를 지우고 필터를 이 매장에서 본인이 처리한 판매 내역으로 되돌린 다음 주문을 다시 다운로드합니다.

### 목록 필터링 {#filters}

검색창 아래의 필터로 목록의 범위를 좁힐 수 있습니다. 필터링은 서버에서 실행되므로 기기에 이미 있는 주문뿐 아니라 모든 주문을 대상으로 합니다.

<details>
<summary>모든 주문 필터</summary>

| 필터 | 필터링 기준 |
|------|--------------------|
| **상태** | 완료, 처리 중 등의 주문 상태입니다. |
| **결제 방법** | 주문을 결제한 방법입니다. |
| **고객 선택** | 특정 고객입니다. |
| **캐셔 선택** | 판매를 처리한 사람입니다. 제거하면 모든 캐셔의 판매 내역이 표시됩니다. |
| **매장** | 특정 매장 또는 주문 생성 경로인 **POS**, **온라인 매장**, **WP Admin**입니다. 매장을 선택하지 않으면 필터에 **생성 경로**가 표시됩니다. |
| **계산대 선택** | 판매를 처리한 계산대입니다. |
| **날짜 범위** | 날짜 구간입니다. 달력에서 **오늘**, **어제**, **이번 주**, **지난주**, **이번 달**, **지난달**을 빠르게 선택할 수 있습니다. **완료**를 눌러 적용하세요. |

</details>

설정된 각 필터에는 해당 필터를 제거하는 **×** 가 있습니다. 필터를 두 개 이상 변경하면 행 끝에 **모두 지우기**가 표시되며, 이를 누르면 필터가 이 매장에서 본인이 처리한 판매 내역으로 되돌아갑니다.

행에서도 필터를 적용할 수 있습니다. 상태 배지를 누르면 해당 상태만, 고객 또는 캐셔 이름을 누르면 해당 고객 또는 캐셔의 주문만 표시됩니다.

### 열 정렬 및 너비 조정 {#sort-and-resize}

열 머리글을 클릭하면 해당 열을 기준으로 정렬되며, 다시 클릭하면 오름차순과 내림차순이 전환됩니다. **상태**, **주문 번호**, **고객**, **생성 날짜**, **결제 방법**, **합계**를 기준으로 정렬할 수 있습니다. 날짜별 제목은 **생성 날짜**로 정렬한 경우에만 표시됩니다. 정렬 설정은 다음에도 유지됩니다.

열 너비를 조정하려면 머리글의 오른쪽 가장자리를 드래그하세요. 마지막 열과 **작업** 열은 너비를 조정할 수 없으며, 페이지를 떠나면 너비가 원래대로 돌아갑니다.

### 목록이 비어 있는 경우 {#empty-list}

**아직 주문이 없습니다**는 이 매장에서 본인이 처리한 판매가 아직 없다는 뜻입니다. 판매를 처리하면 여기에 표시됩니다.

**이 필터와 일치하는 주문이 없습니다**는 검색어나 필터로 인해 모든 주문이 숨겨졌다는 뜻입니다. **필터 지우기**를 눌러 검색어를 지우고 필터를 이 매장에서 본인이 처리한 판매 내역으로 되돌리세요.

<details>

## 확인이 필요한 판매 {#needs-attention}

계산대에서 결제를 받았지만 매장에서 이를 거부하는 경우가 있습니다. 예를 들어 이미 온라인에서 결제된 주문이거나 매장에서 결제 금액의 일부만 받을 수 있는 경우입니다. 이때 검색창 아래에 **판매 1건에 확인이 필요합니다**(또는 **판매 3건에 확인이 필요합니다**)라는 빨간색 알림 영역이 표시됩니다.

각 항목에는 주문, 금액, 결제 방법과 함께 “해당 결제 환불” 또는 “차액 환불” 등 필요한 조치가 표시됩니다. 알림 영역에는 가장 최근 세 건이 표시되며, 그 뒤에 “외 N건”이 표시됩니다.

1. **주문 열기**를 눌러 판매 내역을 확인하세요.
2. 고객과 정산하세요. 결제 금액이나 차액을 환불하거나 잔액을 받으세요.
3. **처리 완료**를 눌러 항목을 지우세요.

이 알림 영역은 거부된 결제를 자동으로 재시도하지 않습니다. 본인이 처리한 판매만 표시되므로 다른 캐셔가 같은 기기에 로그인해도 본인의 항목은 보이지 않습니다.

## 주문 상태 {#order-statuses}

대부분의 POS 주문은 계산대에서 결제를 받으므로 바로 **완료** 상태가 됩니다. 장바구니에 열린 상태로 두고 **주문 동기화**(**결제** 옆의 **⋮**)로 매장에 저장한 주문은 **POS - 열림** 상태이며, 나중에 다시 열어 판매를 완료할 수 있습니다. [열린 주문](../pos/cart/open-orders.mdx)을 참조하세요.

POS 주문은 기본 WooCommerce 주문 상태와 WCPOS 고유의 두 가지 상태를 사용합니다.

<details>
<summary>모든 주문 상태</summary>

| 상태 | 설명 |
|--------|-------------|
| **POS - 열림** | POS에서 저장했지만 아직 결제되지 않은 주문입니다(임시 저장하거나 보류한 주문). |
| **POS - 부분 결제** | 합계의 일부만 결제되었으며 나머지는 아직 미결제 상태입니다. |
| **결제 대기 중** | 결제를 기다리는 중입니다. |
| **보류 중** | 결제 확인 등의 조치를 기다리는 중입니다. |
| **처리 중** | 결제가 완료되었으며 주문을 이행하는 중입니다. |
| **완료** | 주문 이행이 완료되었습니다. |
| **실패** | 결제에 실패했습니다. |
| **취소됨** | 주문이 취소되었습니다. |
| **환불됨** | 주문이 전액 환불되었습니다. |

</details>

## 문제가 발생한 경우 {#goes-wrong}

**원하는 판매 내역이 목록에 없습니다.** 목록에는 처음에 이 매장에서 본인이 처리한 판매 내역이 표시됩니다. 모든 캐셔의 판매 내역을 보려면 **캐셔** 필터를 제거하거나 **매장** 필터를 변경하세요.

**“이 필터와 일치하는 주문이 없습니다”.** **필터 지우기**를 누른 다음 다시 검색하세요.

**다른 계산대의 새 판매 내역이 없습니다.** 하단의 동기화 버튼을 누르세요. 그래도 없으면 버튼을 길게 누르고 **지우고 새로고침**을 선택하세요.

**“이 주문을 새로고침할 수 없습니다”.** 매장에 연결할 수 없습니다. 기기의 사본은 그대로 유지됩니다. 연결된 후 다시 시도하세요.

**“서버에서 주문을 삭제할 권한이 없습니다”.** 현재 WordPress 역할로는 주문을 삭제할 수 없습니다. 관리자에게 요청하세요.

**결제가 “아직 진행 중”이어서 다시 열기가 거부됩니다.** 먼저 해당 결제를 취소한 다음 다시 여세요. [결제 취소](../pos/checkout/cancelling-a-payment.mdx)를 참조하세요.
