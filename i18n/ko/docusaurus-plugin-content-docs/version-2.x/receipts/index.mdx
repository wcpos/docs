**WP 관리자:** 템플릿은 `WP Admin → POS → Templates`에서 선택합니다.

WCPOS에서 인쇄하는 모든 영수증은 판매 데이터로 채워진 템플릿입니다. **WP Admin → POS → 템플릿**에서 템플릿을 선택하면 캐셔가 다른 것을 선택하지 않는 한 계산대는 첫 번째 활성 템플릿을 인쇄합니다. 같은 화면에 청구서, 선물 영수증, 포장 명세서 및 주방 주문서도 있습니다.

필요한 내용으로 바로 이동하세요:

- **계산대에서:** [영수증 인쇄](#at-the-till), [이메일 전송](#email) 또는 [나중에 다시 인쇄](#reprint).
- **매장 소유자:** [매장 영수증 선택](#how-it-works) 및 [프린터로 보내기](#template-printers).

## 계산대에서 {#at-the-till}

판매 결제가 완료되면 결제 완료 화면에 영수증이 표시됩니다. 인쇄하려면 다음 단계를 따르세요:

1. 미리보기(5)에서 영수증을 확인하세요.
2. **프린터**(4)를 확인하세요. **자동**은 템플릿에 맞는 프린터를 선택합니다.
3. **영수증 인쇄**(6)를 누르세요. 처음 인쇄한 후에는 **다시 인쇄**로 표시됩니다.

1. **거스름돈**: 돌려줄 금액입니다.
2. **결제 완료**: 결제 금액과 방법입니다.
3. **템플릿**: 이번 판매에 사용할 영수증입니다. [한 번의 판매에 다른 영수증 사용](#one-sale)을 참조하세요.
4. **프린터**: 인쇄할 위치입니다. [각 템플릿을 프린터로 보내기](#template-printers)를 참조하세요.
5. **미리보기**: 실제 인쇄될 영수증입니다.
6. **영수증 인쇄**: 표시된 영수증을 해당 프린터로 인쇄합니다.
7. **영수증 이메일 전송**: 고객에게 이메일을 보냅니다. [영수증 이메일 전송](#email)을 참조하세요.
8. **새 판매**: 다음 고객을 위한 빈 장바구니를 엽니다.

두 버튼 사이의 **PDF 다운로드**는 영수증을 파일로 저장합니다. 연결이 필요합니다.

### 영수증 이메일 전송 {#email}

1. **영수증 이메일 전송**을 누르세요.
2. **이메일 주소**를 확인하세요. 처음에는 주문의 청구 이메일 주소가 입력됩니다. 새 주소를 주문에 저장하려면 **청구 주소에 이메일 저장**을 켜세요.
3. **보내기**를 누르세요.

고객은 미리보기에 표시된 템플릿이 아닌 해당 주문의 WooCommerce 청구서 이메일을 받습니다. 오프라인 상태에서는 버튼이 **온라인 상태일 때 보내기**로 표시되며, 기기가 매장에 다시 연결되면 이메일이 전송됩니다.

### 영수증 다시 인쇄 {#reprint}

[WCPOS Pro](../getting-started/pro-license.mdx)를 사용하면 나중에 다시 인쇄할 수 있습니다:

1. 사이드 메뉴에서 **주문**을 여세요.
2. 주문을 찾아 영수증 버튼을 누르세요.
3. 열린 영수증에서 인쇄하세요.

Pro가 없으면 **새 판매**를 누르기 전에 결제 완료 화면에서 영수증을 인쇄하거나 이메일로 보내세요.

자세한 내용은 [영수증 다시 인쇄](./at-checkout.mdx#reprinting-receipts)를 참조하세요.

### 한 번의 판매에 다른 영수증 사용 {#one-sale}

캐셔는 결제 완료 화면의 **템플릿**에서 다른 활성 템플릿을 선택할 수 있습니다. 선택은 해당 판매에만 적용됩니다. 활성 템플릿이 하나면 **템플릿**에는 이름만 표시되고 선택할 다른 항목이 없습니다.

## 영수증 선택 {#how-it-works}

:::tip 영수증만 바꾸고 싶으신가요?
**[영수증 맞춤 설정](./customise.mdx)** 부터 살펴보세요. 다른 기본 제공 템플릿 선택, AI에 수정 요청, 직접 편집이라는 가장 간단한 세 가지 방법을 안내합니다.
:::

매장 소유자가 WP Admin에서 한 번 설정하면 됩니다:

1. WP Admin에서 **POS → 템플릿**으로 이동하세요. **영수증** 탭의 위쪽에는 **내 템플릿**, 아래쪽에는 **템플릿 갤러리**가 표시됩니다.
2. 갤러리에서 **템플릿 검색...**, **카테고리**, **형식**, **방향**으로 카드를 좁혀보세요. **미리보기**는 **샘플 데이터**나 실제 주문 중 하나로 채운 템플릿을 보여줍니다.
3. **템플릿 사용**을 클릭하세요. 활성화된 나만의 복사본이 **내 템플릿** 목록 맨 아래에 추가됩니다.
4. 이를 **내 템플릿** 맨 위로 드래그하세요. 계산대는 첫 번째 활성 템플릿을 기본값으로 사용합니다. 내 템플릿을 기본 제공 **레거시 PHP 템플릿** 위로 옮기거나 해당 템플릿의 **활성** 스위치를 끄기 전까지는 레거시 PHP 템플릿이 먼저 사용됩니다.

템플릿의 문구나 모양을 바꾸려면 템플릿 편집기에서 복사본을 여세요. 편집하는 동안 실시간 미리보기가 표시됩니다. [영수증 맞춤 설정](./customise.mdx)을 참조하세요.

## 각 템플릿을 프린터로 보내기 {#template-printers}

앱의 **설정 → 인쇄**에는 계산대에서 인쇄할 수 있는 템플릿이 **영수증 템플릿** 아래에 나열되며, 그 아래에는 **보고서 템플릿**과 **마감 템플릿**이 있습니다. 각 행에는 다음이 표시됩니다:

- **템플릿**: 기본 제공 **레거시 PHP 템플릿** 등이 표시됩니다.
- **유형**: 인쇄 대화 상자용은 **HTML**, 감열식 템플릿은 **감열식 80mm**처럼 용지가 표시됩니다.
- **프린터**: **자동**은 템플릿의 유형과 용지 폭에 맞는 프린터를 선택하고, 맞는 프린터가 없으면 **인쇄 대화 상자**를 엽니다. 이 템플릿을 항상 같은 프린터로 보내려면 프린터를 지정하세요.

프린터 추가 방법은 [프린터](../hardware/printers/index.mdx#adding-a-printer)에서 설명합니다.

- **맨 아래**(감사 문구): Pro에서는 각 매장의 **영수증 메시지**입니다. 그 외에는 기본 감사 문구가 인쇄됩니다.

가격을 표시하는 기본 제공 템플릿은 상품이 할인 판매 중이거나 계산대에서 가격이 변경된 경우 정상가와 절약 금액을 인쇄합니다([장바구니 할인](../pos/cart/discounts.mdx#showing-the-original-price-and-saving-on-receipts)). 내 템플릿에 이를 추가하려면 [정상가 및 절약 금액 표시](./receipt-data.mdx#displaying-regular-price-and-savings)를 참조하세요.

## Pro: 매장별 영수증 {#pro-features}

[WCPOS Pro](../getting-started/pro-license.mdx)를 사용하면 각 매장에서 자체 영수증을 인쇄할 수 있습니다. **POS → 매장**에서 매장을 여세요:

- **영수증**: 매장의 **영수증 템플릿** 목록은 **맞춤 설정**을 클릭하기 전까지 **사이트와 동일**로 표시됩니다. 그런 다음 캐셔가 해당 매장에서 인쇄할 수 있는 템플릿을 선택하세요. 처음 선택된 템플릿이 매장의 기본값이며 드래그하여 순서를 바꿀 수 있습니다. **사이트 템플릿 사용**을 누르면 이전 설정으로 돌아갑니다. 같은 페이지에 매장의 **영수증 메시지**도 있습니다.
- **세부 정보**: **사이트 로고 사용** 또는 **로고 업로드**가 있는 **로고 및 주소**, 그리고 매장의 **연락처** 정보입니다.

[매장 페이지 작성](../stores/setup.mdx#store-pages)과 [매장별 템플릿](./customise.mdx#per-store-assignments)을 참조하세요.

## 계산대 밖에서의 영수증 {#beyond-the-till}

- **이메일**: 계산대의 **영수증 이메일 전송**은 WCPOS 템플릿이 아닌 WooCommerce 자체 고객 청구서 이메일을 보냅니다. **WooCommerce → 설정 → 이메일**에서 모양을 변경하세요.
- **PDF 다운로드**: 서버가 PDF를 생성하므로 연결이 필요합니다.
- **온라인 고객**: **고객의 영수증 다운로드 허용**을 켜면 내 계정의 주문에 **영수증** 버튼이 추가됩니다. 직접 켜기 전까지는 비활성화되어 있으며, **고객용 영수증 템플릿**에서 고객에게 제공할 템플릿을 선택합니다. [온라인 상점 영수증](./storefront.mdx)을 참조하세요.

## 문제 해결 {#goes-wrong}

**새 템플릿으로 인쇄되지 않습니다.** 계산대는 **내 템플릿**의 첫 번째 활성 템플릿을 사용합니다. 내 템플릿을 맨 위로 드래그하거나 그 위의 템플릿을 끄세요. 한 번의 판매에만 사용하려면 캐셔가 결제 완료 화면의 **템플릿**에서 선택할 수 있습니다.

**결제 완료 화면의 템플릿에 이름만 있고 목록이 없습니다.** 활성 영수증 템플릿이 하나뿐입니다. 캐셔가 선택할 수 있도록 **내 템플릿**에서 다른 템플릿을 켜세요.

**오프라인 상태에서 템플릿을 선택할 수 없습니다.** **레거시 PHP 템플릿**과 WP Overnight 템플릿은 서버에서 생성됩니다. 계산대의 연결이 자주 끊기면 HTML 또는 감열식 템플릿을 기본값으로 설정하세요.

**로고가 없습니다.** Pro가 없으면 영수증에 WordPress 사이트 로고를 사용하므로 테마에서 로고를 설정하세요. Pro에서는 매장의 **세부 정보**를 열고 **사이트 로고 사용** 또는 **로고 업로드**를 선택하세요. 브라우저 탭에서 인쇄할 때만 로고가 없다면 [브라우저에서 로고가 표시되지 않음](../hardware/printers/logo-missing-browser.mdx)을 참조하세요.

**아무것도 인쇄되지 않거나 잘못된 프린터로 인쇄됩니다.** **설정 → 인쇄**에서 템플릿의 프린터를 확인한 뒤 [아무것도 인쇄되지 않을 때](../hardware/printers/index.mdx#when-nothing-prints)를 참조하세요.

## 템플릿 갤러리 {#template-gallery}

갤러리에는 그대로 사용하거나 맞춤 설정할 수 있는 템플릿이 기본 제공됩니다. **카테고리**(영수증, 청구서, 선물 영수증, 대변 전표, 구매 주문서, 주방 주문서, 바 주문서), **형식**(**HTML (브라우저 인쇄)** 또는 **ESC/POS (감열식 프린터)**), **방향**(**왼쪽에서 오른쪽** 또는 **오른쪽에서 왼쪽**)으로 필터링하세요. 각 카드에는 **미리보기**와 **템플릿 사용**이 있습니다. **템플릿 사용**은 *내 템플릿*에 편집 가능한 복사본을 만들고 갤러리 원본은 그대로 유지합니다.

복사한 템플릿보다 갤러리 버전이 더 최신이면 카드에 **업데이트 가능**이 표시됩니다. **새 버전 설치**는 새 버전을 별도의 복사본으로 추가하므로 기존 수정 사항은 유지됩니다.

### 타사 문서 템플릿 {#third-party-document-templates}

WP Overnight의 **PDF Invoices & Packing Slips for WooCommerce**가 활성화되어 있으면 해당 플러그인의 청구서와 포장 명세서가 영수증 템플릿에 추가됩니다. 인쇄하려면 연결이 필요합니다.

<Accordion>
  <AccordionItem question="WP Overnight 템플릿의 작동 방식">

WCPOS는 **청구서 (WP Overnight)** 와 **포장 명세서 (WP Overnight)** 를 활성화된 상태로 영수증 템플릿에 추가합니다. 이 템플릿은 주문을 WP Overnight의 문서 API에 전달하므로 해당 플러그인에서 설정한 청구서 및 포장 명세서 번호 체계, 레이아웃, 브랜드 요소, 법적·세금 필드 및 템플릿 변경 사항을 유지합니다.

WP Overnight 플러그인이 활성화되어 있을 때만 표시되며 서버에서 렌더링됩니다. 오프라인에서 인쇄해야 할 때는 기본 제공 HTML 또는 감열식 템플릿을 사용하세요. [WP Overnight 템플릿](./customise.mdx#wp-overnight-invoice-and-packing-slip-templates)을 참조하세요.

  </AccordionItem>
</Accordion>

### 설정에 따른 세금 표시 {#adaptive-tax-display}

대부분의 기본 제공 템플릿은 WooCommerce 세금 표시 설정에 맞춰 세금 포함 또는 제외 가격을 인쇄합니다.

<Accordion>
  <AccordionItem question="설정을 따르는 템플릿과 적용 방식">

표준, 표준 RTL, 미니멀/모던, 좁은 영수증, 청구서, 견적서 및 간단한 감열식 템플릿은 **WooCommerce 세금 표시 설정을 따릅니다**:

- **세금 포함 가격을 표시하는 매장**(EU/UK/AU)은 세금 포함 가격과 ‘세금 포함’ 행을 인쇄합니다.
- **세금 제외 가격을 표시하는 매장**(US/CA)은 세금 제외 가격을 인쇄하고 **총 세금**이라는 별도 행에 세금을 추가합니다.
- 최종 합계에는 항상 실제 청구된 세금 포함 금액이 표시됩니다.

**상세** 템플릿은 정식 세금 청구서입니다. 상품 행에는 항상 세금 제외 가격이 표시되고 뒤이어 세율별 내역이 나옵니다. 세금 제목만 설정을 따릅니다.

  </AccordionItem>
</Accordion>

## 템플릿 엔진 {#template-engines}

각 템플릿은 **HTML (오프라인)**, **XML (영수증 프린터)**, **PHP (레거시)** 중 하나의 엔진을 사용합니다. HTML과 XML은 오프라인에서 인쇄할 수 있으며 PHP는 서버가 필요합니다.

<Accordion>
  <AccordionItem question="세 가지 엔진">

템플릿을 만들 때 엔진을 선택하거나, 갤러리에서 **템플릿 사용**을 클릭하면 해당 카드에 따라 엔진이 결정됩니다. **템플릿을 저장한 후에는 변경할 수 없습니다**. 엔진을 바꾸려면 새 템플릿을 만드세요.

<FeatureGrid>
  <FeatureCard icon="code" title="HTML (오프라인), 권장">
    로직이 없는 HTML로, <code>{"{{variable}}"}</code> 자리 표시자를 사용합니다. 기기에서 렌더링되므로 **오프라인에서도 인쇄할 수 있습니다**. 인쇄 대화 상자용입니다.
  </FeatureCard>
  <FeatureCard icon="print" title="XML (영수증 프린터)">
    화면 미리보기와 감열식 영수증 프린터용 **ESC/POS 명령**을 모두 제공하는 XML입니다. 하나의 템플릿으로 두 가지 출력을 제공합니다. Epson, Star 및 기타 감열식 프린터용입니다.
  </FeatureCard>
  <FeatureCard icon="terminal" title="PHP (레거시)">
    WooCommerce 함수를 사용하는 서버 측 PHP입니다. 기존 <code>yourtheme/woocommerce-pos/receipt.php</code> 재정의와 기본 제공 **레거시 PHP 템플릿**을 위해 유지됩니다. 렌더링하려면 서버 연결이 필요하며 영수증만 지원합니다.
  </FeatureCard>
</FeatureGrid>

  </AccordionItem>
</Accordion>
