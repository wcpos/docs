# 영수증과 결제 완료 화면 {#receipts-and-the-paid-screen}

마지막 결제를 받으면 결제 열이 결제 완료 화면으로 바뀝니다. 돌려줄 금액이 표시되며 영수증을 인쇄하거나 이메일로 보내거나 저장할 수 있습니다. **새 판매**를 누르면 다음 고객을 위해 계산대가 비워집니다. 나중에 주문 화면, 환불 내역 또는 장바구니에서 영수증을 다시 열 수 있습니다.

바로 가기: [영수증 인쇄](#print-receipt) · [영수증 이메일 전송](#email-receipt) · [다음 판매 시작](#new-sale)

## 결제 완료 화면 읽기 {#paid}

<JourneyShot manifest={checkoutManifest} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="현금 판매 후의 결제 완료 화면: 돌려줄 거스름돈, 결제 금액과 받은 금액, 템플릿과 프린터, 영수증 미리보기, 인쇄 및 이메일 전송과 새 판매 시작 버튼">

1. **거스름돈** — 돌려줄 금액입니다. 돌려줄 금액이 없으면 **결제 완료**와 금액이 표시됩니다.
2. **결제 수단** — 금액과 결제 방법입니다.
3. **템플릿** — 이 판매에 사용할 영수증입니다. 여기서 선택한 내용은 현재 판매에만 적용됩니다. [영수증 맞춤 설정](./customise.mdx)을 확인하세요.
4. **프린터** — 인쇄할 곳입니다. [영수증 인쇄](#print-receipt)를 확인하세요.
5. **미리보기** — 인쇄될 영수증의 모습입니다. **−** 와 **+** 로 축소하거나 확대할 수 있습니다. 크기를 선택하기 전에는 열 너비에 맞춰 표시됩니다.
6. **영수증 인쇄** — 위에 표시된 프린터로 인쇄합니다.
7. **영수증 이메일 전송** — 고객에게 보냅니다. [영수증 이메일 전송](#email-receipt)을 확인하세요.
8. **새 판매** — 다음 고객을 위한 빈 장바구니를 엽니다. [다음 판매 시작](#new-sale)을 확인하세요.

</JourneyShot>

**영수증 이메일 전송** 옆의 **PDF 다운로드**는 영수증을 파일로 저장합니다. 인터넷 연결이 필요합니다.

<details>
<summary>현금, 분할 결제, 매장 확인 대기 메시지</summary>

제목 아래의 내용은 판매에 따라 달라집니다.

- **결제 금액 $X · 받은 현금 $Y**: 거스름돈이 있는 현금 판매입니다.
- **현금**, **카드** 등의 결제 수단 이름: 그 밖의 단일 결제입니다.
- 사용한 각 결제 수단이 한 번씩 **+** 로 연결되어 표시되고 결제 횟수가 뒤따르는 경우: 여러 번에 나눠 결제한 판매입니다. 그중 현금 결제에 거스름돈이 있었다면 위의 현금 안내가 대신 표시되며, 이 경우에도 결제 횟수가 뒤에 나옵니다. [분할 결제](../pos/checkout/split-payments.mdx)를 확인하세요.
- 앞에 **매장 확인 대기 ·** 표시: 매장이 아직 판매를 확인하지 않은 상태이며, 주로 계산대가 오프라인일 때 발생합니다. 녹색 체크 표시가 황색 대기 표시로 바뀌고 영수증에 **매장 확인 대기 · 아직 확인되지 않음**이 표시됩니다. 판매는 계산대에 안전하게 저장되어 있으며 연결이 복구되면 매장으로 전송됩니다. [오프라인 모드](../getting-started/offline.mdx#offline-writes)를 확인하세요.

</details>

## 영수증 인쇄 {#print-receipt}

**영수증 인쇄**를 누르세요. 결제 완료 화면에 표시된 프린터로 영수증이 전송됩니다. **자동 — 인쇄 대화상자**는 이 계산대에 영수증 프린터가 지정되지 않아 브라우저의 인쇄 창이 대신 열린다는 뜻입니다. 해당 창에서 프린터를 선택하고 인쇄를 확인하세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-26, 0], [272, 0], [251, 0], [146, 0]]} maxWidth={569} alt="인쇄 후 결제 완료 화면 상단: 닫기 버튼, 돌려줄 거스름돈, 결제 금액과 받은 금액, 영수증이 인쇄된 곳을 나타내는 행">

1. **✕** — **새 판매**와 마찬가지로 판매를 마칩니다.
2. **거스름돈** — 돌려줄 금액입니다.
3. **결제 수단** — 금액과 결제 방법입니다.
4. **인쇄 대상** — 영수증을 보낸 프린터 또는 인쇄 창입니다. 실제로 출력되었는지 확인하세요. **영수증 인쇄**는 한 부 더 인쇄할 수 있도록 **다시 인쇄**로 바뀝니다.

</JourneyShot>

다른 곳에서 인쇄하려면 먼저 **프린터**에서 다른 프린터를 선택하세요. 영수증 프린터를 추가하려면 [프린터](../hardware/printers/index.mdx#adding-a-printer)를 확인하세요.

<details>
<summary>인쇄에 실패하거나 취소한 경우</summary>

인쇄가 진행되지 않으면 오류 코드가 포함된 메시지가 표시됩니다.

- [PRINT101](../error-codes/PRINT101.mdx): 자동 인쇄가 시작되지 않았습니다.
- [PRINT201](../error-codes/PRINT201.mdx): 인쇄 작업이 실패했거나 계산대가 완료 여부를 확인하지 못했습니다.
- [PRINT301](../error-codes/PRINT301.mdx): 계산대가 프린터에 연결하지 못했습니다.

인쇄하지 않고 브라우저 인쇄 창을 닫는 것은 오류가 아닙니다. 인쇄 완료로 표시되지 않으며 **영수증 인쇄**를 다시 누를 수 있습니다.

</details>

## 영수증 이메일 전송 {#email-receipt}

**영수증 이메일 전송**을 누르세요. **이메일 주소**에 고객 주소를 입력하거나 주문의 청구 이메일에서 자동 입력된 주소를 확인하세요. 주소를 주문에 저장하려면 **청구지 주소에 이메일 저장**을 켜세요.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[54, -22]]} maxWidth={400} alt="영수증 이메일 전송 대화상자: 이메일 주소 필드, 청구지 주소에 이메일 저장 스위치, 취소 및 보내기 버튼">

1. **보내기** — 영수증을 전송합니다. 전송되거나 대기열에 추가되면 대화상자가 닫힙니다.

</JourneyShot>

매장의 자체 메일 설정으로 이메일이 전송됩니다. **이메일 전송 완료**가 표시됩니다. 매장에서 거부하면 **서버에서 이메일을 보내지 않았습니다.** 같은 메시지가 표시되고 대화상자가 열린 상태로 유지되므로, 주소를 확인하고 다시 시도할 수 있습니다.

계산대가 매장에 연결할 수 없으면 버튼에 **온라인 상태가 되면 보내기**가 표시됩니다. 영수증은 대기열에 추가되며 연결이 복구되면 자동으로 전송됩니다. 전송 도중 연결이 끊겨도 같은 방식으로 대기열에 추가됩니다. 따라서 계산대가 오프라인이어도 결제 완료된 판매의 영수증을 이메일로 보낼 수 있습니다.

## 다음 판매 시작 {#new-sale}

**새 판매**를 눌러 다음 고객을 위해 장바구니를 비우세요.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[111, -22], [118, -22], [93, -22], [104, -24]]} maxWidth={569} alt="인쇄 후 결제 완료 화면 하단의 버튼: 영수증 이메일 전송, PDF 다운로드, 다시 인쇄, 새 판매">

1. **영수증 이메일 전송** — 고객에게 보냅니다.
2. **PDF 다운로드** — 파일로 저장합니다.
3. **다시 인쇄** — 한 부 더 인쇄합니다.
4. **새 판매** — 다음 고객을 위해 장바구니를 비웁니다.

</JourneyShot>

넓은 화면에서는 오른쪽의 색이 채워진 버튼이 **새 판매**입니다. 휴대전화에서는 결제 완료 화면이 전체 화면을 채우며, **새 판매**가 첫 번째에 전체 너비 버튼으로 표시됩니다.

<details>
<summary>버튼에 영수증 인쇄 · 새 판매가 표시되는 경우</summary>

[결제 후 영수증 자동 인쇄](#automatic-receipt-options)가 켜져 있으면 영수증이 자동으로 인쇄되고 버튼에 **영수증 인쇄 · 새 판매**가 표시됩니다. 인쇄가 시작될 때까지 버튼은 처리 중 상태를 유지합니다. 그 후 버튼을 누르면 다음 판매가 시작됩니다. 추가로 인쇄되지는 않습니다.

</details>

## 영수증 다시 열기 {#reprinting-receipts}

나중에 다음 위치에서 영수증을 다시 열 수 있습니다.

- **주문에서**(WCPOS Pro): 주문 행의 영수증 버튼 또는 열려 있는 주문 하단의 **영수증**을 누르세요. [주문](../orders/index.mdx#receipt-reprinting)을 확인하세요.
- **환불 내역에서**: 열려 있는 주문의 각 환불에는 별도의 **영수증** 버튼이 있습니다. 해당 환불만 담긴 **환불 영수증**을 엽니다.
- **결제 전 미리보기 또는 인쇄**: 장바구니에서 **결제** 옆의 **⋮** 를 누른 다음 **인쇄**를 누르세요. 장바구니에 있는 판매의 결제 전 영수증이 표시됩니다.

**영수증** 창에는 결제 완료 화면과 동일한 **템플릿**, **프린터** 선택 기능과 확대·축소 기능이 있습니다. 버튼도 같은 방식으로 작동하며 **닫기**를 누르면 창이 닫힙니다.

### 미리보기를 사용할 수 없는 경우 {#preview-unavailable}

<details>
<summary>주문을 동기화하여 미리보기 확인하기</summary>

일부 템플릿은 아직 매장에 저장되지 않은 주문을 표시할 수 없습니다. 장바구니에 남아 있는 판매에서 발생합니다. **주문 동기화**를 누르면 주문을 전송하는 동안 선택 항목 위에 **서버와 동기화 중...** 이 표시됩니다. 매장에 저장되면 **주문 동기화**가 사라지고 미리보기가 표시되며 **영수증 이메일 전송**과 **PDF 다운로드**를 사용할 수 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[235, 42], [94, -22], [59, -22], [111, -22], [118, -22], [133, -22]]} maxWidth={560} alt="아직 매장에 저장되지 않은 주문의 영수증 창 하단: 미리보기 메시지, 주문 동기화, 닫기, 영수증 이메일 전송, PDF 다운로드, 영수증 인쇄 버튼. 이메일 전송과 다운로드는 비활성화되어 있습니다">

1. **미리보기 사용 불가** — 이 템플릿에서는 아직 주문을 표시할 수 없습니다. 다른 템플릿을 선택하거나 주문을 동기화하세요.
2. **주문 동기화** — 주문을 매장으로 전송합니다. 주문이 매장에 저장되지 않았을 때만 표시됩니다.
3. **닫기** — 창을 닫습니다.
4. **영수증 이메일 전송** — 주문이 매장에 저장될 때까지 비활성화됩니다.
5. **PDF 다운로드** — 주문이 매장에 저장될 때까지 비활성화됩니다.
6. **영수증 인쇄** — 미리보기가 없어도 계속 사용할 수 있습니다.

</JourneyShot>

아직 매장에 저장되지 않은 주문의 영수증에는 **매장에 저장되지 않음 · 주문 번호 없음**이 표시됩니다.

</details>

## 자동 인쇄 또는 결제 완료 화면 건너뛰기 {#automatic-receipt-options}

장바구니 표시 설정의 두 스위치로 판매 후 동작을 정합니다. 장바구니 위의 슬라이더 버튼으로 설정을 여세요. [장바구니](../pos/cart/index.mdx#display-settings)를 확인하세요.

- **결제 후 영수증 자동 표시**(기본값: 켜짐): 결제 완료 화면을 표시합니다. 끄면 주문 번호와 함께 **주문 결제 완료** 메시지가 표시되고, 장바구니는 다음 판매를 할 수 있는 상태가 됩니다.
- **결제 후 영수증 자동 인쇄**(기본값: 꺼짐): 각 판매 후 결제 완료 화면에 표시될 프린터로 영수증을 자동 인쇄합니다. 결제 완료 화면을 꺼도 작동합니다. 영수증 프린터가 없으면 판매할 때마다 인쇄 창이 열립니다.

이 스위치는 기기별로 설정됩니다. 클라우드 프린터에는 자체 자동 인쇄 규칙이 있습니다. [클라우드 인쇄](./cloud-printing.mdx#auto-print)를 확인하세요.

## 영수증에 표시되는 내용 {#receipt-contents}

템플릿에 따라 영수증에 매장 이름, 주소, 로고, 주문 번호와 날짜, 상품, 합계, 결제 내역, 고객 정보가 표시됩니다. 변경하려면 [영수증 맞춤 설정](./customise.mdx)을 확인하세요. 템플릿에서 사용할 수 있는 모든 필드는 [영수증 데이터](./receipt-data.mdx)를 확인하세요.

## 문제가 발생한 경우 {#goes-wrong}

**아무것도 인쇄되지 않음.** **프린터** 행을 확인한 다음 [아무것도 인쇄되지 않을 때](../hardware/printers/index.mdx#when-nothing-prints)를 확인하세요.

**영수증 이메일 전송 또는 PDF 다운로드가 비활성화됨.** 주문이 매장에 저장되지 않았고 결제도 완료되지 않은 상태입니다. 장바구니에 남아 있는 판매에서 발생합니다. **영수증** 창에서 **주문 동기화**를 누르세요. **PDF 다운로드**를 사용하려면 계산대가 온라인 상태여야 합니다.

**영수증에 매장 확인 대기가 표시됨.** 판매는 계산대에 저장되어 있지만 매장이 아직 확인하지 않은 상태입니다. 연결이 복구되면 처리됩니다. 매장에 저장된 영수증을 인쇄하는 클라우드 프린터도 이를 기다리므로, 매장에 판매가 전송된 후 다시 인쇄하세요.
