**WP 관리자:** `WP Admin → POS → Settings → General`에서 온라인 주문의 **영수증** 버튼을 켜세요.

:::note 이 페이지는 웹사이트 운영자를 위한 안내입니다
[WCPOS Pro](../getting-started/pro-license.mdx)를 사용하면 온라인 주문을 포함한 모든 주문의 영수증을 계산대에서 인쇄하거나 이메일로 보낼 수 있습니다. **주문** 페이지의 [영수증 재인쇄](../orders/index.mdx#receipt-reprinting)를 참고하세요.
:::

:::tip 고객이 온라인 주문 영수증을 요청하는 경우
웹사이트에 설정이 완료되어 있으면 **내 계정 → 주문**의 **영수증** 버튼을 이용하면 됩니다. 매장에서 주문 확인 페이지에 영수증 링크를 추가했다면 해당 링크를 이용할 수도 있습니다.
:::

WCPOS 영수증 템플릿은 웹사이트에서도 사용할 수 있습니다. 온라인으로 구매한 고객은 **내 계정**이나 주문 확인 페이지에 추가한 링크에서 영수증을 PDF로 다운로드할 수 있습니다.

## 영수증 버튼 켜기 {#my-account}

:::warning 먼저 영수증 템플릿을 활성화하세요
시작하기 전에 **POS → 템플릿**에서 템플릿 하나를 활성화하세요. 활성화된 템플릿이 없으면 설정을 켜도 고객에게 **영수증** 버튼이 표시되지 않습니다. [영수증 맞춤 설정](./customise.mdx#option-1--pick-a-different-template)을 참고하세요.
:::

버튼은 직접 켜기 전까지 꺼져 있습니다. PDF는 영수증 템플릿을 바탕으로 생성됩니다.

1. WP Admin에서 **POS → 설정 → 일반**으로 이동하세요.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="메뉴에서 POS, 설정이 선택되고 설정 메뉴의 일반이 열린 WP Admin 화면. 매장, 계산대 및 상품 섹션의 시작 부분이 표시됩니다">

1. **POS → 설정** — POS 설정을 여는 WP Admin 메뉴 항목입니다.
2. **일반** — 처음 표시되는 설정 화면으로, 이동하면 이미 열려 있습니다.

</JourneyShot>

2. 아래로 스크롤하여 **고객** 섹션에서 **고객의 영수증 다운로드 허용**을 켜세요. 변경하는 즉시 저장됩니다.

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="일반의 고객 섹션: 고객 이메일에서 사용자명 자동 생성, 비회원으로 설정된 기본 POS 고객, 아직 꺼져 있는 고객의 영수증 다운로드 허용 옵션">

1. **고객** — 영수증 설정이 있는 섹션입니다.
2. **고객의 영수증 다운로드 허용** — 직접 켜기 전까지 꺼져 있습니다.

</JourneyShot>

3. 그 아래에 **고객용 영수증 템플릿**이 표시됩니다. **활성 영수증 템플릿 사용**으로 두거나 템플릿을 선택하세요. [고객용 템플릿 선택](#template-choice)을 참고하세요.

이제 로그인한 고객은 **내 계정 → 주문**의 주문 옆에서 **영수증** 버튼을 볼 수 있습니다. 이 버튼을 누르면 `receipt-1234.pdf`처럼 주문에 따라 이름이 지정된 PDF가 다운로드됩니다.

버튼은 결제된 주문에만 표시됩니다:

| 주문 상태 | 영수증 버튼 |
|---|---|
| **처리중** | 표시됨 |
| **완료됨** | 표시됨 |
| **환불됨** | 표시됨 |
| **결제 대기중**, **보류중**, **취소됨**, **실패함** 등 그 밖의 상태 | 표시 안 됨 |

개발자는 [버튼이 표시되는 주문 상태를 변경](#developers)할 수 있습니다.

## 고객용 템플릿 선택 {#template-choice}

**고객용 영수증 템플릿**은 다운로드에 사용할 템플릿을 지정합니다.

- **활성 영수증 템플릿 사용** (기본값): 고객에게 **POS → 템플릿**에서 활성화한 영수증 템플릿이 제공됩니다. 여기서 템플릿을 변경하면 고객이 다운로드하는 영수증에도 적용됩니다.
- **이름이 지정된 템플릿**: 캐셔가 계산대에서 무엇을 선택하든 고객에게는 항상 이 템플릿이 제공됩니다. 여러 영수증 템플릿이 활성화되어 있거나 온라인 주문에 별도의 디자인을 적용하려는 경우에 사용하세요.

폭이 좁은 감열지 형식의 템플릿은 폭이 좁은 PDF를 만듭니다. 온라인 주문에는 보통 전체 페이지 형식이 읽기 좋습니다. 갤러리의 **청구서** 템플릿은 A4 및 Letter 용지용으로 제작되었습니다. 추가 방법은 [영수증 맞춤 설정](./customise.mdx#option-1--pick-a-different-template)을 참고하세요.

PDF에는 계산대 영수증과 동일한 [영수증 데이터](./receipt-data.mdx)가 입력되므로 로고, 매장 정보, 세금 설정이 그대로 적용됩니다.

선택한 템플릿이 나중에 삭제되거나 공개 해제되면 드롭다운에 **사용할 수 없는 템플릿**이 표시되고, 고객에게는 활성 영수증 템플릿이 대신 제공됩니다. 다른 템플릿을 선택하세요.

## 주문 확인 페이지에 영수증 링크 추가 {#shortcode}

결제 후 표시되는 ‘감사합니다’ 페이지에 **영수증 다운로드 (PDF)** 링크를 제공하세요. 계정 없이 결제한 비회원은 이 링크로 영수증을 받을 수 있습니다.

WP Admin에 **모양 → 편집기 → 템플릿 → 주문 확인**이 있으면 ‘감사합니다’ 페이지에 직접 링크를 추가하세요:

1. WP Admin에서 **모양 → 편집기 → 템플릿**으로 이동하여 **주문 확인**을 여세요.
2. 링크를 넣을 위치에 **쇼트코드** 블록을 추가하고 `[wcpos_receipt]`를 입력하세요.
3. **저장**을 누르세요.

해당 템플릿이 없거나 **내 계정**의 개별 주문 페이지에 링크를 넣으려면 개발자에게 [코드로 영수증 링크를 추가](#developers)해 달라고 요청하세요.

쇼트코드는 **고객의 영수증 다운로드 허용** 설정이 켜져 있는지와 관계없이 작동합니다. 해당 설정은 **내 계정 → 주문**의 버튼만 제어합니다.

<details>
<summary>쇼트코드 옵션과 예시</summary>

`[wcpos_receipt]`는 주문 확인 페이지와 **내 계정**의 개별 주문 페이지에서 작동합니다. 이 페이지에서는 주문을 자동으로 찾으므로 주문 번호를 입력할 필요가 없습니다. 다른 페이지에서는 `order_id`를 지정하지 않으면 아무것도 표시되지 않습니다.

| 옵션 | 기본값 | 기능 |
|---|---|---|
| `order_id` | *(페이지에서 찾음)* | 어느 페이지에서든 특정 주문으로 연결합니다. 해당 주문의 고객이 로그인한 경우에만 표시됩니다. |
| `link_text` | `Download receipt (PDF)` | 링크에 표시되는 문구입니다. |
| `format` | `pdf` | `pdf`는 PDF를 다운로드합니다. `html`은 브라우저에서 인쇄할 수 있도록 영수증을 엽니다. |
| `template` | *(활성 영수증 템플릿)* | 대신 이 템플릿을 사용합니다. |
| `class` | `wcpos-receipt-link` | 링크의 CSS 클래스입니다. |
| `id` | *(없음)* | 링크의 HTML `id`입니다. |

쇼트코드의 `template` 옵션은 **고객용 영수증 템플릿** 설정을 무시합니다. 이 옵션을 생략하면 링크는 활성 영수증 템플릿을 사용합니다.

원하는 문구를 넣은 다운로드 링크:

```text
[wcpos_receipt link_text="Download your invoice"]
```

PDF를 다운로드하는 대신 브라우저에서 영수증 열기:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

특정 템플릿 사용하기. 예를 들어 80mm 계산대 영수증 대신 A4 청구서 사용:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

템플릿 번호는 **POS → 템플릿**에서 템플릿을 편집할 때 주소 표시줄에 나타납니다(`post=123`). 공개되지 않은 템플릿은 무시되며, 링크는 활성 영수증 템플릿을 사용합니다.

</details>

## 영수증을 열 수 있는 사용자 {#security}

- **계정이 있는 고객**은 로그인한 후 **내 계정 → 주문**의 **영수증** 버튼을 사용합니다.
- 계정 없이 결제한 **비회원**은 주문 확인 페이지에 [추가한 영수증 링크](#shortcode)를 사용합니다.

:::warning 영수증 링크는 해당 고객에게만 공유하세요
영수증 링크를 가진 사람은 누구나 로그인하지 않고 해당 영수증을 열 수 있습니다. 주문 정보와 마찬가지로 주의해서 취급하세요.
:::

<details>
<summary>영수증 링크의 보호 방식</summary>

모든 영수증 링크에는 주문의 비공개 키가 포함됩니다. WooCommerce가 주문 확인 페이지에 사용하는 키와 같습니다. 올바른 키가 없으면 영수증이 열리지 않습니다. `order_id` 옵션이 있는 쇼트코드는 해당 주문의 고객이 로그인한 경우에만 링크를 표시합니다.

</details>

## 문제가 발생한 경우 {#goes-wrong}

아래 해결 방법은 대부분 WP Admin에서 수행합니다. 캐셔라면 고객에게 표시되는 메시지를 웹사이트 운영자에게 전달하세요. 그동안 [WCPOS Pro](../getting-started/pro-license.mdx)를 사용하면 계산대에서 고객의 영수증을 인쇄하거나 이메일로 보낼 수 있습니다. **주문** 페이지의 [영수증 재인쇄](../orders/index.mdx#receipt-reprinting)를 참고하세요.

**고객에게 영수증 버튼이 표시되지 않습니다.** **고객의 영수증 다운로드 허용**이 켜져 있는지, 주문 상태가 **처리중**, **완료됨** 또는 **환불됨**인지, **POS → 템플릿**에서 영수증 템플릿이 하나 이상 활성화되어 있는지 확인하세요. 버튼은 로그인한 고객의 **내 계정 → 주문**에만 표시됩니다.

**‘영수증 템플릿이 설정되지 않았습니다.’** PDF에 사용할 템플릿이 없습니다. **POS → 템플릿**에서 영수증 템플릿을 활성화하세요.

**‘이 영수증을 볼 권한이 없습니다.’** 링크가 불완전하거나 잘못 복사되었습니다. 각 링크에는 해당 주문의 비공개 키가 포함됩니다. 고객의 주문 확인 페이지 또는 **내 계정**에 있는 링크를 다시 보내세요.

**‘영수증 PDF를 생성할 수 없습니다.’** 템플릿으로 PDF를 만들지 못했습니다. **POS → 템플릿**에서 해당 템플릿을 열어 미리 보세요. [영수증 맞춤 설정](./customise.mdx)을 참고하세요.

**링크를 열면 ‘페이지를 찾을 수 없음’ 오류가 표시됩니다.** WP Admin에서 **설정 → 고유주소**로 이동하여 **일반** 이외의 옵션을 선택하세요. **일반**에서는 영수증 링크가 작동하지 않습니다.

## 개발자 안내 {#developers}

<details>
<summary>코드로 영수증 링크 추가</summary>

클래식 테마에서는 해당 페이지를 표시하는 두 WooCommerce 액션에서 링크를 출력하세요:

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

쇼트코드는 두 페이지 모두에서 주문을 찾으므로 `order_id`가 필요하지 않습니다.

</details>

<details>
<summary>영수증 버튼과 PDF 템플릿용 필터</summary>

위 설정보다 우선 적용되는 필터 세 가지가 있습니다. 주문별 또는 고객별 규칙처럼 설정만으로는 지정할 수 없는 규칙에 사용합니다:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

WCPOS 2.0 이전에는 이 필터의 이름이 `woocommerce_pos_storefront_receipt_*`였습니다. 이 이름은 여전히 작동하지만 2.0부터 사용이 권장되지 않으며, 이르면 2.2에서 제거됩니다. [훅 이름 지정](../extensions/index.mdx#hook-naming)을 참고하세요.

PDF 주소는 `/wcpos-checkout/wcpos-receipt/{order_id}`에 `?key={order_key}&format=pdf`를 붙인 형태입니다. POS가 사용하는 것과 동일하게 키로 접근을 제한하는 영수증 주소이며, `format=pdf`를 지정하면 페이지 대신 PDF를 반환합니다.

</details>
