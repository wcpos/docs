플러그인을 이전 버전으로, 주로 2.0에서 1.11로 되돌려야 할 때 이 페이지를 참고하세요. WP Admin에서 자동 업데이트를 끄고 원하는 버전을 다운로드한 다음 현재 버전 위에 업로드합니다. 이 과정에서 아무것도 삭제되지 않으므로 주문, 설정, 영수증 템플릿은 그대로 유지됩니다.

:::tip 먼저 문의하세요
[Discord](https://wcpos.com/discord) 또는 support@wcpos.com으로 어떤 문제가 발생했는지 알려주세요. 업그레이드 당일 발생하는 문제는 대부분 이전 버전으로 되돌리는 것보다 빠르게 해결할 수 있습니다.
:::

## 시작하기 전에 {#before-you-start}

- **동기화할 수 있는 모든 계산대를 동기화하세요.** 각 계산대에서 POS를 열고 저장된 판매 내역을 매장으로 전송하도록 하세요. **전송 대기 중인 변경 사항**이 0이고, 결정을 요청하는 패널이 없으며, 동기화되지 않은 미결 주문이 없을 때 시작하세요([확인 방법](#check-sync)). 1.11을 실행하는 계산대에 미전송 판매 내역이 남아 있어 이전 버전으로 되돌리는 경우, 해당 계산대는 1.11로 되돌린 후에야 전송할 수 있습니다. 먼저 이전 버전으로 되돌린 다음 동기화하세요.
- **어떤 계산대에서 앱을 사용하는지 확인하세요.** 이미 2.0으로 업데이트된 데스크톱 또는 모바일 앱은 1.11 플러그인에 연결할 수 없습니다. [AUTH331](../error-codes/AUTH331.mdx)이 표시되며 앱 스토어에서는 이전 앱을 제공하지 않습니다. 다시 업그레이드할 때까지 해당 계산대에서는 `yourdomain.com/pos`의 브라우저 POS를 사용하도록 준비하세요.
- **관리자가 로그인하도록 하세요.** 플러그인을 설치할 수 있는 WordPress 관리자 계정이 필요합니다.
- **WCPOS Pro를 사용하는 경우 WCPOS Pro만 이전 버전으로 되돌리세요.** 무료 플러그인이 포함되어 있습니다.

2.0에서 이전 버전으로 되돌리는 경우 업그레이드 페이지의 [이전 버전으로 되돌리기](./upgrading-to-2.mdx#rolling-back)도 읽어보세요.

### 계산대가 모든 데이터를 전송했는지 확인하기 {#check-sync}

각 계산대에서 [매장 상태](../support/store-health.mdx#database)를 열고 **데이터베이스** 탭을 확인하세요. 현재 로그인한 캐셔와 매장의 데이터만 집계하므로, 해당 계산대를 사용하는 각 캐셔에 대해 사용하는 모든 매장을 확인하세요:

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [140, 0], [170, 0]]} alt="태블릿의 매장 상태에서 열린 데이터베이스 탭: 판매 준비 완료, 이 기기의 레코드, 사용 중인 저장 공간, 전송 대기 중인 변경 사항 0개">

1. **매장 상태**: 메뉴 맨 아래에 있는 맥박 아이콘입니다.
2. **데이터베이스**: 태블릿이나 컴퓨터에서 매장 상태를 열면 이 탭이 표시됩니다.
3. **전송 대기 중인 변경 사항**: 값이 **0**이고 수치 아래에 패널이 없으며 동기화되지 않은 미결 주문이 없다면, 이 계산대는 모든 데이터를 전송한 상태입니다. 0보다 크면 전송할 수 있도록 POS를 열어 두고 온라인 상태를 유지하세요. 미결 주문은 집계되지 않습니다. 각 주문에서 [주문 동기화](../pos/cart/open-orders.mdx#sync-order)를 누르세요. 매장에서 거부했거나 선택이 필요한 변경 사항은 패널에 표시됩니다. 먼저 해결하세요([조치가 필요한 경우](../support/store-health.mdx#needs-attention)).

## 자동 업데이트 끄기 {#turn-off-auto-updates}

자동 업데이트가 켜져 있으면 WordPress가 최신 버전을 다시 자동으로 설치합니다.

1. **WP Admin → 플러그인**으로 이동하세요.
2. WCPOS 행(또는 WCPOS Pro 행)의 **자동 업데이트** 열을 확인하세요. **자동 업데이트 비활성화**가 표시되면 클릭하세요. **자동 업데이트 활성화**가 표시되면 자동 업데이트가 꺼진 상태입니다.

## 필요한 버전 다운로드하기 {#download}

해당 버전을 `.zip` 파일로 다운로드하고 압축을 풀지 마세요. WordPress는 폴더가 아닌 `.zip` 파일을 설치합니다. 사용 중인 플러그인에 맞는 방법을 따르세요:

- **WCPOS:** [WordPress.org에서 다운로드](#download-free).
- **WCPOS Pro:** [wcpos.com 계정에서 다운로드](#download-pro).

### WCPOS: WordPress.org에서 다운로드 {#download-free}

1. WordPress.org의 [WCPOS 고급 보기](https://wordpress.org/plugins/woocommerce-pos/advanced/)를 여세요.
2. **고급 옵션**까지 스크롤하세요. **이전 버전**에서 원하는 버전을 선택하세요.
3. **다운로드**를 클릭하세요.

원하는 버전의 최신 릴리스를 선택하세요. 2.0에서 되돌리려면 더 오래된 1.x가 아닌 최신 **1.11** 릴리스를 선택하세요. WordPress.org는 이전 버전이 안전하거나 안정적이지 않을 수 있다고 경고하며, 최신 릴리스에는 모든 수정 사항이 포함되어 있습니다.

### WCPOS Pro: wcpos.com 계정에서 다운로드 {#download-pro}

1. [wcpos.com](https://wcpos.com/account/downloads) 계정에 로그인하고 **다운로드**를 여세요.
2. **버전 기록**에서 원하는 버전을 찾으세요. 2.0에서 되돌리려면 최신 1.11 릴리스를 사용하세요.
3. 해당 행에서 **다운로드**를 클릭하세요.

다운로드할 수 있는 버전은 라이선스에 따라 결정됩니다. 라이선스가 만료되어도 만료 전에 출시된 버전은 다운로드할 수 있습니다. 이후 버전은 회색으로 비활성화되며 **라이선스 만료 후 출시되었습니다.** 라고 표시됩니다.

## 현재 버전 위에 업로드하기 {#install}

:::warning 플러그인을 먼저 삭제하지 마세요
현재 플러그인 위에 `.zip` 파일을 업로드하면 모든 데이터가 유지됩니다. **플러그인**에서 플러그인을 삭제하면 WCPOS의 정리 작업이 실행됩니다. 모든 캐셔가 로그아웃되어 각 계산대에서 다시 로그인해야 하며, 각 계산대가 다시 구축하는 동기화 데이터도 지워집니다. 삭제 시 모든 WCPOS 데이터를 제거하도록 사이트를 설정하지 않았다면 이 경우에도 주문, 설정, 영수증 템플릿, 금전 등록기는 유지됩니다. 삭제할 필요가 없습니다.
:::

1. **WP Admin → 플러그인**으로 이동하고 페이지 상단의 **플러그인 추가**를 클릭하세요.
2. **플러그인 업로드**를 클릭하고 다운로드한 `.zip` 파일을 선택한 다음 **지금 설치**를 클릭하세요.
3. WordPress에 **이 플러그인은 이미 설치되어 있습니다.** 라는 메시지와 함께 두 열이 나란히 표시됩니다:
   - **현재**: 현재 설치된 버전입니다.
   - **업로드됨**: `.zip` 파일에 들어 있는 버전입니다. **버전** 행에 원하는 버전이 표시되는지 확인하세요.

   그 아래에 **현재 플러그인보다 이전 버전을 업로드하고 있습니다.** 라고 표시됩니다.
4. **현재 것을 업로드한 것으로 교체**를 클릭하세요.
5. WordPress가 플러그인을 교체하고 **플러그인을 성공적으로 다운그레이드했습니다.** 라고 표시합니다. **플러그인 활성화**가 표시되면 클릭하세요. 그렇지 않으면 플러그인은 이미 활성화되어 있으며 그 상태를 유지합니다.

## 이전 버전으로 되돌린 후 {#after}

1. **앱을 사용하는 계산대를 브라우저로 전환하세요.** 앱이 2.0인 계산대에서는 대신 브라우저에서 `yourdomain.com/pos`를 여세요([시작하기 전에](#before-you-start) 참고).
2. **모든 계산대에서 POS를 열고** 첫 동기화가 완료될 때까지 기다리세요. 브라우저를 사용하는 계산대는 다음에 POS를 열 때 설치한 버전을 불러옵니다.
3. 다시 업데이트할 준비가 될 때까지 **자동 업데이트를 꺼 두세요**. 준비가 되면 [2.0으로 업그레이드](./upgrading-to-2.mdx)를 따르고, 이후 자동 업데이트를 다시 켜세요. 그렇지 않으면 이후 수정 사항이 자동으로 적용되지 않습니다.

2.0에서 생성한 주문은 일반 WooCommerce 주문으로 그대로 유지됩니다. 2.0에서 기록한 금전 등록기 세션과 마감 기록은 데이터베이스에 남지만 1.11에서는 표시되지 않습니다.

## 문제가 발생한 경우 {#if-something-goes-wrong}

**최신 버전이 저절로 다시 설치되었습니다.** 자동 업데이트가 켜져 있었기 때문입니다. [자동 업데이트를 끈](#turn-off-auto-updates) 다음 원하는 버전을 다시 업로드하세요.

**필요한 버전이 버전 기록에서 회색으로 비활성화되어 있습니다.** 라이선스 만료 후 출시된 버전입니다. 라이선스를 갱신하거나 만료 전에 출시된 버전을 선택하세요.

**계산대에 [AUTH331](../error-codes/AUTH331.mdx)이 표시됩니다.** 해당 계산대의 2.0 앱이 1.11 플러그인에 연결하려고 합니다. 해당 기기의 브라우저에서 POS를 여세요.

<details>
<summary>개발자용: WP-CLI로 이전 버전으로 되돌리기</summary>

[WP-CLI](https://developer.wordpress.org/cli/commands/plugin/install/)가 있는 서버에서 다음 명령은 삭제 작업을 실행하지 않고 무료 플러그인을 WordPress.org의 버전으로 교체합니다:

```bash
wp plugin install woocommerce-pos --version=<version> --force
```

`--version`은 릴리스를 선택하고, `--force`는 확인 없이 설치된 사본을 덮어씁니다. WCPOS Pro의 경우 위 안내대로 계정에서 `.zip` 파일을 다운로드하고 플러그인 이름 대신 파일 경로를 전달하세요: `wp plugin install /path/to/woocommerce-pos-pro.zip --force`.

</details>
