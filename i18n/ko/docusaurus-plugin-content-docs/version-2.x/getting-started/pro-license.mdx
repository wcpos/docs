WCPOS Pro는 유료 WordPress 플러그인입니다. 무료 WCPOS 플러그인의 모든 기능이 포함되어 있으므로 무료 플러그인 대신 단독으로 설치합니다. 이 페이지에서는 라이선스 구매부터 POS에서 **Pro** 표시를 확인하기까지 안내합니다.

:::note WordPress 관리자가 필요합니다
설치와 활성화는 POS가 아닌 WP Admin에서 진행합니다. 이 작업을 수행하려면 플러그인을 설치할 수 있는 WordPress 로그인 계정이 필요합니다.
:::

## 라이선스 구매하기 {#purchase-a-license}

Pro는 WordPress 사이트에 설치하는 하나의 플러그인으로, 기기마다 구매하는 것이 아닙니다. 해당 사이트에 연결된 모든 기기와 모든 캐셔가 Pro를 사용할 수 있습니다.

[wcpos.com/pro](https://wcpos.com/pro)에서 라이선스를 구매하세요. 구매, 요금제 변경, 갱신은 모두 wcpos.com에서 진행하며 POS에는 이를 위한 자체 결제 기능이 없습니다. POS 상단의 **Pro로 업그레이드**를 눌러도 같은 페이지가 열립니다([무료 버전에 표시되는 내용](#free-version) 참고). 그런 다음 [플러그인을 설치하세요](#installation).

wcpos.com 계정을 만들거나 구매를 완료할 수 없다면 **support@wcpos.com**으로 이메일을 보내주세요.

연간 라이선스에서 평생 라이선스로 변경하려는 경우에도 **support@wcpos.com**으로 문의하세요. 라이선스와 결제를 담당합니다. [문의처](../support/index.mdx#where-to-ask)를 참고하세요.

Pro에는 상품, 주문, 고객, 쿠폰 화면과 이전 날짜 및 모든 금전 등록기의 보고서, 연동 카드 리더기, 고객용 디스플레이, 환불 기능이 추가되며 금전 등록기와 매장을 더 많이 사용할 수 있습니다. 전체 목록은 [무료 버전과 Pro 비교](./free-vs-pro.mdx)를 참고하세요.

## Pro 플러그인 설치하기 {#installation}

1. wcpos.com에 로그인하고 [다운로드](https://wcpos.com/account/downloads)를 여세요. Pro 플러그인을 다운로드하세요. zip 파일이므로 압축을 풀지 마세요.
2. WP Admin에서 **플러그인**으로 이동하고 새 플러그인을 추가한 다음 **플러그인 업로드**를 누르세요.
3. zip 파일을 선택하고 **지금 설치**를 누른 다음 **플러그인 활성화**를 누르세요.

:::note 무료 플러그인에서 전환하시나요?
무료 플러그인을 먼저 제거할 필요는 없습니다. Pro가 시작되면 무료 플러그인을 비활성화하고 이를 알리는 안내를 표시합니다. 이후 **플러그인** 페이지에서 무료 플러그인을 삭제할 수 있지만 꼭 삭제할 필요는 없습니다. 삭제하면 모든 캐셔가 로그아웃되어 각 계산대에서 다시 로그인해야 합니다. [현재 버전 위에 업로드하기](./previous-versions.mdx#install)를 참고하세요.

이미 무료 플러그인을 제거했어도 괜찮습니다. Pro에는 무료 플러그인의 코드가 포함되어 있어 무료 플러그인 없이도 실행됩니다. Pro를 설치한 후 사이트에 오류가 표시되면 [치명적인 오류](../support/troubleshooting/critical-error.mdx#common-errors)를 참고하세요.
:::

## 라이선스 키 활성화하기 {#activate}

1. 계정의 [라이선스](https://wcpos.com/account/licenses) 페이지에서 키를 복사하세요.
2. WP Admin에서 **POS** > **설정**으로 이동하세요. **계정** 아래의 **라이선스**를 여세요.
3. **라이선스 키**에 키를 붙여 넣고 **활성화**를 누르세요.

화면에 **감사합니다!** 와 **라이선스 …이(가) 활성화되었습니다.** 가 표시되며 키의 중간 부분은 생략됩니다. 다른 메시지가 표시되면 [문제가 발생한 경우](#troubleshooting)를 참고하세요.

## POS가 Pro로 실행되는지 확인하기 {#checking-licence-status}

POS를 다시 불러오세요. 브라우저 페이지를 새로 고치거나 데스크톱 또는 모바일 앱을 닫았다가 다시 여세요. 업그레이드 안내 막대가 사라지고 상품, 주문, 고객, 쿠폰 화면에 흐릿한 미리보기 대신 매장 데이터가 표시됩니다.

확실히 확인하려면 메뉴 맨 아래의 버전 번호(**v 2.0.0**, 휴대전화에서는 **버전 2.0.0**)를 누르세요. **WCPOS 정보**가 열립니다.

<JourneyShot manifest={manifest} device="tablet" step={2} maxWidth={368} alt="Pro 매장의 WCPOS 정보: 앱 버전과 플랫폼, 서버 아래의 WCPOS Pro 플러그인, WooCommerce, WordPress 버전, 라이선스 아래의 상태 Pro" />

- **라이선스**에 **상태**: **Pro**가 표시되어야 합니다. 활성화된 키가 없으면 **무료**가 표시됩니다.
- **서버**에는 **WCPOS Pro 플러그인**과 버전이 표시됩니다(무료 플러그인에서는 **WCPOS 플러그인**). 이는 플러그인이 설치되어 있다는 사실만 확인해 줍니다. 라이선스 활성화 여부와 관계없이 표시됩니다.

## 업데이트 {#updates}

Pro의 새 버전은 다른 플러그인과 마찬가지로 **알림판** > **업데이트**와 **플러그인** 페이지에 표시됩니다. [다운로드](https://wcpos.com/account/downloads)에서 최신 zip 파일을 다운로드할 수도 있습니다.

**플러그인** 페이지의 Pro 행에는 라이선스 상태가 표시됩니다. 유효하며 업데이트를 받는 상태인지, 비활성 상태인지, 만료되었는지 확인할 수 있습니다.

## 문제가 발생한 경우 {#troubleshooting}

### 업데이트 후 Pro를 다시 구매하라는 안내가 표시되는 경우 {#pro-shows-free}

사이트에서 Pro 플러그인이 실행되지 않거나 라이선스 키가 활성화되어 있지 않으면 POS에 **Pro로 업그레이드**와 함께 무료 버전이 표시됩니다. 다시 구매하기 전에 두 가지를 모두 확인하세요:

1. WP Admin에서 **플러그인**을 여세요. **WCPOS Pro – Point of Sale for WooCommerce**가 설치되어 있고 활성화되어 있어야 합니다. 설치되어 있지만 비활성 상태라면 **활성화**를 누르세요. **WCPOS – Point of Sale for WooCommerce**만 있다면 Pro가 제거된 것입니다. [다시 설치하세요](#installation). Pro를 삭제해도 라이선스 키는 유지되므로 다시 설치하면 키도 복원됩니다.
2. **POS** > **설정**으로 이동하고 **계정** 아래의 **라이선스**를 여세요. **라이선스 키** 필드와 **활성화**가 표시되면 이 사이트에서 키가 활성화되지 않은 상태입니다. [라이선스](https://wcpos.com/account/licenses) 페이지의 키를 붙여 넣고 **활성화**를 누르세요.

그런 다음 POS를 다시 불러오세요. **WCPOS 정보**에 **상태** **Pro**가 표시되어야 합니다. [POS가 Pro로 실행되는지 확인하기](#checking-licence-status)를 참고하세요. 활성화 시 다른 메시지가 표시되면 아래에서 자주 나타나는 메시지를 확인하세요. 업데이트가 설치되지 않으면 [LICENSE301](../error-codes/LICENSE301.mdx)을 참고하세요.

### 업데이트가 표시되지만 다운로드되지 않는 경우 {#update-wont-download}

WordPress는 라이선스 유무와 관계없이 모든 사이트에 Pro의 새 버전을 안내합니다. 실제 다운로드 시 라이선스를 확인하며 다음 경우에는 다운로드가 거부됩니다:

- 이 사이트에 활성화된 라이선스 키가 없거나
- 라이선스가 만료된 경우입니다.

**플러그인** 페이지의 Pro 행을 확인하세요. **WCPOS Pro 라이선스가 비활성 상태입니다.** 라면 위의 2단계에 따라 키를 활성화한 다음 다시 업데이트하세요. **WCPOS Pro 라이선스가 만료되었습니다.** 라면 [계정](https://wcpos.com/account/licenses)에서 갱신한 다음 다시 업데이트하세요. 라이선스가 유효하고 활성화되어 있다고 표시되는데도 다운로드에 실패하면 **support@wcpos.com**으로 이메일을 보내주세요. [LICENSE301](../error-codes/LICENSE301.mdx)을 참고하세요.

<details>
<summary>라이선스 화면에 wcpos.com의 메시지가 표시되는 경우</summary>

이 메시지는 키를 확인하는 라이선스 서버에서 보낸 것입니다. 붙여 넣은 키의 앞뒤에 공백이 없는지, [라이선스](https://wcpos.com/account/licenses) 페이지의 키가 맞는지 확인하세요.

</details>

<details>
<summary>라이선스의 활성화 한도에 도달한 경우</summary>

라이선스는 운영 사이트 하나와 개발 사이트 하나, 총 2개 사이트에서 활성화할 수 있습니다. 하위 도메인은 별도로 집계되므로 `example.com`, `staging.example.com`, `dev.example.com`은 세 개로 계산됩니다. 개발, 테스트, 운영 사이트를 기본 제공하는 호스팅에서는 이 한도에 자주 도달합니다. [라이선스](https://wcpos.com/account/licenses) 페이지에서 사이트를 확인하고 활성화를 해제하거나 **support@wcpos.com**으로 이메일을 보내주세요. 요청하면 추가 활성화가 허용됩니다.

</details>

<details>
<summary>네트워크 오류로 활성화에 실패하는 경우</summary>

활성화 요청은 WP Admin에 사용하는 브라우저에서 wcpos.com으로 직접 전송됩니다. 이 브라우저에서 wcpos.com을 열 수 있는지 확인한 다음 광고 또는 개인정보 보호 차단 기능을 끄거나 다른 브라우저에서 **활성화**를 다시 누르세요.

</details>

<details>
<summary>Pro 업데이트가 전혀 표시되지 않는 경우</summary>

업데이트 확인 요청은 WordPress 서버에서 `updates.wcpos.com`으로 전송됩니다. 보안 플러그인이나 호스팅 업체의 방화벽이 이를 차단할 수 있습니다. 호스팅 업체에 `updates.wcpos.com`으로 나가는 요청을 허용해 달라고 요청하세요.

</details>

<details>
<summary>활성화 후에도 업그레이드 안내 막대가 남아 있는 경우</summary>

POS를 다시 불러오세요(페이지를 새로 고치거나 앱을 닫았다가 다시 여세요). **WCPOS 정보**에 여전히 **상태** **무료**가 표시되면 WP Admin을 열고 **POS** > **설정**으로 이동한 다음 **계정** 아래의 **라이선스**를 여세요. **라이선스 …이(가) 활성화되었습니다.** 라고 표시되는지 확인하세요.

</details>

<details>
<summary>라이선스가 만료된 경우</summary>

Pro는 계속 작동하며 POS의 어떤 기능도 꺼지지 않습니다. **플러그인** 페이지에는 "WCPOS Pro 라이선스가 만료되었습니다. 업데이트를 받으려면 갱신하세요."라고 표시됩니다. 업데이트를 다시 받으려면 [계정](https://wcpos.com/account/licenses)에서 갱신하세요. 키는 그대로 유지됩니다.

</details>

<details>
<summary>사이트를 새 도메인으로 이전하는 경우</summary>

먼저 기존 사이트의 활성화를 해제하세요. WP Admin에서 **POS** > **설정**으로 이동하고 **계정** 아래의 **라이선스**를 연 다음 **비활성화**를 누르세요. 그런 다음 새 사이트에서 같은 키를 활성화하세요. 플러그인 자체를 비활성화하는 것만으로는 라이선스 활성화가 해제되지 않습니다. 기존 사이트가 없어졌다면 [라이선스](https://wcpos.com/account/licenses) 페이지에서 해제하거나 **support@wcpos.com**으로 이메일을 보내주세요.

</details>

<details>
<summary>Pro 삭제와 데이터</summary>

Pro 플러그인을 삭제하면 Pro 자체의 작업 데이터와 번역 파일이 제거됩니다. 라이선스 키를 포함한 Pro 설정과 매장은 유지되므로 다시 설치하면 이전 상태에서 이어서 사용할 수 있습니다. 주문과 상품 데이터는 전혀 변경되지 않습니다.

Pro가 무료 플러그인과 공유하는 번역 파일은 무료 플러그인도 더 이상 설치되어 있지 않을 때만 제거됩니다.

설정, 라이선스 키, 매장까지 모두 제거하고 처음부터 시작하려면 플러그인을 삭제하기 전에 전체 삭제를 켜세요. `wp-config.php`에 `define( 'WCPOS_REMOVE_ALL_DATA', true );`를 추가하거나 `wcpos_remove_all_data` 옵션을 `yes`로 설정하세요. 둘 다 설정되어 있으면 상수가 우선합니다. 전체 삭제는 되돌릴 수 없습니다.

</details>
