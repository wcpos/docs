## WCPOS란? {#what-is-wcpos}

WCPOS는 WooCommerce용 판매 시점 관리(POS) 시스템입니다. 온라인 쇼핑몰과 동일한 상품, 재고, 가격으로 판매하며, 모든 판매는 WooCommerce 주문으로 저장됩니다. 웹 브라우저나 Windows, macOS, Linux 앱에서 실행되며, iOS와 Android 앱은 베타 버전으로 제공됩니다.

## 화면 둘러보기 {#find-your-way-around}

아래는 ‘시계’를 검색한 뒤 **재고 있음** 필터를 켜고 장바구니에 시계 하나를 담은 POS 화면입니다. 이 문서의 모든 안내는 여기에서 시작합니다. [POS 화면 개요](../pos/index.mdx)에서 각 부분을 차례로 살펴보세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[36, -12], [124, 0], [-30, 0], [10, 28], [72, 0], [0, -72], [-42, 0], [40, 28], [0, 0]]} alt="장바구니에 시계가 담긴 POS: 왼쪽의 메뉴, 검색창과 상품, 상품 수, 오른쪽의 매장, 알림, 내 아바타, 고객 및 결제 버튼">

1. **메뉴** — **POS**에서 판매를 진행합니다. **상품**, **주문**, **쿠폰**, **고객**에는 [WCPOS Pro](./free-vs-pro.mdx#management-screens)가 필요합니다. **보고서**에서는 오늘의 판매와 마감 내역을 확인할 수 있습니다. 하단에는 **상태**, **설정**, **지원**이 있습니다.
2. **계산대 표시줄** — 이 기기가 연결된 매장을 표시하며, 매장에 계산대가 여러 개 있으면 계산대 이름도 표시합니다. [매장, 계산대 및 기기](../stores/registers-and-devices.mdx)를 참조하세요.
3. **알림** — WCPOS의 공지, 업데이트 안내, 라이선스 알림입니다. [알림](../support/notifications.mdx)을 참조하세요.
4. **내 아바타** — 캐셔 패널을 엽니다. 현금 서랍을 확인하거나 다른 사람에게 계산대를 인계하고 로그아웃할 수 있습니다. [계산대 열기](../pos/register/index.mdx#cashier-sheet)를 참조하세요.
5. **검색** — 이름이나 SKU를 입력하거나 바코드를 스캔하세요. [검색 및 필터링](../pos/product-panel/search-filtering.mdx)을 참조하세요.
6. **상품** — 상품을 누르면 장바구니에 담깁니다. [상품 패널](../pos/product-panel/index.mdx)을 참조하세요.
7. **상품 수** — 조건에 맞는 상품 수입니다. 옆의 화살표를 누르면 매장에서 최신 정보를 가져옵니다.
8. **고객** — 구매하는 고객입니다. 누르면 다른 고객을 선택할 수 있습니다. [장바구니](../pos/cart/index.mdx)를 참조하세요.
9. **결제** — 합계를 표시합니다. 눌러서 결제를 받으세요. [결제](../pos/checkout/index.mdx)를 참조하세요.

## 5분 만에 시작하기 {#get-started-in-5-minutes}

캐셔라면 매장에서 이미 WCPOS를 사용하는 경우 [2단계부터 시작하세요](#open-the-pos). 1단계는 매장 소유자를 위한 안내입니다.

<Steps>

<StepCard number={1} title="플러그인 설치하기(매장 소유자)">

WordPress 사이트에 무료 [WCPOS 플러그인](https://wordpress.org/plugins/woocommerce-pos/)을 설치하세요:

1. WP Admin에서 **플러그인**으로 이동해 새 플러그인을 추가하세요.
2. ‘WCPOS’를 검색하세요.
3. **지금 설치**를 누른 다음 **활성화**를 누르세요.

서버와 기기의 요구 사항은 [설치](./installation.mdx)를 참조하세요.

</StepCard>

<StepCard number={2} title="POS 열기">

<Anchor id="open-the-pos" />

**브라우저에서:** `yourdomain.com/pos`로 이동해 WordPress 사용자명과 비밀번호로 로그인하세요.

**앱에서**([다운로드](#where-it-runs)): 매장 주소를 입력하고 **연결**을 누른 다음 **WordPress로 로그인**을 누르고 **POS 열기**를 누르세요.

한 기기에서 여러 매장과 캐셔를 이용하는 방법은 [연결](./connect.mdx)을 참조하세요.

</StepCard>

<StepCard number={3} title="POS가 시작될 때까지 기다리기">

POS를 열 때마다 진행 표시줄 위에 WCPOS 로고가 나타납니다. 표시줄이 채워질 때까지 기다리면 POS가 열립니다. 앱에 아직 로그인한 사람이 없으면 대신 **연결** 화면이 열립니다. 열리지 않으면 [POS가 시작되지 않는 경우](#wont-start)를 참조하세요.

<details>
<summary>진행 표시줄이 나타내는 작업</summary>

POS가 이 기기에 보관된 데이터를 열고, 매장에 연결하는 방법을 확인하고(브라우저의 경우), 마지막으로 사용한 매장을 여는 동안 표시줄이 채워집니다. 앱에서는 이전과 같은 캐셔로, 브라우저에서는 WordPress에 로그인한 사용자로 열립니다.

이 표시줄은 상품이 아닌 POS 시작 과정을 나타냅니다. 상품은 그다음에 다운로드되며, 다운로드 중에도 판매할 수 있습니다.

</details>

</StepCard>

<StepCard number={4} title="상품을 다운로드하는 동안 판매하기">

전체 상품 목록이 다운로드될 때까지 기다릴 필요가 없습니다. 판매하는 동안에도 상품 다운로드가 계속되며, 검색하면 기기에 아직 없는 상품을 매장에 요청합니다.

<details>
<summary>처음에 상품 수가 적게 표시되는 이유</summary>

POS는 매장 서버에 과부하가 걸리지 않도록 백그라운드에서 상품 목록을 조금씩 나누어 다운로드합니다.

**모든 상품**을 표시할 때 상품 아래의 **…개 중 …개 표시**는 이 기기에 저장된 상품 수를 나타냅니다. 따라서 새 기기에서는 적은 수로 시작해 점차 늘어납니다. [상품 동기화](../products/sync.mdx)를 참조하세요.

</details>

</StepCard>

<StepCard number={5} title="첫 판매 진행하기" isLast>

POS에 **계산대를 열기 전까지는 가격 확인만 가능합니다**가 표시되면 먼저 [계산대를 여세요](../pos/register/index.mdx). **검색**, 상품, **결제**의 위치는 위의 [화면 둘러보기](#find-your-way-around)에 표시되어 있습니다. 그런 다음 현금 판매를 진행하세요:

1. **검색**에 입력하거나 상품을 스캔한 뒤, 상품을 눌러 장바구니에 담으세요.
2. 휴대전화에서는 **장바구니** 탭을 여세요. **결제**를 누르면 결제할 금액이 입력됩니다.
3. **현금**을 선택한 다음 고객에게 받은 금액을 입력하거나 빠른 금액 버튼을 누르세요. 입력하는 동안 거스름돈이 표시됩니다.
4. **받기**를 누르세요. 결제 완료 화면에 돌려줄 거스름돈과 영수증이 표시됩니다.
5. 영수증을 인쇄하거나 이메일로 보낸 다음 **새 판매**를 눌러 다음 고객을 맞이하세요.

아래 예시에서는 $45.00 판매에 고객이 $50.00를 건넵니다:

## POS가 시작되지 않는 경우 {#wont-start}

**진행 표시줄이 중간에 멈춥니다.** 브라우저에서는 POS가 매장에 연결하는 방법을 확인하는 중입니다. 연결 속도가 느리면 시간이 조금 걸릴 수 있으며, 자동으로 계속 진행됩니다.

**‘문제가 발생했습니다’.** 이 기기에서 POS를 시작하지 못했습니다. 메시지 아래에 실패한 작업이 표시됩니다. **다시 시도**를 누르세요. 이 기기의 모든 데이터는 유지됩니다. 같은 메시지가 다시 나오면 내용을 기록하고 [지원팀에 문의하세요](../support/index.mdx).

:::warning

지원팀에서 요청하지 않는 한 해당 화면의 **앱 데이터 초기화 및 다시 시작**을 누르지 마세요. 아직 매장으로 전송되지 않은 판매 내역을 포함하여 이 기기의 모든 데이터를 삭제합니다. 삭제하기 전에 확인을 요청하고, 매장에 아직 전달되지 않은 변경 사항이 있으면 경고합니다.

:::

**‘다른 탭에서 POS가 열려 있습니다’.** POS는 한 탭에서만 실행됩니다. **여기서 이어서 사용**을 누르거나 다른 탭으로 돌아가세요.

**앱이 연결 화면으로 열립니다.** 이 기기에 아직 로그인한 사람이 없거나 로그아웃한 상태입니다. 로그인이 완료되지 않으면 [연결](./connect.mdx#troubleshooting)을 참조하세요.

## 주요 기능 {#key-features}

무료 플러그인으로 판매를 처리할 수 있습니다. 현금, 자체 단말기를 이용한 카드 결제, 현금 서랍이 있는 계산대 하나, 영수증, 장바구니 쿠폰, 바코드 스캔을 지원하며 연결이 끊겨도 판매를 이어갈 수 있습니다. 전체 비교는 [무료 버전과 Pro 비교](./free-vs-pro.mdx)를 참조하세요.
