고객 화면에는 판매의 고객으로 지정할 수 있는 매장의 모든 WordPress 사용자가 표시됩니다. [WCPOS Pro](../getting-started/pro-license.mdx)가 있으면 WP Admin으로 이동하지 않고 여기에서 고객을 추가, 수정, 삭제할 수 있습니다. Pro가 없어도 기존 고객을 판매에 지정할 수 있습니다. [판매의 고객 지정](#on-a-sale)을 확인하세요.

<details>
<summary>Pro 없이 고객 화면 사용하기</summary>

WCPOS Pro가 없으면 업그레이드 카드 뒤의 목록이 흐리게 표시되고, **새 고객 추가**와 각 행의 **›** 가 비활성화됩니다. **표시 옵션**은 계속 사용할 수 있습니다.

3. **새 고객 추가** — WCPOS Pro가 없으면 비활성화됩니다.
4. **Pro로 업그레이드** — 목록 위에 표시되는 카드입니다.

## 판매의 고객 지정 {#on-a-sale}

각 판매는 매장의 기본 고객으로 시작합니다. [기본 POS 고객](../settings/wp-admin/general.mdx#default-pos-customer)에 지정된 고객이며, [캐셔 계정 사용](../settings/wp-admin/general.mdx#use-cashier-account)이 켜져 있으면 캐셔입니다. 다른 고객을 선택하려면 장바구니에서 고객 이름을 누르세요. [고객 선택](../pos/cart/index.mdx#customer-selector)을 확인하세요.

:::note 고객을 변경하면 세금이 달라질 수 있습니다
매장에서 [고객 주소를 기준으로 세금을 계산](../settings/store/tax.mdx#calculate-tax-based-on)한다면 다른 고객을 선택하거나 추가할 때, 또는 장바구니에서 고객 주소를 변경할 때 이미 장바구니에 있는 상품의 세금이 달라질 수 있습니다. 세전 가격은 그대로 유지됩니다. [면세](../pos/cart/index.mdx#tax-exempt) 주문의 세금은 다시 계산되지 않습니다.
:::

<JourneyShot manifest={cartManifest} device="tablet" step={2} alt="장바구니의 고객 선택 검색창에 Smith를 입력한 화면. 상단에 비회원 옵션이 있고 아래에 일치하는 고객이 표시됩니다">

1. **고객 선택** — 이름, 이메일 또는 전화번호의 일부를 입력하세요.
2. **비회원** — 고객 계정 없이 진행하는 판매입니다.
3. **고객** — 누르면 청구지 및 배송지 주소와 함께 해당 고객이 주문에 지정됩니다.

</JourneyShot>

## 고객 찾기 {#find}

메뉴에서 **고객**을 여세요. **고객 검색**에 이름, 이메일 주소 또는 전화번호를 입력하세요.

<details>
<summary>검색할 수 있는 항목</summary>

입력한 모든 단어가 순서에 관계없이 이름, 이메일, 사용자명, 회사, 전화번호, 납세자 ID 필드에서 일치해야 합니다. 따라서 `jane acme`를 입력하면 회사가 Acme인 Jane을 찾습니다. [검색 대상 필드](../reference/search.mdx#customers)를 확인하세요.

</details>

목록은 처음에 성을 기준으로 A부터 Z까지 정렬됩니다. **이름**, **이메일**, **생성 날짜** 등의 열 제목을 누르면 해당 열을 기준으로 정렬되고, 다시 누르면 순서가 반대로 바뀝니다. 하단에는 전체 고객 수와 현재 목록에 표시된 고객 수가 표시됩니다.

## 고객 추가하기 {#add-new-customer}

1. 검색창 옆의 **새 고객 추가**를 누르세요. 빈 **고객 추가** 양식이 열립니다.
2. 고객의 **이메일**을 입력하세요. 유일한 필수 입력 항목입니다.
3. **이름**, **전화번호**와 알고 있는 다른 정보를 추가하세요. 아래의 **주소 및 기타 선택 정보**를 여세요.
4. **고객 추가**를 누르세요. 고객 이름이 포함된 메시지가 표시되고 양식이 닫힙니다.

판매 도중 고객을 추가하려면 장바구니의 추가 메뉴에서 **새 고객 추가**를 사용하세요. 같은 양식이 열리며, 추가한 고객이 바로 주문에 지정됩니다. [새 고객 추가](../pos/cart/index.mdx#new-customer)를 확인하세요.

<details>
<summary>주소 및 기타 선택 정보</summary>

양식에는 처음에 **이름**, **이메일**, **전화번호**, **사용자명**이 표시됩니다.

- **사용자명** — 고객을 추가하는 지금만 설정할 수 있습니다. 기본적으로 켜져 있는 [고객 이메일로 사용자명 자동 생성](../settings/wp-admin/general.mdx#automatically-generate-username-from-customer-email)이 활성화되어 있으면, 비워 둘 경우 매장에서 이메일을 바탕으로 사용자명을 생성합니다.

나머지 항목은 처음에 그 아래 버튼으로 표시됩니다. 버튼을 누르면 해당 행이 추가됩니다.

- **회사**, **청구지 주소**, **배송지 주소**. **다른 주소 사용**을 누르기 전까지 **배송지 주소**는 **청구지와 동일**로 설정됩니다.
- **비밀번호** — 입력하지 않으면 매장에서 생성합니다.
- **납세자 ID** — 유형, ID, 국가로 구성됩니다. 새 행에는 청구지 국가에 맞는 유형이 기본으로 지정되며, 청구지 주소가 없으면 매장 국가를 기준으로 합니다. "형식이 선택한 유형과 일치하지 않습니다."는 경고일 뿐이며 ID는 그대로 저장됩니다.
- **사용자 지정 필드** — 고객 계정에 저장되는 키와 값입니다.

고객의 역할은 여기서 설정하지 않고 WP Admin에서 설정합니다.

</details>

## 고객 수정하기 {#edit-customer}

1. 고객을 여세요. 터치스크린에서는 고객을 누르세요. 마우스를 사용하는 경우 해당 행 끝의 **›** 를 클릭하거나, **작업** 열이 숨겨져 있다면 행 자체를 클릭하세요. 제목에 고객 이름이 표시된 **수정** 대화상자가 열립니다.
2. 필드를 변경하세요. **저장** 버튼은 없습니다. 입력을 멈추면 잠시 후 변경 사항이 저장됩니다.
3. 필드 옆에 녹색 **저장됨** 표시가 있는지 확인하세요.
4. 완료되면 **닫기**를 누르세요.

<details>
<summary>계정 접근 정보와 고객 상세 정보 새로고침</summary>

- **비밀번호**는 입력하는 동안이 아니라 해당 필드에서 벗어날 때 저장됩니다.
- `@`가 없는 이메일처럼 **양식에서 허용하지 않는 값**은 필드 아래에 오류가 표시되며 저장되지 않습니다.
- **사용자명**은 잠겨 있습니다. 계정을 생성할 때 설정됩니다.
- **역할**은 잠겨 있습니다. WordPress에서 설정합니다.
- **동기화**는 대기 중인 변경 사항을 저장한 다음 매장에서 고객 정보를 다시 가져옵니다. 고객 정보가 최신이 아닌 것 같을 때 사용하세요.
- **JSON**은 이 기기에 저장된 고객 기록을 그대로 보여줍니다. 지원팀에서 POS에 어떤 정보가 저장되어 있는지 물을 때 사용합니다.

</details>

## 고객 삭제하기 {#delete-customer}

:::warning 삭제는 되돌릴 수 없습니다
고객을 삭제하면 매장에서 해당 WordPress 사용자도 삭제됩니다. WordPress 사용자에는 휴지통이 없으므로 되돌릴 수 없습니다.
:::

**수정** 대화상자에서 **삭제**를 누르세요. **확인**을 선택하고 **삭제**를 다시 누르세요.

**삭제**는 사용자 삭제 권한이 있는 역할의 캐셔에게만 표시됩니다. 매장 관리자나 다른 캐셔 같은 직원 계정은 관리자만 수정하거나 삭제할 수 있습니다. [접근 권한](../settings/wp-admin/access.mdx)을 확인하세요.

WP Admin에서 삭제한 고객은 다음 동기화 시 POS 목록에서도 사라집니다.

## 표시 설정 {#display-settings}

## 문제가 발생한 경우 {#goes-wrong}

### 버튼이 비활성화됨 {#greyed}

- **새 고객 추가가 비활성화됨** — 매장에 WCPOS Pro가 필요하거나 현재 역할에 고객 추가 권한이 없습니다. 관리자가 [접근 권한](../settings/wp-admin/access.mdx)에서 허용할 수 있습니다. 마우스를 사용하는 경우 버튼 위에 포인터를 올리면 이유를 확인할 수 있습니다.
- **›가 비활성화되어 고객을 열 수 없음** — 현재 역할에 고객 수정 권한이 없습니다. 관리자가 [접근 권한](../settings/wp-admin/access.mdx)에서 허용할 수 있습니다.

### 변경 사항이 저장되지 않음 {#not-saving}

- **"고객 저장 실패"** — 입력한 내용이 유지된 채 양식이 열려 있습니다. **고객 추가**를 다시 누르세요.
- **필드 옆에 "저장되지 않음" 표시** — 해당 변경 사항이 저장되지 않았습니다. 다시 입력하세요.
- **고객이 저장되었지만 이 주문에 추가되지 않음** — 장바구니의 **새 고객 추가**에서 발생합니다. 장바구니에서 해당 고객을 검색하여 다시 추가하세요.

### 고객이 없거나 목록이 올바르지 않음 {#list-wrong}

- **"새로고침하지 못했습니다. 이 기기의 사본은 변경되지 않았습니다"** — **동기화** 중 매장에 연결하지 못했습니다. 연결 상태를 확인하고 **동기화**를 다시 누르세요.
- **있어야 할 고객을 찾을 수 없음** — 오프라인에서는 이 기기에 이미 저장된 고객만 검색됩니다. [기기와 매장의 데이터](../reference/search.mdx#device-and-store)를 확인하세요.
- **목록이 올바르지 않음** — 하단의 동기화 버튼을 길게 누르고 **지우고 새로고침**을 선택하세요. 이 기기의 고객 목록 사본을 지우고 다시 다운로드합니다. 매장의 데이터는 변경되지 않습니다.
