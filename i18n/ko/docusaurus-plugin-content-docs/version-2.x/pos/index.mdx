POS는 판매를 진행하는 화면입니다. 한쪽에는 상품이, 다른 쪽에는 장바구니가 있으며, 나머지 기능은 가장자리에 있는 메뉴에서 이용합니다. 이 페이지는 화면 안내도입니다. 각 부분에서 자세한 설명 페이지로 이동할 수 있습니다.

**작업 바로가기:** [상품 찾기](./product-panel/index.mdx) · [결제받기](./checkout/index.mdx) · [계산대 열기](./register/index.mdx) · [캐셔 패널 열기](#cashier-sheet)

## 화면 둘러보기 {#layout}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[34, -28], [52, 0], [52, 0], [52, 0], [240, 0], [0, -50], [200, 0], [128, 0], [-30, 0], [-14, 26]]} alt="장바구니에 상품 하나가 담긴 태블릿의 POS 화면: 왼쪽 가장자리의 메뉴 아이콘에 마우스를 올리면 주문이라는 이름이 표시되고, 하단에는 매장 상태, 설정, 지원이 있습니다. 상품 검색과 격자 보기, 구분선, 장바구니, 매장 이름과 알림 종, 아바타가 있는 장바구니 위 표시줄도 보입니다">

1. **메뉴** — 화면마다 아이콘이 하나씩 있습니다. 아이콘에 마우스를 올리면 이름이 표시됩니다. [메뉴](#menu)를 참고하세요.
2. **매장 상태** — 이 기기가 매장 데이터를 잘 반영하고 있는지, 어떤 문제가 기록되었는지 확인하세요. 빨간 숫자는 로그에 새 오류가 있다는 뜻입니다. [매장 상태](../support/store-health.mdx)를 참고하세요.
3. **설정** — 이 기기의 언어와 통화 형식, 세금 표시, 프린터, 카드 리더기, 고객용 화면, 스캐너, 테마를 설정합니다. [설정](../settings/index.mdx)을 참고하세요.
4. **지원** — 앱 안에서 이용하는 WCPOS Discord 채팅입니다. [지원](../support/index.mdx)을 참고하세요.
5. **상품 패널** — 검색과 필터로 상품을 찾고 눌러서 추가합니다. [상품 패널](./product-panel/index.mdx)을 참고하세요.
6. **구분선** — 드래그하여 상품이나 장바구니 영역을 넓히세요. POS는 이 기기에서 설정한 너비를 기억합니다.
7. **장바구니** — 현재 판매 내역으로, 고객, 품목, 합계와 **결제** 버튼이 있습니다. [장바구니](./cart/index.mdx)를 참고하세요.
8. **계산대 표시줄** — 판매 중인 매장을 표시하며, 매장에 계산대가 여러 개 있으면 계산대도 표시합니다. [상단 표시줄](#bar)을 참고하세요.
9. **알림 종** — 플러그인 업데이트, 라이선스 알림, 공지 등 WCPOS의 알림을 확인합니다. [알림](../support/notifications.mdx)을 참고하세요.
10. **내 아바타** — 캐셔 패널을 엽니다. [내 캐셔 패널](#cashier-sheet)을 참고하세요.

</JourneyShot>

## 메뉴 {#menu}

태블릿이나 컴퓨터에서는 메뉴 아이콘이 왼쪽 가장자리에 세로로 나열되어 항상 화면에 표시됩니다. 휴대폰에서는 왼쪽 상단의 **☰** 안에 숨겨져 있으며, 열면 이름이 표시된 메뉴가 화면 위로 펼쳐집니다. 이름을 눌러 해당 화면으로 이동하세요.

<JourneyShot manifest={manifest} device="phone" step={2} offsets={[[-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0]]} maxWidth={390} alt="휴대폰에서 열린 메뉴: 상단에는 POS, 상품, 주문, 쿠폰, 고객, 보고서가 있고, 하단에는 매장 상태, 설정, 지원이 있으며 그 아래에 버전이 표시됩니다">

1. **POS** — 판매를 진행하는 계산 화면입니다. [결제](./checkout/index.mdx)를 참고하세요.
2. **상품** — 재고, 가격, 상품 상세 정보를 관리합니다. [상품](../products/index.mdx)을 참고하세요.
3. **주문** — 이전 주문을 조회하고 영수증을 다시 인쇄하거나 환불합니다. [주문](../orders/index.mdx)을 참고하세요.
4. **쿠폰** — 매장의 쿠폰입니다. [쿠폰](../coupons/index.mdx)을 참고하세요.
5. **고객** — 고객을 추가하고 수정합니다. [고객](../customers/index.mdx)을 참고하세요.
6. **보고서** — 결제 수단별·캐셔별 당일 매출과 계산대 마감 내역을 확인합니다. [보고서](../reports/index.mdx)를 참고하세요.
7. **매장 상태** — 이 기기가 매장 데이터를 얼마나 잘 반영하고 있는지, 어떤 문제가 기록되었는지 확인합니다. [매장 상태](../support/store-health.mdx)를 참고하세요.
8. **설정** — 이 기기의 설정입니다. [설정](../settings/index.mdx)을 참고하세요.
9. **지원** — 앱 안에서 이용하는 WCPOS Discord 채팅입니다. [지원](../support/index.mdx)을 참고하세요.

</JourneyShot>

무료 플러그인에서는 **상품**, **주문**, **쿠폰**, **고객** 화면이 수정할 수 없는 미리보기로 표시됩니다.

<details>
<summary>WCPOS Pro에서는 무엇이 달라지나요?</summary>

**무료 플러그인에서는** **상품**, **주문**, **쿠폰**, **고객** 화면이 흐릿한 미리보기와 **Pro로 업그레이드** 패널로 열립니다. 장바구니에서 고객을 선택하고 쿠폰을 적용하는 것은 가능합니다. **보고서**에는 현재 계산대의 오늘 내역이 표시됩니다.

**WCPOS Pro에서는** **상품**, **주문**, **쿠폰**, **고객** 화면에서 편집할 수 있습니다. **보고서**에서는 조회 권한이 있는 모든 계산대와 매장의 오늘 이전 내역도 확인할 수 있으며, 매장이 여러 개라면 표시줄이나 캐셔 패널에서 매장을 전환할 수 있습니다.

[무료 버전과 Pro 비교](../getting-started/free-vs-pro.mdx#management-screens)를 참고하세요.

</details>

## 상단 표시줄 {#bar}

모든 화면의 상단에는 표시줄이 있으며, 그 끝에는 항상 알림 종과 내 아바타가 있습니다.

POS에서는 이 부분이 **계산대 표시줄**입니다. 판매 중인 매장을 표시하며, 매장에 계산대가 여러 개 있으면 계산대 이름도 표시합니다. WCPOS Pro로 여러 매장을 운영한다면 매장 이름을 눌러 매장을 전환하세요. 주의가 필요한 사항이 있으면 이름 옆에 상태가 표시됩니다.

<details>
<summary>계산대 상태의 의미</summary>

- **마감됨**, **계수 중**, **승인 필요**, **마감 기한 초과** — 하루 영업 중 계산대가 어느 단계에 있는지 나타냅니다. [계산대 열기](./register/index.mdx)를 참고하세요.
- **계산대 선택** 또는 **계산대 없음** — 이 기기에 아직 계산대가 지정되지 않았습니다. [매장과 계산대 선택](../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)을 참고하세요.
- **오프라인** 또는 **오프라인 · 전송할 판매 2건** — 아래의 [표시줄에 오프라인이 표시되는 경우](#offline)를 참고하세요.
- **매장 확인 대기 중인 판매 1건** — 매장에서 아직 확인하지 않은 판매입니다. 자동으로 처리되므로 별도로 할 일은 없습니다.

계산대가 열려 있고 알릴 내용이 없으면 상태가 표시되지 않습니다.

</details>

<details>
<summary>다른 화면과 데스크톱 앱의 표시줄</summary>

**상품**, **주문**, **쿠폰**, **고객** 화면에서는 제목 자리에 검색창이 표시되며, 검색창에 해당 화면의 이름이 나타납니다. **보고서** 화면에서는 그 자리에 매장과 계산대 선택 항목이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[34, -28], [260, 0], [10, 40], [10, 40], [10, 40]]} alt="표시줄이 있는 상품 화면: 상품 표 위에 메뉴에서 강조된 상품 아이콘, 검색창, 표시 옵션, 알림 종, 아바타가 보입니다">

1. **현재 위치** — 메뉴에서 강조된 아이콘입니다.
2. **검색** — 이 화면의 내역을 검색합니다.
3. **표시 옵션** — 목록에 표시할 열을 정합니다. [표시 설정](../products/index.mdx#display-settings)을 참고하세요.
4. **알림 종** — POS와 동일한 [알림](../support/notifications.mdx)입니다.
5. **내 아바타** — 어느 화면에서나 동일한 [캐셔 패널](#cashier-sheet)을 엽니다.

</JourneyShot>

데스크톱 앱에서는 매장 이름, 상태, 알림 종, 내 아바타가 창의 제목 표시줄로 올라갑니다. 창을 전체 화면으로 전환하면 원래 표시줄로 돌아옵니다.

</details>

## 내 캐셔 패널 {#cashier-sheet}

어느 화면에서든 내 아바타를 누르면 오른쪽에서 캐셔 패널이 펼쳐집니다. 휴대폰에서는 화면 전체를 채웁니다.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[130, 0], [230, -15], [180, -19], [-30, 0], [0, -32], [0, -32], [100, 0]]} alt="POS 위에 열린 캐셔 패널: 이름, 매장, 로그인 후 경과 시간, 오늘 내 판매, 현금 서랍 타일, 계산대 인계, 전환 버튼이 있는 매장, WordPress 관리자와 데스크톱 앱 링크, 로그아웃이 표시됩니다">

1. **오늘 내 판매** — 내가 처리한 판매 내역입니다.
2. **서랍 내 현금** — 계산대에 있어야 할 현금입니다. 보고서 조회 권한이 없으면 금액 대신 판매 건수가 표시됩니다. 눌러서 입금, 출금, 마감을 진행하세요. [계산대 열기](./register/index.mdx#cashier-sheet)를 참고하세요.
3. **계산대 인계** — 현금 서랍을 마감하지 않고 다른 캐셔에게 계산대를 넘깁니다. 캐셔 이름을 누르거나 **다른 계정…** 을 눌러 로그인하게 하세요. [계산대 열기](./register/index.mdx#cashier-sheet)를 참고하세요.
4. **매장 · 전환** — 다른 매장으로 이동합니다(여러 매장이 있는 WCPOS Pro). 매장에 계산대가 여러 개 있으면 아래에 **계산대 · 전환**이 표시됩니다.
5. **WordPress 관리자** — 접근 권한이 있는 관리자가 사이트의 관리자 화면을 새 탭에서 엽니다.
6. **데스크톱 앱** — 데스크톱 앱 다운로드 페이지입니다. 이 두 링크는 브라우저에서만 표시됩니다.
7. **로그아웃** — 계산대가 열려 있으면 POS에서 먼저 마감할지 묻습니다.

</JourneyShot>

## 키보드 단축키 {#keyboard-shortcuts}

브라우저나 데스크톱 앱에서 키보드를 사용하면 입력란에 입력하는 중에도 POS 화면 어디서나 이 단축키를 사용할 수 있습니다. Mac에서는 **Alt** 대신 **Option** (⌥)을 누르세요.

<details>
<summary>키보드 단축키 보기</summary>

| 단축키 | 기능 |
|---|---|
| `Alt` + `F` | 상품 검색 |
| `Alt` + `P` | 결제 |
| `Alt` + `N` | 새 장바구니 |
| `Alt` + `←` / `Alt` + `→` | 이전 장바구니 / 다음 장바구니 |
| `Alt` + `D` | 할인 추가 |
| `Alt` + `V` | 주문 무효화 |
| `Alt` + `/` | 단축키 보기 |
| `Esc` | 입력란에 입력 중이 아닐 때 결제 화면에서 장바구니로 돌아가기 |

단축키는 해당 작업을 할 수 있는 상황에서만 작동합니다. 예를 들어 **결제**는 장바구니에 상품이 있어야 합니다. 단축키는 변경할 수 없습니다. [키보드 단축키](../settings/store/hotkeys.mdx)를 참고하세요.

</details>

## 문제가 발생한 경우 {#goes-wrong}

### 표시줄에 오프라인이 표시되는 경우 {#offline}

이 기기가 매장에 연결할 수 없는 상태입니다. 인터넷이 끊겼거나 웹사이트가 응답하지 않습니다. 판매는 계속 진행하세요. 현금 결제와 별도의 단말기에서 받는 카드 결제는 계속 완료할 수 있습니다. 표시줄에 대기 중인 건수가 **전송할 판매**로 표시되며, 매장에 다시 연결되면 전송됩니다. 계산대에서 제어하는 카드 리더기와 온라인 결제 게이트웨이는 연결이 필요합니다. [오프라인 모드](../getting-started/offline.mdx)를 참고하세요.

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[80, 0], [52, 26]]} alt="연결이 끊긴 직후의 POS: 표시줄의 매장 이름 옆에 오프라인이 표시되고, 기기가 오프라인 상태가 되었습니다, 작업을 계속하세요, 매장에 연결되면 동기화가 재개됩니다라는 메시지가 나타납니다">

1. **오프라인** — 매장이 다시 응답할 때까지 표시됩니다.
2. **매장 이름** — 판매 내역이 전송될 매장입니다.

</JourneyShot>

### “로컬 데이터베이스를 사용할 수 없습니다” {#database-unavailable}

상품 위와 결제 화면의 배너에 스캔, 결제, 저장, 무효화가 차단되었다고 표시됩니다.

1. **앱 새로고침**을 누르세요.
2. 앱에서 자체적으로 새로고침할 수 없다고 안내하면(일부 휴대폰 및 태블릿 앱), 앱을 완전히 종료한 뒤 다시 여세요.
3. 문제가 계속되면 [로컬 데이터 지우기](../support/troubleshooting/clear-local-data.mdx)를 참고하세요.

<details>
<summary>문제의 원인</summary>

기기에 저장된 매장 데이터 사본이 작동을 멈춘 상태입니다. 배너의 **상태 보기**를 누르면 매장 상태의 [데이터베이스](../support/store-health.mdx#database) 부분이 열립니다.

</details>

### 매장 상태의 빨간 숫자 {#store-health-errors}

이 기기에 새 오류가 기록되었습니다. **매장 상태**를 열고 로그에서 내용을 확인하세요. 로그를 열면 숫자가 사라집니다. [로그](../support/store-health.mdx#logs)를 참고하세요.

### “이 화면이 존재하지 않습니다” {#not-found}

주소가 오래된 경우이며, 이전에 저장한 북마크가 원인인 경우가 많습니다. **시작 화면으로 돌아가기**를 누르세요. POS로 이동하며, 로그아웃 상태라면 매장을 연결하는 화면으로 이동합니다.

### 화면에 “Pro로 업그레이드”가 표시되는 경우 {#upgrade-to-pro}

해당 화면은 WCPOS Pro가 필요합니다. [메뉴](#menu)의 **WCPOS Pro에서는 무엇이 달라지나요?** 또는 [무료 버전과 Pro 비교](../getting-started/free-vs-pro.mdx)를 참고하세요.
