고객은 계산대가 아닌 카드 리더기에서 팁을 추가합니다. 계산대가 결제할 금액을 보내면 리더기가 고객에게 팁을 요청하고, 계산대는 리더기에서 받은 금액을 기록합니다. 계산대에는 팁 버튼이 없습니다.

## 팁을 포함한 카드 결제 받기 {#take-a-tip}

:::info Pro 기능
카드 리더기에서 팁을 받으려면 [WCPOS Pro](../../getting-started/pro-license.mdx)와 팁을 요청하는 리더기가 필요합니다.
:::

시작하기 전에 [리더기가 팁을 요청하는지](#which-readers) 확인하세요. **계산대 열기 및 마감**이 켜져 있다면 먼저 [계산대를 여세요](../register/index.mdx#open). 계산대가 마감된 상태에서는 결제가 기록되지 않습니다.

1. **결제**를 누르고 리더기 타일을 탭하세요. [카드 리더기에서 결제하기](./taking-a-payment.mdx#card-reader)를 참고하세요.
2. **…을(를) …에 보내기**를 누르세요. 버튼에는 결제할 금액과 결제 수단이 표시되며, 계산대가 해당 금액을 리더기로 보냅니다.
3. 고객이 리더기에서 팁 금액 또는 팁 없음을 선택한 다음 결제합니다.
4. 계산대의 결제 내역 창에서 해당 결제 행에 리더기가 받은 전체 금액이 표시되고, 그 아래에 **팁:** 과 팁 금액이 표시됩니다.

주문에 **팁**이라는 수수료 항목이 추가되어 주문 합계가 팁만큼 늘어납니다. 이 팁은 이미 결제된 금액입니다. 영수증에는 주문의 다른 수수료와 함께 표시됩니다. 팁에는 세금이 부과되지 않습니다.

<details>
<summary>팁에 세금 부과하기(개발자용)</summary>

팁에 세금을 부과해야 하는 매장은 `wcpos_payment_tip_fee_taxable` 필터로 과세를 켤 수 있습니다. 이 경우 세금은 팁에서 차감되므로 고객은 리더기에서 선택한 금액 그대로 결제합니다.

</details>

## 팁을 요청하는 리더기 {#which-readers}

| 결제 수단 | 팁을 요청하는 리더기 |
|---|---|
| [Stripe Terminal](../../payment/gateways/stripe-terminal.mdx) | Stripe 대시보드에서 리더기의 팁 기능을 켠 경우 WisePad 3, WisePOS E, S700 및 S710이 지원합니다. M2와 Tap to Pay는 지원하지 않습니다. |
| [SumUp Terminal](../../payment/gateways/sumup-terminal.mdx) | WCPOS 앱과 페어링된 Bluetooth 리더기가 지원합니다. 인터넷에 연결된 리더기는 지원하지 않습니다. |
| [Mollie Terminal](../../payment/gateways/mollie-terminal.mdx) | 모든 리더기가 지원합니다. |

다음 결제 수단은 팁을 요청하지 않습니다.

- [Square Terminal](../../payment/gateways/square-terminal.mdx)
- [PayArc Terminal](../../payment/gateways/payarc-terminal.mdx)
- [Authorize.net Tap to Pay](../../payment/gateways/authorize-net-terminal.mdx): Authorize.net 앱에서 팁을 추가하면 결제가 실패합니다
- [Windcave Terminal](../../payment/gateways/windcave-terminal.mdx)
- [Mercado Pago Terminal](../../payment/gateways/mercadopago-terminal.mdx)
- [PayPal Reader (Zettle)](../../payment/gateways/paypal-reader.mdx)

**카드** 타일은 별도로 사용하는 단말기에서 받은 카드 결제를 기록합니다. 팁은 포함되지 않습니다. [결제 수단](./payment-methods.mdx)을 참고하세요.

## 현금 서랍에서 팁 지급하기 {#pay-out-tips}

직원에게 팁을 현금으로 지급할 때는 현금 서랍 잔액이 맞도록 출금으로 기록하세요. 무료 플러그인에서도 사용할 수 있습니다. **계산대 열기 및 마감**이 필요합니다. [현금 입출금](../register/index.mdx#cash-movements)을 참고하세요.

1. 계산대 표시줄 끝의 아바타를 탭한 다음 **서랍 내 현금**, **출금**을 차례로 탭하세요.
2. 지급할 금액을 키패드로 입력하세요.
3. **사유** 아래의 **팁**을 탭하세요. 금액이 아닌 사유가 채워집니다.
4. **… 출금**을 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[180, 0], [370, 0], [-4, 0], [0, 0], [0, 0], [100, 0], [-14, -36]]} alt="출금 화면: 키패드에 입력된 두 달러, 출금 전후의 서랍 잔액, 선택하여 입력된 팁 사유, $2.00 출금 버튼">

1. **금액** — 꺼낼 금액입니다. 입력하는 대로 표시됩니다.
2. **서랍 내 현금** — 계산대, 현재 예상 현금 잔액, 이번 출금 후 남는 금액입니다.
3. **키패드** — 금액을 입력합니다. 키보드도 사용할 수 있습니다.
4. **팁** — 출금 사유입니다. 탭하면 사유 입력란이 채워지고, 다시 탭하면 지워집니다.
5. **기타…** — 입력란을 비우고 커서를 놓아 사유를 직접 입력할 수 있게 합니다.
6. **사유** — 모든 출금에는 사유가 필요합니다. 사유가 없으면 화면에 **사유 추가**가 표시됩니다.
7. **$2.00 출금** — 금액을 표시합니다. 누르면 출금이 기록됩니다. **취소**를 누르면 서랍 잔액이 그대로 유지됩니다.

</JourneyShot>

확인하려면 **서랍 내 현금**을 탭해 계산대 패널을 연 다음 **서랍 내 예상 현금** 행을 탭해 상세 내역을 여세요. **출금** 아래에 출금 내역과 사유가 표시됩니다. 잘못 기록했다면 해당 내역의 **무효화**를 누르세요. 무효화는 계산대가 열려 있고 현금을 세는 중이 아닐 때만 가능합니다. 무효화한 출금은 복원할 수 없으므로 다시 입력하세요. [문제가 생긴 경우](../register/index.mdx#goes-wrong)를 참고하세요.

## 문제가 생긴 경우 {#goes-wrong}

**리더기가 팁을 요청하지 않았습니다.** [표](#which-readers)를 확인하세요. 일부 결제 수단과 리더기는 팁을 요청하지 않습니다. Stripe에서는 Stripe 대시보드에서 리더기의 팁 기능을 켜세요.

**결제 실패: 단말기에서 다른 금액을 확인했습니다.** 팁을 지원하지 않는 결제 수단으로 리더기가 계산대에서 보낸 금액보다 많이 받았으므로, 계산대는 해당 결제를 실패로 표시하고 주문의 결제 금액에 포함하지 않았습니다.

:::warning
고객에게 다시 청구하기 전에 결제 서비스 제공업체에서 결제 내역을 확인하세요. 그렇지 않으면 중복 청구할 수 있습니다.
:::

제공업체에 청구 내역이 표시되면 그곳에서 환불하세요. 계산대에서는 실패한 결제를 환불할 수 없습니다. 주문에는 여전히 미결제 금액이 남아 있으므로 정상 작동하는 결제 수단으로 다시 받으세요.
