결제 화면의 **레거시** 탭은 POS 안에서 매장의 결제 페이지를 엽니다. 필요한 결제 수단이 **결제** 탭에 없을 때 사용하세요. 매장에서 제공하는 페이지이므로 계산대가 매장에 연결되어 있어야 합니다.

무료 플러그인에서는 이 페이지에 **카드**가 제공되며, [WCPOS Pro](../../getting-started/pro-license.mdx)를 사용하면 매장의 다른 결제 수단도 추가됩니다. 이 페이지에는 **현금**이 없습니다. **결제** 탭의 **현금** 타일로 받으세요. 이 타일에서는 총액의 일부만 받을 수도 있습니다. [분할 결제](./split-payments.mdx)를 참고하세요.

## 결제 페이지에서 결제받기 {#take-payment}

결제 페이지는 주문 전체 금액을 한 번에 받는 용도입니다. 이미 일부 금액을 받았다면 [주문이 일부 결제된 경우](#after-payment)를 참고하세요.

:::note 먼저 계산대를 여세요
**계산대 열기 및 닫기**가 켜져 있다면 여기서 결제받기 전에 계산대를 여세요. [계산대](../../settings/wp-admin/registers.mdx#one-register)를 참고하세요.
:::

1. **결제**를 누른 다음 **레거시** 탭을 누르세요.
2. 결제 페이지가 로드될 때까지 기다리세요. 탭 하단의 **결제 처리**는 로드가 끝날 때까지 회색으로 비활성화됩니다.
3. 페이지에서 결제 수단을 선택하고 요청하는 정보를 입력하세요.
   - **카드**: 먼저 별도의 단말기에서 카드 결제를 받으세요. **카드**는 결제 내역만 기록합니다.
4. **결제 처리**를 누르세요. 판매가 완료되면 결제 완료 화면이 열립니다. [결제 시 영수증](../../receipts/at-checkout.mdx)을 참고하세요.

**결제 처리**를 누른 후 페이지가 로드되지 않으면 다시 결제받기 전에 주문 상태를 확인하세요. [문제가 발생한 경우](#goes-wrong)를 참고하세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[28, 42], [29, 42], [-42, 0], [180, 0], [-42, -5], [80, 30], [430, 40], [-44, 0], [-44, 0], [-60, 0]]} alt="$45.00 주문의 매장 결제 페이지가 표시된 레거시 탭: 결제 설정, 결제 고객 게스트, 쿠폰 필드, 주문 표, 결제 수단 카드(선택됨), 사용자 지정, Stripe Terminal 및 Vipps MobilePay, 결제 처리 버튼">

1. **결제** 탭 — 결제 수단 타일이 있습니다. [결제 패널](./payment-methods.mdx)을 참고하세요.
2. **레거시** 탭 — 현재 페이지입니다.
3. **결제 설정** — 페이지가 깨져 보이거나 페이지의 버튼이 작동하지 않을 때 사용합니다. [결제 문제 해결](./troubleshooting.mdx#checkout-settings-troubleshooting)을 참고하세요.
4. **결제 고객** — 이 주문의 고객입니다. 이름을 클릭하면 청구지 주소와 배송지 주소를 표시하거나 숨길 수 있습니다.
5. **쿠폰 코드** — 여기서 **쿠폰 적용**을 누르면 주문에 쿠폰을 추가합니다.
6. **주문** — 매장에 저장된 주문 항목과 합계입니다.
7. **결제 수단** — 현금을 제외하고 POS에서 활성화된 모든 결제 수단입니다. [결제 설정](../../settings/wp-admin/checkout.mdx#payment-gateways)에 지정된 이름과 순서로 표시됩니다. 기본 결제 수단이 미리 선택되어 있습니다.
8. **결제 처리** — 페이지에서 선택한 수단으로 결제받습니다.
9. **닫기** — 결제하지 않고 장바구니로 돌아갑니다.
10. **잔액** — 이 페이지에서 받을 금액입니다. 여기서는 전액을 받으세요.

</JourneyShot>

주문이 [결제 설정](../../settings/wp-admin/checkout.mdx#order-status-at-the-till)에서 해당 결제 게이트웨이에 지정한 **주문 상태**에 도달하면 판매가 완료됩니다. 결제는 처리되었지만 결제 완료 화면이 열리지 않으면 [문제가 발생한 경우](#goes-wrong)를 참고하세요.

## 주문이 일부 결제된 경우 {#after-payment}

결제 페이지는 주문 전체 금액을 청구하므로 [분할 결제](./split-payments.mdx)의 나머지 금액을 받을 수 없습니다. **결제** 탭에서 한 번이라도 결제받으면 탭 아래에 **전체 금액만 결제 가능**이 표시되고, **레거시** 탭에는 결제 페이지 대신 안내와 결제 수단 목록이 표시됩니다.

다음 중 하나를 선택하세요.

- **타일에서 나머지 금액을 받으세요.** **결제** 탭으로 돌아가 판매를 완료하세요. [분할 결제](./split-payments.mdx)를 참고하세요.
- **결제 페이지에서 전액을 받으세요.** **결제 취소**를 누르고 화면에 표시된 금액을 돌려준 다음 **결제 취소 및 주문 무효화**를 누르세요. POS는 주문을 미결제 상태로 되돌리고 장바구니로 돌아갑니다. **결제**를 누르고 **레거시** 탭을 여세요.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[29, 42], [485, -24], [80, 0], [-44, 0], [130, -20], [-60, 0]]} alt="$10.00 현금 결제 후의 레거시 탭: 결제받은 후에는 레거시 결제 게이트웨이를 사용할 수 없다는 노란색 안내, 그 아래의 결제 수단 목록, 상단의 결제 취소, 잔액 $35.00">

1. **레거시** 탭 — 열려 있습니다.
2. **결제받은 후에는 레거시 결제 게이트웨이를 사용할 수 없습니다** — 결제 페이지는 주문 전체 금액을 받는 용도입니다.
3. **결제 수단** — 목록만 표시되며 여기서 선택할 수는 없습니다.
4. **결제 취소** — 받은 금액을 돌려줍니다. [결제 취소](./cancelling-a-payment.mdx)를 참고하세요.
5. **받은 결제** — 현금 $10.00입니다.
6. **잔액** — 아직 받아야 할 금액입니다.

</JourneyShot>

## 문제가 발생한 경우 {#goes-wrong}

:::warning 다시 결제받기 전에 주문을 확인하세요
탭에 **처리 후 결제 페이지를 로드하지 못했습니다 — 결제 화면을 닫고 주문 상태를 확인한 후 다시 결제하세요.** 라고 표시됩니다. 결제가 이미 처리되었을 수 있습니다. 결제 화면을 닫고 **주문** 페이지에서 해당 판매를 찾아([주문 찾기](../../orders/index.mdx#find-an-order) 참고) 상태를 확인하세요. [결제 설정](../../settings/wp-admin/checkout.mdx#order-status-at-the-till)에서 해당 결제 게이트웨이에 지정한 **주문 상태**에 도달했다면 결제가 완료된 것이므로 다시 결제받지 마세요. 결제 여부가 확실하지 않다면 다시 결제받기 전에 관리자에게 확인을 요청하세요.
:::

<details>
<summary>페이지 대신 회색 자리 표시자가 나타남</summary>

주문을 매장에 저장하는 중이거나 계산대에서 매장의 결제 수단을 불러오는 중입니다. 두 작업이 모두 끝나면 페이지가 열립니다. 오프라인 상태에서는 다시 온라인 상태가 될 때까지 기다립니다.

</details>

<details>
<summary>결제 수단을 불러오지 못함</summary>

탭에 **결제 수단을 불러오지 못했습니다. 다시 시도하세요.** 라고 표시됩니다. **다시 시도**를 누르세요.

</details>

<details>
<summary>주문에 아직 결제 링크가 없음</summary>

탭에 **결제 양식을 로드할 수 없습니다 — 서버에서 이 주문의 결제 링크를 아직 받지 못했습니다. 결제 화면을 닫고 다시 시도하세요.** 라고 표시됩니다. 결제 화면을 닫고 주문이 저장될 때까지 기다린 다음 **결제**를 다시 누르세요.

</details>

<details>
<summary>결제 양식이 로드되지 않음</summary>

탭에 **결제 양식이 로드되지 않았습니다 — 매장 연결을 확인한 후 다시 시도하세요.** 라고 표시됩니다. 계산대에서 매장에 연결할 수 있는지 확인한 다음 **재시도**를 누르세요.

</details>

<details>
<summary>활성화된 레거시 결제 게이트웨이가 없음</summary>

탭에 **POS에 활성화된 레거시 결제 게이트웨이가 없습니다.** 라고 표시됩니다. POS에서 켠 모든 결제 수단에 **결제** 탭의 타일이 있거나, 켜진 결제 수단이 하나도 없는 경우입니다. **결제** 탭에서 결제받거나 [결제 게이트웨이 활성화](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)를 참고하세요.

</details>

<details>
<summary>페이지가 깨져 보이거나 페이지의 버튼이 작동하지 않음</summary>

테마나 플러그인의 스크립트가 방해하고 있을 가능성이 높습니다. [결제 문제 해결](./troubleshooting.mdx#checkout-settings-troubleshooting)을 참고하세요.

</details>

<details>
<summary>결제는 처리되었지만 판매가 완료되지 않음</summary>

주문이 결제 게이트웨이에 지정된 **주문 상태**에 도달하지 않았습니다. [계산대에서 상태를 처리하는 방식](../../settings/wp-admin/checkout.mdx#order-status-at-the-till)을 참고하세요.

</details>

<details>
<summary>결제 게이트웨이가 결제를 거부함</summary>

결제 페이지에 사유가 표시되며 페이지는 열린 상태로 유지됩니다. 대부분의 다른 결제 게이트웨이에서는 계산대에도 게이트웨이 자체 메시지 또는 **결제가 처리되지 않아 이 판매는 미결제 상태입니다. 장바구니는 변경되지 않았습니다.** 라는 메시지가 표시됩니다. [CHECKOUT101](../../error-codes/CHECKOUT101.mdx)을 참고하세요.

</details>
