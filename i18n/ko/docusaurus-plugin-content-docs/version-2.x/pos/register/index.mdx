계산대 세션은 준비금을 세어 금전함에 넣는 순간부터 다시 현금을 세어 마감하는 순간까지 이어집니다. 이 페이지에서는 준비금으로 계산대 열기, 금전함 금액 확인, 현금 입출금 등 하루를 시작하고 운영하는 방법을 설명합니다. 하루가 끝날 때 실사하고 마감하는 방법은 [계산대 마감](../reconciliation.mdx)을 참조하세요.

:::note 이 페이지의 기능을 사용하려면 계산대 기능을 켜야 합니다
여기에서 설명하는 모든 기능은 **계산대 열기 및 마감** 설정이 켜져 있어야 사용할 수 있습니다. 꺼져 있으면 POS가 바로 장바구니로 이동하므로 계산대를 열거나 실사할 필요가 없습니다. 설정은 [계산대](../../settings/wp-admin/registers.mdx#one-register)를 참조하세요. WCPOS Pro에서 매장을 사용하면 매장마다 별도로 설정합니다. [매장 설정](../../stores/setup.mdx)을 참조하세요.
:::

## 계산대 열기 {#open}

계산대가 닫혀 있으면 계산대 표시줄에 **닫힘**이 표시되고 상품에는 **계산대를 열기 전에는 가격 확인만 가능합니다.** 라고 표시됩니다. 상품을 검색하고 가격을 확인할 수 있지만 장바구니에 담을 수는 없습니다. 장바구니 열에는 대신 **계산대 열기** 카드가 표시됩니다.

- **금전함 현금** — 크게 표시된 금액으로, 계산대가 제안하는 준비금이 입력되어 있습니다. [계산대](../../settings/wp-admin/registers.mdx#one-register)의 **시작 준비금**을 사용하며, 설정하지 않았다면 마지막 실사 금액을 사용합니다.
- **기본 준비금** 및 **마지막 실사 금액** — 하나를 누르면 해당 금액으로 다시 입력됩니다. 예상 금액을 보지 않고 실사하는 캐셔에게는 마지막 실사 금액이 표시되지 않습니다.
- **숫자 키패드** — 금전함의 현금을 세어 입력하세요. 첫 번째 키를 누르면 제안된 금액이 대체되므로 먼저 지울 필요가 없습니다. **⌫** 는 마지막 숫자를 지웁니다.
- **시작 차액** — 입력한 금액이 제안된 준비금과 다르면 표시됩니다. 세션에는 직접 센 준비금과 함께 이 차액이 보관됩니다.
- **계산대 열기** — 세션을 시작합니다. 계산대를 열 때 입력한 준비금을 확인하는 메시지가 표시됩니다.
- **마지막 마감** — 이전 마감의 번호와 실사 금액입니다.

다른 기기에서 이미 열린 계산대는 준비금을 입력하라고 요청하지 않습니다. 이 기기는 진행 중인 세션에 참여합니다. [매장, 계산대 및 기기](../../stores/registers-and-devices.mdx#several-devices-on-one-register)를 참조하세요.

## 캐셔 화면 {#cashier-sheet}

계산대 표시줄 끝의 아바타를 누르세요. 여기에서 금전함을 확인하고 다른 사람에게 계산대를 인계할 수 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[325, -31], [140, 0], [147, -17], [-57, 0], [-57, 0], [112, 0]]} alt="캐셔 화면: 금전함 금액, 오늘의 내 매출, 계산대 인계 대상, 계산대 전환, 매장 전환 및 로그아웃">

1. **금전함 잔액** — 계산대의 현재 예상 현금입니다. 누르면 [계산대 패널](#cash-movements)이 열립니다. *보고서 보기* 권한이 없으면 예상 금액을 보지 않고 실사하므로 여기에 금액 대신 판매 건수가 표시됩니다. [접근 권한](../../settings/wp-admin/access.mdx)을 참조하세요.
2. **오늘의 내 매출** — 직접 처리한 판매 내역입니다.
3. **계산대 인계 대상** — 다른 캐셔에게 계산대를 넘깁니다. 금전함은 열린 상태로 유지되고 POS가 해당 캐셔로 다시 로드됩니다. 열려 있는 장바구니는 담당 캐셔를 기다립니다.
4. **계산대 전환** — 계산대가 여러 개일 때만 표시됩니다. 먼저 현재 판매를 완료하거나 보류하세요. [매장 및 계산대 선택](../../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)을 참조하세요.
5. **매장 전환** — 매장이 여러 개일 때만 표시됩니다(WCPOS Pro).
6. **로그아웃** — 열려 있는 계산대는 다음 캐셔를 위해 그대로 유지되며, POS가 먼저 마감할지 묻습니다.

</JourneyShot>

## 현금 입출금 {#cash-movements}

캐셔 화면에서 **금전함 잔액**을 눌러 계산대 패널을 여세요. 맨 위에 금전함에 있어야 할 현금이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[250, 0], [250, 0], [0, 0], [0, 0], [0, 0], [190, 0], [275, 0], [0, -34], [0, -34]]} alt="계산대 패널: 맨 위의 금전함 현금, 세션 매출, 입금, 출금, 판매 없이 열기, 접힌 금전함 예상 금액, 기타 결제 수단, 마지막 마감, X 보고서 인쇄 및 계산대 마감">

1. **금전함 잔액** — 계산대의 예상 현금으로, 판매나 입출금이 발생할 때마다 갱신됩니다. 예상 금액을 보지 않고 실사하는 캐셔에게는 표시되지 않습니다.
2. **세션 매출** — 계산대를 연 이후의 판매 합계와 건수입니다.
3. **입금** — 금전함에 현금을 넣습니다.
4. **출금** — 금전함에서 현금을 꺼냅니다.
5. **판매 없이 열기** — 현금 이동 없이 금전함을 엽니다.
6. **금전함 예상 금액** — 누르면 준비금, 현금 매출, 현금 환불, 모든 입출금 등 금전함 금액의 계산 내역이 펼쳐집니다. 그 아래의 **기타 결제 수단**을 누르면 카드 및 다른 결제 수단의 내역이 펼쳐집니다.
7. **마지막 마감** — 이 세션 이전의 마감으로, 번호와 실사 금액 및 **일치**, **부족**, **초과** 중 어떤 결과로 끝났는지 표시됩니다.
8. **X 보고서 인쇄** — 세션을 마감하지 않고 현재까지의 내역을 보고서로 인쇄합니다.
9. **계산대 마감** — 실사를 시작합니다. [계산대 마감](../reconciliation.mdx#count)을 참조하세요.

</JourneyShot>

### 입금 {#pay-in}

**입금**을 누르세요. 화면에 *금전함에 얼마를 넣나요?* 라는 질문이 표시됩니다. 금액을 입력한 다음 사유를 적으세요. 모든 입출금에는 사유가 필요합니다. 사유를 누르거나 **기타…** 를 누르고 직접 입력하세요.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[392, 0], [100, 0], [0, 0], [0, 0], [0, 0], [150, 0], [0, -34]]} alt="입금 화면: 현재 및 입금 후 금전함 금액, 입금 금액, 숫자 키패드, 격자로 배치된 사유, 입력한 사유 및 넣기 버튼">

1. **현재 및 처리 후 금전함 잔액** — 현재 금전함에 있는 금액과 이번 입출금 후의 금액입니다.
2. **금액** — 입력한 금액입니다.
3. **숫자 키패드** — 금액을 입력하세요.
4. **사유 목록** — **준비금**, **잔돈** 또는 **은행**입니다. 하나를 누르면 사유가 입력되고, 다시 누르면 지워집니다.
5. **기타…** — 사유를 지워 직접 입력할 수 있게 합니다.
6. **사유** — 입출금 내역과 함께 보관할 사유입니다. 여기에 직접 입력하거나 선택한 사유의 문구를 수정하세요.
7. **… 넣기** — 입금 내역을 기록합니다. 금액과 사유가 모두 입력될 때까지 화면에 빠진 항목이 안내됩니다.

</JourneyShot>

### 출금 {#pay-out}

납품업체 대금 지급, 소액 경비, 은행 입금, 팁 등으로 금전함에서 현금을 꺼낼 때는 **출금**을 누르세요. 화면에 *금전함에서 얼마를 꺼내나요?* 라는 질문이 표시되며, 사용 방법은 입금과 같습니다. 휴대폰에서는 사유 목록이 두 열로 배치됩니다.

<JourneyShot manifest={manifest} device="phone" step={6} maxWidth={390} offsets={[[330, 8], [60, 0], [0, 0], [0, 0], [0, 0], [150, 0], [0, 0]]} alt="휴대폰의 출금 화면: 현재 및 출금 후 금전함 금액, 출금 금액, 숫자 키패드, 두 열로 배치된 사유, 입력한 사유 및 꺼내기 버튼">

1. **현재 및 처리 후 금전함 잔액** — 현재 금전함 금액과 출금 후 금액입니다.
2. **금액** — 입력한 금액입니다.
3. **숫자 키패드** — 금액을 입력하세요.
4. **사유 목록** — **공급업체**, **소액 경비**, **은행**, **팁** 또는 **잔돈**입니다.
5. **기타…** — 사유를 직접 입력하세요.
6. **사유** — 입출금 내역과 함께 보관할 사유입니다.
7. **… 꺼내기** — 출금 내역을 기록합니다.

</JourneyShot>

**판매 없이 열기**는 현금 이동 없이 금전함을 엽니다. 이때도 *금전함을 여는 이유가 무엇인가요?* 라고 묻습니다. **잔돈**, **실수**, **금전함 확인** 또는 **기타…** 를 누른 다음 **금전함 열기**를 누르세요.

### 입출금 내역 확인 {#movements}

입출금마다 **$1.00 입금됨**과 같은 확인 메시지가 **실행 취소**와 함께 표시됩니다. 세션의 모든 입출금 내역을 보려면 **금전함 예상 금액**을 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={8} offsets={[[250, 0], [200, 0], [150, -42], [150, -56], [0, 26], [0, -34]]} alt="금전함 예상 금액이 펼쳐진 계산대 패널: 준비금, 현금 매출과 환불, 사유 및 무효화가 있는 입금과 출금 내역, 계산대 마감">

1. **금전함 잔액** — 입출금 내역이 이미 반영된 금액입니다.
2. **준비금** — 세션 시작 금액과 시작 시각입니다. 이 금액에서 시작하여 현금 매출을 더하고 현금 환불을 뺍니다.
3. **입금** — 입금 횟수, 합계, 사유가 표시된 개별 내역입니다.
4. **출금** — 꺼낸 현금에 대해서도 같은 내역이 표시됩니다.
5. **무효화** — 해당 입출금을 취소합니다. 계산대가 열려 있을 때만 가능합니다.
6. **계산대 마감** — 하루가 끝나면 누르세요. [계산대 마감](../reconciliation.mdx#count)을 참조하세요.

</JourneyShot>

## 실사 및 마감 {#close}

하루가 끝나면 패널에서 **계산대 마감**을 누르고 금전함의 현금을 세어 마감 기록을 저장하세요. 실사, 마감 기록, 금전함 금액이 맞지 않을 때의 조치는 [계산대 마감](../reconciliation.mdx#count)을 참조하세요.

## 문제가 발생한 경우 {#goes-wrong}

**입출금을 잘못 입력했습니다.** 표시되는 메시지에서 **실행 취소**를 누르거나 **금전함 예상 금액** 아래의 해당 내역에서 **무효화**를 누르세요. 어느 방법이든 내역이 패널에서 사라지고 금전함 금액이 이전으로 돌아갑니다. 무효화한 입출금은 복원할 수 없으므로 다시 입력하세요. 무효화는 계산대가 열려 있을 때만 가능하며 실사 중에는 사용할 수 없습니다.

**버튼에 “금액을 입력하세요” 또는 “사유를 추가하세요”가 표시됩니다.** 입출금 입력이 완료되지 않았습니다. 금액을 입력한 다음 사유를 누르거나 직접 입력하세요.

**패널에 “다음 동기화 시 금액이 반영됩니다”가 표시됩니다.** 계산대가 매장에서 금액 데이터를 받기를 기다리고 있으며, 데이터가 도착할 때까지 **계산대 마감**이 비활성화됩니다. 페이지를 그대로 열어 두고 연결을 확인하세요.

**입출금이 거부되었습니다.** 패널 상단 알림에 매장에서 거부한 건수가 표시됩니다. 알림의 **다시 시도**를 누르세요.

**다른 단말기에서 계산대를 마감했습니다.** 계산대 열기 카드에 마감한 사람과 시각이 표시됩니다. 금전함의 현금을 세고 다시 여세요.

**다른 사람이 실사 중입니다.** “다른 단말기에서 실사 중”에 실사를 시작한 사람과 시각이 표시됩니다. 실사가 끝날 때까지 기다리세요.

**“이 매장에 계산대가 없습니다” 또는 “이 매장의 계산대에 연결할 수 없습니다”.** POS에서 열 수 있는 계산대가 없습니다. 연결을 확인하고 **다시 시도**를 누르세요. 매장에 실제로 계산대가 없다면 관리자가 추가해야 합니다. [매장, 계산대 및 기기](../../stores/registers-and-devices.mdx#where-the-settings-live)를 참조하세요.

**마감 시 실사 금액이 맞지 않습니다.** [계산대 마감](../reconciliation.mdx#goes-wrong)을 참조하세요.

:::info WCPOS Pro 사용 시
Pro에서는 매장별 계산대 추가와 보고서의 전체 마감 내역을 사용할 수 있습니다. [Pro에서 계산대 추가](../../settings/wp-admin/registers.mdx#more-registers-with-pro)를 참조하세요.
:::
