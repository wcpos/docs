판매 시 할인을 적용하는 방법은 두 가지입니다. 상품 가격을 누르면 해당 상품의 가격을 낮출 수 있습니다. 추가 메뉴에서 **할인 추가**를 선택하면 주문 전체에 정액 할인, 정률 할인 또는 쿠폰을 적용할 수 있습니다.

## 개별 상품 할인하기 {#quick-discounts}

항목의 가격을 누르세요. 그 아래에 키패드가 열리고, 상단에는 빠른 할인 키가 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-120, 0], [-88, 0], [-88, -24], [65, 0], [-24, 0]]} alt="$45.00 항목에서 가격 키패드를 열고 −10%를 누른 모습: 새 가격 $40.50 위에 $45.00 −10%가 표시되며, 빠른 할인 키 세 개, 숫자 키, 삭제 키와 완료 키가 보입니다">

1. **새 가격** — 상품에 적용될 가격과 이전 가격에서 계산된 내역입니다.
2. **빠른 할인 키** — 각 키에 표시된 비율만큼 항목 가격을 할인합니다. 잘못 눌렀다면 **완료**를 누르기 전에 다른 키를 누르세요. 처음 선택한 할인이 새 할인으로 바뀝니다. 강조 표시된 키가 현재 적용 중인 키입니다. 키는 직접 설정할 수 있습니다. [빠른 할인 키 설정하기](#quick-discount-keys)를 참고하세요.
3. **숫자** — 할인 키 대신 새 가격을 직접 입력할 수 있습니다.
4. **삭제** — 마지막 숫자를 지웁니다.
5. **완료** — 새 가격을 적용합니다. 키패드 바깥을 눌러도 동일하게 적용됩니다.

</JourneyShot>

**완료**를 누르면 항목 합계가 수량 × 새 가격으로 바뀝니다.

빠른 할인 키는 키패드를 열었을 때의 항목 가격을 기준으로 계산합니다. 추가로 10%를 할인하려면 **완료**를 누른 다음, 키패드를 다시 열고 **−10%** 를 누르세요.

<details>
<summary>예: $45.00 상품에 할인 키 두 개 사용하기</summary>

**−10%** 를 누르면 $40.50이 표시됩니다. 대신 **−5%** 를 누르면 $42.75가 표시됩니다. 다시 **−10%** 를 누르고 **완료**를 누르면 항목 가격이 $40.50으로 설정됩니다. 키패드를 다시 열고 **−10%** 를 누르면 $40.50이 $36.45로 바뀝니다.

</details>

### 새 가격 입력하기 {#line-item-discounts}

가격 맞춤, 직원 가격 등 일회성 가격을 적용하려면 고객이 지불할 가격을 입력하고 **완료**를 누르세요. 키보드를 사용하는 경우 가격을 입력하고 **Enter**를 누르세요.

각 항목의 가격은 개별적으로 설정됩니다. 서로 다른 상품 세 개에 10% 할인을 적용하려면 각 항목에서 할인하거나, [할인 추가](#order-level-discounts)로 주문 전체에 할인하세요. 항목에서 변경할 수 있는 나머지 내용은 [주문 항목](line-items.mdx#price)을 참고하세요.

## 주문 전체 할인하기 {#order-level-discounts}

장바구니 상단의 **+** 를 누르고 **할인 추가**를 선택하세요. 대화상자가 **빠른 할인** 탭으로 열립니다. 할인 값을 입력하고 **$** 또는 **%** 를 선택한 다음 **할인 추가**를 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[0, 0], [0, 0], [0, 0], [12, 46], [50, -52]]} alt="빠른 할인 탭이 열린 할인 추가 대화상자: 빠른 할인 및 쿠폰 탭, 입력값 10, 퍼센트로 설정된 달러/퍼센트 전환 버튼, 할인 추가 버튼이 보이며, 옆에는 $45.00 Aim Analog Watch가 담긴 장바구니가 있습니다">

1. **빠른 할인** — 이 주문에 정액 또는 정률 할인을 적용합니다.
2. **쿠폰** — 대신 매장에 있는 쿠폰을 사용합니다. [쿠폰 적용하기](#coupon)를 참고하세요.
3. **금액** — 누른 다음 키패드로 입력하세요.
4. **$ 또는 %** — 고정 금액 또는 주문 금액의 일정 비율을 할인합니다.
5. **할인 추가** — 주문에 할인을 적용합니다.

</JourneyShot>

주문 합계 영역에 할인이 표시되고, 항목 합계도 그에 맞게 조정됩니다.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[12, 46], [100, 0], [50, 0], [0, 0]]} alt="$45.00 시계에 10% 할인을 적용한 장바구니: 취소선이 그어진 항목 합계 $45.00 아래에 $40.50이 표시되고, 소계 $45.00, $4.50을 차감하는 할인 (10%) 행과 삭제 버튼, 결제 $40.50이 보입니다">

1. **항목 합계** — 취소선이 그어진 할인 전 가격과 고객이 지금 지불할 금액입니다.
2. **소계** — 할인 전 주문 금액입니다.
3. **할인 (10%)** — 적용된 할인과 차감 금액입니다. **할인**만 표시되면 정액 할인입니다. 삭제하려면 **✕** 를 누르세요.
4. **결제** — 새 합계 금액입니다.

</JourneyShot>

정액 할인은 각 상품의 가격에 비례하여 배분됩니다. 정률 할인은 모든 상품에 적용됩니다. 주문에 할인을 여러 개 추가할 수 있으며, 각 할인은 별도 행에 표시됩니다.

**할인 추가**는 오프라인에서도 작동하며, 세금은 할인된 가격을 기준으로 계산됩니다. 매장에 쿠폰이 생성되지는 않습니다.

### 할인 삭제하기 {#remove-discount}

합계 영역에서 해당 할인 행의 **✕** 를 누르세요. 항목 합계가 이전으로 돌아가고 **할인이 삭제되었습니다**라는 메시지가 표시됩니다. 개별 항목에서 변경한 가격은 설정한 대로 유지됩니다.

## 쿠폰 적용하기 {#coupon}

**할인 추가**에서 **쿠폰** 탭으로 전환하세요. 무료 플러그인에서도 사용할 수 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[-40, 0], [10, 46], [24, -52]]} alt="쿠폰 탭이 열린 할인 추가 대화상자: 쿠폰 선택 필드, 그 옆의 새 쿠폰 버튼, 적용 버튼이 보이며, 옆에는 할인 (10%) 적용 후 시계 가격이 $40.50인 장바구니가 있습니다">

1. **쿠폰 선택** — 코드의 일부를 입력하여 쿠폰을 찾으세요.
2. **새 쿠폰** (WCPOS Pro) — 즉시 쿠폰을 만듭니다. [계산대에서 쿠폰 만들기](#new-coupon)를 참고하세요.
3. **적용** — 쿠폰 조건을 확인하고 주문에 적용합니다.

</JourneyShot>

이 주문에 사용할 수 없는 쿠폰은 그 이유를 표시합니다. 각 메시지의 의미, 쿠폰 삭제 및 오프라인 쿠폰 사용에 대해서는 [쿠폰 적용하기](../../coupons/applying-coupons.mdx)를 참고하세요.

## 계산대에서 쿠폰 만들기 {#new-coupon}

:::info Pro 기능
계산대에서 쿠폰을 만들려면 [WCPOS Pro](../../getting-started/pro-license.mdx)가 필요합니다. 무료 플러그인에서는 **새 쿠폰**에 **Pro로 업그레이드**가 표시됩니다.
:::

1. **쿠폰** 탭에서 **새 쿠폰**을 누르세요.
2. 코드를 입력하거나 **생성**을 누르세요.
3. 할인 유형을 선택하고 할인할 값을 입력하세요.
4. **만료일**과 쿠폰에 필요한 다른 조건을 설정하세요.
5. **쿠폰 추가**를 누르세요. 쿠폰이 먼저 매장에 저장된 다음 이번 판매에 적용되고, **… 저장 후 이번 판매에 적용되었습니다**라는 메시지가 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-40, 0], [22, -40], [-40, 0], [100, 0], [-60, 0], [0, 0], [50, -52]]} alt="코드 SPRING10이 입력된 쿠폰 추가 양식: 코드 옆의 생성 링크, 백분율로 설정된 할인 유형, 만료일 선택 옵션, 일회용 스위치, 최소 주문 금액부터 시작하는 추가 쿠폰 조건 버튼, 쿠폰 추가 버튼이 보이며, 옆에는 동일한 장바구니가 있습니다">

1. **코드** — 고객이 사용할 코드입니다. 유일한 필수 입력 필드입니다.
2. **생성** — 코드를 자동으로 만듭니다.
3. **할인** — 정률 할인, 주문 정액 할인, 상품 정액 할인 중 하나와 할인할 값을 설정합니다.
4. **만료일** — 쿠폰의 유효 기간입니다.
5. **일회용** — 한 번 사용하면 더 이상 사용할 수 없습니다.
6. **추가 조건** — **최소 주문 금액**, **총 사용 횟수**, **함께 사용 불가** 등을 통해 WooCommerce 쿠폰 조건을 하나씩 추가합니다.
7. **쿠폰 추가** — 쿠폰을 매장에 저장한 다음 이번 판매에 적용합니다.

이 쿠폰은 실제 WooCommerce 쿠폰이므로 다음 판매에서도 사용할 수 있으며, **WP Admin → 마케팅 → 쿠폰**과 보고서에도 표시됩니다. 쿠폰 화면에서 쿠폰을 만들려면 [쿠폰 만들기](../../coupons/index.mdx#creating-coupons)를 참고하세요.

## 빠른 할인 키 설정하기 {#quick-discount-keys}

키는 기기별로 설정됩니다. 장바구니 상단의 슬라이더 버튼을 눌러 **장바구니 설정**을 여세요. **빠른 할인**에는 캐셔가 가격 키패드에서 보는 모습 그대로 키가 표시됩니다. 새 기기의 기본값은 5%, 10%, 15%입니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [0, 0], [0, 0], [-34, 0]]} alt="빠른 할인 행이 있는 장바구니 설정: 가격 키패드와 같은 모습으로 5%, 10%, 15% 키 세 개가 표시되고, 열 아래에서 수량 스위치는 켜져 있으며 분할 스위치는 꺼져 있습니다">

1. **첫 번째 키** — 누른 다음 5나 12.5처럼 100 이하의 백분율을 입력하세요.
2. **두 번째 키** — 같은 방식으로 설정합니다.
3. **세 번째 키** — 같은 방식으로 설정합니다. 키는 최대 세 개까지 사용할 수 있습니다.
4. **분할** — 켜면 항목의 수량 아래에 **분할**이 표시됩니다. [같은 상품에 다른 가격 적용하기](#split)를 참고하세요.

</JourneyShot>

키를 없애려면 해당 키에 0을 입력하세요. 남은 키가 행을 채우도록 늘어납니다. 키가 하나도 없으면 가격 키패드에 숫자만 표시됩니다. 정액 할인 키는 없습니다. 정액 할인을 하려면 새 가격을 입력하거나 [할인 추가](#order-level-discounts)를 사용하세요.

## 같은 상품에 다른 가격 적용하기 {#split}

고객이 같은 상품 세 개를 구매하고 그중 한 개를 더 낮은 가격에 구매하는 경우를 예로 들겠습니다. [장바구니 설정](index.mdx#columns)의 **열 → 수량**에서 **분할**을 켜세요. 수량이 하나보다 많은 항목의 수량 아래에 **분할**이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 36], [-38, 0], [12, 28]]} alt="단가 $45.00인 Aim Analog Watch 세 개가 담긴 장바구니 항목: 합계는 $135.00이며 수량 아래에 분할이 표시됩니다">

1. **분할** — 상품 한 개당 한 항목이 되도록 나눕니다.
2. **가격** — 새로 나뉜 각 항목은 변경하기 전까지 이 가격을 유지합니다.
3. **항목 합계** — 세 개를 모두 합한 금액입니다. **분할** 후에는 새로 나뉜 각 항목에 해당 합계가 표시됩니다.

</JourneyShot>

**분할**을 누르면 상품 한 개당 한 항목으로 나뉘며 가격은 모두 동일하게 유지됩니다. 할인하려는 항목의 가격을 낮추세요. 수량이 2.5이면 수량이 하나인 항목 두 개와 수량이 0.5인 항목 하나로 나뉩니다. [주문 항목 분할하기](line-items.mdx#splitting-line-items)를 참고하세요.

## 문제가 발생한 경우 {#goes-wrong}

- **실수로 가격 키패드를 열었습니다.** 강조 표시된 키를 다시 누르거나, 입력값이 비워질 때까지 **삭제**를 누른 다음 **완료**를 누르세요. 가격이 그대로 유지됩니다. 키보드에서는 **Escape**를 누르세요.
- **항목에 잘못된 가격을 설정했습니다.** 가격을 다시 눌러 올바른 값을 입력하거나, 항목을 삭제한 다음 상품을 다시 추가하여 매장 가격부터 시작하세요.
- **영보다 큰 금액을 입력하세요** 또는 **0 초과 100 이하의 백분율을 입력하세요** — **할인 추가**의 입력값이 비어 있거나 허용 범위를 벗어났습니다.
- **… 이미 주문에 적용되어 있으며 다른 쿠폰과 함께 사용할 수 없습니다.** — **개별 사용만 허용**으로 설정된 쿠폰이 주문에 적용되어 있습니다. 먼저 해당 쿠폰을 삭제하거나 할인을 추가하지 마세요.
- **새 쿠폰이 비활성화되어 있습니다** — 툴팁에 이유가 표시됩니다. **Pro로 업그레이드**, 권한 없음(관리자가 **WP Admin → POS → 설정 → 접근**에서 권한을 부여합니다) 또는 **매장에 연결할 수 있을 때 쿠폰이 생성됩니다** 중 하나입니다. 매장에 이미 있는 쿠폰은 계속 적용할 수 있습니다.
- **… 저장되었지만 적용되지 않았습니다** — 쿠폰이 매장에 저장되어 있지만 이 주문이 쿠폰 조건에 맞지 않습니다. 조건을 확인하거나, 주문이 조건에 맞게 되면 **쿠폰 선택**에서 다시 선택하세요.
- **수수료는 음수일 수 없습니다. 대신 할인 추가를 사용하세요.** — POS에서는 음수 수수료로 금액을 차감할 수 없습니다. [할인 추가](#order-level-discounts)를 사용하세요. **세금 포함 금액**을 비롯한 수수료 관련 내용은 [수수료](index.mdx#fees)를 참고하세요.

## POS 할인과 WooCommerce 쿠폰 비교 {#pos-discounts-vs-woocommerce-coupons}

**항목 가격**(빠른 할인 키 또는 직접 입력한 가격) — 캐셔가 개별 항목에 설정합니다. 별도 조건이 없습니다. 가격 맞춤, 직원 가격 또는 손상된 상품에 적합합니다.

**할인 추가** — 캐셔가 주문 전체에 설정합니다. 자체 조건은 없지만 **개별 사용만 허용**으로 설정된 쿠폰과 함께 사용할 수 없습니다. 일회성 정액 또는 정률 할인에 적합합니다.

**WooCommerce 쿠폰** — 사용 한도, 상품, 최소 주문 금액, 만료일, 고객 이메일 등 설정된 조건에 따라 적용됩니다. 매장에서 설정하거나([쿠폰 만들기](../../coupons/index.mdx#creating-coupons) 참고), Pro를 사용하여 계산대에서 만들 수 있습니다. 적용 범위를 제한하고 보고서로 확인하려는 프로모션에 적합합니다.

## 알려진 제한 사항 {#known-limitations}

- **자동 할인 규칙은 없습니다.** POS는 “2개 구매 시 1개 무료”와 같은 할인을 자동으로 적용하지 않습니다. 정해진 조건이 있는 프로모션에는 WooCommerce 쿠폰을 사용하세요.
- **빠른 할인 키는 정률 할인만 지원합니다.** 정액 할인을 하려면 새 가격을 입력하거나 **할인 추가**에서 **$** 를 사용하세요.

## 할인 기록 방식 {#how-discounts-are-recorded}

아래 내용은 계산대에서의 작업 방식을 바꾸지 않습니다. 보고서와 영수증에 무엇이 표시되는지, 이전 주문이 다르게 보일 수 있는 이유를 설명합니다. 가격 저장 방식을 포함한 자세한 배경은 [POS 할인 참조](../../reference/pos-discounts.mdx)에 있습니다.

### 가격 변경과 쿠폰을 다르게 기록하는 이유 {#why-tracked-differently}

빠른 할인 키나 직접 입력한 가격은 WooCommerce의 할인가 기록 방식과 동일하게 기록됩니다. 상품은 캐셔가 설정한 가격으로 판매됩니다. 따라서 **할인** 합계는 영으로 유지되고, 쿠폰은 낮아진 가격을 기준으로 계산되며, **할인 상품 제외**가 설정된 쿠폰은 가격이 낮아진 상품을 제외합니다.

**할인 추가**는 쿠폰 항목으로 기록되고, WooCommerce 쿠폰은 해당 쿠폰으로 기록되므로 둘 다 **할인** 합계에 포함됩니다.

<details>
<summary>WooCommerce의 쿠폰 및 할인가 기록 방식</summary>

WooCommerce에 내장된 할인 개념은 **쿠폰** 하나뿐입니다. 쿠폰은 주문에 속합니다. 별도 필드에 기록되고 보고서의 **할인** 열에 집계되며, 사용 한도나 만료일 같은 자체 조건을 갖습니다.

WooCommerce에서 **할인가**는 할인으로 취급되지 않습니다. 단순히 상품의 현재 가격입니다. 할인 중인 상품이 판매되면 주문에는 지불한 가격만 기록됩니다. 보고서에서는 이를 일반 매출로 집계합니다.

고객은 영수증에서 절약한 금액을 확인하기를 기대합니다. 그래서 WCPOS는 각 항목에 새 가격과 함께 정상가도 기록합니다. 이를 통해 영수증에서 가격 인하로 절약한 금액과 쿠폰 할인을 별도로 표시할 수 있으며, 중복 집계하거나 WooCommerce의 합계 및 보고서를 변경하지 않습니다.

</details>

### POS 가격 변경과 쿠폰의 상호 작용 {#how-pos-price-changes-interact-with-coupons}

캐셔가 상품 가격을 $18에서 $16으로 낮춘 다음 쿠폰을 적용한다고 가정하겠습니다. 쿠폰은 $18이 아닌 **$16**을 기준으로 계산하므로, 고객에게 원래 가격 기준으로 할인이 중복 적용되지 않습니다.

- 계산대에서 가격을 낮춘 상품은 WooCommerce에서 할인가가 설정된 상품과 마찬가지로 할인 상품으로 취급됩니다. 계산대에서 가격을 올린 상품은 해당하지 않습니다. **할인 상품 제외**가 설정된 쿠폰은 할인 상품을 제외하며, **할인 상품 제외**가 설정된 장바구니 정액 쿠폰은 장바구니에 할인 상품이 하나라도 있으면 사용할 수 없습니다.
- 쿠폰을 삭제해도 각 항목은 계산대에서 설정한 가격을 유지합니다.

:::note 개발자 참조
**할인 추가** 항목은 `pos-discount`, `pos-discount-2` 등의 이름을 가진 쿠폰 항목입니다. `wcpos_item_is_on_sale` 필터는 할인 상품으로 취급할 대상을 변경합니다. 계산대에서 설정한 가격의 저장 방식과 다른 필터는 [POS 할인 참조](../../reference/pos-discounts.mdx)를 참고하세요.
:::

### 음수 수수료가 있는 주문 {#discount-fee-tax}

2.0 이전에는 캐셔가 음수 수수료로 주문 금액을 차감할 수 있었습니다. 현재 POS에서는 허용되지 않지만, 이전 주문에는 음수 수수료가 남아 있을 수 있습니다.

<details>
<summary>WCPOS의 음수 수수료 과세 방식과 WooCommerce와의 차이</summary>

WCPOS는 **수수료 자체의 세금 설정**에 따라 음수 수수료에 세금을 적용합니다. 과세 상태가 **없음**이면 세금이 적용되지 않으며 수수료 금액만큼 차감됩니다. 수수료가 `-10.00`이면 고객은 10만큼 적게 지불합니다. **과세 대상**으로 두면 해당 수수료의 세금 클래스에 따라 과세되므로 그 세금도 함께 차감됩니다.

WooCommerce 자체의 처리 방식은 다릅니다. 수수료의 과세 상태를 무시하고 음수 수수료의 세금을 주문의 다른 모든 항목에 분산합니다. **세금 포함 가격 입력**이 *예*로 설정된 매장에서는 세율이 20%일 때 `-10.00` 수수료로 **12.00**을 차감하기도 합니다. WCPOS는 캐셔가 입력한 금액을 유지합니다.

이 동작은 주문을 여는 앱이 아니라 주문에 따라 결정됩니다. **WP Admin → 주문**에서 POS 주문을 다시 계산해도 유지됩니다. POS에서 생성하지 않은 주문은 WooCommerce의 동작을 따릅니다.

:::note 음수 수수료의 세금
수수료의 과세 상태가 **없음**이면 고객은 올바른 합계 금액을 지불하지만 **주문에 기록된 세금은 줄어들지 않으므로**, 낮아진 합계에 해당하는 세금보다 약간 높게 기록됩니다. 차이가 나더라도 과세 당국에 유리한 방향이며, 그 반대는 아닙니다. 과세 대상인 음수 수수료는 해당 세금 클래스의 세율에 따라 세금을 차감합니다. **할인 추가**로 만든 할인은 쿠폰 항목이므로 낮아진 가격을 기준으로 세금이 계산됩니다.
:::

</details>

### v1.9.0에서 변경된 내용 {#what-changed-in-v190}

v1.8에서 업그레이드한 후 영수증과 보고서의 **할인** 합계가 **0**으로 표시된다면, 그 이유는 다음과 같습니다. 이전 버전은 계산대에서의 가격 변경을 WooCommerce 할인으로 기록했으며, 이 때문에 쿠폰 계산에 문제가 있었습니다. 추가로 적용한 쿠폰이 원래 가격을 기준으로 계산되어 고객에게 받아야 할 금액보다 적게 청구되었습니다. v1.9.0부터는 WooCommerce가 할인 상품을 기록하는 방식과 동일하게 계산대에서 설정한 가격이 **곧** 항목 가격이며, 쿠폰만 할인으로 집계됩니다. [가격 변경과 쿠폰을 다르게 기록하는 이유](#why-tracked-differently)를 참고하세요.

#### 실제 사용에 미치는 영향 {#what-this-means-for-you}

<details>
<summary>v1.9.0 이후의 영수증, 보고서, 쿠폰 및 저장된 가격</summary>

- **영수증**에는 정상가, 정상가 대비 절약 금액, 여기에 쿠폰 할인까지 합친 **총 절약 금액**을 표시할 수 있습니다. 가격 인하로 절약한 금액은 WooCommerce의 **할인** 필드와 별도로 유지됩니다.
- **보고서**는 항목 가격만 변경된 경우 `discount_total = 0`을 표시합니다. 쿠폰만 집계되며, **할인 추가**도 쿠폰으로 집계됩니다.
- **쿠폰**은 계산대에서 가격을 낮춘 상품에도 올바르게 계산됩니다.
- 항목의 POS 메타데이터(`_woocommerce_pos_data`)에 **정상가와 판매가가 저장되므로**, WooCommerce의 할인 합계를 변경하지 않고도 영수증에 절약 금액을 표시할 수 있습니다.

</details>

#### 영수증에 원래 가격과 절약 금액 표시하기 {#showing-the-original-price-and-saving-on-receipts}

가격을 표시하는 기본 제공 템플릿은 상품이 할인 중이거나 계산대에서 가격이 변경된 경우 정상가와 절약 금액을 포함합니다. WCPOS가 주문 전체의 절약 금액을 계산할 수 있으면 **총 절약 금액**도 표시합니다. 이 합계는 정상가 대비 절약 금액과 쿠폰 할인을 중복 없이 합산합니다.

<details>
<summary>v1.9.0 이전에 만든 영수증 템플릿 업데이트하기</summary>

갤러리에서 복사한 템플릿은 사용자의 개별 사본이며, WCPOS 업데이트로 덮어쓰지 않습니다. 이 변경 이전에 영수증을 만들었다면 다음 중 한 방법을 사용하세요.

1. 기본 제공 템플릿의 새 사본에서 **템플릿 사용**을 클릭하거나
2. [영수증 데이터 참조](../../receipts/receipt-data.mdx#displaying-regular-price-and-savings)에 있는 필드를 템플릿에 추가하세요.

절약 금액 관련 필드:

| 필드 | 의미 |
|-------|---------|
| `lines[].regular_price_display` | 기록된 정상 단가 |
| `lines[].selling_price_display` | 쿠폰 적용 전 판매 단가 |
| `lines[].unit_savings_display` | 상품 한 개당 절약 금액 |
| `lines[].line_regular_total_display` | 항목의 정상가 기준 합계 |
| `lines[].line_savings_display` | 항목의 총 절약 금액 |
| `totals.sale_savings_total_display` | 상품 카탈로그의 할인과 계산대 가격 변경으로 인한 정상가 대비 판매가의 총 절약 금액 |
| `totals.discount_total_display` | WooCommerce 할인 합계: **할인 추가**를 포함한 쿠폰 |
| `totals.total_saved_display` | 정상가 대비 절약 금액과 WooCommerce 할인을 합산한 금액 |
| `totals.total_saved_complete` | 합산 금액이 완전하여 표시해도 되는지 여부 |

이 필드 대부분은 주문에 근거 데이터가 있을 때만 존재합니다. 사용자 정의 템플릿에서는 각 필드의 존재 여부를 확인하고, 금액이 불완전하거나 절약한 금액이 없으면 **총 절약 금액** 행을 숨겨야 합니다. 구현 방식은 [영수증 데이터 참조](../../receipts/receipt-data.mdx#totals)를 참고하세요.

WooCommerce 보고서는 변경되지 않습니다. 할인 합계에는 쿠폰만 포함되며, 할인가나 계산대 가격 변경으로 절약한 금액은 포함되지 않습니다. 영수증에는 `totals.total_saved`를 사용하고, 절약 금액이 보고서에서도 WooCommerce 할인으로 표시되어야 한다면 쿠폰이나 **할인 추가**를 사용하세요.

</details>
