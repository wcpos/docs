시작한 판매는 결제가 완료될 때까지 열린 주문으로 유지됩니다. 물건을 하나 더 가지러 간 고객, 주문을 추가하며 나중에 결제할 테이블, 수령 대기 중인 전화 주문 등 여러 판매를 동시에 진행할 수 있습니다. 각 주문은 이 기기에 저장되어 장바구니 아래의 개별 탭에서 대기하며, 다른 주문으로 전환해도 내용이 사라지지 않습니다.

:::tip 1.x에서 전환하셨나요?
**서버에 저장**은 이제 **주문 동기화**이며, **무효화**는 더 이상 결제 옆의 빨간색 버튼이 아닙니다. 둘 다 **주문 세부 정보**에 있습니다. **결제** 옆의 **⋮** 버튼을 누르세요. [주문 세부 정보](#order-details)를 참고하세요.
:::

## 주문 간 전환 {#switch}

장바구니 아래의 탭 표시줄에는 열린 주문마다 탭이 하나씩 오래된 순서대로 표시됩니다. 탭을 누르면 해당 장바구니가 열립니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-25, -6], [-25, -6], [-20, -6], [-26, -6], [-20, -18], [0, 0]]} alt="열린 주문이 여러 개 있는 POS: 장바구니 아래 탭 표시줄에 밑줄이 있는 현재 주문, 옆의 다른 주문, 열린 주문 수, 더하기 버튼이 있으며, 표시줄 위에는 주문 세부 정보 및 결제 버튼이 있음">

1. **열린 장바구니** — 현재 화면의 주문이며 밑줄이 표시됩니다. 고객 이름 또는 **비회원**과 합계가 표시됩니다.
2. **다른 열린 주문** — 누르면 해당 주문으로 전환합니다. 이전 장바구니는 그대로 유지됩니다.
3. **주문 수** — 열려 있는 주문 수입니다. 탭을 모두 표시할 공간이 없을 때 나타납니다. 누르면 [목록](#open-orders-list)이 열립니다.
4. **+** — [새 주문](#new-order)을 시작합니다.
5. **⋮** — [주문 세부 정보](#order-details): 주문을 전달, 인쇄, 동기화 또는 무효화합니다.
6. **결제** — 현재 화면의 주문을 결제합니다. [결제](../checkout/index.mdx)를 참고하세요.

</JourneyShot>

- **키보드:** 웹에서 탭에 포커스가 있을 때 **왼쪽** 및 **오른쪽** 화살표 키로 인접한 주문으로 이동합니다.
- **터치:** 탭 표시줄을 스와이프하여 탭을 스크롤합니다.
- **경과 시간:** 주문을 연 지 한 시간 이상 지나면 합계 옆에 경과 시간이 경고 색상으로 표시되어 잊고 있던 판매를 쉽게 발견할 수 있습니다.
- **상태:** 결제가 진행 중인 주문은 탭에 합계 대신 상태가 표시됩니다. 예를 들어 **결제 중**, **일부 결제됨 · $20.00 미결제**, **단말기 대기 중 · $45.00** 등입니다. [분할 결제](../checkout/split-payments.mdx)를 참고하세요.

탭 표시줄에는 현재 매장과 계산대에서 본인이 연 주문이 표시됩니다. 동료의 주문과 다른 계산대에서 본인이 연 주문은 각각의 탭 표시줄에서 대기합니다.

## 새 주문 시작 {#new-order}

**+** 버튼을 누르세요. 빈 장바구니가 열리고 해당 칸에 **+ 새 주문**이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[3, -41], [22, -42], [181, 0]]} alt="빈 장바구니: 탭 표시줄 끝의 더하기 칸에 새 주문이 표시되고 밑줄이 있으며, 이전 주문은 옆에서 대기하고 상품 검색은 사용할 준비가 된 상태">

1. **+ 새 주문** — 현재 보고 있는 빈 장바구니입니다.
2. **이전 주문** — 아직 열려 있습니다. 누르면 돌아갑니다.
3. **검색** — 첫 번째 상품을 추가합니다. [검색 및 필터링](../product-panel/search-filtering.mdx)을 참고하세요.

</JourneyShot>

빈 장바구니는 아직 주문이 아닙니다. 첫 번째 상품을 추가하면 주문이 되고 자체 탭이 생기므로 **+** 버튼을 실수로 눌러도 주문이 남지 않습니다. 휴대폰에서는 장바구니가 비어 있는 동안 **장바구니** 탭의 배지에 **새 주문**이 표시됩니다.

## 모든 열린 주문 보기 {#open-orders-list}

탭 표시줄에 모든 탭을 표시할 공간이 없으면 맨 앞에 주문 수가 나타납니다. 누르면 **열린 주문**에 모든 주문이 오래된 순서대로 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 0], [83, -23], [0, 0], [-34, 0]]} alt="열린 주문 목록: 주문마다 한 행에 고객, 항목, 합계, 경과 시간, 상태가 표시되며 현재 화면의 주문은 강조 표시되고 닫기 버튼이 있음">

1. **열린 주문** — 고객 또는 **비회원**, 합계, 경과 시간, 상태가 표시됩니다. 행을 누르면 해당 주문으로 전환합니다.
2. **항목** — 주문에 담긴 상품입니다. 상품이 세 개 이상이면 개수가 먼저 표시됩니다. **항목 3개 · Aim Analog Watch, …**
3. **현재 화면의 주문** — 강조 표시됩니다.
4. **닫기** — 장바구니로 돌아갑니다.

</JourneyShot>

주문을 연 지 한 시간이 지나면 이 목록과 해당 탭에서 경과 시간이 경고 색상으로 바뀝니다. 목록에서 잊고 있던 판매를 찾아 완료하거나 [무효화하세요](#void).

## 주문 세부 정보 {#order-details}

**결제** 옆의 **⋮** 버튼을 누르면 현재 화면에 있는 주문의 **주문 세부 정보**가 열립니다. **인계** 영역에서 주문을 어디에 대기시킬지 정하고, 하단 버튼으로 주문에 대한 작업을 수행합니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-40, 0], [-40, 0], [-40, 0], [-40, 0], [-33, 0], [19, -30], [33, -30], [41, -30]]} alt="열린 주문의 주문 세부 정보: 상태, 캐셔, 매장, 계산대 및 보내기 버튼이 있는 인계 영역과 하단의 무효화, 인쇄, 주문 동기화 버튼">

1. **상태** — 변경하여 주문을 매장으로 보냅니다. [상태 변경](#status)을 참고하세요.
2. **캐셔** — 동료에게 주문을 인계합니다. [다른 캐셔에게 주문 인계](#hand-over)를 참고하세요.
3. **매장**(WCPOS Pro) — 운영 중인 다른 매장으로 주문을 보냅니다. 매장이 둘 이상일 때만 표시됩니다.
4. **계산대** — 다른 계산대로 주문을 보냅니다.
5. **보내기** — 위에서 변경한 내용을 전송합니다. 변경한 내용이 없으면 비활성화된 상태로 표시됩니다.
6. **무효화** — 주문을 제거합니다. [주문 무효화](#void)를 참고하세요.
7. **인쇄** — 계산서를 인쇄합니다. [계산서 인쇄](#print)를 참고하세요.
8. **주문 동기화** — 주문을 매장에 즉시 저장합니다. [매장에 주문 저장](#sync-order)을 참고하세요.

</JourneyShot>

패널의 나머지 항목(고객 메모, 면세, 통화, 사용자 정의 필드)은 [주문 작업](./order-actions.mdx)에서 설명합니다.

### 다른 캐셔에게 주문 인계 {#hand-over}

교대 시 열린 주문을 다음 근무자에게 인계하세요.

1. 주문을 열고 **⋮** 버튼을 누르세요.
2. **캐셔**에서 동료를 선택하세요. 영역에 **이 장바구니에서 이동**이 표시됩니다.
3. **보내기**를 누르세요. POS에 동료 이름과 함께 **이 주문을 …에게 인계할까요?** 라는 질문이 표시됩니다.
4. 같은 동료 이름이 표시된 **…에게 보내기**를 누르세요.

주문이 본인의 탭 표시줄에서 사라지고 **주문을 보냈습니다**가 표시됩니다. 동료의 POS가 동기화되면 동료의 열린 주문에 나타나 대기합니다.

### 다른 계산대나 매장으로 주문 보내기 {#send-elsewhere}

한 계산대에서 주문을 시작한 고객이 다른 계산대에서 결제할 수 있습니다.

1. 주문을 열고 **⋮** 버튼을 누르세요.
2. **계산대**에서 다른 계산대를 선택하세요. WCPOS Pro를 사용하며 매장이 둘 이상이면 **매장**에서 다른 매장을 선택할 수도 있습니다. 해당 매장에 계산대가 하나뿐이면 자동으로 선택됩니다. 여러 개이면 보내기 전에 하나를 선택하세요.
3. **보내기**를 누르세요. POS에 **이 주문을 AL Store · 계산대로 보낼까요?** 와 같이 주문의 목적지와 변경 내용이 표시됩니다. **취소**를 누르면 주문이 현재 위치에 유지됩니다.
4. **…에게 보내기**를 누르세요. **주문을 보냈습니다**가 표시되고 주문이 이 장바구니에서 이동하여 해당 위치의 열린 주문에서 대기합니다.

1. **매장** — 주문을 보낼 매장입니다.
2. **계산대** — 해당 매장의 계산대입니다.
3. **요약** — **이 장바구니에서 이동**과 함께 변경 전후의 내용이 표시됩니다.
4. **보내기** — 전송하기 전에 확인을 요청합니다.

1. **취소** — 주문을 현재 위치에 유지하며 아무것도 전송하지 않습니다.
2. **…에게 보내기** — 주문을 전송합니다. **주문을 보냈습니다**가 표시되고 주문이 이 장바구니에서 이동하여 해당 위치의 열린 주문에서 대기합니다.

전송에 실패하면 **주문을 저장하지 못했습니다**가 표시되고 주문은 장바구니에 원래 상태로 유지됩니다. 연결을 확인한 후 다시 시도하세요.

### 상태 변경 {#status}

**상태**에는 계산대에서 설정할 수 있는 상태인 **POS - 열림**, **결제 대기**, **보류**, **취소됨**이 있습니다. 일부 결제된 주문처럼 계산대에서 설정할 수 없는 상태가 이미 적용되어 있으면 **상태**에 해당 상태가 비활성화되어 표시됩니다.

- **POS - 열림** 또는 **결제 대기**를 선택하면 주문이 이 장바구니에 유지됩니다. 보내기를 누르면 매장에 저장되며, 영역에 **이 장바구니에 유지**가 표시됩니다.
- **보류** 또는 **취소됨**을 선택하면 주문이 매장으로 전송되고 탭 표시줄에서 사라집니다. 이후 [주문](../../orders/index.mdx) 화면에서 찾을 수 있습니다.

### 계산서 인쇄 {#print}

주문 세부 정보에서 **인쇄**를 누르면 결제 전 주문의 영수증 화면이 열립니다. 테이블에 전달할 계산서나 견적서로 사용할 수 있습니다.

1. **템플릿**과 **프린터**를 선택하세요.
2. 미리보기를 확인하세요.
3. **영수증 인쇄**를 누르세요.

<details>
<summary>미리보기를 사용할 수 없는 경우</summary>

일부 템플릿은 매장에서 생성하므로 매장에 아직 저장되지 않은 주문을 표시할 수 없습니다. 이 경우 미리보기에 **이 주문에는 이 템플릿의 미리보기를 표시할 수 없습니다**가 표시됩니다. 이 화면에서 **주문 동기화**를 누르면 주문이 매장에 저장되고 미리보기가 나타납니다. 또는 다른 템플릿을 선택하세요.

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-37, 0], [-37, 0], [234, -46], [113, 0], [153, 0], [-26, -10]]} alt="결제되지 않은 열린 주문의 영수증 화면: 템플릿 및 프린터 선택기, 이 주문에는 이 템플릿의 미리보기를 표시할 수 없다는 미리보기 영역, 주문 동기화, 영수증 인쇄, 닫기">

1. **템플릿** — 인쇄할 레이아웃입니다. [영수증 사용자 정의](../../receipts/customise.mdx)를 참고하세요.
2. **프린터** — 인쇄에 사용할 프린터입니다. [영수증 인쇄](../../receipts/at-checkout.mdx#print-receipt)를 참고하세요.
3. **미리보기** — 인쇄될 계산서의 모습입니다. 여기서는 **이 주문에는 이 템플릿의 미리보기를 표시할 수 없습니다**가 표시됩니다.
4. **주문 동기화** — 주문을 매장에 저장합니다. [매장에 주문 저장](#sync-order)을 참고하세요.
5. **영수증 인쇄** — 영수증을 인쇄합니다.
6. **닫기** — 장바구니로 돌아갑니다.

</JourneyShot>

</details>

### 매장에 주문 저장 {#sync-order}

열린 주문은 작업하는 동안 이 기기에 저장되므로 다른 주문으로 전환했다가 돌아올 수 있습니다. 매장에도 저장하려면 **결제** 옆의 **⋮** 버튼을 눌러 [주문 세부 정보](#order-details)를 연 다음 **주문 동기화**를 누르세요. 동기화하기 전까지 주문은 이 기기에만 존재합니다. 매장에는 저장되지 않고 다른 계산대에서도 볼 수 없으며, 이 기기의 데이터를 지우면 사라집니다. 동기화된 주문은 **WooCommerce › 주문**에 실제 주문으로 등록됩니다. 매장에서 부여한 번호와 함께 **주문 #… 동기화됨**이 표시됩니다. 1.x에서는 **서버에 저장**이었던 기능입니다.

주문은 결제하거나 다른 곳으로 보낼 때까지 탭 표시줄에 열린 상태로 유지됩니다. 대기하는 동안 다른 고객을 응대하려면 [새 주문을 시작하세요](#new-order).

연결이 없어도 탭 표시줄에서 주문 전환, 항목 추가, 무효화를 할 수 있습니다. **주문 동기화**를 누르면 연결이 복구된 뒤 매장에 저장하도록 요청이 접수됩니다. 약 45초 후 **이 주문을 매장으로 전송하는 중입니다**가 표시되며, 다시 온라인 상태가 되면 주문이 매장에 전달되므로 버튼을 다시 누르지 마세요. **보내기**에는 연결이 필요합니다. 오프라인에서는 **주문을 저장하지 못했습니다**가 표시되고 주문이 장바구니에 유지됩니다.

### 주문 무효화 {#void}

더 이상 필요 없는 주문을 제거하려면 **결제** 옆의 **⋮** 버튼을 눌러 [주문 세부 정보](#order-details)를 연 다음 **무효화**를 누르세요. 확인 단계는 없습니다. **주문이 제거되었습니다**와 함께 **실행 취소**가 표시됩니다. 잘못된 주문을 무효화했다면 즉시 누르세요. 동기화된 주문을 무효화하면 **WooCommerce › 주문**의 **휴지통**으로 이동하며, 그곳에서 복원할 수 있습니다. 매장에서 삭제할 수 없는 경우에는 **주문**에 **취소됨** 상태로 남고 POS에 **주문이 무효화되고 취소됨으로 표시되었습니다**가 표시됩니다. 계산대를 마감한 상태에서도 무효화할 수 있습니다.

결제 내역이 있는 주문은 무효화할 수 없습니다. POS에 **이 주문에는 결제 내역이 있습니다. 결제 패널에서 취소를 눌러 각 결제를 취소한 다음 무효화하세요.** 라고 표시됩니다. [결제 취소](../checkout/cancelling-a-payment.mdx)를 참고하세요.

## 문제가 발생한 경우 {#goes-wrong}

- **인계한 주문이 동료의 탭 표시줄에 없습니다.** 동료의 POS가 동기화되면 나타납니다. 올바른 계산대와 매장으로 보냈는지 확인하세요. 주문은 보낸 대상인 캐셔, 매장, 계산대의 탭 표시줄에서만 대기합니다.
- **탭 표시줄에서 주문이 사라졌습니다.** 상태가 **보류**, **취소됨** 또는 매장에서 설정한 상태로 변경되었거나 다른 사람에게 인계되었습니다. [주문](../../orders/index.mdx) 화면에서 찾으세요.
- **무효화를 누르면 주문에 결제 내역이 있다고 합니다.** 먼저 결제 패널에서 각 결제를 취소하세요. [결제 취소](../checkout/cancelling-a-payment.mdx)를 참고하세요.
- **무효화를 누르면 "주문이 무효화되고 취소됨으로 표시되었습니다"라고 표시됩니다.** 매장에 저장된 주문을 삭제할 수 없어 **취소됨** 상태로 유지한 것입니다. 탭 표시줄에서는 제거된 상태입니다.
- **보내기 또는 주문 동기화를 누르면 "주문을 저장하지 못했습니다"라고 표시됩니다.** 변경된 내용은 없습니다. 연결을 확인한 후 다시 시도하세요.
