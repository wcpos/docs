장바구니의 상품, 수수료, 배송비는 각각 하나의 항목입니다. 수량, 가격, 이름을 누르면 대부분의 내용을 그 자리에서 변경할 수 있습니다. 나머지는 해당 항목의 **편집** 대화 상자에서 변경합니다.

## 장바구니의 항목 {#line}

상품 항목에는 수량, 이름, 단가가 표시되고 오른쪽에 항목 합계가 표시됩니다. 수수료와 배송비도 항목으로 표시되며 상품 아래에 있습니다. 표시하도록 설정한 [열](./index.mdx#columns)에 따라 다른 정보도 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 32], [122, -40], [0, -26], [0, -26], [-34, 0], [-34, 0], [-30, 0], [0, 24]]} maxWidth={379} alt="세 항목이 있는 장바구니: 사용자 정의 필드 ‘각인: 생일 축하해요’가 있는 $45.00의 Aim Analog Watch × 3, 선물 포장 수수료 $2.00, 지역 배송비 $5.00">

1. **수량** — 항목의 수량입니다. 눌러서 변경하세요. [수량 변경](#quantity)을 참고하세요.
2. **항목** — 상품 이름입니다. 누르면 이번 판매에 사용할 항목 이름을 변경할 수 있습니다. 이름이 텍스트 상자로 바뀌며, Enter를 누르거나 다른 곳을 누르면 새 이름이 저장됩니다. 그 아래에는 판매된 [변형 상품](../product-panel/variations.mdx)의 옵션과 항목의 [사용자 정의 필드](#meta-data)가 `Key: value` 형식으로 표시됩니다. SKU도 표시하려면 이 열의 **SKU** 옵션을 켜세요.
3. **가격** — 한 개의 가격입니다. 눌러서 변경하세요. [가격 변경](#price)을 참고하세요. 가격이 정상 가격보다 낮으면 그 위에 정상 가격이 취소선과 함께 표시됩니다.
4. **합계** — 수량에 가격을 곱한 금액입니다. 누르면 **편집** 및 **제거** 버튼이 표시됩니다. [항목 편집 또는 제거](#remove-item)를 참고하세요.
5. **수수료** — 마찬가지로 이름을 눌러 이름을 변경하고 금액을 눌러 금액을 변경합니다. [수수료](./index.mdx#fees)를 참고하세요.
6. **배송 항목** — 마찬가지로 제목이나 금액을 누르세요. [배송](./index.mdx#shipping)을 참고하세요.
7. **+** — 장바구니에 수수료, 배송비, 할인 또는 [기타 상품](./index.mdx#miscellaneous-products)을 추가합니다.
8. **장바구니 설정** — 장바구니 위치, 항목 정렬 방식, 표시할 열을 설정합니다. [항목에 대한 장바구니 설정](#cart-settings)을 참고하세요.

</JourneyShot>

## 수량 변경 {#quantity}

수량 상자를 누르세요. iOS 및 Android 앱에서는 상자에 숫자를 직접 입력하며, 수량을 0으로 입력하면 항목이 제거됩니다. 다른 환경에서는 키패드가 열립니다. 새 수량을 입력한 다음 체크 표시를 누르거나 Enter를 눌러 저장하세요. 휴대폰에서는 키패드가 화면 아래에서 패널로 열립니다. 태블릿이나 컴퓨터에서는 상자가 키패드로 확장되고 맨 위에 수량이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, -24], [0, -24], [0, -24], [-6, 0], [-6, 0], [0, 0]]} maxWidth={441} alt="수량이 1인 항목 위에 열린 수량 키패드: 1 왼쪽의 휴지통, 오른쪽의 더하기, 숫자 키, 지우기 키, 체크 표시">

1. **수량** — 지금까지 입력한 수량입니다.
2. **−** — 하나 줄입니다. 수량이 1이면 그림처럼 휴지통으로 바뀌며, 누르면 항목이 제거됩니다.
3. **+** — 하나 늘립니다.
4. **숫자 키** — 새 수량을 입력합니다.
5. **지우기** — 마지막 자릿수를 지웁니다.
6. **완료**(체크 표시) — 새 수량을 저장합니다. Enter도 같은 역할을 합니다. Escape는 키패드를 닫고 기존 수량을 유지합니다.

</JourneyShot>

매장에서 [소수 수량 활성화](../../settings/wp-admin/general.mdx#enable-decimal-quantities)를 켜면 매장의 소수 구분 기호가 표시된 소수점 키도 키패드에 나타납니다. 무게나 길이 단위로 판매하는 상품에 2.5나 0.25처럼 소수 수량을 입력할 수 있습니다(소수점 아래 여섯 자리까지).

매장에서 초과 판매를 방지하도록 설정한 경우 재고보다 많은 수량을 입력하면 주황색으로 표시됩니다. [결제가 차단되는 경우](#checkout-blocked)를 참고하세요.

### 항목 분할 {#splitting-line-items}

**분할**은 수량이 여러 개인 항목을 하나씩 별도의 항목으로 나누므로, 그중 하나에 다른 가격, 할인 또는 메모를 적용할 수 있습니다. 소수 수량은 소수 부분이 별도 항목으로 남습니다. 수량이 2.5인 항목은 1, 1, 0.5로 나뉩니다.

**분할** 링크는 수량이 하나를 넘는 항목의 수량 아래에 표시됩니다. **장바구니 설정**에서 켜기 전까지는 표시되지 않습니다.

1. **수량** — 항목의 수량이며, 여기서는 3입니다.

## 가격 변경 {#price}

가격을 누르고 새 단가를 입력하거나 빠른 할인 키를 누른 다음, 체크 표시를 누르거나 Enter를 눌러 저장하세요. 가격 영역이 키패드로 확장됩니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [-4, -20], [-4, -20], [-4, -20], [0, 0], [-4, 0], [0, 0]]} maxWidth={293} alt="−10% 키가 켜진 $45.00 항목의 가격 키패드: 새 가격 $40.50 위의 $45.00 −10 %, 숫자 키, 소수점, 지우기 키, 체크 표시">

1. **가격** — 새 단가입니다. 빠른 할인을 적용하면 그 위에 계산식이 표시됩니다. 여기서는 $45.00 −10 %로 계산하여 $40.50이 됩니다.
2. **−5%** — **빠른 할인** 키로, 항목 가격을 5% 할인합니다.
3. **−10%** — 이미 눌렀기 때문에 켜져 있습니다. 켜진 키를 다시 누르면 취소됩니다.
4. **−15%** — 15% 할인합니다. 처음에는 이 세 가지가 제공되며, [변경할 수 있습니다](./discounts.mdx#quick-discounts).
5. **숫자 키** — 새 단가를 입력합니다. 첫 번째 숫자를 입력하면 기존 가격이 대체됩니다.
6. **지우기** — 마지막 자릿수를 지웁니다.
7. **완료**(체크 표시) — 새 가격을 저장합니다. Enter도 같은 역할을 합니다. Escape는 키패드를 닫고 기존 가격을 유지합니다.

</JourneyShot>

키보드에서는 숫자를 입력하고, Backspace로 지우고, Enter로 저장하고, Escape로 취소하세요. 수량 키패드에서 위쪽 및 아래쪽 화살표 키는 수량을 하나씩 늘리거나 줄입니다(아래쪽 화살표로는 1까지만 줄일 수 있습니다).

휴대폰 브라우저에서는 같은 키패드가 패널로 열립니다. iOS 및 Android 앱에서는 가격을 누르면 입력 상자로 바뀝니다. 새 단가를 입력하고 상자를 벗어나면 저장됩니다. 빠른 할인 키는 키패드에만 있습니다.

:::note 가격 변경은 WooCommerce의 ‘할인’과 다릅니다
낮춘 가격은 상품의 할인가로 기록됩니다. 영수증에는 절약한 금액을 표시할 수 있지만, 주문의 **할인** 합계에는 쿠폰 할인만 포함되며 보고서에는 실제 지불한 가격으로 판매가 집계됩니다. WooCommerce가 두 가지를 다르게 처리하는 이유는 [장바구니 할인](./discounts.mdx#why-tracked-differently)을 참고하세요.
:::

### 새 가격은 이번 판매에만 적용 {#price-this-sale}

장바구니에서 변경한 가격은 이번 판매에만 적용됩니다. 상품 자체의 가격은 그대로 유지되므로 이 기기와 다른 기기의 상품 타일에도 기존 가격이 표시됩니다. 모든 판매에 적용할 가격을 변경하려면 [상품](../../products/index.mdx#inline-price-editing) 화면이나 WP Admin에서 상품 가격을 변경하세요.

카탈로그에 없는 상품을 직접 입력한 가격으로 판매하려면 **+** 버튼을 누르고 [기타 상품](./index.mdx#miscellaneous-products)을 추가하세요.

## 항목 편집 또는 제거 {#remove-item}

각 항목 아래에는 **편집** 및 **제거** 버튼이 숨겨져 있습니다. 다음 방법으로 표시할 수 있습니다.

- **항목 합계를 누르세요.** 다시 누르면 버튼이 숨겨집니다.
- 합계 위에 마우스 포인터를 **올리면** 항목이 옆으로 밀리면서 버튼이 살짝 보입니다.
- 터치스크린에서 왼쪽으로 **항목을 스와이프**하거나 마우스로 왼쪽으로 드래그하세요.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[6, -28], [6, -28]]} maxWidth={379} alt="시계 항목이 왼쪽으로 밀려 파란색 편집 버튼과 빨간색 제거 버튼이 표시된 모습">

1. **편집** — [편집 대화 상자](#edit-form)를 엽니다.
2. **제거** — 장바구니에서 항목을 제거합니다.

</JourneyShot>

더 멀리 스와이프하면 **제거** 버튼이 행 전체를 빨간색으로 채웁니다. 손을 떼면 한 번에 항목이 제거됩니다.

제거 후 표시되는 메시지의 **실행 취소** 버튼을 누르면 항목이 원래대로 복원됩니다.

## 편집 대화 상자 {#edit-form}

**편집**을 누르면 항목 이름을 제목으로 하는 대화 상자에 항목 세부 정보가 열립니다. 변경 내용은 즉시 저장됩니다. 작업을 마치면 **닫기**를 누르세요.

상품 항목의 경우:

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-35, 0], [-35, 0], [-35, 0], [-35, 0], [-35, 0], [-10, 0], [-10, 0], [-35, 0]]} alt="Aim Analog Watch 편집: 이름, 수량 3, 가격 45.00, 세금 표준 세율, 제거 버튼이 있는 SKU 24-MG04, 사용자 정의 필드 ‘각인: 생일 축하해요’, 정상 가격 및 사용자 정의 필드 버튼, 닫기">

1. **이름** — 영수증과 주문에 표시되는 이름입니다.
2. **수량** — 장바구니에 표시되는 수량과 같습니다.
3. **가격** — 장바구니에 표시되는 가격과 같습니다. 할인 판매 중인 항목은 옆에 **기존 가격**과 함께 정상 가격이 표시됩니다. 해당 **제거** 버튼을 누르면 정상 가격이 제거됩니다. 항목은 더 이상 할인 판매로 표시되지 않으며 현재 가격은 그대로 유지됩니다.
4. **세금** — 항목의 과세 여부와 세금 등급입니다.
5. **SKU** — 상품에 SKU가 있으면 표시됩니다. SKU가 없는 항목에는 추가할 수 있는 **SKU** 버튼이 표시됩니다.
6. **정상 가격** — 할인 판매 중이 아닌 항목에 정상 가격을 추가합니다.
7. **사용자 정의 필드** — 위의 **각인** 행처럼 키와 값을 추가합니다. [사용자 정의 필드](#meta-data)를 참고하세요.
8. **닫기** — 대화 상자를 닫습니다. 변경 내용은 이미 모두 저장된 상태입니다.

</JourneyShot>

추가된 각 행에는 별도의 **제거** 버튼이 있습니다. [기타 상품](./index.mdx#miscellaneous-products)은 카탈로그에 없으므로 해당 대화 상자에는 **카테고리**, **가상**, **다운로드 가능** 옵션도 있습니다.

항목의 세금은 주문 주소에 적용되는 세율로 계산됩니다. 매장에서 고객 주소를 기준으로 [세금을 계산](../../settings/store/tax.mdx#calculate-tax-based-on)하도록 설정한 경우, 고객이나 고객 주소를 다른 세율이 적용되는 대상으로 변경하면 즉시 새 세율로 항목의 세금이 다시 계산됩니다. [면세](./index.mdx#tax-exempt) 주문은 계속 면세로 유지됩니다.

### 수수료 항목 {#edit-fee}

수수료의 **편집**을 누르면 수수료 이름을 제목으로 하는 대화 상자가 열립니다. 상품과 마찬가지로 변경 내용이 즉시 저장됩니다.

수수료는 음수일 수 없습니다. 대화 상자에 **수수료는 음수일 수 없습니다. 대신 할인 추가를 사용하세요.** 라고 표시됩니다. [할인](./discounts.mdx)을 참고하세요.

<details>
<summary>수수료 편집: 대화 상자와 필드</summary>

<JourneyShot manifest={manifest} device="tablet" step={11} offsets={[[-35, 0], [-35, 0], [-12, 0], [-30, 0], [-35, 0], [-10, 0], [-35, 0]]} alt="선물 포장 편집: 수수료 이름, $ 및 % 전환 옵션이 있는 금액 2.00, 켜진 세금 포함 금액 옵션, 세금 표준 세율, 사용자 정의 필드 버튼, 닫기">

1. **수수료 이름** — 영수증에 표시되는 수수료 이름입니다.
2. **금액** — 고정 금액이며, **%** 선택 시에는 백분율입니다.
3. **$ / %** — 고정 금액과 장바구니 합계에 대한 백분율 사이를 전환합니다.
4. **세금 포함 금액** — 금액에 이미 세금이 포함되어 있으면 켭니다.
5. **세금** — **비과세** 또는 수수료에 적용할 세금 등급입니다.
6. **사용자 정의 필드** — [사용자 정의 필드](#meta-data)를 참고하세요.
7. **닫기** — 대화 상자를 닫습니다.

### JSON 탭 {#raw-json-view}

**양식** 옆의 **JSON** 탭은 WooCommerce로 전송되는 항목 데이터를 그대로 보여줍니다. 판매할 때는 필요하지 않습니다. 플러그인이 어떤 데이터를 받는지 확인하거나 필드가 저장되지 않는 이유를 확인할 때 유용합니다.

#### 세 가지 항목 종류 {#line-item-types}

WooCommerce는 상품, 수수료, 배송을 서로 다른 종류의 항목으로 저장합니다.

| 종류 | WooCommerce에서의 이름 | 예시 |
|------|----------------|----------|
| 상품 | `line_item` | 티셔츠, 커피 머그 |
| 수수료 | `fee_line` | 선물 포장, 서비스 요금 |
| 배송 | `shipping_line` | 일반 배송, 특급 배송 |

#### WCPOS 전용 필드 {#protected-keys}

WooCommerce에서는 사용자 정의 필드를 메타 데이터라고 부릅니다. 밑줄로 시작하는 키는 WCPOS 자체 기록입니다(예: `_woocommerce_pos_data`, `_reduced_stock`). 양식과 장바구니에는 표시되지 않으며 **JSON** 탭에서 확인할 수 있습니다.

</details>

## 사용자 정의 필드 {#meta-data}

사용자 정의 필드는 각인 문구나 일련번호처럼 특정 항목에 저장하는 메모입니다. 각인 문구를 추가하려면 항목의 **편집** 대화 상자를 열고 **사용자 정의 필드**를 누른 다음, **키**에 **각인**을 입력하고 **값**에 고객의 문구를 입력하세요. 필드는 장바구니의 항목 이름 아래와 WP Admin의 주문에 표시됩니다. 각 필드에는 별도의 **제거** 버튼이 있습니다.

일부 필드는 상품과 함께 추가됩니다. 선택한 [메타 데이터 키](../product-panel/meta-data-keys.mdx)는 상품을 추가할 때 해당 항목에 복사됩니다.

양식에 **이 키는 WCPOS에서 관리합니다. 다른 키를 선택하세요.** 라고 표시되면 [WCPOS 전용 키](#protected-keys) 중 하나를 입력한 것입니다. 다른 키를 선택하세요.

## 결제가 차단되는 경우 {#checkout-blocked}

매장에서 [초과 판매 방지](../../settings/wp-admin/checkout.mdx#prevent-overselling)를 설정하면 장바구니에서 모든 상품 항목을 재고와 비교합니다.

- 항목 위의 알림에 재고가 부족한 상품이 각각 표시됩니다. **후드티는 2개만 구매 가능합니다** 옆에는 해당 항목의 수량 입력을 여는 **줄이기** 버튼이, **후드티 품절** 옆에는 **제거** 버튼이 표시됩니다.
- 재고가 부족한 항목은 구매 가능한 수량과 함께 주황색으로 표시됩니다.
- **결제** 버튼이 흐리게 표시됩니다. 누르면 수정해야 할 첫 번째 항목으로 이동합니다.

모든 항목을 수정하면 **결제** 버튼이 다시 활성화됩니다. 이월 주문이 허용된 상품은 판매를 차단하지 않습니다.

## 문제가 발생한 경우 {#goes-wrong}

**"항목을 업데이트할 수 없습니다. 장바구니에 더 이상 없습니다."** 변경하는 동안 항목이 제거되었습니다. 장바구니를 확인하고 다시 변경하세요.

**"해당 항목이 장바구니에 더 이상 없습니다."** 이미 제거된 항목의 **제거** 버튼을 눌렀습니다. 추가로 할 일은 없습니다.

**분할 링크가 없습니다.** **장바구니 설정**의 **수량** 열에서 **분할**을 켜세요. 링크는 수량이 1을 넘는 항목에만 표시됩니다.

**결제 버튼이 흐리게 표시됩니다.** 재고가 부족한 항목이 있습니다. [결제가 차단되는 경우](#checkout-blocked)를 참고하세요.

**사용자 정의 필드가 저장되지 않습니다.** 키가 밑줄로 시작하는 WCPOS 전용 키입니다. 다른 키를 선택하세요.
