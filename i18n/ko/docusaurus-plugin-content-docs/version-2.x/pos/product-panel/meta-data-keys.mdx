각인 문구처럼 이번 판매에만 사용할 메시지는 [항목에 필드 추가](#custom-field)로 바로 이동하세요. 상품에 이미 저장된 필드를 복사하려면 [키 선택](#choose-keys)을 따르세요.

일부 상품에는 이름과 가격 외에도 각인 문구, 공급업체 코드, 다른 플러그인이 추가한 필드 등이 있습니다. WooCommerce에서는 이를 메타 데이터라고 하며, 설정 창의 **메타 데이터 키**에 복사할 필드가 나열됩니다. 각 필드는 이름인 **키**(예: `engraving`)와 **값**(예: `Happy Birthday`)으로 구성됩니다.

**메타 데이터 키**에 키를 지정하지 않으면 상품을 장바구니에 담아도 추가 필드는 따라오지 않습니다. 키를 지정한 필드는 장바구니 항목에 복사되어 해당 주문 항목과 함께 저장됩니다.

주문 전체에 적용할 사용자 정의 필드는 [주문 상세 정보](../cart/order-actions.mdx#order-meta)의 **+ 사용자 정의 필드**로 추가하고, 고객 계정에 적용할 필드는 [고객 양식](../../customers/index.mdx#add-new-customer)의 **사용자 정의 필드**로 추가합니다.

## 키를 복사해야 하는 경우 {#when-to-use}

- **플러그인의 상품 데이터**: 공병 보증금 플러그인은 각 상품에 `_bottle_deposit`을 저장합니다. 이 키를 추가하면 보증금이 주문 항목과 함께 저장됩니다. `_`로 시작하므로 항목에는 보이지 않습니다. [_로 시작하는 필드](#hidden-fields)를 참조하세요.
- **직접 만든 상품 필드**: 각인 문구나 공급업체 코드를 주문까지 전달합니다.
- **다른 플러그인을 위한 데이터**: 주문 항목을 읽는 플러그인이 해당 항목에서 값을 찾을 수 있습니다.
- **배치, 로트 또는 추적 코드**: 판매한 상품과 함께 보관합니다.

## 키 선택 {#choose-keys}

상품에 이미 저장된 키를 정확히 사용하세요. 모르면 필드를 설정한 담당자에게 문의하세요. 여기에서 키를 선택하는 것은 복사할 대상을 지정하는 것일 뿐, 상품에 필드를 추가하지는 않습니다. 키는 이 기기에 해당 매장용으로 저장되므로 이 상품을 판매하는 모든 계산대에서 설정하세요. 그리드와 표 보기에 같은 키가 적용됩니다.

:::note 키가 정확히 일치해야 합니다
`Engraving`과 `engraving`은 서로 다른 키입니다. 상품에 저장된 그대로 키를 입력하세요.
:::

1. 상품 패널에서 검색 모음의 마지막 버튼인 [**설정**](index.mdx#find)을 누르고 **메타 데이터 키**까지 아래로 스크롤하세요.
2. **메타 데이터 키**를 열고 목록에서 키를 선택하세요. 목록에 없다면 직접 입력하고 **“…”을(를) 사용자 정의 키로 추가**를 선택하세요.
3. 같은 방법으로 키를 더 선택한 뒤 **닫기**를 누르세요.
4. 해당 필드가 있는 상품을 장바구니에 추가하고 새 항목에 키와 값이 표시되는지 확인하세요. 옵션이 있는 상품과 `_`로 시작하는 키는 [복사되는 내용](#what-gets-copied)을 참조하세요.

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[38, 0]]} alt="검색 모음에 Aim Analog Watch가 입력된 상품 패널과 그 옆의 빈 장바구니">

1. **설정** — 검색 모음의 마지막 버튼입니다. 패널 설정을 열며, 하단 근처에 **메타 데이터 키**가 있습니다.

</JourneyShot>

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [100, 0], [260, 0], [-30, 0]]} alt="상품 설정의 메타 데이터 키: engraving 키가 칩으로 선택되어 있고 목록이 열린 상태이며, 검색에 gift_message가 입력되어 그 아래에 사용자 정의 키로 추가 행이 표시됩니다">

1. **선택한 키** — 이 필드를 가진 모든 상품에서 필드가 복사됩니다. 복사를 중단하려면 X를 누르세요.
2. **메타 데이터 키** — 이 기기의 상품에서 찾은 키 목록을 엽니다.
3. **검색** — 키를 입력하세요. 목록에 없다면 아래의 **“…”을(를) 사용자 정의 키로 추가**를 선택하세요. 이 기기에 아직 다운로드하지 않은 상품에만 있는 키도 이 방법으로 추가합니다.
4. **닫기** — 선택한 키를 유지하고 창을 닫습니다.

</JourneyShot>

설정 창 하단의 **기본 설정 복원**은 다른 패널 설정과 함께 이 키도 지웁니다.

### 복사되는 내용 {#what-gets-copied}

- **선택한 키만 복사합니다.** 상품의 나머지 필드는 복사하지 않습니다.
- **이후에 추가하는 항목에만 적용합니다.** 이미 장바구니에 있는 항목은 기존 내용을 유지합니다. 새 키를 반영하려면 항목을 제거하고 상품을 다시 추가하세요.
- **개별 옵션의 필드를 복사합니다.** 옵션이 있는 상품에서는 상위 상품이 아니라 선택한 옵션에서 필드를 복사합니다.
- **표시 위치.** 복사한 필드는 장바구니 항목의 상품명 아래에 `key: value` 형식으로 표시되고 해당 주문 항목과 함께 저장됩니다. `_`로 시작하는 키도 복사되지만 화면에는 보이지 않습니다. [_로 시작하는 필드](#hidden-fields)를 참조하세요.

상품을 추가하기 전에 상품 목록에서 이 필드를 보려면 표 보기로 전환한 뒤 **설정**을 열고 **상품명** 아래의 **메타 데이터**를 켜세요.

## 항목에 필드 추가 {#custom-field}

캐셔는 시계에 새길 문구처럼 개별 항목에 필드를 직접 추가할 수 있습니다.

1. 항목의 합계를 탭하거나 항목을 스와이프한 뒤 **편집**을 탭하세요.
2. **사용자 정의 필드**를 누르세요. 첫 번째 상자에 키를, 두 번째 상자에 값을 입력하세요. 항목의 필드는 **사용자 정의 필드** 아래에 나열됩니다.
3. 입력하는 즉시 변경 사항이 저장됩니다. 완료하면 **닫기**를 누른 뒤 항목의 합계를 다시 탭하여 **편집**과 **제거**를 숨기세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[110, 0], [110, 0], [12, 34], [40, 34], [60, 0]]} alt="Aim Analog Watch 항목의 편집 창: 사용자 정의 필드에 engraving 필드가 Happy Birthday로 설정되어 있고, 아래에 정상 가격 및 사용자 정의 필드 버튼이 있습니다">

1. **사용자 정의 필드** — 항목의 필드로, 각 필드는 키와 값 하나씩으로 구성됩니다. **메타 데이터 키**로 복사한 필드도 여기에 나열됩니다.
2. **필드** — 첫 번째 상자에는 키, 두 번째 상자에는 값이 있습니다. 둘 다 그 자리에서 변경할 수 있습니다. 변경 사항은 즉시 저장됩니다.
3. **제거** — 항목에서 필드를 제거합니다.
4. **사용자 정의 필드** — 빈 필드를 하나 더 추가합니다. 옆의 **정상 가격**은 항목에 다른 세부 정보를 추가합니다. [개별 항목](../cart/line-items.mdx)을 참조하세요.
5. **JSON** — `_`로 시작하는 필드를 포함한 항목의 모든 필드입니다. [_로 시작하는 필드](#hidden-fields)를 참조하세요.

</JourneyShot>

그러면 장바구니의 상품명 아래에 필드가 `key: value` 형식으로 표시되고 이 주문 항목과 함께 저장됩니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[130, 8]]} alt="Aim Analog Watch 항목 하나가 담긴 장바구니와 상품명 아래의 engraving: Happy Birthday">

1. **필드** — 상품명 아래에 키, 콜론, 값의 형식인 `engraving: Happy Birthday`로 표시됩니다.

</JourneyShot>

## _로 시작하는 필드 {#hidden-fields}

키가 `_`로 시작하는 필드는 주문과 함께 저장되지만 장바구니 항목, 해당 항목의 편집 창에 있는 **양식** 탭, 영수증에서는 숨겨집니다.

<details>
<summary>비공개 필드 확인 또는 거부된 키 수정</summary>

이러한 비공개 필드는 WCPOS나 다른 플러그인이 관리합니다. 예를 들어 WCPOS는 `_woocommerce_pos_data`에 항목의 가격과 세금 상태를 보관합니다.

`_woocommerce_pos_data`처럼 이미 항목에 있는 비공개 키는 새 필드에 사용할 수 없습니다. 필드의 키에 붙여 넣으면 POS가 거부합니다. 키는 빈 상태로 남고 창 상단에 **이 키는 WCPOS에서 관리합니다. 다른 키를 선택하세요.** 라는 안내가 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[110, 0], [12, 34]]} alt="항목의 편집 창: 상단에 빨간색으로 다음 오류를 수정하세요 및 이 키는 WCPOS에서 관리합니다. 다른 키를 선택하세요. 안내가 표시되며, 새 사용자 정의 필드의 키는 비어 있습니다">

1. **거부된 필드** — 키가 빈 상태로 남습니다. `_`로 시작하지 않는 고유한 키를 지정하면 항목에서 필드를 계속 볼 수 있습니다.
2. **제거** — 미완성 필드를 다시 제거합니다.

</JourneyShot>

비공개 필드를 포함해 항목의 모든 필드를 보려면 항목 창 상단의 **JSON** 탭을 여세요.

<JourneyShot manifest={manifest} device="tablet" step={5} alt="항목 창의 JSON 탭에서 meta_data를 펼친 화면: 비공개 _woocommerce_pos_uuid, Happy Birthday로 설정된 engraving, 비공개 _woocommerce_pos_data의 세 필드" />

주문 상세 정보 같은 다른 창에서는 비공개 필드를 개수가 표시된 **숨겨진 필드** 행 하나로 접어 둡니다. **표시**를 누르면 확인하고 변경할 수 있으며, **숨기기**를 누르면 다시 숨깁니다.

</details>

## 문제가 발생했을 때 {#goes-wrong}

- **항목에 필드가 없습니다** — **메타 데이터 키**에서 키의 철자와 대소문자를 확인하고, 해당 상품이나 옵션에 필드가 있는지 확인하세요. 키를 선택하기 전에 추가한 항목에는 필드가 반영되지 않습니다. 항목을 제거하고 상품을 다시 추가하세요. 다른 계산대에서도 해당 키를 설정해야 합니다.
- **원하는 키가 추천 목록에 없습니다** — 목록에는 이 기기의 상품에 있는 키만 표시됩니다. 키를 입력하고 **“…”을(를) 사용자 정의 키로 추가**를 선택하세요.
- **이 키는 WCPOS에서 관리합니다. 다른 키를 선택하세요.** — 이 항목에 이미 해당 키의 비공개 필드가 있습니다. 필드에 다른 키를 지정하세요.
- **주문에는 필드가 있지만 항목 아래에는 보이지 않습니다** — 키가 `_`로 시작합니다. 항목의 합계를 탭하고 **편집**을 탭한 뒤 **JSON** 탭을 열어 확인하세요.
