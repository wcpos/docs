## 패널 표시 방식 변경 {#display-settings}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[59, 0], [309, 60], [218, 0], [238, 41], [-115, 0], [105, -39], [0, 0], [199, 0], [-29, 0]]} maxWidth={512} alt="상품 설정: 보기 모드, 타일 크기, 각 선택 항목 옆에 개수가 표시된 탐색 기준, 품절 상품 표시, 정렬 기준, 정렬 방향, 옵션과 하단의 기본 설정 복원 및 닫기">

1. **보기 모드** — **그리드**는 이미지가 있는 타일로, **표**는 행으로 표시합니다. [그리드 또는 표](#view-mode)를 참조하세요.
2. **타일 크기** — 패널의 한 줄에 놓이는 타일 수로, 2부터 8까지 설정할 수 있습니다. **그리드**에서만 사용합니다.
3. **탐색 기준** — 패널에 처음 표시할 내용입니다. [탐색 기준](#browse-by)을 참조하세요.
4. **품절 상품 표시** — 끄면 품절 상품을 숨깁니다. [품절 상품](#show-out-of-stock-products)을 참조하세요.
5. **정렬 기준** — 상품이 나열되는 순서입니다. [정렬](#sort)을 참조하세요.
6. **정렬 방향** — **오름차순** 또는 **내림차순**입니다.
7. **옵션** — 옵션이 있는 상품을 여는 방식입니다. [옵션](#variations)을 참조하세요.
8. **기본 설정 복원** — 확인 없이 여기의 모든 설정을 한 번에 새 기기의 기본 설정으로 되돌립니다. 이 기기의 빠른 필터도 삭제합니다. [다시 시작](#restore-default-settings)을 참조하세요.
9. **닫기** — 설정을 닫습니다. 변경 사항은 이미 저장되어 있습니다.

</JourneyShot>

### 그리드 또는 표 {#view-mode}

**그리드**는 각 상품의 이미지, 이름, 가격을 타일로 표시합니다. 타일을 탭하면 장바구니에 하나가 추가됩니다. 옵션이 있는 상품에는 **옵션 …개**가 표시되며, 탭하면 대신 [해당 상품의 옵션](variations.mdx)이 열립니다. **표**는 같은 상품을 행으로 표시하며 각 행 끝의 **+** 로 상품을 추가할 수 있습니다.

새 기기는 한 줄에 타일 네 개를 표시하는 **그리드**로 시작합니다. 검색 필드 옆의 그리드 또는 표 버튼으로 설정을 열지 않고 두 보기를 전환할 수 있습니다.

상품을 장바구니에 담으면 타일 모서리의 작은 원에 담긴 수량이 표시됩니다. 행에서는 **+** 대신 수량이 표시되며, 탭하면 하나 더 추가됩니다.

### 탐색 기준 {#browse-by}

패널에 처음 표시할 내용:

| 선택 항목 | 패널에 처음 표시되는 내용 |
|--------|--------------------|
| **모든 상품** | [정렬 순서](#sort)에 따른 모든 상품 |
| **카테고리** | 최상위 카테고리별 타일. 새 기기의 기본 설정 |
| **태그** | 태그별 타일 |
| **브랜드** | 브랜드별 타일 |
| **바로가기** | [빠른 필터](#quick-filters)별 타일 |

각 선택 항목에는 **카테고리 6개**처럼 개수가 표시됩니다. 항목이 없으면 흐리게 표시되고 **아직 브랜드가 없습니다**처럼 안내합니다.

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-22, 0], [-30, 0], [0, 0], [0, 0], [282, 297]]} alt="용품 카테고리 안에서 탐색하는 화면: 카테고리 › 용품 경로, 뒤로 화살표가 있는 용품 타일, 상품 수가 표시된 하위 카테고리별 타일, 용품에 속한 상품과 그리드 아래의 개수">

1. **카테고리** — 탐색 경로입니다. 경로의 단계를 탭하면 해당 상위 단계로 돌아갑니다.
2. **뒤로 화살표** — 현재 카테고리의 타일에 있습니다. 타일을 탭하면 한 단계 위로 돌아갑니다.
3. **하위 카테고리** — 포함된 상품 수를 표시합니다. 탭하면 들어갑니다.
4. **상품** — 패널의 다른 곳과 마찬가지로 탭하면 장바구니에 추가됩니다.
5. **카테고리 3개 · 43개 중 20개 표시** — 현재 단계의 하위 카테고리 수와 화면에 표시된 상품 수입니다.

</JourneyShot>

타일을 탭하여 들어가세요. 카테고리에는 WooCommerce에서 설정한 대로 하위 카테고리, 상품 또는 둘 다 표시됩니다. 최상위 단계에서는 **모든 상품** 타일이 맨 앞에 표시됩니다. 검색하거나 탐색 기준과 같은 항목의 필터를 적용하면 타일 대신 일치하는 상품이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[0, 0], [259, 0]]} alt="두 단계 아래인 시계 안의 화면: 카테고리 › 용품 › 시계 경로, 뒤로 화살표가 있는 시계 타일과 시계 아홉 개">

1. **상품** — 시계에는 하위 카테고리가 없으므로 상품만 표시됩니다.
2. **시계** — 현재 단계입니다. **용품** 또는 **카테고리**를 탭하면 상위 단계로 돌아갑니다.

</JourneyShot>

한 단계 위로 돌아가려면 탐색 경로를 탭하거나, 키보드의 **Escape**를 누르거나, 터치스크린 왼쪽 가장자리에서 안쪽으로 스와이프하거나, Android의 뒤로 버튼을 사용하세요. 휴대전화에서는 탐색 경로에 바로 위 단계와 뒤로 화살표만 표시됩니다.

**표**에서는 같은 단계가 개수와 화살표가 있는 행으로 표시됩니다.

### 품절 상품 {#show-out-of-stock-products}

새 기기에서는 **품절 상품 표시**가 꺼져 있습니다. 끄면 품절 상품이 숨겨지고 해당 상품의 스캔이 거부됩니다. 켜면 목록에 흐리게 표시되고 **품절**로 표기되며, **재고 있음** 필터는 꺼진 상태로 시작합니다.

매장에서 [초과 판매 방지](../../settings/wp-admin/checkout.mdx#prevent-overselling)를 켰다면 POS는 상품을 추가할 때도 재고를 확인합니다.

- **… 품절** 또는 **…의 구매 가능 수량은 …개뿐입니다** — 상품이 추가되지 않습니다.
- **…의 재고가 아직 이 기기에 로드되지 않았습니다** — 상품 재고를 다운로드하는 중입니다. 잠시 후 다시 시도하세요.
- **…은(는) 예약 주문됩니다** — 상품이 추가됩니다. 예약 주문을 허용하고 고객에게 알리도록 설정된 상품입니다.

### 정렬 {#sort}

**정렬 기준**에서 **이름**, **SKU**, **바코드**, **유형**, **가격**, **생성 날짜**, **수정 날짜**, **인기도**, **재고 수량**, **재고 상태**, **메뉴 순서** 중 하나를 선택합니다. **인기도**는 총판매량으로, **내림차순**이면 가장 많이 팔린 상품부터 표시합니다. **메뉴 순서**는 WooCommerce에서 각 상품에 설정한 순서입니다. 새 기기에서는 **이름**을 기준으로 **오름차순** 정렬합니다.

**표**에서는 열 제목을 탭하여 해당 열을 기준으로 정렬할 수도 있습니다. 그러면 여기의 **정렬 기준**도 바뀝니다.

### 옵션 {#variations}

옵션이 있는 상품을 여는 방식입니다. 새 기기의 기본값인 **현재 위치에서 열기**는 패널에 각 옵션을 타일로 표시합니다. 다른 선택 항목은 **그리드**의 **팝오버**, **표**의 **확장 행**입니다. [옵션 상품](variations.mdx)을 참조하세요.

## 상품마다 표시할 내용 선택 {#fields}

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-302, -288], [-212, 39], [0, 0]]} maxWidth={512} alt="아래로 스크롤한 상품 설정: 타일 필드 스위치, 메타 데이터 키, 필터 모음 사용자 지정 버튼이 있는 필터 모음 영역">

1. **타일 필드** — 각 타일에 표시할 내용입니다. [타일 필드](#tile-fields)를 참조하세요.
2. **메타 데이터 키** — 장바구니에 복사할 상품의 사용자 정의 필드입니다. [메타 데이터 키](#meta-data-keys)를 참조하세요.
3. **필터 모음 사용자 지정** — 모음에 표시할 필터를 선택하고 나만의 필터를 만듭니다. [필터 모음](#filter-bar)을 참조하세요.

</JourneyShot>

### 타일 필드 {#tile-fields}

**그리드**에서는 타일에 표시할 **상품명**, **가격**, **세금**, **할인 중**, **카테고리**, **SKU**, **바코드**, **재고**, **매출 원가**를 켜세요. 새 기기는 이름과 가격을 표시합니다. **할인 중**을 켜면 할인 가격과 함께 취소선이 그어진 정상 가격이 표시됩니다. **재고**를 켜면 타일에 남은 수량이 표시됩니다.

### 열 {#columns}

**표**에서는 같은 위치에 **열** 목록이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 0], [5, 92], [139, 70], [159, 150]]} maxWidth={512} alt="표 보기의 상품 설정을 열 항목까지 스크롤한 화면: 각 열의 드래그 핸들과 스위치, 상품명 아래의 표시 옵션">

1. **확장 행** — **표**에서 **옵션**의 두 번째 선택 항목으로, 상품 아래에 옵션을 행으로 펼칩니다.
2. **드래그 핸들** — 열을 위아래로 드래그하면 표에서 좌우 위치가 바뀝니다.
3. **열 스위치** — 열을 켜거나 끕니다.
4. **표시 옵션** — **재고**, **카테고리** 등 상품명 아래에 표시되는 세부 정보입니다.

</JourneyShot>

새 기기는 이미지, 상품명, 가격, 작업을 표시하며, 이름 아래에는 **재고**와 **카테고리**를, 가격 아래에는 **할인 중**을 표시합니다. **상품명** 아래에 SKU, 바코드, 태그, 브랜드, 속성, 메타 데이터를 추가로 표시할 수 있습니다. **가격** 아래에는 세금도 표시할 수 있습니다.

### 메타 데이터 키 {#meta-data-keys}

장바구니 항목으로 복사되어 주문에 저장될 상품의 사용자 정의 필드를 선택합니다. [메타 데이터 키](meta-data-keys.mdx)를 참조하세요.

## 필터 모음 설정 {#filter-bar}

**필터 모음 사용자 지정**을 눌러 상품 위의 모음에 표시할 항목을 선택하세요.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-24, 0], [-42, 0], [160, 0], [-29, 0]]} maxWidth={512} alt="필터 모음 설정: 각 필터 옆의 드래그 핸들과 스위치, 빠른 필터 추가 버튼">

1. **드래그 핸들** — 필터를 위아래로 드래그하면 모음에서 위치가 바뀝니다.
2. **스위치** — 필터를 끄면 모음에서 사라지고, 켜면 다시 표시됩니다.
3. **빠른 필터 추가** — 나만의 버튼을 만듭니다. [나만의 필터 버튼](#quick-filters)을 참조하세요.
4. **닫기** — 변경 사항은 이미 저장되어 있습니다.

</JourneyShot>

새 기기의 모음에는 **재고 상태**, **추천**, **할인 중**, **카테고리**, **태그**, **브랜드**가 이 순서로 표시됩니다. 설정을 열지 않고 항목을 숨기려면 모음에서 길게 누른 뒤(마우스에서는 오른쪽 클릭) **모음에서 숨기기**를 선택하세요.

## 나만의 필터 버튼 {#quick-filters}

빠른 필터는 여러 조건을 한 번에 적용하는 버튼입니다. 예를 들어 **신발** 카테고리의 **할인 중** 상품을 가격순으로 정렬할 수 있습니다. 현재 화면의 조건으로 만들거나 처음부터 만드세요. 빠른 필터를 패널에 처음 표시할 수도 있습니다. [탐색 기준](#browse-by)을 **바로가기**로 설정하세요.

- [현재 화면의 조건 저장](#save-as-button)
- [처음부터 만들기](#add-quick-filter)
- [빠른 필터 변경](#edit-quick-filter)
- [빠른 필터 삭제](#delete-quick-filter)

### 현재 화면의 조건 저장 {#save-as-button}

모음에서 원하는 필터를 설정한 뒤 끝에 있는 책갈피 버튼인 **버튼으로 저장**을 누르세요. 필터를 하나라도 켜면 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[438, 0], [139, 0], [39, -40]]} maxWidth={512} alt="버튼으로 저장: 버튼 이름 필드, 버튼 미리 보기, 유지할 각 조건 옆의 체크 표시">

1. **버튼 이름** — 모음의 버튼에 표시할 이름입니다.
2. **현재 화면의 조건 유지** — 유지할 조건을 체크하세요. 카테고리 안에서는 해당 카테고리와 하위 카테고리도 조건에 포함됩니다. 검색은 직접 체크하지 않으면 선택되지 않습니다.
3. **모음에 추가** — 버튼을 모음에 추가합니다.

</JourneyShot>

체크 항목 아래에는 이 기기에서 조건에 맞는 상품 수가 표시됩니다. **취소**를 누르면 아무것도 추가하지 않고 닫습니다.

### 처음부터 만들기 {#add-quick-filter}

예를 들어 할인 중인 신발을 표시하는 버튼을 만들어 보세요.

1. **필터 모음 사용자 지정**에서 **빠른 필터 추가**를 누르세요.
2. **카테고리 내 할인 상품**을 선택하세요. 다른 시작 조건으로 **카테고리**, **지정 가격 미만**, **베스트셀러**, **신상품**, **재고 부족**, **태그**가 있습니다. 아무것도 선택하지 않으려면 **처음부터 만들기**를 누르세요.
3. **버튼 이름**에 할인 신발과 같은 이름을 입력하세요.
4. **다음 조건의 상품 표시…** 에는 **할인 중**이 이미 설정되어 있습니다. **카테고리 내**에는 **선택…** 이 표시됩니다. 탭하여 **신발**을 선택하세요.
5. **그다음**에서 **정렬 순서**를 누르고 **가격 낮은순**을 선택하세요. 변경하지 않으면 **그리드의 기본 순서**를 유지합니다.
6. **모음에 추가**를 누르세요. 버튼 이름을 입력하고 모든 조건을 선택하기 전까지는 비활성화되어 있습니다.

3단계와 4단계를 진행한 뒤 카테고리를 선택하기 전의 화면:

<JourneyShot manifest={manifest} device="tablet" step={9} offsets={[[120, 0], [130, 0]]} maxWidth={512} alt="새 빠른 필터: 버튼 이름에 할인 신발을 입력한 모음 미리 보기, 선택… 상태로 기다리는 카테고리 내, 예로 설정된 할인 중, 비활성화된 모음에 추가">

1. **버튼 이름** — 버튼에 표시할 이름입니다. **모음에서의 모습**에 표시 형태가 나옵니다.
2. **카테고리 내** — 카테고리를 고르기 전까지 **선택…** 이 표시됩니다. 아래의 **할인 중**은 이미 **예**로 설정되어 있습니다. 더 아래에 **그다음**과 **정렬 순서**가 있습니다.

</JourneyShot>

### 빠른 필터 변경 {#edit-quick-filter}

빠른 필터를 변경하려면 모음에서 길게 누르고 **편집**을 선택하거나 **필터 모음 사용자 지정**에서 해당 필터를 탭하세요. 변경 사항은 즉시 저장됩니다.

### 빠른 필터 삭제 {#delete-quick-filter}

모음에서 길게 누르고 **모음에서 제거**를 선택하거나 **필터 모음 사용자 지정**에서 해당 필터를 연 뒤 하단의 **모음에서 제거**를 누르세요. **삭제**를 눌러 확인하세요. 빠른 필터는 끈 상태로 보관할 수 없습니다. 제거하면 삭제됩니다.

## 다시 시작 {#restore-default-settings}

**상품 설정** 하단의 **기본 설정 복원**은 여기의 모든 설정을 새 기기의 기본 상태로 되돌립니다. 한 줄에 타일 네 개를 표시하는 **그리드**, **카테고리**, **이름**순 정렬, 모음의 기본 필터 여섯 개로 돌아갑니다. 별도의 확인 없이 실행됩니다.

:::warning
빠른 필터는 필터 모음에 속하므로 기본 설정을 복원하면 이 기기의 빠른 필터도 삭제됩니다.
:::

## 패널 하단 {#footer}

- **…개 중 …개 표시** — 이 기기에서 조건에 맞는 상품 중 화면에 표시된 상품 수입니다.
- **매장 기준**과 같은 **세금 기준** — 매장에서 세금을 계산할 때 표시됩니다. 탭하면 적용 중인 세율을 확인할 수 있습니다.
- **동기화 버튼** — 매장에서 상품 정보를 새로 가져옵니다. 길게 누르면 같은 새로 고침을 수행하는 **동기화**와 이 기기의 상품 데이터를 지우고 다시 다운로드하는 **지우고 새로 고침** 두 가지가 표시됩니다.
