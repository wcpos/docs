검색 필드에 입력하여 상품을 찾고, 그 아래 필터 모음으로 목록을 좁히세요. 검색과 필터는 함께 적용됩니다. 목록에는 검색 조건 **그리고** 켜져 있는 모든 필터에 일치하는 상품만 표시됩니다. 패널 전체에 대한 안내는 [상품 찾기](index.mdx#find)를 참고하세요. 아무것도 표시되지 않으면 [일치하는 상품이 없을 때](#no-match)를 참고하세요.

## 상품 검색하기 {#product-search}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[180, 0], [-32, 0], [0, 38], [0, 0], [-40, 0]]} alt="검색 필드에 watch가 입력된 상품 패널: 필드 안의 지우기 버튼, 켜진 재고 있음 필터, 시계 타일 아홉 개, 그리드 아래의 상품 9개 표시">

1. **상품 검색** — 상품 이름의 일부, SKU 또는 바코드를 입력하세요. 입력할 때마다 목록이 갱신됩니다.
2. **지우기** — 필드를 비웁니다. 켜져 있는 필터는 그대로 적용됩니다.
3. **재고 있음** — 검색 중에도 켜져 있으므로 품절 상품은 계속 숨겨집니다. [재고 상태](#stock-status)를 참고하세요.
4. **상품 타일** — 누르면 장바구니에 하나가 추가됩니다. **옵션 …개**가 표시된 타일은 먼저 옵션을 엽니다. 고객이 원하는 옵션을 누르세요. [변형 선택](index.mdx#variations)을 참고하세요.
5. **상품 …개** — 일치하는 상품 수입니다. 목록이 길면 **…개 중 20개 표시**로 나타납니다. 나머지를 보려면 아래로 스크롤하세요.

</JourneyShot>

### 검색 대상 {#what-search-matches}

- **이름, SKU 및 바코드.** 바코드는 매장에서 바코드용으로 사용하는 필드입니다. [바코드로 사용하는 필드](#barcode-configuration)를 참고하세요.
- **단어의 일부분.** "berry"로 "Blueberry"를, "123"으로 SKU "ABC-123"을 찾을 수 있습니다. 최소 입력 길이는 없습니다.
- **입력한 모든 단어.** "sport watch"를 입력하면 단어 순서와 관계없이 "Bolo Sport Watch"를 찾을 수 있지만, "sport"가 없는 시계는 검색되지 않습니다.
- **대소문자나 악센트 구분 없음.** "creme"로 "Crème"를 찾을 수 있습니다.
- **옵션도 검색.** 옵션 중 하나의 SKU 또는 바코드가 일치하면 해당 가변 상품이 표시됩니다.

카테고리, 태그, 설명은 검색 대상이 아닙니다. 카테고리, 태그 또는 브랜드로 범위를 좁히려면 [필터 모음](#product-filtering)을 사용하세요.

### 검색 작동 방식 {#how-search-works}

POS는 먼저 이 기기에 있는 상품을 검색하므로 결과가 바로 표시됩니다. 매장에도 조회하므로 아직 이 기기에 다운로드되지 않은 상품도 찾을 수 있으며, 다음에 사용할 수 있도록 기기에 저장합니다. 오프라인에서는 기기에 이미 있는 상품만 검색됩니다. 상품 카탈로그가 이 기기에 얼마나 저장되어 있는지 확인하려면 [매장 상태 → 데이터베이스](../../support/store-health.mdx#coverage)를 여세요.

## 목록 필터링 {#product-filtering}

필터를 누르면 켜지면서 강조 표시됩니다. 원하는 만큼 켜세요. 필터를 추가할 때마다 목록이 더 좁혀집니다. 두 개 이상 켜면 모음 끝에 **모두 지우기**가 나타납니다. 처음부터 켜져 있는 **재고 있음**은 이 개수에 포함되지 않습니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[38, 38], [26, 38], [-4, -38], [10, 38], [24, 38], [32, 38], [25, 38], [4, 38], [-40, 0]]} alt="할인 중이 켜지고 카테고리가 장비 외 세 개로 설정된 필터 모음: 태그와 브랜드는 꺼져 있고, 이어서 모두 지우기와 버튼으로 저장이 있으며, 일치하는 상품은 한 개">

1. **할인 중** — 현재 할인 중인 상품만 표시합니다. 다시 누르면 꺼집니다. 모음 뒤쪽의 **추천**도 같은 방식으로 WooCommerce에서 추천으로 지정한 상품을 표시합니다.
2. **카테고리** — 선택한 카테고리를 표시합니다. [카테고리, 태그 및 브랜드](#category)를 참고하세요.
3. **+3** — 카테고리 세 개가 추가로 선택되어 있습니다.
4. **제거** (× 표시) — 이 필터 하나를 해제합니다.
5. **태그** — 태그를 선택하세요.
6. **브랜드** — 브랜드를 선택하세요.
7. **모두 지우기** — 필터를 패널의 초기 상태로 되돌리고 검색 내용을 비웁니다. [모두 지우기로 초기화](#clear-all)를 참고하세요.
8. **버튼으로 저장** — 이 필터들을 나만의 버튼으로 저장합니다. [필터를 버튼으로 저장](#save-as-button)을 참고하세요.
9. **상품 …개** — 필터에 일치하는 상품 수입니다.

</JourneyShot>

모음을 옆으로 밀면 화면 밖에 있는 필터를 볼 수 있습니다.

### 재고 상태 {#stock-status}

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 0], [145, 0], [145, 0], [145, 0], [10, -38]]} alt="재고 있음 필터 아래에 열린 재고 상태 목록: 재고 있음이 선택되어 있고, 품절과 이월 주문 중이 표시됨">

1. **재고 있음** — 표시하는 상태가 필터 이름이 됩니다. 누르면 목록이 열립니다.
2. **재고 있음** — 재고가 있는 상품입니다. [표시 설정](display-settings.mdx#show-out-of-stock-products)에서 **품절 상품 표시**를 켜지 않았다면 처음부터 켜져 있습니다.
3. **품절** — 재고가 남아 있지 않은 상품만 표시합니다.
4. **이월 주문 중** — 재입고 전에 판매할 수 있도록 매장에서 허용한 상품만 표시합니다.
5. **제거** (× 표시) — 모든 재고 상태의 상품을 표시합니다. 검색과 다른 필터는 그대로 적용됩니다.

</JourneyShot>

### 카테고리, 태그 및 브랜드 {#category}

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[40, -38], [246, 0], [147, 0], [39, 0], [131, 0], [10, -38]]} alt="검색 상자에 시계가 입력된 카테고리 목록: 화살표가 있는 장비가 선택되어 있고 그 아래 시계도 선택되어 있으며, 필터에는 장비 외 세 개가 표시됨">

1. **카테고리** — 누르면 카테고리 목록이 열립니다. 하나를 선택하면 해당 카테고리 이름이 표시됩니다.
2. **카테고리 검색** — 입력하여 목록을 좁히세요. 하위 카테고리는 소속된 카테고리 아래에 표시됩니다.
3. **카테고리 항목** — 눌러서 선택하세요. 여러 개를 선택하면 그중 어느 카테고리에든 속한 상품이 표시됩니다. 하위 카테고리가 있으면 함께 선택되므로 **장비**에 **+3**이 표시됩니다.
4. **화살표** — 카테고리의 하위 카테고리를 펼치거나 접습니다. 이를 통해 하위 카테고리 하나만 선택할 수 있습니다.
5. **하위 카테고리** — 여기서는 **장비**가 선택되어 있어 함께 선택된 상태입니다.
6. **제거** (× 표시) — 카테고리 필터를 해제합니다.

</JourneyShot>

**태그**와 **브랜드**도 상단에 검색 상자가 있는 같은 형태의 목록을 엽니다. 태그나 브랜드는 한 번에 하나씩 선택할 수 있습니다. 다른 항목을 선택하면 기존 선택을 대체합니다.

### 모두 지우기로 초기화 {#clear-all}

처음부터 켜져 있는 **재고 있음**을 제외하고 필터를 두 개 이상 켜면 **모두 지우기**가 표시됩니다. 누르면 모음이 패널의 초기 상태로 돌아갑니다. 처음부터 **재고 있음**이 켜져 있었다면 그것만 남고, 나머지 필터는 모두 꺼지며 검색 필드가 비워집니다. **탐색 기준**에서 카테고리, 태그, 브랜드 또는 바로가기를 열었다면 해당 항목 안에 머무르며, 바로가기 자체의 필터와 검색도 유지됩니다. 품절 상품도 보려면 **재고 있음**의 × 표시를 누르세요.

그 외에 켜진 필터가 하나뿐이면 **모두 지우기**가 표시되지 않습니다. 해당 필터의 × 표시를 누르거나 **추천** 또는 **할인 중**을 다시 누르세요.

## 일치하는 상품이 없을 때 {#no-match}

**추천** 또는 **할인 중**을 다시 눌러 끄거나, 다른 필터의 × 표시를 누르세요. **필터 지우기**는 검색 내용을 비우고 필터를 한꺼번에 끕니다. 처음부터 **재고 있음**이 켜져 있었다면 계속 켜져 있으므로, 품절 상품을 찾으려면 **재고 있음**의 × 표시도 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[180, 0], [38, 38], [-20, 0], [-27, 0]]} alt="상품 없음: 패널에 상품 230개 중 watch, 재고 있음, 할인 중에 일치하는 상품이 없다는 메시지가 표시되고, 그 아래에 필터 지우기 버튼이 있음">

1. **검색 내용** — 입력한 내용입니다.
2. **할인 중** — 켜져 있는 필터입니다.
3. **상품 …개 중 …에 일치하는 상품이 없습니다** — 검색 내용과 켜져 있는 모든 필터를 표시하므로 어떤 조건을 해제할지 알 수 있습니다.
4. **필터 지우기** — 검색 내용을 비우고 필터를 끕니다. 단, 처음부터 켜져 있던 **재고 있음**은 유지됩니다. **탐색 기준**에서 연 카테고리, 태그, 브랜드 또는 바로가기는 열린 상태로 유지됩니다.

</JourneyShot>

## 필터를 버튼으로 저장 {#save-as-button}

매일 같은 필터를 사용한다면 모음에 버튼 하나로 저장하세요. 처음부터 켜진 **재고 있음**을 제외하고 필터를 하나 이상 켠 다음, 모음 끝의 책갈피 아이콘인 **버튼으로 저장**을 누르세요. 이름을 입력하고 **모음에 추가**를 누르세요.

저장한 버튼을 누르면 해당 상품이 표시됩니다. 기존에 적용되던 필터와 검색을 대체합니다. 다시 누르면 꺼집니다. 수정하거나 제거하려면 길게 누르세요.

4. **할인 중** — 또 다른 필터입니다. 변경한 검색 내용이나 정렬 순서도 여기에 선택되지 않은 상태로 표시됩니다. 함께 저장하려면 선택하세요.
5. **이 기기에서 상품 …개 일치** — 버튼을 눌렀을 때 표시될 상품이며, 이름이 최대 다섯 개까지 나옵니다.
6. **모음에 추가** — 버튼을 이 기기에 저장합니다. 버튼 이름을 입력하면 사용할 수 있습니다.
7. **취소** — 저장하지 않고 닫습니다.

## 필터 모음 변경 {#customise}

필터를 길게 누르거나 컴퓨터에서 마우스 오른쪽 버튼으로 클릭하면 메뉴가 열립니다. 모음에서 해당 필터를 숨기거나(이때 해당 필터도 패널의 초기 상태로 돌아갑니다), [표시 설정](display-settings.mdx#filter-bar)에서 모음 전체를 원하는 순서로 배치할 수 있습니다. 직접 저장한 버튼의 메뉴에는 **"…" 편집**, **필터 모음 사용자 지정**, **모음에서 제거**가 표시됩니다.

1. **할인 중** — 길게 누른 필터입니다.
2. **모음에서 숨기기** — 이 기기의 모음에서 필터를 숨기고, 해당 필터를 패널의 초기 상태로 되돌립니다.
3. **필터 모음 사용자 지정** — 필터를 원하는 순서로 배치하고, 켜거나 끄고, 나만의 버튼을 추가하세요. [표시 설정](display-settings.mdx#filter-bar)을 참고하세요.

:::

## 바코드로 사용하는 필드 {#barcode-configuration}

검색과 스캔 모두 [바코드 필드](../../settings/wp-admin/general.mdx#barcode-field)에서 설정한 매장의 바코드 필드를 읽습니다. 스캔 방법은 [바코드 스캔](barcode-scanning.mdx)을 참고하세요.

<details>
<summary>바코드 필드 설정</summary>

별도 설정 없이 사용하는 기본 바코드 필드는 WooCommerce의 전역 고유 ID 필드(`_global_unique_id`)이며, 여기에 GTIN, UPC, EAN 또는 ISBN을 입력합니다. SKU(`_sku`)나 바코드 플러그인이 사용하는 필드로 변경할 수 있습니다. POS는 상품당 바코드 하나, 가변 상품의 옵션당 바코드 하나를 읽습니다.

</details>

## 문제가 발생했을 때 {#goes-wrong}

- **상품 …개 중 …에 일치하는 상품이 없습니다** — 메시지에 검색 내용과 켜져 있는 모든 필터가 표시됩니다. 조건 하나를 해제하거나 **필터 지우기**를 누르세요.
- **목록의 상품이 적어 보임** — 아직 켜져 있는 필터가 있습니다. 품절 상품을 숨기는 **재고 있음**을 포함하여 모음에서 강조 표시된 필터를 확인하세요.
- **매장에 있는 상품이 표시되지 않음** — 이름의 일부나 SKU로 검색해 보세요. 검색 시 매장에도 조회하므로 이 기기가 온라인 상태인지 확인하세요. 그래도 표시되지 않으면 온라인 전용으로 지정되어 있을 수 있습니다. [POS 전용 상품](../../products/pos-only-products.mdx)을 참고하세요.
- **카테고리 이름으로 검색해도 결과가 없음** — 카테고리는 검색 대상이 아닙니다. **카테고리** 필터를 사용하세요.
- **필터가 회색으로 비활성화됨** — 가변 상품의 옵션 안에 있습니다. 탐색 경로에서 **상품**을 누르세요.
- **스캔한 바코드를 찾을 수 없음** — 어떤 필드가 바코드로 설정되어 있는지 확인하세요. [바코드로 사용하는 필드](#barcode-configuration)를 참고하세요.
