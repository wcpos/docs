:::info Pro 기능
**쿠폰** 화면을 사용하려면 [WCPOS Pro](/getting-started/pro-license)가 필요합니다. 매장에 이미 등록된 쿠폰은 무료 플러그인에서도 적용할 수 있습니다. [쿠폰 적용](./applying-coupons.mdx)을 참고하세요.
:::

**쿠폰** 화면에서는 POS 안에서 매장의 WooCommerce 쿠폰 목록을 볼 수 있습니다. 쿠폰을 찾거나 프로모션용 쿠폰을 만들고, 금액이나 만료일을 변경하고, 오래된 쿠폰을 삭제할 수 있습니다. 모든 변경 사항이 매장에 반영되므로 **WP Admin › 마케팅 › 쿠폰**과 웹사이트에서도 쿠폰 정보가 동일하게 유지되며, 다른 POS에도 동기화 시 전달됩니다.

왼쪽 메뉴의 **쿠폰** 아이콘을 눌러 여세요. 휴대전화에서는 메뉴를 먼저 여세요.

<details>

## 쿠폰 목록 {#coupon-list}

가장 최근에 만든 쿠폰이 맨 위에 표시됩니다. 더 불러오려면 아래로 스크롤하세요.

목록에서 변경한 내용은 즉시 매장에 반영됩니다. 저장 버튼은 없습니다. 변경을 되돌리려면 값을 원래대로 변경하세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[200, 0], [22, 30], [22, 30], [0, 0], [0, 0], [0, 0], [75, 0], [60, 0], [16, 28], [0, -30]]} alt="10을 검색한 쿠폰 화면: 검색창, 추가 및 표시 버튼, 상태·할인 유형·만료 필터, 활성 상태·코드·금액·유형·설명·사용 횟수·만료일이 표시된 쿠폰 여덟 개. 첫 번째 쿠폰은 31 Dec 2025에 만료되어 비활성으로 표시됨">

1. **쿠폰 검색** — 코드나 설명의 일부를 입력하세요.
2. **+** — [쿠폰을 만듭니다](#creating-coupons).
3. **표시 옵션** — 표시할 열을 선택합니다. **상태**, **생성 날짜**, **수정 날짜**는 처음에는 숨겨져 있습니다.
4. **상태** — **발행됨**, **임시글**, **대기 중**, **휴지통** 중에서 선택합니다. 목록에는 매장에서 발행된 쿠폰이 표시됩니다. 이 기기에서 **임시글** 또는 **대기 중**으로 설정한 쿠폰은 POS가 다음에 쿠폰을 가져올 때까지 여기에 표시됩니다.
5. **할인 유형** — 한 유형의 쿠폰만 표시합니다.
6. **만료** — 선택한 두 날짜 사이에 만료되는 쿠폰만 표시합니다.
7. **활성** — 쿠폰이 발행되었고 아직 만료되지 않았다면 초록색 **활성**으로, 그렇지 않으면 **비활성**으로 표시됩니다. 전환 스위치가 아닌 상태 표시입니다. **활성** 쿠폰도 사용 한도나 구매 금액 조건에 따라 사용이 제한될 수 있습니다. [POS에서 쿠폰이 거부될 때](./applying-coupons.mdx#refused)를 참고하세요.
8. **코드** — 고객이 제시하는 코드입니다. 누르면 변경할 수 있습니다.
9. **>** — 쿠폰을 열어 [변경](#edit)합니다.
10. **47개 중 8개 표시** — 매장의 전체 쿠폰 중 목록에 표시된 쿠폰 수입니다. 옆의 화살표를 누르면 매장에서 최신 정보를 가져옵니다.

2. **만료일** — 누르면 새 날짜를 선택할 수 있습니다. **31 Dec 2025**는 이미 지났으므로 해당 쿠폰은 **비활성**으로 표시됩니다.

### 목록 필터링 {#filters}

필터를 누르고 목록에서 항목을 선택하세요. 선택한 항목과 필터를 해제하는 **✕** 가 표시됩니다. 필터를 둘 이상 적용했다면 **모두 지우기**로 한꺼번에 해제할 수 있습니다.

1. **할인 유형** — 열린 필터입니다.
2. **비율 할인** — 상품 가격에서 일정 비율을 할인합니다.
3. **장바구니 고정 할인** — 주문 전체에서 일정 금액을 할인합니다.
4. **상품 고정 할인** — 조건에 맞는 각 상품에서 일정 금액을 할인합니다.

조건에 맞는 쿠폰이 없으면 목록에 **이 필터에 맞는 쿠폰이 없습니다**가 표시되고 그 아래에 **필터 지우기**가 표시됩니다.

## 쿠폰 만들기 {#creating-coupons}

1. 쿠폰 화면 상단의 **+** 를 누르세요.
2. 코드를 입력하거나 **생성**을 누르세요.
3. 할인 유형을 선택하고 금액을 입력하세요.
4. 만료 시점을 선택하세요.
5. 쿠폰을 바로 사용하려면 **상태**를 **상태 선택**으로 두세요. **활성**으로 저장되며, 목록의 **상태** 필터에서는 **발행됨**으로 표시됩니다. 사용을 보류하려면 **임시글** 또는 **대기 중**을 선택하세요.
6. 필요한 제한을 추가한 다음 **쿠폰 추가**를 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-36, 0], [-32, 0], [-20, 0], [-20, 0], [36, 30], [-30, 0], [440, 0], [12, -30]]} alt="쿠폰 목록 위의 쿠폰 추가 대화상자: 생성된 코드, 생성 버튼, 10퍼센트로 선택된 비율 할인, 날짜와 함께 표시된 만료 1주 선택, 일회용 스위치, 최소 구매 금액 등의 제한 추가 버튼, 쿠폰 추가 버튼">

1. **코드** — 고객이 POS에서 제시하는 코드입니다. 대소문자는 구분하지 않습니다.
2. **생성** — 혼동하기 쉬운 문자(0과 O, 1, I와 L)를 제외하고 **POS-UA43** 같은 코드를 만듭니다.
3. **할인** — **비율**, **주문 금액 할인**, **상품 금액 할인** 중에서 선택합니다. [쿠폰 유형](#coupon-types)을 참고하세요.
4. **금액** — 할인 비율 또는 매장 통화 기준 할인 금액입니다.
5. **만료** — **없음**, **오늘까지**, **1주**, **1개월**, **날짜 선택** 중에서 선택합니다. **오늘까지**, **1주**, **1개월**은 매장 시간대를 기준으로 해당 날짜가 끝날 때까지 유효하며, 날짜가 아래에 표시됩니다.
6. **일회용** — 한 번 사용하면 더 이상 사용할 수 없습니다.
7. **최소 구매 금액** 및 기타 버튼 — 쿠폰에 제한이나 설정을 추가합니다. [설정별 기능](#fields)을 참고하세요.
8. **쿠폰 추가** — 매장에 쿠폰을 저장합니다. **취소**는 저장하지 않고 닫습니다.

</JourneyShot>

새 쿠폰은 쿠폰 목록과 장바구니의 쿠폰 목록에 바로 표시됩니다.

판매 중에 쿠폰을 만들어 주문에 바로 적용하려면 장바구니의 **새 쿠폰**을 사용하세요. [할인](../pos/cart/discounts.mdx#new-coupon)을 참고하세요.

### 쿠폰 유형 {#coupon-types}

세 가지 쿠폰 유형의 이름은 POS와 WooCommerce에서 서로 다릅니다.

- **비율** (WooCommerce: *비율 할인*) — 장바구니에 담긴 상품에서 일정 비율을 할인합니다. `10`을 입력하면 10% 할인됩니다.
- **주문 금액 할인** (WooCommerce: *장바구니 고정 할인*) — 주문 전체에서 일정 금액을 할인합니다. `5.00`을 입력하면 주문에서 $5가 할인됩니다.
- **상품 금액 할인** (WooCommerce: *상품 고정 할인*) — 조건에 맞는 각 상품에서 일정 금액을 할인합니다. `2.00`을 입력하면 티셔츠 한 장당 $2가 할인됩니다.

### 설정별 기능 {#fields}

양식에는 **상태**가 항상 표시됩니다. 그 아래의 각 버튼으로 구매 금액 및 사용 한도, **내부 메모** 등의 설정을 하나씩 추가할 수 있습니다. 추가한 설정에는 다시 없앨 수 있는 **제거** 버튼이 표시됩니다. 아래 목록을 열어 각 설정의 기능을 확인하세요.

<details>
<summary>쿠폰 설정 및 제한</summary>

| 설정 | 기능 |
|---|---|
| **상태** | **활성**, **임시글**, **대기 중** 중에서 선택합니다. **활성**은 WooCommerce와 목록의 **상태** 열에서 **발행됨**으로 표시됩니다. 임시글 또는 대기 중인 쿠폰은 **비활성**으로 표시되며, POS가 다음에 쿠폰을 가져오면 목록에서 사라집니다. 별도로 선택하지 않으면 새 쿠폰은 활성 상태가 됩니다. |
| **최소 구매 금액** | 주문 금액이 이 금액 이상이어야 쿠폰이 적용됩니다. |
| **최대 구매 금액** | 이 금액을 초과하면 쿠폰이 적용되지 않습니다. |
| **총 사용 횟수** | 모든 고객의 사용을 합산한 쿠폰 사용 가능 횟수입니다. **일회용**이 켜져 있으면 이 설정은 제공되지 않습니다. |
| **고객당 사용 횟수** | 한 고객이 쿠폰을 사용할 수 있는 횟수입니다. |
| **최대 할인 상품 수** | 쿠폰으로 할인받을 수 있는 상품 수입니다. **비율**과 **상품 금액 할인**에만 적용됩니다. |
| **중복 사용 불가** | 주문에 다른 쿠폰이 이미 적용되어 있으면 POS에서 이 쿠폰을 거부합니다. |
| **무료 배송도 제공** | 쿠폰이 필요한 무료 배송 방법을 주문에서 사용할 수 있게 됩니다. |
| **내부 메모** | WooCommerce의 쿠폰 설명입니다. 장바구니의 쿠폰 목록에서는 코드 아래에 표시되며, 매장에서 인쇄한 영수증에는 코드 대신 표시되므로 고객도 볼 수 있습니다. 비공개 정보는 입력하지 마세요. |
| **사용자 정의 필드** | 쿠폰에 저장할 사용자 지정 키와 값입니다. |

</details>

일부 WooCommerce 설정은 POS 양식에 없습니다. **상품**, **제외할 상품**, **상품 카테고리**, **제외할 카테고리**, **할인 상품 제외**, **허용된 이메일**이 이에 해당합니다. 허용된 이메일에는 `*` 와일드카드를 사용할 수 있으며, 예를 들어 직원만 사용하도록 하려면 `*@yourcompany.com`을 입력합니다. 이러한 설정은 **WP Admin › 마케팅 › 쿠폰**에서 지정하세요. POS에서도 그대로 적용됩니다. [POS에서 쿠폰이 거부될 때](./applying-coupons.mdx#refused)를 참고하세요. **할인 상품 제외**는 POS에서 가격을 낮춘 상품도 제외합니다. [POS 가격 변경이 쿠폰에 미치는 영향](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons)을 참고하세요. 개발자는 [POS 할인 참조](../reference/pos-discounts.mdx)도 참고할 수 있습니다.

## 쿠폰 변경하기 {#edit}

:::warning 저장 버튼이 없습니다
변경 사항은 즉시 매장에 반영됩니다. **닫기**를 눌러도 변경 사항이 취소되지 않습니다. 되돌리려면 해당 필드를 다시 변경하세요.
:::

쿠폰 행 끝의 **>** 를 누르세요. 휴대전화에서는 쿠폰을 누르세요.

10. **동기화** — 이후 WP Admin에서 변경된 내용을 반영하기 위해 매장에서 이 쿠폰을 다시 가져옵니다.

## 쿠폰 삭제하기 {#delete}

쿠폰 삭제 권한이 있는 직원에게는 쿠폰 대화상자 하단에 **삭제**가 표시됩니다.

1. 쿠폰을 열고 **삭제**를 누르세요.
2. **확인**에 체크한 다음 **삭제**를 누르세요.

대화상자에 **삭제된 쿠폰은 서버의 휴지통으로 이동합니다.** 라는 경고가 표시됩니다. 쿠폰은 WooCommerce의 **휴지통**으로 이동하며 사용할 수 없게 됩니다. 되살리려면 **WP Admin › 마케팅 › 쿠폰**을 열고 **휴지통**을 선택한 다음 복원하세요. 삭제하지 않고 사용을 중단하려면 만료일을 설정하세요. 해당 날짜가 지나면 POS에서 쿠폰을 거부합니다.

## 쿠폰 생성 및 변경 권한 {#permissions}

쿠폰 생성, 변경, 삭제에는 각각 별도의 권한이 필요하며, **WP Admin › POS › 설정 › 접근**에서 설정합니다.

- **쿠폰 생성 및 편집** — 캐셔에게 기본으로 부여됩니다. 이 권한이 없으면 **+** 가 비활성화되고 목록을 변경할 수 없습니다.
- **쿠폰 삭제** — 캐셔에게 기본으로 부여되지 않습니다. 이 권한이 없으면 쿠폰 대화상자에 **삭제**가 표시되지 않습니다.

비활성화된 **+** 에 마우스 포인터를 올리면 이유를 확인할 수 있습니다. 역할을 변경하려면 [POS 접근](../settings/wp-admin/access.mdx)을 참고하세요.

## 판매에 쿠폰 사용하기 {#apply}

장바구니에서 **+** 를 누르고 **할인 추가**를 선택한 다음 **쿠폰** 탭으로 전환하세요. 쿠폰을 선택하고 **적용**을 누르세요. 무료 플러그인에서도 사용할 수 있습니다. [쿠폰 적용](./applying-coupons.mdx)을 참고하세요.

## 문제 해결 {#goes-wrong}

**WP Admin에서 만든 쿠폰이 목록에 없습니다.** 목록 하단의 **…개 중 …개 표시** 옆에 있는 화살표를 눌러 최신 정보를 가져오세요. 길게 누르면 **지우고 새로 고침**을 사용할 수 있습니다. 이 기기에 저장된 목록을 비우고 전체 목록을 다시 가져옵니다.

**+가 비활성화되어 있습니다.** 무료 플러그인에서는 **Pro로 업그레이드**라고 표시됩니다. 그 외에는 현재 역할에 쿠폰 생성 권한이 없는 경우입니다. [쿠폰 생성 및 변경 권한](#permissions)을 참고하세요.

**변경한 값이 되돌아갑니다.** 매장에서 변경을 거부한 것입니다. POS는 매장의 값으로 복원하고 **매장에서 거부한 변경 사항을 되돌렸습니다**라는 로그를 남깁니다. 이미 존재하는 코드 등으로 매장에서 거부한 새 쿠폰은 **매장 상태**에 표시됩니다.

**쿠폰이 비활성으로 표시됩니다.** 만료되었거나 상태가 **활성**이 아닙니다. 쿠폰을 열고 **만료** 또는 **상태**를 변경하세요.

**POS에서 쿠폰이 거부됩니다.** [POS에서 쿠폰이 거부될 때](./applying-coupons.mdx#refused)를 참고하세요.
