고객이 쿠폰 코드를 제시하거나 매장에서 프로모션을 진행할 때 쿠폰을 사용할 수 있습니다. 이 페이지에서는 장바구니에 담긴 판매에 매장의 쿠폰을 적용하는 방법을 안내합니다. 무료 플러그인에서도 쿠폰을 적용할 수 있습니다.

:::note 매장에 등록된 쿠폰을 사용합니다
POS에서는 매장에 이미 등록된 쿠폰을 적용합니다. **WP Admin → 마케팅 → 쿠폰**에서 쿠폰을 만드세요. [쿠폰](./index.mdx#creating-coupons)을 참고하세요. 쿠폰 없이 금액을 할인하려면 [할인 추가](../pos/cart/discounts.mdx#order-level-discounts)를 사용하세요.
:::

## 쿠폰 찾기 {#find}

1. 상품을 장바구니에 담은 상태에서 장바구니 상단의 **+** 를 누르고 **할인 추가**를 선택하세요. 휴대전화에서는 장바구니가 별도 탭에 있으므로 먼저 해당 탭을 여세요.
2. **쿠폰** 탭으로 전환하고 **쿠폰 선택**을 누르세요.
3. 코드나 쿠폰 설명의 일부를 입력한 다음 쿠폰을 누르세요.
4. **적용**을 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 0], [0, 0], [-24, 0], [-30, 0], [-30, 0], [0, -34], [0, -44]]} alt="쿠폰 목록이 열린 할인 추가 대화상자의 쿠폰 탭: 빠른 할인 및 쿠폰 탭, 쿠폰 선택 필드, 검색창, 유형과 금액이 표시된 쿠폰, 새 쿠폰 버튼, 적용 버튼">

1. **빠른 할인** — 쿠폰 없이 주문에서 일정 금액이나 비율을 할인합니다. [할인](../pos/cart/discounts.mdx#order-level-discounts)을 참고하세요.
2. **쿠폰** — 매장의 쿠폰입니다.
3. **쿠폰 선택** — 목록을 엽니다. 쿠폰을 선택하면 여기에 코드가 표시됩니다.
4. **쿠폰 검색** — 코드나 설명의 일부를 입력하세요. 대소문자는 구분하지 않습니다.
5. **쿠폰** — 코드 아래에 설명이 표시됩니다. 설명이 없으면 **비율 할인**, **장바구니 고정 할인**, **상품 고정 할인** 중 해당 유형이 표시됩니다. 오른쪽에는 할인 금액이 표시됩니다.
6. **새 쿠폰** (WCPOS Pro) — 쿠폰을 바로 만들어 현재 판매에 적용합니다. 쿠폰 생성 권한이 있고 매장에 연결되어 있어야 합니다. 그렇지 않으면 **+** 가 비활성화됩니다.
7. **적용** — 현재 주문이 쿠폰 조건을 충족하는지 확인하고 쿠폰을 적용합니다.

</JourneyShot>

목록에는 만료되었거나 사용 한도에 도달한 쿠폰을 포함해 매장의 모든 쿠폰이 표시됩니다. POS는 쿠폰을 선택할 때가 아니라 **적용**을 누를 때 조건을 확인합니다.

## 쿠폰 적용하기 {#apply}

**적용**을 누르면 대화상자가 닫히고 합계 영역의 **소계** 아래에 쿠폰이 표시됩니다. 쿠폰 코드, 제거용 **✕**, 할인 금액이 함께 표시됩니다. 추가한 쿠폰은 적용한 순서대로 각각 별도의 행에 표시됩니다. 다른 쿠폰을 추가하려면 **할인 추가**를 다시 여세요.

장바구니의 상품에도 각 상품에 배분된 할인이 표시됩니다. 각 행의 합계가 줄어들고 기존 금액에는 취소선이 그어집니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-28, 0], [100, 0], [40, 0], [40, 0], [0, 0]]} alt="쿠폰 두 개가 적용된 장바구니: 추가 메뉴, 소계, 코드와 제거 버튼 및 할인 금액이 표시된 각 쿠폰 행, 기존 금액에 취소선이 그어진 상품 합계, 결제 버튼">

1. **+** — 다른 쿠폰을 추가하려면 **할인 추가**를 다시 여세요.
2. **소계** — 쿠폰 적용 전 주문 금액입니다. 쿠폰 행은 그 아래에 표시됩니다.
3. **쿠폰** — 코드, 제거용 **✕**, 할인 금액이 표시됩니다.
4. **다음 쿠폰** — 각 쿠폰은 적용한 순서대로 별도의 행에 표시됩니다.
5. **결제** — 주문 대금을 받습니다. [결제](../pos/checkout/index.mdx)를 참고하세요.

</JourneyShot>

영수증에는 WooCommerce에 등록된 쿠폰 설명이 인쇄되며, 설명이 없으면 코드가 인쇄됩니다. 오프라인에서 인쇄한 영수증에는 코드가 표시됩니다. 장바구니가 변경되면 각 쿠폰의 할인 금액이 다시 계산됩니다. 예를 들어 상품을 추가하면 비율 할인 쿠폰의 할인 금액이 늘어납니다.

쿠폰 확인에는 이 기기에 저장된 정보를 사용하므로 오프라인에서도 적용할 수 있습니다. 다만 매장에서 주문을 수신할 때 합계를 변경하거나 주문을 거부할 수 있습니다. [문제 해결](#goes-wrong)을 참고하세요.

## 쿠폰 제거하기 {#remove}

합계 영역의 쿠폰 행에서 **✕** 를 누르세요. 할인되었던 금액이 다시 더해지고 **쿠폰이 제거되었습니다**라는 메시지가 표시됩니다. 다시 사용하려면 쿠폰을 다시 적용하세요.

결제 화면의 쿠폰 행에는 **✕** 가 없으므로 결제 중에는 쿠폰을 변경할 수 없습니다. 결제 화면 상단의 **✕** 를 눌러 장바구니로 돌아가 쿠폰을 변경한 다음 **결제**를 다시 누르세요. {/* pending: monorepo#3364 */}

주문을 [무효 처리](../pos/cart/order-actions.mdx#void)하면 적용된 쿠폰도 함께 제거됩니다.

## POS에서 쿠폰이 거부될 때 {#refused}

주문이 쿠폰 조건에 맞지 않으면 대화상자가 열린 상태로 유지되고 쿠폰 위에 이유가 빨간색으로 표시됩니다. 다른 쿠폰을 선택하거나 **취소**를 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-24, 0], [0, -44]]} alt="적용을 누른 뒤 쿠폰 필드 위에 이 쿠폰은 만료되었습니다라는 메시지가 빨간색으로 표시된 할인 추가 대화상자">

1. **쿠폰 선택** — 적용을 시도한 쿠폰입니다. 위의 빨간색 문구에 적용되지 않은 이유가 표시됩니다. 여기서 다른 쿠폰을 선택하세요.
2. **적용** — 주문이 조건을 충족하도록 변경한 뒤 다시 시도하세요.

</JourneyShot>

아래에서 원인을 찾아보세요. 각 항목에는 POS에 표시되는 정확한 메시지, 발생 원인, 해결 방법이 나와 있습니다.

<Accordion>
  <AccordionItem question="만료된 쿠폰">

POS 메시지: **이 쿠폰은 만료되었습니다.**

쿠폰의 만료일이 지나 사용할 수 없습니다. 다른 쿠폰을 선택하세요. 아직 유효해야 하는 쿠폰이라면 매장 측에서 WP Admin에서 만료일을 변경할 수 있습니다.

  </AccordionItem>
  <AccordionItem question="사용 한도에 도달한 쿠폰">

POS 메시지: **이 쿠폰은 사용 한도에 도달했습니다.**

매장에서 허용한 횟수만큼 쿠폰이 사용되었습니다. 다른 쿠폰을 선택하세요.

  </AccordionItem>
  <AccordionItem question="고객별 사용 한도에 도달한 경우">

POS 메시지: **이 고객은 이미 이 쿠폰의 최대 사용 횟수에 도달했습니다.**

주문에 지정된 고객이 이 쿠폰의 고객별 사용 한도에 도달했습니다. 주문에 올바른 고객이 지정되어 있는지 확인하거나 다른 쿠폰을 선택하세요.

  </AccordionItem>
  <AccordionItem question="최소 구매 금액 미달">

POS 메시지: **이 쿠폰의 최소 구매 금액은 …입니다.**

주문 금액이 쿠폰의 최소 구매 금액보다 적습니다. 필요한 금액은 메시지에 표시됩니다. 상품을 더 추가하거나 다른 쿠폰을 선택하세요.

  </AccordionItem>
  <AccordionItem question="최대 구매 금액 초과">

POS 메시지: **이 쿠폰은 … 이하의 주문에만 적용됩니다.**

주문 금액이 쿠폰의 최대 구매 금액을 초과합니다. 한도 금액은 메시지에 표시됩니다. 일부 상품을 별도의 판매로 처리하거나 다른 쿠폰을 선택하세요.

  </AccordionItem>
  <AccordionItem question="새 쿠폰을 단독으로 사용해야 하는 경우">

POS 메시지: **… 쿠폰은 다른 쿠폰과 함께 사용할 수 없습니다. 사용하려면 다른 쿠폰을 제거하세요.**

선택한 쿠폰은 주문에서 단독으로 사용해야 합니다. 이미 적용된 쿠폰을 제거한 다음 이 쿠폰을 적용하세요.

  </AccordionItem>
  <AccordionItem question="이미 적용된 쿠폰을 단독으로 유지해야 하는 경우">

POS 메시지: **… 쿠폰이 이미 주문에 적용되어 있으며, 다른 쿠폰과 함께 사용할 수 없습니다.**

주문에 적용된 쿠폰 중 단독으로만 사용할 수 있는 쿠폰이 있습니다. 해당 쿠폰 이름이 메시지에 표시됩니다. 새 쿠폰을 사용하려면 기존 쿠폰을 제거하세요. 기존 쿠폰을 유지하려면 새 쿠폰은 적용하지 마세요.

  </AccordionItem>
  <AccordionItem question="이미 주문에 적용된 쿠폰">

POS 메시지: **이 쿠폰은 이미 주문에 적용되어 있습니다.**

각 쿠폰은 주문당 한 번만 적용할 수 있으며, 이 쿠폰은 이미 적용되어 있습니다. 별도로 할 일은 없습니다.

  </AccordionItem>
  <AccordionItem question="주문에 고객 이메일이 없는 경우">

POS 메시지: **이 쿠폰은 특정 고객만 사용할 수 있습니다. 먼저 이메일 주소가 있는 고객을 주문에 추가하세요.**

이 쿠폰은 특정 이메일 주소를 가진 고객만 사용할 수 있지만, 주문에 아직 고객 이메일이 없습니다. 장바구니에서 고객을 선택한 다음 쿠폰을 다시 적용하세요.

  </AccordionItem>
  <AccordionItem question="고객 이메일이 허용 목록에 없는 경우">

POS 메시지: **이 쿠폰은 특정 고객만 사용할 수 있으며, 이 고객의 이메일은 허용 목록에 없습니다.**

고객의 이메일 주소가 쿠폰의 허용 목록에 없습니다. 주문에 올바른 고객이 지정되어 있는지 확인하거나 다른 쿠폰을 선택하세요.

  </AccordionItem>
  <AccordionItem question="장바구니에 쿠폰 적용 대상 상품이 없는 경우">

POS 메시지: **이 장바구니에는 이 쿠폰을 적용할 수 없습니다.**

장바구니에 쿠폰 적용 대상 상품이 없습니다. 또는 할인 상품을 제외하는 쿠폰인데 장바구니에 할인 상품이 있을 수 있습니다. 쿠폰 적용 대상 상품을 추가하거나 할인 상품을 제거하세요. [가격 변경과 쿠폰](#price-changes)을 참고하세요.

  </AccordionItem>
  <AccordionItem question="이 기기에 쿠폰이 없는 경우">

POS 메시지: **쿠폰을 찾을 수 없습니다**

아직 이 기기에 쿠폰이 없습니다. [쿠폰을 가져온](#sync) 다음 다시 시도하세요.

  </AccordionItem>
  <AccordionItem question="확인 중 장바구니가 변경된 경우">

POS 메시지: **쿠폰 적용 중 장바구니가 변경되었습니다. 다시 시도하세요.**

POS에서 쿠폰을 확인하는 동안 장바구니가 변경되었습니다. **적용**을 다시 누르세요.

  </AccordionItem>
</Accordion>

## 여러 쿠폰 사용하기 {#more-than-one}

한 주문에 쿠폰을 여러 개 적용할 수 있습니다. 쿠폰을 추가할 때마다 **할인 추가**를 다시 여세요. **개별 사용만**으로 설정된 쿠폰은 적용 순서와 관계없이 다른 쿠폰과 같은 주문에 사용할 수 없습니다. POS에 어떤 쿠폰이 중복 적용을 막는지 표시됩니다.

<Accordion>
  <AccordionItem question="두 번째 쿠폰의 할인 계산 방식">

**WP Admin → WooCommerce → 설정 → 일반**에 있는 WooCommerce의 **쿠폰 할인을 순차적으로 계산** 설정에 따라 달라집니다. POS는 매장의 설정을 따릅니다.

$100.00 주문에 10% 쿠폰 두 개를 적용하는 경우:

- **끄기** (WooCommerce 기본값): 각 쿠폰이 $100.00의 10%인 $10.00씩 할인합니다. 고객은 **$80.00**를 결제합니다.
- **켜기**: 첫 번째 쿠폰은 $10.00를 할인합니다. 두 번째 쿠폰은 남은 $90.00의 10%인 $9.00를 할인합니다. 고객은 **$81.00**를 결제합니다.

이 설정을 켜면 쿠폰 적용 순서에 따라 합계가 달라질 수 있습니다. 주문에서 $5를 할인하는 장바구니 고정 할인 쿠폰은 설정과 관계없이 같은 금액을 할인합니다.

  </AccordionItem>
</Accordion>

## 가격 변경과 쿠폰 {#price-changes}

쿠폰 할인은 상품 행의 가격을 기준으로 계산됩니다. POS에서 상품 가격을 낮췄다면 원래 가격이 아닌 낮아진 가격에서 쿠폰 할인이 계산됩니다.

<Accordion>
  <AccordionItem question="할인 상품을 제외하는 쿠폰">

가격을 낮춘 상품은 할인 상품으로 간주됩니다. **할인 상품 제외**로 설정된 쿠폰은 해당 상품을 할인하지 않습니다. **할인 상품 제외**가 설정된 장바구니 고정 할인 쿠폰은 해당 상품이 장바구니에 있는 동안 사용할 수 없습니다. [POS 가격 변경이 쿠폰에 미치는 영향](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons)을 참고하세요.

  </AccordionItem>
</Accordion>

## 문제 해결 {#goes-wrong}

**쿠폰이 목록에 없습니다.** <Anchor id="sync" />이 기기에서 아직 쿠폰을 가져오지 않았습니다. 지금 가져오려면 다음 단계를 따르세요.

1. 메뉴에서 **매장 상태**를 연 다음 **데이터베이스**를 여세요.
2. 쿠폰 행에서 **추가 작업**을 열고 **지금 변경 사항 확인**을 선택하세요.
3. **할인 추가**를 다시 열고 쿠폰을 검색하세요.

그래도 쿠폰이 없으면 같은 행에서 **지우고 다시 다운로드…** 를 선택하세요. POS에서 모든 쿠폰을 다시 가져옵니다. [지우고 다시 다운로드](../support/store-health.mdx#clear-and-redownload)를 참고하세요.

<Accordion>
  <AccordionItem question="쿠폰이 POS에 전달되는 방식">

목록을 처음 열면 POS에서 쿠폰을 가져옵니다. 이후에는 정해진 주기로 매장의 변경 사항을 확인합니다. 기본 프리셋의 확인 주기는 60초입니다. WP Admin에서 만든 쿠폰은 보통 이 시간 안에 표시됩니다. [동기화 프리셋](../support/store-health.mdx#sync-presets)을 참고하세요.

WCPOS Pro에서는 **쿠폰** 화면의 목록 하단에 동기화 버튼이 있습니다. 이 버튼을 길게 누르면 모든 쿠폰을 다시 가져오는 **지우고 새로 고침**을 사용할 수 있습니다.

  </AccordionItem>
</Accordion>

**매장에서 이 주문의 합계를 변경했습니다.** 주문이 매장에 도착했을 때 다른 합계가 계산되었습니다. 매장에서 계산한 금액이 최종 금액이므로 상품을 건네기 전에 합계를 확인하세요.

**주문이 저장되지 않았습니다 — 매장에서 거부했습니다.** 매장에서 주문을 받지 않아 판매 내용이 장바구니에 그대로 남아 있습니다. 메시지에 매장에서 거부한 이유가 표시되거나 **매장에서 이유를 제공하지 않았습니다**라고 표시됩니다. 이유에 특정 쿠폰이 언급되면 해당 쿠폰을 제거하고 **결제**를 다시 누르세요. 메시지의 **매장 상태** 버튼에서 매장이 거부한 내용을 확인할 수 있습니다. [서버에 반영되지 않은 변경 사항](../support/store-health.mdx#refused-changes)을 참고하세요.

## POS에서 활용하기 좋은 쿠폰 설정 {#common-setups}

이 쿠폰들은 **WP Admin → 마케팅 → 쿠폰**에서 만듭니다. 필드 이름은 WooCommerce 기준입니다.

<Accordion>
  <AccordionItem question="내역을 추적할 수 있는 관리자 할인">

`mgr10`이라는 쿠폰을 만드세요.
- **할인 유형:** 비율 할인
- **쿠폰 금액:** 10
- **개별 사용만:** 끄기. 고객의 쿠폰과 함께 사용할 수 있습니다.
- **설명:** "관리자 할인". 캐셔가 *관리자*로 검색해 찾을 수 있습니다.

코드는 관리자에게만 알려 주세요. POS에서 가격을 낮추는 것과 달리 이 할인은 WooCommerce의 **할인** 합계에 포함되고 보고서에 표시됩니다. [POS 할인과 WooCommerce 쿠폰 비교](../pos/cart/discounts.mdx#pos-discounts-vs-woocommerce-coupons)를 참고하세요.

  </AccordionItem>

  <AccordionItem question="재방문 고객을 위한 혜택">

`loyal5`라는 쿠폰을 만드세요.
- **할인 유형:** 장바구니 고정 할인
- **쿠폰 금액:** 5
- **최소 구매 금액:** 25 또는 원하는 기준 금액
- **사용자당 사용 한도:** 혜택을 한 번만 제공하려면 1
- **설명:** "단골 고객 혜택"

POS에서 *단골*로 검색하면 코드 없이도 찾을 수 있습니다. 사용자별 사용 한도를 적용할 고객을 식별할 수 있도록 쿠폰을 적용하기 전에 고객을 선택하세요.

  </AccordionItem>

  <AccordionItem question="전단지나 인쇄물 프로모션">

캠페인마다 쿠폰을 하나씩 만드세요. 일회용 쿠폰이라면 **쿠폰당 사용 한도**를 1로 설정하고, 여러 사람이 쓰는 공용 코드라면 더 큰 값으로 설정하세요. 캠페인이 끝난 뒤 사용할 수 없도록 **쿠폰 만료일**을 설정하세요. 고객마다 한 번씩 사용할 수 있는 공용 코드라면 **사용자당 사용 한도**도 1로 설정하세요.

  </AccordionItem>

  <AccordionItem question="고객의 쿠폰에 관리자 할인을 추가하고 싶은 경우">

고객의 쿠폰을 먼저 적용하고 관리자 쿠폰을 적용하세요. 고객의 쿠폰에 **개별 사용만**이 설정되어 있으면 POS에서 두 번째 쿠폰을 거부합니다. 고객에게 적용할 쿠폰을 선택하거나 [할인 추가](../pos/cart/discounts.mdx#order-level-discounts)로 추가 금액을 할인하세요.

  </AccordionItem>
</Accordion>

:::info WCPOS Pro 사용 시
**새 쿠폰**으로 POS에서 쿠폰을 만들어 판매에 적용할 수 있습니다. **쿠폰** 화면에는 모든 쿠폰의 금액, 유형, 사용 횟수, 만료일이 표시됩니다. 무료 플러그인에서는 미리보기로 표시됩니다.
:::
