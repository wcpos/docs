Mollie Terminal에는 [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0 이상이 필요합니다.
:::

Mollie Terminal은 POS에서 [Mollie](https://www.mollie.com/products/point-of-sale) 카드 단말기로 판매 금액을 전송합니다. 고객이 단말기에서 결제하면 POS에서 판매가 자동으로 완료됩니다. **유로**만 지원하며 POS에서만 사용할 수 있습니다. 온라인 매장의 결제 화면에는 표시되지 않습니다.

## 결제 받기 {#take-payment}

관리자가 매장의 실운영 Mollie 계정에 등록된 단말기로 한 번만 [설정](#setup)하면 됩니다. 시작하기 전에 [계산대를 여세요](../../pos/register/index.mdx#open).

:::warning
**계산대 열기 및 닫기**가 켜져 있으면 닫힌 계산대에서는 결제를 기록할 수 없으며, 이미 청구한 카드 결제는 환불해야 합니다.
:::

1. **결제**를 누른 다음 결제 수단 패널에서 **Mollie Terminal** 타일을 누르세요.
2. 결제 수단 패널의 **단말기:** 옆에 표시된 이름을 확인하세요. 다른 단말기를 사용하려면 **변경**을 누르고 선택하세요. 매장에 활성화된 단말기가 하나뿐이거나 선택이 잠겨 있으면 **변경**이 표시되지 않습니다.
3. **Mollie Terminal로 … 전송**을 누르세요. 해당 금액이 단말기로 전송됩니다.
4. 고객이 단말기에 카드를 대거나 삽입하거나 긁습니다. POS에 **단말기에서 진행 중**이 표시되고 **전송됨**, **단말기에서 진행 중**, **승인됨**, **매입 완료** 단계가 나타납니다.
5. Mollie가 결제를 확인하면 다른 [결제](../../pos/checkout/index.mdx#paid)와 마찬가지로 판매가 결제 완료 상태가 되고 영수증이 준비됩니다.

각 POS는 마지막으로 사용한 단말기를 기억합니다. [카드 리더기로 결제](../../pos/checkout/taking-a-payment.mdx#card-reader)를 참고하세요.

고객이 단말기에서 추가한 팁은 주문에 **팁** 항목으로 기록됩니다. [팁](../../pos/checkout/tips.mdx)을 참고하세요.

### 단말기 결제 취소 {#cancel}

POS가 대기 중일 때 **단말기에서 취소**를 누르세요. POS에 **취소 중 — 단말기 확인 대기 중**이 표시됩니다.

#### 결제가 취소되거나 거부된 경우 {#cancelled}

**결제 취소됨**, 결제 거부 또는 **시간 초과 — 결제 취소됨**이 표시되면 결제가 이루어지지 않은 것입니다. 결제를 다시 전송하려면 **다시 시도**를 누르고, 다른 결제 수단을 사용하려면 **다른 방법 선택**을 누르세요.

#### 단말기가 아직 확인하지 않은 경우 {#not-confirmed}

고객이 결제를 시작한 후에는 Mollie가 POS의 취소 요청을 허용하지 않을 수 있습니다. 단말기에서 직접 취소하세요.

POS가 계속 응답을 받지 못하면 **이 결제 해제**가 표시됩니다.

:::warning 결제를 다시 받기 전에
단말기를 확인하세요. 결제가 승인된 것으로 표시되면 **다시 청구하지 마세요**. 매장이 아직 Mollie에 확인 중입니다. 판단할 수 없다면 다른 결제를 받기 전에 관리자에게 Mollie 대시보드에서 결제 내역을 확인해 달라고 요청하세요.
:::

**이 결제 해제**를 누르면 주문을 다른 수단으로 결제할 수 있게 되며 POS에 **결제 해제됨**이 표시됩니다. 결제가 취소되었다는 뜻은 아닙니다. 매장은 계속 단말기 상태를 확인합니다.

### 레거시 탭에서 결제 {#legacy-tab}

주문 결제 페이지인 결제 화면의 [레거시 탭](../../pos/checkout/legacy-tab.mdx)에서도 결제를 받을 수 있습니다. **레거시** 탭을 열고 **Mollie Terminal**을 선택하세요. 관리자가 **QR 코드 결제**를 켰는지에 따라 표시되는 패널이 달라집니다.

**패널에 단말기와 QR 코드가 표시되면** **단말기**를 선택한 상태에서 **단말기 결제 시작**을 누르세요. 중단하려면 **단말기 결제 취소**를 누르세요. 대신 코드를 표시하려면 [QR 코드로 결제](#qr-code)를 참고하세요.

**그렇지 않은 경우:**

1. 패널에서 요청하면 단말기를 선택하세요.
2. 단말기 이름이 포함된 **… 전송** 버튼을 누르세요. 패널에는 타일과 동일한 단계가 표시됩니다.
3. 중단하려면 [결제 취소](#cancel)의 안내대로 **단말기에서 취소**를 누르세요. 중단된 후 **다시 시도**를 누르면 다시 전송됩니다. POS는 타일에서와 같은 방식으로 이 결제를 기록합니다.

## QR 코드로 결제 {#qr-code}

네덜란드와 벨기에에서는 고객이 단말기를 사용하는 대신 은행 앱으로 iDEAL 또는 Bancontact QR 코드를 스캔하여 결제할 수 있습니다. 먼저 관리자가 [설정](#settings)의 **QR 코드 결제**에서 해당 수단을 켜야 합니다.

1. 결제 화면에서 [레거시 탭](../../pos/checkout/legacy-tab.mdx)을 열고 **Mollie Terminal**을 선택하세요.
2. 결제 패널을 **단말기**에서 **QR 코드**로 전환하세요.
3. 둘 다 켜져 있으면 **iDEAL** 또는 **Bancontact**를 선택하고 **QR 코드 표시**를 누르세요.
4. 고객이 코드를 스캔하고 휴대전화에서 결제합니다. 단말기에서와 같은 방식으로 판매가 완료됩니다.

Bancontact QR 결제의 건당 최대 금액은 €1,500.00입니다. 그보다 큰 금액은 단말기를 사용하세요.

## 환불 {#refunds}

POS에서 Mollie Terminal 판매를 환불할 때 **Mollie Terminal로 환불**을 선택하거나 WooCommerce 주문 화면에서 환불하세요. 금액은 Mollie를 통해 전액 또는 일부가 반환됩니다. [환불](../../pos/refunds.mdx#destination)을 참고하세요.

Mollie 환불은 대기 상태로 시작됩니다. WCPOS Pro가 십 분마다 Mollie에 확인한 다음 환불 완료 또는 실패로 표시하고 주문에 메모를 추가합니다.

## 문제가 발생한 경우 {#goes-wrong}

### 고객이 이미 결제한 경우: 다시 청구하지 마세요 {#already-paid}

**고객이 결제했지만 POS가 계속 대기 중입니다.** **다시 청구하지 마세요.** 화면을 유지하세요. Mollie가 결제를 확인하면 판매가 완료됩니다. 완료되지 않으면 관리자에게 Mollie 대시보드에서 결제 내역을 확인해 달라고 요청하세요.

**“이 판매의 이전 Mollie 결제가 완료되었습니다”.** Mollie에서 이 판매의 결제가 이미 완료되었지만 아직 주문에 반영되지 않았습니다. **다시 청구하지 마세요.** 몇 분 기다린 후 새로고침하세요. 결제가 주문과 일치하지 않는다는 메시지가 표시되면 관리자가 먼저 Mollie 대시보드에서 확인해야 합니다.

### 기타 문제 {#other-problems}

**“Mollie Terminal에 설정된 단말기가 없습니다”.** 매장에 사용 가능한 활성 단말기가 없습니다. 관리자는 **모드**가 **실운영**이고 실운영 키를 사용 중인지, 해당 Mollie 계정에서 단말기가 활성화되어 있는지 확인해야 합니다.

**“주문 #…에서 사용 중”.** 해당 단말기는 다른 판매를 처리 중입니다. 다른 단말기를 선택하거나 먼저 해당 판매를 완료하거나 취소하세요.

**“연결이 필요합니다”.** POS가 오프라인 상태입니다. Mollie Terminal은 온라인에서만 작동합니다. 다른 방법으로 결제를 받거나 연결될 때까지 기다리세요.

**“시간 초과 — 결제 취소됨”.** 제한 시간 내에 결제하지 않아 결제가 취소되었습니다. 단말기가 켜져 있고 온라인 상태인지 확인한 다음 **다시 시도** 또는 **다른 방법 선택**을 누르세요.

**다른 통화로 된 판매는 거부됩니다.** Mollie Terminal은 유로만 지원합니다.

**여전히 해결되지 않나요?** 확장 기능의 문제는 [GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/issues)에 보고하세요. Mollie 계정이나 단말기 자체에 관한 사항은 Mollie 지원팀에 문의하거나 Mollie의 [단말기 설정 안내](https://docs.mollie.com/docs/setting-up-terminal)를 참고하세요.

<details>
<summary>POS와 매장이 Mollie 상태를 확인하는 방식</summary>

- 결제가 대기 중인 동안 결제 페이지는 2초마다 Mollie에 확인합니다. 보통은 Mollie가 매장에 직접 보내는 메시지를 통해 더 빨리 확인됩니다. 이 메시지를 받기 위해 따로 설정할 것은 없습니다.
- 모든 업데이트는 주문을 변경하기 전에 Mollie에 확인하므로 주문 상태는 Mollie의 상태를 따릅니다.
- 환불 요청에 응답이 없으면 확장 기능은 새 환불을 요청하기 전에 Mollie가 이미 처리한 환불이 있는지 확인합니다.
- 레거시 탭에서 **QR 코드 결제**가 켜져 있으면 확장 기능 자체 패널이 결제를 처리합니다. 오 분 안에 아무도 결제하지 않거나, 주문이 다른 수단으로 결제되거나 WooCommerce에서 취소되거나, 결제 도중 결제 페이지가 닫히면 Mollie에 남아 있는 미완료 결제를 취소합니다. 십 분마다 실행되는 확인 작업은 미결제 주문에서 십 분이 지나도 열려 있는 결제를 취소합니다.
- 이미 단말기에 전달된 결제는 매장에서 취소할 수 없습니다. 단말기에서 취소하세요.
- 문제 해결을 위해 모든 결제는 `WooCommerce > Status > 로그`에 기록됩니다. 판매가 완료되지 않으면 관리자가 이곳에서 Mollie 메시지를 확인합니다.

</details>

## 설정하기 {#setup}

관리자가 WP Admin에서 한 번만 설정하면 됩니다. WCPOS Pro 2.0.0 이상, **대면 결제** 수단이 켜진 실운영 Mollie 계정이 필요하며 매장 통화는 유로여야 합니다.

<details>
<summary>관리자 설정: 설치, 키, 단말기, 활성화</summary>

확장 기능에는 WCPOS Pro 2.0.0 이상이 필요합니다. 없으면 작동하지 않으며 WP Admin에 알림을 표시합니다.

:::note 시작하기 전에
Mollie 웹 앱에서 프로필의 **대면 결제** 수단을 켜고 단말기를 구매하세요. Mollie는 네덜란드, 벨기에, 독일, 프랑스, 영국에서 단말기를 판매하며 먼저 계정 인증을 요청할 수 있습니다. 단말기는 **실운영** 계정에만 있으므로 실운영 API 키가 필요합니다.
:::

1. **확장 기능을 설치하세요.** `POS Settings > 확장`을 열어 **Mollie Terminal**을 설치하세요. 또는 [GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases)의 릴리스 zip을 `플러그인 > Add Plugin`의 **플러그인 업로드**로 업로드하세요. 소스 코드 압축 파일이 아닌 릴리스에 첨부된 zip을 사용하세요. [확장 기능](../../extensions/index.mdx#installing-an-extension)을 참고하세요.
2. **키를 추가하세요.** `WooCommerce > 설정 > 결제 > Mollie Terminal`로 이동하세요. **모드**를 **실운영**으로 설정한 다음 **Mollie API 키**에 실운영 키를 붙여넣거나, **API 키 소스**에서 Mollie Payments for WooCommerce 플러그인의 키를 재사용하도록 설정하세요. 저장하세요.
3. **단말기를 선택하세요.** 키를 저장하면 Mollie 계정의 단말기 목록이 표시됩니다. **기본 단말기**를 선택하세요. POS에서 사용하면 안 되는 단말기가 있다면 **활성화된 단말기**에 사용할 단말기만 지정하세요. 저장하세요.
4. **POS에서 활성화하세요.** `POS > 설정 > 결제`로 이동하여 **Mollie Terminal**을 활성화하세요. 이것이 유일한 켜기/끄기 스위치입니다. [결제 게이트웨이 활성화](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)를 참고하세요.

Mollie 대시보드에서 웹훅을 설정하거나 프로필 ID를 붙여넣을 필요가 없습니다. 확장 기능이 매 결제마다 웹훅 주소를 전송하며 계정 전체의 단말기 목록을 조회합니다.

**기본 단말기** 목록이 계속 비어 있다면 **모드**가 **실운영**이고 실운영 키를 사용 중인지(테스트 계정에는 단말기가 없습니다), Mollie에서 단말기가 활성화되어 있는지, 사이트가 Mollie에 연결할 수 있는지 확인하세요.

</details>

### 설정 {#settings}

<details>
<summary>Mollie Terminal 화면의 모든 설정</summary>

모든 설정은 `WooCommerce > 설정 > 결제 > Mollie Terminal`에 있습니다.

| 설정 | 기능 |
|---|---|
| **제목** | POS 타일에 표시되는 이름입니다. 초기값은 “Mollie Terminal”입니다. |
| **설명** | 주문 결제 페이지에서 결제 수단과 함께 표시되는 문구입니다. |
| **모드** | **테스트** 또는 **실운영**입니다. 초기값은 **테스트**이며, 테스트 키로는 단말기를 작동시킬 수 없다는 경고가 표시됩니다. 결제를 받으려면 **실운영**을 사용하세요. |
| **API 키 소스** | **아래에 입력한 키 사용** 또는 **공식 Mollie 플러그인의 키 재사용**(**모드**에 맞는 테스트 또는 실운영 키)을 선택합니다. Mollie 플러그인에 키가 설정되어 있지 않으면 아래에 입력한 키를 사용합니다. |
| **Mollie API 키** | 선택한 모드에 맞는 키입니다. 키 소스가 Mollie 플러그인의 키를 재사용하도록 설정되어 있으면 무시됩니다. |
| **기본 단말기** | POS에서 처음 사용하는 단말기입니다. Mollie 계정에서 실시간으로 목록을 가져옵니다. 비활성 단말기는 Mollie에서 다시 활성화할 수 없으므로 숨겨집니다. |
| **활성화된 단말기** | POS에서는 이 단말기만 선택할 수 있습니다. 비워 두면 모든 활성 단말기를 허용합니다. 기본 단말기는 항상 선택할 수 있으므로 단말기를 사용 중단할 때는 기본 단말기도 변경하세요. 단말기 목록을 불러올 수 없으면 표시되지 않으며 저장된 선택은 유지됩니다. |
| **QR 코드 결제** | **iDEAL** 및 **Bancontact**: 캐셔가 단말기 대신 화면에 QR 코드를 표시할 수 있게 합니다. 각 수단이 Mollie 프로필에서 활성화되어 있어야 합니다. iDEAL QR은 **테스트** 모드에서도 작동하므로 단말기 없이 시험할 수 있습니다. Bancontact QR은 **실운영** 모드가 필요합니다. [QR 코드로 결제](#qr-code)를 참고하세요. |
| **단말기 선택 잠금** | POS가 항상 기본 단말기를 사용하며 캐셔가 변경할 수 없습니다. **기본 단말기**가 필요합니다. |
| **결제 디버그 로그** | 결제 패널에 **로그 표시**, **복사**, **지우기**를 표시합니다. 지원팀이 요청하지 않는 한 꺼 두세요. 결제는 항상 `WooCommerce > Status > 로그`에 기록됩니다. |

</details>
