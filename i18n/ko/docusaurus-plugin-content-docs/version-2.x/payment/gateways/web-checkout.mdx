# 웹 결제 게이트웨이 {#web-checkout-gateway}

:::info Pro 기능
웹 결제로 결제를 받으려면 [WCPOS Pro](../../getting-started/free-vs-pro.mdx)가 필요합니다.
:::

웹 결제를 사용하면 고객이 온라인 매장의 자체 결제 페이지에서 POS 주문을 결제할 수 있습니다. 온라인 카드 입력 양식이나 전자 지갑 등 온라인 매장에서 제공하는 결제 수단을 사용합니다. 고객이 계산대에서 지원하지 않는 수단으로 결제하고 싶어 할 때 사용하세요.

바로가기: [결제 받기](#take-payment) · [설정하기](#set-up) · [문제 해결](#goes-wrong)

## 결제 받기 {#take-payment}

웹 결제는 결제 화면의 **레거시** 탭에 있습니다. 인터넷 연결이 필요하며 주문 전체 금액을 청구합니다. 이미 결제를 받았다면 먼저 [주문 금액의 일부가 이미 결제된 경우](#split)를 확인하세요.

:::warning 결제 처리를 누를 때까지 결제 화면을 유지하세요
계산대는 다른 탭의 상태를 확인하지 않습니다. 고객이 결제한 주문에서 **결제 처리**를 눌러야만 판매가 완료되므로 고객이 결제하는 동안 결제 화면을 열어 두세요.
:::

1. 평소처럼 판매할 상품을 등록하고 **결제**를 누르세요.
2. **레거시** 탭을 여세요. POS 안에 매장의 결제 페이지가 로드됩니다.
3. **웹 결제**를 선택하세요. 그 아래에 안내 문구와 **이 주문 결제** 링크가 나타납니다.
4. **이 주문 결제**를 누르세요. 온라인 매장에서 해당 주문의 결제 페이지가 새 브라우저 탭으로 열립니다. 데스크톱 앱에서는 컴퓨터의 웹 브라우저로 열립니다.
5. 고객에게 화면을 넘겨주세요. 고객은 웹사이트에서와 마찬가지로 결제 수단을 선택하고 결제합니다.
6. 고객이 결제를 마치면 고객의 탭에 매장의 주문 확인 화면이 표시됩니다. 해당 탭을 열어 둔 채 POS로 돌아가세요.
7. **결제 처리**를 누르세요. 주문이 결제되었다면 일반적인 판매와 마찬가지로 계산대에 결제 완료 화면과 영수증이 표시됩니다. 결제되지 않았다면 현재 페이지에 머무릅니다. [문제 해결](#goes-wrong)을 확인하세요.
8. 계산대에 영수증이 표시되면 고객의 탭을 닫으세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[28, 32], [30, 32], [-26, 0], [192, -272], [-30, 0], [230, 0], [-78, 0]]} maxWidth={1024} alt="레거시 탭의 결제 화면: POS 안에 표시된 매장의 결제 페이지에 주문, 결제 게이트웨이 목록, 결제 처리 버튼이 있고, 옆에는 주문 번호와 남은 금액이 표시됨">

1. **결제** 탭 — 현금, 카드, 전용 타일이 있는 결제 게이트웨이의 타일이 표시됩니다.
2. **레거시** 탭 — 매장의 결제 페이지에서 실행되는 결제 게이트웨이입니다. [레거시 탭](../../pos/checkout/legacy-tab.mdx)을 확인하세요.
3. **닫기** — 결제를 받지 않고 장바구니로 돌아갑니다. 주문은 열린 상태로 유지됩니다.
4. **매장의 결제 페이지** — 주문에 이어 POS용으로 활성화한 결제 게이트웨이가 표시됩니다. 웹 결제를 활성화하면 이 목록에 추가됩니다. 이 이미지의 매장에는 웹 결제가 없습니다. 상단의 **결제 설정**은 페이지가 올바르게 표시되지 않을 때 사용합니다. [문제 해결](#goes-wrong)을 확인하세요.
5. **결제 처리** — 고객이 결제를 마친 후 누르세요. 주문이 결제될 때까지 계산대는 이 페이지에 머무릅니다.
6. **주문** — 주문 번호, 고객, 시간입니다.
7. **남은 금액** — 아직 결제하지 않은 금액입니다. 웹 결제는 주문 전체 금액을 청구하므로 다른 결제를 받은 후에는 사용할 수 없습니다.

</JourneyShot>

### 주문 금액의 일부가 이미 결제된 경우 {#split}

레거시 결제 게이트웨이는 주문 전체 금액을 청구하므로 결제를 받은 후에는 레거시 탭에 **이미 결제를 받은 경우 레거시 결제 게이트웨이를 사용할 수 없습니다**라는 메시지가 표시됩니다. 다음 두 가지 방법 중 하나를 선택하세요.

- 결제 탭의 현금이나 카드 등의 **타일에서 나머지 금액을 결제받으세요**. [분할 결제](../../pos/checkout/split-payments.mdx)를 확인하세요.
- **지금까지 받은 결제를 취소**한 다음 웹 결제로 주문 전체 금액을 결제받으세요. 취소가 실행되기 전에 계산대에서 각 결제의 처리 방식을 안내합니다. 현금은 고객에게 돌려주고, 다른 결제는 해당 결제 수단에서 승인 취소하며, 승인 취소가 불가능한 결제는 주문에서 환불합니다. [결제 취소](../../pos/checkout/cancelling-a-payment.mdx)를 확인하세요.

:::tip 고객이 나중에 자신의 휴대전화로 결제하고 싶어 하는 경우
웹 결제는 POS를 실행 중인 기기에서 결제 페이지를 엽니다. 고객에게 나중에 결제할 수 있는 링크를 보내려면 [이메일 청구서](./email-invoice.mdx)를 사용하세요.
:::

## 설정하기 {#set-up}

WP Admin에서 매장을 관리하는 담당자가 웹 결제로 첫 판매를 하기 전에 한 번 설정합니다. 웹 결제는 무료 플러그인이지만 POS에서는 WCPOS Pro가 있어야 사용할 수 있습니다. Pro가 없으면 계산대에서 현금과 카드 결제만 받을 수 있습니다. 온라인 매장에 이미 설정된 결제 수단을 사용하며 별도의 계정이나 키가 필요하지 않습니다.

<details>
<summary>매장 관리자: 설치 및 활성화</summary>

1. **설치하세요.** 웹 결제는 `WP Admin > POS > 설정 > 확장`에 없습니다. [GitHub 릴리스 페이지](https://github.com/wcpos/web-checkout-gateway/releases)에서 **woocommerce-pos-web-checkout-gateway.zip**을 다운로드하세요(소스 코드 zip이 아닙니다). `WP Admin > 플러그인 > Add Plugin`에서 **플러그인 업로드**로 업로드한 다음 활성화하세요.
2. **POS용으로 활성화하세요.** `WP Admin > POS > 설정 > 결제`에서 **웹 결제**를 활성화하고 저장하세요. [결제 설정](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)을 확인하세요. 온라인 결제 화면에는 표시되지 않으며 고객은 POS를 통해서만 접근할 수 있습니다.
3. **온라인 결제 수단을 확인하세요.** 고객은 `WP Admin > WooCommerce > 설정 > 결제`에서 웹용으로 활성화한 결제 수단을 사용합니다. 적어도 하나는 결제를 받을 수 있도록 준비되어 있어야 합니다.

</details>

<details>
<summary>이름 또는 메시지 변경</summary>

결제 페이지의 이름과 안내 문구는 `WP Admin > WooCommerce > 설정 > 결제 > Web Checkout Gateway`에 있는 결제 게이트웨이의 **제목**과 **설명**입니다. 기본 안내 문구는 “결제 페이지로 이동하여 주문을 결제하세요. 결제 후 결제 처리 버튼을 클릭하면 영수증으로 이동합니다.”입니다. POS에서만 이름을 바꾸려면 [결제 설정](../../settings/wp-admin/checkout.mdx#payment-gateways)에서 해당 결제 게이트웨이의 **⋮** 메뉴를 열고 **POS 설정**의 **제목**을 변경하세요. 안내 문구는 항상 WooCommerce에서 가져옵니다.

</details>

<details>
<summary>개발자용: 작동 방식</summary>

이 플러그인은 ID가 `wcpos_web_checkout`인 WooCommerce 결제 게이트웨이를 추가합니다. 코드에서 온라인 결제용으로는 비활성화되어 있으므로 POS에서만 제공할 수 있습니다. 결제 필드에는 설명과 주문 자체의 결제 URL(`$order->get_checkout_payment_url()`)로 연결되는 링크가 표시되며, 링크는 새 창으로 열립니다.

결제 게이트웨이 자체는 대금을 받지 않습니다. **결제 처리**를 통해 POS에서 생성된 이미 결제된 주문이 `wcpos_web_checkout`이 선택된 상태로 전송되면, 플러그인은 결제 페이지를 주문 접수 페이지로 이동시키고 POS는 그 화면에서 판매를 완료합니다. 결제되지 않은 주문은 다음 단계로 넘어가지 않습니다. 소스는 [web-checkout-gateway 저장소](https://github.com/wcpos/web-checkout-gateway)에 있습니다.

</details>

## 문제 해결 {#goes-wrong}

**레거시 탭의 목록에 웹 결제가 없습니다.** 플러그인이 활성화되지 않았거나 [결제 설정](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)에서 웹 결제가 활성화되지 않은 상태입니다. WCPOS Pro가 없으면 POS에서 현금과 카드만 제공합니다.

**“POS용으로 활성화된 레거시 결제 게이트웨이가 없습니다.”** 타일이 없는 결제 게이트웨이가 하나도 활성화되지 않은 상태입니다. 결제 설정에서 웹 결제를 활성화하세요.

**결제 처리를 눌러도 영수증으로 넘어가지 않습니다.** 매장에 해당 주문이 결제된 것으로 기록되지 않은 상태입니다. 고객에게 다시 결제하도록 요청하기 전에 고객의 탭을 확인하세요. 결제 페이지가 여전히 표시된다면 아직 결제를 마치지 않은 것입니다. 주문 확인 화면이 표시된다면 **결제 처리**를 다시 누르세요. 그래도 계산대가 다음 단계로 넘어가지 않으면 `WP Admin > WooCommerce > Orders`에서 주문을 확인하세요.

**결제 페이지에 고객이 사용할 수 있는 결제 수단이 표시되지 않습니다.** 온라인 매장에 고객에게 적합한 결제 수단이 활성화되어 있지 않습니다. `WP Admin > WooCommerce > 설정 > 결제`에서 웹용 결제 수단을 활성화하세요.

**POS 안의 결제 페이지가 올바르게 표시되지 않습니다.** 테마나 플러그인이 영향을 주고 있을 수 있습니다. [결제 게이트웨이의 결제 페이지가 올바르게 표시되지 않는 경우](../../pos/checkout/troubleshooting.mdx#checkout-settings-troubleshooting)를 확인하세요.
