# Mercado Pago Terminal 결제 게이트웨이 {#mercado-pago-terminal-gateway}

POS에서 주문 합계를 Mercado Pago **Point Smart** 단말기로 보내면 고객이 단말기에서 결제합니다. Mercado Pago가 결제를 확인하면 판매가 자동으로 완료됩니다. 이 페이지는 POS에서 [결제 받기](#take-payment)와 WP Admin에서 [설정하기](#setup), 두 부분으로 구성되어 있습니다.

:::warning 베타: 먼저 테스트 결제를 진행하세요
새로 출시된 확장 기능입니다. 아직 이 확장 기능으로 카드 결제나 환불을 완료한 적이 없으므로, 실제로 사용하기 전에 소액을 결제하고 환불해 보세요.

<details>
<summary>지금까지 확인한 내용</summary>

실운영 계정과 실제 Point Smart에서 단말기 목록 조회, 단말기의 PDV 모드 전환, Mercado Pago를 통한 단말기 결제 생성 및 취소가 정상적으로 작동했습니다. 생성한 결제가 단말기에 표시되는지, 카드 결제 완료, 결제된 주문에 대한 Mercado Pago 알림, 환불, Mercado Pago 샌드박스(**테스트** 모드)는 아직 확인하지 않았습니다.

</details>
:::

## 결제 받기 {#take-payment}

POS 내부에 표시되는 매장 자체 결제 페이지에서 결제가 진행되므로 [WCPOS Pro](../../getting-started/pro-license.mdx)가 필요하며 매장이 온라인 상태여야 합니다. 먼저 WP Admin 접근 권한이 있는 담당자가 [결제 게이트웨이를 설정](#setup)해야 합니다.

:::note 먼저 계산대를 여세요
**계산대 열기 및 닫기**가 켜져 있으면 계산대가 닫힌 동안에는 POS에서 결제를 기록할 수 없으며, 이미 받은 카드 결제는 환불해야 합니다. [결제](../../pos/checkout/index.mdx)를 참고하세요.
:::

단말기는 결제 화면의 **레거시** 탭에서 작동합니다. 아래 화면은 Mercado Pago를 설정하지 않은 상태이므로 다른 결제 게이트웨이가 표시되며 **카드**가 선택되어 있습니다. 매장에서 설정을 마치면 이 목록에 **Mercado Pago Terminal**이 표시됩니다.

3. **결제 처리** — Mercado Pago에서는 필요하지 않습니다. 결제가 확인되면 판매가 자동으로 완료됩니다.

1. 장바구니에 상품을 담고 **결제**를 누르세요.
2. **레거시** 탭을 여세요. POS 내부에 매장 결제 페이지가 열립니다. [레거시 탭](../../pos/checkout/legacy-tab.mdx)을 참고하세요.
3. **Mercado Pago Terminal**을 선택하세요. 매장에서 다른 이름으로 지정했을 수도 있습니다.
4. **단말기** 항목에서 단말기를 확인하세요. 기본 단말기가 미리 선택되어 있으며, 단말기 선택이 잠겨 있으면 변경할 수 없습니다.
5. **단말기 결제 시작**을 누르세요. 패널에 **단말기로 전송 중…**, 이어서 **단말기 응답 대기 중…** 이 표시되고 주문 총액이 해당 단말기로 전송됩니다.
6. 고객이 단말기에서 결제합니다. 결제하는 동안 패널에 **고객이 단말기에서 결제 중…** 이 표시됩니다. **단말기에서 결제를 확인하세요.** 라는 메시지가 나타나면 단말기가 요청하는 단계를 완료하세요.
7. Mercado Pago가 결제를 확인하면 패널에 **결제 완료 — 주문 마무리 중…** 이 표시되고 POS가 영수증 화면으로 이동합니다.

레거시 탭 하단의 **결제 처리**는 누를 필요가 없습니다. Mercado Pago가 확인하면 판매가 자동으로 완료됩니다. 그 전에 누르면 주문이 아직 결제되지 않았다는 메시지만 표시됩니다.

단말기에는 항상 주문 총액이 청구되므로 다른 결제 수단과 나누어 결제할 수 없습니다. 주문에 이미 받은 결제가 있으면 레거시 탭을 사용할 수 없습니다. 먼저 [해당 결제를 취소](../../pos/checkout/cancelling-a-payment.mdx)하세요.

### 취소 또는 대기 {#payment-controls}

- 결제가 진행되는 동안 **단말기 결제 시작** 대신 **단말기 결제 취소**가 표시됩니다. 취소는 단말기가 결제를 수신하기 전까지만 가능합니다. 그 이후에는 패널에 **결제가 이미 단말기로 전달되었습니다. 단말기에서 취소하거나 만료될 때까지 기다리세요.** 라고 표시됩니다.
- 결제를 시작한 지 5분이 지나면 Mercado Pago에서 **결제가 만료됩니다**. 패널은 계속 상태를 확인하므로 고객이 그 전에 결제를 마치면 판매가 정상적으로 완료됩니다.
- **페이지를 새로고침하면** 진행 중이던 결제를 이어서 처리하며 **단말기 결제 취소**가 표시됩니다.
- 결제 중 **POS가 닫혔다면** 카드에 다시 청구하지 마세요. 매장은 Mercado Pago 알림과 5분마다 실행하는 확인 작업을 통해 결제된 주문을 자동으로 완료하도록 설계되어 있지만, 아직 실운영 환경에서 확인하지 않았습니다. 주문과 Mercado Pago 계정의 결제 내역을 열어 결제 여부를 확인하세요.

## 판매 후 {#receipts}

단말기는 전표를 인쇄하지 않습니다. 평소처럼 POS 영수증을 인쇄하거나 이메일로 보내세요. [결제 시 영수증](../../receipts/at-checkout.mdx)을 참고하세요.

주문에는 Mercado Pago 주문 ID를 거래 ID로 사용하여 결제가 기록됩니다.

## 환불 {#refunds}

WP Admin에서 주문을 열고 **환불**을 클릭한 다음 금액을 입력하고 **Mercado Pago Terminal을 통해 … 환불**을 누르세요. 주문 총액을 환불하면 전액 환불로, 그보다 적은 금액은 부분 환불로 처리됩니다. Mercado Pago에서는 결제 후 **90일**까지 환불할 수 있습니다.

일부 카드 매입사는 단말기에서만 환불을 허용합니다. Mercado Pago가 환불을 거부하면 Point 단말기에서 환불한 다음 WooCommerce에서 **수동 환불**로 환불을 기록하세요. [환불](../../pos/refunds.mdx)을 참고하세요.

## 문제가 발생한 경우 {#goes-wrong}

패널의 상태 표시줄에서 발생한 상황을 알려 줍니다. 같은 문구로 시작하는 항목을 여세요.

### 결제가 시작되지 않는 경우 {#wont-start}

<details>
<summary>먼저 단말기를 선택하세요.</summary>

**단말기** 항목에서 단말기를 선택한 다음 **단말기 결제 시작**을 다시 누르세요.

</details>

<details>
<summary>단말기 …이(가) STANDALONE 모드입니다.</summary>

아직 단말기가 POS의 결제를 받을 수 없습니다. 결제 게이트웨이 설정 담당자에게 [PDV로 전환](#terminals)한 후 다시 시작해 달라고 요청하세요.

</details>

<details>
<summary>이 Mercado Pago 계정에서 단말기를 찾을 수 없습니다. / 단말기를 불러올 수 없습니다.</summary>

매장에서 단말기 목록을 조회할 수 없습니다. 결제 게이트웨이 설정 담당자에게 [진단 정보](#settings)를 확인해 달라고 요청하세요.

</details>

<details>
<summary>Mercado Pago Terminal이 비활성화되어 있습니다.</summary>

POS에서 이 결제 게이트웨이가 꺼져 있습니다. WP Admin 담당자에게 [켜 달라고](#turn-on) 요청하세요.

</details>

<details>
<summary>Mercado Pago Terminal 요청에 실패했습니다.</summary>

POS가 매장 또는 Mercado Pago에 연결하지 못했습니다. 고객이 이미 결제했을 가능성이 있다면 다른 결제를 시작하기 전에 주문과 Mercado Pago 계정을 확인하세요. 그렇지 않으면 연결을 확인하고 다시 시도하세요. 문제가 계속되면 [지원용 자료 묶음](#logs-and-support-bundle)을 보내세요.

</details>

### 결제가 멈추거나 실패하는 경우 {#stalls}

다시 시작하기 전에 단말기를 확인하세요. **카드에 절대 두 번 청구하지 마세요**. 고객이 이미 결제했을 가능성이 있다면 먼저 주문과 Mercado Pago 계정을 확인하세요.

<details>
<summary>아직 단말기 응답을 기다리고 있습니다.</summary>

응답 없이 일 분이 지났습니다. 단말기에 결제가 표시되면 고객이 결제를 마치도록 하세요. 표시되지 않으면 **단말기 결제 취소**를 누르고 다시 시작하세요.

</details>

<details>
<summary>결제가 이미 단말기로 전달되었습니다.</summary>

단말기에서 취소하거나 5분이 지나 만료될 때까지 기다리세요. 패널은 계속 상태를 확인하므로 그 사이 고객이 결제하면 판매가 완료됩니다.

</details>

<details>
<summary>결제에 실패했습니다.</summary>

카드 또는 결제가 거부되었습니다. **단말기 결제 시작**을 눌러 다시 시도하거나 다른 결제 수단을 사용하세요.

</details>

<details>
<summary>단말기에서 결제가 만료되었습니다.</summary>

오 분이 지났습니다. **단말기 결제 시작**을 다시 누르세요.

</details>

<details>
<summary>단말기 응답 대기 시간이 초과되었습니다.</summary>

결과 없이 육 분이 지나 POS가 Mercado Pago에 결제 취소를 요청합니다. 다시 시작하기 전에 단말기를 확인하세요.

</details>

<details>
<summary>Mercado Pago가 이 주문과 일치하지 않는 결제를 보고했습니다.</summary>

합계나 통화가 변경되는 등의 이유로 결제가 이 주문과 일치하지 않습니다. 카드에 다시 청구하지 마세요. 주문 메모와 Mercado Pago 계정의 결제 내역을 확인하고 관리자에게 연락하세요.

</details>

<details>
<summary>설정 중 표시되는 메시지</summary>

**Mercado Pago가 액세스 토큰을 거부했습니다(HTTP 401).** 토큰이 잘못되었거나 만료되었습니다. Mercado Pago의 **내 연동** → **인증 정보**에서 새 토큰을 복사하여 **액세스 토큰**에 저장하세요.

**액세스 토큰에 Point 사용 권한이 없습니다(HTTP 403).** 토큰에 연결된 애플리케이션이 Point를 사용할 수 없습니다. **내 연동**에서 애플리케이션을 확인하세요.

**Mercado Pago에 연결할 수 없습니다.** 매장에서 연결하지 못했습니다. 토큰을 확인한 다음 설정 페이지를 새로고침하세요.

**아직 이 Mercado Pago 계정에 연결된 Point 단말기가 없습니다.** 단말기에서 이 Mercado Pago 계정으로 로그인한 다음 PDV로 전환하고 다시 시작하세요.

**기본 단말기가 목록 대신 텍스트 상자로 표시됩니다.** 단말기 목록을 불러오지 못했습니다. 토큰과 진단 정보를 확인한 다음 설정 페이지를 새로고침하세요.

**실운영 모드가 선택되어 있지만 액세스 토큰이 테스트 토큰(TEST-…)입니다.** 이 상태에서는 결제가 Mercado Pago 샌드박스로 전송됩니다. 운영용 토큰을 붙여넣거나 **모드**를 **테스트**로 되돌리세요.

**마지막으로 검증된 웹훅: 없음.** Mercado Pago가 아직 서명된 알림을 보내지 않았습니다. 웹훅 URL과 **웹훅 비밀 키**를 확인하세요. 결제 패널이 열려 있는 동안에는 웹훅이 없어도 결제를 완료할 수 있습니다.

**Mercado Pago가 환불을 거부했습니다.** 일부 매입사는 단말기에서만 환불을 허용합니다. 단말기에서 환불한 다음 **수동 환불**로 기록하세요.

**활성화가 거부되었습니다.** 서버에 **PHP 7.4** 이상이 필요합니다.

</details>

## 설정하기 {#setup}

이 부분은 매장의 WP Admin 담당자를 위한 안내입니다. 1단계를 시작하기 전에 [필요한 사항](#requirements)을 확인하세요.

### 필요한 사항 {#requirements}

### 1. 확장 기능 설치 {#install}

`WP Admin > POS > 설정 > 확장`을 열고 **Mercado Pago Terminal for WooCommerce**를 찾아 **설치**를 클릭하세요. WCPOS가 다운로드, 설치, 활성화를 한 번에 처리합니다. [확장 기능 설치](../../extensions/index.mdx#installing-an-extension)를 참고하세요.

확장 기능 디렉터리를 사용하지 않는 경우 [GitHub 릴리스 페이지](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases)에서 소스 코드 zip이 아닌 **플러그인 zip**을 다운로드하세요. `플러그인 > Add Plugin`의 **플러그인 업로드**로 업로드한 다음 활성화하세요. WooCommerce가 활성화되어 있어야 합니다.

### 2. Mercado Pago에서 준비 {#mercado-pago-account}

1. **내 연동**에서 애플리케이션을 생성하고 운영용 인증 정보를 활성화하세요. Mercado Pago에서 업종과 웹사이트를 입력하고 약관에 동의하며 reCAPTCHA를 통과하도록 요청합니다.
2. Mercado Pago에서 **매장**과 **POS**를 생성하세요. 확장 기능이 대신 생성해 주지는 않습니다.
3. Point Smart 단말기를 연결하세요. 단말기에서 동일한 Mercado Pago 계정으로 로그인하면 됩니다.

### 3. 결제 게이트웨이 설정 입력 {#gateway-settings}

1. `WP Admin > WooCommerce > 설정 > 결제`로 이동하여 **Mercado Pago Terminal**을 여세요.
2. **모드**를 선택하세요. **테스트**(기본값)는 Mercado Pago의 샌드박스 가상 단말기를, **실운영**은 실제 단말기를 작동시킵니다.
3. **내 연동** → **인증 정보**에 있는 애플리케이션의 **액세스 토큰**(`APP_USR-…`)을 붙여넣으세요. **모드**에 맞는 토큰을 사용하세요.
4. 칠레 페소처럼 소수 단위를 사용하지 않는 통화라면 `WooCommerce > 설정 > General`에서 **소수 자릿수**를 **0**으로 설정하세요. Mercado Pago는 이러한 계정에서 소수점이 포함된 금액을 거부하며, 이 설정이 0일 때만 확장 기능이 정수 금액을 전송합니다.
5. 저장하세요.

### 4. 웹훅 추가(권장) {#webhook}

웹훅을 통해 Mercado Pago가 결제 완료 사실을 매장에 알립니다. POS가 닫혀 있어도 결제된 주문을 완료하도록 설계되어 있지만, 아직 실운영 환경에서 확인하지 않았습니다. 다시 청구하기 전에 [주문을 확인](#payment-controls)하세요. 웹훅이 없어도 결제 패널이 열려 있는 동안에는 결제를 완료할 수 있습니다.

1. Mercado Pago에서 **내 연동** → 해당 애플리케이션 → **웹훅**을 여세요.
2. 결제 게이트웨이 설정의 **웹훅 비밀 키** 아래에 표시된 웹훅 URL을 추가하세요. URL은 `admin-ajax.php?action=mptfwc_webhook`으로 끝납니다.
3. **주문(Mercado Pago)** 이벤트를 선택하고 저장하세요.
4. **비밀 서명**을 **웹훅 비밀 키**에 복사하고 저장하세요. 비밀 키가 저장되어 있으면 매장은 해당 키로 서명되지 않은 알림을 모두 거부합니다. 비밀 키가 없으면 Mercado Pago 알림에 따라 처리하기는 하지만, Mercado Pago가 보낸 알림인지 확인할 수 없으며 **마지막으로 검증된 웹훅**은 **없음**으로 유지됩니다.

### 5. 단말기 설정 {#terminals}

1. 설정 페이지를 새로고침하세요. 이제 **기본 단말기** 목록과 **단말기** 표에 계정의 단말기가 표시됩니다.
2. 단말기는 **STANDALONE** 모드로 출고됩니다. 각 단말기에서 **PDV로 전환**을 클릭한 다음 **단말기를 다시 시작하세요**. Mercado Pago에서는 다시 시작해야 합니다.
3. **기본 단말기**를 선택하세요.
4. 선택 사항: **활성화된 단말기**를 캐셔가 선택할 수 있는 단말기로 제한하세요. 비워 두면 모두 허용되며 기본 단말기는 항상 허용됩니다.
5. 선택 사항: 캐셔가 항상 기본 단말기를 사용하도록 **단말기 선택 잠금**을 선택하세요.
6. 저장하세요.

### 6. POS에서 활성화 {#turn-on}

`WP Admin > POS > 설정 > 결제`로 이동하여 **Mercado Pago Terminal**을 찾고 **활성화됨**을 켜세요. [결제 게이트웨이 활성화](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)를 참고하세요.

온라인에서도 사용하려는 경우가 아니라면 WooCommerce 설정의 **활성화/비활성화**는 꺼 두세요. 이 확인란의 선택 여부와 관계없이 여기에서 활성화하면 POS에서 결제 게이트웨이를 사용합니다.

## 설정 참고 자료 {#settings}

`WP Admin > WooCommerce > 설정 > 결제 > Mercado Pago Terminal`에서 설정합니다. 위 단계에서는 필요한 설정을 안내했습니다. 모든 설정과 기본값을 보려면 목록을 여세요.

<details>
<summary>전체 11개 설정과 진단 정보</summary>

| 설정 | 기능 |
|---|---|
| **활성화/비활성화** | 온라인 매장에서도 이 결제 게이트웨이를 제공합니다. 기본값은 꺼짐입니다. POS에는 `POS > 설정 > 결제`에 별도의 스위치가 있습니다 |
| **제목** | 캐셔가 결제 페이지에서 선택하는 이름입니다. 기본값은 `Mercado Pago Terminal`입니다 |
| **설명** | 제목 아래에 표시되는 문구입니다. 기본값은 `Pay in person on a Mercado Pago Point terminal.`입니다 |
| **모드** | **테스트**(기본값)는 샌드박스 가상 단말기를, **실운영**은 실제 단말기를 작동시킵니다 |
| **액세스 토큰** | 내 연동 → 인증 정보의 애플리케이션에서 가져옵니다. 저장한 후에는 전체 토큰 대신 마지막 네 글자만 표시됩니다. 기존 토큰을 유지하려면 비워 두세요 |
| **웹훅 비밀 키** | Mercado Pago 웹훅 설정의 비밀 서명입니다. 토큰과 같은 방식으로 저장되고 표시됩니다 |
| **기본 단말기** | 처음에 선택되는 단말기입니다. 계정에서 가져온 목록으로 표시되며, 목록을 불러올 수 없으면 텍스트 상자로 표시됩니다 |
| **활성화된 단말기** | 캐셔가 선택할 수 있는 단말기입니다. 비워 두면 모두 허용되며 기본 단말기는 항상 허용됩니다. 목록을 불러올 수 없으면 숨겨집니다 |
| **단말기 선택 잠금** | 캐셔가 단말기를 변경할 수 없으며 항상 기본 단말기를 사용합니다. 기본 단말기가 필요합니다 |
| **결제 디버그 로그** | 결제 패널에 **로그 표시**, **복사**, **지우기**를 표시합니다. 기본값은 꺼짐이며, 지원 요청용 로그를 수집할 때 켜세요. 이 설정과 관계없이 결제는 로그에 기록됩니다 |
| **로그 수준** | **꺼짐**, **오류만** 또는 **디버그**(기본값) |

설정 아래의 **Mercado Pago Terminal 진단**에는 단말기 수와 PDV 모드인 단말기 수를 포함한 API 확인 결과, 마지막으로 검증된 웹훅, 현재 환경, 토큰과 비밀 키 설정 여부, 기본 단말기, 웹훅 URL, 로그 링크가 표시됩니다. **단말기** 표에는 각 단말기의 ID, 이름, 작동 모드와 함께 필요한 경우 **PDV로 전환**이 표시됩니다.

</details>

## 로그 및 지원용 자료 묶음 {#logs-and-support-bundle}

로그는 `WP Admin > WooCommerce > Status > 로그`의 `mercadopago-terminal` 소스에 있습니다. **로그 수준**의 초기값은 **디버그**로, Mercado Pago에 보내는 모든 요청과 응답, 모든 웹훅, 모든 결제 상태 변경을 기록하며 토큰, 서명, 카드 번호는 제거됩니다.

결제에 실패하면 결제 게이트웨이 설정 페이지에서 **지원용 자료 묶음 다운로드**를 클릭하고 `.txt` 파일을 **주문 번호**와 함께 지원팀에 보내세요. 이 파일에는 결제를 받는 데 사용할 수 있는 정보가 없습니다.

<details>
<summary>지원용 자료 묶음에 포함된 내용</summary>

- 매장 구성: 확장 기능, WordPress, WooCommerce, PHP, WCPOS 버전과 HPOS 사용 여부.
- 액세스 토큰과 웹훅 비밀 키를 가린 결제 게이트웨이 설정.
- 단말기와 각 단말기의 작동 모드.
- 단말기를 사용한 최근 주문 10건의 결제 시도 내역.
- `mercadopago-terminal` 로그의 마지막 500줄.

</details>

## 지원하지 않는 기능 {#scope-and-limitations}

- 분할 결제: 단말기에는 항상 주문 총액이 청구됩니다.
- 팁.
- Mercado Pago 계정과 다른 통화로 가격을 책정한 매장: 주문이 완료되지 않습니다.
- 단말기에서 전표 인쇄.
- 온라인 매장의 블록 결제 화면.
- HPOS(WooCommerce 주문 테이블): 확장 기능이 아직 지원을 선언하지 않았습니다.

<details>
<summary>개발자를 위한 작동 원리</summary>

결제 게이트웨이는 Point용 Mercado Pago **주문 API**를 사용합니다(`type: point`를 지정한 `POST /v1/orders`). 결제를 시작하면 주문에 멱등성 키와 외부 참조를 저장한 다음, 선택한 단말기에서 주문 총액으로 Mercado Pago 주문을 생성합니다. 만료 시간은 5분입니다(필터: `mptfwc_order_expiration_time`). 시간 초과 후 다시 시도할 때는 같은 키를 사용하므로 중복 청구되지 않습니다.

패널은 2초마다 상태를 요청하며(필터: `mptfwc_poll_interval_ms`) 6분이 지나면 중단합니다. 웹훅(`x-signature`, HMAC-SHA256)과 5분마다 실행되는 예약 확인 작업으로도 주문을 완료할 수 있습니다. 웹훅 본문을 그대로 신뢰하지 않으며 항상 Mercado Pago에서 주문을 다시 가져옵니다.

Mercado Pago 주문이 해당 주문을 참조하고, 이 매장에서 해당 주문을 위해 생성되었으며, `point` 주문이고, 합계와 통화가 일치하고, 해당 결제 시도의 단말기를 사용한 경우에만 주문이 완료됩니다. 완료 처리는 주문별 잠금 아래에서 한 번만 실행됩니다. 거래 ID는 Mercado Pago 주문 ID입니다.

</details>
