# PayArc Terminal 결제 게이트웨이 {#payarc-terminal-gateway}

PayArc Terminal은 POS에서 PayArc PAX 단말기로 판매 결제를 전송합니다. 고객이 단말기에서 결제하면 PayArc가 이를 확인한 뒤 POS에 결제가 기록됩니다.

이 페이지에서는 POS에서 사용하는 방법부터 설명합니다. 결제 게이트웨이 설정 방법은 [PayArc Terminal 설정](#setup)을 참조하세요.

:::info Pro 기능
PayArc Terminal을 사용하려면 [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0 이상이 필요합니다.
:::

## 카드 결제 받기 {#take-payment}

:::note 먼저 계산대를 여세요
**계산대 열기 및 닫기**가 켜져 있으면 계산대가 닫힌 동안에는 POS에 결제가 기록되지 않으며, 이미 받은 카드 결제는 환불해야 합니다. 이 설정은 [계산대](../../settings/wp-admin/registers.mdx#one-register)를 참조하세요.
:::

장바구니에서 **결제**를 누르세요. **결제** 탭에 다른 결제 수단과 함께 PayArc Terminal 타일이 표시됩니다.

1. **PayArc Terminal** 타일을 누르세요.
2. 키패드 위의 **단말기: …** 에 표시된 단말기 이름을 확인하세요. 단말기가 여러 대라면 **변경**을 누르고 해당 계산대의 단말기를 선택하세요. POS는 다음에도 이 선택을 기억합니다.
3. 잔액 중 일부만 카드로 받으려면 금액을 입력하세요. 나머지 금액은 다른 결제 수단으로 받을 수 있도록 미결제 상태로 남습니다.
4. **PayArc Terminal로 … 전송**을 누르세요. POS에 **단말기에서 진행 중**이 표시되며 **전송됨**, **단말기에서 진행 중**, **승인됨**, **매입 완료**의 네 단계가 나타납니다.
5. 고객이 단말기에서 결제합니다. 결제 매입이 완료되고 남은 결제 금액이 없으면 영수증이 열립니다. 남은 금액이 있으면 다른 타일을 선택해 결제를 받으세요.

단계 아래의 **상세 정보**를 누르면 결제 전송 시각, 단말기에 도착한 시각, 승인 금액이 담긴 결제 로그가 열립니다. 결제에는 카드 브랜드, 마지막 4자리, 카드 인식 방식, PayArc 승인 코드가 저장됩니다.

단말기에는 팁 입력 화면이 표시되지 않습니다. 팁 입력을 지원하는 단말기는 [팁](../../pos/checkout/tips.mdx)을 참조하세요.

### 결제 취소 {#cancel}

고객이 결제하기 전에 **단말기에서 취소**를 누르세요. POS는 단말기의 확인을 기다린 뒤 **결제가 취소되었습니다**를 표시합니다.

카드를 이미 읽고 있다면 PayArc가 취소를 거부하고 결제를 완료할 수 있습니다. POS는 계속 확인하면서 결과를 표시합니다. 기다리는 동안 **취소 중 — 단말기의 확인을 기다리는 중**이 표시되며 **이 결제 해제**를 선택할 수 있습니다. 결제를 해제하면 매장에서 단말기 상태를 계속 확인하는 동안 해당 주문을 다른 수단으로 결제할 수 있습니다.

:::warning
해제해도 결제가 취소되는 것은 아닙니다. 단말기에서 결제가 완료될 수 있습니다. 다른 결제를 받기 전에 단말기의 결과를 확인하세요.
:::

## 결제에 문제가 생긴 경우 {#goes-wrong}

:::warning
**단말기에서 다른 금액이 확인되었나요?** 결제를 다시 받지 마세요. 먼저 단말기, 주문, PayArc 대시보드를 확인하세요.
:::

<Accordion>
  <AccordionItem question="결제 실패: 카드 승인 거절">

  **다시 시도**를 눌러 단말기로 다시 전송하거나 **다른 방법 선택**을 눌러 다른 타일로 결제하세요.

  </AccordionItem>
  <AccordionItem question="PayArc 자체 메시지와 함께 결제 실패가 표시됨">

  단말기의 전원이 꺼져 있거나 온라인 상태가 아닌 경우 등에는 PayArc가 판매 결제를 거부합니다. 단말기를 확인한 뒤 **다시 시도**를 누르세요.

  </AccordionItem>
  <AccordionItem question="시간 초과 — 결제가 취소되었습니다">

  5분 안에 결제가 이루어지지 않았거나 단말기가 카드를 기다렸지만 카드가 제시되지 않았습니다. 단말기를 확인한 뒤 **다시 시도**를 누르세요.

  </AccordionItem>
  <AccordionItem question="PayArc Terminal 타일이 회색으로 비활성화됨">

  POS의 타일 아래에 이유가 표시됩니다. 모든 이유는 [타일을 사용할 수 없는 경우](../index.mdx#unavailable-tiles)를 참조하세요.

  - **PayArc Terminal에 설정된 단말기가 없습니다** — 매장에 이 결제 게이트웨이용 단말기가 없습니다. 관리자가 [PayArc Terminal 설정](#setup)의 4단계에서 단말기를 추가해야 합니다.
  - **주문 #…에서 사용 중** — 단말기가 다른 주문의 결제를 처리하고 있습니다. 해당 결제를 완료하거나 취소하세요. 또는 **변경**을 눌러 다른 단말기를 선택하세요.
  - **연결 필요** — POS가 오프라인 상태입니다. 단말기 결제는 매장 서버를 거치므로 다른 종류의 결제를 받거나 연결될 때까지 기다리세요.

  </AccordionItem>
  <AccordionItem question="연결이 불안정하여 계속 시도 중">

  이 메시지는 **상세 정보** 로그에 표시됩니다. POS는 계속 상태를 확인합니다. 단말기에서 결제가 계속 진행되므로 화면을 열어 두세요.

  </AccordionItem>
  <AccordionItem question="결제가 멈췄거나 POS에 결제 서비스 제공업체의 응답이 없다고 표시됨">

  [카드 리더기 결제가 멈춘 경우](../index.mdx#card-reader-problems)를 참조하세요.

  </AccordionItem>
  <AccordionItem question="결제 대기 시간이 너무 김">

  - 단말기 화면을 확인하고 결제 화면을 열어 두세요
  - **5분**이 지나면 POS가 중단되고 **시간 초과 — 결제가 취소되었습니다**가 표시됩니다
  - 결제를 다시 받기 전에 단말기, 주문 메모, PayArc 대시보드를 확인하세요

  </AccordionItem>
  <AccordionItem question="이 주문의 이전 PayArc Terminal 결제를 현재 PayArc 인증 정보로 읽을 수 없음">

  - 다른 방법으로 결제를 받거나 관리자에게 문의하세요. 이 주문에는 모드 또는 인증 정보가 변경되기 전에 받은 결제가 있습니다
  - 관리자는 해당 결제를 받은 모드의 PayArc 대시보드에서 결제를 확인합니다
  - 이 주문에서 PayArc를 다시 사용하려면 관리자가 PayArc를 해당 모드로 되돌린 뒤 **이 인증 정보로 연결**을 클릭해야 합니다. 그런 다음 화면을 새로고침하세요

  </AccordionItem>
</Accordion>

## PayArc 결제 환불 {#refunds}

전액 또는 일부 금액의 환불 요청은 판매 결제를 받은 단말기로 전송됩니다.

1. POS에서 해당 주문의 환불 화면을 여세요. [환불](../../pos/refunds.mdx)을 참조하세요.
2. **PayArc Terminal로 환불**을 선택하고 **환불 처리**를 누르세요.
3. PayArc가 단말기로 환불 요청을 전송하면 단말기에서 승인하거나 거절합니다. 단말기가 응답할 때까지 환불은 대기 상태로 유지되며, 결과는 주문 메모에 추가됩니다.

WP Admin에서 WooCommerce의 **PayArc Terminal을 통해 … 환불** 버튼으로 환불할 때도 동일하게 작동합니다.

환불이 계속 대기 상태라면 다시 환불하기 전에 PayArc 대시보드를 확인하세요.

<details>
<summary>PayArc가 환불 요청에 응답하지 않는 경우</summary>

매장은 동일한 요청 키로 2분마다 최대 5회 다시 요청하므로 PayArc는 각 재시도를 동일한 환불로 처리합니다. 그래도 응답이 없으면 직원에게 PayArc 대시보드를 확인하라는 안내가 표시됩니다.

</details>

<details>
<summary>이전 버전에서 받은 결제</summary>

**이 PayArc 결제는 플러그인 자체의 주문 결제 패널에서 받았습니다.** WCPOS 2 이전의 확장 프로그램 버전 0.1에서 받은 결제이므로 결제 게이트웨이에서 환불할 수 없습니다. PayArc 대시보드나 단말기에서 환불한 다음 WooCommerce에서 **… 수동 환불**로 기록하세요.

</details>

## PayArc Terminal 설정 {#setup}

관리자가 WP Admin에서 결제 게이트웨이를 한 번 설정한 뒤 각 POS에서 단말기를 선택합니다.

<details>
<summary>설정 전 준비 사항</summary>

### 요구 사항 {#requirements}

PayArc는 MID, ClientSecret, SecretKey와 계정에 설정된 단말기의 일련번호를 제공합니다.

매장은 인터넷을 통해 PayArc를 거쳐 각 단말기에 연결하므로 별도로 페어링할 필요가 없으며, 어느 POS에서든 모든 단말기를 사용할 수 있습니다. WCPOS Pro 2.0 이상이 없으면 확장 프로그램은 WP Admin에 알림만 표시하고 POS에는 아무것도 추가하지 않습니다.

<RequirementsList>
  <RequirementItem label="PayArc 계정">PayArc Connect V3 접근 권한이 있는 가맹점 계정</RequirementItem>
  <RequirementItem label="호환 하드웨어">계정에 할당된 PayArc 지원 PAX 단말기</RequirementItem>
  <RequirementItem label="연결">인터넷 연결만 지원합니다. 매장은 일련번호를 사용해 각 결제를 PAX 단말기로 전송하므로 모든 POS에서 해당 단말기를 사용할 수 있습니다. 각 POS는 결제 시 단말기를 선택합니다</RequirementItem>
  <RequirementItem label="WCPOS">WCPOS Pro 2.0 이상 및 확장 프로그램 버전 1.0 이상</RequirementItem>
  <RequirementItem label="서버">WooCommerce 7.0+, PHP 7.4+, 실거래 모드용 HTTPS</RequirementItem>
  <RequirementItem label="통화">USD, CAD, GBP, EUR 또는 JPY</RequirementItem>
</RequirementsList>

</details>

<details>
<summary>여섯 단계: 설치, 연결, 단말기 추가, 활성화, 각 POS의 단말기 선택</summary>

<Steps>
  <StepCard number="1" title="PayArc Terminal for WooCommerce 설치">

[GitHub 릴리스 페이지](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases)에서 버전 1.0 이상의 **payarc-terminal-for-woocommerce.zip**을 다운로드하고 `플러그인 > Add Plugin`에서 **플러그인 업로드**를 선택해 업로드하세요. 플러그인을 활성화하세요.

`WP Admin > POS > 설정 > 확장`에는 WCPOS 2 이전에 제작된 버전 0.1이 아직 표시될 수 있습니다. 해당 화면에서 설치하기 전에 버전을 확인하세요.

  </StepCard>
  <StepCard number="2" title="PayArc 인증 정보 입력">

1. `WP Admin > WooCommerce > 설정 > 결제`로 이동해 **PayArc Terminal**을 여세요
2. **모드**를 선택하세요. 기본값은 `Live`입니다. `Test`는 PayArc 테스트 대시보드 인증 정보 및 PayArc Connect Test 앱과 함께만 사용하세요. 환경을 혼용하지 마세요
3. PayArc 가맹점 대시보드에 로그인할 때 사용하는 이메일을 **PayArc 로그인 이메일**에 입력하세요
4. 단말기 ID가 아닌 PayArc 가맹점 프로필의 **PayArc MID**를 입력하세요
5. 대시보드 API 섹션의 **PayArc ClientSecret**과 PayArc 대시보드의 **PayArc SecretKey / API 베어러 토큰**을 입력하세요
6. PayArc 지원팀에서 발급받은 토큰이 없다면 **콜백 베어러 토큰**을 비워 두세요

  </StepCard>
  <StepCard number="3" title="연결">

**이 인증 정보로 연결**을 클릭하세요. 연결되면 화면에 **PayArc에 연결됨**이 표시되며 단말기 일련번호를 입력하거나 확인한 후 저장하라는 안내가 나타납니다. 인증 정보가 다른 환경용인 것 같다는 메시지가 표시되면 **모드**를 변경하고 다시 연결하세요.

:::note
**모드** 또는 인증 정보를 변경할 때마다 **이 인증 정보로 연결**을 다시 클릭한 후 저장하세요. WCPOS에서 PayArc Terminal을 활성화한 후(5단계)에는 이 작업을 하지 않으면 저장 시 오류가 표시됩니다. 단말기에서 결제가 진행 중일 때는 모드, 인증 정보, 연결을 변경할 수 없습니다.
:::

  </StepCard>
  <StepCard number="4" title="단말기 추가">

1. 기기 뒷면의 **S/N** 라벨에 있는 PAX **단말기 일련번호**를 입력하세요. PayArc가 계정에 설정한 번호여야 합니다
2. **결제 유형**과 **영수증 인쇄**를 선택하세요
3. **웹훅 URL**이 HTTPS인지 확인하세요. PayArc가 요청하는 경우에만 전달하세요
4. **변경 사항 저장**을 클릭하세요

계산대에는 이 단말기와 함께 PayArc의 단말기 목록에서 계정에 사용 설정된 것으로 표시된 모든 단말기가 나타납니다. **Connect**를 누르면 목록을 가져오고, **Refresh Terminals**를 누르면 다시 가져옵니다. PayArc에서 사용 중지로 표시한 단말기는 입력한 일련번호와 같더라도 제외됩니다. 목록에 없는 일련번호를 직접 입력한 단말기는 계속 표시됩니다. 실시간 모드에는 HTTPS 사이트가 필요합니다.

  </StepCard>
  <StepCard number="5" title="WCPOS에서 활성화">

1. `WP Admin > POS > 설정 > 결제`로 이동하세요
2. 목록에서 **PayArc Terminal**을 찾아 **활성화** 스위치를 켜세요
3. 다음에 페이지를 불러오면 POS에 타일이 표시됩니다

:::note
이 스위치만 적용됩니다. WooCommerce 결제 목록의 **활성화** 스위치는 영향을 주지 않으며, 온라인 쇼핑몰의 결제 화면에는 PayArc Terminal이 표시되지 않습니다. [결제 설정](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)을 참조하세요.
:::

  </StepCard>
  <StepCard number="6" title="각 POS의 단말기 선택" isLast>

각 POS에서 **설정 > 카드 리더기**를 여세요. PayArc 단말기는 **스마트 리더기** 아래에 한 행씩 표시되며 모두 **온라인**으로 표시됩니다. PayArc는 단말기의 전원 상태를 보고하지 않기 때문입니다. 해당 계산대의 단말기에서 **이 리더기 사용**을 누르면 해당 행에 **선택됨**이 표시됩니다. 캐셔는 결제 시에도 **변경**을 누를 수 있습니다.

PayArc 단말기가 한 대뿐이면 모든 POS에서 이미 **선택됨** 상태이므로 따로 선택할 필요가 없습니다. **매장에서 설정됨**이라고 표시된 행은 POS가 매장의 기본 단말기로 고정되어 있음을 뜻합니다. [스마트 리더기 선택](../../hardware/card-readers/index.mdx#smart-readers)을 참조하세요.

  </StepCard>
</Steps>

</details>

## 설정 참고 자료 {#settings}

`WP Admin > WooCommerce > 설정 > 결제 > PayArc Terminal`의 결제 게이트웨이 페이지에 있는 모든 항목입니다.

<details>
<summary>PayArc Terminal의 모든 설정</summary>

| 설정 | 기능 |
|---|---|
| **제목** | POS에 표시되는 타일 이름. 기본값은 `PayArc Terminal` |
| **설명** | 결제 수단 설명. 기본값은 `Pay in person at a PayArc PAX terminal.` |
| **모드** | `Live`(기본값) 또는 `Test`. 테스트 모드에는 PayArc 테스트 대시보드 인증 정보와 PayArc Connect Test 앱이 필요합니다 |
| **PayArc 로그인 이메일** | PayArc 가맹점 대시보드 로그인 이메일. 연결 전에 입력해야 합니다 |
| **PayArc MID** | 단말기 ID가 아닌 PayArc 가맹점 프로필의 가맹점 MID |
| **PayArc ClientSecret** | 대시보드 API 섹션의 비밀 키. 서버에만 저장됩니다 |
| **PayArc SecretKey / API 베어러 토큰** | PayArc 대시보드의 토큰. 로그인과 단말기 등록 목록 조회에 사용됩니다 |
| **콜백 베어러 토큰** | 선택 사항. PayArc 지원팀에서 발급한 경우에만 입력하세요 |
| **PayArc 연결** | **이 인증 정보로 연결**, **단말기 새로고침**, **연결 해제** 버튼 |
| **단말기 일련번호** | PayArc가 계정에 설정한 PAX S/N. 결제에 필요합니다 |
| **결제 유형** | `CREDIT`(기본값) 또는 `DEBIT` |
| **영수증 인쇄** | 단말기에서 인쇄할 영수증: `0 - No receipt`(기본값), `1 - Merchant receipt`, `2 - Customer receipt` 또는 `3 - Both receipts` |
| **웹훅 URL** | 읽기 전용 콜백 주소. HTTPS인지 확인하고 PayArc가 요청하는 경우에만 전달하세요 |
| **PayArc 진단** | 연결 정보와 **설정 검증** 버튼. 비밀 정보는 표시되지 않습니다 |

저장된 비밀 정보 필드에는 마지막 4자만 표시됩니다. 저장된 값을 유지하려면 해당 필드를 비워 두세요.

**PayArc 진단** 표에는 모드, PayArc 엔드포인트, 로그인 이메일 및 Connect 액세스 토큰의 설정 여부, 가려진 MID, 테넌트 ID와 단말기 일련번호, 검색된 단말기 수, 웹훅 URL, 마지막 콜백 시각, 마지막 PayArc 오류가 표시됩니다. **설정 검증**은 저장된 설정을 확인하고 누락된 항목을 나열합니다.

**연결 해제**는 저장된 PayArc 연결, 단말기 목록, **단말기 일련번호**를 지웁니다. 인증 정보는 유지되므로 빠르게 다시 연결할 수 있습니다. 저장하기 전에 일련번호를 확인하세요.

</details>

## 로그 {#logs}

도움을 요청할 때는 주문 번호와 관련 로그 행을 보내세요.

<details>
<summary>지원 요청에 필요한 로그 찾기</summary>

`WooCommerce > Status > 로그`에서 소스가 `payarc-terminal-for-woocommerce`인 로그를 찾으세요. 식별자는 가려지고 비밀 정보는 제거됩니다.

지원용 정보 묶음을 다운로드하는 기능은 없습니다. 전체 MID, 단말기 ID, 토큰, 카드 데이터를 공유하지 마세요.

</details>

## 지원 범위 및 제한 사항 {#scope-and-limitations}

- 단말기에서 팁을 받을 수 없습니다
- 단말기는 한 번에 하나의 결제만 처리합니다. 처리 중에는 다른 POS에 **주문 #…에서 사용 중**이 표시됩니다
- 지원 통화는 **USD, CAD, GBP, EUR 및 JPY**로 제한됩니다
- 연결을 통해 단말기의 전원 상태는 보고되지 않습니다. 오프라인 단말기로 보내는 판매 결제는 즉시 실패하며 단말기로 아무것도 전송되지 않습니다
- 확장 프로그램 버전 0.1에서 받은 결제는 결제 게이트웨이가 아닌 PayArc에서 환불해야 합니다
- 환불 요청은 판매 결제를 받은 단말기로 전송됩니다

## 설정에 문제가 생긴 경우 {#troubleshooting}

### 일반적인 문제 {#common-issues}

<Accordion>
  <AccordionItem question="테스트(또는 실거래)용 PayArc 인증 정보로 보입니다">

  - 선택한 모드와 인증 정보가 서로 다른 PayArc 환경에 해당합니다
  - **모드**를 메시지에 표시된 모드로 변경하거나 인증 정보를 선택한 모드에 맞는 것으로 교체하세요
  - **이 인증 정보로 연결**을 다시 클릭한 뒤 저장하세요

  </AccordionItem>
  <AccordionItem question="PayArc에 연결할 수 없음">

  - PayArc가 로그인을 거부했습니다. 입력한 인증 정보를 확인하고 다시 시도하세요
  - 자세한 내용은 `WooCommerce > Status > 로그`에서 소스가 `payarc-terminal-for-woocommerce`인 로그를 확인하세요

  </AccordionItem>
  <AccordionItem question="실거래 모드를 활성화하려면 콜백 URL이 HTTPS여야 합니다">

  - 실거래 모드에서는 PayArc가 **웹훅 URL**에 접근할 수 있도록 사이트에서 HTTPS를 사용해야 합니다
  - 사이트를 HTTPS로 전환하거나 테스트 사이트에서 **테스트** 모드를 사용하세요

  </AccordionItem>
  <AccordionItem question="단말기 등록 목록이 비어 있음">

  - 이 경우 POS에는 **단말기 일련번호**에 입력된 단말기만 표시되며, 해당 단말기를 통한 결제는 계속 가능합니다
  - PayArc에 해당 일련번호가 계정에 등록되어 있는지 확인을 요청하세요. 다른 단말기도 POS에 표시하려면 해당 단말기들을 목록에 추가해 달라고 요청하세요
  - PayArc가 단말기를 추가한 후 **단말기 새로고침**을 클릭하세요

  </AccordionItem>
  <AccordionItem question="PayArc가 Connect AccessToken과 SecretKey를 모두 거부함">

  - PayArc가 계정의 거래 API 사용을 거부했습니다
  - PayArc 지원팀에 가맹점 계정의 **PayArc Connect V3** 활성화 여부와 거래 승인에 사용하는 인증 정보가 무엇인지 확인을 요청하세요

  </AccordionItem>
</Accordion>
