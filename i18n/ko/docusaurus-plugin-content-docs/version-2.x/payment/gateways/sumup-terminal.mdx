# SumUp Terminal 결제 게이트웨이 {#sumup-terminal-gateway}

SumUp Terminal을 사용하면 계산대에서 SumUp 카드 리더기로 결제를 받을 수 있습니다. 계산대가 리더기로 금액을 전송하면 고객이 리더기에서 결제하고, SumUp이 결제를 승인하면 판매가 완료됩니다. 이 페이지에서는 결제 게이트웨이의 초기 설정부터 리더기 페어링 또는 연결, 첫 결제까지 안내합니다.

이미 설정을 마쳤나요? [Solo 페어링](#pairing), [Bluetooth 리더기 연결](#card-readers) 또는 [결제 받기](#processing-payments)로 이동하세요.

:::info Pro 기능
SumUp Terminal 2.0을 사용하려면 [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0 이상이 필요합니다. 이 조건을 충족하지 않으면 계산대에서 확장 프로그램이 작동하지 않습니다.
:::

## 클라우드로 Solo 연결 또는 Bluetooth 연결 {#hardware-compatibility}

결제 게이트웨이의 **POS 연결** 설정에서 POS와 리더기의 연결 방식을 선택합니다. 이 설정은 매장 전체에 적용됩니다.

- **클라우드로 Solo 연결**(기본값): 매장이 인터넷을 통해 **SumUp Solo**에 연결합니다. 브라우저, 데스크톱 앱, iPhone, iPad, Android 등 모든 계산대에서 사용할 수 있습니다. 결제 게이트웨이 페이지에서 Solo를 한 번만 페어링하면 됩니다.
- **Bluetooth 리더기**: WCPOS iOS 또는 Android 앱이 Bluetooth를 통해 **Solo Lite**, **Solo** 또는 **Air**에 연결합니다. 각 계산대의 앱에서 해당 계산대에 사용할 리더기를 연결합니다. 이 옵션은 매장의 WCPOS Pro가 앱에서 연결하는 리더기를 지원할 때만 표시됩니다.

브라우저나 데스크톱 앱에서는 Bluetooth 리더기에 연결할 수 없습니다. **Bluetooth 리더기**를 선택하면 해당 계산대의 SumUp 타일이 **… 지금은 사용할 수 없음** 아래에 표시됩니다. 브라우저나 데스크톱 앱을 사용하는 계산대가 있다면 **클라우드로 Solo 연결**을 사용하세요. 타일의 메시지는 [앱의 리더기만 허용됨](#only-app-readers)에서 설명합니다.

## 결제 게이트웨이 설정 {#setup}

관리자가 WP Admin에서 매장마다 한 번씩 설정합니다.

1. **확장 프로그램을 설치하세요.** `WP Admin > POS > 설정 > 확장`에서 **SumUp Terminal for WooCommerce**를 찾아 **설치**를 클릭한 다음 **활성화**를 클릭하세요. 디렉터리에 이전 버전이 표시될 수도 있으므로 버전이 2.0.0 이상인지 확인하세요. [확장 프로그램](../../extensions/index.mdx#installing-an-extension)을 참고하세요.

   <details>
   <summary>다운로드한 zip 파일로 설치하기</summary>

   [GitHub](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases)의 릴리스 첨부 파일에서 `sumup-terminal-for-woocommerce.zip`을 다운로드하고, `플러그인 > Add Plugin`에서 **플러그인 업로드**를 선택해 업로드하세요. GitHub의 "Source code" zip 파일로는 설치할 수 없습니다.

   </details>

2. **API 키를 추가하세요.** **SumUp API 키**는 [SumUp 개발자 포털](https://developer.sumup.com/)에서 리더기를 소유한 계정으로 확인할 수 있습니다. `WP Admin > WooCommerce > 설정 > 결제`로 이동해 **SumUp Terminal**을 열고 **SumUp API 키**에 붙여넣으세요.
3. **POS 연결 방식을 선택하세요**: **클라우드로 Solo 연결** 또는 **Bluetooth 리더기**를 선택합니다. **Bluetooth 리더기**를 선택했다면 [SumUp 제휴 키](https://developer.sumup.com/tools/authorization/affiliate-keys/)에서 받은 **제휴 키**도 입력하세요.
4. **설정을 저장하세요.**
5. **POS에서 사용하도록 활성화하세요.** `WP Admin > POS > 설정 > 결제`로 이동해 **SumUp Terminal**을 켜고 저장하세요. WooCommerce 자체 결제 목록에서는 활성화할 필요가 없습니다. [결제 설정](../../settings/wp-admin/checkout.mdx)을 참고하세요.
6. **리더기를 페어링하거나 연결하세요**: 클라우드로 연결할 Solo는 [이 페이지에서 페어링](#pairing)하고, Bluetooth 리더기는 [앱에서 연결](#card-readers)합니다.

SumUp Terminal은 POS 전용입니다. 온라인 쇼핑몰의 결제 화면에는 표시되지 않습니다.

<details>
<summary>결제 게이트웨이 페이지의 모든 설정</summary>

| 설정 | 기능 |
|---|---|
| **제목** 및 **설명** | 결제 게이트웨이에 표시되는 이름과 설명 문구입니다. 계산대에서는 타일에 제목이 표시됩니다. |
| **SumUp API 키** | SumUp 계정에서 받습니다. |
| **제휴 앱 ID** 및 **제휴 키** | [SumUp 제휴 키](https://developer.sumup.com/tools/authorization/affiliate-keys/)에서 받습니다. **Bluetooth 리더기**에는 키가 필요합니다. 앱이 이 키로 SumUp의 리더기 소프트웨어를 실행합니다. **클라우드로 Solo 연결**에서는 선택 사항입니다. |
| **POS 연결** | *클라우드로 Solo 연결(매장이 리더기를 제어)* 또는 *Bluetooth 리더기(POS 앱이 리더기를 제어: Solo Lite, Solo, Air)*. |
| **오프라인 카드 결제** | 2.0에서는 적용되지 않습니다. [오프라인 결제](#offline-payments)를 참고하세요. |
| **기본 단말기** | 계산대에서 다른 Solo를 선택하기 전까지 결제에 사용하는 페어링된 Solo입니다. |
| **활성화된 단말기** | 계산대에서 사용할 수 있는 Solo를 선택한 기기로 제한합니다. 모두 허용하려면 비워 두세요. |
| **단말기 선택 잠금** | *캐셔가 결제 시 단말기를 변경할 수 없습니다.* **기본 단말기**가 필요합니다. |
| **결제 디버그 로그** | 결제 화면에 상세한 SumUp 결제 로그를 표시합니다. 결제 활동은 항상 `WooCommerce > Status > 로그`에 기록됩니다. |

입력란 아래에는 연결 상태, SumUp 가맹점 정보, 페어링된 리더기가 표시됩니다. 웹훅은 설정할 필요가 없습니다. 매장이 각 결과를 보낼 위치를 SumUp에 알려줍니다.

</details>

## 클라우드로 Solo 페어링 {#pairing}

페어링 코드는 SumUp 앱이 아닌 Solo 자체에 표시됩니다. 이 코드를 WP Admin의 결제 게이트웨이 페이지에 입력합니다.

1. Solo를 켜세요. 기기에서 SumUp에 로그인하지 마세요.
2. Solo에서 메뉴를 열고 **연결 → 클라우드 API**를 선택하세요. 목록의 마지막 항목입니다. **연결**을 누르면 Solo에 페어링 코드가 표시됩니다.
3. WP Admin에서 결제 게이트웨이 페이지(`WooCommerce > 설정 > 결제 > SumUp Terminal`)를 여세요. **새 리더기 페어링** 아래의 **페어링 코드 입력**에 코드를 입력하고 **리더기 페어링**을 누르세요.
4. 페이지에 *리더기가 페어링되었습니다!*가 표시되고 페이지가 새로고침됩니다. Solo가 모델 및 일련번호와 함께 **설정된 리더기** 아래에 표시됩니다.

**Solo에 클라우드 API가 없나요?** 리더기에서 SumUp 계정을 로그아웃한 다음 메뉴를 다시 여세요.

두 번째 Solo를 페어링하려면 **추가 리더기 페어링**을 사용하세요. 리더기 옆의 **리더기 페어링 해제**를 누르면 매장에서 해당 리더기가 제거됩니다.

## 앱에서 Bluetooth 리더기 연결 {#card-readers}

**POS 연결**을 **Bluetooth 리더기**로 설정하면 각 휴대폰이나 태블릿의 WCPOS iOS 또는 Android 앱에서 사용할 리더기를 연결합니다. 사이드 메뉴 하단의 **설정**을 누른 다음 **카드 리더기**를 누르세요. 결제 게이트웨이가 설정되면 **Bluetooth 리더기** 섹션에 **리더기 연결** 버튼이 표시됩니다. **이 매장에 설정된 카드 리더기가 없습니다**만 표시되면 [카드 리더기 없음](#no-card-readers)을 참고하세요.

1. 리더기를 켜고 휴대폰이나 태블릿 가까이에 두세요.
2. **리더기 연결**을 누르세요. **리더기 연결에 사용할 결제 게이트웨이**가 표시되면 **SumUp Terminal**을 선택하세요.
3. SumUp 자체 화면이 열립니다. SumUp 계정으로 로그인하고 리더기를 선택하세요.

리더기를 저장하면 **카드 리더기**에 **SumUp Terminal** 행이 표시됩니다. 다음부터는 해당 행의 **SumUp Terminal 리더기 설정 열기** 버튼을 사용하세요. 버튼에는 결제 게이트웨이의 **제목**이 사용되므로 이름을 변경했다면 다르게 표시됩니다.

**카드 리더기**로 돌아오면 해당 행에 **연결됨**이 표시됩니다. 리더기가 저장되어 있지만 연결되지 않았다면 **SumUp Terminal 앱에 저장됨**이 표시됩니다. **리더기를 사용하려면 SumUp Terminal에 로그인하세요.** 메시지는 앱에서 아직 SumUp에 로그인하지 않았다는 뜻입니다. 버튼을 다시 누르세요.

## 실제 사용 전 테스트 {#testing}

**클라우드로 Solo 연결**에서는 리더기나 실제 돈 없이 판매를 테스트할 수 있습니다. SumUp의 [Virtual Solo](https://virtual-solo.sumup.com)는 SumUp 샌드박스 계정에서 Solo를 시뮬레이션합니다.

<details>
<summary>Virtual Solo로 테스트</summary>

1. 결제 게이트웨이 페이지에서 샌드박스 계정의 API 키를 **SumUp API 키**에 붙여넣고 저장하세요.
2. [Solo](#pairing)와 같은 방법으로 Virtual Solo의 페어링 코드를 사용해 페어링하세요. **설정된 리더기** 아래에 표시됩니다.
3. [결제 받기](#processing-payments)의 단계에 따라 판매를 진행하세요. 타일에 **단말기: …** 와 함께 Virtual Solo가 표시됩니다.

테스트가 끝나면 실제 결제를 받기 전에 실서비스용 API 키를 다시 입력하고 저장한 다음 실제 Solo를 페어링하세요.

</details>

## 결제 받기 {#processing-payments}

:::note 먼저 계산대를 여세요
**계산대 열기 및 닫기**가 켜져 있으면 계산대가 닫힌 동안 결제가 기록되지 않으며, 이미 받은 카드 결제는 환불해야 합니다. [계산대 열기](../../pos/register/index.mdx)를 참고하세요.
:::

1. 장바구니에 상품을 담고 **결제**를 누르세요.
2. 결제 수단 중 **SumUp Terminal** 타일을 누르고 리더기 상태를 확인하세요:
   - **클라우드로 Solo 연결**: **단말기: …** 가 표시됩니다. 매장에서 허용한 경우 **변경**을 눌러 다른 Solo를 선택할 수 있습니다.
   - **Bluetooth 리더기**: **연결됨**과 리더기의 배터리 잔량이 표시됩니다. **연결된 리더기 없음**은 리더기가 연결되지 않았다는 뜻입니다. **설정 → 카드 리더기에서 연결**을 누르세요.
3. **SumUp Terminal로 … 전송**을 누르고 고객이 리더기에서 결제하도록 안내하세요:
   - **클라우드로 Solo 연결**: 계산대에 **단말기에서 고객 결제 대기 중**이 표시됩니다. 중단하려면 **단말기에서 취소**를 누르세요.
   - **Bluetooth 리더기**: 계산대에 **리더기에 카드를 대세요**가 표시됩니다. 중단하려면 리더기에서 직접 취소하세요. 계산대에서 **단말기에서 취소**를 누르면 **리더기에서 취소하세요**가 표시됩니다. 리더기가 고객에게 팁을 요청할 수 있습니다. [팁](../../pos/checkout/tips.mdx)을 참고하세요.

   계산대에서 **전송됨**, **단말기에서 진행 중**, **승인됨**, **매입 완료** 단계에 차례로 완료 표시가 됩니다.
4. 남은 결제 금액이 없으면 영수증 화면이 열립니다. 영수증을 인쇄하거나 이메일로 보낸 다음 **새 판매**를 누르세요. [결제 완료 확인](../../pos/checkout/index.mdx#paid)을 참고하세요. 합계 중 일부 금액이 남았다면 다른 수단으로 나머지를 받으세요. [분할 결제](../../pos/checkout/split-payments.mdx)를 참고하세요.

카드 결제가 거절되거나 취소되면 **결제 실패: …** 와 함께 **다시 시도** 및 **다른 수단 선택**이 표시됩니다. [카드 리더기로 결제](../../pos/checkout/taking-a-payment.mdx#card-reader)를 참고하세요.

결제 화면의 [**레거시**](../../pos/checkout/legacy-tab.mdx) 탭에서 SumUp Terminal은 **단말기** 선택 목록과 **단말기로 전송**, **취소**, **다시 시도**를 표시합니다. 이 결제도 결제 수단 패널에서 받은 결제와 동일하게 기록됩니다.

<details>
<summary>2.0 이전의 SumUp Terminal</summary>

2.0 이전 버전에는 결제 수단 패널에 타일이 없습니다. 결제 게이트웨이는 **레거시** 탭의 자체 결제 페이지에 있으며 **새 결제 시작**, **결제 취소**, **결제 상태**가 표시됩니다. 클라우드로 연결한 Solo만 사용할 수 있습니다. 타일과 Bluetooth 리더기를 사용하려면 2.0으로 업데이트하세요.

</details>

## 오프라인 결제 {#offline-payments}

WCPOS 2.0에서는 계산대가 오프라인 상태일 때 어떤 리더기로도 SumUp 카드 결제를 받을 수 없습니다. 결제 게이트웨이의 **오프라인 카드 결제** 설정과는 무관합니다.{/* pending: monorepo#3387 */} 연결이 없으면 SumUp 타일이 **… 지금은 사용할 수 없음** 아래에 표시되고 **연결 필요** 메시지가 나타납니다. 현금으로 결제를 받거나 연결이 복구될 때까지 기다리세요. [오프라인 모드](../../getting-started/offline.mdx#take-payment-offline)를 참고하세요.

오프라인 카드 결제는 [로드맵](../../getting-started/roadmap.mdx)에 포함되어 있습니다.

- ["매장 관리자가 SumUp 제휴 키를 입력해야 합니다…"](#affiliate-key)
- [카드 결제가 거절됨](#card-declined)

<Anchor id="solo-wont-pair" />

**Solo가 페어링되지 않습니다.** SumUp Solo를 사용하세요. 클라우드로 페어링할 수 있는 리더기는 Solo뿐이며, Bluetooth 리더기는 WCPOS 앱에서 연결합니다. Solo가 온라인 상태이고 SumUp에서 로그아웃되어 있으며 **연결 → 클라우드 API**의 코드가 표시되는지 확인하세요. 표시된 코드를 그대로 입력하세요.

<Anchor id="only-app-readers" />

**"이 결제 수단에는 앱의 리더기만 사용할 수 있습니다."** 계산대가 브라우저 또는 데스크톱 앱이며 **POS 연결**이 **Bluetooth 리더기**로 설정되어 있습니다. iOS 또는 Android 앱에서 결제를 받거나, 관리자에게 **POS 연결**을 **클라우드로 Solo 연결**로 설정하고 [Solo를 페어링](#pairing)하도록 요청하세요. 메시지의 **문제가 있나요?** 링크를 누르면 [카드 리더기](../../hardware/card-readers/index.mdx) 페이지가 열립니다.

<Anchor id="needs-a-connection" />

**오프라인에서는 SumUp 타일을 사용할 수 없습니다.** 카드 리더기는 연결이 복구될 때까지 기다립니다. [오프라인 결제](#offline-payments)를 참고하세요.

<Anchor id="no-card-readers" />

**"이 매장에 설정된 카드 리더기가 없습니다".** 결제 게이트웨이가 아직 [설정](#setup)되지 않아 **카드 리더기**에 이 메시지만 표시됩니다:

<JourneyShot manifest={manifest} device="tablet" step={1} maxWidth={720} alt="아직 카드 리더기가 설정되지 않은 매장의 계산대에서 카드 리더기를 선택한 설정 화면">

1. **이 매장에 설정된 카드 리더기가 없습니다** — [결제 게이트웨이 설정](#setup)을 마친 다음 [리더기를 연결](#card-readers)하세요.

</JourneyShot>

**클라우드로 Solo 연결**을 사용하면 페어링된 Solo는 SumUp 행이 아니라 **카드 리더기**의 **스마트 리더기** 아래에 표시됩니다.

<Anchor id="no-terminals" />

**"SumUp Terminal에 설정된 단말기가 없습니다".** 페어링된 Solo가 없거나 **활성화된 단말기** 설정 때문에 이 계산대에서 사용할 수 있는 Solo가 없습니다. [클라우드로 Solo 페어링](#pairing)을 참고하세요.

<Anchor id="payment-wont-start" />

**결제가 시작되지 않습니다.** WP Admin에서 결제 게이트웨이 페이지를 여세요. **SumUp에 연결됨**이 표시되어야 합니다. **연결 실패**는 **SumUp API 키**가 잘못되었거나 더 이상 유효하지 않다는 뜻입니다. Solo가 켜져 있고 충전되어 있으며 온라인 상태인지, **설정된 리더기**에 표시되는지 확인하세요.

<Anchor id="affiliate-key" />

**"매장 관리자가 SumUp 제휴 키를 입력해야 합니다…".** 결제 게이트웨이에 Bluetooth 리더기에 필요한 **제휴 키**가 없습니다. [결제 게이트웨이 설정](#setup)의 3단계를 참고하세요.

<Anchor id="card-declined" />

**카드 결제가 거절되었습니다.** 다른 카드나 결제 수단을 요청하세요.

**아직 해결되지 않았나요?** **결제 디버그 로그**를 선택하고 `WooCommerce > Status > 로그`에서 결제 활동을 확인하세요. [GitHub](https://github.com/wcpos/sumup-terminal-for-woocommerce/issues)에 버그를 신고하거나, 계정 또는 리더기에 관해서는 SumUp 지원팀에 문의하세요.
