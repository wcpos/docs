:::info Pro 기능
여러 매장을 운영하려면 [WCPOS Pro](../getting-started/pro-license.mdx)가 필요합니다. Pro가 없으면 POS는 하나의 매장으로 운영됩니다. 이름, 연락처, 세금 번호는 **WP Admin → POS → 설정 → 일반**에서 가져오고 나머지는 WooCommerce 설정을 사용합니다.
:::

매장은 상점, 시장 가판대, 판매 창구처럼 판매가 이루어지는 장소입니다. 하나의 WooCommerce 사이트 안에서 매장마다 주소, 영수증, 세금, 계산대, 직원을 별도로 관리합니다. 모든 판매는 발생한 매장에 기록되므로 주문과 보고서를 매장별로 확인할 수 있습니다.

매장을 만들려면 [매장 설정](./setup.mdx)을 참조하세요. 매장, 계산대, 기기의 관계는 [매장, 계산대 및 기기](./registers-and-devices.mdx)를 참조하세요.

## 캐셔가 매장을 확인하는 위치 {#in-the-pos}

캐셔는 로그인할 때 매장을 선택합니다. 목록에는 사용 권한이 있는 매장만 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[170, 0], [170, 0], [0, 0]]} maxWidth={460} alt="캐셔가 로그인한 로그인 카드: 매장 선택에 번호와 함께 두 매장이 표시되고 하나가 선택된 상태이며, POS 열기 버튼이 있습니다">

1. **사용 가능한 매장** — 여기서는 이 매장이 선택되어 있습니다. 오른쪽 숫자는 WP Admin의 매장 ID입니다.
2. **다른 매장** — 이 캐셔가 사용할 수 있는 두 번째 매장입니다.
3. **POS 열기** — 선택한 매장의 POS를 엽니다. 매장이 하나뿐이면 이미 선택되어 있으며 제목은 **매장**으로 표시됩니다.

</JourneyShot>

POS에서는 장바구니 위 계산대 표시줄의 맨 앞에 매장 이름이 표시됩니다. 매장에 계산대가 여러 개 있으면 계산대 이름도 함께 표시됩니다. 매장 이름이나 표시줄 끝의 아바타를 누르면 캐셔 패널이 열립니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[232, 0], [-30, 0]]} maxWidth={512} alt="캐셔 패널: 캐셔 이름 아래에 매장과 계산대 사용 시간이 표시되고, 매장 행에 전환 버튼이 있습니다">

1. **매장 및 계산대 사용 시간** — 이름 아래에 현재 판매 중인 매장이 표시됩니다.
2. **전환** — 여러 매장을 사용할 수 있을 때만 **매장** 행에 표시됩니다.

</JourneyShot>

### 다른 매장으로 전환 {#switch-store}

먼저 진행 중인 결제를 완료하고 온라인 상태를 유지하세요. 그런 다음:

1. 매장 이름이나 표시줄 끝의 아바타를 눌러 캐셔 패널을 여세요.
2. **매장** 행에서 **전환**을 누르고 매장을 선택하세요.
3. 확인 메시지를 읽어보세요. ***매장 이름*으로 전환하시겠습니까?** 라는 질문과 함께 해당 매장의 계산대가 열려 있는지 표시됩니다.
4. ***매장 이름*으로 전환**을 누르세요. 해당 매장으로 POS가 새로고침됩니다.

결제가 진행 중이거나 POS가 사이트에 연결할 수 없을 때는 **전환**이 비활성화됩니다. 연결할 수 없는 경우 해당 행에 **전환하려면 매장 연결 필요**가 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[160, 0], [160, 0], [-16, 0]]} maxWidth={512} alt="캐셔 패널의 매장 전환 화면: 현재 매장에 체크 표시가 있고, 선택할 수 있는 다른 매장과 뒤로 화살표가 있습니다">

1. **현재 매장** — 체크 표시가 있습니다. 다시 선택할 수 없습니다.
2. **다른 매장** — 누르면 해당 매장으로 전환합니다.
3. **뒤로** — 전환하지 않고 캐셔 패널로 돌아갑니다.

</JourneyShot>

<Accordion>
  <AccordionItem question="매장을 전환하면 열려 있는 금전함은 어떻게 되나요?">

계산대가 열려 있으면 확인 화면에 현금 처리 방법 두 가지가 표시됩니다:

- **금전함 가져가기** — 예상 금액으로 현재 계산대를 마감하고, 그 금액을 준비금으로 하여 다른 매장의 계산대를 엽니다. 해당 매장의 계산대가 닫혀 있을 때 제공됩니다.
- **여기에 열어 두기** — 현재 계산대를 열린 상태로 유지하며, 확인 화면에는 금전함이 여기에 열린 상태로 유지된다고 표시됩니다.

다른 매장에 계산대가 여러 개 있으면 그중 하나를 선택합니다. [매장 및 계산대 선택](./registers-and-devices.mdx#choosing-a-store-and-a-register)을 참조하세요.

  </AccordionItem>
</Accordion>

## 매장별 주문 및 보고서 {#filtering-by-store}

- **[주문](../orders/index.mdx)** 을 열면 로그인한 매장에서 본인이 처리한 주문이 표시됩니다. 상단 필터에 매장 이름이 표시됩니다. 이를 눌러 다른 매장을 선택하거나 **생성 경로**에서 **POS**, **온라인 매장**, **WP Admin**을 선택하세요. 온라인 주문과 WP Admin에서 생성한 주문을 포함하여 모든 매장의 주문을 보려면 이 필터와 옆의 캐셔 필터를 해제하세요.
- **[보고서](../reports/index.mdx)** 는 화면 상단에 표시된 매장과 계산대의 데이터를 보여줍니다. 이름을 눌러 다른 매장이나 **모든 매장**을 선택하세요.
- **[영수증](../receipts/index.mdx)** 에는 판매가 이루어진 매장의 주소와 로고가 인쇄됩니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[150, 0], [150, 0], [150, 0], [150, 0]]} maxWidth={344} alt="보고서의 AL 12345 Store · 모든 계산대 아래에 열린 매장 및 계산대 메뉴: 매장 그룹(모든 매장, 체크 표시된 AL 12345 Store, AL Store)과 계산대 그룹(체크 표시된 모든 계산대, 계산대)이 있습니다">

1. **모든 매장** — 모든 매장을 하나의 보고서로 보여줍니다. 매장이 여러 개일 때만 표시됩니다.
2. **매장** — 해당 매장의 판매만 보여줍니다.
3. **모든 계산대** — 선택한 매장의 모든 계산대와 온라인으로 받은 주문을 보여줍니다.
4. **계산대** — 한 계산대의 판매를 보여줍니다.

</JourneyShot>

WP Admin에서 주문의 **POS 매장**은 판매가 이루어진 매장을 표시합니다. 이를 변경하면 주문이 다른 매장으로 이동합니다.

## 매장별 가격, 세금 및 재고 {#store-specific-pricing}

상품에 특정 매장 전용 가격이나 세금을 설정할 수 있습니다. 해당 매장의 캐셔에게는 이 설정이 적용되고, 다른 모든 매장에서는 상품의 일반 WooCommerce 가격과 세금을 사용합니다.

<Accordion>
  <AccordionItem question="특정 매장의 상품 가격 또는 세금 변경">

**WP Admin → 상품**의 상품 또는 각 옵션 상품에서 매장별로 **정상 가격**과 **할인 가격**, 또는 **과세 상태**와 **세금 클래스**를 설정하세요. [매장별 가격 및 세금](./setup.mdx#per-store-pricing)을 참조하세요.

  </AccordionItem>
</Accordion>

### 재고 {#inventory-management}

모든 매장이 동일한 WooCommerce 재고를 공유합니다. 매장별로 재고를 관리하려면 [ATUM Multi-Inventory](../extensions/atum.mdx)를 사용하세요. 각 매장을 ATUM 위치에 연결하면 판매 시 해당 위치의 재고가 차감됩니다. ATUM은 각 매장에 해당 위치의 가격과 SKU를 적용할 수도 있습니다.

<Accordion>
  <AccordionItem question="ATUM 없이 매장을 완전히 분리하기: WordPress Multisite">

아무것도 공유하지 않는 매장을 운영하려면 [WordPress Multisite](https://developer.wordpress.org/advanced-administration/multisite/create-network/)에서 각 매장을 독립된 사이트로 운영하세요:

1. 매장마다 WordPress 사이트를 만드세요.
2. 각 사이트에 WooCommerce와 WCPOS를 설치하세요.
3. 각 사이트가 자체 상품, 재고, 주문을 유지합니다.

이 경우 여러 WooCommerce 설치를 관리하게 되며, 각 사이트의 주문과 보고서는 독립적으로 유지됩니다.

  </AccordionItem>
</Accordion>

## 매장 기능의 제한 사항 {#known-limitations}

- **독립된 상점을 만들지는 않습니다.** 매장은 하나의 WooCommerce 사이트 안에 있는 판매 장소로, 상품, 고객, 쿠폰을 공유합니다.
- **특정 매장에서 상품을 숨길 수는 없습니다.** 모든 매장이 동일한 상품 목록을 판매합니다. ATUM을 사용하면 매장에 연결된 위치의 재고가 소진된 상품은 해당 매장에서 품절로 표시됩니다.
- **매장을 추가해도 기존 주문은 이동하지 않습니다.** 주문은 판매가 이루어진 매장에 그대로 남습니다. [기존 주문의 처리](./setup.mdx#edge-cases)를 참조하세요.
