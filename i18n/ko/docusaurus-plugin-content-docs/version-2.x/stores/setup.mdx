:::info Pro 기능
매장을 여러 개 운영하려면 [WCPOS Pro](../getting-started/pro-license.mdx)가 필요합니다. Pro가 없으면 POS는 WooCommerce 설정을 바탕으로 구성된 매장 하나를 운영합니다.
:::

이 페이지에서는 빈 목록에서 매장을 만들고 캐셔가 로그인하기까지의 과정을 안내합니다. 매장의 용도는 [매장](./index.mdx)부터 확인하세요.

## 시작하기 전에 {#before-you-start}

- **WCPOS Pro가 설치되어 있고 라이선스가 활성화되어 있어야 합니다.** 그러면 Pro가 WP Admin의 **POS** 메뉴 맨 위에 **매장**을 추가합니다.
- **캐셔가 POS에 로그인할 수 있어야 합니다.** POS 접근 권한은 [접근 권한](../settings/wp-admin/access.mdx)에서 설정합니다. 매장에서는 그 목록의 범위만 좁힐 수 있습니다.
- *(선택 사항)* PNG 또는 JPG 형식의 **로고 파일**.

## 매장 만들기 {#create-the-store}

1. WP Admin에서 **POS → 매장**으로 이동하세요.
2. **새 매장 추가**를 클릭하세요.
3. 매장의 **상세 정보** 페이지가 열립니다. 상단의 **매장 이름**에 이름을 입력하세요. 이 이름은 로그인 시 매장 선택 화면과 POS에 표시됩니다.
4. 오른쪽 상단의 **만들기**를 클릭하세요.

이후 매장은 자동으로 저장됩니다. 페이지 상단에 **저장 중…** 이 표시된 다음 **저장됨**으로 바뀝니다. 변경 사항을 저장하는 중에 페이지를 나가려고 하면 브라우저가 먼저 확인을 요청합니다. 대신 **저장하지 못했습니다.** 가 표시되면 [문제가 발생한 경우](#goes-wrong)를 참조하세요.

<Accordion>
  <AccordionItem question="매장 목록에 표시되는 정보">

각 매장 행에는 **매장** 이름, **주소**, **허용된 사용자**(**직원** 페이지에서 아무도 선택하지 않았으면 **모두**), **계산대** 수, 해당 매장에서 POS를 여는 **POS 열기** 버튼이 표시됩니다.

**POS → 설정 → 일반**에서도 매장에 접근할 수 있습니다. 매장을 만들면 **매장** 섹션에 각 매장의 **주소**와 **편집** 버튼이 표시되며, **매장 관리**를 누르면 전체 목록이 열립니다.

  </AccordionItem>
</Accordion>

## 매장의 각 페이지 작성 {#store-pages}

매장의 각 페이지는 왼쪽 메뉴에서 열 수 있습니다. 화면이 좁으면 **매장 메뉴 표시**를 사용하세요. 모든 페이지는 입력하는 대로 저장됩니다. 새 매장에서는 다음을 설정하세요.

1. **상세 정보**에서 매장 주소(**주소 1**, **주소 2**, **국가**, 이어서 도시, 주/도, 우편번호)와 **연락처** 정보인 **웹 주소**, **전화번호**, **이메일**을 입력하세요. 주소는 영수증에 인쇄되며, 로고를 추가하면 함께 인쇄됩니다. 나중에 매장 이름을 바꾸려면 이 페이지의 **매장 이름**을 변경하세요.
2. [계산대를 설정하세요](#registers).
3. [매장을 사용할 사람을 선택하세요](#staff).

다른 페이지에서는 이 매장에만 다르게 적용할 사항을 설정합니다. 메뉴 상단의 **모든 매장**을 누르면 목록으로 돌아갑니다. 나중에 매장을 다시 열려면 **POS → 매장**에서 이름을 클릭하세요.

<Accordion>
  <AccordionItem question="매장 설정 참고: 페이지별 설정 항목">

메뉴는 **매장**(상세 정보, 영업시간, 통화 및 언어, 세금)과 **판매**(영수증, 고객용 화면, 계산대, 직원)의 두 그룹으로 구성됩니다. [ATUM](../extensions/atum.mdx)처럼 매장 설정을 추가하는 플러그인은 세 번째 그룹인 **확장 기능** 아래에 별도 페이지가 생깁니다.

매장을 만들면 일부 항목에 배지가 표시됩니다. **계산대**에는 열린 금전함 수(**1개 열림**)가 표시되며, 열린 금전함이 없으면 전체 수가 표시됩니다. **세금**에는 이 매장의 판매에 세금이 부과되지 않는 경우(WooCommerce에서 세금이 꺼져 있거나, 세율이 없거나, 매장에 맞는 세율이 없는 경우) **설정**이 표시됩니다. **직원**에는 선택한 사람 수가 표시됩니다.

| 페이지 | 설정 항목 |
| --- | --- |
| **상세 정보** | 영수증에 인쇄되는 **로고 및 주소**, 그리고 **연락처**인 **웹 주소**, **전화번호**, **이메일**입니다. **로고 업로드**를 사용하거나, 사이트에 로고가 있으면 **사이트 로고 사용**을 선택하세요. |
| **영업시간** | 요일별 시간대, **화–금에 복사**, **메모**입니다. 영수증에 인쇄됩니다. |
| **통화 및 언어** | **통화**와 **기호 위치**, **언어**(POS 화면 및 영수증), **시간대**(마감 알림 및 보고서 날짜)입니다. |
| **세금** | **세금 계산 기준**으로 이 매장의 주소, 상점 기본 주소, 고객의 청구 또는 배송 주소를 선택하며 **적용되는 세율**이 함께 표시됩니다. 아래에는 **영수증에 인쇄할 세금 번호**가 있습니다. **세금 번호 추가**에서 **유형**, **값**, **국가**, 선택 사항인 **라벨**을 입력하거나, 비워 두면 사이트의 [매장 세금 ID](../settings/wp-admin/store-tax-ids.mdx)가 영수증에 인쇄됩니다. |
| **영수증** | **영수증 메시지**(**감사 문구**, **반품 정책**, **바닥글**: 일반 텍스트이며 `<strong>`, `<em>`, `<b>`, `<i>`, `<br>` 및 `<p>` 사용 가능), **영수증 템플릿** 목록(**사용자 지정**을 클릭하기 전까지는 **사이트와 동일**이며, 이후 캐셔가 인쇄할 항목을 선택합니다. 처음 선택한 항목이 기본값이 되며, 끌어서 순서를 변경할 수 있습니다), 그 아래의 **영수증 미리보기**입니다. 자세한 내용은 [매장별 템플릿](../receipts/customise.mdx#per-store-assignments)을 참조하세요. |
| **고객용 화면** | 판매 중 고객용 화면에 표시할 **화면 템플릿**입니다. |
| **계산대** | 매장의 금전함과 현금 규칙입니다. [계산대 설정](#registers)을 참조하세요. |
| **직원** | 이 매장을 사용할 사람입니다. [매장을 사용할 사람 선택](#staff)을 참조하세요. |

세율 자체는 **WooCommerce → 설정 → 세금**에서 설정합니다. **세금** 페이지에는 적용되는 세율만 표시됩니다.

  </AccordionItem>
</Accordion>

## 계산대 설정 {#registers}

매장 메뉴에서 **계산대**를 여세요. 계산대는 별도의 준비금과 실사 기록을 갖는 현금 서랍 하나입니다. 각 요소의 관계는 [매장, 계산대, 기기](./registers-and-devices.mdx)를 참조하세요.

### 금전함 {#tills}

모든 매장에는 이미 계산대가 하나씩 있습니다. 처음 만드는 매장은 사이트의 기존 계산대를 이어받으며, 이후에 만드는 매장에는 자체 계산대가 생깁니다. 매장을 저장하면 **금전함** 표에 계산대가 나열됩니다. 저장하기 전에는 **계산대를 추가하려면 먼저 매장을 저장하세요.** 라는 안내가 표시됩니다.

1. 캐셔에게 표시될 계산대 이름을 지정하려면 해당 계산대의 **⋯** 메뉴에서 **이름 변경**을 선택하세요.
2. 캐셔가 이 금전함을 열 때 자동으로 입력할 **개점 준비금**을 입력하세요. 변경한 금액은 다음 개점부터 적용됩니다. 여기에 금액을 설정하기 전까지는 POS가 마지막 실사 금액을 입력합니다. 필드에 표시되는 **200.00**은 저장된 값이 아닙니다.
3. 현금 서랍이 하나 더 필요한 경우에만 **+ 계산대 추가**를 클릭하세요. 새 계산대의 이름은 **계산대 2**, **계산대 3** 등으로 지정되며, 변경할 수 있습니다.

<Accordion>
  <AccordionItem question="금전함 표: 상태 및 ⋯ 메뉴">

- **계산대** — POS에 표시되는 계산대 이름입니다.
- **개점 준비금** — 캐셔가 이 금전함에서 업무를 시작할 때의 현금입니다.
- **상태** — 개점한 사람과 시간이 표시되는 **개점 시간**, 실사하는 사람이 표시되는 **실사 중**, 또는 마지막 마감 번호와 날짜가 표시되는 **마감됨**입니다.
- **⋯** — **이름 변경**, 다른 매장으로 **이동**, **사용 종료**를 선택할 수 있습니다. 세션이 아직 열려 있는 금전함은 사용 종료할 수 없습니다. 먼저 세션을 마감하세요. 계산대는 한 번에 하나의 매장에만 속합니다.

</AccordionItem>
</Accordion>

### 현금 서랍 규칙 {#cash-drawer-rules}

이 매장의 캐셔가 개점과 마감 시 서랍의 현금을 세어야 하는데 **매일 계산대 개점 및 마감**이 꺼져 있다면 다음을 수행하세요.

1. **사용자 지정**을 클릭하세요.
2. **매일 계산대 개점 및 마감**을 켜세요.

대부분의 매장에 필요한 규칙입니다. 캐셔는 준비금으로 시작하고 마감할 때 서랍의 현금을 셉니다. 꺼져 있으면 POS가 바로 장바구니로 이동합니다.

이 규칙은 처음에 **POS → 설정 → 일반**의 [계산대](../settings/wp-admin/registers.mdx#one-register)에 설정된 **사이트 기본값**을 따릅니다. **사용자 지정**으로 이 매장에만 적용되는 규칙을 변경할 수 있습니다.

<Accordion>
  <AccordionItem question="선택적 현금 서랍 규칙: 관리자 승인, 마감 알림, 사이트 규칙으로 되돌리기">

매일 계산대를 개점하고 마감하도록 설정한 경우 다음 두 규칙도 켤 수 있습니다.

- **실사 차이가 다음 금액을 초과하면 관리자 승인 요청**에 금액을 설정합니다(처음 켜면 **5.00**). 실사 차이가 이 금액보다 크면 계산대를 마감하기 전에 관리자 승인이 필요합니다.
- **캐셔에게 마감 알림을 보낼 시간**을 설정합니다(처음 켜면 **17:30**). 이 시간이 지나면 계산대에 **마감 시간 초과**가 표시되며, 장바구니가 비어 있을 때 **결제** 버튼이 **계산대 마감**으로 바뀝니다.

사이트 설정을 따르는 동안 각 규칙에는 **사이트 기본값**이 표시됩니다. 변경 후 **사이트 기본값 사용**을 누르면 해당 규칙만 되돌리고, **사이트 기본값으로 재설정**을 누르면 세 규칙을 모두 되돌립니다.

</AccordionItem>
</Accordion>

### 보고서 및 마감 {#reports-and-closures}

**마감 인쇄물**과 **매출 보고서**에서 금전함을 마감하거나 매출 보고서를 실행할 때 인쇄할 내용을 선택합니다. 각각 **사용자 지정**을 누르기 전까지는 **사이트와 동일**이며, **사이트 템플릿 사용**을 누르면 되돌아갑니다.

## 매장을 사용할 사람 선택 {#staff}

매장 메뉴에서 **직원**을 여세요.

- **POS 접근 권한이 있는 모든 사용자** — 기본값입니다. 매장이 하나일 때 적합합니다.
- **선택한 사용자만** — 이 매장에 로그인할 수 있는 사람을 각각 선택하세요. 역할에 따라 권한을 받았든 개별적으로 권한을 받았든 POS 접근 권한이 있는 모든 사람이 목록에 표시됩니다. 열 명이 넘으면 **사용자 검색**으로 목록을 좁힐 수 있습니다.

:::warning 마지막 사람의 선택을 해제하면 모든 사용자가 매장에 접근할 수 있습니다
마지막 사람의 선택을 해제하면 매장 설정이 **POS 접근 권한이 있는 모든 사용자**로 바뀌고 이를 알리는 안내가 표시됩니다. 누군가를 제외하려면 다른 사람이 최소 한 명은 선택된 상태인지 확인하세요.
:::

여러 매장에서 일하는 캐셔는 각 매장에서 선택해야 합니다.

## 캐셔에게 표시되는 화면 {#what-cashiers-see-at-login}

새 매장을 확인하려면 해당 매장 캐셔의 WordPress 계정으로 POS에 로그인하세요. 로그인 후 표시되는 선택지는 기기에 따라 다릅니다.

**로그인 시 새 매장이 표시되는 경우:**

1. **매장 선택**에서 새 매장을 선택하세요. 사용할 수 있는 매장이 하나뿐이면 **매장** 아래에 이미 선택되어 있습니다.
2. **POS 열기**를 누르세요.

**로그인 시 사용할 수 있는 다른 매장만 표시되는 경우**(기기가 이미 해당 매장에서 사용 중인 경우):

1. 해당 매장에서 POS를 여세요.
2. 아바타를 눌러 캐셔 패널을 열고 **매장 전환**에서 새 매장을 선택하세요. [매장과 계산대 선택](./registers-and-devices.mdx#choosing-a-store-and-a-register)을 참조하세요.

어느 경우든 장바구니 상단의 계산대 표시줄에 새 매장 이름이 표시되는지 확인하세요.

새 기기에서는 **매장 선택**에 캐셔가 사용할 수 있는 모든 매장이 나열됩니다.

<JourneyShot manifest={manifest} device="tablet" step={1} alt="캐셔가 로그인한 화면: 매장 선택에 번호와 함께 두 매장이 나열되고 하나가 선택되어 있으며, POS 열기 버튼이 표시됩니다">

1. **사용할 수 있는 매장** — 여기서는 이 매장이 선택되어 있습니다. 이름 뒤의 숫자는 WP Admin의 매장 ID입니다.
2. **다른 매장** — 이 캐셔가 사용할 수 있는 두 번째 매장으로, 대신 선택할 수 있습니다.
3. **POS 열기** — 매장을 선택하면 활성화됩니다. 매장이 하나뿐이면 이미 선택되어 있으며 제목에 **매장**이 표시됩니다.

</JourneyShot>

캐셔가 사용할 수 있는 매장이 없으면 화면에 **이 사용자가 사용할 수 있는 매장이 없습니다**가 표시됩니다. 매장의 **직원** 페이지에서 해당 캐셔를 선택하거나 **POS 접근 권한이 있는 모든 사용자**로 설정하세요.

매장에 계산대가 여러 개이면 계산대 표시줄에 계산대 이름도 표시됩니다. 옆에는 계산대에 필요한 조치가 있을 때 상태가 표시됩니다. [계산대 개점](../pos/register/index.mdx#open)에서 표시줄 화면을 볼 수 있습니다.

<Accordion>
  <AccordionItem question="계산대 상태: 마감됨, 실사 중, 승인 필요, 마감 시간 초과">

각 상태는 매장의 [현금 서랍 규칙](#cash-drawer-rules)을 따릅니다.

| 상태 | 표시되는 경우 |
| --- | --- |
| **마감됨** | 계산대가 열려 있지 않습니다. 현금 필드에는 금전함의 **개점 준비금**이 설정되어 있으면 그 금액이, 그렇지 않으면 마지막 실사 금액이 입력됩니다. |
| **실사 중** | 누군가 서랍을 마감하기 위해 현금을 세고 있습니다. |
| **승인 필요** | 실사 차이가 설정한 한도를 초과하여 관리자의 승인이 필요합니다. |
| **마감 시간 초과** | 마감 시간이 지났는데도 계산대가 열려 있습니다. |

열려 있는 계산대에 필요한 조치가 없으면 상태가 표시되지 않습니다.

  </AccordionItem>
</Accordion>

각 판매는 처리된 매장에 기록됩니다.

## 매장별 가격 및 세금 {#per-store-pricing}

Pro에서는 재고를 공유하면서 특정 매장에만 상품 가격이나 세금을 별도로 설정할 수 있습니다. 필요한 매장이 없으면 이 단계는 건너뛰세요.

<Accordion>
  <AccordionItem question="선택 사항: 이 매장에 다른 가격 또는 세금 설정">

1. **WP Admin → 상품**에서 상품을 여세요.
2. **일반** 탭에서 해당 매장의 ***매장 이름* 전용 가격 사용.** 을 선택하세요.
3. **정상 가격**을 입력하고, 필요하면 **할인 가격**도 입력하세요.
4. 상품을 업데이트하세요.

해당 매장의 캐셔에게는 이 가격이 적용되며, 다른 매장은 모두 일반 WooCommerce 가격을 사용합니다. ***매장 이름* 전용 세금 사용.** 은 세금 관할 지역이 다른 매장의 **세금 상태**와 **세금 클래스**에 같은 방식으로 적용됩니다. 옵션 상품의 경우 **옵션** 아래 각 옵션에 선택 상자가 있으며, 옵션의 세금 선택 상자에서는 **세금 클래스**만 설정합니다.

:::tip 위치별 재고
매장별 가격을 설정해도 재고 수량은 하나로 공유합니다. 위치별로 재고를 관리하려면 [ATUM Multi-Inventory](../extensions/atum.mdx)를 참조하세요. ATUM을 사용할 때 **가격 출처**가 **ATUM**인 매장은 ATUM에 해당 상품의 가격이 있으면 위치별 가격을 대신 사용합니다. [가격 출처 선택](../extensions/atum.mdx#pricing-source)을 참조하세요.
:::

</AccordionItem>
</Accordion>

## 문제가 발생한 경우 {#goes-wrong}

페이지 상단에 **저장하지 못했습니다.** 와 함께 이유가 표시됩니다. 사이트에 변경 사항이 반영되지 않은 상태입니다. 메시지의 **다시 시도**를 누르거나 페이지를 새로 고침하여 현재 내용을 확인하세요.

**계산대를 추가하려면 먼저 매장을 저장하세요.** 먼저 **만들기**를 클릭하세요. 매장이 생성되면 **금전함** 표가 나타납니다.

**계산대를 사용 종료할 수 없습니다.** 열려 있거나 실사 중인 세션이 있습니다. POS에서 실사 후 마감한 다음 **사용 종료**를 선택하세요.

로그인 시 **이 사용자가 사용할 수 있는 매장이 없습니다**가 표시됩니다. 캐셔가 어떤 매장의 **직원** 목록에도 포함되어 있지 않습니다. 해당 캐셔를 선택하거나 매장을 **POS 접근 권한이 있는 모든 사용자**로 설정하세요.

**매장 메뉴가 없습니다.** Pro가 활성화되어 있지 않습니다. **POS → 설정 → 라이선스**에서 라이선스를 확인하세요. [WCPOS Pro 설치](../getting-started/pro-license.mdx)를 참조하세요.

## 특수한 경우 {#edge-cases}

<Accordion>
  <AccordionItem question="매장을 추가하면 기존 주문은 어떻게 되나요?">

변경되지 않습니다. 판매는 처리될 때 해당 매장에 기록되므로 새 매장이 이전 주문을 가져오지 않습니다. 주문 하나를 다른 매장으로 옮기려면 **WooCommerce → 주문**에서 주문을 열고 **POS 매장**을 변경하세요.

  </AccordionItem>

  <AccordionItem question="매장을 삭제하려면 어떻게 하나요?">

매장의 어느 페이지에서든 오른쪽 상단의 **매장을 휴지통으로 이동**을 선택하거나(먼저 확인을 요청합니다), 목록에서 **휴지통**을 선택하세요. 휴지통으로 이동한 매장은 매장 선택 화면에서 사라지지만, 해당 주문에는 매장 이름, 주소, 로고가 그대로 표시됩니다. **복원**을 누르면 설정과 함께 되살릴 수 있습니다.

휴지통에서 **영구 삭제**를 선택하면 완전히 삭제됩니다. 단, 매장의 계산대 중 하나라도 열려 있거나 실사 중이면 삭제할 수 없습니다. 삭제 후 해당 주문에는 **매장 #** 과 ID가 표시됩니다.

  </AccordionItem>

  <AccordionItem question="매장마다 다른 통화를 사용할 수 있나요?">

네, **통화 및 언어**에서 설정할 수 있습니다. 해당 매장의 가격, 합계, 영수증에 그 통화가 사용됩니다. 금액 자체가 아니라 표시 방식이 바뀝니다. 결제 수단이 해당 통화를 지원해야 하며, 환율은 직접 처리해야 합니다.

  </AccordionItem>

  <AccordionItem question="Pro를 끄면 어떻게 되나요?">

사이트는 다시 하나의 계산대를 사용하게 됩니다. [Pro를 비활성화한 경우](../settings/wp-admin/registers.mdx#if-pro-is-deactivated)를 참조하세요.

  </AccordionItem>
</Accordion>
