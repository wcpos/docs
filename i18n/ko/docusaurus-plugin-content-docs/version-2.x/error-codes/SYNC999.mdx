## 의미 {#what-this-means}

동기화 중 예기치 않은 문제가 발생했습니다.

이 항목에 명시된 작업이 완료되었는지 확인하고, 완료되지 않았다면 다시 실행하세요. 문제가 반복되면 **디버그 정보 복사**를 탭하고 지원팀에 보내세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 지우지 마세요. 아직 매장에 없는 변경 사항이 있을 수 있습니다. 항목에 명시된 작업이 완료되지 않았다면 다시 실행하세요.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼치고 명시된 작업을 찾으세요. 작업이 완료되었는지 확인하세요. 저장 작업이라면 주문이나 레코드를 열어 변경 사항이 표시되는지 확인하세요. 표시된다면 WCPOS가 자동으로 전송하므로 그대로 두세요.
2. 완료되지 않았다면 다시 실행하세요. 로그 항목에 변경 사항이 이 기기에 저장되지 않았다고 표시되면 기록된 내용이 없는 것입니다.
3. 로그 항목의 코드와 표시된 이유를 기록하세요. 999 코드는 해당 원인에 대한 전용 코드가 아직 없다는 뜻이므로, 이러한 상황 정보가 지원팀에 꼭 필요합니다.
4. 이 문제가 반복되면 **로그** 탭에서 **디버그 정보 복사**를 탭하고 지원팀에 보내세요. 문제를 보고하면 해당 원인을 위한 코드가 추가되는 데 도움이 됩니다.
