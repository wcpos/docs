## 오류의 의미 {#what-this-means}

검색 색인 재구축에 실패하여 앱이 초기화를 다시 시도하는 동안 검색 결과가 불완전할 수 있습니다.

검색 색인 문제([CLIENT141](/error-codes/CLIENT141) 또는 [CLIENT143](/error-codes/CLIENT143))를 감지한 뒤 앱이 색인 재구축을 시도했으나 재구축 자체가 실패했습니다. 검색은 잘못된 것으로 확인된 결과를 숨긴 기존 색인을 사용하거나 기기의 데이터를 직접 검색하여 계속 결과를 반환하지만, 해당 목록의 결과가 누락되거나 순서가 잘못될 수 있습니다. 다음 검색이나 준비 상태 확인 시 색인 초기화를 다시 시도하며 자동으로 복구될 수 있습니다. 결과가 계속 잘못되면 앱을 새로 고쳐 새로 시작할 수도 있습니다.

## 데이터 영향 {#your-data}

매장 데이터는 변경되지 않았습니다. 이 문제는 기기에 이미 저장된 데이터에서 생성되는 로컬 검색 색인에만 해당합니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 여세요. 항목의 문맥 정보에 영향을 받은 목록과 재구축 중 발생한 오류가 나와 있습니다. 저장 공간 관련 오류라면 먼저 기기의 공간을 확보하세요. 웹에서는 비공개 또는 시크릿 창도 피하세요.
2. 해당 목록에서 다시 검색하세요. 앱이 색인 초기화를 자동으로 다시 시도합니다.
3. 결과가 여전히 누락되거나 순서가 잘못되면 앱을 새로 고치세요. 웹에서는 브라우저 탭을 새로 고치고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요. 이후에도 CLIENT144가 다시 기록되면 로그 화면에서 디버그 정보를 내보내고 지원팀에 문의하세요.
