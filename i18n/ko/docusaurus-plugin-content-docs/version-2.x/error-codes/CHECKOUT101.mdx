## 오류의 의미 {#what-this-means}

결제가 완료되지 않았으며, 장바구니는 안전하게 보존되어 다시 시도할 수 있습니다.

장바구니를 확인하고 결제를 다시 시도하세요. 현재 장바구니 내용은 그대로 보존되어 있습니다.

## 데이터에 미치는 영향 {#your-data}

주문 자체는 안전하며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔 안내:

1. 장바구니는 변경되지 않았습니다. 내용을 확인하고 결제를 다시 시도하세요.
2. 다시 실패하면 매장 상태 → 로그에서 로그 항목을 펼치세요. serverCode와 상태를 통해 매장에서 주문을 거부했는지, 그 이유가 무엇인지 알 수 있습니다.
3. 실패 사유에 특정 항목이 명시되어 있다면 해당 항목을 제거하고 판매를 완료한 다음 해당 상품을 조사하세요.

**매장 사이트에서** — 사이트 관리자 안내: 500번대 상태로 실패가 반복되면 사이트 문제입니다. WooCommerce → 상태 → 로그에서 실패 시점의 PHP 오류를 확인하세요.
