## 오류의 의미 {#what-this-means}

매장에서 이 주문이 이미 결제되었다고 알렸지만, POS에서도 이미 결제를 받은 상태였습니다. 따라서 고객은 두 번 결제했습니다.

POS 결제는 `order_already_paid` 사유로 실패 표시된 채 주문의 거래 원장에 보관됩니다. 따라서 숨겨지는 내역이 없으며 두 번째 결제가 아무 알림 없이 삭제되지도 않습니다. 이제 해당 금액을 돌려주어야 합니다.

## 데이터에 미치는 영향 {#your-data}

금액이 이체되었으며 고객에게 두 번 청구되었습니다. POS에서 받은 결제를 환불하세요. 주문과 온라인 결제는 그대로 유지되며, 추가 결제도 버려지지 않고 주문에 기록됩니다.

## 문제 해결 {#troubleshoot}

**POS 기기에서** — 고객이 떠나기 전에 다음을 수행하세요:

1. 고객에게 이 주문이 이미 온라인에서 결제되었으며 두 번째 결제는 환불될 것이라고 알려 주세요.
2. POS에서 받은 결제 금액과 수단을 확인하세요. **매장 상태 → 데이터베이스**의 **… 확인 필요** 아래에 해당 주문이 *"주문 #…은(는) 이미 온라인에서 결제되었습니다. POS에서도 …을(를) 받았습니다. 해당 결제를 환불하세요"* 등의 문구와 함께 표시됩니다. 같은 문구가 **매장 상태 → 로그**에도 표시됩니다.
3. 결제받은 방식대로 돌려주세요. 현금은 금전함에서 반환하고, 카드 결제는 카드 단말기나 결제 서비스 제공업체의 대시보드에서 해당 결제를 환불하세요. 현금을 돌려줄 때 출금으로 기록하지 마세요. 거부된 결제는 금전함의 예상 현금에 포함된 적이 없으므로 금전함 잔액은 이미 맞습니다.
4. 이 경우 WCPOS에서 해당 주문의 **환불**을 사용하지 마세요. 이 기능은 매장이 거부한 POS 결제가 아니라 주문 자체의 정상적인 온라인 결제를 환불합니다.
5. 주문을 취소하거나 삭제하지 마세요. 정상적으로 결제된 주문이며, 추가 결제만 잘못된 것입니다.

**매장 측 조치** — 사이트 관리자 안내:

1. WooCommerce에서 온라인 결제를 게이트웨이 기록과 대조해 두 결제 중 어느 결제를 유지할지 확인하세요. **WooCommerce → 주문**에 중복 POS 결제를 반환했다는 사실과 반환 방법, 시점을 주문 메모로 추가하세요.
2. 환불 처리가 완료되었는지 확인하세요. 카드 환불이 고객의 명세서에 반영되기까지 며칠이 걸릴 수 있습니다.
3. 이 문제가 반복된다면 대개 POS에서 이미 열어 둔 주문이 온라인에서 결제되는 것이 원인입니다. 결제가 완료되기 전에 주문이 POS로 전달되는 과정을 검토하세요.
