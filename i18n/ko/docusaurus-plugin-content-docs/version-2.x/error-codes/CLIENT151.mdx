## 오류의 의미 {#what-this-means}

화면 일부를 불러오지 못해 오류 메시지로 대체되었습니다.

화면이나 패널을 그리는 중 오류가 발생하여 WCPOS가 종료되는 대신 해당 부분을 빨간색 “문제가 발생했습니다” 메시지로 대체했습니다. 앱의 나머지 부분은 계속 작동합니다. 이는 매장이나 기기의 문제가 아닌 앱의 결함입니다. 메시지에는 발생한 문제가 표시되고, 로그 항목에는 화면의 어느 부분에서 실패했는지가 기록됩니다. 지원팀에 필요한 정보가 바로 이것입니다. 오류 보고가 허용되어 있으면 동일한 오류가 개발자에게 자동으로 전달됩니다.

## 데이터 영향 {#your-data}

이 오류 자체로 데이터가 기록되거나 손실되지는 않았습니다. 이미 저장된 장바구니, 주문, 상품 수정 사항은 기기에 그대로 남아 있으며 정상적으로 동기화됩니다. 작업 도중 메시지가 나타났다면 패널이 복구된 뒤 작업이 완료되었는지 확인하고 다시 시도하세요.

## 문제 해결 {#troubleshoot}

1. 오류 메시지의 X를 눌러 닫으세요. 패널이 다시 그려지며, 일시적인 오류라면 자동으로 해결됩니다.
2. 오류가 바로 다시 나타나면 앱을 새로 고치세요. 웹에서는 브라우저 탭을 새로 고치고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요.
3. 새로 고친 뒤에도 같은 메시지가 다시 나타나면 로그 화면에서 디버그 정보를 내보내고 지원팀에 문의하세요. 로그 항목에는 오류와 문제가 발생한 화면 부분이 나와 있습니다.
