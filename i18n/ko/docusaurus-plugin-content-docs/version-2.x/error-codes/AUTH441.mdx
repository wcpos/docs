## 오류의 의미 {#what-this-means}

로그인 토큰이 이 서버에서 허용하는 크기보다 큽니다.

서버가 크기 때문에 로그인 토큰을 거부했습니다. Authorization 헤더로 전송하면 400이, URL로 전송하면 414가 반환됩니다. 클라이언트 측 인코딩으로는 크기를 줄일 수 없습니다. 서버의 헤더/URL 크기 제한을 높이거나 토큰을 더 작게 만들어야 합니다.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. Apache에서는 vhost 설정의 LimitRequestFieldSize(헤더로 전달 시) 또는 LimitRequestLine(URL로 전달 시) 값을 높이세요.
2. nginx에서는 large_client_header_buffers 값을 높이세요.
3. 프록시나 CDN 뒤에 있다면 해당 계층에서 크기를 제한할 수 있으므로 양쪽 모두 확인하세요.
4. 제한을 변경할 수 없다면 이 사이트에 더 작은 토큰을 발급하는 방법을 지원팀에 문의하세요.
