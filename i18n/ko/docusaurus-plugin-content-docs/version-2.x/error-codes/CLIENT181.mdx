## 오류의 의미 {#what-this-means}

WCPOS가 해당 매장으로 전환하지 못했습니다.

WCPOS를 새로 고치고 매장을 다시 선택하세요. 이 기기의 데이터는 손실되지 않습니다.

동일한 사이트에서 매장이나 캐셔를 전환하는 작업이 완료되기 전에 실패했습니다. 이 기기에 있는 이전 매장의 데이터는 그대로 유지됩니다.

## 데이터 영향 {#your-data}

이 기기의 데이터는 손실되지 않습니다. 전송 대기 중인 항목을 포함하여 이전 매장의 데이터가 그대로 유지됩니다.

## 문제 해결 {#troubleshoot}

1. WCPOS를 새로 고치세요. 웹에서는 브라우저 탭을 새로 고치고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요.
2. 매장과 캐셔를 다시 선택하세요.
3. 전환이 계속 실패하면 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 문의하세요. 문제를 해결하려고 로컬 데이터를 지우거나 사이트를 제거하지 마세요. 아직 전송하지 않은 항목을 포함하여 이전 매장의 데이터가 이 기기에 있습니다.
