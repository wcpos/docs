## 오류의 의미 {#what-this-means}

매장에서 계산한 이 주문의 합계가 계산대에 표시된 금액과 다릅니다. 주문은 매장에서 계산한 합계로 저장됩니다.

고객이 떠나기 전에 주문을 열어 합계를 비교하세요. 이미 대금을 받았다면 차액을 청구하거나 환불하세요. 예상치 못한 차이가 있다면 지원팀에 문의하세요.

## 데이터 상태 {#your-data}

주문은 매장에서 계산한 합계로 저장됩니다. 대금은 이미 받았을 수도 있고 아직 받지 않았을 수도 있습니다. 이 검사는 주문이 저장될 때 실행되므로 결제 전에 실행될 수 있습니다. 이 문제가 계속 발생하면 **로그** 탭의 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 고객이 떠나기 전에 다음을 수행하세요:

1. 주문을 열어 합계를 계산대에 표시된 금액과 비교하세요. 어떤 금액이 다른지는 로그 항목에 기록됩니다.
2. 대금을 이미 받았는지, 얼마를 받았는지 확인하세요. 카드 단말기로 결제했다면 단말기 화면이나 영수증을, 현금이라면 받은 금액을, 다른 결제 게이트웨이라면 해당 게이트웨이의 기록을 확인하세요.
3. 이미 대금을 받았다면 평소 절차에 따라 차액을 청구하거나 환불하세요. 아직 대금을 받지 않았다면 현재 표시된 주문 합계 금액으로 결제를 받으세요.

**매장에서** — 사이트 관리자용:

1. WP Admin에서 주문을 열어 합계를 계산대에 표시된 금액과 비교하세요. 어떤 금액이 달랐는지는 로그 항목에 기록됩니다.
2. 일반적인 원인은 계산대에서 예상한 것과 다른 세금 설정이나 서버에서 금액을 다시 계산하는 할인 또는 가격 책정 플러그인입니다. 먼저 매장의 세금 설정을 검토하세요.
3. 차이가 발생한 이유를 알 수 없다면 **로그** 탭의 **디버그 정보 복사**를 사용하고 주문 번호와 함께 지원팀에 문의하세요.
