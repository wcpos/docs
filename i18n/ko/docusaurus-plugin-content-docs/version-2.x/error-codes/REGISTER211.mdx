## 오류의 의미 {#what-this-means}

현금 서랍의 금액을 집계하고 계산대를 마감했지만 매장에서 마감을 거부하여 매장에서는 해당 근무 세션이 아직 열려 있습니다.

매장이 마감 요청을 받지 못한 것이 아니라 거부한 것이므로 자동으로 재시도되지 않습니다. 계산대에는 집계 금액, 메모, 화폐 단위별 내역이 보관됩니다. 원인을 해결한 뒤 **다시 시도**를 누르세요.

## 데이터 상태 {#your-data}

주문에는 영향이 없으며 판매 내역에도 위험은 없습니다. 계산대에 집계 금액, 메모, 화폐 단위별 내역이 보관되므로 별도로 적어 둘 필요가 없습니다.

## 문제 해결 {#troubleshoot}

1. 먼저 원인을 해결하세요. 그렇지 않으면 다음 시도도 같은 이유로 거부됩니다. 보통 마감하는 캐셔 계정의 현금 관리 권한이 없어졌거나 다른 기기에서 이미 세션이 종료된 경우입니다.
2. 이 계산대에서 현금을 집계하는 동안에는 판매가 차단됩니다. 관리자에게 마감 권한을 복구해 달라고 요청하세요.
3. 마감에 관리자 승인이 필요했다면 승인은 마감 시점에 확인되며 다음 시도로 이어지지 않습니다. 관리자에게 새 시도를 승인해 달라고 요청하세요.
4. **다시 시도**를 누르세요. 입력했던 금액이 담긴 집계 화면이 열리므로 확인한 뒤 다시 마감할 수 있습니다.
5. **매장 관리자:** WP Admin에서 세션이 아직 열려 있는지, 마감하는 캐셔에게 현금 관리 권한이 있는지 확인하세요. 같은 계산대에서 마감이 계속 거부되면 로그 항목에 매장이 문제 삼은 필드나 권한이 표시됩니다.
