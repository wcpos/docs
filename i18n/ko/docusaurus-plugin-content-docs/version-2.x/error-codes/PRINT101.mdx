## 오류의 의미 {#what-this-means}

이 영수증의 자동 인쇄가 시작되지 않았습니다.

판매 내역은 저장되었습니다. 주문의 영수증을 열고 **영수증 인쇄**를 누르세요. 다음 영수증이 자동으로 인쇄되도록 자동 인쇄 설정과 프린터를 확인하세요.

## 데이터 상태 {#your-data}

판매 내역은 저장되었습니다. 주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 판매 후 표시되는 영수증에서 **영수증 인쇄**를 눌러 수동으로 인쇄하세요. 판매 내역에는 영향이 없습니다. 화면에 영수증이 없다면 WCPOS Pro에서 **주문**을 열고 해당 주문의 **영수증** 작업을 선택한 다음 **영수증 인쇄**를 누르세요.
2. 판매 후 아무것도 인쇄되지 않는다면 자동 인쇄가 꺼져 있을 가능성이 큽니다. 장바구니 설정(장바구니 위의 슬라이더 아이콘)을 열고 **결제 후 영수증 자동 인쇄**를 켜세요. **결제 후 영수증 자동 표시**의 설정 여부와 관계없이 인쇄됩니다.
3. **설정 → 인쇄**에서 프린터를 확인하세요. 사용할 프린터가 **프린터** 목록에 있고, 해당 프린터의 **편집** 화면에서 **테스트 인쇄**가 되는지 확인하세요.
4. **영수증 인쇄**도 실패하면 프린터나 연결 문제입니다. [PRINT301](/error-codes/PRINT301)을 참조하세요. 수동 인쇄는 되지만 해당 설정이 켜진 상태에서도 자동 인쇄가 계속 실패하면 **로그** 탭의 **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.
