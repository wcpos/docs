## 오류의 의미 {#what-this-means}

매장 앞단의 프록시가 헤더가 너무 많다는 이유로 서버 응답을 거부합니다.

캐시 또는 프록시 계층(흔히 Varnish)이 응답 헤더의 개수나 크기를 제한합니다. 매장의 간단한 엔드포인트는 제한을 넘지 않지만 전체 API 응답은 제한을 초과하여 WordPress가 아닌 프록시에서 503을 반환합니다. 해당 계층의 제한을 높여야 합니다.

## 데이터 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. Varnish에서 http_max_hdr(헤더 개수)와 http_resp_hdr_len / http_resp_size(크기)를 높이세요.
2. 어느 프록시 계층이 503을 반환하는지 호스팅 업체에 문의하세요. WordPress에서는 요청이 실패하지 않으므로 WordPress 오류 로그에는 아무것도 표시되지 않습니다.
3. 빠른 확인 방법: 매장의 /wcpos/v2/ping은 정상적으로 응답하지만 데이터 엔드포인트는 503을 반환합니다.
