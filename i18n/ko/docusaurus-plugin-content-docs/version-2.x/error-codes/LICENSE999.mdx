## 오류의 의미 {#what-this-means}

라이선스 확인 중 예기치 않은 문제가 발생했습니다.

POS는 계속 작동합니다. Pro 기능이 계속 잠겨 있으면 라이선스 키를 다시 입력한 뒤 지원팀에 문의하세요.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 작업을 계속하세요. 라이선스 확인 때문에 POS가 멈추지는 않습니다.
2. Pro 기능이 계속 잠겨 있으면 매장 관리자에게 **WP Admin > POS > 설정 > 라이선스**를 열어 달라고 요청하세요. 라이선스가 활성화된 것으로 표시되면 WCPOS 계정의 전체 키를 준비하고(페이지에는 축약된 키만 표시됩니다) 먼저 **비활성화**를 누르세요. 그런 다음 **라이선스 키**에 키를 입력하고 **활성화**를 누르세요.
3. POS 기기에서 앱을 다시 로드해 라이선스를 다시 인식하도록 하세요.
4. Pro 기능이 여전히 잠겨 있으면 **매장 상태 → 로그**의 **디버그 정보 복사**를 사용하고, 라이선스 식별 정보를 첨부해 지원팀에 문의하세요.
