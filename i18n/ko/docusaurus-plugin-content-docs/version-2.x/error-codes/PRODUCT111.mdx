## 오류의 의미 {#what-this-means}

이 변형을 상품에 추가하지 못했습니다.

그 외에는 변경된 사항이 없습니다. 상품을 열어 해당 변형이 있는지 확인하세요. 없다면 상위 상품에 설정된 속성을 사용하는지 확인한 뒤 다시 추가하세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 없는 변경 사항이 저장되어 있을 수 있습니다. 이 변형만 추가되지 않았으며 그 외에는 변경된 사항이 없습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 매장의 거부 사유를 확인하세요. 보통 속성이 누락되었거나 옵션 조합이 유효하지 않은 경우입니다.

**계산대에서:** 상품을 열어 해당 변형이 있는지 확인하세요. 이미 있다면 다시 추가하지 마세요. 없다면 상위 상품에 설정된 속성을 사용하는지 확인하고 필드를 수정한 뒤 다시 추가하세요.

**매장에서(WP Admin):** 상위 상품의 속성을 확인하세요. 변형에서 사용하는 모든 속성이 상위 상품에 있어야 하며, 변형에 사용하도록 표시되어 있어야 합니다.

계속 거부되나요? **로그** 탭의 **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.
