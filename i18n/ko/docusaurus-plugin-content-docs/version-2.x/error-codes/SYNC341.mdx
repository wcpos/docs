## 의미 {#what-this-means}

이 매장을 이용하려면 이제 더 최신 버전의 POS 앱이 필요합니다.

매장의 WCPOS 플러그인이 현재 앱 버전에서 지원하는 것보다 새로운 동기화 프로토콜로 전환되었습니다. 따라서 매장에서는 앱이 업데이트될 때까지 의도적으로 동기화를 일시 중지합니다. 이는 오류가 아닌 보호 조치로, 오래된 앱이 매장 데이터를 잘못 읽거나 쓰는 것을 방지합니다. WCPOS를 업데이트한 후 다시 여세요. 웹에서는 페이지를 새로고침하세요. 미전송 판매는 이 기기에 유지되며 업데이트 후 전송됩니다.

## 데이터 상태 {#your-data}

계산대의 데이터는 손실되지 않습니다. 전송 대기 중인 판매와 수정 내용은 기기에 안전하게 유지되며, 업데이트된 앱이 매장에 연결되면 동기화됩니다. 아직 더 최신 버전의 앱이 없다면(아래 마지막 두 단계 참고), 새 버전이 나올 때까지 대기 상태로 유지됩니다.

## 문제 해결 {#troubleshoot}

1. 웹 앱에서는 브라우저 탭을 새로고침하세요. 새로고침하면 새 버전을 불러옵니다. 같은 화면이 다시 나타나면 강력 새로고침을 사용하세요(**Shift**를 누른 상태로 새로고침).
2. 데스크톱에서는 대기 중인 업데이트를 설치한 후 앱을 다시 여세요. 앱이 다시 연결될 때 확인이 실행됩니다. 업데이트가 표시되지 않으면 [설치](/getting-started/installation) 페이지에서 최신 빌드를 다운로드하세요.
3. iPhone, iPad 또는 Android에서는 처음 설치한 경로를 통해 WCPOS를 업데이트한 후 앱을 다시 여세요. iOS는 TestFlight, Android는 Play 테스트 프로그램을 사용하며, 두 경로 모두 [설치](/getting-started/installation) 페이지에 링크가 있습니다.
4. **사이트 관리자:** 아직 더 최신 버전의 앱이 없다면, 이에 맞는 앱이 출시되기 전에 매장의 WCPOS 플러그인이 먼저 업데이트된 것입니다. 매장의 WCPOS 플러그인을 이전 버전으로 복원하면 새 앱이 출시될 때까지 동기화를 재개할 수 있습니다.
5. 앱 업데이트도 플러그인 이전 버전 복원도 할 수 없다면 WCPOS 지원팀에 문의하세요.
