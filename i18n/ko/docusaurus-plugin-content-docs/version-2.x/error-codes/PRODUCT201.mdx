## 오류의 의미 {#what-this-means}

이 상품 이미지를 사용할 수 없지만 상품은 계속 판매할 수 있습니다.

이미지 없이 판매를 계속 진행하세요. WCPOS에서 나중에 이미지를 다시 불러옵니다.

## 데이터 상태 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**계산대에서:** 평소처럼 판매하세요. 상품에는 영향이 없으며 백그라운드에서 이미지 불러오기를 다시 시도합니다.

**매장에서(WP Admin):**

1. 특정 상품의 이미지가 전혀 불러와지지 않으면 이미지를 다시 저장하세요. 미디어 라이브러리에서 파일이 삭제되었을 수 있습니다.
2. 여러 이미지가 한꺼번에 불러와지지 않으면 사이트의 미디어 호스팅이나 CDN이 원인입니다. 매장 웹사이트 자체에서 이미지가 표시되는지 확인하세요.
