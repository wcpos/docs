## 오류의 의미 {#what-this-means}

서버가 브라우저의 권한 확인(CORS 사전 요청)을 차단하고 있어 웹 앱이 서버에 접근할 수 없습니다.

브라우저는 사용자 정의 헤더가 포함된 교차 출처 API 호출 전에 OPTIONS 요청을 보냅니다. 매장 앞단의 구성 요소(대개 방화벽 규칙)가 OPTIONS를 차단하므로 브라우저가 실제 요청을 전송하지 않습니다. 네이티브 앱에는 영향이 없으며, 서버 측에서 수정해야 합니다.

## 데이터 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 방화벽(WAF)에 OPTIONS 메서드를 차단하는 규칙이 있는지 확인하고 /wcpos/ REST 경로에서는 허용하세요.
2. 일부 보안 플러그인에는 '일반적이지 않은 요청 메서드 차단' 옵션이 있습니다. OPTIONS는 계속 허용되어야 합니다.
3. 테스트: 매장 REST API에 OPTIONS 요청을 보냈을 때 403이 반환되지 않아야 합니다.
4. 데스크톱 및 모바일 앱은 CORS를 사용하지 않으므로 이 문제를 수정하는 동안에도 계속 작동합니다.
