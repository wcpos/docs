## 의미 {#what-this-means}

백그라운드 동기화 작업이 완료되기 전에 예기치 않게 중단되었습니다.

조치할 필요가 없습니다. POS가 이러한 작업을 자동으로 다시 시작하며, 손실된 데이터는 없습니다. 이 코드가 계속 나타나면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.

## 데이터 상태 {#your-data}

손실된 데이터는 없으며 주문이나 상품 데이터에도 영향이 없습니다. 이 문제가 지속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 처음 나타났을 때는 조치할 필요가 없습니다. POS가 비정상 종료된 백그라운드 작업을 자동으로 다시 시작하며, 주문 데이터와는 관련이 없습니다.
2. 몇 분 안에 코드가 반복되면 동기화 엔진이 새로 시작되도록 앱을 한 번 새로고침하세요.
3. 그래도 반복되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요. 작업이 반복적으로 비정상 종료되는 것은 매장 문제가 아니라 보고가 필요한 앱 결함입니다.
