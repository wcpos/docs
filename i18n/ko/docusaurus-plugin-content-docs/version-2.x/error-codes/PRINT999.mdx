## 오류의 의미 {#what-this-means}

인쇄 중 예기치 않은 문제가 발생했습니다. 판매 내역에는 영향이 없습니다.

이 항목에 표시된 인쇄 또는 영수증 작업을 다시 시도하세요. 반복되면 지원팀에 문의하세요.

## 데이터 상태 {#your-data}

판매 내역에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 먼저 로그 항목을 펼쳐 실패한 작업을 확인하세요. 이 코드는 실제 인쇄뿐 아니라 영수증 이메일 대기열 작업과 영수증 템플릿 동기화에도 적용됩니다.
2. 로그에 표시된 작업만 다시 시도하세요. 실제 인쇄 작업일 때만 주문 화면에서 다시 인쇄하세요. 대기열에 있는 이메일은 매장 상태에서 다시 보내고, 템플릿 동기화는 연결된 상태에서 영수증 화면을 다시 열어 재시도하세요.
3. 해당 작업이 계속 실패하면 **로그** 탭의 **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.
