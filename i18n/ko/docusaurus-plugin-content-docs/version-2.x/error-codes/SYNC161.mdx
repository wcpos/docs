## 오류의 의미 {#what-this-means}

이 기기의 저장소가 응답을 멈춰 저장이 일시 중지되었습니다.

WCPOS를 재시작하고(웹에서는 탭을 새로고침하세요) 마지막 판매 내역이나 변경 사항이 저장되었는지 확인하세요. 저장소가 멈추기 직전 몇 초 동안의 변경 사항은 기록되지 않았을 수 있습니다. 이 기기의 데이터를 삭제하지 마세요. 문제가 계속되면 지원팀에 문의하세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 아직 매장에 전송되지 않은 판매 내역이 있을 수 있습니다. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하여 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 앱을 닫았다가 다시 열어 WCPOS를 재시작하세요. 웹에서는 탭을 닫지 말고 새로고침하세요. 대부분의 경우 로컬 데이터베이스에 다시 연결됩니다.
2. 재시작 후 마지막 판매 내역이나 변경 사항이 저장되었는지 확인하세요. 오류가 발생하기 직전 몇 초 동안의 변경 사항은 기록되지 않았을 수 있습니다. 없다면 다시 입력하세요.
3. 웹에서는 비공개/시크릿 창으로 POS 단말기를 실행하지 말고, 저장소를 과도하게 정리하는 확장 프로그램을 피하세요. 둘 다 세션 도중 로컬 저장소를 없앨 수 있으며, 비공개 창을 닫으면 미전송 판매 내역을 포함하여 그 안에 저장된 모든 데이터가 삭제됩니다. 현재 그런 창을 사용 중이라면 **매장 상태 → 데이터베이스**의 **전송 대기 중인 변경 사항**이 0개이고, [선택을 요청하는 패널](../support/store-health.mdx#needs-attention)이 없으며, 동기화되지 않은 미결 주문도 없어질 때까지 창을 열어 두세요([주문 동기화](../pos/cart/open-orders.mdx#sync-order)).
4. 같은 기기에서 반복해서 발생하면 **로그** 탭에서 **디버그 정보 복사**를 사용하여 지원팀에 문의하고, 발생 당시 기기 상태(절전, 탭 전환, 메모리 부족)를 알려 주세요.
