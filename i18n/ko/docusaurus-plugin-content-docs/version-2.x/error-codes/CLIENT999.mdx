## 오류의 의미 {#what-this-means}

WCPOS에서 예기치 않은 오류가 발생했습니다.

다시 시도하기 전에 마지막 작업이 처리되었는지 확인하세요. 판매라면 주문을 열어 상태를 확인하세요. 반복되면 **디버그 정보 복사**를 누르고 WCPOS 지원팀에 보내세요.

## 데이터 영향 {#your-data}

결과를 확인할 수 없으므로 다시 시도하기 전에 확인하세요. 반복되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 다시 시도하기 전에 마지막 작업이 처리되었는지 확인하세요. 판매라면 주문을 열어 상태를 확인하고, 결제라면 단말기나 결제 서비스 제공업체에서도 확인하세요. 처리되지 않았다면 한 번 더 시도하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 문맥 정보를 기록하세요. 999 코드는 해당 오류에 아직 전용 코드가 없다는 뜻이며, 이 정보로 오류를 식별할 수 있습니다.
3. 반복되면 **로그** 탭에서 **디버그 정보 복사**를 누르고 WCPOS 지원팀에 보내세요. 이러한 보고를 통해 해당 오류의 전용 코드가 추가됩니다.
