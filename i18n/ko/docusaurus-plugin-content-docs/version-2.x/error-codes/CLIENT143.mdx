## 오류의 의미 {#what-this-means}

검색에서 찾아야 할 상품이 누락되었습니다.

화면에 보이는 상품이 계속 검색되지 않는 경우가 아니라면 조치할 필요가 없습니다. 계속 검색되지 않으면 WCPOS를 새로 고치세요.

정기 자체 점검에서 레코드에 포함된 단어로 로컬 검색 색인에 해당 레코드를 요청했으나 색인이 반환하지 않았습니다. 따라서 검색 결과가 실제 기기에 저장된 항목보다 적게 표시되었을 수 있습니다. 앱이 색인을 자동으로 재구축할 수 있지만 세션마다 목록별로 한 번만 수행하므로 반드시 재구축되는 것은 아닙니다.

## 데이터 영향 {#your-data}

매장 데이터는 변경되지 않았습니다. 이 문제는 기기에 이미 저장된 데이터에서 생성되는 로컬 검색 색인에만 해당하며, 색인을 재구축해도 데이터가 손실되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 화면에 보이는 상품이 계속 검색되지 않는 경우가 아니라면 조치할 필요가 없으며, 판매를 정상적으로 계속할 수 있습니다. 앱이 색인을 자동으로 재구축할 수 있지만 세션마다 목록별로 한 번만 수행하므로 이 코드가 반복되면 다음 단계로 진행하세요.
2. 앱의 상품, 고객, 주문 또는 기타 목록에서 보이는 레코드가 계속 검색되지 않으면 앱을 새로 고치세요. 웹에서는 브라우저 탭을 새로 고치고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요. 그러면 다음에 문제가 감지될 때 재구축을 새로 시도할 수 있습니다.
3. 새로 고친 뒤에도 코드가 다시 나타나면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요. 로그 항목에는 지원팀이 영향을 받은 목록과 색인에서 누락된 레코드를 식별하는 데 필요한 세부 정보가 포함되어 있습니다.
