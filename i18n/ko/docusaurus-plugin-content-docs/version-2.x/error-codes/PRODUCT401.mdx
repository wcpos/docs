## 오류의 의미 {#what-this-means}

표시된 재고가 매장의 현재 재고보다 오래된 정보일 수 있습니다.

재고를 초과해 판매할 우려가 있다면 판매를 완료하기 전에 매장의 현재 재고를 확인하세요.

## 데이터 상태 {#your-data}

데이터 손실 위험은 없습니다. 계산대의 재고 수치가 매장의 수치보다 오래되었을 뿐이며, 동기화가 복구되면 최신 상태로 갱신됩니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. **계산대에서:** 재고가 적은 상품을 판매하기 전에 계산대의 수치만 믿지 말고 진열대나 WP Admin의 상품 재고를 확인해 실제 수량을 파악하세요.
2. 계산대의 데이터를 새로 고치세요. **매장 상태 → 데이터베이스**를 열고 **상품** 행의 **⋮** 메뉴에서 **지금 변경 사항 확인**을 선택하세요. 변형(크기, 색상)이 있는 상품은 각 변형이 자체 재고를 관리하므로 **변형** 행에서도 같은 작업을 하세요.
3. 수치가 여전히 최신 상태가 아니라면 동기화가 실패하거나 일시 중지된 상태입니다. **로그** 탭에서 **오류** 또는 **동기화**를 선택하고 표시된 코드를 해결하세요. 예를 들어 매장에 연결할 수 없으면 [SYNC121](/error-codes/SYNC121)이 표시됩니다. 동기화가 복구되면 재고는 자동으로 최신 상태가 됩니다.
4. **사이트 관리자:** 여러 계산대나 온라인 쇼핑몰에서 같은 재고를 판매한다면 **WP Admin > POS > 설정 > 결제**에서 **초과 판매 방지**를 켜세요. 그러면 계산대의 수치가 오래되었더라도 매장에 있는 재고보다 많은 수량의 판매는 거부됩니다. 이 검사는 계산대가 온라인인 상태에서 결제할 때 이루어집니다. 오프라인에서 완료한 판매는 나중에 동기화될 때 확실하게 검사되지 않으므로, 오프라인에서 재고가 적은 상품을 판매하기 전에 재고를 직접 확인하세요(1단계).
