## 이 오류의 의미 {#what-this-means}

WCPOS가 매장의 연결 지점에 접근할 수 없습니다.

사이트 관리자에게 WCPOS 플러그인이 활성화되어 있는지(**WP Admin → 플러그인**), 보안 플러그인이 REST API를 차단하고 있지 않은지 확인하도록 요청하세요.

## 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 사이트 관리자에게 알리세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔 안내: 사이트 관리자에게 알리세요. 이 기기의 데이터에는 영향이 없습니다.

**매장 사이트에서** — 사이트 관리자 안내:

1. WP Admin → 플러그인에서 WCPOS가 활성화되어 있는지 확인하세요.
2. 두 REST 주소 형식 모두 작동하지 않는다면 보안 플러그인, 프록시 또는 CDN이 WCPOS 요청 헤더를 제거하거나 REST 요청을 차단하는지 확인하세요. 보통 방화벽 규칙이나 REST API를 비활성화하는 보안 강화 옵션이 원인입니다.
3. 일부 호스팅에서는 고유주소를 다시 저장하면(설정 → 고유주소 → 변경사항 저장) 누락된 REST 경로가 복원됩니다.
