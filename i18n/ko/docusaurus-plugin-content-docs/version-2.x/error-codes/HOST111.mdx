## 오류의 의미 {#what-this-means}

서버의 교차 출처(CORS) 설정에 문제가 있어 브라우저가 응답을 거부합니다.

매장은 응답하지만 CORS 응답 헤더가 중복되거나 잘못된 출처로 설정되어 있거나 오류 응답에서 누락되어 있습니다. 이 경우 브라우저가 실제 응답을 웹 앱에 전달하지 않으므로 다른 모든 오류도 일반적인 네트워크 오류로 가려집니다. 서버 측에서 모든 상태 코드의 응답에 Access-Control-Allow-Origin이 정확히 하나씩 포함되도록 수정해야 합니다.

## 데이터 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. CORS를 처리하는 계층이 두 곳인지(플러그인과 서버 설정이 모두 헤더를 추가하는지) 확인하고 하나를 제거하세요. Access-Control-Allow-Origin 중복은 브라우저에서 치명적인 오류를 일으킵니다.
2. nginx에서는 add_header 줄이 'always'로 끝나지 않으면 오류 응답에 적용되지 않습니다. 4xx/5xx 응답에도 CORS 헤더가 있어야 합니다.
3. CDN이나 프록시가 CORS 헤더를 추가한다면 WordPress 자체 헤더와 충돌하지 않는지 확인하세요.
4. 데스크톱 및 모바일 앱은 CORS를 사용하지 않으므로 이 문제를 수정하는 동안에도 계속 작동합니다.
