## 오류의 의미 {#what-this-means}

이 매장에서는 선택한 결제 게이트웨이를 사용할 수 없습니다.

사이트 관리자에게 해당 결제 게이트웨이가 지원되고 활성화되어 있으며 올바르게 설정되어 있는지 확인해 달라고 요청하세요.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**POS 기기에서:**

1. 문제를 해결하는 동안 현금 등 다른 수단으로 판매를 완료하세요.
2. 결제 패널의 **… 현재 사용할 수 없음** 아래에 해당 수단이 회색으로 표시된다면, 이 오류가 아니라 해당 POS 기기의 문제입니다. 표시된 사유(예: **연결 필요** 또는 **리더기를 사용하려면 Bluetooth를 켜세요**)를 통해 무엇을 해결해야 하는지 알 수 있습니다.

**매장 측 조치** — 사이트 관리자 안내:

3. **WP Admin > POS > 설정 > 결제**로 이동하세요. **결제 게이트웨이** 목록에 해당 게이트웨이가 있어야 하며 **활성화됨** 스위치가 켜져 있어야 합니다. 목록에 없으면 해당 플러그인이 설치되고 활성화되어 있는지 확인하세요. **WP Admin > WooCommerce > 설정 > 결제**에서는 켜져 있지 않아도 됩니다. POS는 활성 플러그인이 등록한 모든 게이트웨이를 표시합니다. WCPOS Free에서는 기본 제공되는 현금 및 카드 결제 수단만 활성화할 수 있으며, 다른 WooCommerce 결제 게이트웨이를 사용하려면 WCPOS Pro가 필요합니다.
4. 어제까지 게이트웨이가 작동했다면 해당 게이트웨이나 WooCommerce가 업데이트되었는지 확인하세요. **WooCommerce → 상태 → 로그**에 게이트웨이 시작 오류가 기록되어 있을 수 있습니다.
5. 문제가 해결되면 POS 기기에서 앱을 다시 로드해 게이트웨이를 다시 인식하도록 하세요.
