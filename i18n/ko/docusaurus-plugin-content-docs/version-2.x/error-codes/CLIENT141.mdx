## 이 오류의 의미 {#what-this-means}

검색 결과 중 일부가 상품과 일치하지 않아 WCPOS가 해당 결과를 숨겼습니다.

검색 결과가 계속 잘못 표시되는 경우가 아니라면 별도 조치는 필요하지 않습니다. 그런 경우 WCPOS를 새로고침하세요.

검색 결과를 즉시 표시하기 위해 WCPOS는 상품, 고객, 주문 등 검색하는 목록의 로컬 검색 색인을 유지합니다. 자체 점검에서 입력한 검색어와 실제로 일치하지 않는 항목을 색인에서 발견했습니다. 일치하지 않는 결과는 즉시 숨겼습니다. 앱이 색인을 자동으로 다시 만들 수도 있지만 세션마다 목록별로 한 번만 시도하므로 색인 재생성이 보장되지는 않습니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았습니다. 이 문제는 이 기기에 이미 저장된 데이터에서 만들어진 로컬 검색 색인에만 해당합니다. 일치하지 않는 결과를 숨겨도 검색 결과 표시만 바뀌며, 실제 기록은 변경되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 검색 결과가 계속 잘못 표시되는 경우가 아니라면 별도 조치는 필요하지 않으며 판매를 정상적으로 계속할 수 있습니다. 확인하려면 로그 항목에 표시된 검색어(맥락에 검색어가 기록됨)로 다시 검색하고, 예상한 항목이 빠지지 않았으며 입력한 내용과 결과가 일치하는지 확인하세요.
2. 검색 결과가 계속 잘못 표시되거나 존재하는 것을 아는 상품, 고객 또는 주문이 검색되지 않으면 앱을 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요. 그러면 다음에 문제가 감지될 때 색인을 새로 만들도록 시도합니다.
3. 새로고침한 뒤에도 코드가 다시 나타나면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요. 로그 항목의 맥락에 영향을 받은 목록과 문제를 일으킨 검색어가 표시됩니다.
