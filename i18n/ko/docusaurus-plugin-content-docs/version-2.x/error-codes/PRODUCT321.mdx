## 오류의 의미 {#what-this-means}

이 바코드와 일치하는 상품이 여러 개입니다.

WCPOS에서 어느 상품인지 확실하게 선택할 수 없어 아무것도 추가하지 않았습니다. 상품을 이름으로 검색하고, 매장에서 상품마다 고유한 바코드를 지정해 중복을 해결하세요.

## 데이터 상태 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 매장 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. **계산대에서:** 스캔해도 아무것도 추가되지 않고 **일치하는 항목이 여러 개 있음** 알림이 표시됩니다. 스캔한 코드가 상품 검색창에 입력되어 같은 코드를 사용하는 상품들이 나열됩니다. 올바른 상품을 직접 추가하고 판매를 완료하세요.
2. 먼저 카테고리나 재고 필터를 해제하세요. 같은 검색에 적용되는 필터이므로 일치하는 상품 중 일부가 숨겨질 수 있습니다. 그런 다음 매장 관리자가 확인할 수 있도록 목록에 있는 모든 상품 이름을 적어 두세요.
3. **사이트 관리자:** WP Admin에서 해당 상품을 각각 열어 고유한 바코드를 지정하세요. **WP Admin > POS > 설정 > 일반 > 바코드 필드**에서 매장이 바코드에 사용하는 필드를 확인하세요(기본값은 상품의 GTIN인 `_global_unique_id`). SKU나 다른 바코드 필드의 중복 값도 일치할 수 있으므로 함께 확인하세요.
4. **다시 계산대에서:** **매장 상태 → 데이터베이스**를 열고 **상품** 행의 **⋮** 메뉴에서 **지금 변경 사항 확인**을 선택하세요. 일치한 상품 중 변형이 있다면 **변형** 행에서도 같은 작업을 하세요. 그런 다음 다시 스캔하면 상품이 바로 추가됩니다.
