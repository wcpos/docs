## 오류의 의미 {#what-this-means}

매장의 응답에 불필요한 텍스트가 섞여 있어 WCPOS가 이를 정리하려고 시도했습니다.

진행하던 작업이 완료되었는지 확인하세요. 정리가 항상 성공하는 것은 아닙니다. 불필요한 텍스트는 대개 플러그인이나 PHP 알림이 매장 응답에 추가 출력을 삽입하여 발생합니다. 자주 나타나면 사이트 관리자에게 사이트의 PHP 오류 로그에 경고가 있는지 확인해 달라고 요청하세요.

## 데이터 상태 {#your-data}

진행하던 작업이 완료되지 않았다면(문제 해결의 1단계 참고) 해당 요청에 대한 안내를 따르세요. 그 외에는 주문이나 상품 데이터에 영향이 없습니다. 자주 나타나면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. 진행하던 작업이 완료되었는지 확인하세요. 예를 들어 판매 내역이나 변경 사항이 이제 표시되는지 확인하세요. 완료되었다면 더 할 일은 없습니다. 완료되지 않았다면 다시 시도하고, 또 실패하면 표시되는 오류의 안내를 따르거나 지원팀에 문의하세요.
2. 원인은 사이트에 있습니다. 플러그인이나 테마가 REST 응답에 경고나 불필요한 출력을 삽입하고 있습니다. 사이트 관리자에게 오류 발생 시점의 사이트 로그에 PHP 알림이 있는지 확인해 달라고 요청하세요.
3. **사이트 관리자:** 브라우저 개발자 도구(Network 탭) 또는 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 응답 본문 원본을 볼 수 있습니다. JSON 바로 앞이나 뒤에 불필요한 출력이 표시됩니다.
4. **사이트 관리자:** 정리 기능은 가능한 범위에서만 동작합니다. 자주 나타나면 이 기능에 의존하지 말고 원인이 되는 플러그인을 수정하세요.
