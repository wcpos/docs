## 오류의 의미 {#what-this-means}

WCPOS가 단말기에서 결제가 이루어졌는지 확인하지 못했습니다.

다시 결제하기 전에 결제 단말기를 확인하고, 결과가 여전히 불확실하면 결제 서비스 제공업체에 문의하세요.

## 데이터에 미치는 영향 {#your-data}

결과를 확인하지 못했습니다. 다시 시도하기 전에 확인하세요. 문제가 계속되면 결제 서비스 제공업체에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 아직 카드를 다시 결제하지 마세요.
2. 단말기 자체 화면을 확인한 뒤 결제 서비스 제공업체의 대시보드를 확인하세요. 결제 여부를 판단하는 최종 기준은 제공업체의 기록입니다.
3. WP Admin 접근 권한이 있다면 WooCommerce → 주문을 확인하세요(또는 매장 소유자에게 요청하세요). 성공한 결제가 이미 기록되어 있을 수 있습니다.
4. 제공업체의 대시보드에서 결제 내역이 없음을 확인한 경우에만 다시 결제를 받으세요.
5. 결제가 대기 중이거나 불확실한 상태로 표시되면 조치를 취하기 전에 결제 서비스 제공업체에 문의하세요.
