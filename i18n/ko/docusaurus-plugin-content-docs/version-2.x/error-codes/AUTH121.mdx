## 이 오류의 의미 {#what-this-means}

로그인한 매장 계정이 이 계산대의 캐셔와 일치하지 않습니다.

캐셔마다 계산대 데이터가 별도로 보관되므로 다른 계정으로 작업하면 주문이 잘못된 계정에 기록될 수 있습니다. 로그아웃한 다음 캐셔 본인의 계정으로 로그인하세요.

## 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. POS가 각 캐셔의 데이터를 보호하기 위해 세션을 자동으로 로그아웃합니다. 계정 간에 주문 데이터가 섞이지 않습니다.
2. 캐셔 본인의 계정으로 다시 로그인하세요. 다른 계정으로 작업하면 주문이 잘못된 계정에 기록될 수 있습니다.
3. 여러 캐셔가 계산대를 공유한다면 인수인계 절차에 계정 전환을 포함하세요.
