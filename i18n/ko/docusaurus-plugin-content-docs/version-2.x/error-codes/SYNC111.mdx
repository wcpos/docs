## 오류의 의미 {#what-this-means}

이 기기에 저장된 일부 데이터가 손상되어 동기화할 수 없습니다.

**로그** 탭 상단의 **디버그 정보 복사**를 누르고 WCPOS 지원팀에 보내세요. WCPOS를 재설치하거나 로그아웃하거나 데이터를 삭제하지 마세요. 아직 매장에 전송되지 않은 변경 사항은 이 기기에만 있습니다.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 아직 매장에 전송되지 않은 판매 내역이 있을 수 있습니다. 앱을 재설치하거나 로그아웃해도 해당 내역이 삭제될 수 있습니다. 특정 유형의 데이터를 안전하게 다시 다운로드할 수 있는지는 지원팀에서 안내해 드립니다.

## 문제 해결 {#troubleshoot}

1. WCPOS가 계속 작동한다면 판매를 계속하세요. 재설치하거나 로그아웃하거나 데이터를 삭제하지 마세요.
2. **로그** 탭 상단에서 **디버그 정보 복사**를 누르고, 로그 항목이 나타났을 때 어떤 작업을 하고 있었는지와 함께 WCPOS 지원팀에 보내세요.
3. **매장 상태 → 데이터베이스**를 열고 **전송 대기 중인 변경 사항**이 몇 개 표시되는지, **"…개의 변경 사항이 서버에 전송되지 않았습니다"** 또는 **"…개의 변경 사항이 보류되었습니다"** 패널이 표시되는지 지원팀에 알려 주세요. 해당 변경 사항은 이 기기에만 있습니다.
4. 로그 항목에는 어떤 데이터가 손상되었는지 표시되지 않습니다. 지원팀은 전송 대기 중인 변경 사항이 없어지면 특정 유형의 데이터를 다시 다운로드하도록 요청할 수 있습니다(해당 행의 **⋮** 메뉴 → **삭제 후 다시 다운로드…**). 지원팀이 어떤 데이터인지 확인하기 전에는 실행하지 마세요. 잘못된 데이터를 삭제하거나 변경 사항이 대기 중일 때 삭제하면 매장에 전송되지 않은 판매 내역이 사라질 수 있습니다. 손상으로 인해 변경 사항을 전송할 수 없다면 지원팀이 먼저 복구합니다. 대기 중인 항목이 하나라도 있으면 절대로 다시 다운로드하지 마세요.
