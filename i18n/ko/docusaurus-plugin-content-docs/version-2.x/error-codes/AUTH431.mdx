## 오류의 의미 {#what-this-means}

매장의 REST API가 이 앱에서 사용할 수 있는 어떤 주소 형식에도 응답하지 않았습니다.

앱이 일반 주소(/wp-json/...)와 WordPress의 기본 대체 주소(/?rest_route=...)로 매장의 REST API에 접근을 시도했지만 둘 다 응답하지 않았습니다. 매장 웹사이트 자체는 작동 중일 수 있습니다. 이 문제는 REST API에 접근할 수 없는 것으로, 대개 보안 플러그인이 이를 숨기거나 방화벽 규칙이 차단할 때 발생합니다.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**매장 사이트에서** — 사이트 관리자 안내: 보안 플러그인(예: WP Hide)이 `/wp-json/`을 숨기거나 이름을 바꾼다면 WordPress의 기본 `/?rest_route=` 형식도 허용하세요. 앱이 자동으로 이 형식으로 재시도합니다.

**호스트 / 서버에서:**

1. 방화벽(WAF) 규칙에서 `wp-json` 또는 `rest_route`와 일치하는 항목이 있는지 확인하고 매장 자체의 REST API가 통과하도록 허용하세요.
2. 서버 앞에 유지보수 페이지나 봇 확인 절차가 있다면 REST 요청에 HTML 페이지가 반환될 수 있습니다. REST API에는 이 확인 절차를 적용하지 않도록 설정하세요.

**테스트 방법(누구나 가능):** `https://your-store.com/?rest_route=/`에서 403 페이지나 사이트 홈페이지가 아닌 JSON이 반환되어야 합니다.
