## 의미 {#what-this-means}

매장의 변경 목록 위치가 예상치 못하게 이동하여 WCPOS가 자동으로 다시 확인하고 있습니다. 손실된 데이터는 없습니다.

조치할 필요 없이 판매를 계속하세요. WCPOS가 매장의 변경 사항을 자동으로 다시 확인합니다. 가격이나 재고가 여전히 최신 상태가 아닌 것 같으면 **매장 상태 → 데이터베이스**에서 **지금 모두 확인**을 탭하세요.

## 데이터 상태 {#your-data}

손실된 데이터는 없으며, 이 기기의 데이터에도 위험이 없습니다. 재확인이 끝날 때까지 이 기기의 일부 가격이나 재고가 최신 상태가 아닐 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 판매를 계속하세요. 이 기기의 데이터는 손실되지 않았으며 재확인이 자동으로 실행됩니다. 로그 항목에 무엇이 이동했는지 표시될 수 있습니다. 예를 들어 매장의 일부 변경 사항을 건너뛰었거나 매장의 목록이 이전 위치로 돌아갔다는 내용입니다. 어느 경우든 모든 종류의 데이터에서 발생할 수 있습니다.
2. 가격이나 재고가 여전히 최신 상태가 아닌 것 같으면 **매장 상태 → 데이터베이스**를 열고 **지금 모두 확인**을 탭하세요.
3. 확인 후에도 레코드가 잘못된 것 같거나 이 코드가 계속 나타나면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요. 이 문제를 해결하려고 데이터를 지우지 마세요.
