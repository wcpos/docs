## 오류의 의미 {#what-this-means}

WCPOS가 이 기기의 저장소에 변경 사항을 기록하지 못했습니다.

기기의 저장 공간을 확보한 뒤 변경 사항이 표시되는지 확인하세요. 없다면 다시 입력하세요. 문제가 반복되면 지원팀에 문의하세요. 확인을 마칠 때까지 변경 내용을 메모해 두세요. 변경 사항이 기록되기 전에 WCPOS가 종료되면 해당 내용은 사라집니다. 이 기기의 데이터를 삭제하지 마세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 아직 매장에 전송되지 않은 판매 내역이 있을 수 있습니다. 실패한 변경 사항은 아직 어디에도 저장되지 않았을 수 있으므로, 화면에 표시되는지 확인할 때까지 메모를 보관하세요. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하여 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 변경한 레코드와 입력한 값을 메모하세요. 로그 항목에 레코드가 명시되어 있다면 해당 레코드의 변경 사항이 저장되지 않았을 수 있습니다. 사이트 및 자격 증명 쓰기 작업의 경우 실패한 작업과 오류만 표시될 수 있으므로, 이 정보도 메모하세요.
2. 사이트 데이터를 삭제하거나 앱을 초기화하거나 제거하지 마세요. 판매 내역처럼 아직 매장에 전송되지 않은 다른 변경 사항은 이 기기에만 있으며, 로컬 저장소를 지우면 영구적으로 삭제됩니다.
3. 다른 파일이나 앱을 삭제하여 기기의 저장 공간을 확보하세요. 디스크가 가득 찼거나 브라우저의 저장 용량 한도에 도달한 것이 로컬 쓰기 실패의 가장 흔한 원인입니다. 공간을 확보하려고 브라우저의 "인터넷 사용 기록 삭제"를 사용하지 마세요. WCPOS의 미전송 판매 내역도 삭제됩니다.
4. 레코드를 열어 변경 사항이 표시되는지 확인하세요. 없다면 다시 입력하고 저장하세요. 여전히 저장되지 않으면 WCPOS를 한 번 재시작한 뒤 다시 시도하세요.
5. 저장이 계속 실패하면 복구를 시도하기 전에 **로그** 탭에서 **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.
