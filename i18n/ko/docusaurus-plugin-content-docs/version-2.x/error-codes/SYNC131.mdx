## 오류의 의미 {#what-this-means}

매장에서 오류가 발생하여 이 요청을 완료하지 못했습니다.

매장에 연결되었지만 서버가 요청을 처리하지 못했습니다. POS가 아닌 웹사이트의 문제입니다. 작업을 다시 시도하세요. 문제가 계속되면 사이트 관리자에게 **WooCommerce → 상태 → 로그**를 확인해 달라고 요청하세요. 이 기기에서 손실된 데이터는 없습니다.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 없는 변경 사항이 있을 수 있습니다. 전송 중이던 변경 사항이 매장에 도달하지 않았을 수 있습니다. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하여 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**POS에서(캐셔):** 로그 항목을 펼쳐 상태, 엔드포인트, serverCode를 메모하세요. 서버가 실패했을 때 수행하던 작업을 알 수 있습니다.

**웹사이트에서(사이트 관리자 / 호스팅 업체):**

1. 사이트에서 WooCommerce → 상태 → 로그를 열고 오류 발생 시점 부근의 최신 fatal-errors 로그를 확인하세요. 500 계열 응답은 거의 항상 여기에 PHP 오류를 남깁니다.
2. 사이트의 플러그인, 테마 또는 PHP를 업데이트한 뒤 오류가 발생하기 시작했다면 해당 변경을 먼저 의심하고 되돌리거나 비활성화하세요.
3. WooCommerce 로그에 아무것도 없다면 호스팅 업체에 같은 시간대의 서버 PHP 오류 로그를 요청하세요.

**그런 다음 POS로 돌아와서:** 작업을 다시 시도하세요.
