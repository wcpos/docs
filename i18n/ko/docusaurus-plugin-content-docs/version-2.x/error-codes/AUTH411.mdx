## 오류의 의미 {#what-this-means}

매장 주소가 없거나 유효한 URL이 아닙니다.

주소 필드가 비어 있거나, 매장에서 응답했지만 WCPOS 로그인 주소가 유효하지 않은 경우입니다. 후자는 계산대가 아니라 매장 사이트에서 해결해야 합니다.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. **WooCommerce 매장의 URL을 입력하세요**에 매장 주소(예: `shop.example.com`)를 입력하고 **연결**을 누르세요. 공백만 있는 필드는 비어 있는 것으로 간주됩니다.
2. 주소가 입력되어 있고 **"WCPOS 로그인 URL이 유효하지 않습니다. WCPOS 플러그인이 올바르게 구성되어 있는지 확인하세요"** 라는 메시지가 표시된다면 매장 사이트에 문제가 있습니다. **사이트 관리자:** **WP Admin → 플러그인**에서 WCPOS를 최신 버전으로 업데이트한 다음 **연결**을 다시 누르세요. 이 문제를 해결하려고 비활성화 후 다시 활성화하지 마세요. 다시 활성화하면 모든 역할의 POS 권한이 기본값으로 초기화됩니다.
3. **사이트 관리자:** 그래도 해결되지 않으면 브라우저에서 매장의 전체 주소 뒤에 `/wp-json/`을 붙여 여세요. 예를 들어 `https://your-store.com/wp-json/`을 사용하며, WordPress가 `/shop`에 있다면 `https://example.com/shop/wp-json/`을 사용합니다. 이 주소에서 404가 반환된다면(예: 일반 고유주소 사용 시) 대신 같은 주소 뒤에 `/?rest_route=/`을 붙여 사용하세요. `authentication` → `wcpos` → `endpoints` 아래의 `authorization`은 일반 웹 주소여야 합니다. 목록, 객체 또는 숫자로 되어 있다면 보안, 캐싱 또는 REST 사용자 정의 플러그인이 응답을 변경하고 있는 것입니다. 스테이징 사본에서 해당 플러그인을 하나씩 비활성화하여 원인을 찾으세요.
