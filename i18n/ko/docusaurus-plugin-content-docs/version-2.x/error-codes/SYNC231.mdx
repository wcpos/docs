## 의미 {#what-this-means}

매장에서 이 변경 사항을 받았지만, 이 기기에서 전송 사실을 기록하지 못했습니다.

조치할 필요가 없습니다. 다시 입력하지 마세요. WCPOS가 계속 재확인하며, 매장에서는 중복 전송을 무시합니다.

판매 또는 수정 내용은 매장에 도달하여 저장되었습니다. 이후 이 기기에서 변경 사항이 전송되었다는 사실을 세 번 연속 기록하려 했지만 실패했습니다. 따라서 이 기기에서는 여전히 전송되지 않은 변경 사항으로 표시되며, WCPOS가 다음 동기화 때 다시 전송합니다. 매장에서는 식별자로 변경 사항을 인식하고 중복 전송을 무시하므로 두 번 저장되지 않습니다. 실제로 주의할 점은 판매 또는 수정 내용을 사람이 직접 다시 입력하는 경우뿐입니다. 이렇게 하면 별도의 중복 데이터가 생성됩니다.

## 데이터 상태 {#your-data}

손실된 데이터는 없습니다. 매장에 이미 변경 사항이 있습니다. 이 기기에 재전송 사실이 기록될 때까지는 전송 대기 중인 항목으로 집계될 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 판매 또는 수정 내용을 직접 다시 입력하지 마세요. 매장에 이미 저장되어 있으므로 다시 입력하면 중복 데이터가 생성됩니다.
2. 판매가 매장에 도달했는지 확인하려면 WP Admin의 **WooCommerce → 주문**을 확인하세요. 이 기기에도 저장되어 있으므로 WCPOS에서도 표시됩니다.
3. WCPOS가 동기화하도록 두세요. 다음 재전송은 매장에서 무시되며, 보통 해당 항목이 해소됩니다. 그러면 **매장 상태 → 로그** 상단의 **전송 대기 중인 변경 사항** 수가 줄어듭니다.
4. 이 문제가 계속 표시되면 기기의 자체 저장 공간에 저장하는 데 문제가 있을 수 있습니다. 남은 저장 공간을 확인한 다음 **로그** 탭에서 **디버그 정보 복사**를 탭하고 지원팀에 문의하세요. 이 문제를 해결하려고 기기의 데이터를 지우지 마세요.
