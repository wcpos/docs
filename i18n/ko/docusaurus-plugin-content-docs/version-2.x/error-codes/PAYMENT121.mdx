## 오류의 의미 {#what-this-means}

단말기가 결제를 받았고 매장에서 금액을 보유하고 있습니다. 이후 주문을 완료하는 단계가 실패했기 때문에, 판매 대금은 결제되었지만 주문은 미완료 상태로 남아 있습니다.

결제 문제는 아니며, 카드를 다시 결제하면 금액이 두 번 청구됩니다. 주문을 완료하기만 하면 됩니다.

## 데이터에 미치는 영향 {#your-data}

금액이 이체되었습니다. 카드 결제가 이루어졌으며 매장에서 결제 금액을 보유하고 있습니다. 주문이 미완료 상태이므로 결제가 아니라 완료 처리가 필요합니다.

## 문제 해결 {#troubleshoot}

**POS 기기에서** — 고객이 떠나기 전에 다음을 수행하세요:

1. 결제를 다시 받지 말고, 결제 패널의 닫기 버튼(**X**)도 사용하지 마세요. 결제가 있는 주문을 닫으면 **결제 취소**가 열리며, 이 기능은 결제를 되돌립니다.
2. 앱을 다시 로드하세요(웹에서는 브라우저 탭을 다시 로드하고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요). POS 기기는 시작할 때 카드 결제가 기록된 판매의 완료 처리를 다시 시도하며, 완료된 주문은 장바구니에서 사라집니다.
3. 다시 로드한 뒤에도 주문이 장바구니에 미완료 상태로 남아 있으면 **매장 상태 → 데이터베이스**를 열고 **주문** 행의 **⋮** 메뉴에서 **지금 변경 사항 확인**을 선택한 뒤 한 번 더 다시 로드하세요.
4. 여전히 미완료 상태라면 결제는 이미 받았으므로 고객 응대를 마치고 주문은 그대로 두세요. 매장 관리자에게 주문 완료 처리를 요청하세요(아래 참고).

**매장 측 조치** — 사이트 관리자 안내:

1. POS 기기에서 주문이 계속 완료되지 않으면 **WooCommerce → 주문**에서 해당 주문을 열고 결제 서비스 제공업체의 대시보드에서 결제 내역을 확인하세요. 분할 결제한 판매라면 모든 부분이 결제되었는지 확인하세요. 그런 다음 해당 결제 방식의 판매에 POS가 사용하는 상태로 주문을 설정하세요. **WP Admin > POS > 설정 > 결제**의 **결제 게이트웨이** 표에서 결제를 받은 게이트웨이 행의 **주문 상태** 열에 해당 상태가 표시됩니다.
2. 원인을 알아보려면 POS 기기의 알림에서 **지원 세부 정보**를 펼치거나 **매장 상태 → 로그**의 해당 항목을 펼치세요. 완료 단계에서 어떤 작업이 실패했는지 표시됩니다. 대개는 바로 그 순간 연결이 끊긴 것이 원인입니다. 지원팀에 문의할 때 이 정보를 포함하세요.
