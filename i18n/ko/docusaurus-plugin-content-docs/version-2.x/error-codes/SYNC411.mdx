## 의미 {#what-this-means}

이 기기에서 매장에 평소보다 훨씬 자주 데이터를 요청했습니다.

조치할 필요가 없으며 손실된 데이터도 없습니다. 느려지거나 차단된 것은 없으며, 감지 사실만 알리는 경고입니다. 요청 폭주가 지속되면 보통 사용자의 조작이 아니라 앱 문제(화면에서 같은 데이터를 반복적으로 다시 요청하는 현상)를 뜻합니다. 계속 나타나면 반복 요청의 원인을 찾아 수정할 수 있도록 **디버그 정보 복사**를 탭하고 WCPOS 지원팀에 보내세요.

## 데이터 상태 {#your-data}

손실된 데이터는 없으며 주문이나 상품 데이터에도 영향이 없습니다. 이 문제가 지속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 작업을 계속하세요. 감지 사실만 알리는 경고입니다. WCPOS는 요청을 늦추거나 대기시키거나 버리지 않으며, 주문이나 상품 데이터에도 영향이 없습니다.
2. 코드가 한 번 나타난 뒤 멈추면 조치할 필요가 없습니다. 반복되면 코드가 나타났을 때 어떤 화면이 열려 있었고 어떤 작업을 하고 있었는지 기록하세요.
3. 해당 이벤트가 로그 창에 남아 있을 때 디버그 정보 복사를 사용하고 WCPOS 지원팀에 문의하세요. 내보낸 정보를 통해 지원팀이 반복 요청을 추적할 수 있습니다.
