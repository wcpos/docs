## 오류의 의미 {#what-this-means}

이 변경 사항은 아직 매장으로 전송 중입니다.

별도 조치는 필요하지 않으며 다시 입력하지 마세요. 자동으로 전송되고 매장에서 확인하면 표시됩니다.

판매 내역이나 변경 사항이 이 기기에 저장되어 전송되었지만, 매장에서 평소 대기 시간 내에 확인하지 않았습니다. 대개 매장의 응답이 느리거나 연결이 불안정하기 때문입니다. WCPOS는 매장에서 확인할 때까지 계속 전송합니다. 매장은 이미 받은 변경 사항을 인식하므로 같은 버튼을 다시 눌러도 안전합니다. 하지만 판매 내역이나 레코드를 직접 다시 입력하면 안 됩니다. 별도의 항목이 하나 더 생성되어 중복됩니다.

## 데이터 상태 {#your-data}

손실된 데이터는 없습니다. 변경 사항은 이 기기에서 대기 중이며 자동으로 전송됩니다. 전송 대기 중에는 이 기기의 데이터를 삭제하지 마세요.

## 문제 해결 {#troubleshoot}

1. 판매 내역이나 변경 사항을 직접 다시 입력하지 마세요. 중복 항목이 생성됩니다.
2. 매장에 전송될 때까지 기다리세요. 판매 내역은 이 기기에 저장되어 있으므로 WCPOS에 이미 표시됩니다(장바구니 또는 WCPOS Pro의 **주문**). 매장에 전송되었는지 확인하려면 WP Admin의 **WooCommerce → 주문**을 확인하세요.
3. 전송 상태를 보려면 **매장 상태 → 로그**를 여세요. 변경 사항이 전송될수록 헤더의 **전송 대기 중인 변경 사항** 수가 줄어들고, 더 이상 대기 중인 항목이 없으면 0으로 표시됩니다.
4. 오랫동안 대기 상태가 유지되면 이 기기의 연결 상태와 매장 웹사이트가 열리는지 확인하세요. [SYNC121](/error-codes/SYNC121)을 참고하세요.
5. 연결이 정상인데도 여전히 표시되지 않으면 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 문의하세요.
