## 오류의 의미 {#what-this-means}

로그인하거나 로그인 상태를 유지하는 중에 예기치 않은 문제가 발생했습니다.

작업을 한 번 더 시도하세요. 반복되면 로그아웃한 후 다시 로그인하고, **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 **디버그 정보 복사**를 사용하여 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 작업을 한 번 더 시도하세요. 다시 실패하면 로그아웃한 후 다시 로그인하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 serverCode가 있다면 함께 기록하세요. 999 코드는 원인에 대한 전용 코드가 아직 없다는 뜻이며, 이러한 추가 정보로 원인을 파악할 수 있습니다.
3. 문제가 다시 발생하면 디버그 정보 복사를 사용하여 지원팀에 문의하세요.
