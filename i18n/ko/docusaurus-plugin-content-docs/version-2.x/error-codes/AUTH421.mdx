## 오류의 의미 {#what-this-means}

매장 서버가 이 앱에서 사용할 수 있는 모든 전달 경로에서 로그인 토큰을 차단하고 있습니다.

앱에서 매장에 접근할 수 있음은 확인했지만, 서버(또는 그 앞에 있는 방화벽, 프록시, 보안 플러그인)가 Authorization 헤더를 제거하고 URL 매개변수로 전송한 토큰도 차단합니다. 로그인 토큰을 전달할 다른 방법이 없으므로 서버에서 해결해야 합니다.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**호스팅 업체 / 서버 담당자 안내** — 서버에서 통과를 허용하기 전까지는 로그인 토큰을 전달할 경로가 없습니다:

1. Authorization 헤더가 WordPress에 전달되도록 허용하세요. Apache에서는 대개 `SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1` 한 줄이면 됩니다.
2. 사이트에서 `.htaccess` 재작성 규칙을 사용한다면 WordPress가 생성한 RewriteRule 중 `HTTP_AUTHORIZATION`을 전달하는 줄을 유지하세요. 보안 플러그인이 이 줄을 제거하는 경우가 있습니다.
3. 프록시나 CDN 뒤에 있다면 해당 헤더 허용 목록을 확인하세요. Authorization 요청 헤더가 원본 서버로 전달되어야 합니다.
4. 웹 애플리케이션 방화벽(WAF)이 URL 매개변수를 필터링한다면 `/wcpos/` REST 경로에서 authorization 매개변수를 허용하세요.
