# 오류 코드 {#error-codes}

WCPOS는 문제가 발생하면 원인을 파악하는 데 도움이 되는 오류 코드를 표시합니다. **v1.10.0**부터 코드는 **영역 + 세 자리 숫자** 형식을 따릅니다. 예를 들면 `SYNC131` 또는 `AUTH311`입니다. 영역은 POS의 어느 부분에서 문제가 발생했는지 나타내고, 숫자는 구체적인 상황을 식별합니다. 각 코드에는 의미, 해결 방법, 데이터에 미치는 영향을 설명하는 개별 페이지가 있습니다.

POS에서 오류 코드는 **매장 상태 → 로그**에 표시됩니다. 행을 펼친 다음 **도움말** 링크를 사용하면 여기 있는 해당 코드의 페이지로 바로 이동할 수 있습니다.

## 오류 영역 (v1.10.0+) {#error-domains}

| 영역 | 분야 |
|--------|------|
| [`AUTH`](#auth) | 로그인, 세션 및 토큰 |
| [`CHECKOUT`](#checkout) | 계산대에서 주문 완료 |
| [`CLIENT`](#client) | POS 앱 자체 및 로컬 저장소 |
| [`DISPLAY`](#display) | 고객용 디스플레이 |
| [`HOST`](#host) | POS를 차단하는 호스팅 및 방화벽 규칙 |
| [`LICENSE`](#license) | Pro 라이선스 활성화 및 유효성 검사 |
| [`PAYMENT`](#payment) | 결제 게이트웨이 및 단말기 |
| [`PRINT`](#print) | 영수증 인쇄 |
| [`PRODUCT`](#product) | 상품 데이터 및 카탈로그 작업 |
| [`REGISTER`](#register) | 현금 서랍, 계산대 세션 및 시재 확인 |
| [`SYNC`](#sync) | POS와 매장 간 동기화 |

아래에서 해당 코드를 찾거나 검색하세요.

`999`로 끝나는 코드는 아직 전용 코드가 없는 상황에 사용하는 해당 영역의 공통 코드입니다.
