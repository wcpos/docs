## 오류의 의미 {#what-this-means}

WCPOS에서 인쇄 작업의 완료 여부를 확인하지 못했습니다.

영수증이 두 번 인쇄되지 않도록 재시도 전에 프린터를 확인하세요.

## 데이터 상태 {#your-data}

판매 및 주문 데이터는 안전하며 변경되지 않았습니다. 인쇄 결과만 확인되지 않은 상태입니다.

## 문제 해결 {#troubleshoot}

1. 재시도 전에 프린터를 살펴보세요. 완료 응답이 오지 않았더라도 이미 인쇄되었을 수 있으며, 확인 없이 재시도하면 영수증이 두 번 인쇄됩니다.
2. 프린터의 용지, 덮개, 오류 표시등을 확인하세요.
3. 아무것도 인쇄되지 않았다면 한 번 재시도하세요. 판매 후 표시되는 영수증에서 **영수증 인쇄**(또는 **다시 인쇄**)를 누르세요. 영수증 화면을 이미 나갔다면 WCPOS Pro에서 **주문**을 열고 해당 주문의 **영수증** 작업을 선택한 다음 **영수증 인쇄**를 누르세요. Pro가 없으면 영수증 화면을 나간 후 다시 열 수 없습니다.
4. 계속 실패하면 프린터의 전원을 껐다 켜고 계산대와의 연결을 확인하세요.
