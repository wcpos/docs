## 오류의 의미 {#what-this-means}

이 기기의 시계와 매장의 시계가 일 분 넘게 차이 납니다.

이 기기의 날짜와 시간이 자동으로 업데이트되도록 설정하세요. 이미 자동 업데이트가 설정되어 있다면 사이트 관리자에게 서버 시계를 확인해 달라고 요청하세요.

WCPOS는 이 기기의 시계와 매장 서버가 응답에 포함하여 보내는 시간을 비교합니다. 둘 사이에 일 분 넘게 차이가 나면 두 시계가 일치할 때까지 주문 시간, 영수증, 보고서의 시간이 부정확할 수 있습니다.

## 데이터 영향 {#your-data}

판매는 계속 저장됩니다. 다만 두 시계가 일치하지 않는 동안 판매에 기록되는 시간이 부정확할 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼치세요. 두 시계의 차이와 어느 쪽이 앞서는지 표시됩니다.
2. 기기의 날짜 및 시간 설정을 열고 시간과 시간대의 자동(네트워크) 설정을 켜세요.
3. **사이트 관리자:** 기기에 이미 자동 업데이트가 설정되어 있고 시간이 정확하다면 서버의 시계가 잘못된 것입니다. 호스팅 업체에 서버의 날짜, 시간, 시간대를 확인해 달라고 요청하세요.
4. 수정 후 WCPOS를 다시 여세요. 매장을 열 때마다 두 시계를 다시 비교하며, 일치하면 경고가 더 이상 표시되지 않습니다.
