## 이 오류의 의미 {#what-this-means}

세션이 종료되어 다시 로그인해야 합니다.

다시 로그인하세요. 손실된 데이터는 없습니다. 전송되지 않은 변경 사항은 로그인하면 전송됩니다.

## 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 세션이 종료된 동안 저장한 판매 내역은 손실되지 않고 기기에 보관되며, 로그인하면 자동으로 매장에 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 다시 로그인하세요. WCPOS가 WordPress 로그인 창을 자동으로 엽니다. 창을 닫았다면 WCPOS가 다시 로그인을 요청합니다. 같은 캐셔 계정으로 로그인하세요.
2. 다시 입력하거나 저장할 필요는 없습니다. 대기 중이던 판매 내역은 다시 로그인하면 자동으로 전송됩니다. 전송 상태를 확인하려면 **매장 상태 → 데이터베이스**를 여세요. **전송 대기 중인 변경 사항** 수가 0으로 줄어듭니다.
3. 판매 내역이 **"… 변경 사항이 서버에 도달하지 않음"** 아래에 표시된다면 해당 행의 **다시 보내기**를 탭하세요.
4. 세션이 자주 만료된다면(하루에 여러 번) 보통 사이트가 원인입니다. 보안 플러그인이 세션 유효 시간을 줄이거나 토큰을 지우는 경우가 있습니다. 사이트 관리자에게 매장에서 실행 중인 보안 플러그인을 확인하고 **WP Admin > POS > 설정 > 도구 > 로그**를 살펴보도록 요청하세요. 거부된 로그인과 그 사유가 기록되어 있습니다.
