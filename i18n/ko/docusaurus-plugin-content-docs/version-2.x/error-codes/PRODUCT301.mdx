## 오류의 의미 {#what-this-means}

스캔하거나 검색어를 입력했지만 일치하는 상품을 찾지 못했습니다.

주로 필터가 적용되어 있거나, 바코드가 누락되었거나 다른 필드에 저장되어 있거나, 최초 동기화가 아직 완료되지 않았을 때 발생합니다.

## 데이터 상태 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**계산대에서:**

1. 먼저 필터를 해제하세요. 카테고리나 재고 필터는 별도 알림 없이 모든 검색의 범위를 좁힙니다(스캔한 코드도 같은 검색창에 입력됩니다).
2. 상품을 이름으로 검색하세요. 이름으로는 나오지만 스캔으로 찾지 못했다면 매장에 저장된 바코드가 스캔한 값과 다른 것입니다. 검색어를 직접 입력했다면 철자와 불필요한 공백을 확인하세요.
3. 새로 등록한 상품이라면 로컬 색인이 아직 동기화 중일 수 있습니다. 최초 동기화가 완료될 때까지 기다린 뒤 다시 시도하세요.

**매장에서:**

- 바코드가 없다면 WP Admin에서 **바코드 필드**(아래 참조)에 지정된 필드에 스캔한 값을 추가하세요. 변형(크기, 색상)이 있는 상품은 상위 상품이 아니라 해당 변형 자체에 입력하세요. 상품을 편집하고 해당 변형을 펼치면 됩니다.
- 모든 스캔에서 상품을 찾지 못하면 매장이 잘못된 필드를 조회하고 있을 수 있습니다. **WP Admin > POS > 설정 > 일반 > 바코드 필드**를 확인하세요. 상품의 바코드가 실제로 저장된 필드가 지정되어 있어야 합니다(예: GTIN의 `_global_unique_id`, `_sku` 또는 `_barcode`).
