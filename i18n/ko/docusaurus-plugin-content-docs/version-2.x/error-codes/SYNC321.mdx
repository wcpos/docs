## 의미 {#what-this-means}

이번에는 일부 데이터가 동기화되지 않았습니다.

이 코드는 두 가지 형태로 나타나며, 로그 행의 제목에서 어느 경우인지 알 수 있습니다:

- **"일부만 동기화됨"** (레코드 제목): 일부 레코드는 동기화되었지만 이름이 표시된 레코드는 동기화되지 않았습니다. 다음 동기화에서 해소되면 조치할 필요가 없습니다. **매장 상태 → 데이터베이스**에 주의가 필요한 변경 사항이 나열되어 있으면 그곳에서 해결하세요.
- **"멈춘 데이터 요청 포기"**: 동기화 엔진의 데이터 요청 처리 경로에서 한 요청이 진행되지 않아, 앱이 충분히 기다린 뒤 해당 요청을 포기했습니다. 뒤에 대기 중인 모든 요청이 막히는 것을 방지하기 위한 처리입니다. 동기화 엔진이 자동으로 요청을 다시 보내므로 직접 재시도할 필요가 없습니다. 로컬 데이터베이스 호출이 멈춘 뒤 발생하는 경우가 많으며, 해당 호출은 [SYNC181](/error-codes/SYNC181)로 별도 기록됩니다.

## 데이터 상태 {#your-data}

이 기기의 데이터를 지우지 마세요. 아직 매장에 없는 변경 사항이 있을 수 있습니다. 데이터 요청을 포기한 경우에는 변경된 것이 없으며, 포기한 요청은 자동으로 다시 전송됩니다. 이 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. **"멈춘 데이터 요청 포기"** 항목은 화면이 계속 멈춰 있지 않다면 조치할 필요가 없습니다. 화면이 멈춰 있으면 앱을 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요.
2. 일부만 동기화된 경우 다음 동기화에서 해소되면 조치할 필요가 없습니다. 해결되지 않으면 **매장 상태 → 데이터베이스**를 여세요. 아직 동기화되지 않은 레코드가 상단에 표시됩니다. **"…개 레코드에 주의가 필요합니다"** 안내에는 첫 번째 레코드와 이유가 표시되며, 이를 해결하면 다음 레코드가 표시됩니다. **"…개 변경 사항이 서버에 도달하지 못했습니다"** 및 **"…개 변경 사항이 보류되었습니다"** 패널에는 각각 해당 레코드가 나열됩니다. 동기화된 레코드는 조치할 필요가 없습니다.
3. 나열된 각 레코드를 해당 이유에 따라 해결하세요. 안내에 **레코드 수정**이 표시되면 이를 눌러 레코드를 열고 수정할 수 있습니다. 거부된 변경 사항은 레코드 자체에서 수정하세요([SYNC201](/error-codes/SYNC201)). 보류된 변경 사항은 유지할 버전을 선택하세요([SYNC221](/error-codes/SYNC221)).
4. 그런 다음 다시 전송하세요. 안내의 **재시도**를 누르면 동기화가 실행되며, 패널에서는 해당 레코드 행의 **다시 보내기**를 누르세요. 안내에 *매장에서 다운로드할 수 없음*으로 표시된 레코드에는 **재시도**가 없습니다. [SYNC331](/error-codes/SYNC331)을 참고하세요.
5. 레코드가 여전히 동기화되지 않으면 **로그** 탭에서 **디버그 정보 복사**를 사용하고 지원팀에 문의하세요.
