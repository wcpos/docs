## 오류의 의미 {#what-this-means}

두 기기에서 같은 계산대를 개시했습니다. 매장은 이미 열려 있던 세션을 유지하며, 이 기기도 해당 세션으로 전환되었습니다.

이제 두 POS 단말기는 같은 현금 서랍의 금액을 집계합니다. 이 기기에 표시되는 개시 준비금과 캐셔는 여기서 입력한 값이 아니라 다른 기기의 값입니다.

## 데이터 상태 {#your-data}

손실된 데이터는 없지만, 이 기기에서 시작한 세션은 더 이상 사용하지 않고 매장에 이미 있던 세션을 사용합니다. 전환 전에 여기서 기록한 내용은 모두 이전 세션에 속하며, 현재 표시되는 서랍 합계에는 포함되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 계산대 패널에서 개시 준비금과 캐셔 이름을 확인하세요. 입력한 값과 다르다면 다른 기기의 세션을 사용 중입니다.
2. 하나의 현금 서랍을 사용하는 경우 두 기기가 하나의 계산대를 공유하는 것이 정상적인 구성입니다. 무료 플러그인에서는 모든 기기가 하나의 계산대를 공유합니다. 두 기기의 판매가 같은 서랍에 집계되고 현금은 한 번만 계산하므로, 근무가 끝나기 전에 누가 현금을 계산하고 마감할지 정하세요. 실제로 각 기기에 별도의 현금 서랍이 있다면 두 번째 카운터에 전용 계산대를 할당하세요(WCPOS Pro). [매장, 계산대 및 기기](../stores/registers-and-devices.mdx)를 참고하세요.
3. 전환 전에 이 기기에서 입금이나 출금을 기록했다면 해당 내역은 더 이상 사용하지 않는 세션에 남아 있습니다. 현재 사용 중인 세션에 다시 기록하세요.
4. **매장 관리자:** 계산대 세션이 반복해서 다른 세션으로 전환된다면 두 기기가 해당 계산대를 사용하고 있다는 뜻입니다. 하나의 서랍을 공유한다면 정상적인 동작입니다. WCPOS Pro에서 카운터마다 별도의 서랍이 있다면 매장 편집 화면에서 두 번째 카운터용 계산대를 추가하고, 해당 기기에서 **계산대 전환**으로 선택하세요.
