## 이 오류의 의미 {#what-this-means}

검색 색인이 제때 응답하지 않아 WCPOS가 대신 상품 목록을 직접 검색했습니다.

로컬 검색 색인이 아직 생성 중이거나 응답할 수 없는 상태였습니다. 웹에서는 POS 탭이 백그라운드에 있었기 때문인 경우가 많습니다. 데스크톱과 모바일에서는 대량 동기화 직후 또는 앱을 다시 시작한 뒤 저장된 색인을 불러오는 동안 주로 발생합니다. 이 기기의 데이터를 직접 검색하므로 검색 결과는 계속 표시되며, 색인이 응답하면 자동으로 색인을 다시 사용합니다.

## 데이터 {#your-data}

매장 데이터는 변경되지 않았고 검색에도 응답했습니다. 색인 대신 이 기기의 데이터를 직접 검색해 결과를 표시했습니다. 색인이 다시 사용될 때까지 검색 결과가 조금 느리게 표시될 수 있습니다.

## 문제 해결 {#troubleshoot}

1. 대개 별도 조치는 필요하지 않습니다. 검색은 계속 작동하며 색인이 응답하면 자동으로 다시 사용됩니다.
2. 웹에서는 POS를 백그라운드 탭이 아닌 별도 창에서 열어 두세요.
3. 검색이 계속 느리거나 이 코드가 반복해서 나타나면 앱을 한 번 새로고침하세요. 웹에서는 브라우저 탭을 새로고침하고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요.
4. 그 후에도 코드가 다시 나타나면 디버그 정보를 내보내고 지원팀에 문의하세요.
