## 오류의 의미 {#what-this-means}

호스팅 업체의 보안 필터가 상품 검색을 차단하고 있습니다.

이 호스트의 방화벽 규칙은 쿼리 문자열에 ASCII 이외의 문자나 SQL처럼 보이는 단어가 포함된 REST 요청을 거부합니다. 악센트가 있는 상품명이나 'select', 'union' 같은 단어가 포함된 검색은 일반적인 상품 목록 검색인데도 403 오류로 실패합니다. POS의 다른 기능은 정상 작동하지만, 해당 규칙을 완화하기 전까지 검색은 불안정합니다.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 쿼리 문자열 방화벽 규칙에서 매장 자체의 REST 검색 매개변수(/wcpos/ 및 /wc/ 경로)를 허용 목록에 추가해 달라고 호스팅 업체에 요청하세요.
2. OWASP CRS 기반 방화벽에서는 대개 's' 및 'search' 인수에 적용되는 SQL 삽입 방지 규칙이 원인입니다. REST API 경로에서는 이 인수들을 해당 규칙에서 제외하세요.
3. '의심스러운 쿼리 문자열 필터링' 전환 옵션이 있는 보안 플러그인은 전체 기능을 끄는 대신 REST API에 대한 예외를 설정해야 합니다.
