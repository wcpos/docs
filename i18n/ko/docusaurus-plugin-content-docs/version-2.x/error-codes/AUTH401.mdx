## 이 오류의 의미 {#what-this-means}

이 매장과의 보안 연결을 신뢰할 수 없습니다.

올바른 매장 주소를 사용하고, 다시 연결하기 전에 사이트 관리자에게 인증서 문제를 해결하도록 요청하세요.

## 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. 같은 기기의 브라우저에서 매장 주소를 여세요. 브라우저의 자물쇠 아이콘이나 경고 페이지에서 인증서의 정확한 문제(만료, 자체 서명 또는 다른 도메인용으로 발급됨)를 확인할 수 있습니다.
2. POS에서 사용하는 주소를 확인하세요. https:// 뒤의 도메인이 인증서에 명시된 도메인과 정확히 일치해야 합니다. www 포함 여부도 중요합니다.
3. 사이트 관리자나 호스팅 업체에 인증서를 갱신하거나 문제를 해결하도록 요청하세요. 자동 갱신이 아무런 알림 없이 실패한 경우가 가장 흔한 원인입니다.
4. 인증서 경고를 피하려고 보안 기능을 끄지 마세요. 인증서 문제를 해결하세요.
