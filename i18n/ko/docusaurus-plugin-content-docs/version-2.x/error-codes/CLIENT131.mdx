## 이 오류의 의미 {#what-this-means}

WCPOS가 한 번에 너무 많은 요청을 대기열에 넣어 일부 요청을 버렸습니다.

매장 문제보다는 앱 결함일 가능성이 높습니다. WCPOS를 다시 시작하세요. 코드가 다시 나타나면 진단 정보를 내보내고 지원팀에 문의하세요.

## 데이터 {#your-data}

이미 완료된 요청은 안전합니다. 버려진 요청은 실행되지 않은 것이므로, 진행 중이던 작업이 실제로 완료되었는지 확인한 다음 계속하세요.

## 문제 해결 {#troubleshoot}

1. 몇 초간 기다리세요. 대기열은 저절로 처리되고 오래된 요청은 자동으로 버려집니다. 진행 중이던 작업이 완료되었는지 확인하고, 완료되지 않은 경우에만 다시 시도하세요.
2. 같은 세션에서 다시 발생하면 WCPOS를 다시 시작하세요. 다시 시작하면 대기열이 비워집니다.
3. 매장 문제보다는 앱 결함일 가능성이 높습니다. 계속 다시 나타나면 디버그 정보를 내보내고 지원팀에 문의하세요. 로그 항목의 맥락을 통해 개발자가 대기열을 가득 채운 요청을 확인할 수 있습니다.
