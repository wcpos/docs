## 오류의 의미 {#what-this-means}

WCPOS가 이 기기의 저장소를 설정하거나 제거하지 못했습니다.

기기의 저장 공간을 확보한 뒤 WCPOS를 재시작하세요. 웹에서는 브라우저가 사이트의 저장소 사용을 제한하고 있을 수도 있습니다. 비공개 창에서는 이런 제한이 적용됩니다. 계속 실패하면 지원팀에 문의하세요.

## 데이터 상태 {#your-data}

변경 사항이 거부된 것이 아니라 저장소 문제입니다. 이 기기의 데이터를 삭제하던 중 발생했다면 아직 전송하지 않은 변경 사항을 포함하여 일부 데이터가 이미 삭제되었을 수 있습니다. 최근 판매 내역과 변경 사항이 매장에 표시되는지 확인하세요. 문제가 계속되면 **로그** 탭에서 **디버그 정보 복사**를 사용하여 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 기기의 남은 저장 공간을 확인하고 다른 파일이나 앱을 삭제하여 공간을 확보하세요. 디스크나 브라우저의 저장 용량이 가득 차면 저장소 설정이 실패합니다. 공간을 확보하려고 브라우저의 "인터넷 사용 기록 삭제"를 사용하지 마세요. WCPOS의 미전송 판매 내역도 삭제됩니다.
2. WCPOS를 재시작하고 같은 작업을 다시 시도하세요.
3. 웹에서는 브라우저가 사이트의 영구 저장소 사용을 허용하는지 확인하세요. 비공개 창과 모든 데이터 차단 설정에서는 허용되지 않습니다.
4. 계속 실패하면 **로그** 탭에서 **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.
