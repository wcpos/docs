## 오류의 의미 {#what-this-means}

입금, 출금 또는 판매 없는 서랍 열기를 기록했습니다. 계산대에서는 수락했고 현금도 실제로 이동했지만 매장에서 저장을 거부했습니다.

이동 내역은 이 기기에 남아 있습니다. 매장에는 없으므로 매장에서 보고하는 예상 현금 서랍 총액에 포함되지 않으며, 해당 근무 시간의 계산대 보고서에도 나타나지 않습니다.

## 데이터 상태 {#your-data}

이동 내역은 이 기기에만 저장되어 있습니다. 매장으로 전송되었지만 거부되었으므로 나중에 전달될 대기 항목은 없습니다. 매장에서 수락할 때까지 현금 이동 기록은 이 기기에만 남아 있습니다.

## 문제 해결 {#troubleshoot}

1. 계산대 패널을 여세요. 거부된 이동 내역은 패널 상단에 **다시 시도** 버튼과 함께 표시됩니다. 먼저 재시도하세요. 대부분 입력한 내용의 문제가 아니라 권한이나 세션 문제로 거부됩니다.
2. 로그 항목에 필드 이름이 표시된다면 매장이 해당 필드를 거부한 것입니다. 유효한 금액과 사유를 입력해 이동 내역을 다시 기록하세요.
3. 계속 실패하면 현금을 집계하기 전에 금액, 유형, 사유를 적어 두세요. 매장의 예상 총액에는 이 이동 내역이 포함되지 않으므로 현금 서랍은 정확히 그 금액만큼 부족하거나(출금 후) 초과한(입금 후) 것으로 표시됩니다.
4. 모든 이동 내역이 거부되면 보통 캐셔 계정의 현금 관리 권한이 없어졌거나 다른 기기에서 계산대 세션이 종료된 경우입니다. WP Admin에서 두 가지를 모두 확인하세요.
5. 이동 내역이 정상적으로 처리되거나 별도로 적어 둘 때까지 계산대를 마감하지 마세요.
