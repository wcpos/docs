## 의미 {#what-this-means}

이 기기의 데이터가 다른 WCPOS 버전에서 저장되어 아직 열 수 없습니다.

WCPOS를 최신 버전으로 업데이트한 후 다시 여세요. 그래도 열리지 않으면 **디버그 정보 복사**를 탭하고 지원팀에 문의하세요. 이 문제는 보통 이 기기에서 앱을 업데이트하거나 이전 버전으로 내린 뒤 발생합니다.

:::warning 이 기기의 데이터를 지우지 마세요
이 기기에는 오프라인에서 처리한 판매처럼 아직 매장에 도달하지 않은 판매가 있을 수 있습니다. 데이터를 열 수 없는 동안에는 전송할 수도 없으므로 로컬 데이터베이스를 지우거나 로그아웃하거나 앱을 다시 설치하면 영구적으로 삭제됩니다. 무엇이든 지우기 전에 지원팀에 문의하세요.
:::

## 데이터 상태 {#your-data}

이 기기의 데이터를 지우지 마세요. 아직 매장에 도달하지 않은 판매가 있을 수 있습니다. 매장 자체의 데이터는 안전하며 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. 이 기기에서 WCPOS를 최신 버전으로 업데이트한 후 다시 여세요:
   - **웹:** 브라우저 탭을 새로고침하세요. 이전 버전이 다시 나타나면 **Shift**를 누른 상태로 새로고침하세요. 매장의 WCPOS 플러그인이 불러올 웹 버전을 결정하므로, 새로고침해도 해결되지 않으면 사이트 관리자에게 WCPOS 플러그인 업데이트를 요청하세요.
   - **데스크톱:** 대기 중인 업데이트를 설치하고 앱을 다시 여세요. 업데이트가 표시되지 않으면 [설치](/getting-started/installation) 페이지에서 최신 빌드를 다운로드하세요.
   - **iPhone, iPad 또는 Android:** 처음 설치한 경로를 통해 WCPOS를 업데이트하세요. iOS는 TestFlight, Android는 Play 테스트 프로그램을 사용하며, 두 경로 모두 [설치](/getting-started/installation) 페이지에 링크가 있습니다.
2. 그래도 열리지 않으면 **로그** 탭에서 **디버그 정보 복사**를 탭하고 지원팀에 문의하세요. 이 기기에 아직 매장에 도달하지 않은 판매가 있을 가능성도 알려주세요.
3. 기다리는 동안 로컬 데이터를 지우거나 로그아웃하거나 앱을 다시 설치하지 마세요. 이 기기에서 먼저 복구해야 할 데이터가 있는지 지원팀이 안내합니다.
