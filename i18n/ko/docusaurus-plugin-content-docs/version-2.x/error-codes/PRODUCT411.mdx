## 오류의 의미 {#what-this-means}

바코드 스캔 설정을 불러오지 못해 스캔한 코드와 상품이 일치하지 않을 수 있습니다.

POS에서 백그라운드로 이 설정을 계속 불러옵니다. 스캔이 계속 불안정하면 앱을 한 번 새로 고치세요.

## 데이터 상태 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 작업을 계속하세요. POS에서 백그라운드로 바코드 설정 불러오기를 재시도합니다.
2. 스캔해도 계속 일치하는 상품이 없으면 앱을 한 번 새로 고치세요.
3. 새로 고친 후에도 문제가 계속되면 설정 요청 자체가 실패하는 것입니다. 매장과의 연결을 확인하고 매장 상태 → 로그에서 관련 오류를 찾아보세요(도움이 필요하면 매장 관리자에게 문의하세요).
