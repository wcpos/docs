## 오류의 의미 {#what-this-means}

변경 사항을 장바구니에 적용하지 못했으며, 장바구니는 그대로입니다.

상품, 수수료, 배송 항목 또는 쿠폰이 추가되지 않았으며 삭제된 항목도 없습니다. 작업을 다시 시도하세요.

## 데이터에 미치는 영향 {#your-data}

주문 자체는 안전하며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 상품, 수수료, 배송 항목 또는 쿠폰을 다시 추가해 보세요. 장바구니 자체는 변경되지 않았습니다.
2. 같은 항목에서 계속 실패한다면 다른 상품을 한 번 추가해 보세요. 한 항목만 실패하면 해당 데이터의 문제이고, 모든 항목이 실패하면 기기의 문제일 가능성이 있습니다.
3. 계속 실패하면 WCPOS를 다시 시작하세요. 그래도 계속되면 디버그 정보를 내보내고 지원팀에 문의하세요.
