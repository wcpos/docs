## 오류의 의미 {#what-this-means}

WCPOS와 버전이 맞지 않아 WCPOS Pro가 비활성화되었습니다.

안내된 WCPOS 또는 WCPOS Pro 구성 요소를 업데이트해 두 버전이 호환되도록 하세요.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. WP Admin → 플러그인에서 두 플러그인의 버전을 확인하세요. 로그 항목에 WCPOS와 WCPOS Pro 중 어느 쪽이 오래된 버전인지 표시됩니다.
2. 오래된 쪽을 업데이트하세요. 둘 다 최신 버전으로 업데이트하면 버전 불일치가 해결됩니다.
3. Pro 업데이트가 표시되지 않으면 업데이트 도구에 권한이 없을 수 있습니다(LICENSE301 참고). 먼저 이 문제를 해결한 뒤 업데이트하세요.
