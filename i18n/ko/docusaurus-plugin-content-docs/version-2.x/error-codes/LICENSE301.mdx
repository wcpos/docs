## 오류의 의미 {#what-this-means}

업데이트 도구에 WCPOS Pro 업데이트를 다운로드할 권한이 없습니다.

이 매장의 업데이트 도구에 권한을 다시 부여한 뒤 업데이트를 다시 확인하세요.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

1. **WP Admin > POS > 설정 > 라이선스**로 이동하세요. 페이지에 **라이선스 키** 필드가 표시되면 키를 입력하고 **활성화**를 누르세요. 이미 라이선스가 활성화된 것으로 표시되면 먼저 WCPOS 계정에서 전체 키를 복사하세요(페이지에는 축약된 키만 표시됩니다). 그런 다음 **비활성화**를 누르고 키를 다시 입력한 뒤 **활성화**를 누르세요.
2. WP Admin → 알림판 → 업데이트에서 업데이트를 다시 확인하세요.
3. 권한 부여가 계속 실패하면 사이트가 업데이트 서버로 보내는 아웃바운드 요청을 차단하고 있을 수 있습니다. 호스팅 업체에 아웃바운드 HTTPS가 제한되는지 문의하세요.
