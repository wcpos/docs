## 이 오류의 의미 {#what-this-means}

이 주문은 매장에 더 이상 존재하지 않는 세율을 참조하므로 세액이 잘못되었을 수 있습니다.

주문 항목에 매장의 현재 세율표에 없는 세율이 적용되어 있습니다. 대부분 주문을 시작한 이후 WooCommerce에서 해당 세율을 삭제하거나 수정했기 때문입니다. WCPOS에서 이 세율을 조회할 수 없어 이 주문의 세액이 매장에서 현재 부과하는 세액과 다를 수 있습니다.

## 데이터 {#your-data}

주문은 안전합니다. 확인이 필요한 것은 세액뿐입니다. 결제를 받기 전에 세액을 확인하고, 세율에 대해서는 매장 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 결제를 받기 전에 다음을 진행하세요:

1. 주문의 세액을 확인하세요. 매장에 더 이상 존재하지 않는 세율로 계산된 금액입니다.
2. 세액이 잘못된 것 같다면 새 주문으로 판매를 시작하세요. 새 주문에는 매장의 현재 세율이 적용됩니다.

**매장 관리 화면(WP Admin)에서** — 사이트 관리자가 진행할 작업:

1. **WooCommerce → 설정 → 세금**으로 이동하여 최근에 삭제하거나 수정한 세율이 있는지 확인하세요. 진행 중인 주문에서 이미 참조하는 세율을 삭제한 경우에 주로 발생합니다.
2. 의도적으로 세율을 삭제했다면 당시 진행 중이던 주문을 새로 시작하는 것 외에 다른 조치는 필요하지 않습니다.
3. 매장의 세율이 변경되지 않았다면 POS에 오래된 사본이 남아 있을 수 있습니다. **매장 상태 → 데이터베이스 → 세율 → 초기화 후 다시 다운로드**에서 새로 가져오세요. 해당 컬렉션에만 영향을 주며 누구도 로그아웃되지 않습니다. [매장 상태](/troubleshooting/store-health#clear-and-redownload)를 참조하세요.
4. 세율 다운로드가 완료된 후에도 이 코드가 다시 나타나면 **매장 상태 → 로그**에서 로그 항목을 열고 **복사**(또는 **공유**)를 사용하여 세부 정보를 전달하고, 주문 번호와 함께 지원팀에 문의하세요.
