## 이 오류의 의미 {#what-this-means}

이 주문이 참조하는 세율이 현재 매장에 없어 세금이 잘못 계산되었을 수 있습니다.

주문의 한 항목이 매장의 현재 세율표에 없는 세율을 참조합니다. 대부분 주문을 시작한 뒤 WooCommerce에서 해당 세율이 삭제되거나 수정된 경우입니다. WCPOS는 세율을 조회할 수 없으므로 이 주문의 세금이 현재 매장에서 부과할 금액과 다를 수 있습니다.

## 데이터 {#your-data}

주문 자체는 안전합니다. 세금 금액만 확인이 필요하므로 결제를 받기 전에 확인하고, 세율에 관해 매장 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서** — 결제를 받기 전에 다음을 확인하세요:

1. 주문의 세금 금액을 확인하세요. 현재 매장에 없는 세율로 계산된 금액입니다.
2. 세금 금액이 잘못된 것 같으면 새 주문으로 판매를 시작하세요. 새 주문에는 매장의 현재 세율이 적용됩니다.

**매장(WP Admin)에서** — 사이트 관리자용:

1. **WooCommerce → 설정 → 세금**으로 이동하여 최근에 세율이 삭제되거나 수정되었는지 확인하세요. 진행 중인 주문이 참조하는 세율을 삭제하는 것이 일반적인 원인입니다.
2. 세율을 의도적으로 삭제했다면, 당시 진행 중이던 주문을 새로 시작하는 것 외에는 별도 조치가 필요하지 않습니다.
3. 매장의 세율이 바뀌지 않았다면 POS에 오래된 사본이 남아 있을 수 있습니다. **매장 상태 → 데이터베이스 → 세율 → 지우고 다시 다운로드**에서 새로고침하세요. 이 작업은 해당 데이터 모음에만 영향을 주며 로그아웃시키지 않습니다. [매장 상태](/troubleshooting/store-health#clear-and-redownload)를 참조하세요.
4. 세율 다운로드가 끝난 뒤에도 코드가 다시 나타나면 **매장 상태 → 로그**에서 로그 항목을 열고 **복사**(또는 **공유**)를 사용해 세부 정보를 보낸 다음, 주문 번호와 함께 지원팀에 문의하세요.
