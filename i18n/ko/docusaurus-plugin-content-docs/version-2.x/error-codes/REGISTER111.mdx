## 오류의 의미 {#what-this-means}

확인 메시지의 **실행 취소** 또는 계산대 패널의 **무효화**로 입금이나 출금을 취소했지만 매장에서 취소를 거부했습니다.

계산대에서는 이동 내역이 취소된 것으로 표시됩니다. 매장에서는 계속 반영됩니다.

## 데이터 상태 {#your-data}

손실된 데이터는 없습니다. 매장에는 원래 이동 내역이 그대로 있고 취소 내역은 이 기기에만 있어, 두 곳의 예상 현금 서랍 총액이 해당 이동 금액만큼 차이 납니다.

## 문제 해결 {#troubleshoot}

1. 계산대 패널의 입금 / 출금 목록을 여세요. 취소하려던 이동 내역은 매장에서 여전히 반영하고 있는 내역입니다.
2. 이동 내역은 해당 세션이 열려 있는 동안 한 번만 취소할 수 있습니다. 집계가 시작되면 매장은 설계상 취소를 거부합니다. 집계 대상인 근무 시간의 내역이 집계 도중 변경되는 것을 방지하기 위한 것입니다.
3. 실수로 취소한 경우에는 아무 조치도 필요하지 않습니다. 매장에 취소가 반영되지 않았기 때문입니다.
4. **상쇄하려고 반대 방향의 이동 내역을 기록하지 마세요.** 새 이동 내역은 매장*과* 이 계산대 모두에 전달되어 양쪽 총액을 같은 금액만큼 바꾸므로 차이는 그대로 남습니다. 매장의 수치가 정확한 수치입니다.
5. 계산대의 현금을 집계할 때까지 계산대의 예상 현금 금액은 그 금액만큼 잘못 표시됩니다. 차액의 사유를 알 수 있도록 집계 내역에 차이를 기록하세요.
