## 오류의 의미 {#what-this-means}

이 기기의 메모리가 부족하여 마지막 작업이 완료되지 않았을 수 있습니다.

다른 앱이나 탭을 닫고 WCPOS를 다시 시작한 뒤 마지막 판매나 변경 사항이 저장되었는지 확인하세요. 저장되지 않았다면 다시 수행하세요.

## 데이터 영향 {#your-data}

결과를 확인할 수 없으므로 다시 시도하기 전에 확인하세요. 메모리가 부족해졌을 때 판매나 변경 사항을 저장 중이었다면, 다시 수행하기 전에 저장되었는지 확인하세요.

## 문제 해결 {#troubleshoot}

1. 다른 앱이나 브라우저 탭을 닫으세요. WCPOS는 기기에서 실행 중인 다른 모든 프로그램과 메모리를 공유합니다.
2. WCPOS를 다시 시작하세요.
3. 마지막 판매나 변경 사항을 다시 수행하기 전에 저장되었는지 확인하세요. **매장 상태 → 데이터베이스**(**전송 대기 중인 변경 사항**에 포함된 판매는 저장되어 전송 중입니다), 장바구니, 주문(WCPOS Pro) 또는 **WooCommerce → 주문**을 살펴보세요. 카드 결제였다면 단말기나 결제 서비스 제공업체에서도 확인하세요. 고객에게 이미 청구되었다면 다시 청구하지 마세요. 실제로 저장되지 않은 경우에만 한 번 다시 수행하세요.
4. 특정 작업을 할 때마다 메모리가 부족해진다면 어떤 작업이었는지 기록하고 **로그** 탭에서 **디버그 정보 복사**를 누른 뒤 지원팀에 문의하세요.
5. 같은 기기에서 매일 발생한다면 상품 목록을 처리하기에 기기의 메모리가 부족할 수 있습니다. 지원팀이 확인할 수 있도록 보고하세요.
