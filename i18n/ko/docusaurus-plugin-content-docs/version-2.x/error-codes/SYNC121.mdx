## 오류의 의미 {#what-this-means}

현재 매장에 연결할 수 없습니다.

별도 조치 없이 판매를 계속하세요. 연결이 복구되면 변경 사항이 자동으로 전송됩니다. 상태가 지속되면 이 기기의 연결 상태와 매장 웹사이트가 열리는지 확인하세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 없는 변경 사항이 있을 수 있습니다. 매장에서 응답하면 자동으로 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 판매를 계속하세요. 판매 내역은 이 기기에 저장되며 매장에서 응답하면 자동으로 전송됩니다.
2. POS 단말기 자체가 온라인 상태인지 확인하세요. 이 기기에서 다른 웹사이트가 열리나요?
3. 같은 기기의 브라우저 탭에서 매장 웹사이트를 열어 보세요. 거기에서도 열리지 않는다면 POS가 아니라 사이트나 호스팅이 중단된 것입니다.
4. **이 기기의 네트워크 관리자:** 사이트는 열리지만 POS가 계속 오프라인이라면 둘 사이에서 VPN, 방화벽, 광고 차단기 또는 보안 플러그인이 API 요청을 차단하고 있습니다. 브라우저 개발자 도구(Network 탭) 또는 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 어떤 요청이 실패하는지 확인할 수 있습니다.
