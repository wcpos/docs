## 오류의 의미 {#what-this-means}

이 상품 변경 사항이 아직 매장에 전달되지 않았습니다.

표시된 사유를 읽고 해당 문제를 해결하거나 연결을 확인한 뒤 상품을 다시 저장하세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 없는 변경 사항이 저장되어 있을 수 있습니다. 연결 실패 후에는 다시 연결되면 상품을 다시 저장하세요. 매장이 수정을 거부했다면 이 기기는 매장의 버전으로 되돌아갑니다([SYNC202](/error-codes/SYNC202) 참조). 따라서 원인을 해결한 뒤 다시 수정하세요. 이 문제가 계속 발생하면 **로그** 탭의 **디버그 정보 복사**를 사용하여 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 표시된 사유를 읽으세요. 보통 로그 항목의 오류 메시지에서 연결 실패인지, 매장이 거부한 값인지, 매장에서 이루어진 수정과의 충돌인지 확인할 수 있습니다.

**계산대에서:**

- 연결 실패: 연결을 확인한 뒤 상품을 다시 저장하세요.
- 거부된 값: 사유에 표시된 값을 수정한 뒤 상품을 다시 저장하세요.

**매장에서(WP Admin):** 수정 충돌이 발생했다면 상품을 열어 계산대에 표시된 내용과 비교하고 올바른 값을 한 번 저장하세요.

뚜렷한 이유 없이 저장이 계속 실패하면 **로그** 탭의 **디버그 정보 복사**를 사용하여 지원팀에 문의하세요.
