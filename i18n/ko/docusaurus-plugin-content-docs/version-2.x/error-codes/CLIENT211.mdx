## 오류의 의미 {#what-this-means}

기기 수준의 충돌로 WCPOS가 중단되었습니다.

WCPOS를 다시 시작하고 마지막 판매나 변경 사항이 저장되었는지 확인하세요. 앱이나 시스템 업데이트가 있으면 설치하세요. 충돌이 반복되면 지원팀에 문의하세요.

## 데이터 영향 {#your-data}

결과를 확인할 수 없으므로 다시 시도하기 전에 확인하세요. 충돌이 발생했을 때 판매나 변경 사항을 저장 중이었다면, 다시 수행하기 전에 저장되었는지 확인하세요.

## 문제 해결 {#troubleshoot}

1. WCPOS를 다시 시작하고 마지막 판매나 변경 사항을 다시 수행하기 전에 저장되었는지 확인하세요. **매장 상태 → 데이터베이스**(**전송 대기 중인 변경 사항**에 포함된 판매는 저장되어 전송 중입니다), 장바구니, 주문(WCPOS Pro) 또는 **WooCommerce → 주문**을 살펴보세요. 카드 결제였다면 단말기나 결제 서비스 제공업체에서도 확인하세요. 고객에게 이미 청구되었다면 다시 청구하지 마세요. 실제로 저장되지 않은 경우에만 다시 입력하세요.
2. 앱과 기기 운영 체제의 대기 중인 업데이트를 설치하세요. 네이티브 충돌은 이미 수정된 버그인 경우가 많습니다. 관리되는 POS 기기에서는 기기 관리자가 이 작업을 수행합니다.
3. 같은 작업에서 충돌이 반복되면 **로그** 탭에서 **디버그 정보 복사**를 누르고 지원팀에 문의하세요. 충돌 당시 정확히 무엇을 눌렀는지도 기록하세요.
