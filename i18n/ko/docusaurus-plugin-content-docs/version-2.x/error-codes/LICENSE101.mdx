## 오류의 의미 {#what-this-means}

이 매장 또는 기기에서 WCPOS Pro 라이선스가 활성화되어 있지 않습니다.

로컬 상태, 라이선스 서버 상태, 업데이트 도구 상태를 확인한 다음 해당 매장의 라이선스를 활성화하세요.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**매장 측 조치** — 사이트 관리자 / 라이선스 소유자 안내:

1. **WP Admin > POS > 설정 > 라이선스**로 이동하세요. 라이선스가 활성화되어 있으면 **"라이선스 …이(가) 활성화되었습니다"** 메시지가 표시되고, 그렇지 않으면 **라이선스 키** 필드가 표시됩니다. (대신 업그레이드 카드가 표시되면 WCPOS Pro 플러그인이 비활성 상태라는 뜻입니다. 먼저 **WP Admin → 플러그인**에서 활성화하세요.)
2. 활성화되어 있지 않다면 WCPOS 계정의 키를 **라이선스 키**에 붙여 넣고 **활성화**를 누르세요.
3. 사이트 URL이 변경되면(http에서 https로 변경, www 추가 또는 제거, 도메인 이전, 스테이징 복사본 생성) 라이선스는 이전 주소에 남습니다. 먼저 이전 주소에서 비활성화하세요. 이전 사이트에 접속할 수 있다면 해당 사이트의 **라이선스** 페이지에서, 그렇지 않으면 [WCPOS 계정 페이지](https://wcpos.com/account/licenses)에서 비활성화하세요. 이전 사이트가 없어졌다면 **support@wcpos.com**으로 이메일을 보내 활성화 초기화를 요청하세요. 그런 다음 이 사이트의 **라이선스 키**에 WCPOS 계정의 전체 키를 입력하고 **활성화**를 누르세요. 페이지에 라이선스가 활성화된 것으로 표시되면 먼저 **비활성화**를 누르세요(페이지에는 축약된 키만 표시되며 **비활성화**를 누르면 지워집니다).
4. 라이선스가 활성화된 것으로 표시되지만 POS에서는 여전히 비활성 상태라면 먼저 WCPOS 계정에서 전체 키를 복사하세요(페이지에는 축약된 키만 표시되며 **비활성화**를 누르면 지워집니다). 그런 다음 **비활성화**를 누르고 **라이선스 키**에 키를 붙여 넣은 뒤 **활성화**를 누르세요.
5. 아직 잠겨 있나요? POS 기기에서 **매장 상태 → 로그**의 **디버그 정보 복사**를 사용하고, 라이선스 식별 정보를 첨부해 지원팀에 문의하세요.

**POS 기기에서:** 라이선스가 활성화되면 앱을 다시 로드해 변경 사항을 반영하세요.
