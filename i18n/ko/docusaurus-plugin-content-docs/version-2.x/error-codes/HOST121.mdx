## 오류의 의미 {#what-this-means}

매장 API 대신 봇 방지 페이지가 응답하고 있습니다.

앱은 JSON을 기대하지만 매장 REST API가 HTML 확인 페이지(봇 방지, CAPTCHA 또는 DDoS 중간 확인 페이지)를 반환하고 있습니다. POS 앱은 브라우저 확인 절차를 통과할 수 없으므로 보호 서비스의 허용 목록에 매장 REST API를 추가해야 합니다.

## 데이터 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 확인 페이지에서 보호 서비스를 식별하고 해당 설정을 여세요. Cloudflare, Sucuri, Kinsta 등은 각자 페이지에 브랜드를 표시합니다.
2. API 트래픽을 허용하도록 매장 자체 REST API 경로(/wp-json/ 및 /?rest_route=)를 허용 목록에 추가하세요.
3. Cloudflare에서는 REST API 경로에 대한 WAF **건너뛰기** 규칙을 추가하세요. 봇 방어 모드(무료 요금제)는 어떤 규칙으로도 우회할 수 없으므로 꺼야 합니다. [Cloudflare 가이드](/troubleshooting/common-problems/cloudflare)에서 정확한 규칙과 `curl` 확인 방법을 볼 수 있습니다.
4. Kinsta의 봇/방화벽 설정에서 REST API 경로를 허용 목록에 추가하세요. Sucuri에서는 API 경로에 JavaScript 확인 절차를 사용하는 DDoS 모드를 적용하지 마세요.
