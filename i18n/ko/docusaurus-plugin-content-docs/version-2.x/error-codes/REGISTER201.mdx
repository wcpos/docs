## 오류의 의미 {#what-this-means}

이 기기에서 계산대를 개시하고 준비금을 세어 입력했지만 매장에서 세션 생성을 거부했습니다.

판매는 계속 가능하며 주문에도 위험은 없습니다. 다만 매장에서는 이 계산대가 개시되지 않은 것으로 처리되므로 현금 이동을 해당 세션에 기록할 수 없고 계산대 보고서에 해당 근무 시간이 나타나지 않습니다.

## 데이터 상태 {#your-data}

주문은 정상적으로 저장되고 전송되며 영향이 없습니다. 다만 계산대 세션이 연결되어 있지 않아 해당 근무 시간의 계산대 보고서에 집계되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 계산대 패널에서 계산대를 마감한 뒤 다시 개시하세요. 새 세션은 대개 정상적으로 열립니다.
2. 로그 항목에 필드 이름이 표시된다면 보통 개시 준비금이 원인입니다. 숫자와 소수점 하나만 사용해 다시 입력하세요. `10,50`이나 `10.`이 아니라 `10.50`으로 입력하세요.
3. **매장 관리자:** WP Admin에서 계산대가 여전히 존재하고 사용 중지되지 않았는지, 캐셔 계정에 현금 관리 권한이 있는지 확인하세요.
4. 세션이 없는 동안 접수한 주문은 매장에 남지만 나중에 계산대 보고서에 추가할 수 없습니다. 정산 시 해당 근무 시간의 내역이 중요하다면 계산대를 다시 개시한 시각을 적어 두세요.
