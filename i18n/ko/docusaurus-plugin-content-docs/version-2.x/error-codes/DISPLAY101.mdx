## 오류의 의미 {#what-this-means}

고객 디스플레이가 표시하려던 장바구니 화면을 생성하지 못해 대기 화면으로 돌아갔습니다.

POS 자체에는 영향이 없으므로 고객 응대를 계속하세요. 다음에 장바구니가 변경되면 디스플레이가 스냅샷을 다시 생성하므로, 보통 항목을 추가하거나 제거하면 바로 복구됩니다.

## 데이터 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 이 문제로 판매 내용이 변경되지는 않으며, 고객 디스플레이는 기록을 저장하는 곳이 아니라 정보를 그대로 보여 주는 화면입니다.

## 문제 해결 {#troubleshoot}

1. 판매를 계속 진행하세요. POS는 계속 작동하며 고객 디스플레이만 대기 화면으로 돌아갑니다.
2. 장바구니 항목을 추가하거나 변경하세요. 다음 장바구니 변경 시 디스플레이가 스냅샷을 다시 생성하며 보통 자동으로 복구됩니다.
3. 장바구니를 여러 번 변경해도 디스플레이에 대기 화면이 계속 표시되면 **설정 → 고객 디스플레이**의 **페어링된 디스플레이**에 여전히 나열되어 있는지 확인한 뒤 디스플레이 창을 닫았다가 다시 여세요.
4. 계속 발생하면 문제가 있는 주문을 기록하고 로그 화면에서 **디버그 정보 복사**를 사용하여 둘 다 지원팀에 보내세요. 같은 장바구니에서 스냅샷 생성이 반복적으로 실패한다면 보통 디스플레이 자체보다 특정 주문 항목에 원인이 있습니다.
