## 오류의 의미 {#what-this-means}

매장에서 결제 결과를 반환하지 않아 주문 상태를 알 수 없습니다.

다시 시도하기 전에 주문을 열어 상태를 확인하세요. 이미 결제되었거나 완료된 주문이라면 다시 청구하지 마세요. 응답이 비어 있는 경우, 주문은 생성되었지만 확인 응답이 도착하지 않은 경우가 많습니다.

## 데이터 상태 {#your-data}

결과를 확인하지 못했습니다. 다시 시도하기 전에 확인하세요. 이 문제가 계속 발생하면 **로그** 탭의 **디버그 정보 복사**를 사용하고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

**계산대에서:**

1. 주문 상태를 확인할 때까지 결제 화면의 **레거시** 탭에 있는 **결제 처리**를 다시 누르거나 고객에게 다시 청구하지 마세요.
2. 주문을 열어 상태를 확인하세요. WCPOS Pro에서는 먼저 **매장 상태 → 데이터베이스**에서 **주문** 행의 **⋮** 메뉴를 열고 **지금 변경 사항 확인**을 선택해 계산대의 주문을 새로고침한 다음, **주문**에서 해당 주문을 여세요. Pro를 사용하지 않는 경우, 담당자에게 WP Admin의 **WooCommerce → 주문**에서 합계 금액과 최근 몇 분간의 주문을 기준으로 검색해 해당 주문을 열어 달라고 요청하세요.
3. 주문을 찾는 것만으로는 충분하지 않습니다. 결제되지 않은 주문도 존재할 수 있습니다. 상태가 **처리 중** 또는 **완료됨**이면 판매가 정상적으로 처리된 것이므로 다시 청구하지 마세요.
4. 주문이 아직 미결제 상태이거나 주문을 찾을 수 없다면 고객이 결제했는지 확인하세요. 카드 결제는 결제 서비스 제공업체의 화면, 영수증 또는 대시보드를 확인하고, 현금 결제는 현금 서랍과 받은 금액을 확인하세요. 이미 결제했다면 다시 청구하지 마세요. 주문을 찾았다면 앱을 다시 로드하고 주문 상태를 다시 확인하세요(계산대는 시작할 때 결제가 기록된 판매 건을 완료 처리합니다). 주문을 찾을 수 없거나 여전히 미결제 상태라면 마지막 단계로 이동하세요.
5. 주문이 미결제 상태이고 결제 서비스 제공업체에도 청구 내역이 없다면 결제를 한 번만 다시 시도하세요.
6. 여전히 확실하지 않다면 **로그** 탭의 **디버그 정보 복사**를 사용하고, 다시 시도하기 전에 지원팀에 문의하세요.

**매장에서** — 사이트 관리자용:

1. WooCommerce → 상태 → 로그에서 결제 중 치명적 오류가 발생했는지 확인하세요. 주문 생성 후 PHP가 비정상 종료되면 바로 이런 현상이 발생합니다.
2. WooCommerce 로그에 아무것도 표시되지 않으면 호스팅 제공업체에 서버의 PHP 오류 로그를 요청하세요. 일부 치명적 오류는 해당 로그에만 기록됩니다.

**개발자용:** 브라우저의 개발자 도구 또는 데스크톱 앱의 **고급 → 개발자 도구 전환**에서 네트워크 탭을 확인하세요. 결제 요청의 상태가 성공인데 응답 본문이 비어 있거나 잘려 있다면 플러그인이나 서버 버퍼가 응답을 중간에 끊고 있다는 뜻입니다.
