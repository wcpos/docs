## 오류의 의미 {#what-this-means}

상품 SKU가 중복되었거나 유효하지 않아 결제를 계속할 수 없습니다.

표시된 SKU를 변경하거나 제거한 다음, 보존된 장바구니로 다시 시도하세요.

## 데이터 상태 {#your-data}

주문 자체는 안전하게 유지되며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목에 매장이 거부한 SKU가 표시됩니다.

**계산대에서:** SKU를 수정하기 전에는 이 상품을 판매할 수 없습니다. 장바구니에서 해당 항목을 제거하고 상품을 따로 보관한 뒤, 나머지 상품의 판매를 먼저 완료하세요. 매장에서 수정이 끝나면 해당 상품의 판매를 다시 진행하세요.

**매장에서** — 사이트 관리자용:

1. WP Admin의 상품에서 해당 SKU를 검색하세요. 두 상품(또는 상품과 상품 옵션)이 같은 SKU를 사용한다면 각각 고유한 SKU를 지정하세요. 해당 SKU를 사용하는 상품이 하나뿐이라면 SKU 자체의 형식이 잘못된 것이므로 해당 상품에서 수정하세요.
2. SKU가 고유하고 유효해지면 계산대에서 해당 상품을 추가하고 판매를 완료할 수 있습니다(장바구니는 보존됩니다).
