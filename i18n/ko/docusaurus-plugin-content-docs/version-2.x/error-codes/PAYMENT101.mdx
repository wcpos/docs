## 오류의 의미 {#what-this-means}

결제는 성공했지만 이후 WCPOS가 결제 상태를 새로 고치지 못했습니다.

결제가 완료되었으므로 다시 결제하지 마세요. 주문을 다시 열어 상태를 갱신하세요. 여전히 최신 상태로 보이지 않으면 아래 안내에 따라 새로 고치세요.

## 데이터에 미치는 영향 {#your-data}

이미 결제를 받았으므로 다시 결제하지 마세요. 화면에 표시된 상태만 최신이 아닙니다.

## 문제 해결 {#troubleshoot}

1. 고객에게 다시 결제를 요청하지 마세요. 매장에서 결제를 확인했으며(**주문 #… 결제가 완료되었습니다** 토스트 알림이 표시되었다면 그 알림이 확인 메시지입니다), POS 기기의 후속 갱신만 실패했습니다.
2. 주문을 다시 열어 상태를 갱신한 뒤 다음 판매를 진행하세요.
3. 결제된 주문이 장바구니에 아직 미완료 주문으로 표시되면 POS 기기의 사본을 새로 고치세요. **매장 상태 → 데이터베이스**를 열고 **주문** 행의 **⋮** 메뉴에서 **지금 변경 사항 확인**을 선택하세요. 결제 완료 상태가 수신되면 주문이 장바구니에서 사라집니다. WCPOS Pro에서는 해당 주문만 새로 고칠 수도 있습니다. **주문**에서 해당 주문의 **⋮** 메뉴를 열고 **동기화**를 선택하세요.
4. 여전히 미완료 상태로 표시되면 앱을 다시 로드하세요(웹에서는 브라우저 탭을 다시 로드하고, 데스크톱과 모바일에서는 앱을 닫았다가 다시 여세요). POS 기기는 시작할 때 결제가 기록된 판매를 완료합니다.
5. **사이트 관리자:** 확실히 확인하려면 **WooCommerce → 주문**에서 해당 주문을 여세요. 여기에는 결제 완료로 표시됩니다.
