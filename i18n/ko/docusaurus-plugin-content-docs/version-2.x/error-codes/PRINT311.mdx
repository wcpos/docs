## 오류의 의미 {#what-this-means}

이 영수증을 이메일로 보내거나 다운로드하지 못했습니다.

판매 내역은 저장되었습니다. 이메일 주소를 확인하거나, PDF라면 기기의 여유 저장 공간을 확인한 뒤 영수증에서 다시 시도하세요. 모든 이메일 전송이 실패하면 사이트 관리자에게 매장의 이메일 발송 상태를 확인해 달라고 요청하세요.

## 데이터 상태 {#your-data}

판매 내역은 저장되었으며 변경되지 않았습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼치세요. 이메일 주소가 표시되면 이메일 전송이 실패한 것이고, 그렇지 않으면 PDF 작업(생성, 다운로드, 저장 또는 공유)이 실패한 것입니다.
2. 이메일 전송 문제라면 주소와 연결을 확인한 뒤 영수증에서 다시 보내세요. 모든 이메일 전송이 실패하면 사이트 관리자에게 매장의 발신 이메일과 SMTP 설정을 확인해 달라고 요청하세요.
3. PDF 작업이 실패했다면 기기의 여유 저장 공간을 확인하고 영수증에서 PDF 다운로드를 다시 시도하세요. 다운로드 권한을 확인한 다음 쓰기 가능한 저장 위치나 다른 사용 가능한 공유 대상을 선택하세요.
