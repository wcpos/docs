## 이 오류의 의미 {#what-this-means}

매장에서 로그인 정보를 승인하지 않았습니다.

사용자 이름과 비밀번호를 다시 입력하세요. 계속 실패하면 WordPress에서 비밀번호를 재설정하세요. 주문 데이터에는 영향이 없습니다.

## 데이터 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

**계산대에서** — 캐셔 안내: 사용자 이름과 비밀번호를 다시 입력하세요. 매장에서 이 로그인 정보 조합을 거부했습니다.

**매장 사이트에서** — 사이트 관리자 안내:

1. 같은 로그인 정보로 WP Admin에 로그인하여 계정이 정상적으로 작동하는지 확인하세요. 실패하면 그곳에서 비밀번호를 재설정하세요.
2. 같은 정보로 WP Admin에는 로그인할 수 있지만 POS에는 로그인할 수 없다면 로그인 보호 또는 보안 플러그인이 프로그램을 통한 로그인을 차단하고 있을 수 있습니다. 해당 플러그인의 설정을 확인하세요.
