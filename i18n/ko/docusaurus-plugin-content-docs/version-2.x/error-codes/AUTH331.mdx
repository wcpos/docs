## 오류의 의미 {#what-this-means}

이 매장의 WCPOS 플러그인은 너무 오래되어 현재 앱 버전에서 사용할 수 없습니다.

앱은 업데이트되었지만 매장의 WCPOS 플러그인은 업데이트되지 않아 두 버전이 더 이상 함께 작동하지 않습니다. 사이트 관리자에게 WP Admin에서 WCPOS 플러그인을 업데이트해 달라고 요청한 다음 다시 연결하세요. 계산대에서는 변경할 것이 없습니다.

## 데이터에 미치는 영향 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다. 문제가 계속되면 WordPress 사이트 관리자에게 문의하세요.

## 문제 해결 {#troubleshoot}

**매장 사이트에서** — WordPress 사이트 관리자 안내:

1. WP Admin → 플러그인에서 WCPOS를 최신 버전으로 업데이트하세요. WCPOS Pro가 설치되어 있다면 함께 사용할 수 있는 버전으로 동시에 업데이트하세요.
2. 업데이트가 표시되지 않으면 WP Admin → 알림판 → 업데이트를 확인하세요. Pro의 경우 업데이트 도구가 인증되지 않으면 업데이트가 차단됩니다([LICENSE301](./LICENSE301) 참고). 먼저 이 문제를 해결하세요.

**계산대에서** — 캐셔 안내: 매장 업데이트가 완료되면 다시 연결하세요. 매장 주소를 다시 입력할 필요는 없습니다.

**아직 매장을 업데이트할 수 없다면:** 지원팀에 문의하세요. 계산대에는 플러그인과 맞는 앱 버전이 필요하며, 지원팀에서 해당 버전을 안내해 드릴 수 있습니다. 지원팀은 앱 버전(계산대에서 확인)과 매장의 현재 WCPOS 버전(WP Admin에서 확인)을 요청합니다.
