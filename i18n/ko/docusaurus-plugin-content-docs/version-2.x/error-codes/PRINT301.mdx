## 오류의 의미 {#what-this-means}

선택한 프린터에 연결할 수 없습니다.

프린터의 전원이 켜져 있고 연결되어 있는지 확인한 뒤 다시 인쇄해 보세요.

## 데이터 상태 {#your-data}

주문이나 상품 데이터에는 영향이 없습니다.

## 문제 해결 {#troubleshoot}

1. 프린터의 전원이 켜져 있고 케이블이나 네트워크가 제대로 연결되어 있는지 확인하세요.
2. 프린터 자체에서 자체 테스트 페이지를 인쇄하세요(프린터 설명서 참조). 대부분의 네트워크 프린터는 자체 테스트 페이지에 현재 IP 주소도 표시합니다.
3. 네트워크 프린터라면 계산대와 프린터가 같은 네트워크에 있는지 확인하세요. 그런 다음 **설정 → 인쇄**를 열고 **프린터** 목록에서 해당 프린터의 **편집**을 누른 뒤 **IP 주소**가 자체 테스트 페이지와 일치하는지 확인하세요(페이지에 **포트**도 표시되면 함께 확인하세요). 라우터가 재시작 후 프린터에 새 주소를 할당할 수 있습니다. 값을 수정하거나 **네트워크 검색**을 사용하세요. 변경 사항은 수정하는 즉시 저장됩니다.
4. **설정 → 인쇄**에서 프린터의 **편집** 화면을 열고 **테스트 인쇄**를 누른 다음 영수증을 다시 인쇄하세요.
