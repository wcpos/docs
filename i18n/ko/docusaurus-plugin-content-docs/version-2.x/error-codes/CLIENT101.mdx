## 오류의 의미 {#what-this-means}

WCPOS가 시작을 완료하지 못했습니다.

계산대에서는 화면이 비어 있거나 멈춘 상태로 보이거나, 로딩 표시가 사라지지 않는 증상으로 나타납니다. WCPOS를 다시 시작하세요(웹에서는 탭을 새로고침하세요). 시작 오류는 이렇게 하면 저절로 해결되는 경우가 많습니다. 그래도 시작되지 않으면 아무것도 삭제하지 말고 먼저 지원팀에 문의하세요.

:::warning 이 기기의 데이터를 삭제하지 마세요
이 기기에는 오프라인에서 처리한 판매 내역 등 아직 매장으로 전송되지 않은 판매 내역이 남아 있을 수 있습니다. WCPOS를 시작할 수 없는 동안에는 이 내역을 전송할 수 없으므로, 로컬 데이터를 삭제하거나 로그아웃하거나 앱을 다시 설치하면 해당 내역이 영구적으로 삭제됩니다. 아무것도 삭제하지 말고 먼저 지원팀에 문의하세요.
:::

## 데이터 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 반영되지 않은 변경 사항이 남아 있을 수 있습니다. 매장 자체의 데이터는 안전하며 영향을 받지 않습니다.

## 문제 해결 {#troubleshoot}

1. WCPOS를 한 번 다시 시작하세요. 웹에서는 탭을 완전히 새로고침하세요. 일시적인 시작 오류는 이렇게 하면 저절로 해결되는 경우가 많습니다.
2. 그래도 시작되지 않으면 아무것도 삭제하지 말고 먼저 지원팀에 문의하세요. WCPOS가 **로그** 탭에 접근할 수 있을 정도로 열린다면 **디버그 정보 복사**로 복사한 정보를 보내세요. 그렇지 않으면 브라우저 콘솔(개발자 도구)이나 데스크톱 앱의 **고급 → 개발자 도구 전환**에 표시되는 오류를 보내세요.
3. 답변을 기다리는 동안 로컬 데이터를 삭제하거나 로그아웃하거나 앱을 다시 설치하지 마세요. 지원팀에서 이 기기에 먼저 복구해야 할 데이터가 있는지 안내해 드립니다.
