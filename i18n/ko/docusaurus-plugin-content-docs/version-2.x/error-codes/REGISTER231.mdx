## 오류의 의미 {#what-this-means}

로그인한 계정의 역할에 현금 관리 권한이 없어 매장에서 요청을 거부했습니다. 금전등록기를 열고, 입금, 출금, 판매 없이 여는 작업을 기록하며, 현금을 세고 마감하려면 모두 이 권한이 필요합니다.

판매에는 영향이 없습니다.

## 데이터 상태 {#your-data}

손실된 데이터는 없습니다. 입력한 내용은 계산대에 유지되지만, 매장에는 금전등록기 열기, 현금 이동 또는 마감이 기록되지 않았습니다. 거부된 현금 이동이나 마감은 자동으로 재시도되지 않습니다.

## 문제 해결 {#troubleshoot}

1. 매장 관리자에게 이 계산대에 로그인하여 금전등록기를 열거나 현금을 세거나 마감하도록 요청하세요. 현금을 세는 중이라면 권한이 있는 사람이 마감할 때까지 판매가 계속 차단됩니다.
2. **매장 관리자:** 이 역할에 계산대 운영을 허용할지 결정하세요. 허용하려면 **WP Admin > POS > 설정 > 접근 권한**으로 이동하여 역할을 선택하세요. 화면 맨 아래의 **고급**(*개별 권한*)을 열고 **WCPOS** 아래에서 `manage_woocommerce_pos_cash`를 선택하세요. [계산대 권한](../settings/wp-admin/access.mdx#till-permissions)에서는 이 권한을 **계산대 운영**이라고 합니다.
3. 계산대에서 POS를 새로고침하세요. 그런 다음 계산대 패널의 **다시 시도**를 누르거나 금전등록기 열기, 현금 세기 또는 마감을 다시 진행하세요.
