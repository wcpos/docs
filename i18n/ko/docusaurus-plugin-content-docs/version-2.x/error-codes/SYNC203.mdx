## 오류의 의미 {#what-this-means}

매장에 이 주문이 더 이상 없어 이 기기에서 자체 사본을 정리했습니다.

이 기기에 주문이 남아 있는 동안 누군가 WP Admin에서 해당 주문을 삭제했습니다(휴지통으로 이동). 매장의 사본이 없어졌으므로 이 기기는 장바구니를 새 주문으로 유지하거나 자체 사본을 제거합니다.

## 데이터 상태 {#your-data}

열려 있는 장바구니는 유지되며 새 번호가 부여된 새 주문으로 다시 전송됩니다. 다음에 **결제**를 누를 때 전송됩니다. 그 외의 주문은 매장의 사본이 없어졌으므로 이 기기에서 제거됩니다. 추가로 전송을 기다리는 항목은 없습니다.

## 문제 해결 {#troubleshoot}

1. 로그 항목을 펼쳐 보세요. 매장에서 삭제한 주문 번호와 이 기기에서 장바구니를 새 주문으로 유지했는지 또는 사본을 제거했는지가 나와 있습니다.
2. 장바구니가 유지되었다면 판매는 정상적으로 진행됩니다. **결제**를 누르면 새 번호가 부여된 새 주문으로 매장에 전송됩니다.
3. 주문이 실수로 제거되었다면 매장 관리자가 WP Admin의 **WooCommerce → 주문 → 휴지통**에서 복원할 수 있습니다. 이 기기는 다음 새로고침 때 해당 주문을 다시 가져옵니다.
4. 같은 주문에 대해 계속 보고된다면 관리자가 이 기기에서 아직 사용 중인 주문을 삭제하고 있는 것입니다. 휴지통으로 보내기 전에 누가 열려 있는 장바구니를 종료할지 정하세요.
