## 오류의 의미 {#what-this-means}

판매를 취소하면 매장에 해당 주문의 각 결제를 취소하도록 요청합니다. 그중 하나 이상이 거부되었고 매장이 이를 알리는 응답을 보냈습니다. 연결이 끊긴 상황이 아닙니다.

해당 금액은 아직 고객의 카드에 묶여 있거나 POS의 현금에 포함되어 있습니다. 취소하지 못한 결제는 로그 행에 명시됩니다. "일부 금액이 반환되었다"는 정보만으로는 판매자가 조치할 수 없기 때문입니다.

## 데이터에 미치는 영향 {#your-data}

금액이 이체되었으며 아직 반환되지 않았습니다. 명시된 결제 금액은 여전히 보유 중이며 직접 반환해야 합니다.

## 문제 해결 {#troubleshoot}

**POS 기기에서** — 고객이 떠나기 전에 다음을 수행하세요:

1. 로그 행에서 결제 ID를 확인하세요. 해당 결제 금액들이 아직 반환되지 않은 금액입니다.
2. 고객이 떠나기 전에 어떤 결제가 취소되었고 어떤 결제가 취소되지 않았는지 알려 주세요.
3. 거부가 일시적인 것으로 보이면 취소를 다시 시도하세요.

**매장 측 조치** — 사이트 관리자 안내:

1. WooCommerce에서 주문을 열고 일반적인 환불 절차에 따라 명시된 결제를 환불하세요.
2. 매입되지 않은 카드 승인은 대개 자동으로 해제되지만, 시점은 은행에 따라 다릅니다. 고객에게 해제되었다고 알리기 전에 확인하세요.
3. 명시된 모든 결제의 처리가 끝날 때까지 판매가 취소된 것으로 간주하지 마세요.
