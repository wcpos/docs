## 이 오류의 의미 {#what-this-means}

결제 중 예기치 않은 문제가 발생했습니다.

고객에게 다시 청구하기 전에 매장 관리자 화면에서 주문을 확인하세요. 문제가 반복되면 진단 정보를 내보내고 지원팀에 문의하세요.

## 데이터 {#your-data}

결과를 확인할 수 없습니다. 재시도하기 전에 확인하세요. 문제가 계속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 고객에게 다시 청구하기 전에 WP Admin의 WooCommerce → 주문에서 주문을 확인하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 serverCode가 있는지 확인하세요. 이 일반 코드는 아직 원인에 해당하는 전용 코드가 없다는 뜻입니다.
3. 반복되면 디버그 정보를 내보내고 지원팀에 문의하세요.
