## 오류의 의미 {#what-this-means}

결제 중 예기치 않은 문제가 발생했습니다.

고객에게 다시 결제를 청구하기 전에 매장 관리자 화면에서 주문을 확인하세요. 문제가 반복되면 진단 정보를 내보내고 지원팀에 문의하세요.

## 데이터 상태 {#your-data}

처리 결과를 확인하지 못했습니다. 다시 시도하기 전에 확인하세요. 문제가 지속되면 진단 정보를 내보내고 WCPOS 지원팀에 문의하세요.

## 문제 해결 {#troubleshoot}

1. 고객에게 다시 결제를 청구하기 전에 WP Admin의 WooCommerce → 주문에서 해당 주문을 확인하세요.
2. 로그 항목을 펼쳐 이벤트 코드와 serverCode가 있으면 함께 기록하세요. 이 일반 오류 코드는 해당 원인에 대한 전용 코드가 아직 없음을 의미합니다.
3. 문제가 반복되면 디버그 정보를 내보내고 지원팀에 문의하세요.
