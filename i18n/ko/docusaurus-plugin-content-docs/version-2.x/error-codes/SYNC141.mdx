## 오류의 의미 {#what-this-means}

매장에서 WCPOS에 잠시 요청 속도를 줄이도록 요청했습니다.

별도 조치는 필요하지 않습니다. WCPOS가 기다렸다가 자동으로 다시 시도합니다. 매일 발생한다면 사이트 관리자에게 매장의 요청 빈도 제한에 대해 문의하세요.

## 데이터 상태 {#your-data}

이 기기의 데이터를 삭제하지 마세요. 매장에 아직 없는 변경 사항이 있을 수 있습니다. 이후 시도에서 전송됩니다.

## 문제 해결 {#troubleshoot}

1. 별도 조치는 필요하지 않습니다. POS가 잠시 기다렸다가 자동으로 다시 시도합니다. 수동으로 다시 시도하면 제한 시간만 늘어납니다.
2. 다시 입력할 필요는 없습니다. 영향을 받은 변경 사항은 기기에 남아 있으며 이후 시도에서 전송됩니다.
3. 매일 발생한다면 사이트 관리자에게 보안 플러그인, CDN 또는 방화벽 규칙, 호스팅 자체 제한 중 어디에서 429를 반환하는지 확인하고 POS의 REST 트래픽을 허용해 달라고 요청하세요.
4. 펼친 로그 항목의 엔드포인트와 타임스탬프를 사용하면 관리자가 자신의 대시보드에서 해당 제한 내역을 찾는 데 도움이 됩니다.
