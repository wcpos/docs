계산대에서만 판매할 상품도 있고 온라인에서만 판매할 상품도 있습니다. **POS 전용 상품 활성화**를 켜면 모든 상품에 다음 세 가지 중 하나를 선택하는 **POS 표시 여부**가 추가됩니다.

| POS 표시 여부 | 웹사이트 | POS |
|------------|--------------|-----|
| **POS 및 온라인** (모든 상품의 초기값) | 표시 | 표시 |
| **POS 전용** | 숨김 | 표시 |
| **온라인 전용** | 표시 | 숨김 |

:::note WP Admin에서 설정
POS 표시 여부는 WP Admin에서 설정합니다. POS는 이 설정을 따르기만 하며 계산대에는 이를 변경하는 기능이 없습니다. 계산대에서 상품이 보이지 않나요? [문제가 발생한 경우](#troubleshooting)를 참고하세요.
:::

## 기능 켜기 {#enabling-the-feature}

WP Admin에서 **POS > 설정 > 일반**으로 이동하세요. **상품** 아래에서 **POS 전용 상품 활성화**를 켜세요. 켜는 즉시 저장됩니다. 이제 모든 상품에 **POS 표시 여부**가 생깁니다. 설정하지 않은 상품은 **POS 및 온라인**이 되며, 이전에 이 기능을 켜고 설정을 저장한 상품은 저장된 선택값을 사용합니다.

모든 상품을 양쪽에서 판매한다면 꺼둔 채로 사용하세요. 꺼져 있으면 POS 표시 여부로 숨겨지는 상품은 없으며, WooCommerce 자체의 표시 설정은 계속 적용됩니다.

:::warning
이 기능을 다시 끄거나 WCPOS를 비활성화하면 WooCommerce 표시 설정이 허용하는 범위에서 POS 전용 상품이 웹사이트에 다시 나타납니다. [기능 끄기](#switch-off)를 참고하세요.
:::

## 상품 표시 여부 설정 {#setting-product-visibility}

### 개별 상품 {#individual-products}

1. WP Admin에서 **상품**으로 이동하여 상품을 여세요.
2. **공개** 상자에서 **POS 표시 여부** 옆의 **편집**을 누르세요.
3. **POS 및 온라인**, **POS 전용**, **온라인 전용** 중 하나를 선택하고 **확인**을 누르세요.
4. **업데이트**를 누르세요.

### 옵션 {#variable-products}

각 옵션에는 **옵션** 아래의 해당 패널에 개별 **POS 표시 여부**가 있습니다. 설정을 마치면 **변경 사항 저장**을 누르세요. 모든 색상을 온라인에서 판매하고 일부만 계산대에서 판매하거나, 특정 크기를 매장 전용으로 남겨둘 수 있습니다. 옵션 상품 전체를 변경하려면 상품 자체의 **POS 표시 여부**를 설정하세요. **온라인 전용** 상품은 계산대에 타일이 표시되지 않고, **POS 전용** 상품은 모든 옵션과 함께 온라인 쇼핑몰에서 숨겨집니다.

### 설정한 상품 다시 찾기 {#find-them}

상품 목록의 표 위, **발행됨** 옆에 **POS 전용**과 **온라인 전용** 보기가 추가되며 각각 상품 수가 표시됩니다. 하나를 클릭하면 해당 상품만 표시됩니다.

## POS에서의 동작 {#how-it-affects-the-pos}

**온라인 전용** 상품은 계산대에 전혀 나타나지 않습니다. 상품 패널에 표시되지 않고 검색으로도 찾을 수 없으며, 바코드를 스캔하면 **바코드를 찾을 수 없습니다**라고 나옵니다. **POS 전용** 및 **POS 및 온라인** 상품은 평소처럼 판매할 수 있습니다.

상품의 표시 여부를 변경하면 POS가 다음에 쇼핑몰의 변경 사항을 확인할 때 반영됩니다. 온라인 전용으로 바꾼 상품은 사라지고, 원래대로 변경하면 다시 나타납니다. 지금 확인하려면 상품 수 옆의 화살표를 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[190, 0], [0, 0], [0, 0], [0, -40], [-50, 0]]} alt="검색 후 상품 패널: 재고 있음 필터가 활성화되어 있고 상품 타일 하나와 상품 수가 표시되며, 상품 수 옆의 동기화 메뉴가 열려 동기화 및 지우고 새로고침이 표시됨">

1. **상품 검색** — 쇼핑몰에도 검색을 요청하지만 온라인 전용 상품은 결과에 포함하지 않습니다. [검색 및 필터링](../pos/product-panel/search-filtering.mdx#how-search-works)을 참고하세요.
2. **설정** — **품절 상품 표시**가 포함되어 있습니다. [표시 설정](../pos/product-panel/display-settings.mdx#show-out-of-stock-products)을 참고하세요.
3. **재고 있음** — 품절 상품을 숨깁니다. 상품이 누락되었다고 판단하기 전에 ×를 눌러 해제하세요. [재고 상태](../pos/product-panel/search-filtering.mdx#stock-status)를 참고하세요.
4. **상품 타일** — POS 전용 및 POS 및 온라인 상품이 여기에 표시됩니다.
5. **상품 수** — 이 기기에서 조건에 맞는 상품 수입니다. 여기서는 **상품 1개**, 전체 목록에서는 **259개 중 20개 표시**로 나타납니다. 옆의 화살표를 누르면 즉시 변경 사항을 확인합니다. 길게 누르면 여기에 열린 메뉴처럼 **동기화** 또는 **지우고 새로고침**이 표시됩니다. 지우고 새로고침은 검색과 필터를 지우고 상품을 다시 다운로드합니다. [패널 하단](../pos/product-panel/display-settings.mdx#footer)을 참고하세요.

</JourneyShot>

## 웹사이트에서의 동작 {#where-pos-only-products-stay-visible}

**POS 전용** 상품은 고객에게 숨겨집니다.

- 쇼핑몰, 카테고리 페이지, 검색, 연관 상품, 상품 블록, 피드 또는 사이트맵의 목록에 나타나지 않습니다.
- 장바구니에 추가하거나 온라인으로 구매할 수 없습니다. WooCommerce 자체의 **숨김** 설정과 마찬가지로 직접 링크를 열면 상품 페이지는 표시되지만, 그 페이지에서도 장바구니에 추가할 수 없습니다.
- **POS 전용** 옵션은 상품 페이지의 선택 항목에서 제외됩니다. 다른 옵션이 있는 상품은 온라인에 계속 표시됩니다.

<details>
<summary>카탈로그 표시 여부 및 POS 전용 상품이 계속 표시되는 위치</summary>

WCPOS는 POS 전용 상품의 WooCommerce **카탈로그 표시 여부**를 **숨김**으로 설정하여 상품을 숨깁니다. 상품이 POS 전용인 동안에는 공개 상자의 **카탈로그 표시 여부**가 **숨김**으로 고정되며, *POS 전용 상품은 온라인 카탈로그나 검색에 표시되지 않습니다.*라는 문구가 나옵니다. **POS 및 온라인** 또는 **온라인 전용**으로 되돌리면 WCPOS가 이전 카탈로그 표시 여부를 복원합니다. **업데이트**를 누르기 전에 공개 상자에서 복원될 값을 확인할 수 있습니다. 항상 공개 상태였던 상품은 **상점 및 검색 결과**로 돌아갑니다. 다른 카탈로그 표시 여부를 원하면 업데이트 후에 변경하세요. WooCommerce에서 옵션에는 자체 카탈로그 표시 여부가 없으므로 고정되는 설정도 없습니다.

숨김은 고객에게만 적용되는 규칙입니다. POS 전용 상품은 쇼핑몰을 운영하는 다음 위치에 계속 표시됩니다.

- 상품 목록과 상품 편집기를 포함한 **WP Admin**.
- **WooCommerce 분석**. 따라서 POS 전용 상품의 카테고리로 필터링한 보고서에도 해당 상품의 매출이 표시됩니다.
- **POS** 자체.

</details>

## 기능 끄기 {#switch-off}

**POS 전용 상품 활성화**를 끄면 POS 표시 여부로 숨겨지는 상품은 더 이상 없습니다. WooCommerce 자체의 표시 설정은 계속 적용됩니다. 온라인 전용 상품은 POS가 다음에 변경 사항을 확인할 때 다시 나타나며, POS 전용 상품은 이전 카탈로그 표시 여부로 돌아갑니다. 직접 숨겨두었던 상품은 계속 숨겨진 상태로 유지됩니다. 상품별 선택값은 보존되므로 기능을 다시 켜면 저장된 선택값을 사용하여 같은 상품을 다시 숨깁니다.

WCPOS를 비활성화해도 모든 POS 전용 상품의 카탈로그 표시 여부가 이전 상태로 돌아가므로 웹사이트에 다시 나타날 수 있습니다.

## 활용 사례 {#when-to-use-this-feature}

- **계산대에서 판매하는 기프트 카드** — 계산대에서 활성화하는 실물 카드입니다. **POS 전용**으로 설정하세요.
- **온라인 사전 주문** — 아직 입고되지 않았지만 고객이 온라인으로 주문하는 상품입니다. 계산대 목록이 복잡해지지 않도록 **온라인 전용**으로 설정하세요.
- **하나의 쇼핑몰에서 도매와 소매 운영** — 거래처 고객을 위한 도매 전용 상품은 **온라인 전용**, 매장 한정 상품은 **POS 전용**, 나머지는 **POS 및 온라인**으로 설정하세요.
- **다운로드 및 온라인 한정 혜택** — 계산대에서는 판매하지 않는 디지털 상품과 웹 전용 혜택입니다. **온라인 전용**으로 설정하세요.
- **매장 한정 특가 상품** — 계산대에서만 판매하는 프로모션 상품입니다. **POS 전용**으로 설정하세요.

## 문제가 발생한 경우 {#troubleshooting}

**온라인 전용 상품이 POS에 계속 표시됩니다.** 상품 수 옆의 화살표를 눌러 변경 사항을 확인하세요. 여전히 표시되면 화살표를 길게 누르고 **지우고 새로고침**을 선택하세요.

**POS에 상품이 없습니다.** 검색을 지우고 **재고 있음**을 포함한 필터 표시줄을 확인하세요. 그런 다음 WP Admin에서 상품을 열어 **POS 표시 여부**를 확인하고, 옵션이라면 상품 자체의 설정도 확인하세요.

**한 기기에는 상품이 표시되지만 다른 기기에는 표시되지 않습니다.** 각 기기는 자체 검색과 필터를 유지하며 온라인 상태에서만 변경 사항을 받아옵니다. [상품 동기화](./sync.mdx#one-device)를 참고하세요.

**POS 전용 상품이 쇼핑몰, 카테고리 또는 검색에 계속 표시됩니다.** 직접 링크로 상품 페이지가 열리는 것은 정상입니다. 여기서는 고객이 목록이나 검색에서 여전히 찾을 수 있는 상품을 다룹니다.

1. 상품을 열고 공개 상자의 **카탈로그 표시 여부**를 확인하세요. POS 전용 상품은 **숨김**으로 표시됩니다.
2. 다른 값이 표시되면 **업데이트**를 한 번 누르세요. WCPOS가 다시 **숨김**으로 설정합니다. 그래도 바뀌지 않으면 플러그인이나 사용자 정의 코드가 값을 변경하고 있는 것입니다. [개발자 안내](#developers)를 참고하세요.
3. **숨김**으로 표시된다면 페이지가 캐시되어 있을 가능성이 큽니다. 캐싱 플러그인이나 CDN의 캐시를 지우세요.

**상품에 POS 표시 여부가 없습니다.** **POS 전용 상품 활성화**가 꺼져 있습니다. **POS > 설정 > 일반**에서 켜세요.

## 개발자 안내 {#developers}

<details>
<summary>POS 전용 상품 필터</summary>

POS 전용 상품은 블록 장바구니와 결제에서 사용하는 WooCommerce Store API 및 WooCommerce REST API의 상품과 옵션 목록(`/wc/v1`부터 `/wc/v3`까지)에서 제외됩니다. `wp wc product list` 같은 WP-CLI 명령에서는 계속 조회할 수 있습니다.

**`wcpos_hide_pos_only_products`** 는 상품 쿼리에서 POS 전용 상품을 제외할지 결정합니다. 기본 결정값과 실행 예정인 `WP_Query`를 전달받습니다. 기본값은 쇼핑몰 화면에서는 true이고, WP Admin, WP-CLI, WooCommerce 분석 및 POS에서는 false입니다. 자체적으로 구현한 환경에서 POS 전용 상품을 조회하도록 하려면 `false`를 반환하세요.

```php
add_filter( 'wcpos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

**`wcpos_pos_only_catalog_visibility`** 는 WCPOS가 POS 전용 상품에 기록할 카탈로그 표시 여부를 설정합니다. `hidden`과 상품을 전달받습니다. WooCommerce의 카탈로그 표시 여부 키(`visible`, `catalog`, `search` 또는 `hidden`) 중 하나를 반환하면 해당 값이 대신 적용됩니다. 상품의 카탈로그 표시 여부를 직접 관리하려면 `null`을 반환하세요. 이 필터는 WCPOS가 **카탈로그 표시 여부**에 기록하는 값만 변경합니다. 위의 쇼핑몰 화면 규칙은 계속 적용되므로, POS 전용 상품을 온라인의 특정 위치에 표시하려면 `wcpos_hide_pos_only_products`와 함께 사용하세요.

```php
add_filter( 'wcpos_pos_only_catalog_visibility', function ( $visibility, $product ) {
    if ( has_term( 'club-stock', 'product_cat', $product->get_id() ) ) {
        return null; // I manage catalog visibility for these myself.
    }
    return $visibility;
}, 10, 2 );
```

**`wcpos_default_product_visibility`** 는 편집기에서 새 상품의 초기 **POS 표시 여부**를 설정합니다. `''`(**POS 및 온라인**)과 게시물을 전달받습니다. 새 상품의 초기값을 바꾸려면 `pos_only` 또는 `online_only`를 반환하세요.

WCPOS 2.0 이전에는 이 필터들의 이름이 `woocommerce_pos_hide_pos_only_products`, `woocommerce_pos_pos_only_catalog_visibility`, `woocommerce_pos_default_product_visibility`였습니다. 이전 이름은 여전히 작동하지만 2.0부터 사용이 권장되지 않으며, 빨라도 2.2부터 제거됩니다. [훅 이름 규칙](../extensions/index.mdx#hook-naming)을 참고하세요.

</details>
