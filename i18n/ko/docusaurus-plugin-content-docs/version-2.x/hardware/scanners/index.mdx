거의 모든 바코드 스캐너는 연결하거나 페어링하는 즉시 POS에서 사용할 수 있습니다. 이 페이지에서는 새 스캐너를 개봉한 후 처음 스캔하기까지의 과정을 안내하고, 스캔이 전달되지 않을 때 어디에서 확인할 수 있는지 설명합니다.

## 스캔 방법 {#ways-to-scan}

- **키보드 모드** — 거의 모든 스캐너의 출고 시 기본 모드입니다. 스캐너가 바코드를 입력하면 POS가 입력 속도로 스캔과 타이핑을 구분합니다. 별도로 설정할 필요가 없습니다.
- **카메라** — 스캐너가 필요하지 않습니다. 상품 검색 옆의 스캔 버튼을 누르고 카메라를 바코드에 맞추세요. [카메라 스캔](../../pos/product-panel/barcode-scanning.mdx#camera-scanning)을 참고하세요.
- **직접 연결** — POS가 입력 속도로 스캔을 판단하는 대신 스캐너 자체를 인식합니다. 키보드 모드로 충분하지 않다면 [스캐너 직접 연결](#direct)을 참고하세요.

## 스캐너 연결 {#connect}

1. 스캐너를 기기에 연결하세요.
   - **USB 스캐너:** 케이블을 연결하세요.
   - **Bluetooth 스캐너:** 페어링 모드로 전환한 뒤(방법은 설명서를 참고하세요), 키보드를 연결할 때처럼 기기의 Bluetooth 설정에서 페어링하세요.
2. POS를 여세요. 매장에서 **계산대 열기 및 닫기** 기능을 사용한다면 먼저 [계산대를 여세요](../../pos/register/index.mdx#open).
3. 상품의 바코드를 스캔하세요.
   - **브라우저 또는 데스크톱 앱:** 텍스트 입력란 밖을 클릭한 뒤 스캔하세요. POS의 어느 화면에서든 상품이 바로 장바구니에 담깁니다. 텍스트 입력란에 스캔하면 타이핑으로 처리됩니다.
   - **iPhone, iPad 또는 Android 앱:** 상품 검색란을 탭한 뒤 스캔하세요. 앱은 이 입력란에서만 키보드 모드 스캐너의 입력을 받습니다. [Android에 등록한 스캐너](#direct)는 탭하지 않아도 작동합니다.

상품이 표시되었다면 설정이 완료된 것입니다. 표시되지 않았다면 [스캔 테스트](#test)로 POS가 받은 내용을 확인하세요.

## 스캔 테스트 {#test}

**설정**을 열고 **바코드 스캔**을 선택하세요. iPhone, iPad 또는 Android 앱에서는 **키 입력 이벤트** 아래의 입력란을 탭하세요. 그런 다음 아무 바코드나 스캔하세요. 하단의 **바코드 스캔 테스트**에는 수신된 키, POS가 해당 키에서 읽어 낸 코드, 스캔으로 인식했는지가 표시됩니다. 이 예시에서는 느린 스캐너로 스캔했기 때문에 타이핑으로 처리되었습니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[150, 0], [150, 0], [420, 0], [520, -45], [300, -14], [175, 0]]} alt="느린 스캔 후의 바코드 스캔 테스트: 스캐너가 보낸 키, 감지된 바코드, 임계값을 넘는 주황색 막대가 있는 키 입력 시간 차트, 임계값 상향 제안과 적용 버튼이 있는 타이핑으로 처리됨 결과, 최근 시도, 문제 해결 가이드 링크">

1. **키 입력 이벤트** — 마지막의 Enter를 포함하여 스캐너가 보낸 모든 키입니다.
2. **감지된 바코드** — 접두사와 접미사를 제거한 후 POS가 조회할 코드입니다.
3. **입력 시간 차트** — 키마다 막대가 하나씩 표시되며, 임계값을 나타내는 점선과 비교할 수 있습니다. 점선을 넘는 막대는 해당 키가 너무 늦게 도착했음을 뜻합니다.
4. **판정 결과** — **스캔으로 감지됨** 또는 타이핑으로 처리된 이유와 권장 해결 방법을 표시합니다. **적용**을 누르면 권장 설정이 저장됩니다.
5. **최근 시도** — 최근 몇 번의 시도를 보여 줍니다. 각 시도에는 **스캔**, **타이핑** 또는 **너무 짧음** 표시와 키 입력 사이의 평균 간격이 표시됩니다.
6. **문제 해결 가이드** — 증상별 해결 방법을 안내하는 [스캐너 설정 마법사](./setup-wizard.mdx)를 엽니다.

</JourneyShot>

1. **입력 시간 막대** — 키마다 하나씩 표시되며, 아래에는 입력 간격이 ms 단위로 표시됩니다. 주황색 막대는 임계값보다 늦게 도착한 키를 나타냅니다.
2. **점선** — 설정된 임계값입니다. 여기서는 24ms입니다.
3. **적용** — 제안된 임계값을 저장합니다. 다시 스캔하여 확인하세요.

## 스캐너 설정 {#settings}

**바코드 스캔**의 나머지 부분에는 테스트에서 기준으로 사용하는 설정과 스캐너를 직접 연결하는 기능이 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[50, 0], [50, 0], [50, 0], [50, 0], [45, 0], [260, 0], [151, 0], [341, 0], [175, 0]]} alt="설정의 바코드 스캔 화면: 임계값, 최소 길이, 접두사 및 접미사 입력란, 스캔 시 소리 재생 스위치, 대부분의 스캐너는 설정이 필요하지 않습니다 안내와 스캐너 설정 가이드 및 직접 연결이 있는 스캐너 섹션, 바코드 스캔 테스트 제목">

1. **바코드 평균 입력 시간 임계값(ms)** — 스캔으로 인식되기 위해 필요한 키 입력 속도입니다. POS의 기본값은 24입니다. 스캐너가 느리면 값을 높이고, 빠른 타이핑이 스캔으로 인식되면 값을 낮추세요.
2. **바코드 최소 길이** — 스캔으로 인식되는 코드의 최소 길이입니다. POS의 기본값은 EAN-8의 길이인 8입니다.
3. **바코드 스캐너 접두사** — 스캐너가 각 코드 앞에 추가하는 문자 하나입니다. POS는 코드를 조회하기 전에 이 문자를 제거합니다. 스캐너가 접두사를 추가하지 않는다면 비워 두세요.
4. **바코드 스캐너 접미사** — 스캐너가 각 코드 뒤에 추가하는 문자 하나로, 접두사와 같은 방식으로 제거됩니다. 끝에 붙는 Enter는 POS가 무시하므로 접미사로 설정할 필요가 없습니다.
5. **스캔 시 소리 재생** — 직접 켜기 전까지는 꺼져 있습니다. 켠 다음 **소리 테마**와 **음량**을 선택하고 **성공 소리**와 **실패 소리**를 켜거나 끄세요. iPhone, iPad 및 Android 앱에는 **실패 시 진동**도 있습니다.
6. **대부분의 스캐너는 설정이 필요하지 않습니다** — 직접 연결된 스캐너가 없을 때 이 섹션에 표시되는 안내입니다. 키보드 모드 스캐너는 여기에 표시되지 않습니다.
7. **스캐너 설정 가이드** — 몇 가지 질문을 통해 설정이나 문제 해결 과정을 안내하는 [스캐너 설정 마법사](./setup-wizard.mdx)를 엽니다.
8. **직접 연결** — 스캐너를 직접 연결하기 전까지는 **없음**으로 표시됩니다. [스캐너 직접 연결](#direct)을 참고하세요.
9. **바코드 스캔 테스트** — 이 페이지에서 스캔하여 스캐너가 보내는 내용을 확인하세요. [스캔 테스트](#test)를 참고하세요.

</JourneyShot>

이 설정은 현재 기기에만 적용되므로 스캐너가 있는 각 계산대에서 설정하세요.

## 문제가 발생한 경우 {#goes-wrong}

**스캔해도 아무 반응이 없습니다.** 스캐너에서 소리가 나거나 표시등이 켜지는지 확인하고, 기기의 Bluetooth 설정에 단순히 페어링된 상태가 아니라 **연결됨**으로 표시되는지 확인하세요. iPhone, iPad 또는 Android 앱에서는 스캔하기 전에 상품 검색란을 탭하세요. 그런 다음 메모 앱에서 스캔하세요. 코드가 표시된다면 스캐너는 작동하는 상태이며, [테스트](#test)에서 POS가 이를 타이핑으로 처리한 이유를 확인할 수 있습니다.

**판정 결과에 “타이핑으로 처리됨”이 표시됩니다.** 스캐너의 입력 속도가 설정된 임계값보다 느립니다. 제안된 설정의 **적용**을 누르거나 **바코드 평균 입력 시간 임계값(ms)** 을 높이세요.

**상품 검색란에 입력한 내용이 스캔으로 인식됩니다.** iPhone, iPad 또는 Android 앱에서는 POS가 검색란의 타이핑도 속도로 판단하므로 이런 현상이 발생할 수 있습니다. 임계값을 낮추거나 **바코드 최소 길이**를 높이세요. 브라우저나 데스크톱 앱에서는 입력란에 타이핑한 내용을 스캔으로 인식하지 않습니다.

**스캔 결과가 깨져서 표시됩니다.** 스캐너와 기기의 키보드 배열이 일치하지 않습니다. 설명서의 바코드를 사용해 스캐너를 미국식 배열로 설정하거나 [직접 연결하세요](#direct).

**직접 연결할 때 목록에 스캐너가 없습니다.** 데스크톱 앱, 브라우저, iPhone 또는 iPad에서는 스캐너가 여전히 키보드 모드인 경우가 많습니다. 설명서의 모드 전환 바코드를 스캔하고 [기기에 맞는 단계](#direct)를 다시 따르세요. Bluetooth 직렬 스캐너가 여전히 표시되지 않는다면 자체 서비스 UUID를 사용할 수 있습니다. **스캐너 직접 연결** 아래의 [**데스크톱 앱, Chrome 또는 Edge**](#direct-desktop)를 열고 **Bluetooth 서비스 클래스 UUID**를 찾으세요. Android에는 목록이 없으므로 [스캐너를 등록하세요](#direct).

**직접 연결된 스캐너의 행에 범위 밖, 케이블 연결 안 됨 또는 연결 안 됨이 표시됩니다.** 현재 POS가 스캐너에 연결할 수 없는 상태입니다. 스캐너를 켜거나 가까이 가져오거나 케이블을 다시 연결하세요. [연결 후](#connected)를 참고하세요.

**스캔이 POS에 전달되지만 상품이 표시되지 않습니다.** POS에 **바코드를 찾을 수 없음**, **여러 항목 일치**, **옵션 선택** 등의 이유가 표시됩니다. [바코드 스캔](../../pos/product-panel/index.mdx#scan)을 참고하세요. 바코드가 저장되는 상품 필드는 [바코드 필드](../../settings/wp-admin/general.mdx#barcode-field)에서 설정합니다.

플랫폼과 증상에 따른 단계별 해결 방법은 [스캐너 설정 마법사](./setup-wizard.mdx)를 이용하세요.

## 스캐너 직접 연결 {#direct}

대부분의 매장에서는 키보드 모드가 적합합니다. 스캔 결과가 깨지거나, 잘못된 입력란에 들어가거나, 선택된 입력란이 없어 누락된다면 직접 연결하세요.

POS를 실행하는 기기에 해당하는 섹션을 여세요. 각 섹션에 모든 단계가 순서대로 나와 있습니다.

<details id="direct-desktop">
<summary>데스크톱 앱, Chrome 또는 Edge</summary>

1. 설명서의 설정 바코드를 사용해 스캐너를 키보드 모드에서 *SPP 모드*, *직렬 모드* 또는 *HID POS 모드* 등으로 전환하세요.
2. Bluetooth 스캐너라면 기기의 Bluetooth 설정에서 제거한 뒤 새 모드로 다시 페어링하세요.
3. **바코드 스캔**을 열고 **스캐너 직접 연결(고급)** 을 누른 다음 스캐너의 연결 방식을 선택하세요.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-24, 0], [222, 0], [455, 12], [300, 0], [240, 0]]} alt="브라우저의 스캐너 직접 연결 패널: USB로 연결, Bluetooth 직렬 연결, 키보드 모드 스캐너에 관한 안내, Bluetooth 서비스 클래스 UUID 입력란과 추가 버튼이 있는 내 스캐너가 목록에 없음 항목">

1. **USB로 연결** — HID POS 모드의 USB 스캐너에 사용합니다. 열리는 목록에서 스캐너를 선택하세요.
2. **Bluetooth 직렬 연결** — 직렬(SPP) 모드의 스캐너에 사용합니다. 직렬 모드의 USB 스캐너도 같은 목록에 표시됩니다.
3. **키보드 모드 안내** — 키보드 모드인 스캐너는 이 목록에 표시되지 않습니다. 기기에서 앱이 키보드를 독점적으로 제어하도록 허용하지 않기 때문입니다.
4. **Bluetooth 서비스 클래스 UUID** — 키보드 모드에서 전환했는데도 목록에 표시되지 않는 Bluetooth 직렬 스캐너에 사용합니다. 설명서의 UUID를 입력하고 **추가**를 누른 뒤 다시 연결하세요.
5. **스캐너의 서비스 UUID 찾기** — 어디에서 확인할 수 있는지 안내하는 [스캐너 설정 마법사](./setup-wizard.mdx)를 엽니다.

</JourneyShot>

</details>

<details>
<summary>iPhone 또는 iPad</summary>

1. 설명서의 설정 바코드를 사용해 스캐너를 키보드 모드에서 다른 모드로 전환하세요.
2. 기기의 Bluetooth 설정에서는 스캐너를 여전히 키보드로 인식하므로 해당 설정에서 제거하세요. 다시 페어링하지 마세요.
3. **바코드 스캔**에서 **스캐너 직접 연결(고급)** 을 누른 다음 **Bluetooth 스캐너 연결**을 누르세요. POS는 처음 발견한 Bluetooth LE 스캐너에 연결하므로 다른 스캐너는 꺼 두세요.

</details>

<details>
<summary>Android</summary>

1. 스캐너를 키보드 모드로 두고 페어링 상태를 그대로 유지하세요.
2. **바코드 스캔**에서 **스캐너 등록하기**를 누른 다음 **스캐너 등록**을 누르세요.
3. 스캐너로 한 번 스캔하고 이름을 지정한 뒤 **스캐너 저장**을 누르세요. 그러면 POS가 입력 속도 대신 기기를 기준으로 해당 스캐너의 스캔을 인식합니다.

### 연결 후 {#connected}

연결된 스캐너는 **스캐너** 아래에 행으로 표시되며 상태를 확인할 수 있습니다. 연결이 유지되면 **연결됨**, 연결할 수 없으면 **범위 밖**, **케이블 연결 안 됨** 또는 **연결 안 됨**으로 표시됩니다. Android에서는 **등록됨**으로 표시됩니다. 해당 행의 **⋮** 메뉴에는 **제거**가 있습니다. 키보드 모드 스캐너도 함께 계속 사용할 수 있습니다.
