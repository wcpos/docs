고객용 디스플레이는 웹 브라우저가 있는 태블릿이나 모니터처럼 고객을 향하는 두 번째 화면입니다. 판매 항목을 등록하는 대로 장바구니의 각 항목과 합계를 표시합니다.

:::info Pro 기능
고객용 디스플레이를 사용하려면 WCPOS Pro가 필요합니다. Pro가 없으면 **설정 → 고객용 디스플레이**에 안내가 표시됩니다. [무료 버전과 Pro 비교](../../getting-started/free-vs-pro.mdx#customer-display)를 참고하세요.
:::

각 디스플레이는 하나의 계산대와 페어링되며, 해당 계산대가 장바구니를 직접 전송합니다. 계산대와 디스플레이를 같은 Wi-Fi 네트워크에 연결하세요. 게스트 네트워크는 기기 간 연결을 차단하는 경우가 많습니다.

## 디스플레이 페어링 {#pair}

계산대와 디스플레이 기기를 나란히 준비하세요. 페어링 코드는 한 번만 사용할 수 있으며 10분 후에 만료됩니다.

1. **계산대에서** 사이드 메뉴 하단의 **설정**을 누른 다음 **고객용 디스플레이**를 누르세요.
2. **페어링 코드 생성을 누르세요.** 여섯 자리 코드와 만료 시간이 표시됩니다.
3. **계산대에서 주소를 확인하세요.** 버튼 아래의 **디스플레이 페이지 URL**은 사이트 주소 뒤에 `wcpos-display/`가 붙은 주소입니다. 웹 브라우저에서 실행되는 계산대에서는 **URL 복사**로 주소를 복사해 디스플레이 기기로 보낼 수 있습니다.
4. **디스플레이 기기에서 해당 주소를 여세요.** 페이지에 **이 디스플레이 페어링**이 표시됩니다.
5. **코드를 입력하세요.** **페어링 코드**에 코드를 입력하고, 원하면 **디스플레이 이름**을 변경한 다음(기본 이름은 *고객용 디스플레이*) **디스플레이 페어링**을 누르세요.
6. **계산대를 확인하세요.** **페어링된 디스플레이**에 디스플레이가 나타나고 **연결됨**으로 표시됩니다. 장바구니에 상품을 추가하면 디스플레이에 표시됩니다. 대신 메시지가 표시되면 [문제가 발생한 경우](#troubleshoot)를 참고하세요.

웹 브라우저에서 실행되는 계산대에서 **URL 복사** 옆의 **브라우저에서 열기**를 누르면 디스플레이 기기가 아닌 계산대 자체의 새 탭에 디스플레이 페이지가 열립니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[178, 0], [-44, 0], [0, 0], [-44, 0], [130, -20]]} alt="계산대의 설정, 고객용 디스플레이 화면: 10분 후 만료되는 여섯 자리 페어링 코드, 페어링 코드 생성 버튼, URL 복사와 브라우저에서 열기가 있는 디스플레이 페이지 URL, 비어 있는 페어링된 디스플레이 목록">

1. **고객용 디스플레이** — **설정**에서 카드 리더 다음에 있습니다.
2. **페어링 코드** — 디스플레이에 입력하세요. 코드 하나로 디스플레이 하나를 페어링합니다.
3. **페어링 코드 생성** — 새 코드를 생성합니다. 사용하기 전에 코드가 만료되면 다시 누르세요.
4. **디스플레이 페이지 URL** — 디스플레이에서 열 주소입니다. 웹 브라우저에서 실행되는 계산대에는 **URL 복사**와 **브라우저에서 열기**가 함께 표시됩니다.
5. **페어링된 디스플레이** — 디스플레이에서 코드를 입력하기 전까지 *이 기기와 페어링된 디스플레이가 없습니다.*가 표시됩니다.

</JourneyShot>

화면을 가득 채우려면 디스플레이 기기에서 브라우저의 전체 화면 모드를 사용하세요. 브라우저가 페어링 정보를 저장하므로 같은 브라우저에서 같은 주소를 다시 열면 새 코드 없이 디스플레이가 다시 연결됩니다.

## 페어링된 디스플레이 {#paired-displays}

**페어링된 디스플레이**에는 이 계산대와 페어링된 디스플레이가 나열됩니다. 각 행에는 디스플레이 이름, 계산대에서 마지막으로 감지한 시점, **연결됨** 또는 **연결 끊김** 상태가 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[215, 0], [-22, 0]]} maxWidth={720} alt="설정, 고객용 디스플레이의 페어링된 디스플레이에 디스플레이 하나가 있는 화면: 카운터 디스플레이, 마지막 감지 시점은 일 분 미만 전, 연결됨 상태 및 메뉴 버튼">

1. **연결됨** — *카운터 디스플레이*라는 이름의 디스플레이가 현재 이 계산대에 연결되어 있습니다. **연결 끊김**은 디스플레이 페이지가 닫혔거나 계산대에 연결할 수 없다는 뜻입니다.
2. **⋮** — 해당 행의 메뉴이며 **등록 해제**가 있습니다.

</JourneyShot>

디스플레이 하나에는 계산대 하나의 판매 내용이 표시됩니다. 카운터마다 별도 화면을 사용하려면 각 계산대에서 디스플레이를 페어링하세요.

## 고객에게 표시되는 내용 {#what-the-customer-sees}

디스플레이에 표시되는 내용은 템플릿에 따라 달라집니다. 기본 디스플레이 템플릿인 **Ledger**는 넓은 화면에서는 상품 목록 옆에 합계 패널을 표시하고, 좁은 화면에서는 하단에 합계를 고정합니다. Ledger에서 표시되는 내용은 다음과 같습니다.

- **판매 대기 중**: 매장 로고(로고가 없으면 매장 이름)와 환영 문구가 표시됩니다.
- **판매 중**: **구매 상품** 아래에 각 항목의 수량, 이름, 항목 합계가 표시되고, 별도 패널에는 **소계**, 수수료, 배송비, 할인, 세금 및 **합계**가 표시됩니다. 고객이 이번 구매로 할인받으면 **절약한 금액**이 추가됩니다. 주문에 고객이 지정되어 있으면 고객의 이름으로 인사합니다.

디스플레이는 결제가 끝날 때까지 판매 진행 상황을 반영합니다.

로고는 매장의 **상세 정보** 페이지에 있는 매장 자체 로고이며, 영수증에도 인쇄됩니다. 사이트 로고를 사용하는 매장에는 WordPress 사이트 로고가 표시됩니다. [매장 설정](../../stores/setup.mdx#store-pages)을 참고하세요.

## 템플릿 선택 {#template}

매장에서 자체 템플릿을 선택하지 않으면 모든 디스플레이에 사이트의 **실사용** 디스플레이 템플릿이 표시됩니다. 변경 사항은 다시 페어링하지 않아도 약 일 분 이내에 디스플레이에 반영됩니다.

<details>
<summary>모든 매장의 템플릿 변경</summary>

1. WP Admin에서 **POS → 템플릿**으로 이동한 다음 영수증 템플릿 옆의 **디스플레이** 탭을 여세요.
2. 원하는 템플릿의 **활성화**를 켜세요.
3. **실사용** 열에서 해당 템플릿을 선택하세요.

갤러리 자체에 대한 설명은 [보고서, 마감 및 고객용 디스플레이](../../receipts/index.mdx#other-templates)를 참고하세요.

</details>

<details>
<summary>특정 매장의 템플릿 변경</summary>

1. WP Admin에서 **POS → 매장**으로 이동해 매장을 클릭한 다음, 매장 메뉴의 **고객용 디스플레이**를 클릭하세요.
2. **사이트와 동일**로 표시된 **디스플레이 템플릿** 아래에서 **사용자 지정**을 클릭하세요.
3. 템플릿을 선택하세요. 목록에는 **디스플레이** 탭에서 활성화한 템플릿이 표시됩니다. 변경 사항은 자동으로 저장됩니다.

**사이트 템플릿 사용**을 누르면 매장이 사이트의 **실사용** 템플릿을 다시 사용합니다.

</details>

## 디스플레이 등록 해제 {#forget}

디스플레이의 페어링을 해제하려면 **페어링된 디스플레이**에서 해당 행의 **⋮** 를 열고 **등록 해제**를 선택한 다음 **등록 해제**를 다시 눌러 확인하세요. 디스플레이 페이지에 *이 디스플레이가 제거되었습니다. 다시 페어링하세요.*가 표시됩니다. 해당 화면을 다시 사용하려면 새 코드로 [페어링하세요](#pair).

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-26, 0]]} maxWidth={600} alt="페어링된 디스플레이의 메뉴를 열어 등록 해제가 표시된 화면">

1. **등록 해제** — 이 계산대에서 디스플레이를 제거합니다. 이 계산대의 내용을 다시 표시하려면 새 페어링 코드가 필요합니다.

</JourneyShot>

## 문제가 발생한 경우 {#troubleshoot}

### 페어링 {#troubleshoot-pairing}

<details>
<summary>페어링 코드가 유효하지 않거나 만료되었습니다.</summary>

코드는 10분 동안 유효하며 한 번만 사용할 수 있습니다. 계산대에서 **페어링 코드 생성**을 누르고 새 코드를 입력하세요. 잘못된 코드를 여러 번 입력하면 *시도 횟수가 너무 많습니다. 잠시 후 다시 시도하세요.*가 표시됩니다. 잠시 기다린 후 다시 시도하세요.

</details>

<details>
<summary>페어링 코드 생성 버튼이 비활성화되어 있습니다.</summary>

페이지에 *이 기기에서 고객용 디스플레이 서비스가 실행되고 있지 않습니다.*가 표시됩니다. POS를 새로고침하고, 여전히 버튼이 비활성화되어 있으면 **로그**에서 원인을 확인하세요.

</details>

<details>
<summary>고객용 디스플레이를 사용하려면 더 최신 버전의 WCPOS Pro가 필요합니다.</summary>

사이트의 Pro 플러그인이 고객용 디스플레이 기능이 추가되기 전 버전입니다. WordPress에서 WCPOS Pro를 업데이트한 다음 POS를 새로고침하세요.

</details>

<details>
<summary>이 디스플레이가 제거되었습니다. 다시 페어링하세요.</summary>

누군가 계산대에서 이 디스플레이의 **등록 해제**를 선택했습니다. 새 코드로 [페어링하세요](#pair).

</details>

### 연결 {#troubleshoot-connection}

디스플레이가 30초 동안 연결되지 않으면 화면에 이유를 표시하며 연결을 계속 시도합니다.

<details>
<summary>이 네트워크에서 디스플레이가 POS에 연결할 수 없습니다.</summary>

디스플레이가 매장에는 연결되었지만 계산대에는 연결되지 않았습니다. 두 기기를 같은 Wi-Fi 네트워크에 연결하세요. 게스트 네트워크는 기기 간 통신을 차단하는 경우가 많으므로 매장의 기본 네트워크를 사용하세요.

</details>

<details>
<summary>디스플레이가 매장에 연결할 수 없습니다.</summary>

디스플레이 기기가 인터넷에 연결되지 않았거나 사이트에 접근할 수 없습니다. Wi-Fi를 확인한 다음 디스플레이 페이지를 새로고침하세요.

</details>

<details>
<summary>POS를 기다리는 중입니다.</summary>

이 디스플레이와 페어링된 계산대가 실행되고 있지 않습니다. 해당 계산대에서 POS를 여세요.

</details>

<details>
<summary>POS가 응답했지만 디스플레이 설정을 완료하지 못했습니다.</summary>

계산대에서 POS를 다시 시작한 후 다시 시도하세요.

</details>

### 디스플레이에 표시되는 내용 {#troubleshoot-content}

<details>
<summary>고객용 디스플레이 템플릿이 설정되지 않았습니다.</summary>

활성화된 디스플레이 템플릿이 없습니다. **POS → 템플릿**의 **디스플레이** 탭에서 템플릿을 활성화하세요.

</details>

<details>
<summary>판매 중에 디스플레이에 환영 화면이 표시됩니다.</summary>

장바구니 화면을 생성하지 못했으며, [DISPLAY101](../../error-codes/DISPLAY101.mdx)로 기록됩니다. 판매를 계속 진행하세요. 다음에 장바구니가 변경되면 디스플레이에 반영됩니다.

</details>
