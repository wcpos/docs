**증상:** 웹 브라우저에서 판매하면 영수증 프린터가 매장 로고를 제외한 영수증 전체를 인쇄합니다. 결제 완료 화면의 **미리보기**에는 로고가 표시됩니다. 데스크톱 또는 모바일 앱에서 같은 영수증을 인쇄하면 로고가 포함됩니다.

**가장 빠른 방법: 데스크톱 앱에서 인쇄하세요.** 별도 설정 없이 로고가 인쇄되므로 계산대에 이미 설치되어 있다면 사용하세요. 브라우저에서 계속 인쇄하려면 아래 내용을 읽어보세요.

## 먼저 프린터 확인 {#test-print}

프린터가 이미지를 인쇄할 수 있는지 먼저 확인하세요. **설정 → 인쇄**로 이동하여 영수증 프린터 행의 **테스트 인쇄**를 누르세요. 기본 제공 **인쇄 대화상자** 행의 테스트 페이지에는 이미지가 없으므로 해당 행을 선택하지 마세요. 모든 행의 **테스트 인쇄**와 **추가 작업**은 같은 위치에 있으며, 아래 **인쇄 대화상자** 행에서 확인할 수 있습니다. 직접 추가한 프린터에는 두 버튼 사이에 **수정**도 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[6, -28], [30, 0]]} maxWidth={712} alt="설정의 인쇄 화면에 있는 프린터 목록: 테스트 인쇄 버튼과 추가 작업 버튼이 있는 기본 제공 인쇄 대화상자 행">

1. **테스트 인쇄** — 영수증 프린터에서 테스트 페이지를 인쇄합니다. 페이지의 **2 로고 (래스터)** 섹션에는 WCPOS 마크가 있습니다.
2. **추가 작업** — [지원 요청](#still-missing)에 사용할 **설정 보고서 복사**를 엽니다.

</JourneyShot>

- **WCPOS 마크는 인쇄되지만 매장 로고는 인쇄되지 않습니다.** 프린터는 이미지를 인쇄할 수 있습니다. 다음으로 [로고 주소를 확인](#fix)하세요.
- **테스트 페이지의 나머지 내용은 인쇄되지만 마크는 인쇄되지 않습니다.** 로고 주소를 변경하기 전에 [설정 마법사의 질문](./setup-wizard.mdx#troubleshoot)부터 확인하세요.

## 로고 주소 확인 {#fix}

1. 영수증 **미리보기**의 로고를 마우스 오른쪽 버튼으로 클릭하거나 길게 누른 다음 **새 탭에서 이미지 열기**를 선택하세요.
2. 해당 탭 주소의 `https://`와 그다음 `/` 사이에 있는 사이트 이름을 POS 주소 표시줄의 사이트 이름과 비교하세요. 예를 들면 다음과 같습니다:
   - POS 사이트: `shop.example.com`
   - 로고 사이트: `cdn.example.net`

   두 사이트 이름이 다릅니다.
3. 이름이 다르면 이것이 원인일 가능성이 높습니다. 웹사이트 관리자에게 아래 변경 사항 중 하나를 적용해 달라고 요청하세요.
4. 변경 후 POS를 새로고침하고 영수증을 다시 인쇄하세요. 사이트 이름이 같거나 로고가 여전히 누락되면 [여전히 로고가 없나요?](#still-missing)를 참고하세요.

<details>
<summary>웹사이트 관리자를 위한 해결 방법</summary>

다음 중 하나를 선택하세요:

- **자체 사이트의 로고를 사용하세요.** 매장 주소의 미디어 라이브러리에 로고를 업로드하고 해당 파일을 영수증 로고로 선택하세요.
- **로고를 제공하는 서버에서 헤더로 접근을 허용하세요.** 업로드 파일을 CDN에 유지해야 한다면 이미지 파일에 매장 주소를 허용하는 `Access-Control-Allow-Origin` 헤더를 추가하세요.

</details>

## 문제가 발생하는 이유 {#why-it-happens}

POS가 브라우저에서 영수증 프린터로 이미지를 직접 보내려면 이미지를 호스팅하는 웹사이트가 이를 허용해야 합니다. 데스크톱 및 모바일 앱은 로고를 직접 가져오므로 로고가 인쇄됩니다. **인쇄 대화상자**를 통해 인쇄한 영수증에도 로고가 표시됩니다.

<details>
<summary>웹사이트 관리자를 위한 자세한 설명</summary>

브라우저에서 POS는 영수증을 프린터로 보내기 전에 로고를 점으로 변환합니다. 브라우저는 매장 자체 미디어 라이브러리처럼 POS 페이지와 같은 주소에 있는 이미지에만 이 작업을 허용합니다. 다른 주소에 있는 이미지는 해당 서버의 허용이 필요하며, `Access-Control-Allow-Origin`이라는 헤더로 허용합니다. 이 헤더가 없으면 브라우저가 POS에 이미지를 전달하지 않으므로, 영수증 전체가 인쇄되지 않는 대신 로고만 빠진 채 인쇄됩니다.

다음과 같은 경우 로고를 다른 주소에서 가져옵니다:

- 이미지 CDN 또는 미디어 오프로드 플러그인이 자체 도메인에서 업로드 파일을 제공하는 경우
- 로고 주소와 POS 주소가 `www.` 유무만 다른 경우

</details>

## 여전히 로고가 없나요? {#still-missing}

로고 없이 영수증이 인쇄된 직후 **설정 → 인쇄**로 이동하여 프린터 행의 **추가 작업**을 열고 **설정 보고서 복사**를 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[28, 0]]} maxWidth={285} alt="프린터 행에서 열린 추가 작업 메뉴와 설정 보고서 복사 항목">

1. **추가 작업**
2. **설정 보고서 복사**

</JourneyShot>

보고서에는 현재 세션에서 발생한 앱의 최근 프린터 이벤트만 포함되므로 POS를 새로고침하기 전에 복사하세요. 로고 주소와 함께 메시지에 붙여 넣으세요.
