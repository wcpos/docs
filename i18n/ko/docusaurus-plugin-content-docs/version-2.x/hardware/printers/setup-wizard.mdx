앱에는 설정 마법사가 내장되어 있습니다. **프린터 추가**는 프린터를 검색하고 테스트 페이지를 인쇄한 뒤 제대로 나왔는지 묻습니다. 이 페이지에서 그 과정을 안내합니다. 테스트 페이지가 인쇄되지 않으면 [몇 가지 질문에 답하세요](#troubleshoot). 프린터 설정과 나중에 설정을 변경하는 방법은 [마지막 부분](#more-options)에 있습니다.

## 프린터 추가 {#add-a-printer}

먼저 프린터를 켜고 용지를 넣으세요. 패널을 여는 즉시 검색이 시작됩니다. 그런 다음 **설정 → 인쇄**로 이동하여 **프린터 추가**를 누르세요. **프린터** 아래에는 모든 POS 단말기에 기본으로 제공되는 **인쇄 대화 상자**가 이미 표시되어 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[124, 0], [119, 0]]} maxWidth={460} alt="설정의 인쇄 화면에 있는 프린터 목록 하단: 프린터 추가 버튼과 문제가 있나요? 링크">

1. **프린터 추가** — 설정 패널을 열고 즉시 프린터 검색을 시작합니다.
2. **문제가 있나요?** — [프린터 가이드](./index.mdx)를 엽니다.

</JourneyShot>

검색 중에는 패널에 검색 대상이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[41, -18], [126, -18], [160, -18], [134, -18]]} maxWidth={559} alt="프린터를 검색 중인 프린터 추가 패널: 프린터 검색 중, Wi-Fi 검색 진행 상황, 중지, USB 프린터 찾기, Bluetooth 프린터 찾기, IP 주소 입력 버튼">

1. **중지** — 검색을 종료합니다.
2. **USB 프린터 찾기** — Chrome 또는 Edge에서 케이블로 연결된 프린터를 고르는 브라우저 선택 창을 엽니다. 데스크톱 및 모바일 앱은 검색 과정에서 USB 프린터도 찾습니다. [앱별로 연결할 수 있는 프린터](./index.mdx#supported-printers-by-platform)를 참고하세요.
3. **Bluetooth 프린터 찾기** — Bluetooth 프린터 선택 창을 엽니다. 목록에 없다면 [Bluetooth 페어링](./bluetooth-pairing.mdx)을 참고하세요. 모바일 앱은 검색 과정에서 이미 Bluetooth 프린터를 찾으므로 이 버튼이 없습니다.
4. **IP 주소 입력** — Wi-Fi 또는 네트워크 프린터의 주소를 직접 입력합니다. [아래](#enter-address)를 참고하세요.

</JourneyShot>

## 검색 결과 {#what-it-finds}

발견한 프린터마다 카드가 표시됩니다. 제목에는 검색 결과에 따라 **프린터를 찾았습니다**, 여러 대일 때는 **어떤 프린터인가요?**, 또는 **영수증 프린터가 아닌 사무용 프린터입니다**, **프린터를 찾을 수 없습니다**가 표시됩니다.

프린터 카드에 **준비 완료** 또는 **테스트 필요**가 표시되면 [테스트 페이지 인쇄](#test-page)로 넘어가세요.

카드에는 다음 네 가지 배지 중 하나가 표시됩니다.

- **준비 완료** — 앱에서 이 프린터로 인쇄할 수 있습니다. **테스트 페이지 인쇄**를 누르세요.
- **테스트 필요** — 앱에서 인쇄할 수 있을 것으로 판단했지만, 테스트 페이지로 확인해야 합니다.
- **사무용 프린터** — 영수증 프린터가 아닌 사무용 또는 잉크젯 프린터입니다. 이 카드는 선택하거나 테스트할 수 없습니다. 이 프린터로 영수증을 인쇄하려면 내장 **인쇄 대화 상자**를 사용합니다.
- **연결 없음** — 해당 주소에서 앱이 연결할 수 있는 프린터의 응답이 없었습니다.

검색 결과가 없다면 [프린터를 찾을 수 없음](#not-found)을 참고하세요.

## 테스트 페이지 인쇄 {#test-page}

{/* reshoot: needs a real printer on the network (see reshoot.md) */}

프린터 카드를 선택하고 **테스트 페이지 인쇄**를 누르세요(여러 대인 경우 **테스트 페이지 인쇄 대상**과 프린터 이름이 표시됩니다). 앱에서 용지를 확인하는 동안 패널에 **용지 너비 확인 중…** 이 표시됩니다. 너비를 확인할 수 없으면 먼저 **용지 너비**에서 **58 mm** 또는 **80 mm**를 선택할 수 있습니다.

그러면 패널에 **테스트 페이지가 인쇄되었나요?** 라는 질문이 표시됩니다. 질문 아래의 **테스트 페이지** *n* **·** *n* **자/줄**은 현재 사용 중인 너비를 나타냅니다. 답하기 전에 테스트 페이지의 **열 눈금자**를 확인하세요. 이 숫자 행은 오른쪽 가장자리에 딱 맞게 끝나야 합니다. 두 번째 줄로 넘어가거나 가장자리에 못 미치면 너비가 맞지 않는 것입니다. 결과에 맞는 답을 선택하세요.

### 예, 올바르게 인쇄되었습니다 {#test-page-ok}

프린터가 저장됩니다. 패널에 *이름* **설정이 완료되었습니다**가 표시된 다음, **기본 프린터입니다.** 또는 **영수증이 여기에서 인쇄됩니다.** 가 표시됩니다. **완료**를 누르세요.

### 인쇄되었지만 눈금자가 맞지 않습니다 {#test-page-ruler}

**프린터에 어떤 용지가 들어 있나요?** 에서 너비를 선택하면 테스트 페이지가 다시 인쇄됩니다.

- **32 — 58 mm 용지**
- **42 — 80 mm, 구형 프린터**
- **48 — 80 mm, 대부분의 Epson 및 Star**
- **64 — 80 mm, 작은 글꼴**

[영수증 너비](./receipt-width.mdx)를 참고하세요.

### 아무것도 나오지 않았습니다 {#test-page-nothing}

패널에 **인쇄된 내용 없음**과 함께 용지나 보안 인쇄 등 예상 원인이 한 줄로 표시됩니다. 문제를 해결한 다음 아래 옵션을 사용하세요.

- **다시 시도** — 테스트 페이지를 다시 인쇄합니다.
- **테스트 없이 저장** — 테스트 여부와 관계없이 프린터를 저장합니다. 현재 프린터가 꺼져 있거나 용지가 없지만 설정이 올바른 것을 알고 있을 때 사용하세요. 나중에 해당 프린터 행의 **테스트 인쇄**로 테스트하세요.
- **처음부터 다시 시작**, **설정 보고서 복사**(지원 요청용), **프린터 가이드 열기**.

여전히 아무것도 나오지 않나요? [몇 가지 질문에 답하세요](#troubleshoot).

## 프린터를 찾을 수 없음 {#not-found}

검색 결과가 없으면 패널이 다음과 같이 표시됩니다. 무엇을 해야 할지 모르겠다면 [몇 가지 질문에 답하세요](#troubleshoot).

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[104, -18], [126, -18], [160, -18], [134, -18], [95, 18], [162, 0]]} maxWidth={559} alt="검색 결과가 없는 프린터 추가 패널: 프린터를 찾을 수 없습니다, 다시 검색, 한 줄 안내, USB 프린터 찾기, Bluetooth 프린터 찾기, IP 주소 입력, 추가 옵션 버튼, 프린터 가이드 열기">

1. **다시 검색** — 프린터를 켜거나 연결한 후 다시 검색합니다.
2. **USB 프린터 찾기** — 케이블로 연결된 프린터를 찾습니다.
3. **Bluetooth 프린터 찾기** — Bluetooth 프린터를 찾습니다.
4. **IP 주소 입력** — 검색에서 찾지 못한 네트워크 프린터에 사용합니다. [아래](#enter-address)를 참고하세요.
5. **추가 옵션** — 테스트 페이지를 인쇄하기 전에 이름, 용지 너비, 금전함을 설정합니다. [추가 옵션](#more-options)을 참고하세요.
6. **프린터 가이드 열기** — [프린터 가이드](./index.mdx)를 엽니다.

</JourneyShot>

### 주소 직접 입력 {#enter-address}

검색에서 Wi-Fi 또는 네트워크 프린터를 찾지 못했다면 **IP 주소 입력**을 누르세요. 주소는 프린터의 상태 시트에 있습니다. 대부분의 Epson 프린터에서는 용지 덮개를 열고 **급지**를 1초 동안 누른 뒤 덮개를 닫으면 상태 시트가 인쇄됩니다.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[351, 0], [64, 0], [133, -18], [82, 18]]} maxWidth={559} alt="프린터 IP 주소 입력: IP 주소 및 포트 필드, 이 주소 확인, 취소, 상태 시트 안내, 다시 검색, 프린터 가이드 열기">

1. **IP 주소** — `192.168.1.100`과 같이 상태 시트에 표시된 주소입니다. 주소가 바뀌지 않도록 프린터에 [고정 주소](./network-address.mdx)를 지정하세요.
2. **포트** — 자동으로 입력됩니다.
3. **이 주소 확인** — 프린터 정보를 조회하여 카드로 표시합니다. **준비 완료** 또는 **테스트 필요** 카드에서 [테스트 페이지](#test-page)로 진행할 수 있습니다.
4. **다시 검색** — 검색으로 돌아갑니다.

</JourneyShot>

- **브라우저에서는** 프린터 자체의 웹 포트를 사용합니다. HTTPS 쇼핑몰에서는 Epson은 **8043**, Star는 **443**을 사용합니다(일반 HTTP에서는 8008과 80).
- **데스크톱 앱**은 Epson에는 ePOS-Print를 통해 인쇄하고(**443**부터 시도한 뒤 8043, 80, 8008 순서), 다른 프린터에는 **9100**으로 인쇄합니다. **모바일 앱**은 **9100**으로 인쇄합니다.

</AccordionItem>

1. **프린터 카드** — 주소, 제조사, 연결 방식이 표시됩니다. 여기서 **연결 없음**은 해당 주소에서 응답이 없었다는 뜻입니다. 주소가 맞는지, 프린터가 이 POS 단말기와 같은 네트워크에 있는지 확인하세요. 브라우저를 사용한다면 [권한 및 인증서](./browser-permissions.mdx)도 참고하세요.
2. **IP 주소 입력** — 주소를 다시 입력해 봅니다.

</JourneyShot>

**설정 → 인쇄**로 이동하여 **프린터 추가**를 누르세요. 앱이 네트워크에서 프린터를 검색합니다. 프린터를 찾지 못하면 **IP 주소 입력**을 누르고 주소를 입력한 뒤 **이 주소 확인**을 누르세요. 그런 다음 프린터 카드를 선택하고 **테스트 페이지 인쇄**를 누르세요.

IP 주소를 확인하려면 프린터의 네트워크 상태 시트를 인쇄하세요.

- **Star:** 프린터가 켜진 상태에서 **급지** 버튼을 약 5초 동안 누르세요.

기본 사항에 문제가 없는데도 인쇄되지 않으면 대개 다음 중 하나가 원인입니다.

**주소가 틀렸거나 바뀌었습니다.** 상태 시트의 주소와 앱의 주소가 일치하는지 확인하세요. 다른 프린터의 주소를 잘못 사용하는 경우가 있습니다. DHCP를 사용하는 프린터는 재시작하면 주소가 바뀔 수 있으므로 공유기에서 **DHCP 예약**을 설정하세요. `169.254`로 시작하는 주소는 프린터가 네트워크에 연결되지 못했다는 뜻입니다. [고정 주소](./network-address.mdx)를 참고하세요.

**Epson이 한 번 인쇄한 뒤 멈췄습니다.** 프린터를 껐다가 다시 켜세요. [한 번 인쇄한 뒤 멈춤](./printed-once-then-stopped.mdx)을 참고하세요.

**Epson 보안 인쇄가 켜져 있습니다.** 프린터가 일반 작업을 거부합니다. [보안 인쇄](./secure-printing.mdx)를 참고하세요.

**Epson이 인쇄하지 않지만 웹 페이지는 정상적으로 열립니다.** Server Direct Print가 프린터를 점유하고 있을 수 있습니다. [Server Direct Print](./server-direct-print.mdx)를 참고하세요.

**POS 단말기 두 대가 프린터 한 대를 사용합니다.** 많은 Star 네트워크 프린터는 기본적으로 한 번에 하나의 연결만 허용하므로 두 번째 POS 단말기에서는 시간 초과가 발생합니다. 프린터의 웹 설정에서 **9100 다중 세션**을 켜세요.

**프린터가 다른 프로토콜만 허용합니다.** 모바일 앱과, Star 등 Epson 이외의 프린터를 사용하는 데스크톱 앱은 **포트 9100의 raw TCP**로 인쇄합니다. 브라우저에서 프린터 설정 페이지를 열고 **raw / 포트 9100** 인쇄가 켜져 있는지 확인하세요. LPR, IPP 또는 WSD만 사용하도록 설정된 프린터는 작업을 받지 못합니다.

**Wi-Fi에 연결되지 않거나 자꾸 끊깁니다.** 영수증 프린터는 보통 **2.4 GHz만 지원**합니다. 5 GHz 전용 네트워크가 아닌 2.4 GHz 네트워크에 연결하세요. 고정된 POS 단말기에서는 네트워크 케이블을 사용하는 것이 확실한 해결 방법입니다.

**그날 첫 인쇄가 실패합니다.** 프린터의 네트워크 카드가 절전 상태였다가 첫 작업으로 깨어난 것입니다. 다시 인쇄하세요. 고정된 POS 단말기에서는 네트워크 케이블을 사용하는 것이 확실한 해결 방법입니다.

**iPhone, iPad 또는 Android에서 프린터를 찾을 수 없습니다.** 앱에 로컬 네트워크 접근 권한이 필요합니다. [iPad 및 iPhone](./ios-local-network.mdx) 또는 [Android 권한](./android-permissions.mdx)을 참고하세요.

**웹 브라우저**에서 앱은 HTTP 또는 HTTPS를 통해 프린터의 내장 웹 서버와만 통신할 수 있습니다. **HTTPS** 쇼핑몰에서는 기본적으로 프린터의 보안 포트(Epson은 **8043**, Star는 **443**)를 사용하며, 프린터에 브라우저가 신뢰하는 인증서가 있어야 작동합니다.

가장 흔히 막히는 부분이며, 브라우저에서는 해결할 수 없는 경우가 많습니다. 이유와 해결 방법은 다음과 같습니다.

프린터의 **상태 시트**를 인쇄하여 SSL/TLS 항목을 확인하세요. 인증서가 없으면 인증서를 생성하기 전까지 HTTPS 인쇄를 사용할 수 없습니다. 브라우저가 프린터 자체 인증서를 신뢰하도록 모든 기기에서 `https://<printer-ip>` 를 한 번 열고 인증서를 수락해야 합니다. 다음 안내를 참고하세요: [권한 및 인증서](./browser-permissions.mdx).

작업을 보냈지만 인쇄되지 않는다면 브라우저가 차단했을 가능성이 큽니다. 프린터는 HTTP를 사용하지만 쇼핑몰은 HTTPS를 사용하거나(‘혼합 콘텐츠’ 차단), 보안 포트에 인증서가 없을 수 있습니다.

웹 앱은 Epson의 **ePOS-Print** 또는 Star의 **WebPRNT**와 같은 **내장 웹 서버**를 통해서만 프린터에 접속하므로 프린터 설정에서 해당 서비스가 켜져 있는지 확인하세요. Epson의 ‘intelligent’ 및 **-NT** 모델과 Star **WebPRNT** 모델에만 이 서버가 있습니다. 해당 기능이 없는 프린터에는 브라우저로 접속할 수 없습니다.

**확실한 해결 방법은 데스크톱 앱을 사용하는 것입니다**. 데스크톱 앱은 브라우저의 인증서 및 권한 제한 없이 프린터에 접속합니다. Epson은 ePOS-Print 서비스의 HTTPS 포트 443부터 시도하고, Star는 포트 9100을 사용합니다. 데스크톱 앱에 같은 프린터를 추가하세요.

7. **프린터 언어** — Epson과 대부분의 다른 제조사는 **ESC/POS**, Star는 **StarPRNT** 또는 **Star Line Mode**를 사용합니다.
8. **테스트 인쇄** — 현재 설정으로 테스트 페이지를 인쇄합니다.

</JourneyShot>

<AccordionItem question="연결 및 고급 설정">

- **IP 주소** 및 **포트** — 네트워크 주소입니다. 확인 중에는 패널에 **프린터 감지 중...** 이 표시되고, 이후 **감지됨:** 과 제조사가 표시됩니다.
- **네트워크 검색** — 네트워크에서 프린터를 찾습니다. 발견한 프린터마다 **발견됨:** 과 주소가 표시되며 **이 프린터 사용**을 누르면 필드가 채워집니다. 브라우저에서는 사용할 **웹 인쇄 엔드포인트**가 패널에 표시됩니다. 브라우저는 포트 9100으로 인쇄할 수 없습니다.
- **프린터 언어** — 프린터가 이해하는 명령입니다. Epson과 대부분의 다른 제조사는 **ESC/POS**, Star는 **StarPRNT** 또는 **Star Line Mode**를 사용합니다. 잘못 선택하면 엉뚱한 문자가 인쇄됩니다.
- **용지 너비**, **영수증 언어**, **용지 자동 절단**, **금전함 자동 열기** 및 해당 **금전함 커넥터**, **기본값으로 설정**.
- **영수증을 이미지로 인쇄** — 아랍어, 히브리어, 태국어처럼 프린터가 표현할 수 없는 문자에 사용합니다. 텍스트보다 느리고 작업 크기가 커집니다.

2. **용지 너비** — 한 줄당 문자 수입니다. [영수증 너비](./receipt-width.mdx)를 참고하세요.
