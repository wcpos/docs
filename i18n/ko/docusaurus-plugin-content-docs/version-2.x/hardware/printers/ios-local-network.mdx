**증상:** iPad 또는 iPhone에서 **프린터 추가**를 실행하면 **프린터를 찾을 수 없음**으로 끝나거나, 이전에 인쇄되던 Wi-Fi 프린터가 작동하지 않습니다. 같은 Wi-Fi에 연결된 컴퓨터에서는 해당 프린터로 계속 인쇄할 수 있습니다.

먼저 WCPOS에 로컬 네트워크 사용 권한이 있는지 확인하세요.

<details>
<summary>권한 거부가 프린터 전원 꺼짐과 같은 증상을 보이는 이유</summary>

WCPOS가 처음 프린터를 검색하면 iOS가 로컬 네트워크의 기기를 찾아 연결하도록 허용할지 묻습니다. 질문 아래에는 다음과 같이 표시됩니다: *WCPOS는 카드 리더기와 영수증 프린터에 연결하기 위해 로컬 네트워크를 사용합니다.*

누군가 **허용 안 함**을 누르면 그때부터 iOS는 WCPOS의 모든 Wi-Fi 프린터 접근을 차단합니다. 검색, 주소 확인, 모든 영수증 인쇄가 차단됩니다. iOS가 권한 거부 사실을 앱에 알려주지 않으므로 WCPOS는 프린터가 꺼져 있을 때와 같은 화면을 표시합니다:

- 검색 후 **프린터를 찾을 수 없음**과 함께 *프린터가 켜져 있고 같은 Wi-Fi에 연결되어 있는지, 또는 Bluetooth 설정에서 페어링되어 있는지 확인하세요.* 메시지가 표시됩니다.
- **이 주소 확인**을 누르면 프린터 카드에 **연결 안 됨**이 표시됩니다.
- 이전에 저장한 프린터에서 **테스트 인쇄**가 실패합니다.

Bluetooth 프린터는 이 권한을 사용하지 않습니다. Bluetooth 프린터가 나타나지 않으면 [Bluetooth 영수증 프린터 페어링](./bluetooth-pairing.mdx)을 참고하세요.

</details>

## 권한 켜기 {#turn-the-permission-on}

1. iPad 또는 iPhone의 **설정** 앱을 여세요.
2. **개인정보 보호 및 보안 → 로컬 네트워크**로 이동하세요.
3. **WCPOS** 옆의 스위치를 켜세요.
4. 앱 전환기에서 WCPOS를 위로 밀어 완전히 종료한 다음 다시 여세요.

같은 스위치가 **설정** 앱의 WCPOS 전용 페이지에도 있습니다. 아래로 스크롤하여 **WCPOS**를 선택하고 **로컬 네트워크**를 켜세요.

<details>
<summary>목록에 WCPOS가 없나요?</summary>

iOS는 WCPOS가 프린터를 한 번 검색한 후에만 목록에 WCPOS를 추가합니다. WCPOS에서 **설정 → 인쇄**를 열고 **프린터 추가**를 누르세요. iOS가 로컬 네트워크의 기기 검색을 허용할지 물으면 **허용**을 누르세요. 검색이 여전히 **프린터를 찾을 수 없음**으로 끝나면 **다시 검색**을 누르세요. WCPOS가 권한을 요청한 뒤에는 목록에 표시됩니다.

</details>

## Wi-Fi 확인 {#also-check}

- iPad가 프린터와 같은 네트워크인 **매장 Wi-Fi**에 연결되어 있는지 확인하세요. 게스트 네트워크나 모바일 데이터 연결은 안 됩니다. [프린터에 고정 주소 지정](./network-address.mdx)을 참고하세요.
- Wi-Fi가 켜져 있는지 확인하세요. Wi-Fi가 꺼져 있으면 권한 설정과 관계없이 Wi-Fi 프린터에 연결할 수 없습니다.

## 정상 작동 확인 {#check-it-worked}

WCPOS에서 **설정 → 인쇄**를 여세요:

- **이미 저장한 프린터:** 옆의 **테스트 인쇄**를 누르세요.
- **아직 저장하지 않은 프린터:** **프린터 추가**를 누르세요. 프린터가 나타나면 카드 아래의 **테스트 페이지 인쇄**를 누르고 인쇄 결과에 답하세요. 검색 결과가 없으면 [여전히 검색되지 않는 경우](#if-the-scan-finds-nothing)를 참고하세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[60, 0], [0, -38], [0, -38], [140, 0], [190, 0]]} alt="WCPOS 설정의 인쇄 화면: 각 행에 테스트 인쇄 버튼과 추가 작업 메뉴가 있는 프린터 목록, 프린터 추가 버튼과 문제가 있나요? 링크">

1. **인쇄** — 이 기기의 프린터를 관리하는 곳입니다.
2. **테스트 인쇄** — 저장된 모든 프린터의 행에 있습니다. Wi-Fi 프린터 옆의 버튼을 누르세요. 이제 인쇄되면 완료된 것입니다.
3. **추가 작업** — 해당 행의 메뉴입니다. 여기에 **설정 보고서 복사**가 있습니다. [아직 해결되지 않았나요?](#still-stuck)를 참고하세요.
4. **프린터 추가** — 설정 패널을 열고 즉시 검색을 시작합니다. [영수증 프린터](./index.mdx)를 참고하세요.
5. **문제가 있나요?** — 프린터 안내를 엽니다.

</JourneyShot>

## 여전히 검색되지 않는 경우 {#if-the-scan-finds-nothing}

iPad 또는 iPhone에서는 Wi-Fi, Bluetooth, USB를 통해 **Epson 및 Star** 프린터를 검색합니다. 다른 제조사의 Wi-Fi 프린터는 나타나지 않으며, 일부 네트워크는 검색을 차단합니다. 이 경우 주소로 프린터를 확인하세요:

1. 프린터의 상태 페이지를 인쇄하고 거기에 표시된 IP 주소를 확인하세요. 방법은 [프린터에 고정 주소 지정](./network-address.mdx)에 나와 있습니다.
2. 검색 화면에서 **IP 주소 입력**을 누르세요. 검색이 중지되고 주소 입력 양식이 열립니다.
3. 주소를 입력하고 **이 주소 확인**을 누르세요.
4. 프린터 카드에 **준비됨** 또는 **테스트 필요**가 표시되면 **테스트 페이지 인쇄**를 누르고 인쇄 결과에 답하세요. **연결 안 됨**이 표시되면 iPad가 해당 주소에 연결할 수 없는 것입니다. [Wi-Fi](#also-check)와 새로 인쇄한 상태 페이지의 주소를 확인하세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[110, -38], [40, -38], [-38, 0], [0, 40], [165, 0]]} alt="프린터 추가 패널의 프린터 IP 주소 입력 화면: IP 주소 및 포트 입력란, 이 주소 확인, 취소, 상태 페이지 안내, 다시 검색, 프린터 안내 열기">

1. **IP 주소** — 프린터 상태 페이지에 표시된 주소입니다.
2. **포트** — 처음에는 **9100**으로 설정됩니다. 확인 과정에서 프린터가 응답하는 포트를 찾으므로 변경할 일은 거의 없습니다.
3. **이 주소 확인** — 프린터에 기기 정보를 요청합니다. 응답하면 카드에 **준비됨** 또는 **테스트 필요**가 표시되고 아래에 **테스트 페이지 인쇄**가 나타납니다. 응답이 없으면 **연결 안 됨**이 표시됩니다.
4. **다시 검색** — 검색 화면으로 돌아갑니다.
5. **프린터 안내 열기** — [영수증 프린터](./index.mdx)를 엽니다.

</JourneyShot>

## 아직 해결되지 않았나요? {#still-stuck}

설정 보고서를 보내주세요. **설정 보고서 복사**는 설정 패널의 **아무것도 인쇄되지 않음** 화면과 **설정 → 인쇄**의 프린터 행에 있는 **추가 작업** 메뉴에 있습니다. iPad 또는 iPhone에서는 공유 시트가 열립니다. 이메일로 보내거나 메시지에 복사해 넣으세요.

보고서에는 앱 버전, iOS 버전, 프린터 설정, 앱의 최근 프린터 로그가 포함됩니다. 설정 패널에서 생성하면 확인 과정에서 발견한 내용도 포함됩니다.
