Windows의 데스크톱 앱에서 USB 영수증 프린터를 사용하려면 먼저 Windows에 설치하세요. 앱은 Windows에 설치된 USB 프린터만 찾을 수 있습니다. 그런 다음 POS에 추가하세요.

1. [Windows에 프린터를 설치하세요](#do-this).
2. [POS에 추가하세요](#add-in-pos).

Windows의 데스크톱 앱에서 다음과 같은 문제가 있을 때도 이 페이지를 참고하세요.

- 프린터가 연결되어 있고 전원이 켜져 있는데 **프린터 추가**에 **프린터를 찾을 수 없음**이 표시됩니다. [프린터를 찾을 수 없음](#no-printer-found)을 참고하세요.
- 이전 버전에서 추가한 프린터에 **Windows에서는 이 프린터를 설치된 프린터로 추가하세요.** 라는 메시지가 표시됩니다. [이전 버전에서 추가한 프린터](#earlier-version)를 참고하세요.
- 테스트 페이지에 [이상한 문자와 기호](#stray-symbols)가 나오거나 [아무것도 나오지 않습니다](#nothing-came-out).

## Windows에 프린터 설치하기 {#do-this}

먼저 Windows에 이미 설치되어 있는지 확인하세요.

1. 프린터를 연결하고 전원을 켜세요. 제조사가 Windows 드라이버나 설치 프로그램을 제공한다면 지금 실행하세요.
2. Windows에서 **설정 → Bluetooth 및 장치 → 프린터 및 스캐너**를 여세요.
3. 목록에 프린터가 있다면 [POS에 추가하기](#add-in-pos)로 진행하세요. 없다면 **프린터 또는 스캐너 추가** 옆의 **장치 추가**를 선택하세요. Windows가 프린터를 찾아 추가한 경우에도 [POS에 추가하기](#add-in-pos)로 진행하세요.

Windows에 여전히 표시되지 않으면 Windows에 포함된 기본 드라이버인 **Generic / Text Only**로 직접 추가하세요.

<details>
<summary>프린터 수동 추가</summary>

1. **수동으로 추가**를 선택한 다음 **수동 설정으로 로컬 프린터 또는 네트워크 프린터 추가**를 선택하세요.
2. **기존 포트 사용**에서 프린터의 USB 포트를 선택하세요. 이름이 USB001처럼 **USB**로 시작합니다.
3. 드라이버 선택 시 제조사는 **Generic**, 프린터는 **Generic / Text Only**를 선택하세요.
4. *영수증 프린터*처럼 계산대에서 알아볼 수 있는 이름을 지정하고 마무리하세요.

</details>

<details>
<summary>Windows 10의 경우</summary>

**설정 → 장치 → 프린터 및 스캐너**에서 **프린터 또는 스캐너 추가**를 선택하세요. Windows 11의 **수동으로 추가** 항목은 Windows 10에서 **원하는 프린터가 목록에 없습니다**로 표시됩니다.

</details>

## POS에 추가하기 {#add-in-pos}

1. 데스크톱 앱에서 **설정 → 인쇄**로 이동하여 **프린터 추가**를 누르세요. 검색이 자동으로 시작되어 **USB, Bluetooth 및 Wi-Fi** 프린터를 찾습니다.
2. Windows에서 프린터에 지정한 이름이 있는 카드를 선택하세요. **설치된 프린터** 배지가 표시되어 있습니다. 프린터가 여러 대면 패널에 **어느 것이 사용 중인 프린터인가요?** 라는 질문이 표시되며 자동으로 선택되지 않습니다.
3. **테스트 페이지 인쇄**를 누르세요. 패널에 **테스트 페이지가 인쇄되었나요?** 라는 질문이 표시됩니다.
4. 페이지가 올바르게 인쇄되었다면 **예, 올바르게 인쇄되었습니다**를 선택하세요. 프린터가 저장되며 패널에 *이름*과 **설정 완료**가 표시됩니다. **완료**를 누르면 **설정 → 인쇄**에 해당 프린터의 행이 생깁니다.

페이지가 잘못 인쇄되었거나 전혀 나오지 않았다면 [문제가 생긴 경우](#goes-wrong)를 참고하세요. 다른 응답에 관한 설명은 [테스트 페이지 인쇄](./setup-wizard.mdx#test-page)에 있습니다.

## 문제가 생긴 경우 {#goes-wrong}

### 프린터를 찾을 수 없음 {#no-printer-found}

먼저 Windows의 **프린터 및 스캐너**를 확인하세요. 프린터가 목록에 없다면 [Windows에 설치](#do-this)한 다음 **다시 검색**을 누르세요. 목록에 있는데도 앱이 찾지 못하면 [아직 해결되지 않았나요?](#still-stuck)를 참고하세요.

<details>
<summary>프린터를 찾을 수 없음 패널의 다른 버튼</summary>

1. **다시 검색** — 다시 검색합니다. Windows에 프린터를 설치한 후 누르세요.
2. **Bluetooth 프린터 찾기** — 페어링이 필요 없는 Bluetooth 프린터용입니다.
3. **IP 주소 입력** — 검색에서 찾지 못한 네트워크 프린터용입니다.
4. **추가 옵션** — 테스트 페이지를 인쇄하기 전에 이름, 용지 너비, 서랍을 설정합니다. [추가 옵션](./setup-wizard.mdx#more-options)을 참고하세요.
5. **프린터 안내 열기** — [프린터 안내](./index.mdx)를 엽니다.

</details>

### 이전 버전에서 추가한 프린터 {#earlier-version}

프린터로 인쇄할 때 **Windows에서는 이 프린터를 설치된 프린터로 추가하세요.** 라는 메시지가 표시됩니다. 이전 버전에서는 직접 연결하는 USB 프린터로 저장했지만, 이제 Windows에서 앱은 Windows에 등록된 항목을 통해서만 USB 프린터에 연결합니다. **설정 → 인쇄**에서 프린터의 **추가 작업** 메뉴를 열고 **삭제**를 선택하세요. 그런 다음 **프린터 추가**로 다시 추가하면서 **설치된 프린터** 카드를 선택하세요.

### 이상한 문자와 기호 {#stray-symbols}

#### 프린터를 추가하는 중인 경우 {#symbols-during-setup}

1. 용지가 인쇄되었더라도 **아무것도 나오지 않았습니다**를 선택하세요. 패널에는 기호가 인쇄된 경우를 위한 응답이 없으며, 이 항목을 선택하면 **처음부터 다시 시작**과 **테스트 없이 저장**이 나타납니다.
2. 선택한 카드의 이름을 확인하세요.
   - 사무용 프린터 등 다른 프린터인가요? 해당 프린터는 영수증 명령을 해석할 수 없습니다. **처음부터 다시 시작**을 누르고 영수증 프린터 항목을 선택하세요.
   - 사용 중인 영수증 프린터인가요? **테스트 없이 저장**을 누른 다음 [언어를 수정하세요](#symbols-saved).

#### 이미 저장된 프린터인 경우 {#symbols-saved}

1. **설정 → 인쇄**에서 해당 행의 이름을 확인하세요. 다른 프린터라면 **프린터 추가**를 누르고 영수증 프린터 항목을 선택하세요.
2. 사용 중인 영수증 프린터가 맞다면 **프린터 언어** 설정이 프린터와 일치하지 않을 수 있습니다. 해당 행에서 **편집**을 누르세요.
3. **프린터 언어**를 프린터 설명서에 명시된 언어로 설정하세요. Star 프린터는 **StarPRNT** 또는 **Star Line Mode**를 사용합니다. Epson 프린터는 대부분의 다른 제조사와 마찬가지로 **ESC/POS**를 사용합니다.
4. 해당 행에서 **테스트 인쇄**를 누르세요. Star 프린터가 계속 기호를 인쇄하면 다른 Star 언어로 설정하고 다시 테스트하세요.
5. 모든 언어에서 기호가 인쇄되나요? [지원되는 영수증 프린터](./supported-printers.mdx)에서 모델을 확인한 다음 [아직 해결되지 않았나요?](#still-stuck)를 참고하세요.

### 아무것도 나오지 않음 {#nothing-came-out}

#### 프린터를 추가하는 중인 경우 {#nothing-during-setup}

1. **아무것도 나오지 않았습니다**를 선택하세요.
2. 선택한 카드의 이름을 확인하세요. 다른 프린터라면 **처음부터 다시 시작**을 누르고 영수증 프린터 항목을 선택하세요.
3. 사용 중인 프린터가 맞다면 패널에 **케이블과 프린터 전원이 켜져 있는지 확인한 후 다시 시도하세요.** 라는 메시지가 표시됩니다. 안내대로 확인한 다음 **다시 시도**를 누르세요.

#### 이미 저장된 프린터인 경우 {#nothing-saved}

1. **설정 → 인쇄**에서 해당 행의 이름을 확인하세요. 다른 프린터라면 **프린터 추가**를 누르고 영수증 프린터 항목을 선택하세요.
2. 사용 중인 프린터가 맞다면 케이블과 프린터 전원이 켜져 있는지 확인한 다음 해당 행의 **테스트 인쇄**를 누르세요.

#### 여전히 아무것도 나오지 않음 {#windows-test-page}

Windows의 **프린터 및 스캐너**에서 해당 프린터 항목을 열고 Windows 자체 테스트 페이지를 인쇄하세요. Windows에서도 인쇄하지 못한다면 Windows와 프린터 사이의 케이블, 포트 또는 드라이버에 문제가 있습니다. Windows에서는 인쇄되지만 POS에서는 여전히 인쇄되지 않으면 [아직 해결되지 않았나요?](#still-stuck)를 참고하세요.

### 웹 앱에서 USB 프린터 찾기 실패 {#web-app}

Windows의 웹 앱에서는 **USB 프린터 찾기**로 USB 프린터에 접근하지 못하는 경우가 많습니다. 대신 데스크톱 앱을 사용하세요. [Windows에 프린터를 설치](#do-this)한 다음 [POS에 추가하세요](#add-in-pos).

## Windows에서 앱이 인쇄하는 방식 {#why-it-happens}

데스크톱 앱은 Windows에 설치한 프린터로 인쇄하므로 해당 프린터를 선택하세요. 모델이 영수증 명령을 해석할 수 있는지는 [지원되는 영수증 프린터](./supported-printers.mdx)에서 확인할 수 있습니다.

<details>
<summary>Windows에 프린터를 설치해야 하는 이유</summary>

Windows는 USB 프린터에 자체 드라이버나 제조사 드라이버를 적용하며, 데스크톱 앱은 케이블로 직접 전송하는 대신 Windows에 등록된 프린터 항목을 통해 인쇄합니다. 앱은 각 영수증을 프린터 명령으로 전송하고 Windows는 이를 그대로 프린터에 전달하므로 드라이버가 영수증 형식을 바꾸지 않습니다.

</details>

<details>
<summary>검색 목록에 표시되는 Windows 프린터</summary>

**Microsoft Print to PDF**와 **팩스** 같은 Windows 자체 항목을 제외하고 Windows에 설치된 모든 프린터가 표시됩니다. Windows에 설치된 사무용 프린터도 동일한 형태로 표시되므로 이름을 보고 선택하세요. Windows에서 페어링한 Bluetooth 프린터도 같은 방식으로 설치된 프린터로 표시됩니다.

</details>

## 아직 해결되지 않았나요? {#still-stuck}

**인쇄되지 않음** 패널 또는 **설정 → 인쇄**에 있는 프린터의 **추가 작업** 메뉴에서 **설정 보고서 복사**를 누르세요. 보고서를 메시지에 붙여 넣으세요. 보고서에는 앱이 인쇄를 보낸 Windows 항목의 이름이 포함되어 있습니다.
