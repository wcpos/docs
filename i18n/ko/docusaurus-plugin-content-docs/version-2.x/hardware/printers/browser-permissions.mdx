Epson 또는 Star 프린터의 전원이 켜져 있고 같은 네트워크에 연결되어 있는데도 브라우저 탭의 POS에서 접근할 수 없다면 [다음 순서로 해결하세요](#fix-in-order)부터 시작하세요. 데스크톱 앱에는 이 조치가 필요하지 않습니다.

## 나타나는 증상 {#symptom}

프린터의 전원이 켜져 있고 같은 네트워크에 연결되어 있는데도 **설정 → 인쇄 → 프린터 추가** 에서 검색 결과가 없거나(**프린터를 찾을 수 없습니다**), 프린터 주소를 입력하면 카드에 **연결 없음** 이라고 표시됩니다. 또는 같은 프린터가 데스크톱 앱에서는 인쇄되지만 브라우저 탭에서는 인쇄되지 않습니다.

테스트 페이지 인쇄에 실패하면 앱에 **앱의 프린터 접근이 허용되지 않았습니다. 시스템 설정에서 허용한 후 다시 시도하세요.** 라고 표시될 수 있습니다. 브라우저에서는 브라우저가 프린터에 접근하지 못했다는 뜻입니다. 프린터의 전원이 켜져 있고 주소가 올바른지 확인한 다음 아래 해결 방법을 순서대로 진행하세요. 두 화면의 항목은 [아래에서 설명합니다](#on-screen).

## 다음 순서로 해결하세요 {#fix-in-order}

Safari나 Firefox에서는 먼저 [해당 브라우저에서 가능한 방법](#safari-and-firefox)을 확인하세요. Chrome이나 Edge에서는 다음과 같이 진행하세요.

1. [로컬 네트워크 접근을 허용](#allow-local-network-access)한 다음 다시 확인하세요.
2. 여전히 실패하면 프린터의 **포트** 를 확인하세요. 저장된 프린터는 **프린터 편집** 에서, 새로 추가하는 프린터는 **IP 주소 입력** 에서 확인할 수 있습니다. 포트를 보면 POS가 HTTPS를 사용하는지 일반 HTTP를 사용하는지 알 수 있습니다.

   | 프린터 | HTTPS 포트 | HTTP 포트 |
   |---|---|---|
   | Epson | **8043** 또는 **443** | **8008** 또는 **80** |
   | Star | **443** | **80** |

   그런 다음 해당하는 절차를 따르세요.

   - **HTTPS 포트:** [프린터의 인증서를 신뢰하도록 설정](#the-printers-certificate)한 다음 다시 확인하세요.
   - **HTTP 포트:** [프린터가 HTTP를 사용하는 경우](#mixed-content)를 참고하세요.

3. 여전히 **연결 없음** 이라고 표시되거나 테스트에 실패하나요? [여전히 해결되지 않나요?](#still-stuck)를 참고하세요.

### 다시 확인 {#check-again}

- **프린터를 추가하는 경우:** **IP 주소 입력** 을 누른 다음 **이 주소 확인** 을 누르세요. 카드에 **준비됨** 이라고 표시되면 브라우저가 프린터에 접근할 수 있는 상태입니다. [테스트 페이지 인쇄](./setup-wizard.mdx#test-page)로 진행하세요.
- **이미 저장한 프린터의 경우:** **설정 → 인쇄** 에서 해당 프린터 행의 **테스트 인쇄** 를 누르거나 **프린터 편집** 에서 누르세요.

로컬 네트워크 접근을 허용했는데도 실패하나요? [포트를 확인하세요](#fix-in-order)(2단계). 해당 포트에 맞는 절차를 따랐는데도 실패하나요? [여전히 해결되지 않나요?](#still-stuck)를 참고하세요.

포트 확인 위치는 [HTTPS와 HTTP](#https-or-http)의 화면에서 볼 수 있습니다.

## 로컬 네트워크 접근 허용 {#allow-local-network-access}

Chrome과 Edge는 웹사이트가 로컬 네트워크의 장치에 접근하기 전에 권한을 요청합니다. **로컬 네트워크의 다른 기기에 액세스** 하겠다는 메시지가 표시되면 허용하세요.

누군가 **허용 안 함** 을 선택했거나 요청 창을 닫았다면 다음과 같이 진행하세요.

1. 주소 표시줄 왼쪽의 아이콘을 클릭한 다음 **사이트 설정** 을 클릭하세요.
2. **로컬 네트워크** 를 **허용** 으로 설정하세요.
3. POS를 새로고침하고 [다시 확인](#check-again)하세요.

## 프린터의 인증서 {#the-printers-certificate}

HTTPS 연결 시 프린터는 자체 인증서를 제시합니다. 브라우저가 해당 인증서를 신뢰하지 않으면 데이터를 보내기도 전에 연결에 실패합니다. 다음 절차를 따르면 이 브라우저에서 연결할 수 있습니다.

1. 프린터에 인증서가 있는지 확인하세요. 상태 정보 용지에 인증서가 없다고 표시되면 프린터의 웹 설정에서 자체 서명 인증서를 생성하세요. Epson 프린터에서는 [Epson 보안 인쇄](./secure-printing.mdx#turn-it-off)에 설명된 방법으로 로그인하세요.
2. 같은 브라우저에서 프린터의 실제 IP 주소를 사용하여 HTTPS로 프린터 주소를 여세요.
   - **Epson:** 먼저 `https://192.168.1.200:8043`을 시도하세요. 열리지 않으면 포트 443을 사용하는 `https://192.168.1.200`을 시도하세요.
   - **Star:** 포트 443을 사용하는 `https://192.168.1.200`입니다.
3. 인증서 경고를 수락하세요. 사용 중인 브라우저의 절차를 여세요.

   <details>
   <summary>Chrome</summary>

   **연결이 비공개로 설정되어 있지 않습니다** 화면에서 **고급** 을 누른 다음 **192.168.1.200(안전하지 않음)(으)로 이동** 을 누르세요.

   </details>

   <details>
   <summary>Edge</summary>

   **고급** 을 누른 다음 **192.168.1.200(안전하지 않음)으로 계속** 을 누르세요.

   </details>

   <details>
   <summary>Safari</summary>

   **이 연결은 비공개 연결이 아닙니다** 화면에서 **세부사항 보기** 를 누르고 **이 웹 사이트 방문** 링크를 누른 다음 **웹 사이트 방문** 을 누르세요.

   </details>

   <details>
   <summary>Firefox</summary>

   경고 화면에서 사이트로 계속 이동하는 옵션을 사용하세요.

   </details>

4. POS로 돌아가 [다시 확인](#check-again)하세요.

인쇄에 사용하는 모든 컴퓨터의 각 브라우저에서 이 절차를 진행하세요.

데스크톱 앱은 프린터 인증서를 자체적으로 수락합니다. 따라서 같은 프린터가 데스크톱 앱에서는 작동해도 브라우저 탭에서는 작동하지 않을 수 있습니다.

## 프린터가 HTTP를 사용하는 경우 {#mixed-content}

매장 주소가 `https://`로 시작하고 프린터가 일반 HTTP만 지원한다면 Chrome 또는 Edge 142 이상에서 인쇄하고 [로컬 네트워크 접근을 허용](#allow-local-network-access)하세요.

다른 브라우저는 이를 차단합니다. 보안 페이지에서 보안이 적용되지 않은 주소로 데이터를 보낼 수 없기 때문이며, 브라우저에서는 이를 혼합 콘텐츠라고 합니다. Chrome이나 Edge를 사용할 수 없다면 [인증서](#the-printers-certificate)를 사용하여 프린터를 HTTPS로 전환하거나 데스크톱 앱을 사용하세요.

## Safari 및 Firefox {#safari-and-firefox}

- **Wi-Fi 연결:** 프린터의 프로토콜이 매장과 맞아야 합니다. `https://` 매장에서는 [인증서를 수락](#the-printers-certificate)한 후 HTTPS만 사용할 수 있으며 일반 HTTP는 차단됩니다. `http://` 매장에서는 일반 HTTP를 사용할 수 있습니다.
- **USB 및 Bluetooth:** **USB 프린터 찾기** 와 **Bluetooth 프린터 찾기** 는 해당 장치에 접근할 수 있는 Chrome과 Edge에서만 표시됩니다.

그 밖의 경우에는 Chrome이나 Edge 또는 데스크톱 앱을 사용하세요.

6. **테스트 인쇄** — 해결 방법을 하나씩 시도한 후 다시 인쇄해 보세요.

## HTTPS와 HTTP {#https-or-http}

브라우저는 [위 표](#fix-in-order)에 있는 포트 중 하나로 프린터의 웹 서버에 접근합니다. 포트에 따라 HTTPS 또는 일반 HTTP가 사용됩니다.

- **HTTPS** 를 사용하려면 브라우저가 신뢰하는 인증서가 프린터에 있어야 합니다. [프린터의 인증서](#the-printers-certificate)를 참고하세요.
- HTTPS 매장에서 **HTTP** 를 사용하려면 Chrome 또는 Edge 142 이상과 [로컬 네트워크 권한](#allow-local-network-access)이 필요합니다. [프린터가 HTTP를 사용하는 경우](#mixed-content)를 참고하세요.

저장된 프린터는 **프린터 편집** 의 **웹 인쇄 엔드포인트** 아래에서 어떤 프로토콜을 사용하는지 확인할 수 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={13} offsets={[[290, 0], [0, 30], [572, -2], [700, 0]]} alt="192.168.1.128의 포트 8008을 사용하는 Epson의 프린터 편집 화면: 감지됨: Epson, 웹 인쇄 엔드포인트 http://192.168.1.128:8008/cgi-bin/epos/service.cgi, HTTP를 통해 Epson ePOS 사용 중. Chrome 또는 Edge에서 로컬 네트워크 접근 권한을 요청할 수 있습니다">

1. **IP 주소** — 프린터의 주소입니다.
2. **포트** — 여기서는 Epson의 일반 HTTP 포트인 8008입니다. HTTPS 매장에서 새 Epson 프린터를 추가하면 HTTPS를 사용하는 **8043** 이 기본값입니다.
3. **웹 인쇄 엔드포인트** — 브라우저가 영수증을 보내는 주소입니다. 일반 HTTP는 `http://`로, HTTPS는 `https://`로 시작합니다.
4. **엔드포인트 아래 문구** — 제조사와 HTTPS 또는 HTTP 사용 여부를 설명합니다. HTTP인 경우 Chrome이나 Edge에서 [로컬 네트워크 권한](#allow-local-network-access)을 요청할 수 있다는 설명이 추가됩니다. HTTPS인 경우 브라우저가 신뢰하는 인증서가 프린터에 필요하다는 설명이 추가됩니다([프린터의 인증서](#the-printers-certificate)).

</JourneyShot>

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[351, 0], [64, 0], [133, -18]]} maxWidth={559} alt="프린터의 IP 주소 입력: IP 주소에 192.168.1.200, 포트에 8043이 입력되어 있고 이 주소 확인 버튼이 표시됩니다">

1. **IP 주소** — 프린터의 상태 정보 용지에서 확인할 수 있습니다.
2. **포트** — HTTPS 매장에서는 Epson의 HTTPS 포트인 **8043** 이 기본값입니다.
3. **이 주소 확인** — Epson과 Star에서 일반적으로 사용하는 HTTPS 및 HTTP 포트를 시도하고 응답하는 포트를 사용합니다.

</JourneyShot>

브라우저에서는 Epson과 Star 프린터로만 인쇄할 수 있습니다.

## 여전히 해결되지 않나요? {#still-stuck}
