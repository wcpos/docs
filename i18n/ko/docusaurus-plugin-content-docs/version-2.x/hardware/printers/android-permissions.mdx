**증상:** Android 휴대폰이나 태블릿의 **프린터 추가** 화면에 **프린터를 찾을 수 없습니다** 라고 표시되거나 검색 결과에 Bluetooth 프린터가 나타나지 않습니다.

WCPOS에 Bluetooth 사용 권한이 없으면 Bluetooth 프린터를 찾을 수 없습니다. 먼저 이 권한을 확인하세요.

Wi-Fi 프린터는 모든 Android 버전에서 별도의 권한이 필요하지 않습니다. 바로 [Wi-Fi 프린터](#wi-fi-printers)로 이동하세요. {/* pending: monorepo#3366 */}

## WCPOS의 프린터 접근 허용 {#allow-nearby-devices}

1. Bluetooth 프린터라면 Android의 빠른 설정에서 Bluetooth가 켜져 있는지 확인하세요.
2. Android 버전을 확인하세요. Android **설정 → 휴대전화 정보 → Android 버전** 을 여세요.
3. Android **설정 → 앱 → WCPOS → 권한** 을 여세요.
4. 사용 중인 버전에 맞는 권한을 허용하세요.
   - **Android 11 이하:** 근처 기기 권한이 없습니다. **위치** 를 탭하고 허용하세요. 이 버전에서는 Bluetooth 프린터를 찾으려면 위치 권한이 필요합니다.
   - **Android 12 이상:** **근처 기기** 를 탭하고 **허용** 을 선택하세요. 그러면 WCPOS에서 Bluetooth 프린터를 찾아 연결할 수 있습니다.
5. WCPOS로 돌아가 **프린터 추가** 화면에서 **다시 검색** 을 탭하세요.

프린터가 나타나면 해당 카드 아래의 **테스트 페이지 인쇄** 를 탭하세요. 페이지가 인쇄되고 페이지의 눈금자가 올바르게 보이면 **예, 눈금자도 올바르게 보입니다** 를 선택하세요. 프린터가 저장되며 문제가 해결된 것입니다. 전체 절차는 [프린터 추가](./index.mdx#adding-a-printer)에 나와 있습니다.

Android 자체 설정의 메뉴 이름은 휴대폰 제조사에 따라 조금씩 다르지만, 모든 Android 휴대폰에는 앱별 **권한** 페이지가 있습니다.

## Bluetooth 프린터 {#bluetooth-printers}

권한이 허용되면 WCPOS에서 Bluetooth 프린터를 검색합니다. 프린터를 찾을 수 있는지는 프린터가 사용하는 Bluetooth 유형에 따라서도 달라집니다.

- **Bluetooth Low Energy 프린터** 는 검색 시 자동으로 나타납니다. Android에서 페어링할 필요가 없습니다.
- 저가형 58 mm 프린터 중 상당수를 포함하는 **Bluetooth Classic 프린터** 는 Android에서 페어링해야 나타납니다. **프린터를 찾을 수 없습니다** 화면에서 **Bluetooth 설정 열기** 를 탭하여 프린터를 페어링한 다음, 돌아와 **다시 검색** 을 탭하세요.

프린터 유형을 모르거나 페어링이 되지 않나요? [Bluetooth 영수증 프린터 페어링](./bluetooth-pairing.mdx#classic-or-low-energy)에서 유형을 구별하는 방법과 프린터를 페어링 모드로 전환하는 방법을 안내합니다.

## Wi-Fi 프린터 {#wi-fi-printers}

휴대폰이나 태블릿이 모바일 데이터나 게스트 네트워크가 아닌, 프린터와 동일한 매장 Wi-Fi 네트워크에 연결되어 있는지 확인하세요.

검색 결과가 여전히 없지만 프린터 주소를 알고 있다면 **IP 주소 입력** 을 탭하세요. 검색을 건너뛰고 해당 주소를 직접 확인합니다. 주소는 프린터의 상태 정보 용지에 인쇄되어 있습니다. [프린터의 네트워크 주소 찾기](./network-address.mdx)를 참고하세요.

## 문제가 발생한 경우 {#goes-wrong}

### 검색 실패 {#discovery-failed}

**프린터를 찾을 수 없습니다** 아래에 빨간색으로 프린터 검색 실패 메시지가 표시됩니다. 예를 들어 “Bluetooth가 꺼져 있거나 이 앱에 사용 권한이 없습니다.”라고 표시됩니다. 휴대폰의 Bluetooth가 꺼져 있거나 WCPOS에 사용 권한이 없는 상태입니다. Bluetooth를 켜고 [Android 버전에 맞는 권한을 허용](#allow-nearby-devices)한 다음 **다시 검색** 을 탭하세요.

### 인쇄 권한 없음 {#printing-not-allowed}

테스트 인쇄 후 **아무것도 인쇄되지 않았습니다** 화면에 “앱의 프린터 접근이 허용되지 않았습니다. 시스템 설정에서 허용한 후 다시 시도하세요.”라고 표시됩니다. WCPOS가 인쇄를 시도했을 때 Android에서 거부한 것입니다. [Android 버전에 맞는 권한을 허용](#allow-nearby-devices)한 다음 **다시 시도** 를 탭하세요.

### 프린터 페어링 필요 {#printer-needs-pairing}

테스트 인쇄 후 **아무것도 인쇄되지 않았습니다** 화면에 “이 휴대폰의 Bluetooth 설정에서 프린터를 페어링한 다음 다시 검색하세요.”라고 표시됩니다. 프린터가 Bluetooth Classic을 사용하며 Android에서 페어링이 해제된 상태입니다. 메시지 아래의 **Bluetooth 설정 열기** 를 탭하여 페어링한 다음 **처음부터 다시 시작** 을 탭하여 다시 검색하세요.

### 권한을 허용했지만 여전히 프린터가 나타나지 않는 경우 {#still-missing}

근처 기기 권한(Android 11 이하에서는 위치 권한)을 허용했는데도 프린터를 찾을 수 없는 경우입니다. 프린터를 껐다 켠 다음 **다시 검색** 을 탭하세요. 여전히 나타나지 않으면 다음을 확인하세요.

- **Bluetooth 프린터:** 다른 원인은 [Bluetooth 영수증 프린터 페어링](./bluetooth-pairing.mdx)을 참고하세요.
- **Wi-Fi 프린터:** [Wi-Fi 프린터](#wi-fi-printers)의 안내에 따라 네트워크를 확인하고 프린터 주소로 연결해 보세요.

### 여전히 해결되지 않는 경우 {#still-stuck}

프린터가 전혀 나타나지 않으면 보고할 테스트 인쇄 결과가 없습니다. 아래에서 문의하고 Android 버전과 프린터 제조사 및 모델을 알려 주세요.

프린터가 나타나지만 인쇄되지 않으면 **아무것도 인쇄되지 않았습니다** 화면에서 **설정 보고서 복사** 를 탭하세요. 이 화면은 테스트 인쇄에 실패하거나 테스트 인쇄 후 **아무것도 나오지 않았습니다** 를 선택하면 자동으로 열립니다. Android에서는 설정 보고서 복사를 탭하면 공유 메뉴가 열립니다. 보고서를 이메일로 보내거나 메시지에 복사해 주세요. 보고서에는 앱 버전, 프린터, 앱이 시도한 작업과 프린터의 응답이 담겨 있습니다.
