**증상:** 네트워크 프린터 검색이 **프린터를 찾을 수 없음**으로 끝납니다. 또는 몇 주 동안 잘 작동하던 프린터가 멈추고, 영수증을 인쇄할 때마다 **선택한 프린터에 연결할 수 없습니다** ([PRINT301](../../error-codes/PRINT301.mdx))라는 메시지가 표시됩니다.

대개 프린터 자체에는 문제가 없습니다. POS 단말기와 프린터가 서로 다른 네트워크에 있거나 프린터 주소가 변경되어 단말기가 프린터에 연결하지 못하는 것입니다.

- **프린터를 추가하시나요?** [네트워크를 확인](#same-network)하고 [프린터 주소를 확인](#read-the-address)한 다음 [주소로 프린터를 추가](#enter-address)하세요.
- **잘 작동하던 프린터가 멈췄나요?** [주소를 확인](#read-the-address)한 다음 [기존 프린터의 주소를 변경](#change-address)하세요.

인쇄가 되면 같은 문제가 반복되지 않도록 [주소를 고정](#fixed-address)하세요.

## 먼저 네트워크 확인하기 {#same-network}

POS 단말기와 프린터를 게스트 네트워크가 아닌 **동일한 매장 네트워크**에 연결하세요. 프린터는 Wi-Fi로 연결하거나 공유기에 네트워크 케이블을 꽂아 연결할 수 있습니다. 그런 다음 **설정 → 인쇄**로 이동해 **프린터 추가**를 누르고 검색이 진행되도록 기다리세요. 프린터가 나타나면 추가하고 [주소를 고정](#fixed-address)하세요. 나타나지 않으면 주소를 확인해 직접 추가하세요. 두 기기가 연결되지 않는 이유는 [문제의 원인](#why-it-happens)에서 설명합니다.

## 프린터 주소 확인하기 {#read-the-address}

프린터는 **상태 시트**에 자신의 주소를 인쇄합니다. 제조사에 따라 네트워크 자체 테스트 또는 구성 페이지라고 부르기도 합니다.

- **네트워크에 연결된 Epson TM 프린터**(예: TM-m30III): 프린터가 켜진 상태에서 롤 용지 덮개를 열고 **용지 공급** 버튼을 1초 이상 누른 다음 덮개를 닫으세요. 상태 시트 버튼이 있는 모델은 해당 버튼을 약 3초 동안 누르면 같은 시트가 인쇄됩니다.
- **네트워크에 연결된 Star 프린터:** 프린터가 켜진 상태에서 **용지 공급** 버튼을 약 5초 동안 누르세요. 주소는 **현재 IP 매개변수** 아래에 있습니다.
- **다른 프린터이거나 시트가 나오지 않는 경우:** 버튼 조작 방법은 모델마다 다릅니다. 프린터 설명서에서 ‘상태 시트’ 또는 ‘네트워크 자체 테스트’를 찾아보세요.

시트에서 **IP 주소** 항목을 찾으세요. 예를 들면 `192.168.1.100`입니다. 매장에 프린터가 두 대 있나요? 해당 프린터에서 나온 시트인지 확인하세요.

다음으로 [프린터를 추가](#enter-address)하거나 기존 프린터의 [주소를 변경](#change-address)하세요.

## 주소로 프린터 추가하기 {#enter-address}

검색으로 프린터를 찾지 못하면 주소를 직접 입력하세요. 이 경우에도 매장 네트워크에서 POS 단말기가 프린터에 연결할 수 있어야 합니다.

1. **설정 → 인쇄**로 이동해 **프린터 추가**를 누르세요. 검색이 자동으로 시작됩니다.
2. 검색 중이나 검색이 끝난 뒤 **IP 주소 입력**을 누르세요. 검색이 중지됩니다.
3. **IP 주소**에 상태 시트의 주소를 입력하세요.
4. **이 주소 확인**을 누르세요.
5. 카드에 **준비됨** 또는 **테스트 필요**가 표시되면 **테스트 페이지 인쇄**를 누르세요. 카드 옆에 **용지 너비**가 표시되면 먼저 **58 mm** 또는 **80 mm**를 선택하세요.
6. 앱에서 **테스트 페이지가 인쇄되었나요?** 라고 묻습니다. **예, 올바르게 인쇄되었습니다**를 누르세요. 앱이 프린터를 저장하고 **… 설정이 완료되었습니다**를 표시합니다.

테스트 페이지의 눈금자가 맞지 않거나 아무것도 인쇄되지 않았다면 나머지 두 응답 중 하나를 선택해 계속 진행하세요. [프린터 추가](./index.mdx#adding-a-printer)를 참고하세요.

## 이미 설정한 프린터인가요? 주소 변경하기 {#change-address}

잘 작동하던 프린터가 주소 변경으로 멈췄다면 기존 프린터의 주소를 변경하세요. 다시 추가할 필요는 없습니다.

1. **설정 → 인쇄**로 이동하세요.
2. 프린터 행의 **편집**을 누르세요.
3. **IP 주소**를 상태 시트에 있는 주소로 변경하세요. 입력하는 대로 변경 사항이 저장됩니다. 대신 **네트워크 검색**으로 프린터를 찾을 수도 있습니다.
4. **테스트 인쇄**를 누르세요. 아무것도 인쇄되지 않으면 [문제가 발생하는 경우](#if-something-goes-wrong)를 참고하세요.

3. **포트** — 자동으로 입력되므로 표시된 값과 다를 수 있습니다. 브라우저에서는 HTTPS와 일반 HTTP 중 어느 것을 사용할지도 결정합니다. [HTTPS 또는 HTTP](./browser-permissions.mdx#https-or-http)를 참고하세요.

## 주소 고정하기 {#fixed-address}

프린터를 추가하거나 문제를 해결하는 데 꼭 필요한 단계는 아닙니다. 주소가 다시 변경되지 않도록 하여 한 번만 입력하면 되게 합니다. 프린터가 인쇄되면 매장 공유기 관리자에게 상태 시트에 있는 **프린터 주소를 예약**해 달라고 요청하세요. 그러면 공유기가 매번 프린터에 같은 주소를 할당합니다.

<details>
<summary>공유기 및 프린터 설정</summary>

- **공유기에서 주소 예약하기(권장).** 공유기 설정에서 네트워크의 장치 목록이 표시되는 페이지(보통 DHCP 또는 LAN)를 여세요. 상태 시트의 주소로 프린터를 찾아 해당 주소를 예약하세요. 많은 공유기에서 이때 프린터의 MAC 주소를 입력해야 합니다. 프린터 설정은 바뀌지 않습니다.
- **또는 프린터에서 설정하기.** 동일한 네트워크의 웹 브라우저에서 프린터 주소(예: `http://192.168.1.100`)를 열고 네트워크 설정에서 고정(정적) 주소를 지정하세요. 공유기가 다른 장치에 할당하지 않는 주소를 선택하세요. 그렇지 않으면 두 장치가 같은 주소를 갖게 될 수 있습니다. 공유기 설정에서 할당하는 주소 범위를 확인할 수 있습니다.

</details>

## 문제의 원인 {#why-it-happens}

- **서로 다른 네트워크.** POS 단말기와 프린터가 서로 다른 네트워크에 연결되어 있습니다. 게스트 네트워크, 다른 공유기 또는 직원 기기용 별도 네트워크에 연결된 경우입니다. 검색은 POS 단말기가 연결된 네트워크에서만 이루어집니다.
- **게스트 Wi-Fi의 기기 간 통신 차단.** 게스트 Wi-Fi와 공용 Wi-Fi는 대개 연결된 기기 간 통신을 차단합니다. 공유기 설정에서는 이를 클라이언트 격리 또는 AP 격리라고 합니다. 프린터가 같은 Wi-Fi에 연결되어 있어도 연결할 수 없는 이유입니다.
- **주소 변경.** 공유기는 각 기기에 일정 기간 주소를 임대합니다. 재시작하거나 임대 기간이 만료되면 프린터에 새 주소가 할당될 수 있지만, 앱은 여전히 이전 주소로 인쇄를 시도합니다. 어제는 인쇄되었는데 오늘은 실패하는 이유입니다.

<details>
<summary>웹 브라우저에서는 일반적인 주소만 검색합니다</summary>

브라우저는 네트워크에 어떤 장치가 있는지 조회할 수 없으므로 대부분의 공유기가 사용하는 주소 범위인 `192.168.0.x`, `192.168.1.x`, `192.168.4.x`, `192.168.10.x`, `10.0.0.x`, `10.0.1.x`, `172.16.0.x`에 연결을 시도합니다. 다른 범위의 프린터는 검색되지 않습니다. 대신 주소로 추가하세요. 브라우저에서 앱은 네트워크를 통해 Epson 및 Star 프린터에 연결합니다. [각 앱이 연결할 수 있는 프린터](./index.mdx#supported-printers-by-platform)를 참고하세요.

</details>

## 문제가 발생하는 경우 {#if-something-goes-wrong}

- **시트의 주소가 `169.254`로 시작합니다.** 프린터가 네트워크에서 주소를 받지 못한 상태입니다. 네트워크 케이블이나 Wi-Fi 설정을 확인한 다음 상태 시트를 다시 인쇄하세요.
- **주소는 맞지만 연결 없음이 표시됩니다.** POS 단말기와 프린터가 게스트 Wi-Fi가 아닌 동일한 매장 네트워크에 있는지 확인하세요([문제의 원인](#why-it-happens) 참고). 같은 네트워크에 있다면 아래에서 앱 권한을 확인하세요.
- **iPad 또는 iPhone에서 검색 결과가 없습니다.** 앱에 **로컬 네트워크** 권한이 필요합니다. [iPad 또는 iPhone에서 앱이 프린터를 찾도록 허용하기](./ios-local-network.mdx)를 참고하세요.
- **브라우저에서 검색 결과가 없거나 데스크톱 앱에서는 인쇄되지만 브라우저에서는 인쇄되지 않습니다.** 브라우저에 네트워크 접근 권한이 필요합니다. [브라우저에서 인쇄하기](./browser-permissions.mdx)를 참고하세요.
- **주소는 맞지만 한 번 인쇄된 뒤 멈췄습니다.** 프린터가 작업을 보류 중일 수 있습니다. [Epson이 한 번 인쇄된 뒤 멈춘 경우](./printed-once-then-stopped.mdx)를 참고하세요.

## 아직 해결되지 않았나요? {#still-stuck}

설정 보고서를 복사해 문의 메시지에 붙여 넣으세요. **프린터 추가**의 **인쇄된 내용 없음** 화면이나 **설정 → 인쇄**의 프린터 행에 있는 **⋯** 메뉴에서 **설정 보고서 복사**를 누르세요. 모바일 앱에서는 공유 시트가 열립니다. 보고서에는 앱이 사용한 주소와 포트, 앱의 최근 프린터 로그가 포함됩니다. **프린터 추가**에서 복사한 보고서에는 프린터 포트의 응답도 포함됩니다. 직접 붙여 넣거나 공유하기 전까지는 어떤 내용도 기기 밖으로 전송되지 않습니다.
