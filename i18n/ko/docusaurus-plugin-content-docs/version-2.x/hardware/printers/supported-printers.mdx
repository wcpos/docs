아래에서 사용 중인 프린터, 앱, 연결 방식을 찾아보세요. **검증됨**은 명시된 연결 방식으로 해당 모델에서 직접 인쇄해 보았다는 뜻입니다. 그 외 모델은 **작동 예상**에 나와 있습니다. **제조사** 설정은 앱에 연결된 프린터의 제조사를 알려 줍니다.

## 검증됨 {#verified}

명시된 연결 방식으로 실제 기기에서 직접 인쇄를 확인했습니다.

| 프린터 및 용지 | 인쇄에 사용한 앱 및 연결 방식 |
|---|---|
| **Epson TM-m30III**<br />80 mm | 웹, 데스크톱, 모바일 앱에서 Wi-Fi로 인쇄. Android 앱에서 Bluetooth로 인쇄. |
| **Netum NT-1809**<br />58 mm | 데스크톱 앱에서 USB 및 Bluetooth로 인쇄. |

새 Epson 프린터가 앱에서 검색되지만 아무것도 인쇄하지 않는다면 대개 보안 인쇄가 켜져 있기 때문입니다. [Epson 보안 인쇄](./secure-printing.mdx)를 참고하세요.

## 작동 예상 {#expected-to-work}

모델별로 직접 테스트하지는 않았지만 검증된 프린터와 같은 연결 방식을 사용합니다. 프린터가 인쇄하지 않으면 [설정 마법사](./setup-wizard.mdx)를 따라 진행한 뒤 [제보해 주세요](#report-yours).

**웹 앱**은 브라우저에서 실행하는 WCPOS입니다. **모바일 앱**은 Android, iPhone, iPad용 WCPOS 앱입니다. **데스크톱 앱**은 Windows, macOS, Linux용 WCPOS 앱입니다.

iPhone과 iPad는 USB로 연결할 수 없으며, Bluetooth Classic 프린터는 Epson과 Star 제품에만 연결할 수 있습니다.

- **ePOS를 지원하는 Epson TM 시리즈 프린터 및 Star mC-Print, TSP 프린터**
  - **Wi-Fi**: 모든 앱.
  - **USB**: 데스크톱 앱, Chrome, Edge, Android 앱.
  - **Bluetooth**: 데스크톱 및 모바일 앱.
- **다른 제조사의 ESC/POS 프린터**
  - **Wi-Fi**: 데스크톱 및 모바일 앱.
  - **USB**: 데스크톱 앱, Chrome, Edge.
  - **Bluetooth Low Energy (BLE)**: 프린터 설명서에 지원한다고 명시되어 있다면 Chrome, Edge, 데스크톱 앱, 모바일 앱에서 사용 가능합니다.
  - **Bluetooth Classic**: 컴퓨터 또는 [휴대전화의 Bluetooth 설정](./bluetooth-pairing.mdx#android-pair-first)에서 페어링한 후 데스크톱 앱과 Android 앱에서 사용 가능합니다.

## 아직 지원되지 않음 {#not-supported-yet}

- **웹 앱에서 Epson과 Star 이외 제조사의 Wi-Fi 프린터 사용.** 브라우저는 Epson과 Star 프린터에 내장된 웹 서버에만 연결할 수 있습니다. 데스크톱 또는 모바일 앱, USB 또는 Bluetooth 연결, [클라우드 프린터](../../receipts/cloud-printing.mdx)를 사용하세요.
- **모바일 앱에서 다른 제조사의 USB 프린터 사용.** Android에서는 Epson과 Star 프린터만 USB로 연결할 수 있습니다. Wi-Fi나 Bluetooth 또는 데스크톱 계산대를 사용하세요.
- **iPhone과 iPad에서 다른 제조사의 Bluetooth Classic 프린터 사용.** Bluetooth Low Energy나 Wi-Fi 또는 Android나 데스크톱 계산대를 사용하세요.
- **Sunmi 및 iMin 일체형 단말기의 내장 프린터.** 앱은 이러한 프린터를 지원하지 않습니다. 다른 Android 기기와 마찬가지로 외부 프린터를 연결하세요.

## 앱에 프린터 제조사 지정하기 {#vendor}

**제조사** 설정은 프린터를 만든 업체를 나타냅니다. 앱이 프린터를 찾거나 IP 주소를 확인하면 자동으로 입력됩니다. **프린터 편집**에서는 IP 주소 아래에 **감지됨: Epson**, **감지됨: Star** 또는 **감지됨: 일반**이 표시됩니다. 앱이 잘못 감지했거나 프린터에 연결하지 못한 경우에만 직접 변경하세요.

이 설정은 두 곳에 있습니다. **설정 → 인쇄 → 프린터 추가**의 **추가 옵션**과 이미 추가한 프린터의 **프린터 편집**에서 찾을 수 있습니다.

:::warning

**제조사**를 변경하면 **프린터 언어**도 초기화되며, 웹 앱에서는 **포트**도 초기화됩니다. **프린터 편집**이 열려 있는 동안에는 앱이 해당 주소에서 프린터 제조사를 확인하지 않습니다.

:::

1. **추가 옵션** — 검색 결과가 없거나 다른 프린터가 검색되었을 때 아래 카드를 엽니다.
2. **프린터 이름** — 프린터 목록과 영수증 화면에 표시되는 이름입니다.
3. **Epson** — 웹 앱의 기본값입니다.
4. **Star Micronics** — 카드를 Star 설정으로 전환합니다. **영수증 언어**는 ESC/POS 프린터의 문자 집합을 선택하는 항목이므로 사라집니다. 이 항목은 **프린터 편집**에서 설정하는 명령 언어인 **프린터 언어**와 다릅니다.
5. **현금 서랍 자동 열기** — 서랍을 여는 명령은 제조사와 프린터 언어에 따라 다릅니다. [현금 서랍 연결](./cash-drawer.mdx)을 참고하세요.
6. **USB 프린터 찾기** — Chrome과 Edge에서 사용할 수 있습니다. 가능한 경우 앱이 프린터에서 제조사 정보를 읽습니다.
7. **Bluetooth 프린터 찾기** — 브라우저 또는 컴퓨터의 자체 Bluetooth 선택 창을 엽니다.
8. **IP 주소 입력** — 주소 하나를 확인합니다. **포트**는 선택한 제조사에 따라 정해집니다.

**프린터 편집**에서 **제조사**는 **연결** 아래에 있으며, 앱이 감지한 제조사는 IP 주소 아래에 표시됩니다.

1. **연결** — 웹 앱에서는 Wi-Fi 또는 네트워크 케이블로 연결된 프린터를 뜻하는 **네트워크**를 선택하면 **제조사** 항목이 제공됩니다.
2. **제조사** — 웹 앱에서는 **Epson** 또는 **Star Micronics**입니다. 앱이 잘못 감지한 경우에만 변경하세요.
3. **IP 주소** — 아래의 **감지됨: Epson**은 앱이 이 주소에서 확인한 제조사입니다.
4. **포트** — 웹 앱에서는 **제조사**에 따라 바뀝니다. 여기서는 Epson의 일반 HTTP 포트인 8008입니다. HTTPS를 사용하는 쇼핑몰에서는 초기값이 8043입니다.
5. **웹 인쇄 엔드포인트** — 웹 앱이 영수증을 전송하는 방식이며, 여기서는 Epson ePOS입니다. [변경 시 달라지는 점](#what-vendor-changes)을 참고하세요.
6. **프린터 언어** — **제조사**를 변경하면 해당 제조사의 기본값으로 돌아갑니다. Epson의 기본값은 **ESC/POS**입니다.

### 변경 시 달라지는 점 {#what-vendor-changes}

<details>
<summary>프린터 언어, 포트 및 제조사별 인쇄 방식</summary>

영수증 프린터는 대부분의 제조사가 사용하는 ESC/POS 또는 Star의 자체 언어인 StarPRNT나 Star Line Mode를 사용합니다.

- **프린터 언어**는 해당 제조사의 기본값으로 돌아갑니다. Epson과 일반은 **ESC/POS**, Star는 **Star Line Mode**입니다. 저장된 프린터는 제조사를 변경하기 전까지 설정한 언어를 유지합니다.
- 웹 앱에서 **포트**는 해당 제조사가 연결을 받는 포트로 변경됩니다. 보안 연결을 사용하는 쇼핑몰에서 **Star Micronics**를 선택하면 주소 양식에 **443**이 표시됩니다.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [58, 0], [133, 18]]} maxWidth={559} alt="Star Micronics를 선택한 후 프린터의 IP 주소를 입력하는 화면: IP 주소 필드, 443이 표시된 포트 필드, 이 주소 확인 버튼">

1. **IP 주소** — 프린터의 상태 출력물에 인쇄되어 있습니다.
2. **포트** — Star는 보안 연결을 사용하는 쇼핑몰에서 443, 그렇지 않으면 80입니다. Epson은 8043, 그렇지 않으면 8008을 사용합니다.
3. **이 주소 확인** — 앱이 해당 주소에 요청을 보내 응답하는 제조사를 확인하고 프린터를 카드로 표시합니다. 카드 아래의 **테스트 페이지 인쇄**를 눌러 인쇄하세요.

</JourneyShot>

- **앱의 영수증 전송 방식**도 바뀝니다. 제조사를 직접 선택하면 **프린터 편집**을 닫을 때까지 앱이 제조사를 다시 감지하지 않습니다. 다음에 열면 앱이 주소를 다시 확인하며 제조사를 이전 값으로 되돌릴 수 있습니다.

**앱별 제조사 인쇄 방식**

| | Epson | Star Micronics | 일반 |
|---|---|---|---|
| **웹 앱, Wi-Fi** | Epson ePOS, 포트 8043 (HTTPS를 사용하지 않는 쇼핑몰에서는 8008) | Star WebPRNT, 포트 443 (HTTPS를 사용하지 않으면 80) | 제공되지 않음 |
| **데스크톱 앱, Wi-Fi** | Epson ePOS | 일반 네트워크 인쇄, 포트 9100 | 일반 네트워크 인쇄, 포트 9100 |
| **모바일 앱, Wi-Fi** | 일반 네트워크 인쇄, 포트 9100 | 일반 네트워크 인쇄, 포트 9100 | 일반 네트워크 인쇄, 포트 9100 |
| **모바일 앱, USB 및 Bluetooth** | Epson 자체 소프트웨어 | Star 자체 소프트웨어 | Bluetooth Low Energy 또는 Android에서 페어링한 Bluetooth Classic |
| **서랍 열기 버튼, ESC/POS** | Epson 자체 서랍 명령 | 표준 ESC/POS 서랍 명령 | 표준 ESC/POS 서랍 명령 |

**서랍 열기** 버튼만 Epson 자체 명령을 전송합니다. **현금 서랍 자동 열기**를 켜고 영수증을 인쇄하면 제조사와 관계없이 표준 명령을 사용합니다.

웹 앱에서는 USB 또는 Bluetooth 프린터에 **프린터 언어**로 직접 전송합니다. ESC/POS를 사용하며, Star로 응답하는 프린터에는 Star Line Mode를 사용합니다. Epson ePOS와 Star WebPRNT는 Wi-Fi에서만 사용됩니다.

</details>

## 문제가 생긴 경우 {#goes-wrong}

**"현금 서랍 열기 동작은 프린터 언어/에뮬레이션에 따라 달라집니다."** 제조사와 **프린터 언어**가 일치하지 않는다는 뜻입니다. Star 프린터가 ESC/POS로 설정되었거나 다른 제조사의 프린터가 Star 언어로 설정된 경우입니다. 프린터가 실제로 해당 에뮬레이션 모드라면 문제없습니다. 서랍이 열리지 않으면 **프린터 언어**를 프린터의 현재 모드에 맞게 설정하세요.

**Epson이 아닌 프린터에서 서랍 열기 버튼을 눌러도 반응이 없습니다.** **제조사**가 Epson으로 설정되어 있으면 이 버튼은 Epson 자체 서랍 명령을 전송하며, 다른 프린터 중에는 이 명령을 무시하는 제품이 많습니다. 데스크톱 또는 모바일 앱에서는 **제조사**를 **일반**으로 설정하세요. 웹 앱은 USB 또는 Bluetooth 프린터가 Star로 응답하지 않으면 Epson으로 저장하며, 해당 프린터의 **제조사** 선택 항목을 제공하지 않습니다. 따라서 **현금 서랍 자동 열기**를 켜세요. 그러면 영수증을 인쇄할 때마다 서랍이 열립니다.

**Epson 또는 Star에 감지됨: 일반이 표시됩니다.** **제조사**에서 해당 제조사를 선택하세요. 프린터가 기본 인쇄 포트에서만 응답하여 앱이 제조사를 식별하지 못한 것입니다.

**웹 앱 목록에 사용 중인 제조사가 없습니다.** 브라우저는 Epson과 Star에만 Wi-Fi로 인쇄할 수 있습니다. Chrome이나 Edge에서 USB 또는 Bluetooth로 프린터를 연결하거나 데스크톱 앱을 사용하세요.

## 프린터 정보 제보하기 {#report-yours}

작동 여부와 관계없이 모델을 알려 주세요. **설정 보고서 복사**를 누르세요. 이 버튼은 **프린터 추가**의 **인쇄되지 않음** 화면, 프린터 설정이 완료되었다는 화면, **설정 → 인쇄**에서 각 프린터의 **추가 작업** 메뉴에 있습니다. 보고서에는 프린터, 제조사, 응답 방식, 앱의 최근 프린터 로그가 기록됩니다. 메시지에 붙여 넣어 주세요.
