Epson 프린터가 앱에서 인쇄하지 못하는 다음 상황에 해당한다면 이 페이지를 참고하세요.

- **프린터 설정 중:** [프린터 추가](./setup-wizard.mdx#test-page)에서 테스트 페이지를 인쇄하고 **아무것도 나오지 않았습니다**를 선택하자 패널에 **인쇄된 내용 없음**과 함께 *"보안 인쇄가 켜져 있습니다. 프린터에서 끈 다음 다시 시도하세요."*라는 문구가 표시됩니다. 바로 [끄기](#turn-it-off)로 이동하세요.
- **프린터가 준비된 것 같지만 아무것도 인쇄되지 않음:** 작업이 전송되는 것처럼 보이고 오류도 없지만 아무것도 나오지 않습니다. 프린터 자체 버튼으로 실행하는 자체 테스트는 여전히 인쇄됩니다.

보안 인쇄는 POS가 아닌 프린터의 설정입니다. 변경할 필요가 없을 수도 있으므로 먼저 [꺼야 하나요?](#do-you-need-to)를 확인하세요.

## 꺼야 하나요? {#do-you-need-to}

대부분의 환경에서는 보안 인쇄가 켜져 있어도 앱에서 인쇄할 수 있습니다. 앱의 **인쇄된 내용 없음** 패널에서 끄라고 안내하면 [끄세요](#turn-it-off). 그렇지 않다면 표의 맨 위에서부터 읽으세요. 인쇄 방식과 처음으로 일치하는 행이 적용됩니다. **영수증을 이미지로 인쇄**가 켜져 있는지 모르겠나요? 먼저 [스위치를 확인하세요](#print-as-image).

| 인쇄 방식 | 보안 인쇄가 켜져 있을 때 |
|---|---|
| 모든 앱에서 Wi-Fi 또는 네트워크 케이블로 연결한 Epson을 사용하며 **영수증을 이미지로 인쇄**가 켜진 경우 | 인쇄되지 않습니다. 보안 인쇄를 끄세요. |
| **데스크톱 앱**(컴퓨터에 설치한 WCPOS), Wi-Fi 또는 네트워크 프린터 | 인쇄됩니다. |
| **웹 앱**(Chrome, Edge, Safari 등의 브라우저에서 연 POS) | 해당 브라우저가 프린터의 인증서를 신뢰하면 HTTPS로 인쇄됩니다. [브라우저 권한](./browser-permissions.mdx#the-printers-certificate)을 참고하세요. HTTP(포트 8008 또는 80)로는 인쇄되지 않으므로 보안 인쇄를 끄세요. |
| **모바일 앱** | **프린터 추가**에서 프린터 카드에 **Wi-Fi · 보안**이 표시되면 인쇄됩니다. **Wi-Fi**가 표시되면 보안 인쇄를 끄세요. |
| **USB** 또는 **Bluetooth** | 영향을 받지 않습니다. |

### 영수증을 이미지로 인쇄 확인하기 {#print-as-image}

이 스위치는 보안 인쇄가 켜져 있을 때 프린터가 보류하는 형식으로 영수증을 전송합니다. 직접 켜지 않았다면 꺼져 있습니다. **설정 → 인쇄**로 이동하여 해당 프린터 행의 **편집**을 누르세요.

1. **용지 자동 절단** — 현재 보이는 마지막 행입니다. 이 항목을 지나 아래로 스크롤하면 **영수증을 이미지로 인쇄**가 나타납니다.

설정 양식의 끝부분:

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} maxWidth={799} alt="Epson 프린터의 프린터 편집 설정 화면. 마지막 스위치인 영수증을 이미지로 인쇄가 꺼져 있습니다">

1. **프린터 언어** — 현재 설정을 유지하세요. 보안 인쇄는 1~3번 항목을 변경하지 않습니다.
2. **용지 너비** — 줄당 문자 수입니다.
3. **영수증 언어** — 텍스트 영수증에 사용하는 문자 체계입니다.
4. **영수증을 이미지로 인쇄** — 확인해야 할 스위치입니다. 직접 켜지 않았다면 이 화면처럼 꺼져 있습니다. Wi-Fi 또는 네트워크 케이블로 연결한 Epson에서 이 기능을 사용하려면 보안 인쇄를 꺼야 합니다.

</JourneyShot>

스위치가 꺼져 있다면 [표](#do-you-need-to)로 돌아가 첫 번째 행을 건너뛰세요.

## 끄기 {#turn-it-off}

프린터와 같은 네트워크에 있는 컴퓨터, 프린터의 IP 주소, 관리자 비밀번호인 **초기 비밀번호**가 필요합니다. 보안 인쇄가 켜진 프린터에서는 1단계에서 인쇄하는 상태 시트에 두 정보가 모두 나옵니다.

1. 상태 시트를 인쇄하세요. 대부분의 모델에서는 용지 덮개를 열고 **용지 공급**을 일 초 동안 누른 다음 덮개를 닫습니다. 프린터에 별도의 상태 시트 버튼이 있다면 그 버튼을 삼 초 동안 누르세요. IP 주소와 **초기 비밀번호**를 적어 두세요.
2. 같은 네트워크에 있는 컴퓨터의 브라우저에서 `https://` 뒤에 해당 주소를 붙여 여세요. 인증서 경고를 수락하세요.
3. 시트에 있는 **초기 비밀번호**로 관리자 로그인을 하세요. 비밀번호를 변경했다면 변경한 비밀번호를 사용하세요.
4. **인쇄 → 보안 인쇄**로 이동하세요.
5. **사용 안 함**으로 설정하고 저장하세요.
6. 프린터의 전원 플러그를 뽑고 십 초 후에 다시 꽂으세요.
7. 앱에서 테스트 페이지를 인쇄하세요. **프린터 추가**에서는 **다시 시도**를 누르세요. 이전에 저장한 프린터라면 **설정 → 인쇄**에서 해당 프린터 행의 **테스트 인쇄**를 누르세요.

<Accordion>
<AccordionItem question="상태 시트가 인쇄되지 않거나 비밀번호가 맞지 않는 경우">

- **상태 시트가 나오지 않음:** 버튼과 누르는 시간은 모델마다 다릅니다. 프린터 설명서에서 확인하세요.
- **시트에 초기 비밀번호가 없음:** 프린터의 라벨을 찾아보세요. 일부 모델은 일련번호를 비밀번호로 사용합니다.
- **비밀번호가 변경됨:** 프린터를 설정한 사람에게 문의하세요.

</AccordionItem>
</Accordion>

## 발생 원인 {#why-it-happens}

보안 인쇄가 켜져 있으면 프린터는 앱이 보안 연결을 통해 텍스트로 전송한 내용만 인쇄합니다. 이미지로 전송한 영수증을 비롯한 나머지 작업은 보류합니다. 해당 작업을 거부하는 것이 아니라 약 사 분 동안 **보류**하고, 그동안 다른 작업도 인쇄하지 않다가 해당 작업을 폐기합니다. 그래서 프린터가 정상으로 보여도 반응하지 않는 것입니다. [한 번 인쇄한 후 멈춤](./printed-once-then-stopped.mdx)을 참고하세요.

상태 시트에 **보안 모드: RED**가 표시되면 이 프린터에 보안 인쇄가 적용됩니다.

<Accordion>
<AccordionItem question="영향을 받는 프린터와 연결 방식">

**2025년 8월 1일**부터 EU, 영국, EFTA에서 판매되는 Epson TM 시리즈 프린터는 EU 무선기기 지침을 충족하기 위해 **보안 인쇄**가 켜진 상태로 출고됩니다. Ethernet으로만 사용하더라도 달라지지 않습니다. 다른 지역에서 판매되는 프린터는 보통 꺼져 있지만, EU나 영국 재고에서 구매한 제품은 켜져 있습니다.

Epson이 명시한 모델은 TM-H6000VI, TM-L100, TM-m30II-S, TM-m30II-SL, TM-m30III, TM-m30III-H, TM-m50, TM-m50II, TM-P20II, TM-P80II, TM-T20IV, TM-T88VII입니다. USB 또는 직렬 포트만 있는 TM-L100이나 TM-T20IV는 영향을 받지 않습니다.

해당 프린터에 대한 Epson 공식 안내는 다음과 같습니다.

| 연결 방식 | 보안 인쇄 **켜짐** | **꺼짐** |
|---|---|---|
| Raw, 포트 9100 | 인쇄 불가 | 인쇄 가능 |
| HTTP를 통한 ePOS-Print, 포트 80 | 인쇄 불가 | 인쇄 가능 |
| ePOS SDK, 포트 8008 및 8009 | 인쇄 불가 | 인쇄 가능 |
| HTTPS를 통한 ePOS-Print, 포트 443 | 인쇄 가능 | 인쇄 가능 |
| TLS를 통한 ePOS SDK, 포트 8043 및 8143 | 인쇄 가능 | 인쇄 가능 |
| TLS를 통한 Raw, 포트 9143 | 인쇄 가능 | 인쇄 가능 |
| Bluetooth | 인쇄 가능 | 인쇄 가능 |

데스크톱 앱은 먼저 HTTPS의 포트 443으로 Epson에 인쇄합니다. 웹 앱은 HTTPS의 포트 8043을 사용하며, 설정 마법사가 포트 443에서 프린터를 찾았다면 해당 포트를 사용합니다. 모바일 앱은 카드에 **Wi-Fi · 보안**이 표시되지 않는 한 포트 9100으로 Raw 인쇄를 합니다.

</AccordionItem>
</Accordion>

## 아직 해결되지 않았나요? {#still-stuck}

**보안 인쇄가 이미 꺼져 있는데 아무것도 인쇄되지 않습니다.** 프린터의 웹 페이지는 열리지만 모든 작업이 실패한다면 [서버 직접 인쇄](./server-direct-print.mdx)를 참고하세요.

**한 번 인쇄한 후 멈췄습니다.** [한 번 인쇄한 후 멈춤](./printed-once-then-stopped.mdx)을 참고하세요.

**그 밖의 문제.** 설정 보고서를 복사하여 문의 메시지에 붙여넣으세요. **프린터 추가**에서는 **인쇄된 내용 없음** 아래의 **설정 보고서 복사**를 누르세요. 저장된 프린터라면 **설정 → 인쇄**에서 해당 행의 **추가 작업** 메뉴를 열고 **설정 보고서 복사**를 선택하세요. 이 설정에 대한 자세한 내용은 Epson의 [무선기기 지침 FAQ](https://www.epson.eu/en_EU/faq/KA-01896/contents?loc=en-us)를 참고하세요.
