프린터는 POS의 **설정 → 인쇄**에서 관리합니다. 기기마다 별도의 목록을 유지합니다. 한 계산대에서 추가한 프린터는 다른 계산대에 표시되지 않으므로 해당 프린터로 인쇄하는 모든 기기에서 설정하세요.

프린터를 추가하지 않아도 브라우저나 컴퓨터의 자체 인쇄 창인 **인쇄 대화 상자**로 영수증을 인쇄할 수 있습니다. 기본으로 제공되며 항상 사용할 수 있습니다.

:::tip 프린터가 다른 방에 있거나 모든 계산대에서 함께 사용하나요?
[클라우드 인쇄](../../receipts/cloud-printing.mdx)를 사용하세요. 클라우드 프린터는 모든 기기에 자동으로 나타나므로 여기서 추가할 필요가 없습니다.
:::

## 프린터 추가하기 {#adding-a-printer}

1. **설정 → 인쇄**로 이동하여 **프린터 추가**를 누르세요. 창에 **프린터를 찾는 중…** 이 표시되고 즉시 검색이 시작됩니다. 미리 선택할 항목은 없습니다.
2. 사용할 프린터를 찾으세요. 검색된 프린터는 각각 카드로 표시됩니다. 하나를 찾으면 **프린터를 찾았습니다**, 여러 개를 찾으면 **어느 프린터를 사용하시나요?** 아래에 나타납니다. 웹 앱에서는 Wi-Fi만 검색합니다. USB 또는 Bluetooth 프린터를 사용하려면 **USB 프린터 찾기** 또는 **Bluetooth 프린터 찾기**를 누르세요([검색 결과가 없는 경우](#nothing-found) 참조).
3. 아래의 **테스트 페이지 인쇄**를 누르세요. 프린터가 여러 개 검색되었다면 먼저 사용할 프린터를 누르세요. 그러면 버튼에 **테스트 페이지를 인쇄할 프린터**와 해당 프린터 이름이 표시됩니다.
4. **테스트 페이지가 인쇄되었나요?** 에 답하세요. **예, 올바르게 인쇄되었습니다**를 선택하면 프린터가 저장됩니다. [테스트 페이지 인쇄하기](#test-page)를 참조하세요.

카드에 표시된 프린터가 사용할 프린터가 아니라면 **이 프린터가 아닌가요? 다시 검색**을 누르세요. **중지**는 검색을 일찍 끝내고 이미 찾은 프린터를 유지합니다. **닫기**는 아무것도 추가하지 않고 창을 닫습니다. 아무것도 나타나지 않으면 [검색 결과가 없는 경우](#nothing-found)를 참조하세요.

자동 검색은 앱에 따라 다음 연결을 확인합니다.

- **웹 앱** — Wi-Fi.
- **데스크톱 앱** — USB, Bluetooth, Wi-Fi.
- **Android** — Wi-Fi, Bluetooth 및 USB로 연결된 Epson과 Star 프린터, Bluetooth Low Energy로 연결된 다른 제조사 프린터, Android 설정에서 이미 페어링된 Bluetooth 프린터.
- **iPhone 및 iPad** — Wi-Fi, Bluetooth로 연결된 Epson과 Star 프린터, Bluetooth Low Energy로 연결된 다른 제조사 프린터. iPhone과 iPad에서는 USB를 사용할 수 없습니다.

### 테스트 페이지 인쇄하기 {#test-page}

테스트 페이지에는 용지 너비에 걸쳐 숫자가 있는 눈금자가 인쇄됩니다. 이를 통해 프린터가 작동하는지와 너비가 맞는지를 함께 확인할 수 있습니다. 앱이 용지 너비를 판단하지 못하면 카드 아래에 **58 mm** 또는 **80 mm**를 선택하는 **용지 너비** 스위치가 나타나며, 더 가능성이 높은 값이 미리 선택됩니다. 인쇄하기 전에 확인하세요.

그런 다음 **테스트 페이지가 인쇄되었나요?** 라는 질문이 나타납니다.

- **예, 올바르게 인쇄되었습니다** — *영수증 프린터가 설정되었습니다*와 같은 메시지와 함께 프린터가 저장됩니다. 이름, 너비, 현금 서랍 설정은 **설정 → 인쇄**의 해당 프린터 행 아래에 표시됩니다.
- **인쇄되었지만 눈금자가 맞지 않습니다** — 앱이 **프린터에 어떤 용지가 들어 있나요?** 라고 묻습니다. **48 — 80 mm, 대부분의 Epson 및 Star** 등 해당하는 항목을 선택하면 테스트 페이지가 다시 인쇄됩니다. [영수증 너비 맞추기](./receipt-width.mdx)를 참조하세요.
- **아무것도 나오지 않았습니다** — 창에 **아무것도 인쇄되지 않았습니다**와 함께 가장 가능성이 높은 원인을 설명하는 문구가 표시됩니다. 안내된 문제를 해결한 다음 **다시 시도**를 누르세요.

<details>
<summary>아무것도 인쇄되지 않은 경우: 다른 선택 항목</summary>

- **테스트 없이 저장** — 테스트 페이지를 인쇄하지 않고 프린터를 저장합니다.
- **Bluetooth 설정 열기** — Android에서 Bluetooth 프린터가 아직 페어링되지 않은 경우에만 표시됩니다. 설정에서 페어링한 다음 다시 검색하세요.
- **처음부터 다시 시작**, **설정 보고서 복사**, **프린터 안내서 열기** — 다시 시작하거나 지원에 필요한 정보를 수집합니다.

</details>

**예, 올바르게 인쇄되었습니다**를 선택하거나 **테스트 없이 저장**을 누르기 전에는 아무것도 저장되지 않습니다. 따라서 도중에 창을 닫아도 설정이 미완료된 프린터가 목록에 남지 않습니다.

### 검색 결과가 없는 경우 {#nothing-found}

창에 **프린터를 찾을 수 없습니다**가 표시됩니다. 이어서 할 수 있는 모든 작업이 그 아래에 버튼으로 나타납니다.

<JourneyShot manifest={manifest} device="phone" step={1} offsets={[[-20, 0], [-14, -16], [-2, -18], [-14, -16], [-2, -18], [149, 0]]} maxWidth={390} alt="프린터를 찾을 수 없습니다가 표시된 프린터 추가 화면과 다시 검색, USB 프린터 찾기, Bluetooth 프린터 찾기, IP 주소 입력, 추가 옵션, 프린터 안내서 열기">

1. **다시 검색** — 프린터가 켜져 있고 용지가 있는지 확인한 다음 다시 찾습니다.
2. **USB 프린터 찾기** — 브라우저 자체의 USB 기기 선택 창을 엽니다. USB 기기에 접근할 수 있는 브라우저인 Chrome과 Edge에서 표시됩니다.
3. **Bluetooth 프린터 찾기** — 브라우저나 컴퓨터의 Bluetooth 기기 선택 창을 엽니다. 모바일 앱에서는 검색에 이미 Bluetooth가 포함되므로 표시되지 않습니다. 데스크톱 앱에서는 이 창 안에 목록이 열리며, 프린터로 보이는 이름이 *프린터로 추정됨* 표시와 함께 먼저 나옵니다.
4. **IP 주소 입력** — 전체 검색 대신 하나의 주소를 확인합니다. 프린터 주소를 알고 있지만 검색으로 찾을 수 없을 때 사용하세요. 기업 네트워크에서 흔히 발생하는 상황입니다. [IP 주소 입력하기](#enter-an-ip-address)를 참조하세요.
5. **추가 옵션** — 테스트 인쇄 전에 프린터 이름과 옵션을 설정합니다. [테스트 인쇄 전에 옵션 설정하기](#more-options)를 참조하세요.
6. **프린터 안내서 열기** — 이 페이지를 엽니다.

</JourneyShot>

### IP 주소 입력하기 {#enter-an-ip-address}

<JourneyShot manifest={manifest} device="phone" step={3} offsets={[[0, 0], [58, 0], [-14, -16], [-14, -16], [149, 0]]} maxWidth={390} alt="프린터의 IP 주소 입력: IP 주소와 포트 필드, 이 주소 확인, 취소, 그리고 그 아래의 다시 검색과 프린터 안내서 열기">

1. **IP 주소** — 프린터 상태 페이지에 인쇄되어 있습니다. 상태 페이지를 인쇄하려면 [프린터에 고정 주소 지정하기](./network-address.mdx)를 참조하세요.
2. **포트** — 자동으로 입력됩니다. 여기서는 8043으로, HTTPS 쇼핑몰에서 웹 앱이 Epson에 사용하는 포트입니다(HTTP에서는 8008). 데스크톱 및 모바일 앱에서는 9100이 입력됩니다. 프린터가 다른 포트를 사용하는 경우가 아니라면 그대로 두세요. [HTTPS 또는 HTTP](./browser-permissions.mdx#https-or-http)를 참조하세요.
3. **이 주소 확인** — 해당 주소에서 프린터를 찾습니다. 응답한 프린터가 있으면 카드로 표시됩니다. 아래의 **테스트 페이지 인쇄**를 누르세요. 응답이 없으면 입력 양식 아래에 이유가 표시됩니다.
4. **다시 검색** — 검색으로 돌아갑니다.
5. **프린터 안내서 열기** — 이 페이지를 엽니다.

</JourneyShot>

### 테스트 인쇄 전에 옵션 설정하기 {#more-options}

**추가 옵션**은 버튼 아래에 카드를 엽니다. 설정을 그대로 두어도 됩니다. 모든 항목은 나중에 [프린터 편집](#printer-options)에서 변경할 수 있습니다.

<details>
<summary>선택 사항: 추가 옵션 카드의 각 필드</summary>

<JourneyShot manifest={manifest} device="phone" step={2} offsets={[[301, 0], [0, 0], [-30, 0], [-30, 0], [-30, 0]]} maxWidth={390} alt="프린터를 찾을 수 없습니다 아래의 추가 옵션 카드: 프린터 이름, Epson과 Star Micronics가 있는 제조사, 프린터 텍스트 너비, 영수증 언어, 용지 자동 절단, 현금 서랍 자동 열기, 기본값으로 설정">

1. **프린터 이름** — 목록과 영수증 화면에 표시되는 프린터 이름입니다. 초기 이름은 *영수증 프린터*입니다.
2. **제조사** — 웹 앱에서는 브라우저가 접근할 수 있는 두 제조사인 **Epson** 또는 **Star Micronics**입니다.
3. **용지 자동 절단** — 영수증을 인쇄할 때마다 용지를 자릅니다. 처음에는 켜져 있습니다.
4. **현금 서랍 자동 열기** — 판매가 완료되면 이 프린터에 연결된 서랍을 엽니다. 처음에는 꺼져 있습니다.
5. **기본값으로 설정** — 라우팅에서 다른 프린터를 지정하지 않으면 이 프린터로 영수증을 보냅니다. 이 기기에 처음 추가하는 프린터에서는 켜져 있고, 이후에 추가하는 프린터에서는 꺼져 있습니다.

</JourneyShot>

그 사이에 **프린터 텍스트 너비**와 **영수증 언어**가 있습니다. 프린터에 대해 잘 아는 경우가 아니라면 그대로 두세요. 테스트 페이지에서 너비를 확인할 수 있습니다.

</details>

## 프린터 목록 {#printers-list}

프린터를 추가하면 **설정 → 인쇄**의 **프린터** 목록에 표시됩니다. *영수증을 보낼 수 있는 기기입니다.* 각 행에는 프린터 이름, 주소, 제조사(예: *192.168.1.128:8008 · Epson*)가 표시됩니다. 다른 곳으로 지정하지 않은 영수증이 전달되는 프린터에는 **기본값** 태그가 붙습니다. **인쇄 대화 상자**는 항상 목록에 *인쇄 대화 상자 · 내장*으로 표시됩니다. 클라우드 프린터에는 *PrintNode · WCPOS에서 관리*와 같이 제공업체가 표시됩니다.

각 행에는 **테스트 인쇄**, **편집**, **추가 작업**(**⋯**)이라는 세 가지 조작 항목이 있습니다. **편집**은 프린터 설정을 엽니다. [프린터 설정 변경하기](#printer-options)를 참조하세요. 인쇄 대화 상자와 클라우드 프린터에는 **편집**이 없습니다. 클라우드 프린터는 [클라우드 인쇄](../../receipts/cloud-printing.mdx)에서 변경합니다.

### 프린터 테스트하기 {#test-print}

해당 행에서 **테스트 인쇄**를 누르세요. 페이지가 출력된 것을 확인하면 프린터 이름과 함께 **인쇄됨** 메시지가 표시됩니다. 작업이 계산대에서 전송된 것만 확인할 수 있으면 **전송됨**이 표시됩니다. 실패하면 메시지에 원인이 표시됩니다.

### 프린터를 기본값으로 지정하기 {#set-default}

해당 행에서 **추가 작업**(**⋯**)을 열고 **기본값으로 설정**을 누르세요. 현재 기본 프린터, 인쇄 대화 상자, 클라우드 프린터에는 표시되지 않습니다.

### 프린터 삭제하기 {#delete-printer}

해당 행에서 **추가 작업**(**⋯**)을 열고 **삭제**를 누른 다음 **영수증 프린터를 삭제하시겠습니까?** 라는 메시지(해당 프린터 이름으로 표시됨)를 확인하세요. 프린터는 이 기기에서만 제거됩니다. 해당 프린터로 라우팅되던 템플릿은 *대신 자동 설정으로 인쇄됩니다*([인쇄 라우팅](#print-routing) 참조).

### 지원팀에 설정 보고서 보내기 {#setup-report}

해당 행에서 **추가 작업**(**⋯**)을 열고 **설정 보고서 복사**를 누르세요. 앱 버전, 프린터 설정, 최근 인쇄 로그가 수집됩니다. 웹 및 데스크톱 앱에서는 복사되어 지원 문의 메시지에 붙여넣을 수 있습니다. 모바일 앱에서는 전송할 수 있도록 공유 창이 열립니다.

## 프린터 설정 변경하기 {#printer-options}

프린터 행에서 **편집**을 누르세요. 오른쪽에서 **프린터 편집** 패널이 열립니다. 저장 버튼은 없습니다. 입력 양식이 완성되면 변경 사항이 즉시 저장되며, **닫기**를 누르면 아직 저장되지 않은 내용도 저장됩니다.

## 각 앱에서 연결할 수 있는 프린터 {#supported-printers-by-platform}

## 인쇄 라우팅 {#print-routing}

감열식 영수증과 A4 청구서처럼 여러 템플릿으로 인쇄할 때는 라우팅이 각 템플릿을 보낼 프린터를 결정합니다. 다음 세 단계를 순서대로 확인합니다.

1. **영수증 화면에서.** **템플릿** 아래에 **프린터** 선택 항목이 있습니다. **자동**으로 설정되어 있으며 *자동 — 인쇄 대화 상자*처럼 자동으로 선택한 대상이 표시됩니다. 여기서 프린터를 선택하면 해당 영수증이 그 프린터로 전송됩니다. 템플릿을 변경하거나 화면을 나갈 때까지 재인쇄도 같은 프린터로 전송됩니다. 템플릿을 변경하면 **자동**으로 돌아갑니다.
2. **설정에서.** 프린터 목록 아래의 **영수증 템플릿**, **보고서 템플릿**, **마감 템플릿**에 활성 템플릿이 각각 나열됩니다. *각 템플릿을 인쇄할 프린터를 선택하세요.* 템플릿에 사용할 프린터를 선택하거나 **자동**으로 되돌리세요. 각 목록에는 클라우드 프린터도 있습니다.
3. **자동.** 선택한 항목이 없으면 앱이 각 템플릿을 적합한 프린터로 보냅니다. 적합한 프린터가 여러 대라면 기본 프린터로 보냅니다.

라우팅 선택은 프린터 설정과 마찬가지로 기기에 저장됩니다.

<details>
<summary>자동 설정이 프린터를 선택하는 방법</summary>

템플릿은 두 종류입니다. [감열식 템플릿](../../receipts/thermal-templates.mdx)은 영수증 프린터용으로, 한 줄의 문자 수가 고정된 레이아웃입니다. [HTML 템플릿](../../receipts/html-templates.mdx)은 A4 청구서처럼 웹 페이지 형식의 레이아웃입니다.

- 감열식 템플릿은 용지 너비가 맞는 영수증 프린터로 전송됩니다. 58 mm 템플릿은 32자로 설정된 프린터로, 80 mm 템플릿은 42자 또는 48자로 설정된 프린터로 전송됩니다.
- HTML 템플릿은 **인쇄 대화 상자**로 전송됩니다.
- 적합한 프린터가 여러 대면 기본 프린터가 선택됩니다.

템플릿에 선택한 프린터가 적합하지 않으면 영수증 화면에 황색 경고가 표시되지만 인쇄는 진행됩니다. 감열식 템플릿을 **인쇄 대화 상자**로 보내면 화면의 미리보기가 인쇄되고, HTML 템플릿을 영수증 프린터로 보내면 내장 영수증 레이아웃이 인쇄됩니다. 유일한 예외는 감열식 템플릿만 지원하는 클라우드 프린터입니다. HTML 템플릿을 보내면 아무것도 인쇄되지 않으며, 경고에도 이 내용이 표시됩니다.

</details>

:::note 모든 영수증 자동 인쇄하기
판매 완료 시 인쇄하는 기능은 프린터가 아닌 장바구니 설정입니다. 장바구니 머리글의 설정을 열고 **결제 후 영수증 자동 인쇄**를 켜세요. 사용할 프린터는 라우팅에 따라 결정됩니다.
:::

## 문제가 발생한 경우 {#when-nothing-prints}

**검색 결과가 없습니다.** 프린터가 켜져 있고 용지가 있는지 확인하세요. Wi-Fi에서는 고정 주소를 지정하고 **IP 주소 입력**을 사용하세요. [프린터에 고정 주소 지정하기](./network-address.mdx)를 참조하세요. 브라우저에서는 로컬 네트워크 접근을 허용하세요. [브라우저](./browser-permissions.mdx)를 참조하세요.

**테스트 인쇄가 실패했다고 표시됩니다.** 메시지나 창에 있는 안내 문구를 읽으세요. 그런 다음 프린터 행의 **설정 보고서 복사** 또는 **프린터 편집**의 **지원 정보**를 눌러 지원 요청과 함께 보내세요. 앱이 시도한 작업이 담겨 있습니다.

**서랍이 열리지 않습니다.** **프린터 편집**에서 **서랍 열기**를 누르세요. 아무 반응이 없으면 **현금 서랍 커넥터**를 다른 핀으로 바꾸세요. 그래도 열리지 않으면 스위치 위에 프린터 언어 경고가 있는지 확인한 다음 [현금 서랍 연결하기](./cash-drawer.mdx)를 참조하세요.

**영수증은 인쇄되지만 화면과 다르게 나옵니다.** 영수증 화면의 황색 경고를 확인하고 템플릿에 맞는 프린터를 선택하세요.

상황에 맞는 안내서를 선택하세요.

**설정하기**

- [영수증 너비 맞추기](./receipt-width.mdx) — 눈금자가 용지 너비를 넘거나 너비에 못 미치는 경우
- [프린터에 고정 주소 지정하기](./network-address.mdx) — Wi-Fi에서 아무것도 찾지 못하거나 프린터가 작동을 멈춘 경우
- [Bluetooth 영수증 프린터 페어링하기](./bluetooth-pairing.mdx) — 기기 선택 창에 프린터가 없는 경우
- [Windows의 USB](./usb-windows.mdx) 및 [Linux의 USB](./usb-linux.mdx)
- [지원되는 영수증 프린터](./supported-printers.mdx)

**Epson이 아무것도 인쇄하지 않는 경우**

- [Epson Secure Printing](./secure-printing.mdx) — 새 Epson 프린터에 전송되는 것처럼 보이지만 아무것도 인쇄되지 않는 경우
- [Server Direct Print](./server-direct-print.mdx) — 프린터 웹 페이지는 작동하지만 인쇄 작업이 출력되지 않는 경우
- [한 번 인쇄한 뒤 멈춘 경우](./printed-once-then-stopped.mdx) — 먼저 전원을 껐다 켜세요
