**증상:** 화면에서는 영수증이 올바르게 보이지만 용지에는 물음표, 빈 네모 또는 잘못된 문자가 인쇄됩니다.

이 페이지는 영수증 프린터에 관한 설명입니다. **인쇄 대화 상자**와 사무용 프린터는 컴퓨터의 글꼴을 사용하므로 모든 언어를 화면에 보이는 대로 인쇄합니다.

## 해결 방법 선택하기 {#choose-a-fix}

먼저 프린터에서 어떤 설정을 사용할 수 있는지 확인하세요. **설정 → 인쇄**로 이동해 프린터 행의 **편집**을 누르세요.

<details>
<summary>편집 버튼이 없나요? 프린터에 WCPOS에서 관리라고 표시되는 경우</summary>

**WCPOS에서 관리**라고 표시된 프린터는 클라우드 프린터입니다. 앱이 아니라 매장 관리자가 **WP Admin → POS → 설정 → 클라우드 인쇄**에서 설정하므로 **편집**이 없습니다. 클라우드 프린터의 인쇄 방식은 [클라우드 인쇄](../../receipts/cloud-printing.mdx)에서 설명합니다.

</details>

**빠르게 텍스트로 인쇄: [영수증 언어 설정](#receipt-language)** — **프린터 편집**에 **영수증 언어**가 표시되고 영수증에 키릴 문자, 그리스어, 터키어, 베트남어 또는 악센트가 있는 서유럽·중부 유럽 문자를 사용하는 경우에 적합합니다.

**속도는 느리지만 모든 언어 지원: [영수증을 이미지로 인쇄](#print-the-receipt-as-an-image)** — 다음 경우에 적합합니다:

- **프린터 편집**에 **영수증 언어**가 없습니다.
- 영수증이 중국어, 일본어 또는 한국어입니다.
- 영수증이 아랍어, 히브리어 또는 태국어입니다. 이 언어들은 영수증 언어로 선택할 수 있지만 이미지로 인쇄할 때 가장 잘 출력됩니다. 속도가 중요한 경우에만 영수증 언어 설정을 먼저 시도하세요.
- 하나의 영수증에 그리스어와 러시아어처럼 두 가지 문자 체계가 섞여 있습니다.
- 영수증 언어를 설정했는데도 문자가 여전히 잘못 인쇄됩니다.

<details>
<summary>일부 프린터에 영수증 언어가 없는 이유</summary>

**영수증 언어**는 **프린터 언어**가 Epson과 대부분의 영수증 프린터에서 사용하는 명령 언어인 **ESC/POS**일 때만 표시됩니다([지원되는 프린터](supported-printers.mdx) 참고). **StarPRNT** 또는 **Star Line Mode**로 설정된 Star 프린터에는 이 항목이 없습니다. 비라틴 문자를 인쇄하려면 [영수증을 이미지로 인쇄](#print-the-receipt-as-an-image)를 켜세요.

</details>

## 영수증 언어 설정하기 {#receipt-language}

영수증을 인쇄할 언어를 선택하세요. 영수증은 계속 텍스트로 인쇄되므로 빠른 속도가 유지됩니다.

**이미 추가한 프린터의 경우:**

1. **설정 → 인쇄**로 이동해 프린터 행의 **편집**을 누르세요.
2. **영수증 언어**를 열고 영수증의 언어에 해당하는 항목을 선택하세요. **프린터 편집**에서는 변경할 때마다 저장됩니다.
3. **프린터 편집** 하단의 **테스트 인쇄**를 누르세요. 문자가 여전히 잘못 인쇄되면 프린터에 해당 언어가 내장되어 있지 않을 수 있습니다. 대신 [이미지로 인쇄](#print-the-receipt-as-an-image)하세요.

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} alt="네트워크 Epson 프린터의 프린터 편집 화면: 프린터 언어 ESC/POS, 용지 너비 48 — 80 mm, 대부분의 Epson 및 Star, 영수증 언어 자동, 용지 자동 절단, 금전함 자동 열기 및 기본값으로 설정 스위치, 영수증을 이미지로 인쇄와 해당 설명">

1. **프린터 언어** — 여기서는 **ESC/POS**입니다. **영수증 언어**는 ESC/POS일 때만 표시됩니다.
2. **용지 너비** — 한 줄의 문자 수입니다. [영수증 너비](receipt-width.mdx)를 참고하세요.
3. **영수증 언어** — 열어서 영수증 언어에 해당하는 항목을 선택하세요. 모든 프린터의 초기 설정은 **자동**입니다.
4. **영수증을 이미지로 인쇄** — 모든 언어에 사용할 수 있는 또 다른 해결 방법입니다. [영수증을 이미지로 인쇄](#print-the-receipt-as-an-image)를 참고하세요.

</JourneyShot>

**프린터를 추가하는 중인 경우:** **프린터 추가** 패널에서 **추가 옵션**을 누르세요. **영수증 언어**는 **프린터 텍스트 너비** 아래에 있는 네 번째 설정입니다(**프린터 편집**에서는 같은 설정을 **용지 너비**라고 합니다).

목록에는 열한 개 항목이 있습니다. 중국어, 일본어, 한국어 항목은 없으므로 [이미지로 인쇄](#print-the-receipt-as-an-image)하세요. 일부 항목은 언어 대신 지역이나 문자 체계의 이름을 사용합니다. 러시아어, 우크라이나어, 불가리아어는 **키릴 문자**에, 폴란드어, 체코어, 헝가리어는 **중부 유럽**에 해당합니다.

<details>
<summary>어떤 영수증 언어를 선택해야 하나요?</summary>

| 항목 | 용도 |
|---|---|
| **자동** | 앱이 줄마다 문자표를 선택합니다. 모든 프린터의 초기 설정입니다 |
| **영어** | 일반 영어 텍스트 |
| **서유럽** | 프랑스어, 독일어, 스페인어, 이탈리아어, 포르투갈어, 네덜란드어 및 북유럽 언어 |
| **중부 유럽** | 폴란드어, 체코어, 슬로바키아어, 헝가리어, 크로아티아어, 슬로베니아어 |
| **키릴 문자** | 러시아어, 우크라이나어, 불가리아어, 세르비아어 |
| **그리스어**, **터키어**, **아랍어**, **히브리어**, **태국어**, **베트남어** | 해당 언어 |

</details>

**영수증 언어**는 **프린터 편집**의 **프린터 언어**가 Epson과 대부분의 영수증 프린터에서 사용하는 **ESC/POS**일 때만 표시됩니다.

<details>
<summary>추가 옵션의 다른 설정</summary>

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[100, -18], [463, 0], [0, 0], [442, -38], [442, 45], [-34, 0], [-34, 0]]} alt="프린터 추가 패널에서 추가 옵션을 연 화면: 프린터 이름, Epson과 Star Micronics를 선택할 수 있는 제조사, 프린터 텍스트 너비, 자동으로 설정된 영수증 언어, 용지 자동 절단 및 금전함 자동 열기">

1. **추가 옵션** — 테스트 페이지를 인쇄하기 전에 패널에서 프린터 설정을 엽니다. 다시 누르면 닫힙니다.
2. **프린터 이름** — **설정 → 인쇄**의 프린터 행과 프린터 목록에 표시되는 이름입니다. 변경하기 전까지는 **영수증 프린터**입니다.
3. **제조사** — **Epson** 또는 **Star Micronics**입니다. **Star Micronics**를 선택하면 **영수증 언어**가 숨겨집니다. Star 프린터에서는 [비라틴 문자를 이미지로 인쇄](#print-the-receipt-as-an-image)하세요.
4. **프린터 텍스트 너비** — 한 줄에 들어가는 문자 수입니다. 58 mm 용지는 32자, 80 mm 용지는 42, 48 또는 64자입니다. 테스트 페이지로 확인할 수 있습니다. [영수증 너비](receipt-width.mdx)를 참고하세요.
5. **영수증 언어** — 영수증 텍스트에 사용할 문자표입니다. **자동**을 선택하면 앱이 줄마다 선택합니다. 목록은 [위](#receipt-language)에 있습니다.
6. **용지 자동 절단** — 영수증을 인쇄할 때마다 용지를 자릅니다.
7. **금전함 자동 열기** — 이 프린터에 연결된 금전함을 엽니다. [금전함](cash-drawer.mdx)을 참고하세요.

</JourneyShot>

아래의 **기본값으로 설정**을 켜면 다른 곳으로 지정되지 않은 모든 영수증을 이 프린터로 인쇄합니다. 여기 있는 모든 설정은 나중에 **프린터 편집**에서 변경할 수 있습니다. 패널의 나머지 항목은 [설정 마법사](setup-wizard.mdx)에서 설명합니다.

</details>

## 영수증을 이미지로 인쇄하기 {#print-the-receipt-as-an-image}

이 방법은 앱에서 추가한 모든 영수증 프린터에서 모든 언어에 사용할 수 있습니다. 앱이 영수증을 이미지로 만들어 전송하므로 프린터의 문자표는 더 이상 중요하지 않습니다.

:::warning
Wi-Fi 또는 네트워크 케이블로 연결된 Epson에서 이미지로 인쇄하려면 [보안 인쇄](secure-printing.mdx)를 꺼야 합니다.
:::

1. **설정 → 인쇄**로 이동하세요.
2. 프린터 행의 **편집**을 누르세요.
3. **프린터 편집**의 마지막 스위치인 **영수증을 이미지로 인쇄**를 켜세요. 다음과 같은 설명이 표시됩니다: *프린터에서 표시할 수 없는 문자(아랍어, 히브리어, 태국어)에 사용합니다. 텍스트보다 느리고 데이터 크기가 큽니다.*
4. **프린터 편집** 하단의 **테스트 인쇄**를 눌러 확인하세요. **설정 → 인쇄**의 프린터 행에도 **테스트 인쇄**가 있습니다.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} maxWidth={799} alt="프린터 편집의 설정 화면. 마지막 스위치인 영수증을 이미지로 인쇄는 꺼져 있으며 다음 설명이 표시됨: 프린터에서 표시할 수 없는 문자(아랍어, 히브리어, 태국어)에 사용합니다. 텍스트보다 느리고 데이터 크기가 큽니다.">

1. **프린터 언어** — 여기서는 **ESC/POS**입니다. **영수증 언어**가 없는 Star 프린터에서도 이미지 인쇄를 사용할 수 있습니다.
2. **용지 너비** — 한 줄의 문자 수입니다. [영수증 너비](receipt-width.mdx)를 참고하세요.
3. **영수증 언어** — 이미지는 프린터의 문자표를 사용하지 않으므로 이 설정은 더 이상 영향을 주지 않습니다.
4. **영수증을 이미지로 인쇄** — 여기서는 꺼져 있는 스위치입니다. 켠 다음 **테스트 인쇄**를 눌러 확인하세요.

</JourneyShot>

이 스위치는 **추가 옵션**에는 없고 **프린터 편집**에만 있습니다. 먼저 프린터를 추가한 뒤 켜세요.

:::tip
이미지는 텍스트보다 전송할 데이터가 훨씬 많아 영수증 한 장을 인쇄하는 데 더 오래 걸립니다. 필요한 프린터에서만 켜세요.
:::

## 문제의 원인 {#why-it-happens}

영수증 프린터는 컴퓨터의 글꼴을 사용하지 않습니다. 해당 문자를 텍스트로 인쇄할 수 없으면 물음표나 네모로 인쇄됩니다. 이미지를 사용하면 이 문제를 피할 수 있습니다.

<details>
<summary>영수증 프린터의 텍스트 인쇄 방식</summary>

프린터에 내장된 문자표를 한 번에 하나씩 사용해 텍스트를 인쇄합니다. 앱은 각 줄의 문자가 포함된 문자표를 선택합니다. 영어와 대부분의 유럽 언어 영수증은 이 방식으로 인쇄할 수 있습니다. 다른 문자 체계는 앱이 선택할 수 있는 문자표가 프린터에 없을 수 있으며, 인쇄할 수 없는 문자는 모두 물음표나 네모로 표시됩니다. **영수증 언어**는 영수증 전체에 사용할 문자표를 고정합니다. 이미지를 사용하면 문자표가 전혀 필요하지 않습니다.

</details>

## 아직 해결되지 않았나요? {#still-stuck}

**설정 → 인쇄**의 프린터 행에서 **⋯** 메뉴를 열고 **설정 보고서 복사**를 누르세요. Android 및 iOS 앱에서는 대신 공유 시트가 열립니다. 보고서를 문의 메시지에 붙여 넣고, 인쇄된 영수증 사진과 인쇄하려는 언어도 함께 알려주세요.
