Epson의 전원이 켜져 있고 자체 웹 페이지도 열리며 자체 테스트도 인쇄되지만, POS가 보내는 내용은 아무것도 나오지 않습니다. 껐다 켜도 달라지지 않습니다. 프린터의 **서버 직접 인쇄** 설정이 켜져 있는지 확인하세요.

:::note 먼저 WCPOS에서 사용 중인지 확인하세요
**설정 → 인쇄**의 해당 프린터 행에 **Epson 서버 직접 인쇄 · WCPOS에서 관리**가 표시되나요? 그렇다면 서버 직접 인쇄를 켜 두세요. WCPOS **클라우드 인쇄**가 이 방식으로 프린터에 영수증을 전송합니다. **프린터 추가**로 같은 프린터를 다시 추가하지 마세요. [클라우드 인쇄](../../receipts/cloud-printing.mdx#setup-polling)를 참고하세요.
:::

이 프린터를 처음 추가하거나 해당 행에 그런 문구가 없다면 [프린터의 웹 페이지에서 설정을 확인하세요](#turn-it-off).

## POS에 표시되는 내용 {#what-you-see}

**설정 → 인쇄 → 프린터 추가**에서 프린터를 추가하면 카드에 **연결 없음**이 표시되고 선택할 수 없습니다.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[302, 0], [0, 0], [136, -20], [161, 0]]} maxWidth={559} alt="주소를 확인한 후의 프린터 추가 패널. 오른쪽 위에 다시 검색이 있고, 그 아래 프린터 카드에는 주소와 Epson, 연결 없음 배지가 표시되며, 하단에는 IP 주소 입력과 프린터 안내 열기가 있습니다">

1. **프린터 카드** — 주소와 제조사가 표시됩니다. **연결 없음**은 앱이 해당 프린터로 인쇄할 방법을 찾지 못했다는 뜻이므로 카드를 선택할 수 없습니다.
2. **다시 검색** — 네트워크를 다시 검색합니다. 서버 직접 인쇄를 끈 후 사용하세요.
3. **IP 주소 입력** — 주소 하나를 직접 확인합니다. [주소 직접 입력하기](./setup-wizard.mdx#enter-address)를 참고하세요.
4. **프린터 안내 열기** — 이 프린터 안내 페이지들을 엽니다.

</JourneyShot>

다음과 같은 현상이 나타날 수도 있습니다.

- 테스트 페이지를 인쇄한 후 **인쇄된 내용 없음**과 함께 "프린터가 작업을 보류 중입니다. 껐다 켠 다음 다시 시도하세요."가 표시됩니다. 다시 시작한 후에도 같은 문구가 표시되면 서버 직접 인쇄가 켜져 있는지 확인하세요. 꺼져 있다면 POS에서 보낸 작업의 인쇄를 막는 또 다른 Epson 설정인 [Epson 보안 인쇄](./secure-printing.mdx)를 참고하세요.
- 이전에 저장한 프린터의 **테스트 인쇄**가 실패하고 모든 영수증도 인쇄되지 않습니다.

## 발생 원인 {#why-it-happens}

**서버 직접 인쇄**가 켜져 있으면 프린터가 서버에서 인쇄 작업을 가져옵니다. 이 기능이 켜져 있는 동안에는 네트워크에서 직접 전송되는 작업을 거부합니다. POS는 **프린터 추가**로 추가한 네트워크 프린터에 바로 이 방식으로 인쇄합니다. 프린터의 웹 페이지는 계속 작동하므로 정상처럼 보입니다. 저장되는 설정이므로 다시 시작해도 해제되지 않습니다.

직접 켜지 않았다면 이전 설정 과정이나 주방 서비스, 온라인 주문 서비스 또는 다른 계산대에서 켰을 수 있습니다.

## 끄기 {#turn-it-off}

:::warning 다른 시스템에서 필요할 수 있습니다
주방 디스플레이나 온라인 주문 서비스가 서버 직접 인쇄를 통해 이 Epson으로 인쇄하고 있다면, 이 기능을 끌 경우 해당 서비스에서 인쇄할 수 없게 됩니다. 둘 중 하나만 프린터를 사용할 수 있으므로 POS 전용 프린터를 마련하거나 해당 서비스를 다른 프린터로 옮기세요.
:::

프린터와 같은 네트워크에 있는 컴퓨터나 태블릿에서 프린터 자체 웹 페이지를 열어 설정합니다.

1. `https://` 뒤에 프린터 주소를 붙여 여세요. 예를 들면 `https://192.168.1.100`입니다. 인증서 경고를 수락하세요. 주소는 프린터의 상태 시트에 있습니다. [프린터 주소 찾기](./network-address.mdx)를 참고하세요.
2. **관리자 로그인**을 누르세요. 최근 모델은 누군가 변경하지 않았다면 프린터 밑면의 라벨에 있는 **일련번호**가 비밀번호입니다.
3. 메뉴에서 **서버 직접 인쇄**를 찾으세요. 위치는 모델과 펌웨어에 따라 다릅니다. TM-i 모델에서는 **웹 서비스 설정 → 직접 인쇄** 아래에 있고, 펌웨어 3.x 이하에서는 **구성 → 직접 인쇄** 아래에 있습니다. 다른 모델은 메뉴나 해당 모델의 설명서에서 찾아보세요.
4. 이미 **사용 안 함**으로 표시된다면 꺼진 상태를 유지하고 대신 [Epson 보안 인쇄](./secure-printing.mdx)의 안내를 따르세요. 그렇지 않다면 **사용 안 함**으로 설정하고 저장한 후 아래 단계를 계속 진행하세요.
5. 프린터가 다시 시작되도록 기다리거나, 전원을 끄고 십 초 후에 다시 켜세요.
6. POS로 돌아가 프린터를 테스트하세요.
   - **프린터를 추가하는 경우:** **다시 검색** 또는 **IP 주소 입력**을 누르세요. 카드에 **준비됨**이 표시되면 선택하고 **테스트 페이지 인쇄**를 누르세요.
   - **이미 저장된 프린터인 경우:** **설정 → 인쇄**에서 해당 프린터 행의 **테스트 인쇄**를 누르세요.

## 아직 해결되지 않았나요? {#still-stuck}

**설정 보고서 복사**를 누르고 문의 메시지에 붙여넣으세요. **인쇄된 내용 없음** 화면의 보고서에는 앱이 프린터에서 시도한 포트와 수신한 거부 응답이 나옵니다. 저장된 프린터라면 **설정 → 인쇄**에서 해당 행의 **추가 작업** 메뉴에 있습니다.
