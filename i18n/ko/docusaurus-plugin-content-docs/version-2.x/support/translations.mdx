**설정 안내가 아닙니다:** POS, 플러그인 또는 이 문서의 번역을 수정하거나 추가하는 방법입니다.

WCPOS는 AI로 번역하며, 배포 전에 사람이 매번 번역 내용을 확인합니다. 자신의 언어로 WCPOS를 사용하는 분들은 기계가 놓친 부분을 발견합니다. POS, 플러그인 또는 이 문서에 어색한 표현이 있다면 직접 수정할 수 있습니다. GitHub에서 한 줄을 고치고 풀 리퀘스트를 열면 됩니다. 개발자가 아니어도 괜찮습니다.

바로 가기: [POS 또는 플러그인 수정](#apps-and-plugin) · [이 문서 수정](#docs) · [언어 추가](#add-a-language)

## 사용하는 언어로 화면 확인하기 {#see-it}

표현을 수정하기 전에 실제로 사용되는 화면에서 확인하세요. POS는 WordPress의 사이트 언어에 설정된 매장의 언어로 열립니다. 한 기기에서 다른 언어를 사용해 보려면 메뉴에서 **설정**을 연 다음 **일반**을 여세요.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [120, 0], [110, 0]]} alt="설정의 일반 화면: 현지화 아래에서 언어 선택 목록을 열고 검색창에 Deutsch를 입력한 모습">

1. **설정** — 메뉴 하단에 있습니다.
2. **일반** — 설정의 첫 번째 페이지입니다.
3. **언어** — 이 기기에서 POS에 표시되는 언어입니다. 탭하면 목록이 열립니다. [언어](../settings/store/general.mdx#language)를 참조하세요.

</JourneyShot>

목록의 검색창에 입력해 원하는 언어를 찾은 다음 탭하세요:

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[110, 0], [150, 0], [292, 0]]} maxWidth={700} alt="열린 언어 목록: 검색창에 Deutsch가 입력되어 있고 아래에 독일어(Deutsch)와 독일어(스위스)(Deutsch (Schweiz))가 표시된 모습">

1. **검색** — 언어 이름을 영어나 해당 언어로 입력하세요. **Deutsch**를 입력하면 독일어를 찾을 수 있습니다.
2. **독일어(Deutsch)** — 언어를 탭하면 해당 언어로 전환됩니다. 각 언어는 영어 이름 뒤에 해당 언어의 이름이 표시됩니다.
3. **독일어(스위스)** — 기본 언어 옆에 지역별 언어가 표시됩니다. 매장에서 사용하는 언어를 선택하세요.

</JourneyShot>

이 변경 사항은 이 기기에만 적용됩니다. 매장과 다른 기기는 각각의 언어를 유지합니다. 매장의 언어로 돌아가려면 같은 페이지 하단에서 **서버 설정 복원**을 누르세요. 매장에서 보내는 통화와 숫자 형식도 함께 복원됩니다. 플러그인의 WP Admin 화면은 WordPress에서 설정한 사용자 언어를 따릅니다.

## POS 또는 플러그인의 표현 수정하기 {#apps-and-plugin}

앱과 플러그인의 모든 번역은 [wcpos/translations](https://github.com/wcpos/translations)에 있습니다.

1. 수정하려는 WCPOS 영역과 언어에 맞는 **파일을 찾으세요**. 독일어의 경우 POS 문구는 [독일어 POS: `core.json`](https://github.com/wcpos/translations/blob/main/translations/js/de_DE/monorepo/core.json)에, 플러그인의 PHP 문구는 [독일어 플러그인: `woocommerce-pos-de_DE.po`](https://github.com/wcpos/translations/blob/main/translations/php/de_DE/woocommerce-pos-de_DE.po)에 있습니다. 아래 **파일별 내용**에 모든 폴더가 나와 있습니다.
2. **표현을 찾으세요.** Ctrl+F 또는 Mac의 ⌘F를 눌러 화면에서 본 표현을 파일에서 검색하세요. JSON 파일에서는 키 뒤에 번역이 나옵니다. PO 파일에서는 영어 `msgid` 아래의 `msgstr` 줄이 번역입니다. 키나 영어 원문이 화면에서 본 위치와 일치하는지 확인하세요.
3. **번역된 텍스트만 변경하세요.** 키와 `msgid` 및 다음과 같은 모든 자리표시자: `{name}`, `%s`, `%d` 또는 `<strong>` 는 그대로 두세요.

   JSON 파일의 각 항목은 키, 콜론, 번역 순으로 구성됩니다. 여기서 영어 원문은 `Delete {name}`이며, 독일어에서는 동사가 마지막에 옵니다:

   ```json title="Before"
   "coupons.delete":
     "Löschen {name}",
   ```

   ```json title="After"
   "coupons.delete":
     "{name} löschen",
   ```

   독일어 단어만 변경되었습니다. 키인 `"coupons.delete"`와 `{name}`은 그대로 유지됩니다.

   PO 파일에서 `msgid`는 영어 원문이고 `msgstr`은 번역문입니다:

   ```text
   msgid "Copy of %s"
   msgstr "Kopie von %s"
   ```

   `msgstr` 줄의 표현만 변경하세요. `msgid` 줄과 `%s`는 그대로 두세요.

4. **풀 리퀘스트로 제출하세요.** [GitHub에서 수정 사항 제출하기](#send)를 참조하세요.

<details>
<summary>파일별 내용</summary>

| 폴더 | 내용 |
|---|---|
| `source/` | 자동으로 수집된 영어 원문입니다. 수정하지 마세요. |
| `translations/js/<locale>/monorepo/` | 캐셔가 사용하는 POS: 버튼, 장바구니, 결제, 대화 상자, 오류. |
| `translations/js/<locale>/electron/` | Windows 및 macOS용 데스크톱 앱 자체의 창과 메뉴. |
| `translations/js/<locale>/woocommerce-pos/` | 설정, 템플릿 등 무료 플러그인의 WP Admin 화면. 화면마다 파일이 하나씩 있습니다. |
| `translations/js/<locale>/woocommerce-pos-pro/` | 매장 편집기, Pro 설정 등 Pro 플러그인의 WP Admin 화면. |
| `translations/php/<locale>/` | 플러그인의 PHP 문구입니다. 수정할 파일은 `.po` 파일뿐입니다. 그 옆의 `.mo` 및 `.l10n.php` 파일은 저장소의 스크립트가 이 파일을 바탕으로 다시 생성하므로, 풀 리퀘스트 검사에서 `.mo` 파일이 최신 상태가 아니라는 메시지가 나올 수 있습니다. 풀 리퀘스트에 `.po` 파일만 변경했다고 적으세요. |

많은 언어에는 `de` 같은 기본 폴더와 `de_DE`, `de_AT` 같은 지역별 폴더가 있습니다. POS는 해당 언어가 가리키는 지역별 폴더를 읽습니다. 독일어(Deutsch)는 `de_DE`를 읽습니다. 기본 폴더인 `de`, `en`, `es`, `fr`, `nl`, `pt`, `zh`는 릴리스마다 대표 지역별 폴더에서 복사됩니다(`de`는 `de_DE`에서 복사). 따라서 지역별 폴더에서 수정하세요. 기본 폴더만 수정하면 나중에 덮어쓰입니다.

</details>

사용하는 언어가 없다면 [언어 추가](#add-a-language)를 참조하세요.

## 이 문서의 페이지 수정하기 {#docs}

[wcpos/docs](https://github.com/wcpos/docs)에는 각 페이지의 언어별 사본이 있습니다.

1. **파일을 찾으세요.** 페이지 하단의 **이 페이지 편집**을 누르면 GitHub에서 영어 파일이 열립니다. 경로에서 `versioned_docs/` 대신 `i18n/<locale>/docusaurus-plugin-content-docs/`를 사용하세요. 이때 해당 언어의 [언어 코드](#locale-codes) 를 `<locale>`자리에 넣으세요: `de` 는 독일어 코드입니다. 나머지 경로는 그대로 유지합니다. 예시는 다음과 같습니다: [이 페이지의 독일어 1.x 버전](https://github.com/wcpos/docs/blob/main/i18n/de/docusaurus-plugin-content-docs/version-1.x/support/translations.mdx).

   <details>
   <summary>다른 페이지 또는 언어 찾기</summary>

   이 문서는 Docusaurus를 사용합니다. 영어 페이지는 `versioned_docs/`의 버전별 폴더에 있습니다. 각 언어의 사본은 `i18n/<locale>/docusaurus-plugin-content-docs/`아래의 동일한 버전 폴더에 있으며 영어 페이지와 경로가 같습니다. 코드 목록은 다음을 참조하세요: [언어 코드](#locale-codes).

   프랑스어의 경우 영어 파일 `versioned_docs/version-2.x/support/translations.mdx`는 `i18n/fr/docusaurus-plugin-content-docs/version-2.x/support/translations.mdx`가 됩니다. [프랑스어 폴더](https://github.com/wcpos/docs/tree/main/i18n/fr/docusaurus-plugin-content-docs)를 둘러보며 어떤 파일이 있는지 확인하세요.

   </details>

2. **표현을 수정하세요.** Markdown 및 MDX 문법, 링크, 코드, 프런트매터 키는 그대로 두세요. 독자에게 보이는 본문, 제목, 레이블을 번역하세요.
3. **풀 리퀘스트로 제출하세요.** 수정할 파일은 `i18n/<locale>/`아래의 파일뿐이며, 영어 페이지는 수정하지 마세요. 다음을 참조하세요: [GitHub에서 수정 사항 제출하기](#send).

섹션 전체나 새 언어처럼 규모가 큰 작업은 먼저 이슈를 열어 함께 계획할 수 있도록 해주세요.

## GitHub에서 수정 사항 제출하기 {#send}

무료 GitHub 계정이 필요합니다. 모든 작업은 브라우저에서 진행하므로 설치할 것은 없습니다.

1. **GitHub에 로그인**하고 수정할 파일을 여세요.
2. 파일 오른쪽 위의 **연필 아이콘**인 **이 파일 편집**을 누르세요. 처음에는 GitHub에서 저장소를 포크하라는 안내가 표시됩니다. **이 저장소 포크**를 누르세요. 직접 수정할 수 있는 사본이 생성됩니다.
3. 편집기에서 **내용을 수정하세요**.
4. 편집기 위의 **변경 사항 커밋…** 을 누르세요. 대화 상자가 열립니다.
5. 대화 상자의 메시지 입력란에 **수정한 내용을 한 줄로 설명**한 다음 **변경 사항 제안**을 누르세요.
6. 다음 페이지에서 **풀 리퀘스트 만들기**를 누른 다음 **풀 리퀘스트 만들기**를 한 번 더 눌러 제출하세요.

검토자가 변경 사항을 확인하고 병합하거나 풀 리퀘스트에서 질문합니다.

## 수정 사항이 사용자에게 전달되는 과정 {#how-it-works}

모든 변경 사항은 배포 전에 사람이 검토합니다. 문서 수정 사항은 병합 후 사이트와 함께 게시됩니다. POS, 데스크톱 앱 또는 플러그인의 수정 사항은 다음 업데이트에서 사용자에게 전달됩니다.

<details>
<summary>전체 과정 단계별 안내</summary>

1. **영어 원문을 수집합니다.** 앱이나 플러그인이 변경되면 영어 문자열이 [wcpos/translations](https://github.com/wcpos/translations) 저장소에 수집됩니다. 이 문서의 원문은 [wcpos/docs](https://github.com/wcpos/docs)에 보관합니다.
2. 모든 언어에서 **AI가 빠진 번역을 채웁니다**. 언어별 규칙과 용어집을 따릅니다. 자리표시자나 마크업을 손상하거나 이전의 긴 제품명을 사용하는 번역은 거부되며 나중에 다시 시도합니다.
3. 풀 리퀘스트로 올라온 **번역 묶음을 사람이 검토**하고 병합합니다.
4. **수정 사항을 배포합니다.** 이 문서는 병합된 페이지를 바탕으로 사이트를 다시 빌드하여 게시합니다. 앱과 플러그인은 병합하면 새 번역 릴리스가 생성됩니다. POS, 데스크톱 앱, 플러그인은 각각 고정된 릴리스를 사용하므로 수정 사항은 다음 업데이트에서 반영됩니다. `.po` 파일의 수정 사항은 먼저 `.l10n.php` 파일도 다시 생성해야 하므로 더 오래 걸릴 수 있습니다.

앱과 플러그인은 매일 검사하며, 빠진 번역이 남아 있으면 [wcpos/translations](https://github.com/wcpos/translations/issues)에 이슈를 엽니다.

</details>

따라서 대개 빈 파일에서 시작할 일은 없습니다. 이미 번역되어 있지만 어색한 부분을 고치게 됩니다. 딱딱한 문장, 해당 언어의 WooCommerce 용어와 맞지 않는 표현, 버튼에 맞지 않는 레이블 등이 있습니다.

:::note translate.wordpress.org에서는 받지 않습니다
WCPOS는 더 이상 translate.wordpress.org에서 번역을 받지 않습니다. 해당 사이트는 기계 번역을 허용하지 않아 대부분의 언어가 완성되지 못했습니다. 플러그인은 wcpos/translations에서 자체 번역을 다운로드합니다. 이전에 그곳에서 WCPOS를 번역해 주셨다면 감사드립니다. 이제 수정 사항은 이 페이지에 안내된 곳으로 제출해 주세요.
:::

## 언어 추가 {#add-a-language}

앱과 플러그인은 50개 이상의 언어와 지역별 언어를 지원하며, 목록은 [`locales.json`](https://github.com/wcpos/translations/blob/main/locales.json)에 있습니다. 이 문서는 그보다 적은 언어를 지원하며 아래에 나와 있습니다. 사용하는 언어가 없다면 필요한 저장소에 이슈를 열어 주세요. 해당 언어를 추가하겠습니다. AI가 새 언어의 번역을 빠르게 채우면, 그 언어를 사용하는 분들이 자연스럽게 다듬습니다.

### 언어 코드 {#locale-codes}

<details>
<summary>언어 코드 찾기</summary>

이 문서는 다음 언어로 제공됩니다:

| 코드 | 언어 |
|---|---|
| `ar` | 아랍어 *(오른쪽에서 왼쪽으로)* |
| `de` | 독일어 |
| `es` | 스페인어 |
| `fr` | 프랑스어 |
| `hi-IN` | 힌디어(인도) |
| `it` | 이탈리아어 |
| `ja` | 일본어 |
| `ko` | 한국어 |
| `nl` | 네덜란드어 |
| `pt-BR` | 포르투갈어(브라질) |
| `zh-CN` | 중국어(간체) |

두 저장소는 코드를 다르게 표기합니다. wcpos/translations는 `de_DE`, `pt_BR`, `zh_CN`처럼 밑줄을 사용하며, 기본 언어(`de`, `fr`, `es`)와 지역별 언어(`de_AT`, `fr_CA`, `es_MX`)가 모두 있습니다. 이 문서는 `pt-BR`, `hi-IN`, `zh-CN`처럼 하이픈을 사용합니다. 수정하는 저장소의 형식을 따르세요.

</details>

## 검토자가 확인하는 사항 {#translator-tips}

AI가 따르는 규칙이며, 검토자도 이 규칙을 기준으로 변경 사항을 확인합니다.

- **자리표시자는 그대로 유지합니다.** `{name}`, `%s`, `%d` 및 다음과 같은 태그: `<strong>` 는 WCPOS가 값을 채우거나 화면에 표시합니다. 그 주변의 텍스트를 번역하세요.
- **제품명은 영어로 유지합니다.** `WCPOS`, `WCPOS Pro`, `WooCommerce`, `WordPress`는 번역하지 않으며, Stripe, PayPal, Square, Android, iOS, macOS, Windows 같은 다른 브랜드와 플랫폼 이름도 마찬가지입니다. 사용자가 읽는 텍스트에는 **WCPOS**라고 쓰세요. 이전의 긴 이름은 슬러그, 파일 이름, 웹 주소에만 사용합니다.
- **WooCommerce 용어를 우선합니다.** 매장 운영자는 WCPOS와 WooCommerce를 함께 사용하므로 쿠폰, 환불, 세금, 결제 방법처럼 WooCommerce에서도 쓰는 용어는 해당 언어의 WooCommerce 번역과 일치해야 합니다. 캐셔, 계산대, 현금 서랍처럼 WooCommerce에 없는 용어는 해당 언어의 용어집인 `scripts/translation-glossary.json`을 따르세요.
- **영어와 비슷한 길이를 유지하세요.** 한 단어로 된 버튼은 한두 단어로 유지하세요. POS 화면은 공간이 좁습니다.
- **격식 수준은 해당 언어의 지침을 따릅니다.** 일부 언어는 wcpos/translations의 `scripts/locale-context/`에 문체, 소수점 구분 기호, 자주 하는 실수 등을 정리한 지침이 있습니다. 예를 들어 독일어는 **Sie**를 사용합니다.
- **코드는 그대로 유지합니다.** 쿠폰 코드, 결제 게이트웨이 ID, 언어 코드, 파일 경로, 쇼트코드는 번역하지 않습니다. 확실하지 않다면 영어로 두세요. 이 문서에서는 한 가지 예외가 있습니다. `WP Admin > WooCommerce > 설정 > 결제`처럼 코드 형식으로 표시한 메뉴 경로는 해당 언어의 WordPress와 WooCommerce에 표시되는 메뉴 이름을 사용합니다. `>` 기호와 WP Admin, WooCommerce, WCPOS라는 이름은 그대로 두세요.
- **화면에서 확인하세요.** 한 화면에 잘 맞는 표현이 다른 화면에서는 줄바꿈될 수 있습니다. [사용하는 언어로 화면 확인하기](#see-it)를 참조하세요.

아랍어, 히브리어, 페르시아어, 우르두어처럼 오른쪽에서 왼쪽으로 쓰는 언어는 영수증에도 같은 방향의 템플릿이 필요합니다. 갤러리에서 찾을 수 있습니다. [영수증 맞춤 설정](../receipts/customise.mdx#the-bundled-templates)과 [비라틴 문자 영수증](../hardware/printers/non-latin-receipts.mdx)을 참조하세요.
