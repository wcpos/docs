POS는 빠르게 판매하고 오프라인에서도 판매를 계속할 수 있도록 각 기기에 매장 데이터의 사본을 보관합니다. **모든 로컬 데이터 삭제**는 이 사본을 삭제하고 매장에서 다시 다운로드합니다. 다른 부분적인 조치로 해결할 수 없을 만큼 기기의 데이터에 문제가 생겼을 때 사용하는 방법입니다. 처음부터 시도하지 말고 마지막 수단으로 사용하세요.

:::warning 매장에 전송되지 않은 판매 내역은 사라집니다
이 기기에서 아직 전송하지 않은 데이터는 다른 데이터와 함께 삭제되며 복구할 수 없습니다. 이미 판매를 완료해 대금이 현금 서랍에 들어 있는 판매 내역도 포함될 수 있습니다. [먼저 확인하세요](#check-unsent).
:::

## 먼저 시도할 방법 {#try-first}

다음 방법은 각각 한 가지 문제만 해결하며 기기의 다른 데이터에는 영향을 주지 않습니다.

- **특정 종류의 기록에 문제가 있는 경우**(상품, 고객, 주문): [매장 상태 → 데이터베이스](../store-health.mdx#clear-and-redownload)의 해당 행에서 **삭제 후 다시 다운로드…** 를 선택하세요. 기기의 다른 데이터는 바뀌지 않으며 로그인도 유지됩니다. **주문**을 삭제하기 전에 모든 미결 주문을 완료하거나 동기화하세요. 한 번도 동기화하지 않은 주문은 이 기기에만 존재합니다.
- **WooCommerce의 변경 사항이 반영되지 않은 경우:** 같은 행의 메뉴에서 **지금 변경 사항 확인**을 선택하세요. [다운로드 및 동기화](../../products/sync.mdx)를 참조하세요.
- **이 기기의 언어, 통화 또는 숫자 형식이 잘못된 경우:** **설정 → 일반** 하단의 **서버 설정 복원**을 누르면 WooCommerce 매장의 값으로 돌아갑니다. [일반 설정](../../settings/store/general.mdx#restore-server-settings)을 참조하세요.
- **화면에 빨간색 "문제가 발생했습니다" 패널이 나타나는 경우:** 패널을 닫거나 새로고침하세요. [CLIENT151](../../error-codes/CLIENT151.mdx)을 참조하세요.

## 전송 대기 중인 항목이 없는지 확인하기 {#check-unsent}

매장 상태는 현재 로그인한 매장과 캐셔의 데이터만 집계합니다. 각 매장에서 각 캐셔가 처리한 판매 내역은 기기에 별도로 보관되며, 데이터를 삭제하면 모두 사라집니다. 따라서 이 기기를 사용하는 모든 캐셔에 대해 각자가 사용하는 모든 매장을 확인하세요:

1. **매장 상태**를 열고 **데이터베이스** 탭에서 **전송 대기 중인 변경 사항**을 확인하세요. 반드시 **0**이어야 하며, 수치 아래에 **변경 사항 …개가 서버에 전송되지 않았습니다** 또는 **변경 사항 …개가 보류되었습니다** 패널이 없어야 합니다. 패널이 있다면 먼저 해결하세요. [조치가 필요할 때](../store-health.mdx#needs-attention)를 참조하세요.
2. 장바구니 아래의 미결 주문을 확인하세요. 결제하거나 동기화하지 않은 주문은 이 기기에만 존재하며 해당 수치에 포함되지 않습니다. 주문을 완료하거나 **주문 상세 정보**에서 **주문 동기화**를 누르세요. [매장에 주문 저장하기](../../pos/cart/open-orders.mdx#sync-order)를 참조하세요. 주문 표시줄에는 한 번에 계산대 하나의 주문만 표시됩니다. 이 캐셔가 같은 매장에서 다른 계산대도 사용한다면 캐셔 패널에서 **계산대 전환**을 선택하고 하나씩 확인하세요.
3. 아바타를 탭해 캐셔 패널을 열고 다음 캐셔를 선택하세요. 다른 매장을 확인하려면 같은 패널에서 **매장 전환**을 선택하세요. [매장 및 계산대 선택](../../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)을 참조하세요.
4. 모든 캐셔가 조건을 충족할 때까지 반복하세요. 모두 확인할 수 없다면 삭제하지 말고 [지원팀에 문의하세요](../index.mdx).

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [150, 0], [160, 0], [100, -369]]} alt="매장 상태의 데이터베이스 탭: 상단에 전송 대기 중인 변경 사항 0개가 표시되고 아래에는 이 기기의 기록 표가 있는 모습">

1. **매장 상태** — 메뉴 하단의 맥박 아이콘입니다.
2. **데이터베이스** — 이 기기에 있는 데이터와 전송 대기 중인 항목을 보여줍니다.
3. **전송 대기 중인 변경 사항** — 매장으로 전송 중인 판매 내역, 고객 및 수정 사항입니다. 장바구니에 남아 있는 미결 주문과 사용자의 결정을 기다리는 변경 사항은 여기에 포함되지 않습니다.
4. **표** — 이 기기와 매장에 있는 기록을 종류별로 보여줍니다. **⋮** 메뉴에는 [먼저 시도할 방법](#try-first)에서 설명한 부분적인 해결 방법이 있습니다.

</JourneyShot>

- **0이고, 패널이 없으며, 동기화하지 않은 미결 주문도 없는 경우:** 이 캐셔가 이 매장에서 처리한 작업은 모두 매장에 전송되었습니다. 다음 캐셔를 확인하세요.
- **0보다 큰 경우:** 아직 삭제하지 마세요. 기기를 인터넷에 연결하고 수치가 0이 될 때까지 기다리세요. 줄어들지 않으면 ["전송 대기 중인 변경 사항"이 줄어들지 않음](../store-health.mdx#waiting-to-send)을 참조하세요.

## 삭제되는 항목 {#what-gets-cleared}

이 기기에만 적용됩니다. 매장과 다른 모든 기기는 영향을 받지 않습니다. 전송되지 않은 판매 내역은 사라지며, 프린터, 스캐너 및 계산대 선택을 다시 설정해야 합니다. 데스크톱 및 모바일 앱에서는 저장된 매장과 로그인 정보도 삭제되므로 이후 매장을 다시 연결해야 합니다.

<Accordion>
<AccordionItem question="이 기기에서 삭제되는 항목">

- 기기에 보관된 상품, 고객, 주문, 쿠폰 및 세금
- 아직 전송하지 않은 판매 내역과 변경 사항
- 이 기기에 설정된 프린터와 바코드 스캐너
- 선택한 계산대
- 이 기기의 **설정 → 일반**에서 변경한 내용
- 매장 상태에 기록된 이 기기의 활동 로그
- 데스크톱 및 모바일 앱의 매장과 로그인 정보

</AccordionItem>
<AccordionItem question="매장에 유지되는 항목">

- 이 기기에서 이미 전송한 모든 데이터: 판매 내역, 고객, 수정 사항
- WooCommerce 상품, 고객 및 주문
- WP Admin에서 지정한 설정
- 계산대 및 이미 전송된 마감 내역

</AccordionItem>

삭제한 후에는 [인쇄](../../hardware/printers/index.mdx)에서 프린터를, [바코드 스캔](../../settings/store/barcode.mdx)에서 스캐너를 다시 설정하세요.

## 모든 로컬 데이터 삭제하기 {#clear}

1. 메뉴 하단의 톱니바퀴 아이콘으로 **설정**을 연 다음, 목록 맨 위의 **일반**을 여세요.
2. 맨 아래로 스크롤하고 **모든 로컬 데이터 삭제**를 누르세요.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[40, 0], [-72, 0], [-100, 0]]} alt="설정 → 일반의 맨 아래로 스크롤한 모습: 메뉴의 설정 톱니바퀴, 설정 목록 맨 위의 일반, 서버 설정 복원과 그 아래의 모든 로컬 데이터 삭제">

1. **설정** — 메뉴 하단의 톱니바퀴입니다. **일반**은 목록의 첫 번째 페이지입니다.
2. **서버 설정 복원** — [먼저 시도할 방법](#try-first)에서 설명한 부분적인 해결 방법입니다. 아무 데이터도 삭제하지 않습니다.
3. **모든 로컬 데이터 삭제** — 페이지의 마지막 버튼입니다. 삭제하기 전에 확인을 요청합니다.

</JourneyShot>

3. 확인 메시지를 읽으세요. 첫 줄의 내용에 따라 다음과 같이 진행하세요:
   - **변경 사항 개수가 표시되면 취소를 누르세요.** *이 기기의 변경 사항 N개가 서버에 전송되지 않았으며 영구적으로 삭제됩니다.* [먼저 전송하세요](#check-unsent).
   - **앱에서 확인할 수 없었다고 나오면, 모든 매장의 모든 캐셔가 [확인 조건](#check-unsent)을 충족한 경우에만 진행하세요. 대기 중인 항목 0개, 패널 없음, 동기화하지 않은 미결 주문 없음이 조건입니다.** 그렇지 않으면 **취소**를 누르고 [지원팀에 문의하세요](../index.mdx). 앱은 기기의 다른 캐셔와 매장을 확인할 수 없으므로, 현재 매장에 대기 중인 항목이 없을 때마다 *앱에서 전송 대기 중인 변경 사항을 확인할 수 없습니다…* 메시지를 표시합니다.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-24, 0], [0, 32]]} alt="설정 위에 표시된 모든 로컬 데이터를 삭제하시겠습니까? 확인 창: 서버에 전송되지 않은 판매 내역에 대한 경고, 취소 버튼과 모든 로컬 데이터 삭제 버튼">

1. **취소** — 확인 창을 닫습니다. 아무 데이터도 삭제하지 않습니다.
2. **모든 로컬 데이터 삭제** — 이 기기에 저장된 모든 데이터를 삭제합니다. 되돌릴 수 없습니다.

</JourneyShot>

4. **모든 로컬 데이터 삭제**를 누르세요. 데스크톱 앱에서는 **정말 진행하시겠습니까?** 라고 한 번 더 묻습니다. **예**를 누르세요. POS가 다시 시작됩니다. iOS 및 Android 앱에서는 **다시 시작 필요**가 표시됩니다. 앱을 완전히 종료한 다음 다시 여세요.

## 삭제 후 진행 과정 {#what-happens-next}

**브라우저에서는** 페이지가 새로고침되며, WordPress에 로그인되어 있으므로 로그인 상태가 유지됩니다. **데스크톱 앱에서는** 처음 설치한 상태처럼 다시 시작되므로 매장을 연결하고 다시 로그인해야 합니다. **iOS 및 Android 앱에서는** 안내가 나오면 앱을 닫았다가 다시 연 다음 매장을 연결하고 다시 로그인하세요. [매장에 연결하기](../../getting-started/connect.mdx)를 참조하세요.

그런 다음 POS가 처음 사용했을 때처럼 상품, 고객 및 최근 주문을 다운로드합니다. [다운로드 및 동기화](../../products/sync.mdx)를 참조하세요. 매장에 계산대가 여러 개 있으면 POS가 이 기기에서 사용할 계산대를 묻습니다. [매장 및 계산대 선택](../../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)을 참조하세요.

## 앱이 열리지 않을 때 {#app-wont-open}

앱 전체가 **문제가 발생했습니다** 화면에서 멈추고 **다시 시도하면 이 기기의 모든 데이터가 유지됩니다**라는 메시지가 표시되면 버튼 두 개가 제공됩니다. 먼저 **다시 시도**를 누르세요.

:::warning 초기화 전에 확인하세요
이 화면이나 아래에 설명된 데스크톱 앱 메뉴에서 초기화하면 이 기기에서 전송하지 않은 판매 내역이 모두 삭제됩니다. [모든 매장의 각 캐셔](#check-unsent)가 조건을 충족한 후에만 초기화하세요. 전송 대기 중인 변경 사항 **0**개, 패널 없음, 동기화하지 않은 미결 주문 없음이 조건입니다. 앱이 열리지 않아 확인할 수 없다면 초기화하기 전에 [지원팀에 문의하세요](../index.mdx).
:::

- **다시 시도** — 데이터를 건드리지 않고 앱을 다시 열어 봅니다. 항상 이 방법을 먼저 시도하세요.
- **앱 데이터 초기화 및 다시 시작** — 이 화면에서 모든 로컬 데이터를 삭제합니다. **앱 데이터를 초기화하고 다시 시작하시겠습니까?** 라고 묻고, 설정의 확인 창처럼 삭제될 변경 사항의 개수를 알려줍니다. **초기화 및 다시 시작** 또는 **취소**를 누르세요.

앱에서 전송 대기 중인 항목이 있는지 알 수 없는 경우도 있습니다. 이때는 서버에 전송되지 않은 완료된 판매 내역이 초기화 대상에 포함될 **수 있음**을 경고합니다. 오프라인에서 처리한 판매가 WooCommerce에 보이지 않는다면 초기화하지 말고 지원팀에 문의하세요.

데스크톱 앱은 메뉴 막대에서도 데이터를 삭제할 수 있습니다. **창 → 고급 → 앱 데이터 삭제**를 선택한 다음 **예**를 누르세요. 앱이 제대로 열리지 않아 설정에 접근할 수 없을 때 사용하세요.

## 문제가 발생한 경우 {#goes-wrong}

**"다시 시작 필요".** 앱이 스스로 다시 시작할 수 없습니다. 완전히 종료한 다음 다시 여세요. 시작하면서 데이터를 삭제합니다.

**"초기화가 완료되지 않았습니다".** 삭제가 중간에 멈췄으며, 완료될 때까지 새 데이터를 저장할 수 없습니다. **새로고침 후 다시 시도**를 누르세요. 버튼이 없다면 앱을 완전히 종료한 다음 다시 여세요.

**"로컬 데이터를 삭제할 수 없습니다".** 앱을 완전히 종료하고 다시 연 다음 한 번 더 시도하세요.

**첫 다운로드가 느립니다.** 규모가 큰 매장은 시간이 걸립니다. [매장 상태 → 데이터베이스](../store-health.mdx#database)에서 진행 상황을 확인할 수 있습니다. 오래된 주문처럼 필요할 때 다운로드하는 기록은 해당 항목을 열면 다시 가져옵니다.

**삭제 후 문제가 다시 발생했습니다.** 다시 삭제하지 마세요. 화면에 나타나는 내용을 기록하고 [지원팀에 문의하세요](../index.mdx).
