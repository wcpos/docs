**WCPOS StoreApps Smart Coupons** 확장 기능을 사용하면 기프트 카드와 같은 StoreApps의 [Smart Coupons](https://woocommerce.com/products/smart-coupons/) 매장 적립금 쿠폰으로 POS 판매 대금의 일부를 결제할 수 있습니다. WCPOS Pro에서는 결제 화면의 결제 페이지에서 카드를 사용할 수 있으며, 정확한 금액이 차감되고 남은 잔액이 영수증에 표시됩니다.

:::warning 할인 추가에서는 매장 적립금을 사용할 수 없습니다
장바구니의 **할인 추가**에 기프트 카드를 입력하면 **쿠폰을 찾을 수 없습니다**가 표시됩니다. 대신 결제 화면의 **레거시** 탭에서 사용하세요. [계산대에서 기프트 카드로 결제받기](#at-the-till)를 참고하세요.
:::

## 계산대에서 기프트 카드로 결제받기 {#at-the-till}

시작하기 전에 관리자가 StoreApps의 Smart Coupons를 활성화하고 [이 확장 기능을 설치](#install)해야 합니다. 결제 화면의 [레거시 탭](../pos/checkout/legacy-tab.mdx)에 결제 수단도 있어야 합니다. 이 탭에서는 쿠폰 입력란이 있는 매장 자체 결제 페이지가 열립니다.

1. 장바구니에 상품을 담고 **결제**를 누른 다음 **레거시** 탭을 여세요. 결제 화면 안에 매장의 결제 페이지가 열립니다.
2. **쿠폰 코드**에 기프트 카드 코드를 입력하고 **쿠폰 적용**을 누르세요. 카드로 결제되는 금액만큼 주문 합계가 줄어듭니다.
3. 고객이 나머지 금액을 지불할 결제 수단을 선택하고 해당 페이지에서 결제를 받은 다음 **결제 처리**를 누르세요.
4. [영수증에 표시되는 내용](#receipt)과 같이 영수증의 쿠폰 할인 행에서 **매장 적립금 잔액**을 확인하세요. 표시되지 않으면 [문제가 발생한 경우](#goes-wrong)를 참고하세요.

**레거시** 탭에 결제 수단이 없으면 카드를 사용할 결제 페이지도 없습니다. 평소처럼 결제를 받고 고객에게 기프트 카드를 다음 구매에 사용하도록 안내하세요. 카드에서는 아무 금액도 차감되지 않았습니다.

## 영수증에 표시되는 내용 {#receipt}

쿠폰 할인 행 끝에는 영수증 생성 시점의 카드 잔액이 표시됩니다. 설명이 **기프트 카드**인 매장 적립금 쿠폰은 **표준 영수증**에 다음과 같이 인쇄됩니다.

> 할인 · 기프트 카드 — 매장 적립금 잔액: $61.50

결제 시 발행하는 영수증에는 판매 직후의 잔액이 표시됩니다. 영수증 템플릿에 새로 추가할 내용은 없습니다. 쿠폰에 설명이 없어도 행 끝에 **매장 적립금 잔액**이 표시됩니다. 해당 행에 **할인** 대신 **기프트 카드**를 인쇄하려면 [개발자 안내](#developers)를 참고하세요.

## 주요 기능 {#what-it-does}

StoreApps는 온라인 주문의 기프트 카드 잔액을 관리하지만, 단독으로는 POS에서 결제한 주문을 처리하지 못합니다. POS 주문에 매장 적립금 쿠폰이 있으면 이 확장 기능은 다음 작업을 수행합니다.

- **사용한 금액만 정확히 차감합니다.** 주문에서 카드로 사용한 금액을 기록하므로 StoreApps가 그 금액만 차감하고 나머지는 카드에 남겨 둡니다.
- **주문이 결제될 때 잔액을 차감합니다.** 쿠폰을 적용할 때는 차감하지 않으며, 중복으로 차감하지도 않습니다.
- **제거한 쿠폰은 처리 대상에서 제외합니다.** 결제 전에 쿠폰을 제거하면 해당 쿠폰에서는 아무 금액도 차감되지 않습니다.
- **주문에 메모를 남깁니다.** [주문 메모](#order-note)를 참고하세요.
- **영수증에 잔액을 인쇄합니다.** [영수증에 표시되는 내용](#receipt)을 참고하세요.

StoreApps Smart Coupons를 비활성화하면 이 확장 기능은 아무 작업도 수행하지 않습니다.

## 확장 기능 설치 {#install}

관리자가 **WP Admin**에서 한 번 설치하면 됩니다. WCPOS Pro에서는 **POS → 설정 → 확장 기능**에서 설치하고, 무료 플러그인에서는 릴리스 파일을 업로드하여 설치합니다.

<details>
<summary>WCPOS Pro 또는 무료 플러그인에서 설치하는 방법</summary>

:::note 시작하기 전에
**WP Admin**에 로그인할 관리자 계정이 필요하며, 사이트에 StoreApps의 Smart Coupons(WooCommerce.com에서 판매)가 활성화되어 있어야 합니다. 이 확장 기능은 해당 플러그인에서만 작동하며, 이름에 ‘Smart Coupons’가 포함된 다른 플러그인에서는 작동하지 않습니다.
:::

### WCPOS Pro 사용 시 {#install-pro}

1. **WP Admin**에서 **POS → 설정 → 확장 기능**으로 이동하세요.
2. **WCPOS StoreApps Smart Coupons**를 찾아 **설치**를 누르세요.
3. **활성화**를 누르세요.

업데이트와 자동 업데이트는 [확장 기능 설치](./index.mdx#installing-an-extension)를 참고하세요.

### 무료 플러그인 사용 시 {#install-free}

확장 기능 화면에 이 확장 기능이 표시되지만, 버튼을 사용하려면 Pro가 필요합니다. 대신 다음과 같이 설치하세요.

1. 확장 기능의 [최신 릴리스](https://github.com/wcpos/wcpos-storeapps-smart-coupons/releases/latest)에서 `wcpos-storeapps-smart-coupons.zip`을 다운로드하세요.
2. **WP Admin**에서 **플러그인 → 새 플러그인 추가**로 이동하고 **플러그인 업로드**를 누르세요.
3. 다운로드한 파일을 선택하고 **지금 설치**를 누르세요.
4. **플러그인 활성화**를 누르세요.

</details>

설치 후 별도로 설정할 항목은 없습니다. 평소처럼 WooCommerce에서 매장 적립금 쿠폰이나 기프트 카드를 만드세요.

## 주문 메모 {#order-note}

주문이 결제되면 확장 기능이 비공개 메모를 하나 추가합니다. 직원은 **WP Admin → WooCommerce → 주문**의 해당 주문에서 이 메모를 확인할 수 있습니다.

> WCPOS용 StoreApps Smart Coupons 매장 적립금 기록: 쿠폰 store100에서 $38.50 사용. 현재 잔액: $61.50.

이 메모로 어떤 카드로 결제했는지, 사용한 금액과 남은 잔액이 얼마인지 확인하세요. 메모는 주문당 한 번 추가됩니다.

## 환불 및 취소 {#refunds}

이 확장 기능은 적립금을 복원하지 않습니다. 매장 적립금으로 일부를 결제한 주문을 환불하거나 취소하면 StoreApps가 잔액 처리 방식을 결정합니다. 이후 **WP Admin → 마케팅 → 쿠폰**에서 쿠폰 금액을 확인하세요. 고객에게 있어야 할 금액과 다르면 매장 관리자에게 문의하세요. 관리자가 해당 화면에서 쿠폰 금액을 변경할 수 있습니다.

## 문제가 발생한 경우 {#goes-wrong}

**할인 추가**에서 기프트 카드를 적용하면 **쿠폰을 찾을 수 없습니다**가 표시됩니다. WCPOS 2.0의 할인 추가에서는 비율 할인, 장바구니 고정 할인, 상품 고정 할인 쿠폰만 적용할 수 있으므로, 이 확장 기능의 설치 여부와 관계없이 매장 적립금 쿠폰을 입력하면 **쿠폰을 찾을 수 없습니다**가 표시됩니다. 대신 [레거시 탭의 결제 페이지](#at-the-till)를 사용하세요.

**판매 후 잔액이 줄어들지 않았습니다.** **플러그인**에서 **Smart Coupons**와 **WCPOS StoreApps Smart Coupons**가 모두 활성화되어 있는지 확인하세요. 잔액은 쿠폰을 적용할 때가 아니라 주문이 결제될 때 차감됩니다. 매장 적립금 메모가 없는 주문은 이 확장 기능에서 잔액을 차감하지 않은 주문입니다.

**영수증에 잔액이 없습니다.** 계산대가 오프라인일 때 인쇄한 영수증에는 잔액이 표시되지 않습니다. 계산대가 다시 온라인 상태가 되면 재인쇄하세요. 그래도 표시되지 않으면 영수증 템플릿이 할인 행의 라벨을 인쇄하지 않는 것입니다. [영수증 데이터](../receipts/receipt-data.mdx#discounts)를 참고하세요.

<details>
<summary>개발자 안내: 저장 데이터 및 훅</summary>

<Anchor id="developers" />

이 확장 기능은 WCPOS 쿠폰 필드를 추가하지 않습니다. WooCommerce 주문 메타와 StoreApps 자체 잔액 처리 로직을 통해 작동합니다. POS 주문(`wcpos_is_pos_order()`: `created_via`가 `woocommerce-pos`)에만 적용되며, `smart_coupon` 유형의 쿠폰만 처리합니다.

- **사용 내역.** `woocommerce_order_after_calculate_totals`에서 StoreApps가 아직 기록하지 않았다면 StoreApps의 `smart_coupons_contribution` 주문 메타(쿠폰 코드 → 사용 금액)와 `wc_sc_environment`를 기록합니다. 미결제 주문에서 제거된 쿠폰의 항목은 삭제합니다.
- **결제 페이지의 쿠폰 입력란.** 이 양식은 `WC_Order::apply_coupon()`으로 보내는 일반적인 프런트엔드 POST 요청이며, StoreApps는 이를 주문 컨텍스트로 처리하지 않습니다. `smart_coupon` 행이 있는 미결제 POS 주문이 REST 요청 외부에서 재계산될 때 확장 기능은 REST 컨텍스트로 보고하여 StoreApps 자체 주문 할인 로직이 실행되도록 합니다.
- **차감.** POS 주문은 `pos-open` 또는 `pos-partial` 상태에서 결제되지만, StoreApps는 `pending` 또는 `failed` 상태에서 전환될 때만 차감합니다. 그 외의 상태에서 결제된 상태 또는 `on-hold`로 전환되는 `woocommerce_order_status_changed` 시점에 StoreApps의 `WC_SC_Coupon_Process::update_smart_coupon_balance()`를 호출합니다. 이 메서드는 각 쿠폰 행에 표시를 남겨 중복 차감을 방지합니다.
- **주문 메모.** `processing`, `completed` 또는 `on-hold`로 전환될 때 주문당 한 번 추가됩니다(`_wcpos_storeapps_smart_coupons_audit_note_added`).
- **영수증.** WCPOS 영수증을 렌더링하는 동안 `woocommerce_coupon_get_description`을 필터링합니다. 또한 영수증 데이터 필터에서 `discounts`의 매장 적립금 행에 `gift_card: true`를 추가하고 해당 행의 `label` 끝에 잔액을 덧붙입니다. 그러면 템플릿에서 다음과 같이 인쇄할 수 있습니다.

```text
{{#discounts}}{{#gift_card}}Gift Card{{/gift_card}}{{^gift_card}}{{i18n.discount}}{{/gift_card}} · {{label}}{{/discounts}}
```

- **훅 이름.** 버전 0.2.3은 여전히 2.0 이전 이름인 `woocommerce_pos_receipt_data`, `woocommerce_pos_before_template_render`, `woocommerce_pos_after_template_render`에 훅을 등록합니다. WCPOS 2.0은 `wcpos_` 이름의 훅을 실행한 뒤 이 훅들도 실행하며, `WP_DEBUG`가 켜져 있으면 WordPress가 각 훅에 대해 사용 중단 알림을 기록합니다. [훅 이름 규칙](./index.mdx#hook-naming)을 참고하세요.

소스: [github.com/wcpos/wcpos-storeapps-smart-coupons](https://github.com/wcpos/wcpos-storeapps-smart-coupons).

</details>

:::info WCPOS Pro 사용 시
계산대에서는 레거시 탭의 결제 페이지에서 기프트 카드로 결제를 받으며, **POS → 설정 → 확장 기능**에서 확장 기능을 설치하고 업데이트합니다. Pro가 없으면 위에서 설명한 대로 릴리스 파일을 직접 설치하세요.
:::
