**WP 관리자:** `WP Admin → POS → Settings → Extensions`에서 설치하고, `WP Admin → POS → Stores`에서 매장별로 설정합니다.

WPML은 상품의 각 번역을 별도의 상품으로 저장합니다. 별도 처리가 없으면 POS에 이 상품들이 모두 표시됩니다. 예를 들어 시계를 검색하면 영어, 프랑스어, 독일어 상품이 나란히 나타납니다. 무료 **WCPOS WPML** 확장 기능을 사용하면 POS에 한 언어만 표시되어 각 상품이 한 번씩만 나타납니다.

캐셔가 설정할 사항은 없습니다. 첫 번째 섹션에서는 캐셔에게 달라지는 점을 설명합니다. 나머지 내용은 매장 관리자를 위한 안내입니다.

## 캐셔에게 표시되는 내용 {#what-the-cashier-sees}

상품 검색, 상품 그리드, 옵션 상품의 옵션이 모두 매장 언어로 표시되며, 매대의 상품 하나당 하나의 상품만 나타납니다. 캐셔의 판매 방식은 달라지지 않습니다. 평소처럼 장바구니에 담고, 결제를 받고, 영수증을 인쇄하면 됩니다. [결제](../pos/checkout/index.mdx)를 참고하세요.

## 확장 기능 설치 {#install}

:::note 시작하기 전에
사이트에 [WPML](https://wpml.org/)이 설정되어 있고 기본 언어가 지정되어 있어야 하며, **WP Admin**에 로그인할 관리자 계정이 필요합니다.
:::

관리자가 **WP Admin**에서 한 번 설치하면 됩니다. 매장에 다른 언어를 선택하지 않으면 상품은 WPML의 **기본 언어**를 사용합니다. 확장 기능을 활성화한 후 아래의 [작동 확인](#check) 안내를 따르세요.

### WCPOS Pro 사용 시 {#install-pro}

1. **POS → 설정 → 확장 기능**으로 이동하세요.
2. **WCPOS WPML**을 찾아 **설치**를 누르세요. 설치와 활성화가 한 번에 진행되며 카드에 **활성**이 표시됩니다. **비활성**이 표시되면 **활성화**를 누르세요.

업데이트 및 자동 업데이트는 [확장 기능 설치](./index.mdx#installing-an-extension)를 참고하세요.

### 무료 플러그인 사용 시 {#install-free}

확장 기능 화면에 해당 확장 기능이 표시되지만 버튼을 사용하려면 Pro가 필요합니다. 대신 다음과 같이 진행하세요:

1. 확장 기능의 [최신 릴리스](https://github.com/wcpos/wcpos-wpml/releases/latest)에서 `wcpos-wpml.zip`을 다운로드하세요.
2. **플러그인 → 새 플러그인 추가**로 이동하여 **플러그인 업로드**를 누르세요.
3. 다운로드한 파일을 선택하고 **지금 설치**를 누르세요.
4. **플러그인 활성화**를 누르세요.

### 작동 확인 {#check}

1. POS를 여세요. 상품 패널 하단의 **…개 중 …개 표시** 옆에 있는 [동기화 버튼](../pos/product-panel/display-settings.mdx#footer) (<Icon name="arrow-rotate-right" />)을 길게 누르고 **지우고 새로 고침**을 선택하세요.
2. 번역이 있는 상품을 검색하세요. WPML의 기본 언어로 상품이 한 번만 표시됩니다. 아래에서 매장 언어를 선택했다면 해당 언어로 표시됩니다.

여전히 두세 번 표시되면 [문제가 발생한 경우](#goes-wrong)를 참고하세요.

## 매장 언어 선택 {#store-language}

WCPOS Pro를 사용하면 각 [매장](../stores/index.mdx)에 별도의 언어를 표시할 수 있습니다. 같은 사이트에 있는 프랑스어 매장과 영어 매장에서 각각 자신의 언어로 된 번역을 볼 수 있습니다.

:::note 언어 페이지에는 세 가지 조건이 필요합니다
WCPOS Pro가 있어야 하고, **WCPOS WPML** 확장 기능이 활성화되어 있어야 하며, WPML이 켜져 있고 언어가 하나 이상 활성화되어 있어야 합니다. 이 조건을 충족하지 않으면 매장 메뉴에 **언어** 페이지가 표시되지 않습니다. **WooCommerce Multilingual**이 설치되어 있다면 버전이 4.11.0 이상이어야 합니다.
:::

1. **WP Admin**에서 **POS → 매장**으로 이동하여 매장 이름을 클릭하세요.
2. 매장 메뉴의 **확장 기능** 아래에서 **언어**를 여세요.
3. **매장 언어**에서 언어를 선택하세요. 목록에는 WPML에서 활성화된 모든 언어가 표시됩니다. **기본 언어**는 WPML의 기본값을 따릅니다. 선택한 내용은 자동으로 저장됩니다.
4. 이 매장의 POS를 열고 [작동을 확인](#check)하세요. 선택한 언어로 상품이 한 번만 표시됩니다.

다른 매장의 언어는 그대로 유지됩니다.

### 상품 언어와 화면 언어 {#product-and-screen-language}

매장 메뉴의 서로 다른 두 위치에 **언어**라는 설정이 있습니다:

- **확장 기능 → 언어 → 매장 언어**에서는 POS에 표시할 상품 번역의 언어를 선택합니다.
- **통화 및 언어 → 언어**에서는 POS 화면과 영수증의 문구에 사용할 언어를 선택합니다. [매장 설정 페이지 작성](../stores/setup.mdx#store-pages)을 참고하세요.

:::tip
프랑스어를 사용하는 매장이라면 두 설정 모두 프랑스어로 지정하세요.
:::

## 문제가 발생한 경우 {#goes-wrong}

**각 상품이 여전히 두세 번 표시됩니다.** **플러그인**에서 **WCPOS WPML**이 활성화되어 있고 WPML에 기본 언어가 지정되어 있는지 확인하세요. **WooCommerce Multilingual**이 설치되어 있다면 버전이 4.11.0 이상이어야 합니다. 이전 버전에서는 확장 기능이 자동으로 비활성화됩니다.

**매장 메뉴의 확장 기능 아래에 언어 페이지가 없습니다.** 이 페이지를 사용하려면 WCPOS Pro가 있어야 하고, 확장 기능이 활성화되어 있어야 하며, WPML이 켜져 있고 언어가 하나 이상 활성화되어 있어야 합니다. **WooCommerce Multilingual**이 설치되어 있다면 버전이 4.11.0 이상이어야 합니다.

**POS 전용 또는 온라인 전용 상품이 다른 언어에서는 표시되면 안 되는 곳에 나타납니다.** POS 전용 및 온라인 전용 설정은 상품별로 저장됩니다. 각 번역은 별도의 상품이므로 원본의 설정이 번역에 적용되지 않습니다. 각 번역을 열어 동일한 표시 설정을 지정하세요. [POS 전용 상품](../products/pos-only-products.mdx)을 참고하세요.

:::info WCPOS Pro 사용 시
각 매장에서 상품 언어를 개별적으로 선택합니다. Pro가 없으면 매장은 하나이며 WPML의 기본 언어를 사용합니다.
:::

<details>
<summary>개발자 안내: 필터와 저장 데이터</summary>

이 확장 기능은 POS가 보내는 상품 및 상품 변형 요청에만 작동하며, 해당 상품 쿼리에 WPML의 `lang`을 추가합니다. 다른 WooCommerce REST 클라이언트에는 영향을 주지 않습니다. 로그인한 사용자에게 요청에 지정된 매장을 사용할 권한이 있으면 해당 매장의 언어를 사용하고, 그렇지 않으면 WPML의 기본 언어를 사용합니다.

- 매장에서 선택한 언어는 해당 매장의 `_wcpos_wpml_language` 메타에 저장됩니다. 빈 값은 WPML의 기본 언어를 의미합니다.
- `wcpos_wpml_resolved_language`는 개별 요청에 사용할 언어를 변경합니다.
- `wcpos_wpml_default_language`는 기본 언어를 변경합니다.
- `wcpos_wpml_is_supported`는 확장 기능을 켜거나 끕니다.
- `wcpos_wpml_minimum_wpml_version`과 `wcpos_wpml_minimum_wcml_version`은 확장 기능이 작동하는 WPML 및 WooCommerce Multilingual의 최소 버전을 지정합니다. WooCommerce Multilingual의 최소 버전은 `4.11.0`이며, WPML에는 기본적으로 최소 버전 제한이 없습니다.

소스: [github.com/wcpos/wcpos-wpml](https://github.com/wcpos/wcpos-wpml).

</details>
