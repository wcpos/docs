# WCPOS Polylang {#wcpos-polylang}

**WP 관리자:** `WP Admin → POS → Settings → Extensions`에서 설치하고, `WP Admin → POS → Stores`에서 매장별로 설정합니다.

WCPOS Polylang은 검색 결과와 상품 그리드에 각 상품을 매장 언어로 한 번만 표시합니다. 이 확장 기능이 없으면 [Polylang](https://wordpress.org/plugins/polylang/)으로 번역한 상품이 POS에 언어별로 각각 표시됩니다.

## 캐셔에게 표시되는 내용 {#what-it-does}

- **각 상품이 한 번만 표시됩니다.** 검색 결과, 상품 그리드, 상품 옵션 모두 한 언어의 데이터를 사용합니다.
- **매장의 언어를 사용합니다.** WCPOS Pro에서는 매장마다 별도의 언어를 사용할 수 있습니다. Pro가 없으면 POS는 Polylang의 기본 언어를 사용합니다.
- **POS 전용 설정은 그대로 적용됩니다.** **온라인 전용**으로 설정된 상품은 POS에 표시되지 않습니다. [POS 전용 상품](../products/pos-only-products.mdx)을 참조하세요.

매장 언어로 번역되지 않은 상품은 해당 매장에 표시되지 않습니다. 해당 매장에서 판매하려면 Polylang에서 번역을 추가하세요.

## 설정 방법 {#installation}

1~3단계는 WP Admin에서 진행합니다. 4단계는 각 계산대에서 진행합니다.

1. **Polylang을 설정하세요.** [Polylang](https://wordpress.org/plugins/polylang/)을 설치하고 활성화한 뒤 언어를 추가하고 기본 언어를 선택하세요. WordPress 6.5 이상에서는 Polylang이 활성화되어 있어야 WCPOS Polylang을 활성화할 수 있습니다.
2. **WCPOS Polylang을 설치하세요.**

   **WCPOS Pro를 사용하는 경우:** **POS → 설정 → 확장 기능**을 열고 **WCPOS Polylang**을 찾은 다음 **설치**하고 **활성화**하세요. [확장 기능 설치](./index.mdx#installing-an-extension)를 참조하세요.

   **WCPOS Pro가 없는 경우:** [최신 릴리스](https://github.com/wcpos/wcpos-polylang/releases/latest)에서 `wcpos-polylang.zip`을 다운로드하여 **플러그인 → 새 플러그인 추가 → 플러그인 업로드**에서 업로드하세요. **지금 설치**를 클릭한 다음 **플러그인 활성화**를 클릭하세요.

3. 매장에서 Polylang의 기본 언어를 사용하지 않으려면 **WCPOS Pro에서 매장별 언어를 선택하세요**. [매장별 언어 선택](#per-store-language-pro)을 참조하세요.
4. **각 계산대에서 상품을 다시 다운로드하세요.** [상품 다시 다운로드](#redownload)를 참조하세요.

## 매장별 언어 선택 {#per-store-language-pro}

:::info WCPOS Pro 사용 시
각 매장에 별도의 Polylang 언어를 지정할 수 있습니다. Pro가 없으면 모든 계산대가 Polylang의 기본 언어를 사용합니다. 매장별로 언어를 설정하려면 [WCPOS Pro](../getting-started/pro-license.mdx)로 업그레이드하세요.
:::

1. WP Admin에서 **POS → 매장**을 열고 매장을 클릭하세요.
2. 매장 메뉴의 **확장 기능** 아래에서 **언어**를 클릭하세요.
3. **매장 언어**에서 언어를 선택하세요. Polylang은 `en`, `fr` 같은 코드로 언어를 표시합니다. 첫 번째 선택 항목인 **기본 언어** 옆에는 기본 언어 코드가 표시되며, 이 항목은 Polylang의 기본 언어를 따릅니다.

페이지는 변경 사항을 자동으로 저장합니다. 그런 다음 아래 안내에 따라 해당 매장의 계산대에서 [상품을 다시 다운로드](#redownload)하세요.

**언어** 페이지는 WCPOS Pro, 하나 이상의 언어가 설정된 Polylang, WCPOS Polylang이 모두 활성화된 경우에만 표시됩니다.

### 언어라는 이름의 두 설정 {#two-languages}

매장에는 **언어** 설정이 두 곳에 있으며, 서로 다르게 지정할 수 있습니다.

| 매장 메뉴 위치 | 변경되는 내용 |
| --- | --- |
| **확장 기능 → 언어** | 매장의 계산대가 가져오는 상품을 결정합니다. 하나의 Polylang 언어를 사용합니다. |
| **통화 및 언어 → 언어** | POS 화면과 영수증의 언어입니다. [매장 페이지 작성](../stores/setup.mdx#store-pages)을 참조하세요. |

## 상품 다시 다운로드 {#redownload}

각 계산대에 한 언어의 데이터만 저장되도록 상품을 다시 가져오세요. 각 계산대가 온라인 상태일 때 다음 작업을 진행하세요.

1. 탐색 메뉴를 열고 **매장 상태**(심장 박동 아이콘)를 누르세요. **데이터베이스** 탭이 열립니다.
2. **상품** 행에서 **추가 작업** 메뉴를 열고 **삭제 후 다시 다운로드…** 를 선택한 다음 확인하세요. 상품 옵션도 함께 삭제됩니다.
3. 매장 언어로 번역된 상품을 검색하세요. 해당 언어의 이름으로 한 번만 표시됩니다. 그렇지 않으면 [문제가 발생한 경우](#compatibility-notes)를 참조하세요.

<JourneyShot manifest={manifest} device="tablet" step={1} alt="매장 상태의 데이터베이스 탭에서 상품 행의 추가 작업 메뉴가 열려 있고, 삭제 후 다시 다운로드 항목이 표시된 모습">

1. **상품** — 사이트의 전체 상품 중 이 계산대에 저장된 상품 수입니다. 아래의 **상품 옵션** 행도 함께 삭제됩니다.
2. **추가 작업** — 해당 행의 메뉴입니다.
3. **삭제 후 다시 다운로드…** — 이 계산대에 저장된 데이터를 제거하고 한 언어로 다시 가져옵니다. [매장 상태](../support/store-health.mdx#clear-and-redownload)를 참조하세요.

</JourneyShot>

서버의 데이터는 변경되지 않습니다. 첫 상품들은 즉시 다시 다운로드되고, 나머지는 탐색, 검색, 판매 중에 다운로드됩니다. **상품** 행에서 다시 다운로드된 수를 확인할 수 있습니다. [다운로드 진행 상황 확인](../products/sync.mdx#progress)을 참조하세요.

## 문제가 발생한 경우 {#compatibility-notes}

**모든 상품이 중복으로 표시됩니다.** **플러그인**에서 Polylang과 WCPOS Polylang이 모두 활성화되어 있는지 확인하세요. Polylang이 꺼져 있으면 WCPOS Polylang은 작동하지 않으며 POS가 모든 언어의 상품을 가져옵니다. 그런 다음 각 계산대에서 [상품을 다시 다운로드](#redownload)하세요.

**매장에 잘못된 언어의 상품이 표시됩니다.** 해당 매장의 **확장 기능 → 언어** 페이지가 **기본 언어** 또는 다른 언어로 설정되어 있습니다. 매장 언어를 선택한 다음 해당 계산대에서 [상품을 다시 다운로드](#redownload)하세요.

**특정 매장에 상품이 표시되지 않습니다.** 해당 매장 언어로 번역되어 있는지 확인하고, 없다면 Polylang에서 번역을 추가하세요. 이미 번역되어 있다면 [상품을 찾을 수 없는 경우](../pos/product-panel/index.mdx#goes-wrong)를 참조하세요.

**확장 기능 아래에 언어 페이지가 없습니다.** WCPOS Pro, 하나 이상의 언어가 설정된 Polylang, WCPOS Polylang이 모두 활성화되어 있어야 합니다.

## 개발자 안내 {#developer-hooks}

<details>
<summary>필터링 작동 방식과 필터</summary>

- WCPOS Polylang은 WCPOS가 만드는 상품 및 상품 옵션 REST 쿼리에 Polylang의 `lang` 쿼리를 추가합니다. `/wcpos/v…/` 경로와 무료 플러그인의 `wcpos_request()`가 WCPOS 요청으로 표시한 요청 모두에 적용됩니다.
- WCPOS의 ID 전용 상품 및 상품 옵션 목록 요청(`/wcpos/v1/products` 및 상품 옵션 경로에서 `posts_per_page=-1`과 `fields=id` 또는 `fields=id,date_modified_gmt`를 사용하는 요청)에 언어별로 필터링한 결과를 직접 반환합니다. POS 전용 상품 기능이 켜져 있으면 **온라인 전용** ID는 제외합니다.
- WCPOS Pro에서는 사용자가 접근할 수 있는 `store_id`가 포함된 요청에 해당 매장의 언어가 적용됩니다. 매장 언어는 `_wcpos_polylang_language` 포스트 메타에 저장되며, `/wcpos/v1/stores`에서 `language`로 반환됩니다.

| 필터 | 용도 |
| --- | --- |
| `wcpos_polylang_resolved_language` | 요청에 사용할 언어를 변경합니다. 언어 슬러그와 `WP_REST_Request`를 받습니다. |
| `wcpos_polylang_default_language` | 매장에 언어가 설정되지 않았을 때 사용할 대체 언어를 변경합니다. |
| `wcpos_polylang_is_supported` | Polylang 감지 결과와 관계없이 연동을 켜거나 끕니다. |
| `wcpos_polylang_minimum_version` | 최소 Polylang 버전을 지정합니다. 기본값은 비어 있으며 버전을 확인하지 않습니다. |

소스: [github.com/wcpos/wcpos-polylang](https://github.com/wcpos/wcpos-polylang).

</details>
