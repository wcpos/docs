# بوابات الدفع {#payment-gateways}

يدعم WCPOS عدة بوابات دفع مخصصة توسّع وظائف نظام نقاط البيع. وقد صُممت هذه البوابات خصيصًا لبيئات نقاط البيع، وتوفر تكاملاً سلسًا مع مختلف أساليب وخدمات الدفع.

## بوابات الدفع المخصصة المتاحة {#available-custom-gateways}

### بوابات الدفع لأجهزة الدفع الطرفية {#hardware-terminal-gateways}

- **[Stripe Terminal](./stripe-terminal.mdx)** - قبول المدفوعات باستخدام أجهزة قراءة Stripe Terminal
- **[SumUp Terminal](./sumup-terminal.mdx)** - معالجة المدفوعات عبر أجهزة قراءة بطاقات SumUp
- **[Square Terminal](./square-terminal.mdx)** - تحصيل المدفوعات الحضورية على أجهزة Square Terminal
- **[PayPal Reader (Zettle)](./paypal-reader.mdx)** - تحصيل مدفوعات البطاقات حضوريًا باستخدام جهاز PayPal Reader (Zettle)
- **[Mollie Terminal](./mollie-terminal.mdx)** - تحصيل المدفوعات حضوريًا على أجهزة Mollie Terminal
- **[Mercado Pago Terminal](./mercadopago-terminal.mdx)** - تحصيل المدفوعات الحضورية على أجهزة Mercado Pago Point Smart (جديد في 0.1.0)
- **[Windcave Terminal](./windcave-terminal.mdx)** - تحصيل مدفوعات البطاقات حضوريًا على أجهزة Windcave (جديد في 0.1.0)
- **[PayArc Terminal](./payarc-terminal.mdx)** - تحصيل المدفوعات حضوريًا على أجهزة PayArc PAX

### بوابات الدفع عبر الجوال {#mobile-payment-gateways}

- **[Vipps MobilePay](./vipps-mobilepay.mdx)** - قبول المدفوعات عبر الهاتف باستخدام رمز QR أو إشعار فوري

### بوابات الدفع الرقمية {#digital-payment-gateways}

- **[فاتورة عبر البريد الإلكتروني](./email-invoice.mdx)** - إرسال فواتير الدفع إلى العملاء عبر البريد الإلكتروني
- **[الدفع عبر الويب](./web-checkout.mdx)** - إعادة توجيه العملاء لإتمام الدفع عبر الإنترنت

## إنشاء بوابة الدفع الخاصة بك {#creating-your-own-gateway}

إذا كنت بحاجة إلى بوابة دفع مخصصة لمتطلباتك المحددة، يمكنك استخدام **[قالب البوابة](/reference/gateway-template)** لإنشاء بوابة دفع WCPOS خاصة بك.

## نظرة عامة على التثبيت {#installation-overview}

تتبع جميع البوابات المخصصة عملية تثبيت متشابهة:

1. **تنزيل** أحدث إصدار من مستودع GitHub المعني
2. **تثبيت** الملحق عبر `WP Admin > إضافات > إضافة جديد > رفع إضافة`
3. **تهيئة** إعدادات البوابة في `WP Admin > WooCommerce > الإعدادات > المدفوعات`
4. **فعّل** بوابة الدفع في `WP Admin > نقطة البيع > الإعدادات > إتمام الطلب`
