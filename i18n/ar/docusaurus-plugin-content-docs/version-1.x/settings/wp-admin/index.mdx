تهيّئ هذه الإعدادات الوظائف الخلفية لتطبيق نقطة البيع، بما في ذلك تهيئة PHP وWooCommerce. يمكنك الوصول إليها بالانتقال إلى `WP Admin > POS > Settings`.

## الإعدادات في لمحة {#settings-at-a-glance}

| الإعداد | ما يفعله | معرفة المزيد |
|---|---|---|
| **General** | العميل الافتراضي للسلة لجميع أمناء الصندوق، والمنتجات المخصصة لـ POS، والكميات العشرية، وحقل باركود المنتج. | [الإعدادات العامة](./general.mdx) |
| **الدفع** | بوابات الدفع المتاحة في POS وكيفية معالجة طلبات POS. | [إعدادات الدفع](./checkout.mdx) |
| **إشعارات البريد الإلكتروني** | إعدادات مستقلة للمسؤول والعميل وأمين الصندوق لكل رسالة بريد، تحدد رسائل WooCommerce التي تُرسل لطلبات POS. | [إشعارات البريد الإلكتروني](./email-notifications.mdx) |
| **الوصول** | أذونات أدوار المستخدمين وصلاحياتهم لتحديد من يمكنه استخدام POS، بما في ذلك دور أمين الصندوق المخصص. | [الوصول إلى POS](./access.mdx) |
| **الجلسات** | عرض جلسات تسجيل الدخول النشطة إلى POS لكل مستخدم وجهاز، وتسجيل خروج الأجهزة عن بُعد. | [الجلسات](./sessions.mdx) |
| **المعرّفات الضريبية للمتجر** | معرّفات الضرائب التجارية (VAT وABN وGSTIN وEIN وأرقام السجل التجاري) المطبوعة على الإيصالات والفواتير. | [المعرّفات الضريبية للمتجر](./store-tax-ids.mdx) |
| **المعرّفات الضريبية للعملاء** | كيفية تخزين المعرّفات الضريبية للعملاء، وحقل الإضافة الذي تُكتب فيه، وكيفية نسخها إلى الطلبات عند الدفع. | [المعرّفات الضريبية للعملاء](./customer-tax-ids.mdx) |
