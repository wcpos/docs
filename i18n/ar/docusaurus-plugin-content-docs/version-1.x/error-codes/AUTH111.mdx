## ماذا يعني هذا {#what-this-means}

لم يقبل المتجر بيانات اعتماد تسجيل الدخول.

أعد إدخال اسم المستخدم وكلمة المرور، أو أعد تعيين كلمة المرور في WordPress إذا استمر الفشل. ولا تتأثر أي بيانات طلبات.

## بياناتك {#your-data}

لا تتأثر أي بيانات طلبات أو منتجات.

## استكشاف الأخطاء {#troubleshoot}

**عند نقطة البيع** — لأمين الصندوق: أعد إدخال اسم المستخدم وكلمة المرور؛ فقد رفض المتجر هذين البيانين.

**في المتجر** — لمسؤول الموقع:

1. تأكد من صلاحية الحساب بتسجيل الدخول إلى WP Admin ببيانات الاعتماد نفسها؛ وإذا فشل ذلك، فأعد تعيين كلمة المرور هناك.
2. إذا نجحت بيانات الاعتماد في WP Admin ولم تنجح في POS، فقد تمنع إضافة لحماية تسجيل الدخول أو إضافة أمنية تسجيل الدخول آليًا — راجع إعداداتها.
