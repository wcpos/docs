## ماذا يعني هذا {#what-this-means}

ترخيص WCPOS Pro لديك غير نشط لهذا المتجر أو الجهاز.

تحقق من الحالة المحلية وحالة خادم الترخيص وحالة المُحدِّث، ثم فعّل الترخيص للمتجر المذكور.

## بياناتك {#your-data}

لا تتأثر أي بيانات طلبات أو منتجات. وإذا استمر هذا، فصدّر التشخيصات وتواصل مع دعم WCPOS.

## استكشاف الأخطاء {#troubleshoot}

**في المتجر** — لمسؤول الموقع / حامل الترخيص:

1. تحقق من حالة الترخيص في إعدادات POS داخل WP Admin — ينبغي أن تظهر نشطة لعنوان هذا المتجر بالضبط.
2. يؤدي تغيير عنوان الموقع (من http إلى https، أو إضافة www أو إزالتها، أو نقل النطاق، أو نسخة تجريبية) إلى إلغاء تفعيل الترخيص للعنوان الجديد — فأعد تفعيله للعنوان الحالي.
3. إذا ظهر الترخيص نشطًا لكن POS لا يزال يشير إلى خلاف ذلك، فعطّله ثم أعد تفعيله مرة واحدة.
4. ما زال مقفلًا؟ صدّر معلومات التصحيح وتواصل مع الدعم مرفقًا مرجع الترخيص لديك.

**عند نقطة البيع:** بعد إعادة تفعيل الترخيص، أعد التحميل لالتقاط التغيير.
