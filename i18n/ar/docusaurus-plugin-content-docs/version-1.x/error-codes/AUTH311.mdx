## ماذا يعني هذا {#what-this-means}

مسار متجر WCPOS غير متاح.

اطلب من مسؤول الموقع التحقق مما إذا كانت إضافة حماية أو وكيل تحذف ترويسات طلبات WCPOS.

## بياناتك {#your-data}

لا تتأثر أي بيانات طلبات أو منتجات. وإذا استمر هذا، فاسأل الشخص الذي يدير موقع WordPress لديك.

## استكشاف الأخطاء {#troubleshoot}

**عند نقطة البيع** — للكاشير: اختبر صيغتي REST المدعومتين كلتيهما في متصفح — عنوان `/wp-json/` الخاص بمتجرك وعنوان `/index.php?rest_route=/`. لا تشخّص وجود حظر لـ REST إلا إذا لم يُرجع أي منهما JSON؛ ثم أبلغ مسؤولك بذلك.

**في المتجر** — لمسؤول الموقع:

1. تأكد من تفعيل WCPOS: WP Admin → الإضافات.
2. إذا لم تعمل أيٌّ من صيغتَي REST، فتحقق مما إذا كانت إضافة أمنية أو خادم وكيل أو CDN تزيل ترويسات طلبات WCPOS أو تحظر طلبات REST — وغالبًا ما يكون السبب قواعد جدار الحماية أو خيارات التحصين التي تعطّل REST API.
3. على بعض الاستضافات، تؤدي إعادة حفظ الروابط الدائمة (الإعدادات → الروابط الدائمة → حفظ) إلى استعادة مسارات REST المفقودة.
