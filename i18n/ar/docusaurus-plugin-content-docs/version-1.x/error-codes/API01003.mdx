# API01003: إعادة تعيين الاتصال {#api01003-connection-reset}

## ما المقصود بذلك؟ {#what-this-means}

تم إنشاء الاتصال بالخادم، لكنه أُغلق فجأة بعد ذلك. يحدث هذا عادةً أثناء تبادل البيانات عندما يقطع شيء ما الاتصال.

## الأسباب الشائعة {#common-causes}

- **تعطل الخادم** — ربما تعطّلت عملية الخادم أثناء الطلب
- **حدود الذاكرة** — نفدت ذاكرة PHP وتم إيقافه
- **انتهاء المهلة أثناء الطلب** — انتهت مهلة الخادم أثناء المعالجة
- **عدم استقرار الشبكة** — مشكلات متقطعة في الشبكة
- **برامج الأمان** — قد تؤدي إعدادات الأمان الصارمة إلى إغلاق الاتصالات

## كيفية الإصلاح {#how-to-fix}

### 1. تحقق من سجلات أخطاء الخادم {#1-check-server-error-logs}

ابحث في سجلات أخطاء WordPress أو لوحة تحكم الاستضافة عن أخطاء ذات صلة بوقت إعادة تعيين الاتصال.

### 2. زد حد ذاكرة PHP {#2-increase-php-memory-limit}

في ملف `wp-config.php`:

```php
define('WP_MEMORY_LIMIT', '256M');
```

### 3. تحقق من تعارض الإضافات {#3-check-for-plugin-conflicts}

قد تتسبب إضافة في تعطل PHP:
- عطّل الإضافات مؤقتًا
- أعد تفعيلها واحدة تلو الأخرى لتحديد الإضافة المسببة للمشكلة

### 4. راجع موارد الخادم {#4-review-server-resources}

تواصل مع مزود الاستضافة للتحقق من:
- حدود عمليات PHP
- استخدام الذاكرة وقت حدوث الخطأ
- سجلات استقرار الخادم

### 5. اختبر استقرار الشبكة {#5-test-network-stability}

إذا كنت تستخدم WiFi، فجرّب اتصالًا سلكيًا. إذا استمرت المشكلة عبر شبكات مختلفة، فالأرجح أنها من جهة الخادم.
