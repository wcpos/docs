# API06003: إعداد التكوين غير صالح {#api06003-invalid-site-configuration}

## ماذا يعني هذا {#what-this-means}

إعداد التكوين غير صالح أو غير مكتمل. قد يتضمن ذلك عناوين URL غير صحيحة، إعدادات المصادقة، أو مشاكل تكوين أخرى.

## الأسباب الشائعة {#common-causes}

- **تكوين جزئي** — بعض الإعدادات مفقودة
- **إعدادات غير متطابقة** — التكوين لا يتطابق مع الموقع
- **تكوين تالف** — تم تلف الإعدادات
- **تغييرات الموقع** — تم تعديل الموقع دون تحديث إعدادات POS

## كيفية الإصلاح {#how-to-fix}

### 1. مراجعة جميع الإعدادات {#1-review-all-settings}

تحقق من التكوين الكامل:
- عنوان URL للموقع صحيح
- تم تكوين المصادقة بشكل صحيح
- أي إعدادات إضافية صحيحة

### 2. إعادة التكوين من البداية {#2-reconfigure-from-scratch}

:::warning تحقق من الأعمال غير المحفوظة أولًا
يؤدي مسح البيانات المحلية أو إعادة تثبيت التطبيق إلى حذف كل ما لم يصل إلى متجرك من هذا الجهاز — بما في ذلك المبيعات المسجلة أثناء عدم الاتصال، وعربات التسوق المفتوحة، والتعديلات التي لم تُحفظ. قبل مسح أي شيء، افتح **صحة المتجر → قاعدة البيانات** وتحقق من عدم وجود أي عناصر معلّقة أو لم تصل مطلقًا إلى خادمك، ثم افتح **صحة المتجر → السجلات** وتحقق من وجود **0 سجل عالق** و**0 تغيير ينتظر الإرسال**؛ ثم أكمل كل عربة مفتوحة أو دوّن تفاصيلها. إذا لم تظهر صفحة صحة المتجر في WCPOS، فحدّث WCPOS أولًا ثم أجرِ التحقق. إذا كان هناك أي عنصر مدرج أو ينتظر الإرسال، أو تعذّر عليك التحقق، فلا تمسح البيانات — اطلب المساعدة من مالك المتجر أو تواصل مع الدعم.
:::

فقط إذا كان الإعداد تالفًا، وبعد إجراء التحقق أعلاه:
1. مسح جميع الإعدادات المخزنة
2. بدء عملية الإعداد مرة أخرى
3. إدخال تكوين جديد

### 3. تحقق من متطلبات الموقع {#3-check-site-requirements}

تحقق من أن موقع WordPress الخاص بك يفي بالمتطلبات:
- تم تثبيت WordPress ويمكن الوصول إليه
- تم تثبيت WooCommerce وهو نشط
- تم تثبيت ملحق WCPOS وهو نشط
- تم تمكين الروابط الدائمة (ليس "Plain")

### 4. اختبار وصول الموقع {#4-test-site-access}

تحقق من أن هذه عناوين URL تعمل في متصفح:
- `https://yoursite.com/` — الموقع الرئيسي
- `https://yoursite.com/wp-json/` — واجهة برمجة التطبيقات REST
- `https://yoursite.com/wp-json/wcpos/v1/` — واجهة برمجة تطبيقات WCPOS

### 5. تحقق من إعدادات WordPress {#5-check-wordpress-settings}

في إدارة WordPress:
1. الإعدادات → عام — التحقق من عناوين URL
2. الإعدادات → الروابط الدائمة — التأكد من أنها ليست "عادية"
3. WooCommerce → الحالة — تحقق من وجود مشاكل

## متطلبات التكوين {#configuration-requirements}

تحتاج التكوينات الصالحة إلى:
- **عنوان URL للموقع** — عنوان URL كامل مع البروتوكول
- **المصادقة** — بيانات اعتماد صحيحة أو مفاتيح API
- **الأذونات** — المستخدم لديه وصول إلى POS
- **الملحقات** — الملحقات المطلوبة نشطة
