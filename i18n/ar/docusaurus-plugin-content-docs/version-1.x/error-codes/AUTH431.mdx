## ما معنى ذلك {#what-this-means}

لم تستجب واجهة REST API الخاصة بالمتجر عبر أي صيغة عنوان يمكن لهذا التطبيق استخدامها.

حاول التطبيق الوصول إلى واجهة REST API الخاصة بالمتجر عبر عنوانها المعتاد (/wp-json/...) وعبر عنوان WordPress الاحتياطي المضمّن (/?rest_route=...)، ولم يستجب أيٌّ منهما. قد يكون موقع المتجر نفسه متاحًا، لكن واجهة REST API تحديدًا غير قابلة للوصول، وعادةً ما يكون السبب إضافة أمان تخفيها أو قاعدة في جدار الحماية تحظرها.

## ما يجب فعله {#what-to-do}

صدّر معلومات التشخيص وتواصل مع الدعم. أعد المحاولة بعد إجراء التغيير المذكور أعلاه؛ ستفشل إعادة المحاولة بدونه بالطريقة نفسها.

## بياناتك {#your-data}

لا تتأثر أي بيانات للطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. إذا كانت إضافة أمان تخفي أو تعيد تسمية /wp-json/ (مثل WP Hide)، فاسمح أيضًا بنموذج /?rest_route= المضمّن في WordPress — يعود التطبيق إليه تلقائيًا.
2. تحقق من قواعد جدار الحماية (WAF) بحثًا عن أي شيء يطابق wp-json أو rest_route، واسمح بمرور REST API الخاص بالمتجر.
3. اختبر من المتصفح: https://your-store.com/?rest_route=/ يجب أن يعرض JSON، وليس صفحة 403 أو الصفحة الرئيسية للموقع.
4. إذا كان الخادم خلف صفحة صيانة أو اختبار للتحقق من الروبوتات، فقد يتم الرد على طلبات REST بصفحة HTML — عطّل الاختبار لـ REST API.

## أين تبحث {#where-to-look}

عندما يتمكن WCPOS من حفظ هذا الخطأ، يُسجَّل على الجهاز الذي أطلقه. افتح **صحة المتجر → السجلات** (أيقونة نبض القلب أسفل درج التنقل)، ثم ابحث عن الإدخال المعلَّم بهذا الرمز ووسّعه: يعرض الصف الموسَّع السبب بلغة بسيطة والسياق الذي تم التقاطه لحظة حدوث الفشل. بالنسبة إلى طلب متجر، قد يتضمن هذا السياق رمز الخطأ الخاص بالخادم (`serverCode`) أو `status` الخاص بـ HTTP أو `endpoint`؛ وتعتمد الحقول المعروضة على موضع حدوث الفشل. عند الإبلاغ عن مشكلة، استخدم **نسخ معلومات التصحيح** أعلى شاشة السجلات (**مشاركة معلومات التصحيح** على الهواتف والأجهزة اللوحية) بدلًا من لقطات الشاشة: إذ يجمع إصدار التطبيق وحالة الاتصال وأحدث الأخطاء. تُحتفظ بالسجلات لمدة لا تتجاوز 30 يومًا، لذا اجمعها بينما تكون المشكلة حديثة. انسخ أيضًا أي خطأ في وحدة تحكم المتصفح ظهر قبل أن يتمكن POS من كتابة إدخال السجل الخاص به.

- **الخطورة:** خطأ
