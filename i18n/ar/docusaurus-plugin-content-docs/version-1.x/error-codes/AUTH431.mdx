## ماذا يعني هذا {#what-this-means}

لم تستجب واجهة REST API الخاصة بالمتجر على أي صيغة عنوان يمكن لهذا التطبيق استخدامها.

جرّب التطبيق واجهة REST API الخاصة بالمتجر على عنوانها المعتاد (/wp-json/...) وعلى العنوان الاحتياطي المدمج في WordPress (/?rest_route=...)، ولم يستجب أيّ منهما. قد يكون موقع المتجر نفسه يعمل — فالمشكلة تحديدًا هي تعذّر الوصول إلى واجهة REST API، وعادةً بسبب إضافة أمان تخفيها أو قاعدة جدار حماية تحظرها.

## بياناتك {#your-data}

لم تتأثر أي بيانات طلبات أو منتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

**على المتجر** — لمسؤول الموقع: إذا كانت إضافة أمان تخفي `/wp-json/` أو تعيد تسميته (مثل WP Hide)، فاسمح أيضًا بالصيغة `/?rest_route=` المدمجة في WordPress — فالتطبيق يلجأ إليها تلقائيًا.

**على المضيف / الخادم:**

1. تحقق من قواعد جدار الحماية (WAF) بحثًا عن أي شيء يطابق `wp-json` أو `rest_route` واسمح بمرور واجهة REST API الخاصة بالمتجر نفسه.
2. إذا كان الخادم خلف صفحة صيانة أو تحدٍّ لكشف الروبوتات، فقد تُجاب طلبات REST بصفحة HTML — عطّل التحدي بالنسبة إلى واجهة REST API.

**للاختبار (لأي شخص):** ينبغي أن يعيد `https://your-store.com/?rest_route=/` استجابة JSON، لا صفحة 403 ولا الصفحة الرئيسية للموقع.
