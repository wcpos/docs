## ماذا يعني هذا {#what-this-means}

صفحة حماية من الروبوتات تستجيب بدلًا من واجهة API الخاصة بالمتجر.

تعيد واجهة REST API الخاصة بالمتجر صفحة تحدٍّ بصيغة HTML (حماية من الروبوتات، أو CAPTCHA، أو صفحة اعتراض ضد هجمات DDoS) حيث يتوقع التطبيق استجابة JSON. ولا يستطيع تطبيق نقطة البيع حلّ تحدٍّ خاص بالمتصفح؛ لذا يجب إضافة واجهة REST API الخاصة بالمتجر إلى القائمة المسموحة في خدمة الحماية.

## بياناتك {#your-data}

لم تتأثر أي بيانات طلبات أو منتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. حدّد طبقة الحماية من صفحة التحدي (لكلٍّ من Cloudflare وSucuri وKinsta وغيرها علامتها الخاصة) وافتح إعداداتها.
2. أضف مسارات واجهة REST API الخاصة بالمتجر (/wp-json/ و/?rest_route=) إلى القائمة المسموحة لحركة مرور API.
3. على Cloudflare، لا يمكن تجاوز Bot Fight Mode لكل مسار على حدة — استخدم قواعد السماح 'definitely automated' في Super Bot Fight Mode أو عطّله لهذا النطاق.
4. في إعدادات الروبوتات/جدار الحماية لدى Kinsta، أضف مسارات REST API إلى القائمة المسموحة؛ وعلى Sucuri، تجنّب وضع تحدي JavaScript ضد DDoS لمسارات API.
