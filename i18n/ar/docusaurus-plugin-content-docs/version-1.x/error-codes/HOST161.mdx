## ماذا يعني هذا {#what-this-means}

المضيف يحدّ من معدل طلبات نقاط البيع في هذا المتجر.

يستمر الخادم في الرد بخطأ 429 (طلبات كثيرة جدًا) رغم أن التطبيق يقلّل وتيرته بالفعل ويحترم مهل Retry-After التي يحددها الخادم. وتتشارك عدة نقاط بيع على اتصال إنترنت واحد عنوانًا واحدًا، فتعامل حدود المعدل لكل مصدر هذه النقاط كعميل واحد شديد الانشغال. تستمر المزامنة تلقائيًا لكنها ستتأخر حتى يُرفع الحد.

## بياناتك {#your-data}

لم تتأثر أي بيانات طلبات أو منتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. اطلب من المضيف رفع حد معدل REST API أو إعفاء حركة مرور المتجر نفسه منه — واذكر عنوان IP الثابت للمتجر إن وُجد.
2. قد تحتاج خدمات الأمان التي تحتسب استجابات الأخطاء المتكررة (429) ضمن الحظر (مثل نظام كشف التسلل IDS في Sucuri) إلى استثناء واجهة API الخاصة بالمتجر من ذلك العدّاد.
3. إذا كانت عدة نقاط بيع تتشارك اتصالًا واحدًا، فاذكر ذلك للمضيف: عنوان IP واحد هنا هو متجر بأكمله، لا مستخدم واحد.
