:::note مكان واحد لكل جهاز
يوجهك مركز الأجهزة إلى إعداد كل جهاز، لكن الخطوات الفعلية موجودة في مكان واحد فقط. يوجد حساب قارئ البطاقات وطريقة اقترانه في صفحة بوابة الدفع الخاصة به؛ ويوجد توصيل درج النقد وإعداد فتحه في صفحة درج النقد.
:::

## توافق قارئات البطاقات {#card-reader-compatibility}

تعتمد قارئات البطاقات التي تعمل على **طريقة تشغيل WCPOS** وعلى نوع اتصال القارئ:

- لا يستطيع **تطبيق الويب** تشغيل سوى القارئات التي توفر **SDK للويب (المتصفح)** — وهي عادةً أجهزة طرفية مكتبية متصلة بالإنترنت. أما القارئات التي تعمل عبر **Bluetooth فقط** (مثل Stripe M2 / WisePad 3 وSumUp Air) وميزة **الدفع باللمس** عبر الهاتف فهي **غير مدعومة** في تطبيق الويب.
- الدعم **مرتبط بكل بوابة** وليس عامًا — تحقق من توافق القارئ مع البوابة التي تنوي استخدامها ([Stripe Terminal](/payment/gateways/stripe-terminal)، [SumUp](/payment/gateways/sumup-terminal)، [PayPal Reader](/payment/gateways/paypal-reader)) قبل الشراء.

تعرض كل صفحة بوابة القارئات الدقيقة التي تدعمها.
