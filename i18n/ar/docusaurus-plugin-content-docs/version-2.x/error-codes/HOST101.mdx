## ما معنى ذلك {#what-this-means}

يحظر الخادم فحص الأذونات الذي يجريه المتصفح (التحقق المسبق لـ CORS)، لذا لا يستطيع تطبيق الويب الاتصال به.

ترسل المتصفحات طلب OPTIONS قبل أي استدعاء API عبر مصادر مختلفة يتضمن ترويسات مخصصة. هناك ما يحظر OPTIONS قبل وصوله إلى هذا المتجر — وغالبًا ما يكون قاعدة في جدار الحماية — لذا لا يرسل المتصفح الطلب الفعلي مطلقًا. لا تتأثر التطبيقات الأصلية بذلك؛ ويجب إجراء الإصلاح على الخادم.

## بياناتك {#your-data}

لم تتأثر أي بيانات للطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. تحقق من وجود قاعدة في جدار الحماية (WAF) تحظر طريقة OPTIONS، واسمح بها على مسارات REST ضمن /wcpos/.
2. تتضمن بعض إضافات الأمان خيارًا لتفعيل 'حظر طرق الطلبات غير الشائعة' — ويجب أن تظل OPTIONS مسموحًا بها.
3. اختبار: يجب ألا يعيد طلب OPTIONS إلى REST API الخاص بالمتجر الرمز 403.
4. لا تستخدم تطبيقات سطح المكتب والأجهزة المحمولة CORS، وستستمر في العمل أثناء إصلاح هذه المشكلة.
