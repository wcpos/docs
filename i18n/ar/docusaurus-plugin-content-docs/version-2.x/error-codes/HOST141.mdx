## معنى هذا الخطأ {#what-this-means}

يحظر مرشح الأمان لدى مزود الاستضافة عمليات البحث عن المنتجات.

ترفض قاعدة جدار حماية لدى مزود الاستضافة هذا طلبات REST التي تحتوي سلسلة الاستعلام فيها على أحرف خارج ASCII أو كلمات تشبه SQL. تفشل أسماء المنتجات ذات علامات النبر، وعمليات البحث التي تتضمن كلمات مثل 'select' أو 'union'، مع الخطأ 403 رغم أنها عمليات بحث عادية في الكتالوج. يعمل جهاز البيع فيما عدا ذلك؛ وستظل عمليات البحث غير موثوقة حتى تُخفف قيود القاعدة.

## بياناتك {#your-data}

لا تتأثر بيانات الطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. اطلب من مزود الاستضافة إدراج معاملات البحث عبر REST الخاصة بالمتجر (مسارا /wcpos/ و/wc/) في قائمة السماح ضمن قواعد جدار الحماية لسلسلة الاستعلام.
2. في جدران الحماية المبنية على OWASP CRS، تكون قواعد حقن SQL على المعاملين 's' و'search' هي السبب المعتاد — استثنِ هذين المعاملين لمسارات REST API.
3. تحتاج إضافات الأمان التي تتضمن مفتاح تبديل «تصفية سلاسل الاستعلام المشبوهة» إلى استثناء لـ REST API، وليس إلى تعطيل الحماية بالكامل.
