# رموز الأخطاء {#error-codes}

عندما يواجه WCPOS مشكلة، يعرض رمز خطأ يساعد على تحديدها. بدءًا من **v1.10.0**، تتبع الرموز صيغة **المجال + ثلاثة أرقام** — مثل `SYNC131` أو `AUTH311`. يشير المجال إلى الجزء المعني من POS، ويحدد الرقم الحالة بعينها. لكل رمز صفحة خاصة تشرح معناه والإجراء المطلوب ودلالته على بياناتك.

في POS، تظهر رموز الأخطاء ضمن **حالة المتجر → السجلات**: وسّع أحد الصفوف واستخدم رابط **المساعدة** للانتقال مباشرة إلى صفحة الرمز هنا.

## مجالات الأخطاء (v1.10.0+) {#error-domains}

| المجال | الجزء المعني |
|--------|------|
| [`AUTH`](#auth) | تسجيل الدخول والجلسات والرموز المميزة |
| [`CHECKOUT`](#checkout) | إتمام الطلبات عند نقطة البيع |
| [`CLIENT`](#client) | تطبيق POS نفسه والتخزين المحلي |
| [`DISPLAY`](#display) | الشاشة الموجّهة للعميل |
| [`HOST`](#host) | الاستضافة وقواعد جدار الحماية التي تحظر POS |
| [`LICENSE`](#license) | تفعيل ترخيص Pro والتحقق من صلاحيته |
| [`PAYMENT`](#payment) | بوابات الدفع وأجهزة الدفع |
| [`PRINT`](#print) | طباعة الإيصالات |
| [`PRODUCT`](#product) | بيانات المنتجات وعمليات الكتالوج |
| [`REGISTER`](#register) | درج النقد وجلسات الصندوق وعمليات الجرد |
| [`SYNC`](#sync) | المزامنة بين POS ومتجرك |

اعثر على الرمز أدناه، أو ابحث عنه.

الرموز التي تنتهي بـ `999` تشمل حالات المجال التي لم يُخصّص لها رمز محدد بعد.

## رموز الإصدارات السابقة لـ v1.10.0 {#legacy-codes}

تعود رموز مثل `API04001` إلى إصدارات أقدم من v1.10.0؛ ولا يُنتجها هذا الإصدار مطلقًا. قد تظل تراها في إدخال سجل محفوظ من قبل الترقية، أو في نقاش دعم قديم. بدّل قائمة الإصدارات إلى **1.x** للاطلاع عليها.
