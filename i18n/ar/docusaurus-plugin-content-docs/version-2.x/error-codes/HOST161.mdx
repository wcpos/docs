## معنى هذا الخطأ {#what-this-means}

يقيّد مزود الاستضافة معدل طلبات أجهزة البيع في هذا المتجر.

يواصل الخادم الرد بالرمز 429 (طلبات كثيرة جداً)، رغم أن التطبيق يباعد بالفعل بين المحاولات ويلتزم بفترات الانتظار التي يحددها الخادم في Retry-After. تشترك عدة أجهزة بيع على اتصال إنترنت واحد في عنوان واحد، لذلك تعاملها قيود المعدل بحسب المصدر كعميل واحد كثير النشاط. تستمر المزامنة تلقائياً، لكنها ستتأخر حتى يُرفع الحد.

## بياناتك {#your-data}

لا تتأثر بيانات الطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. اطلب من مزود الاستضافة رفع حد معدل REST API لطلبات المتجر نفسه أو إعفاءها منه — واذكر عنوان IP الثابت للمحل إن وُجد.
2. قد تحتاج خدمات الأمان التي تحتسب استجابات الأخطاء المتكررة (429) ضمن معايير الحظر (مثل IDS لدى Sucuri) إلى استثناء API الخاصة بالمتجر من هذا العداد.
3. إذا كانت عدة أجهزة بيع تشترك في اتصال واحد، فاذكر ذلك لمزود الاستضافة: عنوان IP واحد هنا يمثل محلاً بأكمله، وليس مستخدماً واحداً.
