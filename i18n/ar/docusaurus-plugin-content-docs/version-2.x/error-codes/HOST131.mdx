## معنى هذا الخطأ {#what-this-means}

يرفض خادم وكيل أمام المتجر استجابات الخادم لاحتوائها على ترويسات كثيرة جداً.

تفرض طبقة تخزين مؤقت أو خادم وكيل (غالباً Varnish) حداً لعدد ترويسات الاستجابة أو حجمها. تقع نقاط النهاية الخفيفة للمتجر ضمن هذا الحد، لكن استجابات API الكاملة تتجاوزه وتعود بأخطاء 503 من الخادم الوكيل، لا من WordPress. يجب رفع الحد في تلك الطبقة.

## بياناتك {#your-data}

لا تتأثر بيانات الطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. على Varnish، ارفع http_max_hdr (عدد الترويسات) وhttp_resp_hdr_len / http_resp_size (الأحجام).
2. اسأل مزود الاستضافة عن طبقة الخادم الوكيل التي تعيد 503 — لن يُظهر سجل أخطاء WordPress شيئاً لأن الطلب لا يفشل فيه أصلاً.
3. فحص سريع: يستجيب مسار /wcpos/v2/ping للمتجر بشكل سليم، بينما تعيد نقاط نهاية البيانات 503.
