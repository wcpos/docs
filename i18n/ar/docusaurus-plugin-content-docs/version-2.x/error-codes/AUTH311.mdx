## ما معنى ذلك {#what-this-means}

يتعذر على WCPOS الوصول إلى نقطة اتصاله في متجرك.

اطلب من مسؤول موقعك التأكد من تفعيل إضافة WCPOS (**WP Admin → إضافات**) ومن عدم وجود إضافة أمان تحظر REST API.

## بياناتك {#your-data}

لم تتأثر أي بيانات للطلبات أو المنتجات. أبلغ مسؤول موقعك.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

**عند نقطة البيع** — لأمين الصندوق: أبلغ مسؤول موقعك. لم يتأثر أي شيء على هذا الجهاز.

**في المتجر** — لمسؤول الموقع:

1. تأكد من تفعيل WCPOS: ‏WP Admin → إضافات.
2. إذا لم تعمل أي من صيغتي REST، فتحقق مما إذا كانت إضافة أمان أو خادم وكيل أو CDN تزيل ترويسات طلبات WCPOS أو تحظر طلبات REST — غالبًا ما تكون قواعد جدار الحماية وخيارات تعزيز الأمان التي تعطّل REST API هي السبب.
3. لدى بعض مزودي الاستضافة، تؤدي إعادة حفظ الروابط الدائمة (الإعدادات → روابط دائمة → حفظ التغييرات) إلى استعادة مسارات REST المفقودة.
