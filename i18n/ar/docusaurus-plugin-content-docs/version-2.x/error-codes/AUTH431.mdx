## ما معنى هذا {#what-this-means}

لم تستجب REST API الخاصة بالمتجر عبر أي صيغة عنوان يستطيع هذا التطبيق استخدامها.

حاول التطبيق الوصول إلى REST API الخاصة بالمتجر عبر عنوانها المعتاد (/wp-json/...) وعبر عنوان WordPress الاحتياطي المدمج (/?rest_route=...)، ولم يستجب أي منهما. قد يكون موقع المتجر نفسه يعمل — المشكلة تحديدًا هي تعذّر الوصول إلى REST API، وعادةً ما تكون إضافة أمان تخفيها أو قاعدة جدار حماية تحظرها.

## بياناتك {#your-data}

لم تتأثر أي بيانات للطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

**على المتجر** — لمسؤول الموقع: إذا كانت إضافة أمان تخفي `/wp-json/` أو تعيد تسميته (مثل WP Hide)، فاسمح أيضًا بصيغة `/?rest_route=` المدمجة في WordPress — يلجأ إليها التطبيق تلقائيًا عند الحاجة.

**لدى مزود الاستضافة / على الخادم:**

1. افحص قواعد جدار الحماية (WAF) بحثًا عن أي قاعدة تطابق `wp-json` أو `rest_route`، واسمح بمرور طلبات REST API الخاصة بالمتجر.
2. إذا كان الخادم خلف صفحة صيانة أو اختبار للتحقق من عدم كون الزائر روبوتًا، فقد تُرجع طلبات REST صفحة HTML — عطّل هذا الاختبار لـ REST API.

**للاختبار (يمكن لأي شخص إجراؤه):** يجب أن يعيد `https://your-store.com/?rest_route=/` بيانات JSON، لا صفحة 403 أو الصفحة الرئيسية للموقع.
