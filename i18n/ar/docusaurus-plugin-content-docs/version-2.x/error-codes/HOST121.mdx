## معنى هذا الخطأ {#what-this-means}

ترد صفحة حماية من الروبوتات بدلاً من API الخاصة بالمتجر.

تعيد REST API الخاصة بالمتجر صفحة اختبار بصيغة HTML (حماية من الروبوتات أو CAPTCHA أو صفحة وسيطة للحماية من DDoS) بينما يتوقع التطبيق JSON. لا يستطيع تطبيق نقطة البيع اجتياز اختبار المتصفح؛ يجب إدراج REST API الخاصة بالمتجر في قائمة السماح لدى خدمة الحماية.

## بياناتك {#your-data}

لا تتأثر بيانات الطلبات أو المنتجات.

## استكشاف الأخطاء وإصلاحها {#troubleshoot}

1. حدد طبقة الحماية من صفحة الاختبار (تضع Cloudflare وSucuri وKinsta وغيرها علامتها على صفحاتها) وافتح إعداداتها.
2. أدرج مسارات REST API الخاصة بالمتجر (/wp-json/ و/?rest_route=) في قائمة السماح لطلبات API.
3. على Cloudflare، أضف قاعدة **تخطي** في WAF لمسارات REST API؛ لا يمكن لأي قاعدة تجاوز وضع مكافحة الروبوتات (الخطة المجانية)، ويجب تعطيله. يتضمن [دليل Cloudflare](/troubleshooting/common-problems/cloudflare) القاعدة الدقيقة وفحصاً باستخدام `curl`.
4. في إعدادات الروبوتات/جدار الحماية لدى Kinsta، أدرج مسارات REST API في قائمة السماح؛ وعلى Sucuri، تجنب وضع الحماية من DDoS الذي يستخدم اختبار JavaScript لمسارات API.
