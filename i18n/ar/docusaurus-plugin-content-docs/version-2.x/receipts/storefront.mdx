**لوحة تحكم WordPress:** فعّل زر **إيصال** للطلبات عبر الإنترنت من `WP Admin → POS → Settings → General`.

:::note هذه الصفحة موجهة إلى المسؤول عن الموقع
مع [WCPOS Pro](../getting-started/pro-license.mdx)، يمكنك طباعة إيصال أو إرساله بالبريد الإلكتروني من نقطة البيع لأي طلب، بما في ذلك الطلبات عبر الإنترنت: راجع [إعادة طباعة إيصال](../orders/index.mdx#receipt-reprinting) في صفحة **الطلبات**.
:::

:::tip إذا طلب العميل إيصال طلبه عبر الإنترنت
بعد إعداد هذه الميزة على الموقع، يتوفر الإيصال عبر زر **إيصال** في **حسابي → الطلبات**، أو عبر رابط الإيصال في صفحة تأكيد الطلب إذا أضاف المتجر هذا الرابط.
:::

تعمل نماذج إيصالات WCPOS على موقعك أيضًا. يستطيع العميل الذي اشترى عبر الإنترنت تنزيل إيصال بصيغة PDF من **حسابي**، أو من رابط تضيفه إلى صفحة تأكيد الطلب.

## تفعيل زر الإيصال {#my-account}

:::warning فعّل نموذج إيصال أولًا
فعّل نموذجًا في **نقطة البيع → النماذج** قبل البدء. من دونه، لن يظهر زر **إيصال** للعملاء، حتى مع تفعيل الإعداد. راجع [تخصيص الإيصال](./customise.mdx#option-1--pick-a-different-template).
:::

يظل الزر معطّلًا حتى تفعّله. يُنشأ ملف PDF من نموذج الإيصال لديك.

1. في WP Admin، انتقل إلى **نقطة البيع → الإعدادات → عام**.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="WP Admin مع تحديد الإعدادات ضمن نقطة البيع في القائمة وفتح عام في قائمة الإعدادات، مع عرض المتاجر وصندوق البيع وبداية قسم المنتجات">

1. **نقطة البيع → الإعدادات** — عنصر قائمة WP Admin الخاص بإعدادات نقطة البيع.
2. **عام** — أول شاشة للإعدادات، وتكون مفتوحة عند الوصول.

</JourneyShot>

2. مرّر لأسفل إلى قسم **العملاء** وفعّل **السماح للعملاء بتنزيل الإيصالات**. يُحفظ الإعداد فور تبديله.

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="قسم العملاء ضمن عام: إنشاء اسم المستخدم تلقائيًا من البريد الإلكتروني للعميل، والعميل الافتراضي لنقطة البيع مضبوط على ضيف، والسماح للعملاء بتنزيل الإيصالات، وهو لا يزال معطّلًا هنا">

1. **العملاء** — القسم الذي يضم إعداد الإيصال.
2. **السماح للعملاء بتنزيل الإيصالات** — معطّل حتى تفعّله.

</JourneyShot>

3. يظهر أسفله **نموذج الإيصال للعملاء**. اتركه على **استخدام نموذج الإيصال النشط** أو اختر نموذجًا. راجع [اختيار نموذج العميل](#template-choice).

يرى العميل الذي سجّل الدخول الآن زر **إيصال** بجانب طلباته في **حسابي → الطلبات**. ينزّل الزر ملف PDF يحمل اسمًا مرتبطًا بالطلب، مثل `receipt-1234.pdf`.

يظهر الزر فقط للطلبات المدفوعة:

| حالة الطلب | زر الإيصال |
|---|---|
| **قيد التنفيذ** | نعم |
| **مكتمل** | نعم |
| **مسترد** | نعم |
| أي حالة أخرى، مثل **بانتظار الدفع** أو **قيد الانتظار** أو **ملغي** أو **فشل** | لا |

يمكن للمطوّر [تغيير الحالات التي يظهر فيها الزر](#developers).

## اختيار نموذج العميل {#template-choice}

يحدد **نموذج الإيصال للعملاء** النموذج المستخدم في التنزيل.

- **استخدام نموذج الإيصال النشط** (الافتراضي): يحصل العملاء على نموذج الإيصال النشط في **نقطة البيع → النماذج**. إذا غيّرته هناك، تتغير تنزيلاتهم تبعًا لذلك.
- **نموذج محدد بالاسم**: يحصل العملاء دائمًا على ذلك النموذج، أيًا كان ما يختاره أمين الصندوق في نقطة البيع. استخدم هذا الخيار عند وجود عدة نماذج إيصالات نشطة، أو لمنح الطلبات عبر الإنترنت مظهرًا خاصًا بها.

ينتج النموذج الضيق المصمم للطباعة الحرارية ملف PDF ضيقًا. أما الطلبات عبر الإنترنت، فعادةً ما تكون قراءتها أسهل في صفحة كاملة: صُمم نموذج **فاتورة** في المعرض لورق A4 وLetter. راجع [تخصيص الإيصال](./customise.mdx#option-1--pick-a-different-template) لإضافته.

يُملأ ملف PDF من [بيانات الإيصال](./receipt-data.mdx) نفسها المستخدمة في إيصال نقطة البيع، فتظهر فيه أيضًا تفاصيل متجرك وشعاره وإعدادات الضرائب.

إذا حُذف النموذج الذي اخترته لاحقًا أو أُلغي نشره، تعرض القائمة المنسدلة **نموذج غير متاح**، ويحصل العملاء على نموذج الإيصال النشط بدلًا منه. اختر نموذجًا آخر.

## إضافة رابط إيصال إلى صفحة تأكيد الطلب {#shortcode}

وفّر للعملاء رابط **تنزيل الإيصال (PDF)** في صفحة «شكرًا لك» التي يرونها بعد إتمام الدفع. بهذه الطريقة يحصل الضيوف الذين أتموا الدفع دون حساب على إيصالاتهم.

إذا كان المسار **المظهر → المحرر → القوالب → تأكيد الطلب** متاحًا في WP Admin لديك، فأضف الرابط بنفسك إلى صفحة الشكر:

1. في WP Admin، انتقل إلى **المظهر → المحرر → القوالب** وافتح **تأكيد الطلب**.
2. أضف مكوّن **كود قصير** في الموضع الذي تريد وضع الرابط فيه، واكتب فيه `[wcpos_receipt]`.
3. اضغط على **حفظ**.

إذا لم يكن هذا القالب متاحًا لديك، أو أردت وضع الرابط في صفحة طلب ضمن **حسابي**، فاطلب من مطوّر [إضافة رابط الإيصال برمجيًا](#developers).

يعمل الكود القصير سواء كان **السماح للعملاء بتنزيل الإيصالات** مفعّلًا أم لا: فهذا الإعداد يتحكم فقط في الزر الموجود في **حسابي → الطلبات**.

<details>
<summary>خيارات الكود القصير وأمثلة عليه</summary>

يعمل `[wcpos_receipt]` في صفحة تأكيد الطلب وفي صفحة الطلب ضمن **حسابي**. ويعثر على الطلب تلقائيًا في هذين الموضعين، لذا لا تحتاج إلى كتابة رقم الطلب. أما في أي صفحة أخرى، فلا يعرض شيئًا ما لم تزوّده بقيمة `order_id`.

| الخيار | الافتراضي | وظيفته |
|---|---|---|
| `order_id` | *(يُعثر عليه في الصفحة)* | رابط لطلب واحد في أي صفحة. يظهر فقط للعميل صاحب الطلب بعد تسجيل الدخول. |
| `link_text` | `Download receipt (PDF)` | نص الرابط. |
| `format` | `pdf` | ينزّل `pdf` ملف PDF. ويفتح `html` الإيصال في المتصفح جاهزًا للطباعة. |
| `template` | *(نموذج الإيصال النشط لديك)* | استخدام هذا النموذج بدلًا منه. |
| `class` | `wcpos-receipt-link` | فئة CSS على الرابط. |
| `id` | *(لا شيء)* | سمة HTML المسماة `id` على الرابط. |

يتجاهل خيار `template` في الكود القصير إعداد **نموذج الإيصال للعملاء**: إذا لم تضفه، يستخدم الرابط نموذج الإيصال النشط لديك.

رابط تنزيل بنص تختاره:

```text
[wcpos_receipt link_text="Download your invoice"]
```

فتح الإيصال في المتصفح بدلًا من تنزيل ملف PDF:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

استخدام نموذج محدد، مثل فاتورة A4 بدلًا من إيصال نقطة البيع بعرض 80mm:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

يظهر رقم النموذج في شريط العنوان عند تحريره في **نقطة البيع → النماذج** (`post=123`). يُتجاهل النموذج غير المنشور، ويستخدم الرابط نموذج الإيصال النشط لديك.

</details>

## من يمكنه فتح الإيصال {#security}

- يسجّل **العملاء الذين لديهم حساب** الدخول ويستخدمون زر **إيصال** في **حسابي → الطلبات**.
- يستخدم **الضيوف** الذين أتموا الدفع دون حساب رابط الإيصال في صفحة تأكيد طلبهم، بعد أن [تضيفه إليها](#shortcode).

:::warning شارك روابط الإيصالات مع العميل وحده
يمكن لأي شخص لديه رابط إيصال فتح ذلك الإيصال دون تسجيل الدخول. تعامل معه كما تتعامل مع الطلب نفسه.
:::

<details>
<summary>كيفية حماية روابط الإيصالات</summary>

يحمل كل رابط إيصال المفتاح الخاص بالطلب، وهو المفتاح نفسه الذي يضعه WooCommerce في صفحة تأكيد الطلب. لا يُفتح الإيصال دون المفتاح الصحيح. وعند استخدام خيار `order_id` في الكود القصير، لا يظهر الرابط إلا للعميل صاحب الطلب بعد تسجيل الدخول.

</details>

## إذا حدث خطأ {#goes-wrong}

تُنفّذ معظم الحلول أدناه في WP Admin. إذا كنت أمين صندوق، فانقل الرسالة التي يراها العميل إلى المسؤول عن الموقع. وفي الأثناء، يمكنك باستخدام [WCPOS Pro](../getting-started/pro-license.mdx) طباعة إيصال العميل أو إرساله بالبريد الإلكتروني من نقطة البيع: راجع [إعادة طباعة إيصال](../orders/index.mdx#receipt-reprinting) في صفحة **الطلبات**.

**لا يظهر زر الإيصال للعميل.** تأكد من تفعيل **السماح للعملاء بتنزيل الإيصالات**، ومن أن حالة الطلب هي **قيد التنفيذ** أو **مكتمل** أو **مسترد**، ومن وجود نموذج إيصال نشط واحد على الأقل في **نقطة البيع → النماذج**. لا يظهر الزر إلا في **حسابي → الطلبات** للعميل الذي سجّل الدخول.

**«لم يُعدّ أي نموذج إيصال.»** لا يوجد نموذج يستخدمه ملف PDF. فعّل نموذج إيصال في **نقطة البيع → النماذج**.

**«ليس لديك إذن لعرض هذا الإيصال.»** الرابط ناقص أو نُسخ بصورة خاطئة: فكل رابط يحمل مفتاحًا خاصًا بطلبه. أرسل إلى العميل الرابط من صفحة تأكيد طلبه أو من **حسابي** مرة أخرى.

**«تعذّر إنشاء ملف PDF للإيصال.»** تعذّر إنشاء ملف PDF من النموذج. افتحه في **نقطة البيع → النماذج** وعاينه. راجع [تخصيص الإيصال](./customise.mdx).

**يفتح الرابط صفحة خطأ «الصفحة غير موجودة».** في WP Admin، انتقل إلى **الإعدادات → الروابط الدائمة** واختر أي خيار باستثناء **عادي**. لا تعمل روابط الإيصالات مع **عادي**.

## للمطوّرين {#developers}

<details>
<summary>إضافة رابط الإيصال برمجيًا</summary>

في القوالب التقليدية، أخرج الرابط عبر إجراءَي WooCommerce اللذين يعرضان هاتين الصفحتين:

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

يعثر الكود القصير على الطلب في كلتا الصفحتين، لذا لا يحتاج إلى `order_id`.

</details>

<details>
<summary>مرشحات زر الإيصال ونموذج PDF</summary>

تتجاوز ثلاثة مرشحات الإعدادات أعلاه لتطبيق قواعد لا يمكن التعبير عنها بالإعدادات، مثل القواعد الخاصة بكل طلب أو بكل عميل:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

قبل WCPOS 2.0، كانت هذه المرشحات تُسمّى `woocommerce_pos_storefront_receipt_*`. لا تزال هذه الأسماء تعمل، لكنها مهملة منذ 2.0 وستُزال في 2.2 على أقرب تقدير. راجع [تسمية الخطافات](../extensions/index.mdx#hook-naming).

عنوان ملف PDF هو `/wcpos-checkout/wcpos-receipt/{order_id}` مع `?key={order_key}&format=pdf`: وهو عنوان الإيصال نفسه الذي تستخدمه نقطة البيع ويتطلب مفتاحًا للوصول إليه، ويعيد `format=pdf` ملف PDF بدلًا من الصفحة.

</details>
