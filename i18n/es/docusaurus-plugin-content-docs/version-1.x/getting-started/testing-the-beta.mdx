WCPOS 2.0 está en beta pública, para las cajas en el navegador y la aplicación de escritorio. Las aplicaciones para Android e iOS saldrán cuando termine la fase de pruebas de la beta, así que mantenga los teléfonos y las tabletas en una tienda 1.11 hasta entonces. La beta sirve para hacer pruebas en una copia de staging de su tienda o en una tienda que pueda permitirse interrumpir; no es la versión definitiva, y WordPress.org sigue ofreciendo la 1.11. Esta página reúne todo lo que necesita un probador.

## Qué necesita {#what-you-need}

- **WooCommerce 9.0 o posterior.** Con cualquier versión anterior, la 2.0 se detiene en un aviso.
- **La aplicación y el plugin deben estar ambos en la 2.0.** Una aplicación 2.0 no funciona con un plugin 1.11, y una aplicación 1.11 pide una actualización cuando encuentra un plugin 2.0. Actualice primero el plugin y después cada caja.
- **Sin lector de tarjetas de banda magnética.** La 2.0 elimina el lector experimental. Los lectores de tarjetas en la caja funcionan mediante Stripe Terminal o SumUp con WCPOS Pro.
- **Las extensiones de terminal necesitan WCPOS Pro 2.0.** Cada extensión de terminal de tarjetas tiene una versión preliminar beta en GitHub; instálela manualmente después de Pro: [Stripe Terminal](https://github.com/wcpos/stripe-terminal-for-woocommerce/releases/tag/v2.0.0-beta1), [SumUp](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases/tag/v2.0.0-beta1), [Mollie](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases/tag/v2.0.0-beta1), [Square](https://github.com/wcpos/square-terminal-for-woocommerce/releases/tag/v1.0.0-beta1), [PayArc](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases/tag/v1.0.0-beta1), [Windcave](https://github.com/wcpos/windcave-terminal-for-woocommerce/releases/tag/v1.0.0-beta1) y [Mercado Pago](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases/tag/v1.0.0-beta1). Las versiones estables actuales de estas extensiones son para 1.11.

## Antes de instalar {#before-you-install}

1. **Sincronice cada caja antes de actualizar.** La 2.0 inicia una nueva base de datos local en cada caja y no conserva las ventas que una caja 1.11 aún no haya enviado a la tienda. Abra cada caja con la 1.11, deje que termine de sincronizar y solo entonces actualice el plugin. Una venta que siga sin enviarse desde una caja 1.11 se pierde después de la actualización.
2. **Haga una copia de seguridad del sitio** o pida a su proveedor de hosting un punto de restauración.
3. **Elija una hora tranquila.** La primera vez que se abre, cada caja se recarga en la nueva caja registradora, y una venta que esté a medio tramitar en la 1.11 debe volver a registrarse.
4. Lea las [notas de la versión de la aplicación](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.2) para conocer los cambios: el registro, el proceso de pago y el cajón de efectivo son nuevos, se han rediseñado todas las pantallas y los descuentos mediante tarifas negativas se sustituyen por «Añadir descuento».

## Obtener la beta {#get-the-beta}

**Plugin (gratuito):** descargue `woocommerce-pos.zip` desde la [versión WCPOS 2.0.0 beta 2](https://github.com/wcpos/woocommerce-pos/releases/tag/v2.0.0-beta.2) e instálelo mediante **Admin de WP → Plugins → Añadir nuevo → Subir plugin**, reemplazando la versión actual. Las cajas del navegador pasan a la 2.0 en cuanto se activa el plugin.

**Plugin (Pro):** inicie sesión en [wcpos.com/account/downloads](https://wcpos.com/account/downloads), descargue `woocommerce-pos-pro.zip` desde la tarjeta **WCPOS Pro 2.0 beta** (se requiere una licencia activa) y súbalo de la misma manera. Pro incluye el plugin gratuito; no es necesario instalar ambos.

**Aplicación de escritorio:** la [versión WCPOS Desktop 2.0.0 beta 2](https://github.com/wcpos/electron/releases/tag/v2.0.0-beta.2) incluye los instaladores para macOS, Windows y Linux. La compilación beta no se actualiza sola; las betas posteriores se descargan de nuevo desde la misma página de versiones.

**iPhone, iPad y Android:** no están en esta beta. Las aplicaciones 2.0 para las tiendas de aplicaciones saldrán cuando termine la fase de pruebas de la beta; una aplicación 1.11 se detiene en un aviso de actualización cuando encuentra una tienda 2.0, así que mantenga los teléfonos y las tabletas en una tienda 1.11 hasta entonces.

Las notas de la versión de la aplicación para la beta están en la [versión de la aplicación](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.2); los cambios del plugin figuran en las notas de cada versión del plugin.

## Volver a la 1.11 {#rolling-back}

Avísenos primero en [Discord](https://wcpos.com/discord); la mayoría de los problemas de los días de beta tienen una solución más rápida que volver a la versión anterior.

1. **Sincronice cada caja antes de volver a la versión anterior.** Todo lo que una caja 2.0 no haya enviado se queda en la base de datos local de la 2.0, que la aplicación 1.11 nunca abre.
2. Reinstale el plugin 1.11: el gratuito desde [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) o [Versiones anteriores](/getting-started/previous-versions), Pro desde [wcpos.com/account/downloads](https://wcpos.com/account/downloads) (la última versión 1.11 de la lista).
3. Reinstale la aplicación de escritorio 1.11 allí donde instaló la beta. Una aplicación 2.0 no puede conectarse a un plugin 1.11.
4. La caja 1.11 empieza con una base de datos local vacía y vuelve a sincronizarse desde la tienda. Los pedidos realizados en la 2.0 son pedidos normales de WooCommerce y se quedan donde están; las sesiones de caja y los cierres registrados en la 2.0 permanecen en la base de datos, pero la 1.11 no los muestra.

## Informar de lo que encuentre {#reporting}

Abra una incidencia en [wcpos/roadmap](https://github.com/wcpos/roadmap/issues/new) con la etiqueta `beta`, o escriba al [soporte](https://wcpos.com/support). Indique qué parte (plugin, escritorio, iOS, Android, navegador), la versión, qué hizo, qué esperaba y qué ocurrió; una captura de pantalla o el código de error que muestra la pantalla ayuda. Si el problema es con una venta o un pago, incluya el número de pedido.
