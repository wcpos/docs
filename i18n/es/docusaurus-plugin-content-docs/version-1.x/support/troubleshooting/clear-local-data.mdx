WCPOS almacena una copia local de sus productos, pedidos y clientes para que el POS pueda funcionar rápidamente y operar sin conexión. Ocasionalmente, estos datos locales pueden dejar de estar sincronizados con su tienda WooCommerce. Limpiar todos los datos locales elimina la base de datos local e inicia una nueva sincronización desde su servidor.

:::tip Pruebe primero un restablecimiento selectivo (v1.10.0+)
A partir de la v1.10.0, **Estado de la tienda → Base de datos** ofrece **Borrar y volver a descargar** por colección: elimina y vuelve a descargar solo la colección que da problemas (por ejemplo, los productos), sin tocar nada más ni cerrar su sesión. La confirmación muestra cuántos registros se eliminarán y confirma que la copia de su servidor no se ve afectada. Tenga en cuenta que es normal que las colecciones que se descargan bajo demanda muestren un recuento bajo justo después de un restablecimiento y vuelvan a llenarse a medida que se usan: es el comportamiento previsto y no indica que la sincronización se haya bloqueado. Consulte [Estado de la tienda](/1.x/support/store-health#clear-and-redownload).
:::

:::warning
Esta es la opción más drástica. Limpiar los datos locales elimina todo lo almacenado en el dispositivo y fuerza una nueva sincronización completa. Dependiendo del tamaño de su tienda, esto puede tardar un tiempo. Úsela solo cuando otras opciones — una [sincronización](/1.x/products/sync) normal o **Borrar y volver a descargar** por colección — no hayan resuelto el problema.

Antes de limpiar, revise el panel de **cambios pendientes de enviar** en **Estado de la tienda → Base de datos**: limpiar los datos locales destruye cualquier cambio del dispositivo que aún no se haya enviado.
:::

## Cuándo usarlo {#when-to-use-it}

Puede que necesite limpiar los datos locales en estos casos:

- **Problemas de sincronización** — Los productos, pedidos o clientes no se actualizan correctamente
- **Después de una actualización del plugin** — Para asegurar la compatibilidad con nuevas estructuras de datos
- **Datos obsoletos** — Los precios, niveles de existencias u otra información parecen desactualizados

## Qué se limpia {#what-gets-cleared}

| Se elimina | No se elimina |
|---------|-------------|
| Base de datos local de productos | Datos del servidor |
| Base de datos local de pedidos | Ajustes de WooCommerce |
| Base de datos local de clientes | |
| Sesión de usuario | |

Los datos de su tienda WooCommerce no se ven afectados: solo se elimina la copia local de su dispositivo. Una nueva sincronización comienza automáticamente después de la limpieza.

:::info Diferencia entre plataformas
- **Aplicación de escritorio:** Se cerrará su sesión y deberá volver a conectar su tienda.
- **Aplicación web:** Se eliminan los datos de inicio de sesión, pero, como sigue teniendo la sesión iniciada en WP Admin, la sesión se restablece automáticamente, por lo que no notará que se haya cerrado.
:::

## Cómo limpiar los datos locales {#how-to-clear-local-data}

### Web {#web}

1. Haga clic en su **menú de usuario** en la esquina superior derecha para abrir el menú
2. Haga clic en **Limpiar Todos los Datos Locales**
3. La base de datos local se eliminará y comenzará automáticamente una nueva sincronización

### Escritorio {#desktop}

1. Abra el menú de la aplicación **WCPOS** en la barra de menú superior
2. Sitúe el puntero sobre **Avanzado**
3. Haga clic en **Limpiar Datos de la Aplicación**
4. La base de datos local se eliminará y comenzará automáticamente una nueva sincronización

:::note
Todas las plataformas almacenan los datos en el mismo formato de base de datos local (almacenamiento de archivos basado en OPFS a partir de la v1.10.0). Se limpia por completo en todas las plataformas, pero el comportamiento del inicio de sesión difiere; consulte la nota sobre la diferencia entre plataformas más arriba.
:::
