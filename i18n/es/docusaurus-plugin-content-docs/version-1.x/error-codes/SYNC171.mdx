## Qué significa esto {#what-this-means}

No se ha podido crear o eliminar una base de datos local en este dispositivo.

Reinicie WCPOS y vuelva a intentarlo. Si sigue fallando, puede que el dispositivo tenga poco almacenamiento o que el perfil del navegador esté restringiendo el almacenamiento; libere espacio y contacte con el soporte si persiste.

## Sus datos {#your-data}

No se pudo configurar ni borrar la base de datos local del dispositivo. Se trata de un problema de almacenamiento o configuración, no de una edición sin sincronizar: libere espacio y vuelva a intentarlo; si persiste, exporte los diagnósticos y póngase en contacto con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Reinicie WCPOS y vuelva a intentar la misma acción — la mayoría de los fallos de configuración son transitorios.
2. Compruebe el almacenamiento libre del dispositivo; la creación de una base de datos local falla directamente cuando el disco o la cuota de almacenamiento del navegador están llenos.
3. En la web, compruebe que el navegador permite almacenamiento persistente para el sitio — las ventanas privadas y los ajustes que bloquean todos los datos no lo permiten.
4. Si sigue fallando, exporte la información de depuración y contacte con el soporte.
