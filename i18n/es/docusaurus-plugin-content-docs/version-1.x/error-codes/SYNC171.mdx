## Qué significa esto {#what-this-means}

WCPOS no pudo configurar ni eliminar el almacenamiento de este dispositivo.

Libere espacio de almacenamiento en el dispositivo y reinicie WCPOS. En la web, es posible que el navegador también esté restringiendo el almacenamiento del sitio; esto ocurre en las ventanas privadas. Si sigue fallando, contacte con soporte.

## Sus datos {#your-data}

Este es un problema de almacenamiento, no un rechazo de la edición. Si ocurrió mientras se borraban datos de este dispositivo, es posible que parte de ellos ya se haya eliminado, incluidos cambios que aún no se habían enviado: compruebe que las ventas y los cambios recientes aparecen en su tienda. Si sigue ocurriendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Compruebe el espacio libre del dispositivo y libere espacio eliminando otros archivos o aplicaciones: la configuración del almacenamiento falla por completo si el disco o la cuota de almacenamiento del navegador están llenos. No use «Borrar datos de navegación» del navegador para liberar espacio: también elimina las ventas de WCPOS que aún no se han enviado.
2. Reinicie WCPOS e intente realizar la misma acción de nuevo.
3. En la web, compruebe que el navegador permite almacenamiento persistente para el sitio — las ventanas privadas y los ajustes que bloquean todos los datos no lo permiten.
4. Si sigue fallando, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte.
