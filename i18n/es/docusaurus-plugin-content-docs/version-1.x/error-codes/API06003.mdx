# API06003: Configuración de Sitio Inválida {#api06003-invalid-site-configuration}

## Qué Significa Esto {#what-this-means}

La configuración del sitio es inválida o incompleta. Esto podría involucrar URLs incorrectas, configuraciones de autenticación u otros problemas de configuración.

## Causas Comunes {#common-causes}

- **Configuración parcial** — Faltan algunas configuraciones
- **Configuraciones desajustadas** — La configuración no coincide con el sitio
- **Configuración corrupta** — Las configuraciones fueron corrompidas
- **Cambios en el sitio** — El sitio fue modificado sin actualizar la configuración de POS

## Cómo Solucionar {#how-to-fix}

### 1. Revisar Todas las Configuraciones {#1-review-all-settings}

Verifica la configuración completa:
- La URL del sitio es correcta
- La autenticación está configurada correctamente
- Cualquier configuración adicional es correcta

### 2. Reconfigurar desde Cero {#2-reconfigure-from-scratch}

:::warning Compruebe primero si hay trabajo sin guardar
Al borrar los datos locales o reinstalar la aplicación, se elimina todo lo que haya en este dispositivo y aún no haya llegado a la tienda, incluidas las ventas realizadas sin conexión, los carritos abiertos y los cambios que no se guardaron. Antes de borrar nada, abra **Salud de la tienda → Base de datos** y compruebe que no haya nada retenido ni que no haya llegado al servidor; después, revise **Salud de la tienda → Registros** para confirmar que hay **0 registros atascados** y **0 cambios pendientes de envío**. Por último, finalice o anote cada carrito abierto. Si WCPOS no tiene una página Salud de la tienda, actualice WCPOS antes de comprobarlo. Si aparece algo pendiente o no puede comprobarlo, no borre nada: consulte al responsable de la tienda o contacte con soporte.
:::

Solo si la configuración está dañada y después de realizar la comprobación anterior:
1. Limpia todas las configuraciones almacenadas
2. Inicia el proceso de configuración nuevamente
3. Ingresa la nueva configuración

### 3. Verificar los Requisitos del Sitio {#3-check-site-requirements}

Verifica que tu sitio de WordPress cumpla con los requisitos:
- WordPress está instalado y accesible
- WooCommerce está instalado y activo
- El plugin WCPOS está instalado y activo
- Los enlaces permanentes están habilitados (no "Plain")

### 4. Probar el Acceso al Sitio {#4-test-site-access}

Verifica que estas URLs funcionen en un navegador:
- `https://yoursite.com/` — Sitio principal
- `https://yoursite.com/wp-json/` — REST API
- `https://yoursite.com/wp-json/wcpos/v1/` — API de WCPOS

### 5. Verificar las Configuraciones de WordPress {#5-check-wordpress-settings}

En el Admin de WordPress:
1. Configuración → General — Verifica las URLs
2. Configuración → Enlaces Permanentes — Asegúrate de que no sea "Plain"
3. WooCommerce → Estado — Verifica si hay problemas

## Requisitos de Configuración {#configuration-requirements}

Una configuración válida necesita:
- **URL del Sitio** — URL completa con protocolo
- **Autenticación** — Credenciales o claves API válidas
- **Permisos** — El usuario tiene acceso al POS
- **Plugins** — Los plugins requeridos están activos
