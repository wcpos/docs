## Qué significa esto {#what-this-means}

El almacenamiento de este dispositivo dejó de responder, por lo que los guardados están en pausa.

Reinicie WCPOS (en la web, vuelva a cargar la pestaña) y compruebe que se guardó la última venta o cambio: es posible que no se haya escrito un cambio realizado en los segundos previos a que dejara de responder el almacenamiento. No borre los datos de este dispositivo. Si sigue ocurriendo, contacte con soporte.

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener ventas que aún no han llegado a su tienda. Si sigue ocurriendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Reinicie WCPOS: cierre y vuelva a abrir la aplicación; en la web, vuelva a cargar la pestaña en lugar de cerrarla. Esto vuelve a conectar la base de datos local en casi todos los casos.
2. Después de reiniciar, compruebe que se guardó la última venta o cambio: es posible que no se haya escrito un cambio realizado en los segundos previos al fallo. Si falta, vuelva a introducirlo.
3. En la web, no use la caja en una ventana privada o de incógnito y evite las extensiones que limpian el almacenamiento de forma agresiva: ambas cosas pueden interrumpir el almacenamiento local durante la sesión, y cerrar una ventana privada elimina todo lo almacenado en ella, incluidas las ventas que no se han enviado. Si está usando una ahora, manténgala abierta hasta que **Estado de la tienda → Base de datos** muestre 0 **cambios pendientes de envío**.
4. Si vuelve a aparecer en este dispositivo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte; indique qué estaba haciendo el dispositivo (suspensión, cambio de pestaña, poca memoria) cuando ocurrió.
