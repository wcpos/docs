## Qué significa esto {#what-this-means}

La ruta de la tienda de WCPOS no está disponible.

Pida al administrador del sitio que compruebe si un plugin de seguridad o de proxy está eliminando las cabeceras de solicitud de WCPOS.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos. Si esto persiste, consulte a la persona que gestiona su sitio de WordPress.

## Resolución de problemas {#troubleshoot}

**En el terminal** — para el cajero: pruebe en un navegador las dos formas REST compatibles: la dirección `/wp-json/` de la tienda y `/index.php?rest_route=/`. Considere que hay un bloqueo REST solo si ninguna devuelve JSON; en ese caso, informe al administrador.

**En la tienda** — para el administrador del sitio:

1. Confirme que WCPOS está activo: WP Admin → Plugins.
2. Si ninguna de las dos formas REST funciona, compruebe si un plugin de seguridad, un proxy o una CDN elimina los encabezados de las solicitudes de WCPOS o bloquea las solicitudes REST. Las causas habituales son las reglas del cortafuegos y las opciones de refuerzo que desactivan la API REST.
3. En algunos proveedores de alojamiento, volver a guardar los enlaces permanentes (Ajustes → Enlaces permanentes → Guardar) restaura las rutas REST que faltan.
