## Qué significa esto {#what-this-means}

Algunos registros se sincronizaron, pero uno o varios no lo hicieron.

Este código aparece de dos formas; el título de la fila del registro indica cuál corresponde:

- **"Sync partial"** (títulos de registros): algunos registros se han sincronizado y los registros indicados no. Revise cada registro indicado y el motivo antes de volver a intentar sincronizar solo esos registros.
- **"Gave up on a stuck data request"**: el canal de solicitudes de datos del motor de sincronización dejó de avanzar en una solicitud, así que, tras esperar un tiempo considerable, la aplicación la abandonó en lugar de dejar que bloqueara todo lo que estaba en cola detrás. No hace falta volver a intentarlo manualmente: el motor de sincronización vuelve a emitir la solicitud automáticamente. A menudo esto ocurre después de una llamada a la base de datos local que se quedó bloqueada, registrada por separado como [SYNC181](/error-codes/SYNC181).

## Sus datos {#your-data}

Para los registros que no se sincronizaron: el cambio está guardado en este dispositivo, pero aún no ha llegado a su tienda. Si el problema persiste, exporte los diagnósticos y contacte con el soporte de WCPOS. Para una solicitud de datos abandonada: no se ha cambiado nada; la solicitud se vuelve a emitir automáticamente.

## Resolución de problemas {#troubleshoot}

1. Si la sincronización fue parcial, expanda la entrada del registro para ver qué registros no se sincronizaron y el motivo indicado para cada uno.
2. Trate cada registro indicado según su propio motivo — un campo no válido hay que editarlo, un conflicto hay que compararlo con la tienda.
3. Reintente solo los registros que fallaron; el resto ya está sincronizado y no necesita nada.
4. Si aparece la entrada "Gave up on a stuck data request", no hace falta hacer nada, salvo que la pantalla siga bloqueada; en ese caso, vuelva a cargar la aplicación y, si sigue ocurriendo, exporte la información de depuración y contacte con el soporte.
