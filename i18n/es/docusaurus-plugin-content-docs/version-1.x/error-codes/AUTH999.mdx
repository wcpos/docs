## Qué significa esto {#what-this-means}

El inicio de sesión o el mantenimiento de la sesión encontró un problema inesperado.

Vuelva a intentar la acción una vez. Si vuelve a ocurrir, cierre sesión y vuelva a iniciarla; después, use **Copiar información de depuración** y contacte con soporte.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Si el problema persiste, use **Copiar información de depuración** y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Intente la acción una vez más; si vuelve a fallar, cierre la sesión y vuelva a iniciarla.
2. Expanda la entrada del registro y anote el código del evento y cualquier serverCode — un código 999 significa que la causa aún no tiene un código propio, y ese contexto es lo que la identifica.
3. Si se repite, utilice Copiar información de depuración y contacte con el soporte.
