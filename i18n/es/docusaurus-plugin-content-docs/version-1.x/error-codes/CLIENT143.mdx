## Qué significa esto {#what-this-means}

La búsqueda no encontró un producto que debería haber encontrado.

No tiene que hacer nada, a menos que un producto visible siga sin aparecer en la búsqueda; en ese caso, vuelva a cargar WCPOS.

Una comprobación periódica pidió al índice de búsqueda local un registro usando las propias palabras de ese registro, pero el índice no lo devolvió. Esto significa que las búsquedas podrían haber mostrado menos resultados de los que realmente hay en este dispositivo. Es posible que la aplicación reconstruya el índice por sí sola, pero solo una vez por lista durante cada sesión, así que no se garantiza la reconstrucción.

## Sus datos {#your-data}

No se modificaron datos de la tienda. Esto solo afecta al índice de búsqueda local, que se deriva de los datos ya presentes en este dispositivo; no se pierde nada al reconstruirlo.

## Solución de problemas {#troubleshoot}

1. No tiene que hacer nada, a menos que un producto visible siga sin aparecer en la búsqueda; las ventas pueden continuar con normalidad. Es posible que la aplicación reconstruya el índice por sí sola, pero solo una vez por lista durante cada sesión; por tanto, si el código vuelve a aparecer, continúe con el paso siguiente.
2. Si la búsqueda sigue sin encontrar registros visibles en la aplicación —un producto, cliente, pedido u otra lista—, recargue la aplicación: en la web, recargue la pestaña del navegador; en escritorio y dispositivos móviles, cierre y vuelva a abrir la aplicación. Esto permite intentar una nueva reconstrucción la próxima vez que se detecte el problema.
3. Si el código vuelve a aparecer después de recargar, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte: la entrada del registro incluye los datos que soporte necesita para identificar la lista afectada y el registro que no encontró el índice.
