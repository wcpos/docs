## Qué significa esto {#what-this-means}

El índice de búsqueda no pudo encontrar un producto que debería contener; la aplicación intenta reconstruir automáticamente el índice de búsqueda.

Una comprobación automática periódica solicitó al índice de búsqueda local un registro usando las propias palabras de ese registro, y el índice no lo devolvió. Esto significa que las búsquedas podrían haber mostrado menos resultados de los que realmente contiene este dispositivo. La aplicación intenta una reconstrucción automática del índice por lista y sesión para corregirlo.

## Sus datos {#your-data}

No se modificaron datos de la tienda. Esto solo afecta al índice de búsqueda local, que se deriva de los datos ya presentes en este dispositivo; no se pierde nada al reconstruirlo.

## Solución de problemas {#troubleshoot}

1. Normalmente no es necesario realizar ninguna acción y las ventas pueden continuar con normalidad: la aplicación intenta reconstruirlo automáticamente y las búsquedas se recuperan cuando finaliza. Solo se intenta una reconstrucción por lista y sesión, por lo que, si este código se repite, continúe con el siguiente paso.
2. Si la búsqueda sigue sin encontrar registros visibles en la aplicación —un producto, cliente, pedido u otra lista—, recargue la aplicación: en la web, recargue la pestaña del navegador; en escritorio y dispositivos móviles, cierre y vuelva a abrir la aplicación. Esto permite intentar una nueva reconstrucción la próxima vez que se detecte el problema.
3. Si el código vuelve a aparecer después de recargar, exporte la información de depuración y contacte con soporte; la entrada de registro incluye los detalles que soporte necesita para identificar la lista afectada y el registro que el índice no encontró.
