## Qué significa esto {#what-this-means}

Los datos almacenados en este dispositivo pertenecen a una versión diferente de la aplicación y no se pueden abrir.

La solución consiste en borrar la base de datos local del dispositivo y volver a abrir la aplicación: WCPOS volverá a descargar todo de su tienda. Una discrepancia de esquema suele producirse tras actualizar o revertir la versión de la aplicación en este dispositivo.

:::warning Al borrar se pierden los datos no sincronizados
Al borrar la base de datos local **se elimina permanentemente todo lo que haya en este dispositivo y aún no se haya sincronizado con su tienda**; por ejemplo, las ventas realizadas sin conexión. Como no se puede abrir la base de datos, no es posible sincronizarlas antes y, por tanto, no se pueden recuperar. Si sabe que hay ventas importantes sin sincronizar en este dispositivo, contacte con el soporte **antes** de borrar los datos.
:::

## Sus datos {#your-data}

Los datos de su tienda están a salvo: se descargarán de nuevo la próxima vez que se abra la aplicación. Solo se borra la copia local del dispositivo, incluidos los cambios que aún no habían llegado a su tienda (consulte la advertencia anterior).

## Resolución de problemas {#troubleshoot}

1. Asegúrese de que WCPOS esté actualizado en este dispositivo; una discrepancia de esquema suele producirse tras un cambio de versión.
2. Borre la base de datos local y vuelva a abrir la aplicación; siga las instrucciones de [Borrar todos los datos locales](/support/troubleshooting/clear-local-data), donde se explica cómo usar el botón de la aplicación, la aplicación web y la aplicación de escritorio. WCPOS volverá a descargar automáticamente los datos de su tienda. (Esto elimina los datos no sincronizados de este dispositivo; consulte la advertencia anterior).
3. Si el error vuelve a aparecer después de borrar los datos, use **Copiar información de depuración** y contacte con el soporte.
