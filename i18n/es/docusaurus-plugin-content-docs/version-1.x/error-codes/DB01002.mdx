# DB01002: Tiempo de expiración de consulta {#db01002-query-timeout}

## Qué significa esto {#what-this-means}

Una operación de base de datos tardó demasiado en completarse. La consulta a la base de datos local superó el tiempo máximo permitido.

## Causas comunes {#common-causes}

- **Conjunto de datos grande** — Número muy grande de productos o registros
- **Consulta compleja** — Consulta que involucra muchas condiciones
- **Rendimiento del dispositivo** — El dispositivo está funcionando lentamente
- **Fragmentación de la base de datos** — La base de datos necesita optimización

## Cómo arreglar {#how-to-fix}

### 1. Esperar y reintentar {#1-wait-and-retry}

La consulta puede tener éxito en el reintento:
- Cerrar y reabrir el POS
- Intentar la operación de nuevo
- Evitar otras operaciones intensivas simultáneamente

### 2. Cerrar otras aplicaciones {#2-close-other-applications}

Liberar recursos del dispositivo:
- Cerrar pestañas de navegador no utilizadas
- Cerrar otras aplicaciones
- Reiniciar el dispositivo si es necesario

### 3. Reducir el alcance de datos {#3-reduce-data-scope}

Si busca:
- Utilizar términos de búsqueda más específicos
- Aplicar filtros para restringir los resultados
- Dividir operaciones grandes en más pequeñas

### 4. Optimizar la base de datos {#4-optimise-the-database}

:::warning Compruebe primero si hay trabajo sin guardar
Borrar los datos locales o reinstalar la aplicación elimina todo lo que haya en este dispositivo y no haya llegado a su tienda, incluidas las ventas realizadas sin conexión, los carritos abiertos y los cambios que no se guardaron. Antes de borrar nada, abra **Estado de la tienda → Base de datos** y compruebe que no haya nada indicado como retenido o que nunca haya llegado al servidor; después, consulte **Estado de la tienda → Registros** y compruebe que haya **0 registros atascados** y **0 cambios pendientes de envío**. Luego, complete o anote cada carrito abierto. Si su WCPOS no tiene la página Estado de la tienda, actualice WCPOS primero y vuelva a comprobarlo. Si aparece algo, hay elementos pendientes o no puede comprobarlo, no borre nada: consulte al propietario de la tienda o contacte con soporte.
:::

Solo si los demás pasos de esta página no ayudaron, y únicamente después de la comprobación anterior, borre y vuelva a sincronizar:
1. Limpiar los datos locales (opción de configuración si está disponible)
2. Iniciar sesión nuevamente
3. Dejar que los datos se sincronicen de nuevo

### 5. Verificar el rendimiento del dispositivo {#5-check-device-performance}

Asegúrese de que su dispositivo cumpla con los requisitos:
- RAM suficiente
- Velocidad del procesador adecuada
- SSD preferido sobre HDD

## Catálogos grandes {#large-catalogues}

Si tiene un catálogo de productos muy grande:
- La sincronización inicial tarda más
- Considere utilizar filtros en el POS
- Algunas operaciones naturalmente toman más tiempo
- Contacte al soporte para obtener consejos de optimización
