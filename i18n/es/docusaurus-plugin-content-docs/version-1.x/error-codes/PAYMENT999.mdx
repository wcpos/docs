## Qué significa esto {#what-this-means}

La gestión del pago encontró un problema inesperado.

Confirme si el pago se completó antes de reintentar. Exporte los diagnósticos y contacte con el soporte si no está claro.

## Sus datos {#your-data}

No se ha podido confirmar el resultado: verifíquelo antes de reintentar. Si esto persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Confirme si el pago se completó antes de reintentar: la pantalla del terminal, el panel del proveedor y el pedido en WP Admin.
2. Expanda la entrada del registro para ver el código del evento y el contexto — este código genérico significa que la causa aún no tiene un código propio.
3. Si el resultado sigue sin estar claro o el código se repite, exporte la información de depuración y contacte con el soporte.
