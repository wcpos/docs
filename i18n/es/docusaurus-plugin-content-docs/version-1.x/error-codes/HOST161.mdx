## Qué significa {#what-this-means}

El host está limitando la tasa de las cajas de esta tienda.

El servidor sigue respondiendo 429 (demasiadas solicitudes) aunque la aplicación ya está reduciendo el ritmo y respetando los retrasos Retry-After del servidor. Varias cajas en una misma conexión a internet comparten una única dirección, así que los límites de tasa por origen las tratan como un solo cliente muy activo. La sincronización continúa automáticamente, pero irá con retraso hasta que se eleve el límite.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos.

## Solución de problemas {#troubleshoot}

1. Pida al host que eleve o exima el límite de tasa de la API REST para el tráfico propio de la tienda — indique la IP estática de la tienda si tiene una.
2. Los servicios de seguridad que cuentan las respuestas de error repetidas (429) para un bloqueo (por ejemplo, el IDS de Sucuri) pueden necesitar que se excluya la API de la tienda de ese contador.
3. Si varias cajas comparten una conexión, menciónelo al host: una IP aquí es toda una tienda, no un solo usuario.
