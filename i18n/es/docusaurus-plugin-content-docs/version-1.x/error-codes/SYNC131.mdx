## Qué significa esto {#what-this-means}

Se produjo un error en su tienda y no se completó esta solicitud.

Se pudo acceder a la tienda, pero el servidor no pudo procesar la solicitud: es un problema del sitio web, no del POS. Vuelva a intentar la acción. Si sigue ocurriendo, pida al administrador del sitio que revise **WooCommerce → Estado → Registros**. No se perdió nada en este dispositivo.

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener cambios que aún no han llegado a su tienda. Es posible que un cambio que se estaba enviando no haya llegado a la tienda. Si sigue ocurriendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

**En el POS (cajero):** expanda la entrada del registro y anote el status, el endpoint y el serverCode — indican qué estaba haciendo el servidor cuando falló.

**En el sitio web (administrador del sitio / proveedor de alojamiento):**

1. Abra WooCommerce → Estado → Registros en el sitio y revise el registro de errores fatales más reciente en torno a la hora del fallo; una respuesta de clase 500 casi siempre deja allí un error de PHP.
2. Si el fallo comenzó tras la actualización de un plugin, un tema o PHP en el sitio, sospeche primero de ese cambio y reviértalo o desactívelo.
3. Si los registros de WooCommerce no muestran nada, solicite al proveedor de alojamiento el registro de errores de PHP del servidor para esa misma franja horaria.

**Después, de vuelta en el POS:** vuelva a intentar la acción.
