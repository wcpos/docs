## Qué significa esto {#what-this-means}

Este cambio no se pudo guardar en la base de datos local y permanece únicamente en este dispositivo.

No borre ni vuelva a cargar los datos locales. Primero anote (o vuelva a introducir) el cambio que no se pudo guardar — un reinicio podría hacerlo perder — y después compruebe el almacenamiento del dispositivo. Si los intentos de escritura siguen fallando, exporte los diagnósticos y póngase en contacto con soporte.

## Sus datos {#your-data}

Los datos de este dispositivo pueden estar en riesgo: no borre los datos locales. Si esto persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Si la entrada del registro indica un registro, anótelo — ese es el cambio que no se ha guardado. Las escrituras de sitio y de credenciales pueden indicar solo la operación fallida y el error; anote esos datos antes de continuar.
2. No borre los datos del sitio, ni restablezca la aplicación, ni la desinstale: el cambio no guardado existe solo en este dispositivo, y borrar el almacenamiento local lo elimina de forma permanente.
3. Compruebe el almacenamiento libre del dispositivo — un disco lleno o una cuota de almacenamiento del navegador agotada es el motivo más habitual de que falle una escritura local.
4. Reinicie WCPOS una vez y realice una edición pequeña e inofensiva para confirmar si se guardan los cambios nuevos.
5. Si las escrituras siguen fallando, utilice Copiar información de depuración en la pantalla de Registros y contacte con el soporte antes de intentar cualquier reparación.
