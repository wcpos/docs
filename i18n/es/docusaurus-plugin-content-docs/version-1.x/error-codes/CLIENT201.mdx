## Qué significa esto {#what-this-means}

Este dispositivo se quedó sin memoria y es posible que la última acción no haya terminado.

Cierre otras aplicaciones o pestañas, reinicie WCPOS y compruebe si se guardó la última venta o cambio. Si no se guardó, vuelva a hacerlo.

## Sus datos {#your-data}

No se pudo confirmar el resultado; compruébelo antes de volver a intentarlo. Si estaba guardando una venta o un cambio cuando se agotó la memoria, confirme que se guardó antes de repetirlo.

## Resolución de problemas {#troubleshoot}

1. Cierre otras aplicaciones o pestañas del navegador: WCPOS comparte la memoria del dispositivo con todo lo demás que esté en ejecución.
2. Reinicie WCPOS.
3. Antes de repetir la acción, compruebe si se guardó la última venta o cambio: revise **Salud de la tienda → Base de datos** (una venta incluida en **cambios pendientes de envío** está guardada y todavía se está enviando), el carrito y Pedidos (WCPOS Pro) o **WooCommerce → Pedidos**. Si se usó una tarjeta, compruebe también el terminal o el proveedor de pago; si se cobró al cliente, no vuelva a cobrarle. Repita la acción una sola vez únicamente si realmente no se guardó.
4. Si una acción concreta provoca de forma sistemática que se agote la memoria, anote cuál fue, pulse **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte.
5. Si esto ocurre a diario en el mismo dispositivo, puede que el dispositivo sea insuficiente para el catálogo — notifíquelo para que el soporte pueda confirmarlo.
