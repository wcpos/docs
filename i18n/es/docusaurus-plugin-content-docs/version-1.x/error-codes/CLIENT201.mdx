## Qué significa esto {#what-this-means}

WCPOS se quedó sin memoria y no pudo terminar la operación.

Reinicie WCPOS y reinténtelo una vez; exporte los diagnósticos si el dispositivo vuelve a quedarse sin memoria.

## Sus datos {#your-data}

No se pudo confirmar el resultado: si estaba guardando algo cuando se agotó la memoria, compruebe si se completó antes de volver a intentarlo.

## Resolución de problemas {#troubleshoot}

1. Reinicie WCPOS. Si estaba guardando algo cuando se agotó la memoria, compruebe si se completó antes de volver a intentarlo; si no, inténtelo una vez.
2. Cierre otras aplicaciones o pestañas del navegador — el POS comparte la memoria del dispositivo con todo lo demás que se esté ejecutando en él.
3. Si una acción concreta agota la memoria de forma sistemática, anote cuál era y contacte con el soporte con la información de depuración.
4. Si esto ocurre a diario en el mismo dispositivo, puede que el dispositivo sea insuficiente para el catálogo — notifíquelo para que el soporte pueda confirmarlo.
