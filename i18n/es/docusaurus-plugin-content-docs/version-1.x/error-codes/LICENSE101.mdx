## Qué significa esto {#what-this-means}

Su licencia de WCPOS Pro no está activa para esta tienda o este dispositivo.

Compruebe el estado local, el del servidor de licencias y el del actualizador, y active después la licencia para la tienda indicada.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos. Si esto persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

**En la tienda** — para el administrador del sitio o titular de la licencia:

1. Compruebe el estado de la licencia en los ajustes del POS en WP Admin — debería figurar como activa para la URL exacta de esta tienda.
2. Un cambio en la URL del sitio (de http a https, añadir o quitar www, un cambio de dominio, una copia de staging) desactiva la licencia para la nueva dirección — vuelva a activarla para la actual.
3. Si la licencia aparece activa, pero WCPOS sigue indicando lo contrario, desactívela y vuelva a activarla una vez.
4. ¿Sigue bloqueado? Exporte la información de depuración y contacte con el soporte indicando su referencia de licencia.

**En el terminal:** después de volver a activar la licencia, recargue la página para aplicar el cambio.
