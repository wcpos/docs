## Qué significa esto {#what-this-means}

Los datos locales de la tienda están dañados y necesitan repararse para que la sincronización pueda continuar.

Ejecute la reparación específica de los datos afectados y restablezca esos datos locales solo si el problema vuelve a aparecer.

## Sus datos {#your-data}

Los datos de este dispositivo pueden estar en riesgo: no borre los datos locales. Si esto persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Abra Estado de la tienda → Base de datos y ejecute la reparación específica de los datos afectados; un restablecimiento completo descarta más cosas que la reparación.
2. Reintente la acción que falló y luego vigile Estado de la tienda → Registros por si este código se repite.
3. Si se vuelven a señalar los mismos datos, restablezca únicamente esos datos locales para que se descarguen de nuevo desde su tienda — pero solo después de haber anotado los cambios sin enviar.
4. Una corrupción que se repite apunta a un fallo del almacenamiento del dispositivo: exporte la información de depuración y contacte con el soporte.
