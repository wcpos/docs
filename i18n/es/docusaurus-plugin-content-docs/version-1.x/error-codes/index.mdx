# Códigos de Error

Cuando WCPOS encuentra un problema, muestra un código de error que ayuda a identificarlo. A partir de la **v1.10.0**, los códigos siguen el formato **dominio + tres dígitos**, por ejemplo `SYNC131` o `AUTH311`. El dominio indica el área del POS; el número identifica la condición concreta. Cada código tiene su propia página con lo que significa, qué hacer y qué implica para sus datos.

En el POS, los códigos de error aparecen en **Estado de la tienda → Registros**: despliegue una fila y utilice el enlace **Ayuda** para ir directamente a la página del código aquí.

## Dominios de error (v1.10.0+) {#error-domains}

| Dominio | Área | Ejemplos |
|--------|------|----------|
| `AUTH` | Inicio de sesión, sesiones y tokens | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | Finalización de pedidos en la caja | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | La propia aplicación POS y el almacenamiento local | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `LICENSE` | Activación y validación de la licencia Pro | [LICENSE101](./LICENSE101) |
| `PAYMENT` | Pasarelas de pago y terminales | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | Impresión de recibos | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | Datos de productos y operaciones del catálogo | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `SYNC` | Sincronización entre el POS y su tienda | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

Utilice la barra lateral para consultar todos los códigos de un dominio, o busque el código directamente.

Los códigos que terminan en `999` son el comodín del dominio para condiciones que todavía no tienen un código específico.

## Códigos heredados (anteriores a la v1.10.0) {#legacy-codes}

Las versiones anteriores a la v1.10.0 utilizaban un esquema distinto: `[DOMINIO][CATEGORÍA][CÓDIGO_ESPECÍFICO]`, por ejemplo `API04001` = API (dominio) + 04 (errores de respuesta) + 001 (formato de respuesta no válido). Si utiliza una versión anterior, o está leyendo una entrada de registro antigua o un hilo de soporte, estas páginas siguen siendo válidas:

| Dominio | Total de Códigos | Cubre |
|---------|------------------|-------------------|
| [API](./api) | 39 códigos | Comunicación del servidor, autenticación, problemas de plugins |
| [DB](./db) | 9 códigos | Almacenamiento y recuperación de datos locales |
| [PY](./py) | 6 códigos | Procesamiento de pagos |
| [SY](./sy) | 5 códigos | Recursos del dispositivo y configuración |

Un cliente v1.10.0+ nunca emite estos códigos: si ve uno en un POS actualizado, procede de una entrada de registro antigua conservada o de un mensaje del lado del servidor.
