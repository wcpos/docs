## Qué significa esto {#what-this-means}

WCPOS no pudo confirmar si el terminal cobró el pago.

Compruebe el terminal de pago antes de intentar otro cargo y contacte con el proveedor de pagos si el resultado sigue sin estar claro.

## Sus datos {#your-data}

No se ha podido confirmar el resultado: verifíquelo antes de reintentar. Si esto persiste, contacte con su proveedor de pagos.

## Resolución de problemas {#troubleshoot}

1. No pase la tarjeta de nuevo todavía.
2. Compruebe la pantalla del propio terminal y después el panel de su proveedor de pagos — el registro del proveedor es la autoridad sobre si el cargo se realizó.
3. Si tiene acceso a WP Admin (o se lo puede pedir al propietario de la tienda), compruebe WooCommerce → Pedidos: es posible que el pago completado ya esté registrado allí.
4. Vuelva a cobrar únicamente cuando el panel del proveedor no muestre ningún cargo.
5. Si el cargo figura como pendiente o incierto, contacte con el proveedor de pagos antes de actuar.
