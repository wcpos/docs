## Qué significa esto {#what-this-means}

Una tarea de sincronización en segundo plano se detuvo inesperadamente antes de terminar.

No tiene que hacer nada: WCPOS reinicia estas tareas automáticamente y no se pierde nada. Si este código sigue apareciendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte.

## Sus datos {#your-data}

No se pierde nada; no afecta a los datos de pedidos ni de productos. Si persiste, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. En principio no hay nada que hacer: el POS reinicia automáticamente la tarea en segundo plano que se bloqueó y no hay datos de pedidos implicados.
2. Si el código se repite en cuestión de minutos, recargue la aplicación una vez para que el motor de sincronización arranque limpio.
3. Si sigue ocurriendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte: vale la pena informar de un bloqueo recurrente de una tarea, ya que es un defecto de la aplicación, no un problema de la tienda.
