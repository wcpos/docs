## Qué significa {#what-this-means}

La API REST de la tienda no respondió en ninguna de las formas de dirección que esta aplicación puede usar.

La aplicación probó la API REST de la tienda en su dirección normal (/wp-json/...) y en la dirección de reserva integrada de WordPress (/?rest_route=...), y ninguna respondió. Es posible que el propio sitio web de la tienda esté funcionando — esto es específicamente que la API REST no es accesible, normalmente por un plugin de seguridad que la oculta o una regla de firewall que la bloquea.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos.

## Solución de problemas {#troubleshoot}

**En la tienda** — para el administrador del sitio: si un plugin de seguridad oculta o renombra `/wp-json/` (por ejemplo, WP Hide), permita también la forma integrada de WordPress `/?rest_route=` — la aplicación recurre a ella automáticamente.

**En el host / servidor:**

1. Revise las reglas del firewall (WAF) en busca de cualquier cosa que coincida con `wp-json` o `rest_route` y permita el paso de la propia API REST de la tienda.
2. Si el servidor está detrás de una página de mantenimiento o un desafío de bots, las solicitudes REST pueden responderse con una página HTML — desactive el desafío para la API REST.

**Para probar (cualquiera):** `https://your-store.com/?rest_route=/` debería devolver JSON, no una página 403 ni la página de inicio del sitio.
