## Qué significa esto {#what-this-means}

WCPOS encontró un error inesperado.

Compruebe si se completó la última acción antes de volver a intentarlo; en el caso de una venta, abra el pedido y compruebe su estado. Si vuelve a ocurrir, pulse **Copiar información de depuración** y envíela al soporte de WCPOS.

## Sus datos {#your-data}

No se pudo confirmar el resultado; compruébelo antes de volver a intentarlo. Si vuelve a ocurrir, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Compruebe si se completó la última acción antes de volver a intentarlo; en el caso de una venta, abra el pedido y compruebe su estado; si se trataba de un pago, compruebe también el terminal o el proveedor. Si no se completó, inténtelo una vez más.
2. Expanda la entrada del registro y anote el código del evento y el contexto — un código 999 significa que el fallo aún no tiene un código propio, y esta es la información que lo identifica.
3. Si vuelve a ocurrir, pulse **Copiar información de depuración** en la pestaña **Registros** y envíela al soporte de WCPOS; los avisos permiten añadir el código específico.
