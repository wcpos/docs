## Qué significa esto {#what-this-means}

WCPOS encontró un error inesperado.

Intente la acción una vez más y, si vuelve a fallar, exporte los diagnósticos y contacte con el soporte.

## Sus datos {#your-data}

No se ha podido confirmar el resultado: verifíquelo antes de reintentar. Si esto persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Intente la acción una vez más.
2. Expanda la entrada del registro y anote el código del evento y el contexto — un código 999 significa que el fallo aún no tiene un código propio, y esta es la información que lo identifica.
3. Si se repite, exporte la información de depuración y contacte con el soporte — informar de ello es la forma de que se cree el código específico.
