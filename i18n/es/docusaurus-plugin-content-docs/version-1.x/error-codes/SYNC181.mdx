## Qué significa esto {#what-this-means}

Una operación de base de datos local está tardando mucho más de lo normal; su resultado aún se desconoce.

Una única lectura o escritura en la base de datos local de este dispositivo ha quedado sin respuesta durante mucho más tiempo de lo normal, mientras la base de datos sigue respondiendo a todo lo demás. Este registrador solo registra el bloqueo; no cancela ni vuelve a intentar la operación, por lo que la llamada original aún puede completarse o fallar más tarde. La entrada existe para que una pantalla o indicador de carga bloqueado deje un registro que identifique exactamente qué operación se bloqueó. El trabajo de sincronización bloqueado tiene una ruta de tiempo de espera y reintento independiente, registrada como una entrada "Se abandonó una solicitud de datos bloqueada" en [SYNC321](/error-codes/SYNC321). Una llamada bloqueada desde una pantalla permanece pendiente hasta que finaliza o se recarga la aplicación.

## Sus datos {#your-data}

La operación bloqueada suele ser una consulta, que no modifica nada. Si se estaba guardando un cambio en ese momento, abra el registro y confirme que se guardó; es posible que no haya habido ningún síntoma visible. El contexto de la entrada indica la operación y la colección de datos implicadas.

## Solución de problemas {#troubleshoot}

1. Si todo funciona correctamente, no se requiere ninguna acción: lo más probable es que la llamada se haya completado, aunque lentamente.
2. Si una pantalla o indicador de carga permanece bloqueado, recargue la aplicación: en la web, recargue la pestaña del navegador; en escritorio y dispositivos móviles, cierre y vuelva a abrir la aplicación. Esto abandona la operación bloqueada; la pantalla se carga de nuevo y realiza una nueva consulta a la base de datos. No se vuelve a enviar un guardado que estaba en curso; abra el registro y confirme que se guardó.
3. Si este código aparece regularmente en el mismo dispositivo, exporte la información de depuración desde la pantalla Registros y contacte con el soporte: el contexto de la entrada indica la operación y la colección, la espera exacta y la carga de trabajo de la base de datos durante ese tiempo.
