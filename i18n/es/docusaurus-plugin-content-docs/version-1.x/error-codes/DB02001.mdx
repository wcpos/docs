# DB02001: Registro Duplicado {#db02001-duplicate-record}

## Lo que Esto Significa {#what-this-means}

La base de datos intentó insertar un registro con un ID que ya existe. Cada registro debe tener un identificador único.

## Causas Comunes {#common-causes}

- **Conflicto de sync** — Los mismos datos sincronizados dos veces
- **Condición de carrera** — Múltiples operaciones creando el mismo registro
- **Corrupción de datos** — Los ID fueron corrompidos o duplicados
- **Problema de importación** — Importando datos que ya existen

## Cómo Solucionarlo {#how-to-fix}

### 1. Refrescar los Datos {#1-refresh-data}

Re-sincronizar desde el servidor:
- Obtener los datos más recientes
- Dejar que el proceso de sync resuelva conflictos
- Los datos más nuevos deberían tener prioridad

### 2. Reintentar la Operación {#2-retry-the-operation}

Si está creando nuevos registros:
- El sistema puede que ya lo haya creado
- Verificar si el registro existe
- Evitar hacer clic en enviar varias veces

### 3. Limpiar la Caché Local {#3-clear-local-cache}

:::warning Compruebe primero si hay trabajo sin guardar
Al borrar los datos locales o reinstalar la aplicación, se elimina todo lo que haya en este dispositivo y aún no haya llegado a su tienda, incluidas las ventas realizadas sin conexión, los carritos abiertos y los cambios que no se guardaron. Antes de borrar nada, abra **Estado de la tienda → Base de datos** y compruebe que no haya nada retenido ni que nunca haya llegado al servidor; después, abra **Estado de la tienda → Registros** y compruebe que haya **0 registros bloqueados** y **0 cambios pendientes de envío**. Luego, complete o anote cada carrito abierto. Si su WCPOS no tiene la página Estado de la tienda, actualice primero WCPOS y vuelva a comprobarlo. Si aparece algo en la lista, hay elementos pendientes o no puede comprobarlo, no borre nada: consulte con el propietario de la tienda o póngase en contacto con el servicio de asistencia.
:::

Solo si los pasos 1, 2 y 4 no han servido de ayuda, y únicamente tras realizar la comprobación anterior, restablezca los datos locales:
1. Limpiar la base de datos/cache local
2. Iniciar sesión nuevamente
3. Sincronizar datos de nuevo

### 4. Verificar Duplicados en WooCommerce {#4-check-for-duplicates-in-woocommerce}

Si el problema persiste:
- Verificar WooCommerce en busca de entradas duplicadas
- Buscar productos/pedidos con los mismos ID
- Limpiar cualquier duplicado en el admin

### 5. Reportar Problemas Persistentes {#5-report-persistent-issues}

Si esto sucede con frecuencia:
- Anotar qué acciones lo causan
- Verificar si hay patrones
- Informar al soporte con detalles

## Por Qué Esto Es Importante {#why-this-matters}

Los ID duplicados causarían:
- Confusión sobre cuál registro es correcto
- Sobrescritura de datos
- Problemas de sincronización

El error previene la corrupción de datos.
