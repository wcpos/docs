## Qué significa esto {#what-this-means}

No se puede acceder a su tienda en este momento.

No tiene que hacer nada: siga vendiendo. Los cambios se envían automáticamente cuando se restablece la conexión. Si el problema persiste, compruebe la conexión de este dispositivo y si se carga el sitio web de su tienda.

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener cambios que aún no han llegado a su tienda. Se envían automáticamente cuando la tienda vuelve a responder.

## Resolución de problemas {#troubleshoot}

1. Siga vendiendo: las ventas se guardan en este dispositivo y se envían automáticamente cuando la tienda vuelve a responder.
2. Compruebe si la propia caja está en línea: ¿puede cargarse cualquier otro sitio web desde este dispositivo?
3. Abra el sitio web de su propia tienda en una pestaña del navegador del mismo dispositivo; si tampoco se carga allí, el que está caído es el sitio o su alojamiento, no el POS.
4. **Para quien administre la red de este dispositivo:** si el sitio carga, pero el POS sigue sin conexión, algo entre ambos está bloqueando las solicitudes a la API: una VPN, un cortafuegos, un bloqueador de anuncios o un plugin de seguridad. Las herramientas de desarrollo del navegador (pestaña Red) — o **Avanzado → Alternar herramientas para desarrolladores** en la aplicación de escritorio — muestran qué solicitud falla.
