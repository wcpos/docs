## Qué significa esto {#what-this-means}

La carga o la actualización de productos encontró un problema inesperado.

Vuelva a intentarlo. Si después los datos del producto siguen sin ser correctos, exporte los diagnósticos y contacte con el soporte.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos. Si esto persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. Vuelva a intentarlo — la mayoría de los problemas puntuales de carga de productos se resuelven al reintentar.
2. Si los datos del producto siguen sin ser correctos, expanda la entrada del registro para ver el código del evento y el contexto; este código genérico significa que la causa aún no tiene un código propio.
3. Exporte la información de depuración y contacte con el soporte si se repite.
