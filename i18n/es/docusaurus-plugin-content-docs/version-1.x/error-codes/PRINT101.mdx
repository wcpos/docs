## Qué significa esto {#what-this-means}

La impresión automática no se inició para este recibo.

Compruebe la impresora, la plantilla y la conexión seleccionadas; a continuación, use Imprimir ahora para imprimir el recibo manualmente.

## Qué hacer {#what-to-do}

Vuelva a intentar la acción. WCPOS no vuelve a intentarlo automáticamente; repita la acción cuando esté listo.

## Sus datos {#your-data}

No se ven afectados los datos de pedidos ni de productos.

## Solución de problemas {#troubleshoot}

1. Utilice Imprimir ahora para imprimir el recibo manualmente — la venta no se ve afectada.
2. Compruebe los ajustes de impresión: que esté seleccionada la impresora correcta y que se haya elegido una plantilla de recibo.
3. Si la impresión automática falla en todas las ventas, compruebe si la impresión manual funciona — si la manual funciona pero la automática falla, se trata de un problema de configuración; si ambas fallan, se trata de un problema de impresora.

## Dónde buscar {#where-to-look}

Cada aparición de este código se registra en el dispositivo que lo generó. Abra **Estado de la tienda → Registros** (el icono de pulso cardíaco situado en la parte inferior del panel de navegación), busque la entrada marcada con este código y expándala: la fila expandida muestra el motivo en lenguaje sencillo y el contexto capturado en el momento del error — para todo lo que haya implicado una solicitud a su tienda, esto incluye el propio código de error del servidor (`serverCode`), el `status` HTTP y el `endpoint`. Al informar de un problema, utilice **Copiar información de depuración** en la parte superior de la pantalla Registros (**Compartir información de depuración** en teléfonos y tabletas) en lugar de capturas de pantalla: incluye la versión de la aplicación, el estado de conexión y los errores más recientes. Los registros se conservan durante un máximo de 30 días, por lo que deben recopilarse mientras el problema sea reciente.
