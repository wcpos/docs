## Qué significa esto {#what-this-means}

Más de un producto coincide con este código de barras.

WCPOS no puede elegir entre ellos de forma segura, así que no se añadió nada. Busque el producto por su nombre y asigne a cada producto un código de barras único en la tienda para resolver el conflicto.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos. Si esto persiste, consulte al administrador de su tienda.

## Resolución de problemas {#troubleshoot}

**En el terminal:** busque el producto por nombre para completar esta venta; el escaneo no añadió nada porque el código de barras coincide con más de un producto.

La entrada del registro recoge el código escaneado y cuántos productos coincidieron; buscar el valor del código de barras en el POS muestra cuáles son.

**En la tienda (WP Admin):** asigne un código de barras único a cada uno de esos productos y vuelva a escanear para confirmar que solo queda una coincidencia.
