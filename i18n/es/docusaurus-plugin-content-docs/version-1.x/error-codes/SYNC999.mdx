## Qué significa esto {#what-this-means}

La sincronización encontró un problema inesperado.

Compruebe si terminó la acción indicada en esta entrada; si no, repítala. Si vuelve a ocurrir, pulse **Copiar información de depuración** y envíela a soporte.

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener cambios que aún no están en la tienda. Si la acción indicada en la entrada no terminó, repítala.

## Resolución de problemas {#troubleshoot}

1. Despliegue la entrada del registro y busque la acción que indica. Compruebe si terminó; si se trataba de un guardado, abra el pedido o registro y compruebe que aparezca el cambio. Si aparece, WCPOS lo envía automáticamente, así que déjelo como está.
2. Si no terminó, repítala. Si la entrada del registro indica que el cambio nunca se guardó en este dispositivo, no se capturó nada.
3. Anote el código y cualquier motivo de la entrada del registro: un código 999 significa que la causa concreta aún no tiene un código específico, por lo que este contexto es justo lo que necesita soporte.
4. Si vuelve a ocurrir, pulse **Copiar información de depuración** en la pestaña **Registros** y envíela a soporte; informar del problema permite añadir un código específico.
