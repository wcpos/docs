## Qué significa esto {#what-this-means}

La sincronización encontró un problema inesperado.

Las ventas ya registradas en este dispositivo están a salvo. Consulte primero el registro (vea Resolución de problemas): puede que se vuelva a intentar automáticamente o que, si la escritura nunca llegó a la cola, sea necesario volver a introducirla. Si este código sigue apareciendo, exporte los diagnósticos y contacte con el soporte.

## Sus datos {#your-data}

Si se registró su operación, está a salvo en este dispositivo y aún no ha llegado a su tienda; si el registro indica que la escritura falló antes de ponerse en cola (consulte el paso 2 de Resolución de problemas), vuelva a introducirla. Si el problema persiste, exporte los diagnósticos y contacte con el soporte de WCPOS.

## Resolución de problemas {#troubleshoot}

1. No dé por hecho que este código se reintentará. Expanda primero la entrada del registro: si confirma que la modificación ya estaba en cola, WCPOS la reintenta automáticamente, así que déjela abierta y deje que la cola se vacíe.
2. Si el error indica que falta el residente del motor o que la escritura falló antes de que se devolviera un ID de modificación, no se encoló nada — vuelva a ese registro o pedido y guárdelo de nuevo.
3. Expanda la entrada del registro y anote el código del evento y cualquier serverCode: un código 999 significa que la causa concreta aún no tiene un código propio, así que este contexto es justo lo que el soporte necesita.
4. Si el código sigue apareciendo, utilice Copiar información de depuración y contacte con el soporte — informar de ello es la forma de que se añada el código específico.
