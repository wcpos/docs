## Qué significa esto {#what-this-means}

WCPOS no pudo terminar de iniciarse.

En el terminal, esto se ve como una pantalla en blanco o bloqueada, o un indicador de carga que no desaparece. Suele significar que no se pudo abrir la base de datos local del dispositivo. A veces se soluciona al reiniciar; si no, hay que borrar la base de datos local y volver a abrir la aplicación. WCPOS volverá a descargarlo todo de la tienda.

:::warning Borrar estos datos elimina los datos no sincronizados
Al borrar la base de datos local, **se eliminan permanentemente de este dispositivo los datos que aún no se hayan sincronizado con la tienda**, por ejemplo, ventas realizadas sin conexión. Como no se puede abrir la aplicación, estos datos no se pueden sincronizar antes y no se podrán recuperar. Si sabe que hay ventas importantes sin sincronizar en este dispositivo, contacte con soporte **antes** de borrar los datos.
:::

## Sus datos {#your-data}

Los datos de la tienda están a salvo: se volverán a descargar la próxima vez que se abra la aplicación. Borrar los datos elimina solo la copia local de este dispositivo, incluidos los cambios que aún no hayan llegado a la tienda (consulte la advertencia anterior).

## Resolución de problemas {#troubleshoot}

1. Reinicie la aplicación una vez; en la web, vuelva a cargar la pestaña por completo. A menudo, un fallo temporal de inicio se resuelve solo.
2. Si sigue sin iniciarse, lo más probable es que no se pueda abrir la base de datos local. Bórrela y vuelva a abrir la aplicación; siga [Borrar todos los datos locales](/support/troubleshooting/clear-local-data), donde se explica el botón de la aplicación, la aplicación web y la aplicación de escritorio. WCPOS volverá a descargar automáticamente los datos de la tienda. (Esto elimina los datos no sincronizados de este dispositivo; consulte la advertencia anterior.)
3. Si sigue sin iniciarse después de borrar los datos, use **Copiar información de depuración** — o el error de la consola del navegador, si la aplicación no puede abrir sus propios registros — y contacte con soporte.
