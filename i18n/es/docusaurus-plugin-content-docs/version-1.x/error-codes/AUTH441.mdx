## Qué significa {#what-this-means}

El token de inicio de sesión es más grande de lo que este servidor acepta.

El servidor rechazó el token de inicio de sesión por su tamaño: un 400 cuando viaja en la cabecera Authorization, o un 414 cuando viaja en la URL. Ninguna codificación del lado del cliente puede reducirlo — hay que elevar los límites de tamaño de cabecera/URL del servidor, o hacer el token más pequeño.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos ni de productos.

## Solución de problemas {#troubleshoot}

1. En Apache, eleve LimitRequestFieldSize (ruta de cabecera) o LimitRequestLine (ruta de URL) en la configuración del vhost.
2. En nginx, eleve large_client_header_buffers.
3. Detrás de un proxy o CDN, el límite puede estar en esa capa — revise ambas.
4. Si los límites no se pueden cambiar, contacte con soporte para emitir un token más pequeño para este sitio.
