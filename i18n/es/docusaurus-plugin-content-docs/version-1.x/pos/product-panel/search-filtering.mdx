## Búsqueda de productos {#product-search}

### Campo de búsqueda unificado {#unified-search-field}

WCPOS cuenta con un único campo de búsqueda que busca simultáneamente en varios atributos del producto:

- **Nombre del producto** - Busca en el título y la descripción del producto
- **SKU** - Busca coincidencias en el campo postmeta `_sku` del producto
- **Código de barras** - Busca en el campo de código de barras configurado, que de forma predeterminada es el campo GTIN de WooCommerce `_global_unique_id` y puede cambiarse por `_sku` o cualquier clave postmeta personalizada en [Ajustes](/1.x/settings/wp-admin/general#barcode-field).

Basta con escribir el término de búsqueda en el campo «Buscar productos» y el POS filtrará al instante los resultados en todos estos campos.

### Tecnología de búsqueda tokenizada {#tokenized-search-technology}

La funcionalidad de búsqueda utiliza la [biblioteca FlexSearch](https://github.com/nextapps-de/flexsearch) con capacidades avanzadas de tokenización:

- **Coincidencia de subcadenas** - Encuentra el término en cualquier parte de una palabra (por ejemplo, buscar «berry» encuentra «blueberry»)
- **Optimizado para rendimiento** - Utiliza una configuración de rendimiento preestablecida para obtener resultados de búsqueda rápidos
- **Adaptación al idioma** - Se adapta al idioma configurado en la tienda
- **Inicialización diferida** - Optimiza el uso de memoria al cargar los índices de búsqueda solo cuando son necesarios

:::note Los términos de búsqueda necesitan al menos 3 caracteres
A partir de la v1.10.0, la búsqueda encuentra subcadenas **dentro** de las palabras: «berry» encuentra «blueberry» y «saippua» encuentra «Kuorintasaippua». Esto exige una longitud mínima del término: las consultas de menos de **3 caracteres** no se comparan con el índice de texto. Los códigos cortos siguen funcionando mediante las búsquedas por código de barras y SKU.

Antes de la v1.10.0, las coincidencias se limitaban al prefijo (la búsqueda encontraba el inicio de una palabra, nunca una parte intermedia).
:::

### Cómo funciona la búsqueda {#how-search-works}

Al escribir en el campo de búsqueda, el POS:

1. **Tokeniza** la entrada en términos de búsqueda
2. **Busca localmente** primero en los datos de productos almacenados para obtener resultados instantáneos
3. **Consulta el servidor** para obtener los productos coincidentes si aún no están almacenados localmente, y los guarda para que la misma búsqueda sea instantánea la próxima vez
4. **Actualiza los resultados** en tiempo real a medida que escribe

La búsqueda descarga lo que ha buscado; el resto del catálogo se descarga mediante la carga inicial en segundo plano (consulte [Sincronización de productos](/1.x/products/sync)). Así, la búsqueda sigue siendo rápida sin descargar datos no relacionados.

## Filtrado de productos {#product-filtering}

### Barra de filtros {#filter-bar}

Debajo del campo de búsqueda encontrará botones de filtro interactivos y menús desplegables que permiten acotar los productos según criterios específicos.

### Filtros disponibles {#available-filters}

#### Estado de stock {#stock-status}
Filtre productos según su estado de inventario:
- **En stock** - Productos con inventario disponible
- **Agotado** - Productos sin existencias
- **Bajo pedido** - Productos disponibles para pedidos pendientes

#### Productos destacados {#featured-products}
Active esta opción para mostrar solo los productos marcados como «Destacados» en su tienda WooCommerce.

#### Productos en oferta {#on-sale-products}
Filtre para mostrar solo los productos que están actualmente en oferta o tienen descuentos activos.

#### Categoría {#category}
Utilice el menú desplegable de categorías para filtrar productos por sus categorías asignadas. Esto permite encontrar rápidamente productos de departamentos o líneas de productos específicos.

#### Etiqueta {#tag}
Filtre por etiquetas de producto para encontrar artículos con atributos o características específicos que haya definido en su tienda WooCommerce.

### Uso de filtros {#using-filters}

- **Activar filtros** - Haga clic en cualquier botón de filtro para activarlo (los filtros activos aparecen resaltados)
- **Filtros múltiples** - Puede combinar varios filtros para acotar aún más la búsqueda
- **Borrar filtros** - Haga clic de nuevo en un filtro activo para desactivarlo
- **Búsqueda + Filtro** - Utilice los filtros junto con el campo de búsqueda para localizar productos con precisión

## Configuración de código de barras {#barcode-configuration}

### Campos de búsqueda {#search-fields}

La función de búsqueda incluye automáticamente el campo de código de barras configurado. El campo de código de barras utilizado en las búsquedas depende de la configuración de los ajustes del POS.

## Preguntas frecuentes {#faq}

<Accordion>
  <AccordionItem question="¿Para qué sirve el campo _global_unique_id de códigos de barras?">

El campo `_global_unique_id` es el campo GTIN que WooCommerce añadió para mejorar la estandarización de los códigos de barras entre tiendas. Es el campo de código de barras **predeterminado** en WCPOS.

**Puntos clave:**

- **Estándar moderno**: Este campo se diseñó específicamente para la identificación global de códigos de barras (GTIN / UPC / EAN)
- **Predeterminado**: El POS utiliza `_global_unique_id` como campo de código de barras sin necesidad de configuración adicional; puede cambiarlo por `_sku` o cualquier campo de metadatos personalizado en los ajustes
- **Flexibilidad**: Puede configurar cualquier campo de metadatos del producto como campo de código de barras si utiliza plugins de códigos de barras de terceros
- **Un campo por producto**: El POS busca en un único campo de código de barras configurado, y WooCommerce almacena un valor de código de barras por producto (o por variación). Si necesita varios códigos en un producto, almacénelos en un campo personalizado y seleccione ese campo en el ajuste de código de barras
- **Se reconstruye al cambiar**: Al cambiar el campo de código de barras, se reconstruye el índice de códigos de barras del catálogo local, de modo que los escaneos se comparan inmediatamente con el nuevo campo seleccionado

Para configurar qué campo utiliza el POS para los códigos de barras, acceda a los ajustes del POS en el área de administración de WordPress.

  </AccordionItem>

  <AccordionItem question="¿Por qué no aparecen todos los productos al buscar?">

Puede que la carga inicial del catálogo en segundo plano aún no haya terminado. Si no ve un producto:

1. **Búsquelo** - Esto obtiene los productos coincidentes directamente del servidor si aún no están almacenados localmente
2. **Compruebe el progreso de la descarga** - **Estado de la tienda → Base de datos** muestra qué parte del catálogo está en este dispositivo
3. **Compruebe su visibilidad** - Los productos agotados se ocultan de forma predeterminada y solo se admiten los tipos de producto estándar de WooCommerce

Encontrará más información en nuestra guía de [Sincronización de productos](/1.x/products/sync).

  </AccordionItem>

  <AccordionItem question="¿Es posible buscar nombres parciales de productos o SKU?">

¡Sí! La búsqueda tokenizada encuentra subcadenas, lo que significa que:

- Buscar «blue» encontrará productos con «blueberry», «blue shirt», etc.
- Buscar «berry» también encontrará «blueberry»: el término puede aparecer en cualquier parte de la palabra
- Buscar «ABC» encontrará SKU como «ABC123», «ABC-XYZ», etc.
- No necesita escribir palabras o códigos completos (pero no se buscan coincidencias para términos de menos de 3 caracteres)

La búsqueda está diseñada para encontrar productos rápidamente escribiendo lo mínimo posible.

  </AccordionItem>
</Accordion>
