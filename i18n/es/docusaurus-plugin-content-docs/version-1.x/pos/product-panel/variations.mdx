Los productos variables de WooCommerce tienen varias opciones, como distintos tamaños, colores o materiales. WCPOS ofrece varias formas de trabajar con ellos de manera eficiente.

## Cómo identificar productos variables {#identifying-variable-products}

En el Panel de Productos, los productos variables se distinguen por lo siguiente:

- **Botón de flecha** (<Icon name="circle-arrow-right" color="green" />) en lugar del botón con el signo más (<Icon name="circle-plus" color="green" />) que se usa para los productos simples
- **Opciones de atributo** que aparecen debajo del nombre del producto (p. ej., "Color: azul, verde, rojo")
- **Enlace de "Expandir"** para ver todas las variaciones en línea

## Añadir productos variables al carrito {#adding-variable-products-to-cart}

### Método 1: menú emergente rápido {#method-1-quick-popover}

Haga clic en el <Icon name="circle-arrow-right" color="green" /> botón de flecha verde de un producto variable para abrir un menú emergente con listas desplegables para cada atributo:

1. Haga clic en el <Icon name="circle-arrow-right" color="green" /> botón
2. Seleccione una opción en cada lista desplegable (p. ej., Tamaño: grande, Color: azul)
3. La variación correspondiente se añade al carrito

Cuando la selección se reduce a una única variación, el menú emergente muestra su estado de existencias junto al botón para añadir al carrito: **"8 en existencias"** si se controlan las existencias, **"Disponible para pedido pendiente"** si se permiten pedidos pendientes o **"Agotado"** (con el botón desactivado). Las variaciones que no controlan sus propias existencias no muestran ninguna cantidad.

Cuando el ajuste de visualización **Mostrar productos agotados** oculta los productos agotados, las opciones cuyas variaciones están todas agotadas aparecen atenuadas y no se pueden seleccionar.

Este es el método más rápido cuando sabe exactamente qué variación necesita.

{/* Screenshot: variation-popover.png */}

### Método 2: expandir en línea {#method-2-expand-inline}

Haga clic en el enlace **"Expandir"** de un producto variable para mostrar todas sus variaciones directamente en la lista de productos:

1. Haga clic en **Expandir** debajo del nombre del producto
2. Todas las variaciones aparecen en filas separadas debajo del producto principal
3. Haga clic en el <Icon name="circle-plus" color="green" /> botón de cualquier variación para añadirla al carrito
4. Haga clic en **Contraer** para volver a ocultar las variaciones

Cuando el ajuste de visualización **Mostrar productos agotados** oculta los productos agotados, las variaciones agotadas no aparecen en estas filas (las variaciones disponibles para pedido pendiente sí aparecen, ya que se pueden vender).

Este método resulta útil cuando desea ver todas las opciones disponibles, sus existencias individuales y sus precios.

{/* Screenshot: variations-expanded.png */}

### Método 3: escaneo de códigos de barras {#method-3-barcode-scanning}

Cada variación de producto puede tener su propio código de barras. Al escanear el código de barras de una variación:

- Si coincide exactamente con una variación, esta se añade directamente al carrito
- Si el código de barras coincide con varias variaciones, la barra de búsqueda muestra los resultados coincidentes
- Si la variación encontrada está agotada y el ajuste de visualización **Mostrar productos agotados** oculta los productos agotados, se rechaza el escaneo y se muestra el mensaje *"agotado"* en lugar de añadirla al carrito

La búsqueda de variaciones también consulta el **servidor**: si la variación escaneada aún no está en el dispositivo, WCPOS la busca en línea y la descarga, igual que con los productos simples.

Consulta [Escaneo de Códigos de Barras](/pos/product-panel/barcode-scanning) para más detalles.

## Información de Variación {#variation-information}

Cada variación puede mostrar:

- **Atributos de variación** - Las opciones específicas para esta variación (por ejemplo, "Tamaño: Grande, Color: Azul")
- **SKU** - Identificador único para la variación (puede diferir del producto padre)
- **Cantidad en stock** - Nivel de inventario individual para la variación
- **Precio** - Las variaciones pueden tener precios diferentes al del producto padre o entre sí

## Variaciones en el Carrito {#variations-in-the-cart}

Cuando una variación se agrega al carrito, muestra:

- **Nombre del producto** del producto padre
- **Atributos de variación** debajo del nombre
- **Precio** para esa variación específica

Puedes editar el artículo en la línea como cualquier otro producto en el carrito.

## Consejos para una Selección Eficiente de Variaciones {#tips-for-efficient-variation-selection}

### Usa Escaneo de Código de Barras {#use-barcode-scanning}

Si tus variaciones tienen códigos de barras individuales (recomendado), escanear es la forma más rápida de agregarlas al carrito.

### Configura Opciones de Visualización {#configure-display-options}

En el Panel de Productos [Configuración de Visualización](/pos/product-panel#display-settings), habilita la opción **Atributos** para mostrar los atributos de variación directamente en la lista de productos sin necesidad de expandir.

### Navegación por Teclado {#keyboard-navigation}

Cuando la ventana emergente de variación está abierta, puedes usar las teclas de dirección del teclado para navegar entre opciones y Enter para seleccionar.

## F.A.Q. {#faq}

<Accordion>
  <AccordionItem question="¿Por qué no puedo ver una variación específica?">

Verifica que la variación:
- Esté publicada y no en estado de borrador
- Esté configurada como "En Stock" o tenga una cantidad en stock > 0 (si la gestión de inventario está habilitada)
- Tenga todos los atributos requeridos definidos

También asegúrate de no haber filtrado el producto con el filtro "En Stock" si la variación está fuera de stock.

  </AccordionItem>

  <AccordionItem question="¿Cómo agrego códigos de barras a variaciones individuales?">

En WooCommerce, edita el producto variable y expande cada variación. Puedes agregar un código de barras único al campo de código de barras de cada variación (típicamente `_sku` o `_global_unique_id` dependiendo de tu configuración).

  </AccordionItem>
</Accordion>
