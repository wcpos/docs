## Nota de Pedido {#order-note}

<div class="image-container">

    alt="Nota de Pedido en el POS"

    style={{maxHeight: 500}}

- Abre un diálogo para agregar al pedido una nota para el cliente.
- Las notas para el cliente son visibles para este y aparecen de forma predeterminada en el recibo, en el área Mi Cuenta del cliente y en `WP Admin > WooCommerce > Orders > Order`, debajo de la dirección de envío.

:::note
Las notas de pedido son visibles para los clientes.
:::

- Abre un modal para gestionar metadatos adicionales del pedido.
- Las funciones incluyen:
  - Cambiar la moneda del pedido.
  - Agregar un ID de transacción (por ejemplo, de un terminal de pago externo).
  - Agregar metadatos personalizados al pedido.

:::note
Con el tiempo se agregarán funciones adicionales a este modal, incluida la integración con otros complementos de WooCommerce.
:::

### ¿Qué son los metadatos en WooCommerce? {#what-is-meta-data-in-woocommerce}

Los metadatos proporcionan información adicional sobre los pedidos y son accesibles mediante la API REST de WooCommerce. Los desarrolladores y complementos utilizan estos datos para ampliar la funcionalidad, por ejemplo, mediante la integración de servicios de terceros.

### Vista JSON {#json-view}

- Permite ver la representación JSON sin procesar del pedido, útil para tareas de depuración o integración.

## Guardar en el Servidor {#save-to-server}

- Permite guardar los carritos abiertos en el servidor para que queden almacenados de forma segura y accesibles para su uso posterior.
- Crea un pedido de WooCommerce con el estado `pos-open`.

### ¿Por qué guardar? {#why-save}

Cuando se crea un nuevo pedido en el POS, solo existe localmente. 
Guardar el pedido garantiza que se conserve, incluso si se vacía la base de datos local.

Consulte [Pedidos Abiertos](/1.x/pos/cart/open-orders) para obtener más información sobre la gestión de pedidos guardados.

## Anular {#void}

- Dos situaciones:
  - Pedidos no guardados:
    - Si el pedido no se ha guardado en el servidor, se eliminará permanentemente de la base de datos local.
  - Pedidos guardados:
    - Si el pedido está guardado en el servidor, se moverá a la Papelera de WooCommerce y se eliminará de la base de datos local.
- Para recuperar un pedido anulado:
  - Vaya a `WP Admin > WooCommerce > Orders > Trash`.

## Pagar {#checkout}

- Guarda el pedido en el servidor e inicia el proceso de pago.
- Abre la [pantalla de pago](/1.x/pos/checkout) para completar el pago.
