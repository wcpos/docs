WCPOS tiene tres tipos de configuración, organizados según dónde se configuran.

## Dónde encontrar la configuración {#where-to-find-settings}

### 1. Configuración del administrador de WordPress {#1-wordpress-admin-settings}

Ajustes del backend que se configuran en el panel de WordPress:

**Ubicación:** `WP Admin > POS > Ajustes`

Controlan lo siguiente:
- Cliente predeterminado del carrito para todos los cajeros
- Configuración del campo de código de barras del producto
- Configuración de los correos electrónicos de pedidos
- Permisos de los roles de usuario (quién puede acceder al POS)
- Disponibilidad de las pasarelas de pago

Consulte [Configuración del administrador de WordPress](/1.x/settings/wp-admin) para obtener más información.

### 2. Configuración de la tienda POS {#2-pos-store-settings}

Ajustes que afectan a toda la aplicación y se configuran dentro de la aplicación POS:

**Ubicación:** Menú de usuario (esquina superior derecha) → Ajustes, o `Ctrl + Shift + S`

Controlan lo siguiente:
- Opciones de cálculo de impuestos
- Configuración del escáner de códigos de barras
- Atajos de teclado
- Tema/apariencia

Consulte [Configuración de la tienda](/1.x/settings/store) para obtener más información.

### 3. Configuración de visualización (por pantalla) {#3-display-settings-per-screen}

Cada pantalla del POS tiene su propia configuración de visualización para personalizar la tabla de datos:

**Ubicación:** Haga clic en el icono de deslizadores (<Icon name="sliders" />) en cualquier pantalla

Controlan lo siguiente:
- Qué columnas son visibles
- Opciones de visualización de las columnas
- Funciones específicas de cada pantalla

La configuración de visualización se explica en la documentación de cada pantalla:
- [Panel de productos POS](/1.x/pos/product-panel#display-settings)
- [Panel del carrito](/1.x/pos/cart#display-settings)
- [Pantalla de productos](/1.x/products#display-settings)
- [Pantalla de pedidos](/1.x/orders#display-settings)
- [Pantalla de clientes](/1.x/customers#display-settings)
- [Pantalla de informes](/1.x/reports#display-settings)
