# Pasarela PayArc Terminal {#payarc-terminal-gateway}

La pasarela PayArc Terminal permite aceptar pagos presenciales en un terminal PayArc PAX desde WCPOS mediante PayArc Connect. El pago se inicia en WooCommerce y se completa en el terminal; el pedido solo se marca como pagado después de que PayArc lo confirme.

## Características {#features}

<FeatureGrid>
  <FeatureCard icon="credit-card" title="Integración con terminales PAX">

  </FeatureCard>
  <FeatureCard icon="shield" title="Finalización verificada">
    El importe y la moneda deben coincidir con los del pedido para completar el pago; la marca de la tarjeta, el modo de entrada y los últimos 4 dígitos se guardan en el pedido

  <FeatureCard icon="file-lines" title="Motivos de rechazo claros">
    Los motivos del rechazo se muestran al cajero y se añaden como nota del pedido
  </FeatureCard>
  <FeatureCard icon="receipt" title="Recibos del terminal">
    Imprima en el terminal un recibo para el comercio, uno para el cliente o ambos
  </FeatureCard>
  <FeatureCard icon="bolt" title="Diagnóstico integrado">
    Compruebe la conexión con el botón **Validate Settings** y una tabla de diagnóstico con identificadores enmascarados
  </FeatureCard>

## Cómo funciona {#how-it-works}

WordPress se comunica con **PayArc Connect**, y PayArc se conecta al terminal PAX. WCPOS solo se comunica con su sitio. Cada pago cobra el **importe total del pedido**.

La página de pago comprueba el resultado cada **1.5 segundos** y se detiene después de **5 minutos**. Las notificaciones de PayArc a **Webhook URL** aceleran el resultado; los pagos también se completan mediante consultas periódicas si no hay notificaciones. Mantenga abierta la página de pago mientras el cliente paga en el terminal.

## Configuración {#setup}

<Steps>
  <StepCard number="1" title="Instale PayArc Terminal for WooCommerce">

Instálelo desde `WP Admin > POS > Ajustes > Extensiones` o descargue el archivo **payarc-terminal-for-woocommerce.zip** desde la [página de versiones de GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases) y súbalo mediante `Plugins > Añadir nuevo > Subir plugin`. Active el plugin.

  </StepCard>
  <StepCard number="2" title="Introduzca sus credenciales de PayArc">

1. Vaya a `WP Admin > WooCommerce > Ajustes > Pagos` y abra **PayArc Terminal**
2. Elija **Mode**: `Live` es la opción predeterminada. Use `Test` solo con las credenciales del panel de pruebas de PayArc y la aplicación PayArc Connect Test. No mezcle entornos
3. Introduzca **PayArc login email**, el correo electrónico que usa para iniciar sesión en el panel de comerciante de PayArc
4. Introduzca **PayArc MID** del perfil de comerciante de PayArc, no el ID del terminal
5. Introduzca **PayArc ClientSecret** de la sección API del panel y **PayArc SecretKey / API bearer token** del panel de PayArc
6. Deje **Callback bearer token** en blanco, salvo que el equipo de soporte de PayArc le haya proporcionado uno; es opcional

  </StepCard>
  <StepCard number="3" title="Conectar">

Haga clic en **Connect using these credentials**. Si la conexión se realiza correctamente, la pantalla le pedirá que introduzca o confirme el número de serie del terminal y guarde los ajustes. Si indica que las credenciales parecen corresponder al otro entorno, cambie **Mode** y vuelva a conectar.

:::note
Después de cambiar el modo o las credenciales, haga clic de nuevo en **Connect using these credentials** y guarde los cambios. Los pagos se bloquean hasta que el modo y las credenciales coincidan con la conexión guardada. Si actualiza desde una versión anterior a 0.1.14, pulse Connect una vez.
:::

  </StepCard>
  <StepCard number="4" title="Añada su terminal">

1. Introduzca el **Terminal serial number** del PAX, que aparece en la etiqueta **S/N** de la parte posterior del dispositivo, tal como PayArc lo haya configurado para su cuenta
2. Elija **Tender type** y **Print receipt**
3. Compruebe que **Webhook URL** usa HTTPS. Proporciónesela a PayArc solo si se la solicitan
4. Haga clic en **Save changes**

El modo Live requiere que el sitio use HTTPS.

  </StepCard>
  <StepCard number="5" title="Active la pasarela en WCPOS" isLast>

1. Vaya a `WP Admin > POS > Ajustes > Finalizar compra`
2. Busque la pasarela **PayArc Terminal** y actívela para WCPOS
3. Guarde los ajustes

:::note
La casilla **Enable/Disable** en la pantalla de ajustes de WooCommerce solo controla el pago de la *tienda en línea*. WCPOS utiliza esta pasarela una vez configurada, esté marcada o no esa casilla.

La mayoría de las tiendas dejan esta casilla sin marcar.
:::

  </StepCard>
</Steps>

## Referencia de ajustes {#settings}

| Ajuste | Función |
|---|---|
| **Enable/Disable** | Activa PayArc Terminal para el pago de la tienda en línea. Está desactivado de forma predeterminada; la activación en WCPOS se controla en `POS > Ajustes > Finalizar compra` |
| **Title** | La etiqueta del método de pago; el valor predeterminado es `PayArc Terminal` |
| **Description** | La descripción del método de pago; el valor predeterminado es `Pay in person at a PayArc PAX terminal.` |
| **Mode** | `Live` (predeterminado) o `Test`. El modo Test requiere credenciales del panel de pruebas de PayArc y la aplicación PayArc Connect Test |
| **PayArc login email** | Correo electrónico para iniciar sesión en el panel de comerciante de PayArc; es obligatorio para conectar |
| **PayArc MID** | El MID del comerciante del perfil de comerciante de PayArc, no el ID del terminal |
| **PayArc ClientSecret** | El secreto de la sección API del panel; solo se almacena en su servidor |
| **PayArc SecretKey / API bearer token** | El token del panel de PayArc, que se usa para iniciar sesión y obtener el registro de terminales |
| **Callback bearer token** | Opcional. Rellénelo solo si el equipo de soporte de PayArc le ha proporcionado uno |
| **PayArc connection** | Botones **Connect using these credentials**, **Refresh Terminals** y **Disconnect** |
| **Terminal serial number** | El número S/N del PAX asignado a su cuenta; es obligatorio para los pagos. Se completa desde el registro si se encuentra; introdúzcalo o confírmelo antes de guardar |
| **Tender type** | `CREDIT` (predeterminado) o `DEBIT` |
| **Print receipt** | `0` — ninguno (predeterminado), `1` — comercio, `2` — cliente, `3` — ambos |
| **Webhook URL** | Dirección de notificación de solo lectura. Compruebe que usa HTTPS; proporciónesela a PayArc solo si se la solicitan |
| **PayArc diagnostics** | Información de conexión y un botón **Validate Settings**; los secretos nunca se muestran |

Los campos de secretos guardados solo muestran los últimos 4 caracteres. Deje vacío un campo de secreto para conservar el valor guardado.

La tabla **PayArc diagnostics** muestra el modo, los puntos de conexión, el MID / ID de inquilino / número de serie enmascarados, si está configurado el token de acceso de Connect, la URL del webhook, la última notificación y el último error de PayArc. Use **Validate Settings** para comprobar los ajustes.

## Uso {#usage}

### Procesamiento de pagos {#processing-payments}

1. **Select Gateway**: Elija **PayArc Terminal** como método de pago en WCPOS
2. **Start Payment**: Haga clic en **Start Payment** para enviar el importe total del pedido al terminal
3. **Customer Payment**: Mantenga la página abierta mientras el cliente completa el pago en el terminal PAX. Siga los mensajes de estado: `Starting terminal payment...` → `Payment sent to terminal.` → `Waiting for the terminal result...` → `Payment approved. Completing the order...`
4. **Automatic Completion**: Cuando PayArc confirma el pago, el pedido se completa automáticamente

### Controles de pago {#payment-controls}

- **Cancel Payment** aparece cuando se inicia un pago. Si PayArc aún no ha devuelto un ID de seguimiento, espere un momento antes de cancelar
- Después de un rechazo, una cancelación o un tiempo de espera agotado, puede volver a intentarlo. Compruebe el terminal antes de reintentar un pago cuyo tiempo de espera se haya agotado
- El registro de actividad de pagos está contraído de forma predeterminada. Use **Show activity** para verlo y **Clear** para borrar la actividad mostrada

### Recibos {#receipts}

El ajuste **Print receipt** controla la impresión en el terminal: ninguno, comercio, cliente o ambos.

## Reembolsos {#refunds}

El plugin no admite reembolsos. Realice el reembolso a través de PayArc y, después, regístrelo manualmente en WooCommerce.

## Registros {#logs}

Busque los registros en `WooCommerce > Status > Registros`, en el origen `payarc-terminal-for-woocommerce`. Incluyen intentos de conexión, ventas iniciadas o fallidas, cancelaciones y notificaciones aceptadas o rechazadas. Los identificadores están enmascarados y los secretos, ocultos.

No hay ninguna opción para descargar un paquete de soporte. Cuando solicite ayuda, envíe el número del pedido y las líneas de registro pertinentes. No comparta MID completos, ID de terminal, tokens ni datos de tarjetas.

## Alcance y limitaciones {#scope-and-limitations}

- El plugin no admite reembolsos
- Los pagos cobran el **importe total del pedido**; no se admiten pagos parciales ni divididos
- No se admiten propinas
- Un terminal por tienda: un único ajuste de número de serie, sin selector de cajero
- Las monedas están limitadas a **USD, CAD, GBP, EUR y JPY**
- Los pagos se bloquean hasta que el modo y las credenciales coincidan con la conexión guardada

## Solución de problemas {#troubleshooting}

### Problemas comunes {#common-issues}

<Accordion>
  <AccordionItem question="Las credenciales parecen corresponder al otro entorno">

  - El modo seleccionado y las credenciales pertenecen a entornos distintos
  - Cambie **Mode** para que coincida con las credenciales o sustituya las credenciales por las del modo seleccionado
  - Vuelva a hacer clic en **Connect using these credentials** y guarde los cambios

  </AccordionItem>
  <AccordionItem question="No se puede conectar con PayArc">

  - PayArc ha rechazado las credenciales de inicio de sesión. Compruebe las credenciales introducidas y vuelva a intentarlo
  - Consulte `WooCommerce > Status > Registros`, en el origen `payarc-terminal-for-woocommerce`, para obtener más información

  </AccordionItem>
  <AccordionItem question="No se puede procesar la solicitud de pago. (HTTP 500)">

  - Este mensaje para el cajero es genérico. Busque **PayArc payment action failed** en el registro de WooCommerce para encontrar la causa real
  - Después de cambiar el modo o las credenciales, vuelva a hacer clic en **Connect using these credentials** y guarde los cambios
  - Compruebe que se haya rellenado **Terminal serial number**
  - Si el registro indica que PayArc ha rechazado tanto el token de acceso de Connect como SecretKey, solicite al equipo de soporte de PayArc que confirme que **PayArc Connect V3** está habilitado para su cuenta de comerciante
  - Compruebe que la moneda de la tienda sea **USD, CAD, GBP, EUR o JPY**

  </AccordionItem>
  <AccordionItem question="Acceso denegado. (HTTP 403) al iniciar el pago">

  - Actualice a **0.1.12 o posterior**, que corrige este error en las sesiones de WCPOS

  </AccordionItem>
  <AccordionItem question="El registro de terminales está vacío">

  - Es normal que el registro esté vacío o que se muestre un terminal sin identificador de POS
  - Los datos del registro son solo informativos. Los pagos usan **Terminal serial number**

  </AccordionItem>
  <AccordionItem question="Un pago tarda demasiado">

  - Compruebe la pantalla del terminal y mantenga abierta la página de pago
  - Compruebe las notas del pedido y el panel de PayArc antes de volver a intentarlo
  - La página comprueba el resultado cada **1.5 segundos** y se detiene después de **5 minutos**

  </AccordionItem>
</Accordion>

### Obtener ayuda {#getting-help}

- Incluya el **número del pedido** y las **líneas de registro** pertinentes en su solicitud de soporte
- Visite el [repositorio de GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce) para informar de problemas
- Póngase en contacto con el equipo de soporte de PayArc para obtener ayuda con la cuenta, PayArc Connect y la configuración del terminal
