Cada tipo de dispositivo tiene su propia página de configuración aquí o enlaza a la página donde se encuentra su configuración.

El centro de hardware dirige a la configuración de cada dispositivo, pero los pasos concretos se encuentran en un único lugar. :::

## Compatibilidad de lectores de tarjetas {#card-reader-compatibility}

Los lectores de tarjetas compatibles dependen de **cómo se ejecute WCPOS** y del tipo de conexión del lector:

- **La aplicación web** solo puede controlar lectores que ofrecen un **SDK web (de navegador)**; normalmente, terminales de mostrador conectados a Internet. Los lectores **solo Bluetooth** (por ejemplo, Stripe M2 / WisePad 3, SumUp Air) y Tap-to-Pay en teléfonos **no son compatibles** con la aplicación web.
- La compatibilidad es **por pasarela**, no universal; compruebe el lector con la pasarela que tenga previsto utilizar ([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [Lector de PayPal](/payment/gateways/paypal-reader)) antes de comprarlo.

Cada página de pasarela enumera los lectores exactos que admite.
