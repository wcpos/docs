:::info Función Pro
La pantalla de Productos requiere [WCPOS Pro](/1.x/getting-started/pro-license). Los usuarios de la versión gratuita pueden ver y agregar productos al carrito desde el [Panel de Producto POS](/1.x/pos/product-panel), pero no pueden editar el inventario ni los precios.
:::

La pantalla de Productos es una interfaz dedicada a la gestión del inventario. A diferencia del [Panel de Producto POS](/1.x/pos/product-panel) (que sirve para vender), esta pantalla está diseñada para gestionar su catálogo de productos.

## Pantalla de Productos frente al Panel de Producto POS {#products-screen-vs-pos-product-panel}

| Característica | Panel de Producto POS | Pantalla de Productos |
|---------|-------------------|-----------------|
| **Propósito** | Agregar productos al carrito | Gestionar inventario |
| **Stock** | Solo consulta | Edición directa |
| **Precios** | Solo consulta | Edición directa |
| **Acciones** | Agregar al carrito | Editar, Sincronizar, Eliminar |
| **Disponible en** | Gratis + Pro | Solo Pro |

## Descripción general de la interfaz {#interface-overview}

### Búsqueda y filtros {#search--filters}

En la parte superior de la pantalla:

- **Barra de búsqueda** - Busque productos por nombre, SKU o código de barras
- **Botones de filtro** - Estado del Stock, Destacados, En Rebaja, Categoría, Etiqueta, Marca
- **Configuración de visualización** (<Icon name="sliders" />) - Configure las columnas visibles

### Lista de productos {#product-list}

El área principal muestra sus productos en una tabla desplazable:

- **Imagen** - Miniatura del producto
- **Nombre del producto** - Con SKU, código de barras y atributos opcionales
- **Stock** - Cantidad de stock editable con el interruptor «Gestionar»
- **Estado del Stock** - En Stock (verde), Sin Stock (rojo), Pedido Pendiente
- **Categorías** - Etiquetas de categoría del producto
- **Precios** - Precio actual, precio regular y precio en rebaja (todos editables)
- **Acciones** - Menú de tres puntos con Editar, Sincronizar y Eliminar

:::note La clasificación y el filtrado abarcan toda la tienda
La clasificación y el filtrado se realizan en el **servidor**, por lo que se aplican a todo el catálogo, no solo a los productos que ya están en el dispositivo. Puede ordenar por nombre, SKU, stock, precio o fecha; la lista seguirá cargando más filas al desplazarse, hasta recorrer todo el catálogo. En cambio, la **búsqueda** de productos se realiza en el dispositivo una vez que el catálogo está disponible localmente, por lo que los resultados aparecen al instante y sin solicitudes al servidor.
:::

### Productos variables {#variable-products}

Los productos variables muestran:
- Opciones de atributos (Color, Tamaño, etc.)
- Enlace «Expandir» para ver todas las variaciones
- Filas individuales de variaciones con stock y precios independientes

### Pie de página {#footer}

- **Estado fiscal** - Base actual para el cálculo de impuestos
- **Conteo de productos** - «Mostrando X de Y» con botón de sincronización (<Icon name="arrow-rotate-right" />). **Mantenga pulsado** el botón de sincronización para acceder a la opción Borrar y volver a descargar (a partir de la v1.10.0, esto también borra la búsqueda y los filtros activos de la pantalla, por lo que la lista vuelve a mostrarse sin filtrar)

## Características principales {#key-features}

### Edición directa del stock {#inline-stock-editing}

Haga clic directamente en la cantidad de stock para editarla:

1. Haga clic en la cifra de stock
2. Introduzca la nueva cantidad
3. Pulse Intro para guardar

Los cambios se sincronizan automáticamente con WooCommerce.

### Interruptor de gestión de stock {#manage-stock-toggle}

El interruptor «Gestionar» controla si WooCommerce lleva el control del inventario de este producto:

- **Activado** - Se lleva el control de los niveles de stock y se reducen con las ventas
- **Desactivado** - El producto siempre está disponible (stock infinito)

### Edición directa de precios {#inline-price-editing}

Haga clic en cualquier campo de precio para editarlo:

- **Precio** - Precio de venta actual
- **Precio Regular** - Precio sin descuento
- **Precio de Rebaja** - Precio con descuento (cuando está en rebaja)

### Costo de los Bienes Vendidos {#cost-of-goods-sold}

La función Costo de los Bienes Vendidos (COGS) de WooCommerce permite registrar el precio de costo de cada producto. WCPOS muestra estos datos en la pantalla de Productos.

Para ver los precios de costo, active la columna **Costo de los Bienes Vendidos** en [Configuración de Visualización](#display-settings) (<Icon name="sliders" />). La columna muestra el precio de costo junto a tus precios de venta, facilitando la revisión de los márgenes de un vistazo.

:::info Función Pro
Los usuarios de [WCPOS Pro](/1.x/getting-started/pro-license) pueden **editar** el precio de costo directamente desde la pantalla de Productos: haga clic en el valor del costo para actualizarlo ahí mismo, igual que los campos de stock y precio.
:::

:::note Requisito de WooCommerce
El Costo de los Bienes Vendidos debe estar habilitado en tu tienda WooCommerce: ve a **WooCommerce > Settings > Advanced > Features** y habilita la opción Cost of Goods Sold. Esto requiere una versión reciente de WooCommerce con la función Cost of Goods Sold habilitada. Consulta la documentación de WooCommerce para más detalles de configuración.
:::

### Acciones del Producto {#product-actions}

Haz clic en el menú de tres puntos (⋮) para cada producto:

- **Editar** - Abrir el modal de edición del producto
- **Sincronizar** - Sincronizar este producto con WooCommerce
- **Eliminar** - Eliminar el producto de la base de datos local

:::note
Al eliminar un producto del POS, solo se elimina **localmente**: el producto permanece en WooCommerce y vuelve a aparecer en la siguiente sincronización. Si se elimina un producto **en WooCommerce**, la sincronización también lo elimina del POS, para que el dispositivo siga al día con la tienda.
:::

### Columnas Disponibles {#available-columns}

| Columna | Descripción | Opciones de Visualización |
|--------|-------------|-----------------|
| **Imagen** | Miniatura del producto | - |
| **ID** | ID de producto de WooCommerce | - |
| **Producto** | Nombre del producto | SKU, Código de Barras, Atributos |
| **Tipo** | Simple, variable, agrupado, etc. | - |
| **SKU** | Unidad de Mantenimiento de Stock | - |
| **Código de Barras** | Código de barras del producto | - |
| **Stock** | Cantidad actual (editable) | - |
| **Estado del Stock** | En Stock / Sin Stock / Pedido Pendiente | - |
| **Categorías** | Categorías de producto | - |
| **Etiquetas** | Etiquetas de producto | - |
| **Marcas** | Información de marca (si el complemento está activo) | - |
| **Costo de los Bienes Vendidos** | Precio de costo del producto (editable con Pro) | - |
| **Precio** | Precio de venta actual (editable) | Información fiscal |
| **Precio Regular** | Precio sin descuento (editable) | Información fiscal |
| **Precio de Rebaja** | Precio con descuento (editable) | Información fiscal |
| **Fecha de Creación** | Fecha en que se creó el producto | - |
| **Fecha de Modificación** | Fecha de la última modificación | - |
| **Acciones** | Botones Editar, Sincronizar, Eliminar | - |

### Restaurar Configuraciones Predeterminadas {#restore-default-settings}

Haz clic para restablecer todas las configuraciones de visualización a sus valores predeterminados originales.

## Filtrando Productos {#filtering-products}

Utiliza los botones de filtro para reducir tu vista:

- **Estado del Stock** - En Stock, Sin Stock, Pedido Pendiente
- **Destacados** - Productos marcados como destacados
- **En Rebaja** - Productos actualmente en rebaja
- **Categoría** - Filtrar por categoría de producto
- **Etiqueta** - Filtrar por etiqueta de producto
- **Marca** - Filtrar por marca (si se está utilizando el complemento de marca)

## Ordenar {#sorting}

Haz clic en cualquier encabezado de columna para ordenar por esa columna. Haz clic nuevamente para invertir el orden de clasificación.
