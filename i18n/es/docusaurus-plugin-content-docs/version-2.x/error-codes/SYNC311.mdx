## Qué significa {#what-this-means}

Los datos de este dispositivo se guardaron con otra versión de WCPOS y todavía no se pueden abrir.

Actualice WCPOS a la última versión y vuelva a abrirlo. Si sigue sin abrirse, pulse **Copiar información de depuración** y contacte con soporte. Esto suele ocurrir después de actualizar la aplicación o volver a una versión anterior en este dispositivo.

:::warning No borre los datos de este dispositivo
Este dispositivo puede contener ventas que aún no han llegado a su tienda, por ejemplo, ventas realizadas sin conexión. Mientras los datos no puedan abrirse, no se pueden enviar, por lo que borrar la base de datos local, cerrar sesión o reinstalar los eliminaría permanentemente. Contacte con soporte antes de borrar nada.
:::

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener ventas que aún no han llegado a su tienda. Los datos de la propia tienda están a salvo y no se ven afectados.

## Solución de problemas {#troubleshoot}

1. Actualice WCPOS a la última versión en este dispositivo y vuelva a abrirlo:
   - **Web:** recargue la pestaña del navegador. Si vuelve a aparecer la versión anterior, mantenga pulsada la tecla **Mayús** al recargar. El plugin WCPOS de la tienda determina qué versión web se carga, por lo que, si recargar no ayuda, pida al administrador del sitio que actualice el plugin WCPOS.
   - **Escritorio:** instale la actualización pendiente y vuelva a abrir la aplicación. Si no se ofrece ninguna actualización, descargue la última versión desde la página de [Instalación](/getting-started/installation).
   - **iPhone, iPad o Android:** actualice WCPOS a través del canal desde el que lo instaló: TestFlight en iOS o el programa de pruebas de Play en Android; ambos están enlazados desde la página de [Instalación](/getting-started/installation).
2. Si sigue sin abrirse, pulse **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte. Indique si este dispositivo puede contener ventas que aún no han llegado a su tienda.
3. No borre los datos locales, cierre sesión ni reinstale mientras espera: soporte le indicará si primero es necesario recuperar algún dato de este dispositivo.
