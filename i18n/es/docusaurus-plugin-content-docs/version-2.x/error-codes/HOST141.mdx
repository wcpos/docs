## Qué significa {#what-this-means}

El filtro de seguridad del proveedor de alojamiento está bloqueando las búsquedas de productos.

Una regla del cortafuegos de este servidor rechaza las solicitudes REST cuya cadena de consulta contiene caracteres no ASCII o palabras que parecen SQL. Los nombres de productos con acentos y las búsquedas que contienen palabras como 'select' o 'union' fallarán con un 403, aunque sean búsquedas normales del catálogo. El resto de las funciones de la caja funciona; las búsquedas no serán fiables hasta que se flexibilice la regla.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados.

## Solución de problemas {#troubleshoot}

1. Pida al proveedor de alojamiento que incluya los parámetros de búsqueda REST de la propia tienda (rutas /wcpos/ y /wc/) en la lista de permitidos de las reglas del cortafuegos para cadenas de consulta.
2. En los cortafuegos basados en OWASP CRS, las reglas de inyección SQL aplicadas a los argumentos 's' y 'search' suelen ser las responsables: excluya esos argumentos para las rutas de la API REST.
3. Los plugins de seguridad con una opción para 'filtrar cadenas de consulta sospechosas' necesitan una excepción para la API REST, no una desactivación global.
