## Qué significa {#what-this-means}

La búsqueda no mostraba un producto que debería haber encontrado.

No es necesario hacer nada, salvo que un producto visible siga sin aparecer en las búsquedas; en ese caso, vuelva a cargar WCPOS.

Una comprobación automática periódica solicitó al índice de búsqueda local un registro utilizando las palabras del propio registro, pero el índice no lo devolvió. Esto significa que las búsquedas podrían haber mostrado menos resultados de los que realmente guarda este dispositivo. La aplicación puede reconstruir el índice por sí sola, pero solo una vez por lista y sesión, por lo que la reconstrucción no está garantizada.

## Sus datos {#your-data}

No se ha modificado ningún dato de la tienda. Esto solo afecta al índice de búsqueda local, que se genera a partir de los datos que ya están en este dispositivo; no se pierde nada al reconstruirlo.

## Solución de problemas {#troubleshoot}

1. No es necesario hacer nada, salvo que un producto visible siga sin aparecer en las búsquedas; las ventas pueden continuar con normalidad. La aplicación puede reconstruir el índice por sí sola, pero solo una vez por lista y sesión, así que, si este código se repite, continúe con el siguiente paso.
2. Si las búsquedas siguen omitiendo registros que puede ver en la aplicación, ya sea en una lista de productos, clientes, pedidos u otra, vuelva a cargar la aplicación: en la web, recargue la pestaña del navegador; en escritorio y móvil, cierre la aplicación y vuelva a abrirla. Así podrá intentar reconstruir el índice de nuevo la próxima vez que se detecte el problema.
3. Si el código vuelve a aparecer después de recargar, utilice **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte; la entrada del registro incluye los detalles que soporte necesita para identificar la lista afectada y el registro que el índice no encontró.
