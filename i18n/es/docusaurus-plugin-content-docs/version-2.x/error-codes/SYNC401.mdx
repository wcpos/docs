## Qué significa {#what-this-means}

Una tarea de sincronización en segundo plano se detuvo inesperadamente antes de finalizar.

No tiene que hacer nada: el POS reinicia estas tareas automáticamente y no se pierde nada. Si este código sigue apareciendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte.

## Sus datos {#your-data}

No se pierde nada; los datos de pedidos y productos no se ven afectados. Si el problema persiste, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Solución de problemas {#troubleshoot}

1. No tiene que hacer nada la primera vez que lo vea: el POS reinicia automáticamente la tarea en segundo plano que ha fallado y no hay datos de pedidos implicados.
2. Si el código se repite al cabo de unos minutos, recargue la aplicación una vez para que el motor de sincronización arranque desde cero.
3. Si sigue repitiéndose, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte: un fallo recurrente de una tarea es un defecto de la aplicación que conviene comunicar, no un problema de la tienda.
