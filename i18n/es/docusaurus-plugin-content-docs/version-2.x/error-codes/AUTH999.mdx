## Qué significa {#what-this-means}

Se ha producido un problema inesperado al iniciar o mantener la sesión.

Intente realizar la acción una vez más. Si el problema se repite, cierre la sesión y vuelva a iniciarla; después, use **Copiar información de depuración** y contacte con el servicio de asistencia.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Si el problema persiste, use **Copiar información de depuración** y contacte con el servicio de asistencia de WCPOS.

## Solución de problemas {#troubleshoot}

1. Intente realizar la acción una vez más; si vuelve a fallar, cierre la sesión y vuelva a iniciarla.
2. Despliegue la entrada del registro y anote el código del evento y cualquier serverCode; un código 999 significa que la causa aún no tiene un código específico y ese contexto permite identificarla.
3. Si vuelve a ocurrir, use Copiar información de depuración y contacte con el servicio de asistencia.
