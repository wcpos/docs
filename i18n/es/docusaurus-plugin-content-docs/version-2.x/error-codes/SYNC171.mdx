## Qué significa {#what-this-means}

WCPOS no pudo configurar ni eliminar el almacenamiento en este dispositivo.

Libere espacio de almacenamiento en el dispositivo y reinicie WCPOS. En la web, el navegador también puede estar restringiendo el almacenamiento del sitio, como ocurre en las ventanas privadas. Contacte con el soporte si sigue fallando.

## Sus datos {#your-data}

Se trata de un problema de almacenamiento, no de una edición rechazada. Si ocurrió mientras se borraban datos de este dispositivo, es posible que parte de esos datos ya se haya eliminado, incluidos cambios que no se habían enviado: compruebe que sus ventas y cambios recientes aparecen en su tienda. Si sigue ocurriendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte de WCPOS.

## Solución de problemas {#troubleshoot}

1. Compruebe el espacio de almacenamiento libre del dispositivo y libere algo eliminando otros archivos o aplicaciones: la configuración del almacenamiento falla por completo cuando el disco está lleno o se ha agotado la cuota de almacenamiento del navegador. No use la opción «Borrar datos de navegación» del navegador para liberar espacio: también elimina las ventas de WCPOS que no se han enviado.
2. Reinicie WCPOS y vuelva a intentar la misma acción.
3. En la web, compruebe que el navegador permite el almacenamiento persistente para el sitio: las ventanas privadas y los ajustes que bloquean todos los datos no lo permiten.
4. Si sigue fallando, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte.
