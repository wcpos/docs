## Qué significa {#what-this-means}

El plugin WCPOS de esta tienda es demasiado antiguo para esta versión de la aplicación.

La aplicación se ha actualizado, pero el plugin WCPOS de la tienda no, y las dos versiones ya no funcionan juntas. Pida a la persona que administra el sitio que actualice el plugin WCPOS en WP Admin y vuelva a conectarse. No es necesario cambiar nada en la caja.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Si el problema persiste, consulte a la persona que administra su sitio de WordPress.

## Solución de problemas {#troubleshoot}

**En la tienda** — para la persona que administra el sitio de WordPress:

1. WP Admin → Plugins → actualice WCPOS a la última versión. Si WCPOS Pro está instalado, actualícelo al mismo tiempo a una versión compatible.
2. Si no se ofrece ninguna actualización, revise WP Admin → Escritorio → Actualizaciones; en Pro, un actualizador no autorizado bloquea las actualizaciones (consulte [LICENSE301](./LICENSE301)); resuelva primero ese problema.

**En la caja** — para el cajero: una vez actualizada la tienda, vuelva a conectarse. No necesita volver a escribir la dirección de la tienda.

**Si todavía no se puede actualizar la tienda:** contacte con el servicio de asistencia; la caja necesita una versión de la aplicación compatible con el plugin, y el servicio de asistencia puede indicarle cuál. Le pedirán la versión de la aplicación (en la caja) y la versión actual de WCPOS de la tienda (en WP Admin).
