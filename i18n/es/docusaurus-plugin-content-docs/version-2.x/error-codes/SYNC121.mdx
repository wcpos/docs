## Qué significa {#what-this-means}

No se puede conectar con su tienda en este momento.

No tiene que hacer nada: siga vendiendo. Los cambios se envían automáticamente cuando se restablece la conexión. Si el problema persiste, compruebe la conexión de este dispositivo y si el sitio web de su tienda carga.

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener cambios que su tienda aún no tiene. Se envían automáticamente en cuanto su tienda responde.

## Solución de problemas {#troubleshoot}

1. Siga vendiendo: las ventas se guardan en este dispositivo y se envían automáticamente en cuanto la tienda responde.
2. Compruebe si el propio terminal tiene conexión: ¿se puede cargar algún otro sitio web desde este dispositivo?
3. Abra el sitio web de su tienda en una pestaña del navegador en el mismo dispositivo; si tampoco carga allí, el problema está en el sitio o en su alojamiento, no en el POS.
4. **Para quien gestione la red de este dispositivo:** si el sitio carga pero el POS sigue sin conexión, algo entre ambos está bloqueando las solicitudes a la API: una VPN, un cortafuegos, un bloqueador de anuncios o un plugin de seguridad. Las herramientas de desarrollo del navegador (pestaña Red), o **Avanzado → Alternar herramientas de desarrollo** en la aplicación de escritorio, muestran qué solicitud falla.
