## Qué significa {#what-this-means}

El actualizador no está autorizado para descargar actualizaciones de WCPOS Pro.

Vuelva a autorizar el actualizador para esta tienda y después busque actualizaciones de nuevo.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Si el problema persiste, consulte a la persona que administra su sitio de WordPress.

## Solución de problemas {#troubleshoot}

1. Vaya a **WP Admin > POS > Ajustes > Licencia**. Si la página muestra el campo **Clave de licencia**, introduzca su clave y pulse **Activar**; si ya muestra la licencia como activada, copie primero la clave completa de su cuenta de WCPOS (la página solo muestra una versión abreviada), pulse **Desactivar**, vuelva a introducir la clave y pulse **Activar**.
2. Busque actualizaciones de nuevo desde WP Admin → Escritorio → Actualizaciones.
3. Si la autorización sigue fallando, es posible que el sitio esté bloqueando las solicitudes salientes al servidor de actualizaciones; pregunte al proveedor de alojamiento si las conexiones HTTPS salientes están restringidas.
