# Códigos de error {#error-codes}

Cuando WCPOS encuentra un problema, muestra un código de error que ayuda a identificarlo. A partir de **v1.10.0**, los códigos siguen el formato **dominio + tres dígitos**; por ejemplo, `SYNC131` o `AUTH311`. El dominio indica el área del POS; el número identifica la condición concreta. Cada código tiene su propia página, que explica qué significa, qué hacer y qué consecuencias tiene para sus datos.

En el POS, los códigos de error aparecen en **Estado de la tienda → Registros**: expanda una fila y use el enlace **Ayuda** para acceder directamente a la página del código en esta documentación.

## Dominios de error (v1.10.0+) {#error-domains}

| Dominio | Área |
|--------|------|
| [`AUTH`](#auth) | Inicio de sesión, sesiones y tokens |
| [`CHECKOUT`](#checkout) | Finalización de pedidos en caja |
| [`CLIENT`](#client) | La propia aplicación POS y el almacenamiento local |
| [`DISPLAY`](#display) | La pantalla del cliente |
| [`HOST`](#host) | Alojamiento y reglas del cortafuegos que bloquean el POS |
| [`LICENSE`](#license) | Activación y validación de la licencia Pro |
| [`PAYMENT`](#payment) | Pasarelas de pago y terminales |
| [`PRINT`](#print) | Impresión de recibos |
| [`PRODUCT`](#product) | Datos de productos y operaciones del catálogo |
| [`REGISTER`](#register) | Cajón de efectivo, sesiones de caja y arqueos |
| [`SYNC`](#sync) | Sincronización entre el POS y su tienda |

Localice su código a continuación o utilice la búsqueda.

Los códigos terminados en `999` agrupan las condiciones del dominio que aún no tienen un código específico.

## Códigos anteriores a v1.10.0 {#legacy-codes}

Los códigos como `API04001` proceden de versiones anteriores a v1.10.0; esta versión nunca los genera. Es posible que aún encuentre alguno en una entrada del registro conservada desde antes de la actualización o en un hilo antiguo de soporte. Seleccione **1.x** en el menú de versiones para consultarlos.
