## Qué significa {#what-this-means}

El proveedor de alojamiento está limitando la frecuencia de las solicitudes de las cajas de esta tienda.

El servidor sigue respondiendo con 429 (demasiadas solicitudes), aunque la aplicación ya está espaciando los reintentos y respetando los tiempos de espera Retry-After del servidor. Varias cajas conectadas a internet mediante una misma conexión comparten una dirección, por lo que los límites de solicitudes por origen las tratan como un único cliente con mucha actividad. La sincronización continúa automáticamente, pero se retrasará hasta que se aumente el límite.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados.

## Solución de problemas {#troubleshoot}

1. Pida al proveedor de alojamiento que aumente el límite de solicitudes de la API REST para el tráfico de la propia tienda o lo exima de dicho límite; indique la IP estática de la tienda si dispone de una.
2. Los servicios de seguridad que contabilizan las respuestas de error repetidas (429) para aplicar un bloqueo (por ejemplo, el IDS de Sucuri) pueden necesitar que se excluya la API de la tienda de ese recuento.
3. Si varias cajas comparten una conexión, indíqueselo al proveedor de alojamiento: en este caso, una IP corresponde a toda una tienda, no a un único usuario.
