## Qué significa {#what-this-means}

El token de inicio de sesión supera el tamaño que acepta este servidor.

El servidor ha rechazado el token de inicio de sesión por su tamaño: un 400 cuando se envía en la cabecera Authorization o un 414 cuando se envía en la URL. Ninguna codificación del lado del cliente puede reducirlo; hay que aumentar los límites de tamaño de las cabeceras o de la URL del servidor, o reducir el tamaño del token.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados.

## Solución de problemas {#troubleshoot}

1. En Apache, aumente LimitRequestFieldSize (envío por cabecera) o LimitRequestLine (envío por URL) en la configuración del host virtual.
2. En nginx, aumente large_client_header_buffers.
3. Si hay un proxy o una CDN, el límite puede estar en esa capa; compruebe ambas.
4. Si no se pueden modificar los límites, contacte con el servicio de asistencia para consultar la emisión de un token más pequeño para este sitio.
