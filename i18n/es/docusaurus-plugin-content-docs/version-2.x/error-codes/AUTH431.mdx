## Qué significa {#what-this-means}

La API REST de la tienda no ha respondido en ninguno de los formatos de dirección que esta aplicación puede utilizar.

La aplicación ha intentado acceder a la API REST de la tienda mediante su dirección habitual (/wp-json/...) y la dirección alternativa integrada de WordPress (/?rest_route=...), pero ninguna ha respondido. El sitio web de la tienda puede estar funcionando; lo que no es accesible es la API REST, normalmente porque un plugin de seguridad la oculta o una regla del cortafuegos la bloquea.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados.

## Solución de problemas {#troubleshoot}

**En la tienda** — para el administrador del sitio: si un plugin de seguridad oculta o cambia el nombre de `/wp-json/` (por ejemplo, WP Hide), permita también el formato `/?rest_route=` integrado de WordPress; la aplicación recurre a él automáticamente.

**En el alojamiento / servidor:**

1. Revise las reglas del cortafuegos (WAF) que coincidan con `wp-json` o `rest_route` y permita el acceso a la propia API REST de la tienda.
2. Si el servidor está detrás de una página de mantenimiento o una verificación contra bots, las solicitudes REST pueden recibir una página HTML como respuesta; desactive esa verificación para la API REST.

**Para comprobarlo (cualquier persona):** `https://your-store.com/?rest_route=/` debe devolver JSON, no una página 403 ni la página de inicio del sitio.
