## Qué significa {#what-this-means}

La pasarela de pago seleccionada no está disponible para esta tienda.

Pida al administrador del sitio que compruebe que la pasarela de pago sea compatible, esté activada y esté configurada correctamente.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Si el problema persiste, consulte a la persona que administra su sitio de WordPress.

## Solución de problemas {#troubleshoot}

**En la caja:**

1. Mientras tanto, complete la venta con otro método, como efectivo.
2. Si el método aparece atenuado bajo **… no disponible en este momento** en el panel de pago, se trata de un problema en esta caja, no de este error; el motivo que se muestra (por ejemplo, **Necesita conexión** o **Active Bluetooth para usar el lector**) le indica qué debe solucionar.

**En la tienda** — para el administrador del sitio:

3. Vaya a **WP Admin > POS > Ajustes > Caja**. En **Pasarelas de pago**, la pasarela de pago debe figurar en la lista y tener activado el interruptor **Activado**. Si no aparece, compruebe que su plugin esté instalado y activo. No es necesario que esté activada en **WP Admin > WooCommerce > Ajustes > Pagos**: WCPOS muestra todas las pasarelas de pago que registra un plugin activo. En WCPOS Free solo se pueden activar los métodos integrados de efectivo y tarjeta; las demás pasarelas de pago de WooCommerce requieren WCPOS Pro.
4. Si la pasarela de pago funcionaba ayer, compruebe si se ha actualizado esta o WooCommerce; **WooCommerce → Estado → Registros** puede recoger errores de inicio de la pasarela de pago.
5. Una vez solucionado, recargue la aplicación en la caja para que vuelva a reconocer la pasarela de pago.
