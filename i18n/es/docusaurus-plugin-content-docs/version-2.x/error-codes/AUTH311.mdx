## Qué significa esto {#what-this-means}

WCPOS no puede acceder a su punto de conexión en la tienda.

Pida al administrador del sitio que compruebe que el complemento de WCPOS está activo (**WP Admin → Plugins**) y que ningún complemento de seguridad bloquea la API REST.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Avise al administrador del sitio.

## Resolución de problemas {#troubleshoot}

**En el terminal** — para el cajero: avise al administrador del sitio. Nada en este dispositivo se ve afectado.

**En la tienda** — para el administrador del sitio:

1. Confirme que WCPOS está activo: WP Admin → Plugins.
2. Si no funciona ninguna de las dos formas de acceso REST, compruebe si un complemento de seguridad, un proxy o una CDN está eliminando las cabeceras de las solicitudes de WCPOS o bloqueando las solicitudes REST. Las causas más habituales son las reglas del cortafuegos y las opciones de refuerzo de seguridad que desactivan la API REST.
3. En algunos alojamientos, volver a guardar los enlaces permanentes (Ajustes → Enlaces permanentes → Guardar cambios) restaura las rutas REST que faltan.
