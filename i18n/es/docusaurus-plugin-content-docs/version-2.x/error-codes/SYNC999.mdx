## Qué significa {#what-this-means}

Se produjo un problema inesperado durante la sincronización.

Compruebe que la acción indicada en esta entrada haya finalizado; si no es así, repítala. Si esto se repite, pulse **Copiar información de depuración** y envíela a soporte.

## Sus datos {#your-data}

No borre los datos de este dispositivo: puede contener cambios que su tienda aún no tiene. Si la acción indicada en la entrada no finalizó, repítala.

## Solución de problemas {#troubleshoot}

1. Despliegue la entrada del registro y busque la acción que indica. Compruebe que haya finalizado: si se trata de un guardado, abra el pedido o registro y compruebe que el cambio aparezca. Si aparece, WCPOS lo envía automáticamente, por lo que no necesita hacer nada más.
2. Si no finalizó, repítala. Si la entrada del registro indica que el cambio nunca se guardó en este dispositivo, no se capturó nada.
3. Anote el código y cualquier motivo que aparezca en la entrada del registro: un código 999 significa que la causa concreta todavía no tiene un código propio, por lo que este contexto es precisamente lo que necesita el equipo de soporte.
4. Si esto se repite, pulse **Copiar información de depuración** en la pestaña **Registros** y envíela a soporte: comunicarlo permite que se añada el código específico.
