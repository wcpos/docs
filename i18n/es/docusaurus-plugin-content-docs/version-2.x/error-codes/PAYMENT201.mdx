## Qué significa {#what-this-means}

WCPOS no pudo confirmar si el terminal cobró el pago.

Compruebe el terminal de pago antes de intentar otro cobro y contacte con el proveedor de pagos si el resultado sigue sin estar claro.

## Sus datos {#your-data}

No se pudo confirmar el resultado; verifíquelo antes de volver a intentarlo. Si el problema persiste, contacte con su proveedor de pagos.

## Solución de problemas {#troubleshoot}

1. No vuelva a pasar la tarjeta todavía.
2. Compruebe la pantalla del propio terminal y después el panel de su proveedor de pagos; el registro del proveedor es la referencia definitiva para saber si se realizó el cargo.
3. Si tiene acceso a WP Admin, compruebe WooCommerce → Pedidos (o pídaselo al propietario de la tienda); es posible que un pago realizado correctamente ya figure allí.
4. Solo vuelva a cobrar cuando el panel del proveedor confirme que no hay ningún cargo.
5. Si el cargo aparece como pendiente o con un resultado incierto, contacte con el proveedor de pagos antes de actuar.
