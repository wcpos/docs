## Qué significa esto {#what-this-means}

Este navegador solo permite que una pestaña envíe cambios a la vez.

WCPOS ya no genera este código: el POS solo se ejecuta en una pestaña. En una segunda pestaña aparece **El POS está abierto en otra pestaña**; pulse **Continuar aquí** para seguir en esa pestaña o vuelva a la primera. Consulte [Si el POS no se inicia](../getting-started/index.mdx#wont-start).

## Sus datos {#your-data}

No se ven afectados los datos de pedidos ni de productos.

## Resolución de problemas {#troubleshoot}

1. Use el POS en una sola pestaña. Si aparece **El POS está abierto en otra pestaña**, pulse **Continuar aquí** para seguir allí.
2. Este navegador (o una ventana privada) no dispone de la función de coordinación entre pestañas que prefiere el POS, por lo que utiliza una sola pestaña para sincronizar. No hace falta corregir nada.
