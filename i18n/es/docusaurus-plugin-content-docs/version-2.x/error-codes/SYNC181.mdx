## Qué significa {#what-this-means}

El guardado o la carga en este dispositivo está tardando mucho y aún no se conoce su resultado.

No tiene que hacer nada si WCPOS funciona. Si una pantalla se queda atascada, recargue WCPOS y compruebe que su último cambio se guardó.

Una sola lectura o escritura en la base de datos local de este dispositivo lleva mucho más tiempo del normal sin respuesta, mientras la base de datos sigue respondiendo a todo lo demás. Este mecanismo solo registra el atasco: no cancela ni reintenta la operación, por lo que la llamada original aún puede completarse o fallar más adelante; la entrada permite que una pantalla o un indicador de carga atascados dejen constancia de qué operación exacta se atascó. Las tareas de sincronización atascadas tienen un tiempo de espera y un mecanismo de reintento independientes, y se registran con una entrada «Se abandonó una solicitud de datos atascada» bajo [SYNC321](/error-codes/SYNC321). Una llamada atascada desde una pantalla permanece pendiente hasta que termina o se recarga la aplicación.

## Sus datos {#your-data}

No se pudo confirmar el resultado: compruébelo antes de volver a intentarlo. La operación atascada suele ser una consulta, que no modifica nada. Si se estaba guardando un cambio en ese momento, abra el registro y confirme que se guardó; puede que no haya habido ningún síntoma visible. El contexto de la entrada identifica la operación y la colección de datos implicada.

## Solución de problemas {#troubleshoot}

1. Si WCPOS funciona, no tiene que hacer nada: lo más probable es que la llamada se haya completado, aunque lentamente. Si la operación indicada en la entrada era un guardado, abra el registro y confirme que se guardó.
2. Si una pantalla o un indicador de carga se queda atascado, recargue la aplicación: en la web, recargue la pestaña del navegador; en escritorio y móvil, cierre y vuelva a abrir la aplicación. Esto abandona la operación atascada; la pantalla vuelve a cargarse y realiza una nueva consulta a la base de datos. Un guardado que estaba en curso no se vuelve a enviar: abra el registro y confirme que se guardó.
3. Si este código se repite con frecuencia en el mismo dispositivo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con el soporte: el contexto de la entrada identifica la operación y la colección, el tiempo exacto de espera y la carga de trabajo de la base de datos durante ese tiempo.
