## Qué significa {#what-this-means}

La lista de cambios de su tienda se desplazó de forma inesperada, por lo que WCPOS está volviendo a comprobarla automáticamente. No se pierde nada.

No tiene que hacer nada; puede seguir vendiendo. WCPOS vuelve a comprobar los cambios de su tienda automáticamente. Si los precios o las existencias siguen pareciendo desactualizados, pulse **Comprobar todo ahora** en **Estado de la tienda → Base de datos**.

## Sus datos {#your-data}

No se pierde nada y ningún dato de este dispositivo está en riesgo. Hasta que finalice la nueva comprobación, algunos precios o existencias de este dispositivo pueden estar desactualizados.

## Solución de problemas {#troubleshoot}

1. Siga vendiendo: no se pierde nada en este dispositivo y la nueva comprobación se realiza automáticamente. La entrada del registro puede indicar qué se desplazó; por ejemplo, que se omitieron algunos cambios de la tienda o que la lista de la tienda retrocedió. En ambos casos puede tratarse de cualquier tipo de dato.
2. Si los precios o las existencias siguen pareciendo desactualizados, abra **Estado de la tienda → Base de datos** y pulse **Comprobar todo ahora**.
3. Si un registro sigue pareciendo incorrecto después de esa comprobación, o este código sigue apareciendo, use **Copiar información de depuración** en la pestaña **Registros** y contacte con soporte. No borre los datos para solucionarlo.
