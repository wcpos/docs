## Qué significa esto {#what-this-means}

La tienda no aceptó las credenciales de inicio de sesión.

Vuelva a introducir el nombre de usuario y la contraseña, o restablezca la contraseña en WordPress si el problema persiste. Los datos de pedidos no se ven afectados.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados.

## Resolución de problemas {#troubleshoot}

**En el terminal** — para el cajero: vuelva a introducir el nombre de usuario y la contraseña; la tienda rechazó esa combinación.

**En la tienda** — para el administrador del sitio:

1. Confirme que la cuenta funciona iniciando sesión en WP Admin con las mismas credenciales; si no funciona, restablezca allí la contraseña.
2. Si las credenciales funcionan en WP Admin pero no en el POS, es posible que un complemento de seguridad o de protección del inicio de sesión esté bloqueando el acceso mediante la aplicación; revise sus ajustes.
