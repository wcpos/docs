## Qué significa {#what-this-means}

No se han podido leer los datos de precios de las variaciones de este producto, por lo que los precios mostrados pueden ser incorrectos o no aparecer.

Vuelva a guardar el producto en WooCommerce para reconstruir sus datos de precios, o póngase en contacto con el servicio de asistencia si ocurre con muchos productos.

## Sus datos {#your-data}

Los datos de pedidos y productos no se ven afectados. Si el problema persiste, consulte al administrador de su tienda.

## Solución de problemas {#troubleshoot}

**En la caja:** compruebe el precio antes de vender; si parece incorrecto o no aparece, no venda a ese precio hasta que se corrija en la tienda.

**En la tienda (WP Admin):**

1. Abra el producto y vuelva a guardarlo: así se reconstruyen los datos de precios que el POS no ha podido leer.
2. Compruebe que cada variación tenga un precio establecido; una variación sin precio genera intervalos de precios que no se pueden leer.
3. Si muchos productos muestran este código a la vez, es probable que un plugin de precios esté escribiendo los datos de precios en un formato que el POS no puede leer; anote qué plugin gestiona los precios y póngase en contacto con el servicio de asistencia.
