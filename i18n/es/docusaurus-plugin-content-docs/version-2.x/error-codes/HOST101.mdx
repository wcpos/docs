## Qué significa {#what-this-means}

El servidor bloquea la comprobación de permisos del navegador (comprobación preliminar de CORS), por lo que la aplicación web no puede acceder a él.

Los navegadores envían una solicitud OPTIONS antes de cualquier llamada a la API entre orígenes distintos que incluya cabeceras personalizadas. Algo situado delante de esta tienda, normalmente una regla del cortafuegos, está bloqueando OPTIONS, por lo que el navegador nunca envía la solicitud real. Las aplicaciones nativas no se ven afectadas; la solución debe aplicarse en el servidor.

## Sus datos {#your-data}

No se ve afectado ningún dato de pedidos o productos.

## Solución de problemas {#troubleshoot}

1. Compruebe si el cortafuegos (WAF) tiene una regla que bloquee el método OPTIONS y permítalo en las rutas REST /wcpos/.
2. Algunos plugins de seguridad tienen una opción para «bloquear métodos de solicitud poco habituales»; OPTIONS debe seguir permitido.
3. Prueba: una solicitud OPTIONS a la API REST de la tienda no debería devolver 403.
4. Las aplicaciones de escritorio y móvil no utilizan CORS y seguirán funcionando mientras se soluciona este problema.
