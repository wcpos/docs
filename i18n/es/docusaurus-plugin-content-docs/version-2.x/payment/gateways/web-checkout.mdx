# Pasarela de pago Web Checkout {#web-checkout-gateway}

:::info Función Pro
Necesita [WCPOS Pro](../../getting-started/free-vs-pro.mdx) para cobrar con Web Checkout.
:::

Web Checkout permite que el cliente pague un pedido del POS en la página de pago de su tienda en línea, con los métodos que esta ofrece, como un formulario de pago con tarjeta o una cartera digital. Úselo cuando el cliente quiera pagar con un método que la caja no acepte.

Ir directamente a: [Cobrar](#take-payment) · [Configuración](#set-up) · [Si algo sale mal](#goes-wrong)

## Cobrar {#take-payment}

Web Checkout se encuentra en la pestaña **Legado** de la pantalla de pago. Necesita conexión y cobra el pedido completo: si ya se ha recibido un pago, consulte primero [Parte del pedido ya está pagada](#split).

:::warning Mantenga abierta la pantalla de pago hasta pulsar Procesar pago
La caja no supervisa la otra pestaña. Solo cierra la venta cuando pulsa **Procesar pago** en un pedido que el cliente ya ha pagado, así que mantenga abierta la pantalla de pago mientras el cliente paga.
:::

1. Registre la venta como de costumbre y pulse **Pagar**.
2. Abra la pestaña **Legado**. La página de pago de su tienda se carga dentro del POS.
3. Seleccione **Web Checkout**. Debajo aparecen su nota y un enlace **Pagar este pedido**.
4. Pulse **Pagar este pedido**. La página de pago de su tienda en línea correspondiente a este pedido se abre en una nueva pestaña del navegador; en la aplicación de escritorio, se abre en el navegador web de su ordenador.
5. Ceda la pantalla al cliente. El cliente elige un método de pago y paga, igual que en su sitio web.
6. Cuando el cliente haya pagado, su pestaña mostrará la confirmación del pedido de su tienda. Deje esa pestaña abierta y vuelva al POS.
7. Pulse **Procesar pago**. Si el pedido está pagado, la caja muestra la pantalla de pago realizado y el recibo, como en cualquier venta. Si no lo está, la caja permanece en esta página: consulte [Si algo sale mal](#goes-wrong).
8. Cierre la pestaña del cliente cuando la caja muestre el recibo.

### Parte del pedido ya está pagada {#split}

Una pasarela de pago de legado cobra el pedido completo, por lo que, una vez recibido un pago, la pestaña Legado indica **No se puede usar una pasarela de pago de legado una vez recibido un pago**. Tiene dos opciones:

- **Cobre el resto con un botón**, como Efectivo o Tarjeta, en la pestaña Pagos. Consulte [Pagos divididos](../../pos/checkout/split-payments.mdx).
- **Cancele los pagos recibidos hasta el momento** y después use Web Checkout para el pedido completo. Antes de deshacer nada, la caja detalla qué ocurre con cada pago: el efectivo se devuelve al cliente, los demás pagos se anulan en su método de pago y los que no se pueden anular se reembolsan desde el pedido. Consulte [Cancelar un pago](../../pos/checkout/cancelling-a-payment.mdx).

:::tip El cliente quiere pagar más tarde desde su propio teléfono
Web Checkout abre la página de pago en el dispositivo donde se ejecuta el POS. Para enviar al cliente un enlace con el que pueda pagar más tarde, use [Factura por correo electrónico](./email-invoice.mdx).
:::

## Configuración {#set-up}

La persona que administra su tienda en WP Admin realiza esta configuración una sola vez, antes de la primera venta con Web Checkout. Web Checkout es un plugin gratuito, pero el POS solo lo ofrece con WCPOS Pro; sin Pro, la caja acepta Efectivo y Tarjeta. Utiliza los métodos de pago que su tienda en línea ya tiene. No necesita cuenta ni claves.

<details>
<summary>Responsable de la tienda: instalación y activación</summary>

1. **Instálelo.** Web Checkout no está en `WP Admin > POS > Ajustes > Extensiones`. Descargue **woocommerce-pos-web-checkout-gateway.zip** (no el zip del código fuente) desde la [página de versiones de GitHub](https://github.com/wcpos/web-checkout-gateway/releases), súbalo desde `WP Admin > Plugins > Add Plugin`, después **Subir plugin**, y actívelo.
2. **Actívelo para el POS.** En `WP Admin > POS > Ajustes > Finalizar compra`, active **Web Checkout** y guarde. Consulte [Ajustes de caja](../../settings/wp-admin/checkout.mdx#enabling-a-gateway). Nunca aparece al finalizar la compra en su tienda en línea: los clientes solo acceden a él a través del POS.
3. **Compruebe sus métodos de pago en línea.** El cliente paga con los métodos activados para la web en `WP Admin > WooCommerce > Ajustes > Pagos`. Al menos uno debe estar listo para recibir pagos.

</details>

<details>
<summary>Cambiar el nombre o el mensaje</summary>

El nombre y la nota de la página de pago son el **Título** y la **Descripción** de la pasarela de pago, en `WP Admin > WooCommerce > Ajustes > Pagos > Web Checkout Gateway`. La nota predeterminada dice: «Vaya a la página de pago para pagar el pedido. Después del pago, haga clic en el botón Procesar pago para continuar al recibo». Para cambiar el nombre solo en el POS, modifique su **Título** en **Ajustes del POS**, dentro del menú **⋮** de la pasarela de pago en [Ajustes de caja](../../settings/wp-admin/checkout.mdx#payment-gateways); la nota siempre procede de WooCommerce.

</details>

<details>
<summary>Para desarrolladores: cómo funciona</summary>

El plugin añade una pasarela de pago de WooCommerce con el ID `wcpos_web_checkout`. Está desactivada por código para la finalización de compra en línea, de modo que solo el POS puede ofrecerla. Sus campos de pago muestran la descripción y un enlace a la URL de pago del propio pedido (`$order->get_checkout_payment_url()`), que se abre en una ventana nueva.

La pasarela de pago no cobra por sí misma. Cuando **Procesar pago** envía un pedido ya pagado, creado por el POS y con `wcpos_web_checkout` seleccionado, el plugin redirige la página de pago a la página de pedido recibido y el POS cierra la venta desde allí. Si el pedido no está pagado, no se avanza. El código fuente está en el [repositorio web-checkout-gateway](https://github.com/wcpos/web-checkout-gateway).

</details>

## Si algo sale mal {#goes-wrong}

**Web Checkout no aparece en la lista de la pestaña Legado.** El plugin no está activo o Web Checkout no está activado en [Ajustes de caja](../../settings/wp-admin/checkout.mdx#enabling-a-gateway). Sin WCPOS Pro, el POS solo ofrece Efectivo y Tarjeta.

**«No hay pasarelas de pago de legado activadas para el POS».** No hay ninguna pasarela de pago sin botón propio activada. Active Web Checkout en Ajustes de caja.

**Procesar pago no avanza al recibo.** La tienda no tiene el pedido registrado como pagado. Antes de pedir al cliente que vuelva a pagar, mire su pestaña: si sigue mostrando la página de pago, no ha terminado. Si muestra la confirmación del pedido, pulse **Procesar pago** de nuevo y, si la caja sigue sin avanzar, compruebe el pedido en `WP Admin > WooCommerce > Orders`.

**No aparece ningún método que el cliente pueda usar en la página de pago.** Su tienda en línea no tiene activado ninguno que le sirva. Active uno para la web en `WP Admin > WooCommerce > Ajustes > Pagos`.

**La página de pago dentro del POS no se muestra correctamente.** Puede que un tema o plugin esté interfiriendo. Consulte [La página de pago de una pasarela no se muestra correctamente](../../pos/checkout/troubleshooting.mdx#checkout-settings-troubleshooting).
