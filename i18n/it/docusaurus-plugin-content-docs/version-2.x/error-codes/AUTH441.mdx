## Cosa significa {#what-this-means}

Il token di accesso supera le dimensioni accettate da questo server.

Il server ha rifiutato il token di accesso per le sue dimensioni: un errore 400 quando viene trasmesso nell'intestazione Authorization, oppure un 414 quando viene trasmesso nell'URL. Nessuna codifica lato client può ridurlo: occorre aumentare i limiti di dimensione delle intestazioni/degli URL sul server oppure ridurre le dimensioni del token.

## I tuoi dati {#your-data}

I dati degli ordini e dei prodotti non sono interessati.

## Risoluzione dei problemi {#troubleshoot}

1. Su Apache, aumenta LimitRequestFieldSize (invio tramite intestazione) o LimitRequestLine (invio tramite URL) nella configurazione del vhost.
2. Su nginx, aumenta large_client_header_buffers.
3. Se il server è dietro un proxy o una CDN, il limite potrebbe essere imposto a quel livello: controlla entrambi.
4. Se non è possibile modificare i limiti, contatta l'assistenza per ottenere un token più piccolo per questo sito.
