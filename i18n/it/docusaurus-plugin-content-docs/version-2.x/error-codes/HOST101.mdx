## Cosa significa {#what-this-means}

Il server blocca il controllo delle autorizzazioni del browser (richiesta preliminare CORS), quindi l'app web non riesce a raggiungerlo.

I browser inviano una richiesta OPTIONS prima di ogni chiamata API tra origini diverse che contiene intestazioni personalizzate. Qualcosa a monte del negozio, di solito una regola del firewall, blocca OPTIONS, quindi il browser non invia mai la richiesta effettiva. Le app native non sono interessate; la correzione va effettuata sul server.

## I tuoi dati {#your-data}

Nessun dato di ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Controlla se nel firewall (WAF) è presente una regola che blocca il metodo OPTIONS e consentilo sulle route REST /wcpos/.
2. Alcuni plugin di sicurezza hanno un'opzione «blocca i metodi di richiesta poco comuni»: OPTIONS deve rimanere consentito.
3. Verifica: una richiesta OPTIONS alla REST API del negozio non dovrebbe restituire 403.
4. Le app desktop e mobili non utilizzano CORS e continueranno a funzionare durante la risoluzione del problema.
