## Cosa significa {#what-this-means}

WCPOS non riesce a raggiungere il proprio punto di connessione sul negozio.

Chiedi all'amministratore del sito di verificare che il plugin WCPOS sia attivo (**WP Admin → Plugin**) e che nessun plugin di sicurezza blocchi l'API REST.

## I tuoi dati {#your-data}

I dati degli ordini e dei prodotti non sono interessati. Avvisa l'amministratore del sito.

## Risoluzione dei problemi {#troubleshoot}

**Alla cassa** — per il cassiere: avvisa l'amministratore del sito. Nulla su questo dispositivo è interessato.

**Sul negozio** — per l'amministratore del sito:

1. Verifica che WCPOS sia attivo: WP Admin → Plugin.
2. Se nessuna delle due forme di indirizzo REST funziona, controlla se un plugin di sicurezza, un proxy o una CDN rimuove le intestazioni delle richieste WCPOS o blocca le richieste REST: le cause più comuni sono le regole del firewall e le opzioni di protezione che disabilitano l'API REST.
3. Su alcuni hosting, salvare di nuovo i permalink (Impostazioni → Permalink → Salva le modifiche) ripristina le route REST mancanti.
