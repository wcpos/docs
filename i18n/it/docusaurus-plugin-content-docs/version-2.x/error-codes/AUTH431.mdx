## Cosa significa {#what-this-means}

L'API REST del negozio non ha risposto con nessuna delle forme di indirizzo utilizzabili da questa app.

L'app ha provato a contattare l'API REST del negozio al suo indirizzo normale (/wp-json/...) e all'indirizzo alternativo integrato in WordPress (/?rest_route=...), senza ricevere risposta da nessuno dei due. Il sito web del negozio potrebbe essere comunque disponibile: è specificamente l'API REST a non essere raggiungibile, di solito perché un plugin di sicurezza la nasconde o una regola del firewall la blocca.

## I tuoi dati {#your-data}

I dati degli ordini e dei prodotti non sono interessati.

## Risoluzione dei problemi {#troubleshoot}

**Sul negozio** — per l'amministratore del sito: se un plugin di sicurezza nasconde o rinomina `/wp-json/` (ad esempio WP Hide), consenti anche la forma `/?rest_route=` integrata in WordPress: l'app la usa automaticamente come alternativa.

**Sull'hosting / sul server:**

1. Controlla le regole del firewall (WAF) che corrispondono a `wp-json` o `rest_route` e consenti il passaggio delle richieste all'API REST del negozio.
2. Se il server è dietro una pagina di manutenzione o una verifica anti-bot, le richieste REST potrebbero ricevere una pagina HTML come risposta: disabilita la verifica per l'API REST.

**Per verificare (chiunque):** `https://your-store.com/?rest_route=/` dovrebbe restituire JSON, non una pagina 403 o la homepage del sito.
