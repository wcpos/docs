## Cosa significa {#what-this-means}

Un altro plugin di autenticazione impedisce a WCPOS di connettersi.

Chiedi all'amministratore del sito di risolvere il conflitto con il plugin indicato prima di accedere di nuovo.

## I tuoi dati {#your-data}

I dati degli ordini e dei prodotti non sono interessati. Se il problema persiste, rivolgiti a chi gestisce il tuo sito WordPress.

## Risoluzione dei problemi {#troubleshoot}

**Sul negozio** — per l'amministratore del sito:

1. L'errore indica il plugin in conflitto. Controlla le sue impostazioni: la maggior parte dei plugin di autenticazione consente di escludere le route REST di WCPOS dai controlli, senza dover disattivare completamente il plugin.
2. Se non è chiaro quale plugin causi il conflitto, fai una prova su una copia di staging disattivando i plugin di sicurezza e di accesso uno alla volta.

**Alla cassa** — per il cassiere: dopo la modifica, accedi di nuovo.
