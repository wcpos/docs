## Cosa significa {#what-this-means}

WCPOS non è riuscito a configurare o rimuovere lo spazio di archiviazione su questo dispositivo.

Libera spazio sul dispositivo, poi riavvia WCPOS. Sul web, il browser potrebbe anche limitare l'archiviazione per il sito, come accade nelle finestre private. Contatta l'assistenza se il problema persiste.

## I tuoi dati {#your-data}

È un problema di archiviazione, non una modifica rifiutata. Se si è verificato durante la cancellazione dei dati su questo dispositivo, una parte potrebbe essere già stata eliminata, comprese modifiche non ancora inviate: verifica che le vendite e le modifiche recenti siano presenti nel negozio. Se il problema persiste, usa **Copia informazioni di debug** nella scheda **Log** e contatta l'assistenza WCPOS.

## Risoluzione dei problemi {#troubleshoot}

1. Controlla lo spazio libero sul dispositivo e liberane un po' rimuovendo altri file o app: la configurazione dello spazio di archiviazione non può riuscire se il disco è pieno o la quota del browser è esaurita. Non usare l'opzione del browser «Cancella dati di navigazione» per liberare spazio: elimina anche le vendite di WCPOS non ancora inviate.
2. Riavvia WCPOS e riprova la stessa azione.
3. Sul web, verifica che il browser consenta l'archiviazione persistente per il sito: le finestre private e le impostazioni che bloccano tutti i dati non la consentono.
4. Se il problema persiste, usa **Copia informazioni di debug** nella scheda **Log** e contatta l'assistenza.
