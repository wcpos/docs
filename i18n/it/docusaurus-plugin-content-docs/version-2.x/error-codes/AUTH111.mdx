## Cosa significa {#what-this-means}

Il negozio non ha accettato le credenziali di accesso.

Inserisci di nuovo nome utente e password oppure, se l'accesso continua a non riuscire, reimposta la password in WordPress. I dati degli ordini non sono interessati.

## I tuoi dati {#your-data}

I dati degli ordini e dei prodotti non sono interessati.

## Risoluzione dei problemi {#troubleshoot}

**Alla cassa** — per il cassiere: inserisci di nuovo nome utente e password; il negozio ha rifiutato questa combinazione.

**Sul negozio** — per l'amministratore del sito:

1. Verifica che l'account funzioni accedendo a WP Admin con le stesse credenziali; se l'accesso non riesce, reimposta lì la password.
2. Se le credenziali funzionano in WP Admin ma non nel POS, un plugin di protezione dell'accesso o di sicurezza potrebbe bloccare l'accesso tramite software: controlla le sue impostazioni.
