## Cosa significa {#what-this-means}

Il filtro di sicurezza del provider di hosting blocca le ricerche dei prodotti.

Una regola del firewall su questo server rifiuta le richieste REST la cui stringa di query contiene caratteri non ASCII o parole che sembrano comandi SQL. I nomi di prodotti con accenti e le ricerche contenenti parole come 'select' o 'union' restituiscono un errore 403, anche se sono normali ricerche nel catalogo. Per il resto la cassa funziona; le ricerche non saranno affidabili finché la regola non verrà resa meno restrittiva.

## I tuoi dati {#your-data}

Nessun dato di ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Chiedi al provider di hosting di consentire i parametri di ricerca REST del negozio (percorsi /wcpos/ e /wc/) nelle regole del firewall sulle stringhe di query.
2. Nei firewall basati su OWASP CRS, di solito sono responsabili le regole contro le iniezioni SQL sugli argomenti 's' e 'search': escludi questi argomenti per i percorsi dell'API REST.
3. Per i plugin di sicurezza con un'opzione per filtrare le stringhe di query sospette serve un'eccezione per l'API REST, non la disattivazione globale del filtro.
