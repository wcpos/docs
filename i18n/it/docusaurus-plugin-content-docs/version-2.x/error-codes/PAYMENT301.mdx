## Cosa significa {#what-this-means}

Il gateway di pagamento selezionato non è disponibile per questo negozio.

Chiedi all'amministratore del sito di verificare che il gateway di pagamento sia supportato, abilitato e configurato correttamente.

## I tuoi dati {#your-data}

Nessun dato di ordini o prodotti è interessato. Se il problema persiste, rivolgiti a chi gestisce il tuo sito WordPress.

## Risoluzione dei problemi {#troubleshoot}

**Alla cassa:**

1. Nel frattempo, completa la vendita con un altro metodo, ad esempio in contanti.
2. Se il metodo è disattivato sotto **… non disponibile al momento** nel pannello dei pagamenti, si tratta di un problema di questa cassa, non di questo errore: il motivo mostrato (ad esempio **Richiede una connessione** o **Attiva il Bluetooth per usare il lettore**) indica cosa correggere.

**Sul sito** — per l'amministratore del sito:

3. Vai su **WP Admin > POS > Impostazioni > Cassa**. In **Gateway di pagamento**, il gateway di pagamento deve comparire nell'elenco e il suo interruttore **Abilitato** deve essere attivo. Se non è presente, verifica che il relativo plugin sia installato e attivo. Non è necessario abilitarlo in **WP Admin > WooCommerce > Impostazioni > Pagamenti**: il POS elenca tutti i gateway di pagamento registrati dai plugin attivi. Su WCPOS Free è possibile abilitare solo i metodi integrati per contanti e carte; gli altri gateway di pagamento di WooCommerce richiedono WCPOS Pro.
4. Se il gateway di pagamento funzionava ieri, controlla se è stato aggiornato o se è stato aggiornato WooCommerce: **WooCommerce → Stato → Log** potrebbe riportare errori di avvio del gateway di pagamento.
5. Una volta risolto il problema, ricarica l'app sulla cassa per farle rilevare di nuovo il gateway di pagamento.
