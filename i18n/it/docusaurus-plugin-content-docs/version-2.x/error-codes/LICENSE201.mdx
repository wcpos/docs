## Cosa significa {#what-this-means}

WCPOS Pro è disabilitato perché la sua versione non corrisponde a quella di WCPOS.

Aggiorna il componente WCPOS o WCPOS Pro indicato, in modo che entrambe le versioni siano compatibili.

## I tuoi dati {#your-data}

Nessun dato di ordini o prodotti è interessato. Se il problema persiste, rivolgiti a chi gestisce il tuo sito WordPress.

## Risoluzione dei problemi {#troubleshoot}

1. Controlla le versioni di entrambi i plugin in WP Admin → Plugin: la voce del log indica quale tra WCPOS e WCPOS Pro è rimasto indietro.
2. Aggiorna quello meno recente; aggiornando entrambi alle ultime versioni si risolve il disallineamento.
3. Se non vengono proposti aggiornamenti di Pro, il sistema di aggiornamento potrebbe non essere autorizzato (vedi LICENSE301): risolvi prima questo problema, poi aggiorna.
