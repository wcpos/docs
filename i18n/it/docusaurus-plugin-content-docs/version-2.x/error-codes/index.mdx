# Codici di errore {#error-codes}

Quando WCPOS riscontra un problema, mostra un codice di errore che aiuta a identificarlo. A partire dalla **v1.10.0**, i codici seguono il formato **dominio + tre cifre**, ad esempio `SYNC131` o `AUTH311`. Il dominio indica l'area del POS; il numero identifica la condizione specifica. Ogni codice ha una pagina dedicata che ne spiega il significato, cosa fare e le implicazioni per i tuoi dati.

Nel POS, i codici di errore compaiono in **Stato del negozio → Log**: espandi una riga e usa il collegamento **Aiuto** per aprire direttamente la pagina del codice in questa guida.

## Domini degli errori (v1.10.0+) {#error-domains}

| Dominio | Area |
|--------|------|
| [`AUTH`](#auth) | Accesso, sessioni e token |
| [`CHECKOUT`](#checkout) | Completamento degli ordini alla cassa |
| [`CLIENT`](#client) | L'app POS e l'archiviazione locale |
| [`DISPLAY`](#display) | Il display rivolto al cliente |
| [`HOST`](#host) | Hosting e regole del firewall che bloccano il POS |
| [`LICENSE`](#license) | Attivazione e validazione della licenza Pro |
| [`PAYMENT`](#payment) | Gateway di pagamento e terminali |
| [`PRINT`](#print) | Stampa delle ricevute |
| [`PRODUCT`](#product) | Dati dei prodotti e operazioni sul catalogo |
| [`REGISTER`](#register) | Cassetto portadenaro, sessioni e conteggi di cassa |
| [`SYNC`](#sync) | Sincronizzazione tra il POS e il tuo negozio |

Trova il tuo codice qui sotto oppure cercalo.

I codici che terminano con `999` raggruppano le condizioni del dominio che non hanno ancora un codice specifico.

## Codici precedenti alla v1.10.0 {#legacy-codes}

Codici come `API04001` provengono dalle versioni precedenti alla v1.10.0; questa versione non li genera mai. Potresti ancora trovarne uno in una voce di log conservata da prima dell'aggiornamento o in una vecchia discussione di assistenza. Seleziona **1.x** nel menu delle versioni per consultarli.
