## Cosa significa {#what-this-means}

Una pagina di protezione antibot risponde al posto dell'API del negozio.

La REST API del negozio restituisce una pagina HTML di verifica (protezione antibot, CAPTCHA o pagina intermedia di protezione DDoS) dove l'app si aspetta JSON. Un'app per punto vendita non può superare una verifica per browser; la REST API del negozio deve essere inserita nell'elenco degli elementi consentiti del servizio di protezione.

## I tuoi dati {#your-data}

Nessun dato di ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Identifica il servizio di protezione dalla pagina di verifica (Cloudflare, Sucuri, Kinsta e altri mostrano ciascuno il proprio marchio) e aprine le impostazioni.
2. Inserisci i percorsi della REST API del negozio (/wp-json/ e /?rest_route=) nell'elenco degli elementi consentiti per il traffico API.
3. Su Cloudflare, aggiungi una regola WAF **Ignora** per i percorsi della REST API; Bot Fight Mode (piano gratuito) non può essere aggirato da alcuna regola e deve essere disattivato. La [guida a Cloudflare](/troubleshooting/common-problems/cloudflare) contiene la regola esatta e una verifica con `curl`.
4. Nelle impostazioni antibot e firewall di Kinsta, inserisci i percorsi della REST API nell'elenco degli elementi consentiti; su Sucuri, evita la modalità DDoS con verifica JavaScript per le route API.
