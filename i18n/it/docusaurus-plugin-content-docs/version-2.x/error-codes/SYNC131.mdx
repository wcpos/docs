## Cosa significa {#what-this-means}

Si è verificato un errore nel negozio, che non ha completato questa richiesta.

Il negozio è stato raggiunto, ma il suo server non è riuscito a gestire la richiesta: è un problema del sito web, non del POS. Riprova l'azione. Se il problema persiste, chiedi all'amministratore del sito di controllare **WooCommerce → Stato → Log**. Su questo dispositivo non è andato perso nulla.

## I tuoi dati {#your-data}

Non cancellare i dati di questo dispositivo: potrebbe contenere modifiche non ancora presenti nel negozio. Una modifica in corso di invio potrebbe non essere arrivata al negozio. Se il problema persiste, usa **Copia informazioni di debug** nella scheda **Log** e contatta l'assistenza WCPOS.

## Risoluzione dei problemi {#troubleshoot}

**Nel POS (cassiere):** espandi la voce del log e annota lo stato, l'endpoint e serverCode: indicano cosa stava facendo il server quando si è verificato l'errore.

**Sul sito web (amministratore del sito / fornitore di hosting):**

1. Apri WooCommerce → Stato → Log sul sito e controlla il log fatal-errors più recente in corrispondenza dell'ora dell'errore; una risposta di classe 500 lascia quasi sempre un errore PHP in quel log.
2. Se il problema è iniziato dopo un aggiornamento di un plugin, del tema o di PHP sul sito, considera prima quella modifica e annullala o disattivala.
3. Se i log di WooCommerce non mostrano nulla, chiedi al fornitore di hosting il log degli errori PHP del server per lo stesso intervallo di tempo.

**Poi, di nuovo nel POS:** riprova l'azione.
