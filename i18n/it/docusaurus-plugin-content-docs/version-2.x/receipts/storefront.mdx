**WP admin:** attiva il pulsante **Ricevuta** per gli ordini online in `WP Admin → POS → Settings → General`.

:::note Questa pagina è rivolta a chi gestisce il sito web
Con [WCPOS Pro](../getting-started/pro-license.mdx), puoi stampare o inviare via email una ricevuta dalla cassa per qualsiasi ordine, inclusi quelli online: vedi [Ristampare una ricevuta](../orders/index.mdx#receipt-reprinting) nella pagina **Ordini**.
:::

:::tip Se un cliente chiede la ricevuta di un acquisto online
Una volta configurata la funzione sul sito web, il cliente trova il pulsante **Ricevuta** in **Il mio account → Ordini**, oppure un link alla ricevuta nella pagina di conferma dell'ordine, se il negozio lo ha aggiunto.
:::

I template di ricevuta di WCPOS funzionano anche sul tuo sito web. Un cliente che ha acquistato online può scaricare la ricevuta in PDF da **Il mio account**, oppure da un link che inserisci nella pagina di conferma dell'ordine.

## Attivare il pulsante Ricevuta {#my-account}

:::warning Attiva prima un template di ricevuta
Attivane uno in **POS → Template** prima di iniziare. Senza un template attivo, i clienti non vedranno il pulsante **Ricevuta**, anche se l'impostazione è attiva. Vedi [Personalizzare la ricevuta](./customise.mdx#option-1--pick-a-different-template).
:::

Il pulsante rimane disattivato finché non lo attivi. Il PDF viene generato dal tuo template di ricevuta.

1. In WP Admin, vai a **POS → Impostazioni → Generali**.

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="WP Admin con POS, Impostazioni selezionato nel menu e Generali aperto nel menu delle impostazioni, con Negozi, Cassa e l'inizio di Prodotti visibili">

1. **POS → Impostazioni** — la voce del menu di WP Admin per le impostazioni del POS.
2. **Generali** — la prima schermata delle impostazioni, già aperta quando accedi.

</JourneyShot>

2. Scorri fino alla sezione **Clienti** e attiva **Consenti ai clienti di scaricare le ricevute**. La modifica viene salvata appena azioni l'interruttore.

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="La sezione Clienti di Generali: Genera automaticamente il nome utente dall'email del cliente, Cliente POS predefinito impostato su Ospite e Consenti ai clienti di scaricare le ricevute, qui ancora disattivato">

1. **Clienti** — la sezione che contiene l'impostazione per le ricevute.
2. **Consenti ai clienti di scaricare le ricevute** — disattivato finché non lo attivi.

</JourneyShot>

3. Subito sotto compare **Template di ricevuta per i clienti**. Lascia selezionato **Usa il template di ricevuta attivo**, oppure scegline uno. Vedi [Scegliere il template per il cliente](#template-choice).

Ora un cliente che ha effettuato l'accesso vede un pulsante **Ricevuta** accanto ai propri ordini in **Il mio account → Ordini**. Il pulsante scarica un PDF il cui nome fa riferimento all'ordine, ad esempio `receipt-1234.pdf`.

Il pulsante compare solo per gli ordini già pagati:

| Stato dell'ordine | Pulsante Ricevuta |
|---|---|
| **In lavorazione** | Sì |
| **Completato** | Sì |
| **Rimborsato** | Sì |
| Qualsiasi altro stato, come **In attesa di pagamento**, **In sospeso**, **Annullato** o **Fallito** | No |

Uno sviluppatore può [modificare gli stati per cui compare il pulsante](#developers).

## Scegliere il template per il cliente {#template-choice}

**Template di ricevuta per i clienti** determina quale template viene usato per il download.

- **Usa il template di ricevuta attivo** (opzione predefinita): i clienti ricevono il template di ricevuta attivo in **POS → Template**. Se lo cambi lì, anche i loro download useranno il nuovo template.
- **Un template specifico**: i clienti ricevono sempre quello, qualunque sia la scelta del cassiere alla cassa. Usa questa opzione quando sono attivi più template di ricevuta o per dare agli ordini online un aspetto diverso.

Un template stretto, in stile ricevuta termica, genera un PDF stretto. Per gli ordini online, una pagina intera è in genere più leggibile: il template **Fattura** della galleria è pensato per carta A4 e Letter. Vedi [Personalizzare la ricevuta](./customise.mdx#option-1--pick-a-different-template) per aggiungerlo.

Il PDF viene compilato con gli stessi [dati della ricevuta](./receipt-data.mdx) usati per la ricevuta alla cassa, quindi mantiene il logo, i dati del negozio e le impostazioni fiscali.

Se un template scelto viene successivamente eliminato o la sua pubblicazione viene annullata, il menu a discesa mostra **Template non disponibile** e i clienti ricevono invece il template di ricevuta attivo. Scegline un altro.

## Aggiungere un link alla ricevuta nella pagina di conferma dell'ordine {#shortcode}

Offri ai clienti un link **Scarica ricevuta (PDF)** nella pagina di ringraziamento che vedono dopo il pagamento. Gli ospiti che hanno completato l'acquisto senza un account ottengono la ricevuta in questo modo.

Se in WP Admin è presente **Aspetto → Editor → Template → Conferma dell'ordine**, inserisci direttamente il link nella pagina di ringraziamento:

1. In WP Admin, vai a **Aspetto → Editor → Template** e apri **Conferma dell'ordine**.
2. Aggiungi un blocco **Shortcode** nel punto in cui vuoi inserire il link e digita `[wcpos_receipt]` al suo interno.
3. Premi **Salva**.

Se non hai quel template o vuoi inserire il link nella pagina di un ordine in **Il mio account**, chiedi a uno sviluppatore di [aggiungere il link alla ricevuta tramite codice](#developers).

Lo shortcode funziona indipendentemente dall'attivazione di **Consenti ai clienti di scaricare le ricevute**: questa impostazione controlla solo il pulsante in **Il mio account → Ordini**.

<details>
<summary>Opzioni ed esempi dello shortcode</summary>

`[wcpos_receipt]` funziona nella pagina di conferma dell'ordine e nella pagina di un ordine in **Il mio account**. In queste pagine trova l'ordine da solo, quindi non devi digitare un numero d'ordine. In qualsiasi altra pagina non mostra nulla, a meno che tu non gli fornisca un `order_id`.

| Opzione | Valore predefinito | Funzione |
|---|---|---|
| `order_id` | *(rilevato nella pagina)* | Link a un ordine specifico, in qualsiasi pagina. Compare solo per il cliente che ha effettuato l'accesso ed è titolare dell'ordine. |
| `link_text` | `Download receipt (PDF)` | Il testo del link. |
| `format` | `pdf` | `pdf` scarica un PDF. `html` apre la ricevuta nel browser, pronta per la stampa. |
| `template` | *(il tuo template di ricevuta attivo)* | Usa questo template al suo posto. |
| `class` | `wcpos-receipt-link` | Classe CSS del link. |
| `id` | *(nessuno)* | `id` HTML del link. |

L'opzione `template` dello shortcode ignora **Template di ricevuta per i clienti**: se la ometti, il link usa il tuo template di ricevuta attivo.

Un link di download con un testo personalizzato:

```text
[wcpos_receipt link_text="Download your invoice"]
```

Aprire la ricevuta nel browser invece di scaricare un PDF:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

Usare un template specifico, ad esempio una fattura A4 al posto della ricevuta da cassa da 80mm:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

Il numero del template si trova nella barra degli indirizzi quando modifichi il template in **POS → Template** (`post=123`). Un template non pubblicato viene ignorato e il link usa il tuo template di ricevuta attivo.

</details>

## Chi può aprire una ricevuta {#security}

- **I clienti con un account** effettuano l'accesso e usano il pulsante **Ricevuta** in **Il mio account → Ordini**.
- **Gli ospiti** che hanno completato l'acquisto senza un account usano il link alla ricevuta nella pagina di conferma dell'ordine, dopo che lo hai [inserito lì](#shortcode).

:::warning Condividi i link alle ricevute solo con il cliente
Chiunque abbia un link a una ricevuta può aprirla senza effettuare l'accesso. Trattalo con la stessa riservatezza dell'ordine.
:::

<details>
<summary>Come vengono protetti i link alle ricevute</summary>

Ogni link a una ricevuta contiene la chiave privata dell'ordine, la stessa che WooCommerce inserisce nella pagina di conferma dell'ordine. Senza la chiave corretta, la ricevuta non si apre. Uno shortcode con l'opzione `order_id` mostra il link solo al cliente che ha effettuato l'accesso ed è titolare dell'ordine.

</details>

## Se qualcosa va storto {#goes-wrong}

La maggior parte delle soluzioni riportate di seguito si applica in WP Admin. Se sei un cassiere, comunica a chi gestisce il sito web il messaggio visualizzato dal cliente. Nel frattempo, con [WCPOS Pro](../getting-started/pro-license.mdx), puoi stampare o inviare via email la ricevuta dalla cassa: vedi [Ristampare una ricevuta](../orders/index.mdx#receipt-reprinting) nella pagina **Ordini**.

**Il cliente non vede il pulsante Ricevuta.** Verifica che **Consenti ai clienti di scaricare le ricevute** sia attivo, che l'ordine sia **In lavorazione**, **Completato** o **Rimborsato** e che sia attivo almeno un template di ricevuta in **POS → Template**. Il pulsante compare solo in **Il mio account → Ordini**, per un cliente che ha effettuato l'accesso.

**"Nessun template di ricevuta configurato."** Non c'è un template da usare per il PDF. Attiva un template di ricevuta in **POS → Template**.

**"Non hai i permessi per visualizzare questa ricevuta."** Il link è incompleto o è stato copiato male: ogni link contiene una chiave privata per il relativo ordine. Invia di nuovo al cliente il link dalla sua pagina di conferma o da **Il mio account**.

**"Impossibile generare il PDF della ricevuta."** Non è stato possibile generare il PDF dal template. Aprilo in **POS → Template** e visualizzane l'anteprima. Vedi [Personalizzare la ricevuta](./customise.mdx).

**Il link apre un errore "Pagina non trovata".** In WP Admin, vai a **Impostazioni → Permalink** e scegli un'opzione qualsiasi tranne **Semplice**. I link alle ricevute non funzionano con **Semplice**.

## Per gli sviluppatori {#developers}

<details>
<summary>Aggiungere il link alla ricevuta tramite codice</summary>

In un tema classico, genera il link dalle due azioni di WooCommerce che producono queste pagine:

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

Lo shortcode trova l'ordine in entrambe le pagine, quindi non richiede `order_id`.

</details>

<details>
<summary>Filtri per il pulsante Ricevuta e il template PDF</summary>

Tre filtri si sovrappongono alle impostazioni descritte sopra, per applicare regole che le impostazioni non consentono di esprimere, ad esempio per singolo ordine o cliente:

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

Prima di WCPOS 2.0 questi filtri si chiamavano `woocommerce_pos_storefront_receipt_*`. Questi nomi funzionano ancora, ma sono deprecati dalla versione 2.0 e verranno rimossi non prima della versione 2.2. Vedi [Nomi degli hook](../extensions/index.mdx#hook-naming).

L'indirizzo del PDF è `/wcpos-checkout/wcpos-receipt/{order_id}` con `?key={order_key}&format=pdf`: lo stesso indirizzo della ricevuta protetto da chiave usato dal POS, con `format=pdf` che restituisce un PDF al posto della pagina.

</details>
