## Cosa significa {#what-this-means}

L'API REST del negozio non ha risposto a nessuna forma di indirizzo utilizzabile da questa app.

L'app ha provato l'API REST del negozio al suo indirizzo normale (/wp-json/...) e all'indirizzo di riserva integrato di WordPress (/?rest_route=...), e nessuno dei due ha risposto. Il sito web del negozio potrebbe essere attivo — qui si tratta specificamente dell'API REST irraggiungibile, di solito un plugin di sicurezza che la nasconde o una regola del firewall che la blocca.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

**Sul negozio** — per l'amministratore del sito: se un plugin di sicurezza nasconde o rinomina `/wp-json/` (ad esempio WP Hide), consenti anche la forma integrata di WordPress `/?rest_route=` — l'app vi ricorre automaticamente come riserva.

**Sull'host / server:**

1. Controlla le regole del firewall (WAF) per qualsiasi elemento che corrisponda a `wp-json` o `rest_route` e lascia passare l'API REST del negozio.
2. Se il server è protetto da una pagina di manutenzione o da una verifica anti-bot, le richieste REST potrebbero ricevere in risposta una pagina HTML — disattiva la verifica per l'API REST.

**Per fare una prova (chiunque):** `https://your-store.com/?rest_route=/` dovrebbe restituire JSON, non una pagina 403 o la homepage del sito.
