## Cosa significa {#what-this-means}

Un altro plugin di autenticazione impedisce a WCPOS di connettersi.

Chiedi all'amministratore del sito di risolvere il conflitto con il plugin indicato prima di accedere di nuovo.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti viene compromesso. Se il problema persiste, rivolgiti alla persona che gestisce il tuo sito WordPress.

## Risoluzione dei problemi {#troubleshoot}

**Nel negozio** — per l'amministratore del sito:

1. L'errore indica il plugin in conflitto. Controllane le impostazioni: la maggior parte dei plugin di autenticazione consente di escludere gli endpoint REST di WCPOS senza dover disattivare del tutto il plugin.
2. Se non è chiaro quale plugin sia in conflitto, fai una prova su una copia di staging disattivando i plugin di sicurezza e di login uno alla volta.

**Al registratore di cassa** — per il cassiere: dopo la modifica, accedi di nuovo.
