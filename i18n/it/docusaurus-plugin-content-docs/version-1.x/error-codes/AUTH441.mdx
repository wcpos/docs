## Cosa significa {#what-this-means}

Il token di accesso è più grande di quanto questo server accetti.

Il server ha rifiutato il token di accesso per le sue dimensioni: un 400 quando viaggia nell'header Authorization, oppure un 414 quando viaggia nell'URL. Nessuna codifica lato client può ridurlo — i limiti di dimensione di header/URL del server devono essere aumentati, oppure il token deve essere reso più piccolo.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Su Apache, aumenta LimitRequestFieldSize (percorso header) o LimitRequestLine (percorso URL) nella configurazione del vhost.
2. Su nginx, aumenta large_client_header_buffers.
3. Dietro un proxy o una CDN, il limite potrebbe trovarsi a quel livello — controlla entrambi.
4. Se i limiti non possono essere modificati, contatta l'assistenza per l'emissione di un token più piccolo per questo sito.
