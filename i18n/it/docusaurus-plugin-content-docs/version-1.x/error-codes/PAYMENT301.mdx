## Cosa significa {#what-this-means}

Il gateway di pagamento selezionato non è disponibile per questo negozio.

Chiedi all'amministratore del sito di verificare che il gateway sia supportato, attivo e configurato correttamente.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti viene compromesso. Se il problema persiste, rivolgiti alla persona che gestisce il tuo sito WordPress.

## Risoluzione dei problemi {#troubleshoot}

**Al registratore di cassa:** nel frattempo, completa la vendita con un altro metodo, ad esempio in contanti.

**Nel negozio** — per l'amministratore del sito:

1. Controlla il gateway in WooCommerce → Impostazioni → Pagamenti: deve essere installato, attivo e abilitato per l'uso nel POS nelle impostazioni POS.
2. Se il gateway funzionava ieri, controlla se è stato aggiornato lui o WooCommerce: in WooCommerce → Stato → Log potrebbero esserci errori di inizializzazione del gateway.
