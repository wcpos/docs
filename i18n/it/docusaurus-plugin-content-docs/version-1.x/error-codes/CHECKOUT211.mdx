## Cosa significa {#what-this-means}

Il negozio non ha restituito alcun risultato della procedura di cassa, quindi lo stato dell'ordine è sconosciuto.

Verifica se l'ordine è stato creato prima di riprovare la procedura di cassa.

## I tuoi dati {#your-data}

Non è stato possibile confermare l'esito — verifica prima di riprovare. Se il problema persiste, esporta le informazioni diagnostiche e contatta l'assistenza WCPOS.

## Risoluzione dei problemi {#troubleshoot}

**Verifica prima se l'ordine esiste** — una risposta vuota spesso indica che l'ordine è stato creato, ma la conferma non è arrivata. Con WCPOS Pro, sincronizza il POS e controlla l'elenco Ordini del registratore di cassa; altrimenti chiedi a qualcuno di controllare WooCommerce → Ordini in WP Admin. Riprova la procedura di cassa solo dopo aver confermato che non è stato creato alcun ordine.

**Nel negozio** — per l'amministratore del sito:

1. Controlla WooCommerce → Stato → Log per un errore fatale durante la procedura di cassa — un arresto anomalo di PHP dopo la creazione dell'ordine produce esattamente questo.
2. Se il registro di WooCommerce non mostra nulla, chiedi al provider di hosting il registro degli errori PHP del server: alcuni errori fatali vengono registrati solo lì.

**Per uno sviluppatore:** negli strumenti per sviluppatori del browser — oppure in **Avanzate → Attiva/disattiva strumenti per sviluppatori** dell'app desktop — la richiesta di cassa nella scheda Rete con stato di successo ma corpo vuoto o troncato indica che un plugin o un buffer del server interrompe la risposta.
