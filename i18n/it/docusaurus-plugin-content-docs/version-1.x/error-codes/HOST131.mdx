## Cosa significa {#what-this-means}

Un proxy davanti al negozio rifiuta le risposte del server perché contengono troppi header.

Un livello di cache o proxy (comunemente Varnish) applica un limite al numero o alla dimensione degli header di risposta. Gli endpoint leggeri del negozio rientrano nel limite, ma le risposte API complete lo superano e tornano come errori 503 dal proxy, non da WordPress. Il limite deve essere aumentato su quel livello.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Su Varnish, aumenta http_max_hdr (numero di header) e http_resp_hdr_len / http_resp_size (dimensioni).
2. Chiedi all'host quale livello proxy restituisce il 503 — il registro degli errori di WordPress non mostrerà nulla perché la richiesta non fallisce mai lì.
3. Un controllo rapido: /wcpos/v2/ping del negozio risponde correttamente mentre gli endpoint dei dati restituiscono 503.
