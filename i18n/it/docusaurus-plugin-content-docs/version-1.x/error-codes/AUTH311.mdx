## Cosa significa {#what-this-means}

WCPOS non riesce a raggiungere il punto di connessione nel negozio.

Chiedi all'amministratore del sito di verificare che il plugin WCPOS sia attivo (**WP Admin → Plugin**) e che nessun plugin di sicurezza blocchi la REST API.

## I tuoi dati {#your-data}

I dati di ordini e prodotti non sono interessati. Avvisa l'amministratore del sito.

## Risoluzione dei problemi {#troubleshoot}

**Al punto cassa** — per il cassiere: avvisa l'amministratore del sito. I dati su questo dispositivo non sono interessati.

**Nel negozio** — per l'amministratore del sito:

1. Verifica che WCPOS sia attivo: WP Admin → Plugin.
2. Se nessuno dei due formati REST funziona, verifica se un plugin di sicurezza, un proxy o una CDN rimuove le intestazioni delle richieste di WCPOS o blocca le richieste REST. Le cause più comuni sono le regole del firewall e le opzioni di protezione che disattivano la REST API.
3. Su alcuni hosting, risalvare i permalink (Impostazioni → Permalink → Salva) ripristina le route REST mancanti.
