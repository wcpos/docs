## Cosa significa {#what-this-means}

La route del negozio WCPOS non è disponibile.

Chiedi all'amministratore del sito di verificare se un plugin di sicurezza o un proxy sta rimuovendo le intestazioni delle richieste WCPOS.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti viene compromesso. Se il problema persiste, rivolgiti alla persona che gestisce il tuo sito WordPress.

## Risoluzione dei problemi {#troubleshoot}

**Al registratore di cassa** — per il cassiere: prova in un browser entrambi i formati REST supportati: l'indirizzo `/wp-json/` del negozio e `/index.php?rest_route=/`. Diagnostica un blocco REST solo se nessuno dei due restituisce JSON; poi segnalalo all'amministratore.

**Nel negozio** — per l'amministratore del sito:

1. Verifica che WCPOS sia attivo: WP Admin → Plugin.
2. Se nessuno dei due formati REST funziona, verifica se un plugin di sicurezza, un proxy o una CDN rimuove le intestazioni delle richieste di WCPOS o blocca le richieste REST. Le cause più comuni sono le regole del firewall e le opzioni di protezione che disattivano la REST API.
3. Su alcuni hosting, risalvare i permalink (Impostazioni → Permalink → Salva) ripristina le route REST mancanti.
