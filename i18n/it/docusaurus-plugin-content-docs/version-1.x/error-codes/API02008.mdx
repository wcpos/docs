# API02008: Token di Aggiornamento Non Valido {#api02008-refresh-token-invalid}

## Cosa Significa {#what-this-means}

Il token di aggiornamento memorizzato dal POS non è riconosciuto dal server. I token di aggiornamento vengono utilizzati per ottenere nuovi token di accesso senza richiedere nuovamente di effettuare il login.

## Cause Comuni {#common-causes}

- **Token revocato** — Un amministratore ha invalidato la tua sessione
- **Secret del server cambiati** — Le chiavi di sicurezza di WordPress sono state aggiornate
- **Corruzione dei dati** — Il token è stato corrotto durante la memorizzazione
- **Accessi multipli** — Accedere altrove potrebbe aver invalidato questo token

## Come Risolvere {#how-to-fix}

### 1. Accedi Nuovamente {#1-log-in-again}

Poiché il token di aggiornamento è non valido, è necessario autenticarsi nuovamente:
1. Disconnettiti dal POS
2. Inserisci il tuo nome utente e la tua password
3. Questo genera nuovi token validi

### 2. Controlla le Sessioni Revocate {#2-check-for-revoked-sessions}

Se un amministratore ha revocato le sessioni:
- Questa è una pratica di sicurezza normale
- Accedi semplicemente di nuovo
- La tua nuova sessione funzionerà normalmente

### 3. Controlla le Modifiche del Server {#3-check-server-changes}

Se questo influisce su tutti gli utenti:
- Le sali/chiavi di WordPress potrebbero essere cambiate
- Le impostazioni del plugin JWT potrebbero essere state modificate
- Contatta l'amministratore del server

### 4. Cancella i Dati Memorizzati {#4-clear-stored-data}

Se continui ad avere problemi, e solo dopo aver effettuato il controllo seguente:

:::warning Controlla prima che non ci siano modifiche non salvate
La cancellazione dei dati locali o la reinstallazione dell'app elimina tutto ciò che si trova su questo dispositivo e non è ancora arrivato al negozio, comprese le vendite effettuate offline, i carrelli aperti e le modifiche non salvate. Prima di cancellare qualsiasi dato, apri **Stato del negozio → Database** e verifica che non ci siano elementi indicati come bloccati o mai arrivati al server; poi controlla in **Stato del negozio → Registri** che ci siano **0 record bloccati** e **0 modifiche in attesa di invio**; infine completa o annota ogni carrello aperto. Se WCPOS non mostra la pagina Stato del negozio, aggiorna prima WCPOS e poi verifica. Se trovi elementi elencati o in attesa, oppure non puoi effettuare il controllo, non cancellare nulla: chiedi al proprietario del negozio o contatta il supporto.
:::

- Cancella i dati dell'applicazione POS
- Rimuovi le credenziali memorizzate nella cache
- Inizia con un accesso pulito
