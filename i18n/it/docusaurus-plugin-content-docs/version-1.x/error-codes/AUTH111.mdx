## Cosa significa {#what-this-means}

Il negozio non ha accettato le credenziali di accesso.

Inserisci di nuovo il nome utente e la password, oppure reimposta la password in WordPress se continua a non funzionare. Nessun dato relativo agli ordini viene compromesso.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti viene compromesso.

## Risoluzione dei problemi {#troubleshoot}

**Al registratore di cassa** — per il cassiere: inserisci di nuovo nome utente e password; il negozio ha rifiutato questa coppia.

**Nel negozio** — per l'amministratore del sito:

1. Verifica che l'account funzioni accedendo a WP Admin con le stesse credenziali; se l'accesso non riesce, reimposta la password lì.
2. Se le credenziali funzionano in WP Admin ma non in WCPOS, un plugin di protezione dell'accesso o di sicurezza potrebbe bloccare l'accesso automatico: controllane le impostazioni.
