## Cosa significa {#what-this-means}

Una pagina di protezione anti-bot risponde al posto dell'API del negozio.

L'API REST del negozio restituisce una pagina HTML di verifica (protezione anti-bot, CAPTCHA o pagina interstiziale anti-DDoS) dove l'app si aspetta JSON. Un'app di punto vendita non può superare una verifica del browser; l'API REST del negozio deve essere inserita nella lista consentita del servizio di protezione.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Individua il livello di protezione dalla pagina di verifica (Cloudflare, Sucuri, Kinsta e altri hanno ciascuno la propria versione) e apri le sue impostazioni.
2. Inserisci nella lista consentita i percorsi dell'API REST del negozio (/wp-json/ e /?rest_route=) per il traffico API.
3. Su Cloudflare, la Bot Fight Mode non può essere aggirata per singolo percorso — usa le regole di consenso "definitely automated" della Super Bot Fight Mode oppure disattivala per questa zona.
4. Nelle impostazioni bot/firewall di Kinsta, inserisci nella lista consentita i percorsi dell'API REST; su Sucuri, evita la modalità DDoS con verifica JavaScript per le route API.
