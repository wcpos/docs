## Cosa significa {#what-this-means}

Una pagina di protezione anti-bot risponde al posto dell'API del negozio.

L'API REST del negozio restituisce una pagina HTML di verifica (protezione anti-bot, CAPTCHA o pagina interstiziale anti-DDoS) dove l'app si aspetta JSON. Un'app per il punto vendita non può superare una verifica del browser; l'API REST del negozio deve essere inserita nella lista consentita del servizio di protezione.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti è interessato.

## Risoluzione dei problemi {#troubleshoot}

1. Individua il servizio di protezione dalla pagina di verifica (Cloudflare, Sucuri, Kinsta e altri mostrano ciascuno il proprio marchio) e apri le sue impostazioni.
2. Inserisci nella lista consentita i percorsi dell'API REST del negozio (/wp-json/ e /?rest_route=) per il traffico API.
3. Su Cloudflare, aggiungi una regola WAF **Skip** per i percorsi dell'API REST; Bot Fight Mode (piano gratuito) non può essere aggirato da alcuna regola e deve essere disattivato. La [guida di Cloudflare](/1.x/support/troubleshooting/cloudflare) contiene la regola esatta e un controllo con `curl`.
4. Nelle impostazioni bot/firewall di Kinsta, inserisci nella lista consentita i percorsi dell'API REST; su Sucuri, evita la modalità DDoS con verifica JavaScript per le route API.
