## Cosa significa {#what-this-means}

Si è verificato un problema imprevisto durante il controllo della licenza.

Il POS continua a funzionare. Se le funzionalità Pro restano bloccate, reinserisci la chiave di licenza, poi contatta l'assistenza.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti viene compromesso. Se il problema persiste, esporta le informazioni diagnostiche e contatta l'assistenza WCPOS.

## Risoluzione dei problemi {#troubleshoot}

1. Continua a lavorare — il POS non si blocca a causa dei controlli sulla licenza.
2. Se le funzionalità Pro restano bloccate, reinserisci la chiave di licenza nelle impostazioni POS.
3. Se così non si risolve, esporta le informazioni di debug e contatta l'assistenza.
