## Cosa significa {#what-this-means}

Il database locale su questo dispositivo ha smesso di rispondere, quindi le azioni che lo richiedono sono in pausa.

Riavvia WCPOS per riconnettere il database locale. Le modifiche non salvate su questo dispositivo potrebbero non essere state scritte; controlla gli ordini recenti dopo il riavvio. Se continua a succedere, esporta le informazioni diagnostiche e contatta l'assistenza.

## I tuoi dati {#your-data}

I dati su questo dispositivo potrebbero essere a rischio — non cancellare i dati locali. Se il problema persiste, esporta le informazioni diagnostiche e contatta l'assistenza WCPOS.

## Risoluzione dei problemi {#troubleshoot}

1. Riavvia WCPOS — chiudere e riaprire l'app (o la scheda del browser) riconnette il database locale in quasi tutti i casi.
2. Dopo il riavvio, controlla gli ordini più recenti: una modifica effettuata nei secondi precedenti al problema potrebbe non essere stata scritta.
3. Sul web, evita le finestre private/in incognito e le estensioni aggressive per la pulizia dell'archiviazione — entrambe possono azzerare l'archiviazione locale nel mezzo di una sessione.
4. Se il problema si ripresenta regolarmente sullo stesso dispositivo, esporta le informazioni di debug e contatta l'assistenza, indicando che cosa stava facendo il dispositivo (sospensione, cambio di scheda, poca memoria) quando è accaduto.
