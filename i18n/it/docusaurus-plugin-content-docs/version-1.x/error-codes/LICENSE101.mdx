## Cosa significa {#what-this-means}

La tua licenza WCPOS Pro non è attiva per questo negozio o dispositivo.

Controlla lo stato locale, quello del server delle licenze e quello dell'updater, poi attiva la licenza per il negozio indicato.

## I tuoi dati {#your-data}

Nessun dato relativo a ordini o prodotti viene compromesso. Se il problema persiste, esporta le informazioni diagnostiche e contatta l'assistenza WCPOS.

## Risoluzione dei problemi {#troubleshoot}

**Nel negozio** — per l'amministratore del sito o il titolare della licenza:

1. Controlla lo stato della licenza nelle impostazioni POS in WP Admin — deve risultare attiva per l'URL esatto di questo negozio.
2. Un cambio di URL del sito (da http a https, l'aggiunta o la rimozione di www, uno spostamento di dominio, una copia di staging) disattiva la licenza per il nuovo indirizzo — riattivala per quello attuale.
3. Se la licenza risulta attiva ma WCPOS continua a indicare il contrario, disattivala e riattivala una volta.
4. Ancora bloccato? Esporta le informazioni di debug e contatta l'assistenza indicando il riferimento della tua licenza.

**Al registratore di cassa:** dopo aver riattivato la licenza, ricarica la pagina per applicare la modifica.
