# Gateway PayArc Terminal {#payarc-terminal-gateway}

Il gateway PayArc Terminal consente di accettare pagamenti di persona su un terminale PayArc PAX da WCPOS tramite PayArc Connect. Il pagamento viene avviato da WooCommerce e completato sul terminale; l'ordine viene contrassegnato come pagato solo dopo la conferma di PayArc.

## Come funziona {#how-it-works}

WordPress chiama **PayArc Connect** e PayArc raggiunge il terminale PAX. WCPOS comunica solo con il tuo sito. Ogni pagamento addebita l'**importo totale dell'ordine**.

La pagina di pagamento controlla il risultato ogni **1.5 secondi** e si arresta dopo **5 minuti**. Le callback di PayArc all'**Webhook URL** accelerano il risultato; i pagamenti vengono comunque completati tramite polling anche senza callback. Lascia aperta la pagina di pagamento mentre il cliente paga sul terminale.

## Configurazione {#setup}

<Steps>
  <StepCard number="1" title="Installa PayArc Terminal for WooCommerce">

Installa da `WP Admin > POS > Impostazioni > Estensioni` oppure scarica il file **payarc-terminal-for-woocommerce.zip** dalla [pagina delle release di GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases) e caricalo tramite `Plugin > Aggiungi Nuovo > Carica plugin`. Attiva il plugin.

  </StepCard>
  <StepCard number="2" title="Inserisci le credenziali PayArc">

1. Vai a `WP Admin > WooCommerce > Impostazioni > Pagamenti` e apri **PayArc Terminal**
2. Scegli **Mode**: `Live` è l'impostazione predefinita. Usa `Test` solo con le credenziali della dashboard di test PayArc e l'app PayArc Connect Test. Non mescolare mai gli ambienti
3. Inserisci **PayArc login email**, l'indirizzo email usato per accedere alla dashboard esercenti PayArc
4. Inserisci **PayArc MID** dal profilo esercente PayArc, non l'ID del terminale
5. Inserisci **PayArc ClientSecret** dalla sezione API della dashboard e **PayArc SecretKey / API bearer token** dalla dashboard PayArc
6. Lascia vuoto **Callback bearer token**, a meno che non te ne abbia fornito uno il supporto PayArc; è facoltativo

  </StepCard>
  <StepCard number="3" title="Connetti">

Fai clic su **Connect using these credentials**. In caso di esito positivo, la schermata ti chiede di inserire o confermare il numero di serie del terminale e salvare le impostazioni. Se indica che le credenziali sembrano appartenere all'altro ambiente, cambia **Mode** e connettiti di nuovo.

:::note
Dopo ogni modifica alla modalità o alle credenziali, fai nuovamente clic su **Connect using these credentials** e salva. I pagamenti sono bloccati finché la modalità e le credenziali non corrispondono alla connessione salvata. Se esegui l'aggiornamento da una versione precedente alla 0.1.14, premi Connect una volta.
:::

  </StepCard>
  <StepCard number="4" title="Aggiungi il terminale">

1. Inserisci il **Terminal serial number** PAX riportato sull'etichetta **S/N** sul retro del dispositivo, come configurato da PayArc per il tuo account
2. Scegli **Tender type** e **Print receipt**
3. Verifica che **Webhook URL** usi HTTPS. Forniscilo a PayArc solo se te lo chiede
4. Fai clic su **Save changes**

La modalità Live richiede un sito HTTPS.

  </StepCard>
  <StepCard number="5" title="Abilita in WCPOS" isLast>

1. Vai a `WP Admin > POS > Impostazioni > Pagamento`
2. Trova il gateway **PayArc Terminal** e abilitalo per WCPOS
3. Salva le impostazioni

:::note
La casella **Enable/Disable** nella schermata delle impostazioni di WooCommerce controlla solo il pagamento nel *negozio online*. WCPOS usa questo gateway una volta configurato, indipendentemente dal fatto che la casella sia selezionata.

La maggior parte dei negozi lascia questa opzione deselezionata.
:::

  </StepCard>
</Steps>

## Riferimento delle impostazioni {#settings}

| Impostazione | Funzione |
|---|---|
| **Enable/Disable** | Abilita PayArc Terminal per il pagamento nel negozio online. Disattivato per impostazione predefinita; l'abilitazione per WCPOS si gestisce in `POS > Impostazioni > Pagamento` |
| **Title** | L'etichetta di pagamento; il valore predefinito è `PayArc Terminal` |
| **Description** | La descrizione del pagamento; il valore predefinito è `Pay in person at a PayArc PAX terminal.` |
| **Mode** | `Live` (predefinito) o `Test`. Test richiede le credenziali della dashboard di test PayArc e l'app PayArc Connect Test |
| **PayArc login email** | L'indirizzo email usato per accedere alla dashboard esercenti PayArc; obbligatorio prima di connettersi |
| **PayArc MID** | Il MID esercente del profilo esercente PayArc, non l'ID del terminale |
| **PayArc ClientSecret** | Il segreto dalla sezione API della dashboard; viene memorizzato solo sul tuo server |
| **PayArc SecretKey / API bearer token** | Il token dalla dashboard PayArc, usato per accedere e recuperare il registro dei terminali |
| **Callback bearer token** | Facoltativo. Inseriscilo solo se te ne ha fornito uno il supporto PayArc |
| **PayArc connection** | Pulsanti **Connect using these credentials**, **Refresh Terminals** e **Disconnect** |
| **Terminal serial number** | Il numero S/N PAX assegnato al tuo account, necessario per i pagamenti. Se viene trovato nel registro, è compilato automaticamente; inseriscilo o confermalo prima di salvare |
| **Tender type** | `CREDIT` (predefinito) o `DEBIT` |
| **Print receipt** | `0` — nessuna (predefinito), `1` — esercente, `2` — cliente, `3` — entrambe |
| **Webhook URL** | Indirizzo di callback di sola lettura. Verifica che usi HTTPS; forniscilo a PayArc solo se te lo chiede |
| **PayArc diagnostics** | Informazioni sulla connessione e pulsante **Validate Settings**; i segreti non vengono mai mostrati |

I campi dei segreti salvati mostrano solo gli ultimi 4 caratteri. Lascia vuoto un campo segreto per mantenere il valore salvato.

La tabella **PayArc diagnostics** mostra la modalità, gli endpoint, MID / ID tenant / numero di serie mascherati, se il token di accesso Connect è configurato, il Webhook URL, l'ultima callback e l'ultimo errore PayArc. Usa **Validate Settings** per verificare le impostazioni.

## Utilizzo {#usage}

### Elaborazione dei pagamenti {#processing-payments}

1. **Select Gateway**: scegli **PayArc Terminal** come metodo di pagamento in WCPOS
2. **Start Payment**: fai clic su **Start Payment** per inviare il totale dell'ordine al terminale
3. **Customer Payment**: lascia aperta la pagina mentre il cliente completa il pagamento sul terminale PAX. Segui i messaggi di stato: `Starting terminal payment...` → `Payment sent to terminal.` → `Waiting for the terminal result...` → `Payment approved. Completing the order...`
4. **Automatic Completion**: quando PayArc conferma il pagamento, l'ordine viene completato automaticamente

### Controlli dei pagamenti {#payment-controls}

- **Cancel Payment** appare una volta avviato un pagamento. Se PayArc non ha ancora restituito un ID di tracciamento, attendi qualche istante prima di annullare
- Dopo un rifiuto, un annullamento o un timeout, puoi riprovare. In caso di timeout, controlla il terminale prima di riprovare il pagamento
- Il registro delle attività di pagamento è compresso per impostazione predefinita. Usa **Show activity** per visualizzarlo e **Clear** per cancellare le attività mostrate

### Ricevute {#receipts}

L'impostazione **Print receipt** controlla la stampa sul terminale: nessuna, esercente, cliente o entrambe.

## Rimborsi {#refunds}

Il plugin non supporta i rimborsi. Esegui il rimborso tramite PayArc, quindi registralo manualmente in WooCommerce.

## Registri {#logs}

Trovi i registri in `WooCommerce > Status > Log`, nella sorgente `payarc-terminal-for-woocommerce`. I registri includono tentativi di connessione, vendite avviate o non riuscite, annullamenti e callback accettate o rifiutate. Gli identificatori sono mascherati e i segreti oscurati.

Non è possibile scaricare un pacchetto di assistenza. Quando chiedi aiuto, invia il numero dell'ordine e le righe di registro pertinenti. Non condividere MID completi, ID dei terminali, token o dati della carta.

## Ambito e limitazioni {#scope-and-limitations}

- Il plugin non supporta i rimborsi
- I pagamenti addebitano l'**importo totale dell'ordine**; i pagamenti parziali o suddivisi non sono supportati
- Le mance non sono supportate
- Un terminale per negozio: una sola impostazione per il numero di serie, senza selettore del cassiere
- Le valute sono limitate a **USD, CAD, GBP, EUR e JPY**
- I pagamenti sono bloccati finché la modalità e le credenziali non corrispondono alla connessione salvata

## Risoluzione dei problemi {#troubleshooting}

### Problemi comuni {#common-issues}

<Accordion>
  <AccordionItem question="Le credenziali sembrano appartenere all'altro ambiente">

  - La modalità selezionata e le credenziali provengono da ambienti diversi
  - Imposta **Mode** in base alle credenziali oppure sostituisci le credenziali con quelle dell'ambiente selezionato
  - Fai nuovamente clic su **Connect using these credentials** e salva

  </AccordionItem>
  <AccordionItem question="Impossibile connettersi a PayArc">

  - PayArc ha rifiutato le credenziali di accesso. Controlla le credenziali inserite e riprova
  - Per i dettagli, controlla `WooCommerce > Status > Log`, sorgente `payarc-terminal-for-woocommerce`

  </AccordionItem>
  <AccordionItem question="Impossibile elaborare la richiesta di pagamento. (HTTP 500)">

  - Questo messaggio mostrato al cassiere è generico. Cerca **PayArc payment action failed** nel registro WooCommerce per conoscere la causa effettiva
  - Dopo una modifica alla modalità o alle credenziali, fai nuovamente clic su **Connect using these credentials** e salva
  - Verifica che **Terminal serial number** sia compilato
  - Se il registro indica che PayArc ha rifiutato sia il token di accesso Connect sia SecretKey, chiedi al supporto PayArc di confermare che **PayArc Connect V3** sia abilitato per il tuo account esercente
  - Verifica che la valuta del negozio sia **USD, CAD, GBP, EUR o JPY**

  </AccordionItem>
  <AccordionItem question="Accesso negato. (HTTP 403) durante Start Payment">

  - Aggiorna alla versione **0.1.12 o successiva**, che corregge questo errore nelle sessioni WCPOS

  </AccordionItem>
  <AccordionItem question="Il registro dei terminali è vuoto">

  - È normale che il registro sia vuoto o che un terminale sia mostrato senza un identificatore WCPOS
  - I dati del registro sono solo informativi. Per i pagamenti viene usato il **Terminal serial number**

  </AccordionItem>
  <AccordionItem question="Un pagamento impiega troppo tempo">

  - Controlla lo schermo del terminale e lascia aperta la pagina di pagamento
  - Controlla le note dell'ordine e la dashboard PayArc prima di riprovare
  - La pagina controlla ogni **1.5 secondi** e si arresta dopo **5 minuti**

  </AccordionItem>
</Accordion>
