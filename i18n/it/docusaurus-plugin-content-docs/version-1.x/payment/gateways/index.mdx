# Gateway di pagamento {#payment-gateways}

WCPOS supporta diversi gateway di pagamento personalizzati che estendono le funzionalità del sistema punto vendita. Questi gateway sono progettati specificamente per gli ambienti POS e offrono un'integrazione fluida con vari metodi e servizi di pagamento.

## Gateway di pagamento personalizzati disponibili {#available-custom-gateways}

### Gateway per terminali hardware {#hardware-terminal-gateways}

- **[Stripe Terminal](./stripe-terminal.mdx)** - Accetta pagamenti con i lettori hardware Stripe Terminal
- **[SumUp Terminal](./sumup-terminal.mdx)** - Elabora pagamenti tramite i lettori di carte SumUp
- **[Square Terminal](./square-terminal.mdx)** - Accetta pagamenti in presenza sui dispositivi Square Terminal
- **[PayPal Reader (Zettle)](./paypal-reader.mdx)** - Accetta pagamenti con carta in presenza su un terminale PayPal Reader (Zettle)
- **[Mollie Terminal](./mollie-terminal.mdx)** - Accetta pagamenti in presenza sui dispositivi Mollie Terminal
- **[Mercado Pago Terminal](./mercadopago-terminal.mdx)** - Accetta pagamenti in presenza sui terminali Mercado Pago Point Smart (novità nella versione 0.1.0)
- **[Windcave Terminal](./windcave-terminal.mdx)** - Accetta pagamenti con carta in presenza sui terminali Windcave (novità nella versione 0.1.0)
- **[PayArc Terminal](./payarc-terminal.mdx)** - Accetta pagamenti in presenza sui terminali PayArc PAX

### Gateway di pagamento mobile {#mobile-payment-gateways}

- **[Vipps MobilePay](./vipps-mobilepay.mdx)** - Accetta pagamenti tramite telefono con codice QR o notifica push

### Gateway di pagamento digitali {#digital-payment-gateways}

- **[Fattura via email](./email-invoice.mdx)** - Invia fatture di pagamento ai clienti via email
- **[Checkout web](./web-checkout.mdx)** - Reindirizza i clienti per completare i pagamenti online

## Crea il tuo gateway di pagamento {#creating-your-own-gateway}

Se è necessario un gateway di pagamento personalizzato per requisiti specifici, è possibile utilizzare il nostro **[Modello di gateway](/reference/gateway-template)** per creare un gateway di pagamento WCPOS.

## Panoramica dell'installazione {#installation-overview}

Tutti i gateway personalizzati seguono una procedura di installazione simile:

1. **Scaricare** l'ultima versione dal rispettivo repository GitHub
2. **Installare** il plugin tramite `WP Admin > Plugin > Aggiungi Nuovo > Carica plugin`
3. **Configurare** le impostazioni del gateway in `WP Admin > WooCommerce > Impostazioni > Pagamenti`
4. **Attivare** il gateway in `WP Admin > POS > Impostazioni > Pagamento`
