## Nota Ordine {#order-note}

<div class="image-container">
  <Image
    alt="Nota Ordine nel POS"
    img="/img/order-note.png"
    style={{maxHeight: 500}}
  />

- Apre una finestra di dialogo per aggiungere all'ordine una nota destinata al cliente.
- Le note destinate al cliente sono visibili al cliente e compaiono per impostazione predefinita sulla ricevuta, nell'area Il mio account del cliente e in `WP Admin > WooCommerce > Orders > Order` sotto l'indirizzo di spedizione.

:::note
Le note sugli ordini sono visibili ai clienti.
:::

## Meta Ordine {#order-meta}

- Apre una finestra modale per gestire i metadati aggiuntivi dell'ordine.
- Le funzionalità includono:
  - Modifica della valuta dell'ordine.
  - Aggiunta di un ID transazione (ad esempio, da un terminale di pagamento esterno).
  - Aggiunta di metadati personalizzati per l'ordine.

:::note
Nel tempo verranno aggiunte altre funzionalità a questa finestra modale, inclusa l'integrazione con altri plugin WooCommerce.
:::

### Cosa sono i metadati in WooCommerce? {#what-is-meta-data-in-woocommerce}

I metadati forniscono informazioni aggiuntive sugli ordini e sono accessibili tramite l'API REST di WooCommerce. Sviluppatori e plugin usano questi dati per estendere le funzionalità, ad esempio integrando servizi di terze parti.

### Visualizzazione JSON {#json-view}

- Visualizza la rappresentazione JSON grezza dell'ordine, utile per il debug o per le integrazioni.

## Salva sul Server {#save-to-server}

- Consente di salvare i carrelli aperti sul server, in modo che siano conservati in sicurezza e accessibili in seguito.
- Crea un ordine WooCommerce con stato `pos-open`.

### Perché salvare? {#why-save}

Quando viene creato un nuovo ordine nel POS, esiste solo localmente. 
Salvare l'ordine garantisce che venga conservato anche se il database locale viene cancellato.

Consulta [Ordini Aperti](/1.x/pos/cart/open-orders) per ulteriori dettagli sulla gestione degli ordini salvati.

## Annulla {#void}

- Due scenari:
  - Ordini non salvati:
    - Se l'ordine non è stato salvato sul server, viene eliminato definitivamente dal database locale.
  - Ordini salvati:
    - Se l'ordine è stato salvato sul server, viene spostato nel Cestino di WooCommerce ed eliminato dal database locale.
- Per recuperare un ordine annullato:
  - Vai a `WP Admin > WooCommerce > Orders > Trash`.

## Cassa {#checkout}

- Salva l'ordine sul server e avvia il processo di pagamento.
- Apre la [schermata di pagamento](/1.x/pos/checkout) per completare il pagamento.
