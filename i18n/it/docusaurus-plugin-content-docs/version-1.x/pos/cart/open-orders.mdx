WCPOS consente di lavorare contemporaneamente con più ordini. Questa funzione è utile per gestire ordini in sospeso, passare da una transazione all'altra e riprendere il lavoro dopo un'interruzione.

## Carosello degli ordini aperti {#open-orders-carousel}

Nella parte inferiore del pannello del carrello, un carosello orizzontale mostra tutti gli ordini aperti:

{/* Screenshot: open-orders-carousel.png */}

- Ogni carrello mostra l'**importo totale**
- L'**ordine corrente** è evidenziato
- Fai clic su un carrello per passare a quell'ordine
- Scorri a sinistra o a destra per visualizzare altri carrelli

## Creare un nuovo ordine {#creating-a-new-order}

È sempre disponibile un nuovo carrello vuoto. Fai clic su un carrello vuoto nel carosello oppure inizia ad aggiungere prodotti quando il carrello corrente è vuoto.

## Passare da un ordine all'altro {#switching-between-orders}

Fai clic su un ordine nel carosello per passare a quell'ordine. Il pannello del carrello si aggiorna mostrando il contenuto dell'ordine selezionato.

**Casi d'uso:**

- Il cliente si allontana per prendere un altro articolo
- Devi assistere un cliente rapidamente mentre è in corso un ordine voluminoso
- Confrontare prezzi o articoli tra più ordini

## Salvare gli ordini sul server {#saving-orders-to-server}

Gli ordini possono trovarsi in due stati:

### Solo locale {#local-only}

Per impostazione predefinita, i nuovi ordini vengono salvati solo nel database locale del browser o dell'app. Rimangono disponibili dopo l'aggiornamento della pagina, ma:

- Non sono visibili nell'amministrazione di WooCommerce
- Vanno persi se il database locale viene cancellato
- Non sono accessibili da altri dispositivi

### Salvato sul server {#saved-to-server}

Fai clic su **Salva sul server** per creare un ordine WooCommerce con lo stato `pos-open`. In questo modo:

- Viene creato un ordine effettivo in WooCommerce
- L'ordine rimane disponibile anche se il database locale viene cancellato
- È possibile accedere all'ordine da altri dispositivi
- L'ordine compare in WP Admin > WooCommerce > Ordini

:::tip Quando salvare
Salva gli ordini sul server quando:
- Un cliente vuole mettere da parte un ordine per ritirarlo in seguito
- Stai terminando il turno e un altro cassiere continuerà a gestire l'ordine
- Vuoi avere una copia di sicurezza in caso di problemi con l'app o il browser
:::

## Recuperare gli ordini salvati {#recovering-saved-orders}

Se hai salvato gli ordini sul server, puoi accedervi di nuovo:

1. Aprendo la schermata **Ordini** (funzione Pro)
2. Filtrando per stato `pos-open`
3. Riaprendo l'ordine

## Persistenza degli ordini {#order-persistence}

### Archiviazione locale {#local-storage}

WCPOS archivia gli ordini nel database locale del dispositivo. Questo garantisce:

- La persistenza tra sessioni del browser
- Un accesso rapido senza richieste di rete
- La possibilità di lavorare offline

### Sincronizzazione con il server {#sync-with-server}

Quando salvi sul server o completi il pagamento:

- L'ordine viene inviato a WooCommerce
- Viene ricevuta una conferma
- I dati locali e quelli del server vengono sincronizzati

## Annullare gli ordini {#voiding-orders}

Per rimuovere un ordine aperto:

1. Passa all'ordine che vuoi rimuovere
2. Fai clic sul pulsante **Annulla**

**Cosa succede:**

- **Ordini non salvati:** vengono eliminati definitivamente dal database locale
- **Ordini salvati:** vengono spostati nel cestino di WooCommerce ed eliminati localmente

Per recuperare un ordine salvato annullato:
1. Vai a `WP Admin > WooCommerce > Orders > Trash`
2. Ripristina l'ordine

## Suggerimenti {#tips}

### Organizzare gli ordini {#keep-orders-organized}

Quando ci sono più ordini aperti, può essere utile:

- Aggiungere i nomi dei clienti agli ordini per identificarli facilmente
- Aggiungere note all'ordine che descrivano il motivo della sospensione
- Salvare sul server gli ordini importanti

### Passaggio di consegne tra turni {#shift-handoffs}

Quando termini un turno con ordini aperti:

1. Salva sul server tutti gli ordini importanti
2. Aggiungi note all'ordine che ne spieghino lo stato
3. Il cassiere del turno successivo può accedervi dalla schermata Ordini

### Considerazioni sulla modalità offline {#offline-considerations}

Se perdi la connessione:

- Gli ordini locali restano accessibili e puoi continuare ad aggiungere articoli
- Puoi completare un ordine con un metodo di pagamento utilizzabile offline; i gateway che dipendono dal server non sono disponibili finché i relativi servizi non sono raggiungibili
- Non puoi salvare gli ordini sul server finché la connessione non viene ripristinata
- Non puoi creare nuovi clienti finché la connessione non viene ripristinata
