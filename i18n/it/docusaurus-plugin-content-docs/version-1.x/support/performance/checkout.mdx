Se stai riscontrando prestazioni lente durante il processo di checkout, questa guida ti aiuterà a identificare e risolvere le cause più comuni.

## Come Funziona il Checkout di WCPOS {#how-wcpos-checkout-works}

Il checkout di WCPOS apre un modale con un iframe/webview che carica una versione semplificata del WooCommerce Order Pay template. Questa è essenzialmente la stessa pagina della [Customer Payment page](https://woocommerce.com/document/managing-orders/paying-for-orders/#customer-payment-page-link) che i clienti vedono quando pagano gli ordini online.

:::info Nota per gli Sviluppatori
Puoi visualizzare il modello di checkout nel repository del plugin WCPOS: [templates/payment.php](https://github.com/wcpos/woocommerce-pos/blob/main/templates/payment.php)
:::

## Ottimizzazioni Incorporate {#built-in-optimizations}

WCPOS include diverse ottimizzazioni per migliorare le prestazioni del checkout:

- **Modello snellito** - Rimuove elementi e disordine inutili del tema
- **Caricamento selettivo di script/stile** - Vengono caricati solo script e stili essenziali
- **Struttura DOM minimale** - Riduce la complessità della pagina di checkout

Tuttavia, alcuni script e stili non possono essere completamente disabilitati poiché i gateway di pagamento potrebbero richiederli per funzionare correttamente.

## Problemi Comuni di Prestazioni {#common-performance-issues}

### 1. Script e Stili Inutili {#1-unnecessary-scripts-and-styles}

**Problema:** Temi e plugin aggiungono script e stili non necessari per il checkout, rallentando i tempi di caricamento della pagina.

**Soluzione:** Usa le [Impostazioni di Checkout](/pos/checkout#checkout-settings-troubleshooting) per disabilitare risorse inutili:

1. Clicca il pulsante **Impostazioni di Checkout** nel modale di checkout
2. Prova prima a disabilitare gli stili del tema:
   - wp-block-library
   - classic-theme-styles
   - Gli stili personalizzati del tuo tema
3. Disabilita script di WooCommerce non essenziali:
   - wc-add-to-cart
   - selectWoo (se non necessario dal tuo gateway)
   - html5shiv

### 2. Interferenze dei plugin durante la creazione degli ordini {#2-plugin-interference-during-order-creation}

**Problema:** I plugin che si agganciano al processo di creazione degli ordini possono causare ritardi significativi. Ad esempio, i plugin di contabilità come Xero possono inviare i dati degli ordini a server esterni, bloccando il processo di checkout.

**Passaggi per la risoluzione dei problemi:**

1. **Esegui un test in staging** - Se hai un server di staging, disattiva tutti i plugin tranne WooCommerce e WCPOS
2. **Verifica la velocità del checkout** - Elabora un ordine di prova e annota le prestazioni
3. **Riattiva i plugin gradualmente** - Se le prestazioni migliorano notevolmente, riattiva i plugin uno alla volta per individuare il responsabile
4. **Contatta gli sviluppatori del plugin** - Se un plugin specifico causa problemi, contatta il relativo sviluppatore per ricevere consigli sull'ottimizzazione

**Tipi di plugin che causano spesso problemi:**
- Integrazioni di contabilità e tenuta dei registri (Xero, QuickBooks)
- Strumenti di email marketing che si attivano alla creazione di un ordine
- Sistemi di gestione dell'inventario
- Calcolatori di spedizione complessi
- Strumenti di analisi di terze parti

### 3. Limiti delle risorse del server {#3-server-resource-limitations}

**Problema:** Se il server è sotto carico o non dispone di risorse sufficienti, tutte le operazioni, incluso il checkout, saranno lente.

**Monitoraggio e soluzioni:**

1. **Monitora le prestazioni del server:**
   - Utilizzo della CPU durante il checkout
   - Consumo di memoria
   - Prestazioni delle query del database
   - Latenza della rete

2. **Ottimizza le risorse del server:**
   - Aumenta il limite di memoria di PHP
   - Ottimizza le query del database
   - Usa plugin di caching (verificandone la compatibilità)
   - Valuta un piano di hosting superiore

3. **Ottimizzazione del database:**
   - Pulisci i dati degli ordini meno recenti
   - Ottimizza le tabelle del database
   - Rimuovi plugin e temi non necessari

## Buone pratiche per gli sviluppatori WordPress {#wordpress-developer-best-practices}

:::tip Per gli sviluppatori
Gli sviluppatori WordPress dovrebbero usare `wp_enqueue_scripts` per aggiungere correttamente script e stili alle pagine. Purtroppo, alcuni sviluppatori di plugin e temi non seguono le buone pratiche e inseriscono il codice direttamente nei template, rendendo impossibile rimuovere facilmente queste risorse dalla coda.
:::

Se riscontri problemi con script o stili che non possono essere disattivati tramite le impostazioni di Checkout:

1. **Contatta lo sviluppatore** - Chiedigli di seguire gli standard di codifica di WordPress
2. **Usa temi child** - Sovrascrivi i template problematici in un tema child
3. **Hook personalizzati** - Usa gli hook di WordPress per rimuovere il codice problematico dalle pagine di checkout

## Test delle prestazioni {#performance-testing}

Per verificare i miglioramenti delle prestazioni del checkout:

1. **Misura di riferimento** - Cronometra la durata del checkout prima di apportare modifiche
2. **Apporta una modifica alla volta** - In questo modo puoi individuare quali modifiche hanno l'impatto maggiore
3. **Esegui test con gateway di pagamento reali** - Non limitarti ai pagamenti in contanti
4. **Esegui test su dispositivi diversi** - I dispositivi mobili possono mostrare caratteristiche prestazionali diverse

## Miglioramenti rapidi {#quick-wins}

Ecco i miglioramenti più efficaci che puoi apportare alle prestazioni:

1. **Disattiva gli stili del tema** - Spesso offre il miglioramento maggiore
2. **Rimuovi gli script WooCommerce non necessari** - Riduce il tempo di esecuzione JavaScript
3. **Controlla gli hook di creazione degli ordini** - Individua e ottimizza i plugin lenti
4. **Ottimizza le immagini** - Assicurati che tutte le immagini nel checkout siano ottimizzate
5. **Usa un plugin di monitoraggio delle prestazioni** - Tieni traccia dei miglioramenti nel tempo

## Quando chiedere aiuto {#when-to-seek-help}

Contatta il supporto WCPOS se:

- Il checkout richiede regolarmente più di 10 secondi
- Hai seguito questa guida ma riscontri ancora problemi
- Sospetti un plugin specifico ma non riesci a individuarlo
- Hai bisogno di aiuto per ottimizzare le risorse del server
