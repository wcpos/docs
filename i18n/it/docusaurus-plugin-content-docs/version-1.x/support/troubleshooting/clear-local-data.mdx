WCPOS memorizza una copia locale dei tuoi prodotti, ordini e clienti in modo che il POS possa funzionare rapidamente e operare offline. Occasionalmente, questi dati locali possono non essere più sincronizzati con il tuo negozio WooCommerce. Cancellare tutti i dati locali rimuove il database locale e avvia una nuova sincronizzazione dal tuo server.

:::tip Prova prima una reimpostazione mirata (v1.10.0+)
Dalla v1.10.0, **Stato del negozio → Database** offre **Cancella e riscarica** per ogni collezione — rimuove e riscarica soltanto la collezione che sta dando problemi (per esempio i prodotti), senza toccare nient'altro e senza disconnetterti. La conferma indica quanti record verranno rimossi e conferma che la copia sul tuo server resta invariata. Tieni presente che è normale che le collezioni scaricate su richiesta mostrino un conteggio basso subito dopo una reimpostazione e si ripopolino man mano che vengono usate — è il comportamento previsto, non una sincronizzazione bloccata. Vedi [Stato del negozio](/1.x/support/store-health#clear-and-redownload).
:::

:::warning
Questa è la soluzione più drastica. Cancellare i dati locali elimina tutto ciò che è memorizzato sul dispositivo e forza una nuova sincronizzazione completa. A seconda delle dimensioni del tuo negozio, l'operazione può richiedere del tempo. Usala solo quando altre opzioni — una normale [sincronizzazione](/1.x/products/sync) o l'opzione **Cancella e riscarica** per singola collezione — non hanno risolto il problema.

Prima di cancellare, controlla il riquadro **modifiche in attesa di essere inviate** in **Stato del negozio → Database** — cancellare i dati locali elimina definitivamente qualsiasi modifica non ancora inviata presente sul dispositivo.
:::

## Quando usarla {#when-to-use-it}

Potresti dover cancellare i dati locali nei seguenti casi:

- **Problemi di sincronizzazione** — prodotti, ordini o clienti non si aggiornano correttamente
- **Dopo un aggiornamento del plugin** — per garantire la compatibilità con le nuove strutture di dati
- **Dati obsoleti** — prezzi, livelli delle scorte o altre informazioni sembrano non aggiornati

## Cosa viene cancellato {#what-gets-cleared}

| Cancellato | Non cancellato |
|---------|-------------|
| Database locale dei prodotti | Dati lato server |
| Database locale degli ordini | Impostazioni di WooCommerce |
| Database locale dei clienti | |
| Sessione di accesso | |

I dati del tuo negozio WooCommerce restano invariati — viene rimossa solo la copia locale sul tuo dispositivo. Una nuova sincronizzazione inizia automaticamente dopo la cancellazione.

:::info Differenza tra piattaforme
- **App desktop:** verrai disconnesso e dovrai ricollegare il tuo negozio.
- **App web:** i dati di accesso vengono cancellati, ma poiché sei ancora connesso a WP Admin la sessione viene ripristinata automaticamente — quindi non noterai la disconnessione.
:::

## Come cancellare i dati locali {#how-to-clear-local-data}

### Web {#web}

1. Clicca sul tuo **menu utente** in alto a destra per aprire il menu
2. Clicca su **Cancella Tutti i Dati Locali**
3. Il database locale verrà eliminato e una nuova sincronizzazione inizierà automaticamente

### Desktop {#desktop}

1. Apri il menu dell'applicazione **WCPOS** nella barra dei menu in alto
2. Passa il mouse su **Avanzate**
3. Clicca su **Cancella Dati App**
4. Il database locale verrà eliminato e una nuova sincronizzazione inizierà automaticamente

:::note
Tutte le piattaforme memorizzano i dati nello stesso formato di database locale (archiviazione su file basata su OPFS dalla v1.10.0). Il database viene cancellato completamente su ogni piattaforma, ma il comportamento di accesso differisce — vedi la nota sulla differenza tra piattaforme sopra.
:::
