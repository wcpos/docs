:::info Funzionalità Pro
[WCPOS Pro](https://wcpos.com/pro) è un plugin a pagamento che alimenta le schermate di gestione, gateway di pagamento aggiuntivi e altre funzionalità disponibili solo nella versione Pro di WCPOS.

**A partire dalla v1.8+, Pro è un plugin autonomo** — non è necessario avere installato accanto ad esso il [plugin WCPOS](https://wordpress.org/plugins/woocommerce-pos/) gratuito.
:::

## Cosa include Pro? {#whats-included-in-pro}

WCPOS Pro sblocca funzionalità aggiuntive:

- **Schermata Prodotti** - Modifica le scorte e i prezzi direttamente nel POS
- **Schermata Ordini** - Visualizza e gestisci la cronologia degli ordini
- **Schermata Clienti** - Aggiungi e modifica le informazioni dei clienti
- **Schermata Report** - Genera report delle vendite di fine giornata
- **Gateway di pagamento aggiuntivi** - Stripe Terminal, SumUp e gateway personalizzati

## Installazione {#installation}

Se hai acquistato una licenza per WCPOS Pro, segui i passaggi seguenti per installare e attivare il plugin:

:::note Aggiornamento da versioni precedenti?
Se in precedenza avevi installato sia il plugin gratuito WCPOS sia un vecchio componente aggiuntivo Pro, **disattiva ed elimina il plugin gratuito** prima di attivare il nuovo plugin Pro autonomo. L'esecuzione contemporanea dei due plugin può causare errori di attivazione come *"Invalid response fetching remote state"* o errori fatali *"Class not found"*.
:::

1. Vai a: [https://wcpos.com/account/downloads](https://wcpos.com/account/downloads)
2. Nella sezione **Downloads**, fai clic sul link per scaricare e salva il plugin sul desktop.
3. Poi vai al tuo sito, accedi e vai a `WP Admin > Plugin > Add Plugin > Carica plugin`
4. Carica il file zip del plugin dal desktop e attivalo.
5. Poi vai a `WP Admin > POS > Impostazioni > License` e inserisci la chiave di licenza (visibile nella [pagina delle licenze](https://wcpos.com/account/licenses)) e l'indirizzo email associato alla licenza per completare l'attivazione.

## Aggiornamenti {#updates}

Quando sono disponibili nuove versioni, appariranno nella bacheca Aggiornamenti come per qualsiasi altro plugin. Puoi anche scaricare la versione più recente dalla [pagina del tuo account](https://wcpos.com/account/downloads).

## Disinstallare Pro e i tuoi dati {#uninstalling}

La disinstallazione del plugin Pro rimuove i dati operativi propri di Pro, ma **mantiene le impostazioni Pro (inclusa la chiave di licenza) e la configurazione del negozio**, così, reinstallandolo, puoi riprendere da dove avevi lasciato. I dati di traduzione condivisi vengono rimossi solo dopo aver disinstallato anche il plugin **gratuito**; quindi, la sola rimozione di Pro non influisce mai sul plugin gratuito.

Se vuoi ripartire davvero da zero, rimuovendo anche impostazioni, licenza e configurazione del negozio, scegli la cancellazione completa definendo `wcpos_remove_all_data` prima della disinstallazione. In caso contrario, la disinstallazione è sicura e reversibile.

## Risoluzione dei problemi {#troubleshooting}

### Errori di attivazione {#activation-failures}

- **"Chiave di licenza non valida"** — quando incolli la chiave, controlla che non ci siano spazi finali e verifica che l'indirizzo email corrisponda a quello usato per l'acquisto.
- **"Limite di licenze raggiunto"** — per impostazione predefinita, una licenza si attiva su **2 domini** (pensati per un sito live e uno di staging). Nota che i **sottodomini contano come attivazioni separate**: `example.com`, `staging.example.com` e `dev.example.com` sono tre. Questo problema si presenta spesso con hosting come Pantheon, che impongono ambienti dev/test/live. Disattiva i siti inutilizzati dalla [pagina del tuo account](https://wcpos.com/account/licenses) oppure scrivi a **support@wcpos.com**: su richiesta vengono spesso concesse attivazioni aggiuntive.

### Licenza scaduta {#expired-licence}

- Quando una licenza scade, le funzionalità Pro restano attive, ma non riceverai aggiornamenti.
- Rinnova dalla [pagina del tuo account](https://wcpos.com/account/licenses): la chiave esistente rimane invariata.

### Trasferimenti di dominio {#domain-transfers}

- Se hai spostato il sito su un nuovo dominio, disattiva prima la licenza sul vecchio dominio, poi riattivala su quello nuovo.
- Se il vecchio dominio non è più accessibile, contatta **support@wcpos.com** per reimpostare l'attivazione.

### Connessione al server delle licenze {#licence-server-connectivity}

- Per l'attivazione, il server WordPress deve poter raggiungere il server delle licenze WCPOS.
- Se l'attivazione non riesce senza mostrare errori, verifica che il firewall del tuo hosting o un plugin di sicurezza non blocchi le richieste HTTPS in uscita.
- Alcuni hosting gestiti bloccano per impostazione predefinita le chiamate API esterne: contatta il tuo provider e chiedi di autorizzare `wcpos.com`.

### Verificare lo stato della licenza {#checking-licence-status}

- Vai a `WP Admin > POS > Impostazioni > License` per visualizzare lo stato attuale dell'attivazione.
- La [pagina del tuo account](https://wcpos.com/account/licenses) mostra tutti i siti attivi e la data di scadenza.

## Acquistare una licenza {#purchase-a-license}

Visita [wcpos.com/pro](https://wcpos.com/pro) per acquistare una licenza Pro.

:::note Gli acquisti e gli upgrade si effettuano sul sito web
Non esiste un pulsante in-app "passa a Pro": gli acquisti, gli upgrade del piano e i rinnovi si gestiscono su [wcpos.com](https://wcpos.com/pro) e nella [pagina del tuo account](https://wcpos.com/account/licenses). Dopo l'acquisto, installa Pro seguendo i [passaggi precedenti](#installation).
:::
