:::info Funzionalità Pro
[WCPOS Pro](https://wcpos.com/pro) è un plugin a pagamento che alimenta le schermate di gestione, gateway di pagamento aggiuntivi e altre funzionalità disponibili solo nella versione Pro di WCPOS.

**A partire dalla v1.8+, Pro è un plugin autonomo** — non è necessario avere installato accanto ad esso il [plugin WCPOS](https://wordpress.org/plugins/woocommerce-pos/) gratuito.
:::

## Cosa include Pro? {#whats-included-in-pro}

WCPOS Pro sblocca funzionalità aggiuntive:

- **Schermata Prodotti** - Modifica i livelli di scorte e i prezzi direttamente nel POS
- **Schermata Ordini** - Visualizza e gestisci la cronologia degli ordini
- **Schermata Clienti** - Aggiungi e modifica le informazioni dei clienti
- **Schermata Report** - Genera report sulle vendite di fine giornata
- **Gateway di pagamento aggiuntivi** - Stripe Terminal, SumUp e gateway personalizzati

## Installazione {#installation}

Se hai acquistato una licenza per WCPOS Pro, segui i passaggi riportati di seguito per installare e attivare il plugin:

:::note Aggiornamento da versioni precedenti?
Se in precedenza avevi installato sia il plugin gratuito WCPOS sia un componente aggiuntivo Pro più vecchio, **disattiva ed elimina il plugin gratuito** prima di attivare il nuovo plugin Pro autonomo. Eseguire entrambi affiancati può causare errori di attivazione come *"Invalid response fetching remote state"* o errori fatali *"Class not found"*.
:::

1. Vai a: [https://wcpos.com/my-account/](https://wcpos.com/my-account/)
2. In **Downloads**, fai clic sul link di download e salva il plugin sul desktop.
3. Quindi vai al tuo sito, accedi e vai su `WP Admin > Plugins > Add Plugin > Upload Plugin`
4. Carica il file zip del plugin dal desktop e attivalo.
5. Successivamente, vai su `WP Admin > POS > Settings > License` e inserisci la chiave di licenza e l'email della licenza per completare l'attivazione.

![I miei download](https://wcpos.com/wp-content/uploads/2014/07/my-download.png "Puoi scaricare WCPOS Pro dalla pagina del tuo account")

## Aggiornamenti {#updates}

Quando saranno pronte nuove versioni, appariranno nella tua bacheca Aggiornamenti come qualsiasi altro plugin. Puoi anche scaricare la versione più recente dalla [pagina del tuo account](https://wcpos.com/my-account/).

## Disinstallazione di Pro e i tuoi dati {#uninstalling}

La disinstallazione del plugin Pro rimuove i dati operativi propri di Pro, ma **conserva le impostazioni Pro (inclusa la chiave di licenza) e la configurazione del negozio**, così che la reinstallazione riprenda da dove avevi lasciato. I dati di traduzione condivisi vengono rimossi solo dopo che è stato disinstallato anche il plugin **gratuito**, quindi rimuovere solo Pro non disturba mai il plugin gratuito.

Se desideri un vero e proprio azzeramento — rimuovendo anche impostazioni, licenza e configurazione del negozio — opta per una cancellazione completa definendo `wcpos_remove_all_data` prima della disinstallazione. Senza di essa, la disinstallazione è sicura e reversibile.

## Risoluzione dei problemi {#troubleshooting}

### Errori di attivazione {#activation-failures}

- **"Chiave di licenza non valida"** — verifica che non ci siano spazi finali quando incolli la chiave e conferma che l'indirizzo email corrisponda a quello usato al momento dell'acquisto.
- **"Limite di licenza raggiunto"** — per impostazione predefinita una licenza si attiva su **2 domini** (pensati per un sito di produzione e un sito di staging). Tieni presente che **i sottodomini contano come attivazioni separate** — `example.com`, `staging.example.com` e `dev.example.com` sono tre. Questo spesso crea problemi con host come Pantheon, che prevedono ambienti dev/test/live obbligatori. Disattiva i siti inutilizzati dalla [pagina del tuo account](https://wcpos.com/my-account/), oppure invia un'email a **support@wcpos.com** — le attivazioni aggiuntive vengono normalmente concesse su richiesta.

### Licenza scaduta {#expired-licence}

- Quando una licenza scade, le funzionalità Pro restano attive, ma non riceverai aggiornamenti.
- Rinnova dalla [pagina del tuo account](https://wcpos.com/my-account/) — la chiave esistente rimane la stessa.

### Trasferimenti di dominio {#domain-transfers}

- Se hai spostato il tuo sito su un nuovo dominio, disattiva prima la licenza sul vecchio dominio, quindi riattivala su quello nuovo.
- Se il vecchio dominio non è più accessibile, contatta **support@wcpos.com** per reimpostare l'attivazione.

### Connettività del server delle licenze {#licence-server-connectivity}

- L'attivazione richiede che il tuo server WordPress possa raggiungere il server delle licenze WCPOS.
- Se l'attivazione fallisce senza mostrare messaggi, verifica che le richieste HTTPS in uscita non siano bloccate dal firewall del tuo host o da un plugin di sicurezza.
- Alcuni host gestiti bloccano per impostazione predefinita le chiamate API esterne — contatta il tuo host per inserire `wcpos.com` nella lista consentita.

### Verifica dello stato della licenza {#checking-licence-status}

- Vai su `WP Admin > POS > Settings > License` per vedere lo stato di attivazione corrente.
- La [pagina del tuo account](https://wcpos.com/my-account/) mostra tutti i siti attivi e la data di scadenza.

## Acquistare una licenza {#purchase-a-license}

Visita [wcpos.com/pro](https://wcpos.com/pro) per acquistare una licenza Pro.

:::note L'acquisto e l'upgrade avvengono sul sito web
Non c'è alcun pulsante "aggiorna a Pro" nell'app — acquisti, upgrade di piano e rinnovi sono tutti gestiti su [wcpos.com](https://wcpos.com/pro) e nella [pagina del tuo account](https://wcpos.com/my-account/). Dopo l'acquisto, installa Pro seguendo i [passaggi precedenti](#installation).
:::
