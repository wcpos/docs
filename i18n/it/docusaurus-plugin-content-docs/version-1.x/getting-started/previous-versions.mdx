## Re-installare una versione precedente {#re-installing-a-previous-version}

Se hai bisogno di tornare a una versione precedente del plugin WCPOS, segui questi passaggi:

1. Visita la pagina di WordPress.org [Visualizzazione Avanzata](https://wordpress.org/plugins/woocommerce-pos/advanced/) per WCPOS.

2. Scorri fino alla sezione **Opzioni avanzate** e individua il menu a discesa **Versioni precedenti**.

3. Apri il menu a discesa per visualizzare l'elenco delle versioni del plugin disponibili. Trova la versione che vuoi installare e fai clic sul pulsante **Scarica** accanto. Salva il file scaricato sul desktop o in una posizione comoda.

4. Accedi alla bacheca di amministrazione di WordPress.

5. Vai alla pagina **Plugin** facendo clic su **Plugin** nel menu a sinistra.

6. Disattiva ed elimina la versione attuale del plugin WCPOS. Il plugin verrà rimosso dall'installazione di WordPress. Non preoccuparti: i tuoi dati non andranno persi.

7. Fai clic sul pulsante **Aggiungi plugin** nella parte superiore della pagina.

8. Nella pagina **Aggiungi plugin**, fai clic sul pulsante **Carica plugin**.

9. Seleziona il file del plugin scaricato in precedenza dal desktop o dalla posizione in cui l'hai salvato.

10. Fai clic su **Installa ora** e attendi il completamento dell'installazione.

11. Al termine dell'installazione, fai clic su **Attiva** per attivare la versione precedente del plugin WCPOS.

Ecco fatto! Hai reinstallato correttamente una versione precedente del plugin WCPOS.

Se riscontri problemi durante la reinstallazione o hai bisogno di ulteriore assistenza, contatta il nostro team di supporto all'indirizzo support@wcpos.com.
