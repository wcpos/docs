## इसका क्या मतलब है {#what-this-means}

स्टोर के API की जगह बॉट सुरक्षा पृष्ठ जवाब दे रहा है।

जहाँ ऐप को JSON चाहिए, वहाँ स्टोर का REST API एक HTML सत्यापन पृष्ठ (बॉट सुरक्षा, CAPTCHA या DDoS का मध्यवर्ती पृष्ठ) लौटा रहा है। पॉइंट-ऑफ़-सेल ऐप ब्राउज़र का सत्यापन पूरा नहीं कर सकता; स्टोर के REST API को सुरक्षा सेवा की अनुमति सूची में जोड़ना होगा।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद का डेटा प्रभावित नहीं होता।

## समस्या निवारण {#troubleshoot}

1. सत्यापन पृष्ठ से सुरक्षा परत की पहचान करें (Cloudflare, Sucuri, Kinsta और अन्य सेवाएँ अपना ब्रांड दिखाती हैं) और उसकी सेटिंग्स खोलें।
2. API ट्रैफ़िक के लिए स्टोर के अपने REST API पथ (/wp-json/ और /?rest_route=) अनुमति सूची में जोड़ें।
3. Cloudflare पर REST API पथों के लिए WAF **छोड़ें** नियम जोड़ें; बॉट फ़ाइट मोड (मुफ़्त प्लान) को किसी नियम से बायपास नहीं किया जा सकता, इसलिए उसे बंद करना होगा। [Cloudflare गाइड](/troubleshooting/common-problems/cloudflare) में सटीक नियम और `curl` से जाँच दी गई है।
4. Kinsta की बॉट/फ़ायरवॉल सेटिंग्स में REST API पथ अनुमति सूची में जोड़ें; Sucuri पर API रूट के लिए JavaScript सत्यापन वाला DDoS मोड इस्तेमाल न करें।
