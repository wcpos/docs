## इसका क्या अर्थ है {#what-this-means}

स्टोर के REST API ने पते के किसी भी ऐसे रूप पर जवाब नहीं दिया जिसका यह ऐप उपयोग कर सकता है।

ऐप ने स्टोर के REST API को उसके सामान्य पते (/wp-json/...) और WordPress के अंतर्निहित वैकल्पिक पते (/?rest_route=...) पर आज़माया, लेकिन दोनों में से किसी ने जवाब नहीं दिया। स्टोर की वेबसाइट खुद चालू हो सकती है — यह समस्या विशेष रूप से REST API तक न पहुँच पाने की है, आम तौर पर कोई सुरक्षा प्लगइन इसे छिपा रहा होता है या कोई फ़ायरवॉल नियम इसे रोक रहा होता है।

## आपका डेटा {#your-data}

किसी भी ऑर्डर या उत्पाद का डेटा प्रभावित नहीं होता।

## समस्या निवारण {#troubleshoot}

**स्टोर पर** — साइट प्रशासक के लिए: यदि कोई सुरक्षा प्लगइन `/wp-json/` को छिपाता है या उसका नाम बदलता है (जैसे WP Hide), तो WordPress के अंतर्निहित `/?rest_route=` रूप को भी अनुमति दें — ऐप अपने आप उसे वैकल्पिक तरीके के रूप में इस्तेमाल करता है।

**होस्ट / सर्वर पर:**

1. फ़ायरवॉल (WAF) नियमों में `wp-json` या `rest_route` से मेल खाने वाले नियम जाँचें और स्टोर के अपने REST API को अनुमति दें।
2. यदि सर्वर के आगे रखरखाव पृष्ठ या बॉट जाँच है, तो REST अनुरोधों के जवाब में HTML पृष्ठ आ सकता है — REST API के लिए यह जाँच बंद करें।

**जाँच करने के लिए (कोई भी):** `https://your-store.com/?rest_route=/` से JSON मिलना चाहिए, 403 पृष्ठ या साइट का मुखपृष्ठ नहीं।
