## इसका क्या मतलब है {#what-this-means}

होस्ट का सुरक्षा फ़िल्टर उत्पादों की खोज अवरुद्ध कर रहा है।

इस होस्ट का एक फ़ायरवॉल नियम उन REST अनुरोधों को अस्वीकार करता है जिनकी क्वेरी स्ट्रिंग में गैर-ASCII अक्षर या SQL जैसे शब्द हों। उच्चारण चिह्न वाले उत्पाद नाम और 'select' या 'union' जैसे शब्दों वाली खोजें 403 के साथ विफल होंगी, भले ही वे सामान्य कैटलॉग खोजें हों। बिक्री काउंटर का बाकी काम चलता है; नियम में छूट दिए जाने तक खोज भरोसेमंद नहीं होगी।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद का डेटा प्रभावित नहीं होता।

## समस्या निवारण {#troubleshoot}

1. होस्ट से क्वेरी-स्ट्रिंग फ़ायरवॉल नियमों में स्टोर के अपने REST खोज पैरामीटर (/wcpos/ और /wc/ रूट) को अनुमति सूची में जोड़ने को कहें।
2. OWASP CRS पर आधारित फ़ायरवॉल में आम तौर पर 's' और 'search' आर्ग्युमेंट पर लागू SQL-इंजेक्शन नियम इसका कारण होते हैं — REST API रूट के लिए इन आर्ग्युमेंट को उन नियमों से बाहर रखें।
3. जिन सुरक्षा प्लगइन में 'संदिग्ध क्वेरी स्ट्रिंग फ़िल्टर करें' टॉगल है, उनमें REST API के लिए अपवाद चाहिए, पूरी सुरक्षा बंद करने की ज़रूरत नहीं है।
