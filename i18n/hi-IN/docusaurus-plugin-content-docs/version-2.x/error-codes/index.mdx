# त्रुटि कोड {#error-codes}

WCPOS में कोई समस्या आने पर एक त्रुटि कोड दिखाई देता है, जिससे समस्या पहचानने में मदद मिलती है। **v1.10.0** से कोड का प्रारूप **डोमेन + तीन अंक** है — जैसे `SYNC131` या `AUTH311`। डोमेन POS के संबंधित क्षेत्र का नाम बताता है; संख्या विशिष्ट स्थिति की पहचान करती है। हर कोड का अपना पृष्ठ है, जिसमें उसका अर्थ, उठाए जाने वाले कदम और आपके डेटा पर उसका प्रभाव बताया गया है।

POS में त्रुटि कोड **स्टोर की स्थिति → लॉग** में दिखाई देते हैं: किसी पंक्ति को विस्तृत करें और **सहायता** लिंक से यहाँ उस कोड के पृष्ठ पर सीधे जाएँ।

## त्रुटि डोमेन (v1.10.0+) {#error-domains}

| डोमेन | क्षेत्र |
|--------|------|
| [`AUTH`](#auth) | लॉगिन, सत्र और टोकन |
| [`CHECKOUT`](#checkout) | काउंटर पर ऑर्डर पूरे करना |
| [`CLIENT`](#client) | POS ऐप और स्थानीय स्टोरेज |
| [`DISPLAY`](#display) | ग्राहक के लिए डिस्प्ले |
| [`HOST`](#host) | POS को ब्लॉक करने वाले होस्टिंग और फ़ायरवॉल नियम |
| [`LICENSE`](#license) | Pro लाइसेंस का सक्रियण और सत्यापन |
| [`PAYMENT`](#payment) | भुगतान गेटवे और टर्मिनल |
| [`PRINT`](#print) | रसीद प्रिंट करना |
| [`PRODUCT`](#product) | उत्पाद डेटा और कैटलॉग संबंधी कार्य |
| [`REGISTER`](#register) | नकदी दराज़, रजिस्टर सत्र और गिनती |
| [`SYNC`](#sync) | POS और आपके स्टोर के बीच सिंक |

नीचे अपना कोड ढूँढें या उसे खोजें।

जिन कोड के अंत में `999` होता है, वे उस डोमेन की ऐसी सभी स्थितियों के लिए हैं जिनका अभी कोई विशिष्ट कोड नहीं है।
