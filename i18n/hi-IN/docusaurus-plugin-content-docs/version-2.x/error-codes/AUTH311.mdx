## इसका क्या अर्थ है {#what-this-means}

WCPOS आपके स्टोर पर अपने कनेक्शन बिंदु तक नहीं पहुँच पा रहा है।

अपने साइट एडमिन से जाँचने को कहें कि WCPOS प्लगइन सक्रिय है (**WP Admin → प्लगइन्स**) और कोई सुरक्षा प्लगइन REST API को ब्लॉक नहीं कर रहा है।

## आपका डेटा {#your-data}

किसी भी ऑर्डर या उत्पाद के डेटा पर असर नहीं पड़ता। अपने साइट एडमिन को बताएँ।

## समस्या निवारण {#troubleshoot}

**काउंटर पर** — कैशियर के लिए: अपने साइट एडमिन को बताएँ। इस डिवाइस पर किसी चीज़ पर असर नहीं पड़ता।

**स्टोर पर** — साइट एडमिन के लिए:

1. पुष्टि करें कि WCPOS सक्रिय है: WP Admin → प्लगइन्स।
2. अगर REST के दोनों रूपों में से कोई भी काम नहीं करता, तो जाँचें कि क्या कोई सुरक्षा प्लगइन, प्रॉक्सी या CDN WCPOS अनुरोध के हेडर हटा रहा है या REST अनुरोधों को ब्लॉक कर रहा है—आमतौर पर फ़ायरवॉल नियम और REST API बंद करने वाले सुरक्षा विकल्प इसकी वजह होते हैं।
3. कुछ होस्ट पर पर्मालिंक दोबारा सहेजने से (सेटिंग्स → पर्मालिंक → सहेजें) गायब REST रूट वापस आ जाते हैं।
