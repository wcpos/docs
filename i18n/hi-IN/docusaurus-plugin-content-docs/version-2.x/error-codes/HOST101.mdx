## इसका क्या अर्थ है {#what-this-means}

सर्वर ब्राउज़र की अनुमति जाँच (CORS प्रीफ़्लाइट) को रोक रहा है, इसलिए वेब ऐप उससे संपर्क नहीं कर पा रहा है।

कस्टम हेडर वाली किसी भी क्रॉस-ओरिजिन API कॉल से पहले ब्राउज़र OPTIONS अनुरोध भेजते हैं। इस स्टोर तक पहुँचने के रास्ते में कोई चीज़—आमतौर पर फ़ायरवॉल का कोई नियम—OPTIONS को रोक रही है, इसलिए ब्राउज़र असली अनुरोध भेजता ही नहीं। नेटिव ऐप पर इसका असर नहीं पड़ता; इसे सर्वर पर ठीक करना होगा।

## आपका डेटा {#your-data}

किसी भी ऑर्डर या उत्पाद के डेटा पर असर नहीं पड़ता।

## समस्या निवारण {#troubleshoot}

1. फ़ायरवॉल (WAF) में जाँचें कि कोई नियम OPTIONS मेथड को रोक तो नहीं रहा है, और /wcpos/ REST रूट पर इसकी अनुमति दें।
2. कुछ सुरक्षा प्लगइन में 'असामान्य अनुरोध मेथड रोकें' टॉगल होता है—OPTIONS की अनुमति बनी रहनी चाहिए।
3. परीक्षण करें: स्टोर के REST API को भेजे गए OPTIONS अनुरोध के जवाब में 403 नहीं आना चाहिए।
4. डेस्कटॉप और मोबाइल ऐप CORS का उपयोग नहीं करते और इस समस्या को ठीक किए जाने के दौरान भी काम करते रहेंगे।
