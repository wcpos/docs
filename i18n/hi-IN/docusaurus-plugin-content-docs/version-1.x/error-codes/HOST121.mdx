## इसका क्या अर्थ है {#what-this-means}

स्टोर के API के बजाय एक बॉट-सुरक्षा पृष्ठ उत्तर दे रहा है।

स्टोर का REST API वहाँ एक HTML चुनौती पृष्ठ (बॉट सुरक्षा, CAPTCHA, या DDoS इंटरस्टिशियल) लौटा रहा है जहाँ ऐप JSON की अपेक्षा करता है। कोई पॉइंट-ऑफ़-सेल ऐप ब्राउज़र चुनौती हल नहीं कर सकता; स्टोर के REST API को सुरक्षा सेवा की अनुमति-सूची में जोड़ना आवश्यक है।

## आपका डेटा {#your-data}

ऑर्डर या उत्पाद का कोई डेटा प्रभावित नहीं हुआ है।

## समस्या निवारण {#troubleshoot}

1. चुनौती पृष्ठ से सुरक्षा परत की पहचान करें (Cloudflare, Sucuri, Kinsta और अन्य सेवाएँ अपने पृष्ठ पर अपना ब्रांड दिखाती हैं) और उसकी सेटिंग्स खोलें।
2. API ट्रैफ़िक के लिए स्टोर के अपने REST API पथ (/wp-json/ और /?rest_route=) को अनुमति-सूची में जोड़ें।
3. Cloudflare पर REST API पथों के लिए WAF **Skip** नियम जोड़ें; Bot Fight Mode (निःशुल्क प्लान) को किसी नियम से बायपास नहीं किया जा सकता, इसलिए इसे बंद करना होगा। सटीक नियम और `curl` जाँच के लिए [Cloudflare गाइड](/1.x/support/troubleshooting/cloudflare) देखें।
4. Kinsta की बॉट/फ़ायरवॉल सेटिंग्स में REST API पथों को अनुमति-सूची में जोड़ें; Sucuri पर API मार्गों के लिए JavaScript-चुनौती DDoS मोड से बचें।
