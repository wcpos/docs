## इसका क्या अर्थ है {#what-this-means}

स्टोर के API के बजाय एक बॉट-सुरक्षा पृष्ठ उत्तर दे रहा है।

स्टोर का REST API वहाँ एक HTML चुनौती पृष्ठ (बॉट सुरक्षा, CAPTCHA, या DDoS इंटरस्टिशियल) लौटा रहा है जहाँ ऐप JSON की अपेक्षा करता है। कोई पॉइंट-ऑफ़-सेल ऐप ब्राउज़र चुनौती हल नहीं कर सकता; स्टोर के REST API को सुरक्षा सेवा में अनुमति-सूची में जोड़ने की आवश्यकता है।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद डेटा पर कोई असर नहीं पड़ता।

## समस्या निवारण {#troubleshoot}

1. चुनौती पृष्ठ से सुरक्षा परत की पहचान करें (Cloudflare, Sucuri, Kinsta और अन्य प्रत्येक अपनी परत को ब्रांड करते हैं) और उसकी सेटिंग्स खोलें।
2. API ट्रैफ़िक के लिए स्टोर के अपने REST API पथ (/wp-json/ और /?rest_route=) को अनुमति-सूची में जोड़ें।
3. Cloudflare पर, Bot Fight Mode को प्रति-पथ बायपास नहीं किया जा सकता — Super Bot Fight Mode के 'definitely automated' अनुमति नियमों का उपयोग करें या इस ज़ोन के लिए इसे अक्षम करें।
4. Kinsta की बॉट/फ़ायरवॉल सेटिंग्स में, REST API पथों को अनुमति-सूची में जोड़ें; Sucuri पर, API मार्गों के लिए JavaScript-चुनौती DDoS मोड से बचें।
