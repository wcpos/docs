# त्रुटि कोड {#error-codes}

WCPOS में कोई समस्या आने पर यह समस्या पहचानने में मदद करने वाला त्रुटि कोड दिखाता है। **v1.10.0** से कोड का प्रारूप **डोमेन + तीन अंक** है — उदाहरण के लिए `SYNC131` या `AUTH311`। डोमेन POS का क्षेत्र बताता है; संख्या खास स्थिति बताती है। हर कोड के अपने पेज पर उसका अर्थ, क्या करना है और आपके डेटा पर उसका प्रभाव दिया गया है।

POS में त्रुटि कोड **स्टोर हेल्थ → लॉग्स** में दिखते हैं: कोई पंक्ति विस्तृत करें और सीधे यहाँ उस कोड के पेज पर जाने के लिए **Help** लिंक चुनें।

## त्रुटि डोमेन (v1.10.0+) {#error-domains}

| डोमेन | क्षेत्र | उदाहरण |
|--------|------|----------|
| `AUTH` | लॉगिन, सेशन और टोकन | [AUTH101](./AUTH101.mdx), [AUTH311](./AUTH311.mdx) |
| `CHECKOUT` | कैश रजिस्टर पर ऑर्डर पूरे करना | [CHECKOUT101](./CHECKOUT101.mdx), [CHECKOUT201](./CHECKOUT201.mdx) |
| `CLIENT` | POS ऐप और स्थानीय स्टोरेज | [CLIENT101](./CLIENT101.mdx), [CLIENT201](./CLIENT201.mdx) |
| `HOST` | POS को अवरुद्ध करने वाले होस्टिंग और फ़ायरवॉल नियम | [HOST101](./HOST101.mdx), [HOST121](./HOST121.mdx) |
| `LICENSE` | Pro लाइसेंस सक्रिय करना और सत्यापित करना | [LICENSE101](./LICENSE101.mdx) |
| `PAYMENT` | पेमेंट गेटवे और टर्मिनल | [PAYMENT101](./PAYMENT101.mdx), [PAYMENT301](./PAYMENT301.mdx) |
| `PRINT` | रसीद प्रिंट करना | [PRINT101](./PRINT101.mdx), [PRINT301](./PRINT301.mdx) |
| `PRODUCT` | उत्पाद डेटा और कैटलॉग कार्रवाइयाँ | [PRODUCT101](./PRODUCT101.mdx), [PRODUCT401](./PRODUCT401.mdx) |
| `SYNC` | POS और आपके स्टोर के बीच सिंक्रोनाइज़ेशन | [SYNC101](./SYNC101.mdx), [SYNC121](./SYNC121.mdx), [SYNC311](./SYNC311.mdx) |

किसी डोमेन के सभी कोड देखने के लिए साइडबार ब्राउज़ करें, या सीधे कोड खोजें।

`999` पर समाप्त होने वाले कोड उन स्थितियों के लिए डोमेन के सामान्य कोड हैं जिनका अभी कोई विशिष्ट कोड नहीं है।

## पुराने कोड (v1.10.0 से पहले) {#legacy-codes}

v1.10.0 से पुराने संस्करणों में अलग प्रारूप था: `[DOMAIN][CATEGORY][SPECIFIC_CODE]`, जैसे `API04001` = API (डोमेन) + 04 (प्रतिक्रिया त्रुटियाँ) + 001 (अमान्य प्रतिक्रिया प्रारूप)। यदि आप पुराना संस्करण चला रहे हैं या पुरानी लॉग प्रविष्टि अथवा सहायता चर्चा देख रहे हैं, तो ये पेज लागू होते हैं:

| डोमेन | कुल कोड | इसमें शामिल |
|--------|-------------|---------------|
| [API](./api.mdx) | 39 कोड | सर्वर संचार, प्रमाणीकरण, प्लगइन समस्याएँ |
| [DB](./db.mdx) | 9 कोड | स्थानीय डेटा स्टोरेज और प्राप्ति |
| [PY](./py.mdx) | 6 कोड | पेमेंट प्रोसेसिंग |
| [SY](./sy.mdx) | 5 कोड | डिवाइस संसाधन और कॉन्फ़िगरेशन |

v1.10.0+ क्लाइंट ये कोड कभी नहीं देता — यदि आपको अप-टू-डेट POS पर ऐसा कोड दिखे, तो वह पुरानी सहेजी गई लॉग प्रविष्टि या सर्वर-साइड संदेश से आया है।

## और सहायता चाहिए? {#need-more-help}

समस्या निवारण के चरणों का पालन करने के बाद भी समस्या बनी हुई है, तो:

1. अधिक विस्तृत गाइड के लिए [समाधान](/support/troubleshooting/response-error) अनुभाग की जाँच करें
2. सहायता के लिए हमारे [Discord समुदाय](https://wcpos.com/discord) में शामिल हों
3. [GitHub](https://github.com/wcpos) पर समस्याएँ रिपोर्ट करें
