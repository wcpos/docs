## इसका क्या अर्थ है {#what-this-means}

इस स्टोर का WCPOS प्लगइन ऐप के इस संस्करण के लिए बहुत पुराना है।

ऐप को अपडेट कर दिया गया है लेकिन स्टोर पर मौजूद WCPOS प्लगइन को नहीं, और दोनों संस्करण अब एक साथ काम नहीं करते। जो कोई भी साइट का प्रबंधन करता है, उससे WP Admin में WCPOS प्लगइन अपडेट करने के लिए कहें, फिर दोबारा कनेक्ट करें। काउंटर पर कुछ भी बदलने की आवश्यकता नहीं है।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद डेटा पर कोई असर नहीं पड़ता। यदि यह बना रहता है, तो उस व्यक्ति से पूछें जो आपकी WordPress साइट का प्रबंधन करता है।

## समस्या निवारण {#troubleshoot}

**स्टोर पर** — जो कोई भी WordPress साइट का प्रबंधन करता है, उसके लिए:

1. WP Admin → Plugins → WCPOS को नवीनतम संस्करण में अपडेट करें। यदि WCPOS Pro इंस्टॉल है, तो उसे भी उसी समय एक मेल खाते संस्करण में अपडेट करें।
2. यदि कोई अपडेट नहीं दिखाया जाता, तो WP Admin → Dashboard → Updates की जाँच करें; Pro के लिए, एक अनधिकृत अपडेटर अपडेट रोकता है ([LICENSE301](./LICENSE301) देखें) — पहले उसे ठीक करें।

**काउंटर पर** — कैशियर के लिए: स्टोर के अपडेट हो जाने के बाद, दोबारा कनेक्ट करें। आपको स्टोर का पता फिर से टाइप करने की आवश्यकता नहीं है।

**यदि स्टोर को अभी अपडेट नहीं किया जा सकता:** इसके बजाय सपोर्ट से संपर्क करें — काउंटर को ऐसे ऐप संस्करण की आवश्यकता है जो प्लगइन से मेल खाता हो, और सपोर्ट आपको बता सकता है कि कौन सा। वे ऐप संस्करण (काउंटर से) और स्टोर का वर्तमान WCPOS संस्करण (WP Admin से) पूछेंगे।
