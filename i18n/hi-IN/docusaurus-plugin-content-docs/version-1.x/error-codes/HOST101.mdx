## इसका क्या अर्थ है {#what-this-means}

सर्वर ब्राउज़र की अनुमति-जाँच (CORS प्रीफ़्लाइट) को अवरुद्ध कर रहा है, इसलिए वेब ऐप उस तक नहीं पहुँच सकता।

ब्राउज़र किसी भी क्रॉस-ऑरिजिन API कॉल से पहले एक OPTIONS अनुरोध भेजते हैं जो कस्टम हेडर ले जाता है। इस स्टोर के सामने मौजूद कोई चीज़ — आमतौर पर कोई फ़ायरवॉल नियम — OPTIONS को अवरुद्ध कर रही है, इसलिए ब्राउज़र वास्तविक अनुरोध कभी नहीं भेजता। नेटिव ऐप्स पर कोई असर नहीं पड़ता; समाधान सर्वर-साइड है।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद डेटा पर कोई असर नहीं पड़ता।

## समस्या निवारण {#troubleshoot}

1. फ़ायरवॉल (WAF) में OPTIONS मेथड को अवरुद्ध करने वाले किसी नियम की जाँच करें और /wcpos/ REST मार्गों पर इसकी अनुमति दें।
2. कुछ सुरक्षा प्लगइनों में 'block uncommon request methods' टॉगल होता है — OPTIONS को अनुमत बना रहना चाहिए।
3. परीक्षण: स्टोर के REST API को किया गया OPTIONS अनुरोध 403 नहीं लौटाना चाहिए।
4. डेस्कटॉप और मोबाइल ऐप CORS का उपयोग नहीं करते और जब तक इसे ठीक किया जा रहा है तब भी काम करते रहेंगे।
