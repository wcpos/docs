## इसका क्या अर्थ है {#what-this-means}

स्टोर के REST API ने इस ऐप द्वारा उपयोग किए जा सकने वाले किसी भी पते-रूप पर उत्तर नहीं दिया।

ऐप ने स्टोर के REST API को उसके सामान्य पते (/wp-json/...) पर और WordPress के अंतर्निहित फ़ॉलबैक पते (/?rest_route=...) पर आज़माया, और किसी ने भी उत्तर नहीं दिया। स्टोर की वेबसाइट स्वयं चालू हो सकती है — यह विशेष रूप से REST API का पहुँच से बाहर होना है, आमतौर पर कोई सुरक्षा प्लगइन इसे छिपा रहा है या कोई फ़ायरवॉल नियम इसे अवरुद्ध कर रहा है।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद डेटा पर कोई असर नहीं पड़ता।

## समस्या निवारण {#troubleshoot}

**स्टोर पर** — साइट व्यवस्थापक के लिए: यदि कोई सुरक्षा प्लगइन `/wp-json/` को छिपाता या उसका नाम बदलता है (उदाहरण के लिए WP Hide), तो WordPress के अंतर्निहित `/?rest_route=` रूप की भी अनुमति दें — ऐप स्वचालित रूप से उस पर फ़ॉलबैक कर लेता है।

**होस्ट / सर्वर पर:**

1. फ़ायरवॉल (WAF) नियमों में `wp-json` या `rest_route` से मेल खाती किसी भी चीज़ की जाँच करें और स्टोर के अपने REST API को पास होने दें।
2. यदि सर्वर किसी रखरखाव पृष्ठ या बॉट चुनौती के पीछे है, तो REST अनुरोधों का उत्तर एक HTML पृष्ठ से दिया जा सकता है — REST API के लिए चुनौती अक्षम करें।

**परीक्षण करने के लिए (कोई भी):** `https://your-store.com/?rest_route=/` को JSON लौटाना चाहिए, न कि कोई 403 पृष्ठ या साइट का होमपेज।
