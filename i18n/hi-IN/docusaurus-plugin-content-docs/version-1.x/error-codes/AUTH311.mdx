## इसका क्या अर्थ है {#what-this-means}

WCPOS आपके स्टोर के कनेक्शन पॉइंट तक नहीं पहुँच पा रहा है।

अपने साइट एडमिन से जाँचने को कहें कि WCPOS प्लगइन सक्रिय है (**WP Admin → प्लगइन्स**) और कोई सुरक्षा प्लगइन REST API को ब्लॉक नहीं कर रहा है।

## आपका डेटा {#your-data}

ऑर्डर या उत्पाद का कोई डेटा प्रभावित नहीं हुआ है। अपने साइट एडमिन को बताएँ।

## समस्या निवारण {#troubleshoot}

**बिक्री-काउंटर पर** — कैशियर के लिए: अपने साइट एडमिन को बताएँ। इस डिवाइस पर कुछ भी प्रभावित नहीं हुआ है।

**स्टोर पर** — साइट एडमिन के लिए:

1. पुष्टि करें कि WCPOS सक्रिय है: WP Admin → Plugins।
2. अगर REST के दोनों रूप काम नहीं करते, तो जाँचें कि कोई सुरक्षा प्लगइन, प्रॉक्सी या CDN WCPOS अनुरोध हेडर हटा तो नहीं रहा या REST अनुरोध रोक तो नहीं रहा—आमतौर पर फ़ायरवॉल नियम और REST API अक्षम करने वाले सुरक्षा विकल्प इसका कारण होते हैं।
3. कुछ होस्ट पर, परमालिंक्स दोबारा सहेजने (सेटिंग्स → परमालिंक्स → सहेजें) से गायब REST रूट्स वापस आ जाते हैं।
