## इसका क्या अर्थ है {#what-this-means}

WCPOS स्टोर रूट उपलब्ध नहीं है।

साइट एडमिनिस्ट्रेटर से जाँचने के लिए कहें कि कहीं कोई सुरक्षा या प्रॉक्सी प्लगइन WCPOS अनुरोध हेडर तो नहीं हटा रहा।

## आपका डेटा {#your-data}

किसी ऑर्डर या उत्पाद डेटा पर कोई प्रभाव नहीं पड़ा है। यदि यह बना रहे, तो अपनी WordPress साइट का प्रबंधन करने वाले व्यक्ति से पूछें।

## समस्या निवारण {#troubleshoot}

**काउंटर पर** — कैशियर के लिए: ब्राउज़र में REST के दोनों समर्थित रूप जाँचें—आपके स्टोर का `/wp-json/` पता और `/index.php?rest_route=/`। REST ब्लॉक होने का निष्कर्ष तभी निकालें जब दोनों से JSON न मिले; फिर इसकी सूचना एडमिन को दें।

**स्टोर पर** — साइट एडमिन के लिए:

1. पुष्टि करें कि WCPOS सक्रिय है: WP Admin → Plugins।
2. अगर REST के दोनों रूप काम नहीं करते, तो जाँचें कि कोई सुरक्षा प्लगइन, प्रॉक्सी या CDN WCPOS अनुरोध हेडर हटा तो नहीं रहा या REST अनुरोध रोक तो नहीं रहा—आमतौर पर फ़ायरवॉल नियम और REST API अक्षम करने वाले सुरक्षा विकल्प इसका कारण होते हैं।
3. कुछ होस्ट पर, परमालिंक्स दोबारा सहेजने (सेटिंग्स → परमालिंक्स → सहेजें) से गायब REST रूट्स वापस आ जाते हैं।
