# PayArc Terminal गेटवे {#payarc-terminal-gateway}

PayArc Terminal गेटवे, PayArc Connect के ज़रिए WCPOS से PayArc PAX टर्मिनल पर आमने-सामने भुगतान स्वीकार करने देता है। भुगतान WooCommerce से शुरू होता है और टर्मिनल पर पूरा होता है। PayArc की पुष्टि के बाद ही ऑर्डर को भुगतान किया हुआ चिह्नित किया जाता है।

## यह कैसे काम करता है {#how-it-works}

WordPress, **PayArc Connect** को कॉल करता है और PayArc PAX टर्मिनल तक पहुँचता है। POS केवल आपकी साइट से संचार करता है। हर भुगतान में **ऑर्डर की पूरी कुल राशि** ली जाती है।

भुगतान पेज हर **1.5 सेकंड** में परिणाम जाँचता है और **5 मिनट** बाद रुक जाता है। **Webhook URL** पर आने वाले PayArc कॉलबैक से परिणाम जल्दी मिलता है; कॉलबैक न होने पर भी पोलिंग से भुगतान पूरा होता है। जब ग्राहक टर्मिनल पर भुगतान करे, तब भुगतान पेज खुला रखें।

## सेटअप {#setup}

<Steps>
  <StepCard number="1" title="WooCommerce के लिए PayArc Terminal इंस्टॉल करें">

`WP Admin > POS > सेटिंग्स > Extensions` से इंस्टॉल करें, या [GitHub releases page](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases) से **payarc-terminal-for-woocommerce.zip** एसेट डाउनलोड करें और `प्लगइन्स > नया जोड़ें > Upload Plugin` के ज़रिए अपलोड करें। प्लगइन सक्रिय करें।

  </StepCard>
  <StepCard number="2" title="अपने PayArc क्रेडेंशियल दर्ज करें">

1. `WP Admin > WooCommerce > सेटिंग्स > भुगतान` पर जाएँ और **PayArc Terminal** खोलें
2. **Mode** चुनें: `Live` डिफ़ॉल्ट है। `Test` का उपयोग केवल PayArc टेस्ट डैशबोर्ड क्रेडेंशियल और PayArc Connect Test ऐप के साथ करें। अलग-अलग परिवेशों को कभी न मिलाएँ
3. **PayArc login email** दर्ज करें; यह वह ईमेल है जिसका उपयोग PayArc व्यापारी डैशबोर्ड में साइन इन करने के लिए किया जाता है
4. PayArc Merchant Profile से **PayArc MID** दर्ज करें, टर्मिनल ID नहीं
5. डैशबोर्ड के API अनुभाग से **PayArc ClientSecret** और PayArc डैशबोर्ड से **PayArc SecretKey / API bearer token** दर्ज करें
6. **Callback bearer token** खाली छोड़ें, जब तक PayArc सहायता टीम ने आपको कोई टोकन न दिया हो; यह वैकल्पिक है

  </StepCard>
  <StepCard number="3" title="कनेक्ट करें">

**Connect using these credentials** पर क्लिक करें। सफल होने पर, स्क्रीन आपसे टर्मिनल सीरियल नंबर दर्ज या पुष्टि करने और सेटिंग सहेजने को कहती है। यदि संदेश आए कि क्रेडेंशियल दूसरे परिवेश के लगते हैं, तो **Mode** बदलें और फिर से कनेक्ट करें।

:::note
मोड या क्रेडेंशियल में कोई भी बदलाव करने के बाद, फिर से **Connect using these credentials** पर क्लिक करें और सहेजें। जब तक मोड और क्रेडेंशियल सहेजे गए कनेक्शन से मेल नहीं खाते, भुगतान अवरुद्ध रहेंगे। यदि आप 0.1.14 से पहले के संस्करण से अपग्रेड कर रहे हैं, तो एक बार Connect दबाएँ।
:::

  </StepCard>
  <StepCard number="4" title="अपना टर्मिनल जोड़ें">

1. अपने खाते के लिए PayArc द्वारा कॉन्फ़िगर किए गए PAX टर्मिनल के पीछे लगे **S/N** लेबल से **Terminal serial number** दर्ज करें
2. **Tender type** और **Print receipt** चुनें
3. जाँचें कि **Webhook URL** HTTPS है। PayArc से माँगने पर ही उसे दें
4. **Save changes** पर क्लिक करें

Live मोड के लिए HTTPS साइट आवश्यक है।

  </StepCard>
  <StepCard number="5" title="WCPOS में सक्षम करें" isLast>

1. `WP Admin > POS > सेटिंग्स > Checkout` पर जाएँ
2. **PayArc Terminal** गेटवे ढूँढें और POS के लिए उसे सक्षम करें
3. अपनी सेटिंग सहेजें

:::note
WooCommerce सेटिंग स्क्रीन पर मौजूद **Enable/Disable** चेकबॉक्स केवल ऑनलाइन स्टोर के चेकआउट को नियंत्रित करता है। WCPOS इस गेटवे को कॉन्फ़िगर होने के बाद इस्तेमाल करता है, चाहे उस बॉक्स पर निशान लगा हो या नहीं।

अधिकांश स्टोर इस बॉक्स पर निशान नहीं लगाते।
:::

  </StepCard>
</Steps>

## सेटिंग संदर्भ {#settings}

| सेटिंग | इसका काम |
|---|---|
| **Enable/Disable** | ऑनलाइन स्टोर चेकआउट के लिए PayArc Terminal सक्षम करता है। डिफ़ॉल्ट रूप से बंद; POS को `POS > सेटिंग्स > Checkout` में सक्षम किया जाता है |
| **Title** | चेकआउट लेबल; डिफ़ॉल्ट `PayArc Terminal` है |
| **Description** | चेकआउट विवरण; डिफ़ॉल्ट `Pay in person at a PayArc PAX terminal.` है |
| **Mode** | `Live` (डिफ़ॉल्ट) या `Test`। Test के लिए PayArc टेस्ट डैशबोर्ड क्रेडेंशियल और PayArc Connect Test ऐप आवश्यक हैं |
| **PayArc login email** | PayArc व्यापारी डैशबोर्ड का लॉगिन ईमेल; कनेक्ट करने से पहले आवश्यक |
| **PayArc MID** | PayArc Merchant Profile का व्यापारी MID, टर्मिनल ID नहीं |
| **PayArc ClientSecret** | डैशबोर्ड के API अनुभाग का सीक्रेट; केवल आपके सर्वर पर सहेजा जाता है |
| **PayArc SecretKey / API bearer token** | PayArc डैशबोर्ड का टोकन, जिसका उपयोग लॉग इन करने और टर्मिनल रजिस्ट्री पाने के लिए किया जाता है |
| **Callback bearer token** | वैकल्पिक। इसे केवल तभी भरें जब PayArc सहायता टीम ने आपको दिया हो |
| **PayArc connection** | **Connect using these credentials**, **Refresh Terminals** और **Disconnect** बटन |
| **Terminal serial number** | आपके खाते को असाइन किया गया PAX S/N; भुगतान के लिए आवश्यक। रजिस्ट्री में मिलने पर अपने आप भर जाता है; सहेजने से पहले इसे दर्ज करें या इसकी पुष्टि करें |
| **Tender type** | `CREDIT` (डिफ़ॉल्ट) या `DEBIT` |
| **Print receipt** | `0` — कोई नहीं (डिफ़ॉल्ट), `1` — व्यापारी, `2` — ग्राहक, `3` — दोनों |
| **Webhook URL** | केवल-पढ़ने योग्य कॉलबैक पता। जाँचें कि यह HTTPS है; PayArc से माँगने पर ही उसे दें |
| **PayArc diagnostics** | कनेक्शन जानकारी और **Validate Settings** बटन; सीक्रेट कभी प्रदर्शित नहीं किए जाते |

सहेजे गए सीक्रेट फ़ील्ड में केवल अंतिम 4 अक्षर दिखते हैं। सहेजा गया मान बनाए रखने के लिए सीक्रेट फ़ील्ड खाली छोड़ें।

**PayArc diagnostics** तालिका में मोड, एंडपॉइंट, छिपाए गए MID / tenant ID / serial number, Connect access token कॉन्फ़िगर है या नहीं, Webhook URL, अंतिम कॉलबैक और PayArc की अंतिम त्रुटि दिखाई जाती है। अपनी सेटिंग जाँचने के लिए **Validate Settings** का उपयोग करें।

## उपयोग {#usage}

### भुगतान संसाधित करना {#processing-payments}

1. **Select Gateway**: POS में भुगतान विधि के रूप में **PayArc Terminal** चुनें
2. **Start Payment**: ऑर्डर की कुल राशि टर्मिनल पर भेजने के लिए **Start Payment** पर क्लिक करें
3. **Customer Payment**: जब तक ग्राहक PAX टर्मिनल पर भुगतान पूरा न कर ले, पेज खुला रखें। स्थिति संदेशों का क्रम देखें: `Starting terminal payment...` → `Payment sent to terminal.` → `Waiting for the terminal result...` → `Payment approved. Completing the order...`
4. **Automatic Completion**: PayArc द्वारा भुगतान की पुष्टि होने पर ऑर्डर अपने आप पूरा हो जाता है

### भुगतान नियंत्रण {#payment-controls}

- भुगतान शुरू होने के बाद **Cancel Payment** दिखाई देता है। यदि PayArc ने अभी तक trace id नहीं लौटाया है, तो रद्द करने से पहले थोड़ा इंतज़ार करें
- अस्वीकृति, रद्दीकरण या समय-सीमा समाप्त होने के बाद आप फिर से कोशिश कर सकते हैं। समय-सीमा समाप्त हुए भुगतान को दोबारा आज़माने से पहले टर्मिनल जाँचें
- भुगतान गतिविधि लॉग डिफ़ॉल्ट रूप से संक्षिप्त होता है। इसे देखने के लिए **Show activity** और दिखाई गई गतिविधि हटाने के लिए **Clear** का उपयोग करें

### रसीदें {#receipts}

**Print receipt** सेटिंग टर्मिनल पर प्रिंटिंग नियंत्रित करती है: कोई नहीं, व्यापारी, ग्राहक या दोनों।

## रिफ़ंड {#refunds}

प्लगइन के ज़रिए रिफ़ंड समर्थित नहीं हैं। PayArc के ज़रिए रिफ़ंड करें, फिर WooCommerce में रिफ़ंड को मैन्युअल रूप से दर्ज करें।

## लॉग {#logs}

लॉग `WooCommerce > Status > Logs` में `payarc-terminal-for-woocommerce` स्रोत के अंतर्गत मिलेंगे। लॉग में कनेक्शन प्रयास, शुरू हुई या विफल हुई बिक्री, रद्दीकरण और स्वीकार या अस्वीकार किए गए कॉलबैक शामिल हैं। पहचानकर्ता छिपाए जाते हैं और सीक्रेट हटाए जाते हैं।

सहायता बंडल डाउनलोड करने का विकल्प नहीं है। सहायता माँगते समय ऑर्डर नंबर और संबंधित लॉग पंक्तियाँ भेजें। पूरे MID, टर्मिनल ID, टोकन या कार्ड डेटा साझा न करें।

## दायरा और सीमाएँ {#scope-and-limitations}

- प्लगइन के ज़रिए रिफ़ंड समर्थित नहीं हैं
- भुगतान में **ऑर्डर की पूरी कुल राशि** ली जाती है; आंशिक या विभाजित भुगतान समर्थित नहीं हैं
- टिप समर्थित नहीं हैं
- प्रति स्टोर एक टर्मिनल: एक सीरियल नंबर सेटिंग, कैशियर चयन का विकल्प नहीं
- मुद्राएँ **USD, CAD, GBP, EUR और JPY** तक सीमित हैं
- जब तक मोड और क्रेडेंशियल सहेजे गए कनेक्शन से मेल नहीं खाते, भुगतान अवरुद्ध रहेंगे

## समस्या निवारण {#troubleshooting}

### आम समस्याएँ {#common-issues}

<Accordion>
  <AccordionItem question="क्रेडेंशियल दूसरे परिवेश के लगते हैं">

  - चयनित मोड और क्रेडेंशियल अलग-अलग परिवेशों से हैं
  - क्रेडेंशियल से मेल खाने के लिए **Mode** बदलें, या चयनित मोड के क्रेडेंशियल से उन्हें बदलें
  - फिर से **Connect using these credentials** पर क्लिक करें और सहेजें

  </AccordionItem>
  <AccordionItem question="PayArc से कनेक्ट नहीं हो पा रहा">

  - PayArc ने लॉगिन क्रेडेंशियल अस्वीकार कर दिए। दर्ज किए गए क्रेडेंशियल जाँचें और फिर कोशिश करें
  - विवरण के लिए `WooCommerce > Status > Logs` में `payarc-terminal-for-woocommerce` स्रोत जाँचें

  </AccordionItem>
  <AccordionItem question="भुगतान अनुरोध संसाधित नहीं हो सका। (HTTP 500)">

  - कैशियर को दिखाया गया यह संदेश सामान्य है। असली कारण जानने के लिए WooCommerce लॉग में **PayArc payment action failed** खोजें
  - मोड या क्रेडेंशियल बदलने के बाद, फिर से **Connect using these credentials** पर क्लिक करें और सहेजें
  - जाँचें कि **Terminal serial number** भरा हुआ है
  - यदि लॉग कहता है कि PayArc ने Connect access token और SecretKey दोनों अस्वीकार किए, तो PayArc सहायता टीम से पुष्टि करने को कहें कि आपके व्यापारी खाते के लिए **PayArc Connect V3** सक्षम है
  - जाँचें कि स्टोर की मुद्रा **USD, CAD, GBP, EUR या JPY** में से एक है

  </AccordionItem>
  <AccordionItem question="Start Payment पर पहुँच अस्वीकृत। (HTTP 403)">

  - **0.1.12 या बाद के संस्करण** पर अपडेट करें; इससे POS सत्रों में यह त्रुटि ठीक होती है

  </AccordionItem>
  <AccordionItem question="Terminal Registry खाली है">

  - खाली रजिस्ट्री या POS पहचानकर्ता के बिना दिखाया गया टर्मिनल सामान्य है
  - रजिस्ट्री डेटा केवल रिपोर्टिंग के लिए है। भुगतान में **Terminal serial number** इस्तेमाल होता है

  </AccordionItem>
  <AccordionItem question="भुगतान में बहुत देर लग रही है">

  - टर्मिनल स्क्रीन जाँचें और भुगतान पेज खुला रखें
  - फिर से कोशिश करने से पहले ऑर्डर नोट और PayArc डैशबोर्ड जाँचें
  - पेज हर **1.5 सेकंड** में जाँचता है और **5 मिनट** बाद रुक जाता है

  </AccordionItem>
