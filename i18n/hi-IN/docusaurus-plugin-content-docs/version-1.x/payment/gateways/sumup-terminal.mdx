# SumUp Terminal गेटवे {#sumup-terminal-gateway}

SumUp Terminal गेटवे आपको WCPOS के भीतर सीधे SumUp कार्ड रीडर से कार्ड भुगतान स्वीकार करने देता है। यह गेटवे आमने-सामने लेन-देन के लिए SumUp की भुगतान प्रोसेसिंग प्रणाली के साथ सहज एकीकरण प्रदान करता है।

## स्थापना {#installation}

<Steps>
  <StepCard number="1" title="WooCommerce के लिए SumUp Terminal इंस्टॉल करें">

`WP Admin > POS > सेटिंग्स > Extensions` से इंस्टॉल करें, या नवीनतम **प्लगइन ज़िप एसेट** (GitHub का सोर्स-कोड ज़िप या tarball नहीं) [GitHub रिलीज़ पेज](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases) से डाउनलोड करके `प्लगइन्स > नया जोड़ें > Upload Plugin` के ज़रिए अपलोड करें।

  </StepCard>
  <StepCard number="2" title="SumUp सेटिंग कॉन्फ़िगर करें">

1. `WP Admin > WooCommerce > सेटिंग्स > भुगतान` पर जाएँ
2. भुगतान विधियों की सूची में **SumUp Terminal** खोजें
3. सेटिंग खोलने के लिए **SumUp Terminal** पर क्लिक करें
4. अपनी **SumUp API Key** दर्ज करें (यह आपके SumUp व्यापारी डैशबोर्ड में उपलब्ध है)
5. सेटिंग सहेजें

:::note
आपको WooCommerce सेटिंग में SumUp Terminal गेटवे सक्षम करने की ज़रूरत नहीं है। इसे बाद के चरण में खास तौर पर POS के लिए सक्षम किया जाएगा।
:::

  </StepCard>
  <StepCard number="3" title="अपना SumUp Terminal पेयर करें">

1. उसी सेटिंग पेज पर **रीडर पेयर करें** सेक्शन खोजें
2. पेयरिंग कोड दिखाने के लिए अपने SumUp डिवाइस पर पेयरिंग स्क्रीन खोलें
3. अपने SumUp डिवाइस पर दिखाया गया पेयरिंग कोड दर्ज करें
4. कनेक्शन स्थापित करने के लिए **"रीडर पेयर करें"** पर क्लिक करें
5. रीडर के सफलतापूर्वक पेयर होने की पुष्टि की प्रतीक्षा करें

**क्या आपके SumUp Solo पर “Cloud API” नहीं दिख रहा?** रीडर पर अपने SumUp खाते से लॉग आउट करें, फिर मेनू दोबारा देखें।

:::warning महत्वपूर्ण
भुगतान प्रोसेस करने से पहले रीडर का सफलतापूर्वक पेयर होना ज़रूरी है। आगे बढ़ने से पहले पेयरिंग प्रक्रिया पूरी करें।
:::

  </StepCard>
  <StepCard number="4" title="WCPOS में सक्षम करें" isLast>

1. `WP Admin > POS > सेटिंग्स > Checkout` पर जाएँ
2. सूची में **SumUp Terminal** गेटवे खोजें
3. POS में उपयोग के लिए गेटवे सक्षम करें
4. अपनी सेटिंग सहेजें

  </StepCard>
</Steps>

## उपयोग {#usage}

### भुगतान प्रोसेस करना {#processing-payments}

1. **आइटम जोड़ें**: POS में अपने कार्ट में उत्पाद जोड़ें
2. **गेटवे चुनें**: भुगतान विधि के रूप में "SumUp Terminal" चुनें
3. **भुगतान शुरू करें**: अपने SumUp डिवाइस पर नया भुगतान शुरू करने के लिए क्लिक करें
4. **ग्राहक का भुगतान**: ग्राहक SumUp टर्मिनल पर भुगतान पूरा करता है
5. **अपने आप पूरा होना**: भुगतान का पता चलने पर ऑर्डर अपने आप पूरा हो जाता है

### भुगतान नियंत्रण {#payment-controls}

SumUp Terminal गेटवे का उपयोग करते समय आपके पास ये विकल्प होते हैं:

- **नया भुगतान शुरू करें**: कनेक्ट किए गए टर्मिनल पर भुगतान अनुरोध शुरू करें
- **भुगतान रद्द करें**: प्रक्रिया में मौजूद भुगतान रद्द करें
- **भुगतान की स्थिति**: भुगतान प्रक्रिया की मौजूदा स्थिति देखें

### ऑर्डर प्रबंधन {#order-management}

- **अपने आप अपडेट होना**: सफल भुगतान के बाद ऑर्डर अपने आप पूरा चिह्नित हो जाते हैं
- **भुगतान ट्रैकिंग**: भुगतान के सभी विवरण ऑर्डर नोट्स में दर्ज किए जाते हैं
- **रसीद बनाना**: सफल भुगतान के बाद मानक POS रसीदें बनाई जाती हैं

## हार्डवेयर संगतता {#hardware-compatibility}

:::important कनेक्टिविटी आवश्यकताएँ
यह कार्यान्वयन SumUp के JavaScript SDK का उपयोग करता है, इसलिए यह वेब ऐप्लिकेशन के ज़रिए काम करता है, लेकिन इसके लिए **केवल इंटरनेट से जुड़े टर्मिनल** आवश्यक हैं। Bluetooth टर्मिनल अभी समर्थित नहीं हैं।
:::

### समर्थित टर्मिनल (इंटरनेट से जुड़े) {#supported-terminals-internet-connected}

- **SumUp Solo** ✅ - WiFi/Ethernet से जुड़ा टर्मिनल

### असमर्थित टर्मिनल (Bluetooth) {#unsupported-terminals-bluetooth}

- **SumUp Air** ❌ - केवल Bluetooth
- **SumUp 3G** ❌ - केवल Bluetooth

:::note भविष्य में सहायता
भविष्य के iOS और Android ऐप रिलीज़ में Bluetooth टर्मिनल सहायता की योजना है। उपलब्ध होने पर, इससे Air और 3G मॉडल सहित SumUp प्रमाणित सभी टर्मिनलों के लिए सहायता मिलेगी।
:::

## समस्या निवारण {#troubleshooting}

### आम समस्याएँ {#common-issues}

<Accordion>
  <AccordionItem question="रीडर पेयर नहीं हो रहा">

  - पुष्टि करें कि आप समर्थित इंटरनेट-कनेक्टेड टर्मिनल (केवल Solo) का उपयोग कर रहे हैं
  - जाँचें कि आपका SumUp Solo डिवाइस WiFi से जुड़ा है और ऑनलाइन है
  - जाँचें कि डिवाइस पेयरिंग मोड में है और पेयरिंग कोड सही दर्ज किया गया है
  - पुष्टि करें कि आपके SumUp खाते में API एक्सेस सक्षम है
  - पेयरिंग के दौरान स्थिर इंटरनेट कनेक्शन सुनिश्चित करें

  </AccordionItem>

  <AccordionItem question="भुगतान प्रोसेस नहीं हो रहा">

  - पुष्टि करें कि रीडर सही तरीके से पेयर किया गया है
  - जाँचें कि आपका SumUp खाता सक्रिय और अच्छी स्थिति में है
  - सुनिश्चित करें कि डिवाइस की बैटरी पर्याप्त है और कनेक्टिविटी उपलब्ध है
  - पुष्टि करें कि API कुंजी सही और सक्रिय है

  </AccordionItem>

  <AccordionItem question="ऑर्डर पूरा नहीं हो रहा">

  - इंटरनेट कनेक्शन की स्थिरता जाँचें
  - अपने SumUp खाते में webhook सेटिंग सत्यापित करें
  - सुनिश्चित करें कि SumUp टर्मिनल पर भुगतान सफल हुआ
  - API संचार संबंधी समस्याओं के लिए WordPress त्रुटि लॉग जाँचें

  </AccordionItem>
</Accordion>

### API अनुरोध दर सीमाएँ {#api-rate-limits}

API कॉल कम करने और अनुरोध दर सीमा से बचने के लिए गेटवे को अनुकूलित किया गया है:
- भुगतान की स्थिति कुशलता से जाँची जाती है
- अनावश्यक API अनुरोध कम से कम किए जाते हैं
- अपने आप दोबारा कोशिश करने की व्यवस्था अस्थायी विफलताओं को संभालती है

### सहायता प्राप्त करें {#getting-help}

तकनीकी सहायता के लिए:
- मुद्दों की रिपोर्ट करने के लिए [GitHub रिपॉजिटरी](https://github.com/wcpos/sumup-terminal-for-woocommerce) पर जाएं
- API से संबंधित प्रश्नों के लिए [SumUp डेवलपर दस्तावेज़](https://developer.sumup.com/) देखें
- खाता और हार्डवेयर मुद्दों के लिए SumUp सहायता से संपर्क करें
