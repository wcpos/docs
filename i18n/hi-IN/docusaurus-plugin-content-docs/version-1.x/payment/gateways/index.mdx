# भुगतान गेटवे {#payment-gateways}

WCPOS कई कस्टम भुगतान गेटवे का समर्थन करता है जो आपके पॉइंट ऑफ सेल सिस्टम की कार्यक्षमता को बढ़ाते हैं। ये गेटवे विशेष रूप से POS वातावरण के लिए डिज़ाइन किए गए हैं और विभिन्न भुगतान विधियों और सेवाओं के साथ सहज एकीकरण प्रदान करते हैं।

## उपलब्ध कस्टम गेटवे {#available-custom-gateways}

### हार्डवेयर टर्मिनल गेटवे {#hardware-terminal-gateways}

- **[Stripe Terminal](./stripe-terminal.mdx)** - Stripe Terminal हार्डवेयर रीडर का उपयोग करके भुगतान स्वीकार करें
- **[SumUp Terminal](./sumup-terminal.mdx)** - SumUp कार्ड रीडर के माध्यम से भुगतान प्रोसेस करें
- **[Square Terminal](./square-terminal.mdx)** - Square Terminal डिवाइस पर व्यक्तिगत भुगतान एकत्र करें
- **[PayPal Reader (Zettle)](./paypal-reader.mdx)** - PayPal Reader (Zettle) टर्मिनल पर व्यक्तिगत कार्ड भुगतान लें
- **[Mollie Terminal](./mollie-terminal.mdx)** - Mollie Terminal डिवाइसों पर आमने-सामने भुगतान स्वीकार करें
- **[Mercado Pago Terminal](./mercadopago-terminal.mdx)** - Mercado Pago Point Smart टर्मिनलों पर आमने-सामने भुगतान स्वीकार करें (0.1.0 में नया)
- **[Windcave Terminal](./windcave-terminal.mdx)** - Windcave टर्मिनलों पर आमने-सामने कार्ड भुगतान स्वीकार करें (0.1.0 में नया)
- **[PayArc Terminal](./payarc-terminal.mdx)** - PayArc PAX टर्मिनलों पर आमने-सामने भुगतान स्वीकार करें

### मोबाइल भुगतान गेटवे {#mobile-payment-gateways}

- **[Vipps MobilePay](./vipps-mobilepay.mdx)** - QR कोड या पुश अधिसूचना के माध्यम से फोन-आधारित भुगतान स्वीकार करें

### डिजिटल भुगतान गेटवे {#digital-payment-gateways}

- **[Email Invoice](./email-invoice.mdx)** - ग्राहकों को ईमेल के माध्यम से भुगतान चालान भेजें
- **[Web Checkout](./web-checkout.mdx)** - ग्राहकों को ऑनलाइन भुगतान पूरा करने के लिए पुनः निर्देशित करें

## अपना गेटवे बनाना {#creating-your-own-gateway}

यदि आपको अपनी विशिष्ट आवश्यकताओं के लिए कस्टम भुगतान गेटवे चाहिए, तो अपना WCPOS भुगतान गेटवे बनाने के लिए हमारे **[गेटवे टेम्पलेट](/1.x/reference/gateway-template)** का उपयोग कर सकते हैं।

## स्थापना का अवलोकन {#installation-overview}

सभी कस्टम गेटवे की स्थापना प्रक्रिया समान है:

1. संबंधित GitHub रिपॉज़िटरी से नवीनतम रिलीज़ **डाउनलोड** करें
2. `WP Admin > प्लगइन्स > नया जोड़ें > Upload Plugin` के माध्यम से प्लगइन **स्थापित** करें
3. `WP Admin > WooCommerce > सेटिंग्स > भुगतान` में गेटवे सेटिंग्स **कॉन्फ़िगर** करें
4. `WP Admin > POS > सेटिंग्स > Checkout` में गेटवे **सक्षम करें**

## सहायता {#support}

कस्टम गेटवे में समस्या होने पर कृपया संबंधित GitHub रिपॉज़िटरी पर जाएँ और समस्या की विस्तृत जानकारी के साथ एक इश्यू बनाएँ।
