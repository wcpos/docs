**लक्षण:** स्कैन करने पर प्रिंटर दिख जाता है, पर प्रिंट करते समय पहुँच या अनुमति की त्रुटि आती है।

## ऐसा क्यों होता है {#why-it-happens}

Linux पर कोई USB डिवाइस `root` का होता है, जब तक कोई नियम कुछ और न कहे, इसलिए आपके नाम से चल रहा ऐप उसे खोल नहीं सकता। हो सकता है कर्नेल का अपना प्रिंटर ड्राइवर पहले ही उस डिवाइस पर दावा कर चुका हो।

## यह करें {#do-this}

1. प्रिंटर की vendor और product आईडी ढूँढें:

   ```bash
   lsusb
   ```

   अपने प्रिंटर की पंक्ति देखें — आईडी `ID` के बाद आने वाले चार-चार अक्षरों के दो मान होते हैं, जैसे `04b8:0e28`।

2. एक नियम फ़ाइल बनाएँ, आईडी की जगह अपनी वाली रखें:

   ```bash
   sudo tee /etc/udev/rules.d/99-receipt-printer.rules <<'RULE'
   SUBSYSTEM=="usb", ATTRS{idVendor}=="04b8", ATTRS{idProduct}=="0e28", MODE="0666"
   RULE
   ```

3. नियम दोबारा लोड करके लागू करें:

   ```bash
   sudo udevadm control --reload-rules && sudo udevadm trigger
   ```

4. प्रिंटर का प्लग निकालकर वापस लगाएँ, और ऐप दोबारा चालू करें। एक परीक्षण पृष्ठ प्रिंट करें।

ऐप को अपने सामान्य उपयोगकर्ता के रूप में चलाएँ, `sudo` से नहीं — जो नियम सिर्फ़ root के लिए चले, उसका कोई मतलब नहीं रह जाता।

## अब भी अटके हैं? {#still-stuck}

समस्या स्क्रीन पर **सेटअप रिपोर्ट कॉपी करें** दबाएँ और उसे अपने प्रिंटर की `lsusb` पंक्ति के साथ अपने संदेश में चिपका दें।
