# WCPOS Polylang {#wcpos-polylang}

WCPOS में [Polylang](https://polylang.pro/) की जानकारी जोड़ता है, ताकि POS केवल एक भाषा के उत्पाद दिखाए। इससे उत्पाद खोज, कैटलॉग ग्रिड और कैशियर workflows में अनुवादित उत्पादों की डुप्लिकेट प्रविष्टियाँ नहीं आतीं। WCPOS Pro स्टोर प्रत्येक स्टोर के लिए भाषा तय कर सकते हैं; निःशुल्क इंस्टॉलेशन Polylang की डिफ़ॉल्ट भाषा पर वापस जाते हैं।

## यह क्या करता है {#what-it-does}

- WCPOS उत्पाद और वैरिएशन REST queries को भाषा के आधार पर फ़िल्टर करता है।
- WCPOS **fast-sync** routes को रोकता है, यानी वे हल्के `posts_per_page=-1` और `fields` requests जिनसे POS अपनी local index refresh करता है, ताकि अनुवादित duplicates client तक न पहुँचें।
- निःशुल्क इंस्टॉलेशन पर Polylang की डिफ़ॉल्ट भाषा लागू करता है।
- Pro इंस्टॉलेशन पर प्रत्येक store को store editor के नए **Language** section से अपनी भाषा चुनने देता है।
- fast-sync payload बनाते समय WCPOS **POS-only** product visibility का सम्मान करता है।

जब Polylang सक्रिय नहीं होता, integration साफ़ तौर पर कुछ नहीं करता। आप Polylang सक्षम करने से पहले भी plugin इंस्टॉल कर सकते हैं और कोई error नहीं आएगा।

## इंस्टॉलेशन {#installation}

<Steps>
  <StepCard number="1" title="Polylang इंस्टॉल करें">

[Polylang](https://wordpress.org/plugins/polylang/) या Polylang Pro इंस्टॉल करें और अपनी site languages सामान्य रूप से configure करें। सुनिश्चित करें कि कम से कम एक भाषा default के रूप में set है।

  </StepCard>
  <StepCard number="2" title="WCPOS Polylang इंस्टॉल करें">

`WP Admin > POS > Settings > Extensions` में WCPOS extensions directory से इंस्टॉल करें, या [GitHub releases page](https://github.com/wcpos/wcpos-polylang/releases) से latest release डाउनलोड करके `Plugins > Add New > Upload Plugin` से upload करें।

  </StepCard>
  <StepCard number="3" title="(Pro) हर store के लिए भाषा सेट करें" isLast>

यदि आप WCPOS Pro पर [कई स्टोर](/1.x/stores) चलाते हैं, तो `POS > स्टोर` पर जाएँ, कोई स्टोर संपादित करें और साइडबार के **Language** अनुभाग से उसकी भाषा चुनें। Polylang की डिफ़ॉल्ट भाषा इस्तेमाल करने के लिए इसे *डिफ़ॉल्ट* पर रहने दें।

  </StepCard>
</Steps>

## हर स्टोर की भाषा (Pro) {#per-store-language-pro}

WCPOS Pro में प्लगइन स्टोर एडिटर के साइडबार में **Language** अनुभाग जोड़ता है। हर स्टोर के लिए एक Polylang भाषा स्लग तय किया जा सकता है — उस स्टोर को दिए जाने वाले उत्पाद केवल उसी भाषा तक सीमित रहते हैं। *डिफ़ॉल्ट* पर रखे गए स्टोर Polylang की डिफ़ॉल्ट भाषा का उपयोग करते हैं।

हर स्टोर का मान उसकी स्टोर पोस्ट में `_wcpos_polylang_language` मेटा के रूप में सहेजा जाता है और WCPOS Pro स्टोर REST API (`/wcpos/v1/stores`) के माध्यम से उपलब्ध होता है, इसलिए अन्य स्टोर सेटिंग्स की तरह इसे भी POS से पढ़ा और वापस सहेजा जा सकता है।

## संगतता संबंधी नोट्स {#compatibility-notes}

- **केवल POS वाले उत्पाद:** जब WCPOS सेटिंग्स में केवल POS मोड सक्षम होता है, तो केवल ऑनलाइन उपलब्ध उत्पादों की ID को तेज़ सिंक के पेलोड से बाहर रखा जाता है, ताकि वे POS में न आ जाएँ।
- **निःशुल्क इंस्टॉलेशन:** हर स्टोर की भाषा बदलने के लिए कोई UI नहीं है — प्लगइन Polylang की डिफ़ॉल्ट भाषा इस्तेमाल करता है। यदि आपको हर स्टोर के लिए अलग भाषा चाहिए, तो [WCPOS Pro](/1.x/getting-started/pro-license) में अपग्रेड करें।
- **प्लगइन उपलब्ध नहीं है:** Polylang निष्क्रिय होने पर प्लगइन बिना किसी संदेश के कुछ नहीं करता। इससे त्रुटियाँ नहीं आएँगी और POS अवरुद्ध नहीं होगा।

## डेवलपर हुक {#developer-hooks}

उन्नत उपयोग के लिए प्लगइन कुछ फ़िल्टर उपलब्ध कराता है:

| फ़िल्टर | उद्देश्य |
| --- | --- |
| `wcpos_polylang_resolved_language` | किसी अनुरोध के लिए इस्तेमाल की जाने वाली भाषा बदलें। इसे निर्धारित स्लग और `WP_REST_Request` मिलते हैं। |
| `wcpos_polylang_default_language` | जब स्टोर के लिए कोई मान सेट न हो, तो इस्तेमाल होने वाली फ़ॉलबैक भाषा बदलें। |
| `wcpos_polylang_is_supported` | Polylang का पता लगने या न लगने से स्वतंत्र रूप से प्लगइन को जबरन चालू या बंद करें। |
| `wcpos_polylang_minimum_version` | Polylang का न्यूनतम संस्करण अनिवार्य करें (डिफ़ॉल्ट: संस्करण की कोई शर्त नहीं)। |
