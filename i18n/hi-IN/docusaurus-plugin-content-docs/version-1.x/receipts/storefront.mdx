आपके WCPOS रसीद टेम्पलेट केवल कैश काउंटर तक सीमित नहीं हैं। ऑनलाइन स्टोर के ग्राहक My Account या ऑर्डर पुष्टिकरण पेज से अपने ऑर्डर की रसीद या इनवॉइस देख और डाउनलोड कर सकते हैं, जिसे **WP Admin → POS → टेम्पलेट्स** से चुने गए कस्टम टेम्पलेट के साथ रेंडर किया जाता है।

:::info संस्करण संबंधी नोट
स्टोरफ्रंट रसीद एक्सेस — **My Account** बटन और `[wcpos_receipt]` शॉर्टकोड — WCPOS **1.9.11** में उपलब्ध है। नीचे बताई गई **ग्राहकों को रसीदें डाउनलोड करने दें** सेटिंग और **ग्राहकों के लिए रसीद टेम्पलेट** चयनकर्ता **1.9.12** में जोड़े गए थे; 1.9.11 में बटन डिफ़ॉल्ट रूप से चालू रहता है और इसे नियंत्रित करने के लिए कोई सेटिंग नहीं होती। पुराने संस्करण केवल POS के भीतर रसीदें रेंडर करते हैं।
:::

:::note यह पेज ग्राहकों द्वारा अपनी रसीदें डाउनलोड करने के बारे में है
कैशियर और कर्मचारियों को इसकी आवश्यकता नहीं है — POS की **ऑर्डर** स्क्रीन में ऑनलाइन ऑर्डर सहित हर WooCommerce ऑर्डर पहले से सूचीबद्ध होता है, और तीन-बिंदु मेनू से उसकी [रसीद देखी, प्रिंट की या ईमेल की जा सकती है](/orders#receipt-reprinting)। यह पेज दूसरे पक्ष को कवर करता है: **ग्राहकों** को आपकी वेबसाइट से स्वयं रसीद डाउनलोड करने देना।
:::

## My Account डाउनलोड बटन {#my-account}

**रसीद** बटन **डिफ़ॉल्ट रूप से बंद** रहता है। इसे **POS > सेटिंग्स > सामान्य** में, **ग्राहक** अनुभाग के अंतर्गत चालू करें: **ग्राहकों को रसीदें डाउनलोड करने दें** सक्षम करें। सक्षम होने पर, लॉग-इन किए हुए ग्राहकों को **My Account → ऑर्डर** में योग्य ऑर्डरों के पास **रसीद** बटन दिखाई देता है, और उस पर क्लिक करने से आपकी रसीद टेम्पलेट से रेंडर किया गया PDF (`receipt-1234.pdf`) डाउनलोड हो जाता है।

बटन **प्रोसेसिंग**, **पूर्ण**, और **रिफ़ंड किए गए** ऑर्डर के लिए दिखाई देता है — ये वे स्थितियाँ हैं जिनमें ऑर्डर का भुगतान हो चुका है। लंबित, रद्द किए गए और विफल ऑर्डर में यह दिखाई नहीं देता। (डेवलपर [यह बदल सकता है कि यह किन स्थितियों में दिखाई दे](#developers)।)

एक **सक्रिय** रसीद टेम्पलेट भी आवश्यक है — यदि कोई टेम्पलेट सक्रिय नहीं है, तो रेंडर करने के लिए कुछ नहीं है, इसलिए सेटिंग चालू होने पर भी बटन छिपा रहेगा।

:::note शॉर्टकोड अलग है
नीचे दिया गया [`[wcpos_receipt]` शॉर्टकोड](#shortcode) इस सेटिंग के चालू होने या न होने, दोनों स्थितियों में काम करता है — टॉगल केवल स्वचालित **मेरा खाता** बटन को नियंत्रित करता है।
:::

## `[wcpos_receipt]` शॉर्टकोड {#shortcode}

ऑर्डर पुष्टिकरण ("धन्यवाद") पृष्ठ या **मेरा खाता → ऑर्डर देखें** पृष्ठ पर रसीद लिंक जोड़ने के लिए, इसका उपयोग करें:

```text
[wcpos_receipt]
```

बिना विशेषताओं के, शॉर्टकोड दोनों पृष्ठों पर वर्तमान ऑर्डर का स्वतः पता लगाता है और *रसीद डाउनलोड करें (PDF)* लिंक रेंडर करता है। अन्य पृष्ठों पर यह कुछ भी प्रदर्शित नहीं करता। स्पष्ट `order_id` केवल उस लॉग-इन ग्राहक के लिए काम करता है, जिसका वह ऑर्डर है।

### विशेषताएँ {#shortcode-attributes}

| विशेषता | डिफ़ॉल्ट | इसका कार्य |
|---|---|---|
| `order_id` | *(स्वतः पता लगाया गया)* | किसी विशिष्ट ऑर्डर का लिंक। केवल उस लॉग-इन ग्राहक के लिए काम करता है, जिसका वह ऑर्डर है। |
| `link_text` | `Download receipt (PDF)` | लिंक का टेक्स्ट। |
| `format` | `pdf` | `pdf` PDF डाउनलोड करता है; इसके बजाय `html` प्रिंट करने योग्य रसीद दृश्य खोलता है। |
| `template` | *(स्टोरफ़्रंट डिफ़ॉल्ट)* | स्टोरफ़्रंट डिफ़ॉल्ट के बजाय किसी विशिष्ट टेम्पलेट ID के साथ रेंडर करें। |
| `class` | `wcpos-receipt-link` | लिंक के लिए CSS क्लास। |
| `id` | *(कोई नहीं)* | लिंक के लिए HTML `id`। |

### उदाहरण {#shortcode-examples}

ऑर्डर पुष्टि पृष्ठ पर डाउनलोड लिंक:

```text
[wcpos_receipt link_text="Download your invoice"]
```

PDF के बजाय स्क्रीन पर दिखाई देने वाली (प्रिंट करने योग्य) रसीद का लिंक:

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

किसी विशिष्ट टेम्पलेट के साथ रेंडर करें — उदाहरण के लिए, अपनी 80mm कैश-रजिस्टर रसीद के बजाय A4 इनवॉइस टेम्पलेट:

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

टेम्पलेट ID, **WP Admin → POS → टेम्पलेट्स** में टेम्पलेट के संपादन-पृष्ठ के URL (`post=123`) में दिया गया नंबर है।

## ग्राहकों को कौन-सा टेम्पलेट मिलता है? {#template-choice}

टॉगल के ठीक नीचे, **ग्राहकों के लिए रसीद टेम्पलेट** यह चुनता है कि डाउनलोड में कौन-सा टेम्पलेट उपयोग होगा। डिफ़ॉल्ट रूप से **सक्रिय रसीद टेम्पलेट का उपयोग करें** चुना होता है, इसलिए ग्राहकों को वही टेम्पलेट मिलता है जिसका उपयोग आपका POS करता है — सक्रिय टेम्पलेट बदलने पर उनकी रसीदें अपने-आप बदल जाती हैं।

ऑनलाइन ऑर्डर को अलग रूप देने के लिए, इसके बजाय ड्रॉपडाउन से कोई विशिष्ट टेम्पलेट चुनें। फिर ग्राहक डाउनलोड हमेशा उसी टेम्पलेट का उपयोग करता है, भले ही कैशियर कैश-रजिस्टर ड्रॉपडाउन से कोई भी टेम्पलेट चुने। यदि ग्राहक टेम्पलेट संकरी थर्मल-शैली की रसीद है, तो PDF भी संकरी होगी — ऑनलाइन ऑर्डर के लिए पूरे पृष्ठ का दस्तावेज़ बेहतर हो सकता है, और गैलरी का **इनवॉइस** टेम्पलेट A4/Letter के लिए बनाया गया है।

:::tip प्रति-पृष्ठ ओवरराइड
यह सेटिंग **मेरा खाता** बटन को नियंत्रित करती है। किसी विशिष्ट पृष्ठ पर एकबारगी लिंक के लिए, शॉर्टकोड के [`template` विशेषता](#shortcode-attributes) से टेम्पलेट को फिर भी ओवरराइड किया जा सकता है, या नीचे दिए गए [डेवलपर फ़िल्टर](#developers) से इसे साइट-व्यापी (बटन के लिए भी) बदला जा सकता है।
:::

टेम्पलेट उसी [रसीद डेटा पेलोड](/receipts/receipt-data) से रेंडर होते हैं जिसका उपयोग POS करता है, इसलिए आपका लोगो, स्टोर पहचान, कर सेटिंग्स और अनुकूलन सभी लागू रहते हैं।

## सुरक्षा {#security}

रसीद लिंक में ऑर्डर की विशिष्ट key होती है — यही तंत्र WooCommerce अपने ऑर्डर पुष्टिकरण पृष्ठों के लिए उपयोग करता है — इसलिए बिना खाते के चेकआउट करने वाले अतिथि भी पुष्टिकरण पृष्ठ से लिंक का उपयोग कर सकते हैं। लिंक के बिना किसी व्यक्ति को उस ऑर्डर के ग्राहक के रूप में लॉग इन होना आवश्यक है। स्पष्ट `order_id` शॉर्टकोड केवल उस ऑर्डर के लॉग-इन स्वामी के लिए रेंडर होते हैं।

:::note सुंदर परमालिंक्स आवश्यक
सभी WCPOS चेकआउट पृष्ठों की तरह, रसीद URL WordPress रीराइट नियमों का उपयोग करता है। **सादे** परमालिंक्स (सेटिंग्स → परमालिंक्स) का उपयोग करने वाली साइटों को किसी अन्य परमालिंक संरचना पर स्विच करना होगा।
:::

## डेवलपर्स के लिए {#developers}

तीन फ़िल्टर स्टोरफ्रंट इंटरफ़ेसों को नियंत्रित करते हैं। वे ऊपर दी गई सेटिंग्स के ऊपर लागू होते हैं — ऐसी सशर्त लॉजिक के लिए उपयोगी जिन्हें सेटिंग्स व्यक्त नहीं कर सकतीं (प्रति-ऑर्डर, प्रति-ग्राहक, आदि):

```php
// Force the My Account Receipt button on or off, overriding the setting.
// The filter's default value is the "Let customers download receipts" setting,
// so you only need this to override it — e.g. show the button for one user role.
add_filter( 'woocommerce_pos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'woocommerce_pos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the
// "Receipt template for customers" setting. Receives and returns the full
// template array (null when none is configured).
add_filter( 'woocommerce_pos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

PDF रूट स्वयं `/wcpos-checkout/wcpos-receipt/{order_id}?key={order_key}&format=pdf` है — वही ऑर्डर-key-गेटेड एंडपॉइंट जिसका उपयोग POS रसीदों के लिए करता है, जहाँ `format=pdf` स्क्रीन पर दिखने वाले दृश्य के बजाय रेंडर किया गया PDF लौटाता है।
