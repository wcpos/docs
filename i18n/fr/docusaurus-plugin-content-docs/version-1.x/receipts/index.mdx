WCPOS comprend un système complet de modèles pour les reçus, factures, reçus cadeaux, bons de livraison, tickets de cuisine et plus encore — le tout géré dans **WP Admin → PDV → Modèles**.

:::tip Vous souhaitez simplement modifier votre reçu ?
Commencez par **[Personnaliser votre reçu](/1.x/receipts/customise)**. Cette page présente les trois façons les plus simples de le faire — choisir un autre modèle inclus, demander à l’IA d’en ajuster un ou le modifier manuellement.
:::

## Moteurs de modèles {#template-engines}

WCPOS prend en charge trois moteurs de modèles. Le moteur est choisi lors de la création d’un modèle ou lorsque vous cliquez sur **Utiliser le modèle** dans une carte de la galerie, et **ne peut pas être modifié ultérieurement** — créez un nouveau modèle pour changer de moteur.

<FeatureGrid>
  <FeatureCard icon="code" title="HTML sans logique (recommandé)">
    Des espaces réservés de style Mustache <code>{"{{variable}}"}</code> dans du HTML simple. Le rendu se fait côté client : les reçus **fonctionnent hors ligne**. À utiliser pour l’impression depuis le navigateur et les reçus PDF.
  </FeatureCard>
  <FeatureCard icon="print" title="XML thermique">
    Modèles XML qui produisent à la fois un aperçu à l’écran et des **commandes ESC/POS** pour les imprimantes de reçus thermiques. Un même modèle, deux sorties. À utiliser pour les imprimantes thermiques Epson, Star et autres.
  </FeatureCard>
  <FeatureCard icon="terminal" title="PHP hérité">
    Modèles PHP côté serveur utilisant les fonctions WooCommerce. Conservés pour assurer la rétrocompatibilité avec les personnalisations existantes du fichier <code>yourtheme/woocommerce-pos/receipt.php</code> . Une connexion au serveur est nécessaire pour le rendu.
  </FeatureCard>
</FeatureGrid>

## Galerie de modèles {#template-gallery}

La galerie propose des modèles prêts à l’emploi que vous pouvez utiliser tels quels ou personnaliser. Filtrez par **catégorie** (Reçu, Facture, Reçu cadeau, Ticket de cuisine, Devis / Bon de commande), **format** (HTML / Thermique) et **direction** (LTR / RTL) ; affichez un aperçu avec les données réelles de votre boutique. Le pied de chaque carte comporte un lien **Aperçu** et un bouton principal **Utiliser le modèle** — cliquer sur Utiliser le modèle crée une copie modifiable dans *Vos modèles*.

### Modèles de documents tiers {#third-party-document-templates}

Si **PDF Invoices & Packing Slips for WooCommerce** de WP Overnight est actif, WCPOS affiche également **Facture (WP Overnight)** et **Bon de livraison (WP Overnight)** dans la liste des modèles de reçus. Ces modèles HTML rendus côté serveur utilisent l’API de documents de WP Overnight et réemploient la numérotation des factures et bons de livraison, la mise en page, l’identité visuelle, les champs juridiques et fiscaux, ainsi que les personnalisations des modèles configurées dans cette extension.

Ils sont disponibles uniquement lorsque l’extension WP Overnight est active et nécessitent une connexion au serveur pour le rendu. Utilisez les modèles HTML ou thermiques inclus dans WCPOS lorsqu’une impression hors ligne est nécessaire.

### Affichage adaptatif des taxes {#adaptive-tax-display}

La plupart des modèles inclus (Standard, Standard RTL, Minimaliste/Moderne, Étroit, Facture, Devis, variantes Thermique simple) **s’adaptent automatiquement au réglage WooCommerce d’affichage des taxes** :

- Les **boutiques avec taxes incluses** (UE/Royaume-Uni/Australie) affichent les prix TTC avec une ligne « Taxes incluses ».
- Les **boutiques avec taxes exclues** (États-Unis/Canada) affichent les prix HT, avec les taxes ajoutées sur une ligne distincte.
- Le total général affiche toujours le montant TTC réellement facturé.

La famille **Détaillé** correspond à une facture fiscale formelle et détaille toujours les taxes avec des lignes HT et une ventilation explicite, quel que soit le réglage de la boutique.

## Fonctionnement {#how-it-works}

1. **Ajoutez un modèle** — cliquez sur **Utiliser le modèle** dans une carte de la galerie, ou créez le vôtre de toutes pièces.
2. **Personnalisez-le** à l’aide de l’éditeur intégré avec aperçu en direct, ou collez-le dans ChatGPT / Claude et demandez les modifications souhaitées.
3. **Activez-le** — activez le commutateur **Actif** dans *Vos modèles*. Chaque modèle de reçu actif apparaît dans la liste déroulante de l’écran des reçus à la caisse.
4. **Imprimez ou affichez** — les reçus s’ouvrent après le paiement, avec des options pour les imprimer, les envoyer par e-mail ou les consulter à l’écran. Vos modèles fonctionnent également au-delà de la caisse : les clients en ligne peuvent [télécharger leurs reçus depuis Mon compte](/1.x/receipts/storefront), avec la même présentation.

Les modèles sont générés à partir d’un [jeu de données de reçu](/1.x/receipts/receipt-data) standardisé, avec des sections pour les informations de la boutique, les lignes d’articles, les totaux, les taxes, les paiements, les remboursements, etc. Tous les champs monétaires incluent des variantes `_display` préformatées (par ex., `$29.99` au lieu de `29.99`).

## Fonctionnalités Pro {#pro-features}

Avec [WCPOS Pro](/1.x/getting-started/pro-license), chaque boutique peut avoir ses propres affectations de modèles, son identité visuelle (logo, adresse, coordonnées) et son ordre de modèles — utile pour les entreprises disposant de plusieurs points de vente, où chaque boutique imprime son propre en-tête.
