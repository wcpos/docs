WCPOS prend en charge des extensions qui ajoutent de nouvelles fonctionnalités à votre point de vente. Le répertoire d’extensions vous permet de parcourir les extensions disponibles, de les installer directement depuis les paramètres du PDV et de gérer les mises à jour.

:::info Fonctionnalité Pro
L’installation et la gestion des extensions nécessitent [WCPOS Pro](/1.x/getting-started/pro-license). La version gratuite affiche le catalogue d’extensions mais désactive les commandes d’installation et d’activation.
:::

## Parcourir les extensions {#browsing-extensions}

Ouvrez le répertoire d’extensions depuis `POS Settings > Extensions` (également intitulé **Extensions** dans certaines versions).

Le répertoire affiche une grille de cartes des extensions disponibles. Chaque carte indique :

- **Icône** (ou une pièce de puzzle par défaut si l’extension n’en fournit pas)
- **Nom et version**
- **Description**
- **Badge de catégorie**
- **Statut** — active, inactive, mise à jour disponible ou non installée

### Filtrage et recherche {#filtering-and-search}

Utilisez les **boutons-pastilles de catégorie** en haut pour filtrer les extensions par catégorie. Vous pouvez également utiliser le **champ de recherche** pour trouver des extensions par nom, description ou étiquettes.

## Installer une extension {#installing-an-extension}

1. Ouvrez `POS Settings > Extensions`.
2. Trouvez l’extension souhaitée et cliquez sur **Installer**.
3. L’extension est téléchargée et installée à l’aide de l’outil d’installation d’extensions de WordPress.
4. Une fois l’extension installée, cliquez sur **Activer** pour l’activer.

WCPOS utilise le `Plugin_Upgrader` natif de WordPress pour gérer l’installation : les extensions suivent donc le même processus que toute autre extension WordPress.

## Activation et désactivation {#activating-and-deactivating}

Chaque extension installée dispose de boutons **Activer** et **Désactiver** sur sa carte.

- **Activer** active l’extension afin qu’elle puisse fonctionner dans le PDV.
- **Désactiver** la désactive sans la désinstaller. Les fichiers de l’extension restent sur votre serveur et l’extension peut être réactivée à tout moment.

## Mettre à jour les extensions {#updating-extensions}

Lorsqu’une version plus récente d’une extension installée est disponible, la carte affiche un badge **Mise à jour disponible** et un bouton **Mettre à jour**.

### Mises à jour automatiques {#auto-updates}

Les extensions installées depuis le répertoire ont les **mises à jour automatiques activées par défaut**. Vous pouvez activer ou désactiver les mises à jour automatiques pour chaque extension depuis sa carte dans le répertoire. Lorsqu’elles sont activées, WordPress applique automatiquement les nouvelles versions, comme pour les autres extensions dont les mises à jour automatiques sont activées.

## Dépannage {#troubleshooting}

### Message « Nécessite Pro » sur les boutons {#requires-pro-message-on-buttons}

Les boutons d’installation, d’activation et de mise à jour sont désactivés dans la version gratuite de WCPOS. Passez à [WCPOS Pro](/1.x/getting-started/pro-license) pour gérer les extensions.

### L’extension ne s’installe pas {#extension-fails-to-install}

- Vérifiez que votre serveur WordPress dispose des autorisations d’écriture sur le répertoire `wp-content/plugins`.
- Vérifiez que votre serveur peut effectuer des requêtes HTTPS sortantes (certains hébergeurs bloquent les téléchargements externes).
- Consultez les détails de l’erreur dans `WP Admin > POS > Forums de support > Journaux`.

### L’extension n’apparaît pas après l’installation {#extension-not-appearing-after-install}

- Actualisez le PDV — la liste des extensions est mise en cache pendant une durée maximale de 12 heures.
- Vérifiez que l’extension est activée (les extensions installées mais inactives ne fonctionnent pas).

### Le catalogue ne se charge pas {#catalog-not-loading}

Le catalogue d’extensions est récupéré depuis une source distante et mis en cache localement pendant 12 heures. Si le catalogue ne se charge pas :

- Vérifiez la connexion Internet de votre serveur.
- Réessayez après l’expiration du cache, ou videz le cache des transients de votre serveur.

## Pour les développeurs {#for-developers}

### Créer une extension PDV {#creating-a-pos-extension}

Une extension WCPOS est une extension WordPress standard qui s’intègre au PDV via les hooks et les API de WCPOS. Pour en créer une :

1. **Commencez avec une extension WordPress.** Votre extension a besoin d’un en-tête d’extension standard et d’un fichier d’entrée, comme toute extension WooCommerce ou WordPress.
2. **Intégrez votre extension à WCPOS.** Utilisez les hooks et filtres fournis par WCPOS pour ajouter des fonctionnalités à l’interface ou au backend du PDV.
3. **Hébergez les versions sur GitHub.** Le répertoire d’extensions utilise GitHub Releases pour suivre les versions et fournir les mises à jour.

### Soumettre au répertoire {#submitting-to-the-directory}

Le catalogue d’extensions est maintenu dans le dépôt GitHub [`wcpos/extensions`](https://github.com/wcpos/extensions). Pour y répertorier votre extension :

1. Consultez le format du catalogue et les exigences relatives aux métadonnées dans le README du dépôt.
2. Ouvrez une pull request pour ajouter les métadonnées de votre extension à `catalog.json`.
3. Une fois la pull request fusionnée, votre extension apparaîtra dans le répertoire pour tous les utilisateurs de WCPOS Pro.

### Conventions de publication sur GitHub {#github-release-conventions}

Le cycle de mise à jour repose sur GitHub Releases :

- **Étiquetez les versions** en suivant le versionnage sémantique (par ex. `v1.0.0`, `v1.2.3`).
- **Joignez le fichier zip de l’extension** comme fichier de la version — c’est ce fichier qui est téléchargé lorsqu’un utilisateur installe ou met à jour l’extension.
- **Publiez la version** (ne la laissez pas à l’état de brouillon) pour que le répertoire puisse la détecter.

Lorsque vous publiez une nouvelle version, les utilisateurs ayant installé votre extension verront la mise à jour disponible dans leur répertoire d’extensions. Si les mises à jour automatiques sont activées, elle sera appliquée automatiquement.

Pour tous les détails sur le schéma du catalogue et le processus de soumission, consultez le dépôt [`wcpos/extensions`](https://github.com/wcpos/extensions).
