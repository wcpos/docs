## Note de commande {#order-note}

<div class="image-container">

    alt="Note de commande dans le PDV"

- Ouvre une boîte de dialogue pour ajouter une note client à la commande.
- Les notes clients sont visibles par le client et apparaissent par défaut sur le reçu, dans son espace Mon compte et dans `WP Admin > WooCommerce > Orders > Order`, sous l'adresse de livraison.

:::note
Les notes de commande sont visibles par les clients.
:::

## Métadonnées de commande {#order-meta}

- Ouvre une fenêtre pour gérer les métadonnées supplémentaires de la commande.
- Les fonctionnalités permettent de :
  - Changer la devise de la commande.
  - Ajouter un ID de transaction (par ex. provenant d'un terminal de paiement externe).
  - Ajouter des métadonnées personnalisées à la commande.

:::note
De nouvelles fonctionnalités seront ajoutées à cette fenêtre au fil du temps, notamment l'intégration avec d'autres extensions WooCommerce.
:::

### Que sont les métadonnées dans WooCommerce ? {#what-is-meta-data-in-woocommerce}

Les métadonnées fournissent des informations supplémentaires sur les commandes et sont accessibles via l'API REST de WooCommerce. Les développeurs et les extensions utilisent ces données pour étendre les fonctionnalités, par exemple en intégrant des services tiers.

### Vue JSON {#json-view}

- Affiche la représentation JSON brute de la commande, utile pour le débogage ou l'intégration.

## Enregistrer sur le serveur {#save-to-server}

- Permet d'enregistrer les paniers ouverts sur le serveur, afin qu'ils soient conservés en toute sécurité et accessibles ultérieurement.
- Crée une commande WooCommerce avec le statut `pos-open`.

### Pourquoi enregistrer ? {#why-save}

Lorsqu'une nouvelle commande est créée dans le PDV, elle n'existe que localement. 
L'enregistrement de la commande garantit sa conservation, même si la base de données locale est effacée.

Consultez [Commandes ouvertes](/1.x/pos/cart/open-orders) pour en savoir plus sur la gestion des commandes enregistrées.

## Annuler {#void}

- Deux cas de figure :
  - Commandes non enregistrées :
    - Si la commande n'a pas été enregistrée sur le serveur, elle sera définitivement supprimée de la base de données locale.
  - Commandes enregistrées :
    - Si la commande est enregistrée sur le serveur, elle sera déplacée dans la corbeille de WooCommerce et supprimée de la base de données locale.
- Pour récupérer une commande annulée :
  - Accédez à `WP Admin > WooCommerce > Orders > Trash`.

## Paiement {#checkout}

- Enregistre la commande sur le serveur et lance le processus de paiement.
- Ouvre l'[écran de paiement](/1.x/pos/checkout) pour finaliser le paiement.
