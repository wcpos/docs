Chaque article du panier occupe une ligne directement modifiable. WCPOS permet de modifier facilement les quantités, les prix et d’autres détails au sein même du panier.

## Types d’éléments de ligne {#line-item-types}

WooCommerce utilise trois types d’éléments de ligne :

| Type | Description | Exemples |
|------|-------------|----------|
| **line_item** | Produits de votre catalogue | T-shirt, tasse à café |
| **fee_line** | Frais supplémentaires | Emballage cadeau, frais de service |
| **shipping_line** | Frais d’expédition | Expédition standard, livraison express |

:::note
Les frais d’expédition sont saisis manuellement. Le PDV ne calcule pas automatiquement les tarifs d’expédition.
:::

## Modification des éléments de ligne {#editing-line-items}

### Quantité {#quantity}

Cliquez sur le champ de quantité pour le modifier directement. Saisissez un nouveau nombre ou utilisez les flèches d’incrémentation et de décrémentation.

{/* Screenshot: cart-line-item-edit-qty.png */}

### Nom du produit {#product-name}

Pour les produits divers et les frais, vous pouvez modifier le nom directement en cliquant dessus.

### Prix {#price}

Cliquez sur le champ du prix pour modifier le prix unitaire. Cela permet de :

- Appliquer des remises manuelles
- S’aligner sur un autre prix
- Corriger les erreurs de prix

Le total est automatiquement recalculé selon la quantité × le prix.

:::note Modifier un prix ne constitue pas une « remise » WooCommerce
Un prix réduit est enregistré comme prix promotionnel de l’article — les reçus peuvent afficher l’économie réalisée, mais le total **Remise** de la commande est réservé aux coupons et les rapports comptabilisent la vente au prix payé. Consultez [Remises sur le panier](/1.x/pos/cart/discounts#why-tracked-differently) pour comprendre pourquoi WooCommerce traite ces deux cas différemment.
:::

### Menu à trois points {#three-dot-menu}

Cliquez sur les **⋮** (trois points) de n’importe quel élément de ligne pour accéder à des options supplémentaires :

{/* Screenshot: cart-line-item-menu.png */}

#### Formulaire de modification {#edit-form}

Ouvre un formulaire détaillé permettant de modifier tous les champs de l’élément de ligne.

#### Vue JSON brute {#raw-json-view}

Affiche les données JSON brutes de l’élément de ligne. Cette vue est particulièrement utile pour :

- **Débogage** - Voir exactement quelles données sont envoyées à WooCommerce
- **Dépannage** - Identifier les problèmes liés aux champs personnalisés ou aux métadonnées
- **Développement** - Comprendre la structure des données pour les intégrations

### Supprimer un élément {#remove-item}

Cliquez sur le bouton rouge **×** pour supprimer un élément du panier.

## Attributs de variation {#variation-attributes}

Pour les produits variables, les attributs de la variation sélectionnée s’affichent sous le nom du produit :

```
Hoodie
Colour: Green
Size: Large
```

Ces attributs font partie des données de l’élément de ligne et sont inclus dans la commande.

## Métadonnées {#meta-data}

Si vous avez configuré les [Clés de métadonnées](/1.x/pos/product-panel#meta-data-keys) dans les paramètres du panneau des produits, ces données sont automatiquement copiées dans l’élément de ligne lorsque le produit est ajouté au panier.

Vous pouvez consulter ces métadonnées dans la vue JSON brute.

## Fractionnement des éléments de ligne {#splitting-line-items}

Si cette option est activée dans les [Paramètres d’affichage](/1.x/pos/cart#display-settings), vous pouvez fractionner un élément de ligne en plusieurs lignes. Cela permet d’appliquer des remises différentes à certaines unités d’un même produit selon les souhaits du client.

## Conseils {#tips}

### Ajustements rapides des prix {#quick-price-adjustments}

Pour appliquer rapidement une remise :

1. Cliquez sur le champ du prix
2. Saisissez le nouveau prix
3. Appuyez sur Entrée

### Navigation au clavier {#keyboard-navigation}

- **Tab** - Passer d’un champ modifiable à l’autre
- **Entrée** - Confirmer la modification
- **Échap** - Annuler la modification

### Modifications groupées {#batch-edits}

Pour les commandes complexes, utilisez le menu à trois points afin d’accéder au formulaire de modification complet, qui affiche tous les champs à la fois.
