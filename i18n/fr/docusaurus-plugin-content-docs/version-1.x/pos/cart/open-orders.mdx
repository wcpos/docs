WCPOS vous permet de gérer plusieurs commandes simultanément. C’est pratique pour mettre des commandes de côté à la demande des clients, passer d’une transaction à une autre et reprendre votre travail après une interruption.

## Carrousel des commandes ouvertes {#open-orders-carousel}

Au bas du panneau du panier, un carrousel horizontal affiche toutes les commandes ouvertes :

{/* Screenshot: open-orders-carousel.png */}

- Chaque panier affiche son **montant total**
- La **commande active** est mise en évidence
- Cliquez sur un panier pour y accéder
- Faites défiler vers la gauche ou la droite pour afficher les autres paniers

## Créer une nouvelle commande {#creating-a-new-order}

Un nouveau panier vide est toujours disponible. Cliquez simplement sur un panier vide dans le carrousel ou commencez à ajouter des produits lorsque le panier actif est vide.

## Passer d’une commande à une autre {#switching-between-orders}

Cliquez sur une commande du carrousel pour y accéder. Le panneau du panier affiche alors le contenu de la commande sélectionnée.

**Cas d’utilisation :**

- Un client s’absente pour aller chercher un autre article
- Vous devez aider rapidement un client alors qu’une commande importante est en cours
- Comparer les prix ou les articles de différentes commandes

## Enregistrer les commandes sur le serveur {#saving-orders-to-server}

Les commandes se trouvent dans l’un de ces deux états :

### En local uniquement {#local-only}

Par défaut, les nouvelles commandes sont enregistrées uniquement dans la base de données locale du navigateur ou de l’application. Elles sont conservées après l’actualisation de la page, mais :

- Elles ne sont pas visibles dans l’administration WooCommerce
- Elles sont perdues si la base de données locale est effacée
- Elles ne sont pas accessibles depuis d’autres appareils

### Enregistrées sur le serveur {#saved-to-server}

Cliquez sur **Enregistrer sur le serveur** pour créer une commande WooCommerce avec le statut `pos-open`. Cela :

- Crée une véritable commande dans WooCommerce
- La conserve même si la base de données locale est effacée
- La rend accessible depuis d’autres appareils
- La fait apparaître dans l’administration WP > WooCommerce > Commandes

:::tip Quand enregistrer une commande
Enregistrez les commandes sur le serveur lorsque :
- Un client souhaite mettre une commande de côté pour venir la récupérer plus tard
- Vous terminez votre service et un autre caissier va prendre le relais
- Vous souhaitez disposer d’une sauvegarde en cas de problème avec l’application ou le navigateur
:::

## Récupérer les commandes enregistrées {#recovering-saved-orders}

Si vous avez enregistré des commandes sur le serveur, vous pouvez les retrouver en :

1. Ouvrant l’écran **Commandes** (fonctionnalité Pro)
2. Filtrant par statut `pos-open`
3. Rouvrant la commande

## Persistance des commandes {#order-persistence}

### Stockage local {#local-storage}

WCPOS stocke les commandes dans la base de données locale de l’appareil. Vous bénéficiez ainsi :

- D’une conservation des commandes entre les sessions du navigateur
- D’un accès rapide, sans requêtes réseau
- D’un fonctionnement hors ligne

### Synchronisation avec le serveur {#sync-with-server}

Lorsque vous enregistrez une commande sur le serveur ou procédez au paiement :

- La commande est envoyée à WooCommerce
- Une confirmation est reçue
- Les données locales et celles du serveur sont synchronisées

## Annuler des commandes {#voiding-orders}

Pour supprimer une commande ouverte :

1. Accédez à la commande que vous souhaitez supprimer
2. Cliquez sur le bouton **Annuler**

**Conséquences :**

- **Commandes non enregistrées :** suppression définitive de la base de données locale
- **Commandes enregistrées :** déplacées dans la corbeille WooCommerce et supprimées localement

Pour récupérer une commande enregistrée annulée :
1. Accédez à `WP Admin > WooCommerce > Orders > Trash`
2. Restaurez la commande

## Conseils {#tips}

### Organiser les commandes {#keep-orders-organized}

Lorsque plusieurs commandes sont ouvertes, il est utile de :

- Ajouter le nom du client aux commandes pour les repérer facilement
- Ajouter des notes à la commande pour indiquer la raison de sa mise de côté
- Enregistrer les commandes importantes sur le serveur

### Passation de service {#shift-handoffs}

Lorsque vous terminez votre service avec des commandes ouvertes :

1. Enregistrez toutes les commandes importantes sur le serveur
2. Ajoutez des notes à la commande pour expliquer son statut
3. Le prochain caissier peut y accéder depuis l’écran Commandes

### Considérations en mode hors ligne {#offline-considerations}

En cas de perte de connexion :

- Les commandes locales restent accessibles et vous pouvez continuer à ajouter des articles
- Vous pouvez finaliser une commande avec un moyen de paiement utilisable hors ligne ; les passerelles dépendant du serveur restent indisponibles tant que leurs services ne sont pas accessibles
- Vous ne pouvez pas enregistrer de commandes sur le serveur avant le rétablissement de la connexion
- Vous ne pouvez pas créer de nouveaux clients avant le rétablissement de la connexion
