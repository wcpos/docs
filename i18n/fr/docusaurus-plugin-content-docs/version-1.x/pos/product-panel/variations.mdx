Dans WooCommerce, les produits variables sont des produits qui proposent plusieurs options, comme différentes tailles, couleurs ou matières. WCPOS offre plusieurs moyens de gérer efficacement les produits variables.

## Identifier les produits variables {#identifying-variable-products}

Dans le panneau des produits, les produits variables se distinguent par les éléments suivants :

- **Bouton fléché** (<Icon name="circle-arrow-right" color="green" />) à la place du bouton plus (<Icon name="circle-plus" color="green" />) utilisé pour les produits simples
- **Options d'attributs** affichées sous le nom du produit (par ex. « Couleur : bleu, vert, rouge »)
- Lien **« Développer »** pour afficher toutes les variations directement dans la liste

## Ajouter des produits variables au panier {#adding-variable-products-to-cart}

### Méthode 1 : fenêtre contextuelle rapide {#method-1-quick-popover}

Cliquez sur la <Icon name="circle-arrow-right" color="green" /> flèche verte d'un produit variable pour ouvrir une fenêtre contextuelle contenant un menu déroulant pour chaque attribut :

1. Cliquez sur le <Icon name="circle-arrow-right" color="green" /> bouton
2. Sélectionnez une option dans chaque menu déroulant (par ex. Taille : grande, Couleur : bleu)
3. La variation correspondante est ajoutée au panier

Une fois votre sélection réduite à une seule variation, la fenêtre contextuelle affiche son état de stock à côté du bouton d'ajout au panier : **« 8 en stock »** si le stock est suivi, **« En réapprovisionnement »** pour les articles disponibles en commande différée, ou **« Rupture de stock »** (le bouton est alors désactivé). Les variations dont le stock n'est pas suivi individuellement n'affichent aucun nombre.

Lorsque le paramètre d'affichage **Afficher les produits en rupture de stock** masque les articles épuisés, les options dont toutes les variations sont en rupture de stock apparaissent en grisé et ne peuvent pas être sélectionnées.

C'est la méthode la plus rapide lorsque vous savez exactement quelle variation vous voulez.

{/* Screenshot: variation-popover.png */}

### Méthode 2 : développer dans la liste {#method-2-expand-inline}

Cliquez sur le lien **« Développer »** d'un produit variable pour afficher toutes ses variations directement dans la liste des produits :

1. Cliquez sur **Développer** sous le nom du produit
2. Toutes les variations apparaissent sur des lignes distinctes sous le produit parent
3. Cliquez sur le <Icon name="circle-plus" color="green" /> bouton d'une variation pour l'ajouter au panier
4. Cliquez sur **Réduire** pour masquer à nouveau les variations

Lorsque le paramètre d'affichage **Afficher les produits en rupture de stock** masque les articles épuisés, les variations en rupture de stock ne figurent pas dans ces lignes (les variations disponibles en réapprovisionnement restent affichées, car elles peuvent toujours être vendues).

Cette méthode est utile si vous souhaitez voir toutes les options disponibles, leur niveau de stock et leur prix respectifs.

{/* Screenshot: variations-expanded.png */}

### Méthode 3 : numérisation de codes-barres {#method-3-barcode-scanning}

Chaque variation de produit peut avoir son propre code-barres. Lorsque vous scannez le code-barres d'une variation :

- Si une seule variation correspond, elle est directement ajoutée au panier
- Si plusieurs variations partagent le même code-barres, la barre de recherche affiche les résultats correspondants
- Si la variation correspondante est en rupture de stock et que le paramètre d'affichage **Afficher les produits en rupture de stock** masque les articles épuisés, le scan est refusé et un message *« Rupture de stock »* s'affiche au lieu de l'ajouter au panier

La recherche de variations s'effectue également sur le **serveur** : si la variation scannée ne se trouve pas encore sur l'appareil, WCPOS la recherche en ligne et la télécharge, comme pour les produits simples.

Consultez [Numérisation de Code-Barres](/pos/product-panel/barcode-scanning) pour plus de détails.

## Informations sur les Variations {#variation-information}

Chaque variation peut afficher :

- **Attributs de variation** - Les options spécifiques pour cette variation (ex. : "Size : Large, Colour : Blue")
- **SKU** - Identifiant unique pour la variation (peut différer du produit parent)
- **Quantité en Stock** - Niveau de stock individuel pour la variation
- **Prix** - Les variations peuvent avoir des prix différents de ceux du produit parent ou entre elles

## Variations dans le Panier {#variations-in-the-cart}

Lorsqu'une variation est ajoutée au panier, elle s'affiche :

- **Nom du produit** du produit parent
- **Attributs de variation** sous le nom
- **Prix** pour cette variation spécifique

Vous pouvez modifier l'article de ligne comme n'importe quel autre produit dans le panier.

## Conseils pour une Sélection Efficace des Variations {#tips-for-efficient-variation-selection}

### Utiliser la Numérisation de Code-Barres {#use-barcode-scanning}

Si vos variations ont des codes-barres individuels (recommandé), le scan est le moyen le plus rapide de les ajouter au panier.

### Configurer les Réglages d'Affichage {#configure-display-options}

Dans le Product Panel [Réglages d'Affichage](/pos/product-panel#display-settings), activez l'option **Attributs** pour afficher les attributs de variation directement dans la liste des produits sans développer.

### Navigation au Clavier {#keyboard-navigation}

Lorsque le popover de variation est ouvert, vous pouvez utiliser les touches fléchées du clavier pour naviguer entre les options et Entrée pour sélectionner.

## F.A.Q. {#faq}

<Accordion>
  <AccordionItem question="Pourquoi ne puis-je pas voir une variation spécifique ?">

Vérifiez que la variation :
- Est publiée et n'est pas en statut brouillon
- Est définie sur "En Stock" ou a une quantité en stock > 0 (si la gestion des stocks est activée)
- A tous les attributs requis définis

Assurez-vous également que vous n'avez pas filtré le produit avec le filtre "En Stock" si la variation est en rupture de stock.

  </AccordionItem>

  <AccordionItem question="Comment ajouter des codes-barres aux variations individuelles ?">

Dans WooCommerce, éditez le produit variable et développez chaque variation. Vous pouvez ajouter un code-barres unique au champ de code-barres de chaque variation (généralement `_sku` ou `_global_unique_id` en fonction de votre configuration).

  </AccordionItem>
</Accordion>
