Dans WooCommerce, les produits variables proposent plusieurs options, comme différentes tailles, couleurs ou matières. WCPOS offre plusieurs moyens de gérer efficacement ces produits.

## Identifier les produits variables {#identifying-variable-products}

Dans le panneau des produits, les produits variables se distinguent par les éléments suivants :

- **Bouton fléché** (<Icon name="circle-arrow-right" color="green" />) à la place du bouton plus (<Icon name="circle-plus" color="green" />) utilisé pour les produits simples
- **Options d'attributs** affichées sous le nom du produit (par ex. « Couleur : bleu, vert, rouge »)
- **Lien « Développer »** pour afficher toutes les variations directement dans la liste

## Ajouter des produits variables au panier {#adding-variable-products-to-cart}

### Méthode 1 : fenêtre contextuelle rapide {#method-1-quick-popover}

Cliquez sur le bouton fléché vert <Icon name="circle-arrow-right" color="green" /> d'un produit variable pour ouvrir une fenêtre contextuelle contenant un menu déroulant pour chaque attribut :

1. Cliquez sur le bouton <Icon name="circle-arrow-right" color="green" /> bouton
2. Sélectionnez une option dans chaque menu déroulant (par ex. Taille : grande, Couleur : bleu)
3. La variation correspondante est ajoutée au panier

Une fois votre sélection réduite à une seule variation, la fenêtre contextuelle affiche l'état de son stock à côté du bouton d'ajout au panier : **« 8 en stock »** si le stock est suivi, **« En réapprovisionnement »** pour les articles disponibles en commande différée, ou **« Rupture de stock »** (le bouton est alors désactivé). Les variations dont le stock n'est pas suivi individuellement n'affichent aucun nombre.

Lorsque le paramètre d'affichage **Afficher les produits en rupture de stock** masque les articles épuisés, les options dont toutes les variations sont en rupture de stock apparaissent en grisé et ne peuvent pas être sélectionnées.

C'est la méthode la plus rapide lorsque vous savez exactement quelle variation vous souhaitez.

{/* Screenshot: variation-popover.png */}

### Méthode 2 : développer dans la liste {#method-2-expand-inline}

Cliquez sur le lien **« Développer »** d'un produit variable pour afficher toutes ses variations directement dans la liste des produits :

1. Cliquez sur **Développer** sous le nom du produit
2. Toutes les variations apparaissent sur des lignes distinctes sous le produit parent
3. Cliquez sur le bouton <Icon name="circle-plus" color="green" /> d'une variation pour l'ajouter au panier
4. Cliquez sur **Réduire** pour masquer à nouveau les variations

Lorsque le paramètre d'affichage **Afficher les produits en rupture de stock** masque les articles épuisés, les variations en rupture de stock ne figurent pas dans ces lignes (les variations disponibles en réapprovisionnement restent affichées, car elles peuvent toujours être vendues).

Cette méthode est utile lorsque vous souhaitez voir toutes les options disponibles, leurs niveaux de stock et leurs prix respectifs.

{/* Screenshot: variations-expanded.png */}

### Méthode 3 : lecture de codes-barres {#method-3-barcode-scanning}

Chaque variation de produit peut avoir son propre code-barres unique. Lorsque vous scannez le code-barres d'une variation :

- Si une seule variation correspond, elle est ajoutée directement au panier
- Si plusieurs variations partagent le même code-barres, la barre de recherche affiche les résultats correspondants
- Si la variation correspondante est en rupture de stock et que le paramètre d'affichage **Afficher les produits en rupture de stock** masque les articles épuisés, le scan est refusé avec un message *« Rupture de stock »* au lieu d'ajouter la variation au panier

La recherche de variations s'effectue également sur le **serveur** : si une variation scannée n'est pas encore présente sur l'appareil, WCPOS la recherche en ligne et la télécharge — comme pour les produits simples.

Consultez [Lecture de codes-barres](/1.x/pos/product-panel/barcode-scanning) pour plus de détails.

## Informations sur les variations {#variation-information}

Chaque variation peut afficher :

- **Attributs de variation** - Les options propres à cette variation (par ex. « Taille : grande, Couleur : bleu »)
- **SKU** - Identifiant unique de la variation (peut différer de celui du produit parent)
- **Quantité en Stock** - Niveau de stock individuel de la variation
- **Prix** - Les variations peuvent avoir des prix différents de celui du produit parent ou des autres variations

## Variations dans le panier {#variations-in-the-cart}

Lorsqu'une variation est ajoutée au panier, elle affiche :

- Le **nom du produit** parent
- Les **attributs de variation** sous le nom
- Le **Prix** de cette variation

Vous pouvez modifier cette ligne comme n'importe quel autre produit du panier.

## Conseils pour sélectionner efficacement les variations {#tips-for-efficient-variation-selection}

### Utiliser la lecture de codes-barres {#use-barcode-scanning}

Si vos variations possèdent chacune leur propre code-barres (recommandé), le scan est le moyen le plus rapide de les ajouter au panier.

### Configurer les options d'affichage {#configure-display-options}

Dans les [Réglages d'Affichage](/1.x/pos/product-panel#display-settings) du panneau des produits, activez l'option **Attributs** pour afficher les attributs de variation directement dans la liste des produits, sans la développer.

### Navigation au clavier {#keyboard-navigation}

Lorsque la fenêtre contextuelle des variations est ouverte, vous pouvez utiliser les touches fléchées du clavier pour parcourir les options et la touche Entrée pour sélectionner une option.

## F.A.Q. {#faq}

<Accordion>
  <AccordionItem question="Pourquoi une variation spécifique n'apparaît-elle pas ?">

Vérifiez que la variation :
- Est publiée et n'est pas à l'état de brouillon
- Est définie sur « En Stock » ou possède une quantité en stock > 0 (si la gestion des stocks est activée)
- Possède tous les attributs requis

Vérifiez également que le filtre « En Stock » ne masque pas le produit si la variation est en rupture de stock.

  </AccordionItem>

  <AccordionItem question="Comment ajouter des codes-barres aux variations individuelles ?">

Dans WooCommerce, modifiez le produit variable et développez chaque variation. Vous pouvez ajouter un code-barres unique dans le champ de code-barres de chaque variation (généralement `_sku` ou `_global_unique_id`, selon votre configuration).

  </AccordionItem>
</Accordion>
