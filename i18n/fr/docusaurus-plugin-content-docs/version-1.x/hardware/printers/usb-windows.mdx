**Symptôme :** l'imprimante est listée, mais la page de test n'arrive jamais — ou bien une page de lettres, de crochets et de symboles sans queue ni tête sort à la place d'un reçu.

## Pourquoi cela arrive {#why-it-happens}

Sous Windows, le pilote installé avec l'imprimante s'approprie le port USB. L'application ne peut pas atteindre l'imprimante directement au-delà de ce pilote : elle imprime donc via la **file d'attente Windows installée** de l'imprimante. Cela fonctionne — à condition que la file d'attente transmette les commandes du reçu sans y toucher. Une file d'attente liée au pilote du fabricant les réinterprète ou les supprime souvent, d'où la page de symboles.

## Ce qu'il faut faire {#do-this}

1. Ouvrez **Paramètres → Bluetooth et appareils → Imprimantes et scanners**.
2. Choisissez **Ajouter un appareil**, puis **Ajouter manuellement** lorsque Windows ne parvient pas à la trouver.
3. Sélectionnez **Ajouter une imprimante locale**, et choisissez le port **USB** de l'imprimante dans la liste.
4. Comme pilote, choisissez le fabricant **Generic** et le modèle **Generic / Text Only**.
5. Donnez à la file d'attente un nom que vous reconnaîtrez, puis terminez.
6. De retour dans le POS, ouvrez **Paramètres → Impression → Ajouter une imprimante**, relancez la recherche et choisissez cette file d'attente. Imprimez une page de test.

Si une page de symboles sort encore, c'est que l'application trouve toujours la file d'attente du pilote du fabricant. Supprimez-la, ou assurez-vous de sélectionner la file Generic/Text par son nom.

## Toujours bloqué ? {#still-stuck}

Utilisez **Copier le rapport de configuration** sur l'écran de dépannage et collez-le dans votre message — il indique la file d'attente utilisée par l'application.
