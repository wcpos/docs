**Symptôme :** la page web de l'imprimante se charge, son auto-test au panneau s'imprime, Secure Printing est déjà désactivé — et chaque travail envoyé depuis le POS échoue ou expire quand même. Éteindre et rallumer n'y change rien.

## Pourquoi cela arrive {#why-it-happens}

On peut demander aux imprimantes Epson d'aller chercher elles-mêmes leurs travaux sur un serveur, une fonction appelée **Server Direct Print**. Une fonction voisine, **ePOS-Device**, permet à une application de garder l'imprimante ouverte pendant toute une session. L'une comme l'autre s'approprie le moteur d'impression, et tant qu'il est occupé, l'imprimante refuse tout le reste comme si elle était occupée — sans le dire. Comme il s'agit d'un réglage enregistré dans l'imprimante, un redémarrage ne le supprime pas.

C'est généralement une installation précédente, un service d'impression en cuisine ou une autre caisse qui l'a laissé activé.

## Le désactiver {#turn-it-off}

1. Ouvrez `https://printer-ip` dans un navigateur et acceptez l'avertissement de certificat.
2. **Administrator Login** — le mot de passe est le numéro de série figurant sur l'étiquette sous l'imprimante, sauf si quelqu'un l'a changé.
3. Trouvez **Server Direct Print** (dans les services ou les paramètres d'impression de l'imprimante, selon le micrologiciel) et réglez-le sur **Disable**.
4. Sur le même écran, vérifiez que **ePOS-Device** est également désactivé si rien d'autre ne l'utilise.
5. Confirmez, puis débranchez l'imprimante dix secondes et rebranchez-la.
6. Réimprimez la page de test.

:::note Un autre système l'utilise peut-être
Si un autre système imprime réellement via Server Direct Print — un écran de cuisine, un service de commandes en ligne — un seul des deux peut s'approprier l'imprimante. Dirigez cet autre système ailleurs, ou donnez au POS sa propre imprimante.
:::

## Toujours bloqué ? {#still-stuck}

Utilisez **Copier le rapport de configuration** sur l'écran de dépannage et collez-le dans votre message — il enregistre la réponse de l'imprimante sur chaque port.
