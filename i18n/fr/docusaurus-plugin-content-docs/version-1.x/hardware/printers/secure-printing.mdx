**Symptôme :** l'application indique *« Secure Printing est activé. Désactivez-le sur l'imprimante, puis réessayez. »* Ou bien une Epson toute neuve est trouvée sur le réseau, la page de test semble partir, et rien ne sort — aucune erreur, aucun voyant, et la page d'état de l'imprimante indique qu'elle est disponible. Les auto-tests lancés depuis le panneau s'impriment sans problème.

## Pourquoi cela arrive {#why-it-happens}

Les imprimantes Epson de la série TM fabriquées pour l'UE et le Royaume-Uni depuis le **1er août 2025** sont livrées avec **Secure Printing** activé, afin de respecter la directive européenne sur les équipements radioélectriques. Tant que cette option est active, l'imprimante accepte les travaux envoyés par les anciens canaux non chiffrés puis les **supprime silencieusement**.

| Canal | Secure Printing **activé** | **désactivé** |
|---|---|---|
| TCP brut, port 9100 | Accepté, puis supprimé | Imprime |
| ePOS-Print en HTTP (80, 8008) | Non pris en charge | Imprime |
| ePOS-Print en HTTPS (443, 8043) | Imprime | Imprime |

Les unités vendues hors de l'UE peuvent embarquer le même micrologiciel. Si une Epson neuve présente ce symptôme, où que ce soit, vérifiez le réglage.

## Le désactiver {#turn-it-off}

Il vous faut le mot de passe administrateur de l'imprimante. Sur les modèles récents, c'est le **numéro de série** figurant sur l'étiquette sous l'imprimante ; les modèles plus anciens utilisaient `epson`.

1. Trouvez l'adresse de l'imprimante — elle figure sur la page d'état (ouvrez le capot du rouleau, maintenez **Feed**).
2. Ouvrez `https://printer-ip` dans un navigateur et acceptez l'avertissement de certificat.
3. **Administrator Login**, puis **Print → Secure Printing**.
4. Réglez sur **Disable** et confirmez.
5. Débranchez l'imprimante dix secondes, puis rebranchez-la.
6. Réimprimez la page de test.

:::warning Une mise à jour du micrologiciel le réactive
Epson réinitialise la configuration de sécurité à ses valeurs par défaut lors d'une mise à jour du micrologiciel. Si une imprimante qui fonctionnait depuis des mois s'arrête juste après une mise à jour, refaites ces étapes.
:::

Pendant que vous y êtes, définissez votre propre mot de passe administrateur — n'importe qui sur le même réseau peut atteindre une imprimante de reçus laissée ouverte.

## Toujours bloqué ? {#still-stuck}

Utilisez **Copier le rapport de configuration** et collez-le dans votre message. Voir aussi la [FAQ d'Epson sur la directive sur les équipements radioélectriques](https://www.epson.co.uk/en_GB/faq/KA-01896/contents?loc=en-us).
