  <WizardStep id="network-setup" title="Connecter une imprimante réseau">

Allez dans **PDV &gt; Paramètres &gt; Impression &gt; Ajouter une imprimante**. Saisissez l'**adresse IP** de l'imprimante, puis cliquez sur Enregistrer.

Pour trouver l'adresse IP, imprimez l'auto-test réseau de l'imprimante :

- **Star :** maintenez le bouton **FEED** enfoncé pendant environ 5 secondes alors que l'imprimante est déjà allumée.
- **Epson :** maintenez le bouton **FEED** enfoncé pendant que vous allumez l'imprimante.

Nous recommandons vivement d'attribuer à l'imprimante une **adresse fixe** (une réservation DHCP sur votre routeur) afin qu'un changement d'adresse ne bloque pas l'impression par la suite.

<WizardFigure src="/img/printer-wizard/star-selftest.png" alt="Auto-test réseau de l'imprimante avec l'adresse IP et les ports ouverts mis en évidence" summary="L'auto-test affiche l'adresse IP actuelle de l'imprimante et les ports réseau ouverts." />

  <WizardFix id="fix-not-printing" title="L'impression de test ne sort pas">

Commencez par les vérifications rapides : y a-t-il du papier, le capot est-il fermé et le papier est-il chargé dans le bon sens ? Le papier thermique ne s'imprime que sur une face — s'il est à l'envers, l'imprimante fait sortir du papier vierge. Faites le test de la rayure : grattez le papier avec un ongle ; la face qui se marque doit être orientée vers la tête d'impression.

Vérifiez ensuite que l'imprimante est joignable : ouvrez `http://<printer-ip>/` dans un navigateur web (si la page ne se charge pas, essayez `https://<printer-ip>/`). Si la page de configuration de l'imprimante s'affiche, celle-ci est sur le réseau et le problème vient des paramètres ; si aucune des deux pages ne se charge, il s'agit d'un problème de réseau ou d'adresse IP (adresse incorrecte ou imprimante non connectée).

  <WizardFix id="net-deep" title="Vérifications réseau approfondies">
Si les vérifications de base sont concluantes mais que rien ne s'imprime, l'un de ces problèmes réseau en est généralement la cause :

**L'adresse IP est incorrecte ou a changé.** Vérifiez que l'adresse IP figurant sur l'auto-test de l'imprimante correspond à celle que vous avez saisie — il est facile d'utiliser celle d'une autre imprimante. Les imprimantes en DHCP peuvent changer d'adresse au redémarrage ; configurez une **réservation DHCP** sur votre routeur pour qu'elle reste fixe. Une adresse commençant par `169.254` signifie que l'imprimante n'a jamais rejoint le réseau.

**L'impression fonctionnait, puis la première impression de la journée échoue.** La carte réseau de l'imprimante s'est mise en veille ; le premier travail la réveille et se perd. Envoyez un second test et envisagez une connexion **Ethernet** filaire pour une caisse fixe.

**Deux caisses, une imprimante.** De nombreuses imprimantes réseau Star n'acceptent qu'une seule connexion à la fois par défaut — la seconde caisse dépasse alors le délai de connexion. Activez le **multi-session sur le port 9100** dans la configuration web de l'imprimante.

**Les paramètres réseau de l'imprimante utilisent le mauvais protocole.** WCPOS envoie les travaux en **TCP brut sur le port 9100**. Ouvrez la page de configuration de l'imprimante dans un navigateur (`http://<printer-ip>/`, ou `https://<printer-ip>/` si la page ne se charge pas) et assurez-vous que l'impression **brute / port 9100** est activée — si l'imprimante n'est configurée que pour LPR, IPP ou WSD, le travail n'arrive jamais.

**Le Wi-Fi ne se connecte pas ou se déconnecte sans arrêt.** Les imprimantes de reçus fonctionnent généralement **uniquement en 2.4GHz** — connectez-les à un réseau 2.4GHz, et non à un réseau exclusivement 5GHz ou avec sélection automatique de bande. Si la connexion est instable, une connexion Ethernet filaire est la solution fiable.

  <WizardInvalid id="web-generic-invalid" title="Les imprimantes génériques nécessitent l'application de bureau">

Un navigateur web ne peut pas ouvrir de connexion réseau brute ; il ne peut donc joindre que les imprimantes **Epson** et **Star** dotées d'un serveur d'impression intégré. Pour une imprimante réseau ESC/POS générique, utilisez l'**application de bureau**, qui se connecte directement sur le réseau (port 9100) — téléchargez-la depuis la page [Configuration de l'imprimante](/1.x/hardware/printers).

  </WizardInvalid>

  <WizardStep id="web-net-setup" title="Connecter une imprimante réseau depuis l'application web">

Imprimer sur une imprimante réseau **depuis un navigateur web** est la configuration la plus délicate, car le navigateur ne peut communiquer avec le serveur web intégré de l'imprimante qu'en HTTP/HTTPS — et un PDV sécurisé (HTTPS) impose également une connexion sécurisée à l'imprimante.

Vérifiez d'abord que l'imprimante est joignable : ouvrez `http://<printer-ip>/` dans un nouvel onglet du navigateur (si la page ne se charge pas, essayez `https://<printer-ip>/`). Si la page de configuration de l'imprimante s'affiche, celle-ci est sur le réseau ; si aucune des deux pages ne se charge, résolvez d'abord le problème de réseau ou d'adresse IP.

Ajoutez ensuite l'imprimante dans **PDV &gt; Paramètres &gt; Impression** avec son adresse IP. Si votre PDV fonctionne en **HTTPS**, la connexion à l'imprimante est obligatoirement en HTTPS (port 8043 pour Epson, 443 pour Star) — ce qui ne fonctionne que si l'imprimante dispose d'un **certificat SSL** reconnu comme fiable.

  <WizardFix id="web-net-fix" title="L'impression réseau depuis le web ne fonctionne pas">

C'est le blocage le plus courant, et il ne peut généralement pas être résolu depuis le navigateur. Voici pourquoi et comment procéder :

Imprimez l'**auto-test** de l'imprimante et consultez la section SSL/TLS. S'il indique que le certificat **n'existe pas**, l'impression HTTPS ne peut pas fonctionner tant que vous n'en avez pas généré un — et le navigateur ne fera pas confiance à un certificat autosigné sans que vous consultiez `https://<printer-ip>` une fois et acceptiez le certificat sur chaque appareil.

Un message « envoyé avec succès » sans impression signifie que le navigateur a bloqué la requête sans avertissement (l'imprimante utilise HTTP mais votre PDV utilise HTTPS — c'est un blocage de « contenu mixte »), ou que le port HTTPS (8043 pour Epson, 443 pour Star) a été imposé sans certificat.

L'application web ne peut joindre une imprimante que via son **serveur web intégré** — **ePOS-Print** d'Epson ou **WebPRNT** de Star — assurez-vous donc que ce service est **activé** dans la configuration de l'imprimante. Seuls les modèles Epson « intelligents » / **-NT** et les modèles Star **WebPRNT** en possèdent un ; si le vôtre n'en a pas, un navigateur ne peut pas le joindre.

**La solution fiable est l'application de bureau**, qui se connecte directement à l'imprimante sur le réseau (port 9100), sans les restrictions HTTPS du navigateur. Téléchargez-la depuis [Configuration de l'imprimante](/1.x/hardware/printers) et ajoutez-y la même imprimante.

  <WizardStep id="bt-setup" title="Connecter via Bluetooth">

L'impression de reçus par Bluetooth utilise le logiciel propre au fabricant de l'imprimante ; celle-ci doit donc être un modèle **Epson** ou **Star** — les imprimantes Bluetooth génériques ne sont prises en charge via Bluetooth sur aucune plateforme.

Commencez par **appairer l'imprimante dans les paramètres Bluetooth du système de votre ordinateur ou appareil** — pas dans WCPOS. Les imprimantes Bluetooth ne mémorisent qu'un seul appareil à la fois ; si elle était appairée à une autre caisse, utilisez d'abord l'option « oublier » sur cette dernière. Sur **iPhone/iPad**, accordez également à WCPOS les autorisations **Bluetooth** et **Réseau local** lorsqu'elles sont demandées. Sur **Android**, réglez l'utilisation de la batterie de WCPOS sur **sans restriction** pour que le système ne coupe pas la connexion. Sur un **ordinateur Windows ou Mac**, appairez-la d'abord dans les paramètres Bluetooth du système d'exploitation, puis lancez la recherche dans WCPOS.

Ensuite, dans **PDV &gt; Paramètres &gt; Impression**, appuyez sur **Rechercher des imprimantes** et choisissez la vôtre — son nom et sa marque sont renseignés automatiquement.

  <WizardFix id="bt-fix" title="L'appairage Bluetooth échoue ou la connexion se coupe sans arrêt">

Appairez l'imprimante **d'abord dans les paramètres Bluetooth du système** de l'appareil, puis relancez la recherche dans WCPOS. Si elle était déjà appairée et refuse de se reconnecter, utilisez l'option « oublier » sur l'autre appareil (et réinitialisez le Bluetooth de l'imprimante) pour supprimer cette association. Assurez-vous qu'elle est allumée et à portée. Sur iPhone/iPad, vérifiez que WCPOS dispose des autorisations Bluetooth et Réseau local ; sur Android, réglez l'application sur une utilisation de la batterie sans restriction. N'oubliez pas que le Bluetooth prend en charge **uniquement Epson et Star** — une imprimante Bluetooth générique ne se connectera pas.

Branchez l'imprimante en USB. Sur **Android**, acceptez la demande d'autorisation USB lorsqu'elle apparaît, puis choisissez l'imprimante dans **PDV &gt; Paramètres &gt; Impression**. Sur un **Mac**, l'USB fonctionne généralement sans configuration supplémentaire. Sur **Windows**, une imprimante générique peut nécessiter l'installation de son pilote **avant** son branchement.

  <WizardFix id="usb-fix" title="La connexion USB échoue">

Sur **Android**, rebranchez le câble et acceptez la demande d'autorisation USB. Dans l'**application de bureau (Windows)**, une erreur `LIBUSB_ERROR_NOT_SUPPORTED` signifie que Windows réserve l'appareil à son propre pilote d'impression — la solution la plus simple est de **connecter plutôt l'imprimante au réseau (port 9100)**, ce qui évite complètement les pilotes USB. (Les utilisateurs avancés peuvent remplacer le pilote avec un outil WinUSB, mais cela désactive la file d'attente d'impression Windows habituelle pour cet appareil — ne le faites que si vous maîtrisez cette opération.)

  <WizardStep id="web-btusb" title="Bluetooth &amp; USB depuis un navigateur web">

La connexion d'une imprimante à l'**application web** via Bluetooth ou USB ne fonctionne que dans **Google Chrome ou Microsoft Edge** (Safari et Firefox ne le permettent pas). Cliquez sur **Connecter** dans **PDV &gt; Paramètres &gt; Impression** et choisissez l'imprimante dans le sélecteur d'appareils du navigateur.

L'**USB** fonctionne avec les imprimantes Epson, Star et la plupart des imprimantes ESC/POS génériques — si votre imprimante apparaît dans le sélecteur du navigateur, elle devrait imprimer. Sur **Windows**, le pilote de l'imprimante peut empêcher le navigateur de communiquer avec elle ; si la connexion échoue, utilisez l'application de bureau.

Le **Bluetooth** dépend du type de Bluetooth de l'imprimante, pas de sa marque : le navigateur ne peut joindre que les imprimantes **Bluetooth Low Energy (BLE)**. De nombreuses petites imprimantes portables utilisent le BLE et fonctionnent correctement, mais les imprimantes Bluetooth classique — dont la plupart des modèles Bluetooth Epson et Star — n'apparaissent jamais dans le sélecteur du navigateur. Si la vôtre n'y figure pas, c'est la raison : utilisez plutôt l'application de bureau ou mobile.

Si la connexion échoue dans les deux cas, l'**application de bureau** est l'option la plus fiable pour le Bluetooth et l'USB. Téléchargez-la depuis [Configuration de l'imprimante](/1.x/hardware/printers).

  <WizardFix id="garbled-raster" title="Écriture non latine — imprimer sous forme d'image">
Les imprimantes thermiques disposent d'une police intégrée limitée ; les écritures qu'elle ne couvre pas (arabe, hébreu, de nombreux caractères CJK et thaïs) s'impriment donc sous forme de cases. L'impression est un peu plus lente ; utilisez donc cette option uniquement si nécessaire.
