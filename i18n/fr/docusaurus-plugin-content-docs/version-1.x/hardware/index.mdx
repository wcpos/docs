Cette page est le point de départ pour connecter votre matériel — imprimantes de reçus, lecteurs de codes-barres, lecteurs de cartes et tiroirs-caisses. Chaque type de périphérique dispose ici de sa propre page de configuration, ou renvoie vers la page où sa configuration est décrite.

Le compte et la procédure d’appairage d’un lecteur de cartes se trouvent sur sa page Passerelle de paiement ; le câblage d’un tiroir-caisse et son réglage d’ouverture se trouvent sur la page Tiroir-caisse.
:::

## Compatibilité des lecteurs de cartes {#card-reader-compatibility}

Les lecteurs de cartes compatibles dépendent de **la façon dont vous utilisez WCPOS** et du type de connexion du lecteur :

- **L’application web** ne peut piloter que les lecteurs disposant d’un **SDK web (navigateur)** — généralement des terminaux de comptoir connectés à Internet. Les lecteurs **Bluetooth uniquement** (par ex. Stripe M2 / WisePad 3, SumUp Air) et le **Tap-to-Pay** par téléphone ne sont **pas pris en charge** dans l’application web.
- La prise en charge se fait **par passerelle**, elle n’est pas universelle — vérifiez la compatibilité du lecteur avec la passerelle que vous comptez utiliser ([Stripe Terminal](/1.x/payment/gateways/stripe-terminal), [SumUp](/1.x/payment/gateways/sumup-terminal), [PayPal Reader](/1.x/payment/gateways/paypal-reader)) avant d’acheter.

Chaque page de passerelle indique précisément les lecteurs qu’elle prend en charge.
