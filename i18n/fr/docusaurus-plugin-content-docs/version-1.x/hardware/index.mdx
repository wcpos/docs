WCPOS fonctionne avec les appareils physiques déjà utilisés au comptoir. Cette page est le point de départ pour connecter le matériel : imprimantes de reçus, lecteurs de codes-barres, lecteurs de cartes et tiroirs-caisses. Chaque type d’appareil dispose de sa propre page de configuration ici, ou renvoie vers la page où sa configuration est réellement expliquée.

## Compatibilité des lecteurs de cartes {#card-reader-compatibility}

Les lecteurs de cartes compatibles dépendent de **la manière dont WCPOS est utilisé** et du type de connexion du lecteur :

- **L’application web** peut uniquement utiliser des lecteurs proposant un **SDK web (navigateur)** — généralement des terminaux de comptoir connectés à Internet. Les lecteurs **Bluetooth uniquement** (par exemple Stripe M2 / WisePad 3, SumUp Air) et le **paiement sans contact** sur téléphone ne sont **pas pris en charge** dans l’application web.
- La prise en charge est **propre à chaque passerelle**, et non universelle — vérifiez la compatibilité du lecteur avec la passerelle que vous prévoyez d’utiliser ([Stripe Terminal](/payment/gateways/stripe-terminal), [SumUp](/payment/gateways/sumup-terminal), [PayPal Reader](/payment/gateways/paypal-reader)) avant l’achat.

Chaque page de passerelle répertorie les lecteurs exacts qu’elle prend en charge.
