# DB01001 : Échec de la connexion {#db01001-connection-failed}

## Ce que cela signifie {#what-this-means}

Le POS n'a pas pu se connecter à sa base de données locale. WCPOS utilise une base de données locale pour stocker les produits, les clients et d'autres données pour un accès rapide et une fonctionnalité hors ligne.

## Causes courantes {#common-causes}

- **Stockage plein** — L'appareil n'a plus d'espace de stockage disponible
- **Base de données corrompue** — Les fichiers de la base de données locale sont endommagés
- **Problème de permission** — L'application n'a pas les autorisations de stockage
- **Stockage du navigateur désactivé** — IndexedDB est désactivé (version web)

## Comment réparer {#how-to-fix}

### 1. Vérifiez l'espace de stockage {#1-check-storage-space}

Assurez-vous que votre appareil dispose d'un espace de stockage disponible :
- Libérez de l'espace si le stockage est plein
- Supprimez les applications ou fichiers inutilisés
- Vérifiez l'espace disque disponible

### 2. Effacez les données de l'application {#2-clear-app-data}

:::warning Vérifiez d’abord les travaux non enregistrés
Effacer les données locales ou réinstaller l’application supprime tout ce qui se trouve sur cet appareil sans être arrivé dans votre boutique, notamment les ventes effectuées hors ligne, les paniers ouverts et les modifications non enregistrées. Avant tout effacement, ouvrez **État de la boutique → Base de données** et vérifiez qu’aucun élément n’est indiqué comme retenu ou comme n’ayant jamais atteint votre serveur, puis consultez **État de la boutique → Journaux** pour vérifier qu’il y a **0 enregistrement bloqué** et **0 modification en attente d’envoi** ; terminez ou notez ensuite chaque panier ouvert. Si votre WCPOS ne comporte pas de page État de la boutique, mettez d’abord WCPOS à jour, puis vérifiez. Si un élément est répertorié ou en attente, ou si vous ne pouvez pas vérifier, n’effacez rien : demandez au propriétaire de la boutique ou contactez le support.
:::

Uniquement si les étapes 1, 3 et 4 n’ont pas résolu le problème, et seulement après la vérification ci-dessus, réinitialisez la base de données locale :
- **Application de bureau :** Cherchez "Effacer les données" dans les paramètres
- **Navigateur web :** Effacez les données du site pour le domaine POS
- **Remarque :** les données déjà présentes dans votre boutique seront téléchargées à nouveau ; celles qui ne l’ont jamais atteinte sont perdues

### 3. Vérifiez les paramètres du navigateur (Web) {#3-check-browser-settings-web}

Si vous utilisez la version web :
1. Assurez-vous qu'IndexedDB est activé
2. N'utilisez pas le mode privé/incognito (stockage limité)
3. Autorisez le site à stocker des données

### 4. Vérifiez les autorisations {#4-check-permissions}

Sur ordinateur de bureau :
- Assurez-vous que l'application a la permission d'écrire dans son répertoire de données
- Vérifiez si l'antivirus bloque l'accès à la base de données

### 5. Réinstallez l'application {#5-reinstall-the-app}

:::warning Vérifiez d’abord les travaux non enregistrés
Effacer les données locales ou réinstaller l’application supprime tout ce qui se trouve sur cet appareil sans être arrivé dans votre boutique, notamment les ventes effectuées hors ligne, les paniers ouverts et les modifications non enregistrées. Avant tout effacement, ouvrez **État de la boutique → Base de données** et vérifiez qu’aucun élément n’est indiqué comme retenu ou comme n’ayant jamais atteint votre serveur, puis consultez **État de la boutique → Journaux** pour vérifier qu’il y a **0 enregistrement bloqué** et **0 modification en attente d’envoi** ; terminez ou notez ensuite chaque panier ouvert. Si votre WCPOS ne comporte pas de page État de la boutique, mettez d’abord WCPOS à jour, puis vérifiez. Si un élément est répertorié ou en attente, ou si vous ne pouvez pas vérifier, n’effacez rien : demandez au propriétaire de la boutique ou contactez le support.
:::

Uniquement si les autres solutions échouent, et seulement après la vérification ci-dessus :
1. Désinstallez l'application POS
2. Redémarrez votre appareil
3. Réinstallez l'application
4. Connectez-vous et synchronisez les données

## Récupération des données {#data-recovery}

Si vous avez des données non sauvegardées :
- L'application peut avoir des modifications en attente qui n'ont pas pu être synchronisées
- Contactez le support si vous avez besoin d'aide pour récupérer les données
- Les données déjà présentes dans votre boutique sont téléchargées à nouveau après l’effacement, mais les ventes qui ne l’ont jamais atteinte n’existent que sur cet appareil. Leur effacement ou la réinstallation les supprime : contactez le support avant de faire l’un ou l’autre.
