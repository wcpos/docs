## Ce que cela signifie {#what-this-means}

Une base de données locale n’a pas pu être créée ou supprimée sur cet appareil.

Redémarrez WCPOS et réessayez. Si l’échec persiste, l’appareil manque peut-être d’espace de stockage ou le profil du navigateur limite peut-être le stockage ; libérez de l’espace, puis contactez l’assistance si le problème persiste.

## Vos données {#your-data}

La base de données locale de l’appareil n’a pas pu être configurée ou vidée. Il s’agit d’un problème de stockage ou de configuration, et non d’une modification non synchronisée — libérez de l’espace de stockage et réessayez ; si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Redémarrez WCPOS et relancez la même action — la plupart des échecs de configuration sont temporaires.
2. Vérifiez l’espace de stockage disponible sur l’appareil ; la création d’une base de données locale échoue purement et simplement lorsque le disque ou le quota de stockage du navigateur est plein.
3. Sur le web, vérifiez que le navigateur autorise le stockage persistant pour le site — les fenêtres de navigation privée et les réglages bloquant toutes les données ne le permettent pas.
4. Si l’échec persiste, exportez les infos de débogage et contactez l’assistance.
