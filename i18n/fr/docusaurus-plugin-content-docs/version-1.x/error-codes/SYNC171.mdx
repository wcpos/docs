## Ce que cela signifie {#what-this-means}

WCPOS n'a pas pu configurer ou supprimer le stockage sur cet appareil.

Libérez de l'espace de stockage sur l'appareil, puis redémarrez WCPOS. Sur le Web, le navigateur peut également restreindre le stockage du site ; c'est le cas des fenêtres privées. Contactez le support si le problème persiste.

## Vos données {#your-data}

Il s'agit d'un problème de stockage, et non d'une modification refusée. Si cela s'est produit pendant l'effacement des données de cet appareil, une partie de ces données a peut-être déjà disparu, y compris des modifications qui n'avaient pas été envoyées : vérifiez que vos ventes et modifications récentes apparaissent dans votre boutique. Si le problème persiste, utilisez **Copier les infos de débogage** dans l'onglet **Journaux** et contactez l'assistance WCPOS.

## Dépannage {#troubleshoot}

1. Vérifiez l'espace de stockage disponible sur l'appareil et libérez-en en supprimant d'autres fichiers ou applications : la configuration du stockage échoue lorsque le disque ou le quota de stockage du navigateur est plein. N'utilisez pas l'option « Effacer les données de navigation » du navigateur pour libérer de l'espace : elle supprime aussi les ventes WCPOS non envoyées.
2. Redémarrez WCPOS et réessayez la même action.
3. Sur le web, vérifiez que le navigateur autorise le stockage persistant pour le site — les fenêtres de navigation privée et les réglages bloquant toutes les données ne le permettent pas.
4. Si le problème persiste, utilisez **Copier les infos de débogage** dans l'onglet **Journaux** et contactez l'assistance.
