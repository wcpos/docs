## Ce que cela signifie {#what-this-means}

La connexion ou le maintien de la session a rencontré un problème inattendu.

Réessayez l’action une fois. Si l’erreur se reproduit, déconnectez-vous puis reconnectez-vous, utilisez **Copier les infos de débogage** et contactez l’assistance.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, utilisez **Copier les infos de débogage** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Réessayez l’action une fois de plus ; si elle échoue à nouveau, déconnectez-vous puis reconnectez-vous.
2. Dépliez l’entrée de journal et notez le code d’événement ainsi que tout serverCode — un code 999 signifie que la cause n’a pas encore de code dédié, et c’est ce contexte qui permet de l’identifier.
3. Si cela se reproduit, utilisez Copier les infos de débogage et contactez l’assistance.
