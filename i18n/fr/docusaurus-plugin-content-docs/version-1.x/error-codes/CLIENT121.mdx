## Ce que cela signifie {#what-this-means}

Ce navigateur ne permet qu’à un seul onglet d’envoyer des modifications à la fois.

Vous pouvez continuer à utiliser tous les onglets — ils partagent les mêmes données locales. Un onglet assure discrètement la synchronisation pour l’ensemble.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée.

## Dépannage {#troubleshoot}

1. Continuez à utiliser tous les onglets normalement — ils partagent les mêmes données locales, et un onglet assure discrètement la synchronisation pour les autres.
2. Ce navigateur (ou une fenêtre de navigation privée) ne dispose pas de la fonction de coordination entre onglets que le POS privilégie ; il se rabat donc sur un seul onglet synchronisant. Aucune correction n’est nécessaire.
