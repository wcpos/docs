## Ce que cela signifie {#what-this-means}

Une recherche par scan ou par saisie n’a trouvé aucun produit correspondant.

Les causes habituelles sont un filtre actif, un code-barres absent ou enregistré dans un autre champ, ou une première synchronisation qui n’est pas terminée.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée.

## Dépannage {#troubleshoot}

**À la caisse :**

1. Effacez d’abord les filtres : un filtre de catégorie ou de stock limite toutes les recherches sans le signaler (un code scanné est saisi dans le même champ de recherche).
2. Recherchez le produit par son nom. S’il apparaît, mais que le scan n’a rien trouvé, le code-barres enregistré dans la boutique ne correspond pas à la valeur scannée. Si vous avez saisi la recherche, vérifiez l’orthographe et les espaces superflus.
3. Si le produit vient d’être créé, l’index local est peut-être encore en cours de synchronisation : attendez la fin de la première synchronisation, puis réessayez.

**Sur la boutique :**

- Si le code-barres est absent, ajoutez la valeur scannée au champ de code-barres du produit dans WP Admin.
- Si aucun scan ne trouve de produit, le PDV lit peut-être le mauvais champ : vérifiez, dans les réglages des codes-barres du PDV, quel champ contient les codes-barres de votre boutique.
