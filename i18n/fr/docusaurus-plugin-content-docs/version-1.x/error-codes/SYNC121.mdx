## Ce que cela signifie {#what-this-means}

Votre boutique est momentanément inaccessible.

Vous n'avez rien à faire : continuez à vendre. Les modifications sont envoyées automatiquement lorsque la connexion est rétablie. Si le problème persiste, vérifiez la connexion de cet appareil et que le site Web de votre boutique se charge.

## Vos données {#your-data}

N'effacez pas les données de cet appareil : elles peuvent contenir des modifications qui ne sont pas encore arrivées dans votre boutique. Elles seront envoyées automatiquement dès que votre boutique répondra.

## Dépannage {#troubleshoot}

1. Continuez à vendre : les ventes sont enregistrées sur cet appareil et envoyées automatiquement dès que la boutique répond.
2. Vérifiez si la caisse elle-même est en ligne : un autre site web se charge-t-il depuis cet appareil ?
3. Ouvrez le site web de votre boutique dans un onglet du navigateur sur le même appareil ; s’il ne se charge pas non plus, c’est le site ou son hébergement qui est hors service, pas le POS.
4. **Pour la personne qui gère le réseau de cet appareil :** si le site se charge, mais que le PDV reste hors ligne, un élément entre les deux bloque les requêtes API — VPN, pare-feu, bloqueur de publicités ou extension de sécurité. Les outils de développement du navigateur (onglet Réseau) — ou **Avancé → Afficher/Masquer les outils de développement** dans l’application de bureau — indiquent quelle requête échoue.
