## Signification {#what-this-means}

La recherche a affiché des résultats qui ne correspondent pas à vos produits ; WCPOS les a donc masqués.

Aucune action n’est nécessaire, sauf si les résultats de recherche semblent toujours incorrects : dans ce cas, rechargez WCPOS.

Pour répondre instantanément aux recherches, WCPOS conserve un index de recherche local pour les listes consultées : produits, clients, commandes et autres éléments similaires. Une vérification a trouvé dans cet index des entrées qui ne correspondent pas à la recherche saisie. Les résultats incohérents ont été masqués immédiatement. L’application peut également reconstruire l’index automatiquement, mais une seule fois par liste et par session ; cette reconstruction n’est donc pas garantie.

## Vos données {#your-data}

Aucune donnée de la boutique n’a été modifiée. Cela concerne uniquement l’index de recherche local, dérivé des données déjà présentes sur cet appareil : masquer un résultat non concordant modifie uniquement ce que la recherche affiche, jamais l’enregistrement sous-jacent.

## Résolution des problèmes {#troubleshoot}

1. Aucune action n’est nécessaire, sauf si les résultats de recherche semblent toujours incorrects : les ventes peuvent continuer normalement. Pour vérifier, relancez la recherche indiquée dans l’entrée du journal (son contexte enregistre le terme recherché) et confirmez que les résultats correspondent maintenant à la recherche et qu’aucun résultat attendu ne manque.
2. Si la recherche affiche toujours des résultats incorrects ou ne trouve pas un produit, un client ou une commande dont vous savez qu’il existe, rechargez l’application : sur le Web, rechargez l’onglet du navigateur ; sur ordinateur ou appareil mobile, fermez et rouvrez l’application. L’index pourra ainsi être reconstruit lors de la prochaine détection du problème.
3. Si le code réapparaît après le rechargement, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez le support : le contexte de l’entrée indique la liste concernée et la recherche qui l’a déclenchée.
