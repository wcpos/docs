## Signification {#what-this-means}

La recherche a affiché des résultats qui ne correspondent pas à vos produits ; WCPOS les a donc masqués.

Aucune action n'est nécessaire, sauf si les résultats de recherche semblent toujours incorrects ; dans ce cas, rechargez WCPOS.

Pour répondre instantanément aux recherches, WCPOS conserve un index de recherche local pour les listes consultées : produits, clients, commandes et autres éléments similaires. Une vérification automatique a trouvé dans cet index des entrées qui ne correspondent pas réellement au texte saisi. Les résultats incorrects ont été immédiatement masqués. L'application peut également reconstruire l'index automatiquement, mais une seule fois par liste et par session ; cette reconstruction n'est donc pas garantie.

## Vos données {#your-data}

Aucune donnée de la boutique n’a été modifiée. Cela concerne uniquement l’index de recherche local, dérivé des données déjà présentes sur cet appareil : masquer un résultat non concordant modifie uniquement ce que la recherche affiche, jamais l’enregistrement sous-jacent.

## Résolution des problèmes {#troubleshoot}

1. Aucune action n'est nécessaire si les résultats de recherche semblent corrects ; les ventes peuvent se poursuivre normalement. Pour vérifier, relancez la recherche indiquée dans l'entrée du journal (son contexte indique le terme recherché) et confirmez que les résultats correspondent maintenant au texte saisi, sans aucun élément manquant.
2. Si les résultats de recherche sont toujours incorrects ou si un produit, un client ou une commande dont vous connaissez l'existence est absent, rechargez l'application : sur le Web, rechargez l'onglet du navigateur ; sur ordinateur et sur mobile, fermez puis rouvrez l'application. Elle pourra ainsi tenter de reconstruire l'index la prochaine fois que le problème sera détecté.
3. Si le code réapparaît après avoir rechargé l'application, utilisez **Copy debug info** dans l'onglet **Logs** et contactez l'assistance : le contexte de l'entrée indique la liste concernée et la recherche à l'origine du problème.
