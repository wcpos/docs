## Ce que cela signifie {#what-this-means}

WCPOS ne parvient pas à joindre son point de connexion sur votre boutique.

Demandez à l’administrateur du site de vérifier que l’extension WCPOS est active (**WP Admin → Extensions**) et qu’aucune extension de sécurité ne bloque l’API REST.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Prévenez l’administrateur du site.

## Dépannage {#troubleshoot}

**À la caisse** — pour le caissier : prévenez l’administrateur du site. Cet appareil n’est pas affecté.

**Sur la boutique** — pour l’administrateur du site :

1. Vérifiez que WCPOS est actif : WP Admin → Extensions.
2. Si aucune des deux formes REST ne fonctionne, vérifiez si une extension de sécurité, un proxy ou un CDN supprime les en-têtes des requêtes WCPOS ou bloque les requêtes REST. Les règles de pare-feu et les options de durcissement qui désactivent l’API REST sont les causes les plus courantes.
3. Chez certains hébergeurs, réenregistrer les permaliens (Réglages → Permaliens → Enregistrer) rétablit les routes REST manquantes.
