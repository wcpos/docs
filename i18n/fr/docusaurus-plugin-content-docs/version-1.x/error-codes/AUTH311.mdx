## Ce que cela signifie {#what-this-means}

La route de la boutique WCPOS est indisponible.

Demandez à l’administrateur du site de vérifier si une extension de sécurité ou de proxy supprime les en-têtes de requête de WCPOS.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, adressez-vous à la personne qui gère votre site WordPress.

## Dépannage {#troubleshoot}

**À la caisse** — pour le caissier : testez les deux formes REST prises en charge dans un navigateur : l’adresse `/wp-json/` de votre boutique et `/index.php?rest_route=/`. Ne concluez à un blocage REST que si aucune des deux ne renvoie de JSON ; signalez alors le problème à votre administrateur.

**Sur la boutique** — pour l’administrateur du site :

1. Vérifiez que WCPOS est actif : WP Admin → Extensions.
2. Si aucune des deux formes REST ne fonctionne, vérifiez si une extension de sécurité, un proxy ou un CDN supprime les en-têtes des requêtes WCPOS ou bloque les requêtes REST. Les règles de pare-feu et les options de durcissement qui désactivent l’API REST sont les causes les plus courantes.
3. Chez certains hébergeurs, réenregistrer les permaliens (Réglages → Permaliens → Enregistrer) rétablit les routes REST manquantes.
