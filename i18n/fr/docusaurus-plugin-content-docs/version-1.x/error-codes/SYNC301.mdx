## Ce que cela signifie {#what-this-means}

La liste des modifications de votre boutique a changé de façon inattendue. WCPOS la vérifie de nouveau automatiquement. Rien n’est perdu.

Vous n’avez rien à faire : continuez à vendre. WCPOS vérifie de nouveau automatiquement les modifications de votre boutique. Si les prix ou les stocks semblent toujours obsolètes, touchez **Tout vérifier maintenant** dans **Santé de la boutique → Base de données**.

## Vos données {#your-data}

Rien n’est perdu et rien sur cet appareil n’est en danger. Tant que la nouvelle vérification n’est pas terminée, certains prix ou stocks sur cet appareil peuvent être obsolètes.

## Dépannage {#troubleshoot}

1. Continuez à vendre : rien n’est perdu sur cet appareil et la nouvelle vérification s’exécute automatiquement. L’entrée du journal peut préciser ce qui a changé — par exemple, que certaines modifications de la boutique ont été ignorées ou que sa liste a reculé. Dans tous les cas, cela peut concerner n’importe quel type de données.
2. Si les prix ou les stocks semblent toujours obsolètes, ouvrez **Santé de la boutique → Base de données**, puis touchez **Tout vérifier maintenant**.
3. Si un enregistrement semble toujours incorrect après cette vérification, ou si ce code réapparaît, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance. N’effacez pas les données pour résoudre le problème.
