# SY01002: Disque Plein {#sy01002-disk-full}

## Ce Que Cela Signifie {#what-this-means}

Le stockage de votre appareil est plein. Le POS ne peut pas enregistrer de données ni continuer à opérer sans espace disque disponible.

## Causes Courantes {#common-causes}

- **Stockage plein** — Aucun espace libre sur le lecteur
- **Grande base de données locale** — Données du POS utilisant un espace significatif
- **Fichiers temporaires** — Fichiers temporaires consommant de l'espace
- **Autres applications** — D'autres applications remplissant le disque

## Comment Corriger {#how-to-fix}

### 1. Libérer de l'Espace Disque {#1-free-up-disk-space}

Supprimez les fichiers inutiles :
- Videz la corbeille/poubelle
- Supprimez les anciens téléchargements
- Supprimez les applications inutilisées
- Effacez les fichiers temporaires

### 2. Vérifier l'Espace Disponible {#2-check-available-space}

**Windows :**
- Ouvrez l'Explorateur de fichiers
- Faites un clic droit sur le lecteur → Propriétés
- Consultez l'espace utilisé et libre

**macOS :**
- Menu Apple → À propos de ce Mac
- Cliquez sur Stockage

### 3. Effacer les Données du Navigateur (Version Web) {#3-clear-browser-data-web-version}

:::warning Vérifiez d’abord qu’aucun travail n’est en attente d’enregistrement
La suppression des données locales ou la réinstallation de l’application efface tout ce qui se trouve sur cet appareil sans avoir été transmis à votre boutique — notamment les ventes effectuées hors ligne, les paniers ouverts et les modifications non enregistrées. Avant toute suppression, ouvrez **Store health → Database** et vérifiez qu’aucun élément n’est indiqué comme retenu ou comme n’ayant jamais atteint votre serveur, puis vérifiez dans **Store health → Logs** qu’il y a **0 enregistrement bloqué** et **0 modification en attente d’envoi** ; terminez ou notez ensuite chaque panier ouvert. Si votre WCPOS ne comporte pas de page Store health, mettez d’abord WCPOS à jour, puis vérifiez. Si un élément est répertorié ou en attente, ou si vous ne pouvez pas vérifier, ne supprimez rien — demandez conseil au propriétaire de votre boutique ou contactez l’assistance.
:::

Les navigateurs stockent localement les données du PDV. Uniquement après avoir effectué la vérification ci-dessus :
- Effacez le cache et les cookies
- Supprimez les anciennes données de site
- Vérifiez l'utilisation du stockage du navigateur

### 4. Déplacer ou Supprimer de Gros Fichiers {#4-move-or-delete-large-files}

Trouvez et gérez les gros fichiers :
- Anciennes vidéos ou photos
- Gros téléchargements
- Logiciels inutilisés
- Fichiers de sauvegarde pouvant être déplacés vers un stockage externe

### 5. Vérifier les Données du POS {#5-check-pos-data}

Si les données du POS sont très volumineuses :
- La base de données locale peut nécessiter un nettoyage
- Envisagez de vider le cache et de synchroniser à nouveau — uniquement après la vérification de l’étape 3
- Vérifiez si les anciennes données peuvent être purgées

## Espace Libre Recommandé {#recommended-free-space}

Gardez au moins :
- **10 Go** libres pour un fonctionnement normal
- **20 Go+** pour de grands catalogues
- Plus d'espace est toujours mieux

## Prévenir de Futurs Problèmes {#preventing-future-issues}

- Nettoyez régulièrement les fichiers inutiles
- Configurez un nettoyage automatique des fichiers temporaires
- Surveillez l'utilisation de l'espace disque
- Envisagez un stockage plus grand si souvent plein
