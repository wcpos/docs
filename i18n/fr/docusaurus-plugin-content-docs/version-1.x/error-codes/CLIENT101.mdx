## Ce que cela signifie {#what-this-means}

WCPOS n’a pas pu terminer son démarrage.

À la caisse, cela se manifeste par un écran vide ou bloqué, ou par un indicateur de chargement qui ne disparaît jamais. En général, la base de données locale de l’appareil n’a pas pu s’ouvrir. Un redémarrage résout parfois le problème ; sinon, il faut effacer la base locale puis rouvrir l’application. WCPOS retéléchargera toutes les données de votre boutique.

:::warning L’effacement supprime les données non synchronisées
L’effacement de la base de données locale **supprime définitivement toutes les données de cet appareil qui n’ont pas encore été synchronisées avec votre boutique** — par exemple les ventes réalisées hors ligne. Comme l’application ne peut pas s’ouvrir, ces données ne peuvent pas être synchronisées au préalable et ne peuvent pas être récupérées. Si vous savez que des ventes importantes ne sont pas encore synchronisées sur cet appareil, contactez l’assistance **avant** l’effacement.
:::

## Vos données {#your-data}

Les données de votre boutique sont en sécurité : elles seront téléchargées à nouveau à la prochaine ouverture de l’application. L’effacement ne supprime que la copie locale sur cet appareil, y compris les modifications qui n’ont pas encore atteint votre boutique (voir l’avertissement ci-dessus).

## Dépannage {#troubleshoot}

1. Redémarrez l’application une fois ; sur le Web, rechargez complètement l’onglet. Un échec temporaire au démarrage se résout souvent de lui-même.
2. Si l’application ne démarre toujours pas, la base de données locale ne peut probablement pas être ouverte. Effacez-la et rouvrez l’application en suivant [Effacer toutes les données locales](/support/troubleshooting/clear-local-data), qui explique la procédure avec le bouton dans l’application, l’application Web et l’application de bureau. WCPOS retéléchargera automatiquement les données de votre boutique. (Cette opération supprime les données non synchronisées sur cet appareil ; voir l’avertissement ci-dessus.)
3. Si le démarrage échoue encore après l’effacement, utilisez **Copier les infos de débogage** — ou l’erreur de la console du navigateur si l’application ne peut pas ouvrir ses propres journaux — et contactez l’assistance.
