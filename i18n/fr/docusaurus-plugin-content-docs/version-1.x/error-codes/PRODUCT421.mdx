## Ce que cela signifie {#what-this-means}

Les données de prix des variations de ce produit n’ont pas pu être lues ; les prix affichés peuvent donc être erronés ou absents.

Réenregistrez le produit dans WooCommerce pour reconstruire ses données de prix, ou contactez l’assistance si de nombreux produits présentent ce problème.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, adressez-vous à l’administrateur de votre boutique.

## Dépannage {#troubleshoot}

**À la caisse :** vérifiez le prix avant de vendre. S’il semble erroné ou manque, ne vendez pas l’article à ce prix tant qu’il n’a pas été corrigé dans la boutique.

**Sur la boutique (WP Admin) :**

1. Ouvrez le produit et enregistrez-le à nouveau : cela reconstruit les données de prix que le PDV n’a pas pu lire.
2. Vérifiez que chaque variation a un prix défini ; une variation sans prix produit des fourchettes de prix illisibles.
3. Si de nombreux produits affichent ce code en même temps, une extension de tarification écrit probablement les données de prix dans un format que le POS ne peut pas lire — notez quelle extension gère les prix et contactez l’assistance.
