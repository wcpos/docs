## Ce que cela signifie {#what-this-means}

La synchronisation a rencontré un problème inattendu.

Vérifiez que l’action indiquée dans cette entrée est terminée ; si ce n’est pas le cas, recommencez-la. Si cela se reproduit, touchez **Copier les informations de débogage** et envoyez-les à l’assistance.

## Vos données {#your-data}

N’effacez pas les données de cet appareil : elles peuvent contenir des modifications que votre boutique n’a pas encore reçues. Si l’action indiquée dans l’entrée n’est pas terminée, recommencez-la.

## Dépannage {#troubleshoot}

1. Développez l’entrée du journal et repérez l’action indiquée. Vérifiez qu’elle est terminée — pour un enregistrement, ouvrez la commande ou l’enregistrement et vérifiez que la modification apparaît. Si c’est le cas, WCPOS l’envoie automatiquement ; ne faites rien.
2. Si l’action n’est pas terminée, recommencez-la. Si l’entrée du journal indique que la modification n’a jamais été enregistrée sur cet appareil, rien n’a été conservé.
3. Notez le code et tout motif figurant dans l’entrée du journal : un code 999 signifie que la cause précise n’a pas encore de code dédié ; ce contexte est donc exactement ce dont l’assistance a besoin.
4. Si cela se reproduit, touchez **Copier les informations de débogage** dans l’onglet **Journaux** et envoyez-les à l’assistance : le signalement permettra d’ajouter un code spécifique.
