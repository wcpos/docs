## Ce que cela signifie {#what-this-means}

Le compte de boutique connecté ne correspond pas au caissier utilisant cette caisse.

Chaque caissier conserve ses propres données de caisse ; travailler sous un autre compte peut donc mal classer les commandes. Déconnectez-vous, puis reconnectez-vous avec le compte du caissier concerné.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée.

## Dépannage {#troubleshoot}

1. Le POS ferme la session de lui-même pour protéger les données de chaque caissier — aucune donnée de commande n’est mélangée entre les comptes.
2. Reconnectez-vous avec le compte du caissier concerné ; travailler sous un autre compte peut mal classer les commandes.
3. Si les caisses sont partagées entre plusieurs caissiers, intégrez le changement de compte à la procédure de passation.
