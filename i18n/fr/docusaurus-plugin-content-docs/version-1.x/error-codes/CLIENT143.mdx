## Signification {#what-this-means}

La recherche n'a pas trouvé un produit qu'elle aurait dû trouver.

Aucune action n'est nécessaire, sauf si un produit visible ne s'affiche toujours pas dans les résultats de recherche ; dans ce cas, rechargez WCPOS.

Lors d'une vérification périodique, l'index de recherche local a été interrogé sur un enregistrement à partir des mots mêmes de cet enregistrement, mais ne l'a pas renvoyé. Les recherches ont donc pu afficher moins de résultats que ce que cet appareil contient réellement. L'application peut reconstruire l'index automatiquement, mais une seule fois par liste et par session ; cette reconstruction n'est donc pas garantie.

## Vos données {#your-data}

Aucune donnée de la boutique n’a été modifiée. Cela concerne uniquement l’index de recherche local, qui est généré à partir des données déjà présentes sur cet appareil : aucune donnée n’est perdue lors de sa reconstruction.

## Résolution des problèmes {#troubleshoot}

1. Aucune action n'est nécessaire, sauf si un produit visible ne s'affiche toujours pas dans les résultats de recherche : les ventes peuvent se poursuivre normalement. L'application peut reconstruire l'index automatiquement, mais une seule fois par liste et par session ; si ce code se reproduit, passez à l'étape suivante.
2. Si la recherche omet toujours des enregistrements visibles dans l’application — un produit, un client, une commande ou une autre liste — rechargez l’application : sur le Web, rechargez l’onglet du navigateur ; sur ordinateur et mobile, fermez puis rouvrez l’application. Cela lui permettra de tenter une nouvelle reconstruction lors de la prochaine détection du problème.
3. Si le code réapparaît après un rechargement, utilisez **Copy debug info** dans l'onglet **Logs** et contactez l'assistance : l'entrée du journal contient les informations nécessaires pour identifier la liste concernée et l'enregistrement absent de l'index.
