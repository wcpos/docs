## Signification {#what-this-means}

L’index de recherche n’a pas pu trouver un produit qu’il devrait contenir ; l’application tente de reconstruire automatiquement l’index de recherche.

Une vérification périodique a demandé à l’index de recherche local un enregistrement à l’aide de ses propres termes, mais l’index ne l’a pas renvoyé. Cela signifie que les recherches ont peut-être affiché moins de résultats que ceux réellement présents sur cet appareil. L’application tente une reconstruction automatique de l’index par liste et par session afin de corriger le problème.

## Vos données {#your-data}

Aucune donnée de la boutique n’a été modifiée. Cela concerne uniquement l’index de recherche local, qui est généré à partir des données déjà présentes sur cet appareil : aucune donnée n’est perdue lors de sa reconstruction.

## Résolution des problèmes {#troubleshoot}

1. Aucune action n’est généralement nécessaire et les ventes peuvent se poursuivre normalement : l’application tente automatiquement une reconstruction, puis les recherches fonctionnent de nouveau lorsqu’elle est terminée. Une seule reconstruction est tentée par liste et par session ; si ce code se répète, passez à l’étape suivante.
2. Si la recherche omet toujours des enregistrements visibles dans l’application — un produit, un client, une commande ou une autre liste — rechargez l’application : sur le Web, rechargez l’onglet du navigateur ; sur ordinateur et mobile, fermez puis rouvrez l’application. Cela lui permettra de tenter une nouvelle reconstruction lors de la prochaine détection du problème.
3. Si le code réapparaît après un rechargement, exportez les informations de débogage et contactez l’assistance : l’entrée de journal contient les détails nécessaires pour identifier la liste concernée et l’enregistrement omis par l’index.
