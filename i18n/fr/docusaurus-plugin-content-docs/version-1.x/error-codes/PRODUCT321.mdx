## Ce que cela signifie {#what-this-means}

Plusieurs produits correspondent à ce code-barres.

WCPOS ne peut pas trancher entre eux sans risque ; rien n’a donc été ajouté. Recherchez le produit par son nom, et attribuez à chaque produit un code-barres unique dans la boutique pour résoudre le conflit.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, adressez-vous à l’administrateur de votre boutique.

## Dépannage {#troubleshoot}

**À la caisse :** recherchez le produit par son nom pour terminer cette vente : le scan n’a rien ajouté parce que le code-barres correspond à plusieurs produits.

L’entrée de journal consigne le code scanné et le nombre de produits correspondants ; rechercher la valeur du code-barres dans le POS permet de voir lesquels.

**Sur la boutique (WP Admin) :** attribuez à chacun de ces produits un code-barres unique, puis scannez à nouveau pour confirmer qu’il ne reste qu’une seule correspondance.
