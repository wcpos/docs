## Ce que cela signifie {#what-this-means}

Une tâche de synchronisation en arrière-plan s’est arrêtée de façon inattendue avant d’avoir terminé.

Vous n’avez rien à faire : le PDV redémarre automatiquement ces tâches et rien n’est perdu. Si ce code réapparaît, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance.

## Vos données {#your-data}

Rien n’est perdu : aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Rien à faire dans un premier temps : le POS redémarre automatiquement la tâche d’arrière-plan qui a planté et aucune donnée de commande n’est concernée.
2. Si le code se répète en quelques minutes, rechargez l’application une fois afin que le moteur de synchronisation reparte sur des bases saines.
3. Si le problème se reproduit, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance : un plantage récurrent d’une tâche est un défaut de l’application qu’il convient de signaler, et non un problème de la boutique.
