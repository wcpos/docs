## Ce que cela signifie {#what-this-means}

Le traitement du paiement a rencontré un problème inattendu.

Confirmez si le paiement a abouti avant de réessayer. Exportez les diagnostics et contactez l’assistance en cas de doute.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé — vérifiez avant de réessayer. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Confirmez si le paiement a abouti avant de réessayer : l’écran du terminal, le tableau de bord du prestataire et la commande dans WP Admin.
2. Dépliez l’entrée de journal pour relever le code d’événement et le contexte — ce code générique signifie que la cause n’a pas encore de code dédié.
3. Si l’issue reste incertaine ou si le code se reproduit, exportez les infos de débogage et contactez l’assistance.
