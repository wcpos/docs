# Codes d'erreur

Lorsque WCPOS rencontre un problème, il affiche un code d'erreur qui aide à identifier le problème. À partir de la **v1.10.0**, les codes suivent le format **domaine + trois chiffres** — par exemple `SYNC131` ou `AUTH311`. Le domaine désigne la zone du POS concernée ; le nombre identifie la condition précise. Chaque code dispose de sa propre page indiquant ce qu'il signifie, ce qu'il faut faire et ce qu'il implique pour vos données.

Dans le POS, les codes d'erreur apparaissent dans **État de la boutique → Journaux** : développez une ligne et utilisez le lien **Aide** pour accéder directement à la page du code ici.

## Domaines d'erreur (v1.10.0+) {#error-domains}

| Domaine | Zone | Exemples |
|--------|------|----------|
| `AUTH` | Connexion, sessions et jetons | [AUTH101](./AUTH101), [AUTH311](./AUTH311) |
| `CHECKOUT` | Finalisation des commandes en caisse | [CHECKOUT101](./CHECKOUT101), [CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | L'application POS elle-même et le stockage local | [CLIENT101](./CLIENT101), [CLIENT201](./CLIENT201) |
| `LICENSE` | Activation et validation de la licence Pro | [LICENSE101](./LICENSE101) |
| `PAYMENT` | Passerelles de paiement et terminaux | [PAYMENT101](./PAYMENT101), [PAYMENT301](./PAYMENT301) |
| `PRINT` | Impression des reçus | [PRINT101](./PRINT101), [PRINT301](./PRINT301) |
| `PRODUCT` | Données produits et opérations sur le catalogue | [PRODUCT101](./PRODUCT101), [PRODUCT401](./PRODUCT401) |
| `SYNC` | Synchronisation entre le POS et votre boutique | [SYNC101](./SYNC101), [SYNC121](./SYNC121), [SYNC311](./SYNC311) |

Utilisez la barre latérale pour parcourir tous les codes d'un domaine, ou recherchez le code directement.

Les codes se terminant par `999` sont le fourre-tout du domaine pour les conditions qui n'ont pas encore de code spécifique.

## Codes hérités (avant la v1.10.0) {#legacy-codes}

Les versions antérieures à la v1.10.0 utilisaient un schéma différent : `[DOMAIN][CATEGORY][SPECIFIC_CODE]`, par exemple `API04001` = API (domaine) + 04 (erreurs de réponse) + 001 (format de réponse invalide). Si vous utilisez une version plus ancienne, ou si vous consultez une ancienne entrée de journal ou un ancien fil de support, ces pages restent valables :

| Domaine | Total de codes | Couvre |
|--------|-------------|---------------|
| [API](./api) | 39 codes | Communication avec le serveur, authentification, problèmes de plugins |
| [DB](./db) | 9 codes | Stockage et récupération des données locales |
| [PY](./py) | 6 codes | Traitement des paiements |
| [SY](./sy) | 5 codes | Ressources de l'appareil et configuration |

Un client v1.10.0+ n'émet jamais ces codes — si vous en voyez un sur un POS à jour, il provient d'une ancienne entrée de journal conservée ou d'un message côté serveur.
