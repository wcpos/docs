## Ce que cela signifie {#what-this-means}

La boutique n’a pas accepté les identifiants de connexion.

Ressaisissez le nom d’utilisateur et le mot de passe, ou réinitialisez le mot de passe dans WordPress si l’échec persiste. Aucune donnée de commande n’est affectée.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée.

## Dépannage {#troubleshoot}

**À la caisse** — pour le caissier : saisissez à nouveau le nom d’utilisateur et le mot de passe ; la boutique a refusé ces identifiants.

**Sur la boutique** — pour l’administrateur du site :

1. Vérifiez que le compte fonctionne en vous connectant à WP Admin avec les mêmes identifiants ; si la connexion échoue, réinitialisez-y le mot de passe.
2. Si les identifiants fonctionnent dans WP Admin mais pas dans le PDV, une extension de protection des connexions ou de sécurité bloque peut-être la connexion automatisée : vérifiez ses réglages.
