## Ce que cela signifie {#what-this-means}

Cet appareil a manqué de mémoire et la dernière action n’est peut-être pas terminée.

Fermez les autres applications ou onglets, redémarrez WCPOS, puis vérifiez que votre dernière vente ou modification a bien été enregistrée. Sinon, recommencez-la.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé : vérifiez avant de réessayer. Si vous enregistriez une vente ou une modification lorsque la mémoire est venue à manquer, vérifiez qu’elle a bien été enregistrée avant de recommencer.

## Dépannage {#troubleshoot}

1. Fermez les autres applications ou onglets du navigateur : WCPOS partage la mémoire de l’appareil avec tous les programmes en cours d’exécution.
2. Redémarrez WCPOS.
3. Vérifiez que votre dernière vente ou modification a bien été enregistrée avant de la refaire : consultez **État de la boutique → Base de données** (une vente comptabilisée parmi les **modifications en attente d’envoi** est enregistrée et son envoi est en cours), le panier et les commandes (WCPOS Pro) ou **WooCommerce → Commandes**. Si une carte a été utilisée, vérifiez aussi le terminal ou le prestataire de paiement : si le client a été débité, ne le débitez pas à nouveau. Recommencez une seule fois uniquement si l’enregistrement a réellement échoué.
4. Si une action précise provoque systématiquement un manque de mémoire, notez de laquelle il s’agit, appuyez sur **Copier les informations de débogage** dans l’onglet **Journaux** et contactez le support.
5. Si cela se produit quotidiennement sur le même appareil, l’appareil est peut-être trop limité pour le catalogue — signalez-le afin que l’assistance puisse le confirmer.
