## Ce que cela signifie {#what-this-means}

WCPOS a manqué de mémoire et n’a pas pu terminer l’opération.

Redémarrez WCPOS et réessayez une fois ; exportez les diagnostics si l’appareil manque à nouveau de mémoire.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé : si vous étiez en train d’enregistrer quelque chose lorsque la mémoire a été épuisée, vérifiez que l’enregistrement a abouti avant de réessayer.

## Dépannage {#troubleshoot}

1. Redémarrez WCPOS. Si vous étiez en train d’enregistrer quelque chose lorsque la mémoire a été épuisée, vérifiez si l’enregistrement a abouti avant de réessayer ; s’il n’a pas abouti, réessayez une seule fois.
2. Fermez les autres applications ou onglets du navigateur — le POS partage la mémoire de l’appareil avec tout ce qui y tourne.
3. Si une action précise provoque systématiquement un manque de mémoire, notez laquelle et contactez l’assistance avec les infos de débogage.
4. Si cela se produit quotidiennement sur le même appareil, l’appareil est peut-être trop limité pour le catalogue — signalez-le afin que l’assistance puisse le confirmer.
