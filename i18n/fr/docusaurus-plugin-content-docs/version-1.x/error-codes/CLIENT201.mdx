## Ce que cela signifie {#what-this-means}

La mémoire de cet appareil est épuisée et la dernière action n'est peut-être pas terminée.

Fermez les autres applications ou onglets, redémarrez WCPOS, puis vérifiez que votre dernière vente ou modification a bien été enregistrée. Si ce n'est pas le cas, recommencez.

## Vos données {#your-data}

Le résultat n'a pas pu être confirmé : vérifiez avant de réessayer. Si vous étiez en train d'enregistrer une vente ou une modification lorsque la mémoire a été épuisée, vérifiez qu'elle a bien été enregistrée avant de recommencer.

## Dépannage {#troubleshoot}

1. Fermez les autres applications ou onglets du navigateur : WCPOS partage la mémoire de l'appareil avec tous les autres programmes en cours d'exécution.
2. Redémarrez WCPOS.
3. Vérifiez que votre dernière vente ou modification a été enregistrée avant de recommencer : consultez **Store health → Database** (une vente comptabilisée dans **changes waiting to send** est enregistrée et toujours en cours d'envoi), le panier et **Orders** (WCPOS Pro) ou **WooCommerce → Commandes**. Si une carte était utilisée, vérifiez également le terminal ou le prestataire de paiement : si le client a été débité, ne le facturez pas à nouveau. Recommencez une seule fois, uniquement si l'enregistrement a réellement échoué.
4. Si une action précise entraîne systématiquement une insuffisance de mémoire, notez laquelle, appuyez sur **Copy debug info** dans l'onglet **Logs** et contactez l'assistance.
5. Si cela se produit quotidiennement sur le même appareil, l’appareil est peut-être trop limité pour le catalogue — signalez-le afin que l’assistance puisse le confirmer.
