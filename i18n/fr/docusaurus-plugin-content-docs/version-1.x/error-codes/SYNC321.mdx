## Ce que cela signifie {#what-this-means}

Certains enregistrements ont été synchronisés, mais un ou plusieurs autres non.

Ce code apparaît sous deux formes — le titre de la ligne du journal indique laquelle vous concerne :

- **"Synchronisation partielle"** (titres des enregistrements) : certains enregistrements ont été synchronisés, mais pas ceux qui sont nommés. Examinez chaque enregistrement indiqué et son motif avant de réessayer uniquement ceux-ci.
- **"Abandon d’une requête de données bloquée"** : la voie des requêtes de données du moteur de synchronisation n’avançait plus sur une requête ; après un délai d’attente généreux, l’application l’a abandonnée plutôt que de bloquer toutes les requêtes en attente derrière elle. Aucune relance manuelle n’est nécessaire — le moteur de synchronisation réémet automatiquement la requête — et cela fait souvent suite à un appel bloqué à la base de données locale, consigné séparément sous [SYNC181](/error-codes/SYNC181).

## Vos données {#your-data}

Pour les enregistrements non synchronisés : la modification est enregistrée sur cet appareil, mais n’a pas atteint votre boutique. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS. Pour une requête de données abandonnée : rien n’a été modifié — une requête abandonnée est automatiquement émise à nouveau.

## Dépannage {#troubleshoot}

1. Pour une synchronisation partielle : développez l’entrée du journal pour voir les enregistrements qui n’ont pas été synchronisés et le motif indiqué pour chacun.
2. Traitez chaque enregistrement identifié selon la raison qui lui est propre — un champ invalide doit être corrigé, un conflit doit être comparé avec la boutique.
3. Ne réessayez que les enregistrements en échec ; les autres sont déjà synchronisés et ne nécessitent rien.
4. Pour une entrée "Abandon d’une requête de données bloquée", aucune action n’est nécessaire, sauf si l’écran reste bloqué — rechargez alors l’application et, si le problème persiste, exportez les informations de débogage et contactez l’assistance.
