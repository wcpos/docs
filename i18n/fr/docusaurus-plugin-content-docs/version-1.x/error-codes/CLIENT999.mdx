## Ce que cela signifie {#what-this-means}

WCPOS a rencontré une erreur inattendue.

Avant de réessayer, vérifiez si votre dernière action a abouti : pour une vente, ouvrez la commande et vérifiez son statut. Si le problème se reproduit, appuyez sur **Copy debug info** et envoyez ces informations à l'assistance WCPOS.

## Vos données {#your-data}

Le résultat n'a pas pu être confirmé : vérifiez avant de réessayer. Si le problème se reproduit, utilisez **Copy debug info** dans l'onglet **Logs** et contactez l'assistance WCPOS.

## Dépannage {#troubleshoot}

1. Avant de réessayer, vérifiez si votre dernière action a abouti : pour une vente, ouvrez la commande et vérifiez son statut ; pour un paiement, vérifiez également le terminal ou le prestataire. Si l'opération n'a pas abouti, réessayez une seule fois.
2. Dépliez l’entrée de journal et notez le code d’événement et le contexte — un code 999 signifie que l’échec n’a pas encore de code dédié, et ce sont ces informations qui permettent de l’identifier.
3. Si le problème se reproduit, appuyez sur **Copy debug info** dans l'onglet **Logs** et envoyez ces informations à l'assistance WCPOS : le signalement permettra d'ajouter ce code spécifique.
