## Ce que cela signifie {#what-this-means}

WCPOS a rencontré une erreur inattendue.

Réessayez l’action une fois de plus, puis exportez les diagnostics et contactez l’assistance si elle échoue à nouveau.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé — vérifiez avant de réessayer. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Réessayez l’action une fois de plus.
2. Dépliez l’entrée de journal et notez le code d’événement et le contexte — un code 999 signifie que l’échec n’a pas encore de code dédié, et ce sont ces informations qui permettent de l’identifier.
3. Si cela se répète, exportez les infos de débogage et contactez l’assistance — c’est en le signalant qu’un code spécifique finit par être créé.
