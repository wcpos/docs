## Ce que cela signifie {#what-this-means}

WCPOS a rencontré une erreur inattendue.

Réessayez l’action une fois, puis exportez les diagnostics et contactez l’assistance si le problème se reproduit.

## Que faire {#what-to-do}

Exportez les diagnostics et contactez l’assistance. WCPOS ne réessaie pas cette opération automatiquement — réessayez lorsque vous serez prêt.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé — vérifiez-le avant de réessayer. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Résolution des problèmes {#troubleshoot}

1. Réessayez l’action une fois.
2. Développez l’entrée de journal et notez le code d’événement ainsi que le contexte — un code 999 signifie que l’échec ne dispose pas encore d’un code dédié, et ces informations permettent de l’identifier.
3. Si le problème se reproduit, exportez les informations de débogage et contactez l’assistance — le signaler permet d’attribuer un code spécifique.

## Où chercher {#where-to-look}

Chaque occurrence de ce code est enregistrée sur l’appareil qui l’a générée. Ouvrez **État de santé de la boutique → Journaux** (l’icône de pouls cardiaque en bas du panneau de navigation), recherchez l’entrée marquée de ce code et développez-la : la ligne développée affiche la raison en langage clair et le contexte capturé au moment de l’échec — pour tout ce qui impliquait une requête vers votre boutique, cela inclut le propre code d’erreur du serveur (`serverCode`), le `status` HTTP et l’`endpoint`. Pour signaler un problème, utilisez **Copier les informations de débogage** en haut de l’écran Journaux (**Partager les informations de débogage** sur les téléphones et tablettes) plutôt que des captures d’écran : cette option regroupe la version de l’application, l’état de la connexion et les erreurs les plus récentes. Les journaux sont conservés pendant 30 jours au maximum ; recueillez-les donc tant que le problème est récent.

Au-delà du journal intégré à l’application, cet échec peut laisser des traces dans :

- **Console** (web et ordinateur) : l’onglet **Console** des mêmes outils de développement enregistre les erreurs côté client, y compris celles qui surviennent avant que le POS puisse écrire sa propre entrée de journal.

## Détails {#details}

- **Code :** `CLIENT999` (`UNEXPECTED_ERROR`)
- **Gravité :** erreur
- **Introduit dans :** WCPOS 1.10.0
