## Ce que cela signifie {#what-this-means}

Votre boutique a demandé à WCPOS de ralentir momentanément.

Vous n'avez rien à faire : WCPOS attend et réessaie automatiquement. Si ce message apparaît tous les jours, demandez à l'administrateur de votre site quelle est la limite de requêtes de la boutique.

## Vos données {#your-data}

N'effacez pas les données de cet appareil : elles peuvent contenir des modifications qui ne sont pas encore arrivées dans votre boutique. Elles seront transmises lors d'une prochaine tentative.

## Dépannage {#troubleshoot}

1. Vous n'avez rien à faire : le PDV attend avant de réessayer automatiquement ; une nouvelle tentative manuelle ne ferait que prolonger la limitation.
2. Rien n’a besoin d’être ressaisi : les modifications concernées restent sur l’appareil et passeront lors d’une tentative ultérieure.
3. Si ce message apparaît tous les jours, demandez à l'administrateur du site de trouver quel niveau renvoie le code 429 : une extension de sécurité, un CDN, une règle de pare-feu ou les limites de l'hébergeur, et d'autoriser le trafic REST du PDV.
4. L’endpoint et les horodatages de l’entrée de journal dépliée aident l’administrateur à retrouver la limitation dans ses propres tableaux de bord.
