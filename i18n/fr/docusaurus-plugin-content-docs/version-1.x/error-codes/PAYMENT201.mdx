## Ce que cela signifie {#what-this-means}

WCPOS n’a pas pu confirmer si le terminal a encaissé le paiement.

Vérifiez le terminal de paiement avant de tenter un nouvel encaissement, et contactez le prestataire de paiement si le résultat reste incertain.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé — vérifiez avant de réessayer. Si le problème persiste, contactez votre prestataire de paiement.

## Dépannage {#troubleshoot}

1. Ne repassez pas encore la carte.
2. Vérifiez l’écran du terminal lui-même, puis le tableau de bord de votre prestataire de paiement — l’enregistrement du prestataire fait foi pour savoir si le paiement a été encaissé.
3. Si vous avez accès à WP Admin (sinon, demandez au propriétaire de la boutique), vérifiez WooCommerce → Commandes : un paiement réussi peut déjà y être enregistré.
4. N’encaissez à nouveau que lorsque le tableau de bord du prestataire n’indique aucun paiement.
5. Si le paiement apparaît comme en attente ou incertain, contactez le prestataire de paiement avant d’agir.
