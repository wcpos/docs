## Ce que cela signifie {#what-this-means}

Cette variation n’a pas pu être ajoutée au produit.

Rien d’autre n’a changé. Ouvrez le produit et vérifiez si la variation est présente ; si ce n’est pas le cas, vérifiez qu’elle utilise les attributs définis sur le produit parent, puis ajoutez-la à nouveau.

## Vos données {#your-data}

Ne supprimez pas les données de cet appareil — elles peuvent contenir des modifications qui ne sont pas encore dans votre boutique. Rien d’autre n’a changé : seule cette variation n’a pas été ajoutée.

## Dépannage {#troubleshoot}

1. Développez l’entrée du journal pour connaître le motif indiqué par la boutique — généralement un attribut manquant ou une combinaison d’options non valide.

**À la caisse :** ouvrez le produit et vérifiez si la variation est présente — si c’est le cas, ne l’ajoutez pas à nouveau. Sinon, vérifiez qu’elle utilise les attributs définis sur le produit parent, corrigez ses champs, puis ajoutez-la à nouveau.

**Sur la boutique (WP Admin) :** vérifiez les attributs du produit parent : chaque attribut utilisé par la variation doit exister sur le produit parent et être marqué comme utilisé pour les variations.

Le refus persiste ? Utilisez **Copy debug info** dans l’onglet **Logs** et contactez l’assistance.
