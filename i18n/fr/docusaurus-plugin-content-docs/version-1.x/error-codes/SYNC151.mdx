## Ce que cela signifie {#what-this-means}

La réponse de votre boutique contenait du texte superflu, que WCPOS a tenté de supprimer.

Vérifiez que l'action effectuée est terminée : le nettoyage ne fonctionne pas toujours. Le texte superflu provient généralement d'une extension ou d'un avis PHP qui ajoute du contenu aux réponses de la boutique. Si cela se produit souvent, demandez à l'administrateur de votre site de vérifier les avertissements dans le journal d'erreurs PHP du site.

## Vos données {#your-data}

Si l'action effectuée n'est pas terminée (voir l'étape 1 du dépannage), suivez les conseils associés à cette requête ; sinon, aucune donnée de commande ou de produit n'est affectée. Si cela se produit souvent, demandez à la personne qui gère votre site WordPress.

## Dépannage {#troubleshoot}

1. Vérifiez que l'action effectuée est terminée, par exemple que la vente ou la modification apparaît maintenant. Si c'est le cas, vous n'avez rien d'autre à faire. Sinon, réessayez ; si cela échoue, suivez les indications de l'erreur affichée ou contactez le support.
2. La cause se trouve sur le site : une extension ou un thème insère des avertissements ou du contenu parasite dans les réponses REST. Demandez à l’administrateur du site de rechercher des notices PHP dans les journaux du site à l’heure de l’échec.
3. **Pour l'administrateur du site :** les outils de développement du navigateur (onglet Réseau), ou **Avancé → Afficher/Masquer les outils de développement** dans l'application de bureau, affichent le corps brut de la réponse ; le contenu superflu apparaît juste avant ou après le JSON.
4. **Pour l'administrateur du site :** le nettoyage n'est pas garanti ; si cela se produit souvent, corrigez l'extension fautive au lieu de vous y fier.
