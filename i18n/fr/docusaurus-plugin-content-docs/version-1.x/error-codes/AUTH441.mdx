## Ce que cela signifie {#what-this-means}

Le jeton de connexion est plus volumineux que ce que ce serveur accepte.

Le serveur a rejeté le jeton de connexion à cause de sa taille : une erreur 400 lorsqu'il circule dans l'en-tête Authorization, ou une erreur 414 lorsqu'il circule dans l'URL. Aucun encodage côté client ne peut le réduire — il faut augmenter les limites de taille d'en-tête/d'URL du serveur, ou réduire la taille du jeton.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n'est affectée.

## Dépannage {#troubleshoot}

1. Sur Apache, augmentez LimitRequestFieldSize (voie de l'en-tête) ou LimitRequestLine (voie de l'URL) dans la configuration du vhost.
2. Sur nginx, augmentez large_client_header_buffers.
3. Derrière un proxy ou un CDN, la limite peut se trouver à cette couche — vérifiez les deux.
4. Si les limites ne peuvent pas être modifiées, contactez le support pour l'émission d'un jeton plus petit pour ce site.
