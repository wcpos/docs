## Ce que cela signifie {#what-this-means}

La validation de commande a rencontré un problème inattendu.

Vérifiez la commande dans l’administration de votre boutique avant de débiter à nouveau le client. Exportez les diagnostics et contactez l’assistance si le problème se répète.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé — vérifiez avant de réessayer. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Cherchez la commande dans WooCommerce → Commandes dans WP Admin avant de débiter à nouveau le client.
2. Dépliez l’entrée de journal et notez le code d’événement ainsi que tout serverCode — ce code générique signifie que la cause n’a pas encore de code dédié.
3. Si cela se répète, exportez les infos de débogage et contactez l’assistance.
