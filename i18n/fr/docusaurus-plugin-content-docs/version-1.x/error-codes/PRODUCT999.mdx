## Ce que cela signifie {#what-this-means}

Le chargement ou la mise à jour des produits a rencontré un problème inattendu.

Réessayez. Si les données du produit semblent toujours incorrectes ensuite, exportez les diagnostics et contactez l’assistance.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Réessayez — la plupart des problèmes ponctuels de chargement de produit disparaissent à la seconde tentative.
2. Si les données du produit semblent toujours incorrectes, dépliez l’entrée de journal pour relever le code d’événement et le contexte ; ce code générique signifie que la cause n’a pas encore de code dédié.
3. Exportez les infos de débogage et contactez l’assistance si cela se reproduit.
