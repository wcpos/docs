## Ce que cela signifie {#what-this-means}

Les données locales de la boutique sont endommagées et doivent être réparées avant que la synchronisation puisse reprendre.

Lancez la réparation ciblée pour les données concernées, et ne réinitialisez ces données locales que si le problème réapparaît.

## Vos données {#your-data}

Les données de cet appareil peuvent être menacées — n’effacez pas les données locales. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Ouvrez État de la boutique → Base de données et lancez la réparation ciblée pour les données concernées ; une réinitialisation complète supprime bien plus que la réparation.
2. Réessayez l’action qui a échoué, puis surveillez État de la boutique → Journaux pour voir si ce code réapparaît.
3. Si les mêmes données sont à nouveau signalées, réinitialisez uniquement ces données locales afin qu’elles soient retéléchargées depuis votre boutique — mais seulement après avoir noté les éventuelles modifications non envoyées.
4. Une corruption qui revient sans cesse indique un stockage défaillant sur l’appareil : exportez les infos de débogage et contactez l’assistance.
