## Ce que cela signifie {#what-this-means}

Une modification sur cet appareil a rencontré une modification plus récente dans votre boutique. Rien n’est perdu.

Si **État de la boutique → Base de données** répertorie une modification mise en attente pour cet enregistrement, touchez **Renvoyer** pour conserver la version de cet appareil, ou **Utiliser la version du serveur** pour conserver celle de la boutique. Sinon, aucune action n’est nécessaire : le conflit a déjà été résolu.

## Vos données {#your-data}

Rien n’est perdu. Lorsqu’une modification est mise en attente, votre boutique conserve sa version et cet appareil conserve sa modification jusqu’à ce que vous choisissiez laquelle garder ; les modifications ultérieures de cet enregistrement restent en attente sur cet appareil jusque-là. N’effacez pas les données de cet appareil tant qu’une modification est en attente : l’effacement la supprimerait.

## Dépannage {#troubleshoot}

1. Ouvrez **État de la boutique → Base de données**. Une modification en attente apparaît dans un panneau commençant par **« 1 modification mise en attente »** (ou **« … modifications mises en attente »**), avec l’enregistrement concerné.
2. Si aucune modification n’est plus en attente pour cet enregistrement, le conflit a déjà été résolu, ici ou dans un autre onglet ; aucune action n’est nécessaire. Un conflit de commande que WCPOS résout automatiquement en renvoyant la version de cet appareil est plutôt consigné sous [SYNC222](/error-codes/SYNC222).
3. Si une modification est en attente, touchez **Ouvrir l’enregistrement** (si l’option apparaît) pour afficher la version de cet appareil, puis comparez-la avec le même enregistrement dans WP Admin (l’intervention d’un administrateur du site peut être nécessaire).
4. Pour conserver la version de cet appareil, touchez **Renvoyer** : la modification est renvoyée et remplace les valeurs de la boutique pour les champs modifiés sur cet appareil. Pour conserver la version de la boutique, touchez **Utiliser la version du serveur** (certaines lignes indiquent **Abandonner la modification de l’appareil**) et confirmez : la modification de cet appareil est abandonnée. Les modifications ultérieures de cet enregistrement restent en attente jusqu’à votre choix.
5. Des conflits fréquents sur les mêmes enregistrements signifient généralement que deux personnes modifient les mêmes données en parallèle, par exemple le stock à la caisse et dans WP Admin. Convenez de l’endroit où effectuer chaque type de modification.
