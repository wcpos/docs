WCPOS stocke une copie locale de vos produits, commandes et clients pour que le PDV puisse fonctionner rapidement et hors ligne. Il arrive que ces données locales ne soient plus synchronisées avec votre boutique WooCommerce. Effacer toutes les données locales supprime la base de données locale et déclenche une nouvelle synchronisation depuis votre serveur.

:::tip Essayez d’abord une réinitialisation ciblée (v1.10.0+)
À partir de la v1.10.0, **État de la boutique → Base de données** propose **Effacer et retélécharger** pour chaque collection : cette option supprime et récupère à nouveau uniquement la collection qui pose problème (les produits, par exemple), sans toucher au reste ni vous déconnecter. La confirmation indique combien d’enregistrements seront supprimés et confirme que la copie sur votre serveur n’est pas affectée. Notez que les collections téléchargées à la demande affichent normalement un faible nombre d’enregistrements juste après une réinitialisation, puis se remplissent à mesure que vous les utilisez. C’est le comportement prévu, pas une synchronisation bloquée. Consultez [État de la boutique](/1.x/support/store-health#clear-and-redownload).
:::

:::warning
C’est une solution de dernier recours. Effacer les données locales supprime tout ce qui est stocké sur l’appareil et force une nouvelle synchronisation complète. Selon la taille de votre boutique, cela peut prendre du temps. Utilisez cette option uniquement lorsque les autres solutions — une [synchronisation](/1.x/products/sync) normale ou l’option **Effacer et retélécharger** par collection — n’ont pas résolu le problème.

Avant d’effacer les données, vérifiez la tuile **modifications en attente d’envoi** dans **État de la boutique → Base de données** — l’effacement des données locales détruit toutes les modifications non envoyées présentes sur l’appareil.
:::

## Quand l’utiliser {#when-to-use-it}

Vous pourriez avoir besoin d’effacer les données locales dans les cas suivants :

- **Problèmes de synchronisation** — les produits, commandes ou clients ne se mettent pas à jour correctement
- **Après une mise à jour d’extension** — pour garantir la compatibilité avec les nouvelles structures de données
- **Données obsolètes** — les prix, niveaux de stock ou autres informations semblent périmés

## Ce qui est effacé {#what-gets-cleared}

| Effacé | Non effacé |
|---------|-------------|
| Base de données locale des produits | Données côté serveur |
| Base de données locale des commandes | Paramètres WooCommerce |
| Base de données locale des clients | |
| Session de connexion | |

Les données de votre boutique WooCommerce ne sont pas affectées — seule la copie locale sur votre appareil est supprimée. Une nouvelle synchronisation commence automatiquement après l’effacement.

:::info Différence entre plateformes
- **Application de bureau :** vous serez déconnecté et devrez reconnecter votre boutique.
- **Application web :** les données de connexion sont effacées, mais comme vous êtes toujours connecté à WP Admin, la session est automatiquement restaurée — vous ne remarquerez donc pas la déconnexion.
:::

## Comment effacer les données locales {#how-to-clear-local-data}

### Web {#web}

1. Cliquez sur votre **menu utilisateur** dans le coin supérieur droit pour ouvrir le menu
2. Cliquez sur **Effacer toutes les données locales**
3. La base de données locale sera supprimée et une nouvelle synchronisation commencera automatiquement

### Bureau {#desktop}

1. Ouvrez le menu de l’application **WCPOS** dans la barre de menus supérieure
2. Survolez **Advanced**
3. Cliquez sur **Clear App Data**
4. La base de données locale sera supprimée et une nouvelle synchronisation commencera automatiquement

:::note
Toutes les plateformes stockent les données dans le même format de base de données locale (stockage de fichiers basé sur OPFS à partir de la v1.10.0). La base est entièrement effacée sur chaque plateforme, mais le comportement de connexion diffère — consultez la note sur la différence entre plateformes ci-dessus.
:::
