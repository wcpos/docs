:::info Fonctionnalité Pro
L'écran Coupons et la possibilité d'appliquer des coupons en caisse nécessitent [WCPOS Pro](/getting-started/pro-license). Les utilisateurs de la version gratuite voient un aperçu flouté de l'écran Coupons, mais ne peuvent ni consulter les détails des coupons ni appliquer de codes dans le panier.
:::

L'écran Coupons vous permet de parcourir et de rechercher vos coupons WooCommerce depuis le PDV. Le bouton **Ajouter un coupon** du panier les applique à la commande en cours. Les coupons sont toujours créés et gérés dans WooCommerce : le PDV les synchronise et les valide localement pour un retour immédiat à la caisse.

## Présentation de l'interface {#interface-overview}

### Actions de l'en-tête {#header-actions}

En haut de l'écran :

- **Barre de recherche** — Rechercher un coupon par code
- **Paramètres d'affichage** (<Icon name="sliders" />) — Configurer les colonnes visibles

### Tableau des coupons {#coupons-table}

La zone principale affiche vos coupons synchronisés avec les informations suivantes :

- **Code** — Le code de coupon saisi par les clients
- **Description** — Description interne (également utilisée comme libellé sur le reçu si elle est renseignée)
- **Type de remise** — Pourcentage, montant fixe sur le panier ou montant fixe sur un produit
- **Montant** — Valeur de la remise
- **Utilisé / Limite** — Nombre d'utilisations et limite d'utilisation totale
- **Expiration** — Date d'expiration, ou vide si aucune date n'est définie
- **Actions** — Menu à trois points

### Pied de page {#footer}

- Nombre de coupons avec bouton de synchronisation (<Icon name="arrow-rotate-right" />). **Appui long** pour afficher les options Effacer et Actualiser.

## Types de coupons {#coupon-types}

WCPOS prend en charge les trois types de coupons standard de WooCommerce :

| Type | Fonctionnement | Exemple |
|---|---|---|
| **Remise en pourcentage** | Réduit le sous-total du panier d'un pourcentage | `10%` de réduction sur la commande |
| **Remise fixe sur le panier** | Réduit le total du panier d'un montant fixe | `$5` de réduction sur la commande |
| **Remise fixe par produit** | Réduit les lignes de produits correspondants d'un montant fixe par unité | `$2` de réduction sur chaque T-shirt |

Les trois types respectent les mêmes règles de validation (expiration, limites d'utilisation, restrictions sur les produits et catégories, etc.).

## Création de coupons {#creating-coupons}

Les coupons se créent dans WooCommerce, et non dans le PDV. Accédez à **WP Admin → Marketing → Coupons → Ajouter un coupon** :

1. **Code promo** — code saisi par les caissiers à la caisse. Les codes ne tiennent pas compte des majuscules et minuscules.
2. **Description** — note interne. Si elle est renseignée, WCPOS l'utilise comme libellé de remise sur les reçus. Préférez une formulation destinée aux clients, comme « Remise responsable 10 % », plutôt qu'un code interne.
3. **Type de remise** — pourcentage, montant fixe sur le panier ou montant fixe sur un produit.
4. **Montant du coupon** — valeur de la remise.
5. **Date d'expiration** — facultative. Après cette date, le coupon sera refusé.

### Restriction d'utilisation {#usage-restriction}

| Restriction | Fonctionnement | Exemple |
|---|---|---|
| **Montant minimum / maximum** | Le coupon ne s'applique que si le sous-total dépasse / reste sous un seuil | Valable uniquement pour les commandes de plus de `$50` |
| **Utilisation individuelle uniquement** | Empêche de cumuler ce coupon avec un autre coupon | Impossible de cumuler « VIP20 » et « SALE10 » |
**Exclure les articles en promotion** — ignore les articles déjà en promotion (ainsi que toute ligne dont le prix a été modifié en caisse par un caissier — voir [Modifications de prix au PDV](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)).
| **Produits / Exclure des produits** | Limite le coupon à certains produits, ou en exclut certains | S'applique uniquement aux « Grains d'espresso » |
| **Catégories de produits / Exclure des catégories** | Limite l'application par catégorie. Les produits divers ou personnalisés créés dans le PDV respectent aussi les catégories qui leur sont attribuées dans le PDV | S'applique uniquement à la catégorie « Boissons » |
| **Adresses e-mail autorisées** | Limite le coupon à certaines adresses e-mail client (les jokers `*` sont acceptés) | `*@yourcompany.com` pour le personnel uniquement |

### Limites d'utilisation {#usage-limits}

| Limite | Fonctionnement |
|---|---|
| **Limite d'utilisation par coupon** | Nombre total d'utilisations de ce code pour l'ensemble des clients |
| **Limite d'utilisation par utilisateur** | Nombre d'utilisations autorisées pour un même client |
| **Limiter l'utilisation à X articles** | Pour les coupons à montant fixe sur un produit, plafonne le nombre d'articles éligibles bénéficiant de la remise par utilisation |

<a id="tips-for-pos-use"></a>

:::tip Conseils pour l'utilisation en point de vente
- Créez un coupon **« Responsable 10 % »** (10 % de réduction, sans minimum d'achat ni date d'expiration, restriction d'utilisation unique désactivée) et communiquez le code aux responsables. Le personnel pourra l'appliquer en caisse pour des ajustements ponctuels, et vous conserverez une remise traçable dans les rapports.
- Créez un coupon **« Fidélité 5 $ »** pour récompenser les clients réguliers.
- Pour les promotions ponctuelles, définissez une date d'expiration proche afin d'éviter que le code soit réutilisé par erreur plus tard.
- Renseigner le champ **Description** avec le texte que vous souhaitez imprimer sur les reçus est le moyen le plus rapide de personnaliser vos remises.
:::

## Appliquer un coupon en caisse {#applying-a-coupon-at-the-register}

Appuyez sur **Ajouter un coupon** dans le panier, puis saisissez le code ou recherchez par description. Le coupon est immédiatement validé à partir des données synchronisées et apparaît sous forme de pastille supprimable au-dessus des totaux du panier.

Pour le flux de travail complet en caisse — recherche, pastilles de coupon, cumul de plusieurs coupons et résolution des erreurs de validation — consultez **[Appliquer des coupons en caisse](/coupons/applying-coupons)**.

## Fonctionnement de la validation {#how-validation-works}

Lorsqu'un code est saisi, le PDV vérifie toutes les mêmes règles que WooCommerce vérifierait sur le serveur :

- Le coupon existe et n'est pas expiré
- Les limites d'utilisation ne sont pas dépassées (globales et par utilisateur)
- Le montant minimum/maximum d'achat est atteint
- Les coupons « Utilisation individuelle » ne sont pas en conflit avec les coupons déjà appliqués
- Les restrictions de produit/catégorie correspondent au contenu du panier
- Les restrictions par e-mail correspondent au client sélectionné (ou sont ignorées pour les commandes d'invités)
- Les articles en promotion sont exclus si **Exclure les articles en promotion** est activé

Si une vérification échoue, le caissier voit un message d'erreur spécifique (par ex., « Ce coupon a expiré » ou « Montant minimum non atteint »). Les mêmes vérifications sont effectuées à nouveau sur le serveur lors de la soumission de la commande — la validation locale sert à la rapidité, pas à la confiance.

## Comportement de synchronisation {#sync-behaviour}

Les coupons se synchronisent depuis WooCommerce vers l'appareil comme les autres données du PDV :

- Les nouveaux coupons créés dans WP Admin apparaissent dans le PDV lors de la prochaine synchronisation.
- Les modifications apportées aux coupons existants (nombre d'utilisations, changements de date d'expiration, etc.) sont synchronisées automatiquement.
- Les coupons sont stockés dans la base de données locale et restent donc disponibles hors ligne.

Si vous venez de créer un coupon dans WP Admin et qu'il n'apparaît pas encore, la synchronisation n'a peut-être pas encore eu lieu. Depuis le pied de page de l'écran Coupons, appuyez sur l'icône de synchronisation (<Icon name="arrow-rotate-right" />) pour actualiser — appuyez longuement pour **Effacer et actualiser** si une récupération complète est nécessaire.

## Connectivité {#connectivity}

- **L'application des coupons** fonctionne hors ligne, car la validation est effectuée côté client à partir des données synchronisées.
- **La finalisation du paiement** peut fonctionner hors ligne avec un moyen de paiement compatible hors connexion. La vente est mise en file d'attente localement ; le serveur revalide le coupon et met à jour son compteur d'utilisation lorsque la commande parvient à WooCommerce.
- **La création ou la modification des coupons** s'effectue dans WP Admin et nécessite une connexion à votre site WordPress.

## Interaction entre les coupons et les remises PDV {#how-coupons-interact-with-pos-discounts}

Lorsqu'un caissier réduit le prix d'une ligne en caisse et qu'un coupon est ensuite appliqué, le coupon est calculé sur le **prix réduit**, et non sur le prix d'origine. Les lignes dont le prix a été réduit via le PDV sont traitées comme « en promotion » — les coupons avec l'option **Exclure les articles en promotion** activée les ignoreront. Consultez la section [Remises](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons) pour en savoir plus.
