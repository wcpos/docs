WCPOS propose trois types de paramètres, organisés selon l'endroit où ils sont configurés.

## Où trouver les paramètres {#where-to-find-settings}

### 1. Paramètres de l'administration WordPress {#1-wordpress-admin-settings}

Paramètres d'administration configurés dans votre tableau de bord WordPress :

**Emplacement :** `WP Admin > POS > Paramètres`

Ils permettent de configurer :
- Le client du panier par défaut pour tous les caissiers
- Le champ de code-barres des produits
- Les e-mails de commande
- Les autorisations des rôles utilisateurs (qui peut accéder au PDV)
- La disponibilité des passerelles de paiement

Consultez [Paramètres de l'administration WordPress](/1.x/settings/wp-admin) pour plus de détails.

### 2. Paramètres de la boutique dans le PDV {#2-pos-store-settings}

Paramètres applicables à toute l'application, configurés dans le PDV :

**Emplacement :** menu utilisateur (en haut à droite) → Paramètres, ou `Ctrl + Shift + S`

Ils permettent de configurer :
- Les options de calcul des taxes
- Le scanner de codes-barres
- Les raccourcis clavier
- Le thème et l'apparence

Consultez [Paramètres de la boutique](/1.x/settings/store) pour plus de détails.

### 3. Paramètres d'affichage (par écran) {#3-display-settings-per-screen}

Chaque écran du PDV possède ses propres paramètres d'affichage pour personnaliser le tableau de données :

**Emplacement :** cliquez sur l'icône de curseurs (<Icon name="sliders" />) sur n'importe quel écran

Ils permettent de configurer :
- Les colonnes visibles
- Les options d'affichage des colonnes
- Les fonctionnalités propres à l'écran

Les paramètres d'affichage sont décrits dans la documentation de chaque écran :
- [Panneau des produits du PDV](/1.x/pos/product-panel#display-settings)
- [Panneau du panier](/1.x/pos/cart#display-settings)
- [Écran des produits](/1.x/products#display-settings)
- [Écran des commandes](/1.x/orders#display-settings)
- [Écran des clients](/1.x/customers#display-settings)
- [Écran des rapports](/1.x/reports#display-settings)
