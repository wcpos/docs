## Vue d'ensemble {#overview}

Au premier chargement, le PDV récupère automatiquement les paramètres par défaut de la configuration de votre boutique WooCommerce. Dans la plupart des cas, vous souhaiterez garder ces paramètres synchronisés avec votre boutique WooCommerce afin de maintenir la cohérence sur tous vos canaux de vente.

:::tip Bonne pratique
En règle générale, les utilisateurs devraient conserver les mêmes paramètres que ceux de leur boutique WooCommerce, sauf besoin commercial précis de les personnaliser pour le PDV, par exemple pour utiliser une autre devise sur un marché différent ou définir un autre client par défaut pour les ventes en boutique.
:::

## Informations sur la boutique {#store-information}

### Nom de la boutique {#store-name}

Nom de votre boutique tel qu'il apparaît dans toute l'interface du PDV et sur les reçus. Il est généralement synchronisé avec le nom de votre boutique WooCommerce.

### Adresse de la boutique {#store-address}

Les champs de l'adresse de la boutique comprennent :

- **Ville de la boutique** : ville où se trouve votre boutique
- **Code postal de la boutique** : code postal de votre boutique
- **État ou province de la boutique** : État ou province où votre boutique exerce son activité
- **Pays de la boutique** : pays où se trouve votre boutique

:::warning Paramètres d'adresse désactivés
Les champs d'adresse de la boutique sont actuellement désactivés dans les paramètres du PDV, car une modification de l'adresse peut avoir une incidence sur le calcul des taxes et entraîner des problèmes lors du traitement des commandes. Ces paramètres restent synchronisés avec la configuration de votre boutique WooCommerce.
:::

## Paramètres de localisation {#localisation-settings}

### Langue {#language}

Définit la langue d'affichage de l'interface du PDV. Ce paramètre contrôle la langue utilisée pour :

- Les éléments de menu et la navigation
- Les libellés des boutons et le texte de l'interface
- Les messages système et les notifications
- Le format des dates et des heures

### Devise {#currency}

Définit la devise principale utilisée pour les transactions et l'affichage des prix. Ce paramètre influe sur :

- L'affichage des prix des produits
- Les totaux et les calculs des commandes
- Le format des reçus
- Les rapports financiers

### Position de la devise {#currency-position}

Détermine la position du symbole monétaire par rapport au montant :

- **À gauche** : $10.00 (symbole avant le montant)
- **À droite** : 10.00$ (symbole après le montant)
- **À gauche avec espace** : $ 10.00
- **À droite avec espace** : 10.00 $

## Format des nombres {#number-formatting}

### Séparateur décimal {#decimal-separator}

Caractère utilisé pour séparer la partie entière de la partie décimale (p. ex. « . » ou « , »).

### Nombre de décimales {#number-of-decimals}

Indique le nombre de décimales à afficher pour les prix et les valeurs monétaires (généralement 2 pour la plupart des devises).

### Séparateur des milliers {#thousand-separator}

Caractère utilisé pour séparer les milliers dans les grands nombres (p. ex. « , » pour 1,000 ou « . » pour 1.000).

### Style de groupement des milliers {#thousands-group-style}

Détermine comment les milliers sont regroupés et affichés :

- **thousand** : groupement occidental standard (123,456,789) - groupes de 3 chiffres
- **lakh** : système de numération indien (12,34,56,789) - premier groupe de 3 chiffres, puis groupes de 2 chiffres
- **wan** : système de numération est-asiatique (1,2345,6789) - groupes de 4 chiffres

## Paramètres du client {#customer-settings}

### Client par défaut {#default-customer}

Définit le client sélectionné automatiquement pour les nouvelles commandes. Les options comprennent généralement :

- **Invité** : pour les clients de passage sans compte
- **Client spécifique** : un compte client prédéfini
- **Caissier** : le caissier connecté comme client

### Le client par défaut est le caissier {#default-customer-is-cashier}

Lorsque cette option est activée, le caissier actuellement connecté est automatiquement défini comme client des nouvelles commandes.

## Restaurer les paramètres du serveur {#restore-server-settings}

Le bouton « Restaurer les paramètres du serveur » permet de rétablir tous les paramètres généraux à leurs valeurs par défaut, telles que définies dans votre boutique WooCommerce.

:::info Synchronisation
Cliquer sur « Restaurer les paramètres du serveur » récupère les valeurs par défaut actuelles de la boutique WooCommerce et remplace tous les paramètres personnalisés du PDV.
:::
