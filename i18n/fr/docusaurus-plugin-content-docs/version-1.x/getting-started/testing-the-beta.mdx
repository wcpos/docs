WCPOS 2.0 est en bêta publique, pour les caisses dans le navigateur et l'application de bureau. Les applications Android et iOS sortiront une fois la phase de test bêta terminée ; d'ici là, gardez les téléphones et les tablettes sur une boutique en 1.11. La bêta sert à tester sur une copie de préproduction de votre boutique ou sur une boutique dont vous pouvez vous permettre d'interrompre l'activité ; ce n'est pas la version finale, et WordPress.org propose toujours la 1.11. Cette page contient tout ce dont un testeur a besoin.

## Ce qu'il vous faut {#what-you-need}

- **WooCommerce 9.0 ou une version ultérieure.** Sur une version plus ancienne, la 2.0 s'arrête sur un avis.
- **L'application et l'extension doivent toutes deux être en 2.0.** Une application 2.0 ne fonctionne pas avec une extension 1.11, et une application 1.11 demande une mise à jour lorsqu'elle rencontre une extension 2.0. Mettez d'abord à jour l'extension, puis chaque caisse.
- **Pas de lecteur de carte à bande magnétique.** La 2.0 supprime ce lecteur expérimental. Les lecteurs de carte en caisse passent par Stripe Terminal ou SumUp avec WCPOS Pro.
- **Les extensions de terminal nécessitent WCPOS Pro 2.0.** Stripe Terminal, SumUp et les autres extensions de terminal de paiement ont leurs propres préversions `2.0.0-beta1` sur GitHub ; installez-les manuellement après Pro.

## Avant l'installation {#before-you-install}

1. **Synchronisez chaque caisse avant la mise à niveau.** La 2.0 crée une nouvelle base de données locale sur chaque caisse et ne reprend pas les ventes qu'une caisse 1.11 n'a pas encore envoyées à la boutique. Ouvrez chaque caisse en 1.11, laissez la synchronisation se terminer, et seulement ensuite mettez à jour l'extension. Une vente encore non envoyée sur une caisse 1.11 est perdue après la mise à niveau.
2. **Sauvegardez le site** ou demandez à votre hébergeur un point de restauration.
3. **Choisissez une heure creuse.** Chaque caisse se recharge dans le nouvel écran de caisse à la première ouverture, et une vente en cours d'encaissement en 1.11 doit être saisie de nouveau.
4. Lisez les [notes de version de l'application](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.1) pour connaître les changements : l'écran de caisse, l'encaissement et le tiroir-caisse sont nouveaux, chaque écran est redessiné, et les remises par frais négatifs sont remplacées par « Ajouter une remise ».

## Obtenir la bêta {#get-the-beta}

**Extension (gratuite) :** téléchargez `woocommerce-pos.zip` depuis la [version WCPOS 2.0.0 bêta 1](https://github.com/wcpos/woocommerce-pos/releases/tag/v2.0.0-beta.1) et installez-la via **WP Admin → Extensions → Ajouter une extension → Téléverser une extension**, en remplaçant la version actuelle. Les caisses dans le navigateur passent à la 2.0 dès que l'extension est active.

**Extension (Pro) :** connectez-vous sur [wcpos.com/account/downloads](https://wcpos.com/account/downloads), téléchargez `woocommerce-pos-pro.zip` depuis la carte **WCPOS Pro 2.0 bêta** (une licence active est requise) et téléversez-la de la même manière. Pro contient l'extension gratuite ; vous n'installez pas les deux.

**Application de bureau :** la [version WCPOS Desktop 2.0.0 bêta 1](https://github.com/wcpos/electron/releases/tag/v2.0.0-beta.1) contient les programmes d'installation pour macOS, Windows et Linux. La version bêta ne se met pas à jour automatiquement ; les bêtas suivantes sont de nouveaux téléchargements depuis la même page des versions.

**iPhone, iPad et Android :** pas dans cette bêta. Les applications 2.0 pour les magasins d'applications sortiront une fois la phase de test bêta terminée ; une application 1.11 s'arrête sur un avis de mise à jour lorsqu'elle rencontre une boutique en 2.0, donc d'ici là, gardez les téléphones et les tablettes sur une boutique en 1.11.

Les notes de version de l'application pour la bêta se trouvent sur la [version de l'application](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.1) ; les changements des extensions figurent dans les notes de version de chaque extension.

## Revenir à la 1.11 {#rolling-back}

Prévenez-nous d'abord sur [Discord](https://wcpos.com/discord) ; la plupart des problèmes du jour de la bêta ont une solution plus rapide qu'un retour en arrière.

1. **Synchronisez chaque caisse avant de revenir en arrière.** Tout ce qu'une caisse 2.0 n'a pas envoyé reste dans la base de données locale 2.0, que l'application 1.11 n'ouvre jamais.
2. Réinstallez l'extension 1.11 : la version gratuite depuis [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) ou [Versions précédentes](/getting-started/previous-versions), Pro depuis [wcpos.com/account/downloads](https://wcpos.com/account/downloads) (la dernière version 1.11 de la liste).
3. Réinstallez l'application de bureau 1.11 là où vous avez installé la bêta. Une application 2.0 ne peut pas se connecter à une extension 1.11.
4. La caisse 1.11 démarre avec une base de données locale vide et se resynchronise depuis la boutique. Les commandes passées en 2.0 sont des commandes WooCommerce ordinaires et restent en place ; les sessions de caisse et les clôtures enregistrées en 2.0 restent dans la base de données, mais la 1.11 ne les affiche pas.

## Signaler ce que vous constatez {#reporting}

Ouvrez un ticket sur [wcpos/roadmap](https://github.com/wcpos/roadmap/issues/new) avec l'étiquette `beta`, ou écrivez à l'[assistance](https://wcpos.com/support). Indiquez la partie concernée (extension, bureau, iOS, Android, navigateur), la version, ce que vous avez fait, ce que vous attendiez et ce qui s'est passé ; une capture d'écran ou le code d'erreur affiché à l'écran est utile. Pour un problème lié à une vente ou à un paiement, indiquez le numéro de commande.
