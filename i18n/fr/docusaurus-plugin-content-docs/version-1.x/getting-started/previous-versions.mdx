## Réinstallation d'une Version Précédente {#re-installing-a-previous-version}

Pour revenir à une version antérieure de l’extension, désactivez les mises à jour automatiques, téléchargez la version souhaitée et téléversez-la par-dessus celle déjà installée. Rien n’est supprimé pendant l’opération : vos commandes, réglages et modèles de reçu restent en place.

:::warning Ne supprimez pas d’abord l’extension
Téléversez le fichier `.zip` par-dessus l’extension installée : vous conserverez ainsi tout le reste. Avec la version 2.0, supprimer l’extension depuis **Extensions** lance le nettoyage de WCPOS : cela déconnecte tous les caissiers, qui doivent alors se reconnecter sur chaque caisse, et efface les données de synchronisation que chaque caisse doit reconstruire. Il n’y a aucune raison de la supprimer.
:::

Si vous quittez la version 2.0, lisez d’abord [Revenir à une version précédente](/getting-started/upgrading-to-2#rolling-back). Avec WCPOS Pro, réinstallez uniquement WCPOS Pro : l’extension gratuite est incluse.

### Désactiver les mises à jour automatiques {#turn-off-auto-updates}

Lorsque les mises à jour automatiques sont activées, WordPress réinstalle de lui-même la version la plus récente.

1. Rendez-vous dans **WP Admin → Extensions**.
2. Sur la ligne WCPOS (ou WCPOS Pro), repérez la colonne **Mises à jour automatiques**. Si le lien **Désactiver les mises à jour automatiques** y figure, cliquez dessus.

### Télécharger la version souhaitée {#download}

Laissez le fichier `.zip` compressé. WordPress installe le fichier `.zip`, pas un dossier.

**WCPOS :**

1. Ouvrez la [vue avancée de WCPOS](https://wordpress.org/plugins/woocommerce-pos/advanced/) sur WordPress.org.
2. Faites défiler jusqu’à **Options avancées**. Sous **Versions précédentes**, choisissez la version souhaitée.
3. Cliquez sur **Télécharger**.

**WCPOS Pro :**

1. Connectez-vous à votre compte sur [wcpos.com](https://wcpos.com/account/downloads), puis ouvrez **Téléchargements**.
2. Dans **Historique des versions**, repérez la version souhaitée.
3. Cliquez sur **Télécharger** sur cette ligne.

Pour quitter la version 2.0, choisissez la version **1.11** la plus récente, et non une version 1.x plus ancienne.

### Téléverser par-dessus la version actuelle {#install}

1. Rendez-vous dans **WP Admin → Extensions**, puis cliquez sur **Ajouter une extension** en haut de la page.
2. Cliquez sur **Téléverser une extension**, choisissez le fichier `.zip` téléchargé, puis cliquez sur **Installer maintenant**.
3. WordPress indique **Cette extension est déjà installée.** et affiche côte à côte les versions **Actuelle** et **Téléversée**. Vérifiez que la version souhaitée apparaît sous **Téléversée**.
4. Cliquez sur **Remplacer l’actuelle par la téléversée**.
5. WordPress indique **L’extension a bien été rétrogradée.** Si l’option **Activer l’extension** s’affiche, cliquez dessus. Sinon, l’extension était déjà active et le reste.

Laissez les mises à jour automatiques désactivées jusqu’à ce que vous soyez prêt à mettre à jour de nouveau, puis réactivez-les ; sinon, les correctifs à venir ne seront pas installés automatiquement.

Si vous rencontrez un problème lors de la réinstallation ou avez besoin d’aide, contactez notre équipe d’assistance à l’adresse support@wcpos.com.
