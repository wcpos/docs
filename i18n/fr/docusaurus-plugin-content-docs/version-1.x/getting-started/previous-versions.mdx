## Réinstallation d'une Version Précédente {#re-installing-a-previous-version}

Si vous devez revenir à une version précédente du plugin WCPOS, suivez ces étapes :

1. Rendez-vous sur la page WordPress.org [Vue Avancée](https://wordpress.org/plugins/woocommerce-pos/advanced/) pour WCPOS.

2. Faites défiler jusqu’à la section **Options avancées**, puis repérez le menu déroulant **Versions précédentes**.

3. Ouvrez le menu déroulant pour afficher la liste des versions de l’extension disponibles. Repérez la version à installer et cliquez sur le bouton **Télécharger** correspondant. Enregistrez le fichier téléchargé sur votre bureau ou dans un emplacement pratique.

4. Connectez-vous au tableau de bord d’administration WordPress.

5. Accédez à la page **Extensions** en cliquant sur **Extensions** dans le menu de gauche.

6. Désactivez et supprimez la version actuelle de l’extension WCPOS. L’extension sera ainsi retirée de votre installation WordPress. Ne vous inquiétez pas, vos données ne seront pas perdues.

7. Cliquez sur le bouton **Ajouter une extension** en haut de la page.

8. Sur la page **Ajouter des extensions**, cliquez sur le bouton **Téléverser une extension**.

9. Choisissez le fichier de l’extension téléchargé précédemment depuis votre bureau ou l’emplacement où vous l’avez enregistré.

10. Cliquez sur le bouton **Installer maintenant** et attendez la fin de l’installation.

11. Une fois l’installation terminée, cliquez sur le bouton **Activer** pour activer la version précédente de l’extension WCPOS.

Et voilà ! Vous avez réinstallé avec succès une version précédente de l’extension WCPOS.

Si vous rencontrez un problème lors de la réinstallation ou avez besoin d’aide, contactez notre équipe d’assistance à l’adresse support@wcpos.com.
