WCPOS prend en charge plusieurs méthodes de paiement pour s'adapter aux différents besoins commerciaux. Le processus de paiement utilise une iframe/webview pour charger la page de paiement de commande (Order Pay) de WooCommerce, ce qui signifie que toute passerelle de paiement compatible avec WooCommerce peut fonctionner dans le POS.

## Méthodes de Paiement Par Défaut {#default-payment-methods}

La version gratuite inclut deux passerelles de paiement intégrées :

### Espèces {#cash}

- Saisir le montant remis
- Calcul automatique de la monnaie
- Aucune configuration supplémentaire requise

### Carte {#card}

- À utiliser avec des terminaux de carte externes
- Il suffit de marquer le paiement comme complet après traitement sur votre terminal
- Aucune intégration directe requise

## Passerelles de Paiement Supplémentaires (Pro) {#additional-payment-gateways-pro}

:::info Fonction Pro
Les passerelles de paiement supplémentaires nécessitent [WCPOS Pro](/1.x/getting-started/pro-license).
:::

Avec Pro, vous pouvez activer des passerelles de paiement WooCommerce supplémentaires lors du paiement au PDV :

- **Stripe Terminal** - Intégration directe avec les lecteurs de cartes Stripe
- **SumUp Terminal** - Intégration avec les lecteurs de cartes SumUp
- **Toute passerelle de paiement WooCommerce** - Activez n’importe quelle passerelle de paiement installée sur votre boutique

## Activer et désactiver les passerelles de paiement {#enabling-and-disabling-gateways}

Les passerelles de paiement sont gérées dans l’administration WordPress :

1. Accédez à `WP Admin > POS > Réglages > Validation de la commande`
2. Vous verrez la liste de toutes les passerelles de paiement WooCommerce installées
3. Activez ou désactivez chaque passerelle de paiement pour le PDV indépendamment de votre boutique en ligne
4. Faites-les glisser pour modifier leur ordre — la première passerelle de paiement activée devient celle par défaut au moment du paiement

Une passerelle de paiement peut donc être active sur votre site web mais désactivée dans le PDV, ou inversement. Consultez les [Paramètres de paiement](/1.x/settings/wp-admin/checkout) pour tous les détails.

## Tester les paiements {#testing-payments}

Avant de mettre en service une nouvelle passerelle de paiement :

1. **Passerelle de paiement Espèces** — toujours disponible pour tester le processus de paiement sans transactions réelles.
2. **Stripe Terminal** — Stripe fournit un [lecteur simulé](https://docs.stripe.com/terminal/testing) pour le mode test. Activez d'abord le mode test dans votre tableau de bord Stripe.
3. **Passerelles de paiement tierces** — consultez leur documentation pour connaître les instructions du mode test ou bac à sable. La plupart des passerelles de paiement WooCommerce proposent une option pour activer le mode test.

:::tip
Si une passerelle de paiement nouvellement activée n’apparaît pas au moment du paiement, essayez d’actualiser le PDV. Les modifications effectuées dans WP Admin prennent effet au prochain chargement de la page.
:::

## Problèmes courants {#common-issues}

### La passerelle de paiement n’apparaît pas au paiement {#gateway-not-appearing-at-checkout}

- Vérifiez que la passerelle de paiement est activée pour le PDV dans `WP Admin > POS > Réglages > Validation de la commande`.
- Vérifiez que la passerelle de paiement est également activée dans `WP Admin > WooCommerce > Réglages > Paiements` — elle doit être active dans WooCommerce pour apparaître dans le PDV.
- Actualisez le PDV après vos modifications.

### La passerelle de paiement s’affiche incorrectement {#gateway-displays-incorrectly}

L’iframe de paiement charge les styles du thème de votre site, ce qui peut parfois perturber l’affichage. Utilisez le bouton **Paramètres de paiement** dans la fenêtre de paiement pour désactiver certains styles ou scripts. Consultez le [Dépannage du paiement](/1.x/pos/checkout#checkout-settings-troubleshooting) pour plus de détails.

### Le traitement du paiement échoue {#payment-processing-fails}

- Consultez les journaux d’erreurs de votre site (`WP Admin > POS > Forums de support > Journaux`) pour repérer les erreurs propres à la passerelle de paiement.
- Assurez-vous que votre certificat SSL est valide — la plupart des passerelles de paiement nécessitent HTTPS.
- Si vous utilisez un environnement de préproduction ou local, vérifiez que la passerelle de paiement prend en charge le mode test ou bac à sable.
