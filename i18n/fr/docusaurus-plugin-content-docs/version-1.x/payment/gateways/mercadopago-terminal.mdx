# Passerelle Mercado Pago Terminal {#mercado-pago-terminal-gateway}

La passerelle Mercado Pago Terminal vous permet d’accepter des paiements en personne sur les terminaux Mercado Pago Point Smart depuis WCPOS. Le paiement est lancé depuis WooCommerce et finalisé sur le terminal ; la confirmation de Mercado Pago est ensuite enregistrée dans la commande.

:::info Nouveau dans la version 0.1.0
Mercado Pago Terminal for WooCommerce est une nouvelle extension, et la version 0.1.0 est sa première version. Considérez-la comme une version bêta : commencez en mode **Test** avec le terminal virtuel de test Mercado Pago et effectuez un paiement de test avant d’accepter des paiements réels.
:::

## Fonctionnement {#how-it-works}

La passerelle utilise l’**API Orders for Point** dans le cloud de Mercado Pago. Le lancement d’un paiement crée une commande Mercado Pago correspondant au montant total de la commande WooCommerce et l’envoie au terminal sélectionné. La commande Mercado Pago expire après **5 minutes**.

La page de paiement interroge Mercado Pago toutes les **2 secondes**. Le webhook et une **vérification en arrière-plan après 5 minutes** peuvent également finaliser une commande payée, même si le navigateur a été fermé. Le webhook est facultatif, mais recommandé ; sans **Webhook secret**, les notifications sont tout de même traitées, mais leur signature n’est pas vérifiée.

Le terminal doit être en mode **PDV (intégré)**. Les terminaux sont livrés en mode **STANDALONE** ; passez donc en mode PDV dans les réglages de la passerelle et redémarrez le terminal avant d’accepter des paiements.

## Configuration {#setup}

<Steps>
  <StepCard number="1" title="Installer Mercado Pago Terminal for WooCommerce">

Téléchargez l’**archive zip de l’extension** (et non l’archive zip du code source GitHub) depuis la [page des versions GitHub](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases). Téléversez-la via `Extensions > Ajouter > Téléverser une extension` et activez-la avec WooCommerce installé et activé.

  </StepCard>
  <StepCard number="2" title="Ajouter vos identifiants Mercado Pago">

1. Accédez à `WP Admin > WooCommerce > Réglages > Paiements` et ouvrez **Mercado Pago Terminal**
2. Choisissez **Mode** : `Test` utilise le terminal virtuel de test ; `Live` utilise les terminaux réels
3. Collez le jeton **Access token** (`APP_USR-…`) de votre application, disponible dans Mercado Pago → **Your integrations** → **Credentials**

:::warning Vérifiez votre jeton en mode Live
Un jeton `TEST-` en mode Live envoie les paiements vers l’environnement de test. L’écran des réglages signale cette combinaison ; collez votre jeton de production avant d’accepter des paiements réels.
:::

  </StepCard>
  <StepCard number="3" title="Enregistrer le webhook">

1. Dans Mercado Pago, accédez à **Your integrations** → votre application → **Webhooks**
2. Ajoutez l’URL du webhook affichée sur l’écran des réglages de la passerelle
3. Sélectionnez l’événement **Order (Mercado Pago)** et enregistrez
4. Copiez la **secret signature** dans **Webhook secret** dans WooCommerce

Le webhook est facultatif. Les paiements sont tout de même finalisés par interrogation sans lui, mais la configuration du secret permet à l’extension de vérifier les signatures des webhooks.

  </StepCard>
  <StepCard number="4" title="Configurer vos terminaux">

1. Enregistrez puis rechargez l’écran des réglages. La liste déroulante **Default terminal** et le tableau **Terminals** affichent les terminaux de votre compte
2. Pour un terminal affiché en mode **STANDALONE**, cliquez sur **Switch to PDV**, puis **redémarrez le terminal**
3. Choisissez un **Default terminal**
4. *(Facultatif)* Limitez **Enabled terminals** aux appareils que les caissiers peuvent sélectionner. Laissez le champ vide pour autoriser tous les terminaux ; le terminal par défaut enregistré reste disponible même s’il n’est pas sélectionné ici
5. *(Facultatif)* Activez **Lock terminal selection** pour toujours utiliser le terminal par défaut et empêcher les caissiers de le modifier. Un terminal par défaut est requis
6. Enregistrez vos réglages

  </StepCard>
  <StepCard number="5" title="Activer dans WCPOS" isLast>

1. Accédez à `WP Admin > POS > Réglages > Validation de la commande`
2. Repérez la passerelle **Mercado Pago Terminal** et activez-la pour le PDV
3. Enregistrez vos réglages

:::note
La case **Enable/Disable** dans l’écran des réglages WooCommerce contrôle uniquement le paiement de la *boutique en ligne*. WCPOS utilise cette passerelle dès qu’elle est configurée, que cette case soit cochée ou non.
:::

  </StepCard>
</Steps>

## Référence des réglages {#settings}

| Réglage | Fonction |
|---|---|
| **Enable/Disable** | Active la passerelle pour le paiement dans la boutique en ligne. L’activation dans le PDV se règle sous `POS > Réglages > Validation de la commande` |
| **Title** | Libellé du paiement ; valeur par défaut : `Mercado Pago Terminal` |
| **Description** | Description du paiement ; valeur par défaut : `Pay in person on a Mercado Pago Point terminal.` |
| **Mode** | `Test` (par défaut) utilise le terminal virtuel de test ; `Live` utilise les terminaux réels avec des identifiants de production |
| **Access token** | Jeton de votre application depuis Mercado Pago → Your integrations → Credentials. Un jeton enregistré ne s’affiche plus ; laissez le champ vide pour le conserver |
| **Webhook secret** | Signature secrète des réglages de webhook Mercado Pago, utilisée pour vérifier les notifications |
| **Default terminal** | Terminal utilisé par défaut au paiement, récupéré en temps réel depuis votre compte. Un champ de texte apparaît si la liste ne peut pas être récupérée |
| **Enabled terminals** | Limite les terminaux que les caissiers peuvent sélectionner. Une liste vide autorise tous les terminaux ; le terminal par défaut reste toujours disponible. Masqué si la liste ne peut pas être chargée |
| **Lock terminal selection** | Utilise toujours le terminal par défaut afin que les caissiers ne puissent pas le modifier. Un terminal par défaut est requis |
| **Checkout debug logs** | Affiche **Show logs**, **Copy** et **Clear** dans le panneau de paiement. Désactivé par défaut ; activez cette option pour recueillir des journaux destinés à l’assistance |
| **Log level** | `Off`, `Errors only` ou `Debug`. La valeur par défaut est Debug dans cette version ; les requêtes et les réponses sont enregistrées après suppression des secrets |

Sous les champs, le tableau **Mercado Pago Terminal diagnostics** affiche le contrôle de l’API (notamment le nombre de terminaux et de PDV), la date de dernière vérification du webhook, l’environnement actif, l’état de configuration des identifiants, le terminal par défaut, l’URL du webhook et le lien vers les journaux de paiement.

## Utilisation {#usage}

### Traitement des paiements {#processing-payments}

1. **Add Items** : Ajoutez des produits à votre panier dans le PDV
2. **Select Gateway** : Choisissez **Mercado Pago Terminal** comme mode de paiement
3. **Choose Terminal** : Sélectionnez un terminal ou utilisez le terminal par défaut si la sélection est verrouillée
4. **Start Payment** : Cliquez sur **Start Terminal Payment** pour envoyer le montant total de la commande au terminal
5. **Customer Payment** : Suivez les messages d’état — `Sending to terminal…` → `Waiting for terminal…` → `Customer is paying on the terminal…` — pendant que le client effectue le paiement sur le terminal
6. **Finalisation automatique** : Lorsque Mercado Pago confirme le paiement, la commande est finalisée et le PDV affiche le reçu

### Commandes de paiement {#payment-controls}

- **Start Terminal Payment** : Envoyez une nouvelle demande de paiement au terminal sélectionné
- **Cancel Terminal Payment** : Annulez uniquement avant que le terminal ne prenne en charge le paiement. Ensuite, annulez-le sur le terminal ou attendez son expiration après **5 minutes**
- **Rechargement de la page** : Reprend un paiement déjà en cours

### Reçus {#receipts}

Le terminal n’imprime pas de ticket. Utilisez le reçu du PDV une fois le paiement finalisé.

## Remboursements {#refunds}

Ouvrez l’écran de remboursement de la commande WooCommerce et choisissez **Refund via Mercado Pago Terminal** pour effectuer un remboursement total ou partiel. Mercado Pago autorise les remboursements jusqu’à **90 jours** après le paiement.

Certains acquéreurs de cartes n’autorisent les remboursements que sur le terminal. Dans ce cas, effectuez le remboursement sur le terminal et enregistrez un **remboursement manuel** dans WooCommerce.

## Journaux et dossier d’assistance {#logs-and-support-bundle}

Retrouvez les journaux dans `WooCommerce > Status > Journaux`, sous la source `mercadopago-terminal`. Le niveau de journalisation par défaut est **Debug** dans cette version. Les requêtes, réponses, webhooks et changements d’état des paiements sont enregistrés après masquage des secrets et des numéros de carte.

Cliquez sur **Download support bundle** dans l’écran des réglages de la passerelle pour télécharger un fichier `.txt` et le joindre à votre demande d’assistance. Il contient des informations sur l’environnement, les réglages avec les identifiants masqués, la liste des terminaux et leurs modes de fonctionnement, les tentatives de paiement des 10 commandes les plus récentes et les 500 dernières lignes de journal ; il ne contient rien qui permette d’effectuer des paiements.

Activez **Checkout debug logs** pour ajouter **Show logs**, **Copy** et **Clear** au panneau de paiement. L’activité de paiement est enregistrée dans les journaux WooCommerce, que cette option soit activée ou non.

## Périmètre et limitations {#scope-and-limitations}

- Le terminal débite le **montant total de la commande**. Le paiement d’une partie seulement de la commande sur le terminal n’est pas pris en charge
- Les pourboires ne sont pas pris en charge
- Les montants sont envoyés avec **deux décimales**. Les boutiques qui vendent en pesos chiliens ou colombiens doivent d’abord effectuer un paiement de test
- La **validation de commande par blocs** de la boutique en ligne n’est pas prise en charge
- L’extension ne déclare pas encore la **compatibilité HPOS**

## Dépannage {#troubleshooting}

### Problèmes courants {#common-issues}

<Accordion>
  <AccordionItem question="Jeton d’accès refusé par Mercado Pago (HTTP 401)">

  - Le jeton d’accès est invalide ou obsolète
  - Copiez un nouveau jeton depuis **Your integrations** → **Credentials** et enregistrez-le dans **Access token**

  </AccordionItem>
  <AccordionItem question="Aucun terminal n’est répertorié">

  - Si aucun terminal Point n’est associé au compte, connectez-vous au terminal avec ce compte Mercado Pago, passez en mode PDV et redémarrez-le
  - Si **Default terminal** est un champ de texte plutôt qu’une liste déroulante, la liste n’a pas pu être récupérée. Vérifiez le jeton et les diagnostics, puis rechargez l’écran des réglages

  </AccordionItem>
  <AccordionItem question="Le terminal est en mode STANDALONE">

  - Les paiements intégrés nécessitent le mode **PDV**
  - Cliquez sur **Switch to PDV** dans le tableau **Terminals** de l’écran des réglages, puis redémarrez le terminal

  </AccordionItem>
  <AccordionItem question="Le paiement est déjà sur le terminal">

  - Le terminal a pris en charge le paiement ; il n’est donc plus possible de l’annuler depuis WooCommerce
  - Annulez le paiement sur le terminal ou attendez son expiration après **5 minutes**. La page de paiement continue de vérifier son état

  </AccordionItem>
  <AccordionItem question="Le webhook n’a jamais été vérifié">

  - Si les diagnostics affichent **Last verified webhook: never**, vérifiez l’URL et le secret du webhook dans Mercado Pago
  - Si **Webhook secret** est manquant, collez la **secret signature** fournie par Mercado Pago. Les paiements sont tout de même finalisés par interrogation, mais les notifications sans le secret ne font pas l’objet d’une vérification de signature

  </AccordionItem>
  <AccordionItem question="L’acquéreur de la carte a refusé le remboursement">

  - Certains acquéreurs n’autorisent les remboursements que sur le terminal ; Mercado Pago limite également les remboursements à **90 jours**
  - Effectuez le remboursement sur le terminal et enregistrez un **remboursement manuel** dans WooCommerce

  </AccordionItem>
  <AccordionItem question="Le paiement a expiré sur le terminal">

  - Les commandes Mercado Pago expirent après **5 minutes**
  - Relancez le paiement

  </AccordionItem>
</Accordion>
