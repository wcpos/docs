Un client vous présente un code de coupon, ou vous proposez une promotion. Cette page explique comment appliquer un coupon de votre boutique à la vente dans le panier. L’application de coupons fonctionne aussi avec l’extension gratuite.

:::note Le coupon provient de votre boutique
La caisse applique les coupons qui existent déjà dans votre boutique. Créez-les dans **WP Admin → Marketing → Codes promo** ; consultez [Coupons](./index.mdx#creating-coupons). Pour accorder une réduction sans coupon, utilisez plutôt [Ajouter une remise](../pos/cart/discounts.mdx#order-level-discounts).
:::

## Trouver le coupon {#find}

1. Une fois les articles dans le panier, appuyez sur **+** en haut du panier et choisissez **Ajouter une remise**. Sur un téléphone, le panier dispose de son propre onglet : ouvrez-le d’abord.
2. Passez à **Coupon** et appuyez sur **Sélectionner un coupon**.
3. Saisissez une partie du code ou de la description du coupon, puis appuyez sur le coupon.
4. Appuyez sur **Appliquer**.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 0], [0, 0], [-24, 0], [-30, 0], [-30, 0], [0, -34], [0, -44]]} alt="La boîte de dialogue Ajouter une remise sur l’onglet Coupon, avec la liste des coupons ouverte : les onglets Remise rapide et Coupon, le champ Sélectionner un coupon, le champ de recherche, un coupon avec son type et son montant, le bouton Nouveau coupon et le bouton Appliquer">

1. **Remise rapide** — un montant ou un pourcentage déduit de la commande, sans coupon. Consultez [Remises](../pos/cart/discounts.mdx#order-level-discounts).
2. **Coupon** — les coupons de votre boutique.
3. **Sélectionner un coupon** — ouvre la liste. Une fois le coupon choisi, son code apparaît ici.
4. **Rechercher des coupons** — saisissez une partie du code ou de la description. La recherche ne tient pas compte des majuscules.
5. **Un coupon** — son code, puis sa description ou, s’il n’en a pas, son type : **Remise en pourcentage**, **Remise panier fixe** ou **Remise produit fixe**. À droite, le montant de la réduction.
6. **Nouveau coupon** (WCPOS Pro) — créez un coupon maintenant et appliquez-le à cette vente. Vous devez disposer de l’autorisation de créer des coupons et d’une connexion à votre boutique ; sinon, le **+** est grisé.
7. **Appliquer** — vérifie les conditions du coupon pour cette commande et l’applique.

</JourneyShot>

La liste affiche tous les coupons de votre boutique, y compris ceux qui ont expiré ou atteint leur limite d’utilisation. La caisse vérifie les conditions lorsque vous appuyez sur **Appliquer**, pas lorsque vous choisissez le coupon.

## Appliquer le coupon {#apply}

Lorsque vous appuyez sur **Appliquer**, la boîte de dialogue se ferme et le coupon apparaît dans les totaux, sous **Sous-total** : son code, une **✕** pour le retirer et le montant de la réduction. Chaque coupon ajouté dispose de sa propre ligne, dans l’ordre d’application. Pour en ajouter un autre, ouvrez à nouveau **Ajouter une remise**.

Les articles du panier affichent eux aussi leur part de la réduction : le total de chaque ligne diminue et l’ancien montant est barré.

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-28, 0], [100, 0], [40, 0], [40, 0], [0, 0]]} alt="Le panier avec deux coupons appliqués : le menu d’ajout, le sous-total, une ligne par coupon avec son code, un bouton de retrait et le montant de la réduction, le total de l’article avec l’ancien montant barré, et le bouton Paiement">

1. **+** — ouvrez à nouveau **Ajouter une remise** pour ajouter un autre coupon.
2. **Sous-total** — le montant de la commande avant les coupons. Les lignes des coupons apparaissent en dessous.
3. **Un coupon** — son code, la **✕** qui permet de le retirer et le montant de la réduction.
4. **Le coupon suivant** — chaque coupon dispose de sa propre ligne, dans l’ordre d’application.
5. **Paiement** — encaissez la commande. Consultez [Paiement](../pos/checkout/index.mdx).

</JourneyShot>

Le reçu affiche la description du coupon issue de WooCommerce, ou son code s’il n’a pas de description. Un reçu imprimé hors ligne affiche le code. Lorsque vous modifiez le panier, le montant de chaque coupon est recalculé : si vous ajoutez un article, un coupon en pourcentage déduit davantage.

La vérification d’un coupon utilise les données présentes sur cet appareil : vous pouvez donc aussi l’appliquer hors ligne. Votre boutique peut toutefois modifier le total ou refuser la commande lorsqu’elle la reçoit ; consultez [En cas de problème](#goes-wrong).

## Retirer un coupon {#remove}

Appuyez sur **✕** sur la ligne du coupon dans les totaux. Le montant déduit est rétabli et le message **Coupon retiré** s’affiche. Pour le remettre, appliquez-le à nouveau.

Lors du paiement, les lignes des coupons n’ont pas de **✕**, afin qu’un coupon ne puisse pas changer pendant l’encaissement. Appuyez sur **✕** en haut de l’écran de paiement pour revenir au panier, modifiez-y les coupons, puis appuyez à nouveau sur **Paiement**. {/* pending: monorepo#3364 */}

L’[annulation](../pos/cart/order-actions.mdx#void) de la commande retire aussi ses coupons.

## Lorsque la caisse refuse un coupon {#refused}

Si le coupon ne s’applique pas à cette commande, la boîte de dialogue reste ouverte et en indique la raison en rouge au-dessus du coupon. Choisissez un autre coupon ou appuyez sur **Annuler**.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-24, 0], [0, -44]]} alt="La boîte de dialogue Ajouter une remise après avoir appuyé sur Appliquer, avec le message Ce coupon a expiré en rouge au-dessus du champ Coupon">

1. **Sélectionner un coupon** — le coupon que vous avez essayé d’appliquer. La ligne rouge au-dessus indique pourquoi il n’a pas été appliqué. Choisissez un autre coupon ici.
2. **Appliquer** — réessayez une fois que la commande remplit les conditions.

</JourneyShot>

Trouvez la cause ci-dessous. Chaque entrée donne le message exact de la caisse, sa cause et la marche à suivre :

<Accordion>
  <AccordionItem question="Coupon expiré">

La caisse indique : **Ce coupon a expiré.**

La date d’expiration du coupon est dépassée : il ne peut donc plus être utilisé. Choisissez un autre coupon. S’il devrait encore être valable, la boutique peut modifier sa date dans WP Admin.

  </AccordionItem>
  <AccordionItem question="Limite d’utilisation du coupon atteinte">

La caisse indique : **Ce coupon a atteint sa limite d’utilisation.**

Le coupon a été utilisé autant de fois que la boutique l’autorise. Choisissez un autre coupon.

  </AccordionItem>
  <AccordionItem question="Le client a atteint sa limite d’utilisation">

La caisse indique : **Ce client a déjà utilisé ce coupon le nombre maximal de fois.**

Le client associé à la commande a épuisé le nombre d’utilisations de ce coupon auquel il a droit. Vérifiez que le bon client est associé à la commande ou choisissez un autre coupon.

  </AccordionItem>
  <AccordionItem question="Montant inférieur au minimum requis">

La caisse indique : **Ce coupon nécessite un montant minimum d’achat de …**

Le montant de la commande est inférieur au minimum requis par le coupon ; le message précise ce minimum. Ajoutez des articles ou choisissez un autre coupon.

  </AccordionItem>
  <AccordionItem question="Montant supérieur au maximum autorisé">

La caisse indique : **Ce coupon s’applique uniquement aux commandes de … ou moins.**

Le montant de la commande dépasse le maximum autorisé par le coupon ; le message précise ce maximum. Enregistrez une partie des articles dans une vente distincte ou choisissez un autre coupon.

  </AccordionItem>
  <AccordionItem question="Le nouveau coupon doit être utilisé seul">

La caisse indique : **… ne peut pas être cumulé avec d’autres coupons. Retirez les autres pour l’utiliser.**

Le coupon choisi doit être le seul coupon de la commande. Retirez ceux qui y figurent déjà, puis appliquez celui-ci.

  </AccordionItem>
  <AccordionItem question="Un coupon de la commande doit rester seul">

La caisse indique : **… est déjà appliqué à la commande et ne peut pas être cumulé avec d’autres coupons.**

Un coupon de la commande doit être le seul utilisé ; le message indique lequel. Retirez-le si vous préférez utiliser le nouveau ; sinon, conservez-le et n’ajoutez pas le nouveau.

  </AccordionItem>
  <AccordionItem question="Coupon déjà appliqué à la commande">

La caisse indique : **Ce coupon est déjà appliqué à la commande.**

Chaque coupon ne s’applique qu’une fois à une commande, et celui-ci y figure déjà. Vous n’avez rien à faire.

  </AccordionItem>
  <AccordionItem question="Aucun e-mail client sur la commande">

La caisse indique : **Ce coupon est réservé à certains clients. Ajoutez d’abord à la commande un client disposant d’une adresse e-mail.**

Le coupon n’est valable que pour certaines adresses e-mail, et la commande ne comporte pas encore d’e-mail client. Choisissez le client dans le panier, puis appliquez à nouveau le coupon.

  </AccordionItem>
  <AccordionItem question="L’e-mail du client ne figure pas dans la liste">

La caisse indique : **Ce coupon est réservé à certains clients, et l’e-mail de ce client n’en fait pas partie.**

L’adresse e-mail du client ne figure pas dans la liste du coupon. Vérifiez que le bon client est associé à la commande ou choisissez un autre coupon.

  </AccordionItem>
  <AccordionItem question="Aucun article du panier n’est couvert par le coupon">

La caisse indique : **Ce coupon ne peut pas être appliqué à ce panier.**

Aucun article du panier n’est couvert par le coupon. Ou bien le coupon exclut les articles en promotion, et le panier en contient un. Ajoutez un article couvert par le coupon ou retirez l’article en promotion. Consultez [Modifications de prix et coupons](#price-changes).

  </AccordionItem>
  <AccordionItem question="Coupon absent de cet appareil">

La caisse indique : **Coupon introuvable**

Le coupon n’est pas encore présent sur cet appareil. [Récupérez les coupons](#sync), puis réessayez.

  </AccordionItem>
  <AccordionItem question="Panier modifié pendant la vérification">

La caisse indique : **Le panier a été modifié pendant l’application du coupon. Veuillez réessayer.**

Le panier a été modifié pendant que la caisse vérifiait le coupon. Appuyez à nouveau sur **Appliquer**.

  </AccordionItem>
</Accordion>

## Utiliser plusieurs coupons {#more-than-one}

Vous pouvez appliquer plusieurs coupons à une commande : ouvrez à nouveau **Ajouter une remise** pour chacun. Un coupon réglé sur **Utilisation individuelle uniquement** ne peut pas être cumulé avec un autre sur la même commande, quel que soit l’ordre d’application. La caisse indique quel coupon empêche l’ajout.

<Accordion>
  <AccordionItem question="Comment la réduction du deuxième coupon est calculée">

Cela dépend du réglage WooCommerce **Calculer les remises de codes promo séquentiellement**, dans **WP Admin → WooCommerce → Réglages → Général**. La caisse suit le réglage de votre boutique.

Deux coupons de 10% sur une commande de $100.00 :

- **Désactivé** (réglage par défaut de WooCommerce) : chaque coupon déduit 10% de $100.00, soit $10.00 chacun. Le client paie **$80.00**.
- **Activé** : le premier coupon déduit $10.00. Le deuxième déduit 10% des $90.00 restants, soit $9.00. Le client paie **$81.00**.

Lorsque ce réglage est activé, l’ordre d’application des coupons peut modifier le total. Un coupon de remise fixe sur le panier, par exemple $5 de réduction sur la commande, déduit le même montant dans les deux cas.

  </AccordionItem>
</Accordion>

## Modifications de prix et coupons {#price-changes}

Un coupon se base sur le prix de la ligne. Si vous avez baissé le prix d’un article à la caisse, le coupon calcule sa réduction sur ce prix réduit, et non sur le prix initial.

<Accordion>
  <AccordionItem question="Coupons qui excluent les articles en promotion">

Un article dont vous avez baissé le prix est considéré comme étant en promotion. Un coupon réglé sur **Exclure les articles en promotion** l’ignore, et un coupon de remise fixe sur le panier avec **Exclure les articles en promotion** ne peut pas être utilisé tant que cet article est dans le panier. Consultez [Interaction entre les modifications de prix au PDV et les coupons](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons).

  </AccordionItem>
</Accordion>

## En cas de problème {#goes-wrong}

**Le coupon ne figure pas dans la liste.** <Anchor id="sync" />Cet appareil ne l’a pas encore récupéré. Pour le récupérer maintenant :

1. Ouvrez **État de la boutique** dans le menu, puis **Base de données**.
2. Sur la ligne des coupons, ouvrez **Plus d’actions** et choisissez **Rechercher les modifications maintenant**.
3. Ouvrez à nouveau **Ajouter une remise** et recherchez le coupon.

S’il n’apparaît toujours pas, choisissez **Effacer et retélécharger…** sur la même ligne. La caisse récupère à nouveau tous les coupons. Consultez [Effacer et retélécharger](../support/store-health.mdx#clear-and-redownload).

<Accordion>
  <AccordionItem question="Comment les coupons arrivent à la caisse">

La caisse récupère vos coupons la première fois que vous ouvrez la liste. Ensuite, elle recherche régulièrement les modifications dans votre boutique : toutes les 60 secondes avec le préréglage par défaut. Un coupon créé dans WP Admin apparaît généralement dans ce délai. Consultez [Préréglages de synchronisation](../support/store-health.mdx#sync-presets).

Avec WCPOS Pro, l’écran **Coupons** comporte un bouton de synchronisation au bas de la liste. Maintenez-le enfoncé pour accéder à **Effacer et actualiser**, qui récupère à nouveau tous les coupons.

  </AccordionItem>
</Accordion>

**Votre boutique a modifié les totaux de cette commande.** La boutique a calculé des totaux différents lorsqu’elle a reçu la commande. Ce sont les montants de la boutique qui font foi ; vérifiez le total avant de remettre les articles au client.

**Commande non enregistrée — la boutique l’a refusée.** La boutique n’a pas accepté la commande, et la vente est restée telle quelle dans le panier. Le message précise la raison donnée par la boutique, ou indique **La boutique n’a donné aucune raison**. Si la raison mentionne un coupon, retirez-le et appuyez à nouveau sur **Paiement**. Le bouton **État de la boutique** du message montre ce que la boutique a refusé ; consultez [Modifications qui ne sont jamais parvenues à votre serveur](../support/store-health.mdx#refused-changes).

## Configurations de coupons adaptées à la caisse {#common-setups}

Ces coupons se créent dans **WP Admin → Marketing → Codes promo**. Les noms des champs sont ceux de WooCommerce.

<Accordion>
  <AccordionItem question="Une remise du responsable dont vous pouvez suivre l’utilisation">

Créez un coupon nommé `mgr10` :
- **Type de remise :** Remise en pourcentage
- **Montant du code promo :** 10
- **Utilisation individuelle uniquement :** désactivé, pour pouvoir le cumuler avec un coupon du client
- **Description :** « Remise du responsable », pour que les caissiers le trouvent en recherchant *responsable*

Communiquez le code uniquement aux responsables. Contrairement à une baisse de prix à la caisse, cette remise entre dans le total **Remise** de WooCommerce et apparaît dans les rapports. Consultez [Remises du PDV et coupons WooCommerce](../pos/cart/discounts.mdx#pos-discounts-vs-woocommerce-coupons).

  </AccordionItem>

  <AccordionItem question="Une récompense pour un client fidèle">

Créez un coupon nommé `loyal5` :
- **Type de remise :** Remise panier fixe
- **Montant du code promo :** 5
- **Dépense minimale :** 25, ou le seuil de votre choix
- **Limite d’utilisation par utilisateur :** 1, si la récompense ne peut être utilisée qu’une fois
- **Description :** « Récompense fidélité »

À la caisse, recherchez *fidélité* pour le trouver sans connaître le code. Choisissez le client avant de l’appliquer, afin que la limite par utilisateur puisse être vérifiée pour ce client.

  </AccordionItem>

  <AccordionItem question="Un prospectus ou une promotion imprimée">

Créez un coupon par campagne. Réglez **Limite d’utilisation par code** sur 1 pour un bon à usage unique, ou sur une valeur supérieure pour un code partagé. Définissez une **Date d’expiration du code** afin qu’il ne puisse plus être utilisé après la campagne. Pour un code partagé utilisable une seule fois par client, réglez également **Limite d’utilisation par utilisateur** sur 1.

  </AccordionItem>

  <AccordionItem question="Un client présente un coupon et vous souhaitez ajouter une remise du responsable">

Appliquez d’abord le coupon du client, puis celui du responsable. Si le coupon du client est réglé sur **Utilisation individuelle uniquement**, la caisse refuse le deuxième. Choisissez celui dont le client bénéficiera, ou utilisez [Ajouter une remise](../pos/cart/discounts.mdx#order-level-discounts) pour le montant supplémentaire.

  </AccordionItem>
</Accordion>

:::info Avec WCPOS Pro
**Nouveau coupon** crée un coupon à la caisse et l’applique à la vente. L’écran **Coupons** répertorie chaque coupon avec son montant, son type, son utilisation et sa date d’expiration ; dans l’extension gratuite, cet écran s’affiche en aperçu.
:::
