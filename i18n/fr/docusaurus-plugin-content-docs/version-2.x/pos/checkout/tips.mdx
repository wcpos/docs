Le client ajoute un pourboire sur le lecteur de carte, pas sur la caisse. La caisse envoie le montant dû, le lecteur propose au client de laisser un pourboire et la caisse enregistre le montant encaissé par le lecteur. Il n’y a pas de bouton de pourboire sur la caisse.

## Encaisser un paiement par carte avec un pourboire {#take-a-tip}

:::info Fonctionnalité Pro
Les pourboires sur un lecteur de carte nécessitent [WCPOS Pro](../../getting-started/pro-license.mdx) et un lecteur qui les propose.
:::

Avant de commencer, vérifiez que [votre lecteur propose les pourboires](#which-readers). Si **Ouvrir et fermer la caisse** est activé, [ouvrez d’abord la caisse](../register/index.mdx#open) : elle n’enregistre aucun paiement tant qu’elle est fermée.

1. Appuyez sur **Paiement**, puis sur la tuile de votre lecteur. Consultez [Sur un lecteur de carte](./taking-a-payment.mdx#card-reader).
2. Appuyez sur **Envoyer … à …**. Le bouton indique le montant dû et le moyen de paiement, et la caisse envoie ce montant au lecteur.
3. Sur le lecteur, le client choisit un pourboire, ou aucun pourboire, puis paie.
4. Sur la caisse, la ligne du paiement dans le volet d’encaissement affiche le montant total encaissé par le lecteur, avec **Pourboire :** et le montant du pourboire en dessous.

Une ligne de frais nommée **Pourboire** est ajoutée à la commande : le total augmente donc du montant du pourboire, qui est déjà payé. Le reçu le présente avec les autres frais de la commande. Le pourboire n’est pas taxé.

<details>
<summary>Taxer les pourboires (pour les développeurs)</summary>

Une boutique qui doit taxer les pourboires peut activer cette option avec le filtre `wcpos_payment_tip_fee_taxable`. La taxe est alors déduite du pourboire : le client paie toujours le montant qu’il a choisi sur le lecteur.

</details>

## Quels lecteurs demandent un pourboire {#which-readers}

| Moyen de paiement | Demande un pourboire |
|---|---|
| [Stripe Terminal](../../payment/gateways/stripe-terminal.mdx) | Les WisePad 3, WisePOS E, S700 et S710, une fois les pourboires activés pour vos lecteurs dans le tableau de bord Stripe. Ni le M2 ni Tap to Pay. |
| [SumUp Terminal](../../payment/gateways/sumup-terminal.mdx) | Un lecteur Bluetooth associé à l’application WCPOS. Pas un lecteur connecté à Internet. |
| [Mollie Terminal](../../payment/gateways/mollie-terminal.mdx) | Tous les lecteurs. |

Ces moyens de paiement ne demandent pas de pourboire :

- [Square Terminal](../../payment/gateways/square-terminal.mdx)
- [PayArc Terminal](../../payment/gateways/payarc-terminal.mdx)
- [Windcave Terminal](../../payment/gateways/windcave-terminal.mdx)
- [Mercado Pago Terminal](../../payment/gateways/mercadopago-terminal.mdx)
- [PayPal Reader (Zettle)](../../payment/gateways/paypal-reader.mdx)

La tuile **Carte** enregistre un paiement par carte encaissé sur votre propre terminal. Elle ne prévoit pas de pourboire. Consultez [Moyens de paiement](./payment-methods.mdx).

## Verser les pourboires depuis le tiroir-caisse {#pay-out-tips}

Lorsque vous remettez les pourboires au personnel en espèces, enregistrez une sortie d’espèces pour que le solde du tiroir-caisse reste juste. Cette fonction est aussi disponible dans l’extension gratuite. Elle nécessite **Ouvrir et fermer la caisse** ; consultez [Entrées et sorties d’espèces](../register/index.mdx#cash-movements).

1. Appuyez sur votre avatar à l’extrémité de la barre de caisse, puis sur **Dans le tiroir-caisse**, puis sur **Sortie d’espèces**.
2. Saisissez sur le pavé numérique le montant que vous remettez.
3. Appuyez sur **Pourboires** sous **Motif**. Cela renseigne le motif, pas le montant.
4. Appuyez sur **Retirer …**.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[180, 0], [370, 0], [-4, 0], [0, 0], [0, 0], [100, 0], [-14, -36]]} alt="Le panneau Sortie d’espèces : deux dollars saisis sur le pavé numérique, le solde du tiroir-caisse avant et après, le motif Pourboires sélectionné et renseigné, et le bouton Retirer $2.00">

1. **Montant** — la somme que vous retirez. Ce champ se remplit au fil de votre saisie.
2. **Dans le tiroir-caisse** — la caisse, le montant d’espèces attendu actuellement et ce qui reste après cette sortie.
3. **Pavé numérique** — permet de saisir le montant. Vous pouvez aussi utiliser un clavier.
4. **Pourboires** — le motif. Appuyez dessus pour remplir le champ du motif, puis à nouveau pour le vider.
5. **Autre…** — vide le champ et y place le curseur pour vous permettre de saisir votre propre motif.
6. **Motif** — obligatoire pour chaque sortie d’espèces. Sans motif, le panneau affiche **Ajouter un motif**.
7. **Retirer $2.00** — indique le montant. Appuyez dessus pour enregistrer la sortie d’espèces. **Annuler** laisse le tiroir-caisse inchangé.

</JourneyShot>

Pour vérifier la sortie, appuyez sur **Dans le tiroir-caisse** pour ouvrir le panneau de caisse, puis sur la ligne **Montant attendu dans le tiroir-caisse** pour en afficher le détail. La sortie y figure sous **Sortie d’espèces**, avec son motif. Appuyez sur **Invalider** si elle a été enregistrée par erreur. L’invalidation n’est possible que lorsque la caisse est ouverte, en dehors d’un comptage, et une sortie invalidée ne peut pas être rétablie : saisissez-la à nouveau. Consultez [En cas de problème](../register/index.mdx#goes-wrong).

## En cas de problème {#goes-wrong}

**Le lecteur n’a pas proposé de pourboire.** Consultez le [tableau](#which-readers) : certains moyens de paiement et lecteurs ne le proposent jamais. Pour Stripe, activez les pourboires pour le lecteur dans le tableau de bord Stripe.

**Échec du paiement : le terminal a confirmé un montant différent.** Le lecteur a encaissé un montant supérieur à celui envoyé par la caisse, avec un moyen de paiement qui n’accepte pas les pourboires. La caisse a donc marqué le paiement comme échoué et ne l’a pas comptabilisé dans la commande.

:::warning
Vérifiez le paiement auprès de votre prestataire avant de faire payer à nouveau le client, sinon vous risquez de le débiter deux fois.
:::

Si le prestataire affiche le débit, effectuez le remboursement chez lui : la caisse ne peut pas rembourser un paiement échoué. Le montant reste dû sur la commande ; encaissez-le à nouveau avec un moyen de paiement qui fonctionne.
