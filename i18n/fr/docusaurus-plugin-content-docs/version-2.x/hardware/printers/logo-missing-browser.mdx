**Ce que vous constatez :** vous effectuez vos ventes dans un navigateur web et l’imprimante de reçus imprime tout le reçu sauf le logo de la boutique. L’**Aperçu** sur l’écran de confirmation du paiement affiche le logo. Le même reçu imprimé depuis l’application de bureau ou mobile le contient.

**Le plus rapide : imprimez depuis l’application de bureau.** Elle imprime le logo sans configuration particulière. Utilisez-la si elle est déjà installée sur la caisse. Pour continuer à imprimer depuis le navigateur, lisez la suite.

## Vérifier d’abord l’imprimante {#test-print}

Assurez-vous que l’imprimante peut bien imprimer une image. Accédez à **Paramètres → Impression** et appuyez sur **Impression test** sur la ligne de votre imprimante de reçus, et non sur la ligne intégrée **Boîte de dialogue d’impression** : la page de test de cette dernière ne contient pas d’image. Chaque ligne comporte **Impression test** et **Autres actions** au même endroit, illustré ici sur la ligne **Boîte de dialogue d’impression** ; une imprimante que vous avez ajoutée vous-même comporte aussi **Modifier** entre les deux.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[6, -28], [30, 0]]} maxWidth={712} alt="La liste des imprimantes dans Paramètres, Impression : la ligne intégrée Boîte de dialogue d’impression avec son bouton Impression test et le bouton Autres actions">

1. **Impression test** — sur une imprimante de reçus, imprime la page de test. La section **2 LOGO (RASTER)** de cette page contient le logo WCPOS.
2. **Autres actions** — donne accès à **Copier le rapport de configuration**, pour l’[assistance](#still-missing).

</JourneyShot>

- **Le logo WCPOS s’imprime, mais pas le vôtre.** L’imprimante peut imprimer des images. Ensuite, [vérifiez l’adresse de votre logo](#fix).
- **Le reste de la page de test s’imprime, mais pas le logo.** Commencez par les [questions de l’assistant de configuration](./setup-wizard.mdx#troubleshoot) avant de modifier l’adresse de votre logo.

## Vérifier l’adresse du logo {#fix}

1. Faites un clic droit (ou un appui prolongé) sur le logo dans l’**Aperçu** du reçu, puis choisissez **Ouvrir l’image dans un nouvel onglet**.
2. Comparez le nom du site dans l’adresse de cet onglet, la partie située entre `https://` et le `/` suivant, avec celui de la barre d’adresse du PDV. Par exemple :
   - Site du PDV : `shop.example.com`
   - Site du logo : `cdn.example.net`

   Ils sont différents.
3. S’ils diffèrent, c’est probablement la cause du problème : demandez à la personne qui gère votre site web d’effectuer l’une des modifications ci-dessous.
4. Après la modification, rechargez le PDV et imprimez à nouveau le reçu. Si les noms de site sont identiques, ou si le logo est toujours absent, consultez [Toujours absent ?](#still-missing)

<details>
<summary>Solutions pour la personne qui gère votre site web</summary>

Choisissez l’une de ces solutions :

- **Utilisez un logo provenant de votre propre site.** Téléversez le logo dans la médiathèque à l’adresse de la boutique et sélectionnez ce fichier comme logo du reçu.
- **Autorisez l’accès par un en-tête sur le serveur qui héberge le logo.** Si vos fichiers téléversés doivent rester sur un CDN, ajoutez `Access-Control-Allow-Origin` pour l’adresse de votre boutique sur ses fichiers image.

</details>

## Pourquoi cela se produit {#why-it-happens}

Lorsque le PDV envoie une image directement à une imprimante de reçus depuis un navigateur, le site web qui héberge l’image doit l’y autoriser. Les applications de bureau et mobiles récupèrent elles-mêmes le logo, qui s’imprime donc avec elles. Les reçus imprimés via la **Boîte de dialogue d’impression** l’affichent aussi.

<details>
<summary>Les détails, pour la personne qui gère votre site web</summary>

Dans un navigateur, le PDV convertit le logo en points avant d’envoyer le reçu à l’imprimante. Un navigateur ne l’autorise que pour une image provenant de la même adresse que la page du PDV, par exemple de la médiathèque de votre boutique. Une image provenant d’une autre adresse nécessite l’autorisation de ce serveur, sous la forme d’un en-tête nommé `Access-Control-Allow-Origin`. Sans cet en-tête, le navigateur ne transmet rien au PDV et le reçu s’imprime sans logo, plutôt que de ne pas s’imprimer du tout.

Le logo provient d’une autre adresse lorsque :

- un CDN d’images ou une extension de déport des médias diffuse vos fichiers téléversés depuis son propre domaine
- l’adresse du logo et celle du PDV ne diffèrent que par `www.`

</details>

## Toujours absent ? {#still-missing}

Juste après l’impression d’un reçu sans logo, accédez à **Paramètres → Impression**, ouvrez **Autres actions** sur la ligne de l’imprimante et appuyez sur **Copier le rapport de configuration**.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[28, 0]]} maxWidth={285} alt="Le menu Autres actions ouvert sur une ligne d’imprimante, avec Copier le rapport de configuration">

1. **Autres actions**
2. **Copier le rapport de configuration**

</JourneyShot>

Le rapport contient uniquement les événements récents de l’imprimante enregistrés par l’application durant cette session. Copiez-le donc avant de recharger le PDV. Collez-le dans votre message avec l’adresse du logo.
