Si le PDV ouvert dans un onglet du navigateur ne parvient pas à accéder à votre imprimante Epson ou Star, alors qu’elle est allumée et sur le même réseau, commencez par [Résoudre le problème dans cet ordre](#fix-in-order). L’application de bureau n’a pas besoin de ces corrections.

## Ce que vous verrez {#symptom}

Dans **Paramètres → Impression → Ajouter une imprimante**, la recherche ne trouve rien (**Aucune imprimante trouvée**), ou vous saisissez l’adresse de l’imprimante et sa fiche affiche **Aucune connexion**, alors qu’elle est allumée et sur le même réseau. Il se peut aussi que la même imprimante imprime depuis l’application de bureau, mais pas depuis l’onglet du navigateur.

Après l’échec d’une page de test, l’application peut afficher **L’application n’a pas été autorisée à accéder à l’imprimante. Autorisez-la dans les paramètres système, puis réessayez.** Dans un navigateur, cela signifie que celui-ci n’a pas pu accéder à l’imprimante. Vérifiez que l’imprimante est allumée et que son adresse est correcte, puis suivez les solutions ci-dessous. Les deux écrans sont [annotés plus bas](#on-screen).

## Résoudre le problème dans cet ordre {#fix-in-order}

Dans Safari ou Firefox, commencez par [les possibilités offertes par ces navigateurs](#safari-and-firefox). Dans Chrome ou Edge :

1. [Autorisez l’accès au réseau local](#allow-local-network-access), puis vérifiez à nouveau.
2. Si le problème persiste, trouvez le **Port** de l’imprimante : dans **Modifier l’imprimante** pour une imprimante enregistrée, ou sous **Saisir une adresse IP** lors de l’ajout. Le port vous indique si le PDV utilise HTTPS ou HTTP non chiffré :

   | Imprimante | Port HTTPS | Port HTTP |
   |---|---|---|
   | Epson | **8043** ou **443** | **8008** ou **80** |
   | Star | **443** | **80** |

   Suivez ensuite la procédure correspondante :

   - **Port HTTPS :** [acceptez le certificat de l’imprimante](#the-printers-certificate), puis vérifiez à nouveau.
   - **Port HTTP :** consultez [Lorsque l’imprimante utilise HTTP](#mixed-content).

3. Toujours **Aucune connexion**, ou le test échoue encore ? Consultez [Le problème persiste ?](#still-stuck)

### Vérifier à nouveau {#check-again}

- **Ajout d’une imprimante :** appuyez sur **Saisir une adresse IP**, puis sur **Vérifier cette adresse**. Lorsque la fiche affiche **Prête**, le navigateur peut accéder à l’imprimante : passez à [Imprimer une page de test](./setup-wizard.mdx#test-page).
- **Imprimante déjà enregistrée :** dans **Paramètres → Impression**, appuyez sur **Impression de test** sur sa ligne, ou dans **Modifier l’imprimante**.

Le problème persiste après avoir autorisé l’accès au réseau local ? [Trouvez le port](#fix-in-order) (étape 2). Il persiste après la procédure correspondant à votre port ? Consultez [Le problème persiste ?](#still-stuck)

La section [HTTPS ou HTTP](#https-or-http) contient des captures d’écran montrant où lire le port.

## Autoriser l’accès au réseau local {#allow-local-network-access}

Chrome et Edge demandent votre autorisation avant de laisser un site web accéder à un appareil de votre réseau local. La fenêtre vous demande d’**Accéder à d’autres appareils sur votre réseau local**. Autorisez cet accès.

Si quelqu’un a choisi **Ne jamais autoriser** ou a fermé la fenêtre :

1. Cliquez sur l’icône à gauche de la barre d’adresse, puis sur **Paramètres du site**.
2. Réglez **Réseau local** sur **Autoriser**.
3. Rechargez le PDV et [vérifiez à nouveau](#check-again).

## Le certificat de l’imprimante {#the-printers-certificate}

En HTTPS, l’imprimante présente son propre certificat. Si ce navigateur ne lui fait pas confiance, la connexion échoue avant tout envoi. Ces étapes permettent au navigateur de se connecter.

1. Assurez-vous que l’imprimante possède un certificat. Si sa feuille d’état n’en indique aucun, créez un certificat autosigné dans l’interface de configuration web de l’imprimante. Sur une Epson, connectez-vous comme décrit dans [Impression sécurisée Epson](./secure-printing.mdx#turn-it-off).
2. Dans le même navigateur, ouvrez l’adresse de l’imprimante en HTTPS, en utilisant l’adresse IP de votre imprimante :
   - **Epson :** essayez d’abord `https://192.168.1.200:8043`. Si cette adresse ne s’ouvre pas, essayez `https://192.168.1.200`, qui utilise le port 443.
   - **Star :** `https://192.168.1.200`, qui utilise le port 443.
3. Acceptez l’avertissement relatif au certificat. Ouvrez les étapes correspondant à votre navigateur :

   <details>
   <summary>Chrome</summary>

   Sur l’écran **Votre connexion n’est pas privée**, appuyez sur **Paramètres avancés**, puis sur **Continuer vers le site 192.168.1.200 (dangereux)**.

   </details>

   <details>
   <summary>Edge</summary>

   Appuyez sur **Avancé**, puis sur **Continuer vers 192.168.1.200 (non sécurisé)**.

   </details>

   <details>
   <summary>Safari</summary>

   Sur l’écran **Cette connexion n’est pas privée**, appuyez sur **Afficher les détails**, puis sur le lien **visiter ce site web**, puis sur **Visiter le site web**.

   </details>

   <details>
   <summary>Firefox</summary>

   Utilisez l’option proposée dans l’avertissement pour poursuivre vers le site.

   </details>

4. Revenez au PDV et [vérifiez à nouveau](#check-again).

Effectuez cette opération dans chaque navigateur de chaque ordinateur utilisé pour imprimer.

L’application de bureau accepte elle-même le certificat de l’imprimante. C’est pourquoi la même imprimante peut y fonctionner, mais pas dans l’onglet du navigateur.

## Lorsque l’imprimante utilise HTTP {#mixed-content}

Si l’adresse de votre boutique commence par `https://` et que l’imprimante ne propose que HTTP non chiffré, imprimez depuis Chrome ou Edge 142 ou une version ultérieure et [autorisez l’accès au réseau local](#allow-local-network-access).

Les autres navigateurs bloquent cette connexion : une page sécurisée ne peut pas envoyer de données à une adresse non sécurisée, ce que les navigateurs appellent du contenu mixte. Si vous ne pouvez pas utiliser Chrome ou Edge, passez l’imprimante en HTTPS avec un [certificat](#the-printers-certificate), ou utilisez l’application de bureau.

## Safari et Firefox {#safari-and-firefox}

- **En Wi-Fi :** l’imprimante doit utiliser le même protocole que la boutique. Depuis une boutique en `https://`, seul HTTPS fonctionne, après avoir [accepté le certificat](#the-printers-certificate) ; HTTP non chiffré est bloqué. Depuis une boutique en `http://`, HTTP non chiffré fonctionne.
- **USB et Bluetooth :** **Rechercher une imprimante USB** et **Rechercher une imprimante Bluetooth** apparaissent uniquement dans les navigateurs capables d’accéder à ces périphériques, Chrome et Edge.

Pour les autres cas, utilisez Chrome ou Edge, ou l’application de bureau.

## Où le PDV affiche ces informations {#on-screen}

## HTTPS ou HTTP {#https-or-http}

Le navigateur accède au serveur web de l’imprimante sur l’un des ports du [tableau ci-dessus](#fix-in-order). Le port détermine si la connexion utilise HTTPS ou HTTP non chiffré.

- **HTTPS** nécessite un certificat sur l’imprimante auquel ce navigateur fait confiance. Consultez [Le certificat de l’imprimante](#the-printers-certificate).
- **HTTP** depuis une boutique en HTTPS nécessite Chrome ou Edge 142 ou une version ultérieure et l’[autorisation d’accès au réseau local](#allow-local-network-access). Consultez [Lorsque l’imprimante utilise HTTP](#mixed-content).

Pour une imprimante enregistrée, **Modifier l’imprimante** indique le protocole utilisé sous **Point de terminaison d’impression web** :

<JourneyShot manifest={manifest} device="tablet" step={13} offsets={[[290, 0], [0, 30], [572, -2], [700, 0]]} alt="Modifier l’imprimante pour une Epson à l’adresse 192.168.1.128 sur le port 8008, Détecté : Epson, et le point de terminaison d’impression web http://192.168.1.128:8008/cgi-bin/epos/service.cgi, Utilisation d’Epson ePOS via HTTP. Chrome ou Edge peut demander l’autorisation d’accéder à votre réseau local">

1. **Adresse IP** — l’adresse de l’imprimante.
2. **Port** — ici 8008, le port HTTP non chiffré d’Epson. Sur une boutique en HTTPS, une nouvelle Epson utilise initialement **8043**, qui correspond à HTTPS.
3. **Point de terminaison d’impression web** — l’adresse à laquelle le navigateur envoie le reçu. Elle commence par `http://` pour HTTP non chiffré et par `https://` pour HTTPS.
4. **La ligne sous le point de terminaison** — indique en toutes lettres le fabricant et HTTPS ou HTTP. En HTTP, elle précise que Chrome ou Edge peut demander l’[autorisation d’accès au réseau local](#allow-local-network-access) ; en HTTPS, que l’imprimante a besoin d’un certificat auquel ce navigateur fait confiance ([le certificat de l’imprimante](#the-printers-certificate)).

## Le problème persiste ? {#still-stuck}

Utilisez **Copier le rapport de configuration** et collez-le dans votre message. Cette option se trouve sur l’écran **Rien ne s’est imprimé** après l’échec d’une page de test, ainsi que dans le menu d’une imprimante enregistrée. Le rapport consigne l’adresse, le port et les opérations tentées. Sur l’écran **Rien ne s’est imprimé**, **Détails pour l’assistance** indique également le navigateur utilisé.
