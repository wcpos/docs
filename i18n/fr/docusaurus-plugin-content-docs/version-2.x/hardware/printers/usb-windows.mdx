Pour utiliser une imprimante de reçus USB avec l’application de bureau sous Windows, installez-la d’abord dans Windows : l’application ne la détecte qu’une fois qu’elle y est installée. Ajoutez-la ensuite au PDV :

1. [Installer l’imprimante dans Windows](#do-this).
2. [L’ajouter au PDV](#add-in-pos).

Cette page vous concerne aussi si, dans l’application de bureau sous Windows :

- **Ajouter une imprimante** affiche **Aucune imprimante trouvée**, alors que l’imprimante est branchée et allumée. Consultez [Aucune imprimante trouvée](#no-printer-found).
- Une imprimante ajoutée dans une version antérieure affiche **Sous Windows, ajoutez plutôt cette imprimante en tant qu’imprimante installée.** Consultez [Une imprimante d’une version antérieure](#earlier-version).
- La page de test contient des [lettres et symboles incohérents](#stray-symbols), ou [rien n’est sorti](#nothing-came-out).

## Installer l’imprimante dans Windows {#do-this}

Vérifiez d’abord si elle est déjà installée dans Windows :

1. Branchez l’imprimante et allumez-la. Si le fabricant fournit un pilote ou un programme d’installation pour Windows, exécutez-le maintenant.
2. Dans Windows, ouvrez **Paramètres → Bluetooth et appareils → Imprimantes et scanners**.
3. Si votre imprimante figure dans la liste, passez à [L’ajouter au PDV](#add-in-pos). Sinon, à côté d’**Ajouter une imprimante ou un scanner**, choisissez **Ajouter un appareil**. Si Windows trouve l’imprimante et l’ajoute, passez également à [L’ajouter au PDV](#add-in-pos).

Si Windows ne la répertorie toujours pas, ajoutez-la manuellement avec **Generic / Text Only**, le pilote de base fourni avec Windows.

<details>
<summary>Ajouter l’imprimante manuellement</summary>

1. Choisissez **Ajouter manuellement**, puis **Ajouter une imprimante locale ou réseau avec des paramètres manuels**.
2. Sous **Utiliser un port existant**, choisissez le port USB de l’imprimante : son nom commence par **USB**, par exemple USB001.
3. Pour le pilote, choisissez le fabricant **Generic** et l’imprimante **Generic / Text Only**.
4. Donnez-lui un nom que vous reconnaîtrez à la caisse, par exemple *Imprimante de reçus*, puis terminez.

</details>

<details>
<summary>Sous Windows 10</summary>

Ouvrez **Paramètres → Périphériques → Imprimantes et scanners** et choisissez **Ajouter une imprimante ou un scanner**. Là où Windows 11 affiche **Ajouter manuellement**, Windows 10 affiche **Je ne trouve pas l’imprimante recherchée dans la liste**.

</details>

## L’ajouter au PDV {#add-in-pos}

1. Dans l’application de bureau, accédez à **Paramètres → Impression** et appuyez sur **Ajouter une imprimante**. La recherche démarre automatiquement et recherche les imprimantes **USB, Bluetooth et Wi-Fi**.
2. Sélectionnez la fiche portant le nom que vous avez donné à l’imprimante dans Windows. Elle porte la mention **Imprimante installée**. Si plusieurs imprimantes sont présentes, le panneau demande **Quelle est votre imprimante ?** et n’en sélectionne aucune à votre place.
3. Appuyez sur **Imprimer une page de test**. Le panneau demande **La page de test s’est-elle imprimée ?**
4. Si la page est correcte, répondez **Oui, et elle est correcte**. L’imprimante est enregistrée : le panneau affiche *nom* **est configurée**. Appuyez sur **Terminé** ; l’imprimante possède désormais sa propre ligne dans **Paramètres → Impression**.

Si la page est incorrecte ou ne s’est pas imprimée, consultez [En cas de problème](#goes-wrong). Les autres réponses sont décrites dans [Imprimer une page de test](./setup-wizard.mdx#test-page).

## En cas de problème {#goes-wrong}

### Aucune imprimante trouvée {#no-printer-found}

Vérifiez d’abord **Imprimantes et scanners** dans Windows. Si votre imprimante ne figure pas dans la liste, [installez-la dans Windows](#do-this), puis appuyez sur **Relancer la recherche**. Si elle y figure et que l’application ne trouve toujours rien, consultez [Toujours bloqué ?](#still-stuck).

<details>
<summary>Les autres boutons du panneau Aucune imprimante trouvée</summary>

1. **Relancer la recherche** — effectue une nouvelle recherche. Appuyez dessus après avoir installé l’imprimante dans Windows.
2. **Rechercher une imprimante Bluetooth** — pour une imprimante Bluetooth qui ne nécessite pas d’appairage.
3. **Saisir une adresse IP** — pour une imprimante réseau que la recherche n’a pas trouvée.
4. **Plus d’options** — nom, largeur du papier et tiroir, avant la page de test. Consultez [Plus d’options](./setup-wizard.mdx#more-options).
5. **Ouvrir le guide des imprimantes** — le [guide des imprimantes](./index.mdx).

</details>

### Une imprimante d’une version antérieure {#earlier-version}

L’impression affiche **Sous Windows, ajoutez plutôt cette imprimante en tant qu’imprimante installée.** Une version antérieure l’a enregistrée comme imprimante USB directe. Désormais, sous Windows, l’application n’accède à une imprimante USB que par son entrée dans Windows. Dans **Paramètres → Impression**, ouvrez le menu **Plus d’actions** de l’imprimante, choisissez **Supprimer**, puis ajoutez-la à nouveau avec **Ajouter une imprimante** et sélectionnez sa fiche **Imprimante installée**.

### Lettres et symboles incohérents {#stray-symbols}

#### Lors de l’ajout d’une imprimante {#symbols-during-setup}

1. Répondez **Rien n’est sorti**, même si du papier a été imprimé. Le panneau ne propose pas de réponse pour les symboles, et celle-ci donne accès à **Recommencer** et **Enregistrer sans tester**.
2. Vérifiez le nom sur la fiche sélectionnée :
   - Une autre imprimante, par exemple une imprimante de bureau ? Elle ne peut pas interpréter les commandes de reçus. Appuyez sur **Recommencer** et sélectionnez l’entrée de votre imprimante de reçus.
   - Votre imprimante de reçus ? Appuyez sur **Enregistrer sans tester**, puis [corrigez son langage](#symbols-saved).

#### Une imprimante déjà enregistrée {#symbols-saved}

1. Vérifiez le nom sur sa ligne dans **Paramètres → Impression**. S’il s’agit d’une autre imprimante, appuyez sur **Ajouter une imprimante** et sélectionnez l’entrée de votre imprimante de reçus.
2. S’il s’agit de votre imprimante de reçus, le réglage **Langage de l’imprimante** ne correspond peut-être pas à l’imprimante. Appuyez sur **Modifier** sur sa ligne.
3. Réglez **Langage de l’imprimante** sur celui indiqué dans le manuel de votre imprimante. Les imprimantes Star utilisent **StarPRNT** ou **Star Line Mode** ; les imprimantes Epson utilisent **ESC/POS**, comme la plupart des autres marques.
4. Appuyez sur **Impression de test** sur la ligne. Si une imprimante Star imprime toujours des symboles, sélectionnez l’autre langage Star et refaites un test.
5. Des symboles avec tous les langages ? Vérifiez votre modèle dans [Imprimantes de reçus compatibles](./supported-printers.mdx), puis consultez [Toujours bloqué ?](#still-stuck).

### Rien n’est sorti {#nothing-came-out}

#### Lors de l’ajout d’une imprimante {#nothing-during-setup}

1. Répondez **Rien n’est sorti**.
2. Vérifiez le nom sur la fiche sélectionnée. S’il s’agit d’une autre imprimante, appuyez sur **Recommencer** et sélectionnez l’entrée de votre imprimante de reçus.
3. S’il s’agit de la vôtre, le panneau affiche **Vérifiez le câble et assurez-vous que l’imprimante est allumée, puis réessayez.** Faites-le, puis appuyez sur **Réessayer**.

#### Une imprimante déjà enregistrée {#nothing-saved}

1. Vérifiez le nom sur sa ligne dans **Paramètres → Impression**. S’il s’agit d’une autre imprimante, appuyez sur **Ajouter une imprimante** et sélectionnez l’entrée de votre imprimante de reçus.
2. S’il s’agit de la vôtre, vérifiez le câble et assurez-vous que l’imprimante est allumée, puis appuyez sur **Impression de test** sur sa ligne.

#### Toujours rien {#windows-test-page}

Imprimez une page de test depuis Windows lui-même, à partir de l’entrée de votre imprimante dans **Imprimantes et scanners**. Si Windows ne peut pas non plus imprimer, le problème se situe entre Windows et l’imprimante : le câble, le port ou le pilote. Si Windows imprime mais que le PDV n’imprime toujours pas, consultez [Toujours bloqué ?](#still-stuck).

### Rechercher une imprimante USB échoue dans l’application web {#web-app}

Dans l’application web, **Rechercher une imprimante USB** ne parvient souvent pas à accéder à une imprimante USB sous Windows. Utilisez plutôt l’application de bureau : [installez l’imprimante dans Windows](#do-this), puis [ajoutez-la au PDV](#add-in-pos).

## Comment l’application imprime sous Windows {#why-it-happens}

L’application de bureau imprime sur l’imprimante que vous avez installée dans Windows : sélectionnez donc celle-ci. Pour savoir si votre modèle interprète les commandes de reçus, consultez [Imprimantes de reçus compatibles](./supported-printers.mdx).

<details>
<summary>Pourquoi l’imprimante doit être installée dans Windows</summary>

Windows associe son propre pilote, ou celui du fabricant, à une imprimante USB. L’application de bureau imprime via l’entrée de l’imprimante dans Windows plutôt que directement par le câble. Elle envoie chaque reçu sous forme de commandes d’imprimante, que Windows transmet sans modification : le pilote ne modifie donc pas la mise en forme du reçu.

</details>

<details>
<summary>Quelles imprimantes Windows la recherche répertorie</summary>

Toutes les imprimantes installées dans Windows, à l’exception des entrées propres à Windows comme **Microsoft Print to PDF** et **Fax**. Une imprimante de bureau installée dans Windows figure aussi dans la liste et se présente comme les autres : choisissez donc d’après le nom. Une imprimante Bluetooth appairée dans Windows apparaît de la même manière, en tant qu’imprimante installée.

</details>

## Toujours bloqué ? {#still-stuck}

Appuyez sur **Copier le rapport de configuration** dans le panneau **Rien n’a été imprimé**, ou dans le menu **Plus d’actions** de l’imprimante dans **Paramètres → Impression**. Collez-le dans votre message : il indique l’entrée Windows vers laquelle l’application a envoyé l’impression.
