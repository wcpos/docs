**Symptôme :** sur un téléphone ou une tablette Android, **Ajouter une imprimante** affiche **Aucune imprimante trouvée**, ou votre imprimante Bluetooth n’apparaît pas dans les résultats.

Si WCPOS n’est pas autorisé à utiliser le Bluetooth, il ne peut pas trouver les imprimantes Bluetooth. Vérifiez ce point en premier.

Une imprimante Wi-Fi ne nécessite aucune autorisation, quelle que soit la version d’Android : passez directement à [Imprimantes Wi-Fi](#wi-fi-printers). {/* pending: monorepo#3366 */}

## Autoriser WCPOS à accéder à votre imprimante {#allow-nearby-devices}

1. Pour une imprimante Bluetooth, vérifiez que le Bluetooth est activé dans les paramètres rapides d’Android.
2. Vérifiez votre version d’Android : ouvrez **Paramètres → À propos du téléphone → Version d’Android** dans Android.
3. Ouvrez **Paramètres → Applications → WCPOS → Autorisations** dans Android.
4. Accordez l’autorisation correspondant à votre version :
   - **Android 11 et versions antérieures :** l’autorisation Appareils à proximité n’existe pas. Appuyez sur **Position** et autorisez l’accès. Ces versions ont besoin de l’accès à la position pour trouver les imprimantes Bluetooth.
   - **Android 12 et versions ultérieures :** appuyez sur **Appareils à proximité** et choisissez **Autoriser**. Cela permet à WCPOS de trouver les imprimantes Bluetooth et de s’y connecter.
5. Revenez dans WCPOS et appuyez sur **Relancer la recherche** sur l’écran **Ajouter une imprimante**.

Lorsque votre imprimante apparaît, appuyez sur **Imprimer une page de test** sous sa fiche. Si la page s’imprime et que la règle qui la traverse semble correcte, répondez **Oui, et le résultat est correct** : l’imprimante est enregistrée et le problème est résolu. La procédure complète se trouve dans [Ajouter une imprimante](./index.mdx#adding-a-printer).

Les noms des menus dans les paramètres d’Android varient légèrement selon le fabricant du téléphone, mais tous les téléphones Android disposent d’une page **Autorisations** pour chaque application.

## Imprimantes Bluetooth {#bluetooth-printers}

Une fois l’autorisation accordée, WCPOS recherche les imprimantes Bluetooth. La détection de la vôtre dépend aussi du type de Bluetooth qu’elle utilise :

- Les **imprimantes Bluetooth Low Energy** apparaissent automatiquement dans les résultats de recherche. Elles n’ont pas besoin d’être associées dans Android.
- Les **imprimantes Bluetooth Classic**, dont font partie de nombreuses imprimantes 58 mm bon marché, n’apparaissent qu’après avoir été associées dans Android. Sur l’écran **Aucune imprimante trouvée**, appuyez sur **Ouvrir les paramètres Bluetooth**, associez-y l’imprimante, puis revenez et appuyez sur **Relancer la recherche**.

Vous ne savez pas de quel type d’imprimante vous disposez, ou l’association échoue ? [Associer une imprimante de reçus Bluetooth](./bluetooth-pairing.mdx#classic-or-low-energy) explique comment le déterminer et comment mettre l’imprimante en mode association.

## Imprimantes Wi-Fi {#wi-fi-printers}

Vérifiez que le téléphone ou la tablette utilise le Wi-Fi de la boutique, sur le même réseau que l’imprimante, et non les données mobiles ou un réseau invité.

Si la recherche ne donne toujours aucun résultat mais que vous connaissez l’adresse de l’imprimante, appuyez sur **Saisir une adresse IP**. Cela permet d’ignorer la recherche et de vérifier directement cette adresse. L’adresse figure sur la feuille d’état de l’imprimante. Consultez [Trouver l’adresse réseau de votre imprimante](./network-address.mdx).

## En cas de problème {#goes-wrong}

### Échec de la détection {#discovery-failed}

Une ligne rouge sous **Aucune imprimante trouvée** indique que la détection des imprimantes a échoué, par exemple « Le Bluetooth est désactivé ou n’est pas autorisé pour cette application. » Le Bluetooth est désactivé sur le téléphone, ou WCPOS n’est pas autorisé à l’utiliser. Activez le Bluetooth et [accordez l’autorisation correspondant à votre version d’Android](#allow-nearby-devices), puis appuyez sur **Relancer la recherche**.

### Impression non autorisée {#printing-not-allowed}

Après une impression de test, l’écran **Rien ne s’est imprimé** affiche « L’application n’a pas été autorisée à accéder à l’imprimante. Autorisez-la dans les paramètres système, puis réessayez. » Android a bloqué WCPOS lors de la tentative d’impression. [Accordez l’autorisation correspondant à votre version d’Android](#allow-nearby-devices), puis appuyez sur **Réessayer**.

### L’imprimante doit être associée {#printer-needs-pairing}

Après une impression de test, l’écran **Rien ne s’est imprimé** affiche « Associez l’imprimante dans les paramètres Bluetooth de ce téléphone, puis relancez la recherche. » L’imprimante utilise le Bluetooth Classic et n’est plus associée dans Android. Appuyez sur **Ouvrir les paramètres Bluetooth** sous le message, associez-la, puis appuyez sur **Recommencer** pour relancer la recherche.

### L’autorisation est accordée, mais l’imprimante reste introuvable {#still-missing}

L’autorisation Appareils à proximité (ou Position sur Android 11 et les versions antérieures) est accordée, mais l’imprimante reste introuvable. Éteignez puis rallumez l’imprimante, puis appuyez sur **Relancer la recherche**. Si elle reste introuvable :

- **Imprimante Bluetooth :** consultez [Associer une imprimante de reçus Bluetooth](./bluetooth-pairing.mdx) pour connaître les autres causes possibles.
- **Imprimante Wi-Fi :** vérifiez le réseau et essayez l’adresse de l’imprimante, comme indiqué dans [Imprimantes Wi-Fi](#wi-fi-printers).

### Le problème persiste {#still-stuck}

Si l’imprimante n’apparaît jamais, aucune impression de test ne peut faire l’objet d’un rapport : contactez-nous ci-dessous en indiquant votre version d’Android ainsi que la marque et le modèle de l’imprimante.

Si l’imprimante apparaît mais n’imprime pas, appuyez sur **Copier le rapport de configuration** sur l’écran **Rien ne s’est imprimé**. Cet écran s’ouvre automatiquement lorsqu’une impression de test échoue, ou lorsque vous répondez **Rien n’est sorti** après une impression de test. Sur Android, Copier le rapport de configuration ouvre le menu de partage : envoyez-nous le rapport par e-mail ou copiez-le dans votre message. Il indique la version de l’application, l’imprimante, les opérations tentées par l’application et les réponses de l’imprimante.
