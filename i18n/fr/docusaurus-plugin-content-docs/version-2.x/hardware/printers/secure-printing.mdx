Cette page vous concerne si une imprimante Epson n’imprime pas depuis l’application :

- **Pendant la configuration de l’imprimante :** vous imprimez la page de test dans [Ajouter une imprimante](./setup-wizard.mdx#test-page), répondez **Rien n’est sorti**, et le panneau affiche **Rien ne s’est imprimé** avec la ligne *« L’impression sécurisée est activée. Désactivez-la sur l’imprimante, puis réessayez. »* Passez directement à [La désactiver](#turn-it-off).
- **L’imprimante semble prête, mais rien ne s’imprime :** la tâche semble être envoyée, aucune erreur n’apparaît et rien ne sort. L’autotest lancé avec les boutons de l’imprimante s’imprime toujours.

L’impression sécurisée est un paramètre de l’imprimante, et non du PDV. Vous n’avez peut-être pas besoin de le modifier : consultez d’abord [Faut-il la désactiver ?](#do-you-need-to).

## Faut-il la désactiver ? {#do-you-need-to}

Dans la plupart des configurations, l’application imprime avec l’impression sécurisée activée. Si le panneau **Rien ne s’est imprimé** de l’application vous demande de la désactiver, [désactivez-la](#turn-it-off). Sinon, commencez en haut du tableau : la première ligne qui correspond à votre façon d’imprimer vous donne la réponse. Vous ne savez pas si **Imprimer les reçus sous forme d’image** est activé ? [Vérifiez d’abord l’interrupteur](#print-as-image).

| Votre mode d’impression | Avec l’impression sécurisée activée |
|---|---|
| Toute application, Epson en Wi-Fi ou par câble réseau, avec **Imprimer les reçus sous forme d’image** activé | L’impression est impossible. Désactivez l’impression sécurisée. |
| **Application de bureau** (WCPOS installé sur un ordinateur), imprimante Wi-Fi ou réseau | L’impression fonctionne. |
| **Application web** (le PDV ouvert dans Chrome, Edge, Safari ou un autre navigateur) | L’impression fonctionne en HTTPS une fois que ce navigateur fait confiance au certificat de l’imprimante. Consultez [Autorisations du navigateur](./browser-permissions.mdx#the-printers-certificate). En HTTP (port 8008 ou 80), elle est impossible : désactivez l’impression sécurisée. |
| **Applications mobiles** | L’impression fonctionne lorsque la fiche de l’imprimante dans **Ajouter une imprimante** indique **Wi-Fi · sécurisé**. Si elle indique **Wi-Fi**, désactivez l’impression sécurisée. |
| **USB** ou **Bluetooth** | Non concernés. |

### Vérifier Imprimer les reçus sous forme d’image {#print-as-image}

Cet interrupteur envoie le reçu dans un format que l’imprimante retient tant que l’impression sécurisée est activée. Il est désactivé, sauf si vous l’avez activé. Accédez à **Paramètres → Impression** et appuyez sur **Modifier** sur la ligne de l’imprimante :

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-46, 0]]} alt="Modifier l’imprimante ouvert par-dessus Paramètres, Impression, pour une Epson nommée Comptoir d’accueil sur le réseau : les paramètres réseau, puis Langage de l’imprimante, Largeur du papier, Langue des reçus et Découpe automatique du papier, avec Ouvrir le tiroir, Test d’impression et Fermer en bas">

1. **Découpe automatique du papier** — la dernière ligne visible. Faites défiler plus bas pour atteindre **Imprimer les reçus sous forme d’image**.

</JourneyShot>

À la fin du formulaire :

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} maxWidth={799} alt="Les paramètres de Modifier l’imprimante pour une imprimante Epson, avec Imprimer les reçus sous forme d’image comme dernier interrupteur, désactivé">

1. **Langage de l’imprimante** — conservez le réglage actuel. L’impression sécurisée ne change rien aux lignes 1 à 3.
2. **Largeur du papier** — le nombre de caractères par ligne.
3. **Langue des reçus** — l’alphabet utilisé pour les reçus en texte.
4. **Imprimer les reçus sous forme d’image** — l’interrupteur à vérifier. Il est désactivé ici, comme il l’est tant que vous ne l’activez pas. Sur une Epson connectée en Wi-Fi ou par câble réseau, son utilisation nécessite de désactiver l’impression sécurisée.

</JourneyShot>

Si l’interrupteur est désactivé, revenez au [tableau](#do-you-need-to) et ignorez sa première ligne.

<Accordion>
<AccordionItem question="Quand faut-il activer Imprimer les reçus sous forme d’image ?">

Cette option sert aux reçus dans une écriture que l’imprimante ne peut pas imprimer sous forme de texte, comme l’arabe, l’hébreu ou le thaï. Si vous en avez besoin sur une Epson connectée en Wi-Fi ou par câble réseau, désactivez l’impression sécurisée. Consultez [Reçus en écritures non latines](./non-latin-receipts.mdx#print-the-receipt-as-an-image).

</AccordionItem>

## La désactiver {#turn-it-off}

Vous avez besoin d’un ordinateur sur le même réseau que l’imprimante, ainsi que de son adresse IP et de son mot de passe administrateur, le **Mot de passe initial**. Sur une imprimante dont l’impression sécurisée est activée, ces deux informations figurent sur la feuille d’état que vous imprimez à l’étape 1.

1. Imprimez la feuille d’état : sur la plupart des modèles, ouvrez le capot du papier, maintenez **Avance papier** enfoncé pendant une seconde, puis refermez le capot. Si votre imprimante possède un bouton dédié à la feuille d’état, maintenez plutôt celui-ci enfoncé pendant trois secondes. Notez l’adresse IP et le **Mot de passe initial**.
2. Sur un ordinateur connecté au même réseau, ouvrez `https://` suivi de cette adresse dans un navigateur. Acceptez l’avertissement concernant le certificat.
3. Connectez-vous en tant qu’administrateur avec le **Mot de passe initial** figurant sur la feuille, ou avec le mot de passe que vous avez défini si vous l’avez modifié.
4. Accédez à **Impression → Impression sécurisée**.
5. Sélectionnez **Désactiver** et enregistrez.
6. Débranchez l’imprimante pendant dix secondes, puis rebranchez-la.
7. Imprimez une page de test depuis l’application. Dans **Ajouter une imprimante**, appuyez sur **Réessayer**. Pour une imprimante déjà enregistrée, appuyez sur **Test d’impression** sur sa ligne dans **Paramètres → Impression**.

<Accordion>
<AccordionItem question="Si la feuille d’état ne s’imprime pas ou si le mot de passe ne fonctionne pas">

- **Pas de feuille d’état :** le bouton à utiliser et la durée d’appui varient selon le modèle. Le manuel de votre imprimante les précise.
- **Aucun Mot de passe initial sur la feuille :** cherchez une étiquette sur l’imprimante. Sur certains modèles, le mot de passe est le numéro de série.
- **Le mot de passe a été modifié :** adressez-vous à la personne qui a configuré l’imprimante.

</AccordionItem>
</Accordion>

:::warning Vérifiez ce paramètre après une mise à jour du micrologiciel
Une mise à jour du micrologiciel peut réactiver l’impression sécurisée. Si l’impression s’arrête après une mise à jour, vérifiez si elle a été réactivée. Si c’est le cas, répétez ces étapes.
:::

## Pourquoi cela se produit {#why-it-happens}

Tant que l’impression sécurisée est activée, l’imprimante imprime uniquement ce que l’application envoie sous forme de texte par sa connexion sécurisée. Elle retient tout le reste, y compris les reçus envoyés sous forme d’image. Elle ne rejette pas ces tâches : elle les **retient** pendant environ quatre minutes, n’imprime rien d’autre pendant ce temps, puis les supprime. C’est pourquoi l’imprimante semble en bon état mais ne réagit plus. Consultez [Une impression, puis plus rien](./printed-once-then-stopped.mdx).

Si la feuille d’état indique **Mode de sécurité : RED**, l’impression sécurisée s’applique à cette imprimante.

<Accordion>
<AccordionItem question="Quelles imprimantes et connexions sont concernées ?">

Les imprimantes Epson de la série TM vendues dans l’UE, au Royaume-Uni et dans l’AELE depuis le **1 août 2025** sont livrées avec **Impression sécurisée** activée, conformément à la directive européenne sur les équipements radioélectriques. Utiliser l’imprimante uniquement en Ethernet n’y change rien. Les imprimantes vendues ailleurs ont normalement ce réglage désactivé, mais une imprimante provenant d’un stock destiné à l’UE ou au Royaume-Uni l’a activé.

Les modèles répertoriés par Epson sont les TM-H6000VI, TM-L100, TM-m30II-S, TM-m30II-SL, TM-m30III, TM-m30III-H, TM-m50, TM-m50II, TM-P20II, TM-P80II, TM-T20IV et TM-T88VII. Une TM-L100 ou une TM-T20IV équipée uniquement de ports USB ou série n’est pas concernée.

D’après le guide Epson de ces imprimantes :

| Connexion | Impression sécurisée **activée** | **désactivée** |
|---|---|---|
| Données brutes, port 9100 | Impression impossible | Impression possible |
| ePOS-Print sur HTTP, port 80 | Impression impossible | Impression possible |
| ePOS SDK, ports 8008 et 8009 | Impression impossible | Impression possible |
| ePOS-Print sur HTTPS, port 443 | Impression possible | Impression possible |
| ePOS SDK sur TLS, ports 8043 et 8143 | Impression possible | Impression possible |
| Données brutes sur TLS, port 9143 | Impression possible | Impression possible |
| Bluetooth | Impression possible | Impression possible |

L’application de bureau essaie d’abord d’imprimer sur une Epson en HTTPS, sur le port 443. L’application web imprime en HTTPS sur le port 8043, ou 443 si l’assistant de configuration y a trouvé l’imprimante. Les applications mobiles envoient les données brutes sur le port 9100, sauf si la fiche indique **Wi-Fi · sécurisé**.

</AccordionItem>
</Accordion>

## Toujours bloqué ? {#still-stuck}

**L’impression sécurisée est déjà désactivée et rien ne s’imprime.** Si la page web de l’imprimante s’ouvre mais que toutes les tâches échouent, consultez [Impression directe depuis le serveur](./server-direct-print.mdx).

**Elle a imprimé une fois, puis plus rien.** Consultez [Une impression, puis plus rien](./printed-once-then-stopped.mdx).

**Tout autre cas.** Copiez le rapport de configuration et collez-le dans votre message. Dans **Ajouter une imprimante**, appuyez sur **Copier le rapport de configuration** sous **Rien ne s’est imprimé**. Pour une imprimante enregistrée, ouvrez le menu **Autres actions** sur sa ligne dans **Paramètres → Impression** et choisissez **Copier le rapport de configuration**. La [FAQ sur la directive relative aux équipements radioélectriques](https://www.epson.eu/en_EU/faq/KA-01896/contents?loc=en-us) d’Epson fournit davantage d’informations sur ce paramètre.
