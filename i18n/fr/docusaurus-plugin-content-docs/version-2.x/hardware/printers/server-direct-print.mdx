L’Epson est allumée, sa page web s’ouvre et son autotest s’imprime, mais rien de ce que le PDV envoie ne sort. L’éteindre puis la rallumer ne change rien. Vérifiez si le paramètre **Impression directe depuis le serveur** de l’imprimante est activé.

:::note Vérifiez d’abord si WCPOS l’utilise
Dans **Paramètres → Impression**, la ligne de cette imprimante indique-t-elle **Impression directe depuis le serveur Epson · gérée par WCPOS** ? Dans ce cas, laissez l’impression directe depuis le serveur activée : la fonction **Impression cloud** de WCPOS envoie les reçus à l’imprimante de cette façon. N’ajoutez pas de nouveau la même imprimante avec **Ajouter une imprimante**. Consultez [Impression cloud](../../receipts/cloud-printing.mdx#setup-polling).
:::

Si vous ajoutez cette imprimante pour la première fois, ou si sa ligne ne porte pas cette mention, [vérifiez le paramètre sur la page web de l’imprimante](#turn-it-off).

## Ce que le PDV affiche {#what-you-see}

Lorsque vous ajoutez l’imprimante dans **Paramètres → Impression → Ajouter une imprimante**, sa fiche indique **Aucune connexion** et vous ne pouvez pas la sélectionner.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[302, 0], [0, 0], [136, -20], [161, 0]]} maxWidth={559} alt="Le panneau Ajouter une imprimante après la vérification d’une adresse : Rechercher à nouveau en haut à droite, puis la fiche de l’imprimante affichant son adresse et Epson avec la mention Aucune connexion, et en dessous Saisir une adresse IP et Ouvrir le guide des imprimantes">

1. **La fiche de l’imprimante** — son adresse et son fabricant. **Aucune connexion** signifie que l’application n’a trouvé aucun moyen d’imprimer sur cette imprimante ; la fiche ne peut donc pas être sélectionnée.
2. **Rechercher à nouveau** — relance la recherche sur le réseau. Utilisez cette option après avoir désactivé l’impression directe depuis le serveur.
3. **Saisir une adresse IP** — vérifie directement une adresse. Consultez [Saisir l’adresse vous-même](./setup-wizard.mdx#enter-address).
4. **Ouvrir le guide des imprimantes** — ouvre ces pages consacrées aux imprimantes.

</JourneyShot>

Vous pouvez aussi rencontrer l’un de ces cas :

- **Rien ne s’est imprimé** après une page de test, avec le message « L’imprimante retient des tâches. Éteignez-la puis rallumez-la, puis réessayez. » Si ce message persiste après un redémarrage, vérifiez si l’impression directe depuis le serveur est activée. Si elle est désactivée, consultez [Impression sécurisée Epson](./secure-printing.mdx), un autre paramètre Epson qui empêche l’impression des tâches envoyées par le PDV.
- **Test d’impression** échoue sur une imprimante déjà enregistrée, tout comme l’impression de chaque reçu.

## Pourquoi cela se produit {#why-it-happens}

Lorsque **Impression directe depuis le serveur** est activé, l’imprimante récupère ses tâches sur un serveur. Tant que ce réglage est activé, elle refuse les tâches qui lui sont envoyées directement sur votre réseau. Or, c’est ainsi que le PDV imprime sur une imprimante réseau ajoutée avec **Ajouter une imprimante**. Sa page web fonctionne toujours, ce qui donne l’impression qu’elle est en bon état. Ce paramètre est enregistré : un redémarrage ne l’efface donc pas.

Si vous ne l’avez pas activé, il l’a été dans un autre contexte : une configuration précédente, un service de cuisine ou de commandes en ligne, ou une autre caisse.

## La désactiver {#turn-it-off}

:::warning Un autre système peut en avoir besoin
Si un écran de cuisine ou un service de commandes en ligne imprime sur cette Epson par l’impression directe depuis le serveur, sa désactivation empêche ce service d’imprimer. Un seul des deux systèmes peut utiliser l’imprimante : attribuez au PDV sa propre imprimante ou faites utiliser une autre imprimante à ce service.
:::

Cette opération s’effectue sur la page web de l’imprimante, depuis un ordinateur ou une tablette sur le même réseau qu’elle.

1. Ouvrez `https://` suivi de l’adresse de l’imprimante, par exemple `https://192.168.1.100`, et acceptez l’avertissement concernant le certificat. L’adresse figure sur la feuille d’état de l’imprimante. Consultez [Trouver l’adresse de votre imprimante](./network-address.mdx).
2. Appuyez sur **Connexion administrateur**. Sur les modèles récents, le mot de passe est le **numéro de série** de l’imprimante, inscrit sur l’étiquette située sous celle-ci, sauf si quelqu’un l’a modifié.
3. Cherchez **Impression directe depuis le serveur** dans le menu. Son emplacement varie selon le modèle et le micrologiciel : sur les modèles TM-i, il se trouve sous **Paramètres du service web → Impression directe**, ou **Configuration → Impression directe** avec le micrologiciel 3.x et les versions antérieures. Sur les autres modèles, cherchez-le dans le menu ou dans le manuel de votre modèle.
4. Si le réglage indique déjà **Désactiver**, laissez-le désactivé et suivez plutôt [Impression sécurisée Epson](./secure-printing.mdx). Sinon, sélectionnez **Désactiver**, enregistrez, puis poursuivez ci-dessous.
5. Laissez l’imprimante redémarrer, ou éteignez-la pendant dix secondes puis rallumez-la.
6. De retour dans le PDV, testez l’imprimante :
   - **Ajout d’une imprimante :** appuyez sur **Rechercher à nouveau** ou **Saisir une adresse IP**. Lorsque la fiche indique **Prête**, sélectionnez-la et appuyez sur **Imprimer une page de test**.
   - **Imprimante déjà enregistrée :** appuyez sur **Test d’impression** sur sa ligne dans **Paramètres → Impression**.

## Toujours bloqué ? {#still-stuck}

Appuyez sur **Copier le rapport de configuration** et collez-le dans votre message. Sur l’écran **Rien ne s’est imprimé**, le rapport répertorie les ports essayés par l’application sur l’imprimante et les éventuels refus reçus. Pour une imprimante enregistrée, cette option se trouve dans le menu **Autres actions** de sa ligne, dans **Paramètres → Impression**.
