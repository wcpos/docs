Un tiroir-caisse ne se connecte pas au PDV. Il se branche sur l’**imprimante de reçus**, et le PDV demande à l’imprimante de l’ouvrir. Cette page vous guide pour brancher le tiroir, activer son ouverture dans l’application et le tester.

:::note Vous devez d’abord disposer d’une imprimante de reçus
Ajoutez l’imprimante avant le tiroir. Consultez l’[Assistant de configuration d’imprimante](./setup-wizard.mdx). La **Boîte de dialogue d’impression** intégrée et les imprimantes cloud ne peuvent pas ouvrir de tiroir.
:::

## Brancher le tiroir sur l’imprimante {#wire-it-up}

1. Repérez la prise à l’arrière de l’imprimante portant la mention **DK**, **Drawer** ou **Cash Drawer**.
2. Branchez le câble du tiroir. Sa fiche ressemble à une fiche téléphonique. La prise réseau située à côté est plus large : ne l’utilisez pas.
3. Éteignez l’imprimante, puis rallumez-la.

## Activer l’ouverture dans l’application {#switch-it-on-in-the-app}

L’option **Ouvrir automatiquement le tiroir-caisse** se règle pour chaque imprimante. Elle est désactivée pour toute nouvelle imprimante. Vous pouvez l’activer lors de l’ajout de l’imprimante ou plus tard depuis sa ligne dans la liste. Vous avez déjà ajouté votre imprimante ? Passez à [Tester le tiroir](#test-the-drawer).

:::note Chaque reçu ouvre le tiroir
Lorsque l’option **Ouvrir automatiquement le tiroir-caisse** est activée, le tiroir s’ouvre chaque fois que cette imprimante imprime un reçu, y compris pour les ventes par carte et les réimpressions. Consultez [Quand le tiroir s’ouvre](#when-it-opens).
:::

### Lors de l’ajout de l’imprimante {#while-adding}

Dans **Paramètres → Impression**, appuyez sur **Ajouter une imprimante**. Une fois la recherche terminée, appuyez sur **Plus d’options**.

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[96, 0], [-24, 0], [-60, 0], [-60, 0]]} maxWidth={559} alt="Le panneau Ajouter une imprimante avec Plus d’options déployé : Nom de l’imprimante, Fabricant, Largeur du texte de l’imprimante, Langue du reçu et les options Couper automatiquement le papier, Ouvrir automatiquement le tiroir-caisse et Définir par défaut, toutes activées">

1. **Plus d’options** — affiche les paramètres de l’imprimante sous les résultats de recherche.
2. **Fabricant** — **Epson** ou **Star Micronics**. Chaque marque utilise sa propre commande d’ouverture du tiroir : choisissez donc celle de votre imprimante.
3. **Ouvrir automatiquement le tiroir-caisse** — l’imprimante ouvre le tiroir chaque fois qu’elle imprime un reçu.
4. **Définir par défaut** — **Sans vente** ouvre le tiroir de l’imprimante par défaut. Consultez [Ouvrir le tiroir sans vente](#no-sale).

</JourneyShot>

Terminez l’ajout de l’imprimante comme indiqué dans l’[Assistant de configuration d’imprimante](./setup-wizard.mdx). La page de test de l’assistant n’ouvre jamais le tiroir : testez donc ensuite le tiroir.

### Tester le tiroir ou modifier une imprimante existante {#test-the-drawer}

1. Dans **Paramètres → Impression**, appuyez sur **Modifier** sur la ligne de l’imprimante.
2. Activez **Ouvrir automatiquement le tiroir-caisse** si l’option est désactivée. **Connecteur du tiroir-caisse** apparaît en dessous : il s’agit de la broche à laquelle le tiroir est raccordé. **Broche 2 / Tiroir 1** convient à la plupart des tiroirs. Choisissez **Broche 5 / Tiroir 2** pour un second tiroir ou si le manuel du tiroir indique la broche 5.
3. Appuyez sur **Ouvrir le tiroir**, en bas du panneau **Modifier l’imprimante**, à côté de **Impression test**. Cette action ouvre le tiroir une fois, sans imprimer. Vérifiez que le tiroir s’ouvre bien. S’il reste fermé, consultez [Si le tiroir ne s’ouvre pas](#when-it-doesnt-open), même si l’application indique **Tiroir-caisse ouvert**.

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[685, 0], [685, 0], [47, -30], [36, -30]]} alt="Paramètres → Impression avec le panneau Modifier l’imprimante ouvert pour une imprimante réseau, défilé jusqu’aux paramètres du tiroir : Ouvrir automatiquement le tiroir-caisse activé, Connecteur du tiroir-caisse réglé sur Broche 2 / Tiroir 1 et les boutons Ouvrir le tiroir et Impression test en bas">

1. **Ouvrir automatiquement le tiroir-caisse** — activé ici. L’imprimante ouvre le tiroir chaque fois qu’elle imprime un reçu.
2. **Connecteur du tiroir-caisse** — la broche à laquelle le tiroir est raccordé, ici **Broche 2 / Tiroir 1**. Ce réglage n’apparaît que lorsque **Ouvrir automatiquement le tiroir-caisse** est activé.
3. **Ouvrir le tiroir** — ouvre le tiroir une fois, sans imprimer.
4. **Impression test** — imprime une page de test sur cette imprimante. Lorsque **Ouvrir automatiquement le tiroir-caisse** est activé, comme ici, cette action ouvre aussi le tiroir.

</JourneyShot>

## Quand le tiroir s’ouvre {#when-it-opens}

Lorsque **Ouvrir automatiquement le tiroir-caisse** est activé, le tiroir s’ouvre chaque fois que cette imprimante imprime un reçu :

- un reçu imprimé au moment du paiement, manuellement ou automatiquement ;
- un reçu que vous réimprimez plus tard ;
- **Impression test** sur la ligne de l’imprimante.

Il s’ouvre pour tous les moyens de paiement, pas seulement pour les espèces.

Il reste fermé lors de l’impression des rapports de caisse : rapport X, passation et clôture. Consultez [Ouvrir la caisse](../../pos/register/index.mdx).

## Ouvrir le tiroir sans vente {#no-sale}

Pour faire de la monnaie ou vérifier le fonds de caisse, utilisez **Sans vente** dans le panneau de caisse. Cette action ouvre le tiroir et enregistre le motif, sans mouvement d’argent.

{/* pending: monorepo#3360 */}
:::note Avant de commencer
- La caisse doit être ouverte. Consultez [Ouvrir la caisse](../../pos/register/index.mdx).
- L’option **Ouvrir automatiquement le tiroir-caisse** doit être activée sur votre imprimante de reçus par défaut. **Sans vente** ouvre le tiroir de cette imprimante. Pour définir une imprimante par défaut, ouvrez son menu **Plus d’actions** dans **Paramètres → Impression** et appuyez sur **Définir par défaut**.
:::

Appuyez sur votre avatar à l’extrémité de la barre de caisse, puis sur **Dans le tiroir**, pour ouvrir le panneau de caisse.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [200, 0]]} alt="Le panneau de caisse lorsque la caisse est ouverte : les espèces dans le tiroir, les tuiles Entrée d’espèces, Sortie d’espèces et Sans vente, et Imprimer le rapport X en bas">

1. **Sans vente** — ouvre le tiroir, uniquement lorsque la caisse est ouverte. Les actions **Entrée d’espèces** et **Sortie d’espèces**, à côté, enregistrent les mouvements d’espèces sans ouvrir le tiroir.
2. **Dans le tiroir** — le montant d’espèces attendu par la caisse. Une opération Sans vente ne le modifie pas. **Imprimer le rapport X**, en bas, n’ouvre jamais le tiroir.

</JourneyShot>

Appuyez sur **Sans vente**. Le panneau demande **Pourquoi ouvrir le tiroir ?**

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [440, 0], [140, -42]]} alt="Le panneau Sans vente, Pourquoi ouvrir le tiroir ? : les espèces dans le tiroir, les motifs Monnaie, Erreur, Vérification du tiroir et Autre…, le champ du motif rempli avec Monnaie et le bouton Ouvrir le tiroir">

1. **Monnaie** — l’un des motifs prédéfinis, avec **Erreur** et **Vérification du tiroir**. Appuyez sur un motif pour remplir le champ. **Autre…** vide le champ pour vous permettre de saisir votre propre motif.
2. **Motif** — le motif qui sera enregistré. Tant qu’il n’est pas renseigné, le panneau indique **Ajouter un motif**.
3. **Ouvrir le tiroir** — enregistre l’opération Sans vente et ouvre le tiroir.

</JourneyShot>

Le montant en haut correspond aux espèces attendues dans le tiroir. Il est masqué pour les caissiers qui effectuent un comptage à l’aveugle.

Vérifiez que le tiroir s’ouvre. S’il reste fermé, consultez [Si le tiroir ne s’ouvre pas](#when-it-doesnt-open). L’opération Sans vente est enregistrée dans tous les cas.

## Si le tiroir ne s’ouvre pas {#when-it-doesnt-open}

Commencez par **Ouvrir le tiroir** dans **Modifier**. Cette action ouvre le tiroir sans imprimer de reçu, ce qui permet de vérifier s’il peut s’ouvrir. Déployez ensuite la rubrique correspondant au symptôme.

<Accordion>
<AccordionItem question="Ouvrir le tiroir fonctionne, mais les reçus n’ouvrent pas le tiroir">

Le branchement est correct. Vérifiez que **Ouvrir automatiquement le tiroir-caisse** est activé pour l’imprimante qui imprime vos reçus.

</AccordionItem>
<AccordionItem question="Ouvrir le tiroir affiche « L’imprimante n’a pas accepté la tâche. »">

L’imprimante n’a pas accepté la commande. Imprimez d’abord une page de test depuis la ligne de l’imprimante. Consultez [Imprimantes de reçus](./index.mdx#when-nothing-prints).

</AccordionItem>
<AccordionItem question="L’application indique Tiroir-caisse ouvert, mais rien ne se passe">

Vérifiez que le câble est branché dans la prise du tiroir, et non dans la prise réseau. Essayez ensuite l’autre **Connecteur du tiroir-caisse** : le tiroir est peut-être raccordé à la broche 5.

</AccordionItem>
<AccordionItem question="Le tiroir émet un clic, mais ne s’ouvre pas">

Vérifiez la position de la clé du tiroir. La plupart des tiroirs ont une serrure à l’avant, et l’une des positions de la clé maintient le tiroir fermé. Vérifiez ensuite la tension : les tiroirs sont conçus pour 12 V ou 24 V, et leur tension doit correspondre à celle fournie par l’imprimante. Le manuel de l’imprimante précise laquelle.

</AccordionItem>
<AccordionItem question="Modifier affiche un avertissement : les impulsions du tiroir-caisse dépendent du langage ou de l’émulation de l’imprimante">

Le **Langage de l’imprimante** ne correspond pas à sa marque, par exemple une imprimante Star réglée sur ESC/POS. Réglez le langage pour qu’il corresponde au mode d’émulation de l’imprimante.

</AccordionItem>
<AccordionItem question="Le panneau Sans vente s’est fermé, mais le tiroir est resté fermé">

L’opération Sans vente est enregistrée dans tous les cas. Vérifiez que **Ouvrir automatiquement le tiroir-caisse** est activé sur votre imprimante de reçus par défaut. Si l’imprimante a refusé la commande, le panneau reste ouvert et affiche l’erreur : appuyez de nouveau sur **Ouvrir le tiroir**. Cette action ouvre seulement le tiroir, sans enregistrer une seconde opération Sans vente.

</AccordionItem>
<AccordionItem question="Une imprimante bon marché ne répond pas">

Certaines imprimantes bon marché ne comprennent qu’une ancienne version de la commande d’ouverture du tiroir. Pour une imprimante réglée sur **Epson**, **Ouvrir le tiroir** envoie la commande Epson plus récente, que ces imprimantes ignorent. Certaines imprimantes n’ont pas de prise pour tiroir ou ne peuvent pas le commander. Le manuel de l’imprimante précise si elle prend en charge un tiroir-caisse.

</AccordionItem>
<AccordionItem question="Le tiroir s’ouvre alors que l’option Ouvrir automatiquement le tiroir-caisse est désactivée">

Un modèle thermique personnalisé peut contenir sa propre commande `<drawer />` , qui ouvre le tiroir quel que soit le réglage de l’option. Retirez la balise du modèle pour empêcher cette ouverture. Consultez [Modèles thermiques](../../receipts/thermal-templates.mdx).

</AccordionItem>
</Accordion>

## Toujours bloqué ? {#still-stuck}

Dans **Paramètres → Impression**, ouvrez le menu **Plus d’actions** de l’imprimante et appuyez sur **Copier le rapport de configuration**. Collez-le dans votre message, en précisant les modèles de l’imprimante et du tiroir.
