:::info Fonctionnalité Pro
L’écran Produits nécessite [WCPOS Pro](../getting-started/pro-license.mdx). Sans Pro, vos produits apparaissent floutés, avec les boutons **Passer à Pro** et **Voir la démo**. Vous pouvez toujours vendre tous les produits depuis le [panneau des produits](../pos/product-panel/index.mdx).
:::

L’écran Produits vous permet de gérer votre catalogue depuis la caisse : modifier les stocks et les prix, corriger un code-barres ou vérifier la présentation d’un produit dans votre boutique. Ouvrez-le en choisissant **Produits** dans le menu. Chaque modification est transmise à votre boutique et apparaît donc dans WooCommerce et sur toutes les autres caisses.

Accès direct : [Modifier le stock](#inline-stock-editing) · [Modifier les prix](#inline-price-editing) · [Modifier un produit](#product-actions) · [Modifier une variation](#edit-variation)

## Écran Produits ou panneau des produits {#products-screen-vs-pos-product-panel}

Pour ajouter des produits à une vente, utilisez le [panneau des produits](../pos/product-panel/index.mdx). Pour modifier votre catalogue, ouvrez **Produits** ; WCPOS Pro est nécessaire.

## Repérez les éléments de l’écran {#interface-overview}

3. **Produit** — la colonne selon laquelle la liste est triée, avec une flèche indiquant le sens du tri. Appuyez sur un en-tête pour trier selon cette colonne. Voir [Trier et redimensionner les colonnes](#sorting).

## Rechercher un produit {#search--filters}

<Anchor id="filtering-products" />

- **Rechercher** — saisissez un nom, un SKU ou un code-barres. La recherche interroge votre boutique pour trouver les produits qui ne sont pas encore sur cet appareil.
- **Scanner** — scannez un produit avec un lecteur de codes-barres. Le PDV affiche **Code-barres scanné** avec le code et le nombre de produits correspondants, puis place le code dans le champ de recherche. Le champ utilisé comme code-barres est défini dans [Champ de code-barres](../settings/wp-admin/general.mdx#barcode-field).
- **Filtres** — les boutons sous le champ de recherche permettent de restreindre la liste : **En stock**, **Mis en avant**, **En promotion**, **Catégorie**, **Étiquettes** et **Marques**. **En stock**, **Catégorie**, **Étiquettes** et **Marques** ouvrent une liste de choix ; **En stock** permet de choisir un état du stock (**En stock**, **Rupture de stock**, **En réapprovisionnement**). Appuyez sur la croix d’un filtre actif pour le retirer.

## Modifier les stocks, les prix et les noms dans la liste {#key-features}

Vous pouvez modifier directement le stock et les prix de chaque ligne, avec les mêmes pavés numériques que dans le panier : appuyez sur le nombre pour ouvrir un pavé numérique. Toute modification validée est transmise à votre boutique.

### Stock {#inline-stock-editing}

Appuyez sur le nombre sous **Stock** et saisissez la nouvelle quantité, ou utilisez **−** et **+**. Le stock est un nombre entier et **−** s’arrête à 0. Appuyez sur la coche ou sur Entrée pour valider ; Échap conserve la valeur précédente. Dans les applications iOS et Android, saisissez le nombre dans le champ.

### Gérer {#manage-stock-toggle}

L’interrupteur **Gérer** sous le nombre active ou désactive le suivi du stock du produit :

- **Activé** — votre boutique décompte le stock à chaque vente. Le nombre peut être modifié.
- **Désactivé** — le stock n’est pas décompté et le nombre est grisé. **État du stock** indique si le produit peut être vendu.

Pour empêcher la caisse de vendre plus d’unités d’un produit que vous n’en avez, activez [Empêcher la survente](../settings/wp-admin/checkout.mdx#prevent-overselling) ; cette option est désactivée dans une nouvelle boutique.

### Prix {#inline-price-editing}

- **Prix normal** — appuyez dessus, saisissez le nouveau prix, puis appuyez sur la coche ou sur Entrée pour valider. Échap conserve la valeur précédente. Dans les applications iOS et Android, saisissez le prix dans le champ.
- **Prix promotionnel** — modifiable uniquement lorsque le produit est en promotion. Pour mettre un produit en promotion, ajoutez un prix promotionnel dans sa [boîte de dialogue](#product-actions).
- **Prix** — le prix facturé à la caisse. Il dépend des deux autres et ne peut pas être modifié directement.

Les prix d’un produit variable proviennent de ses options et ne peuvent donc pas être modifiés sur sa ligne. Modifiez le prix de chaque option sur sa propre ligne : voir [Produits variables](#variable-products).

### Nom {#inline-name-editing}

Appuyez sur le nom d’un produit dans la liste, saisissez le nouveau nom, puis appuyez sur Entrée ou en dehors du champ pour valider.

### Coût des marchandises vendues {#cost-of-goods-sold}

Si votre boutique utilise le coût des marchandises vendues de WooCommerce, activez la colonne **Coût des marchandises vendues** dans les [réglages d’affichage](#display-settings) pour voir le coût de chaque produit à côté de ses prix. Appuyez sur un coût, saisissez la nouvelle valeur, puis appuyez sur la coche ou sur Entrée pour valider. Échap conserve la valeur précédente. Dans les applications iOS et Android, saisissez le coût dans le champ.

:::note Activez d’abord cette fonctionnalité dans WooCommerce
Le coût des marchandises vendues est une fonctionnalité de WooCommerce. Activez-la dans **WooCommerce > Réglages > Avancé > Fonctionnalités**.
:::

### Si vous ne pouvez pas modifier un champ {#permissions}

Un champ grisé dont l’infobulle indique **Vous n’avez pas l’autorisation de modifier les produits** signifie que votre compte ne peut pas modifier les produits. Un administrateur peut vous accorder cette autorisation dans **WP Admin > PDV > Réglages > Accès**. Les variations disposent de leur propre autorisation, tout comme la suppression.

## Modifier un produit {#product-actions}

Appuyez sur **›** à la fin d’une ligne pour ouvrir la boîte de dialogue du produit.

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-40, 0], [95, 0], [-14, 0], [-10, 0], [-40, 0], [-30, 0], [-20, 0], [-20, 0], [75, 0], [-30, 0]]} alt="Modification de Aim Analog Watch : onglets Formulaire et JSON, lignes Nom, Prix normal 45.00, SKU, Code-barres avec Retirer, Stock 81 avec Arrêter le suivi, Taxe, Catégories, Statut et Champs masqués, puis boutons Prix promotionnel, Mis en avant, Virtuel, Téléchargeable et Champ personnalisé, et Synchroniser et Fermer en bas">

1. **Nom** — le nom du produit tel qu’il apparaît dans votre boutique.
2. **Prix normal** — le prix hors promotion.
3. **Retirer** — retire le champ du produit ; son bouton réapparaît en bas.
4. **Arrêter le suivi** — arrête le décompte du stock de ce produit. La ligne indique alors **Non suivi**, avec **Suivre la quantité** pour réactiver le suivi.
5. **Taxe** — la classe de taxe du produit, ou **Non taxable**.
6. **Afficher** — affiche la liste des champs masqués. Voir [Champs avancés](#advanced-fields).
7. **Prix promotionnel** — ajoute un champ que le produit n’a pas encore. **Mis en avant**, **Virtuel** et **Téléchargeable** fonctionnent de la même manière.
8. **Champ personnalisé** — ajoute un champ de votre choix. Voir [Champs avancés](#advanced-fields).
9. **Synchroniser** — met à jour cette caisse avec le produit tel qu’il est enregistré dans votre boutique. Voir [Synchroniser ou supprimer](#delete).
10. **Fermer** — ferme la boîte de dialogue. Il n’y a pas de bouton Enregistrer : chaque modification est enregistrée immédiatement.

</JourneyShot>

Chaque modification est enregistrée immédiatement. **Enregistré** apparaît brièvement à côté du champ. Si une modification ne peut pas être enregistrée, **Non enregistré** apparaît en rouge et reste affiché jusqu’à votre prochaine modification.

<Anchor id="advanced-fields" />

<details>
<summary>Champs avancés et dépannage</summary>

- **Champs masqués** — appuyez sur **Afficher** pour en voir la liste. Ce sont des champs personnalisés que les extensions utilisent pour leurs propres besoins. Ne les modifiez que si vous savez à quoi ils servent.
- **Champ personnalisé** — ajoute un champ personnalisé de votre choix, avec un nom et une valeur.
- **JSON** — l’onglet en haut affiche le produit tel qu’il est stocké sur cet appareil, à des fins de dépannage.

</details>

La boîte de dialogue d’un produit variable comporte une ligne **Variations** qui indique **Gérées dans la liste des produits** : vous modifiez ses options depuis sa ligne dans la liste, pas ici. Voir [Produits variables](#variable-products).

<details>
<summary>Pourquoi ne puis-je pas modifier les variations dans cette boîte de dialogue ?</summary>

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[280, 0], [330, 0], [75, 0]]} alt="Modification de Abominable Hoodie : Stock indique Non suivi avec Suivre la quantité, et une ligne Variations indique 15 variations, Gérées dans la liste des produits">

1. **Gérées dans la liste des produits** — les options du produit se modifient depuis sa ligne dans la liste.
2. **Non suivi** — le stock n’est pas décompté au niveau du produit. **Suivre la quantité** active le suivi.
3. **Synchroniser** — met à jour cette caisse avec le produit tel qu’il est enregistré dans votre boutique.

</JourneyShot>

Dans WooCommerce, chaque option est une variation avec son propre prix, son stock et ses réglages ; elle possède donc sa propre boîte de dialogue. Celle du produit indique seulement leur nombre.

</details>

## Produits variables {#variable-products}

Un produit variable, comme un sweat à capuche proposé en cinq tailles et trois couleurs, possède sa propre ligne et une ligne par option. La ligne affiche les tailles et les couleurs du produit, ainsi que le nombre d’options, par exemple **15 variations**.

Appuyez sur **15 variations** pour ouvrir les options. Leur mode d’ouverture dépend du réglage **Variations** dans les [réglages d’affichage](#display-settings) :

- **Ouvrir sur place** — les options occupent toute la liste, avec **Produits** au-dessus pour revenir en arrière. C’est le réglage initial d’un nouvel appareil.
- **Lignes développées** — les options s’ouvrent sous forme de lignes sous le produit.

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-4, -30], [150, 0], [-30, 0], [0, -28]]} alt="Abominable Hoodie ouvert sur place : Produits et nom du produit au-dessus du tableau, filtres Taille et Couleur, et une ligne par option, par exemple L, Bleu avec un stock de 100, un interrupteur Gérer, En stock et $69.00">

1. **Produits** — revient à la liste précédente.
2. **Abominable Hoodie** — le produit dont vous consultez les options.
3. **Stock** — chaque option possède son propre stock et son interrupteur **Gérer**.
4. **›** — ouvre la boîte de dialogue de l’option. Voir [Modifier une variation](#edit-variation).

</JourneyShot>

La ligne de chaque option possède son propre stock, son interrupteur **Gérer** et ses prix, que vous modifiez de la même manière que ceux d’un produit. Appuyez sur **›** sur une option pour ouvrir sa boîte de dialogue.

### Modifier une variation {#edit-variation}

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[95, 0], [-10, 0], [-40, 0], [-30, 0], [-20, 0], [75, 0]]} alt="Modification de L, Bleu : lignes Prix normal 69.00, SKU et Code-barres avec Retirer, Stock 100 avec Arrêter le suivi, Taxe, Statut et Champs masqués, boutons Prix promotionnel et Champ personnalisé, puis Synchroniser et Fermer en bas">

1. **Prix normal** — le prix propre à cette option.
2. **Arrêter le suivi** — arrête le décompte du stock de cette option.
3. **Taxe** — la classe de taxe de cette option. Voir **Identique au parent** ci-dessous.
4. **Afficher** — affiche la liste des champs masqués de l’option.
5. **Prix promotionnel** — met cette option en promotion.
6. **Synchroniser** — met à jour cette caisse avec l’option telle qu’elle est enregistrée dans votre boutique.

</JourneyShot>

Une option possède son propre prix, SKU, code-barres, stock, taxe et statut. Sa ligne **Taxe** peut reprendre le réglage du produit : elle indique alors **Identique au parent**, avec la classe de taxe du produit à côté. Appuyez sur **Définir pour cette variation** pour choisir la classe propre à l’option. Pour reprendre le réglage du produit, choisissez **Identique au parent** dans la liste.

## Synchroniser ou supprimer {#delete}

En bas de la boîte de dialogue d’un produit ou d’une option :

- **Synchroniser** — met à jour cette caisse avec le produit tel qu’il est enregistré dans votre boutique, au cas où il aurait été modifié ailleurs. Une modification que vous venez d’effectuer dans la boîte de dialogue est enregistrée d’abord, et une modification qui n’a pas pu être enregistrée n’est pas écrasée.
- **Supprimer** — demande une confirmation, puis supprime le produit ou l’option dans votre boutique.

:::warning La suppression retire aussi l’élément de votre boutique
La suppression ne retire pas seulement l’élément de cette caisse :

- **Un produit** est placé dans la corbeille de WooCommerce. Le message de confirmation indique : *Voulez-vous vraiment supprimer ce produit ? Les produits supprimés seront placés dans la corbeille sur le serveur.*
- **Une variation** est supprimée définitivement. Le message de confirmation indique : *Voulez-vous vraiment supprimer cette variation ? La suppression d’une variation est définitive, il n’existe pas de corbeille pour les variations.*

**Supprimer** s’affiche uniquement pour un compte disposant des permissions `delete_products`, `delete_others_products` et `delete_published_products` (une variation nécessite aussi `delete_product`). Le rôle Caissier ne les possède pas ; un administrateur peut les accorder dans **WP Admin → PDV → Réglages → Accès**.
:::

Un produit supprimé dans WooCommerce disparaît aussi de toutes les caisses lors de la prochaine vérification des modifications.

## Tri et bas de la liste {#list-tools}

### Trier et redimensionner les colonnes {#sorting}

<Anchor id="product-list" />

Appuyez sur l’en-tête d’une colonne pour trier selon celle-ci, puis à nouveau pour inverser l’ordre. Faites glisser le bord droit d’un en-tête pour élargir ou rétrécir la colonne. Pour choisir les colonnes affichées, voir [Réglages d’affichage](#display-settings).

<details>
<summary>Colonnes permettant le tri et réglages conservés</summary>

- La flèche à côté de l’en-tête indique le sens du tri de la liste.
- Vous pouvez trier par **Produit**, **ID**, **Type**, **SKU**, **Code-barres**, **Stock**, **État du stock**, **Prix** et **Date de création**.
- Un nouvel appareil trie par **Produit**, de A à Z. Le tri que vous choisissez est conservé sur cet appareil.
- La nouvelle largeur d’une colonne n’est pas enregistrée dans vos réglages.

</details>

### Le bas de la liste {#footer}

- **Base de calcul des taxes**, par exemple **Adresse de la boutique** — la base utilisée par votre boutique pour calculer les taxes. Appuyez dessus pour voir les taux de taxe appliqués.
- **Affichage de 10 sur 212** — le nombre de produits affichés à l’écran parmi ceux de cet appareil qui correspondent à votre recherche et à vos filtres. D’autres se chargent à mesure que vous faites défiler la liste.
- **Flèche de synchronisation** — appuyez dessus pour vérifier immédiatement les modifications dans votre boutique.

<details>
<summary>Un nombre peu élevé et la possibilité de repartir de zéro</summary>

- Sur un nouvel appareil, le second nombre peut être peu élevé au début, pendant le téléchargement de votre catalogue.
- Appuyez longuement sur la flèche de synchronisation pour accéder à **Effacer et actualiser**, qui efface les produits sur cet appareil et les télécharge à nouveau. Cette action efface également la recherche et réinitialise les filtres. Voir [Actualiser ou repartir de zéro](sync.mdx#refresh).

</details>

## Réglages d’affichage {#display-settings}

Appuyez sur le bouton des réglages à côté du champ de recherche pour ouvrir **Réglages des produits**.

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[0, 0], [0, 0], [205, 0], [-30, 0]]} alt="Réglages des produits : Variations réglé sur Ouvrir sur place avec Lignes développées à côté, puis Colonnes, chacune avec une poignée de déplacement et un interrupteur, et Produit avec SKU, Code-barres et Attributs en dessous, puis Rétablir les réglages par défaut et Fermer en bas">

1. **Ouvrir sur place** — les options d’un produit variable occupent toute la liste. C’est le réglage initial d’un nouvel appareil.
2. **Lignes développées** — les options s’ouvrent sous forme de lignes sous le produit.
3. **Rétablir les réglages par défaut** — rétablit les colonnes. Voir [Rétablir les réglages par défaut](#restore-default-settings).
4. **Fermer** — vos choix sont conservés.

</JourneyShot>

Le réglage **Variations** est le même ici que dans le [panneau des produits](../pos/product-panel/variations.mdx#change-style) : modifiez-le à un endroit et l’autre suit. Vos choix ne s’appliquent qu’à cet appareil.

### Colonnes {#available-columns}

Chaque colonne possède une ligne sous **Colonnes** : une poignée en pointillés à gauche, puis un interrupteur et le nom de la colonne. Activez l’interrupteur pour afficher la colonne ou désactivez-le pour la masquer. Faites glisser une ligne vers le haut ou le bas par sa poignée pour déplacer la colonne vers la gauche ou la droite dans le tableau. **Produit** possède trois lignes supplémentaires que vous pouvez afficher sous le nom : **SKU**, **Code-barres** et **Attributs**. **Prix**, **Prix normal** et **Prix promotionnel** peuvent également afficher la taxe.

### Rétablir les réglages par défaut {#restore-default-settings}

**Rétablir les réglages par défaut**, en bas de **Réglages des produits**, rétablit les colonnes telles qu’elles sont sur un nouvel appareil.

## En cas de problème {#goes-wrong}

- **Un produit ne figure pas dans la liste** — vérifiez les filtres, puis recherchez-le par nom ou SKU. Un produit réservé à la vente en ligne n’est jamais transmis au PDV : voir [Produits réservés au PDV](pos-only-products.mdx).
- **Un prix ou un niveau de stock semble obsolète** — ouvrez le produit et appuyez sur **Synchroniser**, ou appuyez sur la flèche de synchronisation sous la liste.
- **Non enregistré** — la modification n’a pas été appliquée au produit. Vérifiez la valeur et réessayez. Si l’échec persiste, survolez le champ ou appuyez longuement dessus : si l’infobulle indique **Vous n’avez pas l’autorisation de modifier les produits**, voir [Si vous ne pouvez pas modifier un champ](#permissions). Si votre boutique refuse une modification, le PDV rétablit la valeur de la boutique dans le champ et le journal indique **Une modification rejetée par votre boutique a été annulée**.
- **Un champ est grisé** — votre compte n’est pas autorisé à le modifier. Voir [Si vous ne pouvez pas modifier un champ](#permissions).
- **Le prix promotionnel ne peut pas être modifié** — le produit n’est pas en promotion. Ajoutez un prix promotionnel dans sa boîte de dialogue.
- **Le bouton Supprimer n’apparaît pas** — votre compte n’est pas autorisé à supprimer des produits. Le rôle Caissier ne l’est pas par défaut ; un administrateur peut lui accorder cette autorisation dans **WP Admin → PDV → Réglages → Accès**.
