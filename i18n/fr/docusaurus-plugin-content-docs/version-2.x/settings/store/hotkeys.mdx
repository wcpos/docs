Avec un clavier sur le comptoir, vous pouvez encaisser une vente sans toucher à la souris. Maintenez **Alt** (**Option ⌥** sur un Mac) et appuyez sur une touche. **Alt + /** affiche tous les raccourcis.

:::note Où fonctionnent les raccourcis
Dans un navigateur et dans l’application de bureau, sur l’écran du PDV. Ils fonctionnent même lorsque le curseur se trouve dans un champ de texte. {/* pending: monorepo#3357 */} Sur un Mac, pour utiliser un raccourci qui y saisit un accent, comme **Option + N**, vous devez d’abord [cliquer en dehors du champ](#goes-wrong). Les applications pour téléphone et tablette n’en proposent pas. Les autres écrans non plus, à l’exception de la liste des commandes, qui possède ses propres [touches fléchées](#orders).
:::

## Les raccourcis {#shortcuts}

Tous les raccourcis sauf **Alt + /** sont inactifs pendant le paiement ou sur l’écran de confirmation du paiement. Tous sauf **Alt + F** et **Alt + /** sont également inactifs lorsque le panier est masqué : par le sélecteur de caisse, la carte **Ouvrir la caisse**, le comptage ou la liste des commandes ouvertes.

| Touches | Résultat |
|---|---|
| **Alt + F** | Le curseur se place dans **Rechercher des produits**. Sur un écran étroit, l’onglet Produits s’ouvre d’abord. |
| **Alt + P** | Ouvre **Paiement**.<br />_Le panier doit également contenir un article._ |
| **Alt + N** | Crée un panier vide. La commande sur laquelle vous étiez reste ouverte.<br />_Une commande doit également être présente dans le panier ; celui-ci ne doit pas être vide._ |
| **Alt + ←** ou **Alt + →** | Passe à la commande ouverte précédente ou suivante.<br />_Il faut également au moins deux commandes ouvertes._ |
| **Alt + D** | Ouvre **Ajouter une remise**.<br />_Une commande doit également être présente dans le panier._ |
| **Alt + V** | Annule immédiatement la commande dans le panier. Appuyez aussitôt sur **Rétablir** si c’était une erreur.<br />_Une commande doit également être présente dans le panier._ |
| **Alt + /** | Ouvre ou ferme la liste des raccourcis.<br />_Fonctionne à tout moment sur l’écran du PDV, y compris pendant le paiement._ |

:::warning Alt + V ne demande pas de confirmation
La commande est annulée dès que vous appuyez sur ce raccourci. Le message qui apparaît comporte un bouton **Rétablir** : appuyez dessus aussitôt si c’était une erreur.
:::

Les raccourcis sont fixes. Aucun réglage ne permet de les modifier. Si vous souhaitez utiliser d’autres touches, dites-le-nous sur [Discord](https://wcpos.com/discord).

## Afficher tous les raccourcis {#list}

Appuyez sur **Alt + /**. La liste s’ouvre depuis la droite.

Une ligne grisée correspond à une action indisponible pour le moment. Lorsque le panier est vide, **Paiement**, **Nouveau panier**, **Ajouter une remise** et **Annuler la commande** sont grisés, et **Panier précédent** et **Panier suivant** le restent tant que deux commandes ne sont pas ouvertes. Appuyez sur toute autre ligne pour exécuter l’action, comme avec ses touches. Sous Windows, une note en bas de la liste signale une particularité de [Firefox](#goes-wrong). Appuyez sur **Fermer**, ou à nouveau sur **Alt + /**, pour fermer la liste.

La liste recouvre le panier et assombrit les produits à côté.

1. **Rechercher des produits** — place le curseur dans la recherche de produits, pour saisir du texte ou scanner un code. Voir [Recherche et filtrage](../../pos/product-panel/search-filtering.mdx).
2. **Paiement** — ouvre le volet de règlement de la commande dans le panier. Voir [Paiement](../../pos/checkout/index.mdx).
3. **Nouveau panier** — crée un panier vide. La commande sur laquelle vous étiez reste dans les [Commandes ouvertes](../../pos/cart/open-orders.mdx).
4. **Panier précédent** — passe à la commande ouverte précédente.
5. **Panier suivant** — passe à la commande ouverte suivante.
6. **Ajouter une remise** — ouvre **Ajouter une remise** pour la commande. Voir [Remises](../../pos/cart/discounts.mdx).
7. **Annuler la commande** — annule immédiatement la commande dans le panier, sans demander de confirmation. Appuyez aussitôt sur **Rétablir** si c’était une erreur. Voir [Annuler](../../pos/cart/order-actions.mdx#void).
8. **Raccourcis clavier** — cette liste.

## Parcourir la liste des commandes {#orders}

Sur l’écran **Commandes**, dans un navigateur ou dans l’application de bureau, cliquez sur une commande (ou accédez à la liste avec **Tab**), puis :

- **↓** / **↑** déplace la sélection vers la commande suivante ou précédente.
- **Entrée** ouvre la commande sélectionnée.

:::info Fonctionnalité Pro
L’écran Commandes est inclus dans WCPOS Pro. Voir [Commandes](../../orders/index.mdx).
:::

## En cas de problème {#goes-wrong}

**Rien ne se passe.** Ouvrez la liste avec **Alt + /** : si la ligne du raccourci est grisée, il n’est pas encore disponible, pour la raison indiquée dans [le tableau](#shortcuts). Vérifiez que vous êtes sur l’écran du PDV, que la caisse est ouverte et que la liste des commandes ouvertes ne recouvre pas le panier.

**Alt + F ou Alt + D ouvre le menu de Firefox.** Sous Windows, Firefox peut réserver ces deux raccourcis à son propre usage. Appuyez plutôt sur la ligne dans la liste des raccourcis, ou utilisez Chrome, Edge ou l’application de bureau.

**Sur un Mac, Option + N saisit un accent dans le champ de recherche.** Certaines dispositions de clavier utilisent Option + une lettre pour saisir un accent, et le PDV laisse passer cet accent lorsque vous saisissez du texte dans un champ. Cliquez en dehors du champ, puis appuyez à nouveau sur le raccourci.
