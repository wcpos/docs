## Signification {#what-this-means}

WCPOS n’a pas pu configurer ou supprimer le stockage sur cet appareil.

Libérez de l’espace de stockage sur l’appareil, puis redémarrez WCPOS. Sur le web, le navigateur peut aussi limiter le stockage du site, comme le font les fenêtres privées. Contactez l’assistance si l’échec persiste.

## Vos données {#your-data}

Il s’agit d’un problème de stockage, pas d’une modification refusée. S’il est survenu pendant l’effacement des données de cet appareil, une partie de ces données peut déjà avoir disparu, y compris des modifications qui n’avaient pas été envoyées. Vérifiez que vos ventes et modifications récentes apparaissent dans votre boutique. Si le problème persiste, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Vérifiez l’espace de stockage disponible sur l’appareil et libérez-en en supprimant d’autres fichiers ou applications : la configuration du stockage échoue immédiatement lorsque le disque ou le quota de stockage du navigateur est plein. N’utilisez pas l’option « Effacer les données de navigation » du navigateur pour faire de la place : elle supprime aussi les ventes WCPOS non envoyées.
2. Redémarrez WCPOS et réessayez la même action.
3. Sur le web, vérifiez que le navigateur autorise le stockage persistant pour le site : les fenêtres privées et les réglages bloquant toutes les données ne l’autorisent pas.
4. Si l’échec persiste, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance.
