## Signification {#what-this-means}

Une modification sur cet appareil est entrée en conflit avec une modification plus récente dans votre boutique. Rien n’est perdu.

Si **État de santé de la boutique → Base de données** affiche une modification mise en attente pour cet enregistrement, appuyez sur **Renvoyer** pour conserver la version de cet appareil, ou sur **Utiliser la version du serveur** pour conserver celle de la boutique. Sinon, vous n’avez rien à faire : le conflit a déjà été résolu.

## Vos données {#your-data}

Rien n’est perdu. Lorsqu’une modification est mise en attente, votre boutique conserve sa version et cet appareil conserve sa modification jusqu’à ce que vous choisissiez laquelle garder ; les modifications ultérieures de cet enregistrement attendent sur cet appareil jusque-là. N’effacez pas les données de cet appareil tant qu’une modification est mise en attente : l’effacement la supprime.

## Dépannage {#troubleshoot}

1. Ouvrez **État de santé de la boutique → Base de données**. Une modification mise en attente figure dans un panneau commençant par **« 1 modification a été mise en attente »** (ou **« … modifications ont été mises en attente »**), avec l’enregistrement auquel elle se rapporte.
2. Si plus aucune modification n’est en attente pour cet enregistrement, le conflit a déjà été résolu, ici ou dans un autre onglet, et vous n’avez rien à faire. Un conflit de commande que WCPOS résout automatiquement en renvoyant la version de cet appareil est consigné sous le code [SYNC222](/error-codes/SYNC222).
3. Si une modification est mise en attente, appuyez sur **Ouvrir l’enregistrement** (lorsque ce bouton est affiché) pour voir la version de cet appareil, puis comparez-la au même enregistrement dans WP Admin (l’intervention d’un administrateur du site peut être nécessaire).
4. Pour conserver la version de cet appareil, appuyez sur **Renvoyer** : la modification est renvoyée et remplace les valeurs de la boutique pour les champs modifiés sur cet appareil. Pour conserver la version de la boutique, appuyez sur **Utiliser la version du serveur** (certaines lignes indiquent **Abandonner la modification de l’appareil**), puis confirmez : la modification de cet appareil est abandonnée. Les modifications ultérieures de cet enregistrement attendent votre choix.
5. Des conflits fréquents sur les mêmes enregistrements indiquent généralement que deux personnes modifient les mêmes données en parallèle, par exemple le stock sur le terminal et dans WP Admin. Convenez de l’endroit où chaque type de modification doit être effectué.
