## Ce que cela signifie {#what-this-means}

WCPOS Pro est désactivé car sa version ne correspond pas à celle de WCPOS.

Mettez à jour le composant WCPOS ou WCPOS Pro indiqué pour que les deux versions soient compatibles.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, adressez-vous à la personne qui gère votre site WordPress.

## Dépannage {#troubleshoot}

1. Vérifiez les versions des deux extensions dans WP Admin → Extensions — l’entrée du journal indique laquelle de WCPOS ou WCPOS Pro est en retard.
2. Mettez à jour la plus ancienne ; installer les dernières versions des deux extensions résout ce décalage.
3. Si les mises à jour Pro ne sont pas proposées, le système de mise à jour n’est peut-être pas autorisé (voir LICENSE301) — corrigez d’abord ce problème, puis effectuez la mise à jour.
