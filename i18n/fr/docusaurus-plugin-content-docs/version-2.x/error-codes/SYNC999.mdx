## Signification {#what-this-means}

La synchronisation a rencontré un problème inattendu.

Vérifiez que l’action indiquée dans cette entrée s’est terminée ; sinon, répétez-la. Si cela se reproduit, appuyez sur **Copier les informations de débogage** et transmettez-les à l’assistance.

## Vos données {#your-data}

N’effacez pas les données de cet appareil — il peut contenir des modifications que votre boutique n’a pas encore reçues. Si l’action indiquée dans l’entrée ne s’est pas terminée, répétez-la.

## Dépannage {#troubleshoot}

1. Développez l’entrée du journal et repérez l’action indiquée. Vérifiez qu’elle s’est terminée — pour une sauvegarde, ouvrez la commande ou l’enregistrement et vérifiez que la modification apparaît. Si c’est le cas, WCPOS l’envoie automatiquement ; laissez-le faire.
2. Si l’action ne s’est pas terminée, répétez-la. Si l’entrée du journal indique que la modification n’a jamais été enregistrée sur cet appareil, rien n’a été conservé.
3. Notez le code et toute raison indiquée dans l’entrée du journal : un code 999 signifie que la cause précise n’a pas encore de code dédié. Ce contexte est donc exactement ce dont l’assistance a besoin.
4. Si cela se reproduit, appuyez sur **Copier les informations de débogage** dans l’onglet **Journaux** et transmettez-les à l’assistance — ce signalement permettra d’ajouter un code spécifique.
