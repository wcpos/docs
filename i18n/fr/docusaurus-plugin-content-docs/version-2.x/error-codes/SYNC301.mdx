## Signification {#what-this-means}

La liste des modifications de votre boutique a évolué de manière inattendue ; WCPOS la vérifie donc à nouveau automatiquement. Rien n’est perdu.

Vous n’avez rien à faire — poursuivez vos ventes. WCPOS vérifie à nouveau les modifications de votre boutique automatiquement. Si les prix ou les stocks semblent toujours obsolètes, appuyez sur **Tout vérifier maintenant** dans **État de la boutique → Base de données**.

## Vos données {#your-data}

Rien n’est perdu et aucune donnée de cet appareil n’est en danger. Tant que la nouvelle vérification n’est pas terminée, certains prix ou stocks sur cet appareil peuvent être obsolètes.

## Dépannage {#troubleshoot}

1. Poursuivez vos ventes — aucune donnée de cet appareil n’est perdue et la nouvelle vérification s’effectue automatiquement. L’entrée du journal peut préciser ce qui a changé — par exemple, certaines modifications de la boutique ont été ignorées, ou la liste de la boutique est revenue en arrière. Dans les deux cas, cela peut concerner n’importe quel type de données.
2. Si les prix ou les stocks semblent toujours obsolètes, ouvrez **État de la boutique → Base de données** et appuyez sur **Tout vérifier maintenant**.
3. Si un enregistrement semble toujours incorrect après cette vérification, ou si ce code continue de réapparaître, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance. N’effacez pas les données pour résoudre le problème.
