## Signification {#what-this-means}

Le jeton de connexion dépasse la taille acceptée par ce serveur.

Le serveur a refusé le jeton de connexion en raison de sa taille : une erreur 400 lorsqu’il est transmis dans l’en-tête Authorization, ou une erreur 414 lorsqu’il est transmis dans l’URL. Aucun encodage côté client ne peut le réduire : il faut augmenter les limites de taille des en-têtes ou des URL du serveur, ou réduire la taille du jeton.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée.

## Dépannage {#troubleshoot}

1. Sur Apache, augmentez LimitRequestFieldSize (transmission par en-tête) ou LimitRequestLine (transmission par URL) dans la configuration du vhost.
2. Sur nginx, augmentez large_client_header_buffers.
3. Si le serveur est derrière un proxy ou un CDN, la limite peut se situer à ce niveau : vérifiez les deux.
4. Si les limites ne peuvent pas être modifiées, contactez l’assistance pour obtenir un jeton plus petit pour ce site.
