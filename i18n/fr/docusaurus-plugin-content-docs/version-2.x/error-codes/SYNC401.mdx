## Signification {#what-this-means}

Une tâche de synchronisation en arrière-plan s’est arrêtée de manière inattendue avant de se terminer.

Vous n’avez rien à faire — le PDV redémarre automatiquement ces tâches et rien n’est perdu. Si ce code continue d’apparaître, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance.

## Vos données {#your-data}

Rien n’est perdu — aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Vous n’avez rien à faire à la première apparition : le PDV redémarre automatiquement la tâche en arrière-plan qui s’est arrêtée et aucune donnée de commande n’est concernée.
2. Si le code réapparaît dans les minutes qui suivent, rechargez l’application une fois pour que le moteur de synchronisation reparte sur de bonnes bases.
3. S’il réapparaît encore, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance — l’arrêt récurrent d’une tâche est un défaut de l’application à signaler, pas un problème de la boutique.
