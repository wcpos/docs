## Ce que cela signifie {#what-this-means}

Une erreur inattendue s’est produite lors du paiement.

Vérifiez la commande dans l’administration de votre boutique avant de débiter à nouveau le client. Exportez les diagnostics et contactez l’assistance si le problème se reproduit.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé : vérifiez-le avant de réessayer. Si le problème persiste, exportez les diagnostics et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Dans WP Admin, vérifiez la commande dans WooCommerce → Commandes avant de débiter à nouveau le client.
2. Développez l’entrée du journal et notez le code d’événement ainsi que toute valeur serverCode : ce code générique signifie qu’aucun code spécifique n’est encore associé à la cause.
3. Si le problème se reproduit, exportez les informations de débogage et contactez l’assistance.
