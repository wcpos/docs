## Ce que cela signifie {#what-this-means}

Un problème inattendu est survenu lors du paiement.

Vérifiez la commande dans l’administration de votre boutique avant de débiter à nouveau le client. Exportez les données de diagnostic et contactez l’assistance si le problème se reproduit.

## Vos données {#your-data}

Le résultat de l’opération n’a pas pu être confirmé — vérifiez-le avant de réessayer. Si le problème persiste, exportez les données de diagnostic et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Vérifiez la commande dans WooCommerce → Commandes dans WP Admin avant de débiter à nouveau le client.
2. Développez l’entrée du journal et notez le code de l’événement ainsi que tout serverCode — ce code générique signifie que la cause ne dispose pas encore d’un code dédié.
3. Si le problème se reproduit, exportez les informations de débogage et contactez l’assistance.
