## Ce que cela signifie {#what-this-means}

WCPOS n'a pas pu confirmer que la tâche d'impression était terminée.

Vérifiez l'imprimante avant de réessayer pour éviter d'imprimer le reçu deux fois.

## Vos données {#your-data}

Les données de vente et de commande sont intactes et inchangées : seul le résultat de l'impression n'est pas confirmé.

## Dépannage {#troubleshoot}

1. Regardez l'imprimante avant de réessayer : l'impression peut avoir eu lieu même si aucune confirmation n'a été reçue. Réessayer sans vérifier risque d'imprimer le reçu deux fois.
2. Vérifiez le papier, les capots et les voyants d'erreur de l'imprimante.
3. Si rien ne s'est imprimé, réessayez une fois : appuyez sur **Imprimer le reçu** (ou **Imprimer à nouveau**) sur le reçu affiché après la vente. Si vous avez quitté ce reçu, dans WCPOS Pro, ouvrez **Commandes**, utilisez l'action **Reçu** de la commande et appuyez sur **Imprimer le reçu** ; sans Pro, le reçu ne peut pas être rouvert une fois que vous l'avez quitté.
4. Si les échecs se répètent, éteignez puis rallumez l'imprimante et vérifiez sa connexion à la caisse.
