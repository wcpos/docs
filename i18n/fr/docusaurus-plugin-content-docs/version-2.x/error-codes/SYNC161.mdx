## Signification {#what-this-means}

Le stockage de cet appareil ne répond plus. L’enregistrement des données est donc suspendu.

Redémarrez WCPOS (sur le web, rechargez l’onglet), puis vérifiez que votre dernière vente ou modification a été enregistrée : une modification effectuée dans les secondes précédant l’arrêt du stockage n’a peut-être pas été écrite. N’effacez pas les données de cet appareil. Si le problème persiste, contactez l’assistance.

## Vos données {#your-data}

N’effacez pas les données de cet appareil : il peut contenir des ventes qui ne sont pas encore parvenues à votre boutique. Si le problème persiste, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Redémarrez WCPOS : fermez puis rouvrez l’application ; sur le web, rechargez l’onglet plutôt que de le fermer. Cela rétablit la connexion à la base de données locale dans presque tous les cas.
2. Après le redémarrage, vérifiez que votre dernière vente ou modification a été enregistrée : une modification effectuée dans les secondes précédant l’échec n’a peut-être pas été écrite. Si elle est absente, saisissez-la à nouveau.
3. Sur le web, n’utilisez pas le terminal dans une fenêtre de navigation privée et évitez les extensions de nettoyage du stockage trop agressives : les deux peuvent interrompre le stockage local en pleine session, et fermer une fenêtre privée supprime tout ce qui y est stocké, y compris les ventes non envoyées. Si vous en utilisez une actuellement, gardez-la ouverte jusqu’à ce que **État de santé de la boutique → Base de données** affiche 0 **modifications en attente d’envoi**, sans [panneau vous demandant une décision](../support/store-health.mdx#needs-attention) et sans commande ouverte encore non synchronisée ([Synchroniser la commande](../pos/cart/open-orders.mdx#sync-order)).
4. Si le problème revient régulièrement sur le même appareil, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance en précisant l’état de l’appareil au moment du problème (mise en veille, changement d’onglet, mémoire insuffisante).
