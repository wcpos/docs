## Ce que cela signifie {#what-this-means}

Cet appareil a manqué de mémoire, et la dernière action ne s’est peut-être pas terminée.

Fermez les autres applications ou onglets, redémarrez WCPOS, puis vérifiez que votre dernière vente ou modification a été enregistrée. Sinon, recommencez-la.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé : vérifiez avant de réessayer. Si vous enregistriez une vente ou une modification au moment du manque de mémoire, vérifiez qu’elle a été enregistrée avant de recommencer.

## Dépannage {#troubleshoot}

1. Fermez les autres applications ou onglets du navigateur : WCPOS partage la mémoire de l’appareil avec tous les autres programmes en cours d’exécution.
2. Redémarrez WCPOS.
3. Vérifiez que votre dernière vente ou modification a été enregistrée avant de recommencer : consultez **État de santé de la boutique → Base de données** (une vente comptabilisée dans **modifications en attente d’envoi** est enregistrée et son envoi est toujours en cours), le panier, ainsi que Commandes (WCPOS Pro) ou **WooCommerce → Commandes**. Si une carte a été utilisée, vérifiez aussi le terminal ou le prestataire de paiement ; si le client a été débité, ne le débitez pas à nouveau. Recommencez une seule fois, uniquement si l’enregistrement n’a vraiment pas eu lieu.
4. Si une action précise provoque systématiquement un manque de mémoire, notez laquelle, appuyez sur **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance.
5. Si cela se produit quotidiennement sur le même appareil, ses capacités sont peut-être insuffisantes pour le catalogue. Signalez-le pour que l’assistance puisse le confirmer.
