## Ce que cela signifie {#what-this-means}

WCPOS n’a pas pu terminer son démarrage.

À la caisse, cela se traduit par un écran vide ou figé, ou par un indicateur de chargement qui ne disparaît jamais. Redémarrez WCPOS (sur le web, rechargez l’onglet) — un échec de démarrage se résout souvent de lui-même. Si l’application ne démarre toujours pas, contactez le support avant d’effacer quoi que ce soit.

:::warning N’effacez pas les données de cet appareil
Cet appareil peut contenir des ventes qui n’ont pas encore été transmises à votre boutique — par exemple, des ventes réalisées hors ligne. Tant que WCPOS ne peut pas démarrer, elles ne peuvent pas être envoyées : effacer les données locales, vous déconnecter ou réinstaller l’application les supprimerait donc définitivement. Contactez le support avant d’effacer quoi que ce soit.
:::

## Vos données {#your-data}

N’effacez pas les données de cet appareil — il peut contenir des modifications qui n’ont pas encore été transmises à votre boutique. Les données de votre boutique sont en sécurité et ne sont pas affectées.

## Dépannage {#troubleshoot}

1. Redémarrez WCPOS une fois ; sur le web, rechargez complètement l’onglet — un échec de démarrage temporaire se résout souvent de lui-même.
2. Si l’application ne démarre toujours pas, contactez le support avant d’effacer quoi que ce soit. Envoyez les informations obtenues avec **Copier les informations de débogage** dans l’onglet **Journaux** si WCPOS s’ouvre suffisamment pour vous permettre d’y accéder — sinon, envoyez l’erreur affichée dans la console du navigateur (outils de développement), ou dans **Avancé → Afficher/Masquer les outils de développement** de l’application de bureau.
3. En attendant, n’effacez pas les données locales, ne vous déconnectez pas et ne réinstallez pas l’application — le support vous indiquera si des données sur cet appareil doivent d’abord être récupérées.
