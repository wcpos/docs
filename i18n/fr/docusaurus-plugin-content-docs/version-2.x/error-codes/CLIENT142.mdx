## Ce que cela signifie {#what-this-means}

L’index de recherche n’a pas répondu à temps ; WCPOS a donc recherché directement dans le catalogue.

L’index de recherche local était encore en cours de création ou ne pouvait pas répondre. Sur le Web, cela se produit généralement lorsque l’onglet du PDV est resté en arrière-plan. Sur ordinateur et mobile, cela arrive généralement juste après une synchronisation importante ou dans les instants qui suivent le redémarrage de l’application, pendant le rechargement de l’index enregistré. Les recherches aboutissent tout de même grâce à une analyse directe des données de cet appareil, puis repassent automatiquement par l’index dès qu’il répond.

## Vos données {#your-data}

Aucune donnée de la boutique n’a été modifiée et votre recherche a tout de même abouti : elle a été effectuée directement dans les données de cet appareil plutôt qu’avec l’index. Les résultats peuvent simplement s’afficher un peu plus lentement jusqu’à ce que l’index prenne de nouveau le relais.

## Dépannage {#troubleshoot}

1. En général, aucune action n’est nécessaire : les résultats de recherche continuent de s’afficher et l’index reprend automatiquement le relais dès qu’il répond.
2. Sur le Web, gardez le PDV dans sa propre fenêtre plutôt que dans un onglet en arrière-plan.
3. Si les recherches restent lentes ou si ce code continue d’apparaître, rechargez l’application une fois. Sur le Web, rechargez l’onglet du navigateur ; sur ordinateur et mobile, fermez puis rouvrez l’application.
4. Si le code réapparaît, exportez les informations de débogage et contactez l’assistance.
