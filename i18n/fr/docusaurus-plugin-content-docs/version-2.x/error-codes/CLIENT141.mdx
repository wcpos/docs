## Ce que cela signifie {#what-this-means}

La recherche a affiché des résultats qui ne correspondent pas à vos produits ; WCPOS les a donc masqués.

Aucune action n’est nécessaire, sauf si les résultats de recherche semblent toujours incorrects. Dans ce cas, rechargez WCPOS.

Pour afficher rapidement les résultats, WCPOS conserve un index de recherche local pour les listes consultées — produits, clients, commandes, entre autres. Une vérification automatique a détecté dans cet index des entrées qui ne correspondaient pas réellement aux termes saisis. Les résultats non concordants ont été immédiatement masqués. L’application peut également reconstruire l’index automatiquement, mais une seule fois par liste et par session ; cette reconstruction n’est donc pas garantie.

## Vos données {#your-data}

Aucune donnée de la boutique n’a été modifiée. Seul l’index de recherche local, dérivé des données déjà présentes sur cet appareil, est concerné : masquer un résultat non concordant modifie ce qu’affiche la recherche, jamais l’enregistrement sous-jacent.

## Dépannage {#troubleshoot}

1. Aucune action n’est nécessaire, sauf si les résultats semblent toujours incorrects : vous pouvez continuer à vendre normalement. Pour vérifier, relancez la recherche indiquée dans l’entrée du journal (son contexte consigne le terme recherché) et assurez-vous que les résultats correspondent désormais aux termes saisis et qu’aucun résultat attendu ne manque.
2. Si la recherche affiche toujours des résultats incorrects ou ne trouve pas un produit, un client ou une commande dont vous savez qu’il existe, rechargez l’application. Sur le Web, rechargez l’onglet du navigateur ; sur ordinateur et mobile, fermez puis rouvrez l’application. L’index pourra ainsi être reconstruit lors de la prochaine détection du problème.
3. Si le code réapparaît après le rechargement, utilisez **Copier les informations de débogage** dans l’onglet **Journaux**, puis contactez l’assistance : le contexte de l’entrée indique la liste concernée et la recherche qui a déclenché le problème.
