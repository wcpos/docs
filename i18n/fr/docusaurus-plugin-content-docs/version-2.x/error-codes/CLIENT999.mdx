## Ce que cela signifie {#what-this-means}

WCPOS a rencontré une erreur inattendue.

Vérifiez si votre dernière action a abouti avant de réessayer ; pour une vente, ouvrez la commande et vérifiez son état. Si l’erreur se répète, appuyez sur **Copier les informations de débogage** et transmettez-les à l’assistance WCPOS.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé : vérifiez avant de réessayer. Si l’erreur se répète, utilisez **Copier les informations de débogage** dans l’onglet **Journaux** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Vérifiez si votre dernière action a abouti avant de réessayer ; pour une vente, ouvrez la commande et vérifiez son état ; pour un paiement, vérifiez aussi le terminal ou le prestataire. Si elle n’a pas abouti, réessayez une fois.
2. Dépliez l’entrée du journal et notez le code de l’événement ainsi que son contexte. Un code 999 signifie que cette erreur n’a pas encore de code dédié, et ces informations permettent de l’identifier.
3. Si l’erreur se répète, appuyez sur **Copier les informations de débogage** dans l’onglet **Journaux** et transmettez-les à l’assistance WCPOS : votre signalement permettra d’ajouter un code spécifique.
