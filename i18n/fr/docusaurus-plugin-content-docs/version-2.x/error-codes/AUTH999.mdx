## Signification {#what-this-means}

Un problème inattendu est survenu lors de la connexion ou du maintien de la session.

Réessayez l’action une fois. Si le problème se reproduit, déconnectez-vous, puis reconnectez-vous, utilisez **Copier les informations de débogage** et contactez l’assistance.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée. Si le problème persiste, utilisez **Copier les informations de débogage** et contactez l’assistance WCPOS.

## Dépannage {#troubleshoot}

1. Réessayez l’action une fois ; si elle échoue à nouveau, déconnectez-vous, puis reconnectez-vous.
2. Développez l’entrée du journal et notez le code de l’événement ainsi que tout serverCode : un code 999 signifie que la cause n’a pas encore de code dédié, et ce contexte permet de l’identifier.
3. Si le problème se reproduit, utilisez Copier les informations de débogage et contactez l’assistance.
