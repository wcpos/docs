# Codes d’erreur {#error-codes}

Lorsque WCPOS rencontre un problème, il affiche un code d’erreur qui aide à l’identifier. À partir de la version **v1.10.0**, les codes suivent le format **domaine + trois chiffres** — par exemple `SYNC131` ou `AUTH311`. Le domaine indique la partie du PDV concernée ; le numéro identifie la situation précise. Chaque code dispose de sa propre page expliquant sa signification, les mesures à prendre et les conséquences pour vos données.

Dans le PDV, les codes d’erreur apparaissent dans **État de la boutique → Journaux** : développez une ligne et utilisez le lien **Aide** pour accéder directement à la page du code dans cette documentation.

## Domaines d’erreur (v1.10.0+) {#error-domains}

| Domaine | Partie concernée |
|--------|------|
| [`AUTH`](#auth) | Connexion, sessions et jetons |
| [`CHECKOUT`](#checkout) | Finalisation des commandes en caisse |
| [`CLIENT`](#client) | Application PDV et stockage local |
| [`DISPLAY`](#display) | Écran client |
| [`HOST`](#host) | Hébergement et règles de pare-feu bloquant le PDV |
| [`LICENSE`](#license) | Activation et validation de la licence Pro |
| [`PAYMENT`](#payment) | Passerelles de paiement et terminaux |
| [`PRINT`](#print) | Impression des reçus |
| [`PRODUCT`](#product) | Données des produits et opérations sur le catalogue |
| [`REGISTER`](#register) | Tiroir-caisse, sessions de caisse et comptages |
| [`SYNC`](#sync) | Synchronisation entre le PDV et votre boutique |

Retrouvez votre code ci-dessous ou recherchez-le.

Les codes se terminant par `999` regroupent les situations du domaine qui ne disposent pas encore d’un code spécifique.

## Tous les codes {#every-code}

### AUTH : connexion, sessions et jetons {#auth}

|------|---------------|

| [AUTH321](./AUTH321.mdx) | WooCommerce n’est pas actif sur ce site ; WCPOS ne peut donc pas se connecter. |
| [AUTH331](./AUTH331.mdx) | L’extension WCPOS de cette boutique est trop ancienne pour cette version de l’application. |
| [AUTH341](./AUTH341.mdx) | Cette boutique indique la même identité qu’une boutique déjà enregistrée sur cet appareil. |

## Codes antérieurs à v1.10.0 {#legacy-codes}

Les codes tels que `API04001` proviennent de versions antérieures à v1.10.0 ; cette version ne les produit jamais. Vous pouvez encore en voir dans une entrée de journal conservée depuis avant votre mise à jour, ou dans une ancienne discussion d’assistance. Sélectionnez **1.x** dans le menu des versions pour les consulter.
