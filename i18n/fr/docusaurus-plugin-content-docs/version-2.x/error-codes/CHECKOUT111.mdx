## Signification {#what-this-means}

Cette modification n’a pas pu être appliquée au panier, qui reste inchangé.

L’article, les frais, la ligne de livraison ou le code promo n’ont pas été ajoutés et rien n’a été supprimé. Réessayez l’action.

## Vos données {#your-data}

La commande elle-même est préservée et inchangée.

## Dépannage {#troubleshoot}

1. Essayez à nouveau d’ajouter l’article, les frais, la ligne de livraison ou le code promo : le panier lui-même est inchangé.
2. Si l’ajout du même article échoue systématiquement, essayez une fois avec un autre produit : si un seul article pose problème, sa fiche est en cause ; si tous les ajouts échouent, le problème vient de l’appareil.
3. Si l’échec persiste, redémarrez WCPOS ; exportez les informations de débogage et contactez l’assistance si le problème continue.
