## Signification {#what-this-means}

Le paiement n’a pas abouti et le panier est préservé pour une nouvelle tentative.

Vérifiez le panier et réessayez le paiement ; le contenu actuel du panier a été conservé.

## Vos données {#your-data}

La commande elle-même est préservée et inchangée.

## Dépannage {#troubleshoot}

**À la caisse** — pour le caissier :

1. Vérifiez le panier — il est inchangé — et réessayez le paiement.
2. Si le paiement échoue à nouveau, développez l’entrée du journal dans État de santé de la boutique → Journaux : le serverCode et le statut indiquent si la boutique a refusé la commande et pourquoi.
3. Si la raison mentionne une ligne d’article précise, supprimez-la, terminez la vente et examinez ensuite le produit concerné.

**Sur la boutique** — pour l’administrateur du site : un échec répété avec un statut de classe 500 indique un problème du site ; recherchez dans WooCommerce → État → Journaux une erreur PHP à l’heure de l’échec.
