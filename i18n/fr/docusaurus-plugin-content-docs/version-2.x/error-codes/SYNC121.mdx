## Signification {#what-this-means}

Votre boutique est actuellement injoignable.

Vous n’avez rien à faire : continuez à vendre. Les modifications sont envoyées automatiquement lorsque la connexion est rétablie. Si le problème dure, vérifiez la connexion de cet appareil et si le site web de votre boutique se charge.

## Vos données {#your-data}

N’effacez pas les données de cet appareil : il peut contenir des modifications que votre boutique n’a pas encore reçues. Elles sont envoyées automatiquement dès que votre boutique répond.

## Dépannage {#troubleshoot}

1. Continuez à vendre : les ventes sont enregistrées sur cet appareil et envoyées automatiquement dès que la boutique répond.
2. Vérifiez que le terminal lui-même est connecté : un autre site web se charge-t-il depuis cet appareil ?
3. Ouvrez le site web de votre boutique dans un onglet du navigateur sur le même appareil. S’il ne se charge pas non plus, c’est le site ou son hébergement qui est en panne, pas le PDV.
4. **Pour la personne qui gère le réseau de cet appareil :** si le site se charge mais que le PDV reste hors ligne, un élément entre les deux bloque les requêtes API : un VPN, un pare-feu, un bloqueur de publicités ou une extension de sécurité. Les outils de développement du navigateur (onglet Réseau), ou **Avancé → Afficher/masquer les outils de développement** dans l’application de bureau, indiquent quelle requête échoue.
