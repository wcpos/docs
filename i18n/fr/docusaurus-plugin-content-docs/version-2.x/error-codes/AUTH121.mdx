## Ce que cela signifie {#what-this-means}

Le compte connecté à la boutique ne correspond pas au caissier de cette caisse.

Chaque caissier dispose de ses propres données de caisse. Travailler avec un autre compte risque donc d’attribuer les commandes au mauvais compte. Déconnectez-vous, puis connectez-vous avec le compte du caissier concerné.

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est affectée.

## Dépannage {#troubleshoot}

1. Le PDV ferme automatiquement la session pour protéger les données de chaque caissier : aucune donnée de commande n’est mélangée entre les comptes.
2. Reconnectez-vous avec le compte du caissier concerné ; travailler avec un autre compte risque d’attribuer les commandes au mauvais compte.
3. Si plusieurs caissiers partagent les caisses, intégrez le changement de compte à la procédure de relève.
