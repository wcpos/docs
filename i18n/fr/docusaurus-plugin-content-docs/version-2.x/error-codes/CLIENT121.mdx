## Ce que cela signifie {#what-this-means}

Ce navigateur ne permet qu’à un seul onglet d’envoyer des modifications à la fois.

WCPOS ne génère plus ce code : un seul onglet exécute le PDV. Dans un deuxième onglet, le message **Le PDV est ouvert dans un autre onglet** s’affiche ; appuyez sur **Prendre le contrôle ici** pour continuer dans cet onglet, ou revenez au premier. Consultez [Si le PDV ne démarre pas](../getting-started/index.mdx#wont-start).

## Vos données {#your-data}

Aucune donnée de commande ou de produit n’est concernée.

## Dépannage {#troubleshoot}

1. Utilisez le PDV dans un seul onglet. Si un onglet affiche **Le PDV est ouvert dans un autre onglet**, appuyez sur **Prendre le contrôle ici** pour continuer dans cet onglet.
2. Ce navigateur (ou une fenêtre privée) ne dispose pas de la fonctionnalité de coordination des onglets privilégiée par le PDV ; il utilise donc un seul onglet pour la synchronisation. Aucune correction n’est nécessaire.
