## Ce que cela signifie {#what-this-means}

WCPOS a mis trop de requêtes en file d’attente à la fois et en a abandonné certaines.

Il s’agit généralement d’un défaut de l’application plutôt que d’un problème de la boutique. Redémarrez WCPOS ; si le code réapparaît, exportez les diagnostics et contactez l’assistance.

## Vos données {#your-data}

Les requêtes déjà terminées sont sans risque. Une requête abandonnée n’a tout simplement pas été exécutée. Avant de continuer, vérifiez donc que l’action que vous étiez en train d’effectuer a bien abouti.

## Dépannage {#troubleshoot}

1. Patientez quelques secondes : la file se vide d’elle-même et les requêtes obsolètes sont automatiquement abandonnées. Vérifiez si l’action en cours a abouti et réessayez uniquement si ce n’est pas le cas.
2. Si le problème se reproduit au cours de la même session, redémarrez WCPOS ; le redémarrage vide la file d’attente.
3. Il s’agit généralement d’un défaut de l’application plutôt que d’un problème de la boutique. Si le problème persiste, exportez les informations de débogage et contactez l’assistance : le contexte de l’entrée indique aux développeurs quelles requêtes ont saturé la file d’attente.
