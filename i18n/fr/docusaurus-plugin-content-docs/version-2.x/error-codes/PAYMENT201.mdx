## Ce que cela signifie {#what-this-means}

WCPOS n’a pas pu confirmer si le terminal avait prélevé le paiement.

Vérifiez le terminal de paiement avant de tenter un nouveau débit et contactez le prestataire de paiement si le résultat reste incertain.

## Vos données {#your-data}

Le résultat n’a pas pu être confirmé — vérifiez avant de réessayer. Si le problème persiste, contactez votre prestataire de paiement.

## Dépannage {#troubleshoot}

1. Ne repassez pas encore la carte.
2. Consultez l’écran du terminal, puis le tableau de bord de votre prestataire de paiement — c’est l’enregistrement du prestataire qui fait foi pour savoir si le débit a eu lieu.
3. Si vous avez accès à WP Admin (ou demandez au propriétaire de la boutique), consultez WooCommerce → Commandes — un paiement réussi peut déjà y être enregistré.
4. N’encaissez à nouveau le paiement qu’une fois que le tableau de bord du prestataire indique l’absence de débit.
5. Si le débit apparaît comme en attente ou incertain, contactez le prestataire de paiement avant d’agir.
