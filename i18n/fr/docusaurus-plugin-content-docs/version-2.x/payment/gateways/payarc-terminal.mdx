# Passerelle de paiement PayArc Terminal {#payarc-terminal-gateway}

PayArc Terminal envoie une vente de la caisse à un terminal PayArc PAX. Le client paie sur le terminal, puis la caisse enregistre le paiement dès que PayArc le confirme.

Cette page commence par l’utilisation en caisse. Pour configurer la passerelle de paiement, consultez [Configurer PayArc Terminal](#setup).

:::info Fonctionnalité Pro
PayArc Terminal nécessite [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0 ou une version ultérieure.
:::

## Encaisser un paiement par carte {#take-payment}

:::note Ouvrez d’abord la caisse
Lorsque l’option **Ouvrir et fermer la caisse** est activée, la caisse n’enregistre aucun paiement tant qu’elle est fermée. Un paiement par carte déjà encaissé devrait alors être remboursé. Consultez [Caisses](../../settings/wp-admin/registers.mdx#one-register) pour ce réglage.
:::

Appuyez sur **Paiement** dans le panier. PayArc Terminal apparaît sous forme de tuile dans l’onglet **Paiements**, à côté des autres moyens de paiement.

1. Appuyez sur la tuile **PayArc Terminal**.
2. Vérifiez le terminal indiqué au-dessus du pavé numérique : **Terminal : …**. Si vous avez plusieurs terminaux, appuyez sur **Changer** et sélectionnez celui de votre comptoir. La caisse mémorise votre choix pour la prochaine fois.
3. Pour encaisser une partie du solde par carte, saisissez le montant. Le reste demeure dû et pourra être réglé par un autre paiement.
4. Appuyez sur **Envoyer … à PayArc Terminal**. La caisse affiche **Sur le terminal** avec quatre étapes : **Envoyé**, **Sur le terminal**, **Approuvé** et **Capturé**.
5. Le client paie sur le terminal. Lorsque le paiement est capturé et qu’il ne reste rien à payer, le reçu s’ouvre. S’il reste un solde, encaissez-le avec une autre tuile.

Le bouton **Détails**, sous les étapes, ouvre un journal du paiement : l’heure de son envoi, celle de son arrivée sur le terminal et le montant approuvé. Le paiement conserve la marque de la carte, ses 4 derniers chiffres, son mode de lecture et le code d’autorisation de PayArc.

Le terminal ne propose pas de laisser un pourboire. Consultez [Pourboires](../../pos/checkout/tips.mdx) pour connaître les terminaux qui le proposent.

### Annuler un paiement {#cancel}

Appuyez sur **Annuler sur le terminal** avant que le client ne paie. La caisse attend la confirmation du terminal, puis affiche **Paiement annulé**.

Si la lecture de la carte a déjà commencé, PayArc peut refuser l’annulation et terminer le paiement ; la caisse continue de vérifier et affiche le résultat. Pendant l’attente, elle indique **Annulation — en attente de confirmation du terminal** et propose **Libérer ce paiement**. Cette action permet de régler la commande autrement pendant que votre boutique continue de vérifier le terminal.

:::warning
Libérer le paiement ne l’annule pas : le terminal peut encore l’encaisser. Vérifiez le résultat sur le terminal avant d’encaisser un autre paiement.
:::

## En cas de problème de paiement {#goes-wrong}

:::warning
**Le terminal a confirmé un montant différent ?** N’encaissez pas à nouveau le paiement. Vérifiez d’abord le terminal, la commande et le tableau de bord PayArc.
:::

<Accordion>
  <AccordionItem question="Échec du paiement : carte refusée">

  Appuyez sur **Réessayer** pour l’envoyer à nouveau au terminal, ou sur **Choisir un autre moyen** pour payer avec une autre tuile.

  </AccordionItem>
  <AccordionItem question="Échec du paiement avec un message de PayArc">

  PayArc a refusé la vente, par exemple parce que le terminal est éteint ou hors ligne. Vérifiez le terminal, puis appuyez sur **Réessayer**.

  </AccordionItem>
  <AccordionItem question="Délai dépassé — paiement annulé">

  Personne n’a payé dans les 5 minutes, ou le terminal attendait une carte qui n’a pas été présentée. Vérifiez le terminal, puis appuyez sur **Réessayer**.

  </AccordionItem>
  <AccordionItem question="La tuile PayArc Terminal est grisée">

  La caisse en indique la raison sous les tuiles. Consultez [Lorsqu’une tuile est indisponible](../index.mdx#unavailable-tiles) pour connaître toutes les raisons possibles.

  - **Aucun terminal configuré pour PayArc Terminal** — la boutique ne dispose d’aucun terminal pour cette passerelle de paiement. Un responsable en ajoute un à l’étape 4 de [Configurer PayArc Terminal](#setup).
  - **Utilisé par la commande #…** — le terminal traite le paiement d’une autre commande. Terminez ou annulez ce paiement, ou appuyez sur **Changer** et choisissez un autre terminal.
  - **Connexion requise** — la caisse est hors ligne. Un paiement par terminal passe par votre boutique : utilisez donc un autre moyen de paiement ou attendez le rétablissement de la connexion.

  </AccordionItem>
  <AccordionItem question="Connexion instable, nouvelles tentatives en cours">

  Ce message apparaît dans le journal **Détails**. La caisse continue de vérifier. Laissez l’écran ouvert : le paiement se poursuit sur le terminal.

  </AccordionItem>
  <AccordionItem question="Un paiement est bloqué, ou la caisse indique que le prestataire n’a pas répondu">

  Consultez [Lorsqu’un paiement par lecteur de carte est bloqué](../index.mdx#card-reader-problems).

  </AccordionItem>
  <AccordionItem question="Un paiement reste en attente trop longtemps">

  - Vérifiez l’écran du terminal et laissez l’écran de paiement ouvert
  - Au bout de **5 minutes**, la caisse s’arrête et affiche **Délai dépassé — paiement annulé**
  - Vérifiez le terminal, les notes de la commande et le tableau de bord PayArc avant d’encaisser à nouveau le paiement

  </AccordionItem>
  <AccordionItem question="Un paiement PayArc Terminal antérieur sur cette commande ne peut pas être consulté avec les identifiants PayArc actuels">

  - Encaissez le paiement autrement ou demandez à un responsable. La commande contient un paiement effectué avant un changement de mode ou d’identifiants
  - Le responsable vérifie ce paiement dans le tableau de bord PayArc, dans le mode utilisé pour l’encaisser
  - Pour utiliser à nouveau PayArc sur cette commande, le responsable rétablit ce mode dans PayArc et clique sur **Se connecter avec ces identifiants**, puis vous rechargez la page

  </AccordionItem>
</Accordion>

## Rembourser un paiement PayArc {#refunds}

Le remboursement est envoyé au terminal qui a encaissé la vente, pour la totalité ou une partie du montant.

1. Dans le PDV, ouvrez l’écran de remboursement de la commande. Consultez [Remboursements](../../pos/refunds.mdx).
2. Choisissez **Rembourser via PayArc Terminal** et appuyez sur **Effectuer le remboursement**.
3. PayArc envoie le remboursement au terminal, où il est approuvé ou refusé. Le remboursement reste en attente jusqu’à la réponse du terminal, et le résultat est ajouté aux notes de la commande.

Un remboursement dans WP Admin, avec le bouton **Rembourser … via PayArc Terminal** de WooCommerce, fonctionne de la même façon.

Si un remboursement reste en attente, vérifiez le tableau de bord PayArc avant de le relancer.

<details>
<summary>Si PayArc ne répond pas à un remboursement</summary>

Votre boutique renouvelle la requête toutes les 2 minutes, jusqu’à 5 fois, avec la même clé de requête, afin que PayArc traite chaque nouvelle tentative comme le même remboursement. Si elle ne reçoit toujours pas de réponse, elle invite le personnel à vérifier le tableau de bord PayArc.

</details>

<details>
<summary>Paiements encaissés avec une ancienne version</summary>

**Ce paiement PayArc a été encaissé par le panneau de paiement de commande propre à l’extension.** Le paiement a été encaissé par la version 0.1 de l’extension, avant WCPOS 2 : la passerelle de paiement ne peut donc pas le rembourser. Remboursez-le dans le tableau de bord PayArc ou sur le terminal, puis enregistrez-le dans WooCommerce avec **Rembourser … manuellement**.

</details>

## Configurer PayArc Terminal {#setup}

Un responsable configure la passerelle de paiement une seule fois dans WP Admin, puis choisit un terminal sur chaque caisse.

<details>
<summary>Avant la configuration : ce dont vous avez besoin</summary>

### Prérequis {#requirements}

PayArc fournit votre MID, votre ClientSecret et votre SecretKey, ainsi que le numéro de série d’un terminal configuré pour vous.

Votre boutique communique avec chaque terminal via PayArc sur Internet : aucun appairage n’est nécessaire et chaque caisse peut utiliser n’importe lequel de vos terminaux. Sans WCPOS Pro 2.0 ou une version ultérieure, l’extension affiche un avis dans WP Admin et n’ajoute rien au PDV.

<RequirementsList>
  <RequirementItem label="Compte PayArc">Un compte marchand avec accès à PayArc Connect V3</RequirementItem>
  <RequirementItem label="Matériel compatible">Un terminal PAX pris en charge par PayArc et associé à votre compte</RequirementItem>
  <RequirementItem label="Connexions">Connexion Internet uniquement. La boutique envoie chaque paiement à un terminal PAX identifié par son numéro de série, afin que chaque caisse puisse l’utiliser ; chaque caisse choisit son terminal au moment du paiement</RequirementItem>
  <RequirementItem label="WCPOS">WCPOS Pro 2.0 ou une version ultérieure, et la version 1.0 ou ultérieure de l’extension</RequirementItem>
  <RequirementItem label="Serveur">WooCommerce 7.0+, PHP 7.4+ et HTTPS pour le mode production</RequirementItem>
  <RequirementItem label="Devise">USD, CAD, GBP, EUR ou JPY</RequirementItem>
</RequirementsList>

</details>

<details>
<summary>Six étapes : installer, se connecter, ajouter votre terminal, activer la passerelle de paiement, choisir le terminal de chaque caisse</summary>

<Steps>
  <StepCard number="1" title="Installer PayArc Terminal for WooCommerce">

Téléchargez **payarc-terminal-for-woocommerce.zip**, version 1.0 ou ultérieure, depuis la [page des versions sur GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases), puis téléversez le fichier via `Extensions > Add Plugin`, puis **Téléverser une extension**. Activez l’extension.

`WP Admin > POS > Réglages > Extensions` peut encore proposer la version 0.1, conçue avant WCPOS 2. Vérifiez la version avant de l’installer depuis cette page.

  </StepCard>
  <StepCard number="2" title="Saisir vos identifiants PayArc">

1. Accédez à `WP Admin > WooCommerce > Réglages > Paiements` et ouvrez **PayArc Terminal**
2. Choisissez le **Mode** : `Live` est sélectionné par défaut. Utilisez `Test` uniquement avec les identifiants du tableau de bord de test PayArc et l’application PayArc Connect Test. Ne mélangez jamais les environnements
3. Renseignez le champ **E-mail de connexion PayArc** avec l’adresse e-mail que vous utilisez pour vous connecter à votre tableau de bord marchand PayArc
4. Renseignez le champ **MID PayArc** avec le MID figurant dans le profil marchand PayArc, et non l’ID du terminal
5. Renseignez **ClientSecret PayArc** depuis la section API du tableau de bord et **SecretKey PayArc / jeton porteur API** depuis le tableau de bord PayArc
6. Laissez le champ **Jeton porteur de rappel** vide, sauf si l’assistance PayArc vous en a fourni un

  </StepCard>
  <StepCard number="3" title="Se connecter">

Cliquez sur **Se connecter avec ces identifiants**. Si la connexion réussit, l’écran affiche **Connecté à PayArc** et vous demande de saisir ou de confirmer le numéro de série du terminal, puis d’enregistrer. S’il indique que les identifiants semblent appartenir à l’autre environnement, changez de **Mode** et reconnectez-vous.

:::note
Après toute modification du **Mode** ou d’un identifiant, cliquez à nouveau sur **Se connecter avec ces identifiants**, puis enregistrez. Une fois PayArc Terminal activé dans WCPOS (étape 5), l’enregistrement affiche une erreur tant que vous ne l’avez pas fait. Lorsqu’un paiement est en cours sur un terminal, vous ne pouvez modifier ni le mode, ni les identifiants, ni la connexion.
:::

  </StepCard>
  <StepCard number="4" title="Ajouter votre terminal">

1. Saisissez le **Numéro de série du terminal** PAX figurant sur l’étiquette **S/N** au dos de l’appareil, tel que configuré par PayArc pour votre compte
2. Choisissez les options **Type de paiement** et **Imprimer le reçu**
3. Vérifiez que l’**URL du webhook** utilise HTTPS. Transmettez-la à PayArc uniquement sur demande
4. Cliquez sur **Enregistrer les modifications**

La caisse propose ce terminal, ainsi que tous ceux que le registre des terminaux PayArc indique comme activés pour votre compte. **Se connecter** récupère le registre, et **Actualiser les terminaux** le récupère à nouveau. Un terminal marqué comme désactivé par PayArc n’est pas proposé, mais le numéro de série que vous avez saisi l’est toujours. Le mode production nécessite un site HTTPS.

  </StepCard>
  <StepCard number="5" title="Activer la passerelle de paiement dans WCPOS">

1. Accédez à `WP Admin > POS > Réglages > Validation de la commande`
2. Repérez **PayArc Terminal** dans la liste et activez son interrupteur **Activé**
3. La tuile apparaît en caisse au prochain chargement de la page

:::note
C’est le seul interrupteur à utiliser. L’interrupteur **Activé** de la liste des paiements WooCommerce n’a aucun effet, et PayArc Terminal n’est jamais proposé sur la page de paiement de votre boutique en ligne. Consultez [Réglages de la caisse](../../settings/wp-admin/checkout.mdx#enabling-a-gateway).
:::

  </StepCard>
  <StepCard number="6" title="Choisir le terminal de chaque caisse" isLast>

Sur chaque caisse, ouvrez **Réglages > Lecteurs de carte**. Vos terminaux PayArc sont répertoriés sous **Lecteurs intelligents**, à raison d’une ligne par terminal, tous marqués **En ligne** : PayArc n’indique pas si un terminal est allumé. Appuyez sur **Utiliser ce lecteur** pour celui de ce comptoir ; sa ligne affiche **Sélectionné**. Le caissier peut toujours appuyer sur **Changer** au moment du paiement.

Si vous n’avez qu’un terminal PayArc, aucun choix n’est nécessaire : il est déjà **Sélectionné** sur chaque caisse. Une ligne indiquant **Défini par la boutique** signifie que les caisses sont verrouillées sur le terminal par défaut de la boutique. Consultez [Choisir un lecteur intelligent](../../hardware/card-readers/index.mdx#smart-readers).

  </StepCard>
</Steps>

</details>

## Référence des réglages {#settings}

Tous les réglages de la page de la passerelle de paiement dans `WP Admin > WooCommerce > Réglages > Paiements > PayArc Terminal`.

<details>
<summary>Tous les réglages de PayArc Terminal</summary>

| Réglage | Fonction |
|---|---|
| **Titre** | Le nom de la tuile en caisse ; par défaut : `PayArc Terminal` |
| **Description** | La description du moyen de paiement ; par défaut : `Pay in person at a PayArc PAX terminal.` |
| **Mode** | `Live` (par défaut) ou `Test`. Le mode test nécessite les identifiants du tableau de bord de test PayArc et l’application PayArc Connect Test |
| **E-mail de connexion PayArc** | Votre adresse e-mail de connexion au tableau de bord marchand PayArc ; requise avant la connexion |
| **MID PayArc** | Le MID marchand figurant dans votre profil marchand PayArc, et non l’ID du terminal |
| **ClientSecret PayArc** | Le secret de la section API du tableau de bord ; stocké uniquement sur votre serveur |
| **SecretKey PayArc / jeton porteur API** | Le jeton du tableau de bord PayArc, utilisé pour se connecter et consulter le registre des terminaux |
| **Jeton porteur de rappel** | Facultatif. Renseignez-le uniquement si l’assistance PayArc vous en a fourni un |
| **Connexion PayArc** | Boutons **Se connecter avec ces identifiants**, **Actualiser les terminaux** et **Se déconnecter** |
| **Numéro de série du terminal** | Le S/N PAX configuré par PayArc pour votre compte. Requis pour les paiements |
| **Type de paiement** | `CREDIT` (par défaut) ou `DEBIT` |
| **Imprimer le reçu** | Impression sur le terminal : `0 - No receipt` (par défaut), `1 - Merchant receipt`, `2 - Customer receipt` ou `3 - Both receipts` |
| **URL du webhook** | Adresse de rappel en lecture seule. Vérifiez qu’elle utilise HTTPS ; transmettez-la à PayArc uniquement sur demande |
| **Diagnostics PayArc** | Informations de connexion et bouton **Valider les réglages** ; les secrets ne sont jamais affichés |

Les champs de secret enregistrés n’affichent que les 4 derniers caractères. Laissez un champ de secret vide pour conserver la valeur enregistrée.

Le tableau **Diagnostics PayArc** affiche le mode, les points de terminaison PayArc, si l’e-mail de connexion et le jeton d’accès Connect sont renseignés, le MID, l’ID du locataire et le numéro de série du terminal masqués, le nombre de terminaux trouvés, l’URL du webhook, l’heure du dernier rappel et la dernière erreur PayArc. **Valider les réglages** vérifie les réglages enregistrés et répertorie les éléments manquants.

**Se déconnecter** efface la connexion PayArc enregistrée, la liste des terminaux et le **Numéro de série du terminal**. Vos identifiants sont conservés pour vous permettre de vous reconnecter rapidement. Vérifiez le numéro de série avant d’enregistrer.

</details>

## Journaux {#logs}

Lorsque vous demandez de l’aide, transmettez le numéro de commande et les lignes de journal pertinentes.

<details>
<summary>Trouver les journaux pour l’assistance</summary>

Les journaux se trouvent dans `WooCommerce > Status > Journaux`, sous la source `payarc-terminal-for-woocommerce`. Les identifiants sont masqués et les secrets sont supprimés.

Aucune archive de diagnostic pour l’assistance n’est téléchargeable. Ne partagez pas de MID complets, d’ID de terminal, de jetons ou de données de carte.

</details>

## Périmètre et limites {#scope-and-limitations}

- Pas de pourboires sur le terminal
- Un terminal encaisse un paiement à la fois ; lorsqu’il est occupé, les autres caisses affichent **Utilisé par la commande #…**
- Les devises sont limitées à **USD, CAD, GBP, EUR et JPY**
- La connexion n’indique pas si un terminal est allumé : une vente envoyée à un terminal hors ligne échoue immédiatement, sans que rien ne lui soit transmis
- Les paiements encaissés par la version 0.1 de l’extension se remboursent dans PayArc, et non via la passerelle de paiement
- Un remboursement est envoyé au terminal qui a encaissé la vente

## En cas de problème de configuration {#troubleshooting}

### Problèmes courants {#common-issues}

<Accordion>
  <AccordionItem question="Ces identifiants PayArc semblent correspondre au mode test (ou production)">

  - Le mode sélectionné et les identifiants proviennent d’environnements PayArc différents
  - Réglez le **Mode** sur celui indiqué dans le message, ou remplacez les identifiants par ceux du mode sélectionné
  - Cliquez à nouveau sur **Se connecter avec ces identifiants**, puis enregistrez

  </AccordionItem>
  <AccordionItem question="Impossible de se connecter à PayArc">

  - PayArc a refusé la connexion. Vérifiez les identifiants saisis et réessayez
  - Consultez `WooCommerce > Status > Journaux`, source `payarc-terminal-for-woocommerce`, pour plus de détails

  </AccordionItem>
  <AccordionItem question="L’URL de rappel doit utiliser HTTPS avant l’activation du mode production">

  - Le mode production nécessite que votre site utilise HTTPS, afin que PayArc puisse accéder à l’**URL du webhook**
  - Passez le site en HTTPS ou utilisez le mode **Test** sur un site de test

  </AccordionItem>
  <AccordionItem question="Le registre des terminaux est vide">

  - La caisse propose alors uniquement le terminal indiqué dans **Numéro de série du terminal**, et les paiements vers ce terminal fonctionnent toujours
  - Demandez à PayArc de confirmer ce numéro de série pour votre compte et de répertorier vos autres terminaux si vous souhaitez que la caisse les propose
  - Cliquez sur **Actualiser les terminaux** après leur ajout par PayArc

  </AccordionItem>
  <AccordionItem question="PayArc a rejeté à la fois le Connect AccessToken et la SecretKey">

  - PayArc a refusé l’accès à son API de transactions pour votre compte
  - Demandez à l’assistance PayArc de confirmer que **PayArc Connect V3** est activé pour votre compte marchand et de préciser quel identifiant autorise ses transactions

  </AccordionItem>
</Accordion>

### Obtenir de l’aide {#getting-help}

- Joignez le **numéro de commande** et les **lignes de journal** pertinentes à votre demande d’assistance
- Consultez le [dépôt GitHub](https://github.com/wcpos/payarc-terminal-for-woocommerce) pour signaler des problèmes
- Contactez l’assistance PayArc pour votre compte, PayArc Connect et la configuration du terminal
