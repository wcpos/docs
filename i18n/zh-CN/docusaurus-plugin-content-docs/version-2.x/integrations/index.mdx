WCPOS 通过 WooCommerce REST API 保存 POS 销售订单，因此大多数 WooCommerce 插件无需额外设置即可处理这些订单。少数插件只在网店结账或 WP Admin 订单页面中生效，需要 WCPOS 进行适配；还有一些完全无法与 POS 配合使用。本页介绍其中四款插件，以及各自需要执行的操作。

Product Bundles、Composite Products 和 Product Add-Ons 已列入 2.3 的[路线图](../getting-started/roadmap.mdx#your-other-plugins)。

## 无法与 POS 配合使用的插件 {#not-supported}

:::warning 请检查这两款插件
使用 WCPOS 前，请停用 **wePOS**。**Stripe Tax** 不支持 POS 订单：如需在收银台自动计算税费，请使用 WooCommerce Tax。
:::

### wePOS {#wepos}

**您需要做什么：** 在 **WP Admin > 插件** 中找到 **wePOS**，选择 **停用**，然后找到 **WCPOS – Point of Sale for WooCommerce**，选择 **启用**。如果无法打开 **插件**，请让店铺管理员操作。wePOS 启用期间，WCPOS 会在下次加载 WP Admin 时自动停用，并显示：*由于兼容性问题，WCPOS 无法与 wePOS 插件同时运行。WCPOS 已停用。*

**原因：** wePOS 会改变店铺发送可变商品数据的方式，导致 POS 中的商品变体无法正常使用。

### Stripe Tax {#stripe-tax}

**您需要做什么：** 如需为 POS 订单自动计算税费，请使用 [WooCommerce Tax](#woocommerce-tax)。这是 WCPOS 支持的自动税费插件。

**原因：** Stripe Tax 不支持 POS 订单，且没有变通方法。

## WCPOS 支持的插件 {#plugins}

### WooCommerce Tax {#woocommerce-tax}

**您需要做什么：** 按照 [WooCommerce Tax 设置步骤](./woocommerce-tax.mdx#setup)开启自动税费。POS 每次加载店铺时都会复制 WooCommerce 的税费设置，因此无需在 POS 中更改任何内容。

<details>
<summary>WCPOS 如何处理 WooCommerce Tax</summary>

WooCommerce Tax 在网店结账和 WP Admin 订单页面中查询税率，而 POS 订单通过另一种途径传送到店铺。因此，每次保存尚未完成的 POS 订单时，WCPOS 都会向 WooCommerce Tax 请求税率，使 POS 销售订单与线上订单采用相同的税率。

</details>

### Yoast SEO {#yoast-seo}

**您需要做什么：** 无需操作。

<details>
<summary>WCPOS 如何处理 Yoast SEO</summary>

WCPOS 会从 POS 下载的内容中排除 Yoast 的 SEO 数据，以减少同步数据量。即使 Yoast 设置为移除应用查找店铺所用的链接，WCPOS 也会保留该链接。

</details>

## 集成与扩展 {#extensions}

:::info 使用 WCPOS Pro
安装扩展需要 WCPOS Pro。免费版会显示扩展目录，但安装按钮不可用。
:::

如果您使用的插件有对应的 WCPOS 扩展，请从[扩展](../extensions/index.mdx)中进行设置。

<details>
<summary>集成与扩展有什么区别？</summary>

集成是指您已在网店中使用的插件。WCPOS 无需额外组件即可与其配合，并在必要时进行适配，就像对 WooCommerce Tax 所做的那样。扩展则是专为 WCPOS 构建的附加组件，例如银行卡终端组件，或让 WCPOS 能够与 WPML 等翻译插件配合使用的组件。

</details>

## 遇到问题？ {#something-not-working}

如果您依赖的插件在 POS 中运行异常，请先查看[插件冲突](../support/troubleshooting/plugin-conflicts.mdx)。其中列出了[已知冲突](../support/troubleshooting/plugin-conflicts.mdx#known-plugin-conflicts)，以及排查新冲突的方法。
