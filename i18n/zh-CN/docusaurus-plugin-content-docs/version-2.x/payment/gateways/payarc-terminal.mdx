# PayArc Terminal 支付网关 {#payarc-terminal-gateway}

PayArc Terminal 将销售交易从收银机发送到 PayArc PAX 终端。顾客在终端上付款，PayArc 确认后，收银机会记录这笔付款。

本页先介绍收银机上的操作。网关配置请参阅[设置 PayArc Terminal](#setup)。

:::info Pro 功能
PayArc Terminal 需要 [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0 或更高版本。
:::

## 收取银行卡付款 {#take-payment}

:::note 请先开班
启用 **收银机开班与结班** 后，收银机在结班状态下不会记录付款，已经收取的银行卡付款则需要退款。有关此设置，请参阅[收银机](../../settings/wp-admin/registers.mdx#one-register)。
:::

在购物车中点击 **结账**。PayArc Terminal 以卡片形式显示在 **付款** 选项卡上，与其他支付方式并列。

1. 点击 **PayArc Terminal** 卡片。
2. 检查数字键盘上方显示的终端名称：**终端：…**。如果有多个终端，点击 **更改**，然后选择您柜台上的终端。收银机会记住您的选择，供下次使用。
3. 如需通过银行卡收取部分应付余额，请输入金额。剩余金额仍为待付款，可通过另一笔付款收取。
4. 点击 **将 … 发送到 PayArc Terminal**。收银机会显示 **正在终端上处理**，并列出四个步骤：**已发送**、**已到达终端**、**已批准** 和 **已扣款**。
5. 顾客在终端上付款。扣款完成且没有剩余应付金额时，会打开收据。如果仍有未付金额，请使用其他支付方式卡片收取。

点击步骤下方的 **详情**，可打开付款日志，查看发送时间、到达终端的时间以及获批金额。付款记录会保留卡组织、卡号后 4 位、读卡方式以及 PayArc 的授权码。

终端不会提示支付小费。支持此功能的终端请参阅[小费](../../pos/checkout/tips.mdx)。

### 取消付款 {#cancel}

在顾客付款前点击 **在终端上取消**。收银机会等待终端确认，然后显示 **付款已取消**。

如果已经开始读卡，PayArc 可能会拒绝取消并完成付款；收银机会持续查询并显示结果。等待期间会显示 **正在取消 — 等待终端确认**，并提供 **释放此笔付款** 选项。释放后，订单即可通过其他方式付款，同时店铺仍会继续查询终端状态。

:::warning
释放并不等于取消付款：终端仍可能收取这笔款项。在收取另一笔付款前，请先检查终端上的结果。
:::

## 付款出现问题时 {#goes-wrong}

:::warning
**终端确认的金额不一致？** 请勿再次收款。先检查终端、订单和 PayArc 控制面板。
:::

<Accordion>
  <AccordionItem question="付款失败：银行卡被拒绝">

  点击 **重试**，将付款再次发送到终端；或点击 **选择其他方式**，使用其他支付方式卡片付款。

  </AccordionItem>
  <AccordionItem question="付款失败，并显示 PayArc 的提示消息">

  PayArc 拒绝了这笔销售交易，例如终端已关机或未联网。检查终端后，点击 **重试**。

  </AccordionItem>
  <AccordionItem question="已超时 — 付款已取消">

  5 分钟内无人付款，或终端等待顾客出示银行卡但一直未收到。检查终端后，点击 **重试**。

  </AccordionItem>
  <AccordionItem question="PayArc Terminal 卡片呈灰色">

  收银机会在卡片下方说明原因。所有可能的原因请参阅[支付方式卡片不可用时](../index.mdx#unavailable-tiles)。

  - **尚未为 PayArc Terminal 设置终端** — 店铺没有用于此网关的终端。管理员可在[设置 PayArc Terminal](#setup) 的第 4 步添加终端。
  - **订单 #… 正在使用** — 终端正在处理另一笔订单的付款。请先完成或取消该笔付款，或点击 **更改**，选择其他终端。
  - **需要网络连接** — 收银机处于离线状态。终端付款需要通过店铺处理，请使用其他支付方式收款，或等待网络恢复。

  </AccordionItem>
  <AccordionItem question="连接不稳定，仍在尝试">

  此消息会显示在 **详情** 日志中。收银机会继续查询。请保持此界面打开：终端上的付款仍在进行。

  </AccordionItem>
  <AccordionItem question="付款卡住，或收银机提示支付服务商未响应">

  请参阅[读卡器付款卡住时](../index.mdx#card-reader-problems)。

  </AccordionItem>
  <AccordionItem question="付款等待时间过长">

  - 检查终端屏幕，并保持付款界面打开
  - **5 分钟** 后，收银机会停止等待，并显示 **已超时 — 付款已取消**
  - 再次收款前，请先检查终端、订单备注和 PayArc 控制面板

  </AccordionItem>
  <AccordionItem question="无法使用当前 PayArc 凭据读取此订单之前的一笔 PayArc Terminal 付款">

  - 请使用其他方式收款，或联系管理员。此订单包含一笔在模式或凭据更改前收取的付款
  - 管理员需在 PayArc 控制面板中切换到收取该笔付款时使用的模式，检查该笔付款
  - 如需再次在此订单上使用 PayArc，管理员需将 PayArc 切换回该模式，点击 **使用这些凭据连接**，然后由您重新加载页面

  </AccordionItem>
</Accordion>

## 退还 PayArc 付款 {#refunds}

退款会发送到原收款终端，可以全额退款，也可以部分退款。

1. 在 POS 中打开订单的退款界面。请参阅[退款](../../pos/refunds.mdx)。
2. 选择 **退款至 PayArc Terminal**，然后点击 **处理退款**。
3. PayArc 会将退款发送到终端，由终端批准或拒绝。终端响应前，退款会保持待处理状态，处理结果会添加到订单备注中。

在 WP Admin 中使用 WooCommerce 的 **通过 PayArc Terminal 退款 …** 按钮退款时，流程相同。

如果退款一直处于待处理状态，请先检查 PayArc 控制面板，再尝试退款。

<details>
<summary>PayArc 未响应退款时</summary>

店铺会每隔 2 分钟使用相同的请求键再次请求，最多重试 5 次，因此 PayArc 会将每次重试视为同一笔退款。如果仍未收到响应，系统会提示员工检查 PayArc 控制面板。

</details>

<details>
<summary>通过旧版本收取的付款</summary>

**这笔 PayArc 付款是通过插件自带的订单付款面板收取的。** 这笔付款由 WCPOS 2 之前的扩展版本 0.1 收取，因此无法通过网关退款。请在 PayArc 控制面板或终端上退款，然后在 WooCommerce 中使用 **手动退款 …** 记录退款。

</details>

## 设置 PayArc Terminal {#setup}

管理员在 WP Admin 中完成一次网关设置后，再为每台收银机选择终端。

<details>
<summary>设置前的准备工作</summary>

### 要求 {#requirements}

PayArc 会提供您的 MID、ClientSecret 和 SecretKey，以及已为您配置好的终端序列号。

店铺通过互联网经由 PayArc 连接各台终端，因此无需配对，任意收银机都可以使用您的任意终端。如果未安装 WCPOS Pro 2.0 或更高版本，扩展会在 WP Admin 中显示提示，且不会向 POS 添加任何功能。

<RequirementsList>
  <RequirementItem label="PayArc 账户">拥有 PayArc Connect V3 访问权限的商户账户</RequirementItem>
  <RequirementItem label="兼容硬件">分配给您账户的、受 PayArc 支持的 PAX 终端</RequirementItem>
  <RequirementItem label="连接方式">仅支持互联网连接。店铺根据序列号将每笔付款发送到 PAX 终端，因此每台收银机都可以使用它；收银机在结账时选择终端</RequirementItem>
  <RequirementItem label="WCPOS">WCPOS Pro 2.0 或更高版本，以及 1.0 或更高版本的扩展</RequirementItem>
  <RequirementItem label="服务器">WooCommerce 7.0+、PHP 7.4+，正式模式还需要 HTTPS</RequirementItem>
  <RequirementItem label="货币">USD、CAD、GBP、EUR 或 JPY</RequirementItem>
</RequirementsList>

</details>

<details>
<summary>六个步骤：安装、连接、添加终端、启用，以及为每台收银机选择终端</summary>

<Steps>
  <StepCard number="1" title="安装 PayArc Terminal for WooCommerce">

从 [GitHub 发布页面](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases) 下载 1.0 或更高版本的 **payarc-terminal-for-woocommerce.zip**，进入 `插件 > Add Plugin`，点击 **上传插件** 进行上传。然后启用插件。

`WP Admin > POS > 设置 > 扩展` 中可能仍列出 0.1 版本，该版本是在 WCPOS 2 之前构建的。从这里安装前，请先检查版本。

  </StepCard>
  <StepCard number="2" title="输入 PayArc 凭据">

1. 前往 `WP Admin > WooCommerce > 设置 > 支付`，打开 **PayArc Terminal**
2. 选择 **模式**：默认值为 `Live`。只有使用 PayArc 测试控制面板凭据和 PayArc Connect Test 应用时，才能使用 `Test`。切勿混用环境
3. 输入 **PayArc 登录邮箱**，即用于登录 PayArc 商户控制面板的邮箱
4. 输入 PayArc 商户资料中的 **PayArc MID**，不要输入终端 ID
5. 输入控制面板 API 部分提供的 **PayArc ClientSecret**，以及 PayArc 控制面板提供的 **PayArc SecretKey / API 持有者令牌**
6. 将 **回调持有者令牌** 留空，除非 PayArc 支持团队已提供此令牌

  </StepCard>
  <StepCard number="3" title="连接">

点击 **使用这些凭据连接**。连接成功后，界面会显示 **已连接到 PayArc**，并提示您输入或确认终端序列号后保存。如果提示凭据似乎属于另一个环境，请切换 **模式** 并重新连接。

:::note
每次更改 **模式** 或凭据后，都需要再次点击 **使用这些凭据连接**，然后保存。在 WCPOS 中启用 PayArc Terminal（第 5 步）后，如果未重新连接，保存时就会报错。终端正在处理付款时，无法更改模式、凭据或连接。
:::

  </StepCard>
  <StepCard number="4" title="添加终端">

1. 输入设备背面 **S/N** 标签上的 PAX **终端序列号**，该序列号应已由 PayArc 为您的账户配置
2. 选择 **付款类型** 和 **打印收据**
3. 确认 **Webhook URL** 使用 HTTPS。仅在 PayArc 要求时向其提供此地址
4. 点击 **保存更改**

收银机会提供此终端，以及 PayArc 终端注册表中为您账户列为已启用的所有终端。点击 **连接** 会获取注册表，点击 **刷新终端** 可重新获取。PayArc 标记为已禁用的终端不会列出，但您输入的序列号所对应的终端始终可供选择。正式模式要求网站使用 HTTPS。

  </StepCard>
  <StepCard number="5" title="在 WCPOS 中启用">

1. 前往 `WP Admin > POS > 设置 > 结账`
2. 在列表中找到 **PayArc Terminal**，打开其 **已启用** 开关
3. 下次加载页面时，收银机上就会显示该卡片

:::note
这是唯一生效的开关。WooCommerce 付款列表中的 **已启用** 开关没有作用，PayArc Terminal 也不会出现在网店的结账页面上。请参阅[收银台设置](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)。
:::

  </StepCard>
  <StepCard number="6" title="为每台收银机选择终端" isLast>

在每台收银机上打开 **设置 > 读卡器**。PayArc 终端会列在 **智能读卡器** 下，每台占一行，均标为 **在线**：PayArc 不会报告终端是否已开机。找到该柜台的终端，点击 **使用此读卡器**；该行会显示 **已选择**。收银员仍可在结账时点击 **更改**。

如果只有一台 PayArc 终端，则无需选择：它在每台收银机上都已处于 **已选择** 状态。如果某行显示 **由店铺设置**，则表示收银机已锁定使用店铺的默认终端。请参阅[选择智能读卡器](../../hardware/card-readers/index.mdx#smart-readers)。

  </StepCard>
</Steps>

</details>

## 设置参考 {#settings}

以下涵盖 `WP Admin > WooCommerce > 设置 > 支付 > PayArc Terminal` 网关页面上的所有设置。

<details>
<summary>PayArc Terminal 的所有设置</summary>

| 设置 | 作用 |
|---|---|
| **标题** | 收银机上显示的卡片名称；默认为 `PayArc Terminal` |
| **描述** | 支付方式的描述；默认为 `Pay in person at a PayArc PAX terminal.` |
| **模式** | `Live`（默认）或 `Test`。测试模式需要 PayArc 测试控制面板凭据和 PayArc Connect Test 应用 |
| **PayArc 登录邮箱** | 用于登录 PayArc 商户控制面板的邮箱；连接前必须填写 |
| **PayArc MID** | PayArc 商户资料中的商户 MID，而非终端 ID |
| **PayArc ClientSecret** | 控制面板 API 部分提供的密钥；仅存储在您的服务器上 |
| **PayArc SecretKey / API 持有者令牌** | PayArc 控制面板提供的令牌，用于登录和读取终端注册表 |
| **回调持有者令牌** | 可选。仅在 PayArc 支持团队已提供时填写 |
| **PayArc 连接** | 包含 **使用这些凭据连接**、**刷新终端** 和 **断开连接** 按钮 |
| **终端序列号** | PayArc 为您的账户配置的 PAX S/N。收款时必填 |
| **付款类型** | `CREDIT`（默认）或 `DEBIT` |
| **打印收据** | 终端打印选项：`0 - No receipt`（默认）、`1 - Merchant receipt`、`2 - Customer receipt` 或 `3 - Both receipts` |
| **Webhook URL** | 只读的回调地址。请确认使用 HTTPS；仅在 PayArc 要求时向其提供 |
| **PayArc 诊断** | 连接信息和 **验证设置** 按钮；不会显示密钥 |

已保存的密钥字段只显示最后 4 个字符。将密钥字段留空即可保留已保存的值。

**PayArc 诊断** 表格会显示模式、PayArc 端点、是否已设置登录邮箱和 Connect 访问令牌、经过掩码处理的 MID、租户 ID 和终端序列号、找到的终端数量、Webhook URL、最近一次回调时间以及最近一次 PayArc 错误。**验证设置** 会检查已保存的设置，并列出缺失项。

**断开连接** 会清除已存储的 PayArc 连接、终端列表和 **终端序列号**。凭据会保留，方便您快速重新连接。保存前请检查序列号。

</details>

## 适用范围与限制 {#scope-and-limitations}

- 终端不支持收取小费
- 一台终端一次只能处理一笔付款；忙碌时，其他收银机会显示 **订单 #… 正在使用**
- 仅支持 **USD、CAD、GBP、EUR 和 JPY**
- 此连接不会报告终端是否已开机：向离线终端发起销售交易会立即失败，不会向其发送任何请求
- 通过扩展版本 0.1 收取的付款需在 PayArc 中退款，不能通过网关退款
- 退款会发送到原收款终端

## 设置出现问题时 {#troubleshooting}

### 常见问题 {#common-issues}

<Accordion>
  <AccordionItem question="这些凭据似乎是 PayArc 测试（或正式）环境的凭据">

  - 所选模式和凭据来自不同的 PayArc 环境
  - 将 **模式** 切换为提示消息中指出的模式，或将凭据替换为适用于所选模式的凭据
  - 再次点击 **使用这些凭据连接** 并保存

  </AccordionItem>
  <AccordionItem question="无法连接 PayArc">

  - PayArc 拒绝了登录。请检查输入的凭据后重试
  - 查看 `WooCommerce > Status > 日志` 中来源为 `payarc-terminal-for-woocommerce` 的日志，了解详情

  </AccordionItem>
  <AccordionItem question="启用正式模式前，回调 URL 必须使用 HTTPS">

  - 正式模式要求网站使用 HTTPS，以便 PayArc 能够访问 **Webhook URL**
  - 将网站改为使用 HTTPS，或在测试网站上使用 **测试** 模式

  </AccordionItem>
  <AccordionItem question="终端注册表为空">

  - 此时收银机只会提供 **终端序列号** 中指定的终端，仍可正常通过该终端收款
  - 请 PayArc 确认您账户中的该序列号；如果希望收银机提供其他终端，也请 PayArc 将它们加入列表
  - PayArc 添加完成后，点击 **刷新终端**

  </AccordionItem>
  <AccordionItem question="PayArc 拒绝了 Connect AccessToken 和 SecretKey">

  - PayArc 拒绝了您的账户对其交易 API 的访问
  - 请 PayArc 支持团队确认您的商户账户已启用 **PayArc Connect V3**，并确认使用哪个凭据来授权交易

  </AccordionItem>
</Accordion>
