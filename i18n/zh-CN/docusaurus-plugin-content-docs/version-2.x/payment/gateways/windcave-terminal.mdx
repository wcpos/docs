# Windcave Terminal 网关 {#windcave-terminal-gateway}

收银机将订单总额发送到 Windcave 终端，顾客在终端上付款，Windcave 批准付款后销售便会自动完成。安装此扩展以及在收银机上使用它，都需要 [WCPOS Pro](../../getting-started/pro-license.mdx)。本页分为两部分：在收银机上[收款](#take-payment)，以及在 WP Admin 中[设置](#setup)。

:::warning 尚未通过 Windcave 认证
**仅用于测试付款。** 目前请勿用它收取顾客的真实付款：只能使用 Windcave 的 **UAT**（测试）凭据。

<details>
<summary>原因及尚未测试的内容</summary>

Windcave 要求所有 POS 集成都必须通过其 QA 认证，才能收取真实付款。此集成尚未通过认证，也尚未使用 Windcave 账户或实体终端运行测试：以下步骤依据 Windcave 的 HIT 文档和扩展代码编写。

</details>
:::

## 收款 {#take-payment}

开始之前：店铺必须联网，因为付款会在 POS 内的店铺付款页面上进行，并且需要有 WP Admin 访问权限的人员[设置网关](#setup)。如果启用了 **开启和关闭收银机**，请先[开启收银机](../../pos/register/index.mdx#open)。

:::info Windcave 收取全额付款
终端始终收取整个订单的金额，因此不能与其他付款方式共同支付同一笔销售。
:::

1. 将商品加入购物车，然后点击 **结账**。
2. 打开 **传统** 选项卡。店铺的付款页面会在 POS 内打开。请参阅[传统选项卡](../../pos/checkout/legacy-tab.mdx)。

   <details>
   <summary>选项卡显示“仅限整单付款”</summary>

   该订单已经收取过一笔付款，因此此选项卡不会打开付款页面。要使用 Windcave，请先[取消该笔付款](../../pos/checkout/cancelling-a-payment.mdx)。

   </details>

3. 选择 **Windcave Terminal**。您的店铺可能为它设置了其他名称。
4. 在 **终端** 下选择终端。只有一台终端或已锁定默认终端时，系统会自动选中。如果有两台或更多终端且未设置默认终端，则必须手动选择。
5. 点击 **开始终端付款**。面板会显示 **正在发送到终端…**，并将订单全额发送到该终端。
6. 顾客在终端上感应、插入或刷银行卡。终端显示的内容及其按钮也会出现在面板上。终端要求核对签名时，请在面板中选择 **是** 或 **否**。
7. Windcave 批准付款后，面板会显示 **付款完成 — 正在完成订单…**，POS 随即进入收据页面。

无需点击传统选项卡底部的 **处理付款**：终端批准付款后，销售会自动完成。

### 停止或暂时搁置付款 {#payment-controls}

:::warning 暂时搁置的付款仍可能成功
改用其他方式收款前，请先查看终端。如果显示付款已批准，请勿再次向顾客收费。如果无法确定，请询问经理。
:::

- 付款进行时，**取消终端付款** 会替换 **开始终端付款**。如果终端提供 **取消** 按钮，此操作会按下该按钮。否则，面板会给出提示：请直接在终端上取消，或暂时搁置付款。
- 付款进行 5 分钟仍无响应，或终端无法取消付款时，会显示 **暂时搁置付款**。此操作 **不会** 取消 Windcave 端的付款。改用其他方式收款前，请确认终端显示付款已被拒绝或已取消。如果仍在等待、屏幕空白或状态不明，请先让经理查看 Windcave 门户。
- **重新加载页面** 会恢复正在进行的付款，并显示 **取消终端付款**。

<details>
<summary>暂时搁置付款后会发生什么</summary>

即使关闭收银机，店铺仍会每隔 10 分钟向 Windcave 查询该笔付款。如果订单已通过其他方式付款，之后 Windcave 又批准了这笔付款，订单中会添加说明此情况的备注：请在 Windcave 门户中退还这笔付款。

</details>

## 故障排查 {#goes-wrong}

以下消息可能意味着顾客已经付款。再次收款前，请先阅读这些说明。

### 等待终端超时 {#timed-out}

五分钟后仍无结果，面板已停止查询。执行其他操作之前，请先查看终端：

- **显示付款已批准。** 请勿再次收费。重新加载页面后，面板会恢复该笔付款并完成销售。如果销售仍未完成，请让经理检查订单备注和 Windcave 门户。
- **显示付款已被拒绝或已取消。** 点击 **取消终端付款** 或 **暂时搁置付款**，然后重新收款。
- **屏幕空白、仍在等待或无法判断状态。** 暂时不要再次收款。请先让经理查看 Windcave 门户。请参阅[警告](#payment-controls)。

### 此订单已通过另一笔付款支付 {#already-paid}

终端批准了付款，但订单此前已通过其他方式支付，因此顾客支付了两次。请勿重试。请在 Windcave 门户中退还终端付款；订单备注中会注明该笔付款。

### 无法验证终端付款 {#not-verified}

Windcave 批准了一笔无法用于此订单的付款，例如订单总额发生了变化。请勿再次从银行卡扣款：问题解决之前，点击开始按钮仍会显示相同消息。请先检查订单备注和 Windcave 门户，并联系经理。

<details>
<summary>付款被拒绝、终端忙碌、未选择终端及其他消息</summary>

**请先选择终端。** 在 **终端** 下选择一台终端，然后再次点击 **开始终端付款**。

**付款被拒绝**、终端自身的拒绝提示，或 **Windcave 拒绝了付款（代码 …）**。点击 **开始终端付款** 重试，或使用其他方式收款。

**终端仍在完成上一笔交易。** 请在终端上完成或取消该笔交易，然后重新开始。

**Windcave 没有此交易的记录。请重新发起付款。** 付款请求未到达 Windcave。请再次点击 **开始终端付款**。

**Windcave 返回代码 …：请检查站点 ID 和 HIT 设置。** Windcave 拒绝了请求，通常是因为站点 ID 有误。请让设置网关的人员检查[设置](#settings)，或暂时搁置付款。

**此付款在 UAT 环境中发起**（或 **生产环境**）。付款进行期间，有人更改了 **环境**。请切换回原环境以完成付款，或在 Windcave 门户中检查。

</details>

<details>
<summary>设置过程中出现的消息</summary>

**尚未配置 Windcave HIT 凭据。** **HIT 用户名** 或 **HIT 密钥** 为空。请输入两项内容并保存，同时确认 **环境** 与凭据相匹配。

**终端** 列表显示 **未配置站点 ID**。请添加 Windcave 提供的站点 ID，每行一个，然后保存。

**无法启用。** 服务器需要 **PHP 7.4** 或更高版本以及 PHP DOM 扩展（**php-xml**）。请让主机服务商启用该扩展。

</details>

## 销售完成后 {#receipts}

Windcave 从终端发送收据文本时，该文本会作为 **私密备注** 保存到订单中。POS 仍会照常显示自己的收据。

## 退款 {#refunds}

此版本不支持从 WooCommerce 发起退款。请在 Windcave 门户（Payline）或终端上退款，然后在 WooCommerce 的订单中手动记录退款。请参阅[退款](../../pos/refunds.mdx)。

## 设置 {#setup}

本部分适用于管理店铺 WP Admin 的人员。请按顺序完成以下四步：

1. 从扩展目录[安装扩展](#install)。
2. 向 Windcave [获取 HIT 凭据](#credentials)。
3. [填写网关设置](#gateway-settings)。
4. [为 POS 启用网关](#enable)。

### 安装扩展 {#install}

打开 `WP Admin > POS > 设置 > 扩展`，找到 **Windcave Terminal for WooCommerce**，然后点击 **安装**。WCPOS 会一次性完成下载、安装和启用。请参阅[安装扩展](../../extensions/index.mdx#installing-an-extension)。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[700, 0], [-42, 0], [-40, 0]]} alt="WP Admin 中的 POS 设置、扩展页面，搜索 windcave 后：Windcave Terminal for WooCommerce 卡片显示版本 0.1.1 和安装按钮">

1. **搜索扩展** — 输入 `windcave` 查找卡片。
2. **Windcave Terminal for WooCommerce** — 此扩展及目录将安装的版本。
3. **安装** — 下载、安装并启用扩展。需要 WCPOS Pro。

</JourneyShot>

如果不使用扩展目录，请从 [GitHub 发布页面](https://github.com/wcpos/windcave-terminal-for-woocommerce/releases)下载 **插件 zip**（不是源代码 zip），在 `插件 > Add Plugin` 中通过 **上传插件** 上传，然后启用。WooCommerce 必须已启用。

### 向 Windcave 获取 HIT 凭据 {#credentials}

向 Windcave 申请 **HIT 用户名**、**HIT 密钥**，以及每台终端各自的 **站点 ID**。如需开发账户，请使用 Windcave 的[集成需求表单](https://www.windcave.com/merchant-attended-developer-hit)。

UAT 和生产环境使用不同的凭据。在此集成通过 Windcave 认证之前，请使用 UAT 凭据。

### 填写网关设置 {#gateway-settings}

1. 前往 `WP Admin > WooCommerce > 设置 > 支付`，打开 **Windcave Terminal**。
2. 将 **环境** 保持为默认的 **UAT（测试）**。通过认证后，才能使用 **生产环境** 及其凭据。
3. 输入 **HIT 用户名** 和 **HIT 密钥**。
4. 输入 **站点 ID**，每行一个。
5. 可选：设置 **默认站点 ID**，并勾选 **锁定终端选择**，让收银员始终使用该终端。
6. 将 **供应商 ID** 留空。Windcave 会在认证期间提供该 ID。
7. 可选：勾选 **结果通知（FPRN）**，让 Windcave 在结果就绪时也通知店铺，作为收银机自行查询的补充。
8. 保存。

此处没有测试连接按钮。凭据和站点 ID 会在首次付款时验证，因此请在 UAT 终端上进行一次测试付款。

### 为 POS 启用网关 {#enable}

前往 `WP Admin > POS > 设置 > 结账`，找到 **Windcave Terminal**，打开 **已启用** 开关。请参阅[启用网关](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)。

请勿勾选 WooCommerce 设置中的 **启用/禁用**。无论是否勾选该项，只要此处的 **已启用** 开关打开，POS 就能使用该网关。

## 设置参考 {#settings}

位于 `WP Admin > WooCommerce > 设置 > 支付 > Windcave Terminal`。上述步骤已涵盖必需的设置；展开列表可查看所有设置及其默认值。

<details>
<summary>全部 15 项设置</summary>

| 设置 | 作用 |
|---|---|
| **启用/禁用** | 让网店也显示此网关。请保持关闭：在线使用时，它只能在现有订单的付款页面收款，无法用于常规结账页面。默认关闭。POS 有独立的开关，位于 `POS > 设置 > 结账` |
| **标题** | 收银员在付款页面选择的名称。默认为 `Windcave Terminal` |
| **描述** | 显示在标题下方的说明。默认为 `Pay in person on the Windcave terminal.` |
| **环境** | **UAT（测试）**（默认）或 **生产环境**。每种环境都有独立的 HIT 凭据；生产环境需要通过 Windcave 认证 |
| **HIT 用户名** | 由 Windcave 提供，适用于所选环境 |
| **HIT 密钥** | 由 Windcave 提供，适用于所选环境 |
| **站点 ID** | 每行一个站点 ID，每台终端对应一个。由 Windcave 提供，不会自动发现 |
| **默认站点 ID** | 初始选中的终端，也是在未选择终端时使用的终端 |
| **锁定终端选择** | 收银员无法更改终端，始终使用默认终端。仅在已设置默认终端时生效 |
| **供应商 ID** | 由 Windcave 在认证期间提供。在此之前请留空 |
| **POS 名称** | 您的 POS 在 Windcave 中使用的名称。默认为 `WCPOS` |
| **结果通知（FPRN）** | 结果就绪时，Windcave 也会通知店铺，作为收银机查询的补充。默认关闭 |
| **结账日志** | 在付款面板上显示 **显示日志**、**复制** 和 **清除**。默认关闭 |
| **日志级别** | **关闭**、**仅错误** 或 **调试**（默认） |
| **支持** | **下载支持包**，以及日志链接 |

</details>

## 日志和支持包 {#logs-and-support-bundle}

日志位于 `WP Admin > WooCommerce > Status > 日志`，来源为 `windcave-terminal`。**日志级别** 默认为 **调试**，会记录发送到 Windcave 的每次请求及其响应，并遮蔽 HIT 密钥和银行卡号。

付款失败时，请在网关设置页面点击 **下载支持包**，将 `.json` 文件连同 **订单编号** 一起发送给支持团队。

<details>
<summary>支持包包含的内容</summary>

- 店铺配置：WordPress、WooCommerce、PHP 和扩展的版本、环境以及终端数量。
- 网关设置，其中 HIT 密钥已遮蔽，HIT 用户名仅保留前三个字符。
- 最近最多 20 个订单的付款尝试记录，不含收据。
- 最新两个 `windcave-terminal` 日志文件的最后 1,000 行。这些日志可能包含终端收据文本，其中银行卡号已遮蔽。

如果 WooCommerce 将日志保存在数据库中，支持包将不包含日志行：请从 `WooCommerce > Status > 日志` 导出日志并一并发送。

</details>

## 不支持的功能 {#scope-and-limitations}

- 从 WooCommerce 发起退款。
- 小费、附加费和刷卡取现。
- 不使用两位小数的货币。
- 部分付款：终端始终收取整个订单的金额。
- 自动发现终端：需要手动输入每个站点 ID。
- 网店的常规结账页面。在线使用时，它只能在现有订单的付款页面收款。

<details>
<summary>开发者说明：工作原理</summary>

此网关通过 HTTPS 使用 Windcave **HIT（主机发起交易）**。**环境** 决定使用 UAT 还是生产环境端点，每台终端通过其 **站点 ID** 寻址。

发起付款时，系统会在订单上记录交易参考编号，然后发送包含订单总额和货币的购买请求。面板每隔 1.5 秒向 Windcave 查询状态，并同步显示终端上的文本行和已启用按钮。启用 **结果通知（FPRN）** 后，Windcave 也会在结果就绪时回调店铺。

只有付款结果获批，且与订单上记录的付款尝试相符时，订单才会完成：核对内容包括参考编号、金额、环境，以及订单总额和货币。系统会给 Windcave 30 秒来登记新交易，之后才会将“无记录”视为拒绝。定时检查每隔 10 分钟跟进无响应或已暂时搁置的付款。

</details>
