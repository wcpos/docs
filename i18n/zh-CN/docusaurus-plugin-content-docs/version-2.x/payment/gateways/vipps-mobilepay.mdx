# Vipps MobilePay 支付网关 {#vipps-mobilepay-gateway}

:::info Pro 功能
在收银台收取 Vipps MobilePay 付款需要 [WCPOS Pro](../../getting-started/pro-license.mdx)。没有 Pro，网关仍可用于网店结账。
:::

顾客使用自己手机上的 Vipps 或 MobilePay 应用付款。他们可以扫描收银屏幕上的二维码，或批准发送到手机上的付款请求。无需读卡器。此网关位于结账页面的**传统**选项卡中，使用店铺自己的付款页面。

店铺需要先设置网关。请参阅[设置 Vipps MobilePay](#setup)。

## 收取 Vipps 付款 {#take-payment}

Vipps 会一次性收取整个订单的款项。如果订单已支付部分金额，传统选项卡会显示**已有付款后无法使用传统网关**，此时无法选择 Vipps：请先[取消该笔付款](../../pos/checkout/cancelling-a-payment.mdx)，或使用其他方式收取余款。

点击**结账**，打开**传统**选项卡并选择 **Vipps MobilePay**。其操作控件会显示在下方。然后向顾客出示[二维码](#qr)，或[将请求发送到顾客手机](#send-to-phone)。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[98, 0], [148, 0], [300, 0], [0, 0], [0, 0], [-80, 0], [-42, 0]]} alt="结账页面的传统选项卡中已选中 Vipps MobilePay：显示电话号码字段、生成二维码和发送到手机按钮、剩余金额及处理付款按钮">

3. **电话号码（可选）** — 仅用于**发送到手机**。使用二维码时可留空。
4. **生成二维码** — 显示供顾客扫描的二维码。请参阅[使用二维码](#qr)。
5. **发送到手机** — 将付款请求发送到输入的号码。输入号码后，按钮即可用。请参阅[发送到顾客手机](#send-to-phone)。
6. **剩余金额** — 顾客在应用中批准的付款金额，即整个订单的金额。
7. **处理付款** — 使用 Vipps 时无需点击。顾客批准付款后，销售会自动完成。

### 使用二维码 {#qr}

1. 点击**生成二维码**。二维码会出现在按钮下方，其下显示**正在等待付款…**。
2. 将屏幕转向顾客。顾客使用 Vipps 或 MobilePay 应用扫码并批准付款。
3. 收银台每两秒向 Vipps 查询一次。顾客批准付款后，页面会显示**付款成功！** 并自动打开收据页面，与其他[已付款的销售](../../pos/checkout/index.mdx#paid)相同。

收银台等待期间，两个按钮均呈灰色不可用，下方会显示**取消付款**按钮。如果五分钟内无人批准，页面会显示**付款已过期。请重试。**

### 发送到顾客手机 {#send-to-phone}

输入顾客的电话号码并点击**发送到手机**。随后会出现以下两种情况之一：

- **直接推送：** 请求出现在顾客的 Vipps 应用中，顾客在应用内批准付款。页面的等待和完成流程与二维码付款相同。
- **Vipps 页面在新窗口中打开**，或页面先要求再次点击。如果 Vipps 尚未为店铺开启直接推送，这是正常现象：请展开下方的**提示再次点击“发送到手机”？**

**仅限挪威号码。** 输入八位数字，或在前面加上 `47`、`+47` 或 `0047`。八位号码始终会被视为挪威号码，因此丹麦或芬兰的 MobilePay 顾客应使用二维码。

<details>
<summary>提示再次点击“发送到手机”？</summary>

如果 Vipps 尚未为账户开启[直接推送](#enabling-direct-push)，页面会显示**您的账户无法使用直接推送。请再次点击发送到手机。**

1. 再次点击**发送到手机**。
2. 新窗口会打开该号码对应的 Vipps 页面，并从该页面向顾客发送请求。
3. 顾客付款后，窗口会显示**付款完成**并自动关闭。如果浏览器不允许关闭，它会跳转到店铺首页：请关闭窗口并返回结账页面。

此后，每次点击**发送到手机**都会打开该窗口，直到[开启直接推送](#enabling-direct-push)。在**测试模式**下不会打开窗口：页面每次都会要求再次点击，因此请使用二维码测试。

</details>

### 停止付款 {#cancel}

在收银台等待期间点击**取消付款**。Vipps 中的付款会被取消，页面显示**付款已取消。** 不会扣款。点击**生成二维码**或**发送到手机**即可重试，也可改用其他付款方式：在传统选项卡中选择其他网关，或返回**付款**选项卡。

顾客在应用中拒绝付款时，也会显示**付款已取消。**

## 出现问题时 {#goes-wrong}

**付款已过期。请重试。** 五分钟内未收到顾客回应。请再次点击**生成二维码**或**发送到手机**。

**付款已取消。** 但您并未点击取消，表示顾客在应用中拒绝了付款。请与顾客确认后重试。

**电话号码无效。请使用挪威号码，例如 4741234567。** 此号码不是挪威手机号码。请检查号码，或使用二维码。

**弹出窗口被拦截。请允许弹出窗口后重试。** 浏览器阻止了 Vipps 窗口打开。请在浏览器设置中允许店铺网站弹出窗口，然后再次点击**发送到手机**。

**网络错误。请检查连接。** 收银台无法连接店铺以发起付款。请检查收银台的网络连接，然后再次点击**生成二维码**或**发送到手机**。

**创建 Vipps 付款失败。** 店铺无法通过 Vipps 发起付款。请询问顾客是否已在应用中批准付款。如果已批准，请让店主先检查 Vipps，再收取另一笔付款。如果未批准，请改用其他方式收取本次销售的款项，并让店主检查网关设置。

<details>
<summary>店主操作：检查设置和日志</summary>

- 检查[设置](#settings)中的四个密钥和**测试模式**：使用正式密钥时关闭测试模式，使用测试密钥时开启测试模式。
- 确认网站使用 HTTPS。
- 确认订单使用 Vipps 支持的货币。请参阅[支持的地区](#supported-markets)。
- 要查找原因，请开启**调试日志**并重试。日志会显示在付款页面的**显示日志**下，也可在 `WooCommerce > Status > 日志` 中选择来源 `wcpos-vipps` 查看。

</details>

:::warning 再次收款前先检查 Vipps
**Vipps 付款已被接受，但 … 请重试。** 顾客的付款已在 Vipps 中成功，但 WooCommerce 未将订单标记为已付款。收取新付款前，请在 [Vipps MobilePay 门户](https://portal.vippsmobilepay.com/)中找到这笔付款，以免顾客重复付款。
:::

**发送到手机会打开窗口，而非直接进入应用。** 您的账户使用的是**网页重定向**。此方式可以正常使用，但顾客需多操作一步。要直接进入应用，请参阅[开启直接推送](#enabling-direct-push)。

## 设置 Vipps MobilePay {#setup}

:::note 开始前
您需要一个已开通 ePayment API 的 Vipps MobilePay 商户账户及其四个 API 密钥、[WCPOS Pro](../../getting-started/pro-license.mdx)，以及使用 HTTPS 的网站，这是 Vipps API 的要求。
:::

店主安装网关、添加四个密钥并为 POS 启用后，网关就会显示在结账页面的传统选项卡中。

<details>
<summary>店主操作：安装并启用网关</summary>

1. 在 `WP Admin > POS > 设置 > 扩展` 中**安装** WCPOS Vipps MobilePay。请参阅[安装扩展](../../extensions/index.mdx#installing-an-extension)。也可从[发布页面](https://github.com/wcpos/wcpos-vipps/releases)下载**插件 zip 附件**（不是源代码 zip），进入`插件 > Add Plugin`，然后点击**上传插件**进行上传。
2. **添加密钥。** 打开 `WP Admin > WooCommerce > 设置 > 支付 > WCPOS Vipps MobilePay`，输入从 [Vipps MobilePay 门户](https://portal.vippsmobilepay.com/)获取的**商户序列号**、**客户端 ID**、**客户端密钥**和**订阅密钥**，然后保存。
3. 在 `WP Admin > POS > 设置 > 结账` 中**为 POS 启用网关**。请参阅[启用网关](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)。启用后，它会出现在结账页面的传统选项卡中。

:::tip 已在使用 Vipps 官方插件？
如果网站已设置 [Checkout with Vipps MobilePay](https://wordpress.org/plugins/woo-vipps/)，WCPOS Vipps MobilePay 会在首次加载时复制其密钥，包括测试密钥。请检查后保存。
:::

WooCommerce 页面上的**启用/禁用**复选框仅适用于网店结账。无论是否勾选此框，只要在收银台设置中启用，POS 就会使用该网关。

</details>

### 设置 {#settings}

这些设置位于 `WP Admin > WooCommerce > 设置 > 支付 > WCPOS Vipps MobilePay`。大多数店铺只需填写四个密钥。其余设置的默认值已适合收银台使用：顾客批准后立即扣款，**发送到手机**会优先尝试直接推送。

<details>
<summary>全部设置：名称和描述、密钥、自动扣款、手机付款方式、调试日志和测试模式</summary>

| 设置 | 作用 |
|---|---|
| **启用/禁用** | 在网店结账时提供 Vipps MobilePay。POS 无需启用此项。默认关闭。 |
| **标题** | 网关在传统选项卡和网店中显示的名称。默认值为 `Vipps MobilePay`。可在收银台设置中为 POS 单独设置标题。 |
| **描述** | 名称下方的说明文字。默认值为“通过二维码或推送通知使用 Vipps MobilePay 付款。” |
| **商户序列号**、**客户端 ID**、**客户端密钥**、**订阅密钥** | 从 Vipps MobilePay 门户获取的正式密钥。全部填写后网关才可用（开启**测试模式**时，则需填写四个**测试**密钥）。 |
| **自动扣款** | 默认开启：顾客批准后立即扣款。仅当您在 WCPOS 之外自行对预授权款项执行扣款时，才应关闭。 |
| **手机付款方式** | 决定**发送到手机**如何向顾客发送请求。**直接推送**（默认）直接发送到顾客的 Vipps 应用。**网页重定向**会在新窗口中打开 Vipps 页面。如果 Vipps 拒绝直接推送，会自动切换为**网页重定向**（测试模式除外）。 |
| **调试日志** | 将每个付款步骤记录到 `WooCommerce > Status > 日志`，并在付款控件下方添加**显示日志**面板。开启后可查找付款失败原因，排查完毕后请关闭。 |
| **测试模式** | 改为将付款发送到 Vipps 测试系统，使用下方的四个**测试**密钥。收取真实付款前请关闭。 |

</details>

### 开启直接推送 {#enabling-direct-push}

使用直接推送时，**发送到手机**会直接向顾客的 Vipps 应用发送请求，不会打开额外窗口。Vipps 必须先为账户开通此功能，然后由店主手动将网关切换回直接推送。

<details>
<summary>店主操作：联系 Vipps，然后切换回直接推送</summary>

1. 登录 [Vipps MobilePay 门户](https://portal.vippsmobilepay.com/)。
2. 联系您的 Vipps 大客户经理、合作伙伴经理或客服。
3. 向他们说明：“我需要为我的 MSN 启用 PUSH_MESSAGE，以便用于 POS 集成”。MSN 即您的**商户序列号**。
4. 他们确认开通后，将**手机付款方式**改回**直接推送**并保存。网关不会自动切换回来。使用**网页重定向**时，该设置的说明文字会提示如何开启直接推送。

在**测试模式**下，如果直接推送被拒绝，设置会保持不变，也不会打开 Vipps 页面：每次点击**发送到手机**都会要求再次点击。请改用二维码测试。

</details>

### 退款 {#refunds}

在 POS 中为订单退款并选择**退款至 Vipps MobilePay**，或在 WooCommerce 订单页面退款。款项会通过 Vipps 退还给顾客。请参阅[退款](../../orders/refunds.mdx)。如果 Vipps 拒绝退款，则不会记录退款，并显示 **Vipps 退款请求失败。** 请重试，或以现金退款。

## 支持的地区 {#supported-markets}

| 国家 | 应用 | 货币 |
|---|---|---|
| 挪威 | Vipps | NOK |
| 丹麦、芬兰 | MobilePay | DKK、EUR |

订单必须使用上述货币之一，具体可接受哪些货币由您的商户账户决定。**发送到手机**仅支持挪威号码；二维码适用于所有支持的地区。

## 获取帮助 {#getting-help}

- 账户和密钥：联系 Vipps MobilePay 客服。
- Vipps API：参阅 [Vipps MobilePay 开发者文档](https://developer.vippsmobilepay.com/)。
- 网关故障：访问 [GitHub 仓库](https://github.com/wcpos/wcpos-vipps)。
