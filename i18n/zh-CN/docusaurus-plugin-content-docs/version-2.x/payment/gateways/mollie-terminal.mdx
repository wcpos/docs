:::info Pro 功能
Mollie Terminal 需要 [WCPOS Pro](../../getting-started/pro-license.mdx) 2.0.0 或更高版本。
:::

Mollie Terminal 将销售从收银机发送至 [Mollie](https://www.mollie.com/products/point-of-sale) 银行卡终端。顾客在终端上付款，销售便会在收银机上自动完成。它仅接受**欧元**，且仅在 POS 中可用，不会出现在网店的结账界面上。

## 收款 {#take-payment}

由经理使用店铺正式 Mollie 账户下的终端完成一次[设置](#setup)。开始前，请先[开启收银](../../pos/register/index.mdx#open)。

:::warning
启用**开启和关闭收银**后，收银关闭时无法记录付款，已收取的银行卡付款将需要退款。
:::

1. 按**结账**，然后点击收款面板上的 **Mollie Terminal** 卡片。
2. 检查收款面板上的终端：**终端：** 后面显示其名称。要使用另一台，请点击**更改**并选择设备。如果店铺仅启用了一台终端，或锁定了终端选择，就不会显示**更改**。
3. 按**发送 … 至 Mollie Terminal**。金额会发送至终端。
4. 顾客在终端上感应、插入或刷银行卡。收银机显示**在终端上**，并依次显示**已发送**、**已到终端**、**已批准**和**已扣款**这些步骤。
5. Mollie 确认付款后，销售即为已付款，收据也已就绪，与其他[结账](../../pos/checkout/index.mdx#paid)流程相同。

每台收银机会记住上次使用的终端。请参阅[使用读卡器](../../pos/checkout/taking-a-payment.mdx#card-reader)。

顾客在终端上添加的小费会以**小费**条目记录到订单中。请参阅[小费](../../pos/checkout/tips.mdx)。

### 取消终端上的付款 {#cancel}

收银机等待期间，按**在终端上取消**。收银机会显示**正在取消 — 等待终端确认**。

#### 付款已取消或被拒绝 {#cancelled}

出现**付款已取消**、付款被拒绝或**已超时 — 付款已取消**后，表示付款未成功：按**重试**可再次发送付款，或按**选择其他方式**改用其他付款方式。

#### 终端尚未确认 {#not-confirmed}

顾客开始付款后，Mollie 可能不再允许收银机取消。请直接在终端上取消。

如果收银机仍无法收到响应，会提供**解除此付款占用**选项。

:::warning 再次收款前
请查看终端。如果显示付款已批准，**请勿再次扣款**：店铺仍在向 Mollie 核实。如果无法确定，请让经理先在 Mollie 控制面板中检查付款，再收取另一笔款项。
:::

**解除此付款占用**会让订单可以改用其他方式付款，收银机会显示**付款占用已解除**。这不表示付款已取消：店铺仍会持续查询终端。

### 使用旧版选项卡 {#legacy-tab}

也可以在结账界面的[旧版选项卡](../../pos/checkout/legacy-tab.mdx)，即订单付款页面上收款。打开**旧版**选项卡并选择 **Mollie Terminal**。显示的面板取决于经理是否已开启**二维码付款**。

**如果面板显示终端和二维码**，请停留在**终端**，并按**开始终端付款**。按**取消终端付款**可停止付款。若要改为显示二维码，请参阅[二维码付款](#qr-code)。

**否则：**

1. 如果面板提示选择终端，请选择设备。
2. 按标有**发送 … 至**并后接终端名称的按钮。面板显示的步骤与卡片相同。
3. 要停止付款，请按**在终端上取消**，操作见[取消付款](#cancel)。停止后，按**重试**可再次发送。POS 记录此付款的方式与通过卡片付款相同。

## 二维码付款 {#qr-code}

在荷兰和比利时，顾客可以使用银行应用扫描 iDEAL 或 Bancontact 二维码付款，无需使用终端。经理需先在[设置](#settings)中的**二维码付款**下启用相应方式。

1. 结账时，打开[旧版选项卡](../../pos/checkout/legacy-tab.mdx)，然后选择 **Mollie Terminal**。
2. 将付款面板从**终端**切换至**二维码**。
3. 如果两种方式均已启用，请选择 **iDEAL** 或 **Bancontact**，然后按**显示二维码**。
4. 顾客扫描二维码并在手机上付款。销售会像使用终端付款一样完成。

Bancontact 每笔二维码付款最高为 €1,500.00；超过此金额请使用终端。

## 退款 {#refunds}

在 POS 中为 Mollie Terminal 销售退款时，选择**退款至 Mollie Terminal**，也可在 WooCommerce 订单页面中退款。款项会通过 Mollie 全额或部分退回。请参阅[退款](../../pos/refunds.mdx#destination)。

Mollie 退款最初处于待处理状态。WCPOS Pro 每十分钟向 Mollie 查询一次，随后将其标记为已退款或失败，并向订单添加备注。

## 出现问题时 {#goes-wrong}

### 顾客已付款：请勿再次扣款 {#already-paid}

**顾客已付款，但收银机仍在等待。** **请勿再次扣款。** 请停留在当前界面：Mollie 确认付款后，销售就会完成。如果未完成，请让经理在 Mollie 控制面板中检查付款。

**“此销售之前发起的一笔 Mollie 付款已支付”。** 此销售的一笔付款已在 Mollie 成功，但尚未记录到订单中。**请勿再次扣款。** 请等待几分钟，然后重新加载。如果提示付款与订单不匹配，请由经理先在 Mollie 控制面板中检查。

### 其他问题 {#other-problems}

**“尚未为 Mollie Terminal 设置终端”。** 店铺没有可用的已激活终端。请由经理检查**模式**是否为**正式**且使用正式密钥，并确认终端在该 Mollie 账户中处于激活状态。

**“订单 #… 正在使用”。** 该终端正忙于处理另一笔销售。请选择其他终端，或先完成或取消另一笔销售。

**“需要连接”。** 收银机已离线。Mollie Terminal 仅支持在线使用：请改用其他方式收款，或等待连接恢复。

**“已超时 — 付款已取消”。** 无人在规定时间内付款，因此付款已取消。请检查终端是否已开机并联网，然后按**重试**或**选择其他方式**。

**其他币种的销售会被拒绝。** Mollie Terminal 仅接受欧元。

**仍然无法解决？** 请在 [GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/issues) 上报告扩展问题。有关 Mollie 账户或终端本身的问题，请联系 Mollie 支持，或参阅 Mollie 的[终端设置指南](https://docs.mollie.com/docs/setting-up-terminal)。

<details>
<summary>收银机和店铺如何与 Mollie 保持同步</summary>

- 等待付款期间，付款页面每两秒向 Mollie 查询一次，而 Mollie 发给店铺的通知通常会更早确认付款。无需为该通知进行任何设置。
- 每次更改订单前，都会先向 Mollie 核实更新，因此订单始终以 Mollie 的信息为准。
- 如果退款请求未收到响应，扩展会先查找 Mollie 是否已完成该笔退款，再决定是否发起另一笔退款。
- 在启用**二维码付款**的旧版选项卡中，付款由扩展自带的面板处理。如果五分钟内无人付款、订单通过其他方式付款或在 WooCommerce 中被取消，或者付款期间关闭了付款页面，扩展会取消 Mollie 中仍未结束的付款。系统每十分钟检查一次，取消未付款订单上已持续十分钟仍未结束的付款。
- 付款一旦到达终端，就无法从店铺端取消：请在终端上取消。
- 为便于排查问题，每笔付款都会记录在 `WooCommerce > Status > 日志` 下。销售未完成时，经理可到此处查找 Mollie 消息。

</details>

## 设置 {#setup}

由经理在 WP Admin 中完成一次设置。需要 WCPOS Pro 2.0.0 或更高版本、已启用**销售点**付款方式的正式 Mollie 账户，并将店铺币种设为欧元。

<details>
<summary>经理设置：安装、密钥、终端、启用</summary>

此扩展需要 WCPOS Pro 2.0.0 或更高版本：未满足此条件时，扩展不会运行，并会在 WP Admin 中显示提示。

:::note 开始之前
在 Mollie 网页应用中，为您的资料启用**销售点**付款方式，并在其中购买终端。Mollie 在荷兰、比利时、德国、法国和英国销售终端，可能会要求先验证账户。终端仅存在于**正式**账户中，因此需要使用正式 API 密钥。
:::

1. **安装扩展。** 打开`POS Settings > 扩展`并安装 **Mollie Terminal**，也可从 [GitHub](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases) 下载发布版 zip 文件，在`插件 > Add Plugin`中点击**上传插件**进行上传。请使用发布版本附带的 zip 文件，而非源代码压缩包。请参阅[扩展](../../extensions/index.mdx#installing-an-extension)。
2. **添加密钥。** 转到 `WooCommerce > 设置 > 支付 > Mollie Terminal`。将**模式**设为**正式**，然后将正式密钥粘贴到 **Mollie API 密钥**中，或设置 **API 密钥来源**以复用 Mollie Payments for WooCommerce 插件中的密钥。保存。
3. **选择终端。** 保存密钥后，会列出 Mollie 账户下的终端。请选择**默认终端**。如果某些终端不应供收银机使用，请在**已启用终端**下仅列出允许使用的设备。保存。
4. **在 POS 中启用。** 转到`POS > 设置 > 结账`并启用 **Mollie Terminal**。这是唯一的启用/关闭开关。请参阅[启用网关](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)。

无需在 Mollie 控制面板中设置 Webhook，也无需粘贴资料 ID：扩展会随每笔付款发送其 Webhook 地址，并列出整个账户下的终端。

如果**默认终端**列表一直为空，请检查**模式**是否为**正式**并使用了正式密钥（测试账户中不存在终端），确认终端在 Mollie 中处于激活状态，且网站能够连接 Mollie。

</details>

### 设置项 {#settings}

<details>
<summary>Mollie Terminal 页面上的全部设置</summary>

以下设置均位于 `WooCommerce > 设置 > 支付 > Mollie Terminal`。

| 设置 | 作用 |
|---|---|
| **标题** | 收银机上卡片显示的名称。默认为“Mollie Terminal”。 |
| **描述** | 订单付款页面上随付款方式显示的文字。 |
| **模式** | **测试**或**正式**。默认为**测试**，此时会显示警告：测试密钥无法操作终端。收款时请使用**正式**模式。 |
| **API 密钥来源** | **使用下方输入的密钥**或**复用 Mollie 官方插件的密钥**（与**模式**对应的测试或正式密钥）。如果 Mollie 插件未设置密钥，则使用下方的密钥。 |
| **Mollie API 密钥** | 所选模式对应的密钥。密钥来源设为复用 Mollie 插件的密钥时，会忽略此项。 |
| **默认终端** | 收银机初始使用的终端。从 Mollie 账户实时获取列表；未激活的终端会隐藏，因为 Mollie 无法将其重新激活。 |
| **已启用终端** | 收银机仅可选择这些终端。留空表示所有已激活的终端。默认终端始终可用，因此停用终端时也要更改默认终端。无法加载终端列表时不显示此项，但会保留已保存的选择。 |
| **二维码付款** | **iDEAL** 和 **Bancontact**：让收银员改为在屏幕上显示二维码。每种方式都必须在 Mollie 资料中处于激活状态。iDEAL 二维码也支持**测试**模式，因此无需终端即可试用；Bancontact 二维码需要**正式**模式。请参阅[二维码付款](#qr-code)。 |
| **锁定终端选择** | 收银机始终使用默认终端，收银员无法更改。需要先设置**默认终端**。 |
| **结账调试日志** | 在付款面板上显示**显示日志**、**复制**和**清除**。除非支持人员要求，否则请保持关闭：付款始终会记录在 `WooCommerce > Status > 日志` 下。 |

</details>
