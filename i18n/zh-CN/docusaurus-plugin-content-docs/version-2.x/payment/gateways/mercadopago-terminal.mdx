# Mercado Pago Terminal 支付网关 {#mercado-pago-terminal-gateway}

收银机会将订单总额发送至 Mercado Pago **Point Smart** 终端，顾客在终端上付款，Mercado Pago 确认付款后，销售便会自动完成。本页分为两部分：在收银机上[收款](#take-payment)，以及在 WP Admin 中[设置网关](#setup)。

:::warning 测试版：请先测试付款
这是一个新扩展，目前尚未使用它完成任何银行卡付款或退款。正式使用前，请先收取一笔小额付款并将其退回。

<details>
<summary>目前已测试的功能</summary>

已使用正式账户和真实的 Point Smart 测试过以下功能，均正常运行：列出终端、将终端切换至 PDV 模式，以及通过 Mercado Pago 为终端创建和取消付款。尚未测试的项目包括：付款是否随后显示在终端上、完成银行卡付款、Mercado Pago 对已付款订单的通知、退款，以及 Mercado Pago 的沙盒（**测试**模式）。

</details>
:::

## 收款 {#take-payment}

需要使用 [WCPOS Pro](../../getting-started/pro-license.mdx)，且店铺必须在线，因为付款是在 POS 内嵌的店铺自有付款页面上进行的。请先由具有 WP Admin 访问权限的人员[设置网关](#setup)。

:::note 请先开启收银
启用**开启和关闭收银**后，收银关闭期间收银机无法记录付款，已收取的银行卡付款将需要退款。请参阅[结账](../../pos/checkout/index.mdx)。
:::

终端通过结账界面的**旧版**选项卡运行。下图中尚未设置 Mercado Pago，因此列表显示的是其他网关，并已选中**银行卡**。在您的店铺中，**Mercado Pago Terminal** 会出现在该列表中：

1. **旧版**选项卡 — 在 POS 内打开店铺自有的付款页面。
2. **店铺付款页面** — 显示订单总额和店铺的支付网关。设置完成后，**Mercado Pago Terminal** 会出现在此列表中。选中它后，下方便会展开面板，其中包含**终端**和**开始终端付款**。
3. **处理付款** — Mercado Pago 无需使用此按钮：付款确认后，销售会自动完成。

</JourneyShot>

1. 将商品加入购物车，然后按**结账**。
2. 打开**旧版**选项卡。店铺的付款页面会在 POS 内打开。请参阅[旧版选项卡](../../pos/checkout/legacy-tab.mdx)。
3. 选择 **Mercado Pago Terminal**。您的店铺可能已将其改为其他名称。
4. 检查**终端**下的设备。默认终端已预先选中；如果终端选择已锁定，则无法更改。
5. 按**开始终端付款**。面板先显示**正在发送至终端…**，随后显示**正在等待终端…**，订单的全部金额会发送至该终端。
6. 顾客在终端上付款。付款期间，面板显示**顾客正在终端上付款…**。如果显示**请在终端上确认付款。** 请按终端提示完成操作。
7. Mercado Pago 确认付款后，面板显示**付款完成 — 正在完成订单…**，POS 随后进入收据界面。

无需使用旧版选项卡底部的**处理付款**按钮：Mercado Pago 确认后，销售会自动完成。如果提前按下该按钮，只会提示订单尚未付款。

终端始终收取整笔订单金额，因此无法与其他付款方式组合支付同一笔销售。订单已有付款后，将无法使用旧版选项卡；请先[取消该笔付款](../../pos/checkout/cancelling-a-payment.mdx)。

### 取消或等待 {#payment-controls}

- 付款进行期间，**取消终端付款**会替代**开始终端付款**。只有在终端接收付款前才能取消。此后，面板会显示**付款已发送到终端。请在终端上取消，或等待其过期。**
- 发起付款 5 分钟后，**付款会过期**，由 Mercado Pago 处理。面板会持续查询，因此顾客在过期前完成付款，仍可完成销售。
- **重新加载页面**会恢复正在进行的付款，并显示**取消终端付款**。
- 付款期间**如果收银机已关闭**，请勿再次向银行卡扣款。店铺设计为通过 Mercado Pago 通知以及每 5 分钟运行一次的检查，自动完成已付款订单，但此功能尚未经实际运行验证。请打开订单及 Mercado Pago 账户中的付款记录，检查是否已付款。

## 销售完成后 {#receipts}

终端不会打印小票。请照常打印 POS 收据或通过电子邮件发送；请参阅[结账时的收据](../../receipts/at-checkout.mdx)。

订单会记录这笔付款，并将 Mercado Pago 的订单 ID 用作交易 ID。

## 退款 {#refunds}

在 WP Admin 中打开订单，点击**退款**，输入金额，然后按**通过 Mercado Pago Terminal 退款 …**。退回整笔订单金额即为全额退款，退回较小金额则为部分退款。Mercado Pago 允许在付款后 **90 天**内退款。

某些银行卡收单机构只允许在终端上退款。如果 Mercado Pago 拒绝退款，请在 Point 终端上退款，然后在 WooCommerce 中使用**手动退款**记录退款。请参阅[退款](../../pos/refunds.mdx)。

<details>
<summary>Mercado Pago Terminal 已禁用。</summary>

此网关在 POS 中处于关闭状态。请让 WP Admin 管理人员[将其启用](#turn-on)。

</details>

<details>
<summary>Mercado Pago Terminal 请求失败。</summary>

收银机无法连接到店铺或 Mercado Pago。如果顾客可能已付款，请先检查订单及 Mercado Pago 账户，再发起另一笔付款。否则，请检查连接并重试。如果问题持续发生，请发送[支持信息包](#logs-and-support-bundle)。

</details>

### 付款停滞或失败 {#stalls}

重新发起付款前，请先查看终端。**切勿向银行卡重复扣款**：如果顾客可能已付款，请先检查订单及 Mercado Pago 账户。

<details>
<summary>仍在等待终端。</summary>

已过一分钟，仍未收到响应。如果终端显示了付款，请让顾客完成付款；否则，按**取消终端付款**并重新开始。

</details>

<details>
<summary>付款已发送到终端。</summary>

请在终端上取消，或等待 5 分钟让付款过期。面板会持续查询，因此如果顾客仍完成了付款，销售也会完成。

</details>

<details>
<summary>付款失败。</summary>

银行卡或付款被拒绝。请按**开始终端付款**重试，或使用其他方式收款。

</details>

<details>
<summary>付款已在终端上过期。</summary>

已过五分钟。请再次按**开始终端付款**。

</details>

<details>
<summary>等待终端超时。</summary>

已过六分钟，仍无结果，收银机会请求 Mercado Pago 取消付款。重新发起付款前，请先检查终端。

</details>

<details>
<summary>Mercado Pago 报告的付款与此订单不匹配。</summary>

付款与此订单不匹配，例如总额或币种发生了变化。请勿再次向银行卡扣款。请检查订单备注及 Mercado Pago 账户中的付款记录，并联系经理。

</details>

<details>
<summary>设置过程中的提示</summary>

**访问令牌无权使用 Point（HTTP 403）。** 令牌所属的应用无法使用 Point。请在**您的集成**中检查该应用。

**无法连接到 Mercado Pago。** 店铺无法建立连接。请检查令牌，然后重新加载设置页面。

**此 Mercado Pago 账户尚未关联任何 Point 终端。** 请在终端上使用此 Mercado Pago 账户登录，然后切换至 PDV 并重启。

**默认终端显示为文本框，而非列表。** 无法加载终端列表。请检查令牌及诊断信息，然后重新加载设置页面。

**已选择正式模式，但访问令牌是测试令牌（TEST-…）。** 付款将发送至 Mercado Pago 沙盒。请粘贴生产环境令牌，或将**模式**切回**测试**。

**上次验证的 Webhook：从未。** Mercado Pago 尚未发送带签名的通知。请检查 Webhook URL 和 **Webhook 密钥**。只要付款面板保持打开，仍可完成付款。

**Mercado Pago 拒绝了退款。** 某些收单机构只允许在终端上退款：请在终端上退款，再使用**手动退款**记录。

**无法激活。** 服务器需要 **PHP 7.4** 或更高版本。

</details>

## 设置 {#setup}

本部分面向店铺的 WP Admin 管理人员。开始步骤 1 前，请检查[所需条件](#requirements)。

### 所需条件 {#requirements}

<RequirementsList>
  <RequirementItem label="Mercado Pago 账户">阿根廷、巴西、墨西哥、乌拉圭、哥伦比亚、智利或秘鲁的卖家账户，以及应用和该应用的访问令牌</RequirementItem>
  <RequirementItem label="终端">处于 PDV 模式的 Mercado Pago Point Smart 1 或 2</RequirementItem>
  <RequirementItem label="连接">仅限在线使用。店铺通过互联网将每笔付款发送至终端，因此任意收银机都可使用任意终端，并在结账时选择设备</RequirementItem>
  <RequirementItem label="WCPOS">WCPOS Pro</RequirementItem>
  <RequirementItem label="服务器">WordPress 5.2 或更高版本、WooCommerce，以及 PHP 7.4 或更高版本</RequirementItem>
  <RequirementItem label="币种">与 Mercado Pago 账户使用相同的币种</RequirementItem>
</RequirementsList>

### 1. 安装扩展 {#install}

打开 `WP Admin > POS > 设置 > 扩展`，找到 **Mercado Pago Terminal for WooCommerce**，然后点击**安装**。WCPOS 会一次完成下载、安装和激活。请参阅[安装扩展](../../extensions/index.mdx#installing-an-extension)。

如果无法使用扩展目录，请从 [GitHub 发布页面](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases)下载**插件 zip 文件**（不是源代码 zip 文件），在`插件 > Add Plugin`中使用**上传插件**上传，然后激活。WooCommerce 必须已激活。

### 2. 在 Mercado Pago 中做好准备 {#mercado-pago-account}

1. 在**您的集成**下创建应用，并激活其生产环境凭据。Mercado Pago 会要求提供行业和网站信息、接受条款并通过 reCAPTCHA 验证。
2. 在 Mercado Pago 中创建**店铺**和**销售点**。扩展不会自动创建这些项目。
3. 关联 Point Smart 终端：在终端上使用同一个 Mercado Pago 账户登录。

### 3. 填写网关设置 {#gateway-settings}

1. 转到 `WP Admin > WooCommerce > 设置 > 支付`，然后打开 **Mercado Pago Terminal**。
2. 选择**模式**：**测试**（默认）使用 Mercado Pago 的沙盒虚拟终端；**正式**使用真实终端。
3. 从**您的集成** → **凭据**下的应用中复制**访问令牌**(`APP_USR-…`)并粘贴到此处。请使用与**模式**相符的令牌。
4. 如果使用的币种没有小数单位，例如智利比索，请在 `WooCommerce > 设置 > General` 下将**小数位数**设为 **0**。Mercado Pago 会拒绝这些账户中带小数的金额，只有此设置为 0 时，扩展才会发送整数金额。
5. 保存。

### 4. 添加 Webhook（推荐） {#webhook}

Webhook 可让 Mercado Pago 在付款完成时通知店铺。它设计为即使收银机已关闭，也能完成已付款订单，但尚未经实际运行验证：再次收款前，请先[检查订单](#payment-controls)。即使没有 Webhook，只要付款面板保持打开，仍可完成付款。

1. 在 Mercado Pago 中，打开**您的集成** → 您的应用 → **Webhook**。
2. 添加网关设置中 **Webhook 密钥**下显示的 Webhook URL。该地址以 `admin-ajax.php?action=mptfwc_webhook` 结尾。
3. 选择**订单（Mercado Pago）** 事件并保存。
4. 将**签名密钥**复制到 **Webhook 密钥**，然后保存。保存密钥后，店铺会拒绝所有未使用该密钥签名的通知。未设置密钥时，店铺仍会处理 Mercado Pago 的通知，但无法验证通知是否确实来自 Mercado Pago，且**上次验证的 Webhook** 会一直显示**从未**。

### 5. 设置终端 {#terminals}

1. 重新加载设置页面。**默认终端**列表和**终端**表格现在会显示您账户下的终端。
2. 终端出厂时处于 **STANDALONE** 模式。对每台终端点击**切换至 PDV**，然后**重启终端**。Mercado Pago 要求重启后才能生效。
3. 选择**默认终端**。
4. 可选：将**已启用终端**限制为收银员可选择的设备。留空表示允许使用全部终端；默认终端始终允许使用。
5. 可选：勾选**锁定终端选择**，让收银员始终使用默认终端。
6. 保存。

### 6. 在 POS 中启用 {#turn-on}

转到 `WP Admin > POS > 设置 > 结账`，找到 **Mercado Pago Terminal**，然后开启**已启用**。请参阅[启用网关](../../settings/wp-admin/checkout.mdx#enabling-a-gateway)。

除非也希望在网店中使用此网关，否则请保持 WooCommerce 设置中的**启用/禁用**处于关闭状态。只要在此处启用，POS 就会使用此网关，无论是否勾选该复选框。

## 设置参考 {#settings}

位于 `WP Admin > WooCommerce > 设置 > 支付 > Mercado Pago Terminal`。上述步骤涵盖了必要设置；展开列表可查看全部设置及其默认值。

<details>
<summary>全部 11 项设置及诊断信息</summary>

| 设置 | 作用 |
|---|---|
| **启用/禁用** | 同时在网店中提供此网关。默认关闭。POS 有独立的开关，位于`POS > 设置 > 结账` |
| **标题** | 收银员在付款页面上选择的名称。默认为 `Mercado Pago Terminal` |
| **描述** | 标题下方显示的文字。默认为 `Pay in person on a Mercado Pago Point terminal.` |
| **模式** | **测试**（默认）使用沙盒虚拟终端；**正式**使用真实终端 |
| **访问令牌** | 来自“您的集成 → 凭据”下的应用。保存后不再完整显示，仅显示最后四个字符；留空即可保留现有令牌 |
| **Webhook 密钥** | 来自 Mercado Pago Webhook 设置的签名密钥。保存和显示方式与令牌相同 |
| **默认终端** | 开始时选中的终端。通常显示从账户获取的列表，无法加载列表时则显示文本框 |
| **已启用终端** | 收银员可选择的终端。留空表示允许全部；默认终端始终允许使用。无法加载列表时隐藏 |
| **锁定终端选择** | 收银员无法更改终端，始终使用默认终端。需要先设置默认终端 |
| **结账调试日志** | 在付款面板上显示**显示日志**、**复制**和**清除**。默认关闭；需要收集日志供支持人员排查时开启。无论是否开启，都会记录付款日志 |
| **日志级别** | **关闭**、**仅错误**或**调试**（默认） |

设置下方的 **Mercado Pago Terminal 诊断**会显示 API 检查结果，包括终端数量及其中处于 PDV 模式的数量、上次验证的 Webhook、当前环境、令牌与密钥是否已设置、默认终端、Webhook URL 以及日志链接。**终端**表格列出每台终端的 ID、标签和运行模式，并在需要时提供**切换至 PDV**。

</details>

## 日志和支持信息包 {#logs-and-support-bundle}

日志位于 `WP Admin > WooCommerce > Status > 日志`，来源为 `mercadopago-terminal`。**日志级别**默认为**调试**，会记录发送到 Mercado Pago 的每个请求及其响应、每个 Webhook 和付款状态的每次变化，并移除令牌、签名和卡号。

付款失败时，请在网关设置页面点击**下载支持信息包**，将 `.txt` 文件连同**订单号**发送给支持人员。其中不含可用于收款的信息。

<details>
<summary>支持信息包包含的内容</summary>

- 店铺配置：扩展、WordPress、WooCommerce、PHP 和 WCPOS 的版本，以及是否开启 HPOS。
- 网关设置，其中访问令牌和 Webhook 密钥已被遮蔽。
- 终端及其运行模式。
- 最近 10 笔使用终端的订单中的付款尝试记录。
- `mercadopago-terminal` 日志的最后 500 行。

</details>

## 不支持的功能 {#scope-and-limitations}

- 分笔付款：终端始终收取整笔订单金额。
- 小费。
- 店铺计价币种与 Mercado Pago 账户币种不同：订单将无法完成。
- 在终端上打印小票。
- 网店的区块结账。
- HPOS（WooCommerce 的订单表）：此扩展尚未声明支持。

<details>
<summary>开发者参考：工作原理</summary>

此网关使用 Mercado Pago 面向 Point 的**订单 API**（`POST /v1/orders`，参数为 `type: point`）。发起付款时，会在订单上保存幂等键和外部引用，再针对所选终端按订单总额创建 Mercado Pago 订单，有效期为 5 分钟（过滤器 `mptfwc_order_expiration_time`）。超时后重试会复用该键，因此不会重复扣款。

面板每 2 秒查询一次状态（过滤器 `mptfwc_poll_interval_ms`），6 分钟后停止等待。Webhook（`x-signature`，HMAC-SHA256）以及每 5 分钟运行一次的定时检查也可完成订单；系统从不直接信任 Webhook 正文，而是始终重新从 Mercado Pago 获取订单。

只有在 Mercado Pago 订单明确关联此订单、由本店铺为此订单创建、属于 `point` 订单、总额和币种匹配，且使用了本次付款尝试的终端时，订单才会完成。完成操作在每个订单独立的锁保护下仅执行一次。交易 ID 即 Mercado Pago 订单 ID。

</details>
