报表显示某台收银机、某家店铺或所有店铺在一段时间内的销售情况：总额及对比，以及付款、商品、收银员、税费和退款卡片。从侧边菜单的**报表**打开。所有数据都由设备根据已下载的订单计算。

1. 报表默认显示今天店铺内所有收银机的数据（免费版插件仅显示此设备的收银机）。若要查看其他数据，请先[选择时段](#dates)，再选择[店铺和收银机](#scope)。
2. [查看销售数据](#sales)：总额及对比。
3. 若要了解详情，请向下滚动至[卡片](#cards)，点击卡片上的箭头以[打开面板](#panels)。

:::info 免费版与 Pro
免费版插件的报表显示此设备收银机今天的数据。[WCPOS Pro](../getting-started/free-vs-pro.mdx#at-a-glance) 可查看更早日期、其他收银机、所有店铺的数据以及交班历史记录。
:::

## 选择时段 {#dates}

打开**报表**，点击顶部的时段即可打开预设选项和日历。

<JourneyShot manifest={manifest} device="tablet" step={2} alt="时段菜单：今天、昨天、本周、上周、本月和上月，旁边是选中 6 日的十一月日历，以及完成按钮">

1. **今天**和**昨天** — 单日数据，与前一天或上周同一星期几对比。
2. **本周**和**上周** — 一个自然周。本周截至今天。
3. **本月**和**上月** — 一个自然月。本月截至今天。
4. **日历** — 点击一个日期可选择当天，点击两个日期可选择两者之间的时段。
5. **完成** — 应用所选日期。

</JourneyShot>

<details>
<summary>时段被锁定时</summary>

免费版插件中，除**今天**外的所有时段均带锁图标。点击后会显示**查看更早日期需使用 WCPOS Pro**，以及**查看 Pro** 按钮。

</details>

## 选择店铺和收银机 {#scope}

点击顶部的店铺和收银机名称。

<JourneyShot manifest={manifest} device="tablet" step={3} alt="店铺和收银机菜单，包含店铺组（所有店铺、AL Store、AL 12345 Store）和收银机组（所有收银机、收银机）">

1. **所有店铺** — 在一份报表中显示所有店铺。仅在有多家店铺时出现。
2. **某家店铺** — 单家店铺的销售额。
3. **所有收银机** — 店铺内所有收银机，以及线上订单。
4. **某台收银机** — 单台收银机的销售额。

</JourneyShot>

<details>
<summary>店铺或收银机被锁定时</summary>

免费版插件只能打开当前登录的店铺和收银机。其他选项带锁图标，选择后会显示**查看其他收银机需使用 WCPOS Pro**（或**其他店铺**、**所有店铺**），以及**查看 Pro**。

</details>

时段旁的两个按钮可进一步缩小统计范围。点击**所有人**，可从曾在此设备上登录的收银员中选择。在收银员卡片上，从未登录过此设备的收银员会显示为编号，例如 **#8**。点击**已完成和处理中**，可改为选择**所有状态**。

在手机上，时段和打印按钮位于顶部同一行，**所有人**与**已完成和处理中**在下方分两列显示。[排除订单](#leave-out)后，这里还会出现**已排除订单**按钮。

## 查看销售数据 {#sales}

页面顶部展示所选时段、店铺和收银机的经营表现。总额包含所有付款方式和税费，尚未扣除退款。它不是钱箱中的现金；钱箱现金显示在收银机状态栏的**钱箱预计金额**中。

:::caution 请等待订单下载完成
请等到顶部的**正在下载订单**消失后再使用这些数据。当所选时段的订单数多于设备上的订单数时，会出现此提示，并显示已下载的数量。
:::

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-22, 0], [-22, 0], [-22, 0], [0, 0], [0, 0], [0, 0]]} alt="平板电脑上所有收银机昨天的报表：店铺和收银机名称、收银机状态栏、时段、收银员和状态筛选按钮、打印汇总、$520.00 总计及订单数、平均订单金额和商品件数、与昨天对比按钮，以及按小时图表">

1. **店铺和收银机** — 数据涵盖的店铺和收银机。参阅[选择店铺和收银机](#scope)。
2. **收银机状态栏** — 此设备收银机的当前班次：**已开班**或**已关班**，以及**钱箱预计金额**。无论选择哪个店铺、收银机或时段，该栏内容都不变。参阅[收银机状态栏与交班记录](#closures)。
3. **时段** — 数据涵盖的日期。参阅[选择时段](#dates)。
4. **收银员** — **所有人**或某位收银员的销售额。
5. **状态** — **已完成和处理中**统计已售出的订单。**所有状态**还会包含待付款和保留订单。
6. **打印汇总** — 打印所选时段的**销售汇总**。参阅[打印或导出](#print)。

</JourneyShot>

筛选按钮下方是数据和图表。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-10, -30], [60, -26], [0, 0], [0, 0]]} alt="昨天的数据：$520.00，与昨天相比下降 85.1%，订单数 22、平均订单金额 $23.64 和商品件数 16，各自带有变化幅度；另有与昨天对比按钮，以及用虚线表示前一天数据的按小时图表">

1. **总计** — 所选时段的含税销售额，尚未扣除退款（**退款**卡片显示实际保留的金额）。它包含所有付款方式，不是钱箱中的现金。下方以百分比显示相对于对比时段的变化。红色表示下降，绿色表示上升。
2. **订单数、平均订单金额、商品件数** — 各自显示相对于对比时段的变化。**—** 表示没有可供对比的数据。
3. **对比** — 计算变化时所用的基准。查看单日时，可选择**与昨天对比**，或选择**与上周对比**及对应的星期几。参阅[对比方式](#comparisons)。
4. **图表** — 单日可选**按小时**，较长时段可选**按天**，也可选择**累计总额**查看该时段的累积变化。虚线表示对比时段。

</JourneyShot>

### 对比方式 {#comparisons}

数据下方的对比按钮会标明计算变化时使用的基准时段。单日与前一天或上周同一星期几对比，一周与前一周对比，一个月与前一个月对比。

<details>
<summary>对比时段的计算方式</summary>

- **单日**与前一天或上周同一星期几对比，取决于您在对比按钮中所选的选项。
- **今天**的数据实时变化，因此会按相同时间点对比：下午 3 点时，与昨天截至下午 3 点的数据对比。
- **一周**或任意两至七天的时段，会与一周前的对应日期对比。按钮显示**与前一周对比**，且无法更改。
- **完整自然月**与前一个完整自然月对比。**本月**及任意超过七天的时段，会与起点提前一个月、天数相同的时段对比。按钮显示**与前一个月对比**。
- 数据下方的 **—** 表示对比时段内没有订单。

</details>

## 查看卡片 {#cards}

向下滚动可查看卡片。每张卡片都可打开包含完整列表的面板。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-26, 0], [-26, 0], [-26, 0], [-26, 0], [-26, 0]]} alt="本周报表卡片：订单及其平均值和状态条、按付款方式划分的付款、分为店内和线上的销售渠道，以及畅销商品">

1. **订单** — 展示典型订单的数据，以及**已完成**、**处理中**和**已退款**订单的分布条。
2. **需要处理** — 仍处于处理中、保留或待付款状态的订单数。没有此类订单时显示**无需处理**。
3. **付款** — 按付款方式划分的销售额及各自占比。**未付款**是订单仍未支付的金额。**未知**表示订单未记录付款方式。
4. **销售渠道** — 对比**店内**与**线上**。当数据涵盖多台收银机时，可切换为**收银机**；选择**所有店铺**时，可切换为**店铺**。未关联收银机的订单显示为**无收银机**。
5. **畅销商品** — 按销售额排名的畅销商品，包含各自的占比和售出数量。

</JourneyShot>

<details>
<summary>订单数据的含义</summary>

- **平均订单金额** — 销售额除以订单数。
- **中位数** — 排在中间的订单总额，一半订单的总额低于此值。
- **最大订单** — 金额最高的订单。
- **售出商品数** — 订单包含的商品件数。
- **每单商品数** — 售出商品数除以订单数。
- **折扣** — 已提供的折扣金额。

</details>

继续向下可查看：

- **分类** — 按商品分类划分的销售额。
- **品牌** — 按品牌划分的销售额。
- **收银员** — 每位收银员的销售额。
- **税费** — 各税率对应的税额，每项均注明**计税基数**，即征税所依据的净销售额。
- **退款** — 所选时段内的退款：退款金额、涉及的订单数，以及该时段销售额中实际保留的金额。退款计入实际退款所在的时段，即使订单来自更早日期。

<details>
<summary>缺失的商品、分类或品牌</summary>

- 分类卡片上的**未分类**表示商品不属于任何分类。
- **未知商品**表示该订单项对应的商品不在此设备上，因此无法确定其分类。提示会说明此类订单项的数量，例如 **117 个订单项中有 58 个没有本地商品**。这些销售额仍计入总额。
- 品牌卡片上的**无品牌**表示商品未设置品牌。仅当商品带有品牌或店铺跟踪商品成本时，才会显示品牌卡片。

</details>

## 打开面板 {#panels}

点击卡片上的箭头。在平板电脑上，面板从右侧滑入并覆盖报表，侧边菜单仍保留在旁边。在手机上，面板会作为独立页面打开，点击顶部的**销售**可返回。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-18, 0], [0, 0], [-34, 0], [-10, 0], [0, 0]]} alt="本周的畅销商品面板：所有分类筛选器、包含数量、金额、成本、利润和利润率 % 列的报表预览、提示 134 件商品中有 134 件缺少成本的状态行，以及关闭、导出 CSV 和打印报表">

1. **时段和收银机** — 面板涵盖的范围。
2. **筛选** — 畅销商品可按单个分类筛选（**所有分类**），按品牌销售额可按单个品牌筛选。
3. **状态行** — 订单数和总额。启用商品成本后，还会显示缺少成本的商品件数。参阅[成本、利润和利润率](#margin)。
4. **导出 CSV** — 将列表保存为 CSV 文件。在浏览器中会下载文件；在应用中会打开分享面板。
5. **打印报表** — 使用预览上方显示的**模板**和**打印机**打印列表。

</JourneyShot>

面板包括**订单**、**按付款方式销售额**、**畅销商品**、**按分类销售额**、**按品牌销售额**、**按收银员销售额**、**已收税费**（各税率对应的净额、税额和含税总额）、**退款**，以及销售渠道中的**渠道**、**收银机**或**店铺**。

## 排除订单 {#leave-out}

测试销售或员工购买可能影响当天的数据。打开**订单**面板，取消勾选要排除的订单。

<JourneyShot manifest={manifest} device="tablet" step={6} maxWidth={543} alt="昨天的订单面板顶部：所有订单复选框呈部分选中状态，已排除 2 笔；下方按编号列出订单及其时间、收银员、总计和付款方式，其中两笔取消勾选并呈灰色">

1. **所有订单** — 勾选或取消勾选全部订单。旁边显示已排除的数量，此处为**已排除 2 笔**。
2. **某笔订单** — 取消勾选即可排除。该订单会变灰，面板底部显示 **38 笔中已计入 36 笔 · 数据随之更新**。

</JourneyShot>

每行显示订单号、时间和收银员、总计及付款方式。面板列出最近的 60 笔订单，并提示还有多少笔。若要查找更早的订单，请先缩小报表范围：选择更短的时段、单台收银机或单个收银员。报表数据和卡片会重新计算，不再包含已排除的订单。收银机状态栏保持不变。

随后，状态旁的**已排除订单**按钮会显示类似**已排除 2 笔订单**的文字。点击可返回订单面板，或点击其 **×** 将这些订单重新计入。排除订单只会更改此设备上的这份报表，不会修改订单本身。若取消勾选所有订单，订单卡片会显示**所有订单均已排除**。

## 打印或导出 {#print}

- 顶部的**打印汇总**可打印所选时段的**销售汇总**：销售额（净额、税费、退款和折扣）、付款方式、税费、运费；若有多个店铺、收银机或收银员，还会列出各自数据；此外还包含售出商品数和平均订单金额。已排除的订单仍不计入。
- 面板中的**打印报表**可打印该面板的列表。
- 面板中的**导出 CSV** 可保存该列表。

打印使用您的[收据模板](../receipts/index.mdx)和所选打印机。

<details>
<summary>打印等待或失败时</summary>

- **仍在加载。** 报表或模板尚未加载完成时，打印面板会显示对应提示：**正在等待店铺响应**、**正在加载报表**、**仍在加载此时段的订单**、**仍在加载此时段的退款**或**正在加载模板**。加载完成后即可打印。
- **没有可离线打印的模板 · 请在 WP Admin 中管理模板。** 此设备没有可离线打印的模板。模板需在 WP Admin 中管理。
- **已保存的打印机无法打印此模板。** 模板与打印机不匹配：请在面板中选择另一台打印机。
- **“无法打印。请重试。”或“导出失败。请重试。”** 请重试。如果打印持续失败，请检查面板中的打印机。

</details>

## 成本、利润和利润率 {#margin}

当店铺跟踪[商品成本](../products/index.mdx#cost-of-goods-sold)时，畅销商品、按分类销售额和按品牌销售额面板会增加**成本**、**利润**和**利润率 %** 列。未设置成本的商品会在这些列中显示 **—**，状态行还会显示缺少成本的商品件数，例如 **40 件商品中有 3 件缺少成本**，便于您判断利润率的参考价值。

## 收银机状态栏与交班记录 {#closures}

收银机状态栏显示此设备的收银机状态：**已开班**或**已关班**、状态开始时间和开班人，以及钱箱金额计算式：**期初备用金 + 现金销售额 − 现金退款 = 钱箱预计金额**。如果班次中有**存入**和**支出**，也会纳入计算。**打印 X 报表**打印当前未结束的班次；已关班的收银机则提供**打印交班记录**。未关联收银机的设备显示**此设备没有收银机**。

使用 WCPOS Pro 时，状态栏末尾的箭头可打开**交班记录**，列出您可查看的收银机的所有编号交班记录，供重新打印、重新清点或核查。此处的**导出 CSV** 可保存列表中的交班记录。`WP Admin > POS > 设置`中**工具**下的**导出交班记录**可下载全部交班记录。每日操作流程请参阅[对账](./reconciliation.mdx)。

## 在 WooCommerce 分析中查看更长时段 {#woocommerce-analytics}

若要导出订单明细或查看任意日期范围，请使用 `WP Admin > WooCommerce > Analytics`。它读取的是同一批订单。使用 WCPOS Pro 时：

- **订单**报表的订单类型筛选器会增加 **POS 订单**和**线上订单**。
- **营收**报表会增加**店铺**、**收银员**和**付款方式**筛选器，各项在对应选项超过一个时显示。

## 遇到问题时 {#goes-wrong}

**“不允许访问报表”。** 您的用户没有*查看报表*权限。参阅[访问权限](../settings/wp-admin/access.mdx)。

**数据看起来偏低。** 检查状态按钮：**已完成和处理中**不包含待付款和保留订单。检查是否有**已排除订单**按钮，然后检查店铺、收银机和收银员。

**商品显示为未知商品。** 此设备上没有该商品，因此无法为对应订单项确定分类。销售额仍计入总额。

**收银员显示为编号。** 该收银员从未在此设备上登录。销售额仍归属于该收银员，只是缺少姓名。

**打印处于等待状态或失败。** 请展开[打印或导出](#print)下的**打印等待或失败时**。

:::info 使用 WCPOS Pro
Pro 可查看更早日期、自定义时段、其他收银机、**所有店铺**以及**交班记录**历史。参阅[免费版与 Pro 对比](../getting-started/free-vs-pro.mdx#at-a-glance)。
:::
