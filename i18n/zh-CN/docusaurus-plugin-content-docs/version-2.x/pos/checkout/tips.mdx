顾客在读卡器上添加小费，而不是在收银机上操作。收银机发送应付金额，读卡器提示顾客选择小费，收银机再记录读卡器实际收取的金额。收银机上没有小费按钮。

## 收取含小费的银行卡付款 {#take-a-tip}

:::info Pro 功能
通过读卡器收取小费需要 [WCPOS Pro](../../getting-started/pro-license.mdx)，以及支持提示顾客支付小费的读卡器。
:::

开始前，请确认[读卡器支持提示支付小费](#which-readers)。如果启用了 **开启和关闭收银台**，请先[开启收银台](../register/index.mdx#open)：收银台关闭时，收银机不会记录付款。

1. 点击 **结账**，然后点击读卡器对应的卡片。参阅[使用读卡器](./taking-a-payment.mdx#card-reader)。
2. 点击 **将 … 发送到 …**。按钮上显示应付金额和付款方式，收银机会将该金额发送到读卡器。
3. 顾客在读卡器上选择小费金额，或选择不付小费，然后付款。
4. 收银机的收款面板中，该笔付款所在行会显示读卡器收取的总金额，下方显示 **小费：** 及小费金额。

订单中会新增名为 **小费** 的费用项，因此订单总额会增加相应的小费金额，而这笔小费已经支付。收据会将小费与订单的其他费用一同列出。小费不计税。

<details>
<summary>对小费计税（面向开发者）</summary>

需要对小费计税的店铺可以通过 `wcpos_payment_tip_fee_taxable` 过滤器启用此功能。税款会从小费中扣除，因此顾客支付的金额仍是其在读卡器上选择的金额。

</details>

## 哪些读卡器会提示支付小费 {#which-readers}

| 付款方式 | 提示支付小费的条件 |
|---|---|
| [Stripe Terminal](../../payment/gateways/stripe-terminal.mdx) | 在 Stripe 控制面板中为读卡器启用小费后，WisePad 3、WisePOS E、S700 和 S710 支持此功能。M2 和 Tap to Pay 不支持。 |
| [SumUp Terminal](../../payment/gateways/sumup-terminal.mdx) | 与 WCPOS 应用配对的蓝牙读卡器支持。通过互联网连接的读卡器不支持。 |
| [Mollie Terminal](../../payment/gateways/mollie-terminal.mdx) | 所有读卡器。 |

以下付款方式不会提示支付小费：

- [Square Terminal](../../payment/gateways/square-terminal.mdx)
- [PayArc Terminal](../../payment/gateways/payarc-terminal.mdx)
- [Windcave Terminal](../../payment/gateways/windcave-terminal.mdx)
- [Mercado Pago Terminal](../../payment/gateways/mercadopago-terminal.mdx)
- [PayPal Reader (Zettle)](../../payment/gateways/paypal-reader.mdx)

**银行卡** 卡片用于记录通过自有终端收取的银行卡付款，不包含小费。参阅[付款方式](./payment-methods.mdx)。

## 从钱箱支出小费 {#pay-out-tips}

向员工发放现金小费时，请将其记录为现金支出，以确保钱箱金额核对准确。免费版插件也支持此功能。需要启用 **开启和关闭收银台**；参阅[存入和取出现金](../register/index.mdx#cash-movements)。

1. 点击收银台栏末端的头像，再依次点击 **钱箱内现金** 和 **现金支出**。
2. 在数字键盘上输入要发放的金额。
3. 点击 **原因** 下的 **小费**。这会填入原因，而不会填入金额。
4. 点击 **取出 …**。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[180, 0], [370, 0], [-4, 0], [0, 0], [0, 0], [100, 0], [-14, -36]]} alt="现金支出面板：数字键盘上已输入两美元，显示支出前后的钱箱金额，已选择并填入小费原因，以及取出 $2.00 按钮">

1. **金额** — 要取出的金额，随输入更新。
2. **钱箱内现金** — 显示收银台、当前预计现金金额，以及此次支出后的余额。
3. **数字键盘** — 用于输入金额，也可以使用键盘。
4. **小费** — 支出原因。点击可将其填入原因框，再次点击可清除。
5. **其他…** — 清空输入框并将光标移入其中，以便自行输入原因。
6. **原因** — 每笔现金支出都需要填写原因。未填写时，面板会提示 **添加原因**。
7. **取出 $2.00** — 显示取出金额。点击可记录现金支出。点击 **取消** 则保持钱箱金额不变。

</JourneyShot>

要核对记录，请点击 **钱箱内现金** 打开收银台面板，再点击 **钱箱预计金额** 行查看明细。这笔支出及其原因会列在 **现金支出** 下。如果记录有误，请点击该笔记录上的 **作废**。只有收银台开启且未在盘点时才能作废。已作废的现金支出无法恢复，需要重新录入。参阅[出现问题时](../register/index.mdx#goes-wrong)。

## 出现问题时 {#goes-wrong}

**读卡器没有提示支付小费。** 请查看[表格](#which-readers)：部分付款方式和读卡器不支持提示支付小费。使用 Stripe 时，请在 Stripe 控制面板中为读卡器启用小费。

**付款失败：终端确认的金额不一致。** 读卡器收取的金额高于收银机发送的金额，而所用付款方式不支持小费，因此收银机将该笔付款标记为失败，且未将其计入订单。

:::warning
再次向顾客收款前，请先向支付服务商核实付款情况，否则可能重复收费。
:::

如果服务商显示已扣款，请在服务商处退款：收银机无法退还失败的付款。订单中的这笔金额仍待支付，请使用可用的付款方式重新收款。
