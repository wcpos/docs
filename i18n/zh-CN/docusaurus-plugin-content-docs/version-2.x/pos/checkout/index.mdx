客户拿着要购买的商品来到收银处。本页以一笔现金销售为例，介绍从添加第一件商品到接待下一位客户的完整流程。

:::note 请先开启收银机
启用 **开启和关闭收银机** 后，收银机关闭期间，收银端不会记录付款；如果已通过银行卡收款，则需要退款。有关设置，请参见[收银机](../../settings/wp-admin/registers.mdx#one-register)；有关运作方式，请参见[店铺、收银机和设备](../../stores/registers-and-devices.mdx)。
:::

## 添加商品到购物车 {#cart}

点击商品即可将其加入购物车，再点一次会再添加一件。商品和购物车并排显示；在手机上，两者分别位于不同的选项卡。

每笔销售开始时都会使用店铺的默认客户，即[默认 POS 客户](../../settings/wp-admin/general.mdx#default-pos-customer)指定的客户；如果启用了[使用收银员账户](../../settings/wp-admin/general.mdx#use-cashier-account)，则使用收银员账户。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[180, 0], [281, 0], [141, -224], [103, 0], [54, -38], [6, 56], [-27, 0], [165, 0], [12, 0]]} alt="购物车中有一块手表的 POS：收银机栏、搜索框、商品网格、未完成订单，以及购物车中的客户、数量、添加菜单、小计和结账按钮">

1. **收银机栏** — 当前使用的收银机及其班次。参见[店铺、收银机和设备](../../stores/registers-and-devices.mdx)。
2. **搜索** — 输入名称或 SKU，或[扫描条形码](../product-panel/barcode-scanning.mdx)。参见[搜索和筛选](../product-panel/search-filtering.mdx)。
3. **商品** — 点击即可添加。如果商品有可选规格，系统会让您选择；参见[变体](../product-panel/variations.mdx)。
4. **未完成订单** — 此收银机上正在处理的所有销售。点击即可切换到相应订单。参见[未完成订单](../cart/open-orders.mdx)。
5. **客户** — 此笔销售的客户。点击可选择其他客户。参见[购物车](../cart/index.mdx)。
6. **数量** — 点击后输入新数量，再点击 **完成**。参见[订单项目](../cart/line-items.mdx#quantity)。
7. **添加菜单** — 添加新客户、商品目录中没有的商品、附加费用或折扣。参见[折扣](../cart/discounts.mdx)。
8. **小计** — 收款前的订单金额。
9. **结账** — 显示总额。确认购物车无误后点击。

</JourneyShot>

## 收款 {#take-cash}

点击 **结账**。收款界面会在订单旁打开，以大号数字显示待付金额，并选中第一种付款方式。在手机上，该界面占满屏幕，顶部显示 **结账订单 #** 和订单号。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[28, 42], [29, 42], [-55, 0], [66, 0], [-4, 0], [122, 0], [0, 0], [0, 0]]} alt="$45.00 现金销售的收款界面：付款和传统选项卡、显示待付金额的待付区域、拆分、现金和银行卡卡片、快捷金额、数字键盘和收款按钮">

1. **付款** 选项卡 — 显示付款方式卡片和已收取的款项。参见[收款面板](./payment-methods.mdx)。
2. **传统** 选项卡 — 在 POS 内显示店铺自身的付款页面。免费插件提供 **银行卡**；[WCPOS Pro](../../getting-started/pro-license.mdx) 可添加店铺的其他付款方式。此页面不提供 **现金**。收取一笔款项后，选项卡下方会显示 **仅支持整单付款**。参见[传统选项卡](./legacy-tab.mdx)和[订单已部分付款时](./legacy-tab.mdx#after-payment)。
3. **待付** — 尚未支付的余额。部分付款后，会显示下一笔付款金额和剩余金额。
4. **拆分** — 将账单拆分为多笔付款。参见[拆分账单](#split)。
5. **付款方式卡片** — 店铺在收银端接受的付款方式，可在[收银台设置](../../settings/wp-admin/checkout.mdx)中配置。参见[付款方式](./payment-methods.mdx)。
6. **快捷金额** — 选择准确金额，或向上取整到较大的纸币面额。
7. **数字键盘** — 输入客户交付的金额。点击 **C** 可清除。
8. **收款** — 显示金额和付款方式。点击即可记录付款。参见[收款操作](./taking-a-payment.mdx)。

</JourneyShot>

在手机上，相同的控件会依次排列在标题下方，右上角有 **✕**。

<JourneyShot manifest={manifest} device="phone" step={5} offsets={[[0, 0], [0, 0], [-40, 0], [55, 0], [0, 0], [115, 0], [0, 0], [0, 0]]} maxWidth={300} alt="手机上的收款界面：结账订单标题及订单号、关闭按钮、付款和传统选项卡、待付、拆分、现金和银行卡卡片、快捷金额、数字键盘和收款按钮" />

使用您自己的终端收取银行卡付款时，操作方式相同：先完成银行卡收款，再进行记录。已配对的读卡器会从收银端获取金额；参见[使用读卡器](./taking-a-payment.mdx#card-reader)。

## 找零 {#change}

输入或点击大于待付金额的数额后，找零金额会以大号数字显示，下方是客户交付的金额。点击 **收款** 前，请先清点好找零。

<JourneyShot manifest={manifest} device="tablet" step={8} offsets={[[-40, 0], [-40, 0], [-45, 0], [-60, 0], [-4, 0], [0, 0]]} alt="$45.00 现金销售收到 $50.00 时的收款界面：关闭按钮、待付 $45.00、以大号数字显示的找零 $5.00、下方的实收 $50.00、已选中的现金和收款按钮">

1. **✕** — 返回购物车，订单仍会保留。收取款项后，点击会改为打开 **取消付款**；参见[取消付款](./cancelling-a-payment.mdx)。
2. **待付** — 此笔销售的应付金额。
3. **找零** — 需要找回的金额。
4. **实收** — 您输入或点击的金额。
5. **现金** — 此笔付款所使用的方式。
6. **收款** — 记录付款并完成销售。

</JourneyShot>

## 拆分账单 {#split}

点击 **拆分**，即可分多笔收取账单款项。展开的选项栏包含 **百分比**，以及从 **2 份** 到 **6 份** 的均分选项，每项都会显示每份金额；横向滚动可查看更多。您还可以选择每个人付款的商品。再次点击 **拆分** 可恢复为一次付款。参见[拆分付款](./split-payments.mdx)。

<JourneyShot manifest={manifest} device="tablet" step={9} offsets={[[55, 0], [108, -50], [76, -56]]} alt="启用拆分的收款界面：拆分剩余金额栏中有百分比以及 2 份至 5 份选项，每项显示每份金额；旁边的订单有本次付款列，每行都有减号和加号按钮">

1. **拆分** — 设置拆分时处于开启状态。再次点击可关闭；已收取的付款会保留。
2. **拆分剩余金额** — 点击 **2 份** 至 **6 份** 可均分剩余金额，或点击 **百分比** 收取其中一部分。
3. **本次付款** — 通过 **−** 和 **+** 选择此笔付款涵盖的每种商品数量。

</JourneyShot>

## 查看付款完成界面 {#paid}

没有待付金额后，销售即告完成，收据也已准备就绪。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="现金销售后的付款完成界面：应找零金额、已付和实收金额、选中标准收据的模板选择器、打印机选择器、收据预览，以及通过电子邮件发送收据、下载 PDF、打印收据和新销售按钮">

1. **找零** — 需要找回的金额。
2. **付款方式及金额** — 显示金额和付款方式。
3. **模板** — 此笔销售使用的收据模板。这里的选择仅对本次销售有效。参见[自定义收据](../../receipts/customise.mdx)。
4. **打印机** — 选择打印设备。参见[打印收据](../../receipts/at-checkout.mdx#print-receipt)。
5. **预览** — 收据的打印效果。
6. **打印收据** — 打印收据。
7. **通过电子邮件发送收据** — 将收据发送给客户。参见[通过电子邮件发送收据](../../receipts/at-checkout.mdx#email-receipt)。
8. **新销售** — 为下一位客户打开空购物车，并恢复为默认客户。

</JourneyShot>

**下载 PDF** 可将收据保存为文件，此操作需要联网。顶部的 **✕** 与 **新销售** 一样，也会结束本次销售。

如果收银端设置为跳过付款完成界面并自动打印，每笔销售后仍会打印收据。参见[自动打印或跳过付款完成界面](../../receipts/at-checkout.mdx#automatic-receipt-options)。

## 遇到问题时 {#goes-wrong}

**购物车中的商品有误。** 点击该行的总计，再点击 **移除**。如果移除操作也是误操作，可点击随后消息中的 **撤销** 按钮。参见[订单项目](../cart/line-items.mdx#remove-item)。

**客户改变了主意。** 在结账页面点击 **✕** 可返回购物车，订单仍会保留。要放弃此笔销售，请点击 **结账** 旁的 **⋮**，再点击 **作废**。参见[作废](../cart/order-actions.mdx#void)。如果已收取款项，点击 **✕** 会先打开 **取消付款**；参见[取消付款](./cancelling-a-payment.mdx)。

**现金不足。** 输入客户交付的金额。按钮会显示类似 **收取 $20.00 现金 · 剩余 $25.00** 的文字。点击后会记录此笔付款，其余金额仍待支付；可选择任意付款方式卡片收取余款。参见[收取部分余额](./taking-a-payment.mdx#part-payment)。

**连接中断。** 对于店铺已记录的销售，即结账页面商品上方已有订单号的销售，仍可通过现金完成付款；离线时新建的销售则必须等连接恢复后才能付款。收据会保留真实的时间和收银机信息，订单会在连接恢复后同步。如果所有付款方式都不支持离线收款，结账页面会提示 **无连接**，并说明此笔销售已保存到未完成订单中；请点击 **返回收银界面**。参见[离线模式](../../getting-started/offline.mdx)。

:::info 使用 WCPOS Pro
已配对的客户显示屏会在您录入销售时向客户显示购物车内容。
:::
