显示设置决定商品面板的外观和初始显示内容。点击搜索框旁的 **设置**，打开 **商品设置**。每项更改都会即时保存，且仅保存在此设备上，因此每台收银设备都可以单独设置。要了解如何使用面板，请先阅读[查找商品](index.mdx#find)。

- [切换卡片和行视图](#view-mode)

## 更改面板外观 {#display-settings}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[59, 0], [309, 60], [218, 0], [238, 41], [-115, 0], [105, -39], [0, 0], [199, 0], [-29, 0]]} maxWidth={512} alt="商品设置：视图模式、卡片大小、每个选项旁显示数量的浏览方式、显示缺货商品、排序依据、排序方向、变体，以及底部的恢复默认设置和关闭">

1. **视图模式** — **网格** 显示带图片的卡片，**表格** 按行显示。参见[网格或表格](#view-mode)。
2. **卡片大小** — 面板每行显示的卡片数量，范围为 2 到 8。仅适用于 **网格**。
3. **浏览方式** — 面板的初始显示内容。参见[浏览方式](#browse-by)。
4. **显示缺货商品** — 关闭时隐藏缺货商品。参见[缺货商品](#show-out-of-stock-products)。
5. **排序依据** — 商品的排列顺序。参见[排序](#sort)。
6. **排序方向** — **升序** 或 **降序**。
7. **变体** — 多选项商品的打开方式。参见[变体](#variations)。
8. **恢复默认设置** — 立即将此处的所有设置恢复为新设备的初始状态，不会要求确认。同时还会删除此设备上的快捷筛选。参见[重新开始](#restore-default-settings)。
9. **关闭** — 关闭设置。您的更改已经保存。

</JourneyShot>

### 网格或表格 {#view-mode}

**网格** 将每件商品显示为一张卡片，包含图片、名称和价格。点击卡片即可将一件商品加入购物车。多选项商品会显示 **… 个选项**，点击后会打开[商品变体](variations.mdx)。**表格** 按行显示相同的商品，每行末尾都有一个 **+**，点击即可添加商品。

新设备默认使用 **网格**，每行显示四张卡片。搜索框旁的网格或表格按钮可直接切换这两种视图，无需打开设置。

商品加入购物车后，卡片角落的小圆圈会显示已添加的数量。在行视图中，数量会取代 **+**，点击即可再添加一件。

### 浏览方式 {#browse-by}

面板的初始显示内容：

| 选项 | 面板的初始显示内容 |
|--------|--------------------|
| **所有商品** | 按[排序顺序](#sort)显示所有商品 |
| **分类** | 每个顶级分类显示为一张卡片。新设备的默认设置 |
| **标签** | 每个标签显示为一张卡片 |
| **品牌** | 每个品牌显示为一张卡片 |
| **快捷方式** | 每个[快捷筛选](#quick-filters)显示为一张卡片 |

每个选项都会显示数量，例如 **6 个分类**。没有内容的选项会变灰并显示提示，例如 **暂无品牌**。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-22, 0], [-30, 0], [0, 0], [0, 0], [282, 297]]} alt="在装备分类内按分类浏览：面包屑导航“分类 › 装备”、带返回箭头的装备卡片、各子分类卡片及其商品数量、装备分类自身的商品，以及网格下方的数量">

1. **分类** — 面包屑导航。点击其中任一级即可返回该级。
2. **返回箭头** — 位于当前分类的卡片上。点击该卡片可返回上一级。
3. **子分类** — 显示其中的商品数量。点击即可进入。
4. **商品** — 点击即可加入购物车，与面板其他位置的操作相同。
5. **3 个分类 · 已显示 20 件，共 43 件** — 当前层级的内容：子分类数量，以及屏幕上显示的商品数量。

</JourneyShot>

点击卡片即可进入。分类会按照 WooCommerce 中的设置，显示子分类、商品或两者。在顶级层级，**所有商品** 卡片排在最前面。搜索或使用与当前浏览方式相同维度的筛选条件时，匹配的商品会取代这些卡片。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[0, 0], [259, 0]]} alt="进入两级后的手表分类：面包屑导航“分类 › 装备 › 手表”、带返回箭头的手表卡片，以及九款手表">

1. **商品** — 手表分类没有子分类，因此只显示商品。
2. **手表** — 您当前所在的层级。点击 **装备** 或 **分类** 可返回上级。

</JourneyShot>

要返回上一级，可点击面包屑导航、按键盘上的 **Escape** 键、从触摸屏左边缘向内滑动，或使用 Android 的返回按钮。在手机上，面包屑导航仅显示上一级，并带有返回箭头。

在 **表格** 中，相同的层级按行显示，每行都有数量和箭头。

### 缺货商品 {#show-out-of-stock-products}

新设备默认关闭 **显示缺货商品**。关闭时，缺货商品会被隐藏，扫描缺货商品也会被拒绝。开启后，这些商品会保留在列表中，以灰色显示并标记为 **售罄**，且 **有货** 筛选默认处于关闭状态。

如果您的店铺开启了[防止超卖](../../settings/wp-admin/checkout.mdx#prevent-overselling)，POS 还会在添加商品时检查库存：

- **… 缺货** 或 **仅有 … 件可用于 …** — 不会添加该商品。
- **此设备尚未加载 … 的库存** — 该商品的库存仍在下载中。请稍后重试。
- **… 将延期交货** — 商品已添加。该商品设置为允许延期交货并通知顾客。

### 排序 {#sort}

**排序依据** 可选择以下排序字段：**名称**、**SKU**、**条形码**、**类型**、**价格**、**创建日期**、**修改日期**、**受欢迎程度**、**库存数量**、**库存状态** 或 **菜单顺序**。**受欢迎程度** 指总销量，选择 **降序** 时销量最高的商品排在最前。**菜单顺序** 是在 WooCommerce 中为每件商品设置的顺序。新设备默认按 **名称** **升序** 排列。

在 **表格** 中，也可以点击列标题按该列排序。这也会同步更改此处的 **排序依据**。

### 变体 {#variations}

设置多选项商品的打开方式。新设备默认使用 **原位打开**，在面板中为每个选项显示一张卡片。另一种方式是在 **网格** 中使用 **弹出框**，在 **表格** 中使用 **展开行**。参见[可变商品](variations.mdx)。

### 卡片字段 {#tile-fields}

在 **网格** 中，可以开启卡片要显示的内容：**商品名称**、**价格**、**税费**、**促销**、**分类**、**SKU**、**条形码**、**库存** 和 **销售成本**。新设备默认显示名称和价格。开启 **促销** 后，促销价旁会显示带删除线的原价。开启 **库存** 后，卡片会显示剩余数量。

### 列 {#columns}

在 **表格** 中，同一位置显示的是 **列**。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 0], [5, 92], [139, 70], [159, 150]]} maxWidth={512} alt="表格视图中的商品设置，已滚动至列区域：每列都有拖动手柄和开关，商品名称下方还有显示选项">

1. **展开行** — 在 **表格** 中，**变体** 的第二个选项会在商品下方按行展开其选项。
2. **拖动手柄** — 上下拖动某一列，即可调整它在表格中的左右位置。
3. **列开关** — 开启或关闭某一列。
4. **显示选项** — 商品名称下方显示的详细信息，例如 **库存** 和 **分类**。

</JourneyShot>

新设备默认显示图片、商品名称、价格和操作列，并在名称下显示 **库存** 和 **分类**，在价格下显示 **促销**。在 **商品名称** 下还可以显示 SKU、条形码、标签、品牌、属性和元数据。在 **价格** 下还可以显示税费。

### 元数据键 {#meta-data-keys}

选择要复制到购物车商品行、进而保存到订单中的商品自定义字段。参见[元数据键](meta-data-keys.mdx)。

## 设置筛选栏 {#filter-bar}

点击 **自定义筛选栏**，选择商品上方筛选栏中显示的内容。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-24, 0], [-42, 0], [160, 0], [-29, 0]]} maxWidth={512} alt="筛选栏设置：每个筛选项旁都有拖动手柄和开关，并有添加快捷筛选按钮">

1. **拖动手柄** — 上下拖动筛选项，即可调整它在筛选栏中的位置。
2. **开关** — 关闭筛选项可将其从筛选栏隐藏，开启则重新显示。
3. **添加快捷筛选** — 创建自定义按钮。参见[自定义筛选按钮](#quick-filters)。
4. **关闭** — 您的更改已经保存。

</JourneyShot>

新设备的筛选栏依次显示 **库存状态**、**精选**、**促销**、**分类**、**标签** 和 **品牌**。无需打开设置即可隐藏其中一项：在筛选栏上长按该项（使用鼠标时右键单击），然后选择 **从筛选栏隐藏**。

## 自定义筛选按钮 {#quick-filters}

快捷筛选是一个可同时应用多个条件的按钮，例如筛选 **鞋类** 分类中的 **促销** 商品，并按价格排序。您可以根据屏幕上的当前条件创建，也可以从头创建。还可以让面板首先显示快捷筛选：将[浏览方式](#browse-by)设为 **快捷方式**。

- [保存屏幕上的当前条件](#save-as-button)
- [从头创建](#add-quick-filter)
- [修改快捷筛选](#edit-quick-filter)
- [删除快捷筛选](#delete-quick-filter)

### 保存屏幕上的当前条件 {#save-as-button}

在筛选栏上设置所需的筛选条件，然后点击筛选栏末尾的书签按钮 **保存为按钮**。启用筛选条件后，此按钮就会出现。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[438, 0], [139, 0], [39, -40]]} maxWidth={512} alt="保存为按钮：按钮名称字段、按钮预览，以及每个保留条件旁的勾选标记">

1. **按钮名称** — 按钮在筛选栏上显示的文字。
2. **保留屏幕上的当前条件** — 勾选要保留的条件。如果当前位于某个分类内，该分类及其子分类也会作为一个条件。搜索条件默认不勾选，需手动选择。
3. **添加到筛选栏** — 将按钮放到筛选栏上。

</JourneyShot>

勾选项下方会显示此设备上匹配的商品数量。点击 **取消** 将关闭窗口，不会添加任何内容。

### 从头创建 {#add-quick-filter}

例如，创建一个筛选促销鞋类商品的按钮：

1. 在 **自定义筛选栏** 中，点击 **添加快捷筛选**。
2. 选择 **某分类中的促销商品**。其他预设包括 **某个分类**、**低于某个价格**、**畅销商品**、**新品**、**库存不足** 和 **某个标签**。如不想选择预设，请点击 **从头创建**。
3. 在 **按钮名称** 下输入名称，例如“促销鞋类”。
4. 在 **显示符合以下条件的商品…** 下，已设置 **促销** 条件。**所属分类** 显示 **选择…**：点击并选择 **鞋类**。
5. 在 **然后** 下，点击 **排序方式** 并选择 **价格从低到高**。如果不更改，会保留 **网格的常规顺序**。
6. 点击 **添加到筛选栏**。只有填写按钮名称并选定所有条件后，此按钮才会从灰色变为可用。

完成步骤 3 和 4、尚未选择分类时：

<JourneyShot manifest={manifest} device="tablet" step={9} offsets={[[120, 0], [130, 0]]} maxWidth={512} alt="新建快捷筛选：按钮名称中已输入“促销鞋类”，并显示在筛选栏预览中；所属分类仍显示“选择…”，促销设为“是”，添加到筛选栏按钮为灰色">

1. **按钮名称** — 按钮上显示的文字。**在筛选栏上** 显示按钮的外观预览。
2. **所属分类** — 在选定分类之前显示 **选择…**。下方的 **促销** 已设为 **是**。继续向下可找到 **然后** 和 **排序方式**。

</JourneyShot>

### 修改快捷筛选 {#edit-quick-filter}

要修改快捷筛选，可在筛选栏上长按它并选择 **编辑**，或在 **自定义筛选栏** 中点击它。更改会即时保存。

### 删除快捷筛选 {#delete-quick-filter}

在筛选栏上长按它并选择 **从筛选栏移除**，或在 **自定义筛选栏** 中打开它，再点击底部的 **从筛选栏移除**。点击 **删除** 确认。快捷筛选无法仅关闭而保留；移除即会删除。

## 重新开始 {#restore-default-settings}

**商品设置** 底部的 **恢复默认设置** 会将此处的所有设置恢复为新设备的初始状态：**网格**、每行四张卡片、按 **分类** 浏览、按 **名称** 排序，以及筛选栏上的六个标准筛选项。此操作不会先要求确认。

:::warning
恢复默认设置还会删除此设备上的快捷筛选，因为它们属于筛选栏的一部分。
:::

## 面板底部 {#footer}

- **已显示 … 件，共 … 件** — 此设备上匹配的商品总数，以及屏幕上已显示的数量。
- **计税依据**，例如 **店铺所在地** — 店铺计算税费时会显示。点击可查看当前使用的税率。
- **同步按钮** — 从店铺刷新商品。长按可显示两个选项：**同步** 执行相同的刷新操作；**清除并刷新** 则清除此设备的商品数据并重新下载。
