购物车中的每项商品、费用和运费各占一行。大多数内容都可以直接在行内修改：点击数量、价格或名称即可。其他内容则在该行的**编辑**对话框中修改。

## 购物车中的行项目 {#line}

商品行显示数量、名称和单价，右侧显示该行的总计。费用和运费也各占一行，位于商品下方。其他显示内容取决于您启用的[列](./index.mdx#columns)。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[0, 32], [122, -40], [0, -26], [0, -26], [-34, 0], [-34, 0], [-30, 0], [0, 24]]} maxWidth={379} alt="包含三行的购物车：3 × Aim Analog Watch，单价 $45.00，自定义字段为刻字：生日快乐；礼品包装费 $2.00；本地配送运费 $5.00">

1. **数量** — 商品数量。点击即可修改；参见[修改数量](#quantity)。
2. **项目** — 商品名称。点击可为本次销售中的行项目重命名：名称会变成文本框，按 Enter 或点击其他位置即可保留新名称。下方显示所售[变体](../product-panel/variations.mdx)的选项和该行的[自定义字段](#meta-data)，格式为 `Key: value`。启用此列的 **SKU** 选项还可显示 SKU。
3. **价格** — 单件商品的价格。点击即可修改；参见[修改价格](#price)。价格低于常规价格时，上方会显示带删除线的常规价格。
4. **总计** — 数量乘以价格。点击可显示**编辑**和**移除**；参见[编辑或移除行项目](#remove-item)。
5. **费用** — 同样，点击名称可重命名，点击金额可修改金额。参见[费用](./index.mdx#fees)。
6. **运费行** — 操作相同：点击标题或金额即可。参见[配送](./index.mdx#shipping)。
7. **+** — 向购物车添加费用、运费、折扣或[杂项商品](./index.mdx#miscellaneous-products)。
8. **购物车设置** — 设置购物车位于哪一侧、行项目如何排序以及显示哪些列；参见[行项目的购物车设置](#cart-settings)。

</JourneyShot>

## 修改数量 {#quantity}

点击数量框。在 iOS 和 Android 应用中，直接在框内输入数字；数量为 0 时会移除该行。在其他平台上会打开数字键盘：输入新数量，然后点击对勾（或按 Enter）保留。在手机上，数字键盘以面板形式从屏幕底部弹出；在平板电脑或电脑上，它从数量框展开，顶部显示数量：

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, -24], [0, -24], [0, -24], [-6, 0], [-6, 0], [0, 0]]} maxWidth={441} alt="数量为 1 的行上方打开的数字键盘：1 的左侧是垃圾桶，右侧是加号，下方有数字键、删除键和对勾">

1. **数量** — 当前已输入的数量。
2. **−** — 减少一个。数量为 1 时会变成垃圾桶，如图所示：点击即可移除该行。
3. **+** — 增加一个。
4. **数字键** — 输入新数量。
5. **删除** — 删除最后一位数字。
6. **完成**（对勾）— 保留新数量。按 Enter 的效果相同。按 Escape 可关闭数字键盘并保留原来的数量。

</JourneyShot>

店铺开启[启用小数数量](../../settings/wp-admin/general.mdx#enable-decimal-quantities)后，数字键盘还会显示小数键，其标记为店铺的小数分隔符。对于按重量或长度销售的商品，可以输入 2.5 或 0.25 等小数数量（最多六位小数）。

如果店铺禁止超卖，数量超过库存时会显示为琥珀色；参见[结账被阻止时](#checkout-blocked)。

### 拆分行项目 {#splitting-line-items}

**拆分**会将数量为多个的一行拆成多个数量为一的独立行，方便为其中某个商品设置不同的价格、折扣或备注。小数部分会单独保留在一行中：数量为 2.5 的行会拆成 1、1 和 0.5。

数量大于一的行会在数量下方显示**拆分**链接。默认不显示，需在**购物车设置**中启用。

<details>
<summary>拆分链接的位置及启用方法</summary>

1. **数量** — 该行的数量，此处为 3。
2. **拆分** — 点击可拆成三行，每行数量为一。

</JourneyShot>

要启用此功能，请打开**购物车设置**（购物车上方的滑块图标），找到**数量**列并开启其中的**拆分**选项。

## 修改价格 {#price}

点击价格，输入新的单价（或点击快捷折扣键），然后点击对勾（或按 Enter）保留。价格框会展开为数字键盘：

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [-4, -20], [-4, -20], [-4, -20], [0, 0], [-4, 0], [0, 0]]} maxWidth={293} alt="价格为 $45.00 的行上打开的价格数字键盘，−10% 键已亮起：新价格 $40.50 上方显示 $45.00 −10 %，下方有数字键、小数点、删除键和对勾">

1. **价格** — 新的单价。使用快捷折扣后，上方会显示计算过程：此处为 $45.00 −10 %，结果为 $40.50。
2. **−5%** — **快捷折扣**键：将该行的价格降低 5%。
3. **−10%** — 已点击，因此亮起。再次点击亮起的键可撤销该折扣。
4. **−15%** — 将价格降低 15%。这三个是初始选项，您可以[修改它们](./discounts.mdx#quick-discounts)。
5. **数字键** — 输入新的单价。输入的第一位数字会替换原价格。
6. **删除** — 删除最后一位数字。
7. **完成**（对勾）— 保留新价格。按 Enter 的效果相同。按 Escape 可关闭数字键盘并保留原价格。

</JourneyShot>

使用实体键盘时，输入数字，按 Backspace 删除，按 Enter 保留，按 Escape 取消。在数量数字键盘上，上下方向键可增加或减少一个（减至 1 后停止）。

在手机浏览器中，同样的数字键盘会以面板形式弹出。在 iOS 和 Android 应用中，点击价格会将其变为输入框：输入新的单价，离开输入框时即可保留。快捷折扣键仅在数字键盘上提供。

:::note 修改价格不属于 WooCommerce 的“折扣”
降低后的价格会记为该商品的促销价格。收据可以显示节省的金额，但订单的**折扣**总额仅用于优惠券，报表则按实际支付价格统计销售额。有关 WooCommerce 为何区别处理这两者，请参见[购物车折扣](./discounts.mdx#why-tracked-differently)。
:::

### 新价格仅适用于本次销售 {#price-this-sale}

在购物车中修改的价格仅适用于本次销售。商品本身的价格不变：无论在本设备还是其他设备上，商品卡片仍显示原价。若要修改所有销售使用的价格，请在[商品](../../products/index.mdx#inline-price-editing)页面或 WP Admin 中修改商品价格。

若要以自行输入的价格销售商品目录中没有的商品，请点击 **+** 并添加[杂项商品](./index.mdx#miscellaneous-products)。

## 编辑或移除行项目 {#remove-item}

每行下方都隐藏着**编辑**和**移除**按钮。以下操作可显示这些按钮：

- **点击该行的总计。** 再次点击可隐藏按钮。
- 将鼠标**悬停**在总计上，该行会向一侧滑动，露出按钮。
- 在触摸屏上向左**滑动该行**，或用鼠标向左拖动。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[6, -28], [6, -28]]} maxWidth={379} alt="手表所在行向左滑动，显示蓝色的编辑按钮和红色的移除按钮">

1. **编辑** — 打开[编辑对话框](#edit-form)。
2. **移除** — 将该行从购物车中移除。

</JourneyShot>

继续滑动，**移除**按钮会以红色填满整行：松开即可一次完成移除。

移除后显示的消息中有**撤销**按钮，可将该行恢复原样。

## 编辑对话框 {#edit-form}

点击**编辑**，会在以该行名称命名的对话框中打开详细信息。修改会即时保存；完成后点击**关闭**。

对于商品行：

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[-35, 0], [-35, 0], [-35, 0], [-35, 0], [-35, 0], [-10, 0], [-10, 0], [-35, 0]]} alt="编辑 Aim Analog Watch：名称、数量 3、价格 45.00、税费为标准税率、SKU 24-MG04 及其移除按钮、自定义字段刻字：生日快乐、常规价格和自定义字段按钮，以及关闭按钮">

1. **名称** — 收据和订单上显示的名称。
2. **数量** — 与购物车中的数量相同。
3. **价格** — 与购物车中的价格相同。该行处于促销状态时，旁边会显示常规价格，并标注**原价**。点击其**移除**按钮可删除常规价格：该行不再处于促销状态，当前价格保持不变。
4. **税费** — 该行是否应税及其税类。
5. **SKU** — 商品有 SKU 时显示。没有 SKU 的行会显示 **SKU** 按钮，可用于添加。
6. **常规价格** — 为未处于促销状态的行添加常规价格。
7. **自定义字段** — 添加键和值，例如上方的**刻字**行；参见[自定义字段](#meta-data)。
8. **关闭** — 关闭对话框。所有修改都已保存。

</JourneyShot>

每个新增行都有自己的**移除**按钮。[杂项商品](./index.mdx#miscellaneous-products)不在商品目录中，因此其对话框还提供**分类**、**虚拟**和**可下载**选项。

行项目的税费按订单地址对应的税率计算。如果店铺根据顾客地址[计算税费](../../settings/store/tax.mdx#calculate-tax-based-on)，更换顾客或修改其地址后，若适用税率发生变化，各行会立即按新税率重新计税。[免税](./index.mdx#tax-exempt)订单仍然免税。

### 费用行 {#edit-fee}

点击费用的**编辑**，会打开以该费用名称命名的专用对话框。与商品一样，修改会即时保存。

费用不能为负数：对话框会提示**费用不能为负数。请改用添加折扣。** 参见[折扣](./discounts.mdx)。

<details>

<JourneyShot manifest={manifest} device="tablet" step={11} offsets={[[-35, 0], [-35, 0], [-12, 0], [-30, 0], [-35, 0], [-10, 0], [-35, 0]]} alt="编辑礼品包装：费用名称、金额 2.00 及 $ 和 % 切换选项、已开启的金额含税选项、税费为标准税率、自定义字段按钮和关闭按钮">

1. **费用名称** — 收据上显示的费用名称。

3. **$ / %** — 在固定金额与购物车总计的百分比之间切换。

5. **税费** — **不应税**，或对此费用适用的税类。

7. **关闭** — 关闭对话框。

### 运费行 {#edit-shipping}

点击运费行的**编辑**，会打开该行的专用对话框，修改同样会即时保存。

<summary>技术详情：JSON 选项卡、行项目类型和 WCPOS 自有字段</summary>

### JSON 选项卡 {#raw-json-view}

**表单**旁的 **JSON** 选项卡会原样显示发送给 WooCommerce 的行项目数据。日常销售无需使用此选项卡。检查插件会读取到什么内容或字段为何无法保存时，它会很有帮助。

#### 三种行项目类型 {#line-item-types}

WooCommerce 将商品、费用和运费分别存储为不同类型的行项目：

| 类型 | 在 WooCommerce 中的类型 | 示例 |
|------|----------------|----------|
| 商品 | `line_item` | T 恤、咖啡杯 |
| 费用 | `fee_line` | 礼品包装、服务费 |
| 运费 | `shipping_line` | 标准配送、快递配送 |

#### WCPOS 自有字段 {#protected-keys}

WooCommerce 将自定义字段称为元数据。以下划线开头的键是 WCPOS 自有记录（例如 `_woocommerce_pos_data` 和 `_reduced_stock`）。它们不会显示在表单或购物车中，但可在 **JSON** 选项卡中查看。

</details>

## 自定义字段 {#meta-data}

自定义字段是随某一行保存的备注，例如刻字内容或序列号。要添加刻字内容，请打开该行的**编辑**对话框，点击**自定义字段**，在**键**中输入**刻字**，在**值**中输入顾客要求的文字。该字段会显示在购物车的行项目名称下方，以及 WP Admin 的订单中。每个字段都有自己的**移除**按钮。

有些字段来自商品本身：添加商品时，您选定的[元数据键](../product-panel/meta-data-keys.mdx)都会复制到该行上。

如果表单提示**此键由 WCPOS 管理。请选择其他键。**，说明您输入了 [WCPOS 自有键](#protected-keys)。请换一个键。

**购物车设置**位于购物车上方，以滑块图标表示，用于设置购物车位于哪一侧以及商品行的排列顺序。费用和运费始终位于末尾，按添加顺序排列。

## 结账被阻止时 {#checkout-blocked}

店铺[禁止超卖](../../settings/wp-admin/checkout.mdx#prevent-overselling)时，购物车会逐行核对商品数量与库存：

- 行项目上方的提示会列出每个库存不足的商品：**连帽衫仅剩 2 件**，并提供**减少**按钮以打开该行的数量输入；或显示**连帽衫缺货**，并提供**移除**按钮。
- 库存不足的行会以琥珀色标记，并显示可用数量。
- **结账**按钮变暗。点击会跳转到第一个需要调整的行。

调整好所有行后，**结账**按钮会恢复可用。允许缺货下单的商品不会阻止销售。

## 遇到问题时 {#goes-wrong}

**“无法更新该项目 — 它已不在购物车中。”** 您修改该行时，它已被移除。请检查购物车并重新修改。

**“该项目已不在购物车中。”** 您对已移除的行点击了**移除**。无需进一步操作。

**没有拆分链接。** 在**购物车设置**的**数量**列下启用**拆分**。只有数量大于 1 的行才会显示此链接。

**结账按钮变暗。** 某行商品库存不足。参见[结账被阻止时](#checkout-blocked)。

**自定义字段无法保存。** 其键以下划线开头，属于 WCPOS。请选择其他键。
