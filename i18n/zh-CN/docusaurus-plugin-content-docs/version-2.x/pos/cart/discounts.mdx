销售时有两种减价方式。点击商品价格，可单独调低该商品的价格。在添加菜单中选择 **添加折扣**，可为整笔订单按金额、百分比或优惠券减价。

## 为单件商品减价 {#quick-discounts}

点击商品行中的价格，下方会打开数字键盘，顶部显示快捷折扣键。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-120, 0], [-88, 0], [-88, -24], [65, 0], [-24, 0]]} alt="在价格为 $45.00 的商品行上打开价格键盘并按下 −10%：新价格为 $40.50，上方显示 $45.00 −10%，另有三个快捷折扣键、数字键、删除键和完成键">

1. **新价格** — 商品将采用的价格，以及该价格如何根据原价计算得出。
2. **快捷折扣键** — 每个键都按对应百分比调低该行的价格。按错了？在按 **完成** 前按另一个键，即可替换先前的选择。亮起的键表示当前使用的折扣。您可以自行设置这些键，参见[设置快捷折扣键](#quick-discount-keys)。
3. **数字键** — 也可以直接输入新价格。
4. **删除** — 删除最后一位数字。
5. **完成** — 确定新价格。点击键盘外部也有同样的效果。

</JourneyShot>

按 **完成** 后，行总计会变为数量 × 新价格。

快捷折扣键以打开键盘时该行的价格为计算基准。若要再减 10%，请先按 **完成**，然后重新打开键盘并按 **−10%**。

<details>
<summary>示例：在 $45.00 的商品上使用两个折扣键</summary>

按 **−10%** 显示 $40.50。改按 **−5%**，则显示 $42.75。再次按 **−10%**，然后按 **完成**，该行价格就设为 $40.50。重新打开键盘并按 **−10%**，$40.50 就会变为 $36.45。

</details>

### 输入新价格 {#line-item-discounts}

需要匹配其他报价、设置员工价或进行其他临时调价时，输入顾客应付的价格，再按 **完成**。使用实体键盘时，输入价格后按 **Enter**。

每个商品行单独定价。若要为三种不同商品减价 10%，可逐行操作，也可通过[添加折扣](#order-level-discounts)为整笔订单减价。有关商品行的其他可修改内容，参见[商品行](line-items.mdx#price)。

## 为整笔订单减价 {#order-level-discounts}

按购物车顶部的 **+**，选择 **添加折扣**。对话框默认打开 **快捷折扣** 选项卡。输入数值，选择 **$** 或 **%**，然后按 **添加折扣**。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[0, 0], [0, 0], [0, 0], [12, 46], [50, -52]]} alt="添加折扣对话框的快捷折扣选项卡：显示快捷折扣和优惠券选项卡，数值为 10，美元与百分比切换开关设为百分比，以及添加折扣按钮；旁边的购物车中有价格为 $45.00 的 Aim 指针手表">

1. **快捷折扣** — 为当前订单按金额或百分比减价。
2. **优惠券** — 改用店铺中的优惠券。参见[应用优惠券](#coupon)。
3. **金额** — 点击后在数字键盘上输入。
4. **$ 或 %** — 减去固定金额，或按订单金额的百分比减价。
5. **添加折扣** — 将折扣应用到订单。

</JourneyShot>

折扣会显示在订单总计区域，各行总计也会相应调整。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[12, 46], [100, 0], [50, 0], [0, 0]]} alt="为 $45.00 的手表减价 10% 后的购物车：行总计 $45.00 带有删除线，下方为 $40.50，小计为 $45.00，折扣（10%）行显示减去 $4.50 并带有移除按钮，结账金额为 $40.50">

1. **行总计** — 带删除线的折扣前价格，以及顾客现在应付的金额。
2. **小计** — 折扣前的订单金额。
3. **折扣（10%）** — 折扣及其减免金额。如果只显示 **折扣**，则表示减去固定金额。按 **✕** 可移除。
4. **结账** — 新的总计金额。

</JourneyShot>

固定金额折扣会按各商品的价格比例分摊。百分比折扣则应用于每件商品。一笔订单可以添加多个折扣，每个折扣单独显示一行。

**添加折扣** 可离线使用，税额按减价后的价格计算。此操作不会在店铺中创建优惠券。

### 移除折扣 {#remove-discount}

在总计区域的折扣行上按 **✕**。各行总计会恢复，并显示 **折扣已移除** 提示。您在商品行上修改过的价格仍保持原样。

## 应用优惠券 {#coupon}

在 **添加折扣** 中切换到 **优惠券**。免费版插件也支持此功能。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[-40, 0], [10, 46], [24, -52]]} alt="添加折扣对话框的优惠券选项卡：显示选择优惠券字段、旁边的新建优惠券按钮和应用按钮；旁边购物车中的手表在应用折扣（10%）后价格为 $40.50">

1. **选择优惠券** — 输入部分优惠码即可查找。
2. **新建优惠券**（WCPOS Pro）— 当场创建优惠券。参见[在收银时创建优惠券](#new-coupon)。
3. **应用** — 检查优惠券规则并将其应用到订单。

</JourneyShot>

如果优惠券无法用于当前订单，会显示原因。有关各条提示的含义、如何移除优惠券以及离线使用优惠券，参见[应用优惠券](../../coupons/applying-coupons.mdx)。

## 在收银时创建优惠券 {#new-coupon}

:::info Pro 功能
在收银时创建优惠券需要 [WCPOS Pro](../../getting-started/pro-license.mdx)。在免费版插件中，**新建优惠券** 会提示 **升级到 Pro**。
:::

1. 在 **优惠券** 选项卡上按 **新建优惠券**。
2. 输入优惠码，或按 **生成**。
3. 选择折扣类型，并输入减免数值。
4. 设置 **到期时间** 及优惠券所需的其他规则。
5. 按 **添加优惠券**。优惠券会先保存到店铺，再应用于本次销售，并显示 **…已保存并应用于本次销售** 提示。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[-40, 0], [22, -40], [-40, 0], [100, 0], [-60, 0], [0, 0], [50, -52]]} alt="已输入优惠码 SPRING10 的添加优惠券表单：优惠码旁有生成链接，折扣类型设为百分比，还显示到期时间选项、一次性使用开关、以最低消费金额开头的更多优惠券规则按钮，以及添加优惠券按钮；旁边是同一个购物车">

1. **优惠码** — 顾客使用的代码。这是唯一的必填字段。
2. **生成** — 自动生成优惠码。
3. **折扣** — 选择按百分比、订单固定金额或商品固定金额减免，并设置减免数值。
4. **到期时间** — 优惠券的有效期限。
5. **一次性使用** — 优惠券使用一次后即失效。
6. **更多规则** — **最低消费金额**、**总使用次数**、**不可叠加使用** 等选项各自添加一条 WooCommerce 优惠券规则。
7. **添加优惠券** — 将优惠券保存到店铺，再应用于本次销售。

</JourneyShot>

创建的是真正的 WooCommerce 优惠券，因此下次销售时仍可使用，也会出现在 **WP Admin → 营销 → 优惠券** 和报表中。如果希望从优惠券页面创建，参见[创建优惠券](../../coupons/index.mdx#creating-coupons)。

## 设置快捷折扣键 {#quick-discount-keys}

快捷折扣键需在每台设备上分别设置。按购物车顶部的滑块图标按钮，打开 **购物车设置**。**快捷折扣** 会按收银员在价格键盘上看到的样式显示这些键。新设备的默认值为 5%、10% 和 15%。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [0, 0], [0, 0], [-34, 0]]} alt="购物车设置中的快捷折扣行：三个键分别显示 5%、10% 和 15%，样式与价格键盘上相同；列设置中的数量开关已开启，其拆分开关已关闭">

1. **第一个键** — 点击并输入不超过 100 的百分比数值，例如 5 或 12.5。
2. **第二个键** — 设置方法相同。
3. **第三个键** — 设置方法相同。最多可以设置三个键。
4. **拆分** — 开启后，商品行的数量下方会显示 **拆分**。参见[同一商品设置不同价格](#split)。

</JourneyShot>

要移除某个键，将其数值设为 0 即可。其余键会自动拉伸以填满整行。如果移除所有快捷折扣键，价格键盘就只显示数字键。没有固定金额折扣键；若要减去一定金额，请输入新价格或使用[添加折扣](#order-level-discounts)。

## 同一商品设置不同价格 {#split}

例如，顾客购买同一商品三件，其中一件享受较低价格。在[购物车设置](index.mdx#columns)的 **列 → 数量** 下开启 **拆分**。这样，数量大于一的商品行就会在数量下方显示 **拆分**。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[0, 36], [-38, 0], [12, 28]]} alt="购物车中一行包含三只单价 $45.00 的 Aim 指针手表，总计 $135.00，数量下方显示拆分">

1. **拆分** — 将该行拆成每件商品各占一行。
2. **价格** — 拆分后的每一行都会保留此价格，直到您修改为止。
3. **行总计** — 三件商品的合计金额。**拆分** 后，每个新行显示各自的总计。

</JourneyShot>

按 **拆分** 后，每件商品各占一行，价格均保持一致。然后调低需要打折的商品行的价格。例如，数量为 2.5 时，会拆成两个数量为一的行和一个数量为 0.5 的行。参见[拆分商品行](line-items.mdx#splitting-line-items)。

## 遇到问题时 {#goes-wrong}

- **误打开了价格键盘。** 再按一次亮起的键，或按 **删除** 直到内容为空，然后按 **完成**，价格就会保持不变。使用实体键盘时，按 **Escape**。
- **商品行的价格设错了。** 再次点击价格并输入正确价格，或移除该行后重新添加商品，以恢复店铺中的价格。
- **请输入大于零的金额** 或 **请输入大于 0 且不超过 100 的百分比** — **添加折扣** 中的数值为空或超出范围。
- **…已应用于订单，且不能与其他优惠券叠加使用。** — 订单中已有标记为 **仅限单独使用** 的优惠券。请先移除该优惠券，或不添加此次折扣。
- **新建优惠券呈灰色** — 工具提示会说明原因：**升级到 Pro**、没有权限（需由管理员在 **WP Admin → POS → 设置 → 访问权限** 中授予），或 **连接到店铺后才能创建优惠券**。您仍可应用店铺已有的优惠券。
- **…已保存但未应用** — 优惠券已保存到店铺，但当前订单不符合其规则。请检查规则，或在订单符合条件后，从 **选择优惠券** 中再次选择。
- **费用不能为负数。请改用添加折扣。** — POS 不支持通过负数费用减价。请使用[添加折扣](#order-level-discounts)。有关费用本身的说明，包括 **金额含税**，参见[费用](index.mdx#fees)。

## POS 折扣与 WooCommerce 优惠券的区别 {#pos-discounts-vs-woocommerce-coupons}

**商品行价格**（通过快捷折扣键或手动输入设置）— 由收银员设置，仅作用于一行，没有规则限制。适合匹配其他报价、设置员工价或为瑕疵商品减价。

**添加折扣** — 由收银员设置，作用于整笔订单。本身没有规则限制，但不能与标记为 **仅限单独使用** 的优惠券叠加。适合临时按金额或百分比减价。

**WooCommerce 优惠券** — 按其规则使用，包括使用次数限制、适用商品、最低消费金额、到期时间、顾客电子邮箱。可在店铺中设置（参见[创建优惠券](../../coupons/index.mdx#creating-coupons)），或使用 Pro 在收银时创建。适合需要设置限制并在报表中统计的促销活动。

## 已知限制 {#known-limitations}

- **没有自动折扣规则。** POS 不会自动执行“买 2 送 1”。需要按规则开展促销时，请使用 WooCommerce 优惠券。
- **快捷折扣键仅支持百分比。** 若要减去固定金额，请输入新价格，或使用 **添加折扣** 并选择 **$**。

## 折扣的记录方式 {#how-discounts-are-recorded}

以下内容不会改变您的收银操作，只是解释报表和收据中的显示内容，以及旧订单为何可能有所不同。完整背景说明（包括价格的存储方式）见 [POS 折扣参考](../../reference/pos-discounts.mdx)。

<Accordion>
  <AccordionItem question="供管理人员参考：折扣在报表和收据中的显示方式">

### 价格调整与优惠券为何采用不同的记录方式 {#why-tracked-differently}

快捷折扣键或手动输入的价格采用 WooCommerce 记录促销价的方式记录：商品按收银员设定的价格售出。因此，**折扣** 总额仍为零，优惠券以降低后的价格计算，设置了 **排除促销商品** 的优惠券会跳过已减价的商品。

**添加折扣** 会记录为优惠券行，WooCommerce 优惠券也按优惠券记录，因此两者都会计入 **折扣** 总额。

<details>
<summary>WooCommerce 如何记录优惠券和促销价</summary>

WooCommerce 内置的折扣概念只有一种：**优惠券**。优惠券属于订单，记录在独立字段中，计入报表的 **折扣** 列，并自带使用次数限制、到期日期等规则。

对 WooCommerce 而言，**促销价** 不算折扣，而只是商品当前的价格：促销商品售出时，订单只记录实付价格，不记录其他差额。报表将其计为普通收入。

顾客希望在收据上看到节省了多少钱，因此 WCPOS 会在每个商品行上同时记录原价和新价格。这样，收据就能分别显示促销节省金额和优惠券折扣，既不会重复计算，也不会改变 WooCommerce 的总计或报表。

</details>

### POS 价格调整如何影响优惠券 {#how-pos-price-changes-interact-with-coupons}

假设收银员将商品价格从 $18 降至 $16，然后应用优惠券。优惠券以 **$16** 为基准计算，而不是 $18，因此不会基于原价为顾客重复减免。

- 在收银时调低价格的商品会被视为促销商品，与 WooCommerce 促销价的处理方式相同；调高价格则不会。设置了 **排除促销商品** 的优惠券会跳过促销商品；如果是设置了 **排除促销商品** 的固定购物车金额优惠券，只要购物车中有促销商品，就完全无法使用。
- 移除优惠券后，各商品行仍保留收银时设定的价格。

:::note 开发者参考
**添加折扣** 生成的行是优惠券行，依次命名为 `pos-discount`、`pos-discount-2`，以此类推。`wcpos_item_is_on_sale` 过滤器可更改促销商品的判定方式。有关收银价格的存储方式和其他过滤器，参见 [POS 折扣参考](../../reference/pos-discounts.mdx)。
:::

### 含负数费用的订单 {#discount-fee-tax}

在 2.0 之前，收银员可以通过负数费用为订单减价。POS 现已不再允许这样操作，但旧订单仍可能包含负数费用。

<details>
<summary>WCPOS 如何计算负数费用的税额，以及与 WooCommerce 的区别</summary>

WCPOS 根据 **费用本身的税务设置** 计算负数费用的税额。税务状态设为 **无** 时，该费用不计税，费用金额就是减免金额：费用为 `-10.00` 表示顾客少付 10。如果保持 **应税**，则按该费用自己的税类计税，相应税额也会一并扣减。

WooCommerce 自身的处理方式不同。它会忽略费用的税务状态，将负数费用的税额分摊到订单中的其他所有商品。如果店铺的 **输入的价格含税** 设为 *是*，在税率为 20% 时，一笔 `-10.00` 的费用也会减去 **12.00**。WCPOS 则保留收银员输入的金额。

此处理方式取决于订单本身，与打开订单所用的应用无关：从 **WP Admin → 订单** 重新计算 POS 订单时，也会保留这一行为。非 POS 来源的订单仍按 WooCommerce 的方式处理。

:::note 负数费用的税额
费用的税务状态设为 **无** 时，顾客支付的总额正确，但 **订单记录的税额不会减少**，因此会略高于减价后总额对应的税额。这只会导致多计税，不会少计税。应税的负数费用则按自身税类的税率扣减税额。通过 **添加折扣** 创建的折扣属于优惠券行，因此税额按降低后的价格计算。
:::

</details>

### v1.9.0 的变化 {#what-changed-in-v190}

如果您从 v1.8 升级后发现收据和报表的 **折扣** 总额显示为 **0**，原因如下。早期版本将收银时的调价记录为 WooCommerce 折扣，导致优惠券计算出错：叠加使用的优惠券以原价计算，造成少收款。从 v1.9.0 起，收银时设定的价格 **就是** 商品行价格，与 WooCommerce 记录促销商品的方式完全相同，只有优惠券才计为折扣。参见[价格调整与优惠券为何采用不同的记录方式](#why-tracked-differently)。

#### 这些变化对您的影响 {#what-this-means-for-you}

<details>
<summary>v1.9.0 起的收据、报表、优惠券和价格存储</summary>

- **收据** 可以显示原价、相对原价节省的金额，以及将这些节省金额与优惠券折扣合并计算的 **共节省**。价格差额带来的节省与 WooCommerce 的 **折扣** 字段仍分开记录。
- **报表** 在只有商品行价格发生变化时显示 `discount_total = 0`。只有优惠券计入折扣，**添加折扣** 也按优惠券计入。
- **优惠券** 能对收银时已减价的商品正确计算优惠金额。
- **原价和售价会存储** 在商品行的 POS 元数据(`_woocommerce_pos_data`)中，因此收据可以显示节省金额，而无需改变 WooCommerce 的折扣总额。

</details>

#### 在收据上显示原价和节省金额 {#showing-the-original-price-and-saving-on-receipts}

在商品促销或收银时调价的情况下，内置的价格显示模板会列出原价和节省金额。如果 WCPOS 能计算出整笔订单的完整节省金额，还会显示 **共节省**。该总额合并了相对原价的节省金额和优惠券折扣，不会重复计算。

<details>
<summary>更新 v1.9.0 之前创建的收据模板</summary>

从模板库复制的模板是您自己的副本，WCPOS 更新不会覆盖这些副本。如果您的收据是在此次变更前创建的，可以任选一种方式更新：

1. 在最新的内置模板副本上点击 **使用模板**；或
2. 将[收据数据参考](../../receipts/receipt-data.mdx#displaying-regular-price-and-savings)中的字段添加到您的模板中。

节省金额相关字段：

| 字段 | 含义 |
|-------|---------|
| `lines[].regular_price_display` | 记录的原始单价 |
| `lines[].selling_price_display` | 应用优惠券前的销售单价 |
| `lines[].unit_savings_display` | 每件商品节省的金额 |
| `lines[].line_regular_total_display` | 按原价计算的行总计 |
| `lines[].line_savings_display` | 该行节省的总金额 |
| `totals.sale_savings_total_display` | 商品目录促销和收银调价带来的原价与售价差额总计 |
| `totals.discount_total_display` | WooCommerce 折扣总额：优惠券，包括 **添加折扣** |
| `totals.total_saved_display` | 相对原价的节省金额与 WooCommerce 折扣的合计 |
| `totals.total_saved_complete` | 合计金额是否完整且可安全显示 |

这些字段大多只有在订单包含对应数据时才会存在。自定义模板应逐一检查字段，并在金额不完整或没有任何节省时隐藏 **共节省** 行。[收据数据参考](../../receipts/receipt-data.mdx#totals)中提供了相应写法。

WooCommerce 报表保持不变：折扣总额只包含优惠券，不包含促销价或收银调价带来的节省金额。在收据中使用 `totals.total_saved`；如果某笔优惠也必须在报表中显示为 WooCommerce 折扣，请使用优惠券或 **添加折扣**。

</details>
