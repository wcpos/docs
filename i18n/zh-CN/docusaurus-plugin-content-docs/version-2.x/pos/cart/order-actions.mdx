使用 **订单详情** 添加客户备注、移交订单、更改币种或税费、同步、打印或作废订单。点击 **结账** 旁的 **⋮** 按钮即可打开。

## 打开订单详情 {#open}

购物车底部有以下内容：

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[170, 0], [-22, 0], [40, 0]]} alt="平板电脑上的 POS，购物车中有 Aim Analog Watch：总计下方的备注行显示“请用礼品包装”，结账旁有 ⋮ 按钮">

1. **备注行** — 订单添加客户备注后，会在总计下方显示。点击即可打开 **订单详情** 并修改备注。
2. **⋮** — 打开 **订单详情**。
3. **结账** — 收取款项。参见[结账](../checkout/index.mdx)。

</JourneyShot>

在平板电脑上，面板在购物车旁打开；在手机上，面板占满屏幕。顶部是 **表单** 和 **JSON** 选项卡，下方是 **客户备注** 和 **移交** 框。向下滚动可查看其余内容。

字段的更改会即时保存，字段旁会短暂显示 **已保存** 标记。这里没有保存按钮：点击 **关闭** 或 **✕** 即可收起面板。唯一的例外是 **移交**，需要点击 **发送** 才会生效。

## 添加客户备注 {#order-note}

在 **客户备注** 中输入内容。备注会显示在购物车总计下方，方便一眼查看；点击该行即可修改。

:::warning 客户可以看到此备注
这是 WooCommerce 订单中的客户备注：客户可以在自己的订单上阅读，WP Admin 的订单页面会将其显示在配送地址下方，收据模板也可以打印此备注。请勿在此填写内部备注。
:::

## 移交订单 {#hand-over}

**移交** 是 **客户备注** 下方的琥珀色框，用于决定订单接下来留在哪里：

- **状态** — 未完成、待付款、保留或已取消。保留和已取消会将订单移出购物车；待付款则会保留在购物车中。其他状态的订单（例如已部分付款的订单）会显示其状态，但无法在此更改。
- **收银员** — 将订单移交给其他人。对方同步后，订单会出现在其未完成订单中。
- **店铺** 和 **收银机** — 将订单转移至另一收银端。当您有多个店铺或有可选收银机时，这些字段才会显示。

只有点击 **发送** 并确认后，**移交** 中的更改才会生效。如果先关闭面板，这些更改会被放弃，订单仍留在原处。

移交步骤：

1. 更改 **状态**、**收银员**、**店铺** 或 **收银机**。每项更改都会以琥珀色标记。
2. 检查框内信息：其中会说明订单将 **移出此购物车** 还是 **保留在此购物车**，并显示每项更改前后的值。
3. 点击 **发送**，然后确认。

有关未完成订单如何随收银员和收银机分配，请参见[未完成订单](./open-orders.mdx)。

## 移除订单税费 {#tax-exempt}

开启 **免税** 可移除订单的全部税费，包括附加费用和运费中的税费。关闭后即可恢复税费。

无法更改时，开关会变灰，下方提示会说明需要进行的操作：完成正在处理的付款、重新打开订单，或在订单使用了优惠券时连接店铺，或将店铺的 WooCommerce 更新至 11.3 或更高版本。如果店铺的价格含税，则不会显示此开关。

## 更改币种 {#currency}

:::warning 不会换算价格
更改币种不会换算价格。金额数值保持不变。
:::

点击 **+ 币种**，然后点击币种打开列表。在 **搜索币种** 中输入内容以缩小范围，再点击所需币种。

订单及其收取的款项都会以该币种记录。如果店铺支持多种币种，且本次销售不使用默认币种，可使用此功能。

当订单币种与店铺币种不同时，**币种** 行会自动显示。

## 添加额外信息 {#order-meta}

使用 **+ 自定义字段** 为订单添加额外信息，例如桌号或外部支付终端的参考编号。在 **键** 中输入名称，在 **值** 中输入信息。字段会列在 **自定义字段** 标题下，键和值并排显示，点击某行下方的 **移除** 即可删除该字段。

<details>
<summary>进阶：隐藏字段和订单数据</summary>

每个自定义字段都会以其键名保存在订单的 WooCommerce 订单元数据中。插件和报表会从中读取这些信息。

以下划线开头的键属于写入它们的插件的私有字段。这些字段折叠在 **隐藏字段** 下；点击 **显示** 可查看和编辑，点击 **隐藏** 可收起。WCPOS 自用的字段始终不会显示，新字段也不能使用这些字段的键名，否则 POS 会提示 **此键由 WCPOS 管理。请选择其他键。**

<JourneyShot manifest={manifest} device="phone" step={4} maxWidth={390} alt="订单详情的 JSON 选项卡：以原始数据形式显示订单状态、币种、总计、订单项目和客户备注" />

**JSON** 选项卡以数据形式显示完整订单，供您在支持人员协助下排查问题，或供开发者检查插件读取到的内容。

## 同步订单 {#sync-order}

POS 会将新订单保留在当前设备上，直到结账或移交时才与店铺通信。点击 **同步订单** 可立即发送订单。**订单 #… 已同步** 消息会显示店铺分配的订单号。在 **WooCommerce > 订单** 中，订单状态显示为 **POS - 未完成**。

对于暂存以便稍后处理的订单，请进行同步，以免设备被清空时丢失订单。参见[未完成订单](./open-orders.mdx)。

## 打印 {#print}

**打印** 会打开订单付款前、按当前内容生成的收据，方便用作报价单或餐桌账单。参见[打印收据](../../receipts/at-checkout.mdx)。

## 作废订单 {#void}

:::warning 请先取消付款
如果订单有已完成或正在处理的付款，就无法作废。POS 会提示 **此订单已有付款。请先在收款面板中使用“取消”撤销付款，然后作废订单。** 返回结账页面，在那里取消付款，然后再作废订单。参见[取消付款](../checkout/cancelling-a-payment.mdx)。
:::

**作废** 会删除订单并清空购物车。如果误点，可使用 **订单已移除** 消息中的 **撤销** 按钮。

- 从未同步的订单只存在于当前设备上，因此会被直接删除。
- 已同步的订单会移至 WooCommerce 的回收站。要找回订单，请从 **WooCommerce > 订单 > 回收站** 中恢复。如果店铺无法删除订单，则会将其标记为 **已取消**，并提示 **订单已作废并标记为已取消**。

作废不会涉及资金变动，因此收银机关闭时也可以操作。

## 遇到问题时 {#goes-wrong}

**保存订单失败。** 同步或移交未能传至店铺，订单已恢复原状。请检查连接后重试。

**此订单仍在发送至店铺。** 店铺尚未响应。请等待，不要再次发送；店铺确认后，订单会更新。

**发送按钮仍为灰色。** **移交** 中尚无更改，或新店铺的收银机仍在加载。如果该店铺有收银机，请选择一台。

**字段旁显示未保存。** 更改未能保存。请再次修改；该标记会保留到您下次更改时。

**免税开关变灰。** 请阅读开关下方的提示。参见[移除订单税费](#tax-exempt)。

**误将订单作废。** 在消息关闭前点击 **撤销**，即可将订单按原样放回购物车。
