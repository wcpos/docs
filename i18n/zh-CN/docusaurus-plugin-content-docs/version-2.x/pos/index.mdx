POS 是进行销售的地方。商品位于一侧，购物车位于另一侧，边缘的菜单用于访问其他功能。本页为你介绍界面的各个部分，并提供相应说明页面的链接。

**跳转到任务：** [查找商品](./product-panel/index.mdx) · [收款](./checkout/index.mdx) · [开启收银机](./register/index.mdx) · [打开收银员面板](#cashier-sheet)

## 熟悉界面 {#layout}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[34, -28], [52, 0], [52, 0], [52, 0], [240, 0], [0, -50], [200, 0], [128, 0], [-30, 0], [-14, 26]]} alt="平板电脑上的 POS，购物车中有一件商品：左侧边缘的菜单栏在悬停时显示“订单”名称，底部有店铺健康状况、设置和支持；界面还显示商品搜索框和网格、分隔线、购物车，以及购物车上方带有店铺名称、铃铛和头像的栏">

1. **菜单** — 每个图标对应一个页面。将指针移到图标上即可查看名称。参见[菜单](#menu)。
2. **店铺健康状况** — 查看此设备与店铺的同步情况，以及记录的问题。红色数字表示日志中有新错误。参见[店铺健康状况](../support/store-health.mdx)。
3. **设置** — 此设备的设置：语言和金额格式、税费显示、打印机、读卡器、顾客显示屏、扫描器及主题。参见[设置](../settings/index.mdx)。
4. **支持** — 应用内的 WCPOS Discord 聊天。参见[支持](../support/index.mdx)。
5. **商品面板** — 搜索、筛选并点击商品以添加到购物车。参见[商品面板](./product-panel/index.mdx)。
6. **分隔线** — 拖动可为商品或购物车分配更多空间。POS 会在此设备上记住宽度。
7. **购物车** — 当前正在处理的销售，包含顾客、商品明细、总计和**结账**按钮。参见[购物车](./cart/index.mdx)。
8. **收银机栏** — 显示当前销售所属的店铺；如果店铺有多台收银机，还会显示收银机。参见[顶部栏](#bar)。
9. **铃铛** — WCPOS 通知：插件更新、许可证提醒和公告。参见[通知](../support/notifications.mdx)。
10. **你的头像** — 打开收银员面板。参见[收银员面板](#cashier-sheet)。

</JourneyShot>

点击菜单下方的版本号（此处为 **v 2.0.0**）可打开[关于 WCPOS](#about)。

## 菜单 {#menu}

在平板电脑或电脑上，菜单以一列图标的形式始终显示在屏幕左侧边缘。在手机上，菜单收起在左上角的 **☰** 中，打开后会滑出并覆盖屏幕，同时显示各项名称。点击名称即可前往相应页面。

<JourneyShot manifest={manifest} device="phone" step={2} offsets={[[-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0], [-6, 0]]} maxWidth={390} alt="手机上展开的菜单：顶部为 POS、商品、订单、优惠券、顾客和报表，底部为店铺健康状况、设置和支持，其下方显示版本号">

1. **POS** — 进行销售的收银界面。参见[结账](./checkout/index.mdx)。
2. **商品** — 库存、价格和商品详情。参见[商品](../products/index.mdx)。
3. **订单** — 历史订单：查找订单、重新打印收据或退款。参见[订单](../orders/index.mdx)。
4. **优惠券** — 店铺的优惠券。参见[优惠券](../coupons/index.mdx)。
5. **顾客** — 添加和编辑顾客。参见[顾客](../customers/index.mdx)。
6. **报表** — 按付款方式和收银员统计的当日收入，以及收银机结班记录。参见[报表](../reports/index.mdx)。
7. **店铺健康状况** — 此设备与店铺的同步情况，以及记录的问题。参见[店铺健康状况](../support/store-health.mdx)。
8. **设置** — 此设备的设置。参见[设置](../settings/index.mdx)。
9. **支持** — 应用内的 WCPOS Discord 聊天。参见[支持](../support/index.mdx)。

</JourneyShot>

使用免费版插件时，**商品**、**订单**、**优惠券**和**顾客**页面仅供预览，无法修改。

<details>
<summary>WCPOS Pro 有哪些不同？</summary>

**使用免费版插件时**，**商品**、**订单**、**优惠券**和**顾客**页面会显示模糊预览和**升级到 Pro**面板。你仍可在购物车中选择顾客并使用优惠券。**报表**显示当前收银机的当日数据。

**使用 WCPOS Pro 时**，可以在**商品**、**订单**、**优惠券**和**顾客**页面进行编辑；**报表**可查看今天之前的数据，涵盖你有权查看的所有收银机和店铺；如果有多家店铺，还可通过顶部栏或收银员面板切换店铺。

参见[免费版与 Pro 对比](../getting-started/free-vs-pro.mdx#management-screens)。

</details>

## 手机界面 {#phone}

在手机或较窄的浏览器窗口中，商品和购物车分别位于底部的两个标签页。顶部栏仍保持在顶部，可通过 **☰** 打开菜单。

<JourneyShot manifest={manifest} device="phone" step={3} offsets={[[-10, 0], [108, 0], [-12, 0], [-14, 0], [40, 0], [40, 0]]} maxWidth={390} alt="手机上的 POS，购物车中有一件商品：顶部有菜单按钮、店铺名称、铃铛和头像，中间有商品搜索框和商品卡片，底部有商品和购物车标签页，购物车标签上显示数量">

1. **☰ 菜单** — 打开[菜单](#menu)。
2. **收银机栏** — 显示店铺；如果有多台收银机，还会显示收银机。
3. **铃铛** — [通知](../support/notifications.mdx)。
4. **你的头像** — [收银员面板](#cashier-sheet)。
5. **商品** — [商品面板](./product-panel/index.mdx)。
6. **购物车** — 当前销售，显示其中的商品数量。从这里开始结账。

</JourneyShot>

其他页面的布局也会变化。在触摸屏上，商品、订单、优惠券和顾客页面将每条记录显示为一行，行末带有 **›**；使用鼠标时则显示为表格。在手机上，点击一行会在独立页面中打开该记录；点击 **✕** 可返回列表。

1. **☰ 菜单** — 手机上的每个页面都有此按钮。
2. **搜索** — 搜索框会注明当前页面，例如**搜索商品**、**搜索订单**等。

</details>

## 顶部栏 {#bar}

每个页面顶部都有一个横栏，铃铛和你的头像始终位于其末端。

在 POS 中，这是**收银机栏**：显示当前销售所属的店铺；如果店铺有多台收银机，还会显示收银机名称。使用 WCPOS Pro 且有多家店铺时，点击店铺名称即可切换店铺。有需要注意的情况时，名称旁会显示状态。

<details>
<summary>收银机状态的含义</summary>

- **已关闭**、**盘点中**、**需要审批**或**已逾期** — 表示收银机当天所处的阶段。参见[开启收银机](./register/index.mdx)。
- **选择收银机**或**无收银机** — 此设备尚未关联收银机。参见[选择店铺和收银机](../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)。
- **离线**或**离线 · 2 笔销售待发送** — 参见下方[顶部栏显示离线](#offline)。
- **1 笔销售等待店铺确认** — 店铺尚未确认的一笔销售。系统会自动处理，无需操作。

已开启的收银机如果没有需要提示的情况，就不会显示状态。

</details>

<details>
<summary>其他页面及桌面应用中的顶部栏</summary>

在**商品**、**订单**、**优惠券**和**顾客**页面，搜索框取代了标题，并注明页面名称。**报表**页面则在此处显示店铺和收银机选择器。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[34, -28], [260, 0], [10, 40], [10, 40], [10, 40]]} alt="商品页面及其顶部栏：菜单中的商品图标高亮显示，商品表格上方有搜索框、显示选项、铃铛和头像">

1. **当前位置** — 菜单中高亮显示的图标。
2. **搜索** — 查找当前页面的记录。
3. **显示选项** — 选择列表显示哪些列。参见[显示设置](../products/index.mdx#display-settings)。
4. **铃铛** — 与 POS 中相同的[通知](../support/notifications.mdx)。
5. **你的头像** — 可从任意页面打开同一个[收银员面板](#cashier-sheet)。

</JourneyShot>

在桌面应用中，店铺名称、状态、铃铛和头像会上移到窗口标题栏。窗口全屏显示时，它们会回到顶部栏。

</details>

## 收银员面板 {#cashier-sheet}

在任意页面点击头像，收银员面板就会从右侧滑出。在手机上，面板会占满屏幕。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[130, 0], [230, -15], [180, -19], [-30, 0], [0, -32], [0, -32], [100, 0]]} alt="覆盖在 POS 上的收银员面板：显示你的姓名、店铺及已登录时长、你今天的销售、钱箱卡片、将收银机交接给、带切换按钮的店铺、WordPress 后台和桌面应用链接，以及退出登录">

1. **你今天的销售** — 你已完成的销售。
2. **钱箱内现金** — 收银机预计应有的现金金额。如果没有查看报表的权限，则显示销售笔数而非金额。点击可进行现金存入、支出和结班。参见[开启收银机](./register/index.mdx#cashier-sheet)。
3. **将收银机交接给** — 无需结班，即可将收银机交给另一位收银员。点击对方姓名，或点击**其他账户…** 让对方登录。参见[开启收银机](./register/index.mdx#cashier-sheet)。
4. **店铺 · 切换** — 切换到另一家店铺（需要 WCPOS Pro 且有多家店铺）。店铺有多台收银机时，下方还会显示**收银机 · 切换**。
5. **WordPress 后台** — 在新标签页中打开网站后台，供有访问权限的管理员使用。
6. **桌面应用** — 桌面应用的下载页面。这两个链接仅在浏览器中显示。
7. **退出登录** — 如果收银机处于开启状态，POS 会询问是否先结班。

</JourneyShot>

## 键盘快捷键 {#keyboard-shortcuts}

在浏览器或桌面应用中使用键盘时，这些快捷键在 POS 页面的任何位置都有效，即使正在输入框中输入也不例外。在 Mac 上，请按住 **Option**（⌥）而不是 **Alt**。

<details>
<summary>显示键盘快捷键</summary>

| 快捷键 | 功能 |
|---|---|
| `Alt` + `F` | 搜索商品 |
| `Alt` + `P` | 结账 |
| `Alt` + `N` | 新建购物车 |
| `Alt` + `←` / `Alt` + `→` | 上一个购物车 / 下一个购物车 |
| `Alt` + `D` | 添加折扣 |
| `Alt` + `V` | 作废订单 |
| `Alt` + `/` | 显示快捷键 |
| `Esc` | 未在输入框中输入时，从结账返回购物车 |

快捷键仅在适用时才会生效，例如**结账**需要购物车中有商品。快捷键无法更改。参见[键盘快捷键](../settings/store/hotkeys.mdx)。

</details>

## 遇到问题时 {#goes-wrong}

### 顶部栏显示离线 {#offline}

此设备无法连接店铺：可能是网络中断，或网站没有响应。你可以继续销售，现金付款和通过独立终端收取的银行卡付款仍可完成。顶部栏会将待处理的销售计为**待发送销售**，待店铺恢复连接后自动发送。由收银机控制的读卡器和在线支付网关需要联网。参见[离线模式](../getting-started/offline.mdx)。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[80, 0], [52, 26]]} alt="连接刚刚中断时的 POS：顶部栏的店铺名称旁显示离线，并提示设备已离线，可继续工作，店铺恢复连接后将恢复同步">

1. **离线** — 持续显示，直到店铺重新响应。
2. **店铺名称** — 这些销售将发送到的店铺。

</JourneyShot>

### “本地数据库不可用” {#database-unavailable}

商品上方和结账界面中的横幅会提示，扫描、结账、保存和作废操作已被阻止。

1. 点击**重新加载应用**。
2. 如果应用提示无法自行重新加载（某些手机和平板应用会出现这种情况），请彻底关闭应用后重新打开。
3. 如果问题持续出现，参见[清除本地数据](../support/troubleshooting/clear-local-data.mdx)。

<details>
<summary>问题原因</summary>

设备上保存的店铺数据副本已停止工作。点击横幅上的**查看状态**可打开店铺健康状况中的[数据库](../support/store-health.mdx#database)部分。

</details>

### 店铺健康状况上的红色数字 {#store-health-errors}

此设备记录了新错误。打开**店铺健康状况**及其中的日志即可查看；打开日志后，数字就会清除。参见[日志](../support/store-health.mdx#logs)。

### “此页面不存在” {#not-found}

地址已过期，通常是因为使用了旧书签。点击**返回起始页面**：系统会转到 POS；如果已退出登录，则会转到连接店铺的页面。

### 页面显示“升级到 Pro” {#upgrade-to-pro}

该页面需要 WCPOS Pro。参见[菜单](#menu)下的**WCPOS Pro 有哪些不同？** 或[免费版与 Pro 对比](../getting-started/free-vs-pro.mdx)。
