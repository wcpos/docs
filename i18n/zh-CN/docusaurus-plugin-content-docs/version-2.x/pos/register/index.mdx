收银机的一个班次，从您清点备用金并放入钱箱时开始，到再次盘点钱箱时结束。本页介绍每天开始时及营业期间的操作：输入备用金开班、查看钱箱金额，以及存入和取出现金。有关每天结束时的盘点与结班，请参阅[收银机结班](../reconciliation.mdx)。

:::note 本页操作需要启用收银机功能
本页所有操作都依赖于 **收银机开班和结班** 设置。关闭该设置后，POS 会直接进入购物车，无需开班或盘点。有关此设置，请参阅[收银机](../../settings/wp-admin/registers.mdx#one-register)。使用 WCPOS Pro 的店铺功能时，每个店铺都有自己的设置：请参阅[设置店铺](../../stores/setup.mdx)。
:::

## 收银机开班 {#open}

收银机处于结班状态时，收银机栏显示 **已结班**，商品区域显示 **收银机开班前仅可查价。** 您可以搜索商品和查看价格，但无法将商品加入购物车。购物车栏此时显示 **收银机开班** 卡片：

- **钱箱内现金** — 以大号数字显示，默认填入收银机建议的备用金金额：即[收银机](../../settings/wp-admin/registers.mdx#one-register)中的 **开班备用金**；未设置时，则使用上次盘点金额。
- **默认备用金** 和 **上次盘点** — 点击其中一项即可将金额恢复为对应数值。采用盲盘方式的收银员看不到上次盘点金额。
- **数字键盘** — 盘点钱箱内的现金并输入金额。按下第一个键时就会替换建议金额，无需事先清空。**⌫** 用于删除最后一位数字。
- **开班差异** — 您输入的金额与建议备用金不同时显示。班次会将此差异与您清点的备用金一起保存。
- **收银机开班** — 开始班次。系统会提示确认开班时的备用金金额。
- **上次结班** — 上一次结班的编号和实点金额。

如果收银机已在另一台设备上开班，就不会要求输入备用金：本设备会加入该班次。请参阅[店铺、收银机和设备](../../stores/registers-and-devices.mdx#several-devices-on-one-register)。

## 收银员面板 {#cashier-sheet}

点击收银机栏末尾的头像。在这里可以查看钱箱，也可以将收银工作交接给其他人。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[325, -31], [140, 0], [147, -17], [-57, 0], [-57, 0], [112, 0]]} alt="收银员面板：钱箱金额、您的今日销售、交接给、切换收银机、切换店铺和退出登录">

1. **钱箱金额** — 收银机当前预计应有的现金。点击可打开[收银机面板](#cash-movements)。没有 *查看报表* 权限时，您需采用盲盘方式，因此这里显示销售笔数而非金额。请参阅[访问权限](../../settings/wp-admin/access.mdx)。
2. **您的今日销售** — 您已完成的销售。
3. **交接给** — 将收银工作交给另一位收银员。收银机保持开班状态，POS 会以对方的身份重新加载。未完成的购物车会保留给原收银员。
4. **切换收银机** — 仅在有多台收银机时可用。请先完成或挂起当前销售。请参阅[选择店铺和收银机](../../stores/registers-and-devices.mdx#choosing-a-store-and-a-register)。
5. **切换店铺** — 仅在有多个店铺时可用（WCPOS Pro）。
6. **退出登录** — 未结班的收银机会保持开班状态，供下一位收银员使用，POS 会询问是否先结班。

</JourneyShot>

## 现金存取 {#cash-movements}

在收银员面板上点击 **钱箱金额**，打开收银机面板。面板首先显示钱箱应有的现金。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[250, 0], [250, 0], [0, 0], [0, 0], [0, 0], [190, 0], [275, 0], [0, -34], [0, -34]]} alt="收银机面板：首先显示钱箱内现金，其后为本班次销售、存入现金、支出现金和无销售开钱箱、收起的钱箱应有金额、其他支付方式、上次结班、打印 X 报表以及收银机结班">

1. **钱箱金额** — 收银机预计应有的现金，随每笔销售和现金存取而更新。采用盲盘方式的收银员看不到此金额。
2. **本班次销售** — 收银机开班以来的销售总额和笔数。
3. **存入现金** — 向钱箱放入现金。
4. **支出现金** — 从钱箱取出现金。
5. **无销售开钱箱** — 打开钱箱，不发生资金变动。
6. **钱箱应有金额** — 点击可展开钱箱金额的计算明细：备用金、现金销售、现金退款和每笔现金存取。下方的 **其他支付方式** 可展开银行卡及其他付款方式的明细。
7. **上次结班** — 本班次之前的一次结班，显示编号、实点金额及结果：**相符**、**短款** 或 **长款**。
8. **打印 X 报表** — 打印本班次截至此时的报表，不进行结班。
9. **收银机结班** — 开始盘点。请参阅[收银机结班](../reconciliation.mdx#count)。

</JourneyShot>

### 存入现金 {#pay-in}

点击 **存入现金**。面板会询问 *要向钱箱存入多少现金？* 输入金额，然后填写原因。每笔现金存取都需要原因：点击一个原因，或点击 **其他…** 并自行输入。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[392, 0], [100, 0], [0, 0], [0, 0], [0, 0], [150, 0], [0, -34]]} alt="存入现金面板：钱箱当前金额和存入后金额、金额、数字键盘、以网格排列的原因、输入的原因以及存入按钮">

1. **钱箱当前金额及操作后金额** — 钱箱当前的现金，以及此次现金存取后的现金。
2. **金额** — 您输入的金额。
3. **数字键盘** — 输入金额。
4. **原因选项** — **备用金**、**换零** 或 **银行**。点击其中一项可填入原因；再次点击可清除。
5. **其他…** — 清除原因，以便您自行输入。
6. **原因** — 随现金存取记录保存的原因。可直接在此输入，也可修改所选原因填入的文字。
7. **存入 …** — 记录此次现金存入。如果金额或原因尚未填写，面板会提示缺少哪一项。

</JourneyShot>

### 支出现金 {#pay-out}

从钱箱取出现金时，请点击 **支出现金**：例如向上门供应商付款、支付零用支出、存入银行或支付小费。面板会询问 *要从钱箱取出多少现金？*，操作方式相同。在手机上，原因选项分为两列。

<JourneyShot manifest={manifest} device="phone" step={6} maxWidth={390} offsets={[[330, 8], [60, 0], [0, 0], [0, 0], [0, 0], [150, 0], [0, 0]]} alt="手机上的支出现金面板：钱箱当前金额和支出后金额、金额、数字键盘、分为两列的原因、输入的原因以及取出按钮">

1. **钱箱当前金额及操作后金额** — 钱箱当前金额及支出后的金额。
2. **金额** — 您输入的金额。
3. **数字键盘** — 输入金额。
4. **原因选项** — **供应商**、**零用支出**、**银行**、**小费** 或 **换零**。
5. **其他…** — 自行输入原因。
6. **原因** — 随现金存取记录保存的原因。
7. **取出 …** — 记录此次现金支出。

</JourneyShot>

**无销售开钱箱** 会打开钱箱，不发生资金变动。它仍会询问 *为什么打开钱箱？*：点击 **换零**、**误操作**、**检查钱箱** 或 **其他…**，然后点击 **打开钱箱**。

### 查看现金存取记录 {#movements}

每笔现金存取完成后都会显示确认提示，例如 **已存入 $1.00**，并提供 **撤销** 按钮。要查看本班次的全部现金存取记录，请点击 **钱箱应有金额**。

<JourneyShot manifest={manifest} device="tablet" step={8} offsets={[[250, 0], [200, 0], [150, -42], [150, -56], [0, 26], [0, -34]]} alt="展开钱箱应有金额后的收银机面板：备用金、现金销售和退款、带原因及作废按钮的存入现金和支出现金明细，以及收银机结班">

1. **钱箱金额** — 已包含现金存取。
2. **备用金** — 本班次开班时的备用金及开班时间。以此为起点，加上现金销售额，再减去现金退款。
3. **存入现金** — 存入笔数、总额，以及每笔存入的原因。
4. **支出现金** — 以同样方式显示取出的现金。
5. **作废** — 取消该笔现金存取。仅在收银机处于开班状态时可用。
6. **收银机结班** — 一天结束时使用。请参阅[收银机结班](../reconciliation.mdx#count)。

</JourneyShot>

## 盘点并结班 {#close}

每天结束时，点击面板上的 **收银机结班**，盘点钱箱并保存结班记录。有关盘点、结班以及钱箱金额不符时的处理方法，请参阅[收银机结班](../reconciliation.mdx#count)。

## 遇到问题时 {#goes-wrong}

**现金存取输入有误。** 点击弹出提示上的 **撤销**，或点击 **钱箱应有金额** 下对应行上的 **作废**。两种方式都会从面板移除该记录，并恢复钱箱金额。已作废的现金存取记录无法恢复，需要重新输入。只有收银机处于开班状态且未在盘点时，才能作废。

**按钮显示“输入金额”或“添加原因”。** 现金存取信息尚未填写完整。请先输入金额，再选择或输入原因。

**面板显示“金额将在下次同步时更新”。** 收银机正在等待店铺传回金额，在收到之前，**收银机结班** 按钮保持禁用。请停留在页面上并检查网络连接。

**现金存取记录被拒绝。** 面板顶部的提示会显示店铺拒绝了多少笔记录。请点击提示上的 **重试**。

**收银机已在另一台终端上结班。** 收银机开班卡片会显示结班人员和时间。请盘点钱箱并重新开班。

**其他人正在盘点。** “正在另一台终端上盘点”会显示开始盘点的人员和时间。请等待对方完成。

**“此店铺没有收银机”或“无法连接此店铺的收银机”。** POS 没有可供开班的收银机。请检查网络连接，然后点击 **重试**。如果店铺确实没有收银机，需要由经理添加。请参阅[店铺、收银机和设备](../../stores/registers-and-devices.mdx#where-the-settings-live)。

**结班时盘点金额不符。** 请参阅[收银机结班](../reconciliation.mdx#goes-wrong)。

:::info 使用 WCPOS Pro
Pro 支持每个店铺使用更多收银机，并在报表中查看完整的结班历史记录。请参阅[通过 Pro 使用更多收银机](../../settings/wp-admin/registers.mdx#more-registers-with-pro)。
:::
