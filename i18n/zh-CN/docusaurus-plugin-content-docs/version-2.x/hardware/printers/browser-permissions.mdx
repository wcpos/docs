如果 Epson 或 Star 打印机已开启且与收银设备处于同一网络，但浏览器标签页中的 POS 无法访问它，请先[按此顺序排查](#fix-in-order)。桌面应用不需要这些修复操作。

## 您会看到的情况 {#symptom}

在**设置 → 打印 → 添加打印机**中，扫描没有结果（**未找到打印机**），或输入打印机地址后，卡片显示**未连接**，但打印机已开启且处于同一网络。也可能同一台打印机能通过桌面应用打印，却无法通过浏览器标签页打印。

测试页打印失败后，应用可能提示**应用未获准访问打印机。请在系统设置中允许访问，然后重试。** 在浏览器中，这表示浏览器无法访问打印机。请检查打印机已开启且地址正确，然后按下文逐项排查。两种界面均在[下文中标注说明](#on-screen)。

## 按此顺序排查 {#fix-in-order}

如果使用 Safari 或 Firefox，请先查看[这些浏览器支持的方式](#safari-and-firefox)。如果使用 Chrome 或 Edge：

1. [允许访问本地网络](#allow-local-network-access)，然后再次检查。
2. 如果仍然失败，请查找打印机的**端口**：已保存的打印机在**编辑打印机**中查看，添加打印机时在**输入 IP 地址**下查看。端口表明 POS 使用的是 HTTPS 还是普通 HTTP：

   | 打印机 | HTTPS 端口 | HTTP 端口 |
   |---|---|---|
   | Epson | **8043** 或 **443** | **8008** 或 **80** |
   | Star | **443** | **80** |

   然后按对应方式处理：

   - **HTTPS 端口：** [信任打印机的证书](#the-printers-certificate)，然后再次检查。
   - **HTTP 端口：** 请参阅[打印机使用 HTTP 时](#mixed-content)。

3. 仍显示**未连接**，或测试仍然失败？请参阅[仍未解决？](#still-stuck)

### 再次检查 {#check-again}

- **添加打印机时：** 按下**输入 IP 地址**，再按下**检查此地址**。卡片显示**就绪**时，说明浏览器可以访问打印机，请继续[打印测试页](./setup-wizard.mdx#test-page)。
- **已保存的打印机：** 在**设置 → 打印**中，按下该打印机所在行的**测试打印**，或在**编辑打印机**中按下此按钮。

允许访问本地网络后仍然失败？[查找端口](#fix-in-order)（第 2 步）。按对应端口的方式处理后仍然失败？请参阅[仍未解决？](#still-stuck)

[HTTPS 还是 HTTP](#https-or-http)提供了界面截图，展示在哪里查看端口。

## 允许访问本地网络 {#allow-local-network-access}

网站访问本地网络上的设备前，Chrome 和 Edge 会询问您的许可。提示会请求**访问您本地网络上的其他设备**。请允许访问。

如果之前有人选择了**永不允许**，或关闭了提示：

1. 点击地址栏左侧的图标，再点击**网站设置**。
2. 将**本地网络**设为**允许**。
3. 重新加载 POS 并[再次检查](#check-again)。

## 打印机的证书 {#the-printers-certificate}

通过 HTTPS 连接时，打印机会提供自己的证书。如果当前浏览器不信任该证书，连接会在发送任何内容前失败。以下步骤可让当前浏览器建立连接。

1. 确认打印机有证书。如果状态页显示没有证书，请在打印机的网页配置中创建自签名证书。对于 Epson，请按 [Epson 安全打印](./secure-printing.mdx#turn-it-off)中的方法登录。
2. 在同一浏览器中，使用打印机实际的 IP 地址，通过 HTTPS 打开打印机地址：
   - **Epson：** 先尝试 `https://192.168.1.200:8043`。如果无法打开，再尝试 `https://192.168.1.200`，该地址使用端口 443。
   - **Star：** `https://192.168.1.200`，使用端口 443。
3. 在证书警告中选择继续访问。展开您所用浏览器的操作步骤：

   <details>
   <summary>Chrome</summary>

   在**您的连接不是私密连接**页面，按下**高级**，再按下**继续前往 192.168.1.200（不安全）**。

   </details>

   <details>
   <summary>Edge</summary>

   按下**高级**，再按下**继续访问 192.168.1.200（不安全）**。

   </details>

   <details>
   <summary>Safari</summary>

   在**此连接非私人连接**页面，按下**显示详细信息**，再点击**访问此网站**链接，最后按下**访问网站**。

   </details>

   <details>
   <summary>Firefox</summary>

   使用警告页面上提供的选项继续访问网站。

   </details>

4. 返回 POS 并[再次检查](#check-again)。

每台用于打印的电脑上的每个浏览器都需要执行此操作。

桌面应用会自行接受打印机的证书，因此同一台打印机可能在桌面应用中可用，在浏览器标签页中却不可用。

## 打印机使用 HTTP 时 {#mixed-content}

如果店铺地址以 `https://` 开头，而打印机仅支持普通 HTTP，请使用 Chrome 或 Edge 142 或更新版本打印，并[允许访问本地网络](#allow-local-network-access)。

其他浏览器会阻止此连接：安全页面不能向不安全的地址发送内容，浏览器称之为混合内容。如果无法使用 Chrome 或 Edge，请为打印机配置[证书](#the-printers-certificate)并改用 HTTPS，或使用桌面应用。

## Safari 和 Firefox {#safari-and-firefox}

- **通过 Wi-Fi：** 打印机的协议必须与店铺匹配。店铺地址为 `https://` 时，只有在[接受证书](#the-printers-certificate)后才能使用 HTTPS，普通 HTTP 会被阻止。店铺地址为 `http://` 时，可以使用普通 HTTP。
- **USB 和蓝牙：** **查找 USB 打印机**和**查找蓝牙打印机**仅在能访问这些设备的浏览器中显示，即 Chrome 和 Edge。

其他情况请使用 Chrome、Edge 或桌面应用。

2. **输入 IP 地址** — 修复后再次检查地址。

## HTTPS 还是 HTTP {#https-or-http}

浏览器通过[上表](#fix-in-order)中的某个端口访问打印机的网页服务器。端口决定使用 HTTPS 还是普通 HTTP。

- **HTTPS** 要求打印机上有当前浏览器信任的证书。请参阅[打印机的证书](#the-printers-certificate)。
- HTTPS 店铺使用 **HTTP** 连接打印机时，需要 Chrome 或 Edge 142 或更新版本，以及[本地网络权限](#allow-local-network-access)。请参阅[打印机使用 HTTP 时](#mixed-content)。

对于已保存的打印机，**编辑打印机**会在 **Web 打印端点**下显示使用的协议：

<JourneyShot manifest={manifest} device="tablet" step={13} offsets={[[290, 0], [0, 30], [572, -2], [700, 0]]} alt="编辑地址为 192.168.1.128、端口为 8008 的 Epson 打印机：已检测到：Epson，Web 打印端点为 http://192.168.1.128:8008/cgi-bin/epos/service.cgi，正在通过 HTTP 使用 Epson ePOS。Chrome 或 Edge 可能会请求访问本地网络的权限">

1. **IP 地址** — 打印机的地址。
2. **端口** — 此处为 8008，即 Epson 的普通 HTTP 端口。在 HTTPS 店铺中，新添加的 Epson 默认使用 **8043**，即 HTTPS 端口。
3. **Web 打印端点** — 浏览器发送收据的目标地址。普通 HTTP 地址以 `http://` 开头，HTTPS 地址以 `https://` 开头。
4. **端点下方的文字** — 以文字说明厂商以及所用的 HTTPS 或 HTTP 协议。使用 HTTP 时，还会提示 Chrome 或 Edge 可能请求[本地网络权限](#allow-local-network-access)；使用 HTTPS 时，则会提示打印机需要当前浏览器信任的证书（[打印机的证书](#the-printers-certificate)）。

</JourneyShot>

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[351, 0], [64, 0], [133, -18]]} maxWidth={559} alt="输入打印机的 IP 地址：IP 地址字段为 192.168.1.200，端口字段为 8043，以及检查此地址按钮">

1. **IP 地址** — 可在打印机的状态页上找到。
2. **端口** — 在 HTTPS 店铺中，默认使用 Epson 的 HTTPS 端口 **8043**。
3. **检查此地址** — 尝试 Epson 和 Star 常用的 HTTPS 和 HTTP 端口，并保留有响应的端口。

</JourneyShot>

## 仍未解决？ {#still-stuck}

使用**复制设置报告**，并将其粘贴到消息中。测试页打印失败后，可在**未打印任何内容**界面找到此选项，也可在已保存打印机的菜单中找到。报告记录了地址、端口和尝试过的操作。在**未打印任何内容**界面中，**支持详情**还会显示您使用的浏览器。
