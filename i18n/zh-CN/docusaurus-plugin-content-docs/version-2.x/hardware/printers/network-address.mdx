**现象：** 搜索网络打印机后显示**未找到打印机**。或者打印机正常使用数周后停止工作，每次打印收据都失败，并提示**无法连接所选打印机**（[PRINT301](../../error-codes/PRINT301.mdx)）。

打印机本身通常没有问题。收银设备无法连接它，可能是因为两者处于不同网络，或打印机的地址发生了变化。

- **正在添加打印机？** [检查网络](#same-network)、[查看地址](#read-the-address)，然后[通过地址添加打印机](#enter-address)。
- **原本正常的打印机停止工作了？** [查看地址](#read-the-address)，然后[修改已保存打印机的地址](#change-address)。

恢复打印后，请[固定地址](#fixed-address)，以免再次出现此问题。

## 先检查网络 {#same-network}

将收银设备和打印机连接到**同一个店铺网络**，不要使用访客网络。打印机可以通过 Wi-Fi 连接，也可以用网线连接路由器。然后前往**设置 → 打印**，点击**添加打印机**，等待搜索。如果找到打印机，添加它并[固定其地址](#fixed-address)。如果没有找到，请查看其地址并直接添加。[原因说明](#why-it-happens)介绍了两者无法互通的原因。

## 查看打印机的地址 {#read-the-address}

打印机会在**状态页**上打印自己的地址。有些厂商将其称为网络自检页或配置页。

- **联网的 Epson TM 打印机**（例如 TM-m30III）：在打印机开机时，打开卷纸盖，按住**进纸**至少一秒，然后关闭盖子。如果您的型号有状态页按钮，按住约三秒也能打印同样的页面。
- **联网的 Star 打印机：** 在打印机开机时，按住**进纸**约五秒。地址位于**当前 IP 参数**下方。
- **其他打印机，或没有打印出状态页：** 不同型号的按键操作有所不同。请在打印机手册中查找“状态页”或“网络自检”。

在状态页上找到 **IP 地址**一行，例如 `192.168.1.100`。店里有两台打印机？请确认状态页来自正确的那一台。

接下来，[添加打印机](#enter-address)，或[修改已保存打印机的地址](#change-address)。

## 通过地址添加打印机 {#enter-address}

如果搜索未找到打印机，请直接输入地址。收银设备仍须能够通过店铺网络访问打印机。

1. 前往**设置 → 打印**，点击**添加打印机**。搜索会自动开始。
2. 在搜索过程中或结束后，点击**输入 IP 地址**。这会停止搜索。
3. 在 **IP 地址**中输入状态页上的地址。
4. 点击**检查此地址**。
5. 卡片显示**就绪**或**需要测试**时，点击**打印测试页**。如果卡片旁显示**纸张宽度**，请先选择 **58 mm** 或 **80 mm**。
6. 应用会询问**测试页打印出来了吗？** 点击**是的，而且显示正常**。应用会保存打印机，并显示 **… 已设置完成**。

如果测试页上的标尺不正确，或没有打印出任何内容，另外两个回答会引导您继续操作。请参阅[添加打印机](./index.mdx#adding-a-printer)。

## 打印机已设置好？修改其地址 {#change-address}

如果原本正常的打印机因地址变化而停止工作，请修改已保存打印机的地址，无需重新添加。

1. 前往**设置 → 打印**。
2. 点击打印机所在行的**编辑**。
3. 将 **IP 地址**改为状态页上的地址。输入时会自动保存更改。也可用**扫描网络**来查找打印机。
4. 点击**测试打印**。如果没有打印出任何内容，请参阅[出现问题时](#if-something-goes-wrong)。

1. **打印机名称** — 当前正在修改的打印机。
2. **IP 地址** — 状态页上的地址。输入时会自动保存更改。
3. **端口** — 已自动填写，您的值可能与此处不同。在浏览器中，它还决定使用 HTTPS 还是普通 HTTP：请参阅 [HTTPS 或 HTTP](./browser-permissions.mdx#https-or-http)。

5. **测试打印** — 使用新地址打印测试页。
6. **关闭** — 保存并关闭。

## 固定地址 {#fixed-address}

添加打印机或恢复打印不需要执行这一步。它能防止地址再次变化，让您只需输入一次地址。打印机恢复打印后，请负责店铺路由器的人**为打印机保留地址**，即状态页上的地址。此后路由器每次都会为打印机分配该地址。

<details>
<summary>路由器和打印机设置</summary>

- **在路由器上保留地址（推荐）。** 在路由器设置中，打开列出网络设备的页面（通常名为 DHCP 或 LAN）。根据状态页上的地址找到打印机，并为其保留该地址。许多路由器会要求在此输入打印机的 MAC 地址。打印机上无需改动。
- **也可在打印机上设置。** 在同一网络中的网页浏览器内打开打印机地址，例如 `http://192.168.1.100`，然后在其网络设置中指定固定（静态）地址。请选择路由器不会分配给其他设备的地址，否则两台设备可能使用相同地址。路由器设置中可查看其分配的地址范围。

</details>

## 原因说明 {#why-it-happens}

- **处于不同网络。** 收银设备和打印机分别连接到不同网络，例如访客网络、第二台路由器或员工设备专用网络。搜索只会在收银设备所在网络中进行。
- **访客 Wi-Fi 会隔离设备。** 访客 Wi-Fi 和公共 Wi-Fi 通常禁止网络中的设备互相通信。路由器设置中称其为客户端隔离或 AP 隔离。即使打印机在同一 Wi-Fi 网络中，也可能无法访问。
- **地址发生变化。** 路由器会将地址租给各设备使用一段时间。重启或租期结束后，打印机可能获得新地址，而应用仍向旧地址发送打印任务，于是出现昨天能打印、今天却失败的情况。

<details>
<summary>在网页浏览器中，搜索只会尝试常见地址</summary>

浏览器无法查询网络中有哪些设备，因此搜索会尝试大多数路由器使用的地址范围：`192.168.0.x`、`192.168.1.x`、`192.168.4.x`、`192.168.10.x`、`10.0.0.x`、`10.0.1.x` 和 `172.16.0.x`。处于其他地址范围的打印机无法通过搜索找到，请改为通过地址添加。在浏览器中，应用通过网络连接 Epson 和 Star 打印机；请参阅[各平台应用可连接的打印机](./index.mdx#supported-printers-by-platform)。

</details>

## 出现问题时 {#if-something-goes-wrong}

- **状态页上的地址以 `169.254` 开头。** 打印机未从网络获得地址。请检查网线或 Wi-Fi 设置，然后重新打印状态页。
- **地址正确，但显示未连接。** 检查收银设备和打印机是否连接到同一个店铺网络，而非访客 Wi-Fi（请参阅[原因说明](#why-it-happens)）。如果确实在同一网络，请按下文检查应用权限。
- **在 iPad 或 iPhone 上搜索无结果。** 应用需要**本地网络**权限。请参阅[允许应用在 iPad 或 iPhone 上查找打印机](./ios-local-network.mdx)。
- **在浏览器中搜索无结果，或桌面应用能打印而浏览器不能。** 浏览器需要访问本地网络的权限。请参阅[通过浏览器打印](./browser-permissions.mdx)。
- **地址正确，打印一次后就停止了。** 打印机可能保留着未完成的任务。请参阅 [Epson 打印一次后停止](./printed-once-then-stopped.mdx)。

## 仍有问题？ {#still-stuck}

复制设置报告并粘贴到消息中。在**添加打印机**的**未打印任何内容**界面，或**设置 → 打印**中打印机所在行的 **⋯** 菜单内，点击**复制设置报告**。在移动应用中，这会打开共享面板。报告包含应用使用的地址和端口，以及应用最近的打印机日志。从**添加打印机**生成的报告还包含打印机各端口的响应。在您粘贴或分享之前，报告不会离开设备。
