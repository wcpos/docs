打印机位于 POS 的**设置 → 打印**中。每台设备各自保存打印机列表：在一台收银设备上添加的打印机不会出现在另一台上，因此每台需要使用该打印机的设备都必须单独设置。

即使未添加打印机，仍可通过**打印对话框**打印收据，即浏览器或电脑自带的打印窗口。此功能内置且始终可用。

:::tip 打印机在另一个房间，或由所有收银设备共用？
请使用[云打印](../../receipts/cloud-printing.mdx)。云打印机会自动出现在所有设备上，无需在此添加。
:::

## 添加打印机 {#adding-a-printer}

1. 前往**设置 → 打印**，点击**添加打印机**。窗口显示**正在查找打印机…**，随即开始搜索，无需预先选择任何选项。
2. 找到您的打印机。搜索到的每台打印机都会显示为一张卡片；只有一台时，标题为**已找到您的打印机**，多台时则为 **哪台是您的打印机？** 在网页应用中，搜索仅涵盖 Wi-Fi：如果使用 USB 或蓝牙打印机，请点击**查找 USB 打印机**或**查找蓝牙打印机**（参阅[扫描未找到打印机时](#nothing-found)）。
3. 点击下方的**打印测试页**。如果搜索到了多台打印机，请先点击您的打印机：按钮会显示**在此打印机上打印测试页**及其名称。
4. 回答 **测试页打印出来了吗？** 选择**是的，效果正常**后，打印机会被保存。请参阅[打印测试页](#test-page)。

如果卡片中的打印机不是您的，请点击**不是这台？重新扫描**。**停止**会提前结束搜索，并保留已找到的打印机；**关闭**则退出，不添加任何打印机。如果没有找到打印机，请参阅[扫描未找到打印机时](#nothing-found)。

自动搜索会根据所用应用检查以下连接方式：

- **网页应用** — Wi-Fi。
- **桌面应用** — USB、蓝牙和 Wi-Fi。
- **Android** — Wi-Fi；通过蓝牙和 USB 连接的 Epson 和 Star 打印机；通过低功耗蓝牙连接的其他品牌打印机；以及已在 Android 设置中配对的蓝牙打印机。
- **iPhone 和 iPad** — Wi-Fi；通过蓝牙连接的 Epson 和 Star 打印机；通过低功耗蓝牙连接的其他品牌打印机。iPhone 和 iPad 不支持 USB。

### 打印测试页 {#test-page}

测试页会在纸张上横向打印一把带数字的标尺，既能确认打印机工作正常，也能检查宽度是否正确。如果应用无法判断纸张宽度，卡片下方会显示**纸张宽度**开关，可选 **58 mm** 或 **80 mm**，并预先选中更可能适用的一项。打印前请确认该选项。

随后会询问 **测试页打印出来了吗？**

- **是的，效果正常** — 保存打印机，并显示诸如*收据打印机已设置完成*的消息。在**设置 → 打印**中，打印机名称、宽度和钱箱设置会显示在其所在行下方。
- **已打印，但标尺不准确** — 应用会询问 **打印机使用哪种纸张？** 选择符合实际情况的一项，例如 **48 — 80 mm，大多数 Epson 和 Star**，即可重新打印测试页。请参阅[正确设置收据宽度](./receipt-width.mdx)。
- **没有打印出来** — 窗口显示**未打印任何内容**，并说明最可能的原因。解决所述问题后，点击**重试**。

<details>
<summary>未打印任何内容时的其他选项</summary>

- **跳过测试并保存** — 不打印测试页，直接保存打印机。
- **打开蓝牙设置** — 仅在 Android 上蓝牙打印机尚未配对时显示。先在那里配对，然后重新扫描。
- **重新开始**、**复制设置报告**和**打开打印机指南** — 重新开始设置，或收集技术支持所需的信息。

</details>

只有选择**是的，效果正常**或点击**跳过测试并保存**后，打印机才会被保存。因此，中途关闭窗口不会在列表中留下设置未完成的打印机。

### 扫描未找到打印机时 {#nothing-found}

窗口显示**未找到打印机**。下方的按钮提供了所有后续操作。

<JourneyShot manifest={manifest} device="phone" step={1} offsets={[[-20, 0], [-14, -16], [-2, -18], [-14, -16], [-2, -18], [149, 0]]} maxWidth={390} alt="添加打印机窗口显示未找到打印机，并提供重新扫描、查找 USB 打印机、查找蓝牙打印机、输入 IP 地址、更多选项和打开打印机指南按钮">

1. **重新扫描** — 检查打印机是否已开机并装有纸张，然后再次搜索。
2. **查找 USB 打印机** — 打开浏览器自带的 USB 设备选择器。仅在可访问 USB 设备的浏览器（Chrome 和 Edge）中显示。
3. **查找蓝牙打印机** — 打开浏览器或电脑的蓝牙设备选择器。移动应用的扫描已涵盖蓝牙，因此不显示此按钮。在桌面应用中，列表会在当前窗口中展开，名称看似打印机的设备会排在前面，并标注*可能是打印机*。
4. **输入 IP 地址** — 检查指定地址，而不执行扫描。已知打印机地址但扫描找不到时可使用此功能，这种情况在企业网络中很常见。请参阅[输入 IP 地址](#enter-an-ip-address)。
5. **更多选项** — 在测试打印前设置打印机名称和选项。请参阅[测试打印前设置选项](#more-options)。
6. **打开打印机指南** — 打开本页。

</JourneyShot>

### 输入 IP 地址 {#enter-an-ip-address}

<JourneyShot manifest={manifest} device="phone" step={3} offsets={[[0, 0], [58, 0], [-14, -16], [-14, -16], [149, 0]]} maxWidth={390} alt="输入打印机的 IP 地址：IP 地址和端口字段、检查此地址和取消按钮，下方还有重新扫描和打开打印机指南">

1. **IP 地址** — 可在打印机的状态页上找到。打印状态页的方法请参阅[为打印机设置固定地址](./network-address.mdx)。
2. **端口** — 已自动填写：图中为 8043，这是网页应用在 HTTPS 店铺中连接 Epson 时使用的端口（HTTP 使用 8008）。桌面和移动应用会填入 9100。除非打印机使用其他端口，否则请保留原值。请参阅[HTTPS 或 HTTP](./browser-permissions.mdx#https-or-http)。
3. **检查此地址** — 在该地址查找打印机。如果打印机有响应，会显示一张卡片：点击其下方的**打印测试页**。如果没有响应，表单下方会显示原因。
4. **重新扫描** — 返回扫描。
5. **打开打印机指南** — 打开本页。

</JourneyShot>

**更多选项**会在按钮下方展开一张卡片。可以保留原设置：卡片中的所有选项都能稍后在[编辑打印机](#printer-options)中修改。

<summary>可选：更多选项卡片的各字段说明</summary>

2. **厂商** — 网页应用中可选 **Epson** 或 **Star Micronics**，这是浏览器能连接的两个品牌。

</details>

## 您的打印机 {#printers-list}

添加打印机后，**设置 → 打印**会在**打印机**下列出它，说明文字为*可接收收据的设备。* 每行显示打印机名称、地址和品牌（例如 *192.168.1.128:8008 · Epson*）。未另行指定目标时接收收据的打印机带有**默认**标签。**打印对话框**始终在列表中，显示为*打印对话框 · 内置*；云打印机则显示其服务提供商，例如 *PrintNode · 由 WCPOS 管理*。

每行有三个操作：**测试打印**、**编辑**和**更多操作**（**⋯**）。**编辑**会打开打印机设置；请参阅[修改打印机设置](#printer-options)。打印对话框和云打印机没有**编辑**选项：云打印机需在[云打印](../../receipts/cloud-printing.mdx)中修改。

### 测试打印机 {#test-print}

点击打印机所在行的**测试打印**。确认纸张已打印出来时，消息会显示**已打印至**及打印机名称；只能确认任务已从收银设备发出时，则显示**已发送至**及打印机名称。如果失败，消息会说明原因。

### 将打印机设为默认 {#set-default}

打开打印机所在行的**更多操作**（**⋯**），点击**设为默认**。当前默认打印机、打印对话框和云打印机不显示此选项。

### 删除打印机 {#delete-printer}

打开打印机所在行的**更多操作**（**⋯**），点击**删除**，然后确认 **删除收据打印机？** （其中会显示实际名称）。此操作只会从当前设备移除打印机。原先路由到它的模板会*改用自动选择方式打印*（请参阅[打印路由](#print-routing)）。

### 向技术支持发送设置报告 {#setup-report}

打开打印机所在行的**更多操作**（**⋯**），点击**复制设置报告**。报告会收集应用版本、打印机设置和最新的打印日志。在网页和桌面应用中，报告会被复制，可直接粘贴到求助消息中；在移动应用中，则会打开分享面板，方便发送。

## 修改打印机设置 {#printer-options}

点击打印机所在行的**编辑**，右侧会展开**编辑打印机**面板。这里没有保存按钮：只要表单填写完整，每项更改都会立即保存，点击**关闭**也会保存尚未保存的内容。

1. **打印机名称** — 在列表和收据页面上显示的名称。
2. **连接方式** — **网络**、**蓝牙**或 **USB**。更改后会清空地址。
3. **厂商** — 网页应用中可选 **Epson** 或 **Star Micronics**。

6. **打印机语言** — 随**厂商**自动设置，通常无需更改。可选项请查看下方的*连接方式、厂商和打印机语言*。
7. **纸张宽度** — 每行的字符数，由测试页确定。请参阅[正确设置收据宽度](./receipt-width.mdx)。
8. **收据语言** — **自动**适用于大多数店铺。只有其他文字系统的收据打印不正常时才需更改；请参阅[非拉丁文字收据](./non-latin-receipts.mdx)。
9. **自动切纸** — 每张收据打印后切纸。

</JourneyShot>

2. **钱箱连接器** — 打印机钱箱接口中发送脉冲的引脚：**引脚 2 / 钱箱 1**（通常使用此项）或**引脚 5 / 钱箱 2**。如果钱箱无法打开，请尝试另一项。

5. **测试打印** — 使用当前设置打印测试页。如果像图中一样开启了**自动打开钱箱**，也会打开钱箱。
6. **关闭** — 保存并关闭。

<details>
<summary>连接方式、厂商和打印机语言</summary>

这些设置位于**打印机名称**和各开关之间。成功打印测试页后，通常无需再调整。

| 字段 | 作用 |
|---|---|
| **连接方式** | **网络**、**蓝牙**或 **USB**，具体取决于设备支持的方式（iPhone 和 iPad 不支持 USB；仅有一种方式时隐藏此项）。更改后会清空地址，需要重新连接打印机。 |
| **厂商** | **Epson** 或 **Star Micronics**。桌面应用还提供适用于其他品牌的**通用**选项；移动应用则为 Wi-Fi 和普通蓝牙打印机提供此选项。 |
| **IP 地址**和**端口** | 用于网络连接。**扫描网络**会重新搜索，并将每台打印机显示为*已发现：…*；点击**使用此打印机**可填入其地址。应用连接到打印机后，会显示*已检测到：Epson*或*已检测到：Star*。并非所有打印机都会响应扫描，因此也可以随时手动输入地址。 |
| **连接蓝牙打印机** / **连接 USB 打印机** | 在浏览器中使用蓝牙或 USB 时，会打开浏览器的设备选择器。桌面应用则列出操作系统中已安装（Windows）或已配对（Mac）的打印机。 |
| **打印机语言** | **ESC/POS**、**StarPRNT** 或 **Star Line Mode**，即打印机支持的指令集。 |
| **收据语言** | ESC/POS 打印机使用的字符集。**自动**适用于大多数店铺；请参阅[非拉丁文字收据](./non-latin-receipts.mdx)。 |
| **将收据作为图像打印** | 最后一个开关。适用于打印机无法呈现的文字，例如阿拉伯文、希伯来文或泰文。与文本打印相比，速度更慢、数据量更大。 |

</details>

如果开关上方出现 *钱箱开启脉冲取决于打印机语言或仿真模式。* 警告，说明**厂商**与**打印机语言**不匹配：例如将 Star 打印机设为 ESC/POS，或将其他品牌设为 Star 语言。此时钱箱可能无法打开。请将**打印机语言**设为打印机实际使用的模式。

**测试打印**失败时，窗口会以红色显示原因，旁边是 **遇到问题？**，下方是**支持详情**：

<JourneyShot manifest={manifest} device="tablet" step={18} offsets={[[-36, -4], [0, 36], [130, 0], [110, 0]]} maxWidth={559} alt="测试打印失败后的编辑打印机面板：红色消息显示应用未获准访问打印机。请在系统设置中允许访问，然后重试，旁边为遇到问题？，下方为支持详情">

1. **原因** — 应用给出的错误说明。在浏览器中，*应用未获准访问打印机*表示浏览器完全无法连接到打印机：请检查打印机是否已开机、地址是否正确，然后参阅[从浏览器打印](./browser-permissions.mdx)。
2. **遇到问题？** — 打开此打印机指南。
3. **支持详情** — 应用尝试过的操作。在网页和桌面应用中，**复制支持详情**可复制这些信息，以便发送给技术支持。
4. **测试打印** — 解决消息中指出的问题后重试。

</JourneyShot>

## 各应用支持的连接方式 {#supported-printers-by-platform}

桌面和移动应用可连接支持 ESC/POS（大多数厂商使用的语言）或 Star 自有语言的 Wi-Fi 收据打印机。[支持的收据打印机](./supported-printers.mdx)列出了经过测试的型号。网页应用只能添加 Epson 和 Star 打印机。其他品牌请使用桌面或移动应用，或使用[云打印机](../../receipts/cloud-printing.mdx)。

<details>
<summary>各应用的 Wi-Fi、USB 和蓝牙连接支持</summary>

浏览器无法像应用一样与打印机建立直接连接。通过 Wi-Fi 连接时，网页应用使用打印机内置的网页服务器访问 Epson 和 Star 打印机，而非直接使用原始端口 9100。

| | 通过 Wi-Fi | 通过 USB 和蓝牙 |
|---|---|---|
| **网页应用** | 通过打印机自带的网页端口连接 Epson 和 Star。在 HTTPS 店铺中，Chrome 首次连接时会请求访问本地网络的权限。 | 通过浏览器自带的设备选择器，以 USB 或低功耗蓝牙连接 Epson 和 Star。仅限 Chrome 和 Edge。 |
| **桌面应用** | 支持 ESC/POS、StarPRNT 或 Star Line Mode 的 Wi-Fi 收据打印机。应用会扫描网络来查找它们。 | USB、低功耗蓝牙，以及操作系统中已安装（Windows）或已配对（Mac）的打印机。 |
| **iPhone 和 iPad** | 支持 ESC/POS、StarPRNT 或 Star Line Mode 的 Wi-Fi 收据打印机。 | Epson 和 Star 通过厂商自有软件连接；其他品牌通过低功耗蓝牙连接。不支持 USB。 |
| **Android** | 支持 ESC/POS、StarPRNT 或 Star Line Mode 的 Wi-Fi 收据打印机。 | Epson 和 Star 通过厂商自有软件连接；其他品牌通过低功耗蓝牙连接，或[在设置中配对](./bluetooth-pairing.mdx#android-pair-first)后通过经典蓝牙连接。 |

</details>

## 打印路由 {#print-routing}

使用多个模板打印时，例如热敏收据和 A4 发票，路由会决定每个模板发送到哪台打印机。应用按以下顺序检查三个层级的设置：

1. **在收据页面上。** **模板**下方有**打印机**选项，默认设为**自动**，并显示自动选中的目标，例如*自动 — 打印对话框*。在此选择打印机后，本张收据及其补打件都会发送到该打印机，直到切换模板或离开页面。切换模板后，此选项会重置为**自动**。
2. **在设置中。** 打印机列表下方的**收据模板**、**报表模板**和**结班模板**分别列出已启用的模板，说明文字为*选择每个模板使用的打印机。* 可以为模板指定打印机，或恢复为**自动**。云打印机也会出现在各列表中。
3. **自动。** 未指定打印机时，应用会将每个模板发送到适合它的打印机；如果有多台符合条件，则使用默认打印机。

路由设置与打印机配置一样，保存在当前设备上。

<details>
<summary>自动模式如何选择打印机</summary>

模板有两种。[热敏模板](../../receipts/thermal-templates.mdx)针对收据打印机排版，每行字符数固定。[HTML 模板](../../receipts/html-templates.mdx)则像网页一样排版，例如 A4 发票。

- 热敏模板会发送到纸张宽度匹配的收据打印机：58 mm 模板发送到设为 32 个字符的打印机，80 mm 模板发送到设为 42 或 48 个字符的打印机。
- HTML 模板会发送到**打印对话框**。
- 如果有多台打印机符合条件，则优先使用默认打印机。

如果为模板选择的打印机不适合该模板，收据页面会出现琥珀色警告，但仍会打印：热敏模板发送到**打印对话框**时，会打印屏幕上的预览；HTML 模板发送到收据打印机时，会使用内置的收据布局。唯一的例外是仅支持热敏模板的云打印机：它不会打印 HTML 模板，警告中也会说明这一点。

</details>

:::note 自动打印每张收据
销售完成后打印收据属于购物车设置，而非打印机设置。打开购物车顶部的设置，开启**结账后自动打印收据**。随后由路由决定使用哪台打印机。
:::

## 出现问题时 {#when-nothing-prints}

**扫描未找到打印机。** 检查打印机是否已开机并装有纸张。使用 Wi-Fi 时，为打印机设置固定地址并选择**输入 IP 地址**：请参阅[为打印机设置固定地址](./network-address.mdx)。在浏览器中，请允许访问本地网络：参阅[浏览器](./browser-permissions.mdx)。

**测试打印提示失败。** 阅读消息或窗口中的说明。然后点击打印机所在行的**复制设置报告**，或**编辑打印机**中的**支持详情**，将相关内容随求助请求一起发送。这些信息会说明应用尝试过哪些操作。

**钱箱无法打开。** 在**编辑打印机**中点击**打开钱箱**。如果没有反应，将**钱箱连接器**切换到另一个引脚。如果仍无法打开，请检查开关上方是否有打印机语言警告，然后参阅[连接钱箱](./cash-drawer.mdx)。

**收据能打印，但与屏幕显示不同。** 检查收据页面上的琥珀色警告，并选择适合该模板的打印机。

选择与问题相符的指南：

**设置**

- [正确设置收据宽度](./receipt-width.mdx) — 标尺超出纸张或未铺满纸张
- [为打印机设置固定地址](./network-address.mdx) — Wi-Fi 扫描未找到打印机，或打印机停止工作
- [配对蓝牙收据打印机](./bluetooth-pairing.mdx) — 打印机未出现在设备选择器中
- [在 Windows 上使用 USB](./usb-windows.mdx)和[在 Linux 上使用 USB](./usb-linux.mdx)
- [支持的收据打印机](./supported-printers.mdx)

**Epson 未打印任何内容**

- [Epson 安全打印](./secure-printing.mdx) — 新 Epson 打印机似乎已接收任务，却未打印任何内容
- [Server Direct Print](./server-direct-print.mdx) — 打印机网页可正常访问，但无法打印任务
- [打印一次后便停止](./printed-once-then-stopped.mdx) — 先关闭电源再重新开机
