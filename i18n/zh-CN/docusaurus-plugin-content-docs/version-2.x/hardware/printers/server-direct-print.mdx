Epson 已开机，自身网页可以打开，自检页也能打印，但 POS 发送的内容完全无法打印。关闭再开启也没有效果。请检查打印机中名为 **服务器直接打印** 的设置是否已启用。

:::note 先检查 WCPOS 是否正在使用此功能
在 **设置 → 打印** 中，这台打印机所在行是否显示 **Epson 服务器直接打印 · 由 WCPOS 管理**？如果是，请保持服务器直接打印开启：WCPOS **云打印** 就是通过这种方式向打印机发送收据的。请勿通过 **添加打印机** 再次添加同一台打印机。参阅[云打印](../../receipts/cloud-printing.mdx#setup-polling)。
:::

如果您首次添加这台打印机，或其所在行未显示上述文字，请[在打印机网页上检查该设置](#turn-it-off)。

## POS 中的提示 {#what-you-see}

在 **设置 → 打印 → 添加打印机** 中添加打印机时，其卡片显示 **未连接**，且无法选中。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[302, 0], [0, 0], [136, -20], [161, 0]]} maxWidth={559} alt="检查地址后的“添加打印机”面板：右上角是“重新扫描”，下方打印机卡片显示地址、Epson 和“未连接”标记，再下方是“输入 IP 地址”和“打开打印机指南”">

1. **打印机卡片** — 显示地址和厂商。**未连接** 表示应用未找到可用的打印方式，因此无法选中该卡片。
2. **重新扫描** — 再次搜索网络。关闭服务器直接打印后，请使用此操作。
3. **输入 IP 地址** — 直接检查某个地址。参阅[手动输入地址](./setup-wizard.mdx#enter-address)。
4. **打开打印机指南** — 打开这些打印机帮助页面。

</JourneyShot>

您还可能遇到以下情况：

- 打印测试页后显示 **未打印任何内容**，并提示“打印机正在暂存任务。请关闭再开启打印机，然后重试。”如果重启后仍显示此提示，请检查是否启用了服务器直接打印。如果已关闭，请参阅 [Epson 安全打印](./secure-printing.mdx)，这是另一项会阻止 POS 任务打印的 Epson 设置。
- 之前保存的打印机执行 **测试打印** 失败，所有收据也都无法打印。

## 原因 {#why-it-happens}

启用 **服务器直接打印** 时，打印机会从服务器获取任务。只要此功能处于开启状态，它就会拒绝通过本地网络直接发送给它的任务，而 POS 正是通过这种方式向使用 **添加打印机** 添加的网络打印机发送任务的。打印机的网页仍然正常，因此看起来没有问题。这项设置会保存下来，重启不会清除它。

如果您没有开启过此功能，可能是之前的配置、厨房或在线订单服务，或另一台收银机开启了它。

## 关闭服务器直接打印 {#turn-it-off}

:::warning 其他系统可能需要此功能
如果厨房显示系统或在线订单服务通过服务器直接打印向这台 Epson 打印，关闭此功能会导致该服务无法打印。两者只能有一个使用这台打印机：请为 POS 配备独立打印机，或将该服务改为使用另一台打印机。
:::

请使用与打印机在同一网络中的电脑或平板电脑，在打印机自身的网页上操作。

1. 打开 `https://` 加上打印机地址组成的网址，例如 `https://192.168.1.100`，接受证书警告并继续访问。地址可以在打印机状态页上找到。参阅[查找打印机地址](./network-address.mdx)。
2. 点击 **管理员登录**。新款型号默认以打印机的 **序列号** 作为密码，序列号位于打印机底部的标签上，除非有人修改过密码。
3. 在菜单中找到 **服务器直接打印**。其位置因型号和固件而异：TM-i 型号位于 **Web 服务设置 → 直接打印** 下；固件 3.x 及更早版本则位于 **配置 → 直接打印** 下。其他型号请在菜单中查找，或查阅相应型号的手册。
4. 如果已经显示 **禁用**，请保持关闭，转而按照 [Epson 安全打印](./secure-printing.mdx)中的说明操作。否则，将其设为 **禁用** 并保存，然后继续执行下方步骤。
5. 等待打印机重启，或将其关闭十秒后再开启。
6. 返回 POS，测试打印机：
   - **正在添加打印机：** 点击 **重新扫描** 或 **输入 IP 地址**。卡片显示 **就绪** 后，选中它并点击 **打印测试页**。
   - **打印机已保存：** 在 **设置 → 打印** 中点击该打印机所在行的 **测试打印**。

## 仍未解决？ {#still-stuck}

点击 **复制设置报告**，将报告粘贴到您的消息中。在 **未打印任何内容** 界面生成的报告会列出应用尝试连接的打印机端口，以及收到的所有拒绝响应。对于已保存的打印机，请在 **设置 → 打印** 中打开其所在行的 **更多操作** 菜单找到此选项。
