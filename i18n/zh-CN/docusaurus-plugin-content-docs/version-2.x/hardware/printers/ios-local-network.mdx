**现象：** 在 iPad 或 iPhone 上，**添加打印机**最终显示**未找到打印机**，或原本能打印的 Wi-Fi 打印机停止打印。同一 Wi-Fi 网络中的电脑仍能使用这台打印机打印。

首先，检查 WCPOS 是否有权使用本地网络。

<details>
<summary>为什么拒绝权限后的现象与打印机关机相同</summary>

WCPOS 首次查找打印机时，iOS 会询问是否允许它查找并连接本地网络中的设备。问题下方的说明为：*WCPOS 使用本地网络连接读卡器和收据打印机。*

如果有人点过**不允许**，此后 iOS 就会阻止 WCPOS 访问所有 Wi-Fi 打印机，包括扫描、地址检查和每一张收据的打印。iOS 不会告知应用权限已被拒绝，因此 WCPOS 显示的界面与打印机关机时相同：

- 扫描后显示**未找到打印机**，并提示*请检查打印机是否已开机并连接到同一 Wi-Fi，或已在蓝牙设置中配对。*
- 点击**检查此地址**后，打印机卡片上显示**未连接**。
- 此前保存的打印机**测试打印**失败。

蓝牙打印机不使用此权限。如果找不到蓝牙打印机，请参阅[配对蓝牙收据打印机](./bluetooth-pairing.mdx)。

</details>

## 开启权限 {#turn-the-permission-on}

1. 打开 iPad 或 iPhone 的**设置**应用。
2. 前往**隐私与安全性 → 本地网络**。
3. 打开 **WCPOS** 旁边的开关。
4. 完全关闭 WCPOS：在应用切换器中向上轻扫，将其移出屏幕。然后重新打开。

**设置**应用中 WCPOS 自己的页面上也有同一个开关：向下滚动到 **WCPOS**，开启**本地网络**。

<details>
<summary>列表中没有 WCPOS？</summary>

只有在 WCPOS 查找过一次打印机后，iOS 才会将它加入列表。在 WCPOS 中打开 **设置 → 打印**，然后点击 **添加打印机**。如果 iOS 询问是否允许查找本地网络中的设备，请点击 **允许**。如果扫描结束后仍显示 **未找到打印机**，请点击 **重新扫描**。WCPOS 请求过权限后，就会出现在列表中。

</details>

## 检查 Wi-Fi {#also-check}

- 确保 iPad 连接的是**店铺的 Wi-Fi**，与打印机处于同一网络，而不是访客网络或移动数据网络。请参阅[为打印机设置固定地址](./network-address.mdx)。
- 确保 Wi-Fi 已开启。关闭 Wi-Fi 后，无论权限如何设置，都无法连接 Wi-Fi 打印机。

## 确认问题已解决 {#check-it-worked}

在 WCPOS 中打开**设置 → 打印**：

- **已保存打印机：** 点击其旁边的**测试打印**。
- **尚未保存打印机：** 点击**添加打印机**。打印机出现后，点击其卡片下方的**打印测试页**，并回答打印结果。如果扫描没有找到打印机，请参阅[扫描仍无结果时](#if-the-scan-finds-nothing)。

## 扫描仍无结果时 {#if-the-scan-finds-nothing}

在 iPad 或 iPhone 上，扫描会通过 Wi-Fi、蓝牙和 USB 查找 **Epson 和 Star** 打印机。其他品牌的 Wi-Fi 打印机不会显示，某些网络也会阻止搜索。此时请改用地址检查打印机：

1. 打印打印机的状态页，查看上面的 IP 地址。[为打印机设置固定地址](./network-address.mdx)介绍了具体方法。
2. 在扫描界面点击**输入 IP 地址**。扫描将停止，并打开地址表单。
3. 输入地址，点击**检查此地址**。
4. 如果打印机卡片显示**就绪**或**需要测试**，请点击**打印测试页**，并回答打印结果。如果显示**未连接**，说明 iPad 无法访问该地址：检查 [Wi-Fi](#also-check)，并重新打印状态页核对地址。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[110, -38], [40, -38], [-38, 0], [0, 40], [165, 0]]} alt="添加打印机面板中的输入打印机 IP 地址界面：IP 地址和端口字段、检查此地址、取消、状态页提示、重新扫描和打开打印机指南">

1. **IP 地址** — 打印机状态页上的地址。
2. **端口** — 初始值为 **9100**。检查会找出打印机响应的端口，因此通常无需修改。
3. **检查此地址** — 查询打印机类型。随后卡片会显示**就绪**或**需要测试**，下方显示**打印测试页**；如果没有响应，则显示**未连接**。
4. **重新扫描** — 返回扫描界面。
5. **打开打印机指南** — 打开[收据打印机](./index.mdx)。

</JourneyShot>

## 仍有问题？ {#still-stuck}

请将设置报告发给我们。**复制设置报告**位于设置面板的**未打印任何内容**界面，以及**设置 → 打印**中打印机所在行的**更多操作**菜单内。在 iPad 或 iPhone 上，点击后会打开共享面板：可通过电子邮件发送，也可复制到消息中。

报告包含应用版本、iOS 版本、打印机设置和应用最近的打印机日志。从设置面板生成的报告还包含检查结果。
