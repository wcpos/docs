**现象：** 收据在屏幕上显示正常，但打印到纸上却出现问号、空方框或错误字母。

本页介绍收据打印机。**打印对话框**和办公打印机使用电脑上的字体，因此各种语言都能按屏幕上的样式打印。

## 选择解决方法 {#choose-a-fix}

首先查看打印机提供哪些选项：前往**设置 → 打印**，点击打印机所在行的**编辑**。

<details>
<summary>没有编辑按钮？打印机标记为由 WCPOS 管理</summary>

标记为**由 WCPOS 管理**的打印机是云打印机。它没有**编辑**按钮，因为它由店铺管理人员在 **WP Admin → 销售点 → 设置 → 云打印**中配置，而不是在应用中设置。云打印机的打印方式请参阅[云打印](../../receipts/cloud-printing.mdx)。

</details>

**速度快，以文本方式打印：[设置收据语言](#receipt-language)**。适用于**编辑打印机**中显示**收据语言**，且收据使用西里尔字母、希腊语、土耳其语、越南语，或带重音符号的西欧或中欧字母的情况。

**速度较慢，适用于所有语言：[将收据作为图片打印](#print-the-receipt-as-an-image)**。适用于以下情况：

- **编辑打印机**中没有**收据语言**。
- 收据使用中文、日语或韩语。
- 收据使用阿拉伯语、希伯来语或泰语。这些语言有对应的收据语言选项，但以图片方式打印效果最佳。只有在打印速度很重要时，才建议先尝试设置收据语言。
- 一张收据混用两种字母系统，例如希腊语和俄语。
- 已设置收据语言，但字母仍然不正确。

<details>
<summary>为什么有些打印机没有收据语言选项</summary>

只有当**打印机语言**为 **ESC/POS** 时，才会显示**收据语言**。ESC/POS 是 Epson 和大多数其他收据打印机使用的指令语言（请参阅[支持的打印机](supported-printers.mdx)）。设为 **StarPRNT** 或 **Star Line Mode** 的 Star 打印机没有此选项：打印非拉丁文字时，请开启[将收据作为图片打印](#print-the-receipt-as-an-image)。

</details>

## 设置收据语言 {#receipt-language}

选择收据所用的语言。收据仍以文本方式打印，因此速度依然很快。

**对于已添加的打印机：**

1. 前往**设置 → 打印**，点击打印机所在行的**编辑**。
2. 打开**收据语言**，选择与收据语言对应的选项。**编辑打印机**会即时保存每项更改。
3. 点击**编辑打印机**底部的**测试打印**。如果字母仍然不正确，打印机可能未内置该语言：请改为[作为图片打印](#print-the-receipt-as-an-image)。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} alt="Epson 网络打印机的编辑打印机界面：打印机语言为 ESC/POS，纸张宽度为 48 — 80 mm，适用于大多数 Epson 和 Star 打印机，收据语言为自动，包含自动切纸、自动打开钱箱和设为默认开关，以及将收据作为图片打印及其说明">

1. **打印机语言** — 此处为 **ESC/POS**。只有 ESC/POS 才会显示**收据语言**。
2. **纸张宽度** — 每行的字符数。请参阅[收据宽度](receipt-width.mdx)。
3. **收据语言** — 打开后选择与收据语言对应的选项。每台打印机的初始设置都是**自动**。
4. **将收据作为图片打印** — 另一种解决方法，适用于所有语言。请参阅[将收据作为图片打印](#print-the-receipt-as-an-image)。

</JourneyShot>

**添加打印机时：** 在**添加打印机**面板中点击**更多选项**。**收据语言**是第四项设置，位于**打印机文本宽度**下方（此设置在**编辑打印机**中称为**纸张宽度**）。

列表中有十一个选项。没有中文、日语和韩语选项：[请将这些语言的收据作为图片打印](#print-the-receipt-as-an-image)。有些选项以地区或字母系统命名，而不是语言：俄语、乌克兰语和保加利亚语归在**西里尔字母**下，波兰语、捷克语和匈牙利语归在**中欧**下。

## 将收据作为图片打印 {#print-the-receipt-as-an-image}

此方法适用于所有语言，以及您在应用中添加的任何收据打印机。应用会将收据绘制成图片并发送，因此不再依赖打印机的字符表。

:::warning
对于通过 Wi-Fi 或网线连接的 Epson 打印机，以图片方式打印需要关闭[安全打印](secure-printing.mdx)。
:::

1. 前往**设置 → 打印**。
2. 点击打印机所在行的**编辑**。
3. 开启**编辑打印机**中的最后一个开关：**将收据作为图片打印**。其说明为：*适用于打印机无法呈现的文字（阿拉伯语、希伯来语、泰语）。比文本打印更慢，数据量更大。*
4. 点击**编辑打印机**底部的**测试打印**进行检查。**设置 → 打印**中打印机所在行也有**测试打印**。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} maxWidth={799} alt="编辑打印机中的设置，最后一个开关为将收据作为图片打印，当前关闭，说明为：适用于打印机无法呈现的文字（阿拉伯语、希伯来语、泰语）。比文本打印更慢，数据量更大。">

1. **打印机语言** — 此处为 **ESC/POS**。图片方式也适用于没有**收据语言**选项的 Star 打印机。
2. **纸张宽度** — 每行的字符数。请参阅[收据宽度](receipt-width.mdx)。
3. **收据语言** — 图片不使用打印机的字符表，因此此设置不再影响打印。
4. **将收据作为图片打印** — 此处开关处于关闭状态。开启后点击**测试打印**进行检查。

</JourneyShot>

此开关仅位于**编辑打印机**中，**更多选项**中没有：请先添加打印机，再开启它。

:::tip
图片的传输数据量远大于文本，因此每张收据的打印耗时更长。请只为需要此功能的打印机开启。
:::

## 原因说明 {#why-it-happens}

收据打印机不使用电脑上的字体。当它无法以文本方式打印所用文字时，就会打印出问号或方框；使用图片可避免此问题。

<details>
<summary>收据打印机如何打印文本</summary>

打印机使用内置字符表打印文本，一次使用一张表。对于每一行，应用会选择包含该行字母的字符表。这适用于英语和大多数欧洲语言的收据。对于其他文字，打印机可能没有可供应用选择的字符表，无法打印的每个字符都会变成问号或方框。**收据语言**会为整张收据指定同一个字符表；使用图片则完全绕过字符表。

</details>

## 仍有问题？ {#still-stuck}

在**设置 → 打印**中，打开打印机所在行的 **⋯** 菜单，点击**复制设置报告**。在 Android 和 iOS 应用中，这会打开共享面板。请将报告粘贴到消息中，附上打印收据的照片，并说明使用的语言。
