要在 Windows 桌面版应用中使用 USB 收据打印机，请先在 Windows 中安装：只有 Windows 已安装该打印机，应用才能找到它。然后在收银台中添加：

1. [在 Windows 中安装打印机](#do-this)。
2. [在 POS 中添加打印机](#add-in-pos)。

如果您在 Windows 桌面版应用中遇到以下情况，本页也适用：

- 打印机已连接并开机，但**添加打印机**显示**未找到打印机**。请参阅[未找到打印机](#no-printer-found)。
- 在早期版本中添加的打印机提示**在 Windows 上，请将此打印机添加为已安装的打印机。** 请参阅[早期版本中添加的打印机](#earlier-version)。
- 测试页出现[杂乱的字母和符号](#stray-symbols)，或[没有打印出来](#nothing-came-out)。

## 在 Windows 中安装打印机 {#do-this}

首先，检查 Windows 是否已安装该打印机：

1. 连接打印机并开机。如果厂商提供 Windows 驱动或安装程序，请立即运行。
2. 在 Windows 中，打开**设置 → 蓝牙和其他设备 → 打印机和扫描仪**。
3. 如果列表中已有您的打印机，请继续[在 POS 中添加打印机](#add-in-pos)。如果没有，请在**添加打印机或扫描仪**旁选择**添加设备**。如果 Windows 找到并添加了打印机，也请继续[在 POS 中添加打印机](#add-in-pos)。

如果 Windows 仍未列出打印机，请使用 Windows 自带的基本驱动 **Generic / Text Only** 手动添加。

<details>
<summary>手动添加打印机</summary>

1. 选择**手动添加**，然后选择**通过手动设置添加本地打印机或网络打印机**。
2. 在**使用现有的端口**下，选择打印机的 USB 端口：名称以 **USB** 开头，例如 USB001。
3. 选择驱动时，厂商选择 **Generic**，打印机选择 **Generic / Text Only**。
4. 为其起一个在收银时容易识别的名称，例如*收据打印机*，然后完成安装。

</details>

<details>
<summary>在 Windows 10 上</summary>

从**设置 → 设备 → 打印机和扫描仪**进入，选择**添加打印机或扫描仪**。Windows 11 中的**手动添加**在 Windows 10 中显示为**我需要的打印机不在列表中**。

</details>

## 在 POS 中添加打印机 {#add-in-pos}

1. 在桌面版应用中，进入**设置 → 打印**并点击**添加打印机**。应用会自动开始搜索 **USB、蓝牙和 Wi-Fi** 打印机。
2. 选择名称与您在 Windows 中设置的打印机名称相同的卡片。卡片带有**已安装的打印机**标记。如果有多台打印机，面板会询问**哪台是您的打印机？** 并且不会自动选择。
3. 点击**打印测试页**。面板会询问**测试页打印出来了吗？**
4. 如果页面正常，请选择**是的，而且看起来正确**。打印机会被保存：面板显示*名称* **已设置完成**。点击**完成**，打印机便会在**设置 → 打印**中单独列出。

如果打印结果不正确或完全没有打印，请参阅[遇到问题时](#goes-wrong)。其他回答选项见[打印测试页](./setup-wizard.mdx#test-page)。

## 遇到问题时 {#goes-wrong}

### 未找到打印机 {#no-printer-found}

先检查 Windows 中的**打印机和扫描仪**。如果列表中没有您的打印机，请[在 Windows 中安装](#do-this)，然后点击**重新扫描**。如果已列出，但应用仍找不到，请参阅[仍有问题？](#still-stuck)。

<details>
<summary>“未找到打印机”面板上的其他按钮</summary>

1. **重新扫描** — 再次搜索。在 Windows 中安装打印机后点击此按钮。
2. **查找蓝牙打印机** — 适用于无需配对的蓝牙打印机。
3. **输入 IP 地址** — 适用于搜索未找到的网络打印机。
4. **更多选项** — 在打印测试页之前设置名称、纸张宽度和钱箱。请参阅[更多选项](./setup-wizard.mdx#more-options)。
5. **打开打印机指南** — 打开[打印机指南](./index.mdx)。

</details>

### 早期版本中添加的打印机 {#earlier-version}

向打印机打印时提示**在 Windows 上，请将此打印机添加为已安装的打印机。** 早期版本将其保存为直连 USB 打印机，而现在 Windows 上的应用只能通过 Windows 中的打印机条目访问 USB 打印机。在**设置 → 打印**中，打开打印机的**更多操作**菜单，选择**删除**，然后通过**添加打印机**重新添加，并选择其**已安装的打印机**卡片。

### 杂乱的字母和符号 {#stray-symbols}

#### 添加打印机时 {#symbols-during-setup}

1. 即使已经出纸，也请选择**没有打印出来**。面板没有针对符号乱码的回答选项，选择此项会显示**重新开始**和**不测试直接保存**。
2. 检查所选卡片上的名称：
   - 是其他打印机，例如办公打印机？它无法识别收据命令。请点击**重新开始**，选择您的收据打印机条目。
   - 是您的收据打印机？请点击**不测试直接保存**，然后[修正打印机语言](#symbols-saved)。

#### 已保存的打印机 {#symbols-saved}

1. 检查**设置 → 打印**中该打印机所在行的名称。如果是其他打印机，请点击**添加打印机**，选择您的收据打印机条目。
2. 如果是您的收据打印机，可能是**打印机语言**设置与打印机不匹配。点击该行的**编辑**。
3. 将**打印机语言**设为打印机手册指定的语言。Star 打印机使用 **StarPRNT** 或 **Star Line Mode**；Epson 打印机和大多数其他品牌一样，使用 **ESC/POS**。
4. 点击该行的**测试打印**。如果 Star 打印机仍打印出符号，请切换为另一种 Star 语言后再次测试。
5. 使用每种语言都打印出符号？请在[支持的收据打印机](./supported-printers.mdx)中查看您的型号，然后参阅[仍有问题？](#still-stuck)。

### 没有打印出来 {#nothing-came-out}

#### 添加打印机时 {#nothing-during-setup}

1. 选择**没有打印出来**。
2. 检查所选卡片上的名称。如果是其他打印机，请点击**重新开始**，选择您的收据打印机条目。
3. 如果是您的打印机，面板会提示**检查线缆并确认打印机已开机，然后重试。** 完成检查后，点击**重试**。

#### 已保存的打印机 {#nothing-saved}

1. 检查**设置 → 打印**中该打印机所在行的名称。如果是其他打印机，请点击**添加打印机**，选择您的收据打印机条目。
2. 如果是您的打印机，请检查线缆并确认打印机已开机，然后点击该行的**测试打印**。

#### 仍无任何输出 {#windows-test-page}

在 Windows 的**打印机和扫描仪**中，找到您的打印机条目，直接通过 Windows 打印测试页。如果 Windows 也无法打印，问题出在 Windows 与打印机之间：线缆、端口或驱动。如果 Windows 可以打印，而 POS 仍无法打印，请参阅[仍有问题？](#still-stuck)。

### 网页版应用中的“查找 USB 打印机”失败 {#web-app}

在网页版应用中，**查找 USB 打印机**在 Windows 上经常无法打开 USB 打印机。请改用桌面版应用：先[在 Windows 中安装打印机](#do-this)，再[在 POS 中添加打印机](#add-in-pos)。

## 应用在 Windows 上的打印方式 {#why-it-happens}

桌面版应用向您在 Windows 中安装的打印机打印，因此请选择该打印机。要了解您的型号是否能识别收据命令，请参阅[支持的收据打印机](./supported-printers.mdx)。

<details>
<summary>为什么必须在 Windows 中安装打印机</summary>

Windows 会为 USB 打印机使用自带驱动或厂商提供的驱动，桌面版应用通过 Windows 中的打印机条目打印，而非直接通过线缆发送。应用将每张收据作为打印机命令发送，Windows 再原样传给打印机，因此驱动不会改变收据的排版。

</details>

<details>
<summary>搜索会列出哪些 Windows 打印机</summary>

Windows 中安装的所有打印机，但不包括 **Microsoft Print to PDF** 和**传真**等 Windows 自带条目。Windows 中安装的办公打印机也会列出，外观与其他条目相同，因此请按名称选择。在 Windows 中配对的蓝牙打印机也会以相同方式显示为已安装的打印机。

</details>

## 仍有问题？ {#still-stuck}

在**未打印任何内容**面板上，或在**设置 → 打印**中打印机的**更多操作**菜单中，点击**复制设置报告**。将报告粘贴到您的消息中：报告会列出应用实际向其打印的 Windows 打印机条目。
