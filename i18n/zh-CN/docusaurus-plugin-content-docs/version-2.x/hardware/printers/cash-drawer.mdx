钱箱不直接连接 POS，而是连接到**收据打印机**，由 POS 通知打印机打开钱箱。本页介绍如何连接钱箱、在应用中启用并测试它。

:::note 请先准备好收据打印机
先添加打印机，再连接钱箱。请参阅[打印机设置向导](./setup-wizard.mdx)。内置的**打印对话框**和云打印机无法打开钱箱。
:::

## 将钱箱连接到打印机 {#wire-it-up}

1. 找到打印机背面标有 **DK**、**钱箱**或**现金钱箱**的接口。
2. 插入钱箱连接线。它的插头形似电话线插头。旁边较宽的是网络接口，请勿插入该接口。
3. 关闭打印机，然后重新开机。

## 在应用中启用 {#switch-it-on-in-the-app}

每台打印机都有一个**自动打开钱箱**开关，新添加的打印机默认关闭此开关。可以在添加打印机时开启，也可以稍后通过打印机所在行开启。如果已添加打印机，请跳至[测试钱箱](#test-the-drawer)。

:::note 每次打印收据都会打开钱箱
开启**自动打开钱箱**后，该打印机每次打印收据都会打开钱箱，刷卡交易和补打收据也不例外。请参阅[钱箱何时打开](#when-it-opens)。
:::

### 添加打印机时设置 {#while-adding}

在**设置 → 打印**中，点击**添加打印机**。搜索结束后，点击**更多选项**。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[96, 0], [-24, 0], [-60, 0], [-60, 0]]} maxWidth={559} alt="添加打印机面板中展开了更多选项：打印机名称、厂商、打印机文本宽度、收据语言，以及均已开启的自动切纸、自动打开钱箱和设为默认开关">

1. **更多选项** — 在搜索结果下方展开打印机设置。
2. **厂商** — **Epson** 或 **Star Micronics**。不同品牌使用的钱箱指令不同，请选择打印机的品牌。
3. **自动打开钱箱** — 打印机每次打印收据时都会打开钱箱。
4. **设为默认** — **无销售开箱**会打开默认打印机连接的钱箱。请参阅[无销售时打开钱箱](#no-sale)。

</JourneyShot>

按照[打印机设置向导](./setup-wizard.mdx)完成添加。向导中的测试页不会打开钱箱，因此接下来需要测试钱箱。

### 测试钱箱或修改已添加的打印机 {#test-the-drawer}

1. 在**设置 → 打印**中，点击打印机所在行的**编辑**。
2. 如果**自动打开钱箱**尚未开启，请将其开启。下方会出现**钱箱连接器**，用于选择钱箱连接的引脚。**引脚 2 / 钱箱 1** 适用于大多数钱箱。如果连接的是第二个钱箱，或钱箱说明书指定使用引脚 5，请选择**引脚 5 / 钱箱 2**。
3. 点击**编辑打印机**面板底部、**测试打印**旁的**打开钱箱**。此操作只打开一次钱箱，不会打印。检查钱箱是否弹开。如果没有打开，即使应用显示**钱箱已打开**，也请参阅[钱箱无法打开时](#when-it-doesnt-open)。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[685, 0], [685, 0], [47, -30], [36, -30]]} alt="设置 → 打印中打开了网络打印机的编辑打印机面板，并滚动到钱箱设置：自动打开钱箱已开启，钱箱连接器设为引脚 2 / 钱箱 1，底部显示设为默认选项，以及打开钱箱和测试打印按钮">

1. **自动打开钱箱** — 图中已开启。打印机每次打印收据都会打开钱箱。
2. **钱箱连接器** — 钱箱连接的引脚，图中为**引脚 2 / 钱箱 1**。仅在**自动打开钱箱**开启时显示。
3. **打开钱箱** — 打开一次钱箱，不打印。
4. **测试打印** — 在此打印机上打印测试页。如果像图中一样开启了**自动打开钱箱**，也会打开钱箱。

</JourneyShot>

## 钱箱何时打开 {#when-it-opens}

开启**自动打开钱箱**后，该打印机每次打印收据都会打开钱箱，包括：

- 结账时手动或自动打印收据；
- 稍后补打收据；
- 点击打印机所在行的**测试打印**。

无论使用哪种付款方式都会打开钱箱，并不限于现金付款。

打印收银机报表时不会打开钱箱，包括 X 报表、交接报表和结班报表。请参阅[开启收银机](../../pos/register/index.mdx)。

## 无销售时打开钱箱 {#no-sale}

需要兑换零钱或检查备用金时，可使用收银机面板中的**无销售开箱**。此操作会打开钱箱并记录原因，不涉及资金变动。

{/* pending: monorepo#3360 */}
:::note 开始前
- 确保收银机已开启。请参阅[开启收银机](../../pos/register/index.mdx)。
- 确保默认收据打印机已开启**自动打开钱箱**。**无销售开箱**会打开该打印机连接的钱箱。要将打印机设为默认，请在**设置 → 打印**中打开其**更多操作**菜单，然后点击**设为默认**。
:::

点击收银机栏末尾的头像，再点击**钱箱现金**，打开收银机面板。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [200, 0]]} alt="收银机已开启时的面板：钱箱中的现金、存入现金、取出现金和无销售开箱选项，以及底部的打印 X 报表">

1. **无销售开箱** — 打开钱箱，仅在收银机已开启时可用。旁边的**存入现金**和**取出现金**用于记录现金的存入或取出，不会打开钱箱。
2. **钱箱现金** — 收银机记录的应有现金金额。无销售开箱不会改变此金额。底部的**打印 X 报表**不会打开钱箱。

</JourneyShot>

点击**无销售开箱**。面板会询问 **为什么打开钱箱？**

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-30, 0], [440, 0], [140, -42]]} alt="无销售开箱面板显示为什么打开钱箱？：钱箱中的现金，兑换零钱、操作失误、检查钱箱和其他…原因选项，已填入兑换零钱的原因字段，以及打开钱箱按钮">

1. **兑换零钱** — 预设原因之一，其他还有**操作失误**和**检查钱箱**。点击任一选项即可填入原因。**其他…** 会清空字段，方便自行输入。
2. **原因** — 将要记录的原因。未填写时，面板会显示**添加原因**。
3. **打开钱箱** — 记录无销售开箱操作并打开钱箱。

</JourneyShot>

顶部的金额是收银机记录的钱箱应有现金金额。采用盲盘方式清点现金的收银员看不到此金额。

检查钱箱是否打开。如果仍未打开，请参阅[钱箱无法打开时](#when-it-doesnt-open)。无论是否打开，都会记录此次无销售开箱操作。

## 钱箱无法打开时 {#when-it-doesnt-open}

先在**编辑**中点击**打开钱箱**。此操作不会打印收据，可用来确认钱箱能否打开。然后展开与实际情况相符的问题。

<Accordion>
<AccordionItem question="点击打开钱箱有效，但打印收据时钱箱不打开">

线路连接正常。请检查打印收据的打印机是否已开启**自动打开钱箱**。

</AccordionItem>
<AccordionItem question="点击打开钱箱后显示“打印机未接受打印任务。”">

打印机未接受指令。请先在打印机所在行打印测试页。请参阅[收据打印机](./index.mdx#when-nothing-prints)。

</AccordionItem>
<AccordionItem question="应用显示钱箱已打开，但钱箱没有反应">

检查连接线是否插入钱箱接口，而非网络接口。然后尝试**钱箱连接器**的另一个选项：钱箱可能连接到了引脚 5。

</AccordionItem>
<AccordionItem question="钱箱发出咔嗒声，但未打开">

检查钱箱的钥匙。大多数钱箱正面有锁，其中一个钥匙位置会锁住钱箱。然后检查电压：钱箱有 12 V 和 24 V 两种规格，必须与打印机的输出电压匹配。具体电压请查看打印机说明书。

</AccordionItem>
<AccordionItem question="编辑面板警告：钱箱开启脉冲取决于打印机语言或仿真模式">

**打印机语言**与打印机品牌不匹配，例如将 Star 打印机设为了 ESC/POS。请将语言设为与打印机仿真模式一致。

</AccordionItem>
<AccordionItem question="无销售开箱面板已关闭，但钱箱没有打开">

无论钱箱是否打开，都会记录无销售开箱操作。请检查默认收据打印机是否已开启**自动打开钱箱**。如果打印机拒绝指令，面板会保持打开并显示错误：请再次点击**打开钱箱**。此操作只会打开钱箱，不会重复记录无销售开箱。

</AccordionItem>
<AccordionItem question="低价打印机没有反应">

部分低价打印机只支持旧版钱箱指令。对于设为 **Epson** 的打印机，**打开钱箱**会发送 Epson 的新版指令，而这些打印机会忽略该指令。部分打印机没有钱箱接口，或无法驱动钱箱。请查看打印机说明书，确认其是否支持钱箱。

</AccordionItem>
<AccordionItem question="自动打开钱箱已关闭，钱箱却仍会打开">

自定义热敏模板可以包含自己的 `<drawer />` 指令，无论开关是否开启，该指令都会打开钱箱。要停止此行为，请从模板中移除该标签。请参阅 [热敏模板](../../receipts/thermal-templates.mdx)。

</AccordionItem>
</Accordion>

## 仍未解决？ {#still-stuck}

在**设置 → 打印**中，打开打印机的**更多操作**菜单，点击**复制设置报告**。将报告粘贴到求助消息中，并附上打印机和钱箱的型号。
