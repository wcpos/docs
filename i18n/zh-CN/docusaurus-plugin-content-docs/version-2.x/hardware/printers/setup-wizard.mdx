应用内置了设置向导：**添加打印机**会查找打印机、打印测试页，并询问打印结果是否正常。本页介绍整个流程。如果测试页未打印出来，请[回答几个问题](#troubleshoot)。打印机设置及后续修改方法见[本页末尾](#more-options)。

## 添加打印机 {#add-a-printer}

请先打开打印机并装好纸张：面板一打开就会开始搜索。然后前往**设置 → 打印**，点击**添加打印机**。在**打印机**下，您会看到**打印对话框**，这是每台收银机都内置的打印选项。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[124, 0], [119, 0]]} maxWidth={460} alt="设置中打印页面的打印机列表底部：添加打印机按钮和遇到问题？链接">

1. **添加打印机** — 打开设置面板并立即开始查找打印机。
2. **遇到问题？** — 打开[打印机指南](./index.mdx)。

</JourneyShot>

搜索过程中，面板会显示搜索范围：

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[41, -18], [126, -18], [160, -18], [134, -18]]} maxWidth={559} alt="正在查找打印机的添加打印机面板：正在查找打印机、Wi-Fi 扫描进度、停止，以及查找 USB 打印机、查找蓝牙打印机和输入 IP 地址按钮">

1. **停止** — 结束搜索。
2. **查找 USB 打印机** — 在 Chrome 或 Edge 中打开浏览器的选择器，以选择通过线缆连接的打印机。桌面应用和移动应用在搜索时就会查找 USB 打印机。请参阅[各应用支持的连接方式](./index.mdx#supported-printers-by-platform)。
3. **查找蓝牙打印机** — 打开蓝牙打印机选择器。列表中没有您的打印机？请参阅[蓝牙配对](./bluetooth-pairing.mdx)。移动应用没有此按钮：搜索时就已包含蓝牙打印机。
4. **输入 IP 地址** — 手动输入 Wi-Fi 或网络打印机的地址。请参阅[下文](#enter-address)。

</JourneyShot>

## 搜索结果 {#what-it-finds}

找到的每台打印机都会显示为一张卡片。标题会说明搜索结果：**已找到您的打印机**、找到多台时显示**哪台是您的打印机？**、**这是一台办公打印机，不是收据打印机**，或**未找到打印机**。

如果打印机卡片显示**就绪**或**需要测试**，请继续[打印测试页](#test-page)。

每张卡片会显示以下四种状态之一：

- **就绪** — 应用可以向这台打印机发送打印任务。点击**打印测试页**。
- **需要测试** — 应用判断这台打印机可能可以打印，但需要通过测试页确认。
- **办公打印机** — 这是办公打印机或喷墨打印机，而非收据打印机。无法选择或测试其卡片。要在这台打印机上打印收据，请使用内置的**打印对话框**。
- **未连接** — 该地址上没有应用可以访问的打印机响应。

如果搜索没有结果，请参阅[未找到打印机](#not-found)。

## 打印测试页 {#test-page}

{/* reshoot: needs a real printer on the network (see reshoot.md) */}

选择打印机卡片并点击**打印测试页**（如果有多台，则显示**在此打印机上打印测试页**及其名称）。应用检查纸张时，面板会显示**正在检查纸张宽度…**。如果无法确定，您可以先在**纸张宽度**中选择 **58 mm** 或 **80 mm**。

接着，面板会询问**测试页是否已打印？** 问题下方的**测试页** *n* **·** *n* **字符/行**显示当前使用的宽度。回答之前，请查看测试页上的**列标尺**：这是一行数字，末尾应与右边缘对齐。如果换行到第二行，或未到达右边缘，就说明宽度不正确。然后选择符合情况的答案。

### 已打印，且效果正常 {#test-page-ok}

打印机已保存。面板会显示*名称* **已设置完成**，然后显示**这是您的默认打印机。** 或**收据将在此打印。** 点击**完成**。

### 已打印，但标尺不对 {#test-page-ruler}

在**打印机中装的是哪种纸张？** 下选择宽度，测试页就会重新打印：

- **32 — 58 mm 纸张**
- **42 — 80 mm，较旧的打印机**
- **48 — 80 mm，大多数 Epson 和 Star 打印机**
- **64 — 80 mm，小字体**

请参阅[收据宽度](./receipt-width.mdx)。

### 没有打印出来 {#test-page-nothing}

面板会显示**未打印任何内容**，并用一行文字说明可能的原因，例如纸张或安全打印。解决问题后：

- **重试** — 再次打印测试页。
- **不测试，直接保存** — 不经测试也保存打印机。如果打印机当前关机或缺纸，但您确定设置正确，可以使用此选项。之后可在打印机所在行点击**测试打印**进行测试。
- **重新开始**、**复制设置报告**（提供给支持团队）和**打开打印机指南**。

仍然没有打印出来？请[回答几个问题](#troubleshoot)。

## 未找到打印机 {#not-found}

如果搜索没有结果，面板会如下所示。不确定该尝试什么？请[回答几个问题](#troubleshoot)。

### 手动输入地址 {#enter-address}

如果搜索未找到 Wi-Fi 或网络打印机，请点击**输入 IP 地址**。地址可在打印机的状态页上找到。对于大多数 Epson 打印机，打开纸仓盖，按住**进纸**一秒，然后关上纸仓盖即可打印状态页。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[351, 0], [64, 0], [133, -18], [82, 18]]} maxWidth={559} alt="输入打印机的 IP 地址：IP 地址和端口字段、检查此地址、取消、状态页提示、重新扫描和打开打印机指南">

1. **IP 地址** — 状态页上的地址，例如 `192.168.1.100`。为打印机设置[固定地址](./network-address.mdx)，以免地址发生变化。
2. **端口** — 已自动填写。
3. **检查此地址** — 查询打印机类型，并将其显示为卡片。状态为**就绪**或**需要测试**的卡片可继续[打印测试页](#test-page)。
4. **重新扫描** — 返回搜索。

</JourneyShot>

- **桌面应用**通过 ePOS-Print 向 Epson 打印机发送任务（先尝试 **443**，然后依次尝试 8043、80、8008），向其他打印机发送任务时使用 **9100**。**移动应用**使用 **9100** 打印。

  <WizardFix id="fix-not-printing" title="测试页未打印出来时">

先阅读**未打印任何内容**下方的提示：它会说明可能的原因，例如安全打印、任务被挂起或纸张问题。

  <WizardFix id="net-deep" title="进一步检查网络">
如果基本设置都正确但仍无法打印，通常是以下原因之一：

**地址错误或已变化。** 检查状态页上的地址是否与应用中的一致，很容易误用另一台打印机的地址。使用 DHCP 的打印机重启后地址可能会变化，请在路由器上设置 **DHCP 地址保留**。以 `169.254` 开头的地址表示打印机尚未加入网络。请参阅[固定地址](./network-address.mdx)。

**Epson 打印一次后就停止。** 关闭打印机再重新打开。请参阅[打印一次后停止](./printed-once-then-stopped.mdx)。

**Epson 安全打印已开启。** 打印机会拒绝未加密的任务。请参阅[安全打印](./secure-printing.mdx)。

**Epson 无法打印，但其网页仍可访问。** 可能是 Server Direct Print 占用了打印机。请参阅 [Server Direct Print](./server-direct-print.mdx)。

**两台收银机共用一台打印机。** 许多 Star 网络打印机默认一次只接受一个连接，因此第二台收银机会超时。请在打印机的网页设置中开启 **9100 多会话**。

**打印机仅接受其他协议。** 移动应用，以及连接 Star 或其他非 Epson 打印机的桌面应用，通过 **9100 端口上的原始 TCP** 打印。在浏览器中打开打印机的设置页面，确保已开启 **raw / 端口 9100** 打印。仅启用 LPR、IPP 或 WSD 的打印机无法接收任务。

**无法连接 Wi-Fi，或频繁断开。** 收据打印机通常**仅支持 2.4 GHz**。请将其连接到 2.4 GHz 网络，而非仅支持 5 GHz 的网络。对于固定位置的收银机，使用网线是可靠的解决方法。

**每天第一次打印失败。** 打印机的网卡进入了休眠状态，第一个任务将其唤醒。请再次打印。对于固定位置的收银机，使用网线是可靠的解决方法。

**iPhone、iPad 或 Android 找不到打印机。** 应用需要访问本地网络的权限。请参阅 [iPad 和 iPhone](./ios-local-network.mdx) 或 [Android 权限](./android-permissions.mdx)。

  <WizardStep id="web-net-setup" title="在网页版应用中添加网络打印机">

在**网页浏览器**中，应用只能通过 HTTP 或 HTTPS 与打印机内置的网页服务器通信。如果店铺使用 **HTTPS**，默认会使用打印机的安全端口（Epson 为 **8043**，Star 为 **443**），这要求打印机具备浏览器信任的证书。

首先，确认能否访问打印机：在新的浏览器标签页中打开 `http://<printer-ip>/` （如果无法加载，请尝试 `https://<printer-ip>/`）。如果能看到打印机自身的设置页面，说明打印机已联网。如果两个地址都无法加载，请先解决网络或地址问题。

然后前往**设置 → 打印**，点击**添加打印机**，让应用搜索 **Wi-Fi**。如果未找到您的打印机，请点击**输入 IP 地址**。Chrome 可能会请求访问本地网络的权限，请允许。

  <WizardFix id="web-net-fix" title="网页端网络打印无法工作时">

这是最常见的卡点，而且往往无法在浏览器中解决。以下是原因和处理方法：

打印打印机的**状态页**，查看 SSL/TLS 部分。如果没有证书，必须先创建证书才能通过 HTTPS 打印。浏览器默认不信任打印机自身的证书，需要在每台设备上打开 `https://<printer-ip>` 一次并接受该证书。请参阅 [权限和证书](./browser-permissions.mdx)。

如果任务已发送却没有打印，很可能是被浏览器拦截了：打印机使用 HTTP，而店铺使用 HTTPS（触发“混合内容”拦截），或安全端口没有配置证书。

网页版应用只能通过打印机**内置的网页服务器**访问打印机，即 Epson 的 **ePOS-Print** 或 Star 的 **WebPRNT**，因此请确保打印机设置中已开启该服务。只有 Epson 的“智能”型号和 **-NT** 型号，以及 Star 的 **WebPRNT** 型号具备该服务。如果您的打印机不具备，浏览器就无法访问它。

**可靠的解决方法是使用桌面应用**，它访问打印机时不受浏览器证书和权限的限制：通过 ePOS-Print 服务连接 Epson，优先使用 HTTPS 端口 443；通过端口 9100 连接 Star。在桌面应用中添加同一台打印机即可。
