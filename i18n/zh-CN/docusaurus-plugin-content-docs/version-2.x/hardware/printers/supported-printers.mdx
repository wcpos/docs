请在下方查找您的打印机、应用和连接方式。**已验证**表示我们已通过所列连接方式在该型号上完成实际打印；其他型号列在**预计可用**下。**厂商**设置用于告知应用正在与哪个品牌的打印机通信。

## 已验证 {#verified}

以下型号已通过所列连接方式在实机上完成打印测试。

| 打印机及纸张 | 打印方式 |
|---|---|
| **Epson TM-m30III**<br />80 mm | 网页版、桌面版和移动版应用通过 Wi-Fi 打印。Android 应用通过蓝牙打印。 |
| **Netum NT-1809**<br />58 mm | 桌面版应用通过 USB 和蓝牙打印。 |

如果应用能找到一台新的 Epson 打印机，但它不打印任何内容，通常是因为开启了安全打印。请参阅 [Epson 安全打印](./secure-printing.mdx)。

## 预计可用 {#expected-to-work}

我们尚未逐一测试这些型号，但它们使用的连接方式与已验证的打印机相同。如果您的打印机无法打印，请按照[设置向导](./setup-wizard.mdx)操作，然后[反馈情况](#report-yours)。

**网页版应用**是在浏览器中运行的 WCPOS。**移动版应用**是适用于 Android、iPhone 和 iPad 的 WCPOS 应用。**桌面版应用**是适用于 Windows、macOS 和 Linux 的 WCPOS 应用。

iPhone 和 iPad 无法通过 USB 连接打印机，且只能连接 Epson 和 Star 的经典蓝牙打印机。

- **支持 ePOS 的 Epson TM 系列打印机，以及 Star mC-Print 和 TSP 打印机**
  - **Wi-Fi**：所有应用。
  - **USB**：桌面版应用、Chrome、Edge 和 Android 应用。
  - **蓝牙**：桌面版和移动版应用。
- **其他厂商的 ESC/POS 打印机**
  - **Wi-Fi**：桌面版和移动版应用。
  - **USB**：桌面版应用、Chrome 和 Edge。
  - **低功耗蓝牙（BLE）**，前提是打印机手册列出了此功能：Chrome、Edge、桌面版应用和移动版应用。
  - **经典蓝牙**：在电脑或[手机的蓝牙设置](./bluetooth-pairing.mdx#android-pair-first)中配对后，可通过桌面版应用和 Android 应用使用。

## 尚不支持 {#not-supported-yet}

- **网页版应用中的非 Epson 和 Star 品牌 Wi-Fi 打印机。** 浏览器只能访问 Epson 和 Star 打印机内置的 Web 服务器。请使用桌面版或移动版应用、USB 或蓝牙连接，或[云打印机](../../receipts/cloud-printing.mdx)。
- **移动版应用中的其他厂商 USB 打印机。** 在 Android 上，USB 仅支持 Epson 和 Star 打印机。请使用 Wi-Fi 或蓝牙，或使用桌面收银设备。
- **iPhone 和 iPad 上的其他厂商经典蓝牙打印机。** 请使用低功耗蓝牙或 Wi-Fi，或使用 Android 或桌面收银设备。
- **Sunmi 和 iMin 一体式终端的内置打印机。** 应用尚不支持这些打印机。请像使用其他 Android 设备一样，为其连接外置打印机。

## 告知应用打印机的品牌 {#vendor}

**厂商**设置用于指定打印机的品牌。应用在找到打印机或您检查 IP 地址时会自动填写此项。在**编辑打印机**中，IP 地址下方会显示**检测到：Epson**、**检测到：Star**或**检测到：通用**。仅当应用判断错误或无法连接打印机时，才需要手动更改。

此设置位于两处：**设置 → 打印 → 添加打印机**的**更多选项**中，以及已添加打印机的**编辑打印机**中。

:::warning

更改**厂商**也会重置**打印机语言**，在网页版应用中还会重置**端口**。**编辑打印机**保持打开期间，应用会停止检查该地址上的打印机品牌。

:::

在**编辑打印机**中，**厂商**位于**连接**下方，应用检测到的品牌会显示在 IP 地址下方：

1. **连接** — 网页版应用为**网络**连接提供**厂商**选项，即通过 Wi-Fi 或网线连接的打印机。
2. **厂商** — 网页版应用中可选 **Epson** 或 **Star Micronics**。仅在应用判断错误时更改。
3. **IP 地址** — 下方的**检测到：Epson**表示应用在此地址找到的品牌。
4. **端口** — 在网页版应用中随**厂商**变化。此处为 8008，即 Epson 的普通 HTTP 端口；在使用 HTTPS 的店铺中，初始值为 8043。
5. **Web 打印端点** — 网页版应用发送收据的方式，此处为 Epson ePOS。请参阅[更改此项的影响](#what-vendor-changes)。
6. **打印机语言** — 更改**厂商**时恢复为该厂商的默认值：Epson 对应 **ESC/POS**。

### 更改此项的影响 {#what-vendor-changes}

<details>
<summary>打印机语言、端口以及各厂商的打印方式</summary>

收据打印机使用大多数厂商采用的 ESC/POS，或 Star 专有的语言 StarPRNT 或 Star Line Mode。

- **打印机语言**会恢复为该厂商的默认值：Epson 和通用对应 **ESC/POS**，Star 对应 **Star Line Mode**。已保存的打印机会保留您设置的语言，直到您更改厂商。
- 网页版应用中的**端口**会变为该品牌监听的端口。在使用安全连接的店铺中，选择 **Star Micronics** 后，地址表单显示 **443**：

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[0, 0], [58, 0], [133, 18]]} maxWidth={559} alt="选择 Star Micronics 后输入打印机的 IP 地址：IP 地址字段、显示 443 的端口字段，以及“检查此地址”">

1. **IP 地址** — 打印机的状态页上会打印此地址。
2. **端口** — 在使用安全连接的店铺中，Star 使用 443（否则为 80）。Epson 使用 8043（否则为 8008）。
3. **检查此地址** — 应用查询该地址，判断响应的是哪个品牌，并以卡片形式显示打印机。点击卡片下方的**打印测试页**即可打印。

</JourneyShot>

- **应用发送收据的方式**也会改变。手动选择厂商后，应用会停止重新检测，直到您关闭**编辑打印机**。下次打开时，应用会再次检查该地址，并可能将厂商改回原来的值。

**各厂商在不同应用中的打印方式**

| | Epson | Star Micronics | 通用 |
|---|---|---|---|
| **网页版应用，Wi-Fi** | Epson ePOS，端口 8043（未使用 HTTPS 的店铺为 8008） | Star WebPRNT，端口 443（未使用 HTTPS 时为 80） | 不提供 |
| **桌面版应用，Wi-Fi** | Epson ePOS | 普通网络打印，端口 9100 | 普通网络打印，端口 9100 |
| **移动版应用，Wi-Fi** | 普通网络打印，端口 9100 | 普通网络打印，端口 9100 | 普通网络打印，端口 9100 |
| **移动版应用，USB 和蓝牙** | Epson 自有软件 | Star 自有软件 | 低功耗蓝牙，或在 Android 上配对后的经典蓝牙 |
| **打开钱箱按钮，ESC/POS** | Epson 专有的钱箱命令 | 标准 ESC/POS 钱箱命令 | 标准 ESC/POS 钱箱命令 |

只有**打开钱箱**按钮会发送 Epson 的专有命令。启用**自动打开钱箱**后，打印收据时使用的都是标准命令，与厂商无关。

在网页版应用中，应用会直接以 USB 或蓝牙打印机的**打印机语言**发送内容：通常为 ESC/POS；若打印机响应为 Star，则为 Star Line Mode。Epson ePOS 和 Star WebPRNT 仅用于 Wi-Fi 连接。

</details>

## 遇到问题时 {#goes-wrong}

**“钱箱弹出命令取决于打印机语言/仿真模式。”** 厂商与**打印机语言**不匹配：例如 Star 打印机设为 ESC/POS，或其他品牌设为 Star 语言。如果打印机确实处于该仿真模式，则没有问题。如果钱箱无法打开，请将**打印机语言**设为打印机当前使用的模式。

**非 Epson 打印机的“打开钱箱”按钮没有反应。** 当**厂商**设为 Epson 时，该按钮会发送 Epson 专有的钱箱命令，许多其他打印机会忽略此命令。在桌面版或移动版应用中，请将**厂商**设为**通用**。网页版应用会将 USB 或蓝牙打印机保存为 Epson，除非它响应为 Star，且不提供**厂商**选项。因此，请启用**自动打开钱箱**，这样每次打印收据时都会打开钱箱。

**您的 Epson 或 Star 显示“检测到：通用”。** 请在**厂商**中选择对应品牌。打印机仅在基本打印端口上响应，因此应用无法识别品牌。

**网页版应用的列表中没有您的品牌。** 浏览器只能通过 Wi-Fi 向 Epson 和 Star 打印机打印。请在 Chrome 或 Edge 中通过 USB 或蓝牙连接打印机，或使用桌面版应用。

## 反馈您的打印机情况 {#report-yours}

无论能否正常打印，都请告知我们打印机型号。点击**复制设置报告**：它位于**添加打印机**的**未打印任何内容**界面、提示打印机设置完成的界面，以及**设置 → 打印**中每台打印机的**更多操作**菜单中。报告会记录打印机、厂商、响应情况以及应用近期的打印机日志。请将其粘贴到您的消息中。
