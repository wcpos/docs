几乎所有条码扫描器在插入或配对后都能立即用于 POS。本页将指导您从拆箱开始完成首次扫描，并说明扫描未成功时该如何排查。

## 扫描方式 {#ways-to-scan}

- **键盘模式** — 几乎所有扫描器出厂时都使用此模式。扫描器像键盘一样输入条码，POS 根据输入速度区分扫描和手动输入。无需设置。
- **摄像头** — 无需扫描器。点击商品搜索框旁的扫描按钮，将摄像头对准条码。参见[摄像头扫描](../../pos/product-panel/barcode-scanning.mdx#camera-scanning)。
- **直接连接** — POS 直接识别扫描器设备，无需根据输入速度判断是否为扫描。适用于键盘模式无法满足需求的情况，参见[直接连接扫描器](#direct)。

## 连接扫描器 {#connect}

1. 将扫描器连接到您的设备：
   - **USB 扫描器：** 插入设备即可。
   - **蓝牙扫描器：** 将扫描器切换到配对模式（操作方法见说明书），然后像配对键盘一样，在设备的蓝牙设置中完成配对。
2. 打开 POS。如果您的店铺启用了 **开启和关闭收银机**，请先[开启收银机](../../pos/register/index.mdx#open)。
3. 扫描商品条码：
   - **浏览器或桌面应用：** 点击任意文本框以外的区域，然后扫描。在 POS 的任何位置扫描，商品都会直接加入购物车；如果在文本框中扫描，则会被视为手动输入。
   - **iPhone、iPad 或 Android 应用：** 点按商品搜索框，然后扫描。应用只有在此输入框中才能接收键盘模式扫描器的输入。[在 Android 上注册](#direct)过的扫描器无需先点按搜索框。

如果商品已显示，就设置完成了。如果未显示，请[测试扫描](#test)，查看 POS 收到了什么。

## 测试扫描 {#test}

打开 **设置**，选择 **条码扫描**。在 iPhone、iPad 或 Android 应用中，点按 **按键事件** 下方的输入框，然后扫描任意条码。底部的 **条码扫描测试** 会按接收顺序显示按键、POS 从中读取的条码，以及是否将其识别为扫描。以下示例来自一台速度较慢的扫描器，因此被视为手动输入：

1. **按键事件** — 扫描器发送的每个按键，包括末尾的回车键。
2. **检测到的条码** — 去除前缀和后缀后，POS 将用于查找商品的条码。
3. **按键间隔图** — 每个条柱代表一个按键，虚线表示您设置的阈值。条柱超过虚线表示该按键传入过慢。
4. **判断结果** — 显示 **识别为扫描**，或说明为何被视为手动输入，并给出修复建议。点击 **应用** 即可保存建议的设置。
5. **最近的尝试** — 显示最近几次尝试，每次均标记为 **扫描**、**手动输入** 或 **过短**，并附有平均按键间隔。
6. **故障排查指南** — 打开[扫描器设置向导](./setup-wizard.mdx)，按故障现象查找解决方法。

1. **间隔条柱** — 每个条柱代表一个按键，下方显示其间隔，单位为 ms。琥珀色条柱表示间隔超出了阈值。
2. **虚线** — 您设置的阈值，此处为 24ms。
3. **应用** — 保存建议的阈值。再次扫描以验证效果。

如果判断结果提示扫描器正在 **将 Shift 作为单独的按键发送**，请扫描说明书中的相应条码，将扫描器设为美式键盘布局，或[直接连接扫描器](#direct)。

## 扫描器设置 {#settings}

**条码扫描** 页面的其余部分包含测试所依据的设置，以及直接连接扫描器的选项。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[50, 0], [50, 0], [50, 0], [50, 0], [45, 0], [260, 0], [151, 0], [341, 0], [175, 0]]} alt="设置中的条码扫描页面：阈值、最小长度、前缀和后缀字段，扫描时播放声音开关，扫描器区域中的“大多数扫描器无需设置”、扫描器设置指南和直接连接，以及条码扫描测试标题">

1. **条码平均输入时间阈值（ms）** — 按键输入需要达到多快才算扫描。POS 的初始值为 24。扫描器较慢时可提高此值；如果快速打字被误判为扫描，则降低此值。
2. **条码最小长度** — 可被识别为扫描的最短条码长度。POS 的初始值为 8，即 EAN-8 的长度。
3. **条码扫描器前缀** — 扫描器在每个条码前添加的单个字符。POS 会在查找条码前将其去除。如果扫描器不添加前缀，请留空。
4. **条码扫描器后缀** — 扫描器在每个条码后添加的单个字符，POS 会以同样的方式将其去除。末尾的回车键无需设为后缀，POS 会自动忽略它。
5. **扫描时播放声音** — 默认关闭。开启后，可选择 **声音主题** 和 **音量**，并开启或关闭 **成功提示音** 和 **失败提示音**。iPhone、iPad 和 Android 应用还提供 **失败时振动**。
6. **大多数扫描器无需设置** — 尚未直接连接任何扫描器时，此区域会显示这条提示。键盘模式的扫描器不会出现在这里。
7. **扫描器设置指南** — 打开[扫描器设置向导](./setup-wizard.mdx)，回答几个问题后，向导会引导您完成设置或排除故障。
8. **直接连接** — 在您直接连接扫描器之前，显示为 **无**。参见[直接连接扫描器](#direct)。
9. **条码扫描测试** — 在此页面扫描，查看扫描器发送的内容。参见[测试扫描](#test)。

</JourneyShot>

这些设置仅适用于当前设备，因此每台配有扫描器的收银设备都需要单独设置。

## 出现问题时 {#goes-wrong}

**扫描时没有任何反应。** 检查扫描器是否发出提示音或亮灯，并确认设备的蓝牙设置显示 **已连接**，而不只是已配对。在 iPhone、iPad 或 Android 应用中，请先点按商品搜索框再扫描。然后尝试在记事应用中扫描：如果能显示条码，说明扫描器工作正常，[扫描测试](#test)会显示 POS 为何将其视为手动输入。

**判断结果显示“视为手动输入”。** 扫描器的输入速度低于阈值要求。点击建议旁的 **应用**，或提高 **条码平均输入时间阈值（ms）**。

**在商品搜索框中打字被识别为扫描。** 这种情况会发生在 iPhone、iPad 或 Android 应用中，因为 POS 也会根据输入速度判断搜索框中的输入。请降低阈值，或提高 **条码最小长度**。在浏览器或桌面应用中，文本框中的输入不会被视为扫描。

**扫描结果出现乱码。** 扫描器的键盘布局与设备不匹配。请扫描说明书中的相应条码，将其设为美式键盘布局，或[直接连接扫描器](#direct)。

**直接连接时，列表中找不到扫描器。** 在桌面应用、浏览器、iPhone 或 iPad 上，这通常意味着扫描器仍处于键盘模式：请扫描说明书中的模式条码，然后重新按照[适用于您设备的步骤](#direct)操作。如果蓝牙串口扫描器仍未显示，它可能使用了专有的服务 UUID：请展开 **直接连接扫描器** 下的 [**桌面应用、Chrome 或 Edge**](#direct-desktop)，找到 **蓝牙服务类 UUID**。Android 上没有设备列表，请[注册扫描器](#direct)。

**直接连接的扫描器所在行显示“不在范围内”、“未插入”或“未连接”。** POS 当前无法与其通信。请开启扫描器、将其移近设备，或重新插入。参见[连接成功后](#connected)。

**POS 收到了扫描结果，但没有显示商品。** POS 会说明原因：**未找到条码**、**多个匹配项**、**选择变体**。参见[扫描条码](../../pos/product-panel/index.mdx#scan)。用于存储条码的商品字段可在[条码字段](../../settings/wp-admin/general.mdx#barcode-field)中设置。

如需按平台和故障现象逐步排查，请使用[扫描器设置向导](./setup-wizard.mdx)。

## 直接连接扫描器 {#direct}

键盘模式适合大多数店铺。如果扫描结果出现乱码、输入到了错误的文本框，或在未选中文本框时丢失，请使用直接连接。

展开您运行 POS 的设备所对应的部分。每个部分都按顺序列出了完整步骤：

<details id="direct-desktop">
<summary>桌面应用、Chrome 或 Edge</summary>

1. 扫描说明书中的设置条码，将扫描器从键盘模式切换到其他模式，例如 *SPP 模式*、*串口模式* 或 *HID POS 模式*。
2. 如果使用蓝牙扫描器，请在设备的蓝牙设置中移除它，然后以新模式重新配对。
3. 打开 **条码扫描**，点击 **直接连接扫描器（高级）**，然后选择扫描器的连接方式：

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[-24, 0], [222, 0], [455, 12], [300, 0], [240, 0]]} alt="浏览器中的直接连接扫描器面板：通过 USB 连接、通过蓝牙串口连接、关于键盘模式扫描器的说明，以及“列表中没有我的扫描器”下的蓝牙服务类 UUID 字段和添加按钮">

1. **通过 USB 连接** — 适用于处于 HID POS 模式的 USB 扫描器。在打开的列表中选择扫描器。
2. **通过蓝牙串口连接** — 适用于处于串口（SPP）模式的扫描器。串口模式的 USB 扫描器也会显示在同一个列表中。
3. **键盘模式说明** — 仍处于键盘模式的扫描器不会出现在这些列表中。您的设备不允许任何应用接管键盘。
4. **蓝牙服务类 UUID** — 适用于已退出键盘模式、但仍未出现在列表中的蓝牙串口扫描器。输入说明书中的 UUID，点击 **添加**，然后重新连接。
5. **查找扫描器的服务 UUID** — 打开[扫描器设置向导](./setup-wizard.mdx)，了解在哪里查找。

</JourneyShot>

</details>

<details>
<summary>iPhone 或 iPad</summary>

1. 扫描说明书中的设置条码，让扫描器退出键盘模式。
2. 设备的蓝牙设置仍将扫描器识别为键盘，请在其中移除扫描器。不要重新配对。
3. 在 **条码扫描** 中，点击 **直接连接扫描器（高级）**，然后点击 **连接蓝牙扫描器**。POS 会连接找到的第一台低功耗蓝牙（Bluetooth LE）扫描器，因此请关闭其他扫描器。

</details>

<details>
<summary>Android</summary>

1. 让扫描器保持键盘模式，并保留当前配对。
2. 在 **条码扫描** 中，点击 **注册扫描器**，然后点击 **注册扫描器**。
3. 用扫描器扫描一次，为其命名，然后点击 **保存扫描器**。此后，POS 会根据设备识别其扫描输入，无需再依靠输入速度判断。

</details>

<details>
<summary>Safari 或 Firefox</summary>

不支持直接连接，因此没有 **扫描器** 区域。请使用键盘模式或摄像头，或改用桌面应用或 Chrome。

</details>

### 连接成功后 {#connected}

连接后的扫描器会在 **扫描器** 下单独显示一行及其状态：连接正常时显示 **已连接**；连接不可用时显示 **不在范围内**、**未插入** 或 **未连接**；在 Android 上则显示 **已注册**。其 **⋮** 菜单中提供 **移除** 选项。键盘模式的扫描器仍可同时使用。
