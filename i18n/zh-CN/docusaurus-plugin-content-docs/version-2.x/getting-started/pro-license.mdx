WCPOS Pro 是付费的 WordPress 插件，包含免费 WCPOS 插件的全部功能，因此只需单独安装它来替代免费插件。本页介绍从购买许可证到在 POS 中看到 **Pro** 的完整流程。

:::note 需要 WordPress 管理员账号
安装和激活操作在 WP Admin 中进行，而非在 POS 中进行。执行操作的人需要使用能够安装插件的 WordPress 账号登录。
:::

## 购买许可证 {#purchase-a-license}

Pro 是安装在 WordPress 网站上的一个插件，无需按设备购买：连接到该网站的所有设备和收银员都能使用 Pro。

前往 [wcpos.com/pro](https://wcpos.com/pro) 购买许可证。购买、方案变更和续订均在 wcpos.com 上进行，POS 本身不提供购买结账功能。POS 顶部的 **升级到 Pro** 也会打开同一页面（参见[免费版的显示内容](#free-version)）。然后[安装插件](#installation)。

如果无法创建 wcpos.com 账号或完成购买，请发送邮件至 **support@wcpos.com**。

如果要将年度许可证改为终身许可证，也请联系 **support@wcpos.com**，由支持团队处理许可证和账单事宜。参见[咨询渠道](../support/index.mdx#where-to-ask)。

Pro 增加了产品、订单、客户和优惠券页面，历史日期及各收银机的报表，集成式读卡器、顾客显示屏、退款，以及更多收银机和店铺。完整列表请参见[免费版与 Pro 对比](./free-vs-pro.mdx)。

## 安装 Pro 插件 {#installation}

1. 登录 wcpos.com，打开[下载](https://wcpos.com/account/downloads)页面，下载 Pro 插件。文件为 zip 格式，请保持压缩状态。
2. 在 WP Admin 中前往 **插件**，添加新插件，然后点击 **上传插件**。
3. 选择 zip 文件，点击 **立即安装**，然后点击 **启用插件**。

:::note 从免费插件升级？
无需先移除免费插件。Pro 启动时会停用免费插件，并显示相应通知。之后可以在 **插件** 页面删除免费插件，但这并非必要操作：删除会使所有收银员退出登录，每台收银设备都需重新登录。参见[上传以覆盖当前版本](./previous-versions.mdx#install)。

已经移除了免费插件？没有关系：Pro 包含免费插件的代码，无需免费插件即可运行。如果安装 Pro 后网站出现错误，请参见[严重错误](../support/troubleshooting/critical-error.mdx#common-errors)。
:::

## 激活许可证密钥 {#activate}

1. 从账号的[许可证](https://wcpos.com/account/licenses)页面复制密钥。
2. 在 WP Admin 中前往 **POS** > **设置**。在 **账号** 下打开 **许可证**。
3. 将密钥粘贴到 **许可证密钥** 中，然后点击 **激活**。

随后页面会显示 **谢谢！** 和 **许可证 … 已激活。**，其中密钥的中间部分会缩略显示。如果显示的是其他消息，请参见[遇到问题时](#troubleshooting)。

## 确认 POS 已运行 Pro {#checking-licence-status}

重新加载 POS：刷新浏览器页面，或关闭后重新打开桌面或移动应用。升级提示条会消失，产品、订单、客户和优惠券页面会显示店铺数据，而不再是模糊的预览。

如需确认，点击菜单底部的版本号（**v 2.0.0**，手机上为 **版本 2.0.0**），即可打开 **关于 WCPOS**。

- **许可证** 中应显示 **状态**：**Pro**。未激活任何密钥时，显示 **免费版**。
- **服务器** 会列出 **WCPOS Pro 插件** 及其版本（免费插件显示为 **WCPOS 插件**）。这只能确认插件已安装：无论许可证是否已激活，都会显示。

## 更新 {#updates}

与其他插件一样，Pro 的新版本会出现在 **仪表盘** > **更新** 和 **插件** 页面中。您也可以从[下载](https://wcpos.com/account/downloads)页面下载最新的 zip 文件。

**插件** 页面中的 Pro 行会显示许可证状态：有效且可接收更新、未激活或已过期。

## 遇到问题时 {#troubleshooting}

### 更新后提示再次付费购买 Pro {#pro-shows-free}

只要网站没有运行 Pro 插件，或没有在该网站激活许可证密钥，POS 就会显示免费版及 **升级到 Pro** 提示。再次购买前，请检查这两项：

1. 在 WP Admin 中打开 **插件**。应能找到 **WCPOS Pro – Point of Sale for WooCommerce**，且它必须处于启用状态。如果已安装但未启用，请点击 **启用**。如果只有 **WCPOS – Point of Sale for WooCommerce**，则表示 Pro 已被移除，请[重新安装](#installation)。删除 Pro 时会保留许可证密钥，因此重新安装后密钥也会恢复。
2. 前往 **POS** > **设置**，在 **账号** 下打开 **许可证**。如果看到 **许可证密钥** 字段和 **激活** 按钮，说明密钥尚未在此网站激活：从[许可证](https://wcpos.com/account/licenses)页面复制并粘贴密钥，然后点击 **激活**。

然后重新加载 POS。**关于 WCPOS** 中应显示 **状态** **Pro**，参见[确认 POS 已运行 Pro](#checking-licence-status)。如果激活时出现其他消息，下文列出了常见情况。如果更新无法安装，请参见 [LICENSE301](../error-codes/LICENSE301.mdx)。

### 有更新提示，但无法下载 {#update-wont-download}

WordPress 会向所有网站提供 Pro 新版本提示，无论是否拥有许可证。实际下载时才会检查许可证，以下情况会拒绝下载：

- 此网站没有已激活的许可证密钥，或
- 许可证已过期。

查看 **插件** 页面中的 Pro 行。**您的 WCPOS Pro 许可证未激活。** 对应上面的第 2 步：激活密钥后再次更新。**您的 WCPOS Pro 许可证已过期。** 表示需要从[账号](https://wcpos.com/account/licenses)续订，然后再次更新。如果该行显示许可证有效且已激活，但下载仍然失败，请发送邮件至 **support@wcpos.com**。参见 [LICENSE301](../error-codes/LICENSE301.mdx)。

<details>
<summary>许可证页面显示来自 wcpos.com 的消息</summary>

该消息来自负责检查密钥的许可证服务器。请检查粘贴的密钥前后是否有空格，并确认密钥来自您的[许可证](https://wcpos.com/account/licenses)页面。

</details>

<details>
<summary>许可证已达到激活次数上限</summary>

一份许可证可在 2 个网站上激活：一个正式网站和一个开发网站。子域名单独计数，因此 `example.com`、`staging.example.com` 和 `dev.example.com` 算作三个网站。内置开发、测试和正式网站的主机服务经常会遇到这种情况。请在[许可证](https://wcpos.com/account/licenses)页面查看网站并释放激活名额，或发送邮件至 **support@wcpos.com**，可按需申请额外激活名额。

</details>

<details>
<summary>激活因网络错误而失败</summary>

激活请求会从您用于访问 WP Admin 的浏览器直接发送到 wcpos.com。请确认此浏览器可以打开 wcpos.com，然后关闭广告或隐私拦截工具，再次点击 **激活**，也可以换用其他浏览器。

</details>

<details>
<summary>Pro 从不提示更新</summary>

更新检查请求会从 WordPress 服务器发送到 `updates.wcpos.com`。安全插件或主机的防火墙可能会拦截这些请求，请联系主机服务商，允许向 `updates.wcpos.com` 发送出站请求。

</details>

<details>
<summary>激活后仍显示升级提示条</summary>

重新加载 POS（刷新页面，或关闭后重新打开应用）。如果 **关于 WCPOS** 仍显示 **状态** **免费版**，请打开 WP Admin，前往 **POS** > **设置**，在 **账号** 下打开 **许可证**。确认页面显示 **许可证 … 已激活。**

</details>

<details>
<summary>许可证已过期</summary>

Pro 会继续运行，POS 中的所有功能都不会关闭。**插件** 页面会显示“您的 WCPOS Pro 许可证已过期。请续订以接收更新。”从[账号](https://wcpos.com/account/licenses)续订后即可重新获取更新，密钥保持不变。

</details>

<details>
<summary>将网站迁移到新域名</summary>

先释放旧网站的激活名额：在 WP Admin 中前往 **POS** > **设置**，在 **账号** 下打开 **许可证**，然后点击 **停用**。再在新网站上激活同一个密钥。仅停用插件本身不会释放激活名额。如果旧网站已不存在，请从[许可证](https://wcpos.com/account/licenses)页面释放名额，或发送邮件至 **support@wcpos.com**。

</details>

<details>
<summary>卸载 Pro 对数据的影响</summary>

删除 Pro 插件会移除 Pro 自身的运行数据和翻译文件。Pro 设置（包括许可证密钥）和店铺会保留，因此重新安装后即可继续使用。订单和产品数据始终不会受到影响。

只有在免费插件也不再安装的情况下，才会移除 Pro 与免费插件共用的翻译文件。

如果要彻底清除数据，连同设置、许可证密钥和店铺一起移除，请在删除插件前开启完全清除：将 `define( 'WCPOS_REMOVE_ALL_DATA', true );` 添加到 `wp-config.php`，或将 `wcpos_remove_all_data` 选项设为 `yes`。两者都设置时，以常量为准。完全清除操作无法撤销。

</details>
