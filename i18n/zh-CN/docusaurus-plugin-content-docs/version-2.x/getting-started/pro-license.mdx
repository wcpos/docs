WCPOS Pro 是付费的 WordPress 插件，包含免费 WCPOS 插件的全部功能，因此只需单独安装它来替代免费插件。本页介绍从购买许可证到在 POS 中看到 **Pro** 的完整流程。

:::note 需要 WordPress 管理员账号
安装和激活操作在 WP Admin 中进行，而非在 POS 中进行。执行操作的人需要使用能够安装插件的 WordPress 账号登录。
:::

## 购买许可证 {#purchase-a-license}

前往 [wcpos.com/pro](https://wcpos.com/pro) 购买许可证，然后[安装插件](#installation)。购买、套餐变更和续订都在 wcpos.com 上完成：POS 本身没有结账功能。点击 POS 顶部的 **Upgrade to Pro** 会打开同一页面（请参阅[免费版的显示内容](#free-version)）。

Pro 是安装在 WordPress 网站上的一个插件，并非按设备购买：连接到该网站的每台设备和每位收银员都能使用 Pro。无法完成购买或想更改套餐？请参阅[遇到问题时](#troubleshooting)。

Pro 提供 Products、Orders、Customers 和 Coupons 页面；可查看所有收银台和店铺中更早日期的数据报告（最多可追溯 92 天）；还提供集成式读卡器、顾客显示屏、退款功能，以及更多收银台和店铺。[免费版与 Pro](./free-vs-pro.mdx)列出了全部功能。

## 安装 Pro 插件 {#installation}

1. 登录 wcpos.com，打开[下载](https://wcpos.com/account/downloads)页面，下载 Pro 插件。文件为 zip 格式，请保持压缩状态。
2. 在 WP Admin 中，前往 **Plugins**，然后按 **Plugins** 标题旁边的 **Add Plugin**。
3. 按 **Add Plugins** 标题旁边的 **Upload Plugin**。此时会打开一个用于上传 zip 文件的框，按钮会变为 **Browse Plugins**。
4. 按 **Choose File** 并选择 zip 文件，然后按 **Install Now**。

<JourneyShot manifest={wpAdmin} device="desktop" step={1} offsets={[[-30, 0], [-40, 0]]} alt="WP Admin 的 Add Plugins 页面在按下 Upload Plugin 后的状态：用于 .zip 格式插件的框，其中有 Choose File 字段和 Install Now 按钮；标题旁的按钮此时显示为 Browse Plugins">

1. **Choose File** — 选择下载的 Pro zip 文件。
2. **Install Now** — 选择文件前，此按钮为灰色且不可用。

</JourneyShot>

5. 安装完成后，按 **Activate Plugin**。

:::note 从免费插件升级？
无需先移除免费插件。Pro 启动时会停用免费插件，并显示相应通知。之后可以在 **Plugins** 页面删除免费插件，也可以保留。安装 Pro 期间，删除免费插件不会让收银员退出登录，也不会删除收银台使用的同步数据。

已经移除了免费插件？没有关系：Pro 包含免费插件的代码，无需免费插件即可运行。如果安装 Pro 后网站出现错误，请参见[严重错误](../support/troubleshooting/critical-error.mdx#common-errors)。
:::

## 激活许可证密钥 {#activate}

1. 从账号的[许可证](https://wcpos.com/account/licenses)页面复制密钥。
2. 在 WP Admin 中前往 **POS** > **设置**。在 **账号** 下打开 **许可证**。
3. 将密钥粘贴到 **许可证密钥** 中，然后点击 **激活**。

<JourneyShot manifest={wpAdmin} device="desktop" step={3} offsets={[[0, 0], [27, 30]]} alt="WP Admin 中的 POS → Settings → License 页面，尚未激活密钥：License Key 字段为空，Activate 按钮为灰色且不可用">

1. **License Key** — 在此粘贴 Licenses 页面上的密钥。
2. **Activate** — 字段中有密钥后，此按钮才会启用。

</JourneyShot>

随后页面会显示 **谢谢！** 和 **许可证 … 已激活。**，其中密钥的中间部分会缩略显示。如果显示的是其他消息，请参见[遇到问题时](#troubleshooting)。

<JourneyShot manifest={wpAdmin} device="desktop" step={2} offsets={[[-80, 0], [99, 0]]} alt="WP Admin 中的 POS → Settings → License 页面，许可证已激活：显示 Thank You!，License 后面显示已激活的缩短密钥（此处已遮盖），以及 Deactivate 按钮">

1. **Your key** — 中间部分已缩短。此图片中对密钥进行了遮盖。
2. **Deactivate** — 释放此网站的激活名额，例如在[迁移到新域名](#new-domain)之前。

</JourneyShot>

## 确认 POS 已运行 Pro {#checking-licence-status}

重新加载 POS：刷新浏览器页面，或关闭后重新打开桌面或移动应用。升级提示条会消失，产品、订单、客户和优惠券页面会显示店铺数据，而不再是模糊的预览。

如需确认，点击菜单底部的版本号（**v 2.0.0**，手机上为 **版本 2.0.0**），即可打开 **关于 WCPOS**。

<JourneyShot manifest={manifest} device="tablet" step={2} maxWidth={368} alt="Pro 店铺的关于 WCPOS 页面：应用版本和平台，服务器下的 WCPOS Pro 插件、WooCommerce 和 WordPress 版本，以及许可证下的状态 Pro" />

- **许可证** 中应显示 **状态**：**Pro**。未激活任何密钥时，显示 **免费版**。
- **服务器** 会列出 **WCPOS Pro 插件** 及其版本（免费插件显示为 **WCPOS 插件**）。这只能确认插件已安装：无论许可证是否已激活，都会显示。

3. **查看演示** — 在 WCPOS 演示店铺中打开同一页面，方便您在购买前试用。

## 更新 {#updates}

与其他插件一样，Pro 的新版本会出现在 **仪表盘** > **更新** 和 **插件** 页面中。您也可以从[下载](https://wcpos.com/account/downloads)页面下载最新的 zip 文件。

**插件** 页面中的 Pro 行会显示许可证状态：有效且可接收更新、未激活或已过期。

## 遇到问题时 {#troubleshooting}

### 更新后提示再次付费购买 Pro {#pro-shows-free}

只要网站没有运行 Pro 插件，或没有在该网站激活许可证密钥，POS 就会显示免费版及 **升级到 Pro** 提示。再次购买前，请检查这两项：

1. 在 WP Admin 中打开 **Plugins**。列表中应有 **WCPOS Pro – Point of Sale for WooCommerce**，且处于启用状态。如果列表中有它但未启用，请按 **Activate**。如果列表中只有 **WCPOS – Point of Sale for WooCommerce**，说明 Pro 已被移除：[重新安装](#installation)。删除 Pro 会保留许可证密钥，因此重新安装后密钥仍会恢复（请参阅[卸载 Pro 和您的数据](#uninstalling-pro)）。
2. 前往 **POS** > **设置**，在 **账号** 下打开 **许可证**。如果看到 **许可证密钥** 字段和 **激活** 按钮，说明密钥尚未在此网站激活：从[许可证](https://wcpos.com/account/licenses)页面复制并粘贴密钥，然后点击 **激活**。

然后重新加载 POS。**About WCPOS** 中的 **Status** 应显示 **Pro**：请参阅[检查 POS 是否运行 Pro](#checking-licence-status)。如果激活时显示了其他消息，下面列出了常见情况。如果更新无法安装，请查看下一项。

### 有更新提示，但无法下载 {#update-wont-download}

WordPress 会向所有网站提供 Pro 新版本提示，无论是否拥有许可证。实际下载时才会检查许可证，以下情况会拒绝下载：

- 此网站没有已激活的许可证密钥，或
- 许可证已过期。

查看 **Plugins** 页面上的 Pro 条目。**Your WCPOS Pro license is inactive.** 表示此网站尚未激活该密钥：前往 **POS** > **Settings** > **License** 激活，然后再次更新。**Your WCPOS Pro license has expired.** 表示许可证已过期：前往[账户](https://wcpos.com/account/licenses)续订，然后再次更新。如果条目显示许可证有效且已激活，但下载仍然失败，请发送邮件至 **support@wcpos.com**。请参阅 [LICENSE301](../error-codes/LICENSE301.mdx)。

<details>
<summary>无法完成购买，或想更改套餐</summary>

如果无法创建 wcpos.com 账户或完成购买，请发送邮件至 **support@wcpos.com**。如果要将 Yearly 许可证改为 Lifetime 许可证，也请联系 **support@wcpos.com**：他们负责许可证和账单事宜。请参阅[联系支持](../support/index.mdx#where-to-ask)。

</details>

<details>
<summary>许可证页面显示来自 wcpos.com 的消息</summary>

该消息来自负责检查密钥的许可证服务器。请检查粘贴的密钥前后是否有空格，并确认密钥来自您的[许可证](https://wcpos.com/account/licenses)页面。

</details>

<details>
<summary>许可证已达到激活次数上限</summary>

一份许可证可在 2 个网站上激活：一个正式网站和一个开发网站。子域名单独计数，因此 `example.com`、`staging.example.com` 和 `dev.example.com` 算作三个网站。内置开发、测试和正式网站的主机服务经常会遇到这种情况。请在[许可证](https://wcpos.com/account/licenses)页面查看网站并释放激活名额，或发送邮件至 **support@wcpos.com**，可按需申请额外激活名额。

</details>

<details>
<summary>激活因网络错误而失败</summary>

激活请求会从您用于访问 WP Admin 的浏览器直接发送到 wcpos.com。请确认此浏览器可以打开 wcpos.com，然后关闭广告或隐私拦截工具，再次点击 **激活**，也可以换用其他浏览器。

</details>

<details>
<summary>Pro 从不提示更新</summary>

更新检查请求会从 WordPress 服务器发送到 `updates.wcpos.com`。安全插件或主机的防火墙可能会拦截这些请求，请联系主机服务商，允许向 `updates.wcpos.com` 发送出站请求。

</details>

<details>
<summary>激活后仍显示升级提示条</summary>

重新加载 POS（刷新页面，或关闭并重新打开应用）。如果 **About WCPOS** 仍显示 **Status** **Free**，请打开 WP Admin，前往 **POS** > **Settings**，然后在 **Account** 下打开 **License**。确认页面显示 **License … has been activated.**。如果显示的是 **License Key** 字段，请按照[更新后再次被要求购买 Pro](#pro-shows-free)中的步骤操作。

</details>

<details>
<summary>许可证已过期</summary>

Pro 会继续运行，POS 中的所有功能都不会关闭。**插件** 页面会显示“您的 WCPOS Pro 许可证已过期。请续订以接收更新。”从[账号](https://wcpos.com/account/licenses)续订后即可重新获取更新，密钥保持不变。

</details>

<details id="new-domain">
<summary>将网站迁移到新域名</summary>

先释放旧网站的激活名额：在 WP Admin 中前往 **POS** > **设置**，在 **账号** 下打开 **许可证**，然后点击 **停用**。再在新网站上激活同一个密钥。仅停用插件本身不会释放激活名额。如果旧网站已不存在，请从[许可证](https://wcpos.com/account/licenses)页面释放名额，或发送邮件至 **support@wcpos.com**。

</details>

<details id="uninstalling-pro">
<summary>卸载 Pro 对数据的影响</summary>

删除 Pro 插件会移除 Pro 自身的运行数据和翻译文件。Pro 设置（包括许可证密钥）和店铺会保留，因此重新安装后即可继续使用。订单和产品数据始终不会受到影响。

只有在免费插件也不再安装的情况下，才会移除 Pro 与免费插件共用的翻译文件。

如果免费插件也未安装，删除 Pro 还会清除 POS 与其共享的数据：收银员登录信息、每台收银台重建的同步数据，以及打印队列。所有收银员都会退出登录，因此每台收银台都必须重新登录。

如果要彻底清除数据，连同设置、许可证密钥和店铺一起移除，请在删除插件前开启完全清除：将 `define( 'WCPOS_REMOVE_ALL_DATA', true );` 添加到 `wp-config.php`，或将 `wcpos_remove_all_data` 选项设为 `yes`。两者都设置时，以常量为准。完全清除操作无法撤销。

</details>
