需要回退到插件的早期版本时，请参照本页操作，最常见的情况是从 2.0 回退到 1.11。在 WP Admin 中关闭自动更新，下载所需版本，再上传以覆盖当前版本。整个过程不会删除任何内容，订单、设置和收据模板都会保留。

:::tip 请先咨询我们
请通过 [Discord](https://wcpos.com/discord) 或 support@wcpos.com 告诉我们遇到了什么问题。升级当天遇到的大多数问题都有比回退更快捷的解决办法。
:::

## 开始之前 {#before-you-start}

- **同步所有能够同步的收银设备。** 在每台收银设备上打开 POS，让它将暂存的销售记录发送到店铺。等到 **待发送的更改** 显示为 0、没有面板要求您作出选择，且没有未同步的未结订单后，再开始操作（[如何检查](#check-sync)）。如果回退是因为某台运行 1.11 的收银设备仍有未发送的销售记录，该设备必须等恢复到 1.11 后才能发送：先回退，再让它同步。
- **检查哪些收银设备使用应用。** 已更新到 2.0 的桌面或移动应用无法连接 1.11 插件，会显示 [AUTH331](../error-codes/AUTH331.mdx)，而应用商店不提供旧版应用。请安排这些设备通过浏览器访问 `yourdomain.com/pos` 使用 POS，直到再次升级。
- **请管理员登录。** 您需要一个能够安装插件的 WordPress 管理员账号。
- **如果使用 WCPOS Pro，只需回退 WCPOS Pro。** 它已包含免费插件。

如果要从 2.0 回退，请同时阅读升级页面中的[回退](./upgrading-to-2.mdx#rolling-back)说明。

### 确认收银设备已发送所有内容 {#check-sync}

在每台收银设备上打开[店铺健康状况](../support/store-health.mdx#database)，查看 **数据库** 选项卡。这里仅统计当前登录的收银员和店铺，因此请逐一检查使用该设备的每位收银员，以及他们使用的每家店铺：

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[40, 0], [140, 0], [170, 0]]} alt="平板上的店铺健康状况，已打开数据库选项卡：可以开始销售、此设备上的记录、已用存储空间，以及 0 项待发送的更改">

1. **店铺健康状况**：菜单底部的脉搏图标。
2. **数据库**：在平板或电脑上，店铺健康状况默认打开此选项卡。
3. **待发送的更改**：数值为 **0**、数字下方没有面板，且没有未同步的未结订单时，表示此收银设备已发送所有内容。如果大于 0，请保持 POS 打开并联网，以便发送。未结订单不计入此数值：请对每个未结订单点击[同步订单](../pos/cart/open-orders.mdx#sync-order)。面板会列出店铺拒绝的更改或需要您选择如何处理的更改，请先处理这些项目（[需要您处理的情况](../support/store-health.mdx#needs-attention)）。

## 关闭自动更新 {#turn-off-auto-updates}

如果开启自动更新，WordPress 会自行重新安装最新版本。

1. 前往 **WP Admin → 插件**。
2. 在 WCPOS（或 WCPOS Pro）所在行查看 **自动更新** 列。如果显示 **禁用自动更新**，请点击它。显示 **启用自动更新** 时，表示自动更新已关闭。

## 下载所需版本 {#download}

将所需版本下载为 `.zip` 文件，并保持压缩状态。WordPress 安装的是 `.zip` 文件，而不是文件夹。请按您使用的插件选择对应步骤：

- **WCPOS：** [从 WordPress.org 下载](#download-free)。
- **WCPOS Pro：** [从 wcpos.com 账号下载](#download-pro)。

### WCPOS：从 WordPress.org 下载 {#download-free}

1. 打开 WordPress.org 上的 [WCPOS 高级视图](https://wordpress.org/plugins/woocommerce-pos/advanced/)。
2. 滚动到 **高级选项**。在 **历史版本** 下选择所需版本。
3. 点击 **下载**。

请选择目标版本系列中的最新发布版：如果要从 2.0 回退，应选择最新的 **1.11** 发布版，而不是更早的 1.x。WordPress.org 会提示历史版本可能不安全或不稳定，而该系列的最新发布版包含所有修复。

### WCPOS Pro：从 wcpos.com 账号下载 {#download-pro}

1. 登录您的 [wcpos.com](https://wcpos.com/account/downloads) 账号，打开 **下载**。
2. 在 **版本历史** 中找到所需版本。从 2.0 回退时，请使用最新的 1.11 发布版。
3. 点击该行的 **下载**。

可下载的版本取决于您的许可证。许可证过期后，仍可下载到期前发布的版本；之后发布的版本会呈灰色，并显示 **此版本发布于您的许可证到期之后。**

## 上传以覆盖当前版本 {#install}

:::warning 不要先删除插件
上传 `.zip` 文件以覆盖现有插件，即可保留所有内容。从 **插件** 页面删除插件会触发 WCPOS 的清理操作：所有收银员都会退出登录，因此每台收银设备都需要重新登录；同步数据也会被清除，随后由各设备重新构建。即便如此，订单、设置、收据模板和收银机仍会保留，除非网站设置为在卸载时移除所有 WCPOS 数据。没有必要删除插件。
:::

1. 前往 **WP Admin → 插件**，点击页面顶部的 **添加插件**。
2. 点击 **上传插件**，选择下载的 `.zip` 文件，然后点击 **立即安装**。
3. WordPress 会显示 **此插件已安装。** 并排列出两列：
   - **当前**：目前安装的版本。
   - **已上传**：`.zip` 文件中的版本。请确认其 **版本** 行显示的是所需版本。

   下方会显示 **您正在上传当前插件的较旧版本。**
4. 点击 **使用上传的插件替换当前插件**。
5. WordPress 替换插件后会显示 **插件降级成功。** 如果出现 **启用插件**，请点击它。否则，说明插件之前已启用，并会保持启用状态。

## 回退之后 {#after}

1. **让使用应用的收银设备改用浏览器。** 对于应用版本为 2.0 的收银设备，请改为在浏览器中打开 `yourdomain.com/pos`（参见[开始之前](#before-you-start)）。
2. **在每台收银设备上打开 POS**，等待首次同步完成。使用浏览器的收银设备会在下次打开 POS 时加载您安装的版本。
3. **保持自动更新关闭**，直到准备好再次更新。届时请按照[升级到 2.0](./upgrading-to-2.mdx)操作，并在完成后重新开启自动更新，否则后续修复不会自动安装。

在 2.0 中创建的订单是普通的 WooCommerce 订单，会原样保留。在 2.0 中记录的收银班次和结班记录也会保留在数据库中，但 1.11 不会显示它们。

## 遇到问题时 {#if-something-goes-wrong}

**新版本又自动装回来了。** 自动更新仍处于开启状态。请[关闭自动更新](#turn-off-auto-updates)，然后重新上传所需版本。

**所需版本在版本历史中呈灰色。** 该版本发布于许可证到期之后。请续订许可证，或选择到期前发布的版本。

**收银设备显示 [AUTH331](../error-codes/AUTH331.mdx)。** 该设备正在使用 2.0 应用连接您的 1.11 插件。请改为在该设备的浏览器中打开 POS。

<details>
<summary>开发者说明：使用 WP-CLI 回退</summary>

在安装了 [WP-CLI](https://developer.wordpress.org/cli/commands/plugin/install/) 的服务器上，以下命令会将免费插件替换为 WordPress.org 上的指定版本，而不执行卸载操作：

```bash
wp plugin install woocommerce-pos --version=<version> --force
```

`--version` 用于选择发布版本；`--force` 会直接覆盖已安装的副本，不再询问。对于 WCPOS Pro，请按上述步骤从账号下载 `.zip` 文件，并用其路径替代插件名称：`wp plugin install /path/to/woocommerce-pos-pro.zip --force`。

</details>
