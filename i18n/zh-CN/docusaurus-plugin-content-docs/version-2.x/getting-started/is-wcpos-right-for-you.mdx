WCPOS 是适用于 WooCommerce 的销售点（POS）系统。您可以在浏览器中使用，也可以使用 Windows、macOS 或 Linux 桌面应用，iOS 和 Android 应用目前处于测试阶段。它与您的网店共用商品目录、库存和价格，并将每笔销售记录为 WooCommerce 订单。

在 2025 年十一月之前，此插件在 wordpress.org 上以 WooCommerce POS 的名称列出；插件别名仍为 `woocommerce-pos`，早期的评论、论坛帖子和教程也使用该名称。

本页解答安装前的常见问题：[适合哪些用户](#who-its-for)、[不适合哪些用户](#who-its-not-for)、[使用要求](#what-you-need)、[费用](#what-it-costs)、[界面介绍](#what-it-looks-like)、[与其他方案的比较](#how-it-compares)以及[如何试用](#try-it)。

## WCPOS 适合哪些用户 {#who-its-for}

WCPOS 适合已通过 WooCommerce 销售商品，并希望在线下销售时共用同一份库存的商家。

- **同时在线上销售的实体店、柜台、集市摊位或快闪店。** 无论交易发生在网站上还是收银台，都使用同一份商品目录、库存数量和订单列表。
- **希望将销售数据保存在自己数据库中的店铺。** WCPOS 是一款 WordPress 插件；订单、客户和商品都保存在您自己的 WooCommerce 系统中，而非第三方服务中。
- **配有钱箱的柜台。** 免费插件支持一个收银机，由柜台上的所有设备共用，可管理备用金、现金存入和取出，并进行日终盘点和生成交班报告。Pro 可为每个钱箱增设一个收银机。
- **电话订购或批发业务柜台。** 查找现有客户、为其创建订单，并以现金或银行卡收款；使用 Pro 还可发送[电子邮件账单](../payment/gateways/email-invoice.mdx)，让客户通过链接付款。
- **拥有多个收银台或多个营业地点的商家。** 每台设备都保存一份商品目录，因此收银台能保持快速响应。Pro 支持更多收银机和[更多店铺](../stores/index.mdx)，每个店铺都可设置自己的地址、标志、税号和收据模板。所有店铺共用同一份库存数量；如需按地点分别管理库存，可添加 [ATUM](../extensions/atum.mdx)。

## WCPOS 不适合哪些用户 {#who-its-not-for}

- **您未使用 WooCommerce。** WCPOS 需要一个已安装 WooCommerce 的 WordPress 网站。它不适用于 Shopify、Magento 或独立运行的店铺。
- **您现在就需要经过认证的收银系统。** WCPOS 2.0 尚未获得任何国家的税务认证，包括法国的 NF525 和西班牙的 VeriFactu。[税务合规](../reference/fiscal-compliance.mdx)按国家介绍了当前情况。认证要求无法通过其他方式绕过。
- **您需要完全离线地发起并完成一笔销售。** 能否收款取决于结账界面商品上方是否有订单号。**有订单号**，表示销售记录在断线前已送达店铺：您可以收取现金、通过自备终端收取银行卡付款，或使用其他在收银台记录的付款方式。**没有订单号**，例如离线时发起的销售，请将其保留在设备上，待连接恢复后再收款。已连接的读卡器和在线支付网关始终需要连接。参见[离线模式](./offline.mdx#take-payment-offline)。
- **您需要自助终端模式或供应商提供的硬件套装。** WCPOS 没有自助终端模式，也不销售硬件：它可在您选择的电脑、平板电脑和手机上运行，并搭配任何[受支持的打印机、扫描器和钱箱](../hardware/index.mdx)。

## 使用要求 {#what-you-need}

| 要求 | 最低配置 |
|---|---|
| WordPress | 5.6 |
| WooCommerce | 9.0（自 WCPOS 2.0 起要求） |
| PHP | 7.4（推荐 8.x） |
| 设备 | 任何现代浏览器，或 Windows、macOS、Linux 桌面应用；iOS 和 Android 应用目前处于测试阶段 |

收据打印机、条码扫描器和钱箱均为可选设备。参见[安装](./installation.mdx#server-requirements)和[硬件](../hardware/index.mdx)。

首次下载完成后，同步对服务器的资源消耗取决于数据的变化量，而非商品目录的规模：参见[同步性能](../reference/sync-performance.mdx#the-four-rules)。

## 费用 {#what-it-costs}

免费插件支持现金收款、自备终端银行卡收款及拆分付款，可管理一个收银机及其钱箱，并打印收据。WCPOS Pro 另提供读卡器连接、退款、库存和价格编辑、订单历史、客户显示屏，以及更多收银机和店铺。

- **WCPOS（免费插件）：** $0。采用 GPL-3.0 许可证开源，可从 [WordPress 插件目录](https://wordpress.org/plugins/woocommerce-pos/)安装。它支持销售收款、打印收据，并将每笔销售记录为 WooCommerce 订单，WCPOS 不收取交易手续费。
- **WCPOS Pro，年度许可证：** $129，一次性支付。包含一年的更新和优先支持。不会自动续费，到期后 Pro 仍可继续使用，只是不再提供新更新和优先支持。
- **WCPOS Pro，终身许可证：** $399，一次性支付，永久更新。

每个 Pro 许可证可在两个网站上激活：一个正式网站和一个开发网站。Pro 涵盖该网站上的所有设备和收银员。以上价格截至 2026 年十一月，来自 [wcpos.com/pro](https://wcpos.com/pro)。银行卡处理费由您的支付服务商设定，而非 WCPOS。

如果您只需要一个能记录销售的收银系统，免费插件就足够了。[免费版与 Pro 对比](./free-vs-pro.mdx)逐项列出了所有区别，[安装 WCPOS Pro](./pro-license.mdx)则介绍了激活步骤。

## 界面介绍 {#what-it-looks-like}

这是平板电脑上的 POS 界面，购物车中有一件商品。左侧菜单可打开其他界面。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="平板电脑上的 POS，购物车中有一件商品：左侧菜单、搜索框和商品网格，以及包含店铺名称、收银员头像、客户和结账按钮的购物车">

1. **收银机状态栏** — 显示此设备所服务的店铺；当收银机需要您处理时，还会显示 **已关闭** 或 **离线** 等状态。参见[店铺、收银机和设备](../stores/registers-and-devices.mdx)。
2. **您的头像** — 打开收银员面板，您可从中进入收银机面板。参见[开启收银机](../pos/register/index.mdx)。
3. **搜索** — 输入名称或 SKU，或使用摄像头或扫描器扫描条码。参见[商品面板](../pos/product-panel/index.mdx)。
4. **商品** — 您的 WooCommerce 商品目录，价格和库存与网站保持一致。点按商品即可将其加入购物车。
5. **客户** — 本次销售的客户，从您的 WooCommerce 客户中选择。参见[购物车](../pos/cart/index.mdx)。
6. **结账** — 收取现金、记录通过自备终端收取的银行卡付款，或拆分付款。Pro 还支持已连接的读卡器及店铺中的其他付款方式。参见[结账](../pos/checkout/index.mdx)。
7. 菜单中的 **商品** — 下方是 **订单**、**客户** 和 **优惠券**：这些界面用于在 POS 中管理店铺，需要 Pro；免费插件会显示预览。参见[免费版与 Pro 对比](./free-vs-pro.mdx#management-screens)。
8. **报表** — 查看当天的销售和收银机交班记录。查看更早日期、其他收银机和其他店铺的数据需要 Pro。参见[报表](../reports/index.mdx)。
9. **设置** — 配置此设备的打印机、读卡器、条码扫描器和客户显示屏。参见[设置](../settings/index.mdx)。

</JourneyShot>

店铺有多个收银机时，收银机状态栏还会显示此设备当前使用的收银机名称。

启用 **开启和关闭收银机** 后，收银员面板会显示钱箱中的现金；收银机面板可用于存入和取出现金，随后盘点钱箱、关闭收银机并生成交班报告。参见[开启收银机](../pos/register/index.mdx)。

在手机上，商品和购物车分别位于屏幕底部的两个选项卡中。

<JourneyShot manifest={manifest} device="phone" step={1} maxWidth={390} alt="手机上的 POS 购物车选项卡：未结订单、客户、一件商品及其数量，以及结账按钮">

1. **未结订单** — 此收银机上正在进行的销售。点按一个订单即可切换到该订单，其他订单会保留等待处理。参见[未结订单](../pos/cart/open-orders.mdx)。
2. **客户** — 点按可选择其他客户。
3. **数量** — 点按可输入数量。参见[订单行项目](../pos/cart/line-items.mdx)。
4. **结账** — 显示总计金额。按此按钮即可收款。

## 与其他方案的比较 {#how-it-compares}

[wcpos.com/compare](https://wcpos.com/compare)提供了 WCPOS 与各主要 WooCommerce 收银方案的比较：[Oliver POS](https://wcpos.com/compare/oliver-pos)、[WooCommerce 官方 POS](https://wcpos.com/compare/woocommerce-pos)、[Square](https://wcpos.com/compare/square)、[Jovvie](https://wcpos.com/compare/jovvie)、[Vitepos](https://wcpos.com/compare/vitepos)、[YITH Point of Sale](https://wcpos.com/compare/yith-pos) 和 [FooSales](https://wcpos.com/compare/foosales)。每篇比较均由 WCPOS 的开发者撰写，事实依据来自对方供应商的定价页面和 wordpress.org，注明了日期，并说明在哪些情况下其他产品是更好的选择。

## 试用 {#try-it}

[演示店铺](https://demo.wcpos.com/pos)运行的是 WCPOS Pro，登录用户名和密码为 `demo` / `demo`，因此也能展示 Pro 界面。在免费插件中，每个 Pro 界面上的 **查看演示** 按钮都会打开演示店铺中的对应界面。

要在自己的店铺中试用，请从 WP Admin 的 **插件** 中安装免费插件：[安装](./installation.mdx#installing-the-plugin)中有具体步骤。
