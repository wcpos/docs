WCPOS 有两个版本。**免费插件** 支持日常销售收银：现金、通过独立刷卡终端收取的银行卡付款、一台收银机及其钱箱、收据、购物车内使用优惠券，以及断网后继续销售。**WCPOS Pro** 则增加了在 POS 中管理店铺的界面（商品、订单、客户、优惠券，以及今天之前的报表）、退款、已连接的读卡器和其他支付网关、客户显示屏，以及更多收银机和店铺。

如果您只需要记录销售的收银系统，免费插件就已足够。如果还想修改库存和价格、查找历史订单、为客户退款，或通过已配对的读卡器收款，则需要 Pro。价格和许可证到期后的情况，请参阅[价格](#pricing)。

## Pro 功能在免费插件中的显示方式 {#on-the-free-plugin}

免费插件会在相应位置展示各项 Pro 功能，并提供体验入口。这些界面上的操作不会更改您的店铺。

### Pro 功能界面 {#pro-screen}

打开 **商品**、**订单**、**客户** 和 **优惠券** 时，会看到经过模糊处理的实际界面，上方覆盖着一张卡片。

1. **您正在使用 WCPOS 免费版。** — 免费插件每个界面顶部的横幅。在手机上，其后的文字和 **查看 Pro 新增功能** 会隐藏。
2. **升级到 Pro** — 覆盖在模糊界面上的卡片，下方有放大图。
3. **商品** — 菜单中的四个 Pro 界面之一，另外三个是 **订单**、**客户** 和 **优惠券**。

### 报表 {#reports}

免费插件的[报表](../reports/index.mdx)显示此设备所用收银机今天的销售数据。查看以往日期、其他收银机和其他店铺的数据需要 Pro：点击锁定的选项即可了解原因。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[100, 0], [0, 0], [100, 0], [215, 0], [0, 0]]} maxWidth={560} alt="免费插件中的报表日期选择器：已选中今天，其他日期范围和所有其他日期均呈灰色并带锁图标，显示查看以往日期需要 WCPOS Pro 提示和查看 Pro 按钮">

1. **今天** — 免费插件报表涵盖的范围：您的收银机今天的销售数据。
2. **昨天** 及其他日期范围 — 已锁定，点击即可了解原因。
3. **日历** — 只能选择今天。
4. **查看以往日期需要 WCPOS Pro** — 提示文字。同样，收银机菜单会显示 **查看其他收银机需要 WCPOS Pro**，店铺菜单会显示 **查看其他店铺需要 WCPOS Pro**。在结班记录中则显示 **查看以往结班记录需要 WCPOS Pro**。
5. **查看 Pro** — 打开 wcpos.com 上的 WCPOS Pro 页面。

</JourneyShot>

### 客户显示屏 {#customer-display}

客户显示屏是第二块屏幕，可在收银时向客户展示购物车内容。您可以在 **设置 › 客户显示屏** 中配对。免费插件的该页面会提示客户显示屏是 Pro 功能。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[130, 0], [260, -13], [-40, 0]]} maxWidth={640} alt="免费插件中的设置、客户显示屏页面：显示客户显示屏是 Pro 功能，以及了解客户显示屏链接">

1. **客户显示屏** — 位于 **设置** 中，点击菜单底部的齿轮图标即可进入设置。
2. **客户显示屏是 Pro 功能。** — 使用 Pro 时，可在此页面配对显示屏。如果已安装 Pro，但版本过旧，不支持显示屏，则会显示 **客户显示屏需要较新版本的 WCPOS Pro。请在 WordPress 中更新 Pro 插件。**
3. **了解客户显示屏** — 在浏览器中打开[客户显示屏](../hardware/customer-display/index.mdx)指南。

</JourneyShot>

## 免费插件包含哪些功能 {#whats-in-the-free-plugin}

从 [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) 获取的免费插件涵盖从添加第一件商品到出具收据的完整销售流程：现金和银行卡、一台收银机、购物车内使用优惠券、收据和打印、离线销售、条码扫描及客户税号，所有平台均可使用。

  </FeatureCard>
  <FeatureCard icon="calculator" title="一台收银机">

## Pro 新增哪些功能 {#what-pro-adds}

Pro 解锁 POS 的其余功能：管理界面、更多收款方式，以及更多收银机和店铺。

### 管理界面 {#management-screens}

| 界面 | Pro 提供的功能 |
|---|---|
| **[商品](../products/index.mdx)** | 直接在商品列表中修改库存和价格。 |
| **[订单](../orders/index.mdx)** | 查找历史订单，重新打开、编辑、重新打印收据，并退款。 |
| **[客户](../customers/index.mdx)** | 添加客户并编辑其详细信息。 |
| **[报表](../reports/index.mdx)** | 查看以往日期、所有收银机和所有店铺的数据，以及结班历史记录。 |
| **[优惠券](../coupons/index.mdx)** | 查找优惠券，并在拥有相应权限时创建新优惠券。 |

### 支付网关 {#payment-gateways}

免费插件可记录现金付款，以及通过独立刷卡终端收取的银行卡付款。Pro 还支持通过已连接的读卡器和其他支付服务收款。

使用 Pro 时，您可以在[收银台设置](../settings/wp-admin/checkout.mdx)中，为 POS 启用店铺的其他支付方式（WooCommerce 称之为网关）。下列 WCPOS 支付选项均需安装各自对应的插件。

- 购买许可证即可获得 [Discord](https://wcpos.com/discord) 上的 **优先支持**。

## 价格 {#pricing}

Pro 可在 [wcpos.com/pro](https://wcpos.com/pro) 购买。每份许可证可用于两个网站：一个正式网站和一个开发网站。

- **年度许可证** — $129。提供一年的更新和优先支持，不会自动续费。
- **终身许可证** — 一次性支付 $399，永久获得更新。

价格截至 2026 年十一月。

年度许可证到期后，不会关闭任何功能：您现有的 Pro 版本及其全部功能仍可继续使用。新更新和优先支持会暂停，续费后恢复。

:::tip 先体验再购买
每个 Pro 界面上的 **查看演示** 按钮都会打开 WCPOS 演示店铺 [demo.wcpos.com/pos](https://demo.wcpos.com/pos) 中的对应界面。
:::

## 准备好升级了吗？ {#ready-to-upgrade}

[安装 WCPOS Pro](./pro-license.mdx) 提供下载和激活步骤。

- **Pro 1.8 及更高版本** 是独立插件，包含免费插件的所有功能。安装时保留免费插件，无需事先移除任何内容（请参阅[在免费插件基础上安装 Pro](./installation.mdx#pro-over-free)）。安装完成后，可以停用并删除免费插件。
- **1.8 之前的 Pro 版本** 是与免费插件配合运行的附加组件。从这些版本升级时，也请按照相同步骤操作。
