WCPOS 2.0 是一次重大更新：全新的收银界面、结账流程和钱箱功能。本页面向负责点击 **更新** 的人员。请先读完本页再操作。

:::warning 先同步所有收银设备
收银设备首次打开 2.0 时，会清除该设备上的 1.11 数据。届时尚未发送到店铺的销售记录将会丢失。请等所有收银设备完成同步后再更新。

店铺已经更新，但某台收银设备仍有未发送的销售记录？请参阅 [1.11 收银设备仍有未发送的销售记录](#unsent-sales)。
:::

## 现在可以升级吗？ {#can-you-upgrade-today}

打开 **WP Admin → 插件**，检查以下两项。

- **WooCommerce 为 9.0 或更高版本。** 2.0 需要此版本。若低于 9.0，请参阅 [店铺尚未准备就绪](#if-your-store-isnt-ready-yet)，不要先更新 WCPOS。
- **如果使用刷卡终端扩展，您已拥有 WCPOS Pro。** 从 2.0 起，Stripe Terminal、SumUp、Mollie Terminal 和其他终端扩展都需要 Pro。如果您正在使用这些扩展但没有 Pro，请先暂停更新，阅读 [免费版与 Pro 版对比](./free-vs-pro.mdx)。

如果 WooCommerce 已为 9.0 或更高版本，并且您不使用刷卡终端扩展，或已拥有 WCPOS Pro，请继续阅读 [点击更新之前](#before-you-click-update)。

## 点击更新之前 {#before-you-click-update}

1. **同步所有收银设备。** 打开每台收银设备，然后从菜单打开 **店铺健康 → 数据库**。其中的 **等待发送的更改** 必须显示 **0**，且没有 [需要您作出决定的面板](../support/store-health.mdx#needs-attention)。数值大于 0 表示仍有数据未发送到店铺：请保持设备联网并等待。此计数不包括未结订单：请逐一完成订单，或点击订单上的 **保存到服务器**（在 2.0 中为 [同步订单](../pos/cart/open-orders.mdx#sync-order)）。这两处都只显示当前登录人员的数据：请针对使用该设备的每位收银员，在其使用的每个店铺和每个收银台上重复这些操作。收银设备打开 2.0 时，尚未发送到店铺的销售记录、未结订单或更改都会丢失。
2. **备份网站**，或请托管服务商创建还原点。更新不会更改订单，但重大更新前应做好回退准备。
3. **选择业务清闲的时段。** 插件更新后，每台收银设备都必须升级到 2.0，才能再次将销售记录发送到店铺；旧版本上结账到一半的交易则需要重新录入。
4. **如果使用 WCPOS Pro，请检查许可证是否有效**，位置在 **WP Admin → POS → 设置 → 许可证**。只有持有效许可证才能收到 Pro 更新。请参阅 [安装 WCPOS Pro](./pro-license.mdx)。
5. **告知收银员折扣操作的变化。** 如果他们通过添加 *负数费用* 来减免金额，这种方式将不再可用。2.0 改为提供 **添加折扣** 功能。请参阅 [升级后的即时变化](#what-changes-on-day-one)。
6. **如果使用刷卡终端扩展，请确认它已发布 2.0 版本。** Stripe Terminal、SumUp 和 Mollie Terminal 均已发布。请按下文步骤，在更新 WCPOS 后立即更新扩展。

## 更新插件和收银设备 {#updating}

1. **更新插件。** 使用免费版的网站应更新 **WCPOS**。使用 Pro 时，只需更新 **WCPOS Pro**：它已包含免费插件，并会停用单独安装的免费版。系统会显示相关提示，之后您可以删除免费插件。
2. **更新刷卡终端扩展**（如果使用），将其升级到 2.0 版本。尚未更新的扩展仍会显示在结账界面的 **旧版** 选项卡上，但无法从收款面板控制读卡器。
3. **将所有收银设备升级到 2.0。** 浏览器收银设备只需重新加载页面，即可从店铺加载 2.0。按平常的更新方式将桌面和移动应用更新到 2.0，然后打开应用。请等待每台设备完成首次同步。
4. **确认每台收银设备均为 2.0。** 点击菜单底部的版本号（**v 2.0.0**，手机上则为 **版本 2.0.0**），即可打开 **关于 WCPOS**。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-40, 0], [-40, -10], [-40, 10], [-40, 0], [162, 0]]} alt="Pro 店铺的关于 WCPOS 页面：应用版本 2.0.0、平台为 Web，服务器下列出 WCPOS Pro 插件、WooCommerce 和 WordPress 的版本，许可证下的状态为 Pro，以及关闭和发行说明按钮">

1. **应用版本** — 此收银设备上的 POS 版本，必须以 2.0 开头。
2. **WCPOS Pro 插件** — 店铺上的插件，免费网站上显示为 **WCPOS 插件**。它也必须为 2.0 版本。
3. **WooCommerce** — 9.0 或更高版本。
4. **状态** — **Pro** 或 **免费版**。如果使用 Pro，但此处显示 **免费版**，请参阅 [安装 WCPOS Pro](./pro-license.mdx)。
5. **发行说明** — 各版本的变更内容。

</JourneyShot>

应用和插件都必须为 2.0。版本不一致的收银设备会停留在提示此问题的界面：

- **1.11 应用连接 2.0 店铺时**，会要求更新应用。请参阅 [SYNC341](../error-codes/SYNC341.mdx)。如果设备仍有未发送的销售记录，请暂勿更新，参阅 [1.11 收银设备仍有未发送的销售记录](#unsent-sales)。{/* pending: docs#675 */}
- **2.0 应用连接仍为 1.11 的店铺时**，会报告 **AUTH331**。请更新插件后重新连接。参阅 [AUTH331](../error-codes/AUTH331.mdx)。

## 升级后的即时变化 {#what-changes-on-day-one}

收银员首次打开 POS 时，会看到全新的收银界面。大部分操作与之前相同；以下是他们会注意到的变化。完整列表请参阅 [2.0 新功能](./whats-new.mdx)。

### 折扣取代负数费用 {#discounts}

费用不再允许为负数。要减免金额，请点击购物车中的 **+**，选择 **添加折扣**。已有负数费用的订单不受影响。

<details>
<summary>找到添加折扣和优惠券功能</summary>

1. **收银台栏** — 显示此收银设备所属的店铺；店铺有多个收银台时，还会显示收银台。请参阅 [店铺、收银台和设备](../stores/registers-and-devices.mdx)。
2. **+** — 购物车的添加菜单，用于添加商品卡片以外的项目。
3. **添加费用** — 费用现在只能增加订单金额。
4. **添加折扣** — 按金额或百分比减免订单金额，也可在其 **优惠券** 选项卡上使用 WooCommerce 优惠券代码。收银时使用优惠券不再需要 Pro。请参阅 [购物车折扣](../pos/cart/discounts.mdx)。
5. **小计** — 付款前的订单金额。
6. **结账** — 打开下文介绍的收款面板。

### 通过收款面板结账 {#checkout}

点击 **结账** 会在购物车旁打开数字键盘，不再打开 WooCommerce 的付款页面。输入顾客交付的金额后，即会显示找零金额。一笔交易可以拆分为现金和银行卡支付。

<details>
<summary>找到支付方式、拆分和旧版功能</summary>

1. **付款** — 店铺收银时接受的支付方式，以及与此收银设备配对的读卡器。请参阅 [收款面板](../pos/checkout/payment-methods.mdx)。
2. **旧版** — 仍使用各自付款页面的网关，包括尚未更新的终端扩展。请参阅 [旧版选项卡](../pos/checkout/legacy-tab.mdx)。
3. **拆分** — 分多笔收取订单款项。请参阅 [拆分付款](../pos/checkout/split-payments.mdx)。

5. **数字键盘** — 输入顾客交付的金额。
6. **收款** — 记录付款。请参阅 [结账](../pos/checkout/index.mdx)。

### 其他即时变化 {#also-new}

- **全新外观。** 表单和选择器以面板形式滑入。**设置 → 主题** 中的 **缩放** 设置可调整 POS 界面大小以适配设备。您可以将购物车放在左侧，并添加自己的快捷筛选按钮。请参阅 [新功能：全新收银界面](./whats-new.mdx#a-new-register)。
- **WooCommerce Analytics 会在 POS 订单付清后才将其计入统计。** 收银设备上尚未结清或仅支付部分金额的订单不再计入销售额，因此原本包含这些订单的总额会降低。
- **收据包含收银台名称和软件版本。** 退款会打印单独的收据，标题为 **退款**，并注明所冲减的原销售记录。自定义收据模板仍可正常使用，但只有在您添加新字段后才会显示这些详情。请参阅 [收据](../receipts/index.mdx)。
- **仅限 POS 的商品会将目录可见性设为隐藏**。此操作会在插件更新时执行一次，确保这些商品不出现在网店中。
- **不再支持磁条读卡器。** 请使用配对的读卡器（Pro）或您自己的终端收取银行卡付款，并在收银设备上记录付款。

### 收银台和钱箱 {#registers-and-cash-drawer}

<details>
<summary>收银台和钱箱：手动启用后才生效</summary>

2.0 支持在开台时设置备用金、结班时清点现金，免费插件也包含此功能。升级后不会立即改变操作流程：经理需在 **WP Admin → POS → 设置 → 常规** 的 **收银台** 下启用 **开台和结班**，此处也可设置 **开台备用金**。启用后，POS 会在首笔交易前要求输入备用金；**结班** 会清点钱箱并生成带编号的结班记录，随后显示的面板可通过 **打印结班报告** 将其打印出来。请参阅 [日终对账](../pos/reconciliation.mdx)。

免费插件提供一个收银台，由所有设备共用。更多收银台需要 Pro。请参阅 [收银台](../settings/wp-admin/registers.mdx#one-register) 和 [开台](../pos/register/index.mdx)。

</details>

## 店铺尚未准备就绪 {#if-your-store-isnt-ready-yet}

**继续使用 WCPOS 1.11。** 它仍可正常使用，并会在 2.0 发布后的六个月内继续获得修复更新。

1. **关闭自动更新**，对 WCPOS 和 WCPOS Pro 都执行此操作。在 **WP Admin → 插件** 中，每个插件行都有 **启用自动更新** / **禁用自动更新** 链接。请确保链接显示 **启用自动更新**，这表示自动更新已关闭。这样可以避免收银设备在当班期间自动更新。
2. 准备就绪后，**将 WooCommerce 更新到 9.0 或更高版本**。相关更新说明见 WooCommerce 自身的发行说明。
3. **返回 [点击更新之前](#before-you-click-update)。**
4. 如果之前使用自动更新，**升级到 2.0 后请重新启用自动更新**，否则后续修复将不会自动安装。

### 如果 WCPOS 比 WooCommerce 先更新了 {#if-wcpos-updated-first}

{/* pending: docs#675 */}
WooCommerce 升级到 9.0 或更高版本后才能打开 POS。已保存在店铺中的订单会保留。收银设备上未发送的销售记录只会保留到该设备打开 2.0 为止，因此请勿更新或重新加载该设备，按 [1.11 收银设备仍有未发送的销售记录](#unsent-sales) 中的步骤操作。您可以立即更新 WooCommerce，也可以 [重新安装 WCPOS 1.11](./previous-versions.mdx)，然后按上述方法关闭自动更新。

## 插件更新后 POS 消失了 {#pos-gone}

WP Admin 中的 **POS** 菜单消失了，`yourdomain.com/pos` 也无法再打开 POS。WCPOS 2.0 仅在网站满足其 [要求](./installation.mdx#server-requirements) 时运行。如果不满足，插件会保持已安装状态，但不会启用任何功能。订单仍保存在 WooCommerce 中。

1. **检查 WooCommerce。** 在 **WP Admin → 插件** 中，WooCommerce 必须已启用且为 9.0 或更高版本。请更新或启用它。如果暂时无法更新，请参阅 [如果 WCPOS 比 WooCommerce 先更新了](#if-wcpos-updated-first)。
2. **检查 PHP。** 2.0 需要 PHP 7.4 或更高版本。请向托管服务商查询网站运行的版本。
3. **使用 Pro 时，请确认 WCPOS Pro 已启用。** 免费的 **WCPOS** 插件是有意停用的，因为 Pro 已包含它。请参阅 [更新插件和收银设备](#updating)。
4. 在 WP Admin 顶部 **查找“WCPOS 插件未能正确加载。”提示**。插件自身的文件未加载，因此无法继续运行。请重新下载相同版本并上传，覆盖现有版本，操作方法见 [覆盖安装当前版本](./previous-versions.mdx#install)。不要先删除插件。

如果某台收银设备仍保留更新前的销售记录，请先阅读 [1.11 收银设备仍有未发送的销售记录](#unsent-sales)，再重新加载该设备。

## 回退版本 {#rolling-back}

### 1.11 收银设备仍有未发送的销售记录 {#unsent-sales}

收银设备显示更新界面，但销售记录尚未发送到店铺。在设备打开 2.0 之前，这些记录仍保存在设备上。要发送这些记录，请执行以下操作：

1. **保持该收银设备的现状。** 不要更新应用；若使用浏览器收银，也不要重新加载页面。这两种操作都会打开 2.0，从而清除未发送的销售记录。
2. 在店铺上 **[重新安装 1.11 插件](./previous-versions.mdx)**。
3. **重新加载浏览器收银页面，或关闭并重新打开应用。** 店铺恢复到 1.11 后，收银设备会重新连接并发送销售记录。请等待 **店铺健康 → 数据库** 中的 **等待发送的更改** 显示 **0**，且没有 [需要您作出决定的面板](../support/store-health.mdx#needs-attention)。此计数不包含未结订单：请逐一完成订单，或点击订单上的 **保存到服务器**。此时销售记录已保存到店铺。
4. 从 [更新插件和收银设备](#updating) 开始，**再次更新到 2.0**。

### 回退到 1.11 {#back-to-1-11}

如果 2.0 无法满足您的使用需要，请先通过 [Discord](https://wcpos.com/discord) 告诉我们。升级当天遇到的大多数问题都有比回退更快捷的解决方法。

:::warning 回退前先同步
回退到 1.11 后，每台收银设备都会从空的本地数据库重新开始；1.11 也无法发送 2.0 收银设备尚未发送到店铺的销售记录。请先等待所有 2.0 收银设备完成同步：**店铺健康 → 数据库** 中的 **等待发送的更改** 必须显示 **0**，没有 [需要您作出决定的面板](../support/store-health.mdx#needs-attention)，也没有尚未同步的未结订单（[同步订单](../pos/cart/open-orders.mdx#sync-order)）。
:::

**已升级到 2.0 的桌面或移动应用无法连接 1.11 插件**（会报告 [AUTH331](../error-codes/AUTH331.mdx)），且应用商店不提供旧版本。在再次升级之前，请在该收银设备上通过 `yourdomain.com/pos` 使用浏览器版 POS。

要回退，请 [重新安装 1.11 插件](./previous-versions.mdx)。浏览器收银设备和仍为 1.11 的应用可以照常使用。

在 2.0 中创建的订单是普通的 WooCommerce 订单，会保留在原处。在 2.0 中记录的收银班次和结班记录会保留在数据库中，但 1.11 不会显示它们。
