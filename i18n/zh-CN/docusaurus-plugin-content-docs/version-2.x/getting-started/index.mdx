## 什么是 WCPOS？ {#what-is-wcpos}

WCPOS 是适用于 WooCommerce 的收银系统（POS）。它与您的网店共用商品、库存和价格，每笔销售都会生成一个 WooCommerce 订单。您可以在浏览器中使用，也可以使用 Windows、macOS 和 Linux 应用；iOS 和 Android 应用目前处于测试阶段。

## 熟悉界面 {#find-your-way-around}

下图是搜索“手表”后的 POS 界面，已开启 **有货** 筛选，购物车中有一块手表。本文档的其他内容都以此为起点。[POS 界面概览](../pos/index.mdx)会逐一介绍各个部分。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[36, -12], [124, 0], [-30, 0], [10, 28], [72, 0], [0, -72], [-42, 0], [40, 28], [0, 0]]} alt="购物车中有一块手表的 POS 界面：左侧是菜单、搜索框、商品和商品数量，右侧是店铺、通知、您的头像、客户和结账按钮">

1. **菜单** — 在 **POS** 中进行销售。**商品**、**订单**、**优惠券** 和 **客户** 需要 [WCPOS Pro](./free-vs-pro.mdx#management-screens)。**报表** 显示当天的销售和关账记录。**健康状况**、**设置** 和 **支持** 位于底部。
2. **收银台栏** — 显示此设备所属的店铺；如果店铺有多个收银台，还会显示收银台名称。参阅[店铺、收银台和设备](../stores/registers-and-devices.mdx)。
3. **通知** — 来自 WCPOS 的公告、更新通知和许可证提醒。参阅[通知](../support/notifications.mdx)。
4. **您的头像** — 打开收银员面板，可查看钱箱、交接收银台以及退出登录。参阅[开台](../pos/register/index.mdx#cashier-sheet)。
5. **搜索** — 输入名称或 SKU，或扫描条形码。参阅[搜索与筛选](../pos/product-panel/search-filtering.mdx)。
6. **商品** — 点击商品即可将其加入购物车。参阅[商品面板](../pos/product-panel/index.mdx)。
7. **商品数量** — 符合条件的商品数量。点击旁边的箭头可从店铺刷新数据。
8. **客户** — 本笔销售的客户。点击可选择其他客户。参阅[购物车](../pos/cart/index.mdx)。
9. **结账** — 显示总金额。点击即可收款。参阅[结账](../pos/checkout/index.mdx)。

</JourneyShot>

在手机上，点击左上角的按钮可打开菜单，底部的 **购物车** 标签页用于查看购物车。

## 5 分钟快速入门 {#get-started-in-5-minutes}

收银员：如果您的店铺已经在使用 WCPOS，请[从第 2 步开始](#open-the-pos)。第 1 步由店主操作。

<Steps>

<StepCard number={1} title="安装插件（店主操作）">

在您的 WordPress 网站上安装免费的 [WCPOS 插件](https://wordpress.org/plugins/woocommerce-pos/)：

1. 在 WP Admin 中，进入 **插件** 并添加新插件。
2. 搜索“WCPOS”。
3. 点击 **立即安装**，然后点击 **启用**。

服务器和设备要求请参阅[安装](./installation.mdx)。

</StepCard>

<StepCard number={2} title="打开 POS">

<Anchor id="open-the-pos" />

**在浏览器中：** 访问 `yourdomain.com/pos`，使用您的 WordPress 用户名和密码登录。

**在应用中**（[下载应用](#where-it-runs)）：输入店铺地址，点击 **连接**，然后点击 **使用 WordPress 登录**，再点击 **打开 POS**。

有关在同一设备上添加多个店铺和收银员的说明，请参阅[连接](./connect.mdx)。

</StepCard>

<StepCard number={3} title="等待 POS 启动">

每次打开 POS 时，都会显示 WCPOS 标志和下方的进度条。等待进度条填满，POS 随即打开。如果应用中尚无人登录，则会打开 **连接** 界面。如果无法打开，请参阅[POS 无法启动时](#wont-start)。

<details>
<summary>进度条表示什么</summary>

随着进度条推进，POS 会打开保存在此设备上的数据，检查连接店铺的方式（在浏览器中），然后打开您上次使用的店铺：应用中沿用上次的收银员身份，浏览器中则使用当前登录 WordPress 的账户。

进度条表示 POS 的启动进度，并非商品下载进度。商品会在随后下载，您可以同时进行销售。

</details>

</StepCard>

<StepCard number={4} title="商品下载期间即可销售">

无需等待整个商品目录下载完毕。销售期间商品会继续下载；搜索时，如果商品尚未保存到此设备，POS 会向店铺查询。

<details>
<summary>为什么商品数量起初较少</summary>

POS 会在后台分小批次下载商品目录，避免给店铺服务器造成过大负担。

显示 **所有商品** 时，商品下方的 **显示 …，共 …** 统计的是此设备上的商品，因此在新设备上，数量起初较少，随后会逐渐增加。参阅[商品同步](../products/sync.mdx)。

</details>

</StepCard>

<StepCard number={5} title="完成首笔销售" isLast>

如果 POS 提示 **开台前仅可查询价格**，请先[开台](../pos/register/index.mdx)。上文的[熟悉界面](#find-your-way-around)已标出 **搜索**、商品和 **结账** 的位置。接下来，以现金销售为例：

1. 在 **搜索** 中输入内容或扫描商品，然后点击商品将其加入购物车。
2. 在手机上，打开 **购物车** 标签页。点击 **结账**，应付金额会自动填入。
3. 选择 **现金**，然后输入客户交付的金额，或点击快捷金额。输入时会实时显示找零。
4. 点击 **收款**。付款完成界面会显示应找零金额和收据。
5. 打印收据或通过电子邮件发送收据，然后点击 **新销售**，为下一位客户结账。

下图中，销售金额为 $45.00，客户交付 $50.00：

<JourneyShot manifest={checkoutManifest} device="tablet" step={8} offsets={[[-40, 0], [-70, 0], [-75, 0], [-90, 0], [-4, 0], [0, 0]]} alt="现金销售金额为 $45.00、实收 $50.00 的付款界面：关闭按钮、待付 $45.00、以大号数字显示的找零 $5.00、下方的实收 $50.00、已选中的现金及收款按钮">

1. **✕** — 返回购物车，订单仍保留在其中。
2. **待付** — 尚需支付的余额。
3. **找零** — 应退还给客户的金额。
4. **实收** — 您输入或点击选择的金额。
5. **现金** — 本次收款使用的支付方式。
6. **收款** — 显示金额和支付方式。点击即可记录付款。

</JourneyShot>

<details>
<summary>查看付款完成界面（另一笔销售）：找零、打印收据、新销售</summary>

<JourneyShot manifest={checkoutManifest} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="现金销售后的付款完成界面：应找零金额、已付和实收金额、已选择标准收据的模板选择器和打印机选择器、收据预览，以及电子邮件发送收据、下载 PDF、打印收据和新销售按钮">

1. **找零** — 应退还给客户的金额。
2. **已付 … · 现金实收 …** — 本笔销售的金额和客户交付的金额。
3. **模板** — 本笔销售使用的收据模板。参阅[自定义收据](../receipts/customise.mdx)。
4. **打印机** — 打印收据的设备。参阅[打印收据](../receipts/at-checkout.mdx#print-receipt)。
5. **预览** — 收据打印后的样式。
6. **打印收据** — 打印此收据。
7. **电子邮件发送收据** — 将收据发送给客户。参阅[电子邮件发送收据](../receipts/at-checkout.mdx#email-receipt)。
8. **新销售** — 为下一位客户准备空购物车，并恢复为默认客户。

</JourneyShot>

</details>

完整的销售流程请参阅[结账](../pos/checkout/index.mdx)，银行卡和其他支付方式请参阅[支付方式](../payment/index.mdx)。

</StepCard>

</Steps>

## POS 无法启动时 {#wont-start}

**进度条停在中途。** 在浏览器中，POS 正在检查连接店铺的方式。网络较慢时可能需要稍等，随后会自动继续。

**“出现了问题”。** POS 无法在此设备上启动。提示下方会显示失败原因。点击 **重试**：此设备上的所有数据都会保留。如果再次出现相同提示，请记下内容并[联系支持](../support/index.mdx)。

:::warning

除非支持人员要求，否则不要点击该界面上的 **重置应用数据并重启**。此操作会删除此设备上的所有数据，包括尚未发送到店铺的销售记录。删除前会要求您确认，并提示是否有尚未同步到店铺的更改。

:::

**“POS 已在另一个标签页中打开”。** POS 只能在一个标签页中运行。点击 **在此接管**，或返回另一个标签页。

**应用打开后显示连接界面。** 此设备上尚无人登录，或您已退出登录。如果无法完成登录，请参阅[连接](./connect.mdx#troubleshooting)。

## 主要功能 {#key-features}

免费插件支持销售收款：现金、自有终端刷卡、一个收银台及其钱箱、收据、购物车优惠券、条形码扫描，以及断网后继续销售。完整比较请参阅[免费版与 Pro 版](./free-vs-pro.mdx)。
