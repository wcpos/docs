WCPOS 通过 POS 顶部的铃铛向您发送插件更新、Pro 许可证通知和 WCPOS 最新消息。面板为空并显示 **暂无通知** 属于正常情况：WCPOS 尚未在此店铺向您发送任何通知。销售相关消息不会出现在这里：店铺发送的订单邮件需在[电子邮件通知](../settings/wp-admin/email-notifications.mdx)中设置。

## 找到铃铛 {#bell}

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-27, 0], [10, 30]]} alt="平板电脑上的 POS，左侧为商品，右侧为购物车。购物车顶部依次为店铺名称、带有红色未读通知数的铃铛，以及旁边的收银员头像">

1. **通知**——铃铛图标。红色数字表示未读通知的数量，超过 99 时显示 **99+**。没有未读通知时不显示数字。
2. **您的头像**——打开您的收银员面板，而非通知。请参阅[您的收银员面板](../pos/register/index.mdx#cashier-sheet)。

</JourneyShot>

在 POS 页面，铃铛位于收银栏的末端。在商品、订单、优惠券、顾客和报表页面，铃铛位于顶部栏的末端。在桌面应用中，铃铛会移到窗口标题栏；窗口进入全屏模式时，则回到页面栏中。

## 阅读通知 {#read}

点击铃铛，**通知** 面板会在侧边打开（手机上则占满整个屏幕）。通知按时间从新到旧排列，分为 **今天** 和 **更早** 两组。打开面板不会将通知标记为已读。

点击一条通知可将其标记为已读，也可以点击 **全部标记为已读**，将所有通知标记为已读并清除红色数字。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[95, 0], [458, -66], [140, 0], [0, 12], [-40, 0], [140, 0], [-30, 0]]} alt="POS 旁打开的通知面板：“更早”下有两条未读通知，一条是带“更新插件”按钮的插件更新通知，另一条是欢迎通知，两条通知都显示类型和日期；顶部有叉号，底部有“全部标记为已读”和“关闭”按钮">

1. **更早**——按店铺时间计算，今天之前的所有通知。今天的通知显示在上方的 **今天** 分组中。
2. **插件更新通知**——在标记为已读之前，标题会一直加粗显示，末尾带有一个圆点。消息下方显示通知的[类型](#kinds)和接收时间：最近一天内的通知显示距今多久，更早的通知则显示日期。
3. **更新插件**——打开 WordPress 后台的插件页面，由 WordPress 管理员安装更新。如果您不是管理员，请让网站管理人员安装更新。许可证通知在此处显示的是 **续订**。
4. **欢迎通知**——来自 WCPOS 的问候，不带按钮。
5. **叉号**——收起面板。
6. **全部标记为已读**——将所有通知标记为已读，并清除红色数字。仅在有未读通知时显示。
7. **关闭**——与叉号一样，用于收起面板。

</JourneyShot>

## 这里会收到哪些通知 {#kinds}

通知分为四种类型，类型名称显示在消息下方。

- **欢迎**——来自 WCPOS 的问候。不带按钮，也不会弹出提示。
- **插件更新**——WCPOS 插件有新版本发布。**更新插件** 会打开 WordPress 后台的插件页面。通知到达时会弹出提示。
- **许可证**——您的 Pro 许可证即将到期或已到期。**续订** 会打开 [wcpos.com/pro](https://wcpos.com/pro)。通知到达时会弹出带有 **续订** 按钮的提示；许可证到期后，弹窗按钮会变为 **立即续订**，且不再显示关闭按钮。
- **公告**——来自 WCPOS 的最新消息。不带按钮，通知到达时会弹出提示。

只有在 POS 打开期间到达的通知才会弹出提示。在 POS 关闭期间发送的通知会保留在面板中。POS 打开期间收到的插件更新和许可证通知还会写入[店铺健康状况](store-health.mdx#logs)中的日志，方便您寻求帮助时查阅。

## 通知属于谁 {#whose}

- **属于您在此店铺的通知。** 每位 WordPress 用户在每个店铺都有独立的通知列表。切换店铺后，您会看到对应店铺的列表。
- **每个应用各有一份列表。** 浏览器和桌面应用分别保存各自的列表，因此在其中一端读过的通知，在另一端仍为未读。
- **保存在此设备上。** 即使没有网络连接，列表仍然可用。

## 遇到问题时 {#goes-wrong}

**红色数字一直不消失。** 该数字表示未读通知数，打开面板不会将通知标记为已读。请逐条点击通知，或点击 **全部标记为已读**。

**“离线 · 正在显示已保存的通知”。** POS 启动时无法连接 WCPOS 通知服务，因此您看到的是保存在此设备上的通知。恢复联网后，请重新加载页面或重新打开应用，以获取新通知。

**“暂无通知”。** 尚未在此店铺向您发送任何通知。面板中会说明您可能收到哪些通知，并提供返回本页的链接。

**点击更新插件后打开登录页面，或提示您没有权限。** 更新插件需要 WordPress 管理员权限。请联系网站管理人员。

**续订后，许可证通知仍然存在。** 该通知是在您续订前发送的，会保留在列表中。要查看 POS 当前识别到的许可证状态，请参阅[确认 POS 已启用 Pro](../getting-started/pro-license.mdx#checking-licence-status)。
