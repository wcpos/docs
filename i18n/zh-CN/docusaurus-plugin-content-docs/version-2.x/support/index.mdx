遇到了文档中没有解答的问题？您可以直接从 POS 在 WCPOS Discord 中提问。本页介绍在哪里提问，以及应提供哪些信息，以便他人首次回复时就能帮上忙。

1. 先查看[常见问题](#before-asking)。许多答案只需搜索一下就能找到。
2. 从**店铺健康 → 日志**中[复制调试信息](#what-to-send)。
3. [在 Discord 中发帖](#in-app-support)，附上调试信息并说明发生了什么。

如果涉及许可证、账单或任何私密事项，请改为[通过电子邮件联系支持](#where-to-ask)。

## 从 POS 提问 {#in-app-support}

首先[复制调试信息](#what-to-send)。然后点击菜单底部的**支持**。WCPOS Discord 会在 POS 内打开，您无需离开收银界面，就能查看他人的提问并发布自己的问题。选择 **general**，然后点击**登录**，登录后发布问题。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="支持页面：POS 内的 WCPOS Discord，包含频道列表、welcome-and-rules 频道、登录按钮和消息框，菜单底部的支持已选中">

1. **支持** — 菜单底部的对话气泡图标。在手机上，请先打开菜单。
2. **支持** — POS 内的 WCPOS Discord。默认打开 **welcome-and-rules**。
3. **Discord** — 在左侧选择频道。在 **general** 中提问。点击**登录**以登录 Discord 并发帖。
4. **店铺健康** — 此处的红色数字表示自您上次打开**日志**以来出现的新错误数量。请将这些错误[随问题一起发送](#what-to-send)。

</JourneyShot>

在手机上，从顶部角落打开菜单。**支持**是最后一项，图标旁会显示名称。

## 提供所需信息 {#what-to-send}

提供您使用的版本以及 POS 遇到的错误，通常能让问题更快得到解答。POS 会为您收集这两类信息。

打开菜单中的**店铺健康**，然后打开**日志**，点击**复制调试信息**，信息便会复制到剪贴板。在 iOS 和 Android 应用中，按钮显示为**分享调试信息**，点击后会打开系统分享面板。将信息粘贴或分享到消息中，并说明：

- 您当时正在进行什么操作，
- 您预期的结果，以及实际发生的情况，
- 屏幕上显示的任何代码，例如 `SYNC201`，
- 是否每次都会发生。

附上屏幕截图也有帮助。

<JourneyShot manifest={manifest} device="tablet" step={2} alt="店铺健康的日志选项卡：当天的统计数据、复制调试信息按钮、日志搜索和筛选按钮">

1. **店铺健康** — 菜单中的心跳图标。请参阅[店铺健康](./store-health.mdx)。
2. **日志** — POS 执行过的操作及发生的问题。请参阅[日志](./logs.mdx)。
3. **今日错误** — 点击后仅显示错误。
4. **复制调试信息** — 复制支持人员所需的 POS 详细信息及最近的错误。
5. **搜索日志** — 根据日志条目中的文字查找条目。
6. **错误** — 与**今日错误**使用相同的筛选条件。
7. **详细诊断** — 记录更多详细信息。仅在帮助您的人要求时开启；它会在 24 小时后自动关闭。

</JourneyShot>

准备好了吗？返回[从 POS 提问](#in-app-support)，登录后将调试信息与问题一起粘贴。

## 在哪里提问 {#where-to-ask}

- **Discord** — 使用问题、缺陷和建议。解答会保留在频道中，方便其他人查找。[wcpos.com/discord](https://wcpos.com/discord)
- **[wcpos.com/support](https://wcpos.com/support) 上的提问框** — 输入问题，即可获得根据 WCPOS 文档生成的解答及相关链接。无法解答时，它会引导您前往 Discord。
- **电子邮件 [support@wcpos.com](mailto:support@wcpos.com)** — 许可证、账单、退款，以及任何您不愿公开发布的事项。

:::info 使用 WCPOS Pro
Discord 的 Pro 频道提供优先支持。购买许可证也能为 WCPOS 免费版和 Pro 版的开发提供资金。请参阅 [Pro 许可证](../getting-started/pro-license.mdx)。
:::

<details>
<summary>关联 Discord 以获取 Pro 支持</summary>

1. 在您的 [wcpos.com 账号](https://wcpos.com/account/licenses)中，点击许可证上的**关联 Discord**。或者，在 Discord 服务器中输入 `/link` 并附上许可证密钥。
2. 许可证有效期间，您的 Discord 账号可访问 Pro 频道。许可证到期后访问权限会关闭，续订后会重新开放。

每个许可证最多可供五人使用。

</details>

## 提问之前 {#before-asking}

许多答案只需搜索一下就能找到：

- **还不确定 WCPOS 是否适合您的店铺？** — 请先安装免费插件并试用几天。这能解答大多数“它能否做到这一点”的问题。
- **屏幕上出现错误代码** — 请在[错误代码](../error-codes/index.mdx)中查找。
- **产品、订单或客户缺失或未更新** — 检查**店铺健康 → 数据库**。请参阅[店铺健康](./store-health.mdx#database)。
- **POS 无法加载或显示旧数据** — 请先参阅[清除本地数据](./troubleshooting/clear-local-data.mdx)，然后查看[插件冲突](./troubleshooting/plugin-conflicts.mdx)和 [Cloudflare](./troubleshooting/cloudflare.mdx)。
- **POS 运行缓慢** — 请参阅[性能](./performance/index.mdx)。
- **总计与 WooCommerce 不一致** — 请参阅[总计不一致](./troubleshooting/totals-disagree.mdx)。
- **可能已经有人问过** — 发帖前请先搜索 Discord。

## 出现问题时 {#goes-wrong}

**支持页面一直空白。** Discord 需要互联网连接。请检查连接，或在浏览器中打开 [wcpos.com/discord](https://wcpos.com/discord)。

**“无法复制调试信息”。** 信息未能复制到剪贴板。请点击 POS 窗口内部，然后再次点击**复制调试信息**，或改为截取**日志**页面的屏幕截图。

## 帮助改进 WCPOS {#contributing}

WCPOS 是开源软件。您可以：

- 在 Discord 或 [GitHub](https://github.com/wcpos) 上报告缺陷，
- 在 Discord 中提出功能建议，
- 在 Discord 的 **general** 频道中解答其他店主的问题，
- 改进应用或文档的翻译。请参阅[贡献翻译](./translations.mdx)。
