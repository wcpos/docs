## 这意味着什么 {#what-this-means}

此网站未启用 WooCommerce，因此 WCPOS 无法连接。

WCPOS 需要 WooCommerce 插件。请让站点管理员安装或重新启用 WooCommerce，然后再次连接。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续出现，请联系负责管理您的 WordPress 网站的人员。

## 故障排除 {#troubleshoot}

1. 请让站点管理员检查 WP Admin → 插件：只有安装并启用 WooCommerce 后，WCPOS 才能连接。
2. 如果 WooCommerce 因更新失败而被停用，请重新启用它，并留意是否出现错误横幅——WooCommerce → 状态 → 日志 中会记录失败原因。
3. WooCommerce 重新启用后，请从收银台再次连接。
