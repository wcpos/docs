## 含义说明 {#what-this-means}

无法连接所选打印机。

检查打印机是否已开机并连接，然后重试打印。

## 数据状况 {#your-data}

订单和商品数据均不受影响。

## 故障排查 {#troubleshoot}

1. 检查打印机是否已开机，以及线缆或网络连接是否正常。
2. 通过打印机自身的功能打印自检页（请参阅其说明书）。大多数网络打印机的自检页也会显示当前 IP 地址。
3. 如果使用网络打印机，请确认收银机和打印机连接到同一网络。然后打开 **设置 → 打印**，在 **打印机** 下点击该打印机的 **编辑**，检查 **IP 地址** 是否与自检页一致（如果自检页显示端口，也检查 **端口**）。路由器重启后可能会给打印机分配新地址。请修正这些值，或使用 **扫描网络**。更改会即时保存。
4. 在 **设置 → 打印** 中打开打印机的 **编辑** 页面，点击 **测试打印**，然后重新打印收据。
