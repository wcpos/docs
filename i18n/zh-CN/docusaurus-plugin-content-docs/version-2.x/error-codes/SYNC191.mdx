## 含义 {#what-this-means}

此项更改仍在发送到店铺的途中。

无需操作，不要重新输入。它会自动发送，并在店铺确认后显示。

一笔销售或一项更改已在此设备上保存并发送，但店铺未在通常的等待时间内确认，通常是因为店铺响应缓慢或连接不稳定。WCPOS 会持续发送，直到店铺确认。店铺能识别已收到的更改，因此再次点击同一按钮是安全的。但手动重新输入销售记录或其他记录则不安全：这会创建另一条独立记录，造成重复。

## 您的数据 {#your-data}

没有数据丢失。更改正在此设备上等待，会自动发送。等待发送期间，不要清除此设备的数据。

## 故障排查 {#troubleshoot}

1. 不要手动重新输入销售记录或更改，这会造成重复。
2. 等待其传送到店铺。由于销售记录已保存在此设备上，WCPOS 中已能看到它（在购物车中，或 WCPOS Pro 的 **订单** 中）；要确认它是否已传送到店铺，请查看 WP Admin 中的 **WooCommerce → 订单**。
3. 要查看发送进度，请打开 **店铺健康状况 → 日志**：随着更改发送，顶部的 **等待发送的更改** 数量会减少，没有其他更改等待发送时会显示 0。
4. 如果长时间处于等待状态，请检查此设备的网络连接以及店铺网站能否加载，参见 [SYNC121](/error-codes/SYNC121)。
5. 如果连接正常后仍未显示，请点击 **日志** 选项卡中的 **复制调试信息**，并联系支持团队。
