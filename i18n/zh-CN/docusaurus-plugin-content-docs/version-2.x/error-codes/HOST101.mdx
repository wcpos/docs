## 含义 {#what-this-means}

服务器阻止了浏览器的权限检查（CORS 预检），因此网页版应用无法访问服务器。

浏览器在发起带有自定义请求头的跨域 API 调用前，会先发送 OPTIONS 请求。店铺前方的某个环节（通常是防火墙规则）阻止了 OPTIONS，因此浏览器根本不会发送实际请求。原生应用不受影响，需要在服务器端修复。

## 您的数据 {#your-data}

订单或商品数据均不受影响。

## 故障排除 {#troubleshoot}

1. 检查防火墙（WAF）是否有阻止 OPTIONS 方法的规则，并在 /wcpos/ REST 路由上允许此方法。
2. 某些安全插件设有“阻止不常见请求方法”开关，必须保持允许 OPTIONS。
3. 测试：向店铺 REST API 发送 OPTIONS 请求，不应返回 403。
4. 桌面版和移动版应用不使用 CORS，在修复期间仍可正常使用。
