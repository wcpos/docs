## 含义 {#what-this-means}

服务器的跨域（CORS）配置有误，导致浏览器拒绝其响应。

店铺返回了响应，但 CORS 响应头有误：可能重复、设置了错误的来源，或在错误响应中缺失。浏览器因此不向网页版应用提供实际响应，其他错误也都会被掩盖为通用的网络故障。需要在服务器端修复：所有状态码的响应都必须且只能包含一个 Access-Control-Allow-Origin。

## 您的数据 {#your-data}

订单或商品数据均不受影响。

## 故障排除 {#troubleshoot}

1. 检查是否有两处在处理 CORS（插件和服务器配置都添加了响应头），并移除其中一处。重复的 Access-Control-Allow-Origin 会导致浏览器出现致命错误。
2. 在 nginx 中，add_header 指令除非以 'always' 结尾，否则不会应用于错误响应。4xx/5xx 响应也必须包含 CORS 响应头。
3. 如果 CDN 或代理会添加 CORS 响应头，请确保它们不会与 WordPress 自身的响应头冲突。
4. 桌面版和移动版应用不使用 CORS，在修复期间仍可正常使用。
