## 这意味着什么 {#what-this-means}

此店铺现在要求使用更新版本的 POS 应用。

店铺的 WCPOS 插件已采用比当前应用版本所支持的更新的同步协议，因此店铺会主动暂停同步，直到应用更新。这是一项保护措施，并非故障，目的是防止过时的应用错误地读写店铺数据。请更新 WCPOS（网页版请重新加载页面），然后重新打开。未发送的销售会保留在此设备上，并在更新后发送。

## 您的数据 {#your-data}

收银端没有丢失任何内容。待发送的销售和修改会安全地保留在设备上，并在更新后的应用连接到店铺时同步。如果尚无更新版本的应用（参见下面最后两个步骤），它们会继续排队等待，直到新版本可用。

## 故障排除 {#troubleshoot}

1. 使用网页版时，请重新加载浏览器标签页，网页应用会在重新加载时获取新版本。如果再次出现此界面，请强制重新加载，即按住 **Shift** 重新加载。
2. 使用桌面版时，请安装待安装的更新，然后重新打开应用。应用重新连接时会执行检查。如果没有可用更新，请从[安装](/getting-started/installation)页面下载最新版本。
3. 使用 iPhone、iPad 或 Android 时，请通过原安装渠道更新 WCPOS：iOS 使用 TestFlight，Android 使用 Play 测试计划；[安装](/getting-started/installation)页面提供了这两个渠道的链接。更新后重新打开应用。
4. **网站管理员：** 如果尚无更新版本的应用，说明店铺的 WCPOS 插件先于配套的应用版本进行了更新。在店铺中恢复到上一个 WCPOS 插件版本即可恢复同步，直到新版应用发布。
5. 如果既无法更新应用，也无法回退插件版本，请联系 WCPOS 支持团队。
