## 含义 {#what-this-means}

店铺发生错误，未能完成此次请求。

已连接到店铺，但其服务器未能处理请求。这是网站端的问题，而不是 POS 的问题。请重试该操作。如果问题持续，请让站点管理员检查 **WooCommerce → 状态 → 日志**。此设备上没有数据丢失。

## 您的数据 {#your-data}

不要清除此设备的数据，其中可能存有店铺尚未收到的更改。当时正在发送的更改可能尚未传送到店铺。如果问题持续出现，请使用 **日志** 选项卡中的 **复制调试信息**，并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

**在 POS 上（收银员）：** 展开日志条目，记下状态、端点和 serverCode，它们说明了服务器发生故障时正在执行的操作。

**在网站端（站点管理员 / 托管服务提供商）：**

1. 在网站上打开 WooCommerce → 状态 → 日志，检查最新的 fatal-errors 日志中故障发生时间附近的内容。500 类响应几乎总会在其中留下 PHP 错误。
2. 如果故障是在网站更新插件、主题或 PHP 后开始的，请先排查该项更改，并将其回退或禁用。
3. 如果 WooCommerce 日志中没有相关内容，请向托管服务提供商索取同一时间段的服务器 PHP 错误日志。

**然后返回 POS：** 重试该操作。
