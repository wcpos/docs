## 这意味着什么 {#what-this-means}

此订单引用的税率已不在店铺中，因此税额可能不正确。

订单中的某个条目使用了店铺当前税率表中不存在的税率——这几乎总是因为订单创建后，该税率在 WooCommerce 中被删除或修改了。WCPOS 无法查到该税率，因此此订单的税额可能与店铺当前应收取的税额不符。

## 您的数据 {#your-data}

订单数据安全无损。只有税额可能有误——请在收款前核对，并向店铺管理员询问税率情况。

## 故障排除 {#troubleshoot}

**在收银台**——请在收款前完成以下操作：

1. 核对订单上的税额。该税额是按店铺中已不存在的税率计算的。
2. 如果税额看起来不正确，请新建订单重新进行这笔销售——新订单会使用店铺当前的税率。

**在店铺后台（WP Admin）**——由站点管理员执行：

1. 前往 **WooCommerce → 设置 → 税费**，检查最近是否有税率被删除或修改。通常是因为删除了尚未完成的订单已引用的税率。
2. 如果税率是有意删除的，只需重新开始当时尚未完成的订单，无需进行其他操作。
3. 如果店铺的税率没有变化，POS 可能仍保留着过时的副本。请通过 **商店健康 → 数据库 → 税率 → 清除并重新下载** 刷新税率——此操作仅影响该数据集合，不会使任何用户退出登录。参阅[商店健康](/troubleshooting/store-health#clear-and-redownload)。
4. 如果税率下载完成后再次出现此错误代码，请打开 **商店健康 → 日志** 中的日志条目，使用 **复制**（或 **分享**）发送详细信息，并提供订单号联系支持团队。
