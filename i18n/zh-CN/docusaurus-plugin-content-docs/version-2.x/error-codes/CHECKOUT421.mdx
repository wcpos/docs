## 这意味着什么 {#what-this-means}

此订单引用的税率已不在店铺中，因此订单税额可能有误。

订单中的某个商品行使用的税率不在店铺当前的税率表中——几乎总是因为订单创建后，该税率在 WooCommerce 中被删除或编辑。WCPOS 无法查询该税率，因此此订单的税额可能与店铺目前收取的金额不一致。

## 您的数据 {#your-data}

订单本身安全无虞。只有税额存在疑问——收款前请先核对，并向店铺管理员询问税率。

## 故障排除 {#troubleshoot}

**在收银台** — 请在收款前执行：

1. 检查订单的税额。该税额是按店铺已不再使用的税率计算的。
2. 如果税额有误，请创建新订单来开始销售——新订单会采用店铺当前的税率。

**在店铺（WP Admin）中** — 供站点管理员操作：

1. 前往 **WooCommerce → 设置 → 税费**，检查近期是否有税率被删除或编辑。未结订单已引用的税率被删除，是最常见的原因。
2. 如果税率是有意删除的，只需重新创建当时仍处于未结状态的订单，无需其他操作。
3. 如果店铺的税率没有变化，POS 可能仍在使用过期副本。请前往 **店铺健康状况 → 数据库 → 税率 → 清除并重新下载** 刷新数据——这只会影响该数据集，不会让任何人退出登录。请参阅[店铺健康状况](/troubleshooting/store-health#clear-and-redownload)。
4. 如果税率下载完成后该代码再次出现，请在 **店铺健康状况 → 日志** 中打开日志条目，使用 **复制**（或 **分享**）发送其详细信息，并联系支持，同时提供订单编号。
