## 这意味着什么 {#what-this-means}

店铺报告该订单已付款，但收银机也已经为此订单收取了一笔款项。因此，顾客支付了两次。

收银机收取的付款会保留在订单账目中，并以 `order_already_paid` 为原因标记为失败，确保所有记录可见，第二笔付款不会被悄然丢弃。接下来需要退还这笔款项。

## 您的数据 {#your-data}

款项已转移，顾客已被收款两次。请退还收银机收取的付款；订单和在线付款均完好无损，额外的付款也已记录在订单上，没有被丢弃。

## 故障排除 {#troubleshoot}

**在收银机端**——请在顾客离开前完成以下操作：

1. 告知顾客该订单已在线付款，第二笔付款将予以退还。
2. 核对收银机收取的金额和付款方式：**店铺健康状况 → 数据库** 会在 **… 需要处理** 下列出该订单，并显示类似 *“订单 #… 已在线付款；收银机还收取了 …，请退还该笔付款”* 的信息。**店铺健康状况 → 日志** 中也有相同信息。
3. 按原收款方式退还该笔款项：现金从钱箱退还；银行卡付款则在刷卡机或支付服务商的管理面板中对该笔扣款发起退款。退还现金时不要记录为现金支出；被拒绝的付款从未计入钱箱的预期现金，因此钱箱账目本就平衡。
4. 不要在 WCPOS 中对该订单使用 **退款** 来处理此问题。该功能会针对订单本身，也就是那笔有效的在线付款退款，而不是针对店铺拒绝记录的收银机付款。
5. 不要作废或删除订单。这是一笔有效的已付款订单；只有额外收取的付款有误。

**在店铺端**——供网站管理员操作：

1. 在 WooCommerce 中与支付网关核对在线付款，确认两笔付款中应保留哪一笔。在 **WooCommerce → 订单** 中添加订单备注，说明重复收取的收银机付款已退还，以及退款方式和时间。
2. 确认退款是否已到账；银行卡退款可能需要数天才会显示在顾客的账单上。
3. 如果反复出现这种情况，通常是因为订单已在收银机上打开处理，同时又在线完成了付款；请检查订单在结清前进入 POS 的流程。
