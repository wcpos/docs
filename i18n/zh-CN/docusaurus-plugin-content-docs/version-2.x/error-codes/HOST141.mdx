## 这意味着什么 {#what-this-means}

主机的安全过滤器正在拦截商品搜索。

此主机上的一条防火墙规则会拒绝查询字符串中包含非 ASCII 字符或类似 SQL 关键词的 REST 请求。带重音符号的商品名称，以及包含“select”或“union”等词的搜索，即使只是普通的商品目录搜索，也会返回 403 错误。收银机的其他功能正常；在放宽此规则之前，搜索功能无法稳定使用。

## 您的数据 {#your-data}

订单和商品数据均不受影响。

## 故障排除 {#troubleshoot}

1. 请主机服务商在查询字符串防火墙规则中，将店铺自身的 REST 搜索参数（/wcpos/ 和 /wc/ 路由）加入允许列表。
2. 对于基于 OWASP CRS 的防火墙，问题通常出在针对“s”和“search”参数的 SQL 注入规则上；请对 REST API 路由中的这些参数设置例外。
3. 对于带有“过滤可疑查询字符串”开关的安全插件，应为 REST API 设置例外，而不是全局关闭此功能。
