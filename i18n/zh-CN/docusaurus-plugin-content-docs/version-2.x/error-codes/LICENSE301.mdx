## 这意味着什么 {#what-this-means}

更新程序未获授权下载 WCPOS Pro 更新。

为此店铺重新授权更新程序，然后再次检查更新。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续存在，请联系 WordPress 网站管理人员。

## 故障排除 {#troubleshoot}

1. 前往 **WP Admin > POS > 设置 > 许可证**。如果页面显示 **许可证密钥** 字段，请输入密钥并点击 **激活**；如果已显示许可证已激活，请先从 WCPOS 账户复制完整密钥（页面只显示缩略密钥），然后点击 **停用**，再重新输入密钥并点击 **激活**。
2. 在 WP Admin → 仪表盘 → 更新中再次检查更新。
3. 如果授权持续失败，网站可能正在拦截发往更新服务器的出站请求；请向主机服务商确认是否限制了出站 HTTPS。
