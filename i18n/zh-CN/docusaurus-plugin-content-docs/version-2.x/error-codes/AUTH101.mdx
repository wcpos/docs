## 这意味着什么 {#what-this-means}

您的会话已结束，需要重新登录。

请重新登录。没有数据丢失——登录后，尚未发送的更改会自动发送。

## 您的数据 {#your-data}

订单和商品数据均不受影响。会话失效期间保存的销售记录会保留在设备上，不会丢失，并会在您登录后自动发送到店铺。

## 故障排除 {#troubleshoot}

1. 请重新登录。WCPOS 会自动打开 WordPress 登录窗口；如果您关闭了该窗口，WCPOS 会提示您重新登录。请使用同一收银员账户登录。
2. 您无需重新录入或保存任何内容：重新登录后，等待中的销售记录会自动发送。要查看发送进度，请打开 **商店健康 → 数据库**——**待发送的更改** 数量会降至 0。
3. 如果销售记录列在 **“… 从未送达服务器的更改”** 下，请点按该行的 **重新发送**。
4. 会话频繁过期（每天数次）通常是网站端造成的：安全插件缩短了会话有效期或清除了令牌。请让站点管理员确认店铺使用了哪些安全插件，并检查 **WP Admin > POS > 设置 > 工具 > 日志**——被拒绝的登录及其原因会记录在此处。
