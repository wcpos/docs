## 含义 {#what-this-means}

此设备上的更改与店铺中更新的编辑发生冲突。没有数据丢失。

如果 **店铺健康状况 → 数据库** 中列出了此记录的暂缓更改，请点击 **重新发送** 以保留此设备的版本，或点击 **使用服务器版本** 以保留店铺版本。如果没有，则无需操作，冲突已经解决。

## 您的数据 {#your-data}

没有数据丢失。更改被暂缓时，店铺保留自己的版本，此设备保留其更改，直到您选择保留哪一个版本；在此之前，对该记录的后续编辑会在此设备上等待。存在暂缓更改时，不要清除此设备的数据，清除操作会删除暂缓的更改。

## 故障排查 {#troubleshoot}

1. 打开 **店铺健康状况 → 数据库**。暂缓的更改及其所属记录会列在以 **“1 项更改已暂缓”**（或 **“… 项更改已暂缓”**）开头的面板中。
2. 如果该记录已没有暂缓的更改，说明已在此处或另一个选项卡中解决，无需操作。对于 WCPOS 通过重新发送此设备版本自行解决的订单冲突，则会改为记录为 [SYNC222](/error-codes/SYNC222)。
3. 如果有更改被暂缓，请点击 **打开记录**（如果显示此按钮）查看此设备的版本，并与 WP Admin 中的同一条记录比较（可能需要站点管理员执行此操作）。
4. 要保留此设备的版本，请点击 **重新发送**。更改会重新发送，并用此设备更改过的字段值替换店铺中的对应值。要保留店铺版本，请点击 **使用服务器版本**（某些行显示为 **丢弃设备更改**）并确认，此设备的更改将被丢弃。在您作出选择前，对该记录的后续编辑都会等待。
5. 同一批记录频繁发生冲突，通常意味着有两个人同时编辑相同的数据，例如分别在收银终端和 WP Admin 中修改库存。请约定各类编辑应在何处进行。
