## 含义说明 {#what-this-means}

显示的库存数据可能落后于店铺的库存数据。

如果销售可能导致商品超卖，请先核实店铺的当前库存，再完成销售。

## 数据状况 {#your-data}

数据没有风险，只是收银机的库存数值落后于店铺，同步恢复后会更新。如果问题持续，请咨询 WordPress 网站管理人员。

## 故障排查 {#troubleshoot}

1. **在收银机上：** 销售库存较低的商品前，请核实实际数量，可以查看货架或 WP Admin 中的商品库存，不要仅依赖收银机显示的数量。
2. 刷新收银机上的数据副本：打开 **店铺健康 → 数据库**，打开 **商品** 行的 **⋮** 菜单，然后选择 **立即检查更改**。对于带有变体（尺寸、颜色）的商品，也对 **变体** 行执行同样操作，因为每个变体都单独记录库存。
3. 如果数值仍然滞后，说明同步失败或已暂停。在 **日志** 选项卡中选择 **错误** 或 **同步**，处理其中的错误代码，例如无法连接店铺时出现的 [SYNC121](/error-codes/SYNC121)。同步恢复后，库存会自动更新。
4. **网站管理员：** 如果多台收银机或网店共用同一库存，请在 **WP Admin > POS > 设置 > 收银台** 中开启 **防止超卖**。这样，即使收银机的数据已过时，店铺也会拒绝销售数量超过现有库存的订单。该检查在收银机在线结账时进行；离线完成的销售稍后同步时，无法可靠地执行此检查，因此离线销售低库存商品前，请手动核实库存（步骤 1）。
