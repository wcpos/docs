## 含义说明 {#what-this-means}

收银机收取的款项超过了店铺记录的该订单待付余额，店铺因此拒绝将其计入订单。这次尝试会作为失败的付款保留在订单中，所有记录均可查看。

款项没有计入订单，但现金已经收进钱箱，或顾客的银行卡已经扣款。因此需要完成两件事：将差额退还顾客，再从已收款项中，将实际应付的部分记入订单。

这通常意味着，在这台收银机上次读取订单后，订单已在其他地方发生变化，例如另一台收银机或 WooCommerce 后台。

## 数据状况 {#your-data}

款项已经收取，但店铺未将其计入订单。实收金额与订单欠款之间的差额应退还给顾客。

## 故障排查 {#troubleshoot}

**在收银机上** — 请在顾客离开前完成以下操作：

1. 不要让顾客再次付款。被拒绝的付款虽然未计入订单，但现金已经收进钱箱，或顾客的银行卡已经扣款。
2. 查看店铺记录的订单欠款，以该金额为准。**店铺健康 → 日志** 中的记录通常会注明，例如 *“订单 #… 的未付金额仅为 …；收银机收取了 …”*；如果其中没有金额，可在步骤 3 刷新后的付款面板中查看。
3. 记账前先刷新订单：打开 **店铺健康 → 数据库**，打开 **订单** 行的 **⋮** 菜单，然后选择 **立即检查更改**，使付款面板显示店铺记录的待付余额。
4. 从已收款项中，将这笔待付余额记入订单。此错误只会出现在现金或手动录入的银行卡等仅记账的付款方式中：在付款面板中选择相同的方式，点击 **正好 …**（现金）或 **全部余额 …**，然后确认收款。切勿选择银行卡终端或支付网关方式，否则会发起新的扣款。不要再向顾客收取任何款项。
5. 将实收金额与订单欠款之间的差额退还给顾客：从钱箱退还现金，或在刷卡机或支付服务商的控制面板中退还差额。

**在店铺端** — 供网站管理员操作：

1. 在收款的那台收银机上，**店铺健康 → 日志** 中记录了被拒绝的付款尝试及其原因；**WooCommerce → 订单** 中的订单只显示店铺已接受的款项。
2. 如果同一订单反复出现此问题，说明还有其他途径在同时结清该订单，例如另一台收银机，或柜台上打开订单期间到账的在线付款。
