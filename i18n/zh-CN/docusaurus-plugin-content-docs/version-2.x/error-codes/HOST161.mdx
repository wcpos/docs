## 这意味着什么 {#what-this-means}

主机正在限制此店铺收银机的请求频率。

尽管应用已降低请求频率，并遵守服务器 Retry-After 指定的等待时间，服务器仍持续返回 429（请求过多）。共用一个互联网连接的多台收银机会使用同一个地址，因此按来源设置的频率限制会将它们视为一个请求非常频繁的客户端。同步会自动继续，但在提高限额之前会有延迟。

## 您的数据 {#your-data}

订单和商品数据均不受影响。

## 故障排除 {#troubleshoot}

1. 请主机服务商提高店铺自身流量的 REST API 请求频率限额，或将其豁免；如果店铺有静态 IP，请提供该地址。
2. 某些安全服务会累计重复的错误响应（429），达到阈值后进行封禁，例如 Sucuri 的 IDS。对于这类服务，可能需要将店铺 API 排除在该计数范围之外。
3. 如果多台收银机共用一个连接，请告知主机服务商：这里的一个 IP 代表整家店铺，而非一个用户。
