## 含义 {#what-this-means}

店铺的响应中夹杂了多余文本，WCPOS 已尝试清理。

请检查您当时进行的操作是否已完成，清理并不总能成功。这些多余文本通常来自插件或 PHP 提示，它们向店铺响应中加入了额外输出。如果经常出现，请让站点管理员检查网站的 PHP 错误日志中是否有警告。

## 您的数据 {#your-data}

如果您当时进行的操作未完成（参见故障排查第 1 步），请遵循该请求对应的指引；否则，订单和商品数据均不受影响。如果经常出现，请咨询负责管理 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

1. 检查您当时进行的操作是否已完成，例如销售记录或更改现在是否已显示。如果已完成，无需进一步操作。如果未完成，请重试；若重试失败，请按显示的错误提示处理，或联系支持团队。
2. 原因在网站端：插件或主题向 REST 响应中输出了警告或多余内容。请让站点管理员检查网站日志中故障发生时的 PHP 提示。
3. **站点管理员：** 浏览器的开发者工具（网络选项卡），或桌面应用中的 **高级 → 切换开发者工具**，可以显示原始响应正文。多余输出就在 JSON 的前面或后面。
4. **站点管理员：** 清理只能尽力而为。如果经常出现，请修复引发问题的插件，不要依赖自动清理。
