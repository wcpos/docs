## 含义 {#what-this-means}

目前无法连接到您的店铺。

无需操作，可以继续销售。连接恢复后，更改会自动发送。如果问题持续，请检查此设备的网络连接以及店铺网站能否加载。

## 您的数据 {#your-data}

不要清除此设备的数据，其中可能存有店铺尚未收到的更改。店铺恢复响应后，这些更改会自动发送。

## 故障排查 {#troubleshoot}

1. 可以继续销售。销售记录会保存在此设备上，并在店铺恢复响应后自动发送。
2. 检查收银终端本身是否联网：此设备能否加载其他网站？
3. 在同一设备的浏览器选项卡中打开店铺网站。如果在那里也无法加载，说明是网站或其托管服务出现了故障，而不是 POS。
4. **负责管理此设备网络的人员：** 如果网站可以加载，但 POS 一直离线，说明两者之间有某个环节正在拦截 API 请求，例如 VPN、防火墙、广告拦截器或安全插件。浏览器的开发者工具（网络选项卡），或桌面应用中的 **高级 → 切换开发者工具**，可以显示哪个请求失败了。
