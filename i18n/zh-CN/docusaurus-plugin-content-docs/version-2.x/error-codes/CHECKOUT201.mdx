## 这意味着什么 {#what-this-means}

WCPOS 无法确认结账是否已完成。

重试前请打开订单并检查其状态。如果订单已付款或已完成，请勿再次收费。

## 您的数据 {#your-data}

无法确认结果，请在重试前先检查。如果问题持续出现，请在 **日志** 标签页中使用 **复制调试信息**，并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 在确认订单状态之前，请勿再次按结账界面 **旧版** 标签页中的 **处理付款**，也不要再次向顾客收费。
2. 打开订单并检查其状态。使用 WCPOS Pro 时，请先刷新收银台的订单：打开 **店铺健康 → 数据库**，点按 **订单** 行中的 **⋮** 菜单，再选择 **立即检查更改**，然后在 **订单** 中打开订单。没有 Pro 时，请让他人前往 WP Admin 中的 **WooCommerce → 订单**，按总额和最近几分钟的时间范围搜索并打开该订单。
3. 找到订单还不够，订单可能已创建但尚未付款。如果订单状态为 **处理中** 或 **已完成**，说明销售已完成，请勿再次收费。
4. 如果订单仍未付款，或找不到订单，请检查顾客是否已付款：银行卡付款请查看支付服务提供商自身的界面、收据或控制面板；现金付款请检查钱箱和实收金额。如果顾客已付款，请勿再次收费。如果已找到订单，请重新加载应用并再次检查订单状态（启动时，收银台会完成已记录付款的销售）；如果找不到订单或订单仍未付款，请继续执行最后一步。
5. 如果订单尚未付款且支付服务提供商显示未扣款，请重试结账一次。
6. 如果仍无法确定，请在再次尝试前使用 **日志** 标签页中的 **复制调试信息**，并联系支持团队。
