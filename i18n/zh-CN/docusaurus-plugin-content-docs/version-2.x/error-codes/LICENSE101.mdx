## 这意味着什么 {#what-this-means}

您的 WCPOS Pro 许可证尚未在此店铺或设备上激活。

检查本地、许可证服务器和更新程序的状态，然后为所指的店铺激活许可证。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持。

## 故障排除 {#troubleshoot}

**在店铺端**——供网站管理员或许可证持有人操作：

1. 前往 **WP Admin > POS > 设置 > 许可证**。已激活的许可证会显示 **“许可证 … 已激活”**；否则，页面会显示 **许可证密钥** 字段。（如果显示的是升级卡片，则表示 WCPOS Pro 插件尚未启用；请先在 **WP Admin → 插件** 中启用它。）
2. 如果尚未激活，请将 WCPOS 账户中的密钥粘贴到 **许可证密钥** 中，然后点击 **激活**。
3. 网站 URL 变更（从 http 改为 https、添加或移除 www、更换域名、创建预发布副本）会使许可证仍绑定在旧地址上。请先在旧地址停用许可证：如果旧网站仍可访问，可在其 **许可证** 页面操作，也可从 [WCPOS 账户页面](https://wcpos.com/account/licenses)操作。如果旧网站已不存在，请发送邮件至 **support@wcpos.com** 以重置激活状态。然后，在当前网站的 **许可证密钥** 中输入 WCPOS 账户中的完整密钥，并点击 **激活**；如果页面显示许可证已激活，请先点击 **停用**（页面只显示缩略密钥，点击 **停用** 会清除它）。
4. 如果许可证显示已激活，但 POS 仍未识别，请先从 WCPOS 账户复制完整密钥（页面只显示缩略密钥，点击 **停用** 会清除它）。然后点击 **停用**，将密钥粘贴到 **许可证密钥** 中，再点击 **激活**。
5. 功能仍未解锁？请在收银机的 **店铺健康状况 → 日志** 中使用 **复制调试信息**，并在联系支持时提供许可证信息。

**在收银机端：** 许可证激活后，请重新加载应用以使更改生效。
