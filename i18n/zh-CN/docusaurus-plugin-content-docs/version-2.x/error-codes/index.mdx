# 错误代码 {#error-codes}

WCPOS 遇到问题时会显示错误代码，帮助您识别问题。从 **v1.10.0** 起，代码采用 **领域 + 三位数字** 的格式，例如 `SYNC131` 或 `AUTH311`。领域表示 POS 中的功能范围，数字则标识具体情况。每个代码都有专属页面，说明其含义、处理方法以及对数据的影响。

在 POS 中，错误代码显示在 **店铺健康 → 日志** 中：展开某一行，点击 **帮助** 链接即可直接跳转到本文档中对应的代码页面。

## 错误领域（v1.10.0+） {#error-domains}

| 领域 | 范围 |
|--------|------|
| [`AUTH`](#auth) | 登录、会话和令牌 |
| [`CHECKOUT`](#checkout) | 在收银台完成订单 |
| [`CLIENT`](#client) | POS 应用本身及本地存储 |
| [`DISPLAY`](#display) | 面向顾客的显示屏 |
| [`HOST`](#host) | 阻止 POS 连接的主机和防火墙规则 |
| [`LICENSE`](#license) | Pro 许可证的激活和验证 |
| [`PAYMENT`](#payment) | 支付网关和终端 |
| [`PRINT`](#print) | 收据打印 |
| [`PRODUCT`](#product) | 商品数据和目录操作 |
| [`REGISTER`](#register) | 钱箱、收银会话和盘点 |
| [`SYNC`](#sync) | POS 与店铺之间的同步 |

在下方查找您的代码，或直接搜索。

以 `999` 结尾的代码是该领域的通用代码，用于尚未分配专用代码的情况。

## v1.10.0 之前的代码 {#legacy-codes}

`API04001` 等代码来自 v1.10.0 之前的版本，当前版本不会产生这些代码。您仍可能在升级前保留的日志条目或旧的支持讨论中看到它们。将版本菜单切换到 **1.x** 即可查阅。
