## 这意味着什么 {#what-this-means}

WCPOS Pro 因版本与 WCPOS 不匹配而被禁用。

更新所指的 WCPOS 或 WCPOS Pro 组件，使两者版本兼容。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续存在，请联系 WordPress 网站管理人员。

## 故障排除 {#troubleshoot}

1. 在 WP Admin → 插件中检查两个插件的版本；日志条目会指出 WCPOS 和 WCPOS Pro 中哪个版本较旧。
2. 更新版本较旧的插件；将两者都更新到最新版本即可解决版本不匹配的问题。
3. 如果没有提供 Pro 更新，可能是更新程序未获授权（参见 LICENSE301）；请先解决授权问题，再进行更新。
