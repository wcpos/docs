## 含义 {#what-this-means}

店铺前方的代理因响应头过多而拒绝服务器响应。

缓存或代理层（通常是 Varnish）对响应头的数量或大小设有限制。店铺的轻量级端点未超出限制，但完整的 API 响应超出了限制，因此代理返回 503，而不是 WordPress 返回的。需要提高该层的限制。

## 您的数据 {#your-data}

订单或商品数据均不受影响。

## 故障排除 {#troubleshoot}

1. 在 Varnish 中，提高 http_max_hdr（响应头数量）以及 http_resp_hdr_len / http_resp_size（大小）的值。
2. 询问主机服务商是哪一层代理返回了 503。WordPress 错误日志中不会有记录，因为请求并不是在 WordPress 中失败的。
3. 快速检查：店铺的 /wcpos/v2/ping 响应正常，但数据端点返回 503。
