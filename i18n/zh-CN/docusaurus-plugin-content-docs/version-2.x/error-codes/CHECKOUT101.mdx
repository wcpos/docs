## 含义 {#what-this-means}

结账未完成，购物车仍完好保留，可以放心重试。

请检查购物车并重新结账，当前购物车内容已保留。

## 您的数据 {#your-data}

订单本身完好无损，未发生任何更改。

## 故障排查 {#troubleshoot}

**在收银端** — 收银员操作：

1. 请检查购物车并重新尝试结账，购物车未发生任何更改。
2. 如果再次失败，请展开店铺健康状况 → 日志中的日志条目，serverCode 和状态会说明店铺是否拒绝了订单以及原因。
3. 如果原因中指出了某个具体订单项，请移除该项，完成销售后再排查该商品。

**在店铺端** — 网站管理员操作：如果反复失败并返回 500 类状态码，则属于网站问题。请在 WooCommerce → 状态 → 日志中检查失败时是否有 PHP 错误。
