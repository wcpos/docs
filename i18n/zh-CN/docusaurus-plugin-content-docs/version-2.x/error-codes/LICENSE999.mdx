## 这意味着什么 {#what-this-means}

许可证检查遇到了意外问题。

POS 会继续运行。如果 Pro 功能仍未解锁，请重新输入许可证密钥，然后联系支持。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持。

## 故障排除 {#troubleshoot}

1. 继续工作即可；POS 不会因许可证检查而停止运行。
2. 如果 Pro 功能仍未解锁，请店铺管理人员打开 **WP Admin > POS > 设置 > 许可证**。如果许可证显示已激活，请准备好 WCPOS 账户中的完整密钥（页面只显示缩略密钥），先点击 **停用**；然后在 **许可证密钥** 中输入密钥，并点击 **激活**。
3. 在收银机上重新加载应用，以重新获取许可证状态。
4. 如果 Pro 功能仍未解锁，请在 **店铺健康状况 → 日志** 中使用 **复制调试信息**，并在联系支持时提供许可证信息。
