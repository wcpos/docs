## 含义 {#what-this-means}

店铺中已没有此订单，因此此设备已对本地副本作出相应处理。

有人在 WP Admin 中删除了订单（移入回收站），而此设备上仍保留着它。店铺端的副本已不存在，因此此设备会将购物车保留为新订单，或移除本地副本。

## 您的数据 {#your-data}

未结购物车会被保留，并以新编号的新订单重新发送。它会在您下次点击 **结账** 时发送。其他状态的订单会从此设备上移除，因为店铺端的副本已不存在。没有其他内容等待发送。

## 故障排查 {#troubleshoot}

1. 展开日志条目，其中会指出店铺删除的订单编号，以及此设备是将购物车保留为新订单，还是移除了本地副本。
2. 如果购物车已保留，销售可正常继续。点击 **结账** 时，它会作为新编号的新订单传送到店铺。
3. 如果订单被误删，店铺管理员可以在 WP Admin 的 **WooCommerce → 订单 → 回收站** 中恢复它。此设备会在下次刷新时重新获取该订单。
4. 如果同一订单反复触发此提示，说明管理员正在删除此设备仍在使用的订单。请约定在将订单移入回收站之前，由谁关闭未结购物车。
