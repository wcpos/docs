## 含义 {#what-this-means}

返回的是机器人防护页面，而非店铺 API 响应。

应用期望收到 JSON，但店铺 REST API 返回的却是 HTML 验证页面（机器人防护、CAPTCHA 或 DDoS 拦截页面）。收银应用无法完成浏览器验证，需要在防护服务中将店铺 REST API 加入允许名单。

## 您的数据 {#your-data}

订单或商品数据均不受影响。

## 故障排除 {#troubleshoot}

1. 根据验证页面识别所用的防护服务（Cloudflare、Sucuri、Kinsta 等都有自己的品牌标识），然后打开其设置。
2. 为 API 流量将店铺自身的 REST API 路径（/wp-json/ 和 /?rest_route=）加入允许名单。
3. 在 Cloudflare 中，为 REST API 路径添加一条 WAF **跳过**规则；机器人对抗模式（免费套餐）无法通过任何规则绕过，必须关闭。[Cloudflare 指南](/troubleshooting/common-problems/cloudflare)提供了具体规则和 `curl` 检查方法。
4. 在 Kinsta 的机器人防护或防火墙设置中，将 REST API 路径加入允许名单；在 Sucuri 中，避免对 API 路由使用带 JavaScript 验证的 DDoS 模式。
