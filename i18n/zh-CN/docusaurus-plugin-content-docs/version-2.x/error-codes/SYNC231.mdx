## 这意味着什么 {#what-this-means}

店铺已收到此更改，但此设备未能记录其已发送状态。

无需操作，请勿重新录入。WCPOS 会持续重新检查，店铺会忽略重复发送的内容。

销售或修改已发送到店铺并保存在那里。随后，此设备连续三次尝试记录该更改已发送，但均未成功。因此，此更改在设备上仍显示为未发送，WCPOS 会在下次同步时再次发送。店铺会通过标识符识别该更改，并忽略重复发送的内容，因此不会重复保存。唯一的实际风险是有人再次手动录入该销售或修改，这会创建第二份独立的副本。

## 您的数据 {#your-data}

没有任何数据丢失。店铺已保存该更改。在此设备成功记录重新发送的状态之前，它可能仍被计入待发送更改。

## 故障排除 {#troubleshoot}

1. 请勿再次手动录入该销售或修改，店铺已保存它，再次录入会造成重复。
2. 要确认销售已发送到店铺，请检查 WP Admin 中的 **WooCommerce → 订单**。它也会显示在 WCPOS 中，因为它已保存在此设备上。
3. 让 WCPOS 自行同步。店铺会忽略下次重复发送的内容，而该条目通常也会随之清除；清除后，**店铺健康状况 → 日志** 顶部的 **待发送更改** 数量会减少。
4. 如果此问题持续出现，设备可能无法正常写入自身存储。请检查剩余存储空间，然后在 **日志** 选项卡中点击 **复制调试信息**，并联系支持团队。请勿通过清除此设备的数据来解决问题。
