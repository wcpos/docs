## 这意味着什么 {#what-this-means}

店铺已收到此笔付款，并已将其记录在订单上。随后失败的环节影响较小：收银机未能更新自己的订单副本，使其与店铺一致。

款项安全，销售也已记录。支付面板计算剩余应付金额时已计入此笔付款，但收银机上的其他视图（购物车和订单列表）可能要等到数据更新后才会显示最新状态。因此，提示信息会提醒收银员不要再次收取此笔款项。

发生这种情况时，WCPOS 会立即向店铺请求最新的订单副本，因此在大多数情况下，收银机会在几秒内自行恢复正确状态。

## 您的数据 {#your-data}

款项已转移，店铺已收到付款。切勿再次收取此笔款项；只是收银机上的本地订单副本尚未更新，应以店铺的记录为准。

## 故障排除 {#troubleshoot}

**在收银机端**——请在顾客离开前完成以下操作：

1. 请勿再次收取此笔款项。
2. 按支付面板显示的剩余应付金额继续操作；它已计入此笔付款。收取尚未支付的金额；如果没有剩余应付金额，销售就会完成。
3. 请勿使用关闭按钮（**X**）来“重新打开”订单。如果订单上已有付款，点击关闭会打开 **取消付款**，该操作会退还款项，而不是刷新数据。
4. 如果销售完成后收银机显示的状态仍未更新，请打开 **店铺健康状况 → 数据库**，打开 **订单** 行的 **⋮** 菜单，然后选择 **立即检查更改**。

**在店铺端**——供网站管理员操作：

1. 店铺端无需修复，因为它已接受付款。**WooCommerce → 订单** 中的订单会显示当前状态。
2. 如果收银机反复无法保存本地副本，请在该设备的 **店铺健康状况 → 数据库** 中检查 **已用存储空间** 数值，并确认设备的可用空间是否不足。其本地数据库可能已满或出现故障。
