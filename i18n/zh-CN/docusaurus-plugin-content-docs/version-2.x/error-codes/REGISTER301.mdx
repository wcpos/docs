## 含义 {#what-this-means}

盘点差额超出了店铺设定的上限，因此需要经理审批。店铺拒绝了该审批，收银机仍处于开启状态，停留在盘点步骤。

## 您的数据 {#your-data}

盘点结果保留在此设备上，没有数据丢失。您输入的钱箱金额仍显示在屏幕上，可以再次尝试。

## 故障排查 {#troubleshoot}

1. 检查用户名和密码。审批使用常规的 WordPress 登录验证，区分大小写。
2. 收银员不能审批自己的盘点。审批人必须使用不同于关班人员的账号，也不能使用开启该会话的账号。
3. 审批账号需要有管理收银机关班的权限。店铺经理默认拥有此权限，收银员则没有。
4. 如果审批仍然失败，可以保留盘点结果，让经理使用自己的账号登录后关班。请先记下盘点总额。
5. **店铺管理员：** 同一收银终端反复被拒绝值得关注。每次尝试都会留下记录；如果钱箱现金短缺且多次审批失败，应调查这一情况。
