## 这意味着什么 {#what-this-means}

此设备上的某条记录副本与店铺端不一致。您录入的内容均不受影响。

在 **店铺健康状况 → 数据库** 中，对该列表使用 **清除并重新下载**，用店铺端的副本替换此设备上的副本。在此之前，该记录可能显示过时的价格或库存。请先检查是否有待发送的内容，参见“故障排除”。

## 您的数据 {#your-data}

销售和未发送的更改均不受影响。在替换之前，此设备上的记录副本可能显示过时的价格或库存。如果此问题持续发生，请在 **日志** 选项卡中使用 **复制调试信息**，并联系 WCPOS 支持团队。

## 故障排除 {#troubleshoot}

1. 可以继续销售。打开 **店铺健康状况 → 数据库**，顶部会列出该记录：副本不一致的记录显示为 **“… 无法从店铺下载”**，店铺端已删除的记录显示为 **“… 必须从此设备移除”**。
2. 销售该商品之前，请对照货架上的信息核实其价格和库存，或向店铺负责人确认，他们可以与 WP Admin 中的信息进行比对。
3. 清除任何内容之前，请在 **店铺健康状况 → 数据库** 中确认 **待发送更改** 为 0，且未显示 **“… 项更改从未发送到服务器”** 或 **“… 项更改已暂缓发送”** 面板。这些更改仅存在于此设备上，清除其所在列表可能导致更改丢失。请等待数量变为 0，并先处理所有列出的更改（[SYNC201](/error-codes/SYNC201)、[SYNC221](/error-codes/SYNC221)）。清除 **订单** 之前，还必须使用 **保存到服务器** 保存此设备上所有未完成的购物车，或完成结账。从未保存到店铺的购物车仅存在于此设备上，且不会计入上述任何检查，因此清除 **订单** 会将其删除。如果某个购物车无法保存，请跳过 **订单** 行并联系支持团队。然后打开该记录所在列表（例如 **商品**）的 **⋮** 菜单，选择 **清除并重新下载…**。设备会丢弃本地副本并获取店铺端的副本，店铺端已删除的记录也会被移除。该条目可能会一直保留到下次后台检查，请以价格和库存现在是否一致来判断是否解决。如果提示随后列出了另一个列表中的记录，请对该列表重复此步骤，同样要先完成检查。
4. **网站管理员：** 如果重新下载后仍反复出现相同的记录，通常是因为某次批量更改绕过了 WooCommerce 的保存钩子，例如 CSV 导入、迁移插件、WP-CLI 或直接执行 SQL。请尽量通过 WooCommerce 进行修改，以确保收银端的检查准确；如果同一差异持续出现，WCPOS 会自动重建其完整性数据。
5. 如果重新下载后，收银端仍显示错误的价格或库存，请在 **日志** 选项卡中使用 **复制调试信息**，并联系支持团队。
