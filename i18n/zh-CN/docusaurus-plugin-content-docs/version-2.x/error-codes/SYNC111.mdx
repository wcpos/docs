## 含义 {#what-this-means}

此设备上存储的部分数据已损坏，无法同步。

点击 **日志** 选项卡顶部的 **复制调试信息**，并将信息发送给 WCPOS 支持团队。不要重新安装 WCPOS、退出登录或清除其数据：尚未传送到店铺的更改仅保存在此设备上。

## 您的数据 {#your-data}

不要清除此设备的数据，其中可能存有尚未传送到店铺的销售记录。重新安装应用或退出登录也可能将其删除。支持团队可以告知您哪类数据可以安全地重新下载。

## 故障排查 {#troubleshoot}

1. 如果 WCPOS 仍能正常运行，可以继续销售。不要重新安装、退出登录或清除其数据。
2. 在 **日志** 选项卡中，点击顶部的 **复制调试信息**，将信息发送给 WCPOS 支持团队，并说明该条目出现时您正在进行什么操作。
3. 打开 **店铺健康状况 → 数据库**，告知支持团队其中显示的 **等待发送的更改** 数量，以及是否显示 **“… 项更改未能传送到您的服务器”** 或 **“… 项更改已暂缓”** 面板。这些更改仅保存在此设备上。
4. 日志条目不会说明哪些数据已损坏。在没有任何更改等待发送后，支持团队可能会让您重新下载某一类数据（通过该行的 **⋮** 菜单 → **清除并重新下载…**）。在支持团队确认具体类别前，不要执行此操作：清除了错误的数据，或在仍有更改等待发送时清除数据，都可能删除尚未传送到店铺的销售记录。如果数据损坏导致更改无法发送，支持团队会先恢复这些更改；只要还有内容等待发送，就绝不要重新下载。
