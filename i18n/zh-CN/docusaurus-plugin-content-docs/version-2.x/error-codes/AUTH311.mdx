## 这意味着什么 {#what-this-means}

WCPOS 无法访问店铺上的连接端点。

请让站点管理员确认 WCPOS 插件已启用（**WP Admin → 插件**），并检查是否有安全插件拦截 REST API。

## 您的数据 {#your-data}

订单和商品数据均不受影响。请告知站点管理员。

## 故障排除 {#troubleshoot}

**在收银台**——收银员操作：请告知站点管理员。此设备上的内容均不受影响。

**在店铺端**——站点管理员操作：

1. 确认 WCPOS 已启用：WP Admin → 插件。
2. 如果两种 REST 地址形式都无法使用，请检查是否有安全插件、代理或 CDN 移除了 WCPOS 请求标头，或拦截了 REST 请求——常见原因是防火墙规则，以及禁用 REST API 的安全加固选项。
3. 在某些托管环境中，重新保存固定链接（设置 → 固定链接 → 保存更改）可以恢复缺失的 REST 路由。
