## 含义 {#what-this-means}

此店铺返回的标识与此设备上已保存的某个店铺相同。

每个店铺都有一个由 WCPOS 插件一次性创建的标识。复制网站时，例如为了创建预发布网站，副本会保留原网站的标识，因此应用无法区分两者，会拒绝保存第二个店铺，以免将其与第一个混在一起。

这两个网站中，一个是另一个的副本。标识冲突本身无法说明哪一个是副本：如果先连接的是副本，您刚才尝试连接的店铺就是原网站。网站管理员知道哪一个是复制出来的，需要新标识的正是这个副本。

## 您的数据 {#your-data}

拒绝保存本身不会改变任何内容：已保存的店铺保持原样，新店铺未被保存。

但下方第二种解决方法中的移除已保存店铺操作则不同。该店铺下尚待同步的销售记录仍保留在设备上，但重新添加店铺后不会自动恢复使用。移除店铺前，请确认已保存的店铺没有待同步内容；如果仍有，请先联系支持团队。

## 故障排查 {#troubleshoot}

**在网站副本上** — 该 WordPress 网站管理员操作：

1. 确定两个网站中哪一个是副本（通常是预发布或测试网站）。
2. 在副本上：前往 WP Admin → 插件 → 将 WCPOS 更新至最新版本。从 1.10.21 起，插件首次在新地址运行时，会为复制的网站赋予独立标识。更新原网站对此没有作用，因为其地址未发生变化。
3. 从收银端再次连接。

**在收银端** — 如果副本暂时无法更新：

1. 确认提示中指出的已保存店铺的每笔销售记录都已同步。如果仍有记录等待同步，请先同步，或在继续之前联系支持团队。
2. 在连接界面上，移除该已保存的店铺。
3. 通过地址连接您需要的店铺。

在副本拥有独立标识之前，您只能保持其中一个店铺的连接。

**如果两个地址指向同一店铺**（例如局域网地址和公共域名）：移除已保存的条目，然后使用此收银机今后要使用的地址重新连接。移除之前，同样需要检查是否存在未同步的销售记录。
