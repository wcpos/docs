## 含义 {#what-this-means}

登录令牌的大小超出了此服务器允许的范围。

服务器因登录令牌过大而拒绝了它：通过 Authorization 请求头传送时返回 400，通过 URL 传送时返回 414。客户端编码无法缩小令牌，必须提高服务器的请求头／URL 大小限制，或缩小令牌本身。

## 您的数据 {#your-data}

订单和商品数据均不受影响。

## 故障排查 {#troubleshoot}

1. 在 Apache 上，请在虚拟主机配置中增大 LimitRequestFieldSize（通过请求头传送时）或 LimitRequestLine（通过 URL 传送时）。
2. 在 nginx 上，请增大 large_client_header_buffers。
3. 如果使用了代理或 CDN，限制也可能来自该层，请同时检查服务器和这一层。
4. 如果无法更改限制，请联系支持团队，咨询如何为此网站签发更小的令牌。
