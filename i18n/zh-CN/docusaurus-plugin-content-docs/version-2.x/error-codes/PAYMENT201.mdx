## 这意味着什么 {#what-this-means}

WCPOS 无法确认终端是否已扣款。

再次尝试扣款前，请先检查支付终端；如果结果仍不明确，请联系支付服务商。

## 您的数据 {#your-data}

无法确认支付结果，请核实后再重试。如果问题持续存在，请联系支付服务商。

## 故障排除 {#troubleshoot}

1. 暂时不要再次刷卡。
2. 先查看终端自身的屏幕，再查看支付服务商的管理面板；是否扣款成功应以服务商的记录为准。
3. 如果您有 WP Admin 访问权限，请查看 WooCommerce → 订单，也可请店铺所有者代为查看；成功的付款可能已经记录在那里。
4. 只有在服务商的管理面板显示没有扣款后，才能再次收款。
5. 如果扣款显示为处理中或结果不确定，请先联系支付服务商，再采取行动。
