## 这意味着什么 {#what-this-means}

此店铺无法使用所选的支付网关。

请网站管理员确认该网关受支持、已启用且配置正确。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续存在，请联系 WordPress 网站管理人员。

## 故障排除 {#troubleshoot}

**在收银机端：**

1. 在问题解决前，可先使用现金等其他方式完成销售。
2. 如果付款方式在支付面板的 **… 当前不可用** 下呈灰色，说明是此收银机自身的问题，而不是本错误所指的问题；显示的原因（例如 **需要网络连接** 或 **开启蓝牙以使用读卡器**）会告诉您需要解决什么。

**在店铺端**——供网站管理员操作：

3. 前往 **WP Admin > POS > 设置 > 收银台**。该网关必须列在 **支付网关** 下，且 **已启用** 开关处于开启状态。如果未列出，请检查其插件是否已安装并启用。无需在 **WP Admin > WooCommerce > 设置 > 付款** 中启用该网关：POS 会列出所有已启用插件注册的网关。WCPOS 免费版只能启用内置的现金和银行卡付款方式；其他 WooCommerce 网关需要 WCPOS Pro。
4. 如果网关昨天还能使用，请检查它或 WooCommerce 是否有过更新；**WooCommerce → 状态 → 日志** 中可能记录了网关启动错误。
5. 修复后，请在收银机上重新加载应用，以重新识别该网关。
