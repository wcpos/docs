## 含义 {#what-this-means}

店铺地址缺失或不是有效的 URL。

可能是地址字段为空，也可能是店铺已响应，但其 WCPOS 登录地址无效。后一种情况需要在店铺端修复，而非收银端。

## 您的数据 {#your-data}

订单和商品数据均不受影响。

## 故障排查 {#troubleshoot}

1. 在 **输入您的 WooCommerce 店铺 URL** 中填写店铺地址，例如 `shop.example.com`，然后按 **连接**。仅包含空格的字段视为空。
2. 如果已填写地址，且提示为 **“WCPOS 登录 URL 无效。请确保 WCPOS 插件已正确配置”**，则问题出在店铺端。**网站管理员：** 请在 **WP Admin → 插件** 中将 WCPOS 更新至最新版本，然后再次按 **连接**。不要通过停用后重新启用来解决此问题，重新启用会将所有角色的 POS 权限重置为默认值。
3. **网站管理员：** 如果问题仍未解决，请在浏览器中打开店铺完整地址并在末尾加上 `/wp-json/`，例如 `https://your-store.com/wp-json/`；如果 WordPress 位于 `/shop`，则使用 `https://example.com/shop/wp-json/`。如果返回 404（例如使用朴素固定链接时），请改为在同一地址末尾加上 `/?rest_route=/`。在 `authentication` → `wcpos` → `endpoints` 下，`authorization` 应为普通网址。如果它是列表、对象或数字，则说明安全、缓存或 REST 自定义插件正在修改该响应。请在预发布副本上逐一停用这些插件，找出问题来源。
