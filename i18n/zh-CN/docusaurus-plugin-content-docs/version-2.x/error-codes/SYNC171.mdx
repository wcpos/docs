## 含义 {#what-this-means}

WCPOS 无法在此设备上创建或移除存储。

释放设备存储空间，然后重启 WCPOS。使用网页版时，浏览器也可能限制了站点的存储，隐私窗口就会如此。如果持续失败，请联系支持团队。

## 您的数据 {#your-data}

这是存储问题，并非编辑被拒绝。如果发生在清除此设备数据的过程中，部分数据可能已被删除，包括尚未发送的更改。请检查最近的销售记录和更改是否已显示在店铺中。如果问题持续出现，请使用 **日志** 选项卡中的 **复制调试信息**，并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 检查设备的可用存储空间，并删除其他文件或应用以腾出空间。磁盘或浏览器存储配额已满时，创建存储会直接失败。不要使用浏览器的“清除浏览数据”来腾出空间，这也会删除 WCPOS 尚未发送的销售记录。
2. 重启 WCPOS，然后重试同一操作。
3. 使用网页版时，请检查浏览器是否允许站点使用持久存储。隐私窗口和阻止所有数据的设置都不允许这样做。
4. 如果持续失败，请使用 **日志** 选项卡中的 **复制调试信息**，并联系支持团队。
