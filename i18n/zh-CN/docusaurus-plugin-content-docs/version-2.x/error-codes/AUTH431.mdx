## 含义 {#what-this-means}

使用应用支持的所有地址形式访问店铺 REST API，均未获得响应。

应用尝试通过常规地址（/wp-json/...）和 WordPress 内置的备用地址（/?rest_route=...）访问店铺 REST API，但两者均未响应。店铺网站本身可能正常运行，此问题特指 REST API 无法访问，通常是安全插件将其隐藏，或防火墙规则将其阻止。

## 您的数据 {#your-data}

订单和商品数据均不受影响。

## 故障排查 {#troubleshoot}

**在店铺端** — 网站管理员操作：如果安全插件（例如 WP Hide）隐藏或重命名了 `/wp-json/`，请同时允许 WordPress 内置的 `/?rest_route=` 地址形式，应用会自动改用该形式。

**在主机／服务器端：**

1. 检查防火墙（WAF）规则中是否有匹配 `wp-json` 或 `rest_route` 的规则，并允许店铺自身的 REST API 通过。
2. 如果服务器前面设有维护页面或人机验证，REST 请求可能会收到 HTML 页面响应。请对 REST API 关闭验证。

**测试方法（任何人均可）：** `https://your-store.com/?rest_route=/` 应返回 JSON，而不是 403 页面或网站首页。
