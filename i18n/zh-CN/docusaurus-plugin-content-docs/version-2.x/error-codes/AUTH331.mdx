## 含义 {#what-this-means}

此店铺的 WCPOS 插件版本过旧，无法与当前应用版本配合使用。

应用已更新，但店铺上的 WCPOS 插件尚未更新，两个版本已无法配合使用。请让网站管理员在 WP Admin 中更新 WCPOS 插件，然后再次连接。收银端无需做任何更改。

## 您的数据 {#your-data}

订单和商品数据均不受影响。如果问题持续存在，请联系您的 WordPress 网站管理员。

## 故障排查 {#troubleshoot}

**在店铺端** — WordPress 网站管理员操作：

1. 前往 WP Admin → 插件 → 将 WCPOS 更新至最新版本。如果安装了 WCPOS Pro，请同时将其更新至匹配的版本。
2. 如果未显示可用更新，请检查 WP Admin → 仪表盘 → 更新；对于 Pro，未经授权的更新程序会阻止更新（参见 [LICENSE301](./LICENSE301)），请先解决此问题。

**在收银端** — 收银员操作：店铺更新后，重新连接。您无需再次输入店铺地址。

**如果店铺暂时无法更新：** 请联系支持团队。收银机需要使用与插件匹配的应用版本，支持团队可以告诉您应使用哪个版本。他们会询问应用版本（在收银端查看）和店铺当前的 WCPOS 版本（在 WP Admin 中查看）。
