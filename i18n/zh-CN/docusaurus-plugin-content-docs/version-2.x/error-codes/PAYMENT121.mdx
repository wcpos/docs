## 这意味着什么 {#what-this-means}

终端已收款，店铺已收到款项。失败的是随后结束订单的步骤，因此这笔销售已付款，但订单仍处于未结状态。

这不是支付问题，再次从银行卡扣款会导致重复收费。只需完成订单即可。

## 您的数据 {#your-data}

款项已转移：银行卡已扣款，店铺已收到付款。订单处于未结而非已完成状态，因此需要完成订单，无需再次付款。

## 故障排除 {#troubleshoot}

**在收银机端**——请在顾客离开前完成以下操作：

1. 请勿再次收款，也不要点击支付面板上的关闭按钮（**X**）。如果订单上已有付款，点击关闭会打开 **取消付款**，从而撤销付款。
2. 重新加载应用（网页版重新加载浏览器标签页；桌面版和移动版关闭后重新打开应用）。启动时，收银机会重新尝试完成所有已记录银行卡付款的销售，完成的订单会从购物车中移除。
3. 如果重新加载后，订单在购物车中仍处于未结状态，请打开 **店铺健康状况 → 数据库**，打开 **订单** 行的 **⋮** 菜单，选择 **立即检查更改**，然后再次重新加载。
4. 如果订单仍未结，请继续为顾客提供服务，并保持订单原样；款项已经收取。请店铺管理人员按下述方法完成订单。

**在店铺端**——供网站管理员操作：

1. 如果订单仍无法在收银机上完成，请在 **WooCommerce → 订单** 中打开它，并在支付服务商的管理面板中确认扣款；如果使用了拆分付款，请确保每一部分都已支付。然后将订单设为 POS 对此种付款方式使用的销售状态：在 **WP Admin > POS > 设置 > 收银台** 中，**支付网关** 表格的 **订单状态** 列会在收取该笔付款的网关所在行显示此状态。
2. 如需了解原因，请展开收银机通知中的 **支持详情**，或查看 **店铺健康状况 → 日志** 中的条目：其中会指出完成步骤在哪个环节失败，通常是在关键时刻连接中断。联系支持时，请附上这些信息。
