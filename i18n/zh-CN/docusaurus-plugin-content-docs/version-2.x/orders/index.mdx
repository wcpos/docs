订单页面需要 [WCPOS Pro](../getting-started/pro-license.mdx)。未使用 Pro 时，您只能看到模糊的列表预览，需在 WP Admin 的 **WooCommerce → 订单** 中管理订单。

菜单中的 **订单** 会列出店铺的销售记录。客户再次到店时，您可以在此查找销售记录、重印收据、退款，或将订单放回购物车进行修改。这些操作都无需切换到 WP Admin。

## 查找订单 {#find-an-order}

列表默认显示 **您本人在当前店铺的销售记录**，最新记录排在最前面。查找销售记录的方法：

1. 在顶部的 **搜索订单** 中输入订单号、客户姓名、电话、电子邮箱或商品。
2. 如果列表中没有该记录，可能是由其他收银员经办：点击 **收银员** 筛选标签上的 **×**，搜索所有人的销售记录。如果销售发生在其他店铺或线上，请更改 **店铺** 筛选标签。
3. 点击销售记录即可打开。请参阅[打开订单](#order-details)。

打开订单页面后，可以扫描纸质收据上的订单号条形码，无需手动输入。扫描结果会填入 **搜索订单** 并显示相应的销售记录。请参阅[条形码扫描器](../hardware/scanners/index.mdx)。

<details>
<summary>搜索匹配的内容</summary>

订单号、客户的姓名、公司和电话（账单或配送信息）、账单电子邮箱，以及订单中商品的名称或 SKU。请参阅[搜索匹配的内容](../reference/search.mdx#orders)。

</details>

打开页面时，**收银员** 筛选标签显示您本人，**店铺** 筛选标签显示您登录的店铺（如果站点只有一家店铺，则显示 **POS**）。销售记录按店铺时区的日期分组，每日有一个标题，最新记录排在最前面。

1. **搜索订单**：输入订单号、姓名、电话号码或商品。
2. **筛选标签**：缩小列表范围。请参阅[筛选列表](#filters)。
3. **收银员**：打开页面时设为您本人。点击 **×** 可查看所有收银员的销售记录。

## 打开订单 {#order-details}

点击订单所在行即可打开。使用鼠标时，点击行末的箭头（<Icon name="chevron-right" />），或使用方向键选中一行并按 **Enter**。订单会在右侧面板中打开，默认显示 **查看** 选项卡。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[350, 0], [24, -29], [26, -29], [19, -29], [28, -29], [31, -29]]} alt="从订单页面打开的订单，位于“查看”选项卡：日期、店铺和收银员信息、商品、总计和现金付款，以及底部的“删除”“退款”“同步”“关闭”“收据”和“重新打开”按钮">

1. **订单详情**：下单时间、店铺、经办收银员及订单来源。
2. **删除**：将已保存的订单移至店铺的回收站。请参阅[删除订单](#delete)。
3. **退款**：打开退款表单。请参阅[为订单退款](#refunds)。
4. **同步**：从店铺获取此订单的最新数据。请参阅[同步单个订单](#sync)。
5. **收据**：打开订单收据，以便重新打印或通过电子邮件发送。请参阅[重印收据](#receipt-reprinting)。
6. **重新打开**：将订单放回购物车进行修改。请参阅[更改商品或数量](#reopening-orders)。

</JourneyShot>

可见的按钮因订单而异；请参阅[订单操作](#order-actions)。如果本机没有该订单，面板会显示 **未找到订单**。

<details>
<summary>“查看”“编辑”和 JSON 选项卡</summary>

- **查看**：显示客户购买时的订单内容。请参阅[“查看”中的内容](#view-tab)。
- **编辑**：通过表单更改订单详情。请参阅[更改状态、客户或地址](#editing-orders)。
- **JSON**：订单的原始数据，用于技术支持和故障排查。打开商品、客户或优惠券时，也会有相同的 **JSON** 选项卡。

</details>

### “查看”中的内容 {#view-tab}

“查看”将整个订单呈现在一个可滚动的页面中，包括状态、商品、总计、付款、退款和客户信息。

<details>
<summary>“查看”中从上到下的各部分</summary>

- **状态**：订单的状态徽章。部分退款的订单显示 **部分退款**；未结订单显示 **POS 未结** 或 **POS 部分付款**。
- **订单详情**：日期和时间、店铺（如果订单关联了店铺）、收银员，以及表示订单来源的图标。
- **商品**：每个条目的数量、商品、价格和总计，以及各项费用。没有条目的订单会显示 **无订单条目。**
- **总计**：小计、折扣、运费、费用和税费，每个税率各占一行。退款后，退款金额以红色显示，最后一行是 **净付款额**；否则为 **总计**。
- **付款**：订单的付款方式和金额。已付款订单显示 **已收款** 及付款日期，有交易 ID 时也会显示。分多次付款的订单会在 **付款记录** 下列出每笔付款。通过电子邮件发送的付款账单会显示发送地址和时间。
- **退款**：如果订单有退款，会列出每笔退款记录。
- **客户**：姓名、电子邮箱、电话、客户备注、账单地址、配送地址（与账单地址不同时）以及税号。

</details>

## 订单操作 {#order-actions}

<details>
<summary>订单会显示哪些按钮</summary>

| 按钮 | 作用 | 显示条件 |
|--------|--------------|-----------------|
| **重新打开** | 将订单放回购物车，以便修改并再次收款。 | 使用 Pro 时始终显示。 |
| **收据** | 显示收据，以便打印或通过电子邮件发送。 | 订单已保存到店铺后。 |
| **重新发送** | 在结账页面重新打开订单，并预先选中付款账单支付方式，以便发送新的付款账单。 | 订单正在等待客户支付通过电子邮件发送的付款账单时。 |
| **同步** | 从店铺重新获取这一个订单。 | 订单已保存到店铺后。 |
| **删除** | 删除订单。 | 使用 Pro 时始终显示。 |
| **退款** | 打开退款表单。 | 订单已保存到店铺，且状态为已完成、处理中或保留时。 |
| **取消付款账单** | 撤回通过电子邮件发送的付款账单。需要联网。 | 订单正在等待客户支付通过电子邮件发送的付款账单时。 |

</details>

### 重印收据 {#receipt-reprinting}

再次打印收据或通过电子邮件发送收据的方法：

1. 打开订单，点击底部的 **收据**。
2. 打印收据，或通过电子邮件发送给客户。请参阅[重印收据](../receipts/index.mdx#reprint)。

要从列表中一键重印，请在[显示设置](#display-settings)中启用 **收据** 列。随后，每笔已保存订单所在行都会显示收据按钮。尚未传送到店铺的订单没有收据按钮。

### 更改状态、客户或地址 {#editing-orders}

打开订单的 **编辑** 选项卡。此处不能更改订单条目；要修改条目，请重新打开订单。

- **状态**：选择新状态，然后点击 **更新状态**。店铺收到更新后，会显示 **状态已更新**。
- **客户、客户备注和地址**：修改相应字段。这里没有保存按钮：每个字段都会在修改时保存，保存成功后显示 **已保存**。**未保存** 表示修改未成功，请再次修改该字段。

<details>
<summary>可以更改的其他详情</summary>

付款方式、货币、交易 ID、税号和元数据。与上述字段一样，各项都会在修改时保存。

</details>

### 更改商品或数量 {#reopening-orders}

:::note 编辑时库存会同步变动
对于已经扣减库存的销售记录，每次修改条目都会立即调整库存。
:::

:::warning 降低总额不会自动退还差额
如果修改后的订单金额低于已付金额，POS 不会退还多付部分。请与客户结清差额；请参阅[为订单退款](#refunds)。
:::

1. 点击订单底部的 **重新打开**。POS 会打开该订单的购物车（在手机上则打开 **购物车** 选项卡），订单状态变为 **POS - 未结**。

2. 修改购物车：
   - **更改数量**：点击数量，输入新值，然后点击 **完成**（对勾）或按 **Enter**。iOS 和 Android 应用没有小键盘，直接在输入框中输入即可。请参阅[更改数量](../pos/cart/line-items.mdx#quantity)。
   - **移除条目**：点击条目的总计，然后点击 **移除**。
   - **添加商品**：像新建销售订单一样，在商品网格中点击商品或扫描商品。每扫描一次添加一件。
   - **更改价格或客户**：请参阅[订单条目](../pos/cart/line-items.mdx)和[选择客户](../pos/cart/index.mdx#customer-selector)。
   - **更改备注或自定义字段**：点击 **结账** 旁的 **⋮**，打开 **订单详情**。请参阅[添加客户备注](../pos/cart/order-actions.mdx#order-note)和[添加额外信息](../pos/cart/order-actions.mdx#order-meta)。

3. 再次结账以完成更新后的订单。已收取的款项会保留在订单中。结账页面会列出这些付款，并且只要求收取尚欠的款项，显示为 **剩余金额**：如果购物车未变且未退款，则无需再收款；如果添加了商品，则收取差额。请参阅[结账](../pos/checkout/index.mdx)。

<details>
<summary>重新打开订单后的库存和付款</summary>

如果该订单已扣减库存（重新打开前已收款），购物车中每次条目变更都会立即调整库存：添加条目或增加数量会扣减商品库存，移除条目或减少数量则会归还库存。再次完成订单不会重复扣减库存。

如果移除商品后订单金额低于已付金额，结账时无需再收款，但 POS 不会代您退还多付部分。请与客户结清差额，例如办理退款。请参阅[为订单退款](#refunds)。

</details>

银行卡付款仍在进行中的订单无法重新打开。提示会说明哪笔付款仍在处理中，请先取消该付款。请参阅[取消付款](../pos/checkout/cancelling-a-payment.mdx)。

### 为订单退款 {#refunds}

您可以在 POS 中进行全额或部分退款，原路退回（支付网关支持时）或从收银设备以现金退还。打开订单并点击底部的 **退款**。

有关收银设备上的退款步骤，请参阅[在收银设备上退款](../pos/refunds.mdx)。有关退款去向、部分退款以及收据上的退款显示方式，请参阅[退款](./refunds.mdx)。

### 同步单个订单 {#sync}

点击 **同步** 可从店铺获取此订单的最新数据，例如有人在 WP Admin 中修改订单后。如果无法连接店铺，会显示“无法刷新此订单。本机上的数据未更改”。请检查网络连接后重试。

### 删除订单 {#delete}

点击 **删除**，然后确认。已保存的订单会移至店铺的 **回收站**，管理员可以从 WP Admin 恢复。尚未传送到店铺的订单将被永久删除，确认提示会说明这一点。

如果您使用收银员角色，会看到 **您没有权限删除服务器上的订单**，订单会保留。请让店铺经理或管理员删除。

<details>
<summary>管理员需了解的权限</summary>

删除订单需要 WordPress 的 `delete_shop_orders` 权限；删除其他收银员的订单或线上订单还需要 `delete_others_shop_orders` 权限。收银员角色不具备这两项权限。

</details>

## 使用订单列表 {#the-list}

滚动时，列表会持续加载更多订单。底部显示已列出的数量（**已显示 10 条，共 240 条**）和同步按钮（<Icon name="arrow-rotate-right" />）。点击可获取新增和已更改的订单；长按可选择 **清除并刷新**，清空搜索，将筛选标签恢复为您本人在当前店铺的销售记录，并重新下载订单。

### 筛选列表 {#filters}

搜索栏下方的筛选标签可缩小列表范围。筛选在服务器上执行，因此涵盖所有订单，而不仅是本机已有的订单。

<details>
<summary>所有订单筛选条件</summary>

| 筛选标签 | 筛选依据 |
|------|--------------------|
| **状态** | 订单状态，例如已完成或处理中。 |
| **付款方式** | 订单的付款方式。 |
| **选择客户** | 指定客户。 |
| **选择收银员** | 经办销售的收银员。移除此条件可查看所有收银员的销售记录。 |
| **店铺** | 指定店铺，或订单来源：**POS**、**在线店铺** 或 **WP Admin**。未选择店铺时，标签显示 **创建来源**。 |
| **选择收银机** | 进行销售时使用的收银机。 |
| **日期范围** | 一段日期。日历提供 **今天**、**昨天**、**本周**、**上周**、**本月** 和 **上月** 快捷选项；点击 **完成** 即可应用。 |

</details>

每个已设置的筛选标签都有一个 **×**，点击即可移除。更改两个或更多筛选标签后，该行末尾会出现 **全部清除**，可将筛选标签恢复为您本人在当前店铺的销售记录。

也可以从订单行进行筛选：点击状态徽章可仅显示该状态的订单，点击客户或收银员姓名可仅显示与其对应的订单。

### 排序和调整列宽 {#sort-and-resize}

点击列标题可按该列排序，再次点击可切换升序和降序。**状态**、**订单号**、**客户**、**创建日期**、**付款方式** 和 **总计** 均支持排序。只有按 **创建日期** 排序时才显示日期标题。排序设置会保留供下次使用。

拖动列标题的右边缘可加宽或缩窄该列。最后一列和 **操作** 列不能调整宽度，离开页面后列宽会恢复默认。

### 列表为空时 {#empty-list}

**暂无订单** 表示您在当前店铺尚无销售记录。您经办的销售记录会显示在这里。

**没有符合这些筛选条件的订单** 表示搜索或筛选标签隐藏了所有记录。点击 **清除筛选条件** 可清空搜索，并将筛选标签恢复为您本人在当前店铺的销售记录。

## 需要关注的销售记录 {#needs-attention}

有时收银设备收取了款项，但店铺随后拒绝接受。例如，订单已在线支付，或店铺只能接受部分款项。发生这种情况时，搜索栏下方会出现红色提示栏：**1 笔销售需要关注**（或 **3 笔销售需要关注**）。

每条记录会列出订单、金额和付款方式，并说明应采取的措施，例如“退还该笔付款”或“退还差额”。提示栏会列出最新的三条记录，然后显示“另有 N 条”。

1. 点击 **打开订单** 查看该销售记录。
2. 与客户结清款项：退还付款或差额，或收取余款。
3. 点击 **已处理** 清除该条记录。

提示栏不会自动重试被拒绝的付款。它只显示您经办的销售记录，其他收银员在同一设备上登录时不会看到您的记录。

## 订单状态 {#order-statuses}

大多数 POS 订单会直接变为 **已完成**，因为款项是在收银设备上收取的。购物车中保持未结、并通过 **同步订单**（**结账** 旁的 **⋮**）保存到店铺的订单，状态为 **POS - 未结**，稍后可以重新打开以完成销售。请参阅[未结订单](../pos/cart/open-orders.mdx)。

POS 订单使用 WooCommerce 的标准订单状态，以及 WCPOS 自有的两种状态。

<details>
<summary>所有订单状态</summary>

| 状态 | 说明 |
|--------|-------------|
| **POS - 未结** | 已从 POS 保存，但尚未付款（暂存或挂起的订单）。 |
| **POS - 部分付款** | 已支付部分金额，余款尚未支付。 |
| **待付款** | 等待付款。 |
| **保留** | 等待处理，例如确认付款。 |
| **处理中** | 已收到款项，正在履行订单。 |
| **已完成** | 订单已履行并完成。 |
| **失败** | 付款失败。 |
| **已取消** | 订单已取消。 |
| **已退款** | 订单已全额退款。 |

</details>

## 出现问题时 {#goes-wrong}

**列表中没有您要找的销售记录。** 列表默认显示您本人在当前店铺的销售记录。移除 **收银员** 筛选标签可查看所有人的记录，或更改 **店铺** 筛选标签。

**“没有符合这些筛选条件的订单”。** 点击 **清除筛选条件**，然后重新搜索。

**缺少另一台收银设备上的新销售记录。** 点击底部的同步按钮。如果仍未出现，请长按该按钮并选择 **清除并刷新**。

**“无法刷新此订单”。** 无法连接店铺。本机上的数据保持不变，请恢复连接后重试。

**“您没有权限删除服务器上的订单”。** 您的 WordPress 角色无法删除订单。请联系经理。

**付款“仍在处理中”，导致订单无法重新打开。** 请先取消该付款，再重新打开订单。请参阅[取消付款](../pos/checkout/cancelling-a-payment.mdx)。
