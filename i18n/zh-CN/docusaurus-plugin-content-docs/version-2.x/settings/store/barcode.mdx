**POS 设置：** 此设备上 POS 中的 `Settings → Barcode Scanning`。条形码字段位于 WP Admin 的常规设置中。

打开 **设置**，选择 **条形码扫描**。大多数店铺无需更改这里的任何选项：插入扫描器或完成配对后即可使用。需要开启扫描提示音，或扫描结果不符合预期时，再来这里调整。

更改会立即保存，没有 **保存** 按钮。这些设置仅属于此设备，因此需要在每台配有扫描器的收银机上分别设置。

**扫描无法正常工作？** 请先[测试扫描器](#test)。测试会显示 POS 收到的内容，并提供解决方法。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[60, 0], [60, 0], [60, 0], [60, 0], [-50, 0], [260, 0], [165, 0], [-50, 0], [150, 0]]} alt="设置中的条形码扫描页面：扫描区域的阈值为 24，最小长度为 8，前缀和后缀为空；声音区域的扫描时播放声音已关闭；扫描器区域显示大多数扫描器无需设置、扫描器设置指南和直接连接；下方可见条形码扫描测试区域的顶部">

1. **条形码平均输入时间阈值（ms）** — 按键输入达到多快才会被判定为扫描。请参阅[区分扫描与打字](#settings)。
2. **条形码最小长度** — 被判定为扫描的条形码所需的最小长度。
3. **条形码扫描器前缀** — 扫描器在每个条形码前添加的字符，查找前会被移除。
4. **条形码扫描器后缀** — 扫描器在每个条形码后添加的字符，查找前会被移除。
5. **扫描时播放声音** — 默认关闭。开启后可选择声音。请参阅[选择扫描提示音](#sound)。
6. **大多数扫描器无需设置** — 在此设备上直接连接或注册扫描器之前，**扫描器** 区域显示的提示。
7. **扫描器设置指南** — 打开[扫描器设置向导](../../hardware/scanners/setup-wizard.mdx)。
8. **直接连接扫描器（高级）** — 适用于键盘模式无法满足需求的情况。请参阅[连接扫描器](#scanner)。
9. **条形码扫描测试** — 在此处扫描，查看 POS 如何判断扫描输入。请参阅[测试扫描器](#test)。

</JourneyShot>

## 区分扫描与打字 {#settings}

不确定该如何设置？请[进行扫描测试](#test)。测试会测量扫描器的输入速度，并提供解决方法。

<details>
<summary>调整扫描检测</summary>

几乎所有扫描器都使用键盘模式，像打字极快的键盘一样输入条形码。POS 会测量按键之间的时间间隔。平均间隔低于阈值时，输入被判定为扫描；高于阈值时，则被判定为打字。**扫描** 区域用于设置这个分界点。

- **条形码平均输入时间阈值（ms）** — 默认值为 **24**。按键的平均间隔低于此毫秒数时，输入会被判定为扫描。扫描器较慢时可调高；快速打字被误判为扫描时可调低。
- **条形码最小长度** — 默认值为 **8**，即被判定为扫描的条形码所需的最小长度。请设为您最短条形码的长度；8 适用于 EAN-8。
- **条形码扫描器前缀** — 默认为空。扫描器在每个条形码前添加的单个字符。POS 会在查找条形码前移除它。
- **条形码扫描器后缀** — 默认为空。扫描器在每个条形码后添加的单个字符，移除方式与前缀相同。

</details>

<details>
<summary>移除多余字符</summary>

除非扫描器设置了添加字符，否则请将 **条形码扫描器前缀** 和 **条形码扫描器后缀** 留空。如果扫描器在每个条形码前添加 `A`、后添加 `Z`，请将前缀设为 `A`，后缀设为 `Z`：扫描得到的 `A4006381333931Z` 将按 `4006381333931` 查找。POS 只会移除条形码对应端的字符，不会移除中间的字符。末尾的 Enter 无需设为后缀，POS 会忽略它。

</details>

<details>
<summary>条形码过短时</summary>

扫描结果短于 **条形码最小长度** 时，POS 不会进行查找，而会显示 **已扫描条形码：** 及条形码内容，并提示 **条形码长度必须至少为 8 个字符**（或您设置的最小长度）。对于键盘模式扫描器，仅当按键输入看起来像扫描（全为数字或以 Enter 结尾）时才会显示此提示，且每 30 秒最多显示一次。短时间内输入少量字母会被视为快速打字，不作处理。

</details>

## 选择扫描提示音 {#sound}

扫描提示音让您无需移开看向顾客的视线，就能听出商品是否已加入购物车，或扫描是否需要处理。选择方法如下：

1. 在 **声音** 下开启 **扫描时播放声音**。其余声音设置会显示在下方。
2. 点击主题名称即可选中。点击该主题的 **▶** 和 **▶✕** 可试听成功和失败提示音。
3. 拖动 **音量** 滑块，点击旁边的 **▶** 试听效果。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-50, 0], [110, -108], [2, -40], [8, -40], [0, -30], [0, -34], [-50, 0], [-50, 0]]} alt="条形码扫描页面，已开启扫描时播放声音：声音主题列表包含经典、收银和柔和，各有说明及两个试听按钮；音量滑块带有独立的试听按钮；下方为成功提示音和失败提示音开关">

1. **扫描时播放声音** — 开启扫描提示音，并显示下方选项。
2. **声音主题** — **经典**、**收银** 或 **柔和**。点击主题名称即可选中。
3. **▶** — 播放该主题的成功提示音，即商品加入购物车时的声音。
4. **▶✕** — 播放该主题的失败提示音。
5. **音量** — 拖动滑块调整，默认音量较低。
6. **音量** 旁的 **▶** — 按当前音量播放所选主题的成功提示音。
7. **成功提示音** — 默认开启。关闭后仅播放失败提示音。
8. **失败提示音** — 默认开启。关闭后仅播放成功提示音。

</JourneyShot>

<details>
<summary>比较声音主题</summary>

每个主题都有成功和失败提示音。应用中的描述如下：

| 主题 | 成功 / 失败 |
|---|---|
| **经典** | 清脆上扬的短音 / 低沉的嗡鸣声。默认主题。 |
| **收银** | 超市风格的单调哔声 / 两声低音 |
| **柔和** | 轻柔的铃声 / 低沉的敲击声，适合安静的店铺 |

试听会按您设置的音量播放，因此可通过试听同时选定主题和音量。

</details>

**各提示音何时播放。** 扫描的商品加入购物车时，会播放成功提示音。扫描后 POS 给出的其他所有结果都会播放失败提示音，包括 **未找到条形码**、**多个匹配结果**、**选择变体**、缺货，以及[屏幕提示说明](../../pos/product-panel/barcode-scanning.mdx#messages)中的其他情况。**正在搜索店铺…** 不播放声音，因为结果尚未返回。

<details>
<summary>iPhone、iPad 和 Android 上的振动</summary>

iPhone、iPad 和 Android 应用还提供 **失败时振动** 开关，默认开启。扫描失败时，设备会在播放失败提示音的同时振动；如果关闭了 **失败提示音**，则仅振动。此功能要求开启 **扫描时播放声音**。▶✕ 试听只播放声音，不会振动。浏览器和桌面应用没有此功能。

</details>

:::tip 保持收银台安静
如需轻柔的提示音，请选择 **柔和** 并调低音量。如需静音，可在 iPhone、iPad 或 Android 应用中保持 **扫描时播放声音** 和 **失败时振动** 开启，同时关闭 **成功提示音** 和 **失败提示音**。这样只有扫描失败时才会通过振动提醒您。
:::

## 连接扫描器 {#scanner}

**扫描器** 区域适用于 POS 根据设备本身而非输入速度来识别的扫描器。几乎所有扫描器都作为蓝牙或 USB 键盘连接，无需在此设置：在设备设置中完成配对后即可扫描。

- **扫描器设置指南** 会打开[扫描器设置向导](../../hardware/scanners/setup-wizard.mdx)，通过几个问题引导您完成设置或解决问题。
- **直接连接扫描器（高级）** 会打开用于连接非键盘模式 USB 或蓝牙扫描器的面板。在 Android 上，此项显示为 **注册扫描器**：它按设备注册键盘模式扫描器，使扫描识别不再依赖打字速度。请参阅[直接连接扫描器](../../hardware/scanners/index.mdx#direct)。

Safari 和 Firefox 中没有 **扫描器** 区域，因为这些浏览器无法直接连接扫描器。

## 测试扫描器 {#test}

屏幕底部的 **条形码扫描测试** 会显示 POS 根据上述设置对每次扫描做出的判断。

1. 准备扫描。在浏览器或桌面应用中，点击所有文本输入框之外的位置。在 iPhone、iPad 或 Android 应用中，点击 **按键事件**。
2. 扫描任意条形码。
3. 查看图表下方的判定结果：**检测为扫描**，或被视为打字的原因。
4. 如果提供了解决建议，点击 **应用**。
5. 再次扫描，检查结果。

这里对同一条形码扫描了两次：一次输入较慢，被视为打字；另一次以扫描器速度输入。

<JourneyShot manifest={manifest} device="tablet" step={3} offsets={[[190, 0], [190, 0], [420, 0], [330, -24], [200, -52], [175, -8]]} alt="快速扫描后的条形码扫描测试：按键事件中收到的按键，检测到的条形码中的内容，带阈值虚线的按键时间图表，检测为扫描的判定及平均按键间隔，最近尝试中的一次扫描和一次打字，以及故障排除指南链接">

1. **按键事件** — 收到的每个按键，包括末尾的 Enter。
2. **检测到的条形码** — 移除前缀和后缀后，POS 将要查找的条形码。
3. **时间图表** — 每个按键对应一个柱条，虚线表示您设置的阈值。超出虚线的琥珀色柱条表示该按键输入过慢。
4. **判定结果** — 显示 **检测为扫描**，或被视为打字的原因。如果某项设置妨碍了识别，系统会提供解决建议，点击 **应用** 按钮即可保存调整。
5. **最近尝试** — 最近几次尝试，每次均标记为 **扫描**、**打字** 或 **过短**，并显示平均按键间隔。
6. **故障排除指南** — 打开[扫描器设置向导](../../hardware/scanners/setup-wizard.mdx)，根据症状寻找解决方法。

</JourneyShot>

测试提供的解决建议包括：扫描器稍慢时 **提高阈值**，条形码短于最小长度时 **降低最小长度**，以及将开头的字符设为前缀并移除。各项判定的详细说明见[在测试面板中检查扫描](../../hardware/scanners/setup-wizard.mdx#test-panel)。

## 遇到问题时 {#goes-wrong}

**测试区域没有显示任何内容。** 请先检查扫描输入的位置。在浏览器或桌面应用中，如果焦点位于文本输入框内，扫描内容会输入该框，因此请先点击输入框之外的位置再扫描；在 iPhone、iPad 或 Android 应用中，请先点击 **按键事件**。如果测试区域仍为空，请检查扫描器是否已配对或插入：请参阅[连接扫描器](#scanner)。

**判定结果显示“视为打字”。** 扫描器的输入速度未达到阈值要求。点击建议中的 **应用**，或调高 **条形码平均输入时间阈值（ms）** 后再次扫描。

**在商品搜索中打字被误判为扫描。** 这种情况会出现在 iPhone、iPad 和 Android 应用中，因为 POS 也会根据搜索输入的速度做出判断。请降低阈值，或提高 **条形码最小长度**。在浏览器或桌面应用中，输入框内的打字不会被判定为扫描。

**条形码开头或末尾有多余字符。** 该字符由扫描器添加。请将它填入 **条形码扫描器前缀** 或 **条形码扫描器后缀**。末尾的 Enter 无需处理。

**“条形码长度必须至少为 8 个字符”。** 条形码短于 **条形码最小长度**。请将该值降低到您最短条形码的长度。

**扫描时没有声音。** 请检查 **扫描时播放声音** 是否开启、对应的 **成功提示音** 或 **失败提示音** 是否开启，以及设备是否处于静音状态。在浏览器中，只有点击或轻触过页面上的任意位置后才能播放声音，因此打开页面后的首次扫描可能没有声音。

**POS 收到了扫描内容，但未显示商品。** POS 会说明原因。请参阅[屏幕提示说明](../../pos/product-panel/barcode-scanning.mdx#messages)。用于存储条形码的商品字段在[条形码字段](../wp-admin/general.mdx#barcode-field)中设置。
