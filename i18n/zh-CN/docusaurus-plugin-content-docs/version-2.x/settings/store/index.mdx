**POS 设置：** POS 内的设置仅影响当前设备。

在**设置**中，可以配置 POS 在当前设备上的运行方式：语言和金额格式、税费显示方式、此收银台的打印机、读卡器和扫描器、顾客显示屏，以及 POS 外观。这里没有保存按钮，任何更改都会立即生效。

这里的更改会保存在当前设备上，包括**税费**设置：重新加载或与店铺同步后也会保留。其他收银台各自保存自己的设置，因此需要在每台收银台上分别配置。

谁可以使用 POS、结账时的付款方式以及收银机，都需要在 WordPress 中设置，而不是在这里。参见 [WP Admin 中的设置](#wp-admin)。

## 打开设置 {#open}

在手机上，点击左上角的菜单（**☰**），再点击**设置**。参见[在手机上](#phone)。

在较宽的屏幕上，点击侧边菜单靠近底部的**设置**，它位于**店铺健康状况**和**支持**之间。设置默认打开**常规**页面，旁边列出七个设置页面。点击页面名称即可打开。完成后，点击侧边菜单顶部的 **POS** 返回收银界面。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[38, -20], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0], [150, 0]]} alt="设置中的常规页面：侧边菜单中的设置按钮高亮显示，旁边的七个页面列表中选中了常规，常规页面显示店铺名称、在 WooCommerce 中设置的地址、语言、默认顾客和货币">

1. **设置** — 位于侧边菜单中，在**店铺健康状况**（带红色计数的脉搏图标）下方、**支持**上方。
2. **常规** — 店铺名称、语言、新购物车的默认顾客，以及金额格式：货币、小数位和分隔符。底部有**恢复服务器设置**。参见[常规](./general.mdx)。
3. **税费** — 税费的计算依据，以及价格是否含税。参见[税费](./tax.mdx)。
4. **打印** — 当前设备使用的收据打印机，以及每个收据模板使用哪台打印机。参见[打印机](../../hardware/printers/index.mdx)。
5. **读卡器** — 此收银台用于收款的读卡器：连接、断开连接或忘记设备。读卡器功能由 WCPOS Pro 提供。参见[读卡器](../../hardware/card-readers/index.mdx)。
6. **顾客显示屏** — 配对面向顾客的第二块屏幕。顾客显示屏功能由 WCPOS Pro 提供。参见[配对顾客显示屏](#customer-display)。
7. **条码扫描** — 设置并测试此收银台的条码扫描器。如果扫描未被识别，或键盘输入被误认为扫描，请参见[条码设置](./barcode.mdx)。
8. **主题** — 颜色、按钮和文字大小、图标及字体。参见[主题](./theme.mdx)。

</JourneyShot>

:::warning 恢复服务器设置会覆盖您的更改
**恢复服务器设置**会将您在此设备上修改的**常规**和**税费**设置替换为店铺的值，**千位分组样式**除外。打印机、扫描器和主题保持不变。参见[恢复服务器设置](./general.mdx#restore-server-settings)。
:::

标有**在 WooCommerce 中设置**的行显示的是店铺发送的值，例如店铺地址或**启用税费**。这些值无法在此处更改：请按旁边的**打开**，前往 WooCommerce 修改。

### 配对顾客显示屏 {#customer-display}

1. 在**设置**中打开**顾客显示屏**。
2. 按**生成配对码**。
3. 在面向顾客的屏幕上打开**显示页面 URL**，然后输入配对码。

## 在手机上 {#phone}

1. 点击左上角的菜单（**☰**），再点击菜单靠近底部的**设置**。
2. 设置会显示七个页面的列表，与[上文](#open)相同。点击其中一个即可打开。
3. 点击顶部的 **‹ 设置**返回列表。
4. 要返回收银界面，请在列表页面点击菜单（**☰**），再点击 **POS**。

## 键盘快捷键 {#shortcuts}

键盘快捷键没有专门的设置页面，也无法更改。在 POS 界面按 **Alt + /** 可查看所有快捷键。参见[键盘快捷键](./hotkeys.mdx)。

## WP Admin 中的设置 {#wp-admin}

谁可以使用 POS、结账时的支付网关、收银机及其备用金、POS 订单发送的电子邮件，以及店铺税号，都需要在 WordPress 的 `WP Admin > POS > 设置` 中配置，而不是在应用中。参见 [WordPress 后台设置](../wp-admin/index.mdx)。

## 遇到问题时 {#goes-wrong}

**另一台收银台的外观或运行方式不同。** 每台设备各自保存自己的设置。请在那台收银台上打开**设置**，进行相应配置。

**某个值与 WooCommerce 不一致。** 恢复操作会将您在此设备上修改的**常规**和**税费**设置替换为店铺的值，**千位分组样式**除外。打印机、扫描器和主题保持不变。请按**常规**底部的**恢复服务器设置**。参见[恢复服务器设置](./general.mdx#restore-server-settings)。

**此店铺尚未配置读卡器。** 读卡器需要先在 WooCommerce 的支付网关页面中配置，并且需要 WCPOS Pro。参见[支付网关](../../payment/gateways/index.mdx)。

**顾客显示屏是 Pro 功能。** 您的店铺正在运行免费版插件。参见 [WCPOS Pro](../../getting-started/pro-license.mdx)。如果提示**顾客显示屏需要更新版本的 WCPOS Pro**，请在 WordPress 中更新 Pro 插件。
