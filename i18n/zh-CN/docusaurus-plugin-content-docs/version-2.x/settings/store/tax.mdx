**POS 设置：** POS 中的 `Settings → Tax`。税率本身在 WooCommerce 中设置。

税费页面显示 POS 如何计算和展示税费。点击菜单底部的**设置**，再点击**税费**即可打开。

税率和四项[在 WooCommerce 中设置](#set-in-woocommerce)的值来自店铺：POS 每次加载店铺时都会复制这些值。**税费计算依据**和显示选项则属于收银台自身的设置，保存在此设备上，直到您在[常规](general.mdx#restore-server-settings)页面按**恢复服务器设置**。

## 税费页面 {#tax-page}

此页面分为三个部分：**计算**、**显示**和**税率**。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[-68,0],[176,0],[0,-28],[245,0],[176,0],[245,0],[-55,0],[-124,0],[-39,0],[-125,0],[140,0]]} alt="设置中的税费页面：税费计算依据设为店铺地址，四项在 WooCommerce 中设置的选项开关呈灰色，另有三个显示选项、价格显示后缀和查看所有税率按钮">

1. **税费计算依据** — 使用哪个地址确定税率。参见[税费计算依据](#calculate-tax-based-on)。
2. **启用税费** — WooCommerce 计算税费时，此项处于开启状态。关闭时，POS 不会为销售添加税费。开关呈灰色，因为该值[在 WooCommerce 中设置](#set-in-woocommerce)。
3. **打开** — 在浏览器中打开店铺的 WooCommerce 税费设置。每个灰色设置行都有各自的**在 WooCommerce 中设置**提示和**打开**链接。
4. **输入的价格含税** — 商品价格已包含税费时，此项处于开启状态。
5. **运费税类** — 运费行使用的税类，此处为**标准税率**。
6. **在小计级别对税费四舍五入** — 开启时，对整个订单的税费统一四舍五入，而不是逐行处理。
7. **显示税费总额** — **逐项显示**会在购物车和收据中将每项税费单独列为一行；**合并为一个总额**则将各项税费合并为一行。
8. **店铺中的价格显示** — 商品卡片和商品行显示的价格是否含税。
9. **购物车和结账时的价格显示** — 控制购物车、结账和收据中的价格是否含税。
10. **价格显示后缀** — WooCommerce 在网站价格后显示的文字。POS 不显示此文字。参见[税费显示方式](#display-settings)。
11. **查看所有税率** — 此设备上的全部税率，每个税类对应一个选项卡。参见[查看税率](#view-all-tax-rates)。

</JourneyShot>

## 税费计算依据 {#calculate-tax-based-on}

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[230,0],[230,0],[230,0]]} maxWidth={731} alt="展开的税费计算依据列表，其中包含顾客收货地址、顾客账单地址和已勾选的店铺地址">

1. **顾客收货地址** — 根据订单的收货地址确定税率。
2. **顾客账单地址** — 根据顾客的账单地址确定税率。
3. **店铺地址** — 根据店铺自身的地址确定税率，该地址显示在[常规](general.mdx#store-address)页面。

</JourneyShot>

此项初始值来自 WooCommerce 的**税费计算依据**。这里的更改会保存在当前设备上，重新加载或同步后也会保留，直到您在[常规](general.mdx#restore-server-settings)页面按**恢复服务器设置**。

订单没有相应地址时，POS 会按 WooCommerce 的方式使用备用地址。选择**顾客收货地址**时，先改用账单地址，再改用店铺地址。选择**顾客账单地址**时，则改用店铺地址。未指定顾客的到店销售会按店铺地址计算税费。

在购物车中添加或更换顾客后，如果其地址适用的税率不同，POS 会按这些税率重新计算购物车税费。[免税](../../pos/cart/index.mdx#tax-exempt)订单仍然不收税。参见[选择顾客](../../pos/cart/index.mdx#customer-selector)。

此选项会随每个 POS 订单一起传递，让店铺以相同方式计算该订单的税费。要查看购物车使用的地址和税率，请参见[本次销售适用的税率](#rates-for-this-address)。

## 税费显示方式 {#display-settings}

这四项只改变金额的显示方式，不会影响实际收取的税费。更改会立即显示，行名称旁会出现**已保存**。设置保存在当前设备上，重新加载或同步后也会保留，直到您在[常规](general.mdx#restore-server-settings)页面按**恢复服务器设置**。

| 设置行 | 选项 |
|---|---|
| **显示税费总额** | **逐项显示**：在购物车和收据中，每项税费单独列为一行，例如“州税”和“县税”。**合并为一个总额**：只显示一行税费。 |
| **店铺中的价格显示** | 商品卡片和商品行显示**含税**或**不含税**价格。 |
| **购物车和结账时的价格显示** | 购物车商品行、结账、收据和顾客显示屏显示**含税**或**不含税**价格。 |
| **价格显示后缀** | WooCommerce 在网站价格后显示的文字，例如“含增值税”。POS 会保留此值，但不会在商品卡片、购物车或结账时显示。 |

## 查看税率 {#view-all-tax-rates}

按**查看所有税率**，即可查看此设备已下载的全部税率，每个税类对应一个选项卡。这些税率来自 WooCommerce 的税费设置。像此处这样从 POS 打开时，适用于购物车地址的税率会带有标记：参见[本次销售适用的税率](#rates-for-this-address)。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[79,-28],[363,0],[113,0],[307,0],[700,0],[275,0],[-34,0]]} alt="从 POS 打开的税率面板：包含标准税率、优惠税率和零税率选项卡，四个标准税率中两个美国税率带有标记，底部显示 8 个税率，4 个适用于此地址（US）">

1. **标准税率 4** — 每个税类对应一个选项卡，并显示其中的税率数量。
2. **US，10%，优先级 1** — 带标记的行以底色突出显示，左侧有一条蓝色竖线：此税率适用于购物车当前使用的地址。该行还显示**复合税**，但它前面没有其他税率，因此仅按 10% 计算。
3. **US，AL，12345，123456，2%，优先级 2** — 此行也带有标记。它仅适用于阿拉巴马州的这些邮政编码，**复合税**表示在已加上 10% 税费的价格上继续计税：以 $100 为例，先收取 $10，再收取 $2.20，总税率为 12.2%。
4. **GB，附加税** — 没有标记的行不适用于此地址。
5. **优先级** — WooCommerce 按优先级顺序匹配税率。对于一个地址，每个税类中每个优先级只会有一个税率生效。
6. **8 个税率 · 4 个适用于此地址（US）** — 显示所有税类的税率总数，以及与购物车地址匹配的税率数量。旁边的同步按钮可从店铺获取更新。
7. **关闭** — 返回之前的页面。

</JourneyShot>

- **在手机上** — 从列表中选择税类，而不是使用选项卡。
- **了解各列** — 这些列与 WooCommerce 中相同。**任意**表示所有值均适用；名称下方的**不适用于运费**表示此税率不对运费征税。
- **刷新税率** — 部分税率尚在下载时，底部会显示**已同步 … / … 个税率**。要重新下载所有税率，请长按同步按钮，然后选择**清除并刷新**。

### 本次销售适用的税率 {#rates-for-this-address}

按商品下方的计税地址按钮，例如**店铺所在地**，即可查看购物车使用的地址及匹配的税率。

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[132,0],[159,0],[107,0],[149,0],[130,0]]} maxWidth={440} alt="店铺所在地按钮上方的计税地址面板：计算依据为店铺地址，店铺地址为 AL 12345，美国（US），下方显示匹配的标准税率、优惠税率和零税率，以及查看所有税率">

1. **计算依据** — 此购物车使用的地址选项，此处为**店铺地址**。
2. **在设置 › 税费中更改** — 打开此页面。
3. **店铺地址** — 用于匹配税率的地址。如果订单中有顾客地址，此处会显示**订单上的地址**。
4. **匹配的税率** — 显示各税类及其总税率，下方列出每个适用税率及适用原因，例如“US 全境”或“邮政编码 12345”。
5. **查看所有税率** — 打开[完整列表](#view-all-tax-rates)，其中这些税率会带有标记，底部显示适用的税率数量，例如“4 个适用于此地址（US）”。

</JourneyShot>

## 恢复服务器设置 {#restore-server-settings}

**恢复服务器设置**位于[常规](general.mdx#restore-server-settings)页面底部，不在此页面。它会重新加载店铺设置（包括税费设置），并还原您在此设备上修改的值。

<JourneyShot manifest={manifest} device="tablet" step={4} offsets={[[-32,0],[0,0]]} alt="设置中常规页面的底部：恢复服务器设置按钮，下方显示无法连接到店铺以及重试按钮">

1. **恢复服务器设置** — 位于**常规**底部，在**从您的 WooCommerce 店铺复制；恢复将覆盖本地更改。** 下方。
2. **重试** — 恢复操作需要网络连接。离线时，页面会显示**无法连接到店铺**，设置保持原样。恢复联网后，请按**重试**。

</JourneyShot>

:::warning

恢复操作会还原您在此设备上修改的所有店铺设置，包括常规和税费设置。

:::

1. 按**恢复服务器设置**。
2. 在**恢复服务器设置？** 对话框中，再次按**恢复服务器设置**以确认，或按**取消**。

<JourneyShot manifest={manifest} device="tablet" step={7} offsets={[[192,0],[0,-22],[0,-22]]} maxWidth={468} alt="恢复服务器设置？确认对话框，包含取消和恢复服务器设置按钮">

1. **恢复服务器设置？** — 店铺的值将替换您在此设备上修改的值。
2. **恢复服务器设置** — 执行恢复。
3. **取消** — 保持当前设置不变。

</JourneyShot>

3. 完成后，按钮下方会显示**已恢复**。

## 在 WooCommerce 中设置 {#set-in-woocommerce}

有四项设置无法在 POS 中更改。店铺保存订单时会按这些设置进行计算，因此收银台使用不同的值只会导致总额不一致。请在 WooCommerce 中更改：按相应行的**打开**，或前往 `WP Admin > WooCommerce > 设置 > Tax`。POS 下次加载店铺时会获取新值。

<details>
<summary>启用税费、输入的价格含税、运费税类和在小计级别对税费四舍五入</summary>

### 启用税费 {#enable-taxes}

对应 WooCommerce 的**启用税率和计算**，位于 `WP Admin > WooCommerce > 设置 > General`。关闭时，所有销售均不收税，POS 也会隐藏商品下方的计税地址按钮。

### 输入的价格含税 {#prices-entered-with-tax}

开启时：您设置的价格已包含税费，POS 会从中计算出税额。关闭时：税费会另加在价格之上。

### 运费税类 {#shipping-tax-class}

**基于购物车商品**使用购物车中商品的税类。选择指定税类（例如**标准**或**优惠税率**）时，运费将按该税类的税率计税。

### 在小计级别对税费四舍五入 {#rounding}

开启时：先汇总整个订单的税费，再统一四舍五入。关闭时：每行税费单独四舍五入。金额较大的订单中，两种方式可能相差一两分。

</details>

## POS 如何计算税费 {#tax-maths}

POS 使用店铺的税率，并按 WooCommerce 的方式计算税费。

<details>
<summary>四舍五入与复合税</summary>

- **四舍五入** — 计算每项税费时会保留更多小数位，再按所用货币的小数位数四舍五入。关闭**在小计级别对税费四舍五入**时，会逐行处理；开启时，则对订单税费总额统一处理。
- **复合税** — 标为**复合税**的税率会按[优先级](#view-all-tax-rates)顺序，在已加上前面税费的金额基础上计算。

</details>

使用 [WooCommerce Tax](../../integrations/woocommerce-tax.mdx#what-to-expect) 自动计税时，新地点的首笔销售可能会出现一次税额差异，直到该地点的税率同步到 POS。

## 遇到问题时 {#troubleshooting}

**POS 和 WooCommerce 显示的总额不同。** 请检查**在 WooCommerce 中设置**下的四项值是否与店铺一致，然后在[常规](general.mdx#restore-server-settings)页面按**恢复服务器设置**。使用 WooCommerce Tax 时，新地点的首笔销售可能会出现一次差异：参见 [WooCommerce Tax](../../integrations/woocommerce-tax.mdx#what-to-expect)。有关购物车显示的提示，请参见[总额不一致](../../support/troubleshooting/totals-disagree.mdx)。

**销售没有收税。** 请按以下顺序检查：

1. **启用税费**已开启。
2. 商品在 WooCommerce 中的**税费状态**为**应税**。
3. 商品所属税类中有税率：按**查看所有税率**，然后打开该税类的选项卡。
4. 正在使用 [WooCommerce Tax](../../integrations/woocommerce-tax.mdx) 自动计税？某个地点首次销售前，税类为空是正常现象。无需继续以下步骤。
5. 否则，请在 WooCommerce 的税费设置中添加税率。然后长按税率列表中的同步按钮，选择**清除并刷新**。

**税率错误。** 按商品下方的计税地址按钮，例如**店铺所在地**，查看购物车正在使用哪个地址。更换顾客会按该顾客的地址重新计算购物车税费。如果顾客没有登记地址，则按店铺地址计税。启用 [WooCommerce Tax](../../integrations/woocommerce-tax.mdx) 自动计税时，请勿手动添加税率：某个地点的税率会在该地点首次销售后出现。

**显示价格低于标价。** **输入的价格含税**已开启，但某个显示选项设为**不含税**。POS 显示的是扣除税费后的价格，实际收取的总额不变。

**相差一两分。** 收银台与店铺的四舍五入方式不同。请检查 WooCommerce 中的**在小计级别对税费四舍五入**，然后在[常规](general.mdx#restore-server-settings)页面按**恢复服务器设置**，让 POS 使用相同的值。
