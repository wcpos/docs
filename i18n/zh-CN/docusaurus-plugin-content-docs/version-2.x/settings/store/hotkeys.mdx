收银台配有键盘时，无需使用鼠标就能完成销售。按住 **Alt**（Mac 上为 **Option ⌥**）再按相应按键。按 **Alt + /** 可查看所有快捷键。

:::note 快捷键的适用范围
快捷键可用于浏览器和桌面应用中的 POS 界面，即使光标位于文本输入框内也有效。{/* pending: monorepo#3357 */} 在 Mac 上，某些快捷键会在输入框中输入重音符号，例如 **Option + N**，使用前需要先[点击输入框外部](#goes-wrong)。手机和平板应用不支持这些快捷键。其他界面也不支持，但订单列表有自己的[方向键操作](#orders)。
:::

## 快捷键一览 {#shortcuts}

在结账或已付款界面，除 **Alt + /** 外，所有快捷键都会暂停响应。当购物车被收银机选择器、**开启收银机**卡片、盘点界面或未结订单列表遮挡时，除 **Alt + F** 和 **Alt + /** 外，其他快捷键也会暂停响应。

| 按键 | 执行的操作 |
|---|---|
| **Alt + F** | 将光标移至**搜索商品**。在较窄的屏幕上，会先打开商品选项卡。 |
| **Alt + P** | 打开**结账**。<br />_还需要购物车中有商品。_ |
| **Alt + N** | 新建一个空购物车。之前操作的订单保持未结状态。<br />_还需要购物车中已有订单，不能是空购物车。_ |
| **Alt + ←** 或 **Alt + →** | 切换到上一个或下一个未结订单。<br />_还需要至少有两个未结订单。_ |
| **Alt + D** | 打开**添加折扣**。<br />_还需要购物车中已有订单。_ |
| **Alt + V** | 立即作废购物车中的订单。如果是误操作，请立即按**撤销**。<br />_还需要购物车中已有订单。_ |
| **Alt + /** | 打开或关闭快捷键列表。<br />_在 POS 界面随时可用，包括结账时。_ |

:::warning Alt + V 不会先要求确认
按下此快捷键就会立即作废订单。随后出现的提示中有**撤销**按钮：如果是误操作，请立即按下。
:::

快捷键是固定的，无法在设置中更改。如果希望使用其他按键，请在 [Discord](https://wcpos.com/discord) 上告诉我们。

## 查看所有快捷键 {#list}

按 **Alt + /**。列表会从右侧滑入。

灰色行表示当前无法执行该操作。购物车为空时，**结账**、**新建购物车**、**添加折扣**和**作废订单**会显示为灰色；至少有两个未结订单时，**上一个购物车**和**下一个购物车**才会变为可用。按其他行即可执行相应操作，效果与快捷键相同。在 Windows 上，底部会显示有关 [Firefox](#goes-wrong) 的提示。按**关闭**或再次按 **Alt + /** 即可收起列表。

列表会覆盖购物车，并使旁边的商品区域变暗。

1. **搜索商品** — 将光标移至商品搜索框，准备输入或扫描。参见[搜索与筛选](../../pos/product-panel/search-filtering.mdx)。
2. **结账** — 打开购物车中订单的收款面板。参见[结账](../../pos/checkout/index.mdx)。
3. **新建购物车** — 新建一个空购物车。之前操作的订单保留在[未结订单](../../pos/cart/open-orders.mdx)中。
4. **上一个购物车** — 切换到当前订单之前的未结订单。
5. **下一个购物车** — 切换到下一个未结订单。
6. **添加折扣** — 为订单打开**添加折扣**窗口。参见[折扣](../../pos/cart/discounts.mdx)。
7. **作废订单** — 立即作废购物车中的订单，不会先要求确认。如果是误操作，请立即按**撤销**。参见[作废](../../pos/cart/order-actions.mdx#void)。
8. **键盘快捷键** — 打开此列表。

## 在订单列表中移动 {#orders}

在浏览器或桌面应用的**订单**界面，点击一个订单（或按 **Tab** 进入列表），然后：

- **↓** / **↑** 将高亮选中项移至下一个或上一个订单。
- **Enter** 打开高亮选中的订单。

:::info Pro 功能
订单界面由 WCPOS Pro 提供。参见[订单](../../orders/index.mdx)。
:::

## 遇到问题时 {#goes-wrong}

**按下后没有反应。** 按 **Alt + /** 打开列表：如果快捷键所在行是灰色，说明当前无法执行，原因见[表格](#shortcuts)。请确认当前处于 POS 界面、收银机已开启，且未结订单列表没有遮挡购物车。

**Alt + F 或 Alt + D 打开了 Firefox 菜单。** 在 Windows 上，Firefox 可能会占用这两个快捷键。请改为按快捷键列表中的相应行，或使用 Chrome、Edge 或桌面应用。

**在 Mac 上，Option + N 在搜索框中输入了重音符号。** 某些键盘布局使用 Option 加字母来输入重音符号，在输入框内打字时，POS 会保留这一输入行为。请点击输入框外部，然后再次按快捷键。
