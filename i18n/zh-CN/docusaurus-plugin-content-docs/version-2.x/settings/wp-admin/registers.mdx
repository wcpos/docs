**WP admin：** `WP Admin → POS → Settings → General → Register`。

您可以在此启用收银机，设置开班备用金、何时需要经理审批盘点结果，以及何时提醒收银员结班。下文还会介绍各项设置对收银员界面的影响。

要了解什么是收银机，以及它与店铺和设备的区别，请参阅[店铺、收银机和设备](../../stores/registers-and-devices.mdx)。

## 启用收银机 {#one-register}

使用 Pro 且至少创建了一个店铺后，这些设置会成为站点默认值，各收银机的备用金改为在所属店铺中设置；请参阅[店铺的收银机页面](#store-registers)。

1. 在**常规**设置页面上，向下滚动到**收银机**。
2. 开启**收银机开班与结班**。下方会显示相关规则。关闭时，POS 会直接进入购物车，收银员无需为收银机开班或盘点。
3. 检查**开班备用金**。首次启用收银机时，其值为 **200.00**。请将其改为钱箱每日开始营业时的金额。如果已使用 Pro 创建店铺，此处不会显示该字段：请在[所属店铺的收银机页面](#store-registers)设置各收银机的备用金。
4. 可选：开启**盘点差额超过以下金额时请经理审批**，并设置金额。
5. 可选：开启**提醒收银员结班的时间**，并设置时间。

每项更改会在修改后或离开字段时立即保存。字段留空时会恢复为上次的值。

<Accordion>
<AccordionItem question="开班备用金、经理审批和结班提醒">

每项设置都以一句话呈现，设置值嵌在句子中。

- **收银机开班与结班**用于启用收银班次。收银员带着备用金开班，记录现金进出，并在结班时盘点钱箱。关闭后，POS 会直接进入购物车，无需开班或盘点。
- **开班备用金**是钱箱开始营业时的现金金额。收银员开班时，此值会自动填入**钱箱现金**，收银员可以改为实际金额。该字段仅在启用收银机时显示。
- **盘点差额超过以下金额时请经理审批 …** 默认关闭；开启时初始值为 **5.00**。结班盘点的短款或溢款超过此金额时，必须经经理审批才能结班。关闭时，无论差额多少都无需审批即可结班。
- **提醒收银员结班的时间 …** 默认关闭；开启时初始值为 **17:30**。超过该时间后，收银机会显示**已超时**，空购物车中的**结账**按钮会变为**结班**。请参阅[到达结班时间时](#overdue)。

开启可选规则时会填入初始值；关闭时会清空，再次开启时仍会使用初始值。

</AccordionItem>
</Accordion>

设置下方有一个链接，文字为**使用 Pro 获取更多收银机和店铺**。

免费插件仅提供一台收银机。

<Accordion>
<AccordionItem question="在多台设备上使用同一台收银机">

每台登录的设备都会使用这唯一的一台收银机：同一柜台的浏览器、桌面应用和手机的销售款项都归入同一个钱箱，并共用一个收银班次，因此只需盘点和结班一次。没有可为其命名的设置，收银机栏中仅显示店铺。

</AccordionItem>
</Accordion>

## 收银员看到的界面 {#what-the-cashier-sees}

收银机已结班时，收银员盘点钱箱后，可从购物车栏开班。

<JourneyShot manifest={registerManifest} device="tablet" step={1} offsets={[[81, 0], [-34, 0], [0, 0], [255, 0], [157, 0], [0, 0]]} alt="收银机已结班时的 POS：收银机栏显示已结班状态，产品上方显示查价提示条，购物车栏中显示现金字段、上次盘点金额和开班按钮">

1. **收银机状态** — 此处为**已结班**。也可能显示**已超时**（请参阅[到达结班时间时](#overdue)）或**需要审批**（请参阅[盘点有差额时](#count-out)）。
2. **收银机栏** — 此设备所服务的店铺。使用 Pro 且店铺有多台收银机时，还会显示收银机名称。
3. **查价提示条** — 收银机已结班时，收银员可以搜索和查看价格，但无法将商品加入购物车。
4. **钱箱现金** — 初始值为您设置的**开班备用金**；如果未设置，则使用上次盘点金额。收银员在此输入实际盘点的金额。
5. **上次盘点** — 显示上次结班盘点金额的标签，点击即可使用。进行盲盘（看不到预期现金金额）的收银员也看不到此标签；可在[访问权限](./access.mdx)中设置。
6. **开班** — 开始收银班次。输入金额与备用金不同的部分会显示为**开班差额**。

</JourneyShot>

[收银机开班](../../pos/register/index.mdx)介绍了从备用金到结班的整个班次流程。

### 到达结班时间时 {#overdue}

**提醒收银员结班的时间**不会自动结班，也不会停止销售。按店铺时间超过设定时间后，POS 会提醒正在收银的人员：

- 收银机栏显示**已超时**。
- 购物车为空时，**结账**按钮会变为**结班**。购物车有商品时，仍可照常结账。
- 收银机面板中的按钮显示为**结班 · 已过 17:30**，其中的时间为您设置的时间。

在设定时间之后开班的收银机，其结班时间为次日的同一时间。跨夜未结班的收银机会一直显示**已超时**，直到有人结班。

{/* reshoot: Overdue bar and Close register in an empty cart, see reshoot.md */}

### 盘点有差额时 {#count-out}

结班时，收银员输入实际盘点金额（包含备用金），差额会随输入实时显示。下方的**备注**字段用于解释差额。

<JourneyShot manifest={registerManifest} device="tablet" step={7} offsets={[[150, 0], [-90, 0], [-12, -24]]} alt="收银机结班：实盘现金字段、标记为相符的预期金额，以及结班并打印按钮">

1. **实盘现金（含备用金）** — 收银员盘点的金额。
2. **预期金额**和差额 — 此处为**相符**。盘点有差额时，会显示**短款**或**溢款**的金额；超出您设定的阈值时，还会显示*超过 … 的阈值 · 需要经理审批*。
3. **结班并打印** — 为收银机结班。当差额超过**盘点差额超过以下金额时请经理审批**中设定的阈值时，按钮会变为**审批并结班**，经理需登录进行审批。审批需要网络连接。

</JourneyShot>

谁可以审批、谁需要盲盘，都在[访问权限](./access.mdx)中设置。结班和审批记录保存在[对账](../../reports/reconciliation.mdx)中。

:::note 与会话页面不同
[会话](./sessions.mdx)列出谁在什么设备上登录了 POS。*收银班次*则是另一个概念：从带着备用金开班，到盘点后结班之间的这段时间。
:::

## 使用 Pro 添加更多收银机 {#more-registers-with-pro}

第二个钱箱需要第二台收银机，这是 [WCPOS Pro](../../getting-started/free-vs-pro.mdx) 的功能。使用 Pro 时，收银机归属于店铺。激活 Pro 后，常规设置中的**收银机**部分会发生变化：

<Accordion>
<AccordionItem question="创建第一个店铺之前">

- 与免费插件一样，**收银机开班与结班**及两项规则适用于站点唯一的一台收银机。
- **开班备用金**仍在此处设置，适用于这唯一的一台收银机。
- 设置下方会显示*要使用多台收银机，请创建店铺并在其页面上添加收银机。*以及**添加店铺**链接。

</AccordionItem>
<AccordionItem question="创建店铺之后">

- **收银机开班与结班**及两项规则会成为**站点默认值**。此部分会显示*站点默认值。各店铺可在自己的页面上自定义这些设置。*
- 此部分不再显示**开班备用金**。各收银机的备用金在其所属店铺的**收银机**页面上设置。
- 设置下方的**管理店铺**可打开店铺列表。

</AccordionItem>
</Accordion>

创建店铺时：

- 您创建的第一个店铺会原样接管现有收银机，不会为它新建收银机。
- 此后创建的每个店铺都会获得自己的一台收银机。
- 如果一个已发布的店铺没有收银机，下次 POS 或店铺页面列出其收银机时，会自动添加一台名为**收银机**的收银机。
- 一台收银机同一时间只能归属于一个店铺。

### 店铺的收银机页面 {#store-registers}

打开 **POS → 店铺**，点击店铺，然后在店铺菜单的**销售**下选择**收银机**。**收银台**表格列出店铺的收银机；点击 **+ 添加收银机**可新增一台，默认依次命名为**收银机 2**、**收银机 3** 等，您可以重命名。新店铺需要先点击**创建**；在此之前，表格会显示**请先保存店铺，再添加收银机。**

<Accordion>
  <AccordionItem question="收银台表格：列、状态和 ⋯ 菜单">

| 列 | 显示内容 |
| --- | --- |
| **收银机** | POS 中显示的收银机名称。 |
| **开班备用金** | 收银员在此收银台开始工作时的现金金额。更改从下次开班起生效。 |
| **状态** | **开班于**某个时间 **·** 开班人员，带有绿点。**盘点中** **·** 开班人员，带有琥珀色圆点。**已结班 · 上次结班 #**后显示编号和日期，带有灰点；首次结班之前只显示**已结班**。 |
| **⋯** | **重命名**、**移至**其他店铺，或**停用**。有正在进行或盘点中的班次时，收银机无法停用：提示为**请先结束其班次**。 |

店铺菜单中**收银机**旁的徽标显示已开班的收银台数量；没有收银台开班时，则显示全部收银台的数量。

  </AccordionItem>
  <AccordionItem question="单个店铺的钱箱规则">

表格下方的**钱箱规则**在店铺沿用常规页面规则时保持折叠，并显示**站点默认值**。点击**自定义**可查看相同的三项设置：**每天为收银机开班与结班**、**盘点差额超过以下金额时请经理审批**和**提醒收银员结班的时间**。在此处修改之前，每项均显示**站点默认值**。**使用站点默认值**可恢复一项规则；**重置为站点默认值**可恢复全部三项。

下方的**报表和结班**用于设置此店铺在收银台结班时（**结班打印件**）以及生成销售报表时（**销售报表**）打印的内容。

  </AccordionItem>
</Accordion>

完整操作流程（包括店铺的收据和员工）请参阅[设置店铺](../../stores/setup.mdx#registers)。

### 停用 Pro 后 {#if-pro-is-deactivated}

免费插件会恢复为仅使用一台收银机。其他收银机上尚未结束的班次仍可盘点和结班，但在重新启用 Pro 之前，这些收银机无法再次开班。

## 故障排查 {#goes-wrong}

**无法保存收银机。** 开班备用金未保存成功。请检查连接并重新输入。

**开班备用金字段呈灰色。** 该字段正在加载或保存。请稍候；如果一直呈灰色，请重新加载页面。

**收银员始终看不到已超时。** 请检查是否已开启**提醒收银员结班的时间**。使用 Pro 时，还需检查店铺自己的**钱箱规则**：自定义了规则的店铺不会沿用常规页面的设置。在设定时间之后开班的收银机，其结班时间为次日。

**请先保存店铺，再添加收银机。** 新店铺创建之前没有**收银台**表格。请点击**创建**，然后添加收银机。

**请先结束其班次。** 您尝试停用的收银机仍在营业或正在盘点。请先在 POS 中盘点并结班，再将其停用。
