**WP admin：** `WP Admin → POS → Settings`，所有收银机共用这些设置。

您需要具备**管理 POS 设置**权限才能看到这些设置：管理员和店铺管理员拥有此权限，收银员没有（[访问权限](./access.mdx)）。

如需设置某一台收银机的打印机、条码扫描器、主题或显示，请打开 [POS 内的设置](../index.mdx#open)。这些设置仅适用于该设备。

## 查找设置 {#settings-at-a-glance}

常见操作：

- 更改店铺名称、电话或退货政策：[店铺详情](#store-details)。
- 选择收银机提供的付款方式：[选择付款方式](./checkout.mdx#payment-gateways)。
- 决定收银员可以执行哪些操作：[访问权限](./access.mdx)。
- 将丢失或共用的设备退出登录：[会话](./sessions.mdx)。
- 设置开班备用金：[收银机](./registers.mdx#one-register)。
- 选择条码扫描器读取的产品字段：[条码字段](./general.mdx#barcode-field)。
- 选择每笔销售开始时使用的客户：[默认 POS 客户](./general.mdx#default-pos-customer)。
- 将所有收银机结班记录下载为电子表格：[导出结班记录](../../reports/reconciliation.mdx#export)。
- 查看 WCPOS 记录的错误和警告：[日志](../../support/logs.mdx#wp-admin-logs)。
- 激活您的 WCPOS Pro 许可证密钥：[安装 WCPOS Pro](../../getting-started/pro-license.mdx#activate)。

**POS > 设置**左侧的菜单分为三组：**设置**、**工具**和**账户**。在常规和收银台页面中，每项更改都会立即保存；只有付款方式的 POS 设置才有**保存**按钮。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [75, 0], [95, 0]]} alt="安装 WCPOS Pro 后的 WP Admin、POS、设置、常规页面：左侧 WCPOS 菜单包含设置、工具和账户分组，已选中常规，旁边显示店铺、收银机和产品部分">

1. **设置** — 常规、收银台、云打印、访问权限、会话和扩展。
2. **工具** — 导出结班记录和日志。
3. **账户** — 许可证。

</JourneyShot>

<details>
<summary>设置菜单中的所有项目</summary>

**设置**

- **常规**：店铺详情、收银机、产品、客户、隐私和**强制 SSL**。请参阅[常规设置](./general.mdx)，或展开下方的**常规页面包含哪些内容**。
- **收银台**：超卖、POS 邮件，以及付款方式（**网关**）和各付款方式对应的订单状态。请参阅[收银台设置](./checkout.mdx)，或展开下方的**收银台页面包含哪些内容**。
- **云打印**：通过互联网获取收据的打印机、自动打印订单的规则以及打印队列。请参阅[云打印](../../receipts/cloud-printing.mdx)。
- **访问权限**：各 WordPress 角色（包括收银员）可在 POS 中执行的操作。请参阅[访问权限](./access.mdx)。
- **会话**：查看谁在什么设备上登录了 POS，以及将设备退出登录。请参阅[会话](./sessions.mdx)。
- **扩展**：浏览、安装、更新和停用 WCPOS 扩展。名称旁的数字表示待更新的数量。请参阅[扩展](../../extensions/index.mdx)。

**工具**

- **导出结班记录**：通过**下载 CSV** 获取此店铺记录的所有收银机结班记录，每行一条，包含结班时的数据。请参阅[对账](../../reports/reconciliation.mdx)。
- **日志**：店铺自身的 WCPOS 日志，包含错误和警告。名称旁的两个数字分别表示未读错误和未读警告的数量。请参阅[日志](../../support/logs.mdx#wp-admin-logs)。

**账户**

- **许可证**：安装 WCPOS Pro 后，可输入并**激活**您的**许可证密钥**，或将其**停用**。未安装 Pro 时，此页面会提供升级选项。请参阅[安装 WCPOS Pro](../../getting-started/pro-license.mdx#activate)。

扩展可以在**工具**或**账户**下添加自己的页面。

</details>

<details>
<summary>常规页面包含哪些内容：店铺详情、收银机、产品、客户、隐私、强制 SSL</summary>

- **店铺详情**：名称、电话、电子邮件、退货政策和**店铺税号**。请参阅[店铺详情](#store-details)。
- **收银机**：开班与结班、开班备用金和结班规则。免费插件提供一台收银机；更多收银机需要 Pro。请参阅[收银机](./registers.mdx)。
- **产品**：仅限 POS 的产品、小数数量、删除订单时恢复库存，以及**条码字段**。请参阅[常规设置](./general.mdx)。
- **客户**：生成的用户名、**默认 POS 客户**、**允许客户下载收据**以及客户**税号**（[客户税号](./customer-tax-ids.mdx)）。请参阅[常规设置](./general.mdx#default-pos-customer)。
- **隐私**：匿名使用数据和错误报告。在管理员作出选择之前，会显示**允许**和**不用了，谢谢**按钮。请参阅[常规设置](./general.mdx#privacy)。
- **高级**：**强制 SSL**。请参阅[强制 SSL](#force-ssl)。

</details>

<details>
<summary>收银台页面包含哪些内容：超卖、邮件、付款方式</summary>

- **防止超卖**。请参阅[收银台设置](./checkout.mdx#prevent-overselling)。
- **管理员邮件**、**客户邮件**和**收银员邮件**开关。请参阅[邮件通知](./email-notifications.mdx)。
- 付款**网关**表格。请参阅[收银台设置](./checkout.mdx#payment-gateways)。您可以在其中：
  - 选择收银机提供的付款方式及其排列顺序（免费插件只能启用或更改**现金**和**银行卡**；其他付款方式需要 Pro）；
  - 选择使用各付款方式支付后 POS 订单的**订单状态**；
  - 打开某种付款方式的 POS 设置，更改收银机显示的名称和说明；对于现金，还可以设置**金额舍入**：**不舍入**，或选择从 **0.05** 到 **10** 的舍入单位。请参阅[现金舍入](../../payment/index.mdx#cash-rounding)。

</details>

<details>
<summary>邮件通知、收银机和税号</summary>

**邮件通知**指的是**收银台**页面上的三个邮件开关。**收银机**位于**常规**页面的**收银机**部分。**店铺税号**位于**店铺详情**中，**客户税号**位于**客户**部分，两者都在**常规**页面上。

</details>

## 店铺详情 {#store-details}

打开 **`WP Admin > POS > 设置 > General`**，更改顶部的字段。每项更改都会立即保存。这些详情用于 POS 收据和发票：

| 字段 | 内容 |
|---|---|
| **店铺名称** | 您的店铺名称。 |
| **电话** | 店铺的电话号码。 |
| **电子邮件** | 店铺的电子邮件地址。 |
| **退款和退货政策** | 打印在 POS 收据上的简短声明。 |
| **店铺税号** | 店铺的税号。请参阅[店铺税号](./store-tax-ids.mdx)。 |

将字段留空可沿用 WooCommerce 中已有的值，该值会以灰色显示在空字段中。如果 WooCommerce 中也没有值，**店铺名称**将使用站点标题，**电子邮件**将使用 WooCommerce 邮件的发件人地址。

<JourneyShot manifest={manifest} device="desktop" step={3} offsets={[[100, 0], [100, 0], [100, 0], [0, 34], [100, -6]]} maxWidth={560} alt="免费插件常规页面中的店铺详情：解锁按店铺设置的提示框、店铺名称、电话、电子邮件和退款和退货政策，下方是包含一行记录的店铺税号及添加税号按钮">

1. **店铺名称** — 此处为空，因此使用灰色显示的站点标题。
2. **电话** — 默认无内容。
3. **电子邮件** — 此处为空，因此使用灰色显示的地址。
4. **退款和退货政策** — 打印在 POS 收据上。
5. **店铺税号** — 店铺的税号。请参阅[店铺税号](./store-tax-ids.mdx)。

</JourneyShot>

:::info 使用 WCPOS Pro 时
在创建店铺之前，**店铺详情**会显示相同的字段，以及一个**管理店铺**按钮。创建店铺后，此部分将变为**店铺**，列出所有店铺，每个店铺旁都有一个**编辑**按钮，各店铺的详情在其自己的页面上设置。请参阅[设置店铺](../../stores/setup.mdx#store-pages)。
:::

## 强制 SSL {#force-ssl}

请保持**强制 SSL** 开启。此设置位于**常规**页面底部的**高级**部分，默认开启，可确保 POS 与您的站点之间的每次连接都安全（HTTPS）。

<JourneyShot manifest={manifest} device="desktop" step={2} offsets={[[102, 0]]} maxWidth={560} alt="常规页面底部的高级部分，强制 SSL 已开启">

1. **强制 SSL** — 默认开启。请保持开启。

</JourneyShot>

<details>
<summary>强制 SSL 的作用及何时应关闭</summary>

开启**强制 SSL** 后，通过 `http://` 地址打开 POS 会跳转到 `https://` 地址。即使站点自身的地址以 `http://` 开头（例如站点位于处理 SSL 的代理后方），POS 的登录、结账和收据链接也会使用 HTTPS。

只有在站点没有 SSL 证书时才应关闭此设置，例如您自己电脑上的测试站点。关闭后，POS 将使用站点自身的地址。

</details>

## 使用 WCPOS Pro 时 {#pro}

Pro 会在 WP Admin 菜单中添加 **POS > 店铺**。每个店铺都有自己的详情、收据模板、收银机、员工和**客户显示屏**页面。请参阅[设置店铺](../../stores/setup.mdx)。

<details>
<summary>为店铺选择客户显示屏模板</summary>

在店铺的**客户显示屏**页面上，**显示模板**列表的第一项为**与站点相同**，后面的括号中显示站点的显示模板名称（如果站点没有启用任何模板，则显示**店铺默认**）。保留此选项，店铺就会跟随站点使用的模板。选择其他模板即可为此店铺单独指定模板。模板在 **POS > 模板**的**显示**选项卡中启用后，就会出现在列表中。

</details>

## 故障排查 {#goes-wrong}

**WP Admin 中没有 POS 菜单。** WordPress 仅向拥有**管理 POS 设置**权限的用户显示整个 **POS** 菜单（包括**设置**），而您的账户没有此权限。请让管理员为您的角色授予该权限，或参阅[访问权限](./access.mdx)。

**常规页面中原来的店铺详情变成了店铺。** 您已安装 WCPOS Pro，并且至少创建了一个店铺。点击店铺旁的**编辑**即可更改其详情。

<details>
<summary>无法下载收据字体</summary>

警告的开头为：“WCPOS 无法从 cdn.jsdelivr.net 下载收据字体。”所有管理 WooCommerce 的用户都会在 WP Admin 中看到此警告。下载成功之前，收据会使用仅支持拉丁字母的基本字体，因此其他文字可能无法正确打印。WCPOS 每小时会重试一次。如果您的主机服务商拦截了对外请求，请让他们放行 `cdn.jsdelivr.net`。

</details>

<details>
<summary>无法设置收据字体</summary>

警告的开头为：“WCPOS 无法发布收据字体映射。”这表示 WCPOS 无法保存用于指明收据字体位置的文件。在成功保存之前，收据会使用基本的拉丁字体，WCPOS 每小时会重试一次。请让主机服务商检查 WordPress 上传文件夹是否可写。

</details>

**常规页面顶部显示“您的店铺位于 Cloudflare 后方”。** WCPOS 检测到您的站点通过 Cloudflare 提供服务，其安全检查可能阻止 POS 访问店铺。如果 POS 显示 **HOST121** 或安全检查窗口，请参阅 [Cloudflare](../../support/troubleshooting/cloudflare.mdx)。

<details>
<summary>收银台页面警告结账速度变慢</summary>

收银台页面顶部的警告开头为：“随着产品目录和订单历史增长，WCPOS 的结账速度会变慢”。您的店铺仍使用 WooCommerce 的旧版订单存储方式。请切换到高性能订单存储：警告中提供了 WooCommerce 设置的链接，切换前警告会一直显示。请参阅[订单存储](../../support/performance/order-storage.mdx#switch-to-hpos)。

</details>

<details>
<summary>WP Admin 中的“帮助我们改进 WCPOS”</summary>

WCPOS 正在询问是否可以发送匿名使用数据和错误报告。请点击**允许**或**不用了，谢谢**。您可以随时在**常规 > 隐私**中更改选择。

在拥有**管理 POS 设置**权限的用户作出选择之前，此提示框会显示在仪表盘和插件页面上。安装或更新 WCPOS 后的 7 天内，大多数 WooCommerce 页面也会显示它。关闭提示后，它会对您隐藏 7 天。

</details>
