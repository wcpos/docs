**WP 后台：** `WP Admin → POS → Settings → General`，适用于所有收银机。

常规是 WordPress 中 POS 设置的第一个页面：**`WP Admin > POS > 设置 > General`**。其中的设置适用于整个店铺，供每位收银员的 POS 使用。每次更改都会立即保存，并显示 **已保存** 消息以确认。此页面没有保存按钮。

:::note 谁可以更改这些设置
拥有 **管理 POS 设置** 权限的用户（默认为管理员或店铺管理员）可以打开此页面，收银员则不能。请参阅[访问 POS](./access.mdx)。
:::

## 店铺详情 {#store-details}

POS 收据和发票上显示的店铺信息：**店铺名称**、**电话**、**电子邮箱**，以及打印在 POS 收据上的简短声明 **退款与退货政策**。

将字段留空即可使用其中以灰色显示的默认值。如果已在 WooCommerce 自带的销售点设置中填写该字段（WooCommerce 10.5 及更高版本），则以该值为默认值。否则：

| 字段 | 留空时的默认值 |
|---|---|
| **店铺名称** | 您的 WordPress 站点标题 |
| **电话** | 无 |
| **电子邮箱** | WooCommerce 邮件的“发件人”地址，其次为 WordPress 管理员邮箱 |
| **退款与退货政策** | 无 |

<Anchor id="store-tax-ids" />

这些字段下方是 **店铺税号**：打印在收据和发票上的 VAT 号码、ABN、GSTIN 或其他企业号码。请参阅[店铺税号](./store-tax-ids.mdx)。

:::info 使用 WCPOS Pro 时
创建店铺后，此区域会变为 **店铺** 列表，每个店铺都有独立的详情、收据模板、价格、税率和用户。请参阅[设置店铺](../../stores/setup.mdx)。
:::

## 收银机 {#register}

**开启和关闭收银机** 用于启用收银班次：收银员以备用金开班，记录现金收入和支出，并在结班时清点钱箱。关闭后，POS 无需开启班次即可销售。

开启后会显示另外三项：**开班备用金**、**盘点差额超过 … 时请经理审批** 和 **在 … 提醒收银员结班**。[收银机设置](./registers.mdx#one-register)中逐一介绍了这些选项。免费版插件提供一台收银机；**使用 Pro 获得更多收银机和店铺** 链接可前往升级。

## 产品 {#products}

<JourneyShot manifest={manifest} device="desktop" step={3} offsets={[[204, 0], [204, 0], [228, 0], [60, 0]]} maxWidth={640} alt="常规页面的产品部分：已开启启用仅限 POS 的产品、启用小数数量和删除订单时恢复库存，条形码字段设为 _sku">

1. **启用仅限 POS 的产品** — 为产品添加仅限 POS 的可见性选项。请参阅[下文](#enable-pos-only-products)。
2. **启用小数数量** — 允许商品行的数量为小数。请参阅[下文](#enable-decimal-quantities)。
3. **删除订单时恢复库存** — 从 POS 删除订单时恢复库存。请参阅[下文](#restore-stock-on-order-delete)。
4. **条形码字段** — 扫码时查找条形码的字段，此处为 `_sku`。请参阅[条形码字段](#barcode-field)。

</JourneyShot>

### 启用仅限 POS 的产品 {#enable-pos-only-products}

为 WP 后台中的每个产品添加可见性选项：**POS 和线上**、**仅限 POS** 或 **仅限线上**。*仅限 POS* 的产品在网店中隐藏，*仅限线上*的产品在 POS 中隐藏。

如果所有产品都在两个渠道销售，可保持关闭。关闭此选项不会隐藏任何产品，而且每个产品都会保留原有选择，以便重新开启时使用。要为单个或多个产品设置可见性，请参阅[仅限 POS 的产品](../../products/pos-only-products.mdx)。

### 启用小数数量 {#enable-decimal-quantities}

允许商品行的数量为小数，例如 `0.25`、`1.5` 或 `2.75`。适用于按重量、长度或时间销售的商品或服务，例如 0.5 kg 咖啡豆、1.5 小时的人工服务。

开启后，购物车的数量键盘会显示小数点。关闭后，键盘不显示小数点，店铺也会拒绝数量含小数的订单。

:::note 按重量销售
WCPOS 不会连接电子秤，也不会从电子秤读取重量。请先称重，再将重量输入为商品行的数量：对于按千克计价的产品，350 g 对应的数量是 `0.35`。

WCPOS 也不会读取某些电子秤打印的条形码标签中编码的重量或价格。
:::

### 删除订单时恢复库存 {#restore-stock-on-order-delete}

默认开启。通过 POS 将订单移至回收站或删除时，订单中产品的库存会相应增加，因此删除误录的销售记录会将商品归还库存。

:::warning 仅适用于从 POS 删除的订单
在 WP 后台删除订单不会恢复库存。从回收站还原订单也不会再次扣减库存。
:::

如果您通过其他方式统计库存，不希望删除订单影响库存，请关闭此选项。

### 条形码字段 {#barcode-field}

选择保存产品条形码号码的字段。收银员扫描条形码或在 **搜索产品** 中输入条形码时，POS 会查找该字段中的条形码与之匹配的产品。

在 **条形码字段** 列表中选择该字段。大多数店铺使用以下两种之一：

<Anchor id="default-option" />

- **WooCommerce 的条形码字段**，即默认选项。它是产品“库存”选项卡中的 **GTIN、UPC、EAN 或 ISBN** 输入框，新店铺应使用此字段。列表中显示为 `_global_unique_id`。
- **产品的 SKU**，适用于条形码与 SKU 相同的情况。列表中显示为 `_sku`。

如果条形码由条形码插件保存，请改选该插件的字段。如果列表中没有该插件的字段，请展开下方的 **插件和自定义条形码字段**，了解应输入的名称。

<Anchor id="other-common-options" />
<Anchor id="third-party-plugin-meta-keys" />

<details>
<summary>插件和自定义条形码字段</summary>

#### 常见插件 → 元数据键 {#common-plugins-meta-key}

如果条形码由条形码插件保存，请改用该插件的元数据键：

| 插件或字段 | 元数据键 |
|---|---|
| WooCommerce GTIN、UPC、EAN 或 ISBN *（默认）* | `_global_unique_id` |
| 产品 SKU | `_sku` |
| EAN 插件（欧洲商品编码） | `_ean`、`_ean13`、`_ean8` |
| EAN for WooCommerce（WPFactory 的 EAN Barcode Generator） | `_alg_ean`，除非您在其高级设置中更改了 **元数据键** |
| UPC 插件（通用产品代码） | `_upc`、`_upc_code` |
| GTIN 插件（全球贸易项目代码） | `_gtin`、`_gtin13`、`_gtin14` |
| 通用条形码字段 | `_barcode`、`_product_barcode` |
| WooCommerce Product Barcodes | `_barcode_text` |
| ATUM Inventory | `_atum_barcode` |

<Anchor id="custom-meta-keys" />

**条形码字段** 列表提供产品及其变体已使用的所有元数据键，以及 `_sku` 和 `_global_unique_id`。如果字段不在列表中，您需要输入其实际存储名称（元数据键），而不是插件在页面上显示的名称。请准确输入，包括开头的下划线（如有），然后选择 **创建“…”**。

#### 查找插件的元数据键 {#finding-your-plugins-meta-key}

1. 在 WP 后台编辑一个产品，并使用插件为其设置条形码。
2. 在插件文档中查找元数据键名称。
3. 或者，在数据库的 `wp_postmeta` 表中查找为该产品创建的键。

</details>

更改字段后，POS 会在下次同步时重建条形码索引，让扫码结果匹配新字段。您无需手动清除任何内容。

## 客户 {#customers}

### 根据客户邮箱自动生成用户名 {#automatically-generate-username-from-customer-email}

默认开启。收银员在 POS 中添加客户时，WooCommerce 会根据客户的邮箱地址生成用户名。关闭后，收银员需要在客户表单中输入用户名。此 POS 设置仅适用于在 POS 中添加的客户；线上结账仍沿用其 WooCommerce 设置。

### 默认 POS 客户 {#default-pos-customer}

设置每个新购物车默认使用的客户，以及自动填入的客户信息。**访客** 表示订单不属于任何账户。也可以在下拉列表中搜索并选择任意 WordPress 用户，例如您为柜台销售创建的“到店客户”账户。如果下拉列表呈灰色，请关闭下方的[使用收银员账户](#use-cashier-account)。

收银员随时都可以在购物车中更改客户。请参阅[选择客户](../../pos/cart/index.mdx#customer-selector)。

每个 POS 首次加载您的店铺时，都会复制 **默认 POS 客户** 和 **使用收银员账户** 设置，各设备也可以在自己的[设置](../store/general.mdx#default-customer)中更改这两项。已经加载过店铺的设备会保留自己的副本：要让设备采用您在此处新选的设置，请在该设备上使用[恢复服务器设置](../store/general.mdx#restore-server-settings)。

### 使用收银员账户 {#use-cashier-account}

勾选后，每个新购物车都会以当前登录的收银员作为客户。勾选期间，**默认 POS 客户** 会呈灰色，无法更改。

### 允许客户下载收据 {#storefront-receipts}

默认关闭。开启后，网店的 **我的账户 > 订单** 中会显示 **收据** 按钮，客户可以下载使用您的 WCPOS 收据模板生成的 PDF 收据。该按钮会显示在处理中、已完成或已退款的订单上。

开启后会显示 **客户收据模板**。初始选项为 **使用当前收据模板**，因此客户获取的收据与 POS 相同；也可以选择其他模板，为客户提供不同的收据，例如整页发票。请参阅[网店收据](../../receipts/storefront.mdx)。

### 税号 {#customer-tax-ids}

WCPOS 会将客户税号保存在其账户中，并在结账时复制到订单上。您可以在此查看检测到的税务插件：**已自动检测** 会显示插件名称，您无需操作；**未检测到插件** 表示 WCPOS 使用自己的内置字段。只有当插件使用自定义字段名称时，才需要在 **高级：使用其他字段名称** 中设置。请参阅[客户税号](./customer-tax-ids.mdx)。

## 隐私 {#privacy}

**允许匿名使用数据和错误报告** 可让 WCPOS 了解您的配置及出现的问题，以便发现程序缺陷。在您做出选择之前，此区域会显示 **允许** 和 **不用了，谢谢** 供您选择。您随时可以更改决定。

点击 **了解收集的内容**，即可在页面上展开完整列表。

<details>
<summary>收集的内容</summary>

- **会收集：** 您的配置（PHP 和 WooCommerce 版本、国家/地区、货币）、店铺规模（产品、订单和 POS 用户的大致数量）、您使用的页面和功能，以及错误和相关版本信息。
- **绝不收集：** 客户详情、订单内容、价格、站点地址，以及任何能够识别您或客户身份的信息。

</details>

## 高级：强制 SSL {#force-ssl}

默认开启。它可确保 POS 使用安全连接，请保持开启。

<details>
<summary>强制 SSL 的作用</summary>

POS 通过 HTTPS 打开：访问者通过普通 `http://` 访问 POS 页面时，会被重定向至 `https://`，且 WCPOS 生成的 POS 链接也使用 `https://`。只有在站点没有 SSL 证书时才关闭此选项。

</details>

## 故障排查 {#if-something-goes-wrong}

屏幕顶部显示 **“您的店铺使用了 Cloudflare”**
: 您的站点通过 Cloudflare 提供服务，其安全检查可能阻止 POS 访问店铺。如果 POS 显示 HOST121 或安全检查页面，请按照 **如何添加规则** 操作。请参阅 [Cloudflare](../../support/troubleshooting/cloudflare.mdx)。

**更改条形码字段后，扫码找不到产品**
: POS 会在下次同步时重建条形码索引。要立即重新开始，请长按 POS 中产品数量旁的同步箭头，然后选择 **清除并刷新**。请参阅[刷新或重新开始](../../products/sync.mdx#refresh)。

**数量为 0.5 等小数的订单无法保存**
: 请开启[启用小数数量](#enable-decimal-quantities)。
