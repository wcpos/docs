**WP 后台：** 热敏打印模板在 `WP Admin → POS → Templates` 中编辑。

热敏打印模板是一个简短的 XML 文本文件，用于设置收据打印机的收据布局。无论打印机使用哪种**打印机语言**（**ESC/POS**、**StarPRNT** 或 **Star Line Mode**），同一个文件既用于绘制屏幕预览，也用于告诉打印机要打印什么。它使用与 [HTML 模板](./html-templates.mdx)相同的 `{{placeholders}}` 来填入订单数据。[收据数据](./receipt-data.mdx)列出了所有占位符。

在[打印机设置](../hardware/printers/index.mdx)中配置的任何收据打印机，都应使用热敏打印模板。

## 创建热敏打印模板 {#make-a-thermal-template}

从模板库中选择一个模板并修改即可，无需从头编写。

1. **打开模板库。** 在 WP Admin 中，前往**销售点 → 模板**。在**模板库**中，将格式筛选为 **ESC/POS（热敏打印机）**。
2. **复制模板。** 在某张卡片（例如**简易热敏收据（80mm）**）上点击**使用模板**。副本会出现在**您的模板**中。打开它的**启用**开关。
3. **编辑模板。** 打开副本。修改左侧的 XML，右侧预览会随着输入更新。点击**更新**保存。编辑器不会自动保存。
4. **发送到收据打印机。** 在 POS 中，前往**设置 → 打印**。在**收据模板**下，选择模板旁的收据打印机，或保留**自动**选项。
5. **打印收据。** 在收据窗口的**模板**下选择您的模板，然后点击**打印收据**。

### 示例：修改致谢语 {#example-change-the-thank-you-line}

先检查店铺的收据页脚备注。如果已设置备注，打印时会用它替代致谢语，因此应按照[自定义收据](./customise.mdx#common-customisations)中的说明修改备注。如果未设置备注，请继续以下操作。

在**简易热敏收据（80mm）** 的编辑器中，找到靠近底部的 `{{i18n.thank_you_purchase}}`。只将这个占位符替换为您自己的文字。

修改前：

```xml
{{i18n.thank_you_purchase}}
```

修改后：

```xml
See you again soon!
```

该行中占位符前后的所有内容都保持不变。

```xml

```

</details>

点击**更新**。预览会在收据底部显示新的致谢语。

## 模板与打印机 {#the-template-and-the-printer}

有些选项需要在打印机上设置，而不是在模板中设置。在 POS 中，前往**设置 → 打印**，然后点击打印机所在行的**编辑**。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[680, 0], [680, 0], [680, 0], [680, 0]]} alt="编辑 Epson 网络打印机：打印机语言为 ESC/POS，纸张宽度为 48 — 80 mm，适用于大多数 Epson 和 Star 打印机；收据语言为自动；还有自动切纸、自动打开钱箱、设为默认值开关，以及将收据作为图像打印选项">

1. **打印机语言**——此处为 **ESC/POS**。同一模板适用于全部三种语言。
2. **纸张宽度**——此处为 **48**。实际打印时，它会替代模板的 `paper-width`。
3. **收据语言**——打印机用于打印的字符和符号集。仅适用于 ESC/POS。
4. **将收据作为图像打印**——将整张收据作为图片打印。

</JourneyShot>

启用**自动打开钱箱**后，下方会显示**钱箱接口**：

<JourneyShot manifest={manifest} device="tablet" step={6} offsets={[[680, 0], [680, 0], [47, -30], [36, -30]]} maxWidth={799} alt="编辑打印机窗口底部：自动打开钱箱已启用，钱箱接口设为引脚 2 / 钱箱 1，以及设为默认值选项和打开钱箱、测试打印、关闭按钮">

1. **自动打开钱箱**——打印收据后打开钱箱，除非模板本身包含 `<drawer />`。
2. **钱箱接口**——此处为**引脚 2 / 钱箱 1**。 `<drawer />` 未指定接口时，会使用此设置。
3. **打开钱箱**——打开钱箱一次，不进行打印。
4. **测试打印**——打印应用的测试页（*打印机诊断*），而不是您的模板。如果像此处一样启用了**自动打开钱箱**，也会打开钱箱。

</JourneyShot>

尤其要注意**纸张宽度**。模板的 `paper-width` 仅设置**预览**的宽度。实际打印以打印机的**纸张宽度**为准。`width="*"` 列会占据其他列之外的剩余空间（[自适应列](#star-width-columns)）。请检查您使用的每种纸张宽度下的效果（[收据宽度](../hardware/printers/receipt-width.mdx)）。

<details>
<summary>影响收据的打印机设置</summary>

| 打印机设置 | 对热敏打印模板的影响 |
|---|---|
| **纸张宽度**（32、42、48 或 64） | 纸张上每行的字符数。打印时会**替代**模板的 `paper-width`。请参阅[收据宽度](../hardware/printers/receipt-width.mdx)。 |
| **打印机语言** | **ESC/POS**、**StarPRNT** 或 **Star Line Mode**。同一模板可以使用这三种语言打印。 |
| **收据语言**（仅限 ESC/POS） | 打印机用于打印的字符和符号集。 |
| **自动打开钱箱** | 打印收据后打开钱箱，除非模板本身包含 `<drawer />`。 |
| **钱箱接口** | **引脚 2 / 钱箱 1** 或**引脚 5 / 钱箱 2**。启用**自动打开钱箱**时显示。供 `<drawer />` 在未指定接口时使用。 |
| **将收据作为图像打印** | 将整张收据作为图片打印。适用于打印机无法以文本方式打印的文字，如阿拉伯文、希伯来文和泰文。速度比文本打印慢。 |

</details>

## 可用标签 {#xml-elements}

下文为每个标签提供了单独的说明和示例。标签内的设置（如 `width="2"`）均为可选，除非标明必填。

<details>
<summary>所有元素和属性一览表</summary>

| 标签 | 打印内容及其设置（省略设置时采用的值） |
|---|---|
| `<receipt>` | 必需。包裹整个模板。<br />`paper-width` (`48`) |
| `<text>` | 一行文本。 |
| `<bold>`、 `<underline>`、 `<invert>` | 带样式的文本。 `<invert>` 为黑底白字。 |
| `<size>` | 放大文本，1–8 倍。<br />`width` (`1`)， `height` （同 `width`） |
| `<align>` | 对齐内部内容。<br />`mode`： `left`、 `center`、 `right` (`left`) |
| `<row>` + `<col>` | 并排显示的列。<br />`width`：数字或 `*` (`12`)； `align`： `left`、 `right` (`left`) |
| `<line />` | 横贯纸张的线。<br />`style`： `single`、 `double`、 `dashed`、 `dotted` (`single`) |
| `<feed />` | 空白行。<br />`lines` (`1`) |
| `<barcode>` | 将内部文本生成条形码。<br />`type` (`code128`)， `height` (`40`) |
| `<qrcode>` | 将内部文本生成二维码。<br />`size` (`4`) |
| `<image />` | 标志或图片。<br />`src` （必填）， `width` 以打印点为单位(`200`) |
| `<cut />` | 切纸。<br />`type`： `full`、 `partial` (`partial`) |
| `<drawer />` | 打开钱箱。<br />`connector`： `pin2`、 `pin5` （打印机的设置） |

</details>

数字必须是正整数。其他值（如 `width="1.5"` 或 `lines="0"`）会被忽略，标签会采用默认值。不在此表中的标签会被跳过，但其内部文本仍会打印。

### `<receipt>` 标签 {#root-element}

每个热敏打印模板的开头和结尾都使用 `<receipt>`：

```xml
<receipt paper-width="48">
  <!-- 48 characters = 80 mm paper on most Epson and Star printers -->
  <!-- 32 characters = 58 mm paper -->
</receipt>
```

`paper-width` 以字符数设置预览宽度。实际打印时，打印机的**纸张宽度**会替代它（[模板与打印机](#the-template-and-the-printer)）。

### 粗体、下划线和反白文本 {#text-and-formatting}

```xml
<text>Plain text</text>
<bold><text>Bold text</text></bold>
<underline><text>Underlined text</text></underline>
<invert><text>Inverted (white on black)</text></invert>
```

样式标签本身不会结束当前行，因此需要在其内部放入 `<text>` 。 `<text>` 会在文本之后结束当前行（[包裹带样式的标题](#wrap-styled-headings-in-text-for-a-line-break)）。在居中或右对齐的 `<align>` 内有一种例外情况（[居中的带样式标题](#centred-styled-headings-inside-align-blocks)）。

### 左对齐、居中和右对齐 {#alignment}

```xml
<align mode="left"><text>Left aligned</text></align>
<align mode="center"><text>Centered</text></align>
<align mode="right"><text>Right aligned</text></align>
```

其他任何 `mode` 值都会使内容靠左打印。

### 放大文本 {#text-size}

将文本加宽、加高，或同时加宽加高：

```xml
<size width="2" height="2"><text>Double-size text</text></size>
<size width="2" height="1"><text>Wide text</text></size>
<size width="1" height="2"><text>Tall text</text></size>
```

如果省略 `height`，它会与 `width` 相同。ESC/POS 打印机最多支持 8 倍，Star 打印机最多支持 6 倍。

### 列 {#tabular-layout}

使用 `<row>` 和 `<col>` 将文本分列并排显示：

```xml
<row>
  <col width="16">Item name</col>
  <col width="4" align="right">Qty</col>
  <col width="12" align="right">Price</col>
</row>
```

这些宽度的总和为 32，对应最窄的纸张，因此该行适用于所有打印机。在更宽的纸张上，该行剩余部分会留白。

列宽以字符数计算。为某一列设置 `width="*"`，它就会占据剩余空间，使整行适应纸张宽度：

```xml
<row>
  <col width="*">{{name}}</col>
  <col width="12" align="right">{{line_total_display}}</col>
</row>
```

- 一个 `<col>` 可按以下方式对齐： `left` 或 `right`。列无法居中。
- 一个 `<col>` 如果位于 `<row>` 之外，就会被跳过。
- 列**只打印文本**。位于 `<col>` （`<bold>`、 `<size>` 等）会显示在预览中，但不会打印到纸上，除非启用**将收据作为图像打印**。模板库中的模板以这种方式将总计加粗（例如**简易热敏收据（80mm）**），因此其总计实际打印时为普通字体。要将整行打印为粗体，请用 `<bold>` 包裹 `<row>`。

<details>
<summary>示例：以粗体打印的总计行</summary>

```xml
<!-- Prints bold on paper -->
<bold>
  <row>
    <col width="*">{{i18n.total}}</col>
    <col width="16" align="right">{{totals.total_display}}</col>
  </row>
</bold>
```

</details>

### 分隔线与留白 {#separators-and-spacing}

```xml
<line />                       <!-- Single line -->
<line style="double" />        <!-- Double line -->
<line style="dashed" />        <!-- Dashed line -->
<line style="dotted" />        <!-- Dotted line -->
<feed lines="2" />             <!-- Two blank lines -->
```

预览会为各个样式绘制不同效果。在纸上，`single` 和 `dashed` 的效果相同。

<details>
<summary>各线条样式的实际打印效果</summary>

- `single` 和 `dashed` 都会打印一行横贯纸张的 `-` 字符。
- `dotted` 会横贯纸张打印 `. . . .`。如果应用通过 ePOS（Epson 自有的网络连接方式）连接 Epson 打印机，则会像 `single` 一样打印 `-`。这种连接包括浏览器中的 Epson 网络打印机，以及桌面端通过 ePOS 端口响应的打印机。
- `double` 会打印一行双线字符。通过 ePOS 或云打印时，则会打印一行 `=`。

</details>

### 切纸和打开钱箱 {#printer-commands}

```xml
<cut />                <!-- Partial cut (leaves a small tab) -->
<cut type="full" />    <!-- Full cut -->
<drawer />             <!-- Open the cash drawer -->
<drawer connector="pin5" /> <!-- Open the drawer on pin 5 -->
```

- `<cut />` 会先将纸张送到切刀处。预览会用带有 ✂ 的虚线表示切纸位置。在应用通过 ePOS 连接的 Epson 打印机上， `<cut />` 和 `<cut type="full" />` 的切纸效果相同。
- `<drawer />` 无论**自动打开钱箱**如何设置，都会打开钱箱。如果模板本身包含 `<drawer />`，应用就不会再次打开钱箱。预览中不会显示此标签的效果。请参阅 [钱箱](../hardware/printers/cash-drawer.mdx)。

### 条形码和二维码 {#barcodes-and-qr-codes}

```xml
<barcode type="code128" height="40">{{order.number}}</barcode>
<qrcode size="4">{{fiscal.qr_payload}}</qrcode>
```

- `height` 是条形码的高度，以打印点为单位。
- `size` 是二维码中每个小方块的大小：数值越大，二维码越大。

<details>
<summary>用于生成二维码的标签： `<barcode>`</summary>

`<barcode type="qrcode">` （或 `type="qr"`）也能生成二维码。其大小由此属性决定： `height`： `height` ÷ 10，取值限制在 2 到 10 之间。

</details>

预览将条形码和二维码绘制为图片。打印机收到的则是自身支持的条码命令，或者在应用已生成图片时直接打印该图片。

## 示例：简易 80mm 收据 {#example-simple-80mm-receipt}

一张从上到下完整的收据包含：店铺名称和地址、订单号、日期和收银员、分为三列的商品、带粗体**总计**行的金额汇总、每笔付款及其实收金额和找零、致谢语以及切纸操作。

<details>
<summary>显示完整模板（约 80 行）</summary>

```xml
<receipt paper-width="48">
  <align mode="center">
    <bold><size height="2"><text>{{store.name}}</text></size></bold>
    {{#store.address_lines}}<text>{{.}}</text>{{/store.address_lines}}
    {{#store.phone}}<text>{{store.phone}}</text>{{/store.phone}}
  </align>
  <line />

  <text>Order: #{{order.number}}</text>
  <text>Date: {{order.created.datetime}}</text>
  {{#cashier.name}}<text>Cashier: {{cashier.name}}</text>{{/cashier.name}}
  <line />

  <!-- Column headers, bold on paper -->
  <bold>
    <row>
      <col width="*">Item</col>
      <col width="4" align="right">Qty</col>
      <col width="12" align="right">Total</col>
    </row>
  </bold>
  <line />

  <!-- Line items -->
  {{#lines}}
  <row>
    <col width="*">{{name}}</col>
    <col width="4" align="right">{{qty}}</col>
    <col width="12" align="right">{{line_total_display}}</col>
  </row>
  {{/lines}}

  <line />

  <!-- Totals -->
  <row>
    <col width="*">Subtotal</col>
    <col width="16" align="right">{{totals.subtotal_display}}</col>
  </row>
  {{#totals.tax_total}}
  <row>
    <col width="*">Tax</col>
    <col width="16" align="right">{{totals.tax_total_display}}</col>
  </row>
  {{/totals.tax_total}}
  <bold>
    <row>
      <col width="*">TOTAL</col>
      <col width="16" align="right">{{totals.total_display}}</col>
    </row>
  </bold>

  <line />

  {{#payments}}
  <row>
    <col width="*">{{method_title}}</col>
    <col width="16" align="right">{{amount_display}}</col>
  </row>
  {{#tendered}}
  <row>
    <col width="*">Tendered</col>
    <col width="16" align="right">{{tendered_display}}</col>
  </row>
  <row>
    <col width="*">Change</col>
    <col width="16" align="right">{{change_display}}</col>
  </row>
  {{/tendered}}
  {{/payments}}

  <feed lines="2" />
  <align mode="center">
    <text>Thank you for your purchase!</text>
  </align>
  <feed lines="3" />

</receipt>
```

</details>

此处的标签使用普通英文。模板库中的模板则使用 `{{i18n.*}}` 标签，使收据采用店铺的语言（[i18n 字段](./receipt-data.mdx#i18n)）。

## 自适应列 {#star-width-columns}

`width="*"` 列会随纸张宽度伸缩。无需为一种纸张尺寸固定所有列宽，只需将应当伸缩的列设为 `*`：

```xml
<!-- Works on 58 mm (32 characters) AND 80 mm (48 characters) printers -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

在每行 48 个字符的打印机上，商品名称占 38 个字符。在每行 32 个字符的打印机上，它占 22 个字符。固定列在两种打印机上保持相同宽度。

<details>
<summary>多个 `*` 列</summary>

剩余空间会平均分配。无法均分的字符空间分配给最后一个 `*` 列。`*` 列的宽度始终不少于 1 个字符。

</details>

## 模板预览 {#template-preview}

WP Admin 中的模板编辑器会在您输入时显示**实时热敏打印预览**。它在您停止输入 300 ms 后更新。POS 中的收据窗口也会在打印前显示同样的预览。两处都使用等宽字符绘制模板，宽度为 `paper-width`。

预览和打印使用同一个模板，没有单独的打印模板。预览接近纸上效果，但并非完全一致，因此正式使用前，请在您使用的每种纸张宽度上打印测试收据。

<details>
<summary>预览与实际打印的差异</summary>

| 预览中 | 纸张上 |
|---|---|
| 宽度为 `paper-width` | 宽度为打印机的**纸张宽度** |
| `<bold>`、 `<size>` 即使位于 `<col>` 内也会显示效果 | 列以普通文本打印，除非启用**将收据作为图像打印** |
| `<size>` 仅根据 `width` 放大，因此只加高的文本看起来仍为正常大小 | 宽度和高度均生效 |
| 单线与虚线看起来不同 | 两者都打印为 `-` 字符 |
| `<cut />` 显示为带有 ✂ 的虚线； `<drawer />` 不显示任何内容 | 纸张被切断，钱箱打开 |
| 所有文字都能显示 | 只能打印打印机内置的字符，除非启用**将收据作为图像打印** |

</details>

## 模板编写技巧 {#authoring-tips-and-pitfalls}

热敏打印有一些 HTML 打印中不会遇到的问题。以下逐一介绍这些问题及解决方法。

### 用 `<text>` 包裹带样式的标题以换行 {#wrap-styled-headings-in-text-for-a-line-break}

样式标签—— `<bold>`、 `<size>`、 `<underline>`、 `<invert>`、 `<align>` ——**本身不会结束当前行**。 `<text>` 会在文本之后结束当前行，整行标签也会如此，例如 `<line />`、 `<row>` 和 `<feed />`。有一种例外：直接放在居中或右对齐的 `<align>` 内的带样式标题，如果后面还有一行内容，就会结束自身所在行（[居中的带样式标题](#centred-styled-headings-inside-align-blocks)）。

```xml
<!-- ❌ Wrong: the heading runs into whatever follows -->
<bold>{{i18n.bill_to}}</bold>
{{customer.name}}

<!-- ✅ Right: put the words inside <text> -->
<bold><text>{{i18n.bill_to}}</text></bold>
<text>{{customer.name}}</text>
```

模板库中的 80 mm 模板对每个标题都采用了这种做法。

### 避免在较窄的行内使用 `<size width="2">` {#avoid-size-width2-inside-narrow-rows}

双倍宽度的文本**每个字符占用的空间加倍**。在每行 48 个字符的打印机上能容纳的标题，到了每行 42 个字符的打印机上可能会溢出；在 58 mm 纸张上，一行只能容纳 16 个字符。

位于 `<col>` 内的尺寸设置本来就不会体现在打印结果中。要放大某个值（例如醒目的总计或厨房订单号），请改用 `<size>` 将它单独打印在一行上。

<details>
<summary>示例：加高的店铺名称和放大的总计</summary>

```xml
<!-- For store names, prefer normal-width, double-height -->
<bold><size height="2"><text>{{store.name}}</text></size></bold>

<!-- For a big total, put it on its own line above the row -->
<align mode="right">
  <bold><size height="2"><text>{{totals.total_display}}</text></size></bold>
</align>
```

</details>

### 使用 `width="*"` 让行适应各种纸张 {#use-width-for-paper-width-agnostic-layouts}

`width="*"` 列占据固定列之外的剩余宽度。这样构建的行适用于每行 32、42、48 和 64 个字符的打印机（[自适应列](#star-width-columns)）。固定列和双倍宽度文本仍会占用各自的完整空间，因此请检查您使用的每种纸张宽度下的效果。

如果确实使用固定宽度，**请确保宽度总和不超过打印机的纸张宽度**：58 mm 纸张上为 32。80 mm 纸张上应使用 42，而不是 48：许多 80 mm 打印机每行打印 42 个字符，宽度总和为 48 的行在这些打印机上会换行。请在[收据宽度](../hardware/printers/receipt-width.mdx)中查看如何确定打印机的字符数。

### `<align>` 块内居中的带样式标题 {#centred-styled-headings-inside-align-blocks}

在 `<align mode="center">` （或 `right`）内，直接放在 `<align>` 内的带样式标题—— `<bold>`、 `<size>`、 `<underline>` 或 `<invert>` ——如果后面还有一行内容，就会结束自身所在行。居中放大的店铺名称下方若是居中地址，即使没有 `<text>` 包裹。

在 `<align>` 块之外，请保留 `<text>` 包裹。

### 破折号和弯引号 {#escpos-punctuation-normalisation}

在 **ESC/POS** 打印机上，破折号和弯引号会打印为普通形式，因此可以放心输入。在 Star 打印机上，请只使用打印机内置的字符和符号。

<details>
<summary>具体转换内容及适用的打印机</summary>

当**打印机语言**为 **ESC/POS** 时，特殊标点会在打印前转换为普通键盘字符：

- 各种长度的连字符和破折号（短破折号、长破折号、数字横线、减号）→ `-`
- 弯引号 → 直引号

因此，即使打印机没有内置这些字符，`Mon–Sat 9:00–18:00` 和 `“open”` 也能正确打印。应用向 Star 打印机（**StarPRNT** 和 **Star Line Mode**）打印时，会保留原始破折号和引号，因此请只使用打印机内置的字符。通过云打印时，Star 收据也会进行同样的普通字符转换。

在所有打印机上，特殊空格（不换行空格、窄空格和细空格）都会打印为普通空格。

</details>

### 非拉丁文字和从右向左书写的文字 {#non-latin-and-rtl-scripts}

热敏打印机使用自身内置的字符打印文本。只有打印机内置了相应文字，阿拉伯文、希伯来文、波斯文、乌尔都文、泰文等非拉丁文字才能正确打印。否则会出现空白或错误字符。

可靠的解决方法是在打印机上启用**将收据作为图像打印**。它会将整张收据绘制成图片，因此无论打印机内置哪些字符，都能按设计效果打印。切纸、走纸或 `<drawer />` 命令如果位于模板末尾，仍会生效；如果位于模板中间，则会被忽略。其他解决方法请参阅 [非拉丁文字收据](../hardware/printers/non-latin-receipts.mdx)。

:::note 热敏打印设备需要热敏打印模板
热敏打印机无法打印整页 **HTML** 模板。打印任务必须转换为打印机命令（ESC/POS 或 Star），而 HTML 页面无法按这种方式表达。热敏打印设备请使用热敏打印模板。对于整页 A4/Letter HTML，请使用系统打印机或 PDF 打印机，或通过 [PrintNode](./cloud-printing.mdx#setup-printnode) 打印。
:::

### 标志和图片 {#logos-and-images}

使用 `<image />` 添加标志。店铺标志位于 `{{store.logo}}`：

```xml
<align mode="center">
  <image src="{{store.logo}}" width="200" />
</align>
```

应用会在设备上将图片转换为打印点：将透明区域填充为白色，缩小图片以适应纸张，并转换为黑白图像（以点阵保留标志的明暗层次）。然后将其作为图片发送到打印机。请使用高对比度的 PNG；目前还无法打印 SVG。

<details>
<summary>图片宽度、支持的来源和格式</summary>

- **宽度**：`width` 以打印点为单位（省略时为 200）。图片打印宽度不会超过纸张：58 mm 纸张（每行 32 个字符或更少）为 384 点，80 mm 纸张为 576 点。
- **支持的来源**：`data:image/png` 和 `data:image/jpeg` 数据 URL、`http(s)` 地址，以及您自己网站上以 `/` 开头的路径。不接受以 `//` 开头的地址，以及包含反斜杠或 `..` 的路径。
- **最佳格式**：透明或白色背景的高对比度 PNG。JPEG 也可用，但模糊区域可能打印成杂点。
- 热敏打印机**尚不支持 SVG**。

</details>

### 建议 {#tips}

- **从模板库中的模板开始。** 模板库中的热敏打印模板使用了上述所有模式，包括 58 mm、80 mm 和从右向左书写的收据、厨房小票，以及收银结算单、盘点单和报表版本。
- **测试您使用的每种纸张宽度**，即使使用了 `width="*"` 列也不例外。固定列和双倍宽度文本仍可能导致一行内容折成多行。
- 金额**使用 `_display` 字段**。这些字段已按店铺的货币格式设置好（[货币字段](./receipt-data.mdx#currency-fields)）。
- **保持简洁。** 热敏打印机可用的文本样式比网页少。构建收据时使用 `<text>`、 `<row>` 和 `<col width="*">`。

## 故障排查 {#if-something-goes-wrong}

**编辑器预览提示“热敏打印模板渲染错误。请检查 XML 语法。”**
模板无法读取，原因有两种：

- 标签未闭合，或文本中存在未转义的 `&` 或 `<` 。请闭合每个标签（使用`<line />`，而不是 `<line>`），并使用 `&amp;` 来表示 `&`。
- 最外层标签不是 `<receipt>`。请用以下标签包裹整个模板： `<receipt>…</receipt>`。

**标题与下一行内容连在一起。**
样式标签本身不会结束当前行，因此后续文字会接在同一行上。请在其内部放入 `<text>` （[包裹带样式的标题](#wrap-styled-headings-in-text-for-a-line-break)）。直接位于居中或右对齐的 `<align>` 内的带样式标题是例外（[居中的带样式标题](#centred-styled-headings-inside-align-blocks)）。

**一行内容在纸上打印成了两行。**
固定宽度的总和超过了打印机的**纸张宽度**。将其中一列设为 `width="*"`，或让固定宽度的总和不超过**纸张宽度**：58 mm 纸张为 32，许多 80 mm 打印机为 42（[使用 `width="*"`](#use-width-for-paper-width-agnostic-layouts)）。

**总计在预览中为粗体，打印到纸上却是普通字体。**
位于 `<col>` 内的样式不会打印，而模板库中的模板正是以这种方式将总计加粗。请用 `<bold>` 包裹整个 `<row>` （[列](#tabular-layout)），或启用**将收据作为图像打印**。

**预览比纸张窄或宽。**
实际打印以打印机的**纸张宽度**为准，而不是 `paper-width`。将 `paper-width` 设为相同数值，即可预览实际打印效果。

**切纸后仍留有一小段连接。**
`<cut />` 是部分切纸。使用 `<cut type="full" />` 可完全切断。在通过 ePOS 连接的 Epson 打印机上，两者的切纸效果相同，因此 `type` 在这种情况下不起作用。

**标志未打印出来。**
检查 `src` 是否属于[支持的来源](#logos-and-images)，且不是 SVG。如果在浏览器中遇到此问题，请参阅[浏览器中标志缺失](../hardware/printers/logo-missing-browser.mdx)。

**出现问号、空白或错误字符。**
打印机没有内置该文字。请启用**将收据作为图像打印**（[非拉丁文字](#non-latin-and-rtl-scripts)）。

**每次打印收据都会打开钱箱。**
可能是启用了**自动打开钱箱**，也可能是模板中包含 `<drawer />`，该标签无论设置如何都会打开钱箱。要停止此行为，请关闭该设置，并将 `<drawer />` 从模板中移除。

**钱箱无法打开。**
如果模板中的 `<drawer />` 具有 `connector`属性，它会覆盖打印机的设置。移除 `connector` ，让打印机的**钱箱接口**设置生效，然后尝试该设置中的另一个引脚（启用**自动打开钱箱**时会显示此设置）。还要检查**打印机语言**是否与打印机匹配，因为钱箱命令取决于此设置。

**为旧版 StarPRNT 固定布局编写的模板无法正常打印。**
该布局已在 1.10 版本中移除。请使用 `<row>`、 `<col>` 和 `width="*"`重新构建，或从模板库中的模板重新开始。
