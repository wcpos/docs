**WP 后台：** 在 `WP Admin → POS → Templates` 中选择模板。

WCPOS 打印的每张收据，都是将销售数据填入模板后生成的。你可以在 **WP Admin → POS → 模板**中选择模板；除非收银员另选模板，否则收银时会打印第一个已启用的模板。同一界面还提供发票、礼品收据、装箱单和厨房小票。

跳转到所需内容：

- **收银操作：** [打印收据](#at-the-till)、[邮件发送收据](#email)或[稍后重新打印](#reprint)。
- **店主：** [选择店铺收据](#how-it-works)并[发送到打印机](#template-printers)。

## 收银操作 {#at-the-till}

销售付款完成后，付款完成界面会显示收据。打印步骤如下：

1. 检查预览中的收据（5）。
2. 检查**打印机**（4）。**自动**会选择适合该模板的打印机。
3. 点击**打印收据**（6）。首次打印后，按钮会变为**再次打印**。

<JourneyShot manifest={checkoutShots} device="tablet" step={6} offsets={[[279, 0], [260, 0], [292, 0], [292, 0], [0, 0], [48, -38], [49, -38], [128, 0]]} alt="付款完成界面：应找零金额、付款方式、模板和打印机选择器、收据预览，以及邮件发送收据、下载 PDF、打印收据和新销售按钮">

1. **找零**：应退还的金额。
2. **已付款**：付款金额及方式。
3. **模板**：本次销售使用的收据。请参阅[为单笔销售选择不同收据](#one-sale)。
4. **打印机**：打印目的地。请参阅[将各模板发送到打印机](#template-printers)。
5. **预览**：收据打印时的样子。
6. **打印收据**：在所选打印机上打印当前显示的收据。
7. **邮件发送收据**：向顾客发送邮件。请参阅[邮件发送收据](#email)。
8. **新销售**：清空购物车，准备接待下一位顾客。

</JourneyShot>

两者之间的**下载 PDF**可将收据保存为文件，需要联网。

### 邮件发送收据 {#email}

1. 点击**邮件发送收据**。
2. 检查**电子邮件地址**。默认使用订单的账单邮箱。要将新地址保存在订单中，请打开**将邮箱保存到账单地址**。
3. 点击**发送**。

顾客收到的是 WooCommerce 针对该订单发送的发票邮件，而非预览中显示的模板。离线时，按钮会显示**联网后发送**，设备重新连接到店铺后便会发送邮件。

### 重新打印收据 {#reprint}

使用 [WCPOS Pro](../getting-started/pro-license.mdx)，可以稍后重新打印：

1. 从侧边菜单打开**订单**。
2. 找到订单，点击其收据按钮。
3. 在打开的收据中执行打印。

未使用 Pro 时，请在点击**新销售**前，从付款完成界面打印收据或通过邮件发送收据。

更多信息请参阅[重新打印收据](./at-checkout.mdx#reprinting-receipts)。

### 为单笔销售选择不同收据 {#one-sale}

收银员可在付款完成界面的**模板**中选择另一个已启用的模板。该选择仅对本次销售有效。如果只启用了一个模板，**模板**会显示其名称，不提供选择列表。

## 选择收据 {#how-it-works}

:::tip 只是想更改收据？
请从 **[自定义收据](./customise.mdx)** 开始。该页面介绍了三种最简单的方式：选择另一款内置模板、让 AI 帮忙调整模板，或手动编辑。
:::

店主只需在 WP 后台设置一次：

1. 在 WP 后台，进入 **POS → 模板**。**收据**选项卡顶部列出**你的模板**，下方是**模板库**。
2. 在模板库中，使用**搜索模板…**、**类别**、**格式**和**方向**筛选卡片。**预览**会使用**示例数据**或你的某个订单填充模板。
3. 点击**使用模板**。你的副本会添加到**你的模板**列表底部，并默认启用。
4. 将其拖到**你的模板**顶部。收银时会默认使用第一个已启用的模板；在你将新模板移到内置的**旧版 PHP 模板**上方，或关闭后者的**启用**开关之前，旧版模板的优先级仍高于新模板。

要修改模板文字或外观，请在模板编辑器中打开副本，编辑时即可实时预览。请参阅[自定义收据](./customise.mdx)。

## 将各模板发送到打印机 {#template-printers}

在应用的**设置 → 打印**中，**收据模板**列出了收银时可打印的模板，下方是**报表模板**和**交班模板**。每一行显示：

- **模板**，例如内置的**旧版 PHP 模板**。
- **类型**：**HTML** 表示使用打印对话框；热敏模板则显示纸张规格，例如**热敏 80mm**。
- **打印机**：**自动**会选择符合模板类型和纸张宽度的打印机；如果没有合适的打印机，则打开**打印对话框**。选定某台打印机后，该模板将始终发送到这台打印机。

添加打印机的方法请参阅[打印机](../hardware/printers/index.mdx#adding-a-printer)。

## Pro：为各店铺设置专属收据 {#pro-features}

使用 [WCPOS Pro](../getting-started/pro-license.mdx)，每个店铺都可以打印自己的收据。在 **POS → 店铺**中打开一个店铺：

- **收据**：店铺的**收据模板**列表默认显示**与站点相同**，点击**自定义**后即可勾选收银员在该店铺可打印的模板；第一个勾选的模板是店铺默认模板，可通过拖动更改顺序。点击**使用站点模板**可恢复原设置。同一页面还提供店铺的**收据留言**。
- **详情**：包含**标志和地址**，可选择**使用站点标志**或**上传标志**，以及店铺的**联系方式**。

请参阅[填写店铺页面](../stores/setup.mdx#store-pages)和[各店铺的模板](./customise.mdx#per-store-assignments)。

## 收银以外的收据用途 {#beyond-the-till}

- **电子邮件**：收银时使用**邮件发送收据**，发送的是 WooCommerce 自带的顾客发票邮件，而非 WCPOS 模板。可在 **WooCommerce → 设置 → 电子邮件**中修改其外观。
- **下载 PDF**：PDF 由服务器生成，因此需要联网。
- **线上顾客**：打开**允许顾客下载收据**后，“我的账户”中的订单会新增**收据**按钮。此功能默认关闭，**顾客收据模板**用于选择顾客收到的模板。请参阅[店面收据](./storefront.mdx)。

## 问题排查 {#goes-wrong}

**打印的不是新模板。** 收银时使用**你的模板**中第一个已启用的模板。将新模板拖到顶部，或停用其上方的模板。对于单笔销售，收银员可在付款完成界面的**模板**中选择它。

**付款完成界面的模板只显示名称，没有列表。** 当前只启用了一个收据模板。在**你的模板**中再启用一个，收银员即可选择。

**离线时无法选择某个模板。** **旧版 PHP 模板**和 WP Overnight 模板在服务器上生成。如果收银设备经常断线，请将 HTML 或热敏模板设为默认模板。

**标志未显示。** 未使用 Pro 时，收据使用 WordPress 站点标志，请在主题中设置。使用 Pro 时，打开店铺的**详情**，选择**使用站点标志**或**上传标志**。如果仅从浏览器选项卡打印时缺少标志，请参阅[浏览器中标志缺失](../hardware/printers/logo-missing-browser.mdx)。

**无法打印，或打印到了错误的打印机。** 在**设置 → 打印**中检查模板对应的打印机，然后参阅[无法打印时](../hardware/printers/index.mdx#when-nothing-prints)。

## 模板库 {#template-gallery}

模板库提供现成模板，可直接使用或自定义。按**类别**（收据、发票、礼品收据、贷项通知单、采购订单、厨房小票、吧台小票）、**格式**（**HTML（浏览器打印）**或 **ESC/POS（热敏打印机）**）和**方向**（**从左到右**或**从右到左**）筛选。每张卡片都有**预览**和**使用模板**；点击**使用模板**会在*你的模板*中创建可编辑的副本，模板库原版保持不变。

如果你复制的模板在模板库中有更新版本，卡片会显示**有可用更新**。**安装新版本**会将新版本添加为独立副本，因此你已有的修改会保留。

### 第三方单据模板 {#third-party-document-templates}

启用 WP Overnight 的 **PDF Invoices & Packing Slips for WooCommerce** 后，其发票和装箱单会加入收据模板。打印这些模板需要联网。

<Accordion>
  <AccordionItem question="WP Overnight 模板的工作方式">

WCPOS 会将**发票（WP Overnight）**和**装箱单（WP Overnight）** 添加到收据模板中，并默认启用。它们会将订单传递给 WP Overnight 的单据 API，因此会保留在该插件中设置的发票和装箱单编号、布局、品牌信息、法律及税务字段，以及模板修改。

这些模板仅在 WP Overnight 插件启用时可用，由服务器渲染。需要离线打印时，请使用内置的 HTML 或热敏模板。请参阅 [WP Overnight 模板](./customise.mdx#wp-overnight-invoice-and-packing-slip-templates)。

  </AccordionItem>
</Accordion>

### 自适应税额显示 {#adaptive-tax-display}

大多数内置模板会遵循 WooCommerce 的税费显示设置，打印含税或不含税价格。

<Accordion>
  <AccordionItem question="哪些模板遵循该设置，以及如何显示">

标准、标准 RTL、极简/现代、窄版、发票、报价和简易热敏模板**遵循 WooCommerce 的税费显示设置**：

- **显示含税价格的店铺**（EU/UK/AU）会打印含税价格，并显示“已含税”行。
- **显示不含税价格的店铺**（US/CA）会打印不含税价格，并将税额单独列为一行，标签为**税额总计**。
- 总计始终显示实际收取的含税金额。

**详细**模板属于正式税务发票：商品行始终不含税，后面列出各税率的税额明细。只有税额标题遵循你的设置。

  </AccordionItem>
</Accordion>

## 模板引擎 {#template-engines}

每个模板使用以下三种引擎之一：**HTML（离线）**、**XML（收据打印机）** 或 **PHP（旧版）**。HTML 和 XML 支持离线打印；PHP 需要连接服务器。

<Accordion>
  <AccordionItem question="三种引擎">

创建模板时可以选择引擎；从模板库点击**使用模板**时，则由卡片决定引擎。**模板保存后无法更改引擎**：如需切换，请新建模板。

<FeatureGrid>
  <FeatureCard icon="code" title="HTML（离线），推荐">
    不含逻辑的 HTML，使用 <code>{"{{variable}}"}</code> 占位符。在设备上渲染，因此**支持离线打印**。用于打印对话框。
  </FeatureCard>
  <FeatureCard icon="print" title="XML（收据打印机）">
