**WP 后台：** 在 `WP Admin → POS → Settings → General` 中，为线上订单启用 **收据** 按钮。

:::note 本页面向网站管理人员
使用 [WCPOS Pro](../getting-started/pro-license.mdx)，您可以在收银台为任何订单打印收据或通过电子邮件发送收据，包括线上订单。请参阅 **订单** 页面的[重新打印收据](../orders/index.mdx#receipt-reprinting)。
:::

:::tip 客户索取线上订单收据时
网站设置好后，客户可以使用 **我的账户 → 订单** 中的 **收据** 按钮；如果店铺在订单确认页面添加了收据链接，也可以使用该链接。
:::

WCPOS 收据模板也适用于您的网站。在线购物的客户可以从 **我的账户** 下载 PDF 收据，也可以通过您放在订单确认页面上的链接下载。

## 启用收据按钮 {#my-account}

:::warning 请先启用收据模板
开始前，请在 **POS → 模板** 中启用一个模板。如果没有启用模板，即使开启了设置，客户也看不到 **收据** 按钮。请参阅[自定义收据](./customise.mdx#option-1--pick-a-different-template)。
:::

该按钮默认关闭，需要手动启用。PDF 根据您的收据模板生成。

1. 在 WP Admin 中，转到 **POS → 设置 → 常规**。

<JourneyShot manifest={manifest} device="desktop" step={1} offsets={[[95, 0], [105, 0]]} alt="WP Admin 中已选中 POS 菜单下的“设置”，并打开设置菜单中的“常规”，显示“店铺”“收银机”和“商品”部分的开头">

1. **POS → 设置** — WP Admin 中用于打开 POS 设置的菜单项。
2. **常规** — 第一个设置页面，进入时默认打开。

</JourneyShot>

2. 向下滚动到 **客户** 部分，开启 **允许客户下载收据**。切换开关后会立即保存。

<JourneyShot manifest={manifest} device="desktop" step={2} maxWidth={880} offsets={[[100, 0], [310, 0]]} alt="“常规”中的“客户”部分：根据客户电子邮件自动生成用户名、默认 POS 客户设为访客，以及尚未开启的“允许客户下载收据”">

1. **客户** — 包含收据设置的部分。
2. **允许客户下载收据** — 默认关闭，需要手动开启。

</JourneyShot>

3. 下方会出现 **客户收据模板**。保留 **使用已启用的收据模板**，或选择一个模板。请参阅[选择客户使用的模板](#template-choice)。

现在，已登录的客户会在 **我的账户 → 订单** 中的订单旁看到 **收据** 按钮。点击后会下载以订单命名的 PDF，例如 `receipt-1234.pdf`。

该按钮仅在已付款的订单中显示：

| 订单状态 | 收据按钮 |
|---|---|
| **处理中** | 显示 |
| **已完成** | 显示 |
| **已退款** | 显示 |
| 其他任何状态，例如 **待付款**、**保留**、**已取消** 或 **失败** | 不显示 |

开发人员可以[更改显示按钮的订单状态](#developers)。

## 选择客户使用的模板 {#template-choice}

**客户收据模板** 决定下载的收据使用哪个模板。

- **使用已启用的收据模板**（默认）：客户获得的收据使用 **POS → 模板** 中已启用的收据模板。在那里更换模板后，客户下载的收据也会随之更改。
- **指定模板**：无论收银员在收银台选择哪个模板，客户始终使用此模板。如果启用了多个收据模板，或希望线上订单采用独立的样式，可以使用此选项。

窄幅热敏收据样式的模板会生成窄幅 PDF。对于线上订单，整页格式通常更易阅读：模板库中的 **发票** 模板适用于 A4 和 Letter 纸张。有关添加方法，请参阅[自定义收据](./customise.mdx#option-1--pick-a-different-template)。

PDF 与收银台收据使用相同的[收据数据](./receipt-data.mdx)，因此会沿用您的标志、店铺详情和税费设置。

如果选中的模板之后被删除或取消发布，下拉菜单会显示 **模板不可用**，客户将改为使用已启用的收据模板。此时请选择其他模板。

## 在订单确认页面添加收据链接 {#shortcode}

在客户结账后看到的“感谢购买”页面上，提供 **下载收据（PDF）** 链接。未注册账户的访客可以通过这种方式获取收据。

如果 WP Admin 中有 **外观 → 编辑器 → 模板 → 订单确认**，您可以自行在感谢购买页面添加链接：

1. 在 WP Admin 中，转到 **外观 → 编辑器 → 模板**，打开 **订单确认**。
2. 在希望显示链接的位置添加 **短代码** 区块，并在其中输入 `[wcpos_receipt]`。
3. 点击 **保存**。

如果没有该模板，或希望在 **我的账户** 中的订单页面上显示链接，请让开发人员[通过代码添加收据链接](#developers)。

无论是否开启 **允许客户下载收据**，短代码都有效：该设置仅控制 **我的账户 → 订单** 中的按钮。

<details>
<summary>短代码选项和示例</summary>

`[wcpos_receipt]` 适用于订单确认页面和 **我的账户** 中的订单页面。在这些页面上，它会自动找到订单，无需输入订单号。在其他页面上，除非提供 `order_id`，否则不会显示任何内容。

| 选项 | 默认值 | 作用 |
|---|---|---|
| `order_id` | *（从页面获取）* | 在任意页面链接到指定订单。仅向该订单所属的已登录客户显示。 |
| `link_text` | `Download receipt (PDF)` | 链接文字。 |
| `format` | `pdf` | `pdf` 下载 PDF。`html` 在浏览器中打开收据，以便打印。 |
| `template` | *（已启用的收据模板）* | 改用此模板。 |
| `class` | `wcpos-receipt-link` | 链接的 CSS 类。 |
| `id` | *（无）* | 链接的 HTML `id`。 |

短代码的 `template` 选项不受 **客户收据模板** 设置影响：省略此选项时，链接使用已启用的收据模板。

使用自定义文字的下载链接：

```text
[wcpos_receipt link_text="Download your invoice"]
```

在浏览器中打开收据，而不是下载 PDF：

```text
[wcpos_receipt format="html" link_text="View your receipt"]
```

使用指定模板，例如用 A4 发票替代 80mm 收银台收据：

```text
[wcpos_receipt template="123" link_text="Download invoice (PDF)"]
```

在 **POS → 模板** 中编辑模板时，地址栏会显示模板编号(`post=123`)。未发布的模板会被忽略，链接将使用已启用的收据模板。

</details>

## 谁可以打开收据 {#security}

- **有账户的客户** 登录后，可使用 **我的账户 → 订单** 中的 **收据** 按钮。
- 未注册账户的 **访客** 可使用订单确认页面上的收据链接，前提是您已[在该页面添加链接](#shortcode)。

:::warning 收据链接只应分享给对应客户
任何持有收据链接的人都可以在未登录的情况下打开该收据。请像保护订单本身一样保护此链接。
:::

<details>
<summary>收据链接如何受到保护</summary>

每个收据链接都包含订单的私密密钥，与 WooCommerce 放在订单确认页面上的密钥相同。没有正确的密钥就无法打开收据。带有 `order_id` 选项的短代码只向该订单所属的已登录客户显示链接。

</details>

## 遇到问题时 {#goes-wrong}

以下大多数修复操作都在 WP Admin 中完成。如果您是收银员，请将客户看到的提示转告网站管理人员。同时，您可以使用 [WCPOS Pro](../getting-started/pro-license.mdx) 在收银台打印收据或通过电子邮件发送收据：请参阅 **订单** 页面的[重新打印收据](../orders/index.mdx#receipt-reprinting)。

**客户看不到收据按钮。** 请检查是否已开启 **允许客户下载收据**，订单是否处于 **处理中**、**已完成** 或 **已退款** 状态，以及 **POS → 模板** 中是否至少启用了一个收据模板。该按钮仅向已登录客户显示在 **我的账户 → 订单** 中。

**“未配置收据模板。”** PDF 没有可用的模板。请在 **POS → 模板** 中启用一个收据模板。

**“您没有权限查看此收据。”** 链接不完整或复制有误：每个链接都包含对应订单的私密密钥。请重新将客户订单确认页面或 **我的账户** 中的链接发送给客户。

**“无法生成收据 PDF。”** 无法根据模板生成 PDF。请在 **POS → 模板** 中打开该模板并预览。请参阅[自定义收据](./customise.mdx)。

**打开链接时出现“未找到页面”错误。** 在 WP Admin 中，转到 **设置 → 固定链接**，选择 **朴素** 以外的任意选项。收据链接不支持 **朴素** 格式。

## 面向开发人员 {#developers}

<details>
<summary>通过代码添加收据链接</summary>

对于经典主题，可通过用于呈现这两个页面的 WooCommerce 动作输出链接：

```php
// The order confirmation ("thank you") page.
add_action( 'woocommerce_thankyou', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );

// An order's page in My Account.
add_action( 'woocommerce_view_order', function () {
	echo do_shortcode( '[wcpos_receipt]' );
} );
```

短代码可以在这两个页面上找到订单，因此无需 `order_id`。

</details>

<details>
<summary>收据按钮和 PDF 模板的过滤器</summary>

这三个过滤器可覆盖上述设置，用于实现设置无法表达的规则，例如按订单或客户分别设置：

```php
// Force the My Account Receipt button on or off, overriding the setting.
// Its default value is the "Let customers download receipts" setting,
// so you only need it to override that, e.g. show the button for one user role.
add_filter( 'wcpos_storefront_receipt_my_account_button', '__return_true' );

// Change which order statuses show the button (default: processing, completed, refunded).
add_filter( 'wcpos_storefront_receipt_order_statuses', function ( $statuses, $order ) {
	$statuses[] = 'on-hold';
	return $statuses;
}, 10, 2 );

// Use a different template for storefront PDF downloads, overriding the template
// chosen by the setting or the shortcode. Receives and returns the full template array
// (null when none is configured).
add_filter( 'wcpos_storefront_receipt_template', function ( $template, $order ) {
	return \WCPOS\WooCommercePOS\Templates::get_template( 123 );
}, 10, 2 );
```

在 WCPOS 2.0 之前，这些过滤器名为 `woocommerce_pos_storefront_receipt_*`。这些名称仍然有效，但已从 2.0 起弃用，最早将在 2.2 中移除。请参阅[钩子命名](../extensions/index.mdx#hook-naming)。

PDF 地址为 `/wcpos-checkout/wcpos-receipt/{order_id}`，带有 `?key={order_key}&format=pdf` 参数：它与 POS 使用的是同一个受密钥保护的收据地址，`format=pdf` 会使其返回 PDF 而非页面。

</details>
