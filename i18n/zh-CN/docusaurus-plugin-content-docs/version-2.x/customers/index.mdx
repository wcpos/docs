客户界面列出所有可关联到销售的客户，即店铺的 WordPress 用户。使用 [WCPOS Pro](../getting-started/pro-license.mdx)，即可在此添加、编辑和删除客户，无需前往 WP Admin。没有 Pro 时，仍可为销售选择现有客户：请参阅[销售中的客户](#on-a-sale)。

<details>
<summary>未使用 Pro 时的客户功能</summary>

没有 WCPOS Pro 时，列表会模糊显示在升级卡片后方，**添加新客户**和每行的 **›** 均为灰色。**显示选项**仍然可用。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[0, 0], [560, 0], [-40, 0], [-45, 0], [-30, 0], [150, 0]]} alt="未使用 WCPOS Pro 时的客户界面：模糊列表上方有搜索框和灰色的添加新客户按钮，升级到 Pro 卡片提供查看演示和升级到 Pro 选项">

1. **客户** — 从菜单打开此界面。
2. **搜索客户** — 输入部分姓名、电子邮件地址、电话号码或税号。
3. **添加新客户** — 没有 WCPOS Pro 时为灰色。
4. **升级到 Pro** — 列表上方的卡片。
5. **查看演示** — 打开 WCPOS 演示店铺的客户界面。
6. **升级到 Pro** — 打开 wcpos.com/pro。

</JourneyShot>

</details>

## 销售中的客户 {#on-a-sale}

每笔销售最初都会使用店铺的默认客户，即[默认 POS 客户](../settings/wp-admin/general.mdx#default-pos-customer)指定的用户；如果启用了[使用收银员账户](../settings/wp-admin/general.mdx#use-cashier-account)，则使用收银员。点击购物车中的客户姓名即可选择其他人。请参阅[选择客户](../pos/cart/index.mdx#customer-selector)。

:::note 更改客户可能会改变税费
如果店铺[根据客户地址计算税费](../settings/store/tax.mdx#calculate-tax-based-on)，选择或添加其他客户，或在购物车中更改客户地址，都可能改变购物车内现有商品的税费。税前价格保持不变。[免税](../pos/cart/index.mdx#tax-exempt)订单不会重新计算税费。
:::

<JourneyShot manifest={cartManifest} device="tablet" step={2} alt="购物车的选择客户搜索框中输入了 Smith，顶部为访客选项，下方为匹配的客户">

1. **选择客户** — 输入部分姓名、电子邮件地址或电话号码。
2. **访客** — 不关联客户账户的销售。
3. **客户** — 点击即可将其关联到订单，同时带入账单地址和配送地址。

</JourneyShot>

## 查找客户 {#find}

从菜单打开**客户**。在**搜索客户**中输入姓名、电子邮件地址或电话号码。

<details>
<summary>可以搜索哪些内容</summary>

输入的每个词都必须在姓名、电子邮件、用户名、公司、电话或税号字段中找到匹配，顺序不限。因此，`jane acme` 可以找到公司为 Acme 的 Jane。请参阅[搜索匹配范围](../reference/search.mdx#customers)。

</details>

列表最初按姓氏从 A 到 Z 排序。点击**名字**、**电子邮件**或**创建日期**等列标题可按该列排序，再次点击可反转顺序。底部显示已列出的客户数量和客户总数。

## 添加客户 {#add-new-customer}

1. 点击搜索框旁的**添加新客户**，打开空白的**添加客户**表单。
2. 输入客户的**电子邮件**。这是唯一必填的字段。
3. 填写**姓名**、**电话**及其他已知信息：展开下方的**地址和其他可选详情**。
4. 点击**添加客户**。系统会显示包含客户姓名的提示，并关闭表单。

如需在销售过程中添加客户，请使用购物车添加菜单中的**添加新客户**。它会打开相同的表单，并将客户直接关联到订单。请参阅[添加新客户](../pos/cart/index.mdx#new-customer)。

<details>
<summary>地址和其他可选详情</summary>

表单最初显示**姓名**、**电子邮件**、**电话**和**用户名**：

- **用户名** — 只能在添加客户时设置。如果留空，且[根据客户电子邮件自动生成用户名](../settings/wp-admin/general.mdx#automatically-generate-username-from-customer-email)已启用，店铺就会根据电子邮件地址生成用户名；该设置默认启用。

其他字段最初以下方按钮的形式显示，点击相应按钮即可添加该行：

- **公司**、**账单地址**和**配送地址**。在点击**使用其他地址**之前，**配送地址**为**与账单地址相同**。
- **密码** — 留空时由店铺生成。
- **税号** — 包括类型、号码和国家/地区。新增行默认使用账单地址所在国家/地区对应的类型；没有账单地址时，则使用店铺所在国家/地区对应的类型。“格式与所选类型不匹配。”仅为警告，税号仍会保存。
- **自定义字段** — 一组键和值，保存在客户账户中。

客户角色在 WP Admin 中设置，不在此处设置。

</details>

## 编辑客户 {#edit-customer}

1. 打开客户。在触摸屏上，点击客户即可。使用鼠标时，点击该行末尾的 **›**；如果**操作**列已隐藏，则点击该行本身。系统会打开**编辑**对话框，标题中显示客户姓名。
2. 修改字段。这里没有**保存**按钮：停止输入片刻后，更改会自动保存。
3. 确认字段旁出现绿色的**已保存**标记。
4. 完成后点击**关闭**。

<details>
<summary>账户访问与刷新客户详情</summary>

- **密码**在离开该字段时保存，而不是在输入时保存。
- **表单无法接受的值**，例如不含 `@` 的电子邮件地址，会在字段下方显示错误，且不会保存。
- **用户名**已锁定，只能在创建时设置。
- **角色**已锁定，需在 WordPress 中设置。
- **同步**会先保存所有待保存的更改，再从店铺重新获取客户信息。客户信息看起来不是最新时，可使用此功能。
- **JSON** 显示此设备上保存的客户记录，供支持人员询问 POS 中保存了哪些信息时查看。

</details>

## 删除客户 {#delete-customer}

:::warning 删除是永久操作
删除客户会删除店铺中对应的 WordPress 用户。WordPress 用户没有回收站，因此无法撤销。
:::

在**编辑**对话框中点击**删除**。勾选**确认**，然后再次点击**删除**。

只有角色具有删除用户权限的收银员才会看到**删除**。只有管理员可以编辑或删除员工账户，例如店铺经理或其他收银员。请参阅[访问权限](../settings/wp-admin/access.mdx)。

在 WP Admin 中删除的客户，也会在下次同步时从 POS 列表中移除。

## 显示设置 {#display-settings}

点击**显示选项**（**添加新客户**旁的滑块图标），打开**客户设置**。可以打开或关闭某列，也可以拖动其拖动柄（⠿）调整位置。这些设置仅保存在此设备上。

1. **恢复默认设置** — 将各列恢复到初始状态，详见下方的默认列。
2. **关闭** — 关闭面板。每项更改都会立即生效。

## 遇到问题时 {#goes-wrong}

### 按钮变灰 {#greyed}

- **添加新客户变灰** — 店铺需要 WCPOS Pro，或者当前角色没有添加客户的权限。管理员可以在[访问权限](../settings/wp-admin/access.mdx)中授予权限。使用鼠标时，将指针悬停在按钮上即可查看具体原因。
- **› 变灰，无法打开客户** — 当前角色没有编辑客户的权限。管理员可以在[访问权限](../settings/wp-admin/access.mdx)中授予权限。

### 更改未保存 {#not-saving}

- **“保存客户失败”** — 表单会保持打开，并保留已输入的内容。请再次点击**添加客户**。
- **字段旁显示“未保存”** — 该项更改未写入。请重新输入。
- **客户已保存，但未添加到此订单** — 使用购物车中的**添加新客户**时出现。请在购物车中搜索该客户并重新添加。

### 客户缺失或列表显示不正确 {#list-wrong}

- **“无法刷新。此设备上的副本未更改”** — **同步**无法连接到店铺。请检查网络连接，然后再次点击**同步**。
- **找不到预期的客户** — 离线时，搜索只能找到此设备上已有的客户。请参阅[设备与店铺中的数据](../reference/search.mdx#device-and-store)。
- **列表显示不正确** — 长按底部的同步按钮，然后选择**清除并刷新**。此操作会清除设备上的客户列表副本并重新下载，不会更改店铺中的数据。
