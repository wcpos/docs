:::info Pro 功能
使用多个店铺需要 [WCPOS Pro](../getting-started/pro-license.mdx)。未启用 Pro 时，POS 根据 WooCommerce 设置运行一个店铺。
:::

本页介绍如何从空白列表开始创建店铺，直到收银员成功登录。要了解店铺的用途，请先阅读[店铺](./index.mdx)。

## 开始之前 {#before-you-start}

- **已安装 WCPOS Pro，且许可证已激活。** 此时 Pro 会在 WP Admin 的 **POS** 菜单顶部添加**店铺**。
- **收银员能够登录 POS。** 哪些人员拥有 POS 访问权限，由[访问权限](../settings/wp-admin/access.mdx)中的设置决定。店铺只能在此基础上缩小人员范围。
- *（可选）* **标志文件**，PNG 或 JPG 格式。

## 创建店铺 {#create-the-store}

1. 在 WP Admin 中，进入 **POS → 店铺**。
2. 点击**添加新店铺**。
3. 店铺会打开**详细信息**页面。在顶部的**店铺名称**中输入名称。此名称会显示在登录时的店铺选择器中以及 POS 内。
4. 点击右上角的**创建**。

此后店铺会自动保存：页面顶部先显示**正在保存…**，随后显示**已保存**。如果在更改尚未保存完成时离开，浏览器会先询问。如果显示**无法保存。** 请参见[出现问题时](#goes-wrong)。

<Accordion>
  <AccordionItem question="店铺列表显示什么">

每个店铺占一行，显示**店铺**名称、**地址**、**授权用户**（若未在**员工**页面选定任何人，则显示**所有人**）、**收银机**数量，以及用于打开该店铺 POS 的**打开 POS**按钮。

也可以从 **POS → 设置 → 常规**访问店铺。创建店铺后，**店铺**部分会列出各个店铺，显示**地址**和**编辑**按钮，点击**管理店铺**可打开完整列表。

  </AccordionItem>
</Accordion>

## 填写店铺各页面 {#store-pages}

通过左侧菜单打开店铺的各个页面（窄屏上点击**显示店铺菜单**）。每个页面都会随修改自动保存。新建店铺时：

1. 在**详细信息**中输入店铺地址（**地址 1**、**地址 2**、**国家/地区**，然后是城市、省/州和邮政编码），以及**联系信息**：**网站地址**、**电话**、**电子邮箱**。地址会打印在收据上，如果添加了标志，也会一并打印。日后如需重命名店铺，可在此修改**店铺名称**。
2. [设置收银机](#registers)。
3. [指定有权使用店铺的人员](#staff)。

其他页面用于设置此店铺的特有配置。点击菜单顶部的**所有店铺**可返回列表；以后要再次进入某个店铺，在 **POS → 店铺**中点击其名称即可。

<Accordion>
  <AccordionItem question="店铺设置参考：各页面的设置内容">

菜单分为两组：**店铺**（详细信息、营业时间、货币与语言、税费）和**销售**（收据、顾客显示屏、收银机、员工）。添加店铺设置的插件，例如 [ATUM](../extensions/atum.mdx)，会在第三组**扩展**下拥有独立页面。

创建店铺后，部分菜单项会显示标记：**收银机**显示已开班数量（**1 台已开班**），若没有已开班的收银机，则显示总数；当此店铺的销售不计税时（WooCommerce 未启用税费、未设置税率，或没有匹配店铺的税率），**税费**显示**设置**；**员工**显示已勾选的人数。

| 页面 | 设置内容 |
| --- | --- |
| **详细信息** | 打印在收据上的**标志和地址**，以及**联系信息**：**网站地址**、**电话**、**电子邮箱**。可**上传标志**，或在站点已有标志时选择**使用站点标志**。 |
| **营业时间** | 每天的营业时段、**复制到周二至周五**和**备注**。这些信息会打印在收据上。 |
| **货币与语言** | **货币**及其**符号位置**、**语言**（用于 POS 界面和收据），以及**时区**（用于结班提醒和报表日期）。 |
| **税费** | **计税依据**可选择此店铺地址、商店基本地址或顾客的账单地址或配送地址，并显示**适用税率**。下方为**收据上打印的税号**：点击**添加税号**（填写**类型**、**值**、**国家/地区**和可选的**标签**），也可留空，让收据打印站点的[店铺税号](../settings/wp-admin/store-tax-ids.mdx)。 |
| **收据** | **收据文字**（**致谢语**、**退货政策**、**页脚**：纯文本，也允许使用 `<strong>`、 `<em>`、 `<b>`、 `<i>`、 `<br>` 和 `<p>` ），**收据模板**列表（点击**自定义**前为**与站点相同**；之后勾选收银员可打印的模板，第一个勾选项为默认模板，可拖动调整顺序），以及下方的**收据预览**。参见 [按店铺设置模板](../receipts/customise.mdx#per-store-assignments)。 |
| **顾客显示屏** | 销售过程中面向顾客的屏幕使用的**显示模板**。 |
| **收银机** | 店铺的收银台及现金规则。参见[设置收银机](#registers)。 |
| **员工** | 哪些人员有权使用此店铺。参见[指定有权使用店铺的人员](#staff)。 |

税率本身在 **WooCommerce → 设置 → 税费**中设置；**税费**页面仅显示适用的税率。

  </AccordionItem>
</Accordion>

## 设置收银机 {#registers}

在店铺菜单中打开**收银机**。每台收银机对应一个钱箱，有独立的备用金和清点记录。参见[店铺、收银机与设备](./registers-and-devices.mdx)，了解它们之间的关系。

### 收银台 {#tills}

每个店铺都已配有一台收银机。您创建的第一个店铺会接管站点原有的收银机；之后创建的每个店铺都会获得自己的收银机。保存店铺后，**收银台**表格会列出这些收银机；保存前会显示**请先保存店铺，再添加收银机。**

1. 要设置收银员看到的收银机名称，请从其 **⋯** 菜单中选择**重命名**。
2. 输入收银员为此收银台开班时应自动填入的**开班备用金**；更改会在下次开班时生效。未在此设置金额时，POS 会填入上次清点的金额：字段显示的 **200.00** 并未保存。
3. 只有增加钱箱时，才需点击 **+ 添加收银机**。新收银机默认命名为**收银机 2**、**收银机 3**，依此类推，可随时重命名。

<Accordion>
  <AccordionItem question="收银台表格：状态和 ⋯ 菜单">

- **收银机** — POS 中显示的收银机名称。
- **开班备用金** — 收银员在此收银台开始工作时的现金金额。
- **状态** — **开班时间**及开班人员；**正在清点**及清点人员；或**已结班**及上次结班的编号和日期。
- **⋯** — **重命名**、**移动到**其他店铺，或**停用**。收银台仍有未结束的班次时无法停用，请先结班。一台收银机同一时间只能属于一个店铺。

</AccordionItem>
</Accordion>

### 钱箱规则 {#cash-drawer-rules}

如果此店铺要求收银员在开班和结班时清点钱箱，但**每天为收银机开班和结班**尚未启用：

1. 点击**自定义**。
2. 启用**每天为收银机开班和结班**。

这是大多数店铺需要的规则：收银员以备用金开班，并在结班时清点钱箱。关闭此设置时，POS 会直接进入购物车。

这些规则初始使用 **POS → 设置 → 常规**中[收银机](../settings/wp-admin/registers.mdx#one-register)的**站点默认值**；点击**自定义**后，更改仅影响此店铺。

<Accordion>
  <AccordionItem question="可选的钱箱规则：经理审批、结班提醒、恢复站点规则">

启用每日开班与结班后，还可启用两条规则：

- **清点差额超过此金额时请经理审批**，并设置金额（首次启用时为 **5.00**）。清点差额超过该金额时，必须经经理审批才能结班。
- **在此时间提醒收银员结班**，并设置时间（首次启用时为 **17:30**）。超过该时间后，收银机显示**逾期未结班**，购物车为空时，**结账**按钮会变为**收银机结班**。

沿用站点设置时，每条规则都会显示**站点默认值**；更改后，点击**使用站点默认值**可恢复该条规则，点击**重置为站点默认值**可恢复全部三条规则。

</AccordionItem>
</Accordion>

### 报表与结班 {#reports-and-closures}

**结班打印单**和**销售报表**用于选择收银台结班或生成销售报表时打印的内容。点击**自定义**前，两者均为**与站点相同**；点击**使用站点模板**可恢复。

## 指定有权使用店铺的人员 {#staff}

在店铺菜单中打开**员工**。

- **所有拥有 POS 访问权限的人员** — 默认选项，适合只有一个店铺的情况。
- **仅限以下人员** — 勾选每位有权登录此店铺的人员。列表包含所有拥有 POS 访问权限的人，无论权限来自其角色还是单独授予。超过十人时，可用**搜索人员**缩小列表范围。

:::warning 取消勾选最后一人会向所有人开放店铺
取消勾选最后一人后，店铺会切换为**所有拥有 POS 访问权限的人员**，并显示提示。要移除某人的权限，请确保至少还有另一人保持勾选。
:::

在多个店铺工作的收银员，需要在每个店铺中分别勾选。

## 收银员看到什么 {#what-cashiers-see-at-login}

要检查新店铺，请使用该店铺一位收银员的 WordPress 账号登录 POS。登录后提供的选项取决于设备。

**如果登录时显示新店铺：**

1. 在**选择店铺**下选择新店铺。如果这是该收银员唯一有权使用的店铺，系统会自动选中，并在**店铺**下显示。
2. 点击**打开 POS**。

**如果登录时只显示该收银员的另一个店铺**（设备已在该店铺工作）：

1. 打开该店铺的 POS。
2. 点击头像打开收银员面板，选择**切换店铺**，再选择新店铺。参见[选择店铺和收银机](./registers-and-devices.mdx#choosing-a-store-and-a-register)。

无论采用哪种方式，都请检查购物车顶部的收银机栏是否显示新店铺名称。

在新设备上，**选择店铺**会列出收银员有权使用的所有店铺：

<JourneyShot manifest={manifest} device="tablet" step={1} alt="收银员已登录的登录界面：“选择店铺”列出两个店铺及其编号，其中一个已选中，下方是“打开 POS”按钮">

1. **有权使用的店铺** — 此处已选中。名称后面的数字是该店铺在 WP Admin 中的 ID。
2. **另一个店铺** — 该收银员有权使用的第二个店铺，可改选此店铺。
3. **打开 POS** — 选中店铺后即可使用。若只有一个店铺，会自动选中，标题显示**店铺**。

</JourneyShot>

如果收银员无权使用任何店铺，界面会显示**此用户没有可用店铺**：请在某个店铺的**员工**页面勾选此人，或将该店铺设为**所有拥有 POS 访问权限的人员**。

店铺有多台收银机时，收银机栏也会显示收银机名称。收银机需要处理某些事项时，旁边会显示状态。[收银机开班](../pos/register/index.mdx#open)页面展示了该栏在界面中的位置。

<Accordion>
  <AccordionItem question="收银机状态：已结班、正在清点、需要审批、逾期未结班">

各项状态遵循店铺的[钱箱规则](#cash-drawer-rules)：

| 状态 | 显示时机 |
| --- | --- |
| **已结班** | 收银机尚未开班。如果设置了**开班备用金**，现金字段默认填入该金额，否则填入上次清点金额。 |
| **正在清点** | 有人正在清点钱箱，准备结班。 |
| **需要审批** | 清点差额超过您设置的限额，需由经理审批。 |
| **逾期未结班** | 超过设定的结班时间后，收银机仍未结班。 |

已开班且没有待处理事项的收银机不显示状态。

  </AccordionItem>
</Accordion>

每笔销售都会记录在完成收款的店铺名下。

## 按店铺设置价格和税费 {#per-store-pricing}

Pro 可以在共用库存的同时，为商品在某个店铺设置独立的价格或税费。除非店铺有此需求，否则可以跳过。

<Accordion>
  <AccordionItem question="可选：为此店铺设置不同的价格或税费">

1. 在 **WP Admin → 产品**中打开商品。
2. 在**常规**选项卡中，为该店铺勾选**启用 *店铺名称* 专属价格。**
3. 输入**常规价格**，如有需要，也可输入**促销价格**。
4. 更新商品。

该店铺的收银员会使用此价格，其他店铺仍使用 WooCommerce 的常规价格。对于处于不同税区的店铺，**启用 *店铺名称* 专属税费。** 可同样单独设置**税务状态**和**税类**。对于可变商品，这些复选框位于**变体**下的各个变体中；变体的税费复选框仅用于设置**税类**。

:::tip 按地点管理库存
各店铺的独立价格共用同一份库存数量。如需按地点分别统计库存，请参见 [ATUM Multi-Inventory](../extensions/atum.mdx)。使用 ATUM 时，如果店铺的**价格来源**为 **ATUM**，且 ATUM 为该商品设置了价格，就会改用该地点的价格；参见[选择价格来源](../extensions/atum.mdx#pricing-source)。
:::

</AccordionItem>
</Accordion>

## 出现问题时 {#goes-wrong}

页面顶部显示**无法保存。** 及原因，表示站点未保存此次更改。点击提示中的**重试**，或重新加载页面并检查已保存的内容。

**请先保存店铺，再添加收银机。** 请先点击**创建**；店铺创建后，**收银台**表格才会出现。

**收银机无法停用。** 它有尚未结束或正在清点的班次。请在 POS 中清点并结班，然后再**停用**。

登录时显示**此用户没有可用店铺**。该收银员不在任何店铺的**员工**名单中。请勾选此人，或将一个店铺设为**所有拥有 POS 访问权限的人员**。

**没有店铺菜单。** Pro 尚未激活。请在 **POS → 设置 → 许可证**中检查许可证；参见[安装 WCPOS Pro](../getting-started/pro-license.mdx)。

## 特殊情况 {#edge-cases}

<Accordion>
  <AccordionItem question="添加店铺后，旧订单会怎样？">

不会受到影响。销售在收款时就已记入所属店铺，因此新店铺不会接管旧订单。要将某个订单移到其他店铺，请在 **WooCommerce → 订单**中打开它，并更改 **POS 店铺**。

  </AccordionItem>

  <AccordionItem question="如何删除店铺？">

点击店铺任一页面右上角的**将店铺移至回收站**（会先要求确认），或列表中的**移至回收站**。移入回收站后，店铺不再出现在店铺选择器中，但其订单仍显示原有名称、地址和标志。点击**还原**可恢复店铺及其设置。

在回收站中点击**永久删除**会彻底删除店铺；如果店铺的任一收银机仍在开班或清点中，则无法执行此操作。删除后，其订单将显示**店铺 #** 及店铺 ID。

  </AccordionItem>

  <AccordionItem question="店铺可以使用不同的货币吗？">

可以，在**货币与语言**中设置。该店铺的价格、总计和收据都会使用所选货币。此设置只改变金额的显示方式，不换算金额：付款方式必须支持该货币，汇率需自行处理。

  </AccordionItem>

  <AccordionItem question="停用 Pro 后会怎样？">

站点会恢复为仅使用一台收银机。参见[停用 Pro 后](../settings/wp-admin/registers.mdx#if-pro-is-deactivated)。

  </AccordionItem>
</Accordion>
