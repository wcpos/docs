:::info Pro 功能
**优惠券**页面需要 [WCPOS Pro](/getting-started/pro-license)。免费版插件也能使用店铺已有的优惠券：参阅[应用优惠券](./applying-coupons.mdx)。
:::

**优惠券**页面在 POS 中列出店铺的 WooCommerce 优惠券。您可以查找优惠券、为促销活动创建优惠券、修改金额或到期日期，也可以移除旧优惠券。每次更改都会同步到店铺，因此 **WP Admin › 营销 › 优惠券**中的优惠券与网站上的保持一致，其他收银设备也会在同步时获取这些更改。

点击左侧菜单中的**优惠券**图标即可打开。在手机上，请先打开菜单。

最新的优惠券显示在顶部。向下滚动可加载更多。

列表中的更改会立即同步到店铺。这里没有保存按钮：若要撤销更改，请将其改回原值。

### 筛选列表 {#filters}

点击筛选器并从列表中选择。筛选器随后会显示所选条件，点击 **✕** 可移除。启用两个或更多筛选条件时，点击**全部清除**可将其全部移除。

<JourneyShot manifest={manifest} device="tablet" step={5} offsets={[[0, 0], [-14, 0], [-14, 0], [-14, 0]]} maxWidth={400} alt="状态、折扣类型和到期时间筛选器，其中折扣类型已展开，列出百分比折扣、固定购物车折扣和固定产品折扣">

1. **折扣类型** — 已展开的筛选器。
2. **百分比折扣** — 按百分比减免商品金额。
3. **固定购物车折扣** — 从整个订单中减免固定金额。
4. **固定产品折扣** — 从每件符合条件的商品中减免固定金额。

## 创建优惠券 {#creating-coupons}

1. 点击优惠券页面顶部的 **+**。
2. 输入代码，或点击**生成**。
3. 选择折扣类型并输入金额。
4. 选择到期时间。
5. 若要立即使用优惠券，请将**状态**保留为**选择状态**：优惠券会保存为**有效**，在列表的**状态**筛选器中称为**已发布**。若暂不启用，请选择**草稿**或**待审核**。
6. 添加所需的限制，然后点击**添加优惠券**。

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[-36, 0], [-32, 0], [-20, 0], [-20, 0], [36, 30], [-30, 0], [440, 0], [12, -30]]} alt="优惠券列表上方的添加优惠券对话框：已生成的代码、生成按钮、选中的百分比折扣及 10 的百分比值、选中的 1 周到期选项及其日期、一次性使用开关、用于添加最低消费等限制的按钮，以及添加优惠券按钮">

1. **代码** — 顾客在收银时提供的代码。不区分大小写。
2. **生成** — 生成类似 **POS-UA43** 的代码，避开容易混淆的字符（0 和 O，以及 1、I 和 L）。
3. **折扣** — **百分比**、**订单减免金额**或**商品减免金额**。参阅[优惠券类型](#coupon-types)。
4. **金额** — 百分比，或以店铺货币计价的金额。
5. **到期时间** — **永不到期**、**当天结束**、**1 周**、**1 个月**或**选择日期**。**当天结束**、**1 周**和**1 个月**均以店铺时区中对应日期的结束时间为准，下方会显示日期。
6. **一次性使用** — 优惠券使用一次后即失效。
7. **最低消费**及其他按钮 — 为优惠券添加限制或设置。参阅[各项设置的作用](#fields)。
8. **添加优惠券** — 将优惠券保存到店铺。**取消**会关闭对话框且不保存。

</JourneyShot>

新优惠券会立即出现在此列表和购物车的优惠券列表中。

若要在销售过程中创建优惠券并立即应用到订单，请使用购物车中的**新建优惠券**：参阅[折扣](../pos/cart/discounts.mdx#new-coupon)。

### 优惠券类型 {#coupon-types}

POS 和 WooCommerce 对这三种类型的命名不同：

- **百分比**（WooCommerce：*百分比折扣*）— 按百分比减免购物车中的商品金额。`10` 表示减免 10%。
- **订单减免金额**（WooCommerce：*固定购物车折扣*）— 从整个订单中减免固定金额。`5.00` 表示订单减免 $5。
- **商品减免金额**（WooCommerce：*固定产品折扣*）— 从每件符合条件的商品中减免固定金额。`2.00` 表示每件 T 恤减免 $2。

### 各项设置的作用 {#fields}

表单始终显示**状态**。下方的每个按钮可添加一项设置，包括消费和使用次数限制、**内部备注**等。每项已添加的设置都有一个**移除**按钮，可将其移除。展开下方列表了解各项设置的作用。

<details>
<summary>优惠券设置与限制</summary>

| 设置 | 作用 |
|---|---|
| **状态** | **有效**、**草稿**或**待审核**。**有效**在 WooCommerce 和列表的**状态**列中对应**已发布**。草稿或待审核的优惠券显示为**无效**，并会在收银设备下次获取优惠券时从列表中消失。除非另行选择，否则新优惠券默认为有效。 |
| **最低消费** | 订单金额必须达到此值才能应用优惠券。 |
| **最高消费** | 订单金额超过此值时无法应用优惠券。 |
| **总使用次数** | 所有顾客合计可使用此优惠券的次数。启用**一次性使用**时不提供此设置。 |
| **每位顾客使用次数** | 每位顾客可使用此优惠券的次数。 |
| **最多优惠商品数** | 可享受此优惠券减免的商品数量。仅适用于**百分比**和**商品减免金额**。 |
| **不可叠加使用** | 若订单已使用其他优惠券，收银设备会拒绝此优惠券。 |
| **同时提供免运费** | 订单可使用需要优惠券才能启用的免运费配送方式。 |
| **内部备注** | WooCommerce 中的优惠券描述。购物车的优惠券列表会将其显示在代码下方，从店铺打印的收据会用它替代代码，因此顾客可以看到。请勿填写私密信息。 |
| **自定义字段** | 保存在优惠券上的自定义键值对。 |

</details>

POS 表单中不包含某些 WooCommerce 设置：**产品**和**排除产品**、**产品分类**和**排除分类**、**排除促销商品**以及**允许的电子邮件**（支持 `*` 通配符，例如 `*@yourcompany.com` 可限定为仅员工使用）。请在 **WP Admin › 营销 › 优惠券**中设置。这些规则在收银时仍然生效；参阅[收银设备拒绝优惠券时](./applying-coupons.mdx#refused)。**排除促销商品**还会跳过您在收银时降低了价格的商品：参阅 [POS 价格更改如何与优惠券配合](../pos/cart/discounts.mdx#how-pos-price-changes-interact-with-coupons)，开发者还可参阅 [POS 折扣参考](../reference/pos-discounts.mdx)。

:::warning 没有保存按钮
每次更改都会立即同步到店铺。**关闭**不会撤销任何更改：若要恢复，请再次修改相应字段。
:::

点击优惠券所在行末尾的 **>**。在手机上，点击优惠券即可。

1. **代码** — 在此修改，或点击**生成**获取新代码。
2. **生成** — 生成新代码。旧代码随即失效。
3. **折扣** — 折扣类型。
4. **金额** — 折扣金额。
5. **到期时间** — 优惠券失效的日期。
6. **一次性使用** — 此处已开启，因此列表中的**使用次数**显示为 **0 / 1**。

10. **同步** — 从店铺重新获取此优惠券，以获取此后在 WP Admin 中所做的更改。

## 删除优惠券 {#delete}

有权删除优惠券的员工可在优惠券对话框底部看到**删除**。

1. 打开优惠券并点击**删除**。
2. 勾选**确认**，然后点击**删除**。

对话框会提示：**删除的优惠券将放入服务器上的回收站。** 优惠券会进入 WooCommerce 的**回收站**，无法再使用。若要恢复，请打开 **WP Admin › 营销 › 优惠券**，选择**回收站**并将其恢复。若要停用优惠券而不删除，可改为设置到期日期：该日期过后，收银设备会拒绝使用它。

## 哪些员工可以创建和修改优惠券 {#permissions}

创建、修改和删除优惠券分别需要相应权限，在 **WP Admin › 收银 › 设置 › 访问权限**中设置：

- **创建和编辑优惠券** — 收银员默认拥有此权限。没有此权限时，**+** 会呈灰色，且无法修改列表。
- **删除优惠券** — 收银员默认没有此权限。没有此权限时，优惠券对话框中不会显示**删除**。

将鼠标悬停在灰色的 **+** 上可查看原因。若要修改角色，请参阅[访问 POS](../settings/wp-admin/access.mdx)。

## 销售时使用优惠券 {#apply}

在购物车中点击 **+** 并选择**添加折扣**，然后切换到**优惠券**，选择优惠券并点击**应用**。免费版插件也支持此操作。参阅[应用优惠券](./applying-coupons.mdx)。

## 遇到问题时 {#goes-wrong}

**在 WP Admin 中创建的优惠券未出现在列表中。** 点击列表底部**已显示 … 张中的 … 张**旁边的箭头以获取最新数据。长按可执行**清除并刷新**，清空此设备上的列表副本并重新获取全部内容。

**+ 呈灰色。** 免费版插件会显示**升级到 Pro**。否则，说明您的角色没有创建优惠券的权限：参阅[哪些员工可以创建和修改优惠券](#permissions)。

**更改后又恢复原值。** 店铺拒绝了该更改。POS 会恢复店铺中的值，并记录**已撤销店铺拒绝的更改**。店铺拒绝的新优惠券（例如代码已存在）会列在**店铺健康状况**中。

**优惠券显示为无效。** 优惠券已到期，或其状态不是**有效**。打开优惠券并修改**到期时间**或**状态**。

**收银设备拒绝优惠券。** 参阅[收银设备拒绝优惠券时](./applying-coupons.mdx#refused)。
