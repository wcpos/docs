有些产品只适合在收银端销售，有些则只在线上销售。开启 **启用仅限 POS 的产品** 后，每个产品都会获得 **POS 可见性** 设置，提供三个选项：

| POS 可见性 | 您的网站 | POS |
|------------|--------------|-----|
| **POS 和在线**（所有产品的初始设置） | 显示 | 显示 |
| **仅限 POS** | 隐藏 | 显示 |
| **仅在线** | 显示 | 隐藏 |

:::note 在 WP Admin 中设置
POS 可见性在 WP Admin 中设置。POS 仅遵循此设置，收银端没有相应的设置项。在收银端找不到产品？参见[出现问题时](#troubleshooting)。
:::

## 启用功能 {#enabling-the-feature}

在 WP Admin 中，前往 **POS > 设置 > 常规**。在 **产品** 下开启 **启用仅限 POS 的产品**。切换后会立即保存。此时每个产品都有 **POS 可见性**：未设置过的产品为 **POS 和在线**；如果您以前启用过此功能并为某个产品设置了选项，该产品会沿用之前保存的选择。

如果所有产品都在两处销售，请保持此功能关闭。关闭时，POS 可见性不会隐藏任何产品；WooCommerce 自身的可见性设置仍然适用。

:::warning
再次关闭此功能或停用 WCPOS 后，只要 WooCommerce 的可见性设置允许，仅限 POS 的产品就会重新出现在网站上。参见[关闭功能](#switch-off)。
:::

## 设置产品可见性 {#setting-product-visibility}

### 单个产品 {#individual-products}

1. 在 WP Admin 中，前往 **产品** 并打开要设置的产品。
2. 在 **发布** 框中，点击 **POS 可见性** 旁的 **编辑**。
3. 选择 **POS 和在线**、**仅限 POS** 或 **仅在线**，然后点击 **确定**。
4. 点击 **更新**。

在产品列表中，对产品使用 **快速编辑** 也可以设置相同的 **POS 可见性** 选项。

### 批量设置产品 {#bulk-editing}

1. 在 WP Admin 中，前往 **产品** 并勾选要设置的产品。
2. 从 **批量操作** 中选择 **编辑**，然后点击 **应用**。
3. 在 **POS 可见性** 中选择一个选项。如果保留 **— 不更改 —**，各产品会保持自己的设置。
4. 点击 **更新**。

### 变体 {#variable-products}

每个变体都有独立的 **POS 可见性**，位于 **变体** 下该变体的面板内。完成后点击 **保存更改**。您可以在线销售所有颜色，只在收银端销售部分颜色，或将某个尺码留作店内专售。要更改整个可变产品的销售渠道，请设置产品本身的 **POS 可见性**：**仅在线** 的产品不会在收银端显示产品卡片，**仅限 POS** 的产品及其所有变体都会从网店中隐藏。

### 再次查找这些产品 {#find-them}

产品列表的表格上方会在 **已发布** 旁新增两个视图：**仅限 POS** 和 **仅在线**，各自带有产品数量。点击其中一个即可只列出对应的产品。

## 在 POS 中 {#how-it-affects-the-pos}

**仅在线** 的产品完全不会出现在收银端。它不会显示在产品面板中，搜索也找不到，扫描其条形码会提示 **未找到条形码**。**仅限 POS** 和 **POS 和在线** 的产品照常销售。

修改产品可见性后，POS 会在下次向店铺检查更改时获取新设置：仅在线的产品会消失，改回原设置后又会出现。要立即检查，请点击产品数量旁的箭头。

1. **搜索产品** — 也会向店铺查询，但不会返回仅在线的产品。参见[搜索与筛选](../pos/product-panel/search-filtering.mdx#how-search-works)。
2. **设置** — 包含 **显示缺货产品**。参见[显示设置](../pos/product-panel/display-settings.mdx#show-out-of-stock-products)。
3. **有货** — 隐藏缺货产品。在判断产品是否缺失前，请先点击此筛选器的叉号。参见[库存状态](../pos/product-panel/search-filtering.mdx#stock-status)。

## 在您的网站上 {#where-pos-only-products-stay-visible}

**仅限 POS** 的产品对顾客隐藏：

- 它不会列出在网店、分类页面、搜索结果、相关产品、产品区块、订阅源或站点地图中。
- 它无法加入购物车，也无法在线购买。与 WooCommerce 自身的 **隐藏** 设置一样，直接链接仍能打开产品页面，但顾客无法在该页面将其加入购物车。
- **仅限 POS** 的变体不会出现在产品页面的选项中。该产品的其他变体仍可在线销售。

<details>
<summary>目录可见性，以及仅限 POS 的产品仍会显示在哪里</summary>

WCPOS 会将仅限 POS 产品的 WooCommerce **目录可见性** 设为 **隐藏**，从而隐藏该产品。产品处于仅限 POS 状态时，发布框中的 **目录可见性** 会锁定为 **隐藏**，并显示说明：*仅限 POS 的产品不会出现在在线目录或搜索结果中。* 将其改回 **POS 和在线** 或 **仅在线** 后，WCPOS 会恢复之前的目录可见性；在点击 **更新** 前，发布框会告知将恢复为何种设置。此前始终可见的产品会恢复为 **商店和搜索结果**。如需使用其他目录可见性，请在更新后修改。WooCommerce 中的变体没有独立的目录可见性，因此不会锁定变体的任何设置。

隐藏规则只针对顾客。仅限 POS 的产品在店铺管理相关界面中仍然可见：

- **WP Admin**，包括产品列表和产品编辑器。
- **WooCommerce 分析**，因此按仅限 POS 产品所属分类筛选的报表会显示这些产品的销售情况。
- **POS** 本身。

</details>

## 关闭功能 {#switch-off}

关闭 **启用仅限 POS 的产品** 后，POS 可见性不再隐藏任何产品；WooCommerce 自身的可见性设置仍然适用。仅在线的产品会在 POS 下次检查更改时重新出现，仅限 POS 的产品会恢复之前的目录可见性：您自行隐藏的产品仍会保持隐藏。每个产品的选择都会保留，因此再次启用时会沿用已保存的选择，并再次隐藏相同的产品。

停用 WCPOS 也会将所有仅限 POS 产品的目录可见性恢复为之前的设置，因此它们可能重新出现在网站上。

## 适用场景 {#when-to-use-this-feature}

- **柜台销售的礼品卡** — 在收银端激活的实体卡。将其设为 **仅限 POS**。
- **在线预订** — 尚未到货、供顾客在线预订的产品。将其设为 **仅在线**，以免占据收银端的产品列表。
- **同一店铺同时经营批发和零售** — 面向批发客户的专供产品设为 **仅在线**，店内专售产品设为 **仅限 POS**，其余产品设为 **POS 和在线**。
- **下载产品和线上专享优惠** — 不在柜台销售的数字产品和线上专享优惠产品。将其设为 **仅在线**。
- **店内特惠** — 仅在收银端销售的促销商品。将其设为 **仅限 POS**。

## 出现问题时 {#troubleshooting}

**仅在线的产品仍显示在 POS 中。** 点击产品数量旁的箭头以检查更改。如果仍然显示，请长按箭头并选择 **清除并刷新**。

**POS 中缺少某个产品。** 清空搜索并检查筛选栏，包括 **有货** 筛选器。然后在 WP Admin 中打开产品并检查其 **POS 可见性**；如果是变体，还要检查产品本身的设置。

**产品在一台设备上显示，在另一台上却不显示。** 每台设备都会保留各自的搜索和筛选条件，并且仅在联网时获取更改：参见[产品同步](./sync.mdx#one-device)。

**仅限 POS 的产品仍出现在网店、分类或搜索结果中。** 通过直接链接打开产品页面是正常现象；此处针对的是顾客仍能在这些位置找到产品的情况。

1. 打开产品，查看发布框中的 **目录可见性**。仅限 POS 的产品应显示为 **隐藏**。
2. 如果显示为其他值，点击一次 **更新**，WCPOS 会重新设为 **隐藏**。如果仍未生效，则是某个插件或自定义代码正在修改此设置：参见[开发者指南](#developers)。
3. 如果显示为 **隐藏**，很可能是页面被缓存了。请清除缓存插件或 CDN 的缓存。

**产品没有 POS 可见性设置。** **启用仅限 POS 的产品** 处于关闭状态。请在 **POS > 设置 > 常规** 中开启。

## 开发者指南 {#developers}

<details>
<summary>仅限 POS 产品的过滤器</summary>

仅限 POS 的产品会从区块购物车和结账所使用的 WooCommerce Store API，以及 WooCommerce REST API 的产品和变体列表（`/wc/v1` 至 `/wc/v3`）中排除。`wp wc product list` 等 WP-CLI 命令仍能获取这些产品。

**`wcpos_hide_pos_only_products`** 决定产品查询是否排除仅限 POS 的产品。它接收默认判断结果和即将运行的 `WP_Query`：前台为 true，WP Admin、WP-CLI、WooCommerce 分析和 POS 中为 false。返回 `false` 可让您自己的使用场景获取仅限 POS 的产品。

```php
add_filter( 'wcpos_hide_pos_only_products', function ( $hide, $query ) {
    if ( defined( 'MY_PLUGIN_EXPORTING' ) ) {
        return false;
    }
    return $hide;
}, 10, 2 );
```

**`wcpos_pos_only_catalog_visibility`** 设置 WCPOS 为仅限 POS 产品写入的目录可见性。它接收 `hidden` 和产品对象。返回 WooCommerce 的某个目录可见性键（`visible`、`catalog`、`search` 或 `hidden`）可改用该值；返回 `null` 则由您自行管理产品的目录可见性。它只改变 WCPOS 写入 **目录可见性** 的值：上述前台规则仍然适用，因此如果希望仅限 POS 的产品出现在某些线上位置，请配合 `wcpos_hide_pos_only_products` 使用。

```php
add_filter( 'wcpos_pos_only_catalog_visibility', function ( $visibility, $product ) {
    if ( has_term( 'club-stock', 'product_cat', $product->get_id() ) ) {
        return null; // I manage catalog visibility for these myself.
    }
    return $visibility;
}, 10, 2 );
```

**`wcpos_default_product_visibility`** 设置编辑器中新产品的初始 **POS 可见性**。它接收 `''`（**POS 和在线**）和文章对象；返回 `pos_only` 或 `online_only` 可让新产品默认使用相应设置。

在 WCPOS 2.0 之前，这些过滤器分别名为 `woocommerce_pos_hide_pos_only_products`、`woocommerce_pos_pos_only_catalog_visibility` 和 `woocommerce_pos_default_product_visibility`。旧名称仍然有效，但自 2.0 起已弃用，最早将在 2.2 中移除。参见[钩子命名](../extensions/index.mdx#hook-naming)。

</details>
