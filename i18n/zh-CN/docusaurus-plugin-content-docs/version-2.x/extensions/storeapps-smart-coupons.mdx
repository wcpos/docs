**WCPOS StoreApps Smart Coupons** 扩展可让 StoreApps 的 [Smart Coupons](https://woocommerce.com/products/smart-coupons/) 店铺储值优惠券（例如礼品卡）抵扣 POS 销售金额。使用 WCPOS Pro 时，您可以在结账的付款页面接受礼品卡付款，系统会扣除正确金额，并在收据上显示剩余余额。

:::warning 添加折扣无法使用店铺储值
在购物车的 **添加折扣** 中使用礼品卡会显示 **未找到优惠券**。请改为在结账的 **传统** 选项卡中使用：参阅[在收银台接受礼品卡付款](#at-the-till)。
:::

## 在收银台接受礼品卡付款 {#at-the-till}

开始之前，管理员应已[安装此扩展](#install)，并启用 StoreApps 的 Smart Coupons。结账的[传统选项卡](../pos/checkout/legacy-tab.mdx)中还需有可用的付款方式：此选项卡会打开店铺自己的付款页面，其中包含优惠券输入框。

1. 将商品加入购物车，点击 **结账**，然后打开 **传统** 选项卡。店铺的付款页面会在结账界面中打开。
2. 在 **优惠券代码** 中输入礼品卡代码，然后点击 **使用优惠券**。订单总额会减去礼品卡抵扣的金额。
3. 选择客户支付剩余款项所用的付款方式，在该页面完成收款，然后点击 **处理付款**。
4. 在收据的优惠券折扣行中查看 **店铺储值余额**，如[收据显示的内容](#receipt)所示。如果未显示，请参阅[故障排查](#goes-wrong)。

如果 **传统** 选项卡中没有付款方式，就没有可接受礼品卡付款的页面。请照常收款，并让客户保留礼品卡供下次购物使用：卡内金额尚未扣除。

## 收据显示的内容 {#receipt}

优惠券折扣行的末尾会显示生成收据时的卡内余额。在 **标准收据** 上，描述为 **礼品卡** 的店铺储值优惠券会打印为：

> 折扣 · 礼品卡 — 店铺储值余额：$61.50

结账时生成的收据显示的是本次销售完成后的余额。无需修改收据模板。即使优惠券没有描述，该行末尾仍会显示 **店铺储值余额**。如果希望在该行将 **折扣** 改为 **礼品卡**，请参阅[开发者指南](#developers)。

## 功能说明 {#what-it-does}

StoreApps 会维护在线订单的礼品卡余额，但单独使用时无法处理在 POS 中支付的订单。当 POS 订单包含店铺储值优惠券时，此扩展会：

- **仅扣除实际使用的金额。** 扩展会记录订单使用了多少礼品卡金额，让 StoreApps 扣除相应金额，并将余款保留在卡内。
- **在订单付款时扣减余额。** 不会在应用优惠券时扣款，也不会重复扣款。
- **不再处理已移除的优惠券。** 如果在付款前移除了优惠券，就不会扣除其金额。
- **在订单中添加备注。** 请参阅[订单备注](#order-note)。
- **在收据上打印余额。** 请参阅[收据显示的内容](#receipt)。

如果停用了 StoreApps Smart Coupons，此扩展不会执行任何操作。

## 安装扩展 {#install}

管理员只需在 **WP Admin** 中安装一次：使用 WCPOS Pro 时，通过 **POS → 设置 → 扩展** 安装；使用免费插件时，上传扩展的发布版本即可。

<details>
<summary>使用 WCPOS Pro 或免费插件的安装步骤</summary>

:::note 开始之前
您需要使用管理员账号登录 **WP Admin**，且网站上已启用 StoreApps 的 Smart Coupons（在 WooCommerce.com 销售）。此扩展仅适用于该插件，不适用于其他名称中含有“Smart Coupons”的插件。
:::

### 使用 WCPOS Pro {#install-pro}

1. 在 **WP Admin** 中，前往 **POS → 设置 → 扩展**。
2. 找到 **WCPOS StoreApps Smart Coupons**，然后点击 **安装**。
3. 点击 **启用**。

有关更新和自动更新，请参阅[安装扩展](./index.mdx#installing-an-extension)。

### 使用免费插件 {#install-free}

扩展界面会列出此扩展，但其中的按钮需要 Pro。您可以改用以下方式：

1. 从扩展的[最新发布版本](https://github.com/wcpos/wcpos-storeapps-smart-coupons/releases/latest)下载 `wcpos-storeapps-smart-coupons.zip`。
2. 在 **WP Admin** 中，前往 **插件 → 安装插件**，然后点击 **上传插件**。
3. 选择下载的文件，然后点击 **立即安装**。
4. 点击 **启用插件**。

</details>

之后无需其他设置。照常在 WooCommerce 中创建店铺储值优惠券或礼品卡即可。

## 订单备注 {#order-note}

订单付款后，扩展会添加一条私密备注。员工可在 **WP Admin → WooCommerce → 订单** 中打开订单查看：

> 已为 WCPOS 记录 StoreApps Smart Coupons 店铺储值使用情况：优惠券 store100 使用了 $38.50。当前余额：$61.50。

通过此备注可核对使用了哪张卡、抵扣了多少金额，以及剩余多少余额。每个订单只添加一次备注。

## 退款和取消 {#refunds}

此扩展不会返还储值金额。当您退款或取消部分使用店铺储值支付的订单时，余额如何处理由 StoreApps 决定。操作后请在 **WP Admin → 营销 → 优惠券** 中检查优惠券金额。如果与客户应有的金额不符，请联系店铺管理员，他们可以在那里修改优惠券金额。

## 故障排查 {#goes-wrong}

通过 **添加折扣** 应用礼品卡时，显示 **未找到优惠券**。在 WCPOS 2.0 中，添加折扣仅支持百分比折扣、购物车固定金额折扣和商品固定金额折扣优惠券，因此无论是否安装此扩展，店铺储值优惠券都会在这里显示 **未找到优惠券**。请改用[传统选项卡中的付款页面](#at-the-till)。

**销售后余额未减少。** 检查 **插件** 中的 **Smart Coupons** 和 **WCPOS StoreApps Smart Coupons** 是否都已启用。扣款发生在订单付款时，而非应用优惠券时。如果订单没有店铺储值备注，说明此扩展未执行扣款。

**收据上没有余额。** 收银台离线时打印的收据不含余额。恢复联网后，请重新打印。如果仍未显示，说明您的收据模板没有打印折扣行的标签；请参阅[收据数据](../receipts/receipt-data.mdx#discounts)。

<details>
<summary>开发者指南：存储的数据和钩子</summary>

<Anchor id="developers" />

此扩展不会添加 WCPOS 优惠券字段，而是通过 WooCommerce 订单元数据和 StoreApps 自身的余额逻辑工作。它仅适用于 POS 订单（`wcpos_is_pos_order()`：`created_via` 为 `woocommerce-pos`），且仅处理类型为 `smart_coupon` 的优惠券。

- **使用情况。** 在 `woocommerce_order_after_calculate_totals` 上，如果 StoreApps 尚未写入，扩展会写入 StoreApps 的 `smart_coupons_contribution` 订单元数据（优惠券代码 → 使用金额）和 `wc_sc_environment`。对于未付款订单中已移除的优惠券，扩展会删除对应条目。
- **付款页面的优惠券输入框。** 该表单通过普通前端 POST 请求调用 `WC_Order::apply_coupon()`，StoreApps 不会将其视为订单上下文。当包含 `smart_coupon` 行的未付款 POS 订单在 REST 请求之外重新计算时，扩展会将上下文标记为 REST，让 StoreApps 自身的订单折扣逻辑得以运行。
- **扣款。** POS 订单从 `pos-open` 或 `pos-partial` 状态进入已付款状态，而 StoreApps 仅在订单从 `pending` 或 `failed` 转变时扣款。当 `woocommerce_order_status_changed` 表示订单从其他任何状态转为已付款状态或 `on-hold` 时，扩展会调用 StoreApps 的 `WC_SC_Coupon_Process::update_smart_coupon_balance()`；该方法会标记每个优惠券行，以免重复扣款。
- **订单备注。** 在状态转为 `processing`、`completed` 或 `on-hold` 时添加，每个订单仅添加一次(`_wcpos_storeapps_smart_coupons_audit_note_added`)。
- **收据。** 渲染 WCPOS 收据时，扩展会过滤 `woocommerce_coupon_get_description`；在收据数据过滤器中，它会为 `discounts` 中的店铺储值行添加 `gift_card: true`，并在其 `label` 后附加余额。模板随后即可打印：

```text
{{#discounts}}{{#gift_card}}Gift Card{{/gift_card}}{{^gift_card}}{{i18n.discount}}{{/gift_card}} · {{label}}{{/discounts}}
```

- **钩子名称。** 版本 0.2.3 仍挂载到 2.0 之前的名称：`woocommerce_pos_receipt_data`、`woocommerce_pos_before_template_render` 和 `woocommerce_pos_after_template_render`。WCPOS 2.0 在触发对应的 `wcpos_` 名称后，仍会触发这些旧钩子；开启 `WP_DEBUG` 时，WordPress 会为每个旧钩子记录弃用通知。请参阅[钩子命名](./index.mdx#hook-naming)。

源代码：[github.com/wcpos/wcpos-storeapps-smart-coupons](https://github.com/wcpos/wcpos-storeapps-smart-coupons)。

</details>

收银台可在传统选项卡的付款页面接受礼品卡付款，您可以通过 **POS → 设置 → 扩展** 安装和更新此扩展。没有 Pro 时，请按上述方法从发布版本手动安装。
