**WP 后台：** 在 `WP Admin → POS → Settings → Extensions` 中安装，并在 `WP Admin → POS → Stores` 中为各店铺设置。

WPML 会将产品的每种译文保存为独立产品。如果不做处理，POS 会将它们全部显示出来：搜索一块手表，英语、法语和德语版本会并排出现。免费的 **WCPOS WPML** 扩展让 POS 只显示一种语言，从而使每个产品仅出现一次。

收银员无需进行任何设置：第一节介绍他们会看到的变化。本页其余内容面向店铺管理员。

## 收银员会看到什么 {#what-the-cashier-sees}

产品搜索、产品网格及可变产品的选项都只显示店铺所用的一种语言，每件在售商品只对应一个产品。收银员的销售操作不变：照常添加到购物车、收款和打印收据。请参阅[结账](../pos/checkout/index.mdx)。

## 安装扩展 {#install}

:::note 开始之前
您需要在站点上配置好 [WPML](https://wpml.org/) 并设置默认语言，还需要使用管理员账号登录 **WP Admin**。
:::

管理员只需在 **WP Admin** 中安装一次。除非您为店铺选择其他语言，否则产品会使用 WPML 的**默认语言**。启用扩展后，请按照下方[检查是否生效](#check)中的步骤操作。

### 使用 WCPOS Pro {#install-pro}

1. 前往 **POS → 设置 → 扩展**。
2. 找到 **WCPOS WPML**，然后点击**安装**。安装与启用会一次完成，卡片会显示**已启用**。如果显示**未启用**，请点击**启用**。

有关更新和自动更新的信息，请参阅[安装扩展](./index.mdx#installing-an-extension)。

### 使用免费插件 {#install-free}

扩展页面会列出此扩展，但其按钮需要 Pro 才能使用。您可以按以下步骤安装：

1. 从扩展的[最新版本](https://github.com/wcpos/wcpos-wpml/releases/latest)下载 `wcpos-wpml.zip`。
2. 前往**插件 → 安装插件**，然后点击**上传插件**。
3. 选择下载的文件，然后点击**现在安装**。
4. 点击**启用插件**。

### 检查是否生效 {#check}

1. 打开 POS。在产品面板底部的**显示 …，共 …** 旁，长按 [同步按钮](../pos/product-panel/display-settings.mdx#footer) （<Icon name="arrow-rotate-right" />），然后选择**清除并刷新**。
2. 搜索一个有译文的产品。它应仅显示一次，使用 WPML 的默认语言；如果您按下文为店铺选择了语言，则使用店铺语言。

如果它仍然显示两次或三次，请参阅[出现问题时](#goes-wrong)。

## 选择店铺语言 {#store-language}

使用 WCPOS Pro 时，每个[店铺](../stores/index.mdx)都可以显示自己的语言：同一站点上的法语店铺和英语店铺，分别只能看到各自的译文。

:::note 语言页面需要满足三个条件
需要 WCPOS Pro、已启用的 **WCPOS WPML** 扩展，以及已启用且至少开启了一种语言的 WPML。缺少任何一项，店铺菜单中都不会出现**语言**页面。如果安装了 **WooCommerce Multilingual**，其版本必须为 4.11.0 或更高版本。
:::

1. 在 **WP Admin** 中，前往 **POS → 店铺**，然后点击店铺名称。
2. 在店铺菜单的**扩展**下打开**语言**。
3. 在**店铺语言**下选择一种语言。列表会显示 WPML 已开启的所有语言。**默认语言**会沿用 WPML 的默认语言。选择后会自动保存。
4. 打开此店铺的 POS，并[检查是否生效](#check)。产品应以您所选的语言仅显示一次。

其他店铺会保留各自的语言。

### 产品语言与界面语言 {#product-and-screen-language}

店铺菜单中有两个名为**语言**的设置，分别位于不同位置：

- **扩展 → 语言 → 店铺语言**用于选择 POS 显示每个产品的哪种译文。
- **货币和语言 → 语言**用于选择 POS 界面和收据上的文字语言。请参阅[填写店铺各页面](../stores/setup.mdx#store-pages)。

:::tip
对于法语店铺，将两项都设为法语。
:::

## 出现问题时 {#goes-wrong}

**每个产品仍然显示两次或三次。** 检查**插件**中是否已启用 **WCPOS WPML**，并确认 WPML 已设置默认语言。如果安装了 **WooCommerce Multilingual**，其版本必须为 4.11.0 或更高版本：版本过旧时，扩展会自行关闭。

**店铺菜单的扩展下没有语言页面。** 此页面需要 WCPOS Pro、已启用的扩展，以及已启用且至少开启了一种语言的 WPML。如果安装了 **WooCommerce Multilingual**，其版本必须为 4.11.0 或更高版本。

**仅限 POS 或仅限在线的产品以另一种语言出现在不该出现的位置。** 仅限 POS 和仅限在线的设置保存在各个产品中，而每种译文都是独立产品，因此译文不会继承原产品的设置。请打开每种译文，为其设置相同的可见性。请参阅[仅限 POS 的产品](../products/pos-only-products.mdx)。

:::info 使用 WCPOS Pro
每个店铺都可以选择自己的产品语言。没有 Pro 时，只有一个店铺，使用 WPML 的默认语言。
:::

<details>
<summary>开发者信息：过滤器与存储数据</summary>

此扩展仅作用于 POS 发出的产品和变体请求：它会向产品查询中添加 WPML 的 `lang`。其他 WooCommerce REST 客户端不受影响。如果已登录用户有权使用请求指定的店铺，则使用该店铺的语言；否则使用 WPML 的默认语言。

- 店铺的语言选择保存在该店铺的 `_wcpos_wpml_language` 元数据中。空值表示使用 WPML 的默认语言。
- `wcpos_wpml_resolved_language` 用于更改单次请求使用的语言。
- `wcpos_wpml_default_language` 用于更改默认语言。
- `wcpos_wpml_is_supported` 用于开启或关闭扩展。
- `wcpos_wpml_minimum_wpml_version` 和 `wcpos_wpml_minimum_wcml_version` 用于设置扩展运行所需的最低 WPML 和 WooCommerce Multilingual 版本。WooCommerce Multilingual 的最低版本为 `4.11.0`；WPML 默认没有最低版本要求。

源码：[github.com/wcpos/wcpos-wpml](https://github.com/wcpos/wcpos-wpml)。

</details>
