# WCPOS Polylang {#wcpos-polylang}

**WP 后台：** 在 `WP Admin → POS → Settings → Extensions` 中安装，并在 `WP Admin → POS → Stores` 中按店铺配置。

WCPOS Polylang 让每个商品在搜索结果和商品网格中仅显示一次，并使用店铺的语言。未安装此扩展时，在 [Polylang](https://wordpress.org/plugins/polylang/) 中翻译的商品会在 POS 中按语言分别显示，每种语言各显示一次。

## 收银员看到的内容 {#what-it-does}

- **每个商品仅显示一次。** 搜索结果、商品网格和变体均使用同一种语言。
- **使用店铺的语言。** 使用 WCPOS Pro 时，每个店铺都可以设置自己的语言。未使用 Pro 时，POS 使用 Polylang 的默认语言。
- **仅限 POS 的设置仍然有效。** 设置为 **仅限线上** 的商品不会出现在 POS 中。请参阅[仅限 POS 的商品](../products/pos-only-products.mdx)。

如果商品没有店铺所用语言的译文，就不会在该店铺显示。请在 Polylang 中添加相应译文，才能在该店铺销售此商品。

## 使用要求 {#requirements}

<RequirementsList>
  <RequirementItem label="WooCommerce">已安装并启用 WooCommerce</RequirementItem>
  <RequirementItem label="Polylang">已启用 Polylang，并添加了至少一种语言</RequirementItem>
  <RequirementItem label="WCPOS">可与免费版插件配合使用；为各店铺单独设置语言需要 WCPOS Pro</RequirementItem>

## 设置步骤 {#installation}

步骤 1 至 3 在 WP 后台中完成，步骤 4 在每台收银机上完成。

1. **设置 Polylang。** 安装并启用 [Polylang](https://wordpress.org/plugins/polylang/)，添加所需语言并选择默认语言。在 WordPress 6.5 及更高版本中，必须先启用 Polylang，WordPress 才允许启用 WCPOS Polylang。
2. **安装 WCPOS Polylang。**

   **使用 WCPOS Pro：** 打开 **POS → 设置 → 扩展**，找到 **WCPOS Polylang**，然后点击 **安装** 和 **启用**。请参阅[安装扩展](./index.mdx#installing-an-extension)。

   **未使用 WCPOS Pro：** 从[最新发布版本](https://github.com/wcpos/wcpos-polylang/releases/latest)下载 `wcpos-polylang.zip`，然后在 **插件 → 安装插件 → 上传插件** 中上传。点击 **立即安装**，然后点击 **启用插件**。

3. 如果某个店铺不应使用 Polylang 的默认语言，可 **通过 WCPOS Pro 为各店铺选择语言**。请参阅[为各店铺选择语言](#per-store-language-pro)。
4. **在每台收银机上重新下载商品。** 请参阅[重新下载商品](#redownload)。

## 为各店铺选择语言 {#per-store-language-pro}

:::info 使用 WCPOS Pro
每个店铺都可以设置自己的 Polylang 语言。未使用 Pro 时，所有收银机都使用 Polylang 的默认语言。要为各店铺单独设置语言，请升级到 [WCPOS Pro](../getting-started/pro-license.mdx)。
:::

1. 在 WP 后台中，打开 **POS → 店铺**，然后点击相应店铺。
2. 在店铺菜单的 **扩展** 下，点击 **语言**。
3. 在 **店铺语言** 下选择一种语言。Polylang 按代码列出语言，例如 `en` 或 `fr`。第一个选项是 **默认语言**，旁边显示默认语言的代码；此选项会沿用 Polylang 的默认语言。

页面会自动保存更改。然后，按下文说明在该店铺的收银机上[重新下载商品](#redownload)。

只有 WCPOS Pro、Polylang（已添加至少一种语言）和 WCPOS Polylang 全部启用后，才会显示 **语言** 页面。

### 两个名为“语言”的设置 {#two-languages}

每个店铺有两个 **语言** 设置，两者可以设为不同的语言。

| 店铺菜单中的位置 | 影响的内容 |
| --- | --- |
| **扩展 → 语言** | 决定店铺的收银机获取哪种 Polylang 语言的商品。 |
| **货币和语言 → 语言** | POS 界面和收据的语言。请参阅[填写店铺各页面的信息](../stores/setup.mdx#store-pages)。 |

## 重新下载商品 {#redownload}

为使每台收银机仅保留一种语言的商品，需要重新获取商品。请在每台收银机联网时执行以下操作：

1. 打开导航抽屉，点击 **店铺健康状况**（心跳图标）。打开后会显示 **数据库** 选项卡。
2. 在 **商品** 行中，打开 **更多操作** 菜单，选择 **清除并重新下载…**，然后确认。这也会清除商品变体。
3. 搜索一个已有店铺语言译文的商品。该商品应仅显示一次，名称使用店铺的语言。如果不是这样，请参阅[遇到问题时](#compatibility-notes)。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="店铺健康状况的数据库选项卡，商品行的更多操作菜单已展开，其中包含清除并重新下载选项">

1. **商品** — 显示此收银机已保存的商品数量及网站上的商品总数。下方 **变体** 行的数据也会一并清除。
2. **更多操作** — 该行的操作菜单。
3. **清除并重新下载…** — 删除此收银机上的本地副本，然后重新获取单一语言的商品。请参阅[店铺健康状况](../support/store-health.mdx#clear-and-redownload)。

</JourneyShot>

服务器上的内容不会改变。第一批商品会立即重新下载，其余商品则会随着浏览、搜索和销售逐步下载。**商品** 行会显示已重新下载的数量。请参阅[查看下载进度](../products/sync.mdx#progress)。

## 遇到问题时 {#compatibility-notes}

**每个商品都重复显示。** 请在 **插件** 中检查 Polylang 和 WCPOS Polylang 是否均已启用。Polylang 停用时，WCPOS Polylang 不起作用，POS 会获取所有语言的商品。然后，在每台收银机上[重新下载商品](#redownload)。

**店铺显示的商品语言不正确。** 该店铺的 **扩展 → 语言** 页面选择了 **默认语言** 或其他语言。请选择店铺所需的语言，然后在该店铺的收银机上[重新下载商品](#redownload)。

**某个店铺中缺少商品。** 请检查该商品是否有该店铺所用语言的译文；如果没有，请在 Polylang 中添加。如果已有译文，请参阅[找不到商品时](../pos/product-panel/index.mdx#goes-wrong)。

**扩展下没有语言页面。** 需要同时启用 WCPOS Pro、Polylang 和 WCPOS Polylang，并且 Polylang 中至少添加了一种语言。

## 开发者信息 {#developer-hooks}

<details>
<summary>筛选原理及其过滤器</summary>

- WCPOS Polylang 会在 WCPOS 发起的商品和变体 REST 查询中添加 Polylang 的 `lang` 查询参数。这适用于 `/wcpos/v…/` 路由，也适用于免费版插件通过 `wcpos_request()` 标记为 WCPOS 的请求。
- 对于 WCPOS 仅请求 ID 的商品和变体列表（在 `/wcpos/v1/products` 及其变体路由中，使用 `posts_per_page=-1` 配合 `fields=id` 或 `fields=id,date_modified_gmt`），它会自行响应，按语言筛选结果；启用仅限 POS 的商品功能时，还会排除 **仅限线上** 商品的 ID。
- 使用 WCPOS Pro 时，如果请求包含用户有权使用的 `store_id`，则会采用该店铺的语言。店铺语言保存在文章元数据 `_wcpos_polylang_language` 中，并由 `/wcpos/v1/stores` 以 `language` 字段返回。

| 过滤器 | 用途 |
| --- | --- |
| `wcpos_polylang_resolved_language` | 更改请求使用的语言。接收语言 slug 和 `WP_REST_Request`。 |
| `wcpos_polylang_default_language` | 更改店铺未设置语言时使用的回退语言。 |
| `wcpos_polylang_is_supported` | 无论 Polylang 检测结果如何，启用或停用此集成。 |
| `wcpos_polylang_minimum_version` | 指定所需的最低 Polylang 版本。默认为空，即不检查版本。 |

源码：[github.com/wcpos/wcpos-polylang](https://github.com/wcpos/wcpos-polylang)。

</details>
