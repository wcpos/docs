**WP 后台：** 在 `WP Admin → POS → Settings → Extensions` 中安装，并在 `WP Admin → POS → Stores` 中为各店铺设置。

[WP Multilang](https://wordpress.org/plugins/wp-multilang/) 将产品的所有译文保存在同一个产品中，并允许您将产品限定为仅在部分语言中显示。免费的 **WCPOS WP Multilang** 扩展让 POS 使用一种语言，因此限定为其他语言的产品不会出现在 POS 中。

收银员无需进行任何设置：第一节介绍他们会看到的变化。本页其余内容面向店铺管理员。

## 收银员会看到什么 {#what-the-cashier-sees}

产品搜索、产品网格及可变产品的选项会显示以店铺语言销售的产品：

- **没有语言限制**的产品会显示在每个店铺中。
- **仅限部分语言**的产品，只会显示在使用这些语言之一的店铺中。

收银员的销售操作不变：照常添加到购物车、收款和打印收据。请参阅[结账](../pos/checkout/index.mdx)。

## 安装扩展 {#install}

:::note 开始之前
您需要启用 [WooCommerce](https://woocommerce.com/) 和 [WP Multilang](https://wordpress.org/plugins/wp-multilang/)，在 WP Multilang 中设置好语言，并使用管理员账号登录 **WP Admin**。只有这两个插件都已启用，WordPress 才能启用此扩展。
:::

管理员只需在 **WP Admin** 中安装一次。除非您[为店铺选择语言](#store-language)，否则 POS 会使用 WP Multilang 的**默认语言**。

### 使用 WCPOS Pro {#install-pro}

1. 前往 **POS → 设置 → 扩展**。
2. 找到 **WCPOS WP Multilang**，然后点击**安装**。
3. 点击**启用**。

有关更新和自动更新的信息，请参阅[安装扩展](./index.mdx#installing-an-extension)。

启用扩展后：

- 如需为店铺指定语言，请先[选择语言](#store-language)，再[检查是否生效](#check)。
- 否则，直接前往[检查是否生效](#check)。

### 使用免费插件 {#install-free}

扩展页面会列出此扩展，但其**安装**按钮需要 Pro 才能使用。您可以按以下步骤安装：

1. 从扩展的[最新版本](https://github.com/wcpos/wcpos-wp-multilang/releases/latest)下载 `wcpos-wp-multilang.zip`。
2. 前往**插件 → 安装插件**，然后点击**上传插件**。
3. 选择下载的文件，然后点击**现在安装**。
4. 点击**启用插件**。

然后[检查是否生效](#check)。没有 Pro 时，只有一个店铺，使用 WP Multilang 的默认语言。

### 检查是否生效 {#check}

POS 会在每台设备上保存一份产品数据，因此需要清除一次，才能应用更改。

#### 在 WP Admin 中：准备两个产品 {#check-prepare}

选择两个有货的产品进行测试：一个以店铺语言销售，另一个不以该语言销售。产品的语言在 **WP Admin** 中设置，而非在 POS 中。对这两个产品分别执行以下操作：

1. 在 **WP Admin** 中打开产品编辑页面。
2. 在 WP Multilang 的**语言**框中，在**仅以以下语言显示文章：** 下勾选产品销售时使用的语言。如果全部不选，产品会在所有语言中显示，因此请至少勾选一种。
3. 保存产品。

#### 在每台 POS 设备上：检查结果 {#check-device}

在每台使用 POS 的设备上：

1. 长按产品下方的同步按钮，选择**清除并刷新**。等待产品重新下载。
2. 关闭筛选栏中除**有货**以外所有已启用的筛选条件。在**搜索产品**中输入以店铺语言销售的产品名称。该产品应会显示。
3. 搜索另一个产品。该产品应不会显示。

<JourneyShot manifest={manifest} device="tablet" step={1} offsets={[[240, 0], [0, 0], [0, 0], [-42, 0]]} alt="搜索某个产品后的 POS 产品面板：搜索框、已启用的有货筛选条件、一个产品卡片和产品数量">

1. **搜索产品** — 输入产品名称。
2. **有货** — 默认启用，除非在[显示设置](../pos/product-panel/display-settings.mdx#show-out-of-stock-products)中开启了**显示缺货产品**。启用时，缺货产品会保持隐藏。因此，用于测试的两个产品都需要有货。请参阅[库存状态](../pos/product-panel/search-filtering.mdx#stock-status)。
3. **产品** — 仅在以店铺语言销售时显示。
4. **产品数量** — 此设备上符合搜索条件的产品数量。刷新完成后，仅统计以店铺语言销售的产品。

长按同步按钮可打开其菜单：

<JourneyShot manifest={manifest} device="tablet" step={2} offsets={[[80, 0], [-38, -94], [42, -41]]} maxWidth={580} alt="产品面板底部，长按同步按钮后打开的菜单中显示同步和清除并刷新">

1. **同步按钮**（<Icon name="arrow-rotate-right" />）— 长按可打开此菜单。请参阅 [面板底部](../pos/product-panel/display-settings.mdx#footer)。
2. **同步** — 与点击按钮的作用相同。店铺语言更改后，同步不会移除现在应隐藏的产品，因此请选择**清除并刷新**。
3. **清除并刷新** — 清除此设备上的产品，然后重新下载店铺的产品。

如果另一个产品仍然显示，请参阅[出现问题时](#goes-wrong)。

## 选择店铺语言 {#store-language}

使用 WCPOS Pro 时，每个[店铺](../stores/index.mdx)都可以使用自己的语言：同一站点上的法语店铺和英语店铺，分别只能看到以各自语言销售的产品。

:::note 语言页面需要满足三个条件
需要 WCPOS Pro、已启用的 **WCPOS WP Multilang** 扩展，以及已启用且至少设置了一种语言的 WP Multilang。缺少任何一项，店铺菜单中都不会出现**语言**页面。
:::

1. 在 **WP Admin** 中，前往 **POS → 店铺**，然后点击店铺名称。
2. 在店铺菜单的**扩展**下打开**语言**。不要选择**货币和语言 → 语言**，后者用于更改屏幕和收据上的文字，详见[下文](#product-and-screen-language)。
3. 在**店铺语言**下选择一种语言。列表会显示 WP Multilang 中设置的所有语言。**默认语言**会沿用 WP Multilang 的默认语言。选择后会自动保存。
4. 打开此店铺的 POS，并[检查是否生效](#check)。

其他店铺会保留各自的语言。

### 产品语言与界面语言 {#product-and-screen-language}

店铺菜单中有两个名为**语言**的设置，分别位于不同位置：

- **扩展 → 语言 → 店铺语言**用于选择 POS 显示哪些产品。
- **货币和语言 → 语言**用于选择 POS 界面和收据上的文字语言。请参阅[填写店铺各页面](../stores/setup.mdx#store-pages)。

:::tip
对于法语店铺，将两项都设为法语。
:::

## 出现问题时 {#goes-wrong}

**仅限另一种语言的产品仍然显示。** 检查**插件**中是否已启用 **WCPOS WP Multilang**，然后在该设备上长按同步按钮，选择**清除并刷新**。

**某个店铺中缺少产品。** 在 WP Multilang 中检查产品的语言是否包含该店铺的语言。如果不包含，请添加该语言，然后刷新 POS。如果已包含，请参阅[找不到产品时](../pos/product-panel/index.mdx#goes-wrong)。

**WordPress 无法启用扩展。** 请先启用 WooCommerce 和 WP Multilang。

**店铺菜单的扩展下没有语言页面。** 此页面需要 WCPOS Pro、已启用的扩展，以及已启用且至少设置了一种语言的 WP Multilang。

:::info 使用 WCPOS Pro
每个店铺都可以选择自己的语言。没有 Pro 时，只有一个店铺，使用 WP Multilang 的默认语言。
:::

<details>
<summary>开发者信息：过滤器与存储数据</summary>

此扩展仅作用于 POS 发出的产品和变体请求：它会向产品查询中添加 WP Multilang 的 `lang` 查询变量及 `_languages` 元数据查询。产品没有 `_languages` 元数据，或其 `_languages` 包含所选语言时，即符合条件。其他 REST 客户端不受影响。语言优先取自请求指定的店铺(`store_id`)，其次使用 WP Multilang 的默认语言。

- 店铺的语言选择保存在该店铺的 `_wcpos_wp_multilang_language` 元数据中。空值表示使用 WP Multilang 的默认语言。店铺 API(`/wcpos/v1/stores`)通过 `language` 返回当前使用的语言：店铺所选语言，或在元数据为空时返回默认语言的代码。
- `wcpos_wp_multilang_resolved_language` 用于更改单次请求使用的语言。
- `wcpos_wp_multilang_default_language` 用于更改默认语言。
- `wcpos_wp_multilang_is_supported` 用于开启或关闭扩展。
- `wcpos_wp_multilang_minimum_version` 用于设置扩展运行所需的最低 WP Multilang 版本。默认没有最低版本要求。
- 对于 1.x 应用，扩展还会使用相同的语言筛选条件，响应其向 `/wcpos/v1/products` 和变体路由发出的 ID 列表请求（`posts_per_page=-1` 且 `fields=id`）。2.x 应用不会发送这些请求。

源码：[github.com/wcpos/wcpos-wp-multilang](https://github.com/wcpos/wcpos-wp-multilang)。

</details>
