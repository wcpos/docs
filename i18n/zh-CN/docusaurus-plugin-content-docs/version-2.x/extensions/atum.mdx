:::info Pro 功能
ATUM 扩展将 ATUM 库存地点与[店铺](../stores/index.mdx)关联，店铺功能由 [WCPOS Pro](../getting-started/pro-license.mdx) 提供。
:::

[ATUM Multi-Inventory](https://stockmanagementlabs.com/addons/atum-multi-inventory/) 可分别管理一件商品在仓库、店面、集市摊位等多个地点的库存。**WCPOS ATUM Integration** 扩展将每个 WCPOS 店铺关联到其中一个 **库存地点**。该店铺的收银机会使用此地点的库存数量，也可使用其价格和 SKU。销售时扣减的是该地点的库存，而非网店的总库存。

收银员无需进行设置，请参阅[收银员看到的内容](#what-the-cashier-sees)和[销售与退款](#stock)。管理员请从[安装扩展](#install)开始。收银机上的库存数量不对？请参阅[库存数量不正确时](#count-wrong)。库存或价格设置有误？请参阅[故障排查](#goes-wrong)。

## 收银员看到的内容 {#what-the-cashier-sees}

销售操作不变，变化的是各件商品的数据：

- **库存** — 此店铺所关联库存地点的数量。
- **此地点缺货** — 某件商品在该地点售罄时，即使仓库中库存充足，也会显示为缺货，并被 **有货** 筛选条件隐藏。
- **此地点无库存记录** — 如果商品没有此地点的库存记录（ATUM 称之为 **库存记录**），则沿用未使用 ATUM 时的库存、价格和 SKU。
- **价格** — 店铺配置为使用 ATUM 价格时，价格来自 ATUM，详见[选择价格来源](#pricing-source)。
- **SKU** — 店铺配置为使用地点专属 SKU 时，显示该地点的 SKU，详见[使用地点专属 SKU](#location-skus)。

### 库存数量不正确时 {#count-wrong}

1. 长按 [同步按钮](../pos/product-panel/display-settings.mdx#footer) （<Icon name="arrow-rotate-right" />），然后选择 **清除并刷新**。收银机会重新下载该地点的库存数量。
2. 找不到该地点已售罄的商品？启用 **有货** 筛选条件时，这类商品会被隐藏。点击 **有货** 上的叉号即可显示。请参阅[找不到商品时](../pos/product-panel/index.mdx#goes-wrong)。
3. 仍然不对？请让管理人员检查店铺的 **库存地点**，以及 ATUM 中该商品在此地点的库存记录，详见[故障排查](#goes-wrong)。

## 销售与退款 {#stock}

在已关联的店铺中销售时，会从该店铺对应的库存地点扣减库存。退款或取消订单时，库存会退回原地点。ATUM 自行处理库存数量的增减，因此每次变动都会显示在 ATUM 的库存历史记录中，并关联到相应订单。

## 安装扩展 {#install}

:::note 开始之前
您需要安装并启用 [ATUM Inventory Management](https://wordpress.org/plugins/atum-stock-manager-for-woocommerce/) 及其 [Multi-Inventory](https://stockmanagementlabs.com/addons/atum-multi-inventory/) 附加组件，并在 ATUM 中创建库存地点。此外，还需要 WCPOS Pro 和可登录 **WordPress 后台** 的管理员账号。
:::

1. 在 **WordPress 后台** 中，前往 **收银台 → 设置**，选择 **扩展**。
2. 选择 **库存** 选项卡，找到 **WCPOS ATUM Integration**。
3. 点击 **安装**，即可一次完成安装并启用。

有关更新和自动更新的说明，请参阅[安装扩展](./index.mdx#installing-an-extension)。

也可从 [GitHub 发布页面](https://github.com/wcpos/wcpos-atum/releases)下载 zip 文件，然后在 **WordPress 后台 → 插件 → 安装插件 → 上传插件** 中上传。

## 将店铺关联到库存地点 {#store-location}

每个拥有独立库存的店铺只需设置一次。店铺中销售的每件商品还需要在 ATUM 中有该地点的 **库存记录**，用于记录商品在该地点的库存。如果没有这条记录，收银机会沿用商品原有的 WooCommerce 库存、价格和 SKU。

1. 在 **WordPress 后台** 中，前往 **收银台 → 店铺**，点击店铺名称。
2. 在店铺菜单的 **扩展** 下，打开 **ATUM 库存**。
3. 在 **库存地点** 下，选择此店铺销售商品时使用的库存地点。选择 **无地点（使用默认库存）** 会让店铺继续使用网店原有的 WooCommerce 库存。
4. 随后会出现另外两项设置：**价格来源** 和 **使用 ATUM 中的地点专属 SKU**。可按下文设置，也可保留当前设置。
5. 更改会自动保存。在店铺的每台收银机上，长按 [同步按钮](../pos/product-panel/display-settings.mdx#footer) （<Icon name="arrow-rotate-right" />），然后选择 **清除并刷新**。此时库存就会与 ATUM 中该地点的库存一致。

### 选择价格来源 {#pricing-source}

**价格来源** 有三个选项：

- **默认（WooCommerce 价格）** — 不使用 ATUM 的价格。如果商品为此店铺设置了[店铺专属价格](../stores/setup.mdx#per-store-pricing)，收银机会显示该价格，否则显示 WooCommerce 价格。
- **WCPOS Pro（按店铺定价）** — 与 **默认** 相同：有店铺专属价格时使用该价格，否则使用 WooCommerce 价格。
- **ATUM（按库存记录定价）** — 常规价格和促销价格来自 ATUM 中该地点的库存记录。如果 ATUM 未为其设置价格，收银机会沿用选择 **默认** 时显示的价格。

无论选择哪一项，库存都来自所关联的地点。

### 使用地点专属 SKU {#location-skus}

如果各地点使用各自的 SKU 标识库存，请勾选 **使用 ATUM 中的地点专属 SKU**。收银机会显示该地点的 SKU，搜索此 SKU 即可找到商品。如果 ATUM 未设置该地点的 SKU，则沿用商品自身的 SKU。

## 在 POS 中编辑商品 {#write-back}

使用 WCPOS Pro 时，POS 菜单中的 **商品** 页面会显示所关联地点的数据。如果商品在店铺所关联的地点恰好有一条库存记录，在此页面所做的编辑会回写到 ATUM 中的该地点。只会更改该地点，其他地点不受影响。

要在收银机上修改某个地点的库存：

1. 在 POS 菜单中，打开 **商品** 并搜索目标商品。
2. 点击商品的 **库存** 数字，输入新的数量，然后按 **回车键**。
3. 在 ATUM 中核对：打开该商品，查看对应地点的库存记录，此时应显示新的数量。

<JourneyShot manifest={manifest} device="tablet" step={1} alt="搜索手表后的 POS 商品页面：搜索框、有货筛选条件，以及每款手表的库存数量、库存状态、价格、常规价格、促销价格和用于打开商品的箭头">

1. **搜索** — 按名称或 SKU 查找商品。如果店铺使用[地点专属 SKU](#location-skus)，则按该地点的 SKU 查找。
2. **有货** — 仅显示库存状态为 **有货** 的商品，该状态由所关联地点的库存数量决定。
3. **库存** — 此地点的库存数量。如果商品在此地点有一条库存记录，在这里修改数量也会更改 ATUM 中该地点的数量。请参阅[直接编辑库存](../products/index.mdx#inline-stock-editing)。
4. **库存状态** — 此地点的数量大于 0 时为 **有货**，等于或小于 0 时为 **缺货**。
5. **价格** — 收银机收取的价格。店铺的 **价格来源** 设为 **ATUM** 时，此价格及旁边的 **常规价格** 和 **促销价格** 均来自该地点。下表说明了更改在什么情况下会回写到 ATUM。
6. **打开**（›）— 打开商品以进行编辑。请参阅[商品操作](../products/index.mdx#product-actions)。

如果商品在店铺所关联的地点恰好有一条库存记录，以下字段会回写：

| 字段 | 回写到 ATUM 的条件 |
| --- | --- |
| **库存** | 每次更改都会回写。 |
| **常规价格**、**促销价格** | 仅当店铺的 **价格来源** 为 **ATUM**，且商品没有为此店铺设置[店铺专属价格](../stores/setup.mdx#per-store-pricing)时。如果有店铺专属价格，更改会写入该专属价格，而收银机仍显示 ATUM 的价格。 |
| **SKU** | 仅当勾选 **使用 ATUM 中的地点专属 SKU** 时。 |

以下情况不会向 ATUM 回写任何内容：

- 新建商品时。请在 ATUM 中添加该地点的库存。
- 商品在该地点没有库存记录时。扩展不会添加库存记录。
- 商品在该地点有多条库存记录时。扩展无法确定应修改哪一条，因此不会修改任何一条。

## 故障排查 {#goes-wrong}

**收银机显示的是网店总库存，而非所关联地点的库存。** 请确认店铺已设置 **库存地点**，且商品在 ATUM 中有该地点的库存记录。然后长按同步按钮，选择 **清除并刷新**。还请在 **扩展** 页面检查扩展版本：早于 0.1.4 的版本在 WCPOS 2.0 中会显示总库存。

**店铺菜单的扩展下没有 ATUM 库存页面。** 此页面需要 WCPOS Pro，且必须启用该扩展、ATUM Inventory Management 和 ATUM Multi-Inventory。

**“未找到 ATUM 库存地点。请在 ATUM 设置中创建地点。”** ATUM 中尚未创建库存地点。请在 ATUM 中创建，然后重新加载店铺页面。

**没有价格来源设置。** 店铺设置 **库存地点** 后，此项才会出现。

**收银机的价格与 ATUM 中的价格不同。** 请确认店铺的 **价格来源** 为 **ATUM**，且商品在该地点的库存记录中已设置价格。如果没有设置，收银机会沿用选择 **默认** 时显示的价格。更改价格来源后，请在每台收银机上长按同步按钮，选择 **清除并刷新**。请参阅[选择价格来源](#pricing-source)。

**商品页面上的库存更改未同步到 ATUM。** 商品在店铺所关联的地点没有库存记录，或有多条记录。请参阅[在 POS 中编辑商品](#write-back)。

<details>
<summary>开发者参考：存储的数据、REST 字段和过滤器</summary>

- 店铺将设置保存在三个文章元数据键中：`_wcpos_atum_inventory_location`（`atum_location` 分类项的 ID）、`_wcpos_pricing_source`（`default`、`wcpos_pro` 或 `atum`）和 `_wcpos_atum_sku_override`（`1` 或空值）。WCPOS 店铺端点分别以 `atum_inventory_location`、`pricing_source` 和 `atum_sku_override` 返回这些值。
- 面向 POS 的商品及变体响应在优先级 20 时修改，晚于优先级 10 的 WCPOS Pro 店铺专属价格处理。库存状态仅根据所关联地点的数量设置。
- POS 保存订单时，扩展会为每个订单行项目添加 `mi_inventories`，并将 `atum/multi_inventory/order_item_inventories` 过滤为店铺所关联的地点。随后 ATUM 负责扣减和恢复库存，并将订单 ID 记录在 `atum_inventory_orders` 中。
- 商品编辑仅在更新时写入 `atum_inventory_meta`，新建时不会写入，且必须恰好有一条库存记录匹配该地点（或请求通过 `inventory_id` 指定了一条记录）。
- `wcpos_atum_is_supported` 控制扩展的启用和关闭。默认情况下，ATUM Multi-Inventory 启用时，此扩展也会启用。
- 使用要求：WordPress 5.9 或更高版本，PHP 7.4 或更高版本。

源代码：[github.com/wcpos/wcpos-atum](https://github.com/wcpos/wcpos-atum)。

</details>
