## 重新安装旧版本 {#re-installing-a-previous-version}

要返回到插件的较早版本，请先关闭自动更新，再下载所需版本并覆盖安装。此过程不会删除任何内容，因此您的订单、设置和收据模板都会保留。

:::warning 请勿先删除插件
将 `.zip` 文件覆盖安装到现有插件上，即可保留所有内容。在 2.0 中，从 **插件** 页面删除插件会运行 WCPOS 的清理流程：所有收银员都会退出登录，因此每个收银台都必须重新登录；此外，每个收银台重新构建的同步数据也会被清除。无需删除插件。
:::

如果您要从 2.0 降级，请先阅读[回退](/getting-started/upgrading-to-2#rolling-back)。使用 WCPOS Pro 时，只回退 WCPOS Pro 即可，其中已包含免费插件。

### 关闭自动更新 {#turn-off-auto-updates}

如果开启了自动更新，WordPress 会再次自动安装最新版本。

1. 前往 **WP Admin → 插件**。
2. 在 WCPOS 行（或 WCPOS Pro 行）中查看 **自动更新** 列。如果显示 **禁用自动更新**，请点击它。

### 下载所需版本 {#download}

请保持 `.zip` 文件为压缩状态。WordPress 安装的是 `.zip` 文件，而不是文件夹。

**WCPOS：**

1. 在 WordPress.org 上打开 [WCPOS 高级视图](https://wordpress.org/plugins/woocommerce-pos/advanced/)。
2. 向下滚动到 **高级选项**。在 **以前的版本** 下选择所需版本。
3. 点击 **下载**。

**WCPOS Pro：**

1. 登录 [wcpos.com](https://wcpos.com/account/downloads) 帐户，然后打开 **下载**。
2. 在 **版本历史记录** 中找到所需版本。
3. 点击该行中的 **下载**。

要从 2.0 降级，请选择最新的 **1.11** 版本，而不是更早的 1.x 版本。

### 覆盖安装当前版本 {#install}

1. 前往 **WP Admin → 插件**，然后点击页面顶部的 **添加插件**。
2. 点击 **上传插件**，选择下载的 `.zip` 文件，然后点击 **立即安装**。
3. WordPress 会显示 **此插件已安装。**，并并排显示 **当前版本** 和 **已上传版本**。请确认 **已上传版本** 是您需要的版本。
4. 点击 **将当前版本替换为已上传版本**。
5. WordPress 会显示 **插件降级成功。**。如果出现 **启用插件**，请点击它；否则，插件原本已启用，会继续保持启用状态。

请保持自动更新关闭，直到您准备好再次更新，然后重新开启自动更新，否则之后的修复将不会自动安装。

如果重新安装过程中遇到问题，或需要进一步帮助，请通过 support@wcpos.com 联系我们的支持团队。
