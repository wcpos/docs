## 重新安装旧版本 {#re-installing-a-previous-version}

如果您需要恢复到 WCPOS 插件的旧版本，请按照以下步骤操作：

1. 访问 WordPress.org 页面 [高级视图](https://wordpress.org/plugins/woocommerce-pos/advanced/) 以获取 WCPOS。

2. 向下滚动到 **高级选项** 部分，找到 **旧版本** 下拉菜单。

3. 打开下拉菜单，即可查看可用的插件版本列表。找到要安装的版本，然后点击旁边的 **下载** 按钮。将下载的文件保存到桌面或方便查找的位置。

4. 登录 WordPress 管理后台。

5. 点击左侧菜单中的 **插件**，打开 **插件** 页面。

6. 停用并删除当前版本的 WCPOS 插件。这会从 WordPress 安装中移除该插件。请放心，您的数据不会丢失。

7. 点击页面顶部的 **添加插件** 按钮。

8. 在 **添加插件** 页面，点击 **上传插件** 按钮。

9. 选择之前下载的插件文件（位于桌面或您保存文件的位置）。

10. 点击 **立即安装** 按钮，并等待安装完成。

11. 安装完成后，点击 **激活** 按钮以启用旧版本的 WCPOS 插件。

完成！您已成功重新安装 WCPOS 插件的旧版本。

如果重新安装过程中遇到问题，或需要进一步帮助，请通过 support@wcpos.com 联系我们的支持团队。
