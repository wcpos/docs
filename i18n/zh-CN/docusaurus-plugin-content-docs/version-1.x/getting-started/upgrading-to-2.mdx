WCPOS 2.0 是一次重大更新。收银台、结账界面和现金抽屉都焕然一新，插件现在还要求 **WooCommerce 9.0 或更高版本**。本页是供点击 **更新** 的人员使用的升级前检查清单。请先阅读，再进行更新。

## 现在可以升级吗？ {#can-you-upgrade-today}

打开 **WP Admin → 插件**，查看 WooCommerce 版本。

- **WooCommerce 9.0 或更高版本：** 请按照[店铺已准备就绪](#if-your-store-is-ready)中的说明操作。
- **低于 9.0：** 请按照[店铺尚未准备就绪](#if-your-store-isnt-ready-yet)中的说明操作。请勿先更新 WCPOS。

## 如果店铺已准备就绪 {#if-your-store-is-ready}

### 点击更新前 {#before-you-click-update}

1. **同步每个收银台。** 2.0 会在每个收银台上创建新的本地数据库，不会带入 1.11 收银台尚未发送到店铺的内容。请打开每个收银台，等待同步完成，然后再更新。在 **店铺健康状况 → 数据库** 中，**等待发送的更改**必须显示 **0**，且不能有任何要求您做出决定的面板。此计数不包括未完成的订单：请完成每笔订单，或在订单上点击 **保存到服务器**。这两种操作都只显示当前已登录的用户：请在每家店铺以及每个收银员使用的每台收银设备上重复这些步骤。
2. **备份网站**，或请主机服务商创建还原点。更新本身不会影响您的订单或商品，但重大更新应当有回退方法。
3. **选择客流较少的时段。** 每个收银台都会重新加载到新版收银界面；如果旧版本上的交易在结账过程中尚未完成，就需要重新录入。
4. **确认 Pro 许可证处于有效状态**（WP Admin → POS → 设置 → 许可证；请参阅[安装 WCPOS Pro](/getting-started/pro-license)）。只有许可证有效时才能收到 Pro 更新。
5. **了解折扣的处理方式。** 如果收银员一直通过添加*负数费用*来减少订单金额，这种方式将不再有效。2.0 的收银台改为提供 **添加折扣**，可正确记录折扣。请参阅[购物车折扣](/pos/cart/discounts)。
6. **同时更新终端扩展。** Stripe Terminal、SumUp 和 Mollie Terminal 都有 2.0 版本。旧版扩展仍可通过结账界面中的 **旧版** 标签页使用，但无法通过新的支付方式面板控制读卡器。

### 更新 {#updating}

1. **更新插件。** 免费版网站请更新 **WCPOS**。使用 Pro 时，只更新 **WCPOS Pro**：它已包含免费插件，并会停用单独安装的副本。
2. 在每台设备上打开 POS，并等待首次同步完成。插件更新后，浏览器收银台会立即切换到 2.0。桌面版和移动版应用通过各自的常规渠道更新。连接到 2.0 插件的 1.11 应用会停留在更新提示页面，直到应用完成更新：应用和插件都必须升级到 2.0。

如果更新后收银台报告 **AUTH331**，说明 2.0 应用连接的店铺尚未更新。请更新插件并重新连接。请参阅 [AUTH331](/error-codes/AUTH331)。

### 首日会有哪些变化 {#what-changes-on-day-one}

- **收银界面焕然一新。** 所有屏幕采用统一的视觉风格，并可根据设备尺寸设置界面缩放（紧凑、标准、宽松）。表单和选择器会以面板形式滑入，而不是弹出对话框。顶部栏会显示当前店铺名称；如果店铺有多个收银台，也会显示收银台名称。您可以选择购物车所在的一侧，并在收银台设置中配置一排快速筛选按钮。
- **结账界面就是付款面板。** 按 **结账** 会打开数字键盘。输入顾客支付的金额，界面会显示找零金额。您可以将一笔交易拆分为现金和银行卡支付，也可以使用多张银行卡支付。连接到收银台的读卡器可在同一屏幕上操作（Pro）。仍使用自有付款页面的支付网关位于 **旧版** 标签页中。请参阅[结账](/pos/checkout)。
- **每台收银设备都有一个收银台。** 收银员首次打开 POS 时，会存入备用金并开启收银台。点击 **关闭收银台** 会清点现金抽屉，并将清点结果记为带编号的结账记录；随后可在完成页面打印结账报告（Z 报告）。此功能包含在免费插件中。免费插件只有一个收银台，供所有设备共用；管理员可在 **WP Admin → POS → 设置 → 收银台** 中为其命名并设置默认备用金，Pro 则提供更多收银台。如果您不使用现金抽屉，可以在 POS 设置中关闭收银台会话。请参阅[日终对账](/pos/reconciliation)。
- **收银台可免费使用优惠券。** 使用免费插件的收银员可以在购物车中应用 WooCommerce 优惠券代码。在 POS 中浏览优惠券页面仍属于 Pro 功能。
- **负数费用已取消。** 请使用 **添加折扣**。已包含负数费用的订单不会改变。
- **WooCommerce Analytics 会在 POS 订单付款后才计入该订单。** 尚未完成或只支付了部分金额的订单，在完成前不会再显示为销售额，因此包含这些订单的总额会降低。
- **收据包含更多信息。** 每张收据都会显示收银台名称、软件版本和 QR 码。退款会单独打印一张收据，作为贷项通知单。自定义收据模板仍可继续使用。
- **不再支持磁条读卡器。** 收银台的银行卡付款将通过集成读卡器处理（Pro），或记录为外部银行卡付款。

## 如果店铺尚未准备就绪 {#if-your-store-isnt-ready-yet}

**继续使用 WCPOS 1.11。** 它仍可正常运行，并会在 2.0 发布后的六个月内继续收到修复。

1. **关闭 WCPOS 和 WCPOS Pro 的自动更新。** 在 **WP Admin → 插件** 中，每个插件行都有 **启用自动更新** / **禁用自动更新** 链接。请确认显示的是*启用*。此步骤可防止自动更新在轮班期间向收银员显示阻止操作的提示。
2. **准备好后，将 WooCommerce 更新到 9.0 或更高版本。** 有关此更新的信息，请参阅 WooCommerce 自身的发行说明。
3. **返回[店铺已准备就绪](#if-your-store-is-ready)部分。**
4. **升级到 2.0 后，如果您之前使用了自动更新，请重新开启。** 否则之后的修复将不会自动安装。

### WCPOS 先于 WooCommerce 更新时 {#if-wcpos-updated-first}

POS 会停留在提示页面，说明需要 WooCommerce 9.0；不会丢失任何内容。您可以现在更新 WooCommerce，也可以[重新安装 WCPOS 1.11](/getting-started/previous-versions)，并按照上述步骤关闭自动更新。

## 回退 {#rolling-back}

### 1.11 收银台仍有未发送的销售记录 {#unsent-sales}

收银台会显示更新屏幕，销售记录尚未发送到店铺。在打开 2.0 之前，这些记录仍保存在该设备上。发送方法如下：

1. **保持该收银台当前状态。** 请勿更新应用；如果是浏览器收银台，请勿重新加载页面：这两种操作都会打开 2.0 并清除未发送的销售记录。
2. 在您的店铺中 **[重新安装 1.11 插件](/getting-started/previous-versions)**。
3. **在浏览器收银台重新加载页面，或关闭并重新打开应用。** 现在店铺已恢复到 1.11，收银台会重新连接并发送销售记录。等待 **店铺健康状况 → 数据库** 中的 **等待发送的更改** 显示 **0**，且没有任何要求您做出决定的面板。未完成的订单不计入其中：请完成每笔订单，或在订单上点击 **保存到服务器**。此时，销售记录已发送到店铺。
4. **再次更新到 2.0**，请按照[更新](#updating)中的说明操作。

### 返回 1.11 {#back-to-1-11}

如果 2.0 无法满足您的需求，请先在 [Discord](https://wcpos.com/discord) 上告诉我们。升级当天的大多数问题都能更快解决，无需回退。

:::warning 回退前先同步
返回 1.11 会让每台收银设备从空的本地数据库开始，而且 1.11 无法发送 2.0 收银台尚未发送到店铺的销售记录。请先等待所有 2.0 收银台完成同步：在 **店铺健康状况 → 数据库** 中，**等待发送的更改**必须显示 **0**，不能有要求您做出决定的面板，也不能有尚未同步的未完成订单。
:::

**已升级到 2.0 的桌面版或移动版应用无法连接到 1.11 插件**（会报告 [AUTH331](/error-codes/AUTH331)），而且应用商店不提供旧版本。再次升级前，请在该收银设备上使用浏览器访问 `yourdomain.com/pos` 来打开 POS。

要回退，请[重新安装 1.11 插件](/getting-started/previous-versions)。仍使用 1.11 的浏览器收银台和应用会照常运行。

在 2.0 上创建的订单是普通 WooCommerce 订单，会继续保留。记录于 2.0 的收银台会话和结账记录也会保留在数据库中，但 1.11 不会显示它们。
