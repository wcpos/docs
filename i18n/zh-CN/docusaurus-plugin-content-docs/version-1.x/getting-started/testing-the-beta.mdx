WCPOS 2.0 正在公开测试中，测试范围为浏览器中的收银设备和桌面应用。Android 和 iOS 应用将在测试结束后推出，在此之前，请让手机和平板电脑继续使用 1.11 站点。测试版用于在站点的预发布副本上测试，或在一个可以接受短暂中断的站点上测试；它不是正式版本，WordPress.org 上提供的仍是 1.11。测试人员需要了解的内容都在本页中。

## 准备条件 {#what-you-need}

- **WooCommerce 9.0 或更高版本。** 在更旧的版本上，2.0 会显示一条通知并停止运行。
- **应用和插件都必须是 2.0。** 2.0 应用无法与 1.11 插件配合使用，而 1.11 应用连接到 2.0 插件时会要求更新。请先更新插件，再更新每台收银设备。
- **不支持磁条读卡器。** 2.0 移除了这一实验性读卡器。收银设备上的读卡器需配合 WCPOS Pro，通过 Stripe Terminal 或 SumUp 使用。
- **终端扩展需要 WCPOS Pro 2.0。** 每个刷卡终端扩展在 GitHub 上都有一个测试版预发布；请在安装 Pro 之后手动安装：[Stripe Terminal](https://github.com/wcpos/stripe-terminal-for-woocommerce/releases/tag/v2.0.0-beta1)、[SumUp](https://github.com/wcpos/sumup-terminal-for-woocommerce/releases/tag/v2.0.0-beta1)、[Mollie](https://github.com/wcpos/mollie-terminal-for-woocommerce/releases/tag/v2.0.0-beta1)、[Square](https://github.com/wcpos/square-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)、[PayArc](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)、[Windcave](https://github.com/wcpos/windcave-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)和[Mercado Pago](https://github.com/wcpos/mercadopago-terminal-for-woocommerce/releases/tag/v1.0.0-beta1)。这些扩展当前的稳定版本面向 1.11。

## 安装之前 {#before-you-install}

1. **升级前先同步每台收银设备。** 2.0 会在每台收银设备上启用一个新的本地数据库，不会带入 1.11 收银设备尚未发送到站点的销售。请在 1.11 上打开每台收银设备，等待同步完成，然后再更新插件。仍未发送、留在 1.11 收银设备上的销售在升级后将会丢失。
2. **备份站点**，或请主机服务商创建一个还原点。
3. **选择一个空闲的时段。** 每台收银设备首次打开时都会重新加载到新的收银界面，而在 1.11 上结账到一半的销售需要重新录入。
4. 阅读[应用发行说明](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.2)了解变更内容：收银界面、结账流程和钱箱都是全新的，每个界面都经过重新设计，负费用形式的折扣已由“添加折扣”取代。

## 获取测试版 {#get-the-beta}

**插件（免费版）：** 从 [WCPOS 2.0.0 测试版 2 发布页](https://github.com/wcpos/woocommerce-pos/releases/tag/v2.0.0-beta.2)下载 `woocommerce-pos.zip`，然后通过 **WP 管理后台 → 插件 → 添加插件 → 上传插件** 安装，替换当前版本。插件一启用，浏览器中的收银设备就会切换到 2.0。

**插件（Pro）：** 登录 [wcpos.com/account/downloads](https://wcpos.com/account/downloads)，从 **WCPOS Pro 2.0 beta** 卡片下载 `woocommerce-pos-pro.zip`（需要有效许可证），并以相同方式上传。Pro 已包含免费版插件，无需两者都安装。

**桌面应用：** [WCPOS Desktop 2.0.0 测试版 2 发布页](https://github.com/wcpos/electron/releases/tag/v2.0.0-beta.2)提供 macOS、Windows 和 Linux 安装程序。测试版不会自动更新；后续测试版需从同一发布页重新下载。

**iPhone、iPad 和 Android：** 不在本次测试版中。应用商店中的 2.0 应用将在测试结束后推出；1.11 应用连接到 2.0 站点时会停在更新提示处，因此在此之前，请让手机和平板电脑继续使用 1.11 站点。

测试版应用的发行说明见[应用发布页](https://github.com/wcpos/monorepo/releases/tag/v2.0.0-beta.2)；插件的变更见各插件发布页的说明。

## 回滚到 1.11 {#rolling-back}

请先在 [Discord](https://wcpos.com/discord) 上告诉我们；测试期间遇到的大多数问题都有比回滚更快的解决办法。

1. **回滚前先同步每台收银设备。** 2.0 收银设备尚未发送的内容会留在 2.0 本地数据库中，而 1.11 应用永远不会打开该数据库。
2. 重新安装 1.11 插件：免费版可从 [WordPress.org](https://wordpress.org/plugins/woocommerce-pos/) 或[旧版本](/getting-started/previous-versions)获取，Pro 从 [wcpos.com/account/downloads](https://wcpos.com/account/downloads) 重新安装（列表中最新的 1.11 版本）。
3. 在安装过测试版的设备上重新安装 1.11 桌面应用。2.0 应用无法连接到 1.11 插件。
4. 1.11 收银设备会从空的本地数据库开始，并从站点重新同步。在 2.0 上创建的订单是普通的 WooCommerce 订单，会保持原样；在 2.0 上记录的收银会话和结算记录仍保留在数据库中，但 1.11 不会显示它们。

## 报告发现的问题 {#reporting}

在 [wcpos/roadmap](https://github.com/wcpos/roadmap/issues/new) 上提交一个带有 `beta` 标签的 issue，或联系[支持团队](https://wcpos.com/support)。请说明是哪个部分（插件、桌面端、iOS、Android、浏览器）、版本号、您做了什么、预期结果以及实际发生了什么；附上截图或屏幕上显示的错误代码会很有帮助。如果是销售或付款方面的问题，请附上订单号。
