为确保 WCPOS 插件正常运行并获得最佳性能，请确认环境满足以下最低要求：

## 服务器要求 {#server-requirements}

WCPOS 插件运行在 WordPress 站点上，该站点必须满足以下最低要求：

| 组件        | 最低版本        | 备注            |
| ----------- | --------------- | --------------- |
| WordPress   | 5.6             | —               |
| WooCommerce | 5.3             | —               |
| PHP         | 7.4             | 推荐使用 8.x    |

满足这些最低要求可确保与 WordPress 环境的兼容性和稳定性，并可使用最新的 WCPOS 功能。

## 浏览器要求 {#browser-requirements}

POS 的网页版可在任何现代浏览器中运行。请使用最新的稳定版本：

| 浏览器         | 支持的版本 |
| --------------- | ----------------- |
| Google Chrome 浏览器   | 最新稳定版     |
| Mozilla Firefox 浏览器 | 最新稳定版     |
| Safari 浏览器          | 最新稳定版     |
| Microsoft Edge 浏览器  | 最新稳定版     |

:::warning 避免使用隐私/无痕浏览模式
隐私浏览模式可能会阻止访问浏览器的本地存储，而 WCPOS 使用它来离线存储数据——部分功能将无法正常工作。同时还必须启用 JavaScript。
:::

## 应用要求 {#app-requirements}

WCPOS 还提供桌面端和移动端应用。各应用所需的最低操作系统版本如下：

| 平台        | 最低操作系统                | 架构              |
| --------------- | ------------------------- | -------------------------- |
| Windows 桌面版 | Windows 10                | x64、ARM64                 |
| macOS 桌面版   | macOS 12（Monterey）       | Intel（x64）、Apple Silicon |
| Linux 桌面端   | 当前 64 位发行版 | x64                     |
| iOS / iPadOS    | iOS 16.4                  | —                          |
| 安卓         | 安卓 10（API 级别 29） | —                          |

:::note 打印权限
蓝牙和网络打印需要在提示时授予应用相关的蓝牙和本地网络权限。
:::

## 安装插件 {#installing-the-plugin}

WP Admin 中的 **添加插件** 会从 WordPress.org 安装最新版 WCPOS，正式发布后即为 2.0。若要安装 WCPOS 1.x，请改为上传最新的 1.11 版本：

1. 在 WordPress.org 上打开 [WCPOS 高级视图](https://wordpress.org/plugins/woocommerce-pos/advanced/)。
2. 向下滚动到 **高级选项**。在 **以前的版本** 下选择最新的 **1.11** 版本，然后点击 **下载**。请勿解压 `.zip` 文件。
3. 前往 **WP Admin → 插件**，点击页面顶部的 **添加插件**，然后点击 **上传插件**。
4. 选择 `.zip` 文件，点击 **立即安装**，然后点击 **启用插件**。
5. 请保持 WCPOS 的自动更新关闭，否则 WordPress 会自动将其更新到 2.0。在 **插件** 页面上，自动更新关闭时，WCPOS 行的 **自动更新** 列会显示 **启用自动更新**。

如需安装 WCPOS Pro，或替换已安装的版本，请参见[旧版本](./previous-versions.mdx)。

## 访问 POS {#accessing-the-pos}

激活后，可通过以下方式访问 POS：

- **网页端：** `yourdomain.com/pos`
- **桌面端：** [Windows](https://updates.wcpos.com/v1/electron/download/win32-x64)、[Mac（Intel）](https://updates.wcpos.com/v1/electron/download/darwin-x64)、[Mac（Apple Silicon）](https://updates.wcpos.com/v1/electron/download/darwin-arm64)、[Linux](https://updates.wcpos.com/v1/electron/download/linux-x64)
- **移动端：** [iOS](https://testflight.apple.com/join/JGBdVRrW)、[安卓](https://play.google.com/apps/testing/com.wcpos.main)

满足最低要求并使用兼容的网页浏览器，即可顺畅使用 WCPOS 插件，并充分发挥其功能，高效管理销售点运营。
