:::info Pro 功能
[WCPOS Pro](https://wcpos.com/pro) 是一款付费插件，用于支持 WCPOS 中的管理界面、其他支付网关以及仅 Pro 可用的功能。

**自 v1.8+ 起，Pro 是独立插件** —— 你无需在其旁边同时安装免费的 [WCPOS 插件](https://wordpress.org/plugins/woocommerce-pos/)。
:::

## Pro 包含哪些功能？ {#whats-included-in-pro}

WCPOS Pro 解锁以下附加功能：

- **产品界面** - 直接在 POS 中编辑库存水平和价格
- **订单界面** - 查看和管理订单历史记录
- **客户界面** - 添加和编辑客户信息
- **报告界面** - 生成日终销售报告
- **其他支付网关** - Stripe Terminal、SumUp 和自定义网关

## 安装 {#installation}

如果你已购买 WCPOS Pro 许可证，请按照以下步骤安装并激活插件：

:::note 从旧版本升级？
如果你之前同时安装了免费的 WCPOS 插件和旧版 Pro 附加组件，请在启用新的独立版 Pro 插件前**停用并删除免费插件**。同时运行这两个插件可能导致激活错误，例如 *"Invalid response fetching remote state"* 或致命的 *"Class not found"* 错误。
:::

1. 前往：[https://wcpos.com/account/downloads](https://wcpos.com/account/downloads)
2. 在 **Downloads** 下，点击下载链接并将插件保存到桌面。
3. 然后前往你的站点并登录，打开 `WP Admin > 插件 > Add Plugin > 上传插件`
4. 上传桌面上的插件 zip 文件并启用。
5. 接着前往 `WP Admin > POS > 设置 > License`，输入你的许可证密钥（可在[许可证页面](https://wcpos.com/account/licenses)查看）和许可证邮箱，以完成激活。

## 更新 {#updates}

有新版本时，它们会像其他插件一样显示在你的“更新”仪表盘中。你也可以从[账户页面](https://wcpos.com/account/downloads)下载最新版本。

## 卸载 Pro 与你的数据 {#uninstalling}

卸载 Pro 插件会移除 Pro 自身的运行数据，但会**保留你的 Pro 设置（包括许可证密钥）和店铺配置**，因此重新安装后可从原处继续使用。只有在**免费**插件也卸载后，共享翻译数据才会被移除；因此，仅卸载 Pro 不会影响免费插件。

如果你确实希望彻底清除数据——包括设置、许可证和店铺配置——请在卸载前定义 `wcpos_remove_all_data`，选择完全清除。否则，卸载过程安全且可恢复。

## 故障排除 {#troubleshooting}

### 激活失败 {#activation-failures}

- **"许可证密钥无效"** — 粘贴时请检查末尾是否有空格，并确认邮箱地址与购买时使用的邮箱一致。
- **"已达到许可证限制"** — 默认情况下，一个许可证可在 **2 个域名**上激活（适用于一个正式站点和一个暂存站点）。请注意，**子域名也分别计为独立激活** — `example.com`、`staging.example.com` 和 `dev.example.com` 会计为三个。这种情况常见于 Pantheon 等强制使用开发、测试和正式环境的托管服务商。请在[账户页面](https://wcpos.com/account/licenses)停用不再使用的站点，或发送邮件至 **support@wcpos.com** — 可按需申请额外激活名额，通常都会获批。

### 许可证已过期 {#expired-licence}

- 许可证过期后，Pro 功能仍会保持启用，但你将无法收到更新。
- 请从[账户页面](https://wcpos.com/account/licenses)续订 — 现有密钥保持不变。

### 域名转移 {#domain-transfers}

- 如果你已将站点迁移到新域名，请先在旧域名上停用许可证，然后在新域名上重新激活。
- 如果无法再访问旧域名，请联系 **support@wcpos.com** 重置激活状态。

### 许可证服务器连接 {#licence-server-connectivity}

- 激活需要你的 WordPress 服务器能够连接到 WCPOS 许可证服务器。
- 如果激活失败但没有显示错误，请检查托管服务商的防火墙或安全插件是否阻止了外发 HTTPS 请求。
- 某些托管服务默认会阻止外部 API 调用 — 请联系你的服务商，将 `wcpos.com` 加入允许列表。

### 检查许可证状态 {#checking-licence-status}

- 前往 `WP Admin > POS > 设置 > License` 查看当前激活状态。
- 你的[账户页面](https://wcpos.com/account/licenses)会显示所有已激活的站点及其到期日期。

## 购买许可证 {#purchase-a-license}

访问 [wcpos.com/pro](https://wcpos.com/pro) 购买 Pro 许可证。

:::note 购买和升级请在网站上进行
应用内没有“升级到 Pro”按钮 — 所有购买、套餐升级和续订均通过 [wcpos.com](https://wcpos.com/pro) 和你的[账户页面](https://wcpos.com/account/licenses)办理。购买后，请按照[上述步骤](#installation)安装 Pro。
:::
