WCPOS 是适用于 WooCommerce 的销售点系统（POS）。它可在网页浏览器中运行，也可作为 Windows、macOS 或 Linux 桌面应用运行；iOS 和 Android 应用目前处于测试阶段。它使用与你的网店相同的商品目录、库存和价格，并将每笔销售记录为 WooCommerce 订单。免费插件支持现金和外部银行卡付款，并可打印收据；WCPOS Pro 还提供集成读卡器、退款、库存编辑、订单历史记录、报表和多店铺功能。

截至 2025 年 11 月，该插件在 wordpress.org 上以 WooCommerce POS 的名称列出；插件 slug 仍为 `woocommerce-pos`，较早的评论、论坛帖子和教程中也会使用这个名称。

本页回答人们安装前常问的问题：它适合哪些人、哪些人不适合，需要什么、费用多少，以及它与其他方案相比如何。

## WCPOS 适合哪些人 {#who-its-for}

WCPOS 适合已经在 WooCommerce 上销售，并希望使用相同库存进行线下销售的商家。

- **同时经营网店的商店、柜台、集市摊位或快闪店。** 无论销售发生在网站还是收银台，都使用同一商品目录、同一库存数量和同一订单列表。
- **希望将销售数据保存在自有数据库中的店铺。** WCPOS 是 WordPress 插件；订单、顾客和商品都保留在你的 WooCommerce 安装中，而不是存放在第三方服务里。
- **电话订购或批发业务柜台。** 查找现有顾客、为其创建订单并收取现金或银行卡付款，也可以使用 Pro 发送[电子邮件发票](/payment/gateways/email-invoice)。
- **拥有多台收银机或多个营业地点的商家。** 每台设备都会保留自己的商品目录本地副本；Pro 可添加[多个店铺](/stores)，每个店铺都可使用自己的收据、税号和品牌标识；除非添加 [ATUM](/extensions/atum) 来管理各地点的库存，否则各店铺共用库存。

## WCPOS 不适合哪些人 {#who-its-not-for}

- **你没有使用 WooCommerce。** WCPOS 需要安装了 WooCommerce 的 WordPress 网站。它不能与 Shopify、Magento 或独立网店搭配使用。
- **你现在就需要通过认证的税务合规方案。** WCPOS 未通过法国 NF525、西班牙 VERIFACTU 或类似认证。[税务合规](/reference/fiscal-compliance)说明了各国目前的情况；如果认证是硬性要求，则没有变通办法。
- **你必须在完全没有网络连接时完成每笔销售。** 完成销售需要连接到你的店铺：你可以浏览商品、创建购物车并离线保存订单，但必须等到重新联网后才能进行付款。请参阅[离线模式](/getting-started/offline)；离线完成现金销售已列入[路线图](/getting-started/roadmap)。
- **你需要自助服务终端或供应商提供的硬件套装。** WCPOS 可在你已有的硬件上运行；它没有自助服务终端模式，也不销售支付终端或平板电脑。

## 所需条件 {#what-you-need}

| 要求 | 最低版本 |
|---|---|
| WordPress | 5.6 |
| WooCommerce | 5.3 |
| PHP | 7.4（建议使用 8.x） |
| 设备 | 任意现代浏览器，或适用于 Windows、macOS 或 Linux 的桌面应用；iOS 和 Android 应用目前处于测试阶段 |

收据打印机、条码扫描器和钱箱均为可选设备。请参阅[安装要求](/getting-started/installation)和[硬件](/hardware)。

## 费用 {#what-it-costs}

- **WCPOS（免费插件）：**$0。根据 GPL-3.0 开源，可从 [WordPress 插件目录](https://wordpress.org/plugins/woocommerce-pos/)安装。它可处理交易、打印收据并将订单同步到 WooCommerce，WCPOS 不收取交易费。
- **WCPOS Pro：** 每个网站每年 $129，或每个网站一次性支付 $399 获取永久许可证。两种许可方案都在许可期限内包含更新和支持。请参阅[Pro 许可证](/getting-started/pro-license)了解激活方式，并参阅[免费版与 Pro 版](/getting-started/free-vs-pro)查看完整功能表。

价格截至 2026 年 5 月，可能会有变动。银行卡处理费由你的支付网关设定，而非 WCPOS。

## 对比情况 {#how-it-compares}

[wcpos.com/compare](https://wcpos.com/compare) 提供了 WooCommerce 主要销售点方案的逐项对比：[Oliver POS](https://wcpos.com/compare/oliver-pos)、[WooCommerce 官方 POS](https://wcpos.com/compare/woocommerce-pos)、[Square](https://wcpos.com/compare/square)、[Jovvie](https://wcpos.com/compare/jovvie)、[Vitepos](https://wcpos.com/compare/vitepos)、[YITH Point of Sale](https://wcpos.com/compare/yith-pos) 和 [FooSales](https://wcpos.com/compare/foosales)。每篇对比均由 WCPOS 的开发者撰写，依据其他供应商自己的定价页面和 wordpress.org 信息，并标注日期，同时说明何时其他产品会是更好的选择。

## 试用 {#try-it}

[演示店铺](https://demo.wcpos.com/pos)运行的是 WCPOS Pro，登录账号为 `demo` / `demo`，因此也能展示 Pro 专属界面。在已运行 WooCommerce 的网站上安装免费插件大约需要五分钟。
