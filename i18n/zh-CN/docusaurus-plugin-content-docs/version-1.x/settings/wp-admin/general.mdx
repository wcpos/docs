## 启用仅限 POS 的产品 {#enable-pos-only-products}

此设置为产品添加可见性选项，让您控制产品在在线商店、POS 或两者中显示。

:::warning 性能影响
仅在需要从在线商店或 POS 中隐藏产品时启用此设置。启用后，每个产品请求都会增加一次数据库查询。
:::

有关此功能的详细用法，包括设置单个产品的可见性和批量编辑，请参见[仅限 POS 的产品](/1.x/products/pos-only-products)。

## 启用小数数量 {#enable-decimal-quantities}

此设置允许客户和员工在将产品加入购物车时输入小数数量。

**小数数量示例：**
- 0.25（四分之一单位）
- 1.5（一个半单位）
- 2.75（两个又四分之三单位）

**适用于：**
- 按重量销售的产品（例如 0.5kg 咖啡豆）
- 按非整数数量计费的服务（例如 1.5 小时咨询）
- 可按部分数量销售的散装产品

:::note 按重量销售
WCPOS 不会连接称重秤，也不会读取秤上的重量。请先称量商品，再将重量输入为购物车中该行的数量：对于按千克定价的产品，350 g 对应的数量为 `0.35`。请先启用此设置，否则店铺会拒绝包含小数数量的订单。

WCPOS 也不会读取某些称重秤打印的条形码标签中编码的重量或价格。
:::

## 删除订单时恢复库存 {#restore-stock-on-order-delete}

启用后，当 POS 订单被移入回收站或删除时，WCPOS 会自动恢复产品库存，因此取消误操作产生的销售订单会将商品补回库存。此设置 **默认开启**。

如果您通过其他方式核对库存，不希望删除 POS 订单时调整库存，请关闭此设置。

## 从客户电子邮件自动生成用户名 {#automatically-generate-username-from-customer-email}

启用后，WCPOS 会在结账时根据新客户的电子邮件地址自动生成用户名，简化客户创建流程，并确保用户名格式一致。

## 默认 POS 客户 {#default-pos-customer}

选择要分配给新 POS 订单的默认客户。常见选项包括：

- **访客**：订单不与任何用户帐户关联
- **收银员**：订单与当前登录的收银员帐户关联
- **进店客户**：订单与指定的客户帐户关联（需先创建此帐户）

## 使用收银员帐户 {#use-cashier-account}

启用后，POS 订单将使用收银员的用户帐户作为默认客户，替代所选的默认 POS 客户。

## 让客户下载收据 {#storefront-receipts}

启用后，WCPOS 会在在线商店的 **我的账户 → 订单** 中添加 **收据** 按钮，让客户可以下载用 WCPOS 模板生成的订单收据 PDF。此设置 **默认关闭**。

开关下方的 **客户收据模板** 下拉菜单用于选择客户使用的模板。默认为 **使用启用的收据模板**，与 POS 保持一致；也可选择特定模板，让在线订单采用不同的外观（例如整页发票）。

完整指南请参见[在线商店收据](/1.x/receipts/storefront)，其中包括适用的订单状态、`[wcpos_receipt]` 短代码以及开发者过滤器。

## 条形码字段 {#barcode-field}

此设置决定 WCPOS 扫描条形码或使用条形码搜索功能时搜索哪个产品字段。

<a id="default-option"></a>

:::note 默认元键
请使用 **`_global_unique_id`**——WooCommerce 的全局唯一 ID 字段，于 WooCommerce 9.2（2024 年 8 月）推出。该字段专为存储 GTIN、UPC、EAN 或 ISBN 编码而设计，是新安装的推荐选项。如果您未使用全局唯一 ID 字段，**`_sku`**（产品 SKU／库存单位字段）是一个不错的备用选项。
:::

### 常见插件 → 元键 {#common-plugins-meta-key}

如果您使用条形码管理插件，可能需要改用该插件专用的元键：

| 插件 / 字段类型 | 元键 |
|---|---|
| WooCommerce 全局唯一 ID *（默认，推荐）* | `_global_unique_id` |
| 产品 SKU *（备用）* | `_sku` |
| EAN 插件（欧洲商品编号） | `_ean`、`_ean13`、`_ean8` |
| EAN for WooCommerce（WPFactory 的 EAN Barcode Generator） | `_alg_ean`，除非您在其高级设置中更改了 **元键** |
| UPC 插件（通用产品代码） | `_upc`、`_upc_code` |
| GTIN 插件（全球贸易项目编号） | `_gtin`、`_gtin13`、`_gtin14` |
| 通用条形码字段 | `_barcode`、`_product_barcode` |
| WooCommerce Product Barcodes | `_barcode_text` |
| ATUM Inventory | `_atum_barcode` |

<a id="custom-meta-keys"></a>

:::tip 自定义元键
您可以使用 **任何** 存储条形码数据的自定义元键。只需在此字段中输入元键名称（如有下划线前缀，也需包含在内）。
:::

### 查找插件的元键 {#finding-your-plugins-meta-key}

如果您的插件未列在上方，可按以下方式找到正确的元键：

<Steps>
  <StepCard number="1" title="为产品添加条形码">

在 WP Admin 中编辑产品，并使用您的插件添加条形码。

  </StepCard>
  <StepCard number="2" title="查看插件文档">

在插件文档中查找其使用的元键名称。

  </StepCard>
  <StepCard number="3" title="或检查数据库" isLast>

检查数据库的 `wp_postmeta` 表，查看为该产品创建了哪个元键。

  </StepCard>
</Steps>

:::note 更改此设置会重建条形码索引
更改条形码字段后，WCPOS 会重建本地产品目录的条形码索引，让扫描结果匹配新选定的字段，无需手动清除并重新下载产品。

如果扫描结果仍不匹配，可以强制完整刷新：前往产品页面，**长按** 底部的同步图标（↻），然后选择 **“清除并刷新”**。接着进行扫描测试，确认正在使用新字段。
:::

## 隐私 {#privacy}

**允许匿名使用数据** 开关控制 WCPOS 是否收集匿名使用分析数据，以帮助改进产品。您可自由选择加入或退出，系统绝不会收集客户数据、价格或店铺地址。通过设置旁边的 **了解更多** 链接，可以查看具体收集和不收集哪些内容。

## 店铺税号 {#store-tax-ids}

添加企业税务标识符，例如 VAT 号、ABN、GSTIN、EIN 或当地公司注册号，WCPOS 会将其打印在 POS 收据和发票上。WooCommerce 没有这些信息的内置字段，而许多地区需要填写不止一个标识符。

完整指南请参见[店铺税号](/1.x/settings/wp-admin/store-tax-ids)。

## 客户税号 {#customer-tax-ids}

WCPOS 在客户记录中保留税号字段，并在结账时将其复制到订单上。由于不同插件使用不同的字段名存储税号，WCPOS 会检测已安装的插件，并自动写入正确的字段。此处的 **税号** 部分也允许您按需覆盖字段名。

完整指南请参见[客户税号](/1.x/settings/wp-admin/customer-tax-ids)。
