WCPOS 让您可以逐项控制 POS 订单触发哪些 WooCommerce 通知电子邮件，独立于站点级的 WooCommerce 电子邮件设置。您还可以通知处理该笔销售的 **收银员**。

这些设置位于 **收银台** 页面，请前往 **WP Admin > POS > 设置 > 收银台**。电子邮件控件位于订单状态和支付网关部分的上方。

:::info 关于 POS 订单电子邮件
WooCommerce 的默认电子邮件触发器并不总能正确处理 POS 订单，因为 POS 使用了 WooCommerce 无法识别的自定义状态，例如 *POS - 未结账* 和 *POS - 部分付款*。当订单从这些状态之一转为已完成、处理中或暂时保留时，WCPOS 会手动重新触发新订单电子邮件，因此无论订单经历怎样的结账流程，您都能可靠地收到通知。
:::

## 三个电子邮件组 {#the-three-email-groups}

每个组的顶部都有一个 **主开关**。打开时，下方会出现复选框列表，供您分别启用或禁用各类电子邮件。关闭时，POS 订单不会发送该组中的任何电子邮件，无论各项复选框是否勾选。

### 管理员电子邮件 {#admin-emails}

*“针对 POS 订单的 WooCommerce 管理员通知电子邮件”*——**默认开启。**

发送至 **WooCommerce → 设置 → 电子邮件 →（电子邮件类型）→ 收件人** 中配置的地址。

| 电子邮件 | 默认 | 发送时机 |
|---|---|---|
| **新订单** | ✓ 已勾选 | POS 订单进入处理中 / 已完成 / 暂时保留状态 |
| **已取消订单** | ✓ 已勾选 | POS 订单被取消 |
| **失败订单** | ✓ 已勾选 | POS 订单失败（网关错误等） |

### 客户电子邮件 {#customer-emails}

*“针对 POS 订单的 WooCommerce 客户通知电子邮件”*——**默认开启。**

发送至客户的账单电子邮件地址，仅对关联了客户的订单触发（访客销售会被跳过，不作提示）。

| 电子邮件 | 默认 | 发送时机 |
|---|---|---|
| **订单暂时保留** | ✓ 已勾选 | POS 订单进入暂时保留状态 |
| **处理中订单** | ✓ 已勾选 | POS 订单进入处理中状态 |
| **已完成订单** | ✓ 已勾选 | POS 订单完成 |
| **已退款订单** | ✓ 已勾选 | POS 订单退款（全额或部分） |
| **失败订单** | ✓ 已勾选 | POS 订单失败 |

### 收银员电子邮件 {#cashier-emails}

*“向处理该 POS 订单的收银员发送新订单通知”*——**默认关闭。**

| 电子邮件 | 默认 | 发送时机 |
|---|---|---|
| **新订单** | ✓ 已勾选 *（主开关打开时）* | 该收银员完成 POS 订单 |

WCPOS 通过订单的 `_pos_user` 元数据识别收银员（登录收银台的 WP 用户），并读取其账户电子邮件地址。如果收银员与管理员的电子邮件地址相同，例如店主同时担任管理员和收银员的店铺，WCPOS 会对收件人 **去重**，避免您收到两封相同的电子邮件。

管理员和收银员开关 **独立** 运作，关闭其中一个不会影响另一个。

## 常见场景 {#common-scenarios}

<Accordion>
  <AccordionItem question="避免繁忙时段的通知邮件塞满收件箱">

如果店铺每天有 50+ 笔销售，而管理员不需要收到每笔销售的通知，请关闭 **管理员电子邮件 → 新订单**。保持 **已取消订单** 和 **失败订单** 开启，这些才是需要关注的通知。

跟踪营收时，使用[报表](/1.x/reports)页面比清点新订单电子邮件更合适。

  </AccordionItem>

  <AccordionItem question="只通知值班收银员，不通知管理员">

关闭 **管理员电子邮件** 主开关，并打开 **收银员电子邮件** 主开关。完成每笔销售的收银员会通过个人账户的电子邮件地址收到新订单通知，而管理员收件箱不会收到这些通知。

这适用于有多位收银员、且店主不需要了解每笔交易的店铺。

  </AccordionItem>

  <AccordionItem question="为店内销售禁用客户电子邮件">

游客众多的店铺、集市摊位和提供快捷服务的咖啡馆通常无需向客户发送收据邮件，因为客户已经拿到了打印的收据。关闭 **客户电子邮件** 主开关后，POS 销售就不会发送任何处理中 / 已完成 / 已退款电子邮件。

这不会影响在线订单的客户电子邮件，因为这些订单通过标准 WooCommerce 流程处理，而非 POS 流程。

  </AccordionItem>

  <AccordionItem question="保持客户电子邮件开启，但关闭“处理中”邮件">

如果 POS 订单即时完成（现金 + 当面刷卡），客户会在同一秒内收到一封 *处理中* 电子邮件 *和* 一封 *已完成* 电子邮件。在客户电子邮件列表中取消勾选 **处理中订单**，即可去掉多余的那封。

  </AccordionItem>

  <AccordionItem question="从 v1.8.9 之前的版本升级后，原来的单个“启用电子邮件”开关消失了">

早期版本的单个开关已被上述三组结构取代。WCPOS 会自动迁移旧设置：如果之前关闭了电子邮件，三个主开关都会关闭；如果之前开启了电子邮件，管理员和客户主开关会开启，收银员主开关则关闭（新的默认值）。

您无需执行任何操作；升级后打开收银台设置页面时，迁移会自动运行。

  </AccordionItem>
</Accordion>

## 开发者钩子 {#developer-hooks}

如需在 UI 之外通过代码控制，可使用以下 WordPress 过滤器：

| 过滤器 | 用途 |
|---|---|
| `woocommerce_pos_admin_email_enabled` | 覆盖管理员主开关 |
| `woocommerce_pos_customer_email_enabled` | 覆盖客户主开关 |
| `woocommerce_pos_admin_emails` | 过滤已启用的管理员电子邮件列表 |
| `woocommerce_pos_customer_emails` | 过滤已启用的客户电子邮件列表 |

收银员通知通过 WooCommerce 现有的 `woocommerce_email_recipient_new_order` 过滤器接入，因此针对收件人的覆盖设置（例如抄送其他地址）与其他 WooCommerce 电子邮件的工作方式相同。
