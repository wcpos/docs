这些设置用于配置 POS 应用程序的后端功能，包括 PHP 和 WooCommerce 配置。你可以通过导航到 `WP Admin > POS > 设置` 来访问它们。

## 设置概览 {#settings-at-a-glance}

| 设置 | 作用 | 了解更多 |
|---|---|---|
| **常规** | 所有收银员的默认购物车客户、仅限 POS 的产品、小数数量以及产品条码字段。 | [常规设置](./general.mdx) |
| **收银台** | POS 中可用的支付网关，以及 POS 订单的处理方式。 | [收银台设置](./checkout.mdx) |
| **邮件通知** | 按邮件分别设置管理员、客户和收银员开关，以控制哪些 WooCommerce 邮件会针对 POS 订单发送。 | [邮件通知](./email-notifications.mdx) |
| **访问权限** | 用户角色和功能权限，用于控制谁可以使用 POS，包括专用的收银员角色。 | [访问 POS](./access.mdx) |
| **会话** | 查看每位用户和设备的活跃 POS 登录会话，并可远程将设备登出。 | [会话](./sessions.mdx) |
| **店铺税号** | 打印在收据和发票上的企业税务标识符（VAT、ABN、GSTIN、EIN、公司注册编号）。 | [店铺税号](./store-tax-ids.mdx) |
| **客户税号** | 了解客户税号的存储方式、写入的插件字段，以及结账时如何复制到订单中。 | [客户税号](./customer-tax-ids.mdx) |
