店铺设置是影响 POS 运行方式的全应用配置。这些设置适用于整个店铺，而非单个屏幕。

## 访问店铺设置 {#accessing-store-settings}

通过以下方式打开店铺设置：

- 点击**用户菜单**（右上角），然后选择**设置**
- 使用键盘快捷键 `Ctrl + Shift + S`

设置会在**侧边面板**中打开，而不是弹出窗口，因此调整设置时仍可查看当前销售。[店铺健康状况](/support/store-health)也会以相同方式打开。

## 设置选项卡 {#settings-tabs}

店铺设置面板包含以下选项卡：

| 选项卡 | 描述 |
|-----|-------------|
| [常规](./general.mdx) | 商店信息、语言、货币、默认客户 |
| [税收](./tax.mdx) | 税收计算和显示选项 |
| [条形码](./barcode.mdx) | 条形码扫描器配置 |
| [键盘快捷键](./hotkeys.mdx) | 可用的键盘快捷键 |
| [主题](./theme.mdx) | 外观和颜色方案 |
| [打印机](/hardware/printers) | 收据打印机的连接和配置 |
