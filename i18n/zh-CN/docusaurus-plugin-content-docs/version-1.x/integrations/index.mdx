WCPOS 基于 WooCommerce REST API 运行，因此大多数 WooCommerce 插件无需额外设置即可与 POS 订单配合使用。少数插件需要 WCPOS 代为执行某些操作，因为它们仅挂接到在线结账流程或 WP Admin 订单页面。本节中的页面介绍这些插件：WCPOS 为其执行的操作、设置方法，以及在收银台中的预期表现。

这与[扩展](/extensions)不同：扩展是专为 WCPOS 构建的附加组件，可从扩展目录安装。集成则是已在网店中运行的插件。
