:::info 专业版功能
多店铺功能需要 [WCPOS Pro](/1.x/getting-started/pro-license)。未启用 Pro 时，WCPOS 会根据 WooCommerce 常规设置作为单个虚拟店铺运行，不会显示店铺管理界面。
:::

本页将完整介绍创建店铺的流程。如需了解多店铺的作用、按店铺定价和 ATUM 集成等基本概念，请先阅读[多店铺](/1.x/stores)。

## 开始之前 {#before-you-start}

- **已安装 WCPOS Pro 并激活许可证。** 激活 Pro 后，WP Admin 的 POS 菜单下会新增 **店铺** 子菜单。
- **在此店铺工作的收银员拥有 WordPress 账户**，且其角色包含 *访问 WCPOS* 权限。如尚未设置，请参阅[访问设置](/1.x/settings/wp-admin/access)。
- *（可选）* **准备好要上传的 Logo 文件** — PNG 或 JPG 格式，建议尺寸为 300×300 或更大。

## 创建店铺 {#create-the-store}

<Steps>
  <StepCard number="1" title="打开店铺列表">

在 WP Admin 中，前往 **POS → 店铺**。您会看到现有店铺列表，其中包含 **店铺**、**地址**、**授权用户** 列，以及每行的 **打开 POS** 按钮。

如果这是您的第一家店铺且刚刚激活 Pro，列表将为空。点击页面顶部的 **添加新店铺**。

  </StepCard>
  <StepCard number="2" title="命名店铺">

在编辑器顶部设置 **店铺名称**。该名称会显示在收据、登录时的店铺选择器以及 POS 各处的店铺筛选器中。这是必填项。

示例：*“街边咖啡馆”*、*“仓库 — 自提点”*、*“市集摊位 #3”*。

  </StepCard>
  <StepCard number="3" title="填写主栏内容">

编辑器左侧汇集了所有会显示在收据上的内容：

- **店铺 Logo** — 通过 WP 媒体库上传。如果站点已在自定义器中设置 Logo，且您希望将其作为后备选项，可以启用 *“未设置店铺 Logo 时使用站点 Logo”* 开关。
- **地址** — 地址 1、地址 2、城市、州/省、邮编、国家。国家下拉框支持边输入边搜索。
- **联系方式** — 网址、电话、邮箱。
- **收据信息** — *结束语*、*退换政策*、*页脚*。支持纯文本和简单 HTML（`<strong>`， `<em>`， `<b>`， `<i>`， `<br>`， `<p>`）。
- **收据模板** — 将 *“店铺专属收据模板”* 开关保持 **关闭**，即可沿用 **POS → 模板** 中的站点级模板列表；将其 **打开**，则可为此店铺选择一组自定义模板。选择自定义模板组后，即可通过拖拽手柄调整顺序。
- **收据预览** — 提供实时预览，配有模板选择器和示例数据 / 订单切换开关，让您在保存前查看收据的实际效果。

</StepCard>
  <StepCard number="4" title="配置侧边栏">

右侧栏包含不会显示在收据上的店铺专属配置：

- **授权用户** — 以复选框列表列出所有角色包含 *访问 WCPOS* 权限的 WordPress 用户。勾选允许登录此店铺的收银员。**列表留空表示所有具备 POS 权限的用户均获授权**，适合单店铺站点。
- **税率** — *计税依据* 下拉框：**本店铺地址** *（默认）* 或 **基准位置**。下方表格按税种显示所选地址对应的税率；该表只读，请在 **WooCommerce → 设置 → 税务** 中配置实际税率。
- **税号** — 可重复添加的行（类型 / 值 / 国家 / 标签），用于设置各店铺的 VAT、ABN、GSTIN 等。留空则使用站点级的[店铺税号](/1.x/settings/wp-admin/store-tax-ids)。
- **店铺设置** — 货币、货币符号位置、区域、时区。默认采用站点设置；仅当此店铺需要不同设置时才需覆盖。
- **营业时间** — 每日的时间段，以及可自由输入文本的备注字段。可选，部分模板会使用。

</StepCard>
  <StepCard number="5" title="保存" isLast>

新店铺在首次保存之前会一直显示 **创建** 按钮。点击 **创建**。

首次保存后，页面会切换为自动保存模式：编辑内容会在短暂延迟后自动保存，角落会显示 *正在保存… → 已保存* 状态。您可以随时离开页面，更改会保留；如果尝试在更改尚未保存时关闭页面，浏览器会发出警告。

  </StepCard>
</Steps>

## 收银员登录时看到的内容 {#what-cashiers-see-at-login}

收银员登录时，POS 会显示 **店铺选择器**，列出其获授权的所有店铺：

- **仅授权一家店铺** — 该店铺会自动选中，**打开 POS** 按钮立即可用。选择器仍会显示，以便收银员确认即将进入哪家店铺。
- **授权多家店铺** — 选择器显示单选列表。选择一家店铺，然后点击 **打开 POS**。
- **未授权任何店铺** — 选择器为空。请将该收银员添加到某家店铺的 *授权用户* 列表中，或将该列表留空以授权所有人。

POS 启动时，所选店铺会以 `?store={id}` 的形式附加到地址中，并记录在该会话期间提交的每一笔订单上（即 `_pos_store` 订单元数据）。按店铺报表、订单页面的店铺筛选器、收据上对应的 Logo 和地址，以及按店铺定价，都以此为基础。

## 按店铺定价 {#per-store-pricing}

WCPOS Pro 内置按店铺定价机制，独立于 ATUM。在每个商品（及变体）的编辑界面上，**价格** 和 **税务** 选项卡都会新增按店铺覆盖设置的选项：

1. 在 WP Admin → 商品 → 编辑中打开一个商品。
2. 在 **价格** 选项卡上，为需要覆盖价格的店铺勾选 *“设置店铺专属价格”* 复选框。
3. 输入该店铺的常规价格，以及可选的促销价。
4. 保存商品。

收银员在该店铺操作时，POS 会使用店铺专属价格。在没有覆盖设置的店铺操作时，则采用标准的 WooCommerce 价格。

同样的方式也适用于 **税务** 选项卡，可按店铺设置税务状态 / 税种。当一家店铺位于免税区而另一家不在时，这尤其有用。

:::tip ATUM 与原生按店铺定价
如果您希望不同店铺采用不同的货架价格，但 **共享** 库存，WCPOS 的原生按店铺定价就很合适。如果还需要 **按位置统计库存数量**，请安装 [ATUM Multi-Inventory](/1.x/extensions/atum) 集成。它会在店铺编辑器中新增 *库存位置* 下拉框和 *定价来源* 选择器（默认 / WCPOS Pro / ATUM），让您可以按店铺搭配使用这两套系统。
:::

## 特殊情况 {#edge-cases}

<Accordion>
  <AccordionItem question="添加新店铺时，已有订单会受到什么影响？">

不会受到影响。订单会在销售时记录 `_pos_store` 元数据。添加新店铺不会重新分配任何已有订单。在激活 Pro 之前（或在单店铺配置下）提交的订单没有 `_pos_store` 元数据，会继续使用站点级默认设置显示。

如果需要将已有订单重新分配到其他店铺，请在 WP Admin → WooCommerce → 订单中打开该订单，使用 Pro 在单个订单页面中新增的 **店铺** 下拉框。

  </AccordionItem>

  <AccordionItem question="如何删除店铺？">

店铺编辑器中的 **移至回收站** 按钮（以及店铺列表中的行操作）会执行 WordPress 软删除(`wp_trash_post`)。它不会永久删除店铺，因此：

- 该店铺会从收银员的店铺选择器和筛选下拉框中隐藏。
- 引用该店铺的已有订单仍可正确显示，以便重新打印收据和查看订单详情。已移入回收站的店铺名称、地址和 Logo 仍然可用。
- 从回收站还原后，店铺会恢复为可用状态，所有设置保持不变。

只有彻底删除（回收站 → 永久删除）才会移除店铺记录。引用已永久删除店铺的订单会改用 *“店铺 #ID”* 和站点级默认设置。

  </AccordionItem>

  <AccordionItem question="一名收银员可以在多家店铺工作吗？">

可以。在允许该收银员访问的每家店铺的 *授权用户* 列表中勾选其姓名即可。系统没有为每个用户设置“主店铺”的概念。每次登录时，收银员都通过选择器选择要在哪家店铺操作。

  </AccordionItem>

  <AccordionItem question="可以为不同店铺设置不同货币吗？">

在店铺侧边栏中设置 **货币** 和 **货币符号位置**。在该店铺打开的任何会话都会使用这些设置覆盖站点级的 WooCommerce 货币设置，收据、价格和总计金额都将按该店铺的货币格式显示。

这只影响显示格式；您仍需为每种货币配备兼容 WooCommerce 的支付网关，汇率处理也由您的店铺自行负责。

  </AccordionItem>

  <AccordionItem question="为什么安装 Pro 后没有出现店铺子菜单？">

有两个常见原因：

1. **Pro 未激活** — 前往 **WP Admin > POS > 设置 > 许可证**，确认许可证密钥显示为已激活。
2. **旧版免费版 + Pro 安装方式** — 在 v1.8 之前，Pro 是免费插件的附加组件。如果已升级到 v1.8+，需要停用并删除免费插件（请参阅[安装 WCPOS Pro](/1.x/getting-started/pro-license) 中的说明）。同时保留两者可能会导致店铺菜单不显示。

  </AccordionItem>
</Accordion>
