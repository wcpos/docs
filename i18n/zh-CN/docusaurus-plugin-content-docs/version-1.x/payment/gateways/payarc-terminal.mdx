# PayArc Terminal 支付网关 {#payarc-terminal-gateway}

PayArc Terminal 网关可让您通过 PayArc Connect，在 WCPOS 中使用 PayArc PAX 终端收取现场付款。付款从 WooCommerce 发起，并在终端上完成；只有 PayArc 确认付款后，订单才会标记为已付款。

## 功能 {#features}

<FeatureGrid>
  <FeatureCard icon="credit-card" title="PAX 终端集成">
    通过云端 PayArc Connect 向 PayArc PAX 终端发送付款，无需在本地配对
  </FeatureCard>
  <FeatureCard icon="shield" title="验证付款完成">
    完成付款前，金额和币种必须与订单一致；卡品牌、刷卡方式和卡号后 4 位会保存到订单中
  </FeatureCard>
  <FeatureCard icon="file-lines" title="明确的付款拒绝原因">
    付款被拒的原因会显示给收银员，并添加为订单备注
  </FeatureCard>
  <FeatureCard icon="receipt" title="终端收据">
    可在终端上打印商户收据、顾客收据或两者
  </FeatureCard>
  <FeatureCard icon="bolt" title="内置诊断">
    使用 **验证设置** 按钮和显示脱敏标识符的诊断表检查连接
  </FeatureCard>

## 工作原理 {#how-it-works}

WordPress 会调用 **PayArc Connect**，然后由 PayArc 连接 PAX 终端。POS 只与您的网站通信。每笔付款都会收取**完整订单总额**。

付款页面每 **1.5 秒**检查一次结果，并在 **5 分钟**后停止。PayArc 向 **Webhook URL** 发送回调可以加快结果返回；即使没有回调，付款仍会通过轮询完成。顾客在终端上付款时，请保持付款页面打开。

## 设置 {#setup}

<Steps>
  <StepCard number="1" title="安装 PayArc Terminal for WooCommerce">

从 `WP Admin > POS > 设置 > 扩展` 安装，或从 [GitHub 发布页面](https://github.com/wcpos/payarc-terminal-for-woocommerce/releases) 下载 **payarc-terminal-for-woocommerce.zip** 文件，然后通过 `插件 > 新增 > 上传插件` 上传。激活插件。

  </StepCard>
  <StepCard number="2" title="输入 PayArc 凭据">

1. 前往 `WP Admin > WooCommerce > 设置 > 支付`，然后打开 **PayArc Terminal**
2. 选择 **模式**：默认值为 `Live`。只有使用 PayArc 测试仪表板凭据和 PayArc Connect Test 应用时才选择 `Test`。切勿混用不同环境的凭据。
3. 输入 **PayArc 登录邮箱**，即用于登录 PayArc 商户仪表板的邮箱
4. 输入 PayArc Merchant Profile 中的 **PayArc MID**，不要使用终端 ID
5. 输入仪表板 API 区域中的 **PayArc ClientSecret**，以及 PayArc 仪表板中的 **PayArc SecretKey / API 持有者令牌**
6. 除非 PayArc 支持人员提供了 **回调持有者令牌**，否则请留空；此项为可选

  </StepCard>
  <StepCard number="3" title="连接">

点击 **使用这些凭据连接**。连接成功后，屏幕会提示您输入或确认终端序列号并保存设置。如果提示凭据似乎属于另一个环境，请切换 **模式** 后重新连接。

:::note
每次更改模式或凭据后，都要再次点击 **使用这些凭据连接** 并保存。模式和凭据与已保存的连接不匹配时，付款会被阻止。如果您从 0.1.14 之前的版本升级，请点击一次连接按钮。
:::

  </StepCard>
  <StepCard number="4" title="添加终端">

1. 输入 PAX **终端序列号**，即设备背面 **S/N** 标签上的号码，并确保 PayArc 已为您的账户配置该终端
2. 选择 **付款类型** 和 **打印收据**
3. 确认 **Webhook URL** 使用 HTTPS。仅在 PayArc 要求时提供此 URL
4. 点击 **保存更改**

实时模式需要使用 HTTPS 网站。

  </StepCard>
  <StepCard number="5" title="在 WCPOS 中启用" isLast>

1. 前往 `WP Admin > POS > 设置 > 结账`
2. 找到 **PayArc Terminal** 网关，并为 POS 启用
3. 保存设置

:::note
WooCommerce 设置页面上的 **启用/禁用** 复选框仅控制*在线店铺*结账。配置完成后，无论是否勾选此项，WCPOS 都会使用该网关。

大多数店铺都不勾选此项。
:::

  </StepCard>
</Steps>

## 设置参考 {#settings}

| 设置 | 功能 |
|---|---|
| **启用/禁用** | 启用 PayArc Terminal 在线店铺结账。默认关闭；POS 是否启用由 `POS > 设置 > 结账` 中的设置控制 |
| **标题** | 结账时显示的标签；默认为 `PayArc Terminal` |
| **描述** | 结账说明；默认为 `Pay in person at a PayArc PAX terminal.` |
| **模式** | `Live`（默认）或 `Test`。测试模式需要 PayArc 测试仪表板凭据和 PayArc Connect Test 应用 |
| **PayArc 登录邮箱** | 您的 PayArc 商户仪表板登录邮箱；连接前必须填写 |
| **PayArc MID** | PayArc Merchant Profile 中的商户 MID，不是终端 ID |
| **PayArc ClientSecret** | 仪表板 API 区域中的密钥；仅存储在您的服务器上 |
| **PayArc SecretKey / API 持有者令牌** | PayArc 仪表板中的令牌，用于登录并获取终端注册信息 |
| **回调持有者令牌** | 可选。只有 PayArc 支持人员提供时才填写 |
| **PayArc 连接** | **使用这些凭据连接**、**刷新终端** 和 **断开连接** 按钮 |
| **终端序列号** | 分配给您账户的 PAX S/N，付款所必需。如果在注册信息中找到该号码，会自动填入；保存前请填写或确认 |
| **付款类型** | `CREDIT`（默认）或 `DEBIT` |
| **打印收据** | `0` — 不打印（默认），`1` — 商户收据，`2` — 顾客收据，`3` — 两者都打印 |
| **Webhook URL** | 只读回调地址。确认其使用 HTTPS；仅在 PayArc 要求时提供 |
| **PayArc 诊断** | 连接信息和 **验证设置** 按钮；不会显示密钥 |

已保存的密钥字段只显示最后 4 个字符。将密钥字段留空可保留已保存的值。

**PayArc 诊断** 表会显示模式、端点、已脱敏的 MID / 租户 ID / 序列号、Connect 访问令牌是否已配置、Webhook URL、最近一次回调和最近一次 PayArc 错误。使用 **验证设置** 检查设置。

## 使用方法 {#usage}

### 处理付款 {#processing-payments}

1. **选择网关**：在 POS 中选择 **PayArc Terminal** 作为付款方式
2. **发起付款**：点击 **发起付款**，将订单总额发送到终端
3. **顾客付款**：顾客在 PAX 终端完成付款时，请保持页面打开。请留意状态消息：`Starting terminal payment...` → `Payment sent to terminal.` → `Waiting for the terminal result...` → `Payment approved. Completing the order...`
4. **自动完成**：PayArc 确认付款后，订单会自动完成

### 付款控制 {#payment-controls}

- 付款开始后会显示 **取消付款**。如果 PayArc 尚未返回追踪 ID，请稍等片刻再取消
- 付款被拒、取消或超时后，您可以重试。超时付款重试前，请先检查终端。
- 付款活动日志默认处于折叠状态。使用 **显示活动记录** 查看日志，使用 **清除** 清除当前显示的活动记录

### 收据 {#receipts}

**打印收据** 设置控制终端上的打印内容：不打印、商户收据、顾客收据或两者都打印。

## 退款 {#refunds}

此插件不支持退款。请通过 PayArc 退款，然后在 WooCommerce 中手动记录退款。

## 日志 {#logs}

在 `WooCommerce > Status > 日志` 中查找日志，来源为 `payarc-terminal-for-woocommerce`。日志包含连接尝试、已发起或失败的销售、取消操作，以及已接受或拒绝的回调。标识符会脱敏，密钥会被隐藏。

没有支持包下载功能。寻求帮助时，请提供订单号和相关日志行。请勿分享完整 MID、终端 ID、令牌或卡片数据。

## 范围与限制 {#scope-and-limitations}

- 此插件不支持退款
- 付款会收取**完整订单总额**；不支持部分付款或拆分付款
- 不支持小费
- 每个店铺只能使用一个终端：仅有一个序列号设置，且没有收银员选择器
- 币种仅限 **USD、CAD、GBP、EUR 和 JPY**
- 模式与已保存的连接凭据不匹配时，付款会被阻止

## 故障排除 {#troubleshooting}

### 常见问题 {#common-issues}

<Accordion>
  <AccordionItem question="凭据似乎属于另一个环境">

  - 所选模式与凭据来自不同环境
  - 切换 **模式** 以匹配凭据，或将凭据替换为所选模式对应的凭据
  - 再次点击 **使用这些凭据连接** 并保存

  </AccordionItem>
  <AccordionItem question="无法连接 PayArc">

  - PayArc 拒绝了登录凭据。请检查输入的凭据并重试
  - 查看 `WooCommerce > Status > 日志` 中来源为 `payarc-terminal-for-woocommerce` 的日志，了解详情

  </AccordionItem>
  <AccordionItem question="无法处理付款请求。（HTTP 500）">

  - 此收银员提示内容较笼统。请在 WooCommerce 日志中查找 **PayArc payment action failed**，了解实际原因
  - 更改模式或凭据后，再次点击 **使用这些凭据连接** 并保存
  - 检查是否已填写 **终端序列号**
  - 如果日志显示 PayArc 同时拒绝了 Connect 访问令牌和 SecretKey，请联系 PayArc 支持，确认您的商户账户已启用 **PayArc Connect V3**
  - 确认店铺币种为 **USD、CAD、GBP、EUR 或 JPY**

  </AccordionItem>
  <AccordionItem question="发起付款时访问遭拒。（HTTP 403）">

  - 更新到 **0.1.12 或更高版本**，此版本修复了 POS 会话中的此错误

  </AccordionItem>
  <AccordionItem question="Terminal Registry 为空">

  - 注册信息为空，或显示的终端没有 POS 标识符，均属正常情况
  - 注册信息仅用于报告。付款使用 **终端序列号**

  </AccordionItem>
  <AccordionItem question="付款等待时间过长">

  - 检查终端屏幕，并保持付款页面打开
  - 重试前，请检查订单备注和 PayArc 仪表板
  - 页面每 **1.5 秒**检查一次，并在 **5 分钟**后停止

  </AccordionItem>
</Accordion>
