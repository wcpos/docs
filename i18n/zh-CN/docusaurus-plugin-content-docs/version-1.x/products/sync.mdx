WCPOS 会在每台设备上保留您产品的本地副本，因此产品目录的浏览和搜索都是即时的，并且在离线时仍可继续使用。本指南说明产品如何进入设备，以及它们如何保持最新。

:::info v1.10.0 中的变更
v1.10.0 引入了全新的同步引擎。如果您的 POS 版本早于 v1.10.0，请参阅下方的 [v1.10.0 中的变更](#what-changed-in-v1100)。
:::

## 产品如何进入设备 {#how-products-arrive}

- **产品目录预填充在后台运行。** 从首次启动开始，POS 就会按计划分小批下载您的产品目录，无需您操作。首批产品下载完成后，您即可开始销售，结账无需等待整个目录下载完成。
- **您正在查看的内容按需下载。** 搜索、按类别筛选或扫描条形码时，如果匹配的产品尚未存于本地，POS 会直接获取它们。搜索不再连带获取无关产品，而是只获取您所请求的内容。
- **通过变更检查获取更新。** 产品存入本地后，POS 不会为了确认它是否有变化而重新下载它。POS 会轮询一份轻量的变更日志（默认预设为每 60 秒一次），只获取实际发生变化的内容；店铺没有变化时，只会返回一个几乎不消耗资源的“无变化”响应。

## 每批下载多少产品？ {#batch-size}

默认情况下，POS **每次请求 50 个产品**。这不再是固定常量，而是由**店铺健康 → 性能**中的同步预设设定的两个参数之一：

| 预设 | 检查间隔 | 每次请求的记录数 |
| --- | --- | --- |
| 节能 | 5 分钟 | 25 |
| 均衡（默认） | 60 秒 | 50 |
| 实时 | 10 秒 | 75 |

采用小批量是为了保护您的服务器：生成较大的分页结果需要消耗服务器处理时间，在共享主机上还可能拖慢店铺前台或触发速率限制。主机配置一般时请选择节能；使用高性能主机的多收银台店铺可选择实时。详情请参阅[店铺健康](/1.x/support/store-health#sync-presets)。

## 查看下载进度 {#checking-progress}

打开**店铺健康 → 数据库**，即可按集合对比此设备与服务器上的记录数量，并查看覆盖率进度条。*服务器上*的数字是服务器实际报告的总数；在 POS 仍在确认该数字时，该行会显示*检查中…*，而不会给出估算值。

产品进度条未满只是表示预填充尚未完成，后台会继续下载。如果某个产品似乎缺失，请搜索它，这会直接获取该产品。

:::tip
如果某个集合似乎卡住了，请先在店铺健康 → 数据库中使用该行的**清除并重新下载**，再考虑通过[清除所有本地数据](/1.x/support/troubleshooting/clear-local-data)执行完整重置。
:::

## v1.10.0 中的变更 {#what-changed-in-v1100}

早期版本会*在使用过程中逐步*下载产品目录：每次搜索或滚动都会获取另一批产品，并且每 5 分钟运行一次完整轮询。该模式已不再使用。在 v1.10.0 中：

- 产品目录通过定时运行的后台预填充逐步下载完成，您无需通过搜索或滚动来触发产品下载。
- 搜索获取的是匹配的产品，而不是任意的下一批产品。
- 变更检查使用条件请求，按您选择的预设间隔运行（默认 60 秒），不再固定每 5 分钟执行一次完整轮询。
- 可在**店铺健康 → 数据库**中按集合查看下载进度。

开发者可在[同步引擎的工作原理](/1.x/reference/sync-engine)中了解完整机制。

## 常见问题 {#faq}

<Accordion>
  <AccordionItem question="下载产品需要我进行任何操作吗？">

  不需要。产品目录预填充会在后台自动下载您的产品。如果某些产品尚未存于本地，搜索或筛选会立即获取它们。不过，完成整个目录下载的是后台预填充，而非日常浏览操作。

  </AccordionItem>

  <AccordionItem question="产品变更多快能同步到 POS？">

  在默认的均衡预设下，POS 每 60 秒检查一次变更（检查时间会略作随机调整，以免多台收银台同时访问服务器）。只有发生变化的产品才会被获取。如果多台收银台需要更快地看到彼此的更改，请使用实时预设。

  </AccordionItem>

  <AccordionItem question="我在 POS 中看不到所有产品">

  有以下几种可能：

  - 后台预填充可能只是尚未完成，请查看**店铺健康 → 数据库**中的产品行。
  - POS 默认隐藏缺货产品。可在产品显示设置中更改此设置。
  - WooCommerce REST API 仅支持标准产品类型（简单型、可变型、分组型、外部型）。自定义产品类型可能不会在 POS 中显示。

  </AccordionItem>
</Accordion>
