**WooCommerce REST API** 就像一组标准化的“通道”，让店铺所有者能够将 WooCommerce 店铺连接到其他应用和服务。

下面用简单的方式说明它的工作原理：

1. 它充当 WooCommerce 店铺与外部应用之间的桥梁，让双方能够通信并共享数据。

2. API 通过向特定的 **端点** 发送请求来工作——可以把它们想象成不同类型店铺数据的“通道”。例如，产品、订单和客户各有对应的端点。

3. 外部应用可以通过这些端点：

- 获取信息（例如获取产品列表）
- 添加新数据（例如创建新订单）
- 更新现有信息（例如更改产品价格）
- 删除数据（例如移除过时的产品）

与许多传统 WordPress 插件依赖 PHP 钩子和筛选器不同，它通过结构化且可预测的格式（即 **JSON**）发送和接收数据。

## 为什么有些插件无法在 POS 中使用？ {#why-dont-some-plugins-work-in-the-pos}

WCPOS 通过 REST API 从 WooCommerce 店铺下载产品、订单和客户数据。
随后，它会在本地保留这些数据的副本，因此即使网络连接不稳定，也能继续运行。
这种方式让 POS 在繁忙的结账环境中运行得更快、更可靠。

不过，这也意味着 POS 无法“看到”网站上实时发生的动态变化。例如：
