:::info 专业版功能
优惠券界面以及在收银台应用优惠券的功能需要 [WCPOS 专业版](/getting-started/pro-license)。免费用户只能看到优惠券界面的模糊预览，无法查看优惠券详情或在购物车中应用优惠码。
:::

优惠券界面可让您在 POS 中浏览和查找 WooCommerce 优惠券，购物车中的 **添加优惠券** 按钮可将优惠券应用于当前订单。优惠券仍需在 WooCommerce 中创建和管理；POS 会同步优惠券，并在本地进行验证，以便收银时即时反馈。

## 界面概览 {#interface-overview}

### 顶部操作栏 {#header-actions}

界面顶部：

- **搜索栏** — 按优惠码查找优惠券
- **显示设置**（<Icon name="sliders" />）— 配置可见列

### 优惠券表格 {#coupons-table}

主区域显示已同步的优惠券，其中包括：

- **代码** — 顾客输入的优惠券代码
- **描述** — 内部描述（设置后也会用作收据标签）
- **折扣类型** — 百分比、固定购物车折扣或固定商品折扣
- **金额** — 折扣值
- **已用 / 限制** — 已使用次数和总使用限制
- **到期时间** — 到期日期；如未设置则留空
- **操作** — 三点菜单

### 页脚 {#footer}

- 优惠券数量及同步按钮（<Icon name="arrow-rotate-right" />）。**长按**可显示清除和刷新选项。

## 优惠券类型 {#coupon-types}

WCPOS 支持 WooCommerce 的三种标准优惠券类型：

| 类型 | 功能 | 示例 |
|---|---|---|
| **百分比折扣** | 按百分比降低购物车小计 | 订单优惠 `10%` |
| **固定购物车折扣** | 按固定金额降低购物车总额 | 订单优惠 `$5` |
| **固定商品折扣** | 按每件固定金额降低符合条件的商品行金额 | 每件 T 恤优惠 `$2` |

这三种类型均遵循相同的验证规则（到期时间、使用限制、商品/分类限制等）。

## 创建优惠券 {#creating-coupons}

优惠券需在 WooCommerce 中创建，而不是在 POS 中创建。前往 **WP Admin → 营销 → 优惠券 → 添加优惠券**：

1. **优惠券代码** — 收银员在收银台输入的代码。代码不区分大小写。
2. **描述** — 内部备注。设置后，WCPOS 会将其用作收据上的折扣标签，因此建议使用顾客容易理解的短语，例如“经理折扣 10%”，而不是内部代码。
3. **折扣类型** — 百分比、固定购物车折扣或固定商品折扣。
4. **优惠券金额** — 折扣值。
5. **到期日期** — 可选。超过此日期后，优惠券将无法使用。

### 使用限制 {#usage-restriction}

| 限制 | 功能 | 示例 |
|---|---|---|
| **最低/最高消费** | 仅当小计高于/低于指定门槛时应用优惠券 | 仅适用于小计超过 `$50` 的订单 |
| **仅限单独使用** | 禁止此优惠券与其他优惠券同时使用 | “VIP20”不能与“SALE10”叠加使用 |
| **排除促销商品** | 跳过已打折的商品（以及收银员在收银台降价的任何商品行 — 参见 [POS 价格覆盖](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)） | 清仓商品不再享受额外折扣 |
| **商品/排除商品** | 限定优惠券适用或不适用的特定商品 | 仅适用于“Espresso Beans” |
| **商品分类/排除分类** | 按分类限定。在 POS 创建的杂项/自定义商品也遵循通过 POS 分配的分类 | 仅适用于“Drinks”分类 |
| **允许的邮箱** | 将优惠券限定为特定顾客邮箱地址（支持 `*` 通配符） | `*@yourcompany.com` 仅供员工使用 |

### 使用限额 {#usage-limits}

| 限额 | 功能 |
|---|---|
| **每张优惠券的使用限制** | 此优惠码可供所有顾客使用的总次数 |
| **每位用户的使用限制** | 单个顾客可使用的次数 |
| **限制使用于 X 件商品** | 对固定商品优惠券，限制每次使用时可享受折扣的符合条件商品数量 |

<a id="tips-for-pos-use"></a>

:::tip POS 使用技巧
- 创建一张 **“经理 10%”** 优惠券（优惠 10%、无最低消费额、无到期日、关闭单独使用限制），并将优惠码提供给经理 — 员工可在收银时用它进行临时调整，同时您也能在报告中追踪折扣。
- 创建一张 **“忠诚客户 $5”** 优惠券，用于奖励回头客。
- 针对一次性促销，请设置较短的到期日期，以免优惠码之后被误用。
- 将 **描述** 设置为希望打印在收据上的短语，是为折扣添加品牌标识的最快方式。
:::

## 在收银台使用优惠券 {#applying-a-coupon-at-the-register}

在购物车中点击 **添加优惠券**，然后输入优惠码或按描述搜索。系统会立即根据已同步的数据验证优惠券，并在购物车合计上方显示可移除的标签。

如需了解完整的收银操作流程——搜索、优惠券标签、叠加多张优惠券以及解决验证错误——请参阅**[在收银台使用优惠券](/coupons/applying-coupons)**。

## 验证机制 {#how-validation-works}

输入优惠码时，POS 会检查 WooCommerce 在服务器端会检查的所有相同规则：

- 优惠券存在且未过期
- 未超过使用次数限制（总体限制和每位用户限制）
- 满足最低/最高消费要求
- "仅限单独使用"的优惠券与已应用的优惠券不冲突
- 商品/分类限制与购物车内容匹配
- 邮箱限制与所选客户匹配（访客订单则跳过此项）
- 如果启用了**排除促销商品**，则排除促销商品

如果任何一项检查未通过，收银员会看到具体的错误提示（例如"此优惠券已过期"或"未达到最低消费金额"）。提交订单时，服务器会再次执行相同的检查——本地验证是为了速度，而非作为最终依据。

## 同步行为 {#sync-behaviour}

优惠券会像其他 POS 数据一样从 WooCommerce 同步到设备：

- 在 WP Admin 中创建的新优惠券将在下次同步时显示在 POS 中。
- 对现有优惠券的更新（使用次数、过期时间更改等）会自动同步。
- 优惠券存储在本地数据库中，因此离线时仍可使用。

如果您刚在 WP Admin 中创建了优惠券但尚未看到，可能是同步尚未执行。在优惠券页面底部，点击同步图标（<Icon name="arrow-rotate-right" />）即可刷新——长按可选择**清除并刷新**以重新获取数据。

## 网络连接 {#connectivity}

- **应用优惠券**可以离线使用，因为验证在客户端基于同步数据进行。
- **完成结账**在使用支持离线的付款方式时也可以进行。该笔销售会在本地排队；待订单到达 WooCommerce 后，服务器会重新验证优惠券并更新其使用次数。
- **创建或编辑优惠券**在 WP Admin 中进行，需要连接到您的 WordPress 站点。

## 优惠券与 POS 折扣的交互方式 {#how-coupons-interact-with-pos-discounts}

当收银员在收银台降低了商品单价后再应用优惠券时，优惠券将按**降低后的价格**计算，而非原价。POS 中降价的商品被视为“促销商品”——启用了**排除促销商品**的优惠券将跳过这些商品。详情请参阅[折扣](/pos/cart/discounts#how-pos-price-changes-interact-with-coupons)。
