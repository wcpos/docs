## 这意味着什么 {#what-this-means}

无法连接到所选的打印机。

请检查打印机是否已通电并已连接，然后再次尝试打印。

## 您的数据 {#your-data}

订单和产品数据不受影响。

## 故障排查 {#troubleshoot}

1. 检查打印机是否已通电，其数据线或网络连接是否插牢。
2. 对于通过本地网络直接与收银台通信的打印机，请确认收银台和打印机处于同一网络，且打印机地址未发生变化——DHCP 续租可能会更改地址；如果地址已变，请在 POS 中设置打印机的位置更新其地址。
3. 云端打印收据时，收银台和打印机无需连接到同一网络；具体检查内容取决于传送方式（[云端打印](../receipts/cloud-printing.mdx#status)）：
   - **Star CloudPRNT 或 Epson Server Direct Print**（打印机轮询 WCPOS）：打印机完成连接前，POS 中的打印机卡片会显示 **等待中**。请确认打印机可以访问互联网，并且其轮询 URL 和令牌与 WCPOS 生成的内容一致——请参阅[打印机一直处于等待中](../receipts/cloud-printing.mdx#troubleshooting)。
   - **Star Online**：卡片会显示 Star Online 报告的设备状态；如果设备标记为 **离线** 或 **未知**，请在 Star Online 控制面板中处理，而不是在收银台上处理。
   - **PrintNode**：运行 PrintNode 桌面客户端的计算机必须保持唤醒且客户端在线；POS 中所选的打印机必须与客户端报告的打印机一致——请参阅[PrintNode 作业始终无法打印](../receipts/cloud-printing.mdx#troubleshooting)。
4. 从打印机自身打印一张自检页，确认硬件正常，然后再从 POS 重试。
