# 错误代码 {#error-codes}

当 WCPOS 遇到问题时，它会显示一个错误代码，帮助识别问题。从 **v1.10.0** 起，代码采用**域名 + 三位数字**的格式——例如 `SYNC131` 或 `AUTH311`。域名标明 POS 中的区域；数字标识具体的状况。每个代码都有自己的页面，说明它的含义、应采取的措施，以及它对您的数据意味着什么。

在 POS 中，错误代码会显示在 **商店健康 → 日志** 中：展开某一行，然后使用 **帮助** 链接直接跳转到此处该代码的页面。

## 错误域（v1.10.0+） {#error-domains}

| 域 | 区域 | 示例 |
|--------|------|----------|
| `AUTH` | 登录、会话和令牌 | [AUTH101](./AUTH101)、[AUTH311](./AUTH311) |
| `CHECKOUT` | 在收银台完成订单 | [CHECKOUT101](./CHECKOUT101)、[CHECKOUT201](./CHECKOUT201) |
| `CLIENT` | POS 应用本身及本地存储 | [CLIENT101](./CLIENT101)、[CLIENT201](./CLIENT201) |
| `LICENSE` | 专业版许可证的激活与验证 | [LICENSE101](./LICENSE101) |
| `PAYMENT` | 支付网关和终端 | [PAYMENT101](./PAYMENT101)、[PAYMENT301](./PAYMENT301) |
| `PRINT` | 收据打印 | [PRINT101](./PRINT101)、[PRINT301](./PRINT301) |
| `PRODUCT` | 产品数据和目录操作 | [PRODUCT101](./PRODUCT101)、[PRODUCT401](./PRODUCT401) |
| `SYNC` | POS 与您商店之间的同步 | [SYNC101](./SYNC101)、[SYNC121](./SYNC121)、[SYNC311](./SYNC311) |

使用侧边栏浏览某个域中的所有代码，或直接搜索该代码。

以 `999` 结尾的代码是该域的兜底代码，用于尚未拥有专门代码的状况。

## 旧版代码（v1.10.0 之前） {#legacy-codes}

v1.10.0 之前的版本使用不同的方案：`[DOMAIN][CATEGORY][SPECIFIC_CODE]`，例如 `API04001` = API（域）+ 04（响应错误）+ 001（无效的响应格式）。如果您运行的是较早版本，或在查看旧的日志条目或支持帖子，以下页面仍然适用：

| 域 | 总代码数 | 涵盖范围 |
|--------|-------------|---------------|
| [API](./api) | 39 个代码 | 服务器通信、认证、插件问题 |
| [DB](./db) | 9 个代码 | 本地数据存储和检索 |
| [PY](./py) | 6 个代码 | 支付处理 |
| [SY](./sy) | 5 个代码 | 设备资源和配置 |

v1.10.0+ 的客户端绝不会发出这些代码——如果您在最新版 POS 上看到它们，那是来自保留的旧日志条目或服务器端消息。

## 需要更多帮助？ {#need-more-help}

如果在遵循故障排除步骤后仍然遇到问题：

1. 检查 [故障排除](/support/troubleshooting/response-error) 部分以获取更详细的指南
2. 加入我们的 [Discord社区](https://wcpos.com/discord) 寻求支持
3. 在 [GitHub](https://github.com/wcpos) 上报告问题
