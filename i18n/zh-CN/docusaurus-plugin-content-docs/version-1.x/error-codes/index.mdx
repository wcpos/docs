# 错误代码 {#error-codes}

WCPOS 遇到问题时，会显示有助于识别问题的错误代码。从 **v1.10.0** 起，代码采用 **域 + 三位数字** 的格式，例如 `SYNC131` 或 `AUTH311`。域表示 POS 中的问题所属区域，数字则标识具体情况。每个代码都有独立页面，说明其含义、应采取的措施，以及对您数据的影响。

在 POS 中，错误代码会显示在 **店铺健康 → 日志** 中：展开一行，然后使用 **帮助** 链接直接跳转到此处对应的代码页面。

## 错误域（v1.10.0+） {#error-domains}

| 域 | 区域 | 示例 |
|--------|------|----------|
| `AUTH` | 登录、会话和令牌 | [AUTH101](./AUTH101.mdx)、[AUTH311](./AUTH311.mdx) |
| `CHECKOUT` | 在收银台完成订单 | [CHECKOUT101](./CHECKOUT101.mdx)、[CHECKOUT201](./CHECKOUT201.mdx) |
| `CLIENT` | POS 应用本身和本地存储 | [CLIENT101](./CLIENT101.mdx)、[CLIENT201](./CLIENT201.mdx) |
| `HOST` | 阻止 POS 运行的托管服务和防火墙规则 | [HOST101](./HOST101.mdx), [HOST121](./HOST121.mdx) |
| `LICENSE` | Pro 许可证的激活和验证 | [LICENSE101](./LICENSE101.mdx) |
| `PAYMENT` | 支付网关和终端 | [PAYMENT101](./PAYMENT101.mdx)、[PAYMENT301](./PAYMENT301.mdx) |
| `PRINT` | 收据打印 | [PRINT101](./PRINT101.mdx)、[PRINT301](./PRINT301.mdx) |
| `PRODUCT` | 产品数据和目录操作 | [PRODUCT101](./PRODUCT101.mdx)、[PRODUCT401](./PRODUCT401.mdx) |
| `SYNC` | POS 与您的店铺之间的同步 | [SYNC101](./SYNC101.mdx)、[SYNC121](./SYNC121.mdx)、[SYNC311](./SYNC311.mdx) |

使用侧边栏浏览某个域中的所有代码，或直接搜索代码。

以 `999` 结尾的代码是该域的通用代码，用于尚无专用代码的情况。

## 旧版代码（v1.10.0 之前） {#legacy-codes}

v1.10.0 之前的版本采用不同的编码方案：`[DOMAIN][CATEGORY][SPECIFIC_CODE]`，例如 `API04001` = API（域）+ 04（响应错误）+ 001（无效的响应格式）。如果您使用的是旧版本，或正在查看旧日志条目或支持帖子，这些页面仍然适用：

| 域 | 代码总数 | 涵盖内容 |
|--------|-------------|---------------|
| [API](./api.mdx) | 39 个代码 | 服务器通信、身份验证、插件问题 |
| [DB](./db.mdx) | 9 个代码 | 本地数据存储和检索 |
| [PY](./py.mdx) | 6 个代码 | 支付处理 |
| [SY](./sy.mdx) | 5 个代码 | 设备资源和配置 |

v1.10.0+ 客户端不会生成这些代码。如果您在最新版 POS 中看到它们，说明它们来自保留的旧日志条目或服务器端消息。

## 需要更多帮助？ {#need-more-help}

如果按照故障排除步骤操作后问题仍然存在：

1. 检查 [故障排除](/support/troubleshooting/response-error) 部分以获取更详细的指南
2. 加入我们的 [Discord社区](https://wcpos.com/discord) 寻求支持
3. 在 [GitHub](https://github.com/wcpos) 上报告问题
