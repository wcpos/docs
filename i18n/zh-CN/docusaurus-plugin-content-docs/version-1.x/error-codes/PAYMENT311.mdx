## 这意味着什么 {#what-this-means}

WCPOS 无法确认这笔退款是否成功。

再次尝试前，请打开订单并检查其退款记录——重试可能导致重复退款。

退款请求已发送，但响应丢失——请求超时、店铺返回错误，或要求 WCPOS 等待后重试。退款可能已完成，也可能没有完成。每次重试都会向支付网关发送新的退款请求，因此未经检查就重试可能会向客户重复退款。

## 您的数据 {#your-data}

此设备上的数据不会丢失。店铺或支付网关可能已经向客户退款。

## 故障排查 {#troubleshoot}

1. 暂时不要再次退款。
2. 在线时，请在 **Orders** 中打开订单并检查其退款记录——这些记录会直接从店铺加载。您也可以在 WP Admin 中打开 **WooCommerce → 订单**，查看订单的退款记录。
3. 如果退款通过支付网关处理（例如刷卡终端或 Vipps MobilePay 等服务商），还要检查该网关自己的控制面板，或请店铺所有者代为检查：即使订单中尚未显示，控制面板也会显示退款是否已发送。
4. 如果退款记录已存在，说明退款已成功——不要再次退款。只有两处都没有记录时，才再尝试一次。如果无人能检查支付网关，请直接进行下一步。
5. 如果仍无法确定，请在 **Logs** 标签页点按 **Copy debug info**，并在再次尝试前联系支持团队。
