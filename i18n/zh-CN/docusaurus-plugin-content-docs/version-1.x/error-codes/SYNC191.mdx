## 这意味着什么 {#what-this-means}

此更改仍在发送到您的店铺。

无需操作——请勿重新录入。系统会自动发送，并在店铺确认后显示。

一笔销售或一项更改已保存在此设备上并发送，但店铺未能在通常的等待时间内确认——通常是因为店铺响应缓慢或连接不稳定。WCPOS 会持续发送，直到店铺确认。店铺能够识别已收到的更改，因此再次按同一个按钮是安全的；但手动重新录入销售或记录并不安全：这会创建第二份独立记录，也就是重复项。

## 您的数据 {#your-data}

没有数据丢失。此更改正在此设备上等待，并会自动发送。更改等待发送期间，请勿清除此设备的数据。

## 故障排除 {#troubleshoot}

1. 请勿手动重新录入销售或更改——这会造成重复项。
2. 等待其发送到店铺。销售记录已保存在此设备上，因此会显示在 WCPOS 中（购物车中，或在 WCPOS Pro 的 **订单** 中）；要确认其已送达店铺，请检查 WP Admin 中的 **WooCommerce → 订单**。
3. 要查看发送进度，请打开 **商店健康 → 日志**：标题中的 **待发送的更改** 数量会随着更改发送而减少，全部发送完成后会显示为 0。
4. 如果长时间处于等待状态，请检查此设备的连接以及店铺网站是否能正常加载——请参阅 [SYNC121](/error-codes/SYNC121)。
5. 如果连接正常后仍未显示，请点按 **日志** 标签页上的 **复制调试信息** 并联系支持人员。
