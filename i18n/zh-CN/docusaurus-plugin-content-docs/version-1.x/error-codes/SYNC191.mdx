## 这意味着什么 {#what-this-means}

此更改仍在发送到店铺的途中。

无需操作——请勿再次录入。更改会自动发送，并在店铺确认后显示。

销售或更改已保存在此设备上并已发送，但店铺未在通常的等待时间内确认——通常是因为店铺响应缓慢或网络连接不稳定。WCPOS 会持续发送，直到店铺确认。店铺能识别已收到的更改，因此再次按下同一个按钮是安全的。但手动重新录入销售或记录并不安全：那会创建另一个独立项目，造成重复。

## 您的数据 {#your-data}

没有数据丢失。更改正在此设备上等待，并会自动发送。更改等待发送期间，请勿清除此设备上的数据。

## 故障排查 {#troubleshoot}

1. 请勿手动重新录入销售或更改——那会造成重复。
2. 等待其发送到店铺。销售已显示在 WCPOS 中（购物车中；或在 WCPOS Pro 中的 **Orders** 中），因为它已保存在此设备上；要确认店铺已收到，请在 WP Admin 中检查 **WooCommerce → 订单**。
3. 如需查看发送进度，请打开 **Store health → Logs**：随着更改发送，标题中的 **changes waiting to send** 数量会减少；全部发送完毕后会显示 0。
4. 如果长时间处于等待状态，请检查此设备的网络连接，以及店铺网站是否能正常加载——请参阅 [SYNC121](/error-codes/SYNC121)。
5. 如果网络正常后仍未显示，请在 **Logs** 标签页点按 **Copy debug info** 并联系支持团队。
