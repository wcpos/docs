## 这意味着什么 {#what-this-means}

此订单在店铺中的总额与收银台显示的金额不同。订单已按店铺中的总额保存。

顾客离开前，请打开订单并核对总额。如果已经收款，请补收或退还差额。如果差额并非预期，请联系支持团队。

## 您的数据 {#your-data}

订单已按店铺中的总额保存。付款可能已经收取，也可能尚未收取——此项检查在订单保存时运行，可能早于付款。如果问题持续出现，请在 **Logs** 标签页中使用 **Copy debug info**，并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

**在收银设备上** — 请在客户离开前完成以下操作：

1. 打开订单并将其总额与收银台显示的金额进行比较；日志条目会记录具体哪些金额不同。
2. 检查是否已收款以及收取了多少——银行卡终端请查看其屏幕或收据；现金请查看收取的金额；其他支付网关请查看其记录。
3. 如果已经收款，请按常规流程补收或退还差额。如果尚未收款，请按订单当前显示的总额收款。

**在店铺端** — 网站管理员：

1. 在 WP Admin 中打开该订单，将其合计金额与收银机显示的金额进行比较；日志条目记录了哪些金额出现了差异。
2. 常见原因是收银设备预期的税费设置与实际设置不同，或折扣、定价插件在服务器上重新计算了金额 — 请先检查店铺的税费设置。
3. 如果无法解释差额，请在 **Logs** 标签页中使用 **Copy debug info**，并联系支持团队，同时提供订单号。
