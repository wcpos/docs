# DB01001: 连接失败 {#db01001-connection-failed}

## 这意味着什么 {#what-this-means}

POS 无法连接到其本地数据库。WCPOS 使用本地数据库来存储产品、客户和其他数据，以便快速访问和离线功能。

## 常见原因 {#common-causes}

- **存储空间已满** — 设备没有剩余存储空间
- **数据库损坏** — 本地数据库文件已损坏
- **权限问题** — App 没有存储权限
- **浏览器存储被禁用** — IndexedDB 已禁用（网页版）

## 如何修复 {#how-to-fix}

### 1. 检查存储空间 {#1-check-storage-space}

确保您的设备有可用存储：
- 如果存储已满，请释放空间
- 删除未使用的 App 或文件
- 检查可用磁盘空间

### 2. 清除 App 数据 {#2-clear-app-data}

:::warning 请先检查是否有未保存的工作
清除本地数据或重新安装应用会删除此设备上尚未同步到店铺的所有内容，包括离线期间完成的销售、未结购物车以及未保存的编辑。清除前，请打开 **Store health → Database**，确认没有记录显示为暂存或从未到达服务器；然后打开 **Store health → Logs**，确认 **0 条记录卡住**且 **0 项更改等待发送**；接着完成或记录每个未结购物车。如果您的 WCPOS 没有 Store health 页面，请先更新 WCPOS，再进行检查。如果存在任何记录或等待发送的内容，或者无法检查，请勿清除；请咨询店铺所有者或联系支持团队。
:::

只有在第 1、3 和 4 步均无效，并且完成上述检查后，才重置本地数据库：
- **桌面 App:** 在设置中查找“清除数据”
- **网页浏览器:** 清除 POS 域名的站点数据
- **注意：** 店铺中已有的数据会再次下载；从未到达店铺的内容则会丢失

### 3. 检查浏览器设置（网页） {#3-check-browser-settings-web}

如果使用网页版：
1. 确保启用 IndexedDB
2. 请勿使用私人/隐身模式（存储空间有限）
3. 允许该网站存储数据

### 4. 检查权限 {#4-check-permissions}

在桌面上：
- 确保 App 有权限写入其数据目录
- 检查防病毒软件是否阻止了数据库访问

### 5. 重新安装 App {#5-reinstall-the-app}

:::warning 请先检查是否有未保存的工作
清除本地数据或重新安装应用会删除此设备上尚未同步到店铺的所有内容，包括离线期间完成的销售、未结购物车以及未保存的编辑。清除前，请打开 **Store health → Database**，确认没有记录显示为暂存或从未到达服务器；然后打开 **Store health → Logs**，确认 **0 条记录卡住**且 **0 项更改等待发送**；接着完成或记录每个未结购物车。如果您的 WCPOS 没有 Store health 页面，请先更新 WCPOS，再进行检查。如果存在任何记录或等待发送的内容，或者无法检查，请勿清除；请咨询店铺所有者或联系支持团队。
:::

只有在其他解决方法均无效，并且完成上述检查后，才执行以下操作：
1. 卸载 POS App
2. 重启设备
3. 重新安装 App
4. 登录并同步数据

## 数据恢复 {#data-recovery}

如果您有未保存的数据：
- App 可能有无法同步的待处理更改
- 如果您需要帮助恢复数据，请联系支持
- 清除后，店铺中已有的数据会再次下载；但从未同步到店铺的销售记录只存在于此设备上——清除或重新安装会将其删除，因此请在执行任一操作前联系支持团队。
