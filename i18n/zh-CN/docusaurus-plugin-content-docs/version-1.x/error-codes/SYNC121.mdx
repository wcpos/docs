## 这意味着什么 {#what-this-means}

目前无法连接到您的商店，因此更改会暂时保留在本设备上。

请检查网络连接并继续离线工作；当商店恢复可访问时，同步会自动重试。

## 您的数据 {#your-data}

该更改已保存在本设备上，但尚未传到您的商店。

## 故障排查 {#troubleshoot}

1. 继续销售——销售数据已保存在本设备上，商店恢复响应后同步会自动继续。
2. 检查收银机本身是否在线：本设备能否打开其他任何网站？
3. 在同一设备的浏览器标签页中打开您商店自己的网站；如果它同样无法加载，说明是网站或其主机出了故障，而不是 POS。
4. **致负责管理此设备网络的人员：**如果网站可以加载，但 POS 仍处于离线状态，则两者之间的某个环节正在阻止 API 请求——可能是 VPN、防火墙、广告拦截器或安全插件。浏览器开发者工具的网络选项卡——或桌面应用中的 **高级 → 切换开发者工具**——可以显示哪个请求失败。
