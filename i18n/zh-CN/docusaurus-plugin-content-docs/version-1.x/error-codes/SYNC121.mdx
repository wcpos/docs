## 这意味着什么 {#what-this-means}

目前无法连接到您的店铺。

无需处理——继续销售即可。连接恢复后，更改会自动发送。如果问题持续，请检查此设备的网络连接，以及您的店铺网站是否可以加载。

## 您的数据 {#your-data}

请勿清除此设备的数据——其中可能包含店铺尚未收到的更改。店铺恢复响应后，这些更改会自动发送。

## 故障排查 {#troubleshoot}

1. 继续销售即可——销售记录会保存在此设备上，并在店铺恢复响应后自动发送。
2. 检查收银机本身是否在线：本设备能否打开其他任何网站？
3. 在同一设备的浏览器标签页中打开您商店自己的网站；如果它同样无法加载，说明是网站或其主机出了故障，而不是 POS。
4. **负责管理此设备网络的人员：** 如果网站可以加载，但 POS 仍处于离线状态，则两者之间的某个环节正在阻止 API 请求——可能是 VPN、防火墙、广告拦截器或安全插件。浏览器开发者工具的网络选项卡——或桌面应用中的 **高级 → 切换开发者工具**——可以显示哪个请求失败。
