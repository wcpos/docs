## 这意味着什么 {#what-this-means}

此订单引用的税率已不再存在于您的店铺中，因此其税额可能不正确。

订单中的某个项目使用了店铺当前税率表中不存在的税率——几乎总是因为订单开始后，该税率已在 WooCommerce 中被删除或编辑。WCPOS 无法查找该税率，因此此订单的税额可能与店铺当前应收的税额不一致。

## 您的数据 {#your-data}

订单是安全的。只有其税额需要确认——请在收款前核对，并向店铺管理员咨询税率。

## 故障排除 {#troubleshoot}

**在收银台**——请在收款前执行以下操作：

1. 检查订单中的税额。该税额是使用店铺当前已不存在的税率计算的。
2. 如果税额看起来不正确，请在新订单中开始销售——新订单会采用店铺当前的税率。

**在店铺中（WP Admin）** — 适用于网站管理员：

1. 前往 **WooCommerce → 设置 → 税**，检查最近是否删除或编辑过税率。删除已被未完成订单引用的税率通常会导致此问题。
2. 如果是有意移除了税率，则无需采取其他操作，只需重新开始当时处于未完成状态的订单。
3. 如果店铺的税率没有变更，POS 可能保留了过期副本。可通过 **店铺健康 → 数据库 → 税率 → 清除并重新下载** 刷新——这只会影响该集合，不会将任何人注销。请参阅[店铺健康](/support/store-health#clear-and-redownload)。
4. 如果税率下载完成后再次出现该代码，请在 **店铺健康 → 日志** 中打开日志条目，使用 **复制**（或 **分享**）发送其详细信息，并携带订单号联系支持团队。
