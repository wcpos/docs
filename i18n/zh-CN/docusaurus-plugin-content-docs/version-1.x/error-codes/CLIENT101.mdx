## 这意味着什么 {#what-this-means}

WCPOS 未能完成启动。

在收银台看来，这会表现为空白或卡住的屏幕，或一直不消失的加载动画。重新启动 WCPOS（在网页上重新加载标签页）——启动故障通常会自行消失。如果仍无法启动，请先联系支持团队，再清除任何内容。

:::warning 请勿清除此设备上的数据
此设备上可能保存着尚未同步到店铺的销售记录，例如离线时完成的销售。WCPOS 无法启动时，这些记录无法发送，因此清除本地数据、退出登录或重新安装都会将其永久删除。请先联系支持团队，再清除任何内容。
:::

## 您的数据 {#your-data}

请勿清除此设备上的数据——其中可能包含店铺尚未收到的更改。店铺自身的数据安全无虞，不会受到影响。

## 故障排查 {#troubleshoot}

1. 重新启动一次 WCPOS；在网页上，请彻底重新加载标签页——临时启动故障通常会自行消失。
2. 如果仍无法启动，请先联系支持团队，再清除任何内容。如果 WCPOS 能打开到足以访问相应页面，请从 **Logs** 标签页发送 **Copy debug info**；否则，请提供浏览器控制台（开发者工具）中显示的错误，或桌面应用中 **Advanced → Toggle Developer Tools** 里的错误。
3. 等待期间，请勿清除本地数据、退出登录或重新安装——支持团队会先告知您此设备上是否有需要恢复的内容。
