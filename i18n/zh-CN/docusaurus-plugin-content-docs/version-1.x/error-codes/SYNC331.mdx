## 这意味着什么 {#what-this-means}

此设备上的记录副本与店铺中的版本不一致。您输入的内容不受影响。

在 **店铺健康 → 数据库** 中，使用该列表上的 **清除并重新下载**，以店铺中的版本替换此设备上的副本。在此之前，该记录可能显示过时的价格或库存。请先确认没有待发送内容——参阅故障排除。

## 您的数据 {#your-data}

销售记录和未发送的更改均不受影响。替换前，此设备上的记录副本可能显示过时的价格或库存。如果这种情况持续发生，请在 **日志** 选项卡中使用 **复制调试信息**，并联系 WCPOS 支持。

## 故障排查 {#troubleshoot}

1. 继续销售。打开 **店铺健康 → 数据库**：记录名称会显示在顶部——副本不一致的记录会显示 **"… 无法从您的店铺下载"**，而已被店铺删除的记录会显示 **"… 必须从此设备移除"**。
2. 销售该商品前，请对照货架上的信息，或向店铺管理员确认其价格和库存（管理员可以在 WP Admin 中进行核对）。
3. 清除任何内容前，请在 **店铺健康 → 数据库** 中确认 **待发送的更改** 为 0，并确认没有显示 **"… 个更改未能到达您的服务器"** 或 **"… 个更改已暂存"** 面板——这些更改仅存在于此设备上，清除列表可能会导致它们丢失。请等待计数变为 0，并先处理所有列出的更改（[SYNC201](/error-codes/SYNC201)、[SYNC221](/error-codes/SYNC221)）。清除 **订单** 前，还要使用 **保存到服务器** 保存此设备上的所有未完成购物车（或完成结账）——从未保存到店铺的购物车仅存在于此设备上，也不会计入上述检查；因此清除 **订单** 会将其删除。如果购物车无法保存，请跳过 **订单** 行并联系支持团队。然后打开记录列表（例如 **商品**）中的 **⋮** 菜单，并选择 **清除并重新下载…**——设备会移除本地副本并获取店铺中的版本，已删除的记录也会被移除。该条目可能会一直显示到下一次后台检查；请以价格和库存是否已匹配为准。如果提示框随后指出其他列表中的记录，请先完成检查，再对该列表重复此步骤。
4. **站点管理员：** 如果重新下载后同一批记录仍不断出现，通常是某种批量更改绕过了 WooCommerce 的保存钩子——例如 CSV 导入、迁移插件、WP-CLI 或直接执行 SQL。建议通过 WooCommerce 编辑，以确保收银台的检查结果准确；同一差异反复出现后，WCPOS 会自行重建完整性数据。
5. 如果重新下载后收银台仍显示错误的价格或库存，请在 **日志** 选项卡中使用 **复制调试信息**，并联系支持团队。
