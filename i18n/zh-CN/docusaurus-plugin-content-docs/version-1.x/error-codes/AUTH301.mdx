## 这意味着什么 {#what-this-means}

另一个身份验证插件正在阻止 WCPOS 连接。

请网站管理员解决指明的插件冲突后再重新登录。

## 您的数据 {#your-data}

订单和产品数据不受影响。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

**在店铺端** — 网站管理员：

1. 错误信息会指出冲突的插件。请检查该插件的设置 — 大多数身份验证插件都可以将 WCPOS REST 路由设为例外，无需完全停用插件。
2. 如果不清楚是哪个插件冲突，请在暂存副本上测试，逐个停用安全和登录类插件。

**在收银设备上** — 收银员：更改完成后，请重新登录。
