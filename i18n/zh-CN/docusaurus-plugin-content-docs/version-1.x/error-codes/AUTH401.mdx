## 这意味着什么 {#what-this-means}

无法信任与此商店建立的安全连接。

请使用正确的商店地址，并在重新连接之前请网站管理员修复证书。

## 您的数据 {#your-data}

订单和产品数据不受影响。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

1. 在同一设备的浏览器中打开商店地址——浏览器的锁形图标或警告页面会准确显示证书的问题所在（已过期、自签名，或签发给了其他域名）。
2. 检查 POS 使用的地址：https:// 以及证书所覆盖的确切域名——带不带 www 是有区别的。
3. 请网站管理员或主机服务商续期或修复证书；自动续期悄然失败是最常见的原因。
4. 不要通过关闭安全功能来绕过证书警告——请修复证书。
