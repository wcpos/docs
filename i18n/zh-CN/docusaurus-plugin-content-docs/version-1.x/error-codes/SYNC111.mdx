## 这意味着什么 {#what-this-means}

此设备上存储的部分数据已损坏，因此无法同步。

点按 **Logs** 标签页顶部的 **Copy debug info**，并发送给 WCPOS 支持团队。请勿重新安装 WCPOS、退出登录或清除其数据：尚未同步到店铺的更改仅存在于此设备上。

## 您的数据 {#your-data}

请勿清除此设备上的数据——其中可能有店铺尚未收到的销售记录。重新安装应用或退出登录也可能删除这些记录。支持团队可以告知您是否有某一类数据可以安全地重新下载。

## 故障排查 {#troubleshoot}

1. 如果 WCPOS 仍能正常运行，请继续销售。请勿重新安装、退出登录或清除其数据。
2. 在 **Logs** 标签页点按顶部的 **Copy debug info**，并发送给 WCPOS 支持团队，同时说明日志条目出现时您正在进行什么操作。
3. 打开 **Store health → Database**，告知支持团队其中显示有多少 **changes waiting to send**，以及是否显示 **"… changes never reached your server"** 或 **"… changes were held"** 面板——这些更改仅存在于此设备上。
4. 日志条目未说明哪些数据已损坏。当没有待发送内容时，支持团队可能会要求您重新下载某一类数据（该行的 **⋮** 菜单 → **Clear & re-download…**）。在支持团队确认具体数据之前，请勿操作：清错数据，或在仍有待发送更改时清除数据，都可能删除店铺尚未收到的销售记录。如果数据损坏导致更改无法发送，支持团队会先恢复这些更改；只要仍有待发送内容，就绝不要重新下载。
