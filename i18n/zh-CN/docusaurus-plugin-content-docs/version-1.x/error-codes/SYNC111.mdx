## 这意味着什么 {#what-this-means}

本地商店数据已损坏，需要先修复才能继续同步。

请对受影响的数据运行定向修复；只有当问题再次出现时，才重置该部分本地数据。

## 您的数据 {#your-data}

本设备上的数据可能面临风险——请不要清除本地数据。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 打开“商店健康 → 数据库”，对受影响的数据运行定向修复；完全重置会丢弃比修复更多的内容。
2. 重试失败的那个操作，然后留意商店健康 → 日志中是否再次出现此代码。
3. 如果同一份数据再次被标记，请仅重置那部分本地数据，让它从您的商店重新下载——但务必先记录下所有未发送的更改。
4. 反复出现的损坏说明设备存储正在失效：请导出调试信息并联系支持团队。
