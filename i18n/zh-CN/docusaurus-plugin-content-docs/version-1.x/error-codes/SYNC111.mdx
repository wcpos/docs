## 这意味着什么 {#what-this-means}

此设备上存储的部分数据已损坏，因此无法同步。

点按 **日志** 标签页顶部的 **复制调试信息**，并将其发送给 WCPOS 支持人员。请勿重新安装 WCPOS、退出登录或清除其数据：店铺尚未收到的更改仅存在于此设备上。

## 您的数据 {#your-data}

请勿清除此设备的数据——其中可能有店铺尚未收到的销售记录。重新安装应用或退出登录也可能将其删除。支持人员可以告知您是否可以安全地重新下载某一类数据。

## 故障排查 {#troubleshoot}

1. 如果 WCPOS 仍能正常工作，请继续销售。请勿重新安装、退出登录或清除其数据。
2. 在 **日志** 标签页中，点按顶部的 **复制调试信息** 并发送给 WCPOS 支持人员，同时说明该条目出现时您正在进行什么操作。
3. 打开 **商店健康 → 数据库**，告知支持人员其中显示有多少条 **待发送的更改**，以及是否显示 **"… 从未送达服务器的更改"** 或 **"… 更改被暂存"** 面板——这些更改仅存在于此设备上。
4. 日志条目没有指出哪类数据已损坏。待发送的更改清空后，支持人员可能会要求您重新下载某一类数据（其所在行的 **⋮** 菜单 → **清除并重新下载…**）。在支持人员确认具体类别前，请勿这样做：清除错误的数据，或在仍有待发送更改时清除数据，都可能删除店铺尚未收到的销售记录。如果损坏导致更改无法发送，支持人员会先恢复这些更改；只要还有任何待发送内容，就绝不要重新下载。
