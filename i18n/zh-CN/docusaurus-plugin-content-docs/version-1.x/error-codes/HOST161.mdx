## 含义说明 {#what-this-means}

主机正在对此商店的收银机进行限速。

即使应用已经在退避并遵守服务器的 Retry-After 延迟，服务器仍持续返回 429（请求过多）。同一互联网连接上的多台收银机共用一个地址，因此按来源的限速会将它们视为单个非常繁忙的客户端。同步会自动继续，但在限制被提高之前会有延迟。

## 你的数据 {#your-data}

订单或产品数据不会受到影响。

## 排查方法 {#troubleshoot}

1. 请求主机商为商店自己的流量提高或豁免 REST API 限速 —— 如果商店有静态 IP，请提供它。
2. 将重复的错误响应（429）计入封禁的安全服务（例如 Sucuri 的 IDS）可能需要将商店的 API 从该计数器中排除。
3. 如果多台收银机共用一个连接，请向主机商说明这一点：此处的一个 IP 代表的是整个商店，而非单个用户。
