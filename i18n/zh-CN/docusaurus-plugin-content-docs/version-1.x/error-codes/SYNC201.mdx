## 这意味着什么 {#what-this-means}

此记录被您的商店拒绝，目前仅保存在本设备上。

请针对指明记录所显示的原因进行修正，然后重试该记录。如果仍被拒绝，请导出诊断信息。

## 您的数据 {#your-data}

该更改已保存在本设备上，但尚未传到您的商店。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 展开日志条目：它会指明被拒绝的记录，并附带商店自己给出的拒绝原因（serverCode）。
2. 被拒绝的记录会列在商店健康中——打开该记录，修正商店拒绝的那个细节，然后从那里重试。
3. **站点管理员：**如果原因中提到 POS 未显示的字段，请在 WP Admin 中打开同一条记录并检查——其他插件可能添加了 POS 无法看到的验证规则。
4. 如果编辑后仍被拒绝，请使用“复制调试信息”并联系支持团队，同时提供 serverCode。
