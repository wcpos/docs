## 这意味着什么 {#what-this-means}

您的会话已结束，需要重新登录。

重新登录。不会丢失任何内容——登录后，未发送的更改会自动发送。

## 您的数据 {#your-data}

订单或商品数据不会受到影响。会话失效期间保存的销售记录会暂存在设备上，不会丢失；登录后会自动发送到店铺。

## 故障排查 {#troubleshoot}

1. 重新登录。WCPOS 会自动打开 WordPress 登录窗口；如果你已关闭该窗口，WCPOS 会再次提示你登录。请使用同一位收银员的账号登录。
2. 无需重新输入或保存任何内容：等待中的销售记录会在你重新登录后自动发送。要查看进度，请打开 **店铺健康 → 数据库**——**等待发送的更改**会降至 0。
3. 如果销售记录显示在 **“……更改从未到达服务器”**下，请点按该行上的 **重新发送**。
4. 频繁过期（每天多次）通常是网站端导致的：安全插件缩短了会话有效期或清除了令牌。请让网站管理员确认店铺启用了哪些安全插件，并检查 **WP Admin > POS > Settings > Tools > Logs**——被拒绝的登录及其原因会记录在此处。
