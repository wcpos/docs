## 这意味着什么 {#what-this-means}

您的会话已结束，需要重新登录。

重新登录即可继续操作。此前已保存的内容会保留在收银设备上，并在您重新登录后自动发送。

## 您的数据 {#your-data}

订单或商品数据不会受到影响。会话失效期间保存的销售记录会暂存在设备上，不会丢失；登录后会自动发送到店铺。

## 故障排查 {#troubleshoot}

1. 出现提示时请重新登录。等待发送的销售记录会自动发送，无需重新录入或再次点击保存。如需查看发送进度，请打开健康状态，再进入数据库。
2. 如果重新登录几分钟后，同一订单仍显示为等待发送，请在健康状态 → 数据库中找到该订单所在行，并点击重新发送。
3. 频繁过期（每天数次）通常是网站端造成的：安全插件可能缩短了会话有效期或清除了令牌。请询问网站管理员店铺启用了哪些安全插件，并请其检查 WP Admin → POS → 日志；被拒绝的登录及原因会记录在那里。
