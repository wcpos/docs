## 这意味着什么 {#what-this-means}

此设备上的更改与店铺中较新的编辑发生冲突。没有数据丢失。

如果 **Store health → Database** 列出了此记录的待处理更改，请点按 **Send again** 以保留此设备上的版本，或点按 **Use server version** 以保留店铺中的版本。否则无需操作——冲突已解决。

## 您的数据 {#your-data}

没有数据丢失。更改处于待处理状态时，店铺保留其版本，此设备保留其更改，直到您选择保留哪一个；在此之前，此设备上对该记录的进一步编辑都会等待。更改待处理期间请勿清除此设备上的数据——清除会删除该更改。

## 故障排查 {#troubleshoot}

1. 打开 **Store health → Database**。待处理更改会列在以 **"1 change was held"**（或 **"… changes were held"**）开头的面板中，并注明其所属记录。
2. 如果此记录已没有待处理更改，说明它已在此处或其他标签页中解决，无需操作。WCPOS 自动解决并重新发送此设备版本的订单冲突时，会记录为 [SYNC222](/error-codes/SYNC222)。
3. 如果更改仍待处理，请点按 **Open record**（如果显示该按钮）查看此设备上的版本，并与 WP Admin 中的同一条记录进行比较（可能需要站点管理员协助）。
4. 要保留此设备上的版本，请点按 **Send again**——更改会再次发送，并替换店铺中此设备所更改字段的值。要保留店铺中的版本，请点按 **Use server version**（有些行显示 **Discard device change**）并确认——此设备上的更改将被丢弃。在您作出选择前，对该记录的进一步编辑都会等待。
5. 同一记录频繁发生冲突，通常意味着两个人在同时编辑相同数据——例如一人在收银台修改库存，另一人在 WP Admin 中修改。请商定各类编辑分别在哪里进行。
