## 这意味着什么 {#what-this-means}

此设备上的更改遇到了店铺中较新的编辑内容。没有数据丢失。

如果 **商店健康 → 数据库** 中列出了此记录的一项暂存更改，请点按 **重新发送** 以保留此设备上的版本，或点按 **使用服务器版本** 以保留店铺版本。否则无需操作——冲突已经解决。

## 您的数据 {#your-data}

没有数据丢失。更改暂存时，店铺保留其版本，此设备保留其更改，直到您选择要保留哪一个；在此之前，此设备上对此记录的后续编辑都会等待。更改暂存期间，请勿清除此设备的数据——清除会删除暂存的更改。

## 故障排查 {#troubleshoot}

1. 打开 **商店健康 → 数据库**。暂存的更改会列在一个面板中，面板开头显示 **"1 个更改被暂存"**（或 **"… 更改被暂存"**），并注明对应的记录。
2. 如果此记录已没有暂存的更改，说明它已在此处或其他标签页中解决，无需操作。WCPOS 自动通过重新发送此设备上的版本来解决的订单冲突，则会记录为 [SYNC222](/error-codes/SYNC222)。
3. 如果有更改处于暂存状态，请点按 **打开记录**（若显示此选项）查看此设备上的版本，并与 WP Admin 中的同一记录进行比较（可能需要由站点管理员操作）。
4. 要保留此设备上的版本，请点按 **重新发送**——系统会再次发送此更改，并替换店铺中此设备所更改字段的值。要保留店铺版本，请点按 **使用服务器版本**（有些行会显示 **放弃设备更改**）并确认——此设备上的更改将被舍弃。在您作出选择前，对该记录的后续编辑都会等待。
5. 同一记录频繁发生冲突，通常意味着两人同时编辑相同数据——例如一人在收银台，另一人在 WP Admin 中更改库存。请商定每类编辑应在哪处进行。
