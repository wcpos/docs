## 这意味着什么 {#what-this-means}

本设备上的某个本地数据库无法创建或删除。

请重启 WCPOS 并再试一次。如果持续失败，可能是设备存储空间不足，或浏览器配置限制了存储；请释放空间，若问题依旧，请联系支持团队。

## 您的数据 {#your-data}

设备的本地数据库无法初始化或清除。这是存储空间/设置问题，而非未同步的编辑——请释放存储空间后重试；如果问题仍然存在，请导出诊断信息并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 重启 WCPOS 并再次尝试同一操作——大多数初始化失败都是暂时的。
2. 检查设备上的可用存储空间；当磁盘或浏览器的存储配额已满时，创建本地数据库会直接失败。
3. 在网页版中，请检查浏览器是否允许该站点使用持久化存储——隐私窗口和“阻止所有数据”设置不允许。
4. 如果持续失败，请导出调试信息并联系支持团队。
