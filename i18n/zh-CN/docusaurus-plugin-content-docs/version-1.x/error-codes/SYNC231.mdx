## 这意味着什么 {#what-this-means}

您的店铺已收到此更改，但此设备无法记录它已发送。

无需操作——请勿重新录入。WCPOS 会持续检查，店铺会忽略重复发送的内容。

销售或编辑已送达店铺并保存。之后，此设备连续三次尝试记录该更改已发送，但均未成功。因此，此设备仍将该更改显示为未发送，并会在下次同步时由 WCPOS 再次发送。店铺会根据更改的 id 识别它并忽略重复项，因此不会重复保存。真正的风险只有手动再次录入销售或编辑：那会创建第二份独立副本。

## 您的数据 {#your-data}

没有数据丢失。店铺已收到此更改。在此设备记录下重新发送已完成之前，该更改可能仍会计入待发送项。

## 故障排除 {#troubleshoot}

1. 请勿手动再次录入销售或编辑——店铺已经有记录，再次录入会造成重复项。
2. 要确认销售已送达店铺，请在 WP Admin 中检查 **WooCommerce → 订单**。该记录也会显示在 WCPOS 中，因为它保存在此设备上。
3. 让 WCPOS 继续同步。店铺会忽略下一次重发，通常随后会清除该条目；清除后，**商店健康 → 日志** 标题中的 **待发送的更改** 数量会减少。
4. 如果此情况持续出现，此设备可能无法正常保存到自身存储空间——请检查可用空间，然后点按 **日志** 标签页上的 **复制调试信息** 并联系支持人员。请勿通过清除此设备的数据来解决问题。
