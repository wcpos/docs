## 这意味着什么 {#what-this-means}

一些较早的商店更改被跳过，必须重新下载。

请对受影响的数据运行定向下载；如果差距仍然存在，请导出诊断信息。

## 您的数据 {#your-data}

店铺中的部分变更尚未传到本设备，因此下载完成前，本地数据可能已过时。本地变更不会有丢失风险。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 展开日志条目——其上下文记录了收银机落后了多少，以及是否有更改被跳过。
2. 对受影响的数据运行定向下载，以便重新获取被跳过的商店更改。
3. 之后，请抽查几条最近编辑过的记录并与 WP Admin 对照，确认差距已消除。
4. 如果差距再次出现，请导出调试信息并联系支持团队，而不要重置任何内容。
