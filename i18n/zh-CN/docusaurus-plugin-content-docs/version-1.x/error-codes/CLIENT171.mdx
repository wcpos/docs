## 这意味着什么 {#what-this-means}

此设备的时钟与店铺时钟相差超过一分钟。

将此设备的日期和时间设为自动更新。如果已经启用，请让站点管理员检查服务器时钟。

WCPOS 会将此设备的时钟与店铺服务器在响应中报告的时间进行比较。如果两者相差超过一分钟，订单时间、收据和报告可能会有偏差，直到两个时钟一致为止。

## 您的数据 {#your-data}

销售仍会保存。时钟不一致期间，只有记录的时间可能有偏差。

## 故障排查 {#troubleshoot}

1. 展开日志条目：其中会显示两个时钟相差多少，以及哪个时钟较快。
2. 打开此设备的日期和时间设置，并启用自动（网络）时间和时区。
3. **站点管理员：** 如果设备已设为自动更新时间，且设备时间正确，则问题出在服务器时钟。请让主机服务商检查服务器的日期、时间和时区。
4. 修复后重新打开 WCPOS。每次打开店铺时都会再次比较时钟；两者一致后，警告便会消失。
