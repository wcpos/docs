# DB02002: 记录未找到 {#db02002-record-not-found}

## 这意味着什么 {#what-this-means}

请求的记录在本地数据库中不存在。POS尝试访问未存储在本地的产品、客户、订单或其他记录。

## 常见原因 {#common-causes}

- **尚未同步** — 数据尚未下载
- **服务器上已删除** — 记录在WooCommerce中被移除
- **同步未完成** — 初始同步仍在运行
- **应用了过滤器** — 记录被活动过滤器排除

## 如何修复 {#how-to-fix}

### 1. 等待同步 {#1-wait-for-sync}

如果最近开始：
- 等待初始同步完成
- 检查同步进度指示器
- 记录应该在同步后出现

### 2. 刷新/重新同步 {#2-refreshre-sync}

触发数据刷新：
- 使用刷新/同步按钮 (<Icon name="arrow-rotate-right" />) - 短按以进行同步
- 请勿在此处选择通过**长按**打开的清除和刷新选项——这会清空此设备上的整个列表，包括从未保存的未结购物车；请先参阅步骤 5
- 从服务器拉取最新数据
- 等待完成

### 3. 检查WooCommerce {#3-check-woocommerce}

验证记录在服务器上存在：
- 登录WordPress Admin
- 检查产品、订单或客户
- 确认项目仍然存在

### 4. 检查过滤器 {#4-check-filters}

记录可能被过滤掉：
- 查看POS中的活动过滤器
- 检查类别过滤器
- 验证可见性设置

### 5. 清除并重新同步 {#5-clear-and-re-sync}

:::warning 请先检查是否有未保存的工作
清除本地数据或重新安装应用会删除此设备上尚未同步到店铺的所有内容，包括离线期间完成的销售、未结购物车以及未保存的编辑。清除前，请打开 **店铺健康 → 数据库**，确认没有项目被列为暂存或从未同步到服务器；然后打开 **店铺健康 → 日志**，确认有 **0 条卡住的记录**和 **0 项等待发送的更改**；再完成或记录所有未结购物车。如果 WCPOS 中没有“店铺健康”页面，请先更新 WCPOS，然后再检查。如果有任何项目被列出或正在等待，或者您无法检查，请勿清除数据；请联系店铺所有者或支持团队。
:::

只有在同步仍然卡住且完成上述检查后，才执行此操作：
1. 清除本地数据
2. 再次登录
3. 完成新的同步

## 常见场景 {#common-scenarios}

- **产品未显示：** 检查其是否已发布且可见
- **客户未找到：** 可能尚未同步
- **订单丢失：** 可能超出了同步日期范围
