## 这意味着什么 {#what-this-means}

显示的库存可能比商店中的库存更旧。

在完成可能导致超卖的销售之前，请先在商店中核实当前库存。

## 您的数据 {#your-data}

数据没有丢失风险 — 收银设备上的库存数量只是比店铺端的数据旧，等同步恢复后就会更新。如果问题持续存在，请联系负责管理 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

**在收银设备上：**销售低库存商品前，请确认实际数量 — 查看货架或向经理确认 — 不要只相信收银设备上的数字，因为它可能落后于店铺端数据。

**修复延迟：**库存数据过时通常表示同步失败或已暂停 — 请检查商店健康 → 日志中的同步错误并解决问题。同步恢复后，库存显示会自动更新。
