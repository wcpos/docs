## 这意味着什么 {#what-this-means}

付款已成功，但 WCPOS 随后无法刷新其状态。

付款已完成——请勿再次扣款。重新打开订单以更新其状态；如果状态仍未更新，请按下文所述刷新。

## 您的数据 {#your-data}

已收到付款——请勿再次扣款。只有屏幕上显示的状态尚未更新。

## 故障排查 {#troubleshoot}

1. 请勿再次向顾客收款。店铺的付款页面已确认付款（如果您看到 **订单 #… 付款已完成** 提示，即表示已确认），仅收银台后续更新失败。
2. 重新打开订单以更新其状态，然后继续处理下一笔销售。
3. 如果已付款的订单在购物车中仍显示为未结订单，请刷新收银台中的副本：打开 **店铺健康 → 数据库**，打开 **订单** 行上的 **⋮** 菜单，然后选择 **立即检查更改**。收到已付款状态后，订单便会从购物车中移除。在 WCPOS Pro 中，也可以只刷新该订单：在 **订单** 中打开该订单的 **⋮** 菜单，然后选择 **同步**。
4. 如果订单仍显示为未结，请重新加载应用（网页版重新加载浏览器标签页；桌面端和移动端请关闭并重新打开应用）。启动时，收银台会完成所有已记录付款的销售。
5. **网站管理员：**如需确认，请在 **WooCommerce → 订单** 中打开该订单——此处会显示已付款。
