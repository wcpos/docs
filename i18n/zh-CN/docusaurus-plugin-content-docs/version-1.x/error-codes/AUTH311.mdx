## 这意味着什么 {#what-this-means}

WCPOS 无法连接到店铺中的连接端点。

请让网站管理员确认 WCPOS 插件已启用（**WP Admin → 插件**），且没有安全插件阻止 REST API。

## 您的数据 {#your-data}

订单或商品数据均不受影响。请告知网站管理员。

## 故障排查 {#troubleshoot}

**在收银台**——收银员：请告知网站管理员。此设备上的内容不受影响。

**在店铺端** — 网站管理员：

1. 确认 WCPOS 已启用：WP Admin → 插件。
2. 如果两种 REST 形式都无法使用，请检查安全插件、代理或 CDN 是否移除了 WCPOS 请求标头或拦截了 REST 请求；常见原因是防火墙规则和禁用 REST API 的加固选项。
3. 在某些主机上，重新保存固定链接（设置 → 固定链接 → 保存）可以恢复缺失的 REST 路由。
