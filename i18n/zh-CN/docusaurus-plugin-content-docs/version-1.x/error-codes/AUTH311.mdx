## 这意味着什么 {#what-this-means}

WCPOS 商店路由不可用。

请网站管理员检查是否有安全或代理插件剥离了 WCPOS 的请求标头。

## 您的数据 {#your-data}

订单和产品数据不受影响。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

**在收银设备上** — 收银员：在浏览器中测试两种受支持的 REST 形式 — 店铺的 `/wp-json/` 地址和 `/index.php?rest_route=/`。只有两者都未返回 JSON 时，才能判断 REST 请求遭到拦截；然后将情况告知管理员。

**在店铺端** — 网站管理员：

1. 确认 WCPOS 已启用：WP Admin → 插件。
2. 如果两种 REST 形式都无法使用，请检查安全插件、代理或 CDN 是否移除了 WCPOS 请求标头或拦截了 REST 请求；常见原因是防火墙规则和禁用 REST API 的加固选项。
3. 在某些主机上，重新保存固定链接（设置 → 固定链接 → 保存）可以恢复缺失的 REST 路由。
