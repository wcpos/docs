# DB02001: 重复记录 {#db02001-duplicate-record}

## 这意味着什么 {#what-this-means}

数据库尝试插入一个已存在的 ID 的记录。每条记录必须有一个唯一的标识符。

## 常见原因 {#common-causes}

- **同步冲突** — 相同数据同步了两次
- **竞态条件** — 多个操作创建相同记录
- **数据损坏** — ID 被损坏或重复
- **导入问题** — 导入已存在的数据

## 如何修复 {#how-to-fix}

### 1. 刷新数据 {#1-refresh-data}

从服务器重新同步：
- 拉取最新数据
- 让同步过程解决冲突
- 更新的数据应优先使用

### 2. 重试操作 {#2-retry-the-operation}

如果创建新记录：
- 系统可能已经创建了它
- 检查记录是否存在
- 避免多次点击提交

### 3. 清除本地缓存 {#3-clear-local-cache}

:::warning 请先检查是否有未保存的工作
清除本地数据或重新安装应用会删除此设备上尚未同步到店铺的所有内容，包括离线期间完成的销售、未结购物车以及未保存的编辑。清除前，请打开 **店铺健康 → 数据库**，确认没有项目被列为暂存或从未同步到服务器；然后打开 **店铺健康 → 日志**，确认有 **0 条卡住的记录**和 **0 项等待发送的更改**；再完成或记录所有未结购物车。如果 WCPOS 中没有“店铺健康”页面，请先更新 WCPOS，然后再检查。如果有任何项目被列出或正在等待，或者您无法检查，请勿清除数据；请联系店铺所有者或支持团队。
:::

只有在步骤 1、2 和 4 无效且完成上述检查后，才重置本地数据：
1. 清除本地数据库/缓存
2. 重新登录
3. 新鲜同步数据

### 4. 检查 WooCommerce 中的重复项 {#4-check-for-duplicates-in-woocommerce}

如果问题依然存在：
- 检查 WooCommerce 中的重复条目
- 查找具有相同 ID 的产品/订单
- 在管理后台清理任何重复项

### 5. 报告持续问题 {#5-report-persistent-issues}

如果频繁发生：
- 记录导致此问题的操作
- 检查模式
- 向支持部门报告详细信息

## 为什么这很重要 {#why-this-matters}

重复的 ID 会导致：
- 不确定哪个记录是正确的
- 数据覆盖
- 同步问题

该错误可防止数据损坏。
