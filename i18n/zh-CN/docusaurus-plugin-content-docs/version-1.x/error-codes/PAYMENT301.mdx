## 这意味着什么 {#what-this-means}

所选的支付网关在此商店不可用。

请网站管理员确认该支付网关受支持、已启用且配置正确。

## 您的数据 {#your-data}

订单和产品数据不受影响。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

**在收银设备上：**与此同时，请改用其他方式（例如现金）完成销售。

**在店铺端** — 网站管理员：

1. 在 WooCommerce → 设置 → 付款中检查支付网关：必须已安装并启用，而且还须在 POS 设置中启用 POS 支付。
2. 如果该支付网关昨天还正常工作，请检查它或 WooCommerce 是否更新 — WooCommerce → 状态 → 日志中可能记录了网关初始化错误。
