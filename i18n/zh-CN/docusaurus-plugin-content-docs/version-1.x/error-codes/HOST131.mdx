## 含义说明 {#what-this-means}

商店前端的代理因响应头过多而拒绝服务器的响应。

缓存或代理层（通常是 Varnish）对响应头的数量或大小设有限制。商店的轻量端点符合限制，但完整的 API 响应超出了限制，于是返回的是来自代理（而非 WordPress）的 503。必须在那一层提高该限制。

## 你的数据 {#your-data}

订单或产品数据不会受到影响。

## 排查方法 {#troubleshoot}

1. 在 Varnish 上，提高 http_max_hdr（头部数量）以及 http_resp_hdr_len / http_resp_size（大小）。
2. 询问主机商是哪一层代理返回了 503 —— WordPress 错误日志中不会显示任何内容，因为请求从未在那里失败。
3. 一个快速检查方法：商店的 /wcpos/v2/ping 响应正常，而数据端点却返回 503。
