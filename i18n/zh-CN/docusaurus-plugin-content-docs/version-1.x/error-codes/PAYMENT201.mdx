## 这意味着什么 {#what-this-means}

WCPOS 无法确认终端是否已完成扣款。

在再次尝试扣款之前请检查支付终端；如果结果仍不明确，请联系支付服务商。

## 您的数据 {#your-data}

无法确认结果——请在重试之前先核实。如果问题持续存在，请联系您的支付服务商。

## 故障排查 {#troubleshoot}

1. 暂时不要再次刷卡。
2. 先查看终端自身的屏幕，再查看您的支付服务商后台——服务商的记录才是判断扣款是否成功的权威依据。
3. 如果您有 WP Admin 访问权限（或可请店铺所有者协助），请检查 WooCommerce → 订单 — 成功的付款可能已记录在那里。
4. 只有在服务商后台显示没有扣款之后，才再次收款。
5. 如果扣款显示为待处理或状态不确定，请先联系支付服务商再采取行动。
