# SY02001: 无效的配置 {#sy02001-invalid-configuration}

## 这意味着什么 {#what-this-means}

系统配置无效或已损坏。POS 应用程序发现配置设置不合逻辑或不完整。

## 常见原因 {#common-causes}

- **损坏的设置** — 配置文件已损坏
- **设置不完整** — 设置过程未完成
- **手动编辑错误** — 配置文件被错误修改
- **版本升级问题** — 旧配置与新版本不兼容

## 如何修复 {#how-to-fix}

### 1. 重置为默认设置 {#1-reset-to-default-settings}

如果在应用程序中可用：
- 查找“重置设置”或“恢复默认值”
- 这会清除自定义设置，但可修复损坏。如果重置操作提示要移除您的店铺或其数据，请停止操作，并先按照第 3 步警告中的说明进行检查

### 2. 完成设置 {#2-complete-the-setup}

如果设置未完成：
1. 再次启动设置过程
2. 完成所有必需步骤
3. 在完成之前验证配置

### 3. 清除应用程序数据 {#3-clear-application-data}

:::warning 请先检查是否有未保存的工作
清除本地数据或重新安装应用会删除此设备上尚未同步到店铺的所有内容，包括离线期间进行的销售、未结账购物车以及未保存的编辑。清除任何内容前，请打开 **店铺健康 → 数据库**，确认没有内容标记为暂存或从未到达服务器；然后打开 **店铺健康 → 日志**，确认 **0 条卡住的记录**且 **0 项更改等待发送**；最后完成或记录每个未结账购物车。如果您的 WCPOS 没有“店铺健康”页面，请先更新 WCPOS，然后再检查。如果有任何内容被列出或正在等待，或者您无法检查，请勿清除数据——请咨询店铺所有者或联系支持人员。
:::

仅当此页面上的其他步骤无效且完成上述检查后，才移除损坏的配置：
- **桌面：** 删除应用程序数据文件夹，重启应用
- **浏览器：** 清除网站数据，重新加载

### 4. 重新安装应用程序 {#4-reinstall-the-application}

:::warning 请先检查是否有未保存的工作
清除本地数据或重新安装应用会删除此设备上尚未同步到店铺的所有内容，包括离线期间进行的销售、未结账购物车以及未保存的编辑。清除任何内容前，请打开 **店铺健康 → 数据库**，确认没有内容标记为暂存或从未到达服务器；然后打开 **店铺健康 → 日志**，确认 **0 条卡住的记录**且 **0 项更改等待发送**；最后完成或记录每个未结账购物车。如果您的 WCPOS 没有“店铺健康”页面，请先更新 WCPOS，然后再检查。如果有任何内容被列出或正在等待，或者您无法检查，请勿清除数据——请咨询店铺所有者或联系支持人员。
:::

仅当问题持续存在且完成上述检查后，才执行以下操作：
1. 完全卸载
2. 删除任何剩余的数据文件夹
3. 重新安装
4. 从头开始完成设置

### 5. 检查更新 {#5-check-for-updates}

配置格式可能会变化：
- 更新 POS 应用程序
- 更新 WCPOS 插件
- 更新后重新配置

## 重置时会重置什么 {#what-gets-reset}

重置配置时：
- 您需要重新登录
- 自定义设置将丢失
- 数据将需要重新同步
- 您的 WooCommerce 数据安全地保存在服务器上，但此设备上从未同步到店铺的内容（例如未结账购物车）将会丢失
