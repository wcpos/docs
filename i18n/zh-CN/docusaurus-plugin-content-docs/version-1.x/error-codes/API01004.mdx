# API01004：DNS 解析失败 {#api01004-dns-resolution-failed}

## 这意味着什么 {#what-this-means}

POS 无法将您网站的域名（例如 `yourstore.com`）转换为 IP 地址。DNS（域名系统）就像互联网的电话簿 — 如果找不到对应记录，就无法建立连接。

## 常见原因 {#common-causes}

- **域名拼写错误** — URL 可能存在拼写错误
- **DNS 服务器问题** — DNS 服务器没有响应
- **域名已过期** — 域名注册可能已失效
- **DNS 传播** — 最近的 DNS 更改尚未传播完成
- **本地 DNS 缓存** — 设备缓存的 DNS 信息已过时

## 解决方法 {#how-to-fix}

### 1. 核对域名 {#1-verify-the-domain-name}

仔细检查 URL 是否有拼写错误。尝试在浏览器中访问该网站。

### 2. 检查域名状态 {#2-check-domain-status}

使用 WHOIS 查询确认：
- 域名仍处于注册状态
- 域名尚未过期
- DNS 记录已配置

### 3. 清除 DNS 缓存 {#3-clear-dns-cache}

**在您的设备上：**

macOS：
```bash
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
```

Windows：
```bash
ipconfig /flushdns
```

### 4. 尝试使用其他 DNS {#4-try-alternative-dns}

切换到公共 DNS 服务器，例如：
- Google：`8.8.8.8` 和 `8.8.4.4`
- Cloudflare：`1.1.1.1`

### 5. 等待 DNS 传播 {#5-wait-for-dns-propagation}

如果您最近更改了 DNS 设置，请等待 24-48 小时，让更改完全传播。
