## 这意味着什么 {#what-this-means}

WCPOS 遇到了意外错误。

重试前，请检查上一步操作是否已完成——对于销售，请打开订单并检查其状态。如果问题再次出现，请点按 **Copy debug info** 并发送给 WCPOS 支持团队。

## 您的数据 {#your-data}

无法确认结果——重试前请先检查。如果问题再次出现，请在 **Logs** 标签页中使用 **Copy debug info**，并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 重试前，请检查上一步操作是否已完成——对于销售，请打开订单并检查其状态；对于付款，还要检查终端或支付服务提供商。如果操作未完成，请再尝试一次。
2. 展开日志条目，记下事件代码和上下文——999 代码表示该故障尚无专属代码，而这些正是用来识别它的信息。
3. 如果问题再次出现，请在 **Logs** 标签页中点按 **Copy debug info** 并发送给 WCPOS 支持团队——报告问题后，才会添加相应的特定代码。
