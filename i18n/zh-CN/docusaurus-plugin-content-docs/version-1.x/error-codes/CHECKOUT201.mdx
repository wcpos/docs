## 这意味着什么 {#what-this-means}

WCPOS 无法确认结账是否已完成。

请不要盲目重试。请先在商店中查找该订单，如果其结果仍不明确，再导出诊断信息。

## 您的数据 {#your-data}

无法确认结果——请在重试之前先核实。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

**首先，请勿让情况恶化：**在确认订单是否存在前，不要重试结账，也不要再次向客户收款。

**确认订单是否存在** — 具体方法取决于您能访问的内容：如果使用 WCPOS Pro，请同步 POS 并查看收银设备的订单列表；否则，请让他人打开 WP Admin 中的 WooCommerce → 订单，并按总额和最近几分钟的时间范围搜索。如果订单已存在，说明销售已完成 — 请勿再次创建。

**然后：**如果检查后确认没有订单，请重试结账一次。如果仍无法确定，请先导出调试信息并联系支持团队，再进行其他尝试。
