## 这意味着什么 {#what-this-means}

WCPOS 无法确认结账是否已完成。

重试前请打开订单并检查其状态。如果订单已付款或已完成，请勿再次收费。

## 您的数据 {#your-data}

无法确认结果——请先检查，再重试。如果问题持续，请在 **日志** 标签页中使用 **复制调试信息**，并联系 WCPOS 支持。

## 故障排查 {#troubleshoot}

1. 在确认订单状态前，请勿再次按 **处理付款**，也不要再次向顾客收费。
2. 打开订单并检查其状态。使用 WCPOS Pro 时，请先刷新收银台的订单——打开 **店铺健康 → 数据库**，点按 **订单** 行上的 **⋮** 菜单，再选 **立即检查更改**——然后在 **订单** 中打开订单。没有 Pro 时，请让他人在 WP Admin 的 **WooCommerce → 订单** 中按总金额和最近几分钟的时间范围搜索。
3. 找到订单并不代表已付款——订单可能存在但尚未付款。如果状态为 **处理中** 或 **已完成**，则销售已成功：请勿再次收费。
4. 如果订单仍未付款或找不到订单，请检查顾客是否已付款——刷卡付款请查看支付服务提供商自己的界面、收据或控制面板；现金付款请检查钱箱和收款金额。如果顾客已付款，请勿再次收费。如果找到订单，请重新加载应用并再次检查其状态（启动时，收银台会完成已记录付款的销售）；如果找不到订单或仍未付款，请执行最后一步。
5. 如果订单未付款，且支付服务提供商的记录中没有扣款，请重试结账一次。
6. 如果仍无法确定，请在再次尝试前使用 **日志** 标签页中的 **复制调试信息** 并联系支持人员。
