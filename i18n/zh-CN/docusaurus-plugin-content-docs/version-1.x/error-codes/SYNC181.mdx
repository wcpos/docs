## 这意味着什么 {#what-this-means}

此设备上的保存或加载速度非常慢，结果目前尚不明确。

如果 WCPOS 正常运行，则无需处理。如果某个屏幕一直卡住，请重新加载 WCPOS，然后检查上次更改是否已保存。

此设备上的本地数据库有一项读取或写入操作长时间未得到响应，但数据库仍在响应其他所有操作。此报告程序只记录停滞情况，不会取消或重试该操作，因此原始调用可能仍会在之后完成或失败；创建此条目是为了让卡住的屏幕或加载指示器留下记录，明确指出是哪项操作发生了停滞。停滞的同步工作有单独的超时和重试机制——会记录为 [SYNC321](/error-codes/SYNC321) 中的“已放弃停滞的数据请求”条目。来自屏幕的停滞调用会一直处于等待状态，直到完成或重新加载应用。

## 数据 {#your-data}

无法确认操作结果——请先检查，再决定是否重试。停滞的操作通常是查询，不会造成任何更改。如果当时正在保存更改，请打开相应记录并确认是否已保存——可能完全没有明显迹象。条目的上下文会注明所涉及的操作和数据集合。

## 故障排除 {#troubleshoot}

1. 如果 WCPOS 正常运行，则无需处理——该调用很可能只是完成得较慢。如果条目中的操作是保存，请打开相应记录并确认是否已保存。
2. 如果屏幕或加载指示器一直卡住，请重新加载应用——在 Web 端，重新加载浏览器标签页；在桌面端和移动端，关闭后重新打开应用。这会放弃停滞的操作；屏幕会重新加载并重新向数据库发起请求。正在进行的保存不会重新发送——请打开记录并确认其已保存。
3. 如果此代码在同一设备上反复出现，请在 **日志** 标签页中使用 **复制调试信息** 并联系支持人员——条目的上下文会注明操作和集合、确切的等待时间，以及期间数据库的繁忙程度。
