## 这意味着什么 {#what-this-means}

本地数据库操作耗时远超正常情况；其结果尚不明确。

此设备上的本地数据库有一项读取或写入操作长时间未得到响应，但数据库仍在响应其他所有操作。此报告程序只记录停滞情况，不会取消或重试该操作，因此原始调用可能仍会在之后完成或失败；创建此条目是为了让卡住的屏幕或加载指示器留下记录，明确指出是哪项操作发生了停滞。停滞的同步工作有单独的超时和重试机制——会记录为 [SYNC321](/error-codes/SYNC321) 中的“已放弃停滞的数据请求”条目。来自屏幕的停滞调用会一直处于等待状态，直到完成或重新加载应用。

## 数据 {#your-data}

停滞的操作通常是查询，不会更改任何内容。如果当时正在保存更改，请打开记录并确认其已保存——也可能完全没有可见症状。条目的上下文会标明相关操作和数据集合。

## 故障排除 {#troubleshoot}

1. 如果一切正常运行，无需采取任何操作——该调用很可能已经完成，只是速度较慢。
2. 如果屏幕或加载指示器一直卡住，请重新加载应用——在 Web 端，重新加载浏览器标签页；在桌面端和移动端，关闭后重新打开应用。这会放弃停滞的操作；屏幕会重新加载并重新向数据库发起请求。正在进行的保存不会重新发送——请打开记录并确认其已保存。
3. 如果此代码在同一设备上经常出现，请从日志屏幕导出调试信息并联系支持团队——条目的上下文会标明操作和集合、确切的等待时间，以及期间数据库的繁忙程度。
