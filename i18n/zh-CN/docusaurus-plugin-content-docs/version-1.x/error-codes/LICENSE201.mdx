## 这意味着什么 {#what-this-means}

WCPOS Pro 已被停用，因为其版本与 WCPOS 不匹配。

请更新指明的 WCPOS 或 WCPOS Pro 组件，使两者版本兼容。

## 您的数据 {#your-data}

订单和产品数据不受影响。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

1. 在 WP Admin → 插件 中检查两个插件的版本——日志条目会指明 WCPOS 和 WCPOS Pro 中哪一个版本落后。
2. 请更新版本较旧的那一个；将两者都更新到最新版本即可解决版本错配。
3. 如果没有提供 Pro 更新，可能是更新程序未获授权（参见 LICENSE301）——请先解决该问题，然后再更新。
