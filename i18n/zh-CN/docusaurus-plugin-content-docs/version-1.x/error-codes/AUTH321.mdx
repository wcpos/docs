## 这意味着什么 {#what-this-means}

WooCommerce 未在此网站上启用，因此 WCPOS 无法连接。

WCPOS 需要 WooCommerce 插件。请网站管理员安装或重新启用 WooCommerce，然后重新连接。

## 您的数据 {#your-data}

订单和产品数据不受影响。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

1. 请网站管理员检查 WP Admin → 插件：WooCommerce 必须已安装并已启用，WCPOS 才能连接。
2. 如果 WooCommerce 因更新失败而被停用，请重新启用它并留意错误横幅——WooCommerce → 状态 → 日志 中记录了失败原因。
3. WooCommerce 重新启用后，请从收银机上重新连接。
