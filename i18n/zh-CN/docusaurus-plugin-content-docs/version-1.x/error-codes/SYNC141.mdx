## 这意味着什么 {#what-this-means}

您的店铺要求 WCPOS 暂缓片刻。

无需处理——WCPOS 会自动等待并重试。如果每天都出现此情况，请向站点管理员咨询店铺的速率限制。

## 您的数据 {#your-data}

请勿清除此设备的数据——其中可能包含店铺尚未收到的更改。这些更改会在之后的尝试中发送。

## 故障排查 {#troubleshoot}

1. 无需处理——POS 会自动退避并重试；手动重试只会延长限流时间。
2. 无需重新录入任何内容：受影响的更改会保留在设备上，并在稍后的尝试中成功提交。
3. 如果每天都出现此情况，请让站点管理员找出返回 429 的环节——安全插件、CDN、防火墙规则或主机自身的限制——并允许 POS 的 REST 流量。
4. 展开后的日志条目中的端点和时间戳，可帮助管理员在他们自己的后台中对应上限流记录。
