## 这意味着什么 {#what-this-means}

您的商店正在临时限制请求，因此此操作稍后会重试。

请稍候再重试。如果限流持续存在，请让网站管理员或主机服务商检查商店的请求限制。

## 您的数据 {#your-data}

该更改已保存在本设备上，但尚未传到您的商店。如果问题持续存在，请咨询管理您 WordPress 网站的人员。

## 故障排查 {#troubleshoot}

1. 请等待——POS 会自行退避并重试；手动重试只会延长限流时间。
2. 无需重新录入任何内容：受影响的更改会保留在设备上，并在稍后的尝试中成功提交。
3. 如果该代码持续出现，请让网站管理员查明是哪一层返回了 429——安全插件、CDN 或防火墙规则，还是主机自身的限制——并放行 POS 的 REST 流量。
4. 展开后的日志条目中的端点和时间戳，可帮助管理员在他们自己的后台中对应上限流记录。
