## 这意味着什么 {#what-this-means}

此设备将自己的版本保存到了店铺中，覆盖了较新的编辑。

请在 WP Admin 中检查日志条目列出的字段。如果店铺中的编辑才是正确的，请在那里重新进行编辑。

这种情况会发生在订单上。此设备上次下载订单后，店铺中的订单又被更改了——可能是有人在 WP Admin 中修改，也可能是插件或支付通知自动修改。随后此设备将自己的订单更改保存到店铺时，店铺报告了冲突。为了不耽误收银台的销售，WCPOS 再次发送此设备上的版本并覆盖店铺版本，店铺也接受了它。日志条目会列出此设备的值替换了店铺中不同值的所有字段。其中有些可能是此设备自身的更改（例如添加的商品行或在收银台设置的状态），而不一定是店铺中的编辑。

如果连续两次发生相同冲突，WCPOS 会改为暂存更改并让您选择——请参阅 [SYNC221](/error-codes/SYNC221)。

## 您的数据 {#your-data}

订单已在店铺中保存为此设备上的版本，收银台上的内容没有丢失。可能需要重新进行的是店铺中较新的编辑，具体字段见列表。日志会列出哪些字段被替换，但不会显示其旧值。如果条目注明只显示了部分字段，则实际被替换的字段更多——请检查整个订单。

## 故障排查 {#troubleshoot}

1. 展开日志条目：其中会注明订单，并列出此设备上的值替换了店铺值的字段。
2. 在 WP Admin 中打开 **WooCommerce → 订单** 中的订单，并检查这些字段。订单备注可能会显示是谁或什么操作更改了店铺中的订单。
3. 如果这些字段当前的值正确（例如它们正是在收银台所做的更改），则无需操作。
4. 如果店铺中的编辑才是正确的，请在 WP Admin 中重新进行编辑。收银台会在下次同步时获取更改。
5. 如果这种情况持续发生，说明有两个地方同时更改了相同的订单——例如销售仍在收银台保持打开时，有人在 WP Admin 中设置了状态；或者某个插件在订单创建后更新了订单。请商定各类订单编辑分别在哪里进行；站点管理员可以检查是哪个插件在编辑订单。
