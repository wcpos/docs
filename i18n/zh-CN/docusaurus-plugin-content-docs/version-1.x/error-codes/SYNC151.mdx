## 这意味着什么 {#what-this-means}

店铺的响应中包含多余文本，WCPOS 已尝试清理。

请检查您正在执行的操作是否已完成——清理并不总是成功。多余文本通常来自某个插件或 PHP 通知，它们向店铺响应中输出了额外内容。如果此情况频繁出现，请让站点管理员检查站点的 PHP 错误日志中是否有警告。

## 您的数据 {#your-data}

如果您正在执行的操作没有完成（请参阅故障排除步骤 1），请按照该请求的指引操作；否则，订单或商品数据不会受到影响。如果此情况频繁出现，请联系负责管理 WordPress 站点的人员。

## 故障排查 {#troubleshoot}

1. 请检查您正在执行的操作是否已完成——例如，销售记录或更改现在是否已显示。如果已显示，则无需进一步处理。如果没有，请重试；如果仍然失败，请按照显示的错误说明操作，或联系支持人员。
2. 原因出在网站上：某个插件或主题正在向 REST 响应中输出警告或多余内容。请让网站管理员检查网站日志中故障时段的 PHP 通知。
3. **供站点管理员参考：**浏览器的开发者工具（网络选项卡）——或桌面应用中的 **高级 → 切换开发者工具**——可显示原始响应正文；多余的输出内容紧挨着 JSON 的前面或后面。
4. **供站点管理员参考：**清理仅尽力而为——如果此情况频繁出现，请修复有问题的插件，而不要依赖清理功能。
