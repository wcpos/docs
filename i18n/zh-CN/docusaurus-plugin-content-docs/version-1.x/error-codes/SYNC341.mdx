## 这意味着什么 {#what-this-means}

此店铺现在需要较新版本的 POS 应用。

店铺的 WCPOS 插件已升级到比此版本应用支持的更新同步协议，因此店铺会有意暂停同步，直到应用完成更新。这是一项保护措施，并非故障：它可防止过时的应用错误读取或写入店铺数据。

## 数据 {#your-data}

收银终端上的任何数据都不会丢失。等待发送的销售记录和编辑内容会安全保留在设备上，并会在更新后的应用连接到店铺后同步。如果尚未提供较新版本的应用（请参阅下面最后两个步骤），这些内容会一直排队等待，直到有可用版本为止。

## 故障排除 {#troubleshoot}

1. 在 Web 应用中，重新加载浏览器标签页——Web 应用会在重新加载时获取新版本。如果仍显示此页面，请执行强制重新加载（重新加载时按住 **Shift**）。
2. 在桌面版中，安装待处理的更新后重新打开应用——应用重新连接时会执行检查。如果未提供更新，请从[安装](/getting-started/installation)页面下载最新版本。
3. 在 iPhone、iPad 或 Android 上，请通过安装 WCPOS 时使用的渠道进行更新——iOS 使用 TestFlight，Android 使用 Play 测试计划；两者的链接均位于[安装](/getting-started/installation)页面——然后重新打开应用。
4. **网站管理员：**如果尚无可用的新版本应用，说明店铺的 WCPOS 插件已先于对应的应用版本发布而更新。将店铺中的 WCPOS 插件恢复至上一版本可继续同步，直到新版本应用发布。
5. 如果既无法更新应用，也无法回退插件，请联系 WCPOS 支持团队。
