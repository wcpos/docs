## 这意味着什么 {#what-this-means}

此设备的存储已停止响应，因此暂停了保存。

重启 WCPOS（在网页端，请重新加载标签页），然后检查上次销售或更改是否已保存——存储停止响应前几秒内进行的更改可能尚未写入。请勿清除此设备的数据。如果问题持续出现，请联系支持人员。

## 您的数据 {#your-data}

请勿清除此设备的数据——其中可能包含店铺尚未收到的销售记录。如果问题持续出现，请在 **日志** 标签页中使用 **复制调试信息**，并联系 WCPOS 支持人员。

## 故障排查 {#troubleshoot}

1. 重启 WCPOS——关闭并重新打开应用；在网页端，请重新加载标签页，而不要关闭它。几乎所有情况下，这都能重新连接本地数据库。
2. 重启后，请检查上次销售或更改是否已保存：故障发生前几秒内进行的更改可能尚未写入。如果没有保存，请重新输入。
3. 在网页端，请勿在隐私/无痕窗口中运行收银台，并避免使用过度清理存储空间的扩展程序——两者都可能在会话中途关闭本地存储；关闭隐私窗口还会删除其中存储的所有内容，包括尚未发送的销售记录。如果您当前正在使用此类窗口，请保持打开状态，直到 **店铺健康 → 数据库** 显示 0 项 **待发送更改**。
4. 如果此问题在同一设备上反复出现，请在 **日志** 标签页中使用 **复制调试信息** 并联系支持人员，同时说明问题发生时设备正在进行什么操作（休眠、切换标签页、内存不足）。
