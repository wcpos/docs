## 含义说明 {#what-this-means}

此商店的 WCPOS 插件版本对于当前应用版本来说过旧。

应用已更新，但商店上的 WCPOS 插件尚未更新，两者版本已不再兼容。请让网站管理者在 WP Admin 中将 WCPOS 插件更新到最新版本，然后重新连接。收银机端无需做任何更改。

## 你的数据 {#your-data}

订单或产品数据不会受到影响。如果问题持续存在，请咨询管理你 WordPress 网站的人员。

## 排查方法 {#troubleshoot}

**在商店端** —— 面向 WordPress 网站的管理者：

1. WP Admin → 插件 → 将 WCPOS 更新到最新版本。如果安装了 WCPOS Pro，请同时将其更新到匹配的版本。
2. 如果没有提示可用更新，请查看 WP Admin → 仪表盘 → 更新；对于 Pro，未授权的更新程序会阻止更新（参见 [LICENSE301](./LICENSE301)）—— 请先解决该问题。

**在收银机端** —— 面向收银员：商店更新完成后，重新连接即可。你无需再次输入商店地址。

**如果商店暂时无法更新：** 请改为联系支持团队 —— 收银机需要一个与插件匹配的应用版本，支持团队可以告诉你应该用哪个版本。他们会询问应用版本（从收银机获取）以及商店当前的 WCPOS 版本（从 WP Admin 获取）。
