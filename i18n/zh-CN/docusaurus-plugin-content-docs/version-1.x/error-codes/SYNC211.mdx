## 这意味着什么 {#what-this-means}

店铺拒绝了记录中的某个字段。偶尔，此代码也表示店铺拒绝了某项设置或身份验证请求。

如果条目指出了某条记录，请修正指定字段并重试；在同步完成前，本地副本仍可使用。否则，请按照店铺针对指定请求返回的消息处理。

## 您的数据 {#your-data}

如果这是记录变更，它仍保存在本设备上，尚未传到您的店铺。设置或身份验证请求则没有需要保存的内容。

## 故障排查 {#troubleshoot}

1. 请先展开日志条目并检查端点和服务器响应：此代码也可能表示来自设置、身份验证或其他非记录类请求的 HTTP 400。
2. 如果上下文指明了某条记录或字段，请在 POS 中编辑该字段——常见原因是取值超出范围、格式被拒绝，或必填选项留空——然后重试。
3. 如果这不是记录请求，请改为按照服务器针对指定端点返回的消息处理。如果 POS 日志中没有详细信息，可在浏览器开发者工具的网络选项卡中查看响应；桌面应用中则可选择 **高级 → 切换开发者工具**。
4. **站点管理员：**如果 POS 中显示指定字段无误，请在 WP Admin 中对比同一条记录——店铺上由插件添加的验证规则可能会拒绝 POS 认为正确的值。
