## 这意味着什么 {#what-this-means}

同步遇到了意外问题。

已在本设备上记录的销售数据是安全的。请先查看日志（见“故障排查”）：系统可能会自动重试；如果写入从未进入队列，则需要重新录入。如果此代码持续出现，请导出诊断信息并联系支持团队。

## 您的数据 {#your-data}

如果您的录入已被捕获，它会安全保存在本设备上，但尚未传到您的店铺；如果日志显示写入在进入队列前失败（见“故障排查”步骤 2），请重新录入。如果问题持续存在，请导出诊断信息并联系 WCPOS 支持团队。

## 故障排查 {#troubleshoot}

1. 不要想当然地认为此代码会自动重试。请先展开日志条目：如果它确认该变更已进入队列，WCPOS 会自动重试，因此请保持应用打开，让队列自行处理完毕。
2. 如果错误显示引擎常驻进程缺失，或写入在返回变更 ID 之前就已失败，则没有任何内容进入队列——请回到该记录或订单并重新保存。
3. 展开日志条目，记下事件代码和任何 serverCode：999 代码表示具体原因尚无专属代码，因此这些上下文正是支持团队所需要的。
4. 如果该代码持续出现，请使用“复制调试信息”并联系支持团队——正是通过上报，才能为它添加专属代码。
