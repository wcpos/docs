WCPOS 在所有平台上都支持扫描条码：可使用设备的**摄像头**、普通的**键盘模式**扫描器，或与 USB 或蓝牙扫描器建立**直接连接**。大多数扫描器插入或配对后即可使用。以下页面介绍设置向导、收银机上的扫描行为，以及检测设置的微调方法。

## 扫描方式 {#ways-to-scan}

- **摄像头**——Web、桌面、iOS 和 Android 均支持。通过搜索栏中的扫描图标打开摄像头后，它会以可调整大小的面板显示在筛选器下方，让产品列表始终可见。无需额外硬件。
- **键盘模式（HID）**——几乎所有扫描器的出厂默认模式。扫描器会“输入”条码，WCPOS 则识别这些快速的按键输入。无需配置，插入或配对后即可扫描。
- **直接连接**——适用于已切换到串行或 POS 模式的扫描器：USB 串行和 HID-POS（通过浏览器的 Web Serial 和 WebHID 支持）、蓝牙 SPP，以及通过厂商 GATT 服务连接的蓝牙 LE。直接连接会将每次扫描结果直接传递给 WCPOS，不受输入速度、键盘布局或当前焦点字段的影响。桌面应用和基于 Chrome 的浏览器均支持此方式；桌面应用会在应用内显示设备选择器。

:::note 哪个字段是条码？
WCPOS 根据一个已配置的条码字段匹配扫描结果，默认使用 WooCommerce 的 GTIN 字段(`_global_unique_id`)。你可以在[设置](/1.x/settings/wp-admin/general#barcode-field)中将其指定为 `_sku` 或任意自定义元数据键；更改后，本地条码索引会自动重建。
:::
