WCPOS 在所有平台上都可以扫描条码 —— 可使用设备**摄像头**、普通的**键盘模式**扫描器，或通过与 USB 或蓝牙扫描器的**直接连接**。大多数扫描器在你插入或配对后即可立即使用；下面的页面介绍了引导式设置、扫描在收银机上的行为，以及如何微调检测。

## 扫描方式 {#ways-to-scan}

- **摄像头** —— 在 Web、桌面、iOS 和 Android 上均可用。从搜索栏中的扫描图标打开摄像头；它会以可调整大小的面板形式出现在筛选器下方，以便产品列表保持可见。无需额外硬件。
- **键盘模式（HID）** —— 几乎所有扫描器的出厂默认设置。扫描器会“输入”条码，而 WCPOS 会识别出这些快速的按键。无需任何配置 —— 插入或配对后即可扫描。
- **直接连接** —— 适用于已切换到串行或 POS 模式的扫描器：USB 串行和 HID-POS（通过浏览器的 Web Serial 和 WebHID 支持）、蓝牙 SPP，以及通过厂商 GATT 服务的蓝牙 LE。无论输入速度、键盘布局或焦点在哪个字段，直接连接都会将每次扫描直接传递给 WCPOS。桌面应用和基于 Chrome 的浏览器均支持；桌面应用会在应用内显示设备选择器。

:::note 哪个字段是条码？
WCPOS 会将扫描结果与单个已配置的条码字段进行匹配，该字段默认为 WooCommerce 的 GTIN 字段（`_global_unique_id`）。你可以在[设置](/settings/wp-admin/general#barcode-field)中将其指向 `_sku` 或任意自定义 meta 键；更改后会自动重建本地条码索引。
:::
