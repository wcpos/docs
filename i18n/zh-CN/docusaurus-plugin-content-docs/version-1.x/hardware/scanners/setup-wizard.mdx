  <WizardStep id="kb-first-d" title="先从键盘模式开始——无需任何配置">

几乎每一台扫描仪出厂时都表现为一个 **键盘**：它会把每个条形码“打”出来。WCPOS 会把这些快速按键识别为一次扫描。没有任何东西需要配置。

1. **USB 扫描仪：** 插上就行——就这么简单。
2. **蓝牙扫描仪：** 让它进入配对模式（查看说明书——通常是长按扳机或听到一段提示音），然后像配对普通键盘一样在 **系统蓝牙设置** 中配对它。
3. 打开 WCPOS 并扫描任意产品条形码。产品应当出现并被添加到这笔销售中。

  <WizardFix id="fix-nothing" title="当扫描毫无反应时">

1. **扫描仪有反应吗？** 扣一下扳机——没有蜂鸣声或灯光，说明是电源/电池问题，不是 WCPOS 的问题。
2. **它连接上了吗？** 蓝牙设置中必须显示 **已连接**，而不只是“已配对”。不确定就重新配对。
3. **验证它能打字：** 打开任意记事应用或一个空白文本框并扫描。如果字符出现在那里，说明扫描仪没问题——只是 POS 没有把这些输入识别为一次扫描。
4. 如果它能打字但 WCPOS 忽略了它：打开 <kbd>设置</kbd> → <kbd>条形码扫描</kbd> 并朝 **测试面板** 扫描。它会准确说明每次尝试为什么被当成了打字，并通过 **应用** 按钮给出修复建议（例如提高时序阈值）。

  </WizardFix>

  <WizardFix id="fix-garbled-d" title="当扫描结果出现乱码时">

键盘模式的扫描仪是通过 **键盘布局** 来“打字”的。如果扫描仪的布局与你设备的布局不一致（QWERTY 与 AZERTY、符号位置不同），字符就会错位。

1. 朝 **测试面板** 扫描（<kbd>设置</kbd> → <kbd>条形码扫描</kbd>）。它能识别常见情况——比如扫描仪把 Shift 作为独立按键发送——并告诉你它看到了什么。
2. 在扫描仪说明书中查找 **“keyboard language”**（键盘语言）或 **“keyboard layout”**（键盘布局）设置条形码，把它设置成与你的设备一致（美式布局通常是稳妥的选择）。
3. 最彻底的解决办法是 **直连**。直连的扫描仪把条形码作为数据发送——完全不涉及键盘布局，所以什么都乱不了。

  <WizardFix id="fix-focus-d" title="扫描落到错误的位置，或没有焦点时丢失">

这是键盘模式与生俱来的局限：扫描仪会把内容打进 **当前拥有焦点的任何地方**。如果光标停在数量字段里，条形码就会落到那里；如果焦点在另一个窗口上，扫描内容就会跑到那个窗口。

在这个平台上真正的解决办法是 **直连**：每次扫描都会被直接送到 WCPOS——不受焦点影响，即使 POS 在后台标签页中也一样。

  <WizardFix id="fix-osk-a" title="把屏幕键盘找回来">

手机和平板在连接了硬件键盘时会隐藏屏幕键盘——而键盘模式的扫描仪 *就是* 一个硬件键盘。这是操作系统的行为，不是 WCPOS 的设置。

1. **大多数扫描仪都有把它切换回来的快捷方式**——通常是长按扳机或某个小功能键几秒钟（Inateck：长按扫描键约 3&nbsp;秒）。在扫描仪说明书中查找 *“iOS keyboard”* 或 *“virtual keyboard”*。
2. 或者在需要大量打字时，在蓝牙设置中断开扫描仪的连接。
3. 在 Android 上，在 WCPOS 中 **注册扫描仪** 可以彻底避免这个问题——已注册的扫描仪对 POS 输入框而言不再算作打字用的键盘。

  <WizardStep id="android-register" title="注册你的扫描仪——无需切换模式">

在 Android 上，WCPOS 通过 **设备身份** 来识别你的扫描仪，因此可以让它保持出厂的键盘模式。不需要设置条形码，也不需要重新配对。

1. 在 Android 的蓝牙设置中配对扫描仪（或用 USB 插上它）——完全保持它出厂时的状态。
2. 在 WCPOS 中打开 <kbd>设置</kbd> → <kbd>条形码扫描</kbd> → **已注册的扫描仪** → 点击 <kbd>注册扫描仪</kbd>。

4. 给它起个名字（例如“前台”），然后点击 <kbd>保存扫描仪</kbd>。

从此以后，来自该扫描仪的每次扫描都会直接进入 WCPOS——不再需要猜测打字速度，也不会在没有字段获得焦点时丢失扫描。

1. **它多半仍处于键盘模式**——这是迄今为止最常见的原因。模式条形码可能没有生效：再扫描一次，然后把扫描仪关机再开机。快速验证：点进任意文本框并扣一下扳机——如果有字符出现，说明它仍然是键盘。对于 Eyoyo，请检查蓝牙名称：它必须显示为 `ScannerSPP`。
