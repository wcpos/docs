## 读卡器兼容性 {#card-reader-compatibility}

哪些读卡器可用，取决于**你以哪种方式运行 WCPOS**，以及读卡器的连接类型：

- **Web 应用**只能驱动提供 **Web（浏览器）SDK** 的读卡器，通常是联网的柜台终端。**仅支持 Bluetooth** 的读卡器（例如 Stripe M2 / WisePad 3、SumUp Air）以及手机的 **Tap-to-Pay**，在 Web 应用中**不受支持**。
- 支持情况**按网关而定**，并非通用。购买前，请对照你打算使用的网关核对读卡器（[Stripe Terminal](/payment/gateways/stripe-terminal)、[SumUp](/payment/gateways/sumup-terminal)、[PayPal Reader](/payment/gateways/paypal-reader)）。

每个网关页面都会列出它支持的具体读卡器型号。
