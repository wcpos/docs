**症状：** 应用提示*“安全打印已开启。请在打印机上关闭它，然后重试。”* 或者：一台全新的 Epson 在网络上被找到了，测试页看起来已经发送，却什么都没打印出来——没有错误、没有指示灯提示，打印机自己的状态页还显示“可用”。从面板发起的自检打印正常。

## 原因说明 {#why-it-happens}

自 **2025 年 8 月 1 日**起，面向欧盟和英国生产的 Epson TM 系列打印机出厂时都启用了 **安全打印**，以满足欧盟《无线电设备指令》的要求。在它开启期间，打印机会接收通过旧的未加密通道发送的作业，然后**静默丢弃**它们。

| 通道 | 安全打印**开启** | **关闭** |
|---|---|---|
| 原始 TCP，端口 9100 | 接收后丢弃 | 正常打印 |
| 通过 HTTP 的 ePOS-Print（80、8008） | 不提供服务 | 正常打印 |
| 通过 HTTPS 的 ePOS-Print（443、8043） | 正常打印 | 正常打印 |

在欧盟以外销售的机器也可能带有相同的固件。如果任何地方的新 Epson 出现这种症状，请检查这项设置。

## 关闭它 {#turn-it-off}

你需要打印机的管理员密码。在较新的型号上，它是打印机底部标签上的**序列号**；较旧的型号用的是 `epson`。

1. 找到打印机的地址——它印在状态页上（打开纸卷仓盖，按住 **走纸**）。
2. 在浏览器中打开 `https://printer-ip`，并接受证书警告。
3. 点击 **管理员登录**，然后进入 **打印 → 安全打印**。
4. 把它设为 **禁用** 并确认。
5. 拔掉打印机电源十秒，再插回去。
6. 重新打印测试页。

:::warning 固件更新会把它重新打开
Epson 在固件更新时会把安全配置恢复为默认值。如果一台用了几个月的打印机在更新之后立刻不工作了，请重复上述步骤。
:::

既然进了设置页，顺手设置一个你自己的管理员密码——同一网络上的任何人都能访问一台不设防的收据打印机。

## 仍未解决？ {#still-stuck}

使用 **复制设置报告**，并把内容粘贴到你的消息里。另请参阅 [Epson 的《无线电设备指令》常见问题](https://www.epson.co.uk/en_GB/faq/KA-01896/contents?loc=en-us)。
