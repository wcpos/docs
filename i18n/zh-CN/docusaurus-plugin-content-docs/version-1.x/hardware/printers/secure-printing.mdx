# Epson 安全打印 {#epson-secure-printing}

**症状：**添加新的 Epson 小票打印机后，WCPOS 在网络上发现了它，测试打印显示已发送——但打印机毫无反应。没有错误、没有闪烁的指示灯，打印机自身的状态页面还显示“可用”。面板自检可以正常打印。

如果遇到这种情况，打印机几乎肯定已启用 **安全打印**，而近期的 Epson 型号出厂时默认就是如此。

## 原因说明 {#whats-happening}

自 **2025 年 8 月 1 日**起，欧盟网络安全法规（无线电设备指令，即“RED”）要求在欧盟市场销售的联网设备必须**默认安全**。Epson 针对 TM 系列小票打印机的应对方式是提供名为 **安全打印** 的设置：启用后，打印机会**静默保留并随后丢弃**通过传统未加密通道到达的打印任务——包括大多数 POS 软件使用的原始 TCP 端口（9100），以及纯 HTTP ePOS。任务不会因错误而被拒绝，只是悄无声息地不打印，因此表面上一切*看起来*正常。

这会影响所有 POS 产品，而不只是 WCPOS——Epson 针对旧版系统的官方建议是重新启用经典端口，其他 POS 供应商也记录了同样的解决方法。

:::info 欧盟以外地区？
欧盟法规本身并不适用于欧盟以外地区，但在其他地区销售的设备也可能搭载相同的固件和默认设置。如果世界任何地方的新 Epson 打印机出现完全相同的症状，请检查此设置——只需两分钟即可确认问题。
:::

## 解决方法 {#the-fix}

需要打印机的网页配置页面及其**管理员密码**。对于较新的 Epson 打印机，出厂管理员密码因设备而异——通常是打印机的**序列号**，印在打印机底部标签上（旧型号的密码为 `epson`）。如果此前有人配置过该打印机，密码可能已被更改。

1. 找到打印机的 IP 地址（可在自检页上查看，或在 WCPOS 打印机设置中使用**扫描网络**）。
2. 在浏览器中，打开 `https://<printer-ip>` ——例如 `https://192.168.1.131`. 接受证书警告（打印机使用自签名证书；这是正常现象）。
3. 点击**管理员登录**，然后使用管理员密码登录。
4. 转到**打印**选项卡 → **安全打印**。
5. 将**安全打印**设置为**禁用**，然后确认。
6. **重启打印机**——拔下电源十秒钟。部分设置仅会在重启后生效。
7. 如果使用较新型号的**网页应用**，请在 **POS > 设置 > 打印**中编辑打印机：当店铺使用 HTTP 时，将其**端口**设置为 `80`；使用 HTTPS 时，设置为 `443`。对于 HTTPS，请先按照第 2 步所述，在该设备上接受打印机的证书警告。
8. 返回 WCPOS，再次运行**测试打印**。应会立即开始打印。

:::warning 固件更新会重新启用它
Epson 指南指出，固件更新会将安全配置重置为符合要求的默认设置——这意味着**更新打印机固件后，安全打印会重新启用**。如果一台已正常使用数月的打印机在固件更新后突然停止打印，请重新执行上述步骤。
:::

**不确定打印机是否受影响？** 打印其网络状态页（打开卷纸盖后，按住 FEED 按钮一秒；对于配有状态页按钮的机型，则按住该按钮三秒），并查看 `Security Mode` 行：`RED` 表示出厂时启用了安全打印；`Normal`（或没有该行）表示未启用。

:::tip 同时更改管理员密码
出厂密码印在任何人都能看到的标签上，并且网络中的所有设备都能访问打印机的管理页面。如果打印机位于共享网络中（如办公室、共享办公空间或商场），请设置自己的管理员密码——最好还应将打印机置于独立的网络分段中。任何能够访问未受保护收据打印机的人，都可以向其发送打印任务、使其无法使用，或弹开连接的现金抽屉。
:::

## 法规存在的原因 {#why-the-regulation-exists}

这并非随意规定。带有开放且未经身份验证网络端口的收据打印机，会接受**网络中的任何人**发送的命令——包括打开所连接现金抽屉的命令。暴露在互联网上的收据打印机曾被大规模劫持用于打印垃圾信息，而使用出厂密码的嵌入式设备也曾被纳入僵尸网络。该规则——[欧盟授权法规 (EU) 2022/30](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32022R0030)，并根据[欧盟法规 (EU) 2023/2444](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32023R2444)自 2025 年 8 月 1 日起适用于投放市场的产品——要求设备出厂时不得保留这些开放入口。

禁用安全打印是合理的——法规要求的是安全的*默认设置*，而非始终保持安全；重新启用传统端口是设备所有者有意作出的选择。请在知情的情况下作出这一选择：收银设备应优先使用专用网络，并设置自己的管理员密码。

## 端口：面向技术读者 {#ports}

已在实际运行的 TM-m30III（固件 13.21）上验证：

| 状态 | 原始 TCP 9100 | ePOS-Print (HTTP :80) | ePOS-Print (HTTPS :443) |
|---|---|---|---|
| 安全打印**已启用** | 已接受，但会被静默丢弃 | 不提供服务 | 可用 |
| 安全打印**已禁用** | 可用 | 可用 | 可用 |

有两个细节值得了解。首先，启用安全打印后，丢弃并非立即发生——打印机会保留任务几分钟，且**在保留任务期间，无法通过任何通道打印**，因此一个误发的任务就可能让正常工作的打印机看起来完全无法使用。其次，在这一代打印机上，经典 ePOS 端口 `8008`/`8043` **不**提供 ePOS-Print 服务（8008 已关闭；8043 承载另一项 Epson 服务）——因此，在 **Web 应用**中，如果店铺使用 HTTP，请将打印机的**端口设为 80**；如果使用 HTTPS，请将其设为 **443**。

Epson 自身的兼容性指南确认了此矩阵，并补充了加密变体：启用安全打印后，TLS 端口——`9143`（加密原始连接）、`443`（HTTPS ePOS）以及 `8043`/`8143`（SDK）——仍可使用，这也是兼容 RED 的软件无需禁用任何功能即可打印的方式。在 RED 固件上，无论安全打印开关状态如何，LPR（端口 515）以及 TLS 1.0/1.1 都会被直接禁用。
