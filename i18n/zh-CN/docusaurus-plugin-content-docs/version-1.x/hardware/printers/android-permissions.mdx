**症状：** 在 Android 手机或平板电脑上扫描不到任何打印机，蓝牙打印机始终不出现在选择器中，或者连接地址已知的打印机时超时。

## 原因说明 {#why-it-happens}

Android 对这些权限分别管控，拒绝访问时也不会提示；被阻止的连接会超时，表现与打印机未开机完全相同。

- **附近的设备** 权限用于发现和连接蓝牙打印机。
- 在较新的 Android 版本上，应用必须获得 **本地网络** 访问权限，才能访问 Wi-Fi 上的任何设备。

## 开启权限 {#turn-the-permissions-on}

1. 打开 Android 的 **设置 → 应用 → WCPOS → 权限**。
2. 允许 **附近的设备**。
3. 如果列表中有 **本地网络**，也一并允许。较旧的 Android 版本没有这一项。
4. 关闭应用后重新打开，然后再次扫描。

## 蓝牙打印机 {#bluetooth-printers}

在 Android 上，Epson 和 Star 打印机通过厂商自己的软件连接，必须 **先在 Android 中配对**，路径为 **设置 → 已连接的设备 → 配对新设备**，之后才会出现在应用中。小型低功耗蓝牙打印机则应在应用自己的选择器中选取，不要在 Android 中配对。请参阅[配对蓝牙收据打印机](/1.x/hardware/printers/bluetooth-pairing)。

## Wi-Fi 打印机 {#wi-fi-printers}

确认平板电脑连接的是店铺的 Wi-Fi，而不是移动数据或访客网络。如果扫描结果为空，但你知道打印机的地址，请使用 **输入 IP 地址**；它会直接检查这一个地址，不依赖设备发现功能。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并将内容粘贴到你的消息中。
