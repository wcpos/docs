打印机设置位于 **POS → 设置 → 打印**。每台设备各自保存打印机配置，配置存储在收银台本机上，不会在设备之间同步。

:::tip 需要使用不在这台收银台旁的打印机？
本页介绍通过 USB 或 Bluetooth 连接到收银台，或与收银台处于同一 Wi-Fi 网络的打印机。如果打印机位于另一个房间或另一家店铺，或者需要供所有设备共用，请参阅[云打印](/1.x/receipts/cloud-printing)。云打印机会自动出现在每台设备的打印机列表中，无需在这里添加。
:::

## 添加打印机 {#adding-a-printer}

<Steps>
  <StepCard number="1" title="扫描">

前往 **设置 → 打印**，轻触 **添加打印机**。一次扫描会同时查找 USB、Bluetooth 和 Wi-Fi 打印机，无需事先选择连接类型。每找到一台打印机，就会立即显示一张对应的卡片。

  </StepCard>
  <StepCard number="2" title="打印测试页">

在打印机对应的卡片上轻触 **打印测试页**。测试页上有一把横跨纸张的带编号标尺，既能确认打印机是否正常工作，也能检查纸张宽度是否正确。

如果应用尚未确定纸张宽度，会先询问你使用的是 **58 mm** 还是 **80 mm**。

  </StepCard>
  <StepCard number="3" title="回答问题">

接着应用会询问 **测试页打印出来了吗？** 有三个选项：

- **是** —— 保存打印机，完成设置。
- **打印出来了，但标尺不对** —— 应用会询问打印机中装的是哪种纸张，并根据你的回答重新打印测试页。请参阅[把收据宽度调对](/1.x/hardware/printers/receipt-width)。
- **什么都没出来** —— 应用会用一行文字说明最可能的原因及处理方法。

</StepCard>
  <StepCard number="4" title="给它起个名字" isLast>

保存后，打印机的 **名称**、**纸张宽度** 和 **钱箱** 设置会显示在 **设置 → 打印** 中该打印机所在行的下方。你可以随时在此修改。

  </StepCard>
</Steps>

### 扫描进行中 {#while-the-scan-is-running}

扫描结果旁有三个按钮：

- **查找 Bluetooth 打印机** —— 打开浏览器或计算机自带的 Bluetooth 选择器。Chrome 和桌面应用会将名称看起来像打印机的设备排在列表顶部。
- **输入 IP 地址** —— 停止扫描，改为检查指定地址。如果你知道打印机的地址，但扫描无法找到它，可以使用此选项。这种情况在企业网络中很常见。
- **停止** —— 停止扫描。已找到的设备仍会显示在屏幕上。

## 什么都打印不出来时 {#when-nothing-prints}

每个故障提示界面都会用一行文字说明问题及处理方法，并提供两个按钮：

- **复制设置报告** —— 复制应用尝试过的操作、打印机的响应以及当时已建立的连接。将报告粘贴到支持请求中，可以省去大量来回询问。
- **打开打印机指南** —— 打开本页。

选择符合当前情况的指南：

**设置阶段**

- [把收据宽度调对](/1.x/hardware/printers/receipt-width) —— 标尺超出纸边或长度不足
- [给打印机一个固定地址](/1.x/hardware/printers/network-address) —— 在 Wi-Fi 上找不到打印机，或打印机停止工作
- [配对 Bluetooth 收据打印机](/1.x/hardware/printers/bluetooth-pairing) —— 打印机未出现在选择器中
- [Windows 上的 USB](/1.x/hardware/printers/usb-windows) 和 [Linux 上的 USB](/1.x/hardware/printers/usb-linux)
- [支持的收据打印机](/1.x/hardware/printers/supported-printers)

**Epson 什么都不打印**

- [Epson 安全打印](/1.x/hardware/printers/secure-printing) —— 新的 Epson 打印机看似已收到作业，却什么都不打印
- [Server Direct Print](/1.x/hardware/printers/server-direct-print) —— 打印机网页可以打开，但任何作业都无法打印
- [打印了一次之后就停了](/1.x/hardware/printers/printed-once-then-stopped) —— 先断电重启

**权限**

- [iPad 和 iPhone](/1.x/hardware/printers/ios-local-network)
- [Android](/1.x/hardware/printers/android-permissions)
- [浏览器](/1.x/hardware/printers/browser-permissions)

**收据上有内容不对**

- [浏览器打印时缺少徽标](/1.x/hardware/printers/logo-missing-browser)
- [中文、泰文、阿拉伯文或西里尔文收据](/1.x/hardware/printers/non-latin-receipts)
- [连接钱箱](/1.x/hardware/printers/cash-drawer)

## 各应用支持的连接方式 {#supported-printers-by-platform}

| | 通过 Wi-Fi | 通过 USB 和 Bluetooth |
|---|---|---|
| **Web 应用** | 通过打印机自带的网页端口连接 Epson 和 Star。在使用 HTTPS 的店铺中，Chrome 首次连接时会请求访问本地网络的权限。 | 通过浏览器自带的设备选择器连接 USB 和 Bluetooth Low Energy 设备，仅限 Chrome 和 Edge。 |
| **桌面应用** | 任何 Wi-Fi 收据打印机。应用会通过扫描网络来查找打印机。 | USB、Bluetooth Low Energy，以及已在操作系统中安装或配对的打印机。 |
| **iPhone 和 iPad** | 任何 Wi-Fi 收据打印机。 | Epson 和 Star 通过厂商自带的软件连接；其他品牌通过 Bluetooth Low Energy 连接。 |
| **Android** | 任何 Wi-Fi 收据打印机。 | Epson 和 Star 通过厂商自带的软件连接；其他品牌通过 Bluetooth Low Energy 连接，也可以先[在系统设置中配对](/1.x/hardware/printers/bluetooth-pairing#android-pair-first)，再通过 Bluetooth Classic 连接。 |

浏览器无法像应用那样与打印机建立直接连接，因此 Web 应用可以通过 Wi-Fi 连接 Epson 和 Star，却无法连接其他品牌，因为这两个品牌的打印机内置了网页服务器。对于其他 Wi-Fi 打印机，请使用桌面应用、移动应用或[云打印机](/1.x/receipts/cloud-printing)。

## 打印机选项 {#printer-options}

以下选项位于 **设置 → 打印** 中每台打印机所在行的下方：

| 选项 | 作用 |
|---|---|
| **纸张宽度** | 每行可容纳的字符数。通过测试页确定，请参阅[收据宽度](/1.x/hardware/printers/receipt-width)。 |
| **自动切纸** | 每张收据打印后自动切纸。 |
| **自动打开钱箱** | 弹开通过线缆连接到这台打印机的钱箱，请参阅[钱箱](/1.x/hardware/printers/cash-drawer)。 |
| **设为默认** | 使用这台打印机打印所有未路由到其他打印机的收据。 |
| **整张收据光栅化** | 将收据作为图像而非文本打印。速度较慢，但支持任何语言，请参阅[非拉丁文收据](/1.x/hardware/printers/non-latin-receipts)。 |

:::note 在找“结账后自动打印”？
销售完成后自动打印收据属于 **购物车设置**，而非打印机设置。请在 POS 购物车设置中开启 **自动打印收据**。具体使用*哪台*打印机，由默认打印机和打印路由决定。
:::

## 打印路由 {#print-routing}

如果你使用多个模板，例如热敏收据 **和** A4 发票，打印路由会决定每个模板使用哪台打印机。路由分为三个层级，按以下顺序检查：

1. **单次作业覆盖。** 收据界面上的模板切换器旁有一个打印机下拉菜单。在此选择打印机，会覆盖这一次打印作业的所有其他设置。切换模板后，该选项会重置为 **自动**。
2. **设置覆盖。** 前往 **POS → 设置 → 打印**，在 **收据模板** 部分为每个模板指定打印机。将模板改回 **自动** 即可取消覆盖。
3. **自动匹配。** 没有覆盖设置时，WCPOS 会自动匹配：热敏模板发送到宽度匹配的热敏打印机（58 mm 模板优先选择 32 列打印机；80 mm 模板优先选择 42 或 48 列打印机），HTML 模板则使用系统打印对话框。如果有多台打印机匹配，则优先使用 **默认** 打印机。

如果你将模板发送到不兼容的打印机，例如将热敏模板发送到系统打印对话框，收据界面上会出现琥珀色的 **不匹配警告**。打印仍会继续，但输出结果可能不正确。

路由 **按设备** 存储，每台收银台各自管理自己的路由。

:::note
至少添加一台打印机后，才会显示 **收据模板** 控件。没有打印机时，所有模板都使用系统打印对话框。云打印机也计入其中，会自动显示为路由目标。
:::
