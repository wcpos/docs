打印机设置位于 **POS > 设置 > 打印**。每台设备分别管理自己的打印机配置；打印机仅存储在本地，不会在设备之间同步。

:::tip 要打印到未连接到此设备的打印机？
本页面介绍通过 USB、蓝牙或本地网络连接到收银终端的打印机。如需使用位于其他房间或地点的打印机，或希望所有设备共享同一台打印机，请参阅[云打印](/receipts/cloud-printing)。为店铺设置的云打印机会**自动**显示在每台设备的打印机列表中，无需在此处添加。
:::

## 各平台支持的打印机 {#supported-printers-by-platform}

**添加打印机**表单会根据所用应用自动调整；每个平台仅显示其实际支持的连接方式和选项。

| 平台 | 支持的打印机 | 连接方式 |
|----------|--------------------|-------------|
| **Web 应用** | 带有内置 Web 服务器的 Epson 和 Star 打印机（网络）；大多数 ESC/POS 打印机可通过 WebUSB（USB）连接；BLE 打印机可通过 Web Bluetooth 连接（USB/Bluetooth 仅支持 Chrome/Edge） | 网络（HTTP）、USB、Bluetooth |
| **桌面应用** | 任何网络小票打印机 | 网络（原始 TCP）、USB、Bluetooth |
| **iOS 应用** | Epson 和 Star | 网络、Bluetooth |
| **Android 应用** | Epson 和 Star | 网络、Bluetooth、USB |

:::info 为什么 Web 版仅支持通过网络连接 Epson 和 Star？
Web 浏览器无法建立原始 TCP 连接。Epson 和 Star 小票打印机内置 Web 服务器，可通过 HTTP 接收打印任务——这是从浏览器向*网络*打印机发送 ESC/POS 命令的唯一方式。桌面应用没有此限制，因为它可以直接通过 TCP 连接。

浏览器也支持 USB 和 Bluetooth 打印，但仅限 **Chrome 或 Microsoft Edge**（它们使用 WebUSB 和 Web Bluetooth API）——Safari 和 Firefox 不支持。通过 **USB** 连接时，并不限于 Epson 和 Star：大多数出现在浏览器设备选择器中的 ESC/POS 打印机都可以打印。通过 **Bluetooth** 连接时，关键在于打印机的 Bluetooth 类型——浏览器只能连接 **Bluetooth Low Energy (BLE)** 打印机；经典 Bluetooth 型号（包括大多数 Bluetooth Epson 和 Star 打印机）无法从浏览器连接。

在**移动应用**中，Bluetooth 和 USB 打印通过 Epson 和 Star 的官方 SDK 实现，因此这些连接需要使用 Epson 或 Star 打印机。通用打印机仅支持通过网络连接。
:::

## 添加打印机 {#adding-a-printer}

<Steps>
  <StepCard number="1" title="打开打印机设置">

前往 **POS > 设置 > 打印**。如果尚未配置打印机，将看到一个空状态页面，其中包含 **添加打印机** 按钮。每台打印机都有一个 **打印机名称**，它只是一个标签，会自动填充为“收据打印机”（然后是“收据打印机 2”，依此类推），可将其更改为任何有助于区分打印机的名称。

  </StepCard>
  <StepCard number="2" title="选择打印机连接方式">

所有平台都会先询问相同的问题：**连接类型**，并且只显示该平台支持的选项。下方字段会根据所选项更新。

- **Web 应用**：**网络**、**USB** 或 **蓝牙**（USB 和蓝牙需要 Chrome 或 Edge）。对于 **网络** 打印机，还需要选择 **供应商**：Epson 或 Star，因为浏览器通过该品牌内置的 Web 服务器连接网络打印机。
- **桌面应用**：**网络**、**USB** 或 **蓝牙**。
- **移动应用**：**网络** 或 **蓝牙**，Android 还支持 **USB**（iOS 不支持 USB）。

</StepCard>
  <StepCard number="3" title="识别打印机">

**网络打印机**：输入 **IP 地址**（例如 `192.168.1.100`）。WCPOS 会检测该地址，以识别其是否为 Epson 或 Star 设备，并自动填充端口、命令语言和供应商。检测完成后，将看到“已检测到：Epson”或“已检测到：Star”标签。在 Web 应用中，还会显示将要连接的确切端点 URL。

**蓝牙或 USB 打印机**（移动设备）：从已发现的设备列表中选择打印机。选择设备后会自动填充其名称和供应商。如果列表中尚未显示打印机，请点击 **扫描打印机**（蓝牙）或 **刷新**（USB）。

如果自动检测未能正确识别所有内容，可在 **高级设置** 中进行调整。

  </StepCard>
  <StepCard number="4" title="保存并测试" isLast>

点击 **保存**。WCPOS 会先发送 **测试打印**，仅在成功后保存打印机。

测试打印是一项简短的诊断功能——包含带编号的列标尺、居中的常规和双倍大小文本、左/右对齐行以及切纸操作。它旨在帮助确认纸张宽度、对齐方式、尺寸和切纸是否均已正确配置，而不只是确认打印机是否可访问。

:::tip 测试失败？仍可保存
如果测试失败，将显示错误信息，并提供 **不测试直接保存** 选项，以便仍然保存该配置文件。
:::

  </StepCard>
</Steps>

## 连接类型 {#connection-types-mobile-apps}

首先在添加打印机表单顶部选择 **连接类型**，连接字段会随之更新。可用类型取决于平台（请参阅上表）。

### 网络 {#network}

打印机与设备连接到同一 Wi-Fi 网络。在 **桌面版** 和 **移动版** 应用中，点击 **扫描网络** 可自动发现打印机，也可以手动输入 IP 地址——请参阅[查找打印机的 IP 地址](#finding-your-printers-ip-address)。**网页版**应用仅支持手动输入 IP 地址。在桌面版和移动版应用中，网络打印机可以是 Epson、Star 或通用型号；在网页版中则必须是 **Epson 或 Star**，并需要在网络连接下选择供应商。

### 蓝牙 {#bluetooth}

打印机通过蓝牙与设备配对。请从列表中选择对应的打印机——其名称和供应商会自动填入。在 **移动版** 中，蓝牙打印使用 Epson 和 Star 的原生 SDK，因此打印机必须是 **Epson 或 Star** 型号；在 **网页版** 中，可通过 Web Bluetooth API 在 Chrome 或 Edge 中使用蓝牙。

### USB {#usb-android-only}

打印机通过 USB 线缆连接。请从已连接设备列表中选择它。USB 可用于 **网页版**（Chrome 或 Edge，通过 WebUSB）、**桌面版**应用和 **Android**，但**不支持 iOS**，因为 iOS 不提供通用 USB 外设支持。在移动版中，USB 打印需要使用 **Epson 或 Star** 打印机。

:::note
**端口**设置仅适用于网络打印机——蓝牙和 USB 连接时会隐藏此设置。
:::

## 高级设置 {#advanced-settings}

展开**高级设置**可微调打印机配置。其中大多数设置会在识别出供应商后自动填充。

这些设置适用于所有平台：

| 设置 | 选项 | 说明 |
|---------|---------|-------------|
| **语言** | ESC/POS、StarPRNT、Star Line Mode | 打印机使用的命令协议。会根据识别出的供应商自动填充。 |
| **打印机文本宽度** | 58mm（32 个字符）、80mm 标准（42 个字符）、80mm 加宽（48 个字符） | 每行可容纳的字符数。请与纸张和打印机相匹配——大多数 80mm 打印机每行可打印 42 个字符，部分为 48 个字符。 |
| **整张收据光栅化** | 关闭 / 开启 | 将整张收据作为图像而非文本打印——请参阅下方的[整张收据光栅化](#full-receipt-raster)。 |

这两项设置会因平台和连接类型而有不同表现：

| 设置 | 选项 | 适用位置 |
|---------|---------|------------------|
| **供应商** | Epson、Star、通用 | 打印机制造商。在**网页应用**中，可直接在**网络**连接下选择供应商（仅限 Epson 或 Star），而不是在高级设置中选择。通用选项适用于桌面和移动应用中的**网络**打印机，但不适用于蓝牙或 USB 连接。 |
| **端口** | 自动填充 | 打印机的网络端口，显示在 IP 地址旁边。**仅限网络连接**——蓝牙和 USB 连接时将隐藏。系统会根据供应商自动填充该端口（在网页端，还会根据 POS 是通过 HTTP 还是 HTTPS 提供服务确定）；仅当网络对端口进行了重映射时才需更改。 |

## 打印机选项 {#printer-options}

这些开关位于“添加打印机”表单底部：

| 选项 | 说明 |
|--------|-------------|
| **自动切纸** | 每张收据打印后自动切纸 |
| **自动打开钱箱** | 打印后发送触发命令以打开已连接的钱箱 |
| **设为默认** | 将此打印机设为默认打印机——用于未路由到特定打印机的所有收据 |

:::note 正在寻找“结账后自动打印”？
销售完成时自动打印收据属于**购物车设置**，而非打印机设置——请在 POS 购物车设置中开启**自动打印收据**。使用*哪一台*打印机由默认打印机及各模板的打印机路由决定。
:::

## 打印路由 {#print-routing}

如果使用多个模板，例如热敏收据**和** A4 发票，打印路由将决定每个模板使用哪台打印机打印。路由分为三个层级，按以下顺序检查：

1. **单次任务覆盖。** 在收据屏幕上，打印机下拉菜单位于模板切换器旁边。在此处选择打印机将覆盖该次打印任务的所有其他设置。切换模板后会重置为**自动**。
2. **设置覆盖。** 前往 **POS > 设置 > 打印**，然后使用**收据模板**部分为每个模板分配特定打印机。例如，将热敏收据路由到 Epson 网络打印机，将 HTML 发票路由到系统打印对话框。将模板设回**自动**即可移除覆盖。
3. **自动匹配。** 未设置覆盖时，WCPOS 会自动匹配：
   - **热敏模板**会路由到字符宽度匹配的热敏打印机。58mm 热敏模板优先使用 32 列打印机；80mm 模板优先使用 42 列或 48 列打印机。
   - **HTML 模板**会路由到系统打印对话框。
   - 如果有多台匹配的打印机，则使用**默认**打印机。

如果手动将模板发送到不兼容的打印机，例如将热敏模板发送到系统对话框，收据屏幕上会显示琥珀色的**不匹配警告**。打印仍会继续，但输出可能无法正确呈现。

路由覆盖按**设备**存储。每台 iPad、手机或计算机各自管理自己的路由设置，不会进行服务器端同步。

:::note
只有在至少添加了一台打印机后，**POS > 设置 > 打印**中的**收据模板**打印机控件才会显示。未配置打印机时，每个模板都会默认使用系统打印对话框。为店铺设置的**云打印机**也会计入其中，它们会自动显示为路由目标，无需添加到设备上。
:::

## 整张收据光栅化 {#full-receipt-raster}

默认情况下，WCPOS 会将收据以**文本**形式发送到热敏打印机——速度快、版面紧凑且清晰，并使用打印机内置字体。需要注意的是：热敏打印机字体仅支持有限的字符集。对于打印机没有对应字体的文字系统——许多非拉丁字母、从右至左文本以及部分符号——可能会打印成空白方框或乱码。

**整张收据光栅化**可解决此问题。启用后，WCPOS 会将整张收据渲染为图像并发送给打印机，因此无论使用何种语言或文字系统，打印结果都会与屏幕显示完全一致。

可在每台打印机的**高级设置**中启用。注意事项：

- **速度较慢。** 图像比一行文本大得多，因此收据的发送和打印时间会更长。
- **仅在需要时使用。** 如果收据以文本形式打印正常，请保持关闭。
- 此功能适用于通过任何连接方式（网络、Bluetooth、USB）使用的热敏打印机。不适用于系统打印对话框，因为系统打印对话框已基于整页渲染进行打印。

## 查找打印机 {#discovering-printers}

查找打印机的方式取决于连接类型：

- **Bluetooth 和 USB**——在**移动应用**中，轻触**扫描打印机**（Bluetooth）或**刷新**（USB），然后从列表中选择所需打印机；其名称和供应商会自动填入。在**网页端**（Chrome 或 Edge）中，点击**连接**，然后在浏览器自带的设备选择器中选择打印机。
- **网络**——在**桌面应用**和**移动应用**中，轻触**扫描网络**可自动查找本地网络上的打印机（桌面应用通过 mDNS/Bonjour 发现设备；移动应用使用 Epson 和 Star SDK），然后从列表中选择所需打印机。也可以直接输入 IP 地址——请参阅下方的[查找打印机的 IP 地址](#finding-your-printers-ip-address)。浏览器无法扫描网络，因此**网页应用**始终使用手动输入 IP 地址的方式。

## 查找打印机的 IP 地址 {#finding-your-printers-ip-address}

大多数小票打印机都可以打印包含 IP 地址的自检页：

- **Epson**：开机时按住走纸按钮
- **Star**：开机后按住走纸按钮 5 秒

或者，查看路由器的已连接设备列表或打印机配置工具。

### 建议使用静态 IP {#static-ip-recommended}

小票打印机应使用**静态 IP 地址**，以防止打印机重启后地址发生变化。可通过以下任一方式进行配置：

- 在打印机的内置网页界面中进行配置（通常可通过以下地址访问 `http://<printer-ip>`）
- 在路由器的 DHCP 设置中进行配置（为打印机的 MAC 地址分配保留 IP）

## Epson 打印机 {#epson-printers}

支持 ePOS 的 Epson 打印机通过 HTTP 通信。WCPOS 会向打印机的内置 Web 服务器发送 SOAP/XML 请求。

**连接详情：**
- 端口 `8008`（HTTP）或 `8043`（HTTPS）——会根据 POS 是通过 HTTP 还是 HTTPS 提供服务自动填充
- 端点：`/cgi-bin/epos/service.cgi`
- **较新型号（TM-m30III 及类似型号）：**这些机型通过以下端口提供 ePOS 服务 `80` （HTTP）/ `443` （HTTPS），而非 8008/8043——如果自动填充的端口无法在 Web 应用中连接，请将**端口**设置为 `80` （HTTP 店铺）或 `443` （HTTPS 店铺）。对于 HTTPS，请先打开 `https://<printer-ip>` 在每台收银设备上接受打印机的证书警告。如果浏览器无法信任打印机，请改用**桌面应用**。

**已确认可用的型号：**
- Epson TM-T70-i 2（网络）
- Epson TM-m30III（网络——直连，无需中间件）

:::tip
请确保 Epson 打印机已在其配置中启用 ePOS。请访问打印机的 Web 界面： `http://<printer-ip>` 以检查并启用 ePOS 设置。
:::

:::warning 新款 Epson 打印机不打印？
自 2025 年中期起生产的 Epson 打印机默认启用 **安全打印**，会静默丢弃网络打印任务——测试打印会“发送”，但不会输出任何内容。请参阅 [Epson 安全打印](/hardware/printers/secure-printing)，了解两分钟即可完成的修复方法。
:::

在 **移动应用** 中，Epson 打印机还可通过 Epson 原生 SDK 使用蓝牙或 USB 连接——无需 IP 地址或 ePOS Web 服务器。

## Star 打印机 {#star-printers}

支持 WebPRNT 的 Star 打印机通过 HTTP 通信。WCPOS 会向 Star WebPRNT 端点发送命令。

**连接详情：**
- 端口 `80`（HTTP）或 `443`（HTTPS）——会根据 POS 是通过 HTTP 还是 HTTPS 提供服务自动填充
- 端点：`/StarWebPRNT/SendMessage`

在**移动应用**中，Star 打印机还可通过 Star 原生 SDK 经由蓝牙或 USB 连接。

## 通用打印机 {#generic-printers}

**桌面应用**通过原始 TCP 支持任何网络小票打印机。输入打印机的 IP 地址和端口（通常为 `9100`）。只要接受 ESC/POS 命令，此功能适用于大多数热敏打印机，无论制造商为何。

在**移动应用**中，也支持通用打印机——但仅支持**网络**连接，不支持蓝牙或 USB（后两者需要 Epson 或 Star 打印机）。**Web 应用**完全不支持通用打印机。

## 钱箱 {#cash-drawers}

连接到小票打印机的钱箱可在每次销售后自动打开：

1. 在打印机选项中启用**自动打开钱箱**
2. POS 会在打印后发送 ESC/POS 弹钱箱命令

:::note
钱箱控制需要热敏打印机配置文件——浏览器打印对话框无法触发钱箱。
:::

## 故障排除 {#troubleshooting}

  <AccordionItem question="设置期间未检测到打印机">

  - 对于网络打印机：请在桌面版或移动版应用中尝试使用 **扫描网络** 自动查找；否则请检查 IP 地址是否正确（打印自检页）
  - 对于通过 **网络** 使用的 Web 应用：确认打印机为支持 ePOS/WebPRNT 的 Epson 或 Star 型号（Web 应用中的 USB 和 Bluetooth 不受品牌限制——请参阅下文）
  - 对于桌面版应用：尝试使用端口 9100 的通用厂商选项

  - 对于 USB（Android）：检查线缆；如出现 USB 权限提示，请予以授权
  - 检查是否有防火墙阻止连接

  </AccordionItem>

  <AccordionItem question="已检测到打印机，但未打印任何内容">

  - **新 Epson 打印机？** 近期 Epson 型号出厂时启用了 **安全打印**，即使打印机显示正常运行，它也会静默丢弃网络打印任务——请参阅 [Epson 安全打印](/hardware/printers/secure-printing) 了解解决方法
  - 检查纸卷——可能已用完或卡纸
  - 确认 **打印机文本宽度** 设置与纸张相符（58mm 或 80mm）
  - 尝试直接从打印机打印自检页，以确认其工作正常
  - 检查命令语言是否与打印机匹配（Epson 使用 ESC/POS，Star 使用 StarPRNT 或 Star Line Mode）

  </AccordionItem>

  <AccordionItem question="新的 Epson 打印机：测试打印显示已发送，但没有任何输出">

  这是 **安全打印** 的典型表现。自 2025 年年中起生产的 Epson 打印机出厂时启用了此功能（因欧盟安全法规要求）。打印机会静默保留并丢弃通过传统通道发送的任务——不会在任何位置显示错误，状态页则显示“可用”。控制面板自检仍可正常打印。可在打印机网页设置中用两分钟完成修复：[Epson 安全打印](/hardware/printers/secure-printing)。

  </AccordionItem>

  <AccordionItem question="收据内容乱码或字符不正确">

  - 命令语言设置可能不正确——尝试在 ESC/POS、StarPRNT 和 Star Line Mode 之间切换
  - 确保 **打印机文本宽度** 设置正确
  - 如果收据使用非拉丁文字或从右至左书写的语言，请在高级设置中启用 **完整收据光栅化**——该选项会将收据作为图像打印，从而确保任何语言都能正确呈现

  </AccordionItem>

  <AccordionItem question="钱箱无法打开">

  - 确认已在打印机选项中启用 **自动打开钱箱**
  - 检查钱箱是否连接到打印机的 DK 端口（而非独立电源）
  - 并非所有打印机都支持钱箱弹出命令——请查阅打印机文档

  </AccordionItem>

  <AccordionItem question="无法从 Web 应用连接">

  - 通过**网络**，Web 应用只能连接 Epson 和 Star 打印机（通过其内置 Web 服务器）——浏览器不支持通用原始网络打印机；请使用桌面版或移动版应用，或使用[云打印机](/receipts/cloud-printing)
  - **USB 和蓝牙**打印机可在 Web 端使用，但仅限 **Chrome 或 Microsoft Edge**（Safari 和 Firefox 不支持 WebUSB / Web Bluetooth API）
  - 通过**蓝牙**，浏览器只能连接**低功耗蓝牙（BLE）**打印机——经典蓝牙型号（包括大多数蓝牙 Epson 和 Star 打印机）不会显示在浏览器的选择器中；请使用桌面版或移动版应用
  - 如果站点使用 HTTPS，而打印机仅支持 HTTP，浏览器可能会将连接视为混合内容而阻止——打印机必须与 POS 使用相同的 HTTP/HTTPS

  </AccordionItem>

  <AccordionItem question="蓝牙打印机无法连接（移动端）">

  - 在 WCPOS 中添加打印机前，请先在设备的系统蓝牙设置中完成配对
  - 蓝牙打印仅支持 Epson 和 Star 打印机——不支持通用蓝牙打印机
  - 如果打印机未显示在列表中，请再次点击**扫描打印机**，并确认打印机已开机且在有效范围内

  </AccordionItem>

  <AccordionItem question="测试打印正常，但列未对齐">

  **打印机文本宽度**设置与纸张不匹配。请在**高级设置**中将其设为与打印机相符的值：58mm 为 32 个字符，80mm 为 42 个字符，80mm 宽纸为 48 个字符。

  </AccordionItem>

  <AccordionItem question="文本模糊或浅淡，像复印件">

  文字发灰、类似复印效果，表示收据是通过**系统打印对话框**打印，而不是以 **ESC/POS** 命令发送。请将热敏模板路由到热敏打印机配置文件，而不是系统对话框。文字清晰锐利表示 ESC/POS 正常工作。

  </AccordionItem>

  <AccordionItem question="显示收据已发送，但没有打印任何内容（Web 应用）">

  在 Web 应用中，“发送成功”消息仅表示请求已离开浏览器，并不代表打印机已接收。通常这意味着浏览器无法通过网络访问打印机（HTTP/HTTPS 协议错误、端口被阻止或缺少证书）。最可靠的解决方法是使用**桌面应用**，它可直接连接到打印机。

  </AccordionItem>
</Accordion>
