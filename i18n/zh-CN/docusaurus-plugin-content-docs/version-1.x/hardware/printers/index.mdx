打印机设置位于 **POS → 设置 → 打印**。每台设备各自保存自己的打印机——它们存在收银台本机上，不会在设备之间同步。

:::tip 要打印到不在这台收银台旁边的打印机？
本页讲的是通过 USB 或 Bluetooth 连接到收银台、或者在同一个 Wi-Fi 上的打印机。如果打印机在另一个房间、另一家店，或者希望所有设备共用一台，请参阅[云打印](/receipts/cloud-printing)。云打印机会自动出现在每台设备的打印机列表中，无需在这里添加。
:::

## 添加打印机 {#adding-a-printer}

<Steps>
  <StepCard number="1" title="扫描">

前往 **设置 → 打印**，轻触 **添加打印机**。一次扫描会同时寻找 USB、Bluetooth 和 Wi-Fi 打印机——不需要先选择哪一种。每找到一台打印机，就会立刻显示为一张卡片。

  </StepCard>
  <StepCard number="2" title="打印测试页">

在你的打印机卡片上轻触 **打印测试页**。测试页是一把横跨纸张的带编号标尺，所以它既能说明打印机能用，也能说明纸张宽度是否正确。

如果应用还不知道纸张有多宽，它会先问你是 **58 mm** 还是 **80 mm**。

  </StepCard>
  <StepCard number="3" title="回答问题">

接着应用会问 **测试页打印出来了吗？** 有三个答案：

- **是** —— 打印机已保存，设置完成。
- **打印出来了，但标尺不对** —— 应用会问打印机里装的是哪种纸，并按你的回答重新打印测试页。请参阅[把收据宽度调对](/hardware/printers/receipt-width)。
- **什么都没出来** —— 你会看到一行说明，指出最可能的原因以及该怎么处理。

</StepCard>
  <StepCard number="4" title="给它起个名字" isLast>

保存之后，这台打印机的**名称**、**纸张宽度**和**钱箱**设置就在 **设置 → 打印** 里它那一行的下方。你随时可以在那里修改。

  </StepCard>
</Steps>

### 扫描进行中 {#while-the-scan-is-running}

结果旁边有三个按钮：

- **查找 Bluetooth 打印机** —— 打开浏览器或计算机自带的 Bluetooth 选择器。Chrome 和桌面应用会把看起来像打印机的名称排在列表最前面。
- **输入 IP 地址** —— 停止扫描，改为检查某一个地址。当你知道打印机在哪里而扫描又看不到它时用这个，在企业网络里很常见。
- **停止** —— 中止扫描。已经找到的内容会留在屏幕上。

## 什么都打印不出来时 {#when-nothing-prints}

每个故障提示界面都会用一行文字说明问题出在哪、该怎么做，并附带两个按钮：

- **复制设置报告** —— 复制应用尝试了什么、打印机如何应答、哪些连接是通的。把它粘贴到支持请求里，可以省去一长串来回提问。
- **打开打印机指南** —— 带你来到这里。

选择对应的指南：

**设置阶段**

- [把收据宽度调对](/hardware/printers/receipt-width) —— 标尺超出纸边或者不够长
- [给打印机一个固定地址](/hardware/printers/network-address) —— Wi-Fi 上找不到，或者原本能用的打印机不工作了
- [配对 Bluetooth 收据打印机](/hardware/printers/bluetooth-pairing) —— 它没出现在选择器里
- [Windows 上的 USB](/hardware/printers/usb-windows) 和 [Linux 上的 USB](/hardware/printers/usb-linux)
- [支持的收据打印机](/hardware/printers/supported-printers)

**Epson 什么都不打印**

- [Epson 安全打印](/hardware/printers/secure-printing) —— 新的 Epson 看起来已发送却什么都不打印
- [Server Direct Print](/hardware/printers/server-direct-print) —— 它的网页能打开，但没有任何作业打印出来
- [打印了一次之后就停了](/hardware/printers/printed-once-then-stopped) —— 先断电重启

**权限**

- [iPad 和 iPhone](/hardware/printers/ios-local-network)
- [Android](/hardware/printers/android-permissions)
- [浏览器](/hardware/printers/browser-permissions)

**收据上有内容不对**

- [浏览器打印时缺少徽标](/hardware/printers/logo-missing-browser)
- [中文、泰文、阿拉伯文或西里尔文收据](/hardware/printers/non-latin-receipts)
- [连接钱箱](/hardware/printers/cash-drawer)

## 各应用能连接什么 {#supported-printers-by-platform}

| | 通过 Wi-Fi | 通过 USB 和 Bluetooth |
|---|---|---|
| **Web 应用** | Epson 和 Star，通过打印机自带的网页端口。在 HTTPS 店铺上，Chrome 首次会请求访问本地网络的权限。 | 通过浏览器自带的设备选择器使用 USB 和 Bluetooth Low Energy——仅限 Chrome 和 Edge。 |
| **桌面应用** | 任何 Wi-Fi 收据打印机。它会扫描网络来发现它们。 | USB、Bluetooth Low Energy，以及已经在操作系统中安装或配对的打印机。 |
| **iPhone 和 iPad** | 任何 Wi-Fi 收据打印机。 | Epson 和 Star 通过厂商自己的软件；其他品牌通过 Bluetooth Low Energy。 |
| **Android** | 任何 Wi-Fi 收据打印机。 | Epson 和 Star 通过厂商自己的软件；其他品牌通过 Bluetooth Low Energy，或在[系统设置中配对](/hardware/printers/bluetooth-pairing#android-pair-first)后使用 Bluetooth Classic。 |

浏览器无法像应用那样直接与打印机建立连接，所以 Web 应用在 Wi-Fi 上只能连 Epson 和 Star，而连不上其他品牌——只有这两家的打印机内置了网页服务器。Wi-Fi 上的其他打印机，请使用桌面或移动应用，或者[云打印机](/receipts/cloud-printing)。

## 打印机选项 {#printer-options}

在 **设置 → 打印** 中每台打印机那一行下面：

| 选项 | 作用 |
|---|---|
| **纸张宽度** | 一行能容纳多少个字符。由测试页确定——请参阅[收据宽度](/hardware/printers/receipt-width)。 |
| **自动切纸** | 每张收据打印后自动切纸。 |
| **自动打开钱箱** | 弹开接在这台打印机上的钱箱——请参阅[钱箱](/hardware/printers/cash-drawer)。 |
| **设为默认** | 所有没有被路由到别处的收据都用这台打印机。 |
| **整张收据光栅化** | 把收据作为图像而不是文本打印。速度较慢，但任何语言都能打印——请参阅[非拉丁文收据](/hardware/printers/non-latin-receipts)。 |

:::note 在找“结账后自动打印”？
销售完成时自动打印收据属于**购物车设置**，不是打印机设置——请在 POS 购物车设置中开启 **自动打印收据**。至于用*哪一台*打印机，由你的默认打印机和打印路由决定。
:::

## 打印路由 {#print-routing}

如果你使用了不止一个模板——比如热敏收据**加上** A4 发票——打印路由决定每个模板打到哪台打印机。路由分三层，按以下顺序检查：

1. **单次作业覆盖。** 在收据界面上，模板切换器旁边有一个打印机下拉菜单。在这里选择打印机，会覆盖该次打印作业的所有其他设置。切换模板会把它重置为 **自动**。
2. **设置覆盖。** 前往 **POS → 设置 → 打印**，然后在 **收据模板** 部分为每个模板指定一台打印机。把模板设回 **自动** 即可取消覆盖。
3. **自动匹配。** 没有任何覆盖时，WCPOS 会自动匹配：热敏模板送往宽度相符的热敏打印机（58 mm 模板优先选择 32 列打印机，80 mm 模板优先选择 42 或 48 列），HTML 模板送往系统打印对话框。如果有多台打印机都匹配，则由**默认**打印机胜出。

如果你把模板送到不兼容的打印机——比如把热敏模板送到系统对话框——收据界面上会出现琥珀色的**不匹配警告**。打印仍会继续，但结果可能不正确。

路由**按设备**存储；每台收银台各自管理自己的路由。

:::note
只有在至少添加了一台打印机之后，**收据模板** 控件才会出现。没有打印机时，每个模板都使用系统打印对话框。云打印机也算在内——它们会自动显示为路由目标。
:::
