**症状：** 打印机自己的网页能打开，面板自检也能打印，安全打印也早已关闭——但 POS 发出的每一个作业仍然失败或超时。断电重启毫无改变。

## 原因说明 {#why-it-happens}

Epson 打印机可以被设置为自己去服务器拉取作业，这项功能叫做 **Server Direct Print**。与之相关的另一项功能 **ePOS-Device**，允许某个应用以会话方式独占打印机。这两者都会接管打印引擎，而在被占用期间，打印机会以“忙”为由拒绝其他一切请求——而且不会告诉你。因为这是保存在打印机上的设置，重启并不能清除它。

这通常是上一次安装、厨房打印服务或另一台收银机留下的。

## 关闭它 {#turn-it-off}

1. 在浏览器中打开 `https://printer-ip`，并接受证书警告。
2. 点击 **管理员登录**——密码是打印机底部标签上的序列号，除非有人改过它。
3. 找到 **Server Direct Print**（视固件版本，它在打印机的服务或打印设置中），把它设为 **禁用**。
4. 在同一个界面上，如果没有别的东西在用，也确认 **ePOS-Device** 已禁用。
5. 确认保存，然后拔掉打印机电源十秒，再插回去。
6. 重新打印测试页。

:::note 可能有别的系统正在用它
如果确实有另一个系统在通过 Server Direct Print 打印——厨房显示屏、在线订单服务之类——那么两者只能有一个占用这台打印机。请把那个系统指向别处，或者给 POS 配一台自己的打印机。
:::

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并把内容粘贴到你的消息里——它会记录打印机在每个端口上的应答。
