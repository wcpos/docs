  <WizardStep id="network-setup" title="连接网络打印机">

前往 **POS &gt; 设置 &gt; 打印 &gt; 添加打印机**。输入打印机的 **IP 地址**，然后保存。

要查找 IP 地址，请打印打印机的网络自检页：

- **Star：** 在打印机已开机的状态下，按住 **FEED** 按钮约 5 秒。
- **Epson：** 按住 **FEED** 按钮，同时打开打印机电源。

强烈建议为打印机设置一个**固定地址**（在路由器上设置 DHCP 保留），以免地址变化导致日后无法打印。

  <WizardFix id="fix-not-printing" title="测试内容未打印出来">

先做几个简单检查：是否有纸、机盖是否合上、纸张方向是否正确？热敏纸只有一面可以打印，装反后打印机只会送出空白纸。可以用指甲刮一下纸张；能刮出痕迹的那一面必须朝向打印头。

然后确认能否访问打印机：在 Web 浏览器中打开 `http://<printer-ip>/` （如果无法加载，请尝试 `https://<printer-ip>/`）。如果能看到打印机自身的配置页面，说明打印机已联网，问题出在设置上；如果两者都无法加载，则是网络/IP 问题（地址错误或打印机未连接）。

  <WizardFix id="net-deep" title="深入检查网络">
如果基本设置都正确却仍然无法打印，通常是以下某个网络问题导致的：

**IP 错误或已更改。** 确认打印机自检页上的 IP 与输入的一致，以免误用另一台打印机的地址。使用 DHCP 的打印机可能在重启后更换地址；请在路由器上设置 **DHCP 保留**，使地址保持不变。以 `169.254` 开头的地址表示打印机根本没有连上网络。

**之前可以打印，但当天第一次打印失败。** 打印机的网卡进入了休眠，第一个作业将其唤醒，却在此过程中丢失。请再发送一次测试打印；对于固定收银台，可考虑使用有线**以太网**连接。

**两台收银机共用一台打印机。** 许多 Star 网络打印机默认一次只接受一个连接，第二台收银机会超时。请在打印机的 Web 配置中启用 **9100 多会话**。

**打印机的网络设置使用了错误的协议。** WCPOS 通过 **端口 9100 上的原始 TCP** 发送作业。在浏览器中打开打印机的配置页面（`http://<printer-ip>/`，如果无法加载，则尝试 `https://<printer-ip>/` ），并确保已启用 **raw / 端口 9100** 打印。如果打印机仅设置为 LPR、IPP 或 WSD，作业就无法送达。

**Wi-Fi 无法连接或频繁断线。** 收据打印机通常**仅支持 2.4GHz**，请连接到 2.4GHz 网络，而非仅支持 5GHz 或启用了频段引导的网络。如果连接不稳定，改用有线以太网是可靠的解决方法。

  <WizardInvalid id="web-generic-invalid" title="通用打印机需要使用桌面应用">

  <WizardStep id="web-net-setup" title="从 Web 应用连接网络打印机">

**从 Web 浏览器**向网络打印机发送打印作业的设置最为复杂，因为浏览器只能通过 HTTP/HTTPS 与打印机内置的 Web 服务器通信，而使用安全连接（HTTPS）的 POS 也会强制要求与打印机建立安全连接。

首先确认能否访问打印机：在新的浏览器标签页中打开 `http://<printer-ip>/` （如果无法加载，请尝试 `https://<printer-ip>/`）。如果能看到打印机自身的配置页面，说明打印机已联网；如果两者都无法加载，请先解决网络/IP 问题。

然后在 **POS &gt; 设置 &gt; 打印** 中，通过 IP 地址添加打印机。如果 POS 通过 **HTTPS** 运行，与打印机的连接也会被强制使用 HTTPS（Epson 使用端口 8043，Star 使用 443）。这要求打印机具有受信任的 **SSL 证书**。

  <WizardFix id="web-net-fix" title="Web 网络打印无法工作">

这是最常见的难题，通常无法仅在浏览器中解决。原因及处理方法如下：

打印打印机的**自检页**，查看 SSL/TLS 部分。如果显示证书**不存在**，则必须先生成证书才能通过 HTTPS 打印。对于自签名证书，浏览器不会自动信任，你需要在每台设备上访问一次 `https://<printer-ip>` 并接受该证书。

如果提示“发送成功”却未打印任何内容，说明浏览器悄悄拦截了请求（打印机使用 HTTP，而 POS 使用 HTTPS，触发了“混合内容”拦截），或者在没有证书的情况下强制使用了 HTTPS 端口（Epson 为 8043，Star 为 443）。

Web 应用只能通过打印机的**内置 Web 服务器**访问打印机，即 Epson 的 **ePOS-Print** 或 Star 的 **WebPRNT**。请确保该服务已在打印机配置中**开启**。只有 Epson 的“intelligent”/ **-NT** 型号和 Star **WebPRNT** 型号配有此服务；如果你的型号没有，浏览器就无法访问它。

**可靠的解决方案是使用桌面应用**，它通过网络直接连接打印机（端口 9100），不受浏览器的 HTTPS 限制。从[打印机设置](/1.x/hardware/printers)下载后，在其中添加同一台打印机即可。

  <WizardStep id="bt-setup" title="通过蓝牙连接">

通过蓝牙打印收据需要使用打印机厂商的软件，因此打印机必须是 **Epson** 或 **Star** 型号。所有平台均不支持通过蓝牙连接通用蓝牙打印机。

首先，**在计算机或设备的系统蓝牙设置中配对打印机**，而不是在 WCPOS 中配对。蓝牙打印机一次只能记住一台设备，如果之前与另一台收银机配对，请先在那台设备上“忘记”此打印机。在 **iPhone/iPad** 上，还需在提示时授予 WCPOS **蓝牙**和**本地网络**权限。在 **Android** 上，将 WCPOS 的电池使用设置为**不受限制**，以免系统断开连接。在 **Windows 或 Mac 桌面**上，先在操作系统的蓝牙设置中配对，再到 WCPOS 中扫描。

然后在 **POS &gt; 设置 &gt; 打印** 中，点按**扫描打印机**并选择你的打印机，其名称和品牌会自动填入。

  <WizardFix id="bt-fix" title="蓝牙无法配对或频繁断线">

**先在设备的系统蓝牙设置中**配对打印机，再到 WCPOS 中重新扫描。如果之前配对过但无法重新连接，请在另一台设备上“忘记”此打印机，并重置打印机的蓝牙，解除原有绑定。确保打印机已开机且在连接范围内。在 iPhone/iPad 上，确认 WCPOS 同时拥有蓝牙和本地网络权限；在 Android 上，将应用的电池使用设置为不受限制。请记住，蓝牙**仅支持 Epson 和 Star**，通用蓝牙打印机无法连接。

在 **Android** 上，重新插拔线缆，并在 USB 权限提示中允许访问。在**桌面应用（Windows）**中，`LIBUSB_ERROR_NOT_SUPPORTED` 错误表示 Windows 已将设备绑定到自身的打印驱动程序。最简单的解决方法是**改用网络连接打印机（端口 9100）**，从而完全避开 USB 驱动程序。（高级用户可以使用 WinUSB 工具替换驱动程序，但这会禁用该设备的正常 Windows 打印队列。仅在清楚操作影响时才这样做。）

  <WizardStep id="web-btusb" title="在 Web 浏览器中使用蓝牙 &amp; USB">

通过蓝牙或 USB 将打印机连接到 **Web 应用**，仅在 **Google Chrome 或 Microsoft Edge** 中可行（Safari 和 Firefox 不支持）。在 **POS &gt; 设置 &gt; 打印** 中点击**连接**，然后在浏览器的设备选择器中选择打印机。

**USB** 支持 Epson、Star 和大多数通用 ESC/POS 打印机。如果打印机出现在浏览器的设备选择器中，通常就能打印。在 **Windows** 上，打印机自身的驱动程序可能阻止浏览器与其通信；如果连接失败，请改用桌面应用。

**蓝牙**连接是否可用取决于打印机的蓝牙类型，而非品牌：浏览器只能连接**低功耗蓝牙（BLE）** 打印机。许多小型便携式打印机使用 BLE，可以正常工作，但经典蓝牙打印机（包括大多数蓝牙版 Epson 和 Star 型号）不会出现在浏览器的设备选择器中。如果你的打印机没有显示，原因就在这里，请改用桌面或移动应用。

如果两种方式都无法连接，**桌面应用**是蓝牙和 USB 连接最可靠的选择。可从[打印机设置](/1.x/hardware/printers)下载。
