**症状：** POS 运行在浏览器里，连不上打印机——扫描不到任何设备，或者同一台打印机在桌面应用里能打印，在浏览器标签页里却不行。

## 允许访问本地网络 {#allow-local-network-access}

Chrome 和 Edge 会先请求许可，网站才能与你网络上的设备通信。如果那个提示被关掉了，之后每一次尝试都会静默失败。

点击地址栏左侧的图标 → **网站设置** → 把 **本地网络** 设为 **允许**，然后重新加载页面并再次扫描。

## 混合内容 {#mixed-content}

通过 `https://` 提供的 POS 无法与打印机建立明文的 `http://` 连接。在你授予本地网络访问权限后，Chrome 和 Edge 会放行；其他浏览器则会直接拦截。如果你的店铺跑在 HTTPS 上，而打印机只支持 HTTP，请改用桌面应用。

## 打印机的证书 {#the-printers-certificate}

打印机使用自己的证书来保护连接，而没有任何浏览器默认信任它——连接还没开始就失败了。请在同一个浏览器中打开一次 `https://printer-ip`，接受警告，然后回到 POS。每台计算机上都要做一次。

桌面应用没有这个问题：它自己会接受打印机的证书，这就是为什么同一台打印机在那里能用，在标签页里却不行。

## Safari 和 Firefox {#safari-and-firefox}

这两者都没有上述任何一条路可走。它们没有可以授予的本地网络权限，也不支持从网页连接 USB 或 Bluetooth 打印机。在这些浏览器上，请使用与店铺的 HTTP 或 HTTPS 相匹配的 Wi-Fi 打印机，或者改用桌面应用。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并把内容粘贴到你的消息里——它会记录用了哪个浏览器、尝试了哪条通道。
