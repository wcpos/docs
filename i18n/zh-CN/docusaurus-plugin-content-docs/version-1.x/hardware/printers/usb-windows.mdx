**症状：** 打印机已列出，但测试页始终没有出来——或者出来的是一整页零散的字母、括号和符号，而不是一张收据。

## 原因说明 {#why-it-happens}

在 Windows 上，你随打印机安装的那个驱动会接管 USB 端口。应用无法越过它直接访问打印机，因此它通过打印机**已安装的 Windows 队列**来打印。只要该队列原样透传收据命令，这样是可行的。而绑定到厂商自有驱动的队列往往会重新渲染或丢弃这些命令，那一整页符号就是这么来的。

## 这样做 {#do-this}

1. 打开 **设置 → 蓝牙和其他设备 → 打印机和扫描仪**。
2. 选择 **添加设备**，当 Windows 找不到它时选择 **手动添加**。
3. 选择 **添加本地打印机**，并从列表中选取打印机的 **USB** 端口。
4. 驱动方面，厂商选择 **Generic**，型号选择 **Generic / Text Only**。
5. 给这个队列起一个你认得出的名字，然后完成。
6. 回到 POS，打开 **设置 → 打印 → 添加打印机**，重新扫描并选中那个队列。打印一张测试页。

如果仍然打出一整页符号，说明应用找到的还是厂商驱动的那个队列。请把它删掉，或者按名称确认你选中的是 Generic/Text 那个。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并把内容粘贴到你的消息里——它会写明应用用的是哪个队列。
