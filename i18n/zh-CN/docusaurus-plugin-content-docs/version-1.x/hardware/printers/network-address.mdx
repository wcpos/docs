**症状：** 在 Wi-Fi 上扫描不到任何打印机，或者一台用了好几周的打印机突然在每一张收据上都超时。

## 原因说明 {#why-it-happens}

几乎所有情况都源于三种网络状况：

- **不在同一个网络上。** 收银台连的是一个 Wi-Fi，打印机连的是另一个——访客 SSID、第二个无线接入点，或者一个独立的 VLAN。打印机发现不会跨越它们。
- **客户端隔离。** 访客和公共 Wi-Fi 通常完全禁止设备之间互相通信。打印机就在同一个网络上，却依然无法访问。
- **地址变了。** 路由器按租约分配地址。租约变更时，打印机会换到一个新地址，而已保存的打印机仍指向旧地址——所以它昨天还好好的，今天就超时了。

## 这样做 {#do-this}

1. 让收银台和打印机连到**同一个 Wi-Fi**，而不是访客网络。
2. 打印打印机的状态页，读出它当前的地址。Epson 是打开纸卷仓盖并按住 **走纸** 一秒；Star 是在开机状态下按住 **走纸** 五秒。
3. 给它一个**固定地址**：在路由器的 DHCP 设置中为打印机的 MAC 地址保留一个地址，或者在打印机自己的网页（`http://printer-ip`）里设置静态地址。无论哪种方式，它都不会再变。
4. 在应用中使用 **输入 IP 地址** 并把它填进去。这会停止扫描，直接检查这一个地址，即使发现功能被拦截也照样有效。

如果地址没错却仍然超时，可能是打印机正扣着一个作业——请参阅[打印了一次之后就停了](/hardware/printers/printed-once-then-stopped)。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并把内容粘贴到你的消息里——它会列出尝试过的地址以及哪些端口有响应。
