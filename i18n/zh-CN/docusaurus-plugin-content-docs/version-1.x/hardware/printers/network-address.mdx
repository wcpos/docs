**症状：** 通过 Wi-Fi 扫描不到打印机，或者原本正常使用了数周的打印机，突然在每次打印收据时都超时。

## 原因说明 {#why-it-happens}

几乎所有此类问题都由以下三种网络状况引起：

- **不在同一个网络上。** 收银台和打印机连接了不同的 Wi-Fi，例如访客 SSID、第二个无线接入点或独立的 VLAN。打印机发现功能无法跨越这些网络。
- **客户端隔离。** 访客 Wi-Fi 和公共 Wi-Fi 通常会完全阻止设备之间的通信。因此，即使打印机在同一网络上，也仍然无法访问。
- **地址变了。** 路由器以租约方式分配地址。租约变更时，打印机会获得新地址，而保存的打印机配置仍指向旧地址，因此昨天还能正常使用，今天却连接超时。

## 这样做 {#do-this}

1. 将收银台和打印机连接到 **同一个 Wi-Fi**，不要使用访客网络。
2. 打印打印机的状态页，查看当前地址。对于 Epson，打开纸卷仓盖并按住 **走纸** 一秒；对于 Star，在开机状态下按住 **走纸** 五秒。
3. 为打印机设置 **固定地址**：在路由器的 DHCP 设置中，为打印机的 MAC 地址保留一个地址；或者打开打印机自带的网页 `http://printer-ip`，设置静态地址。两种方式都能防止地址发生变化。
4. 在应用中使用 **输入 IP 地址**，填入打印机地址。这会停止扫描，直接检查指定地址，即使设备发现功能被阻止也能使用。

如果地址正确却仍然超时，打印机可能正扣着一个作业。请参阅[打印了一次之后就停了](/1.x/hardware/printers/printed-once-then-stopped)。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并将内容粘贴到你的消息中。报告会列出尝试连接的地址以及作出响应的端口。
