**症状：** 在 iPad 或 iPhone 上扫描不到任何打印机，或者一台地址确认无误的打印机就是超时。同一台打印机在同一个 Wi-Fi 上的计算机可以正常使用。

## 原因说明 {#why-it-happens}

iOS 只在首次使用时询问一次：应用是否可以与本地网络上的设备通信。如果当时拒绝了——或者由别人代为回答，又或者提示根本没出现过——从那以后每一次扫描和每一次打印都会被拦下。iOS 不会给应用任何错误提示，所以它看起来和打印机没开机完全一样。

## 开启权限 {#turn-the-permission-on}

1. 打开 iPad 或 iPhone 的 **设置** 应用。
2. 前往 **隐私与安全性 → 本地网络**。
3. 打开 **WCPOS** 的开关。
4. 完全关闭应用（在应用切换器中向上划掉），然后重新打开。

然后前往 **设置 → 打印 → 添加打印机**，重新扫描。

## 另外还要检查 {#also-check}

- iPad 连的是**店里的 Wi-Fi**，而不是访客网络或移动数据。请参阅[给打印机一个固定地址](/hardware/printers/network-address)。
- Wi-Fi 已打开。Wi-Fi 关闭时，无论权限如何设置，本地地址上的打印机都无法访问。

## 如果扫描不到但打印机是好的 {#if-the-scan-finds-nothing}

扫描依赖打印机对外通告自己的存在，而有些网络会拦截这种通告。请改用 **输入 IP 地址**——它会停止扫描，直接检查这一个地址。打印打印机的状态页即可读出它的地址。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并把内容粘贴到你的消息里——它会记录 iPad 尝试了什么、返回了什么。
