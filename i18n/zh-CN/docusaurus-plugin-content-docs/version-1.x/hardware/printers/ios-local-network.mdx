**症状：** 在 iPad 或 iPhone 上扫描不到任何打印机，或者打印机地址确认无误，连接却仍然超时。同一台打印机在连接相同 Wi-Fi 的计算机上可以正常使用。

## 原因说明 {#why-it-happens}

iOS 会在首次使用时询问一次，是否允许应用与本地网络中的设备通信。如果当时拒绝了请求，或由其他人作答，又或者提示从未出现，此后的所有扫描和打印操作都会被阻止。iOS 不会向应用提供相应的错误提示，因此表现与打印机未开机完全一样。

## 开启权限 {#turn-the-permission-on}

1. 打开 iPad 或 iPhone 的 **设置** 应用。
2. 前往 **隐私与安全性 → 本地网络**。
3. 打开 **WCPOS** 的开关。
4. 完全关闭应用（在应用切换器中将其向上划掉），然后重新打开。

然后前往 **设置 → 打印 → 添加打印机**，重新扫描。

## 另外还要检查 {#also-check}

- 确认 iPad 连接的是 **店铺的 Wi-Fi**，而非访客网络或移动数据。请参阅[给打印机一个固定地址](/1.x/hardware/printers/network-address)。
- 确认 Wi-Fi 已开启。关闭 Wi-Fi 时，无论权限如何设置，都无法访问使用本地地址的打印机。

## 扫描不到打印机，但打印机可以正常工作 {#if-the-scan-finds-nothing}

扫描依赖打印机在网络中通告自身，而某些网络会阻止此类通告。请改用 **输入 IP 地址**，这会停止扫描，直接检查指定地址。打印打印机的状态页，即可查看其地址。

## 仍未解决？ {#still-stuck}

在故障提示界面上使用 **复制设置报告**，并将内容粘贴到你的消息中。报告会记录 iPad 尝试过的操作及收到的响应。
