WCPOS 会在本地保存产品、订单和客户的副本，让 POS 能够快速运行并支持离线操作。这些本地数据偶尔可能与 WooCommerce 店铺不同步。清除所有本地数据会删除本地数据库，并触发从服务器重新同步。

:::tip 先尝试有针对性的重置（v1.10.0+）
从 v1.10.0 起，**店铺健康 → 数据库** 为每个集合提供 **清除并重新下载**，只删除并重新获取出现问题的集合（例如产品），不会影响其他内容，也不会让您退出登录。确认对话框会显示将删除的记录数，并说明服务器上的副本不受影响。请注意，按需下载的集合在重置后计数较低属于正常现象，数据会随使用逐步补齐。这是预期行为，并非同步停滞。参见[店铺健康](/1.x/support/store-health#clear-and-redownload)。
:::

:::warning
这是最后的处理手段。清除本地数据会删除设备上存储的所有内容，并强制重新执行完整同步。所需时间取决于店铺的数据规模。仅在其他方法——常规[同步](/1.x/products/sync)或按集合执行 **清除并重新下载**——无法解决问题时使用。

清除前，请检查 **店铺健康 → 数据库** 中的 **等待发送的更改** 信息卡片。清除本地数据会销毁设备上所有尚未发送的更改。
:::

## 适用场景 {#when-to-use-it}

以下情况可能需要清除本地数据：

- **同步问题**——产品、订单或客户无法正常更新
- **插件更新后**——确保与新的数据结构兼容
- **数据过时**——价格、库存或其他信息未更新

## 清除内容 {#what-gets-cleared}

| 将清除 | 不会清除 |
|---------|-------------|
| 本地产品数据库 | 服务器端数据 |
| 本地订单数据库 | WooCommerce 设置 |
| 本地客户数据库 | |
| 登录会话 | |

WooCommerce 店铺的数据不受影响，只有设备上的本地副本会被移除。清除后会自动开始重新同步。

:::info 平台差异
- **桌面应用：** 您会退出登录，必须重新连接店铺。
- **Web 应用：** 登录数据会被清除，但由于您仍登录着 WP Admin，会话将自动恢复，因此您不会察觉到退出登录。
:::

## 如何清除本地数据 {#how-to-clear-local-data}

### Web {#web}

1. 点击右上角的 **用户菜单** 将其打开
2. 点击 **清除所有本地数据**
3. 本地数据库将被删除，并自动开始重新同步

### 桌面端 {#desktop}

1. 在顶部菜单栏中打开 **WCPOS** 应用菜单
2. 将鼠标悬停在 **高级** 上
3. 点击 **清除应用数据**
4. 本地数据库将被删除，并自动开始重新同步

:::note
所有平台均使用相同的本地数据库格式存储数据（从 v1.10.0 起采用基于 OPFS 的文件存储）。每个平台都会完整清除数据，但登录行为有所不同，请参见上方的平台差异说明。
:::
