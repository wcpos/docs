WCPOS 存储您产品、订单和客户的本地副本，以便 POS 可以快速工作并进行离线操作。偶尔，这些本地数据可能与您的 WooCommerce 商店不同步。清除所有本地数据将删除本地数据库，并从您的服务器触发新的同步。

:::tip 先尝试有针对性的重置（v1.10.0+）
从 v1.10.0 起，**商店健康 → 数据库** 为每个集合提供 **清除并重新下载**——它只会删除并重新获取出问题的那个集合（例如产品），不会影响其他内容，也不会让您退出登录。确认对话框会显示将删除多少条记录，并确认您服务器上的副本不受影响。请注意，按需下载的集合在重置后计数偏低是正常的，随着使用会逐步补齐——这是设计行为，而非同步卡住。参见[商店健康](/support/store-health#clear-and-redownload)。
:::

:::warning
这是一个核选项。清除本地数据会删除设备上存储的所有内容，并强制进行完全重新同步。根据您的商店规模，这可能需要一些时间。仅在其他选项（正常的 [同步](/products/sync) 或按集合的 **清除并重新下载**）未能解决问题时使用。

在清除之前，请查看 **商店健康 → 数据库** 中的 **待发送的更改** 卡片——清除本地数据会销毁设备上任何尚未发送的更改。
:::

## 何时使用 {#when-to-use-it}

您可能需要清除本地数据的情况包括：

- **同步问题** — 产品、订单或客户未正确更新
- **插件更新后** — 确保与新数据结构的兼容性
- **过时数据** — 价格、库存水平或其他信息显示过时

## 清除的内容 {#what-gets-cleared}

| 清除的内容 | 未清除的内容 |
|------------|---------------|
| 本地产品数据库 | 服务器端数据 |
| 本地订单数据库 | WooCommerce 设置 |
| 本地客户数据库 | |
| 登录会话 | |

您的 WooCommerce 商店数据不受影响 — 仅删除您设备上的本地副本。清除后将自动开始新的同步。

:::info 平台差异
- **桌面应用：** 您会被注销，必须重新连接您的商店。
- **网页应用：** 登录数据会被清除，但由于您仍处于 WP Admin 的登录状态，会话会自动重新建立——因此您不会察觉到被注销。
:::

## 如何清除本地数据 {#how-to-clear-local-data}

### 网站 {#web}

1. 点击右上角的 **用户菜单** 打开菜单
2. 点击 **清除所有本地数据**
3. 本地数据库将被删除，并将自动开始新的同步

### 桌面 {#desktop}

1. 在顶部菜单栏中打开 **WCPOS** 应用程序菜单
2. 悬停在 **高级** 上
3. 点击 **清除应用数据**
4. 本地数据库将被删除，并将自动开始新的同步

:::note
所有平台都使用相同的本地数据库格式存储数据（从 v1.10.0 起为基于 OPFS 的文件存储）。在每个平台上都会被完全清除，但登录行为有所不同——请参见上方的平台差异说明。
:::
