## 产品搜索 {#product-search}

### 统一搜索字段 {#unified-search-field}

WCPOS 提供一个统一的搜索字段，可同时搜索多个产品属性：

- **产品名称** - 搜索产品标题和描述
- **SKU** - 匹配产品 postmeta 中的 `_sku` 字段
- **条形码** - 搜索已配置的条形码字段，默认使用 WooCommerce 的 GTIN 字段 `_global_unique_id`，可在[设置](/1.x/settings/wp-admin/general#barcode-field)中改为 `_sku` 或任意自定义 postmeta 键。

只需在“搜索产品”字段中输入搜索词，POS 就会立即根据所有这些字段筛选结果。

### 分词搜索技术 {#tokenized-search-technology}

搜索功能使用具备高级分词能力的 [FlexSearch library](https://github.com/nextapps-de/flexsearch)：

- **子串匹配** - 查找出现在单词任意位置的搜索词（例如搜索“berry”可找到“blueberry”）
- **性能优化** - 使用性能预设，快速返回搜索结果
- **语言感知** - 适配店铺配置的语言
- **延迟初始化** - 仅在需要时加载搜索索引，优化内存使用

:::note 搜索词至少需要 3 个字符
从 v1.10.0 起，搜索会匹配单词 **内部** 的子串：“berry”可找到“blueberry”，“saippua”可找到“Kuorintasaippua”。相应地，搜索词有最小长度限制：短于 **3 个字符** 的查询不会与文本索引匹配。较短的编码仍可通过条形码和 SKU 查找。

在 v1.10.0 之前，搜索仅匹配前缀（只能匹配单词开头，无法匹配中间部分）。
:::

### 搜索的工作方式 {#how-search-works}

在搜索字段中输入时，POS 会：

1. 对输入内容 **分词**，生成可搜索的词项
2. 优先 **搜索本地** 存储的产品数据，立即返回结果
3. 如果匹配的产品尚未存于本地，则 **查询服务器** 并存储这些产品，让下次相同的搜索能够立即返回结果
4. 在输入时实时 **更新结果**

搜索只获取您所搜索的内容，其余产品目录通过后台预填充下载（参阅[产品同步](/1.x/products/sync)），因此搜索能保持快速，也不会获取无关数据。

## 产品筛选 {#product-filtering}

### 筛选栏 {#filter-bar}

搜索字段下方提供交互式筛选开关和下拉菜单，可按特定条件缩小产品范围。

### 可用筛选器 {#available-filters}

#### 库存状态 {#stock-status}
根据库存状态筛选产品：
- **有库存** - 有可用库存的产品
- **缺货** - 库存为零的产品
- **延期交货** - 可延期交货的产品

#### 特色产品 {#featured-products}
启用此选项，仅显示 WooCommerce 店铺中标记为“特色”的产品。

#### 促销产品 {#on-sale-products}
筛选后仅显示当前正在促销或享有有效折扣的产品。

#### 分类 {#category}
使用分类下拉菜单，按产品所属分类筛选，快速找到特定部门或产品线中的产品。

#### 标签 {#tag}
按产品标签筛选，查找具有您在 WooCommerce 店铺中定义的特定属性或特征的商品。

### 使用筛选器 {#using-filters}

- **切换筛选器** - 点击任意筛选器按钮即可启用（已启用的筛选器会高亮显示）
- **多个筛选器** - 组合多个筛选器，进一步缩小搜索范围
- **清除筛选器** - 再次点击已启用的筛选器即可停用
- **搜索 + 筛选** - 将筛选器与搜索字段配合使用，精确定位产品

## 条形码配置 {#barcode-configuration}

### 搜索字段 {#search-fields}

搜索功能会自动包含已配置的条形码字段。用于搜索的条形码字段取决于您的 POS 设置。

## 常见问题 {#faq}

<Accordion>
  <AccordionItem question="条形码的 _global_unique_id 字段是什么？">

`_global_unique_id` 是 WooCommerce 新增的 GTIN 字段，用于提高不同店铺间条形码的标准化程度。它是 WCPOS 的 **默认** 条形码字段。

**要点：**

- **现代标准**：此字段专为全球条形码标识（GTIN / UPC / EAN）设计
- **默认值**：POS 默认使用 `_global_unique_id` 作为条形码字段；您可以在设置中将其改为 `_sku` 或任意自定义元数据字段
- **灵活性**：如果使用第三方条形码插件，可以将任意产品元数据字段配置为条形码字段
- **每个产品一个字段**：POS 搜索单个已配置的条形码字段，WooCommerce 为每个产品（或每个变体）存储一个条形码值。如果一个产品需要多个编码，请将它们存储在自定义字段中，并将条形码设置指向该字段
- **更改后重建**：更改条形码字段会重建本地产品目录的条形码索引，因此扫描会立即匹配新选定的字段

要配置 POS 使用的条形码字段，请前往 WordPress 管理后台中的 POS 设置。

  </AccordionItem>

  <AccordionItem question="为什么搜索时看不到所有产品？">

后台产品目录预填充可能尚未完成。如果看不到某个产品：

1. **搜索它** - 如果匹配的产品尚未存于本地，搜索会直接从服务器获取它们
2. **查看下载进度** - **店铺健康 → 数据库** 显示产品目录已下载到此设备的进度
3. **检查它的可见性** - 缺货产品默认隐藏，且仅支持标准 WooCommerce 产品类型

请参阅[产品同步](/1.x/products/sync)指南了解更多信息。

  </AccordionItem>

  <AccordionItem question="可以搜索部分产品名称或 SKU 吗？">

可以！分词搜索会匹配子串，也就是说：

- 搜索“blue”会找到包含“blueberry”、“blue shirt”等内容的产品。
- 搜索“berry”也会找到“blueberry”——搜索词可以出现在单词的任意位置
- 搜索“ABC”会找到“ABC123”、“ABC-XYZ”等 SKU。
- 无需输入完整的单词或编码（但短于 3 个字符的搜索词不会被匹配）

搜索功能旨在让您用尽可能少的输入快速找到产品。

  </AccordionItem>
</Accordion>
