产品面板位于 POS 屏幕左侧，您可以在这里搜索、浏览并选择要添加到购物车的产品。

{/* Screenshot: pos-product-panel.png */}

## 界面概述 {#interface-overview}

### 搜索栏 {#search-bar}

面板顶部的搜索栏可让您通过以下方式快速查找产品：

- **产品名称** - 输入产品名称的任意部分
- **SKU** - 按库存单位搜索
- **条形码** - 扫描或输入条形码号码

有关详细信息，请参阅[搜索与过滤](/1.x/pos/product-panel/search-filtering)。

### 显示设置 {#display-settings}

单击搜索栏旁的 **滑块图标**（<Icon name="sliders" />）打开显示设置，自定义产品列表中显示的列和信息。

### 筛选按钮 {#filter-buttons}

搜索栏下方的筛选按钮可让您缩小产品范围：

- **有货** - 仅显示有可用库存的产品
- **推荐** - 显示在 WooCommerce 中标记为推荐的产品
- **特价** - 显示当前特价的产品
- **类别** - 按产品类别筛选
- **标签** - 按产品标签筛选
- **品牌** - 按品牌筛选（如果使用了品牌插件）

已启用的筛选器会高亮显示。再次单击即可移除。

### 产品列表 {#product-list}

主区域以可滚动的列表显示产品。每行显示：

- **产品图片** - 产品缩略图
- **产品名称** - 可附带详情（库存、SKU、类别等）
- **价格** - 当前售价（有促销价时会显示促销价）
- **操作按钮** - 添加到购物车（<Icon name="circle-plus" color="green" />）或选择变体（<Icon name="circle-arrow-right" color="green" />）

### 产品类型 {#product-types}

- **简单产品** 显示绿色 <Icon name="circle-plus" color="green" /> 按钮，可直接添加到购物车
- **可变产品** 显示绿色 <Icon name="circle-arrow-right" color="green" /> 箭头，可打开变体选择器

有关详细信息，请参阅[可变产品](/1.x/pos/product-panel/variations)。

### 页脚 {#footer}

产品面板底部包含：

- **税务状态** - 显示当前税务计算依据（例如“税务基于：店铺基本地址”）。单击可查看当前适用的税率。
- **产品数量** - 显示当前列出的产品数量（例如“显示 10 个，共 17 个”）
- **同步按钮**（<Icon name="arrow-rotate-right" />）- 从服务器刷新产品。**长按** 可查看更多选项：
  - **同步** - 从服务器执行常规刷新
  - **清除并刷新** - 清除本地数据并重新加载所有内容

### 显示缺货产品 {#show-out-of-stock-products}

控制当前缺货的产品是否显示。

- **启用**：缺货产品仍然可见但无法添加到购物车
- **禁用**：缺货产品从列表中隐藏

### 列 {#columns}

配置在产品列表中显示的列：

| 列 | 描述 |
|--------|-------------|
| **图片** | 产品缩略图 |
| **产品** | 产品名称和详情 |
| **SKU** | 库存单位（单独列） |
| **条形码** | 产品条形码（单独列） |
| **类型** | 产品类型（简单、可变等） |
| **库存** | 当前库存数量 |
| **销售成本** | 产品成本价格 |
| **价格** | 销售价格 |
| **操作** | 添加到购物车按钮 |

有两个列具有可启用的额外显示选项：

| 列 | 显示选项 |
|--------|-----------------|
| **产品** | 库存、SKU、条形码、类别、标签、品牌、属性、元数据 |
| **价格** | 税务信息、特价指示 |

### 元数据键 {#meta-data-keys}

元数据键是存储在 WooCommerce 产品上的自定义字段。默认情况下，这些字段保留在产品上——不会复制到订单中。此设置允许您在添加产品时将特定的键转移到购物车行项目上。

**示例：** 某个瓶子押金插件在每个产品上存储一个 `_bottle_deposit` 值。在此处添加该键后，每当产品被添加到购物车时，其押金值都会随行项目一起进入订单——因此它会显示在订单、小票以及任何下游报告中。

输入一个以逗号分隔的元键列表：

```
_bottle_deposit,_custom_field,_tracking_code
```

:::tip
元键是区分大小写的，必须与存储在产品元数据中的内容完全匹配。
:::

  <AccordionItem question="我什么时候会用到它？">

将产品元数据传递到订单行项目的常见场景：

- **瓶子押金插件**——将押金金额带入订单。
- **自定义产品字段**——将您自己的产品数据传递到订单。
- **第三方集成数据**——将值传递给读取订单行项目的其他插件。
- **合规/跟踪信息**——将批次、批号或跟踪代码与售出的商品关联。

### 恢复默认设置 {#restore-default-settings}

单击可将所有显示设置重置为初始默认值。

## 将产品添加到购物车 {#adding-products-to-cart}

### 简单产品 {#simple-products}

单击绿色 <Icon name="circle-plus" color="green" /> 按钮，将简单产品添加到购物车。每次单击增加一个单位。

### 可变产品 {#variable-products}

可变产品（例如有尺寸和颜色选项的 T 恤）会显示绿色 <Icon name="circle-arrow-right" color="green" /> 箭头。单击后可使用以下方式：

1. **快速弹出** - 从下拉菜单中选择变体
2. **展开内联** - 单击“展开”，在列表中查看所有变体

有关详细信息，请参阅[可变产品](/1.x/pos/product-panel/variations)。

### 条形码扫描 {#barcode-scanning}

连接 USB 或蓝牙条形码扫描仪即可快速添加产品。扫描条形码时，WCPOS 会自动搜索并添加匹配的产品。

有关设置说明，请参阅[条形码扫描](/1.x/pos/product-panel/barcode-scanning)。

## 为什么看不到某些产品？ {#why-cant-i-see-some-products}

如果产品面板中缺少产品，请检查：

- **POS 可见性** - 设置为“仅在线”的产品不会出现在 POS 中。请参阅[仅限 POS 的产品](/1.x/products/pos-only-products)。
- **库存设置** - 如果在显示设置中禁用了“显示缺货产品”，缺货商品就会被隐藏。
- **同步状态** - 新增或最近更新的产品可能需要同步。长按同步按钮并选择 **“清除并刷新”**。
- **筛选器** - 检查是否有已启用的筛选器（类别、标签等）隐藏了产品。
