- 打开模态框，管理订单的附加元数据。
- 功能包括：
  - 更改订单货币。
  - 添加交易 ID（例如来自外部支付终端的交易 ID）。
  - 为订单添加自定义元数据。

:::note
此模态框后续会陆续添加更多功能，包括与其他 WooCommerce 插件的集成。
:::

### 什么是 WooCommerce 中的元数据？ {#what-is-meta-data-in-woocommerce}

元数据提供有关订单的额外信息，可通过 WooCommerce REST API 访问。开发人员和插件使用这些数据扩展功能，例如集成第三方服务。

### JSON 视图 {#json-view}

- 查看订单的原始 JSON 数据，便于调试或集成。

## 保存到服务器 {#save-to-server}

- 将打开的购物车保存到服务器，确保安全存储，方便日后访问。
- 创建状态为 `pos-open` 的 WooCommerce 订单。

### 为什么要保存？ {#why-save}

在 POS 中创建的新订单最初仅存在于本地。 
保存订单可确保即使本地数据库被清空，订单也不会丢失。

有关管理已保存订单的详细信息，请参阅[打开的订单](/1.x/pos/cart/open-orders)。

## 作废 {#void}

- 分为两种情况：
  - 未保存的订单：
    - 如果订单尚未保存到服务器，它将从本地数据库中永久删除。
  - 已保存的订单：
    - 如果订单已保存到服务器，它将被移至 WooCommerce 的回收站，并从本地数据库中删除。
- 要恢复已作废的订单：
  - 前往 `WP Admin > WooCommerce > Orders > Trash`。

## 结账 {#checkout}

- 将订单保存到服务器并启动结账流程。
- 打开[结账页面](/1.x/pos/checkout)以完成支付。
