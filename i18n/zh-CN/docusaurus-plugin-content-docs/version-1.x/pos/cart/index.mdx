购物车面板位于 POS 屏幕右侧，用于管理当前订单。在这里，您可以查看项目、编辑数量和价格、选择客户并继续结账。

{/* Screenshot: pos-cart-panel.png */}

## 界面概述 {#interface-overview}

### 客户选择器 {#customer-selector}

在购物车面板顶部：

- **客户徽章** - 显示当前客户（例如“访客”或客户姓名）
- **添加客户图标**（<Icon name="plus" />）- 创建新客户
- **显示设置**（<Icon name="sliders" />）- 配置购物车列和选项

点击客户徽章以搜索并选择其他客户。

### 行项目 {#line-items}

主要区域显示当前订单中的项目：

- **数量** - 数量（可编辑）
- **名称** - 产品名称及变体属性
- **价格** - 单价（可编辑）
- **总计** - 行总计

有关编辑的详细信息，请参阅[行项目](/1.x/pos/cart/line-items)。

### 添加到购物车选项 {#add-to-cart-options}

在行项目下方，您可以添加特殊项目：

- **添加杂项产品** - 添加自定义项目并手动输入价格
- **添加费用** - 添加费用行（例如礼品包装、服务费）
- **添加运费** - 添加运费行并手动输入费用

:::note 行项目类型
WooCommerce 使用三种类型的行项目：`line_item`（产品）、`fee_line`（费用）和 `shipping_line`（运费）。目前仅支持手动输入运费，POS 不会自动计算运费。
:::

### 订单摘要 {#order-summary}

- **小计** - 未计入税费和费用的总额
- **税** - 计算出的税额（如适用）
- **总计** - 最终订单总额

### 订单操作 {#order-actions}

在购物车面板底部：

- **订单备注** - 添加对客户可见的备注
- **订单元数据** - 添加自定义元数据或查看 JSON
- **保存到服务器** - 将订单保存到 WooCommerce，状态为 `pos-open`

有关详细信息，请参阅[订单操作](/1.x/pos/cart/order-actions)。

### 主要按钮 {#main-buttons}

- **作废**（红色）- 取消/删除当前订单
- **结账**（绿色）- 继续支付

### 开放订单 {#open-orders}

最底部的轮播区域显示所有开放订单：

- 每个购物车显示其总计
- 点击购物车即可切换到该购物车
- 当前购物车会突出显示

有关详细信息，请参阅[开放订单](/1.x/pos/cart/open-orders)。

### 结账后自动显示收据 {#automatically-show-receipt-after-checkout}

启用后，销售完成时会自动显示收据界面。

### 结账后自动打印收据 {#automatically-print-receipt-after-checkout}

启用后，收据显示时会自动打印，减少手动打印步骤以节省时间。

### 快速折扣 {#quick-discounts}

以逗号分隔的折扣百分比列表，各百分比会显示为快捷按钮。

例如，输入 `5,10,15,20`，会在每个行项目 **价格** 字段的数字键盘上添加四个按钮。点击其中一个，即可按相应百分比降低该行价格。请参阅[购物车折扣](/1.x/pos/cart/discounts#quick-discounts)。

### 列 {#columns}

配置购物车中显示的列：

| 列 | 说明 |
|--------|-------------|
| **数量** | 每件商品的数量 |
| **名称** | 商品名称 |
| **价格** | 单价 |
| **原价** | 未打折的价格 |
| **小计** | 行小计（数量 × 价格） |
| **总计** | 行总计 |
| **操作** | 移除商品按钮 |

部分列提供额外的显示选项：

| 列 | 选项 |
|--------|--------|
| **数量** | 拆分（允许拆分商品） |
| **名称** | SKU |
| **价格** | 促销标记 |
| **小计** | 税额 |
| **总计** | 税额、促销标记 |

### 恢复默认设置 {#restore-default-settings}

点击即可将所有购物车显示设置恢复为原始默认值。

## 向购物车添加商品 {#adding-items-to-cart}

### 从产品面板添加 {#from-product-panel}

点击[产品面板](/1.x/pos/product-panel)中的产品，即可将其添加到购物车。对于可变产品，请先选择变体。

### 杂项产品 {#miscellaneous-products}

对于不在产品目录中的项目：

1. 点击 **添加杂项产品**
2. 输入名称和价格
3. 该项目会被添加到购物车

这是 POS 的开放价格商品功能，有时也称为自由定价或自定义价格按钮。免费版已包含此功能，无需设置。如果目录中的商品每次售价不同，请先添加该商品，再在行项目中[更改其价格](/1.x/pos/cart/line-items#price)。

### 费用 {#fees}

要添加费用（例如礼品包装）：

1. 点击 **添加费用**
2. 输入名称和金额
3. 费用会显示为单独的行项目

### 运费 {#shipping}

要添加运费：

1. 点击 **添加运费**
2. 输入运送方式名称和费用
3. 运费会被添加到订单中

## 编辑购物车项目 {#editing-cart-items}

所有行项目均可直接在购物车中编辑。有关以下操作的详细信息，请参阅[行项目](/1.x/pos/cart/line-items)：

- 编辑数量
- 更改价格
- 查看和编辑原始 JSON 数据
- 移除项目
