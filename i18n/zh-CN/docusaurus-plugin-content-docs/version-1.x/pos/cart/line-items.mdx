购物车中的每个项目都是可以直接编辑的行项目。WCPOS 提供灵活的内联编辑功能，可修改数量、价格和其他详情。

## 行项目类型 {#line-item-types}

WooCommerce 使用三种类型的行项目：

| 类型 | 描述 | 示例 |
|------|-------------|----------|
| **line_item** | 来自产品目录的产品 | T 恤、咖啡杯 |
| **fee_line** | 附加费用 | 礼品包装、服务费 |
| **shipping_line** | 运费 | 标准配送、加急配送 |

:::note
运费需要手动输入。POS 不会自动计算运费。
:::

## 编辑行项目 {#editing-line-items}

### 数量 {#quantity}

点击数量字段即可直接编辑。输入新数字，或使用增减按钮调整。

{/* Screenshot: cart-line-item-edit-qty.png */}

### 产品名称 {#product-name}

对于杂项产品和费用，点击名称即可直接编辑。

### 价格 {#price}

点击价格字段即可更改单价。这适用于：

- 应用手动折扣
- 价格匹配
- 更正定价错误

总计会根据数量 × 价格自动更新。

:::note 修改价格不等于 WooCommerce 的“折扣”
调低后的价格会记录为商品的促销价，收据可以显示节省金额，但订单的 **折扣** 总额仅用于优惠券，报告则按实际成交价统计销售额。请参阅[购物车折扣](/1.x/pos/cart/discounts#why-tracked-differently)，了解 WooCommerce 为何以不同方式处理两者。
:::

### 三点菜单 {#three-dot-menu}

点击任意行项目上的 **⋮**（三个点）即可访问其他选项：

{/* Screenshot: cart-line-item-menu.png */}

#### 编辑表单 {#edit-form}

打开行项目的详细编辑表单，以修改所有字段。

#### 原始 JSON 视图 {#raw-json-view}

显示行项目的原始 JSON 数据。这对以下工作很有帮助：

- **调试** - 查看发送到 WooCommerce 的确切数据
- **故障排除** - 识别自定义字段或元数据的问题
- **开发** - 了解集成所用的数据结构

### 删除项目 {#remove-item}

点击红色 **×** 按钮即可从购物车中删除项目。

## 变体属性 {#variation-attributes}

对于可变产品，所选的变体属性会显示在产品名称下方：

```
Hoodie
Colour: Green
Size: Large
```

这些属性是行项目数据的一部分，会包含在订单中。

## 元数据 {#meta-data}

如果您在产品面板设置中配置了[元数据键](/1.x/pos/product-panel#meta-data-keys)，产品添加到购物车时，这些数据会自动复制到行项目中。

您可以在原始 JSON 视图中查看这些元数据。

## 拆分行项目 {#splitting-line-items}

在[显示设置](/1.x/pos/cart#display-settings)中启用后，您可以将一个行项目拆分为多行。当客户希望对同一产品的不同部分应用不同折扣时，这项功能很有用。

## 提示 {#tips}

### 快速调整价格 {#quick-price-adjustments}

要快速提供折扣：

1. 点击价格字段
2. 输入新价格
3. 按 Enter

### 键盘导航 {#keyboard-navigation}

- **Tab** - 在可编辑字段之间移动
- **Enter** - 确认编辑
- **Escape** - 取消编辑

### 批量编辑 {#batch-edits}

对于复杂订单，可以使用三点菜单打开完整编辑表单，一次查看所有字段。
