热敏模板采用 XML 格式，可通过同一个模板生成屏幕预览和 ESC/POS 打印机命令。它们使用与 [HTML 模板](/1.x/receipts/html-templates)相同的 `{{variable}}` 占位符进行数据绑定。

如果您已通过[打印机设置](/1.x/hardware/printers)连接收据打印机，请选择此引擎。

## XML 元素 {#xml-elements}

### 根元素 {#root-element}

每个热敏模板都以 `<receipt>` 为根元素：

```xml
<receipt paper-width="48">
  <!-- 48 characters = 80mm paper -->
  <!-- 32 characters = 58mm paper -->
</receipt>
```

### 文本与格式 {#text-and-formatting}

```xml
<text>Plain text</text>
<bold>Bold text</bold>
<underline>Underlined text</underline>
<invert>Inverted (white on black)</invert>
```

### 对齐方式 {#alignment}

```xml
<align mode="left">Left aligned</align>
<align mode="center">Centered</align>
<align mode="right">Right aligned</align>
```

### 文本大小 {#text-size}

分别缩放文本的宽度和高度：

```xml
<size width="2" height="2">Double-size text</size>
<size width="2" height="1">Wide text</size>
<size width="1" height="2">Tall text</size>
```

### 表格布局 {#tabular-layout}

使用 `<row>` 和 `<col>` 实现列对齐：

```xml
<row>
  <col width="24">Item name</col>
  <col width="8" align="right">Qty</col>
  <col width="16" align="right">Price</col>
</row>
```

列宽以字符为单位。使用 `width="*"` 创建占据剩余空间的弹性列，让模板无需修改即可适用于不同纸张宽度：

```xml
<row>
  <col width="*">{{name}}</col>
  <col width="12" align="right">{{line_total_display}}</col>
</row>
```

### 分隔线与间距 {#separators-and-spacing}

```xml
<line />                       <!-- Default single rule -->
<line style="double" />        <!-- Printer-native double rule -->
<line style="dashed" />        <!-- Character dashes across the width -->
<line style="dotted" />        <!-- Character dots across the width -->
<feed lines="2" />             <!-- Blank lines -->
```

`<line/>` （或 `style="single"`）和 `style="double"` 会打印打印机原生的分隔线。 `dashed` 和 `dotted` 会在当前列宽范围内打印由字符组成的分隔线，适合需要在热敏预览截图中保留可见分隔线的场景。

### 打印机命令 {#printer-commands}

```xml
<cut />              <!-- Full paper cut -->
<cut mode="partial" /> <!-- Partial cut (leaves a tab) -->
<drawer />           <!-- Open cash drawer -->
```

### 条形码与二维码 {#barcodes-and-qr-codes}

```xml
<barcode type="code128" height="40">{{order.number}}</barcode>
<barcode type="qrcode" scale="3">{{fiscal.qr_payload}}</barcode>
```

## 示例：简易 80mm 收据 {#example-simple-80mm-receipt}

```xml
<receipt paper-width="48">
  <align mode="center">
    <size width="2" height="2">{{store.name}}</size>
  </align>
  <feed lines="1" />
  <align mode="center">
    <text>{{store.address_1}}</text>
    <text>{{store.city}} {{store.state}} {{store.postcode}}</text>
    {{#store.phone}}<text>{{store.phone}}</text>{{/store.phone}}
  </align>
  <line />

  <text>Order: #{{order.number}}</text>
  <text>Date: {{order.created.datetime}}</text>
  {{#cashier.name}}<text>Cashier: {{cashier.name}}</text>{{/cashier.name}}
  <line />

  <!-- Column headers -->
  <row>
    <col width="*"><bold>Item</bold></col>
    <col width="4" align="right"><bold>Qty</bold></col>
    <col width="12" align="right"><bold>Total</bold></col>
  </row>
  <line />

  <!-- Line items -->
  {{#lines}}
  <row>
    <col width="*">{{name}}</col>
    <col width="4" align="right">{{qty}}</col>
    <col width="12" align="right">{{line_total_display}}</col>
  </row>
  {{/lines}}

  <line />

  <!-- Totals -->
  <row>
    <col width="*">Subtotal</col>
    <col width="16" align="right">{{totals.subtotal_display}}</col>
  </row>
  {{#totals.tax_total}}
  <row>
    <col width="*">Tax</col>
    <col width="16" align="right">{{totals.tax_total_display}}</col>
  </row>
  {{/totals.tax_total}}
  <row>
    <col width="*"><bold>TOTAL</bold></col>
    <col width="16" align="right"><bold>{{totals.total_display}}</bold></col>
  </row>

  <line />

  {{#payments}}
  <row>
    <col width="*">{{method_title}}</col>
    <col width="16" align="right">{{amount_display}}</col>
  </row>
  {{#tendered}}
  <row>
    <col width="*">Tendered</col>
    <col width="16" align="right">{{tendered_display}}</col>
  </row>
  <row>
    <col width="*">Change</col>
    <col width="16" align="right">{{change_display}}</col>
  </row>
  {{/tendered}}
  {{/payments}}

  <feed lines="2" />
  <align mode="center">
    <text>Thank you for your purchase!</text>
  </align>
  <feed lines="3" />
  <cut />
</receipt>
```

## 星号宽度列 {#star-width-columns}

`width="*"` 功能让模板不依赖纸张宽度。无需针对特定纸张尺寸硬编码列宽，只需对需要拉伸的列使用 `*`：

```xml
<!-- Works on 58mm (32 char) AND 80mm (48 char) printers -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

在 80mm 打印机（48 个字符）上，商品名称可占用 38 个字符。在 58mm 打印机（32 个字符）上，则可占用 22 个字符。固定列在两者上保持相同宽度。

:::warning 已移除旧版 StarPRNT 固定布局适配器
旧版 StarPRNT **固定布局输出适配器**已在 v1.10 中移除。如果模板依赖此适配器，请改用当前的热敏模板（本页介绍的 XML 引擎），它通过共享热敏布局生成 Star 输出。请使用 `<row>`/`<col>` 和 `width="*"` 重新创建布局，替代固定布局适配器。
:::

## 模板预览 {#template-preview}

模板编辑器会在编辑时显示**实时热敏预览**。预览会将 XML 渲染为带样式的等宽字体 HTML，模拟收据打印在纸上的效果。更改会在短暂延迟后更新（300ms 防抖）。

同一个模板会同时生成预览和 ESC/POS 打印机输出，无需单独的“打印”模板。条形码和二维码在预览中渲染为内联 SVG，在打印机上则输出为原生 ESC/POS 命令（或光栅图像）。

## 编写提示和注意事项 {#authoring-tips-and-pitfalls}

热敏打印有一些 HTML 中不存在的问题。以下是编写模板时最常遇到的情况。

### 将带样式的标题包在 `<text>` 中以换行 {#wrap-styled-headings-in-text-for-a-line-break}

带样式的容器—— `<bold>`、 `<size>`、 `<underline>`、 `<align>` ——**本身不会输出换行**。只有 `<text>` 和块级元素（`<line/>`、 `<row>`、 `<feed>`）才会。

```xml
<!-- ❌ Bug: the heading runs together with whatever follows -->
<bold>{{i18n.bill_to}}</bold>
{{customer.name}}

<!-- ✅ Fix: wrap the inner content in <text> -->
<bold><text>{{i18n.bill_to}}</text></bold>
<text>{{customer.name}}</text>
```

模板库内置的 80mm 模板对每个标题都采用了这种写法。

### 避免在窄行内使用 `<size width="2">` {#avoid-size-width2-inside-narrow-rows}

双倍宽度文本会**使实际占用的字符数翻倍**。在某款 80mm 打印机上能放下的标题，在 42 列的通用 80mm 打印机上可能溢出，而在 58mm 纸张上只能容纳 16 个字符。

对于需要突出显示的值（大号总计、厨房订单号），请单独输出一行缩放后的文本，不要将其放入多列的 `<row>`中：

```xml
<!-- For store names, prefer normal-width, double-height -->
<bold><size height="2"><text>{{store.name}}</text></size></bold>

<!-- For a bold total, put it on its own line above the row -->
<align mode="right">
  <bold><size height="2"><text>{{totals.total_display}}</text></size></bold>
</align>
```

### 使用 `width="*"` 创建不依赖纸张宽度的布局 {#use-width-for-paper-width-agnostic-layouts}

`width="*"`（星号）列会占据固定宽度列之外的剩余宽度。这样，同一个模板无需修改即可在 32 列（58mm）、42 列（80mm 标准）和 48 列（80mm 宽幅）打印机上正确渲染：

```xml
<!-- Works on 58mm AND 80mm without changes -->
<row>
  <col width="*">{{name}}</col>
  <col width="10" align="right">{{line_total_display}}</col>
</row>
```

如果确实要使用硬编码的数字宽度，**请按总宽度 42 分配**，而非 48。总宽度为 48 的行会在常见的 42 列 80mm 打印机上换行。

### `<align>` 块内居中的带样式标题 {#centred-styled-headings-inside-align-blocks}

在 `<align mode="center">` （或 `right`）中，带样式的标题——即 `<bold>`、 `<size>`、 `<underline>`、 `<invert>` 等直接放在 `<align>` 内的元素——若后面还有另一行，会自动独占一行。居中缩放的店铺名称可清晰地打印在居中的地址行上方，即使没有显式使用 `<text>` 包裹。

在对齐块之外，请保留 `<text>` 包裹。

### ESC/POS 标点规范化 {#escpos-punctuation-normalisation}

当打印机语言为 ESC/POS 时，编码器会在写入前将排版标点规范化为安全的 ASCII 字符：

- 短破折号、长破折号、数字破折号、Unicode 减号 → `-`
- 弯引号 → 直引号
- 不换行空格 → 普通空格

因此，`Mon–Sat 9:00–18:00` 和 `"open"` 即使在没有 Unicode 字体的打印机上也能正确打印。Star 打印机（`star-line` / `star-prnt`）会**保留**原始排版字符，因此编写内容时应使用打印机字体支持的字符。

### 非拉丁文字与从右到左书写的文字 {#non-latin-and-rtl-scripts}

热敏打印机使用内置字体和代码页打印文本，因此阿拉伯语、希伯来语、波斯语、乌尔都语及其他非拉丁文字只有在打印机设置为匹配的代码页（例如阿拉伯语使用 CP864 / Windows-1256）时才能正确打印，否则会出现空白或乱码。

这些文字的可靠打印方式是使用**完整收据光栅化**，将整张收据渲染为图像，不受打印机内置字体影响，按设计效果打印。启用光栅模式的方法请参阅[打印机设置](/1.x/hardware/printers)。

:::note 热敏硬件需要热敏模板
热敏打印机无法打印整页 **HTML** 模板：打印任务必须渲染为 ESC/POS 或 Star 命令，而 HTML 无法表达这些命令。热敏硬件请使用热敏模板；整页 A4/Letter HTML 则应使用系统/PDF 打印机，或通过 [PrintNode](/1.x/receipts/cloud-printing#setup-printnode) 打印。
:::

### 徽标和图像 {#logos-and-images}

使用 `<image>` 嵌入徽标：

```xml
<align mode="center">
  <image src="data:image/png;base64,..." />
</align>
```

WCPOS 会在客户端对图像进行光栅化：解码、将透明区域转为白色、调整尺寸以适应打印机的点数限制、转换为单色（徽标使用 Atkinson 抖动，条形码使用阈值处理），然后发送 ESC/POS 或 Star 图像命令。

- **点数预算**：58mm 的宽度为 384 点，80mm 的宽度为 576 点。
- **接受的来源**：`data:image/png` 和 `data:image/jpeg` 数据 URL、绝对 `http(s)` URL，以及同源的根相对路径。协议相对路径 `//`、反斜杠及百分号编码的 `..` 路径遍历均会被拒绝。
- **推荐格式**：背景透明或为白色的高对比度 PNG。JPEG 也可使用，但压缩伪影可能会打印成噪点。
- 原始热敏输出**尚不支持 SVG**。

### 提示 {#tips}

- **从模板库中的模板开始**——模板库中的热敏模板采用了上述所有写法，并已通过真实打印机验证。
- 如果您的店铺使用不同的打印机，**请测试两种纸张尺寸**，或统一使用 `width="*"` 列。
- 货币请**使用 `_display` 字段**，它们已经过本地化格式处理。
- **保持简单**——热敏打印在设计上就比 HTML 提供更少的格式工具。多利用 `<row>` + `<col width="*">` ，让打印机完成排版。
