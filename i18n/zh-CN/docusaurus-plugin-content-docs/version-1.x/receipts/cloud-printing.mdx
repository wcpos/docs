云打印让 WCPOS 能将收据发送到未直接连接收银设备的打印机。只需在 WP Admin 中设置一次，订单就能打印到厨房、后台办公室或其他房间的打印机，无需每台设备分别发现硬件并与其配对。

## 什么是云打印？ {#what-is-cloud-printing}

使用**本地打印**时，运行 POS 的设备通过 USB、蓝牙或本地网络直接与打印机通信。如果打印机就在收银台旁边，这种方式很合适。有关在同一设备上连接 USB、蓝牙和网络打印机的方法，请参阅[打印机设置](/1.x/hardware/printers)。

**云打印**适用于其他情况：打印机位于不同地点或网络，或者您希望所有设备共享一台打印机，而无需逐台配置。有两种投递模式：

- **轮询打印机。** 打印机定期通过互联网主动联系 WCPOS，询问“有没有待打印任务？”，并拉取等待中的任务。WCPOS 从不主动连接打印机，始终由打印机发起通信。**Star CloudPRNT** 和 **Epson Server Direct Print** 就采用这种方式。
- **托管中继提供商。** WCPOS 将打印任务提交给托管服务，再由该服务投递给打印机。**Star Online** 和 **PrintNode** 就采用这种方式。Star Online 将任务投递到您 stario.online 账户中注册的 Star CloudPRNT 打印机；PrintNode 则通过桌面客户端投递到该计算机已经能够使用的几乎任何打印机。

:::info 为什么使用轮询打印机？
轮询打印机只发出出站请求，因此不需要开放端口、设置静态 IP 或更改防火墙。这非常适合位于远程地点，或连接在您无法管理的路由器后面的打印机。代价是会有短暂延迟：打印机要等到下一次轮询时才会打印。
:::

## WCPOS Cloud Print——中继 {#relay}

设置**轮询**打印机（Star CloudPRNT 或 Epson Server Direct Print）时，WCPOS 提供的轮询 URL 指向 **cloudprint.wcpos.com**，而不是您的站点。这就是 **WCPOS Cloud Print**，由 WCPOS 运营的免费中继，位于打印机与您的店铺之间。

**为什么需要中继。** 收据打印机的固件功能精简，且很少更新。许多打印机无法与采用现代托管服务的店铺建立安全连接：较新的 TLS 版本、较新的证书颁发机构，或站点前的 CDN/防火墙（Cloudflare 是常见原因）可能拒绝打印机连接，也可能被打印机拒绝。表现就是所有设置均正确，打印机却始终停留在**等待**状态。中继为打印机提供旧固件也能完成协商的连接，并将其流量转发到您的店铺。

**工作方式：**

- 首次打开云打印设置时，您的站点会**自动**连接到中继，无需启用或配置任何内容。
- 打印机轮询 `cloudprint.wcpos.com`；中继将请求转发到您的店铺，并返回店铺的响应。打印任务只是**经过**中继，绝不会存储在中继上。
- 中继处理了大部分空闲轮询，因此空闲打印机向您站点发出的请求约为每分钟一次，而不是每几秒一次。
- 如果您的站点无法连接中继（例如中继无法访问的本地开发站点），WCPOS 会自动回退到直连站点的 URL。

:::note 更希望直接连接？
每台打印机的设置界面都有一个**高级**展开项，显示直连站点的 URL。如果您确定托管环境支持打印机连接，或不希望任务经过中继，可以使用该 URL。开发者只需一行代码即可在全站关闭中继：

```php
add_filter( 'woocommerce_pos_cloud_print_relay_enabled', '__return_false' );
```
:::

**中继能看到什么。** 连接会将您的站点 URL 共享给 wcpos.com，并且打印任务——包含订单详情的收据内容——会在送往打印机的途中经过中继。不会保留任何内容。完整详情见[隐私政策](https://wcpos.com/privacy)。

## 设置云打印机 {#setup}

云打印机只需在 WP Admin 中配置一次，即可供所有设备共享；本地打印机的配置则按设备单独存储。

前往 **WP Admin > POS > 设置 > 云打印**，点击**添加打印机**。为其设置**名称**（例如“厨房”或“后台办公室”）。WCPOS 会根据打印机自动生成一个固定的**打印机 ID**，该 ID 永远不会改变，因此可以放心地在打印机固件配置中引用。

创建打印机后，配置提供商端。

### Star 或 Epson（轮询打印机） {#setup-polling}

<Steps>
  <StepCard number="1" title="在 WCPOS 中添加打印机">

在 **WP Admin > POS > 设置 > 云打印** 中添加打印机，选择 **Star CloudPRNT** 或 **Epson Server Direct Print** 作为提供商。WCPOS 会为该打印机生成**轮询 URL** 和**一次性令牌**。

  </StepCard>
  <StepCard number="2" title="复制轮询 URL 和令牌">

复制生成的轮询 URL 和令牌。URL 通常指向 **cloudprint.wcpos.com**，即 [WCPOS Cloud Print 中继](#relay)，请使用此地址；直连站点的 URL 则位于**高级**展开项中。**令牌只显示一次**，如果丢失，请在打印机卡片上重新生成令牌，并用新值更新打印机配置。

  </StepCard>
  <StepCard number="3" title="在打印机配置中输入 URL 和令牌" isLast>

打开打印机的配置页面：Star 对应 **CloudPRNT** 设置，Epson 对应 **Server Direct Print** 设置。粘贴轮询 URL 和令牌。如果打印机要求设置轮询间隔，请进行设置（通常为几秒）。保存设置，并根据需要重启打印机。

在一个轮询周期内，打印机会联系 WCPOS，其状态会从**等待**变为**已连接**。

  </StepCard>
</Steps>

### PrintNode {#setup-printnode}

<Steps>
  <StepCard number="1" title="安装 PrintNode 桌面客户端">

在已经能使用目标打印机的计算机上安装 **PrintNode 客户端**并登录。客户端必须保持运行且在线，才能打印任务。

  </StepCard>
  <StepCard number="2" title="获取 PrintNode API 密钥">

在您的 PrintNode 账户中创建 **API 密钥**，以便 WCPOS 向该账户提交任务。

  </StepCard>
  <StepCard number="3" title="在 WCPOS 中输入 API 密钥">

在 **WP Admin > POS > 设置 > 云打印** 中添加打印机，选择 **PrintNode** 作为提供商，并粘贴 API 密钥。WCPOS 会使用该密钥获取您 PrintNode 账户中注册的打印机列表。

  </StepCard>
  <StepCard number="4" title="选择打印机" isLast>

从 PrintNode 客户端报告的打印机列表中选择目标打印机，然后保存。WCPOS 会将该打印机的任务提交给 PrintNode，由客户端执行打印。

  </StepCard>
</Steps>

### Star Online {#setup-star-online}

如果您的 Star 打印机已注册到 **stario.online** 账户，且您希望由 Star 的托管服务负责投递任务，请使用 Star Online。

<Steps>
  <StepCard number="1" title="获取 CloudPRNT URL">

在 stario.online 中打开**设备组**，复制该组的 **CloudPRNT URL**。其形式应类似于 `https://device.stario.online/cloudprnt/...` 或 `https://eu-device.stario.online/cloudprnt/...`。

  </StepCard>
  <StepCard number="2" title="创建具有所需权限的 API 密钥">

在 stario.online 中为 WCPOS 创建 API 密钥。该密钥必须具有列出设备及向设备打印的权限。至少需启用：

- **EnumDevices** —— WCPOS 获取设备列表时必需
- **ViewDevice** —— 用于检查设备状态
- **PrintToDevice** —— 提交打印任务时必需
- **ViewDeviceGroups** —— 建议启用，用于设备组查询和诊断

如果未启用这些权限，即使 API 密钥存在，操作仍可能失败。

  </StepCard>
  <StepCard number="3" title="在 WCPOS 中输入 URL 和 API 密钥">

在 **WP Admin > POS > 设置 > 云打印** 中添加打印机，选择 **Star Online** 作为提供商，然后粘贴 CloudPRNT URL 和 API 密钥。点击**获取我的设备**。

  </StepCard>
  <StepCard number="4" title="选择 Star 设备" isLast>

从设备列表中选择打印机并保存。WCPOS 将 API 密钥存储在服务器端，并在向 Star Online 提交任务时使用所选设备的访问标识符。

  </StepCard>
</Steps>

## 自动打印规则 {#auto-print}

自动打印规则用简单的句子描述自动打印的内容及目标位置。规则由**范围 × 打印机 × 模板**组成，还包括触发**时间**和打印**份数**，例如：

> **每笔订单**在**付款后**，使用**厨房单**模板打印到**厨房**，打印份数为 **×2**。

规则可以在**订单创建时**触发，也可以**仅在付款后**触发，这样厨房单在下单时即可打印，而顾客收据等到付款后再打印。如果某个工作站需要多份，还可以设置**打印份数**。匹配的订单满足所选触发条件后，WCPOS 会在服务器端将所选**模板**渲染为打印机所需的格式并加入队列，收银员无需操作。

:::note 注意模板兼容性
Star 和 Epson 打印机只能使用**热敏**模板，因为任务必须渲染为打印机的原生命令语言（Star 使用 Star Document Markup 或 ESC/POS，Epson 使用 ePOS-Print）。PrintNode 可以使用**任何**模板，包括热敏模板和整页 HTML 模板，因为任务会渲染为 **PDF**。如果某个模板未出现在打印机的可选列表中，说明打印机无法渲染该格式。有关创建热敏布局的信息，请参阅[热敏模板](/1.x/receipts/thermal-templates)。
:::

## 按店铺配置打印机（Pro） {#per-store-printers}

:::info Pro 功能
按店铺路由打印任务需要 [WCPOS Pro](/1.x/getting-started/pro-license) 和[多店铺](/1.x/stores)设置。
:::

默认情况下，自动打印规则是全局的，由所有店铺共享。使用 Pro 后，您可以为单个店铺设置**专属**的云打印规则，将其订单打印到自己的打印机（某个地点的厨房单不应在另一个地点打印）。

在 **POS → 店铺** 下编辑店铺，打开**云打印**部分，然后点击**添加规则**。每条规则包含：

- **打印机 ID** —— 接收任务的云打印机的固定 ID
- **范围** —— **仅 POS 订单**（默认）、**仅在线订单**或**每个订单**
- **格式** —— **StarPRNT**（默认）、**ESC/POS**、**Epson ePOS-Print** 或 **HTML**

当订单所属的店铺设有专属规则时，WCPOS 会将订单路由到该店铺的打印机。如果店铺**没有**自己的规则，则会**回退到全局**自动打印规则，因此您只需配置有不同需求的店铺。

## 手动打印 {#manual}

无需等待自动打印规则触发。收银员可在**结账/收据界面**按需将收据发送到云打印机，方便重新打印，或临时将某张单据发送到指定打印机。

收据的生成方式取决于打印机：

- **Star CloudPRNT** —— 收据**在设备上**渲染，再通过 CloudPRNT 交给打印机。
- **Star Online、Epson 和 PrintNode** —— 收据根据所选订单和模板**在服务器上**渲染，再投递到打印机或托管中继。

:::note 打印机无法处理某些格式时的渲染回退方案
**Star CloudPRNT** 会与打印机协商媒体类型；如果打印机不接受更丰富的格式，则回退为纯文本(`text/plain`)。对于固件无法解码 StarPRNT 命令的 Star 打印机，WCPOS 可以在**服务器端将收据渲染为 PNG 图像**，改为发送图像，使收据仍能打印，避免失败。
:::

## 打印队列 {#print-queue}

每个云打印任务都会在您的站点上排队，直到打印机取走任务（轮询打印机）或提供商确认投递。**WP Admin > POS > 设置 > 云打印**会在打印机下方显示队列：

- 按打印机或状态**筛选**，状态包括**等待**、**打印中**、**已打印**、**失败**、**已取消**，并显示实时数量。
- 每一行显示收据已**等待**多长时间，并提供其对应 WooCommerce **订单**的链接。
- 可逐个、批量或一次性**取消**某台打印机的所有待处理任务。**重试**会将失败的任务重新加入队列。

如果打印机有待处理任务，但已超过几分钟未取走任何任务，系统会显示**警告横幅**，列出打印机名称、积压收据数量和等待时长，并提供**全部取消**操作。这样，打印机拔掉后，任务积压也不会悄然发生。

## 测试打印与连接状态 {#status}

每张打印机卡片都有**测试打印**按钮，可发送简短的诊断内容，让您在打印真实订单前确认打印机能够连接且格式正确。

卡片还会显示实时状态：

| 提供商 | 状态 | 含义 |
|----------|--------|---------|
| **Star CloudPRNT / Epson** | **等待** | 打印机尚未联系 WCPOS，WCPOS 正在等待其首次轮询。 |
| **Star CloudPRNT / Epson** | **已连接** | 打印机最近轮询过 WCPOS，正在获取任务。 |
| **Star Online** | **在线** | Star Online 报告所选设备可用。 |
| **Star Online** | **离线** | Star Online 报告所选设备不可用。 |
| **Star Online** | **未知** | WCPOS 无法从 Star Online 确认设备状态。 |
| **PrintNode** | **在线** | PrintNode 服务报告客户端和打印机均可用。 |
| **PrintNode** | **离线** | PrintNode 报告客户端或打印机不可用。 |

## 故障排除 {#troubleshooting}

<Accordion>
  <AccordionItem question="打印机一直处于等待状态">

  轮询打印机始终处于**等待**状态，说明它从未成功联系到 WCPOS。请检查：

  - 打印机固件中的**轮询 URL 和令牌**必须与 WCPOS 生成的完全一致。哪怕只有一个字符错误，每次轮询也会被拒绝。如果不确定，请在 WCPOS 中重新生成令牌并重新输入。
  - 打印机能通过互联网**访问您的站点**（DNS 正确、防火墙未阻止出站 HTTPS、店铺的 SSL 证书有效）。
  - 打印机的 CloudPRNT / Server Direct Print 配置中**已启用轮询**，且间隔合理。更改设置后请重启打印机。
  - 如果您输入了**直连站点的 URL**（位于高级展开项中），但打印机仍无法连接，请改用标准的 **cloudprint.wcpos.com** URL。许多打印机无法与现代托管环境协商安全连接，而[这正是中继解决的问题](#relay)。

  </AccordionItem>

  <AccordionItem question="为什么打印机 URL 指向 cloudprint.wcpos.com？">

  这是 [WCPOS Cloud Print](#relay)，一个免费中继，为打印机提供其固件能够完成协商的连接，并将打印任务转发到您的店铺。它会自动启用，绝不存储任务。如果您更希望直接连接，打印机的**高级**展开项中始终提供直连站点的 URL。

  </AccordionItem>

  <AccordionItem question="我在推出中继之前已设置好打印机，需要更改配置吗？">

  不需要，已保存在打印机配置中的 URL 仍然有效。不过，如果打印机**一直处于等待状态**，其固件很可能无法直接连接您的托管环境。请在打印机卡片上打开**设置与令牌**，重新生成令牌，然后在打印机配置中输入新的 **cloudprint.wcpos.com** URL 和令牌。

  </AccordionItem>

  <AccordionItem question="Star Online 提示 API 密钥未授权或禁止访问">

  Star Online 将**身份验证**和**权限**分开处理：

  - **401 / 身份验证失败**表示 API 密钥本身未被接受。请检查密钥是否复制正确、是否未被撤销，以及是否属于预期的 Star Online 账户/区域。
  - **403 / 禁止**表示 API 密钥已被接受，但没有执行所请求操作的权限。在 stario.online 中编辑密钥，启用所需权限，尤其是**获取我的设备**所需的 **EnumDevices** 和打印所需的 **PrintToDevice**。

  如果**获取我的设备**成功，但未显示任何打印机，请检查 stario.online 的**设备组**页面。该组必须至少包含一台已连接的设备，且 WCPOS 中的 CloudPRNT URL 必须指向同一设备组。

  </AccordionItem>

  <AccordionItem question="PrintNode 任务始终未打印">

  任务已到达 PrintNode，但打印机没有输出。请检查：

  - 连接打印机的计算机上的 **PrintNode 桌面客户端正在运行且在线**。如果计算机处于睡眠状态或客户端已关闭，就无法打印。
  - 您在 WCPOS 中选择了**正确的打印机**，名称必须与客户端报告的打印机一致。
  - **API 密钥有效**且未被撤销。如果 PrintNode 显示打印机离线，请重新输入密钥。

  </AccordionItem>

  <AccordionItem question="无法为 Star 或 Epson 打印机选择我的模板">

  Star 和 Epson 云打印机只能使用**热敏**模板，因为收据必须渲染为 ESC/POS 或 ePOS-Print 命令。HTML 和整页模板无法用这些格式表达，因此不会出现在这些打印机的可选列表中。

  请选择[热敏模板](/1.x/receipts/thermal-templates)，或使用 **PrintNode** 打印机。PrintNode 渲染为 PDF，因此可以打印任何模板。

  </AccordionItem>
</Accordion>
