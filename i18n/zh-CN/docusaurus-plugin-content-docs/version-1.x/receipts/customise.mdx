如果您想更改收据的外观，有三种方式可以选择。选择最适合您需求的方式——大多数店铺只需要第一种即可。

## 三种自定义方式 {#three-ways-to-customise}

<FeatureGrid>
  <FeatureCard icon="grid" title="1. 选择不同的模板">
    从模板库中选择一个现成模板。**完全不需要编写代码。** 适用于：更换版式、隐藏价格、制作 A4 发票或厨房小票。
  </FeatureCard>
  <FeatureCard icon="sparkles" title="2. 让 AI 帮您调整">
    将模板粘贴到 ChatGPT 或 Claude 中，描述您想要的效果。**无需编码技能**——用自然语言描述即可。适用于：小幅调整，如措辞、颜色或元素位置。
  </FeatureCard>
  <FeatureCard icon="code" title="3. 手动编辑">
    应用内编辑器允许您直接修改模板。适用于：精确控制，或者您已经熟悉 HTML。
  </FeatureCard>
</FeatureGrid>

三种方式的起点相同：**WP Admin → POS → 模板**。页面分为两部分——顶部是**您的模板**（当前正在使用的模板），下方是**模板库**（预置的模板合集）。

## 选项 1 — 选择其他模板 {#option-1--pick-a-different-template}

这是最简单的方式，能满足大多数需求。

<Steps>
  <StepCard number="1" title="打开模板库">

在 WP Admin 中前往 **POS → 模板**。向下滚动跳过*您的模板*，找到**模板库**部分——这是入门模板合集。

  </StepCard>
  <StepCard number="2" title="浏览和预览">

可按**类别**（收据、发票、礼品收据、厨房单、报价单 / 采购订单）、**格式**（用于浏览器打印的 HTML、用于热敏打印机的热敏格式）或**方向**（从左到右或从右到左）筛选。点击任意卡片的缩略图，或点击其页脚中的**预览**链接，即可使用店铺的真实数据打开实时预览。

  </StepCard>
  <StepCard number="3" title="使用模板" isLast>

点击卡片上的**使用模板**按钮。WCPOS 会创建一个可编辑的副本，并将其添加到页面顶部的**您的模板**中。切换该行的**启用**开关即可在收据中使用；拖动该行的手柄可调整顺序。您可以同时启用多个模板——收银员在收银台自行选择。

  </StepCard>
</Steps>

:::tip “使用模板”不会替换任何内容
点击**使用模板**始终会创建一个全新的副本。原始的模板库模板保持不变，因此您可以随时返回选择不同的起点。如果同时启用了多个收据模板，收据界面会显示一个下拉菜单，方便收银员随时切换。
:::

### 内置模板 {#the-bundled-templates}

| 模板 | 格式 | 用途 |
|---|---|---|
| **标准收据** | HTML | 默认模板——包含 Logo、商品、合计、付款信息，适用于大多数店铺 |
| **标准收据（RTL）** | HTML | 与标准收据相同，为阿拉伯语/希伯来语/波斯语/乌尔都语镜像排版 |
| **简约/现代** | HTML | 与标准收据信息相同，纵向空间更紧凑 |
| **详细收据** | HTML | 完整税务发票——包含 SKU 列、单价、分税率明细、地址 |
| **礼品收据** | HTML | 仅显示商品——隐藏价格，包含礼品留言和退货政策 |
| **发票** | HTML | A4/Letter 整页发票，为未付款订单添加\"付款方式\"面板 |
| **装箱单** | HTML | 仓库配套单据——包含商品和数量、收货地址，不含价格 |
| **报价单/估价单** | HTML | 售前文档，包含定价和条款——无付款部分 |
| **窄幅收据** | HTML | 等宽字体收据，适用于窄幅纸张或支持 HTML 的热敏打印机 |
| **简易热敏收据（58mm）** | 热敏 | 简洁的 58mm 热敏打印布局 |
| **简易热敏小票（80mm）** | 热敏 | 简洁的 80mm 热敏布局——最常用 |
| **简易热敏小票 80mm（RTL）** | 热敏 | 80mm 的 RTL 对应版本。需要支持阿拉伯语代码页的打印机 |
| **详细热敏小票（58mm / 80mm）** | 热敏 | 添加税费明细、地址、退款、付款、条款、条形码 |
| **厨房小票** | 热敏 | 仅显示商品、大字体、无价格——适用于备餐台 |

大多数内置模板会**自动适配店铺的税费设置**——含税店铺显示含税价格和"含税"行；不含税店铺显示净价，税费作为单独一行显示。**详细**系列模板无论设置如何，始终显示完整的税费明细。

### WP Overnight 发票和装箱单模板 {#wp-overnight-invoice-and-packing-slip-templates}

如果您的站点还使用了 WP Overnight 的 [PDF Invoices & Packing Slips for WooCommerce](https://wordpress.org/plugins/woocommerce-pdf-invoices-packing-slips/)，WCPOS 会自动向**您的模板**中添加两个额外的模板：

| 模板 | 格式 | 用途 |
|---|---|---|
| **发票（WP Overnight）** | 服务器端渲染的 HTML | 使用 WP Overnight 配置的发票文档处理 POS 订单 |
| **装箱单（WP Overnight）** | 服务器端渲染的 HTML | 使用 WP Overnight 配置的装箱单文档处理 POS 订单 |

这些模板不会复制 WCPOS 内置的发票或装箱单布局，而是请求 WP Overnight 为 POS 订单渲染文档。因此，线上订单与店内订单会保持一致，沿用您现有的发票编号、品牌标识、法律/税务字段及 WP Overnight 模板自定义设置。

这些模板仅在 WP Overnight 插件启用时显示。输出会在 WCPOS 打印界面中以 HTML 形式打开，而不是单独下载 PDF。由于文档在服务器上渲染，打印这些模板时 POS 需要连接您的站点；如需离线打印，请使用内置的 HTML 或热敏模板。

## 按店铺分配 {#per-store-assignments}

如果您有多个[店铺](/1.x/stores)（Pro），每个店铺都可拥有**独立的模板选择和排序**，与全站默认设置分开。街边的咖啡馆可以使用带有不同徽标和地址的小型热敏收据；仓库可以使用装箱单；主店铺则保留标准收据，所有模板均来自同一个模板库。

前往 **WP Admin → POS → 店铺**，打开要配置的店铺。**编辑店铺**页面的**收据模板**区域中有一个*“店铺专属收据模板”*开关：

- **关闭** *（默认）*——店铺继承 **POS → 模板** 主页面中的全站模板列表。
- **开启**——店铺拥有独立的模板选择和排序，与全站默认设置分开。拖动手柄调整顺序的方式相同。

每个店铺的**信头**也在同一个编辑店铺页面中设置，包括徽标、地址、联系方式，以及*收据信息*区块中的结束语、退货政策和页脚。内置模板会读取这些按店铺设置的字段，因此同一个“标准收据”模板可以在不同地点显示不同的品牌信息。

收银员在某个店铺登录后，收据下拉菜单只显示该店铺已启用的模板。

:::tip 全站设置与按店铺设置
WP Admin 中的**模板**页面设置全站默认模板。按店铺覆盖设置可让同一个模板（例如标准收据）在不同地点展示不同的品牌信息，也可让某个地点使用其他地点不使用的布局。如果所有店铺都需要相同的模板，只需将按店铺分配留空，即可应用全站默认设置。
:::

## 选项 2 — 请 AI 帮忙调整 {#option-2--ask-ai-to-tweak-it}

如果模板库中的模板接近但还不完全符合需求，AI 助手可以在几分钟内帮您修改，您无需了解 HTML。

<Steps>
  <StepCard number="1" title="复制模板">

在 **WP Admin → POS → 模板** 中打开您想用作起点的模板，点击编辑器，选中左侧所有文本（Ctrl/Cmd + A），然后复制。

  </StepCard>
  <StepCard number="2" title="粘贴到 ChatGPT 或 Claude 中">

打开 [ChatGPT](https://chat.openai.com) 或 [Claude](https://claude.ai)。粘贴模板，然后用简单的语言描述您的需求：

  </StepCard>
  <StepCard number="3" title="描述需要更改的内容">

明确告诉 AI 您的需求。以下是一些有效的示例：

- *“将店铺名称放大并居中显示。”*
- *“在底部添加一条斜体的感谢语。”*
- *“隐藏顾客姓名，改为在订单号下方添加电话号码。”*
- *“将条形码改为链接到我的退货页面的二维码。”*
- *“在店铺名称下方添加标语‘家族经营，始于 1987 年’。”*

AI 会返回修改后的模板。

  </StepCard>
  <StepCard number="4" title="粘贴回编辑器" isLast>

复制 AI 的回复。回到 WCPOS 模板编辑器，全选（Ctrl/Cmd + A），粘贴新版本，然后点击**更新**。右侧预览会刷新，方便您查看修改效果。如果效果不对，请向 AI 描述问题，让它修正。

  </StepCard>
</Steps>

:::tip 最佳实践
每次在模板库中点击**使用模板**，都会创建一个全新的可编辑副本，原始模板始终保留。如果您在尝试不同方案，可以多次使用同一个模板库模板，为副本重命名*（收据 v1、收据 v2）*，并在做决定时来回切换。
:::

:::info 变量怎么处理？
`{{store.name}}` 和 `{{order.number}}` 这样的内容是实际数据的**占位符**。AI 能理解它们，您无需了解细节。如需查看所有可用占位符，请参阅[收据数据参考](/1.x/receipts/receipt-data)。
:::

## 选项 3 — 手动编辑 {#option-3--edit-it-by-hand}

如果您了解一些 HTML（或与开发者合作），可以直接在应用内编辑器中编辑模板。编辑器提供实时预览、语法高亮、可搜索的字段选择器、撤销/重做及查找替换功能。

选择模板引擎：

- **[HTML 模板](/1.x/receipts/html-templates)** —— 使用 Mustache 风格的 `{{variable}}` 占位符，在客户端渲染，支持离线使用。**推荐大多数店铺使用。**
- **[热敏打印模板](/1.x/receipts/thermal-templates)** —— 用于 ESC/POS 热敏打印机的 XML。同一模板同时生成屏幕预览和打印输出。
- **[收据数据参考](/1.x/receipts/receipt-data)** —— 按分区列出所有可用占位符。

:::note 旧版 PHP 模板
如果您之前通过主题中的 PHP 文件(`yourtheme/woocommerce-pos/receipt.php`)覆盖收据，该方式仍然有效。现在它在模板库中标为**旧版 PHP 模板**，与新的无逻辑和热敏模板引擎并列。WP Overnight 集成也采用服务器端渲染，因为第三方文档 API 在服务器上渲染 HTML。新的自定义应使用模板库或应用内编辑器，它们支持离线使用和实时预览，无需与服务器来回通信。
:::

## 常见自定义 {#common-customisations}

以下是常见问题的简要解答。

<Accordion>
  <AccordionItem question="如何添加店铺徽标？">

徽标来自店铺设置，而非模板本身。前往 **WP Admin > POS > 设置 > 店铺**，编辑店铺并上传徽标。所有显示徽标的内置模板都会自动使用它。

如果您想更改徽标在模板中的*显示位置*，请编辑模板，将 `{{#store.logo}}<img src="{{store.logo}}" ...>{{/store.logo}}` 代码块移至所需位置。

  </AccordionItem>

  <AccordionItem question="如何更改页脚文本（例如“感谢您的惠顾！”）？">

有两种方式：

1. **最简单的方法** —— 在 **WP Admin > POS > 设置 > 店铺 > 店铺详情 > 收据页脚 / 个人备注** 中设置一次，即可应用于所有收据。内置模板会自动读取；如果未设置页脚，则会使用友好的默认文本，例如*“感谢您的惠顾！”*。
2. **在单个模板中** —— 编辑模板并直接替换页脚文本。查找 `{{store.personal_notes}}` 或直接写在模板中的感谢语。

  </AccordionItem>

  <AccordionItem question="如何在店铺名称下方添加标语或口号？">

编辑模板，在 `{{store.name}}` 下方添加一行：

```html
<div style="font-style: italic; color: #6b7280;">Family-owned since 1987</div>
```

在热敏打印模板中：

```xml
<align mode="center"><text>Family-owned since 1987</text></align>
```

  </AccordionItem>

  <AccordionItem question="如何隐藏价格（用于礼品收据）？">

在模板库中点击**礼品收据**卡片上的**使用模板**，即可隐藏所有价格和总计，同时保留商品、SKU、属性和礼品留言。无需编辑。

如果您希望自行制作不含价格的收据，请复制任意模板，并删除 `{{...total...}}`、`{{...price...}}` 和 `{{#totals}}...{{/totals}}` 代码块。

  </AccordionItem>

  <AccordionItem question="如何将条形码改为二维码？">

在模板中找到 `<barcode>` 元素，并修改其 `type` 属性：

```html
<!-- Default: Code 128 barcode of the order number -->
<barcode type="code128">{{order.number}}</barcode>

<!-- Switch to a QR code -->
<barcode type="qrcode">{{order.number}}</barcode>

<!-- Or encode something else, like a returns URL -->
<barcode type="qrcode">https://example.com/returns?order={{order.number}}</barcode>
```

相同的 `<barcode>` 语法在 HTML 和热敏打印模板中均适用。其他支持的类型包括 `ean13`、 `ean8`、 `upca`、 `pdf417`，以及 [bwip-js 支持的所有格式](https://github.com/metafloor/bwip-js/wiki/Supported-Barcode-Types)。

  </AccordionItem>

  <AccordionItem question="如何将不同的模板发送到特定打印机？">

在 POS 应用中，前往 **POS > 设置 > 打印**，然后查看**收据模板**。您会看到每个已启用的模板旁都有一个打印机下拉菜单。选择所需打印机，或保留为**自动**。

- **自动**模式会自动将模板匹配到打印机——热敏模板发送到热敏打印机，HTML 模板发送到系统打印对话框。
- **指定打印机**会覆盖自动模式，始终将该模板发送到指定的打印机。
- 打印时，收银员可以通过收据界面上的打印机下拉菜单覆盖以上任一设置。

路由设置按设备存储，因此每台 iPad 或电脑可以有各自的配置。

  </AccordionItem>

  <AccordionItem question="编辑后收据仍然显示旧版本">

在模板编辑界面点击 WordPress 的**更新**按钮。编辑器不会自动保存——您的更改只有在点击更新后才会保留。

对于**旧版 PHP 模板**，编辑器中的预览显示的是*上次保存*的版本，而非当前正在输入的内容。请先保存，然后刷新预览。

  </AccordionItem>

  <AccordionItem question="预览为空白或显示&quot;未找到 POS 订单&quot;">

此问题仅出现在**旧版 PHP 模板**中，因为它们需要一个真实订单才能进行预览。处理一笔 POS 订单（即使是 $0 的测试交易）后，预览即可正常显示。

无逻辑（HTML）模板和热敏打印模板始终有示例数据可供回退，因此即使在全新店铺上也能正常预览。

  </AccordionItem>

  <AccordionItem question="搞乱了——如何重新开始？">

三重安全保障：

1. 编辑器提供**撤销**功能（Ctrl/Cmd + Z），可恢复当前会话中的更改。
2. 每次保存都会创建一个 WordPress **修订版本**——在编辑页面打开**修订版本**即可比较并恢复任何先前的版本。
3. 如果您是从模板库中的模板开始的，请在*您的模板*中点击副本上的**删除**，然后再次点击同一模板库卡片上的**使用模板**，即可获得一份全新的未修改副本。

  </AccordionItem>
</Accordion>

## 何时寻求帮助 {#when-to-ask-for-help}

- 模板编辑器无法加载，或保存后更改未生效。
- 收据在一台设备上打印正常，但在另一台设备上无法正常打印。
- 您需要符合特定国家（意大利、巴西、西班牙等）财税或法律要求的布局，通常可通过 [WCPOS Pro](/1.x/getting-started/pro-license) 或针对该国家的集成方案实现。
- 您正在尝试自定义内容，但 AI 无法完全实现预期效果。

请提交[支持工单](https://wcpos.com/support)并粘贴您正在使用的模板——这将为我们提供帮助您所需的全部信息。
