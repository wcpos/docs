## German (de) — docs rules

- Formal "Sie" or neutral instructional wording throughout. Never informal imperatives such as "Gehe" or "Aktiviere".
- Terms the German docs already use: Zahlungsgateway (payment gateway), Bargeld-Gateway (Cash gateway), Checkout-Einstellungen (Checkout Settings), Checkout-Fehlerbehebung (Checkout Troubleshooting), Gateway-Vorlage (gateway template, never "Gateway-Template"), Vorlage (template), Beleg (receipt), Kassierer (cashier), Rückerstattung (refund).
- A WCPOS store location is "Filiale" / "Filialen", never "Store", "Stores" or "pro Store".
- Search at the checkout is "Kassensuche", never "Kassierersuche". In-person is "Vor-Ort", never "persönlicher Einsatz".
- Keep "POS" when it is the product or domain acronym, as "im POS" / "den POS" (never "die POS" or "in der POS").
- Keep Stripe Terminal, SumUp Terminal, Barcode and Upgrade unchanged.
- Compound nouns are one word ("Rückerstattung", not "Rück Erstattung"). Decimal comma: 0,25. German quotation marks „…“ in prose.
