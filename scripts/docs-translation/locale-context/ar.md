## Arabic (ar) — docs rules

- Professional Modern Standard Arabic (فصحى) documentation wording.
- The page is right-to-left, but code spans, URLs, placeholders, MDX syntax and brand names (WCPOS, WooCommerce, POS) stay exactly as in the source.
- Use "نموذج" consistently for "template" and "بوابة الدفع" for "payment gateway", matching WooCommerce's Arabic translation.
- After a number placeholder, use the singular noun form; the numeral carries the plural.
- Translate POS when it is a visible app or admin menu label and the app has an Arabic label for it.
