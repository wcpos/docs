## French (fr) — docs rules

- Professional register with "vous" throughout.
- A retail location is "boutique" / "boutiques" or "point(s) de vente". Keep WCPOS exactly and never shorten it to POS.
- A standalone "POS" (not part of WCPOS) is "PDV" or "point de vente", including admin menu labels. Never "paiement POS".
- WordPress plugins are "extensions", not "plugins". API/server requests are "requêtes", not "demandes".
- Order statuses: "En attente de paiement" (Pending) and "Suspendue" (On hold) are different statuses; never render both as "En attente".
- After "et", use an infinitive or a noun with its article: "Enregistrer et prévisualiser", not "Enregistrer et aperçu".
- Use "p. ex." or "par ex.", never "eg:" or "e.g.". Decimal comma: 0,25. French punctuation spacing in prose (never inside code spans).
