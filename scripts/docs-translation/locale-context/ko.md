## Korean (ko) — docs rules

- Concise professional Korean. Explanations end in 합니다체; instructions use 해요체 imperatives (확인하세요), as the existing docs do. Avoid stiff 하십시오체.
- A WCPOS store location is "매장", never "스토어" (so never "WCPOS Pro 스토어"). A payment gateway is "결제 게이트웨이".
- Prefer native Korean over loanwords where natural (작업 over 액션, 용지 over 지면), and use full particles (템플릿이 삭제되었습니다).
- Keep WCPOS exactly. Translate POS when it is a visible app or admin menu label and the app has a Korean label for it.
