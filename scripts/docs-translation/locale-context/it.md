## Italian (it) — docs rules

- Professional Italian. Imperatives use the informal "tu" form, as the app and the existing docs do ("Vai", not "Vada"); descriptions are often impersonal ("il cassiere può…").
- A retail location is "negozio" / "negozi" or "punto/i vendita". Keep WCPOS exactly; never shorten it to POS.
- Keep "Gateway di pagamento" and "Template" where WooCommerce's Italian translation keeps them.
- Decimal comma: 0,25.
