## Brazilian Portuguese (pt-BR) — docs rules

- Professional Brazilian Portuguese documentation register, addressing the reader as "você".
- A retail location is "loja" / "lojas". A payment gateway is "gateway de pagamento", as the existing docs use. Keep WCPOS exactly; never shorten it to POS.
- Translate POS when it is a visible app or admin menu label and the app has a Portuguese label for it.
- Decimal comma: 0,25.
