## Simplified Chinese (zh-CN) — docs rules

- Concise professional Simplified Chinese documentation wording.
- A WCPOS store location is "店铺", never "商店" (so never "WCPOS Pro 商店").
- Use full-width Chinese punctuation in prose (，：。), not ASCII commas or colons, but never change code spans, URLs or MDX syntax.
- Keep WCPOS exactly. Translate POS when it is a visible app or admin menu label and the app has a Chinese label for it.
