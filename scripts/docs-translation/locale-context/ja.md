## Japanese (ja) — docs rules

- Concise professional Japanese documentation style (です・ます調). Reorder sentences naturally instead of following English word order.
- A WCPOS store location is "店舗", never "ストア" (so never "WCPOS Pro ストア").
- Keep WCPOS exactly. Translate POS when it is a visible app or admin menu label and the app has a Japanese label for it.
