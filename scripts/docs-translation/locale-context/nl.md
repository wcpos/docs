## Dutch (nl) — docs rules

- Professional Dutch software-documentation wording, addressing the reader as "je" as the existing docs do.
- A retail location is "winkel" / "winkels". A receipt is "bon" (or "kassabon"). Keep WCPOS exactly.
- Translate POS when it is a visible app or admin menu label and the app has a Dutch label for it.
- Decimal comma: 0,25.
