## Spanish (es) — docs rules

- Neutral professional Spanish with formal "usted" or impersonal wording. Never informal tú imperatives such as visita, crea, descarga, instala, configura, activa, habilita, envía, acepta or procesa.
- Recibo is a POS receipt; never "Factura" (a formal invoice) for receipts.
- A retail location is "tienda" / "tiendas". Keep WCPOS exactly; never shorten it to POS.
- In admin breadcrumbs, use the WordPress, WooCommerce and WCPOS Spanish labels; keep POS as POS where the WCPOS labels do.
- Decimal comma: 0,25.
